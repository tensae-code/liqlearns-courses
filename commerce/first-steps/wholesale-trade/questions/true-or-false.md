# Wholesale Trade — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** In Samoa, wholesalers are the prominent middle people in most chains. (Sub lesson 1)
**Answer: False** — Samoa's way: the wholesaler is not prominent; importers usually sell directly to retailers.

**2.** Money flows back up the distribution chain, so each party benefits. (Sub lesson 1)
**Answer: True** — The taro chart shows money flowing back up so each party benefits.
