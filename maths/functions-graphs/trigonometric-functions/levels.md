# Trigonometric Functions — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the trig functions as functions —
any angle and its signs first, then the graphs with period and
asymptotes, then amplitude, phase and sinusoidal models.

## Level 1 — functions of any angle
Level 1 questions from the type files. Pass mark: give sine,
cosine and tangent for angles past 90°, and name the sign of
each function in each quadrant.

## Level 2 — the graphs
Level 2 questions from the type files. Pass mark: sketch
y = sin x, y = cos x and y = tan x over one period, state each
domain and range, and mark the tangent's asymptotes.

## Level 3 — amplitude, period, phase and models
Level 3 questions from the type files. Pass mark: read the
amplitude, period, phase shift and middle line off
a + b sin(cθ + d), and fit a simple sinusoidal model to a
tide- or wheel-shaped pattern.
