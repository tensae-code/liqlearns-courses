# Trigonometric Functions — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
trigonometric functions — any angle and its signs first,
then the graphs with period and asymptotes, then amplitude,
phase and sinusoidal models, the order the books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Trig Functions of Any Angle
Sub lesson 1 questions from the type files. Pass mark: give sine, cosine and tangent for angles past 90°, and name the sign of each function in each quadrant.

## Sub lesson 2 — The Graphs of the Trig Functions
Sub lesson 2 questions from the type files. Pass mark: sketch y = sin x, y = cos x and y = tan x over one period, state each domain and range, and mark the tangent's asymptotes.

## Sub lesson 3 — Amplitude, Period, Phase and Models
Sub lesson 3 questions from the type files. Pass mark: read the amplitude, period, phase shift and middle line off a + b sin(cθ + d), and fit a simple sinusoidal model to a tide- or wheel-shaped pattern.
