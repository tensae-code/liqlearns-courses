# Trigonometric Functions — true or false

Say true or false, and why in one line.

**1. (Level 1)** sin(400°) = sin(40°). — **True.** 400° is coterminal with 40° — one full turn more, same point, same height.

**2. (Level 1)** cos(−x) = −cos x. — **False.** Cosine is unchanged by turning the other way: cos(−x) = cos x (Iraq, Grade 11, Ch. 4).

**3. (Level 2)** The tangent function is defined for every real angle. — **False.** It fails at odd multiples of π/2, where cosine is zero and the graph has asymptotes.

**4. (Level 2)** Secant can take the value 0.5. — **False.** Secant is 1/cosine, and |cosine| ≤ 1, so |secant| ≥ 1 always (Pakistan, Unit 11).

**5. (Level 3)** Doubling the c in sin(cx) doubles the period. — **False.** The period is 2π/c; doubling c halves the period — the wave is squeezed.

**6. (Level 3)** A sine wave model of a tide needs the time of the first high tide, not just the heights. — **True.** The heights fix the middle line and amplitude; the timing fixes the period and the phase.
