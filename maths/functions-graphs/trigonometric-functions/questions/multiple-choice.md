# Trigonometric Functions — multiple choice

Pick the one right answer.

**1. (Level 1)** sin(210°) is —
a) positive  b) negative  c) zero
**Answer:** b) negative — 210° is in the third quadrant, where the point's height is below the centre line.

**2. (Level 1)** Which angle is coterminal with 30°?
a) 330°  b) 390°  c) 210°
**Answer:** b) 390° — one full turn more; coterminal angles land on the same point of the circle (Iraq, Grade 11, Ch. 4).

**3. (Level 1)** In the second quadrant, the one positive function among sine, cosine, tangent is —
a) sine  b) cosine  c) tangent
**Answer:** a) sine — the height is still positive there; cosine and tangent are negative.

**4. (Level 2)** The period of y = cos x is —
a) π  b) 2π  c) 1
**Answer:** b) 2π — one full walk around the circle (Pakistan, Class 11, Unit 11).

**5. (Level 2)** y = tan x has no value at —
a) x = 0  b) x = π  c) x = π/2
**Answer:** c) x = π/2 — an odd multiple of π/2, where the graph runs to its asymptote (Ethiopia, Grade 10, Unit 4).

**6. (Level 2)** The range of y = sin x is —
a) all real numbers  b) [−1, 1]  c) [0, 1]
**Answer:** b) [−1, 1] — the height on a unit circle never passes the top or the bottom.

**7. (Level 3)** The amplitude and period of y = 3 sin(2x) are —
a) amplitude 3, period 2π  b) amplitude 3, period π  c) amplitude 2, period π
**Answer:** b) amplitude 3, period π — amplitude is |b| = 3; period is 2π/c = 2π/2 (Pakistan, Unit 11).

**8. (Level 3)** For h = 4 + 2 sin(πt/6), the maximum height is —
a) 4  b) 2  c) 6
**Answer:** c) 6 — maximum = a + |b| = 4 + 2.
