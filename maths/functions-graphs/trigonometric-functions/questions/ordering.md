# Trigonometric Functions — ordering

Put the items in the right order.

**1. (Level 1)** Order by size, smallest first: sin(0°), sin(90°), sin(180°), sin(270°).
**Answer:** sin(270°) = −1, then sin(0°) = sin(180°) = 0 (equal), then sin(90°) = 1 — the height around the circle.

**2. (Level 2)** Order these functions by period, shortest first: y = tan x, y = sin x, y = sin(x/2).
**Answer:** y = tan x (period π), then y = sin x (period 2π), then y = sin(x/2) (period 4π).

**3. (Level 3)** Order the steps for building y = 2 sin(3x) from y = sin x: (a) squeeze the period to 2π/3; (b) draw y = sin x; (c) stretch the amplitude to 2.
**Answer:** b, a, c — start from the parent wave, then apply the squeeze and the stretch (China, §7.3, pp.36–56).

**4. (Level 3)** Order these waves by amplitude, smallest first: y = 5 + sin x; y = 3 sin(2x); y = 1 + 4 cos x; y = −2 sin x.
**Answer:** y = 5 + sin x (amplitude 1), then y = −2 sin x (amplitude 2), then y = 3 sin(2x) (amplitude 3), then y = 1 + 4 cos x (amplitude 4) — amplitude is the size of the number multiplying the function, sign ignored.
