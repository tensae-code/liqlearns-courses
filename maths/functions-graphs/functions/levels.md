# Functions — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — inputs and outputs — set by the
pattern across the countries' books: function or not first,
then the families and their graphs, then composite, inverse
and piecewise.

## Level 1 — function or not
Level 1 questions from the type files. Pass mark: say whether
a table, a set of pairs or a graph is a function, and name the
domain and the range.

## Level 2 — the families and their graphs
Level 2 questions from the type files. Pass mark: work out
f(x) for a number, name the family (constant, linear,
quadratic) from a formula or a graph, and read where a
function is positive or negative from its graph.

## Level 3 — composite, inverse and piecewise
Level 3 questions from the type files. Pass mark: work out a
composite function inside-out, find an inverse function, and
work out a piecewise function on both sides of its break.
