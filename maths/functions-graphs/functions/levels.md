# Functions — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
functions — function or not first, then the families and
their graphs, then composite, inverse and piecewise, the
order the books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Function or Not
Sub lesson 1 questions from the type files. Pass mark: say whether a table, a set of pairs or a graph is a function, and name the domain and the range.

## Sub lesson 2 — Writing a Function and Its Families
Sub lesson 2 questions from the type files. Pass mark: work out f(x) for a number, name the family (constant, linear, quadratic) from a formula or a graph, and read where a function is positive or negative from its graph.

## Sub lesson 3 — Composite, Inverse and Piecewise Functions
Sub lesson 3 questions from the type files. Pass mark: work out a composite function inside-out, find an inverse function, and work out a piecewise function on both sides of its break.
