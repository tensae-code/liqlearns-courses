# Hands-on — Functions

## The machine game
One person is the machine: they secretly pick a rule ("times
3, minus 1"). The others feed in numbers and record the
outputs, then guess the rule. Then the machine answers a
number nobody fed in — the guessers check their rule against
it. A rule that fits every input and gives one output is a
function.

## Function or not?
Deal cards with ordered pairs on them. Sort them into two
piles: functions and not-functions. The test is one question
only: does any input appear twice with a different output?
Argue every card out loud — the arguing is the learning.

## The graph walk
Draw y = x² on big squared paper on the floor. Walk along it:
stand on x = −2 (y = 4), x = −1 (y = 1), x = 0 (y = 0), x = 1
(y = 1), x = 2 (y = 4). Feel the curve dip and rise. Then
walk y = 2x + 1: every step right is two steps up — a
straight climb, no dip.

## The inverse walk
Write a function on a card (f(x) = 2x + 3). A partner writes
its inverse on another card. Test them against each other:
feed 4 through f (11), then 11 through the inverse (4).
If you get home, the inverse is right.
