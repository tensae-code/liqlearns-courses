# Functions — ordering

Put each set in order, smallest to largest or in the order the
steps are done.

**1. (Level 1)** Order these steps for testing a relation: (a) look for an input that appears twice, (b) list the ordered pairs, (c) check whether its outputs differ.
**Answer:** (b), (a), (c).

**2. (Level 2)** f(x) = 2x + 1. Order f(−1), f(0), f(1), f(2) from smallest to largest.
**Answer:** f(−1) = −1, f(0) = 1, f(1) = 3, f(2) = 5.

**3. (Level 2)** Order these functions by the steepness of their graphs: f(x) = x, f(x) = 3x, f(x) = (1/2)x.
**Answer:** f(x) = (1/2)x, f(x) = x, f(x) = 3x.

**4. (Level 3)** f(x) = 2x + 4. Order these steps for finding its inverse: (a) swap x and y, (b) write y = 2x + 4, (c) solve for y to get y = (x − 4)/2.
**Answer:** (b), (a), (c).

**5. (Level 3)** Order these composite values from smallest to largest, for f(x) = x² and g(x) = x + 1: f(g(0)), g(f(0)), f(g(1)), g(f(1)).
**Answer:** g(f(0)) = 1, f(g(0)) = 1, g(f(1)) = 2, f(g(1)) = 4. (f(g(0)) and g(f(0)) tie at 1.)
