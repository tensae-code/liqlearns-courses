# Functions — true or false

Say true or false, and why in one line.

**1. (Level 1)** A function can give two different outputs for the same input. — **False.** One input, one output — that is the definition.

**2. (Level 1)** Two different inputs can give the same output in a function. — **True.** f(x) = x² gives 4 for both 2 and −2; it is still a function.

**3. (Level 1)** {(1, 5), (2, 5), (3, 5)} is a function. — **True.** Every input has exactly one output (5).

**4. (Level 2)** f(x) = 2x + 1 is a linear function. — **True.** Its graph is a straight line.

**5. (Level 2)** f(3) for f(x) = x² is 6. — **False.** f(3) = 9.

**6. (Level 2)** A constant function has the same output for every input. — **True.** f(x) = 5 always gives 5.

**7. (Level 3)** g(f(2)) is always the same as f(g(2)). — **False.** Order matters: doubling then adding 3 is not adding 3 then doubling.

**8. (Level 3)** Every function has an inverse function. — **False.** Only a one-to-one function (never the same output twice) has an inverse.
