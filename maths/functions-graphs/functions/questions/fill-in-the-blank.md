# Functions — fill in the blank

Put the missing word or number in the space.

**1. (Level 1)** A function gives exactly ______ output for each input.
**Answer:** one.

**2. (Level 1)** The set of all inputs is the ______.
**Answer:** domain.

**3. (Level 1)** The set of outputs that actually come out is the ______.
**Answer:** range.

**4. (Level 2)** f(x) = 2x + 1. f(0) = ______.
**Answer:** 1.

**5. (Level 2)** A linear function has a ______-line graph.
**Answer:** straight.

**6. (Level 2)** A quadratic function has a ______ for a graph.
**Answer:** parabola (curve).

**7. (Level 3)** In g(f(x)), the function ______ runs first.
**Answer:** f (the inner one).

**8. (Level 3)** The inverse of f undoes f: f⁻¹(f(x)) = ______.
**Answer:** x.
