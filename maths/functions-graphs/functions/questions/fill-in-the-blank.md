**1. (Sub lesson 1)** A function gives exactly ______ output for each input.
**Answer:** one.

**2. (Sub lesson 1)** The set of all inputs is the ______.
**Answer:** domain.

**3. (Sub lesson 1)** The set of outputs that actually come out is the ______.
**Answer:** range.

**4. (Sub lesson 2)** f(x) = 2x + 1. f(0) = ______.
**Answer:** 1.

**5. (Sub lesson 2)** A linear function has a ______-line graph.
**Answer:** straight.

**6. (Sub lesson 2)** A quadratic function has a ______ for a graph.
**Answer:** parabola (curve).

**7. (Sub lesson 3)** In g(f(x)), the function ______ runs first.
