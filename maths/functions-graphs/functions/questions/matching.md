# Functions — matching

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Function or Not · (Level 2) -> Sub lesson 2 — Writing a Function and Its Families · (Level 3) -> Sub lesson 3 — Composite, Inverse and Piecewise Functions.

Join the two sides that go together.

**1. (Sub lesson 1)** Match each word to its meaning.
- Domain — a) the outputs that come out
- Range — b) the inputs
- Relation — c) a set of ordered pairs
- Function — d) a relation with one output per input
**Answer:** Domain–b, Range–a, Relation–c, Function–d.

**2. (Sub lesson 2)** Match each formula to its family.
- f(x) = 5 — a) linear
- f(x) = 2x + 1 — b) constant
- f(x) = x² — c) quadratic
**Answer:** f(x) = 5–b, f(x) = 2x + 1–a, f(x) = x²–c.

**3. (Sub lesson 3)** Match each pair to its result for f(x) = 2x and g(x) = x + 1.
- f(g(3)) — a) 7
- g(f(3)) — b) 8
- f⁻¹(6) — c) 3
**Answer:** f(g(3)) = f(4) = 8–b, g(f(3)) = g(6) = 7–a, f⁻¹(6) = 3–c.
