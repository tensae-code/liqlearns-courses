# Functions — matching

Join the two sides that go together.

**1. (Level 1)** Match each word to its meaning.
- Domain — a) the outputs that come out
- Range — b) the inputs
- Relation — c) a set of ordered pairs
- Function — d) a relation with one output per input
**Answer:** Domain–b, Range–a, Relation–c, Function–d.

**2. (Level 2)** Match each formula to its family.
- f(x) = 5 — a) linear
- f(x) = 2x + 1 — b) constant
- f(x) = x² — c) quadratic
**Answer:** f(x) = 5–b, f(x) = 2x + 1–a, f(x) = x²–c.

**3. (Level 3)** Match each pair to its result for f(x) = 2x and g(x) = x + 1.
- f(g(3)) — a) 7
- g(f(3)) — b) 8
- f⁻¹(6) — c) 3
**Answer:** f(g(3)) = f(4) = 8–b, g(f(3)) = g(6) = 7–a, f⁻¹(6) = 3–c.
