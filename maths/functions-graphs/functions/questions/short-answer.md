# Functions — short answer

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Function or Not · (Level 2) -> Sub lesson 2 — Writing a Function and Its Families · (Level 3) -> Sub lesson 3 — Composite, Inverse and Piecewise Functions.

Answer in a word or a short sentence.

**1. (Sub lesson 1)** What is a function, in one sentence?
**Answer:** A relation in which every input has exactly one output.

**2. (Sub lesson 1)** Give the domain of {(1, 2), (2, 4), (3, 6)}.
**Answer:** {1, 2, 3}.

**3. (Sub lesson 1)** Give the range of {(1, 2), (2, 4), (3, 6)}.
**Answer:** {2, 4, 6}.

**4. (Sub lesson 2)** f(x) = x² + 1. What is f(−3)?
**Answer:** 10.

**5. (Sub lesson 2)** What family is f(x) = 7?
**Answer:** A constant function.

**6. (Sub lesson 2)** The graph of y = x² is below the x-axis for no x. Where is the function positive?
**Answer:** Everywhere except x = 0, where it is zero (y = x² is never negative).

**7. (Sub lesson 3)** f(x) = 3x − 6. What is the inverse function?
**Answer:** f⁻¹(x) = (x + 6)/3.

**8. (Sub lesson 3)** A piecewise function is f(x) = x + 1 for x < 0 and f(x) = 2x for x ≥ 0. What is f(−2)? What is f(3)?
**Answer:** f(−2) = −1; f(3) = 6.
