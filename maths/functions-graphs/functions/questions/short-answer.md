# Functions — short answer

Answer in a word or a short sentence.

**1. (Level 1)** What is a function, in one sentence?
**Answer:** A relation in which every input has exactly one output.

**2. (Level 1)** Give the domain of {(1, 2), (2, 4), (3, 6)}.
**Answer:** {1, 2, 3}.

**3. (Level 1)** Give the range of {(1, 2), (2, 4), (3, 6)}.
**Answer:** {2, 4, 6}.

**4. (Level 2)** f(x) = x² + 1. What is f(−3)?
**Answer:** 10.

**5. (Level 2)** What family is f(x) = 7?
**Answer:** A constant function.

**6. (Level 2)** The graph of y = x² is below the x-axis for no x. Where is the function positive?
**Answer:** Everywhere except x = 0, where it is zero (y = x² is never negative).

**7. (Level 3)** f(x) = 3x − 6. What is the inverse function?
**Answer:** f⁻¹(x) = (x + 6)/3.

**8. (Level 3)** A piecewise function is f(x) = x + 1 for x < 0 and f(x) = 2x for x ≥ 0. What is f(−2)? What is f(3)?
**Answer:** f(−2) = −1; f(3) = 6.
