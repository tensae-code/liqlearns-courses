# Functions — multiple choice

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Function or Not · (Level 2) -> Sub lesson 2 — Writing a Function and Its Families · (Level 3) -> Sub lesson 3 — Composite, Inverse and Piecewise Functions.

Pick the one right answer.

**1. (Sub lesson 1)** Which of these is a function?
a) {(1, 2), (1, 3)}  b) {(1, 2), (2, 3)}  c) {(1, 2), (2, 2), (1, 5)}
**Answer: b) {(1, 2), (2, 3)}** — no input repeats with a different output.

**2. (Sub lesson 1)** The domain of a function is —
a) all the outputs  b) all the inputs  c) all the graphs
**Answer: b) all the inputs.**

**3. (Sub lesson 1)** A vertical line cuts a graph twice. The graph is —
a) a function  b) not a function  c) a straight line
**Answer: b) not a function** — one input, two outputs.

**4. (Sub lesson 2)** f(x) = 2x + 1. f(3) = —
a) 6  b) 7  c) 5
**Answer: b) 7.**

**5. (Sub lesson 2)** Which is a quadratic function?
a) f(x) = 5  b) f(x) = 2x + 1  c) f(x) = x²
**Answer: c) f(x) = x².**

**6. (Sub lesson 2)** The graph of f(x) = x² is —
a) a straight line  b) a parabola (a curve)  c) a circle
**Answer: b) a parabola (a curve).**

**7. (Sub lesson 3)** f(x) = 2x, g(x) = x + 3. g(f(2)) = —
a) 7  b) 10  c) 5
**Answer: a) 7** — f(2) = 4, g(4) = 7.

**8. (Sub lesson 3)** The inverse of f(x) = 2x + 3 is —
a) f⁻¹(x) = (x − 3)/2  b) f⁻¹(x) = 2x − 3  c) f⁻¹(x) = (x + 3)/2
**Answer: a) f⁻¹(x) = (x − 3)/2.**
