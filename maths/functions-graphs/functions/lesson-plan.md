# Lesson plan — Functions

**Course:** Maths · **Unit:** 10, Functions, Graphs and Sequences · **Lesson:** Functions
**Place in the curriculum:** Unit 10, the second lesson of the
stage (maths/CURRICULUM.md).
**The one thing this lesson teaches:** functions — what makes a
relation a function, domain and range, the families (constant,
linear, quadratic), composite functions, inverse functions and
piecewise functions.
**This lesson's own level:** it stands on coordinates and graphs
(Stage 10, first lesson) and on equations (Stage 6). It needs
nothing else.

## Sub lessons
The parts of this lesson, in order — the list the learner sees
from the start, locked ahead, each opening when the one before
it is proved (the gate: README, "Units, Lessons and Sub Lessons
(ruled 2026-11-08)"):

1. **Function or Not** — telling a function from a relation — one input, one output — and naming the domain, codomain and range. (Was depth Level 1.)
2. **Writing a Function and Its Families** — writing f(x), working out f(x) for a number, the constant, linear and quadratic families, and reading where a function is positive or negative from its graph. (Was depth Level 2.)
3. **Composite, Inverse and Piecewise Functions** — composites worked inside-out, inverse functions and their reflection in y = x, and piecewise functions with different rules for different inputs. (Was depth Level 3.)

Gate pool: all questions of the sub lesson (no hardness ranking is written in this lesson's question files).

## Before this lesson
- Recommended first: coordinates and graphs — a function is
  read off its graph there. Recommended, never forced.

## What the learner can do when it ends
1. Say whether a relation is a function, and name its domain
   and range.
2. Work out f(x) for a number, and read a function's sign off
   its graph.
3. Put two functions together (composite) and undo one
   (inverse).
4. Read and write a piecewise function.

## What you need
Paper, a pencil, squared paper for the graphs.

## The run of the lesson (in order)
1. **Do it first** — the learner thinks of the doubling
   machine and the dithering machine (lesson/lesson.md).
2. **The explanation** — relation or function; writing a
   function; the families; composite; inverse; piecewise
   (lesson/lesson.md).
   - ADD IMAGE at the machine part: a picture of a function

5. **Hands-on** — hands-on.md.
6. **Do It Yourself** — the four tasks at the end of

## If the learner is stuck
- Cannot tell a function from a relation → look for one input
  with two outputs; one is enough to fail the test.
- Loses track of x in f(x) → cover the x and write the number
  in its place, every x, every time.
- Mixes composite order → work inside out: the inner machine
  runs first.
- This lesson's next door: sequences and series (a sequence is
  a function whose inputs are 1, 2, 3, … — the next lesson
  says so).
