# Functions — the lesson

Course: Maths · Unit 10, Functions, Graphs and Sequences · Lesson: Functions
Built from: Egypt, Jordan, Kazakhstan, Vietnam, Libya, Mauritania
— see lesson/sources.md for every part.

## Do it first
Think of a machine. You put a number in, the machine does one
job to it, and one number comes out. Put in 3, the machine
doubles it, out comes 6. Put in 5, out comes 10. Put in the
same number twice, and the same answer comes out twice. That
machine is a **function**. Now think of a machine that
sometimes gives two different answers for the same input —
put in 3, get 6 one day and 9 the next. That is not a function.
A function never dithers: one input, one output.

## Sub lesson 1 — Function or Not
**Relation or function?** Egypt's Preparatory 3 book builds
the idea in order: first the Cartesian product (ordered
pairs), then a **relation** (a set of ordered pairs between
two sets), then a **function** — a relation in which every
input has exactly one output. Jordan's Grade 9 book teaches
the same test in its first functions lesson: deciding whether
a relation is a function. The words the books use are
**domain** (all the inputs), **codomain** (all the possible
outputs) and **range** (the outputs that actually come out).
Libya's Grade 11 book teaches it the same way: a relation
between two sets, a relation as a set of ordered pairs, a
function and its graph, with an independent variable (the
input) and a dependent variable (the output).

Check it three ways. As a table: does any input appear twice
with different outputs? As arrows: does any input have two
arrows leaving it? As a graph: does any vertical line cut the
graph twice? (Mauritania's 5AS book teaches the general
study of functions with limits and continuity, and its
function chapter is the generalities the other books build
on.) If any of those answers is yes, it is a relation, not a
function.

## Sub lesson 2 — Writing a Function and Its Families

**Writing a function.** A function is usually written
f(x) = … — "f of x". The machine f(x) = 2x + 1 takes x = 3
and gives f(3) = 7. Egypt's book teaches the families one by
one: constant functions (f(x) = 5, the same output for every
input), linear functions (f(x) = 2x + 1, a straight-line
graph), and quadratic functions (f(x) = x², a curve). Vietnam's
Grade 8 book teaches the first-degree function and its graph,
and its Grade 9 book teaches the quadratic function
y = ax². Jordan's Grade 9 book teaches the quadratic function,
its properties and its graph, and how to read a graph to say
where a function is positive, negative or zero (Egypt's
Secondary 1 book teaches the sign of a function the same way:
read it off the graph).

## Sub lesson 3 — Composite, Inverse and Piecewise Functions

**Composite functions — machines in a row.** Put two machines
together: the output of the first becomes the input of the
second. Jordan's Grade 11 book does not teach this under
that name in Term 1, but the idea is in the books through
function work: if f(x) = 2x and g(x) = x + 3, then
g(f(2)) = g(4) = 7 — first double, then add 3. Written
(g∘f)(x) = g(f(x)). Order matters: f(g(2)) = f(5) = 10, a
different answer. Work from the inside out, one machine at a
time.

**Inverse functions — the machine in reverse.** Egypt's Grade
11 Pure book teaches the inverse function as its own lesson:
the inverse undoes what the function did. If f(x) = 2x + 3,
then f(4) = 11, and the inverse takes 11 back to 4:
f⁻¹(x) = (x − 3)/2. A function has an inverse only if it
never gives the same output for two different inputs — the
books call this one-to-one. The graph of an inverse is the
graph of the function reflected in the line y = x, and
Libya's Grade 11 book teaches the algebra of functions —
adding, subtracting, multiplying and dividing them — in the
same chapter as functions themselves.

**Piecewise functions — different rules for different inputs.**
Jordan's Grade 11 book opens its functions unit with
piecewise functions: one rule for x below some value, another
rule above it. A taxi fare is the everyday example: a fixed
charge for the first kilometre, then a charge per kilometre
after that. One function, two rules, and the graph has a
corner (or a jump) where the rule changes.

> **Tip — from us, not from the books.** When a question asks
> for f(3), cover up the x in the formula and write 3 in its
> place — every x, every time. Most wrong answers come from
> replacing only the first x.

## Say it to your companion
Write a table of inputs and outputs. Ask your companion:
"Function or not — and why?" Then swap: they give you
f(x) = 3x − 2 and ask for f(5), f(0) and f(−1), and you
answer with the working shown.

## Do It Yourself
1. Is this a function? {(1, 2), (2, 4), (3, 6), (2, 5)}.
   (Answer: No — the input 2 has two different outputs, 4
   and 5.)
2. f(x) = x² + 1. Find f(3) and f(−3). (Answers: 10 and 10.)
3. f(x) = 2x, g(x) = x + 3. Find g(f(4)) and f(g(4)).
   (Answers: g(f(4)) = g(8) = 11; f(g(4)) = f(7) = 14.)
4. Find the inverse of f(x) = 3x − 6. (Answer:
   f⁻¹(x) = (x + 6)/3. Check: f(4) = 6, f⁻¹(6) = 4.)
