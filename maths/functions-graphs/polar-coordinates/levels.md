# Polar Coordinates — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
polar coordinates — the polar name first, then polar to
Cartesian, then Cartesian to polar and the many names of
one point, the order the books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — The Polar Name (r, θ)
Sub lesson 1 questions from the type files. Pass mark: say what r and θ each mean, and read off the polar name of a plotted point.

## Sub lesson 2 — Polar to Cartesian
Sub lesson 2 questions from the type files. Pass mark: use x = r cos θ and y = r sin θ to turn a polar point into (x, y), including angles past 90°.

## Sub lesson 3 — Cartesian to Polar and the Many Names of a Point
Sub lesson 3 questions from the type files. Pass mark: find r = √(x² + y²) and the quadrant-correct θ for a Cartesian point, give a second polar name for the same point, and keep r ≥ 0 with the argument in [0, 2π).
