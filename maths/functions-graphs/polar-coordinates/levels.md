# Polar Coordinates — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — polar coordinates — the polar name first, then polar to Cartesian, then Cartesian to polar and the many names of one point, the order the books teach it in.

## Level 1 — the polar name (r, θ)
Level 1 questions from the type files. Pass mark: say what r and θ each mean, and read off the polar name of a plotted point.

## Level 2 — polar to Cartesian
Level 2 questions from the type files. Pass mark: use x = r cos θ and y = r sin θ to turn a polar point into (x, y), including angles past 90°.

## Level 3 — Cartesian to polar, and the many names of a point
Level 3 questions from the type files. Pass mark: find r = √(x² + y²) and the quadrant-correct θ for a Cartesian point, give a second polar name for the same point, and keep r ≥ 0 with the argument in [0, 2π).
