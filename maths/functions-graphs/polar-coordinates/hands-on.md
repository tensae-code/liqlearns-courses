# Hands-on — Polar Coordinates

The lesson named points by a length and a turn, the way the books set it up.

## String and turn
Pin one end of a string at the origin corner of a squared page. Mark a point. Swing the free end of the string to the point. Measure the string against the grid for r, and measure the turn from the positive x-axis with a protractor for θ. Write the point as (r, θ). Do five points, one in each quadrant and one on an axis.

## Treasure map in polar words
Hide a small object in the room. Write its position as a polar instruction from a fixed starting point: "r = 6 steps, θ = 40° left of the door line." Your partner follows only the two numbers. Swap roles. A Cartesian instruction ("3 across, 4 up") and a polar instruction can find the same treasure — check that both land on the same spot.

## One point, many names
Plot P(2, 150°) — the corrected Bangladesh example point. Now write two more polar names for the same plotted point: add 360° to the angle, then subtract 360°. Plot each name and watch all three land on the one point. Then try it Kuwait's way: keep r ≥ 0 and keep the angle inside [0, 2π).
