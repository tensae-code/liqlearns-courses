# Polar Coordinates — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — The Polar Name (r, θ) · (Level 2) -> Sub lesson 2 — Polar to Cartesian · (Level 3) -> Sub lesson 3 — Cartesian to Polar and the Many Names of a Point.

Say true or false, and be ready to say why.

**1. (Sub lesson 1)** Every point of the plane has a polar name (r, θ). True or false?
**Answer:** True — every point has a distance from the origin and a direction.

**2. (Sub lesson 1)** In polar coordinates the angle is written first. True or false?
**Answer:** False — the distance r is written first: (r, θ).

**3. (Sub lesson 2)** (5, 240°) and (−5/2, −5√3/2) are the same point. True or false?
**Answer:** True — x = 5 cos 240° and y = 5 sin 240° give exactly that point (Bangladesh, §10.2).

**4. (Sub lesson 3)** For P(−√3, 1), r = √5. True or false?
**Answer:** False — that is the book's printed error (Bangladesh, p. 174); r = √(3 + 1) = 2, taught corrected.

**5. (Sub lesson 3)** (2, 150°) and (2, −210°) name the same point. True or false?
**Answer:** True — 150° − 360° = −210°, a whole turn less.

**6. (Sub lesson 3)** Under Kuwait's rule, r may be negative in the standard form. True or false?
**Answer:** False — Kuwait requires r ≥ 0, with the argument in [0, 2π) (7-2, pp. 25–32).
