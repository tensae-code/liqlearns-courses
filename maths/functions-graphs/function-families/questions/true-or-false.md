# True or false — Function Families: Graphs with a Parameter

Sub-lesson markers: every item's marker names the sub lesson it belongs to — Sub lesson 1 — One Formula, Many Graphs · Sub lesson 2 — Investigating a Family · Sub lesson 3 — Locus Curves. This lesson was built new with its sub lessons (Germany expansion merge, 2026-11-11), so its markers are original — there are no older depth layers to map from.

1. (Sub lesson 1) Every member of a family shares the same formula shape; only the parameter's value changes from member to member. **True** — that is what makes them one family. Item constructed for this lesson from its founding teaching. Germany, *Lambacher Schweizer Mathematik 11, Ausgabe Bayern* (student book, Grade 11), Kapitel V, Exkursion (Funktionenscharen und Ortskurven), printed p. 181; *Lambacher Schweizer Mathematik 12, Ausgabe Bayern* (student book, Grade 12), Kapitel I, printed p. 6.

2. (Sub lesson 2) For t = 0, the member f_0(x) = x² + 1 has a zero. **False** — x² + 1 > 0 for every x; the member floats above the axis, matching the case |t| < 1. Item constructed for this lesson from its founding teaching. 3. (Sub lesson 2) The minimum value of f_t(x) = x² − 2tx + 1, namely 1 − t², can be negative. **True** — for |t| > 1 it is negative, which is exactly the case where the parabola dips below the axis and has two zeros. 4. (Sub lesson 3) A locus curve is found by eliminating the parameter between the two coordinates of the special point. **True** — write X and Y in terms of t, then remove t; what remains is the locus equation.
