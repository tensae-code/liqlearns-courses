# Hands-on — Function Families: Graphs with a Parameter

## Activity 1 — Draw the family (15 minutes)

On one pair of axes, draw f_t(x) = x² − 2tx + 1 for
t = −2, −1, 0, 1, 2. Use the completed-square form
(x − t)² + 1 − t² to place each vertex first, then sketch.
Say out loud, for each member, how many zeros it has — and
check your count against the discriminant cases. This is
Sub lessons 1 and 2 drawn by hand.

## Activity 2 — The vertex trail (10 minutes)

On your drawing from Activity 1, mark all five vertices in
a bright colour and join them with a smooth curve. Then
verify algebraically that your curve is y = 1 − x² by
testing each vertex in it. This is Sub lesson 3 discovered
with a pencil before it is proved.

## Activity 3 — Build your own locus (15 minutes)

Take h_t(x) = (x − t)² + t. Write out three members, find
each vertex, and guess the locus before computing it. Then
run the three steps: coordinates in terms of t, X and Y,
eliminate t. Swap with a partner and check each other's
elimination by testing a member neither of you used
(t = 4, say). This is the locus method as a game.
