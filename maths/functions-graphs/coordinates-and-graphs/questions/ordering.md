# Coordinates and graphs — ordering

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Plotting, Distance and Midpoint · (Level 2) -> Sub lesson 2 — Gradient and Intercepts · (Level 3) splits by what the item asks: items about parallel or perpendicular gradients, and reading an intercept off a given equation, -> Sub lesson 2, where the gradient part teaches those rules; items about writing a line's equation -> Sub lesson 3 — The Equation y = mx + c.

Put each set in order, smallest to largest.

**1. (Sub lesson 1)** Order these points by their distance from the origin, smallest to largest: (3, 4), (1, 1), (6, 8), (0, 5).
**Answer:** (1, 1) (about 1.41), (3, 4) (5), (0, 5) (5), (6, 8) (10). (3, 4) and (0, 5) tie at 5.

**2. (Sub lesson 2)** Order these gradients from smallest to largest: 2, −1, 0, 1/2.
**Answer:** −1, 0, 1/2, 2.

**3. (Sub lesson 2)** Order these lines by steepness (ignoring direction), least steep to steepest: gradient 1/2, gradient 3, gradient −1, gradient 2.
**Answer:** 1/2, −1 (steepness 1), 2, 3.

**4. (Sub lesson 3)** The line y = 2x + 1 is drawn. Order these x-values by their y-values, smallest to largest: x = −1, x = 0, x = 2, x = 1.
**Answer:** x = −1 (y = −1), x = 0 (y = 1), x = 1 (y = 3), x = 2 (y = 5).

**5. (Sub lesson 3)** Order these steps for finding a line's equation from two points: (a) find c with one point, (b) find m from change in y over change in x, (c) write y = mx + c.
**Answer:** (b), (a), (c).
