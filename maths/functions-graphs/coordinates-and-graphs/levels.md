# Coordinates and graphs — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
coordinates and graphs — plotting, distance and midpoint
first, then gradient and intercepts, then the equation
y = mx + c, the order the books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 splits by where the
text teaches each half — writing the equation is Sub
lesson 3, while the parallel-and-perpendicular gradient
rules are taught inside Sub lesson 2's gradient part, so
their questions are marked Sub lesson 2 — and its pass
mark splits the same way below.

## Sub lesson 1 — Plotting, Distance and Midpoint
Sub lesson 1 questions from the type files. Pass mark: plot points in all four quadrants, name a point's coordinates, and find a distance and a midpoint.

## Sub lesson 2 — Gradient and Intercepts
Sub lesson 2 questions from the type files. Pass mark: find a gradient from two points, say whether a line rises or falls, and read both intercepts off a graph or an equation. The parallel-and-perpendicular gradient rules are taught inside this sub lesson's gradient part, so their questions sit here too (they were the second half of old Level 3's pass mark).

## Sub lesson 3 — The Equation y = mx + c
Sub lesson 3 questions from the type files. Pass mark: write the equation of a line from its gradient and intercept, and from two points. (The equation-writing half of old Level 3; its parallel-and-perpendicular half is carried in Sub lesson 2.)
