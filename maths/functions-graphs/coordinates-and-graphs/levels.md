# Coordinates and graphs — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — points and straight lines — set by
the pattern across the countries' books: plot first, then
gradient, then the equation.

## Level 1 — plotting, distance and midpoint
Level 1 questions from the type files. Pass mark: plot points
in all four quadrants, name a point's coordinates, and find a
distance and a midpoint.

## Level 2 — gradient and intercepts
Level 2 questions from the type files. Pass mark: find a
gradient from two points, say whether a line rises or falls,
and read both intercepts off a graph or an equation.

## Level 3 — the equation y = mx + c
Level 3 questions from the type files. Pass mark: write the
equation of a line from its gradient and intercept, from two
points, and say whether two lines are parallel or
perpendicular from their gradients.
