# Lesson plan — Coordinates and graphs

**Course:** Maths · **Stage:** 10, Functions, Graphs and Sequences · **Lesson:** Coordinates and graphs
**Place in the curriculum:** Stage 10, the first lesson of the
stage (maths/CURRICULUM.md).
**The one thing this lesson teaches:** plotting points on the
coordinate plane, and straight-line graphs — gradient,
intercepts, and the equation y = mx + c.
**This lesson's own level:** it stands on the Stage 7 angles
lesson and on equations (Stage 6). It needs nothing else.

## Before this lesson
- Recommended first: equations (Stage 6) — a line's equation
  is an equation in x and y. Recommended, never forced.

## What the learner can do when it ends
1. Plot points in all four quadrants and name them (x, y).
2. Find the distance and the midpoint between two points.
3. Find a line's gradient from two points and say whether it
   rises or falls.
4. Read the intercepts off a graph and write the line's
   equation as y = mx + c.

## What you need
Squared paper, a ruler, a pencil.

## The run of the lesson (in order)
1. **Do it first** — the learner plots points in the four
   quadrants (lesson/lesson.md).
2. **The explanation** — distance and midpoint; straight-line
   graphs from tables; gradient; intercepts; y = mx + c
   (lesson/lesson.md).
   - ADD IMAGE at the plotting part: a picture of a coordinate
     plane with four quadrants and a point in each, labelled
     with its coordinates → the student plots the same four
     points.
   - ADD GIF at the gradient part: a picture of a line getting
     steeper, then flattening, then falling, the gradient
     number changing with it → the student says whether each
     line rises or falls.
   - ADD IMAGE at the equation part: a picture of the line
     y = 2x + 1 with its y-intercept marked and its steps
     (up 2, across 1) drawn on it → the student steps along
     the line.
3. **Say it to your companion** — plot two points, ask for the
   gradient, the equation and the x-intercept (lesson/lesson.md).
   - ADD VIDEO: the script in video-script.md, filmed — the
     plane, the gradient and y = mx + c in the super-simple
     voice (made later, when videos are made).
4. **Questions** — from questions/: multiple-choice, short-answer,
   fill-in-the-blank, true-or-false, ordering, matching — served
   at the learner's level and teaching-mix (levels.md).
5. **Hands-on** — hands-on.md.
6. **Do It Yourself** — the four tasks at the end of
   lesson/lesson.md.

## Add-ons for this lesson (the full list)
- IMAGE — a coordinate plane with a point in each quadrant →
  the student plots the same points.
- GIF — a line changing steepness → the student says rise or
  fall.
- IMAGE — the line y = 2x + 1 with its steps marked → the
  student steps along it.
- VIDEO — the video-script filmed (made later) → the student
  plots along with it.

## If the learner is stuck
- Writes (y, x) instead of (x, y) → x first, always: walk
  along, then climb up.
- Gets the gradient upside down → gradient is change in y
  OVER change in x; rise first, run second.
- Mixes the intercepts → the y-intercept is where x = 0; the
  x-intercept is where y = 0.
- This lesson's next door: functions (the line y = mx + c is
  a function — the next lesson names it).
