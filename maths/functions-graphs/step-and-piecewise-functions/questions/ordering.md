# Step and Piecewise Functions — ordering

Put the steps in the right order, or the values in size order.

**1. (Level 1)** Order these by size, smallest first: [2.9], [−1.1], [0.4], [−3].
**Answer:** [−3] = −3, then [−1.1] = −2, then [0.4] = 0, then [2.9] = 2.

**2. (Level 2)** Order these by size, smallest first: {3.8}, {−0.3}, {5.05}, sgn(−9).
**Answer:** sgn(−9) = −1, then {5.05} = 0.05, then {−0.3} = 0.7, then {3.8} = 0.8.

**3. (Level 3)** Order the steps for evaluating a piecewise f at x = −4, where f(x) = x² for x < 0 and f(x) = 2x for x ≥ 0: (a) square −4; (b) decide which side of 0 the input is on; (c) answer 16.
**Answer:** b, a, c — the break is read first; only the matching rule runs.

**4. (Level 3)** Order the steps for drawing f(x) = |x − 2| + 1 from the parent V of |x|: (a) shift up by 1; (b) draw y = |x|; (c) shift right by 2.
**Answer:** b, c, a — start from the parent V, then apply the shifts (Kuwait's transformation method, Grade 10 Term 1, pp.16–32).
