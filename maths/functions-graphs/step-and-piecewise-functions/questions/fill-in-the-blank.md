# Step and Piecewise Functions — fill in the blank

Fill each blank with the missing number or words.

**1. (Level 1)** [x] is the greatest ______ not bigger than x.
**Answer:** integer — the floor drops x to the whole number at or below it.

**2. (Level 1)** [−0.5] = ______.
**Answer:** −1 — 0 and −0 are bigger than −0.5; the first whole number walking down is −1.

**3. (Level 2)** Every number splits as x = [x] + ______, and the second part always lies between 0 and ______.
**Answer:** {x}; 1 — 0 ≤ {x} < 1 always (Kazakhstan, Algebra 9, §21, p.24).

**4. (Level 2)** sgn(x) takes only three values: ______, ______ and ______.
**Answer:** 1, 0, −1 — positive, zero, negative (Laos, Grade 10, p.83).

**5. (Level 3)** To evaluate a piecewise function, first find which ______ the input falls in, then run only that part's rule.
**Answer:** part (of the domain) — the break decides the rule.

**6. (Level 3)** Reflecting f(x) = |x + 1| + 2 in the x-axis gives ______, with vertex (−1, −2).
**Answer:** −|x + 1| − 2 — taught corrected: Kuwait's p.30 caption mislabels this curve.
