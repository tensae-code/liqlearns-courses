# Step and Piecewise Functions — short answer

Answer in a word or a short sentence.

**1. (Level 1)** Work out [9.99] and [−9.99].
**Answer:** [9.99] = 9; [−9.99] = −10 — the floor never passes x, on either side of zero.

**2. (Level 1)** For which x in [2, 3) is [x] = 2 — all of them, or only some?
**Answer:** All of them — the step holds the value 2 from 2 up to (not including) 3 (Nicaragua, Grade 10, pp.269–271).

**3. (Level 2)** Work out {−1.2}.
**Answer:** 0.8 — {x} = x − [x] = −1.2 − (−2) (Kazakhstan, Algebra 9, §21, p.24).

**4. (Level 2)** Work out sgn(14), sgn(0) and sgn(−3/4).
**Answer:** 1, 0, −1 — the sign function answers only: positive, zero, or negative (Laos, Grade 10, p.83).

**5. (Level 2)** A phone plan charges a flat 10 for the first 100 minutes, then steps up by 2 for each started block of 50 extra minutes. What do 230 minutes cost?
**Answer:** 16 — three started extra blocks (100–150, 150–200, 200–230) at 2 each, on top of the flat 10: a step charge in the shape of Iran's tariff examples (p.34).

**6. (Level 3)** f(x) = x + 3 for x < 0 and f(x) = x² for x ≥ 0. Find f(−2), f(0), f(3).
**Answer:** f(−2) = 1; f(0) = 0; f(3) = 9 — each input runs only its own side's rule.

**7. (Level 3)** Rewrite f(x) = |x − 3| as a piecewise function.
**Answer:** f(x) = −(x − 3) for x < 3, and f(x) = x − 3 for x ≥ 3 — Kuwait's redefinition method (Grade 10 Term 1, pp.16–32).

**8. (Level 3)** Name the vertex, axis of symmetry and range of f(x) = |2x − 4| + 5.
**Answer:** Vertex (2, 5); axis x = 2; range f(x) ≥ 5 — the inside is zero at x = 2.
