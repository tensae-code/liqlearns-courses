# Step and Piecewise Functions — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — functions that jump — the floor
and its staircase first, then the fractional part, the sign
function and stepped charges, then piecewise rules and the
absolute-value graph.

## Level 1 — the floor function and its staircase
Level 1 questions from the type files. Pass mark: work out [x]
for positive and negative numbers, and read values off the
staircase graph, saying which step a number lands on.

## Level 2 — fractional part, sign and stepped charges
Level 2 questions from the type files. Pass mark: work out
{x} and sgn(x) for any number, keep {x} between 0 and 1, and
price a stepped charge from a tariff table.

## Level 3 — piecewise rules and the absolute-value function
Level 3 questions from the type files. Pass mark: evaluate a
piecewise function on both sides of its break, and draw
f(x) = |ax + b| + c with its vertex, axis of symmetry and
range named.
