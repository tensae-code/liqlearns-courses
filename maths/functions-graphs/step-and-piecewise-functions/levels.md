# Step and Piecewise Functions — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
step and piecewise functions — the floor and its staircase
first, then the fractional part, the sign function and
stepped charges, then piecewise rules and the absolute-value
graph, the order the books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — The Floor Function and Its Staircase
Sub lesson 1 questions from the type files. Pass mark: work out [x] for positive and negative numbers, and read values off the staircase graph, saying which step a number lands on.

## Sub lesson 2 — Fractional Part, Sign and Stepped Charges
Sub lesson 2 questions from the type files. Pass mark: work out {x} and sgn(x) for any number, keep {x} between 0 and 1, and price a stepped charge from a tariff table.

## Sub lesson 3 — Piecewise Rules and the Absolute-Value Graph
Sub lesson 3 questions from the type files. Pass mark: evaluate a piecewise function on both sides of its break, and draw f(x) = |ax + b| + c with its vertex, axis of symmetry and range named.
