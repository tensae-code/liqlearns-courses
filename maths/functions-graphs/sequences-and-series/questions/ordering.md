# Sequences and series — ordering

Put each set in order, smallest to largest or in the order the
steps are done.

**1. (Level 1)** Order these sequences by their 5th term, smallest to largest: 1, 2, 3, 4, …; 1, 3, 5, 7, …; 2, 4, 8, 16, ….
**Answer:** 1, 2, 3, 4, … (5th term 5), 1, 3, 5, 7, … (5th term 9), 2, 4, 8, 16, … (5th term 32).

**2. (Level 2)** Order these sums from smallest to largest: 1 + 2 + 3 + 4; 2 + 4 + 6 + 8; 1 + 3 + 5 + 7.
**Answer:** 1 + 2 + 3 + 4 = 10, 1 + 3 + 5 + 7 = 16, 2 + 4 + 6 + 8 = 20.

**3. (Level 2)** Order these steps for finding an arithmetic sum: (a) find the last term aₙ, (b) write Sₙ = n/2 × (a₁ + aₙ), (c) count n.
**Answer:** (c), (a), (b).

**4. (Level 3)** Order these infinite sums from smallest to largest: 1 + 1/2 + 1/4 + …; 1/2 + 1/4 + 1/8 + …; 2 + 1 + 1/2 + ….
**Answer:** 1/2 + 1/4 + … = 1, 1 + 1/2 + … = 2, 2 + 1 + 1/2 + … = 4.

**5. (Level 3)** A salary starts at 100 and rises 10% a year. Order the pay in years 1, 2, 3 from smallest to largest.
**Answer:** Year 1: 100, Year 2: 110, Year 3: 121.
