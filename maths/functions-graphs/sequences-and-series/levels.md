# Sequences and series — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — lists made by a rule, and their
sums — set by the pattern across the countries' books: the rule
and the nth term first, then the two families' sums, then the
infinite sum.

## Level 1 — the rule and the nth term
Level 1 questions from the type files. Pass mark: extend a
sequence from its rule, tell arithmetic from geometric, and
find an nth term with aₙ = a₁ + (n − 1)d or bₙ = b₁rⁿ⁻¹.

## Level 2 — the sums
Level 2 questions from the type files. Pass mark: add up an
arithmetic series with Sₙ = n/2 × (a₁ + aₙ) and a geometric
series with Sₙ = b₁(1 − rⁿ)/(1 − r).

## Level 3 — the infinite sum and real problems
Level 3 questions from the type files. Pass mark: use
S = b₁/(1 − r) for |r| < 1, turn a repeating decimal into a
fraction, and solve an applied sequence problem (salary rise,
bouncing ball, well-drilling cost).
