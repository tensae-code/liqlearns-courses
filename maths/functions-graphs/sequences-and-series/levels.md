# Sequences and series — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
sequences and series — the rule and the nth term first,
then the two families' sums, then the infinite sum, the
order the books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Sequences, Rules and the nth Term
Sub lesson 1 questions from the type files. Pass mark: extend a sequence from its rule, tell arithmetic from geometric, and find an nth term with aₙ = a₁ + (n − 1)d or bₙ = b₁rⁿ⁻¹.

## Sub lesson 2 — Series — Adding the Terms
Sub lesson 2 questions from the type files. Pass mark: add up an arithmetic series with Sₙ = n/2 × (a₁ + aₙ) and a geometric series with Sₙ = b₁(1 − rⁿ)/(1 − r).

## Sub lesson 3 — The Infinite Geometric Sum
Sub lesson 3 questions from the type files. Pass mark: use S = b₁/(1 − r) for |r| < 1, turn a repeating decimal into a fraction, and solve an applied sequence problem (salary rise, bouncing ball, well-drilling cost).
