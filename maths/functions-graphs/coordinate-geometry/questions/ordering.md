# Coordinate Geometry — ordering

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Dividing a Segment Inside · (Level 2) -> Sub lesson 3 — Distance to a Line and Coordinate Proof · (Level 3) splits by what the item asks: external-division items -> Sub lesson 2 — Dividing a Segment Outside, circle items -> Sub lesson 4 — The Equation of a Circle. One exception: ordering item 4, about distances from a point to lines, is Sub lesson 3's work and is marked Sub lesson 3.

Put the steps in the right order.

**1. (Sub lesson 1)** Order the steps for finding a dividing point: (a) write the weights — far part on each end; (b) name the two ends and the ratio; (c) work out each coordinate.
**Answer:** b, a, c — ends and ratio first, then the far-end weights, then the arithmetic (Kuwait, 9-2, pp.124–130).

**2. (Sub lesson 3)** Order the steps for a coordinate proof that a quadrilateral is a rectangle: (a) check the diagonals are equal; (b) give the corners coordinates; (c) check the diagonals share a midpoint.
**Answer:** b, c, a — parallelogram first (shared midpoint), then rectangle (equal diagonals) (Jordan, Grade 9, p.177).

**3. (Sub lesson 4)** Order the steps for reading a centre from x² + y² − 6x + 2y + 6 = 0: (a) read centre (3, −1) and radius 2; (b) complete the square on x; (c) complete the square on y.
**Answer:** b, c, a — square on x and on y separately, then read (South Sudan, Secondary 4, pp.30–40).

**4. (Sub lesson 3)** Order these by the size of the distance from (0, 0): the line x + y − 2 = 0; the line x + y − 6 = 0; the line x + y + 4 = 0.
**Answer:** x + y − 2 = 0 (distance √2), then x + y + 4 = 0 (distance 2√2), then x + y − 6 = 0 (distance 3√2) — each distance is |C| / √(1 + 1).
