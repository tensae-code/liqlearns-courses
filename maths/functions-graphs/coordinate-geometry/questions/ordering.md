# Coordinate Geometry — ordering

Put the steps in the right order.

**1. (Level 1)** Order the steps for finding a dividing point: (a) write the weights — far part on each end; (b) name the two ends and the ratio; (c) work out each coordinate.
**Answer:** b, a, c — ends and ratio first, then the far-end weights, then the arithmetic (Kuwait, 9-2, pp.124–130).

**2. (Level 2)** Order the steps for a coordinate proof that a quadrilateral is a rectangle: (a) check the diagonals are equal; (b) give the corners coordinates; (c) check the diagonals share a midpoint.
**Answer:** b, c, a — parallelogram first (shared midpoint), then rectangle (equal diagonals) (Jordan, Grade 9, p.177).

**3. (Level 3)** Order the steps for reading a centre from x² + y² − 6x + 2y + 6 = 0: (a) read centre (3, −1) and radius 2; (b) complete the square on x; (c) complete the square on y.
**Answer:** b, c, a — square on x and on y separately, then read (South Sudan, Secondary 4, pp.30–40).

**4. (Level 3)** Order these by the size of the distance from (0, 0): the line x + y − 2 = 0; the line x + y − 6 = 0; the line x + y + 4 = 0.
**Answer:** x + y − 2 = 0 (distance √2), then x + y + 4 = 0 (distance 2√2), then x + y − 6 = 0 (distance 3√2) — each distance is |C| / √(1 + 1).
