# Coordinate Geometry — matching

Match each item on the left with the one right item on the right.

**1. (Level 1)** Section formula, ratio 1:1 → **Answer:** the midpoint — equal weights average the ends.

**2. (Level 2)** Diagonals with the same midpoint → **Answer:** a parallelogram — Jordan's coordinate-proof test (Grade 9, p.177).

**3. (Level 2)** Distance from a point to a line → **Answer:** the perpendicular length — the shortest rope (Jordan, Grade 9, p.168).

**4. (Level 3)** (x − 3)² + (y − 4)² = 8 → **Answer:** centre (3, 4), radius 2√2 — Ethiopia's worked circle through (5, 6) (Grade 10, §7.5).

**5. (Level 3)** a² + b² > 4c → **Answer:** a real circle — Iran's expanded-form test (Geometry (3), p.42).

Right-hand items in full: the midpoint · a parallelogram · the perpendicular length · centre (3, 4), radius 2√2 · a real circle.
