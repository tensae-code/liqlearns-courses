# Coordinate Geometry — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — coordinate geometry — dividing a
segment first, then distance to a line and coordinate proof, then
the circle's equation, the order the books teach it in.

## Level 1 — dividing a segment
Level 1 questions from the type files. Pass mark: find the point
dividing a segment internally in a given ratio, and say in words
which end it sits closer to and why.

## Level 2 — distance to a line and coordinate proof
Level 2 questions from the type files. Pass mark: find the
shortest distance from a point to a line, and choose and carry
out the right coordinate test to prove a quadrilateral is a
parallelogram, rectangle, rhombus or square.

## Level 3 — the circle's equation
Level 3 questions from the type files. Pass mark: write a
circle's equation from its centre and radius or from a diameter,
read centre and radius back by completing the square, divide a
segment externally, and say when an equation names no real
circle.
