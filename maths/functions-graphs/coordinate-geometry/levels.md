# Coordinate Geometry — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
coordinate geometry — dividing a segment inside first,
then dividing it outside, then distance to a line and
coordinate proof, then the circle's equation, the order
the lesson's text teaches it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 3; old Level 3 covered two natural
jumps that stand apart in the text, so it splits — its
external-division part is Sub lesson 2 (the text teaches it
second, straight after internal division) and its circle
part is Sub lesson 4 — and its pass mark splits the same
way below.

## Sub lesson 1 — Dividing a Segment Inside
Sub lesson 1 questions from the type files. Pass mark: find the point dividing a segment internally in a given ratio, and say in words which end it sits closer to and why.

## Sub lesson 2 — Dividing a Segment Outside
Sub lesson 2 questions from the type files. Pass mark: divide a segment externally in a given ratio, say where the point lands, and say why equal external division (m = n) gives no point at all. (From old Level 3.)

## Sub lesson 3 — Distance to a Line and Coordinate Proof
Sub lesson 3 questions from the type files. Pass mark: find the shortest distance from a point to a line, and choose and carry out the right coordinate test to prove a quadrilateral is a parallelogram, rectangle, rhombus or square.

## Sub lesson 4 — The Equation of a Circle
Sub lesson 4 questions from the type files. Pass mark: write a circle's equation from its centre and radius or from a diameter, read centre and radius back by completing the square, and say when an equation names no real circle. (From old Level 3.)
