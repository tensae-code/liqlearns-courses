# Special Sequences — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
special sequences — the pictured families first, then
harmonic progressions, then arithmetico-geometric
progressions, the order the books teach them in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Square, Cube and Triangular Numbers
Sub lesson 1 questions from the type files. Pass mark: continue each pictured family, state its rule, and find a named term (for example the 6th triangular number).

## Sub lesson 2 — Harmonic Progressions and the Harmonic Mean
Sub lesson 2 questions from the type files. Pass mark: flip a harmonic progression into its A.P., find an nth term and a harmonic mean, and insert a harmonic mean between two numbers.

## Sub lesson 3 — Arithmetico-Geometric Progressions
Sub lesson 3 questions from the type files. Pass mark: spot the A.P. part and the G.P. part of an arithmetico-geometric progression, and find its sum to infinity by the multiply-and-subtract method.
