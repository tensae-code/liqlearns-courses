# Special Sequences — true or false

Say true or false, and be ready to say why.

**1. (Level 1)** Every triangular number after the first is found by adding one more than the previous gap. True or false?
**Answer:** True — the gaps are 2, 3, 4, 5, …, the counting numbers from 2 on.

**2. (Level 1)** 36 is both a square number and a triangular number. True or false?
**Answer:** True — 36 = 6², and 36 is the 8th triangular number: 8 × 9/2 = 36.

**3. (Level 2)** 1, 1/2, 1/4, 1/8, … is a harmonic progression. True or false?
**Answer:** False — flipped it is 1, 2, 4, 8, …, a G.P., not an A.P.; the sequence is itself a G.P.

**4. (Level 2)** The harmonic mean of two different positive numbers is smaller than their arithmetic mean. True or false?
**Answer:** True — the order is arithmetic ≥ geometric ≥ harmonic.

**5. (Level 3)** The sum to infinity of an A.G.P. with G.P. ratio 2 is finite. True or false?
**Answer:** False — with |r| ≥ 1 the terms do not die away, so there is no finite sum to infinity.

**6. (Level 2)** Sierra Leone's Primary 6 square-number lessons come from a pupil's book. True or false?
**Answer:** False — they come from teacher lesson plans, Lessons 116–117 (printed pp. 143–145): teacher evidence only.
