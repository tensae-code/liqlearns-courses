# Video script — Roots and Surds

The super-simple voice, for the video that rides on top of the
lesson (lesson-plan.md, add-on list). Made later, when videos are
made; the script is the slot's written form until then.

---

A square! Twelve by twelve is 144.
So the square root of 144 is TWELVE.
A root UNDOES a square!

A cube! Nine by nine by nine is 729.
So the cube root of 729 is NINE.
A root undoes a cube!

Root of two? There is no whole number!
Root two is a SURD — a root we leave exact.
Do not round it away. Keep it as root two!

Root 32? Pull out the biggest square inside:
32 is 16 times 2. Root 16 is 4.
So root 32 is FOUR root two. 4√2. Neat!

One over root two? No root downstairs!
Multiply top and bottom by root two.
Root two over two. Clean!
