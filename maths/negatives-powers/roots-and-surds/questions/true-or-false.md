# Roots and Surds — true or false

Say true or false, and fix the false ones.

**1. (Level 1)** There is a square root of −9 among the real numbers.
**Answer: False.** No square root of a negative real number (Egypt, Grade 8 Term 1, 1-1).

**2. (Level 2)** √2 + √3 = √5.
**Answer: False.** Different surds do not add; √2 + √3 stays as it is.

**3. (Level 3)** 1/√2 = √2/2.
**Answer: True.**
