# Roots and Surds — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — square and
cube roots first, then surds in basic form, then operating on
surds and rationalising.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Roots Square and Cube Roots
Sub lesson 1 questions from the type files. Pass mark: give square and cube roots of perfect powers, name both roots of a perfect square, and estimate a root that is not exact.

## Sub lesson 2 — Surds In Basic Form
Sub lesson 2 questions from the type files. Pass mark: pull the biggest perfect square (or cube) out of a surd and write it in basic form, checking by squaring back.

## Sub lesson 3 — Surds Operating and Rationalising
Sub lesson 3 questions from the type files. Pass mark: add, subtract and multiply surds exactly, and rationalise a denominator.
