# Negative Numbers — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — below zero
and the line first, then adding and subtracting, then multiplying
and dividing.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Negative Numbers Below Zero and the Line
Sub lesson 1 questions from the type files. Pass mark: read negatives aloud, place them on the line, and say which of two negatives is bigger every time.

## Sub lesson 2 — Negative Numbers Adding and Subtracting
Sub lesson 2 questions from the type files. Pass mark: add and subtract negatives, including subtracting a negative, and check each answer on the line.

## Sub lesson 3 — Negative Numbers Multiplying and Dividing
Sub lesson 3 questions from the type files. Pass mark: give the sign first and the size second, and explain a long product's sign by counting its negative factors.
