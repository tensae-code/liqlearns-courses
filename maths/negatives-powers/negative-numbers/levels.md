# Negative Numbers — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — below zero and the line first, then adding and subtracting, then multiplying and dividing.

## Level 1 — below zero and the line
Level 1 questions from the type files. Pass mark: read negatives aloud, place them on the line, and say which of two negatives is bigger every time.

## Level 2 — adding and subtracting negatives
Level 2 questions from the type files. Pass mark: add and subtract negatives, including subtracting a negative, and check each answer on the line.

## Level 3 — multiplying and dividing negatives
Level 3 questions from the type files. Pass mark: give the sign first and the size second, and explain a long product's sign by counting its negative factors.
