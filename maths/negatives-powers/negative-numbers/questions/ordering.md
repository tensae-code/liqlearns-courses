# Negative Numbers — ordering

Put each set in order, smallest first.

**1. (Level 1)** −2 · −7 · 0 · 3 · −4
**Answer:** −7, −4, −2, 0, 3.

**2. (Level 2)** Work these out, then put the answers in order, smallest first: −1 − 3 · −5 + 3 · 5 − (−4) · −3 + (−4) · 0
**Answer:** the values are −4, −2, 9, −7, 0; in order: −7, −4, −2, 0, 9.
