# Standard Form — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — big numbers first, then small numbers, then converting both ways and comparing.

## Level 1 — big numbers in standard form
Level 1 questions from the type files. Pass mark: write any big number as a × 10ⁿ with 1 ≤ a < 10, and read standard form back as an ordinary number.

## Level 2 — small numbers in standard form
Level 2 questions from the type files. Pass mark: write any small number with a negative power of ten, and read it back.

## Level 3 — converting, comparing and choosing
Level 3 questions from the type files. Pass mark: convert both ways without error, order numbers in standard form by power first, and say when standard form is worth using.
