# Standard Form — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — big
numbers first, then small numbers, then converting both ways and
comparing.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Standard Form Big Numbers
Sub lesson 1 questions from the type files. Pass mark: write any big number as a × 10ⁿ with 1 ≤ a < 10, and read standard form back as an ordinary number.

## Sub lesson 2 — Standard Form Small Numbers
Sub lesson 2 questions from the type files. Pass mark: write any small number with a negative power of ten, and read it back.

## Sub lesson 3 — Standard Form Converting, Comparing and Choosing
Sub lesson 3 questions from the type files. Pass mark: convert both ways without error, order numbers in standard form by power first, and say when standard form is worth using.
