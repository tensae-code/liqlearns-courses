# Powers and Indices — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — powers as repeated multiplication first, then the multiply/divide laws, then power-of-a-power with zero and negative powers.

## Level 1 — powers as repeated multiplication
Level 1 questions from the type files. Pass mark: write any repeated multiplication as a power, give its value for small bases, and read the base and the index apart.

## Level 2 — the multiply and divide laws
Level 2 questions from the type files. Pass mark: add indices when multiplying same-base powers, subtract when dividing, and refuse to join different bases.

## Level 3 — power of a power, zero and negative powers
Level 3 questions from the type files. Pass mark: multiply indices for a power of a power, give any zero power as 1, and turn a negative index into a reciprocal.
