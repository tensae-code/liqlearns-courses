# Ordering — Types of Zero and Scale Origins

1. (Layer 3) Put these January temperatures in order from coldest to warmest, using the book's city readings and the scale's chosen zero:
   (a) +12 °C
   (b) 0 °C
   (c) −9 °C
   (d) −2 °C

   **Answer: (c), (d), (b), (a)** — below the chosen zero the temperatures keep falling: −9 < −2 < 0 < +12. Turkey, *Matematik 7. Sınıf Ders Kitabı, 1. Kitap* (Grade 7), printed p. 19 (readings), pp. 15–16 (the chosen zero).

2. (Layers 2–4) Order these zeros from "hardest floor" to "softest": which ones can a value pass below?
   (a) Kelvin's 0 K
   (b) a scale's 0 kg
   (c) Celsius's 0 °C

   **Answer: (c) can be passed — temperatures run below it; (a) and (b) cannot — Kelvin's zero is the absolute floor of temperature and 0 kg is no mass at all, so (a) and (b) tie as impassable, with (c) the only passable zero.** Turkey, Grade 7, printed pp. 15–16, 34.
