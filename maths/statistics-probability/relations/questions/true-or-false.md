# Relations — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Ordered Pairs and the Cartesian Product · (Level 2) -> Sub lesson 2 — Relations, Domain, Range and Inverse · (Level 3) -> Sub lesson 3 — Transitive and Equivalence Relations.

Say true or false, and be ready to say why.

**1. (Sub lesson 1)** (a, b) and (b, a) are always the same pair. True or false?
**Answer:** False — they are equal only when a = b; order matters.

**2. (Sub lesson 1)** S × T = T × S for all sets S and T. True or false?
**Answer:** False — Yemen's Grade 7 book states S × T ≠ T × S (p. 34); the pairs are turned round.

**3. (Sub lesson 2)** Every member of B must appear in the range of a relation from A to B. True or false?
**Answer:** False — only members that actually appear in a pair are in the range.

**4. (Sub lesson 2)** The inverse of the inverse of a relation is the relation itself. True or false?
**Answer:** True — turning every pair round twice restores each pair.

**5. (Sub lesson 3)** "Is greater than" is an equivalence relation on the counting numbers. True or false?
**Answer:** False — it is transitive but not reflexive (no number is greater than itself) and not symmetric.

**6. (Sub lesson 3)** Two relations are equal when they have the same domain. True or false?
**Answer:** False — Libya's rule: relations are equal when they hold exactly the same pairs (Grade 10, Ch. 1).
