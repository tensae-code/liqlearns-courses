# Relations — true or false

Say true or false, and be ready to say why.

**1. (Level 1)** (a, b) and (b, a) are always the same pair. True or false?
**Answer:** False — they are equal only when a = b; order matters.

**2. (Level 1)** S × T = T × S for all sets S and T. True or false?
**Answer:** False — Yemen's Grade 7 book states S × T ≠ T × S (p. 34); the pairs are turned round.

**3. (Level 2)** Every member of B must appear in the range of a relation from A to B. True or false?
**Answer:** False — only members that actually appear in a pair are in the range.

**4. (Level 2)** The inverse of the inverse of a relation is the relation itself. True or false?
**Answer:** True — turning every pair round twice restores each pair.

**5. (Level 3)** "Is greater than" is an equivalence relation on the counting numbers. True or false?
**Answer:** False — it is transitive but not reflexive (no number is greater than itself) and not symmetric.

**6. (Level 3)** Two relations are equal when they have the same domain. True or false?
**Answer:** False — Libya's rule: relations are equal when they hold exactly the same pairs (Grade 10, Ch. 1).
