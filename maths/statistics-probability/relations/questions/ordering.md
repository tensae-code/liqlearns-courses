# Relations — ordering

Put each list in order, or build it in the order asked.

**1. (Level 1)** List the pairs of {a, b} × {1, 2} in dictionary order (by first member, then second).
**Answer:** (a, 1), (a, 2), (b, 1), (b, 2) — all of a's pairs before all of b's.

**2. (Level 2)** A relation is built in steps. Put the steps in order: choose pairs by a link; write the Cartesian product; name the two sets.
**Answer:** Name the two sets → write the Cartesian product → choose pairs by a link. The relation is chosen from the product.

**3. (Level 3)** Put the three equivalence tests in the order this lesson runs them: transitivity; reflexivity; symmetry.
**Answer:** Reflexivity → symmetry → transitivity. One failed test ends the claim at that step.
