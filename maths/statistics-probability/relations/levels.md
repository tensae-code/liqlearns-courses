# Relations — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
relations — ordered pairs and the product first, then relations with domain, range and inverse, then transitive and equivalence relations, the order the books teach them in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Ordered Pairs and the Cartesian Product
Sub lesson 1 questions from the type files. Pass mark: write and compare ordered pairs, build A × B for small sets, and count its pairs as |A| × |B|.

## Sub lesson 2 — Relations, Domain, Range and Inverse
Sub lesson 2 questions from the type files. Pass mark: state a relation as a set of pairs, read off its domain and range, and write its inverse relation.

## Sub lesson 3 — Transitive and Equivalence Relations
Sub lesson 3 questions from the type files. Pass mark: test reflexivity, symmetry and transitivity on a small relation, declare equivalence only when all three hold, and list the equivalence classes.
