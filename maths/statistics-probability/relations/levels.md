# Relations — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — relations — ordered pairs and the product first, then relations with domain, range and inverse, then transitive and equivalence relations, the order the books teach them in.

## Level 1 — ordered pairs and the Cartesian product
Level 1 questions from the type files. Pass mark: write and compare ordered pairs, build A × B for small sets, and count its pairs as |A| × |B|.

## Level 2 — relations, domain, range and inverse
Level 2 questions from the type files. Pass mark: state a relation as a set of pairs, read off its domain and range, and write its inverse relation.

## Level 3 — transitive and equivalence relations
Level 3 questions from the type files. Pass mark: test reflexivity, symmetry and transitivity on a small relation, declare equivalence only when all three hold, and list the equivalence classes.
