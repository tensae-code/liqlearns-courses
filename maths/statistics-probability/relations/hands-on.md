# Hands-on — Relations

The lesson paired real things first, the way Yemen's Grade 7 book opens relations (Unit 1, printed pp. 32–37).

## Pairing cards
Take three people (or three named cards) and four fruits. Write every possible pairing on its own card: (person, fruit). Count the cards before you write them — 3 × 4 = 12 — then write them all and check the count. Turn one card round and read it: the turned card is a different pair, and it belongs to the other product, fruits × people.

## Who likes what
From your 12 cards, keep only the true ones: the pairs where that person really likes that fruit. That kept set is a relation. Read off its domain (the people who appear) and its range (the fruits that appear). Is there a fruit nobody likes? Then it is in the second set but not in the range — say so out loud.

## Sort the buttons
Take a box of buttons or shapes. Sort them by "has the same colour as". Check the three tests with your hands: every button has the same colour as itself; if A matches B then B matches A; if A matches B and B matches C then A matches C. All three hold, so this is an equivalence relation, and each colour pile is one equivalence class. Now try "is bigger than": which test fails first?
