# Collecting and Showing Data — ordering

Put each set in order, as the question says.

**1. (Level 1)** Put the work in order: draw the chart; collect the data; tally the answers; build the frequency table.
**Answer:** Collect the data; tally the answers; build the frequency table; draw the chart.

**2. (Level 2)** Order these pie sectors from smallest to largest angle: one half, one quarter, one eighth, the whole pie.
**Answer:** One eighth (45°), one quarter (90°), one half (180°), the whole pie (360°).

**3. (Level 3)** Order these displays from youngest to oldest in the books: histogram, pictogram, bar chart.
**Answer:** Pictogram, bar chart, histogram — pictograms come first (Kazakhstan Grade 1; South Africa Grades 1–3), histograms last (Egypt Grade 6; Jordan Grade 9).
