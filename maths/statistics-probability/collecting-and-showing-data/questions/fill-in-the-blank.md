# Collecting and Showing Data — fill in the blank

Fill each blank with a word from the box.

**Box:** tally · frequency · pictogram · bar chart · pie chart · histogram

**1. (Level 1)** One mark per answer is called a ______.
**Answer: tally.**

**2. (Level 1)** A table that counts how often each answer happens is a ______ table.
**Answer: frequency.**

**3. (Level 2)** A picture chart that uses symbols is a ______.
**Answer: pictogram.**

**4. (Level 2)** A chart that cuts a circle into sectors is a ______ chart.
**Answer: pie.**

**5. (Level 3)** A chart with touching bars for grouped numbers is a ______.
**Answer: histogram.**

**6. (Level 3)** Bars with gaps show separate categories: that is a ______ chart.
**Answer: bar.**
