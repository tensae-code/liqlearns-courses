# Collecting and Showing Data — fill in the blank

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Collecting and Tabling · (Level 2) -> Sub lesson 2 — Picture Displays · (Level 3) -> Sub lesson 3 — Histograms and Choosing.

Fill each blank with a word from the box.

**Box:** tally · frequency · pictogram · bar chart · pie chart · histogram

**1. (Sub lesson 1)** One mark per answer is called a ______.
**Answer: tally.**

**2. (Sub lesson 1)** A table that counts how often each answer happens is a ______ table.
**Answer: frequency.**

**3. (Sub lesson 2)** A picture chart that uses symbols is a ______.
**Answer: pictogram.**

**4. (Sub lesson 2)** A chart that cuts a circle into sectors is a ______ chart.
**Answer: pie.**

**5. (Sub lesson 3)** A chart with touching bars for grouped numbers is a ______.
**Answer: histogram.**

**6. (Sub lesson 3)** Bars with gaps show separate categories: that is a ______ chart.
**Answer: bar.**
