# Collecting and Showing Data — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — counting and tabling first, then the picture displays, then histograms and choosing between displays.

## Level 1 — collecting and tabling
Level 1 questions from the type files. Pass mark: collect data by a survey, tally it, and build a frequency table.

## Level 2 — picture displays
Level 2 questions from the type files. Pass mark: draw and read pictograms, bar charts, line graphs and pie charts, with the sector-angle rule.

## Level 3 — histograms and choosing
Level 3 questions from the type files. Pass mark: draw a histogram, tell it from a bar chart, and choose the right display for a set of data.
