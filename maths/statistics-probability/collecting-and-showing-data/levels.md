# Collecting and Showing Data — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
counting and tabling first, then the picture displays, then histograms and choosing between displays.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Collecting and Tabling
Sub lesson 1 questions from the type files. Pass mark: collect data by a survey, tally it, and build a frequency table.

## Sub lesson 2 — Picture Displays
Sub lesson 2 questions from the type files. Pass mark: draw and read pictograms, bar charts, line graphs and pie charts, with the sector-angle rule.

## Sub lesson 3 — Histograms and Choosing
Sub lesson 3 questions from the type files. Pass mark: draw a histogram, tell it from a bar chart, and choose the right display for a set of data.
