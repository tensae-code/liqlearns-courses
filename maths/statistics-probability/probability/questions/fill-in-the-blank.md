# Probability — fill in the blank

Fill each blank with a word from the box.

**Box:** sample space · event · certain · impossible · complement · conditional

**1. (Level 1)** The set of all possible outcomes is the ______ space.
**Answer: sample.**

**2. (Level 1)** An event that must happen is ______.
**Answer: certain.**

**3. (Level 1)** An event that cannot happen is ______.
**Answer: impossible.**

**4. (Level 2)** P(not A) = 1 − P(A) is the ______ rule.
**Answer: complement.**

**5. (Level 3)** Probability given that another event happened is ______ probability.
**Answer: conditional.**

**6. (Level 3)** A tree ______ shows the branches of a multi-stage experiment.
**Answer: diagram.**
