# Probability — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — one event first, then the complement and combining events, then counting, conditional probability and distributions.

## Level 1 — one event
Level 1 questions from the type files. Pass mark: name the sample space and the event, and find a theoretical probability as a fraction, decimal or percentage.

## Level 2 — combining events
Level 2 questions from the type files. Pass mark: use the complement, the addition law and the multiplication law, and list outcomes with tables and trees.

## Level 3 — conditional probability and distributions
Level 3 questions from the type files. Pass mark: work conditional probability without replacement, use Bayes' shape, and name the binomial, geometric and normal distributions.
