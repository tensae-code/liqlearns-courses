# Carroll Diagrams — true or false

Say true or false, and be ready to say why.

**1. (Level 1)** A thing can belong in two boxes of a Carroll diagram at once. True or false?
**Answer:** False — the two yes/no answers fix exactly one box.

**2. (Level 2)** "Big" is a good opposite label for "small" in a Carroll diagram. True or false?
**Answer:** False — the opposite label must be "not small", so that everything answers yes or no with no middle left over.

**3. (Level 2)** In a Carroll diagram, the four box counts add up to the number of things sorted. True or false?
**Answer:** True — nothing is counted twice and nothing is missed; that is the check on a finished diagram.

**4. (Level 3)** A Venn diagram and a Carroll diagram sort in the same drawing. True or false?
**Answer:** False — Venn sorts with overlapping loops, Carroll with a table; Laos's Grade 6 book sets them side by side as different drawings (pp. 193–197).

**5. (Level 3)** Kuwait's Grade 4 book teaches Carroll diagrams before Venn diagrams. True or false?
**Answer:** False — Venn diagrams are lesson 4-9 (p. 156) and Carroll diagrams lesson 4-10 (p. 158), after.
