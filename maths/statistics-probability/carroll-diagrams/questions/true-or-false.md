# Carroll Diagrams — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. This lesson's parts did not cut by the old depth layers — the text's own order governs — so items are marked item by item by what each item actually asks: table-shape and label items are Sub lesson 1 — The Carroll Table; Venn-comparison items are Sub lesson 2 — Carroll Beside Venn; reading, counting and placing items are Sub lesson 3 — Reading and Placing in a Box.

Say true or false, and be ready to say why.

**1. (Sub lesson 1)** A thing can belong in two boxes of a Carroll diagram at once. True or false?
**Answer:** False — the two yes/no answers fix exactly one box.

**2. (Sub lesson 1)** "Big" is a good opposite label for "small" in a Carroll diagram. True or false?
**Answer:** False — the opposite label must be "not small", so that everything answers yes or no with no middle left over.

**3. (Sub lesson 3)** In a Carroll diagram, the four box counts add up to the number of things sorted. True or false?
**Answer:** True — nothing is counted twice and nothing is missed; that is the check on a finished diagram.

**4. (Sub lesson 2)** A Venn diagram and a Carroll diagram sort in the same drawing. True or false?
**Answer:** False — Venn sorts with overlapping loops, Carroll with a table; Laos's Grade 6 book sets them side by side as different drawings (pp. 193–197).

**5. (Sub lesson 2)** Kuwait's Grade 4 book teaches Carroll diagrams before Venn diagrams. True or false?
**Answer:** False — Venn diagrams are lesson 4-9 (p. 156) and Carroll diagrams lesson 4-10 (p. 158), after.
