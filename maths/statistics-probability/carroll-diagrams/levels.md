# Carroll Diagrams — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — Carroll diagrams — reading a diagram first, then sorting into one, then Carroll beside Venn, the order the books teach them in.

## Level 1 — reading a Carroll diagram
Level 1 questions from the type files. Pass mark: given a filled Carroll diagram, say what a named box holds and count a box.

## Level 2 — sorting into a Carroll diagram
Level 2 questions from the type files. Pass mark: place new things into the right boxes by the two yes/no questions, and complete a partly filled diagram.

## Level 3 — Carroll beside Venn, and building the labels
Level 3 questions from the type files. Pass mark: choose correct "not" labels for a new sorting task, and explain where the "not, not" things go in a Carroll diagram versus a Venn diagram.
