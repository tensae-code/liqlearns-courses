# Averages and Spread — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the middle and the fair share first, then quartiles and the box plot, then variance and standard deviation.

## Level 1 — mean, median, mode
Level 1 questions from the type files. Pass mark: find the mean, median and mode of a list, and say which one fits.

## Level 2 — quartiles and the box plot
Level 2 questions from the type files. Pass mark: find the quartiles and the interquartile range, and read a box-and-whisker plot.

## Level 3 — spread: deviation, variance, standard deviation
Level 3 questions from the type files. Pass mark: find the range, mean deviation, variance and standard deviation, for grouped and ungrouped data.
