# Averages and Spread — ordering

Put each set in order, as the question says.

**1. (Level 1)** Order these from smallest to largest: the median of 1, 9, 9; the mean of 1, 9, 9; the mode of 1, 9, 9.
**Answer:** mean (≈6.33), median (9), mode (9) — the median and mode tie at 9.

**2. (Level 2)** Order these steps for finding the median: order the numbers; find the middle one; count how many there are.
**Answer:** Count how many there are; order the numbers; find the middle one.

**3. (Level 3)** Order these spreads from smallest to largest for 2, 4, 6, 8, 10: range, interquartile range, standard deviation.
**Answer:** Standard deviation (≈2.8), interquartile range (Q1 = 3, Q3 = 9, so 6), range (8). Order: standard deviation, interquartile range, range.
