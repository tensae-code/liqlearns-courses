# Averages and Spread — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Mean, Median, Mode · (Level 2) -> Sub lesson 2 — Quartiles and the Box Plot · (Level 3) -> Sub lesson 3 — Spread: Deviation, Variance, Standard Deviation.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** The mean of 1, 2, 3 is 2.
**True** — 6 ÷ 3.

**2. (Sub lesson 1)** You can find the median without ordering the numbers.
**False** — the median is the middle value of the ordered list.

**3. (Sub lesson 2)** A set can have no mode.
**True** — if no value repeats, there is no mode.

**4. (Sub lesson 2)** The interquartile range holds the middle half of the numbers.
**True** — from Q1 to Q3.

**5. (Sub lesson 3)** An outlier pulls the mean more than the median.
**True** — the mean is pulled toward the outlier; the median stands still (Egypt, Grade 6 Term 1).

**6. (Sub lesson 3)** For grouped data the exact mean can always be got back.
**False** — the single numbers inside each class are lost, so the mean is estimated from class midpoints (Sierra Leone, JSS 3 Term 3, L128).
