# Hands-on — Sets

## Sorting the table
Tip your things on the table. Sort them into two sets that overlap — round things, and red things. Put a loop of string round each set so the loops cross. Touch each thing and say which set or sets it is in. Move one thing and say what changes.

## Venn on the floor
Draw two big overlapping circles on paper, or with chalk outside. Write the numbers 1 to 9 on small cards. Put the odd numbers in one circle and the numbers 1 to 5 in the other, the way Sierra Leone's book does. Stand in the overlap: which numbers are under your feet? Step out of both circles: which numbers are nowhere?

## The empty set hunt
Find a set in your home with nothing in it — a box with no toys, a shelf with no books. That is the empty set, and it is still a set. Write it as { } and as ∅. Now name a set it sits inside — the empty set sits inside every set.

## Complement walk
Pick a set — the books on one shelf. Its complement is every book that is NOT on that shelf. Walk the room and count both. Check: the set plus its complement is the whole shelf of books, the universal set.
