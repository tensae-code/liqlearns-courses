# Sets — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
naming a set first, then joining and meeting sets, then complements, laws and counting.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Naming a Set
Sub lesson 1 questions from the type files. Pass mark: write a set by listing and by a rule, name its elements, and tell finite from infinite from empty.

## Sub lesson 2 — Union and Intersection
Sub lesson 2 questions from the type files. Pass mark: find a union and an intersection, draw both on a Venn diagram, and find a subset.

## Sub lesson 3 — Complement, Laws and Counting
Sub lesson 3 questions from the type files. Pass mark: find complements and differences, use De Morgan's laws, and count a union with the n(A ∪ B) formula.
