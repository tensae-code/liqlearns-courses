# Sets — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — naming a set first, then joining and meeting sets, then complements, laws and counting.

## Level 1 — naming a set
Level 1 questions from the type files. Pass mark: write a set by listing and by a rule, name its elements, and tell finite from infinite from empty.

## Level 2 — union and intersection
Level 2 questions from the type files. Pass mark: find a union and an intersection, draw both on a Venn diagram, and find a subset.

## Level 3 — complement, laws and counting
Level 3 questions from the type files. Pass mark: find complements and differences, use De Morgan's laws, and count a union with the n(A ∪ B) formula.
