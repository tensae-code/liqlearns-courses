# Sets — the lesson

Course: Maths · Stage 11 — Statistics and Probability · Lesson 42 of 52
Built from: Egypt, Grade 7 Term 1 — Libya, Grade 10 Part 1 — Sierra Leone, JSS 3 Term 1 — Armenia, Algebra 7 — Jordan, Grade 9 Term 1 — Greece, Grade 9 — Kazakhstan, Grade 1 Part 1.

## Do it first
Put your buttons, coins and stones on the table. Push the round ones into one pile and the red ones into another pile. One button is round AND red — it belongs in both piles at once, so let the piles overlap and put it where they cross. You have just built sets, and found their overlap, before a single definition.

## Then the explanation
**What a set is.** A set is a collection of things, put together and given a name. The things in it are its **elements** (or members). Egypt's Grade 7 book writes a set two ways: by **listing** its elements between braces, and by a **rule** (set-builder notation) that says which things belong. A set is usually named with a capital letter: A = {1, 3, 5, 7, 9}. The sign ∈ means "is an element of": 3 ∈ A, and 2 ∉ A. Armenia's Algebra 7 opens its set chapter the same way: a set, then its elements, then the question of what belongs.

**Kinds of sets.** A **finite** set has a countable number of elements — {1, 3, 5, 7, 9} has five. An **infinite** set goes on without end, like the counting numbers. The **empty set**, written ∅ or { }, has no elements at all — and it is still a set. Two sets are **equal** when they hold exactly the same elements. One set is a **subset** of another when every element of the first is also in the second: A is a subset of B, written A ⊆ B. Kazakhstan's Grade 1 book meets sets at their youngest: a set, an element, the empty set, and equal and unequal sets — the same ideas, learned on pictures first. The **universal set**, usually U, is the big set everything in the question comes from.

**Union and intersection.** The **union** of two sets, A ∪ B, holds everything that is in A OR in B (or both): the either-set. The **intersection**, A ∩ B, holds only what is in A AND in B: the both-set. Sierra Leone's JSS 3 book works this on A = {1, 3, 5, 7, 9} and B = {1, 2, 3, 4, 5}: A ∩ B = {1, 3, 5} and A ∪ B = {1, 2, 3, 4, 5, 7, 9}. A **Venn diagram** draws each set as a circle, overlapping so the crossing holds the intersection; Greece's Grade 9 book puts sets beside sample spaces and events, the same circles carrying probability later. Jordan's Grade 9 book writes sets beside intervals: a set of numbers can be written as an interval on the number line, and a solution set is a set.

**Complement and difference.** The **complement** of A, written Aᶜ, holds everything in the universal set that is NOT in A. The **difference** A − B holds what is in A but not in B. Libya's Grade 10 book carries the **laws of set operations**: the complement of a union is the intersection of the complements, and the complement of an intersection is the union of the complements — De Morgan's laws — proved on membership tables, with commutativity, identity, and distribution beside them. Libya also teaches the **Cartesian product**: pairing every element of one set with every element of another, the pairs that relations and functions are built from.

**Counting a union.** When two sets overlap, adding their sizes counts the overlap twice. So the books count it once: n(A ∪ B) = n(A) + n(B) − n(A ∩ B), where n(A) means the number of elements in A. Sierra Leone's SSS 3 review lesson keeps this formula ready for examinations, worked on Venn diagrams with mixed set problems.

> **Tip — from us, not from the books:** read ∪ as "or" and ∩ as "and", out loud, every time. The shape helps too: ∪ opens upward like a cup that holds everything from both sets; ∩ closes downward to the little bit the two share.

## Say it to your companion
Show your companion your two string loops and the things inside them. Say: "This is set A. This is set B. This thing is in the intersection, because it is in both. These things are only in the union." Then your companion points at a thing outside both loops and asks: "What set is that in?" Answer: "The complement — it is in neither."

## Do It Yourself
1. Make three sets from your home: the books on one shelf, the red things in one room, the round things in one room. Write each set by listing.
2. Find the union and the intersection of the red things and the round things. Draw the Venn diagram.
3. Name the universal set (everything in that room), and write the complement of the red-things set.
4. Count with the formula: count your red things, count your round things, count the things that are both, and check that n(A ∪ B) = n(A) + n(B) − n(A ∩ B) matches what you counted by hand.
