# Sets — ordering

Put each set in order, as the question says.

**1. (Level 1)** Put these in order from fewest elements to most: {1}, {1, 2, 3}, ∅, {1, 2}.
**Answer:** ∅, {1}, {1, 2}, {1, 2, 3}.

**2. (Level 2)** A = {1, 2, 3, 4}, B = {3, 4, 5, 6}. Order these from smallest set to largest: A ∪ B, A ∩ B, A.
**Answer:** A ∩ B = {3, 4} (2 elements), A = {1, 2, 3, 4} (4 elements), A ∪ B = {1, 2, 3, 4, 5, 6} (6 elements).

**3. (Level 3)** Order the steps for finding n(A ∪ B): add n(A) and n(B); take away n(A ∩ B) once; count n(A ∩ B).
**Answer:** Count n(A ∩ B); add n(A) and n(B); take away n(A ∩ B) once.
