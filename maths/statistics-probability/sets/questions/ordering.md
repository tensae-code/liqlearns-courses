# Sets — ordering

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Naming a Set · (Level 2) -> Sub lesson 2 — Union and Intersection · (Level 3) -> Sub lesson 3 — Complement, Laws and Counting.

Put each set in order, as the question says.

**1. (Sub lesson 1)** Put these in order from fewest elements to most: {1}, {1, 2, 3}, ∅, {1, 2}.
**Answer:** ∅, {1}, {1, 2}, {1, 2, 3}.

**2. (Sub lesson 2)** A = {1, 2, 3, 4}, B = {3, 4, 5, 6}. Order these from smallest set to largest: A ∪ B, A ∩ B, A.
**Answer:** A ∩ B = {3, 4} (2 elements), A = {1, 2, 3, 4} (4 elements), A ∪ B = {1, 2, 3, 4, 5, 6} (6 elements).

**3. (Sub lesson 3)** Order the steps for finding n(A ∪ B): add n(A) and n(B); take away n(A ∩ B) once; count n(A ∩ B).
**Answer:** Count n(A ∩ B); add n(A) and n(B); take away n(A ∩ B) once.
