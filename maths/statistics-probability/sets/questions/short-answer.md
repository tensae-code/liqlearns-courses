# Sets — short answer

Answer in a word or a short line.

**1. (Level 1)** Write the set of odd numbers from 1 to 9 by listing.
**Answer:** {1, 3, 5, 7, 9}.

**2. (Level 1)** Is 4 an element of {1, 3, 5, 7, 9}? Answer with ∈ or ∉.
**Answer:** 4 ∉ {1, 3, 5, 7, 9}.

**3. (Level 2)** A = {2, 4, 6}, B = {4, 6, 8}. Write A ∩ B and A ∪ B.
**Answer:** A ∩ B = {4, 6}; A ∪ B = {2, 4, 6, 8}.

**4. (Level 2)** Draw a Venn diagram in words: two circles overlap. Where does the intersection sit?
**Answer:** In the crossing — the part shared by both circles.

**5. (Level 3)** U = {1, 2, 3, 4, 5}, A = {2, 4}. Write Aᶜ.
**Answer:** Aᶜ = {1, 3, 5}.
