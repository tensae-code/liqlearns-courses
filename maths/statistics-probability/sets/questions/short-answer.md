# Sets — short answer

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Naming a Set · (Level 2) -> Sub lesson 2 — Union and Intersection · (Level 3) -> Sub lesson 3 — Complement, Laws and Counting.

Answer in a word or a short line.

**1. (Sub lesson 1)** Write the set of odd numbers from 1 to 9 by listing.
**Answer:** {1, 3, 5, 7, 9}.

**2. (Sub lesson 1)** Is 4 an element of {1, 3, 5, 7, 9}? Answer with ∈ or ∉.
**Answer:** 4 ∉ {1, 3, 5, 7, 9}.

**3. (Sub lesson 2)** A = {2, 4, 6}, B = {4, 6, 8}. Write A ∩ B and A ∪ B.
**Answer:** A ∩ B = {4, 6}; A ∪ B = {2, 4, 6, 8}.

**4. (Sub lesson 2)** Draw a Venn diagram in words: two circles overlap. Where does the intersection sit?
**Answer:** In the crossing — the part shared by both circles.

**5. (Sub lesson 3)** U = {1, 2, 3, 4, 5}, A = {2, 4}. Write Aᶜ.
**Answer:** Aᶜ = {1, 3, 5}.
