# Sets — matching

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Naming a Set · (Level 2) -> Sub lesson 2 — Union and Intersection · (Level 3) -> Sub lesson 3 — Complement, Laws and Counting.

Match each left side to its right side.

**Set (Sub lesson 1)** — symbols
1. ∪ — **union**
2. ∩ — **intersection**
3. ∈ — **is an element of**
4. ∅ — **the empty set**
5. ⊆ — **is a subset of**

**Set (Sub lesson 2)** — words
1. everything in either set — **union**
2. only what is in both sets — **intersection**
3. everything not in the set — **complement**
4. what is in A but not in B — **difference**

**Set (Sub lesson 3)** — laws and counts
1. n(A ∪ B) — **n(A) + n(B) − n(A ∩ B)**
2. (A ∪ B)ᶜ — **Aᶜ ∩ Bᶜ**
3. (A ∩ B)ᶜ — **Aᶜ ∪ Bᶜ**
