# Sets — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Naming a Set · (Level 2) -> Sub lesson 2 — Union and Intersection · (Level 3) -> Sub lesson 3 — Complement, Laws and Counting.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** The empty set is not a set at all.
**False** — the empty set is a real set with no elements, and it sits inside every set.

**2. (Sub lesson 1)** Every element of a subset is also in the bigger set.
**True** — that is what subset means (Armenia, Algebra 7, §3.3).

**3. (Sub lesson 2)** The union holds only the elements in both sets.
**False** — that is the intersection. The union holds everything in either set.

**4. (Sub lesson 2)** In a Venn diagram, the overlap of two circles is the intersection.
**True** — the both-part.

**5. (Sub lesson 3)** n(A ∪ B) = n(A) + n(B) always.
**False** — only when the sets do not overlap. With an overlap, take n(A ∩ B) away once.

**6. (Sub lesson 3)** De Morgan's law says the complement of a union is the intersection of the complements.
**True** — Libya, Grade 10 Part 1, Chapter 1.
