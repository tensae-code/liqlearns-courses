# Sets — multiple choice

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Naming a Set · (Level 2) -> Sub lesson 2 — Union and Intersection · (Level 3) -> Sub lesson 3 — Complement, Laws and Counting.

Pick the one right answer.

**1. (Sub lesson 1)** A set is ______.
a) a single number  b) a collection of things put together  c) a kind of graph
**Answer: b) a collection of things put together.**

**2. (Sub lesson 1)** The empty set has ______ elements.
a) 0  b) 1  c) too many to count
**Answer: a) 0** — it is still a set (Egypt, Grade 7 Term 1, pp.14–18).

**3. (Sub lesson 2)** For A = {1, 3, 5, 7, 9} and B = {1, 2, 3, 4, 5}, A ∩ B is ______.
a) {1, 3, 5}  b) {1, 2, 3, 4, 5, 7, 9}  c) {2, 4}
**Answer: a) {1, 3, 5}** — the elements in both sets (Sierra Leone, JSS 3 Term 1, L13).

**4. (Sub lesson 2)** For the same A and B, A ∪ B is ______.
a) {1, 3, 5}  b) {1, 2, 3, 4, 5, 7, 9}  c) {7, 9}
**Answer: b) {1, 2, 3, 4, 5, 7, 9}** — everything in either set (Sierra Leone, JSS 3 Term 1, L13).

**5. (Sub lesson 3)** The complement of A holds ______.
a) everything in A  b) everything in the universal set that is not in A  c) nothing at all
**Answer: b) everything in the universal set that is not in A.**

**6. (Sub lesson 3)** If n(A) = 5, n(B) = 4 and n(A ∩ B) = 2, then n(A ∪ B) = ______.
a) 9  b) 7  c) 11
**Answer: b) 7** — 5 + 4 − 2 (Sierra Leone, SSS 3 Term 3, L121).
