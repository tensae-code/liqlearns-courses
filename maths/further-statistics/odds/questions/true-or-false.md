# Odds — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** Odds of 1:5 and probability 1/5 say the same thing.
**Answer:** False — odds 1:5 mean 1 for and 5 against, a probability of 1/6; the die's 2 is exactly this case (Kuwait, 4-6).

**2. (Level 1)** Odds simplify like a ratio: 4:10 is the same odds as 2:5.
**Answer:** True — the pens box's blue is the book's own example.

**3. (Level 2)** If the odds are 3:10, the probability is 3/10.
**Answer:** False — the probability is 3/(3 + 10) = 3/13 (Kuwait, 4-6).

**4. (Level 3)** A game is fair whenever both sides can win.
**Answer:** False — fairness is in the counts: doubles (6) against different numbers (30) can both win, and the game is still one-sided (Kuwait, 4-6).
