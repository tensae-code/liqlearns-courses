# Odds — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one small thing — odds stated first, then the two conversions, then fairness.

## Level 1 — stating odds
Level 1 questions from the type files. Pass mark: state the odds of a simple event as favourable : unfavourable, simplified, from the book's own die and pens cases.

## Level 2 — odds ↔ probability
Level 2 questions from the type files. Pass mark: convert odds a : b to the probability a/(a + b) and a probability back to odds, landing on the book's own pairs — 2:3 ↔ 2/5 and 5/13 → 5:8 — without a slip.

## Level 3 — odds and fairness
Level 3 questions from the type files. Pass mark: judge a two-sided game fair or unfair from the outcome counts, and defend the verdict in a whole sentence.
