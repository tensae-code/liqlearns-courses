# Quartiles, Percentiles and Box Plots — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** The whiskers of a box plot run from the box to the smallest and largest values.
**Answer:** True — the box itself runs only from Q1 to Q3 (Kuwait Grade 9, pp.198–203).

**2. (Level 1)** Quartiles split the *size* of the numbers into four equal amounts.
**Answer:** False — they split the *count* of ordered values into four equal parts; order the data first (Jordan Grade 8, p.144).

**3. (Level 2)** Cambodia's grouped decile answers (Q1 = 53.31 and the rest) are printed in its Grade 11 Basic student book.
**Answer:** False — they are the teacher guide's answers (guide, printed p.222), cited as teacher evidence only.

**4. (Level 2)** Ethiopia's guide value D3 = 21.5 may be taught as printed.
**Answer:** False — it is the guide's arithmetic slip; the corrected teacher-evidence value is D3 = 20.15 (guide, p.228, corrected).

**5. (Level 3)** The median read from an ogive and the median found by grouped interpolation are the same number, up to drawing accuracy.
**Answer:** True — the ogive is the interpolation drawn (Iraq, pp.80–82; Kuwait Grade 11 Statistics, pp.15–18).

**6. (Level 3)** A longer box in a box plot means a larger interquartile range.
**Answer:** True — the box stretches from Q1 to Q3, so its length is the IQR (Kuwait Grade 10, pp.174–175).
