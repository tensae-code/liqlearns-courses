# Quartiles, Percentiles and Box Plots — ordering

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Quartiles, the Five-Number Summary and the Box Plot · (Level 2) -> Sub lesson 2 — Deciles, Percentiles, Grouped Interpolation and the Semi-Interquartile Range · (Level 3) -> Sub lesson 3 — Cumulative Frequency Curves and Comparing Plots.

Put the steps in the right order.

**1. (Sub lesson 1)** Finding quartiles in raw data: (a) order the values (b) find the median (c) find the median of the lower half (Q1) and of the upper half (Q3).
**Answer:** a, b, c — nothing is found before the data are ordered (Kuwait Grade 11 Statistics, p.12).

**2. (Sub lesson 1)** Drawing a box plot: (a) mark the five-number summary on a number line (b) draw the box from Q1 to Q3 with a line at the median (c) draw whiskers to the smallest and largest values (d) find the five numbers.
**Answer:** d, a, b, c — numbers first, then the drawing (Kuwait Grade 9, pp.198–203).

**3. (Sub lesson 2)** A grouped quartile by interpolation: (a) find the rank (n/4 for Q1) (b) locate the class where the cumulative frequency passes the rank (c) interpolate inside the class across its width.
**Answer:** a, b, c — Kuwait Grade 11 Statistics, pp.15–18.

**4. (Sub lesson 3)** Reading a percentile off an ogive: (a) compute the cumulative frequency kn/100 (b) run across to the curve (c) drop down to the value axis and read the value (d) draw the ogive.
**Answer:** d, a, b, c — the curve first, then across and down (Iraq, pp.80–82; South Sudan, pp.76–82).

**5. (Sub lesson 3)** The five landmarks in order along the axis: (a) Q3 (b) smallest (c) median (d) largest (e) Q1.
**Answer:** b, e, c, a, d — smallest, Q1, median, Q3, largest (Kuwait Grade 10, pp.170–175).
