# Quartiles, Percentiles and Box Plots — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — quartiles and the box plot on raw data first, then deciles, percentiles and grouped interpolation, then percentiles read from the cumulative frequency curve.

## Level 1 — quartiles, the five-number summary and the box plot
Level 1 questions from the type files. Pass mark: order data and find Q1, the median and Q3, state the five-number summary, draw and read a box-and-whisker plot, and find the interquartile range.

## Level 2 — deciles, percentiles, grouped interpolation and the semi-interquartile range
Level 2 questions from the type files. Pass mark: define and find deciles and percentiles in raw and grouped data by interpolation, find the semi-interquartile range, and state Cambodia's guide answers as teacher evidence and Ethiopia's guide values at their corrected values (D3 = 20.15, Q1 = 34, cf = 92).

## Level 3 — cumulative frequency curves and comparing plots
Level 3 questions from the type files. Pass mark: draw an ogive, read the median, quartiles and any percentile off it, and compare two box plots on one scale by middle and spread.
