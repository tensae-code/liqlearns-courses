# Hypothesis Testing — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Hypotheses, Tails and the Two Errors · (Level 2) -> Sub lesson 2 — The Procedure and Tests of a Mean · (Level 3) -> Sub lesson 3 — Proportions, Differences and Paired Tests.

Say true or false, and why.

**1. (Sub lesson 1)** Failing to reject H₀ proves H₀ is true.
**Answer:** False — the evidence did not convict H₀; absence of a rejection is not a proof (Pakistan, Ch. 13, pp.115–117).

**2. (Sub lesson 1)** Making α smaller makes a Type II error more likely, on the same evidence.
**Answer:** True — the two errors trade against each other; a stricter gate misses more false H₀s.

**3. (Sub lesson 2)** Kuwait teaches one-tailed tests as well as two-tailed tests.
**Answer:** False — two-sided tests ONLY (H₁: μ ≠ μ₀) in Kuwait's book (4-2, pp.177–181).

**4. (Sub lesson 2)** A test statistic of Z = −1.66 at the 5% level, two-tailed, rejects H₀.
**Answer:** False — |−1.66| < 1.96, inside the acceptance region, as in Kuwait's old water study (4-2, pp.177–181).

**5. (Sub lesson 3)** Iran can be cited for a hypothesis-testing method because its book mentions Fisher.
**Answer:** False — the mention is a historical note in a reading passage (p.79); no test is taught, and Iran is a recorded negative for this lesson.

**6. (Sub lesson 3)** Pakistan's Class 12 chapter tests hypotheses about a variance with a χ² test.
**Answer:** False — the chapter has no test about a variance; χ² appears in that book only as the test of independence in the association chapter (Ch. 15), not in Ch. 13.
