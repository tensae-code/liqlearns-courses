# Hypothesis Testing — true or false

Say true or false, and why.

**1. (Level 1)** Failing to reject H₀ proves H₀ is true.
**Answer:** False — the evidence did not convict H₀; absence of a rejection is not a proof (Pakistan, Ch. 13, pp.115–117).

**2. (Level 1)** Making α smaller makes a Type II error more likely, on the same evidence.
**Answer:** True — the two errors trade against each other; a stricter gate misses more false H₀s.

**3. (Level 2)** Kuwait teaches one-tailed tests as well as two-tailed tests.
**Answer:** False — two-sided tests ONLY (H₁: μ ≠ μ₀) in Kuwait's book (4-2, pp.177–181).

**4. (Level 2)** A test statistic of Z = −1.66 at the 5% level, two-tailed, rejects H₀.
**Answer:** False — |−1.66| < 1.96, inside the acceptance region, as in Kuwait's old water study (4-2, pp.177–181).

**5. (Level 3)** Iran can be cited for a hypothesis-testing method because its book mentions Fisher.
**Answer:** False — the mention is a historical note in a reading passage (p.79); no test is taught, and Iran is a recorded negative for this lesson.

**6. (Level 3)** Pakistan's Class 12 chapter tests hypotheses about a variance with a χ² test.
**Answer:** False — the chapter has no test about a variance; χ² appears in that book only as the test of independence in the association chapter (Ch. 15), not in Ch. 13.
