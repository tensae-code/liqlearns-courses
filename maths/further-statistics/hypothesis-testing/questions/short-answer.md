# Hypothesis Testing — short answer

Answer in a word or a short line.

**1. (Level 1)** A hypothesis fixing exactly one value of the parameter is called what?
**Answer:** Simple — one covering a range is composite (Pakistan, Ch. 13, pp.111–114).

**2. (Level 1)** What is β?
**Answer:** The probability of a Type II error — failing to reject a false H₀ (Pakistan, Ch. 13, pp.115–117).

**3. (Level 2)** Kuwait's food-spending case gives t ≈ −0.6917 at df 9, critical 2.262. State the verdict.
**Answer:** Do not reject H₀ — |−0.6917| < 2.262, inside the acceptance region (Kuwait, 4-2, pp.177–181).

**4. (Level 2)** n = 16, x̄ = 52, s = 8, H₀: μ = 50. Compute the t statistic.
**Answer:** t = (52 − 50)/(8/√16) = 2/2 = 1.0 (Pakistan, Ch. 13, pp.120–130).

**5. (Level 2)** Why did Kuwait's new water study (Z = −3.33) reject H₀ when the old study (Z = −1.66) kept it, though the new mean was closer to the target?
**Answer:** The new spread was smaller, so the same kind of distance counted for more standard errors (Kuwait, 4-2, pp.177–181).

**6. (Level 3)** In 200 coin tosses, heads come 118 times. Compute the Z for H₀: π = 0.5.
**Answer:** p = 0.59; SE = √(0.5 × 0.5/200) ≈ 0.0354; Z ≈ (0.59 − 0.5)/0.0354 ≈ 2.55 (Pakistan, Ch. 13, pp.135–139).

**7. (Level 3)** Differences for 8 pairs are 6, 3, 4, 3, 3, 5, 2, 4. Give d̄.
**Answer:** d̄ = 30/8 = 3.75 (Pakistan, Ch. 13, pp.158–165).

**8. (Level 3)** Name one country whose filing teaches NO hypothesis testing.
**Answer:** Any of Egypt, Cambodia, Greece, Iran — recorded negatives, cited nowhere for tests.
