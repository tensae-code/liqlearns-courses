# Correlation and Regression — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — first seeing the link in a picture, then measuring it with r and with ranks, then fitting the line, predicting with it, and judging what it does not prove.

## Level 1 — scatter diagrams and the mean point
Level 1 questions from the type files. Pass mark: plot paired data as a scatter diagram, find and plot the mean point (x̄, ȳ), and describe the cloud's direction and strength in whole sentences.

## Level 2 — Pearson's r and Spearman's rank coefficient
Level 2 questions from the type files. Pass mark: compute Pearson's r from deviations or sums, place it in Kuwait's strength bands, rank paired data (ties averaged), and compute Spearman's r_s from Σd².

## Level 3 — the regression line, determination, causation and ANOVA
Level 3 questions from the type files. Pass mark: fit ŷ = a + bx by least squares, predict with it and state the error of prediction, use both regression lines and r², explain why correlation is not causation, and say what ANOVA compares and how it splits variation.
