# Correlation and Regression — ordering

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Scatter Diagrams and the Mean Point · (Level 2) -> Sub lesson 2 — Pearson's r and Spearman's Rank Coefficient · (Level 3) -> Sub lesson 3 — The Regression Line, Determination, Causation and ANOVA.

Put the steps in the right order.

**1. (Sub lesson 1)** Reading paired data: (a) describe the cloud's direction and strength (b) plot the scatter diagram (c) collect the pairs.
**Answer:** c, b, a — pairs first, picture second, description third (Egypt Unit 1, 1-1, p.4).

**2. (Sub lesson 2)** A Spearman computation: (a) rank each list (b) compute 1 − 6Σd²/(n(n² − 1)) (c) write d and d² for each pair and add Σd².
**Answer:** a, c, b — ranks, differences, then the formula (Iraq pp.116–117; Pakistan Ch. 15, pp.236–237).

**3. (Sub lesson 2)** A Pearson computation from deviations: (a) find x̄ and ȳ (b) divide Σ(x − x̄)(y − ȳ) by √(Σ(x − x̄)² · Σ(y − ȳ)²) (c) build the deviation columns.
**Answer:** a, c, b — means, deviations, then the ratio (Iraq [4-4-2], p.108).

**4. (Sub lesson 3)** Fitting and using a regression line: (a) predict ŷ for a new x inside the data's range (b) compute b = s_xy/s²_x, then a = ȳ − bx̄ (c) check the scatter looks straight.
**Answer:** c, b, a — picture first, fit second, predict last (Pakistan Ch. 14, pp.183–194).

**5. (Sub lesson 3)** Judging a claimed link: (a) compute r (b) ask whether a third quantity could drive both (c) look at the scatter for outliers and curve.
**Answer:** a, c, b — measure, inspect the picture, then face the causation question (Pakistan p.195, p.206; Indonesia Edisi Revisi Bab 1 on outliers).
