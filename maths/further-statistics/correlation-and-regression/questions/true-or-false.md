# Correlation and Regression — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Scatter Diagrams and the Mean Point · (Level 2) -> Sub lesson 2 — Pearson's r and Spearman's Rank Coefficient · (Level 3) -> Sub lesson 3 — The Regression Line, Determination, Causation and ANOVA.

Say true or false, and why.

**1. (Sub lesson 1)** A scatter diagram has one point for each pair of measurements.
**Answer:** True — Egypt Statistics Unit 1, 1-1 (p.4); Cambodia §5.1 (p.146).

**2. (Sub lesson 1)** Cambodia's baby example has 8 babies.
**Answer:** False — taught corrected: the table has 6 columns, so the count is 6 babies (p.146, corrected as filed).

**3. (Sub lesson 2)** If every y is exactly double the x, Pearson's r = 2.
**Answer:** False — r = 1; r can never leave [−1, 1] (Pakistan Ch. 14, pp.200–202; Iraq Grade 10 Scientific works r = 1 and r = −1 cases, pp.153–154).

**4. (Sub lesson 2)** Spearman's coefficient is Pearson's r computed on the ranks instead of the raw values.
**Answer:** True — Pakistan derives it exactly that way (Ch. 15, pp.236–237).

**5. (Sub lesson 3)** The regression line of y on x and the regression line of x on y are always the same line.
**Answer:** False — they are two lines crossing at (x̄, ȳ), becoming one only when |r| = 1 (Pakistan Ch. 14, Theorems 14.4–14.6, pp.203–206).

**6. (Sub lesson 3)** A very strong correlation, say r = 0.98, proves that x causes y.
**Answer:** False — correlation does not imply causation, however strong (Pakistan Ch. 14, p.206).
