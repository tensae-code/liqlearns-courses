# Time Series — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** The seasonal component repeats inside every year, on the calendar.
**Answer:** True — harvests, rains and festivals come round yearly (Pakistan, pp.242–243; Libya, Ch. 3).

**2. (Level 1)** The cyclical component has a fixed length of exactly one year.
**Answer:** False — the cycle is the long business swing with no fixed length; the fixed yearly rhythm is the seasonal component.

**3. (Level 2)** Pakistan's Statistics Class 12 chapter computes seasonal indices.
**Answer:** False — as filed, that chapter measures trend only; no seasonal index is computed and there is no deseasonalisation. The indices in this lesson are Libya's.

**4. (Level 2)** A 4-quarter moving average removes the yearly seasonal wave.
**Answer:** True — the window matches the wave's length, so the seasons average out (Pakistan, pp.250–253).

**5. (Level 3)** Shifting the origin of the coded time changes the trend line itself.
**Answer:** False — shifting the origin only re-codes x; the fitted line is the same line (Pakistan, pp.253–261).

**6. (Level 3)** Extrapolation rests on known values on both sides of the estimate.
**Answer:** False — that is interpolation. Extrapolation extends beyond the end and leans only on the pattern continuing (Iran, pp.63–70, filed "for study").
