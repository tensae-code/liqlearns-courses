# Monte Carlo and Simulation — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — random numbers first, then the generator and the table at work, then Monte Carlo judgement and the model test.

## Level 1 — random numbers and digits
Level 1 questions from the type files. Pass mark: say what random digits are for, read a short run off a table under a fixed rule, and turn digits into coin tosses without changing the rule mid-run.

## Level 2 — the congruential generator and PPS ranges
Level 2 questions from the type files. Pass mark: run xₙ₊₁ = axₙ + b (mod m) for several steps from a seed, spot the cycle returning, and assign ranges in proportion to cumulative probabilities.

## Level 3 — Monte Carlo and testing a model
Level 3 questions from the type files. Pass mark: state the Monte Carlo method, judge how long a run must be before its frequency can be trusted, and test the Mendel model's 0.25/0.5/0.25 against counts — worded as the reading it is filed as.
