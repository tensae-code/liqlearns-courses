# Monte Carlo and Simulation — ordering

Put the items in the order asked. Check each step before you write the answer.

**1. (Level 1)** Order the steps of an honest table simulation: read digits under the rule; fix the digit-to-outcome rule in writing; tally the simulated outcomes; choose the run length.
Answer in order, first step first.
**Answer:** Fix the rule in writing → choose the run length → read digits under the rule → tally the outcomes.

**2. (Level 2)** Order Pakistan's generator run from seed 5 (a = 13, b = 0, m = 16): 9, 5, 1, 13.
Answer in the order the generator produces them.
**Answer:** 1, 13, 9, 5 — then 5 is the seed again and the cycle repeats.

**3. (Level 3)** Order a model test from first to last: compare counts with the model's promises; state the model's probabilities; collect or simulate the counts; judge the model, allowing for wobble.
Answer in order, first step first.
**Answer:** State the probabilities → collect or simulate the counts → compare with the promises → judge, allowing for wobble — the Mendel reading's shape (China, pp.259–260).
