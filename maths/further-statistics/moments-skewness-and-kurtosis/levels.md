# Moments, Skewness and Kurtosis — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — moments first, then skewness in its three forms, then kurtosis and the corrected values.

## Level 1 — moments about the mean, an origin and zero
Level 1 questions from the type files. Pass mark: define the three moment families, state m₁ = 0 and m₂ = variance, convert a moment from an origin to the mean, and apply Sheppard's correction.

## Level 2 — skewness by eye, by Pearson and by Bowley
Level 2 questions from the type files. Pass mark: name a skew from the tail, from the mean–median–mode order and from a box plot; compute Pearson's and Bowley's coefficients; and read a teacher-evidence value as teacher evidence.

## Level 3 — moment skewness and kurtosis
Level 3 questions from the type files. Pass mark: compute √β₁ and b₁ from moments, judge a distribution by β₂ with its Greek name, and catch the book's own slips — Q1 = 40.51 and the (Q3 + Q1) denominator.
