# Moments, Skewness and Kurtosis — ordering

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Moments About the Mean, an Origin and Zero · (Level 2) -> Sub lesson 2 — Skewness by Eye, by Pearson and by Bowley · (Level 3) -> Sub lesson 3 — Moment Skewness and Kurtosis.

Put the items in the order asked. Check each step before you write the answer.

**1. (Sub lesson 1)** Order the moments of 1, 2, 3, 4, 5 about the mean from smallest to largest: m₄ = 6.8, m₂ = 2, m₁ = 0, m₃ = 0.
Answer in order, smallest first.
**Answer:** m₁ = 0 and m₃ = 0 (equal), then m₂ = 2, then m₄ = 6.8 — higher powers feel the far values more.

**2. (Sub lesson 2)** Order the centres of a positively skewed distribution from smallest to largest: mean, median, mode.
Answer in order, smallest first.
**Answer:** Mode, median, mean — the right tail drags the mean farthest right (Kuwait, lesson 4-2; Pakistan, Ch. 4).

**3. (Sub lesson 3)** Order these distributions by β₂ from flattest to sharpest: β₂ = 4.2, β₂ = 1.7, β₂ = 3.
Answer in order, flattest first.
**Answer:** 1.7 (platykurtic), 3 (mesokurtic), 4.2 (leptokurtic).
