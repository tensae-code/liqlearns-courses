# Sampling and Sampling Distributions — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
sampling — populations and data kinds first, then the methods and their errors, then sampling distributions and the Central Limit Theorem.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Populations, Censuses and Kinds of Data
Sub lesson 1 questions from the type files. Pass mark: say what a population, a sample, a frame and a census are, choose census against sample for a given job, and sort data into discrete, continuous, nominal and ordinal.

## Sub lesson 2 — The Sampling Methods, Bad Samples and Errors
Sub lesson 2 questions from the type files. Pass mark: draw simple random, stratified and systematic samples correctly, criticise an unrepresentative survey, separate sampling from non-sampling errors, and compute a bias as E(T) − θ.

## Sub lesson 3 — Sampling Distributions and the Central Limit Theorem
Sub lesson 3 questions from the type files. Pass mark: enumerate a small sampling distribution whole, read its mean and standard error off it, state the Central Limit Theorem, and read population statistics and the randomised-response idea.
