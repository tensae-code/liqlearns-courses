# Random Variables and Distributions — ordering

Put the steps in the right order.

**1. (Level 1)** Building a distribution table: (a) list the variable's values (b) check the probabilities sum to 1 (c) attach each value's probability.
**Answer:** a, c, b — values first, chances attached, then the sum check that Pakistan's p.206 example fails as printed.

**2. (Level 2)** Finding a variance from a table: (a) find E(X) (b) find Σx²p(x) (c) subtract E(X)².
**Answer:** a, b, c — Var(X) = Σx²p(x) − μ² needs the mean first.

**3. (Level 2)** Building a CDF: (a) run the total up to x (b) list the values in order (c) add each value's probability as you pass it.
**Answer:** b, c, a — the staircase climbs in value order, Kuwait Grade 12 Statistics, Ex. 12.

**4. (Level 3)** A normal-table problem: (a) read Φ(z) from the table (b) standardise with z = (x − μ)/σ (c) state the probability asked for.
**Answer:** b, a, c — standardise first; Indonesia TL Revisi, pp.265–273, table pp.281–282.

**5. (Level 3)** Picking a distribution for a story: (a) ask whether anything is taken out and not put back (b) ask whether there is a fixed number of independent trials (c) name the distribution.
**Answer:** b, a, c — trials first separates binomial ground; no replacement then moves the count to hypergeometric.
