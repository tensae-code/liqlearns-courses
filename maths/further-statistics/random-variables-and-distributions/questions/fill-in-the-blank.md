# Random Variables and Distributions — fill in the blank

Fill each blank with the missing word or number.

**1. (Level 1)** The probabilities in a pmf table sum to ______.
**Answer:** 1 — the validity check every distribution table must pass.

**2. (Level 1)** A variable whose values fill an interval, like a height or a time, is called ______.
**Answer:** continuous — Indonesia TL Revisi, p.239.

**3. (Level 2)** E(X) = Σ x · ______.
**Answer:** p(x) — each value weighted by its probability.

**4. (Level 2)** The CDF is F(x) = P(X ______ x).
**Answer:** ≤ — the cumulative probability up to and including x.

**5. (Level 3)** In the binomial formula C(n,x) pˣ qⁿ⁻ˣ, q = 1 − ______.
**Answer:** p — the failure chance, as in Cambodia Grade 12 Advanced, pp.134–159.

**6. (Level 3)** Indonesia's Definisi 4.6 (p.256), taught corrected, writes the binomial coefficient as (n / ______).
**Answer:** x — the lower entry is the number of successes, not p.
