Pick the one right answer.

**1. (Sub lesson 1)** A random variable is:
a) a number chosen by the teacher  b) a number tied to each outcome of a chance experiment  c) any unknown in an equation
**Answer:** b) a number tied to each outcome — X : S → R in Cambodia's PRIVATE booklet notation, pp.123–147.

**2. (Sub lesson 1)** Which of these is a discrete random variable?
a) the height of a grown person  b) the number of heads in 10 tosses  c) the time to run 100 metres
**Answer:** b) the number of heads — counts are discrete; heights and times fill intervals and are continuous (Indonesia TL Revisi, pp.232, 239).

**3. (Sub lesson 1)** A pmf table's probabilities must sum to:
a) 0  b) 1  c) n
**Answer:** b) 1 — a table summing to more, like Pakistan's p.206 example at 1.07 as printed, is not a valid distribution.

**4. (Sub lesson 2)** X takes 1, 2, 3 with probabilities 0.2, 0.5, 0.3. E(X) =
a) 2.0  b) 2.1  c) 6.0
**Answer:** b) 2.1 — 1×0.2 + 2×0.5 + 3×0.3 = 0.2 + 1.0 + 0.9.

**5. (Sub lesson 2)** For X with values 3, 4, 5 and probabilities 0.5, 0.3, 0.2 (Kuwait's CDF example), F(4) =
a) 0.3  b) 0.5  c) 0.8
**Answer:** c) 0.8 — F(4) = P(X ≤ 4) = 0.5 + 0.3.

**6. (Sub lesson 3)** Heads in 8 fair coin tosses follow which distribution, and with what mean?
a) hypergeometric, mean 8  b) binomial, mean 4  c) Poisson, mean 8
**Answer:** b) binomial, mean 4 — fixed independent trials, E(X) = np = 8 × 1/2 (Kuwait Grade 12 Statistics, Ex. 19 shape).

**7. (Sub lesson 3)** Drawing 4 balls from 7 white and 3 red without replacement, the number of reds is:
a) binomial  b) normal  c) hypergeometric
**Answer:** c) hypergeometric — the chances change as balls are taken out (Kuwait Grade 12 Statistics, Ex. 7; Pakistan Ch. 9).

**8. (Sub lesson 3)** For a normal variable with μ = 50 and σ = 10, the z-score of x = 65 is:
a) 1.5  b) 15  c) 0.65
**Answer:** a) 1.5 — z = (65 − 50) / 10.
