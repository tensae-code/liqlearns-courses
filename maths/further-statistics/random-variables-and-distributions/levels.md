# Random Variables and Distributions — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — variables and tables first, then expectation, variance and the CDF, then the named distributions and the normal curve.

## Level 1 — variables, pmf and pdf
Level 1 questions from the type files. Pass mark: say what a random variable is, split discrete from continuous, write a pmf table and check it sums to 1, and say what a pdf's total area means.

## Level 2 — expectation, variance and the CDF
Level 2 questions from the type files. Pass mark: find E(X) and Var(X) from a table, build F(x) = P(X ≤ x) step by step, and use the corrected discrete interval forms.

## Level 3 — the named distributions, z-scores and the empirical rule
Level 3 questions from the type files. Pass mark: choose and work the right named distribution — binomial, hypergeometric, Poisson, uniform, geometric or normal — standardise with a z-score, and apply the empirical rule 68–95–99.7.
