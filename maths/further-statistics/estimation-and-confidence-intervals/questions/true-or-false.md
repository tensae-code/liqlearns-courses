# Estimation and Confidence Intervals — true or false

Say true or false, and why.

**1. (Level 1)** Kuwait's book is right that |x̄ − μ| is called the standard error.
**Answer:** False — taught corrected: |x̄ − μ| is the point estimation ERROR; the standard error is σ/√n (Kuwait, 4-1, p.171, error corrected).

**2. (Level 1)** S² with denominator n is an unbiased estimator of σ².
**Answer:** False — E(S²) = ((n − 1)/n)σ²; Ŝ² with n − 1 is the unbiased one (Pakistan, Ch. 12, pp.74–76).

**3. (Level 2)** A wider sample (bigger n) gives a narrower interval, other things equal.
**Answer:** True — the standard error σ/√n shrinks as n grows.

**4. (Level 2)** The t interval is narrower than the z interval on the same data because t "corrects" z.
**Answer:** False — the t interval is wider: you pay for not knowing σ (Kuwait, 4-1, pp.168–176).

**5. (Level 3)** Iran's Grade 11 book teaches hypothesis testing alongside its estimation.
**Answer:** False — it teaches estimation only; hypothesis testing is never taught there (a Fisher mention in a reading, p.79, only) (Iran, Ch. 4, pp.97–121).

**6. (Level 3)** The German tank estimate N ≈ x_max·(n + 1)/n is always smaller than the largest serial seen.
**Answer:** False — the factor (n + 1)/n is greater than 1, so the estimate stretches ABOVE x_max (China, reading, pp.208–209).
