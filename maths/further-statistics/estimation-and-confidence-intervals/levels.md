# Estimation and Confidence Intervals — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — estimation — point estimates and unbiasedness first, then intervals for one mean, then intervals for proportions and differences and the German tank problem.

## Level 1 — point estimation and unbiasedness
Level 1 questions from the type files. Pass mark: separate estimator, estimate, point and interval estimation; judge unbiasedness by E(T) = θ; and keep the point estimation error |x̄ − μ| apart from the standard error σ/√n.

## Level 2 — confidence intervals for a mean
Level 2 questions from the type files. Pass mark: build a z interval with σ known and a t interval with σ unknown and small n (ν = n − 1), and say correctly what the confidence level means.

## Level 3 — proportions, differences and the German tank problem
Level 3 questions from the type files. Pass mark: build intervals for a proportion and for differences of means and proportions, describe Iran's machinery-free estimation, and run the German tank estimate N ≈ x_max·(n + 1)/n.
