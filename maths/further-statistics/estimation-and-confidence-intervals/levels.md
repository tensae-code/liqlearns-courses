Sub lesson 1 questions from the type files. Pass mark: separate estimator, estimate, point and interval estimation; judge unbiasedness by E(T) = θ; and keep the point estimation error |x̄ − μ| apart from the standard error σ/√n.

## Sub lesson 2 — Confidence Intervals for a Mean
Sub lesson 2 questions from the type files. Pass mark: build a z interval with σ known and a t interval with σ unknown and small n (ν = n − 1), and say correctly what the confidence level means.

## Sub lesson 3 — Proportions, Differences and the German Tank Problem
Sub lesson 3 questions from the type files. Pass mark: build intervals for a proportion and for differences of means and proportions, describe Iran's machinery-free estimation, and run the German tank estimate N ≈ x_max·(n + 1)/n.
