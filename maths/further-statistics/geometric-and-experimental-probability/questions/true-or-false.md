# Geometric and Experimental Probability — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** A geometric probability can be greater than 1 if the region is large.
**Answer:** False — the favourable measure is part of the whole, so the ratio never passes 1.

**2. (Level 1)** Jordan's final test asks for the probability that a random point falls on a named segment.
**Answer:** True — pp.172–174, following the geometric-probability lesson at p.165.

**3. (Level 2)** The region y < 2x fills exactly half the unit square.
**Answer:** False — it fills 3/4; the failing triangle has area 1/4 (Abylkasymova, §32, p.113).

**4. (Level 2)** All four Kazakhstan Grade 9 books teach the statistical definition of probability.
**Answer:** False — Yelemessov's book has none, as filed; the other three carry it.

**5. (Level 3)** After 20 tosses, a coin's heads frequency must equal 1/2 exactly.
**Answer:** False — frequencies stabilise as trials multiply; Soltan's series is still at 0.49 after 100 tosses (p.234).

**6. (Level 3)** Nicaragua's book sets theoretical and frequentist probability side by side as a taught contrast.
**Answer:** True — pp.45–48, with the 500-toss experiment between them.
