# Conditional Probability and Bayes' Theorem — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — reading "given" first, then trees and dependent draws, then total probability and Bayes.

## Level 1 — reading "given"
Level 1 questions from the type files. Pass mark: read P(A|B) in words, work P(A|B) = P(A∩B) / P(B) from counts or from given probabilities, and tell a certain, impossible and ordinary given event apart.

## Level 2 — independence, dependence and trees
Level 2 questions from the type files. Pass mark: test independence with P(A∩B) = P(A)·P(B), and draw and use a tree for two draws without replacement, with the second branches correctly changed.

## Level 3 — total probability and Bayes
Level 3 questions from the type files. Pass mark: split a probability by cases with the total-probability formula and turn a conditional probability around with Bayes' theorem, showing every step.
