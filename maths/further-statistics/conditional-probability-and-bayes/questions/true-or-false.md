# Conditional Probability and Bayes' Theorem — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Reading "Given" · (Level 2) -> Sub lesson 2 — Independence, Dependence and Trees · (Level 3) -> Sub lesson 3 — Total Probability and Bayes.

Say true or false, and why.

**1. (Sub lesson 1)** P(A|B) and P(B|A) are always equal.
**Answer:** False — Kuwait's p.202 pair gives 2/3 one way and 1/3 the other.

**2. (Sub lesson 1)** If B is certain, then P(A|B) = P(A).
**Answer:** True — given the whole sample space, the world has not shrunk at all.

**3. (Sub lesson 2)** Drawing with replacement makes the draws dependent.
**Answer:** False — replacement restores the bag, so the draws are independent.

**4. (Sub lesson 2)** Sierra Leone's SSS 3 book writes the symbol P(A|B).
**Answer:** False — as filed, that book teaches the idea on tree diagrams only, with no P(A|B) notation.

**5. (Sub lesson 3)** Cambodia's Probability booklet is a MoEYS government book.
**Answer:** False — it is a PRIVATE Khem Putthi booklet, labelled private wherever cited.

**6. (Sub lesson 3)** Bayes' theorem needs the total probability of the evidence when the evidence has several roads in.
**Answer:** True — P(B) in the denominator is built by splitting B over its cases, as in the PRIVATE booklet, pp.85–94.
