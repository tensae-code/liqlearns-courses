# Index Numbers — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the simple indices first, then the weighted indices, then the CPI, purchasing power and inflation.

## Level 1 — simple indices, relatives and chain indices
Level 1 questions from the type files. Pass mark: say what an index number measures, build the simple aggregative index and the average of relatives, and work link relatives into a chain index — with Pakistan's potato link relatives at their corrected values 111.1 and 100.0.
