# Index Numbers — ordering

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Simple Indices, Relatives and Chain Indices · (Level 2) -> Sub lesson 2 — The Weighted Indices · (Level 3) -> Sub lesson 3 — CPI, Purchasing Power, Changing the Base and Inflation.

Put the steps in the right order.

**1. (Sub lesson 1)** Constructing an index: (a) choose the base year (b) state the purpose (c) choose the items (d) choose the weights and the average.
**Answer:** b, c, a, d — purpose first, then items, base, and the weighing (Pakistan, Ch. 5).

**2. (Sub lesson 1)** A chain index from link relatives: (a) compute each year's link relative (b) multiply successive links as decimals (c) read the product against the fixed base as the chain index.
**Answer:** a, b, c — links first, then the chain (Pakistan, Ch. 5).

**3. (Sub lesson 2)** Fisher's index: (a) compute Laspeyres (b) multiply L × P (c) compute Paasche (d) take the square root.
**Answer:** a, c, b, d — F = √(L × P) needs both parents first (Pakistan, Ch. 5; corrected Example 5.7: √(118.8 × 110.4) ≈ 114.5).

**4. (Sub lesson 3)** The family budget CPI: (a) weight each group's index by its spending share W (b) compute each group's index I (c) form ΣIW/ΣW.
**Answer:** b, a, c — group indices first, then the weighted mean (Pakistan, Ch. 5).

**5. (Sub lesson 3)** Changing the base: (a) pick the new base year (b) divide every index by that year's index (c) multiply by 100.
**Answer:** a, b, c — Libya, Ch. 2, pp.33–58.
