# Index Numbers — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** An index of 100 means values are unchanged from the base period.
**Answer:** True — 100 is the base itself (Pakistan, Ch. 5).

**2. (Level 1)** Pakistan's printed potato link relative for 1981, 112.5, is correct.
**Answer:** False — it was copied from the onion column; the correct value is 111.1 (30/27), taught corrected (p.140).

**3. (Level 2)** Laspeyres and Paasche always give the same value.
**Answer:** False — they weigh with different baskets, q₀ against qₙ; in Pakistan's corrected Example 5.7 they are 118.8 and 110.4.

**4. (Level 2)** In Example 5.7 the misprinted p₀q₀ cell for item B changes the Laspeyres index.
**Answer:** False — the cell prints 105 for 135, but the column total 425 is correct, so Laspeyres 118.8 is unaffected (p.143, corrected as filed).

**5. (Level 3)** If the CPI doubles, the purchasing power of money doubles.
**Answer:** False — purchasing power = 1/CPI, so it halves (Pakistan, Ch. 5).

**6. (Level 3)** Iran's red-meat prices rising from 28 to 32 thousand tomans is an inflation of exactly 14%.
**Answer:** False — 4/28 × 100 = 14.2857…% ≈ 14.3%; the book prints a rounded value as exact, taught corrected (Iran, Statistics and Probability, pp.89–90).
