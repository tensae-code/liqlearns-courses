# Association of Attributes — short answer

Answer in a word or a short line.

**1. (Level 1)** With two attributes there are how many ultimate class frequencies, and what are they?
**Answer:** Four — (AB), (Aβ), (αB), (αβ); in general 2^k ultimate frequencies for k attributes (Pakistan Ch. 15, pp.215–216).

**2. (Level 1)** A table reports (A) = 50 but its boxes give (AB) + (Aβ) = 42. What is wrong?
**Answer:** The table is inconsistent — a class frequency must equal the sum of the ultimate boxes inside it (pp.215–216).

**3. (Level 2)** Given (A) = 60, (B) = 50, n = 100: what (AB) would independence require?
**Answer:** 30 — (A)(B)/n = 60 × 50/100 (pp.217–219).

**4. (Level 2)** For (AB) = 40, (Aβ) = 20, (αB) = 10, (αβ) = 30, compute Yule's Q.
**Answer:** Q = (1200 − 200)/(1200 + 200) = 1000/1400 ≈ 0.71 — strong positive association (pp.219–220).

**5. (Level 3)** For the same table, the expected frequencies are 30, 30, 20, 20. Compute χ².
**Answer:** χ² = 100/30 + 100/30 + 100/20 + 100/20 ≈ 16.67 on df = 1 (pp.224–232).

**6. (Level 3)** State Yates' correction exactly.
**Answer:** In a 2×2 table, replace each |o − e| by |o − e| − 0.5 before squaring in χ² = ΣΣ(o − e)²/e (pp.224–232).

**7. (Level 3)** With χ² ≈ 16.67 and n = 100, compute the contingency coefficient C.
**Answer:** C = √(16.67/116.67) ≈ 0.378 (p.226).
