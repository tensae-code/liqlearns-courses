# Association of Attributes — true or false

Say true or false, and why.

**1. (Level 1)** Every person in a 2×2 attribute table sits in exactly one ultimate box.
**Answer:** True — the four ultimate frequencies partition the population (Pakistan Ch. 15, pp.215–216).

**2. (Level 1)** (A) and (AB) are the same count whenever B is common.
**Answer:** False — (AB) counts only the part of (A) that also has B; it equals (A) only if every A-holder has B (pp.215–216).

**3. (Level 2)** Q = −1 means there is no association between the attributes.
**Answer:** False — Q = −1 is complete negative association; Q = 0 is independence (pp.219–220).

**4. (Level 2)** If (AB) = (A)(B)/n exactly, the attributes are independent, whatever the other boxes do.
**Answer:** True — that equality is the independence criterion; the other boxes then match their independence values too (pp.217–219).

**5. (Level 3)** Yates' correction makes χ² larger, so the test rejects more easily.
**Answer:** False — subtracting 0.5 from each |o − e| makes χ² smaller and the test more careful, not less (pp.224–232).

**6. (Level 3)** Pakistan's Statistics Class 12 teaches a chi-square goodness-of-fit test in Ch. 15.
**Answer:** False — its χ² is a test of independence only; the goodness-of-fit test is recorded as absent from the book, and this lesson claims none.
