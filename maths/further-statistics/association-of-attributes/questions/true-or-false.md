# Association of Attributes — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Attributes and the 2×2 Table · (Level 2) -> Sub lesson 2 — Independence and Yule's Q · (Level 3) -> Sub lesson 3 — The Chi-Square Test and the Contingency Coefficient.

Say true or false, and why.

**1. (Sub lesson 1)** Every person in a 2×2 attribute table sits in exactly one ultimate box.
**Answer:** True — the four ultimate frequencies partition the population (Pakistan Ch. 15, pp.215–216).

**2. (Sub lesson 1)** (A) and (AB) are the same count whenever B is common.
**Answer:** False — (AB) counts only the part of (A) that also has B; it equals (A) only if every A-holder has B (pp.215–216).

**3. (Sub lesson 2)** Q = −1 means there is no association between the attributes.
**Answer:** False — Q = −1 is complete negative association; Q = 0 is independence (pp.219–220).

**4. (Sub lesson 2)** If (AB) = (A)(B)/n exactly, the attributes are independent, whatever the other boxes do.
**Answer:** True — that equality is the independence criterion; the other boxes then match their independence values too (pp.217–219).

**5. (Sub lesson 3)** Yates' correction makes χ² larger, so the test rejects more easily.
**Answer:** False — subtracting 0.5 from each |o − e| makes χ² smaller and the test more careful, not less (pp.224–232).

**6. (Sub lesson 3)** Pakistan's Statistics Class 12 teaches a chi-square goodness-of-fit test in Ch. 15.
**Answer:** False — its χ² is a test of independence only; the goodness-of-fit test is recorded as absent from the book, and this lesson claims none.
