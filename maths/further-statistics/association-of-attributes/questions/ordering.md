# Association of Attributes — ordering

Put the steps in the right order.

**1. (Level 1)** Building an attribute table: (a) total the rows and columns (b) count each person into one ultimate box (c) choose the two attributes and their absences.
**Answer:** c, b, a — attributes first, counting second, margins last (Pakistan Ch. 15, pp.215–216).

**2. (Level 2)** Judging association in a 2×2: (a) compute Yule's Q (b) compare (AB) with (A)(B)/n (c) name the association positive, negative or none.
**Answer:** b, c, a — the criterion first, its name second, its measure last (pp.217–220).

**3. (Level 3)** A chi-square test of independence: (a) compute the expected frequencies (b) pool any row or column whose expectations fall below 5 (c) form χ² = ΣΣ(o − e)²/e and compare it with the table at df = (r − 1)(c − 1).
**Answer:** a, b, c — expectations, the ≥ 5 guard, then the statistic (pp.224–232).

**4. (Level 3)** A 2×2 test with Yates' correction: (a) subtract 0.5 from each |o − e| (b) build the expected table (c) square and divide by e, then add.
**Answer:** b, a, c — expected values first, the correction applied to their differences, then the sum (pp.224–232).
