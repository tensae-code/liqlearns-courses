# Association of Attributes — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — first laying qualities into a table, then judging independence and measuring association with Q, then testing with chi-square and summarising with the contingency coefficient.

## Level 1 — attributes and the 2×2 table
Level 1 questions from the type files. Pass mark: sort by two attributes in the (A)/(α), (B)/(β) notation, build the 2×2 table with its totals, tell class frequencies from ultimate frequencies, and check a table for consistency.

## Level 2 — independence and Yule's Q
Level 2 questions from the type files. Pass mark: apply the independence criterion (AB) = (A)(B)/n exactly, call an association positive, negative or complete, and compute and interpret Yule's Q, including its end values ±1 and 0.

## Level 3 — the chi-square test and the contingency coefficient
Level 3 questions from the type files. Pass mark: build expected frequencies for an r×c table, run χ² = ΣΣ(o − e)²/e with df = (r − 1)(c − 1), apply the ≥ 5 rule with pooling and Yates' correction in a 2×2, compute C = √(χ²/(n + χ²)), and state that the source book teaches no goodness-of-fit test.
