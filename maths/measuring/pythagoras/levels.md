# Pythagoras — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
the right-triangle rule — set by the pattern across the countries' books: the rule itself first, then finding the hypotenuse, then finding a shorter side and checking with the converse.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Pythagoras — the Rule
Sub lesson 1 questions from the type files. Pass mark: say a² + b² = c²
with c the hypotenuse; name the hypotenuse as the side opposite
the right angle and the longest side; and know 3² + 4² = 5².

## Sub lesson 2 — Pythagoras — Finding the Hypotenuse
Sub lesson 2 questions from the type files. Pass mark: find a hypotenuse
with c = √(a² + b²), square first, add, then take the square root
— and use it for the diagonal of a rectangle and for a ladder
against a wall.

## Sub lesson 3 — Pythagoras — Finding a Shorter Side and the Converse
Sub lesson 3 questions from the type files. Pass mark: find a shorter
side with a = √(c² − b²); check whether a triangle is right-angled
by testing whether the squares add up; and give answers to one
decimal place where the books do.
