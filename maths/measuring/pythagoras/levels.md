# Pythagoras — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the right-triangle rule — set by the
pattern across the countries' books: the rule itself first, then
finding the hypotenuse, then finding a shorter side and checking
with the converse.

## Level 1 — the rule and the hypotenuse
Level 1 questions from the type files. Pass mark: say a² + b² = c²
with c the hypotenuse; name the hypotenuse as the side opposite
the right angle and the longest side; and know 3² + 4² = 5².

## Level 2 — finding the hypotenuse
Level 2 questions from the type files. Pass mark: find a hypotenuse
with c = √(a² + b²), square first, add, then take the square root
— and use it for the diagonal of a rectangle and for a ladder
against a wall.

## Level 3 — finding a shorter side and the converse
Level 3 questions from the type files. Pass mark: find a shorter
side with a = √(c² − b²); check whether a triangle is right-angled
by testing whether the squares add up; and give answers to one
decimal place where the books do.
