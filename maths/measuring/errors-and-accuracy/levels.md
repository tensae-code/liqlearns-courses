# Errors and Accuracy — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — errors and accuracy — absolute error
first, then relative and percentage error, then choosing a degree
of accuracy, the order the books teach it in.

## Level 1 — absolute error
Level 1 questions from the type files. Pass mark: find the absolute error as the size of the gap between a measured value and the true value, and state the biggest possible error of a value rounded to a given place.

## Level 2 — relative and percentage error
Level 2 questions from the type files. Pass mark: find the relative error against the true value, turn it into a percentage error, and compare two measures by their percentage errors.

## Level 3 — degree of accuracy
Level 3 questions from the type files. Pass mark: choose an appropriate degree of accuracy for a job, round to it, and bound the error the rounding can hide.
