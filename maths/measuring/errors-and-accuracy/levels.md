# Errors and Accuracy — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
errors and accuracy — absolute error first, then relative and percentage error, then choosing a degree of accuracy, the order the books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Errors and Accuracy — Absolute Error
Sub lesson 1 questions from the type files. Pass mark: find the absolute error as the size of the gap between a measured value and the true value, and state the biggest possible error of a value rounded to a given place.

## Sub lesson 2 — Errors and Accuracy — Relative and Percentage Error
Sub lesson 2 questions from the type files. Pass mark: find the relative error against the true value, turn it into a percentage error, and compare two measures by their percentage errors.

## Sub lesson 3 — Errors and Accuracy — Degree of Accuracy
Sub lesson 3 questions from the type files. Pass mark: choose an appropriate degree of accuracy for a job, round to it, and bound the error the rounding can hide.
