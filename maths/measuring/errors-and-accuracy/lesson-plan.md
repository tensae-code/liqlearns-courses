# Lesson plan — Errors and Accuracy

**Course:** Maths · **Unit:** Unit 8 — Measuring, Area and Volume · **Lesson:** Errors and Accuracy
**Place in the curriculum:** Level 68 of 136, in Unit 8 — Measuring, Area and Volume (maths/CURRICULUM.md).
**The one thing this lesson teaches:** every measurement is approximate — how far off it can be (absolute error), how big that miss is next to the true value (relative and percentage error), and how to choose a sensible degree of accuracy.
**This lesson's own level:** it stands on Measuring (measuring in units) and on rounding and percentages. It needs nothing else.

## Sub lessons
The parts of this lesson, in order — the list the learner sees
from the start, locked ahead, each opening when the one before

(ruled 2026-11-08)"):

1. **Errors and Accuracy — Absolute Error** — the absolute error as the size of the gap between a measured value and the true value, and the biggest possible error of a value rounded to a given place. (Was depth Level 1.)
2. **Errors and Accuracy — Relative and Percentage Error** — the relative error against the true value, turned into a percentage error, and comparing two measures by their percentage errors. (Was depth Level 2.)
3. **Errors and Accuracy — Degree of Accuracy** — choosing an appropriate degree of accuracy for a job, rounding to it, and bounding the error the rounding can hide. (Was depth Level 3.)

## Before this lesson
- Recommended first: Measuring (Stage 8) — a measurement must exist before its error can be talked about. Recommended, never forced.
- Recommended first: rounding and percentages — percentage error is a percentage, and degree of accuracy is rounding with a reason. Recommended, never forced.

## What the learner can do when it ends
1. Find the absolute error of a measurement: the size of the gap between the measured value and the true value (Kazakhstan, Shynybekov Algebra 7, §1.3, p.42; Yelemessov Algebra 7, Ch. 1, p.66).
2. Find the relative error — absolute error divided by the true value — and say why the same gap matters more on a small measure than on a big one (Kazakhstan, Yelemessov Algebra 7, Ch. 1, p.66).
3. Find the percentage error when rounded values are used (Sierra Leone, SSS 2 Handbook, L7, p.19).
4. Choose an appropriate degree of accuracy for given, possibly rounded, data — and say what the biggest possible error of a rounded value is (Sierra Leone, SSS 2 Handbook, L8, p.22).

## What you need
Paper and a pencil. A ruler. Something to weigh or a packet with its mass printed on it.

## The run of the lesson (in order)
1. **Do it first** — the learner measures a book with a ruler, reads it to the nearest millimetre, and asks how wrong that reading could be (lesson/lesson.md).
2. **The explanation** — absolute error; relative error; percentage error; degree of accuracy (lesson/lesson.md).
   - ADD IMAGE at the absolute-error part: a picture of a ruler reading 24.3 cm against a true length marked 24.5 cm, the small gap between them shaded → the student points to the gap and says its size.
   - ADD GIF at the relative-error part: a picture of the same 2 mm gap shown first on a pencil, then on a road, the gap shrinking in importance as the thing grows → the student says on which one the gap matters more, and why.
   - ADD IMAGE at the degree-of-accuracy part: a picture of one length rounded three ways — to the nearest 10 cm, the nearest cm, and the nearest mm — the student says which rounding fits a room, a book, and a fingernail.
3. **Say it to your companion** — give your companion a measured value and a true value; they find the absolute, relative and percentage error (lesson/lesson.md).
   - ADD VIDEO: the script in video-script.md, filmed — errors in the super-simple voice (made later, when videos are made).
4. **Questions** — from questions/: multiple-choice, short-answer, fill-in-the-blank, true-or-false, matching — served at the learner's level and teaching-mix (levels.md).
5. **Hands-on** — hands-on.md.
6. **Do It Yourself** — measure three things, state each measure's degree of accuracy and its biggest possible error (lesson/lesson.md).

## If the learner is stuck
- Gives a negative error → an error is a size of a gap; it is never negative. Take the gap, not the direction.
- Divides by the measured value instead of the true value → relative error is measured against the true value: the true value is the standard the measure is judged by.
- Thinks a rounded value is exact → a value rounded to the nearest cm can be up to half a cm out. The last place kept sets the biggest possible error: half of that place.
- This lesson's next door: Temperature and Traditional Measures (same stage) — measuring heat, and the measures people used before standard units.
