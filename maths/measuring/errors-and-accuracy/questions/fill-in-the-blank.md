# Errors and Accuracy — fill in the blank

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Errors and Accuracy — Absolute Error · (Level 2) -> Sub lesson 2 — Errors and Accuracy — Relative and Percentage Error · (Level 3) -> Sub lesson 3 — Errors and Accuracy — Degree of Accuracy.

Fill in the missing word or number.

**1. (Sub lesson 1)** The ______ error is the size of the gap between the measured value and the true value.
**Answer:** absolute — it is a size, so it is never negative.

**2. (Sub lesson 1)** A value rounded to the nearest cm can be out by at most ______ cm.
**Answer:** 0.5 — half of the last place kept.

**3. (Sub lesson 2)** Relative error = absolute error ÷ ______.
**Answer:** the true value — the true value is the standard the measure is judged by.

**4. (Sub lesson 2)** Percentage error = relative error × ______.
**Answer:** 100 — turning the relative error into a percentage.
