Match each item on the left to its partner on the right.

**1. (Sub lesson 1)** Match each pair to its absolute error: (a) true 50, measured 47 (b) true 90, measured 92 (c) true 12, measured 12 — 3, 2, 0
**Answer:** a) 3, b) 2, c) 0 — the size of each gap.

**2. (Sub lesson 2)** Match each case to its percentage error: (a) error 2 on true 100 (b) error 2 on true 20 (c) error 2 on true 200 — 2%, 10%, 1%
**Answer:** a) 2%, b) 10%, c) 1% — the same gap, divided by three different true values.

**3. (Sub lesson 3)** Match each job to a sensible degree of accuracy: (a) a road between towns (b) a book's width (c) a crowd at a match — nearest tenth of a km, nearest mm, nearest hundred
**Answer:** a) nearest tenth of a km, b) nearest mm, c) nearest hundred — the degree fits the job and how the number is obtained.
