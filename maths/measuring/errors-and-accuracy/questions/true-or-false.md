# Errors and Accuracy — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** An absolute error can be negative.
**Answer:** False — an error is the size of a gap; sizes are never negative.

**2. (Level 1)** A measured value is always exactly equal to the true value.
**Answer:** False — every measurement carries a small error; that is the opening fact of the lesson.

**3. (Level 2)** The same absolute error gives a bigger percentage error on a smaller true value.
**Answer:** True — the gap is divided by the true value, so a smaller true value makes the fraction bigger.

**4. (Level 3)** Giving a road's length to the nearest millimetre is the most accurate and therefore the best way to report it.
**Answer:** False — the degree of accuracy must be appropriate to the job and to how the number was obtained; false precision pretends to knowledge nobody has.
