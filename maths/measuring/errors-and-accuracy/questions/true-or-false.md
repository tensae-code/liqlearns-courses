# Errors and Accuracy — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Errors and Accuracy — Absolute Error · (Level 2) -> Sub lesson 2 — Errors and Accuracy — Relative and Percentage Error · (Level 3) -> Sub lesson 3 — Errors and Accuracy — Degree of Accuracy.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** An absolute error can be negative.
**Answer:** False — an error is the size of a gap; sizes are never negative.

**2. (Sub lesson 1)** A measured value is always exactly equal to the true value.
**Answer:** False — every measurement carries a small error; that is the opening fact of the lesson.

**3. (Sub lesson 2)** The same absolute error gives a bigger percentage error on a smaller true value.
**Answer:** True — the gap is divided by the true value, so a smaller true value makes the fraction bigger.

**4. (Sub lesson 3)** Giving a road's length to the nearest millimetre is the most accurate and therefore the best way to report it.
**Answer:** False — the degree of accuracy must be appropriate to the job and to how the number was obtained; false precision pretends to knowledge nobody has.
