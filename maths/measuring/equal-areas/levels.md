# Equal Areas — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
equal areas — the order Yemen's Grade 8 book teaches it in: equivalence by counted squares first, then triangles, then parallelograms.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Equal Areas — What Equivalent Means
Sub lesson 1 questions from the type files. Pass mark: say that two
shapes are equivalent when their areas are equal, test it by
counting unit squares on a grid, and say why equivalent does not
mean congruent.

## Sub lesson 2 — Equal Areas — Equivalent Triangles
Sub lesson 2 questions from the type files. Pass mark: show that
triangles on the same base with the third vertex on a line
parallel to the base have equal area (same base, same height),
and find a second base–height pair giving the same area.

## Sub lesson 3 — Equal Areas — Equivalent Parallelograms
Sub lesson 3 questions from the type files. Pass mark: show that
parallelograms sharing a base with the top side on a line
parallel to the base have equal area, whatever their slant, and
compare mixed shapes by area.
