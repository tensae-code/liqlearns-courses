# Equal Areas — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — equal areas — the order Yemen's
Grade 8 book teaches it in: equivalence by counted squares first,
then triangles, then parallelograms.

## Level 1 — equivalent means equal area
Level 1 questions from the type files. Pass mark: say that two
shapes are equivalent when their areas are equal, test it by
counting unit squares on a grid, and say why equivalent does not
mean congruent.

## Level 2 — equivalent triangles
Level 2 questions from the type files. Pass mark: show that
triangles on the same base with the third vertex on a line
parallel to the base have equal area (same base, same height),
and find a second base–height pair giving the same area.

## Level 3 — equivalent parallelograms
Level 3 questions from the type files. Pass mark: show that
parallelograms sharing a base with the top side on a line
parallel to the base have equal area, whatever their slant, and
compare mixed shapes by area.
