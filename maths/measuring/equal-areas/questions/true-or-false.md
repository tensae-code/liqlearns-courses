# Equal Areas — true or false

Say true or false, and why.

**1. (Level 1)** Equivalent shapes must have the same perimeter.
**Answer:** False — equivalence is about area only; Yemen's grid trio has equal areas with different outlines (G8 Pt2, 7-7, p.87).

**2. (Level 2)** If a triangle's top vertex slides along a line parallel to its base, the triangle's area stays the same.
**Answer:** True — base and height are both unchanged (G8 Pt2, 7-7, p.87).

**3. (Level 2)** Two equivalent triangles must be congruent.
**Answer:** False — base 10 cm × height 4 cm and base 8 cm × height 5 cm both give 20 cm² with different sides; equivalence is not congruence.

**4. (Level 3)** A parallelogram that leans further has a larger area because its slant side is longer.
**Answer:** False — area is base × perpendicular height; the slant side is not the height (G8 Pt2, 7-8, p.94).
