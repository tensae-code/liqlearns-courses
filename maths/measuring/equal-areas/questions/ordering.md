# Equal Areas — ordering

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Equal Areas — What Equivalent Means · (Level 2) -> Sub lesson 2 — Equal Areas — Equivalent Triangles · (Level 3) -> Sub lesson 3 — Equal Areas — Equivalent Parallelograms.

Put each list in the right order.

**1. (Sub lesson 1)** Order these shapes by area, smallest first: rectangle 5 × 2; triangle base 5, height 4; L-shape covering 9 unit squares.
**Answer:** L-shape (9), rectangle (10), triangle (10) — the rectangle and triangle tie at 10 and are equivalent to each other (Yemen, G8 Pt2, 7-7, p.87).

**2. (Sub lesson 2)** Order these triangles by area, smallest first: (a) base 8, height 5  (b) base 8, height 3  (c) base 12, height 5.
**Answer:** (b) 12 cm², (a) 20 cm², (c) 30 cm² — on one base the area follows the height (G8 Pt2, 7-7, p.87).

**3. (Sub lesson 3)** Order these parallelograms by area, smallest first: (a) base 6, height 4  (b) base 6, height 4, leaning twice as far as (a)  (c) base 5, height 4.
**Answer:** (c) 20 cm², then (a) and (b) tied at 24 cm² — (a) and (b) are equivalent; the lean adds nothing (Yemen, G8 Pt2, 7-8, p.94).
