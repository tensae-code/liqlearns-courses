# Estimating Areas — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
estimating an irregular area — the order South Sudan's Secondary 4 book teaches it in: counting squares first, then the mid-ordinate rule, then the trapezium rule.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Estimating Areas — Counting Squares
Sub lesson 1 questions from the type files. Pass mark: estimate an
irregular area on grid paper by counting whole squares and
joining part squares into whole ones, and give the answer in
square units as an estimate.

## Sub lesson 2 — Estimating Areas — the Mid-Ordinate Rule
Sub lesson 2 questions from the type files. Pass mark: split a width
into equal strips, measure each strip's mid-ordinate, and apply
area ≈ strip width × (sum of the mid-ordinates).

## Sub lesson 3 — Estimating Areas — the Trapezium Rule
Sub lesson 3 questions from the type files. Pass mark: apply
area ≈ (strip width ÷ 2) × [first + last + 2 × (middle
ordinates)], and compare the rules' answers, saying why they
differ and why narrower strips estimate better.
