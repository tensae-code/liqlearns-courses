# Estimating Areas — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — estimating an irregular area — the
order South Sudan's Secondary 4 book teaches it in: counting
squares first, then the mid-ordinate rule, then the trapezium
rule.

## Level 1 — counting squares
Level 1 questions from the type files. Pass mark: estimate an
irregular area on grid paper by counting whole squares and
joining part squares into whole ones, and give the answer in
square units as an estimate.

## Level 2 — the mid-ordinate rule
Level 2 questions from the type files. Pass mark: split a width
into equal strips, measure each strip's mid-ordinate, and apply
area ≈ strip width × (sum of the mid-ordinates).

## Level 3 — the trapezium rule
Level 3 questions from the type files. Pass mark: apply
area ≈ (strip width ÷ 2) × [first + last + 2 × (middle
ordinates)], and compare the rules' answers, saying why they
differ and why narrower strips estimate better.
