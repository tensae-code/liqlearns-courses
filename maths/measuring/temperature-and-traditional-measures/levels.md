# Temperature and Traditional Measures — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — temperature first, then converting
between the scales, then the traditional measures, the order the
books teach it in.

## Level 1 — temperature and the thermometer
Level 1 questions from the type files. Pass mark: read a thermometer in degrees Celsius, place the fixed points (0 °C ice, 100 °C boiling water, body temperature about 37 °C), and measure a length in body units.

## Level 2 — converting Celsius and Fahrenheit
Level 2 questions from the type files. Pass mark: convert both ways with the correct formulas, including the 32 offset, and check a conversion by converting back.

## Level 3 — the traditional measures
Level 3 questions from the type files. Pass mark: work in Nepal's land units, use the values Mauritania's book gives for the cubit, raṭl and ṣāʿ, and name the traditional units of Nicaragua, Kazakhstan and Laos.
