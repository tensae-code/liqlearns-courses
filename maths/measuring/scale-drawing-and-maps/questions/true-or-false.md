# Scale Drawing and Maps — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Scale Drawing and Maps — What a Scale Is · (Level 2) -> Sub lesson 2 — Scale Drawing and Maps — the Two Directions and Bar Scales · (Level 3) -> Sub lesson 3 — Scale Drawing and Maps — Drawing to Scale, Compass Points and Coordinates.

Say true or false, and why.

**1. (Sub lesson 1)** In the scale 1:100, the 1 is the real length and the 100 is the drawing length.
**Answer:** False — the first number is always the drawing, the second the real thing (Laos, Grade 6, L21).

**2. (Sub lesson 1)** A scale of 1:500,000 shrinks the real thing more than a scale of 1:100.
**Answer:** True — each map centimetre must stand for far more real centimetres.

**3. (Sub lesson 2)** If a map is photocopied bigger, a printed ratio scale stays correct but a bar scale must be redrawn.
**Answer:** False — it is the other way: the bar grows with the map and stays true; the printed ratio no longer matches.

**4. (Sub lesson 2)** Jordan's Grade 7 book teaches scale drawing inside its congruence-and-similarity unit.
**Answer:** True — Unit 6, L2, printed p.56; a scale drawing is similar to the real shape.

**5. (Sub lesson 3)** Nepal's Grade 7 compass points are three-figure bearings.
**Answer:** False — Nepal teaches the eight compass points (N, NE, E, …); three-figure bearings are a different lesson (Nepal, Grade 7, Unit 10).

**6. (Sub lesson 2)** In Indonesia's Grade 7 book, scale is taught on its own, away from ratio.
**Answer:** False — scale factor and map/plan scale are taught inside the Ratio chapter, as applications of ratio (Indonesia, Grade 7, Ch. 3, pp.83–122).
