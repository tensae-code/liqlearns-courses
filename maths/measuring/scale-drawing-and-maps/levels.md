# Scale Drawing and Maps — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
scale — the order the books teach it in: what a scale is first, then the two directions of conversion with bar scales, then drawing to scale with compass points and geographic coordinates.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Scale Drawing and Maps — What a Scale Is
Sub lesson 1 questions from the type files. Pass mark: say scale =
drawing length ÷ real length in the same unit, and read what
1:n means on simple scales like 1:100 and 1:10.

## Sub lesson 2 — Scale Drawing and Maps — the Two Directions and Bar Scales
Sub lesson 2 questions from the type files. Pass mark: turn a real
length into a drawing length and a drawing length back into a
real length, and read a bar scale (for example 1 cm = 5 km is
1:500,000).

## Sub lesson 3 — Scale Drawing and Maps — Drawing to Scale, Compass Points and Coordinates
Sub lesson 3 questions from the type files. Pass mark: plan a drawing
at a chosen scale, enlarge and reduce by a scale, use the eight
compass points on a map, and read a place's latitude and
longitude.
