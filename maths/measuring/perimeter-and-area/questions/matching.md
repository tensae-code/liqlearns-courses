# Perimeter and Area — matching

Match each shape to its formula.

**Set 1 (Level 1) — perimeter**
1. square, side l — **P = 4l**
2. rectangle, l by w — **P = 2l + 2w**
3. triangle, sides a, b, c — **P = a + b + c**
4. any polygon — **P = sum of all its sides**
5. perimeter unit — **cm (a length)**

**Set 2 (Level 2) — area**
1. rectangle — **A = l × w**
2. square, side l — **A = l²**
3. triangle — **A = ½ × base × height**
4. area unit — **cm² (square units)**
5. triangle height — **perpendicular to the base**

**Set 3 (Level 3) — more areas**
1. parallelogram — **A = base × height**
2. trapezium — **A = ½(a + b)h**
3. composite shape — **split it, find each piece, add them**
4. same area, different perimeter — **6 by 4 and 24 by 1 both hold 24 cm²**
5. square and perimeter — **a square holds the most area for its perimeter**
