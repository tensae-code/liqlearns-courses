# Perimeter and Area — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — perimeter and area — set by the
pattern across the countries' books: perimeter first, then the
rectangle and square areas, then the triangle, parallelogram and
trapezium areas with composite shapes.

## Level 1 — perimeter
Level 1 questions from the type files. Pass mark: find a perimeter
by adding the sides, and by the short cuts for a square (4l), a
rectangle (2l + 2w) and a triangle (a + b + c), in the right unit
(cm, never cm²).

## Level 2 — area of rectangles, squares and triangles
Level 2 questions from the type files. Pass mark: find areas with
A = l × w, A = l² and A = ½bh, with the height perpendicular to
the base, and find a missing side from a known area.

## Level 3 — parallelograms, trapeziums and composites
Level 3 questions from the type files. Pass mark: find areas with
A = base × height and A = ½(a + b)h; split a composite shape and
add its pieces; and say why the same area can have different
perimeters.
