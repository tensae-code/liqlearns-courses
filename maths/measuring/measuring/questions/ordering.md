# Measuring — ordering

Put each set in order, smallest first. (This question type exists
for this lesson because units ARE an order — the ladder.)

**1. (Level 1)** Order by size: metre · millimetre · kilometre · centimetre.
**Answer:** millimetre, centimetre, metre, kilometre.

**2. (Level 1)** Order these lengths, smallest first: 2 m · 150 cm · 2,500 mm.
**Answer:** 150 cm (1.5 m), 2 m (200 cm), 2,500 mm (2.5 m).

**3. (Level 2)** Order these masses, smallest first: 500 g · 2 kg · 1,500 g.
**Answer:** 500 g, 1,500 g, 2 kg (2,000 g).

**4. (Level 3)** Order these capacities, smallest first: 2 L · 750 mL · 1,500 mL.
**Answer:** 750 mL, 1,500 mL, 2 L (2,000 mL).

**5. (Level 3)** Order these by how much they hold: teaspoon · jug · water tank · cup.
**Answer:** teaspoon, cup, jug, water tank.
