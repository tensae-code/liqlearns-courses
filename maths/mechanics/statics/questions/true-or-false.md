# Statics: forces in balance — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** A force of "10 N" with no direction stated is fully described.
**Answer:** False — a force is a vector; it needs a size and a direction (Egypt, Applied Grade 11 Term 1, lesson 1-1, printed p.12).

**2. (Level 1)** The components F cos θ and F sin θ of a force F rebuild it: √( (F cos θ)² + (F sin θ)² ) = F.
**Answer:** True — cos² θ + sin² θ = 1, so the pair has size F (lesson 1-2, printed p.20).

**3. (Level 2)** Friction always equals μR.
**Answer:** False — friction equals μR only at limiting equilibrium; below the limit it is only as big as it needs to be (lesson 1-5, printed p.43).

**4. (Level 2)** If ΣFx = 0 but ΣFy ≠ 0, a body at a point is in equilibrium.
**Answer:** False — equilibrium needs both sums to be zero (lesson 1-4, printed p.31).

**5. (Level 3)** The resultant of two parallel forces in the same direction acts closer to the smaller force.
**Answer:** False — it acts closer to the bigger force, splitting the distance in the inverse ratio (Egypt, Applied Grade 12, lesson 2-1, printed p.22).

**6. (Level 3)** A couple can move a body forward without turning it.
**Answer:** False — a couple's forces cancel as pushes; a couple produces turning only (Grade 12, lesson 3-1, printed p.42).
