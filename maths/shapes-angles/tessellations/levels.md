# Tessellations — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
tessellations — tiling by moves first, then which shapes tile,
then the kinds of tessellation, the order the books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Tessellations Tiling by Moves
Sub lesson 1 questions from the type files. Pass mark: define a tessellation and tile a patch by translation, reflection and rotation.

## Sub lesson 2 — Tessellations Which Shapes Tile Alone
Sub lesson 2 questions from the type files. Pass mark: tessellate with triangles, squares, rectangles and regular hexagons, and use the 360° meeting-point rule to rule out regular pentagons.

## Sub lesson 3 — Tessellations Kinds of Tessellation
Sub lesson 3 questions from the type files. Pass mark: sort tilings into regular, semi-regular and irregular, and make a glide-reflection tiling.
