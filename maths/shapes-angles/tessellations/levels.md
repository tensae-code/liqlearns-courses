# Tessellations — questions by level

Practice by level, tied to the skill number. The questions live in the type files; this file is the by-level view. The levels are the depths inside this one thing — tessellations — tiling by moves first, then which shapes tile, then the kinds of tessellation, the order the books teach it in.

## Level 1 — tiling by sliding, flipping and turning
Level 1 questions from the type files. Pass mark: define a tessellation and tile a patch by translation, reflection and rotation.

## Level 2 — which shapes tile alone
Level 2 questions from the type files. Pass mark: tessellate with triangles, squares, rectangles and regular hexagons, and use the 360° meeting-point rule to rule out regular pentagons.

## Level 3 — kinds of tessellation
Level 3 questions from the type files. Pass mark: sort tilings into regular, semi-regular and irregular, and make a glide-reflection tiling.
