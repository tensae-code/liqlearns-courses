# Tessellations — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Tessellations Tiling by Moves · (Level 2) -> Sub lesson 2 — Tessellations Which Shapes Tile Alone · (Level 3) -> Sub lesson 3 — Tessellations Kinds of Tessellation.

Say true or false, and say why.

**1. (Sub lesson 1)** Any shape at all can tessellate if you slide it carefully.
**Answer:** False — the meeting-point angles must sum to exactly 360°; regular pentagons fail this.

**2. (Sub lesson 1)** A reflection and a rotation do the same thing to a tile.
**Answer:** False — a reflection flips the tile over; a rotation turns it in its plane (Laos, Grade 5, L49–L50).

**3. (Sub lesson 2)** Rectangles can tessellate.
**Answer:** True — Nepal, Grade 6, pp.215–223.

**4. (Sub lesson 2)** Four regular pentagons at a point leave no gap.
**Answer:** False — 4 × 108° = 432°, which overlaps; three leave a gap of 36°.

**5. (Sub lesson 3)** Nepal's Grade 8 teacher guide is cited in this lesson for tessellation.
**Answer:** False — that guide is a mismatch guide — teacher evidence only; this lesson cites the Grade 6 and Grade 7 student books.
