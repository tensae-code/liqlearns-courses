# Symmetry — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — a shape
matching itself — set by the pattern across the countries' books:
the fold test first, then the turn test, then the counts for
polygons and the circle.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Symmetry Line Symmetry
Sub lesson 1 questions from the type files. Pass mark: test a shape by
folding, find its lines of symmetry, and say how many a square,
a rectangle and an equilateral triangle have.

## Sub lesson 2 — Symmetry Rotational Symmetry
Sub lesson 2 questions from the type files. Pass mark: test a shape by
turning it, say its order, and know the order counts the matches
in one full turn including the starting position come round again.

## Sub lesson 3 — Symmetry Both Kinds Together
Sub lesson 3 questions from the type files. Pass mark: say for any
shape whether it has line symmetry, rotational symmetry, both or
neither — and give the counts, including the circle's endless
lines and endless order.
