# Symmetry — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — a shape matching itself — set by the
pattern across the countries' books: the fold test first, then the
turn test, then the counts for polygons and the circle.

## Level 1 — line symmetry
Level 1 questions from the type files. Pass mark: test a shape by
folding, find its lines of symmetry, and say how many a square,
a rectangle and an equilateral triangle have.

## Level 2 — rotational symmetry
Level 2 questions from the type files. Pass mark: test a shape by
turning it, say its order, and know the order counts the matches
in one full turn including the starting position come round again.

## Level 3 — both kinds together
Level 3 questions from the type files. Pass mark: say for any
shape whether it has line symmetry, rotational symmetry, both or
neither — and give the counts, including the circle's endless
lines and endless order.
