# Shapes — ordering

Put each set in order by number of sides, fewest first. (This
question type exists for this lesson because naming IS counting
sides.)

**1. (Level 1)** hexagon · triangle · pentagon · quadrilateral
**Answer:** triangle (3), quadrilateral (4), pentagon (5), hexagon (6).

**2. (Level 1)** pentagon · hexagon · triangle · quadrilateral
**Answer:** triangle, quadrilateral, pentagon, hexagon.

**3. (Level 2)** Order these triangles by how many sides are equal, most first: scalene · equilateral · isosceles.
**Answer:** equilateral (3 equal), isosceles (2 equal), scalene (0 equal).

**4. (Level 3)** Order these quadrilaterals from loosest to strictest: square · parallelogram · rectangle.
**Answer:** parallelogram, rectangle, square — each step adds a condition (Jordan, Grade 8, p.91).

**5. (Level 3)** Order by number of right angles a shape must have: rhombus · rectangle · square.
**Answer:** rhombus (0 required), rectangle (4), square (4) — rectangle and square tie at four.
