# Constructions with ruler and compass — questions by level

Practice by level, tied to the skill number. The questions live in the type files; this file is the by-level view. The levels are the depths inside this one thing — constructions — bisections first, then the special angles, then parallels, copying and reasons, the order the books teach it in.

## Level 1 — bisections
Level 1 questions from the type files. Pass mark: bisect a segment and an angle with compasses, keeping the compass openings fixed, and check the halves equal.

## Level 2 — the special angles
Level 2 questions from the type files. Pass mark: construct 90°, 60° and 120°, then make 45°, 30° and 15° by bisecting, and 75°, 105° and 150° by joining.

## Level 3 — parallels, copying and reasons
Level 3 questions from the type files. Pass mark: draw parallels and perpendiculars through a point, copy a segment and an angle, and give the reason each arc is drawn.
