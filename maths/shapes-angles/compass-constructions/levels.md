# Constructions with ruler and compass — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
constructions — bisections first, then the special angles, then
parallels, copying and reasons, the order the books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Constructions Bisections
Sub lesson 1 questions from the type files. Pass mark: bisect a segment and an angle with compasses, keeping the compass openings fixed, and check the halves equal.

## Sub lesson 2 — Constructions The Special Angles
Sub lesson 2 questions from the type files. Pass mark: construct 90°, 60° and 120°, then make 45°, 30° and 15° by bisecting, and 75°, 105° and 150° by joining.

## Sub lesson 3 — Constructions Parallels, Copying and Reasons
Sub lesson 3 questions from the type files. Pass mark: draw parallels and perpendiculars through a point, copy a segment and an angle, and give the reason each arc is drawn.
