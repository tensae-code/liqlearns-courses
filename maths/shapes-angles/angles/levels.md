# Angles — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — angles — set by the pattern across
the countries' books: kinds and measuring first, then the
straight-line and round-a-point facts, then the sums inside shapes
and between parallel lines.

## Level 1 — kinds of angle and the protractor
Level 1 questions from the type files. Pass mark: name acute,
right, obtuse, straight and reflex angles on sight, and measure
one with a protractor, centre on the vertex and baseline on one
arm, reading the right scale.

## Level 2 — the straight line and the point
Level 2 questions from the type files. Pass mark: find a missing
angle on a straight line (180°) and around a point (360°); use
complementary (90°) and supplementary (180°) pairs; and know
vertically opposite angles are equal.

## Level 3 — angles inside shapes and between parallels
Level 3 questions from the type files. Pass mark: find a missing
angle in a triangle (180°) and in a quadrilateral (360°), and find
all the angles where a transversal crosses parallel lines from one
known angle.
