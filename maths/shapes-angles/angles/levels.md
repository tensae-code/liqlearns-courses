# Angles — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — angles —
set by the pattern across the countries' books: kinds and
measuring first, then the straight-line and round-a-point facts,
then the sums inside shapes and between parallel lines.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Angles Kinds and Measuring
Sub lesson 1 questions from the type files. Pass mark: name acute,
right, obtuse, straight and reflex angles on sight, and measure
one with a protractor, centre on the vertex and baseline on one
arm, reading the right scale.

## Sub lesson 2 — Angles on a Straight Line and Around a Point
Sub lesson 2 questions from the type files. Pass mark: find a missing
angle on a straight line (180°) and around a point (360°); use
complementary (90°) and supplementary (180°) pairs; and know
vertically opposite angles are equal.

## Sub lesson 3 — Angles in Shapes and Between Parallel Lines
Sub lesson 3 questions from the type files. Pass mark: find a missing
angle in a triangle (180°) and in a quadrilateral (360°), and find
all the angles where a transversal crosses parallel lines from one
known angle.
