# Angles — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Angles Kinds and Measuring · (Level 2) -> Sub lesson 2 — Angles on a Straight Line and Around a Point · (Level 3) -> Sub lesson 3 — Angles in Shapes and Between Parallel Lines.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** A reflex angle is more than 180°.
**True** — reflex is more than 180° but less than 360° (Egypt, Grade 7, 4-1).

**2. (Sub lesson 1)** A protractor measures length.
**False** — a protractor measures angles, in degrees.

**3. (Sub lesson 2)** Complementary angles must sit beside each other.
**False** — the pair is about the sum (90°), not the position (Sierra Leone, JSS 1, L96).

**4. (Sub lesson 2)** Vertically opposite angles are equal.
**True** — each is supplementary to the same neighbour (Sierra Leone, JSS 1, L99).

**5. (Sub lesson 3)** The angles in any triangle add to 180°.
**True** — the torn-off corners make a straight line (Egypt, Grade 7, 4-3).

**6. (Sub lesson 3)** The angles in a quadrilateral add to 180°.
**False** — they add to 360°; a quadrilateral is two triangles (Egypt, Grade 7, 4-4).
