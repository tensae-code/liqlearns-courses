# Video script — Types of Lines

Super-simple voice. The tutor talks; each line is drawn on screen as it is named.

---

Look at this line. It runs flat, like the top of a table. It is horizontal.

This one stands up straight, like the side of a door. It is vertical.

This one slants. It leans to the right. This one leans to the left. Slanting lines are oblique lines.

Now watch my finger. I follow this line… and I come back to where I started. No gap. This line is closed. Even a zigzag line can close.

This line stops. It never comes back. Its ends stay apart. This line is open.

This line bends smoothly, like a smile. It is curved. And this one turns sharply, again and again — zigzag.

Flat, standing, slanting. Closed, open. Curved, zigzag. Every line has a name.
