# Constructing triangles and quadrilaterals — ordering

Put the steps or items in the right order.

**1. (Level 1)** Order the SSS steps: A) join the crossing point to both ends of the base B) arc the third side from the other end C) draw the base D) arc the second side from one end
**Answer:** C, D, B, A — Sierra Leone SSS 2, L84, p.103.

**2. (Level 2)** Order the rectangle steps: A) join the fourth corner B) draw the length C) raise perpendiculars at both ends D) mark the width on both perpendiculars
**Answer:** B, C, D, A — the Yemen Grade 4 build (pp.100, 103).
