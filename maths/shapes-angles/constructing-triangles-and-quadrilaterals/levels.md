# Constructing triangles and quadrilaterals — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
constructing figures — triangles first, then quadrilaterals, then
the centres, the order the books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Constructing Triangles from Sides and Angles
Sub lesson 1 questions from the type files. Pass mark: construct SSS, SAS and ASA triangles and say which givens each one needs.

## Sub lesson 2 — Constructing Quadrilaterals
Sub lesson 2 questions from the type files. Pass mark: construct a square, rectangle, rhombus, parallelogram, trapezium and kite from the givens each one needs.

## Sub lesson 3 — Constructing Right-Angled Triangles and Centres
Sub lesson 3 questions from the type files. Pass mark: construct an RHS triangle and the incentre and circumcentre of a triangle, and read a construction word problem into a build.
