# Constructing triangles and quadrilaterals — questions by level

Practice by level, tied to the skill number. The questions live in the type files; this file is the by-level view. The levels are the depths inside this one thing — constructing figures — triangles first, then quadrilaterals, then the centres, the order the books teach it in.

## Level 1 — triangles from sides and angles
Level 1 questions from the type files. Pass mark: construct SSS, SAS and ASA triangles and say which givens each one needs.

## Level 2 — quadrilaterals
Level 2 questions from the type files. Pass mark: construct a square, rectangle, rhombus, parallelogram, trapezium and kite from the givens each one needs.

## Level 3 — right-angled triangles and centres
Level 3 questions from the type files. Pass mark: construct an RHS triangle and the incentre and circumcentre of a triangle, and read a construction word problem into a build.
