# Circles — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — the circle
— set by the pattern across the countries' books: the parts
first, then the round edge with pi, then the area of the disc.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Circles Parts of the Circle
Sub lesson 1 questions from the type files. Pass mark: name centre,
radius, diameter, chord, arc and circumference on a picture, and
say d = 2r and r = d/2 every time.

## Sub lesson 2 — Circles Circumference
Sub lesson 2 questions from the type files. Pass mark: find a
circumference with C = πd or C = 2πr, using π ≈ 3.14, and find a
radius or diameter back from a circumference.

## Sub lesson 3 — Circles Area of the Disc
Sub lesson 3 questions from the type files. Pass mark: find the area
with A = πr², tell a circumference from an area by its units, and
work a two-step problem (area from a diameter, or a radius from
an area).
