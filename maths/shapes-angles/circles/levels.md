# Circles — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the circle — set by the pattern
across the countries' books: the parts first, then the round edge
with pi, then the area of the disc.

## Level 1 — the parts of a circle
Level 1 questions from the type files. Pass mark: name centre,
radius, diameter, chord, arc and circumference on a picture, and
say d = 2r and r = d/2 every time.

## Level 2 — circumference
Level 2 questions from the type files. Pass mark: find a
circumference with C = πd or C = 2πr, using π ≈ 3.14, and find a
radius or diameter back from a circumference.

## Level 3 — area of a disc
Level 3 questions from the type files. Pass mark: find the area
with A = πr², tell a circumference from an area by its units, and
work a two-step problem (area from a diameter, or a radius from
an area).
