# Circles — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Circles Parts of the Circle · (Level 2) -> Sub lesson 2 — Circles Circumference · (Level 3) -> Sub lesson 3 — Circles Area of the Disc.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** Every radius of one circle is the same length.
**True** — the centre is the same distance from every point on the edge.

**2. (Sub lesson 1)** The diameter is the longest chord of a circle.
**True** — any other chord is shorter (Egypt, Grade 9, Unit 4, 4-1).

**3. (Sub lesson 2)** C = 2πr uses the diameter.
**False** — C = 2πr uses the radius; C = πd uses the diameter.

**4. (Sub lesson 2)** A circumference is measured in square centimetres.
**False** — a circumference is a length, measured in cm; cm² is area.

**5. (Sub lesson 3)** The area of a circle is πr².
**True** — pi times the radius times itself (Jordan, Grade 7, p.91).

**6. (Sub lesson 3)** Doubling a circle's radius doubles its area.
**False** — the radius is squared, so the area grows four times.
