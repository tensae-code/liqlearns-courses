# Circles — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** Every radius of one circle is the same length.
**True** — the centre is the same distance from every point on the edge.

**2. (Level 1)** The diameter is the longest chord of a circle.
**True** — any other chord is shorter (Egypt, Grade 9, Unit 4, 4-1).

**3. (Level 2)** C = 2πr uses the diameter.
**False** — C = 2πr uses the radius; C = πd uses the diameter.

**4. (Level 2)** A circumference is measured in square centimetres.
**False** — a circumference is a length, measured in cm; cm² is area.

**5. (Level 3)** The area of a circle is πr².
**True** — pi times the radius times itself (Jordan, Grade 7, p.91).

**6. (Level 3)** Doubling a circle's radius doubles its area.
**False** — the radius is squared, so the area grows four times.
