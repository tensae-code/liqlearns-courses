# Fill in the blank — Factorisation

1. (Layer 1) 8y + 12 = 4(______).
   **Answer: 2y + 3.** India, Mathematics Class 8, printed p. 217.

2. (Layer 2) x² − 25 = (x + 5)(______).
   **Answer: x − 5.** India, Mathematics Class 8, printed p. 220.

3. (Layer 3) x² + 9x + 20 = (x + 4)(x + ______) — the two numbers multiply to 20 and add to 9.
   **Answer: 5.** India, Mathematics Class 8, printed p. 221.

4. (Layer 4) x³ − 6x² + 11x − 6 = (x − 1)(x − 2)(______) — after the first two factors, the remaining zero is 3.
   **Answer: x − 3.** India, Mathematics Class 9, printed p. 42.
