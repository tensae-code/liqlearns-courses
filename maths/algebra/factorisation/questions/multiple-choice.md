1. (Sub lesson 1) The factorisation of 6x + 9 is:
   A. 3(2x + 3) B. 3(2x + 9) C. 6(x + 9) D. (6x)(9)
   **Answer: A** — 3 is the common factor of both terms; expanding 3(2x + 3) returns 6x + 9. India, Mathematics Class 8, printed p. 217.

2. (Sub lesson 2) x² − 16 factorises as:
   A. (x − 4)² B. (x + 4)(x − 4) C. (x + 16)(x − 1) D. It cannot be factorised
   **Answer: B** — the difference of two squares, a² − b² = (a + b)(a − b). India, Mathematics Class 8, printed p. 220.

3. (Sub lesson 3) x² + 7x + 12 factorises as:
   A. (x + 6)(x + 2) B. (x + 3)(x + 4) C. (x + 12)(x + 1) D. (x + 7)(x + 12)
   **Answer: B** — 3 and 4 multiply to 12 and add to 7. India, Mathematics Class 8, printed p. 221.

4. (Sub lesson 3) The first step in factorising 2x² + 10x + 12 is:
   A. Split the middle term B. Use the Factor Theorem C. Take out the common factor 2 D. It is already factorised
   **Answer: C** — take the common factor out first: 2(x² + 5x + 6), then factorise the trinomial. India, Mathematics Class 8, printed p. 221.

5. (Sub lesson 4) p(x) = x³ − 6x² + 11x − 6. Since p(1) = 0, one factor of p(x) is:
   A. (x + 1) B. (x − 1) C. (x − 6) D. x
   **Answer: B** — by the Factor Theorem, p(a) = 0 means (x − a) is a factor. India, Mathematics Class 9, printed p. 42.
