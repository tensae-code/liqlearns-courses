# Ordering — Factorisation

1. (Layer 1) Put the steps of factorising 6x + 9 by common factors in order:
   (a) Write the answer 3(2x + 3).
   (b) Divide each term by 3.
   (c) Find the factor common to both terms: 3.
   (d) Expand the answer to check it returns 6x + 9.
   **Answer: (c), (b), (a), (d).** India, Mathematics Class 8, printed p. 217.

2. (Layer 4) Put the steps of factorising a cubic by the Factor Theorem in order:
   (a) Factorise the quadratic quotient.
   (b) Test values of x until p(a) = 0.
   (c) Divide the cubic by (x − a).
   (d) Read off the first factor (x − a).
   **Answer: (b), (d), (c), (a).** India, Mathematics Class 9, printed p. 42.
