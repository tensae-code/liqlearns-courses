1. (Sub lesson 1) Factorisation is the reverse of expanding brackets.
   **Answer: True.** India, Mathematics Class 8, printed p. 217.

2. (Sub lesson 1) 4x + 6 = 4(x + 6).
   **Answer: False — expanding 4(x + 6) gives 4x + 24. The common factor is 2: 4x + 6 = 2(2x + 3).** India, Mathematics Class 8, printed p. 217.

3. (Sub lesson 2) x² + 6x + 9 = (x + 3)².
   **Answer: True — it is the identity form a² + 2ab + b² with a = x, b = 3.** India, Mathematics Class 8, printed p. 220.

4. (Sub lesson 3) (x + 2)(x + 5) is the factorisation of x² + 7x + 12.
   **Answer: False — (x + 2)(x + 5) = x² + 7x + 10. For +12 the numbers are 3 and 4.** India, Mathematics Class 8, printed p. 221.

5. (Sub lesson 4) If p(2) = 0 for a polynomial p(x), then (x − 2) is a factor of p(x).
   **Answer: True — that is the Factor Theorem.** India, Mathematics Class 9, printed p. 42.
