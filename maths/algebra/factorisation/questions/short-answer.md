# Short answer — Factorisation

1. (Layer 2) Factorise ax + ay + bx + by by regrouping, showing both steps.
   **Answer: a(x + y) + b(x + y) = (x + y)(a + b).** India, Mathematics Class 8, printed p. 219.

2. (Layer 3) A learner writes: x² + 7x + 12 = (x + 6)(x + 2). Find the error, in the spirit of the chapter's "Can you find the error?" page, and give the correct factorisation.
   **Answer: 6 and 2 multiply to 12 but add to 8, not 7 — expanding gives x² + 8x + 12. The numbers must add to 7: 3 and 4, so x² + 7x + 12 = (x + 3)(x + 4).** India, Mathematics Class 8, printed pp. 221, 226.

3. (Layer 4) Factorise x² + 5x + 6 by splitting the middle term, showing the split.
   **Answer: x² + 2x + 3x + 6 = x(x + 2) + 3(x + 2) = (x + 2)(x + 3).** India, Mathematics Class 9, printed p. 41.
