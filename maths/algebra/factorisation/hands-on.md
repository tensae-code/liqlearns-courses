# Hands-on — Factorisation

## Activity 1 — Backwards day (10 minutes)

Take any expanded expression from your notebook work (or make one by expanding 4(x + 5), x(x − 3) and (x + 2)(x + 6) yourself on a covered page). Now walk the road backwards: factorise each result without looking at the covered page, then uncover and compare. This is India's Class 8 definition in your hands — factorisation is multiplication reversed.

## Activity 2 — The identity hunt (15 minutes)

Write the three identity shapes on cards: a² + 2ab + b², a² − 2ab + b², a² − b². Now hunt through these expressions and match each to its card before factorising it: x² + 10x + 25; y² − 16; m² − 6m + 9; 9p² − 4; t² + 4t + 4; z² − 12z + 36. Say each factorisation aloud in the form "(x + 5) squared" or "(y + 4)(y − 4)" as you go.

## Activity 3 — Find the error (10 minutes)

India's Class 8 book ends its factorisation chapter with a page of wrong work set for correction (§14.5, "Can you find the error?"). Play it with a partner: each of you writes four worked lines — three correct factorisations and one quietly wrong one (a dropped common factor, a sign slipped in (x + a)(x + b), an expansion that does not return). Swap pages, find each other's planted error, and write the correction. Every wrong line found is one the book's page trained you to catch.
