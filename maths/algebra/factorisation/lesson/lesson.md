# Factorisation

## You do it first

Here is an expression: 6x + 9. It is a sum — but can it be written as a **multiplication** instead? Something times something else, where expanding the multiplication gives 6x + 9 back exactly?

Try it. One of the factors is a single number. When you think you have it, expand your answer to check.

## The reverse of multiplying

Expanding brackets runs one way: 3(x + 2) = 3x + 6. **Factorisation is that same road walked backwards**: given 3x + 6, you find the product it came from — 3(x + 2). The pieces you multiply together are the **factors**, and a factor that cannot be split into smaller factors is called **irreducible**. India's Class 8 book opens its factorisation chapter with exactly this definition, and everything in this lesson is one of its methods for walking the road backwards. (India, Mathematics Class 8, Ch. 14, printed p. 217.)

## Method 1 — take out the common factor

Look for a factor every term shares, and take it outside a bracket:

- 6x + 9: both terms share 3 → **3(2x + 3)**
- 4x + 6: both terms share 2 → **2(2x + 3)**

What is left inside the bracket has no factor common to all its terms — it is finished. (India, Mathematics Class 8, Ch. 14, printed p. 217.)

## Method 2 — regrouping

Sometimes no factor is common to *every* term, but the terms fall into groups that each have one:

ax + ay + bx + by = a(x + y) + b(x + y)

Now (x + y) is common to both groups, so it comes out: **(x + y)(a + b)**. (India, Mathematics Class 8, Ch. 14, printed p. 219.)

## Method 3 — the identities backwards

The standard identities read backwards are factorisations ready-made:

- a² + 2ab + b² = **(a + b)²**
- a² − 2ab + b² = **(a − b)²**
- a² − b² = **(a + b)(a − b)**

x² − 9 is the third shape with b = 3, so x² − 9 = (x + 3)(x − 3) at once; x² + 6x + 9 is the first shape with a = x, b = 3, so it is (x + 3)². Combined expressions may need the common-factor method first and an identity second. (India, Mathematics Class 8, Ch. 14, printed p. 220.)

## Method 4 — trinomials: (x + a)(x + b)

Expanding (x + a)(x + b) gives x² + (a + b)x + ab — so to factorise x² + bx + c, find two numbers a and b that **multiply to c and add to b**:

x² + 7x + 12: the numbers are 3 and 4 (3 × 4 = 12, 3 + 4 = 7) → **(x + 3)(x + 4)**.

And if the whole trinomial has a common factor, take it out first: 2x² + 10x + 12 = 2(x² + 5x + 6) = 2(x + 2)(x + 3). The Class 8 chapter's summary misprints this form once as "x² + (a + b) + ab", dropping the x — the formula list on the same page prints it in full, and the full form is the one to learn. (India, Mathematics Class 8, Ch. 14, printed pp. 221, 229.)

## Method 5 — splitting the middle term (Class 9)

For ax² + bx + c with a ≠ 1, split the middle term into two terms whose coefficients **multiply to ac**, then regroup. For x² + 5x + 6 the split is 5x = 2x + 3x:

x² + 2x + 3x + 6 = x(x + 2) + 3(x + 2) = **(x + 2)(x + 3)**.

(India, Mathematics Class 9, Ch. 2, printed p. 41.)

## Method 6 — cubics with the Factor Theorem (Class 9)

A cubic factorises one zero at a time. By the Factor Theorem, if p(a) = 0 then (x − a) is a factor. Take p(x) = x³ − 6x² + 11x − 6: p(1) = 1 − 6 + 11 − 6 = 0, so (x − 1) is a factor. Divide it out and the quotient is x² − 5x + 6, which splits as (x − 2)(x − 3). The whole cubic is **(x − 1)(x − 2)(x − 3)** — check by expanding: you land back on x³ − 6x² + 11x − 6. (India, Mathematics Class 9, Ch. 2, printed p. 42.)

## Find the error — the book's own game

India's Class 8 chapter ends with a page called "Can you find the error?" (§14.5): worked lines with wrong simplifications, expansions and substitutions, printed wrong **on purpose** so you catch and correct them. Play it on this lesson's methods: a factorisation is only finished when expanding it returns the expression you started with — that one check catches nearly every slip the page exhibits. (India, Mathematics Class 8, Ch. 14, printed p. 226.)

> **Tip — from us, not from the books:** when no method jumps out, run the ladder in order — common factor first, then regrouping, then an identity shape, then the (x + a)(x + b) hunt. The Class 8 chapter teaches the methods in that order for a reason: each later method assumes the earlier ones have already been tried.

## Where this leads

Factorised form is what makes quadratic equations solve cleanly (a product is zero only when one of its factors is zero) — that work lives in quadratic-equations, and the division that Method 6 leans on lives in polynomial-division. Both are soft hints only: open either directly whenever you want it.

## Say it to your companion

Explain to your companion, in your own words: what factorisation is, how the common-factor method and regrouping differ, how you choose a and b for x² + bx + c, and how the Factor Theorem cracks a cubic. Then let them hand you an expression and talk your factorisation through aloud, expanding at the end to check.

## Do It Yourself

1. Factorise by common factors: (a) 8y + 12; (b) 5x² + 15x; (c) 9a − 6b + 3.
2. Factorise by regrouping: (a) ax + ay + bx + by; (b) 2x + 2y + px + py.
3. Factorise with the identities: (a) x² − 25; (b) m² + 8m + 16; (c) 4p² − 9.
4. Factorise the trinomials: (a) x² + 9x + 20; (b) x² − 2x − 15; (c) 3x² + 15x + 18 (common factor first).
5. Factorise by splitting the middle term: (a) x² + 7x + 10; (b) 2x² + 7x + 3.
6. Use the Factor Theorem to factorise x³ − 2x² − x + 2 completely. (Start by testing x = 1.)
