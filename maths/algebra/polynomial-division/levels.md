# Polynomial Division — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — dividing polynomials — long division first, then synthetic division and the remainder theorem, then the factor theorem and rational zeros.

## Level 1 — long division and the division identity
Level 1 questions from the type files. Pass mark: divide a polynomial by a binomial in writing, state quotient and remainder, and check with p(x) = d(x)q(x) + R(x).

## Level 2 — synthetic division and the remainder theorem
Level 2 questions from the type files. Pass mark: run a synthetic (Horner) table by (x − a), and find a remainder by evaluating p(a) — including the divisor (ax + b) case, remainder p(−b/a) — without dividing.

## Level 3 — the factor theorem and rational zeros
Level 3 questions from the type files. Pass mark: test whether (x − a) is a factor by p(a), factorise a cubic completely through one found factor, and list and test possible rational zeros p/q.
