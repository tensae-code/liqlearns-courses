# Polynomial Division — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
polynomial division — long division first, then synthetic
division and the remainder theorem, then the factor theorem
and rational zeros, the order the books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Long Division of Polynomials
Sub lesson 1 questions from the type files. Pass mark: divide a polynomial by a binomial in writing, state quotient and remainder, and check with p(x) = d(x)q(x) + R(x).

## Sub lesson 2 — Synthetic Division and the Remainder Theorem
Sub lesson 2 questions from the type files. Pass mark: run a synthetic (Horner) table by (x − a), and find a remainder by evaluating p(a) — including the divisor (ax + b) case, remainder p(−b/a) — without dividing.

## Sub lesson 3 — The Factor Theorem and Rational Zeros
Sub lesson 3 questions from the type files. Pass mark: test whether (x − a) is a factor by p(a), factorise a cubic completely through one found factor, and list and test possible rational zeros p/q.
