# Polynomial Division — matching

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Long Division of Polynomials · (Level 2) -> Sub lesson 2 — Synthetic Division and the Remainder Theorem · (Level 3) -> Sub lesson 3 — The Factor Theorem and Rational Zeros.

Match each item on the left to its partner on the right.

**1. (Sub lesson 1)** Match each division to its quotient: (a) (x² + 3x + 2) ÷ (x + 1) (b) (x² + 3x + 2) ÷ (x + 2) (c) (x² − 4) ÷ (x − 2) — x + 1, x + 2, x + 2
**Answer:** a) x + 2, b) x + 1, c) x + 2 — check each by multiplying back.

**2. (Sub lesson 2)** Match each divisor to the value whose p-value gives the remainder: (a) (x − 4) (b) (2x + 1) (c) (x + 3) — p(−3), p(4), p(−1/2)
**Answer:** a) p(4), b) p(−1/2), c) p(−3) — for (ax + b) the value is p(−b/a).

**3. (Sub lesson 3)** Match each zero to its factor: (a) zero 3 (b) zero −1 (c) zero 0 — (x + 1), (x − 3), x
**Answer:** a) (x − 3), b) (x + 1), c) x — the factor is (x − a) where a is the zero.
