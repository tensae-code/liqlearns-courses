# Polynomial Division — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Long Division of Polynomials · (Level 2) -> Sub lesson 2 — Synthetic Division and the Remainder Theorem · (Level 3) -> Sub lesson 3 — The Factor Theorem and Rational Zeros.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** Every polynomial division can be checked by multiplying divisor × quotient and adding the remainder.
**Answer:** True — that is the division identity p(x) = d(x)q(x) + R(x).

**2. (Sub lesson 1)** The remainder can have the same degree as the divisor.
**Answer:** False — division continues until the remainder's degree is smaller than the divisor's.

**3. (Sub lesson 2)** The remainder when x² + 1 is divided by (x − 2) is 5.
**Answer:** True — p(2) = 4 + 1 = 5.

**4. (Sub lesson 2)** In synthetic division by (x − 3), the side number is −3.
**Answer:** False — it is 3; the table takes a from (x − a).

**5. (Sub lesson 3)** If p(−2) = 0, then (x + 2) is a factor of p(x).
**Answer:** True — p(−2) = 0 makes the remainder on dividing by (x − (−2)) zero.

**6. (Sub lesson 3)** If (x − 5) is a factor of p(x), then 5 is a zero of p(x).
**Answer:** True — factor and zero are the same fact read two ways: p(5) = 0.
