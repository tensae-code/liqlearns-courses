# True or false — Modulus and Absolute Value

1. (Sub lesson 1) |−3| = −3.
   **Answer: False** — |−3| = 3; a modulus is never negative. Mongolia, Математик XII (Grade 12), printed p. 5.

2. (Sub lesson 3) The equation |f(x)| = g(x) can only hold at points where g(x) ≥ 0.
   **Answer: True** — the left side is a modulus, so it is never negative; a negative right side stops the equation at once. Mongolia, Математик XII (Grade 12), printed p. 7.

3. (Sub lesson 4) |x| ≤ 2 and −2 ≤ x ≤ 2 describe the same set of points.
   **Answer: True** — both say "within distance 2 of 0". Mongolia, Математик XII (Grade 12), printed p. 9.

4. (Sub lesson 5) If |a| = |b|, then a² = b².
   **Answer: True** — one of the squaring theorems the book proves. Mongolia, Математик XII (Grade 12), printed p. 12.
