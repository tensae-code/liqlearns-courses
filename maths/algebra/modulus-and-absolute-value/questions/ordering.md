# Ordering — Modulus and Absolute Value

1. (Layer 1) Put these in order from smallest to largest: |−2|, |5|, |−9|, |0|, |−1|.
   **Answer: |0| = 0, then |−1| = 1, then |−2| = 2, then |5| = 5, then |−9| = 9** — order the distances, not the signed numbers. Mongolia, Математик XII (Grade 12), printed p. 5.

2. (Layer 1) Put these distances in order from shortest to longest: |3 − 7|, |−2 − 4|, |0 − (−5)|, |1 − 1|.
   **Answer: |1 − 1| = 0, then |3 − 7| = 4, then |0 − (−5)| = 5, then |−2 − 4| = 6** — the distance between a and b is |a − b|. Mongolia, Математик VII (Grade 7), printed p. 5.
