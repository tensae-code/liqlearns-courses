# Short answer — Modulus and Absolute Value

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Layer 1) -> Sub lesson 1 — What |x| Is · (Layer 2) -> Sub lesson 2 — First Modulus Equations · (Layer 3) -> Sub lesson 3 — Harder Modulus Equations · (Layer 4) -> Sub lesson 4 — Modulus Inequalities · (Layer 5) -> Sub lesson 5 — The Squaring Theorems. The matching exercise is one set spanning Sub lessons 2–4; its marker names that span.

1. (Sub lesson 1) Write the distance between −3 and 4 on the number line using modulus, and give its value.
   **Answer: |−3 − 4| = |−7| = 7** — the distance between two points a and b is |a − b|. Mongolia, Математик VII (Grade 7), printed p. 5.

2. (Sub lesson 2) Solve |x + 2| = 5 by cases.
   **Answer: x + 2 = 5 gives x = 3; x + 2 = −5 gives x = −7.** Mongolia, Математик XII (Grade 12), printed p. 6.

3. (Sub lesson 3) Solve |x| = |2x − 1|.
   **Answer: x = 1/3 or x = 1** — by the case systems, or by squaring (allowed since |a| = |b| ⇒ a² = b²): x² = (2x − 1)² gives 3x² − 4x + 1 = 0, so (3x − 1)(x − 1) = 0. Mongolia, Математик XII (Grade 12), printed pp. 7, 12.

4. (Sub lesson 4) Solve |x − 5| > 8 geometrically, saying what the equation means first.
   **Answer: it asks for the points more than 8 away from 5: x < −3 or x > 13.** Mongolia, Математик XII (Grade 12), printed p. 9.
