# Multiple choice — Modulus and Absolute Value

1. (Layer 1) |−7| equals:
   A. −7 B. 7 C. 0 D. −1/7
   **Answer: B** — the modulus drops the sign: |−7| is the distance of −7 from 0, which is 7. Mongolia, Математик XII (Grade 12), printed p. 5.

2. (Layer 2) The solutions of |x − 5| = 3 are:
   A. 5 and 3 B. 2 and 8 C. −2 and 8 D. 8 only
   **Answer: B** — the points at distance 3 from 5: 5 − 3 = 2 and 5 + 3 = 8. Mongolia, Математик XII (Grade 12), printed p. 6.

3. (Layer 2) The equation |2x − 5| = −7 has:
   A. The solution x = −1 B. The solution x = 6 C. No solution D. Every number as a solution
   **Answer: C** — a modulus is never negative, so it can never equal −7; the book works this very equation. Mongolia, Математик XII (Grade 12), printed p. 6.

4. (Layer 4) The inequality |x| ≤ 4 says the same as:
   A. x ≤ 4 B. x ≥ −4 C. −4 ≤ x ≤ 4 D. x = 4 or x = −4
   **Answer: C** — the points within distance 4 of 0 form the whole band from −4 to 4. Mongolia, Математик XII (Grade 12), printed p. 9.

5. (Layer 5) For every real number x, |x|² equals:
   A. −x² B. x² C. 2|x| D. x² only when x is positive
   **Answer: B** — one of the book's proved squaring theorems: |x|² = x². Mongolia, Математик XII (Grade 12), printed p. 12.
