# Lesson plan — Modulus and Absolute Value

**One thing:** the modulus of a number, |x| — what it means (the distance of x from 0, so never negative), and how to solve the equations and inequalities built with it: by cases, by distance on the line, and by the squaring theorems.

**Unit:** Algebra (Unit 6). **Level 153** (Mongolia merge, 2026-11-07).

**Why this lesson exists:** Mongolia's Grade 12 book (Математик XII, Ch. II §2.1, printed pp. 5–16) is the one read book that gives modulus a full chapter of its own — definition, three families of equations, two families of inequalities, and three squaring theorems, each proved. Everywhere else in the library modulus appears only in passing: as the distance that defines negative numbers (Mongolia's own Grade 7 book, and the real-number-system lesson), as the absolute-value function inside other function lessons, and as the modulus of a complex number. A learner who looks for "modulus" or "absolute value" should find the whole thing in one place, so under the everything-goes-in ruling (2026-11-06) it gets its own lesson. It stands alone: the inequalities lesson is a soft hint before it, never a gate.

## Sub lessons
The parts of this lesson, in order — the list the learner sees
from the start, locked ahead, each opening when the one before
it is proved (the gate: README, "Units, Lessons and Sub Lessons
(ruled 2026-11-08)"):

1. **What |x| Is** — the definition |x| = x when x ≥ 0 and |x| = −x when x < 0, |x| as the distance from 0, and the distance between two points as |a − b|. (Was depth Layer 1.)
2. **First Modulus Equations** — solving |ax + b| = c by cases and by the distance method on the line, and why an equation like |2x − 5| = −7 has no solution. (Was depth Layer 2.)
3. **Harder Modulus Equations** — solving |f(x)| = g(x) with g(x) ≥ 0 demanded first, |ax + b| = |cx + d| by case systems, and nested moduli opened from the outside in. (Was depth Layer 3.)
4. **Modulus Inequalities** — solving |x| ≤ c as −c ≤ x ≤ c, and |x − a| > c by cases and geometrically, as the points far enough from a on the line. (Was depth Layer 4.)
5. **The Squaring Theorems** — the squaring theorems |x|² = x², |x| = √(x²) and |a| = |b| ⇒ a² = b², and turning |f| > |g| by squaring into (f − g)(f + g) > 0. (Was depth Layer 5.)

Gate pool: all questions of the sub lesson (no hardness ranking is written in this lesson's question files).

## The climb

1. **What |x| is** — |x| = x when x ≥ 0 and |x| = −x when x < 0; |x| ≥ 0 always; on the number line |x| is the distance of x from 0, and the distance between two points a and b is |a − b|.
2. **First equations** — |ax + b| = c solved by cases (the inside is c, or it is −c) and by the distance method on the line; and the stop sign: |2x − 5| = −7 has no solution, because a modulus is never negative.
3. **Harder equations** — |f(x)| = g(x), which first needs g(x) ≥ 0; |ax + b| = |cx + d| by case systems; nested moduli in the starred exercises.
4. **Inequalities** — |x| ≤ c means −c ≤ x ≤ c; |x − 5| > 8 solved by cases and read geometrically: the points more than 8 away from 5. (Simple modulus inequalities are met two years earlier, in Grade 9.)
5. **The squaring theorems** — |x|² = x², |x| = √(x²), and |a| = |b| ⇒ a² = b², each proved; and |f| > |g| turned by squaring into (f − g)(f + g) > 0.
