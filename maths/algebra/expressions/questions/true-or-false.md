# Expressions — true or false

Say true or false, and fix the false ones.

**1. (Level 1)** 4x and 4x² are like terms.
**Answer: False.** Like terms need the same letters to the same powers.

**2. (Level 2)** 2(x + 3) = 2x + 3.
**Answer: False.** 2(x + 3) = 2x + 6.

**3. (Level 3)** Factorising is the reverse of expanding.
**Answer: True.** (South Africa, Grade 9 Book 2, WS76–77.)
