# Expressions — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Terms and Like Terms · (Level 2) -> Sub lesson 2 — Expanding Brackets · (Level 3) -> Sub lesson 3 — Factorising. The matching sets keep their groups; each set's marker names the sub lesson its pairs belong to.

Say true or false, and fix the false ones.

**1. (Sub lesson 1)** 4x and 4x² are like terms.
**Answer: False.** Like terms need the same letters to the same powers.

**2. (Sub lesson 2)** 2(x + 3) = 2x + 3.
**Answer: False.** 2(x + 3) = 2x + 6.

**3. (Sub lesson 3)** Factorising is the reverse of expanding.
**Answer: True.** (South Africa, Grade 9 Book 2, WS76–77.)
