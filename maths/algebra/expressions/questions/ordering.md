# Expressions — ordering

Put each set in order — here, in the order of the steps you take.

**1. (Level 2)** Steps to expand 3(x − 4): multiply 3 by x · multiply 3 by −4 · write 3x − 12 · read the bracket
**Answer:** read the bracket, multiply 3 by x, multiply 3 by −4, write 3x − 12.

**2. (Level 3)** Steps to factorise x² + 5x + 6: write (x + 2)(x + 3) · expand back to check · find two numbers that multiply to 6 and add to 5 · read the trinomial
**Answer:** read the trinomial, find two numbers that multiply to 6 and add to 5, write (x + 2)(x + 3), expand back to check.
