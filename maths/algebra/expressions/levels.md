# Expressions — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
expressions — terms and like terms first, then expanding
brackets, then factorising, the order the books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Terms and Like Terms
Sub lesson 1 questions from the type files. Pass mark: name the terms, coefficients and variables of an expression, and collect like terms without joining unlike ones.

## Sub lesson 2 — Expanding Brackets
Sub lesson 2 questions from the type files. Pass mark: expand a number times a bracket, a letter times a bracket, and a bracket with a minus in front, and check by substitution.

## Sub lesson 3 — Factorising
Sub lesson 3 questions from the type files. Pass mark: take out a common factor, factorise by grouping, and use the identities for a square of a sum, a difference of squares, and a simple trinomial — always checking by expanding back.
