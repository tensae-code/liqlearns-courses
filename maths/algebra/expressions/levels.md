# Expressions — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — terms and like terms first, then expanding brackets, then factorising.

## Level 1 — terms, coefficients and like terms
Level 1 questions from the type files. Pass mark: name the terms, coefficients and variables of an expression, and collect like terms without joining unlike ones.

## Level 2 — expanding brackets
Level 2 questions from the type files. Pass mark: expand a number times a bracket, a letter times a bracket, and a bracket with a minus in front, and check by substitution.

## Level 3 — factorising
Level 3 questions from the type files. Pass mark: take out a common factor, factorise by grouping, and use the identities for a square of a sum, a difference of squares, and a simple trinomial — always checking by expanding back.
