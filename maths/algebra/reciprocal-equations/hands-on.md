# Hands-on — Reciprocal Equations

## Activity 1 — Read it backwards (10 minutes)

Write these coefficient lists on cards: (a) 2, 3, 3, 2 — (b) 1, 0, −5, 0, 1 — (c) 4, −1, 2, 3 — (d) 3, 4, −14, 4, 3 — (e) 5, 2, −1, 2, 0, 5. Read each one backwards. Three of them are reciprocal polynomials and two are not — find which, and for each one that fails, point at the exact pair of positions that does not match. (Answers: (a), (b) and (d) are reciprocal; (c) fails at the first pair, 4 against 3; (e) fails because the x² coefficient 2 would need an x coefficient of 2, but it is 0.) This is the recognition skill of Venezuela's Grade 11 book, printed p. 75.

## Activity 2 — The free root (15 minutes)

Take the equation 2x³ + 3x² + 3x + 2 = 0. First check it is reciprocal by reading its coefficients backwards. The book's theorem (printed p. 76) now hands you a root for free: x = −1. Check it by substitution: −2 + 3 − 3 + 2 = 0. Then divide the cubic by (x + 1) using Ruffini's synthetic division and solve the quadratic that remains, 2x² + x + 2 = 0. Its discriminant is 1 − 16, negative — so the equation has exactly one real root, and the symmetry found it.

## Activity 3 — Fold the quartic (15 minutes)

Solve 3x⁴ + 4x³ − 14x² + 4x + 3 = 0 by the book's method (printed p. 77). Divide by x² and copy the terms into two boxes: one for (x + 1/x), one for (x² + 1/x²). Replace the second box with y² − 2 and the first with y, and solve 3y² + 4y − 20 = 0 by factorising: (3y + 10)(y − 2) = 0. Unfold y = 2 and y = −10/3 separately into quadratics in x, and collect all four roots: 1 (twice), −1/3, −3. Last, draw the roots on a number line and join each root to its reciprocal with an arc — the picture the whole lesson is named for.
