# Ordering — Reciprocal Equations

1. (Layers 4–5) Put the steps for solving 3x⁴ + 4x³ − 14x² + 4x + 3 = 0 in order:
   (a) solve x + 1/x = y for each value of y
   (b) divide the equation by x² and group the symmetric terms
   (c) solve the quadratic 3y² + 4y − 20 = 0
   (d) substitute y = x + 1/x, with x² + 1/x² = y² − 2
   (e) check the roots answer in reciprocal pairs

   **Answer: (b), (d), (c), (a), (e)** — fold first, then the small quadratic, then unfold, then the pairing check: 1 (double), −1/3, −3. Venezuela, La Matemática y el Vivir Bien (Grade 11), printed p. 77.

2. (Layer 1) Put these coefficient lists in order from "reciprocal, lowest degree" to "not reciprocal": (i) 2, 7, −1, 7, 2, 0 (ii) 1, −3, 2, −3, 1 (iii) 4, 4.
   **Answer: (iii) first — degree 1, coefficients 4, 4, reciprocal; (ii) second — degree 4, reciprocal; (i) last — not reciprocal: its constant term is 0, breaking the mirror with the leading 2.** Venezuela, La Matemática y el Vivir Bien (Grade 11), printed p. 75.
