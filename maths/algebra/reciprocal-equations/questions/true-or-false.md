1. (Sub lesson 1) In a reciprocal polynomial, the coefficients read the same backwards as forwards.
   **Answer: True** — that is the definition, the same fact as p(1/x) = p(x)/xⁿ. Venezuela, La Matemática y el Vivir Bien (Grade 11), printed p. 75.

2. (Sub lesson 2) If r ≠ 0 is a root of a reciprocal equation, then 1/r is also a root.
   **Answer: True** — p(1/r) = p(r)/rⁿ, and p(r) = 0. Venezuela, La Matemática y el Vivir Bien (Grade 11), printed p. 75.

3. (Sub lesson 3) x = 0 is a root of 2x³ + 3x² + 3x + 2 = 0.
   **Answer: False** — p(0) is the constant term, 2, not 0; a reciprocal equation with a non-zero constant term never has the root 0. Venezuela, La Matemática y el Vivir Bien (Grade 11), printed p. 76.

4. (Sub lesson 4) With y = x + 1/x, the identity x² + 1/x² = y² − 2 holds for every x ≠ 0.
   **Answer: True** — square y: (x + 1/x)² = x² + 2 + 1/x², and move the 2. Venezuela, La Matemática y el Vivir Bien (Grade 11), printed p. 77.
