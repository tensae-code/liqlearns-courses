1. (Sub lessons 1–4) Match each equation or fact to its correct first move or partner:
   (a) 2x³ + 3x² + 3x + 2 = 0
   (b) 3x⁴ + 4x³ − 14x² + 4x + 3 = 0
   (c) x = −3 is a root of a reciprocal equation
   (d) the coefficient list 5, −2, 0, −2, 5
   (e) 3y² + 4y − 20 = 0

   (i) a reciprocal polynomial of degree 4 — the fold applies
   (ii) open it with the guaranteed root x = −1
   (iii) divide by x² and set y = x + 1/x
   (iv) so x = −1/3 is a root too
   (v) the folded form of (b): its roots are y = 2 and y = −10/3

   **Answer: (a)–(ii), (b)–(iii), (c)–(iv), (d)–(i), (e)–(v).** Venezuela, La Matemática y el Vivir Bien (Grade 11), printed pp. 75–77.
