1. (Sub lesson 3) Show that 2x³ + 3x² + 3x + 2 = 0 has the root −1, and finish solving it over the reals.
   **Answer: the coefficients 2, 3, 3, 2 are symmetric and the degree is odd, so −1 is a root (check: −2 + 3 − 3 + 2 = 0). Dividing by (x + 1) gives 2x² + x + 2, whose discriminant 1 − 16 is negative, so x = −1 is the only real root.** Venezuela, La Matemática y el Vivir Bien (Grade 11), printed p. 76.

2. (Sub lesson 4) Solve 3x⁴ + 4x³ − 14x² + 4x + 3 = 0 completely.
   **Answer: divide by x²: 3(x² + 1/x²) + 4(x + 1/x) − 14 = 0; with y = x + 1/x this is 3y² + 4y − 20 = 0, so y = 2 or y = −10/3. y = 2 gives x = 1 (double); y = −10/3 gives 3x² + 10x + 3 = 0, so x = −1/3 or x = −3.** Venezuela, La Matemática y el Vivir Bien (Grade 11), printed p. 77.

3. (Sub lesson 2) Explain why the roots of a reciprocal equation come in pairs r and 1/r.
   **Answer: the definition p(1/x) = p(x)/xⁿ, read at x = r, gives p(1/r) = p(r)/rⁿ; if p(r) = 0 then p(1/r) = 0.** Venezuela, La Matemática y el Vivir Bien (Grade 11), printed p. 75.

4. (Sub lesson 1) Is 5x⁵ + 2x⁴ − x³ + 2x² + 5 = 0 a reciprocal equation? Say why or why not, position by position.
   **Answer: no. Its coefficient list is 5, 2, −1, 2, 0, 5: the x² coefficient 2 would need the x coefficient to be 2 as its mirror, but there is no x term — the coefficient is 0.** Venezuela, La Matemática y el Vivir Bien (Grade 11), printed p. 75.
