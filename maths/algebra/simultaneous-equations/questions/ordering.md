# Simultaneous Equations — ordering

Put each set in order — here, in the order of the steps you take.

**1. (Level 2)** Steps to solve by substitution: solve the one-variable equation · express one variable · find the second variable · check the pair in both equations · substitute into the other equation
**Answer:** express one variable, substitute into the other equation, solve the one-variable equation, find the second variable, check the pair in both equations.

**2. (Level 3)** Steps to solve by elimination: solve for the second variable · add or subtract to cancel one variable · check the pair in both equations · multiply an equation if nothing cancels · read the system
**Answer:** read the system, multiply an equation if nothing cancels, add or subtract to cancel one variable, solve for the second variable, check the pair in both equations.
