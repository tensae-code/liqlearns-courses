# Simultaneous Equations — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Systems and the Graphical Method · (Level 2) -> Sub lesson 2 — Solving by Substitution · (Level 3) -> Sub lesson 3 — Solving by Elimination. The matching sets keep their groups; each set's marker names the sub lesson its pairs belong to.

Say true or false, and fix the false ones.

**1. (Sub lesson 1)** A pair that fits one equation of a system is the answer.
**Answer: False.** It must fit both equations at once.

**2. (Sub lesson 2)** In substitution, you should express the hardest variable first.
**Answer: False.** Express the easy one — the one standing alone, or with coefficient 1.

**3. (Sub lesson 3)** If the two equations are the same line, there are infinitely many solutions.
**Answer: True.**
