# Simultaneous Equations — true or false

Say true or false, and fix the false ones.

**1. (Level 1)** A pair that fits one equation of a system is the answer.
**Answer: False.** It must fit both equations at once.

**2. (Level 2)** In substitution, you should express the hardest variable first.
**Answer: False.** Express the easy one — the one standing alone, or with coefficient 1.

**3. (Level 3)** If the two equations are the same line, there are infinitely many solutions.
**Answer: True.**
