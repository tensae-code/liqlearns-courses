# Simultaneous Equations — matching

Match each system to its solution.

**Set 1 (Level 1)**
1. x + y = 5, x − y = 1 — **(3, 2)**
2. x + y = 7, 2x − y = 5 — **(4, 3)**
3. 2x + 3y = 12, x − y = 1 — **(3, 2)**
4. x + y = 5, 2x + 2y = 10 — **infinitely many**
5. x + y = 5, x + y = 6 — **no solution**

**Set 2 (Level 3)**
1. Add to cancel y — **x + y = 7 and 2x − y = 5**
2. Subtract to cancel x — **2x + y = 9 and x + y = 5**
3. Multiply first, then add — **2x + 3y = 12 and 3x − y = 7**
4. Substitute x = 7 − 5y — **Kazakhstan's worked example, giving y = 6**
5. Graph first — **Jordan's first method (L1, p. 40)**
