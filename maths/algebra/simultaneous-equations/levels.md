# Simultaneous Equations — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — what a system is and the graphical method first, then substitution, then elimination.

## Level 1 — what a system is, and the graphical method
Level 1 questions from the type files. Pass mark: say what a system's solution is, draw both lines, and read the crossing point — then check it in both equations.

## Level 2 — substitution
Level 2 questions from the type files. Pass mark: express one variable from one equation, substitute it into the other, and solve the one-variable equation that results.

## Level 3 — elimination, and the no-solution and infinite-solutions cases
Level 3 questions from the type files. Pass mark: add or subtract to cancel one variable (multiplying first where needed), and name the no-solution and infinite-solutions cases when they appear.
