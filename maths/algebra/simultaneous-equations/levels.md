# Simultaneous Equations — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
simultaneous equations — what a system is and the graphical
method first, then substitution, then elimination, the order
the books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Systems and the Graphical Method
Sub lesson 1 questions from the type files. Pass mark: say what a system's solution is, draw both lines, and read the crossing point — then check it in both equations.

## Sub lesson 2 — Solving by Substitution
Sub lesson 2 questions from the type files. Pass mark: express one variable from one equation, substitute it into the other, and solve the one-variable equation that results.

## Sub lesson 3 — Solving by Elimination
Sub lesson 3 questions from the type files. Pass mark: add or subtract to cancel one variable (multiplying first where needed), and name the no-solution and infinite-solutions cases when they appear.
