# Lesson plan — Quadratic Equations

**Course:** Maths · **Unit:** Unit 6 — Algebra · **Lesson:** Quadratic Equations
**Place in the curriculum:** Level 25 of the maths course — the fifth lesson of Unit 6 (maths/CURRICULUM.md).
**The one thing this lesson teaches:** quadratic equations — solving ax² + bx + c = 0 by factorising, by completing the square, and by the formula.
**This lesson's own level:** it stands on expressions (Level 21) — factorising — and on equations (Level 22) — balancing. It needs nothing else.

## Before this lesson
- Recommended first: expressions — factorising trinomials; equations — solving in one variable. Recommended, never forced.
- The books climb this lesson in a deliberate ladder, and Jordan's Grade 9 book names it: graphically, then factorising, then completing the square, then the general formula. Sierra Leone's JSS 3 climbs only partway — it teaches expanding, factorising and completing the square, but no formula and no lesson framed as solving for x.

## What the learner can do when it ends
1. Recognise a quadratic equation and its three coefficients.
2. Solve a quadratic by factorising, using the rule that a product is zero only if a factor is zero.
3. Solve a quadratic by completing the square.
4. Solve a quadratic with the formula, and read the number of roots off the discriminant.

## What you need
Paper and a pencil. The factorising skills from Level 21, ready to use.

## If the learner is stuck
- Factorises and writes x = 3 as the answer to (x − 3)(x + 5) = 0 → each factor gives a root: x − 3 = 0 gives x = 3, AND x + 5 = 0 gives x = −5. Two roots, not one.
- Solves x² = 25 as x = 5 only → a square has two roots: x = 5 or x = −5. The equation x² = a has two answers whenever a is positive.
- Completes the square and forgets to subtract what was added → x² + 6x = (x + 3)² − 9, not (x + 3)². The added 9 must be taken away again.
- Uses the formula with the wrong sign on b → write a, b and c down first, with their signs, then put them in: x = (−b ± √(b² − 4ac)) / 2a. Check the discriminant first: it says how many roots there are.
