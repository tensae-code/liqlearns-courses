# Quadratic Equations — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Solving Quadratics by Factorising · (Level 2) -> Sub lesson 2 — Solving Quadratics by Completing the Square · (Level 3) -> Sub lesson 3 — The Quadratic Formula and the Discriminant. The matching sets keep their groups; each set's marker names the sub lesson its pairs belong to.

Say true or false, and fix the false ones.

**1. (Sub lesson 1)** x² = 25 has only the root x = 5.
**Answer: False.** x = 5 or x = −5 — a square has two roots.

**2. (Sub lesson 2)** Completing the square on x² + 6x gives (x + 3)².
**Answer: False.** It gives (x + 3)² − 9.

**3. (Sub lesson 3)** The quadratic formula works even when a quadratic does not factorise neatly.
**Answer: True.**
