# Quadratic Equations — true or false

Say true or false, and fix the false ones.

**1. (Level 1)** x² = 25 has only the root x = 5.
**Answer: False.** x = 5 or x = −5 — a square has two roots.

**2. (Level 2)** Completing the square on x² + 6x gives (x + 3)².
**Answer: False.** It gives (x + 3)² − 9.

**3. (Level 3)** The quadratic formula works even when a quadratic does not factorise neatly.
**Answer: True.**
