# Quadratic Equations — matching

Match each quadratic to its roots or form.

**Set 1 (Level 1)**
1. x² + 8x + 15 = 0 — **x = −3 or −5**
2. x² − 3x = 0 — **x = 0 or 3**
3. x² − 25 = 0 — **x = 5 or −5**
4. x² + 5x + 6 = 0 — **x = −2 or −3**
5. x² = 49 — **x = 7 or −7**

**Set 2 (Level 3)**
1. x² − 5x + 6 = 0, D = 1 — **two roots: 2 and 3**
2. x² + 6x + 9 = 0, D = 0 — **one root: −3**
3. x² + x + 1 = 0, D = −3 — **no real roots**
4. (x + 3)² = 16 — **x = 1 or −7**
5. Roots 2 and 3 — **x² − 5x + 6 = 0**
