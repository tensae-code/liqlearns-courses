# Quadratic Equations — ordering

Put each set in order — here, in the order of the steps you take.

**1. (Level 2)** Steps to complete the square on x² + 6x = 7: take square roots of both sides · halve 6 to get 3 · write (x + 3)² = 16 · add 9 and subtract 9 · read the equation
**Answer:** read the equation, halve 6 to get 3, add 9 and subtract 9, write (x + 3)² = 16, take square roots of both sides.

**2. (Level 3)** Steps to use the formula on x² − 5x + 6 = 0: work out the discriminant · write down a = 1, b = −5, c = 6 · read the equation · put a, b and c into the formula · say how many roots there are
**Answer:** read the equation, write down a = 1, b = −5, c = 6, work out the discriminant, say how many roots there are, put a, b and c into the formula.
