# Quadratic Equations — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
quadratic equations — factorising first, then completing the
square, then the formula and the discriminant, the order the
books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Solving Quadratics by Factorising
Sub lesson 1 questions from the type files. Pass mark: recognise a quadratic and its coefficients, factorise it, and give both roots from the product-equals-zero rule.

## Sub lesson 2 — Solving Quadratics by Completing the Square
Sub lesson 2 questions from the type files. Pass mark: turn x² + bx into (x + b/2)² minus (b/2)², and solve by taking square roots of both sides.

## Sub lesson 3 — The Quadratic Formula and the Discriminant
Sub lesson 3 questions from the type files. Pass mark: write down a, b and c with their signs, apply the formula, and read the number of roots off the discriminant before solving.
