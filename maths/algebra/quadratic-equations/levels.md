# Quadratic Equations — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — factorising first, then completing the square, then the formula and the discriminant.

## Level 1 — factorising
Level 1 questions from the type files. Pass mark: recognise a quadratic and its coefficients, factorise it, and give both roots from the product-equals-zero rule.

## Level 2 — completing the square
Level 2 questions from the type files. Pass mark: turn x² + bx into (x + b/2)² minus (b/2)², and solve by taking square roots of both sides.

## Level 3 — the formula and the discriminant
Level 3 questions from the type files. Pass mark: write down a, b and c with their signs, apply the formula, and read the number of roots off the discriminant before solving.
