Say true or false. If it is false, say why.

**1. (Sub lesson 1)** A partial-fraction split is an identity: it holds for every x (except where a denominator is zero).
**Answer:** True — Pakistan's books stress the split is an identity, not an equation to solve for x.

**2. (Sub lesson 1)** (x + 5)/(x² − 4) is improper and must be divided before splitting.
**Answer:** False — numerator degree 1 is below denominator degree 2; it is proper and splits at once.

**3. (Sub lesson 2)** For the denominator (x + 2)², one piece over (x + 2)² is enough.
**Answer:** False — a repeated factor needs a piece for each power: over (x + 2) and over (x + 2)².

**4. (Sub lesson 1)** The South Sudan worked example on printed pp.130–131 should be copied line for line as the model method.
**Answer:** False — its printed working is muddled; its final answers (A = 3/4, B = −1/4) are correct, but the method must be learned clean.

**5. (Sub lesson 3)** A repeated irreducible quadratic factor is one of Pakistan's four cases (Case IV).
**Answer:** True — Cases I–IV run distinct linear, repeated linear, irreducible quadratic, repeated irreducible quadratic.

**6. (Sub lesson 5)** Kuwait's book teaches partial fractions for repeated linear factors inside integration.
**Answer:** False — Kuwait's §5-6 covers distinct linear factors only; that limit is recorded in the filing.
