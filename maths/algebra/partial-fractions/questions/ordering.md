# Partial Fractions — ordering

Put the items in the order asked. Check each step before you write the answer.

**1. (Level 1)** Put the steps of a split in order: (i) find the constants (ii) factorise the denominator (iii) check the fraction is proper (iv) write one piece per factor, with letters.
**Answer:** (iii), (ii), (iv), (i) — proper first, factors next, pieces next, constants last.

**2. (Level 2)** Put the steps for an improper fraction in order: (i) split the proper remainder-fraction (ii) divide, keeping the quotient (iii) note the fraction is improper (iv) recombine everything as a check.
**Answer:** (iii), (ii), (i), (iv) — spot it, divide it, split the rest, then check the whole.

**3. (Level 3)** Pakistan's four cases in order: (i) repeated irreducible quadratic (ii) distinct linear (iii) repeated linear (iv) non-repeated irreducible quadratic.
**Answer:** (ii), (iii), (iv), (i) — Cases I, II, III, IV in the book's order.
