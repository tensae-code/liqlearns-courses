Show the set-up (the pieces with letters) before the constants.

**1. (Sub lesson 1)** Split (5x + 4)/((x − 4)(x + 2)) into partial fractions.
**Answer:** 4/(x − 4) + 1/(x + 2) — x = 4 gives 24 = 6A, so A = 4; x = −2 gives −6 = −6B, so B = 1 (Pakistan's Class 10 worked example).

**2. (Sub lesson 1)** Split (4x + 2)/((x + 1)(x + 3)) into partial fractions.
**Answer:** −1/(x + 1) + 5/(x + 3) — 4x + 2 = A(x + 3) + B(x + 1); x = −1 gives −2 = 2A, so A = −1; x = −3 gives −10 = −2B, so B = 5.

**3. (Sub lesson 1)** Split 1/((x − 3)(x + 3)) into partial fractions.
**Answer:** (1/6)/(x − 3) − (1/6)/(x + 3), i.e. 1/[6(x − 3)] − 1/[6(x + 3)] — 1 = A(x + 3) + B(x − 3); x = 3 gives A = 1/6; x = −3 gives B = −1/6.

**4. (Sub lesson 2)** Write down, without solving, the set-up for (x + 2)/((x − 1)²(x + 1)).
**Answer:** A/(x − 1) + B/(x − 1)² + C/(x + 1) — one piece per power of the repeated factor, plus one for (x + 1).

**5. (Sub lesson 2)** Solve the set-up of question 4.
**Answer:** A = −1/4, B = 3/2, C = 1/4 — Bangladesh's verified worked answer for this denominator.

**6. (Sub lesson 4)** Split (x³ + 1)/(x² + 1), dividing first.
**Answer:** x − (x − 1)/(x² + 1) — division gives quotient x with remainder −(x − 1), already a linear numerator over the irreducible quadratic (Bangladesh's worked example).

**7. (Sub lesson 3)** Split 1/(x(x² + 1)) into partial fractions.
**Answer:** 1/x − x/(x² + 1) — 1 = A(x² + 1) + (Bx + C)x gives A = 1, B = −1, C = 0.

**8. (Sub lesson 5)** Recombine 2/(x + 3) + 3/(x − 5) into a single fraction.
**Answer:** (5x − 1)/((x + 3)(x − 5)) — the top is 2(x − 5) + 3(x + 3) = 5x − 1.
