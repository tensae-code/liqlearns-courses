# Partial Fractions — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
partial fractions — distinct linear factors first, then a
repeated factor, then a quadratic factor, then dividing an
improper fraction first, then integration and recombining,
the order the lesson's text teaches it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 covered two natural jumps, so it splits at the
jumps — its repeated-factor part is Sub lesson 2 and its
divide-first part is Sub lesson 4; old Level 3 splits the
same way — its quadratic-factor part is Sub lesson 3 and its
integration-and-recombining part is Sub lesson 5. The sub
lessons stand in the lesson text's order, and the pass marks
split the same way below.

## Sub lesson 1 — Distinct Linear Factors
Sub lesson 1 questions from the type files. Pass mark: check a fraction is proper, write one piece per distinct linear factor, and find the constants by substitution or by comparing coefficients.

## Sub lesson 2 — A Repeated Linear Factor
Sub lesson 2 questions from the type files. Pass mark: write one piece for each power of a repeated linear factor and solve for all its constants. (The repeated-factor half of old Level 2.)

## Sub lesson 3 — A Quadratic Factor
Sub lesson 3 questions from the type files. Pass mark: give an irreducible quadratic piece a linear numerator Ax + B (including the repeated-quadratic shape). (The quadratic-factor part of old Level 3.)

## Sub lesson 4 — Divide First When Improper
Sub lesson 4 questions from the type files. Pass mark: divide an improper fraction down before splitting what is left. (The divide-first half of old Level 2.)

## Sub lesson 5 — Integration and Recombining
Sub lesson 5 questions from the type files. Pass mark: integrate a split fraction with distinct linear factors, and recombine pieces into a single fraction. (The integration-and-recombining part of old Level 3.)
