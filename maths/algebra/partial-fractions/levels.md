# Partial Fractions — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — partial fractions — distinct linear factors first, then repeated factors and improper fractions, then quadratic factors and the integration use.

## Level 1 — distinct linear factors
Level 1 questions from the type files. Pass mark: check a fraction is proper, write one piece per distinct linear factor, and find the constants by substitution or by comparing coefficients.

## Level 2 — repeated factors, and divide first
Level 2 questions from the type files. Pass mark: write one piece for each power of a repeated linear factor and solve for all its constants, and divide an improper fraction down before splitting what is left.

## Level 3 — quadratic factors, integration, and recombining
Level 3 questions from the type files. Pass mark: give an irreducible quadratic piece a linear numerator Ax + B (including the repeated-quadratic shape), integrate a split fraction with distinct linear factors, and recombine pieces into a single fraction.
