# Linear Programming — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
linear programming — write the limits first, then draw the
region, then optimise, the order the book teaches it in.

One lesson, one level (Level 139).

Mapping from the old depth layers: old Layer 1 = Sub lesson 1;

## Sub lesson 1 — Writing the Limits
Sub lesson 1 questions from the type files. Turn a situation's limits into linear inequalities, including x ≥ 0, y ≥ 0 where they belong, and read a given region against a system. Pass mark: 4 of 5.

## Sub lesson 2 — Drawing the Feasible Region
Sub lesson 2 questions from the type files. Boundary lines solid or dashed by the inequality sign, a test point chosen, and the feasible region shaded so that every drawn inequality holds inside it. Pass mark: 5 of 6.

## Sub lesson 3 — Finding the Optimum
Sub lesson 3 questions from the type files. State an objective function, list the region's corners, evaluate the objective at each, and give the maximum or minimum with its meaning in the situation. Pass mark: 4 of 5.

## What "maxed" means here

The learner can take a fresh two-quantity situation — a workshop, a farm, a stall — and carry it all the way: constraints, region, corners, objective, answer in words, without being handed any of the steps.
