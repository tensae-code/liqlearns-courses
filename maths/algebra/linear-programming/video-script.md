# Video script — Linear Programming

Super-simple voice. The tutor talks; the region on screen is shaded step by step.

---

You have two things to make. Cloth is short. Time is short. You want the most money. Which mix is best?

Every limit becomes a line. This much cloth. This much time. Each line cuts the page. One side is allowed. One side is not.

Where ALL the limits agree — that patch is your region. Every point in it is a plan that works.

Now the money. Write it as a line: profit equals this times shirts, plus that times trousers.

Here is the trick. The best plan is never in the middle. It is always at a corner. Always. So test the corners. Add up the money at each corner. The biggest corner wins.

Limits, region, corners, best answer. That is linear programming.
