# True or false — Linear Programming

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Layer 1) -> Sub lesson 1 — Writing the Limits · (Layer 2) -> Sub lesson 2 — Drawing the Feasible Region · (Layer 3) -> Sub lesson 3 — Finding the Optimum.

1. (Sub lesson 2) The test point (0, 0) can always be used to find the allowed side of a boundary line. **False** — not when the line passes through the origin; choose another point. Malaysia, Additional Mathematics Form 5, Ch. 7 §7.1, printed pp. 237–239.
2. (Sub lesson 3) If two corners give the same maximum, every point on the edge between them is also a maximum. **True.** Malaysia, Additional Mathematics Form 5, Ch. 7 §7.2, printed pp. 242–244.
3. (Sub lesson 1) x > 5 and x ≥ 5 describe the same region. **False** — the boundary point x = 5 is included only in the second. Malaysia, Additional Mathematics Form 5, Ch. 7 §7.1, printed pp. 234–237.
