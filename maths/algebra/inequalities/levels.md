# Inequalities — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — symbols and the number line first, then solving one-variable inequalities, then compound and two-variable inequalities.

## Level 1 — symbols, situations and the number line
Level 1 questions from the type files. Pass mark: write the four symbols, turn a situation into an inequality, and show it on a number line with the right circle.

## Level 2 — solving one-variable inequalities
Level 2 questions from the type files. Pass mark: solve by the same moves as equations, flip the symbol when multiplying or dividing by a negative, and name the no-solution and every-number cases.

## Level 3 — compound and two-variable inequalities
Level 3 questions from the type files. Pass mark: split a compound inequality into two, intersect the answers, and graph a two-variable inequality.
