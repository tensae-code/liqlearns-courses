# Inequalities — ordering

Put each set in order, smallest first.

**1. (Level 1)** The answers of: x > 2 (smallest whole answer) · x ≤ 3 (biggest whole answer) · x ≥ −4 (smallest whole answer) · x < 0 (biggest whole answer) · 3 ≤ x ≤ 7 (smallest whole answer)
**Answer:** −4, −1, 3, 3, 3 — that is: x ≥ −4 gives −4; x < 0 gives −1; x > 2 gives 3; x ≤ 3 gives 3; 3 ≤ x ≤ 7 gives 3.

**2. (Level 3)** Order these solution sets by their left-hand end, smallest first: ]2, ∞[ · ]−∞, 3] · [−4, ∞[ · ]2, 5[
**Answer:** ]−∞, 3], [−4, ∞[, ]2, ∞[, ]2, 5[ — by left end: −∞, −4, 2, 2; the two starting at 2 tie, and ]2, 5[ ends first.
