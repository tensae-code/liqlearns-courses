# Inequalities — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Inequality Symbols and the Number Line · (Level 2) -> Sub lesson 2 — Solving One-Variable Inequalities · (Level 3) -> Sub lesson 3 — Compound and Two-Variable Inequalities. The matching sets keep their groups; each set's marker names the sub lesson its pairs belong to.

Say true or false, and fix the false ones.

**1. (Sub lesson 1)** x ≥ 2 includes the number 2.
**Answer: True.** The line under the sign means "or equal to", and the circle is closed.

**2. (Sub lesson 2)** Adding the same number to both sides of an inequality reverses the sign.
**Answer: False.** Adding or subtracting keeps the sign; only multiplying or dividing by a negative reverses it.

**3. (Sub lesson 3)** 3 ≤ x ≤ 7 is one inequality, not two.
**Answer: False.** It is two at once: x ≥ 3 and x ≤ 7.
