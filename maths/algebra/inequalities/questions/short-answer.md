# Inequalities — short answer

Answer in a few words.

**1. (Level 1)** Draw in words: x > 2 on a number line.
**Answer:** An open circle at 2 (2 not included) with an arrow to the right.

**2. (Level 2)** Solve 5x − 3 ≤ 12.
**Answer:** x ≤ 3 — ]−∞, 3] (Egypt, Grade 8 Term 2, 2-4).

**3. (Level 3)** Solve −1 < x − 3 < 2.
**Answer:** 2 < x < 5, or ]2, 5[.
