# Inequalities — matching

Match each inequality to its answer.

**Set 1 (Level 2)**
1. 5x + 2 > 12 — **x > 2**
2. 5x − 3 ≤ 12 — **x ≤ 3**
3. 2x − 3 ≤ 5x + 9 — **x ≥ −4**
4. 2 − 3x < 17 — **x > −5**
5. 5x + 3 ≤ 18 — **x ≤ 3**

**Set 2 (Level 1)**
1. x > 2 — **open circle at 2, arrow right**
2. x ≤ 3 — **closed circle at 3, arrow left**
3. x ≥ 18 — **18 included, everything above it**
4. x < 0 — **everything below zero, zero not included**
5. −1 < x < 2 — **a segment between −1 and 2**
