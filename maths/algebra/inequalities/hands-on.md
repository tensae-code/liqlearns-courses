# Hands-on — Inequalities

The lesson writes real rules as inequalities first, the way Egypt's Grade 7 book writes them.

## The rules of the house
Write five real rules as inequalities: driving-licence age (18 or
over), a minimum phone-use age (12), a bag that holds at most 20 kg,
a ticket that costs less than 50, a pass mark of 40 or more. Read
each one aloud and say whether the number itself is included. Egypt's
book uses the driving licence and the phone age as its own examples.

## Circles on the line
Draw a number line. Mark x > 2 (open circle at 2, arrow right),
x ≤ 3 (closed circle at 3, arrow left), −1 < x < 2 (two circles, a
segment between them), x ≥ −4 (closed circle, arrow right). A partner
checks each circle: open means out, closed means in. Then trade:
one calls an inequality, the other draws it without looking at the
book.

## The flip test
Take the true statement 2 < 3. Multiply both sides by −1: −2 and
−3. Which is bigger now? −2. So the sign flipped: −2 > −3. Do it
again with 4 < 7 and −2, and with 5 > 1 and −3. The numbers prove
the flip before any rule states it — that is why Kazakhstan's book
proves the properties instead of only stating them.

## The budget game
You have 150. Pens cost 5 each and you must also buy a 20 notebook.
How many pens? 5x + 20 ≤ 150, so x ≤ 26 — Egypt's own pens problem.
Change the numbers with a partner and solve each other's budgets.
