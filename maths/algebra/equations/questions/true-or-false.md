# Equations — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — One-Step Equations and Balancing · (Level 2) -> Sub lesson 2 — Two-Step and Multi-Step Equations · (Level 3) -> Sub lesson 3 — Brackets, Fractions and Word Problems.

Say true or false, and fix the false ones.

**1. (Sub lesson 1)** In an equation, you may add to one side only.
**Answer: False.** Whatever you do to one side, do to the other, or the balance tips.

**2. (Sub lesson 2)** 0x = 0 has no root.
**Answer: False.** 0x = 0 has every number as a root.

**3. (Sub lesson 3)** Checking by substitution is an optional extra.
**Answer: False.** The check is part of the solving — the two sides must give the same number.
