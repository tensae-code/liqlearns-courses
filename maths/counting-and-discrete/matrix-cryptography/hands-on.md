# Hands-on — Matrix Cryptography

## Activity 1 — Build the table (5 minutes)

The learner writes out the letter–number table from A = 1 to Z = 26 without looking, then checks it — pausing at J and K: J = 10, K = 11 (the book's printed table mislabels these two; 7 is G and 8 is H). The learner converts their own first name into numbers and back.

## Activity 2 — Send a word (10 minutes)

Using the coding matrix with rows (2, 1) and (1, 1), the learner encodes a two-letter word of their choice, pair by pair, and writes only the cryptogram numbers on a card. A partner who is given the matrix — but not the word — must first find its inverse (determinant 1, so the inverse has rows (1, −1) and (−1, 2)) and decode the card.

## Activity 3 — Break a bad matrix (5 minutes)

The learner is offered the "coding matrix" with rows (2, 2) and (1, 1) and asked to encode the pairs for two different words, then to try to decode. The determinant is 0, there is no inverse, and different pairs can land on the same code — the learner states, in one sentence, why such a matrix can never be a coding matrix.
