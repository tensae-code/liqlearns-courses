# True or false — Matrix Cryptography

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Layer 1) -> Sub lesson 1 — Letters into Numbers · (Layer 2) -> Sub lesson 2 — Encoding with the Coding Matrix · (Layer 3) -> Sub lesson 3 — Decoding with the Inverse.

1. (Sub lesson 1) In the letter–number table, K is number 8. **False** — K is 11 (taught corrected: the book's table prints "8 = K"; 8 is H). Rwanda, Advanced Mathematics, Learner's Book, Senior Six, Unit 7, printed p. 345.
2. (Sub lesson 3) A coding matrix with determinant 0 can still be decoded, just more slowly. **False** — with determinant 0 it has no inverse, and decoding is impossible. Rwanda, Advanced Mathematics, Learner's Book, Senior Six, Unit 7, printed p. 346.
