# True or false — Matrix Cryptography

1. (Layer 1) In the letter–number table, K is number 8. **False** — K is 11 (taught corrected: the book's table prints "8 = K"; 8 is H). Rwanda, Advanced Mathematics, Learner's Book, Senior Six, Unit 7, printed p. 345.
2. (Layer 3) A coding matrix with determinant 0 can still be decoded, just more slowly. **False** — with determinant 0 it has no inverse, and decoding is impossible. Rwanda, Advanced Mathematics, Learner's Book, Senior Six, Unit 7, printed p. 346.
