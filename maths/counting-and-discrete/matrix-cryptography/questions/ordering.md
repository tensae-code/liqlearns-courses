# Ordering — Matrix Cryptography

1. (Layer 3) Put the full round trip in the right order:
   (a) Multiply each cryptogram pair by the inverse matrix (b) Turn the letters into numbers with the table (c) Multiply each number pair by the coding matrix (d) Read the recovered numbers back as letters
   **Answer: b, c, a, d.** Rwanda, Advanced Mathematics, Learner's Book, Senior Six, Unit 7, printed pp. 345–346.
