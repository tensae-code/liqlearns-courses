# Multiple choice — Matrix Cryptography

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Layer 1) -> Sub lesson 1 — Letters into Numbers · (Layer 2) -> Sub lesson 2 — Encoding with the Coding Matrix · (Layer 3) -> Sub lesson 3 — Decoding with the Inverse.

1. (Sub lesson 1) The word GO becomes which pair of numbers?
   A. (7, 15) B. (6, 14) C. (7, 14) D. (8, 15)
   **Answer: A** — G = 7, O = 15. Rwanda, Advanced Mathematics, Learner's Book, Senior Six, Unit 7, printed p. 345.

2. (Sub lesson 2) Encoding the pair (8, 9) with the coding matrix with rows (2, 1) and (1, 1) gives:
   A. (16, 9) B. (25, 17) C. (17, 25) D. (10, 10)
   **Answer: B** — (2×8 + 1×9, 1×8 + 1×9) = (25, 17). Rwanda, Advanced Mathematics, Learner's Book, Senior Six, Unit 7, printed pp. 345–346.

3. (Sub lesson 3) To decode a cryptogram, you multiply its pairs by:
   A. The coding matrix again B. The coding matrix's transpose C. The coding matrix's inverse D. The letter–number table
   **Answer: C** — Rwanda, Advanced Mathematics, Learner's Book, Senior Six, Unit 7, printed p. 346.
