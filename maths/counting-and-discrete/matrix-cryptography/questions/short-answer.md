# Short answer — Matrix Cryptography

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Layer 1) -> Sub lesson 1 — Letters into Numbers · (Layer 2) -> Sub lesson 2 — Encoding with the Coding Matrix · (Layer 3) -> Sub lesson 3 — Decoding with the Inverse.

1. (Sub lesson 2) Encode the pair for the word GO — numbers (7, 15) — with the coding matrix with rows (2, 1) and (1, 1).
   **Answer: (2×7 + 1×15, 1×7 + 1×15) = (29, 22).** Rwanda, Advanced Mathematics, Learner's Book, Senior Six, Unit 7, printed pp. 345–346.

2. (Sub lesson 3) Decode the cryptogram pair (27, 14) using the inverse matrix with rows (1, −1) and (−1, 2), and read the word.
   **Answer: (27 − 14, −27 + 28) = (13, 1) = M, A — the word is MA (the first half of MATH).** Rwanda, Advanced Mathematics, Learner's Book, Senior Six, Unit 7, printed p. 346.
