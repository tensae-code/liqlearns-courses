# Inclusion–Exclusion and Venn Counting — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Two Sets and the Venn Regions · (Level 2) -> Sub lesson 2 — Three Sets, Neither and Only · (Level 3) -> Sub lesson 3 — Survey Problems and Onto Functions.

Say true or false, and why.

**1. (Sub lesson 1)** True or false: n(A∪B) is always n(A) + n(B).
**Answer:** False — only when the sets do not overlap; otherwise the overlap is subtracted once.

**2. (Sub lesson 1)** True or false: the four regions of a two-set Venn diagram add up to the whole surveyed group.
**Answer:** True — that is the check on every Venn count (Laos, Grade 10, pp.38–48).

**3. (Sub lesson 2)** True or false: "neither" means the same as "in both".
**Answer:** False — "neither" is outside both circles; "in both" is the overlap.

**4. (Sub lesson 2)** True or false: in the three-set formula, the triple overlap ends up counted exactly once.
**Answer:** True — added 3 times, subtracted 3 times, added back once: net one (Sierra Leone, SSS3, L121).

**5. (Sub lesson 3)** True or false: every function from a bigger set to a smaller set is onto.
**Answer:** False — the constant functions hit only one target; onto must be counted, e.g. by inclusion–exclusion (Iran, Discrete, pp.73–78).

**6. (Sub lesson 3)** True or false: Kazakhstan's books meet overlapping sets before Grade 9.
**Answer:** True — the overlap idea is filed at Grade 5 §5.4, with the formula in the Grade 9 books.
