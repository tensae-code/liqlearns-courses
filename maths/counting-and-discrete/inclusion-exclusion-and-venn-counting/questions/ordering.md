# Inclusion–Exclusion and Venn Counting — ordering

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Two Sets and the Venn Regions · (Level 2) -> Sub lesson 2 — Three Sets, Neither and Only · (Level 3) -> Sub lesson 3 — Survey Problems and Onto Functions.

Put each list in order, smallest first.

**1. (Sub lesson 1)** Order by size: n(A∩B), n(A only), n(A), n(A∪B), using n(A) = 20, n(B) = 14, n(A∩B) = 6.
**Answer:** n(A∩B) = 6, n(A only) = 14, n(A) = 20, n(A∪B) = 28 — each step adds a region or a group.

**2. (Sub lesson 1)** Order the steps of filling a Venn diagram: write the "only" crescents; write the outside count; write the overlap.
**Answer:** Overlap first, then the "only" crescents, then the outside — middle out (Laos, Grade 10, pp.38–48).

**3. (Sub lesson 2)** Order by size: pair overlap, triple overlap, single-set count, in a typical survey where each pair overlap is 8, the triple is 3, and a single set holds 25.
**Answer:** Triple overlap (3), pair overlap (8), single set (25) — the deeper the overlap, the fewer it holds.

**4. (Sub lesson 3)** Order by size: all functions 4→3, onto functions 4→3, functions missing a named target.
**Answer:** Missing a named target: 16, onto: 36, all: 81 — the onto count sits between (Iran, Discrete, pp.73–78).
