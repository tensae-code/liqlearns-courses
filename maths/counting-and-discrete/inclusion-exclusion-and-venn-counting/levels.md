# Inclusion–Exclusion and Venn Counting — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — inclusion–exclusion — two sets and the Venn regions first, then three sets and survey problems, then onto functions.

## Level 1 — two sets and the Venn regions
Level 1 questions from the type files. Pass mark: fill a two-set Venn diagram from the overlap outward, and use n(A∪B) = n(A) + n(B) − n(A∩B) in both directions.

## Level 2 — three sets, neither and only
Level 2 questions from the type files. Pass mark: find "only" and "neither" counts, and apply the three-set formula with the triple overlap added back exactly once.

## Level 3 — survey problems and onto functions
Level 3 questions from the type files. Pass mark: solve a survey problem with a missing region or a missing total, and count onto functions by inclusion–exclusion, explaining each subtraction.
