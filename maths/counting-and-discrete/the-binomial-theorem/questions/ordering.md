# The Binomial Theorem — ordering

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Pascal's Triangle · (Level 2) -> Sub lesson 2 — The Theorem and Full Expansions · (Level 3) -> Sub lesson 3 — The General Term and the Binomial Series.

Put each list in order, smallest first.

**1. (Sub lesson 1)** Order by size: C(5,0), C(5,2), C(5,1).
**Answer:** C(5,0) = 1, C(5,1) = 5, C(5,2) = 10 — the row grows from the edge.

**2. (Sub lesson 1)** Order the rows by their row sum: row 2, row 4, row 3.
**Answer:** Row 2 (sum 4), row 3 (sum 8), row 4 (sum 16) — each row sum doubles: 2ⁿ.

**3. (Sub lesson 2)** Order by size: the coefficients of (a+b)⁶ in the order a⁶, a⁴b², a³b³.
**Answer:** a⁶: 1, a⁴b²: 15, a³b³: 20 — the middle coefficient is the largest.

**4. (Sub lesson 3)** Order by size for x = 0.1: the first three terms of (1+x)^(1/2): 1, x/2, −x²/8 (by absolute value).
**Answer:** |−x²/8| = 0.00125, x/2 = 0.05, 1 — the terms shrink fast, which is why few terms approximate well (Pakistan, pp.158–159).
