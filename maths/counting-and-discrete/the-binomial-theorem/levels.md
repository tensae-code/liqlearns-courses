# The Binomial Theorem — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the binomial theorem — Pascal's triangle first, then the theorem and full expansions, then the general term and the series for negative and fractional powers.

## Level 1 — Pascal's triangle
Level 1 questions from the type files. Pass mark: build the triangle to row 6 by addition, read off the row for a given n, and say how each entry is made from the two above it.

## Level 2 — the theorem and full expansions
Level 2 questions from the type files. Pass mark: state (a+b)ⁿ = Σ C(n,k) aⁿ⁻ᵏ bᵏ, expand (a+b)ⁿ fully for n up to 5, handle (a−b)ⁿ signs, and match coefficients to combination values.

## Level 3 — the general term and the binomial series
Level 3 questions from the type files. Pass mark: extract a named term or coefficient without a full expansion, and expand (1+x)ⁿ for negative or fractional n as a series valid for |x| < 1, using its first terms as an approximation.
