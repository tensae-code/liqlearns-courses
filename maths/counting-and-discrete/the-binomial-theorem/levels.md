# The Binomial Theorem — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — the binomial theorem — Pascal's triangle first, then the theorem and full expansions, then the general term and the series for negative and fractional powers.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3 — each old layer is one sub lesson, in the same order.

## Sub lesson 1 — Pascal's Triangle
Sub lesson 1 questions from the type files. Pass mark: build the triangle to row 6 by addition, read off the row for a given n, and say how each entry is made from the two above it.

## Sub lesson 2 — The Theorem and Full Expansions
Sub lesson 2 questions from the type files. Pass mark: state (a+b)ⁿ = Σ C(n,k) aⁿ⁻ᵏ bᵏ, expand (a+b)ⁿ fully for n up to 5, handle (a−b)ⁿ signs, and match coefficients to combination values.

## Sub lesson 3 — The General Term and the Binomial Series
Sub lesson 3 questions from the type files. Pass mark: extract a named term or coefficient without a full expansion, and expand (1+x)ⁿ for negative or fractional n as a series valid for |x| < 1, using its first terms as an approximation.
