# Graph theory — fill in the blank

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Graphs, Vertices, Edges and Degrees · (Level 2) -> Sub lesson 2 — Paths, Euler Paths, Hamilton Paths and Shortest Paths · (Level 3) -> Sub lesson 3 — Algorithms, Bin Packing and Dominating Sets.

Write the missing word or number.

**1. (Sub lesson 1)** The number of vertices of a graph is called its ______.
**Answer:** order — the number of edges is its size (Iran, pp.34–37).

**2. (Sub lesson 1)** The sum of all the degrees in a graph equals ______ times the number of edges.
**Answer:** two — the handshaking lemma (Iran, p.40).

**3. (Sub lesson 2)** An Euler trail that starts and ends at the same vertex exists exactly when every vertex has ______ degree.
**Answer:** even — the zero-odd-vertices case (Vietnam, Bài 9, p.41).

**4. (Sub lesson 2)** "E for ______": an Euler path uses every one of these exactly once.
**Answer:** edges (Vietnam, Bài 9, p.41).

**5. (Sub lesson 3)** In first-fit bin packing, each item goes into the ______ bin that has room for it.
**Answer:** first (Jordan, p.68).

**6. (Sub lesson 3)** The size of a smallest dominating set is written ______.
**Answer:** γ(G) — the domination number (Iran, pp.43–48).
