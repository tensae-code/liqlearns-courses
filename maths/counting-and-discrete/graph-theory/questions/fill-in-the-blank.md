# Graph theory — fill in the blank

Write the missing word or number.

**1. (Level 1)** The number of vertices of a graph is called its ______.
**Answer:** order — the number of edges is its size (Iran, pp.34–37).

**2. (Level 1)** The sum of all the degrees in a graph equals ______ times the number of edges.
**Answer:** two — the handshaking lemma (Iran, p.40).

**3. (Level 2)** An Euler trail that starts and ends at the same vertex exists exactly when every vertex has ______ degree.
**Answer:** even — the zero-odd-vertices case (Vietnam, Bài 9, p.41).

**4. (Level 2)** "E for ______": an Euler path uses every one of these exactly once.
**Answer:** edges (Vietnam, Bài 9, p.41).

**5. (Level 3)** In first-fit bin packing, each item goes into the ______ bin that has room for it.
**Answer:** first (Jordan, p.68).

**6. (Level 3)** The size of a smallest dominating set is written ______.
**Answer:** γ(G) — the domination number (Iran, pp.43–48).
