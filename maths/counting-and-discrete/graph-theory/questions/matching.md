# Graph theory — matching

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Graphs, Vertices, Edges and Degrees · (Level 2) -> Sub lesson 2 — Paths, Euler Paths, Hamilton Paths and Shortest Paths · (Level 3) -> Sub lesson 3 — Algorithms, Bin Packing and Dominating Sets.

Match each term to its meaning.

**1. (Sub lesson 1)** Match: (a) degree, (b) order, (c) loop — with: (i) an edge from a vertex to itself, (ii) the number of edges at a vertex, (iii) the number of vertices.
**Answer:** (a)–(ii), (b)–(iii), (c)–(i) (Iran, pp.34–37).

**2. (Sub lesson 2)** Match: (a) Euler path, (b) Hamilton path, (c) shortest path — with: (i) visits every vertex once, (ii) uses every edge once, (iii) has the least total length.
**Answer:** (a)–(ii), (b)–(i), (c)–(iii) (Vietnam, Bài 9–10, pp.41–46).

**3. (Sub lesson 3)** Match: (a) dominating set, (b) Δ(G), (c) γ(G) — with: (i) the largest degree in the graph, (ii) a set covering every vertex by itself or a neighbour, (iii) the size of a smallest dominating set.
**Answer:** (a)–(ii), (b)–(i), (c)–(iii) (Iran, pp.34–48).
