# Graph theory — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Graphs, Vertices, Edges and Degrees · (Level 2) -> Sub lesson 2 — Paths, Euler Paths, Hamilton Paths and Shortest Paths · (Level 3) -> Sub lesson 3 — Algorithms, Bin Packing and Dominating Sets.

Say true or false, and why.

**1. (Sub lesson 1)** A graph can have exactly one vertex of odd degree.
**Answer:** False — the number of odd-degree vertices is always even (Iran, p.40).

**2. (Sub lesson 1)** A loop adds 1 to the degree of its vertex.
**Answer:** False — a loop adds 2, joining the vertex to itself at both ends (Iran, pp.34–37).

**3. (Sub lesson 2)** If a graph has a Hamilton path, it must have an Euler path.
**Answer:** False — the two paths use different things (vertices vs edges); one does not force the other (Vietnam, Bài 9, p.41).

**4. (Sub lesson 2)** A disconnected graph can have an Euler trail covering all its edges.
**Answer:** False — a trail cannot jump between separate pieces (Iran, pp.38–39; Vietnam, Bài 9, p.41).

**5. (Sub lesson 3)** Every minimal dominating set is a minimum dominating set.
**Answer:** False — minimal only means nothing can be removed; another set may still be smaller (Iran, pp.43–48).

**6. (Sub lesson 3)** First-fit decreasing packs the items in the order they arrive.
**Answer:** False — it sorts them biggest first, then applies first-fit (Jordan, p.68).
