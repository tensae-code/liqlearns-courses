# Graph theory — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — graph theory — vocabulary and degrees first, then the two kinds of path and shortest routes, then algorithms, bin packing and domination.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3 — each old layer is one sub lesson, in the same order.

## Sub lesson 1 — Graphs, Vertices, Edges and Degrees
Sub lesson 1 questions from the type files. Pass mark: draw and read a graph, give its order and size, find every degree, and check the sum of the degrees against twice the number of edges.

## Sub lesson 2 — Paths, Euler Paths, Hamilton Paths and Shortest Paths
Sub lesson 2 questions from the type files. Pass mark: use the odd-degree test for an Euler path, find a Hamilton path when one exists, and find a shortest path in a small network.

## Sub lesson 3 — Algorithms, Bin Packing and Dominating Sets
Sub lesson 3 questions from the type files. Pass mark: run first-fit bin packing correctly, find a dominating set, use the bound γ(G) ≥ ⌈n/(Δ+1)⌉, and give γ for paths and cycles.
