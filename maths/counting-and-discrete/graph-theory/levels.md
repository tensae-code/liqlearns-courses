# Graph theory — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — graph theory — vocabulary and degrees first, then the two kinds of path and shortest routes, then algorithms, bin packing and domination.

## Level 1 — graphs, vertices, edges and degrees
Level 1 questions from the type files. Pass mark: draw and read a graph, give its order and size, find every degree, and check the sum of the degrees against twice the number of edges.

## Level 2 — Euler paths, Hamilton paths and shortest paths
Level 2 questions from the type files. Pass mark: use the odd-degree test for an Euler path, find a Hamilton path when one exists, and find a shortest path in a small network.

## Level 3 — algorithms, bin packing and dominating sets
Level 3 questions from the type files. Pass mark: run first-fit bin packing correctly, find a dominating set, use the bound γ(G) ≥ ⌈n/(Δ+1)⌉, and give γ for paths and cycles.
