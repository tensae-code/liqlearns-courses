# Counting Principles — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — counting principles — the fundamental principle and factorials first, then permutations, then combinations and circular arrangements.

## Level 1 — the fundamental principle and factorials
Level 1 questions from the type files. Pass mark: multiply step-by-step choices correctly, draw a small tree diagram, and compute factorials including 0! = 1 and 1! = 1.

## Level 2 — permutations, repeats and restrictions
Level 2 questions from the type files. Pass mark: compute ⁿPᵣ, count arrangements with repeats allowed, handle a restriction (a fixed first or last place), and divide correctly when objects are not all different.

## Level 3 — combinations and circular permutations
Level 3 questions from the type files. Pass mark: compute ⁿCᵣ, use ⁿCᵣ = ⁿCₙ₋ᵣ, solve committee, team and diagonal problems, and count circular arrangements as (n−1)! or (n−1)!/2, choosing permutations versus combinations by the swap test.
