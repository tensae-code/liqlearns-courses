# Counting Principles — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — counting principles — the fundamental principle and factorials first, then permutations, then combinations and circular arrangements.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3 — each old layer is one sub lesson, in the same order.

## Sub lesson 1 — The Fundamental Principle and Factorials
Sub lesson 1 questions from the type files. Pass mark: multiply step-by-step choices correctly, draw a small tree diagram, and compute factorials including 0! = 1 and 1! = 1.

## Sub lesson 2 — Permutations, Repeats and Restrictions
Sub lesson 2 questions from the type files. Pass mark: compute ⁿPᵣ, count arrangements with repeats allowed, handle a restriction (a fixed first or last place), and divide correctly when objects are not all different.

## Sub lesson 3 — Combinations and Circular Permutations
Sub lesson 3 questions from the type files. Pass mark: compute ⁿCᵣ, use ⁿCᵣ = ⁿCₙ₋ᵣ, solve committee, team and diagonal problems, and count circular arrangements as (n−1)! or (n−1)!/2, choosing permutations versus combinations by the swap test.
