# Congruences and Diophantine equations — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — congruences and Diophantine equations — remainders and moduli first, then congruence rules, Euclid's algorithm, and the equations themselves.

## Level 1 — remainders, moduli and simplest form
Level 1 questions from the type files. Pass mark: reduce numbers (including negatives) in a given modulus and add, subtract and multiply in a modulus.

## Level 2 — congruence rules, tests and Euclid's algorithm
Level 2 questions from the type files. Pass mark: use the arithmetic of congruences with the corrected cancellation rule, run the mod-9 digit-sum test, and find a gcd by Euclid's algorithm.

## Level 3 — linear congruences and Diophantine equations
Level 3 questions from the type files. Pass mark: solve a linear congruence, decide whether ax + by = c has whole-number solutions, give its general solution, and pick out the non-negative solutions of a real problem.
