# Congruences and Diophantine equations — matching

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Remainders and a Modulus · (Level 2) -> Sub lesson 2 — Congruences, Tests and Euclid's Algorithm · (Level 3) -> Sub lesson 3 — Linear Congruences and Diophantine Equations.

Match each term to its meaning.

**1. (Sub lesson 1)** Match: (a) modulus, (b) simplest form, (c) congruent — with: (i) leaving the same remainder, (ii) the remainder between 0 and m − 1, (iii) the divisor m in mod m.
**Answer:** (a)–(iii), (b)–(ii), (c)–(i) (Sierra Leone, L21–L22, pp.59–62).

**2. (Sub lesson 2)** Match: (a) Euclid's algorithm, (b) casting out nines, (c) residue class — with: (i) all numbers with one fixed remainder, (ii) repeated division for a gcd, (iii) the digit-sum check mod 9.
**Answer:** (a)–(ii), (b)–(iii), (c)–(i) (Iran, pp.15–23; Kazakhstan, Grade 8, starred chapter).

**3. (Sub lesson 3)** Match: (a) Diophantine equation, (b) linear congruence, (c) general solution — with: (i) ax ≡ b (mod m), (ii) an equation solved in whole numbers, (iii) the stepping formula that gives every solution.
**Answer:** (a)–(ii), (b)–(i), (c)–(iii) (Iran, pp.25–29).
