# Congruences and Diophantine equations — true or false

Say true or false, and why.

**1. (Level 1)** 23 ≡ 4 (mod 5).
**Answer:** False — 23 = 4×5 + 3, so 23 ≡ 3 (mod 5), not 4 (Sierra Leone, L22, p.62).

**2. (Level 1)** Every number has exactly one simplest form in mod m, between 0 and m − 1.
**Answer:** True — the remainder on division by m is unique (Sierra Leone, L22, p.62).

**3. (Level 2)** From 2x ≡ 2y (mod 4) you may always conclude x ≡ y (mod 4).
**Answer:** False — cancelling 2 divides the modulus by gcd(2, 4) = 2: the conclusion is x ≡ y (mod 2) (Iran, p.22).

**4. (Level 2)** Iran's Discrete Mathematics book teaches Euclid's algorithm.
**Answer:** False — as filed, that book teaches no Euclidean algorithm and no Bézout identity; this lesson takes the algorithm from Kazakhstan's Grade 8 book.

**5. (Level 3)** If gcd(a, b) divides c, then ax + by = c has infinitely many integer solutions.
**Answer:** True — from one solution, stepping by (b/d, −a/d) gives all the others (Iran, pp.26–29).

**6. (Level 3)** Kazakhstan's Grade 8 Euclid's-algorithm chapter is a required chapter of its book.
**Answer:** False — it sits in the starred additional-materials chapter, filed as OPTIONAL.
