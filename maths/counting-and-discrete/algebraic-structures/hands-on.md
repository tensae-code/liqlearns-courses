# Hands-on — Algebraic structures

The lesson built operation tables by hand, the way Yemen's books open the topic.

## The mod-4 addition table
Draw the 4×4 table for addition mod 4 on {0, 1, 2, 3}, Yemen's table way (Grade 10, 5-1, p.96). Find the identity row — the row that copies the column headings. Then, for each element, find its inverse by hunting the identity inside its row.

## Symmetry check
Fold your table along its main diagonal (in your head or with tracing paper). If the table is symmetric across the diagonal, the operation is commutative; if one pair fails to mirror, it is not — the property checks of 5-2 (p.100) done by eye.

## Ring check for (ℤ, +, ×)
On paper, check Yemen's three ring demands one at a time (Grade 11 Science, 1-2, p.14): (ℤ, +) is an abelian group; × is associative; × distributes over +. Write one number example for the distributive check, e.g. 2 × (3 + 4) against 2×3 + 2×4.
