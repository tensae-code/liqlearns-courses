# Algebraic structures — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — algebraic structures — binary operations and their properties first, then groups, then rings and fields.

## Level 1 — binary operations, tables and properties
Level 1 questions from the type files. Pass mark: read and build an operation table, and check closure, commutativity and associativity on small sets.

## Level 2 — systems and groups
Level 2 questions from the type files. Pass mark: state the group axioms, find identities and inverses in a table, and decide whether a small system is a group (and whether it is abelian).

## Level 3 — rings and fields
Level 3 questions from the type files. Pass mark: state Yemen's ring definition, verify (ℤ, +, ×) against it, and explain what a field adds and why ℝ is a field but ℤ is not.
