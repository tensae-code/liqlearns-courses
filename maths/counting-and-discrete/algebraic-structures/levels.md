# Algebraic structures — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — algebraic structures — binary operations and their properties first, then groups, then rings and fields.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3 — each old layer is one sub lesson, in the same order.

## Sub lesson 1 — Binary Operations, Tables and Properties
Sub lesson 1 questions from the type files. Pass mark: read and build an operation table, and check closure, commutativity and associativity on small sets.

## Sub lesson 2 — Systems and Groups
Sub lesson 2 questions from the type files. Pass mark: state the group axioms, find identities and inverses in a table, and decide whether a small system is a group (and whether it is abelian).

## Sub lesson 3 — Rings and Fields
Sub lesson 3 questions from the type files. Pass mark: state Yemen's ring definition, verify (ℤ, +, ×) against it, and explain what a field adds and why ℝ is a field but ℤ is not.
