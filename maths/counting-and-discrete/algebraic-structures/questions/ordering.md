# Algebraic structures — ordering

Put the steps in the right order.

**1. (Level 2)** Order the group check for a table system: (a) check closure, (b) find the identity, (c) check associativity, (d) find an inverse for every element.
**Answer:** (a), (c), (b), (d) — any working order must end with all four checked; identity before inverses, since inverses are defined by it (Yemen, Grade 10, 5-4, p.110).

**2. (Level 3)** Order the ladder by strength: (a) field, (b) mathematical system, (c) group, (d) ring.
**Answer:** (b), (c), (d), (a) — each later name demands more than the one before (Yemen, Grade 10, Unit 5; Grade 11 Science, Unit 1).
