# Algebraic structures — multiple choice

Pick the one right answer.

**1. (Level 1)** A binary operation on a set S takes…
a) one element and returns two  b) two elements of S and returns an element of S  c) two sets and returns a number
**Answer:** b) — two in, one out, staying inside S (Yemen, Grade 10, 5-1, p.96).

**2. (Level 1)** In clock addition mod 4, 2 + 3 equals…
a) 5  b) 1  c) 0
**Answer:** b) 1 — 5 passes 3, so subtract 4 (Yemen, Grade 10, 5-1, p.96).

**3. (Level 2)** Which is NOT a group axiom?
a) associativity  b) an identity element  c) every element squared equals the identity
**Answer:** c) — a group needs associativity, identity and inverses, nothing more (Yemen, Grade 10, 5-4, p.110).

**4. (Level 2)** In (ℤ, +), the inverse of 7 is…
a) 1/7  b) −7  c) 0
**Answer:** b) −7 — 7 + (−7) = 0, the identity (Yemen, Grade 10, 5-4, p.110).

**5. (Level 3)** By Yemen's definition, a ring (S, *, ∘) requires (S, *) to be…
a) any system  b) an abelian group  c) a field
**Answer:** b) — an abelian group under the first operation (Yemen, Grade 11 Science, 1-2, p.14).

**6. (Level 3)** ℤ is not a field because…
a) addition is not associative  b) 2 has no multiplicative inverse in ℤ  c) ℤ has no identity
**Answer:** b) — 1/2 is not an integer (Yemen, Grade 11 Science, 1-3, p.21).
