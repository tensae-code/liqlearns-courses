# Algebraic structures — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Binary Operations, Tables and Properties · (Level 2) -> Sub lesson 2 — Systems and Groups · (Level 3) -> Sub lesson 3 — Rings and Fields.

Say true or false, and why.

**1. (Sub lesson 1)** Division is a binary operation on the whole numbers.
**Answer:** False — 3 ÷ 2 is not a whole number, so closure fails (Yemen, Grade 10, 5-1, p.96).

**2. (Sub lesson 2)** Every group is abelian.
**Answer:** False — abelian is the extra commutative case; a group need not have it (Yemen, Grade 10, 5-4, p.110).

**3. (Sub lesson 2)** In a group, every element has exactly one inverse.
**Answer:** True — if a′ and a″ both undo a to the identity, the axioms force a′ = a″ (Yemen, Grade 10, 5-4, p.110).

**4. (Sub lesson 3)** Every field is a ring.
**Answer:** True — a field meets every ring demand and adds multiplicative inverses (Yemen, Grade 11 Science, 1-2, p.14; 1-3, p.21).

**5. (Sub lesson 3)** ℝ is a field under + and ×.
**Answer:** True — Yemen's unit closes on exactly this: the field of real numbers (1-4, p.24).

**6. (Sub lesson 1)** If an operation is commutative, it is automatically associative.
**Answer:** False — the two properties are independent checks (Yemen, Grade 10, 5-2, p.100).
