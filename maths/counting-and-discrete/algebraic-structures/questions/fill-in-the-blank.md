# Algebraic structures — fill in the blank

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Binary Operations, Tables and Properties · (Level 2) -> Sub lesson 2 — Systems and Groups · (Level 3) -> Sub lesson 3 — Rings and Fields.

Write the missing word or number.

**1. (Sub lesson 1)** An operation whose answers always stay inside the set is called ______ on the set.
**Answer:** closed (Yemen, Grade 10, 5-1, p.96).

**2. (Sub lesson 1)** The property (a * b) * c = a * (b * c) is called ______.
**Answer:** associativity (Yemen, Grade 10, 5-2, p.100).

**3. (Sub lesson 2)** A commutative group is called an ______ group.
**Answer:** abelian (Yemen, Grade 10, 5-4, p.110).

**4. (Sub lesson 2)** The element e with e * a = a for every a is the ______ element.
**Answer:** identity (Yemen, Grade 10, 5-4, p.110).

**5. (Sub lesson 3)** A set with operations and the properties they satisfy is called, in Yemen's term, a mathematical ______.
**Answer:** system (Yemen, Grade 10, 5-3, p.108).

**6. (Sub lesson 3)** (ℤ, +, ×) is a ______, but not a field.
**Answer:** ring (Yemen, Grade 11 Science, 1-2, p.14).
