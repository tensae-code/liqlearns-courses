# Mathematical investigations — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — investigating — the balance search first, then the doubling phone tree, then painted cubes and segment counting.

## Level 1 — the balance search
Level 1 questions from the type files. Pass mark: split a small set of products in three, carry out the search for up to 9 products, and read the guarantee table up to 27.

## Level 2 — the phone-call tree
Level 2 questions from the type files. Pass mark: build the minute-by-minute totals, state that 2ⁿ people know after n minutes, and use it forwards and backwards.

## Level 3 — painted cubes and counting segments
Level 3 questions from the type files. Pass mark: give the 3/2/1/0 painted-face counts for 3×3×3 and 4×4×4 cubes, and count segments for n points by 1 + 2 + … + (n−1) = n(n−1)/2.
