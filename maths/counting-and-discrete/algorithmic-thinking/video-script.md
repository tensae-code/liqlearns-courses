# Video script — Algorithmic Thinking

Super-simple voice. The tutor talks; on screen a flowchart is
drawn shape by shape while a number travels through it, then a
short messy list of numbers is sorted, searched, and a new list
grows one die-roll at a time.

---

Some steps are so exact that even a machine can follow them.
That is an algorithm. First say what goes in. Then say what
comes out. Then the steps between — no guessing.

Here is a question a machine can answer. Is this number
divisible by three? The number goes in. Yes or No comes out.

We draw it. An oval says Start. A slanted box says: the number
goes in here. A square box says: add the digits. A diamond
asks: is the sum divisible by three? Two arrows come out of
the diamond. One says Yes. One says No.

Try 342. Add the digits: nine. Nine is divisible by three.
Yes! 342 is divisible by three.

But a drawing can lie. So we test it. We run numbers through
it — numbers whose answers we already know. If the chart says
the wrong thing, we find the wrong step. We fix it. We test
again. That is debugging.

Now the list. Seven, two, nine, four — all mixed up. Compare
two, swap them if they are the wrong way round, and go again.
Two, four, seven, nine. Sorted.

Finding is the same idea. Look at one, then the next, then the
next — until you find it, or the list ends.

And a list can be born by chance. Roll the die. Write it down.
Roll again. Write it down. Twenty rolls — a real list of data,
made by simulation, ready to sort and search like any other.
