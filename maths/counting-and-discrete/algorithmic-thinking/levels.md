# Algorithmic Thinking — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and
Sub Lessons"). One lesson, one level (Level 167). The lesson
was built new in the expansion era (Australia expansion merge,
2026-11-11), founded on Book A3's Chapter 11, so there are no
old depth layers to map: the sub lessons below are its depths
as built, cut at the founding chapter's own shape — first the
algorithm itself, drawn as a flowchart with its inputs and
outputs defined and its mistakes found by tracing, then the
lists of data an algorithm works on: putting them in order,
finding things in them, and building them by simulation. The
questions live in the type files; this file is the
by-sub-lesson view.

Pass marks: the founding chapter states no pass mark, so no
mark is invented — each sub lesson's pass mark is stated as
the observable thing the learner can do.

## Sub lesson 1 — Algorithms and Flowcharts
Sub lesson 1 questions from the type files. Pass mark: given a simple test (for example, is this number divisible by 3?), define its input and its output, draw the test as a flowchart using the terminator, input/output, process and decision shapes with labelled Yes/No exits, and debug a faulty chart by tracing it with numbers whose answers are already known.

## Sub lesson 2 — Working with Lists of Data
Sub lesson 2 questions from the type files. Pass mark: sort a short list of data by hand, step by step; search a list for a named value, saying each check in order (and stopping early when a sorted list proves the value absent); and generate a list of data by simulation — repeat a chance action, record every result in order — and say what the finished list can be used for.

## What "maxed" means here

The learner does what Book A3's Chapter 11 teaches: they
write an algorithm as a flowchart — inputs and outputs defined
first, decisions drawn as diamonds with two labelled ways out —
they debug a chart by tracing it with known answers, and they
work a list of data three ways: sort it, search it, and
generate one by simulation. Pupil-textbook teaching (Book A3,
Chapter 11, printed pp. 926–941) — Australia counts in this
lesson.
