# Ordering — Algorithmic Thinking

Sub-lesson markers: every item's marker names the sub lesson it belongs to — Sub lesson 1 — Algorithms and Flowcharts · Sub lesson 2 — Working with Lists of Data. This lesson was built new with its sub lessons (Australia expansion merge, 2026-11-11), founded on Book A3's Chapter 11, so its markers are original — there are no older depth layers to map from.

1. (Sub lesson 1) Put the work of building an algorithm in order:
   draw the flowchart / define the input and the output / write the steps in order / trace the chart with numbers whose answers are known
   **Answer: define the input and the output → write the steps in order → draw the flowchart → trace the chart with numbers whose answers are known.** Item constructed for this lesson from its founding chapter. Australia, *Essential Mathematics for the Victorian Curriculum Year 8, Third Edition* (Greenwood et al., Cambridge University Press, ©2024), Chapter 11 (Algorithmic thinking), Introduction + Activity 1 — algorithms and flowcharts, printed pp. 926–927.

2. (Sub lesson 1) Put the trace of 345 through the digit-sum "divisible by 3" flowchart in order:
   output "Yes" / add the digits: 3 + 4 + 5 = 12 / input the number 345 / ask: is 12 divisible by 3?
   **Answer: input the number 345 → add the digits: 3 + 4 + 5 = 12 → ask: is 12 divisible by 3? → output "Yes".** Item constructed for this lesson from its founding chapter. Australia, *Essential Mathematics for the Victorian Curriculum Year 8, Third Edition* (Greenwood et al., Cambridge University Press, ©2024), Chapter 11 (Algorithmic thinking), Introduction + Activity 1 — algorithms and flowcharts, printed pp. 926–927.

3. (Sub lesson 2) Put the states of the list 7, 2, 9, 4 in the order they appear while it is sorted by comparing and swapping neighbouring pairs:
   2, 4, 7, 9 (a full pass with no swaps — done) / 7, 2, 9, 4 (the start) / 2, 7, 4, 9 / 2, 7, 9, 4
   **Answer: 7, 2, 9, 4 → 2, 7, 9, 4 → 2, 7, 4, 9 → 2, 4, 7, 9.** Item constructed for this lesson from its founding chapter. Australia, *Essential Mathematics for the Victorian Curriculum Year 8, Third Edition* (Greenwood et al., Cambridge University Press, ©2024), Chapter 11 (Algorithmic thinking), Activity 2 — working with lists of data, printed p. ~929.

4. (Sub lesson 2) Put the steps of generating a list by simulation in order:
   use the list (sort it, search it, count its values) / record each result in the list / choose the chance action (roll a die) / repeat until the list is long enough
   **Answer: choose the chance action (roll a die) → record each result in the list → repeat until the list is long enough → use the list (sort it, search it, count its values).** Item constructed for this lesson from its founding chapter.
