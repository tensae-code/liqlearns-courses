# Latin squares — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — Latin squares — the rule and building first, then rearranging, then orthogonality and its scheduling use.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3 — each old layer is one sub lesson, in the same order.

## Sub lesson 1 — The Rule and Building a Latin Square
Sub lesson 1 questions from the type files. Pass mark: state the rule, check a grid against it, and build a Latin square of order 3 or 4 by shifting.

## Sub lesson 2 — Permuting Symbols, Rows and Columns
Sub lesson 2 questions from the type files. Pass mark: produce a new Latin square from a given one by renaming symbols or swapping rows/columns, and explain why it is still a Latin square.

## Sub lesson 3 — Orthogonal Latin Squares and Scheduling
Sub lesson 3 questions from the type files. Pass mark: test a pair of squares for orthogonality by their pairs, and set up the work-scheduling use of an orthogonal pair.
