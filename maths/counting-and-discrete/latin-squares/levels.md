# Latin squares — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — Latin squares — the rule and building first, then rearranging, then orthogonality and its scheduling use.

## Level 1 — the rule and building a Latin square
Level 1 questions from the type files. Pass mark: state the rule, check a grid against it, and build a Latin square of order 3 or 4 by shifting.

## Level 2 — permuting symbols, rows and columns
Level 2 questions from the type files. Pass mark: produce a new Latin square from a given one by renaming symbols or swapping rows/columns, and explain why it is still a Latin square.

## Level 3 — orthogonal Latin squares and scheduling
Level 3 questions from the type files. Pass mark: test a pair of squares for orthogonality by their pairs, and set up the work-scheduling use of an orthogonal pair.
