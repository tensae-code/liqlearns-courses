# Latin squares — true or false

Say true or false, and why.

**1. (Level 1)** A grid where every row has each symbol once is automatically a Latin square.
**Answer:** False — the columns must also have each symbol once (Iran, pp.62–71).

**2. (Level 2)** Swapping two columns of a Latin square can break the Latin-square rule.
**Answer:** False — rows still hold the same symbols, and each column still holds each symbol once (Iran, pp.62–71).

**3. (Level 3)** Iran's book constructs a pair of orthogonal Latin squares of order 5.
**Answer:** True — as filed, pp.62–71.

**4. (Level 3)** Euler's 1782 conjecture, in the book's reading note, concerns orders n = 4k + 2.
**Answer:** True — orders 6, 10, 14, …, as the reading note files it (Iran, pp.62–71).

**5. (Level 1)** Two different-looking Latin squares can have exactly the same pattern with renamed symbols.
**Answer:** True — permuting the symbols changes the dress, not the pattern (Iran, pp.62–71).
