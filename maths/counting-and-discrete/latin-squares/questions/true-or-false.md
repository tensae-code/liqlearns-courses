# Latin squares — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — The Rule and Building a Latin Square · (Level 2) -> Sub lesson 2 — Permuting Symbols, Rows and Columns · (Level 3) -> Sub lesson 3 — Orthogonal Latin Squares and Scheduling.

Say true or false, and why.

**1. (Sub lesson 1)** A grid where every row has each symbol once is automatically a Latin square.
**Answer:** False — the columns must also have each symbol once (Iran, pp.62–71).

**2. (Sub lesson 2)** Swapping two columns of a Latin square can break the Latin-square rule.
**Answer:** False — rows still hold the same symbols, and each column still holds each symbol once (Iran, pp.62–71).

**3. (Sub lesson 3)** Iran's book constructs a pair of orthogonal Latin squares of order 5.
**Answer:** True — as filed, pp.62–71.

**4. (Sub lesson 3)** Euler's 1782 conjecture, in the book's reading note, concerns orders n = 4k + 2.
**Answer:** True — orders 6, 10, 14, …, as the reading note files it (Iran, pp.62–71).

**5. (Sub lesson 1)** Two different-looking Latin squares can have exactly the same pattern with renamed symbols.
**Answer:** True — permuting the symbols changes the dress, not the pattern (Iran, pp.62–71).
