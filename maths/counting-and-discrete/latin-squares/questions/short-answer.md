# Latin squares — short answer

Answer in a word or a short line.

**1. (Level 1)** Complete the order-3 Latin square whose first row is A B C and second row is B C A. What is the third row?
**Answer:** C A B — each column still needs its missing symbol (Iran, pp.62–71).

**2. (Level 1)** A 4×4 grid has each symbol once in every row, but one column reads 1, 2, 1, 4. Is it a Latin square?
**Answer:** No — the column repeats 1 and misses 3 (Iran, pp.62–71).

**3. (Level 2)** Name two moves that turn a Latin square into another Latin square without breaking the rule.
**Answer:** Permuting (renaming) the symbols, and swapping two rows or two columns (Iran, pp.62–71).

**4. (Level 3)** In the scheduling application, what does one cell of the overlaid pair stand for?
**Answer:** One pairing — one worker with one partner/task combination, each occurring exactly once (Iran, pp.62–71).

**5. (Level 2)** A Latin square uses the symbols 1, 2, 3, 4. After the permutation 1→4, 2→3, 3→2, 4→1, what happens to a row that read 1 2 3 4?
**Answer:** It reads 4 3 2 1 — every symbol renamed everywhere (Iran, pp.62–71).
