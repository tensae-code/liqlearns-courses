# Latin squares — multiple choice

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — The Rule and Building a Latin Square · (Level 2) -> Sub lesson 2 — Permuting Symbols, Rows and Columns · (Level 3) -> Sub lesson 3 — Orthogonal Latin Squares and Scheduling.

Pick the one right answer.

**1. (Sub lesson 1)** A Latin square of order 4 uses how many symbols?
a) 16  b) 4  c) 8
**Answer:** b) 4 — order n means n symbols in an n×n grid (Iran, pp.62–71).

**2. (Sub lesson 1)** Which grid can be a Latin square's first two rows?
a) 1 2 3 / 1 2 3  b) 1 2 3 / 2 3 1  c) 1 2 3 / 2 1 2
**Answer:** b) — each column so far has no repeat, and each row holds 1, 2, 3 once (Iran, pp.62–71).

**3. (Sub lesson 2)** Renaming every A as C and every C as A in a Latin square gives…
a) a broken grid  b) still a Latin square  c) an orthogonal square
**Answer:** b) — permuting the symbols never breaks the rule (Iran, pp.62–71).

**4. (Sub lesson 3)** Two order-3 squares laid together give a repeated pair. The squares are…
a) orthogonal  b) not orthogonal  c) not Latin squares
**Answer:** b) — orthogonality needs all 9 pairs different (Iran, pp.62–71).

**5. (Sub lesson 2)** Swapping rows 1 and 2 of a Latin square gives…
a) still a Latin square  b) a broken grid  c) an orthogonal square
**Answer:** a) — whole rows move together, so both rules survive (Iran, pp.62–71).
