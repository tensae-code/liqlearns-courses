# Latin squares — ordering

Put the steps in the right order.

**1. (Level 1)** Order the shift construction for order 3: (a) write the first row A B C, (b) shift it to get C A B for the third row, (c) shift it to get B C A for the second row.
**Answer:** (a), (c), (b) (Iran, pp.62–71).

**2. (Level 3)** Order an orthogonality check: (a) list all the pairs, (b) lay one square on the other, (c) look for a repeated pair.
**Answer:** (b), (a), (c) (Iran, pp.62–71).
