# Hands-on — Latin squares

The lesson built Latin squares on squared paper, the way its one book teaches them.

## Build by sliding
On squared paper, build Latin squares of order 3, 4 and 5 by Iran's shift method (Discrete Mathematics, pp.62–71): first row in order, each next row shifted one step. Check every column before you go on.

## Rename and swap
Take your order-4 square. Rename the symbols by the swap A↔D, and write the new square. Then swap rows 1 and 3 of the original and write that square. Check both against the rule — permuting symbols, rows or columns never breaks a Latin square (pp.62–71).

## The overlay test
Copy your order-3 square in a second colour onto the same grid as a different order-3 square. Write the 9 pairs. Are they all different? If one pair repeats, change one square and test again — this is the book's orthogonality check (pp.62–71).
