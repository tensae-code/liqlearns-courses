# Short answer — Euler's Totient and Multiplicative Functions

1. (Layer 1) Find φ(8) by listing, and say what the list is a list of.
   **Answer: the numbers from 1 to 8 coprime to 8 are 1, 3, 5, 7, so φ(8) = 4; the list is a reduced residue system modulo 8.** North Macedonia, АЛГЕБРА ЗА ТРЕТА ГОДИНА (Grade 12, elective), §2.5, printed p. 37.

2. (Layer 3) Compute φ(20) using multiplicativity, and justify the split.
   **Answer: 20 = 4 × 5 with gcd(4, 5) = 1, so φ(20) = φ(4)·φ(5) = 2·4 = 8.** North Macedonia, АЛГЕБРА ЗА ТРЕТА ГОДИНА (Grade 12, elective), §2.5, printed p. 37.

3. (Layer 4) The book's Theorem 1 is printed without a hypothesis its proof uses. State the theorem correctly, and give the table counterexample to the printed version.
   **Answer: correctly: if gcd(m, n) = 1 then φ(m·n) = φ(m)·φ(n). The printed "for all m, n" fails at m = n = 2: φ(4) = 2 ≠ φ(2)·φ(2) = 1.** North Macedonia, АЛГЕБРА ЗА ТРЕТА ГОДИНА (Grade 12, elective), §2.5, printed p. 37.

4. (Layer 5) Compute φ(45) by splitting, using only values from the table φ(1)…φ(12).
   **Answer: 45 = 5 × 9 with gcd(5, 9) = 1, so φ(45) = φ(5)·φ(9) = 4·6 = 24.** North Macedonia, АЛГЕБРА ЗА ТРЕТА ГОДИНА (Grade 12, elective), §2.5, printed p. 37.
