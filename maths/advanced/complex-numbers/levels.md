# Complex Numbers — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the imaginary unit first, then operations, then the geometry of the complex plane.

## Level 1 — the imaginary unit and a + bi
Level 1 questions from the type files. Pass mark: write a complex number in algebraic form, name its parts, and work out powers of i.

## Level 2 — operations and conjugates
Level 2 questions from the type files. Pass mark: add, subtract, multiply and divide complex numbers, and find a conjugate.

## Level 3 — trigonometric form, De Moivre and loci
Level 3 questions from the type files. Pass mark: find modulus and argument, write the trigonometric form, use De Moivre, and describe a locus.
