# Barycentres — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — barycentres — two weighted points first, then a system of points with grouping, then the centroid and the balance meaning.

## Level 1 — the barycentre of two points
Level 1 questions from the type files. Pass mark: state the vector condition α·GA + β·GB = 0, find a two-point barycentre on a segment, and say why it sits nearer the heavier point; the equal-weights case gives the midpoint.

## Level 2 — a system of points and grouping
Level 2 questions from the type files. Pass mark: compute a three-point barycentre in coordinates with x_G = (αx_A + βx_B + γx_C)/(α + β + γ), and reach the same point by grouping two points first.

## Level 3 — the centroid and the balance point
Level 3 questions from the type files. Pass mark: find a triangle's centroid as the equal-weights barycentre, connect it to the medians, and explain the barycentre as a centre of mass.
