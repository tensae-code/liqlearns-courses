# Barycentres — ordering

Put the items in the order asked. Check each step before you write the answer.

**1. (Level 1)** Put these barycentres of A at 0 and B at 12 in order along the segment, nearest A first: weights (1, 3), weights (1, 1), weights (3, 1).
Answer in order, nearest A first.
**Answer:** weights (3, 1) → 3, then weights (1, 1) → 6, then weights (1, 3) → 9 — the point slides towards the heavier end (Laos, Grade 11, L33, printed p.249).

**2. (Level 2)** Put the grouping steps for A, B, C in order: (i) merge the grouped point with C (ii) compute the barycentre of A and B (iii) add the weights of A and B onto their barycentre.
Answer in order.
**Answer:** (ii), (iii), (i) (Laos, Grade 11, L34, printed p.254).

**3. (Level 3)** Put the lesson's builds in teaching order: system of points, two points, centroid of a triangle.
Answer in teaching order.
**Answer:** Two points first (L33), then a system of points (L34), with the centroid as the equal-weights case of the system (Laos, Grade 11, Ch.9, printed pp.249, 254).
