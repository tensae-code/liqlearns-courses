# True or false — Numerical Methods

1. (Layer 1) If f(a) and f(b) have the same sign, there is definitely no root between a and b. **False** — a function can cross twice (or touch) with no sign change; absence of a sign change proves nothing. Rwanda, Advanced Mathematics, Learner's Book, Senior Five, Unit 4, printed pp. 111–118.
2. (Layer 1) Extrapolation is generally less safe than interpolation. **True** — beyond the known points, nothing guarantees the curve follows the line. Rwanda, Advanced Mathematics, Learner's Book, Senior Five, Unit 4, printed pp. 105–112.
3. (Layer 3) If fixed-point iteration settles on a value, that value satisfies the original equation. **True** — a settled value satisfies x = g(x), which is the equation rearranged. Rwanda, Advanced Mathematics, Learner's Book, Senior Five, Unit 4, printed pp. 122–126.
