# True or false — Numerical Methods

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Layer 1) -> Sub lesson 1 — Estimate and Locate · (Layer 2) -> Sub lesson 2 — Newton–Raphson · (Layer 3) -> Sub lesson 3 — Fixed-Point Iteration.

1. (Sub lesson 1) If f(a) and f(b) have the same sign, there is definitely no root between a and b. **False** — a function can cross twice (or touch) with no sign change; absence of a sign change proves nothing. Rwanda, Advanced Mathematics, Learner's Book, Senior Five, Unit 4, printed pp. 111–118.
2. (Sub lesson 1) Extrapolation is generally less safe than interpolation. **True** — beyond the known points, nothing guarantees the curve follows the line. Rwanda, Advanced Mathematics, Learner's Book, Senior Five, Unit 4, printed pp. 105–112.
3. (Sub lesson 3) If fixed-point iteration settles on a value, that value satisfies the original equation. **True** — a settled value satisfies x = g(x), which is the equation rearranged. Rwanda, Advanced Mathematics, Learner's Book, Senior Five, Unit 4, printed pp. 122–126.
