# Vectors — ordering

Put each set in order, as the question says.

**1. (Level 1)** Order these magnitudes from smallest to largest: |(3, 4)|, |(1, 1)|, |(6, 8)|.
**Answer:** |(1, 1)| = √2 ≈ 1.41, |(3, 4)| = 5, |(6, 8)| = 10.

**2. (Level 2)** Order the steps for adding two vectors: join the second tail to the first head; draw the sum from the first tail to the last head; draw both arrows.
**Answer:** Draw both arrows; join the second tail to the first head; draw the sum from the first tail to the last head.

**3. (Level 3)** Order these dot products from smallest to largest, for vectors of size 2 and 3: angle 90°, angle 0°, angle 60°.
**Answer:** 90°: 0; 60°: 2 × 3 × 1/2 = 3; 0°: 2 × 3 × 1 = 6.
