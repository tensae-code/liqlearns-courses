# Vectors — multiple choice

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Arrows: Size and Direction · (Level 2) -> Sub lesson 2 — Coordinates and the Dot Product · (Level 3) -> Sub lesson 3 — Vectors in Space.

Pick the one right answer.

**1. (Sub lesson 1)** A vector has ______.
a) size only  b) size and direction  c) direction only
**Answer: b) size and direction.**

**2. (Sub lesson 1)** Temperature is a ______.
a) vector  b) scalar  c) matrix
**Answer: b) scalar** — size only, no direction.

**3. (Sub lesson 2)** The magnitude of (3, 4) is ______.
a) 7  b) 5  c) 12
**Answer: b) 5** — √(9 + 16).

**4. (Sub lesson 2)** Two vectors are equal when they have ______.
a) the same magnitude only  b) the same magnitude and the same direction  c) the same starting point
**Answer: b) the same magnitude and the same direction.**

**5. (Sub lesson 3)** The dot product of two perpendicular vectors is ______.
a) 1  b) 0  c) their sum
**Answer: b) 0** — cos 90° = 0.

**6. (Sub lesson 3)** The cross product a × b is ______.
a) a number  b) a vector perpendicular to both a and b  c) always zero
**Answer: b) a vector perpendicular to both a and b** (Egypt, Pure Grade 12, 3-3).
