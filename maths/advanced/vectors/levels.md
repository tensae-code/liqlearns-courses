# Vectors — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — arrows on the ground first, then coordinates and the dot product, then vectors in space.

## Level 1 — arrows: size and direction
Level 1 questions from the type files. Pass mark: tell a scalar from a vector, draw a vector, and find its magnitude.

## Level 2 — coordinates and the dot product
Level 2 questions from the type files. Pass mark: write vectors in coordinates, add and subtract them, and find a dot product and an angle.

## Level 3 — vectors in space
Level 3 questions from the type files. Pass mark: work with 3-D coordinates, lines in space, and the cross product.
