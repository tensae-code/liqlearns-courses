# Conic Sections — ordering

Put the items in the right order.

**1. (Level 1)** Order the cone cuts as the cutting plane tilts further from level: hyperbola (through both halves), circle, parabola, ellipse.
**Answer:** circle; ellipse; parabola; hyperbola — the tilt order of the cone-cutting opening.

**2. (Level 1)** Order the steps for reading a conic off its equation: find the foci and e; read a and b from the denominators; read the sign between the squares.
**Answer:** read the sign first; then a and b; then the foci and e.

**3. (Level 2)** Order by eccentricity, smallest first: hyperbola with e = 5/4; ellipse with e = 4/5; parabola.
**Answer:** ellipse (4/5); parabola (1); hyperbola (5/4).

**4. (Level 2)** For x²/25 + y²/9 = 1, order a, b and c from smallest to largest.
**Answer:** b = 3; c = 4; a = 5 — for an ellipse a is the biggest.

**5. (Level 3)** For x²/16 − y²/9 = 1, order a, b and c from smallest to largest.
**Answer:** b = 3; a = 4; c = 5 — for a hyperbola c is the biggest.
