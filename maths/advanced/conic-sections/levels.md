# Conic Sections — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
conic sections — the cone and the one locus definition first, then the parabola, then the ellipse and the hyperbola with their elements, then translated conics, tangents and classification.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — The Cone, the Locus Definition and the Parabola
Sub lesson 1 questions from the type files. Pass mark: name each conic from its cone cut and from its value of e in MF/MH = e, and write a parabola y² = 4cx with its focus, directrix and latus rectum.

## Sub lesson 2 — The Ellipse and the Hyperbola
Sub lesson 2 questions from the type files. Pass mark: for x²/a² + y²/b² = 1 and x²/a² − y²/b² = 1 find a, b, c, the foci, the vertices, the eccentricity and, for the hyperbola, the asymptotes — using the corrected values where a book printed a slip.

## Sub lesson 3 — Moving, Turning and Classifying Conics
Sub lesson 3 questions from the type files. Pass mark: read and write translated conics, say what translation and rotation of axes do, find a tangent or normal at a point, and classify a conic from its general second-degree equation.
