# Quaternions — ordering

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — The Form and the Defining Rules · (Level 2) -> Sub lesson 2 — Addition and the Multiplication Table · (Level 3) -> Sub lesson 3 — Conjugate and Modulus.

Put the items in the order asked. Check each step before you write the answer.

**1. (Sub lesson 1)** Put the number systems in widening order: quaternions, real numbers, complex numbers.
Answer in order, narrowest first.
**Answer:** Real numbers, then complex numbers, then quaternions — each step adds imaginary parts (China, B-edition Vol. 4, extended reading, printed pp.47–48).

**2. (Sub lesson 2)** Put the cycle products in cycle order starting from ij: ki, ij, jk.
Answer in cycle order.
**Answer:** ij = k, then jk = i, then ki = j (China, B-edition Vol. 4, extended reading, printed pp.47–48).

**3. (Sub lesson 3)** Put the steps for multiplying (1 + j)(1 + i) in order: (i) expand the brackets (ii) replace ji by −k (iii) collect the parts (iv) compare with (1 + i)(1 + j).
Answer in order.
**Answer:** (i), (ii), (iii), (iv) — the comparison is what shows non-commutativity (China, B-edition Vol. 4, extended reading, printed pp.47–48).
