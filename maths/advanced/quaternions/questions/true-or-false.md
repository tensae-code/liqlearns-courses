# Quaternions — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** Every quaternion is a complex number.
**Answer:** False — a quaternion has three imaginary parts; a complex number is the special case with c = d = 0 (China, B-edition Vol. 4, extended reading, printed pp.47–48).

**2. (Level 1)** i, j and k are three names for the same unit.
**Answer:** False — they are three separate units, each squaring to −1 (China, B-edition Vol. 4, extended reading, printed pp.47–48).

**3. (Level 2)** ij = ji.
**Answer:** False — ij = k and ji = −k (China, B-edition Vol. 4, extended reading, printed pp.47–48).

**4. (Level 2)** Adding quaternions is commutative.
**Answer:** True — addition goes part by part, and real addition commutes; it is multiplication that does not (China, B-edition Vol. 4, extended reading, printed pp.47–48).
