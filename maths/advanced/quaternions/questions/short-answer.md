# Quaternions — short answer

Answer in a word or a short line. All questions trace to China, B-edition Compulsory Volume 4, Ch.10 extended reading, printed pp.47–48.

**1. (Level 1)** Write a quaternion with real part 2 and imaginary parts 1, 0, −3.
**Answer:** 2 + i + 0j − 3k, i.e. 2 + i − 3k.

**2. (Level 1)** State the three defining square rules.
**Answer:** i² = j² = k² = −1.

**3. (Level 2)** Give jk and kj.
**Answer:** jk = i, kj = −i.

**4. (Level 2)** Subtract (4 + j) from (4 + 2i + j + k).
**Answer:** 2i + k — part by part.

**5. (Level 3)** Multiply (1 + i)(1 + j) in full.
**Answer:** 1 + i + j + k — since ij = k.
