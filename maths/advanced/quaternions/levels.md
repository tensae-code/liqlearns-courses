# Quaternions — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — quaternions — the form and the defining rules first, then addition and the multiplication table, then non-commutativity worked and the conjugate and modulus. All questions trace to the lesson's only source, the extended reading in China's B-edition Compulsory Volume 4 (Ch.10, pp.47–48).

## Level 1 — the form and the defining rules
Level 1 questions from the type files. Pass mark: write a quaternion as a + bi + cj + dk, name its four parts, and state i² = j² = k² = −1.

## Level 2 — addition and the multiplication table
Level 2 questions from the type files. Pass mark: add and subtract quaternions part by part, and give the products ij, jk, ki and their reversals with correct signs.

## Level 3 — non-commutativity, conjugate and modulus
Level 3 questions from the type files. Pass mark: show with a worked pair that quaternion multiplication is non-commutative, multiply two short quaternions in both orders, and form a conjugate and a modulus.
