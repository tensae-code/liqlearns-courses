# Quaternions — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
quaternions — the form and the defining rules first, then addition and the multiplication table, then non-commutativity worked and the conjugate and modulus. All questions trace to the lesson's only source, the extended reading in China's B-edition Compulsory Volume 4 (Ch.10, pp.47–48).

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — The Form and the Defining Rules
Sub lesson 1 questions from the type files. Pass mark: write a quaternion as a + bi + cj + dk, name its four parts, and state i² = j² = k² = −1.

## Sub lesson 2 — Addition and the Multiplication Table
Sub lesson 2 questions from the type files. Pass mark: add and subtract quaternions part by part, and give the products ij, jk, ki and their reversals with correct signs.

## Sub lesson 3 — Conjugate and Modulus
Sub lesson 3 questions from the type files. Pass mark: show with a worked pair that quaternion multiplication is non-commutative, multiply two short quaternions in both orders, and form a conjugate and a modulus.
