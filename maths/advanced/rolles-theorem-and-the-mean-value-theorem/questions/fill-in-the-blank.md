# Rolle's theorem and the Mean Value Theorem — fill in the blank

Fill each blank with the one right word or number.

**1. (Level 1)** Rolle's theorem guarantees a point c with f′(c) = ______.
**Answer:** 0 — the tangent is flat at c.

**2. (Level 1)** The point c must lie ______ the interval (a, b).
**Answer:** strictly inside — endpoints never count.

**3. (Level 2)** In the Mean Value Theorem, the tangent at c is ______ to the chord joining the endpoints.
**Answer:** parallel — equal slopes is what the theorem says.

**4. (Level 2)** If f′ is 0 everywhere on an interval, the Mean Value Theorem shows f is ______ there.
**Answer:** constant — every chord has slope 0, so f never changes.

**5. (Level 3)** L'Hôpital's rule replaces f/g by ______ in the limit.
**Answer:** f′/g′ — the quotient of the derivatives, for 0/0 and ∞/∞ forms.

**6. (Level 3)** The 0/0 case of L'Hôpital's rule is proved in Cambodia's PRIVATE booklet from Cauchy's extended ______ Theorem.
**Answer:** Mean Value — the generalisation of this lesson's second theorem (pp.53–54).
