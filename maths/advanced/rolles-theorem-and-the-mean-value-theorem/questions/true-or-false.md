# Rolle's theorem and the Mean Value Theorem — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Rolle's Theorem · (Level 2) -> Sub lesson 2 — The Mean Value Theorem · (Level 3) -> Sub lesson 3 — Proofs and L'Hôpital's Rule.

Say true or false, and why.

**1. (Sub lesson 1)** |x| on [−1, 1] satisfies all of Rolle's conditions.
**Answer:** False — it is continuous with equal endpoint values but not differentiable at 0, and indeed has no flat tangent.

**2. (Sub lesson 1)** Rolle's theorem is the Mean Value Theorem's special case f(a) = f(b).
**Answer:** True — equal endpoints make the chord slope 0.

**3. (Sub lesson 2)** The Mean Value Theorem guarantees c could be an endpoint.
**Answer:** False — c is strictly inside (a, b).

**4. (Sub lesson 2)** Yemen teaches Rolle and the Mean Value Theorem in Grade 12 Science, lesson 6-7.
**Answer:** True — Unit 6, 6-7, contents/PDF p.183 (the footer reads 184).

**5. (Sub lesson 3)** L'Hôpital's rule can be applied to any limit whatsoever.
**Answer:** False — only 0/0 and ∞/∞ directly; other indeterminate forms are reduced to quotients first.

**6. (Sub lesson 3)** Iraq's Grade 12 Scientific lesson [3-2] is a source for this lesson.
**Answer:** False — it is unverified and is cited nowhere in this lesson.
