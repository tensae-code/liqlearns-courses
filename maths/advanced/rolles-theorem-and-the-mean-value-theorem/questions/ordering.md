# Rolle's theorem and the Mean Value Theorem — ordering

Put the steps or values in the right order.

**1. (Level 1)** Order the Rolle check: (a) verify f(a) = f(b); (b) verify continuity on [a, b]; (c) solve f′(c) = 0; (d) verify differentiability on (a, b).
**Answer:** (b), (d), (a), (c) — conditions first, then the point the theorem promises.

**2. (Level 3)** Order the MVT proof: (a) apply Rolle to the auxiliary function; (b) build the auxiliary function by subtracting the chord's line; (c) read off f′(c) = chord slope.
**Answer:** (b), (a), (c) — tilt first, then Rolle does the work (Cambodia, PRIVATE booklet, pp.50–52).

**3. (Level 2)** Order the MVT use on x², [1, 3]: (a) set 2x = 4; (b) compute the chord slope 4; (c) solve for c = 2; (d) check c is inside.
**Answer:** (b), (a), (c), (d).

**4. (Level 1)** Order the proof chain: (a) the Mean Value Theorem; (b) Rolle's theorem; (c) an interior extreme point has derivative zero.
**Answer:** (c), (b), (a) — the extreme-point fact proves Rolle, and Rolle proves the Mean Value Theorem.

**5. (Level 3)** Order the L'Hôpital steps: (a) check the form is 0/0 or ∞/∞; (b) differentiate top and bottom separately; (c) take the new limit.
**Answer:** (a), (b), (c) — the form check always comes first.

**6. (Level 2)** Order a journey's speeds: average 60 km/h; the MVT moment; the trip's endpoints in time. Sequence: (a) start; (b) the guaranteed moment strictly inside; (c) finish.
**Answer:** (a), (b), (c) — the guaranteed c is never an endpoint.
