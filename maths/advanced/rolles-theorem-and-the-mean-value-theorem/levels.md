# Rolle's theorem and the Mean Value Theorem — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — Rolle first, then the Mean Value Theorem, then L'Hôpital's rule.

## Level 1 — Rolle's theorem
Level 1 questions from the type files. Pass mark: state Rolle's three conditions and find the guaranteed point c on a polynomial.

## Level 2 — the Mean Value Theorem
Level 2 questions from the type files. Pass mark: state the theorem, check its two conditions, and solve for c on a given interval.

## Level 3 — proofs and L'Hôpital's rule
Level 3 questions from the type files. Pass mark: outline the proof of the Mean Value Theorem from Rolle's theorem, and apply L'Hôpital's rule to 0/0 and ∞/∞ forms, reducing other forms first.
