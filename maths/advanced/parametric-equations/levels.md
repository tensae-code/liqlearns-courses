# Parametric Equations — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — parametric curves — plotting and eliminating first, then circles, ellipses and slope, then the projectile worked whole.

## Level 1 — plotting and eliminating the parameter
Level 1 questions from the type files. Pass mark: build a table for x = f(t), y = g(t), plot the points, and eliminate t to get a Cartesian equation, as in x = t, y = t² → y = x².

## Level 2 — circles, ellipses and the slope
Level 2 questions from the type files. Pass mark: read a parametric circle or ellipse (centre, radii, Cartesian form), and find dy/dx as (dy/dt)/(dx/dt).

## Level 3 — projectile motion
Level 3 questions from the type files. Pass mark: work Cambodia's projectile whole with v₀ = 48 cm/s taught corrected — position at a given t, the path y = −x²/72 + x, and the landing point.
