# Parametric Equations — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Plotting and Eliminating the Parameter · (Level 2) -> Sub lesson 2 — Circles, Ellipses and the Slope · (Level 3) -> Sub lesson 3 — Projectile Motion.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** A parametric curve keeps the direction of travel; its Cartesian equation does not.
**Answer:** True — eliminating t keeps the shape and drops the journey (Cambodia, Grade 12 Advanced, Ch.9, printed p.235).

**2. (Sub lesson 1)** The same formulas x = t, y = t² always draw the whole parabola, whatever the t-interval.
**Answer:** False — with t ≥ 0 only the right half is drawn; the interval is part of the description (Cambodia, Grade 12 Advanced, Ch.9, printed p.235).

**3. (Sub lesson 2)** A circle can be given by one parametric pair but not by one equation y = f(x).
**Answer:** True — a circle is not a function of x, but θ walks it whole (Cambodia, Grade 12 Advanced guide, printed pp.227–236).

**4. (Sub lesson 2)** dy/dx for a parametric curve is dy/dt on its own.
**Answer:** False — it is (dy/dt)/(dx/dt) (Cambodia, Grade 12 Advanced, Ch.9, printed pp.235–252).

**5. (Sub lesson 3)** The Cambodia teacher guide's v₀ = 45 cm/s is the value to teach for the projectile.
**Answer:** False — teach 48 cm/s: the path y = −x²/72 + x requires 48 with g = 32 cm/s² (Cambodia, Grade 12 Advanced, §9.1, printed p.236, taught corrected).

**6. (Sub lesson 3)** At t = 0, Cambodia's projectile is at the origin.
**Answer:** True — x = 0 and y = 0 (Cambodia, Grade 12 Advanced, §9.1, printed p.236).
