# Continuity — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — continuity — the three conditions first, then the kinds of break, then intervals and theorems.

## Level 1 — the three conditions
Level 1 questions from the type files. Pass mark: state the three conditions and run the full test at a point, naming the condition that fails.

## Level 2 — removable and jump discontinuities
Level 2 questions from the type files. Pass mark: tell a removable break from a jump break from the one-sided limits, and repair a removable break by redefining one point.

## Level 3 — continuity on an interval and the theorems
Level 3 questions from the type files. Pass mark: decide continuity on open and closed intervals, use the continuity theorems, and use the Intermediate Value Theorem to place a root.
