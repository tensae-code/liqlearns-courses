# Continuity — ordering

Put the steps or values in the right order.

**1. (Level 1)** Order the three-condition test: (a) compare f(a) with the limit; (b) find f(a); (c) find the two-sided limit.
**Answer:** (b), (c), (a) — value, then limit, then equality (Laos, pp.166–175).

**2. (Level 1)** Order the diagnosis: (a) name the kind of break; (b) compute both one-sided limits; (c) check f(a).
**Answer:** (c), (b), (a) — or any order that checks all three; the first failure found names the break.

**3. (Level 2)** Order by repairability, easiest first: (a) jump; (b) misplaced point; (c) hole.
**Answer:** (c), (b), (a) — hole and misplaced point take one value each; a jump takes none.

**4. (Level 2)** For x + a (x < 1) / 3x (x ≥ 1), order the steps: (a) solve 1 + a = 3; (b) find the left limit 1 + a; (c) find the right value 3.
**Answer:** (b), (c), (a) — set the sides equal and solve: a = 2.

**5. (Level 3)** Order the IVT root proof: (a) check f is continuous on [a, b]; (b) compute f(a) and f(b); (c) note the signs differ; (d) conclude a root lies between.
**Answer:** (a), (b), (c), (d) — continuity first, then the sign change does the work.

**6. (Level 3)** Order the interval check on [0, 4]: (a) right-hand test at 0; (b) three-condition test inside; (c) left-hand test at 4.
**Answer:** (b) with (a) and (c) at the ends — interior two-sided, endpoints one-sided (Kuwait, pp.61–71).
