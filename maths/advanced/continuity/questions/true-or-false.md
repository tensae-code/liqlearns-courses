# Continuity — true or false

Say true or false, and why.

**1. (Level 1)** If f(a) exists and the limit at a exists, f must be continuous at a.
**Answer:** False — they must also be equal; a point at the wrong height breaks continuity.

**2. (Level 2)** Every jump discontinuity can be repaired by redefining one point.
**Answer:** False — the sides disagree, so no single value can meet both.

**3. (Level 2)** (x² − 1)/(x − 1) is discontinuous at x = 1, and the break is removable.
**Answer:** True — the limit is 2 and only the point is missing.

**4. (Level 3)** A rational function is continuous everywhere.
**Answer:** False — only where it is defined; at a zero of the denominator it breaks (Kuwait, 1-6).

**5. (Level 3)** sin x is continuous at every real point.
**Answer:** True — Yemen's Grade 12 Science book opens with continuity of the trigonometric functions (6-1, p.154).

**6. (Level 1)** Nepal's book finds (x² + x − 6)/(x + 3) continuous at x = −3 because its limit exists.
**Answer:** False — f(−3) is undefined there, so it is discontinuous; the limit alone is not enough.
