# Continuity — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — The Three Conditions · (Level 2) -> Sub lesson 2 — Removable and Jump Discontinuities · (Level 3) -> Sub lesson 3 — Continuity on an Interval and the Theorems.

Say true or false, and why.

**1. (Sub lesson 1)** If f(a) exists and the limit at a exists, f must be continuous at a.
**Answer:** False — they must also be equal; a point at the wrong height breaks continuity.

**2. (Sub lesson 2)** Every jump discontinuity can be repaired by redefining one point.
**Answer:** False — the sides disagree, so no single value can meet both.

**3. (Sub lesson 2)** (x² − 1)/(x − 1) is discontinuous at x = 1, and the break is removable.
**Answer:** True — the limit is 2 and only the point is missing.

**4. (Sub lesson 3)** A rational function is continuous everywhere.
**Answer:** False — only where it is defined; at a zero of the denominator it breaks (Kuwait, 1-6).

**5. (Sub lesson 3)** sin x is continuous at every real point.
**Answer:** True — Yemen's Grade 12 Science book opens with continuity of the trigonometric functions (6-1, p.154).

**6. (Sub lesson 1)** Nepal's book finds (x² + x − 6)/(x + 3) continuous at x = −3 because its limit exists.
**Answer:** False — f(−3) is undefined there, so it is discontinuous; the limit alone is not enough.
