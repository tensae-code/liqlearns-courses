# Integrals — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — antiderivatives first, then the methods, then definite integrals, areas and volumes.

## Level 1 — antiderivatives
Level 1 questions from the type files. Pass mark: find an antiderivative and write the indefinite integral with its + C.

## Level 2 — methods of integration
Level 2 questions from the type files. Pass mark: integrate by substitution, by partial fractions and by parts.

## Level 3 — definite integrals, areas and volumes
Level 3 questions from the type files. Pass mark: find a definite integral by Newton–Leibniz, and use it for areas and volumes of revolution.
