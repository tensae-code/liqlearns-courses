# Integrals — multiple choice

Pick the one right answer.

**1. (Level 1)** An antiderivative of 2x is ______.
a) x² + C  b) 2  c) x + C
**Answer: a) x² + C** — differentiating x² gives 2x.

**2. (Level 1)** The indefinite integral always carries ______.
a) a definite number  b) the constant + C  c) no constant
**Answer: b) the constant + C.**

**3. (Level 2)** ∫ 3x² dx = ______.
a) x³ + C  b) 6x + C  c) 3x³ + C
**Answer: a) x³ + C.**

**4. (Level 2)** ∫ 1/x dx = ______.
a) ln x + C  b) 1/x² + C  c) eˣ + C
**Answer: a) ln x + C.**

**5. (Level 3)** ∫₀² x² dx = ______.
a) 4  b) 8/3  c) 8
**Answer: b) 8/3** — F(2) − F(0) = 8/3 − 0.

**6. (Level 3)** The definite integral ∫ₐᵇ f(x)dx is ______.
a) a family of functions  b) a number  c) always zero
**Answer: b) a number** — F(b) − F(a).
