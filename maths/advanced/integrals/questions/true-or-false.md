# Integrals — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** ∫ 2x dx = x².
**False** — it is x² + C; the constant is part of the answer.

**2. (Level 1)** Differentiation and integration undo each other.
**True** — that is the fundamental link.

**3. (Level 2)** ∫ sin x dx = −cos x + C.
**True** — differentiating −cos x gives sin x.

**4. (Level 2)** Integration by parts is for products.
**True** — ∫u dv = uv − ∫v du.

**5. (Level 3)** ∫₀² x² dx = 8.
**False** — it is 8/3 (F(2) = 8/3, F(0) = 0).

**6. (Level 3)** The area under a curve can be found by adding thin rectangles.
**True** — the rectangles become the integral as they grow thinner (Greece, Grade 12 Analysis, Chapter 3).
