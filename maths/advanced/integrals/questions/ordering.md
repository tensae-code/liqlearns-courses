# Integrals — ordering

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Antiderivatives · (Level 2) -> Sub lesson 2 — Methods of Integration · (Level 3) -> Sub lesson 3 — Definite Integrals, Areas and Volumes.

Put each set in order, as the question says.

**1. (Sub lesson 1)** Order these integrals from smallest to largest: ∫₀¹ x² dx, ∫₀¹ x dx, ∫₀¹ 1 dx.
**Answer:** ∫₀¹ x² dx = 1/3, ∫₀¹ x dx = 1/2, ∫₀¹ 1 dx = 1.

**2. (Sub lesson 2)** Order the steps for a definite integral: work out F(b) − F(a); find the antiderivative F; read the bounds a and b.
**Answer:** Read the bounds a and b; find the antiderivative F; work out F(b) − F(a).

**3. (Sub lesson 3)** Order these from the books' teaching order: definite integral, indefinite integral, methods of integration.
**Answer:** Indefinite integral, methods of integration, definite integral — Egypt's Grade 12 book teaches 3-1, then 3-2, then 3-3.
