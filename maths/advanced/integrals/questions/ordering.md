# Integrals — ordering

Put each set in order, as the question says.

**1. (Level 1)** Order these integrals from smallest to largest: ∫₀¹ x² dx, ∫₀¹ x dx, ∫₀¹ 1 dx.
**Answer:** ∫₀¹ x² dx = 1/3, ∫₀¹ x dx = 1/2, ∫₀¹ 1 dx = 1.

**2. (Level 2)** Order the steps for a definite integral: work out F(b) − F(a); find the antiderivative F; read the bounds a and b.
**Answer:** Read the bounds a and b; find the antiderivative F; work out F(b) − F(a).

**3. (Level 3)** Order these from the books' teaching order: definite integral, indefinite integral, methods of integration.
**Answer:** Indefinite integral, methods of integration, definite integral — Egypt's Grade 12 book teaches 3-1, then 3-2, then 3-3.
