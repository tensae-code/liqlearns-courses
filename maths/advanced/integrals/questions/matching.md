# Integrals — matching

Match each left side to its right side.

**Set (Level 1)** — undoing
1. 2x — **x² + C**
2. 3x² — **x³ + C**
3. cos x — **sin x + C**
4. eˣ — **eˣ + C**

**Set (Level 2)** — methods
1. substitution — **see the inner derivative**
2. partial fractions — **split the fraction first**
3. parts — **∫u dv = uv − ∫v du**
4. standard table — **∫xⁿ dx = xⁿ⁺¹/(n+1) + C**

**Set (Level 3)** — uses
1. area under a curve — **∫ₐᵇ f(x)dx**
2. area between curves — **integral of the difference**
3. volume of revolution — **π∫ (f(x))² dx**
4. F(x) = ∫f(t)dt — **the area function**
