# Integrals — short answer

Answer in a word or a short line.

**1. (Level 1)** Find ∫ 3x² dx.
**Answer:** x³ + C.

**2. (Level 1)** Find ∫ eˣ dx.
**Answer:** eˣ + C.

**3. (Level 2)** Find ∫₀¹ x dx.
**Answer:** 1/2.

**4. (Level 2)** Use substitution: ∫ 2x(x² + 1)³ dx.
**Answer:** (x² + 1)⁴/4 + C (u = x² + 1).

**5. (Level 3)** Find the area between y = x² and y = x from 0 to 1.
**Answer:** 1/6 (∫₀¹ (x − x²) dx = 1/2 − 1/3).
