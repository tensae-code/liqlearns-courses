# Matrices — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — what a matrix is first, then adding and multiplying, then determinants, inverses and solving systems.

## Level 1 — what a matrix is
Level 1 questions from the type files. Pass mark: name a matrix's order, recognise the special matrices, and add matrices of the same order.

## Level 2 — multiplication and determinants
Level 2 questions from the type files. Pass mark: multiply two matrices when it is defined, and find 2 × 2 and 3 × 3 determinants.

## Level 3 — inverses and solving systems
Level 3 questions from the type files. Pass mark: find a 2 × 2 inverse, solve a system by inverse matrix and by Cramer's rule, and use the Gauss method.
