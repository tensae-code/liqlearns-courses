# Matrices — ordering

Put each set in order, as the question says.

**1. (Level 1)** Order these matrices from smallest order to largest: 3 × 3, 1 × 4, 2 × 2.
**Answer:** 2 × 2 (4 entries), 1 × 4 (4 entries), 3 × 3 (9 entries) — the first two tie at 4 entries.

**2. (Level 2)** Order the steps for multiplying AB: take a row of A and a column of B; multiply the pairs and add; put the answer in the matching place.
**Answer:** Take a row of A and a column of B; multiply the pairs and add; put the answer in the matching place.

**3. (Level 3)** Order the steps for solving by inverse matrix: write the system as Ax = b; find A⁻¹; multiply x = A⁻¹b.
**Answer:** Write the system as Ax = b; find A⁻¹; multiply x = A⁻¹b.
