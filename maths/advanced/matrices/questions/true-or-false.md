# Matrices — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — What a Matrix Is · (Level 2) -> Sub lesson 2 — Multiplication and Determinants · (Level 3) -> Sub lesson 3 — Inverses and Solving Systems.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** Two matrices can be added only if they have the same order.
**True** — addition is entry by entry, so the shapes must match.

**2. (Sub lesson 1)** The transpose of a 2 × 3 matrix is 3 × 2.
**True** — rows become columns.

**3. (Sub lesson 2)** Matrix multiplication is commutative: AB = BA always.
**False** — AB is usually not BA, and sometimes one of them is not defined.

**4. (Sub lesson 2)** A 2 × 3 matrix can multiply a 3 × 4 matrix.
**True** — the middle numbers match (3 = 3).

**5. (Sub lesson 3)** If det A = 0, then A has an inverse.
**False** — a zero determinant means no inverse.

**6. (Sub lesson 3)** The Gauss method solves a linear system by row operations.
**True** — Mauritania, 7AS-C, Chapter 1.
