# Matrices — matching

Match each left side to its right side.

**Set (Level 1)** — words
1. order m × n — **m rows and n columns**
2. transpose — **rows become columns**
3. unit matrix — **ones on the diagonal, zeros elsewhere**
4. zero matrix — **every entry is zero**

**Set (Level 2)** — operations
1. A + B — **entry by entry, same order**
2. AB defined — **columns of A = rows of B**
3. det [[a, b], [c, d]] — **ad − bc**
4. A × A⁻¹ — **the unit matrix**

**Set (Level 3)** — solving
1. inverse matrix — **solve by A⁻¹b**
2. Cramer's rule — **ratios of determinants**
3. Gauss method — **row operations to a triangle**
