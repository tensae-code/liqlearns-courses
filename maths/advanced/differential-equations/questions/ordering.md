# Differential Equations — ordering

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. Put each set in order, as the question says.

**1. (Sub lesson 1)** Order these from the books' teaching order: differential equations, definite integrals, indefinite integrals.
**Answer:** Indefinite integrals, definite integrals, differential equations — Jordan's Grade 12 book teaches differential equations as the last lesson of its integration unit.

**2. (Sub lesson 2)** Order the steps for solving dy/dx = 2x: integrate both sides; write dy = 2x dx; write y = x² + C.
**Answer:** Write dy = 2x dx; integrate both sides; write y = x² + C.

**3. (Sub lesson 3)** Order the steps for finding the particular solution: use the point to find C; solve for the general solution; write the one curve.
**Answer:** Solve for the general solution; use the point to find C; write the one curve.
