# Differential Equations — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** dy/dx = 2x is a differential equation.
**True** — it holds a derivative.

**2. (Level 1)** A first-order equation holds a second derivative.
**False** — first order means the highest derivative is the first.

**3. (Level 2)** Separating means getting all the y's on one side and all the x's on the other.
**True** — that is the separable form (Greece, Grade 12 Analysis, Chapter 3).

**4. (Level 2)** The general solution of dy/dx = 2x is y = x².
**False** — it is y = x² + C; without the constant it is one curve, not the family.

**5. (Level 3)** An initial condition finds the constant C.
**True** — the point the curve passes through fixes C.

**6. (Level 3)** Checking a solution means differentiating it and putting it back in the equation.
**True** — if it fits, the answer is right.
