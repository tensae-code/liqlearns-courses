# Differential Equations — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — what a differential equation is first, then separating and integrating, then initial conditions and checking.

## Level 1 — what a differential equation is
Level 1 questions from the type files. Pass mark: say what a differential equation is, name its order, and recognise a separable first-order equation.

## Level 2 — separating and integrating
Level 2 questions from the type files. Pass mark: separate the variables and solve by integrating both sides, with the + C.

## Level 3 — initial conditions and checking
Level 3 questions from the type files. Pass mark: use an initial condition to find the particular solution, and check a solution by differentiating it back.
