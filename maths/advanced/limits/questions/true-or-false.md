# Limits — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — The Limit Idea and One-Sided Limits · (Level 2) -> Sub lesson 2 — Computing Limits · (Level 3) -> Sub lesson 3 — Infinity, Sequences, the Sandwich Theorem and ε-δ.

Say true or false, and why.

**1. (Sub lesson 1)** If lim(x→a) f(x) exists, then f(a) must equal that limit.
**Answer:** False — the limit is about values near a; f(a) may differ or not exist, as (x² − 1)/(x − 1) at x = 1 shows.

**2. (Sub lesson 1)** If the left-hand and right-hand limits at a are different, the two-sided limit does not exist.
**Answer:** True — both sides must agree (Libya, Grade 11 Science, Ch.5).

**3. (Sub lesson 2)** 0/0 is a value of a limit.
**Answer:** False — 0/0 is an indeterminate form, a signpost to factorise or rationalise.

**4. (Sub lesson 2)** Direct substitution works for every polynomial limit at a finite point.
**Answer:** True — polynomials are built from the limit theorems; e.g. lim(x→2) (4x³ + x − 4) = 30.

**5. (Sub lesson 3)** Kuwait's book correctly prints cos x/x at x = 100 as −0.00862.
**Answer:** False — taught corrected: the value is +0.00862; the p.47 table drops the sign.

**6. (Sub lesson 3)** Pakistan's Grade 12 book correctly prints its p.25 limit at infinity as ∞.
**Answer:** False — taught corrected: that limit is −∞.

**7. (Sub lesson 1)** Jordan's Grade 11 limits evidence in this lesson comes only from an exercise book, never from a student book.
**Answer:** False — Jordan's held Grade 11 Term 1 student book teaches Limits and continuity itself (Unit 2, p.50); the orphan exercise book (Unit 3, p.46) is a separate, additional source, cited as workbook evidence only.

**8. (Sub lesson 2)** If lim(x→a) f(x) = L and f(a) = L, then f is continuous at a.
**Answer:** True — the limit exists and equals the function's own value at the point (Jordan, Grade 11 Term 1 Student Book, Limits and continuity, p.50).
