# Limits — true or false

Say true or false, and why.

**1. (Level 1)** If lim(x→a) f(x) exists, then f(a) must equal that limit.
**Answer:** False — the limit is about values near a; f(a) may differ or not exist, as (x² − 1)/(x − 1) at x = 1 shows.

**2. (Level 1)** If the left-hand and right-hand limits at a are different, the two-sided limit does not exist.
**Answer:** True — both sides must agree (Libya, Grade 11 Science, Ch.5).

**3. (Level 2)** 0/0 is a value of a limit.
**Answer:** False — 0/0 is an indeterminate form, a signpost to factorise or rationalise.

**4. (Level 2)** Direct substitution works for every polynomial limit at a finite point.
**Answer:** True — polynomials are built from the limit theorems; e.g. lim(x→2) (4x³ + x − 4) = 30.

**5. (Level 3)** Kuwait's book correctly prints cos x/x at x = 100 as −0.00862.
**Answer:** False — taught corrected: the value is +0.00862; the p.47 table drops the sign.

**6. (Level 3)** Pakistan's Grade 12 book correctly prints its p.25 limit at infinity as ∞.
**Answer:** False — taught corrected: that limit is −∞.

**7. (Level 1)** Jordan's Grade 11 limits evidence in this lesson comes from a student book.
**Answer:** False — it comes from an exercise book (workbook evidence): the orphan Grade 11 Term 1 exercise book, whose companion student book is not in hand (Unit 3, p.46).
