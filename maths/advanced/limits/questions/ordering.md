# Limits — ordering

Put the steps or values in the right order.

**1. (Level 1)** Order the steps for finding a limit from a table: (a) read off the value both lists head for; (b) choose x-values closing on a from the left; (c) compute f at each; (d) repeat from the right.
**Answer:** (b), (c), (d), (a) — approach from both sides, compute, then read the heading value.

**2. (Level 2)** Order the steps for a 0/0 limit: (a) substitute again; (b) try direct substitution; (c) factorise and cancel the common factor.
**Answer:** (b), (c), (a) — substitution first; only a 0/0 sends you to factorising.

**3. (Level 2)** Order by closeness to 0 as x grows: (a) x; (b) 1/x; (c) 1/x² — closest to 0 first.
**Answer:** (c), (b), (a) — 1/x² shrinks fastest, 1/x next, and x runs away from 0.

**4. (Level 3)** Order the sequence terms 1, 1/2, 1/4, 1/8 by closeness to the limit 0, least close first.
**Answer:** 1, 1/2, 1/4, 1/8 — each halving lands closer to 0.

**5. (Level 3)** Order the ε-δ proof steps: (a) find a δ that works; (b) be given ε > 0; (c) show |x − a| < δ forces |f(x) − L| < ε.
**Answer:** (b), (a), (c) — ε is given first; δ is the answer to it (Cambodia, PRIVATE Limits booklet, pp.9–31).

**6. (Level 1)** Order: as x closes on 1, the values of (x² − 1)/(x − 1) at x = 0.9, 0.99, 0.999 in the order computed.
**Answer:** 1.9, 1.99, 1.999 — each step closer to 1 gives a value closer to 2.

**7. (Level 2)** Order the exercise sets as they appear in Jordan's Grade 11 exercise book's Limits and Derivatives unit: (a) chain rule; (b) limits and continuity; (c) differentiation.
**Answer:** (b), (c), (a) — the sets run limits/continuity p.46, differentiation p.47, chain rule p.53 (workbook evidence).
