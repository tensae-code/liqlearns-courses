# Limits — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —

## Sub lesson 1 — The Limit Idea and One-Sided Limits
Sub lesson 1 questions from the type files. Pass mark: estimate a limit from a table or graph, read both one-sided limits, and say correctly whether a two-sided limit exists.

## Sub lesson 2 — Computing Limits
Sub lesson 2 questions from the type files. Pass mark: use the limit theorems, and remove a 0/0 form by factorising, cancelling or rationalising.

## Sub lesson 3 — Infinity, Sequences, the Sandwich Theorem and ε-δ
Sub lesson 3 questions from the type files. Pass mark: find limits at infinity and infinite limits with their asymptotes, find sequence limits, apply the sandwich theorem including sin θ/θ → 1, and state the ε-δ definition.
