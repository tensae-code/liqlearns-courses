# Limits — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — limits — the idea and one-sided limits first, then computing limits, then infinity, sequences, the sandwich theorem and ε-δ.

## Level 1 — the limit idea and one-sided limits
Level 1 questions from the type files. Pass mark: estimate a limit from a table or graph, read both one-sided limits, and say correctly whether a two-sided limit exists.

## Level 2 — computing limits
Level 2 questions from the type files. Pass mark: use the limit theorems, and remove a 0/0 form by factorising, cancelling or rationalising.

## Level 3 — infinity, sequences, the sandwich theorem and ε-δ
Level 3 questions from the type files. Pass mark: find limits at infinity and infinite limits with their asymptotes, find sequence limits, apply the sandwich theorem including sin θ/θ → 1, and state the ε-δ definition.
