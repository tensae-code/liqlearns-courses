# Logarithms and Exponentials — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Powers and the Exponential Function · (Level 2) -> Sub lesson 2 — The Logarithm and Its Laws · (Level 3) -> Sub lesson 3 — Log Functions, Graphs and Equations.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** 8^(1/3) = 2.
**True** — the cube root of 8 is 2.

**2. (Sub lesson 1)** An exponential function with base bigger than 1 grows ever more steeply.
**True** — growth by multiplying.

**3. (Sub lesson 2)** log 0 = 0.
**False** — there is no log of zero; the log is defined only for positive numbers.

**4. (Sub lesson 2)** log(a/b) = log a − log b.
**True** — the quotient law.

**5. (Sub lesson 3)** The log function and the exponential function mirror each other across y = x.
**True** — they are inverse functions (Egypt, Pure Grade 11 Term 1, 2-4/2-5).

**6. (Sub lesson 3)** To solve 3ˣ = 81, take logs of both sides.
**True** — x = log₃ 81 = 4.
