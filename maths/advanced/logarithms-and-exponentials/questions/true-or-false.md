# Logarithms and Exponentials — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** 8^(1/3) = 2.
**True** — the cube root of 8 is 2.

**2. (Level 1)** An exponential function with base bigger than 1 grows ever more steeply.
**True** — growth by multiplying.

**3. (Level 2)** log 0 = 0.
**False** — there is no log of zero; the log is defined only for positive numbers.

**4. (Level 2)** log(a/b) = log a − log b.
**True** — the quotient law.

**5. (Level 3)** The log function and the exponential function mirror each other across y = x.
**True** — they are inverse functions (Egypt, Pure Grade 11 Term 1, 2-4/2-5).

**6. (Level 3)** To solve 3ˣ = 81, take logs of both sides.
**True** — x = log₃ 81 = 4.
