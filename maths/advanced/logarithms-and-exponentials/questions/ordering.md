**1. (Sub lesson 1)** Order these from smallest to largest: 2³, 2¹, 2⁵, 2⁰.
**Answer:** 2⁰ = 1, 2¹ = 2, 2³ = 8, 2⁵ = 32.

**2. (Sub lesson 2)** Order these logs from smallest to largest: log₂ 4, log₂ 32, log₂ 2, log₂ 16.
**Answer:** log₂ 2 = 1, log₂ 4 = 2, log₂ 16 = 4, log₂ 32 = 5.

**3. (Sub lesson 3)** Order the steps for solving log x + log 10 = 3 (base 10): use the product law to get log(10x) = 3; write x = 100; work out 10x = 1000.
**Answer:** Use the product law to get log(10x) = 3; work out 10x = 1000; write x = 100.
