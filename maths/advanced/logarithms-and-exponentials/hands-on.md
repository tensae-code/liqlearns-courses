# Hands-on — Logarithms and Exponentials

## Doubling chain
Start with 1 coin. Double the pile again and again: 1, 2, 4, 8, 16, 32, 64. Write each step as a power of 2. Then write the backwards question beside each pile: "How many doublings?" That number is the log base 2.

## Growth and decay
Take a plant that doubles its leaves every week (growth), and a medicine in the body that halves every day (decay). Make a table for 5 steps each. Plot both curves on one page: one climbs ever more steeply, the other falls toward zero and never reaches it.

## Log laws with numbers
Check the product law with numbers you know: log₁₀ 100 = 2, log₁₀ 10 = 1, log₁₀ 1000 = 3. Is 2 + 1 = 3? Yes — log(100 × 10) = log 100 + log 10. Now try the power law: log₁₀ 1000 = 3 × log₁₀ 10 = 3. It works because 1000 = 10³.

## Mirror curves
Draw y = 2ˣ for x = −2, −1, 0, 1, 2, 3. Draw the line y = x. Flip the curve over that line, point by point, and you have drawn y = log₂ x. Check: where the first curve passes through (3, 8), the second passes through (8, 3).
