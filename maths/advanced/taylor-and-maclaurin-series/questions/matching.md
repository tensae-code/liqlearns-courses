# Taylor and Maclaurin Series — matching

Match each item on the left to its partner on the right.

**1. (Level 1)** Match each function to the value of its derivatives at 0: (a) eˣ (b) sin x, first derivative (c) sin x, second derivative — 1, 1, 0
**Answer:** a) 1, b) 1, c) 0 (§2.17, ch-pp.74–78).

**2. (Level 2)** Match each function to its series: (a) eˣ (b) sin x (c) 1/(1+x) — 1 + x + x²/2! + …, x − x³/3! + …, 1 − x + x² − …
**Answer:** a) 1 + x + x²/2! + …, b) x − x³/3! + …, c) 1 − x + x² − … (§2.17, ch-pp.74–78).

**3. (Level 2)** Match each series to its condition: (a) eˣ (b) 1/(1+x) (c) (1+x)ⁿ with n not a whole number — every x, |x| < 1, |x| < 1
**Answer:** a) every x, b) |x| < 1, c) |x| < 1 (§2.17, ch-pp.74–78).

**4. (Level 3)** Match each computation to its centre: (a) sin 31° (b) ln(1+x) in this lesson (c) every Maclaurin series — 30°, x = 2, 0
**Answer:** a) 30°, b) x = 2, c) 0 (§2.17, ch-pp.74–81).
