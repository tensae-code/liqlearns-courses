**1. (Sub lesson 1)** Match each function to the value of its derivatives at 0: (a) eˣ (b) sin x, first derivative (c) sin x, second derivative — 1, 1, 0
**Answer:** a) 1, b) 1, c) 0 (§2.17, ch-pp.74–78).

**2. (Sub lesson 2)** Match each function to its series: (a) eˣ (b) sin x (c) 1/(1+x) — 1 + x + x²/2! + …, x − x³/3! + …, 1 − x + x² − …
**Answer:** a) 1 + x + x²/2! + …, b) x − x³/3! + …, c) 1 − x + x² − … (§2.17, ch-pp.74–78).

**3. (Sub lesson 2)** Match each series to its condition: (a) eˣ (b) 1/(1+x) (c) (1+x)ⁿ with n not a whole number — every x, |x| < 1, |x| < 1
**Answer:** a) every x, b) |x| < 1, c) |x| < 1 (§2.17, ch-pp.74–78).
