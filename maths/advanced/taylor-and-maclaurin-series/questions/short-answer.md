# Taylor and Maclaurin Series — short answer

Answer in a word or a short line. All questions trace to Pakistan, Class 12, §2.17.

**1. (Level 1)** Write the Maclaurin template to the x³ term.
**Answer:** f(0) + xf′(0) + x²f″(0)/2! + x³f‴(0)/3! (§2.17, ch-pp.74–81).

**2. (Level 1)** Why is every coefficient in the eˣ series a reciprocal factorial?
**Answer:** Every derivative of eˣ is eˣ, so every derivative at 0 equals 1 (§2.17, ch-pp.74–78).

**3. (Level 2)** Write sin x as a series to the x⁵ term.
**Answer:** x − x³/6 + x⁵/120 (§2.17, ch-pp.74–78).

**4. (Level 2)** Write (1+x)ⁿ to the x² term.
**Answer:** 1 + nx + n(n−1)x²/2 (§2.17, ch-pp.74–78).

**5. (Level 2)** Estimate 1/(1.1) from the series for 1/(1+x) with three terms.
**Answer:** 1 − 0.1 + 0.01 = 0.91 (true value ≈ 0.909) — x = 0.1 is inside |x| < 1 (§2.17, ch-pp.74–78).

**6. (Level 3)** Write the first two terms of ln(1+x) about x = 2.
**Answer:** ln 3 + (x−2)/3 (§2.17, ch-pp.78–81).
