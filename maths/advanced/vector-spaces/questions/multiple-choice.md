# Multiple choice — Vector Spaces

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Layer 1) -> Sub lesson 1 — Subspaces · (Layer 2) -> Sub lesson 2 — Sums and Dimensions · (Layer 3) -> Sub lesson 3 — Basis and Coordinates.

1. (Sub lesson 1) Which of these is a subspace of R³?
   A. {(x, y, z) : x + y + z = 1} B. {(x, y, z) : x + y + z = 0} C. {(x, y, z) : x ≥ 0} D. {(x, y, z) : xyz = 0}
   **Answer: B** — it contains the zero vector and is closed; the others each fail closure or exclude 0. Rwanda, Advanced Mathematics, Learner's Book, Senior Five, Unit 6, printed pp. 180–186.

2. (Sub lesson 1) The union of two different lines through the origin in R³ is a subspace:
   A. Always B. Never C. Only if one line contains the other — impossible for different lines, so never here D. Only in R²
   **Answer: C** — by the guides' criterion a union is a subspace only in the nested case (guide evidence). Rwanda, Advanced Mathematics, Teacher's Guide, Senior Five, Unit 6, printed p. 97; Rwanda, Advanced Mathematics, Teacher's Guide, Senior Six, Unit 6, printed p. 292.

3. (Sub lesson 2) In R³, dim F = 2, dim G = 2 and dim(F ∩ G) = 1. Then dim(F + G) is:
   A. 4 B. 2 C. 3 D. 1
   **Answer: C** — 2 + 2 − 1 = 3, by the Grassmann formula. Rwanda, Advanced Mathematics, Learner's Book, Senior Six, Unit 6, printed pp. 342–343.

4. (Sub lesson 3) The vectors (1, 2, 0), (0, −1, 3), (−1, 0, 2) are independent because their determinant is:
   A. 0 B. −10 C. −8 D. 10
   **Answer: C** — the determinant is −8 ≠ 0 (taught corrected: the book prints −10; the independence conclusion is unchanged). Rwanda, Advanced Mathematics, Learner's Book, Senior Five, Unit 6, printed pp. 192–194.
