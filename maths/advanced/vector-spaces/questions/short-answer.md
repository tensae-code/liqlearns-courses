# Short answer — Vector Spaces

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Layer 1) -> Sub lesson 1 — Subspaces · (Layer 2) -> Sub lesson 2 — Sums and Dimensions · (Layer 3) -> Sub lesson 3 — Basis and Coordinates.

1. (Sub lesson 1) Test {(x, y, z) : x = y = z} for being a subspace of R³.
   **Answer: It is a subspace — it contains (0, 0, 0), the sum of two of its vectors (a, a, a) + (b, b, b) = (a + b, a + b, a + b) stays in the set, and so does every scalar multiple k(a, a, a).** Rwanda, Advanced Mathematics, Learner's Book, Senior Five, Unit 6, printed pp. 180–186.

2. (Sub lesson 2) F: x + y + z = 0 and G: x − y = 0 in R³. Find F ∩ G and its dimension.
   **Answer: Solving together: y = x and z = −2x, so F ∩ G = {(t, t, −2t)} — one free parameter, dimension 1.** Rwanda, Advanced Mathematics, Learner's Book, Senior Six, Unit 6, printed pp. 331–339.

3. (Sub lesson 3) Find the coordinates of (2, 3, 4) relative to the basis {(1, 1, 0), (0, 1, 1), (1, 0, 1)}.
   **Answer: Solve a + c = 2, a + b = 3, b + c = 4: (a, b, c) = (½, 5/2, 3/2).** Rwanda, Advanced Mathematics, Learner's Book, Senior Five, Unit 6, printed pp. 194–196.
