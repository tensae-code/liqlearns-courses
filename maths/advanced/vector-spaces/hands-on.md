# Hands-on — Vector Spaces

## Activity 1 — Test the sets (10 minutes)

The learner tests three subsets of R³ for being subspaces, using the closure test in full sentences: (a) {(x, y, z) : x + y + z = 0} — a subspace; (b) {(x, y, z) : x + y + z = 1} — fails (no zero vector; sums escape); (c) {(x, y, 0)} — a subspace. For each failure the learner exhibits two vectors or one vector and a scalar that escape the set.

## Activity 2 — Solve the intersection (15 minutes)

Let F: x + y + z = 0 and G: x − y = 0. The learner solves the two conditions together (y = x, z = −2x), writes F ∩ G = {(t, t, −2t)}, reads off its dimension (1), then uses Grassmann with dim F = dim G = 2 to get dim(F + G) = 3 — the sum is the whole of R³, and the learner says why that had to be checked rather than assumed.

## Activity 3 — Coordinates by hand (10 minutes)

With basis B = {(1, 1, 0), (0, 1, 1), (1, 0, 1)} of R³, the learner finds the coordinates of (2, 3, 4) by solving a(1, 1, 0) + b(0, 1, 1) + c(1, 0, 1) = (2, 3, 4): from the three equations a + c = 2, a + b = 3, b + c = 4, giving a = ½, b = 5/2, c = 3/2. The learner then verifies the combination rebuilds (2, 3, 4) exactly — coordinates are unique, so the check must close.
