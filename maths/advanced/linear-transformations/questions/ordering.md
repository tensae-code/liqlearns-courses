1. (Sub lessons 4–5) Put the steps of the rank–nullity check on T(x, y) = (x + y, x + y) in order:
   (a) count the image's dimension: the outputs are the multiples of (1, 1), so dim Im(T) = 1
   (b) write the kernel condition: x + y = 0
   (c) check the count: dim N(T) + dim Im(T) = 1 + 1 = 2 = dim ℝ²
   (d) solve for the kernel: N(T) = {(x, −x)}, so dim N(T) = 1

   **Answer: (b), (d), (a), (c)** — kernel first, as a solved linear system; then the image; then Sylvester's count. Venezuela, La Matemática y el Vivir Bien (Grade 11), printed pp. 152–154.

2. (Sub lesson 2) Put the proof that T(0) = 0 in order:
   (a) but also T(0 + 0) = T(0) + T(0), by the addition law
   (b) so T(0) = 2T(0), which forces T(0) = 0
   (c) start from 0 = 0 + 0

   **Answer: (c), (a), (b).** Venezuela, La Matemática y el Vivir Bien (Grade 11), printed pp. 147–148.
