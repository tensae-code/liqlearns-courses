# Multiple choice — Linear Transformations

1. (Layer 1) A map T between vector spaces is linear when it:
   A. preserves addition and scalar multiplication B. preserves all distances C. is given by any formula D. sends every line to a line of the same length
   **Answer: A** — the two laws T(u + v) = T(u) + T(v) and T(ku) = kT(u), the book's definition. Venezuela, La Matemática y el Vivir Bien (Grade 11), printed p. 144.

2. (Layer 1) Which map is NOT linear?
   A. T(x, y) = (x + 2y, y) B. T(x, y) = (x + 1, y) C. T(x, y) = (0, 0) D. T(x, y) = (−y, x)
   **Answer: B** — it moves the origin, so T(0) ≠ 0; it is affine, not linear (option A is the book's shear, C the zero map, D a rotation). Venezuela, La Matemática y el Vivir Bien (Grade 11), printed pp. 143–144.

3. (Layer 2) For every linear transformation T, T(0) equals:
   A. 1 B. 0 C. it depends on the map D. −T(0) only
   **Answer: B** — T(0) = T(0 + 0) = T(0) + T(0) forces T(0) = 0; the book proves it among the first properties. Venezuela, La Matemática y el Vivir Bien (Grade 11), printed pp. 147–148.

4. (Layer 4) The kernel of the shear T(x, y) = (x + 2y, y) is:
   A. all of ℝ² B. {(0, 0)} C. the line x + 2y = 0 D. {(x, −x)}
   **Answer: B** — the kernel needs both coordinates to vanish: y = 0 and x + 2y = 0 give only (0, 0). Option C forgets the second coordinate; option D is the kernel of the book's rank–nullity example. Venezuela, La Matemática y el Vivir Bien (Grade 11), printed p. 152.

5. (Layer 5) A linear map T on a 5-dimensional space V has dim Im(T) = 3. Then dim N(T) is:
   A. 3 B. 8 C. 2 D. 5
   **Answer: C** — rank–nullity: dim V = dim N(T) + dim Im(T), so dim N(T) = 5 − 3 = 2. Venezuela, La Matemática y el Vivir Bien (Grade 11), printed pp. 153–154.
