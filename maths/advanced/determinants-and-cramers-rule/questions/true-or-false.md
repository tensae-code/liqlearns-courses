# Determinants and Cramer's Rule — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — The 2×2 Determinant · (Level 2) -> Sub lesson 2 — The 3×3 Determinant and Two-Unknown Systems · (Level 3) -> Sub lesson 3 — Three-Unknown Systems, the D = 0 Cases and Codes.

Say true or false, and why.

**1. (Sub lesson 1)** det [[3, 7], [4, −2]] = 34.
**Answer:** False — it is −34: −6 − 28 (Cambodia, Grade 11 Basic, p.135).

**2. (Sub lesson 1)** Kuwait's Grade 10 book teaches 3×3 determinants.
**Answer:** False — Kuwait stops at 2×2, as filed; its Cramer is for two unknowns only (Kuwait, Grade 10 Term 2, Unit 7).

**3. (Sub lesson 2)** Cramer's rule can be used when D = 0.
**Answer:** False — Cramer's rule divides by D; D = 0 needs the numerator test instead (Cambodia, Grade 11 Basic, p.135).

**4. (Sub lesson 2)** The inverse-matrix method and Cramer's rule can give different answers for the same system.
**Answer:** False — they are two roads to the same answer; Kuwait teaches both in one lesson (Lesson 7-5, pp.79–82).

**5. (Sub lesson 3)** det(AB) = det(A)det(B).
**Answer:** True — a determinant property Nicaragua verifies numerically (Grade 10, pp.227–244).

**6. (Sub lesson 3)** A message coded with a matrix can be decoded without the inverse matrix.
**Answer:** False — decoding is multiplication by A⁻¹, which is the whole point of the codes application (Nicaragua, Grade 10, pp.243–244).
