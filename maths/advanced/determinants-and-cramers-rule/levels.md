# Determinants and Cramer's Rule — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — determinants and Cramer's rule — the 2×2 determinant first, then the 3×3 determinant, then solving systems, closing with matrices for codes.

## Level 1 — the 2×2 determinant
Level 1 questions from the type files. Pass mark: find a 2×2 determinant, say when it is zero, and find a triangle's area from a determinant.

## Level 2 — the 3×3 determinant and two-unknown systems
Level 2 questions from the type files. Pass mark: find a 3×3 determinant by Sarrus' rule and by cofactors, and solve two equations in two unknowns by Cramer's rule and by the inverse matrix.

## Level 3 — three-unknown systems, the D = 0 cases and codes
Level 3 questions from the type files. Pass mark: solve three equations in three unknowns by Cramer's rule, read the D = 0 cases, use X = A⁻¹B, and encode and decode with a matrix and its inverse.
