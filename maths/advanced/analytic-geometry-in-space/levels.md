# Analytic Geometry in Space — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — analytic geometry in space — coordinates and distance first, then vectors and their products, then the equations of lines and planes.

## Level 1 — coordinates, octants and distance in space
Level 1 questions from the type files. Pass mark: name the axes, planes and octants, read a point's coordinates, and find a distance in space with Pythagoras used twice.

## Level 2 — vectors in space and their products
Level 2 questions from the type files. Pass mark: write a vector with i, j, k, find its magnitude, unit vector and direction cosines, and use the dot, cross and mixed products.

## Level 3 — equations of lines and planes in space
Level 3 questions from the type files. Pass mark: write a line in parametric and symmetric form, write a plane from a point and a normal, and find the angle between a line and a plane.
