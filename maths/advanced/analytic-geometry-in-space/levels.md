# Analytic Geometry in Space — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
analytic geometry in space — coordinates and distance first, then vectors and their products, then the equations of lines and planes.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Coordinates, Octants and Distance in Space
Sub lesson 1 questions from the type files. Pass mark: name the axes, planes and octants, read a point's coordinates, and find a distance in space with Pythagoras used twice.

## Sub lesson 2 — Vectors in Space and Their Products
Sub lesson 2 questions from the type files. Pass mark: write a vector with i, j, k, find its magnitude, unit vector and direction cosines, and use the dot, cross and mixed products.

## Sub lesson 3 — Equations of Lines and Planes in Space
Sub lesson 3 questions from the type files. Pass mark: write a line in parametric and symmetric form, write a plane from a point and a normal, and find the angle between a line and a plane.
