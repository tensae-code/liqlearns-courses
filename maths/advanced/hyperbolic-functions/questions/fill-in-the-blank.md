# Hyperbolic Functions — fill-in-the-blank

Fill in the missing number, function or word.

**1. (Level 1)** cosh x = (eˣ + ___)/2.
**Answer:** e⁻ˣ — the half-sum defines cosh (Laos, Grade 12, L19, p.207).

**2. (Level 1)** sinh 0 = ___.
**Answer:** 0 — the difference (1 − 1)/2 (Laos, Grade 12, L19, p.207).

**3. (Level 1)** Dividing cosh²x − sinh²x = 1 by cosh²x gives 1 − tanh²x = ___.
**Answer:** sech²x (Laos, Grade 12, L22, p.221).

**4. (Level 2)** d/dx cosh x = ___.
**Answer:** sinh x — the pair swap (Pakistan, Class 12, Ch.2, ch-pp.61–66).

**5. (Level 2)** Taught corrected, d/dx sech x = ___ sech x tanh x, with a minus sign in front.
**Answer:** − — the printed summary drops it (Pakistan, Class 12, Ch.2, ch-p.62, taught corrected).

**6. (Level 3)** cosh⁻¹x = ln(x + √(x² − ___)).
**Answer:** 1 (Pakistan, Class 12, Ch.1, ch-pp.10–11).
