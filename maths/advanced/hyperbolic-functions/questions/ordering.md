# Hyperbolic Functions — ordering

Put the items in the order asked. Check each step before you write the answer.

**1. (Level 1)** Put these in order, smallest first: sinh 0, tanh 0, cosh 0, sinh(ln 2).
Answer in order, smallest first.
**Answer:** sinh 0 = 0 and tanh 0 = 0 (equal), then sinh(ln 2) = 3/4, then cosh 0 = 1 — checked from the definitions (Laos, Grade 12, L19, p.207).

**2. (Level 2)** Put the steps for differentiating sech x by the quotient rule in order: (i) write sech x = 1/cosh x (ii) apply the quotient rule (iii) simplify sinh x / cosh²x to sech x tanh x (iv) keep the minus sign.
Answer in order.
**Answer:** (i), (ii), (iv), (iii) — the minus appears in the quotient-rule step and survives to the corrected rule −sech x tanh x (Pakistan, Class 12, Ch.2, ch-p.62, taught corrected).

**3. (Level 3)** Put these inverse values in order, smallest first: tanh⁻¹0, sinh⁻¹0, cosh⁻¹1.
Answer in order, smallest first.
**Answer:** All three equal 0 — tanh⁻¹0 = 0, sinh⁻¹0 = 0, cosh⁻¹1 = 0, each the inverse image of the function's own anchor value (Laos, Grade 12, L25, p.243).
