# Hyperbolic Functions — short answer

Answer in a word or a short line.

**1. (Level 1)** Evaluate sinh(ln 2) exactly.
**Answer:** 3/4 — (2 − 1/2)/2 (Laos, Grade 12, L19, p.207).

**2. (Level 1)** Evaluate cosh(ln 2) exactly.
**Answer:** 5/4 — (2 + 1/2)/2 (Laos, Grade 12, L19, p.207).

**3. (Level 1)** Which hyperbolic function is even, sinh or cosh? Say how you know from the definition.
**Answer:** Cosh — swapping x for −x swaps eˣ and e⁻ˣ and leaves the sum unchanged (Laos, Grade 12, L20, p.210).

**4. (Level 1)** State the domain and range of tanh x.
**Answer:** Domain all real x; range −1 < y < 1 (Laos, Grade 12, L21, p.217).

**5. (Level 2)** Differentiate cosh(2x).
**Answer:** 2 sinh(2x) — derivative of cosh, times the inner derivative 2 (Pakistan, Class 12, Ch.2, ch-pp.61–66).

**6. (Level 2)** Differentiate tanh x.
**Answer:** sech²x — from 1 − tanh²x = sech²x (Pakistan, Class 12, Ch.2, ch-pp.61–66).

**7. (Level 2)** Write sinh⁻¹x in log form.
**Answer:** ln(x + √(x² + 1)) (Pakistan, Class 12, Ch.1, ch-pp.10–11).

**8. (Level 3)** Differentiate tanh⁻¹x.
**Answer:** 1/(1 − x²), for −1 < x < 1 (Pakistan, Class 12, Ch.2, ch-pp.61–66).

**9. (Level 3)** Why is there no cosh⁻¹(−2)?
**Answer:** Cosh never takes the value −2 — its range is y ≥ 1, so the inverse has no input there (Laos, Grade 12, L25, p.243).
