# Hyperbolic Functions — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** sinh(−x) = −sinh x.
**Answer:** True — sinh is odd (Laos, Grade 12, L20, p.210).

**2. (Level 1)** cosh x can take the value 0.
**Answer:** False — the range of cosh is y ≥ 1 (Laos, Grade 12, L21, p.217).

**3. (Level 2)** The derivative of cosh x is −sinh x.
**Answer:** False — it is +sinh x; the hyperbolic pair picks up no minus, unlike sin and cos (Pakistan, Class 12, Ch.2, ch-pp.61–66).

**4. (Level 2)** As printed in Pakistan's summary, d/dx sech x = sech x tanh x with no minus sign.
**Answer:** True as a statement about the printing — and the printing is wrong: taught corrected, the rule is −sech x tanh x (Pakistan, Class 12, Ch.2, ch-p.62, taught corrected).

**5. (Level 3)** tanh⁻¹x is defined for every real x.
**Answer:** False — only for −1 < x < 1, the range of tanh (Laos, Grade 12, L25, p.243).

**6. (Level 3)** sinh⁻¹x = ln(x + √(x² + 1)) for every real x.
**Answer:** True — sinh takes every real value, so its inverse does too (Pakistan, Class 12, Ch.1, ch-pp.10–11).
