Match each item on the left to its partner on the right.

**1. (Sub lesson 1)** Match each function to its value at 0: (a) sinh (b) cosh (c) tanh — 0, 1, 0
**Answer:** a) 0, b) 1, c) 0 (Laos, Grade 12, L19, p.207).

**2. (Sub lesson 1)** Match each function to its range: (a) sinh (b) cosh (c) tanh — all real y, y ≥ 1, −1 < y < 1
**Answer:** a) all real y, b) y ≥ 1, c) −1 < y < 1 (Laos, Grade 12, L21, p.217).

**3. (Sub lesson 2)** Match each function to its derivative: (a) sinh x (b) tanh x (c) sech x — cosh x, sech²x, −sech x tanh x (corrected)
**Answer:** a) cosh x, b) sech²x, c) −sech x tanh x (Pakistan, Class 12, Ch.2, ch-pp.61–66; ch-p.62 taught corrected).

**4. (Sub lesson 3)** Match each inverse to its log form: (a) sinh⁻¹x (b) cosh⁻¹x (c) tanh⁻¹x — ln(x + √(x² + 1)), ln(x + √(x² − 1)), ½ ln((1 + x)/(1 − x))
**Answer:** a) ln(x + √(x² + 1)), b) ln(x + √(x² − 1)), c) ½ ln((1 + x)/(1 − x)) (Pakistan, Class 12, Ch.1, ch-pp.10–11).
