# Hyperbolic Functions — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** sinh x is ______.
a) (eˣ + e⁻ˣ)/2  b) (eˣ − e⁻ˣ)/2  c) eˣ − e⁻ˣ
**Answer:** b) (eˣ − e⁻ˣ)/2 — the half-difference of eˣ and e⁻ˣ (Laos, Grade 12, L19, p.207).

**2. (Sub lesson 1)** cosh 0 equals ______.
a) 0  b) 1  c) e
**Answer:** b) 1 — (1 + 1)/2 (Laos, Grade 12, L19, p.207).

**3. (Sub lesson 1)** The range of cosh x is ______.
a) all real numbers  b) y ≥ 1  c) −1 < y < 1
**Answer:** b) y ≥ 1 — cosh never falls below its value at 0 (Laos, Grade 12, L21, p.217).

**4. (Sub lesson 1)** cosh²x − sinh²x equals ______.
a) 0  b) cosh 2x  c) 1
**Answer:** c) 1 — the master identity (Laos, Grade 12, L22, p.221).

**5. (Sub lesson 2)** The derivative of sinh x is ______.
a) cosh x  b) −cosh x  c) sinh x
**Answer:** a) cosh x — the pair swap, with no minus (Pakistan, Class 12, Ch.2, ch-pp.61–66).

**6. (Sub lesson 2)** The derivative of sech x, taught corrected, is ______.
a) sech x tanh x  b) −sech x tanh x  c) −sech²x
**Answer:** b) −sech x tanh x — the printed summary drops the minus (Pakistan, Class 12, Ch.2, ch-p.62, taught corrected).

**7. (Sub lesson 2)** The derivative of cosech x, taught corrected, is ______.
a) −coth x cosech x  b) coth x cosech x  c) −cosech²x
**Answer:** a) −coth x cosech x — the printed summary drops the minus (Pakistan, Class 12, Ch.2, ch-p.62, taught corrected).

**8. (Sub lesson 3)** cosh⁻¹x is defined for ______.
a) all x  b) x ≥ 1  c) −1 < x < 1
**Answer:** b) x ≥ 1 — cosh itself never goes below 1 (Laos, Grade 12, L25, p.243).

**9. (Sub lesson 3)** tanh⁻¹x in log form is ______.
a) ln(x + √(x² + 1))  b) ½ ln((1 + x)/(1 − x))  c) ln(x + √(x² − 1))
**Answer:** b) ½ ln((1 + x)/(1 − x)) (Pakistan, Class 12, Ch.1, ch-pp.10–11).

**10. (Sub lesson 3)** The derivative of sinh⁻¹x is ______.
a) 1/√(x² + 1)  b) 1/√(x² − 1)  c) 1/(1 − x²)
**Answer:** a) 1/√(x² + 1) (Pakistan, Class 12, Ch.2, ch-pp.61–66).
