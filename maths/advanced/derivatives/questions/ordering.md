# Derivatives — ordering

Put each set in order, as the question says.

**1. (Level 1)** Order these slopes from smallest to largest: a curve falling steeply (−3), a flat curve (0), a curve rising gently (1).
**Answer:** −3, 0, 1.

**2. (Level 2)** Order the steps for differentiating from first principles: form the chord gradient; let h go to zero; write f(x + h) − f(x).
**Answer:** Write f(x + h) − f(x); form the chord gradient; let h go to zero.

**3. (Level 3)** Order these derivatives from smallest to largest at x = 2: f'(x) for f(x) = x² (4), f(x) = x³ (12), f(x) = 2x (2).
**Answer:** f(x) = 2x gives 2; f(x) = x² gives 4; f(x) = x³ gives 12.
