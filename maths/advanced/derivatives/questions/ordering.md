# Derivatives — ordering

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Rates of Change and the Derivative · (Level 2) -> Sub lesson 2 — The Rules and the Special Functions · (Level 3) -> Sub lesson 3 — Higher Derivatives and Applications.

Put each set in order, as the question says.

**1. (Sub lesson 1)** Order these slopes from smallest to largest: a curve falling steeply (−3), a flat curve (0), a curve rising gently (1).
**Answer:** −3, 0, 1.

**2. (Sub lesson 2)** Order the steps for differentiating from first principles: form the chord gradient; let h go to zero; write f(x + h) − f(x).
**Answer:** Write f(x + h) − f(x); form the chord gradient; let h go to zero.

**3. (Sub lesson 3)** Order these derivatives from smallest to largest at x = 2: f'(x) for f(x) = x² (4), f(x) = x³ (12), f(x) = 2x (2).
**Answer:** f(x) = 2x gives 2; f(x) = x² gives 4; f(x) = x³ gives 12.
