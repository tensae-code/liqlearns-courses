# Derivatives — matching

Match each left side to its right side.

**Set (Level 1)** — meanings
1. derivative — **slope of the tangent**
2. velocity — **derivative of distance**
3. acceleration — **derivative of velocity**
4. tangent — **the line that touches at one point**

**Set (Level 2)** — rules
1. sum rule — **(u + v)' = u' + v'**
2. product rule — **(uv)' = u'v + uv'**
3. chain rule — **outside first, then the inside**
4. power rule — **(xⁿ)' = n·xⁿ⁻¹**

**Set (Level 3)** — functions
1. sin x — **cos x**
2. cos x — **−sin x**
3. eˣ — **eˣ**
4. ln x — **1/x**
