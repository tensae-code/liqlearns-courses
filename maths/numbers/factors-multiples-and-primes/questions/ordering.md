# Factors-multiples-and-primes — ordering

Put the items in the order asked. Check each step before you write the answer.

**1. (Level 1)** Put these factor lists in order by how many factors each number has, fewest first: 7 (2 factors), 12 (6 factors), 10 (4 factors).
Answer the numbers in order.
**Answer:** 7, 10, 12 — 2, 4, then 6 factors.

**2. (Level 2)** Put these numbers in order, primes first then composites, smallest first in each group: 21, 7, 13, 9.
Answer in order.
**Answer:** 7, 13, 9, 21 — primes 7 and 13, then composites 9 and 21.

**3. (Level 3)** Put these LCMs in order, smallest first: LCM(4, 6) = 12; LCM(3, 5) = 15; LCM(6, 8) = 24.
Answer the LCM values in order.
**Answer:** 12, 15, 24 — the LCM values in order.
