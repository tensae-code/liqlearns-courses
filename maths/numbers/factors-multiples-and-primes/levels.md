# Factors-multiples-and-primes — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
factors — factors and multiples first, then the divisibility
tests, then prime and composite, then HCF and LCM.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 3; old Level 3 = Sub lesson 4. Sub
lesson 2 — Divisibility Tests — was added 2026-11-08 under
the whole-arc rule, from the lesson's own stocked sources:
the tests were stocked in 7+ rows (Ethiopia, South Sudan,
Yemen, Armenia's chapter named "Divisibility," Tajikistan,
Laos…) but never taught, and the HCF part never carried the
books' successive-division (Euclidean) GCD method, now taught
in Sub lesson 4 from Tajikistan's worked scheme. The old Sub
lessons 2–3 moved to 3–4 and their question markers were
renumbered to match.

Pass marks: Sub lessons 1, 3 and 4 carry the old layers' pass
marks. The books state no separate pass mark for the
divisibility band, so Sub lesson 2 keeps the same observable
form — the learner can run each test and say what it decides —
rather than an invented mark.

## Sub lesson 1 — Factors and Multiples
Sub lesson 1 questions from the type files. Pass mark: list the factors of a number in pairs, and list the first five multiples of a number.

## Sub lesson 2 — Divisibility Tests
Sub lesson 2 questions from the type files. Pass mark: run the
tests for 2, 3, 4, 5, 6, 8, 9, 10 and 11 on a given number and
say which divisors it has, without dividing.

## Sub lesson 3 — Prime and Composite
Sub lesson 3 questions from the type files. Pass mark: tell prime numbers from composite numbers, know that 1 is neither, and test a number for prime by its factors.

## Sub lesson 4 — HCF and LCM
Sub lesson 4 questions from the type files. Pass mark: find the HCF and the LCM of two numbers, find a GCD by successive division, and choose the right one for a word problem.
