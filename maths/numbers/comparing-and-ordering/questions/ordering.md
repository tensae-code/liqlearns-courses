# Comparing-and-ordering — ordering

Put the items in the order asked. Check each step before you write the answer.

**1. (Level 1)** Put these in order, smallest first: 56, 49, 63, 52.
Answer in order.
**Answer:** 49, 52, 56, 63 — checked by the tens digit: 4, 5, 5, 6, then the ones split 52 and 56.

**2. (Level 2)** Put these in order, biggest first: 128, 405, 296, 312.
Answer in order.
**Answer:** 405, 312, 296, 128 — checked by the hundreds digit: 4, 3, 2, 1.

**3. (Level 3)** Put these in order, smallest first: 1,050; 999; 1,005; 998.
Answer in order.
**Answer:** 998, 999, 1,005, 1,050 — checked by length first (three places before four), then by place.
