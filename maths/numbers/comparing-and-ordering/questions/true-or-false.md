# Comparing-and-ordering — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Comparing and Ordering Bigger, Smaller, Equal · (Level 2) -> Sub lesson 2 — Comparing and Ordering The Biggest Place Decides · (Level 3) -> Sub lesson 3 — Comparing and Ordering The Number Line.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** 39 < 47.
**Answer:** True — 39 is less than 47.

**2. (Sub lesson 1)** The open end of the sign faces the smaller number.
**Answer:** False — the open end eats the bigger number; the sharp end points to the smaller.

**3. (Sub lesson 2)** To compare 47 and 39, the ones decide first.
**Answer:** False — the tens decide first; the ones never get a vote when the tens differ.

**4. (Sub lesson 2)** 98 is bigger than 102.
**Answer:** False — 102 has three places and 98 has two.

**5. (Sub lesson 3)** 27, 29, 31 is in order, smallest to biggest.
**Answer:** True.
