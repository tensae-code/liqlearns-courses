# True or false — Even and Odd Numbers

1. (Layer 1) A number ending in 0 is even.
   **Answer: True.** India, Math-Magic Class 3, printed p. 151.

2. (Layer 1) To tell whether 1,263 is even or odd, you must work with the whole number.
   **Answer: False — only the last digit matters: 3 makes it odd.** India, Math-Magic Class 3, printed p. 151.

3. (Layer 2) 164 is one of the even numbers between 155 and 165.
   **Answer: True.** India, Math-Magic Class 3, printed p. 152.

4. (Layer 3) Odd + 1 = even.
   **Answer: True.** India, Math-Magic Class 3, printed p. 152.

5. (Layer 3) Odd + odd = odd.
   **Answer: False — odd + odd = even: the two left-over ones pair up.** India, Math-Magic Class 3, printed p. 152.
