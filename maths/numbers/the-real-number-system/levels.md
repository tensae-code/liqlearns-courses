# The Real Number System — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
the real number system — the family map first, then the laws checked on the smaller families, then the laws stated for all real numbers, the order the books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;

## Sub lesson 1 — The Real Number System The Families of Numbers
Sub lesson 1 questions from the type files. Pass mark: draw N ⊂ W ⊂ Z ⊂ Q ⊂ R, place common numbers in their smallest family, and tell a rational from an irrational by its decimal.

## Sub lesson 2 — The Real Number System The Laws on Whole Numbers, Fractions and Integers
Sub lesson 2 questions from the type files. Pass mark: verify the commutative, associative and distributive laws on whole numbers, fractions and integers, and name both identities and where subtraction fails.

## Sub lesson 3 — The Real Number System The Laws for Rationals and for All Real Numbers
Sub lesson 3 questions from the type files. Pass mark: verify the three laws for rational numbers, state the laws for real numbers in general form, and find additive and multiplicative inverses, including why 0 has no multiplicative inverse.
