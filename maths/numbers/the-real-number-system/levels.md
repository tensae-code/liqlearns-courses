# The Real Number System — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the real number system — the family map first, then the laws checked on the smaller families, then the laws stated for all real numbers, the order the books teach it in.

## Level 1 — the families of numbers
Level 1 questions from the type files. Pass mark: draw N ⊂ W ⊂ Z ⊂ Q ⊂ R, place common numbers in their smallest family, and tell a rational from an irrational by its decimal.

## Level 2 — the laws on whole numbers, fractions and integers
Level 2 questions from the type files. Pass mark: verify the commutative, associative and distributive laws on whole numbers, fractions and integers, and name both identities and where subtraction fails.

## Level 3 — the laws for rationals and for all real numbers
Level 3 questions from the type files. Pass mark: verify the three laws for rational numbers, state the laws for real numbers in general form, and find additive and multiplicative inverses, including why 0 has no multiplicative inverse.
