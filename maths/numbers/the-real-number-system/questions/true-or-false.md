# The Real Number System — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** Every integer is also a rational number.
**Answer:** True — Z ⊂ Q on the Grade 8 map; −3 is −3/1 (Unit 1, pp.1–3).

**2. (Level 1)** 22/7 is an irrational number.
**Answer:** False — 22/7 is a ratio of integers, so it is rational; it is π that is irrational (Unit 1, pp.1–3).

**3. (Level 2)** The commutative law holds for fraction multiplication.
**Answer:** True — Grade 5 verifies it: swapping the factors keeps the product (pp.36–38).

**4. (Level 2)** The associative law says a + b = b + a.
**Answer:** False — that is the commutative law; associative is about regrouping, (a + b) + c = a + (b + c).

**5. (Level 3)** Every real number has an additive inverse.
**Answer:** True — for every a there is −a with a + (−a) = 0 (Grade 8, Unit 1, pp.6–9).
