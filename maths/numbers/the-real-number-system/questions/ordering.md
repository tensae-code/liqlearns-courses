# The Real Number System — ordering

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — The Real Number System The Families of Numbers · (Level 2) -> Sub lesson 2 — The Real Number System The Laws on Whole Numbers, Fractions and Integers · (Level 3) -> Sub lesson 3 — The Real Number System The Laws for Rationals and for All Real Numbers.

Put the items in the order asked. Check each step before you write the answer.

**1. (Sub lesson 1)** Put the families in nesting order, smallest first: R, Z, N, Q, W.
**Answer:** N, W, Z, Q, R — the Grade 8 chain N ⊂ W ⊂ Z ⊂ Q ⊂ R (Unit 1, pp.1–3).

**2. (Sub lesson 2)** Put these in the order Pakistan's books verify the laws: rationals (Grade 7), whole numbers and fractions (Grade 5), integers (Grade 6).
**Answer:** Grade 5 first, Grade 6 second, Grade 7 third — the verification climb, family by family.

**3. (Sub lesson 3)** Put these real numbers in order on the line, smallest first: 0.5, −1, √2, 0.
**Answer:** −1, 0, 0.5, √2 — √2 ≈ 1.414, so it stands last; all four are real, only the first three are rational-or-smaller.
