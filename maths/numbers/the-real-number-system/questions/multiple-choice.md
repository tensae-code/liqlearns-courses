# The Real Number System — multiple choice

Pick the one right answer.

**1. (Level 1)** Which list shows the families nesting correctly?
a) N ⊂ Z ⊂ W ⊂ Q ⊂ R  b) N ⊂ W ⊂ Z ⊂ Q ⊂ R  c) Q ⊂ N ⊂ W ⊂ Z ⊂ R
**Answer:** b) N ⊂ W ⊂ Z ⊂ Q ⊂ R — each ring adds numbers without losing any (Pakistan, Grade 8, Unit 1, pp.1–3).

**2. (Level 1)** The smallest family that holds −3 is ______.
a) N  b) W  c) Z
**Answer:** c) Z — negatives arrive with the integers (Grade 8, Unit 1, pp.1–3).

**3. (Level 1)** A number whose decimal never ends and never repeats is ______.
a) rational  b) irrational  c) whole
**Answer:** b) irrational — the Grade 8 definition of Q′ (Unit 1, pp.1–3).

**4. (Level 2)** Which check verifies the distributive property with whole numbers?
a) 3 × (4 + 5) = 3 × 4 + 3 × 5 = 27  b) 3 + 4 = 4 + 3  c) (3 + 4) + 5 = 3 + (4 + 5)
**Answer:** a) — multiply across the bracket both ways and compare; Grade 5 verifies it over + and − (pp.13–15).

**5. (Level 2)** Subtraction for integers is ______.
a) commutative  b) not commutative  c) associative
**Answer:** b) not commutative — 7 − 3 ≠ 3 − 7, the Grade 6 failure case (pp.32–33).

**6. (Level 3)** The multiplicative inverse of 4 is ______.
a) −4  b) 1/4  c) 0
**Answer:** b) 1/4 — 4 × 1/4 = 1, the multiplicative identity (Grade 8, Unit 1, pp.6–9).

**7. (Level 3)** Which number has NO multiplicative inverse?
a) 1  b) −1  c) 0
**Answer:** c) 0 — nothing times 0 makes 1 (Grade 8, Unit 1, pp.6–9).

**8. (Level 3)** π and 22/7 are related as ______.
a) π = 22/7 exactly  b) π ≈ 22/7, but π ≠ 22/7  c) unrelated numbers
**Answer:** b) — 22/7 is a rational approximation; π itself is irrational (Grade 8, Unit 1, pp.1–3).
