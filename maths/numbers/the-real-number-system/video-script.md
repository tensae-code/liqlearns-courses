# Video script — The Real Number System

The super-simple voice, for the video that rides on top of the
lesson (lesson-plan.md, add-on list). Made later, when videos are
made; the script is the slot's written form until then.

---

Numbers live in **families**. Rings inside rings!

Counting numbers: 1, 2, 3 — the **naturals**.
Add zero — the **whole numbers**.
Add the negatives — the **integers**.
Add the fractions — the **rationals**.
And the numbers that never end and never repeat —
the **irrationals**. Pi! Root two!
All of them together: the **real numbers**. Every point on the line.

And the reals obey **laws**:
Swap the order — same answer!
Group them differently — same answer!
Multiply across a bracket — same answer!

Now you. Draw the rings. Put a number in each.
That is the real number system.
