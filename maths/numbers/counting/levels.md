# Counting — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — counting — 1–10 first, then 11–20, then the tens to 100 and beyond, the order the books teach it in..


## Level 1 — one to ten
Level 1 questions from the type files. Pass mark: count 1–10 on real things, touching each thing once, and match a count of things to its number.

## Level 2 — eleven to twenty
Level 2 questions from the type files. Pass mark: run the 11–20 line whole, forward and back, and answer How-many for counts to 20.

## Level 3 — tens to a hundred and beyond
Level 3 questions from the type files. Pass mark: count by tens to 100, count in tens and ones to 100, and count past 100 in tens.
