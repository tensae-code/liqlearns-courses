# Place-value — ordering

Put the items in the order asked. Check each step before you write the answer.

**1. (Level 2)** Put these in order by their hundreds: 482, 219, 905, 367.
Answer in order, smallest first.
**Answer:** 219, 367, 482, 905 — checked place by place: 2, 3, 4, 9 hundreds.

**2. (Level 3)** Put these in order by size: 5,048; 5,480; 5,084; 5,804.
Answer in order, smallest first.
**Answer:** 5,048; 5,084; 5,480; 5,804 — checked place by place: thousands all 5, then hundreds 0, 0, 4, 8, then tens.

**3. (Level 1)** Put these in order by their tens: 34, 71, 52, 19.
Answer in order, smallest first.
**Answer:** 19, 34, 52, 71 — checked by the tens digit: 1, 3, 5, 7.
