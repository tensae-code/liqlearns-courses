# Place-value — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Place Value Tens and Ones · (Level 2) -> Sub lesson 2 — Place Value Hundreds · (Level 3) -> Sub lesson 3 — Place Value Thousands and Beyond.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** In 64, the 6 is worth 6.
**Answer:** False — the 6 stands in the tens place, so it is worth 60.

**2. (Sub lesson 1)** 18 = 1 ten + 8 ones.
**Answer:** True — Armenia's Grade 2 book teaches it this way.

**3. (Sub lesson 2)** 305 and 350 are the same number.
**Answer:** False — 305 has 0 tens, 350 has 5 tens; the zero holds a place.

**4. (Sub lesson 2)** In 700, the 7 is worth seven hundred.
**Answer:** True.

**5. (Sub lesson 3)** In 62,019, the 6 is worth sixty thousand.
**Answer:** True — it stands in the ten-thousands place.
