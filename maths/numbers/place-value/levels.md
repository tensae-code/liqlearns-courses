# Place-value — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
place value — tens and ones first, then hundreds, then thousands and beyond, the order the books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Place Value Tens and Ones
Sub lesson 1 questions from the type files. Pass mark: split any two-digit number into tens and ones, and build a two-digit number from tens and ones.

## Sub lesson 2 — Place Value Hundreds
Sub lesson 2 questions from the type files. Pass mark: read and write three-digit numbers as hundreds, tens and ones, including a zero in a place.

## Sub lesson 3 — Place Value Thousands and Beyond
Sub lesson 3 questions from the type files. Pass mark: read big numbers by their places to millions, and write any number in expanded form.
