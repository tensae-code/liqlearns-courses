# Place-value — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — place value — tens and ones first, then hundreds, then thousands and beyond, the order the books teach it in..


## Level 1 — tens and ones
Level 1 questions from the type files. Pass mark: split any two-digit number into tens and ones, and build a two-digit number from tens and ones.

## Level 2 — hundreds
Level 2 questions from the type files. Pass mark: read and write three-digit numbers as hundreds, tens and ones, including a zero in a place.

## Level 3 — thousands and beyond
Level 3 questions from the type files. Pass mark: read big numbers by their places to millions, and write any number in expanded form.
