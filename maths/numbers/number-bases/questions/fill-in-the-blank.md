# Number Bases — fill in the blank

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Number Bases What a Base Is and Binary · (Level 2) -> Sub lesson 2 — Number Bases Other Bases and Converting Through Base 10 · (Level 3) -> Sub lesson 3 — Number Bases Arithmetic in a Base, the Radix Point and the Computer Bases.

Fill in the missing number or word.

**1. (Sub lesson 1)** Base 5 uses exactly ___ digits: 0, 1, 2, 3, 4.
**Answer:** 5 — the count of digits is the base itself.

**2. (Sub lesson 1)** In base 2, the places from the right are 1, 2, 4, ___, 16.
**Answer:** 8 — each place doubles the one before it.

**3. (Sub lesson 2)** 100₅ = ___ in base 10.
**Answer:** 25 — one bundle of twenty-five (Nepal, Grade 7, Unit 12).

**4. (Sub lesson 2)** 75₁₀ = ___₂.
**Answer:** 1001011₂ — the conversion Nepal's Grade 8 book works (Unit 11).

**5. (Sub lesson 3)** In base 2, 1 + 1 = ___.
**Answer:** 10 — you carry at 2, exactly as you carry at 10 in base 10.
