# Number Bases — fill in the blank

Fill in the missing number or word.

**1. (Level 1)** Base 5 uses exactly ___ digits: 0, 1, 2, 3, 4.
**Answer:** 5 — the count of digits is the base itself.

**2. (Level 1)** In base 2, the places from the right are 1, 2, 4, ___, 16.
**Answer:** 8 — each place doubles the one before it.

**3. (Level 2)** 100₅ = ___ in base 10.
**Answer:** 25 — one bundle of twenty-five (Nepal, Grade 7, Unit 12).

**4. (Level 2)** 75₁₀ = ___₂.
**Answer:** 1001011₂ — the conversion Nepal's Grade 8 book works (Unit 11).

**5. (Level 3)** In base 2, 1 + 1 = ___.
**Answer:** 10 — you carry at 2, exactly as you carry at 10 in base 10.
