**1. (Sub lesson 1)** Match each binary number to its base-10 value: (a) 10₂ (b) 100₂ (c) 1000₂ — 2, 4, 8
**Answer:** a) 2, b) 4, c) 8 — each is a single place value.

**2. (Sub lesson 2)** Match each base-5 number to its base-10 value: (a) 213₅ (b) 100₅ (c) 113₅ — 25, 33, 58
**Answer:** a) 58, b) 25, c) 33 — expand with places 25, 5, 1 (Laos, L8; Nepal, Unit 11).

**3. (Sub lesson 3)** Match each base to its job: (a) base 2 (b) base 8 (c) base 16 — octal shorthand, the computer's own system, hexadecimal shorthand
**Answer:** a) the computer's own system, b) octal shorthand, c) hexadecimal shorthand — Pakistan, Statistics Class 12, Ch. 17, pp.281–284.
