# Number Bases — short answer

Answer in a word or a short line.

**1. (Level 1)** Change 1001₂ to base 10.
**Answer:** 9 — 8 + 0 + 0 + 1 (Nepal, Grade 7, Unit 12).

**2. (Level 1)** Change 13₁₀ to base 2.
**Answer:** 1101₂ — repeated division by 2: remainders 1, 0, 1, 1 read up.

**3. (Level 2)** Change 111011₂ to base 10.
**Answer:** 59 — 32 + 16 + 8 + 0 + 2 + 1 (Laos, Grade 6, L8).

**4. (Level 2)** Change 33₁₀ to base 5.
**Answer:** 113₅ — 33 = 1×25 + 1×5 + 3 (Nepal, Grade 8, Unit 11).

**5. (Level 2)** Change 4321₅ to base 10.
**Answer:** 586 — 4×125 + 3×25 + 2×5 + 1 = 586 (Nepal, Grade 8, Unit 11).

**6. (Level 3)** Subtract in base 2: 110₂ − 11₂.
**Answer:** 11₂ — in base 10 this is 6 − 3 = 3, and 3 is 11₂.

**7. (Level 3)** Write (23.25)₁₀ in binary.
**Answer:** (10111.01)₂ — 23 = 10111₂ and 0.25 is one quarter, 0.01₂ (Bangladesh, Class 8, Exp. 9).

**8. (Level 3)** Find the unknown base: 21 in base *x* equals 15 in base 10.
**Answer:** *x* = 7 — expand: 2*x* + 1 = 15, so *x* = 7 (the SSS 1 equation method, L20, p.57).
