# Number Bases — short answer

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Number Bases What a Base Is and Binary · (Level 2) -> Sub lesson 2 — Number Bases Other Bases and Converting Through Base 10 · (Level 3) -> Sub lesson 3 — Number Bases Arithmetic in a Base, the Radix Point and the Computer Bases.

Answer in a word or a short line.

**1. (Sub lesson 1)** Change 1001₂ to base 10.
**Answer:** 9 — 8 + 0 + 0 + 1 (Nepal, Grade 7, Unit 12).

**2. (Sub lesson 1)** Change 13₁₀ to base 2.
**Answer:** 1101₂ — repeated division by 2: remainders 1, 0, 1, 1 read up.

**3. (Sub lesson 2)** Change 111011₂ to base 10.
**Answer:** 59 — 32 + 16 + 8 + 0 + 2 + 1 (Laos, Grade 6, L8).

**4. (Sub lesson 2)** Change 33₁₀ to base 5.
**Answer:** 113₅ — 33 = 1×25 + 1×5 + 3 (Nepal, Grade 8, Unit 11).

**5. (Sub lesson 2)** Change 4321₅ to base 10.
**Answer:** 586 — 4×125 + 3×25 + 2×5 + 1 = 586 (Nepal, Grade 8, Unit 11).

**6. (Sub lesson 3)** Subtract in base 2: 110₂ − 11₂.
**Answer:** 11₂ — in base 10 this is 6 − 3 = 3, and 3 is 11₂.

**7. (Sub lesson 3)** Write (23.25)₁₀ in binary.
**Answer:** (10111.01)₂ — 23 = 10111₂ and 0.25 is one quarter, 0.01₂ (Bangladesh, Class 8, Exp. 9).

**8. (Sub lesson 3)** Find the unknown base: 21 in base *x* equals 15 in base 10.
**Answer:** *x* = 7 — expand: 2*x* + 1 = 15, so *x* = 7 (the SSS 1 equation method, L20, p.57).
