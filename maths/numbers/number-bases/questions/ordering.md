# Number Bases — ordering

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Number Bases What a Base Is and Binary · (Level 2) -> Sub lesson 2 — Number Bases Other Bases and Converting Through Base 10 · (Level 3) -> Sub lesson 3 — Number Bases Arithmetic in a Base, the Radix Point and the Computer Bases.

Put the items in the order asked. Check each step before you write the answer.

**1. (Sub lesson 2)** Put these base-2 numbers in order, smallest first: 110₂, 1011₂, 101₂, 1001₂.
**Answer:** 101₂, 110₂, 1001₂, 1011₂ — in base 10: 5, 6, 9, 11; longer writings first sort the fours from the threes, then digit by digit.

**2. (Sub lesson 2)** Put these in order, smallest first: 59₁₀, 213₅, 111011₂.
**Answer:** 213₅, 59₁₀, 111011₂ — 213₅ = 58, and 111011₂ = 59, so the order is 58, 59, 59 with the two 59s tied; any order of the tied pair is correct.

**3. (Sub lesson 3)** Put these place values in the order they appear in a binary number, from the units place up: 16, 1, 8, 2, 4.
**Answer:** 1, 2, 4, 8, 16 — each place doubles the one before it (Nepal, Grade 8, place-value table 2⁸…2⁰).
