# Number Bases — multiple choice

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Number Bases What a Base Is and Binary · (Level 2) -> Sub lesson 2 — Number Bases Other Bases and Converting Through Base 10 · (Level 3) -> Sub lesson 3 — Number Bases Arithmetic in a Base, the Radix Point and the Computer Bases.

Pick the one right answer.

**1. (Sub lesson 1)** Which digits may appear in a base-2 number?
a) 0–9  b) 0 and 1 only  c) 1 and 2 only
**Answer:** b) 0 and 1 only — a base of 2 has exactly two digits, the count Sierra Leone's JSS 3 book opens with (L18, p.50).

**2. (Sub lesson 1)** 101₂ in base 10 is ______.
a) 3  b) 5  c) 101
**Answer:** b) 5 — expand the places: 4 + 0 + 1 = 5.

**3. (Sub lesson 1)** 1111₂ in base 10 is ______.
a) 4  b) 11  c) 15
**Answer:** c) 15 — 8 + 4 + 2 + 1 = 15 (Nepal, Grade 7, Unit 12).

**4. (Sub lesson 2)** 213₅ in base 10 is ______.
a) 58  b) 213  c) 35
**Answer:** a) 58 — 2×25 + 1×5 + 3 = 58 (Laos, Grade 6, L8).

**5. (Sub lesson 2)** 432₁₀ written in base 5 is ______.
a) 3212₅  b) 1232₅  c) 432₅
**Answer:** a) 3212₅ — repeated division by 5, remainders read up (Nepal, Grade 7, Unit 12).

**6. (Sub lesson 2)** Which binary number is the biggest?
a) 1011₂  b) 110₂  c) 1001₂
**Answer:** a) 1011₂ — four digits beats three, and among the four-digit pair 1011 > 1001 digit by digit from the left.

**7. (Sub lesson 3)** 101₂ + 11₂, staying in base 2, is ______.
a) 112₂  b) 1000₂  c) 100₂
**Answer:** b) 1000₂ — 5 + 3 = 8, and 8 in base 2 is 1000.

**8. (Sub lesson 3)** In hexadecimal (base 16), the digit for ten is ______.
a) 10  b) A  c) X
**Answer:** b) A — base 16 needs sixteen digits, so letters A–F stand for 10–15 (Pakistan, Statistics Class 12, Ch. 17, pp.281–282).
