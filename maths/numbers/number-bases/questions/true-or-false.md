# Number Bases — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Number Bases What a Base Is and Binary · (Level 2) -> Sub lesson 2 — Number Bases Other Bases and Converting Through Base 10 · (Level 3) -> Sub lesson 3 — Number Bases Arithmetic in a Base, the Radix Point and the Computer Bases.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** The digit 2 can appear in a base-2 number.
**Answer:** False — base 2 allows only 0 and 1 (Sierra Leone, JSS 3, L18, p.50).

**2. (Sub lesson 1)** 1001111₂ = 79.
**Answer:** True — 64 + 8 + 4 + 2 + 1 = 79 (Laos, Grade 6, L8).

**3. (Sub lesson 2)** To change from base 5 to base 7, you may pass through base 10.
**Answer:** True — Laos changes between bases via base ten (Grade 6, L8, pp.56–64).

**4. (Sub lesson 2)** 512₁₀ = 4022₅.
**Answer:** True — 4×125 + 0×25 + 2×5 + 2 = 512 (Nepal, Grade 8, Unit 11).

**5. (Sub lesson 3)** A computer character is stored as an 8-bit binary code.
**Answer:** True — Pakistan's Statistics Class 12 book files characters as 8-bit binary codes (Ch. 17, pp.283–284).
