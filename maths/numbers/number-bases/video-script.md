# Video script — Number Bases

The super-simple voice, for the video that rides on top of the
lesson (lesson-plan.md, add-on list). Made later, when videos are
made; the script is the slot's written form until then.

---

Count with me — in **twos**!

Zero, one, **one-zero**, one-one, **one-zero-zero**!
That is 0, 1, 2, 3, 4 — written in base two.
Base two has only two digits: **0 and 1**.

Each place is worth **double** the place before it:
ones, twos, fours, eights, sixteens!

One-one-one-zero-one-one in base two:
32 and 16 and 8 and 2 and 1 — that is **fifty-nine**!

In base five, each place is worth **five times** more.
In base ten, **ten times** more.
The base is just the size of the bundle!

Now you. Write your age in base two.
Check it by adding the places. That is number bases.
