# Lesson plan — Number Bases

**Course:** Maths · **Stage:** Stage 1 — Numbers · **Lesson:** Number Bases
**Place in the curriculum:** Level 53 of 136, inside Stage 1 — Numbers (maths/CURRICULUM.md).
**The one thing this lesson teaches:** a number can be written in any base — base 2 uses only 0 and 1, base 10 uses 0–9 — and you can change a number from one base to another and do arithmetic inside a base.
**This lesson's own level:** it stands on Place Value — the learner already knows that in base 10 each place is worth ten times the place before it. It needs nothing else.

## Before this lesson
- Recommended first: Place Value (Stage 1) — a base is place value with a different bundle size. Recommended, never forced.
- Recommended first: Counting and the four operations in base 10 — conversion checks use ordinary adding and multiplying. Recommended, never forced.

## What the learner can do when it ends
1. Say what a base means and which digits each base allows, the way Sierra Leone's JSS 3 book opens it (JSS 3, Term 1, L18, printed p.50).
2. Change a binary number to base 10 by expanding its places, e.g. 111011₂ = 59 (Laos, Grade 6 student book (2010), L8, printed pp.56–64).
3. Change a base-10 number to base 2, to base 5 and to other bases by repeated division (Sierra Leone, SSS 1, Term 1, L15, printed p.42; Nepal, Grade 7, Unit 12, printed pp.105–120: 432₁₀ = 3212₅).
4. Compare and order numbers written in base 2 (Sierra Leone, JSS 3, Term 1, L19–L20, printed pp.53–56).
5. Add, subtract, multiply and divide inside bases 2, 3, 4, 5 and 7 (Laos, Grade 6, L8, printed pp.56–64; Bangladesh, Class 8, Exp. 9, printed pp.189–206).
6. Use the radix point in binary, e.g. (23.25)₁₀ = (10111.01)₂, and name 1's and 2's complements (Bangladesh, Class 8, Exp. 9, printed pp.189–206).
7. Read binary, octal and hexadecimal place values as the systems computers use (Pakistan, Statistics Class 12, Ch. 17, printed pp.281–284).
8. Solve a simple equation in which a digit or the base itself is unknown (Sierra Leone, SSS 1, Term 1, L20, printed p.57).

## What you need
Paper and a pencil. Buttons or stones in two colours for binary places.
A place-value strip you draw yourself: 32, 16, 8, 4, 2, 1.

## The run of the lesson (in order)
1. **Do it first** — the learner counts 13 stones twice: once in bundles of ten, once in bundles of two, and writes both counts (lesson/lesson.md).
2. **The explanation** — what a base is; binary to base 10; base 10 to binary and to base 5; other bases; arithmetic in a base; the radix point, octal and hexadecimal (lesson/lesson.md).
   - ADD GIF at the binary part: a picture of a row of lamps switching on and off, each lamp worth double the one before it — 1, 2, 4, 8, 16 — the student reads the lit lamps and adds their values.
   - ADD IMAGE under base 5: a picture of hands counting in bundles of five, five bundles tied into one bundle of twenty-five → the student counts the bundles and loose ones and writes the base-5 number.
   - ADD IMAGE in the arithmetic part: a picture of a binary addition laid out in columns, 101 + 11, with the carried 1 shown moving → the student follows the carry and says why 1 + 1 = 10 in base 2.
3. **Say it to your companion** — dictate a binary number, your companion changes it to base 10 aloud, then swap (lesson/lesson.md).
   - ADD VIDEO: the script in video-script.md, filmed — the bases chant in the super-simple voice (made later, when videos are made).
4. **Questions** — from questions/: multiple-choice, short-answer, fill-in-the-blank, true-or-false, ordering, matching — served at the learner's level and teaching-mix (levels.md).
5. **Hands-on** — hands-on.md.
6. **Do It Yourself** — write your age in base 2 and in base 5, and check both by expanding back (lesson/lesson.md).

## If the learner is stuck
- Writes a digit the base does not allow, like 2 in base 2 → Sierra Leone's opening rule: base 2 has only two digits, 0 and 1, the way base 10 has ten digits, 0–9 (JSS 3, L18, p.50). Count the digits: the count IS the base.
- Expands places from the wrong end → Laos's method: write the powers over the digits first, starting with the units place on the right (Grade 6, L8, pp.56–64).
- Repeated division gives the answer backwards → read the remainders from the last one up; the last remainder is the first digit.
- Adds in base 2 and writes 2 → carry instead: in base 2, 1 + 1 = 10, exactly as 9 + 1 = 10 in base 10.
- This lesson's next door: Place Value again, now seen from the other side — every base is place value with a different bundle.
