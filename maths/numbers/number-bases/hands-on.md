# Hands-on — Number Bases

The lesson changed numbers between bases on paper. Here your hands do it.

## Lamps and buttons
Draw six places on paper: 32, 16, 8, 4, 2, 1. A partner calls a number up to 50. Put a button on a place to switch it "on", leave it empty for "off". Read your buttons as a binary number, then add the place values to check you made the called number.

## Bundles of two, bundles of five
Take 23 stones. Bundle them in twos: tie pairs, then pairs of pairs, then pairs of those. Count what is left at each size — that count, read from the biggest bundle down, is 23 in base 2 (10111₂). Untie everything and bundle in fives instead: 23 = 43₅. The stones never changed; the bundle size did.

## Binary adding machine
Write 101 and 11 in columns on squared paper. Add from the right, saying the base-2 rule aloud at each column: 0 + 0 = 0, 1 + 0 = 1, 1 + 1 = 10 — write 0, carry 1. Check your answer by changing all three numbers to base 10.

## Digit police
A partner writes ten "numbers", some in base 2, some in base 5, some with a digit the base forbids (like 10212₂ or 45₅). You are the police: pass the legal ones, arrest the illegal ones, and say the rule each arrest breaks.
