# Number Bases — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
number bases — what a base is and binary first, then other bases and converting between them, then arithmetic inside a base and the computer bases, the order the books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Number Bases What a Base Is and Binary
Sub lesson 1 questions from the type files. Pass mark: say which digits a base allows, and change small numbers between base 2 and base 10 both ways.

## Sub lesson 2 — Number Bases Other Bases and Converting Through Base 10
Sub lesson 2 questions from the type files. Pass mark: change numbers between base 10 and bases 3, 5 and 7, change between two non-decimal bases through base 10, and compare numbers written in base 2.

## Sub lesson 3 — Number Bases Arithmetic in a Base, the Radix Point and the Computer Bases
Sub lesson 3 questions from the type files. Pass mark: add, subtract, multiply and divide in base 2 and other bases, use the binary radix point, name 1's and 2's complements, read octal and hexadecimal values, and solve a simple equation with an unknown digit or base.
