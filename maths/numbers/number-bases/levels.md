# Number Bases — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — number bases — what a base is and binary first, then other bases and converting between them, then arithmetic inside a base and the computer bases, the order the books teach it in.

## Level 1 — what a base is, and binary
Level 1 questions from the type files. Pass mark: say which digits a base allows, and change small numbers between base 2 and base 10 both ways.

## Level 2 — other bases and converting through base 10
Level 2 questions from the type files. Pass mark: change numbers between base 10 and bases 3, 5 and 7, change between two non-decimal bases through base 10, and compare numbers written in base 2.

## Level 3 — arithmetic in a base, the radix point and the computer bases
Level 3 questions from the type files. Pass mark: add, subtract, multiply and divide in base 2 and other bases, use the binary radix point, name 1's and 2's complements, read octal and hexadecimal values, and solve a simple equation with an unknown digit or base.
