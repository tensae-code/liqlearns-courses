# Rounding-and-estimating — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — rounding — the nearest ten first, then the nearest hundred and thousand, then estimating sums and differences..


## Level 1 — nearest ten
Level 1 questions from the type files. Pass mark: round any two-digit number to the nearest ten, and say which ten it is nearest to on the line.

## Level 2 — nearest hundred and thousand
Level 2 questions from the type files. Pass mark: round three- and four-digit numbers to the nearest hundred and to the nearest thousand.

## Level 3 — estimating
Level 3 questions from the type files. Pass mark: estimate a sum or difference before working it out, and judge whether an exact answer is close to the estimate.
