# Rounding-and-estimating — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
rounding — the nearest ten first, then the nearest hundred and thousand, then estimating sums and differences.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Rounding to the Nearest Ten
Sub lesson 1 questions from the type files. Pass mark: round any two-digit number to the nearest ten, and say which ten it is nearest to on the line.

## Sub lesson 2 — Rounding to the Nearest Hundred and Thousand
Sub lesson 2 questions from the type files. Pass mark: round three- and four-digit numbers to the nearest hundred and to the nearest thousand.

## Sub lesson 3 — Estimating
Sub lesson 3 questions from the type files. Pass mark: estimate a sum or difference before working it out, and judge whether an exact answer is close to the estimate.
