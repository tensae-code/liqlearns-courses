# Rounding-and-estimating — ordering

Put the items in the order asked. Check each step before you write the answer.

**1. (Level 1)** Put these rounded-to-ten answers in order, smallest first: 47 → 50; 23 → 20; 68 → 70; 85 → 90.
Answer the rounded numbers in order.
**Answer:** 20, 50, 70, 90 — the rounded values in order.

**2. (Level 2)** Put these numbers in order of their nearest hundred, smallest first: 382, 141, 659, 704.
Answer the numbers in order.
**Answer:** 141, 382, 659, 704 — nearest hundreds 100, 400, 700, 700; 659 and 704 both round to 700, and 659 is smaller.

**3. (Level 3)** Put these estimates in order, smallest first: 73 − 29 (≈40); 48 + 36 (≈90); 247 + 45 (≈300).
Answer the estimates in order.
**Answer:** 40, 90, 300 — the estimates in order.
