# Numerals of the World — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the numeral systems of the world — Roman numerals first, then the living digit sets of other scripts, then the big-number names of South Asia, the order the books teach it in.

## Level 1 — Roman numerals
Level 1 questions from the type files. Pass mark: read and write Roman numerals to 100 with the repetition and subtraction rules, and spot them in daily life.

## Level 2 — the digit sets of the world
Level 2 questions from the type files. Pass mark: recognise and match Ge'ez, Devanagari, Lao, Khmer, Hindi and ancient Egyptian numerals with the counts they stand for.

## Level 3 — lakh, crore and the big-number names
Level 3 questions from the type files. Pass mark: read and write large numbers with South Asian grouping, and use lakh, crore, ayut/ajut and nijut names correctly.
