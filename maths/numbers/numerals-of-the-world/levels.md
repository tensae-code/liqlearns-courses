# Numerals of the World — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
the numeral systems of the world — Roman numerals first, then the living digit sets of other scripts, then the big-number names of South Asia, the order the books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Numerals of the World Roman Numerals
Sub lesson 1 questions from the type files. Pass mark: read and write Roman numerals to 100 with the repetition and subtraction rules, and spot them in daily life.

## Sub lesson 2 — Numerals of the World The Digit Sets of the World
Sub lesson 2 questions from the type files. Pass mark: recognise and match Ge'ez, Devanagari, Lao, Khmer, Hindi and ancient Egyptian numerals with the counts they stand for.

## Sub lesson 3 — Numerals of the World Lakh, Crore and the Big-Number Names
Sub lesson 3 questions from the type files. Pass mark: read and write large numbers with South Asian grouping, and use lakh, crore, ayut/ajut and nijut names correctly.
