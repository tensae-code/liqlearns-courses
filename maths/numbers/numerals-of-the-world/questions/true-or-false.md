# Numerals of the World — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Numerals of the World Roman Numerals · (Level 2) -> Sub lesson 2 — Numerals of the World The Digit Sets of the World · (Level 3) -> Sub lesson 3 — Numerals of the World Lakh, Crore and the Big-Number Names.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** In Roman numerals, a sign may repeat four times in a row.
**Answer:** False — repetition stops at three; four is written with the subtraction rule, IV.

**2. (Sub lesson 1)** Roman numerals appear on clocks and watches.
**Answer:** True — Sierra Leone's JSS 3 book starts from exactly those uses (L16, p.43).

**3. (Sub lesson 2)** Vietnam's Grade 3 book teaches Roman numerals as a full conversion course.
**Answer:** False — Bài 47 (p.12) is "getting to know" only, introductory as filed.

**4. (Sub lesson 2)** Ancient Egyptian numerals have place value, like our digits.
**Answer:** False — each sign stands for one value and the signs add; South Africa's workbooks build numbers by adding signs.

**5. (Sub lesson 3)** In South Asian grouping, commas after the first three digits come every two digits.
**Answer:** True — 1,00,000 and 1,00,00,000 show the pattern (Bangladesh, Class 4, §§1.1–1.2).
