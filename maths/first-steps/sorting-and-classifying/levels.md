# Sorting and Classifying — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — sorting —
one likeness first, then a new likeness on the same set, then two
likenesses at once, the order the books teach them in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Sorting By One Attribute
Sub lesson 1 questions from the type files. Pass mark: sort a mixed pile by one named attribute (size, shape, colour or use) and say the rule of each group.

## Sub lesson 2 — Sorting Re-Sorting and the Not Group
Sub lesson 2 questions from the type files. Pass mark: sort the same set a second way, explain why the groups change, and use a "not" group so nothing is left homeless.

## Sub lesson 3 — Sorting By Two Attributes and Sorting for Data
Sub lesson 3 questions from the type files. Pass mark: sort by two attributes at once in two passes, name each group's two-part rule, and say why sorting opens data work.
