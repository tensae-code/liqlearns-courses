# Sorting and Classifying — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — sorting — one likeness first, then a
new likeness on the same set, then two likenesses at once, the order
the books teach them in.

## Level 1 — sorting by one attribute
Level 1 questions from the type files. Pass mark: sort a mixed pile by one named attribute (size, shape, colour or use) and say the rule of each group.

## Level 2 — re-sorting the same set, and the "not" group
Level 2 questions from the type files. Pass mark: sort the same set a second way, explain why the groups change, and use a "not" group so nothing is left homeless.

## Level 3 — sorting by two attributes, and sorting for data
Level 3 questions from the type files. Pass mark: sort by two attributes at once in two passes, name each group's two-part rule, and say why sorting opens data work.
