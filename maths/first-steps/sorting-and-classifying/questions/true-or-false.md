# Sorting and Classifying — true or false

Say true or false, and say why.

**1. (Level 1)** "The ones I like" is a good sorting rule.
**Answer:** False — a rule must be a likeness anyone can see, like size or colour; only you can see what you like.

**2. (Level 1)** Big things can go to the big bag and small things to the small bag in the same sort.
**Answer:** True — that is Yemen's first lesson: sorting by the one attribute, size (Grade 1 Part 1, printed p. 8).

**3. (Level 2)** The same set of buttons must always make the same groups.
**Answer:** False — change the rule and the groups change; China teaches the re-sort for this (Grade 1, Unit 3, printed p. 27).

**4. (Level 2)** A thing can sit in two groups of the same sort at the same time.
**Answer:** False — in a set it belongs once; re-sorting moves it, it does not copy it.

**5. (Level 3)** Sorting by two attributes is done in one look, never in passes.
**Answer:** False — the safe way is two passes: split by the first attribute, then split each pile by the second (Yemen, Grade 1 Part 1, printed p. 12).

**6. (Level 3)** A pictogram can be drawn before anything is sorted.
**Answer:** False — the pictogram shows sorted groups; sorting opens the statistics unit (Yemen, Grade 2 Part 2, printed p. 140).
