# Sorting and Classifying — fill in the blank

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Sorting By One Attribute · (Level 2) -> Sub lesson 2 — Sorting Re-Sorting and the Not Group · (Level 3) -> Sub lesson 3 — Sorting By Two Attributes and Sorting for Data.

Fill each blank with the right word.

**1. (Sub lesson 1)** Sorting by one ___ means picking one likeness, like size or colour.
**Answer:** attribute — one sort uses one attribute at a time.

**2. (Sub lesson 1)** A group is only finished when you can say its ___ out loud.
**Answer:** rule — the rule names the likeness the group shares.

**3. (Sub lesson 2)** Sort the same set by a different rule and the ___ change, even though the things did not.
**Answer:** groups — China's re-sort shows the result changing with the standard (Grade 1, Unit 3, printed p. 27).

**4. (Sub lesson 2)** In one sort, a thing belongs to its group ___ time(s) — never twice.
**Answer:** one (1) — a set holds each of its things once (Kazakhstan, Grade 2 Part 1, Lessons 56–57).

**5. (Sub lesson 3)** Two attributes, each with two kinds, give ___ groups.
**Answer:** four (4) — 2 × 2 groups, each with a two-part rule.

**6. (Sub lesson 3)** Yemen's Grade 2 statistics unit opens with ___, before any picture or table.
**Answer:** sorting — Unit 11's first lesson is Sorting (Part 2, printed p. 140).
