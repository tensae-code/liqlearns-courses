# Sorting and Classifying — multiple choice

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Sorting By One Attribute · (Level 2) -> Sub lesson 2 — Sorting Re-Sorting and the Not Group · (Level 3) -> Sub lesson 3 — Sorting By Two Attributes and Sorting for Data.

Pick the one right answer.

**1. (Sub lesson 1)** You sort buttons into a big bag and a small bag. What is the attribute?
a) colour  b) size  c) shape
**Answer:** b) size — big and small are sizes (Yemen, Grade 1 Part 1, printed p. 8).

**2. (Sub lesson 1)** Which of these is a good sorting rule anyone can see?
a) the ones I like  b) the red ones together  c) the lucky ones
**Answer:** b) the red ones together — a rule must be a likeness anyone can check.

**3. (Sub lesson 2)** You sort the same buttons first by colour, then by shape. The groups change because…
a) the buttons changed  b) the rule changed  c) sorting is broken
**Answer:** b) the rule changed — China's book re-sorts one set by a different standard to show exactly this (Grade 1, Unit 3, printed p. 27).

**4. (Sub lesson 2)** The groups are "red" and "blue". A green button's honest home is…
a) in the red group  b) in the blue group  c) in a "not red and not blue" group
**Answer:** c) in a "not red and not blue" group — a good sort leaves nothing homeless.

**5. (Sub lesson 3)** Sorting buttons by colour AND size (two colours, two sizes) gives how many groups?
a) 2  b) 3  c) 4
**Answer:** c) 4 — each colour pile splits into big and small (Yemen, Grade 1 Part 1, printed p. 12).

**6. (Sub lesson 3)** Yemen's Grade 2 statistics unit begins with which lesson?
a) bar charts  b) sorting  c) probability words
**Answer:** b) sorting — sorting opens the unit, before any picture is drawn (Grade 2 Part 2, printed p. 140).
