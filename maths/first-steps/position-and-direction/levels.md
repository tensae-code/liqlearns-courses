# Position and Direction — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — position
words — the pairs for one thing first, then places in a line,
then directions for moving, the order the books teach them in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Position The Pairs for One Thing
Sub lesson 1 questions from the type files. Pass mark: use in/out, above/below, over/under and inside/outside/between correctly for real things and pictures.

## Sub lesson 2 — Position Front, Back, Left, Right and Places in a Line
Sub lesson 2 questions from the type files. Pass mark: use front/back, left/right, far/near and before/after correctly, and name places first to tenth from a named end of a line.

## Sub lesson 3 — Position The Compass Points and Routes
Sub lesson 3 questions from the type files. Pass mark: name all eight compass points on a north-up map and follow or give a short route in steps.
