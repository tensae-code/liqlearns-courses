# Position and Direction — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — position words — the pairs for one
thing first, then places in a line, then directions for moving, the
order the books teach them in.

## Level 1 — the pairs for one thing
Level 1 questions from the type files. Pass mark: use in/out, above/below, over/under and inside/outside/between correctly for real things and pictures.

## Level 2 — front, back, left, right, and places in a line
Level 2 questions from the type files. Pass mark: use front/back, left/right, far/near and before/after correctly, and name places first to tenth from a named end of a line.

## Level 3 — the compass points and routes
Level 3 questions from the type files. Pass mark: name all eight compass points on a north-up map and follow or give a short route in steps.
