# Repeating Patterns — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — patterns —
continuing a repeat first, then naming its rule and fixing it,
then growing and shrinking, the order the books teach them in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Patterns Continuing a Repeating Pattern
Sub lesson 1 questions from the type files. Pass mark: continue a repeating pattern of shapes or colours and say what comes next, for repeats of two and of three.

## Sub lesson 2 — Patterns The Rule, Sounds and Movements, and Fixing Errors
Sub lesson 2 questions from the type files. Pass mark: name the smallest part that repeats, continue a sound or movement pattern, and find and fix the wrong piece in a broken pattern.

## Sub lesson 3 — Patterns Growing and Shrinking
Sub lesson 3 questions from the type files. Pass mark: continue a growing or shrinking pattern, say how much it changes by each step, and follow a halving chain.
