# Repeating Patterns — fill in the blank

Fill each blank with the right word or number.

**1. (Level 1)** Blue, yellow, blue, yellow, blue, ___
**Answer:** yellow — the part "blue, yellow" repeats.

**2. (Level 1)** A pattern is a row with a ___: a small part that repeats.
**Answer:** rule — the rule is the repeating part, said in words.

**3. (Level 2)** Clap, stomp, clap, stomp, clap, ___.
**Answer:** stomp — the two-beat part "clap, stomp" copies again.

**4. (Level 2)** To fix a broken pattern, walk the row in ___ and find the one that does not match the rule.
**Answer:** repeats — bracket the row copy by copy; the odd bracket holds the error (Ghana, JICA B3, Lessons 77–79 — teacher evidence).

**5. (Level 3)** 12, 9, 6, 3, ___ — the pattern shrinks by 3 each time.
**Answer:** 0 — 3 − 3 = 0 (Indonesia, Grade 4, printed pp. 85–102).

**6. (Level 3)** 560, 280, 140, ___, 35 — each number is half the one before.
**Answer:** 70 — half of 140 is 70, and half of 70 is 35 (Ghana, JICA B5, Lesson 78 — teacher evidence).
