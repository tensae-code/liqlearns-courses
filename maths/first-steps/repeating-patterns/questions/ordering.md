# Repeating Patterns — ordering

Put each list in the right order.

**1. (Level 1)** A pattern row was cut into pieces: blue, red, blue, red. Put the pieces back in the row's order, starting with red.
**Answer:** red, blue, red, blue — the repeating part is "red, blue", so red starts every copy.

**2. (Level 2)** Put the working steps in order: say the rule; find the repeating part; continue the row.
**Answer:** Find the repeating part, say the rule, continue the row — the rule must be found before it can be said or used.

**3. (Level 3)** Put the growing chain in order: 7, 1, 13, 4, 10 — it grows by 3.
**Answer:** 1, 4, 7, 10, 13 — each step adds 3 (Indonesia, Grade 4, printed pp. 85–102).

**4. (Level 3)** Put Ghana's halving chain in order (teacher evidence): 140, 35, 560, 70, 280.
**Answer:** 560, 280, 140, 70, 35 — each number is half the one before (Ghana, JICA B5, Lesson 78 — teacher evidence).
