# Repeating Patterns — true or false

Say true or false, and say why.

**1. (Level 1)** Red, blue, green, red, blue, green is a repeating pattern.
**Answer:** True — the part "red, blue, green" repeats whole.

**2. (Level 1)** Red, blue, red, green, red, yellow is a repeating pattern with the rule "red, blue".
**Answer:** False — after the first copy the row leaves the rule; blue, then green, then yellow do not copy "red, blue".

**3. (Level 2)** A pattern can be made of sounds, with nothing to see or touch.
**Answer:** True — Indonesia's Grade 2 book teaches sound patterns beside shape and colour ones (printed pp. 101–124).

**4. (Level 2)** If you know a pattern's rule, you can make a new pattern that follows it.
**Answer:** True — creating a pattern for a given rule is the step after finding rules (Ghana, JICA B3, Lessons 77–79 — teacher evidence).

**5. (Level 3)** In a growing pattern, every step must add the same amount.
**Answer:** False — the books' growing patterns here add a fixed amount, but a pattern may grow by a changing rule too (for example Ghana's halving chain changes the amount subtracted each time); what matters is that the growth follows a sayable rule.

**6. (Level 3)** 560, 280, 140, 70, 35 shrinks by the same subtraction each time.
**Answer:** False — it shrinks by halving: −280, −140, −70, −35; the rule is "half the one before", not one fixed subtraction (Ghana, JICA B5, Lesson 78 — teacher evidence).
