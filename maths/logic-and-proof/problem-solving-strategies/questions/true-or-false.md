# Problem-solving strategies — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — The Steps and the Plan · (Level 2) -> Sub lesson 2 — The Eight Named Strategies · (Level 3) -> Sub lesson 3 — Choosing and Combining: China's Tools.

Say true or false, and why.

**1. (Sub lesson 1)** Iran's Grade 7 book opens the whole course with a chapter on problem-solving strategies.
**Answer:** True — Chapter 1 is Problem-solving strategies (pp.1–12), before integers, algebra or anything else.

**2. (Sub lesson 1)** Iraq's Grade 1 book has a problem-solving-plan lesson in only one chapter.
**Answer:** False — every chapter has one, each naming its own move (use a model, use a representation, make a model, write a number sentence, the four steps, logical reasoning, draw a picture).

**3. (Sub lesson 2)** A real problem usually tells you which strategy to use.
**Answer:** False — that is why Iran's Grade 7 review set (pp.10–12) mixes all eight strategies without naming them.

**4. (Sub lesson 2)** Solving a simpler problem means giving up on the real problem.
**Answer:** False — you shrink it until the method shows, then use the same method on the real problem (Iran, Grade 7, p.8).

**5. (Sub lesson 3)** The assumption method and listing always give the same answer on chickens-and-rabbits.
**Answer:** True — both count the same cage; for 35 heads and 94 feet both give 12 rabbits and 23 chickens (China, Grade 4, Unit 9).

**6. (Sub lesson 3)** In a 0/1 logic table, 1 marks a false statement and 0 a true one.
**Answer:** False — 1 marks true and 0 marks false; the rows must agree with every clue (China, Grade 6 review, pp.100–104).
