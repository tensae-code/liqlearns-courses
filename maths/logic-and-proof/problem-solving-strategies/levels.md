# Problem-solving strategies — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — problem-solving strategies — the shared steps first, then the eight named strategies, then choosing and combining strategies the way the books' own tools demand.

## Level 1 — the steps and the plan
Level 1 questions from the type files. Pass mark: state Iran's four steps and Greece's five steps, put them in order, and follow a plan lesson the way Iraq's chapters teach one.

## Level 2 — the eight named strategies
Level 2 questions from the type files. Pass mark: name all eight of Iran's Grade 7 strategies, say what each does, and carry out the drawing, listing, eliminating, pattern, guess-and-check, sub-problem, simpler-problem and symbolic moves on set problems.

## Level 3 — choosing and combining: China's tools
Level 3 questions from the type files. Pass mark: solve chickens-and-rabbits by listing and by the assumption method, work an elimination table and a proto-Sudoku grid, use differencing, and read a 0/1 table — choosing the tool yourself and looking back at the end.
