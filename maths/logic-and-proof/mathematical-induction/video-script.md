---

Dominoes in a row. Push the FIRST one.
If EVERY domino knocks the next one down — they ALL fall.
You never touch the last one. It still falls!

That is **induction**. Two jobs, and the claim is proved for every n.

Job one — the **base**: show it for n = 1. The first domino falls.
Job two — the **step**: suppose it is true for n = k.
Show it must then be true for n = k + 1. Each domino knocks the next.

1 + 3 = 4. 1 + 3 + 5 = 9. The odd numbers build squares: n².
Base: 1 = 1². Step: n² plus the next odd number, 2n + 1, is (n + 1)².
Done — for ALL n. Not by checking. By the staircase.

But beware! Euler's n² − n + 41 is prime for n = 1, 2, 3 … all the way to 40.
And at n = 41? It breaks: 41 × 41. Checking is NOT proving!

Now you. Base. Suppose. Step. Say them out loud. That is induction.
