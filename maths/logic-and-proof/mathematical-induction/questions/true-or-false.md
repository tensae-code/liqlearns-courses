# Mathematical Induction — true or false

Say true or false, and be ready to say why.

**1. (Level 1)** An induction proof is complete once the statement is checked for n = 1, 2 and 3.
**Answer:** False — checks are not the step; the step must be proved for a general k (Laos, Grade 11, Ch.2 L7, p.28).

**2. (Level 1)** In the induction step you may assume the statement for n = k.
**Answer:** True — that assumption is the hypothesis, and k + 1 must be earned from it (Laos, Grade 11, Ch.2 L7, p.28).

**3. (Level 2)** The sum of the first 5 odd numbers is 25.
**Answer:** True — 1 + 3 + 5 + 7 + 9 = 25 = 5² (Cambodia, Grade 11 Advanced, pp.24–34).

**4. (Level 2)** 6²ⁿ − 1 is divisible by 35 when n = 2.
**Answer:** True — 6⁴ − 1 = 1295 = 35 × 37 (Kazakhstan, Abylkasymova Algebra 9, §18, p.153).

**5. (Level 3)** Since n² − n + 41 is prime for 40 values of n, it is prime for all n.
**Answer:** False — at n = 41 it is 41²; forty checks prove nothing (Pakistan, Class 11, Unit 8, pp.140–150).

**6. (Level 3)** If the base case is deleted but the step is perfect, the proof still works.
**Answer:** False — without a true starting case the staircase never starts; false statements can have a working step (Kazakhstan, Shynybekov Algebra 9, §3.2*, p.72).
