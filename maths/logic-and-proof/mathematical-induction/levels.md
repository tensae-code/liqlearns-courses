# Mathematical Induction — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — induction — the principle and its three steps first, then series and divisibility proofs, then extended induction, inequalities and broken proofs.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3 — each old layer is one sub lesson, in the same order.

## Sub lesson 1 — The Principle and the Three Steps
Sub lesson 1 questions from the type files. Pass mark: state the principle, name the three steps in order, and check a base case correctly.

## Sub lesson 2 — Series and Divisibility Proofs
Sub lesson 2 questions from the type files. Pass mark: carry a series formula and a divisibility claim through a complete induction proof, hypothesis stated and used.
