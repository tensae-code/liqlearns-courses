# Hands-on — Mathematical Induction

The lesson proved statements about all natural numbers with three steps, the way the books teach them.

## Dominoes, real or drawn
Stand ten dominoes (or draw ten rectangles) in a row. Tip the first: all fall. Now remove the third domino and tip the first again — the fall stops. Match the pieces aloud: the first tip is the base case; "each knocks the next" is the induction step; a missing domino is a step that fails for one k, and the whole proof fails with it. Laos's Grade 11 book states the same three steps for statements A(n) (Ch.2 L7, p.28), and Kazakhstan's Yelemessov Algebra 9 motivates the method with the same domino picture (§3.1, p.80).

## Build the squares
With counters or squared paper, build 1, then 1 + 3, then 1 + 3 + 5, then 1 + 3 + 5 + 7, as square layers. Record the side of each square: 1, 2, 3, 4. The layer you add to pass from n² to (n + 1)² has 2n + 1 counters — that layer IS the induction step of Cambodia's opening induction proof (Grade 11 Advanced, Ch.1 L3, pp.24–34).

## The 41 trap, by hand
Compute n² − n + 41 for n = 1, 2, 3, 4, 5 and test each answer for primality. Then compute it for n = 41 without expanding blindly: 41² − 41 + 41 = 41². Forty straight primes and then a square — Pakistan's warning, felt in your own arithmetic (Class 11, Unit 8, pp.140–150).

## Break this proof
Here is a "proof" that every n satisfies n = n + 1: assume k = k + 1; add 1 to both sides: k + 1 = k + 2, which is the statement for k + 1. Find the two faults (there is no base case, and the step assumes what it should prove). Kazakhstan's Soltan Algebra 9 sets this kind of "find the student's error" item in its induction section (§14, p.100).
