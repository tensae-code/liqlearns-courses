# Mathematical Logic — multiple choice

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Propositions and Connectives · (Level 2) -> Sub lesson 2 — Truth Tables, Equivalence and De Morgan · (Level 3) -> Sub lesson 3 — Quantifiers, Open Sentences and Inference.

Pick the one right answer.

**1. (Sub lesson 1)** Which of these is a proposition?
a) Close the book.  b) 9 is a prime number.  c) What a fine day!
**Answer:** b) 9 is a prime number — it can be judged (it is false), so it is a proposition (Laos, Grade 10, Ch.I L1, p.1).

**2. (Sub lesson 1)** p is true and q is false. What is the truth value of p∧q?
a) True  b) False  c) It cannot be known
**Answer:** b) False — "and" needs both sides true (Laos, Grade 10, Ch.I L1).

**3. (Sub lesson 1)** What is the negation of "5 is odd"?
a) 5 is even.  b) 5 is not odd.  c) 5 is odd and even.
**Answer:** b) 5 is not odd — negation flips the truth value without changing the subject (Yemen, Grade 10 Part 1, Unit 1 §1-1, p.7).

**4. (Sub lesson 2)** A truth table for a compound of three propositions has how many rows?
a) 6  b) 8  c) 9
**Answer:** b) 8 — n propositions give 2ⁿ rows, and 2³ = 8 (Laos, Grade 10, Ch.I L1).

**5. (Sub lesson 2)** ~(p∨q) is equivalent to which of these?
a) ~p∨~q  b) ~p∧~q  c) p∧q
**Answer:** b) ~p∧~q — De Morgan's law (Cambodia, Grade 10 Part 1, Ch.1, p.17).

**6. (Sub lesson 2)** p⇒q is false in exactly which case?
a) p false, q true  b) p false, q false  c) p true, q false
**Answer:** c) p true, q false — the only lying row of "if…then" (Iraq, Grade 10 Scientific, Ch.1 §1-2).

**7. (Sub lesson 3)** The negation of "Every pupil passed" is:
a) No pupil passed.  b) There is a pupil who did not pass.  c) Every pupil did not pass.
**Answer:** b) There is a pupil who did not pass — ~(∀x, P(x)) is ∃x, ~P(x) (Laos, Grade 10, Ch.I L3, p.20).

**8. (Sub lesson 3)** The contrapositive of "If n ends in 0, then n is even" is:
a) If n is even, then n ends in 0.  b) If n does not end in 0, then n is not even.  c) If n is not even, then n does not end in 0.
**Answer:** c) If n is not even, then n does not end in 0 — swap and negate both parts (Laos, Grade 10, Ch.I L2, p.14).
