# Mathematical Logic — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Propositions and Connectives · (Level 2) -> Sub lesson 2 — Truth Tables, Equivalence and De Morgan · (Level 3) -> Sub lesson 3 — Quantifiers, Open Sentences and Inference.

Say true or false, and be ready to say why.

**1. (Sub lesson 1)** "What is your name?" is a proposition.
**Answer:** False — a question has no truth value (Laos, Grade 10, Ch.I L1, p.1).

**2. (Sub lesson 1)** p∨q is true when exactly one of p and q is true, and also when both are true.
**Answer:** True — ∨ is the inclusive or; the exclusive or is a separate connective (Laos, Grade 10, Ch.I L1).

**3. (Sub lesson 2)** If two compound propositions have the same truth table, they are equivalent.
**Answer:** True — matching in every row is the definition of equivalence (Yemen, Grade 10 Part 1, Unit 1 §1-3, p.16).

**4. (Sub lesson 2)** ~(~p) has the same truth value as p.
**Answer:** True — negating twice returns the original value (Yemen, Grade 10 Part 1, Unit 1 §1-3, p.16).

**5. (Sub lesson 3)** The negation of "All triangles have a right angle" is "No triangle has a right angle."
**Answer:** False — the negation is "There is a triangle with no right angle" (Laos, Grade 10, Ch.I L3, p.20).

**6. (Sub lesson 3)** A statement and its converse always have the same truth value.
**Answer:** False — "ends in 0 ⇒ even" is true while its converse fails at 12 (Armenia, Grade 12 logic book, §6, p.36).
