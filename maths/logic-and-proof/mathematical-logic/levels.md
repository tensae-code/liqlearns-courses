# Mathematical Logic — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — mathematical logic — propositions and connectives first, then truth tables and equivalence, then quantifiers and inference.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3 — each old layer is one sub lesson, in the same order.

## Sub lesson 1 — Propositions and Connectives
Sub lesson 1 questions from the type files. Pass mark: decide whether a sentence is a proposition, give truth values, form negations, and join two propositions with each connective.

## Sub lesson 2 — Truth Tables, Equivalence and De Morgan
Sub lesson 2 questions from the type files. Pass mark: build a full truth table, judge equivalence from tables, apply De Morgan's laws, and recognise tautologies and contradictions.

## Sub lesson 3 — Quantifiers, Open Sentences and Inference
Sub lesson 3 questions from the type files. Pass mark: write and negate ∀ and ∃ statements, use the contrapositive, and judge a short argument valid or invalid.
