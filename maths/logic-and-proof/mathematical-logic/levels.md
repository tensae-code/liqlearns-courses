# Mathematical Logic — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — mathematical logic — propositions and connectives first, then truth tables and equivalence, then quantifiers and inference.

## Level 1 — propositions and connectives
Level 1 questions from the type files. Pass mark: decide whether a sentence is a proposition, give truth values, form negations, and join two propositions with each connective.

## Level 2 — truth tables, equivalence and De Morgan
Level 2 questions from the type files. Pass mark: build a full truth table, judge equivalence from tables, apply De Morgan's laws, and recognise tautologies and contradictions.

## Level 3 — quantifiers, open sentences and inference
Level 3 questions from the type files. Pass mark: write and negate ∀ and ∃ statements, use the contrapositive, and judge a short argument valid or invalid.
