# Levels — Mathematical Modelling

One lesson, one level (Level 141). The depth layers inside it are ranks.

## Depth layers

- **Layer 1 — Tell them apart, name the parts.** Distinguish a modelling question from a closed problem, and state the six components in order. Pass mark: 4 of 5.
- **Layer 2 — Build a small model.** For a given situation: define the problem, list assumptions out loud, name the variables, and write the model's equations. Pass mark: 5 of 6.
- **Layer 3 — Judge and improve.** Find a break-even point from two cost models, verify and interpret a model's answer in the situation's words, state a limitation, and improve the model by adding a variable. Pass mark: 4 of 5.

## What "maxed" means here

The learner can take a fresh "is it worth it?" question, run the full cycle — assumptions stated, variables named, mathematics applied, break-even found, answer interpreted, limitation confessed — and say what the next, better model would add.
