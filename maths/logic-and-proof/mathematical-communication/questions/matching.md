# Matching — Mathematical Communication

This lesson was built new with its sub lessons (Andorra expansion merge, 2026-11-11), founded on curriculum-requirement evidence only, so its markers are original — there are no older depth layers to map from.

1. (Sub lesson 1) Match each phrase to its symbols:
   (a) "a number increased by 7"
   (b) "double a number"
   (c) "a number shared into 4 equal parts"
   Symbols: 2n / n ÷ 4 / n + 7.
   **Answer: (a) n + 7; (b) 2n; (c) n ÷ 4.** Item constructed for this lesson from its founding requirement. 3. (Sub lesson 3) Match each starting representation to its faithful translation:
   (a) the table (1→3, 2→6, 3→9)
   (b) the words "a number minus five"
   (c) a graph whose line rises by the same amount at every step
   Translations: n − 5 / "it grows by the same amount each step" / y = 3x.
   **Answer: (a) y = 3x; (b) n − 5; (c) "it grows by the same amount each step."** Item constructed for this lesson from its founding requirement.
