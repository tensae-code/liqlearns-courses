# Ordering — Mathematical Communication

Sub-lesson markers: every item's marker names the sub lesson it belongs to — Sub lesson 1 — Saying It in Mathematical Language · Sub lesson 2 — The Many Representations · Sub lesson 3 — Translating Between Representations. This lesson was built new with its sub lessons (Andorra expansion merge, 2026-11-11), founded on curriculum-requirement evidence only, so its markers are original — there are no older depth layers to map from.

1. (Sub lesson 1) Put the parts of a complete communication in order:
   state the result / name the concept you are using / show the process step by step
   **Answer: name the concept you are using → show the process step by step → state the result.** Item constructed for this lesson from its founding requirement. Andorra, *Programa de matemàtiques de primera ensenyança* (Decret 376/2021, Annex VII), competency C3, printed pp. 8–21 — the communication competency, standing also as C4 in the Segona programme (Decret 355/2023, printed pp. 8–24) and in both Batxillerat programmes (Decret 374/2023; Decret 242/2025, printed pp. 8–21). Teacher evidence (curriculum requirement) — no pupil textbook teaches this lesson yet.
