# The pigeonhole principle — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — the pigeonhole principle — the plain guarantee first, then the division form, then proving with the generalised form, the order the books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3 — each old layer is one sub lesson, in the same order.

## Sub lesson 1 — More Things Than Boxes
Sub lesson 1 questions from the type files. Pass mark: state the principle, and use it on a direct case — n + 1 things in n boxes means some box holds at least two.

## Sub lesson 2 — The Division Form
Sub lesson 2 questions from the type files. Pass mark: work a case by division with remainder (things ÷ boxes), and read off the guaranteed number in some box, as China's Grade 6 book works 7 ÷ 3 = 2 remainder 1.

## Sub lesson 3 — Proving with the Generalised Form
Sub lesson 3 questions from the type files. Pass mark: apply the kn + 1 form, set up the boxes correctly in a new situation (birth months, error counts, remainders), and write the guarantee as a short proof.
