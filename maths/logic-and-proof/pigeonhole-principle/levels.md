# The pigeonhole principle — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the pigeonhole principle — the plain guarantee first, then the division form, then proving with the generalised form, the order the books teach it in.

## Level 1 — more things than boxes
Level 1 questions from the type files. Pass mark: state the principle, and use it on a direct case — n + 1 things in n boxes means some box holds at least two.

## Level 2 — the division form
Level 2 questions from the type files. Pass mark: work a case by division with remainder (things ÷ boxes), and read off the guaranteed number in some box, as China's Grade 6 book works 7 ÷ 3 = 2 remainder 1.

## Level 3 — proving with the generalised form
Level 3 questions from the type files. Pass mark: apply the kn + 1 form, set up the boxes correctly in a new situation (birth months, error counts, remainders), and write the guarantee as a short proof.
