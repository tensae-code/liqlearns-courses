# The pigeonhole principle — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — More Things Than Boxes · (Level 2) -> Sub lesson 2 — The Division Form · (Level 3) -> Sub lesson 3 — Proving with the Generalised Form.

Say true or false, and why.

**1. (Sub lesson 1)** With 5 things and 4 boxes, the pigeonhole principle tells you WHICH box holds two things.
**Answer:** False — it guarantees that some box does; it never points at the box.

**2. (Sub lesson 1)** Six pupils and six chairs guarantee that two pupils share a chair.
**Answer:** False — the principle needs MORE things than boxes; equal numbers can still sit one each.

**3. (Sub lesson 2)** If 20 things are shared into 6 boxes, some box holds at least 4.
**Answer:** True — 20 ÷ 6 = 3 remainder 2, so the leftovers push some box from 3 to 4.

**4. (Sub lesson 3)** North Macedonia's Grade 8 book calls this Dirichlet's principle and uses it as a proof method.
**Answer:** True — Theme 3, unit 8 (pp.153–155), with the 30-pupils, 9-error-counts proof.

**5. (Sub lesson 3)** In Kazakhstan's Grade 8 Algebra, the pigeonhole principle is a main, compulsory chapter.
**Answer:** False — it is filed as starred, optional additional material (§6.5*, p.177).
