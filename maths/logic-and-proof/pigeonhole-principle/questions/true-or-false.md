# The pigeonhole principle — true or false

Say true or false, and why.

**1. (Level 1)** With 5 things and 4 boxes, the pigeonhole principle tells you WHICH box holds two things.
**Answer:** False — it guarantees that some box does; it never points at the box.

**2. (Level 1)** Six pupils and six chairs guarantee that two pupils share a chair.
**Answer:** False — the principle needs MORE things than boxes; equal numbers can still sit one each.

**3. (Level 2)** If 20 things are shared into 6 boxes, some box holds at least 4.
**Answer:** True — 20 ÷ 6 = 3 remainder 2, so the leftovers push some box from 3 to 4.

**4. (Level 3)** North Macedonia's Grade 8 book calls this Dirichlet's principle and uses it as a proof method.
**Answer:** True — Theme 3, unit 8 (pp.153–155), with the 30-pupils, 9-error-counts proof.

**5. (Level 3)** In Kazakhstan's Grade 8 Algebra, the pigeonhole principle is a main, compulsory chapter.
**Answer:** False — it is filed as starred, optional additional material (§6.5*, p.177).
