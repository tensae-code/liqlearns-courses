# Ratio and Proportion — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — ratio and proportion — set by the
pattern across the countries' books: ratio itself first, then
equivalent ratios and sharing, then proportion, rate, scale and
working together.

## Level 1 — what a ratio is, and equivalent ratios
Level 1 questions from the type files. Pass mark: write and read
a ratio with the order right, find equivalent ratios, and
simplify a ratio.

## Level 2 — sharing in a ratio, and ratio with fractions and percent
Level 2 questions from the type files. Pass mark: share a whole
in a ratio, and turn a ratio into a fraction and a percent.

## Level 3 — proportion, unit rate, scale, working together
Level 3 questions from the type files. Pass mark: check a
proportion by cross-multiplication and find a missing term, find
a unit rate and a best buy, use direct proportion and the rule of
three, read a map scale, and work out a joint job.
