# Variation — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — variation — direct first, then inverse, then joint and partial.

## Level 1 — direct variation
Level 1 questions from the type files. Pass mark: recognise direct variation, write y = kx, find k from one pair, and find y for a new x (or x for a new y).

## Level 2 — inverse variation
Level 2 questions from the type files. Pass mark: recognise inverse variation, write y = k/x with xy = k, find k from one pair, and use it for new values.

## Level 3 — joint and partial variation
Level 3 questions from the type files. Pass mark: write joint variation as a product with one constant and use it, and split partial variation into its constant part and varying part (y = a + bx), finding a and b from two pairs.
