# Variation — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
variation — direct first, then inverse, then joint and partial.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Direct Variation
Sub lesson 1 questions from the type files. Pass mark: recognise direct variation, write y = kx, find k from one pair, and find y for a new x (or x for a new y).

## Sub lesson 2 — Inverse Variation
Sub lesson 2 questions from the type files. Pass mark: recognise inverse variation, write y = k/x with xy = k, find k from one pair, and use it for new values.

## Sub lesson 3 — Joint and Partial Variation
Sub lesson 3 questions from the type files. Pass mark: write joint variation as a product with one constant and use it, and split partial variation into its constant part and varying part (y = a + bx), finding a and b from two pairs. Pakistan's Class 10 items also sit here: joint forms mixed with an inverse square, and reshaping a proportion with its theorems and the k-method (Unit 3, printed pp.49–73).
