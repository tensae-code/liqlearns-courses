# Variation — ordering

Put the items in the order asked. Check each step before you write the answer.

**1. (Level 1)** Put the steps for a variation problem in order: (i) substitute the new value (ii) find k from the given pair (iii) write the law with k in it.
**Answer:** (ii), (iii), (i) — constant first, then the law, then the new value.

**2. (Level 2)** For y = 36/x, put these y-values in rising order: the values at x = 3, x = 12, x = 4, x = 18.
**Answer:** x = 18 (y = 2), x = 12 (y = 3), x = 4 (y = 9), x = 3 (y = 12) — as x grows, y shrinks.

**3. (Level 3)** For the partial law y = 4 + 5x, put these in rising order: y at x = 0, y at x = 3, y at x = 1, y at x = 2.
**Answer:** x = 0 (4), x = 1 (9), x = 2 (14), x = 3 (19) — each step of x adds the same 5.
