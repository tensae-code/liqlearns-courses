# Variation — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** In direct variation, doubling x doubles y.
**Answer:** True — y = kx grows in the same ratio as x.

**2. (Level 1)** If y = kx and k = 0.5, then y is always bigger than x.
**Answer:** False — y is half of x, so y is smaller.

**3. (Level 2)** In inverse variation, xy is the same for every pair of values.
**Answer:** True — xy = k, the constant.

**4. (Level 2)** Speed and time for the same journey vary directly.
**Answer:** False — they vary inversely: faster means less time.

**5. (Level 3)** Joint variation needs only one varying quantity on the right side.
**Answer:** False — joint variation follows two (or more) quantities together, as a product.

**6. (Level 3)** In partial variation, when x = 0 the value of y is a.
**Answer:** True — y = a + b × 0 = a, the still part alone.
