# Variation — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Direct Variation · (Level 2) -> Sub lesson 2 — Inverse Variation · (Level 3) -> Sub lesson 3 — Joint and Partial Variation.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** In direct variation, doubling x doubles y.
**Answer:** True — y = kx grows in the same ratio as x.

**2. (Sub lesson 1)** If y = kx and k = 0.5, then y is always bigger than x.
**Answer:** False — y is half of x, so y is smaller.

**3. (Sub lesson 2)** In inverse variation, xy is the same for every pair of values.
**Answer:** True — xy = k, the constant.

**4. (Sub lesson 2)** Speed and time for the same journey vary directly.
**Answer:** False — they vary inversely: faster means less time.

**5. (Sub lesson 3)** Joint variation needs only one varying quantity on the right side.
**Answer:** False — joint variation follows two (or more) quantities together, as a product.

**6. (Sub lesson 3)** In partial variation, when x = 0 the value of y is a.
**Answer:** True — y = a + b × 0 = a, the still part alone.

**7. (Sub lesson 3)** Gravitation varies jointly as the two masses and inversely as the square of the distance between them, as in Pakistan's Class 10 unit — so doubling one mass, with everything else fixed, doubles the gravitation.
**Answer:** True — the mass sits in the top product of G ∝ m₁m₂/d², so it pulls in direct proportion.
