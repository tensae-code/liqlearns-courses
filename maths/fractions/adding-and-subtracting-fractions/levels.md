# Adding and Subtracting Fractions — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — adding and subtracting fractions —
set by the pattern across the countries' books: same denominators
first, then different denominators made the same, then mixed
numbers.

## Level 1 — same denominators
Level 1 questions from the type files. Pass mark: add and subtract
fractions with the same denominator, and say why the denominator
stays the same.

## Level 2 — different denominators made the same
Level 2 questions from the type files. Pass mark: find a common
denominator with the LCM, rewrite both fractions, add or subtract,
and simplify the answer.

## Level 3 — mixed numbers, estimating, stories
Level 3 questions from the type files. Pass mark: add and subtract
mixed numbers with carrying and borrowing, estimate before
calculating, and solve story problems.
