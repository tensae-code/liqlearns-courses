# Adding and Subtracting Fractions — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Adding and Subtracting Fractions Same Denominators · (Level 2) -> Sub lesson 2 — Adding and Subtracting Fractions Different Denominators Made the Same · (Level 3) -> Sub lesson 3 — Adding and Subtracting Fractions Mixed Numbers, Estimating, Stories.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** 1/4 + 1/4 = 2/8.
**False** — two quarter-pieces are still quarters: 1/4 + 1/4
= 2/4 = 1/2.

**2. (Sub lesson 1)** 3/5 − 1/5 = 2/5.
**True** — subtract the numerators, keep the denominator.

**3. (Sub lesson 2)** 1/2 + 1/3 = 2/5.
**False** — make them sixths first: 3/6 + 2/6 = 5/6.

**4. (Sub lesson 2)** To add unlike fractions, make the denominators
the same first.
**True** — Ghana's B6 teacher manual starts with exactly that
command.

**5. (Sub lesson 3)** 2 1/4 + 1 1/4 = 3 1/2.
**True** — wholes 2 + 1 = 3, fractions 1/4 + 1/4 = 2/4 = 1/2.

**6. (Sub lesson 3)** 4/5 + 2/3 is less than 1.
**False** — it is 22/15, which is more than 1.
