# Adding and Subtracting Fractions — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** 1/4 + 1/4 = 2/8.
**False** — two quarter-pieces are still quarters: 1/4 + 1/4
= 2/4 = 1/2.

**2. (Level 1)** 3/5 − 1/5 = 2/5.
**True** — subtract the numerators, keep the denominator.

**3. (Level 2)** 1/2 + 1/3 = 2/5.
**False** — make them sixths first: 3/6 + 2/6 = 5/6.

**4. (Level 2)** To add unlike fractions, make the denominators
the same first.
**True** — Ghana's B6 teacher manual starts with exactly that
command.

**5. (Level 3)** 2 1/4 + 1 1/4 = 3 1/2.
**True** — wholes 2 + 1 = 3, fractions 1/4 + 1/4 = 2/4 = 1/2.

**6. (Level 3)** 4/5 + 2/3 is less than 1.
**False** — it is 22/15, which is more than 1.
