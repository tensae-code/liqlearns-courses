# Fractions — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
what a fraction is — halves and quarters first, then reading, writing and comparing, then equivalence and the forms bigger than one.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Halves, Quarters, and What a Fraction Says
Sub lesson 1 questions from the type files. Pass mark: split a whole into equal parts, name a half and a quarter, read and write a fraction, and say what the numerator and the denominator each mean.

## Sub lesson 2 — Fractions of Sets, the Number Line, Comparing
Sub lesson 2 questions from the type files. Pass mark: find a fraction of a set, place fractions on a number line, and compare two fractions (same denominator, same numerator).

## Sub lesson 3 — Equal Fractions, and Fractions Bigger Than One
Sub lesson 3 questions from the type files. Pass mark: find fractions equal to a given fraction, tell proper, improper and mixed numbers apart and move between improper and mixed, and find a fraction of a number and a number from its fraction.
