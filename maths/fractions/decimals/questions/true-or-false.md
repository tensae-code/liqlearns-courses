# Decimals — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Decimals Tenths, Hundredths, Thousandths · (Level 2) -> Sub lesson 2 — Decimals Comparing, Ordering, Rounding, Adding, Subtracting · (Level 3) -> Sub lesson 3 — Decimals Multiplying, Dividing, and by 10, 100, 1000.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** 0.5 = 1/2.
**True** — five tenths is one half.

**2. (Sub lesson 1)** 0.25 is bigger than 0.5.
**False** — 0.25 is 25 hundredths; 0.5 is 50 hundredths.

**3. (Sub lesson 2)** 0.40 is the same as 0.4.
**True** — trailing zeros change nothing.

**4. (Sub lesson 2)** 2.35 + 1.7 = 4.05.
**True** — pad first: 2.35 + 1.70 = 4.05.

**5. (Sub lesson 3)** 0.3 × 0.4 = 1.2.
**False** — one place plus one place is two places: 0.12.

**6. (Sub lesson 3)** 2.5 ÷ 0.5 = 5.
**True** — 25 ÷ 5 = 5.
