# Decimals — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — decimals — set by the pattern
across the countries' books: tenths and hundredths first, then
comparing and rounding, then all four operations.

## Level 1 — tenths, hundredths, thousandths
Level 1 questions from the type files. Pass mark: read and write
decimals to thousandths, turn fractions into decimals and decimals
into fractions, and say what each place after the point is worth.

## Level 2 — comparing, ordering, rounding, adding, subtracting
Level 2 questions from the type files. Pass mark: compare, order
and round decimals, and add and subtract them with the point
lined up.

## Level 3 — multiplying, dividing, and by 10, 100, 1000
Level 3 questions from the type files. Pass mark: multiply decimals
by counting the places, divide decimals by making the divisor
whole, and move the point for 10, 100 and 1000.
