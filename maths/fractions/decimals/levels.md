# Decimals — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
decimals — tenths and hundredths first, then comparing and rounding, then all four operations.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Decimals Tenths, Hundredths, Thousandths
Sub lesson 1 questions from the type files. Pass mark: read and write decimals to thousandths, turn fractions into decimals and decimals into fractions, and say what each place after the point is worth.

## Sub lesson 2 — Decimals Comparing, Ordering, Rounding, Adding, Subtracting
Sub lesson 2 questions from the type files. Pass mark: compare, order and round decimals, and add and subtract them with the point lined up.

## Sub lesson 3 — Decimals Multiplying, Dividing, and by 10, 100, 1000
Sub lesson 3 questions from the type files. Pass mark: multiply decimals by counting the places, divide decimals by making the divisor whole, and move the point for 10, 100 and 1000.
