# Bearings — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view.

The sub lessons are the depths inside this one thing — direction clockwise from north in
three figures — in the order Sierra Leone's course teaches it:
read and draw first, then reverse, then solve.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Reading, Writing and Drawing Bearings
Sub lesson 1 questions from the type files. Pass mark: read a compass bearing, write any bearing in three figures measured clockwise from north, and draw a bearing statement with a protractor.

## Sub lesson 2 — Reverse Bearings and Drawn Journeys
Sub lesson 2 questions from the type files. Pass mark: find any reverse bearing by the ±180° rule, draw a two-leg journey to scale, and write a position in distance-bearing form (r, θ).

## Sub lesson 3 — Solving Bearing Problems
Sub lesson 3 questions from the type files. Pass mark: solve a bearing problem with a right triangle (Pythagoras and the ratios), and solve one with a non-right triangle by choosing the sine or cosine rule.
