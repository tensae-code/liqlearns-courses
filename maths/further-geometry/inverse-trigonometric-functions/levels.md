# Inverse trigonometric functions — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — undoing sine, cosine and tangent —
in the order the books teach it: restrict and define first, then
evaluate, then compose and solve.

## Level 1 — restricting and defining
Level 1 questions from the type files. Pass mark: state the restricted domain and the range for arcsine, arccosine and arctangent, and say why a restriction is needed at all.

## Level 2 — evaluating inverse values
Level 2 questions from the type files. Pass mark: give exact inverse values for the special ratios, and use a calculator for other values, always landing inside the range.

## Level 3 — compositions and solving
Level 3 questions from the type files. Pass mark: simplify compositions such as cos(arcsin x), explain when arcsin(sin x) is and is not x, and solve a trigonometric equation graphically.
