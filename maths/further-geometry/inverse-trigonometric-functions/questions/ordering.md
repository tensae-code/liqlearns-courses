# Inverse trigonometric functions — ordering

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Restricting and Defining · (Level 2) -> Sub lesson 2 — Evaluating Inverse Values · (Level 3) -> Sub lesson 3 — Compositions and Solving.

Put each list in the right order.

**1. (Sub lesson 1)** Order the steps for defining an inverse trig function: (a) define the inverse, (b) restrict the domain to a one-to-one piece, (c) check the answer lies in the range.
**Answer:** (b), (a), (c) — restriction comes first, the range check comes last.

**2. (Sub lesson 2)** Order by size, smallest first: arccos(1), arctan(1), arcsin(1).
**Answer:** arccos(1) = 0°, arctan(1) = 45°, arcsin(1) = 90°.

**3. (Sub lesson 3)** Order the steps for simplifying cos(arcsin x): (a) read cos off the triangle, (b) let θ = arcsin x, (c) draw the triangle with hypotenuse 1 and opposite x, (d) find the adjacent side by Pythagoras.
**Answer:** (b), (c), (d), (a) — name the angle, draw, complete the triangle, then read the ratio.
