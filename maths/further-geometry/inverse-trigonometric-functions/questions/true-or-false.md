# Inverse trigonometric functions — true or false

Say true or false, and why.

**1. (Level 1)** Arcsine can be defined without restricting sine's domain. True or false?
**Answer:** False — sine repeats values, so without restriction one input would give many angles.

**2. (Level 1)** arctan a is defined for every real number a. True or false?
**Answer:** True — tangent takes every real value inside (−90°, 90°).

**3. (Level 2)** arcsin(sin 30°) = 30°. True or false?
**Answer:** True — 30° already lies inside the restricted domain.

**4. (Level 3)** arcsin(sin 200°) = 200°. True or false?
**Answer:** False — arcsine answers inside [−90°, 90°]; the value is −20°.

**5. (Level 3)** Cambodia's §3.2 detail was read in full in the student book. True or false?
**Answer:** False — as filed, §3.2 (printed p. 54) comes from the table of contents and the guide's lesson plan; the section start was not read in detail.
