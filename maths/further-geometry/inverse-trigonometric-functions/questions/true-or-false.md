# Inverse trigonometric functions — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Restricting and Defining · (Level 2) -> Sub lesson 2 — Evaluating Inverse Values · (Level 3) -> Sub lesson 3 — Compositions and Solving.

Say true or false, and why.

**1. (Sub lesson 1)** Arcsine can be defined without restricting sine's domain. True or false?
**Answer:** False — sine repeats values, so without restriction one input would give many angles.

**2. (Sub lesson 1)** arctan a is defined for every real number a. True or false?
**Answer:** True — tangent takes every real value inside (−90°, 90°).

**3. (Sub lesson 2)** arcsin(sin 30°) = 30°. True or false?
**Answer:** True — 30° already lies inside the restricted domain.

**4. (Sub lesson 3)** arcsin(sin 200°) = 200°. True or false?
**Answer:** False — arcsine answers inside [−90°, 90°]; the value is −20°.
