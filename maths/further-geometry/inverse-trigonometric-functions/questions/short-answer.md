# Inverse trigonometric functions — short answer

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Restricting and Defining · (Level 2) -> Sub lesson 2 — Evaluating Inverse Values · (Level 3) -> Sub lesson 3 — Compositions and Solving.

Answer in a word or a short sentence.

**1. (Sub lesson 1)** State the restricted domain Nicaragua's book gives for sine before inverting it.
**Answer:** [−π/2, π/2] (that is, [−90°, 90°]).

**2. (Sub lesson 1)** For which inputs is arcsin a defined?
**Answer:** For a in [−1, 1] only.

**3. (Sub lesson 2)** What is arccos(0)?
**Answer:** 90° (π/2).

**4. (Sub lesson 2)** What is arcsin(−√3/2)?
**Answer:** −60°.

**5. (Sub lesson 3)** Let θ = arcsin(3/5). What is tan θ?
**Answer:** 3/4 — the triangle is 3-4-5, so tan = opposite/adjacent = 3/4.

**6. (Sub lesson 3)** Name the method Nicaragua's book uses to solve tan x = sin x.
**Answer:** Graphical solving — draw both sides and read the crossings.
