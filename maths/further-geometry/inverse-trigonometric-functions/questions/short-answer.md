# Inverse trigonometric functions — short answer

Answer in a word or a short sentence.

**1. (Level 1)** State the restricted domain Nicaragua's book gives for sine before inverting it.
**Answer:** [−π/2, π/2] (that is, [−90°, 90°]).

**2. (Level 1)** For which inputs is arcsin a defined?
**Answer:** For a in [−1, 1] only.

**3. (Level 2)** What is arccos(0)?
**Answer:** 90° (π/2).

**4. (Level 2)** What is arcsin(−√3/2)?
**Answer:** −60°.

**5. (Level 3)** Let θ = arcsin(3/5). What is tan θ?
**Answer:** 3/4 — the triangle is 3-4-5, so tan = opposite/adjacent = 3/4.

**6. (Level 3)** Name the method Nicaragua's book uses to solve tan x = sin x.
**Answer:** Graphical solving — draw both sides and read the crossings.
