# Inverse trigonometric functions — multiple choice

Pick the one right answer.

**1. (Level 1)** Why must the domain of sine be restricted before arcsine can be defined?
a) Sine has no values outside [−1, 1]  b) Sine repeats the same value for many angles, so it is not one-to-one  c) Sine is not defined for large angles
**Answer:** b) — one ratio comes from many angles; the restriction keeps one angle per value.

**2. (Level 1)** The range of arccosine is:
a) [−90°, 90°]  b) (−90°, 90°)  c) [0°, 180°]
**Answer:** c) [0°, 180°] — the restricted cosine domain becomes the arccosine range.

**3. (Level 2)** arcsin(1/2) equals:
a) 30°  b) 60°  c) 150°
**Answer:** a) 30° — the angle inside [−90°, 90°] whose sine is 1/2; 150° is outside the range.

**4. (Level 2)** arctan(1) equals:
a) 0°  b) 45°  c) 135°
**Answer:** b) 45° — tan 45° = 1, and 45° lies inside (−90°, 90°).

**5. (Level 2)** tan⁻¹(2016) on a calculator is closest to:
a) 45°  b) just below 90°  c) just above 90°
**Answer:** b) just below 90° — arctangent answers inside (−90°, 90°), and a huge input pushes the angle towards 90°.

**6. (Level 3)** cos(arcsin x) equals:
a) √(1 − x²)  b) 1 − x²  c) x
**Answer:** a) √(1 − x²) — the triangle with hypotenuse 1 and opposite x has adjacent √(1 − x²).

**7. (Level 3)** arcsin(sin 200°) equals:
a) 200°  b) 20°  c) −20°
**Answer:** c) −20° — arcsine must answer inside [−90°, 90°], and sin(−20°) = sin 200°.
