# Transformations — true or false

Say true or false, and why in one line.

**1. (Level 1)** A reflection makes a shape back to front. — **True.** The mirror flips it, like "ambulance" writing.

**2. (Level 1)** A translation can turn a shape round. — **False.** A translation only slides; it never turns or flips.

**3. (Level 1)** Reflecting (5, 5) in the y-axis gives (−5, 5). — **True.** (x, y) → (−x, y).

**4. (Level 2)** A 90° rotation about the origin sends (1, 0) to (0, 1) anticlockwise. — **True.** (x, y) → (−y, x), so (1, 0) → (0, 1).

**5. (Level 2)** An enlargement with scale factor between 0 and 1 makes a shape bigger. — **False.** A factor between 0 and 1 shrinks it.

**6. (Level 2)** A rotation changes the angles of a shape. — **False.** Rotation keeps size and shape — the image is congruent.

**7. (Level 3)** Reflecting in the x-axis and then the y-axis is the same as a half-turn. — **True.** (x, y) → (x, −y) → (−x, −y).

**8. (Level 3)** Enlarging by scale factor 2 and then by scale factor 3 is the same as enlarging by scale factor 5. — **False.** Scale factors multiply: 2 × 3 = 6.
