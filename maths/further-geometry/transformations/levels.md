# Transformations — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view.

The sub lessons are the depths inside this one thing — moving a shape — set by the
pattern across the countries' books: the mirror and the slide
first, then the turn, then growing and combining.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Reflection and Translation
Sub lesson 1 questions from the type files. Pass mark: draw and name a reflection and a translation, and write the image of a point under (x, y) → (x, −y), (x, y) → (−x, y) and (x, y) → (x + a, y + b).

## Sub lesson 2 — Rotation and Enlargement
Sub lesson 2 questions from the type files. Pass mark: write the image of a point under 90° and 180° turns about the origin, enlarge a shape by a scale factor from a centre, and say whether each image is congruent or similar to its object.

## Sub lesson 3 — Combining Moves
Sub lesson 3 questions from the type files. Pass mark: combine two translations into one, name the single move equal to two reflections, and classify a combined result as congruent or similar.
