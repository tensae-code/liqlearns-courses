# Transformations — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — moving a shape — set by the
pattern across the countries' books: the mirror and the slide
first, then the turn, then growing and combining.

## Level 1 — reflection and translation
Level 1 questions from the type files. Pass mark: draw and
name a reflection and a translation, and write the image of a
point under (x, y) → (x, −y), (x, y) → (−x, y) and
(x, y) → (x + a, y + b).

## Level 2 — rotation and enlargement
Level 2 questions from the type files. Pass mark: write the
image of a point under 90° and 180° turns about the origin,
enlarge a shape by a scale factor from a centre, and say
whether each image is congruent or similar to its object.

## Level 3 — combining moves
Level 3 questions from the type files. Pass mark: combine two
translations into one, name the single move equal to two
reflections, and classify a combined result as congruent or
similar.
