# Three-dimensional trigonometry — true or false

Say true or false, and why.

**1. (Level 1)** A 3-D problem needs new ratios that flat trigonometry does not have. True or false?
**Answer:** False — the same sine, cosine, tangent and Pythagoras finish the job once the flat triangle is found.

**2. (Level 2)** The space diagonal of a 3 by 4 by 12 cuboid is 13. True or false?
**Answer:** True — base diagonal 5, then √(25 + 144) = 13.

**3. (Level 2)** You should reach for a trig ratio before drawing the hidden triangle. True or false?
**Answer:** False — length first, angle second; the triangle comes before any ratio.

**4. (Level 3)** The angle between a line and a face is the angle between the line and an edge of that face. True or false?
**Answer:** False — it is the angle between the line and its shadow on the face.

**5. (Level 3)** Jordan's 3-D lesson stands alone, with no bearings or rules lessons before it in its unit. True or false?
**Answer:** False — Unit 4 runs bearings (p. 100), sine rule (p. 106), cosine rule (p. 113) and area (p. 119) before the 3-D lesson (p. 124).
