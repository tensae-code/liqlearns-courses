# Three-dimensional trigonometry — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view.

The sub lessons are the depths inside this one thing — trigonometry in three dimensions —
in Jordan's order: find the hidden triangle first, then work it in
two steps, then angles to faces.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Finding the Hidden Triangle
Sub lesson 1 questions from the type files. Pass mark: given a cuboid or pyramid, name the flat right triangle the problem lives in, with its three vertices.

## Sub lesson 2 — The Two Flat Steps
Sub lesson 2 questions from the type files. Pass mark: work a space diagonal or slant length by Pythagoras first, then use that length in a trig ratio to finish the problem.

## Sub lesson 3 — Angles to Faces and Mixed Problems
Sub lesson 3 questions from the type files. Pass mark: find the angle between a line in space and a face via its shadow, and choose between a ratio, the sine rule and the cosine rule when the hidden triangle is not right-angled.
