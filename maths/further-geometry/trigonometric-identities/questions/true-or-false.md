# Trigonometric identities — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** sin²θ + cos²θ = 1 for θ = 200°.
**Answer:** True — the identity holds for every angle, not only acute ones.

**2. (Level 1)** cot(−225°) = 1, as printed in Pakistan's Class 11 book at p. 184.
**Answer:** False — −225° is coterminal with 135°, and cot 135° = −1; the printed 1 is a book error, taught corrected.

**3. (Level 2)** sin(α + β) = sin α + sin β for all angles.
**Answer:** False — at α = β = 30° the left side is sin 60° ≈ 0.866 and the right side is 1.

**4. (Level 2)** cos 105° is negative.
**Answer:** True — (√2 − √6)/4 is negative, and 105° is in the second quadrant.

**5. (Level 3)** tan 2α = 2 tan α/(1 − tan²α).
**Answer:** True — set β = α in tan(α + β).

**6. (Level 3)** When proving an identity you may move terms across the equals sign as with an equation.
**Answer:** False — work one side into the other; moving terms assumes the very thing to be proved.
