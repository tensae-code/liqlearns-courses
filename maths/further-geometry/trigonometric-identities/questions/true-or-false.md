# Trigonometric identities — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — The Basic Identities · (Level 2) -> Sub lesson 2 — The Addition Formulas · (Level 3) -> Sub lesson 3 — Double, Half, Sums to Products, and Proving.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** sin²θ + cos²θ = 1 for θ = 200°.
**Answer:** True — the identity holds for every angle, not only acute ones.

**2. (Sub lesson 1)** cot(−225°) = 1, as printed in Pakistan's Class 11 book at p. 184.
**Answer:** False — −225° is coterminal with 135°, and cot 135° = −1; the printed 1 is a book error, taught corrected.

**3. (Sub lesson 2)** sin(α + β) = sin α + sin β for all angles.
**Answer:** False — at α = β = 30° the left side is sin 60° ≈ 0.866 and the right side is 1.

**4. (Sub lesson 2)** cos 105° is negative.
**Answer:** True — (√2 − √6)/4 is negative, and 105° is in the second quadrant.

**5. (Sub lesson 3)** tan 2α = 2 tan α/(1 − tan²α).
**Answer:** True — set β = α in tan(α + β).

**6. (Sub lesson 3)** When proving an identity you may move terms across the equals sign as with an equation.
**Answer:** False — work one side into the other; moving terms assumes the very thing to be proved.

**7. (Sub lesson 2)** Egypt's Pure Mathematics Grade 11 book teaches the half-angle identities as a lesson.
**Answer:** False — its Unit 4 carries sum/difference (lesson 4-2) and the double angle (lesson 4-3) only; the filing states there is no half-angle or triple-angle lesson.

**8. (Sub lesson 3)** If α + β + γ = π, then tan α + tan β + tan γ = tan α tan β tan γ.
**Answer:** True — the triangle identity in Kazakhstan's Abylkasymova consolidation section (Algebra 9, Part 2, §29, printed p. 89).
