# Trigonometric identities — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the identity chain — basic
identities first, then the addition formulas, then the formulas
that follow from them and proving identities, the order the books
teach it in.

## Level 1 — the basic identities
Level 1 questions from the type files. Pass mark: state and use
sin²θ + cos²θ = 1, tan θ = sin θ/cos θ and the reciprocal and
Pythagorean partners, and find one ratio from another with the
quadrant's sign.

## Level 2 — the addition formulas
Level 2 questions from the type files. Pass mark: state the
addition formulas for sin, cos and tan, say how cos(α − β) is
proved, and evaluate angles like 75° and 105° exactly.

## Level 3 — double, half, sums to products, and proving
Level 3 questions from the type files. Pass mark: use the
double, half and triple formulas, change a sum to a product and
a·cosθ ± b·sinθ to a single term, and prove a short identity by
rewriting one side.
