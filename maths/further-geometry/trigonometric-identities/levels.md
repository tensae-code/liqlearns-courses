# Trigonometric identities — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson

The sub lessons are the depths inside this one thing — the identity chain — basic
identities first, then the addition formulas, then the formulas
that follow from them and proving identities, the order the books
teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3. The reduction and related-angles paragraph follows the addition chain in the text and is kept in Sub lesson 2 with it.

## Sub lesson 1 — The Basic Identities
Sub lesson 1 questions from the type files. Pass mark: state and use sin²θ + cos²θ = 1, tan θ = sin θ/cos θ and the reciprocal and Pythagorean partners, and find one ratio from another with the quadrant's sign.

## Sub lesson 2 — The Addition Formulas
Sub lesson 2 questions from the type files. Pass mark: state the addition formulas for sin, cos and tan, say how cos(α − β) is proved, and evaluate angles like 75° and 105° exactly.

## Sub lesson 3 — Double, Half, Sums to Products, and Proving
Sub lesson 3 questions from the type files. Pass mark: use the double, half and triple formulas, change a sum to a product and a·cosθ ± b·sinθ to a single term, and prove a short identity by rewriting one side.
