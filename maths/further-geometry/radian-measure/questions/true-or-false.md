# Radian measure — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** 1° = 100′.
**Answer:** False — 1° = 60′; the sexagesimal system splits by 60, not 100.

**2. (Level 1)** −120.43° = −120°25′48″.
**Answer:** True — 0.43° = 25.8′ and 0.8′ = 48″ (Nicaragua, Grade 10 student book, Unit 2).

**3. (Level 2)** 1 rad is bigger than 57°.
**Answer:** True — 1 rad = 180°/π ≈ 57.3°.

**4. (Level 2)** A right angle is 200 gradians.
**Answer:** False — a right angle is 100 gradians; 200 gradians is a half turn.

**5. (Level 3)** 390° and 30° are coterminal.
**Answer:** True — 390° − 360° = 30°, Bangladesh's own pair (Ch. 7, printed pp. 162–163).

**6. (Level 3)** s = rθ gives the right arc length when θ is in degrees.
**Answer:** False — θ must be in radians; in degrees the formula needs a /360 factor.
