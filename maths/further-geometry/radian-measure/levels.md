# Radian measure — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — measuring angles — degrees and DMS
first, then radians and gradians, then directed angles and arc
length, the order the books teach it in.

## Level 1 — degrees, minutes and seconds
Level 1 questions from the type files. Pass mark: state 1° = 60′,
1′ = 60″ and 1° = 3600″, and change a DMS angle to decimal degrees
and back without losing a carry.

## Level 2 — radians and gradians
Level 2 questions from the type files. Pass mark: define the
radian, use 180° = π to convert both ways including the standard
angles, and convert a right angle and a full turn into gradians.

## Level 3 — directed angles and arc length
Level 3 questions from the type files. Pass mark: find a coterminal
angle and its quadrant for angles past 360° and negative angles,
and use s = rθ and A = ½r²θ with θ in radians.
