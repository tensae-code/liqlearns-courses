# Radian measure — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view.

The sub lessons are the depths inside this one thing — measuring angles — degrees and DMS
first, then radians and gradians, then directed angles and arc
length, the order the books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Degrees, Minutes and Seconds
Sub lesson 1 questions from the type files. Pass mark: state 1° = 60′, 1′ = 60″ and 1° = 3600″, and change a DMS angle to decimal degrees and back without losing a carry.

## Sub lesson 2 — Radians and Gradians
Sub lesson 2 questions from the type files. Pass mark: define the radian, use 180° = π to convert both ways including the standard angles, and convert a right angle and a full turn into gradians.

## Sub lesson 3 — Directed Angles and Arc Length
Sub lesson 3 questions from the type files. Pass mark: find a coterminal angle and its quadrant for angles past 360° and negative angles, and use s = rθ and A = ½r²θ with θ in radians.
