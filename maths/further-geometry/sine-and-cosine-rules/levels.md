# Sine and cosine rules — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view.

The sub lessons are the depths inside this one thing — solving any triangle — set by the
pattern across the countries' books: the sine rule first, then
the cosine rule, then area and choosing between the rules.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — The Sine Rule
Sub lesson 1 questions from the type files. Pass mark: write the sine rule, name the matching pairs, and find a missing side or angle when a side and its angle across are known.

## Sub lesson 2 — The Cosine Rule
Sub lesson 2 questions from the type files. Pass mark: write the cosine rule, find a third side from two sides and the angle between them, find an angle from three sides, and say why Pythagoras is the cosine rule with a right angle.

## Sub lesson 3 — Area and Choosing the Rule
Sub lesson 3 questions from the type files. Pass mark: find a triangle's area from two sides and the included angle, spot the ambiguous case, and choose the right rule for a mixed problem (including bearings).
