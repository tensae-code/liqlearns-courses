# Sine and cosine rules — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — solving any triangle — set by the
pattern across the countries' books: the sine rule first, then
the cosine rule, then area and choosing between the rules.

## Level 1 — the sine rule
Level 1 questions from the type files. Pass mark: write the
sine rule, name the matching pairs, and find a missing side
or angle when a side and its angle across are known.

## Level 2 — the cosine rule
Level 2 questions from the type files. Pass mark: write the
cosine rule, find a third side from two sides and the angle
between them, find an angle from three sides, and say why
Pythagoras is the cosine rule with a right angle.

## Level 3 — area and choosing the rule
Level 3 questions from the type files. Pass mark: find a
triangle's area from two sides and the included angle, spot
the ambiguous case, and choose the right rule for a mixed
problem (including bearings).
