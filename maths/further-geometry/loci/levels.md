# Loci: paths of moving points — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the path of a point obeying a rule —
in the order Sierra Leone's course teaches it: distance from a
point, then equal distances, then mixed work.

## Level 1 — what a locus is, and distance from a point or a line
Level 1 questions from the type files. Pass mark: define a locus as the set of all points satisfying a condition, and give the locus for a fixed distance from a point (a circle) and from a straight line (two parallels).

## Level 2 — the two equidistant loci
Level 2 questions from the type files. Pass mark: construct and justify the perpendicular bisector as the locus of points equidistant from two points, and the angle bisectors as the locus of points equidistant from two straight lines.

## Level 3 — the both-directions proof and mixed constructions
Level 3 questions from the type files. Pass mark: argue a locus both ways in Iran's manner (every point on the path obeys the rule, and every point obeying the rule is on the path), use the catalogue loci, and combine two loci to pin down a point.
