# Loci: paths of moving points — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view.

The sub lessons are the depths inside this one thing — the path of a point obeying a rule —
in the order Sierra Leone's course teaches it: distance from a
point, then equal distances, then mixed work.

Mapping from the old depth layers: the lesson text meets the four loci in the order point, two points, two lines, line, while old Level 1 grouped the distance-from-a-point and distance-from-a-line loci together. The sub lessons follow the text's order, so old Level 1 splits at that jump: its definition and distance-from-a-point part is Sub lesson 1, and its distance-from-a-line part is Sub lesson 3, and its pass mark splits the same way below. Old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 4.

## Sub lesson 1 — What a Locus Is, and Distance from a Point
Sub lesson 1 questions from the type files. Pass mark: define a locus as the set of all points satisfying a condition, and give the locus for a fixed distance from a point (a circle).

## Sub lesson 2 — The Two Equidistant Loci
Sub lesson 2 questions from the type files. Pass mark: construct and justify the perpendicular bisector as the locus of points equidistant from two points, and the angle bisectors as the locus of points equidistant from two straight lines.

## Sub lesson 3 — Distance from a Straight Line
Sub lesson 3 questions from the type files. Pass mark: give the locus for a fixed distance from a straight line (two parallels).

## Sub lesson 4 — The Both-Directions Proof and Mixed Constructions
Sub lesson 4 questions from the type files. Pass mark: argue a locus both ways in Iran's manner (every point on the path obeys the rule, and every point obeying the rule is on the path), use the catalogue loci, and combine two loci to pin down a point.
