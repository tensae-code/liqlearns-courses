# Loci: paths of moving points — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** The locus of points at a given distance from a given point is a circle. True or false?
**Answer:** True — centre the point, radius the distance (Sierra Leone, L92, printed p. 126).

**2. (Level 1)** A locus may contain just some of the points that satisfy the condition. True or false?
**Answer:** False — a locus is ALL the points satisfying the condition, and no others.

**3. (Level 2)** The locus of points at a given distance from a straight line is a single parallel line. True or false?
**Answer:** False — it is two parallel lines, one on each side; the rule names no side (L95).

**4. (Level 2)** Every point on the perpendicular bisector of AB is equidistant from A and B. True or false?
**Answer:** True — that equality is exactly the rule the bisector is the locus of (L93).

**5. (Level 3)** To prove a path is a locus, it is enough to check that points on the path obey the rule. True or false?
**Answer:** False — Iran's book proves it both directions: points obeying the rule must also all lie on the path (Geometry (3), Ch. 2 L1, printed pp. 36–38).

**6. (Level 3)** In Greece's book, a point that keeps seeing a fixed chord under the same known angle moves along a straight line. True or false?
**Answer:** False — it moves along an arc of a circle, the arc subtending the known angle (Euclidean Geometry Volume A, Ch. 6, chapter opens printed p. 127).
