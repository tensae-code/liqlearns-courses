# Video script — Loci: paths of moving points

The super-simple voice, for the video that rides on top of the
lesson (lesson-plan.md, add-on list). Made later, when videos are
made; the script is the slot's written form until then.

---

A point is walking. It must obey ONE rule. Where can it go?
The path it draws is called a **locus**!

Rule: stay the SAME distance from one point.
The path is a **circle**!

Rule: stay the same distance from TWO points.
The path is a straight line — the **perpendicular bisector**!

Rule: stay the same distance from two straight LINES.
The path is the **bisector** of the angle between them!

Rule: stay the same distance from one straight line.
The path is TWO lines — one parallel on each side!

One rule. One path. ALL the points that obey — no more, no less.

Now you. I give a rule. You give me the path!
