# Congruence and similarity — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view.

The sub lessons are the depths inside this one thing — same or same-shape — set by the
pattern across the countries' books: congruent first, then
similar, then the scale factor's work on area and volume.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Congruent Shapes
Sub lesson 1 questions from the type files. Pass mark: say what congruent means, name the SSS, SAS, ASA, AAS and RHS checks, and prove two triangles congruent from their sides and angles.

## Sub lesson 2 — Similar Shapes
Sub lesson 2 questions from the type files. Pass mark: say what similar means, name the AA, SSS and SAS checks, find a missing length from a scale factor, and use similar triangles on a shadow problem.

## Sub lesson 3 — The Scale Factor on Area and Volume
Sub lesson 3 questions from the type files. Pass mark: use k for lengths, k² for areas and k³ for volumes every time, and work a scale-drawing area problem without mixing the three up.
