# Congruence and similarity — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — same or same-shape — set by the
pattern across the countries' books: congruent first, then
similar, then the scale factor's work on area and volume.

## Level 1 — congruent
Level 1 questions from the type files. Pass mark: say what
congruent means, name the SSS, SAS, ASA, AAS and RHS checks,
and prove two triangles congruent from their sides and angles.

## Level 2 — similar
Level 2 questions from the type files. Pass mark: say what
similar means, name the AA, SSS and SAS checks, find a missing
length from a scale factor, and use similar triangles on a
shadow problem.

## Level 3 — scale factor on area and volume
Level 3 questions from the type files. Pass mark: use k for
lengths, k² for areas and k³ for volumes every time, and work
a scale-drawing area problem without mixing the three up.
