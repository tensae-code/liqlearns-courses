# Right-triangle trigonometry — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view.

The sub lessons are the depths inside this one thing — sine, cosine and tangent in a
right triangle — set by the pattern across the countries' books:
name the sides and the ratios first, then find sides, then
find angles and use the ratios outside.

Mapping from the old depth layers: the lesson text meets its parts in the order ratios, sides, angles, special angles, applications, while old Level 2 grouped side-finding with the special angles and old Level 3 grouped angle-finding with the outside applications. The sub lessons follow the text's order, so old Level 2 splits at those jumps — its side-finding part is Sub lesson 2 and its special-angles part is Sub lesson 4 — and old Level 3 splits the same way — angle-finding is Sub lesson 3 and using it outside is Sub lesson 5 — and their pass marks split the same way below. Old Level 1 = Sub lesson 1.

## Sub lesson 1 — Naming the Sides and the Ratios
Sub lesson 1 questions from the type files. Pass mark: name the hypotenuse, opposite and adjacent for a marked angle, and write sin, cos and tan as ratios (SOHCAHTOA).

## Sub lesson 2 — Finding Missing Sides
Sub lesson 2 questions from the type files. Pass mark: choose the right ratio for a missing side, and find a side to a sensible accuracy.

## Sub lesson 3 — Finding Angles
Sub lesson 3 questions from the type files. Pass mark: use the inverse ratios to find an angle.

## Sub lesson 4 — The Special Angles
Sub lesson 4 questions from the type files. Pass mark: use the special angles 30°, 45° and 60° from memory.

## Sub lesson 5 — Using It Outside
Sub lesson 5 questions from the type files. Pass mark: solve elevation and depression problems (ladder, building, tree).
