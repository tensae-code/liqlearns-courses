# Right-triangle trigonometry — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — sine, cosine and tangent in a
right triangle — set by the pattern across the countries' books:
name the sides and the ratios first, then find sides, then
find angles and use the ratios outside.

## Level 1 — naming the sides and the ratios
Level 1 questions from the type files. Pass mark: name the
hypotenuse, opposite and adjacent for a marked angle, and
write sin, cos and tan as ratios (SOHCAHTOA).

## Level 2 — finding missing sides
Level 2 questions from the type files. Pass mark: choose the
right ratio for a missing side, use the special angles
30°, 45° and 60° from memory, and find a side to a sensible
accuracy.

## Level 3 — finding angles and using it outside
Level 3 questions from the type files. Pass mark: use the
inverse ratios to find an angle, and solve elevation and
depression problems (ladder, building, tree).
