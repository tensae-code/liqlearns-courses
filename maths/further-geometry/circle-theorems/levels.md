# Circle theorems — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view.

The sub lessons are the depths inside this one thing — angles and lines in a circle —
set by the pattern across the countries' books: the inscribed
angle first, then chords and tangents, then cyclic
quadrilaterals and the segment products.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3. In the lesson text the segment products are met before the cyclic quadrilaterals; both are Sub lesson 3, so the text's order is kept as it stands.

## Sub lesson 1 — The Inscribed Angle
Sub lesson 1 questions from the type files. Pass mark: state the inscribed-angle theorem, use the angle in a semicircle, and say why angles in the same segment are equal.

## Sub lesson 2 — Chords and Tangents
Sub lesson 2 questions from the type files. Pass mark: use the radius-through-a-chord's-midpoint fact, use the tangent–chord angle, and say what a tangent does at the point of contact.

## Sub lesson 3 — Cyclic Quadrilaterals and Segment Products
Sub lesson 3 questions from the type files. Pass mark: use the cyclic quadrilateral rule (opposite angles add to 180°) and its converse, and use the intersecting-chords, secant and tangent–secant products.
