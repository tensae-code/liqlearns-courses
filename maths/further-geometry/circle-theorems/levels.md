# Circle theorems — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — angles and lines in a circle —
set by the pattern across the countries' books: the inscribed
angle first, then chords and tangents, then cyclic
quadrilaterals and the segment products.

## Level 1 — the inscribed angle
Level 1 questions from the type files. Pass mark: state the
inscribed-angle theorem, use the angle in a semicircle, and
say why angles in the same segment are equal.

## Level 2 — chords and tangents
Level 2 questions from the type files. Pass mark: use the
radius-through-a-chord's-midpoint fact, use the tangent–chord
angle, and say what a tangent does at the point of contact.

## Level 3 — cyclic quadrilaterals and segment products
Level 3 questions from the type files. Pass mark: use the
cyclic quadrilateral rule (opposite angles add to 180°) and
its converse, and use the intersecting-chords, secant and
tangent–secant products.
