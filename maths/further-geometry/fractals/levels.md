# Fractals: shapes inside shapes — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view.

The sub lessons are the depths inside this one thing — shapes built by repeating one step —
in the order China's readings present them: the paper figures
first, then the iteration that grows sets on a computer.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Self-Similarity and the Sierpiński Figures
Sub lesson 1 questions from the type files. Pass mark: say what self-similarity means, run one Sierpiński step on a triangle and on a carpet, and count the survivors (×3 triangles, ×8 squares).

## Sub lesson 2 — The Koch Snowflake
Sub lesson 2 questions from the type files. Pass mark: run the Koch step on a segment, count segments (×4) and lengths (×1/3 each), and show the snowflake's perimeter grows by 4/3 at every step.

## Sub lesson 3 — Iteration: Julia and Mandelbrot
Sub lesson 3 questions from the type files. Pass mark: iterate z → z² + c by hand for c = 0, 1 and −1, tell a bounded orbit from an escaping one, and say in one sentence how that one test grows the Julia and Mandelbrot sets in the reading.
