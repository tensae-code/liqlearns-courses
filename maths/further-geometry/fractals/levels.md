# Fractals: shapes inside shapes — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — shapes built by repeating one step —
in the order China's readings present them: the paper figures
first, then the iteration that grows sets on a computer.

## Level 1 — self-similarity and the Sierpiński figures
Level 1 questions from the type files. Pass mark: say what self-similarity means, run one Sierpiński step on a triangle and on a carpet, and count the survivors (×3 triangles, ×8 squares).

## Level 2 — the Koch snowflake
Level 2 questions from the type files. Pass mark: run the Koch step on a segment, count segments (×4) and lengths (×1/3 each), and show the snowflake's perimeter grows by 4/3 at every step.

## Level 3 — iteration: Julia and Mandelbrot
Level 3 questions from the type files. Pass mark: iterate z → z² + c by hand for c = 0, 1 and −1, tell a bounded orbit from an escaping one, and say in one sentence how that one test grows the Julia and Mandelbrot sets in the reading.
