# Fractals: shapes inside shapes — short answer

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Self-Similarity and the Sierpiński Figures · (Level 2) -> Sub lesson 2 — The Koch Snowflake · (Level 3) -> Sub lesson 3 — Iteration: Julia and Mandelbrot.

Answer in a word or a short line.

**1. (Sub lesson 1)** What is the name for a figure's property of looking the same at every scale?
**Answer:** Self-similarity (China, Grade 9 Volume 2 reading, printed pp. 45–46).

**2. (Sub lesson 1)** After three Sierpiński triangle steps (starting from 1 triangle), how many smallest triangles survive?
**Answer:** 27 — the survivors multiply by 3 each step: 1, 3, 9, 27.

**3. (Sub lesson 2)** A Koch snowflake's perimeter after some step is 16/3 units. What is it after the next step?
**Answer:** 64/9 units — multiply by 4/3: (16/3) × (4/3) = 64/9.

**4. (Sub lesson 3)** Iterate z → z² + c from z₀ = 0 with c = 0. Write the first three values after z₀.
**Answer:** 0, 0, 0 — the orbit stays at 0, bounded forever (B-edition reading, printed pp. 40–41).

**5. (Sub lesson 3)** Iterate z → z² + c from z₀ = 0 with c = 1. Write the first three values after z₀ and state the fate.
**Answer:** 1, 2, 5 — and the next is 26; the orbit escapes to infinity.
