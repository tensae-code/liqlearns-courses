**2. (Sub lesson 3)** Match the c value to the fate of the orbit of 0 under z → z² + c: (i) c = 0, (ii) c = 1, (iii) c = −1 — (a) escapes: 1, 2, 5, 26…, (b) stays at 0, (c) cycles: −1, 0, −1, 0…
**Answer:** (i)–(b), (ii)–(a), (iii)–(c) — bounded, escaping, and bounded-cycling, the three fates worked in the lesson from the B-edition reading (printed pp. 40–41).
