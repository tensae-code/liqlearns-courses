# Fractals: shapes inside shapes — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** The Sierpiński carpet is built by removing the centre square and repeating the step in the survivors. True or false?
**Answer:** True — split into 9, remove the centre, repeat in the 8 survivors (Grade 9 Volume 2 reading, printed pp. 45–46).

**2. (Level 2)** The Koch snowflake's perimeter settles at a fixed length after a few steps. True or false?
**Answer:** False — every step multiplies the perimeter by 4/3, so it grows without end while the shape stays in a bounded region.

**3. (Level 2)** In the Koch snowflake, later steps add detail but the smallest segments get longer. True or false?
**Answer:** False — each step's segments are 1/3 the length of the previous step's; the detail gets smaller, not bigger.

**4. (Level 3)** With c = −1, the orbit of 0 under z → z² + c escapes to infinity. True or false?
**Answer:** False — the orbit is 0 → −1 → 0 → −1 …, a bounded cycle of period 2 (B-edition reading, printed pp. 40–41).
