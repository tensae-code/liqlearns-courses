# Fractals: shapes inside shapes — ordering

Put each list in the right order.

**1. (Level 1)** Order the counts of surviving Sierpiński triangles as the steps run: 9, 1, 27, 3.
**Answer:** 1, 3, 9, 27 — multiplied by 3 at every step (Grade 9 Volume 2 reading, printed pp. 45–46).

**2. (Level 3)** Order the orbit of 0 under z → z² + 1, step by step: 5, 0 (the start), 26, 1, 2.
**Answer:** 0, 1, 2, 5, 26 — square, then add 1, each time; the orbit escapes (B-edition reading, printed pp. 40–41).
