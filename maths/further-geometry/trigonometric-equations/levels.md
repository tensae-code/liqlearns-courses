# Trigonometric equations — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — solving trigonometric equations —
the basic forms on the unit circle first, then the general
solution and equations that need identities, then the single-term
form and inequalities, the order the books teach it in.

## Level 1 — the basic forms on the unit circle
Level 1 questions from the type files. Pass mark: solve
sin x = a, cos x = a and tan x = a on [0, 2π) with both angles
named, and recognise the no-solution cases |a| > 1 for sine and
cosine.

## Level 2 — the general solution and identity equations
Level 2 questions from the type files. Pass mark: write the
general solution with n ∈ ℤ, extract the solutions in a given
interval, and solve equations by rewriting in one ratio,
factorising or substituting — including quadratic-shaped ones.

## Level 3 — the single-term form, graphs and inequalities
Level 3 questions from the type files. Pass mark: solve
a·cosθ ± b·sinθ = c by the single-term form, read solutions off
a graph, and solve a trigonometric inequality on the unit circle.
