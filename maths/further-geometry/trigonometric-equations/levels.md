# Trigonometric equations — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view.

The sub lessons are the depths inside this one thing — solving trigonometric equations —
the basic forms on the unit circle first, then the general
solution and equations that need identities, then the single-term
form and inequalities, the order the books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — The Basic Forms on the Unit Circle
Sub lesson 1 questions from the type files. Pass mark: solve sin x = a, cos x = a and tan x = a on [0, 2π) with both angles named, and recognise the no-solution cases |a| > 1 for sine and cosine.

## Sub lesson 2 — The General Solution and Identity Equations
Sub lesson 2 questions from the type files. Pass mark: write the general solution with n ∈ ℤ, extract the solutions in a given interval, and solve equations by rewriting in one ratio, factorising or substituting — including quadratic-shaped ones.

## Sub lesson 3 — The Single-Term Form, Graphs and Inequalities
Sub lesson 3 questions from the type files. Pass mark: solve a·cosθ ± b·sinθ = c by the single-term form, read solutions off a graph, and solve a trigonometric inequality on the unit circle.
