# Trigonometric equations — multiple choice

Pick the one right answer.

**1. (Level 1)** On [0, 2π), sin x = 1/2 has solutions —
a) π/6 only  b) π/6 and 5π/6  c) π/6 and 7π/6
**Answer:** b) π/6 and 5π/6 — the line at height 1/2 cuts the unit circle twice.

**2. (Level 1)** sin x = 2 has —
a) one solution  b) two solutions  c) no solution
**Answer:** c) no solution — sine never passes 1, so |a| > 1 gives no solution.

**3. (Level 1)** On [0, 2π), tan x = 1 has solutions —
a) π/4 and 5π/4  b) π/4 only  c) π/4 and 3π/4
**Answer:** a) π/4 and 5π/4 — tangent repeats every half turn, π.

**4. (Level 2)** The general solution of sin x = 1 is —
a) x = π/2  b) x = π/2 + 2πn, n ∈ ℤ  c) x = π/2 + πn, n ∈ ℤ
**Answer:** b) x = π/2 + 2πn, n ∈ ℤ — one solution per turn, plus whole turns (Nicaragua's module example).

**5. (Level 2)** Solving 2cos²x − 1 = 0 on [0, 2π) starts by —
a) dividing by cos x  b) writing cos x = ±√2/2  c) taking arcsine
**Answer:** b) cos x = ±√2/2 — it is a quadratic in cos x with no cos term.

**6. (Level 2)** In sin x(2cos x − 1) = 0, the solution families are —
a) sin x = 0 only  b) cos x = 1/2 only  c) sin x = 0 or cos x = 1/2
**Answer:** c) sin x = 0 or cos x = 1/2 — factorising keeps both families; dividing would lose one.

**7. (Level 3)** To solve 3cos θ + 4sin θ = 5, first write the left side as —
a) 5cos(θ − φ) with cos φ = 3/5, sin φ = 4/5  b) 7cos(θ − φ)  c) 5sin θ
**Answer:** a) 5cos(θ − φ) — R = √(9 + 16) = 5, Libya's single-term method.

**8. (Level 3)** cos(2x − π/4) ≥ √3/2 on 0 ≤ x < 2π holds for —
a) all x  b) x ∈ [π/24, 5π/24] or [25π/24, 29π/24]  c) x = π/4 only
**Answer:** b) — Laos's worked inequality (Grade 11, Ch. 8 L32), via t = 2x − π/4.
