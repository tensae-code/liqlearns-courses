# Trigonometric equations — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** sin x = 1/2 has exactly one solution on [0, 2π).
**Answer:** False — it has two, π/6 and 5π/6; the line cuts the circle twice.

**2. (Level 1)** cos x = −2 has no solution.
**Answer:** True — cosine never reaches −2.

**3. (Level 2)** Dividing sin x(2cos x − 1) = 0 by sin x is a safe first step.
**Answer:** False — it throws away the whole sin x = 0 family of solutions; factor instead.

**4. (Level 2)** The general solution of tan x = 1 is x = π/4 + πn, n ∈ ℤ.
**Answer:** True — tangent's period is π, so one solution per half turn suffices.

**5. (Level 3)** A trigonometric equation can be checked by reading its solutions off a graph.
**Answer:** True — South Sudan and China both solve from graphs beside the algebra.

**6. (Level 3)** cos t ≥ √3/2 holds exactly for the single angle t = π/6.
**Answer:** False — it holds for the whole arc −π/6 ≤ t ≤ π/6 (plus whole turns); an inequality gives arcs, not points.
