# Trigonometric equations — ordering

Put the items in the order asked. Check each step before you write the answer.

**1. (Level 2)** Put Nicaragua's general-solution method in order: (a) write each solution plus 2πn, (b) find the particular solutions in one period, (c) pick out the solutions inside the interval asked for.
**Answer:** (b) particular solutions in one period, (a) write the general solution, (c) pick out the interval's solutions — Unit 3's order.

**2. (Level 3)** Put the steps for Laos's inequality cos(2x − π/4) ≥ √3/2 in order: (a) turn the t-arcs back into x-intervals, (b) set t = 2x − π/4, (c) shade where cos t ≥ √3/2 on the circle.
**Answer:** (b) set t, (c) shade the arc, (a) turn back into x-intervals — substitution, circle, return.

**3. (Level 3)** Put these solution angles of 2cos²x − 1 = 0 in order, smallest first: 5π/4, π/4, 7π/4, 3π/4.
**Answer:** π/4, 3π/4, 5π/4, 7π/4 — the four quarter-turn family from cos x = ±√2/2.
