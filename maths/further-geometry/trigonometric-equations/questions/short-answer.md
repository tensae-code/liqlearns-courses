# Trigonometric equations — short answer

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — The Basic Forms on the Unit Circle · (Level 2) -> Sub lesson 2 — The General Solution and Identity Equations · (Level 3) -> Sub lesson 3 — The Single-Term Form, Graphs and Inequalities.

Answer in a word or a short line.

**1. (Sub lesson 1)** Solve cos x = −√3/2 on [0, 2π).
**Answer:** 5π/6 and 7π/6 — the vertical line x = −√3/2 cuts the circle in quadrants II and III.

**2. (Sub lesson 1)** Solve sin x = √3/2 on [0, 2π).
**Answer:** π/3 and 2π/3 — heights equal at the symmetric pair.

**3. (Sub lesson 1)** How many solutions does cos x = 1 have on [0, 2π)?
**Answer:** One: x = 0 — the line touches at the single point (1, 0) per turn.

**4. (Sub lesson 2)** Write the general solution of sin x = 1/2.
**Answer:** x = π/6 + 2πn or x = 5π/6 + 2πn, n ∈ ℤ — particular solutions first, then whole turns (Nicaragua, Unit 3).

**5. (Sub lesson 2)** Solve 2cos²x − 3cos x + 1 = 0 on [0, 2π) by substitution.
**Answer:** (2cos x − 1)(cos x − 1) = 0, so cos x = 1/2 or cos x = 1: x = π/3, 5π/3, 0 — a quadratic in cos x (South Sudan's quadratic type).

**6. (Sub lesson 3)** Solve 3cos θ + 4sin θ = 5 on [0, 2π).
**Answer:** θ = φ where cos φ = 3/5, sin φ = 4/5 (θ ≈ 53.1°) — cos(θ − φ) = 1 forces θ = φ in the turn.

**7. (Sub lesson 3)** Solve cos x ≥ √3/2 on [0, 2π).
**Answer:** x ∈ [0, π/6] or x ∈ [11π/6, 2π) — within π/6 of (1, 0) on the circle.

**8. (Sub lesson 3)** Name Armenia's two steps for this topic.
**Answer:** The simplest equations first (§10), then the main solving methods — factorisation and substitution (§11).
