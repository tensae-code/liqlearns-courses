# Trigonometric equations — matching

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — The Basic Forms on the Unit Circle · (Level 2) -> Sub lesson 2 — The General Solution and Identity Equations · (Level 3) -> Sub lesson 3 — The Single-Term Form, Graphs and Inequalities.

Match each item on the left to its partner on the right.

**1. (Sub lesson 1)** Match each equation to its solution set on [0, 2π): (a) sin x = 1 (b) cos x = −1 (c) tan x = 0 — x = 0 and π, x = π/2, x = π
**Answer:** a) x = π/2, b) x = π, c) x = 0 and π — each read off the unit circle.

**2. (Sub lesson 1)** Match each basic form to Cambodia's solving order: (a) tan x = a (b) cos x = a (c) sin x = a — first, second, third
**Answer:** a) third, b) first, c) second — Ch. 3 Lesson 3 order (printed pp. 98–112).

**3. (Sub lesson 2)** Match each equation to its method: (a) 2cos²x − 1 = 0 (b) sin x(2cos x − 1) = 0 (c) mixed sines and cosines — single-ratio rewrite first, factorise, quadratic in one ratio
**Answer:** a) quadratic in one ratio, b) factorise, c) single-ratio rewrite first — Armenia's and Nicaragua's named methods.

**4. (Sub lesson 3)** Match each source to its special strength: (a) Laos (b) Libya (c) South Sudan — the a·cosθ ± b·sinθ form, the worked unit-circle inequality, graphical and arithmetical solving side by side
**Answer:** a) the worked unit-circle inequality, b) the a·cosθ ± b·sinθ form, c) graphical and arithmetical solving side by side — as filed for each book.
