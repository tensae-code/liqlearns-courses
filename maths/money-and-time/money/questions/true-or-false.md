# Money — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Money — Knowing the Pieces · (Level 2) -> Sub lesson 2 — Money — Making and Exchanging Amounts · (Level 3) -> Sub lesson 3 — Money — Paying, Change and Money Arithmetic.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** Every country joins its small money unit to its big unit with the same number.
**Answer:** False — Bangladesh, Ethiopia and Nicaragua join at 100, China joins at 10, and Libya joins at 1,000.

**2. (Sub lesson 1)** 45/1000 of a Kuwaiti dinar is 45 fils.
**Answer:** True — Kuwait's Grade 7 book works fractions of a dinar this way.

**3. (Sub lesson 2)** One amount can be made in more than one way with different pieces.
**Answer:** True — Cambodia's Grade 3 book makes 5000 riel two different ways from note groups.

**4. (Sub lesson 2)** Price + change must equal the payment.
**Answer:** True — that equality is the check on every change sum in the lesson.

**5. (Sub lesson 3)** Kuwait's Grade 3 p.147 item, as printed, has a correct option among groups totalling 8, 11 and 11 dinars for a 10-dinar note.
**Answer:** False — none of 8, 11 or 11 is 10, so the item has no correct option as printed and is taught corrected, never set as a valid question.

**6. (Sub lesson 3)** Iraq's books teach money as a topic.
**Answer:** False — Iraq's filing is an explicit negative: money is never a topic there, so Iraq is not a source for this lesson.
