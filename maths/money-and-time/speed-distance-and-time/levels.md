# Speed, Distance and Time — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
speed, distance and time — the triangle first, then journeys and graphs, then the other rates the books teach with it.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Speed, Distance and Time — the Triangle and Its Units
Sub lesson 1 questions from the type files. Pass mark: find any one of speed, distance and time from the other two, with the unit written, and change between km/h and m/s.

## Sub lesson 2 — Speed, Distance and Time — Journeys: Average Speed, Graphs and Meeting Problems
Sub lesson 2 questions from the type files. Pass mark: find average speed as total distance ÷ total time; read speed, stops and returns off a distance–time graph; solve meeting, opposite-direction and catch-up problems with relative speed.

## Sub lesson 3 — Speed, Distance and Time — Density and Work Rates
Sub lesson 3 questions from the type files. Pass mark: use density = mass ÷ volume and population density in all directions; work mass-per-area problems; add work rates for joint work and find a joint finishing time.
