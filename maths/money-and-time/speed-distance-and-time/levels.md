# Speed, Distance and Time — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — speed, distance and time — the triangle first, then journeys and graphs, then the other rates the books teach with it.

## Level 1 — the triangle and its units
Level 1 questions from the type files. Pass mark: find any one of speed, distance and time from the other two, with the unit written, and change between km/h and m/s.

## Level 2 — journeys: average speed, graphs, meeting problems
Level 2 questions from the type files. Pass mark: find average speed as total distance ÷ total time; read speed, stops and returns off a distance–time graph; solve meeting, opposite-direction and catch-up problems with relative speed.

## Level 3 — the other compound rates: density and work rates
Level 3 questions from the type files. Pass mark: use density = mass ÷ volume and population density in all directions; work mass-per-area problems; add work rates for joint work and find a joint finishing time.
