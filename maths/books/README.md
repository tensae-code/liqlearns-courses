**One file per country** (his workflow rule, 2026-10-25,
carried into the maths phase): for every country — download
its maths books, read them, create the country's file here,
and fill the file as the reading finds things. Every book is
read in full, page by page; then a SEPARATE citation-check
pass (checker ≠ reader) verifies the filing's anchors
against the books' own pages before the country is called
read.

Each country file holds: what the books are (country,
grades, publishers, verified file facts), their full
unit/chapter maps with printed pages, honest negatives,
held-copy defects, and every record correction the covers
prove.
