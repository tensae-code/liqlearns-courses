# Jordan — Maths books

**Jordan is CLOSED in the library, and its maths set is the second largest of any
closed country: 95 books recorded, and all 95 are in hand** (the library record
calls 52 of them student books and 43 teacher books; the books themselves correct
that split in places — see the corrections below). All 95 files were read and filed
below in five grade bands on 2026-11-04: **10,862 PDF pages**, resolving into
**68 distinct works**. Every band's filing then passed a separate citation check
(checker ≠ reader): **1,254 anchors checked against the books' own pages — 1,208
passed, 46 corrected in place, 0 not found**. The per-band counts and every
correction stand in the check block at the end of each band below.

**The file count, reconciled plainly:** the library's books.json records 95 Jordan
maths entries and all 95 were grabbed and held (61 via release assets, 6 from local
staging, 28 from the git tree via the Contents API — each size-verified against the
tree's recorded size). The TSV lists 91 of the 95 — a subset, not a competing count.
The five band lists (23 + 21 + 18 + 8 + 25) sum to 95 unique files, no file in two
bands. One file sits in two record slots by error (the Grade 6 guide in the Grade 3
slot — correction 2 below), which is why a slot count and a distinct-work count
differ: 95 files, 68 distinct works.

**The course:** Jordan's current maths course was prepared originally in English for
the National Center for Curriculum Development (NCCD) by HarperCollins and
translated, adapted and published in Arabic by the Center. It runs Grades 1–12 as a
student book plus an exercise book (كتاب التمارين, "Exercise Book" — recorded as
"Workbook Book") per term, with teacher guides that are wrap-around companions:
they reproduce the student book and the exercise book with answers inside scripted
lesson-by-lesson teaching notes. Older Ministry-series guides also sit in the record
for Grades 3–5. Every book in the set is in Arabic.

## GRADE 1 — STUDENT BOOKS AND WORKBOOKS

**Lesson format (all four student books, W1/W3/W5/W7):** each unit opens with a
readiness page ("I get ready to study the unit") and a unit project page; each lesson
is a 2-page spread — "I learn today" (explore + learn, with a terms box giving English
equivalents) and "I check my understanding", the check page often ending with a home
activity addressed to parents; each unit closes with a "Let's play together" game page
and an end-of-unit test. Grade 2 adds cumulative questions after each unit test.
Manipulatives named throughout are Dienes base-ten blocks (قطع دينز), counters, beans,
sticks and cubes.
