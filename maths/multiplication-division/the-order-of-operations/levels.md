# The-order-of-operations — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the order of operations — multiply and divide first, then brackets first, then left to right and the full order..


## Level 1 — multiply and divide first
Level 1 questions from the type files. Pass mark: work out expressions with no brackets, doing multiply and divide before add and subtract.

## Level 2 — brackets first
Level 2 questions from the type files. Pass mark: work out expressions with brackets, doing the brackets first and then the same order inside and outside.

## Level 3 — left to right and the full order
Level 3 questions from the type files. Pass mark: work left to right when operations are on the same level, and work out expressions with brackets and all four operations.
