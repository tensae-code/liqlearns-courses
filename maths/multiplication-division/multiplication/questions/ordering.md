Put the items in the order asked. Check each step before you write the answer.

**1. (Sub lesson 1)** Put these products in order, smallest first: 3 × 4; 5 × 6; 7 × 8.
Answer the products in order.
**Answer:** 12, 30, 56 — the products in order.

**2. (Sub lesson 2)** Put these column steps in order: multiply the tens; write the carried ten; multiply the ones; write the answer.
Answer in order.
**Answer:** Multiply the ones; write the carried ten; multiply the tens; write the answer — ones first, then tens.

**3. (Sub lesson 3)** Put these products in order, smallest first: 30 × 4; 132 × 3; 300 × 4.
Answer the products in order.
**Answer:** 120, 396, 1,200 — the products in order.

**4. (Sub lesson 4)** Put the steps for 23 × 14 in a working order: (a) add the parts: 230 + 92 = 322 (b) multiply by the ones part: 23 × 4 = 92 (c) multiply by the tens part: 23 × 10 = 230.
**Answer:** c, b, a — split the multiplier, multiply each part, add.
