Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. Put the items in the order asked. Check each step before you write the answer.

**1. (Sub lesson 1)** Put these products in order, smallest first: 3 × 4; 5 × 6; 7 × 8.
Answer the products in order.
**Answer:** 12, 30, 56 — the products in order.

**2. (Sub lesson 2)** Put these column steps in order: multiply the tens; write the carried ten; multiply the ones; write the answer.
Answer in order.
**Answer:** Multiply the ones; write the carried ten; multiply the tens; write the answer — ones first, then tens.
