# Multiplication — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Multiplication Equal Groups and the First Tables · (Level 2) -> Sub lesson 2 — Multiplication The Tables to Nine and Columns · (Level 3) -> Sub lesson 3 — Multiplication Three Digits, Tens and Hundreds. Sub lesson 4 — Big Multiplication: Partial Products, To a Million and Beyond — was added 2026-11-08 under the whole-arc rule.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** 3 × 4 = 4 × 3.
**Answer:** True — multiplication works in either order.

**2. (Sub lesson 1)** 3 × 4 = 3 + 4.
**Answer:** False — 3 × 4 is 3 groups of 4, which is 12; 3 + 4 is 7.

**3. (Sub lesson 2)** 23 × 4 = 92.
**Answer:** True — ones 12 (write 2, carry 1), tens 8 + 1 = 9.

**4. (Sub lesson 2)** In column multiplication you start from the tens.
**Answer:** False — you start from the ones, the way column addition does.

**5. (Sub lesson 3)** 30 × 4 = 120.
**Answer:** True — 3 tens × 4 = 12 tens.

**6. (Sub lesson 3)** 300 × 4 = 120.
**Answer:** False — 300 × 4 is 3 hundreds × 4 = 12 hundreds = 1,200.

**7. (Sub lesson 4)** Partial products means: multiply by each part of the multiplier, then add the parts.
**Answer:** True — that is the method (Saudi Arabia and Pakistan, Grade 4).

**8. (Sub lesson 4)** A product can pass 1,000,000 even when both numbers multiplied are under a million.
**Answer:** True — 48,215 × 32 = 1,542,880 (Rwanda, Primary 6).
