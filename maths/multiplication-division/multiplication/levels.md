# Multiplication — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — multiplying — equal groups and the first tables first, then the tables to nine and columns, then three digits and tens..


## Level 1 — equal groups and the tables
Level 1 questions from the type files. Pass mark: explain multiplication as equal groups, and know the tables for 2, 3, 4 and 5.

## Level 2 — the tables to nine and columns
Level 2 questions from the type files. Pass mark: know the tables for 6, 7, 8 and 9, and multiply two-digit numbers by one digit in columns.

## Level 3 — three digits, tens and hundreds
Level 3 questions from the type files. Pass mark: multiply three-digit numbers by one digit in columns, and multiply by tens and hundreds.
