# Division — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — dividing — sharing and the tables first, then remainders, then columns with checking..


## Level 1 — sharing and the tables
Level 1 questions from the type files. Pass mark: share a number into equal parts, and divide using the times tables.

## Level 2 — remainders
Level 2 questions from the type files. Pass mark: divide with a remainder, say what the remainder means, and know the remainder must be smaller than the divisor.

## Level 3 — in columns and checking
Level 3 questions from the type files. Pass mark: divide two- and three-digit numbers by one digit in columns, and check every division by multiplying.
