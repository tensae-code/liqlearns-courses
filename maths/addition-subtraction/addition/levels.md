# Addition — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — adding — in the head first, then in columns with carrying, then three digits with checking..


## Level 1 — in the head
Level 1 questions from the type files. Pass mark: add one- and two-digit numbers in the head by counting on and making ten.

## Level 2 — in columns with carrying
Level 2 questions from the type files. Pass mark: add two-digit numbers in columns, with carrying from ones to tens, and say each step aloud.

## Level 3 — three digits and checking
Level 3 questions from the type files. Pass mark: add three-digit numbers in columns with carrying, and check an answer by adding the other way round and by estimating.
