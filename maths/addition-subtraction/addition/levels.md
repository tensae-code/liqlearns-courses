# Addition — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — adding —
in the head first, then in columns with carrying, then three
digits with checking..

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Addition In the Head
Sub lesson 1 questions from the type files. Pass mark: add one- and two-digit numbers in the head by counting on and making ten.

## Sub lesson 2 — Addition In Columns with Carrying
Sub lesson 2 questions from the type files. Pass mark: add two-digit numbers in columns, with carrying from ones to tens, and say each step aloud.

## Sub lesson 3 — Addition Three Digits and Checking
Sub lesson 3 questions from the type files. Pass mark: add three-digit numbers in columns with carrying, and check an answer by adding the other way round and by estimating.
