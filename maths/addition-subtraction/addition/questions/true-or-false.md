# Addition — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Addition In the Head · (Level 2) -> Sub lesson 2 — Addition In Columns with Carrying · (Level 3) -> Sub lesson 3 — Addition Three Digits and Checking. Sub lesson 4 — Big Addition: To a Million and Beyond — was added 2026-11-08 under the whole-arc rule.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** 8 + 5 = 13.
**Answer:** True — make ten: 8 + 2 = 10, and 3 are left.

**2. (Sub lesson 1)** In column addition you start from the tens.
**Answer:** False — you start from the ones place (Egypt, Grade 2).

**3. (Sub lesson 2)** 47 + 35 = 82.
**Answer:** True — ones 12, carry 1; tens 4 + 3 + 1 = 8.

**4. (Sub lesson 2)** You may forget the carried 1 if the answer looks right.
**Answer:** False — the carried 1 is part of the tens; forgetting it gives the wrong answer.

**5. (Sub lesson 3)** 63 + 74 must give the same answer as 74 + 63.
**Answer:** True — adding the other way round is the check.

**6. (Sub lesson 4)** Adding numbers past a million needs a new method, different from the three-digit columns.
**Answer:** False — the same columns; only the line is longer.

**7. (Sub lesson 4)** A carry can step out of the ones period into the thousands period.
**Answer:** True — that is carrying across periods (Rwanda, Primary 6).
