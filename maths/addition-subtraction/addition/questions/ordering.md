# Addition — ordering

Put the items in the order asked. Check each step before you write the answer.

**1. (Sub lesson 2)** Put these column steps in order: add the tens; write the carried 1; add the ones; write the answer.
Answer in order.
**Answer:** Add the ones; write the carried 1; add the tens; write the answer — ones first, then tens.

**2. (Sub lesson 3)** Put these sums in order, smallest first: 347 + 185; 658 + 24; 926 + 138.
Answer the sums in order.
**Answer:** 347 + 185 (532); 658 + 24 (682); 926 + 138 (1,064) — smallest answer first.

**3. (Sub lesson 1)** Put these sums in order, smallest first: 8 + 5; 27 + 5; 9 + 7.
Answer the sums in order.
**Answer:** 8 + 5 (13); 9 + 7 (16); 27 + 5 (32) — smallest answer first.

**4. (Sub lesson 4)** Put the steps for 487,650 + 275,483 in the order they run: (a) thousands period: 487 + 275 + 1 = 763 (b) ones period: 650 + 483 = 1,133 — write 133, carry 1 (c) read the answer: 763,133.
**Answer:** b, a, c — work period by period from the ones period, carrying across.
