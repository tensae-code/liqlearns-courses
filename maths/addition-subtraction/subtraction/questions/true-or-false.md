# Subtraction — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** 15 − 3 = 18.
**Answer:** False — 15 − 3 = 12. The workbook answer '15 − 3 = 18' is flagged wrong in Ghana's filing and is never taught.

**2. (Level 1)** 52 − 48 = 4.
**Answer:** True — count up from 48: 4 jumps.

**3. (Level 2)** In 54 − 37 you may subtract 7 − 4 in the ones column.
**Answer:** False — never swap digits in a column; borrow from the tens instead.

**4. (Level 2)** 137 − 54 = 83.
**Answer:** True — ones 3, tens 13 − 5 = 8.

**5. (Level 3)** 83 + 54 = 137 checks 137 − 54 = 83.
**Answer:** True — the difference plus what was taken away gives the starting number.
