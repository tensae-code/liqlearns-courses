# Subtraction — ordering

Put the items in the order asked. Check each step before you write the answer.

**1. (Level 2)** Put these column steps in order: subtract the tens; borrow from the tens; subtract the ones; write the answer.
Answer in order.
**Answer:** Borrow from the tens; subtract the ones; subtract the tens; write the answer — borrow first, then ones, then tens.

**2. (Level 3)** Put these differences in order, smallest first: 107 − 59; 503 − 268; 1,000 − 437.
Answer the differences in order.
**Answer:** 48, 235, 563 — the differences in order.

**3. (Level 1)** Put these differences in order, smallest first: 52 − 48; 13 − 5; 16 − 9.
Answer the differences in order.
**Answer:** 4, 7, 8 — the differences in order.
