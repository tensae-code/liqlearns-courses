# Folk Dance Practice: Tigray and Eskesta Steps — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** The pattern is practised on one side only. True or false?
**Answer: False — it is mirrored.**

**2. (Sub lesson 2)** Eskesta practice uses a different leg pattern from Tigray. True or false?
**Answer: False — the same pattern, counted fast.**
