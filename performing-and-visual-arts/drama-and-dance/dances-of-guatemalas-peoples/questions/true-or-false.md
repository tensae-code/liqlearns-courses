# Dances of Guatemala's Peoples — true or false

Say true or false.

**1. (Sub lesson 1)** Dances have meanings, not only steps.
**Answer: True.**

**2. (Sub lesson 1)** The experience teaches only your own people's dances.
**Answer: False — it initiates learners into other peoples' dances too.**

**3. (Sub lesson 2)** A first initiation is a beginner's entering-in, done with respect.
**Answer: True.**

**4. (Sub lesson 2)** The full activity pages for this theme are held in the PARTIAL file.
**Answer: False — they are not in the file; the theme is taught as named.**
