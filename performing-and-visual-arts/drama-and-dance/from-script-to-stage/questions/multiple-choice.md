# From Script to Stage — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A script is chosen for —
a) artistic quality and realistic resources  b) length only  c) its cover
**Answer: a) artistic quality and realistic resources.**

**2. (Sub lesson 1)** The crew includes —
a) director, choreographer, producer, musical director, PR  b) only actors  c) only the audience
**Answer: a) director, choreographer, producer, musical director, PR.**

**3. (Sub lesson 1)** The rough budget covers —
a) costumes, props, make-up, publicity  b) salaries of kings  c) nothing
**Answer: a) costumes, props, make-up, publicity.**

**4. (Sub lesson 2)** Casting is done by —
a) lottery  b) auditions  c) age
**Answer: b) auditions.**

**5. (Sub lesson 2)** Blocking is —
a) placing the action on stage  b) selling tickets  c) painting the set
**Answer: a) placing the action on stage.**

**6. (Sub lesson 2)** The last rehearsal before opening is —
a) the table read  b) the dress rehearsal  c) the first blocking
**Answer: b) the dress rehearsal.**
