# Video script — From Script to Stage

A short read-aloud script in a super-simple voice, made later as the lesson's video. It follows the lesson's own order and names only what the lesson teaches.

---

First, find a script — quality, and resources you truly have.
Then the outline, the crew, the budget, the vision.
Casting. Then rehearsals: table read, blocking, again and again, dress rehearsal.
Publicity — and opening night.
