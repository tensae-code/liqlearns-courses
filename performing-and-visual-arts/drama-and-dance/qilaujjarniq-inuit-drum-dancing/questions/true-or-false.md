# Qilaujjarniq: Inuit Drum Dancing — true or false

Say true or false.

**1. (Sub lesson 1)** Drum dancing is a new custom invented for schools.
**Answer: False — it is an old custom.**

**2. (Sub lesson 2)** East and west drum dancing are exactly the same.
**Answer: False — one singer with a big skin-wrapped drum in the east; rim-beating and group singing in the west.**

**3. (Sub lesson 3)** Drum dancing is still performed more in the west than the east.
**Answer: True.**

**4. (Sub lesson 3)** Children learn drum dancing only from books.
**Answer: False — schools and communities teach them.**
