# Mato: Surinamese Storytelling Theatre — true or false

Say true or false.

**1. (Sub lesson 1)** A Mato is performed in a circle.
**Answer: True.**

**2. (Sub lesson 1)** Among the Ndyuka, the Anansitori falls under the Mato genre.
**Answer: True.**

**3. (Sub lesson 2)** The Pikiman must never interrupt or confirm — only the Matoman speaks.
**Answer: False — the Pikiman confirms each part and directs the piece.**
