# Interactive Theatre — true or false

Say true or false.

**1. (Sub lesson 1)** In interactive theatre the audience takes part in the performance.
**Answer: True.**

**2. (Sub lesson 1)** Interactive theatre and traditional theatre treat the audience in exactly the same way.
**Answer: False** — in traditional theatre the audience receives a finished performance; in interactive theatre it enters the work.

**3. (Sub lesson 2)** Egypt's Grade 7 book ends this topic with an interactive performance called "Rights and Duties".
**Answer: True.**

**4. (Sub lesson 2)** In an interactive performance, nobody may speak an opinion that was not in a fixed script.
**Answer: False** — speaking one's opinion freely and improvising dialogue from situations are the form's working parts.
