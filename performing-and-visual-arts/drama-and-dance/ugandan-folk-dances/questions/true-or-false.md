# Ugandan Folk Dances — true or false

Say true or false.

**1. (Sub lesson 1)** Every Ugandan ethnic group dances in exactly the same way.
**Answer: False — each group has its own motifs, instruments, costumes and props.**

**2. (Sub lesson 1)** The folk dances are an inheritance transmitted for centuries.
**Answer: True.**

**3. (Sub lesson 2)** The choreographed dance belongs with the folk song.
**Answer: True.**

**4. (Sub lesson 3)** Naming the dance's features and function is part of the work, not an extra.
**Answer: True** (teacher guide — evidence).
