# Simple Drama Structures — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** A play is only people talking, with no shape. True or false?
**Answer: False — a play takes a shape that can be recognised.**

**2. (Sub lesson 2)** A story with no ending still has the full three-beat shape. True or false?
**Answer: False — the end beat is part of the shape.**
