# Hands-on — Traditional Games

The lesson with your hands and your feet, not only your eyes.

## A games afternoon
With friends, run the full set in one session: one circle game (ሰኞ ማክሰኞ Senyo Maksenyo), one hiding game (ድብብቆሽ hide-and-seek), one pair game (ድምቡሸ ገላ Dimbushe Gela), one skill game (ቅልሞሽ Qilmosh or the ሳንካ sanka grid), and rope jumping to finish. Each game gets a different teacher from the group — teaching a game is part of knowing it.

## The stone set
Find five small, smooth stones of about the same size. Keep them as YOUR ቅልሞሽ (Qilmosh) set in a pouch or a tin. Practise the toss and catch seated, legs spread, counting aloud. Smooth stones and a steady count matter more than speed.
