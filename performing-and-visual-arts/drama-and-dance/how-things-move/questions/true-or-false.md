# How Things Move — true or false

Sub-lesson markers: every item's marker names the sub lesson it belongs to.

Say if it is true or false.

**1. (Sub lesson 1)** A child walks and runs on two legs.
**Answer: True.**

**2. (Sub lesson 2)** A cat runs on two legs.
**Answer: False** — the cat runs on four legs.

**3. (Sub lesson 3)** A bird travels by flying with spread wings.
**Answer: True.**

**4. (Sub lesson 2)** Four-legged movers cannot run fast.
**Answer: False** — the dog and the cat run fast on four legs.
