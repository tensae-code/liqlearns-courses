# The Dancer's Body: Conditioning and Safe Practice — true or false

Say true or false.

**1. (Sub lesson 1)** Drinking water during practice is part of dancing well.
**Answer: True.**

**2. (Sub lesson 1)** The body uses water slowly during exercise, so there is no need to drink.
**Answer: False — the body uses it up fast; drink extra.**

**3. (Sub lesson 2)** Stretching before dancing gets the body ready.
**Answer: True.**

**4. (Sub lesson 2)** Stretching is done so muscles will be more sore.
**Answer: False — so muscles are not so sore.**
