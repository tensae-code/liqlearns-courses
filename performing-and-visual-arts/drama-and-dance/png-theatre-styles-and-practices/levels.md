# PNG Theatre Styles and Practices — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure). Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Theatre rooted in the community
Sub lesson 1 questions from the type files. Pass mark: Learners observe a traditional performance in the local community, work on a play by a Papua New Guinean writer, and identify a myth or legend from the local community; the elements of dance and drama are explored against the physical, spiritual and social environment.

## Sub lesson 2 — PNG's named theatre forms
Sub lesson 2 questions from the type files. Pass mark: The guide's world-theatre list names Papua New Guinea's own forms: Orokolo Eharo mask theatre, Sepik Tambaran dance theatre, Trobriand Kesawaga dance theatre, Malangan mask theatre, Kerema Hevehe mask theatre, and Eastern Highlands farce drama.

## Sub lesson 3 — Analysing the genre
Sub lesson 3 questions from the type files. Pass mark: The unit closes with a summative analysis of the genre of the selected work — the community's own performance, judged as theatre.
