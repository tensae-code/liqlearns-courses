# What Theatre Is — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Theatre must always use the voice. True or false?
**Answer: False — it can be organised with voice or without voice.**

**2. (Sub lesson 2)** Music can be part of a play. True or false?
**Answer: True.**

**3. (Sub lesson 3)** The audience organises the play. True or false?
**Answer: False — the director organises it; the audience watches it.**
