# Dance Practice and Imitation — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** You can learn a dance fully just by watching it once. True or false?
**Answer: False — it takes practical, repeated practice.**

**2. (Sub lesson 2)** A photograph cannot carry a theme. True or false?
**Answer: False — drama, video and photograph all carry themes.**

**3. (Sub lesson 3)** Imitation is the same as mockery. True or false?
**Answer: False — imitation copies truly and with respect; mockery shames.**
