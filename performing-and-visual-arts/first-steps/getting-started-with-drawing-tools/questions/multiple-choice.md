# Getting Started With Drawing Tools — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Lines of different thickness come from…
a) the plain pencil, by how you press  b) the eraser  c) the water
**Answer: a) the plain pencil, by how you press**

**2. (Sub lesson 1)** Erasing well means…
a) rubbing hard  b) erasing without tearing the paper  c) never erasing
**Answer: b) erasing without tearing the paper**

**3. (Sub lesson 2)** Gouache can cover a mistake because…
a) it is laid thicker  b) it is invisible  c) it dries instantly
**Answer: a) it is laid thicker**

**4. (Sub lesson 2)** After work, you…
a) leave tools anywhere  b) clean every tool and put it in its place  c) throw tools away
**Answer: b) clean every tool and put it in its place**
