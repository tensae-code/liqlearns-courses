# Getting Started With Drawing Tools — true or false

Say true or false.

**1. (Sub lesson 1)** A pencil can only make one thickness of line.
**Answer: False** — it makes lines of different thickness.

**2. (Sub lesson 2)** Watercolour and gouache are mixed with water.
**Answer: True**

**3. (Sub lesson 2)** A gouache mistake can be covered with another colour.
**Answer: True**
