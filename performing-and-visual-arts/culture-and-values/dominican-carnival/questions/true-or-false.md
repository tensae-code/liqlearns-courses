# Dominican Carnival — true or false

Say true or false.

**1. (Sub lesson 1)** Carnival is a time of rejoicing.
**Answer: True.**

**2. (Sub lesson 2)** The Guloyas belong to San Pedro de Macorís.
**Answer: True.**

**3. (Sub lesson 3)** Carnival masks are a central element of the festival.
**Answer: True.**

**4. (Sub lesson 3)** A carnival costume can only be bought, never made.
**Answer: False.**
