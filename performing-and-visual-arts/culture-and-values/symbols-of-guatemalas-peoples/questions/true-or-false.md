# Symbols of Guatemalas Peoples — true or false

Say true or false.

**1. (Sub lesson 1)** The guide explains its own symbols as cultural art.
**Answer: True.**

**2. (Sub lesson 1)** The conch is only a food and never an instrument.
**Answer: False — the conch is a musical instrument of important ceremonies.**

**3. (Sub lesson 2)** The sun stands for the nawal Ajpú.
**Answer: True.**

**4. (Sub lesson 2)** Noj means wisdom.
**Answer: True.**
