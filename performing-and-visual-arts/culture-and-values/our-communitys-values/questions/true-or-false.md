# Our Community's Values — true or false

Say if the line is true or false.

**1. (Sub lesson 1)** Receiving guests is one of the book's cultural values.
**Answer: True**

**2. (Sub lesson 2)** The summary names dress, eating, dance, coffee-making and national pride as faces of the values.
**Answer: True**

**3. (Sub lesson 3)** A value shown at home every day is weaker than a value only sung.
**Answer: False** — the example at home becomes the child's own way.
