# Indigenous Knowledge of Ethiopia — true or false

Say true or false.

**1. (Sub lesson 1)** Indigenous knowledge is held in practice and handed down by doing.
**Answer: True**

**2. (Sub lesson 2)** Aksum, Lalibela and Gondar stand in the book as building knowledge.
**Answer: True**

**3. (Sub lesson 3)** If a generation stops practising it, indigenous knowledge can be lost.
**Answer: True**
