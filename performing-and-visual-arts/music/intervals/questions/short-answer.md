# Intervals — short answer

Answer in a short sentence.

**1. (Sub lesson 1)** What is an interval?
**Answer: The distance between two sounds.**

**2. (Sub lesson 1)** From which sound is an interval counted, and what is the widest count in this lesson?
**Answer: From the first sound, up to the octave — 1–8.**

**3. (Sub lesson 2)** Name two ways the guide has learners work with an interval besides naming it.
**Answer: Building it, singing it and playing it (any two).**
