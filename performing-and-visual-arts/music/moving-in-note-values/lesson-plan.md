# Lesson plan — Moving in Note Values

**Course:** Performing and Visual Arts · **Title:** Music · **Lesson:** Moving in Note Values
**Place in the curriculum:** Unit 3 — Music (CURRICULUM.md).
**The one thing this lesson teaches:** the body learns note values by moving to them — pupils line up in rows, then in circles with arms raised, sounding each value as they move.
**This lesson's own level:** it stands on Notes and Rests — the learner already knows the whole, half and quarter values; here the feet and arms prove them.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Moving in rows, sounding the values** — pupils line up in three (four) rows and move to the given note values while sounding them.
2. **Moving in circles, arms raised** — in three circles, arms raised above the head, the class moves and sounds the values together.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Notes and Rests (the signs and their values). Recommended, never forced.

## What the learner can do when it ends
1. Move in rows to given note values while sounding them.
2. Move in circles with arms raised above the head, keeping each note's full value.

## What you need
Open floor space and a steady voice or drum to sound the values.

## The run of the lesson (in order)
1. **Do it first** — walk four slow steps for a whole note, two for a half note, one for a quarter note — sounding each value as you step it. (lesson/lesson.md).

## If the learner is stuck
If steps and sounds drift apart, slow down: sound first, step on the sound, and let the count lead both.
