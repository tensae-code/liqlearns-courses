# Moving in Note Values — short answer

Answer in a short sentence or a short list.


**1. (Sub lesson 1)** How are the pupils arranged for the first movement?
**Answer:** In three (four) rows, moving to the given note values while sounding them.

**2. (Sub lesson 2)** Why do raised arms help the class?
**Answer:** Every learner is visible, so a value cut short or stretched can be seen and corrected at once.
