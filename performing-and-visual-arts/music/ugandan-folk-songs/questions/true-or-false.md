# Ugandan Folk Songs — true or false

Say true or false.

**1. (Sub lesson 1)** Every ethnic group in Uganda has its own musical tradition.
**Answer: True.**

**2. (Sub lesson 3)** All Ugandan groups use the pentatonic scale and none use any other.
**Answer: False — most use pentatonic, but a few groups use hexatonic.**

**3. (Sub lesson 2)** Bunyoro and Buganda use the same name for their vocal tone quality.
**Answer: False — Bunyoro's is Kuhugura, Buganda's is eggono.**

**4. (Sub lesson 4)** The performed folk song should depict the singer's natural environment.
**Answer: True.**
