# Movement Songs — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub Lessons"). Practice is tied to the learner's skill number, as before. The questions live in the type files; this file is the by-sub-lesson view. The sub lessons climb inside this one lesson, from the youngest books to the oldest.

## Sub lesson 1 — Clapping songs
Sub lesson 1 questions from the type files. Pass mark: sing and move through the whole pattern: forward, stop, clap; back, stop, clap — never losing the beat.

## Sub lesson 2 — Walking songs
Sub lesson 2 questions from the type files. Pass mark: sing the walking song while walking in a line, and name its journey in order.

## Sub lesson 3 — Riding songs
Sub lesson 3 questions from the type files. Pass mark: sing the riding song with its trotting movement, and name the three horses' colours in order.
