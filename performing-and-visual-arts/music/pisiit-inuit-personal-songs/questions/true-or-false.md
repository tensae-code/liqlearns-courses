# Pisiit: Inuit Personal Songs — true or false

Say true or false.

**1. (Sub lesson 1)** Pisiit were only ever sung from memory, never written.
**Answer: False — Inuit learned to write pisiit in Inuktitut.**

**2. (Sub lesson 1)** Learning to read helped Inuit sing pisiit.
**Answer: True.**

**3. (Sub lesson 2)** The whole community's Sunday singing matters greatly to the community.
**Answer: True.**

**4. (Sub lesson 2)** Pisiit are sung by one singer alone.
**Answer: False — communities gather and sing them together.**
