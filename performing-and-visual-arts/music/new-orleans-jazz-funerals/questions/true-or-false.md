# New Orleans Jazz Funerals — true or false

Say true or false.

**1. (Sub lesson 1)** Grief and joy both have music in a New Orleans funeral.
**Answer: True.**

**2. (Sub lesson 1)** The band plays ragtime behind the coffin.
**Answer: False.**

**Answer: True.**
