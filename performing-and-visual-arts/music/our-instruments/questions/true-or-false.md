# Our Instruments — true or false

Say true or false.

**1. (Sub lesson 1)** The masenqo is played with a bow.
**Answer: True.**

**2. (Sub lesson 2)** The kebero is blown like a flute.
**Answer: False** — the kebero is a drum; the washint is blown.

**3. (Sub lesson 3)** The washint is a long flute.
**Answer: True.**

**4. (Sub lesson 4)** The krar has only one string.
**Answer: False** — the krar is a lyre with many strings; the masenqo has one string.
