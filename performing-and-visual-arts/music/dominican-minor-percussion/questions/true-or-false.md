# Dominican Minor Percussion — true or false

Say true or false.

**1. (Sub lesson 1)** The güira is a Dominican percussion instrument.
**Answer: True.**

**2. (Sub lesson 2)** You learn the instruments without ever playing them.
**Answer: False.**

**3. (Sub lesson 2)** Hearing an instrument is part of knowing it.
**Answer: True.**

**4. (Sub lesson 1)** Minor percussion is played with the hands.
**Answer: True.**
