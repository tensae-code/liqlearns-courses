# Composing Music — true or false

Say true or false.

**1. (Sub lesson 1)** Question-and-answer phrases are part of Andorra's primary composing.
**Answer: True.**

**2. (Sub lesson 1)** An ostinato is a pattern played only once.
**Answer: False — an ostinato repeats.**

**3. (Sub lesson 2)** In experimentation, error is allowed.
**Answer: True.**

**4. (Sub lesson 3)** A composition cannot be kept as a recording.
**Answer: False — it can be kept in scores or in sound and audiovisual recording.**
