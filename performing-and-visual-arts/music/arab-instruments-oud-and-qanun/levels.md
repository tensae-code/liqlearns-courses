# Arab Instruments: Oud and Qanun — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure). Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — The oud
Sub lesson 1 questions from the type files. Pass mark: say what this part teaches, in the book's own terms — the ancient Arab string instrument: its deep bowl body and short bent neck, its five double strings and their tuning names (Yakah, ʿAshiran, Dukah, Nawa, Kirdan), its parts drawn and named, and how it is played with the risha plectrum.

## Sub lesson 2 — The qanun
Sub lesson 2 questions from the type files. Pass mark: say what this part teaches, in the book's own terms — a trapezoid sound-box carrying some 78 strings in courses of three, played with picks on both index fingers, its tuning levers raising and lowering each course — the instrument that sets the tuning for the whole Arab ensemble.

## Sub lesson 3 — The nay
Sub lesson 3 questions from the type files. Pass mark: say what this part teaches, in the book's own terms — the end-blown reed flute of the Arabs: an open tube of cane with six finger holes and a thumb hole, made in seven named sizes (37.5 to 68 cm), one for each degree of the maqam.
