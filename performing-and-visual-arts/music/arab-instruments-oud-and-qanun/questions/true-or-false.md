# Arab Instruments: Oud and Qanun — true or false

Say true or false.

**1. (Sub lesson 1)** The oud’s neck is short and bent back.
**Answer: True.**

**2. (Sub lesson 2)** The qanun’s strings are in courses of three.
**Answer: True.**

**3. (Sub lesson 3)** The nay is a string instrument.
**Answer: False — it is an end-blown reed flute of cane.**

**4. (Sub lesson 3)** The nay’s sizes run from 37.5 to 68 cm.
**Answer: True.**
