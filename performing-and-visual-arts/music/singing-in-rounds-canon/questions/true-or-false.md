# Singing in Rounds: Canon — true or false

Say true or false.

**1. (Sub lesson 1)** A round and a canon are the same thing.
**Answer: True.**

**2. (Sub lesson 2)** Lodoni Sa Kama is the iTaukei version of London's Burning.
**Answer: True.**

**3. (Sub lesson 1)** In a round every group starts at exactly the same moment.
**Answer: False — groups start one after another.**

**4. (Sub lesson 2)** This lesson's evidence is a teacher guide.
**Answer: True — Year 2 Performing Arts teacher guide.**
