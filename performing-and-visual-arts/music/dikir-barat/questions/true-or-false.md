# Dikir Barat — true or false

Say true or false.

**1. (Sub lesson 1)** Dikir barat is a Malay group singing tradition of Singapore.
**Answer: True.**

**2. (Sub lesson 1)** Dikir barat is performed by one singer standing alone.
**Answer: False** — it is seated group singing.

**3. (Sub lesson 2)** The hand actions in dikir barat are synchronised.
**Answer: True.**

**4. (Sub lesson 2)** The learners never perform in this lesson.
**Answer: False** — groups create hand movements and perform them.
