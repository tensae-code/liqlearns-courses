# Lesson plan — The Class Music Project

**Course:** Performing and Visual Arts · **Title:** Music · **Lesson:** The Class Music Project
**Place in the curriculum:** Unit 3 — Music (CURRICULUM.md).
**The one thing this lesson teaches:** Doing a class music project — researching musical giftedness and presenting a musical work.
**This lesson's own level:** it stands on the course's earlier lessons in its title; recommended first, never forced.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of ..." in words, plus one little line saying what the student does with it**.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Проект во наставата** — Проект во наставата — the class music project: groups of five or six research a composer, a performer or an element of folklore, form a performing group, and present — the time shared out: theme 1 part, research half, presentation-making and rehearsal a quarter each.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
