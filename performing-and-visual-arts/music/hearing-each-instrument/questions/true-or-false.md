# Hearing Each Instrument — true or false

Say true or false.

**1.** You can name an instrument by its sound alone, without seeing it.
**Answer: True** — that is this lesson's skill.

**2.** A drum can slide its sound like a bow on a string.
**Answer: False.**

**3.** The trumpet's Amharic name in the song is ጥሩንባ.
**Answer: True.**

**4.** Musical activities can be accompanied by various instruments.
**Answer: True.**
