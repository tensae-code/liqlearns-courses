# Angolan Instruments — short answer

Answer in a short sentence.

**1. (Sub lesson 1)** What is the first part of this lesson called?
**Answer: Ngoma — Angola's drum.**

**2.** Name one more part of this lesson.
**Answer: Kisanji — the plucked lamellophone (any one named part is right).**

**3.** Which country's books teach this lesson's parts?
**Answer: Angola's — the Educação Manual e Plástica and Educação Musical student books (Ministério da Educação).**
