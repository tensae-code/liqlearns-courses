# The Tuk Band of Barbados — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure). Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Naming and recognising the tuk band's instruments
Sub lesson 1 questions from the type files. Pass mark: The Classes 1–4 attainment targets name the tuk band as Barbados's own music to know: pupils name and recognise the instruments of the tuk band — the band is recognised by the instruments that make its sound.

## Sub lesson 2 — Writing about how they are played
Sub lesson 2 questions from the type files. Pass mark: Knowing goes further than naming: the targets ask pupils to write about the instruments used in a tuk band and how they are played — each instrument, and the player's way with it.
