# Bands and Brass Bands — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Sousa is famous for…
a) marches  b) operettas only  c) sea shanties only
**Answer: a) marches**

**2. (Sub lesson 1)** An ostinato is a…
a) repeating rhythm pattern  b) silent pause  c) dance step
**Answer: a) repeating rhythm pattern**

**3. (Sub lesson 1)** Ostinato patterns can be swapped at…
a) section changes  b) the concert's end only  c) never
**Answer: a) section changes**

**4. (Sub lesson 2)** Helgi Helgason founded…
a) Iceland's first brass band  b) the first opera house  c) the M.A. Quartet
**Answer: a) Iceland's first brass band**

**5. (Sub lesson 2)** Two bugle blasts for the fire brigade meant…
a) start spraying  b) stop spraying  c) move
**Answer: a) start spraying**
