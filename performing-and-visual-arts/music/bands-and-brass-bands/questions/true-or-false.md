# Bands and Brass Bands — true or false

Say true or false.

**1. (Sub lesson 1)** Sousa wrote The Washington Post march.
**Answer: True.**

**2. (Sub lesson 1)** Iceland's first brass band was founded before Helgi heard any band.
**Answer: False.**

**3. (Sub lesson 2)** Bugle signals gave fire-brigade orders.
**Answer: True.**

**4. (Sub lesson 2)** An ostinato is played once and never repeated.
**Answer: False.**
