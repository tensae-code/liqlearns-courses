# Greek Folk Instruments — true or false

Say true or false.

**1. (Sub lesson 1)** This lesson's first part is "22. Γνωρίζοντας τα ελληνικά λαϊκά μουσικά όργανα (Meeting the Greek folk instruments)".
**Answer: True.**
