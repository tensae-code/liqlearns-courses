# Notes and Rests — ordering

Put the notes in order, longest value first.

**1. (Sub lesson 4)** Order these by time value, longest first: quarter note, whole note, half note.
**Answer: whole note (4), half note (2), quarter note (1).**

**2. (Sub lesson 4)** Order these rests by silent length, longest first: quarter rest, whole rest, half rest.
**Answer: whole rest (4), half rest (2), quarter rest (1).**
