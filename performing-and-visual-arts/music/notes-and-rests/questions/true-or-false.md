# Notes and Rests — true or false

Say true or false.

**1. (Sub lesson 1)** The whole note takes the highest time value in the music system.
**Answer: True.**

**2. (Sub lesson 2)** The half note is counted four beats.
**Answer: False** — two beats; the whole note is four.

**3. (Sub lesson 3)** The quarter rest is counted one beat without making sound.
**Answer: True.**

**4. (Sub lesson 4)** During a rest you stop counting until the next note.
**Answer: False** — a rest is counted in silence for its full value; the count never stops.
