# Notes and Rests — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure). Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — ሙሉ ኖታ — the whole note and the whole rest
Sub lesson 1 questions from the type files. Pass mark: draw the open oval and the hanging block exactly, and perform each for exactly 4 beats — sounded, then silent.

## Sub lesson 2 — ግማሽ ኖታ — the half note and the half rest
Sub lesson 2 questions from the type files. Pass mark: draw the open oval with its right-side stem and the sitting block exactly, and perform each for exactly 2 beats.

## Sub lesson 3 — The quarter note and the quarter rest
Sub lesson 3 questions from the type files. Pass mark: draw the filled oval with stem and the quarter-rest sign exactly, and perform each for exactly 1 beat.

## Sub lesson 4 — All the signs together, and the Note-Values Song
Sub lesson 4 questions from the type files. Pass mark: mix the six signs in a line, state every value, and sing the values as the Note-Values Song teaches them.

## Sub lesson 5 — The Grade 4 chapter opens — notes, colours, shapes, theatre and photographs (chapter opening — Grade 4)
Sub lesson 5 questions from the type files. Pass mark: the learner can list the Grade 4 Chapter 1 aims in their own words and say which aim each part of the chapter works.

Sub lesson 6 questions from the type files. Pass mark: the learner can say the chapter's closing contrasts — note vs rest, shape vs form — and pick the whole-note sign and the triangle from pictures, as the book's exercise asks.
