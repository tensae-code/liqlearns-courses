# Counting Songs — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** In the ducks song, exactly one duck remains behind at each call.
**Answer: True**

**2. (Sub lesson 1)** The ducks song counts forwards from one to five.
**Answer: False** — It counts back: 5, 4, 3, 2, 1.

**3. (Sub lesson 2)** In the bottles song, the bottles are green.
**Answer: True**

**4. (Sub lesson 2)** Counting back means each verse there is one more.
**Answer: False** — One fewer.
