# Counting Songs — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** In Five Little Ducks, the mother calls and —
a) all five always return  b) one fewer comes back each verse  c) the ducks never return
**Answer: b) one fewer comes back each verse**

**2. (Sub lesson 1)** Five ducks go out; the mother calls. How many come back first?
a) five  b) four  c) three
**Answer: b) four** — One remains behind.

**3. (Sub lesson 1)** The counting in the ducks song goes —
a) 1, 2, 3, 4, 5  b) 5, 4, 3, 2, 1  c) 5, 5, 5, 5
**Answer: b) 5, 4, 3, 2, 1**

**4. (Sub lesson 2)** Five Green Bottles asks at every verse —
a) who is singing?  b) if one falls and breaks, how many remain?  c) what colour is it?
**Answer: b) if one falls and breaks, how many remain?**

**5. (Sub lesson 2)** After the last bottle falls, how many remain?
a) one  b) zero  c) five
**Answer: b) zero** — The row is empty: zero.

**6. (Sub lesson 2)** Counting back from five ends at —
a) one  b) five  c) zero
**Answer: c) zero**
