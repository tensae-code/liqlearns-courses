# The Message in Songs — true or false

Say true or false.

**1. (Sub lesson 1)** Listening without the words lets the music's feeling arrive first.
**Answer: True.**

**2. (Sub lesson 1)** The guide asks for the song's lyrics to be copied out in full.
**Answer: False — the song is placed in summary only.**

**3. (Sub lesson 2)** A song's message can be stated and supported with reasons from the song.
**Answer: True.**

**4. (Sub lesson 2)** Feelings have no place in discussing a song's meaning.
**Answer: False — the feelings it raises are half of the discussion.**
