# Conducting — true or false

Say true or false.

**1. (Sub lesson 1)** The conductor keeps the tempo steady.
**Answer: True.**

**2. (Sub lesson 1)** Each instrument enters whenever it likes, with no cue.
**Answer: False — the conductor cues each entry.**

**3. (Sub lesson 2)** Listening is part of conducting.
**Answer: True.**

**4. (Sub lesson 2)** Rehearsals need no coordination.
**Answer: False — the conductor coordinates rehearsals.**
