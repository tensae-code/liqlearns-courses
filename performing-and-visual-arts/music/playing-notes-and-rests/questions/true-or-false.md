# Playing Notes and Rests — true or false

Say true or false.

**1. (Sub lesson 1)** A whole rest in performance is four beats of counted silence.
**Answer: True.**

**2. (Sub lesson 2)** When a rest comes, the count stops until the next note.
**Answer: False** — the count never stops; silence is played.

**3. (Sub lesson 3)** Movements from daily life can be matched to a note's value in practice.
**Answer: True** — the book's exercise does exactly this.
