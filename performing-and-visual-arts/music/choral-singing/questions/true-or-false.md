# Choral Singing — true or false

Say true or false.

**1. (Sub lesson 1)** A choir is many voices harmonised to sing together.
**Answer: True.**

**2. (Sub lesson 1)** In choral singing each singer ignores the others.
**Answer: False.** — the voices are tuned to each other.

**3. (Sub lesson 2)** A choir is directed — dirección coral is part of the teaching.
**Answer: True.**

**4. (Sub lesson 2)** Choral direction means the choir has no leader.
**Answer: False.** — direction is the leadership that holds it together.
