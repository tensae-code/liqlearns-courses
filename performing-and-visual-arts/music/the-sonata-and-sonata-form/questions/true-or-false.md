# The Sonata and Sonata Form — true or false

Say true or false.

**1. (Sub lesson 1)** The 'Pathétique' foreshadows the Romantic period.
**Answer: True.**

**2. (Sub lesson 1)** Sonata form begins with the recapitulation.
**Answer: False — it begins with the exposition.**

**3. (Sub lesson 2)** The Grave introduction returns twice in the movement.
**Answer: True.**

**4. (Sub lesson 2)** Beethoven's 'Pathétique' was written for the harpsichord.
**Answer: False — for the new pianoforte.**
