# Reading the Beat — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure). Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — What the beat is
Sub lesson 1 questions from the type files. Pass mark: define the beat in the book's words and name its three everyday beat-keepers.

## Sub lesson 2 — Reading notes by their letters
Sub lesson 2 questions from the type files. Pass mark: read a lettered note row aloud, letters correct and time values kept, without stopping.

## Sub lesson 3 — Off-staff melodies
Sub lesson 3 questions from the type files. Pass mark: read an off-staff letter melody with a beat instrument, reading the letters as music — not reciting memorised words.

## Sub lesson 4 — Sol-fa rows
Sub lesson 4 questions from the type files. Pass mark: read the do-do sol-fa row in half notes with a beat instrument, then read a row with substituted letters.

## Sub lesson 5 — The Grade 6 chapter opens — reading pitch, beat and melody (chapter opening — Grade 6)
Sub lesson 5 questions from the type files. Pass mark: the learner can list the Grade 6 Chapter 2 aims, answer the pre-talk's question (a beat, shown in clapping and kebero strokes), and say which aims this lesson keeps.

## Sub lesson 6 — The Grade 6 chapter closes — beat-reading, composition and still life (chapter closing — Grade 6)
Sub lesson 6 questions from the type files. Pass mark: the learner can run both self-check tables by strand, state the summary's high/low pitch ground (high=G, women's thin voices; low=F, men's thick voices), and has performed the exercise's rhythmic sight-readings and the three staff melodies.
