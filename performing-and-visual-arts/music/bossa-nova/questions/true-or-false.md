# Bossa Nova — true or false

Say true or false.

**1. (Sub lesson 1)** Bossa nova harmony uses seventh and extended chords.
**Answer: True.**

**2. (Sub lesson 1)** Bossa nova is samba played as fast as possible.
**Answer: False — it is samba slowed and subdued.**

**3. (Sub lesson 2)** The performance opens with a free-rhythm bass solo.
**Answer: True.**

**4. (Sub lesson 2)** 'Samba Em Prelúdio' is a song of longing for an absent beloved.
**Answer: True.**
