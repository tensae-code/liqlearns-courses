# Pese Samoa and Fa'asala — true or false

Say true or false.

**1. (Sub lesson 1)** A pese Sāmoa's melody can begin on any pitch.
**Answer: True.**

**2. (Sub lesson 1)** A pese Sāmoa needs many chords to be authentic.
**Answer: False** — it uses two chords only, usually I and V.

**3. (Sub lesson 2)** The fa'asala sings under the main melody.
**Answer: False** — it is a descant OVER the main melody.

**4. (Sub lesson 2)** The class composes the melody together, and each pupil writes their own fa'asala.
**Answer: True.**
