# Scales, Pitch and Key Signatures — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub Lessons"). Practice is tied to the learner's skill number, as before. The questions live in the type files; this file is the by-sub-lesson view. The sub lessons climb inside this one lesson, from the youngest books to the oldest.

## Sub lesson 1 — The major scale: the ladder of sounds
Sub lesson 1 questions from the type files. Pass mark: sing and write a major scale marking W and H, with the halves at 3–4 and 7–8.

## Sub lesson 2 — The minor scale: three kinds, and counting back three
Sub lesson 2 questions from the type files. Pass mark: find the natural minor of C and of G by counting back three and write each ordering.

## Sub lesson 3 — Pitch: high and low
Sub lesson 3 questions from the type files. Pass mark: sing the set pitch patterns and say which clef a written melody's pitch belongs to.

## Sub lesson 4 — Key signatures: sharps and flats in order
Sub lesson 4 questions from the type files. Pass mark: write the key signature for one major scale on both clefs, signs in correct order.

Sub lesson 5 questions from the type files. Pass mark: count one written rhythm aloud with syllables and read one melody line on each staff.
