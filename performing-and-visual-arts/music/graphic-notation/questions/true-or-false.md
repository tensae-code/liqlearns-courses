# Graphic Notation — true or false

Say true or false.

**1. (Sub lesson 1)** Graphic notation lets symbols stand for sounds.
**Answer: True**

**2. (Sub lesson 2)** Omitted numbers in the body-percussion chart are rests.
**Answer: True**

**3. (Sub lesson 3)** In "Lub-Dab-Rest" pupils only copy and never create their own compositions.
**Answer: False — they copy, then create and perform each other's.**

**4. (Sub lesson 4)** Each box in a box score is one beat.
**Answer: True**
