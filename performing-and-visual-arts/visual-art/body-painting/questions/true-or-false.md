# Body Painting — true or false

Say true or false.

**1. (Sub lesson 1)** Organic colours and modern paints are the same thing.
**Answer: False — organic colours come from flowers, leaves, clay, soil and charcoal; modern paints are manufactured.**

**2. (Sub lesson 2)** The guides ask learners to know a local painter.
**Answer: True.**

**3. (Sub lesson 3)** Body painting is a modern invention in these guides.
**Answer: False — it is traditional, using organic mediums.**
