# Photographs — true or false

Say if each sentence is true or false.

**1. (Sub lesson 1)** A photograph and a drawing are the same thing, because both show a scene. **Answer: False** — a photograph is obtained using a photo camera; a drawing is made by hand.

**2. (Sub lesson 2)** The Tis Abay photograph shows a wide waterfall. **Answer: True.**

**3. (Sub lesson 5)** Everything in a photograph was really there in front of the camera at one real moment. **Answer: True.**
