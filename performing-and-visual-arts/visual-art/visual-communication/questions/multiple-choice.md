# Visual Communication — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Communication is…
a) the transmission of messages in a language  b) drawing only  c) silence
**Answer: a) the transmission of messages in a language**

**2. (Sub lesson 1)** Visual communication's code is…
a) the word  b) the image  c) the number
**Answer: b) the image**

**3. (Sub lesson 2)** Which is NOT one of the agents?
a) sender  b) receiver  c) painter's brush
**Answer: c) painter's brush** — the agents are sender, receiver, message and channel/support.

**4. (Sub lesson 2)** Which of these is a medium of visual communication?
a) a traffic sign  b) a smell  c) a taste
**Answer: a) a traffic sign**
