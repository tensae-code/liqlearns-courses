# Visual Communication — true or false

Say true or false.

**1. (Sub lesson 1)** Visual communication needs words to carry its message.
**Answer: False** — its code is the image.

**2. (Sub lesson 2)** Clothing can be a medium of visual communication.
**Answer: True**

**3. (Sub lesson 2)** A health poster has a sender, a receiver, a message and a channel.
**Answer: True**
