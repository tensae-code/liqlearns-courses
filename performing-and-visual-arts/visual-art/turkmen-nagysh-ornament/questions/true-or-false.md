# Turkmen Nagysh Ornament — true or false

Say true or false.

**1. (Sub lesson 1)** Nagyş patterns are all the same and unnamed.
**Answer: False** — every pattern has its own name.

**2. (Sub lesson 1)** Nagyş recall flowers and plants.
**Answer: True**

**3. (Sub lesson 2)** Decorating with national patterns is meant to make the toys more beautiful.
**Answer: True**
