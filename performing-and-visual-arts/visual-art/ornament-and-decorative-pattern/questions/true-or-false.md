# Ornament and Decorative Pattern — true or false

Say true or false.

**1. (Sub lesson 1)** Ornament has two kinds in the book: geometric and written.
**Answer: True**

**2. (Sub lesson 1)** Written ornament is built from geometric shapes.
**Answer: False** — Written ornament is built from Arabic letters; geometric ornament is built from shapes.

**3. (Sub lesson 1)** A single ornament unit is never repeated.
**Answer: False** — Units are repeated into bands and panels.

**4. (Sub lesson 1)** Symmetry means the matching repetition of units.
**Answer: True**
