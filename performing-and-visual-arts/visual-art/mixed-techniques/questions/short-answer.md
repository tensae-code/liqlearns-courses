# Mixed Techniques — short answer

Answer in a short sentence.

**1. (Sub lesson 1)** How many techniques must combine for a work to be a mixed technique?
**Answer: Several — more than one, combined in one work.**

**2. (Sub lesson 2)** Name two things that can be printed or stamped in a mixed-technique work.
**Answer: Direct printing of elements and stamping (any printed/stamped elements the learner used).**
