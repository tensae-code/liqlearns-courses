# Arabic and Islamic Calligraphy — true or false

Say true or false.

**1. (Sub lesson 1)** The finished calligraphy pieces are coloured.
**Answer: True**

**2. (Sub lesson 2)** The name Muhammad is set inside a rectangle.
**Answer: False** — it is set inside a semicircle; the rectangle holds the name Allah.

**3. (Sub lesson 3)** The pieces are inked before the dotted outline is traced.
**Answer: False** — the dotted outline comes first, then inking and colouring.
