# Printing — true or false

Say if each sentence is true or false.

**1. (Sub lesson 5)** To print a person facing right, you carve the block with the person facing right too. **Answer: False** — the design is carved reversed, a mirror image: facing left, so the print faces right.

**2. (Sub lesson 6)** In batik, melted candle covers the part of the cloth that should NOT take the dye. **Answer: True** — candle does not mix with water, so the dye cannot reach the covered part; the wax is ironed away afterwards.

**3.** (Sub lesson 7) Sharp tools such as cutters, blades and knives can cause bleeding and cuts. **Answer: True.**

**4.** (Sub lesson 7) Careful, slow work is part of carving safety. **Answer: True.**
