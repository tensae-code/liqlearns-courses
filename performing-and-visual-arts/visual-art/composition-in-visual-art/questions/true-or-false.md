# Composition in Visual Art — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Two works with the same elements can differ because one is composed and the other is not.
**Answer: True** — the difference is the arrangement.

**2. (Sub lesson 2)** If a work's composition fails, its idea can be lost even when its drawing and colour are skilled.
**Answer: True** — the arrangement is what delivers the idea.

**3. (Sub lesson 3)** The guide teaches composition and design together.
**Answer: True** — composition is design's arranging hand inside the work.
