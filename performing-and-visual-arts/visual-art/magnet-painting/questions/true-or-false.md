# Magnet Painting — true or false

Say true or false.

**1. (Sub lesson 1)** The metal object itself does the painting.
**Answer: True.**

**2. (Sub lesson 1)** The magnet touches the paint directly.
**Answer: False** — it works from under the plate.

**3. (Sub lesson 2)** The box variant's raised edges help guide the painting.
**Answer: True.**
