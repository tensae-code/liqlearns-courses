# Making Models and Maquettes — true or false

Say true or false.

**1. (Sub lesson 1)** The map of the school is drawn before building begins.
**Answer: True.**

**2. (Sub lesson 1)** The school model is built by one child alone.
**Answer: False.** — it is built in big groups.

**3. (Sub lesson 2)** Sticks and stones are among the model's materials.
**Answer: True.**

**4. (Sub lesson 3)** The model is painted while it is still wet.
**Answer: False.** — it is painted when dry.
