# Architecture — true or false

Say true or false.

**1. (Sub lesson 1)** A cave can be architecture in this lesson.
**Answer: True** — caves open the guide's set of structures fitted to human needs.

**2. (Sub lesson 2)** All the guide's structures were built to last forever.
**Answer: False** — some were built for a limited time.

**3. (Sub lesson 1)** A house in Togo stands in the same lesson as Beijing's Forbidden City.
**Answer: True** — both are in the guide's set.
