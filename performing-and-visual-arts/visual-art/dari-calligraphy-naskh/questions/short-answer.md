# Dari Calligraphy: Naskh — short answer

Answer in a short sentence.

**1.** Which script does the Grade 2 Beautiful Writing book teach?
**Answer: The Naskh script (خط نسخ), written with the reed pen.**

**2.** Name the first joining letter practised after the alphabet.
**Answer: ب (b) — joined to the other letters in four ranges.**
