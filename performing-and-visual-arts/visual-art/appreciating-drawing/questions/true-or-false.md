# Appreciating Drawing — true or false

Say true or false. If it is false, say why.

**1.** You appreciate drawing only by looking at it, never by drawing yourself.
**Answer: False — the book's way is to use the materials found in your area and draw.**

**2.** Arranging the row is part of the exhibition work, not an extra.
**Answer: True — order and space between drawings are part of showing work.**
