# Papua New Guinea Weaving and Bilum — true or false

Say true or false.

**1. (Sub lesson 1)** Weaving begins before the fibre is prepared.
**Answer: False — gathering, dyeing and sun-drying come first.**

**2. (Sub lesson 2)** Coconut fronds can be woven into a mat.
**Answer: True.**

**3. (Sub lesson 3)** A bilum is made of metal.
**Answer: False — it is a woven fibre string bag.**
