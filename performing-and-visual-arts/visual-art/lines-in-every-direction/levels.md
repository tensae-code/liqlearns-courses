# Lines in Every Direction — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure). Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view. The sub lessons climb from the youngest books to the oldest inside this one lesson.

## Sub lesson 1 — Lines that go across, down and slanting
Sub lesson 1 questions from the type files. Pass mark: draw each of the three straight directions cleanly across the page, following the models.

## Sub lesson 2 — Curved lines and U shapes
Sub lesson 2 questions from the type files. Pass mark: draw a flowing curved line and a row of U shapes, each in one unbroken stroke.

## Sub lesson 3 — Patterns: zigzag, wave and loops
Sub lesson 3 questions from the type files. Pass mark: draw a zigzag, a wave and a row of loops, keeping the pencil down through the zigzag and the wave.

## Sub lesson 4 — The teacher's line lesson (teacher guide — evidence)
Sub lesson 4 questions from the type files. Pass mark: answer "What is a line?" in your own words and name the guide's order: warm up the hand, draw lines, colour.
