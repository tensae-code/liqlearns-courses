# Double Letters — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** The squares on squared paper help measure a letter's height, width and the distance between its twin lines.
**Answer: True** — what the eye guesses, the squares prove.

**2. (Sub lesson 2)** Guide lines are two parallel lines, and the writing rests between them.
**Answer: True** — parallel — the same distance apart all along.
