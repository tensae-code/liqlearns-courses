# The Primary Colours — true or false

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** Green is a primary colour.
**Answer: False — green is made by mixing (the book's own closing-exercise check).**

**2. (Sub lesson 3)** In the clothes-sorting activity, a purple shirt is kept with the primaries.
**Answer: False — purple is a mixture; it is set aside.**

**3. (Sub lesson 4)** A drawing can be made in ONE primary colour only, as a study.
**Answer: True — the book shows pictures made in blue colours (Drawing 10).**
