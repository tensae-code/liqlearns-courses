# The Primary Colours — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure). Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view. The sub lessons climb from the youngest books to the oldest inside this one lesson.

## Sub lesson 1 — What primary colours are
Sub lesson 1 questions from the type files. Pass mark: say the definition and name red, yellow and blue without help.

## Sub lesson 2 — The primaries in pictures
Sub lesson 2 questions from the type files. Pass mark: pick the primaries out of the balloon and glasses pictures and say why the song calls them mother and father of colours.

## Sub lesson 3 — Finding primaries around us
Sub lesson 3 questions from the type files. Pass mark: sort a mixed colour set and keep exactly red, yellow and blue, saying why the others are set aside.

## Sub lesson 4 — Drawing in the primary colours
Sub lesson 4 questions from the type files. Pass mark: make one drawing in a single primary colour and one drawing using all three.

## Sub lesson 5 — The basic colours in the teacher guides (teacher guide — evidence)
Sub lesson 5 questions from the type files. Pass mark: say the guides' other name for the primaries (basic colours) and name the three colour levels: primary, secondary, neutral.
