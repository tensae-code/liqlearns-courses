# Paper Quilling — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure). Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — The art of rolling paper
Sub lesson 1 questions from the type files. Pass mark: say how quilling is done — roll strips on a tool, glue the ends — and name the basic forms: circle, petal, eye, teardrop, half-moon, heart, square, triangle, rectangle.

## Sub lesson 2 — A quilled photo frame
Sub lesson 2 questions from the type files. Pass mark: give the frame's steps in order — 1 cm strips, roll on a needle or brush, pinch to the petal shape, leaves rolled halfway and glued in threes, petals and leaves glued around the frame.
