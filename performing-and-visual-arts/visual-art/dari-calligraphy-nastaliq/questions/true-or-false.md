# Dari Calligraphy: Nastaliq — true or false

Say true or false.

**1.** Grade 4 calligraphy changes the hand from Naskh to Nastaliq.
**Answer: True.**

**2.** In siyah-mashq each word is written only once, very lightly.
**Answer: False — words are repeated, overlapping, in strong black strokes.**
