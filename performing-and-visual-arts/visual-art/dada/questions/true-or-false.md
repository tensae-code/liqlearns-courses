# Dada — true or false

Say true or false.

**1. (Sub lesson 1)** Dada is an anti-art movement.
**Answer: True**

**2. (Sub lesson 1)** Dada's name was chosen carefully for its deep meaning.
**Answer: False** — It was found by chance in a dictionary — a nonsense name.

**3. (Sub lesson 1)** Duchamp is named among Dada's turns from Cubism.
**Answer: True**

**4. (Sub lesson 1)** Dada defended every established value.
**Answer: False** — It agreed against ethics, religion, philosophy and every corrupt value that disables freedom.
