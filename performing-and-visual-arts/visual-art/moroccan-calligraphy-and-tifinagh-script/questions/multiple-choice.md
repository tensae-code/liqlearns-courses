# Moroccan Calligraphy and Tifinagh Script — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Morocco's own scripts in the lesson are…
a) only Latin letters  b) the Moroccan script and the Tifinagh script  c) only printed type
**Answer: b) the Moroccan script and the Tifinagh script.**

**2. (Sub lesson 1)** Tifinagh is the script of…
a) the Amazigh people  b) sailors  c) musicians
**Answer: a) the Amazigh people.**

**3. (Sub lesson 1)** The panels are shown by…
a) unnamed printers  b) named Moroccan calligraphers, Abderrahim Coulin and Hamid El Kharbouchi  c) photographers
**Answer: b) named Moroccan calligraphers, Abderrahim Coulin and Hamid El Kharbouchi.**

**4. (Sub lesson 2)** Pupils make a panel in Tifinagh of…
a) a shopping list  b) their own name  c) a map
**Answer: b) their own name.**

**5. (Sub lesson 2)** The pupil's first calligraphy work is…
a) writing their own name beautifully  b) copying a whole book  c) drawing a house
**Answer: a) writing their own name beautifully.**
