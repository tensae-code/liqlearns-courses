# Moroccan Calligraphy and Tifinagh Script — true or false

Say true or false.

**1. (Sub lesson 1)** Tifinagh is one of Morocco's own lettering arts.
**Answer: True.**

**2. (Sub lesson 1)** The Moroccan script is a kind of dance.
**Answer: False** — it is a lettering art, a way of writing beautifully.

**3. (Sub lesson 2)** Pupils practise by writing their own name.
**Answer: True.**
