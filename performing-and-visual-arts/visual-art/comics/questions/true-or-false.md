# Comics — true or false

Say true or false.

**1. (Sub lesson 1)** Basic shapes can be combined into composite shapes.
**Answer: True.**

**2. (Sub lesson 1)** A character's personality does not matter in design.
**Answer: False — design creates look and personality together.**

**3. (Sub lesson 2)** Kyle and Lulu is a Dhivehi animated series.
**Answer: True.**

**4. (Sub lesson 2)** Facial expressions never change how a character reads.
