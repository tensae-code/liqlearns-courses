# Sewing and Tailoring — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure). Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — The little tailor
Sub lesson 1 questions from the type files. Pass mark: give the tailor's work in order — measure with the tailor's centimetre, cut following the pattern (tipar), baste (a însăila), festoon-stitch the edges (a festona) — and say what festooning stops: fraying.

## Sub lesson 2 — The little fish pencil-case
Sub lesson 2 questions from the type files. Pass mark: give the pencil-case's steps in order — draw the fish on the cloth, cut it out, turn and stuff the shape, finish with a drawn eye and a cord.

## Sub lesson 3 — Buttons sewn as a heart
Sub lesson 3 questions from the type files. Pass mark: say where the buttons come from — clothes that no longer fit — and how they are sewn: one beside another, in the shape of a heart.
