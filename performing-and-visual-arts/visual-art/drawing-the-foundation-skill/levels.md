# Drawing: The Foundation Skill — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub Lessons"). Practice is tied to the learner's skill number, as before. The questions live in the type files; this file is the by-sub-lesson view. The sub lessons climb inside this one lesson, from the youngest books to the oldest.

## Sub lesson 1 — Drawing defined: the basis of all visual art
Sub lesson 1 questions from the type files. Pass mark: say what drawing is, name two jobs drawings do as plans, and explain how a study improves a drawing.

## Sub lesson 2 — The drawing tools and the pencil grades
Sub lesson 2 questions from the type files. Pass mark: name the five tools and say what the hard, medium and soft grades are for.

## Sub lesson 3 — Shading, the human figure and gesture study
Sub lesson 3 questions from the type files. Pass mark: shade one form with an even light-to-dark gradation and make one gesture drawing of a moving figure.

## Sub lesson 4 — Freeing the hand: line drills
Sub lesson 4 questions from the type files. Pass mark: fill a page with the seven drill lines, freely, with no ruler used.

## Sub lesson 5 — Bigger and smaller on a grid; drawing what you see
Sub lesson 5 questions from the type files. Pass mark: enlarge a small drawing on a grid and draw one real thing while looking at it.

## Sub lesson 6 — The five basic skills of drawing (teacher guide — evidence)
Sub lesson 6 questions from the type files. Pass mark: name the five basic skills and say the two great sources a drawing can come from.
