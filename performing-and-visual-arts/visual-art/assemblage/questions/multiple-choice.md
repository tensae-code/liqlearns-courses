# Assemblage — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The bead jewellery is arranged from…
a) natural and man-made beads  b) paper only  c) clay only
**Answer: a) natural and man-made beads**.

**2. (Sub lesson 2)** The 3D objects must show…
a) space and balance  b) speed and noise  c) colour only
**Answer: a) space and balance**.

**3. (Sub lesson 3)** The toys are designed and made from…
a) wood  b) ice  c) cloth only
**Answer: a) wood**.

**4. (Sub lesson 3)** Designing comes…
a) before making the toy  b) never  c) after throwing it away
**Answer: a) before making the toy**.

**5. (Sub lesson 1)** This assemblage work is set for…
a) Class 4  b) Class 1  c) teachers only
**Answer: a) Class 4** — printed p. 15.
