# Vernacular Architecture of the Dominican Republic — true or false

Say true or false.

**1. (Sub lesson 1)** Vernacular architecture belongs to a region's own building tradition.
**Answer: True.**

**2. (Sub lesson 2)** The maqueta shows the house's architectural details.
**Answer: True.**

**3. (Sub lesson 3)** The models represent a historical epoch of the country.
**Answer: True.**

**4. (Sub lesson 1)** Only new houses count as vernacular architecture.
**Answer: False.**
