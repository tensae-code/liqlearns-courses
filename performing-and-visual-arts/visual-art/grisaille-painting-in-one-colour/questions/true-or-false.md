# Grisaille: Painting in One Colour — true or false

Say true or false.

**1. (Sub lesson 1)** Grisaille uses many colours mixed together.
**Answer: False** — it is built on one colour's tones.

**2. (Sub lesson 1)** Tones of one colour can show volume.
**Answer: True**.

**3. (Sub lesson 1)** Grisaille is a kind of sculpture.
**Answer: False** — it is a painting technique.

**4. (Sub lesson 1)** Lightening and darkening are the grisaille painter's main tools.
**Answer: True**.
