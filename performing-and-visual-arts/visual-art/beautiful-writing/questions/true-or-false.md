# Beautiful Writing — true or false

Say if each sentence is true or false.

**1. (Sub lesson 1)** To study calligraphy, one must know line types and directions. **Answer: True.**

**2. (Sub lesson 2)** A diagonal line (ሠያፍ) lies flat across the page. **Answer: False** — diagonal slants; the one that lies flat is horizontal (አግድም).

**3. (Sub lesson 5)** Letters can be decorated with leaves. **Answer: True.**
