# Animation — true or false

Say true or false.

**1. (Sub lesson 1)** In a cartoon film, the pictures change slowly, one per hour.
**Answer: False** — they change quickly, so the heroes seem to move.

**2. (Sub lesson 2)** A film you invent needs a name.
**Answer: True** — the task ends by naming it.

**3. (Sub lesson 3)** Each group in the class project draws all fifteen scenes alone.
**Answer: False** — groups of two each draw one scene, from 1 to 15.

**4. (Sub lesson 3)** The class chooses the film's name together.
**Answer: True** — each group proposes one and the class jointly chooses the best.
