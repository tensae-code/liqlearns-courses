# Illustration and Book Design — true or false

Say true or false.

**1. (Sub lesson 1)** Stylisation adds more and more detail to an image.
**Answer: False** — it simplifies — detail is dropped, shape is kept.

**2. (Sub lesson 1)** A tree can be stylised into geometric forms.
**Answer: True**.

**3. (Sub lesson 1)** The book makes stylised flowers in both colour and black-and-white.
**Answer: True**.

**4. (Sub lesson 1)** Stylisation is only for sculpture.
**Answer: False** — here it serves illustration and book design.
