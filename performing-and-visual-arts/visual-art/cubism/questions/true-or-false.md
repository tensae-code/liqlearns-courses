# Cubism — true or false

Say true or false.

**1. (Sub lesson 1)** An object can be decomposed into geometric forms.
**Answer: True.**

**2. (Sub lesson 1)** Natural forms and geometric forms are the same thing.
**Answer: False — the unit teaches telling them apart.**

**3. (Sub lesson 2)** The programme names cubism and the Vèvès together as references.
**Answer: True.**

**4. (Sub lesson 2)** The Vèvès are European paintings.
**Answer: False — they are Haiti's sacred art.**
