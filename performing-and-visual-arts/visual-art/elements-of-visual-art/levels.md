# The Elements of Visual Art — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub Lessons"). Practice is tied to the learner's skill number, as before. The questions live in the type files; this file is the by-sub-lesson view. The sub lessons climb inside this one lesson, from the youngest books to the oldest.

## Sub lesson 1 — Visual art is a language
Sub lesson 1 questions from the type files. Pass mark: name the seven elements and say, in one sentence, what visual art is for.

## Sub lesson 2 — Lines and their feelings
Sub lesson 2 questions from the type files. Pass mark: draw the five line kinds and say the feeling of each; tell a geometric shape from a natural one.

## Sub lesson 3 — Form, and positive and negative space
Sub lesson 3 questions from the type files. Pass mark: name the four basic forms and point out positive and negative space in one picture.

## Sub lesson 4 — Value: light and dark steps
Sub lesson 4 questions from the type files. Pass mark: make a nine-step value scale in pencil with even steps.

## Sub lesson 5 — The principles of design
Sub lesson 5 questions from the type files. Pass mark: name at least five principles and point to one of them working in a real picture.
