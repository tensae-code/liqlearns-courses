# First Marks and Scribbles — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure). Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view. The sub lessons climb from the youngest books to the oldest inside this one lesson.

## Sub lesson 1 — First free marks
Sub lesson 1 questions from the type files. Pass mark: fill a page with free marks in more than one direction and say that free mark-making is the first drawing act.

## Sub lesson 2 — Scribbling loosens the hand
Sub lesson 2 questions from the type files. Pass mark: say the definition in your own words and show a loosened-hand scribble in all four directions, then lines of your own after a pictured line.

## Sub lesson 3 — The books' own closing words
Sub lesson 3 questions from the type files. Pass mark: say what scribbling builds (handwriting and drawing skill; shapes and colours) and name the drawing professional — an artist.
