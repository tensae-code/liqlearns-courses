# Mixing Colours — true or false

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** "Red mixed equally with yellow creates green" — as the book's exercise tests it.
**Answer: False — it creates orange. (The book's own trap item, answered from §2.3.)**

**2. (Sub lesson 2)** Neutral colours are one of the three levels in the guide's framework.
**Answer: True.**
