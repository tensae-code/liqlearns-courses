# Ornamentation — true or false

Say true or false.

**1. (Sub lesson 1)** An ornament's forms are repeated in a definite rhythm.
**Answer: True**

**2. (Sub lesson 1)** Ornaments belong only on buildings.
**Answer: False** — they decorate vessels, clothes, covers, furniture and everyday objects too.

**3. (Sub lesson 2)** Modern people no longer decorate everyday objects.
**Answer: False** — modern man decorates everyday objects too.

**4. (Sub lesson 3)** A notebook cover can carry an ornament of your own region's heritage.
**Answer: True**
