# Painting Then and Now — sub lessons and depth

This file is the lesson's depth record, re-expressed as its sub lessons. Practice is tied to the learner's skill number, as before. The questions live in the type files; this file is the by-sub-lesson view. Two parts only: the history in one view, then the skill of appreciating.

## Sub lesson 1 — Ethiopian painting then and now
Pass mark: say that Ethiopia's own colour-painting style has changed through time to the present, and name Afework Tekle as the modern example the book names.

## Sub lesson 2 — Appreciating paintings
Pass mark: before one painting, say what you see first, which colours carry it, and how it makes you feel — and accept that a companion may see a thing you missed.
