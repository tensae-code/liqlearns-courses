# Islam: The Farewell Hajj and the Return — depth

This lesson is one whole lesson with no sub lessons. Pass mark: the learner can state the lesson's one thing — The Prophet's farewell pilgrimage and the journey home become the child's first sacred-history story, told as a trip the class takes with him — in their own words, give one real example from the lesson, and answer the lesson's questions. Practice deepens by more items and harder corners: first the plain cases from the lesson, then cases where the lesson's opposite (its false friend) tempts the wrong answer, then the lesson applied in a new place — a new situation the learner has not seen in the lesson.
