# Lesson plan — Prehistoric Morocco: The First Moroccans

**Course:** History — Morocco · **Title:** Ancient World · **Lesson:** Prehistoric Morocco: The First Moroccans
**Place in the curriculum:** Level 2 — Ancient Morocco (CURRICULUM.md).
**The one thing this lesson teaches:** bones and tools in Moroccan soil show the first Moroccans hunting, sheltering and surviving long before any state, any city or any writing.
**This lesson's own level:** Level 2 — Ancient Morocco — it stands on the lessons before it in path order (recommended, never forced).
