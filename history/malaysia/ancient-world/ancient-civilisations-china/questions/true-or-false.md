# Ancient Civilisations: China — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** China's first civilisation farms the fertile mud of the north.
**Answer: True**

**2.** The Yangtze plays no part in China's first civilisation.
**Answer: False** — The Yangtze is named with the Huang He in China's first civilisation.
