# Ancient Egypt: The Nile Kingdom — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** The Nile is the world's longest river.
**Answer: True**

**2.** The pyramids were built in the New Kingdom only, with none earlier.
**Answer: False** — The pyramids rise along the Nile through Egypt's kingdoms, the Old Kingdom above all.
