# From Evidence to a Written History — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** (Sub lesson 2) Secondary sources are written after the event, by people working from primary sources.
**Answer: True**

**2.** (Sub lesson 3) Primary sources are written long after the event by later historians.
**Answer: False** — Primary sources are taken straight from the event; secondary sources are the ones written afterwards.
