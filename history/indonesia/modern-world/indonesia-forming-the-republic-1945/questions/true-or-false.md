# Forming the Republic, 1945 — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** The PPKI built ministries and regions in the days after the Proclamation.
**Answer: True**

**2.** The Republic waited for the Dutch to return before forming a government.
**Answer: False** — The PPKI formed it within days — constitution, president, ministries and regions — while the Japanese still held the depots.
