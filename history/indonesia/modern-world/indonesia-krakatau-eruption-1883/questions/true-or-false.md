# The Krakatau Eruption, 1883 — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Krakatau's 1883 eruption is read through colonial records as the course's opening case.
**Answer: True**

**2.** Krakatau erupted in 1833 and left no records.
**Answer: False** — It erupted in 1883, and the class reads the catastrophe through the colonial records it left behind.
