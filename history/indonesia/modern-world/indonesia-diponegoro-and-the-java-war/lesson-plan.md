# Lesson plan — Diponegoro and the Java War

**Course:** History — Indonesia · **Title:** Modern World · **Lesson:** Diponegoro and the Java War
**Place in the curriculum:** Level 3 — Colonial Rule and the Wars of Resistance (CURRICULUM.md).
**The one thing this lesson teaches:** Prince Diponegoro's five-year Java War (1825–1830) was the last great princely resistance before the colonial state hardened — a guerrilla war that bled Java and the colonial treasury before his capture under a flag of negotiation, fixed forever in Raden Saleh's painting.
**This lesson's own level:** Level 3 — Colonial Rule and the Wars of Resistance (recommended, never forced).

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **A.2, change-over-time section** — The method book meets the Java War through a painting.
2. **Bab I.B** — The Grade 11 survey closes the war in one line: Raden Saleh's canvas of Diponegoro's capture closes the five-year Java War, the last great princely resistance before the colonial state hardens.
3. **Bab 2.B.4 Perang Diponegoro** — The Kurikulum 2013 atlas tells the war itself: the prince's five-year guerrilla war across Java, bleeding the island and the colonial treasury together, a war the Dutch could not finish by fighting.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
