# The British Interregnum, 1811–1816 — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Raffles governed Java during the British interregnum, 1811–1816.
**Answer: True**

**2.** British rule in Java lasted fifty years.
**Answer: False** — It was a five-year interregnum, 1811–1816, before the hand-back to the Dutch.
