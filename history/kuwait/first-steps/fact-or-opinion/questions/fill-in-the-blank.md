# Fact or Opinion — fill in the blank

Fill each blank with the lesson's own word.

**1.** Forged pasts are set beside true ones so learners see how a lie about yesterday bends a whole society's awareness today — the key name for this is ____.
**Answer:** forgery

**2.** A past can be forged as well as told truly, and telling the difference matters: a lie about yesterday bends a whole society's awareness today — the key name for this is ____.
**Answer:** societal awareness
