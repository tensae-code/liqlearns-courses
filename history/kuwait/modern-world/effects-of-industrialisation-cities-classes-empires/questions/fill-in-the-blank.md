# Effects of Industrialisation: Cities, Classes, Empires — fill in the blank

Fill each blank with the lesson's own word.

**1.** Crowded cities, new rich and poor classes and a hungry search for colonies follow the factory system around the world — the key name for this is ____.
**Answer:** new classes

**2.** The factory system spread its results around the world: crowded cities, new rich and poor classes, and a hungry search for colonies — the key name for this is ____.
**Answer:** crowded cities
