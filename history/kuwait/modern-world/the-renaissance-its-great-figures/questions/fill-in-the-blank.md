# The Renaissance: Its Great Figures — fill in the blank

Fill each blank with the lesson's own word.

**1.** The rebirth shows itself in art, letters, science and building, the works by which the age is still recognised — the key name for this is ____.
**Answer:** manifestations

**2.** The rebirth shows itself in works: art, letters, science and building — the manifestations by which the age is still recognised — the key name for this is ____.
