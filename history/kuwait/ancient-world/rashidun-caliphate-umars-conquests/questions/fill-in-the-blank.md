# The Rashidun Caliphate: Umar's Conquests — fill in the blank

Fill each blank with the lesson's own word.

**1.** Under Umar the Islamic state bursts outward — the eastern conquests roll over Persia's world and Syria is taken from Byzantium — the key name for this is ____.
**Answer:** Umar ibn al-Khattab

**2.** Under Umar ibn al-Khattab the Islamic state burst outward: the eastern conquests rolled over Persia's world, and Syria was taken from Byzantium — the key name for this is ____.
**Answer:** the eastern conquests
