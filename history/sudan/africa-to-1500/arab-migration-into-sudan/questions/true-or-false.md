# Arab Migration Into Sudan — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Sudan is Islamised by migration and treaty over centuries, not taken in a single invasion.
**Answer: True**

**2.** The part “The Migration of the Arabs into Sudan” teaches that its events changed nothing for anyone.
**Answer: False** — The lesson teaches the opposite: Sudan is Islamised by migration and treaty over centuries, not taken in a single invasion.
