# The Rashidun State Problems and Administration — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Empire is not only conquered; it has to be filed, paid for and governed.
**Answer: True**

**2.** The part “The Problems That Faced the State under the Rashidun” teaches that its events changed nothing for anyone.
**Answer: False** — The lesson teaches the opposite: Empire is not only conquered; it has to be filed, paid for and governed.
