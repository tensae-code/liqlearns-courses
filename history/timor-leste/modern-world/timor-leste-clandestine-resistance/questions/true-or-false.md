# Timor-Leste: The Clandestine Resistance — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Indonesian solidarity groups such as Solidamor stood with Timor-Leste inside Indonesia itself.
**Answer: True**

**2.** The clandestine resistance worked only in the mountains, never in the towns.
**Answer: False — it worked inside the occupied towns and inside Indonesia itself; the mountains were Falintil's ground.**
