# Decolonisation: Ghana, Kenya and the South — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Decolonisation undid the colonial map territory by territory.
**Answer: True**

**2.** Every independence was won the same way, by negotiation.
**Answer: False** — Some were peaceful and negotiated; others were violent struggles where the coloniser would not let go.
