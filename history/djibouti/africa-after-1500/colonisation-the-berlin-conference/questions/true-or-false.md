# Colonisation: The Berlin Conference — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** The Berlin Conference fixed rules of occupation that the powers then followed on the ground.
**Answer: True**

**2.** African rulers co-wrote the Berlin rules as equal partners.
**Answer: False** — The rules were written in Europe, at a table with no Africans seated at it.
