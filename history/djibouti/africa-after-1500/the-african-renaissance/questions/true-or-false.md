# The African Renaissance — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** A renaissance means renewal that draws on what is deepest in a civilisation itself.
**Answer: True**

**2.** The Renaissance asks Africa to treat its heritage as a museum only, not as fuel for new building.
**Answer: False** — Heritage is fuel for renewal — the call is to build anew on it, answering real present problems.
