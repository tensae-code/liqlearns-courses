# After the Flag: Debt, Drought and the Integration Answer — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Debt and globalisation bind Africa's fortunes to a world economy it does not command.
**Answer: True**

**2.** Independence ended all of Africa's problems on the day the flags rose.
**Answer: False** — Independence opened a new set of challenges — environment, population, health, debt, globalisation.
