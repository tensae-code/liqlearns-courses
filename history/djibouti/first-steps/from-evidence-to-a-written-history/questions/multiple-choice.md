# From Evidence to a Written History — multiple choice

Pick the one right answer.

**1.** What is a written history built from?
a) guesses  b) sources that have been hunted for and questioned  c) dreams about the past  d) the newest book only
**Answer: b) sources that have been hunted for and questioned** — That is what this lesson teaches.

**2.** What must the class do with a source before using it?
a) copy it without reading  b) question it — who made it, when, and what it can prove  c) hide it from others  d) throw away the old ones
**Answer: b) question it — who made it, when, and what it can prove** — That is what this lesson teaches.
