# From Evidence to a Written History — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Africa's past was carried only in written books, never in memory or objects.
**Answer: False** — Much of Africa's past was carried in memory and objects; questioning those sources is how it becomes written history.

**2.** Questioning a source means asking who made it, when, and what it can prove.
**Answer: True**
