# Economies of the Colonial Territories — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Every colonial administration asks the same question — how to make the colony pay the metropole the highest possible return.
**Answer: True**

**Answer: False** — The lesson teaches: Every colonial administration asks the same question — how to make the colony pay the metropole the highest possible return.
