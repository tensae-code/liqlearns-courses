# History — Mozambique course — titles, FROM THE BOTTOM

History belongs to the country: this course is Mozambique's own — built from Mozambique's PESD History modules (student books, Portuguese). Inside the course the organisation is by **levels, not grades**: the titles below sit inside their levels, in path order — what the learner proves, step by step. The grades the books come from live only in each lesson's sources.

The path's own logic is the books': the first cycle reaches Mozambique's story through the African and world story, and the second cycle returns — historiography first, then Africa's invasion and liberation, then Mozambique's own past whole, and Portuguese colonialism in Mozambique to the armed struggle. That ladder IS the path order (recommended, never forced — a learner can jump in higher; the "start here instead" hints point down this ladder).
