# The Arabian Peninsula before Islam — depth

This lesson is one whole lesson with no sub lessons (2026-11-09 ruling: sub lessons only where a lesson genuinely has distinct sequential parts). Practice is tied to the learner's skill number. The questions live in the type files.

Pass mark: before Islam the peninsula was a tribal land with no single state — lost peoples like Tasm and Jadis, wars between tribes and towns, strong values of courage, generosity and protecting the neighbour, and a rich caravan economy centred on Makkah — shown in the learner's own words and one real example.
