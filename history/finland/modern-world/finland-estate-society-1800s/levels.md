# Finland's Estate Society in the 1800s — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure). Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Sääty-yhteiskunta 1800-luvun Suomessa (the estate society: into what groups were people divided, and how did each group live?)
Sub lesson 1 questions from the type files. Pass mark: The module opens with the order itself — shown in the learner's own words and one real example.

## Sub lesson 2 — Etu- ja sukunimet 1800-luvun Suomessa (first names and surnames; did everyone even have a surname?)
Sub lesson 2 questions from the type files. Pass mark: Before anyone can invent a person, they must be named correctly — shown in the learner's own words and one real example.
