# Rwanda: First Republic 1962–1973 — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** The First Republic ruled as a one-party state under PARMEHUTU.
**Answer: True**

**2.** The First Republic opened schools wider to Tutsi pupils.
**Answer: False** — it imposed a 9% Tutsi quota and drove Tutsi from schools
