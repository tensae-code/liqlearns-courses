# History — Nepal course — titles, FROM THE BOTTOM

History belongs to the country: this course is Nepal's own —
built from Nepal's Social Studies student books and teacher
guides (Government of Nepal, Curriculum Development Centre).
Inside the course the organisation is by **levels, not
grades**: the titles below sit inside their levels, in path
order — what the learner proves, step by step. The grade
each book comes from lives only in ABOUT.md and in each
lesson's sources.

The path's own logic is Nepal's books': the child's own past
first, then the country's story in its own three ages —
ancient, medieval, modern — with the old and modern world
set beside it. That ladder IS the path order (recommended,
never forced — a learner can jump in higher; the "start here
instead" hints point down this ladder).
