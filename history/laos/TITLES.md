# History — Laos course — titles, FROM THE BOTTOM

History belongs to the country: this course is Laos's own — built from Laos's History books for the secondary years (student books and teacher guides, Lao). Inside the course the organisation is by **levels, not grades**: the titles below sit inside the levels in path order — what the learner proves, step by step. The grade the book comes from lives only in each lesson's sources.

The path's own logic is the books': one long story told twice — the lower-secondary telling first, the deeper upper-secondary telling after — each level one year-arc of the country's own telling. That ladder IS the path order (recommended, never forced — a learner can jump in higher; the "start here instead" hints point down this ladder).
