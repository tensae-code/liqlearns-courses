# Bahamas: Independence 1973 — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Sir Milo Butler was the first Governor General of the independent Bahamas. (Sub lesson 1)
**Answer: True**

**2.** Before independence, Bahamians carried Bahamian passports and pledged loyalty only to The Bahamas. (Sub lesson 2)
**Answer: False**
