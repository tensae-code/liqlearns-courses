# World Religions: The Five Main Faiths — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Siddhartha was born at Lumbini.
**Answer: True**

**2.** The Four Noble Truths teach that suffering has no cause and cannot end.
**Answer: False** — The teaching is the opposite: suffering has a cause — desire — and the Eightfold Path is the way to end it.
