# Exploration: Columbus, Vespucci and Magellan — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** The Treaty of Tordesillas split the world between Spain and Portugal.
**Answer: True**

**2.** Spanish sailors found the Pacific return route quickly and easily.
**Answer: False — the return route was a decades-long struggle, solved only with the Manila Galleon road of 1565.**
