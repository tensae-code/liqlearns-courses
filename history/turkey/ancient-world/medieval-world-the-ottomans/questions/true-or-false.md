# The Ottoman State at the Start of the Twentieth Century — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** The empire's treasury was indebted to foreign lenders.
**Answer: True**

**2.** The book finds the six-hundred-year state strong on every page.
**Answer: False** — it is measured and found wanting on every page — politically strained, socially burdened, economically dependent.
