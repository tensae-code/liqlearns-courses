# The First Law Codes — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Ur-Namma's code is among the first written law codes known.
**Answer: True**

**2.** A written code lets the judge change the rule to fit his mood.
**Answer: False** — the code fixes the rules — the same yesterday and tomorrow — and binds the judge as well as the judged.
