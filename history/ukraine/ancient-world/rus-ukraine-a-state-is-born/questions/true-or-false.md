# Rus-Ukraine: A State Is Born — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** The book calls the new state Rus-Ukraine, with Kyiv at its head.
**Answer: True**

**2.** Each tribe kept collecting its own tribute separately after the state was formed.
**Answer: False** — Tribute flowed to one centre at Kyiv, and one power defended the whole land.
