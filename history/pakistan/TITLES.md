# History — Pakistan course — titles, FROM THE BOTTOM

History belongs to the country: this course is Pakistan's own — built from Pakistan's Punjab Curriculum and Textbook Board student books (Urdu for Classes 4–7, English for Class 8). Inside the course the organisation is by **levels, not grades**: the titles below sit inside Levels 1–6, in path order — what the learner proves, step by step. The grades the books come from live only in each lesson's sources.

The path's own logic is the books': learn heritage and the historian's craft with the first civilisations; walk the ancient world's empires; follow the rise of Islam and the medieval worlds; cross India from the Sultanate to 1857 and its reformers; watch Europe transform and fight two world wars; and end with the Pakistan Movement and the state it founded. That ladder IS the path order (recommended, never forced — a learner can jump in higher; the "start here instead" hints point down this ladder).
