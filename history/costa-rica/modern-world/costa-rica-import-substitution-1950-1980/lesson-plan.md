# Lesson plan — Costa Rica: Import Substitution, 1950–1980

**Course:** History — Costa Rica · **Title:** Modern World · **Lesson:** Costa Rica: Import Substitution, 1950–1980
**Place in the curriculum:** Level 5 — Costa Rica's Own Twentieth Century (CURRICULUM.md).

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Productive diversification and import substitution (the CONED telling)** — From 1950 to 1980 Costa Rica diversifies production and industrialises by substituting imports.
2. **The import-substitution model (the Porras y Gamboa telling)** — Import substitution and agricultural diversification promise industry — and the model exhausts itself.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
