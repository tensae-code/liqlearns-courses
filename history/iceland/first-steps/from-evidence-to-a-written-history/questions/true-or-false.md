# From Evidence to a Written History — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** An old source is automatically a true source.
**Answer: False** — Before any history is written, its sources must be judged: who made this source, when, and why — a source that is not questioned can make the written history lie.

**2.** When two sources disagree, the disagreement itself tells you something — where each maker stood.
**Answer: True**
