# World Religions: The Five Main Faiths — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Buddhism, Christianity, Islam and Judaism each teach how human beings must treat one another, and those teachings become one root of later rights ideas. (Sub lesson 1)
**Answer: True**

**2.** In this lesson, "Unit 1, Topic 1 resource 4A "Diwali — the Festival of Lights"" is presented as a made-up tale with no real people, no real places and nothing that turned. (Sub lesson 2)
