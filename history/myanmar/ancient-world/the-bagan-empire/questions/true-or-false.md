# The Bagan Empire — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Bagan was Myanmar's first great empire. (Sub lesson 1)
**Answer: True**

**2.** The book asks learners only to praise Bagan, never to question it. (Sub lesson 2)
**Answer: False** — The book asks learners to judge Bagan critically — to weigh the cost as well as the glory.
