# History — Bangladesh course — titles, FROM THE BOTTOM

History belongs to the country: this course is Bangladesh's
own — built from Bangladesh's "History and Social Science"
student books, Classes Six to Nine (National Curriculum 2022,
NCTB; English editions read in full, Bangla parallel editions
spot-checked and confirmed identical in content, as filed).
Inside the course the organisation is by **levels, not
grades**: the titles below sit inside the levels, in path
order — what the learner proves, step by step. The grade each
book comes from lives only in each lesson's sources.

The path's own logic is the books': each class reads the whole
past through one lens, and the lenses deepen in order —
inquiry first (your own locality, then Bengal, then the
world), then economics, then society and culture, then
politics. That ladder IS the path order (recommended, never
forced — a learner can jump in higher; the "start here
instead" hints point down this ladder).
