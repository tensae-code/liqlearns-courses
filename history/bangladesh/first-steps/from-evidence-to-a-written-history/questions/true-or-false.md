# From Evidence to a Written History — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** (Sub lesson 1) A lost cricket ball leads the class to a mound with broken pottery, coins and palm-leaf manuscripts, each a source to be interrogated.
**Answer: True**

**2.** (Sub lesson 3) This lesson's teaching has nothing to do with the life of ordinary people in Bangladesh.
**Answer: False** — A written history is built from sources that are questioned first: a lost ball can lead to a ruined building, and coins, inscriptions, travellers' accounts, manuscripts and buildings each testify — differently — about the past.
