# From Evidence to a Written History — multiple choice

Pick the one right answer.

**1.** (Sub lesson 1) Which statement about “The ruined building in the jungle” is right?
a) A lost cricket ball leads the class to a mound with broken pottery, coins and palm-leaf manuscripts, each a source to be interrogated  b) it has nothing to do with this lesson  c) it is a private matter no learner ever meets  d) it was invented by LiqLearns, not taught in Bangladesh's book
**Answer: a)** — That is what this lesson teaches.

**2.** (Sub lesson 3) What is the one thing this lesson teaches?
a) that this topic concerns only officials and never ordinary people  b) A written history is built from sources that are questioned first: a lost ball can lead to a ruined building, and coins, inscriptions, travellers' accounts, manuscripts and buildings each testify — differently — about the past.  c) that learners need know nothing about it  d) that it is the same in every country and Bangladesh has no way of its own
**Answer: b)** — That is what this lesson teaches.
