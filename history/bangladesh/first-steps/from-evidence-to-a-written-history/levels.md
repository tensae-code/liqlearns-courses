# From Evidence to a Written History — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure). Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — The ruined building in the jungle
Sub lesson 1 questions from the type files. Pass mark: A lost cricket ball leads the class to a mound with broken pottery, coins and palm-leaf manuscripts, each a source to be interrogated — shown in the learner's own words and one real example.

## Sub lesson 2 — Sources of economic history
Sub lesson 2 questions from the type files. Pass mark: Coins, inscriptions, travellers' accounts and artefacts each testify about past economic life, and their differing characters decide what can be claimed — shown in the learner's own words and one real example.

## Sub lesson 3 — Two kinds of sources
Sub lesson 3 questions from the type files. Pass mark: Literary sources like the Charyapada and archaeological sources like inscriptions, copperplates, terracotta, coins and buildings must each be questioned — shown in the learner's own words and one real example.
