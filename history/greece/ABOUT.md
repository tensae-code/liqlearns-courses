# History — Greece course — ABOUT

**The first page (what learners are told):** everything in this course comes from government textbooks — Greece's own History books — except the **Tip boxes**: a tip in a box is from us, the people making LiqLearns. Tips are ours; the lessons are the books'.

## How the course is organised

One course for Greece inside the History folder, organised by **levels, not grades** (CURRICULUM.md carries the ladder and how it is derived from the books' own progression). Lessons sit under 5 title folders — Africa after 1500, Africa to 1500, Ancient world, First steps, Modern world — exactly as filed in the placements. History is taught as stories: who, where, what turned, and what came of it. A lesson stands at the level of the earliest book that teaches it; every later telling of the same story in a deeper book is stocked into the same lesson as its own part, in file order. The school grade each book comes from appears only here and in each lesson's sources, never as the course's organisation.

## The books (full list, exactly as filed)

The two placements files record: file A — 29 records / 16 distinct books; file B — 28 records / 14 distinct books; read via grab.py from the textbooks repo (TSV blob/release URLs and books.json tree paths are the same books; each distinct book read once, in full, page by page). Book numbers below run in teaching order across both files: Books 1–16 are file A's books in file order, Books 17–30 are file B's books in file order. One printed book is filed twice: Book 16 (file A, Book 16) and Book 18 (file B, Book 1) are the same Grade 9 Modern and Contemporary History student book (ISBN 978-960-06-2774-9), read and placed in both filings; its placements from both filings are stocked, and the lesson set is deduped across both files into one course of 333 lessons.
