# Find History in Your Own Locality — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** In this lesson, history can only be found inside printed books.
**Answer: False — the guide sends pupils to an elder in their own locality, whose memory holds the history of sacred and traditional practices.**

**2.** The class writes down what the elder remembers before it is lost.
**Answer: True**
