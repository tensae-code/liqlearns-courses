# Argentina Building the State, 1860–1916 — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Before the national state was built, Argentina was a loose set of provinces, often divided. (Sub lesson 1)
**Answer: True**

**2.** Argentina's railways and meat-packing plants were built without any foreign money. (Sub lesson 3)
**Answer: False** — British and other foreign capital built the railways and meat-packing plants of the export boom.
