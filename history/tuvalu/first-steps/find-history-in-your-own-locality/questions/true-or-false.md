# Find History in Your Own Locality — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** The class lists traditional fishing practices and the fish that were caught.
**Answer: True**

**2.** The guide's method keeps pupils inside the classroom, because everything worth knowing is already in the printed readers.
**Answer: False — the guide sends pupils out to an elder, whose memory holds what no reader holds, to be written down before it is lost.**
