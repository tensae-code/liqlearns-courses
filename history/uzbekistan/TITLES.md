# History — Uzbekistan course — titles, FROM THE BOTTOM

This course is Uzbekistan's own — built from Uzbekistan's history textbooks (student books, Russian editions). Inside the course the organisation is by **levels, not grades**: the titles below sit inside their levels, in path order — what the learner proves, step by step. The grade a book comes from lives only in ABOUT.md and each lesson's sources.
