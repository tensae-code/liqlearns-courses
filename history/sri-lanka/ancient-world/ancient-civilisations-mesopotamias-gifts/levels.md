# Ancient Civilisations: Mesopotamia's Gifts — depth

This lesson is one whole lesson with no sub lessons. Pass mark: the learner can state the lesson's one thing — Scribes press cuneiform into clay, Hammurabi's code promises an eye for an eye, and the first map and library appear — in their own words, give one real example from the lesson, and answer the lesson's questions. Practice deepens by more items and harder corners: first the plain cases from the lesson, then cases where the lesson's opposite (its false friend) tempts the wrong answer, then the lesson applied in a new place — a new situation the learner has not seen in the lesson.
