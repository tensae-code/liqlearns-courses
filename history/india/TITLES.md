# History — India course — titles, FROM THE BOTTOM

History belongs to the country: this course is India's own —
built from India's NCERT *Our Pasts-I*, the Class VI History
student book (Social Science). Inside the course the
organisation is by **levels, not grades**: the titles below
sit inside the levels, in path order — what the learner
proves, step by step. The grade the book comes from lives
only in each lesson's sources.

The path's own logic is the book's: one story journey from a
child's question — how can anyone know? — through the first
farmers, the first cities, the Vedic world, kingdoms and new
ideas, empire and Ashoka, the world of work and trade, the
new kingdoms, and the buildings, paintings and books left
behind. That journey IS the path order (recommended, never
forced — a learner can jump in higher; the "start here
instead" hints point down this ladder).
