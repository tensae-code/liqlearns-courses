# The Code Noir: The Law That Ruled Slavery — short answer

Answer in a sentence or two, in your own words.

**1.** Tell the story of the part "Séance 4, Travail servile et conditions de vie des esclaves dans les plantations, le Code noir (2)": who, where, and what turned?
**Answer:** The class opens the law itself: the Code Noir, the royal code whose articles ruled slavery in France's colonies. Article by article, the pupils read what it did — it defined the enslaved person as property, movable goods to be bought, sold and inherited, and it organised the master's power in legal French. The code also carried a few paper protections — food, rest, limits written on the page. Then the lesson sets the page against the plantation the pupils have already rebuilt: between the code's paper and the estate's reality yawned a gap in which real lives were spent. Law, they learn, can be an instrument of oppression wearing the dress of order.

**2.** In your own words, what is the one thing this lesson teaches?
**Answer:** The Code Noir's articles, read line by line, made the law that called people property — and the gap between its paper protections and plantation reality is the lesson.
