# The Code Noir: The Law That Ruled Slavery — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** The Code Noir's articles are read line by line — the law that called people property, and the gap between its paper protections and plantation reality.
**Answer: True**

**2.** This lesson teaches the opposite of its one thing: the Code Noir's articles, read line by line, made the law that called people property — and the gap between its paper protections and plantation reality is the lesson.
**Answer: False** — The lesson teaches exactly that one thing.
