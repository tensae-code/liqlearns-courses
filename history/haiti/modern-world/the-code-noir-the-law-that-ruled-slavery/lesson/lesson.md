# The Code Noir: The Law That Ruled Slavery

## Do it first

Read any rule that governs your school day. Who wrote it, whom does it protect, whom does it bind? This lesson reads a law book that did the opposite of protecting: the code that ruled slavery.

The class opens the law itself: the Code Noir, the royal code whose articles ruled slavery in France's colonies. Article by article, the pupils read what it did — it defined the enslaved person as property, movable goods to be bought, sold and inherited, and it organised the master's power in legal French. The code also carried a few paper protections — food, rest, limits written on the page. Then the lesson sets the page against the plantation the pupils have already rebuilt: between the code's paper and the estate's reality yawned a gap in which real lives were spent. Law, they learn, can be an instrument of oppression wearing the dress of order.

## Say it to your companion

Tell your companion what this lesson teaches: the Code Noir's articles, read line by line, made the law that called people property — and the gap between its paper protections and plantation reality is the lesson. Give one real example from your own home, school or town, and name the lesson's key words: Code Noir, article. Your companion asks one question back — answer it from the lesson.
