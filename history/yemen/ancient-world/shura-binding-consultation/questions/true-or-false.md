# Shura: Binding Consultation — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Shura is set against mere consultation: advice a ruler may ignore is istishara, but shura binds.
**Answer: True**

**2.** The part “Shura in the Arab Islamic civilisation” teaches that its events changed nothing for anyone.
**Answer: False** — The lesson teaches the opposite: Shura is set against mere consultation: advice a ruler may ignore is istishara, but shura binds.
