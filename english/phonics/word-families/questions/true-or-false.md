# Word families — true or false

True-or-false questions only. Answers at the bottom.

## Level 1
1. Words in one family share the same ending. (True / False)
2. "pan" and "pet" are in the same family. (True / False)
3. There is one family set for each short vowel in the book. (True / False)

## Answers
1-True, 2-False (pan is -an; pet is -et), 3-True (five short vowels, fifteen families)
