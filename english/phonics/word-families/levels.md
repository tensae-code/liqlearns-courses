# Word families — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
words that share the same ending — one family set for each
short vowel first, then growing a family by swapping its first
letter.

Mapping from the old depth layers: old Level 1 (the basics)
covered all fifteen families, so it maps across Sub lessons
1–5, split at the vowels below; old Level 2 = Sub lesson 6.

families' book words — -an (pan, man), -ap (map, cap), -at
(mat, hat) — and sort new family words into the right family,
without help.
