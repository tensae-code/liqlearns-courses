# Word families — questions by level

Practice sessions by level, tied to the learner's skill number.
The questions live in the type files; this file is the by-level view.

## Level 1 — the basics
Run: all Level 1 questions from every type file. Pass mark: the
learner can read all fifteen families' book words, and sort new
family words into the right family, without help.

## Level 2 — grow a family
Pass mark: given any family ending, the learner grows it with new
first letters and reads every word they made.
