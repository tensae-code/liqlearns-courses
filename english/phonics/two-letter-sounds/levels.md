# Two-letter sounds — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
two letters that together make one sound — the pairs first,
then the pairs coming round again, then the rest of the pairs
and the long sounds' other spellings, then the cover test that
tells a pair from a blend.

Mapping from the old depth layers: old Level 1 = Sub lesson 1,
and the cover test, which stood inside Level 1's run of
questions; old Level 2 = Sub lesson 2. Sub lessons 3 and 4
were added 2026-11-08 under the whole-arc rule, from the
lesson's own stocked sources (wh, ph, ck, kn, wr and the
spellings ay, ea, igh, ie, ow, ui, ir/ur were stocked but
untaught); the cover test moved from Sub lesson 3 to Sub
lesson 5 — it had no question items of its own, so no markers
changed.

Pass marks: Sub lessons 1, 2 and 5 carry the old layers' pass
marks. The books state no separate pass mark for the added
pair and spelling bands, so Sub lessons 3 and 4 keep the same
observable form — the learner can say each pair's sound on
sight, with book words — rather than an invented mark.

## Sub lesson 1 — The pairs set by set
Sub lesson 1 questions from the type files. Pass mark: the
learner can say each pair's sound on sight, and both jobs of oo
and th, with the book words.

## Sub lesson 2 — The pairs again
Sub lesson 2 questions from the type files. Pass mark: the learner can still do Level 1 cold — Libya's books

## Sub lesson 3 — More pairs: wh · ph · ck · kn · wr
Sub lesson 3 questions from the type files. Pass mark: say the
sound of wh, ph and ck on sight with a book word each, and
name the silent letter in kn (knife) and wr (write).

## Sub lesson 4 — One sound, more spellings
Sub lesson 4 questions from the type files. Pass mark: read
day (ay), sea (ea), night (igh), tie (ie), snow and cow (ow's
two jobs sorted), and say the ir/ur sound as the er sound.

## Sub lesson 5 — The cover test
Sub lesson 5 questions from the type files, where a file has
them. Pass mark (from old Level 1): the learner can use the
cover test to tell a two-letter sound from a blend — cover one
letter, and hear that the sound left is not half the word's
sound.
