# True or False — Tongue Twisters

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. A tongue twister should be said fast the very first time. (Sub lesson 1) — False
2. The books teach: slowly first, then fast. (Sub lesson 1) — True
3. One sound coming again and again is what makes a twister tricky. (Sub lesson 1) — True
4. If a sound drops out at speed, the twister still counts. (Sub lesson 2) — False
5. When your tongue trips, going back to slow is part of the game. (Sub lesson 2) — True
