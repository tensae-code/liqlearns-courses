# True or False — The Three Sounds of the -s Endings

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. The letter s always sounds the same at the end of a word. (Sub lesson 1) — False
2. /ɪz/ adds a whole syllable to the word. (Sub lesson 1) — True
3. The sound before the ending chooses the ending's sound. (Sub lesson 2) — True
4. Stops ends with /z/. (Sub lesson 2) — False
5. The -s ending appears on plural nouns and on he/she verbs. (Sub lesson 2) — True
