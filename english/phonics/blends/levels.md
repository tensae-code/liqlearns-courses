# Blends — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
two letters at the start of a word where you hear both sounds —
Egypt's s-set first, then its l-set, then the cover test
against the two-letter sounds next door.

Mapping from the old depth layers: the old file carried one
layer only — old Level 1 (the basics) covered the whole lesson,
so it maps across Sub lessons 1–3, and its pass mark splits at
the same jumps below: the s-set's words, the l-set's words,
then the cover test.

## Sub lesson 1 — The s-set blends
Sub lesson 1 questions from the type files. Pass mark (its part
of old Level 1's): say the s-set blends with a book word each —
sk (skip, sky), sn (snail, snake), st (strong, star), sw

## Sub lesson 2 — The l-set blends

of old Level 1's): say the l-set blends with a book word each —

## Sub lesson 3 — The cover test
Sub lesson 3 questions from the type files. Pass mark (its part
