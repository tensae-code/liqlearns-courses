# Blending sounds — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
pushing letter sounds together until they become a word — the
slide itself first, then the order that opens words early, then
the slide done with letter tiles.

Mapping from the old depth layers: the old file carried one
layer only — old Level 1 (the basics) covered the whole lesson,
so it maps across Sub lessons 1–3. Its pass mark (blend sit,
pat, tin and pin, slow then smooth) is Sub lesson 1's, where
those words are taught; Sub lessons 2 and 3 carry the same
depth on their own parts, below.

Sub lesson 1 questions from the type files. Pass mark: given
the sounds group s, a, t, p, i, n, the learner blends sit, pat, tin
