(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. C before e says s, as in face and rice. (Sub lesson 1) — True
2. Every word ending in -se has the buzzing z sound. (Sub lesson 1) — False
3. Cheese and noise have s buzzing like z. (Sub lesson 1) — True
4. G before e says j, as in large and page. (Sub lesson 2) — True
5. The word bridge is spelled b-r-i-j. (Sub lesson 2) — False
6. Catch, stitch and hatch all end in -tch. (Sub lesson 2) — True
