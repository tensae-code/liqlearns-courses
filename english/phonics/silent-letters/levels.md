# Silent letters — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
letters seen but not said — the definition first, then the
families one by one: kn-, wr-, -mb, -lk, -gh, and silent h with
the rest of India's groups.

Mapping from the old depth layers: the old layers were depths
over the SAME family parts, not separate parts — old Level 1
(the word) and old Level 2 (the family) both run across Sub
lessons 1–7: Level 1's pass mark is each family's words read
with the quiet letter kept quiet, Level 2's is the families
sorted and read as families. Old Level 3 (clean reading and
the traps) is the whole-lesson depth; its pass mark is carried
in Sub lesson 7's section, and the trap it names is taught in
Sub lesson 4.
