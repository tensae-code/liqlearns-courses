# Hands-on — Silent letters

You do it, we guide you. Everything here is done out
loud, with a companion or the Explain Companion.

1. **The grey-letter sort (Ecuador's cards, by hand).**
   Write these words on slips: knife, knight, knit,
   knot, knob, knee · comb, doubt, limb, thumb, womb ·
   hour, honest · write, wrist, wrinkle, wrong, wreck.
   Colour the silent letter grey on each slip, then sort
   the slips into families — K, B, H, W — the families
   of Ecuador's Worksheet 6 (printed pp.36–40).
2. **Kuwait's frame, four times.** For each of Kuwait's
   families — wrap (wr-), lamb, climb, thumb (-mb),
   walk, talk, chalk (-lk), through, bright, bought
   (-gh) — say the frame first: "A letter you see, but
   you don't say," then read the family's words. One
   point for every word read with the quiet letter kept
   quiet; the companion listens for sounded letters.
3. **India's pick-out.** Read this list aloud and clap
   once at each word that hides a silent letter: hour,
   knit, wrong, doubt, often, know, night, could, write,
   knife, high, walk (India, Marigold Class 4, Unit 7's
   picked-out set). Then say WHICH letter was quiet in
   each word you clapped.
4. **Five sentences (Ecuador's closing task).** Pick
   five words from any list on this page, make a true
   sentence for each, and read your five sentences
   aloud — the task Ecuador's Worksheet 6 ends with
   (printed p.41).
