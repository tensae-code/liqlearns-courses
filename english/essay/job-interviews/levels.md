# Job interviews — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS
(2026-11-08 restructure — README, "Units, Lessons and Sub Lessons").
Practice is tied to the skill number, as before. The questions live in
the type files; this file is the by-sub-lesson view. The sub lessons are
the depths inside this one thing — the prepared interview — set by the
pattern across the countries' books: the preparation first, then the
STAR answer, then the whole mock survived.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level
2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Job interviews — preparation

Sub lesson 1 questions from the type files. Pass mark: list the
preparation moves — the place researched, dress, early
arrival, phone away, body language — and the documents
carried.

## Sub lesson 2 — Job interviews — the STAR answer

Sub lesson 2 questions from the type files. Pass mark: build any
"Tell me about a time when…" answer in the four parts, in
order, ending on a result with a number or a fact in it.

## Sub lesson 3 — Job interviews — the mock survived

Sub lesson 3 questions from the type files. Pass mark: hold a
whole mock — experience answers, quality adjectives used
truly, thinking-time phrases — and retell the interviewer's
questions afterwards as reported questions.
