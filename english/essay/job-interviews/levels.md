# Job interviews — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the prepared interview — set by
the pattern across the countries' books: the preparation first,
then the STAR answer, then the whole mock survived.

## Level 1 — preparation
Level 1 questions from the type files. Pass mark: list the
preparation moves — the place researched, dress, early
arrival, phone away, body language — and the documents
carried.

## Level 2 — the STAR answer
Level 2 questions from the type files. Pass mark: build any
"Tell me about a time when…" answer in the four parts, in
order, ending on a result with a number or a fact in it.

## Level 3 — the mock survived
Level 3 questions from the type files. Pass mark: hold a
whole mock — experience answers, quality adjectives used
truly, thinking-time phrases — and retell the interviewer's
questions afterwards as reported questions.
