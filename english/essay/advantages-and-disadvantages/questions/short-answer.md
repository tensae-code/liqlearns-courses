# Short answer — Advantages and Disadvantages

(Gate pool: all questions of the sub lesson(s) named — no hardness ranking is written here, so a sub lesson's whole question set is its gate pool.)

1. Write one advantage of learning English, using the word "benefit".
   **Answer:** Any true sentence with benefit on the good side, e.g. "One benefit of learning English is that you can read books from many countries." (Sub lesson 1)

2. Give a turning phrase that moves to the other side.
   **Answer:** On the other hand (or however / but). (Sub lesson 1)

3. Write the opening sentence for a balanced piece about homework.
   **Answer:** Any sentence naming the topic and both sides, e.g. "Homework has both good points and bad points." (Sub lesson 2)

4. Why must the bad points be honest in a balanced piece?
   **Answer:** Because a piece that hides them is an advertisement, not a discussion. (Sub lesson 2)
