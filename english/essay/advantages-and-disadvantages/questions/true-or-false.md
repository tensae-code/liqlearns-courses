# True or false — Advantages and Disadvantages

(Gate pool: all questions of the sub lesson(s) named — no hardness ranking is written here, so a sub lesson's whole question set is its gate pool.)

1. "Drawback" and "disadvantage" name the same side.
   **Answer: True** (Sub lesson 1)

2. "Firstly, secondly, finally" are turning words for changing sides.
   **Answer: False** — they add points on the same side. (Sub lesson 1)

3. The closing view must say which side is stronger for you.
   **Answer: True** (Sub lesson 2)

4. A balanced piece about team sports may only praise team sports.
   **Answer: False** — it must weigh both sides. (Sub lesson 2)
