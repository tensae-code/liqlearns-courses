# True or false — Asking for Advice

(Gate pool: all questions of the sub lesson(s) named — no hardness ranking is written here, so a sub lesson's whole question set is its gate pool.)

1. An advice-asking letter should hide the real problem.
   **Answer: False** — it must tell the problem clearly. (Sub lesson 1)

2. You can write an advice letter to an advice column or to a person you trust.
   **Answer: True** (Sub lesson 1)

3. Good advice gives reasons, not just orders.
   **Answer: True** (Sub lesson 2)

4. "You should" is a question word.
   **Answer: False** — it gives advice. (Sub lesson 2)
