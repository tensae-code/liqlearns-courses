# Short answer — Asking for Advice

(Gate pool: all questions of the sub lesson(s) named — no hardness ranking is written here, so a sub lesson's whole question set is its gate pool.)

1. Write the sentence that tells this problem: your best friend is angry and you don't know why.
   **Answer:** Any clear problem sentence, e.g. "My best friend is angry with me and I don't know why." (Sub lesson 1)

2. Why should an asking letter be short and clear?
   **Answer:** So the helper can understand the problem from the letter alone. (Sub lesson 1)

3. Give two advice steps for the angry-friend problem.
   **Answer:** Any two kind, doable steps, e.g. talk to the friend; ask what is wrong; say sorry if you hurt them. (Sub lesson 2)

4. Write a hopeful closing sentence for an advice answer.
   **Answer:** Any hopeful close, e.g. "I hope this helps — good luck!" (Sub lesson 2)
