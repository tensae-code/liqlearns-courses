# True or False — Judging the Soundness of an Argument

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. An argument fails if either its claim is false or its evidence does not carry the claim. (Sub lesson 1) — True
2. Repetition of a claim counts as evidence for it. (Sub lesson 1) — False
3. Verdicts are given per claim, not per speaker. (Sub lesson 1) — True
4. Hunting only for details that support a claim is good claim-testing. (Sub lesson 2) — False
5. Loaded words doing the work of evidence are a sign of bias. (Sub lesson 2) — True
