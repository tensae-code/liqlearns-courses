# Short Answer — Judging the Soundness of an Argument

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. State the two legs an argument stands on. (Sub lesson 1)
   — The truth of the claim, and the evidence's true support of it; if either breaks, the argument is not sound.

2. A debater proves pollution is severe, claiming it proves humans are solely responsible. Name the failure. (Sub lesson 1)
   — The carry fails: the evidence supports a smaller claim (humans cause much damage), not the asserted one (sole responsibility).

3. What two hunts does claim-testing in a text require? (Sub lesson 2)
   — Details that affirm the claim and details that refute it — both must be gathered before a verdict.

4. Give two signs of bias in a text. (Sub lesson 2)
   — E.g. details chosen from one side only with opposing details omitted; loaded words doing the work of evidence.
