# True or false — Debating

1. The negative team's job is to attack the moot. (Sub lesson 1) — True
2. Rebuttal means answering your own team's arguments. (Sub lesson 1) — False
3. A debater must recognise the other side's arguments accurately before answering them. (Sub lesson 2) — True
4. In the speaking order, the third negative sums up before the third affirmative. (Sub lesson 1) — False
