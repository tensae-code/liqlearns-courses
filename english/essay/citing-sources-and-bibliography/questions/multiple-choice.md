# Multiple Choice — Citing Sources and Bibliography

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. A citation in your work names: (Sub lesson 1)
   a) The source a fact, idea or wording came from ✓
   b) Your best friend
   c) The title of your own work
   d) Nothing — it is an empty mark

2. A citation stands: (Sub lesson 1)
   a) Only on the cover page
   b) Inside the work, at the place where the borrowed material is used ✓
   c) In a different book
   d) Nowhere — citations are spoken, not written

3. A citation is: (Sub lesson 1)
   a) A copy of the whole source pasted into your work
   b) A pointer that names the source so the reader can find it ✓
   c) A promise to name sources later
   d) A decoration at the end of a line

4. Citation follows procedures so that: (Sub lesson 1)
   a) Every citation carries what a reader needs to find the source ✓
   b) Citations all look pretty
   c) Nobody can check the work
   d) The work becomes longer

5. The bibliography is: (Sub lesson 2)
   a) One citation inside the text
   b) The list of the work's sources, gathered at the end ✓
   c) The first paragraph of the work
   d) A story about the writer

6. In finished work, the citations and the bibliography: (Sub lesson 2)
   a) Never meet — they are unrelated
   b) Work together: every cited source stands in the bibliography ✓
   c) Replace each other — you need only one of them
   d) Belong to two different works

7. A work has a bibliography but no citations inside. The reader's problem is: (Sub lesson 2)
   a) The work is too short
   b) They must guess which source backs which line ✓
   c) The bibliography is at the end
   d) There is no problem at all
