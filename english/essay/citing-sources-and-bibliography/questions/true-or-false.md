# True or False — Citing Sources and Bibliography

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. A citation names the source of a fact, idea or wording used in your work. (Sub lesson 1) — True
2. A citation copies the whole source into your work. (Sub lesson 1) — False
3. Citations stand at the place where the borrowed material is used. (Sub lesson 1) — True
4. Anyone may name sources in any way they like; procedures do not matter. (Sub lesson 1) — False
5. The bibliography gathers the work's sources at the end. (Sub lesson 2) — True
6. A bibliography full of sources the work never used is good practice. (Sub lesson 2) — False
