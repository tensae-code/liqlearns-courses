# Personal statements and proposals — true or false

Say true or false, in the strict format.

**1. (Level 1)** A personal statement is a CV written in
paragraph form, line for line. **Answer: False** — it
selects and joins; the list stays in the CV.

**2. (Level 2)** A proposal is addressed to a decider who
can grant it. **Answer: True** — Jordan's model is
written for the headteacher; the ask needs its owner.

**3. (Level 3)** Greece teaches the proposal without any
length. **Answer: False** — it is word-counted work:
130–180 words, register taught beside it.
