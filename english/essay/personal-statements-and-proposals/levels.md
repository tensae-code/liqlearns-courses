# Personal statements and proposals — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — presenting a person and a plan —
set by the pattern across the countries' books: the statement
first, then the proposal, then both judged as formal pieces.

## Level 1 — the personal statement
Level 1 questions from the type files. Pass mark: state what
a personal statement is, where it rides (a university
application), and how it differs from the CV.

## Level 2 — the proposal's shape
Level 2 questions from the type files. Pass mark: lay out a
formal proposal — present situation, why change is needed,
what could be done — inside its taught length and register.

## Level 3 — both judged whole
Level 3 questions from the type files. Pass mark: repair a
statement that merely repeats its CV, and a proposal with
no workable plan, keeping both formal and honest.
