# True or false — The Writing Process

1. A first draft is allowed to be rough; its job is to exist. (Sub lesson 1) — True
2. Revising and editing are the same stage. (Sub lesson 1) — False
3. Talking about a text before writing it can be part of planning. (Sub lesson 2) — True
4. A writing frame is a finished text that learners copy word for word. (Sub lesson 2) — False
