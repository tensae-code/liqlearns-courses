# True or False — The Toast

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. A toast is measured in seconds or a few minutes, not in an argument's arc. (Sub lesson 1) — True
2. A toast may carry three or four separate thoughts comfortably. (Sub lesson 1) — False
3. The honoured name should come early — a toast has no time for approach. (Sub lesson 2) — True
4. The wish in a toast states a hope for the honoured one. (Sub lesson 2) — True
5. Delivery of a toast is seated and quiet, eyes on the page. (Sub lesson 2) — False
