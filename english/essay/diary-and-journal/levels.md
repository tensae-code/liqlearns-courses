# Diary and journal — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the dated, first-person record of a
day — set by the pattern across the countries' books: the parts
first, then the day's order and voice, then the journal's wider job.

## Level 1 — the parts
Level 1 questions from the type files. Pass mark: name the
diary's parts in order (date, greeting, the day's details,
closing) and the voice it is written in (first person, past).

## Level 2 — the day in order
Level 2 questions from the type files. Pass mark: run a day
through its morning / daytime / evening sections with its
feelings carried, and close with a thought, wish or plan.

## Level 3 — diary into journal
Level 3 questions from the type files. Pass mark: widen a
diary entry into a journal entry — goals, lessons and
reflection added — and hold the travel journal's five steps
(basics, what happened, feelings, sensory details, reflection).
