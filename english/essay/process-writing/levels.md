# Process writing — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS
(2026-11-08 restructure — README, "Units, Lessons and Sub Lessons").
Practice is tied to the skill number, as before. The questions live in
the type files; this file is the by-sub-lesson view. The sub lessons are
the depths inside this one thing — the procedure text — set by the
pattern across the countries' books: the shape first, then the working
parts, then the whole piece judged as a reader meets it. The sub lessons
inside this lesson are RANKS: pass a rank to wear it.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level
2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Process writing — the shape

Sub lesson 1 questions from the type files. Pass mark: lay a procedure's parts in order — goal, materials, steps — and write steps as bare imperatives.

## Sub lesson 2 — Process writing — the hinges

Sub lesson 2 questions from the type files. Pass mark: join steps with sequence words, keep one action per step, and turn an infographic or picture set into an ordered process text.

## Sub lesson 3 — Process writing — the four doors

Sub lesson 3 questions from the type files. Pass mark: name procedure, descriptive, recount and report, state each kind's job, and write a procedure that passes the stranger test unaided.
