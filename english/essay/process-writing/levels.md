# Process writing — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the procedure text — set by the pattern across
the countries' books: the shape first, then the working parts,
then the whole piece judged as a reader meets it. The levels
inside this lesson are RANKS: pass a rank to wear it.

## Level 1 — the shape
Level 1 questions from the type files. Pass mark: lay a procedure's parts in order — goal, materials, steps — and write steps as bare imperatives.

## Level 2 — the hinges
Level 2 questions from the type files. Pass mark: join steps with sequence words, keep one action per step, and turn an infographic or picture set into an ordered process text.

## Level 3 — the four doors
Level 3 questions from the type files. Pass mark: name procedure, descriptive, recount and report, state each kind's job, and write a procedure that passes the stranger test unaided.
