# Process writing — True or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Process writing — the shape · (Level 2) -> Sub lesson 2 — Process writing — the hinges · (Level 3) -> Sub lesson 3 — Process writing — the four doors.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** A procedure's steps should be written in the past tense, because the writer did the task before. **Answer: False** — the procedure lives in a standing present of imperatives — true every time anyone does it.

**2. (Sub lesson 2)** Directions in prose (home to school) obey the same law as a recipe: order, completeness, nothing left to guessing. **Answer: True** — Barbados' syllabus sets directions in prose as the same writing kind (syllabus evidence).

**3. (Sub lesson 3)** If a step needs a thing that is not in the materials list, the reader will simply find it. **Answer: False** — a step that discovers a missing thing is a broken step; the list stands before the steps.
