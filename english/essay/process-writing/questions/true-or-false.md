# Process writing — True or false

Say true or false. If it is false, say why.

**1. (Level 1)** A procedure's steps should be written in the past tense, because the writer did the task before. **Answer: False** — the procedure lives in a standing present of imperatives — true every time anyone does it.

**2. (Level 2)** Directions in prose (home to school) obey the same law as a recipe: order, completeness, nothing left to guessing. **Answer: True** — Barbados' syllabus sets directions in prose as the same writing kind (syllabus evidence).

**3. (Level 3)** If a step needs a thing that is not in the materials list, the reader will simply find it. **Answer: False** — a step that discovers a missing thing is a broken step; the list stands before the steps.
