# Process writing — Ordering

Stand the items in their true order.

**1. (Level 1)** Order the sprouts procedure's steps: harvest / soak the beans / rinse and drain again / cover with cheesecloth / place beans in a jar / drain. **Answer: place beans in a jar — soak the beans — cover with cheesecloth — drain — rinse and drain again — harvest** — the run as Indonesia's book files it (Grade 7, Ch.6).

**2. (Level 3)** Order the writing decisions: write the steps / choose the text kind (the door) / test on a stranger / state the goal and list materials. **Answer: choose the text kind — state the goal and list materials — write the steps — test on a stranger** — kind first; sentences second; doing last as the proof.
