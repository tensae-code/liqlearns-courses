# The essay — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the essay's shape — set by the
pattern across the countries' books: the structure first, then the
plan, then the skeleton test run as a reader.

## Level 1 — the structure
Level 1 questions from the type files. Pass mark: define the essay
in Bolivia's terms and lay its parts in order — introduction,
topic paragraphs, conclusion — each with its job named.

## Level 2 — the plan
Level 2 questions from the type files. Pass mark: brainstorm a
topic into piles, outline the points in a felt order, and write
the essay from the outline with every paragraph's naming
sentence in place.

## Level 3 — the skeleton test
Level 3 questions from the type files. Pass mark: read any essay
by its topic sentences alone and judge it — find the paragraph
with two points or none, name the missing order, and weigh the
piece for its centre like a Unit 2 reader.
