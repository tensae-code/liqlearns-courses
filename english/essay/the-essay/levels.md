# The essay — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — the
essay's shape — the definition and structure first, then the
plan, then the skeleton test run as a reader.

Mapping from the old depth layers: old Level 1 covered two
natural jumps, so it splits at the jump — the definition is Sub
lesson 1 and the structure is Sub lesson 2, and its pass mark
splits the same way below; old Level 2 = Sub lesson 3 (the plan,
including the order of the points); old Level 3 = Sub lesson 4.

## Sub lesson 1 — The Essay Defined
Sub lesson 1 questions from the type files. Pass mark: define the essay in Bolivia's terms — five or more paragraphs, one topic, several main points.

## Sub lesson 2 — The Essay's Structure
Sub lesson 2 questions from the type files. Pass mark: lay the essay's parts in order — introduction, topic paragraphs, conclusion — each with its job named.

## Sub lesson 3 — Planning the Essay
Sub lesson 3 questions from the type files. Pass mark: brainstorm a topic into piles, outline the points in a felt order, and write the essay from the outline with every paragraph's naming sentence in place.

## Sub lesson 4 — The Skeleton Test
Sub lesson 4 questions from the type files. Pass mark: read any essay by its topic sentences alone and judge it — find the paragraph with two points or none, name the missing order, and weigh the piece for its centre like a Unit 2 reader.
