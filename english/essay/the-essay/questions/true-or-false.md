# The essay — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — The Essay Defined (item 1) and Sub lesson 2 — The Essay's Structure (item 5) · (Level 2) -> Sub lesson 3 — Planning the Essay · (Level 3) -> Sub lesson 4 — The Skeleton Test (item 4), except item 6, the conclusion's different perspective -> Sub lesson 2.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** An essay may roam across as many topics as
its paragraphs can hold.
**False** — ONE topic (Bolivia's definition). The points
multiply; the topic does not.

**2. (Sub lesson 3)** A strong writer skips the outline when the
topic is familiar.
**False** — Ghana's process has no such exemption; the
road decision precedes the journey at every scale. Familiar
topics wander most proudly.

**3. (Sub lesson 3)** The points' order may be any order the
reader can feel is an order.
**True** — strongest last, time order, near to far: all
lawful. Only the shuffled bag is forbidden.

**4. (Sub lesson 4)** If each paragraph is excellent, the essay
is excellent.
**False** — the skeleton test exists for this: fine rooms,
no house. Order and belonging make the essay.

**5. (Sub lesson 2)** Bolivia's table allows the body to explore
both sides of a debate.
**True** — "explore both sides of debate in a better
answer," under Topic 1/2/3.

**6. (Sub lesson 2)** The conclusion's "different perspective"
means a different TOPIC.
**False** — the SAME information, seen from the far side:
after the saying, not instead of it.
