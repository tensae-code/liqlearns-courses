# Report writing — Multiple choice

Pick the one right answer.

**1. (Level 1)** Egypt's Tip Box defines a formal report as —
a) a story about your day  b) a serious document giving information, usually with advice  c) a letter to a friend **Answer: b)** — the definition whole, Tip Box p.57.

**2. (Level 1)** The formal report's parts, in order, begin —
a) Findings, Title, Conclusion  b) Title, To/From, Introduction  c) Introduction, Title, To/From **Answer: b)** — the frame opens Title, To/From, Introduction (Egypt, p.57).

**3. (Level 2)** In Sudan's survey report, the statistics are carried by —
a) long stories  b) a pie chart and majority/minority sentences  c) the introduction only **Answer: b)** — SPINE 5 Ch.3: pie-chart statistics, majority/minority.

**4. (Level 3)** A recommendation belongs in a report because —
a) reports usually give advice on the information  b) it makes the report longer  c) the conclusion needs a friend **Answer: a)** — Egypt's definition: information, usually with advice.
