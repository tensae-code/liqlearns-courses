# Report writing — Ordering

Stand the items in their true order.

**1. (Level 2)** Order the survey report's run: statistics / aims / conclusion / method. **Answer: aims — method — statistics — conclusion** — Sudan, SPINE 5 Ch.3: the questionnaire's report runs in this order.

**2. (Level 3)** Order the formal report's second half: Conclusion / Findings / Recommendations. **Answer: Findings — Recommendations — Conclusion** — facts first, advice from the facts, then the brief return (Egypt, p.57).
