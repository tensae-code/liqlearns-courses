# Report writing — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS
(2026-11-08 restructure — README, "Units, Lessons and Sub Lessons").
Practice is tied to the skill number, as before. The questions live in
the type files; this file is the by-sub-lesson view. The sub lessons are
the depths inside this one thing — the factual report — set by the
pattern across the countries' books: the shape first, then the working
parts, then the whole piece judged as a reader meets it. The sub lessons
inside this lesson are RANKS: pass a rank to wear it.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level
2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Report writing — the frame

Sub lesson 1 questions from the type files. Pass mark: lay the formal report's parts in order — Title, To/From, Introduction, Findings, Recommendations, Conclusion — and name each part's job.

## Sub lesson 2 — Report writing — the survey

Sub lesson 2 questions from the type files. Pass mark: run the survey report's run — aims, method, statistics, conclusion — and turn counts into majority/minority sentences and a chart.

## Sub lesson 3 — Report writing — the judgement

Sub lesson 3 questions from the type files. Pass mark: write a whole report a stranger could act on: formal language throughout, findings that carry the recommendations, a conclusion that adds nothing new.
