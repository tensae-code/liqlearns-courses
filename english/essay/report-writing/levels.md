# Report writing — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the factual report — set by the pattern across
the countries' books: the shape first, then the working parts,
then the whole piece judged as a reader meets it. The levels
inside this lesson are RANKS: pass a rank to wear it.

## Level 1 — the frame
Level 1 questions from the type files. Pass mark: lay the formal report's parts in order — Title, To/From, Introduction, Findings, Recommendations, Conclusion — and name each part's job.

## Level 2 — the survey
Level 2 questions from the type files. Pass mark: run the survey report's run — aims, method, statistics, conclusion — and turn counts into majority/minority sentences and a chart.

## Level 3 — the judgement
Level 3 questions from the type files. Pass mark: write a whole report a stranger could act on: formal language throughout, findings that carry the recommendations, a conclusion that adds nothing new.
