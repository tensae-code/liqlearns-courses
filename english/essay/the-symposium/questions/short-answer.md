# Short Answer — The Symposium

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. Name the four roles the book assigns and each one's core duty. (Sub lesson 1)
   — Resource speaker — brings the expert knowledge; emcee — hosts and holds the programme together; introduction officer — presents each speaker; moderator/facilitator — runs the open forum and fields questions.

2. What breaks if there is no moderator? (Sub lesson 1)
   — The open forum: questions arrive unordered, overlong or heated, and eat the programme — the forum is a chaired part, not a free-for-all.

3. Give the rubric's five lines. (Sub lesson 2)
   — Organisation and time management; delivery and elocution; preparedness and fielding questions; collaboration and originality; content.

4. Why script the officers' lines, not only the speeches? (Sub lesson 2)
   — Because the event's joints — openings, introductions, handoffs, the forum — are where programmes fall apart; the officers carry the audience between speeches.
