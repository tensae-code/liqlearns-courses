# Hands-On — The Symposium

Things you do with real books, real texts and real talk.

1. **Casting and first lines.** Cast a class symposium. Each officer writes and speaks their first line; speakers state their titles. The class checks every role is filled and distinct.
2. **Handoff rehearsal.** Rehearse only the joints: emcee → introduction → speech opening → applause → forum opening. Time them against the running order.
3. **Rubric dry-run.** Stage a ten-minute mini-symposium (two speakers) and judge it on the book's rubric, one evidence line per rubric point.
