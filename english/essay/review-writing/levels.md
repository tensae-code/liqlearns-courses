# Review writing — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the review — set by the pattern across
the countries' books: the shape first, then the working parts,
then the whole piece judged as a reader meets it. The levels
inside this lesson are RANKS: pass a rank to wear it.

## Level 1 — the four parts
Level 1 questions from the type files. Pass mark: lay a review's parts in order — introduction + overall impression, specific details, pros and cons, conclusion + recommendation — and say each part's job.

## Level 2 — judgement with reasons
Level 2 questions from the type files. Pass mark: order judgements so each strong word is paid for by a specific detail, across film, book and restaurant reviews.

## Level 3 — the trusted verdict
Level 3 questions from the type files. Pass mark: write a whole review whose recommendation matches its weighing — fair summary, ordered judgements, a verdict a named reader can act on.
