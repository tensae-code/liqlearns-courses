# Short answer questions — Making Decisions

(Every item is marked with the sub lesson it belongs to: (Sub lesson N).
The gate pool for a sub lesson is all of that sub lesson's questions —
no hardness ranking is written in questions/, so the whole set is the pool.)

## Short answer

1. **Name the three kinds of decision.** (Sub lesson 1) — **Answer:** No decision, snap decision, responsible decision.
2. **What does a responsible decision do before choosing?** (Sub lesson 1) — **Answer:** It stops, thinks and weighs where each choice leads.
3. **Whose five steps does the book teach, and what does the class apply them to?** (Sub lesson 2) — **Answer:** Bryn's steps, applied to each learner's own last big decision.
