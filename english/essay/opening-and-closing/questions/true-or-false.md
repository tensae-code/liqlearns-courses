# Opening and closing — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — The Opening — Catch and Name · (Level 2) -> Sub lesson 2 — The Closing — Return and Land · (Level 3) -> Sub lesson 3 — The Ends Judged.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** An opening that names the topic clearly has
done its whole job.
**False** — naming is job two. Job one is catching (Ghana's
first question); a form opening names and loses the reader.

**2. (Sub lesson 2)** The closing should use the introduction's
exact sentences so the reader feels the return.
**False** — exact words = echo. The return is of
INFORMATION, from a different perspective; the wording must
be new.

**3. (Sub lesson 2)** A closing may end the essay on a line meant
to be carried away.
**True** — the landing line is the closing's crown; the
essay's last gift to the reader's memory.

**4. (Sub lesson 3)** A question opening is always the best
opening.
**False** — moves are tools, not ranks: scene, fact, story-
breath, question — the best is the one that catches THIS
reader for THIS topic and still lets the naming land.

**5. (Sub lesson 1)** The introduction may hide the points to
create suspense.
**False** — Bolivia's duty is to TELL the main ideas. Essay
suspense lives in how the points will be proven, not in
whether they exist.

**6. (Sub lesson 3)** If the opening was written last, the essay
is dishonest.
**False** — the process expects revised ends; order of
WRITING is the writer's business. Order of READING is the
essay's.
