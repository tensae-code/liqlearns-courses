# Opening and closing — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — the
essay's two ends — the opening first, then the closing, then
both ends judged by the books' questions.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — The Opening — Catch and Name
Sub lesson 1 questions from the type files. Pass mark: write an opening that catches (one named move) and names (topic + points) inside one paragraph, in that order.

## Sub lesson 2 — The Closing — Return and Land
Sub lesson 2 questions from the type files. Pass mark: write a closing that returns the introduction's information from a different perspective — no copied sentences, no new points — with a signal and a final line that lands.
