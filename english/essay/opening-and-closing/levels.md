# Opening and closing — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the essay's two ends — set by the
pattern across the countries' books: the opening first, then the
closing, then both ends judged by the books' questions.

## Level 1 — the opening
Level 1 questions from the type files. Pass mark: write an opening
that catches (one named move) and names (topic + points) inside
one paragraph, in that order.

## Level 2 — the closing
Level 2 questions from the type files. Pass mark: write a closing
that returns the introduction's information from a different
perspective — no copied sentences, no new points — with a
signal and a final line that lands.

## Level 3 — the ends judged
Level 3 questions from the type files. Pass mark: diagnose any
pair of ends by the five faults and Ghana's two questions, and
repair each fault with the smallest change that cures it.
