# Letters that ask and advise — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — the
asking letters — cut by the lesson's own kinds: the primary five
and the enquiry first, then the authority and the editor, then
the advice letter.

Mapping from the old depth layers: the old layers ran as depths
across all the kinds — old Level 1 named the kinds, old Level 2
built each kind's ask, old Level 3 chose the door — so each sub
lesson below carries its own kind's slice of all three: naming
that kind (old Level 1), building its ask (old Level 2) and
choosing it by who holds the power (old Level 3).

## Sub lesson 1 — Letters that ask and advise — the primary five and the enquiry
Sub lesson 1 questions from the type files. Pass mark: name
the primary five — invitation, praise, request, sympathy,
apology — and say what each one asks for, name the four
formal kinds they grow into, and build the enquiry's ask as
a clean list of questions the office can answer.

## Sub lesson 2 — Letters that ask and advise — the authority and the editor
Sub lesson 2 questions from the type files. Pass mark: build
the ask for its reader — facts plus one request for an
authority, a hedged opinion for the editor — and, given any
situation, choose between these doors by who holds the
power and defend the choice.

## Sub lesson 3 — Letters that ask and advise — the advice letter
Sub lesson 3 questions from the type files. Pass mark: build
the advice letter's ask — the trouble restated, counsel
softened for its reader — and defend choosing this door for
a friend or a problem page.
