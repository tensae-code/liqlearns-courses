# Letters that ask and advise — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the asking letters — set by the
pattern across the countries' books: the kinds first, then each
kind's ask, then the door chosen and defended.

## Level 1 — the kinds
Level 1 questions from the type files. Pass mark: name the
four formal kinds and the primary five, and say what each
one asks for.

## Level 2 — each kind's ask
Level 2 questions from the type files. Pass mark: build the
ask for its reader — questions listed for an enquiry, facts
plus one request for an authority, counsel softened for
advice, a hedged opinion for the editor.

## Level 3 — the door chosen
Level 3 questions from the type files. Pass mark: given any
situation, choose the kind by who holds the power, write
it, and defend the choice.
