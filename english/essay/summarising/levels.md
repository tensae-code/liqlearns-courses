# Summarising — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the summary — set by the
pattern across the countries' books: the definition
first, then the length law, then the story frame and the
ladder run whole.

## Level 1 — selection and paraphrase
Level 1 questions from the type files. Pass mark: state
what a summary is — main points selected, written in your
own words as full sentences — and sort main points from
examples and details in any passage, down to
paragraph-length labels, Mauritania's way.

## Level 2 — the set length
Level 2 questions from the type files. Pass mark: hit a
set length — the one-third rule, a 30-word summary on
Sudan's worked pattern, a 50-word and a 100-word summary
as South Sudan sets them — without copying a sentence.

## Level 3 — the ladder and the story frame
Level 3 questions from the type files. Pass mark: shrink
one summary down the ladder (80 → 50 → 30 → 20) keeping
every main point, and summarise a story on
Someone–Wanted–So–But–Then, Malaysia's frame, or one
sentence per heading, South Sudan's.
