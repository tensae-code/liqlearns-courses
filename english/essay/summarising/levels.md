# Summarising — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — the
summary — set by the pattern across the countries' books: the
definition first, then the length law, then the story frame and the
ladder run whole.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old
Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Selecting and Paraphrasing
Sub lesson 1 questions from the type files. Pass mark: state what a
summary is — main points selected, written in your own words as full
sentences — and sort main points from examples and details in any
passage, down to paragraph-length labels, Mauritania's way.

## Sub lesson 2 — Summarising to a Set Length
Sub lesson 2 questions from the type files. Pass mark: hit a set
length — the one-third rule, a 30-word summary on Sudan's worked
pattern, a 50-word and a 100-word summary as South Sudan sets them —
without copying a sentence.

## Sub lesson 3 — The Shrinking Ladder and the Story Frame
Sub lesson 3 questions from the type files. Pass mark: shrink one
summary down the ladder (80 → 50 → 30 → 20) keeping every main
point, and summarise a story on Someone–Wanted–So–But–Then,
Malaysia's frame, or one sentence per heading, South Sudan's.
