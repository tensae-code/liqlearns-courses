# Forms, minutes and questionnaires — Ordering

Stand the items in their true order.

**1. (Level 2)** Order the meeting papers: minutes signed and filed / agenda written / meeting held / actions done and reported. **Answer: agenda written — meeting held — minutes signed and filed — actions done and reported** — before, during, after: the two papers bracket the meeting.

**2. (Level 3)** Order the questionnaire's life: tally the answers / design answer boxes / pilot on two people / write single plain questions / run it on the group. **Answer: write single plain questions — design answer boxes — pilot on two people — run it on the group — tally the answers** — pilot before running: a question two people misunderstand is repaired first.
