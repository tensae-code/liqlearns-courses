# Presentation skills — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the planned talk — set by the
pattern across the countries' books: the plan first, then
the delivery, then the questions.

## Level 1 — planning the talk
Level 1 questions from the type files. Pass mark: stage a
talk before writing it — opening, goal, ordered points,
ending — with slides and notes that support, not carry.

## Level 2 — giving the talk
Level 2 questions from the type files. Pass mark: deliver
to Syria's tips live — open strongly, define your terms,
keep the timing, finish with a bang — in a group
presentation where each speaker owns a stage.

## Level 3 — the questions
Level 3 questions from the type files. Pass mark: run
TRACT whole on hard questions — Thank, Repeat, Answer,
Check, Thank — and say what to do when you do not know.
