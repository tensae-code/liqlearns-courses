# True or False — Writing an Email

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. The signature is the first part of an email. (Sub lesson 1) — False
2. The recipient address says who the email is going to. (Sub lesson 1) — True
3. The subject is read before the email is opened. (Sub lesson 1) — True
4. The message body stands at the very top of the email. (Sub lesson 2) — False
5. An email ends with a closing and a signature. (Sub lesson 2) — True
6. The order of an email's parts can be mixed up in any way you like. (Sub lesson 2) — False
