# Complaint letters — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the complaint and its reply — set
by the pattern across the countries' books: the complaint first,
then the reply, then the pair judged together.

## Level 1 — the complaint's moves
Level 1 questions from the type files. Pass mark: state the
complaint's order — the stay/the order, the facts, the
trouble's cost, the fix asked — in factual sentences.

## Level 2 — the reply's moves
Level 2 questions from the type files. Pass mark: answer any
complaint with apology, honest explanation and promised
action, each present and in that order.

## Level 3 — tone under pressure
Level 3 questions from the type files. Pass mark: hold the
formal register through anger — spot mixed-style faults
and rewrite them — and judge a pair whole.
