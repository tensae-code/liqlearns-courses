# Complaint letters — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS
(2026-11-08 restructure — README, "Units, Lessons and Sub Lessons").
Practice is tied to the skill number, as before. The questions live in
the type files; this file is the by-sub-lesson view. The sub lessons are
the depths inside this one thing — the complaint and its reply — set by
the pattern across the countries' books: the complaint first, then the
reply, then the pair judged together.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level
2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Complaint letters — the complaint's moves

Sub lesson 1 questions from the type files. Pass mark: state the
complaint's order — the stay/the order, the facts, the
trouble's cost, the fix asked — in factual sentences.

## Sub lesson 2 — Complaint letters — the reply's moves

Sub lesson 2 questions from the type files. Pass mark: answer any
complaint with apology, honest explanation and promised
action, each present and in that order.

## Sub lesson 3 — Complaint letters — tone under pressure

Sub lesson 3 questions from the type files. Pass mark: hold the
formal register through anger — spot mixed-style faults
and rewrite them — and judge a pair whole.
