# Advertisements and posters — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — short persuasive copy — set by the pattern across
the countries' books: the shape first, then the working parts,
then the whole piece judged as a reader meets it. The levels
inside this lesson are RANKS: pass a rank to wear it.

## Level 1 — the advert's anatomy
Level 1 questions from the type files. Pass mark: lay an advertisement's parts — claim, benefits, call to action — and name its selling points for a named target market.

## Level 2 — methods and media
Level 2 questions from the type files. Pass mark: choose among advertising methods by audience, and build a poster/flyer with headline, benefits and contact that passes the three-step test.

## Level 3 — honest persuasion
Level 3 questions from the type files. Pass mark: write persuasive copy that sells hard and lies never — claim checked, benefits real, call to action single and clear.
