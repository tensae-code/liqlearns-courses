# Advertisements and posters — Ordering

Stand the items in their true order.

**1. (Level 2)** Order Egypt's poster process: check / plan / draft / improve. **Answer: plan — draft — improve — check** — the model's own build order, pp.62–63.

**2. (Level 3)** Order the advert's writing decisions: write the call to action / choose the target market / check the claim is true / list the benefits. **Answer: choose the target market — check the claim is true — list the benefits — write the call to action** — audience first, honesty before ink, call last and loudest.
