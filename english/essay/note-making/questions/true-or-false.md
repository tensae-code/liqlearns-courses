# Note-making — true or false

Say true or false, in the strict format.

**1. (Level 1)** Notes may keep articles, prepositions
and conjunctions wherever they occur. **Answer: False**
— India's rules omit them; the note keeps the load, not
the scaffolding.

**2. (Level 2)** An abbreviation in notes may be spelled
any way the writer likes. **Answer: False** — the
standard set (ASAP, N.B., V.I.P., RSVP, c/o, e.g.) are
fixed signs, capitals and stops included.

**3. (Level 3)** Notes that only the writer can read,
and only today, still pass. **Answer: False** — India's
standing law: notes must make sense when re-read.
