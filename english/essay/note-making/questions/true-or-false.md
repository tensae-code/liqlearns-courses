# Note-making — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Cutting to Note Form · (Level 2) -> Sub lesson 2 — The Note-Making System · (Level 3) -> Sub lesson 3 — Sub-Titling.

Say true or false, in the strict format.

**1. (Sub lesson 1)** Notes may keep articles, prepositions
and conjunctions wherever they occur. **Answer: False**
— India's rules omit them; the note keeps the load, not
the scaffolding.

**2. (Sub lesson 2)** An abbreviation in notes may be spelled
any way the writer likes. **Answer: False** — the
standard set (ASAP, N.B., V.I.P., RSVP, c/o, e.g.) are
fixed signs, capitals and stops included.

**3. (Sub lesson 3)** Notes that only the writer can read,
and only today, still pass. **Answer: False** — India's
standing law: notes must make sense when re-read.
