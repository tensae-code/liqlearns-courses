# Note-making — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the note form — set by the
pattern across the countries' books: the cutting first,
then the system, then the sub-titles.

## Level 1 — the cutting
Level 1 questions from the type files. Pass mark: cut any
sentence to note form — phrases not sentences, no full
verbs, articles, prepositions and conjunctions omitted —
following India's steps: underline, question the text,
points, then number and group.

## Level 2 — the system
Level 2 questions from the type files. Pass mark: number
a set of notes in either system (1 / (i) / (a), or the
decimal 1.1.1) and use the standard abbreviations —
ASAP, N.B., V.I.P., RSVP, c/o, e.g. — correctly, in notes
that still pass the re-read test.

## Level 3 — sub-titling
Level 3 questions from the type files. Pass mark: divide
a long text into sections and head each with a sub-title
that states its main idea at a glance, India's W3 way —
and judge notes whole, as South Africa's main-idea and
note-taking work demands.
