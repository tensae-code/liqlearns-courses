# Note-making — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — the
note form — set by the pattern across the countries' books: the
cutting first, then the system, then the sub-titles.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old
Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Cutting to Note Form
Sub lesson 1 questions from the type files. Pass mark: cut any
sentence to note form — phrases not sentences, no full verbs,
articles, prepositions and conjunctions omitted — following India's
steps: underline, question the text, points, then number and group.

## Sub lesson 2 — The Note-Making System
Sub lesson 2 questions from the type files. Pass mark: number a set
of notes in either system (1 / (i) / (a), or the decimal 1.1.1) and
use the standard abbreviations — ASAP, N.B., V.I.P., RSVP, c/o, e.g.
— correctly, in notes that still pass the re-read test.

## Sub lesson 3 — Sub-Titling
Sub lesson 3 questions from the type files. Pass mark: divide a long
text into sections and head each with a sub-title that states its
main idea at a glance, India's W3 way — and judge notes whole, as
South Africa's main-idea and note-taking work demands.
