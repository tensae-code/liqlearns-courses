# Speech writing — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the speech — set by the pattern
across the countries' books: the shape first, then the
for/against build, then the rhetoric judged live.

## Level 1 — the shape
Level 1 questions from the type files. Pass mark: lay the
speech in its three parts (Ghana's rule), open with a
vocative address to the real audience, and close with a
line that returns to the opening promise.

## Level 2 — ordered points and the for/against speech
Level 2 questions from the type files. Pass mark: order
two or three points so a listener hearing them once can
follow, and build a for/against speech that gives the
other side fairly before answering it.

## Level 3 — rhetoric
Level 3 questions from the type files. Pass mark: use and
name the devices — tripling / rule of three, repetition,
parallel structure, emotive words, inclusive "we" — and
sort any appeal as ethos, logos or pathos, Greece's table
in hand.
