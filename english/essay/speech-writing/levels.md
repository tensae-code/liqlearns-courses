# Speech writing — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — the
speech — set by the pattern across the countries' books: the shape
first, then the for/against build, then the rhetoric judged live.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old
Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Speech in Three Parts
Sub lesson 1 questions from the type files. Pass mark: lay the
speech in its three parts (Ghana's rule), open with a vocative
address to the real audience, and close with a line that returns to
the opening promise.

## Sub lesson 2 — Ordered Points and the For/Against Speech
Sub lesson 2 questions from the type files. Pass mark: order two or
three points so a listener hearing them once can follow, and build a
for/against speech that gives the other side fairly before answering
it.

## Sub lesson 3 — Speech Rhetoric
Sub lesson 3 questions from the type files. Pass mark: use and name
the devices — tripling / rule of three, repetition, parallel
structure, emotive words, inclusive "we" — and sort any appeal as
ethos, logos or pathos, Greece's table in hand.
