# Article writing — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the article — set by the pattern across
the countries' books: the shape first, then the working parts,
then the whole piece judged as a reader meets it. The levels
inside this lesson are RANKS: pass a rank to wear it.

## Level 1 — the shape
Level 1 questions from the type files. Pass mark: lay an article's parts — headline, hook, ordered body, closing — and a fact file's headed sections, each with its job.

## Level 2 — the hook
Level 2 questions from the type files. Pass mark: open with a rhetorical question or a surprising true sentence, in a direct tone that wins a stranger's attention (Malaysia, Form 5).

## Level 3 — the whole piece
Level 3 questions from the type files. Pass mark: write an article a stranger finishes — points ordered, tone alive, closing line landing — and a fact file a reader can search.
