# True or False — The Goodwill Speech

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. A goodwill speech is measured by the warmth it leaves behind. (Sub lesson 1) — True
2. Flattery and specific appreciation are the same thing. (Sub lesson 2) — False
3. The speaker should learn the audience's names and customs beforehand. (Sub lesson 2) — True
4. A goodwill speech may run as long as it likes — length builds goodwill. (Sub lesson 2) — False
5. Nothing is attacked or demanded in a goodwill speech. (Sub lesson 1) — True
