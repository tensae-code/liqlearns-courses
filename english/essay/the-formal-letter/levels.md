# The formal letter — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the formal letter's frame — set by
the pattern across the countries' books: the layout first, then
the greeting–closing pairs, then the register held whole.

## Level 1 — the layout
Level 1 questions from the type files. Pass mark: name every
part of the formal letter in its order on the page, from the
sender's address to the signature.

## Level 2 — the pairs and the parts' jobs
Level 2 questions from the type files. Pass mark: pair every
salutation with its true closing, place the subject line, and
say what the opening and closing paragraphs each do.

## Level 3 — the register held whole
Level 3 questions from the type files. Pass mark: rewrite a
chatty draft into formal register without losing a fact, and
spot every informality planted in a letter.
