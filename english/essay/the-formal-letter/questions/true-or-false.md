# The formal letter — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — The formal letter — the layout · (Level 2) -> Sub lesson 2 — The formal letter — the pairs and the parts' jobs · (Level 3) -> Sub lesson 3 — The formal letter — the register held whole.

Say true or false, in the strict format.

**1. (Sub lesson 1)** The date stands below the receiver's
address in a formal letter. **Answer: False** — in the
books' anatomy the date sits with the sender's side,
above the receiver's address.

**2. (Sub lesson 2)** A subject line is required in every
formal letter. **Answer: False** — Greece lists it as
optional; the greeting and close are not optional.

**3. (Sub lesson 3)** Contractions like "I'm" and "can't"
belong in a formal letter. **Answer: False** — the formal
register writes full forms; contractions are the informal
dress.
