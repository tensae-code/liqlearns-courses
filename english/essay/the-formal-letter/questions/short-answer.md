# The formal letter — short answer

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — The formal letter — the layout · (Level 2) -> Sub lesson 2 — The formal letter — the pairs and the parts' jobs · (Level 3) -> Sub lesson 3 — The formal letter — the register held whole.

Answer in a word or a short line.

**1. (Sub lesson 1)** List the formal letter's parts in page
order. **Answer: sender's address — date — receiver's
address — greeting — (subject line) — opening — body —
complimentary close — signature** — Greece's anatomy,
top to bottom.

**2. (Sub lesson 2)** Your letter greets "Dear Sir or Madam"
but closes "Yours sincerely". What is wrong?
**Answer: the pair disagrees** — an unnamed greeting
takes Yours faithfully; sincerely needs a named greeting.

**3. (Sub lesson 3)** Rewrite formally: "I want the form, send
it fast." **Answer: I would like to request the form;
I would be grateful if you could send it soon** — any
version with the formal partners and no demand earns it.
