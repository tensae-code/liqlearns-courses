# Lesson plan — The formal letter

**Course:** English · **Title:** Essay · **Lesson:** The formal letter
**Place in the curriculum:** Unit 34 — "Letters That Work" —
the first lesson of the level.
**The one thing this lesson teaches:** the formal letter as a
built object — where every part sits on the page, which
salutation pairs with which closing, and the formal register
that holds the whole letter at arm's length and polite.
**This lesson's own level:** it stands on The paragraph (each
body paragraph still serves one point) and opens the letter
family: application, complaint and enquiry letters all wear
this same frame.
**What the learner can do at the end:** lay out a formal
letter from memory; pair Dear Sir/Madam with Yours faithfully
and a named Dear Mr … with Yours sincerely; and keep the
register formal from first line to last.

## Sub lessons
The parts of this lesson, in order — the list the learner sees
from the start, locked ahead, each opening when the one before
it is proved (the gate: README, "Units, Lessons and Sub Lessons
(ruled 2026-11-08)"):

1. **The formal letter — the layout** — every part of the formal
   letter in its seat on the page, from the sender's address to the
   signature. (Was depth Level 1.)

2. **The formal letter — the pairs and the parts' jobs** — each
   salutation paired with its true closing, the subject line placed,
   and what the opening and closing paragraphs each do. (Was depth
   Level 2.)

3. **The formal letter — the register held whole** — a chatty draft
   rewritten into formal register without losing a fact, and every
   planted informality spotted. (Was depth Level 3.)

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: The paragraph; The essay. Recommended,
  never forced.
- Informal letters to friends are a different dress — this
  lesson is the formal frame only.

## Media slots
1. **Slot 1 — a picture of a blank page slowly filling with
   labelled blocks: addresses, date, greeting, body,
   closing, signature.** What the student does: the student
   names each block as it lands, before reading on.
2. **Slot 2 — a picture of two envelopes side by side, one
   addressed to a named person, one to an office.** What the
   student does: the student chooses the greeting and the
   closing for each envelope aloud.

## The run of the lesson, in order
1. **Do it first**: two openings of the same request — one
   chatty, one formal — ranked by feel.
2. **The layout**: the parts in their seats, top to bottom
   (Greece's anatomy; Laos's labelled diagram).
3. **The pairs**: salutation and closing matched.
4. **The register**: formal words for informal ones
   (Uzbekistan's style pairs).
5. **A model read whole**: Sudan's formal letter work —
   a formal letter beside an informal one.
6. **Do it yourself**: lay out and write a short formal
   letter from the frame in hands-on.md.

## If the learner is stuck
- Parts wandering: rebuild the page as stacked blocks,
  one block per line of the layout list, then fill them.
- Closings mismatched: chant the pair rule — a name takes
  sincerely; no name takes faithfully.
- Register slipping: swap each chatty word for its formal
  partner from the lesson's pairs list.
- Next in this level: Job application letters — this frame,
  aimed at one job.
