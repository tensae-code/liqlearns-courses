# Play scripts — true or false

Say true or false, in the strict format.

**1. (Level 1)** Stage directions are read aloud by one
of the actors during the play. **Answer: False** — they
are bracketed instructions to the bodies; the audience
sees them done, never hears them said.

**2. (Level 2)** A script may drop a story sentence if
it is only narration. **Answer: False** — every sentence
lands as dialogue, direction or setting; narration
dropped is meaning dropped.

**3. (Level 3)** A script line is finished when it looks
right on the page. **Answer: False** — Barbados's test
is the mouth: the dialogue must be speakable Standard
English, so read every line aloud.
