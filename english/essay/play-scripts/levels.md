# Play scripts — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the script's form — set by
the pattern across the countries' books: the layout first,
then the directions, then the conversion judged whole.

## Level 1 — the layout
Level 1 questions from the type files. Pass mark: lay out
any dialogue as a script — names at the left, a colon, a
new line for each speaker, directions in brackets.

## Level 2 — stage directions
Level 2 questions from the type files. Pass mark: write
directions an actor can obey — entrances, movements,
feelings shown by the body — and keep them out of the
spoken lines.

## Level 3 — the conversion
Level 3 questions from the type files. Pass mark: turn a
story scene into a script losing nothing — narration
becomes direction or dialogue, every meaning rehoused —
and sketch the scenario before the lines, Ghana's order.
