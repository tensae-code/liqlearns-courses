# Play scripts — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — the
script's form — set by the pattern across the countries' books: the
layout first, then the directions, then the conversion judged whole.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old
Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Play Script Layout
Sub lesson 1 questions from the type files. Pass mark: lay out any
dialogue as a script — names at the left, a colon, a new line for
each speaker, directions in brackets.

## Sub lesson 2 — Stage Directions
Sub lesson 2 questions from the type files. Pass mark: write
directions an actor can obey — entrances, movements, feelings shown
by the body — and keep them out of the spoken lines.

## Sub lesson 3 — Turning a Story into a Script
Sub lesson 3 questions from the type files. Pass mark: turn a story
scene into a script losing nothing — narration becomes direction or
dialogue, every meaning rehoused — and sketch the scenario before
the lines, Ghana's order.
