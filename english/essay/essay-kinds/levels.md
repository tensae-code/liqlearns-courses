# Essay kinds — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the map of kinds — set by
the pattern across the countries' books: the map first,
then the shared skills, then the counter-argument judged.

## Level 1 — the map
Level 1 questions from the type files. Pass mark: name
each kind by its job and sort any set task to its kind —
argue, opine, persuade, describe, explain, compare,
trace causes, solve, or weigh both sides.

## Level 2 — introductions and conclusions
Level 2 questions from the type files. Pass mark: write
an introduction that states the position without copying
the task, and a conclusion that summarises and closes
with a comment — Malaysia F5's two skills — inside any
kind on the map.

## Level 3 — the counter-argument
Level 3 questions from the type files. Pass mark: plant
the strongest other side fairly (the discussion text's
against-arguments), answer it, and hold India's four
checks — Unity, Coherence, Relevance, Proportion —
across the whole piece.
