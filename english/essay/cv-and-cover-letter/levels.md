# CV and cover letter — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the CV and its letter — set by
the pattern across the countries' books: the sections first,
then the order inside them, then the pair matched to one advert.

## Level 1 — the sections
Level 1 questions from the type files. Pass mark: name the
CV's sections (Syria's nine steps; Egypt's six sections)
and say what each carries.

## Level 2 — the order inside
Level 2 questions from the type files. Pass mark: run
education and experience newest-first, keep the CV to
1–2 pages of relevant fact, and complete a CV category
sort without a miss.

## Level 3 — the pair, matched
Level 3 questions from the type files. Pass mark: write
CV and cover letter to one advert as one act — every
letter claim traceable to a CV line, every CV line
relevant to the advert.
