# Job application letters — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the application letter — set by
the pattern across the countries' books: the order first, then
the match to the advert, then the letter judged whole.

## Level 1 — the paragraph order
Level 1 questions from the type files. Pass mark: state the
five moves in order and name what each paragraph carries.

## Level 2 — matched to the advert
Level 2 questions from the type files. Pass mark: answer an
advert's named asks inside the letter — qualification,
experience, quality — each in its true paragraph.

## Level 3 — the letter judged whole
Level 3 questions from the type files. Pass mark: repair a
generic letter into a matched one, and keep layout, pair
rule and register formal throughout.
