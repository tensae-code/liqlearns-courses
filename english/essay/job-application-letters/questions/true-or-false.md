# Job application letters — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Job application letters — the paragraph order · (Level 2) -> Sub lesson 2 — Job application letters — matched to the advert · (Level 3) -> Sub lesson 3 — Job application letters — the letter judged whole.

Say true or false, in the strict format.

**1. (Sub lesson 1)** The application letter replaces the CV.
**Answer: False** — it points at the CV ("I enclose…");
the CV carries the full record, in its own lesson.

**2. (Sub lesson 2)** One strong generic letter, sent to every
employer, is good practice. **Answer: False** — India's
chain and Egypt's law agree: the letter is written to
ONE advert.

**3. (Sub lesson 3)** An application form and an application
letter are the same skill. **Answer: False** — Laos
keeps them in different lessons: forms are filled in
boxes; letters are written in paragraphs.
