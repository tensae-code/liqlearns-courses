# Short Answer — The Eulogy

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. Why does a eulogy use memories instead of claims? (Sub lesson 1)
   — A claim ('she was kind') asks to be believed; a memory shows the kindness happening, so the listeners remember the person themselves — praise lands as truth, not as words.

2. Name the three works a eulogy does. (Sub lesson 1)
   — Remember the life and character; thank for what the person gave; say farewell so listeners can grieve together and begin to let go.

3. Give two delivery rules for a eulogy and the reason for each. (Sub lesson 2)
   — E.g. speak slower than ordinary speech with pauses — feeling needs time to land; keep the body steady and still — the speaker's calm helps hold the listeners.

4. Is a voice that shakes a failure in a eulogy? (Sub lesson 2)
   — No — the book allows an honest shaken voice; what fails is a performing voice that makes the occasion about the speaker.
