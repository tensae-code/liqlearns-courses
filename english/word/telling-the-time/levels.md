# Telling the time — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — saying the time — o'clock first, then the day in times, then the minutes.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — O'Clock Times
Sub lesson 1 questions from the type files. Pass mark: name the two
hands, ask "What's the time?", and say any o'clock time whole
without a miss.

## Sub lesson 2 — The Day in Times
Sub lesson 2 questions from the type files. Pass mark: split a.m.
from p.m. by the book's rule, place midday and midnight right,
and tell a day's routine in at-times (Mita-style).

## Sub lesson 3 — Minutes, Past and To
Sub lesson 3 questions from the type files. Pass mark: count minutes
by fives, and say half past, quarter past, ten past, and quarter
to times for any clock shown, the way Mongolia's book drills
them.
