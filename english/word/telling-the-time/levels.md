# Telling the time — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — saying the time — set by the
pattern across the countries' books: o'clock first, then the
day's halves, then the minutes.

## Level 1 — o'clock
Level 1 questions from the type files. Pass mark: name the two
hands, ask "What's the time?", and say any o'clock time whole
without a miss.

## Level 2 — the day in times
Level 2 questions from the type files. Pass mark: split a.m.
from p.m. by the book's rule, place midday and midnight right,
and tell a day's routine in at-times (Mita-style).

## Level 3 — minutes, past and to
Level 3 questions from the type files. Pass mark: count minutes
by fives, and say half past, quarter past, ten past, and quarter
to times for any clock shown, the way Mongolia's book drills
them.
