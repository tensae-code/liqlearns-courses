# True or False — Abbreviations

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. An abbreviation is a shortened form of a word or name. (Sub lesson 1) — True
2. "Dr." stands for "Door". (Sub lesson 1) — False
3. "St." can stand for two different full forms. (Sub lesson 1) — True
4. When reading aloud, you say the letters of the short form, not the full form. (Sub lesson 2) — False
5. Writing a word in full means writing every letter of it, nothing cut away. (Sub lesson 2) — True
6. In careful writing it is better to write the full form so the reader does not have to guess. (Sub lesson 2) — True
