# Weather and seasons — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** "What's the weather like today?" — "It's
cloudy and windy" is a right answer in Cambodia's book.
**True** — the book's own drilled pair (Grade 5, p.115).

**2. (Level 1)** Winter is a weather word like rainy.
**False** — winter is a season; rainy is weather. The
seasons are spring, summer, autumn/fall, winter.

**3. (Level 2)** In Bolivia's printed grid, summer runs
June–August.
**True** — as printed in Year 2, Topic 3 (the grid is
Bolivia's book's own; other places set the names on other
months).

**4. (Level 3)** For yesterday we ask "What IS the weather
like yesterday?"
**False** — yesterday takes WAS: "What was the weather
like yesterday?" (Rwanda P4, pp.49–50).

**5. (Level 3)** A typhoon is one of India's storm names.
**True** — cyclone, gale, typhoon, tornado, hurricane,
whirlwind (India, Class 10, Unit 1).
