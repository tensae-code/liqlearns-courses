# Weather and seasons — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — weather and seasons — set by the
pattern across the countries' books: today's weather first,
then the seasons, then yesterday and strong weather.

## Level 1 — today's weather
Level 1 questions from the type files. Pass mark: name the
weather words (sunny, cloudy, rainy, windy, snowy, hot,
cold) and answer "What's the weather like today?" in the
books' shape — "It's cloudy and windy."

## Level 2 — the four seasons
Level 2 questions from the type files. Pass mark: name
spring, summer, autumn/fall and winter, match each season
to its weather and its clothes, and compare two days —
"Today is colder than yesterday" (Albania).

## Level 3 — yesterday and strong weather
Level 3 questions from the type files. Pass mark: answer
"What was the weather like yesterday?" with *it was*, and
name the strong-weather set — flood, lightning, thunder,
storm, cyclone, hurricane, typhoon, tornado, heat wave,
drought, wildfire — with what each one does.
