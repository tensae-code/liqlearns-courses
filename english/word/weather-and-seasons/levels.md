# Weather and seasons — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
weather and seasons — today's weather first, then the seasons,
then yesterday and strong weather, the order the books teach it
in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Today's Weather
Sub lesson 1 questions from the type files. Pass mark: name the
weather words (sunny, cloudy, rainy, windy, snowy, hot,
cold) and answer "What's the weather like today?" in the
books' shape — "It's cloudy and windy."

## Sub lesson 2 — The Four Seasons
Sub lesson 2 questions from the type files. Pass mark: name
spring, summer, autumn/fall and winter, match each season
to its weather and its clothes, and compare two days —
"Today is colder than yesterday" (Albania).

## Sub lesson 3 — Yesterday and Strong Weather
Sub lesson 3 questions from the type files. Pass mark: answer
"What was the weather like yesterday?" with *it was*, and
name the strong-weather set — flood, lightning, thunder,
storm, cyclone, hurricane, typhoon, tornado, heat wave,
drought, wildfire — with what each one does.
