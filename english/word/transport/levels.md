# Transport — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the transport words — set by the
pattern across the countries' books: the street five first, then
the full set sorted, then travelling with them.

## Level 1 — the street five
Level 1 questions from the type files. Pass mark: name
car, bus, bike, van and taxi on sight, and count them in
Palestine's pattern — "How many taxis? Five taxis."

## Level 2 — the full set, sorted
Level 2 questions from the type files. Pass mark: name
train, plane, helicopter, lorry, motorcycle, ambulance,
boat, ferry and horse, and sort the whole set by land,
water and air without a miss (Rwanda's and Mongolia's
sorts).

## Level 3 — travelling
Level 3 questions from the type files. Pass mark: answer
how people travel — "travel by…" for every vehicle and
"travel on foot" for walking — and use the books' own
comparisons (a plane is faster than a train; bus against
moto on time and price).
