# Transport — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — the
transport words — the street five first, then the full set sorted,
then travelling with them, the order the books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — The Street Five
Sub lesson 1 questions from the type files. Pass mark: name
car, bus, bike, van and taxi on sight, and count them in
Palestine's pattern — "How many taxis? Five taxis."

## Sub lesson 2 — The Full Set, Sorted
Sub lesson 2 questions from the type files. Pass mark: name
train, plane, helicopter, lorry, motorcycle, ambulance,
boat, ferry and horse, and sort the whole set by land,
water and air without a miss (Rwanda's and Mongolia's
sorts).

## Sub lesson 3 — Travelling
Sub lesson 3 questions from the type files. Pass mark: answer
how people travel — "travel by…" for every vehicle and
"travel on foot" for walking — and use the books' own
comparisons (a plane is faster than a train; bus against
moto on time and price).
