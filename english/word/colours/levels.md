# Colours — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — the
colour words — the first colours first, then the rainbow set, then
mixing and describing with colours, the order the books teach it
in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — The First Six Colours
Sub lesson 1 questions from the type files. Pass mark: name red,
green, white, blue, black and yellow on sight, and answer
"What colour?" with the colour's name without a miss.

## Sub lesson 2 — The Rainbow Seven and Colours on Things
Sub lesson 2 questions from the type files. Pass mark: name the
rainbow set in order (red, orange, yellow, green, blue,
indigo, violet) and say a colour with its thing — "a blue
car," "a yellow taxi," "blue jeans" — the way the books do.

## Sub lesson 3 — Mixing Colours
Sub lesson 3 questions from the type files. Pass mark: use
Mongolia's mixing chart (red + yellow = orange and its
partners), name the three primary colours (red, yellow,
blue), and describe real things around you by colour in
whole answers.
