# Colours — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the colour words — set by the
pattern across the countries' books: the first colours first,
then the rainbow set, then mixing and describing with colours.

## Level 1 — the first six colours
Level 1 questions from the type files. Pass mark: name red,
green, white, blue, black and yellow on sight, and answer
"What colour?" with the colour's name without a miss.

## Level 2 — the rainbow seven and colour + thing
Level 2 questions from the type files. Pass mark: name the
rainbow set in order (red, orange, yellow, green, blue,
indigo, violet) and say a colour with its thing — "a blue
car," "a yellow taxi," "blue jeans" — the way the books do.

## Level 3 — mixing and describing
Level 3 questions from the type files. Pass mark: use
Mongolia's mixing chart (red + yellow = orange and its
partners), name the three primary colours (red, yellow,
blue), and describe real things around you by colour in
whole answers.
