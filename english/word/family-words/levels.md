# Family words — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — the
kinship words — your own row first, then the whole tree, then the
married-in words, the order the books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Your Own Row and Your Parents
Sub lesson 1 questions from the type files. Pass mark: name
father, mother, brother, sister, baby and me, and answer
"Who's this?" — "This is my…" — without a miss (Palestine).

## Sub lesson 2 — The Whole Tree
Sub lesson 2 questions from the type files. Pass mark: name
grandfather, grandmother, uncle, aunt and cousin in their
tree places, in both registers — father and daddy, mother
and mummy — the way North Macedonia teaches them side by

## Sub lesson 3 — The Wide Tree
Sub lesson 3 questions from the type files. Pass mark: place
nephew, niece, mother-in-law, father-in-law,
daughter-in-law and great grandfather on the tree, and
