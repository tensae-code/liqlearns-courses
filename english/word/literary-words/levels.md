Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
RANKS inside this one lesson — pass each rank to climb.

Level 1 questions from the type files. Pass mark: name Egypt's five kinds and place real works on the right shelves without a miss

## Level 2 — the figures
Level 2 questions from the type files. Pass mark: spot and name simile, metaphor and personification in unseen lines, using the like/as test

Level 3 questions from the type files. Pass mark: talk about a real story or poem for a full minute using plot, setting, character, theme, genre and at least two figure names correctly
