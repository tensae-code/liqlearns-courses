# True or false — Figurative Language

1. A simile openly uses a comparing word such as "like", "as" or "than". (Sub lesson 1) — True
2. A metaphor must contain the word "like". (Sub lesson 1) — False
3. Personification gives human qualities to things that are not human. (Sub lesson 2) — True
4. Alliteration repeats the same opening sound across nearby words. (Sub lesson 2) — True
