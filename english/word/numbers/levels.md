# Numbers — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — counting — set by the pattern
across the countries' books: 1–10 first, then 11–20 with the
counting question, then the tens to 100.

## Level 1 — one to ten
Level 1 questions from the type files. Pass mark: count 1–10 in
figures and words, match a count of things to its number, and
answer "How many … are there?" for counts up to 10.

## Level 2 — eleven to twenty
Level 2 questions from the type files. Pass mark: run the -teen
line whole (eleven and twelve as themselves), and answer
How-many for counts to 20, in Egypt's whole shape.

## Level 3 — the tens to a hundred
Level 3 questions from the type files. Pass mark: count by tens
to 100 forward and back, split thirteen from thirty by ear every
time, and build joined counts (twenty-one…) for dates and
prices.
