# Numbers — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — counting — 1–10 first, then 11–20 with the counting question, then the tens to 100.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Numbers 1 to 10
Sub lesson 1 questions from the type files. Pass mark: count 1–10 in
figures and words, match a count of things to its number, and
answer "How many … are there?" for counts up to 10.

## Sub lesson 2 — Numbers 11 to 20
Sub lesson 2 questions from the type files. Pass mark: run the -teen
line whole (eleven and twelve as themselves), and answer
How-many for counts to 20, in Egypt's whole shape.

## Sub lesson 3 — Numbers by Tens to 100
Sub lesson 3 questions from the type files. Pass mark: count by tens
to 100 forward and back, split thirteen from thirty by ear every
time, and build joined counts (twenty-one…) for dates and
prices.
