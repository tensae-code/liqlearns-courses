# Numbers — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — counting — 1–10 first, then 11–20 with the counting question, then the tens to 100, then the hundreds and thousands to a million, and the ordinals to one hundredth: the whole climb the books teach (whole-arc rule, ruled 2026-11-08).

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3. Sub
lessons 4 and 5 were added 2026-11-08 under the whole-arc
rule, from the lesson's own stocked sources: the old text
stopped at 100 while the sources stock the climb to a
million and the ordinals 1st–100th.

Pass marks: Sub lessons 1–3 carry the old layers' pass marks.
The books state no separate pass mark for the big-number and
ordinal bands, so Sub lessons 4 and 5 keep the same
observable form — the learner can run the band and use it —
rather than an invented mark.

## Sub lesson 1 — Numbers 1 to 10
Sub lesson 1 questions from the type files. Pass mark: count 1–10 in
figures and words, match a count of things to its number, and
answer "How many … are there?" for counts up to 10.

## Sub lesson 2 — Numbers 11 to 20
Sub lesson 2 questions from the type files. Pass mark: run the -teen
line whole (eleven and twelve as themselves), and answer
How-many for counts to 20, in Egypt's whole shape.

## Sub lesson 3 — Numbers by Tens to 100
Sub lesson 3 questions from the type files. Pass mark: count by tens
to 100 forward and back, split thirteen from thirty by ear every
time, and build joined counts (twenty-one…) for dates and
prices.

## Sub lesson 4 — Numbers Past 100: Hundreds, Thousands, a Million
Sub lesson 4 questions from the type files. Pass mark: read and
write three-figure numbers in words with "and" (five hundred
and fourteen), run Jordan's big-number set to a million, and
read a big number whole in its groups (13,617).

## Sub lesson 5 — Ordinal Numbers: First to One Hundredth
Sub lesson 5 questions from the type files. Pass mark: say the
ordinals to thirty-first for dates, name the shape-changers
(fifth, eighth, ninth, twelfth, twentieth) without prompting,
and run the whole list's ends — first to one hundredth.
