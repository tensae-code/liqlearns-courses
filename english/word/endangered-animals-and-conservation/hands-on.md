# Hands-On — Endangered Animals and Conservation

1. **Jigsaw reading.** Teams each read one section about an animal (home, dangers, helpers) and teach the class.
2. **Poster gallery.** Present posters; visitors ask one question each using the lesson's words.
3. **Fact-sheet swap.** Exchange fact sheets and check: are all four parts there?
4. **Conservation debate.** Poachers, farmers and conservationists argue over one forest — kindly, in role.
