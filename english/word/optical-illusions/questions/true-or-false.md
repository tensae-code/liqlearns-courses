# True or False — Optical Illusions

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. An optical illusion is a picture that tricks your eyes. (Sub lesson 1) — True
2. The Duck or Rabbit can only ever be a duck. (Sub lesson 1) — False
3. The young-or-old woman is one picture that can be seen two ways. (Sub lesson 1) — True
4. The Rotating Snakes really move on the page. (Sub lesson 2) — False
5. In White's illusion, the same grey can look light in one place and dark in another. (Sub lesson 2) — True
6. A ruler shows the two tables in the Table illusion are different sizes. (Sub lesson 2) — False
