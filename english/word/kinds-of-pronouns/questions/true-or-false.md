# True or False — Kinds of Pronouns

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. Demonstrative pronouns point — near (this, these) or far (that, those). (Sub lesson 1) — True
2. In 'what happened?', 'what' is a relative pronoun. (Sub lesson 1) — False
3. Indefinite pronouns name exactly which person is meant. (Sub lesson 2) — False
4. A relative pronoun joins a describing clause to its noun. (Sub lesson 2) — True
5. In 'many children came', 'many' is an adjective; in 'many came', it is a pronoun. (Sub lesson 2) — True
