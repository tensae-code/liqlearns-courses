# Hands-On — Pronoun Case

Things you do with real books, real texts and real talk.

1. **Table building.** Draw the three-case table for all seven persons (I, you, he, she, it, we, they) from memory, then check it against a grammar book. Mark the two forms that never change (you, it).
2. **Case hunt.** In one page of a story, circle every personal pronoun and label its case and its job. Count how many of each case the writer used.
3. **Trap fixing.** Write five sentences with a case trap in each (pairs, between, after prepositions). Swap with a partner and fix each other's, naming the rule every time.
