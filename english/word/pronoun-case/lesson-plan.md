# Lesson Plan — Pronoun Case

**Unit:** Unit 6 — Word Kinds

**One thing:** the three cases of the personal pronouns — subjective, objective and possessive — and choosing the correct case for the job a pronoun is doing in a sentence.

## Sub lessons

1. The three cases
2. Choosing the correct case

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Teaching points

- The three cases of the personal pronouns: subjective, objective, possessive, with the full case table (Lesson 1, Task 7, pp.287–289).
- Choosing the correct case in sentences is practised as its own skill (p.289).
- Book error E4: the printed table merges the subjective and possessive headers; the text names three cases — taught as three.
