# Lesson Plan — Events and Announcements

**Unit 7 — Words for the World.**

**One thing:** the words for the events a community announces — conference, book fair, festival, quiz, storm, discount, exhibition, tournament — and how an announcement names them.

## Sub lessons

1. **Words for events.** *Can-do: Name the events: conference, book fair, festival, quiz, exhibition, tournament — and the announcement words that travel with them: storm (an event in the news) and discount (an event in a shop).*
2. **Announcing an event.** *Can-do: Say that an event exists and when: There is a… / There will be… — the announcement shape the books use for festivals, fairs and tournaments.*

(The gate pool for each sub lesson is every question marked with that sub lesson's number in this lesson's `questions/` files — the whole set, because no hardness ranking is written in questions/.)

## Teaching points

- Event vocabulary (item 234): conference, book fair, festival, quiz, storm, discount, exhibition, tournament — taught inside the book's announcements and news unit, beside there + be in all time frames (introductory-there).
