# Hands-On — Events and Announcements

1. **Poster wall.** Each learner makes one event poster (fair, festival, tournament, exhibition) and reads its announcement aloud.
2. **Radio news.** In pairs: one is the radio voice announcing a storm, the other writes down what, where and when.
3. **Event bingo.** Cards with the eight event words; the caller describes an event, players cover its word.
4. **Tournament bracket.** Plan a class quiz tournament on paper and announce each round.
