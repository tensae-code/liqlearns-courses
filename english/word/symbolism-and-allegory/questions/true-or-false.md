# True or False — Symbolism and Allegory

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. A symbol's meaning is always its plain, literal self. (Sub lesson 1) — False
2. Gregor's insect form is a symbol, not just a strange event. (Sub lesson 1) — True
3. In an allegory, only the title carries a second meaning. (Sub lesson 2) — False
4. Animal Farm's pigs stand for rulers. (Sub lesson 2) — True
5. Connotation is the feeling a word carries beyond its plain meaning. (Sub lesson 2) — True
