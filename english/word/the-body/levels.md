# The body — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the words for the body — set by the
pattern across the countries' books: the touched seven first, then
the parts at work in the sense sentences, then the whole set
running free.

## Level 1 — the touched seven
Level 1 questions from the type files. Pass mark: touch and name
Palestine's seven — head, hand, finger, leg, face, nose, mouth —
without a miss or a look.

## Level 2 — parts at work
Level 2 questions from the type files. Pass mark: run the five
sense sentences whole — "I can see with my eyes" — and match
each sense thing (music, flower, moon, ice cream) to its part.

## Level 3 — the whole set
Level 3 questions from the type files. Pass mark: name the added
parts (hair, neck, elbow), count the pairs and singles right
(two eyes, one nose, ten fingers), and correct a swapped sense
sentence on sight.
