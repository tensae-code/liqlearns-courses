# Idioms and collocations — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
RANKS inside this one lesson — pass each rank to climb.

## Level 1 — the whole phrase
Level 1 questions from the type files. Pass mark: give the whole-phrase meaning of common idioms (raining cats and dogs, a piece of cake) without translating word by word

## Level 2 — the partnerships
Level 2 questions from the type files. Pass mark: sort make/do/have collocations and the play/ride/go/make set correctly, and explain a proverb in plain words

## Level 3 — using them
Level 3 questions from the type files. Pass mark: use idioms, a proverb and fresh collocations correctly in your own sentences and writing, as the handbooks' writing lessons demand
