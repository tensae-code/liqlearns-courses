# Ordering words — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — ordering past the first letter — the second letter first, then the third and fourth letters with the index, then the entry taken apart.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

Sub lesson 1 questions from the type files. Pass mark: order
word sets whose first letters tie by reading the SECOND
letter — Barbados's Class 1 step (alphabetising by 1st
and 2nd letter) — without a miss.

## Sub lesson 2 — Ordering Words to the Fourth Letter, and the Index

the order through the third letter (Class 2's step) and
the fourth (Class 3's step), and work an index the way

## Sub lesson 3 — The Dictionary Entry, Taken Apart
