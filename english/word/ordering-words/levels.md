# Ordering words — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — ordering past the first letter — set
by Barbados's own ladder: the second letter at Class 1, the third
at Class 2, the fourth at Class 3, with the index and the entry as
the order's two workplaces (India; Rwanda).

## Level 1 — the second letter decides
Level 1 questions from the type files. Pass mark: order
word sets whose first letters tie by reading the SECOND
letter — Barbados's Class 1 step (alphabetising by 1st
and 2nd letter) — without a miss.

## Level 2 — third and fourth letters; the index
Level 2 questions from the type files. Pass mark: hold
the order through the third letter (Class 2's step) and
the fourth (Class 3's step), and work an index the way
India's Class 9 book and Rwanda's Unit 3 teach it — the
same order, finding topics instead of words.

## Level 3 — the entry, taken apart
Level 3 questions from the type files. Pass mark: read
a whole entry on a real page — headword, meanings (all
of them: ghastly holds two on India's page), the words
that may follow — and use a dictionary's pronunciation
transcription, the way Rwanda's dictionary tasks set
it.
