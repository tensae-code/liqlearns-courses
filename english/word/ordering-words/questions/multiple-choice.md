# Ordering words — multiple choice

Pick the one right answer.

**1. (Level 1)** dark, deep, doctor — which stands FIRST, and why?
a) doctor — the longest word wins  b) deep — e comes first  c) dark — the second letters decide: a before e before o
**Answer: c) dark — the second letters decide: a before e before o** — the first letters tie (d); Barbados's Class 1 step is alphabetising by 1st and 2nd letter.

**2. (Level 1)** doctor, dog, door are tied at the second letter (o). The third letters are —
a) c, g, o — so doctor, dog, door  b) o, g, c — so door, dog, doctor  c) all the same
**Answer: a) c, g, o — so doctor, dog, door** — walk along the word until one letter differs; that letter is the judge.

**3. (Level 2)** On Barbados's ladder, alphabetising reaches the FOURTH letter at —
a) Class 1  b) Class 2  c) Class 3
**Answer: c) Class 3** — Scope and Sequence 3.5.1: 1st–2nd letter at Class 1, 3rd at Class 2, 4th at Class 3 (syllabus evidence).

**4. (Level 3)** On India's reproduced dictionary page, the word meaning the same as "ghastly" holds —
a) no meaning  b) exactly one meaning  c) two meanings, and the book asks for both
**Answer: c) two meanings, and the book asks for both** — Honeysuckle, Class 6, Unit 5: an entry is a small list, read whole.
