# Ordering words — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Ordering Words by the Second Letter · (Level 2) -> Sub lesson 2 — Ordering Words to the Fourth Letter, and the Index · (Level 3) -> Sub lesson 3 — The Dictionary Entry, Taken Apart · except item 1, which is settled at the third letter and is Sub lesson 2.
Say true or false. If it is false, say why.

**1. (Sub lesson 2)** "Door" comes before "doctor" in a dictionary, because it is shorter.
**Answer: False** — length never decides; the third letter does: c (doctor) before g (dog) before o (door).

**2. (Sub lesson 2)** An index is a different machine from a dictionary — different order, different rules.
**Answer: False** — the same deep letter order, ordering topics instead of words; India (Class 9) and Rwanda (P.5 Unit 3) teach the index as the same finding skill.

**3. (Sub lesson 3)** On India's dictionary page, your own meaning of "thank" is written first, and the dictionary's meaning is the check.
**Answer: True** — Honeysuckle, Class 6, Unit 5: "write your own meaning of thank, then the dictionary's."
