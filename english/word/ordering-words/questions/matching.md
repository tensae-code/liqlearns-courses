# Ordering words — matching

Match each item to its place or part, the way the books give them.

**1. (Level 1)** Match: Barbados Class 2's alphabetising step — a) the 2nd letter  b) the 3rd letter  c) the 4th letter
**Answer: b) the 3rd letter** — the ladder: 1st–2nd at Class 1, 3rd at Class 2, 4th at Class 3 (Scope and Sequence 3.5.1).

**2. (Level 2)** Match: India's Class 6 dictionary page — a) term  b) index skills  c) a reproduced dictionary page worked skill by skill (term, test, terrace, terrible…)
**Answer: c) a reproduced dictionary page worked skill by skill (term, test, terrace, terrible…)** — Honeysuckle, Class 6, Unit 5; the index lesson is India's Class 9 book.

**3. (Level 3)** Match: "a part of the school year" on India's page — a) test  b) terrace  c) term
**Answer: c) term** — and "test" is the page's word for an examination (Honeysuckle, Class 6, Unit 5).
