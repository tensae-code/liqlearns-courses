# Ordering words — matching

Sub-lesson markers (2026-11-08 restructure): every set's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Ordering Words by the Second Letter · (Level 2) -> Sub lesson 2 — Ordering Words to the Fourth Letter, and the Index · (Level 3) -> Sub lesson 3 — The Dictionary Entry, Taken Apart · except item 1, which asks Barbados's Class 2 step (the third letter) and is Sub lesson 2, and item 2, which asks India's reproduced dictionary page (the entry) and is Sub lesson 3.
Match each item to its place or part, the way the books give them.

**1. (Sub lesson 2)** Match: Barbados Class 2's alphabetising step — a) the 2nd letter  b) the 3rd letter  c) the 4th letter
**Answer: b) the 3rd letter** — the ladder: 1st–2nd at Class 1, 3rd at Class 2, 4th at Class 3 (Scope and Sequence 3.5.1).

**2. (Sub lesson 3)** Match: India's Class 6 dictionary page — a) term  b) index skills  c) a reproduced dictionary page worked skill by skill (term, test, terrace, terrible…)
**Answer: c) a reproduced dictionary page worked skill by skill (term, test, terrace, terrible…)** — Honeysuckle, Class 6, Unit 5; the index lesson is India's Class 9 book.

**3. (Sub lesson 3)** Match: "a part of the school year" on India's page — a) test  b) terrace  c) term
**Answer: c) term** — and "test" is the page's word for an examination (Honeysuckle, Class 6, Unit 5).
