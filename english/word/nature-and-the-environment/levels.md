# Nature and the environment — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the words for the natural world —
set by the pattern across the countries' books: the places first,
then the homes of animals, then problems and solutions.

## Level 1 — the nature places
Level 1 questions from the type files. Pass mark: name the
place set — forest, hill, mountain, lake, river, stream,
rock, sea, grass — and point each one out in a picture
without a miss.

## Level 2 — habitats
Level 2 questions from the type files. Pass mark: say where
animals live in whole sentences — "Bears can live in the
forest" — and name the homes: forest, mountains, lake, sea,
desert.

## Level 3 — problems and solutions
Level 3 questions from the type files. Pass mark: sort the
environment set into problems (pollution, climate change,
drought, flood, litter) and solutions (recycle, wind power,
renewable energy, organic farming), and say one sentence
with each side.
