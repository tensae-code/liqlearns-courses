# Nature and the environment — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — the
words for the natural world — the places first, then the homes of
animals, then problems and solutions, the order the books teach it
in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — The Nature Places
Sub lesson 1 questions from the type files. Pass mark: name the
place set — forest, hill, mountain, lake, river, stream,
rock, sea, grass — and point each one out in a picture
without a miss.

## Sub lesson 2 — Habitats
Sub lesson 2 questions from the type files. Pass mark: say where
animals live in whole sentences — "Bears can live in the
forest" — and name the homes: forest, mountains, lake, sea,
desert.

## Sub lesson 3 — Problems and Solutions
Sub lesson 3 questions from the type files. Pass mark: sort the
environment set into problems (pollution, climate change,
drought, flood, litter) and solutions (recycle, wind power,
renewable energy, organic farming), and say one sentence
with each side.
