# Nature and the environment — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the
sub lesson it belongs to. The files' old depth groups map onto the sub
lessons as: (Level 1) -> Sub lesson 1 — The Nature Places · (Level 2) -> Sub
lesson 2 — Habitats · (Level 3) -> Sub lesson 3 — Problems and Solutions.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** A stream is big, still water you cross in
a boat.
**False** — that is a lake (Albania: "We're crossing the
lake in a boat"). A stream is small, running water.

**2. (Sub lesson 2)** "Grass can grow in gardens, parks and
forests" is one of Albania's nature sentences.
**True** (Chapter 38, printed pp.48–49).

**3. (Sub lesson 3)** Litter is a solution word.
**False** — litter is rubbish on the ground: a problem word
in Mexico's set. Recycle is the solution.

**4. (Sub lesson 3)** Renewable energy never runs out.
**True** — Mexico's set (Project 18): power like wind
power, which the wind keeps making.
