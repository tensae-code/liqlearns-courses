# Nature and the environment — multiple choice

Sub-lesson markers (2026-11-08 restructure): every item's marker names the
sub lesson it belongs to. The files' old depth groups map onto the sub
lessons as: (Level 1) -> Sub lesson 1 — The Nature Places · (Level 2) -> Sub
lesson 2 — Habitats · (Level 3) -> Sub lesson 3 — Problems and Solutions.

Pick the one right answer.

**1. (Sub lesson 1)** Water that runs in a long line across the
land is a ______.
a) lake  b) river  c) rock
**Answer: b) river** — Albania's nature set (Chapter 38,
printed p.48).

**2. (Sub lesson 1)** The sun coming up in the morning is the
______.
a) sunset  b) moon  c) sunrise
**Answer: c) sunrise** (Albania, Chapter 38).

**3. (Sub lesson 2)** "Bears can live in the ______ and in the
mountains."
a) forest  b) sea  c) desert
**Answer: a) forest** — Albania's own habitat sentence
(printed pp.48–49).

**4. (Sub lesson 3)** Which is a PROBLEM in Mongolia's sorting?
a) wind power  b) air pollution  c) organic farming
**Answer: b) air pollution** — the Grade 8 "Saving the
Earth" sort (English VIII, Unit 8, p.106).

**5. (Sub lesson 3)** No rain for a very long time is a ______.
a) flood  b) drought  c) litter
**Answer: b) drought** — Mexico's environment set (Grade 7,
Project 18, p.162).
