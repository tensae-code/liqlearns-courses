# Lesson Plan — Clear Pronoun Reference

**Unit:** Unit 6 — Word Kinds

**One thing:** making every pronoun point at exactly one antecedent — spotting vague or ambiguous reference in sentences, and fixing it so a reader never has to guess who or what a pronoun means.

## Sub lessons

1. Spotting vague and ambiguous reference
2. Fixing faulty reference

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Teaching points

- Clear versus faulty pronoun reference: vague or ambiguous antecedents spotted in sentences (Lesson 3, Task 9, pp.328–329).
- The practice set works twenty items — the skill is trained, not just stated (p.328).
