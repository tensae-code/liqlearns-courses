# True or False — Clear Pronoun Reference

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. If the writer knows what the pronoun means, the reference is clear. (Sub lesson 1) — False
2. A pronoun pointing at a whole unnamed idea can be vague reference. (Sub lesson 1) — True
3. Direct speech is one way to kill ambiguity. (Sub lesson 2) — True
4. Fixing reference always means deleting the pronoun. (Sub lesson 2) — False
5. 'They say…' with no stated 'they' is vague reference. (Sub lesson 1) — True
