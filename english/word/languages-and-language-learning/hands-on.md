# Hands-on — Languages and Language Learning

1. **Thank you, world.** Learn to say “thank you” in five languages from the Grade 12 book's set, and write each one next to its language.
2. **Judge the strategies.** List three things you do to learn English. Beside each one, write which skill it trains — listening, speaking, reading or writing — and whether the book's learners would call it a good strategy.
