# True or False — Expanded Definitions of Words

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. A dictionary gloss and an expanded definition are the same thing. (Sub lesson 1) — False
2. Shades of Meaning places a word among its neighbours from weakest to strongest. (Sub lesson 1) — True
3. The sentence formula is: term + class + distinguishing characteristics. (Sub lesson 2) — True
4. A definition paragraph keeps the same core definition as the sentence formula. (Sub lesson 2) — True
5. The class in a definition is what makes the word different from its family. (Sub lesson 2) — False
