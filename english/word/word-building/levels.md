# Word building — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — how
words are built — the parts named first, then building with the
sets, then taking real words apart, the order the books teach it
in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — The Three Parts of a Word
Sub lesson 1 questions from the type files. Pass mark: name the
parts — prefix (front), root (middle, the meaning), suffix
(back) — and take unhappy, teacher and careless apart
without a miss.

## Sub lesson 2 — Building with the Sets
Sub lesson 2 questions from the type files. Pass mark: build
true words with Cambodia's prefixes (re-, un-, dis-, mis-,
pre-, under-) and suffixes (-ful, -ment, -ian, -or), and
South Africa's circled set (un-, re-, -ful, -less, -ness).

## Sub lesson 3 — Syllables and New Words
Sub lesson 3 questions from the type files. Pass mark: count the
syllables of a word by clapping (Nepal's work), split a
word into its beats, and guess a new built word's meaning
from its parts alone.
