# Word building — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — how words are built — set by the
pattern across the countries' books: the parts named first, then
building with the sets, then taking real words apart.

## Level 1 — the three parts
Level 1 questions from the type files. Pass mark: name the
parts — prefix (front), root (middle, the meaning), suffix
(back) — and take unhappy, teacher and careless apart
without a miss.

## Level 2 — building with the sets
Level 2 questions from the type files. Pass mark: build
true words with Cambodia's prefixes (re-, un-, dis-, mis-,
pre-, under-) and suffixes (-ful, -ment, -ian, -or), and
South Africa's circled set (un-, re-, -ful, -less, -ness).

## Level 3 — syllables and new words
Level 3 questions from the type files. Pass mark: count the
syllables of a word by clapping (Nepal's work), split a
word into its beats, and guess a new built word's meaning
from its parts alone.
