# Days and months — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — the calendar's words — the days first, then the months with their numbers, then the whole calendar machine.

old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 2 — The Twelve Months
Sub lesson 2 questions from the type files. Pass mark: say the twelve
