# Days and months — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the calendar's words — set by the
pattern across the countries' books: the days first, then the
months with their numbers, then the whole calendar machine.

## Level 1 — the seven days
Level 1 questions from the type files. Pass mark: say the seven
days in order, and answer after/before and "What day is it
today?" without stopping.

## Level 2 — the twelve months
Level 2 questions from the type files. Pass mark: say the twelve
months in order, each with its number word ("September is the
ninth month"), capitals right in writing.

## Level 3 — the calendar machine
Level 3 questions from the type files. Pass mark: run the
thirty-days rhyme, state any month's day-count from it, and
explain February's 28/29 and the leap year (365/366) whole.
