# Days and months — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — The Seven Days · (Level 2) -> Sub lesson 2 — The Twelve Months · (Level 3) -> Sub lesson 3 — The Calendar Machine.
Say true or false. If it is false, say why.

**1. (Sub lesson 1)** There are 7 days in a week.
**True** — Egypt's first exchange (p.6).

**2. (Sub lesson 1)** Every country prints the week starting on
the same day.
**False** — Egypt's list runs Saturday-first; Bangladesh's
calendar prints Sunday-first. The circle is the same; the
starting card is each country's own.

**3. (Sub lesson 2)** We write "january" with a small j.
**False** — month names (and day names) take a capital first
letter (Bangladesh's grammar focus, Class 3).

**4. (Sub lesson 2)** June is the sixth month of the year.
**True** — the sentence ladder: January first… June sixth.

**5. (Sub lesson 3)** February always has 28 days.
**False** — 28 days clear, and 29 in each leap year (the
rhyme, Class 4).

**6. (Sub lesson 3)** A leap year has 365 days.
**False** — 365 is the ordinary year; a leap year has 366
(Bangladesh, U31's written answers).
