# Days and months — ordering

Put each set in calendar order. (This question type exists
for this lesson because the calendar IS order.)

**1. (Level 1)** Wednesday · Saturday · Monday · Friday ·
Sunday
**Answer:** Saturday, Sunday, Monday, Wednesday, Friday —
Egypt's order (Primary 1 Term 2, p.6).

**2. (Level 1)** The full week, from any start: name the day
that MUST stand between Tuesday and Thursday.
**Answer:** Wednesday — the circle leaves no choice.

**3. (Level 2)** May · January · December · March · October
**Answer:** January, March, May, October, December.

**4. (Level 2)** The J-months in year order: July · January ·
June
**Answer:** January, June, July (Bangladesh Class 4's own
letter-play asks how many months begin with J — three).

**5. (Level 3)** Order by length of month, shortest first:
January · February (ordinary year) · April
**Answer:** February (28), April (30), January (31) — the
rhyme (Class 4, pp.62–63).

**6. (Level 3)** Unscramble and order, Bangladesh's game
(Class 4, p.61): brepestem · yarnjua · bedemcre
**Answer:** yarnjua = January (first), brepestem =
September (ninth), bedemcre = December (twelfth).
