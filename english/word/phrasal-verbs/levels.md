# Phrasal verbs — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — small verbs with their own
meanings — set by the pattern across the countries' books: the
meanings and their sets first (Vietnam's Grade 9, the themed
chapters), then the splitting grammar (Bolivia alone teaching it),
then the three-word chains (Vietnam's Grade 12).

## Level 1 — one meaning, in sets
Level 1 questions from the type files. Pass mark: give
the meaning of the common phrasal verbs from the filed
sets (friendship, environment, clothes, travel) and use
each one in a true sentence.

## Level 2 — the splitting grammar
Level 2 questions from the type files. Pass mark: tell
transitive from intransitive, split separable verbs
around noun objects both ways and around pronouns the
one right way, and keep non-separable phrases whole.

## Level 3 — three-word chains
Level 3 questions from the type files. Pass mark: use
the three-word phrasal verbs (look forward to, put up
with, keep up with, live up to, get on with, cut down
on, get through to) as single units with their objects
after the chain, and sort mixed phrasal verbs by every
rule of the lesson.
