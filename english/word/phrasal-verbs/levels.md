# Phrasal verbs — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS
(2026-11-08 restructure — README, "Units, Lessons and Sub Lessons").
Practice is tied to the skill number, as before. The questions live in
the type files; this file is the by-sub-lesson view. The sub lessons are
the depths inside this one thing — small verbs with their own meanings —
set by the pattern across the countries' books: the meanings and their
sets first (Vietnam's Grade 9, the themed chapters), then the splitting
grammar (Bolivia alone teaching it), then the three-word chains
(Vietnam's Grade 12).

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level
2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Phrasal verbs — one meaning, in sets

Sub lesson 1 questions from the type files. Pass mark: give
the meaning of the common phrasal verbs from the filed
sets (friendship, environment, clothes, travel) and use
each one in a true sentence.

## Sub lesson 2 — Phrasal verbs — the splitting grammar

Sub lesson 2 questions from the type files. Pass mark: tell
transitive from intransitive, split separable verbs
around noun objects both ways and around pronouns the
one right way, and keep non-separable phrases whole.

## Sub lesson 3 — Phrasal verbs — three-word chains

Sub lesson 3 questions from the type files. Pass mark: use
the three-word phrasal verbs (look forward to, put up
with, keep up with, live up to, get on with, cut down
on, get through to) as single units with their objects
after the chain, and sort mixed phrasal verbs by every
rule of the lesson.
