# Video script — Phrasal verbs

Super-simple voice. Read slow. The learner hears this
before or beside the written lesson.

---

Two small words. One new meaning.
"Look" is your eyes. "After" is behind.
"Look after" is care for. A new word, with a space.

These are phrasal verbs.
Verb plus a small word. A particle.
Learn the pair together. Never split the meaning.

They come in families.
Friends: hang out, count on, let down, run into.
Clothes: put on, take off, try on.
Travel: get on the bus. Get off. Set off. Come back.

Some take an object. Some do not.
"Wake up" — no object. Nothing to add.
"Pick up the pen" — an object. The pen.

And some can split.
"Pick up the pen." "Pick the pen up."
Both good. But a pronoun must go inside:
"Pick it up." Never "pick up it".
Others never split. "Look after the baby."
Never "look the baby after".

The longest ones have three words.
"Look forward to." "Put up with." "Keep up with."
Three links in one chain. The object comes after.

Now you try.
Put on. Take off. Pick it up. Look after.
Say your morning in phrasal verbs.
