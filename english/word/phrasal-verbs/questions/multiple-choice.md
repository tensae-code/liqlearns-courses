# Phrasal verbs — multiple choice

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Phrasal verbs — one meaning, in sets · (Level 2) -> Sub lesson 2 — Phrasal verbs — the splitting grammar · (Level 3) -> Sub lesson 3 — Phrasal verbs — three-word chains.

Pick the one right answer.

**1. (Sub lesson 1)** "Look after" means: a) search for b) care for c) watch from behind
**Answer: b)** — the pair's own meaning — look after is in Bolivia's LOOK set and its inseparable table, and Cambodia's friendship set.

**2. (Sub lesson 1)** Which sentence uses a price-family travel verb correctly? a) We set off at dawn. b) We set at dawn off. c) We off set at dawn.
**Answer: a)** — set off (start a journey) never splits — Mongolia's travel set (English X, Unit 6).

**3. (Sub lesson 2)** The only correct pronoun placement: a) Put on it. b) Put it on. c) It put on.
**Answer: b)** — a pronoun object must stand between verb and particle in a separable phrasal verb (Bolivia, Year 5, §5).

**4. (Sub lesson 3)** "I look forward to ___" — the chain takes its object: a) between look and forward b) after to, whole c) before look
**Answer: b)** — three-word chains never split; the object follows the last link (Vietnam, Grade 12, Unit 9).
