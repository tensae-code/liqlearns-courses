# True or False — Spelling Patterns

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. Syllables are the beats of a word, and spelling chunk by chunk helps. (Sub lesson 1) — True
2. Sight words and high-frequency words are learned whole, by heart. (Sub lesson 1) — True
3. Inflectional endings never change the spelling of the word they join. (Sub lesson 2) — False
4. A silent consonant is a letter you write but do not sound, as in knight. (Sub lesson 2) — True
5. Homophones sound the same but are spelled the same too. (Sub lesson 2) — False
6. Words from the same root keep the root's letters, like sign and signal. (Sub lesson 3) — True
7. Proofreading with a dictionary is part of finished spelling. (Sub lesson 3) — True
