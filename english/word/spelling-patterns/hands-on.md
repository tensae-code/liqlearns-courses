# Hands-On — Spelling Patterns

Things you do with real people, real pages and real screens. No special materials needed beyond what is named.

1. **Look, say, cover, write, check.** Learn five new words with the study technique, testing each other between rounds.
2. **Pattern sort.** Deal out twenty word cards. Sort them into pattern families and name each family's rule aloud.
3. **Ending changes.** Take ten root words. Add -ed and -ing to each, applying the doubling, dropping and y-to-i changes where they belong.
4. **Break and check.** Each partner picks a long word, breaks it into units on paper, spells it whole, then checks it in the dictionary.
