# Sports — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** Yoga and dancing are in Mexico's sports
vocabulary list.
**True** — Project 6, Vocabulary, p.60.

**2. (Level 2)** A snowboarder is a sportsperson in
Mongolia's table.
**True** — a lifter, a snowboarder, a skier (English IX,
Unit 3).

**3. (Level 3)** "I play swimming" is right in Mongolia's
system.
**False** — swimming ends in -ing, so it takes GO:
"I go swimming."

**4. (Level 3)** "I do basketball" is right in Mongolia's
system.
**False** — basketball is a ball game, so it takes PLAY:
"I play basketball." DO is for exercises and martial
arts — do squats, do judo.
