# Sports — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — the
sports words — naming the sports first, then their actions, then
the play/do/go system, the order the books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Naming the Sports
Sub lesson 1 questions from the type files. Pass mark: name
football, basketball, volleyball, baseball, swimming,
cycling, running, skateboarding, walking, yoga and dancing
on pictures without a miss (Mexico's and Mongolia's sets).

## Sub lesson 2 — Sports in Action
Sub lesson 2 questions from the type files. Pass mark: match
each sport to its action verbs — throw, carry, kick, pass,
dribble, tackle, pitch, bat, jump, swim, paddle, bounce,
block, catch (Mongolia) — and say which sports you play,
and how often.

## Sub lesson 3 — Play, Do and Go
Sub lesson 3 questions from the type files. Pass mark: sort
every sport the lesson teaches under its right partner —
play for team sports and games with a ball, do for
exercises, compound sports and martial arts, go for
sports in -ing — and talk about a favourite sportsperson
the way Mongolia's newspaper task sets it.
