# The home — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — the
words for a home — the rooms first, then the things in them, then
the rooms in whole sentences, the order the books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — The Five Rooms
Sub lesson 1 questions from the type files. Pass mark: name all five
rooms — bedroom, living room, kitchen, dining room, bathroom —
and match each to its picture or its doing word without a miss.

## Sub lesson 2 — The Things in the Rooms
Sub lesson 2 questions from the type files. Pass mark: name the
things (bed, table, chair, oven, fridge, couch, sink, toilet,
closet, lamp, shelf) and say which room each one lives in.

## Sub lesson 3 — Rooms in Sentences
Sub lesson 3 questions from the type files. Pass mark: answer "What
do you do in the …?" for every room in a whole sentence, in the
books' own shapes — "I sleep in the bedroom." "My mother cooks
in the kitchen."
