# The home — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the words for a home — set by the
pattern across the countries' books: the rooms first, then the
things in them, then the rooms in whole sentences.

## Level 1 — the five rooms
Level 1 questions from the type files. Pass mark: name all five
rooms — bedroom, living room, kitchen, dining room, bathroom —
and match each to its picture or its doing word without a miss.

## Level 2 — the things in the rooms
Level 2 questions from the type files. Pass mark: name the
things (bed, table, chair, oven, fridge, couch, sink, toilet,
closet, lamp, shelf) and say which room each one lives in.

## Level 3 — rooms in sentences
Level 3 questions from the type files. Pass mark: answer "What
do you do in the …?" for every room in a whole sentence, in the
books' own shapes — "I sleep in the bedroom." "My mother cooks
in the kitchen."
