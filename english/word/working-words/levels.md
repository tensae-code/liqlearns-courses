# Working words — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the specialist words of hotels,
offices and tourism — set by the pattern across the Greek
vocational books: the hotel desk first, then the office, then
the trade whole.

## Level 1 — the hotel desk
Level 1 questions from the type files. Pass mark: work a
guest's road — enquiry, reservation, deposit, checking in,
key, room — in the Hotel book's own order, without a miss.

## Level 2 — the office
Level 2 questions from the type files. Pass mark: name a
business letter's parts in their order and use the office
set — memo, inquiry, order, complaint, account — in true
sentences.

## Level 3 — the telephone and the trade
Level 3 questions from the type files. Pass mark: take and
leave a telephone message with the desk's phrases (put
through, hold on, call back, engaged), and use the tourism
set — charter flight, airfare, half-board, full-board,
self-catering — correctly.
