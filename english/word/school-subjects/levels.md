# School subjects — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the school-subject words — set
by the pattern across the countries' books: naming the subjects
first, then the timetable, then likings with reasons.

## Level 1 — name the subjects
Level 1 questions from the type files. Pass mark: name
Mathematics, Science, History, Geography, English, Art,
Music, Physical Education, Technology and Computer (ICT)
on a timetable without a miss (Mexico's ten; Rwanda's
eight).

## Level 2 — the timetable
Level 2 questions from the type files. Pass mark: read a
week's timetable aloud — subject, day, time — and say
how many lessons of a subject there are, in Rwanda's
shape: "How many… are there? There are…"

## Level 3 — likings with reasons
Level 3 questions from the type files. Pass mark: run
Rwanda's frame both ways — "I like… because it is…" and
"I don't like… because it is…" — with its adjectives
(boring, difficult, easy, fantastic, splendid, tough,
interesting), name a favourite with Mongolia's evidence
(Anand: physics the most interesting), and say the
subject you would build a job on.
