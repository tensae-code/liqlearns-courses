# Using the dictionary — ordering

Put each set in dictionary order. (This question type exists
for this lesson because the lesson IS order — Bangladesh's
Class 8 unit drills it directly, pp.39–40.)

**1. (Level 1)** zoo · apple · mango · ball · tea
**Answer:** apple, ball, mango, tea, zoo.

**2. (Level 1)** deep · dark · doctor
**Answer:** dark, deep, doctor — the book's own run: first
letters tie (d), second letters decide (a, e, o).

**3. (Level 1)** cat · cow · cup · cake
**Answer:** cake, cat, cow, cup — second letters (a, o, u),
and inside the a's, third letters (k before t).

**4. (Level 2)** technique · tea · team · teapot
**Answer:** tea, team, teapot, technique — all inside the
fence the book draws between 'tea' and 'technique'.

**5. (Level 2)** The fit family: fitting · fit · fixture ·
fitness · fitted
**Answer:** fit, fitness, fitted, fitting, fixture — 'fit'
stands first (the whole word is the others' root); then the
fourth letter decides: fitness (n) before fitted/fitting
(t); inside the t's, the fifth letter: fitted (e) before
fitting (i); fixture's third letter is x, after t, so it
stands last. This is the family order Bangladesh's Lesson 3
asks learners to state (p.40; family as printed pp.36–38).

**6. (Level 3)** Order by the rule TWICE — first as printed,
then say what decides each step: home · hospital · horse ·
house
**Answer:** home, horse, house, hospital — second letters
tie (o); third letters sort m (home), r (horse), then the
two s words; 'house' vs 'hospital' is settled at the fourth
letter: e before p.
