# Using the dictionary — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Dictionary Letter Order · (Level 2) -> Sub lesson 2 — Dictionary Guide Words · (Level 3) -> Sub lesson 3 — Dictionary Entries.
Say true or false. If it is false, say why.

**1. (Sub lesson 1)** 'Doctor' comes before 'deep' in a
dictionary.
**False** — second letters decide: e (deep) before o
(doctor). The order is dark, deep, doctor (Bangladesh, p.39).

**2. (Sub lesson 2)** Guide words are the first and last words on
the page.
**True** (Bangladesh, pp.39–40).

**3. (Sub lesson 3)** Every word has exactly one meaning.
**False** — 'dry' alone has three (Bangladesh, pp.40–41).

**4. (Sub lesson 3)** An entry tells you the word's class — noun,
verb, adjective.
**True** — that is one of the things a dictionary gives
(Bangladesh, pp.36–38).

**5. (Sub lesson 1)** India's Marigold books carry a Picture
Dictionary at the back.
**True** — every year (Class 1 pp.121–122; Class 2
pp.175–176).

**6. (Sub lesson 3)** A synonym means the opposite of a word.
**False** — that is an antonym. A synonym means the same or
almost the same (Bangladesh, pp.40–41).
