# Using the dictionary — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — finding words by letter order — set
by the pattern across the countries' books: the order itself
first, then the guide-word fence, then the whole entry.

## Level 1 — letter order
Level 1 questions from the type files. Pass mark: put word sets
in dictionary order — first letter first, the next letter when
the first ties (dark, deep, doctor) — without a miss.

## Level 2 — the fence
Level 2 questions from the type files. Pass mark: use guide words
to say whether a word sleeps on a page, and find the words
between two fences ('tea' and 'technique') the way Bangladesh's
book drills them.

## Level 3 — the entry
Level 3 questions from the type files. Pass mark: read a whole
entry — spelling, pronunciation, meaning, word class, the
italic example, synonyms/antonyms — and pick the right meaning
of a many-meaning word for the sentence in front of you.
