# Word relationships — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — how words relate — set by the
pattern across the countries' books: same and opposite first,
then same sound, then one word with many meanings.

## Level 1 — same and opposite
Level 1 questions from the type files. Pass mark: give
synonyms from the books' pairs (until/till, buy/purchase,
speak/talk) and antonyms (hot/cold, big/small) without a
miss.

## Level 2 — same sound
Level 2 questions from the type files. Pass mark: tell
homophones apart in sentences — to/two/too, there/their,
allowed/aloud — choosing by meaning, not by ear.

## Level 3 — one word, many meanings
Level 3 questions from the type files. Pass mark: show a
homonym's meanings in two sentences of your own, and answer
closest-meaning and opposite-meaning questions in the
review shape Vietnam's book uses.
