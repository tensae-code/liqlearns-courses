# Money and prices — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the words for money — set by the
pattern across the countries' books: the price questions first,
then currencies, then the money set in sentences.

## Level 1 — asking the price
Level 1 questions from the type files. Pass mark: ask and
answer for one thing and for many things — "How much is
a…?" "It costs 900 Riels." "How much are the clothes?" —
without a miss.

## Level 2 — currencies and near prices
Level 2 questions from the type files. Pass mark: name the
currencies (riel, soum, pound, yen, euro) and soften a price
with about/around the way Sudan's book does.

## Level 3 — the money set
Level 3 questions from the type files. Pass mark: use
Uzbekistan's set — coin, note, exchange, cheque, account,
income, salary, save, lend, borrow — in true sentences, and
never swap lend and borrow.
