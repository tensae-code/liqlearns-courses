# Money and prices — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — the
words for money — the price questions first, then currencies, then
the money set in sentences, the order the books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Asking the Price
Sub lesson 1 questions from the type files. Pass mark: ask and
answer for one thing and for many things — "How much is
a…?" "It costs 900 Riels." "How much are the clothes?" —
without a miss.

## Sub lesson 2 — Currencies and Near Prices
Sub lesson 2 questions from the type files. Pass mark: name the
currencies (riel, soum, pound, yen, euro) and soften a price
with about/around the way Sudan's book does.

## Sub lesson 3 — The Money Set
Sub lesson 3 questions from the type files. Pass mark: use
Uzbekistan's set — coin, note, exchange, cheque, account,
income, salary, save, lend, borrow — in true sentences, and
never swap lend and borrow.
