# Verbs — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** A verb is a word that expresses an action.
**True** — Bangladesh's own definition (Class 3, pp.68–71).

**2. (Level 1)** "School" is a verb.
**False** — what did the school do? Nothing. School names a
place; it is a noun.

**3. (Level 2)** In "Yaa came," the verb is "Yaa."
**False** — Yaa answers "Who?" — a name. Came answers "What
did Yaa do?" — the verb (Ghana, Basic 2).

**4. (Level 2)** A name and a doing word can make a whole
sentence: "Musa ate."
**True** — Ghana names the shape (Name) + (Doing word).

**5. (Level 3)** "He ride a bicycle" is right.
**False** — for he, she, or it, we add -s: "He rides a
bicycle" (Egypt's rule, p.86).

**6. (Level 3)** "I rides" is right.
**False** — the -s comes only with he, she, or it. With I, the
verb stays plain: "I ride."
