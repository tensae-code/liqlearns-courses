# Verbs — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Doing words, what a verb is · (Level 2) -> Sub lesson 2 — The test, what did they do · Sub lesson 3 — The smallest sentence, name plus doing word · (Level 3) -> Sub lesson 4 — He, she, it adds -s.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** A verb is a word that expresses an action.
**True** — Bangladesh's own definition (Class 3, pp.68–71).

**2. (Sub lesson 1)** "School" is a verb.
**False** — what did the school do? Nothing. School names a
place; it is a noun.

**3. (Sub lesson 2)** In "Yaa came," the verb is "Yaa."
**False** — Yaa answers "Who?" — a name. Came answers "What
did Yaa do?" — the verb (Ghana, Basic 2).

**4. (Sub lesson 3)** A name and a doing word can make a whole
sentence: "Musa ate."
**True** — Ghana names the shape (Name) + (Doing word).

**5. (Sub lesson 4)** "He ride a bicycle" is right.
**False** — for he, she, or it, we add -s: "He rides a
bicycle" (Egypt's rule, p.86).

**6. (Sub lesson 4)** "I rides" is right.
**False** — the -s comes only with he, she, or it. With I, the
verb stays plain: "I ride."
