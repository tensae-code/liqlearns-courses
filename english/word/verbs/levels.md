# Verbs — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons are the depths inside this one thing — a doing word — the doing words themselves first, then finding the verb with the books' test, the smallest sentence, and the one change the early books make to it.

Mapping from the old depth layers: old Level 1 (doing words) = Sub lesson 1; old Level 2 splits — the test is Sub lesson 2 and the smallest sentence is Sub lesson 3; old Level 3 (he, she, it adds -s) = Sub lesson 4.

## Sub lesson 1 — Doing words, what a verb is
Sub lesson 1 questions from the type files. Pass mark: given a mixed list of words, pick out every doing word — and leave the naming words and describing words out. (Old Level 1's pass mark.)

## Sub lesson 2 — The test, what did they do
Sub lesson 2 questions from the type files. Pass mark: in a short sentence, find the verb with the test — "What did … do?" (Old Level 2's pass mark, first part.)

## Sub lesson 3 — The smallest sentence, name plus doing word
Sub lesson 3 questions from the type files. Pass mark: build a whole sentence in the books' smallest shape, (Name) + (Doing word): "Yaa came." (Old Level 2's pass mark, second part.)

## Sub lesson 4 — He, she, it adds -s
Sub lesson 4 questions from the type files. Pass mark: change a verb for he, she, or it without a miss — "I ride → he rides," "I take pictures → she takes pictures" — and say Egypt's rule in your own words. (The tenses — present, past, going to — are a different thing and are tested at the Sentence stage, not here.) (Old Level 3's pass mark.)
