# Animals — true or false

Say true or false. If it is false, say why.
(Bangladesh's Class 2 animals unit is itself built as true/false
work — this file follows its shape, pp.86–89.)

**1. (Level 1)** The horse is big.
**True** — Egypt's sentence (p.86).

**2. (Level 1)** The chicken is big.
**False** — the chicken is small; the cow and the horse are
big (Egypt, p.86).

**3. (Level 3)** The cow lives in a forest.
**False** — Bangladesh's own false example: the cow does not
live in a forest; the monkey lives in a tree, the crow in a
nest (pp.86–87).

**4. (Level 3)** The monkey eats fruits and nuts.
**True** — Bangladesh's strips (pp.88–89).

**5. (Level 3)** The deer eats meat.
**False** — the deer eats grass and leaves. The tiger and the
dog eat meat (pp.88–89).

**6. (Level 2)** A kitten is a baby dog.
**False** — a kitten is a baby cat (Palestine's set, p.16).
