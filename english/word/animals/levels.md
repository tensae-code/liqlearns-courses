# Animals — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — the
words for animals — the farm set first, then the wider set, then
animals in whole sentences, the order the books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Farm and Home Animals
Sub lesson 1 questions from the type files. Pass mark: name the farm
four (cow, duck, horse, chicken) and the home set (cat, dog,
goat, rabbit, bird, fish), and say Egypt's size sentences right.

## Sub lesson 2 — The Wild Set
Sub lesson 2 questions from the type files. Pass mark: name the wild
set (lion, zebra, elephant, monkey, tiger, deer, parrot, crow,
insect, kitten) and sort animals into farm/home, wild, and small
creatures without a miss.

## Sub lesson 3 — Animals in Sentences
Sub lesson 3 questions from the type files. Pass mark: build whole
sentences from Bangladesh's table — "The cow eats grass." "The
crow lives in a nest." — for any animal in the set, and correct
a false one.
