# Animals — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the words for animals — set by the
pattern across the countries' books: the farm set first, then the
wider set, then animals in whole sentences.

## Level 1 — farm and home animals
Level 1 questions from the type files. Pass mark: name the farm
four (cow, duck, horse, chicken) and the home set (cat, dog,
goat, rabbit, bird, fish), and say Egypt's size sentences right.

## Level 2 — the wider set
Level 2 questions from the type files. Pass mark: name the wild
set (lion, zebra, elephant, monkey, tiger, deer, parrot, crow,
insect, kitten) and sort animals into farm/home, wild, and small
creatures without a miss.

## Level 3 — animals in sentences
Level 3 questions from the type files. Pass mark: build whole
sentences from Bangladesh's table — "The cow eats grass." "The
crow lives in a nest." — for any animal in the set, and correct
a false one.
