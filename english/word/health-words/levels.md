# Health words — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the words for feeling ill — set by
the pattern across the countries' books: the symptoms first, then
the doctor's room, then advice.

## Level 1 — the symptoms
Level 1 questions from the type files. Pass mark: name the
symptom set — headache, fever, cough, a cold, stomachache,
sore throat, toothache — and say "I have a …" for each one
without a miss.

## Level 2 — at the doctor
Level 2 questions from the type files. Pass mark: play the
patient in the books' dialogue — answer what is wrong, name
the illness — and understand the doctor's words: rest,
medicine, get well soon.

## Level 3 — advice
Level 3 questions from the type files. Pass mark: give the
right advice with should / shouldn't for a named problem,
in the books' own shapes — "You should go to the doctor."
"You shouldn't eat too much junk food."
