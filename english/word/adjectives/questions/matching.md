# Adjectives — matching

Match each adjective to the noun it describes best, the way the
books pair them. (Bangladesh pictures the pairs, Class 4
pp.44–45; Libya hunts them in a story, Grade 5 Unit 6.)

**Set 1 (Level 1)** — the books' own pairs.
1. fresh — **mango**
2. dirty — **shirt**
3. new — **bike**
4. angry — **cat**
5. tall — **tree**
6. brave — **bird**

**Set 2 (Level 2)** — match each word to adjective or not an
adjective.
1. hungry — **adjective** (the hungry wolf)
2. wolf — **not an adjective** (a noun — it names)
3. cold — **adjective** (cold ground)
4. ground — **not an adjective** (a noun)
5. beautiful — **adjective** (a beautiful song)
6. sang — **not an adjective** (a verb — it does)

**Set 3 (Level 3)** — match each start to its right ending.
1. A clean shirt. → The shirt — **is clean**
2. A bad mango. → The mango — **is bad**
3. Cold ground. → The ground — **is cold**
4. A small fire. → The fire — **is small**
