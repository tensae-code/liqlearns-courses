# The town — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the words for a town's places —
set by the pattern across the countries' books: Egypt's eight
words first, then the wider set, then the places in whole
sentences.

## Level 1 — the eight town words
Level 1 questions from the type files. Pass mark: name all eight
— hospital, school, shop, building, street, car, truck, bus —
and match each to its picture or its job without a miss.

## Level 2 — the wider town
Level 2 questions from the type files. Pass mark: name the wider
set — library, post office, supermarket, park, zoo, city — and
say what each place is for.

## Level 3 — places in sentences
Level 3 questions from the type files. Pass mark: run the
dialog's questions and answers about your own town — "Where do
you go when you feel sick?" "What do you see on the street?" —
in whole sentences.
