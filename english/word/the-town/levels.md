# The town — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — the
words for a town's places — Egypt's eight words first, then the
wider set, then the places in whole sentences, the order the books
teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — The Eight Town Words
Sub lesson 1 questions from the type files. Pass mark: name all eight
— hospital, school, shop, building, street, car, truck, bus —
and match each to its picture or its job without a miss.

## Sub lesson 2 — The Wider Town
Sub lesson 2 questions from the type files. Pass mark: name the wider
set — library, post office, supermarket, park, zoo, city — and
say what each place is for.

## Sub lesson 3 — The Town and the Village
Sub lesson 3 questions from the type files. Pass mark: run the
dialog's questions and answers about your own town — "Where do
you go when you feel sick?" "What do you see on the street?" —
in whole sentences.
