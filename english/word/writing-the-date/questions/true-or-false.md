# True or False — Writing the Date

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. A date inside a sentence is set off by commas. (Sub lesson 1) — True
2. "May 3" uses an ordinal number for the day. (Sub lesson 1) — False
3. Mixing two date styles in one document is good writing. (Sub lesson 1) — False
4. The British order is month – day – year. (Sub lesson 2) — False
5. Short numeric dates join the numbers with slashes, full stops or hyphens. (Sub lesson 2) — True
6. 03/05/2026 means the same day in the British and the American order. (Sub lesson 2) — False
7. Fully written-out dates belong on invitations and in formal letters. (Sub lesson 2) — True
