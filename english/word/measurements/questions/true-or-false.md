# True or false — Measurements

(Gate pool: all questions of the sub lesson(s) named — no hardness ranking is written here, so a sub lesson's whole question set is its gate pool.)

1. 1,000 millilitres make a litre.
   **Answer: True** (Sub lesson 1)

2. We measure water in kilos.
   **Answer: False** — liquids are measured in litres. (Sub lesson 1)

3. "How heavy" asks about length.
   **Answer: False** — it asks about weight. (Sub lesson 2)

4. A person's height can be answered with "tall": "He is one metre seventy tall."
   **Answer: True** (Sub lesson 2)
