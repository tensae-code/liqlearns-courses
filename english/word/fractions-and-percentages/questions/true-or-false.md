# True or False — Fractions and Percentages

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. A half is one part of a whole cut into 2 equal parts. (Sub lesson 1) — True
2. A quarter is one part of a whole cut into 2 equal parts. (Sub lesson 1) — False
3. 3/5 is read "three-fifths". (Sub lesson 1) — True
4. 5/8 is read "eight-fifths". (Sub lesson 1) — False
5. "%" means "per cent" — out of every hundred. (Sub lesson 2) — True
6. 75% is said "seventy-five per cent". (Sub lesson 2) — True
7. Per cent counts parts out of every ten. (Sub lesson 2) — False
