# Technology words — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the words for technology — set by
the pattern across the countries' books: the parts first, then
the actions, then the newest words.

## Level 1 — the parts
Level 1 questions from the type files. Pass mark: name
Bolivia's six parts — drive, monitor, keyboard, mouse,
modem/router, printer — and say what each one does, without
a miss.

## Level 2 — the actions
Level 2 questions from the type files. Pass mark: use the
doing words in sentences — plug in, turn on, turn off,
connect, visit a website, upload, download, send a message —
and tell upload from download every time.

## Level 3 — gadgets and the new words
Level 3 questions from the type files. Pass mark: name
Sudan's gadgets (sat-nav, headphones, camera, webcam,
mobile) and use Vietnam's new set — artificial intelligence,
chatbot, programme, analyse — in a sentence of your own.
