# Technology words — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — the
words for technology — the parts first, then the actions, then the
newest words, the order the books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — The Computer Parts
Sub lesson 1 questions from the type files. Pass mark: name
Bolivia's six parts — drive, monitor, keyboard, mouse,
modem/router, printer — and say what each one does, without
a miss.

## Sub lesson 2 — The Technology Actions
Sub lesson 2 questions from the type files. Pass mark: use the
doing words in sentences — plug in, turn on, turn off,
connect, visit a website, upload, download, send a message —
and tell upload from download every time.

## Sub lesson 3 — Gadgets and the Newest Words
Sub lesson 3 questions from the type files. Pass mark: name
Sudan's gadgets (sat-nav, headphones, camera, webcam,
mobile) and use Vietnam's new set — artificial intelligence,
chatbot, programme, analyse — in a sentence of your own.
