# Food and fruit — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — the
words for food — the meals and first foods first, then the fruits
with the like-exchange, then food in whole answers, the order the
books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Meals and First Foods
Sub lesson 1 questions from the type files. Pass mark: name the three
meals — breakfast, lunch, dinner — and the breakfast-plate
foods (egg, cheese, beans, milk, bread) without a miss.

## Sub lesson 2 — Fruits and Likes
Sub lesson 2 questions from the type files. Pass mark: name the
fruit set (banana, orange, apple, mango, grapes, lemon, guava,
papaya, fig, olive), answer "What's this?" with a/an right, and
run "Do you like…?" both ways — "Yes, I do." / "No, I don't.
I like…"

## Sub lesson 3 — Food in Whole Answers
Sub lesson 3 questions from the type files. Pass mark: answer "What
do you eat for breakfast?" in a whole sentence about your real
day, name the wider set (pineapple, cucumber, lettuce, carrot,
tomato), and place fruits and vegetables on the Food Pyramid's
floor.
