# Food and fruit — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the words for food — set by the
pattern across the countries' books: the meals and first foods
first, then the fruits with the like-exchange, then food in
whole answers.

## Level 1 — meals and first foods
Level 1 questions from the type files. Pass mark: name the three
meals — breakfast, lunch, dinner — and the breakfast-plate
foods (egg, cheese, beans, milk, bread) without a miss.

## Level 2 — fruits and likes
Level 2 questions from the type files. Pass mark: name the
fruit set (banana, orange, apple, mango, grapes, lemon, guava,
papaya, fig, olive), answer "What's this?" with a/an right, and
run "Do you like…?" both ways — "Yes, I do." / "No, I don't.
I like…"

## Level 3 — food in whole answers
Level 3 questions from the type files. Pass mark: answer "What
do you eat for breakfast?" in a whole sentence about your real
day, name the wider set (pineapple, cucumber, lettuce, carrot,
tomato), and place fruits and vegetables on the Food Pyramid's
floor.
