# Clothes — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — the
clothes words — naming the clothes first, then wearing sentences,
then materials, the order the books teach it in.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Naming the Clothes
Sub lesson 1 questions from the type files. Pass mark: name the
set — shirt, T-shirt, trousers, jeans, dress, skirt,
shorts, shoes, boots, scarf, hat — on pictures without a
miss.

## Sub lesson 2 — Wearing Sentences and Colours
Sub lesson 2 questions from the type files. Pass mark: say what
a person is wearing in a whole sentence, with the colour —
"He is wearing a yellow shirt" — and set what you usually
wear against what you are wearing today (Cambodia).

## Sub lesson 3 — Materials
Sub lesson 3 questions from the type files. Pass mark: name the
materials (cotton, silk, wool, leather, linen, nylon) and
answer "What is it made of?" — made of when you can still
see the material, made from when you cannot (Mongolia's
pair).
