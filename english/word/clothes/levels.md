# Clothes — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the clothes words — set by the
pattern across the countries' books: naming the clothes first,
then wearing sentences, then materials.

## Level 1 — name the clothes
Level 1 questions from the type files. Pass mark: name the
set — shirt, T-shirt, trousers, jeans, dress, skirt,
shorts, shoes, boots, scarf, hat — on pictures without a
miss.

## Level 2 — wearing, in colours
Level 2 questions from the type files. Pass mark: say what
a person is wearing in a whole sentence, with the colour —
"He is wearing a yellow shirt" — and set what you usually
wear against what you are wearing today (Cambodia).

## Level 3 — materials
Level 3 questions from the type files. Pass mark: name the
materials (cotton, silk, wool, leather, linen, nylon) and
answer "What is it made of?" — made of when you can still
see the material, made from when you cannot (Mongolia's
pair).
