# Choosing your register — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
RANKS inside this one lesson — pass each rank to climb.

## Level 1 — the two suits
Level 1 questions from the type files. Pass mark: re-dress a message formally and informally using the books' own pair words (ask for/inform, book/arrange) without a miss

## Level 2 — place and circumstance
Level 2 questions from the type files. Pass mark: choose dialect or standard, formal or informal, for named moments and defend the choice the way Barbados's objective demands

## Level 3 — the soft tools
Level 3 questions from the type files. Pass mark: hedge an over-hard claim and use vague language deliberately — and say what each softening is FOR
