# Short Answer — Expanding a Definition into a Paragraph

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. What does an example add to a definition? (Sub lesson 1)
   — A real case where the thing is at work, so the reader sees the definition happening instead of only hearing its words.

2. How is comparing-and-contrasting different from giving an example? (Sub lesson 1)
   — An example shows the thing itself at work; comparison sets the thing beside its close neighbours and walks the likenesses and differences, showing the definition's edges.

3. Which expansion way fits the word 'erosion', and why? (Sub lesson 2)
   — Describing a process — erosion happens in steps (water or wind loosening, carrying and dropping material over time), so following the steps teaches the word.

4. Must a definition paragraph use only one of the three ways? (Sub lesson 2)
   — No — the three are tools; a paragraph may use one fully or mix two, as long as it grows the same core definition.
