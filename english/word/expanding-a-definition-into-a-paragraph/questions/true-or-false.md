# True or False — Expanding a Definition into a Paragraph

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. An example expansion shows the defined thing at work in a real case. (Sub lesson 1) — True
2. Comparing and contrasting means naming only how two things are different. (Sub lesson 1) — False
3. A process expansion follows the thing step by step as it happens. (Sub lesson 2) — True
4. Every definition paragraph must use all three ways at once. (Sub lesson 2) — False
5. The same definition can be expanded in more than one way. (Sub lesson 2) — True
