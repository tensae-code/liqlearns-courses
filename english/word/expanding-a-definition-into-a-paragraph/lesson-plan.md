# Lesson Plan — Expanding a Definition into a Paragraph

**Unit:** Unit 8 — Using the Dictionary

**One thing:** growing a one-sentence definition into a full paragraph in three ways — by giving an example, by comparing and contrasting, and by describing a process.

## Sub lessons

1. Expanding by example and by comparison
2. Expanding by describing a process

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Teaching points

- A definition can be expanded into a full paragraph in three ways: by example, by comparing and contrasting, by describing a process (Lesson 6, pp.375–376).
- The book works all three expansions on one word — speed — so the ways can be compared on the same definition (p.375).
