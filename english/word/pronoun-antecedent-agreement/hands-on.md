# Hands-On — Pronoun–Antecedent Agreement

Things you do with real books, real texts and real talk.

1. **Rule sorting.** Write ten sentences, one per trap (intervening phrase, and-compound, or/nor, collective, title, every, many a, the/a number of…). Mix them up; a partner sorts each to its rule and fixes any wrong pronoun.
2. **Page audit.** In one page of a story, list every pronoun with its antecedent. Mark each agreement ✓. If any looks doubtful, name the rule that settles it.
3. **Near/far drill.** Make five or/nor sentences, swapping the order of the antecedents each time, and say how the pronoun changes with proximity.
