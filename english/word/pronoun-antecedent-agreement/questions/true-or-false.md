# True or False — Pronoun–Antecedent Agreement

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. Words between a pronoun and its antecedent can change the agreement. (Sub lesson 1) — False
2. Two antecedents joined by 'and' take a plural pronoun. (Sub lesson 1) — True
3. 'A number of bears were seen' — the pronoun/verb is plural because the sense is the bears. (Sub lesson 2) — True
4. 'Every child' takes a plural pronoun. (Sub lesson 2) — False
5. A collective noun acting as one body takes a singular pronoun. (Sub lesson 2) — True
