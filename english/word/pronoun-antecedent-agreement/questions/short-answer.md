# Short Answer — Pronoun–Antecedent Agreement

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. Why don't intervening phrases change agreement? (Sub lesson 1)
   — Because the pronoun stands for its antecedent, not for the nearest noun; the words in between only decorate the sentence — the match is made with the true antecedent.

2. What decides agreement when the antecedent is some/any/none/all/most? (Sub lesson 1)
   — What it refers to: a countable reference takes a plural pronoun; an uncountable reference takes a singular one.

3. Explain 'the number of' vs 'a number of' with the pronoun each takes. (Sub lesson 2)
   — 'The number of X was…' speaks of the number itself — singular. 'A number of X were…' speaks of the X's — plural.

4. Why is 'Twenty-Three Tales holds its readers' correct? (Sub lesson 2)
   — A title names one work; its pronoun is singular whatever the words inside the title look like.
