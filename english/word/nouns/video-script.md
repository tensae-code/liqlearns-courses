# Video script — Nouns

The super-simple voice, for the video that rides on top of the
lesson (lesson-plan.md, add-on list). Made later, when videos are
made; the script is the slot's written form until then.

---

Look around you.

This is a **chair**. Chair is a word. It names a thing.
A word that names a thing is a **noun**.

This is my **dad**. Dad names a person. Noun.
This is a **school**. School names a place. Noun.

Person. Place. Thing. A noun names all three.

**Car** — thing. Noun.
**Teacher** — person. Noun.
**Park** — place. Noun.

Now — **run**! Run names nothing. Run is what you DO.
Not a noun. That word is for the next lesson.

One more. Some names are for one only.
One boy: **Karim**. Big K!
One river: **the Nile**. Big N!
A name for one only starts big.

Now you. Point. Name it. Person, place, or thing?
That is a noun.
