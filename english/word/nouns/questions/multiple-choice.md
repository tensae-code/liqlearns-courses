# Nouns — multiple choice

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> split item by item by the noun each item turns on: Sub lesson 1 — Nouns that name people · Sub lesson 2 — Nouns that name places · (Level 2) -> the same split by sort, with Sub lesson 3 — Nouns that name things · (Level 3) -> Sub lesson 4 — Special names and capital letters · (Level 4) -> Sub lesson 5 — The noun test, noun or verb.

Pick the one right answer.

**1. (Sub lesson 2)** Which word is a noun?
a) run  b) happy  c) school  d) swim
**Answer: c) school** — it names a place. Run and swim are doing
words; happy is a describing word.

**2. (Sub lesson 1)** Which word names a person?
a) teacher  b) quickly  c) jump  d) blue
**Answer: a) teacher.**

**3. (Sub lesson 1)** "Dad" names a —
a) place  b) thing  c) person
**Answer: c) person** (Egypt's own example, Scope and Sequence
p.4).

**4. (Sub lesson 2)** "Library" names a —
a) person  b) place  c) thing
**Answer: b) place** (Egypt's city unit, Unit 4).

**5. (Sub lesson 3)** "Bicycle" names a —
a) person  b) place  c) thing
**Answer: c) thing** (Egypt's own example, p.4).

**6. (Sub lesson 4)** Which one is written the right way?
a) karim lives in egypt  b) Karim lives in Egypt  c) karim lives
in Egypt
**Answer: b)** — Karim and Egypt are special names; each belongs
to one only, so each starts with a capital.

**7. (Sub lesson 5)** In "Ofori danced," the noun is —
a) danced  b) Ofori
**Answer: b) Ofori** — Who danced? Ofori. Danced answers "What
did Ofori do?" — a doing word (Ghana's test, Basic 2).

**8. (Sub lesson 5)** Which list is all nouns?
a) cat, run, happy  b) book, school, teacher  c) swim, dog,
quickly
**Answer: b)** — a thing, a place, a person.
