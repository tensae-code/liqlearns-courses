# Nouns — multiple choice

Pick the one right answer.

**1. (Level 1)** Which word is a noun?
a) run  b) happy  c) school  d) swim
**Answer: c) school** — it names a place. Run and swim are doing
words; happy is a describing word.

**2. (Level 1)** Which word names a person?
a) teacher  b) quickly  c) jump  d) blue
**Answer: a) teacher.**

**3. (Level 2)** "Dad" names a —
a) place  b) thing  c) person
**Answer: c) person** (Egypt's own example, Scope and Sequence
p.4).

**4. (Level 2)** "Library" names a —
a) person  b) place  c) thing
**Answer: b) place** (Egypt's city unit, Unit 4).

**5. (Level 2)** "Bicycle" names a —
a) person  b) place  c) thing
**Answer: c) thing** (Egypt's own example, p.4).

**6. (Level 3)** Which one is written the right way?
a) karim lives in egypt  b) Karim lives in Egypt  c) karim lives
in Egypt
**Answer: b)** — Karim and Egypt are special names; each belongs
to one only, so each starts with a capital.

**7. (Level 4)** In "Ofori danced," the noun is —
a) danced  b) Ofori
**Answer: b) Ofori** — Who danced? Ofori. Danced answers "What
did Ofori do?" — a doing word (Ghana's test, Basic 2).

**8. (Level 4)** Which list is all nouns?
a) cat, run, happy  b) book, school, teacher  c) swim, dog,
quickly
**Answer: b)** — a thing, a place, a person.
