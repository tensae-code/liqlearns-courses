# Nouns — short answer

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Nouns that name people (the definition sits there), except item 2 (naming a thing in the room), which is Sub lesson 3 — Nouns that name things · (Level 2) -> item 3 is marked Sub lesson 1 (it asks the person noun first; its place noun is Sub lesson 2's) and item 4 is Sub lesson 3 · (Level 3) -> Sub lesson 4 — Special names and capital letters · (Level 4) -> Sub lesson 5 — The noun test, noun or verb.

Answer in a word or a short line.

**1. (Sub lesson 1)** What is a noun?
**Answer:** a word that names a person, a place, or a thing.

**2. (Sub lesson 3)** Name one noun you can see in the room you are
in now.
**Answer:** any true naming word the learner can point at —
chair, door, book, desk…

**3. (Sub lesson 1)** Read: "The teacher is in the library." Name the
person noun and the place noun.
**Answer:** person — teacher; place — library.

**4. (Sub lesson 3)** A cat is a living thing. Which sort does its
name go in?
**Answer:** thing — animals sit with things in the books'
three-way sort.

**5. (Sub lesson 4)** Write the special names in this line the right
way: "ahmed lives in tripoli."
**Answer:** Ahmed lives in Tripoli. (Libya's own example name
and city, Grade 7 WorkBook 7.7.)

**6. (Sub lesson 5)** In "The bus stopped," which word is the noun?
Prove it with the test.
**Answer:** bus — it names a thing; "stopped" answers "What did
the bus do?", so it is a doing word, not a noun.

**7. (Sub lesson 5)** Egypt's review asks you to circle the noun.
Circle it here: run — plane — happy.
**Answer:** plane (Egypt's own example thing, p.4).
