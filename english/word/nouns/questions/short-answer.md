# Nouns — short answer

Answer in a word or a short line.

**1. (Level 1)** What is a noun?
**Answer:** a word that names a person, a place, or a thing.

**2. (Level 1)** Name one noun you can see in the room you are
in now.
**Answer:** any true naming word the learner can point at —
chair, door, book, desk…

**3. (Level 2)** Read: "The teacher is in the library." Name the
person noun and the place noun.
**Answer:** person — teacher; place — library.

**4. (Level 2)** A cat is a living thing. Which sort does its
name go in?
**Answer:** thing — animals sit with things in the books'
three-way sort.

**5. (Level 3)** Write the special names in this line the right
way: "ahmed lives in tripoli."
**Answer:** Ahmed lives in Tripoli. (Libya's own example name
and city, Grade 7 WorkBook 7.7.)

**6. (Level 4)** In "The bus stopped," which word is the noun?
Prove it with the test.
**Answer:** bus — it names a thing; "stopped" answers "What did
the bus do?", so it is a doing word, not a noun.

**7. (Level 4)** Egypt's review asks you to circle the noun.
Circle it here: run — plane — happy.
**Answer:** plane (Egypt's own example thing, p.4).
