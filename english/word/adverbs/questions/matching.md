# Adverbs — matching

Match each verb to its how-word, the way Bangladesh's mime game
pairs them (Class 5, p.27).

**Set 1 (Level 1)**
1. run — **quickly**
2. sing — **loudly**
3. write — **carefully**
4. draw — **quietly**
5. walk (old man) — **slowly**

**Set 2 (Level 2)** — match each adjective to its adverb.
1. quick — **quickly**
2. loud — **loudly**
3. happy — **happily** (y → i)
4. angry — **angrily** (y → i)
5. fast — **fast** (no change — the rebel)
6. good — **well** (a different word — the rebel)

**Set 3 (Level 2)** — match each word to adjective or adverb.
1. beautiful (a beautiful song) — **adjective** — describes
   the song
2. beautifully (she sang beautifully) — **adverb** —
   describes the singing
3. loud (a loud laugh) — **adjective**
4. loudly (he laughed loudly) — **adverb**
(Libya's own story pairs, Grade 8.)

**Set 4 (Level 3)** — match each how-often word to its place on
the ladder.
1. always — **all the time**
2. usually — **most of the time**
3. sometimes — **now and then**
4. never — **not even once**
