# Hands-On — Beach and Seaside Words

1. **Beach map.** Draw a coastline with a lagoon, a cliff, two beaches and a mountain; present the map aloud.
2. **Tourist desk.** In pairs, run the advice dialogue with different wants: calm water, big waves, few tourists.
3. **Word catch.** The caller says a definition ("calm water held apart from the sea"); players answer with the word (lagoon).
4. **Postcard.** Write a postcard from a beach using breathtaking, waves and swimming.
