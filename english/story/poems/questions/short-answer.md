# Short Answer — Poems

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. Name two poems from the Class IV set and say what each teaches. (Sub lesson 1)
   — Any two, e.g.: "The Quarrel" — forgive and ask forgiveness after an argument; "No More Water" — one person's waste is another's shortage; "Picnics" — do not litter.
2. Who wrote "Celebration", and what is it about? (Sub lesson 1)
   — Alonzo Lopez; a joyful community celebration, and keeping one's own traditions.
3. What happens in "Lochinvar"? (Sub lesson 2)
   — Young Lochinvar rides to Netherby, where Ellen is to be married, and dances her away from her wedding.
4. Name the poet and the class book for "I Know Why the Caged Bird Sings". (Sub lesson 2)
   — Maya Angelou; the Class IX book.
5. Why does this course name Keats, not Shelley, for "La Belle Dame sans Merci"? (Sub lesson 3)
   — Because Keats is the poem's real author; the Class XII contents page credits "P. B. Shelley" in error, and the error is taught corrected.
