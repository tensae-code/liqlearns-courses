# Lesson Plan — TWIST Poem Analysis

**Unit:** Unit 41 — Stories and Poems in Detail

**One thing:** TWIST — a five-part method for analysing a poem: Tone, Word choice, Imagery, Style, Theme — worked through in order, so a whole poem gets read closely instead of glanced at.

## Sub lessons

1. T, W, I — tone, word choice, imagery
2. S, T — style and theme

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Teaching points

- TWIST: a five-part method for analysing a poem — Tone, Word choice, Imagery, Style, Theme (Lesson 3, Task 5 "Let's Do the T-W-I-S-T", pp.318–319).
- The method is worked on Baudelaire's "Song of Autumn" — the poem read in the same lesson (p.317).
