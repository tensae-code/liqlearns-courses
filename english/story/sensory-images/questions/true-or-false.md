# True or False — Sensory Images (Imagery)

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. Every describing word is a sensory image. (Sub lesson 1) — False
2. A sensory image must land on one of the five senses. (Sub lesson 1) — True
3. "Beautiful" by itself is a strong sensory image. (Sub lesson 1) — False
4. Images can carry a story's feelings before anyone names them. (Sub lesson 2) — True
5. Comparing two story moments by their images is a fair way to compare them. (Sub lesson 2) — True
