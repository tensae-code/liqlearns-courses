# True or false — Predicting What Happens Next

(Gate pool: all questions of the sub lesson(s) named — no hardness ranking is written here, so a sub lesson's whole question set is its gate pool.)

1. Titles and pictures can be clues.
   **Answer: True** (Sub lesson 1)

2. A prediction is a random guess.
   **Answer: False** — it is joined-up clues. (Sub lesson 1)

3. "I think … will … because …" is the full prediction shape.
   **Answer: True** (Sub lesson 2)

4. A good reader never changes a prediction.
   **Answer: False** — the story's new pages can change it. (Sub lesson 2)
