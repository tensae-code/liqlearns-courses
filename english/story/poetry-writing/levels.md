# Poetry writing — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — writing
to a poem's shape — set by the pattern across the countries' books:
the terms and the steps first, then the three named shapes, then the
choices a poet makes on purpose.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old
Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Poetry Terms and Writing Steps
Sub lesson 1 questions from the type files. Pass mark: use the
writer's core terms correctly (line, stanza, rhyme, rhythm, refrain,
persona, imagery) and run a poem through the writing steps — goal,
theme, imagery, sound, revise.

## Sub lesson 2 — The Named Poetry Shapes
Sub lesson 2 questions from the type files. Pass mark: build a bio
poem and a colour poem to their frames, and a limerick of five lines
rhyming AABBA with its long-short heartbeat.

## Sub lesson 3 — The Poet's Choices
Sub lesson 3 questions from the type files. Pass mark: choose rhyme
or free verse deliberately, place a refrain and a comparison where
they earn their keep, and judge a draft against the shapes and
steps.
