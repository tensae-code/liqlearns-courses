# Telling a story back — ordering

Stand the items in their true order.

**1. (Level 1)** A retelling's walk: tell from memory in
your sentences / read or hear the story / check against
the original / close the book.
**Answer:** read or hear — close the book — tell from
memory in your sentences — check against the original.

**2. (Level 2)** Put the chain in order: the last teller
lands the ending / the first teller opens / middle tellers
carry the next happening each.
**Answer:** first teller opens — middle tellers carry —
last teller lands (and in the hard round, retells whole).

**3. (Level 2)** Shorten lawfully — order the work: find
the load-bearing stones / tell the full story / drop only
small stones / tell it again, shorter.
**Answer:** tell full — find the load-bearing stones —
drop only small stones — tell shorter.

**4. (Level 3)** Bangladesh's lesson order: retell the fable
(first person) / hear the original / compare yours with
the original, item by item.
**Answer:** hear the original — retell (first person) —
compare item by item.
