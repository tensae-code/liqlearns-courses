# Telling a story back — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the faithful retelling — set by the
pattern across the countries' books: whole-and-ordered first, then
lawful shortening, then the turns (first person, comparison).

## Level 1 — whole and in order
Level 1 questions from the type files. Pass mark: retell a short
story whole and in order — with the word box if needed — missing
no load-bearing stone.

## Level 2 — lawful shortening
Level 2 questions from the type files. Pass mark: shorten a
retelling to half and to two sentences, dropping only small
stones, and catch a dropped load-bearing stone in another's
telling on first hearing.

## Level 3 — the turns
Level 3 questions from the type files. Pass mark: retell in the
first person as a character, then compare the retelling against
the original item by item — imports named, order defended,
words demonstrably your own.
