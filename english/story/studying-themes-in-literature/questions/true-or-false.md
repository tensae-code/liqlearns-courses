## True or false

1. A theme can be named with one topic word, like "ships". (Sub lesson 1) **False — a theme is stated as a full sentence about what the work works out.**

2. The *Two Plays* book sets a Theme study section after each play. (Sub lesson 1) **True.**

3. A scene can serve one theme and break another at the same time. (Sub lesson 2) **True — that pull is what weighing themes studies.**

4. Weighing themes means deciding which theme wins. (Sub lesson 2) **False — it means stating each fairly and showing how the work sets them against each other.**
