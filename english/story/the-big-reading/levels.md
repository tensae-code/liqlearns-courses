# The big reading — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — whole-book reading at your level —
set by the pattern across the countries' books: knowing the tool
first, then running it, then climbing with it.

## Level 1 — the tool
Level 1 questions from the type files. Pass mark: say what a graded
reader is, name Libya's two bound-in readers with their books'
places, and run the page test to find an honest level.

## Level 2 — the run
Level 2 questions from the type files. Pass mark: read whole
chapters at story speed under the book-scale ladder, and hold
every chapter with the two-line telling-back before moving on.

## Level 3 — the climb
Level 3 questions from the type files. Pass mark: judge a finished
book whole (five-minute retelling, one-sentence main idea), and
choose the next step up with evidence from the notebook, not
from pride or comfort.
