# Too, enough, so, such — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
pushing a description until it blocks, allows, or produces a
result — set by the pattern across the countries' books: too
then enough, so then such, then the wider set around them.

Mapping from the old depth layers: old Level 1 splits at the
jump between its two pushers — too is Sub lesson 1 and enough
is Sub lesson 2; old Level 2 splits the same way — so is Sub
lesson 3 and such is Sub lesson 4; old Level 3 = Sub lesson 5.
The pass marks split the same way below. Items are marked by
the pusher they actually ask about, item by item.
