# Too, enough, so, such — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths (RANKS) inside this one thing — pushing a description until it blocks, allows, or produces a result — set by the
pattern across the countries' books: the shape first, then its job,
then its borders with its neighbours.

## Level 1 — too and enough
Level 1 questions from the type files. Pass mark: build too + adjective + to-infinitive (blocked) and adjective + enough + to-infinitive (allowed) for the same object, word order exact.

## Level 2 — so and such
Level 2 questions from the type files. Pass mark: run so + adjective/adverb + that and such (a/an) + noun + that, choosing by what follows — adjective alone or noun phrase.

## Level 3 — the intensifier set
Level 3 questions from the type files. Pass mark: grade plain descriptions with the books' wider set (very, really, extremely, absolutely, utterly) matched to the adjective, and correct *too enough*-type pile-ups live.
