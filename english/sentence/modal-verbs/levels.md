# Levels — Modal Verbs

This file is the sub-lesson depth record for the lesson (restructure
2026-11-08): what each sub lesson holds, in teaching order. The old
layer wording is not used; the sub lessons below are the lesson's own
parts, exactly as listed in lesson-plan.md.

| Sub lesson | What it holds |
|---|---|
| Sub lesson 1 — Must — strong obligation | Must for strong/personal obligation and mustn't for prohibition — the Grade 11 treatment. |
| Sub lesson 2 — Should — advice and weaker obligation | Should for advice, suggestions and weaker obligation. |
| Sub lesson 3 — Must to and have to — the written rule and the spoken way | The compendium's comparison: MUST TO for official/written rules (strong moral obligation), SHOULD for personal, weaker obligation, HAVE TO used in place of must in speech — “not a modal verb”, in the book's words. |

Pass mark: the sources state no pass mark and none is invented. In this course a sub lesson opens when the learner proves the previous one with the prove-it check (at most 5 questions, the sub lesson's whole question set as the pool).
