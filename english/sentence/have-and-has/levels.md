# Levels — Have and Has (things you own)

This file is the sub-lesson depth record for the lesson
(restructure 2026-11-08): what each sub lesson holds, in teaching
order. The old layer wording is not used; the sub lessons below
are the lesson's own parts, exactly as listed in lesson-plan.md.

| Sub lesson | What it holds |
|---|---|
| Sub lesson 1 — I / you / we / they have | The positive frame "have" for I, you, we and they, said over real owned things — Activity Book 3's school-supplies pattern (printed p.22) and the Grade 7 book's Unit 2 treatment. |
| Sub lesson 2 — He / she / it has | The third-person change have → has — Activity Book 3 (printed p.24) and the Grade 7 Student's Book, Unit 2 (printed pp.42–48). |
| Sub lesson 3 — Don't have / doesn't have | The negatives don't have (I/you/we/they) and doesn't have (he/she/it), with plain have after doesn't — Activity Book 3 (printed pp.22, 24). |
| Sub lesson 4 — Do you have…? / Does he have…? | The questions Do/Does…have? with the short answers — Activity Book 3's toys-unit treatment (printed pp.28–30). |

Pass mark: the sources state no pass mark and none is invented. In
this course a sub lesson opens when the learner proves the previous
one with the prove-it check (at most 5 questions, the sub lesson's
whole question set as the pool).
