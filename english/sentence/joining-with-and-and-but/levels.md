# Joining with and and but — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the true join — set by the
pattern across the countries' books: and first, then but, then
choosing cold.

## Level 1 — and, the adder
Level 1 questions from the type files. Pass mark: join words,
lists, and sentences with and; drop a shared who the way
Ghana's example does; place the list's commas and final and.

## Level 2 — but, the turner
Level 2 questions from the type files. Pass mark: join with
but where a real turn stands, and feel a false but (no turn)
as wrong without being told.

## Level 3 — choosing cold
Level 3 questions from the type files. Pass mark: given bare
pairs, pick the true joiner every time and defend it by the
meaning's direction; name or as the choice-brother and leave
