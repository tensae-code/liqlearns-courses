# How sure you are — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — saying how sure you are about
now — set by the pattern across the countries' books: the two
sure ends first (Egypt's box opens with must and can't),
then the possible middle, then the numbers held live.

## Level 1 — the sure ends
Level 1 questions from the type files. Pass mark: must be
for a sign that proves it, can't be for a sign that
kills it — and never mustn't for a deduction.

## Level 2 — the possible middle
Level 2 questions from the type files. Pass mark: may /
could be for a half-sure guess and might be for a
less-sure one, chosen from the signs, not from habit.

## Level 3 — the numbers live
Level 3 questions from the type files. Pass mark: run
Egypt's whole ladder on one scene — must 95–100%,
may/could 50%, might 30%, can't 95–100% NOT — and defend
each rung by pointing at its sign.
