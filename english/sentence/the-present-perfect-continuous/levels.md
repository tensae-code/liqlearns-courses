# The present perfect continuous — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the action still moving from a
past start — set by the pattern across the countries' books:
Libya meets the shape inside a story lesson first, then names it
for habits, then drills for/since as a full lesson; Egypt states
the whole box last and fullest.

## Level 1 — the shape
Level 1 questions from the type files. Pass mark: build
have/has + been + verb-ing for every who, statements,
not-forms and questions, with the -ing spellings right
(swimming, running, making) — been never changes.

## Level 2 — the stretch and its measures
Level 2 questions from the type files. Pass mark: answer
"What have you been doing?" and "How long…?" about real
ongoing actions, and place for (length) and since
(starting point) without a single swap.

## Level 3 — the marks and the neighbours
Level 3 questions from the type files. Pass mark: explain
a visible mark with a just-stopped action (I'm tired
because I have been studying all night), report recent
habits, and choose live between the continuous, the
simple perfect (a count, a result) and the present
continuous (only this minute).
