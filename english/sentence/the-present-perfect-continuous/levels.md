# The present perfect continuous — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — the
action still moving from a past start — the shape first, then
the stretch and its measures, then the marks and the neighbours.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 covered two natural
jumps, so it splits at the jump — its marks part is Sub lesson
3 and its recent-habits and neighbours part is Sub lesson 4,
and its pass mark splits the same way below.

## Sub lesson 1 — The Present Perfect Continuous's Shape
Sub lesson 1 questions from the type files. Pass mark: build have/has + been + verb-ing for every who, statements, not-forms and questions, with the -ing spellings right (swimming, running, making) — been never changes.

## Sub lesson 2 — The Stretch and Its Measures
Sub lesson 2 questions from the type files. Pass mark: answer "What have you been doing?" and "How long…?" about real ongoing actions, and place for (length) and since (starting point) without a single swap.

## Sub lesson 3 — The Marks — Just Stopped
Sub lesson 3 questions from the type files. Pass mark: explain a visible mark with a just-stopped action (I'm tired because I have been studying all night).

## Sub lesson 4 — Recent Habits and the Neighbours
Sub lesson 4 questions from the type files. Pass mark: report recent habits, and choose live between the continuous, the simple perfect (a count, a result) and the present continuous (only this minute).
