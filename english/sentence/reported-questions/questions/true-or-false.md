# Reported questions — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** A reported question ends with a
question mark.
**Answer: False** — a reported question is a statement
about a question: statement order, no question mark
(Kuwait, Pearls 9B, p.45).

**2. (Level 2)** "He asked where do I live" is a correct
reported question.
**Answer: False** — inside a report the words run
straight: "He asked where I lived" — no do, and the
tense stepped back.

**3. (Level 3)** Vietnam's Grade 9 book teaches reported
statements and reported wh- questions as well as yes/no
questions.
**Answer: False** — that book teaches Yes/No reported
questions only (Unit 7); the limit is stated in its
filing and in this lesson.
