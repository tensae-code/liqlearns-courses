# Reported questions — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — retelling what somebody asked — set
by the pattern across the countries' books: the yes/no report with
if/whether first (the shape Vietnam's Grade 9 and Nepal's Grade 8
both open with), then the wh- report in statement order (Mauritania's
own chart), then the polite frames that Cambodia builds a whole unit
on.

## Level 1 — yes/no reports: if and whether
Level 1 questions from the type files. Pass mark: report
any yes/no question with asked if / asked whether, in
statement order, the tense stepped back, do/did dropped,
and no question mark.

## Level 2 — wh- reports: the word stays in front
Level 2 questions from the type files. Pass mark: report
any wh- question with its wh- word in the front seat and
a straight statement behind it — where I lived, what she
had bought — backshift and pronoun turns included.

## Level 3 — the polite frames
Level 3 questions from the type files. Pass mark: wrap a
direct question in I was wondering…, Could I ask you…?
or Do you have any idea…?, keeping the straight order
inside the cushion — and choose if or whether on
purpose when a choice or an "or not" is in the air.
