# Reported questions — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — retelling
what somebody asked — set by the pattern across the countries'
books: the yes/no report with if/whether first (the shape
Vietnam's Grade 9 and Nepal's Grade 8 both open with), then the
wh- report in statement order (Mauritania's own chart), then the
polite frames that Cambodia builds a whole unit on.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Reported Questions Yes/No Reports
Sub lesson 1 questions from the type files. Pass mark: report
any yes/no question with asked if / asked whether, in
statement order, the tense stepped back, do/did dropped,
and no question mark.

## Sub lesson 2 — Reported Questions Wh- Reports
Sub lesson 2 questions from the type files. Pass mark: report
any wh- question with its wh- word in the front seat and
a straight statement behind it — where I lived, what she
had bought — backshift and pronoun turns included.

## Sub lesson 3 — Reported Questions Polite Frames
Sub lesson 3 questions from the type files. Pass mark: wrap a
direct question in I was wondering…, Could I ask you…?
or Do you have any idea…?, keeping the straight order
inside the cushion — and choose if or whether on
purpose when a choice or an "or not" is in the air.
