# Modal perfects — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the certainty ladder aimed at
the past — set by the pattern across the countries' books:
deduction first (Egypt's box prints the past ladder beside
the present one), then criticism (Nepal's Criticising unit),
then the wasted effort.

## Level 1 — deduction about the past
Level 1 questions from the type files. Pass mark: build
modal + have + participle for every rung — must have,
can't have, may/might have — with have never changing
shape.

## Level 2 — criticism and regret
Level 2 questions from the type files. Pass mark: should
have for the right thing not done, shouldn't have for
the wrong thing done — aimed at your own past as cleanly
as at another's (Nepal's "should have kept the receipt").

## Level 3 — could have and needn't have
Level 3 questions from the type files. Pass mark: could
have for the open door nobody used, and needn't have for
the effort that was made but not needed — held apart
from didn't need to, every time.
