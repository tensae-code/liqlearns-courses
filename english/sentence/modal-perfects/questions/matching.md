# Modal perfects — matching

Match each sentence to its job.

**1. (Level 1)** "He must have taken the early bus." **Answer: a deduction about the past** — the signs point one way: 95–100% sure it happened (Egypt).

**2. (Level 2)** "You shouldn't have run on that leg." **Answer: criticism** — the wrong thing was done (Nepal's Criticising unit, TG G9 U14).

**3. (Level 3)** "You needn't have waited for me." **Answer: a wasted effort** — the waiting WAS done, and it was not needed.
