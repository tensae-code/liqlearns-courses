# Levels — The Dummy Subject It

How deep each sub lesson goes. The course-wide level ladder (Zero to Story) places this lesson at sentence level — it stands in Unit 18 (Deeper Sentences), with the machinery that reaches beyond the plain sentence.

| Sub lesson | What it holds |
|---|---|
| It + be + adjective | build "It is important", "It is difficult", "It was exciting" — the it that holds the sentence's place |
| It + be + adjective + to-infinitive | build "It is important to practise", "It is difficult to learn" — the pattern completed by an action |

Pass mark: the sources state no pass mark and none is invented. In this course a sub lesson opens when the learner proves the previous one with the prove-it check (at most 5 questions, the sub lesson's whole question set as the pool).
