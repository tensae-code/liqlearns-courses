# Asking yes/no questions — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the yes/no question — set by the
pattern across the countries' books: the be-swap first, then the
do/does engine, then voice and whole answers.

## Level 1 — the be-swap
Level 1 questions from the type files. Pass mark: swap any
be-statement into a question and answer it with the tailed short
answer ("Yes, she is." / "No, they aren't."), no misses.

## Level 2 — the do/does engine
Level 2 questions from the type files. Pass mark: pick do or
does by the who, every time; keep the verb bare after does (the
-s has moved house); answer with the engine's short answers.

## Level 3 — voice and whole answers
Level 3 questions from the type files. Pass mark: ask with the
rising voice and let answers fall (Bangladesh's rule), and turn
short answers into whole-sentence answers without breaking the
shape.
