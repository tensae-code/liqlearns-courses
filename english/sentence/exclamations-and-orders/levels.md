# Exclamations and orders — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS
(2026-11-08 restructure — README, "Units, Lessons and Sub Lessons").
Practice is tied to the skill number, as before. The questions live in
the type files; this file is the by-sub-lesson view. The sub lessons are
the depths inside this one thing — sentences that act instead of state —
set by the pattern across the countries' books: the imperative shape
first (Bolivia's box, Nicaragua's tip), then its work in directions and
rules (Kuwait, Rwanda, Egypt's must), then the cry of feeling and its
mark (Egypt's punctuation teaching).
