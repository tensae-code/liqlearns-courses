# Exclamations and orders — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Exclamations and orders — the order shape · (Level 2) -> Sub lesson 2 — Exclamations and orders — orders at work · (Level 3) -> Sub lesson 3 — Exclamations and orders — the cry.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** An imperative normally includes the subject pronoun you.
**Answer: False** — no subject pronoun is used — the bare verb is the shape (Nicaragua, Grammar Tip, p.13).

**2. (Sub lesson 2)** Egypt's Primary 3 book says imperatives end with an exclamation point because they are strong instructions.
**Answer: True** — the book's own filed note (Primary 3, Term 2, p.8).

**3. (Sub lesson 3)** "How a fast car!" is a correct exclamation.
**Answer: False** — a noun phrase takes What: What a fast car! How takes an adjective or adverb alone: How fast it is!
