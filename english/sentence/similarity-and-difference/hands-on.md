# Hands-on — Similarity and Difference

## Pairs on the table

Pairs of objects — two cups, two books, two bags, some matching, some not — are set out. The learner must describe each pair with the exact form the pair deserves: the same as only for true matches, similar to for near ones, different from for the rest. The class challenges any wrong fit.

## Alike hunt

In pairs, learners hunt the school for the two most alike things they can find and the two least alike, and present all four with whereas sentences joining them.
