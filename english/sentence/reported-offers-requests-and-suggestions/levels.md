# Levels — Reported Offers, Requests and Suggestions

Same as every lesson in this course: the lesson is taught once,
whole, in lesson/lesson.md, and its level is recorded here. This
lesson has no separate level files; the difficulty of each sub
lesson is marked at its end in the lesson text.

**This lesson's own depth record** — this file records how deep
this lesson goes and how far its learners can climb.

- **Floor (every learner):** report an offer with offered + to,
  a request with asked + person + to, and a suggestion with
  suggested + -ing.
- **Climb:** handle the polite request shapes (can you / could
  you / would you) and the that… and to shapes after suggested.
- **Ceiling (as far as this lesson goes):** hear any offer,
  request or suggestion, name its kind by who does the action,
  and report it with its own verb without mixing the shapes.
