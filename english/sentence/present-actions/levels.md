# Present actions — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the present's two faces — set by
the pattern across the countries' books: the every-day face
first, then the right-now face, then choosing between them.

## Level 1 — the every-day face
Level 1 questions from the type files. Pass mark: build routine
and truth sentences with the plain verb, the -s standing guard
on every he/she/it, and ask them with the engine.

## Level 2 — the right-now face
Level 2 questions from the type files. Pass mark: build be +
-ing sentences whole (both parts showing), sew the -ing
spellings right (running, making), and ask them with the swap.

## Level 3 — choosing the face
Level 3 questions from the type files. Pass mark: read the clue
words and pick the face every time; refuse the -ing coat for
Libya's list (be, like, know, see, understand); retell one scene
in both faces without a slip.
