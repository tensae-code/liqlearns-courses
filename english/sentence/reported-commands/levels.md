# Reported commands — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — retelling
what somebody was told to do — set by the pattern across the
countries' books: the bare shape first (Rwanda's and Mauritania's
single-pattern teaching), then the negative, then the choice of
verb by force (Nepal's four-verb set, Vietnam's eleven).

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Reported Commands Shape
Sub lesson 1 questions from the type files. Pass mark: report
any plain command with told/asked + the person it hit +
to-infinitive, the command's own verb frozen unchanged
behind the to.

## Sub lesson 2 — Reported Commands Negative
Sub lesson 2 questions from the type files. Pass mark:
report any Don't… command with not + to-infinitive, the
not always standing guard before the to — and keep
positive and negative reports apart live, in pairs.

## Sub lesson 3 — Reported Commands Verb Force
Sub lesson 3 questions from the type files. Pass mark: choose
the reporting verb by how the words were said — order,
command, instruct for power; ask for a request; advise
for counsel; warn for danger; encourage, remind, invite,
persuade from the wider bank — without breaking the
shape.
