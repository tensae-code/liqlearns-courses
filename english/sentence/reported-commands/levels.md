# Reported commands — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — retelling what somebody was told to
do — set by the pattern across the countries' books: the bare shape
first (Rwanda's and Mauritania's single-pattern teaching), then the
negative, then the choice of verb by force (Nepal's four-verb set,
Vietnam's eleven).

## Level 1 — the shape: verb + person + to
Level 1 questions from the type files. Pass mark: report
any plain command with told/asked + the person it hit +
to-infinitive, the command's own verb frozen unchanged
behind the to.

## Level 2 — the negative: not before to
Level 2 questions from the type files. Pass mark:
report any Don't… command with not + to-infinitive, the
not always standing guard before the to — and keep
positive and negative reports apart live, in pairs.

## Level 3 — the verb carries the force
Level 3 questions from the type files. Pass mark: choose
the reporting verb by how the words were said — order,
command, instruct for power; ask for a request; advise
for counsel; warn for danger; encourage, remind, invite,
persuade from the wider bank — without breaking the
shape.
