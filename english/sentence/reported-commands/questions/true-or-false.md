# Reported commands — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Reported Commands Shape · (Level 2) -> Sub lesson 2 — Reported Commands Negative · (Level 3) -> Sub lesson 3 — Reported Commands Verb Force.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** In a reported command, the main verb
steps back one tense, like in reported statements.
**Answer: False** — a command has no tense to step
back; it freezes as the infinitive behind to
(Mauritania, p.41).

**2. (Sub lesson 2)** "He told me to not go" is the shape
this lesson teaches for a negative command.
**Answer: False** — the books place the not before the
to: "He told me not to go" (Vietnam Grade 12, Unit 10;
Mauritania, p.41).

**3. (Sub lesson 3)** Rwanda's Pupil's Book 6 also teaches
reported statements and reported questions.
**Answer: False** — its reporting is limited to reported
commands (Unit 9) and direct-speech punctuation
(Unit 6); the filing states the limit plainly.
