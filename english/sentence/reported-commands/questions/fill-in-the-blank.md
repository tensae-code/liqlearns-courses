# Reported commands — fill in the blank

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Reported Commands Shape · (Level 2) -> Sub lesson 2 — Reported Commands Negative · (Level 3) -> Sub lesson 3 — Reported Commands Verb Force.

Fill each gap with the right shape.

**1. (Sub lesson 1)** "Close the window." → The teacher told
us ______ close the window.
**Answer: to** — the command freezes behind to, after
the person it hit.

**2. (Sub lesson 1)** "Be quiet." → She ______ the children
to be quiet.
**Answer: told** — the plain carrier, in its past shape
(Rwanda: tell changed to told, p.115).

**3. (Sub lesson 2)** "Don't run in the corridor." → He told
them ______ ______ run in the corridor.
**Answer: not to** — the negative rides as not +
to-infinitive, not first, always.

**4. (Sub lesson 3)** "You should rest today — doctor's
orders in a soft voice." → The doctor ______ me to rest
that day.
**Answer: advised** — counsel takes advise, one of
Nepal's four verbs and of Vietnam's eleven.
