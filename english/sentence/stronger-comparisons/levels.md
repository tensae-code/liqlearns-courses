# Stronger comparisons — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths (RANKS) inside this one thing — grading a comparison — saying how big the gap is, or that there is no gap at all — set by the
pattern across the countries' books: the shape first, then its job,
then its borders with its neighbours.

## Level 1 — the graders
Level 1 questions from the type files. Pass mark: place a lot / far / much before a comparative for a big gap and a little / a bit / slightly for a small one, with no swaps.

## Level 2 — equality and near-equality
Level 2 questions from the type files. Pass mark: run as…as whole and soften it exactly: almost as…as, not quite as…as, not nearly as…as, exactly the same as.

## Level 3 — adverbs and absolutes
Level 3 questions from the type files. Pass mark: compare adverbs in their own shapes (faster, more carefully, better) and refuse to grade an absolute adjective.
