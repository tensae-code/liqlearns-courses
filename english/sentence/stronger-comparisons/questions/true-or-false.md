# Stronger comparisons — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** "Far" can grade a gap of one centimetre honestly. **Answer: False** — far names a big difference (Egypt, p.26); a one-centimetre gap takes a little / a bit / slightly.

**2. (Level 2)** "Exactly the same as" means no difference at all. **Answer: True** — it is the limiting case that opens Egypt's Comparative Phrases box, p.26.

**3. (Level 3)** "A more perfect answer" is the normal, rule-following way to grade perfect. **Answer: False** — perfect is absolute and takes no more/most; Egypt's book quotes "a more perfect union" as a rhetorical exception, not the rule.
