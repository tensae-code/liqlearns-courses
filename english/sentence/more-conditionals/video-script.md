# Video script — More conditionals

Super-simple voice. Read slow. The learner hears this
before or beside the written lesson.

---

You know the if machine.
If it rains, we will stay home.
If I had wings, I would fly.
If I had left early, I would have caught the bus.

Now we mix the machine.

A thing in the past. A result NOW.
If I had studied, I would be a doctor now.
Past in the if half. Now in the other half.

And the other mix.
A thing that is true NOW. A result in the past.
If I were not afraid, I would have asked her yesterday.
Now in the if half. Past in the other half.

Each half keeps its own time. That is a MIXED conditional.

Now take IF away.
If I had known — Had I known.
The helper steps first. The meaning is the same.
Had I known, I would have come.
Were I you, I would rest.
Should you need help, call me.
No if. Still a condition. This is INVERSION.

Two more gate-words.
UNLESS means if not.
Unless you hurry, you will be late.
If you don't hurry, you will be late. Same gate.

PROVIDED THAT means if — with a condition like a rule.
You may go, provided that you are back by nine.

And one small word: WERE.
If I were you. If she were here.
Were for every person, in the unreal world.

Now you try.
Mix one. Past reason, result now.
Drop one if. Had I…
Say one warning with unless.
