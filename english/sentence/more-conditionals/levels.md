# More conditionals — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the conditional machine's
advanced gears — set by the pattern across the countries'
books: mixing first (Armenia and Malaysia teach mixed forms
as their conditional peak), then the if-less forms (Nepal
and Syria), then the gate-words and were.

## Level 1 — mixed conditionals
Level 1 questions from the type files. Pass mark: build
both mixes — past condition with present result, present
condition with past result — and name the time of each
half out loud.

## Level 2 — inverted conditionals
Level 2 questions from the type files. Pass mark: build
and rebuild Had I…, Were I…, Should you… — drop if, step
the helper first, and put if back without changing the
meaning.

## Level 3 — unless, provided that, and subjunctive were
Level 3 questions from the type files. Pass mark: swap
if…not ↔ unless and if ↔ provided that in live
sentences, and hold were for every who in unreal
conditions and wishes.
