# More conditionals — matching

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Mixed Conditionals · (Level 2) -> Sub lesson 2 — Inverted Conditionals · (Level 3) -> Sub lesson 3 — Unless and Provided That, except items about subjunctive were, which are Sub lesson 4 — Subjunctive Were.

Match each sentence to its name.

**1. (Sub lesson 1)** "If I had slept well, I would feel fine now." **Answer: a mixed conditional (past → present)** — had slept is past; would feel is now (Armenia, §6.2).

**2. (Sub lesson 2)** "Had she called, we would have known." **Answer: an inverted conditional** — if is dropped and had steps first; with if it reads "If she had called…" (Syria, G12 U12).

**3. (Sub lesson 3)** "Unless it rains, we will play outside." **Answer: a first conditional with unless** — unless = if…not: if it does not rain, we will play.
