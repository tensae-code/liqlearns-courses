# More conditionals — matching

Match each sentence to its name.

**1. (Level 1)** "If I had slept well, I would feel fine now." **Answer: a mixed conditional (past → present)** — had slept is past; would feel is now (Armenia, §6.2).

**2. (Level 2)** "Had she called, we would have known." **Answer: an inverted conditional** — if is dropped and had steps first; with if it reads "If she had called…" (Syria, G12 U12).

**3. (Level 3)** "Unless it rains, we will play outside." **Answer: a first conditional with unless** — unless = if…not: if it does not rain, we will play.
