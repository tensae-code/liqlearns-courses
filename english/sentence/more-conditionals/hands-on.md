# Hands-on — More conditionals

You do it, we guide you. Everything here is done with a
companion or the Explain Companion, out loud.

1. **The chain of my life.** Tell one true chain: a past
   choice, and its result that is still true today (a
   school chosen, a move, a missed chance). Say it as a
   mixed conditional — If I hadn't…, I wouldn't be… now.
   Then flip it: a true thing about you now, and a past
   result it changed — If I weren't…, I would have…
2. **If on, if off.** The companion says a third
   conditional with if (If I had known…). You must say
   it back with if OFF (Had I known…). Five rounds, then
   swap. Any round where the meaning moves is replayed.
3. **Gate-word warnings.** Make five kind warnings for
   your home — about the stove, the door, the rain.
   Say each twice: once with unless, once with
   provided that. (Provided that sounds like a rule —
   use it for the serious ones.)
4. **Were for everyone.** Go around the room: point at
   each person and wish in their place — If I were
   you… If she were me… Were stays were for every who,
   five people in a row, no was allowed.
