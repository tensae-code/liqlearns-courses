# Quantifiers — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
saying how much without a number — set by the pattern across the
countries' books: some/any and much/many first (Cambodia and
Malaysia open there), then the judging words, then the
partitives that let you shop.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3. One
overlap: the old Level 2 ground a few / a little is taught in a
paragraph that also teaches much/many, so that paragraph stands
whole in Sub lesson 1's text; Sub lesson 2's pass mark below
still carries a few / a little, as the old layer did.
