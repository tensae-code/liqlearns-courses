# Object clauses — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS
(2026-11-08 restructure — README, "Units, Lessons and Sub Lessons").
Practice is tied to the skill number, as before. The questions live in
the type files; this file is the by-sub-lesson view. The sub lessons are
the depths inside this one thing — a clause doing the object job — set
by the pattern across the countries' books: that-clauses first (China's
Unit 2, Albania's guide), then the question carriers (China's Units
2–3), then the certainty frames and the reported-speech boundary
(Nepal's guide, the filings' own distinctions).

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level
2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Object clauses — that-clauses

Sub lesson 1 questions from the type files. Pass mark: build
a that-clause after a verb of thinking or saying and
after sure/certain, and drop that correctly where the
books allow.

## Sub lesson 2 — Object clauses — carrying questions

Sub lesson 2 questions from the type files. Pass mark: turn
a yes/no question into an if/whether clause and a wh-
question into a wh- clause, both in statement word
order, inside polite requests and plain statements.

## Sub lesson 3 — Object clauses — the boundary

Sub lesson 3 questions from the type files. Pass mark:
sort object clauses from reported speech and say why;
use certainty frames (I'm sure that…, There's no doubt
that…) with the right strength; and keep every carrier
word in its own job.
