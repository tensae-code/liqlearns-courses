# Object clauses — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — a clause doing the object job — set
by the pattern across the countries' books: that-clauses first
(China's Unit 2, Albania's guide), then the question carriers
(China's Units 2–3), then the certainty frames and the
reported-speech boundary (Nepal's guide, the filings' own
distinctions).

## Level 1 — that-clauses
Level 1 questions from the type files. Pass mark: build
a that-clause after a verb of thinking or saying and
after sure/certain, and drop that correctly where the
books allow.

## Level 2 — carrying questions
Level 2 questions from the type files. Pass mark: turn
a yes/no question into an if/whether clause and a wh-
question into a wh- clause, both in statement word
order, inside polite requests and plain statements.

## Level 3 — the boundary
Level 3 questions from the type files. Pass mark:
sort object clauses from reported speech and say why;
use certainty frames (I'm sure that…, There's no doubt
that…) with the right strength; and keep every carrier
word in its own job.
