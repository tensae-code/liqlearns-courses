# Object clauses — fill in the blank

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Object clauses — that-clauses · (Level 2) -> Sub lesson 2 — Object clauses — carrying questions · (Level 3) -> Sub lesson 3 — Object clauses — the boundary.

Fill each gap with the right carrier.

**1. (Sub lesson 1)** I'm sure ______ the bus will come. (certainty frame)
**Answer: that** — certainty adjectives carry a that-clause: I'm sure that… (Nepal, Teachers' Guide, Unit 16).

**2. (Sub lesson 2)** Could you tell me where the bank ______ ? (statement order)
**Answer: is** — inside an object clause the question flips back to statement order — no inversion, no do.

**3. (Sub lesson 3)** Ask him ______ he wants tea or coffee. (a choice is in the air)
**Answer: whether** — whether is the carrier when an or-choice stands behind the question.
