# Object clauses — short answer

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Object clauses — that-clauses · (Level 2) -> Sub lesson 2 — Object clauses — carrying questions · (Level 3) -> Sub lesson 3 — Object clauses — the boundary.

Answer in whole sentences.

**1. (Sub lesson 1)** Write a that-clause sentence about tomorrow's weather with think, dropping that.
**Answer: I think it will rain tomorrow.** — think is one of the common verbs that let that drop (China, Grammar Reference).

**2. (Sub lesson 2)** Carry the question inside a request: "Where are the restrooms?"
**Answer: Could you please tell me where the restrooms are?** — China's own Unit 3 pattern — wh- clause, statement order, no flip.

**3. (Sub lesson 3)** Say the same fact through both doors: object clause with know; reported speech with said. ("She is tired.")
**Answer: I know that she is tired. / She said that she was tired.** — know keeps the present is; said backshifts to was — the doors differ in frame and tense.
