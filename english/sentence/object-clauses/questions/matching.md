# Object clauses — matching

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Object clauses — that-clauses · (Level 2) -> Sub lesson 2 — Object clauses — carrying questions · (Level 3) -> Sub lesson 2 — Object clauses — carrying questions.

Match each beginning to its right kind of ending.

**1. (Sub lesson 1)** "I hope…"
**Answer: a that-clause — I hope that you will come.** — hope takes a statement-clause as its object.

**2. (Sub lesson 2)** "Tell me…" + the question "Is she ready?"
**Answer: Tell me if she is ready. (or whether)** — the yes/no question rides in with if/whether, in statement order.

**3. (Sub lesson 2)** "I don't know…" + "whose pen is this?"
**Answer: I don't know whose pen it is.** — the wh- clause as a noun clause — South Africa's own Grade 4 example (Workbook 2, p.99).
