# Object clauses — multiple choice

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Object clauses — that-clauses · (Level 2) -> Sub lesson 2 — Object clauses — carrying questions · (Level 3) -> Sub lesson 3 — Object clauses — the boundary.

Pick the one right answer.

**1. (Sub lesson 1)** Which sentence carries an object clause? a) The shop is open. b) I think that the shop is open. c) Open the shop, please.
**Answer: b)** — the that-clause is the object of think — it says WHAT I think (China, Grade 9, Unit 2).

**2. (Sub lesson 1)** Which is the careful written form after a less common verb? a) I whispered that I was ready. b) I whispered I ready. c) I whispered that ready I was.
**Answer: a)** — that is dropped only after the commonest verbs in easy speech; keep it elsewhere (China, Grammar Reference, pp.151–152).

**3. (Sub lesson 2)** "Tell me ___ he is coming." (a yes/no question carried inside) a) if b) that c) what
**Answer: a)** — if/whether carry yes/no questions; that carries statements (China, Grade 9, Unit 2).

**4. (Sub lesson 3)** Which sentence is REPORTED speech, not an object clause? a) I know that she is tired. b) She said that she was tired. c) I'm sure that she is tired.
**Answer: b)** — said + backshifted was = words replayed under a reporting frame; the others carry present thoughts (Albania filing, §6).
