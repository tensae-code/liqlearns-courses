# Stative verbs — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths (RANKS) inside this one thing — the verbs that name a state and refuse -ing, and the linking verbs that carry a description — set by the
pattern across the countries' books: the shape first, then its job,
then its borders with its neighbours.

## Level 1 — the sort
Level 1 questions from the type files. Pass mark: name the four stative families (thinking, feeling, owning, sensing) and sort a mixed verb list without a miss.

## Level 2 — the coats
Level 2 questions from the type files. Pass mark: keep statives in the simple coat in statements and questions, and move have/see/think between coats as their meaning moves.

## Level 3 — the bridges
Level 3 questions from the type files. Pass mark: build subject + linking verb + adjective sentences with be, seem, look, feel and sound, and repair *she looks tiredly*-type errors live.
