# Adjective order — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths (RANKS) inside this one thing — the fixed stacking order of adjectives before a noun — set by the
pattern across the countries' books: the shape first, then its job,
then its borders with its neighbours.

## Level 1 — the shelf
Level 1 questions from the type files. Pass mark: name the eight boxes in order — quantity, quality, size, shape, age, colour, nationality, material — and place any single adjective in its box.

## Level 2 — short stacks
Level 2 questions from the type files. Pass mark: build two- and three-adjective stacks in order (size–age–colour; quality–material–origin) with no swaps.

## Level 3 — long stacks and repairs
Level 3 questions from the type files. Pass mark: build the books' full worked stack and repair any scrambled stack live, naming the box each word moved to.
