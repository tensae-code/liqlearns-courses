# Adjective order — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — the
fixed stacking order of adjectives before a noun — set by the
pattern across the countries' books: the line first, then the
discovery examples and the second table, then using the line on
long stacks and repairs.

item, so a book-example item sits with the sub lesson that
carries that example.
