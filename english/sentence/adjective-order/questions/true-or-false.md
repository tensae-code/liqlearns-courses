# Adjective order — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to, by what the item actually asks. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Adjective Order — the Line · (Level 2) -> Sub lesson 3 — Adjective Order — a Second Table Agrees, for the Sudan/Bolivia agreement item · (Level 3) -> Sub lesson 4 — Using the Adjective Order, for the same-box adjectives item.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** In a stack, material stands farther from the noun than colour. **Answer: False** — material is the LAST box, nearest the noun — a red plastic shoe, never *a plastic red shoe*.

**2. (Sub lesson 3)** Sudan's order and Bolivia's order agree on the shared boxes. **Answer: True** — both run quality/opinion – size – (shape) – age – colour – nationality – material; Bolivia adds quantity first, as filed.

**3. (Sub lesson 4)** Two adjectives from the SAME box must always be separated by the full line. **Answer: False** — same-box adjectives are equals; the books' own examples join equals with a comma — "a big, modern TV" (Cambodia, Unit 21).
