# Adjective order — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** In a stack, material stands farther from the noun than colour. **Answer: False** — material is the LAST box, nearest the noun — a red plastic shoe, never *a plastic red shoe*.

**2. (Level 2)** Sudan's order and Bolivia's order agree on the shared boxes. **Answer: True** — both run quality/opinion – size – (shape) – age – colour – nationality – material; Bolivia adds quantity first, as filed.

**3. (Level 3)** Two adjectives from the SAME box must always be separated by the full line. **Answer: False** — same-box adjectives are equals; the books' own examples join equals with a comma — "a big, modern TV" (Cambodia, Unit 21).
