# Adjective order — short answer

Answer in a word or a whole sentence, as asked.

**1. (Level 1)** Stack these for a table, in order: wooden, small, square. Say the whole phrase. **Answer: "a small square wooden table"** — size – shape – material, then the noun.

**2. (Level 2)** Describe one real thing you own with three adjectives in order, and name each box. **Answer: (Learner's own true stack, boxes named correctly)** — the words must stand on the line: quality/opinion before size before age before colour before origin before material.

**3. (Level 3)** Why does "a brown old small bag" sound broken, when every word is right? One line. **Answer: The adjectives stand off the fixed line — English orders stacked adjectives: size before age before colour.** — the order, not the words, is the rule (Mongolia's discovery; Bolivia's table).
