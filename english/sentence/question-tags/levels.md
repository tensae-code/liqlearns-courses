# Question tags — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the little checking question on a
statement's tail — set by the pattern across the countries' books:
the mirror rule first (Mauritania and Mongolia both open with the
polarity flip), then the special cases (Egypt's eight-rule box),
then the two voices (Kuwait's intonation guidance).

## Level 1 — the mirror rule
Level 1 questions from the type files. Pass mark: tag
any plain statement — positive takes a negative tag,
negative takes a positive tag — copying the statement's
own auxiliary, and bring in do/does/did when the
statement has no auxiliary to copy.

## Level 2 — the special cases
Level 2 questions from the type files. Pass mark: run
the exceptions without a miss — aren't I for I am,
shall we for Let's, will/won't you for commands, and
the indefinite crowd (somebody, everybody, nobody,
everyone) answered by they in the tag.

## Level 3 — negative words and the two voices
Level 3 questions from the type files. Pass mark: spot
the hidden negative (never, seldom, rarely, few, little)
and give it a positive tag — and choose the voice on
purpose: rising when you truly do not know, falling when
you are checking what you already believe.
