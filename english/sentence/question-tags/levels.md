# Question tags — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — the little
checking question on a statement's tail — set by the pattern
across the countries' books: the mirror rule first (Mauritania and
Mongolia both open with the polarity flip), then the special cases
(Egypt's eight-rule box), then the two voices (Kuwait's intonation
guidance).

old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Question Tags Mirror Rule
Sub lesson 1 questions from the type files. Pass mark: tag
any plain statement — positive takes a negative tag,
negative takes a positive tag — copying the statement's
own auxiliary, and bring in do/does/did when the
statement has no auxiliary to copy.

## Sub lesson 3 — Question Tags Negative Words and Two Voices
