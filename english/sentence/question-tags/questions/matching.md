# Question tags — matching

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Question Tags Mirror Rule · (Level 2) -> Sub lesson 2 — Question Tags Special Cases · (Level 3) -> Sub lesson 3 — Question Tags Negative Words and Two Voices.

Match each statement to its tag.

**1. (Sub lesson 1)** "She has left, ______?" **Answer:
hasn't she** — the tag copies the perfect auxiliary has
and flips it negative.

**2. (Sub lesson 2)** "Open the window, ______?" **Answer:
will you (or won't you)** — commands take will you?,
or the softer inviting won't you?

**3. (Sub lesson 3)** "Few people know this road, ______?"
**Answer: do they** — few is a hidden negative, so the
tag is positive; people-words answer to they, and a
plain present statement brings do-support.
