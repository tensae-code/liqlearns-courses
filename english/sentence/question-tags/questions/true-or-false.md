# Question tags — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Question Tags Mirror Rule · (Level 2) -> Sub lesson 2 — Question Tags Special Cases · (Level 3) -> Sub lesson 3 — Question Tags Negative Words and Two Voices.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** A positive statement takes a positive
tag.
**Answer: False** — the tag flips the sign: a positive
statement takes a negative tag, a negative statement a
positive one (the mirror rule).

**2. (Sub lesson 2)** "Let's start now, shall we?" is a
correct tag sentence.
**Answer: True** — Let's always takes shall we (Egypt's
eight-rule box; Mauritania, pp.46–47).

**3. (Sub lesson 3)** When the tag's voice RISES, the speaker
is almost sure and only wants agreement.
**Answer: False** — rising is the real question: the
speaker does not know. The falling voice is the check
that expects agreement (Kuwait, Pearls 9B, p.57).
