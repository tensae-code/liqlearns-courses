# Subject and object questions — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — asking
after the doer or the done-to — set by the pattern across the
countries' books: object questions first, as Cambodia's Grade 11
course itself teaches them (Unit 31A before 31B), then the subject
shape and the distinguishing test, then the negative question that
Malaysia's Form 3 lists beside them.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Object Questions
Sub lesson 1 questions from the type files. Pass mark: build
object questions with the helper in front — Who did you
see? What did she buy? — for who, what and which, in
present and past.

## Sub lesson 2 — Subject Questions
Sub lesson 2 questions from the type files. Pass mark: build
subject questions with no do/does/did and the verb in
its statement shape, -s included (Who lives here? Who
broke it?) — and pass the answer test: name, for any
question, whether the missing piece is the doer or the
done-to.

## Sub lesson 3 — Both Shapes and Negative Questions
Sub lesson 3 questions from the type files. Pass mark: hold
both shapes against each other on one event without
mixing them — and use a negative question (Didn't
you…? Aren't you…?) as the surprised check it is, not
as an ordinary question.
