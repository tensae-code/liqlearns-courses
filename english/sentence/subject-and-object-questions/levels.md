# Subject and object questions — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — asking after the doer or the
done-to — set by the pattern across the countries' books: object
questions first, as Cambodia's Grade 11 course itself teaches them
(Unit 31A before 31B), then the subject shape and the distinguishing
test, then the negative question that Malaysia's Form 3 lists beside
them.

## Level 1 — object questions: the ordinary machine
Level 1 questions from the type files. Pass mark: build
object questions with the helper in front — Who did you
see? What did she buy? — for who, what and which, in
present and past.

## Level 2 — subject questions: no helper
Level 2 questions from the type files. Pass mark: build
subject questions with no do/does/did and the verb in
its statement shape, -s included (Who lives here? Who
broke it?) — and pass the answer test: name, for any
question, whether the missing piece is the doer or the
done-to.

## Level 3 — both shapes live, and the negative question
Level 3 questions from the type files. Pass mark: hold
both shapes against each other on one event without
mixing them — and use a negative question (Didn't
you…? Aren't you…?) as the surprised check it is, not
as an ordinary question.
