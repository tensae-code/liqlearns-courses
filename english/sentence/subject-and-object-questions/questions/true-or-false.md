# Subject and object questions — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Object Questions · (Level 2) -> Sub lesson 2 — Subject Questions · (Level 3) -> Sub lesson 3 — Both Shapes and Negative Questions.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** "Who did you see?" and "Who saw you?"
ask for the same person.
**Answer: False** — the first hunts the done-to (the one
seen), the second hunts the doer (the one who saw);
the answer test tells them apart.

**2. (Sub lesson 2)** "Who did break the cup?" is the ordinary
way to ask who broke it.
**Answer: False** — a subject question takes no helper:
"Who broke the cup?" The did-shape lives only in
emphasis, never in ordinary asking (Cambodia, Grade 11,
Unit 31B).

**3. (Sub lesson 3)** A negative question like "Aren't you
coming?" usually means the speaker expected the answer
yes.
**Answer: True** — negative questions check in surprise
or press for the expected yes; Malaysia's Form 3 lists
them beside subject and object questions (Unit 7).
