# Hands-on — Non-defining relative clauses

You do it, we guide you. Everything here is done with a
companion or the Explain Companion, out loud first.

1. **The lift-out game.** The learner says a sentence
   with an extra-information clause. The companion
   repeats ONLY the main sentence, hands cupping the
   clause away. If the main sentence still names its
   person or thing fully, the clause scores; if the
   companion must ask "which one?", it was defining —
   rebuild it with a name so it turns non-defining.
   (Vietnam Grade 9, Unit 10's test, played live.)
2. **Name cards.** Write five name cards — a teacher, a
   town, a famous person, a pet, a book. For each card,
   add one spoken extra fact between commas: "Mr An,
   who taught my father, …" No that, no dropped pronoun
   — the companion polices the three rules.
3. **Whole-sentence comments.** The companion narrates
   small events ("The bus was late." "Our team won."
   "The shop was closed."). The learner answers each
   with a which-comment: "…, which annoyed everyone."
   Five events, five comments.
4. **The comma hands.** Write three of your sentences
   on paper and draw the two comma "hands" around each
   clause; then read each sentence twice — once whole,
   once with the clause covered — and check both
   readings stand.
