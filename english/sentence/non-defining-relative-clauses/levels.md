# Non-defining relative clauses — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — extra
information between commas — set by the pattern across the
countries' books: the commas and the lift-out test first (Vietnam
Grade 9 states both outright), then the three hard rules, then the
whole-sentence which and the preposition corner.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Non-Defining Relative Clauses Extra Information and Commas
Sub lesson 1 questions from the type files. Pass mark: spot
a non-defining clause, read it with its commas, and
pass the lift-out test — remove it and show the
sentence still stands and still names its noun fully.

## Sub lesson 2 — Non-Defining Relative Clauses Three Hard Rules
Sub lesson 2 questions from the type files. Pass mark: build
extra-information clauses where the commas stay, that
never enters, and the pronoun is never dropped —
including whose between commas (Egypt, Secondary 11,
Grammar Box p.77).

## Sub lesson 3 — Non-Defining Relative Clauses Whole-Sentence Which
Sub lesson 3 questions from the type files. Pass mark:
comment on a whole sentence with which (Vietnam
Grade 12, Unit 3), and handle a fronted preposition
(the man to whom…) without losing the commas (Yemen,
Pupil's Book 6, Language review 4).
