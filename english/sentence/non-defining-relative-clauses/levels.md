# Non-defining relative clauses — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — extra information between commas —
set by the pattern across the countries' books: the commas and
the lift-out test first (Vietnam Grade 9 states both outright),
then the three hard rules, then the whole-sentence which and the
preposition corner.

## Level 1 — extra information and its commas
Level 1 questions from the type files. Pass mark: spot
a non-defining clause, read it with its commas, and
pass the lift-out test — remove it and show the
sentence still stands and still names its noun fully.

## Level 2 — the three hard rules
Level 2 questions from the type files. Pass mark: build
extra-information clauses where the commas stay, that
never enters, and the pronoun is never dropped —
including whose between commas (Egypt, Secondary 11,
Grammar Box p.77).

## Level 3 — the whole-sentence which
Level 3 questions from the type files. Pass mark:
comment on a whole sentence with which (Vietnam
Grade 12, Unit 3), and handle a fronted preposition
(the man to whom…) without losing the commas (Yemen,
Pupil's Book 6, Language review 4).
