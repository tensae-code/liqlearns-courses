# Used to and would — multiple choice

Pick the one right answer.

**1. (Level 1)** Which sentence tells a finished past state? a) I would live in a village. b) I used to live in a village. c) I am used to live in a village.
**Answer: b)** — states take used to only; would never carries a situation (Egypt, Secondary 11, p.29).

**2. (Level 1)** Correct question: a) Did you used to play here? b) Did you use to play here? c) Do you used to play here?
**Answer: b)** — did carries the past, so use to stands bare — Egypt's Primary 6 paradigm (p.67).

**3. (Level 2)** "When we were children, we ___ climb that tree every day." (repeated action) a) would b) are used to c) use to be
**Answer: a)** — would replays repeated past actions once the past scene is set.

**4. (Level 3)** "I'm getting used to ___ up early." a) get b) getting c) got
**Answer: b)** — be/get used to takes an -ing word (or a noun), never a base verb (Cambodia, Grade 12, Unit 28).
