# Used to and would — multiple choice

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Used to and would — the finished past · (Level 2) -> Sub lesson 2 — Used to and would — would for repeated actions · (Level 3) -> Sub lesson 3 — Used to and would — the accustomed family.

Pick the one right answer.

**1. (Sub lesson 1)** Which sentence tells a finished past state? a) I would live in a village. b) I used to live in a village. c) I am used to live in a village.
**Answer: b)** — states take used to only; would never carries a situation (Egypt, Secondary 11, p.29).

**2. (Sub lesson 1)** Correct question: a) Did you used to play here? b) Did you use to play here? c) Do you used to play here?
**Answer: b)** — did carries the past, so use to stands bare — Egypt's Primary 6 paradigm (p.67).

**3. (Sub lesson 2)** "When we were children, we ___ climb that tree every day." (repeated action) a) would b) are used to c) use to be
**Answer: a)** — would replays repeated past actions once the past scene is set.

**4. (Sub lesson 3)** "I'm getting used to ___ up early." a) get b) getting c) got
**Answer: b)** — be/get used to takes an -ing word (or a noun), never a base verb (Cambodia, Grade 12, Unit 28).
