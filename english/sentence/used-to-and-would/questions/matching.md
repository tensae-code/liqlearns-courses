# Used to and would — matching

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Used to and would — the finished past · (Level 2) -> Sub lesson 2 — Used to and would — would for repeated actions · (Level 3) -> Sub lesson 3 — Used to and would — the accustomed family.

Match each sentence to its family.

**1. (Sub lesson 1)** "I used to have long hair."
**Answer: used to — a finished past state** — have is a state; used to carries it, would cannot.

**2. (Sub lesson 2)** "He wouldn't help us, however often we asked."
**Answer: would — refusal** — wouldn't is would's refusal face (Egypt, Secondary 11, p.29).

**3. (Sub lesson 3)** "She is used to working at night."
**Answer: be used to — accustomed now** — present custom, not past habit: be used to + -ing (Malaysia, Form 3, p.25).
