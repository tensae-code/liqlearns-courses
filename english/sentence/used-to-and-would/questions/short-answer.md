# Used to and would — short answer

Answer in whole sentences.

**1. (Level 1)** Ask your partner a question about a past habit with use to.
**Answer: Did you use to walk to school? (any Did you use to…? question)** — did + use to bare — the standard question form.

**2. (Level 2)** One scene, two forms: set the past with used to, then give one repeated action with would.
**Answer: We used to spend summers at the lake. Every morning we would swim before breakfast.** — used to opens the finished past; would replays its repeated actions — no states with would.

**3. (Level 3)** Explain the difference: "I used to work nights" vs "I am used to working nights".
**Answer: The first is finished — I worked nights before, not now. The second is accustomed — I work nights now and it is normal for me.** — used to + base verb = past only; be used to + -ing = present custom.
