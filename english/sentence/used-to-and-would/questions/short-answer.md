# Used to and would — short answer

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Used to and would — the finished past · (Level 2) -> Sub lesson 2 — Used to and would — would for repeated actions · (Level 3) -> Sub lesson 3 — Used to and would — the accustomed family.

Answer in whole sentences.

**1. (Sub lesson 1)** Ask your partner a question about a past habit with use to.
**Answer: Did you use to walk to school? (any Did you use to…? question)** — did + use to bare — the standard question form.

**2. (Sub lesson 2)** One scene, two forms: set the past with used to, then give one repeated action with would.
**Answer: We used to spend summers at the lake. Every morning we would swim before breakfast.** — used to opens the finished past; would replays its repeated actions — no states with would.

**3. (Sub lesson 3)** Explain the difference: "I used to work nights" vs "I am used to working nights".
**Answer: The first is finished — I worked nights before, not now. The second is accustomed — I work nights now and it is normal for me.** — used to + base verb = past only; be used to + -ing = present custom.
