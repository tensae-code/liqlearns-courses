# Used to and would — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Used to and would — the finished past · (Level 2) -> Sub lesson 2 — Used to and would — would for repeated actions · (Level 3) -> Sub lesson 3 — Used to and would — the accustomed family.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** "Did you used to…?" is the correct question form.
**Answer: False** — did already carries the past: Did you USE to…? (Egypt, Primary 6, p.67).

**2. (Sub lesson 2)** Would can be used for a past state: "We would live in a small house."
**Answer: False** — would serves repeated actions and typical behaviour, NOT past situations or stative verbs (Egypt, p.29; Cambodia, Grade 12, Unit 4).

**3. (Sub lesson 3)** Afghanistan's Grade 11 book says used to must never appear in a question or a negative, and that rule is standard English.
**Answer: False** — the book does print that rule (pp.68–70), but it is non-standard — Egypt and Cambodia print and use Did you use to…? / didn't use to freely; the course corrects it.
