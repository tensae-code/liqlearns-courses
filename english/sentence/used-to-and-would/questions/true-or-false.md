# Used to and would — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** "Did you used to…?" is the correct question form.
**Answer: False** — did already carries the past: Did you USE to…? (Egypt, Primary 6, p.67).

**2. (Level 2)** Would can be used for a past state: "We would live in a small house."
**Answer: False** — would serves repeated actions and typical behaviour, NOT past situations or stative verbs (Egypt, p.29; Cambodia, Grade 12, Unit 4).

**3. (Level 3)** Afghanistan's Grade 11 book says used to must never appear in a question or a negative, and that rule is standard English.
**Answer: False** — the book does print that rule (pp.68–70), but it is non-standard — Egypt and Cambodia print and use Did you use to…? / didn't use to freely; the course corrects it.
