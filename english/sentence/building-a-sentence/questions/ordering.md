# Building a sentence — ordering

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Whole or Waiting · (Level 2) -> Sub lesson 2 — The Two Parts · (Level 3) -> Sub lesson 3 — Order and Growth.
Stand the words in sentence order. (This question type
exists for this lesson because a sentence IS words in order —
Mongolia's self-checks drill it as "word order.")

**1. (Sub lesson 1)** eats / the cow / grass
**Answer:** The cow eats grass.

**2. (Sub lesson 1)** sleeps / the cat
**Answer:** The cat sleeps.

**3. (Sub lesson 2)** in a nest / lives / the crow
**Answer:** The crow lives in a nest (Bangladesh, pp.86–87).

**4. (Sub lesson 2)** at six o'clock / gets up / Mita
**Answer:** Mita gets up at six o'clock.

**5. (Sub lesson 3)** the grapes / are / sweet / very
**Answer:** The grapes are very sweet — subject, verb, then
the describing rest in its place.

**6. (Sub lesson 3)** meat / grass / the cow / eats / not / does
**Answer:** The cow does not eat meat — she eats grass
(Bolivia's negative runs with the formula: do/does not rides
after the subject).
