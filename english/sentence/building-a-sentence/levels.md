# Building a sentence — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the sentence — set by the pattern
across the countries' books: whole-or-waiting first, then the two
parts, then order with longer complements.

## Level 1 — whole or waiting
Level 1 questions from the type files. Pass mark: judge any short
line as a sentence or a waiting-piece, and say which leg is
missing when it waits.

## Level 2 — the two parts
Level 2 questions from the type files. Pass mark: split plain
sentences into subject and verb (+ complement), and build true
sentences from a three-column table, row after row.

## Level 3 — order and growth
Level 3 questions from the type files. Pass mark: unjumble
sentences of five-plus words, grow a bare subject+verb with a
complement of your own, and catch the order-flip that changes
the meaning ("Grass eats the cow").
