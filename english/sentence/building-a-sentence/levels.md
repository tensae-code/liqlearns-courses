Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson

Sub lesson 1 questions from the type files. Pass mark: judge any short

## Sub lesson 2 — The Two Parts
Sub lesson 2 questions from the type files. Pass mark: split plain

## Sub lesson 3 — Order and Growth
Sub lesson 3 questions from the type files. Pass mark: unjumble
