# True or false — Time Clauses

(Gate pool: all questions of the sub lesson(s) named — no hardness ranking is written here, so a sub lesson's whole question set is its gate pool.)

1. A time clause can come before or after the main clause.
   **Answer: True** (Sub lesson 1)

2. "As soon as" means "during a long time".
   **Answer: False** — it means immediately after. (Sub lesson 1)

3. "When I will arrive, we will eat" is correct.
   **Answer: False** — no will inside the time clause: "When I arrive…" (Sub lesson 2)

4. In "When I had finished, I slept", finishing is the earlier action.
   **Answer: True** (Sub lesson 2)
