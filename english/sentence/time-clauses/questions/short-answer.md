# Short answer — Time Clauses

(Gate pool: all questions of the sub lesson(s) named — no hardness ranking is written here, so a sub lesson's whole question set is its gate pool.)

1. Join with "when": "The lesson ended. We went home."
   **Answer:** When the lesson ended, we went home. (or: We went home when the lesson ended.) (Sub lesson 1)

2. Which time word fits both: "___ I was walking home, it started to rain" — while or as soon as?
   **Answer:** while (or as) — as soon as cannot hold a long action. (Sub lesson 1)

3. Fix the sentence: "When I will see him tomorrow, I will tell him."
   **Answer:** When I see him tomorrow, I will tell him. (Sub lesson 2)

4. Write one true sentence about tomorrow with "as soon as".
   **Answer:** Any sentence with a present-form time clause and a will main clause, e.g. "As soon as school finishes, I will go home." (Sub lesson 2)
