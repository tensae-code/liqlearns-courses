# Conditionals — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the if-machine — set by the
pattern across the countries' books: all three countries open
with the always-true and really-possible rungs; the imagined rung
comes next everywhere; the unchangeable-past rung closes the
ladder, exactly where Egypt's three-year climb puts it.

## Level 1 — zero and first
Level 1 questions from the type files. Pass mark: build
zero (if + present, present) and first (if + present,
will + verb) without mixing coats, halves in either
chair — and never let will into the if-half.

## Level 2 — the imagined rung and the dial
Level 2 questions from the type files. Pass mark: build
the second conditional (if + past, would + verb) for
dreams, wishes and advice; run the dial — will for high
possibility, may/might for lower (Libya, p.80); and swap
unless ↔ if…not without moving the meaning.

## Level 3 — the unchangeable past
Level 3 questions from the type files. Pass mark: build
the third conditional whole (if + had + participle,
would have + participle) for a real regret or missed
chance, and choose the right rung live across all four —
a law, a plan, a dream, a regret — coats exact every
time.
