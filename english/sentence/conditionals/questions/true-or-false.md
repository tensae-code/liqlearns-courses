# Conditionals — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 2 — The First Conditional — Really Possible (item 1, will in the if-half) · (Level 2) -> Sub lesson 3 — The Second Conditional — Imagined (item 2) and Sub lesson 2 (item 3, unless) · (Level 3) -> Sub lesson 4 — The Third Conditional — the Unchangeable Past (item 4), and item 5, the books' split over the zero rung's name -> Sub lesson 4, where the split is taught.

Say true or false. If it is false, say why.

**1. (Sub lesson 2)** "If it will rain tomorrow, we will
stay home" is correct.
**False** — will never enters the if-half of the first
conditional; the if-half wears the present: "If it
rains tomorrow…" (Libya, Grade 9, p.80).

**2. (Sub lesson 3)** In "If I had wings, I would fly," the
past coat talks about yesterday.
**False** — on the second rung the past coat marks the
unreal, not the past: the speaker has no wings NOW.

**3. (Sub lesson 2)** Unless means the same as if…not.
**True** — "Unless you hurry" = "If you don't hurry"
(Mongolia, English IX, Unit 7).

**4. (Sub lesson 4)** The third conditional can change what
happened.
**False** — it only talks about the different result
that could have happened, but didn't; the past itself
never moves (Egypt, Prep 9 T1, Tip p.31).

**5. (Sub lesson 4)** Egypt's books call the always-true
rung the "zero conditional."
**False** — Egypt's run states three rungs (first,
second, third) and never names a zero conditional;
Libya and Mongolia name all four. The machine is the
same; the names differ.
