# Introductory There — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and
Sub Lessons"). The lesson was built new in the restructure
era (Bangladesh re-verification sweep merge, 2026-11-08), so
there are no old depth layers to map: the sub lessons below
are its depths as built, cut at the pattern's own joints —
the opener itself, the one-thing form, and the more-than-one
form with the choosing rule. The questions live in the type
files; this file is the by-sub-lesson view.

Pass marks: the book names the pattern in its Language
Point box but states no pass mark for it, so no mark is
invented — each sub lesson's pass mark is stated as the
observable thing the learner can do.

## Sub lesson 1 — There that points nowhere
Sub lesson 1 questions from the type files. Pass mark: say what the opener there does (it introduces the sentence; it points nowhere) and pick the real subject out of a there-sentence — the noun after the verb.

## Sub lesson 2 — There is, one thing
Sub lesson 2 questions from the type files. Pass mark: open sentences about one thing with There is — "There is a book on the desk" — and complete There is ___ sentences whose real subject is one.

## Sub lesson 3 — There are, more than one
Sub lesson 3 questions from the type files. Pass mark: open sentences about more than one thing with There are, and choose is or are in new sentences by the real subject that follows the verb — never by the there that opens.
