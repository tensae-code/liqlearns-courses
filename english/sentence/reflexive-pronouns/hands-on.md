# Hands-on — Reflexive pronouns

You do it, we guide you. Everything here is done with a
companion or the Explain Companion, out loud.

1. **The mirror mime.** One person mimes a morning
   action done to themselves — washing, dressing,
   cutting bread and nicking a finger (mime only!).
   The other must name it with the reflexive before the
   mime ends: "You cut yourself!" Eight mimes, all
   eight forms across the rounds (point at different
   people to force himself/herself/themselves).
2. **By myself, proudly.** Each person does one small
   real task in the room — alone: tie a lace, pour a
   glass, open a stiff jar — and reports it in the full
   frame: "I did it by myself." Then one task done
   together, reported with help — and the by-phrase
   must be refused: not by ourselves, WITH each other.
3. **Crossing arrows.** In pairs: do three real helping
   actions between you (hold a book, pass a cup, check
   a shoe) and narrate each with each other. Then each
   does one of the same actions alone, narrated with a
   reflexive. The companion calls "back!" or "across!"
   for every sentence, and any wrong arrow restarts it.
4. **Emphasis boasts (kind ones).** Each person makes
   one true boast with the reflexive as emphasis: "I
   cooked it myself." "She herself fixed the bicycle."
   The companion answers with a by-sentence about the
   same deed: "And you did it all by yourself."
