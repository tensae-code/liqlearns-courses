# Reflexive pronouns — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the words that point back —
set by the pattern across the countries' books: the forms
and the returning action first (Bolivia's and Nepal's
presentations), then alone and emphasis, then the split
against each other.

## Level 1 — the forms and the returning action
Level 1 questions from the type files. Pass mark: build
all eight reflexives (myself…themselves, -selves in the
plurals) and use them where the action returns to the
doer — cut yourself, wash herself, enjoy yourselves.

## Level 2 — by + reflexive, and emphasis
Level 2 questions from the type files. Pass mark: by +
reflexive for alone/unaided (He did it by himself), and
the reflexive as emphasis (I made it myself) — placed at
the sentence's end or right after the doer.

## Level 3 — reflexive or each other?
Level 3 questions from the type files. Pass mark: split
the two at speed — bent arrow (reflexive) vs crossing
arrows (each other / one another) — in mixed live
sentences with no misses.
