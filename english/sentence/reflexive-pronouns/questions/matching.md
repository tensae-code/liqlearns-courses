# Reflexive pronouns — matching

Match each sentence to its reflexive job.

**1. (Level 1)** "The cat washed itself." **Answer: the returning action** — doer and done-to are one: itself.

**2. (Level 2)** "The queen herself opened the door." **Answer: emphasis** — herself spotlights the doer; delete it and the sentence still stands.

**3. (Level 3)** "They blamed each other." **Answer: the crossing arrows — NOT a reflexive job** — the blame went between them, so each other, never themselves.
