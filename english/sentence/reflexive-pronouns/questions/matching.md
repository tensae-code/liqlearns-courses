# Reflexive pronouns — matching

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Reflexive Pronouns — the Forms and the Returning Action · (Level 2) -> Sub lesson 2 — Reflexive Pronouns — Emphasis and By + Reflexive · (Level 3) -> Sub lesson 3 — Reflexive or Each Other?.

Match each sentence to its reflexive job.

**1. (Sub lesson 1)** "The cat washed itself." **Answer: the returning action** — doer and done-to are one: itself.

**2. (Sub lesson 2)** "The queen herself opened the door." **Answer: emphasis** — herself spotlights the doer; delete it and the sentence still stands.

**3. (Sub lesson 3)** "They blamed each other." **Answer: the crossing arrows — NOT a reflexive job** — the blame went between them, so each other, never themselves.
