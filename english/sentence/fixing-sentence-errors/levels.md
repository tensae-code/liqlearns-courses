# Fixing sentence errors — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS
(2026-11-08 restructure — README, "Units, Lessons and Sub Lessons").
Practice is tied to the skill number, as before. The questions live in
the type files; this file is the by-sub-lesson view. The sub lessons are
the depths inside this one thing — reading a sentence like a mechanic —
set by the pattern across the countries' books: completeness first
(Sierra Leone's lesson, Ethiopia's Grade 11 opening), then the crashes,
then the hanging and crooked shapes (Ethiopia's Grade 12 accuracy
strand).

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level
2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Fixing sentence errors — the fragment

Sub lesson 1 questions from the type files. Pass mark: tell a
complete sentence from a fragment on sight, and complete
any fragment by supplying its missing subject or verb —
or by joining it to its neighbour.

## Sub lesson 2 — Fixing sentence errors — run-ons and comma splices

Sub lesson 2 questions from the type files. Pass mark: spot
a run-on and a comma splice, and repair each one at
least two ways (full stop, semicolon, joining word)
without losing any meaning.

## Sub lesson 3 — Fixing sentence errors — dangling modifiers and parallelism

Sub lesson 3 questions from the type files. Pass mark:
catch a dangling modifier and re-seat it on its true
doer, and straighten a faulty-parallelism list into one
shape — then run the full clinic: name any of the five
errors in a fresh broken sentence and fix it.
