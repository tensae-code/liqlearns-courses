# Fixing sentence errors — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — reading a sentence like a mechanic —
set by the pattern across the countries' books: completeness first
(Sierra Leone's lesson, Ethiopia's Grade 11 opening), then the
crashes, then the hanging and crooked shapes (Ethiopia's Grade 12
accuracy strand).

## Level 1 — is it a sentence at all?
Level 1 questions from the type files. Pass mark: tell a
complete sentence from a fragment on sight, and complete
any fragment by supplying its missing subject or verb —
or by joining it to its neighbour.

## Level 2 — the crashes
Level 2 questions from the type files. Pass mark: spot
a run-on and a comma splice, and repair each one at
least two ways (full stop, semicolon, joining word)
without losing any meaning.

## Level 3 — hanging and crooked
Level 3 questions from the type files. Pass mark:
catch a dangling modifier and re-seat it on its true
doer, and straighten a faulty-parallelism list into one
shape — then run the full clinic: name any of the five
errors in a fresh broken sentence and fix it.
