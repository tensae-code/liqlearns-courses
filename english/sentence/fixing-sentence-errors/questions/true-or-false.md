# Fixing sentence errors — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** A fragment can be a long group of words.
**Answer: True** — length is not the test — "Because the rain came suddenly last night over the whole town" is long and still a fragment.

**2. (Level 2)** A semicolon can join two full sentences without any joining word.
**Answer: True** — the semicolon is an honest joint on its own — one of the four splice repairs.

**3. (Level 3)** In a parallel list, mixing "to read", "swimming" and "play ball" is fine because each item is clear alone.
**Answer: False** — clarity is not the test — parallelism asks one shape for every item (Ethiopia, Grade 12, Unit 6, p.151).
