# Fixing sentence errors — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Fixing sentence errors — the fragment · (Level 2) -> Sub lesson 2 — Fixing sentence errors — run-ons and comma splices · (Level 3) -> Sub lesson 3 — Fixing sentence errors — dangling modifiers and parallelism.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** A fragment can be a long group of words.
**Answer: True** — length is not the test — "Because the rain came suddenly last night over the whole town" is long and still a fragment.

**2. (Sub lesson 2)** A semicolon can join two full sentences without any joining word.
**Answer: True** — the semicolon is an honest joint on its own — one of the four splice repairs.

**3. (Sub lesson 3)** In a parallel list, mixing "to read", "swimming" and "play ball" is fine because each item is clear alone.
**Answer: False** — clarity is not the test — parallelism asks one shape for every item (Ethiopia, Grade 12, Unit 6, p.151).
