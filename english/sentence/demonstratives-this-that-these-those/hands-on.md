# Hands-on — This, That, These and Those

## Near and far hunt

Place ten classroom things: five near the learner's desk, five across the room, some single, some in groups. The learner walks, points, and names each with the right pointing word before touching it.

## The shop table

Set up a small shop on a table. The buyer must ask for things by pointing words only — "that one", "these" — and ask one price. Then swap roles.
