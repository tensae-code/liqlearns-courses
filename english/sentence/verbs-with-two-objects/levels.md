# Verbs with two objects — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — one verb
carrying a person and a thing — set by the pattern across the two
countries' books: the two objects named first (Cambodia Grade 11,
Unit 15A), then the two shapes and the swap (Mongolia's Grammar
Reference pair), then pronouns and the to/for choice live.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Verbs with Two Objects Person and Thing
Sub lesson 1 questions from the type files. Pass mark: build
shape A — verb + person + thing — for give, send, show
and tell, and name each object: the person (indirect)
and the thing (direct).

## Sub lesson 2 — Verbs with Two Objects Swap
Sub lesson 2 questions from the type files. Pass mark:
rebuild any shape-A sentence as thing + to + person
for the handing-over verbs, and thing + for + person
for the doing-for verbs — and back again — without
losing an object (Mongolia, English IX, Unit 7's pair).

## Sub lesson 3 — Verbs with Two Objects Pronouns and Live Choice
Sub lesson 3 questions from the type files. Pass mark: run
pronouns safely (give it to her), choose to or for by
the verb's family at speaking speed, and say which
shape a heard sentence is wearing and why.
