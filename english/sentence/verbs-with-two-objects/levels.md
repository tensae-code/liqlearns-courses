# Verbs with two objects — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — one verb carrying a person and a
thing — set by the pattern across the two countries' books: the
two objects named first (Cambodia Grade 11, Unit 15A), then the
two shapes and the swap (Mongolia's Grammar Reference pair),
then pronouns and the to/for choice live.

## Level 1 — person + thing
Level 1 questions from the type files. Pass mark: build
shape A — verb + person + thing — for give, send, show
and tell, and name each object: the person (indirect)
and the thing (direct).

## Level 2 — the swap: thing + to/for + person
Level 2 questions from the type files. Pass mark:
rebuild any shape-A sentence as thing + to + person
for the handing-over verbs, and thing + for + person
for the doing-for verbs — and back again — without
losing an object (Mongolia, English IX, Unit 7's pair).

## Level 3 — pronouns and the live choice
Level 3 questions from the type files. Pass mark: run
pronouns safely (give it to her), choose to or for by
the verb's family at speaking speed, and say which
shape a heard sentence is wearing and why.
