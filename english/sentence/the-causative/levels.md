# The causative — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — arranging
for things to be done — set by the pattern across the countries'
books: the have/get something done shape first (every source opens
there), then the active family with its persons, then the
force/permission choice and the line against the plain passive.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Causative Have/Get Something Done
Sub lesson 1 questions from the type files. Pass mark: build
have/get + object + past participle for arranged jobs —
hair, repairs, checks — and say who the sentence is
about: the arranger, not the doer (Egypt, Secondary 12;
Malaysia, Form 3 Unit 11).

## Sub lesson 2 — Causative Tenses and Active Family
Sub lesson 2 questions from the type files. Pass mark: move
the causative through past, present and future without
moving the object or the participle — and run the
active pair: have + person + bare verb, get + person +
to-verb (Malaysia, Form 5, Unit 11, p.139; Vietnam,
Grade 12, Unit 6).

## Sub lesson 3 — Causative Force, Permission and Arrangement
Sub lesson 3 questions from the type files. Pass mark:
choose make (forced), let (allowed) and have/get
(arranged) for a situation without mixing their verb
shapes, and tell a causative from a plain passive by
the arranger standing in it (Nepal, Grade 8, Unit 6's
one-line family).
