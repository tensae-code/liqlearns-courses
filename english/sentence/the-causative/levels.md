# The causative — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — arranging for things to be done —
set by the pattern across the countries' books: the have/get
something done shape first (every source opens there), then the
active family with its persons, then the force/permission choice
and the line against the plain passive.

## Level 1 — have/get something done
Level 1 questions from the type files. Pass mark: build
have/get + object + past participle for arranged jobs —
hair, repairs, checks — and say who the sentence is
about: the arranger, not the doer (Egypt, Secondary 12;
Malaysia, Form 3 Unit 11).

## Level 2 — tenses and the active family
Level 2 questions from the type files. Pass mark: move
the causative through past, present and future without
moving the object or the participle — and run the
active pair: have + person + bare verb, get + person +
to-verb (Malaysia, Form 5, Unit 11, p.139; Vietnam,
Grade 12, Unit 6).

## Level 3 — force, permission, arrangement
Level 3 questions from the type files. Pass mark:
choose make (forced), let (allowed) and have/get
(arranged) for a situation without mixing their verb
shapes, and tell a causative from a plain passive by
the arranger standing in it (Nepal, Grade 8, Unit 6's
one-line family).
