# Cleft sentences — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — putting one part of a sentence under
a light — set by the pattern across the two books that teach it:
the shape first (Vietnam's grammar box), then the choice of focus,
then the Jordan unit's full emphasis family.

## Level 1 — the shape
Level 1 questions from the type files. Pass mark: build
It is / It was + focus + that/who from a plain sentence,
with who for a person and that for a thing, without
breaking the rest of the sentence.

## Level 2 — moving the light
Level 2 questions from the type files. Pass mark:
re-light the same event on the time, the place or the
reason, choosing is or was by the focus's own time, and
answer an emphasis question with the cleft it asks for.

## Level 3 — the emphasis family
Level 3 questions from the type files. Pass mark:
recognise and read negative inversion (Never before had
I… / Not only did I…) as emphasis, keep it apart from
the cleft in name, and use a cleft to correct a wrong
claim politely and exactly.
