# Cleft sentences — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS
(2026-11-08 restructure — README, "Units, Lessons and Sub Lessons").
Practice is tied to the skill number, as before. The questions live in
the type files; this file is the by-sub-lesson view. The sub lessons are
the depths inside this one thing — putting one part of a sentence under
a light — set by the pattern across the two books that teach it: the
shape first (Vietnam's grammar box), then the choice of focus, then the
Jordan unit's full emphasis family.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level
2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Cleft sentences — the shape

Sub lesson 1 questions from the type files. Pass mark: build
It is / It was + focus + that/who from a plain sentence,
with who for a person and that for a thing, without
breaking the rest of the sentence.

## Sub lesson 2 — Cleft sentences — moving the light

Sub lesson 2 questions from the type files. Pass mark:
re-light the same event on the time, the place or the
reason, choosing is or was by the focus's own time, and
answer an emphasis question with the cleft it asks for.

## Sub lesson 3 — Cleft sentences — the emphasis family

Sub lesson 3 questions from the type files. Pass mark:
recognise and read negative inversion (Never before had
I… / Not only did I…) as emphasis, keep it apart from
the cleft in name, and use a cleft to correct a wrong
claim politely and exactly.
