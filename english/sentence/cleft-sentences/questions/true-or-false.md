# Cleft sentences — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Cleft sentences — the shape · (Level 2) -> Sub lesson 2 — Cleft sentences — moving the light · (Level 3) -> Sub lesson 3 — Cleft sentences — the emphasis family.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** A cleft sentence changes the facts of the plain sentence.
**Answer: False** — it changes only the light — the event, the people and the time stay exactly as they were.

**2. (Sub lesson 2)** "It was the teacher which helped me" is a good cleft.
**Answer: False** — a person takes who, not which: It was the teacher who helped me.

**3. (Sub lesson 3)** Many countries' books in this course's set teach cleft sentences.
**Answer: False** — exactly two do — Jordan (Grade 12) and Vietnam (Grade 11); the lesson states its narrow base plainly.
