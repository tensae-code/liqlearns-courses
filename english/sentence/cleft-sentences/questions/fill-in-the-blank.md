# Cleft sentences — fill in the blank

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Cleft sentences — the shape · (Level 2) -> Sub lesson 2 — Cleft sentences — moving the light · (Level 3) -> Sub lesson 3 — Cleft sentences — the emphasis family.

Fill each gap with the right shape.

**1. (Sub lesson 1)** It ______ the rain that stopped the match. (past event)
**Answer: was** — the match is finished — was lights a past focus.

**2. (Sub lesson 2)** It is hard work ______ makes a master. (thing focus)
**Answer: that** — things take that; only a person takes who.

**3. (Sub lesson 3)** Not only ______ I pass, but I passed first in the class. (inversion)
**Answer: did** — inversion flips the helper in front of the subject: Not only did I pass (Jordan Workbook, Unit 2).
