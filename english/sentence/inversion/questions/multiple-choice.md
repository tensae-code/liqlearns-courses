## Multiple choice

1. "I can swim." — the agreeing answer with inversion is… (Sub lesson 1)
   a) So can I.  b) So I can.  c) So swim I.
   **Answer: a).**

2. "She came early." — the agreeing answer is… (Sub lesson 1)
   a) So do he.  b) So did he.  c) So will he.
   **Answer: b).**

3. In "Not only did he pass, but he came first", the part that inverts is… (Sub lesson 2)
   a) both parts  b) only the fronted Not only part  c) only the but part
   **Answer: b).**

4. Fronting with Not only is done to… (Sub lesson 2)
   a) hide the first fact  b) stress the first fact and make the reader wait for the second  c) shorten the sentence
   **Answer: b).**
