# Hands-on — Inversion

1. **So-chain.** Sit in a circle. The first learner makes a true statement about themselves. The next must answer "So do I / So did I / So will I…" with the matching helper — and add a new statement. A wrong helper stops the chain; fix it together and restart.

2. **Front it.** Take plain paired sentences from any reading ("He not only farms, but he also teaches."). Learners rebuild each with Not only at the front, then read both versions aloud and vote on which is stronger.
