# Participle adjectives — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths (RANKS) inside this one thing — the -ed feeling and the -ing cause, from one verb — set by the
pattern across the countries' books: the shape first, then its job,
then its borders with its neighbours.

## Level 1 — the pair
Level 1 questions from the type files. Pass mark: build both coats from a verb (bore, tire, interest) and place each on its right owner — feeler or cause.

## Level 2 — live choice
Level 2 questions from the type files. Pass mark: choose -ed or -ing in running sentences about films, lessons, news and people, with no swaps.

## Level 3 — the swap and the repair
Level 3 questions from the type files. Pass mark: catch and repair *I am boring*-type swaps live, and build pairs from verbs never drilled (amaze, confuse, surprise).
