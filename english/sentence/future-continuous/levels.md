# Future continuous — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths (RANKS) inside this one thing — tomorrow's scene, caught mid-action — set by the
pattern across the countries' books: the shape first, then its job,
then its borders with its neighbours.

## Level 1 — the shape
Level 1 questions from the type files. Pass mark: build will be + verb-ing for every who, statements, not-forms and questions — will and be fixed, the -ing spellings right.

## Level 2 — the future moment
Level 2 questions from the type files. Pass mark: picture and report actions in progress at named future points (this time tomorrow, at eight tonight, all day), and ask the polite scene-question (Will you be using…?).

## Level 3 — the neighbours
Level 3 questions from the type files. Pass mark: sort futures live: decided now (will), planned before (going to), in progress at a moment (this tense) — and defend each sort in one line.
