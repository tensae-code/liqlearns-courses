# Subject-verb agreement — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the verb answering to its true
subject — set by the pattern across the countries' books: the base
rule first (Sierra Leone's three passes, South Africa's workbooks),
then Nepal's tricky subjects, then the traps.

## Level 1 — the base rule
Level 1 questions from the type files. Pass mark: choose
the verb for plain singular and plural subjects, there
is/are, and the -s form, without a miss.

## Level 2 — the tricky subjects
Level 2 questions from the type files. Pass mark: hold
the verb singular for one of + plural noun, for
quantities weighed as one lump, and for uncountables —
and plural for police and people — live, in new
sentences.

## Level 3 — the traps
Level 3 questions from the type files. Pass mark: see
through of-phrases to the true subject; answer or/nor
and either…or to the nearer subject; and keep -s-ending
singulars (news, maths) apart from true plurals in one
unbroken set.
