# Subject-verb agreement — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS
(2026-11-08 restructure — README, "Units, Lessons and Sub Lessons").
Practice is tied to the skill number, as before. The questions live in
the type files; this file is the by-sub-lesson view. The sub lessons are
the depths inside this one thing — the verb answering to its true
subject — set by the pattern across the countries' books: the base rule
first (Sierra Leone's three passes, South Africa's workbooks), then
Nepal's tricky subjects, then the traps.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level
2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Subject-verb agreement — the base rule

Sub lesson 1 questions from the type files. Pass mark: choose
the verb for plain singular and plural subjects, there
is/are, and the -s form, without a miss.

## Sub lesson 2 — Subject-verb agreement — the tricky subjects

Sub lesson 2 questions from the type files. Pass mark: hold
the verb singular for one of + plural noun, for
quantities weighed as one lump, and for uncountables —
and plural for police and people — live, in new
sentences.

## Sub lesson 3 — Subject-verb agreement — the traps

Sub lesson 3 questions from the type files. Pass mark: see
through of-phrases to the true subject; answer or/nor
and either…or to the nearer subject; and keep -s-ending
singulars (news, maths) apart from true plurals in one
unbroken set.
