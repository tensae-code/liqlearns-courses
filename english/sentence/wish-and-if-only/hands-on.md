# Hands-on — Wish and if only

You do it, we guide you. Everything here is done in the
learner's real room, with a companion or the Explain
Companion.

1. **The window wishes.** Stand at a window for one
   minute. Say three true wishes about NOW in the past
   coat — I wish it weren't so cold. I wish I had a
   bicycle outside. If only the shop were open. Your
   companion checks only one thing: the coat is past,
   the meaning is now.
2. **The missed-bus game.** One person names a small
   real regret from this week (a missed bus, a forgotten
   book, a lost game). The other must answer with the
   past wish — If only you had… / I wish I hadn't… —
   had + participle, every time. Five rounds, then swap.
3. **Stop and start.** Each person writes one annoying
   habit of the other's (kind ones only — humming,
   borrowing pens, talking over films). Read yours out
   as a would wish: I wish you would… / I wish you
   wouldn't… Then each answers with a could wish about
   themselves: I wish I could…
4. **If only, stronger.** Take your three window wishes
   and say them again with if only at the front. Hear
   what changed: not the shape — the strength.
