# Wish and if only — fill in the blank

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Wishes About Now · (Level 2) -> Sub lesson 2 — Wishes About a Finished Day · (Level 3) -> Sub lesson 3 — Wish + Would — a Wanted Change, except items about a missing ability, which are Sub lesson 4 — Wish + Could — a Missing Ability · and the item asking whether if only is a different shape, which is Sub lesson 5 — If Only — the Same Wishes Said Stronger.

Fill each gap with the right shape.

**1. (Sub lesson 1)** I wish I ______ (know) the answer, but I don't.
**Answer: knew** — the present wish wears the past simple coat; the meaning is now, not past.

**2. (Sub lesson 2)** If only we ______ (leave) earlier — we missed the bus.
**Answer: had left** — a past regret takes wish / if only + past perfect.

**3. (Sub lesson 2)** I wish I ______ (not do) it. (Bolivia's own past-wish example, about a finished day)
**Answer: hadn't done** — had + participle, with the not inside: hadn't done.

**4. (Sub lesson 3)** I wish the lesson ______ (end) — I am so tired.
**Answer: would end** — wish + would asks for something to happen (Bolivia).
