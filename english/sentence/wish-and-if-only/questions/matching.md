# Wish and if only — matching

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Wishes About Now · (Level 2) -> Sub lesson 2 — Wishes About a Finished Day · (Level 3) -> Sub lesson 3 — Wish + Would — a Wanted Change, except items about a missing ability, which are Sub lesson 4 — Wish + Could — a Missing Ability · and the item asking whether if only is a different shape, which is Sub lesson 5 — If Only — the Same Wishes Said Stronger.

Match each wish to its job.

**1. (Sub lesson 1)** "I wish I ate more vegetables." **Answer: a present regret** — past coat, present meaning: I don't eat them now (Bolivia).

**2. (Sub lesson 2)** "I wish I hadn't done it." **Answer: a past regret** — had + participle, about a finished day that cannot change (Bolivia).

**3. (Sub lesson 3)** "I wish you would listen to me!" **Answer: a wanted change** — wish + would asks someone to start doing something (Bolivia; Malaysia, Form 4).
