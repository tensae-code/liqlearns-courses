# Wish and if only — matching

Match each wish to its job.

**1. (Level 1)** "I wish I ate more vegetables." **Answer: a present regret** — past coat, present meaning: I don't eat them now (Bolivia).

**2. (Level 2)** "I wish I hadn't done it." **Answer: a past regret** — had + participle, about a finished day that cannot change (Bolivia).

**3. (Level 3)** "I wish you would listen to me!" **Answer: a wanted change** — wish + would asks someone to start doing something (Bolivia; Malaysia, Form 4).
