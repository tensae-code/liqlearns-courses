# Wish and if only — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Wishes About Now · (Level 2) -> Sub lesson 2 — Wishes About a Finished Day · (Level 3) -> Sub lesson 3 — Wish + Would — a Wanted Change, except items about a missing ability, which are Sub lesson 4 — Wish + Could — a Missing Ability · and the item asking whether if only is a different shape, which is Sub lesson 5 — If Only — the Same Wishes Said Stronger.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** In "I wish I knew", the word knew means the knowing happened in the past.
**Answer: False** — the past coat marks NOT REAL, not past time; the wish is about now.

**2. (Sub lesson 5)** If only is a different grammar shape from wish.
**Answer: False** — if only is the same three shapes said stronger; Malaysia teaches wish and if only as one family (Form 4).

**3. (Sub lesson 2)** "I wish I hadn't done it" is a wish about a finished day.
**Answer: True** — had + participle is the past wish (Bolivia's own example).

**4. (Sub lesson 4)** "I wish I would swim" is the right way to wish for a swimming ability you do not have.
**Answer: False** — your own missing ability takes could: "I wish I could swim." Would points out at the world and other people.
