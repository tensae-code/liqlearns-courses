# Wish and if only — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — wishing for a world that is not
real — set by the pattern across the countries' books: the
present wish first (Bolivia, Nepal and Vietnam all open there),
then the past wish, then the would wish for a change.

## Level 1 — the present wish
Level 1 questions from the type files. Pass mark: build
wish / if only + past simple for a present regret, with
were for every who in careful English (I wish I were…)
— and keep the wish's past coat apart from real past time.

## Level 2 — the past wish
Level 2 questions from the type files. Pass mark: build
wish / if only + past perfect (had + participle) for a
regret about a finished day, and choose between the two
coats by asking "now, or then?".

## Level 3 — the would wish and the could wish
Level 3 questions from the type files. Pass mark: wish
+ would for a wanted change (someone to start or stop
something) and wish + could for a missing ability —
without pointing would at your own ability.
