# Wish and if only — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
wishing for a world that is not real — set by the pattern across
the countries' books: the present wish first (Bolivia, Nepal and
Vietnam all open there), then the past wish, then the would wish
for a change, then the could wish, then if only.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 covered two natural
jumps, so it splits at the jump — its would part is Sub lesson 3
and its could part is Sub lesson 4, and its pass mark splits the
same way below. If only had no separate old layer; it is Sub
lesson 5, from its own paragraph in the lesson text.

## Sub lesson 1 — Wishes About Now
Sub lesson 1 questions from the type files. Pass mark: build wish / if only + past simple for a present regret, with were for every who in careful English (I wish I were…) — and keep the wish's past coat apart from real past time.

## Sub lesson 2 — Wishes About a Finished Day
Sub lesson 2 questions from the type files. Pass mark: build wish / if only + past perfect (had + participle) for a regret about a finished day, and choose between the two coats by asking "now, or then?".

## Sub lesson 3 — Wish + Would — a Wanted Change
Sub lesson 3 questions from the type files. Pass mark: wish + would for a wanted change (someone to start or stop something). (The first half of old Level 3's pass mark, split at the same natural jump as the text.)

## Sub lesson 4 — Wish + Could — a Missing Ability
Sub lesson 4 questions from the type files. Pass mark: wish + could for a missing ability — without pointing would at your own ability. (The second half of old Level 3's pass mark, split at the same natural jump as the text.)

## Sub lesson 5 — If Only — the Same Wishes Said Stronger
No separate old depth layer — if only was carried inside every layer above as the stronger form of the same wish, and its own paragraph in the lesson text makes it its own sub lesson. Depth wording, from the lesson itself: if only is the same three wishes said stronger — the wish with its heart showing.
