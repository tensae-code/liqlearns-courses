# Asking with question words — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the thing-question — set by the
pattern across the countries' books: the words and their prey
first, then the build, then whole answers with the falling voice.

## Level 1 — the words and their prey
Level 1 questions from the type files. Pass mark: name what each
word hunts — what/thing, where/place, when/time, who/person,
how many/count — and pick the right word for a given prey,
without a miss.

## Level 2 — the build
Level 2 questions from the type files. Pass mark: build
thing-questions whole (word + swap/engine + rest), keep the verb
bare after does, and handle the who-as-subject exception without
sending an engine in.

## Level 3 — whole answers, falling voice
Level 3 questions from the type files. Pass mark: answer every
question with the prey inside a whole sentence, ask with the
falling voice, and work why and how (reason and way) as surely as
the big four.
