# Asking with question words — ordering

Stand the words in question order. (This type exists for
this lesson because the build IS an ordering: word first,
machinery behind it.)

**1. (Level 2)** do / what / you / eat / ?
**Answer:** What do you eat?

**2. (Level 2)** the tiger / does / eat / what / ?
**Answer:** What does the tiger eat? — eat bare after does.

**3. (Level 2)** when / up / get / does / Mita / ?
**Answer:** When does Mita get up?

**4. (Level 3)** is / why / she / happy / ?
**Answer:** Why is she happy? — the swap behind the word.

**5. (Level 3)** go / how / to school / you / do / ?
**Answer:** How do you go to school?

**6. (Level 1)** are / how many / in a week / days / there / ?
**Answer:** How many days are there in a week? — Egypt's
first question (p.6), built from be + there.
