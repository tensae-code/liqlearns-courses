# Plans in the past — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths (RANKS) inside this one thing — the future inside a past story — set by the
pattern across the countries' books: the shape first, then its job,
then its borders with its neighbours.

## Level 1 — the plan and the edge
Level 1 questions from the type files. Pass mark: build was/were going to and was/were about to for every who, with the base verb standing plain after to, and catch an about-to moment with a when-clause.

## Level 2 — the expectation
Level 2 questions from the type files. Pass mark: report arrangements with was/were supposed to — kept and broken — and ask and deny across all the lesson's forms with the was/were swap.

## Level 3 — the formal coat and the story
Level 3 questions from the type files. Pass mark: read and write was/were + to-infinitive as the formal arranged future, and run a full past-plan story mixing the four coats, each named and each in its right seat.
