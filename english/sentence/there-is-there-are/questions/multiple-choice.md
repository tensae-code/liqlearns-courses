## Multiple choice

1. ___ a park in my town. (Sub lesson 1)
   a) There are  b) There is  c) It are
   **Answer: b) There is** — one park takes there is.

2. ___ milk in the glass. (Sub lesson 1)
   a) There are  b) There is  c) There be
   **Answer: b) There is** — uncountable things (milk, water) take there is.

3. ___ four chairs in the room. (Sub lesson 2)
   a) There is  b) There are  c) Is there
   **Answer: b) There are** — more than one takes there are.

4. ___ five sheep in the field. (Sub lesson 2)
   a) There is  b) There are  c) There am
   **Answer: b) There are** — sheep stays “sheep” for many, and many takes are.

5. “___ a clock in your room?” — “Yes, there is.” (Sub lesson 3)
   a) Are there  b) Is there  c) There is
   **Answer: b) Is there** — one thing, question form: Is there…?

6. “How many windows ___?” — “There are two.” (Sub lesson 3)
   a) is there  b) are there  c) there is
   **Answer: b) are there** — How many… are there? asks the number of many things.

7. There ___ any eggs. (Sub lesson 3)
   a) isn't  b) aren't  c) is
   **Answer: b) aren't** — eggs are plural: there aren't any eggs.

8. There ___ any milk left. (Sub lesson 3)
   a) aren't  b) isn't  c) are
   **Answer: b) isn't** — milk takes is, so the negative is isn't — and negatives take any, not some.
