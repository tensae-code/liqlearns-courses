# Video script — There Is and There Are

Super-simple voice. The presenter is the LiqLearns mascot, front-facing,
on screen the whole video; the pictures named here appear beside him.

[One apple appears.] “There IS an apple. One thing — IS.” [Two more apples appear.] “Now there ARE three apples. More than one — ARE!”

[A glass of milk.] “There is milk. Milk takes IS — we don't count milk.”

[Five sheep in a field.] “How many sheep are there? There are five sheep! Sheep never changes.”

[An empty plate.] “Are there any eggs? No — there AREN'T any eggs. And there ISN'T any milk. Any comes with questions and no's!”
