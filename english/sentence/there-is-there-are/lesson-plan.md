# Lesson plan — There Is and There Are

**Course:** English (Zero to Story)
**Title:** There Is and There Are
**Lesson:** there-is-there-are — saying what exists: There is a park; There are two parks
**Place in the curriculum:** Unit 10 — Building a Sentence (beside Introductory There)
**The one thing:** There is for one thing, there are for more than one — saying what a place has, asking how many, and saying what is not there.
**This lesson's own level:** Sentence lesson (existence): there is + singular/uncountable, there are + plural, How many… are there?, there isn't/aren't.

## Why this lesson exists

Bolivia teaches there is/are in four places and the course had only the introductory-there lesson (from Bangladesh's XI–XII book): the Grade 7 book's full treatment, the Grade 8 book's treatment across singular, plural and uncountable nouns, and two compendium spreads (Years 1 and 2). This lesson is built from those placements under the everything-goes-in ruling (2026-11-06).

## Sub lessons

1. There is — one thing
2. There are — more than one
3. Questions and negatives

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
Introductory There is its neighbour in the same unit and points here; a learner may take either first — this lesson stands alone and teaches the full system.

## What the learner can do when it ends
- Use there is for one thing and for uncountable things (milk, water).
- Use there are for more than one thing.
- Ask “Is there…? / Are there…? / How many… are there?” and answer.
- Say what is NOT there with there isn't / there aren't.

## What you need
A picture of a room or a street — or the real room you are in.

## The run of the lesson
1. ADD IMAGE: a street scene — one park, three trees, two shops. The learner counts and says what is there before the sentences appear.
2. ADD GIF (1–2 seconds): one apple fades in — “There is an apple.” Then two more — “There are three apples.” One → is; many → are.
3. Room tour: the learner walks the room naming: “There is a table. There are four chairs.”
4. Sub lesson 3 turns the tour into questions and negatives: “Is there a clock? No, there isn't.” “How many windows are there? There are two.”

## Add-ons
- Picture duel: two learners describe different pictures; each must find three differences using there is/are.
- How-many race: “How many books are there on the table?” — count and answer in a full sentence.

## If the learner is stuck
If is/are get mixed, count out loud first: one → is, more → are. Uncountables (milk, water) always take is — the book's own trap, taught carefully in sub lesson 1.

## Teacher note
Grade 8's book prints the negative model “There is not some milk” (printed p. 34), which its own some/any section corrects to any — this lesson teaches “There isn't any milk”, and the slip is recorded in lesson/sources.md. Grade 7's book also gives the unchanging plurals sheep and fish, stocked here.
