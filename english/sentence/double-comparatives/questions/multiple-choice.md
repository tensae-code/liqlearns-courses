# Double comparatives — multiple choice

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to, by what the item actually asks. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Double Comparatives — the Locked Pair, except gradual-change items, which are Sub lesson 2 — Double Comparatives — Gradual Change · (Level 2) -> Sub lesson 2, except locked-pair items, which are Sub lesson 1 · (Level 3) -> Sub lesson 4 — Double Comparatives — the Error to Correct, except the item about China's use-evidence, which is Sub lesson 3 — Double Comparatives — the Shape in Use, and locked-pair items, which are Sub lesson 1.

Pick the one right answer.

**1. (Sub lesson 1)** "______ you practise, ______ you play." a) The more / the better  b) More / better  c) The most / the best **Answer: a) The more / the better** — the locked pair takes the + comparative on BOTH sides (Greece, Applied Arts, pp.50–51).

**2. (Sub lesson 2)** "The days are getting ______." (gradual change) a) long and long  b) longer and longer  c) the longer **Answer: b) longer and longer** — one thing changing step by step repeats the comparative with and.

**3. (Sub lesson 1)** "The more developed the city is, ______ it becomes." a) the more crowded  b) more crowded  c) crowded and crowded **Answer: a) the more crowded** — Vietnam's Grade 9 model sentence, Unit 2 — the second half keeps its the.

**4. (Sub lesson 4)** Which sentence is RIGHT? a) This one is very better.  b) This one is much better.  c) This one is very more good. **Answer: b)** — very never grades a comparative; much / far / a lot do.
