# Double comparatives — multiple choice

Pick the one right answer.

**1. (Level 1)** "______ you practise, ______ you play." a) The more / the better  b) More / better  c) The most / the best **Answer: a) The more / the better** — the locked pair takes the + comparative on BOTH sides (Greece, Applied Arts, pp.50–51).

**2. (Level 1)** "The days are getting ______." (gradual change) a) long and long  b) longer and longer  c) the longer **Answer: b) longer and longer** — one thing changing step by step repeats the comparative with and.

**3. (Level 2)** "The more developed the city is, ______ it becomes." a) the more crowded  b) more crowded  c) crowded and crowded **Answer: a) the more crowded** — Vietnam's Grade 9 model sentence, Unit 2 — the second half keeps its the.

**4. (Level 3)** Which sentence is RIGHT? a) This one is very better.  b) This one is much better.  c) This one is very more good. **Answer: b)** — very never grades a comparative; much / far / a lot do.
