# Double comparatives — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths (RANKS) inside this one thing — two comparisons locked together, and one comparison repeated for step-by-step change — set by the
pattern across the countries' books: the shape first, then its job,
then its borders with its neighbours.

## Level 1 — the locked pair
Level 1 questions from the type files. Pass mark: build the more…the more whole, with the + comparative on both sides and the lever first.

## Level 2 — gradual change
Level 2 questions from the type files. Pass mark: build comparative-and-comparative for adjectives, adverbs and more-forms (more and more difficult) without a break.

## Level 3 — borders and the error
Level 3 questions from the type files. Pass mark: sort locked change from gradual change live, and correct *very better* and its family on sight.
