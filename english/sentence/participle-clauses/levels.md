# Participle clauses — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — the clause
shrunk to its participle — set by the pattern across the
countries' books: the reduced relatives first (Egypt's pair is the
cleanest statement), then free clauses for reason and time with
the perfect participle (Armenia, Vietnam), then the hidden-subject
law and its repair (Ethiopia's misplaced participles).

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Participle Clauses Reduced Relatives
Sub lesson 1 questions from the type files. Pass mark: shrink
who/which + be clauses both ways — present participle
for active, past participle for passive — and grow them
back without changing the meaning (Egypt, Secondary 12
Term 2, Unit 10).

## Sub lesson 2 — Participle Clauses Reason, Time and Perfect Participle
Sub lesson 2 questions from the type files. Pass mark: open
a sentence with a participle clause for reason or time
(Having finished…, Knowing…, Built…) with the main
subject doing the participle's work — the perfect
participle for the action that finished first (Armenia,
Grade 11, §5.2; Vietnam, Grade 11, Units 5 and 7).

## Sub lesson 3 — Participle Clauses Hidden-Subject Law
Sub lesson 3 questions from the type files. Pass mark: catch
and repair a misplaced participle — name the wrong
subject the clause points at and rebuild the sentence
so the participle's doer and the main subject are one
(Ethiopia, Grade 12, Unit 3).
