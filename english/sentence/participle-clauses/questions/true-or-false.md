# Participle clauses — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — Participle Clauses Reduced Relatives · (Level 2) -> Sub lesson 2 — Participle Clauses Reason, Time and Perfect Participle · (Level 3) -> Sub lesson 3 — Participle Clauses Hidden-Subject Law.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** "The car stolen last night" and "the
car which was stolen last night" say the same thing.
**Answer: True** — the reduced form is the book's own
pair (Egypt, Secondary 12 Term 2, Unit 10).

**2. (Sub lesson 2)** A participle clause can give a reason:
"Knowing the road, we drove fast" = because we knew
the road.
**Answer: True** — participle clauses to express reason
are Armenia Grade 11's stated use (§5.2, pp.132–135).

**3. (Sub lesson 3)** "Having finished lunch, the table was
cleared" is a good sentence.
**Answer: False** — the main subject is the table, so
the clause claims the table finished lunch: a
misplaced participle (Ethiopia, Grade 12, Unit 3).
