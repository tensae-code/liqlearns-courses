# Relative clauses — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — joining two
sentences with who/which/that/where/when/whose — set by the
pattern across the countries' books: the word choice and the join
first (Cambodia Grade 9 and Egypt both open there), then the
subject/object seats and the drop, then the full family at work.

Mapping from the old depth layers: old Level 1 = Sub lesson 1;
old Level 2 = Sub lesson 2; old Level 3 = Sub lesson 3.

## Sub lesson 1 — Relative Clauses Join and Word
Sub lesson 1 questions from the type files. Pass mark: join
two sentences with the right word — who for people,
which for things, that for either — and say which noun
the clause is stuck to.

## Sub lesson 2 — Relative Clauses Subject, Object and the Drop
Sub lesson 2 questions from the type files. Pass mark: tell
a subject clause from an object clause, and drop the
joining word exactly where it is the object — never
where it is the subject (Vietnam Grade 9, Unit 9's rule).

## Sub lesson 3 — Relative Clauses Whole Family
Sub lesson 3 questions from the type files. Pass mark: run
whose (possession), where (place) and when (time)
alongside who/which/that, building clauses from two
sentences of your own without a wrong word or a wrong
drop.
