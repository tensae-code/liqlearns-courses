# Lesson Plan — Commas, Colons and Semicolons

**One thing:** the three middle-of-the-sentence marks used appropriately, as one named curriculum requirement: the comma that separates and pauses, the colon that points forward to what follows, and the semicolon that joins and divides weightier parts.

## Sub lessons

1. Commas
2. Colons and semicolons

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Teaching points

- Using commas appropriately (Primary Language Arts Scope and Sequence, objectives 3.83–3.85, printed p.40).
- Using colons appropriately (objectives 3.83–3.85, printed p.40).
- Using semicolons appropriately (objectives 3.83–3.85, printed p.40).
