# True or False — Commas, Colons and Semicolons

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. A comma ends a sentence. (Sub lesson 1) — False
2. Too many commas can make a sentence stutter. (Sub lesson 1) — True
3. A comma can separate the items of a list inside a sentence. (Sub lesson 1) — True
4. A colon points forward to what follows it. (Sub lesson 2) — True
5. A semicolon joins two closely linked parts of a sentence. (Sub lesson 2) — True
6. A semicolon is weaker than a comma. (Sub lesson 2) — False
