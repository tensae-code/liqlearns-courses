# Someone, anyone, no one — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the people/things/places grid —
set by the pattern across the countries' books: the
some/any rows first (Bolivia's box opens there), then the
no- row standing alone, then the whole grid at speed.

## Level 1 — the some and any rows
Level 1 questions from the type files. Pass mark: someone/
something/somewhere in positive sentences and offers;
anyone/anything/anywhere in questions and negatives —
for people, things and places alike (Bolivia's box).

## Level 2 — the no row, standing alone
Level 2 questions from the type files. Pass mark: no
one/nobody, nothing, nowhere with a POSITIVE verb — one
no per sentence — and the short answers (No one.
Nothing. Nowhere.).

## Level 3 — the every row and the whole grid
Level 3 questions from the type files. Pass mark:
everyone/everything/everywhere with singular verbs, and
all sixteen cells built and chosen live, at speaking
speed (Mongolia's discovery set; South Africa's full
list).
