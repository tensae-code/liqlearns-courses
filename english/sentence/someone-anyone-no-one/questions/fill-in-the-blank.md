# Someone, anyone, no one — fill in the blank

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — The Grid and the Some/Any Law · (Level 2) -> Sub lesson 2 — The No Row, Standing Alone · (Level 3) -> Sub lesson 3 — The Every Row and the Whole Grid.

Fill each gap with the right grid word.

**1. (Sub lesson 1)** Is ______ home? (a plain question, to a dark house)
**Answer: anyone** — questions take the any- row (Bolivia's box).

**2. (Sub lesson 1)** Would you like ______ to eat? (an offer)
**Answer: something** — offers take the some- row, like requests with some.

**3. (Sub lesson 2)** We looked all day but found ______ — the bag was gone. (things)
**Answer: nothing** — the no- row for things, with a positive verb (found).

**4. (Sub lesson 3)** ______ in the class passed the test — all thirty! (people, the full set)
**Answer: Everyone / Everybody** — the every- row, with a singular verb understood (passed fits all).
