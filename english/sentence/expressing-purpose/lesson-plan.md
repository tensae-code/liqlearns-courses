# Lesson plan — Expressing Purpose

**Course:** English (Zero to Story)
**Title:** Expressing Purpose
**Lesson:** expressing-purpose — what a thing is for and what you act for: used for, in order to, so that
**Place in the curriculum:** Unit 31 — Linking and Fixing Sentences
**The one thing:** Purpose talk: what a tool is used for (used for + -ing), and why you act (in order to, so as to, so that).
**This lesson's own level:** Sentence lesson (purpose): used for + noun/-ing for a tool's job; in order to / so as to + base verb for the actor's aim; so that + a whole clause.

## Why this lesson exists

Mauritania teaches purpose as its own lesson in the Grade 9 book — farm tools and their uses (a hoe is used for making the soil loose) carrying used for, in order to, so that and so as to — and repeats it in Grade 10. The course's connectors lesson held the joining words but no purpose lesson. This lesson is built from the placements under the everything-goes-in ruling (2026-11-06).

## Sub lessons

1. What is it used for? — used for + -ing
2. In order to, so as to — your aim, with to
3. So that — purpose with a whole clause

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
Nothing is needed before this lesson. Connectors and Clauses joins sentences generally; this lesson carries the purpose joins, and each stands alone.

## What the learner can do when it ends
- Ask and answer what a tool is for: "A hoe is used for making the soil loose."
- Give your aim shortly: "I study in order to succeed."
- Give your aim in a clause: "I study so that I can succeed."

## What you need
Nothing special — tools and objects in the room.

## The run of the lesson
1. ADD IMAGE: a farm hoe with loose soil around it. The learner tries "What is it for?" before any form appears.
2. Teach sub lesson 1 on classroom tools: scissors, a ruler, a brush — each with its used for.
3. ADD GIF (1–2 seconds): an arrow flying from a hand to a target — purpose is the aim of the act.
4. Sub lesson 3 turns the class's own aims into so that clauses: study, work, save, practise.

## Add-ons
- Tool table: mystery tools are drawn from a bag; each must be named and purposed before it is kept.
- Aim chains: each learner's aim becomes the next learner's so that clause opener.

## If the learner is stuck
Keep to "used for + -ing" on real tools until a thing's job is sayable. The aim forms are one step each after — to first, then the clause.

## Teacher note
The Grade 9 book teaches purpose over farm tools — the tool's job first, then the farmer's aim; the Grade 10 book repeats the set with household things (a toothbrush for brushing teeth). The lesson keeps that order.
