# Video script — Expressing Purpose

Super-simple voice. The presenter is the LiqLearns mascot, front-facing,
on screen the whole video; the pictures named here appear beside him.

[The mascot holds up a hoe.] "What is it USED FOR? Making the soil loose!"

[The mascot points at a target.] "I work hard IN ORDER TO succeed!"

[The mascot opens a big speech bubble.] "I study SO THAT I can pass!"
