# Hands-on — Expressing Purpose

## The tool bag

Real tools — or pictures where the tool is too big — come out of a bag one by one: hoe, brush, knife, needle, pump. Each must earn its place on the table with a used for sentence the class accepts.

## Aim wall

Each learner writes one real aim on a card twice — the in order to version and the so that version — and pins both. The class reads the wall and spots which form each card uses and why.
