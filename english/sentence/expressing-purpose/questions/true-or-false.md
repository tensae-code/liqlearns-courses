## True or false

1. "Used for" answers what a tool's job is. (Sub lesson 1)
   **Answer: True** — the tool's-job form.

2. "In order to" is followed by a whole clause. (Sub lesson 2)
   **Answer: False** — in order to takes the base verb; clauses take so that.

3. "So as to" and "in order to" do the same job. (Sub lesson 2)
   **Answer: True** — twins — so as to a little more formal.

4. "So that I can pass" is a complete purpose clause. (Sub lesson 3)
   **Answer: True** — so that + subject + can + verb.

5. "Used for brushing" uses -ing after for. (Sub lesson 1)
   **Answer: True** — for + -ing.
