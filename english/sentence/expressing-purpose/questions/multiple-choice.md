## Multiple choice

1. "A hoe is used ___ making the soil loose." (Sub lesson 1)
   a) to
   b) for
   c) that
   **Answer: b) for** — used for + -ing names the job.

2. "It is used for ___ teeth." (Sub lesson 1)
   a) brush
   b) brushing
   c) to brush
   **Answer: b) brushing** — for takes -ing here.

3. "I work hard ___ succeed." (Sub lesson 2)
   a) in order to
   b) so that
   c) used for
   **Answer: a) in order to** — the folded aim takes in order to + base verb.

4. "She studies ___ she can pass." (Sub lesson 3)
   a) in order to
   b) so as to
   c) so that
   **Answer: c) so that** — a whole clause (she can pass) takes so that.

5. "___ pass, he practises daily." (the formal twin of in order to) (Sub lesson 2)
   a) So that
   b) So as to
   c) Used for
   **Answer: b) So as to** — so as to + base verb opens the aim.

6. Which sentence is right? (Sub lesson 3)
   a) "I save so that to buy books."
   b) "I save in order to buy books."
   c) "I save used for buy books."
   **Answer: b) "I save in order to buy books."** — in order to + base verb; so that needs a clause.
