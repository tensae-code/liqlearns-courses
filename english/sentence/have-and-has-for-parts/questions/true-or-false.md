# True or False — Have and Has for Parts

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. "The bike has 2 brakes" names the bike by its parts. (Sub lesson 1) — True
2. One thing takes "have": "The car have an engine." (Sub lesson 1) — False
3. "It has four wheels" can describe a car. (Sub lesson 1) — True
4. A bike has a paddle for the water. (Sub lesson 2) — False
5. "Doesn't have" names a part a thing lacks. (Sub lesson 2) — True
6. In the invent-a-vehicle task, you present your vehicle by its parts. (Sub lesson 2) — True
