## The book's shape

Six units of ten printed pages each, then two Recycle sections, then
three appendices. Every unit runs the same skeleton: an opener spread,
Part A (Let's talk / Let's learn / Let's spell), Part B (Let's talk /
Let's learn / Read and write), and Part C (Let's check / Let's sing /
Story time). The recurring cast: schoolchildren Mike, Sarah, Amy,
Chen Jie, Wu Binbin, Zhang Peng and John, teacher Miss White, and the
animal pair Zip (a squirrel) and Zoom (a bear) who carry every Story
time. Each unit's Let's spell page teaches one spelling-sound group;
Unit 6's doubles as a review of all six.

## Shape of the book

This is the final primary-school volume: four units, a seven-part Recycle review built around a farm visit and a farewell party, and eight appendices. Each unit runs the same skeleton: a picture opener, Part A (Let's try listening → Let's talk dialogue → Let's learn word set → practice), Part B (the same again at one step up), a Read and write text with tasks, Let's check, a "Let's wrap it up" rule-discovery page, and a C Story time cartoon with Zoom and Zip. The editors' letter (PDF p.4) tells pupils this is their last primary term and names the new features of this volume: Let's try listening tasks, Read and write in every unit, the Let's wrap it up rule-hunting pages, the end-of-primary review (the Recycle), and the two appendix plays for performance.
