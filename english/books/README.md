# Book files — English

**One file per book** (his workflow rule, 2026-10-25): for every book —
download it, read it, create its file here, and fill the file as the
reading finds things. And **one book at a time**: a book is finished —
whole map, every basic found and filed into its lesson in the course —
before the next book starts. No half-read books spread across
countries.

Each book file holds: what the book is (country, grade, publisher,
verified file facts), its full unit map, and every basic found, with
the page it lives on and the course lesson it was filed into.
