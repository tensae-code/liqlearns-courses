# Bolivia — English (Lengua Extranjera), Secundaria Grades 7–12

**STATUS: FULLY READ + CITATION CHECK PASSED 2026-10-26.** One document read in
full, page by page: the ministry's teacher compendium that reproduces the
student learning texts for all six years of secundaria (Grades 7–12).

## The book

- **Title:** *Compendio para Maestras y Maestros — Textos de Aprendizaje
  2023–2024, Secundaria Comunitaria Productiva, Área Lengua Extranjera*
  (Ministerio de Educación, official document 2023; Minister Edgar Pary
  Chambi). A TEACHER compendium: it reprints the six student books
  (Secundaria 1–6 = Grades 7–12) in one volume, keeping the student books'
  own pagination — the printed folios run in the 160s–230s and the index's
  page numbers are the STUDENT books' pages, not this PDF's.
- **Working copy:** `~/workspace/liqlearns-courses-work/bolivia-english/compendio.pdf`
  = 18,972,768 bytes, 130 PDF pp. Source (library list, HEAD-verified
  2026-10-21):
  `https://librosministeriodeeducacionbolivia.webmasterbolivia.com/wp-content/uploads/2023/09/Area-Lengua-Extranjera.pdf`
- **Reading hazard, recorded honestly:** the PDF's text layer is set in a
  custom-encoded font — Spanish accents and some letter pairs extract as
  private-use glyphs ("Ɵ" = "ti", "'ƌĞĞƟŶŐƐ" = "Greetings"). The English
  content is decodable from context and was read in full from the
  extraction (10,502 lines), but plain-text search cannot re-find strings
  that carry the encoded glyphs; the citation check below was run against
  the sequential read with the books' printed folios.
- **Shape:** front matter (cover, imprint, full index of all six years,
  Presentación signed by the Minister — "2023 Año de la Juventud hacia el
  Bicentenario" — and a "Conoce tu texto" icon guide: Glosario, Investiga,
  ¿Sabías que…?, Noticiencia, Escanea el QR, Aprende haciendo, Desafío,
  talleres). Every topic in every year runs the same student-book cycle:
  **¡Iniciemos desde la práctica! → ¡Continuemos con la teoría! →
  ¡Realicemos la valoración! → ¡Es hora de la producción!** The English is
  bilingual throughout — every grammar box and most readings carry their
  Spanish gloss beside them.
