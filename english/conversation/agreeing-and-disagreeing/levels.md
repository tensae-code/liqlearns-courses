# Agreeing and disagreeing — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — agreeing and disagreeing — set by
the pattern across the countries' books: the short echoes first,
then the opinion frames, then the full friendly argument.

## Level 1 — the echoes
Level 1 questions from the type files. Pass mark: answer any
like or habit with the true echo — "So do I" in a yes-world,
"Neither do I" in a no-world, "I don't" when your truth differs.

## Level 2 — stating a view
Level 2 questions from the type files. Pass mark: state an
opinion with "I think… / In my opinion…", agree in full ("I
agree / You're right"), and soften with "I agree, but…".

## Level 3 — the friendly argument
Level 3 questions from the type files. Pass mark: build a whole
argument in Mauritania's frame — claim, two or three reasons
(First… Second… Finally…), conclusion — disagree with reasons
and kind words, and answer another's argument on its other side.
