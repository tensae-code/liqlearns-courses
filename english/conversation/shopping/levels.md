# Shopping — questions by level

Practice by level, tied to the skill number. The questions
live in the type files; this file is the by-level view. The
levels are the depths inside this one thing — the whole
shop conversation — set by the pattern across the
countries' books: the assistant-and-customer frame first
(Cambodia opens with it), then prices, then sizes and
paying.

## Level 1 — the frame
Level 1 questions from the type files. Pass mark: answer
"Can I help you?" with "I want to buy …, please", close
with "Anything else?" — "No, thanks", without a miss.

## Level 2 — how many, how much
Level 2 questions from the type files. Pass mark: ask
"How many … do you want?" for counted things and "How
much is it?" / "How much does it cost?" for prices — and
never swap them.

## Level 3 — sizes and paying
Level 3 questions from the type files. Pass mark: run a
clothes-shop buy live — ask for a size, try the thing on,
choose cash or card, and take the receipt — the whole
conversation without a break.
