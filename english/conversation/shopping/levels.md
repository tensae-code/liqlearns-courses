# Shopping — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons are the depths inside this one thing — the whole shop conversation — in the conversation's own order: the frame, how many, how much, sizes, paying.

Mapping from the old depth layers: old Level 1 (the frame) = Sub lesson 1; old Level 2 splits at its two questions into Sub lessons 2–3; old Level 3 (sizes and paying) splits at its two steps into Sub lessons 4–5.

## Sub lesson 1 — The assistant opens, Can I help you
Sub lesson 1 questions from the type files. Pass mark: answer "Can I help you?" with "I want to buy …, please", and close with "Anything else?" — "No, thanks", without a miss. (Old Level 1's pass mark.)

## Sub lesson 2 — How many, for counted things
Sub lesson 2 questions from the type files. Pass mark: ask "How many … do you want?" for counted things. (Split from old Level 2's pass mark, at the two questions.)

## Sub lesson 3 — How much, the price
Sub lesson 3 questions from the type files. Pass mark: ask "How much is it?" / "How much does it cost?" for prices — and never swap the two questions. (Split from old Level 2's pass mark.)

## Sub lesson 4 — Sizes and trying on
Sub lesson 4 questions from the type files. Pass mark: ask for a size and try the thing on in a clothes-shop buy. (Split from old Level 3's pass mark.)
