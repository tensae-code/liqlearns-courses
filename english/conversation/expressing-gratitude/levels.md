# Levels — Expressing Gratitude

This file is the sub-lesson depth record for the lesson (restructure
2026-11-08): what each sub lesson holds, in teaching order. The old
layer wording is not used; the sub lessons below are the lesson's own
parts, exactly as listed in lesson-plan.md.

| Sub lesson | What it holds |
|---|---|
| Sub lesson 1 — Thank you — the first forms | The base forms: thank you, thanks — said to a person, for the moment. |
| Sub lesson 2 — Thanks for… — naming the gift | Thanks for / thank you for + the thing or the doing: thanks for the tablet, thank you for helping. |
| Sub lesson 3 — I'm grateful — stronger thanks | The stronger set: I'm grateful to you for…, I am really grateful…, that's really kind of you. |
| Sub lesson 4 — The thank-you letter | Thanks in writing: the Grade 10 book's thank-you letter to a whole family. |

Pass mark: the sources state no pass mark and none is invented. In this course a sub lesson opens when the learner proves the previous one with the prove-it check (at most 5 questions, the sub lesson's whole question set as the pool).
