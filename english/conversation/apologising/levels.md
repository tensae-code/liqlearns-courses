# Apologising — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — apologising — set by the pattern
across the countries' books: the sorry itself first, then the
completed apology with its replies, then the apology at full
length, spoken and written.

## Level 1 — the sorry itself
Level 1 questions from the type files. Pass mark: say "I'm
sorry," "I'm really sorry" and "I'm terribly sorry," and match
each strength to the size of the accident.

## Level 2 — sorry + what happened, and the replies
Level 2 questions from the type files. Pass mark: complete the
apology with "I'm afraid I broke / lost / forgot / left…" and
answer any apology with "It doesn't matter / It's all right /
Don't worry."

## Level 3 — the apology at length
Level 3 questions from the type files. Pass mark: run a whole
apology exchange — accident, full apology, reassuring reply —
and write a three-line apology letter (sorry, what happened,
kind ending) without prompting.
