# Apologising — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons are the depths inside this one thing — apologising — in the books' order: the sorry itself, what happened, the replies, then the apology at full length.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 splits at its two jobs — completing the apology is Sub lesson 2 and the replies are Sub lesson 3; old Level 3 = Sub lesson 4.

## Sub lesson 1 — The sorry at three strengths
Sub lesson 1 questions from the type files. Pass mark: say "I'm sorry," "I'm really sorry" and "I'm terribly sorry," and match each strength to the size of the accident. (Old Level 1's pass mark.)

## Sub lesson 2 — Saying what happened, I'm afraid I
Sub lesson 2 questions from the type files. Pass mark: complete the apology with "I'm afraid I broke / lost / forgot / left…" (Old Level 2's pass mark, first half.)

## Sub lesson 3 — The replies that forgive
Sub lesson 3 questions from the type files. Pass mark: answer any apology with "It doesn't matter / It's all right / Don't worry." (Old Level 2's pass mark, second half.)

## Sub lesson 4 — The apology at full length, in writing
Sub lesson 4 questions from the type files. Pass mark: run a whole apology exchange — accident, full apology, reassuring reply — and write a three-line apology letter (sorry, what happened, kind ending) without prompting. (Old Level 3's pass mark.)
