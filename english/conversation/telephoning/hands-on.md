# Hands-on — Telephoning

You do it, we guide you. Everything here is done with a
companion or the Explain Companion — two chairs back to
back, so you hear the voice only, like a real call.

1. **The back-to-back call.** Sit back to back. One person
   calls a hotel and asks for a room and a person; the
   other answers Greece's way — "I'll put you through" —
   then swaps. No faces, only voices: that is the skill.
2. **The message pad.** The caller asks for someone who is
   out. The answerer takes a real message on paper: who
   called, the number (said slowly, in pieces), and
   "please call back." Read the message back to check it.
3. **The appointment call.** Call a clinic the Albania
   way: "Could I make an appointment, please? I'd like to
   come on … at … Is it possible to come earlier?" The
   other side confirms, then changes the time once — and
   the caller must agree the new time politely.
4. **The problem call.** Draw a problem card — engaged
   line, cut off, wrong number. The caller must say the
   right line for the problem and still finish the call
   with "Thank you. Goodbye."
