# Telephoning — questions by level

Practice by level, tied to the skill number. The questions
live in the type files; this file is the by-level view. The
levels are the depths inside this one thing — a whole phone
call — set by the pattern across the countries' books: the
call's fixed lines first (Greece and Uzbekistan both open
with them), then messages, then appointments and problems.

## Level 1 — the fixed lines
Level 1 questions from the type files. Pass mark: answer
with your name, ask for a person, and say the waiting
lines — "Hold on, please" and "I'll put you through" —
without a miss.

## Level 2 — messages
Level 2 questions from the type files. Pass mark: take a
message with a name, a number and a call-back, and leave a
message for someone who is out — spelling the name and
saying the number slowly and clearly.

## Level 3 — appointments and problems
Level 3 questions from the type files. Pass mark: make an
appointment by phone with the polite phrases (Could I…?,
I'd like to…, Is it possible to…?), and handle a problem
live — an engaged line, a cut-off call, a wrong number —
and still finish the call politely.
