# Telephoning — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons are the depths inside this one thing — a whole phone call — in the call's own order: answer, ask, wait, message, fix the business, close.

Mapping from the old depth layers: old Level 1 (the fixed lines) splits at the call's first three steps into Sub lessons 1–3; old Level 2 (messages) = Sub lesson 4; old Level 3 (appointments and problems) splits — appointments are Sub lesson 5 and problems, handled at the close, are Sub lesson 6.

Sub lesson 1 questions from the type files. Pass mark: answer with hello and your name. (Split from old Level 1's pass mark, at the call's steps.)

## Sub lesson 2 — Asking for a person
Sub lesson 2 questions from the type files. Pass mark: ask for a person, plain and up the polite ladder. (Split from old Level 1's pass mark.)

## Sub lesson 3 — Waiting, hold on and put through
Sub lesson 3 questions from the type files. Pass mark: say the waiting lines — "Hold on, please" and "I'll put you through" — without a miss. (Split from old Level 1's pass mark.)

## Sub lesson 4 — Taking and leaving messages
Sub lesson 4 questions from the type files. Pass mark: take a message with a name, a number and a call-back, and leave a message for someone who is out — spelling the name and saying the number slowly and clearly. (Old Level 2's pass mark.)

## Sub lesson 5 — Making an appointment by phone
Sub lesson 5 questions from the type files. Pass mark: make an appointment by phone with the polite phrases (Could I…?, I'd like to…, Is it possible to…?), and accept a change of time politely. (Split from old Level 3's pass mark.)

## Sub lesson 6 — Closing the call
Sub lesson 6 questions from the type files. Pass mark: handle a problem live — an engaged line, a cut-off call — and still finish the call politely, closing clean. (Split from old Level 3's pass mark.)
