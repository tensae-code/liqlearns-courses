# Asking politely — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons are the depths inside this one thing — asking politely — up the ladder: the casual rung, the formal rung, please and thank you, then choosing the rung hearer by hearer.

Mapping from the old depth layers: old Level 1 = Sub lesson 1 (its please wording is carried into Sub lesson 3, where please is taught); old Level 2 = Sub lesson 2; old Level 3 (choosing the rung) = Sub lesson 4, with Sub lesson 3 holding the please-and-thank-you part its exchange needs.

## Sub lesson 1 — The casual rung, Can you and Will you
Sub lesson 1 questions from the type files. Pass mark: ask with "Can you…? / Will you…?" for friends and family. (Old Level 1's pass mark; its please wording is carried in Sub lesson 3.)

## Sub lesson 2 — The formal rung, Could you and Would you mind
Sub lesson 2 questions from the type files. Pass mark: ask with "Could you…? / Would you…? / Would you mind…?" — the -ing after mind, every time — for teachers, elders and strangers. (Old Level 2's pass mark.)

## Sub lesson 3 — Please and thank you
Sub lesson 3 questions from the type files. Pass mark: put please in its seat inside any request, and thank you in accepting. (The please-and-thank-you part of old Level 1's and old Level 3's pass marks.)

## Sub lesson 4 — Choosing the rung
Sub lesson 4 questions from the type files. Pass mark: sort any request to its rung and say why, re-ask a rough request one rung higher without being told, and run a formal request exchange — request, kind answer, thank you — without prompting. (Old Level 3's pass mark.)
