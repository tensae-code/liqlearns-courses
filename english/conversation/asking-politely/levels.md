# Asking politely — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — asking politely — set by the
pattern across the countries' books: the casual rung first, then
the formal rung whole, then choosing the rung live, hearer by
hearer.

## Level 1 — the casual rung
Level 1 questions from the type files. Pass mark: ask with
"Can you…? / Will you…?" and put please in its seat, for friends
and family.

## Level 2 — the formal rung
Level 2 questions from the type files. Pass mark: ask with
"Could you…? / Would you…? / Would you mind…?" — the -ing after
mind, every time — for teachers, elders and strangers.

## Level 3 — choosing the rung
Level 3 questions from the type files. Pass mark: sort any
request to its rung and say why, re-ask a rough request one rung
higher without being told, and run a formal request exchange —
request, kind answer, thank you — without prompting.
