# Short Answer — At the Doctor's

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. Name the five visit words. (Sub lesson 1)
   — Appointment, medical test, diagnosis, prescription, dose.
2. What is the difference between a diagnosis and a prescription? (Sub lesson 1)
   — The diagnosis names what is wrong with you; the prescription names the medicine you must take.
3. Give the patient's four answers in the consultation. (Sub lesson 2)
   — The problem (a bad cough and a fever), since when (since yesterday), what was taken (an aspirin last night), allergies (none / no medication allergies).
4. Say a dose sentence. (Sub lesson 2)
   — Example: "One tablet, twice a day."
