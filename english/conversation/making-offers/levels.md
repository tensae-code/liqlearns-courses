# Making offers — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons are the depths inside this one thing — offering — in the order the books teach the shapes: the thing offer, the help offers, the shop offer, then answering every offer politely.

Mapping from the old depth layers: old Level 1 = Sub lesson 1; old Level 2 splits at its two jobs — help offers are Sub lesson 2 and the shop offer is Sub lesson 3; old Level 3 (offer or request?) is taught inside Sub lesson 3's Cambodia paragraph, and its full-exchange pass mark lands in Sub lesson 4, the answering sub lesson.

## Sub lesson 1 — Offering a thing with Would you like
Sub lesson 1 questions from the type files. Pass mark: make an offer with "Would you like…?" and answer one with "Yes, I would" / "No, I wouldn't" and "Yes, please" / "No, thank you" — the thanks never dropped. (Old Level 1's pass mark.)

## Sub lesson 2 — Offering help with Shall I
Sub lesson 2 questions from the type files. Pass mark: offer help with "Shall I…?" and "Would you like me to…?" (Old Level 2's pass mark, first part.)

## Sub lesson 3 — The shop offer, Can I help you
Sub lesson 3 questions from the type files. Pass mark: open a shop talk with "Can I help you?", and tell an offer from a request every time (the thing moves from you = offer; to you = request). (Old Level 2's shop part, with old Level 3's telling-apart.)

## Sub lesson 4 — Answering an offer, with thanks
Sub lesson 4 questions from the type files. Pass mark: accept or refuse any offer politely, the thanks always carried, and run a full offer exchange — offer, answer, thanks — without prompting. (Old Level 3's exchange pass mark.)
