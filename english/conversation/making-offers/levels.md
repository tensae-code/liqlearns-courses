# Making offers — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — offering — set by the pattern across
the countries' books: the "Would you like…?" offer first, then the
help offers, then telling offers from requests and answering every
offer politely.

## Level 1 — the "Would you like…?" offer
Level 1 questions from the type files. Pass mark: make an offer
with "Would you like…?" and answer one with "Yes, I would" /
"No, I wouldn't" and "Yes, please" / "No, thank you" — the thanks
never dropped.

## Level 2 — offers of help
Level 2 questions from the type files. Pass mark: offer help with
"Shall I…?" and "Would you like me to…?", open a shop talk with
"Can I help you?", and accept or refuse each offer politely.

## Level 3 — offer or request?
Level 3 questions from the type files. Pass mark: tell an offer
from a request every time (the thing moves from you = offer; to
you = request), and run a full offer exchange — offer, answer,
thanks — without prompting.
