# Matching — Making Appointments

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

Match each sentence to its job in the appointment talk.

1. "I'd like to make an appointment" (Sub lesson 1)
2. "Is 3:00 o'clock O.K.?" (Sub lesson 1)
3. "How about 3:30?" (Sub lesson 2)
4. "I'll see you then" (Sub lesson 2)

   a) offers another time when the first does not work
   b) opens the talk politely, saying what you want
   c) closes the talk, confirming the agreed time
   d) proposes a time and asks if it is good

Answers: 1–b, 2–d, 3–a, 4–c ✓
