# True or False — Making Appointments

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. "I'd like to make an appointment" is a polite way to open the talk. (Sub lesson 1) — True
2. A time for an appointment is announced as an order. (Sub lesson 1) — False
3. "Is 3:00 o'clock O.K.?" proposes a time and asks if it is good. (Sub lesson 1) — True
4. If the first time is taken, the talk must end with no appointment. (Sub lesson 2) — False
5. "How about 3:30?" offers another time. (Sub lesson 2) — True
6. "I'll see you then" confirms the appointment at the end of the talk. (Sub lesson 2) — True
