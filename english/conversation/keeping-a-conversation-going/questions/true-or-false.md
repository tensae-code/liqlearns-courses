# True or False — Keeping a Conversation Going

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. A conversation can die when the listener says nothing at all. (Sub lesson 1) — True
2. "Awesome." is one of the book's listening answers. (Sub lesson 1) — True
3. A listening answer is a long speech by the listener. (Sub lesson 1) — False
4. In a mini-dialogue, every speaker line should be left in silence. (Sub lesson 2) — False
5. Interrupting the speaker is a good way to keep a conversation going. (Sub lesson 2) — False
6. The right answer at the right moment keeps the talk alive. (Sub lesson 2) — True
