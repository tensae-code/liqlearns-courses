# Inviting — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons are the depths inside this one thing — inviting — the spoken invitation first, then its two true answers, then the invitation in writing.

Mapping from the old depth layers: old Level 1 splits at its two halves — the invitation itself is Sub lesson 1 and accepting is Sub lesson 2; old Level 2 (declining kindly) = Sub lesson 3; old Level 3 (the invitation on paper) = Sub lesson 4.

## Sub lesson 1 — The invitation, plan first
Sub lesson 1 questions from the type files. Pass mark: invite with the plan + "Would you like to come?" (Old Level 1's pass mark, first half.)

## Sub lesson 2 — Accepting gladly, I'd love to
Sub lesson 2 questions from the type files. Pass mark: accept with "Yes, please. I'd love to." (Old Level 1's pass mark, second half.)

## Sub lesson 3 — Declining kindly, sorry, wish, can't
Sub lesson 3 questions from the type files. Pass mark: decline any invitation in the three-part kind shape — sorry, "I'd like to, but…", a true reason — and carry a telephone invitation from ring to answer. (Old Level 2's pass mark; the telephone invitation is met in Sub lessons 2–3.)

## Sub lesson 4 — The invitation on paper
Sub lesson 4 questions from the type files. Pass mark: write an invitation message and a birthday invitation card carrying who, what, when and where, and switch one invitation between its formal card and informal email dresses without losing a fact. (Old Level 3's pass mark.)
