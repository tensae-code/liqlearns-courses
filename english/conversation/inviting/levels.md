# Inviting — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — inviting — set by the pattern
across the countries' books: the spoken invitation first, then
the two true answers in full, then the invitation in its written
dresses.

## Level 1 — the spoken invitation
Level 1 questions from the type files. Pass mark: invite with
the plan + "Would you like to come?" and accept with "Yes,
please. I'd love to."

## Level 2 — declining kindly
Level 2 questions from the type files. Pass mark: decline any
invitation in the three-part kind shape — sorry, "I'd like to,
but…", a true reason — and carry a telephone invitation from
ring to answer.

## Level 3 — the invitation on paper
Level 3 questions from the type files. Pass mark: write an
invitation message and a birthday invitation card carrying who,
what, when and where, and switch one invitation between its
formal card and informal email dresses without losing a fact.
