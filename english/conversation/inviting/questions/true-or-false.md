# Inviting — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — The invitation, plan first · (Level 2) -> Sub lesson 3 — Declining kindly, sorry, wish, can't · (Level 3) -> Sub lesson 4 — The invitation on paper.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** An invitation names the plan before it asks "Would you like to come?"
**True** — Syria's shape: "I'm going to go shopping. Would you like to come?" (Starters 5, Unit 21).

**2. (Sub lesson 3)** "I'm sorry. I'd like to, but I'm afraid I can't" refuses the person rudely.
**False** — it is the kind refusal: sorry + wish + can't, usually with a reason (Syria, Starters 5, Unit 21 role-cards; Malaysia, Form 1, Chapter 5).

**3. (Sub lesson 4)** A formal invitation card may leave out the time if the email version has it.
**False** — every dress carries all the facts: who, what, when, where (Nepal, Grade 8, Unit 10, pp.116–127).
