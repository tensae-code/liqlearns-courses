# Inviting — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** An invitation names the plan before it asks "Would you like to come?"
**True** — Syria's shape: "I'm going to go shopping. Would you like to come?" (Starters 5, Unit 21).

**2. (Level 2)** "I'm sorry. I'd like to, but I'm afraid I can't" refuses the person rudely.
**False** — it is the kind refusal: sorry + wish + can't, usually with a reason (Syria, Starters 5, Unit 21 role-cards; Malaysia, Form 1, Chapter 5).

**3. (Level 3)** A formal invitation card may leave out the time if the email version has it.
**False** — every dress carries all the facts: who, what, when, where (Nepal, Grade 8, Unit 10, pp.116–127).
