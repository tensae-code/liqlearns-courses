# Short answer — Recommending

(Gate pool: all questions of the sub lesson(s) named — no hardness ranking is written here, so a sub lesson's whole question set is its gate pool.)

1. Recommend one food to a visitor, with a reason.
   **Answer:** Any dish + recommend/should try phrase + a because-reason. (Sub lesson 1)

2. How do you answer a recommendation politely if you don't want it?
   **Answer:** Thank you — maybe next time. (Sub lesson 1)

3. Your friend is hungry, eats no meat and has little money. Recommend one dish and say why.
   **Answer:** A cheap meat-free dish with the fit named, e.g. "Try the lentil soup — it's filling, has no meat, and it's the cheapest dish." (Sub lesson 2)

4. When should you say "you must try" instead of "you could try"?
   **Answer:** Only when you are sure the person will like it. (Sub lesson 2)
