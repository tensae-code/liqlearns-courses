# True or False — Making Reservations

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. A reservation is made after you arrive at the hotel. (Sub lesson 1) — False
2. "I'd like to make a reservation, please" is the polite way to ask for a booking. (Sub lesson 1) — True
3. A round trip flight goes out and back. (Sub lesson 1) — True
4. The reservation talk is finished as soon as you have asked — you do not need a confirmation. (Sub lesson 1) — False
5. The lobby is the big entrance room of a hotel. (Sub lesson 2) — True
6. A security box is where you swim in a hotel. (Sub lesson 2) — False
7. A hostel is a simple, cheaper place to stay. (Sub lesson 2) — True
