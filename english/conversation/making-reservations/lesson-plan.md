# Lesson Plan — Making Reservations

**One thing:** booking ahead in English — asking for a reservation for a room or a trip, saying the trip you want, and hearing the booking confirmed — with the hotel words the talk runs on.

## Sub lessons

1. Asking for a reservation
2. The hotel words and the reservation talk

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Teaching points

- The asking sentence: "I'd like to make a reservation, please" (Tenth and Eleventh Grades syllabus, printed pp.23–24).
- For a flight, name the trip you want: "I'd like a round trip / nonstop flight" (pp.23–24).
- The talk ends when the booking is confirmed: "Your room/flight has been booked" (pp.23–24).
- The lodging set the reservation talk uses: hostel, three-star hotel, front desk, security box, elevator, lobby, swimming pool (pp.23–24).
- Reservation conversations are a named practice of the Grade 11 travel unit too — the same ask–specify–confirm talk, held as a full conversation (pp.36–37).
