# Giving directions — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons are the depths inside this one thing — a route another person can walk — in the route's own order: ask, move, place the end, distance, and the steps held in order.

Mapping from the old depth layers: old Level 1 splits — asking the way is Sub lesson 1 and the straight/turn core is Sub lesson 2 (which also seats old Level 2's go along / go past / cross); old Level 2 (placing the end) = Sub lesson 3; old Level 3 (whole routes) splits — distance is Sub lesson 4 and holding the steps in order is Sub lesson 5.
