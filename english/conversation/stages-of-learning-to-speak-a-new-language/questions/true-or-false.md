# True or False — Stages of Learning to Speak a New Language

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. Observation comes before Participation. (Sub lesson 1) — True
2. A learner in the Observation phase is doing nothing and learning nothing. (Sub lesson 1) — False
3. Participation means joining in with the group's speaking. (Sub lesson 1) — True
4. Performance means using the language independently to express needs, wants and ideas. (Sub lesson 2) — True
5. In the Practice phase, every sentence must be perfect. (Sub lesson 2) — False
6. The four phases are Observation, Participation, Practice, Performance. (Sub lesson 2) — True
