# Making suggestions — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — suggesting — set by the pattern
across the countries' books: "Let's…" first, then the
question-shaped forms, then the full exchange with glad and kind
answers.

## Level 1 — Let's…
Level 1 questions from the type files. Pass mark: make a
suggestion with "Let's + plain verb" and answer one with
"That's a good idea."

## Level 2 — the question shapes
Level 2 questions from the type files. Pass mark: suggest with
"Why don't we…?" and "How about…? + -ing", keeping each verb in
its own shape — plain after Let's and Why don't we, -ing after
How about.

## Level 3 — the whole exchange
Level 3 questions from the type files. Pass mark: run a planning
talk — suggest, answer glad or kind, suggest again with a second
form — and refuse one suggestion kindly ("I don't feel like it /
I'd rather…") without any prompting.
