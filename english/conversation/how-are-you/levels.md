# How are you? — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons are the depths inside this one thing — asking how someone is — the question and its answers first, then giving the question back.

Mapping from the old depth layers: old Level 1 (the basics) splits at the lesson's own jump into Sub lesson 1 (the question and the three answers) and Sub lesson 2 (asking it back); old Level 2 (use it with a person) was the return question used live, and its pass mark is carried into Sub lesson 2. Sub lesson 3 was added 2026-11-08 under the whole-arc rule, from the lesson's own stocked sources (the feelings deepening of the exchange was stocked but untaught). The books state no separate pass mark for the feelings band, so Sub lesson 3 keeps the same observable form — the learner can run the deeper exchange whole — rather than an invented mark.

Sub lesson 1 questions from the type files. Pass mark: ask "How are you?" and give all three answers, each for its right day. (Old Level 1's pass mark, first part.)

## Sub lesson 2 — Asking how are you back
Sub lesson 2 questions from the type files. Pass mark: ask the question back — and in a real exchange, use the return question without prompting. (Old Level 1's last part, with old Level 2's pass mark.)

## Sub lesson 3 — Asking about feelings: How do you feel?
Sub lesson 3 questions from the type files. Pass mark: ask
"How are you feeling?" / "How do you feel?" and answer with a

and answer it ("I'm thirsty…").
