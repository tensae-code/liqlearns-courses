# True or false — Group Discussion Skills

1. In a good group, members respect each other's ideas even when they disagree. (Sub lesson 1) — True
2. A group should judge each idea the moment it is spoken, before listing the others. (Sub lesson 2) — False
3. The three phases of group problem-solving are: identify the possibilities, examine the pros and cons, then decide. (Sub lesson 2) — True
4. Disagreeing with an idea is the same as attacking the person who said it. (Sub lesson 1) — False
