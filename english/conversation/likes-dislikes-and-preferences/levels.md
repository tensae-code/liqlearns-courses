# Levels — Likes, Dislikes and Preferences

This file is the sub-lesson depth record for the lesson (restructure
2026-11-08): what each sub lesson holds, in teaching order. The old
layer wording is not used; the sub lessons below are the lesson's own
parts, exactly as listed in lesson-plan.md.

| Sub lesson | What it holds |
|---|---|
| Sub lesson 1 — Likes and dislikes — like, dislike, favourite | Like/dislike + noun or verb-ing, with favourite for the top one (the Grade 7 set). |
| Sub lesson 2 — Wanting — want, would like, feel like | The desire forms: want + noun/to-infinitive, would like (the polite want), feel like + noun/-ing. |
| Sub lesson 3 — Preferences — prefer X to Y | Prefer as the choosing verb: prefer X to Y; prefer + -ing; do you prefer…or…? |
| Sub lesson 4 — I'd rather — choosing between two | 'd rather + base verb; 'd rather X than Y; would you rather…or…? |

Pass mark: the sources state no pass mark and none is invented. In this course a sub lesson opens when the learner proves the previous one with the prove-it check (at most 5 questions, the sub lesson's whole question set as the pool).
