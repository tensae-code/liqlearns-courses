# Lesson Plan — Labelling

Unit 2 — The Alphabet. Planned shape: two sub lessons —
first drawing and labelling objects (a picture with its name
written beside it), then labelling the world around you
(objects found in the environment, peers and places). The
lesson is built from Ghana's NaCCA Basic 1–3 curriculum,
whose writing strand names Labelling Items at Basic 1
("draw simple pictures of peers or various objects and label
them") and Basic 2 ("draw and label objects found in their
environment"). It stands in this unit beside joined-up-writing:
labelling is among the first real writing a learner does —
one true word, written to name a thing.

## Sub lessons

1. **Drawing and labelling objects** — draw a thing, write
   its name beside it; the label must be the thing's true
   name, readable and rightly placed.
2. **Labelling the world around you** — label objects found
   in the environment, and peers, places and classroom
   things.

Gate pool for each sub lesson's prove-it check: the items of the
earlier sub lessons, hardest first.
