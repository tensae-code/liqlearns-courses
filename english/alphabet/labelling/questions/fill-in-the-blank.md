# Fill in the Blank — Labelling

Fill each blank with the right word.

1. A label is a name ____ for a picture. (Sub lesson 1)
   **Answer: tag**

2. The label must be the thing's ____ name. (Sub lesson 1)
   **Answer: true**

3. Labels are written for ____, not only for the writer. (Sub lesson 1)
   **Answer: readers**

4. A drawing of a whole place with everything named is a labelled ____. (Sub lesson 2)
   **Answer: diagram**

5. If the drawing fills up with labels, start a ____ drawing. (Sub lesson 2)
   **Answer: second**
