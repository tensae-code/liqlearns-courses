# Levels — Print Concepts and Book Handling

This file is the sub-lesson depth record for the lesson
(restructure 2026-11-08): what each sub lesson holds, in teaching
order. The old layer wording is not used; the sub lessons below
are the lesson's own parts, exactly as listed in lesson-plan.md.

| Sub lesson | What it holds |
|---|---|
| Sub lesson 1 — The parts of a book | Front cover, back cover, beginning, end; print told apart from pictures. Sierra Leone Primary 1 Term 1 and Primary 2 Term 2 plans. |
| Sub lesson 2 — Holding and handling a book | Right way up; open at the front; one page at a time. Primary 1 Terms 1–2 and Primary 2 Term 2 plans. |
| Sub lesson 3 — Following the print | Directionality (left to right, top to bottom), tracking lines, noticing missing words. Primary 1–3 plans. |

Pass mark: the sources state no pass mark and none is invented. In
this course a sub lesson opens when the learner proves the previous
one with the prove-it check (at most 5 questions, the sub lesson's
whole question set as the pool).
