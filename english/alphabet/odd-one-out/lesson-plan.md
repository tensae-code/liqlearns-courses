# Lesson plan — The Odd One Out

Unit 2 (The Alphabet) — an eyes-first lesson beside the alphabet work: before letters can be told apart (b from d, p from q), the learner's eye must catch the one thing in a row that is not like the others.

## Sub lessons

1. Spot the one that is different
2. Say why it is different

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
