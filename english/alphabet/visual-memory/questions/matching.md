# Matching — Visual Memory

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

Match the start of the game to what you do next.

1. You looked at three things and they are covered (Sub lesson 1)
2. You looked at a pattern and it is covered (Sub lesson 1)
3. You think of something that happened yesterday (Sub lesson 2)
4. You described everything and want to check (Sub lesson 2)

a) build the pattern again from memory
b) name the three things from memory
c) look again and count what you missed
d) describe it in order — first, then next

Answers: 1-b, 2-a, 3-d, 4-c
