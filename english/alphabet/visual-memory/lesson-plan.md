# Lesson Plan — Visual Memory

**One thing:** visual memory — looking at things, patterns and experiences, then remembering them and describing them from memory, without looking again.

## Sub lessons

1. Remembering things and patterns
2. Remembering and describing experiences

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Teaching points

- Visual memory (0.1.9.6): remembering and describing objects and patterns from memory (ECE Level 1 Term 3).
- Remembering and describing experiences from memory — the same topic's second half.
