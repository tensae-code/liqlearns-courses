# Hands-On — Visual Memory

Things you do with real objects and real people. No special materials needed.

1. **The covering game.** Put three things on a table. Everyone looks. Cover them with a cloth. Each person names what was there. Uncover and check together. Add one more thing each round.
2. **Pattern back.** Build a short pattern with things — stone, leaf, stone, leaf. Your partner looks, you cover it, they rebuild it from memory. Check.
3. **The memory walk.** Walk a short way together. At the end, each person describes everything they passed, in order, from memory.
4. **Draw it from memory.** Look at one picture for one minute. Put it away. Draw what you remember. Then look at the picture again and find what you missed.
