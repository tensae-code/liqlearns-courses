# Joined-up writing — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — joining letters without lifting the
pencil — set by the pattern across the countries' books: one pair
first (Barbados's join types), then whole words (Bangladesh's
steps), then whole lines in the trace-then-copy routine (Kuwait).

## Level 1 — one pair, one join
Level 1 questions from the type files. Pass mark: join any
two letters in one run without lifting the pencil, and
name the join you used — diagonal or horizontal — from
Barbados's four basic joins (ai, ou, ab, ol and their kin).

## Level 2 — whole words in one run
Level 2 questions from the type files. Pass mark: write
whole words in cursive in one run — cursive capitals,
cursive small letters a–p and q–z, and picture words in
cursive — the steps of Bangladesh's Class 4 book (Units
9–11), with letters sitting on the four-line guides.

## Level 3 — whole lines, traced then copied
Level 3 questions from the type files. Pass mark: work a
full line the Kuwait way — trace the grey model, then
copy the solid model unaided — and write the days of the
week in cursive in the right order (Bangladesh, Unit 12),
choosing manuscript or cursive appropriately, as
Barbados's Class 3 syllabus names the choice.
