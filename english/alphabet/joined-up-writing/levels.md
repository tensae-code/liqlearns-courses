# Joined-up writing — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing —
joining letters without lifting the pencil — one pair first
(Barbados's join types), then whole words (Bangladesh's steps),
then whole lines in the trace-then-copy routine (Kuwait).

Mapping from the old depth layers: old Level 1 = Sub lessons
1–2 (its pass mark splits at the join itself: the flick that
makes the bridge, then naming the join from Barbados's four);
old Level 2 = Sub lesson 3; old Level 3 = Sub lessons 4–5 (its
pass mark splits at the same jump: the traced-then-copied line,
then the manuscript-or-cursive choice; its days-of-the-week part
belongs to the steps of Sub lesson 3 and is noted there).

## Sub lesson 1 — The exit flick
Sub lesson 1 questions from the type files. Pass mark (its part
of old Level 1's): join any two letters in one run without
lifting the pencil, using the first letter's exit flick as the
bridge.

## Sub lesson 2 — The four basic joins
Sub lesson 2 questions from the type files. Pass mark (its part
of old Level 1's): name the join you used — diagonal or
horizontal, to a letter with an ascender or without — from
Barbados's four basic joins (ai, ou, ab, ol and their kin).

## Sub lesson 3 — Steps into whole words
Sub lesson 3 questions from the type files. Pass mark: write
whole words in cursive in one run — cursive capitals, cursive
small letters a–p and q–z, and picture words in cursive — the
steps of Bangladesh's Class 4 book (Units 9–11), with letters
sitting on the four-line guides (old Level 2); and write the
days of the week in cursive in the right order (Bangladesh,
Unit 12 — the part of old Level 3's pass mark that belongs to
these steps).

## Sub lesson 4 — Trace then copy
Sub lesson 4 questions from the type files. Pass mark (its part
of old Level 3's): work a full line the Kuwait way — trace the
grey model, then copy the solid model unaided.

## Sub lesson 5 — Manuscript or cursive
Sub lesson 5 questions from the type files. Pass mark (its part
of old Level 3's): choose manuscript or cursive appropriately,
as Barbados's Class 3 syllabus names the choice.
