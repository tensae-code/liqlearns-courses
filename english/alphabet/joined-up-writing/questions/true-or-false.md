# Joined-up writing — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — The exit flick · (Level 2) -> Sub lesson 3 — Steps into whole words · (Level 3) -> Sub lesson 4 — Trace then copy, and Sub lesson 5 — Manuscript or cursive (split item by item).

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** In cursive writing, the pencil lifts between every letter.
**Answer: False** — the whole point of a join is that the pencil stays down inside the word; the exit flick carries it into the next letter.

**2. (Sub lesson 3)** Bangladesh's Class 4 book teaches the cursive small letters before the cursive capitals.
**Answer: False** — capitals A–Z come first (Unit 9, p.19); small letters a–p and q–z follow (Units 10–11).

**3. (Sub lesson 4)** Kuwait's Handwriting Book 3A teaches the four handwriting joins with diagrams.
**Answer: False** — the book teaches no joins at all, as its filing records honestly; it is a trace-and-copy book in a print-style hand, and this lesson takes only its routine and guides from it.

**4. (Sub lesson 5)** Barbados's Class 3 syllabus expects learners to use manuscript or cursive appropriately.
**Answer: True** — the choice itself is the named skill (Class 3 syllabus body, printed p.32, syllabus evidence).
