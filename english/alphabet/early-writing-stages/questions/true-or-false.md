# True or False — Early Writing Stages

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. In the first stage of writing, a child's drawing carries meaning — the child can tell you what it says. (Sub lesson 1) — True
2. Scribbling and drawing are the same stage. (Sub lesson 1) — False
3. Letter-like forms include lines, zigzags and loops. (Sub lesson 2) — True
4. In the random-letters stage, a reversed letter means the child is doing something wrong that must be stopped at once. (Sub lesson 2) — False
5. In invented spelling, a child often writes only the first sound of a word at first. (Sub lesson 3) — True
6. Spaces between words appear at the invented-spelling stage. (Sub lesson 3) — True
7. At the conventional-spelling stage, every word is spelled perfectly, including words like *blue* and *shoe*. (Sub lesson 4) — False
8. Children are expected to perfect handwriting by the end of preschool. (Sub lesson 4) — False
9. Writing development is tracked against the six stages using dated samples with anecdotal notes. (Sub lesson 4) — True
