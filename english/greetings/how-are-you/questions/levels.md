# How are you? — questions by level

Practice sessions by level, tied to the learner's skill number
(starts at 100 and moves as they learn). The questions themselves live
in the type files — this file is the by-level practice view.

## Level 1 — the basics
Run: all Level 1 questions from every type file. Pass mark: the
learner can ask "How are you?", give all three answers, and ask the
question back.

## Level 2 — use it with a person
Run: the Level 2 short-answer question — a real exchange, spoken,
with the return question used without prompting.
