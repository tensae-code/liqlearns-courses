# How old are you? — questions by level

Practice sessions by level, tied to the learner's skill number.
The questions live in the type files; this file is the by-level view.

## Level 1 — the basics
Run: all Level 1 questions from every type file. Pass mark: the
learner can ask the question and answer it about themselves in the
whole sentence, without help.

## Level 2 — a step deeper
Pass mark: the learner can say this year's sentence and next
year's sentence, and explain what changed.
