# How old are you? — true or false

True-or-false questions only. Answers at the bottom.

## Level 1
1. "How old are you?" asks about age. (True / False)
2. The answer "I'm 8" stays the same every year. (True / False)
3. "I'm 8" is a whole sentence in these books. (True / False)

## Answers
1-True, 2-False (the number grows every year), 3-True
