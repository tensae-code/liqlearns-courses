# Lesson Plan — Reading Fluency

**One thing:** reading aloud so it sounds like natural speech — recognising common phrases at a glance, using the punctuation marks and italics on the page as clues, and growing in accuracy, speed and expression together.

## Sub lessons

1. Reading so it sounds like talking
2. Expression, pace and the clues on the page

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Teaching points

- Reading aloud so it sounds like natural speech; recognising common phrases (Primary Language Arts Scope and Sequence, fluency objectives 2.37–2.41, printed p.25).
- Using punctuation marks and italics as visual clues when reading (objectives 2.37–2.41, printed p.25).
- Pacing, intonation and expression in oral reading (objectives 2.37–2.41, printed p.25).
- Increasing accuracy, speed and expression together (objectives 2.37–2.41, printed p.25).
