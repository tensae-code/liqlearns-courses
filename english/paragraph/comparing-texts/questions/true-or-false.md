# True or False — Comparing Texts

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. Two texts on one subject always say the same thing. (Sub lesson 1) — False
2. Comparing includes the words each author chose. (Sub lesson 1) — True
3. Changing the tone changes the facts of the event. (Sub lesson 2) — False
4. A difference in treatment between two texts is never an accident. (Sub lesson 2) — True
5. An author's purpose can be to warn or to comfort. (Sub lesson 2) — True
