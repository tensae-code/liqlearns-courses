# Short Answer — Comparing Texts

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. Name the four comparison steps. (Sub lesson 1)
   — Research the theme; compare ideas and themes; compare language (words, syntax, cohesion); compare the authors' purposes.
2. Compare: "The sea welcomed us" / "The sea attacked the shore." (Sub lesson 1)
   — Same sea; the first welcomes (kind, happy purpose), the second attacks (danger, warning) — different words, feeling and purpose.
3. Write one event — a letter arriving — in a sad tone. (Sub lesson 2)
   — Example: "The letter came thin and grey, and nobody smiled when it was opened."
4. Why is the side-by-side method powerful? (Sub lesson 2)
   — Because each text shows the other's choices: what it says, how it says it, and what it is trying to do.
