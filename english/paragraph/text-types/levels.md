# Levels — Text Types

How deep each sub lesson goes. The course-wide level ladder (Zero to Story) places this lesson as noted in its plan.

| Sub lesson | What it holds |
|---|---|
| The eight text types | the eight kinds Fiji's Year 3 book names — recount, poetry, transaction, report, procedure, persuasive, narrative, exposition — and what each one is for |
| Knowing a text type by its shape | telling a text's type from its structure and language features, the way Fiji's Year 4 feature boxes, Year 6 genre map and Year 8 text-type library teach it |

Pass mark: the sources state no pass mark and none is invented. In this course a sub lesson opens when the learner proves the previous one with the prove-it check (at most 5 questions, the sub lesson's whole question set as the pool).
