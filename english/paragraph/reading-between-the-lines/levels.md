# Reading between the lines — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
RANKS inside this one lesson — pass each rank to climb.

## Level 1 — the two sorts
Level 1 questions from the type files. Pass mark: sort statements into fact and opinion without a miss, and say the check that proves a fact

## Level 2 — clues and guesses
Level 2 questions from the type files. Pass mark: infer an unstated fact from named clues, and guess an unknown word from its surrounding sentences, showing the clue words

## Level 3 — the writer's weather
Level 3 questions from the type files. Pass mark: name tone, viewpoint, purpose and mood for a new text and defend each with a line from it
