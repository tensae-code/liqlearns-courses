# Answering from the text — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the text-bound answer — set by the
pattern across the countries' books: finding carriers first, then
whole own-words answers, then the buckets and the honest silence.

## Level 1 — find the carrier
Level 1 questions from the type files. Pass mark: for any factual
question over a short text, land on the carrying sentence and
answer from it — no answer without a carrier.

## Level 2 — whole answers, own words
Level 2 questions from the type files. Pass mark: give every
answer as a whole sentence in your own words, book closed after
the finding, facts exactly the text's.

## Level 3 — buckets and silence
Level 3 questions from the type files. Pass mark: sort questions
and answers by bucket (from the text / from my head / the text
doesn't say), defend each sort by pointing, and deliver the
honest silence as a complete answer without padding.
