# Lesson plan — The Four Language Skills

**Course:** English (Zero to Story)
**Title:** The Four Language Skills
**Lesson:** the-four-language-skills-orientation — listening, speaking, reading, writing — the four skills every English lesson trains, named and told apart
**Place in the curriculum:** Unit 15 — Reading Whole Texts
**The one thing:** English is learned through four skills — two take language in (listening, reading) and two send it out (speaking, writing) — and every lesson trains one or more of them
**This lesson's own level:** Orientation lesson: the four skills named first, then how they work together.

## Why this lesson exists

No lesson gave the learner the map of the subject itself. Sierra Leone's JSS 1 handbook puts it second in the whole course — Lesson 2, "The Four Language Arts" — before any of the skills is trained. The 2026-11-08 re-verification sweep marked it NEW LESSON NEEDED. Under the everything-goes-in ruling (2026-11-06) it gets its own lesson; its source is the handbook lesson named in lesson/sources.md.

## Sub lessons

1. **The four skills** — listening, speaking, reading, writing — and the two directions: taking in and sending out
2. **How the four work together** — every lesson in this course trains one or more; naming the skill you are using, and balancing the four

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
Nothing is forced first — this lesson stands alone and stands early: it is the map a learner can carry into every other lesson. Nothing in it needs any other lesson first.

## What the learner can do when it ends
- Name the four language skills.
- Say which skills take language in and which send it out.
- Look at any lesson and name the skill or skills it trains.
- Say which of your own four skills is strongest, and which needs the most work.

## What you need
Any lesson of this course, opened at random — the class will name its skills.

## The run of the lesson
1. **Do it first** — the learner watches the teacher do four things in silence (listen, speak, read, write, mimed) and guesses the four, before the names are taught (lesson/lesson.md).
2. Work through sub lesson 1: the four skills and the two directions.
3. Work through sub lesson 2: naming the skill inside any lesson; balancing the four.
4. ADD IMAGE: a four-square map — ear, mouth, eye, hand — the student points at the square for the skill they are using right now.

## Add-ons
- Skill spotting for a week: at the end of each English lesson, the class calls out which skills it trained.
- My four: each learner draws the four squares and shades each by strength — the lightest square is next term's target.

## If the learner is stuck
If a learner mixes reading and listening (both are “taking in”), use the channel: ears take listening in, eyes take reading in. If speaking and writing blur, the channel out: the mouth speaks, the hand writes.

## Teacher note
The JSS book places this lesson second, before all training — the orientation is the course's own idea, kept here in the course's own shape. It is registered in Unit 15 with the course's other whole-text and listening lessons.
