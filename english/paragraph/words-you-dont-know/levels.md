# Words you don't know — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the reader's ladder — set by the
pattern across the countries' books: reading on and inferring
first, then the clue kinds and word parts, then the checked,
swap-tested word log.

## Level 1 — read on and infer
Level 1 questions from the type files. Pass mark: finish a
sentence past its unknown word and state a meaning the sentence
supports — a written guess, in the margin, every time.

## Level 2 — the clues and the parts
Level 2 questions from the type files. Pass mark: name the clue
that carries each inference (the words around, a restating
neighbour, a contrast, a cause) and break long words into parts
that vote.

## Level 3 — check and swap-test
Level 3 questions from the type files. Pass mark: run the whole
ladder unhurried — guess written, dictionary checked, the sense
for THIS sentence chosen, and the meaning swap-tested back into
the sentence whole — and keep a word log that shows all four
steps.
