# Ways to read — multiple choice

Pick the one right answer.

**1. (Level 1)** You need ONE date from a long page, fast. You should — a) read every word b) skim c) scan **Answer: c) scan** — scanning hunts one named thing by its shape — a number — without reading the rest (Rwanda, P.6 U6, p.77)

**2. (Level 1)** You must decide in three minutes whether a chapter is worth slow reading. You should — a) skim b) scan c) recite **Answer: a) skim** — skimming takes the gist — headings, first and last lines — in minutes (Ghana's 3–4 minute drill, curriculum evidence)

**3. (Level 2)** The R in SQ3R that means 'say it back with the book closed' is — a) Read b) Recite c) Review **Answer: b) Recite** — SQ3R = Survey, Question, Read, Recite, Review (Ghana, curriculum evidence)

**4. (Level 3)** In an exam, a question asks for one specific fact. Vietnam's appendix teaches you to — a) use the strategy for that question type b) SQ3R the whole text c) read the text three times slowly **Answer: a) use the strategy for that question type** — Appendix 2 sorts strategies by question type (Vietnam G12, pp.145–146)
