# Lesson Plan — Viewing and Media Literacy

**One thing:** viewing as a skill in its own right — reading visual information on purpose (clues, maps, charts, diagrams, graphs and illustrations), making visual materials that carry your own meaning, and judging the media in front of you, including how it tries to persuade.

## Sub lessons

1. Reading what you see
2. Making and judging visual media

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Teaching points

- Viewing: using visual clues; interpreting maps, charts, diagrams, graphs and other media; how illustrations and graphics support meaning; sensory impressions from viewing (Primary Language Arts Scope and Sequence, Viewing objectives 1.65–1.71, printed p.17).
- Creating visual materials for presentations (Viewing objectives 1.65–1.71, printed p.17).
- Comparing print and electronic media (Viewing objectives 1.65–1.71, printed p.17).
- Critiquing persuasive techniques in media (Viewing objectives 1.65–1.71, printed p.17).
