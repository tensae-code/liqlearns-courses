# True or False — Cohesion and Coherence

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. Cohesion can be listed and counted on the surface of a text. (Sub lesson 1) — True
2. Pronouns pointing back are cohesive ties. (Sub lesson 1) — True
3. If every connector is correct, the text must be coherent. (Sub lesson 2) — False
4. Coherence means the text has one governing purpose. (Sub lesson 2) — True
5. Cohesion and coherence are two names for the same thing. (Sub lesson 2) — False
