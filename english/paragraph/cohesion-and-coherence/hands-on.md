# Hands-On — Cohesion and Coherence

Things you do with real books, real texts and real talk.

1. **Tie hunt.** Take a paragraph from any textbook. Underline every cohesive tie and label it (pronoun / repetition / connector). Count them.
2. **Break and mend.** Write a paragraph, then make two broken copies: one with the connectors removed (cohesion damaged), one with the sentences shuffled (coherence damaged). A partner diagnoses each.
3. **Connector trap.** Write the silliest cohesive-but-incoherent paragraph you can — every connector perfect, ideas wandering. Read it aloud; the class votes where sense was lost.
