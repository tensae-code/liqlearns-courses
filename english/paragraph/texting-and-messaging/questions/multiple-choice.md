# Multiple choice — Texting and Messaging

(Gate pool: all questions of the sub lesson(s) named — no hardness ranking is written here, so a sub lesson's whole question set is its gate pool.)

1. In chatspeak, "u" means:
   A) a letter of the alphabet only
   B) you
   C) under
   D) up
   **Answer: B** (Sub lesson 1)

2. "l8r" means:
   A) lighter
   B) later
   C) letter
   D) eight rooms
   **Answer: B** (Sub lesson 1)

3. "brb" stands for:
   A) bring red books
   B) be right back
   C) big red bus
   D) be really busy
   **Answer: B** (Sub lesson 1)

4. A note or text message must always say:
   A) who it is for, what it is about, what happens next
   B) only "hi"
   C) a long story
   D) the whole day
   **Answer: A** (Sub lesson 2)

5. For a message to a teacher, you should:
   A) use only chatspeak
   B) write the full words
   C) send nothing
   D) use numbers for sounds
   **Answer: B** (Sub lesson 2)

6. Before sending a short message, you should:
   A) delete it
   B) read it as the other person
   C) add more short forms
   D) send it twice
   **Answer: B** (Sub lesson 2)
