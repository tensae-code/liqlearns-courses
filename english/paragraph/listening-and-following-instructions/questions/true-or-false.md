# True or False — Listening and Following Instructions

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. Active listening includes facing the speaker. (Sub lesson 1) — True
2. Good listening means interrupting quickly to show you understand. (Sub lesson 1) — False
3. Occasional eye contact is part of listening when someone speaks to you. (Sub lesson 1) — True
4. An instruction with two steps can be followed in any order. (Sub lesson 2) — False
5. You should hear the whole instruction before you start doing it. (Sub lesson 2) — True
6. Following instructions is only a classroom skill; games cannot practise it. (Sub lesson 2) — False
