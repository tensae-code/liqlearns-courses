# Short Answer — Mediation: Transferring Information Between Texts and Languages

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

Use this source text: "Football practice is on Thursday at 4 p.m. on the school field. New players must bring boots. The coach is Mr Osei."

1. A note asks: "Practice is on ___." Which fact fills the gap? (Sub lesson 1)
   — Thursday.
2. Name two more exact facts in the text that a note could ask for. (Sub lesson 1)
   — Any two of: the time (4 p.m.), the place (the school field), the boots new players must bring, the coach's name (Mr Osei).
3. A learner's finished note says "Practice is at 5 p.m." Check it against the source: what is wrong? (Sub lesson 2)
   — The time changed on the way; the source says 4 p.m.
4. The note is written in another language, and its words for the place mean "the school field." Is that good mediation? Why? (Sub lesson 2)
   — Yes: the words changed with the language, but the fact — the same place — did not.
