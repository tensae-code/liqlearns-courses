# True or False — Mediation: Transferring Information Between Texts and Languages

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. In mediation, you carry the information from one text into another. (Sub lesson 1) — True
2. Opinions travel in mediation; facts do not. (Sub lesson 1) — False
3. When two texts speak about the same thing, you never need to check them against each other. (Sub lesson 1) — False
4. If the new text is in another language, the facts may change a little. (Sub lesson 2) — False
5. You should fill every gap by looking back at the source, not from memory. (Sub lesson 2) — True
6. Adding a true fact of your own that the sources never said is good mediation. (Sub lesson 2) — False
