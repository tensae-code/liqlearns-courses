# True or false — Media Studies: Newspapers

1. Mass media reach large numbers of people at the same time. (Sub lesson 1) — True
2. Everything printed in a newspaper is free of errors. (Sub lesson 2) — False
3. The arrangement of a front page is itself a kind of writing. (Sub lesson 2) — True
4. A joke in a newspaper does no work on the page. (Sub lesson 1) — False
