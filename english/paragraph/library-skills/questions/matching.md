# Matching — Library Skills

Match each source or order to what it is.

1. Fiction shelves (Sub lesson 1) — books ordered by the author's surname
2. Dewey numbers (Sub lesson 1) — subjects in number order along the shelves
3. Microfiche (Sub lesson 2) — pages stored as tiny film images, read on a viewer
4. Oral source (Sub lesson 2) — knowledge held by a person, gathered by interview
5. Archives (Sub lesson 2) — original documents, the primary sources
