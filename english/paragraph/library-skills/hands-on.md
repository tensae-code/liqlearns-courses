# Hands-on — Library Skills

- **The two walks.** Time yourself: find a set fiction book by surname, then a set non-fiction book by Dewey number. Which walk was faster, and why?
- **Source sort.** Given six mixed sources on one topic (book, encyclopaedia, web page, interview notes, archive letter, magazine), sort them into primary and secondary, newest and oldest.
- **Best-two defence.** From the same six, choose the best two for a named task and defend the choice in two sentences — this is the review step researchers actually do.
