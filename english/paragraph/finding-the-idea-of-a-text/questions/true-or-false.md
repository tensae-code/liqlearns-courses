# Finding the idea of a text — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** The main idea is usually the first sentence
of the text.
**False** — the first paragraph often only opens; the idea
is found by weighing ALL paragraphs.

**2. (Level 2)** A supporting detail can be the most
interesting sentence in the text.
**True** — interest is not weight. The seedlings' fame
charms; the work centres.

**3. (Level 3)** "This text is about a garden" is a complete
main idea.
**False** — bare topic: it makes no claim the text proves.

**4. (Level 3)** Writing the idea in your own words is
busywork teachers add.
**False** — it is the proof of the weighing (Ghana's rule).
Eyes can copy; only understanding can re-word.

**5. (Level 2)** Every paragraph in a text serves the main
idea in the same amount.
**False** — they lean differently; the weighing exists
because the loads differ.

**6. (Level 1)** The main idea of a text must be found
inside the text, not brought from outside knowledge.
**True** — the outside idea is the fourth trap; this text,
this centre.
