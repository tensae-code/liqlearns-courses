# Finding the idea of a text — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the text's main idea — set by the
pattern across the countries' books: choosing first, then
weighing, then saying it in own words against all the traps.

## Level 1 — choosing
Level 1 questions from the type files. Pass mark: pick the main
idea from three options (Bangladesh's task shape) and refuse
the too-small one, every time.

## Level 2 — weighing
Level 2 questions from the type files. Pass mark: gather a text's
paragraph ideas in writing and show the weighing — which idea
the others serve — before naming the centre.

## Level 3 — saying it, own words
Level 3 questions from the type files. Pass mark: state any short
text's main idea in one sentence of your own words that no
other text could borrow unchanged, and defeat all four traps
(detail, bare topic, copy, outside idea) by name.
