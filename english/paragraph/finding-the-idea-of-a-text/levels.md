# Finding the idea of a text — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. The
questions live in the type files; this file is the by-sub-lesson
view. The sub lessons are the depths inside this one thing — the
text's main idea — gathering first, then weighing, then saying
it in own words against all the traps.

## Sub lesson 1 — Gathering the Paragraph Ideas
Sub lesson 1 questions from the type files. Pass mark: gather a text's paragraph ideas in writing, each paragraph's naming sentence collected short.

## Sub lesson 2 — Weighing the Ideas
Sub lesson 2 questions from the type files. Pass mark: show the weighing — which idea the others serve — before naming the centre; and pick the main idea from three options (Bangladesh's task shape) and refuse the too-small one, every time.

## Sub lesson 3 — Saying the Idea in Your Own Words
Sub lesson 3 questions from the type files. Pass mark: state any short text's main idea in one sentence of your own words that no other text could borrow unchanged.

## Sub lesson 4 — The Traps
Sub lesson 4 questions from the type files. Pass mark: defeat all four traps (detail, bare topic, copy, outside idea) by name.
