# Exam technique — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
RANKS inside this one lesson — pass each rank to climb.

## Level 1 — the verbs, first half
Level 1 questions from the type files. Pass mark: state what list, state, identify and summarise demand, and give answers of exactly that size

## Level 2 — the verbs, full set
Level 2 questions from the type files. Pass mark: handle discuss, evaluate, compare and compose — judgement with reasons, both sides, differences named — without drifting into another verb's work

## Level 3 — under time
Level 3 questions from the type files. Pass mark: choose a per-question strategy from Vietnam's table and find set topics by contents and index against a clock, losing no marks to hunting
