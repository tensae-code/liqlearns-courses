# Video script — Exam technique

Super-simple voice. Read slow. The learner hears this
before or beside the written lesson.

---

An exam question is an order. Read the ORDER first!

LIST — give the items. Only the items!

STATE — say it, short and plain.

IDENTIFY — pick it out. Point at it.

DISCUSS — talk it around. Both sides.

EVALUATE — judge it. With reasons!

COMPARE — how are they the same? How different?

SUMMARISE — the same story, much shorter.

COMPOSE — build a new piece of writing.

Wrong tool? Lost marks. Right tool? The marks are yours.

And hunt fast: contents for the part, index for the word. The clock is running!
