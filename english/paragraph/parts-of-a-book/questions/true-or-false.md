# True or False — Parts of a Book

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. The spine joins all the pages of a book. (Sub lesson 1) — True
2. The author is the person who drew the book's pictures. (Sub lesson 1) — False
3. The title page carries the full title, the author, the illustrator and the publisher. (Sub lesson 1) — True
4. A call number tells you how many pages a book has. (Sub lesson 1) — False
5. Every book has an illustrator. (Sub lesson 1) — False
6. An article is one piece of writing inside a magazine or newspaper. (Sub lesson 2) — True
7. The loan period is how long you may keep a borrowed book. (Sub lesson 2) — True
8. A thesaurus comes out every week with new articles. (Sub lesson 2) — False
9. The bar code is the label of stripes the library reads to know which book it is. (Sub lesson 2) — True
10. A library keeps its books in any order, because order does not matter. (Sub lesson 3) — False
11. Returning a book when its loan period ends is a rule of use. (Sub lesson 3) — True
12. When you finish a borrowed book, you may keep it if you liked it. (Sub lesson 3) — False
