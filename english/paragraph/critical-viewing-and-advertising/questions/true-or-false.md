# True or False — Critical Viewing and Advertising

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. Every electronic media message was created by someone for a purpose. (Sub lesson 1) — True
2. A programme's central theme and main idea cannot be found the way a text's can. (Sub lesson 1) — False
3. Programmes are built to move the viewer's mood. (Sub lesson 2) — True
4. If a story is on film, it must be factual. (Sub lesson 2) — False
5. An advertisement's purpose is worn openly: it wants you to buy, believe or do. (Sub lesson 3) — True
6. Visual and auditory advertisements have exactly the same strengths. (Sub lesson 3) — False
