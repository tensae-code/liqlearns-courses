# The paragraph — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — the paragraph — set by the
pattern across the countries' books: belonging first, then the
naming sentence, then building whole paragraphs by the books'
process.

## Level 1 — belonging
Level 1 questions from the type files. Pass mark: apply Ghana's
test ("Are all the sentences about the topic?") to any set —
find every stranger, every time.

## Level 2 — the naming sentence
Level 2 questions from the type files. Pass mark: pick and write
the topic sentence that promises a paragraph's idea, and tell a
naming sentence from a serving one on sight.

## Level 3 — building the whole paragraph
Level 3 questions from the type files. Pass mark: run Ghana's
road whole — leading questions, answers as sentences, a naming
sentence at the head — and deliver a paragraph that passes the
three-word test read aloud by someone else.
