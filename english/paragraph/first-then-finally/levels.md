# First, then, finally — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
depths inside this one thing — time order — set by the pattern
across the countries' books: the process home first, then the
recount home, then judgment at the joints.

## Level 1 — the process home
Level 1 questions from the type files. Pass mark: signpost a
how-to paragraph whole — First to Finally, comma dress on —
whose steps a stranger could follow without a wrong move.

## Level 2 — the recount home
Level 2 questions from the type files. Pass mark: retell a
finished stretch of time in the past under the set, varying the
middle words (then / next / after that) so the road does not
stutter.

## Level 3 — judgment at the joints
Level 3 questions from the type files. Pass mark: unscramble any
scrambled paragraph by the world's order before reaching for
signposts; rest the signposts where meaning already glues the
steps; and catch a dressed-up wrong order (signposts lying) on
sight.
