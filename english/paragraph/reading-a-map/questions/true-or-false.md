# True or False — Reading a Map

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. A map shows a place as if looking down at it from the sky. (Sub lesson 1) — True
2. The key on a map tells what things on the map mean. (Sub lesson 1) — True
3. The map of Liberia in the book shows 16 cities. (Sub lesson 1) — True
4. North and South are next to each other on the compass. (Sub lesson 2) — False (they are opposites)
5. A compass gives only two directions. (Sub lesson 2) — False (it gives four: North, South, East and West)
6. You can use a compass on a map to find your way. (Sub lesson 2) — True
