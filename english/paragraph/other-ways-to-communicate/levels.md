# Other ways to communicate — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
RANKS inside this one lesson — pass each rank to climb.

## Level 1 — the channels
Level 1 questions from the type files. Pass mark: name the channels — sign language with its parts, Braille, gesture and the wider nonverbal set — and what each is for

## Level 2 — reading signals
Level 2 questions from the type files. Pass mark: read a person's nonverbal signals as a whole set, and finger-spell your name letter by letter

## Level 3 — across cultures
Level 3 questions from the type files. Pass mark: explain, with Ecuador's grid examples, how one gesture changes meaning across cultures — and communicate a short message with no voice and no writing, understood by your partner
