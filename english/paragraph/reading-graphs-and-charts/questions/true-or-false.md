# True or False — Reading Graphs and Charts

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. In a bar graph, a longer bar means a bigger number. (Sub lesson 1) — True
2. The title of a graph tells you what was counted. (Sub lesson 1) — True
3. The shortest bar on a graph is the most. (Sub lesson 1) — False
4. A graph inside a text can carry facts that the words do not say. (Sub lesson 2) — True
5. If you read the words of a text, you never need to read its graph. (Sub lesson 2) — False
6. Interpreting a graph means saying in your own words what the graph shows. (Sub lesson 2) — True
