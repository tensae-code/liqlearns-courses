# True or False — Analysing Speakers and Persuasion

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. A speaker's purpose is always to inform. (Sub lesson 1) — False
2. Tone and mood are part of reading a speaker. (Sub lesson 1) — True
3. Bias means the speaker leans toward one side before the evidence is heard. (Sub lesson 2) — True
4. Every generalisation is false. (Sub lesson 2) — False
5. Emotive language is chosen to fire feelings. (Sub lesson 2) — True
6. Judging a speaker includes judging the sources of their facts. (Sub lesson 3) — True
7. A speaker's intentions are never worth asking about. (Sub lesson 3) — False
