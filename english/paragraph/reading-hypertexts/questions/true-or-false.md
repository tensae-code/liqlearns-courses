# True or False — Reading Hypertexts and Digital Navigation

(Every item is marked with the sub lesson it belongs to: (Sub lesson N). The gate pool for a sub lesson is all of that sub lesson's questions — no hardness ranking is written in questions/, so the whole set is the pool.)

1. A hypertext is read top to bottom like a printed page, and never by moving. (Sub lesson 1) — False
2. The global structure of a page is one of its organisers for navigation. (Sub lesson 1) — True
3. Links lead the reader to other places in the text or beyond it. (Sub lesson 1) — True
4. Symbols on a page are decoration and signal nothing. (Sub lesson 1) — False
5. Every hypertext is organised in exactly the same way. (Sub lesson 2) — False
6. A good navigator always knows which place they are in and how they got there. (Sub lesson 2) — True
