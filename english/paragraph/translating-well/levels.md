# Translating well — questions by level

Practice by level, tied to the skill number. The questions live in
the type files; this file is the by-level view. The levels are the
RANKS inside this one lesson — pass each rank to climb.

## Level 1 — the law
Level 1 questions from the type files. Pass mark: state Bolivia's principle — word-for-word rarely applicable — and name the two cares: grammatical categories and differing word order

## Level 2 — the repair shop
Level 2 questions from the type files. Pass mark: take word-for-word failures and rebuild them meaning-first, including one idiom carried as a whole

## Level 3 — the real crossing
Level 3 questions from the type files. Pass mark: translate a whole short newspaper or magazine article both ways (English→Spanish / Spanish→English, in Bolivia's set; any pair the learner owns, in this course) following the guidelines, and read it aloud as a text, not as a translation
