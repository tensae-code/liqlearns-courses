# Translating well — true or false

Say true or false. If it is false, say why.

**1. (Level 1)** This lesson is built from many countries' translation teaching. **Answer: False** — one source only: Bolivia, Year 6, Topic 7.3 — stated plainly and never padded

**2. (Level 2)** If every word is translated correctly, the translation must be correct. **Answer: False** — all the right words can still carry none of the meaning when structure and order differ

**3. (Level 3)** Bolivia sets learners to translate real newspaper and magazine texts in both directions. **Answer: True** — its production task: two articles, English to Spanish / Spanish to English, read in class
