# Translating well — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to. The files' old depth groups map onto the sub lessons as: (Level 1) -> Sub lesson 1 — The Law of Translation · (Level 2) -> Sub lesson 2 — The Translation Repair Shop · (Level 3) -> Sub lesson 3 — The Real Crossing.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** This lesson is built from many countries' translation teaching. **Answer: False** — one source only: Bolivia, Year 6, Topic 7.3 — stated plainly and never padded

**2. (Sub lesson 2)** If every word is translated correctly, the translation must be correct. **Answer: False** — all the right words can still carry none of the meaning when structure and order differ

**3. (Sub lesson 3)** Bolivia sets learners to translate real newspaper and magazine texts in both directions. **Answer: True** — its production task: two articles, English to Spanish / Spanish to English, read in class
