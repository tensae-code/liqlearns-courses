# Blending sounds — true or false

True-or-false questions only. Answers at the bottom.

## Level 1
1. Blending means saying each sound alone, forever apart. (True / False)
2. s, a, t, p, i, n can already make whole words. (True / False)
3. You must know all 26 letters before you can blend any word. (True / False)

## Answers
1-False (the sounds slide together), 2-True (sit, pat, tin, pin),
3-False (a few letters in the right order open words early)
