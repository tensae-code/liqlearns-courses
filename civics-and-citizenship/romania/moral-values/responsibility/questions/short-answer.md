# Responsibility — short answer

Answer in a sentence or two, in your own words.

**1.** What is this lesson's one thing, in your own words?
**Answer:** Responsibility answers for one's own acts and duties — against irresponsibility, which shrugs and blames others.

**2.** What does this lesson add?
**Answer:** Responsibility closes the values unit because it is the value that carries all the others into action: a value you will not answer for is only a word.
