# Responsibility — multiple choice

Pick the one right answer.

**1.** What does this lesson teach?
a) Responsibility answers for one's own acts and duties — against irresponsibility, which shrugs and blames others.  b) it teaches nothing in particular  c) the opposite of the book's teaching  d) only adults need it
**Answer: a)** — That is what this lesson teaches.

**2.** Which of these belongs to this lesson?
a) Responsibility closes the values unit because it is the value that carries all the others into action: a value you will not answer for is only a word.  b) a rule invented this morning with no source  c) the opposite of the lesson  d) nothing in the lesson covers it
**Answer: a)** — That is what the lesson teaches.
