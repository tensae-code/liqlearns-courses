# Respect — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Respect honours every person's worth — against disrespect — and it is owed to all, not only to the powerful.
**Answer: True**

**2.** This lesson's teaching does not apply to a child's own home, school or community in Romania.
**Answer: False** — The lesson teaches the opposite: it is learned from life in Romania and lived there.
