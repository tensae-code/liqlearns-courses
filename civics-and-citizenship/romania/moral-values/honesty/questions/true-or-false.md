# Honesty — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Honesty says and does what is true — in words, in work and in dealings — against dishonesty, which deceives.
**Answer: True**

**2.** This lesson's teaching does not apply to a child's own home, school or community in Romania.
**Answer: False** — The lesson teaches the opposite: it is learned from life in Romania and lived there.
