# Honesty Strengthens Relations — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Honesty tightens neighbourly relations.
**Answer: True**

**2.** This lesson teaches that Honesty Strengthens Relations — and that it has no connection to the rest of Malaysia's story.
**Answer: False** — The lesson places it inside Malaysia's own course, in its own order.
