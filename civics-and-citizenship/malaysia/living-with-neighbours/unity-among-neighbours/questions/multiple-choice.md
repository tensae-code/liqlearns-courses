# Unity Among Neighbours — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) Strengthening unity among neighbours, joining in each other's festivals (decorating a Christmas tree together).  b) it has nothing to do with how Malaysia governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) Strengthening unity among neighbours, joining in each other's festivals (decorating a Christmas tree together).** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) Strengthening unity among neighbours, joining in each other's festivals (decorating a Christmas tree together).  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Malaysia
**Answer: a) Strengthening unity among neighbours, joining in each other's festivals (decorating a Christmas tree together).** — That is what this lesson teaches.
