# Steady Effort Brings Wellbeing — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Continuous effort brings wellbeing — neighbours weaving used paper together day after day.
**Answer: True**

**2.** This lesson teaches that Steady Effort Brings Wellbeing — and that it has no connection to the rest of Malaysia's story.
**Answer: False** — The lesson places it inside Malaysia's own course, in its own order.
