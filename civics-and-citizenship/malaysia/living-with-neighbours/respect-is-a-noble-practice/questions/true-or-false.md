# Respect is a Noble Practice — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Respecting neighbours as a noble practice, taught through pantun verses and a model neighbour's diary.
**Answer: True**

**2.** This lesson teaches that Respect is a Noble Practice — and that it has no connection to the rest of Malaysia's story.
**Answer: False** — The lesson places it inside Malaysia's own course, in its own order.
