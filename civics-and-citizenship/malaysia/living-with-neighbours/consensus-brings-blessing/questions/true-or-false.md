# Consensus Brings Blessing — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Consensus brings blessing — fathers joining the Voluntary Patrol Scheme (SRS) together, in the unit's blog story.
**Answer: True**

**2.** This lesson teaches that Consensus Brings Blessing — and that it has no connection to the rest of Malaysia's story.
**Answer: False** — The lesson places it inside Malaysia's own course, in its own order.
