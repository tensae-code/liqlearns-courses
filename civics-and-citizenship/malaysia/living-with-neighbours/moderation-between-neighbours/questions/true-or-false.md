# Moderation Between Neighbours — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Moderation (kesederhanaan) weaves closeness between neighbours.
**Answer: True**

**2.** This lesson teaches that Moderation Between Neighbours — and that it has no connection to the rest of Malaysia's story.
**Answer: False** — The lesson places it inside Malaysia's own course, in its own order.
