# Tolerance a Praiseworthy Practice — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Tolerance (bertolak ansur) as a praiseworthy practice — patience when the road to extra class is closed.
**Answer: True**

**2.** This lesson teaches that Tolerance a Praiseworthy Practice — and that it has no connection to the rest of Malaysia's story.
**Answer: False** — The lesson places it inside Malaysia's own course, in its own order.
