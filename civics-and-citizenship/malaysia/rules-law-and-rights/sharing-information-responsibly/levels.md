# Sharing Information Responsibly — depth

This lesson is ONE lesson with no sub lessons: it teaches a single thing, whole. Practice is tied to the learner's skill number. The questions live in the type files.

Pass mark: The proper way to use sources and spread information — check that it is true, get confirmation from those concerned, name the source, avoid sensitive issues and personal attacks, and never hack, plagiarise or add to what was said — shown in the learner's own words and one real example.
