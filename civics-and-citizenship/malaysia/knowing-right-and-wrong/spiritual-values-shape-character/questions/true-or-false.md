# Spiritual Values Shape Character — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** The traits of a person who holds spiritual values — holding firmly to their religion or belief, fair, honest, brave in upholding truth, loving themselves, respecting others and grateful for life.
**Answer: True**

**2.** This lesson teaches that Spiritual Values Shape Character — and that it has no connection to the rest of Malaysia's story.
**Answer: False** — The lesson places it inside Malaysia's own course, in its own order.
