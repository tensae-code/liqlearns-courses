# Building a Noble Character — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) Building noble character through absorbing pure values — a balanced person in intellect, spirit, emotion and body.  b) it has nothing to do with how Malaysia governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) Building noble character through absorbing pure values — a balanced person in intellect, spirit, emotion and body.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) Building noble character through absorbing pure values — a balanced person in intellect, spirit, emotion and body.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Malaysia
**Answer: a) Building noble character through absorbing pure values — a balanced person in intellect, spirit, emotion and body.** — That is what this lesson teaches.
