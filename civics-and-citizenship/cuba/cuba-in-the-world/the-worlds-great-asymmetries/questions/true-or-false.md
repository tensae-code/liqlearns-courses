# The Worlds Great Asymmetries — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** The main problems of the twenty-first-century world — the great asymmetries between rich and poor countries.
**Answer: True**

**2.** This lesson teaches that The Worlds Great Asymmetries — and that it has no connection to the rest of Cuba's story.
**Answer: False** — The lesson places it inside Cuba's own course, in its own order.
