# Socialist Legality — true or false

Say whether each statement is true or false, and be ready to say why.

**Answer: True**

**2.** This lesson teaches that Socialist Legality — and that it has no connection to the rest of Cuba's story.
**Answer: False** — The lesson places it inside Cuba's own course, in its own order.
