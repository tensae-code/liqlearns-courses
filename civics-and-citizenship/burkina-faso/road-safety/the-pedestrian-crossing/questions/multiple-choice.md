# The Pedestrian Crossing — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) The zebra crossing and how to use it.  b) it has nothing to do with how Burkina Faso governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) The zebra crossing and how to use it.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) The zebra crossing and how to use it.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Burkina Faso
**Answer: a) The zebra crossing and how to use it.** — That is what this lesson teaches.
