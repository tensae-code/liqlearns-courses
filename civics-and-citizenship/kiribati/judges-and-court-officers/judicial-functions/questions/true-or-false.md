# Judicial Functions — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Judicial administration has dimensions the syllabus names; and a judgment or decision has elements — the parts that must be present for the decision to be complete.
**Answer: True**

**2.** This lesson teaches that judicial officers do two main functions, administer justice in set dimensions, and end cases with a judgment built from named elements. This lesson stands on the KCSE Civic syllabus alone — evidence only, labelled as such. — and that it has no connection to the rest of Kiribati's story.
**Answer: False** — The lesson places it inside Kiribati's own course, in its own order.
