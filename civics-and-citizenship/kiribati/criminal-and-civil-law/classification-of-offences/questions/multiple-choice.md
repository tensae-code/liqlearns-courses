# Classification of Offences — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's first teaching — What an offence is?
a) An offence is an act the law forbids and punishes; the syllabus defines it before sorting it.  b) it has nothing to do with how Kiribati governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) An offence is an act the law forbids and punishes; the syllabus defines it before sorting it.** — That is what this lesson teaches.

a) offences are classified: Kiribati sorts offences into classes — including a third, intermediate class — and the class decides how a case is handled. This lesson stands on the KCSE Civic syllabus alone — evidence only, labelled as such.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Kiribati
**Answer: a) offences are classified: Kiribati sorts offences into classes — including a third, intermediate class — and the class decides how a case is handled. This lesson stands on the KCSE Civic syllabus alone — evidence only, labelled as such.** — That is what this lesson teaches.
