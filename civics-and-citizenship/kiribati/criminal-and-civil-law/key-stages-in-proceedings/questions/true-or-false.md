# Key Stages in Proceedings — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Each stage has its own purpose and its own actors; the syllabus teaches the differences between them, so a stage is never confused with the next.
**Answer: True**

**2.** This lesson teaches that every criminal proceeding walks the same road in stages — and knowing the stages, and how they differ, is knowing how a case actually moves. This lesson stands on the KCSE Civic syllabus alone — evidence only, labelled as such. — and that it has no connection to the rest of Kiribati's story.
**Answer: False** — The lesson places it inside Kiribati's own course, in its own order.
