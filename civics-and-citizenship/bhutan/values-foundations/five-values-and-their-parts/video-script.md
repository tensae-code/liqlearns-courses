# Video script — The Five Values and Their Parts

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

This lesson is about one thing.
Each core value is taught through named sub-values — Respect: courtesy, gratitude, respect; Responsibility: punctuality, determination, duty; Compassion: generosity, care, kindness, helpfulness; Integrity: honesty, trustworthiness, honour; Loyalty: patriotism, obedience, unity
