# The Five Values and Their Parts — depth

This lesson is ONE lesson with no sub lessons: it teaches a single thing, whole. Practice is tied to the learner's skill number. The questions live in the type files.

Pass mark: Each core value is taught through named sub-values — Respect: courtesy, gratitude, respect; Responsibility: punctuality, determination, duty; Compassion: generosity, care, kindness, helpfulness; Integrity: honesty, trustworthiness, honour; Loyalty: patriotism, obedience, unity — shown in the learner's own words and one real example.
