# How a Values Lesson Is Built — depth

This lesson is ONE lesson with no sub lessons: it teaches a single thing, whole. Practice is tied to the learner's skill number. The questions live in the type files.

Pass mark: Every lesson activity in the book is built the same way — lesson objectives (concepts, importance and rationale for practising the value), information for teachers, teaching-learning materials, lesson procedure and activities — the four core elements of effective values education — shown in the learner's own words and one real example.
