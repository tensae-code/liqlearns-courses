# How a Values Lesson Is Built — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Every lesson activity in the book is built the same way — lesson objectives (concepts, importance and rationale for practising the value), information for teachers, teaching-learning materials, lesson procedure and activities — the four core elements of effective values education
**Answer: True**

**2.** This lesson teaches that How a Values Lesson Is Built — and that it has no connection to the rest of Bhutan's story.
**Answer: False** — The lesson places it inside Bhutan's own course, in its own order.
