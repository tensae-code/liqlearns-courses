# Duty and Right Conduct — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) Duty as right conduct — doing what is yours to do, properly  b) it has nothing to do with how Bhutan governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) Duty as right conduct — doing what is yours to do, properly** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) Duty as right conduct — doing what is yours to do, properly  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Bhutan
**Answer: a) Duty as right conduct — doing what is yours to do, properly** — That is what this lesson teaches.
