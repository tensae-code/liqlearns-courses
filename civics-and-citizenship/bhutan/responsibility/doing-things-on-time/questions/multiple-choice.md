# Doing Things on Time — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) Doing things on time as a daily habit  b) it has nothing to do with how Bhutan governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) Doing things on time as a daily habit** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) Doing things on time as a daily habit  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Bhutan
**Answer: a) Doing things on time as a daily habit** — That is what this lesson teaches.
