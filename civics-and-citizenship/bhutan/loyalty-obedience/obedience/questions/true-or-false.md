# Obedience — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Loyalty begins as obedience to parents and elders
**Answer: True**

**2.** This lesson teaches that Obedience — and that it has no connection to the rest of Bhutan's story.
**Answer: False** — The lesson places it inside Bhutan's own course, in its own order.
