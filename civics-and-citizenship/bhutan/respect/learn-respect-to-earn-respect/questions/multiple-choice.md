# Learn Respect to Earn Respect — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) Respectful behaviour drawn and practised towards different people, starting with not talking back to parents  b) it has nothing to do with how Bhutan governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) Respectful behaviour drawn and practised towards different people, starting with not talking back to parents** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) Respectful behaviour drawn and practised towards different people, starting with not talking back to parents  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Bhutan
**Answer: a) Respectful behaviour drawn and practised towards different people, starting with not talking back to parents** — That is what this lesson teaches.
