# Learn Respect to Earn Respect

## Do it first

Before anyone explains anything, say in your own words what you already think this is about: Learn Respect to Earn Respect. Write it or say it aloud — this lesson starts from what Bhutan's own book teaches about it, and you will compare your first thought with the book's teaching as you go.

Respectful behaviour drawn and practised towards different people, starting with not talking back to parents
