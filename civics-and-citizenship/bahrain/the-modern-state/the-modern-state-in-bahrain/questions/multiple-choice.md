# The Modern State in Bahrain — multiple choice

Pick the one right answer.

**1.** What does this lesson teach?
a) Bahrain is a modern state — a state with institutions, laws and a government that serves the whole country, and the pupil can say how that state arose and what it consists of.  b) it teaches nothing in particular  c) the opposite of the book's teaching  d) only adults need it

**2.** Which of these belongs to this lesson?
a) The state is met through its institutions in daily life before it is studied as an idea.  b) a rule invented this morning with no source  c) the opposite of the lesson  d) nothing in the lesson covers it
