# Lesson plan — Functions of the State

**Course:** Civics and Citizenship — Greece · **Title:** The Individual and the State · **Lesson:** Functions of the State
**Place in the curriculum:** Level 1 — The Individual and the State (CURRICULUM.md).
**The one thing this lesson teaches:** the state does its work through distinct functions — making laws, carrying them out, and judging disputes under them.
**This lesson's own level:** Level 1 — The Individual and the State — it stands on the lessons before it in path order (recommended, never forced).

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The law-making function** — One function of the state is to make the laws — the general rules everyone lives under.
2. **The executive function** — A second function carries the laws out: governing day to day, running services, and keeping the country safe.
3. **The judging function** — A third function judges: courts settle disputes and decide cases under the laws, independently.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## If the learner is stuck
- Thinks one office should do all the state's work → separating the functions protects the citizen: the body that makes a law is not the body that judges a case under it.
- Go back to the one thing: the state does its work through distinct functions — making laws, carrying them out, and judging disputes under them. Work the Do it first act again, slowly, and name each step aloud.
