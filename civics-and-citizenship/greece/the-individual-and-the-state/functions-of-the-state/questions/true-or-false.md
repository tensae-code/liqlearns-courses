# Functions of the State — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** This lesson's teaching has nothing to do with the life of an ordinary citizen in Greece.
**Answer: False** — The state does its work through distinct functions — making laws, carrying them out, and judging disputes under them.

**2.** One function of the state is to make the laws — the general rules everyone lives under.
**Answer: True**
