# Functions of the State — matching

Match each word with its meaning.

**1.** The law-making function — a)

**2.** The executive function — b)

**3.** The judging function — c)


Meanings:
a) One function of the state is to make the laws — the general rules everyone lives under.
b) A second function carries the laws out: governing day to day, running services, and keeping the country safe.
c) A third function judges: courts settle disputes and decide cases under the laws, independently.

**Answer key:** 1. a; 2. b; 3. c
