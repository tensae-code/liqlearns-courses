# Organising and Investing Time — depth

This lesson is ONE lesson with no sub lessons: it teaches a single thing, whole. Practice is tied to the learner's skill number. The questions live in the type files.

Pass mark: Time as one of man's greatest resources, for which he will be asked; the importance of organising it; the time-wasters, outer (other people) and inner (oneself); and investing time by a daily plan — time set for each task, priorities first, appointments kept, and distance from the wasters — shown in the learner's own words and one real example.
