# Not Taking or Using Others' Things — multiple choice

Pick the one right answer.

**1.** What does this lesson teach?
a) never taking or using another person's things without asking  b) it teaches nothing in particular  c) the opposite of the book's teaching  d) only adults need it
**Answer: a)** — That is what this lesson teaches.

**2.** Which of these belongs to this lesson?
a) never taking or using another person's things without asking  b) a rule invented this morning with no source  c) the opposite of the lesson  d) nothing in the lesson covers it
**Answer: a)** — That is what the lesson teaches.
