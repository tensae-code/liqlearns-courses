# The Pohnpei Model — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Authority in Pohnpei flowed through the title system — rising through titles meant rising in responsibility as well as honour.
**Answer: True**

**2.** This lesson teaches that Pohnpei's traditional leadership model — a system of titles and ranks through which authority was ordered and shared — and that it has no connection to the rest of the FSM's story.
**Answer: False** — The lesson places it inside the FSM's one long story of self-government.
