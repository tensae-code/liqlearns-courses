# Checks and Balances — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Checks and balances turn the separation of powers from three sealed boxes into one shared government, each part inside the others' sight.
**Answer: True**

**2.** This lesson teaches that the FSM's branches check each other so no branch rules alone — and the book is honest about where those checks strain — and that it has no connection to the rest of the FSM's story.
**Answer: False** — The lesson places it inside the FSM's one long story of self-government.
