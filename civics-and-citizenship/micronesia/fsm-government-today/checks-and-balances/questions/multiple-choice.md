# Checks and Balances — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's first teaching — How the branches check each other?
a) Each branch holds tools against the others: laws can be blocked, actions reviewed, appointments and spending watched, judgments enforced or resisted through lawful channels.  b) it has nothing to do with how the FSM governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) Each branch holds tools against the others: laws can be blocked, actions reviewed, appointments and spending watched, judgments enforced or resisted through lawful channels.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) the FSM's branches check each other so no branch rules alone — and the book is honest about where those checks strain  b) government began only when foreigners arrived  c) citizens should never question leaders  d) all islands govern in exactly the same way
**Answer: a) the FSM's branches check each other so no branch rules alone — and the book is honest about where those checks strain** — That is what this lesson teaches.
