# Rights Carry Duties — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Every citizen's right in a democracy is bound to a duty.
**Answer: True**

**2.** This lesson teaches that Rights Carry Duties — and that it has no connection to the rest of Sri Lanka's story.
**Answer: False** — The lesson places it inside Sri Lanka's own course, in its own order.
