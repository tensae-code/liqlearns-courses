# Using Resources Economically — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) Using water, electricity and other resources without waste.  b) it has nothing to do with how Sri Lanka governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) Using water, electricity and other resources without waste.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) Using water, electricity and other resources without waste.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Sri Lanka
**Answer: a) Using water, electricity and other resources without waste.** — That is what this lesson teaches.
