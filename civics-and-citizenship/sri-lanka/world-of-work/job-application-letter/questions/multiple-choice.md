# Job Application Letter — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) Writing a letter applying for a vacancy.  b) it has nothing to do with how Sri Lanka governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) Writing a letter applying for a vacancy.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) Writing a letter applying for a vacancy.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Sri Lanka
**Answer: a) Writing a letter applying for a vacancy.** — That is what this lesson teaches.
