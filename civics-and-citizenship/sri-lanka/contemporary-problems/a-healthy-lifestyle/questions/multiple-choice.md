# A Healthy Lifestyle — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) The need to get used to a healthy lifestyle as a contemporary civic concern.  b) it has nothing to do with how Sri Lanka governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) The need to get used to a healthy lifestyle as a contemporary civic concern.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) The need to get used to a healthy lifestyle as a contemporary civic concern.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Sri Lanka
**Answer: a) The need to get used to a healthy lifestyle as a contemporary civic concern.** — That is what this lesson teaches.
