# Working to a Plan — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** The school works to a plan and timetable; pupils plan their own work the same way; planning the day, using time well, keeping the classroom and school clean and beautiful.
**Answer: True**

**2.** This lesson teaches that Working to a Plan — and that it has no connection to the rest of Sri Lanka's story.
**Answer: False** — The lesson places it inside Sri Lanka's own course, in its own order.
