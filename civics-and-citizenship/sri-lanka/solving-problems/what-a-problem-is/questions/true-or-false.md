# What a Problem Is — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** A problem is the gap between the situation as it is and as it should be — a barrier to reaching a goal.
**Answer: True**

**2.** This lesson teaches that What a Problem Is — and that it has no connection to the rest of Sri Lanka's story.
**Answer: False** — The lesson places it inside Sri Lanka's own course, in its own order.
