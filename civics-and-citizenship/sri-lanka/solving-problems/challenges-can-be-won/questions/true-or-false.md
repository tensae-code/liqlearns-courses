# Challenges Can Be Won — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Examinations, poverty and sport are all challenges of the same kind, and people like Soichiro Honda won theirs by a creative mind.
**Answer: True**

**2.** This lesson teaches that Challenges Can Be Won — and that it has no connection to the rest of Sri Lanka's story.
**Answer: False** — The lesson places it inside Sri Lanka's own course, in its own order.
