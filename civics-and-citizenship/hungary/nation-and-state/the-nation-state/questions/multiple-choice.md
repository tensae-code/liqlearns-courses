# The Nation-State — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) The nation-state.  b) it has nothing to do with how Hungary governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) The nation-state.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) The nation-state.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Hungary
**Answer: a) The nation-state.** — That is what this lesson teaches.
