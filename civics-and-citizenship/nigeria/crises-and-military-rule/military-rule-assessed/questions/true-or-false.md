# Military Rule Assessed — true or false

Say whether each statement is true or false, and be ready to say why.

**Answer: True**

**2.** This lesson teaches that military Rule Assessed — and that it has no connection to the rest of Nigeria's story.
**Answer: False** — The lesson places it inside Nigeria's own course, in its own order.
