# The State — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** The state is the permanent political community with its own features, and it is not the same thing as the government of the day, which comes and goes.
**Answer: True**

**2.** This lesson teaches that the State — and that it has no connection to the rest of Nigeria's story.
**Answer: False** — The lesson places it inside Nigeria's own course, in its own order.
