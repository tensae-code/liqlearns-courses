# Nigeria's Foreign Policy — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) Nigeria's foreign policy is shaped by set factors, pursues set aims, and places Africa as its centrepiece.  b) it has nothing to do with how Nigeria governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) Nigeria's foreign policy is shaped by set factors, pursues set aims, and places Africa as its centrepiece.** — That is what this lesson teaches.

**Answer: a) Nigeria's foreign policy is shaped by set factors, pursues set aims, and places Africa as its centrepiece.** — That is what this lesson teaches.
