# The Presidential System — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** In the presidential system the executive is separately elected, holds a fixed term, and stands outside the legislature.
**Answer: True**

**2.** This lesson teaches that the Presidential System — and that it has no connection to the rest of Nigeria's story.
**Answer: False** — The lesson places it inside Nigeria's own course, in its own order.
