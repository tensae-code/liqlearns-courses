# The Parliamentary System — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** In the parliamentary or cabinet system the executive sits in the legislature and governs only while it keeps the legislature's confidence.
**Answer: True**

**2.** This lesson teaches that the Parliamentary System — and that it has no connection to the rest of Nigeria's story.
**Answer: False** — The lesson places it inside Nigeria's own course, in its own order.
