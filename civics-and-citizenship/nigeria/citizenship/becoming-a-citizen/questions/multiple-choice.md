# Becoming a Citizen — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) Citizenship is acquired in set ways, and there are different types of citizenship a person can hold.  b) it has nothing to do with how Nigeria governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) Citizenship is acquired in set ways, and there are different types of citizenship a person can hold.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) Citizenship is acquired in set ways, and there are different types of citizenship a person can hold.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Nigeria
**Answer: a) Citizenship is acquired in set ways, and there are different types of citizenship a person can hold.** — That is what this lesson teaches.
