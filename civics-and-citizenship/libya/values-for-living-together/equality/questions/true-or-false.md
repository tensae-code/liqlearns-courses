# Equality — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Equality is the same rights and the same duties for all, practised first inside the classroom.
**Answer: True**

**2.** This lesson teaches that equality — and that it has no connection to the rest of Libya's story.
**Answer: False** — The lesson places it inside Libya's own course, in its own order.
