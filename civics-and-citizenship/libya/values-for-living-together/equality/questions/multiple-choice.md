# Equality — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) Equality is the same rights and the same duties for all, practised first inside the classroom.  b) it has nothing to do with how Libya governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) Equality is the same rights and the same duties for all, practised first inside the classroom.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) Equality is the same rights and the same duties for all, practised first inside the classroom.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Libya
**Answer: a) Equality is the same rights and the same duties for all, practised first inside the classroom.** — That is what this lesson teaches.
