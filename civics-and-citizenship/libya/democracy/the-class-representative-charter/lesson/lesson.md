# The Class Representative Charter

## Do it first

Before anyone explains anything, say in your own words what you already think this is about: the Class Representative Charter. Write it or say it aloud — this lesson starts from what Libya's own book teaches about it, and you will compare your first thought with the book's teaching as you go.

The class drafts its charter and elects its representative, pledging respect for the school’s internal order — a project placement.
