# Freedom — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** The kinds of freedom — life, belief, thought, expression, press, movement, personal, political and economic — each with its marks.
**Answer: True**

**2.** This lesson teaches that freedom — and that it has no connection to the rest of Libya's story.
**Answer: False** — The lesson places it inside Libya's own course, in its own order.
