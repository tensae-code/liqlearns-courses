# The Class Election — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** The course ends by doing the thing itself: the class runs a full mock election — nominations, campaign posters, polling and counting — and practises democracy by running one.
**Answer: True**

**2.** This lesson teaches that the Class Election — and that it has no connection to the rest of Vanuatu's story.
**Answer: False** — The lesson places it inside Vanuatu's own course, in its own order.
