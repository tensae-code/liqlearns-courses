# Community Action for a Shared Issue — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** A class can act as citizens on a real issue: name a sustainability issue in your own community, decide together with a decision-making grid, plan collaborative action, act, and reflect on what the action did.
**Answer: True**

**2.** This lesson teaches that community Action for a Shared Issue — and that it has no connection to the rest of Vanuatu's story.
**Answer: False** — The lesson places it inside Vanuatu's own course, in its own order.
