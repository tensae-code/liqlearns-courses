# Building an Autonomous Personality — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) Building an autonomous personality.  b) it has nothing to do with how North Macedonia governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) Building an autonomous personality.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) Building an autonomous personality.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in North Macedonia
**Answer: a) Building an autonomous personality.** — That is what this lesson teaches.
