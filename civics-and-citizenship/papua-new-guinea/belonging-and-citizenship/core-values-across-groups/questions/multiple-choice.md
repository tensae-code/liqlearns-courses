# Core Values Across Groups — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) Core values holding together a nation of many ethnic groups and political beliefs.  b) it has nothing to do with how Papua New Guinea governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) Core values holding together a nation of many ethnic groups and political beliefs.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) Core values holding together a nation of many ethnic groups and political beliefs.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Papua New Guinea
**Answer: a) Core values holding together a nation of many ethnic groups and political beliefs.** — That is what this lesson teaches.
