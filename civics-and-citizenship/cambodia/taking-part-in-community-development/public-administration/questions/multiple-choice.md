# Public Administration — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) How public administration serves the citizen.  b) it has nothing to do with how Cambodia governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) How public administration serves the citizen.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) How public administration serves the citizen.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Cambodia
**Answer: a) How public administration serves the citizen.** — That is what this lesson teaches.
