# Working Together for All — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) Joining hands to work for everyone's benefit.  b) it has nothing to do with how Myanmar governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) Joining hands to work for everyone's benefit.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) Joining hands to work for everyone's benefit.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Myanmar
**Answer: a) Joining hands to work for everyone's benefit.** — That is what this lesson teaches.
