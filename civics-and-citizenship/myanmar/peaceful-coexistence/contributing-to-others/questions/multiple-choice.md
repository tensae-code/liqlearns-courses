# Contributing to Others — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) Contributing so that others benefit.  b) it has nothing to do with how Myanmar governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) Contributing so that others benefit.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) Contributing so that others benefit.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Myanmar
**Answer: a) Contributing so that others benefit.** — That is what this lesson teaches.
