# Clean Environment — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) Keeping the environment nice and clean.  b) it has nothing to do with how Myanmar governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) Keeping the environment nice and clean.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) Keeping the environment nice and clean.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Myanmar
**Answer: a) Keeping the environment nice and clean.** — That is what this lesson teaches.
