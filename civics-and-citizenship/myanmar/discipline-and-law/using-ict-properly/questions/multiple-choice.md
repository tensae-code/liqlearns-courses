# Using Ict Properly — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) Using ICT devices properly and correctly.  b) it has nothing to do with how Myanmar governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) Using ICT devices properly and correctly.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) Using ICT devices properly and correctly.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Myanmar
**Answer: a) Using ICT devices properly and correctly.** — That is what this lesson teaches.
