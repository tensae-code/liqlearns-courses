# Duty Wherever Placed — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) Discharging one's duty in whatever place one finds oneself.  b) it has nothing to do with how Myanmar governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) Discharging one's duty in whatever place one finds oneself.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) Discharging one's duty in whatever place one finds oneself.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Myanmar
**Answer: a) Discharging one's duty in whatever place one finds oneself.** — That is what this lesson teaches.
