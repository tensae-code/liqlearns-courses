# Globalisation and Mondialité — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Globalisation and mondialité are each defined, and the difference between them is taught — precision about the world's interconnection.
**Answer: True**

**2.** The analysis comes home: globalisation's effects in Haiti are examined, so the world citizen judges the process from where they stand.
**Answer: True**

**3.** This lesson teaches that globalisation and mondialité are not the same word for the same thing — the programme defines both, tells them apart, and analyses globalisation's effects in Haiti — and that it has no connection to the rest of Haiti's story.
**Answer: False** — The lesson places it inside Haiti's own course, in its own order.
