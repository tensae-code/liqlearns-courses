# Memory and the Duty of Memory

## Do it first

Write down one event from your family's or your country's past that you think must never be forgotten. This lesson asks why remembering is a citizen's duty.

## Sub lesson 1 — The kinds of memory

Memory is not one thing: the programme distinguishes individual memory, collective memory, historical memory and social memory — and teaches why memory matters.

## Sub lesson 2 — The duty of memory in the state

The duty of memory is not private: it plays its part in the social, political and economic organisation of a state.

## Say it to your companion

Tell your companion what this lesson teaches: a people must remember — memory comes in kinds (individual, collective, historical, social), and the duty of memory shapes how a state is organised. Give one real example from your own life or from the Haiti you live in, and name the lesson's key words: memory, duty of memory, collective, historical. Your companion asks one question back — answer it from the lesson.
