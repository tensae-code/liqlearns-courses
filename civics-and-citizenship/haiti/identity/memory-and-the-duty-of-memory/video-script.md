# Video script — Memory and the Duty of Memory

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

This lesson is about one thing.
A people must remember — memory comes in kinds (individual, collective, historical, social), and the duty of memory shapes how a state is organised.

Memory is not one thing: the programme distinguishes individual memory, collective memory, historical memory and social memory — and teaches why memory matters.

The duty of memory is not private: it plays its part in the social, political and economic organisation of a state.

Now you. Say it back, in your own words. Then go and do it — today, at home, at school, in your street.
