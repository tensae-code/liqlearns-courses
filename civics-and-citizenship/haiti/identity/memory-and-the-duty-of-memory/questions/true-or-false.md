# Memory and the Duty of Memory — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Memory is not one thing: the programme distinguishes individual memory, collective memory, historical memory and social memory — and teaches why memory matters.
**Answer: True**

**2.** The duty of memory is not private: it plays its part in the social, political and economic organisation of a state.
**Answer: True**

**3.** This lesson teaches that a people must remember — memory comes in kinds (individual, collective, historical, social), and the duty of memory shapes how a state is organised — and that it has no connection to the rest of Haiti's story.
**Answer: False** — The lesson places it inside Haiti's own course, in its own order.
