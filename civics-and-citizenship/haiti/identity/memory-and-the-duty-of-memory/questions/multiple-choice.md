# Memory and the Duty of Memory — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching — The kinds of memory?
a) Memory is not one thing: the programme distinguishes individual memory, collective memory, historical memory and social memory — and teaches why memory matters.  b) it has nothing to do with how Haiti governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) Memory is not one thing: the programme distinguishes individual memory, collective memory, historical memory and social memory — and teaches why memory matters.** — That is what this lesson teaches.

**2.** Which statement best gives this lesson's teaching — The duty of memory in the state?
a) The duty of memory is not private: it plays its part in the social, political and economic organisation of a state.  b) it has nothing to do with how Haiti governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) The duty of memory is not private: it plays its part in the social, political and economic organisation of a state.** — That is what this lesson teaches.

**3.** What is this lesson's one thing?
a) a people must remember — memory comes in kinds (individual, collective, historical, social), and the duty of memory shapes how a state is organised.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Haiti
**Answer: a) a people must remember — memory comes in kinds (individual, collective, historical, social), and the duty of memory shapes how a state is organised.** — That is what this lesson teaches.
