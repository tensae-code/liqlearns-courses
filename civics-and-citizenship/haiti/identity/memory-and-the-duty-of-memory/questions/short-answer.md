# Memory and the Duty of Memory — short answer

Answer in a sentence or two, in your own words.

**1.** In your own words, what does the part "The kinds of memory" teach?
**Answer:** Memory is not one thing: the programme distinguishes individual memory, collective memory, historical memory and social memory — and teaches why memory matters.

**2.** In your own words, what does the part "The duty of memory in the state" teach?
**Answer:** The duty of memory is not private: it plays its part in the social, political and economic organisation of a state.

**3.** In your own words, state this lesson's one thing.
**Answer:** A people must remember — memory comes in kinds (individual, collective, historical, social), and the duty of memory shapes how a state is organised.
