# Security Institutions — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** The programme teaches the pupil to identify Haiti's security institutions and the links between them — and to judge their initiatives and decisions, as a citizen should.
**Answer: True**

**2.** This lesson teaches that Haiti has named security institutions, linked to each other — the citizen can identify them and judge their initiatives and decisions — and that it has no connection to the rest of Haiti's story.
**Answer: False** — The lesson places it inside Haiti's own course, in its own order.
