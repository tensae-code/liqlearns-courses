# Security for Rejuvenation — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** A strong guarantee for rejuvenation — the overall national security outlook, defence modernisation, and "one country, two systems" and reunification.
**Answer: True**

**2.** This lesson teaches that Security for Rejuvenation — and that it has no connection to the rest of China's story.
**Answer: False** — The lesson places it inside China's own course, in its own order.
