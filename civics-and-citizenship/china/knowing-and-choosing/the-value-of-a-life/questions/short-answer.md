# The Value of a Life — short answer

Answer in a sentence or two, in your own words.

**1.** In your own words, what does this lesson teach?
**Answer:** Value and values — what values are and how they guide conduct; value judgement and value choice — standing with the people's interests; creating and realising the value of a life through work and contribution; project on upholding historical materialism and opposing historical nihilism.
