# Global Warming — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) Global warming, in the project that makes pupils guardians of the planet.  b) it has nothing to do with how the Dominican Republic governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) Global warming, in the project that makes pupils guardians of the planet.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) Global warming, in the project that makes pupils guardians of the planet.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in the Dominican Republic
**Answer: a) Global warming, in the project that makes pupils guardians of the planet.** — That is what this lesson teaches.
