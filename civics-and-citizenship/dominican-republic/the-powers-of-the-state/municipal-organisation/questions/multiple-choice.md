# Municipal Organisation — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) How the municipality is organised — the nearest level of the State.  b) it has nothing to do with how the Dominican Republic governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) How the municipality is organised — the nearest level of the State.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) How the municipality is organised — the nearest level of the State.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in the Dominican Republic
**Answer: a) How the municipality is organised — the nearest level of the State.** — That is what this lesson teaches.
