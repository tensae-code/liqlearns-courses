# Rights Duties and the Childhood Code — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** We have rights and also duties to fulfil, and the Childhood and Adolescence Code that holds them.
**Answer: True**

**2.** This lesson teaches that Rights Duties and the Childhood Code — and that it has no connection to the rest of Nicaragua's story.
**Answer: False** — The lesson places it inside Nicaragua's own course, in its own order.
