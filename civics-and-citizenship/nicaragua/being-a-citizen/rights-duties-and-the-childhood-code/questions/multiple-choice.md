# Rights Duties and the Childhood Code — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) We have rights and also duties to fulfil, and the Childhood and Adolescence Code that holds them.  b) it has nothing to do with how Nicaragua governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) We have rights and also duties to fulfil, and the Childhood and Adolescence Code that holds them.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) We have rights and also duties to fulfil, and the Childhood and Adolescence Code that holds them.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Nicaragua
**Answer: a) We have rights and also duties to fulfil, and the Childhood and Adolescence Code that holds them.** — That is what this lesson teaches.
