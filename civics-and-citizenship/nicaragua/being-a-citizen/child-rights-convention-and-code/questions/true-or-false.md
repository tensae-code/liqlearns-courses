# Child Rights Convention and Code — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** The International Convention on the Rights of the Child, and Nicaragua's Childhood and Adolescence Code.
**Answer: True**

**2.** This lesson teaches that Child Rights Convention and Code — and that it has no connection to the rest of Nicaragua's story.
**Answer: False** — The lesson places it inside Nicaragua's own course, in its own order.
