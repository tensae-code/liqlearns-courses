# Let's value harmony — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) harmony and unity between people as a value to treasure  b) it has nothing to do with how Mongolia governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) harmony and unity between people as a value to treasure** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) harmony and unity between people as a value to treasure  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Mongolia
**Answer: a) harmony and unity between people as a value to treasure** — That is what this lesson teaches.
