# Local state organisations — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) the state organisations of the child's own locality  b) it has nothing to do with how Mongolia governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) the state organisations of the child's own locality** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) the state organisations of the child's own locality  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Mongolia
**Answer: a) the state organisations of the child's own locality** — That is what this lesson teaches.
