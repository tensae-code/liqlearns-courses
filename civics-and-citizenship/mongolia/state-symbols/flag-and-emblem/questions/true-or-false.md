# State flag and emblem — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** the state flag symbolises independence, sovereignty and good fortune; the Great White Banner (Их цагаан туг) of nine white yak-tail banners, kept in the State Palace and honoured at Naadam; colours and the number nine as symbols (read first-hand on the chapter opener)
**Answer: True**

**2.** This lesson teaches that State flag and emblem — and that it has no connection to the rest of Mongolia's story.
**Answer: False** — The lesson places it inside Mongolia's own course, in its own order.
