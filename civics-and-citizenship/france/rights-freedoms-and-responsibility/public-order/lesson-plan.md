# Lesson plan — Public Order

**Course:** Civics and Citizenship — France · **Title:** Rights, Freedoms and Responsibility · **Lesson:** Public Order
**Place in the curriculum:** Level 1 — Rights, Freedoms and Responsibility (CURRICULUM.md).
**The one thing this lesson teaches:** public order (l'ordre public) is the frame within which freedoms are exercised — the shared safety and calm that let everyone's freedom exist at the same time.
**This lesson's own level:** Level 1 — Rights, Freedoms and Responsibility — it stands on the lessons before it in path order (recommended, never forced).

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Freedoms need a frame** — Each person's freedom ends where it would destroy another's — public order is the shared frame that keeps freedoms from colliding.
2. **Safety and calm as common goods** — Public order protects the safety of people and property and the calm of shared places, so daily life can go on.
3. **Limits inside the frame** — When a freedom is limited for public order, the limit itself must stay inside the law — the frame binds the authorities too.

Gate pool: the prove-it check for each sub lesson is at most 5 questions, mixed with earlier parts, picked as the hardest from the rank right under the wanted sub lesson — drawn from this lesson's question files (questions/).

3. Answer the lesson's questions from the lesson, without looking back.

## If the learner is stuck
- Thinks public order means freedoms are cancelled → public order is the frame that makes freedoms possible together; it limits a freedom only so that everyone else's freedom and safety survive too.
