# Public Order — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Public order (l'ordre public) is the frame within which freedoms are exercised — the shared safety and calm that let everyone's freedom exist at the same time.
**Answer: True**

**2.** This lesson's teaching does not apply to a citizen's own home, school or street in France.
**Answer: False** — The lesson teaches the opposite: it is learned from the public life of France and lived there.
