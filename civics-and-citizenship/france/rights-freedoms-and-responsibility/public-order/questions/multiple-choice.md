# Public Order — multiple choice

Pick the one right answer.

**1.** What does this lesson teach?
a) public order (l'ordre public) is the frame within which freedoms are exercised — the shared safety and calm that let everyone's freedom exist at the same time  b) it teaches nothing in particular  c) the opposite of the book's teaching  d) only adults need it
**Answer: a)** — That is what this lesson teaches.

**2.** Which of these belongs to this lesson's first part — Freedoms need a frame?
a) Each person's freedom ends where it would destroy another's — public order is the shared frame that keeps freedoms from colliding.  b) a rule invented this morning with no source  c) the opposite of the lesson  d) nothing in the lesson covers it
**Answer: a)** — That is what the first sub lesson teaches.
