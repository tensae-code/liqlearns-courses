# Public Order — matching

Match each part with its teaching.

**1.** Freedoms need a frame — a)

**2.** Limits inside the frame — b)


Meanings:
a) Each person's freedom ends where it would destroy another's — public order is the shared frame that keeps freedoms from colliding.
b) When a freedom is limited for public order, the limit itself must stay inside the law — the frame binds the authorities too.

**Answer key:** 1. a; 2. b
