# Friends Hobbies — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Friends have different hobbies and interests, and that difference is enjoyed, not mocked.
**Answer: True**

**2.** This lesson teaches that Friends Hobbies — and that it has no connection to the rest of Indonesia's story.
**Answer: False** — The lesson places it inside Indonesia's own course, in its own order.
