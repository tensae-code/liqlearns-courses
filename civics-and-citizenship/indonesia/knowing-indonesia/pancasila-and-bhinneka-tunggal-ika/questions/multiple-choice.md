# Pancasila and Bhinneka Tunggal Ika — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) How Pancasila and the unity-in-diversity motto hold each other.  b) it has nothing to do with how Indonesia governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) How Pancasila and the unity-in-diversity motto hold each other.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) How Pancasila and the unity-in-diversity motto hold each other.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Indonesia
**Answer: a) How Pancasila and the unity-in-diversity motto hold each other.** — That is what this lesson teaches.
