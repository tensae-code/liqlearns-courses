# The Pancasila Student Profile — depth

This lesson is ONE lesson with no sub lessons: it teaches a single thing, whole. Practice is tied to the learner's skill number. The questions live in the type files.

Pass mark: The six dimensions of the Pancasila Student Profile (faith and noble character; global diversity; gotong royong; independence; critical reasoning; creativity) with Fase A (ages 6–8) element tables, including the five kinds of akhlak (to God, self, others, nature, state) — shown in the learner's own words and one real example.
