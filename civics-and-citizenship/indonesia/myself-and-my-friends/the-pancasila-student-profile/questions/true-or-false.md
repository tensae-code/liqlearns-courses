# The Pancasila Student Profile — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** The six dimensions of the Pancasila Student Profile (faith and noble character; global diversity; gotong royong; independence; critical reasoning; creativity) with Fase A (ages 6–8) element tables, including the five kinds of akhlak (to God, self, others, nature, state).
**Answer: True**

**2.** This lesson teaches that The Pancasila Student Profile — and that it has no connection to the rest of Indonesia's story.
**Answer: False** — The lesson places it inside Indonesia's own course, in its own order.
