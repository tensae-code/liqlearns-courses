# About the Civics and Citizenship — Indonesia course

**The first page (what learners are told):** everything in
this course comes from government textbooks — this country's
own Pendidikan Pancasila books. The one exception is the
**Tip boxes**: a tip in a box is from us, the people making
LiqLearns. Tips are ours; the lessons are the books'.

## How this course is organised

This is ONE course for Indonesia inside the Civics and
Citizenship folder (one course per country). Inside it, the
organisation is by **levels, not grades**: a learner's place
is found by what they prove, and each level stands on the
ones before it as a recommended-first path — never a forced
gate. The school grades the books come from appear only in
each lesson's `lesson/sources.md`, as provenance.

The course as built has **fifteen stocked levels** (Levels
1–15), from the filings for this build
(`indonesia-placements.md` — 25 records / 23 distinct books,
and `indonesia-placements-b.md` — 3 link leads triaged / 1
distinct new book, the Grade 7 student book the first filing's
census lacked). 206 placements in all, stocking 149 lessons —
the coined lesson names were deduped before building (see
CURRICULUM.md, "Where the build stands"): every placement
stocks into exactly one lesson, and every placement's
provenance row is in that lesson's `lesson/sources.md`.

**How the books were read, exactly as filed:** all books in
the first filing were read from the recorded source URLs
(ministry BSE mirror static-sc.cloudapp.web.id) after the
grab.py tree route returned HTTP 404 for every record (books
are secured in GitHub Releases, not the git tree — see group
log); the cover page of each book was rendered and checked
against the record title before reading. Books fetched by URL
are staged in phase3-staging under the push-don't-delete
rule, as filed. The second filing's book was likewise fetched
and staged under the push-don't-delete rule. The filings name
no individual staged-pending file for Indonesia beyond that
staging statement.
