# Problem-Solving in Practice — Mending a Friendship — multiple choice

Pick the one right answer.

**1.** The friends fell out over —
a) money lent  b) a borrowed reference book one denies holding  c) an exam mark  d) a seat
**Answer: b) a borrowed reference book one denies holding**

**2.** The book's model answer for this case is —
a) apologise at once  b) buy two books  c) there is none — the learner must build and defend the solution  d) tell a teacher
**Answer: c) there is none — the learner must build and defend the solution**
