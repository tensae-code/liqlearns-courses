# Virtues — self-discipline — true or false

Say whether each statement is true or false.

**1.** A self-disciplined person obeys only because a watcher stands near.
**Answer: False** — The opposite — no external control.

**2.** Self-discipline includes mastery of your own reactions.
**Answer: True** — Anger answered slowly is its work.

**3.** Denying a pleasure for a harder charitable deed can be self-discipline's
portrait.
**Answer: True** — As the lesson paints it.
