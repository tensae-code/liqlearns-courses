# Virtues — prudence — true or false

Say whether each statement is true or false.

**1.** Prudence is the same as fear.
**Answer: False** — It examines consequences so action can proceed wisely.

**2.** The lesson includes a six-item self-check of your own prudence.
**Answer: True** — Pupils grade themselves item by item.

**3.** A prudent person never learns from mistakes because they never make any.
**Answer: False** — Learning from past mistakes is one of its three habits.
