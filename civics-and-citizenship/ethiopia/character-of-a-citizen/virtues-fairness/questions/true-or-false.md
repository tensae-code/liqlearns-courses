# Virtues — fairness — true or false

Say whether each statement is true or false.

**1.** Fairness always means everyone receives exactly the same thing.
**Answer: False** — Equitable treatment on merit and ability; like situations alike.

**2.** A real judge may be invited to the class for this lesson.
**Answer: True** — The guide suggests it.

**3.** Personal liking is a proper criterion for a fair decision.
**Answer: False** — Decisions rest on proper criteria, without favouritism or prejudice.
