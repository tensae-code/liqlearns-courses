# Concern for Others — Having a Place for People — true or false

Say whether each statement is true or false.

**1.** Concern for others is only a feeling.
**Answer: False** — It holds space, listens, includes and supports.

**2.** Help in mourning is one of the home practices named.
**Answer: True** — Weddings, births, mourning, disaster, sickness.

**3.** The value is called 'helping others' in the lesson itself.
**Answer: False** — The lesson's term is 'concern for others' — the summary's 'helping
others' is the book's slip, corrected.
