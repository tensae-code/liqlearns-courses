# Virtues — honesty — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A reputation for honesty is the best compliment society gives.
**Answer: True** — So the lesson teaches.

**2. (Sub lesson 2)** In the fable, the judge settled the cattle question easily.

**3. (Sub lesson 1)** Honesty matters only when someone is watching.
**Answer: False** — The unwatched moment is its true test.
