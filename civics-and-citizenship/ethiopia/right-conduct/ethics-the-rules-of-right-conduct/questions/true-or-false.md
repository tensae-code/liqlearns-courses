# Ethics — The Rules of Right Conduct — true or false

Say whether each statement is true or false.

**1.** Ethics is one set of rules for school and a different set for home.
**Answer: False**

**2.** Ethics is learned as conduct — what you do — not only as words.
**Answer: True**

**3.** ሥነ-ምግባር is the word this lesson gives for ethics.
**Answer: True**
