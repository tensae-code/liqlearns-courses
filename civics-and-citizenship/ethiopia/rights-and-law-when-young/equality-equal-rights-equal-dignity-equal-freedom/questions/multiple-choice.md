# Equality — Equal Rights, Equal Dignity, Equal Freedom — multiple choice

Pick the one right answer.

**1.** Equality means equal —
a) rights, dignity and freedom  b) height only  c) wealth only  d) marks only
**Answer: a) rights, dignity and freedom**

**2.** Which must never be a basis for treating people differently?
a) Race, religion or language  b) Effort  c) Kindness  d) Work done
**Answer: a) Race, religion or language**

**3.** Carrying responsibilities under equality is —
a) only for some  b) equal too  c) never needed  d) for adults only
**Answer: b) equal too**

**4.** Equality is proved by —
a) words only  b) acts  c) posters only  d) promises only
**Answer: b) acts**
