# Video script — The responsibility to protect — state first, world behind it

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then. A short script — this lesson's design names no full video-script need, so the script stays short.

---

Each state protects its own people first —
from **genocide, war crimes, ethnic cleansing,
crimes against humanity**.
If a state fails them, the world must act —
together, in time, through the Security Council.
Agreed by all, on 16 September 2005.
