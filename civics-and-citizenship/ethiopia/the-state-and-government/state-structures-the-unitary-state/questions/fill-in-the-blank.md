# State structures — the unitary state — fill in the blank

Fill each blank with the lesson's own word or words.

**1. **Any power a sub-unit holds is ____ by the centre.
**Answer: delegated**

**2. **The centre is legally ____ in a unitary state.
**Answer: supreme**

**3. **Against the unitary form: non-recognition of local ____.
**Answer: diversity**
