# Lesson plan — State structures — the unitary state

**Course:** Civics and Citizenship — Ethiopia · **Title:** The State and Government · **Lesson:** State structures — the unitary state
**Place in the curriculum:** Level 16 — The State and Government (CURRICULUM.md).
**The one thing this lesson teaches:** in a unitary state all power concentrates in the central government; lower units hold only what the centre delegates.
**This lesson's own level:** it stands on the levels before it in this course's path order (recommended, never forced); inside its own title it stands on the lessons before it.

## Before this lesson

## What the learner can do when it ends
1. Describe the unitary structure.
2. List its advantages and its costs.
3. Name example unitary states.

## What you need
Paper and a pencil. Nothing else.

## The run of the lesson (in order)
1. **Do it first** — Picture a pyramid. At the top, one capital. Every arrow points down. Lower offices exist — but only because the top allows them, and only with the power the top lends. That is this lesson's state.
2. **The explanation** — the lesson's parts in order (lesson/lesson.md).
