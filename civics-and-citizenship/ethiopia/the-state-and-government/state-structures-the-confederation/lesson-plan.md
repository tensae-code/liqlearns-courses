# Lesson plan — State structures — the confederation

**Course:** Civics and Citizenship — Ethiopia · **Title:** The State and Government · **Lesson:** State structures — the confederation
**Place in the curriculum:** Level 16 — The State and Government (CURRICULUM.md).
**The one thing this lesson teaches:** a confederation is an alliance of sovereign states delegating a little power to a weak shared centre.
**This lesson's own level:** it stands on the levels before it in this course's path order (recommended, never forced); inside its own title it stands on the lessons before it.

## What the learner can do when it ends
1. Describe a confederation.
2. Say why its centre is weak.
3. Repeat the book's own doubt about whether it is a state structure at all.

## What you need
Paper and a pencil. Nothing else.

## The run of the lesson (in order)
1. **Do it first** — Several flags stand in a loose circle. In the middle is one small shared table, and the threads joining flags to table are thin. Any flag can ignore the table. Before reading: is that circle one state, or several states cooperating?
2. **The explanation** — the lesson's parts in order (lesson/lesson.md).
