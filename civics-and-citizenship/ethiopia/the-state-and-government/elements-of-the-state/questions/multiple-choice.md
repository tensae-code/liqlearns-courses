# Elements of the state — people, land, government, sovereignty — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) **Name the four elements of a state.
a) population, territory, government, sovereignty  b) army, flag, anthem, capital  c) king, council, army, tax
**Answer: a) population, territory, government, sovereignty**

**2. (Sub lesson 1) **Must a state's people share one language and religion?
a) yes — always  b) no — a state reconciles many groups  c) yes — by law everywhere
**Answer: b) no — a state reconciles many groups**

**3. (Sub lesson 1) **Vatican City shows that territory —
a) must be vast  b) must be an island  c) has no fixed required size
**Answer: c) has no fixed required size**

**4. (Sub lesson 2) **Government is the state's —
a) working arm that makes, enforces and interprets laws  b) flag and anthem  c) border line only
**Answer: a) working arm that makes, enforces and interprets laws**

**5. (Sub lesson 2) **Internal sovereignty means —
a) dealing with foreign states  b) supreme command inside the state  c)  electing ambassadors
**Answer: b) supreme command inside the state**

**6. (Sub lesson 2) **External sovereignty means —
a) command inside the state  b) the power to tax  c) independence from every foreign will
**Answer: c) independence from every foreign will**
