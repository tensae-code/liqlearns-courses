# Features of Federalism — short answer

Answer in a sentence or two, in your own words.

**1. (Sub lesson 1)** State the revocability test in one sentence.
**Answer:** If the centre can take the local powers back alone, by ordinary statute, the system is decentralised unitary — in a federation, neither level can change the compact alone.

**2. (Sub lesson 2)** Name the guide's five core features.
**Answer:** Constitutional division of power; a decentralised system carefully distinguished from federation; a written and supreme federal constitution; a rigid constitution; an umpire for the federation.
