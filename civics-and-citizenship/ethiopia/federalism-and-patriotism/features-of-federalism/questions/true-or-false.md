# Features of Federalism — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** A unitary state that decentralises generously has thereby become a federation.
**Answer: False** — its local powers remain revocable by the centre; a federation's division is constitutionally guaranteed.

**2. (Sub lesson 2)** The guide's five features include a rigid constitution and an umpire for the federation.
**Answer: True**
