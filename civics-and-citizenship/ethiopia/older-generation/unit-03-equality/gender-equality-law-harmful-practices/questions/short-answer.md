# Gender equality — law, harmful practices and women's achievement — short answer

Answer in one to three sentences, from the lesson.

**1.** Which Criminal Code articles make female circumcision and infibulation crimes?
**Answer:** Articles 565–566 (2005).

**2.** How did maternal mortality change between 2000 and 2005?
**Answer:** It fell from 871 to 673 per 100,000 — a real fall, still high.

**3.** How many women's seats were in the third parliament, and what share?
**Answer:** 117 seats — 25%.
