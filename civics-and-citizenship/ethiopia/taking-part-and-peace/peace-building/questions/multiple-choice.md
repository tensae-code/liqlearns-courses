# Peace Building — multiple choice

Pick the one right answer.

**1.** Simply stopping fighting —
a) does not permanently end violence  b) completes peace building  c) removes root causes  d) repairs relationships
**Answer: a) does not permanently end violence**

**2.** Peace building encourages conflicting parties first to —
a) talk and understand each other's views  b) move apart forever  c) rearm quietly  d) forget everything
**Answer: a) talk and understand each other's views**

**3.** Institutions built by peace building must be able to —
a) address root causes and sustain peace  b) win the next war  c) silence grievances  d) replace all elders
**Answer: a) address root causes and sustain peace**
