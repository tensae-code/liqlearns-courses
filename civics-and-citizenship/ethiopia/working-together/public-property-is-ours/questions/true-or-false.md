# Public Property Is Ours — Use It Properly, Keep It for Tomorrow — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Public wealth is the natural and man-made materials, services and other things that contribute to human benefit.
**Answer: True**

**2.** Use resources responsibly and economically, and build a saving culture.
**Answer: True**

**3.** Public property belongs to no one, so damaging it harms no one.
**Answer: False** — The lesson teaches the opposite.
