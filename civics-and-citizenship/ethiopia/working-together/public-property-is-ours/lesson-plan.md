# Lesson plan — Public Property Is Ours — Use It Properly, Keep It for Tomorrow

**Course:** Civics and Citizenship — Ethiopia · **Title:** Working Together and the Common Good · **Lesson:** Public Property Is Ours — Use It Properly, Keep It for Tomorrow
**Place in the curriculum:** Level 5 — Working Together and the Common Good (CURRICULUM.md).
**The one thing this lesson teaches:** public property is the people's wealth: use it carefully, responsibly, lawfully and morally — so it is saved from destruction and kept for the coming generation.
**This lesson's own level:** it stands on the lessons before it in this title — the learner already knows the earlier circles of this course (myself, then family, neighbours, school, community and culture) as far as this title. It needs nothing else.

## Before this lesson

## What the learner can do when it ends
1. Public wealth is the natural and man-made materials, services and other things that contribute to human benefit.
2. Using it properly means handling and guarding it carefully, responsibly, lawfully, scientifically and morally.
3. Proper use saves it from destruction, theft, shortage and unfair distribution, creates an equal chance for the community to use it, and keeps it for the coming generation.
4. Use resources responsibly and economically, and build a saving culture.
5. Know what correct use is, and prevent acts that destroy resources.

## What you need
