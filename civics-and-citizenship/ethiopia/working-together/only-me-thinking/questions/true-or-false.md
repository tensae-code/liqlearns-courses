# Only-Me Thinking — Selfishness Against the Common Good — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Selfishness (ግለኝነት) is thinking only of oneself, protecting only oneself.
**Answer: True**

**2.** Selfishness and the common good are the same thing under two names.
**Answer: False** — The lesson teaches the opposite.
