# Democratic Values in Indigenous Institutions — multiple choice

Pick the one right answer.

**1.** The values the guide finds in indigenous institutions include —
a) trust, dialogue and reciprocity  b) silence, fear and rank  c) wealth and fame  d) speed and secrecy
**Answer: a) trust, dialogue and reciprocity**

**2.** Indigenous institutions are presented as carrying which functions?
a) Political, social, administrative and judicial  b) Only religious  c) Only military  d) Only commercial
**Answer: a) Political, social, administrative and judicial**
