# A Persons Responsibility — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) Responsibility as answering for one's choices.  b) it has nothing to do with how Kazakhstan governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) Responsibility as answering for one's choices.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) Responsibility as answering for one's choices.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Kazakhstan
**Answer: a) Responsibility as answering for one's choices.** — That is what this lesson teaches.
