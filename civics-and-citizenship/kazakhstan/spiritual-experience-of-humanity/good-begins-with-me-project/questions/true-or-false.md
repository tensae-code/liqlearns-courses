# Good Begins with Me Project — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** A year-long good-deeds project kept in the workbook project diary and presented at year's end.
**Answer: True**

**2.** This lesson teaches that Good Begins with Me Project — and that it has no connection to the rest of Kazakhstan's story.
**Answer: False** — The lesson places it inside Kazakhstan's own course, in its own order.
