# Getting Along with Everyone — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure). Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — What should I do?
Sub lesson 1 questions from the type files. Pass mark: Picture scenes ask the question: children queueing, a shared toy, a game someone wants to join, a snowman built together. Some acts help everyone get along and some must never be done — learn to tell them apart and choose. — shown in the learner's own words and one real example.

## Sub lesson 2 — The rabbit who thought again
Sub lesson 2 questions from the type files. Pass mark: Read the little story of the rabbit, told in the open book's own pages, and think it through: what happened, what should the rabbit have done, and what would you do? — shown in the learner's own words and one real example.
