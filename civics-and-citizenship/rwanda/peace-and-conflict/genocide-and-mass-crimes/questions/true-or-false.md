# Genocide and Mass Crimes — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Genocide set beside other mass crimes.
**Answer: True**

**2.** This lesson teaches that genocide set beside other mass crimes — and that it has no connection to the rest of Rwanda's story.
**Answer: False** — The lesson places it inside Rwanda's own course, in its own order.
