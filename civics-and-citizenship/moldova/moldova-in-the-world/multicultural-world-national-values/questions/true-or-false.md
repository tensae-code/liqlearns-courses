# A Multicultural World and National Values — true or false

Say whether each statement is true or false, and be ready to say why.

**Answer: True**

**2.** This lesson teaches that A Multicultural World and National Values — and that it has no connection to the rest of Moldova's story.
**Answer: False** — The lesson places it inside Moldova's own course, in its own order.
