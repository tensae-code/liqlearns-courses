# Recognising Discrimination — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure). Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — The recognition test
Sub lesson 1 questions from the type files. Pass mark: Ask: what happened, what mark was in play, and would the treatment change if the mark changed? Unequal treatment without a fair, relevant reason is the signal. — shown in the learner's own words and one real example.

## Sub lesson 2 — Signs in daily life
Sub lesson 2 questions from the type files. Pass mark: Refusals, exclusions, unequal rules, mocking and doors that open for some and not others — recognised early, discrimination can be named, questioned and stopped before it hardens. — shown in the learner's own words and one real example.
