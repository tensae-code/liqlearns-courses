# Globalisation, Pluralism and Tolerance — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure). Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Words for a wired world
Sub lesson 1 questions from the type files. Pass mark: Explain in your own words: the global village, the citizen of the world, the global player, globalisation itself. Then name three leading countries of world industry and say by which criteria — economic, political, ecological — you chose them, and three main causes that drive globalisation. — shown in the learner's own words and one real example.

Sub lesson 2 questions from the type files.
