# My Civic Project for Positive Change — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure). Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Choosing and naming
Sub lesson 1 questions from the type files. Pass mark: A project is a form of work and inquiry that solves set tasks inside a set time. First choose the problem, theme and field — a volunteer action, a social project, an initiative — and brainstorm a name that gathers every idea before they are split into sub-themes. — shown in the learner's own words and one real example.

## Sub lesson 2 — Planning, doing, presenting
Sub lesson 2 questions from the type files. Pass mark: Build the schedule and name who is responsible for each activity; gather the materials and information; decide the form of presentation — report, film, poster, interview. The responsible members then work independently to the schedule, and the project closes with presentation, summary and reflection on what went well and what can improve. — shown in the learner's own words and one real example.
