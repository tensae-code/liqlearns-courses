# Intercultural Coexistence — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) Intercultural coexistence.  b) it has nothing to do with how El Salvador governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) Intercultural coexistence.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) Intercultural coexistence.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in El Salvador
**Answer: a) Intercultural coexistence.** — That is what this lesson teaches.
