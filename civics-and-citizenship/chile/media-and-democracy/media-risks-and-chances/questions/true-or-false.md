# Media Risks and Chances for Democracy — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Because media carry risks, citizens should abandon them entirely.
**Answer: False** — A risk is a reason to learn the tool's handling, not to abandon it — the same media bring real democratic opportunities.

**2.** Checking a claim's source and date is part of the citizen's handling of media.
**Answer: True**
