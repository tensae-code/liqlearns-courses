# Helping Others — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Helping others is a human value you practise with your own hands — when someone near you needs help, giving it is what a person does.
**Answer: True**

**2.** This lesson's teaching does not apply to a child's own home, school or community in Nepal.
**Answer: False** — The lesson teaches the opposite: it is learned from life in Nepal and lived there.
