# True Friendship — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** True companionship is a human value — a true friend stands with you in good times and hard ones, and you stand with them.
**Answer: True**

**2.** This lesson's teaching does not apply to a child's own home, school or community in Nepal.
**Answer: False** — The lesson teaches the opposite: it is learned from life in Nepal and lived there.
