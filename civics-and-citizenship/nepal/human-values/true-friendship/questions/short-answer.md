# True Friendship — short answer

Answer in a sentence or two, in your own words.

**1.** What is this lesson's one thing, in your own words?
**Answer:** True companionship is a human value — a true friend stands with you in good times and hard ones, and you stand with them.

**2.** What does this lesson add?
**Answer:** True companionship holds in hard times, not only easy ones — and it runs both ways: be the friend you wish to have.
