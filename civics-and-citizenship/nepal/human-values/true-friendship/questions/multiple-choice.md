# True Friendship — multiple choice

Pick the one right answer.

**1.** What does this lesson teach?
a) true companionship is a human value — a true friend stands with you in good times and hard ones, and you stand with them  b) it teaches nothing in particular  c) the opposite of the book's teaching  d) only adults need it
**Answer: a)** — That is what this lesson teaches.

**2.** Which of these belongs to this lesson?
a) True companionship holds in hard times, not only easy ones — and it runs both ways: be the friend you wish to have.  b) a rule invented this morning with no source  c) the opposite of the lesson  d) nothing in the lesson covers it
**Answer: a)** — That is what the lesson teaches.
