# Order in the Family — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) Order and roles inside the family.  b) it has nothing to do with how Mauritania governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) Order and roles inside the family.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) Order and roles inside the family.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Mauritania
**Answer: a) Order and roles inside the family.** — That is what this lesson teaches.
