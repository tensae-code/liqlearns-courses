# The Wilaya — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** The wilaya and its wali, with Nouakchott's wilayas and all the wilaya capitals.
**Answer: True**

**2.** This lesson teaches that The Wilaya — and that it has no connection to the rest of Mauritania's story.
**Answer: False** — The lesson places it inside Mauritania's own course, in its own order.
