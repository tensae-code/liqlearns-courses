# The Schools Internal Order — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) The rules that order school life.  b) it has nothing to do with how Mauritania governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) The rules that order school life.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) The rules that order school life.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Mauritania
**Answer: a) The rules that order school life.** — That is what this lesson teaches.
