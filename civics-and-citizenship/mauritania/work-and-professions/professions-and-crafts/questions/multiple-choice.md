# Professions and Crafts — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) Crafts learned by practice — smithing, carpentry, mechanics — against knowledge-based professions.  b) it has nothing to do with how Mauritania governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) Crafts learned by practice — smithing, carpentry, mechanics — against knowledge-based professions.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) Crafts learned by practice — smithing, carpentry, mechanics — against knowledge-based professions.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Mauritania
**Answer: a) Crafts learned by practice — smithing, carpentry, mechanics — against knowledge-based professions.** — That is what this lesson teaches.
