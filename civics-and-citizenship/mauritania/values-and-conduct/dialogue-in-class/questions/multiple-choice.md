# Dialogue in Class — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) How discussion is carried on in class.  b) it has nothing to do with how Mauritania governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) How discussion is carried on in class.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) How discussion is carried on in class.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Mauritania
**Answer: a) How discussion is carried on in class.** — That is what this lesson teaches.
