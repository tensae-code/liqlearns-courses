# Human Values — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Human values guide how we live — values, habits and beliefs together shape what a person and a community hold dear.
**Answer: True**

**2.** This lesson's teaching does not apply to a citizen's own home, school or community in Angola.
**Answer: False** — The lesson teaches the opposite: it is learned from life in Angola and lived there.
