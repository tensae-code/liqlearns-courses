# We Write Our Class Rules — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Democracy can be practised in the classroom — pupils can draft their own class rules together and live by what they agreed.
**Answer: True**

**2.** This lesson's teaching does not apply to a citizen's own home, school or community in Angola.
**Answer: False** — The lesson teaches the opposite: it is learned from life in Angola and lived there.
