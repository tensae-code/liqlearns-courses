# Running Dialogue in Class

## Do it first

Imagine the whole class discussing one question at once, with no order. What happens? Now imagine it managed — turns, listening, one subject. This lesson is that practice: managing dialogue in the classroom.

## Discussion with order

Managing dialogue in the classroom (إدارة الحوار في القسم) means the class talks in an ordered way: one subject at a time, speakers in turn, others listening, and the talk guided so it stays useful and fair.

## The classroom is where dialogue is practised

The class is a small society: practising ordered discussion there trains the habits — turns, listening, respect — that dialogue everywhere else needs. What is learned in the section is carried into the home and the street.
