# Running Dialogue in Class — multiple choice

Pick the one right answer.

**1.** What does this lesson teach?
a) dialogue in the classroom is managed — the class practises ordered discussion, with turns, a shared subject and respect, so everyone can speak and be heard  b) it teaches nothing in particular  c) the opposite of the book's teaching  d) only adults need it
**Answer: a)** — That is what this lesson teaches.

**2.** What makes classroom dialogue managed, not noisy?
a) one subject, speakers in turn, others listening  b) everyone shouting at once  c) only one pupil ever speaking  d) no subject at all
**Answer: a) one subject, speakers in turn, others listening** — That is what this lesson teaches.
