# Running Dialogue in Class — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Dialogue in the classroom is managed — the class practises ordered discussion, with turns, a shared subject and respect, so everyone can speak and be heard.
**Answer: True**

**2.** This lesson's teaching does not apply to a child's own home, school or street.
**Answer: False** — The lesson teaches the opposite: it is learned from scenes in the child's own world and lived there.
