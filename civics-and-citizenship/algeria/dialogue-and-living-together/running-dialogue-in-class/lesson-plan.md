# Lesson plan — Running Dialogue in Class

**Course:** Civics and Citizenship — Algeria · **Title:** Dialogue and Living Together · **Lesson:** Running Dialogue in Class
**Place in the curriculum:** Level 1 — Dialogue and Living Together (CURRICULUM.md).
**The one thing this lesson teaches:** dialogue in the classroom is managed — the class practises ordered discussion, with turns, a shared subject and respect, so everyone can speak and be heard.
**This lesson's own level:** Level 1 — it stands at the foot of Algeria's ladder, on nothing before it in this course except the lessons before it in path order (recommended, never forced).

## What the learner can do when it ends
1. State the lesson's one thing in their own words: dialogue in the classroom is managed — the class practises ordered discussion, with turns, a shared subject and respect, so everyone can speak and be heard.
2. Give one real example of it from their own home, street or school.
3. Answer the lesson's questions from the lesson, without looking back.

## What you need
Paper and a pencil. Nothing else — the lesson's scenes are the learner's own home, school and neighbourhood.

## If the learner is stuck
- Thinks classroom dialogue means free noise where anyone shouts → managed dialogue is ordered on purpose: turns and listening are what let thirty voices become one discussion.
- Go back to the one thing: dialogue in the classroom is managed — the class practises ordered discussion, with turns, a shared subject and respect, so everyone can speak and be heard. Work the Do it first act again, slowly, and name each step aloud.
