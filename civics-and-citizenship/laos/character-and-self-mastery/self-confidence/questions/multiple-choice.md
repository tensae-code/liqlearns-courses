# Self Confidence — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) Trusting one's own capacity.  b) it has nothing to do with how Laos governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) Trusting one's own capacity.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) Trusting one's own capacity.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Laos
**Answer: a) Trusting one's own capacity.** — That is what this lesson teaches.
