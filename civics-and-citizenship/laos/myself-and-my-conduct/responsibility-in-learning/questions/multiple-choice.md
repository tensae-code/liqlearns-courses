# Responsibility in Learning — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) Answering for one's own learning.  b) it has nothing to do with how Laos governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) Answering for one's own learning.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) Answering for one's own learning.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Laos
**Answer: a) Answering for one's own learning.** — That is what this lesson teaches.
