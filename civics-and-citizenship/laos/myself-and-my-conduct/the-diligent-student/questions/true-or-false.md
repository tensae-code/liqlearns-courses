# The Diligent Student — true or false

Say whether each statement is true or false, and be ready to say why.

**Answer: True**

**2.** This lesson teaches that The Diligent Student — and that it has no connection to the rest of Laos's story.
**Answer: False** — The lesson places it inside Laos's own course, in its own order.
