# Doing My Own Work — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** A child does their own tasks themselves instead of leaving them to others; doing one's own work oneself; a child does their own tasks themselves, shown in classroom and kitchen pictures.
**Answer: True**

**2.** This lesson teaches that Doing My Own Work — and that it has no connection to the rest of Laos's story.
**Answer: False** — The lesson places it inside Laos's own course, in its own order.
