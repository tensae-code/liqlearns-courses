# Not Taking What Is Not Yours — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** What is not yours is not taken.
**Answer: True**

**2.** This lesson teaches that Not Taking What Is Not Yours — and that it has no connection to the rest of Laos's story.
**Answer: False** — The lesson places it inside Laos's own course, in its own order.
