# Loving Fellow Neighbours — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Love for the neighbours of one's own village.
**Answer: True**

**2.** This lesson teaches that Loving Fellow Neighbours — and that it has no connection to the rest of Laos's story.
**Answer: False** — The lesson places it inside Laos's own course, in its own order.
