# Using Public Property — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) Using common things rightly.  b) it has nothing to do with how Laos governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) Using common things rightly.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) Using common things rightly.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Laos
**Answer: a) Using common things rightly.** — That is what this lesson teaches.
