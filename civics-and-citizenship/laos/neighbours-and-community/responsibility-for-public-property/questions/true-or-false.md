# Responsibility for Public Property — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Public things are one's own responsibility; common things are one's own responsibility.
**Answer: True**

**2.** This lesson teaches that Responsibility for Public Property — and that it has no connection to the rest of Laos's story.
**Answer: False** — The lesson places it inside Laos's own course, in its own order.
