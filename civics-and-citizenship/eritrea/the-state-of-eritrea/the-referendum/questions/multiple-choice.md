# The Referendum — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) The referendum by which Eritreans chose independence.  b) it has nothing to do with how Eritrea governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) The referendum by which Eritreans chose independence.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) The referendum by which Eritreans chose independence.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Eritrea
**Answer: a) The referendum by which Eritreans chose independence.** — That is what this lesson teaches.
