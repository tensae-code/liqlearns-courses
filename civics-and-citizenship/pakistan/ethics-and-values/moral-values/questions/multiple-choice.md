# Moral Values — multiple choice

Pick the one right answer.

**1.** Which statement best gives this lesson's teaching?
a) the values that make a person good — respecting others, living in peace, treating others well, hurting no one, showing honesty, doing justice, being of use to others, respecting others' religion and beliefs, keeping cleanliness.  b) it has nothing to do with how Pakistan governs itself  c) it was invented by foreign governments  d) it matters only in examinations
**Answer: a) the values that make a person good — respecting others, living in peace, treating others well, hurting no one, showing honesty, doing justice, being of use to others, respecting others' religion and beliefs, keeping cleanliness.** — That is what this lesson teaches.

**2.** What is this lesson's one thing?
a) the values that make a person good — respecting others, living in peace, treating others well, hurting no one, showing honesty, doing justice, being of use to others, respecting others' religion and beliefs, keeping cleanliness.  b) citizens should never ask where a rule comes from  c) only officials need to know this  d) it applies in other countries but not in Pakistan
**Answer: a) the values that make a person good — respecting others, living in peace, treating others well, hurting no one, showing honesty, doing justice, being of use to others, respecting others' religion and beliefs, keeping cleanliness.** — That is what this lesson teaches.
