# Moral Values — depth

This lesson is ONE lesson with no sub lessons: it teaches a single thing, whole. Practice is tied to the learner's skill number. The questions live in the type files.

Pass mark: the values that make a person good — respecting others, living in peace, treating others well, hurting no one, showing honesty, doing justice, being of use to others, respecting others' religion and beliefs, keeping cleanliness. — shown in the learner's own words and one real example.
