# The State — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** The state is defined, and its types distinguished — what kind of organised power it is.
**Answer: True**

**2.** The state has a role and functions — the work it exists to do for the whole country.
**Answer: True**

**3.** This lesson teaches that the state is the organised political power of a country — it has types, a role and functions a citizen can name — and that it has no connection to the rest of Senegal's story.
**Answer: False** — The lesson places it inside Senegal's own course, in its own order.
