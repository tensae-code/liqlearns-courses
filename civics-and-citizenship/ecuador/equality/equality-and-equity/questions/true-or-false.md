# Equality and Equity — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Equality is not equity: formal equality is equality before the law, while material equality is equality of real conditions — and equity answers real conditions, not only the written rule.
**Answer: True**

**2.** This lesson teaches that equality and equity — and that it has no connection to the rest of Ecuador's story.
**Answer: False** — The lesson places it inside Ecuador's own course, in its own order.
