# Universal Suffrage — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Universal suffrage is equality in action: every citizen's vote counts, and the book works through the types of vote.
**Answer: True**

**2.** This lesson teaches that universal suffrage — and that it has no connection to the rest of Ecuador's story.
**Answer: False** — The lesson places it inside Ecuador's own course, in its own order.
