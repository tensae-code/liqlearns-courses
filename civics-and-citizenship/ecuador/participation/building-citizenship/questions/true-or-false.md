# Building Citizenship — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Citizenship is constructed: becoming a citizen is a practice, built by taking part — the construction of citizenship.
**Answer: True**

**2.** This lesson teaches that building citizenship — and that it has no connection to the rest of Ecuador's story.
**Answer: False** — The lesson places it inside Ecuador's own course, in its own order.
