# The First Civilisations — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** A civilisation has cities, government, crafts and shared culture — and the first arose beside great rivers.
**Answer: True**

**2.** Civilisation began in Europe in modern times.
**Answer: False** — A civilisation has cities, government, crafts and shared culture — and the first arose beside great rivers.
