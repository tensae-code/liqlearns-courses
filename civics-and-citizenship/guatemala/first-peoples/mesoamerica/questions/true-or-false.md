# Mesoamerica — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Mesoamerica is the territory where many peoples shared one cultural base — farming, cities, calendars and beliefs.
**Answer: True**

**2.** Mesoamerica was one country ruled by one king.
**Answer: False** — Mesoamerica is the territory where many peoples shared one cultural base — farming, cities, calendars and beliefs.
