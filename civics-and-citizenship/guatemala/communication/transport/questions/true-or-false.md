# Transport — Ways and Means — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Transport joins ways (roads, rivers, air routes) with means (vehicles) — combined differently in each country.
**Answer: True**

**2.** Every country uses exactly the same transport in the same way.
**Answer: False** — Transport joins ways (roads, rivers, air routes) with means (vehicles) — combined differently in each country.
