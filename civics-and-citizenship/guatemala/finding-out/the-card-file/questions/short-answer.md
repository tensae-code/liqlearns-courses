# The Card File — short answer

Answer in a sentence or two, in your own words.

**1.** What does this lesson teach about classifying in a card file?
**Answer:** The card file keeps much information usable: one card per item, classified and ordered.

**2.** What does this lesson teach about bibliographic cards?
**Answer:** A bibliographic card records a source's full identity so it can be found and cited again.
