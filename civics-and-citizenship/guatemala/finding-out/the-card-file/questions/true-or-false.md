# The Card File — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** The card file keeps much information usable: one card per item, classified and ordered.
**Answer: True**

**2.** A card file is only for libraries; investigators do not need one.
**Answer: False** — The card file keeps much information usable: one card per item, classified and ordered.
