# The Card File — matching

Match each word with its meaning.

**1.** card file (fichero) — a)

**2.** bibliographic card — b)

**3.** cite — c)


Meanings:
a) an ordered set of cards, one item per card
b) a card recording a source's author, title, publisher and year
c) to name a source exactly where it is used

**Answer key:** 1. a; 2. b; 3. c
