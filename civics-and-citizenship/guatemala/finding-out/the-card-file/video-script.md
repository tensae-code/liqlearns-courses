This lesson is about one thing.
When an investigation gathers much information, the card file keeps it usable: one card per item, ordered — and the bibliographic card records a book or source exactly, so any source can be found and cited again.

The card file (fichero) is a technique for handling much information: each item goes on its own card, and the cards are classified and ordered — by theme, author or date — so any item can be found in seconds and new cards slip into their place.

A bibliographic card records one source completely: author, title, publisher, year — the source's identity card. With it, the investigator can find the source again and cite it honestly in the report.
