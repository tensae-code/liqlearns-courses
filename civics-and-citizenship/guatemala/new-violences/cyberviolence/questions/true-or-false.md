# Cyberviolence — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Harm done through a screen is real harm to a real person.
**Answer: True**

**2.** Cyberbullying is a different thing from violence, so the course's teaching does not apply to it.
**Answer: False** — Each form is a form of the same violence the course has named from its first lesson.
