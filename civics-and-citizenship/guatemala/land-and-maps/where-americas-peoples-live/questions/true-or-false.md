# Where America's Peoples Live — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** America's countries run some 15,000 km, each with its capital and languages.
**Answer: True**

**2.** America is one single country from north to south.
**Answer: False** — America's countries run some 15,000 km, each with its capital and languages.
