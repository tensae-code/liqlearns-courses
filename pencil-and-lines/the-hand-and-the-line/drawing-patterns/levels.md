# Drawing patterns — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the skill number, as before. This
lesson has no questions/ files; its practice is the hand itself,
and this file is the by-sub-lesson view.

## Sub lesson 1 — Copying patterns
Pass mark: the learner looks at a pattern, says what repeats,
and copies it — same shapes, same order — so that a partner,
shown both, can say they are the same pattern.

## Sub lesson 2 — Drawing to answer
Pass mark: the learner hears or reads a short text and draws
its main thing — a drawing a partner can read back as the
text's main point without being told.
