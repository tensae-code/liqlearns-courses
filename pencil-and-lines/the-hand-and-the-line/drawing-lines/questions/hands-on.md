# Drawing lines — hands-on (learn by doing)

## Project 1: hills and mountains
1. Draw one slow line of wavy hills across your page.
2. Draw one slow line of zigzag mountains under it.
3. Look at both lines: which one is smoother? Do that one again.
4. Keep the page — you will compare it with next week's page.

## Project 2: find the two roads in a letter
1. Write a big letter O. Which road is it made of? (The hill road —
   all curve.)
2. Write a big letter Z. Which road? (The mountain road — straights
   and corners.)
3. Write a big letter B. Find both roads inside it: straight down,
   then two hills.
