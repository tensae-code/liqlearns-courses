# Finnish emigration across the oceans — true or false

Say True or False, and why.

**1. (Sub lesson 1)** Fast-industrialising America pulls migrants in crowds around 1900; Finns cross the Atlantic after the same dream, later to the whole world.
**Answer: True** — the book tells this in introduction: Finns chase the American dream

**2. (Sub lesson 1)** This part of *Emigration photo analysis (FI/SV)* is about the SA-kuva archive and the TK companies.
**Answer: False** — it is about introduction: Finns chase the American dream

**3. (Sub lesson 2)** A young woman sits for a formal studio photograph before departure; pupils read her hopes out of the pose.
**Answer: True** — the book tells this in Task 1, Mimmi Törnroos's studio portrait

**4. (Sub lesson 2)** This part of *Emigration photo analysis (FI/SV)* is about using the photographs critically.
**Answer: False** — it is about Task 1, Mimmi Törnroos's studio portrait

**5. (Sub lesson 3)** Photo sets show the jobs Finns actually landed in, and pupils ask why those jobs, and whether being a man or a woman decided them.
**Answer: True** — the book tells this in Task 2, emigrant workers in photographs

**6. (Sub lesson 3)** This part of *Emigration photo analysis (FI/SV)* is about Task 1, analysing one war-front photograph.
**Answer: False** — it is about Task 2, emigrant workers in photographs

**7. (Sub lesson 4)** A crew poses underground in work clothes; pupils judge the clothes against mine work and ask why the photograph was taken at all.
**Answer: True** — the book tells this in Task 3, Finnish miners at Red Lodge

**8. (Sub lesson 4)** This part of *Emigration photo analysis (FI/SV)* is about Task 2, the staged photographs.
**Answer: False** — it is about Task 3, Finnish miners at Red Lodge

**9. (Sub lesson 5)** The same Atlantic crossing is offered twice, as a solo diary/letter/story or as a pair dialogue — the pupil must live the departure, not summarise it.
**Answer: True** — the book tells this in introduction and task choice

**10. (Sub lesson 5)** This part of *Emigration empathy (FI/SV)* is about Task 1, Hitler's visit to Mannerheim's 75th birthday.
**Answer: False** — it is about introduction and task choice

**11. (Sub lesson 6)** A ship lands Finnish Americans, the Valjakka family poses before leaving, a house rises in Sointula, emigrants crowd the Astrea, settlers gather in Argentina's Colonia Finlandesa — one pictured life becomes the pupil's own entry.
**Answer: True** — the book tells this in individual task: write from one photograph

**12. (Sub lesson 6)** This part of *Emigration empathy (FI/SV)* is about Task 1, the 'separate war' critique.
**Answer: False** — it is about individual task: write from one photograph

**13. (Sub lesson 7)** Two pupils voice the people inside one photograph, arguing out the leaving and the hopes before an audience.
**Answer: True** — the book tells this in pair/group task: a dialogue performed to the class

**14. (Sub lesson 7)** This part of *Emigration empathy (FI/SV)* is about Task 1, the front-life photo set.
**Answer: False** — it is about pair/group task: a dialogue performed to the class
