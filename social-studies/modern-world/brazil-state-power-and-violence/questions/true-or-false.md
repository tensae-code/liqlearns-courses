# State power and violence — true or false

Say True or False, and why.

**1. (Sub lesson 1)** The state claims a monopoly of force.
**Answer: True — only the state may arrest, punish and compel, as law.**

**2. (Sub lesson 3)** The book teaches that state force can never become violence against the state's own people.
**Answer: False — the book's whole question is when force is law and when it is violence.**
