# Papua New Guinea — changes in basic needs over time — short answer

Answer in a sentence or two.

**1. (Sub lesson 1)** Retell this part in your own words: Changes in Food / Changes in Shelter / Changes in Clothing.
**Answer: Explorers bring canned beef and rice; native sugarcane, banana and pandanus give ground — for taste, for saved garden time, for prestige, and because town life leaves no land to grow — and shelter and clothing (the meri blouse beside bark cloth) change the same way (any close wording — summary only, never the book's words).**

**2. (Sub lesson 1)** In Papua New Guinea's book, where is this part taught?
**Answer: In *Social Science Teacher Guide — Primary Grade 6, Standards Based* (Papua New Guinea), Changes in Food / Changes in Shelter / Changes in Clothing, printed pp. 97–100.**
