# Timor-Leste — the Santa Cruz massacre, 1991 — true or false

Say True or False, and why.

**1. (Sub lesson 1)** Santa Cruz was a turning point partly because the shooting was filmed.
**Answer: True — foreign journalists' film carried it to the world; the occupation could no longer be hidden.**

**2. (Sub lesson 2)** The Kraras massacre is taught in a different book, not recalled here.
**Answer: False — the book recalls the Kraras massacre in this same lesson.**
