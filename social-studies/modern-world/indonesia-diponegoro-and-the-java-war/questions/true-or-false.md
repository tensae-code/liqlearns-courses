# Indonesia — Diponegoro and the Java War — true or false

Say True or False, and why.

**1. (Sub lesson 1)** Raden Saleh's painting of the capture of Diponegoro is read as a source on the end of the Java War and on how the defeated prince, raised outside the court, became its leader.
**Answer: True** — the book tells this in A.2, change-over-time section

**2. (Sub lesson 1)** This part of *Sejarah untuk SMK Kelas X* is about Indonesia — Sultan Agung attacks Batavia.
**Answer: False** — it is about A.2, change-over-time section

**3. (Sub lesson 2)** Raden Saleh's canvas of Diponegoro's capture closes the five-year Java War, the last great princely resistance before the colonial state hardens.
**Answer: True** — the book tells this in Bab I.B

**4. (Sub lesson 2)** This part of *Sejarah untuk SMA/MA/SMK/MAK Kelas XI, Edisi Revisi* is about Indonesia — Sultan Agung attacks Batavia.
**Answer: False** — it is about Bab I.B

**5. (Sub lesson 3)** The prince's five-year guerrilla war bleeds Java and the colonial treasury before his capture under a flag of negotiation.
**Answer: True** — the book tells this in Bab 2.B.4 Perang Diponegoro

**6. (Sub lesson 3)** This part of *Sejarah Indonesia Kelas XI Semester 1 (Kurikulum 2013)* is about Indonesia — Sultan Agung attacks Batavia.
**Answer: False** — it is about Bab 2.B.4 Perang Diponegoro
