# Capitalism — private ownership, factories, new classes — sub lessons and depth

This file is the lesson's depth record, re-expressed as its sub lessons. Practice is tied to the learner's skill number, as before. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Private ownership — the system's foundation
Sub lesson 1 questions from the type files. Pass mark: Say that capitalism rests on private ownership of most means of production, and that it became dominant in the West as feudalism collapsed.

## Sub lesson 2 — Steam, factories, new classes
Sub lesson 2 questions from the type files. Pass mark: Explain how the Industrial Revolution transformed capitalism: coal and steam replaced wind and water, the factory system replaced the domestic system, and industrial capitalists and factory workers emerged as new classes.

## Sub lesson 3 — The definition in class terms (teacher guide — evidence)
Sub lesson 3 questions from the type files. Pass mark: State the guide's sharper definition: resources owned by a few rich private people, production for profit, the bourgeoisie owning the factors of production, the proletariat selling labour for wages, and no government interference.
