# Guatemala — the colonial era — sub lessons and depth

This file is the lesson's depth record, re-expressed as its sub lessons. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view. Parts are ordered as the book teaches them, as stocked.

## Sub lesson 1 — Four foundings — a capital that keeps moving
Sub lesson 1 questions from the type files. Pass mark: Name Santiago's first home: Iximche', founded 1524. Name the disaster of 1541: Volcán de Agua mud at Almolonga. Name the earthquakes that moved it in 1773: the Santa Marta earthquakes.

## Sub lesson 2 — Colonial society — slavery, encomienda, repartimiento
Sub lesson 2 questions from the type files. Pass mark: Name the laws of 1542: the New Laws, abolishing slavery. Name the weekly labour draft: the repartimiento. Name the top of the pyramid: the peninsulares.

## Sub lesson 3 — Colonial economy, money, art and schools
Sub lesson 3 questions from the type files. Pass mark: Name the colony's paying crops: cacao, cotton and indigo. Say what served as coins until 1733: cacao beans. Name the university founded in 1676: San Carlos University.
