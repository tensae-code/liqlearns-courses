# Guatemala's four peoples — Maya, Garífuna, Xinka, Ladino — sub lessons and depth

This file is the lesson's depth record, re-expressed as its sub lessons. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view. Parts are ordered as the book teaches them, as stocked.

## Sub lesson 1 — Los cuatro pueblos — four peoples, one country
Sub lesson 1 questions from the type files. Pass mark: Name Guatemala's four peoples: Maya, Garífuna, Xinka and Ladino. Say where the Garífuna descend from: Africans brought as slaves. Say what recognises all four peoples: the Peace Accords.

## Sub lesson 2 — Four ways of knowing — the peoples' learning (teacher guide — evidence)
Sub lesson 2 questions from the type files. Pass mark: Name the centre of Xinka learning: the Moon and community. Name the Maya value of work: mitijul, with gratitude. Say where Garífuna spirituality flows from: the sea and the ancestors.

## Sub lesson 3 — A classroom of many peoples (teacher guide — evidence)
Sub lesson 3 questions from the type files. Pass mark: Name the game that teaches the languages: the language lottery. Name three languages on its cards: Cho'rti', Mopan and Tz'utujil. Say what the family tree shows: many peoples descended from shared roots.

## Sub lesson 4 — The four peoples in primero básico (teacher guide — evidence)
Sub lesson 4 questions from the type files. Pass mark: Say who forms the youngest Xinka children: women of the community. Say what mitijul keeps away, in the guide's telling: violence. Name the Garífuna source named here: the Hiyuruwa, with sea and ancestors.

## Sub lesson 5 — The four peoples in segundo básico (teacher guide — evidence)
Sub lesson 5 questions from the type files. Pass mark: Say how the series treats these foundations: it restates them for older pupils. Name the three peoples named in this version: Xinka, Maya and Garífuna.

## Sub lesson 6 — The four peoples in tercero básico (teacher guide — evidence)
Sub lesson 6 questions from the type files. Pass mark: Say for whom this version is restated: the oldest básico pupils. Name the pattern across the series: the four peoples open every guide.
