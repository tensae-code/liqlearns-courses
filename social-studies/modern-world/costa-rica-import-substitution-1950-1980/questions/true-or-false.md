# Costa Rica — import substitution, 1950–1980 — true or false

Say True or False, and why.

**1. (Sub lesson 1)** From 1950 to 1980 Costa Rica diversifies production and industrialises by substituting imports
**Answer: True** — as the book teaches it (Unidad II, Tema 2-A: Diversificación productiva y sustitución de importaciones).

**2. (Sub lesson 2)** Import substitution and agricultural diversification promise industry — and the model exhausts itself
**Answer: True** — as the book teaches it (Unidad 2 (sociedad 1950–1980), A: El modelo de sustitución de importaciones).
