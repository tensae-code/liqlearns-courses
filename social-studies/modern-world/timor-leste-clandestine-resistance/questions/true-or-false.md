# Timor-Leste — the clandestine resistance — true or false

Say True or False, and why.

**1. (Sub lesson 1)** The clandestine resistance worked only in the mountains with Falintil.
**Answer: False — it worked inside the towns and inside Indonesia itself, as well as carrying messages to the bush.**

**2. (Sub lesson 2)** Some Indonesians organised in solidarity with Timor-Leste.
**Answer: True — groups such as Solidamor supported the cause inside Indonesia.**
