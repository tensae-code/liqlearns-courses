# Functions, variables and graphs — true or false

Say True or False, and why.

**1. (Sub lesson 1)** A variable never changes its value.
**Answer: False** — a variable is exactly a quantity that changes.

**2. (Sub lesson 2)** A function shows two variables with no connection.
**Answer: False** — a function is precisely the connection — one depends on the other.

**3. (Sub lesson 3)** A graph hides the relation between variables.
**Answer: False** — a graph draws the relation so it can be seen.
