# Functions, variables and graphs — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** About variables — the things that change — the lesson teaches that —
a) a variable is a quantity that can take different values  b) a function shows how one variable depends on another, like saving on income  c) equations state the relation in symbols; graphs draw it so the eye can see it
**Answer: a) a variable is a quantity that can take different values**

**Answer: b) a function shows how one variable depends on another, like saving on income**
