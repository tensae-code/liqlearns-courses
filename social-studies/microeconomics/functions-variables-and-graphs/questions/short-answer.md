# Functions, variables and graphs — short answer

Answer in one or two sentences, from the lesson.

**1. (Sub lesson 1)** What is a variable?
**Answer:** A variable is a quantity that can take different values, such as income, saving or price.

**2. (Sub lesson 2)** What is a function? Give the book's example.
**Answer:** A function shows how one variable depends on another — saving as a function of income.

**3. (Sub lesson 3)** What do equations and graphs each do in the book's kit?
**Answer:** Equations state the relation in symbols; graphs draw it so the eye can see it.
