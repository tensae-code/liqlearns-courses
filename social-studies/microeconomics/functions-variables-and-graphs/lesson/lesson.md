## Sub lesson 1 — Variables — the things that change

The Class 11 book's tools chapter starts with **variables**: quantities that can take different values — income, saving, price. Economics is written in variables because the things it studies change.

## Sub lesson 2 — Functions — one variable depends on another

A **function** says how one variable depends on another — the book's example is **saving as a function of income**: as income changes, saving changes with it. Functions can be **increasing** (both rise together) or **decreasing** (one rises as the other falls).

## Sub lesson 3 — Equations and graphs

The kit closes with **equations** — the book works with **linear equations** — and **graphic representation**: drawing the relation between variables as a line or curve, so the eye can see what the equation says.
