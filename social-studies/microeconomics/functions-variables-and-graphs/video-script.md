# Video script — Functions, variables and graphs

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

Functions, variables and graphs — as Pakistan's book teaches it, says the narrator: a variable is a quantity that can take different values; a function shows how one variable depends on another, like saving on income; equations state the relation in symbols; graphs draw it so the eye can see it.
