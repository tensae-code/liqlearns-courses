# Multiple cropping — growing more from fixed land — true or false

Say True or False, and why.

**1. (Sub lesson 1)** Palampur can always add new fields.
**Answer: False — its cultivated land is fixed.**

**2. (Sub lesson 2)** Multiple cropping needs extra new land.
**Answer: False — it uses the same fixed land more than once a year.**

**3. (Sub lesson 3)** Tubewells have nothing to do with multiple cropping.
**Answer: False — electric tubewell irrigation makes it possible.**
