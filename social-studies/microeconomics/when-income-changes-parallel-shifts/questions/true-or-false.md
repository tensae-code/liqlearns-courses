# When income changes — parallel shifts — true or false

Say True or False, and why.

**1. (Sub lesson 1)** When income rises at fixed prices, both intercepts of the budget line rise in the same proportion.
**Answer: True**

**2. (Sub lesson 2)** When income falls at fixed prices, the budget line shifts inward parallel to itself.
**Answer: True**

**3. (Sub lesson 3)** Income changes shift the budget line in parallel because its slope — a price ratio — does not change.
**Answer: True**
