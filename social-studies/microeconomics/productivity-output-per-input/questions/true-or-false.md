# Productivity — output per input — true or false

Say True or False, and why.

**1. (Sub lesson 1)** The number of the employed, classified by sex, age, education and qualification, is a labour indicator.
**Answer: True**

**2. (Sub lesson 2)** Value indicators measure production in physical quantities like tonnes and kilometres.
**Answer: False — value indicators measure the produced production and performed work in value (money) units; physical quantities are natural indicators.**

**3. (Sub lesson 3)** Productivity and cost price judge production from two sides — output per labour, and money expenses.
**Answer: True**
