# Profit — theories and kinds — true or false

Say True or False, and why.

**1. (Sub lesson 1)** Profit is paid before all other rewards, as a fixed wage.
**Answer: False** — profit is the remainder after other factor rewards.

**2. (Sub lesson 2)** Net profit contains no reward for the producer's own labour.
**Answer: False** — the book counts the producer's own labour inside net profit's build-up.

**3. (Sub lesson 3)** Profit never changes once a firm is set up.
**Answer: False** — the book lists six factors that move it.
