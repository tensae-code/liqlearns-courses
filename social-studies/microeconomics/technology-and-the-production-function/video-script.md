# Video script — Technology and the production function

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Greece's Grade 12 textbook gives technological change its own section in the production chapter. The production function states the output a given set of inputs can produce with the technology in use. Better technology — a better method, machine or organisation — lets the same inputs produce more.

Moving along a production function (more input, same method) must not be confused with shifting it (same input, better method). The first is growth of quantity; the second is growth of capability.

Because better technology yields more from the same inputs, it lowers the cost of each unit produced — the same wage and rent bill is now spread over more output.
