# Technology and the production function — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Better technology lets the same inputs produce —
a) the same output
b) more output
c) less output
**Answer: b) more output**

**2. (Sub lesson 2)** Finding a method that halves the labour needed is —
a) more input
b) better technology
c) a price change
**Answer: b) better technology**

**3. (Sub lesson 3)** Better technology lowers unit cost because —
a) wages always fall
b) the same input bill is spread over more output
c) demand rises
**Answer: b) the same input bill is spread over more output**
