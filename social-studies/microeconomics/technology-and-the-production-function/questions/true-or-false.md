# Technology and the production function — true or false

Say True or False, and why.

**1. (Sub lesson 1)** Technological change shifts the production function itself.
**Answer: True**

**2. (Sub lesson 2)** More input moves along the function; better technology shifts it.
**Answer: True**

**3. (Sub lesson 3)** A costly new method can still pay through a permanent fall in unit cost.
**Answer: True**
