# Technology and the production function — short answer

Answer in one or two sentences, from the lesson.

**1. (Sub lesson 1)** What shifts when technology improves?
**Answer:** The production function — at every input level, the same inputs now yield more output.

**2. (Sub lesson 2)** Distinguish the two moves.
**Answer:** More input = movement along the same production function; better technology = a shift of the whole function.

**3. (Sub lesson 3)** Why do firms adopt expensive technology?
**Answer:** For the permanent fall in unit cost that follows from producing more with the same inputs.
