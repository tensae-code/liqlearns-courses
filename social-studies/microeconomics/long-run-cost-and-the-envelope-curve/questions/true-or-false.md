# Long-run cost and the envelope curve — true or false

Say True or False, and why.

**1. (Sub lesson 1)** For each output there is a plant size that produces it most cheaply.
**Answer: True**

**2. (Sub lesson 2)** The long-run curve never lies above the best short-run curve for an output.
**Answer: True**

**3. (Sub lesson 3)** The long run is the horizon in which plant size itself can be changed.
**Answer: True**
