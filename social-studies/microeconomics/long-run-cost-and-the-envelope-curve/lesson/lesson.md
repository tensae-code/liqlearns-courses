# Long-run cost and the envelope curve

In Greece's book (Greece Grade 12 Arches Oikonomikis Theorias), **Ch.3 Cost §7 Production cost in the long run** — teaches: choosing plant size and the long-run average cost curve. This lesson teaches that placement in the course's own words.

## Sub lesson 1 — Choosing plant size in the long run

In the **long run** every input can vary — including the plant itself. Greece's Grade 12 textbook builds long-run cost from choice: for each output, the firm picks the **plant size** whose short-run cost is lowest for that output.

A small workshop is cheapest for small output; a factory, ruinous when half-empty, is cheapest for large output. Long-run planning is choosing the right short-run situation for each scale.

## Sub lesson 2 — The envelope curve

Draw all the short-run average cost curves together and the **long-run average cost curve** wraps underneath them like an **envelope** — tangent to each, formed from the lowest arc of each plant's curve.

No point of the long-run curve lies above the best short-run curve for that output, because the firm would simply choose that plant. The envelope is the floor of all the short-run possibilities.

## Sub lesson 3 — What the envelope guides

The envelope curve is the firm's expansion map: it shows the unit cost achievable at each scale when plant is chosen freely, and so where growing stops paying — the ground the next lesson's economies and diseconomies of scale explain.

A firm producing on a short-run curve above the envelope is in the wrong plant for its output; the long run is exactly the horizon in which it can move.
