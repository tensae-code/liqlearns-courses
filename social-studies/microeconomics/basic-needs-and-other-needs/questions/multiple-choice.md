# Basic needs and other needs — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Which of these is a basic need — a thing we cannot do without?
a) a game  b) food  c) tourism
**Answer: b) food**

**2. (Sub lesson 2)** Which of these is named in the book as a need that is NOT basic?
a) water  b) housing  c) computers
**Answer: c) computers**

**3. (Sub lesson 3)** At the supermarket shelf, the family's sorting puts —
a) the other needs first  b) the basic needs first  c) nothing first
**Answer: b) the basic needs first**
