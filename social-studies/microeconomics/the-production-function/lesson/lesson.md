# The production function

## Do it first

A mill takes in wheat and labour and sends out flour. If the miller is skilled, can the same wheat give more flour — and can any miller, however skilled, beat the best possible technique? Say your answers first.

## Sub lesson 1 — Output from inputs — the best technique

The production function, Q = f(L, K), is a technical relationship: it gives the maximum output obtainable from given quantities of inputs — labour L and capital K — using the best available technique. Production is studied here before any prices enter: first what can be made, later what it costs.

## Sub lesson 2 — The short run — one input moves

The short run is defined by one variable input while the others stay fixed. The book sets it on a wheat farm: land, capital and technology are fixed, and only labour varies. With the field unable to grow, every question becomes what extra workers add — the subject of the next lesson.

## Sub lesson 3 — Technical first, prices later

Because the function is technical, two farms with the same inputs and different output differ in technique, not in luck. The maximum in the definition is the standard: a producer below it is wasting inputs that better technique would turn into output. Costs, in the second half of the unit, are this physical story retold in birr.
