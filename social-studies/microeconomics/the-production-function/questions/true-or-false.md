# The production function — true or false

Say True or False, and why.

**1. (Sub lesson 1)** The production function gives the maximum output obtainable from given inputs with the best technique.
**Answer: True**

**2. (Sub lesson 2)** In the book's wheat-farm short run, only labour varies while land, capital and technology stay fixed.
**Answer: True**

**3. (Sub lesson 3)** A producer below the production function's maximum is wasting inputs that better technique would use.
**Answer: True**
