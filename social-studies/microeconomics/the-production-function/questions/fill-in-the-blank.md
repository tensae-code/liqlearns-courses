# The production function — fill in the blank

Fill each blank with the word or words from the lesson.

**1. (Sub lesson 1)** The production function gives the _____ output obtainable from given inputs and the best technique.

**3. (Sub lesson 3)** A farm below the maximum with the same inputs differs in _____ — not in luck.
