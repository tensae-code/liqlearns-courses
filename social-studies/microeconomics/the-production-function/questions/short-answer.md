# The production function — short answer

Answer in one or two sentences, from the lesson.

**1. (Sub lesson 1)** Explain "Output from inputs — the best technique" in your own words.
**Answer:** The production function gives the maximum output obtainable from given inputs with the best technique.

**2. (Sub lesson 2)** Explain "The short run — one input moves" in your own words.
**Answer:** In the book's wheat-farm short run, only labour varies while land, capital and technology stay fixed.

**3. (Sub lesson 3)** Explain "Technical first, prices later" in your own words.
**Answer:** A producer below the production function's maximum is wasting inputs that better technique would use.
