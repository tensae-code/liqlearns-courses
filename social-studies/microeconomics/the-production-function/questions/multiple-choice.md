# The production function — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Which statement best matches "Output from inputs — the best technique"?
a) Q = f(L, K) — the maximum output from given inputs with the best technique  b) the short run: land, capital and technology fixed, only labour varies  c) the function as a standard — below the maximum means wasted inputs
**Answer: a) Q = f(L, K) — the maximum output from given inputs with the best technique**

**2. (Sub lesson 2)** Which statement best matches "The short run — one input moves"?
a) Q = f(L, K) — the maximum output from given inputs with the best technique  b) the function as a standard — below the maximum means wasted inputs  c) the short run: land, capital and technology fixed, only labour varies
**Answer: c) the short run: land, capital and technology fixed, only labour varies**

**3. (Sub lesson 3)** Which statement best matches "Technical first, prices later"?
a) the short run: land, capital and technology fixed, only labour varies  b) the function as a standard — below the maximum means wasted inputs  c) Q = f(L, K) — the maximum output from given inputs with the best technique
**Answer: b) the function as a standard — below the maximum means wasted inputs**
