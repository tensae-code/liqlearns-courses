# Monopoly equilibrium — MR equals MC, price from demand — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Which statement best matches "Two routes to the same output"?
a) the widest TR-TC gap and MR = MC give the same output — three units in the book's table  b) quantity from MR = MC; price read off the demand curve above it  c) normal profit, supernormal profit or loss — and supernormal profit persists because entry is blocked
**Answer: a) the widest TR-TC gap and MR = MC give the same output — three units in the book's table**

**2. (Sub lesson 2)** Which statement best matches "The price is read off demand"?
a) the widest TR-TC gap and MR = MC give the same output — three units in the book's table  b) normal profit, supernormal profit or loss — and supernormal profit persists because entry is blocked  c) quantity from MR = MC; price read off the demand curve above it
**Answer: c) quantity from MR = MC; price read off the demand curve above it**

**3. (Sub lesson 3)** Which statement best matches "Three outcomes — but supernormal profit can stay"?
a) quantity from MR = MC; price read off the demand curve above it  b) normal profit, supernormal profit or loss — and supernormal profit persists because entry is blocked  c) the widest TR-TC gap and MR = MC give the same output — three units in the book's table
**Answer: b) normal profit, supernormal profit or loss — and supernormal profit persists because entry is blocked**
