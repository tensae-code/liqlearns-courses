# Short-run equilibrium — the total approach — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Which statement best matches "The short run — at least one input fixed"?
a) the short run fixes at least one input; only output can change  b) equilibrium where the TR-over-TC vertical gap is greatest  c) the total approach finds the output but not the price or per-unit picture
**Answer: a) the short run fixes at least one input; only output can change**

**2. (Sub lesson 2)** Which statement best matches "The total approach — the widest gap"?
a) the short run fixes at least one input; only output can change  b) the total approach finds the output but not the price or per-unit picture  c) equilibrium where the TR-over-TC vertical gap is greatest
**Answer: c) equilibrium where the TR-over-TC vertical gap is greatest**

**3. (Sub lesson 3)** Which statement best matches "What the approach leaves open"?
a) equilibrium where the TR-over-TC vertical gap is greatest  b) the total approach finds the output but not the price or per-unit picture  c) the short run fixes at least one input; only output can change
**Answer: b) the total approach finds the output but not the price or per-unit picture**
