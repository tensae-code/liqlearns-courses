# Economic data — tables, graphs and charts — fill in the blank

Fill each blank with the word or words from the lesson.

**1. (Sub lesson 1)** When one thing changes and another changes with it in a regular way, the data shows a _____ relationship.
**Answer: functional**

**2. (Sub lesson 2)** A _____ sets economic data out in rows and columns so values can be read exactly.
**Answer: table**

**3. (Sub lesson 3)** Graphs and _____ draw data as pictures so patterns can be seen at a glance.
**Answer: charts**
