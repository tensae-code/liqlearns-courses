# Economic data — tables, graphs and charts — true or false

Say True or False, and why.

**1. (Sub lesson 1)** A functional relationship means the two things never change together.
**Answer: False** — Economic data often shows a functional relationship: when one thing changes, another changes with it in a regular way.

**2. (Sub lesson 2)** A table hides the exact values of economic data.
**Answer: False** — A table sets economic data out in rows and columns so values can be read and compared exactly.

**3. (Sub lesson 3)** Graphs and charts make patterns in data harder to see.
**Answer: False** — Graphs and charts draw economic data as pictures, so patterns and changes can be seen at a glance.
