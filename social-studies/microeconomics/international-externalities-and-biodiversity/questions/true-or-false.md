# International externalities and biodiversity — true or false

Say True or False, and why.

**1. (Sub lesson 1)** Pollution never crosses borders.
**Answer: False — some externalities cross borders and harm other countries.**

**2. (Sub lesson 2)** Biodiversity loss harms only the country where it happens.
**Answer: False — biodiversity is a shared inheritance; its loss impoverishes all.**

**3. (Sub lesson 3)** A single nation can solve cross-border externalities by itself.
**Answer: False — no nation can solve them alone; countries must partner.**
