# The shutdown point — produce or close? — true or false

Say True or False, and why.

**1. (Sub lesson 1)** A closed firm still loses its fixed costs, because they are already committed.
**Answer: True**

**2. (Sub lesson 2)** If price covers average variable cost, the firm keeps producing in the short run despite losses.
**Answer: True**

**3. (Sub lesson 3)** The shutdown point is where the marginal cost curve crosses the average variable cost curve.
**Answer: True**
