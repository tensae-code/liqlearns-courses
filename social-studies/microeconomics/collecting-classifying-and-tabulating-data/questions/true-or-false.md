# Collecting, classifying and tabulating data — true or false

Say True or False, and why.

**1. (Sub lesson 1)** Economic data comes only from newspapers.
**Answer: False** — the book names five kinds of source, not one.

**2. (Sub lesson 2)** Classification mixes all the data into one pile.
**Answer: False** — classification sorts data into groups; a pile is what it fixes.

**3. (Sub lesson 3)** Simple and compound tabulation are the same thing.
**Answer: False** — simple uses one feature, compound more than one.
