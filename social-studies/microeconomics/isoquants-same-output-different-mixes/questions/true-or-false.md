# Isoquants — same output, different mixes — true or false

Say True or False, and why.

**1. (Sub lesson 1)** An isoquant joins input combinations that all yield exactly the same output.
**Answer: True**

**2. (Sub lesson 2)** A farther-out isoquant means more output.
**Answer: True**

**3. (Sub lesson 3)** The MRTS diminishes along an isoquant — each extra worker replaces less capital than the one before.
**Answer: True**
