# Returns to scale — short answer

Answer in one or two sentences, from the lesson.

**1. (Sub lesson 1)** Explain "Scaling everything at once" in your own words.
**Answer:** Returns to scale compare how much output grows with the factor by which all inputs grow.

**2. (Sub lesson 2)** Explain "The three cases in the bakery" in your own words.
**Answer:** Getting less than double the output from double the inputs is decreasing returns to scale.

**3. (Sub lesson 3)** Explain "Technological change — the function itself moves" in your own words.
**Answer:** Technological change shifts the whole production function upward — more output from the same inputs.
