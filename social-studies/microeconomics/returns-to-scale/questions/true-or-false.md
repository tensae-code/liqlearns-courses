# Returns to scale — true or false

Say True or False, and why.

**1. (Sub lesson 1)** Returns to scale compare how much output grows with the factor by which all inputs grow.
**Answer: True**

**2. (Sub lesson 2)** Getting less than double the output from double the inputs is decreasing returns to scale.
**Answer: True**

**3. (Sub lesson 3)** Technological change shifts the whole production function upward — more output from the same inputs.
**Answer: True**
