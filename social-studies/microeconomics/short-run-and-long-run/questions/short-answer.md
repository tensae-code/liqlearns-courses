# Short run and long run — fixed vs flexible — short answer

Answer in one or two sentences, from the lesson.

**1. (Sub lesson 1)** Explain "The short run" in your own words.
**Answer:** In the short run at least one input is fixed, and output rises only by adding variable inputs.

**2. (Sub lesson 2)** Explain "The long run" in your own words.
**Answer:** In the long run all inputs are variable and a new plant can be built.

**3. (Sub lesson 3)** Explain "Flexibility, not months" in your own words.
**Answer:** Short run and long run describe flexibility of arrangements, not a set number of months or years.
