# Short run and long run — fixed vs flexible — fill in the blank

Fill each blank with the word or words from the lesson.

**1. (Sub lesson 1)** In the short run at least one input is _____.
**Answer: fixed**

**2. (Sub lesson 2)** In the long run all inputs are _____.
**Answer: variable**

**3. (Sub lesson 3)** The short and long run describe _____, not a set number of months.
**Answer: flexibility**
