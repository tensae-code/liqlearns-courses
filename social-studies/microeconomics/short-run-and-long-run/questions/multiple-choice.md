# Short run and long run — fixed vs flexible — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Which statement best matches "The short run"?
a) at least one input fixed; output rises only through variable inputs  b) all inputs variable; a new plant can be built  c) the terms describe flexibility, not a set number of months or years
**Answer: a) at least one input fixed; output rises only through variable inputs**

**2. (Sub lesson 2)** Which statement best matches "The long run"?
a) at least one input fixed; output rises only through variable inputs  b) the terms describe flexibility, not a set number of months or years  c) all inputs variable; a new plant can be built
**Answer: c) all inputs variable; a new plant can be built**

**3. (Sub lesson 3)** Which statement best matches "Flexibility, not months"?
a) all inputs variable; a new plant can be built  b) the terms describe flexibility, not a set number of months or years  c) at least one input fixed; output rises only through variable inputs
**Answer: b) the terms describe flexibility, not a set number of months or years**
