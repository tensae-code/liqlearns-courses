# Short run and long run — fixed vs flexible — true or false

Say True or False, and why.

**1. (Sub lesson 1)** In the short run at least one input is fixed, and output rises only by adding variable inputs.
**Answer: True**

**2. (Sub lesson 2)** In the short run at least one input is fixed, and output rises only by adding variable inputs.
**Answer: False** — that statement belongs to sub lesson 1 (The short run); sub lesson 2 says: In the long run all inputs are variable and a new plant can be built.

**3. (Sub lesson 3)** Short run and long run describe flexibility of arrangements, not a set number of months or years.
**Answer: True**
