# Hands-on — Short run and long run — fixed vs flexible

The lesson with your hands and your feet, not only your eyes.

## Say it with things at home
Build with blocks: round one, the table size (fixed) may not change — add only worker figures. Round two, everything may change. Compare the two outputs and name the runs.

## Draw it and check it
Draw the lesson's main picture from memory — two calendars crossed out, replaced by one factory that can only hire, then the same factory adding a new building — and label every part. Then open lesson/lesson.md, compare with the picture there, and fix every label you missed.

## Teach it on the spot
Close the lesson. Teach the whole of sub lesson 1 aloud, as if to a younger learner, with no notes. Where you stop or guess, that is the part to re-read.
