# Video script — Short run and long run — fixed vs flexible

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

The short run is a period in which at least one input is fixed, and output can only be raised by adding more of the variable inputs — more labour, more raw materials, into the same fixed plant.

The long run is a period in which all inputs are variable — a new plant can be built and plant size changed. Nothing about the firm's physical setup is locked any more.

The terms describe flexibility of arrangements, not a set number of months or years. A 'short run' could be a week for a café and two years for a power station — the test is always: what is fixed?
