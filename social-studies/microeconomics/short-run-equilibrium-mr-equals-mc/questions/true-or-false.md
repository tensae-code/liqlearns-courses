# Short-run equilibrium — MR equals MC — true or false

Say True or False, and why.

**1. (Sub lesson 1)** Short-run equilibrium requires MR = MC with MC rising, cutting MR from below.
**Answer: True**

**2. (Sub lesson 2)** For a competitive firm the equilibrium rule is price equals marginal cost.
**Answer: True**

**3. (Sub lesson 3)** Price above average cost at the equilibrium output gives profit; at minimum AC, break-even; below, loss.
**Answer: True**
