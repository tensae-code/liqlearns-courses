# Fixed inputs and variable inputs — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Which statement best matches "Fixed inputs"?
a) quantity cannot be changed in the period — buildings, machinery  b) quantity can be changed — raw materials, labour  c) the fixed/variable distinction defines the short run and long run
**Answer: a) quantity cannot be changed in the period — buildings, machinery**

**2. (Sub lesson 2)** Which statement best matches "Variable inputs"?
a) quantity cannot be changed in the period — buildings, machinery  b) the fixed/variable distinction defines the short run and long run  c) quantity can be changed — raw materials, labour
**Answer: c) quantity can be changed — raw materials, labour**

**3. (Sub lesson 3)** Which statement best matches "The distinction defines the periods"?
a) quantity can be changed — raw materials, labour  b) the fixed/variable distinction defines the short run and long run  c) quantity cannot be changed in the period — buildings, machinery
**Answer: b) the fixed/variable distinction defines the short run and long run**
