# Video script — Fixed inputs and variable inputs

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A fixed input's quantity cannot be changed in the period considered — buildings and machinery are the book's examples. They set the stage size within which production must work for now.

A variable input's quantity can be changed in the period considered — raw materials and labour are the book's examples. To raise output quickly, a firm reaches for its variable inputs first.

This distinction, not the calendar, is what defines the periods of production that follow: the short run and the long run are named by which inputs can move, not by how many months pass.
