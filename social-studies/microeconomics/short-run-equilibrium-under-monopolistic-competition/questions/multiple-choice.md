# Short-run equilibrium under monopolistic competition — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Which statement best matches "A downward but elastic demand"?
a) downward demand, more elastic than monopoly's because substitutes are close  b) MR = MC with MR cutting MC from below — the same rule as monopoly  c) price above AC at the equilibrium output earns supernormal profit (POSR)
**Answer: a) downward demand, more elastic than monopoly's because substitutes are close**

**2. (Sub lesson 2)** Which statement best matches "Equilibrium — MR equals MC again"?
a) downward demand, more elastic than monopoly's because substitutes are close  b) price above AC at the equilibrium output earns supernormal profit (POSR)  c) MR = MC with MR cutting MC from below — the same rule as monopoly
**Answer: c) MR = MC with MR cutting MC from below — the same rule as monopoly**

**3. (Sub lesson 3)** Which statement best matches "The book's outcome — supernormal profit"?
a) MR = MC with MR cutting MC from below — the same rule as monopoly  b) price above AC at the equilibrium output earns supernormal profit (POSR)  c) downward demand, more elastic than monopoly's because substitutes are close
**Answer: b) price above AC at the equilibrium output earns supernormal profit (POSR)**
