# The law of diminishing returns — short answer

Answer in one or two sentences, from the lesson.

**1. (Sub lesson 1)** State the law.
**Answer:** As more units of a variable input are added to fixed inputs, the extra output per added unit eventually falls.

**2. (Sub lesson 2)** Explain the cause in one sentence.
**Answer:** Each added unit of the variable input has less of the fixed input to work with, so it adds less output.

**3. (Sub lesson 3)** How is the law escaped?
**Answer:** By changing the fixed input — more land, premises or machines — a long-run move where all inputs can vary.
