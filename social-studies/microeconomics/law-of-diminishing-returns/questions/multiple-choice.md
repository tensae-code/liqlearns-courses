# The law of diminishing returns — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The law of diminishing returns applies when —
a) all inputs grow together
b) one input grows while others stay fixed
c) prices rise
**Answer: b) one input grows while others stay fixed**

**2. (Sub lesson 2)** Returns diminish because —
a) workers become lazy
b) the fixed input is spread thinner over more variable input
c) demand falls
**Answer: b) the fixed input is spread thinner over more variable input**

**3. (Sub lesson 3)** The law of diminishing returns is a law of —
a) the long run, where all inputs vary
b) the short run, where an input is fixed
c) only farming
**Answer: b) the short run, where an input is fixed**
