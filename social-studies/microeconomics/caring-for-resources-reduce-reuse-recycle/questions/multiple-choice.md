# Caring for resources — reduce, reuse, recycle — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Which statement best matches "Pollution and depletion"?
a) pollution — harmful substances put into nature; renewables can be depleted by overuse  b) not misusing, spoiling or wasting — practised as reduce, reuse, recycle  c) reduce — use less; reuse — use again; recycle — remake into new things
**Answer: a) pollution — harmful substances put into nature; renewables can be depleted by overuse**

**2. (Sub lesson 2)** Which statement best matches "Conservation means care"?
a) pollution — harmful substances put into nature; renewables can be depleted by overuse  b) reduce — use less; reuse — use again; recycle — remake into new things  c) not misusing, spoiling or wasting — practised as reduce, reuse, recycle
**Answer: c) not misusing, spoiling or wasting — practised as reduce, reuse, recycle**

**3. (Sub lesson 3)** Which statement best matches "Reduce, reuse, recycle"?
a) not misusing, spoiling or wasting — practised as reduce, reuse, recycle  b) reduce — use less; reuse — use again; recycle — remake into new things  c) pollution — harmful substances put into nature; renewables can be depleted by overuse
**Answer: b) reduce — use less; reuse — use again; recycle — remake into new things**
