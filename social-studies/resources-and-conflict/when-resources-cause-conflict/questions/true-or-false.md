# When resources cause conflict — true or false

Say True or False, and why.

**1. (Sub lesson 1)** Many small clashes can add up to a national-scale form.
**Answer: True**

**2. (Sub lesson 2)** Resource conflict is only ever about ownership.
**Answer: False**

**3. (Sub lesson 3)** Exclusion from a needed resource can start a conflict.
**Answer: True**
