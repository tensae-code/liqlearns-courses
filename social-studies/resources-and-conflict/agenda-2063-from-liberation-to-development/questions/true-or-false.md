# Agenda 2063 — from liberation to development — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Agenda 2063 refocuses the continental agenda — it does not erase the liberation struggle's win.
**Answer: True** — a turn, built on the win.

**2. (Sub lesson 1)** Peace and security is one of the four priorities.
**Answer: True** — the fourth priority.

**3. (Sub lesson 2)** The four priorities can be treated as a menu to pick one from.
**Answer: False** — they are a set — each holds the others up.

**4. (Sub lesson 2)** This whole lesson rests on student-book pages alone.
**Answer: False** — it is the guide's extension (printed p. 102), labelled as evidence.
