# African unity — the founding of the OAU — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Haile Selassie was the main organiser of the 1958 Accra conference.
**Answer: False** — The chapter's own assessment trap: false — Accra 1958 was Ghana's gathering; Haile Selassie's gathering was Addis Ababa 1963.

**2. (Sub lesson 3)** The OAU's seat is Addis Ababa.
**Answer: True** — Addis Ababa was chosen as its seat.

**3. (Sub lesson 2)** The two groups set the political-union question aside for the time.
**Answer: True** — That setting-aside made the founding possible.
