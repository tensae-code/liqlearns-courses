# Colonisation — direct and indirect rule — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Indirect rule was used partly because it cut cost and the shortage of trained manpower.
**Answer: True** — Cheaper, and fewer trained officials needed.

**2. (Sub lesson 2)** Direct rule was a weakly centralised system.
**Answer: False** — It was strongly centralised.
