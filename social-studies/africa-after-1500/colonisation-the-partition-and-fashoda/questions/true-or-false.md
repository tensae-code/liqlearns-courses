# Colonisation — the partition and Fashoda — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Algeria and Tunisia were under France when Berlin closed.
**Answer: True** — Both were already in French hands.

**2. (Sub lesson 2)** From 1898 Sudan lay under joint British-Egyptian rule.
**Answer: True** — Joint rule followed the Fashoda settlement.
