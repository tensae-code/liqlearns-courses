# Indirect rule and settler rule — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Indirect rule abolished African chiefs.
**Answer: False** — It governed through them — under supervision.

**2. (Sub lesson 2)** Settler minorities usually shared land equally with Africans.
**Answer: False** — Settlers held the best land and power directly, as a minority.

**3. (Sub lesson 2)** Indirect rule was cheaper for Britain than ruling everywhere with European officials.
**Answer: True** — Using existing institutions made it the cheaper design.
