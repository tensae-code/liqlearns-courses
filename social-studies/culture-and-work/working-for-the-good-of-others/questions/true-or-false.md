# Working for the Good of Others — true or false

Say True or False, and why.

**1. (Sub lesson 1)** This lesson's first part teaches: work whose fruit is other people's good — cleaning the road, helping the injured, mending the bridge — done while working for one's own living.
**Answer: True**

**2. (Sub lesson 2)** This lesson's second part teaches: joining hands in work whose benefit is everyone's.
**Answer: True**

**3. (Sub lesson 3)** This lesson stands on a student book, with no teacher guide.
**Answer: True**
