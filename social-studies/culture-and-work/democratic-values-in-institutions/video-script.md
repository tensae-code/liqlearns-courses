# Video script — Democratic Values in Institutions

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). This script is full: the placements name a video-script need for this lesson. Made later, when videos are made; the script is the slot's written form until then.

---

Bangladesh Grade 7 BD G7 HSS (printed pp. 113–114), teaches: The democratic values practised inside socio-political institutions — letting others express opinions, expressing your own, respecting everyone's opinion, and deciding by the majority.

Bangladesh's own way (Grade 7): Civics is learned by doing it — the class runs a real club election with an Election Commission, code of conduct and manifestos, then sits as a Shadow Parliament and passes a law, and only then is told that the national Parliament works the same way; sociology is anchored in living communities the class visits (the Bedey boat fleet) and in guests the class interviews (Sharifa, a third-gender person)..
