# Culture — cultural values — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Every culture has values of its own.
**Answer: True**

**2. (Sub lesson 2)** All cultures judge every act the same way.
**Answer: False**

**3. (Sub lesson 2)** A way of seeing the world can be learned at school.
**Answer: True**
