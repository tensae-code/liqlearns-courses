# Helping Each Other Small Helps Big Happiness

## Do it first

Before you read on, say in your mind what you already think this is about: helping people in need makes daily life easier and grows love, respect, compassion and patience; a class whose friend cannot enter a rest stop for want of a ramp builds an awareness project for a barrier-free life, and a help project is built step by step — observe the need, form the team, set the aim, divide the jobs, evaluate and report ("Small helps, big happinesses") — as Turkey's books teach it. Hold your idea; the lesson will test it.

## Sub lesson 1 — Mutual help

Turkey Grade 3 Hayat Bilgisi 1. Kitap, printed p. 86, teaches: helping people in need makes daily life easier and grows love, respect, compassion and patience; a class whose friend cannot enter a rest stop for want of a ramp builds an awareness project for a barrier-free life, and a help project is built step by step — observe the need, form the team, set the aim, divide the jobs, evaluate and report ("Small helps, big happinesses") This lesson teaches the placements' thing in the course's own words — the book's text itself is never transcribed.

## Sub lesson 2 — Turkey's way — the book's own teaching way

Turkey's own way: Grade 3 is where Hayat Bilgisi turns explicitly civic: an eight-year-old is taught that rights and responsibilities are a pair, and then reads the UN Convention on the Rights of the Child itself — in a child-worded card set (definition of the child, no discrimination, best interests, life and development) — two years before any civics course exists. This lesson teaches the placements' thing in the course's own words — the book's text itself is never transcribed.
