# Helping Each Other Small Helps Big Happiness — true or false

Say True or False, and why.

**1. (Sub lesson 1)** This lesson's first part teaches: helping people in need makes daily life easier and grows love, respect, compassion and patience; a class whose friend cannot enter a rest stop for want of a ramp builds an awareness project for a barrier-free life, and a help project is built step by step — observe the need, form the team, set the aim, divide the jobs, evaluate and report ("Small helps, big happinesses")
