# Video script — Law Norms and Values Shape Each Other

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). This script is full: the placements name a video-script need for this lesson. Made later, when videos are made; the script is the slot's written form until then.

---

Bangladesh Grade 7 BD G7 HSS (printed pp. 117–118), teaches: Law, norms and values push each other both ways — the legal ban on child marriage changed what families could do, and changed thinking (Roy, Vidyasagar, Tagore, Rokeya) changed norms, values and then the law.

Bangladesh's own way (Grade 7): Civics is learned by doing it — the class runs a real club election with an Election Commission, code of conduct and manifestos, then sits as a Shadow Parliament and passes a law, and only then is told that the national Parliament works the same way; sociology is anchored in living communities the class visits (the Bedey boat fleet) and in guests the class interviews (Sharifa, a third-gender person)..
