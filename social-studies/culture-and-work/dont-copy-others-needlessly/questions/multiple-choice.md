# Dont Copy Others Needlessly — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The first part of this lesson is —
a) Don't copy others needlessly  b) learning the alphabet  c) counting to ten
**Answer: a) Don't copy others needlessly**

**2. (Sub lesson 1)** This lesson is mainly about —
a) not imitating others without thought  b) learning the alphabet  c) counting to ten
**Answer: a) not imitating others without thought**

**3. (Sub lesson 2)** The second part of this lesson is —
a) Nepal's way — the book's own teaching way  b) ancient kings only  c) the Moon's phases
**Answer: a) Nepal's way — the book's own teaching way**

**4. (Sub lesson 2)** Which of these is true, from the lesson?
a) This lesson teaches Not imitating others without thought.  b) Nepal's books never study this thing.  c) This lesson teaches nothing about its topic
**Answer: a) This lesson teaches Not imitating others without thought.**
