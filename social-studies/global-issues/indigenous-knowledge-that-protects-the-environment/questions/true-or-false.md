# Indigenous knowledge that protects the environment — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Indigenous knowledge is transmitted across generations.
**Answer: True**

**2. (Sub lesson 1)** A practice kept for centuries was never tested.
**Answer: False**

**3. (Sub lesson 2)** Terracing is among Ethiopia's protective practices.
**Answer: True**
