# Mitigation — cutting the gases — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Mitigation includes enhancing sinks, not only cutting emissions.
**Answer: True**

**2. (Sub lesson 2)** Adaptation alone can stop the target from moving.
**Answer: False**

**3. (Sub lesson 1)** Forests store carbon out of the sky.
**Answer: True**
