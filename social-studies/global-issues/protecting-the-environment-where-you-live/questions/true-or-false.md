# Protecting the Environment Where You Live — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Protection includes repairing damage, not only conserving what exists.
**Answer: True** — conserve, repair, reverse — the guide's three.

**2. (Sub lesson 2)** Reforestation is planting where there was never tree cover.
**Answer: False** — that is afforestation; reforestation replants destroyed or damaged forest.

**3. (Sub lesson 2)** Reducing, reusing and recycling materials is one of the community forms.
**Answer: True** — the guide names the triad.
