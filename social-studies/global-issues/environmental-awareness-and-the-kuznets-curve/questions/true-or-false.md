# Environmental awareness and the Kuznets curve — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** The milestones run from London's Great Smog (1952) and Silent Spring (1962) through Brundtland, Rio and Kyoto to the SDGs (2015).
**Answer: True**

**2. (Sub lesson 2)** The environmental Kuznets curve is an inverted-U: degradation rises, then falls, as incomes grow.
**Answer: True**
