# Corruption — bribery, theft, patronage — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Embezzlement by an official is theft of public assets.
**Answer: True**

**2. (Sub lesson 1)** Corruption exists at only one scale.
**Answer: False**

**3. (Sub lesson 2)** Petty and grand mark corruption's scales.
**Answer: True**
