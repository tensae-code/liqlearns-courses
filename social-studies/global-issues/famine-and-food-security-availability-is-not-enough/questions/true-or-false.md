# Famine and food security — availability is not enough — true or false

Say whether each statement is true or false.

**1. (Sub lesson 2)** A country can hold grain while households starve for lack of entitlement.
**Answer: True**

**2. (Sub lesson 1)** Famine and chronic hunger are the same thing.
**Answer: False**

**3. (Sub lesson 2)** Price instability can cause transitory insecurity.
**Answer: True**
