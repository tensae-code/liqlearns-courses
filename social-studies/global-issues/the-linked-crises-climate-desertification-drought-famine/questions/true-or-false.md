# The linked crises — climate, desertification, drought, famine — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Each of the four issues feeds the others.
**Answer: True**

**2. (Sub lesson 2)** Famine is only a food problem.
**Answer: False**

**3. (Sub lesson 1)** Wildfire risk is rising in some regions.
