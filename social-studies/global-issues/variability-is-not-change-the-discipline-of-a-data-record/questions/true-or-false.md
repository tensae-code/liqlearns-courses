# Variability is not change — the discipline of a data record — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Variability can happen with or without humans.
**Answer: True**

**2. (Sub lesson 1)** A single cold spell disproves a warming trend.
**Answer: False**

**3. (Sub lesson 2)** A change must show in the average and/or the variability, persistently.
**Answer: True**
