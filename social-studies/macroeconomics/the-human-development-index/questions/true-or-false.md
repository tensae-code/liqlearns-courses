# The Human Development Index — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** The HDI combines health, education and income into one quality-of-life index.
**Answer: True**

**2. (Sub lesson 2)** The HDI exists so development is not read off GDP alone.
**Answer: True**

**3. (Sub lesson 3)** Ethiopia's 2019 HDI was 0.485, ranked 173 of 189.
**Answer: True**
