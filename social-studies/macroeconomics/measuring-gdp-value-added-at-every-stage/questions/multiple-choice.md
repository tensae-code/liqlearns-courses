# Measuring GDP — value added at every stage — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Which statement best matches "Production in stages"?
a) staged production would triple-count if full prices were added at every stage  b) value added = selling price minus intermediate inputs bought at that stage  c) the sum of all value added equals the GDP found by spending and by incomes
**Answer: a) staged production would triple-count if full prices were added at every stage**

**2. (Sub lesson 2)** Which statement best matches "Value added at each stage"?
a) staged production would triple-count if full prices were added at every stage  b) the sum of all value added equals the GDP found by spending and by incomes  c) value added = selling price minus intermediate inputs bought at that stage
**Answer: c) value added = selling price minus intermediate inputs bought at that stage**

**3. (Sub lesson 3)** Which statement best matches "All three approaches, one GDP"?
a) value added = selling price minus intermediate inputs bought at that stage  b) the sum of all value added equals the GDP found by spending and by incomes  c) staged production would triple-count if full prices were added at every stage
**Answer: b) the sum of all value added equals the GDP found by spending and by incomes**
