# Measuring GDP — value added at every stage — true or false

Say True or False, and why.

**1. (Sub lesson 1)** Adding full selling prices at every stage of the bread chain would count the wheat's value repeatedly.
**Answer: True**

**2. (Sub lesson 2)** Value added at a stage is its selling price minus the intermediate inputs it bought.
**Answer: True**

**3. (Sub lesson 3)** The sum of value added at every stage equals the GDP found by the expenditure and income approaches.
**Answer: True**
