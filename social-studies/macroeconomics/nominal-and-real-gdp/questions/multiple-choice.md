# Nominal and real GDP — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Which statement best matches "Nominal GDP — current prices"?
a) nominal GDP uses current prices, so it mixes quantity growth with price rises  b) real GDP uses constant base-year prices, so it rises only when quantities rise  c) real growth comes from more capital and labour, or from productivity gains
**Answer: a) nominal GDP uses current prices, so it mixes quantity growth with price rises**

**2. (Sub lesson 2)** Which statement best matches "Real GDP — base-year prices"?
a) nominal GDP uses current prices, so it mixes quantity growth with price rises  b) real growth comes from more capital and labour, or from productivity gains  c) real GDP uses constant base-year prices, so it rises only when quantities rise
**Answer: c) real GDP uses constant base-year prices, so it rises only when quantities rise**

**3. (Sub lesson 3)** Which statement best matches "Where real growth comes from"?
a) real GDP uses constant base-year prices, so it rises only when quantities rise  b) real growth comes from more capital and labour, or from productivity gains  c) nominal GDP uses current prices, so it mixes quantity growth with price rises
**Answer: b) real growth comes from more capital and labour, or from productivity gains**
