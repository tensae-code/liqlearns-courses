# The Davenport Code and oil denationalisation

## Do it first

Before you read on, write what you already think this lesson's title means — the Davenport Code and oil denationalisation — in one sentence of your own. Keep it; you will check it against the lesson at the end.

## Sub lesson 1 — The Code reverses 1937

The Davenport Code reversed the 1937 oil nationalisation: where Toro's Bolivia had taken Standard Oil's goods, the Code opened the industry back to foreign investment.

## Sub lesson 2 — YPFB opened to privatisation

The Code allowed the privatisation of YPFB, the state oil firm, and the sale of its assets — the public company itself put on the market the Code reopened.

## Sub lesson 3 — Bundled reforms — prices, trade, barriers

The Code bundled structural reforms with the oil opening: eliminating price controls, opening foreign trade and removing trade barriers — a whole programme travelling inside one petroleum law.
