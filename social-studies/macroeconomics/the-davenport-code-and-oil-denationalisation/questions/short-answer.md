# The Davenport Code and oil denationalisation — short answer

Answer in one or two sentences, from the lesson.

**1. (Sub lesson 1)** What does the lesson teach about the Code reverses 1937?
**Answer:** The Davenport Code reversed the 1937 oil nationalisation and opened the industry to foreign investment.

**2. (Sub lesson 2)** What does the lesson teach about yPFB opened to privatisation?
**Answer:** The Code allowed the privatisation of YPFB and the sale of its assets.

**3. (Sub lesson 3)** What does the lesson teach about bundled reforms — prices, trade, barriers?
**Answer:** The Code bundled eliminating price controls, opening foreign trade and removing trade barriers.
