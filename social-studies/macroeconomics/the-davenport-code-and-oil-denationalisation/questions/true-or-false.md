# The Davenport Code and oil denationalisation — true or false

Say True or False, and why.

**1. (Sub lesson 1)** The Davenport Code nationalised the oil industry.
**Answer: False** — it reversed the 1937 nationalisation — denationalisation, not nationalisation.

**2. (Sub lesson 2)** YPFB was strengthened as a state monopoly by the Code.
**Answer: False** — the Code allowed its privatisation and the sale of its assets.

**3. (Sub lesson 3)** The Code only concerned oil wells and pipelines.
**Answer: False** — it bundled price, trade and barrier reforms too.
