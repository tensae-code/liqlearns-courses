# The Davenport Code and oil denationalisation — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** About the Code reverses 1937 — the lesson teaches that —
a) the Davenport Code reversed the 1937 oil nationalisation and opened the industry to foreign investment  b) the Code allowed the privatisation of YPFB and the sale of its assets  c) the Code bundled eliminating price controls, opening foreign trade and removing trade barriers
