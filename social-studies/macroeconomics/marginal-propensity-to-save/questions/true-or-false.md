# Marginal propensity to save — true or false

Say whether each statement is true or false, and why.

**1. (Sub lesson 1)** MPS can be greater than 1 when a household is very careful.
**Answer: False — MPS is a share of each extra birr, so it lies between 0 and 1.**

**2. (Sub lesson 2)** If MPC is 0.6, MPS is also 0.6.
**Answer: False — The two add to 1: MPS = 1 − 0.6 = 0.4.**

**3. (Sub lesson 3)** MPS falls as income rises.
**Answer: False — It is MPC that falls with income. MPS, its mirror, rises.**
