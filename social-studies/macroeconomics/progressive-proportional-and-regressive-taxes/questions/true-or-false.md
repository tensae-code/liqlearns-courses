# Progressive, proportional and regressive taxes — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Progressive takes a rising share, proportional the same share, regressive a falling share.
**Answer: True**

**2. (Sub lesson 2)** 300 on 4,000 is 7.5% and 1,400 on 20,000 is 7% — a falling share, so the schedule is regressive.
**Answer: True**

**3. (Sub lesson 3)** The three shapes put ability-to-pay into a schedule; vertical equity argues for the progressive shape.
**Answer: True**
