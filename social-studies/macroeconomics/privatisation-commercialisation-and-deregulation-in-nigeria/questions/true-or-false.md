# Privatisation, commercialisation and deregulation in Nigeria — true or false

Say True or False, and why.

**1. (Sub lesson 1)** Privatisation buys private firms into state ownership.
**Answer: False** — Privatisation sells state enterprises to private owners.

**2. (Sub lesson 2)** Commercialisation forbids state enterprises from earning money.
**Answer: False** — Commercialisation makes state enterprises run on commercial lines, earning their keep without a full sale.

**3. (Sub lesson 3)** Deregulation adds more state controls to every market.
**Answer: False** — Deregulation removes state controls so that prices and entry are set by the market; Nigeria applied all three reforms together.
