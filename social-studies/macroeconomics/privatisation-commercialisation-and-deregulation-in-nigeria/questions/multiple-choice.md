# Privatisation, commercialisation and deregulation in Nigeria — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** About privatisation — the lesson teaches that —
a) privatisation sells state enterprises to private owners.  b) commercialisation makes state enterprises run on commercial lines, earning their keep without a full sale.  c) deregulation removes state controls so that prices and entry are set by the market; Nigeria applied all three reforms together.
**Answer: a) privatisation sells state enterprises to private owners.**

**2. (Sub lesson 2)** About commercialisation — the lesson teaches that —
a) privatisation sells state enterprises to private owners.  b) commercialisation makes state enterprises run on commercial lines, earning their keep without a full sale.  c) deregulation removes state controls so that prices and entry are set by the market; Nigeria applied all three reforms together.
**Answer: b) commercialisation makes state enterprises run on commercial lines, earning their keep without a full sale.**

**3. (Sub lesson 3)** About deregulation — the lesson teaches that —
a) privatisation sells state enterprises to private owners.  b) commercialisation makes state enterprises run on commercial lines, earning their keep without a full sale.  c) deregulation removes state controls so that prices and entry are set by the market; Nigeria applied all three reforms together.
**Answer: c) deregulation removes state controls so that prices and entry are set by the market; Nigeria applied all three reforms together.**
