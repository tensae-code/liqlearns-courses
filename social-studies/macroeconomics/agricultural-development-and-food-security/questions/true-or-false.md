# Agricultural development and food security — true or false

Say True or False, and why.

**1. (Sub lesson 1)** Food security needs no rise in farm production.
**Answer: False — raising production is how food security is built.**

**2. (Sub lesson 2)** The small Indian farm is large and fully mechanised.
**Answer: False — it is small, using cooperative credit and the mandi.**

**3. (Sub lesson 3)** Both case farms are the same size.
**Answer: False — a small Indian farm is set against a large mechanised US farm.**
