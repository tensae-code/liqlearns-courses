# Basic economic magnitudes — a survey — true or false

Say True or False, and why.

**1. (Sub lesson 1)** Each headline number answers a different question about the economy.
**Answer: True**

**2. (Sub lesson 2)** Inflation measures how fast prices rise and money's value falls.
**Answer: True**

**3. (Sub lesson 3)** GDP rising guarantees unemployment falls.
**Answer: False — The magnitudes can move against each other — growth and rising unemployment can coincide.**
