# Comparative advantage — David Ricardo — true or false

Say whether each statement is true or false, and why.

**1. (Sub lesson 1)** If one country is better at both goods, trade cannot benefit it.
**Answer: False — Ricardo's point is that it still can — opportunity costs differ, so both gain by specialising.**

**2. (Sub lesson 2)** Ethiopia should export automobiles because Germany is better at wine.
**Answer: False — Germany is better at BOTH in hours; opportunity cost assigns automobiles to Germany and wine to Ethiopia.**

**3. (Sub lesson 3)** The criticisms of Ricardo include that labour is not homogeneous in reality.
**Answer: True — That is one of the noted criticisms, alongside the labour theory of value and constant costs.**
