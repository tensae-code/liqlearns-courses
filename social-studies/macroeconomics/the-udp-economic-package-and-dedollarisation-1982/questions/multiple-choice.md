# The UDP economic package and dedollarisation, 1982 — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** About democracy returns — the package — the lesson teaches that —
a) the returning UDP government's package acted on the exchange rate, the currency, prices and the external debt  b) the package restored a fixed exchange rate and prohibited dollar transactions — dedollarisation  c) the package raised prices to fund salaries and suspended external-debt payment for three months

**2. (Sub lesson 2)** About fixed rate restored — and the economy dedollarised — the lesson teaches that —

**Answer: b) the package restored a fixed exchange rate and prohibited dollar transactions — dedollarisation**

**3. (Sub lesson 3)** About prices raised, debt payment suspended — the lesson teaches that —
