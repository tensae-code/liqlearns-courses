# Short-run aggregate supply — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Which statement best matches "The upward slope"?
a) SRAS slopes upward because some costs lag behind prices in the short run  b) SRAS shifts with input prices, productivity, production taxes and subsidies, and expectations  c) In the long run supply stands vertical at potential output
**Answer: a) SRAS slopes upward because some costs lag behind prices in the short run**

**2. (Sub lesson 2)** Which statement best matches "The shifters"?
a) SRAS shifts with input prices, productivity, production taxes and subsidies, and expectations  b) In the long run supply stands vertical at potential output  c) SRAS slopes upward because some costs lag behind prices in the short run
**Answer: a) SRAS shifts with input prices, productivity, production taxes and subsidies, and expectations**

**3. (Sub lesson 3)** Which statement best matches "Short run versus long run"?
a) In the long run supply stands vertical at potential output  b) SRAS slopes upward because some costs lag behind prices in the short run  c) SRAS shifts with input prices, productivity, production taxes and subsidies, and expectations
**Answer: a) In the long run supply stands vertical at potential output**
