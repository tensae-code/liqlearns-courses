# Short-run aggregate supply — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** SRAS slopes upward because some costs lag behind prices in the short run.
**Answer: True**

**2. (Sub lesson 2)** SRAS shifts with input prices, productivity, production taxes and subsidies, and expectations.
**Answer: True**

**3. (Sub lesson 3)** In the long run supply stands vertical at potential output.
**Answer: True**
