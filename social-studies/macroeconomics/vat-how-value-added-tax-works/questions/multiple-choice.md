# VAT — how value added tax works — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Which statement best matches "Tax on the value added at each stage"?
a) VAT at 15% taxes the value added at each stage, with input credit, since 1 January 2003  b) VAT falls on final consumption in the destination where the good is used  c) An exempt supplier charges no output VAT but bears unrecoverable input VAT
**Answer: a) VAT at 15% taxes the value added at each stage, with input credit, since 1 January 2003**

**2. (Sub lesson 2)** Which statement best matches "A destination-based consumption tax"?
a) VAT falls on final consumption in the destination where the good is used  b) An exempt supplier charges no output VAT but bears unrecoverable input VAT  c) VAT at 15% taxes the value added at each stage, with input credit, since 1 January 2003
**Answer: a) VAT falls on final consumption in the destination where the good is used**

**3. (Sub lesson 3)** Which statement best matches "The exempt-supply trap"?
a) An exempt supplier charges no output VAT but bears unrecoverable input VAT  b) VAT at 15% taxes the value added at each stage, with input credit, since 1 January 2003  c) VAT falls on final consumption in the destination where the good is used
**Answer: a) An exempt supplier charges no output VAT but bears unrecoverable input VAT**
