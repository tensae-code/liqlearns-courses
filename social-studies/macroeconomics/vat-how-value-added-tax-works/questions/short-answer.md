# VAT — how value added tax works — short answer

Answer in a sentence or two, from the lesson.

**1. (Sub lesson 1)** Explain "Tax on the value added at each stage" in your own words.
**Answer:** VAT at 15% taxes the value added at each stage, with input credit, since 1 January 2003.

**2. (Sub lesson 2)** Explain "A destination-based consumption tax" in your own words.
**Answer:** VAT falls on final consumption in the destination where the good is used.

**3. (Sub lesson 3)** Explain "The exempt-supply trap" in your own words.
**Answer:** An exempt supplier charges no output VAT but bears unrecoverable input VAT.
