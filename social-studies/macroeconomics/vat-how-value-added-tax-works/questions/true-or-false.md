# VAT — how value added tax works — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** VAT at 15% taxes the value added at each stage, with input credit, since 1 January 2003.
**Answer: True**

**2. (Sub lesson 2)** VAT falls on final consumption in the destination where the good is used.
**Answer: True**

**3. (Sub lesson 3)** An exempt supplier charges no output VAT but bears unrecoverable input VAT.
**Answer: True**
