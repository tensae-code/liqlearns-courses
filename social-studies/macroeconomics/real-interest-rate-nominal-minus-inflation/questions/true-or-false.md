# Real interest rate — nominal minus inflation — true or false

Say whether each statement is true or false, and why.

**1. (Sub lesson 1)** The nominal rate already removes inflation's effect.
**Answer: False — Removing inflation is what turns the nominal rate into the real rate. The nominal rate is simply as quoted.**

**2. (Sub lesson 2)** The real rate is found by adding inflation to the nominal rate.
**Answer: False — Inflation is subtracted: real = nominal − inflation.**

**3. (Sub lesson 3)** With 15% nominal interest and 8% inflation, the real return is 23%.
**Answer: False — 23% would be adding. The real return is 15 − 8 = 7%.**
