# Poverty and the poverty line — true or false

Say True or False, and why.

**1. (Sub lesson 1)** BPS, Indonesia's statistics agency, measures poverty by the ability to meet basic needs.
**Answer: True**

**2. (Sub lesson 2)** The poverty line is set per capita: those whose spending per person falls below the line are counted as poor.
**Answer: True**

**3. (Sub lesson 3)** The teacher guide sets out the something else entirely for who counts as poor, so poverty is measured by a rule, not by impression.
**Answer: False** — The teacher guide sets out the criteria for who counts as poor, so poverty is measured by a rule, not by impression.
