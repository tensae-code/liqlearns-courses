# Kuwait — resources and national wealth — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The lesson is about the resources and wealth of —
a) the State of Kuwait  b) Gulf-coast location  c) resource base
**Answer: a) the State of Kuwait**

**2. (Sub lesson 2)** A major income source named is Kuwait's —
a) the State of Kuwait  b) Gulf-coast location  c) resource base
**Answer: b) Gulf-coast location**

**3. (Sub lesson 3)** The country's own standing wealth is its —
a) the State of Kuwait  b) Gulf-coast location  c) resource base
**Answer: c) resource base**
