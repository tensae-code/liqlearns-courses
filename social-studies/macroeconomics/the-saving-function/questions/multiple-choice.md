# The saving function — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Which statement best matches "Saving is income not consumed"?
a) Saving is disposable income not consumed, and the saving function comes from subtracting consumption from income.  b) The saving function starts negative because autonomous consumption must be financed at low income.  c) The saving function's slope is 1 − MPC; saving (a flow) differs from savings (the accumulated stock).
**Answer: a) Saving is disposable income not consumed, and the saving function comes from subtracting consumption from income.**

**2. (Sub lesson 2)** Which statement best matches "Starting negative — dissaving"?
a) The saving function's slope is 1 − MPC; saving (a flow) differs from savings (the accumulated stock).  b) Saving is disposable income not consumed, and the saving function comes from subtracting consumption from income.  c) The saving function starts negative because autonomous consumption must be financed at low income.
**Answer: c) The saving function starts negative because autonomous consumption must be financed at low income.**

**3. (Sub lesson 3)** Which statement best matches "The slope, and saving versus savings"?
a) The saving function starts negative because autonomous consumption must be financed at low income.  b) The saving function's slope is 1 − MPC; saving (a flow) differs from savings (the accumulated stock).  c) Saving is disposable income not consumed, and the saving function comes from subtracting consumption from income.
**Answer: b) The saving function's slope is 1 − MPC; saving (a flow) differs from savings (the accumulated stock).**
