# Disguised unemployment — employed, but adding nothing — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Which statement best matches "Employed, but redundant"?
a) too many workers filling too few jobs, adding minimal or no productivity  b) output would not fall if some workers were removed  c) hidden from open joblessness; tied to labour surplus in developing countries like Ethiopia
**Answer: a) too many workers filling too few jobs, adding minimal or no productivity**

**2. (Sub lesson 2)** Which statement best matches "The removal test"?
a) too many workers filling too few jobs, adding minimal or no productivity  b) hidden from open joblessness; tied to labour surplus in developing countries like Ethiopia  c) output would not fall if some workers were removed
**Answer: c) output would not fall if some workers were removed**

**3. (Sub lesson 3)** Which statement best matches "Hidden, and common where labour is surplus"?
a) output would not fall if some workers were removed  b) hidden from open joblessness; tied to labour surplus in developing countries like Ethiopia  c) too many workers filling too few jobs, adding minimal or no productivity
**Answer: b) hidden from open joblessness; tied to labour surplus in developing countries like Ethiopia**
