# Package projects — comprehensive and minimum — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** The comprehensive package reached millions of smallholders across the whole country.
**Answer: False**

**2. (Sub lesson 2)** The comprehensive package failed because it did not raise incomes at all.
**Answer: False**

**3. (Sub lesson 3)** Minimum package projects gave a full, intensive package to a few zones only.
**Answer: False**
