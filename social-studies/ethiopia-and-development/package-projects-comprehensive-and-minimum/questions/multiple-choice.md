# Package projects — comprehensive and minimum — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Which statement best matches "The comprehensive package"?
a) comprehensive package projects (SIDA; Chillalo, Shashemene, Wolayta, Adaa) raised participants' incomes  b) comprehensive packages could never reach millions of smallholders  c) minimum package projects from 1971: wide coverage, minimum scarce inputs
**Answer: a) comprehensive package projects (SIDA; Chillalo, Shashemene, Wolayta, Adaa) raised participants' incomes**

**2. (Sub lesson 2)** Which statement best matches "Why comprehensive could not be the whole answer"?
a) comprehensive packages could never reach millions of smallholders  b) minimum package projects from 1971: wide coverage, minimum scarce inputs  c) comprehensive package projects (SIDA; Chillalo, Shashemene, Wolayta, Adaa) raised participants' incomes
**Answer: a) comprehensive packages could never reach millions of smallholders**

**3. (Sub lesson 3)** Which statement best matches "The minimum package — and who carried it"?
a) minimum package projects from 1971: wide coverage, minimum scarce inputs  b) comprehensive package projects (SIDA; Chillalo, Shashemene, Wolayta, Adaa) raised participants' incomes  c) comprehensive packages could never reach millions of smallholders
**Answer: a) minimum package projects from 1971: wide coverage, minimum scarce inputs**
