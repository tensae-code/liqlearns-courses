# Ethiopia's first five-year plan, 1957–1961 — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Ethiopia's first five-year plan ran 1957–1961 under Haile Selassie.
**Answer: True**

**2. (Sub lesson 2)** The first plan prioritised infrastructure, skilled workers for processing industries, and commercial agriculture.
**Answer: True**

**3. (Sub lesson 3)** GNP grew 3.2% against a 3.7% target, and coffee supplied 70% of foreign-exchange earnings.
**Answer: True**
