# Real vs nominal GDP and the deflator — true or false

Say True or False, and why.

**1. (Sub lesson 1)** Real GDP values output at base-year prices, so only quantity changes move it.
**Answer: True**

**2. (Sub lesson 2)** The GDP deflator equals nominal GDP divided by real GDP, times 100.
**Answer: True**

**3. (Sub lesson 3)** Table 7.2's deflators run 100, 131 and 148 across 2010–2012.
**Answer: True**
