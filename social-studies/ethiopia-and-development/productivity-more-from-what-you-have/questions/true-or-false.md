# Productivity — more from what you have — true or false

Say whether each statement is true or false, and why.

**1. (Sub lesson 1)** Productivity means working longer hours.
**Answer: False — Longer hours add input. Productivity is output per unit of input — efficiency, not effort-hours.**

**2. (Sub lesson 2)** Producing the same output from MORE input raises productivity.
**Answer: False — That way the ratio falls. Productivity rises when output grows relative to input, not the reverse.**

**3. (Sub lesson 3)** Productivity matters only inside single firms.
**Answer: False — The lesson lifts it to the whole economy: GDP per hour worked is a national measure and a source of national growth.**
