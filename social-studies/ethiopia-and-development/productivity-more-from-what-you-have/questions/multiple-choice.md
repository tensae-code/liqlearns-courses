# Productivity — more from what you have — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Which statement best matches "Output per unit of input"?
a) Productivity is output per unit of input, commonly GDP per hour worked.  b) Productivity rises via more output from the same input, the same output from less input, or a large output rise from a small input rise.  c) Productivity is a key source of growth and competitiveness.
**Answer: a) Productivity is output per unit of input, commonly GDP per hour worked.**

**2. (Sub lesson 2)** Which statement best matches "Three ways to raise it"?
a) Productivity is a key source of growth and competitiveness.  b) Productivity is output per unit of input, commonly GDP per hour worked.  c) Productivity rises via more output from the same input, the same output from less input, or a large output rise from a small input rise.
**Answer: c) Productivity rises via more output from the same input, the same output from less input, or a large output rise from a small input rise.**

**3. (Sub lesson 3)** Which statement best matches "Why productivity matters"?
a) Productivity rises via more output from the same input, the same output from less input, or a large output rise from a small input rise.  b) Productivity is a key source of growth and competitiveness.  c) Productivity is output per unit of input, commonly GDP per hour worked.
**Answer: b) Productivity is a key source of growth and competitiveness.**
