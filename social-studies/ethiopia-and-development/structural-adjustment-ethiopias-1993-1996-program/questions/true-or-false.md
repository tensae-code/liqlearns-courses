# Structural adjustment — Ethiopia's 1993–1996 program — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** By 1991 the economy faced high inflation and negative interest rates.
**Answer: True**

**2. (Sub lesson 2)** Structural adjustment is only a set of budget cuts.
**Answer: False**

**3. (Sub lesson 3)** Expenditure-switching was not part of the program.
**Answer: False**
