# Innovation — and its four types — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Which statement best matches "Innovation — the idea implemented"?
a) implementing a new idea to create new value — the means of exploiting opportunity  b) invention — a new creation; extension — growth of an existing one  c) duplication — replicating an existing thing; synthesis — combining concepts into a new formulation
**Answer: a) implementing a new idea to create new value — the means of exploiting opportunity**

**2. (Sub lesson 2)** Which statement best matches "Invention and extension"?
a) implementing a new idea to create new value — the means of exploiting opportunity  b) duplication — replicating an existing thing; synthesis — combining concepts into a new formulation  c) invention — a new creation; extension — growth of an existing one
**Answer: c) invention — a new creation; extension — growth of an existing one**

**3. (Sub lesson 3)** Which statement best matches "Duplication and synthesis"?
a) invention — a new creation; extension — growth of an existing one  b) duplication — replicating an existing thing; synthesis — combining concepts into a new formulation  c) implementing a new idea to create new value — the means of exploiting opportunity
**Answer: b) duplication — replicating an existing thing; synthesis — combining concepts into a new formulation**
