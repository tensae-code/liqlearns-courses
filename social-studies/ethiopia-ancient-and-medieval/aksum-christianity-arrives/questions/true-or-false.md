# Aksum — Christianity arrives — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Frumentius is also called Abune Selama.
**Answer: True** — He is remembered as Abune Selama.

**2. (Sub lesson 1)** Ezana accepted Christianity before Frumentius arrived.
**Answer: False** — Frumentius brought the faith; then Ezana accepted it.

**3. (Sub lesson 2)** The Bible's translation into Ge'ez was one result of this age.
**Answer: True** — The Bible was translated from Greek into Ge'ez.
