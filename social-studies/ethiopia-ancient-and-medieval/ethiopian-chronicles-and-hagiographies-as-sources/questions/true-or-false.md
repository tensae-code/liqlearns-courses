# Ethiopian chronicles and hagiographies as sources — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** The chronicles were written by foreign travellers only.
**Answer: False** — An indigenous tradition, written at Ethiopian courts.

**2. (Sub lesson 2)** A primary source needs no testing because it is old.
**Answer: False** — Primaries are checked for authenticity and forgery.

**3. (Sub lesson 2)** A source written to praise can still yield evidence when tested.
**Answer: True** — Dates, names and sequences survive cross-testing.
