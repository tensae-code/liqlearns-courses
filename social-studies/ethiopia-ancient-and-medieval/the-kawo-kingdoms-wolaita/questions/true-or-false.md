# The kawo kingdoms — Wolaita — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** True or false: A kingdom's remembered line of kings — this is dynastic memory.
**Answer: True**

**2. (Sub lesson 1)** True or false: in this lesson, kawo means the sacral royal title of Kafa, contrasted with kawo.
**Answer: False**

**3. (Sub lesson 2)** True or false: Payments exacted from absorbed neighbours — this is tribute.
**Answer: True**

**4. (Sub lesson 2)** True or false: in this lesson, expansion means a rich kingdom watched hungrily by stronger neighbours.
**Answer: False**

**5. (Sub lesson 3)** True or false: Absorption into the highland empire, which came late to Wolaita — this is incorporation.
**Answer: True**

**6. (Sub lesson 3)** True or false: in this lesson, resistance means the long self-rule Wolaita remembered.
**Answer: False**
