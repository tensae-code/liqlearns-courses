# The Adal wars — the first phase — true or false

Say whether each statement is true or false.

**1.** The sultanates fought to recover land and independence.
**Answer: True** — That drive is the second named cause.

**2.** The first phase ended in 1543.
**Answer: False** — It ended in 1527; 1543 ends the second phase.

**3.** Dawit defeated Haqq al-Din II in 1387.
**Answer: True** — One of Dawit's three dated victories.
