# The sultanates — Shewa, the oldest sultanate — true or false

Say whether each statement is true or false.

**1.** Shewa is described in the guide as the oldest Muslim sultanate in Ethiopia.
**Answer: True** — The guide's keyed entry (teacher guide — evidence).

**2.** Shewa appears as a full lesson in the Grade 7 student book.
**Answer: False** — The student book has no Shewa counterpart; this lesson stands on guide evidence only.

**3.** The guide names Zeila the main gateway to the interior.
**Answer: True** — Two gateways: Dahlak and Zeila, Zeila main (teacher guide — evidence).

**4. (Grade 11 depth)** True or false: The sultanate that absorbed Shewa — this is Ifat.
**Answer: True**
