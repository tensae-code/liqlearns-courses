# Volcano shapes — shield, strato, cinder cone — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Strato volcanoes erupt only gently, never explosively.
**Answer: False**

**2. (Sub lesson 1)** Fluid lava travels far, so shield volcanoes spread wide.
**Answer: True**

**3. (Sub lesson 2)** Cinder cones are built of loose fragments.
**Answer: True**
