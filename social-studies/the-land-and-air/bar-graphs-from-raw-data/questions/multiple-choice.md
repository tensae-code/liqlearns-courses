# Bar graphs from raw data — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A bar graph compares data by —
a) bar height or length  b) the colour of the bars  c) the number of pages
**Answer: a) bar height or length**

**2. (Sub lesson 2)** The book's bar-graph worked example uses —
a) Ethiopia's population  b) Lake Tana's depth  c) Gore Town's rainfall
**Answer: c) Gore Town's rainfall**

**3. (Sub lesson 1)** Bar graphs suit data series that are —
a) impossible to count  b) independent — categories standing apart  c) a single moment
**Answer: b) independent — categories standing apart**

**4. (Sub lesson 2)** In the worked example, each bar's height stands for —
a) that month's rainfall  b) that month's temperature  c) the number of rainy days only
**Answer: a) that month's rainfall**
