# The elements we measure — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** An element of weather is —
a) soil  b) latitude  c) humidity
**Answer: c) humidity**

**2. (Sub lesson 1)** Precipitation means —
a) sunshine  b) rain and other falling water  c) air pressure
**Answer: b) rain and other falling water**

**3. (Sub lesson 2)** A climate description is built of —
a) the elements averaged over years  b) one day’s elements  c) instruments only
**Answer: a) the elements averaged over years**

**4. (Sub lesson 2)** If an element’s average changes, —
a) nothing changes  b) weather stops  c) the climate description changes
**Answer: c) the climate description changes**
