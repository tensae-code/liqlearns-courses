# Six-figure grid references

## Do it first

Four figures name a square. Six figures find a point inside it — by tenths. Read the refinement.

## Sub lesson 1 — Tenths

Divide the grid square in your mind into tenths each way. The point’s six-figure reference is: the square’s easting, then the tenths eastward to the point; the square’s northing, then the tenths northward. Tenths are estimated by eye between the grid lines.

The book’s procedure table works points B, F and N inside square CA, step by step: square first, tenths second, the point fixed. Follow the table’s order and any point on the map can be given to another reader exactly.
