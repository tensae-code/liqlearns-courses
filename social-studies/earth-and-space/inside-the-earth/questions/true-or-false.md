# Inside the Earth — Crust, Mantle, Core — true or false

Say True or False, and why.

**1. (Sub lesson 1)** The inner core is liquid.
**Answer: False — the outer core is partly molten; the inner core is solid.**

**2. (Sub lesson 2)** Deep ocean drilling is an indirect source.
**Answer: False — drilling brings up real material; it is a direct source.**
