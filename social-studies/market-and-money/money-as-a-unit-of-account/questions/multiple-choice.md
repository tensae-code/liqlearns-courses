# Money as a unit of account — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Which statement best matches "The common measure"?
a) the common measure in which values are expressed  b) up to 999 relative prices per item without money; one price tag each with it  c) orderly pricing, rational calculation and transmission of economic information
**Answer: a) the common measure in which values are expressed**

**2. (Sub lesson 2)** Which statement best matches "The thousand-item problem"?
a) the common measure in which values are expressed  b) orderly pricing, rational calculation and transmission of economic information  c) up to 999 relative prices per item without money; one price tag each with it
**Answer: c) up to 999 relative prices per item without money; one price tag each with it**

**3. (Sub lesson 3)** Which statement best matches "What the measure makes possible"?
a) up to 999 relative prices per item without money; one price tag each with it  b) orderly pricing, rational calculation and transmission of economic information  c) the common measure in which values are expressed
**Answer: b) orderly pricing, rational calculation and transmission of economic information**
