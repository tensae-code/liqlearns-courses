# Financial institutions and the rules of the game — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Which statement best matches "Institutions — rules, formal and informal"?

**2. (Sub lesson 2)** Which statement best matches "Three types, and banks' work in development"?

**3. (Sub lesson 3)** Which statement best matches "Non-bank financial institutions"?

**4. (Sub lesson 4)** Which statement best matches "The financial system in five components (teacher guide)"?
