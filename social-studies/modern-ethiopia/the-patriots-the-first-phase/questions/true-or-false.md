# The Patriots — the first phase, 1936–37 — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** The first phase continued the main war to early 1937.
**Answer: True** — Led by the great lords who had fought in it.

**2. (Sub lesson 2)** Dejazmach Balcha, a leader of the 1936 attempt, was a hero of Adwa.
**Answer: True** — The book calls him 'the Adwa hero Dejazmach Balcha'.

**3. (Sub lesson 2)** The 1936 attack freed Addis Ababa.
**Answer: False** — It did not — the groups fought separately and the attempt failed.
