# How indigenous knowledge behaves — oral, local, inherited — true or false

Say whether each sentence is true or false.

**1. ** Indigenous knowledge is local, practised and inherited.
**Answer: True** — the three marks together.

**2. ** If knowledge is not practised, indigenous transmission still preserves it perfectly.
**Answer: False** — what is not practised is not preserved — transmission and use are the same act.

**3. ** Indigenous knowledge's library is memory and its publishing is practice.
**Answer: True** — the first mark's image.

**4. ** The marks can be used to test any claimed piece of indigenous knowledge.
**Answer: True** — the lesson's purpose — a recognition tool.
