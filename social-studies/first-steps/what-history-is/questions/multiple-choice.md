# What history is — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is istoria?
a) the Greek word for inquiry, from which 'history' comes
b) pre-history
c) cause and effect
**Answer: a) the Greek word for inquiry, from which 'history' comes**

**2. (Sub lesson 2)** What is continuity?
a) what stays the same across long stretches of the past
b) evidence
c) change
**Answer: a) what stays the same across long stretches of the past**

**3. (Sub lesson 3)** What is method?
a) proof
b) the shared rules by which historians test claims from sources
c) reconstruction
**Answer: b) the shared rules by which historians test claims from sources**
