# Cause and effect in history — true or false

Say True or False, and why.

**1. (Sub lesson 3)** Every historical event has both causes that led to it and results that followed.
**Answer: True** — the book teaches both halves of the chain.

**2. (Sub lesson 2)** A result comes before the event that caused it.
**Answer: False** — a result follows the event; a cause comes before it.
