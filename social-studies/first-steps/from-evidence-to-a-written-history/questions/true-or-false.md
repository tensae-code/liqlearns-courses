# From evidence to a written history — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A textbook is a primary source for the events it describes.
**Answer: False** — A textbook is secondary — written later, from primaries.

**2. (Sub lesson 2)** A diary written during an event is a primary source.
**Answer: True** — Contemporary with the event.

**3. (Sub lesson 3)** Avoiding bias is easy for a trained historian.
**Answer: False** — The book admits it is difficult in practice.
