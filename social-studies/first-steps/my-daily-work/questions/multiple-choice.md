# My Daily Work — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The first part of this lesson is —
a) My daily work  b) learning the alphabet  c) counting to ten
**Answer: a) My daily work**

**2. (Sub lesson 1)** This lesson is mainly about —
a) the work a child does each day  b) learning the alphabet  c) counting to ten
**Answer: a) the work a child does each day**

**3. (Sub lesson 2)** The second part of this lesson is —
a) Nepal's way — the book's own teaching way  b) ancient kings only  c) the Moon's phases
**Answer: a) Nepal's way — the book's own teaching way**

**4. (Sub lesson 2)** Which of these is true, from the lesson?
a) This lesson teaches The work a child does each day.  b) Nepal's books never study this thing.  c) This lesson teaches nothing about its topic
**Answer: a) This lesson teaches The work a child does each day.**
