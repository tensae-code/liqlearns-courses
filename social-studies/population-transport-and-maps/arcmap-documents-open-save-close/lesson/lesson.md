# ArcMap documents — open, save, close

## Do it first

Before you read, think about this: you close your map and reopen it tomorrow — where did the data go? Say what you think first, then read on and check yourself.

## Sub lesson 1 — What an .mxd is

An ArcMap document, .mxd, holds the map, its display settings and pointers to the data. It does not hold the data itself — move the document without its data and the map opens empty. When the data must travel with it, the document is shared as a map package.

## Sub lesson 2 — Opening and saving

Start ArcMap from its icon, or by double-clicking an .mxd file. Save with File: give a name and a folder, and .mxd is appended for you.

## Sub lesson 3 — Closing

Close with File → Close. Opening a new map closes the current one — so save before you switch, or the pointers you arranged are lost.
