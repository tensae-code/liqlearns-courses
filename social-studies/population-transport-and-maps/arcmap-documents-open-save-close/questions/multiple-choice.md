# ArcMap documents — open, save, close — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** An .mxd holds the map, display settings and —
a) pointers to data  b) the data itself  c) printed copies
**Answer: a) pointers to data**

**2. (Sub lesson 1)** To make data travel with the document, share it as —
a) a map package  b) a screenshot  c) a printout
**Answer: a) a map package**

**3. (Sub lesson 2)** Double-clicking an .mxd —
a) opens it in ArcMap  b) deletes it  c) prints it
**Answer: a) opens it in ArcMap**

**4. (Sub lesson 3)** Opening a new map —
a) closes the current one  b) keeps both open  c) saves automatically
**Answer: a) closes the current one**
