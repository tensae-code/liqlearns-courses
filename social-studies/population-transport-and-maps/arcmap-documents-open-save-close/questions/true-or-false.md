# ArcMap documents — open, save, close — true or false

Say True or False, and why.

**1. (Sub lesson 1)** The .mxd extension is appended when you save.
**Answer: True**

**2. (Sub lesson 2)** An .mxd stores all its data inside itself.
**Answer: False**

**3. (Sub lesson 3)** File → Close closes the document.
**Answer: True**
