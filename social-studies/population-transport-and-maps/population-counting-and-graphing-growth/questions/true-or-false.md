# Population — counting and graphing growth — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A count you cannot read back in a clear table is not finished.
**Answer: True**

**2. (Sub lesson 2)** A bar graph and a line graph of the same years must tell the same story.
**Answer: True**

**3. (Sub lesson 2)** Population numbers never change classrooms or play space.
**Answer: False**
