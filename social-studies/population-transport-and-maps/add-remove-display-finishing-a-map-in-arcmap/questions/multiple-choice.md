# Add, remove, display — finishing a map in ArcMap — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Data can be added by dragging from —
a) the ArcCatalog window  b) the printer  c) the layout page
**Answer: a) the ArcCatalog window**

**2. (Sub lesson 1)** A layer is removed by —
a) right-click → Remove  b) deleting the data  c) closing ArcMap
**Answer: a) right-click → Remove**

**3. (Sub lesson 2)** The Table of Contents order, top to bottom, is —
a) points, lines, polygons, rasters  b) rasters, polygons, lines, points  c) lines, points, rasters, polygons
**Answer: a) points, lines, polygons, rasters**

**4. (Sub lesson 3)** Titles, north arrows and scale bars belong to —
a) layout view  b) data view  c) ArcCatalog
**Answer: a) layout view**
