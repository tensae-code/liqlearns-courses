# Add, remove, display — finishing a map in ArcMap — short answer

Answer in one or two sentences, from the lesson.

**1. (Sub lesson 1)** Name the two ways to add data.
**Answer:** Drag from ArcCatalog; the Add Data button (with basemap/online routes).

**2. (Sub lesson 2)** State the stacking order and why.
**Answer:** Points, lines, polygons, rasters — so small features stay visible over large ones.

**3. (Sub lesson 3)** Distinguish the two views.
**Answer:** Data view: real-world coordinates, exploring/querying. Layout view: page space, titles/north arrows/scale bars.
