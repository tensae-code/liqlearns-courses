# ArcMap tools — the toolbar and the toolbox

## Do it first

Before you read, think about this: nineteen tools on one toolbar — can you name what each is for? Say what you think first, then read on and check yourself.

## Sub lesson 1 — The nineteen tools

The tools are enumerated in the book's order: new, open, save, print; add layers; edit; ArcCatalog; ArcToolbox; zoom in and out and fixed zooms; pan; full extent; select elements; identify; find; add XY; and measure. Learn them as four families: file, view, select-and-ask, and measure.

## Sub lesson 2 — ArcToolbox

ArcToolbox is organised in three levels: toolboxes contain toolsets, toolsets contain tools. The eight common toolboxes are named: Analysis, Cartography, Conversion, Coverage, Data Management, Geocoding, Linear Referencing and Spatial Analyst.

## Sub lesson 3 — ArcCatalog

ArcCatalog is the file manager and metadata keeper of the system — the librarian standing beside the mapmaker, knowing where every data set lives and what it describes.
