# ArcMap tools — the toolbar and the toolbox — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The toolbar's tools number —
a) nineteen  b) nine  c) twenty-nine
**Answer: a) nineteen**

**2. (Sub lesson 1)** Full extent is a —
a) view tool  b) file tool  c) measure tool
**Answer: a) view tool**

**3. (Sub lesson 2)** Toolboxes contain toolsets, which contain —
a) tools  b) maps  c) printers
**Answer: a) tools**

**4. (Sub lesson 3)** Metadata is kept by —
a) ArcCatalog  b) ArcToolbox  c) the printer
**Answer: a) ArcCatalog**
