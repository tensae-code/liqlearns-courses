# ArcMap tools — the toolbar and the toolbox — short answer

Answer in one or two sentences, from the lesson.

**1. (Sub lesson 1)** Name the four families used in the lesson.
**Answer:** File, view, select-and-ask, measure.

**2. (Sub lesson 2)** Name four of the eight common toolboxes.
**Answer:** Analysis, Cartography, Conversion, Coverage, Data Management, Geocoding, Linear Referencing, Spatial Analyst (any four).

**3. (Sub lesson 3)** What is ArcCatalog's role?
**Answer:** File manager and metadata keeper.
