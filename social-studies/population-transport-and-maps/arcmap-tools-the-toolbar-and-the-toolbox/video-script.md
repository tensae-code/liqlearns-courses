# Video script — ArcMap tools — the toolbar and the toolbox

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

The tools are enumerated in the book's order: new, open, save, print; add layers; edit; ArcCatalog; ArcToolbox; zoom in and out and fixed zooms; pan; full extent; select elements; identify; find; add XY; and measure.

ArcToolbox is organised in three levels: toolboxes contain toolsets, toolsets contain tools.

ArcCatalog is the file manager and metadata keeper of the system — the librarian standing beside the mapmaker, knowing where every data set lives and what it describes..
