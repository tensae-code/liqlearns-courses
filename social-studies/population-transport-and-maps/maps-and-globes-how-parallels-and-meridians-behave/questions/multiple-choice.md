# Maps and globes — how parallels and meridians behave — multiple choice

Pick the one right answer.

**1.** The longest parallel is —
a) Cancer  b) Capricorn  c) The pole ring  d) The equator
**Answer: d) The equator**

**2.** At the poles, a parallel's length is —
a) The same as the equator's  b) Half the equator's  c) 0 km  d) 1,000 km
**Answer: c) 0 km**

**3.** All meridians are equal because —
a) All ring the equator  b) All pass through both poles  c) All shrink  d) None meets a pole
**Answer: b) All pass through both poles**
