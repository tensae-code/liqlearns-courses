# Video script — Thematic Maps of Mercosur Integration

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). This script is full: the placements name a video-script need for this lesson. Made later, when videos are made; the script is the slot's written form until then.

---

A map can be drawn for one theme. That is a thematic map.

Argentina's teacher notebook uses thematic maps to teach how Mercosur's countries are physically joined.

And the maps do not work alone — newspaper articles about the same integration sit beside them.

Map and article, checking each other: that is how Argentina teaches integration.
