# Push and pull — why Africans move — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Corruption and poor governance can be push factors.
**Answer: True** — named in the book's push list.

**2. (Sub lesson 1)** Education is a push factor.
**Answer: False** — education is a pull factor — an attraction of destinations.

**3. (Sub lesson 2)** Migration usually needs both a push and a pull together.
**Answer: True** — either list alone rarely moves a population.

**4. (Sub lesson 3)** Some communities straddle modern borders drawn later than their own settlement.
**Answer: True** — the book names border-straddling communities.
