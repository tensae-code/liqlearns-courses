# Renewable, non-renewable — and using sustainably — true or false

Say whether each statement is true or false.

**1. (Sub lesson 2)** Using sunlight today shrinks tomorrow's sunlight. True or false?
**Answer: False** — sunlight replenishes as fast as it is used; that is what renewable means.

**2. (Sub lesson 2)** A fixed-amount resource can be used forever if we are careful. True or false?
**Answer: False** — careful use slows the end; the amount is still fixed.

**3. (Sub lesson 3)** A renewable resource can still be destroyed by over-use. True or false?
**Answer: True** — sustainable use is the rule that prevents it.
