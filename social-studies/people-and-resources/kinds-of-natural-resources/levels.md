# Kinds of Natural Resources — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The two sub lessons are the book's two sorts,
in the book's order: living against non-living first, then
used-up against renewing.

## Sub lesson 1 — Living and non-living
Sub lesson 1 questions from the type files. Pass mark: sort plants, animals, minerals, water and soil correctly as biotic or abiotic, and say what each word means.

## Sub lesson 2 — Can be used up, or renews itself
Sub lesson 2 questions from the type files. Pass mark: sort minerals, oil, coal, natural gas, air, water, plants and sunlight correctly as exhaustible or renewable; place one resource in both sorts at once; and state the warning that a renewable resource used faster than it replaces itself can still be depleted.
