# Fixing unemployment — the solution set

## Do it first

Before you read, be the minister for one minute: write the three moves you would make first against unemployment in your area. Seal the list in your mind — then compare it with the book's solution set.

## Sub lesson 1 — Job creation

The first solution is the direct one: create jobs — work that did not exist before, in building, services, farming's value chains and small enterprise. Every other solution prepares people for work; this one makes the work itself.

[Picture 21966 — a training workshop beside a new small business opening its doors]

## Sub lesson 2 — Employability and skills

The second solution works on the worker's side: training that builds employability — the skills and fitness real jobs require — so that when work appears, local people can actually take it. Skills without jobs strand people; jobs without skills import workers; the set holds both.

## Sub lesson 3 — Employment that lasts — sustainable development

The third ties employment to sustainable development: work that does not eat the resource base it stands on, so today's jobs do not become tomorrow's unemployment. The solution set is a set because each leg fails without the other two.
