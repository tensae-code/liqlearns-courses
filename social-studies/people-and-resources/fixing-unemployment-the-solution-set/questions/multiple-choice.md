# Fixing unemployment — the solution set — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The first leg of the solution set is —
a) job creation  b) higher taxes  c) fewer schools
**Answer: a) job creation**

**2. (Sub lesson 2)** Employability is built by —
a) waiting for work  b) moving abroad  c) training in the skills real jobs require
**Answer: c) training in the skills real jobs require**

**3. (Sub lesson 3)** The third leg ties employment to —
a) imported labour  b) sustainable development  c) seasonal work only
**Answer: b) sustainable development**

**4. (Sub lesson 1)** Jobs without skills, in the lesson's warning, —
a) import workers  b) create skills by themselves  c) end unemployment
**Answer: a) import workers**
