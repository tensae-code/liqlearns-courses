# Video script — Fixing unemployment — the solution set

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

The first solution is the direct one: create jobs — work that did not exist before, in building, services, farming's value chains and small enterprise.

The second solution works on the worker's side: training that builds employability — the skills and fitness real jobs require — so that when work appears, local people can actually take it.

The third ties employment to sustainable development: work that does not eat the resource base it stands on, so today's jobs do not become tomorrow's unemployment.
