# Poverty and conflict — which causes which? — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Poverty deterministically triggers conflict by itself.
**Answer: False**

**2. (Sub lesson 1)** Conflict and poverty can reinforce each other in cycles.
**Answer: True**

**3. (Sub lesson 2)** Displacement is one way conflict impoverishes.
**Answer: True**
