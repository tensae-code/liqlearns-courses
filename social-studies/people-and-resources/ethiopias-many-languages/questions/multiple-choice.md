# Ethiopia’s many languages — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Ethiopia is home to more than —
a) 8 languages  b) 30 languages  c) 80 languages
**Answer: c) 80 languages**

**2. (Sub lesson 1)** The largest language groups are named from —
a) school registers  b) census data  c) a traveller’s guess
**Answer: b) census data**

**3. (Sub lesson 2)** Amharic is —
a) the federal working language  b) the only language allowed  c) a regional language only
**Answer: a) the federal working language**

**4. (Sub lesson 2)** The working language is a bridge across —
a) one region  b) the capital only  c) all the language communities
**Answer: c) all the language communities**
