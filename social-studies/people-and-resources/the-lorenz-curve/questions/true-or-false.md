# The Lorenz curve — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** The Lorenz curve plots cumulative population share against cumulative income share, poorest first.
**Answer: True**

**2. (Sub lesson 2)** Perfect equality is the 45-degree diagonal, and real curves bow below it.
**Answer: True**

**3. (Sub lesson 3)** Max Lorenz devised the curve in 1905; the Gini coefficient is computed from it.
**Answer: True**
