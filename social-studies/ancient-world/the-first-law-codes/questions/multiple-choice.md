# The first law codes — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The earliest law code the book names is —
a) Hammurabi's  b) Ur-Namma's  c) Rome's Twelve Tables
**Answer: b) Ur-Namma's** — set down in Sumer.

**2. (Sub lesson 1)** Hammurabi's code was —
a) Kept secret in the palace  b) Carved on a tall stone for all to see  c) Written only in Egypt
**Answer: b) Carved on a tall stone for all to see** — Babylon's published laws.

**3. (Sub lesson 1)** Written law changes justice because —
a) It binds the judge as well as the judged  b) Kings write faster  c) Stones are heavy
**Answer: a) It binds the judge as well as the judged** — a poor man can point at the stone.

**4. (Sub lesson 1)** Before written codes, justice depended on —
a) A public vote  b) The strong man's mood  c) Priests' calendars
**Answer: b) The strong man's mood** — the condition the codes ended.
