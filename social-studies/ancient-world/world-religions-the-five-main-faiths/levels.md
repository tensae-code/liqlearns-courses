# World religions — the five main faiths — sub lessons and depth

This is the depth record for the lesson, re-expressed as sub lessons: each sub lesson below is one part of the lesson, proved in order, and practice inside it deepens from its first items to its hardest corners.

## Sub lesson 1 — The five main faiths
Pass mark: the learner can do this part from memory — Religion's root in wonder at nature; 4,300 religions, five holding three-quarters of humanity; each faith's beginning and core teaching, told evenly. Practice deepens with more items, then exact dates, exact names, and the cause-and-effect links between them.
