# World religions — the five main faiths — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Judaism began with the ancient Israelites before 1500 BC.
**Answer: True** — Keeping Moses' teaching, in Israel and worldwide.
**2. (Sub lesson 1)** Hinduism teaches one god only, with no others named.
**Answer: False** — As printed, it has many gods — Vishnu the preserver, Shiva creator-destroyer.
**3. (Sub lesson 3)** Believers in Islam are called Muslims, and its holy book is the Quran.
**Answer: True** — Core guide vocabulary (teacher guide — evidence).
