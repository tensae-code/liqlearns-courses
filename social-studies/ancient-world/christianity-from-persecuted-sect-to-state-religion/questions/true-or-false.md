# Christianity — from persecuted sect to state religion — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Rome welcomed Christianity from the start.
**Answer: False** — It first saw a threat and persecuted.

**2. (Sub lesson 2)** Toleration came before official-religion status.
**Answer: True** — Milan 313 first; official status under Theodosius later.

**3. (Sub lesson 2)** After becoming the state religion, Christianity spread across the world.
**Answer: True** — The book's closing line for the section.
