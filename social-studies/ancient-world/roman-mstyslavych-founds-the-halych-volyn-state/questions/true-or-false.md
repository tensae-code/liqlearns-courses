# Roman Mstyslavych founds the Halych-Volyn state — true or false

Say True or False, and why.

**1. (Sub lesson 1)** The united Volyn-Halych state was the strongest state in Rus.
**Answer: True — The book calls it the strongest state in Rus.**

**2. (Sub lesson 2)** Roman's state passed smoothly to adult sons.
**Answer: False — He left infant sons, grasping boyars and foreign kings circling.**
