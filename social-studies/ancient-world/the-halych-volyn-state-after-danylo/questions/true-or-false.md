# The Halych-Volyn state after Danylo — true or false

Say True or False, and why.

**1. (Sub lesson 1)** Lev held Galicia against all comers.
**Answer: True — The book tells that Lev holds Galicia against all comers.**

**2. (Sub lesson 2)** The Halych-Volyn state still exists unchanged today.
**Answer: False — By 1340 its ruling line died out and Poland and Lithuania divided the inheritance.**
