# The Pyu city-states of ancient Myanmar — true or false

Say True or False, and why.

**1. (Sub lesson 1)** Myanmar's first cities came before any Myanmar empire.
**Answer: True — the Pyu city-states flourished for centuries before any Myanmar empire exists.**

**2. (Sub lesson 2)** Beikthano is remembered as the Vishnu city.
**Answer: True — the placements name Beikthano as the Vishnu city.**
