# Rus-Ukraine — a state is born — true or false

Say True or False, and why.

**1. (Sub lesson 1)** Rus began as a fully united state with no tribal stage before it.
**Answer: False — A loose tribal world becomes a state when the tribes are united under one prince.**

**2. (Sub lesson 2)** The book teaches this state as Ukraine's own first state, Rus-Ukraine.
**Answer: True — The medieval Rus state is taught as Rus-Ukraine, not as a neighbour's prehistory.**
