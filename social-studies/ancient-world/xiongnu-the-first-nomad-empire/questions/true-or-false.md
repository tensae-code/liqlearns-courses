# The Xiongnu — the first nomad empire — true or false

Say True or False, and why.

**1. (Sub lesson 1)** in 209 BC Modu unites the steppe tribes into the Xiongnu empire, the first great nomad state, which treats and wars with Han China as an equal.
**Answer: True** — the book tells this in Ch. 5.1 The Xiongnu empire, the nomads' first state

**2. (Sub lesson 1)** This part of *mn-g6h Түүх VI (History VI)* is about a different part of this story, told in another lesson of this expansion.
**Answer: False** — it is about Ch. 5.1 The Xiongnu empire, the nomads' first state

**3. (Sub lesson 2)** Modu's Xiongnu (209 BC) organises the steppe into a decimal military state, builds towns and crafts, and faces Han China as an equal empire.
**Answer: True** — the book tells this in Ch. 2.1 The Xiongnu empire

**4. (Sub lesson 2)** This part of *mn-g10mh Монголын түүх X (History of Mongolia X)* is about a different part of this story, told in another lesson of this expansion.
**Answer: False** — it is about Ch. 2.1 The Xiongnu empire
