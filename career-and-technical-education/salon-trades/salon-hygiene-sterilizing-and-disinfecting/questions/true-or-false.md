# Salon hygiene — sterilizing and disinfecting tools — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1) Disposable gloves and disposable hand towels are part of the kit.**
**Answer: True** — both are listed.

**2. (Sub lesson 1) Sterilization and disinfection are the same strength.**
**Answer: False** — sterilization is the strongest form; disinfection kills most, not all.

**3. (Sub lesson 2) Tools need the routine only at the end of the day.**
**Answer: False** — between every client.

**4. (Sub lesson 2) A barbicide-type solution is named as common salon practice for
disinfection.**
**Answer: True** — the book names it as common practice.
