# Hands-on — Women's hair — the basic styling techniques

The lesson with your hands, not only your eyes. Real trade practice, done safely and exactly as
the book teaches it.

## Roller set practice

On a practice head, run the definition: (model) wash, lotion, set on rollers, dry gently, then
shape a soft curl style — naming each link as you do it.

## Style spotting

Photograph or sketch (with permission) local styles for a week and file each under its
technique family; present the collection to your group.
