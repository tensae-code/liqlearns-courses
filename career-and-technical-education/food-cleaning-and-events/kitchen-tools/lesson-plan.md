# Lesson plan — Kitchen Tools — Names, Jobs, and the Essential Kit

**Course:** Career and Technical Education · **Title:** Food, Cleaning and Events · **Lesson:** Kitchen Tools — Names, Jobs, and the Essential Kit
**Place in the curriculum:** Unit 8 — Food, Cleaning and Events (CURRICULUM.md).
**The one thing this lesson teaches:** the essential kitchen kit of the book's Table 4.1 — knives, boards, strainers, grinder, tongs, coffee maker, blender, mixer, electric grill and oven — and the job each tool does.
**This lesson's own level:** it stands on Serving Food — Counter Service and Table Service: the learner knows the service; now the tools the food is made with.

## Sub lessons
1. **What a kitchen utensil is** — small hand-held tools; general-purpose and specialised
2. **The Table 4.1 kit** — the eleven entries and their jobs

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Serving Food — Counter Service and Table Service. Recommended, never forced.

## What the learner can do when it ends
1. Define a kitchen utensil, general-purpose vs specialised.
2. Match the kit of Table 4.1 to jobs.
3. Sort tools electrical vs non-electrical (the guide's assessment pattern).

## What you need
Paper and a pencil; the name-and-match drill needs no real knives — drawings or named cards only.

## The run of the lesson (in order)
1. **Do it first** — the learner names every tool in one imagined kitchen before the table is shown (lesson/lesson.md).
2. **The explanation** — utensils defined (general vs specialised), then the Table 4.1 kit tool by tool (lesson/lesson.md).
   - ADD IMAGE [Picture 11963]: a picture of the eleven essential kitchen tools labelled on a counter — knives, cutting board, pasta strainer, spice grinder, mesh strainer, tongs, coffee maker, blender, mixer, electric grill, oven — the student cover the labels and give each tool's job from its shape.
3. **Say it to your companion** — the kit with jobs, from memory — eleven entries (lesson/lesson.md).
   - ADD VIDEO: the script in video-script.md, filmed — the lesson in the super-simple voice (made later, when videos are made).
4. **Questions** — from questions/: served at the learner's level and teaching-mix (levels.md).

## If the learner is stuck
- Learns names without jobs → in a kitchen you reach for the JOB. Drill name→job and job→name both ways ('velvet stocks?' — mesh strainer).
- Treats the kit as universal → the book says the kit varies with cooking style; Table 4.1 is the essential list, not the only list.
