# Kitchen Tools — Names, Jobs, and the Essential Kit — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Every kitchen in the world uses exactly the same kit.
**Answer: False** — the kit varies with cooking style — the book teaches an essential list.

**2. (Sub lesson 2)** The mixer works dough and batter without the labour of hand work.
**Answer: True** — that is the book's line for the mixer.
