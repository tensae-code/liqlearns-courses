# Ethiopian Foods — Shiro, Atkilt, Gonfo, Kitfo — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Shiro ranges from the soupy shiro wot to thicker kinds.
**Answer: True** — the book gives the range explicitly.

**2. (Sub lesson 2)** Kitfo is served with injera and/or kocho.
**Answer: True** — the book names both servings — kocho is the thick enset flatbread.
