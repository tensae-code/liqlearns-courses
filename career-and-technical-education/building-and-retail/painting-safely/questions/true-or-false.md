# Painting Safely — Warnings, Masks, and the Lead Rule — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Signs alone can serve as the warning if no fence is available.
**Answer: True** — the book's rule: set up a fence or barrier, OR use signs.

**2. (Sub lesson 2)** Old paint of unknown make-up can be sanded if you wear a strong mask.
**Answer: False** — the rule is absolute: NEVER sand materials containing lead — unknown old paint is not sanded.
