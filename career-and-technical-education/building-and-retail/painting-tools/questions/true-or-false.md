# Painting Tools — Applicators and Abrasives — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** The hammer is in the painting kit for punching and pushing nails in before painting.
**Answer: True** — a nail standing proud would ruin the finish, so it is dealt with first.

**2. (Sub lesson 2)** Turpentine and kerosene clean the painting tools afterwards.
**Answer: True** — the book names both as the cleaning fluids.
