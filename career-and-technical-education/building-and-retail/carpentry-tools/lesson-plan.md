# Lesson plan — Carpentry Tools — Hand Tools and Power Tools

**Course:** Career and Technical Education · **Title:** Building and Retail · **Lesson:** Carpentry Tools — Hand Tools and Power Tools
**Place in the curriculum:** Unit 7 — Building and Retail (CURRICULUM.md).
**The one thing this lesson teaches:** the two families of carpentry tools — hand tools, powered by hand, and power tools, needing an electric source — and how to sort a real kit between them.
**This lesson's own level:** it stands on Carpentry — the Trade and Its Basic Skills: the learner knows the skills; now the tools that perform them.

## Sub lessons
1. **Hand tools — power from the hand** — what a hand tool is and the family the book pictures
2. **Power tools — power from a source** — what a power tool is, and sorting the kit

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Carpentry — the Trade and Its Basic Skills. Recommended, never forced.

## What the learner can do when it ends
1. Define a hand tool and a power tool by their power source.
2. Sort common carpentry tools into the two families.
3. Say why the sort matters: the power source decides the safety habits.

## What you need
Paper and a pencil; the sorting drill can use drawings, or real tools pointed at (not handled) with an adult present.

## If the learner is stuck
- Sorts by job instead of power → a saw sits in BOTH families. Re-ask the one question: where does the power come from?
- Thinks power tools are simply 'better' → the book sorts, it does not rank: the families differ in power source, and each has its work.
