# Carpentry Tools — Hand Tools and Power Tools — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A hand tool is —
a) a small electric tool  b) any tool made of wood  c) a tool powered by hand, not a motor
**Answer: c) a tool powered by hand, not a motor.**

**2. (Sub lesson 1)** The book's pictured hand family is —
a) saws, a hammer, a plane and chisels  b) drills and sanders  c) only chisels
**Answer: a) saws, a hammer, a plane and chisels.**

**3. (Sub lesson 1)** Hand tools are used for —
a) measuring walls  b) cutting and modifying wooden materials  c) mixing concrete
**Answer: b) cutting and modifying wooden materials.**

**4. (Sub lesson 2)** Power tools are —
a) machine tools needing an electric source  b) tools used by powerful workers  c) any tool with a handle
**Answer: a) machine tools needing an electric source.**

**5. (Sub lesson 2)** The book's pictured power family is —
a) hammers and planes  b) chisels and hand saws  c) drills, sanders and powered saws
**Answer: c) drills, sanders and powered saws.**

**6. (Sub lesson 2)** The one sorting question is —
a) where does the power come from?  b) how heavy is it?  c) what colour is it?
**Answer: a) where does the power come from?.**
