# Carpentry Tools — Hand Tools and Power Tools — short answer

Answer in one or two sentences.

**1. (Sub lesson 1)** A saw with no cord and a saw with a cord: which family is each in, and why?
**Answer:** The cordless-in-the-hand saw is a hand tool and the corded saw a power tool — the family is decided by the power source, not by the job.

**2. (Sub lesson 2)** Sort this kit: hand saw, drill, plane, sander. Give each family's rule as you sort.
**Answer:** Hand tools (powered by hand): hand saw, plane. Power tools (needing an electric source): drill, sander.
