# Carpentry Tools — Hand Tools and Power Tools — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Stop your arm, and a hand tool stops.
**Answer: True** — the hand supplies every stroke — that is what hand-powered means.

**2. (Sub lesson 2)** A tool's family is decided by the job it does.
**Answer: False** — the power source decides — the same job, like sawing, exists in both families.
