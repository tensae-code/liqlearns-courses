# Bricks and Blocks — Concrete Block, Concrete Brick, Clay Brick — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Mineral colours can be added to a concrete brick to make it resemble a clay brick.
**Answer: True** — the book says so — colour alone does not tell the family.

**2. (Sub lesson 2)** A concrete block and a clay brick are the same thing.
**Answer: False** — the block is a hollow concrete unit; the clay brick belongs to the clay family.
