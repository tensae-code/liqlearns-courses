# Brickwork Tools — Float, Trowel, Wheelbarrow, Tape, Shovel — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** The book's Table 3.1 prints the trowel's name as 'Towel' — a misprint.
**Answer: True** — the description in the table is a trowel's; the name is misprinted, and the lesson teaches the true name.

**2. (Sub lesson 2)** The shovel moves spoonfuls and the trowel moves loads.
**Answer: False** — it is the other way round: the trowel moves small amounts; the shovel moves bulk loads.
