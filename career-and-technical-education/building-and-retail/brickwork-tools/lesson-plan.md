# Lesson plan — Brickwork Tools — Float, Trowel, Wheelbarrow, Tape, Shovel

**Course:** Career and Technical Education · **Title:** Building and Retail · **Lesson:** Brickwork Tools — Float, Trowel, Wheelbarrow, Tape, Shovel
**Place in the curriculum:** Unit 7 — Building and Retail (CURRICULUM.md).
**The one thing this lesson teaches:** the five tools of brick and block work (the book's Table 3.1) — concrete float, trowel, wheelbarrow, tape measure and shovel — and the job each one does.
**This lesson's own level:** it stands on Making Concrete — Materials and the 1:2:3 Mix: the learner knows the material; now the tools that work it.

## What the learner can do when it ends
1. Name the five tools of Table 3.1.
2. Match each tool to its job.
3. Say which tool the book's table misnames, and its true name.

## What you need
Paper and a pencil; the hands-on uses drawings or real tools shown by an adult — learners do not carry loads in a wheelbarrow for practice.

## If the learner is stuck
- Confuses float and trowel → the float is flat and wide for surfaces; the trowel is small and pointed for little amounts. Size tells the story.
- Calls the trowel a towel → the book's misprint is named in the lesson on purpose: the description (digging, applying, smoothing mortar) is a trowel's, whatever the table's spelling says.
