# Hands-on — Brickwork Tools — Float, Trowel, Wheelbarrow, Tape, Shovel

The lesson with your hands, not only your eyes — real trade practice, done safely.

## Name-and-match drill

Write the five tool names on five slips and the five jobs on five more. Shuffle and match. Then swap: a partner reads a job; you name the tool before looking.

## Measure like a builder

With a tape measure (or a marked string), measure one real block or brick: length, width, height. Write the three numbers. Builders measure before they build — feel why.
