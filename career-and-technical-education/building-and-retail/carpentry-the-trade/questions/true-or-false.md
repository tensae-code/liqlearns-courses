# Carpentry — the Trade and Its Basic Skills — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** A carpenter only makes things in a workshop and never fits them into a building.
**Answer: False** — installing is one of the trade's three core verbs — the carpenter fits work into the building itself.

**2. (Sub lesson 2)** Fitting trim, doors, stairs and hardware is part of the carpenter's basic skills.
**Answer: True** — the book lists fitting and installing trim, doors, stairs and hardware in the set.
