# Teamwork — Working as Part of a Team — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Accountability — milestones reached and all members participating — increases commitment.
**Answer: True** — the four characteristics feed each other, as the book sets them out.

**2. (Sub lesson 2)** Teamwork skills have nothing to do with moving forward in a career.
**Answer: False** — building them gives more chances to move forward in a career.
