# The Cover Letter — Persuading Them to Read Your CV — short answer

Answer in a sentence or two.

**1. (Sub lesson 1)** Why does the letter name the advertised position first?
**Answer:** So the reader knows at once which job this application answers — the example names the position as advertised on a website or in a newspaper.

**2. (Sub lesson 2)** Name the four moves in order.
**Answer:** Name the position; introduce the writer; state strong interest and the results she can produce; close politely (kind regards).
