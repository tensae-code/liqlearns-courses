# Sewing — hand needle and machine — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Sewing stitches fabrics together with —
a) glue and paper  b) paint and brush  c) thread and needle
**Answer: c) thread and needle.**

**2. (Sub lesson 1)** Sewing can be done —
a) only in a factory  b) by hand or by machine  c) only by machine
**Answer: b) by hand or by machine.**

**3. (Sub lesson 1)** Which of these is a sewn household furnishing?
a) curtains  b) a clay pot  c) a wooden chair
**Answer: a) curtains.**

**4. (Sub lesson 2)** Before modern machines, Ethiopian sewing was —
a) not done at all  b) done only by machine  c) all by hand
**Answer: c) all by hand.**

**5. (Sub lesson 2)** Across sewing machine models, what stays the same?
a) the colour  b) the basic operation  c) the price
**Answer: b) the basic operation.**
