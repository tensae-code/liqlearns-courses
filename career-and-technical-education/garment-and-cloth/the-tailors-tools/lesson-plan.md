# Lesson plan — The tailor's tools — measuring, marking, cutting, pressing

**Course:** Career and Technical Education · **Title:** Garment and Cloth · **Lesson:** The tailor's tools — measuring, marking, cutting, pressing
**Place in the curriculum:** Unit 5 — Garment and Cloth (CURRICULUM.md).
**The one thing this lesson teaches:** the tailor's hand tools beside the machine — for measuring, marking, cutting, holding, pressing and threading.

## What the learner can do when it ends
1. Answer: A measuring tape shows centimetres on one side, inches on the other.
2. Answer: Tailor's chalk is used for removable fabric marking.
3. Answer: If tailor's chalk is missing, the book allows ordinary teaching chalk as a substitute.
4. Answer: Needle size follows fabric weight — lighter fabric, smaller needle.
5. Answer: For knits, the better thread is polyester.
