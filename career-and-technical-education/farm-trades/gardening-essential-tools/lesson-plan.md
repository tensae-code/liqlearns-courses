# Lesson plan — Gardening — the essential tools

**Course:** Career and Technical Education · **Title:** Farm Trades · **Lesson:** Gardening —
the essential tools
**Place in the curriculum:** Unit 3 — Farm Trades (CURRICULUM.md).
**The one thing this lesson teaches:** the gardener's pictured tool set — gloves, pruning
shears, loppers, garden fork, hand trowel, spade, rake, hoe and the traditional hand hoe — and
which job each tool does.
**This lesson's own level:** it stands on the two gardening lessons before it — the learner
knows the garden; now the tools that work it.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below,
the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written
as **"a picture of …" in words, plus one little line saying what the student does with it**.
The words carry the picture while the course is built and while the AI learns from the books;
on the website the real add-on is dropped into that slot and the little explanation stays as
the student's guide. Images follow the picture rule (a real photograph, or real art, with its
source). GIFs come first where a thing must be shown moving — a GIF here is 2 seconds.

## Before this lesson
- Recommended first: Gardening — growing plants as a business. Recommended, never forced.
- The other Farm Trades lessons stand next door in this same title.

## What the learner can do when it ends
1. Name the nine tools of Table 3.1.
2. Match each tool to its job.
3. Name the traditional tools of rural gardens: the hoe for digging and the sickle for clearing
land.
4. List your own locality's traditional tools with each one's use.

## What you need
Paper and a pencil. Any real garden tools that can be shown safely help.

## If the learner is stuck
- Mixes shears and loppers → both cut, but loppers are the bigger, stronger cutter for thicker
growth.
- Cannot name local tools → send them to ask a real gardener; that asking is the lesson's own
activity.
