# Gardening — the essential tools — short answer

Answer in one or two sentences.

**1. (Sub lesson 1) Name five tools from Table 3.1.**
**Answer:** Any five of: gloves, pruning shears (secateurs), loppers, garden fork, hand trowel,
spade, rake, hoe, traditional hand hoe.

**2. (Sub lesson 2) Which two traditional tools does the book name, and what is each for?**
**Answer:** The hoe — for digging; the sickle — for clearing land.

**3. (Sub lesson 2) Name one traditional tool from your own locality and its use.**
**Answer:** The learner's own local tool with its use (answers vary by locality).
