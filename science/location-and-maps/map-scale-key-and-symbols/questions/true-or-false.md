# Map Scale, Key and Symbols — true or false

Say whether each sentence is true or false, and why.

**1. (Sub lesson 1) A map can be read fully without its key.**
**Answer: False** — The key explains the colours and symbols; without it the signs cannot be read.

**2. (Sub lesson 2) Scale compares the map's size to the mapmaker's desk.**
**Answer: False** — Scale compares map distance with ground distance.

**3. (Sub lesson 3) Brown on a map means a forest.**
**Answer: False** — Brown is deserts, historic sites and contour lines; green is forests.

**4. (Sub lesson 4) Every symbol on every map is a mapmaker's own invention.**
**Answer: False** — Some symbols are conventional, shared by all maps; some are the mapmaker's own.

**5. (Sub lesson 5) An old map is useless and should be thrown away.**
**Answer: False** — Read in its own time, an old map is true evidence of its year — the mistake is reading it as today.
