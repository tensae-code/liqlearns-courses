# Absolute Location — A Place's Exact Position — true or false

Say whether each sentence is true or false, and why.

**1. (Sub lesson 1) Absolute location does not change when a neighbouring building changes.**
**Answer: True** — It is independent of what is around the place.

**2. (Sub lesson 2) South Gondar's example uses degrees and minutes, north and east.**
**Answer: True** — 11°20′–12°30′ N and 37°30′–38°40′ E.
