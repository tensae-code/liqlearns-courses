# The National Grid and Grid References — true or false

Say whether each sentence is true or false, and why.

**1. (Sub lesson 1) Northings are the grid's vertical lines.**
**Answer: False** — Northings are horizontal; eastings are vertical.

**2. (Sub lesson 2) You read a grid reference northings first, then eastings.**
**Answer: False** — Eastings first — along the corridor — then northings, up the stairs.
