# Kebele, Woreda and Zone — true or false

Say whether each sentence is true or false, and why.

**1. (Sub lesson 1) The ladder goes kebele, then woreda, then zone.**
**Answer: True** — Each level groups the level below it.

**2. (Sub lesson 2) Each grade's map is wider than the grade before.**
**Answer: True** — G1 kebele, G2 woreda, G3 zone — the scale grows.
