# How materials behave: stretchy, breakable, shapable — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1) We should test if a glass breaks by dropping it.**
**Answer: False**

**2. (Sub lesson 2) A balloon is made of a stretchy material.**
**Answer: True**

**3. (Sub lesson 3) Copper can be drawn into thin wire.**
**Answer: True**
