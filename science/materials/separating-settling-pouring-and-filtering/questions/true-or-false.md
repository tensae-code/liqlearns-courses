# Separating mixtures — settling, pouring off and filtering — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Washing lentils uses settling and pouring off.
**Answer: True** — the kitchen way is decantation.

**2. (Sub lesson 2)** Filtration can separate a dissolved solid from water.
**Answer: False** — dissolved particles pass through; filtration catches insoluble ones.
