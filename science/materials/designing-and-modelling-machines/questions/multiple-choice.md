# Designing and modelling machines — multiple choice

Pick the one right answer.

**1.** What does this lesson teach first?
a) Making a model  b) Design, model, improve  c) None of the parts in this lesson  d) Machine designs
**Answer: d) Machine designs**

**2.** Which part of this lesson is about a machine begins as a design?
a) Machine designs  b) Making a model  c) Design, model, improve
**Answer: a) Machine designs**

**3.** Which part of this lesson is about the model tests the design?
a) Machine designs  b) Making a model  c) Design, model, improve
**Answer: b) Making a model**

**4.** Which part of this lesson is about design, model, improve?
a) Machine designs  b) Making a model  c) Design, model, improve
**Answer: c) Design, model, improve**
