# Lesson plan — Equations — balancing by inspection

**Course:** Science · **Title:** Materials · **Lesson:** Equations — balancing by inspection
**Place in the curriculum:** Unit 3 — Elements, Compounds and Chemical Reactions (CURRICULUM.md).
**The one thing this lesson teaches:** balancing by inspection: adjust coefficients — never subscripts — by trial until every element counts equal on both sides of the equation

## What the learner can do when it ends
1. State the two balancing rules: coefficients only; count every element on both sides.
2. Balance K + O₂ → K₂O to 4K + O₂ → 2K₂O by inspection, stage by stage.
3. Balance carbon burning and magnesium in acid with the same method.
4. Check any finished equation with a full atom tally.

## If the learner is stuck
Changes a subscript to force a balance → forbidden: that changes the substance itself. Balance with coefficients in front. Stops when one element matches → recheck ALL elements after every change; fixing one often unfixes another.
