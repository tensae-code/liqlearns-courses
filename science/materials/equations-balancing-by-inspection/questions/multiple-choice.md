# Equations — balancing by inspection — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Balancing is done by changing —
a) subscripts  b) coefficients  c) the elements
**Answer: b) coefficients**

**2. (Sub lesson 1)** The balanced equation for potassium + oxygen is —
a) K + O₂ → K₂O  b) 2K + O₂ → K₂O  c) 4K + O₂ → 2K₂O
**Answer: c) 4K + O₂ → 2K₂O** — — K: 4 = 4, O: 2 = 2.

**3. (Sub lesson 1)** Carbon burning in oxygen, C + O₂ → CO₂, is —
a) already balanced  b) balanced only as 2C + O₂ → 2CO₂  c) unbalanceable
**Answer: a) already balanced** — — C: 1 = 1, O: 2 = 2.

**4. (Sub lesson 2)** Why may subscripts never be changed?
a) they are printed in ink  b) changing one changes the substance  c) they are always correct already
**Answer: b) changing one changes the substance**

**5. (Sub lesson 2)** The inspection method is also called —
a) the LCM method  b) trial and error  c) the bracket method
**Answer: b) trial and error**
