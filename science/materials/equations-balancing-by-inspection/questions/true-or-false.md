# Equations — balancing by inspection — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** An equation must show equal atom counts of each element on both sides.
**Answer: True**

**2. (Sub lesson 1)** Changing H₂O to H₂O₂ is a way of balancing an equation.
**Answer: False**

**3. (Sub lesson 2)** 4K + O₂ → 2K₂O has 4 potassium atoms on each side.
**Answer: True**

**4. (Sub lesson 2)** Inspection means guessing once and never checking.
**Answer: False**
