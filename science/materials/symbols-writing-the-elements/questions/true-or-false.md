# Symbols — writing the elements — true or false

Say whether each statement is true or false.

**1.** The symbol for sodium is Na, from the Latin natrium.
**Answer: True**

**2.** A symbol's second letter is written as a capital.
**Answer: False**

**3.** Gold's symbol Au comes from the Latin aurum.
**Answer: True**

**4.** Every element's symbol matches its English name.
**Answer: False**
