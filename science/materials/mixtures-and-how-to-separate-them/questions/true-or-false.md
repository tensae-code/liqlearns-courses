# Mixtures and how to separate them — true or false

Say if each one is true or false.

**1. A component keeps its own properties inside a mixture.**
**Answer: True**

**2. A mixture has a fixed composition.**
**Answer: False**

**3. Distillation uses evaporation and then condensation.**
**Answer: True**

**4.** A mixture has a fixed ratio of its parts.
**Answer: False** — no fixed ratio — that is a compound's mark.
