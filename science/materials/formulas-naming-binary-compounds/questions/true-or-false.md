# Formulas — naming binary compounds — true or false

Say whether each statement is true or false.

**1.** In a binary name, the metal is named first.
**Answer: True**

**2.** Greek prefixes are used to name compounds of a metal and a non-metal.
**Answer: False**

**3.** Water and ammonia are common names that hide composition.
**Answer: True**

**4.** SO₃ is sulfur trioxide.
**Answer: True**
