# Oxides — basic, acidic and in-between — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** SO₂ + H₂O → H₂SO₃ is a balanced equation.
**Answer: True**

**2. (Sub lesson 1)** All oxides react with water.
**Answer: False**

**3. (Sub lesson 2)** 2Mg + O₂ → 2MgO has two magnesium atoms on each side.
**Answer: True**

**4. (Sub lesson 2)** MgO in water turns the solution acidic.
**Answer: False**
