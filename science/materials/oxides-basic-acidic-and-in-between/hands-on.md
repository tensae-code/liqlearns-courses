# Hands-on — Oxides — basic, acidic and in-between

The lesson with your hands, not only your eyes.

## Oxide sorting table
Copy a four-column table (basic / acidic / amphoteric / neutral). Place MgO, CO₂, SO₂, CaO, Al₂O₃, ZnO, CO, H₂O, NO₂. Check each against the metal/non-metal rule and mark the exceptions.

## Equation drill
Write and tally: magnesium burning; sulphur burning; CaO + water; CO₂ + water. Count every atom on both sides of each.
