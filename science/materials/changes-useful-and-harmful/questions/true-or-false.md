# Changes — useful and harmful changes in daily life — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Chopping wood is a chemical change.
**Answer: False** — physical — the wood is still wood.

**2. (Sub lesson 2)** Freezing preserves food.
**Answer: True** — a useful physical change.

**3. (Sub lesson 3)** Food decay is a useful change.
**Answer: False** — it is harmful.
