# Formulas — valence, the combining power — true or false

Say whether each statement is true or false.

**1.** Hydrogen's valence is 1.
**Answer: True**

**2.** An element's valence can never change.
**Answer: False**

**3.** Aluminium's valence is 3.
**Answer: True**

**4.** In NaCl, chlorine's valence is 2.
**Answer: False**
