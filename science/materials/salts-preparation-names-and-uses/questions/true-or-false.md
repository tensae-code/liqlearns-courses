# Salts — preparation, names and uses — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** NaCl is a binary salt.
**Answer: True**

**2. (Sub lesson 1)** Acid + metal is the same reaction as neutralisation.
**Answer: False**

**3. (Sub lesson 2)** Chloride, bromide and iodide are salts of oxyacids.
**Answer: False**

**4. (Sub lesson 2)** Vinegar fizzing on a rock shows the rock is a carbonate.
**Answer: True**
