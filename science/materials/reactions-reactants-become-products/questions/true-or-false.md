# Reactions — reactants become products — true or false

Say whether each statement is true or false.

**1.** Products are new substances with different properties from the reactants.
**Answer: True**

**2.** In an equation the products are written on the left.
**Answer: False**

**3.** Making ergo yoghurt is a chemical reaction.
**Answer: True**

**4.** 2H₂ + O₂ → 2H₂O has equal atom counts on both sides.
**Answer: True**
