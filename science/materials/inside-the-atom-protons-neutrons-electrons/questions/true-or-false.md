# Inside the atom — protons, neutrons, electrons — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** The electron's charge is −1 and its mass is about 0 amu.
**Answer: True**

**2. (Sub lesson 1)** The neutron carries a charge of +1.
**Answer: False**

**3. (Sub lesson 2)** In a neutral atom, the number of electrons equals the number of protons.
**Answer: True**

**4. (Sub lesson 3)** An ordinary school microscope can resolve a single atom.
**Answer: False**
