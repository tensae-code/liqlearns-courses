# Neutralisation — cancelling acid with base — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** After neutralisation the mixture tests neutral when the amounts are right.
**Answer: True**

**2. (Sub lesson 1)** NaOH + HCl → NaCl + 2H₂O is balanced.
**Answer: False**

**3. (Sub lesson 2)** Wastewater treatment uses neutralisation.
**Answer: True**

**4. (Sub lesson 2)** Liming makes a soil more acidic.
**Answer: False**
