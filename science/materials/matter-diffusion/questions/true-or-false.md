# Matter — diffusion — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Diffusion ends when particles are evenly spread.
**Answer: True**

**2. (Sub lesson 2)** Two solids pressed together diffuse quickly.
**Answer: False** — essentially no diffusion in solids.

**3. (Sub lesson 1)** Stirring is required for ink to colour water.
**Answer: False** — diffusion does it unstirred, only slower than stirring.
