# Lesson plan — Equations — balancing by LCM, and modelling with circles

**Course:** Science · **Title:** Materials · **Lesson:** Equations — balancing by LCM, and modelling with circles
**Place in the curriculum:** Unit 3 — Elements, Compounds and Chemical Reactions (CURRICULUM.md).
**The one thing this lesson teaches:** the LCM method balances by least common multiple of the valence totals, and coloured-circle models make the same balance visible — coefficients change, subscripts never do
**This lesson's own level:** it stands on Equations — balancing by inspection (same unit). The Chemistry title's balancing lesson treats the LCM method at secondary depth; this is the first-depth doing lesson, new here, cross-referenced not copied.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved (the gate: README, "Units, Lessons and Sub Lessons (ruled 2026-11-08)"):

1. **The LCM method** — Total each element's valence numbers across the skeleton equation, take their **least common multiple**, then divide the LCM back to win the coefficients.
2. **Modelling balance with circles** — Coloured circles turn the counting into something your hands can do.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: the earlier Unit 3 lessons in order — symbols, then formulas, then reactions. Recommended, never forced; this lesson stands alone for a learner landing on it directly.

## What the learner can do when it ends
1. Run the LCM method on Al + O₂ → Al₂O₃ and reach 4Al + 3O₂ → 2Al₂O₃.
2. Verify the result with a full atom tally (Al 4 = 4, O 6 = 6).
3. Build 2H₂ + O₂ → 2H₂O from coloured circles, changing only how many groups there are.
4. State the modelling rule: coefficients change, subscripts never do.

## What you need
Paper, a pencil, and coloured circles — bottle tops, stones or paper discs in two colours.

## If the learner is stuck
Reaches for a subscript when the circles do not match → add another whole group (a coefficient), never split a molecule's insides. Forgets the final tally → the LCM method ends with a check, not with the arithmetic.
