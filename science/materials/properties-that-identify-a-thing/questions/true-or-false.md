# Properties that identify a thing — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1) Measuring a pencil's length changes it into a new thing.**
**Answer: False**

**2. (Sub lesson 1) Colour is a property.**
**Answer: True**

**3. (Sub lesson 2) Burning wood to ash shows a chemical property.**
**Answer: True**
