# Properties that identify a thing — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) A property of a material is —**
a) what it is used for  b) a mark by which it is known from others  c) its price
**Answer: b) a mark by which it is known from others**

**2. (Sub lesson 1) The book's worked example lists the properties of —**
a) a stone  b) a pencil  c) a cup
**Answer: b) a pencil**

**3. (Sub lesson 1) Which of these is a property?**
a) for writing  b) hardness  c) cheap
**Answer: b) hardness**

**4. (Sub lesson 2) A chemical property is seen when —**
a) a thing is measured  b) a thing changes into a new thing  c) a thing is moved
**Answer: b) a thing changes into a new thing**
