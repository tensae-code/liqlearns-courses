# Formulas — writing binary compounds (criss-cross) — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A binary compound holds exactly two elements.
**Answer: True**

**2. (Sub lesson 1)** In a formula the non-metal is written first.
**Answer: False**

**3. (Sub lesson 2)** Valences with a common factor are simplified before crossing.
**Answer: True**

**4. (Sub lesson 2)** Ca₃N₂ balances because 3 × 2 = 2 × 3.
**Answer: True**
