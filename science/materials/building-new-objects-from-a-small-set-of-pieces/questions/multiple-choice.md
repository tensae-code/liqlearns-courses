# Building new objects from a small set of pieces — multiple choice

Pick the one right answer.

**1.** (Sub lesson 1) This sub lesson is mainly about…
a) Objects are made of a small set of pieces  b) A topic from a different lesson  c) Nothing in this lesson  d) Only the questions page

**2.** (Sub lesson 2) This sub lesson is mainly about…
a) Disassemble and reshape — a new object, a new function  b) A topic from a different lesson  c) Nothing in this lesson  d) Only the questions page

**3.** (Whole lesson) This lesson teaches one thing: building new objects from a small set of pieces. That is…
a) True, in the sub lessons' own order  b) False  c) Only in the video  d) Not in the book cited
**Answer: a) True, in the sub lessons' own order**

**4.** (Whole lesson) The book behind this lesson is…
