# Hydrocarbons — alkanes, alkenes, alkynes — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Alkenes contain one double bond.
**Answer: True**

**2. (Sub lesson 1)** Ethyne, C₂H₂, is an alkane.
**Answer: False**

**3. (Sub lesson 2)** There is no alkene with one carbon.
**Answer: True**

**4. (Sub lesson 2)** Hydrocarbons are used only as plastics, never as fuels.
**Answer: False**
