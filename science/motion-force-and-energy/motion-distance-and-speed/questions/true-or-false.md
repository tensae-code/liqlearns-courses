# Motion — distance and speed — true or false

Say true or false.

**6.** Distance counts only the straight line from start to finish.
**Answer: False** — distance counts the whole path actually travelled

**7.** A harder ball roll gives a greater average speed over the same ground.
**Answer: True** — more distance in less time

**8.** Average speed tells the speed at every single moment.
**Answer: False** — it smooths fast and slow parts into one number

**9.** In the ball practical, timing starts when the ball leaves the hand.
**Answer: True** — the run is timed from release to stop
