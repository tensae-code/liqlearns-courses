# Carpentry tools

## Do it first
Before you read: a carpenter is making a table. Which tools will pass through the carpenter's hands before the table stands? Name them, and say what each does. Then read on: this is Rwanda's way in — its Primary 5 book opens with the carpentry tools.

## Sub lesson 1 — Identifying the carpentry tools

The book begins with **identification of carpentry tools** — naming and recognising the tools of the wood worker, one by one, before any of them is picked up.

## Sub lesson 2 — Using and maintaining carpentry tools

Next come **usage and maintenance**: how each carpentry tool is used in the work, and how it is maintained — kept in good condition — so it stays true and lasts. A carpentry tool is learned whole: its name, its use, and its care.

## The key ideas

- **Identifying the carpentry tools** — identifying the tools.
- **Using and maintaining carpentry tools** — using and maintaining the tools.
