# Carpentry tools — short answer

Answer in a sentence or two.

**1.** What does the part "Identifying the carpentry tools" teach?
**Answer:** The book begins with **identification of carpentry tools** — naming and recognising the tools of the wood worker, one by one, before any of them is picked up.

**2.** What does the part "Using and maintaining carpentry tools" teach?
**Answer:** Next come **usage and maintenance**: how each carpentry tool is used in the work, and how it is maintained — kept in good condition — so it stays true and lasts.
