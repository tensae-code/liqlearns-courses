# Taking apart and reassembling simple tools — multiple choice

Pick the one right answer.

**1.** (Sub lesson 1) Taking a tool apart is done…
a) In any order, pieces thrown together  b) Piece by piece, in order  c) By breaking it  d) Only by adults in factories
**Answer: b) Piece by piece, in order**

**2.** (Sub lesson 1) Dismantling teaches…
a) How to buy tools  b) What each piece does and how the pieces make the tool work  c) How to grind faster  d) Nothing
**Answer: b) What each piece does and how the pieces make the tool work**

**3.** (Sub lesson 2) Reassembling proves understanding because…
a) The pieces are hidden  b) The tool must stand whole and work again  c) It takes longest  d) The tool becomes new
**Answer: b) The tool must stand whole and work again**

**4.** (Sub lesson 2) The Grade 4 book teaches this skill on…
a) Clocks  b) Grinding tools  c) Bicycles  d) Radios
**Answer: b) Grinding tools**
