# Blacksmith tools

## Do it first
Before you read: a blacksmith shapes hot metal into the tools everyone else uses. Which tools does the smith hold to do that shaping? Say the ones you can name. Then read on: this is Rwanda's way in — its Primary 6 book teaches the blacksmith tools by name and use.

## Sub lesson 1 — The blacksmith tools — names

The lesson begins with the **names** of the blacksmith tools. Rwanda's Primary 6 book names the smith's tools one by one, so the learner can recognise each tool of the forge on sight.

## Sub lesson 2 — What each blacksmith tool is used for

Names are taught together with **uses**: what each blacksmith tool does in the shaping of metal. A tool whose use you know is a tool you can choose, hold and respect.

## The key ideas

- **The blacksmith tools — names** — the names of the tools.
- **What each blacksmith tool is used for** — what each tool is used for.
