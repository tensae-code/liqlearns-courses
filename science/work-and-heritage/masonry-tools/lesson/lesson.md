# Masonry tools

## Do it first
Before you read: watch a wall being built in your mind. Which tools does the builder use, from the first stone to the smooth finished face? Name them. Then read on: this is Rwanda's way in — after the carpentry tools, its Primary 5 book teaches the masonry tools.

## Sub lesson 1 — The masonry tools

The lesson first gives **examples of masonry tools** — the tools of the builder named and recognised, so the learner can sort the builder's tools from every other trade's tools.

## Sub lesson 2 — Using and maintaining masonry tools

Then come **usage and maintenance**: how each masonry tool is used in building, and how it is maintained so it stays ready for the next wall. The builder's tools are learned whole — name, use and care together.

## The key ideas

- **The masonry tools** — examples of the tools.
- **Using and maintaining masonry tools** — using and maintaining the tools.
