# Masonry tools — short answer

Answer in a sentence or two.

**1.** What does the part "The masonry tools" teach?
**Answer:** The lesson first gives **examples of masonry tools** — the tools of the builder named and recognised, so the learner can sort the builder's tools from every other trade's tools.

**2.** What does the part "Using and maintaining masonry tools" teach?
**Answer:** Then come **usage and maintenance**: how each masonry tool is used in building, and how it is maintained so it stays ready for the next wall.
