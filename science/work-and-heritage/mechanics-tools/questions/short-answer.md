# Mechanics tools — short answer

Answer in a sentence or two.

**1.** What does the part "The mechanics tools — names" teach?
**Answer:** The unit opens with the **names** of the mechanics tools.

**2.** What does the part "What each mechanics tool is used for" teach?
**Answer:** Each name is taught with its **uses** — the work that tool does when something is fixed, tightened, loosened or taken apart.
