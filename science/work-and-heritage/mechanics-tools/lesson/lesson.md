# Mechanics tools

## Do it first
Before you read: a bicycle or a motorcycle stops working and goes to the mechanic. Which tools come out of the mechanic's box first? Name the ones you know. Then read on: this is Rwanda's way in — its Primary 6 book opens its tools unit with the mechanics tools.

## Sub lesson 1 — The mechanics tools — names

The unit opens with the **names** of the mechanics tools. Rwanda's Primary 6 book names the mechanic's tools one by one, so each tool in the box can be recognised and asked for by name.

## Sub lesson 2 — What each mechanics tool is used for

Each name is taught with its **uses** — the work that tool does when something is fixed, tightened, loosened or taken apart. Names and uses together are what make a tool known.

## The key ideas

- **The mechanics tools — names** — the names of the tools.
- **What each mechanics tool is used for** — what each tool is used for.
