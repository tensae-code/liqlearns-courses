# Ethiopia's Four Language Families — true or false

Say whether each sentence is true or false, and why.

**1. (Sub lesson 1) Some of Ethiopia's languages rank above others by family.**
**Answer: False** — All languages are equal — the families are kinships, not ranks.

**2. (Sub lesson 2) Wolaytigna is a Semitic language.**
**Answer: False** — Wolaytigna is Omotic, of the south.
