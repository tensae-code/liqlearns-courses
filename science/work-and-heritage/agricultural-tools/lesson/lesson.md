# Agricultural tools

## Do it first
Before you read: picture a farm near your home. Which tools does the farmer hold in their hands through a day's work? Name every one you can, and say what each one does. Then read on: this is Rwanda's way in — its Primary 4 Science and Elementary Technology book opens with agricultural tools, before anything else.

## Sub lesson 1 — Naming the agricultural tools

Agricultural work begins with knowing the tools themselves. Rwanda's Primary 4 book starts by **identification of agricultural tools** — learning to name and recognise each tool the farmer uses, tool by tool.

## Sub lesson 2 — What each agricultural tool is used for

Each named tool has its **uses**. The book teaches the uses of agricultural tools straight after their names, so a learner never holds a tool without knowing the work it is for.

## Sub lesson 3 — Choosing the right tool for the job

Naming and uses join into one skill: **choosing the right tool for the job**. The farmer who can name every tool and say what each is for picks the tool that fits the work in front of them — that choosing is the lesson's whole point.

## The key ideas

- **Naming the agricultural tools** — naming the tools.
- **What each agricultural tool is used for** — what each tool is used for.
- **Choosing the right tool for the job** — choosing the right tool.
