# Agricultural tools — multiple choice

Pick the one right answer.

**1.** What does this lesson teach first?
a) What each agricultural tool is used for  b) Choosing the right tool for the job  c) None of the parts in this lesson  d) Naming the agricultural tools
**Answer: d) Naming the agricultural tools**

**2.** Which part of this lesson is about naming the tools?
a) Choosing the right tool for the job  b) Naming the agricultural tools  c) What each agricultural tool is used for
**Answer: b) Naming the agricultural tools**

**3.** Which part of this lesson is about what each tool is used for?
a) What each agricultural tool is used for  b) Naming the agricultural tools  c) Choosing the right tool for the job
**Answer: a) What each agricultural tool is used for**

**4.** Which part of this lesson is about choosing the right tool?
a) Naming the agricultural tools  b) What each agricultural tool is used for  c) Choosing the right tool for the job
**Answer: c) Choosing the right tool for the job**
