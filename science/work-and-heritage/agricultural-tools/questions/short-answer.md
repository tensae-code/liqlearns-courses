# Agricultural tools — short answer

Answer in a sentence or two.

**1.** What does the part "Naming the agricultural tools" teach?
**Answer:** Agricultural work begins with knowing the tools themselves.

**2.** What does the part "What each agricultural tool is used for" teach?
**Answer:** Each named tool has its **uses**.

**3.** What does the part "Choosing the right tool for the job" teach?
**Answer:** Naming and uses join into one skill: **choosing the right tool for the job**.
