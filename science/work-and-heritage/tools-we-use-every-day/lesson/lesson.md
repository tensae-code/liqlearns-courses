# Tools we use every day

## Do it first
Before you read: think about this lesson's one thing — tools we use every day — the household, kitchen and garden tools, and how they help us, as Zimbabwe's guides teach them at every level. Say what you already know about it out loud. Then read on: this is Zimbabwe's way in — its PlusOne Science and Technology guides teach this topic as a unit of their own, returning to it across the grades named in this lesson's sources.

## Sub lesson 1 — Household tools and kitchen utensils

Zimbabwe's ECD guides open the topic with **household tools and kitchen utensils**: the everyday tools of the home, named first because they are the ones a young child sees used daily.

## Sub lesson 2 — Garden tools

Beside the home's tools, the guides teach **garden tools** — the second named set at ECD level, and the topic returns as everyday tools and implements in Grades 1–3 and as uses of tools and safety in Grade 5.

## Sub lesson 3 — Tools and how they help us

The topic's point is joined up in ECD A itself: **tools and how they help us**. Each tool is learned with the work it does for us, and in Grade 5 with the safety its use needs.

## The key ideas

- **Household tools and kitchen utensils** — the tools of the home and kitchen.
- **Garden tools** — the tools of the garden.
- **Tools and how they help us** — each tool learned with its work and its safe use.
