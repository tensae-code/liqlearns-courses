# Tools we use every day — short answer

Answer in a sentence or two.

**1.** What does the part "Household tools and kitchen utensils" teach?
**Answer:** Zimbabwe's ECD guides open the topic with **household tools and kitchen utensils**: the everyday tools of the home, named first because they are the ones a young child sees used daily.

**2.** What does the part "Garden tools" teach?
**Answer:** Beside the home's tools, the guides teach **garden tools** — the second named set at ECD level, and the topic returns as everyday tools and implements in Grades 1–3 and as uses of tools and safety in Grade 5.

**3.** What does the part "Tools and how they help us" teach?
**Answer:** The topic's point is joined up in ECD A itself: **tools and how they help us**.
