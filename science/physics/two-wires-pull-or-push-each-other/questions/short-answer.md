# Two wires pull or push each other — short answer

Answer in a few words, or with full working where numbers are given.

**1.** Two parallel wires carry current the same way. Attract or repel?
**Answer: Attract.**

**2.** One current is reversed. Now?
**Answer: They repel.**

**3.** Which earlier effect explains the push on each wire?
**Answer: The motor effect — a current in a field is pushed.**

**4.** What makes the field that pushes the second wire?
**Answer: The first wire's own current.**
