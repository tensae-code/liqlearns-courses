# Two wires pull or push each other — multiple choice

Pick the one right answer.

**1.** Two parallel wires carry current the same way. Attract or repel?
a) Attract.  b) They repel.  c) The motor effect — a current in a field is pushed.  d) The first wire's own current.
**Answer: a) Attract.**

**2.** One current is reversed. Now?
a) Attract.  b) They repel.  c) The motor effect — a current in a field is pushed.  d) The first wire's own current.
**Answer: b) They repel.**

**3.** Which earlier effect explains the push on each wire?
a) Attract.  b) They repel.  c) The motor effect — a current in a field is pushed.  d) The first wire's own current.
**Answer: c) The motor effect — a current in a field is pushed.**

**4.** What makes the field that pushes the second wire?
a) Attract.  b) They repel.  c) The motor effect — a current in a field is pushed.  d) The first wire's own current.
**Answer: d) The first wire's own current.**
