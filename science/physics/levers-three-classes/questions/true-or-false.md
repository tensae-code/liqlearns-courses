# Levers — three classes — true or false

Say if each one is true or false.

**1.** The lever's class is set by which of F, L, E sits in the middle.
**Answer: True**

**2.** First class: fulcrum middle (seesaw). Second: load middle (wheelbarrow). Third: effort middle.
**Answer: True**

**3.** In a second-class lever the effort sits in the middle.
**Answer: False**
