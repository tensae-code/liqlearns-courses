# Levers — three classes — multiple choice

Pick the one right answer.

**1.** A seesaw is which class?
a) First class — fulcrum in the middle.  b) VR = 1.2 ÷ 0.3 = 4.  c) Second class — load in the middle.  d) They trade force for speed/distance of the load.
**Answer: a) First class — fulcrum in the middle.**

**2.** Effort arm 1.2 m, load arm 0.3 m. VR?
a) First class — fulcrum in the middle.  b) VR = 1.2 ÷ 0.3 = 4.  c) Second class — load in the middle.  d) They trade force for speed/distance of the load.
**Answer: b) VR = 1.2 ÷ 0.3 = 4.**

**3.** A bottle opener is which class?
a) First class — fulcrum in the middle.  b) VR = 1.2 ÷ 0.3 = 4.  c) Second class — load in the middle.  d) They trade force for speed/distance of the load.
**Answer: c) Second class — load in the middle.**

**4.** Third-class levers trade what for what?
a) First class — fulcrum in the middle.  b) VR = 1.2 ÷ 0.3 = 4.  c) Second class — load in the middle.  d) They trade force for speed/distance of the load.
**Answer: d) They trade force for speed/distance of the load.**
