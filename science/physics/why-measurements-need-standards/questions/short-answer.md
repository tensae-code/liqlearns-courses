# Why measurements need standards — the SI base quantities — short answer

Answer in a few words, or with full working where numbers are given.

**1.** Why do local measures cause trouble?
**Answer: They vary from place to place, so the same object gets different values.**

**2.** Name the seven SI base quantities.
**Answer: Length, mass, time, temperature, electric current, amount of substance, luminous intensity.**

**3.** What three qualities must a standard have?
**Answer: It must be accessible, reliable, and give the same result anywhere.**

**4.** The metre is defined using what?
**Answer: How far light travels in a set time.**
