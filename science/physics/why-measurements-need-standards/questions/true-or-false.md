# Why measurements need standards — the SI base quantities — true or false

Say if each one is true or false.

**1.** A standard must be accessible, reliable, and give the same result anywhere.
**Answer: True**

**2.** The seven SI base quantities are length, mass, time, temperature, current, amount of substance and luminous intensity.
**Answer: True**

**3.** A good standard only needs to work in one town.
**Answer: False**
