# Dose and detectors — measuring radiation — true or false

Say if each one is true or false.

**1. (Sub lesson 1) Radiation damages cells by ionising atoms.**
**Answer: True**

**2. (Sub lesson 1) released dose is measured in grays (1 Gy = 1 J/kg.**
**Answer: False**

**3. (Sub lesson 1) Absorbed dose is measured in grays (1 Gy = 1 J/kg.**
**Answer: True**

**4. (Sub lesson 2) The rad as the older unit) with lethal ranges stated.**
**Answer: True**
