# Sinusoidal alternating current — period, frequency and rms values with the oscilloscope — short answer

Answer in a sentence or two.

**1.** (Sub lesson 1) How is alternating current different from the direct current of a battery?
**Answer: A battery's current flows steadily in one direction; alternating current grows, falls to zero, reverses, and repeats, tracing a sine wave — crossing zero twice in every cycle.**

**2.** (Sub lesson 2) A current has a frequency of 25 Hz. What is its period, and what does that number say?
**Answer: T = 1/f = 1/25 = 0.04 s — one complete cycle of the wave takes four hundredths of a second.**

**3.** (Sub lesson 3) Why do meters and rating plates use the rms value rather than the peak value?
**Answer: The rms value is the steady direct value that would do the same work — deliver the same power and heating — so it is the honest working value of an alternating supply; the peak only lasts an instant at the top of each hump.**

**4.** (Sub lesson 3) An oscilloscope trace shows one cycle spanning 5 divisions at 2 ms per division. Find the period and frequency.
**Answer: Period = 5 × 2 ms = 10 ms = 0.01 s; frequency = 1/0.01 = 100 Hz.**
