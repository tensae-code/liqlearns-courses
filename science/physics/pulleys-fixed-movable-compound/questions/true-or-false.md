# Pulleys — fixed, movable, compound — true or false

Say if each one is true or false.

**1.** A fixed pulley changes direction only (MA 1).
**Answer: True**

**2.** A movable pulley multiplies force and moves with the load.
**Answer: True**

**3.** A fixed pulley halves the effort needed to lift a load.
**Answer: False**
