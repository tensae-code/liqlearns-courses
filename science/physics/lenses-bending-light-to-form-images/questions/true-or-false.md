# Lenses — bending light to form images — true or false

Say if each one is true or false.

**1.** Convex lens converges; concave lens diverges.
**Answer: True**

**2.** Lens equation 1/f = 1/v + 1/u; magnification m = v/u.
**Answer: True**

**3.** Covering half a lens removes half the image.
**Answer: False**
