# Force on a current-carrying wire — the motor effect — short answer

Answer in a few words, or with full working where numbers are given.

**1.** B = 0.5 T, I = 4 A, L = 0.2 m, perpendicular. Force?
**Answer: F = BIL = 0.5 × 4 × 0.2 = 0.4 N.**

**2.** What happens to the force if the current reverses?
**Answer: It reverses direction.**

**3.** Name this effect.
**Answer: The motor effect.**

**4.** The wire lies parallel to the field. Force?
**Answer: Zero (or minimal) — the wire must cross the field.**
