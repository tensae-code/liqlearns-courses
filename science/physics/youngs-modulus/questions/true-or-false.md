# Young's modulus — how stiff a material is — true or false

Say if each one is true or false.

**1.** Y = stress ÷ strain — a property of the material, not the specimen's size.
**Answer: True**

**2.** Y is measured in a wire-stretching (Young) experiment.
**Answer: True**

**3.** Young's modulus depends on how thick the wire specimen is.
**Answer: False**
