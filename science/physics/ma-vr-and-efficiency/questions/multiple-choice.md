# MA, VR and efficiency — measuring a machine — multiple choice

Pick the one right answer.

**1.** A machine lifts a 600 N load with 150 N of effort. MA?
a) MA = 600 ÷ 150 = 4.  b) VR = 2 ÷ 0.5 = 4.  c) η = MA/VR = 3 ÷ 4 = 0.75 = 75%.  d) 400 ÷ 500 = 80%.
**Answer: a) MA = 600 ÷ 150 = 4.**

**2.** The effort moves 2 m while the load rises 0.5 m. VR?
a) MA = 600 ÷ 150 = 4.  b) VR = 2 ÷ 0.5 = 4.  c) η = MA/VR = 3 ÷ 4 = 0.75 = 75%.  d) 400 ÷ 500 = 80%.
**Answer: b) VR = 2 ÷ 0.5 = 4.**

**3.** A machine has MA 3 and VR 4. Efficiency?
a) MA = 600 ÷ 150 = 4.  b) VR = 2 ÷ 0.5 = 4.  c) η = MA/VR = 3 ÷ 4 = 0.75 = 75%.  d) 400 ÷ 500 = 80%.
**Answer: c) η = MA/VR = 3 ÷ 4 = 0.75 = 75%.**

**4.** Work input 500 J, work output 400 J. Efficiency?
a) MA = 600 ÷ 150 = 4.  b) VR = 2 ÷ 0.5 = 4.  c) η = MA/VR = 3 ÷ 4 = 0.75 = 75%.  d) 400 ÷ 500 = 80%.
**Answer: d) 400 ÷ 500 = 80%.**
