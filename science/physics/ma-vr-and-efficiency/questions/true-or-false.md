# MA, VR and efficiency — measuring a machine — true or false

Say if each one is true or false.

**1.** MA = load ÷ effort; VR = effort distance ÷ load distance.
**Answer: True**

**2.** Efficiency η = work output ÷ work input = MA ÷ VR.
**Answer: True**

**3.** Efficiency can be greater than 100% in a well-oiled machine.
**Answer: False**
