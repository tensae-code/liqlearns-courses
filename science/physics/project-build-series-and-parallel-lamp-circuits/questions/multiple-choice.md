# Project: build series and parallel lamp circuits — multiple choice

Pick the one right answer.

**1.** In the series build, why are the lamps dimmer?
a) They share the supply voltage and the same current path — each gets only part of the voltage.  b) Stays lit — its branch is complete without the first.  c) A multimeter.  d) Parallel — each load gets full voltage and works independently.
**Answer: a) They share the supply voltage and the same current path — each gets only part of the voltage.**

**2.** Unscrew one parallel lamp. The other — ?
a) They share the supply voltage and the same current path — each gets only part of the voltage.  b) Stays lit — its branch is complete without the first.  c) A multimeter.  d) Parallel — each load gets full voltage and works independently.
**Answer: b) Stays lit — its branch is complete without the first.**

**3.** What instrument checks the builds?
a) They share the supply voltage and the same current path — each gets only part of the voltage.  b) Stays lit — its branch is complete without the first.  c) A multimeter.  d) Parallel — each load gets full voltage and works independently.
**Answer: c) A multimeter.**

**4.** Which build matches house wiring, and why?
a) They share the supply voltage and the same current path — each gets only part of the voltage.  b) Stays lit — its branch is complete without the first.  c) A multimeter.  d) Parallel — each load gets full voltage and works independently.
**Answer: d) Parallel — each load gets full voltage and works independently.**
