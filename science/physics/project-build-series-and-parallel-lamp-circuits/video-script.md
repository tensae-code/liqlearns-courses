# Video script — Project: build series and parallel lamp circuits

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.
---

Two builds make the resistor rules visible.
Project 4.1 wires two lamps in series — strip the wires, join the loop, check with a multimeter: both lamps glow dimmer than one alone, and removing one kills both, because one path carries everything.
Project 4.2 wires the same lamps in parallel: each has its own branch across the supply, both glow bright, and removing one leaves the other lit.
Build both, measure both, and the series/parallel rules stop being arithmetic and become memory.

Remember: **Series lamps: dimmer, and one removed kills both (one path).**
Remember: **Parallel lamps: brighter and independent (own branches).**
Remember: **Multimeter checks verify each build before power is trusted.**
