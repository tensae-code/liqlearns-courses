# Sensors — depth

Whole-lesson pass mark: the learner can do all of these — A sensor converts a physical quantity into an electrical signal: thermistor (temperature), LDR (light), strain gauge (strain), piezoelectric crystal (pressure), Hall sensor (magnetic field); Resistive sensors are read in a potential divider; generating sensors (thermocouple, piezoelectric, photovoltaic) make their own small voltage; Sensor signals are often non-linear — usable because the curve is known and repeatable, like the NTC thermistor's plunging resistance; A sensor is judged by sensitivity (signal per unit change), range, response time and repeatability — answering the lesson's questions from the lesson text.
This lesson has 3 sub lessons, proved in order: each opens by proving the previous one. Practice deepens inside each part before the learner moves on — restating each part in the learner's own examples, working its numbers, and checking new cases against it until the teaching is the learner's own.
