# Archimedes' principle — the upthrust — true or false

Say if each one is true or false.

**1. The upthrust equals the weight of fluid displaced (F_B = ρ_fluid g V), derived from the pressure difference between a submerged block's bottom and top faces; buoyancy activities (3.9, 3.10) measure it and find a liquid's density from it.**
