# Communicating vessels — depth

Whole-lesson pass mark: the learner can do all of these — Vessels that connect below the liquid's surface are communicating vessels; Pick the level of the join; Pour a second, immiscible liquid into one arm and the levels split: the lighter liquid stands higher, the columns balancing by ρ₁h₁ = ρ₂h₂ — the trick the Armenian book's own lab strand uses to find an unknown liquid's density against water — answering the lesson's questions from the lesson text.
This lesson has 3 sub lessons, proved in order: each opens by proving the previous one. Practice deepens inside each part before the learner moves on — restating each part in the learner's own examples, working its numbers, and checking new cases against it until the teaching is the learner's own.
