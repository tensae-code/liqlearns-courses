# Full-wave bridge rectifier — true or false

Say if each one is true or false.

**1. (Sub lesson 1) Four diodes in a bridge flip the negative half-cycles up, filling the gaps.**
**Answer: True**

**2. (Sub lesson 1) Four diodes in a bridge flip the negative half-cycles down, filling the gaps.**
**Answer: False**

**3. (Sub lesson 2) A capacitor across the output smooths the pulses toward steady DC.**
**Answer: True**
