# Coulomb's law — how strong the charge force is — true or false

Say if each one is true or false.

**1.** F = kq₁q₂/r² — force grows with charge product, falls with distance squared.
**Answer: True**

**2.** Double the distance → force falls to a quarter.
**Answer: True**

**3.** Doubling the distance between charges halves the force between them.
**Answer: False**
