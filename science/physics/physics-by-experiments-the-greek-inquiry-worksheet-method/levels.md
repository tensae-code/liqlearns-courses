# Physics by experiments — the Greek inquiry worksheet method — depth

Whole-lesson pass mark: the learner can do all of these — Name the five worksheet steps in order (observe → hypothesise → experiment → conclude/record → apply/generalise); Write a testable hypothesis before experimenting, and say why it is allowed to be wrong; Treat the table, graph and written conclusion as the result itself, not paperwork; Compare a conclusion honestly with the hypothesis it tested; Apply and generalise a bench conclusion to an everyday or planetary case — answering the lesson's questions from the lesson text.
This lesson has 3 sub lessons, proved in order: each opens by proving the previous one. Practice deepens inside each part before the learner moves on — restating each part in the learner's own examples, working its numbers, and checking new cases against it until the teaching is the learner's own.
