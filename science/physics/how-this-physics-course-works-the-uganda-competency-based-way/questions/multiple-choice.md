# How this Physics course works — the Uganda competency-based way — multiple choice

Pick the one right answer.

**1.** (Sub lesson 1) In a competency-based course, the main aim is…
a) Covering every page of the book  b) Building what learners can do — competences, generic skills and values practised inside the topics  c) Finishing the syllabus early  d) Copying notes accurately
**Answer: b) Building what learners can do — competences, generic skills and values practised inside the topics**

**2.** (Sub lesson 1) Which is a generic skill in this design?
a) Memorising definitions  b) Critical thinking and problem-solving  c) Neat handwriting only  d) Silence in class
**Answer: b) Critical thinking and problem-solving**

**3.** (Sub lesson 2) A competency-based lesson plan is built starting from…
a) The test questions  b) The learning outcome — what the learner will be able to do  c) The textbook chapter  d) The holiday calendar
**Answer: b) The learning outcome — what the learner will be able to do**

**4.** (Sub lesson 2) In this way of teaching, lessons are…
a) Teacher-talk first, activity never  b) Activity-first, with the teacher guiding and questioning  c) Read aloud from the guide  d) Done only at home
**Answer: b) Activity-first, with the teacher guiding and questioning**

**5.** (Sub lesson 3) Formative assessment is assessment that…
a) Happens only at the end of the year  b) Happens during learning and steers what the teacher does next  c) Is marked by another school  d) Counts for the final certificate only
**Answer: b) Happens during learning and steers what the teacher does next**

**6.** (Sub lesson 3) A rubric is…
a) A red pen  b) A scoring guide setting out levels of performance so work is judged consistently  c) A class register  d) A timetable
**Answer: b) A scoring guide setting out levels of performance so work is judged consistently**
