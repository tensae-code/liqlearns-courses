# The electromagnetic spectrum — uses and dangers — true or false

Say if each one is true or false.

**1.** Order by shrinking wavelength: radio, microwave, infrared, visible, ultraviolet, X-ray, gamma.
**Answer: True**

**2.** Higher frequency means higher energy and greater danger to tissue.
**Answer: True**

**3.** X-rays have longer wavelengths than radio waves.
**Answer: False**
