# Teaching to the standard — expected outcomes and cross-cutting concepts, the Armenian guide way — depth

Whole-lesson pass mark: the learner can do all of these — The shared architecture of the Armenian guides is itself the content: Chapter I is never a topic; For its own grade, each guide names the expected outcomes: what the learner will be able to do — explain, measure, solve, investigate — by the year's end; The guides name cross-cutting concepts: the big ideas that reappear inside every topic — cause and effect, systems, energy, patterns, change — so that kinematics, heat and electricity are met as one connected subject wearing different clothes — answering the lesson's questions from the lesson text.
This lesson has 3 sub lessons, proved in order: each opens by proving the previous one. Practice deepens inside each part before the learner moves on — restating each part in the learner's own examples, working its numbers, and checking new cases against it until the teaching is the learner's own.
