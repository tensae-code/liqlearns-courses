# How this physics course works — the Pakistani (Punjab) Grade 11 way — multiple choice

Pick the one right answer.

**1.** (Sub lesson 1) Every PECTAA chapter opens with…
a) The numerical answers  b) A boxed Learning Objectives list  c) A poem about physics  d) The question has no answer
**Answer: b) A boxed Learning Objectives list**

**2.** (Sub lesson 1) The Learning Objectives are written as…
a) Teacher instructions only  b) Student outcomes — what the learner will be able to do  c) Chapter page numbers  d) The question has no answer
**Answer: b) Student outcomes — what the learner will be able to do**

**3.** (Sub lesson 2) Worked examples in the chapter's middle serve to…
a) Replace all questions  b) Show the method on real numbers first  c) Decorate the page  d) The question has no answer
**Answer: b) Show the method on real numbers first**

**4.** (Sub lesson 2) The information side boxes are headed…
a) Do Not Read  b) For Your Information / Interesting Information  c) Examination Only  d) The question has no answer
**Answer: b) For Your Information / Interesting Information**

**5.** (Sub lesson 3) The five closing sets run from MCQs up to…
a) Only true/false items  b) Comprehensive Questions and Numerical Problems  c) A single essay  d) The question has no answer
**Answer: b) Comprehensive Questions and Numerical Problems**

**6.** (Sub lesson 3) The closing sets come with…
a) No answers anywhere  b) Answers given, so work can be checked  c) Answers sold separately  d) The question has no answer
**Answer: b) Answers given, so work can be checked**
