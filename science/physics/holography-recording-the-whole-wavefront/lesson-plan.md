# Lesson plan — Holography — recording the whole wavefront

**Course:** Science · **Title:** Physics · **Lesson:** Holography — recording the whole wavefront

**The one thing this lesson teaches:** an ordinary photograph records only the light's intensity and throws away its phase — the depth is lost; a hologram records the interference pattern between light from the object and a reference beam, storing amplitude AND phase, so that when laser light replays it, the original wavefront is rebuilt and the image stands in true three dimensions

## Sub lessons
1. **Why an ordinary photograph is not enough** — A camera lens maps each point of the scene to a point of film, and the film records how much light arrived — the intensity, proportional to amplitude squared. But light is a wave, and a wave is fully described by amplitude and phase together. The phase carries the distances the light travelled from each part of the object — which is to say, the depth. Photographic film is blind to phase: the wave's timing information is discarded, and with it the scene's third dimension.
2. **Recording the interference pattern — the hologram** — The arrangement needs coherent light — one laser beam split in two. The object beam illuminates the object and scatters from it onto the photographic plate; the reference beam is routed by mirrors straight onto the same plate, untouched. On the plate the two beams interfere in a pattern of microscopic fringes — typically a thousand lines per millimetre — encoding, in fringe position and contrast, the object's amplitude and phase at every point. Developed, the plate is the hologram: to the eye, a meaningless grey swirl.
3. **Rebuilding the wavefront — the 3-D image** — Shine the reference beam (the same laser geometry) through the developed hologram and the fringe pattern diffracts it back into an exact copy of the original object wave — the wavefront is reconstructed. An eye receiving that wavefront cannot tell it from the wavefront the object itself would send: you see a virtual image hanging in space behind the plate, with true parallax — move your head and you see around the object, near parts hiding far parts as they should.

## What the learner can do when it ends
1. Say, in their own words: A photograph records intensity only and discards phase — and phase is where the depth information lives.
2. Say, in their own words: A hologram records the interference pattern of object beam and reference beam from a split laser: phase converted into fringe brightness/position, so amplitude and phase are both stored.
3. Say, in their own words: Reconstruction: illuminating the hologram with the reference beam rebuilds the object's original wavefront — a true 3-D virtual image with parallax.
4. Answer the lesson's questions from the lesson text alone.

## If the learner is stuck
- Looks for a picture on the hologram plate → there is none: the developed plate is a fringe pattern storing wave information; the picture exists only in the reconstructed wavefront.
- Thinks any light can record one → interference fringes stand still only if the two beams keep a fixed phase relation — coherence — which is why the laser is essential at recording.
