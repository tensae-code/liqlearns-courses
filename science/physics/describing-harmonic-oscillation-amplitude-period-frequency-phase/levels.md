# Describing harmonic oscillation — amplitude, period, frequency, phase — depth

Whole-lesson pass mark: the learner can do all of these — Displacement x is the signed distance from equilibrium; the amplitude A is the greatest displacement — the size of the oscillation; The period T is the time of one full cycle; the frequency f = 1/T is cycles per second, in hertz; the angular frequency is ω = 2πf = 2π/T; Apparatus fixes the rhythm (mass and stiffness for a spring, length for a pendulum); the start fixes the amplitude — the two never mix; Phase says where in the cycle the oscillator is: x = A cos(ωt + φ); oscillators half a cycle apart are in antiphase — answering the lesson's questions from the lesson text.
This lesson has 3 sub lessons, proved in order: each opens by proving the previous one. Practice deepens inside each part before the learner moves on — restating each part in the learner's own examples, working its numbers, and checking new cases against it until the teaching is the learner's own.
