# Wave words — period, frequency, wavelength, amplitude — true or false

Say if each one is true or false.

**1.** Period is the time for one complete oscillation; frequency is oscillations per second, in hertz.
**Answer: True**

**2.** f = 1/T, and wave speed v = fλ.
**Answer: True**

**3.** Frequency and period are the same thing.
**Answer: False**
