# Converting units — true or false

Say if each one is true or false.

**1.** Conversion changes the unit, never the quantity itself.
**Answer: True**

**2.** 1 km = 1000 m, 1 kg = 1000 g, 1 h = 3600 s.
**Answer: True**

**3.** Converting 3 m to centimetres gives a smaller number than 3.
**Answer: False**
