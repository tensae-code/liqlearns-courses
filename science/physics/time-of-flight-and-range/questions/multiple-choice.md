# Time of flight and range — multiple choice

Pick the one right answer.

**1. Which statement about time of flight and range (horizontal launch) is correct?**
a) The bullet summary restates semiconductor, diode, transistor and gate facts (biasing conditions, β, IC limits, gate…  b) Bodies differ in how much heat raises their temperature: heat capacity per body, specific heat capacity per kilogram…  c) Fall time is set by height alone; range is horizontal speed multiplied by that time.
**Answer: c) Fall time is set by height alone; range is horizontal speed multiplied by that time.**

**2. Fall time is set by height alone; ______ is horizontal speed multiplied by that time.**
a) vector  b) displacement  c) range
**Answer: c) range**
