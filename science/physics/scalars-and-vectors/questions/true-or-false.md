# Scalars and vectors — true or false

Say if each one is true or false.

**1. Some quantities need only a size (scalars), others a size and a direction (vectors); vectors are drawn as arrows whose length is the magnitude.**
**Answer: True**

**2. Kinds met here: unequal vectors, negative (opposite) vectors, parallel and collinear vectors, coplanar vectors and the zero vector.**
**Answer: False**

**3. Kinds met here: equal vectors, negative (opposite) vectors, parallel and collinear vectors, coplanar vectors and the zero vector.**
**Answer: True**
