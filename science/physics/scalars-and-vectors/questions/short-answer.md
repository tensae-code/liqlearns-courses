# Scalars and vectors — short answer

Answer in a few words.

**1. Give one key fact this lesson teaches about scalars and vectors; kinds of vectors.**
**Answer: Some quantities need only a size (scalars), others a size and a direction (vectors); vectors are drawn as arrows whose length is the magnitude.**

**2. State one thing this lesson teaches about scalars and vectors; kinds of vectors.**

**3. Name one key idea from this lesson about scalars and vectors; kinds of vectors.**
