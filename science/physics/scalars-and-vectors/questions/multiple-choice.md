# Scalars and vectors — multiple choice

Pick the one right answer.

**1. Which statement about scalars and vectors; kinds of vectors is correct?**
a) A capacitor stores charge on separated plates; capacitance C = Q/V is measured in farads, and the parallel-plate value…  b) Some quantities need only a size (scalars), others a size and a direction (vectors); vectors are drawn as arrows whose…  c) Output is 1 only when all inputs are 1 (the multiplication of logic), pictured as switches in series.
**Answer: b) Some quantities need only a size (scalars), others a size and a direction (vectors); vectors are drawn as…**

**2. Some quantities need only a size (scalars), others a size and a direction (______s); vectors are drawn as arrows whose length is the magnitude.**
a) pressure  b) vector  c) field lines
**Answer: b) vector**

**3. Kinds met here: equal vectors, negative (opposite) vectors, ______ and collinear vectors, coplanar vectors and the zero vector.**
a) bridge  b) energy  c) parallel
**Answer: c) parallel**
