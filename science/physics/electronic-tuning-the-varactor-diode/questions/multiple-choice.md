# Electronic tuning — the varactor diode — multiple choice

Pick the one right answer.

**1.** (Sub lesson 1) The varactor diode is operated…
a) Forward-biased, as a rectifier  b) Reverse-biased, used as a voltage-controlled capacitor  c) At zero bias only  d) As a light emitter
**Answer: b) Reverse-biased, used as a voltage-controlled capacitor**

**2.** (Sub lesson 1) The junction's capacitance exists because…
a) The depletion layer is an insulating region between conducting p and n material — plates and dielectric in miniature  b) All diodes store charge like batteries  c) The leads form a coil  d) The crystal is piezoelectric
**Answer: a) The depletion layer is an insulating region between conducting p and n material — plates and dielectric in miniature**

**3.** (Sub lesson 2) Increasing the reverse bias on a varactor…
a) Narrows the depletion layer and raises C  b) Widens the depletion layer and lowers C  c) Makes it conduct heavily  d) Destroys the junction instantly
**Answer: b) Widens the depletion layer and lowers C**

**4.** (Sub lesson 2) In an LC tuner, lowering the varactor capacitance by raising the bias makes the resonant frequency…
a) Fall, since f = 1/(2π√(LC))  b) Rise — f grows as C shrinks  c) Stay fixed  d) Become zero
**Answer: b) Rise — f grows as C shrinks**

**5.** (Sub lesson 3) Automatic frequency control (AFC) uses the varactor to…
a) Amplify the audio  b) Nudge the tuning voltage so the set pulls itself back onto a drifting station  c) Power the display  d) Rectify the aerial signal
**Answer: b) Nudge the tuning voltage so the set pulls itself back onto a drifting station**

**6.** (Sub lesson 3) A channel preset on an electronically tuned set is physically stored as…
a) A knob position  b) A memorised tuning voltage for the varactors  c) A length of wire  d) A gear setting
**Answer: b) A memorised tuning voltage for the varactors**
