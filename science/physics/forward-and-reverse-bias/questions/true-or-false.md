# Forward and reverse bias — true or false

Say if each one is true or false.

**1. Forward bias (positive to P) shrinks the barrier and current flows; reverse bias widens it and current is blocked (until breakdown); the current–voltage graph's knee captures both behaviours.**
**Answer: True**

**2. Forward bias (negative to P) shrinks the barrier and current flows; reverse bias widens it and current is blocked (until breakdown); the current–voltage graph's knee captures both behaviours.**
**Answer: False**
