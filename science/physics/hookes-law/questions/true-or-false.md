# Hooke's law — springs stretch in proportion — true or false

Say if each one is true or false.

**1.** Hooke's law: F = kx, within the elastic limit.
**Answer: True**

**2.** Extension is proportional to load — double load, double stretch.
**Answer: True**

**3.** Hooke's law holds however far you stretch a spring.
**Answer: False**
