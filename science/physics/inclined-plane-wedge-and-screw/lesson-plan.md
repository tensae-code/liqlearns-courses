**This lesson's own level:** it stands on the Grade 9 lessons before it in Unit 5 and on everyday observation; it needs nothing else to start.

## If the learner is stuck
- Cannot start → return to Do it first and do it with real objects, slowly, naming each step out loud.
- Mixes up the key ideas → go back to the key-ideas list in lesson/lesson.md and test each one against the picture [Picture 21844].
- Calculation slips → the formula is Plane VR = length / height; Wedge VR = penetration / thickness; Screw MA = πd / p; write the knowns first, substitute, then compute, keeping units at every step.
