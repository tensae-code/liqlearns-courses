# Inclined plane, wedge and screw — true or false

Say if each one is true or false.

**1. (Sub lesson 1)** Inclined plane VR = slope length ÷ height.
**Answer: True**

**2. (Sub lesson 2)** Wedge VR = penetration length ÷ thickness.
**Answer: True**

**3. (Sub lesson 3)** A screw is a member of the lever family.
**Answer: False**
