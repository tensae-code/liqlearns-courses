# Lesson plan — Three-part assessment — diagnostic, formative, summative, with test specifications

**Course:** Science · **Title:** Physics · **Lesson:** Three-part assessment — diagnostic, formative, summative, with test specifications
**Place in the curriculum:** Physics (CURRICULUM.md Unit 18), inside the teaching-way strand — the assessment chapter of the Armenian methodological guides (Grades 8–11): learning outcomes assessed in three tenses, with tests built to printed specifications (teacher-guide evidence)
**The one thing this lesson teaches:** the Armenian guides assess in three tenses: diagnostic assessment before teaching finds what the class already holds, formative assessment during teaching steers it, and summative assessment after a topic certifies it — with the summative tests built to a printed specification so the test matches the outcomes it claims to measure (teacher-guide evidence only)
**This lesson's own level:** it stands on its own — a learner can land here directly. Any earlier lesson named below is recommended first, never forced

## Sub lessons
1. **Diagnostic — before the teaching starts** — The guides' assessment chapter opens before the topic does: diagnostic assessment finds the starting point — which prerequisites are firm, which misconceptions are already in the room. Its marks do not count against anyone; its information counts for everything, because it tells the teacher where the topic must actually begin rather than where the book assumes it begins. A five-minute diagnostic can move a whole week's planning.
2. **Formative — assessment that steers** — During the topic, formative assessment is the steering wheel: questions, short tasks, lab observations whose results change what happens next — re-teach this, practise that, let this group run. The guides treat it as part of teaching, not an interruption of it: evidence gathered while there is still time to act on it is the only evidence that improves the learning it measures.
3. **Summative — and the specification behind the test** — After the topic, summative assessment certifies: the thematic test. The guides' discipline is the specification (the test blueprint) printed with it — a table matching items to outcomes and levels, so the test provably samples what the topic promised to teach, at the demand it promised. A sample thematic test with its specification is printed in the guides as the model: assessment designed, not assembled — and fair because its coverage can be checked before a single pupil sits it.
Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
