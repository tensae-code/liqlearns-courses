# Three-part assessment — diagnostic, formative, summative, with test specifications — multiple choice

Pick the one right answer.

**1.** (Sub lesson 1) Diagnostic assessment happens…
a) After the topic  b) Before teaching — to find the starting point  c) Only at year end  d) Never
**Answer: b) Before teaching — to find the starting point**

**2.** (Sub lesson 2) Formative assessment is for…
a) Certifying final grades  b) Steering the teaching while there is still time to act on the evidence  c) Filling report forms  d) Replacing teaching
**Answer: b) Steering the teaching while there is still time to act on the evidence**

**3.** (Sub lesson 3) Summative assessment…
a) Opens a topic  b) Certifies learning at a topic's end — the thematic test  c) Is illegal in Armenia  d) Guides group work
**Answer: b) Certifies learning at a topic's end — the thematic test**

**4.** (Sub lesson 3) A test specification is…
a) The answer key  b) A blueprint table matching test items to outcomes and levels, so coverage can be checked  c) The pupil list  d) A timetable
**Answer: b) A blueprint table matching test items to outcomes and levels, so coverage can be checked**

**5.** (Sub lesson 1) Diagnostic results should mainly change…
a) Pupils' final grades  b) The plan — where teaching must actually begin  c) The textbook  d) Nothing
**Answer: b) The plan — where teaching must actually begin**

**6.** (Sub lesson 3) The guides print a sample thematic test…
a) As decoration  b) With its specification — as the model of assessment designed, not assembled  c) To be copied unchanged every year  d) For parents only
**Answer: b) With its specification — as the model of assessment designed, not assembled**
