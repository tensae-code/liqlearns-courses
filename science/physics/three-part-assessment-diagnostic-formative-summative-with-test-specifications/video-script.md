Today: **the Armenian guides assess in three tenses: diagnostic assessment before teaching finds what the class already holds, formative assessment during teaching steers it, and summative assessment after a topic certifies it — with the summative tests built to a printed specification so the test matches the outcomes it claims to measure (teacher-guide evidence only)**. The guides' assessment chapter opens before the topic does: diagnostic assessment finds the starting point — which prerequisites are firm, which misconceptions are already in the room. Then the lesson builds its three parts in order — diagnostic — before the teaching starts; formative — assessment that steers; summative — and the specification behind the test — each one first met in the hand, then said in words.
