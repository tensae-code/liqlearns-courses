# Converting Celsius, Fahrenheit and Kelvin — true or false

Say if each one is true or false.

**1.** °F = (9/5)°C + 32 and °C = (5/9)(°F − 32).
**Answer: True**

**2.** K = °C + 273.15; Kelvin's floor is absolute zero.
**Answer: True**

**3.** To convert Celsius to kelvin you multiply by 273.15.
**Answer: False**
