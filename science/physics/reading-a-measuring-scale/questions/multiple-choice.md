# Reading a measuring scale — multiple choice

Pick the one right answer.

**1.** What is a scale?
a) The set of marks on a measuring device.  b) Finer precision.  c) About 7.5 — the last digit is estimated between the marks.  d) The last digit.
**Answer: a) The set of marks on a measuring device.**

**2.** What do more marks on a scale give you?
a) The set of marks on a measuring device.  b) Finer precision.  c) About 7.5 — the last digit is estimated between the marks.  d) The last digit.
**Answer: b) Finer precision.**

**3.** The edge sits just past the 7 mark, about halfway to 8. How do you read it?
a) The set of marks on a measuring device.  b) Finer precision.  c) About 7.5 — the last digit is estimated between the marks.  d) The last digit.
**Answer: c) About 7.5 — the last digit is estimated between the marks.**

**4.** Which digit of a careful reading is estimated?
a) The set of marks on a measuring device.  b) Finer precision.  c) About 7.5 — the last digit is estimated between the marks.  d) The last digit.
**Answer: d) The last digit.**
