# Video script — Static equilibrium — balanced forces and balanced turning

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.
---

A rigid body in static equilibrium is going nowhere — neither sliding nor turning.
The first condition: the net force is zero.
Every push is answered by an equal opposite push, so there is no translation.
The second condition: the net torque (moment) is zero.
Every turning effect is answered by an opposite one, so there is no rotation.
Ladders against walls, beams with balanced loads — each is solved by imposing both conditions and solving the pair.

Remember: **First condition: net force = 0 (no translation).**
Remember: **Second condition: net torque/moment = 0 (no rotation).**
Remember: **Both conditions together solve ladders, beams and balanced loads.**
Keep the formula: **ΣF = 0; Στ = 0**
