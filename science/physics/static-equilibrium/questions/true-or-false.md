# Static equilibrium — balanced forces and balanced turning — true or false

Say if each one is true or false.

**1. (Sub lesson 1)** First condition: net force = 0 (no translation).
**Answer: True**

**2. (Sub lesson 2)** Second condition: net torque/moment = 0 (no rotation).
**Answer: True**

**3. (Sub lesson 1)** A body with balanced forces is always in full equilibrium, even if it is twisting.
**Answer: False**
