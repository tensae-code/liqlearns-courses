## If the learner is stuck
- Cannot start → return to Do it first and do it with real objects, slowly, naming each step out loud.
- Mixes up the key ideas → go back to the key-ideas list in lesson/lesson.md and test each one against the picture [Picture 21893].
- Calculation slips → the formula is ΣF = 0; Στ = 0; write the knowns first, substitute, then compute, keeping units at every step.
