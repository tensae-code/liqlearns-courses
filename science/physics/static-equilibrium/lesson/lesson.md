# Static equilibrium — balanced forces and balanced turning

## Do it first
Balance a ruler on a pencil with coins on both sides. Move a coin and watch the second condition fail in a slow tip — then fix it.

[Picture 21893 — ladder against a wall with all forces and moments marked, balanced]

## Sub lesson 1 — First condition — balanced forces
A rigid body in static equilibrium is going nowhere — neither sliding nor turning. The first condition: the net force is zero. Every push is answered by an equal opposite push, so there is no translation.

**Keep the formulas:** ΣF = 0; Στ = 0

## Sub lesson 2 — Second condition — balanced turning
The second condition: the net torque (moment) is zero. Every turning effect is answered by an opposite one, so there is no rotation. Ladders against walls, beams with balanced loads — each is solved by imposing both conditions and solving the pair. One worked platform problem resolves to a 568.4 N pivot force — the two conditions doing real work.

## The key ideas

- First condition: net force = 0 (no translation).
- Second condition: net torque/moment = 0 (no rotation).
- Both conditions together solve ladders, beams and balanced loads.
