# Position and displacement — with a frame of reference — multiple choice

Pick the one right answer.

**1.** A car moves from x = 3 m to x = 11 m. Displacement?
a) 11 − 3 = +8 m.  b) Position is measured from each frame's own origin.  c) No — final minus initial is the same in both frames.  d) Vector.
**Answer: a) 11 − 3 = +8 m.**

**2.** Why do two observers with different origins report different positions for one car?
a) 11 − 3 = +8 m.  b) Position is measured from each frame's own origin.  c) No — final minus initial is the same in both frames.  d) Vector.
**Answer: b) Position is measured from each frame's own origin.**

**3.** Does changing the origin change a journey's displacement?
a) 11 − 3 = +8 m.  b) Position is measured from each frame's own origin.  c) No — final minus initial is the same in both frames.  d) Vector.
**Answer: c) No — final minus initial is the same in both frames.**

**4.** Displacement is scalar or vector?
a) 11 − 3 = +8 m.  b) Position is measured from each frame's own origin.  c) No — final minus initial is the same in both frames.  d) Vector.
**Answer: d) Vector.**
