# Newton's second law — force, mass, acceleration — true or false

Say if each one is true or false.

**1.** F = ma — acceleration grows with net force and shrinks with mass.
**Answer: True**

**2.** 1 N accelerates 1 kg by 1 m/s².
**Answer: True**

**3.** Doubling the mass doubles the acceleration from the same force.
**Answer: False**
