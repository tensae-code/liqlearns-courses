# Simple machines at work — multiple choice

Pick the one right answer.

**1.** Which class of lever is a wheelbarrow?
a) Second class — the load sits between fulcrum and effort.  b) Force.  c) A wedge.  d) Any two of: hoe, axe, crowbar, wheelbarrow.
**Answer: a) Second class — the load sits between fulcrum and effort.**

**2.** What does a crowbar multiply?
a) Second class — the load sits between fulcrum and effort.  b) Force.  c) A wedge.  d) Any two of: hoe, axe, crowbar, wheelbarrow.
**Answer: b) Force.**

**3.** An axe head is which machine?
a) Second class — the load sits between fulcrum and effort.  b) Force.  c) A wedge.  d) Any two of: hoe, axe, crowbar, wheelbarrow.
**Answer: c) A wedge.**

**4.** Name two farm simple machines.
a) Second class — the load sits between fulcrum and effort.  b) Force.  c) A wedge.  d) Any two of: hoe, axe, crowbar, wheelbarrow.
**Answer: d) Any two of: hoe, axe, crowbar, wheelbarrow.**
