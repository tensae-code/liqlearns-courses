# Simple machines at work — short answer

Answer in a few words, or with full working where numbers are given.

**1.** Which class of lever is a wheelbarrow?
**Answer: Second class — the load sits between fulcrum and effort.**

**2.** What does a crowbar multiply?
**Answer: Force.**

**3.** An axe head is which machine?
**Answer: A wedge.**

**4.** Name two farm simple machines.
**Answer: Any two of: hoe, axe, crowbar, wheelbarrow.**
