# The equations of uniformly accelerated motion — true or false

Say if each one is true or false.

**1.** v = u + at; s = ut + ½at²; v² = u² + 2as; s = ½(u + v)t.
**Answer: True**

**2.** The equations hold only for constant acceleration.
**Answer: True**

**3.** These equations work for any acceleration, changing or constant.
**Answer: False**
