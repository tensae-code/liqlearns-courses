# LEDs and photodiodes — true or false

Say if each one is true or false.

**1. (Sub lesson 1) Light-emitting diodes turn current into light.**
**Answer: True**

**2. (Sub lesson 1) Photodiodes turn light into current.**
**Answer: True**

**3. (Sub lesson 2) Diodes guard circuits against over-voltage — the practical-uses run of §5.2/5.3.**
**Answer: True**
