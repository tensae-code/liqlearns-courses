# Continuity — narrow means fast — true or false

Say if each one is true or false.

**1. For incompressible flow A₁v₁ = A₂v₂: narrow pipe, faster flow — related by pupils to rivers and hoses in the section's questions.**
**Answer: True**

**2. For incompressible flow A₁v₁ = A₂v₂: narrow pipe, slower flow — related by pupils to rivers and hoses in the section's questions.**
**Answer: False**
