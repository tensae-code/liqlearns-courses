# STEAM project — build a floating power station — depth

Whole-lesson pass mark: the learner can do all of these — The platform must float by Archimedes' principle and stay stable, centre of mass low; Moving water drives a generator; induction turns the motion into electricity; Output is measured — voltage, current, a lamp lit — not merely claimed; The project joins science, technology, engineering, art and mathematics; The presentation must name the physics, justify the design and report the measurements — answering the lesson's questions from the lesson text.
This lesson has 3 sub lessons, proved in order: each opens by proving the previous one. Practice deepens inside each part before the learner moves on — restating each part in the learner's own examples, working its numbers, and checking new cases against it until the teaching is the learner's own.
