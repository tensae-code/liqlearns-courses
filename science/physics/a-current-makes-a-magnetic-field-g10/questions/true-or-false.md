# A current makes a magnetic field — true or false

Say if each one is true or false.

**1.** A current's field forms concentric circles around the wire.
**Answer: True**

**2.** Right-hand grip rule: thumb = current, curled fingers = field direction.
**Answer: True**

**3.** The field around a straight wire runs in straight lines parallel to the wire.
**Answer: False**
