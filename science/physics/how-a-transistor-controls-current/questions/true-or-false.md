# How a transistor controls current — true or false

Say if each one is true or false.

**1. Correct operation: base–emitter junction forward biased, base–collector reverse biased; the currents obey I_E = I_B + I_C, with the small base current controlling the large collector current.**
**Answer: True**

**2. Correct operation: base–emitter junction reverse biased, base–collector reverse biased; the currents obey I_E = I_B + I_C, with the small base current controlling the large collector current.**
**Answer: False**
