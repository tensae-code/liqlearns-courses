# Splitting a vector — components — true or false

Say if each one is true or false.

**1.** Ax = A cos θ and Ay = A sin θ for a vector at angle θ.
**Answer: True**

**2.** Recombine: A = √(Ax² + Ay²), tan θ = Ay/Ax.
**Answer: True**

**3.** The x-component of a vector at angle θ is A sin θ (with θ from the x-axis).
**Answer: False**
