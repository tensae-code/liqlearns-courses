# Electronic systems and digital electronics — multiple choice

Pick the one right answer.

**1.** (Sub lesson 1) In the input → process → output skeleton, a thermistor is…
a) An output  b) An input sensor for temperature  c) A process block  d) A power supply
**Answer: b) An input sensor for temperature**

**2.** (Sub lesson 1) The output block of a dusk street light is the…
a) Light sensor  b) Lamp  c) Decision circuit  d) Street
**Answer: b) Lamp**

**3.** (Sub lesson 2) The binary number 1011 equals…
a) 9  b) 10  c) 11  d) 13
**Answer: c) 11**

**4.** (Sub lesson 2) A digital signal differs from an analogue signal because it…
a) Is always louder  b) Has only two levels, 1 and 0  c) Cannot be stored  d) Slides through every value
**Answer: b) Has only two levels, 1 and 0**

**5.** (Sub lesson 3) An AND gate gives output 1 when…
a) Either input is 1  b) Both inputs are 1  c) Both inputs are 0  d) The input is inverted
**Answer: b) Both inputs are 1**

**6.** (Sub lesson 3) A NOT gate with input 0 gives output…
a) 0  b) 1  c) 0 and 1 together  d) Nothing
**Answer: b) 1**
