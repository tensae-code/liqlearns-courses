# What a force is — pushes, pulls and weight — true or false

Say if each one is true or false.

**1.** A force is a push or a pull, measured in newtons.
**Answer: True**

**2.** Force can start, stop, speed, slow, redirect or deform a body.
**Answer: True**

**3.** Weight is the same thing as mass and is measured in kilograms as a force.
**Answer: False**
