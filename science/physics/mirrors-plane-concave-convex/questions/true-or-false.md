# Mirrors — plane, concave, convex — true or false

Say if each one is true or false.

**1. (Sub lesson 1)** Plane mirror image: virtual, erect, same size, laterally inverted.
**Answer: True**

**2. (Sub lesson 2)** Concave mirror focuses rays; f = R/2.
**Answer: True**

**3. (Sub lesson 3)** A plane mirror's image is laterally correct — your right hand raises its right hand.
**Answer: False**
