# Motion of a system of bodies — connected masses — depth

Whole-lesson pass mark: the learner can do all of these — Connected bodies share one acceleration — solve the whole system first: F_net = (total mass) × a; Tension is internal to the system; find it by isolating one body with F = ma; A light smooth pulley keeps one tension and only turns the string — answering the lesson's questions from the lesson text.
This lesson has 3 sub lessons, proved in order: each opens by proving the previous one. Practice deepens inside each part before the learner moves on — restating each part in the learner's own examples, working its numbers, and checking new cases against it until the teaching is the learner's own.
