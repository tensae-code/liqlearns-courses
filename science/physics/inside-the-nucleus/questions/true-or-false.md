# Inside the nucleus — true or false

Say if each one is true or false.

**1. The atom's tiny dense core holds protons and neutrons (nucleons); notation A/Z X, isotopes as same-Z different-N family members, and nuclear radius growing with the cube root of A (R ≈ 1.2 fm × A^⅓).**
**Answer: True**

**2. The atom's tiny dense core holds protons and neutrons (nucleons); notation A/Z X, isotopes as same-Z different-N family members, and nuclear radius growing with the cube root of A (R ≈ 2.4 fm × A^⅓).**
**Answer: False**
