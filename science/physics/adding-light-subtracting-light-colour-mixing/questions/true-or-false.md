# Adding light, subtracting light — colour mixing — true or false

Say if each one is true or false.

**1. (Sub lesson 1)** Additive: R+G = yellow, G+B = cyan, B+R = magenta, R+G+B = white.
**Answer: True**

**2. (Sub lesson 2)** Subtractive primaries cyan, magenta, yellow each absorb one light primary.
**Answer: True**

**3. (Sub lesson 1)** Mixing all paints gives white, like mixing all lights.
**Answer: False**
