# Power — how fast work is done

## Do it first
Carry the same bag up the same steps twice — walking, then briskly — timing both. Same work, different power: calculate both.

[Picture 21835 — two pupils carrying the same load upstairs — one running, one walking, with a clock]

## Power — how fast work is done — the teaching
Power is the rate of doing work: P = W/t, work divided by the time it takes, measured in watts (W). Two pupils can carry the same load upstairs — the same work — but the one who runs does it in less time and so has the greater power. Machines are judged the same way: a powerful engine is not just strong, it does its work fast.

**Keep the formula:** P = W / t

## The key ideas

- Power P = W/t, measured in watts.
- Same work in less time means more power.
- Power joins force ideas to time — fast work, not just work.

## Say it to your companion
Explain power — how fast work is done to your companion in your own words. Use the key ideas above, give one example from your own home or street, and finish with the hardest point — the one you would have got wrong before this lesson. If your companion can repeat the main idea back to you, the lesson has landed.
