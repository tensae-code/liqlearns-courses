# The six simple machines — and compound machines — true or false

Say if each one is true or false.

**1.** Inclined-plane family: inclined plane, wedge, screw.
**Answer: True**

**2.** Lever family: lever, wheel and axle, pulley.
**Answer: True**

**3.** There are six families of simple machines, one per machine.
**Answer: False**
