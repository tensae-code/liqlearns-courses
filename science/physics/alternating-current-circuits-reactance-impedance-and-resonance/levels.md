# Alternating-current circuits — reactance, impedance and resonance — depth

Whole-lesson pass mark: the learner can do all of these — Describe an alternator's output and use RMS versus peak correctly; Compute X_C and X_L and state each one's phase and frequency behaviour; Compute Z for a series RLC circuit and the current it draws; Compute a resonance frequency and explain resonance's uses and hazards — answering the lesson's questions from the lesson text.
This lesson has 3 sub lessons, proved in order: each opens by proving the previous one. Practice deepens inside each part before the learner moves on — restating each part in the learner's own examples, working its numbers, and checking new cases against it until the teaching is the learner's own.
