# Prefixes, scientific notation and significant figures — true or false

Say if each one is true or false.

**1.** Kilo means 10³ and milli means 10⁻³.
**Answer: True**

**2.** Scientific notation writes a number as a value between 1 and 10 times a power of ten.
**Answer: True**

**3.** Milli means a thousand times bigger.
**Answer: False**
