# Static electricity — preventing it and putting it to work — depth

Whole-lesson pass mark: the learner can do all of these — Static charge discharges all at once when it finds a path — a spark that can ignite fuel vapour or kill a chip; Prevention: earth straps on tankers and workers, conductive floors, humidity, lightning rods — drain charge continuously, give it a chosen path; Uses: electrostatic copying (toner to a charged drum), spraying (charged droplets seek the earthed work), precipitators (smoke particles charged and collected); One rule prices both faces: control where charge gathers, and choose the path it will take — answering the lesson's questions from the lesson text.
This lesson has 3 sub lessons, proved in order: each opens by proving the previous one. Practice deepens inside each part before the learner moves on — restating each part in the learner's own examples, working its numbers, and checking new cases against it until the teaching is the learner's own.
