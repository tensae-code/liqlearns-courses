# Resistors in series and parallel — true or false

Say if each one is true or false.

**1. (Sub lesson 1)** Series: resistances add, current the same, voltage divides.
**Answer: True**

**2. (Sub lesson 2)** Parallel: reciprocals add, voltage the same, current divides.
**Answer: True**

**3. (Sub lesson 3)** Resistances in parallel always give a bigger equivalent resistance.
**Answer: False**
