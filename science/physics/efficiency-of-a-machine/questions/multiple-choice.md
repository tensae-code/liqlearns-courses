# Efficiency of a machine — multiple choice

Pick the one right answer.

**1.** (Sub lesson 1) Efficiency is defined as…
a) Input ÷ useful output  b) Useful output ÷ total input  c) Wasted output ÷ input  d) Input − output
**Answer: b) Useful output ÷ total input**

**2.** (Sub lesson 1) Input 200 J, wasted 50 J. The efficiency is…
a) 25%  b) 50%  c) 75%  d) 125%
**Answer: c) 75%**

**3.** (Sub lesson 2) A 60%-efficient system must lift a load needing 300 J of useful work. The input needed is…
a) 180 J  b) 300 J  c) 500 J  d) 360 J
**Answer: c) 500 J**

**4.** (Sub lesson 2) Efficiency can also be computed from…
a) Masses  b) Powers over the same time — useful power out ÷ total power in  c) Forces alone  d) Distances alone
**Answer: b) Powers over the same time — useful power out ÷ total power in**

**5.** (Sub lesson 3) The main cause of wasted work in school machines is…
a) Gravity  b) Friction, turning work into heat  c) The load's weight  d) Sound only
**Answer: b) Friction, turning work into heat**

**6.** (Sub lesson 3) An efficiency calculated as 130% means…
a) An excellent machine  b) Energy is being created  c) An error in the calculation — efficiency cannot exceed 100%  d) The machine is an engine
**Answer: c) An error in the calculation — efficiency cannot exceed 100%**
