# Resistivity and how resistance changes with temperature — multiple choice

Pick the one right answer.

**1.** (Sub lesson 1) Resistivity is a property of…
a) The particular wire specimen  b) The material  c) The battery  d) The question has no answer
**Answer: b) The material**

**2.** (Sub lesson 1) Doubling a wire's length at fixed area…
a) Halves it  b) Doubles its resistance  c) Leaves it  d) The question has no answer
**Answer: b) Doubles its resistance**

**3.** (Sub lesson 1) The unit of resistivity is…
a) The ohm per metre  b) The ohm-metre (Ω·m)  c) The volt  d) The question has no answer
**Answer: b) The ohm-metre (Ω·m)**

**4.** (Sub lesson 2) A metal's resistivity with temperature…
a) Falls steeply  b) Rises, roughly linearly  c) Never changes  d) The question has no answer
**Answer: b) Rises, roughly linearly**

**5.** (Sub lesson 2) Bulbs fail at switch-on because cold filaments have…
a) High resistance  b) Low resistance, so the surge current is large  c) No resistance path  d) The question has no answer
**Answer: b) Low resistance, so the surge current is large**

**6.** (Sub lesson 3) A semiconductor's resistivity with temperature…
a) Rises like a metal's  b) Falls steeply as carriers are freed  c) Is always zero  d) The question has no answer
**Answer: b) Falls steeply as carriers are freed**
