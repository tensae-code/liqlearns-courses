# Adding vectors by drawing — triangle and parallelogram — multiple choice

Pick the one right answer.

**1.** In the triangle method, where does the resultant start and end?
a) From the first vector's tail to the last vector's head.  b) The diagonal from the vectors' common starting point.  c) Reverse B and add it (add the negative vector).  d) So measuring the resultant gives true magnitude.
**Answer: a) From the first vector's tail to the last vector's head.**

**2.** In the parallelogram method, the resultant is the — ?
a) From the first vector's tail to the last vector's head.  b) The diagonal from the vectors' common starting point.  c) Reverse B and add it (add the negative vector).  d) So measuring the resultant gives true magnitude.
**Answer: b) The diagonal from the vectors' common starting point.**

**3.** How do you subtract vector B by drawing?
a) From the first vector's tail to the last vector's head.  b) The diagonal from the vectors' common starting point.  c) Reverse B and add it (add the negative vector).  d) So measuring the resultant gives true magnitude.
**Answer: c) Reverse B and add it (add the negative vector).**

**4.** Why must the drawing be to scale?
a) From the first vector's tail to the last vector's head.  b) The diagonal from the vectors' common starting point.  c) Reverse B and add it (add the negative vector).  d) So measuring the resultant gives true magnitude.
**Answer: d) So measuring the resultant gives true magnitude.**
