# Adding vectors by drawing — triangle and parallelogram — true or false

Say if each one is true or false.

**1.** Triangle method: nose-to-tail; resultant from first tail to last head.
**Answer: True**

**2.** Parallelogram method: resultant is the diagonal from the common start.
**Answer: True**

**3.** In the triangle method the vectors are drawn from the same point.
**Answer: False**
