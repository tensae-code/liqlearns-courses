# Pendulum and spring — timing oscillations — true or false

Say if each one is true or false.

**1. (Sub lesson 1)** Pendulum period T = 2π√(l/g) — set by length, not by the bob's mass.
**Answer: True**

**2. (Sub lesson 2)** A pendulum can measure local g: g = 4π²l/T².
**Answer: True**

**3. (Sub lesson 1)** A heavier pendulum bob swings with a longer period.
**Answer: False**
