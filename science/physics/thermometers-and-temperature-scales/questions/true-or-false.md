# Thermometers and temperature scales — including making your own — true or false

Say if each one is true or false.

**1. (Sub lesson 1)** A thermometer uses a thermometric property that changes with heat.
**Answer: True**

**2. (Sub lesson 2)** Celsius fixed points: ice 0 °C, steam 100 °C; Fahrenheit: 32 °F and 212 °F.
**Answer: True**

**3. (Sub lesson 3)** Any marks on a tube make a thermometer, fixed points or not.
**Answer: False**
