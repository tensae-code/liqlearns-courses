# How this Physics course works — the Ethiopian Grade 10 way — multiple choice

Pick the one right answer.

**1.** How many units does the Grade 10 Physics course have, and what is the last one?
a) Five — Electronics  b) Six — Electromagnetic Waves and Geometrical Optics  c) Seven — Temperature  d) Six — Magnetism
**Answer: b) Six — Electromagnetic Waves and Geometrical Optics**

**2.** What closes every Grade 10 unit?
a) A field trip  b) Virtual Labs — named PhET simulations  c) A written exam only  d) Nothing
**Answer: b) Virtual Labs — named PhET simulations**

**3.** Which of these is a PhET simulation named in the book?
a) Bending Light  b) Virtual Farming  c) Word Processor  d) Map Maker
**Answer: a) Bending Light**

**4.** Which unit comes first in Grade 10?
a) Magnetism  b) Uniformly Accelerated Motion  c) Vector Quantities  d) Elasticity
**Answer: c) Vector Quantities**

**5.** What is the correct lesson staging order?
a) Closure → Starting Off → Input  b) Starting Off → Input and Model → Guided Practice → Check for Understanding → Where next → Closure  c) Guided Practice → Closure → Starting Off  d) Check first, then Starting Off
**Answer: b) Starting Off → Input and Model → Guided Practice → Check for Understanding → Where next → Closure**

**6.** The Grade 10 framing is best described as…
a) Memorise-only  b) Competency-based and learner-centred — knowledge, values/attitudes and skills  c) Laboratory-only  d) Teacher-centred lecturing
**Answer: b) Competency-based and learner-centred — knowledge, values/attitudes and skills**
