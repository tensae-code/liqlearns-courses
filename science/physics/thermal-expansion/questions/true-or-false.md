# Thermal expansion — things grow when heated — true or false

Say if each one is true or false.

**1.** Linear expansion: ΔL = αL₀ΔT.
**Answer: True**

**2.** Liquids and gases expand more than solids; a heated hole expands as if solid.
**Answer: True**

**3.** When a metal ring is heated, its hole shrinks.
**Answer: False**
