# Average velocity and instantaneous velocity — true or false

Say if each one is true or false.

**1. (Sub lesson 1)** Average velocity = displacement ÷ time, with direction.
**Answer: True**

**2. (Sub lesson 2)** A round trip back to the start gives zero average velocity.
**Answer: True**

**3. (Sub lesson 1)** A round trip gives zero average speed as well as zero average velocity.
**Answer: False**
