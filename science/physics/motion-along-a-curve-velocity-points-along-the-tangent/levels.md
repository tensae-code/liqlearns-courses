# Motion along a curve — velocity points along the tangent — depth

Whole-lesson pass mark: the learner can do all of these — On a curved path, the velocity at each instant points along the tangent to the curve at that point; A released whirling object flies off along the tangent — sparks, mud and water drops all show it; A path curves exactly when the net force has a component across the velocity; the along-component changes only the speed; Force and velocity generally point differently on a curve: the pull can point inward while the velocity points along — answering the lesson's questions from the lesson text.
This lesson has 3 sub lessons, proved in order: each opens by proving the previous one. Practice deepens inside each part before the learner moves on — restating each part in the learner's own examples, working its numbers, and checking new cases against it until the teaching is the learner's own.
