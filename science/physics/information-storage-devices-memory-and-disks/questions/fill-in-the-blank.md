# Information storage devices — memory and disks — fill in the blank

Fill each blank with the missing word or words.

**1.** (Sub lesson 1) The processor's fast, close storage is ___ memory.
**Answer:** primary

**2.** (Sub lesson 1) RAM is emptied when the ___ dies.
**Answer:** power

**3.** (Sub lesson 2) Hard disks write patterns of ___ on platters.
**Answer:** magnetisation

**4.** (Sub lesson 3) Flash storage has no ___ parts.
**Answer:** moving
