# Information storage devices — memory and disks — short answer

Answer in a sentence or two.

**1.** (Sub lesson 1) What is primary memory for?
**Answer:** Holding what the processor is working on now — fast access, not permanent keeping.

**2.** (Sub lesson 2) How is a hard disk read?
**Answer:** Read-write heads sense the magnetisation pattern of the spinning platters.

**3.** (Sub lesson 3) Why do flash drives suit carrying files between machines?
**Answer:** They are small, solid-state (nothing to spin or scratch) and plug in anywhere.

**4.** (Sub lesson 3) What risk does keeping a file in exactly one place carry?
**Answer:** If that device fails, is lost or is left behind, the information is gone.
