# Video script — Information storage devices — memory and disks

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Today: **information must live somewhere between uses**. Primary memory is the storage the processor works on directly: fast, close, and — for RAM — emptied when the power dies. Then the lesson builds its three parts in order — primary memory — the machine's own desk; magnetic disks — the hard disk and its ancestors; flash drives — storage with no moving parts — each one first met in the hand, then said in words.

Now you. Say it back — in your own words.
