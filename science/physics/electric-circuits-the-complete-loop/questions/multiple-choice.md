# Electric circuits — the complete loop — multiple choice

Pick the one right answer.

**1.** Name the four parts of a basic circuit.
a) Source, conductors, load, control (switch).  b) Current stops everywhere — the circuit is open.  c) Standard symbols let anyone rebuild the same circuit exactly.  d) Closed again — the loop is complete.
**Answer: a) Source, conductors, load, control (switch).**

**2.** A wire is disconnected at one point. What happens?
a) Source, conductors, load, control (switch).  b) Current stops everywhere — the circuit is open.  c) Standard symbols let anyone rebuild the same circuit exactly.  d) Closed again — the loop is complete.
**Answer: b) Current stops everywhere — the circuit is open.**

**3.** Why do diagrams use symbols instead of drawings?
a) Source, conductors, load, control (switch).  b) Current stops everywhere — the circuit is open.  c) Standard symbols let anyone rebuild the same circuit exactly.  d) Closed again — the loop is complete.
**Answer: c) Standard symbols let anyone rebuild the same circuit exactly.**

**4.** The lamp in a series loop is removed and the wires joined. The circuit is — ?
a) Source, conductors, load, control (switch).  b) Current stops everywhere — the circuit is open.  c) Standard symbols let anyone rebuild the same circuit exactly.  d) Closed again — the loop is complete.
**Answer: d) Closed again — the loop is complete.**
