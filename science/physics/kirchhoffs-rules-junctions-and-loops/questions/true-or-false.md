# Kirchhoff's rules — junctions and loops — true or false

Say if each one is true or false.

**1. (Sub lesson 1) Junction rule: currents into a junction equal currents out (charge conservation).**
**Answer: True**

**2. (Sub lesson 1) Junction rule: currents into a junction unequal currents out (charge conservation).**
**Answer: False**

**3. (Sub lesson 1) Loop rule: voltages around any closed loop sum to zero (energy conservation).**
**Answer: True**

**4. (Sub lesson 2) A five-step routine (label branches, apply junction rule, apply loop rule, solve) is worked on multi-loop circuits.**
**Answer: True**
