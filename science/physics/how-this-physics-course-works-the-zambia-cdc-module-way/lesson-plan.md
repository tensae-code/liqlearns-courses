# Lesson plan — How this Physics course works — the Zambia CDC module way

**Course:** Science · **Title:** Physics · **Lesson:** How this Physics course works — the Zambia CDC module way
**Place in the curriculum:** Physics — Course opening (Zambia CDC module band, CURRICULUM.md).
**The one thing this lesson teaches:** Zambia's CDC teaches physics one syllabus topic per term-book, in a Teaching Module written for teachers: the module opens with a scope and sequence, then runs learning activities learners build themselves, checked by formative checks, unit tests, projects and practical assessments.
**This lesson's own level:** it stands on nothing but the learner's own world — it is a map of how the Zambia module itself works, and a learner can land here directly and follow it. The lesson stands on teacher-module evidence only (see lesson/sources.md).

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. Images follow the picture rule (a real photograph, or real art, with its source). GIFs come first where a thing must be shown moving or popping — a GIF here is 1–2 seconds.

## Sub lessons
This lesson is one whole lesson — it has no sub lessons (a short, single-skill lesson; his ruling 2026-11-09).

## Before this lesson
- Recommended first: any other "How this Physics course works" lesson in this course. Recommended, never forced.

## What the learner can do when it ends
1. The Zambia CDC module is a Teaching Module for teachers — one term-book carrying one syllabus topic (the Form 1 Term 3 module carries Topic 5, Mechanics 1).
2. The module opens with front matter: a scope and sequence that lays out what is taught, in what order, across the term.
3. Learning runs through activities learners build themselves — for example designing tools that use moments.
4. Assessment is designed in from the start: formative checks as you learn, plus unit tests, projects and practical assessments.
5. Answer the lesson's questions from the lesson text alone.

## What you need
Paper and a pencil; the hands-on items in hands-on.md. Nothing else.

## The run of the lesson (in order)
1. **Do it first** — the learner studies the lesson picture and says what it shows before any explanation (lesson/lesson.md).
2. **The explanation** — the lesson's parts, in order (lesson/lesson.md).
   - ADD IMAGE: a picture of one term-book standing for one topic — a single book labelled "Form 1, Term 3 — Topic 5: Mechanics 1", with its six sub-topic stops drawn as a short road inside the cover: scalar and vector quantities, linear motion, forces, circular motion, moment of a force, and a crossed-out stop marked "equilibrium — taught in module 1" — the student studies it and names the stops in order.
   - ADD GIF: a 1–2 second GIF of a learner-built moment tool — a simple lever the learner made lifting a load as its long arm is pressed down — the student watches the tool do the lifting the module's activity designs ask learners to build.
   - ADD AUDIO (described slot only — no audio file is made in this build): a voice reading the lesson's key ideas aloud — the student listens, then repeats each one aloud from memory.
3. **Say it to your companion** — the learner explains the lesson's main ideas in their own words (lesson/lesson.md).
   - ADD VIDEO: the script in video-script.md, filmed — the lesson told in the super-simple voice (made later, when videos are made).
4. **Questions** — from questions/: multiple-choice, short-answer and fill-in-the-blank — served at the learner's level and teaching-mix (levels.md).
5. **Hands-on** — hands-on.md.
6. **Do It Yourself** — the doing block at the end of lesson/lesson.md.
