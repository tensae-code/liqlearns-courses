# How this Physics course works — the Zambia CDC module way

## Do it first
Before you read: look at the picture for this lesson — one book, one topic. The book is labelled "Form 1, Term 3 — Topic 5: Mechanics 1", and inside its cover a short road runs through six stops. Say out loud what you think each stop is about, and guess why one stop is crossed out. Then read on and check your guesses.

## One topic per term-book

Zambia's Curriculum Development Centre (CDC) teaches physics in **Teaching Modules** — books written for teachers, one for each term. Each module carries **one syllabus topic**. The Form 1 Term 3 module carries **Topic 5 — Mechanics 1**, in six sub-topics, in this order: **scalar and vector quantities; linear motion; forces; circular motion; moment of a force** — and one stop that is deliberately left out: **equilibrium is not covered in this module, because it was covered in module 1**. One topic, taught whole, in one term — that is the module way: nothing is spread thin across the year, and nothing already taught is taught again.

## The front matter — scope and sequence first

Before the teaching starts, the module's front matter lays out the **scope and sequence**: what will be taught, and in what order, across the term. A teacher opening the module can see the whole term's journey on the opening pages — which sub-topic comes first, which follows, and where the topic ends. The plan comes before the lessons, printed where everyone can check it.

## Learning by building

The module does not only tell. Its **learning activities** are designs learners build themselves — for example, **designing tools that use moments**, so the principle of moments is learned by making a tool that works by it. Worked teaching notes support the teacher through each activity. The Zambian way, in this module, is: build the thing, then name the physics it uses.

## Assessment is designed in

Checking is part of the module's design, not an afterthought. As learning goes on there are **formative checks** — small checks that show what has landed and what has not, while there is still time to fix it. The module's assessment guidance also provides for **unit tests, projects and practical assessments** — the summative side, where the term's learning is gathered and judged. Formative first, summative at the close: that rhythm is printed into the module itself.

## The key ideas

- The Zambia CDC module is a Teaching Module for teachers — one term-book carrying one syllabus topic (Form 1 Term 3 carries Topic 5, Mechanics 1).
- The module opens with front matter: a scope and sequence laying out what is taught, in what order.
- Learning runs through activities learners build themselves — for example designing tools that use moments.
- Assessment is designed in: formative checks as you learn, plus unit tests, projects and practical assessments.
- Equilibrium is expressly not in this module — it was covered in module 1.
