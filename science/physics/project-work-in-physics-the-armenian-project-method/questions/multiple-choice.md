# Project work in physics — the Armenian project method — multiple choice

Pick the one right answer.

**1.** (Sub lesson 1) The essence of the project method is…
a) A longer homework  b) Learning organised around a task learners carry from question to presented result, with real choices  c) Copying a model answer  d) A poster competition
**Answer: b) Learning organised around a task learners carry from question to presented result, with real choices**

**2.** (Sub lesson 2) The first step of a project is…
a) Presenting  b) Choosing a topic that can genuinely be investigated  c) Buying materials  d) Writing the conclusion
**Answer: b) Choosing a topic that can genuinely be investigated**

**3.** (Sub lesson 2) A plan for a project must say…
a) Only the title  b) What will be measured, built or compared, and how  c) The mark desired  d) Who presents first
**Answer: b) What will be measured, built or compared, and how**

**4.** (Sub lesson 3) Inside project work the teacher…
a) Disappears  b) Guides: frames questions, checks feasibility and safety, supplies resources, coaches, assesses  c) Does the work to save time  d) Only marks at the end
**Answer: b) Guides: frames questions, checks feasibility and safety, supplies resources, coaches, assesses**

**5.** (Sub lesson 2) Sample topics are printed in the guides so that…
a) Pupils never choose  b) The first choice is never a blank page — later projects can range freer  c) All classes do identical projects  d) Topics need not be investigable
**Answer: b) The first choice is never a blank page — later projects can range freer**

**6.** (Sub lesson 1) Project work appears in guides for…
a) Grade 8 only  b) Every grade, 8–12 — the method is grade-independent  c) Grade 12 only  d) No grades; it is an appendix myth
**Answer: b) Every grade, 8–12 — the method is grade-independent**
