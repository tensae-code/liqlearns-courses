# Lesson plan — Project work in physics — the Armenian project method

**Course:** Science · **Title:** Physics · **Lesson:** Project work in physics — the Armenian project method
**Place in the curriculum:** Physics (CURRICULUM.md Unit 18), inside the teaching-way strand — the educational-project chapter carried by every Armenian methodological guide (Grades 8–12) (teacher-guide evidence)
**The one thing this lesson teaches:** each Armenian guide carries a chapter on educational project work: pupils take a real question, plan their own route to its answer in steps, do the work over time, and present what they found — with the teacher's functions named at every stage — because some physics is only learned by carrying an investigation of your own (teacher-guide evidence only)
**This lesson's own level:** it stands on its own — a learner can land here directly. Any earlier lesson named below is recommended first, never forced

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. Images follow the picture rule (a real photograph, or real art, with its source). GIFs come first where a thing must be shown moving or popping — a GIF here is 1–2 seconds.

## Sub lessons
1. **What project work is — the essence** — The guides define the project method by its essence: learning organised around a task the learners carry from question to presented result, over days or weeks, with real choices in their hands. It sits in every grade's guide because the method is grade-independent: a Grade 8 project on insulating a box and a Grade 12 project on a home-made instrument are the same species — an owned question, a plan, evidence, a public answer.
2. **The steps — from topic choice to presentation** — The guides walk the steps in order: choosing a topic that is genuinely investigable; planning (what will be measured, built or compared, and how); carrying out the work, with the plan revised when the evidence demands; and presenting the result to an audience that can question it. Sample project topics are printed in the guides so the first choice is never a blank page, and the steps are taught, not assumed — a first project is scaffolded, later ones are freer.
3. **The teacher's functions — guide, not ghost** — The method does not retire the teacher; it re-deploys them. The guides name the teacher's functions inside project work: helping frame a question small enough to answer, checking plans for safety and feasibility, supplying resources and deadlines, coaching through stalls, and assessing both the product and the process. Pupil ownership with teacher structure — that balance, stated in the chapter, is what separates the Armenian project method from both a lecture and a free-for-all.
Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
