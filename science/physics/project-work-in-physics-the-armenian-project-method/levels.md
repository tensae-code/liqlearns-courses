# Project work in physics — the Armenian project method — depth

Whole-lesson pass mark: the learner can do all of these — The guides define the project method by its essence: learning organised around a task the learners carry from question to presented result, over days or weeks, with real choices in their hands; The guides walk the steps in order: choosing a topic that is genuinely investigable; planning (what will be measured, built or compared, and how); carrying out the work, with the plan revised when the evidence demands; and presenting the result to an audience that can question it; The method does not retire the teacher; it re-deploys them — answering the lesson's questions from the lesson text.
This lesson has 3 sub lessons, proved in order: each opens by proving the previous one. Practice deepens inside each part before the learner moves on — restating each part in the learner's own examples, working its numbers, and checking new cases against it until the teaching is the learner's own.
