# Hands-on — XOR and XNOR gates — from basic gates

The lesson with your hands and your feet, not only your eyes.

## Build both gates from basic gate chips (or a logic simulator)
Build both gates from basic gate chips (or a logic simulator): wire XOR as (A·B̄) + (Ā·B), verify all four rows of its truth table with switches and an LED, then add a NOT for XNOR and verify its table is exactly inverted. Finish by wiring the two as a one-bit comparator and testing every input pair.
