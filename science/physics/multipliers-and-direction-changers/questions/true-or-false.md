# Multipliers and direction changers — true or false

Say if each one is true or false.

**1.** Force multiplier: load > effort, but the load moves less.
**Answer: True**

**2.** Speed multiplier: load moves farther/faster than the effort.
**Answer: True**

**3.** A force multiplier also makes the load move farther than the effort.
**Answer: False**
