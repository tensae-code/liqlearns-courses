# Sources of light: lamps people make and light from nature — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1) A fanos is a light source people make.**
**Answer: True**

**2. (Sub lesson 2) The moon is a human-made source.**
**Answer: False**

**3. (Sub lesson 1) A candle is a human-made source of light.**
**Answer: True**
