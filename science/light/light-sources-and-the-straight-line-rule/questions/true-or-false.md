# Light — sources, and the straight-line rule — true or false

Say true or false.

**1. (Sub lesson 1)** A mirror is a luminous body because it shines brightly.
**Answer: False**

**2. (Sub lesson 2)** Light can bend around a card to reach the eye.
**Answer: False**

**3. (Sub lesson 2)** A taut string is used in the experiment to line the holes up straight.
**Answer: True**
