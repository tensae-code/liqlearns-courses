# Bioluminescence — living things that glow — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1) Some living things make their own light.**
**Answer: True**

**2. (Sub lesson 1) Bioluminescence is light from a human-made lamp.**
**Answer: False**

**3. (Sub lesson 1) A glowing living thing is a natural light source.**
**Answer: True**
