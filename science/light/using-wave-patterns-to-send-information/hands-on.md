# Hands-on — Using wave patterns to send information

The lesson with your hands and your feet, not only your eyes.

## Flash a code
Agree a simple code with a partner — short and long flashes for a few letters. Send a three-letter word by torch or by covering and uncovering a lamp, and have your partner decode it.

## Design for distance
Name an information-transfer problem — across a playground, between boats, in a noisy hall. Design the wave-pattern solution: which wave, which code, and how the receiver reads it.
