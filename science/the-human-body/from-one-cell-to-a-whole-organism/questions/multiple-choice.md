# Cells — from one cell to a whole organism — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** An amoeba is —
a) multicellular  b) unicellular — one cell  c) not alive
**Answer: b) unicellular — one cell**

**2. (Sub lesson 1)** In a unicellular organism, the one cell —
a) only moves  b) does everything: moves, feeds, reproduces  c) does nothing alone
**Answer: b) does everything: moves, feeds, reproduces**

**3. (Sub lesson 2)** The correct order of levels is —
a) organ → cell → tissue  b) cell → tissue → organ → system → organism  c) tissue → cell → organism
**Answer: b) cell → tissue → organ → system → organism**

**4. (Sub lesson 2)** A tissue is —
a) one cell  b) specialised cells working together  c) a whole organ system
**Answer: b) specialised cells working together** — e.g. liver tissue.

**5. (Sub lesson 2)** Heart + blood + blood vessels together form —
a) an organ  b) a tissue  c) the circulatory system
**Answer: c) the circulatory system** — an organ system.

**6. (Sub lesson 2)** A leaf is an example of —
a) a tissue  b) an organ  c) a cell
**Answer: b) an organ** — in a plant.
