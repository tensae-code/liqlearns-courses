# Smart prosthetic limbs — technology that helps the body — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1) A prosthetic limb is made by people.**
**Answer: True**

**2. (Sub lesson 1) A prosthetic limb is a limb that grew on the body.**
**Answer: False**

**3. (Sub lesson 1) A smart prosthetic limb uses technology to help the body.**
**Answer: True**
