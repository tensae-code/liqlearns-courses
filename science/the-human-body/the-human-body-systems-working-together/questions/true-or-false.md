# The human body — systems working together — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** An organ and a system are the same thing.
**Answer: False** — an organ is one part; a system is organs working together on one job.

**2. (Sub lesson 2)** The reproductive system is one of the seven systems in this unit.
**Answer: True**

**3. (Sub lesson 3)** Each body system works completely alone, never affecting the others.
**Answer: False** — the systems work together; a failure in one is felt in the others.
