# Measuring biodiversity — the Simpson index — multiple choice

Pick the one right answer.

**1.** On the Simpson index, more diverse means…
a) nearer 0  b) nearer 1  c) exactly 0.5  d) over 2  
**Answer: b) nearer 1**

**2.** Region A 0.78 vs region B 0.54: the more diverse is…
a) region B  b) neither  c) region A  d) they are equal  
**Answer: c) region A**

**3.** An index is used because biodiversity comparison needs…
a) names only  b) one number reading variety and balance together  c) photographs  d) maps  
**Answer: b) one number reading variety and balance together**
