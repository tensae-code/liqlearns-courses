# Putting things in order — sequence — short answer

Answer in a sentence or two.

**1.** (Sub lesson 1) Say what ordering decides, in the Grade 1 book's own words.
**Answer: What comes first, second and last.**

**2.** (Sub lesson 2) How do you check an order by size is right?
**Answer: Check every two neighbours: the size rule must hold between each pair; if it breaks anywhere, the order is not finished.**

**3.** (Sub lesson 1) A friend mixes ordering with classifying. Correct them in one sentence.
**Answer: Classifying groups similar things together; ordering decides the sequence things follow one another in.**
