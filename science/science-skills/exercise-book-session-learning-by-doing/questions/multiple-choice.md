# Exercise-book sessions — learning by doing — multiple choice

Pick the one right answer.

**1.** (Sub lesson 1) This sub lesson is mainly about…
a) A book of sessions, not readings  b) A topic from a different lesson  c) Nothing in this lesson  d) Only the questions page
**Answer: a) A book of sessions, not readings**

**2.** (Sub lesson 2) This sub lesson is mainly about…
a) Done, written, checked  b) A topic from a different lesson  c) Nothing in this lesson  d) Only the questions page
**Answer: a) Done, written, checked**

**3.** (Sub lesson 3) This sub lesson is mainly about…
a) Bangladesh's own way at this level  b) A topic from a different lesson  c) Nothing in this lesson  d) Only the questions page
**Answer: a) Bangladesh's own way at this level**

**4.** (Whole lesson) This lesson teaches one thing: the Exercise Book's own form: every unit is a set of sessions done, written and checked, not read — Bangladesh's own way of teaching science at this level. That is…
a) True, in the sub lessons' own order  b) False  c) Only in the video  d) Not in the book cited
**Answer: a) True, in the sub lessons' own order**

**5.** (Whole lesson) The book behind this lesson is…
a) Bangladesh, Grade 6 — *Science Exercise Book Class 6*, printed p. 1  b) A book from another country  c) No book — it is uncited  d) A teacher guide only
**Answer: a) Bangladesh, Grade 6 — *Science Exercise Book Class 6*, printed p. 1**
