Today: **Scratch — first steps** — Bangladesh's way, from its book (Bangladesh, Grade 4 — *Elementary Science Class 4*, printed p. 94).

Scratch is a place for building programs from blocks. Its figures are sprites, its scenery is the backdrop, and its editor has three working parts: the code area, the script area, and the stage where the program plays. The blocks themselves come in nine types.
A first program is small: blocks joined so that a sprite moves when the green flag is clicked. Class 4 stops there — one sprite, one click, one movement — because a program, however big, is block-codes arranged logically to solve a problem.
Class 5 builds a complete program: the greater-number finder, step by step, with variables (Number 1, Number 2), ask-and-answer input, an if–else control block and a comparison operator — the blocks at work in a program that answers.
