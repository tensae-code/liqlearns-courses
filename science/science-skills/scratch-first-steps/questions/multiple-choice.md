# Scratch — first steps — multiple choice

Pick the one right answer.

**1.** (Sub lesson 1) This sub lesson is mainly about…
a) Sprites, backdrops and the editor  b) A topic from a different lesson  c) Nothing in this lesson  d) Only the questions page
**Answer: a) Sprites, backdrops and the editor**

**2.** (Sub lesson 2) This sub lesson is mainly about…
a) A first program — the green flag  b) A topic from a different lesson  c) Nothing in this lesson  d) Only the questions page
**Answer: a) A first program — the green flag**

**3.** (Sub lesson 3) This sub lesson is mainly about…
a) Taken further — the greater-number finder  b) A topic from a different lesson  c) Nothing in this lesson  d) Only the questions page
**Answer: a) Taken further — the greater-number finder**

**4.** (Whole lesson) This lesson teaches one thing: Scratch — sprites and backdrops, the editor's code area, script area and stage, and a first program that moves a sprite when the green flag is clicked — taken further in Class 5 with the greater-number finder. That is…
a) True, in the sub lessons' own order  b) False  c) Only in the video  d) Not in the book cited
**Answer: a) True, in the sub lessons' own order**

**5.** (Whole lesson) The book behind this lesson is…
a) Bangladesh, Grade 4 — *Elementary Science Class 4*, printed p. 94  b) A book from another country  c) No book — it is uncited  d) A teacher guide only
**Answer: a) Bangladesh, Grade 4 — *Elementary Science Class 4*, printed p. 94**
