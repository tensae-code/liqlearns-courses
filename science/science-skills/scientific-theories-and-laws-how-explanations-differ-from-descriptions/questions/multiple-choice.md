# Scientific theories and laws — how explanations differ from descriptions — multiple choice

Pick the one right answer.

**1.** A scientific theory is…
a) a mere guess  b) a tried explanation of a pattern noticed again and again  c) a law that passed a vote  d) an opinion  
**Answer: b) a tried explanation of a pattern noticed again and again**

**2.** Can a scientific theory change?
a) Never  b) Only once  c) Yes — it stays open to change  d) Only if a law allows it  
**Answer: c) Yes — it stays open to change**

**3.** Set against a theory, a law…
a) explains  b) describes  c) guesses  d) changes first  
**Answer: b) describes**
