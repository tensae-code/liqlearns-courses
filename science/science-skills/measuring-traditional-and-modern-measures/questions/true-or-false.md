# Measuring: traditional and modern measures — true or false

Say if each one is true or false.

**1. A kend is the same length for every seller.**
**Answer: False**

**2. Footsteps were used to measure length.**
**Answer: True**

**3. Modern instruments give one measure for everyone.**
**Answer: True**

**4. A hand span gives the same length for every measurer.**
**Answer: False** — it varies person to person; that is the fault the standard fixes.

**5. Kilometres fit the Bahir Dar to Gondar road better than millimetres.**
**Answer: True** — the unit is fitted to the size.
