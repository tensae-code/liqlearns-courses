# Hands-on — Dimensions of quantities

The lesson with your hands and your feet, not only your eyes.

## Read dimensions off units (paper only)
Write down five quantities you have measured this year, each with its unit (for example: length — metre; time — second; speed — metre per second). For each one, write what its unit is built from, and so what dimension the quantity carries. Mark which are base quantities (their units stand alone) and which are derived (their units are built from others). Your list, sorted that way, is this lesson done by hand.
