# Measurement — scalars, vectors and prefixes — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Velocity is a scalar.
**Answer: False** — velocity needs magnitude and direction

**2. (Sub lesson 2)** A prefix is a multiplier worn by a unit, not a new unit.
**Answer: True** — kilo- means ×10³ wherever it sits

**3. (Sub lesson 1)** Temperature is a scalar.
**Answer: True** — size alone completes it
