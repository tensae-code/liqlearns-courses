# Lesson plan — Measurement — accuracy and precision

**Course:** Science · **Title:** Science Skills · **Lesson:** Measurement — accuracy and precision
**Place in the curriculum:** Unit 1 — Basic Concepts of Science (Grade 7 General Science).
**The one thing this lesson teaches:** accuracy is closeness to the true value; precision is closeness of repeated readings to each other — and a set of readings can be precise yet inaccurate
**This lesson's own level:** it stands on the Grade 7 measuring lessons — the learner can measure length, mass and time; now the quality of measurements themselves is judged

## Before this lesson

## What the learner can do when it ends
1. Define accuracy and precision in one sentence each.
2. Judge the four groups' boiling-water results against the true value, 100 °C.
3. Spot the precise-but-inaccurate set and say what it proves.
4. Diagnose why a tight-but-low set has drifted (a systematic fault, not random scatter).

## What you need

## If the learner is stuck
- Uses the words as twins → accuracy looks OUTWARD to the true value; precision looks INWARD at the set itself. Two different directions of looking.
- Calls Group A "the best" because it is tightest → tight and wrong is the dangerous case: it hides a systematic fault behind confidence.
