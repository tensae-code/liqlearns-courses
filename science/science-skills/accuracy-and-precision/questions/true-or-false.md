# Measurement — accuracy and precision — true or false

Say whether each sentence is true or false.

**1.** Accuracy and precision are the same judgement.
**Answer: False** — two directions of looking

**2.** A scattered set can still centre on the true value on average.
**Answer: True** — scatter hurts precision; the centre can still sit on truth

**3.** Precision alone guarantees the true value was found.
**Answer: False** — Group A is the counterexample
