# Measurement — accuracy and precision — short answer

Answer in a word or a short sentence.

**1.** Define accuracy in one sentence.
**Answer:** Accuracy is how close a measurement (or a set's centre) is to the true value.

**2.** Define precision in one sentence.
**Answer:** Precision is how close repeated readings are to each other.

**3.** What is the true boiling value used in the lesson?
**Answer:** 100 °C.
