# Measurement — accuracy and precision — multiple choice

Pick the one right answer.

**1.** Accuracy means closeness to —
a) each other  b) the true value  c) the biggest reading  d) the first reading
**Answer: b) the true value** — outward, to the truth

**2.** Precision means closeness of —
a) readings to the true value  b) readings to each other  c) the instrument to the table  d) the group to the teacher
**Answer: b) readings to each other** — inward, within the set

**3.** Group A (94, 95, 95, 94) against a true 100 °C is —
a) accurate and precise  b) precise but not accurate  c) accurate but not precise  d) neither
**Answer: b) precise but not accurate** — tight but low

**4.** Group C, centred on 100 °C, shows —
a) accuracy  b) luck only  c) no precision possible  d) a broken thermometer
**Answer: a) accuracy** — its readings centre on the true value

**5.** A tight set that misses the true value suggests —
a) careless single readings  b) a systematic fault in instrument or method  c) perfect measurement  d) that truth moved
**Answer: b) a systematic fault in instrument or method** — every reading pulled the same way

**6.** Can a set be precise yet inaccurate?
a) never  b) yes — Group A proves it  c) only in theory  d) only with digital tools
**Answer: b) yes — Group A proves it** — the lesson's central case
