# Measuring: making and using a balance — true or false

Say if each one is true or false.

**1. String and wood are part of the balance build.**
**Answer: True**

**2. An air-filled bottle has more mass than a water-filled one of the same kind.**
**Answer: False**

**3. The reading of a beam balance is taken while the beam is still swinging wildly.**
**Answer: False** — the reading is the settled, level beam.

**4. A single teff seed can be weighed on an ordinary beam balance alone, exactly.**
**Answer: False** — the book leaves it as a puzzle: too light for the beam alone.
