# Science learning games — multiple choice

Pick the one right answer.

**1.** (Sub lesson 1) Learning games are the closing chapter of…
a) Part 3 of Cambodia's manual (Ch. 6)  b) Part 1  c) the KG core book  d) the Grade 9 book
**Answer: a) Part 3 of Cambodia's manual (Ch. 6)** — Ch. 6 — after analogies and models (Ch. 5).

**2.** (Sub lesson 1) The memory game rehearses…
a) matching what belongs together, from memory  b) running speed  c) handwriting  d) prices
**Answer: a) matching what belongs together, from memory** — Matching from memory — recall played as a game.

**3.** (Sub lesson 1) In a loop game…
a) each answer opens the next question, and the loop must close  b) cards are hidden forever  c) only the teacher plays  d) nothing must match
**Answer: a) each answer opens the next question, and the loop must close** — The closing loop is the game's test of the whole class.

**4.** (Sub lesson 2) A domino game joins…
a) idea to idea by matching ends  b) only pictures  c) only numbers  d) nothing
**Answer: a) idea to idea by matching ends** — Matching ends chain the ideas into one line.

**5.** (Sub lesson 2) The same chapter's worked games teach…
a) the rock cycle and the water cycle  b) fractions  c) spelling  d) map scales
**Answer: a) the rock cycle and the water cycle** — Activities 4 and 5 — the family put to work on two cycles.

**6.** (Sub lesson 2) A loop that will not close shows…
a) exactly which link the class is missing  b) that games are useless  c) that the teacher lost  d) nothing
**Answer: a) exactly which link the class is missing** — The break in the loop is the diagnosis.
