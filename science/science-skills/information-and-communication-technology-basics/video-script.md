Today: **Information and communication technology — the basics** — Bangladesh's way, from its book (Bangladesh, Grade 3 — *Elementary Science Class 3*, printed p. 128).

Information and communication technology — ICT — is the set of tools we use to create, collect, analyse and exchange information. Bangladesh's books name its everyday tools: computer, internet, email, TV, radio and mobile phone.
Class 4 splits ICT into two halves: communication technology, which carries information between people, and recording technology, which keeps information so it can be used again. Every ICT tool does one of these jobs, or both.
Class 5 gives the reason ICT matters: shared information saves lives. A shared warning about flu, or a meteorologist's tidal-surge forecast shared in time, saves lives, boats and cargo — and ICT makes collecting, storing and sharing that information easy.
