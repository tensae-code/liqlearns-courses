Today: **Instructions and code — how machines work** — Bangladesh's way, from its book (Bangladesh, Grade 3 — *Elementary Science Class 3*, printed p. 132).

Humans follow instructions, and so do computers. An instruction tells the follower what to do next; a series of instructions, followed in order, gets a whole job done.
A machine's instructions are called its code, or its commands. The computer does exactly what its code says, in the order the code says it — no more and no less.
Class 4 meets code as blocks: a whole is built by joining blocks in logical order, as in the book's Shahid Minar picture-joining activity — each block in its place, and the whole complete only when the order is right.
