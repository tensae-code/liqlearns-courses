# The scientific method — observe, hypothesise, test, conclude — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** A scientific question should be one that can be answered with the time and resources available.
**Answer: True** — that is the book's test for a workable question

**2. (Sub lesson 2)** A hypothesis formed from earlier reading and others' work is not allowed.
**Answer: False** — a hypothesis may start from prior knowledge and others' work, not only direct observation

**3. (Sub lesson 3)** A theory, once accepted, can never change.
**Answer: False** — a theory is incomplete by nature and evolves as new facts are discovered
