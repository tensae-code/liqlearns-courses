# Fair tests — variables and control groups — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Ideally, only one independent variable is tested in an experiment.
**Answer: True** — all other conditions stay the same — the book's own rule

**2. (Sub lesson 2)** The dependent variable is the one the scientist manipulates.
**Answer: False** — the independent variable is manipulated; the dependent variable is observed and measured

**3. (Sub lesson 2)** Conditions that do not change during an experiment are called constants.
**Answer: True** — constants are the held-still conditions
