# Fair tests — variables and control groups — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The independent variable is —
a) what is measured  b) what the scientist deliberately changes  c) what is held constant  d) the conclusion
**Answer: b) what the scientist deliberately changes** — its effects are what the experiment watches for

**2. (Sub lesson 1)** In the medicine test, blood pressure is —
a) the independent variable  b) a controlled variable  c) the dependent variable  d) the control group
**Answer: c) the dependent variable** — the dose is changed; the pressure is measured

**3. (Sub lesson 1)** Same soil, same water and same light in both pots are —
a) independent variables  b) controlled variables  c) results  d) hypotheses
**Answer: b) controlled variables** — held constant so they cannot confuse the result

**4. (Sub lesson 2)** A control group —
a) gets double treatment  b) is treated like the experimental group except the independent variable is not applied  c) is ignored  d) needs no care
**Answer: b) is treated like the experimental group except the independent variable is not applied** — it is the untreated comparison baseline

**5. (Sub lesson 2)** Changing fertiliser AND light between two pots makes the test —
a) faster and fair  b) unfair: no result can say which change did it  c) a control test  d) quantitative
**Answer: b) unfair: no result can say which change did it** — one change at a time is the fairness rule

**6. (Sub lesson 2)** Without a control group, an investigator cannot be sure —
a) of the time  b) that the result came from the tested variable and not something else  c) of the plant's name  d) of anything at all being alive
**Answer: b) that the result came from the tested variable and not something else** — cause and effect need the comparison baseline
