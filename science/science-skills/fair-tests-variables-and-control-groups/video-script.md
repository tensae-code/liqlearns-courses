# Video script — Fair tests — variables and control groups

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Two pots. One grows tall. Did the fertiliser do it?

Wait. One pot stood in the **sun**. The other in a **dark corner**, barely watered.
Three things changed — so the tall pot proves **nothing**.

A fair test changes **one** thing: the **independent** variable.
It measures **one** thing: the **dependent** variable.
And it holds **everything else still**.

And one pot gets **no treatment at all** — the **control**.
Same light. Same water. Same soil. Nothing added.
Now, if the treated pot grows taller — the fertiliser can speak for itself.
