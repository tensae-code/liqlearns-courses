Today: **Using a simple identification key** — Seychelles' way, from its Integrated Science unit booklets (Unit 5).

Seychelles' Unit 5 Summary, "Using a key", teaches the identification key: a set of yes/no questions arranged in stages, where each answer sends you to the next question until only one organism fits. The unit's key has three stages — answer honestly at each stage, from what you can actually see, and the key narrows the choices down to a name.

The Project, "Making a key", turns the skill around: to build a key for a set of organisms, choose questions that split the set — a question that can only be answered yes or no, and that divides the group into two parts. A good question uses a clear, visible difference; a bad one uses size words like "big" that two observers would judge differently.

Now you. Say it back — in your own words.
