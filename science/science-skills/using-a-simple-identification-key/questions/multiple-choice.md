# Using a simple identification key — multiple choice

Pick the one right answer.

**1.** (Sub lesson 1) An identification key works by…
a) yes/no questions in stages that narrow the choices  b) guessing the name first  c) measuring the organism  d) asking the teacher
**Answer: a) yes/no questions in stages that narrow the choices**

**2.** (Sub lesson 1) The key in this unit has…
a) three stages  b) ten stages  c) one stage  d) no stages
**Answer: a) three stages**

**3.** (Sub lesson 1) A good key question uses…
a) a clear, visible difference  b) the word 'big' with no measure  c) the organism's feelings  d) a coin toss
**Answer: a) a clear, visible difference**

**4.** (Sub lesson 2) When you follow a key, you answer from…
a) what you can actually see  b) what you hope is true  c) the last organism's answer  d) the biggest organism
**Answer: a) what you can actually see**

**5.** (Sub lesson 2) Making a key starts by choosing questions that…
a) split the set into two parts  b) name every organism at once  c) need a microscope  d) ask about colour only
**Answer: a) split the set into two parts**

**6.** (Sub lesson 2) If a partner gets stuck using your key, you…
a) fix the step that failed  b) throw the leaves away  c) add a maybe answer  d) skip the organism
**Answer: a) fix the step that failed**
