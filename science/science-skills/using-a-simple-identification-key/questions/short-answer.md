# Using a simple identification key — short answer

Answer in a sentence or two.

**1.** (Sub lesson 1) Explain, in your own words: following a key to a name.
**Answer:** Seychelles' Unit 5 Summary, "Using a key", teaches the identification key: a set of yes/no questions arranged in stages, where each answer sends you to the next question until only one organism fits.

**2.** (Sub lesson 2) How many stages does this unit's key have, and what must every question in a key be?
**Answer:** Three stages; every question must be answerable yes or no, from a clear visible difference.

**3.** (Whole lesson) Retell the whole lesson in its own order, one sentence per sub lesson.
**Answer:** Following a key to a name → Making your own key — in that order, as taught in lesson/lesson.md.
