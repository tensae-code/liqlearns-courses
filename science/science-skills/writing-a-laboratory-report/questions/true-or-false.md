# Writing a laboratory report — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Data/Observation comes before Result and Discussion.
**Answer: True** — the order is fixed

**2. (Sub lesson 2)** Data may be adjusted in the report to fit the aim.
**Answer: False** — honesty — data as observed

**3. (Sub lesson 1)** The Title carries the date with it.
**Answer: True** — Title (and date)
