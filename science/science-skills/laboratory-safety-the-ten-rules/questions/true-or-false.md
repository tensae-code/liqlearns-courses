# Laboratory safety — the ten rules — true or false

Say whether each sentence is true or false.

**1.** Working alone in the laboratory is allowed for quick experiments.
**Answer: False** — rule 1 forbids lone working

**2.** Spills should be cleaned immediately.
**Answer: True** — rule 10

**3.** Loose clothing and long hair are safe near flames if you are careful.
**Answer: False** — rule 3 — confine them
