# Cloning and plant tissue culture — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (cloning copies one donor's heredity without fertilisation, by a technique based on an egg or by one based on a specialised somatic cell) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: comparing this lesson's two techniques with a neighbouring lesson's facts, and explaining them without looking.
