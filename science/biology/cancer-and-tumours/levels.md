# Cancer and tumours — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (when the control of cell division fails, cells divide without control and form a tumour — the uncontrolled division Azerbaijan's book closes with, in its section titled "Cancer") and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: setting this lesson beside the mitosis lessons and saying exactly which step's control has failed, and explaining it without looking.
