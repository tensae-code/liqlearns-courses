# Tropical rainforest — structure and adaptations — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (the rain forest is built in storeys, and its plants carry the marks of the wet, shaded world: drip tips to shed water, buttress roots to hold tall trunks, cauliflory, climbers reaching for light, and shade plants below — studied practically, from the species actually found, up to the forest's food chains) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: applying the lesson to a new example from the learner's own surroundings, and explaining Nigeria's way of teaching it (Ch. 14, printed p. 206), without looking.
