# Pharming — proteins from transgenic animals — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (pharming makes transgenic animals secrete human pharmaceutical proteins in their milk — a medicine factory on four legs — so the protein is harvested by milking, purified, and used to treat people) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
