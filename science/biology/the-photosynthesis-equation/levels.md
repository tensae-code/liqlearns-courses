# The photosynthesis equation — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Practice deepens by using more examples of the same facts, then the harder corners: comparing this lesson's facts with a neighbouring lesson's, and explaining them without looking.
