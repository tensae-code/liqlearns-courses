# Growth curves — sigmoid and intermittent growth — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (growth can be measured and drawn as a curve: many organisms grow in an S-shaped sigmoid curve, but insects grow in steps — an intermittent, stepped curve — because they can only grow when they shed their hard outer skeleton) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: applying the lesson to a new example from the learner's own surroundings, and explaining Nigeria's way of teaching it (Ch. 4, printed p. 56), without looking.
