# Cells as colonies and filaments — Volvox and Spirogyra — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (between one single cell and a true tissue stand two halfway forms: the colony, where many cells live together in one ball, and the filament, where cells stay joined in a thread — Nigeria's book teaches them through Volvox and Spirogyra) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: applying the lesson to a new example from the learner's own surroundings, and explaining Nigeria's way of teaching it (Ch. 2, printed p. 25), without looking.
