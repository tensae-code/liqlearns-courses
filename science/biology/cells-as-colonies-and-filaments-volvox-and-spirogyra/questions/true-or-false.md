# Cells as colonies and filaments — Volvox and Spirogyra — true or false

Say true or false.

**1.** A Volvox colony can hold up to 20,000 cells.
**Answer: True**

**2.** Spirogyra's cells separate completely after every division and never form threads.
**Answer: False** — Spirogyra's cells stay joined end to end, forming a filament.

**3.** Volvox reproduces only asexually.
**Answer: False** — Volvox reproduces both asexually and sexually.
