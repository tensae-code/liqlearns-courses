# Modelling bile function — fat emulsification — true or false

Say true or false.

**1. Kuwait's Grade 11 Term 2 applications workbook (Activity 4, printed p. 24) models the function of bile: bile's emulsifying action on fats is modelled and observed — with washing-up liquid and oil standing in for bile and fat.**
**Answer: True** — this is what the lesson teaches.

**2. This topic is taught in Kuwait's Ministry of Education biology books as named content.**
**Answer: True** — this is what the lesson teaches (الأحياء — كراسة التطبيقات — الصف الحادي عشر — الفصل الدراسي الثاني (Biology — Applications Workbook, Grade 11, Term 2), printed p. 24).

**3. The lesson's topic has nothing to do with modelling bile function — fat emulsification.**
**Answer: False** — the whole lesson is modelling bile function — fat emulsification.
