# Modelling bile function — fat emulsification — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (bile's job on fats is emulsification: it breaks large fat globules into tiny droplets — and the action can be modelled with washing-up liquid and oil) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
