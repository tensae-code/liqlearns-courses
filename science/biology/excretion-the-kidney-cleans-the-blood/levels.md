# Excretion — the kidney cleans the blood — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (the kidney filters blood, regulates the concentration of solutes in it and even influences red-blood-cell numbers — urine then travels to the bladder for storage and removal) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: comparing this lesson's facts with a neighbouring lesson's, and explaining them without looking.
