# Biochemical molecules — the map of the unit — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (the chemicals of living things sort into inorganic molecules (water and ions) and organic molecules (carbohydrates, lipids, proteins, nucleic acids)) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: comparing this lesson's facts with a neighbouring lesson's, and explaining them without looking.
