# Plant uses and library work — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (group work and a library search extend the uses of plants beyond food, closing Unit 2's content before its summary), explain each key fact in their own words, and run a real library search the lesson's way — question first, find it in a book, note plant, use and page, report back with the evidence. Practice deepens by searching for more uses and harder-to-find plants, then the harder corners: judging whether a found claim is properly evidenced, and reporting it so another learner can check it.
