# Lesson plan — Plant uses and library work

**Course:** Science · **Title:** Biology · **Lesson:** Plant uses and library work
**Place in the curriculum:** Grade 10 — Unit 2 (CURRICULUM.md).
**The one thing this lesson teaches:** group work (Activity 2.20) and a library search (Activity 2.21) extend the uses of plants beyond food, closing Unit 2's content before its summary.
**This lesson's own level:** it stands on the Grade 9–10 Biology course — the learner can already read English science text and handle the lesson's own examples. It needs nothing else.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide.

## Sub lessons
This lesson is one whole lesson — it has no sub lessons (a short, single-skill lesson; his ruling 2026-11-09).

## Before this lesson
- Recommended first: the other lessons of Grade 10 Unit 2, especially Ethiopia's medicinal plants. Recommended, never forced.

## What the learner can do when it ends
1. Say, in their own words, the one thing this lesson teaches: group work and a library search extend the uses of plants beyond food, closing the unit's content before its summary.
2. Name and explain each key fact of the lesson.
3. Carry out a library search the lesson's way: question first, find it in a book, note plant, use and page, report back.
4. Answer the lesson's questions from what the lesson itself taught.

## What you need
Paper and a pencil. Access to a library or a set of plant/biology books for the search itself. Nothing else.

## If the learner is stuck
- Go back to the one thing this lesson teaches, and re-read the key facts slowly, one at a time.
- Use the picture: point at each use tile and each library step and say its fact aloud.
- No library nearby → run the search in any set of books to hand, the lesson's way: question, find, note with page, report.
