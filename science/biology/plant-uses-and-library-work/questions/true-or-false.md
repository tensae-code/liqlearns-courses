# Plant uses and library work — true or false

Say true or false.

**1.** The uses of plants stop at food — there is nothing beyond it for this lesson to extend.
**Answer: False** — the lesson extends plant uses beyond food; medicine is one family of uses the unit has already shown.

**2.** Activity 2.21 is a library search.
**Answer: True**

**3.** In group work, the group's list should be shorter than one person's list, to keep it simple.
**Answer: False** — pooling what each person knows makes the group's list longer and better checked.

**4.** A use found in a book, noted with its book and page, can be checked by anyone.
**Answer: True**
