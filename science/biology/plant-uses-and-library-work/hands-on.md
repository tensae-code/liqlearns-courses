# Hands-on — Plant uses and library work

The lesson with your hands and your feet, not only your eyes.

## The group gather (Activity 2.20, done for real)
In a group, list every use of a plant beyond food that anyone in the group knows from home — one use per line, with the plant's name beside it. Mark each line: certain, or to be checked.

## The library search (Activity 2.21, done for real)
Take the group's "to be checked" lines into a library or book set. For each one: find it in a book, and write the plant, the use, the book and the page. Cross out any line no book supports, and say why.

## Teach it on paper
Draw the lesson's main picture from memory — the uses beyond food and the three search steps — label it, and check your drawing against the lesson. Fix anything you missed.
