# Lichens — a symbiosis — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (A lichen is not one living thing but two living together as one body: a fungus and an alga (or cyanobacterium) in symbiosis, each giving what the other lacks.) and explain each key fact in their own words. Practice deepens by applying the lesson's idea to a new example the learner has not seen, without looking.
