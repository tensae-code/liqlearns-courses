# The female reproductive system — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (the female system makes eggs in the ovaries and carries a pregnancy in the uterus), explain each key fact in their own words, name the external structures and internal organs with each organ's function, and list the system's five jobs. Practice deepens by using more examples of the same facts, then the harder corners: comparing this lesson's facts with a neighbouring lesson's, and explaining them without looking.
