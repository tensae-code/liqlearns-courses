# Assessing an activity of integration — multiple choice

Pick the one right answer.

**1.** Which set names Uganda's evaluation grid for an activity of integration?
a) Speed, Neatness, Length, Silence
b) Accuracy, Coherence, Relevance, Excellence
c) Effort, Behaviour, Attendance, Dress
d) Memory, Copying, Speed, Luck
**Answer: b) Accuracy, Coherence, Relevance, Excellence**

**2.** What does the Relevance criterion ask?
a) Whether the handwriting is neat
b) Whether the work answers the real-life situation the task was set in
c) Whether the work is the longest in class
d) Whether the learner worked alone
**Answer: b) Whether the work answers the real-life situation the task was set in**

**3.** Where does the evaluation grid stand?
a) In the closing pages of Uganda's Senior One Teacher's Guide
b) On the cover of the learner's book
c) In the Senior Two home-study booklet
d) It is not written anywhere
**Answer: a) In the closing pages of Uganda's Senior One Teacher's Guide**
