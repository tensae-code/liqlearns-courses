# Assessing an activity of integration — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (an integrated real-life task — Uganda's activity of integration — is scored on a four-part evaluation grid: Accuracy, Coherence, Relevance and Excellence — the grid in the closing pages of Uganda's Senior One Teacher's Guide) and explain each key fact in their own words. Practice deepens by applying the four criteria to longer integrated work and defending each judgement from the work itself, without looking.
