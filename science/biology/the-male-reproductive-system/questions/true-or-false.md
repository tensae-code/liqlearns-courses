# The male reproductive system — true or false

Say true or false.

**1.** Paired testes produce sperm and the male hormone.
**Answer: True**

**2.** Storage and carrying has nothing to do with this lesson's topic.
**Answer: False** — the lesson teaches it directly.

**3.** Accessory glands add the fluid that makes semen.
**Answer: True**

**4.** Penis has nothing to do with this lesson's topic.
**Answer: False** — the lesson teaches it directly.
**5.** The urethra carries both urine and semen out of the body.
**Answer: True**
