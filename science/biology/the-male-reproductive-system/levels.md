# The male reproductive system — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (the male system makes sperm in the testes, stores them, and delivers them in semen), explain each key fact in their own words, sort the organs into external (penis, testes, scrotum) and internal (prostate, vas deferens, urethra), explain erection mechanically (arteries dilate, engorgement, veins compressed), and name the urethra's two jobs. Practice deepens by using more examples of the same facts, then the harder corners: comparing this lesson's facts with a neighbouring lesson's, and explaining them without looking.
