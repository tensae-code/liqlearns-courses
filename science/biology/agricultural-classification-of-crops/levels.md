# Agricultural classification of crops — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (plants can be classified two ways: botanically, by their natural relationships, and agriculturally, by what they are grown for — Nigeria sorts crops agriculturally into twelve groups by product, useful part and economic importance, with Nigerian crops throughout) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: applying the lesson to a new example from the learner's own surroundings, and explaining Nigeria's way of teaching it (Ch. 9, printed p. 137), without looking.
