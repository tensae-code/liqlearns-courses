# Cyanobacteria — the blue-green algae — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (Cyanobacteria — the blue-green algae — are bacteria that photosynthesise: single cells and filaments of Kingdom Monera that make their own food from sunlight like plants do, which is why they were long mistaken for algae.) and explain each key fact in their own words. Practice deepens by applying the lesson's idea to a new example the learner has not seen, without looking.
