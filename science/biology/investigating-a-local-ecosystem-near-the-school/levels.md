# Investigating a local ecosystem near the school — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (an ecosystem is investigated where it actually is: go out into an ecosystem from the school's area, observe it on a field excursion, and complete a trophic chain for that local ecosystem) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
