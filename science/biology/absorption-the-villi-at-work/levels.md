# Absorption — the villi at work — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (digested food is absorbed in the small intestine through villi — finger-like folds, each with blood vessels and a lacteal, multiplying the absorbing surface) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: comparing this lesson's facts with a neighbouring lesson's, and explaining them without looking.
