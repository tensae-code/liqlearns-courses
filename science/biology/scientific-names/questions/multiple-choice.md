# Scientific names — genus + epithet — multiple choice

Pick the one right answer.

**1.** What does this lesson say about Linnaeus?
a) Linnaeus set out the system in Systema Naturae in 1735 and described thousands of plants and animals
b) It plays no part in this topic at all
c) It happens only at night and nowhere else
d) It is found only in non-living things
**Answer: a) Linnaeus set out the system in Systema Naturae in 1735 and described thousands of plants and animals**

**2.** What does this lesson say about the two parts?
a) It plays no part in this topic at all
b) A scientific name has the genus first with a capital letter and the specific epithet second in lower case
c) It happens only at night and nowhere else
d) It is found only in non-living things
**Answer: b) A scientific name has the genus first with a capital letter and the specific epithet second in lower case**

**3.** What does this lesson say about writing it?
a) It plays no part in this topic at all
b) It happens only at night and nowhere else
c) A scientific name is italicised in print or underlined by hand
d) It is found only in non-living things
**Answer: c) A scientific name is italicised in print or underlined by hand**

**4.** What does this lesson say about Ethiopian wolf?
a) It plays no part in this topic at all
b) It happens only at night and nowhere else
c) It is found only in non-living things
d) The Ethiopian wolf's scientific name is Canis simensis
**Answer: d) The Ethiopian wolf's scientific name is Canis simensis**
