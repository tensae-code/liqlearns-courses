# Scientific names — genus + epithet

## Do it first
Before you read anything: think about this lesson's title — Scientific names — genus + epithet. Write down, or say aloud, anything you already know about it, and one question you want answered. Then read on and check yourself at the end.

## The idea
Common names change from place to place. The two-name system gives every species one name the whole world shares.

[Picture 21014 — a name card for the Ethiopian wolf]

## The key facts
**Linnaeus.** Linnaeus set out the system in Systema Naturae in 1735 and described thousands of plants and animals.

**The two parts.** A scientific name has the genus first with a capital letter and the specific epithet second in lower case.

**Writing it.** A scientific name is italicised in print or underlined by hand.

**Ethiopian wolf.** The Ethiopian wolf's scientific name is Canis simensis.
