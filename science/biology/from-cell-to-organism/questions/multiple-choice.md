# From cell to organism — the levels of life — multiple choice

Pick the one right answer.

**1.** What does this lesson say about the levels?
a) The levels are cell, tissue, organ, organ system and organism
b) It plays no part in this topic at all
c) It happens only at night and nowhere else
d) It is found only in non-living things
**Answer: a) The levels are cell, tissue, organ, organ system and organism**

**2.** What does this lesson say about built up?
a) It plays no part in this topic at all
b) Each level is built from the one below it
c) It happens only at night and nowhere else
d) It is found only in non-living things
**Answer: b) Each level is built from the one below it**

**3.** What does this lesson say about more than parts?
a) It plays no part in this topic at all
b) It happens only at night and nowhere else
c) Each level does more than any part alone
d) It is found only in non-living things
**Answer: c) Each level does more than any part alone**

**4.** What does this lesson say about two traces?
a) It plays no part in this topic at all
b) It happens only at night and nowhere else
