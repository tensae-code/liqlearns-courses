# Stomata — opening by guard-cell turgor — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (A stoma opens when its two guard cells take in water, become turgid and bulge outwards — and it closes when they lose water and go flaccid: osmosis at work in the leaf.) and explain each key fact in their own words. Practice deepens by applying the lesson's idea to a new example the learner has not seen, without looking.
