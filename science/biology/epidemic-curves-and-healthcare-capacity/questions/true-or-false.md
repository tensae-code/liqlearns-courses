# Epidemic curves and healthcare capacity — true or false

Say true or false.

**1.** An epidemic curve plots the number of cases against time.
**Answer: True**

**2.** Without protective measures, the curve stays low and flat.
**Answer: False** — without them cases rise fast to a high peak above the capacity line.

**3.** With protective measures, the peak stays below the healthcare-capacity line.
**Answer: True**

**4.** Healthcare capacity has nothing to do with this lesson's topic.
**Answer: False** — the lesson teaches it directly.
