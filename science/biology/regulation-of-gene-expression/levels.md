# Regulation of gene expression — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (gene expression is a gene being read and made into its product, and its regulation is the control of which genes are expressed, when, and how much.) and explain each key fact in their own words. Practice deepens by restating the lesson's main picture from memory and applying its distinctions to a fresh example the learner chooses.
