# The autonomic nervous system — short answer

Answer in your own words.

**1.** State the one thing this lesson teaches and explain it.
**Answer: the autonomic nervous system runs the body's automatic life — heartbeat, digestion, pupil size, sweating — through two opposing branches, sympathetic speeding and preparing for action, parasympathetic slowing and restoring, without any conscious command. autonomic nervous system as a named section**

**2.** Explain Greece's way of teaching this.
**Answer: autonomic nervous system as a named section**
