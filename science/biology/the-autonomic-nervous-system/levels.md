# The autonomic nervous system — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (the autonomic nervous system runs the body's automatic life — heartbeat, digestion, pupil size, sweating — through two opposing branches, sympathetic speeding and preparing for action, parasympathetic slowing and restoring, without any conscious command) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
