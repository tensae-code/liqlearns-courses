# The Hardy–Weinberg law — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (In a population that is not evolving — no selection, no mutation, no migration, mating at random, in large numbers — allele and genotype frequencies stay the same from generation to generation: that is the Hardy–Weinberg law, the balance point against which real, changing populations are measured, summed in p² + 2pq + q² = 1.) and explain each key fact in their own words. Practice deepens by applying the lesson's idea to a new example the learner has not seen, without looking.
