# Blood groups and the Rhesus factor — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (antigens A and B define the blood groups, and the Rhesus factor is a further inherited red-cell antigen) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: comparing this lesson's facts with a neighbouring lesson's, and explaining them without looking.


Student-book upgrade: the pupil-taught core (see lesson/sources.md, Book 2) is now part of the pass mark — the learner states the student-book key facts as well as the guide facts.
