# Genetically modified organisms — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (a genetically modified organism carries a gene deliberately moved into it — transgenic plants and animals made for production, which Greece's books teach as a named topic — with the new trait inherited by its offspring like any of its own genes) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
