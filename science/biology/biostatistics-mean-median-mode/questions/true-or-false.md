# Biostatistics — mean, median and mode — true or false

Say true or false.

**1. The mean is affected by every value in the set.**
**Answer: True** — this is what the lesson teaches

**2. The median of an unordered list can be read off without sorting it.**
**Answer: False** — the values must first be lined up in order; the median is the middle one

**3. A set can have no mode.**
**Answer: True** — if no value repeats, there is no most-often value

**4. Biostatistics belongs only to mathematics, never to biology.**
**Answer: False** — Punjab's Grade 9 biology book teaches it as its own closing chapter
