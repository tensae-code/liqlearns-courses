# Biostatistics — mean, median and mode — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (Biostatistics is the statistics a biologist uses on living data: a set of measurements is summed up by its mean (the values added and divided by how many there are), its median (the middle value when they are lined up in order) and its mode (the value that occurs most often) — and the set is shown at a glance in a bar chart.) and explain each key fact in their own words. Practice deepens by applying the lesson's idea to a new example the learner has not seen, without looking.
