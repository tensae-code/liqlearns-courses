# Nigeria's vegetation belts — the local biomes — true or false

Say true or false.

**1.** Isoberlinia doka is one of the book's named savannah trees.
**Answer: True**

**2.** The Sahel is Nigeria's wettest vegetation belt.
**Answer: False** — The Sahel, in Borno State near Lake Chad, is the driest belt; the rain forest of the south is the wettest.

**3.** Nigeria's belts run rain forest → Guinea savannahs → Sahel from south to north.
**Answer: True**
