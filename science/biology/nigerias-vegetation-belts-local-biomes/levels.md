# Nigeria's vegetation belts — the local biomes — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (Nigeria's own vegetation belts are its local biomes: rain forest in the wet south, then the Southern and Northern Guinea savannahs with their shea butter and locust bean trees, and finally the dry Sahel in Borno State near Lake Chad) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: applying the lesson to a new example from the learner's own surroundings, and explaining Nigeria's way of teaching it (Ch. 7, printed p. 122), without looking.
