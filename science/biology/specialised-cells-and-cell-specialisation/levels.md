# Specialised cells and cell specialisation — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (A specialised cell is a cell whose structure is fitted to one particular job — and a living thing works better when its jobs are divided among specialised cells, each doing one job well.) and explain each key fact in their own words. Practice deepens by applying the lesson's idea to a new example the learner has not seen, without looking.
