# World biomes — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (A biome is a great region of the Earth sorted by its climate — its rainfall and temperature — each carrying its own characteristic plants and animals, fitted to that climate.) and explain each key fact in their own words. Practice deepens by applying the lesson's idea to a new example the learner has not seen, without looking.
