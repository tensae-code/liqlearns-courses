# Modified plant organs — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (a plant organ can be modified — changed in form so it does a special job besides, or instead of, its ordinary one: tendrils modified to climb and hold, thorns modified to defend, and storage organs modified to keep food and water for the plant) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
