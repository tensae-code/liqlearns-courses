# Digestive system disorders and hygiene — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (The digestive system has its own diseases — most of them carried in by dirty water, dirty hands and spoiled food — and its hygiene is the daily practice that keeps them out.) and explain each key fact in their own words. Practice deepens by applying the lesson's idea to a new example the learner has not seen, without looking.
