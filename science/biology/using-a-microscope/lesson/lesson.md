# Using a microscope — carry, focus, put away

## Do it first
Before you read anything: think about this lesson's title — Using a microscope — carry, focus, put away. Write down, or say aloud, anything you already know about it, and one question you want answered. Then read on and check yourself at the end.

## The idea
Treat the microscope gently and it will serve many classes. The routine never changes.

## The key facts
**Carrying.** Carry the microscope upright, holding the arm and the base.

**Lenses.** Clean lenses only with lens tissue, never with ordinary cloth or fingers.

**Focusing.** Start on the lowest-power objective, focus upward with the coarse knob, then sharpen with the fine knob, and never force the knobs.

**Putting away.** Turn the light off before putting it away, wrap the cord properly and return it to its cabinet with the oculars facing the back.
