# Using a microscope — carry, focus, put away — multiple choice

Pick the one right answer.

**1.** What does this lesson say about carrying?
a) Carry the microscope upright, holding the arm and the base
b) It plays no part in this topic at all
c) It happens only at night and nowhere else
d) It is found only in non-living things
**Answer: a) Carry the microscope upright, holding the arm and the base**

**2.** What does this lesson say about lenses?
a) It plays no part in this topic at all
b) Clean lenses only with lens tissue, never with ordinary cloth or fingers
c) It happens only at night and nowhere else
d) It is found only in non-living things
**Answer: b) Clean lenses only with lens tissue, never with ordinary cloth or fingers**

**3.** What does this lesson say about focusing?
a) It plays no part in this topic at all
b) It happens only at night and nowhere else
c) Start on the lowest-power objective, focus upward with the coarse knob, then sharpen with the fine knob, and never force the knobs
d) It is found only in non-living things
**Answer: c) Start on the lowest-power objective, focus upward with the coarse knob, then sharpen with the fine knob, and never force the knobs**

**4.** What does this lesson say about putting away?
a) It plays no part in this topic at all
b) It happens only at night and nowhere else
c) It is found only in non-living things
d) Turn the light off before putting it away, wrap the cord properly and return it to its cabinet with the oculars facing the back
**Answer: d) Turn the light off before putting it away, wrap the cord properly and return it to its cabinet with the oculars facing the back**
