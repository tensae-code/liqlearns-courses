# Using a microscope — carry, focus, put away — true or false

Say true or false.

**1.** Carry the microscope upright, holding the arm and the base.
**Answer: True**

**2.** Lenses has nothing to do with this lesson's topic.

**3.** Start on the lowest-power objective, focus upward with the coarse knob, then sharpen with the fine knob, and never force the knobs.
**Answer: True**

**4.** Putting away has nothing to do with this lesson's topic.
**Answer: False** — the lesson teaches it directly.
