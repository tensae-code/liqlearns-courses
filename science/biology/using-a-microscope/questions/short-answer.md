# Using a microscope — carry, focus, put away — short answer

Answer in your own words.

**1.** Explain: focusing.
**Answer: Start on the lowest-power objective, focus upward with the coarse knob, then sharpen with the fine knob, and never force the knobs.**

**2.** Explain: putting away.
**Answer: Turn the light off before putting it away, wrap the cord properly and return it to its cabinet with the oculars facing the back.**
