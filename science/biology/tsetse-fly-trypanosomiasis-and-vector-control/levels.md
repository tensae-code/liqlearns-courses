# Tsetse fly, trypanosomiasis and vector control — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (diseases carried by vectors are controlled by controlling the vector: Nigeria's book works the tsetse fly's full life history and builds the control on it — clearing its shade resting places, spraying, breeding nagana-resistant cattle, and treating sleeping sickness promptly — because antelopes carry the parasite harmlessly and cannot be removed) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: applying the lesson to a new example from the learner's own surroundings, and explaining Nigeria's way of teaching it (Ch. 12, printed p. 174), without looking.
