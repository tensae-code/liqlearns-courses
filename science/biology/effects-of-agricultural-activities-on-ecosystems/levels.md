# Effects of agricultural activities on ecosystems — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (farming changes the ecosystem it works in: clearing land, the farming systems practised on it and bush burning each alter the soil, the water and the living community — Nigeria teaches the effects practice by practice and crop by crop) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: applying the lesson to a new example from the learner's own surroundings, and explaining Nigeria's way of teaching it (Ch. 9, printed p. 139), without looking.
