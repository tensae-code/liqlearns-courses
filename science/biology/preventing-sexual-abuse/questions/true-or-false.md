# Preventing sexual abuse — true or false

Say true or false.

**1. A secret about touching is a secret you must keep.**
**Answer: False** — secrets about touching are never secrets to keep — tell a trusted adult.

**2. Sexual abuse can be done by someone the victim knows and trusts.**
**Answer: True** — this is what the lesson teaches.

**3. If the first adult you tell does not act, you should tell another.**
**Answer: True** — this is what the lesson teaches.

**4. Abuse is sometimes the victim's fault.**
**Answer: False** — abuse is always the offender's fault, never the victim's.
