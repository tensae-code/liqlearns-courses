# Ethiopia's own animals and plants — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (Ethiopia is rich in species found nowhere else, and a local survey connects them to classification) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: comparing this lesson's facts with a neighbouring lesson's, and explaining them without looking.
