# Evolution of excretory systems in animals — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (excretory systems evolve along the animal line — from contractile vacuoles and worm tubules to the vertebrate kidney — while the waste itself changes with habitat: ammonia where water is plentiful, urea, and uric acid where water must be saved) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
