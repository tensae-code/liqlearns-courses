# COVID-19 — the spiked virus and how to stop it — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (COVID-19 is caused by a coronavirus with club-shaped spike proteins, spreading mainly in droplets and airborne particles) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: comparing this lesson's facts with a neighbouring lesson's, and explaining them without looking.
