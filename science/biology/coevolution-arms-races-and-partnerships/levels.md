# Coevolution — arms races and partnerships — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (species that live in close relationship shape each other's evolution — coevolution — running two ways: as an arms race where the relationship harms, and as a partnership where both sides come to fit each other) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: setting this lesson beside natural selection (selection by the environment vs selection by another species) and beside the parasitology strand of the same unit, and explaining all three without looking.
