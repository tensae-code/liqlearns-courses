# Coevolution — arms races and partnerships — true or false

Say true or false.

**1.** In coevolution, each of the two species is part of the other's environment.
**Answer: True**

**2.** Coevolution only happens between species that help each other.
**Answer: False** — it also runs between enemies, as an arms race: predator and prey, parasite and host.

**3.** Costa Rica's anthology teaches coevolution in a separate evolution unit, far from the relationships.
**Answer: False** — Coevolución stands inside Unit 1 among the ecological relationships, at printed p. 28, between the symbiotic relationships and the parasitology strand.

**4.** A change in one species can select for an answering change in a species it lives closely with.
**Answer: True**
