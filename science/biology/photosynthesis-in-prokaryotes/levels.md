# Photosynthesis in prokaryotes — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (photosynthesis began in prokaryotes: cyanobacteria run it much as plants do and filled the air with oxygen, while other bacteria photosynthesise without releasing oxygen, using sulphur compounds instead of water — the process is older than the chloroplast, which is itself a captured prokaryote) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
