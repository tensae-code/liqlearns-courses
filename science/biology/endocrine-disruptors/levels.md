# Endocrine disruptors — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (an endocrine disruptor interferes with the hormone system — France's cases are bisphenol A (banned in certain uses) and DDT (an endocrine-system lure)) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: explaining why a lure is dangerous precisely because the system cannot tell it from its own signal, and why a ban can cover certain uses of a substance without covering all of them.
