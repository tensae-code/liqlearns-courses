# Monoclonal antibodies — the hybridoma trick — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (a monoclonal antibody is one antibody made in bulk by one clone: fuse the single B cell that makes it to an endlessly dividing myeloma cell, select and clone the hybridoma, and it makes that one antibody for as long as it lives — the trick behind pregnancy test kits and antibody medicines) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
