# Factors that affect the rate of photosynthesis — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (the rate of photosynthesis is set by limiting factors — light intensity, carbon dioxide concentration and temperature — and whichever is scarcest caps the rate, so raising the others alone does nothing until the scarcest is raised) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
