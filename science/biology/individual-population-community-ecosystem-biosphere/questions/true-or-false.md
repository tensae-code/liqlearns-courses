# Individual, population, community, ecosystem, biosphere — true or false

Say true or false.

**1.** A population is all members of the same species in an area.
**Answer: True**

**2.** Community has nothing to do with this lesson's topic.
**Answer: False** — the lesson teaches it directly.

**3.** An ecosystem is a community plus its environment.
**Answer: True**

**4.** Biosphere has nothing to do with this lesson's topic.
**Answer: False** — the lesson teaches it directly.
