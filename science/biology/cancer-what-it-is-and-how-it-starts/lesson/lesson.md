# Cancer — what it is and how it starts

## Do it first
Before you read anything: think about this lesson's title — Cancer — what it is and how it starts. Write down, or say aloud, anything you already know about it, and one question you want answered. Then read on and check yourself at the end.

## The idea
Cancer begins when mutations strike the genes that control cell multiplication, so a cell divides without control and its descendants form a tumour — and Greece teaches it with its causes, its prevention and the European Code Against Cancer alongside. No lesson in this course taught this on its own before, so this lesson is built for it — from Greece's Gymnasio and Lykeio biology books, which teach it as a named topic.
