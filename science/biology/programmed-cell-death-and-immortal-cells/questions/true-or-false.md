# Programmed cell death and immortal cells — true or false

Say true or false.

**1. Programmed cell death is the cell dismantling itself in an orderly way, on schedule.**
**Answer: True** — this is what the lesson teaches.

**2. Apoptosis is a disorder that healthy bodies never use.**
**Answer: False** — apoptosis is a normal, useful programme that removes cells the body no longer needs.

**3. Immortal cells are cells that obey the death programme strictly.**
**Answer: False** — immortal cells escape the normal death programme and keep dividing.

**4. Italy's book teaches mortal and immortal cells under the heading “Training for the future”.**
**Answer: True** — this is what the lesson teaches (printed p. 120).
