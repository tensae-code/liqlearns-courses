# Programmed cell death and immortal cells — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (cells are mortal, much of their death is programmed (apoptosis — the cell dismantling itself on schedule), and immortal cells are the ones that escape that programme.) and explain each key fact in their own words. Practice deepens by restating the lesson's main picture from memory and applying its distinctions to a fresh example the learner chooses.
