# Fruits — types and placentation — true or false

Say true or false.

**1. Gibberellin drives fruit growth after fertilisation.**
**Answer: True** — the hormone of fruit development here.

**2. A coconut is a berry.**
**Answer: False** — it is a drupe, like mango.

**3. Cotton's fruit is a capsule.**
**Answer: True** — with the poppy.

**4. There are five placentation types in Kenya's account.**
**Answer: True** — the five ways ovules attach.
