# Finland's Move! fitness monitoring — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (Move! is Finland's national system for monitoring the physical functional capacity of school pupils. Pupils are measured with batteries of tests — endurance, strength and mobility — and their results are read against national reference values, so a pupil, a school and the whole country can see how young bodies are doing (oph.fi/move).) and explain each key fact in their own words. Practice deepens by naming the three Move! battery areas — endurance, strength, mobility — and saying what a national reference value is for, without looking.
