# Meiosis — halving the chromosomes — true or false

Say true or false.

**1.** Meiosis divides the cell twice.
**Answer: True**

**2.** Halved has nothing to do with this lesson’s topic.
**Answer: False** — the lesson teaches it directly.

**3.** Meiosis makes gametes — the sex cells.
**Answer: True**

**4.** Four cells has nothing to do with this lesson’s topic.
**Answer: False** — the lesson teaches it directly.
