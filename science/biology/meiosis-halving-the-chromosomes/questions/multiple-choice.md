# Meiosis — halving the chromosomes — multiple choice

Pick the one right answer.

**1.** What does this lesson say about two divisions?
a) Meiosis divides the cell twice  b) It plays no part in this topic at all  c) It happens only at night and nowhere else  d) It is found only in non-living things
**Answer: a) Meiosis divides the cell twice**

**2.** What does this lesson say about halved?
a) It plays no part in this topic at all  b) Meiosis halves the chromosome number  c) It happens only at night and nowhere else  d) It is found only in non-living things
**Answer: b) Meiosis halves the chromosome number**

**3.** What does this lesson say about gametes?
a) It plays no part in this topic at all  b) It happens only at night and nowhere else  c) Meiosis makes gametes — the sex cells  d) It is found only in non-living things
**Answer: c) Meiosis makes gametes — the sex cells**

**4.** What does this lesson say about four cells?
a) It plays no part in this topic at all  b) It happens only at night and nowhere else  c) It is found only in non-living things  d) One cell gives four daughter cells in meiosis
**Answer: d) One cell gives four daughter cells in meiosis**
