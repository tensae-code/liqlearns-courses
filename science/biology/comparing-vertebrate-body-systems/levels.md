# Comparing vertebrate body systems — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (Across the five vertebrate groups the same systems are built to one plan and tuned differently — clearest in the heart: two chambers in fish, three in amphibians and most reptiles, four in crocodiles, birds and mammals, driving a single circulation in fish and a double one on land.) and explain each key fact in their own words.
