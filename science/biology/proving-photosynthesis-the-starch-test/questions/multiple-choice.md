# Proving photosynthesis — the starch test — multiple choice

Pick the one right answer.

**1.** What does this lesson say about de-starching?
a) The plant is de-starched first, so any starch found was made during the test  b) It plays no part in this topic at all  c) It happens only at night and nowhere else  d) It is found only in non-living things
**Answer: a) The plant is de-starched first, so any starch found was made during the test**

**2.** What does this lesson say about the sequence?
a) It plays no part in this topic at all  b) The test runs: boil in water, boil in alcohol, rinse, then add iodine  c) It happens only at night and nowhere else  d) It is found only in non-living things
**Answer: b) The test runs: boil in water, boil in alcohol, rinse, then add iodine**

**3.** What does this lesson say about the result?
a) It plays no part in this topic at all  b) It happens only at night and nowhere else  c) Starch shows only where light reached green tissue  d) It is found only in non-living things
**Answer: c) Starch shows only where light reached green tissue**

**4.** What does this lesson say about what it proves?
a) It plays no part in this topic at all  b) It happens only at night and nowhere else  c) It is found only in non-living things  d) The test proves light and green tissue are needed for the leaf to make starch
**Answer: d) The test proves light and green tissue are needed for the leaf to make starch**
