# Haploid and diploid — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (Cells carry their chromosomes in sets: a diploid nucleus holds two sets (2n) — one from each parent — while a haploid nucleus holds one set (n); body cells are diploid, gametes are haploid, and fertilisation joins two haploid cells back to diploid.) and explain each key fact in their own words. Practice deepens by applying the lesson's idea to a fresh example from the learner's own surroundings and saying why it fits, without looking.
