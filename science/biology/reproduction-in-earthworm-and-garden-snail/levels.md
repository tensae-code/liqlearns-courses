# Reproduction in earthworm and garden snail — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (the earthworm and the garden snail are both hermaphrodites — each individual carries both sexes — yet both still cross-fertilise: two worms exchange sperm at the clitellum and fertilisation happens inside the slipped-off cocoon, and two snails exchange sperm before each lays its batch of eggs in the soil) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: applying the lesson to a new example from the learner's own surroundings, and explaining Nigeria's way of teaching it (Ch. 15, printed p. 217), without looking.
