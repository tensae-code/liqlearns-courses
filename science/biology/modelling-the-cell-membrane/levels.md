# Modelling the cell membrane — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (a cell membrane can be modelled with simple materials — a glass dish of water, vegetable oil and fine sawdust — and each material in the model stands for one part of the real membrane's structure) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
