# Biological waste and lab accident management — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (biological waste from a biology laboratory is sorted and disposed of by set methods — never simply poured away — and a lab accident is met by a set order of steps) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
