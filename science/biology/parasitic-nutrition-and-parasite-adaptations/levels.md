# Parasitic nutrition and parasite adaptations — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (a parasite feeds on or in a living host and harms it, and parasites are built for that life: hooks and suckers to hold on, protection against the host's enzymes, millions of eggs, and often an intermediate host — Nigeria teaches parasitic nutrition through West Africa's own parasites) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: applying the lesson to a new example from the learner's own surroundings, and explaining Nigeria's way of teaching it (Ch. 6, printed p. 97), without looking.
