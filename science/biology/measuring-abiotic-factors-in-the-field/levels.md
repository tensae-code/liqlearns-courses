# Measuring abiotic factors in the field — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (the non-living conditions of a habitat can be measured, each with its own instrument: temperature, relative humidity by wet-and-dry-bulb hygrometer, wind by vane and anemometer, light by light meter, and elevation by aneroid barometer — and Nigeria's book works them with Nigerian data) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: applying the lesson to a new example from the learner's own surroundings, and explaining Nigeria's way of teaching it (Ch. 7, printed p. 110), without looking.
