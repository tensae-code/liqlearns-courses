# Mental health disorders — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (the psyche develops, and its disorders — anxiety disorders, depression and psychoses — are taught by name as illnesses of the mind) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: comparing the three named disorders against each other, and explaining them without looking.
