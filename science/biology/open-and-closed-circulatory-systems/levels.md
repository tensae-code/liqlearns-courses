# Open and closed circulatory systems — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (animals move substances two ways: in an open circulatory system the blood leaves the vessels and bathes the tissues directly, while in a closed system it never leaves the vessels and capillaries do the exchanging — and some simple animals, like jellyfish, manage with no system at all, exchanging by diffusion) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
