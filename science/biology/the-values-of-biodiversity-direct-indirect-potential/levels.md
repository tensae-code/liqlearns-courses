# The values of biodiversity — direct, indirect, potential — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (biodiversity — held at three levels, genetic, species and ecosystem — has value in three kinds: direct value in food, fibres and medicines such as artemisinin, indirect value in carbon fixed, soil and floodwater held and climate steadied, stated to far exceed the direct, and potential value in the uses nobody knows yet) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
