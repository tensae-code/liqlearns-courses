# Cytoskeleton, cilia and flagella — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (the cytoskeleton holds the cell's shape and moves things inside it, and cilia and flagella move the cell or the fluid around it.) and explain each key fact in their own words. Practice deepens by restating the lesson's main picture from memory and applying its distinctions to a fresh example the learner chooses.
