# Improving crop yield — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (crop yield is raised in five ways Nigeria's book sets out: conserving the soil, feeding it with fertilisers and manure, better cultural practices, breeding improved varieties, and putting more land under cultivation) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: applying the lesson to a new example from the learner's own surroundings, and explaining Nigeria's way of teaching it (Ch. 9, printed p. 150), without looking.
