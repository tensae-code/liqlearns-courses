# Plant growth hormones — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (a plant's growth is regulated by its own chemical messengers — the hormones auxins, cytokinins, gibberellins, abscisic acid and ethylene — and auxin explains apical dominance: the top bud holds the side buds back, which is why cutting a hedge's top makes it bush out) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: applying the lesson to a new example from the learner's own surroundings, and explaining Nigeria's way of teaching it (Ch. 4, printed p. 62), without looking.
