# Hydroponics — growing plants without soil — true or false

Say true or false.

**1. Hydroponics grows plants without soil.**
**Answer: True** — the roots grow in a nutrient solution.

**2. In hydroponics the grower does not need to control pH.**
**Answer: False** — solution and pH control are part of the model.

**3. The clean-water flush before harvest lasts 2–3 days.**
**Answer: True** — this is what Vietnam's lesson specifies.

**4. Hydroponics in Vietnam is taught only for large commercial farms.**
**Answer: False** — the book's examples include home and rooftop systems.
