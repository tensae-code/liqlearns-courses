# Common respiratory diseases — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (The breathing passages have common diseases of their own — colds, influenza, bronchitis, pneumonia, tuberculosis and asthma — spread mostly through the air, and preventable by air, hygiene and vaccination habits.) and explain each key fact in their own words. Practice deepens by applying the lesson's idea to a new example the learner has not seen, without looking.
