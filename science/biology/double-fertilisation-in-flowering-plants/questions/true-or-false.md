# Double fertilisation in flowering plants — true or false

Say true or false.

**1. Double fertilisation happens in a single embryo sac.**
**Answer: True** — this is what the lesson teaches.

**2. Both fusions produce a zygote.**
**Answer: False** — only the egg fusion makes the zygote; the polar-nuclei fusion makes the endosperm.

**3. The endosperm is formed even when no fertilisation occurs.**
**Answer: False** — the endosperm is a product of the second fusion, so food tissue is made only when fertilisation succeeds.

**4. Indonesia's Grade 11 teacher guide teaches double fertilisation with a process diagram.**
**Answer: True** — this is what the lesson teaches.
