# Animal migration — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (animals migrate — they travel between places as the seasons change — and the journeys have causes and set routes, from the “explosive” migration of lemmings to the migration schemes of salmon and eels) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
