# Animalia — the five vertebrate groups — multiple choice

Pick the one right answer.

**1.** What does this lesson say about the five groups?
a) The vertebrate classes are fish, amphibians, reptiles, birds and mammals
b) It plays no part in this topic at all
c) It happens only at night and nowhere else
d) It is found only in non-living things
