# Adaptations — how organisms fit their environment — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (organisms carry adaptations — features that fit them to their environment — as Greece's Mediterranean plants show: pine and olive hold small, hard, needle-like leaves against dry summers while the plane tree by the water spreads broad leaves, so the same life function is fitted differently in dry and wet habitats) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
