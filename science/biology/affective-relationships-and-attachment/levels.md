# Affective relationships and attachment — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (Bolivia's Segundo Año biology book teaches "Biología de las relaciones afectivas" — attachment, and the right to a life free of violence in relationships) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: setting this lesson beside the fertilisation and pregnancy lesson that precedes it in Bolivia's book and explaining how the book moves from the biology of reproduction to the biology of relationships, without looking.
