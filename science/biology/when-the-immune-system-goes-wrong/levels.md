# When the immune system goes wrong — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (the immune system itself can be the problem: allergies are its over-reaction to harmless things, autoimmune diseases its attack on the body's own tissues, and immunodeficiency its failure to defend at all — Greece's Grade 11 book gives the failures their own named section) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
