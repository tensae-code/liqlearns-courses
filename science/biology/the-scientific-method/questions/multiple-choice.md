# The scientific method — observe, question, hypothesise, test, conclude — multiple choice

Pick the one right answer.

**1.** What does this lesson say about observation?
a) Scientific study begins with careful observation, which raises a question
b) It plays no part in this topic at all
c) It happens only at night and nowhere else
d) It is found only in non-living things
**Answer: a) Scientific study begins with careful observation, which raises a question**

**2.** What does this lesson say about hypothesis?
a) It plays no part in this topic at all
b) A hypothesis is a testable possible answer to the question
c) It happens only at night and nowhere else
d) It is found only in non-living things
**Answer: b) A hypothesis is a testable possible answer to the question**

**3.** What does this lesson say about experiment?
a) It plays no part in this topic at all
b) It happens only at night and nowhere else
c) An experiment only counts if others can repeat it and get similar results
d) It is found only in non-living things
**Answer: c) An experiment only counts if others can repeat it and get similar results**

**4.** What does this lesson say about conclusion?
a) It plays no part in this topic at all
b) It happens only at night and nowhere else
c) It is found only in non-living things
d) Conclusions either keep the hypothesis as a possible explanation or reject it and form a new one
**Answer: d) Conclusions either keep the hypothesis as a possible explanation or reject it and form a new one**
