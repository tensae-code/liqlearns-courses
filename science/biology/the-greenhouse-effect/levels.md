# The greenhouse effect — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (the greenhouse effect is the atmosphere's blanket: sunlight warms the Earth, the Earth radiates heat back, and greenhouse gases absorb part of that heat instead of letting it escape — Greece's Grade 11 laboratory guide detects it qualitatively and quantitatively in a model experiment with warmed, measured air) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
