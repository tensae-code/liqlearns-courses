# Chromosome numbers in different organisms — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (each species carries its own characteristic chromosome number, constant in every body cell and every generation — cattle 60, sheep 54, pig 38, chicken 78 — a fixed mark of the species) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
