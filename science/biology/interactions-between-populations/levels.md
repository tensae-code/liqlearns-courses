# Interactions between populations — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (Populations sharing one place interact — competition, predation, parasitism, mutualism and commensalism — and every interaction can be read by what each side gains or loses.) and explain each key fact in their own words. Practice deepens by applying the lesson's idea to a new example the learner has not seen, without looking.
