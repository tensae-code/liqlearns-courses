# The sub-fields of biology — multiple choice

Pick the one right answer.

**1.** What does this lesson say about sub-fields?
a) Biology is divided into sub-fields, each studying one slice of life  b) It plays no part in this topic at all  c) It happens only at night and nowhere else  d) It is found only in non-living things
**Answer: a) Biology is divided into sub-fields, each studying one slice of life**

**2.** What does this lesson say about one slice each?
a) It plays no part in this topic at all  b) Each sub-field studies one part of living things, not everything at once  c) It happens only at night and nowhere else  d) It is found only in non-living things
**Answer: b) Each sub-field studies one part of living things, not everything at once**

**3.** What does this lesson say about the map?
a) It plays no part in this topic at all  b) It happens only at night and nowhere else  c) The sub-fields map opens the year, so later units can be located on it  d) It is found only in non-living things
**Answer: c) The sub-fields map opens the year, so later units can be located on it**

**4.** What does this lesson say about sorting?
a) It plays no part in this topic at all  b) It happens only at night and nowhere else  c) It is found only in non-living things  d) Sorting the fields is the first skill — later lessons sort them into pure and applied
**Answer: d) Sorting the fields is the first skill — later lessons sort them into pure and applied**
