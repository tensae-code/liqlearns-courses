# The heart — chambers, valves, beat — multiple choice

Pick the one right answer.

**1.** What does this lesson say about four chambers?
a) The heart has four chambers  b) It plays no part in this topic at all  c) It happens only at night and nowhere else  d) It is found only in non-living things
**Answer: a) The heart has four chambers**

**2.** What does this lesson say about valves?
a) It plays no part in this topic at all  b) Valves sit between the chambers and in the vessels, keeping flow one way  c) It happens only at night and nowhere else  d) It is found only in non-living things
**Answer: b) Valves sit between the chambers and in the vessels, keeping flow one way**

**3.** What does this lesson say about the beat?
a) It plays no part in this topic at all  b) It happens only at night and nowhere else  c) The heart's own beat can be explored and heard as heart sounds  d) It is found only in non-living things
**Answer: c) The heart's own beat can be explored and heard as heart sounds**

**4.** What does this lesson say about dissection?
a) It plays no part in this topic at all  b) It happens only at night and nowhere else  c) It is found only in non-living things  d) A mammalian (cow or sheep) heart is dissected in the laboratory activity
