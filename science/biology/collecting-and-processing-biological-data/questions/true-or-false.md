# Collecting and processing biological data — true or false

Say true or false.

**1. Data should be recorded in tables as the work happens, not from memory later.**
**Answer: True** — this is what the lesson teaches.

**2. An awkward measurement that breaks the pattern should be left out of the records.**
**Answer: False** — it is recorded honestly — it is still data.

**3. Averages and graphs are part of processing data.**
**Answer: True** — this is what the lesson teaches.

**4. A presentation needs only the conclusion, not the method.**
**Answer: False** — it states the question, the method, the processed results and the conclusion, so others can check the work.
