# Collecting and processing biological data — multiple choice

Pick the one right answer.

**1. When should the plan for collecting data be made?**
a) After the measurements  b) Before the work starts — what, in what units, how often, on how many  c) It is never needed  d) Only for examinations
**Answer: b) Before the work starts — what, in what units, how often, on how many**

**2. What should happen to a measurement that breaks the pattern?**
a) It is erased  b) It is changed to fit  c) It is recorded honestly — it is still data  d) It is hidden from the presentation
**Answer: c) It is recorded honestly — it is still data**

**3. Which set names processing steps?**
a) Guessing, hoping, concluding  b) Sorting, ordering, averages, and turning tables into graphs  c) Copying, memorising, reciting  d) Watching, waiting, wandering
**Answer: b) Sorting, ordering, averages, and turning tables into graphs**

**4. Why is scientific presentation part of the method?**
a) It makes the work look tidy  b) It lets others follow, check and repeat the work  c) It is required by law everywhere  d) It replaces the conclusion
**Answer: b) It lets others follow, check and repeat the work**
