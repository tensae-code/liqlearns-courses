# Collecting and processing biological data — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (Biological research stands on data handled well: collect it by planned observation and measurement, record it in order, process it — sorting, averages, tables and graphs — and present it so others can check and use it.) and explain each key fact in their own words. Practice deepens by applying the lesson's idea to a fresh example from the learner's own surroundings and saying why it fits, without looking.
