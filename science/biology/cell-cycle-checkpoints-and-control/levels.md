# Cell cycle checkpoints and control — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (the cell cycle is controlled at checkpoints: at the G1/S checkpoint and the M checkpoint the cell verifies that conditions are right — growth factors present, DNA doubling completed, chromosomes aligned — and halts the cycle if a check fails) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
