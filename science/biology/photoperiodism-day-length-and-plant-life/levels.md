# Photoperiodism — day length and plant life — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (plants measure the length of the day and the night — photoperiodism — and use it to time flowering and other seasonal steps, so a plant's calendar is set by light) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
