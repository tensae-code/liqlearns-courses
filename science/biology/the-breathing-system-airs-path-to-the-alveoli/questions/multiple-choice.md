# The breathing system — air's path to the alveoli — multiple choice

Pick the one right answer.

**1.** What does this lesson say about the path?
a) Air's path runs nose and nasal cavity, pharynx, larynx, trachea, bronchi and bronchioles  b) It plays no part in this topic at all  c) It happens only at night and nowhere else  d) It is found only in non-living things
**Answer: a) Air's path runs nose and nasal cavity, pharynx, larynx, trachea, bronchi and bronchioles**

**2.** What does this lesson say about alveoli?
a) It plays no part in this topic at all  b) The path ends in alveolar sacs, where gas exchange occurs  c) It happens only at night and nowhere else  d) It is found only in non-living things
**Answer: b) The path ends in alveolar sacs, where gas exchange occurs**

**3.** What does this lesson say about voice box?
a) It plays no part in this topic at all  b) It happens only at night and nowhere else  c) Sound is formed in the larynx, at the vocal cords  d) It is found only in non-living things
**Answer: c) Sound is formed in the larynx, at the vocal cords**

**4.** What does this lesson say about epiglottis?
a) It plays no part in this topic at all  b) It happens only at night and nowhere else  c) It is found only in non-living things  d) The epiglottis guards the trachea when you swallow
**Answer: d) The epiglottis guards the trachea when you swallow**
