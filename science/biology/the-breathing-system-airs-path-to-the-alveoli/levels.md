# The breathing system — air's path to the alveoli — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (air travels nose, pharynx, larynx, trachea, bronchi and bronchioles to the alveolar sacs where gas exchange occurs — with the voice made in the larynx and the epiglottis guarding the trachea) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: comparing this lesson's facts with a neighbouring lesson's, and explaining them without looking.
