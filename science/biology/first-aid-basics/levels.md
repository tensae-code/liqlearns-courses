# First aid basics — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (First aid is the first help given to a person who is injured or suddenly taken ill, before medical help takes over: keep the person and yourself safe, keep the airway open and breathing going, stop bleeding, keep the person still and warm, and send for help.) and explain each key fact in their own words. Practice deepens by applying the lesson's idea to a new example the learner has not seen, without looking.
