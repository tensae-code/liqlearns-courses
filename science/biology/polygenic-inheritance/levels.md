# Polygenic inheritance — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (some traits are controlled by many genes together — polygenes, multiple-gene inheritance — taught by Sudan's Grade 12 book as §5 of its genetics unit, printed p. 170) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: sorting named traits into single-gene and polygenic, and explaining why a polygenic trait grades through a population, without looking.
