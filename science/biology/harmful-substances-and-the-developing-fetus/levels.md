# Harmful substances and the developing fetus — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (the placenta feeds the fetus but does not seal it off: alcohol, nicotine and narcotic drugs pass through it and can harm the developing baby, which is why those substances are forbidden in pregnancy) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
