# Comparing invertebrate body systems — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (Across the invertebrate phyla the same life jobs — feeding, breathing, transport, control, excretion — are done by ever more complete systems, from diffusion alone in the simplest animals to closed vessels, brains and kidneys in the highest.) and explain each key fact in their own words. Practice deepens by applying the lesson's idea to a new example the learner has not seen, without looking.
