# Compensation point — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (the compensation point is the light intensity at which a plant's photosynthesis exactly balances its respiration — the plant makes as much food as it burns, so there is no net gain and no net loss) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
