# Information transfer in ecosystems — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (ecosystems run on information as well as energy and matter: physical, chemical and behavioural signals pass from a source through a channel to a receptor — the bee's dances, the silkworm moth's bombykol, a plant's phytochrome reading light, and the volatiles an attacked tobacco plant releases to summon parasitoids) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
