# PCR — polymerase chain reaction — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (PCR copies one chosen piece of DNA over and over in a tube by cycling three temperature steps — denaturation at about 96°C, where the double strand separates; annealing at 55–65°C, where primers bind; and extension at 72°C, where Taq polymerase builds the new strands — so the number of copies doubles with every cycle) and explain each key fact in their own words. Practice deepens by applying the lesson's idea to a new example the learner has not seen, without looking.
