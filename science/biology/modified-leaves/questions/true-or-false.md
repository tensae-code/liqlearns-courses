# Modified leaves — true or false

Say true or false.

**1.** A Venus flytrap's trap is a modified leaf.
**Answer: True**

**2.** Leaf tendrils, like those of the passion fruit, are modified roots.
**Answer: False — tendrils are modified leaves (or leaf parts) that coil around a support so the plant can climb.**

**3.** Swollen leaves, like those of aloe vera, store water.
**Answer: True**
