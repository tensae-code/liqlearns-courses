# Blood and its components — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (Blood is a liquid tissue: red cells, white cells and platelets carried in a watery plasma — each component with its own job in transport and defence.) and explain each key fact in their own words. Practice deepens by applying the lesson's idea to a new example the learner has not seen, without looking.
