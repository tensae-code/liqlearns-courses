# Cell signalling — the membrane as receiver — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (the plasma membrane is also a receiver: it carries receptor proteins that catch message molecules from outside the cell and pass the signal inward, so the cell answers hormones and other signals without the messenger entering) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
