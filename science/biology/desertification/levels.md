# Desertification — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (desertification is fertile land turning to desert under overgrazing, over-cultivation, tree loss and a drying climate — a named Mediterranean problem in Greece's Grade 11 book, fought by careful grazing, tree planting and care of water) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
