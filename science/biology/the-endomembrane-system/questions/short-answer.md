# The endomembrane system — short answer

Answer in your own words.

**1.** State the one thing this lesson teaches and explain it.
**Answer: the endomembrane system is the cell's inner production line: the endoplasmic reticulum makes proteins and lipids, vesicles carry them to the Golgi apparatus for finishing and addressing, and lysosomes digest — membranes flowing into one another as one working system. endomembrane system (ER, Golgi, lysosomes, vesicles)**

**2.** Explain Greece's way of teaching this.
**Answer: endomembrane system (ER, Golgi, lysosomes, vesicles)**
