# The endomembrane system — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (the endomembrane system is the cell's inner production line: the endoplasmic reticulum makes proteins and lipids, vesicles carry them to the Golgi apparatus for finishing and addressing, and lysosomes digest — membranes flowing into one another as one working system) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
