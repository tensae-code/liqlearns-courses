# The cell cycle — interphase prepares — true or false

Say true or false.

**1. Division is how bodies grow, wounds heal and organisms reproduce; cells pass through an ordered cycle whose interphase prepares the cell — G1 growth and building-block gathering, S phase copying the DNA, G2 further preparation — before the mitotic phase divides nucleus (karyokinesis) and cytoplasm (cytokinesis).**
**Answer: True** — this is what the lesson teaches.
