# Classification by form vs by genes — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (living things can be classified by their form — morphological classification, التصنيف الشكلي — or by their genes — genetic classification, التصنيف الجيني — and Palestine's Grade 10 book compares the two) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: taking an organism the learner already groups by its looks and saying what a genetic grouping would rest on instead, and explaining the comparison without looking.
