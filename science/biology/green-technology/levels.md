# Green technology — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (green technology is technology designed to protect the environment — producing energy and goods and handling waste in ways that use fewer resources and do less harm, so development can be sustained) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
