# Teeth — four kinds, one structure — true or false

Say true or false.

**1.** The teeth are incisors, canines, premolars and molars.
**Answer: True**

**2.** Shaped for the job has nothing to do with this lesson’s topic.
**Answer: False** — the lesson teaches it directly.

**3.** A tooth has a crown, enamel, dentine, pulp and a root.
**Answer: True**

**4.** First work has nothing to do with this lesson’s topic.
**Answer: False** — the lesson teaches it directly.
