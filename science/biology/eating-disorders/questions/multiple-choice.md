# Eating disorders — multiple choice

Pick the one right answer.

**1.** Which two eating disorders does Ecuador's Biología — 1ro BGU name?
a) Anorexia and bulimia
b) It plays no part in this topic at all
c) It happens only at night and nowhere else
d) It is found only in non-living things
**Answer: a) Anorexia and bulimia**

**2.** Where does the book teach eating disorders?
a) It plays no part in this topic at all
b) Inside "Salud integral" (Sección 6, Tema 2), in a cause→effect table
c) It happens only at night and nowhere else
d) It is found only in non-living things
**Answer: b) Inside "Salud integral" (Sección 6, Tema 2), in a cause→effect table**

**3.** Which causes share the book's cause→effect table with eating disorders?
a) It plays no part in this topic at all
b) It happens only at night and nowhere else
c) Drugs, alcohol, sedentarism and pollution
d) It is found only in non-living things
**Answer: c) Drugs, alcohol, sedentarism and pollution**

**4.** What does the book itself note about anorexia and bulimia in Ecuador?
a) It plays no part in this topic at all
b) It happens only at night and nowhere else
c) It is found only in non-living things
d) Ecuador lacks updated statistics on them
**Answer: d) Ecuador lacks updated statistics on them**
