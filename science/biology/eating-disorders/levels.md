# Eating disorders — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (eating disorders — anorexia and bulimia — are taught by Ecuador's book inside "Salud integral", in a cause→effect table with drugs, alcohol, sedentarism and pollution, and the book notes Ecuador lacks updated statistics on anorexia and bulimia) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: setting this lesson beside the substance-abuse lesson (the same "Salud integral" pages read for a different cause) and explaining both without looking.
