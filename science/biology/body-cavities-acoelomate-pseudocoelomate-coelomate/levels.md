# Body cavities — acoelomate, pseudocoelomate, coelomate — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (Animals are sorted by the cavity inside the body wall: acoelomates have no cavity — the gut sits in solid tissue; pseudocoelomates have a cavity not lined by mesoderm; coelomates have a true coelom, a cavity fully lined by mesoderm, in which the organs lie and move.) and explain each key fact in their own words. Practice deepens by applying the lesson's idea to a new example the learner has not seen, without looking.
