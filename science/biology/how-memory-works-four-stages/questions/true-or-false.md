# How memory works — four stages — true or false

Say true or false.

**1. memory in four stages (sensory, under a second; first-level, seconds to minutes — the verification code you forget at once; second-level, minutes to years; third-level, possibly permanent — your own name), with the study advice built into the mechanism: repeat, and bind new information to old; short-term memory tied to the hippocampus, long-term to changed and new synapses.**

**Answer: True** — this is what the lesson teaches (普通高中教科书《生物学》选择性必修1 稳态与调节 (Senior High Biology, Selective Compulsory Book 1: Homeostasis and Regulation, People's Education Press, 2019-standard edition)).

**3. The lesson's topic has nothing to do with how memory works — four stages.**
**Answer: False** — the whole lesson is how memory works — four stages.
