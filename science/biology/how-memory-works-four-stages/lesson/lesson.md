# How memory works — four stages

## Do it first
Before you read anything: think about this lesson's title — How memory works — four stages. Write down, or say aloud, anything you already know about it, and one question you want answered. Then read on and check yourself at the end.

## The idea
Memory works in four stages — sensory memory under a second, first-level memory of seconds to minutes (the verification code you forget at once), second-level memory of minutes to years, and third-level memory that may be permanent — and study works with the mechanism: repeat, and bind new information to old. No lesson in this course taught this on its own before, so this lesson is built for it — from China's People's Education Press biology textbooks, which teach it as a named topic.
