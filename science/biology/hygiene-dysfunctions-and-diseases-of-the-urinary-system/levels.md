# Hygiene, dysfunctions and diseases of the urinary system — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (the urinary system is kept healthy by hygiene, and its dysfunctions and diseases are recognised early — kidney-stone (calculi) pain is often confused with radiculitis, which delays treatment) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
