# Diurnal and nocturnal organisms — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (living things keep biological rhythms — some are active by day and some by night, and each is fitted to its time: flowers open and close at set hours, and nocturnal animals see in the dark with large eyes and a reflective eye layer) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
