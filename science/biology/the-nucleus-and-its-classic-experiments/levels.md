# The nucleus — and its classic experiments — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (the nucleus controls the cell, and its control role is proved by four classic experiments set side by side — axolotl nuclear transplant, salamander egg constriction, amoeba cutting and Acetabularia grafting — opened by a cloned-cow case, with chromatin against chromosome closing the account) and explain each key fact in their own words.
