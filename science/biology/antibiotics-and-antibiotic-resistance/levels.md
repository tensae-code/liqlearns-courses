# Antibiotics and antibiotic resistance — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (antibiotics kill bacteria — Fleming's discovery of penicillin in 1928 opened the antibiotic age — but bacteria evolve resistance, so an antibiotic that once cured can fail, as with MRSA) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
