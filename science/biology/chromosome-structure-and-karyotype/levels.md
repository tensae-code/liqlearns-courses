# Chromosome structure and karyotype — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (A cell's long DNA is packaged with protein into chromosomes — DNA wound around histone proteins into nucleosomes, the string folded into chromatin that is loose (euchromatin) or dense (heterochromatin) — each chromosome's shape is named by where its centromere sits, and a karyotype is the individual's whole set of chromosomes photographed, cut out and arranged in order) and explain each key fact in their own words. Practice deepens by applying the lesson's idea to a new example the learner has not seen, without looking.
