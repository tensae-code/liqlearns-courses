# Community structure — layers, seasons and richness — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (a community has a structure: its species are layered vertically, patterned horizontally and changed with the seasons, and its species richness — how many species it holds — is its measure) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
