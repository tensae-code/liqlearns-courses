# Pesticides and the environment — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (pesticides protect crops, but they persist in the environment and concentrate as they pass through food chains — bioaccumulation — harming wildlife and human health far beyond the field that was sprayed) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
