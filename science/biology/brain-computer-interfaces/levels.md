# Brain–computer interfaces — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (a brain–computer interface reads the brain's signals and lets them control a machine directly — implanted arrays give stronger signals at the cost of surgery, while scalp EEG needs no surgery but reads weaker signals) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
