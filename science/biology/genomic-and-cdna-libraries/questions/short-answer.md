# Genomic and cDNA libraries — short answer

Answer in your own words.

**1.** State the one thing this lesson teaches and explain it.
**Answer: a genomic library stores a whole genome as cloned DNA fragments in bacteria — every gene shelved — while a cDNA library is built from a cell's messenger RNA copied back into DNA, so it shelves only the genes that cell was using; a labelled probe finds the wanted clone by hybridisation. a genomic library holds a whole genome (p. 61); cloning mRNA to build a cDNA library (p. 64); nucleic-acid hybridisation to detect clones (p. 64)**
