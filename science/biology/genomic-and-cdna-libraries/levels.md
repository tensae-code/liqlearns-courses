# Genomic and cDNA libraries — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (a genomic library stores a whole genome as cloned DNA fragments in bacteria — every gene shelved — while a cDNA library is built from a cell's messenger RNA copied back into DNA, so it shelves only the genes that cell was using; a labelled probe finds the wanted clone by hybridisation) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
