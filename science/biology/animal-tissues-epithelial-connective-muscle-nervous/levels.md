# Animal tissues — epithelial, connective, muscle, nervous — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (an animal's cells are organised into four tissue kinds — epithelial tissue covering and lining, connective tissue joining and supporting, muscle tissue moving, and nervous tissue carrying messages — each kind built of cells fitted to its one job) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
