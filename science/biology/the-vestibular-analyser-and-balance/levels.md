# The vestibular analyser and balance — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (balance is sensed by the vestibular analyser, which controls static and dynamic balance and carries its signals along the vestibular nerve — the system whose disturbance appears as motion sickness) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
