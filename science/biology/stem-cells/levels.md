# Stem cells — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (Stem cells are cells that are not yet specialised: they can divide to make more cells like themselves, and they can turn into specialised cells of different kinds — the body's source of new specialised cells.) and explain each key fact in their own words. Practice deepens by applying the lesson's idea to a new example the learner has not seen, without looking.
