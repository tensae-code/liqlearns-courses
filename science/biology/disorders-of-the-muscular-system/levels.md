# Disorders of the muscular system — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (the muscular system has its own named disorders — strains and cramps from overuse and diseases that waste or weaken the muscle fibres themselves — taught in Greece's Grade 10 book as their own section, with care and prevention) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
