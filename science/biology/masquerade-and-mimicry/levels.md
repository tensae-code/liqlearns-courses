# Masquerade and mimicry — the hoverfly that imitates a bee — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (a harmless animal can survive by imitating a defended one — mimicry — and Costa Rica's Grade 11 anthology opens its whole ecology course with one case: Eristalis tenax, the hoverfly that imitates a bee) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: setting this lesson beside the relationships lessons (who benefits, who is harmed, who is only fooled?) and explaining all of it without looking.
