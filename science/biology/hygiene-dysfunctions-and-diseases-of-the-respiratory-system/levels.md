# Hygiene, dysfunctions and diseases of the respiratory system — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (the respiratory system is protected by hygiene against its risk factors and diseases, and infectious patients cover mouth and nose and use strictly individual utensils, linen and objects so the disease does not spread) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
