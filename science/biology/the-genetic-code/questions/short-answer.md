# The genetic code — short answer

Answer in your own words.

**1.** State the one thing this lesson teaches and explain it.
**Answer: the genetic code is the dictionary of life: bases are read in threes — codons — each codon naming one amino acid, with AUG as the start signal and three codons as stops; the code is nearly universal, the standing proof that all life shares one ancestry and one language. the genetic code as a "musical code"; full code table in appendix (p. 87)**

**Answer: the genetic code as a "musical code"; full code table in appendix (p. 87) the genetic code: triplet bases matched to amino acids using the genetic-code table in the same decoding exercise (AUG start, UAG/UGA/UAA stop)**
