Today: The genetic code.

Remember this one thing: the genetic code is the dictionary of life: bases are read in threes — codons — each codon naming one amino acid, with AUG as the start signal and three codons as stops; the code is nearly universal, the standing proof that all life shares one ancestry and one language.
