# Germination — what a seed needs, two ways it grows — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (a seed needs water, air (oxygen) and suitable warmth to germinate — epigeal in the bean, hypogeal in maize) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: comparing this lesson's facts with a neighbouring lesson's, and explaining them without looking.
