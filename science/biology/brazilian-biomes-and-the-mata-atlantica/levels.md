# Brazilian biomes and the Mata Atlântica — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (Brazil has its own biomes, and the Mata Atlântica — the Atlantic Forest — is disappearing, which is why Brazil's textbook gives it a whole chapter framed as a cry for help) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: setting this lesson beside the Biomas chapter's question (paradises or inexhaustible resources?) and beside the great-land-biomes lesson, and explaining all three without looking.
