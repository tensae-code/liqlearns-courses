# The European Code Against Cancer — short answer

Answer in your own words.

**1.** State the one thing this lesson teaches and explain it.
**Answer: the European Code Against Cancer is a short public list of everyday rules — do not smoke, keep a healthy weight, move daily, eat well, limit alcohol, respect the sun, and take the offered screenings and vaccinations — reproduced in Greece's Grades 8–9 appendix as the Greek and European way of teaching cancer prevention.
