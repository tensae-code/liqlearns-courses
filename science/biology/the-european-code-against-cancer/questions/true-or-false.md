# The European Code Against Cancer — true or false

Say true or false.

**1. European Code Against Cancer reproduced as a health appendix (Greek/EU way of teaching cancer prevention)**
**Answer: True** — this is what the lesson teaches.

**2. This topic is taught in Greece's Gymnasio and Lykeio biology books as named content.**
**Answer: True** — this is what the lesson teaches (Βιολογία Β΄ & Γ΄ Γυμνασίου (Biologia B' & C' Gymnasiou) — Vivlio Mathiti, Grades 8–9).

**3. The lesson's topic has nothing to do with the european code against cancer.**
**Answer: False** — the whole lesson is the european code against cancer.
