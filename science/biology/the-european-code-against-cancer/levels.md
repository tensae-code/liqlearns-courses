# The European Code Against Cancer — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (the European Code Against Cancer is a short public list of everyday rules — do not smoke, keep a healthy weight, move daily, eat well, limit alcohol, respect the sun, and take the offered screenings and vaccinations — reproduced in Greece's Grades 8–9 appendix as the Greek and European way of teaching cancer prevention) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
