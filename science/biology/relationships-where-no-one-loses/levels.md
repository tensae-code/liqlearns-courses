# Relationships where no one loses — mutualism and commensalism — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (mutualism benefits both species (plus/plus); commensalism benefits one and leaves the other unaffected (plus/zero)) and explain each key fact in their own words. Practice deepens by using more examples of the same facts, then the harder corners: comparing this lesson's facts with a neighbouring lesson's, and explaining them without looking.
