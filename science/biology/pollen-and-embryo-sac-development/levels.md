# Pollen and embryo sac development — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (before a flower can be pollinated, its gametes must be built: pollen grains develop in the anther, each carrying the male gametes, and the embryo sac develops inside the ovule, carrying the egg cell — the two developments that pollination and fertilisation join) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
