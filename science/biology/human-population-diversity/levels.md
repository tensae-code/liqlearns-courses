# Human population diversity — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (human populations vary — in skin colour, blood groups, body build and a thousand inherited traits — but the variation runs within one single species and mostly inside every population, so biology finds no separate human races, only one variable kind) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
