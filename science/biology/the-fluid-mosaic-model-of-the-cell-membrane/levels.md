# The fluid mosaic model of the cell membrane — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (the cell membrane is a fluid mosaic: a double layer of phospholipids that can flow, with proteins scattered through it like tiles in a mosaic — and each kind of membrane protein does its own job) and explain each key fact in their own words. Practice deepens by matching each key fact to what it shows or does, without looking.
