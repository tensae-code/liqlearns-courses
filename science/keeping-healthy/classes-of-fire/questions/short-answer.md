# Classes of fire — short answer

Answer in your own words.

**1.** Explain: class by fuel.
**Answer: The classes sort fires by what burns. Class A fires burn solid materials — wood, paper, cloth, rubbish. Class B fires burn flammable liquids — petrol, paraffin, paint. Class C fires burn gases — cooking gas and other fuel gases. Class D fires burn metals. Class E fires involve live electrical equipment. Class F fires burn cooking oils and fats, as in a deep pan or fryer.**

**2.** Explain: why the class matters.
**Answer: The class decides the safe response. Water cools a Class A fire but spreads a burning liquid and is dangerous on live electricity and on burning oil. Knowing the class is knowing which extinguisher and which method can be used — and which must never be used.**

**3.** Explain: name it before you fight it.
**Answer: The first step with any fire is to identify what is burning. Look at the fuel, name the class, and only then choose how to act — or judge the fire too big, raise the alarm and get out. A small fire of the wrong class fought the wrong way becomes a big fire.**
