# Classes of fire — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (fires are sorted into classes by what is burning — A: solids like wood and paper, B: flammable liquids, C: gases, D: metals, E: electrical fires, F: cooking oils and fats — because the right way to fight a fire depends on its class.) and explain each key fact in their own words. Practice deepens by applying the lesson's idea to a new example the learner has not seen, without looking.
