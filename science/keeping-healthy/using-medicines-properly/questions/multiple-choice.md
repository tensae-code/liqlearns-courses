# Using medicines properly — multiple choice

Pick the one right answer.

**1. Using medicines properly means —**
a) taking them as directed, in the dose directed  b) taking double to heal faster  c) sharing them with anyone sick
**Answer: a) taking them as directed, in the dose directed**

**2. A medicine's dose is measured by —**
a) a guess  b) a health worker  c) the youngest child
**Answer: b) a health worker**

**3. This lesson comes from —**
a) the Amhara student book  b) the Oromia teacher guide (evidence)  c) the SNNP guide's stimulants subtopic
**Answer: b) the Oromia teacher guide (evidence)**
