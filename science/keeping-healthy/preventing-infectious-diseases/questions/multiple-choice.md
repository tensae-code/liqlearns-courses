# Preventing infectious diseases — multiple choice

Pick the one right answer.

**1.** (Sub lesson 1) This sub lesson is mainly about…
a) Strengthen the body, block the roads  b) A topic from a different lesson  c) Nothing in this lesson  d) Only the questions page

**2.** (Sub lesson 2) This sub lesson is mainly about…
a) Remove the breeding places, vaccinate  b) A topic from a different lesson  c) Nothing in this lesson  d) Only the questions page
**Answer: a) Remove the breeding places, vaccinate**

**3.** (Sub lesson 3) This sub lesson is mainly about…
a) When illness comes anyway  b) A topic from a different lesson  c) Nothing in this lesson  d) Only the questions page
**Answer: a) When illness comes anyway**

**4.** (Whole lesson) This lesson teaches one thing: prevention and cure of infectious diseases — strengthening the immune system, blocking the roads of spread, removing mosquito breeding places, vaccination, and rest and a doctor when illness comes — as Bangladesh's Class 5 book teaches it. That is…
a) True, in the sub lessons' own order  b) False  c) Only in the video  d) Not in the book cited
**Answer: a) True, in the sub lessons' own order**

**5.** (Whole lesson) The book behind this lesson is…
a) Bangladesh, Grade 5 — *Elementary Science Class 5*, printed p. 49  b) A book from another country  c) No book — it is uncited  d) A teacher guide only
**Answer: a) Bangladesh, Grade 5 — *Elementary Science Class 5*, printed p. 49**
