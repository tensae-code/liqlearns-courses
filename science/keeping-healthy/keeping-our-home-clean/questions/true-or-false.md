# Keeping our home clean — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 2) Keeping the home clean is separate from keeping the body clean, with no link between them.**
**Answer: False** — The guide extends personal hygiene to the home.

**2. (Sub lesson 1) A clean toilet is part of the home's health.**
**Answer: True** — The guide's competency names the toilet itself.

**3. (Sub lesson 2) A dirty home and surroundings can bring disease to a family.**
**Answer: True** — A clean home protects from many diseases — so a dirty one endangers.
