# Food adulteration and public health — multiple choice

Pick the one right answer.

**1.** (Sub lesson 1) This sub lesson is mainly about…
a) Adulterated for profit  b) A topic from a different lesson  c) Nothing in this lesson  d) Only the questions page
**Answer: a) Adulterated for profit**

**2.** (Sub lesson 2) This sub lesson is mainly about…
a) The harm to public health  b) A topic from a different lesson  c) Nothing in this lesson  d) Only the questions page
**Answer: a) The harm to public health**

**3.** (Sub lesson 3) This sub lesson is mainly about…
a) A unit done, not read  b) A topic from a different lesson  c) Nothing in this lesson  d) Only the questions page
**Answer: a) A unit done, not read**

**4.** (Whole lesson) This lesson teaches one thing: food and daily necessities adulterated for profit, and the harm to public health — Bangladesh's Class 8 Exercise Book's own unit, 'Food Adulteration!'. That is…
a) True, in the sub lessons' own order  b) False  c) Only in the video  d) Not in the book cited
**Answer: a) True, in the sub lessons' own order**

**5.** (Whole lesson) The book behind this lesson is…
a) Bangladesh, Grade 8 — *Science Exercise Book Class 8*, printed p. 149  b) A book from another country  c) No book — it is uncited  d) A teacher guide only
**Answer: a) Bangladesh, Grade 8 — *Science Exercise Book Class 8*, printed p. 149**
