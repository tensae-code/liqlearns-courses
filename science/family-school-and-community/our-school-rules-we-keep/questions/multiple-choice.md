# Our School — Rules We Keep — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Which is a school rule?**
a) Break the desks  b) Arrive on time  c) Skip homework
**Answer: b) Arrive on time** — Arriving on time is a rule; the others break rules.

**2. (Sub lesson 2) Why care for a school desk?**
a) It serves many pupils, class after class  b) Desks like it  c) No reason
**Answer: a) It serves many pupils, class after class** — Shared property must last for everyone.

**3. (Sub lesson 1) A pupil who does homework every day is —**
a) breaking a rule  b) keeping a rule  c) hiding
**Answer: b) keeping a rule** — Homework done is a rule kept.

**4. (Sub lesson 1) Wearing the uniform is part of —**
a) the school's rules  b) a game  c) a punishment
**Answer: a) the school's rules** — The uniform is among the listed rules.

**5. (Sub lesson 1) If you find a broken bench, the rule-keeping thing to do is —**
a) break it more  b) tell a teacher so it can be cared for  c) hide it
**Answer: b) tell a teacher so it can be cared for** — Report damage so property is cared for.
