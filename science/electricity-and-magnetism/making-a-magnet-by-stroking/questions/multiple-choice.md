# Making a magnet by stroking — multiple choice

Pick the one right answer.

**1.** (Sub lesson 1) This sub lesson is mainly about…
a) An object a magnet attracts can become a magnet  b) A topic from a different lesson  c) Nothing in this lesson  d) Only the questions page
**Answer: a) An object a magnet attracts can become a magnet**

**2.** (Sub lesson 2) This sub lesson is mainly about…
a) Stroking — the making, and the test  b) A topic from a different lesson  c) Nothing in this lesson  d) Only the questions page
**Answer: a) Stroking — the making, and the test**

**3.** (Whole lesson) This lesson teaches one thing: making a magnet — an object attracted by a magnet can become a magnet itself. That is…
a) True, in the sub lessons' own order  b) False  c) Only in the video  d) Not in the book cited
**Answer: a) True, in the sub lessons' own order**

**4.** (Whole lesson) The books behind this lesson are…
a) Papua New Guinea's science books (Department of Education, Papua New Guinea)  b) A book from another country  c) No book — it is uncited  d) A teacher guide only
**Answer: a) Papua New Guinea's science books (Department of Education, Papua New Guinea)**
