# Making a magnet by stroking — short answer

Answer in a sentence or two.

**1.** (Sub lesson 1) Explain, in your own words: An object a magnet attracts can become a magnet.
**Answer:** Papua New Guinea's Grade 3 textbook teaches the surprising step after magnets attracting objects: an object that a magnet attracts — an iron or steel object, such as a nail or a needle — can itself **become a magnet**. The magnet does not only pull it; it can pass magnetism into it.

**2.** (Sub lesson 2) Explain, in your own words: Stroking — the making, and the test.
**Answer:** The making is done by **stroking**: the magnet is drawn along the object again and again, in the same direction. Then comes the test — bring the stroked object near paper clips or pins. If it attracts them, the object is now a magnet itself, made by stroking.

**3.** (Whole lesson) Retell the whole lesson in its own order, one sentence per sub lesson.
**Answer:** An object a magnet attracts can become a magnet → Stroking — the making, and the test — in that order, as taught in lesson/lesson.md.
