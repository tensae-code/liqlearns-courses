# Tools and materials for electricity — short answer

Answer in a sentence or two.

**1.** What does the part "The common tools used in electricity" teach?
**Answer:** First, the **common tools used in electricity** — the tools of electrical work named as their own topic, so the learner knows the instruments of the trade before touching a circuit.

**2.** What does the part "The common materials used in electricity" teach?
**Answer:** Then, the **common materials used in electricity** — the materials the work is done with and uses up, named beside the tools, so tools (kept and used again) and materials (used in the job) are never confused.
