# Tools and materials for electricity

## Do it first
Before you read: an electrician comes to fix a light. What is in the bag they carry — which tools, and which materials will be used up in the job? Separate your list into tools and materials. Then read on: this is Rwanda's way in — its Primary 5 electricity unit names the tools and materials before it builds the circuit.

## Sub lesson 1 — The common tools used in electricity

First, the **common tools used in electricity** — the tools of electrical work named as their own topic, so the learner knows the instruments of the trade before touching a circuit.

## Sub lesson 2 — The common materials used in electricity

Then, the **common materials used in electricity** — the materials the work is done with and uses up, named beside the tools, so tools (kept and used again) and materials (used in the job) are never confused.

## The key ideas

- **The common tools used in electricity** — the tools of electrical work.
- **The common materials used in electricity** — the materials of electrical work.
