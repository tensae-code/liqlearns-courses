# Series and parallel circuits — one path, many paths — true or false

Say true or false.

**1. (Sub lesson 1)** In series, the same current passes through each load in turn.
**Answer: True**

**2. (Sub lesson 2)** Brightness and current behave the same way in series and parallel wirings.
**Answer: False**

**3. (Sub lesson 2)** An ammeter is used in the builds to read the current.
**Answer: True**
