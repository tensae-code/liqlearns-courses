# Using household electrical appliances safely — multiple choice

Pick the one right answer.

**1.** (Sub lesson 1) The using order for an appliance is…
a) Plug, forget, leave  b) Know it, connect it rightly, work it, disconnect it  c) Open it, wash it, plug it  d) Borrow, use, return
**Answer: b) Know it, connect it rightly, work it, disconnect it**

**2.** (Sub lesson 2) The iron part that presses the cloth and gets hot is the…
a) Handle  b) Soleplate  c) Cord  d) Switch box
**Answer: b) Soleplate**

**3.** (Sub lesson 2) Safe handling of the iron includes…
a) Leaving it standing on cloth  b) Disconnecting it when its work is done  c) Wetting the cord  d) Touching the soleplate to test it
**Answer: b) Disconnecting it when its work is done**

**4.** (Sub lesson 1) These lessons sit in the Grade 4 book's…
a) Health field only  b) Experimentation field  c) Animals unit  d) Weather unit
**Answer: b) Experimentation field**
