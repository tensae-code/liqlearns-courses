# Classification — scientific names and the seven ranks — true or false

Say true or false. If false, say the right thing.

**1. (Sub lesson 1)** Felis catus is the scientific name of the cat.
**Answer: True**

**2. (Sub lesson 1)** Common names are the same everywhere in the world.
**Answer: False — common names vary; the scientific name is unambiguous.**

**3. (Sub lesson 2)** The seven ranks run Kingdom, Phylum, Class, Order, Family, Genus, Species.
**Answer: True**
