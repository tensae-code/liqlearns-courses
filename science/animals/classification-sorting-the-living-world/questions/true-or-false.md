# Classification — sorting the living world — true or false

Say true or false. If false, say the right thing.

**1. (Sub lesson 1)** An ordered shelf is like classification: things are easier to find.
**Answer: True**

**2. (Sub lesson 2)** Every specimen you collect should be kept forever.
**Answer: False — observe, record and release unharmed.**

**3. (Sub lesson 2)** Features such as wings and legs can be used to build grouping criteria.
**Answer: True**
