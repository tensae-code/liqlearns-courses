# Animals — mammals — true or false

Say true or false. If false, say the right thing.

**1. (Sub lesson 1)** A whale is a mammal, not a fish.
**Answer: True**

**2. (Sub lesson 1)** All mammals live on land.
**Answer: False — whales and dolphins live in water.**

**3. (Sub lesson 2)** Mammals have hair.
**Answer: True**
