# Animal word–picture reading support — multiple choice

Pick the one right answer.

**1.** (Sub lesson 1) Sweden's Lässtöd is…
a) A story about animals  b) A picture–word table naming 24 animals  c) A test of reading speed  d) A list of words with no pictures
**Answer: b) A picture–word table naming 24 animals**

**2.** (Sub lesson 1) In the table, each animal is shown as…
a) A word alone  b) A number  c) A picture with its name beside it  d) A sound only
**Answer: c) A picture with its name beside it**

**3.** (Sub lesson 1) The pupil works…
a) Word first, picture never  b) Picture first, word with it  c) Neither — the teacher reads everything  d) Only with animals they already know
**Answer: b) Picture first, word with it**

**4.** (Sub lesson 1) The support exists so that pupils who cannot yet read can still…
a) Skip the animals work  b) Name and work with the animals  c) Read faster than everyone  d) Memorise the alphabet
**Answer: b) Name and work with the animals**

**5.** (Sub lesson 1) Which of these animals is in the table of 24?
a) Elephant  b) Perch  c) Penguin  d) Giraffe
**Answer: b) Perch**

**6.** (Sub lesson 1) "Lässtöd" means…
a) Animal book  b) Picture page  c) Reading support  d) Copy page
**Answer: c) Reading support**
