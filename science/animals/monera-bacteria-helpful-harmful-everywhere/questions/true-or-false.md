# Monera — bacteria: helpful, harmful, everywhere — true or false

Say true or false. If false, say the right thing.

**1. (Sub lesson 1)** Some bacteria move with flagella.
**Answer: True**

**2. (Sub lesson 2)** All bacteria are harmful.
**Answer: False — bacteria also do useful work, such as curdling milk.**

**3. (Sub lesson 2)** Cyanobacteria bloom in warm, nutrient-rich slow water.
**Answer: True**
