# Reversible reactions

## Do it first
Water evaporates from an open dish and is gone. In a sealed bottle it stops disappearing — yet evaporation has not stopped. Before reading, say what balances it.

[Picture 21671 — Evaporation and condensation in a closed bottle.]

Some reactions go to completion — irreversible for practical purposes.

Reversible reactions can run in both directions: the products can react back to reactants, shown with the ⇌ arrow.

In a closed bottle, evaporation and condensation run together — the doorway example to equilibrium.

[GIF 21672 — forward and reverse running at once]
