# Variables in a fair test — short answer

Answer in a sentence or two.

**1.** (Sub lesson 1) Name the three kinds of variable and give each one's job in one sentence.
**Answer: The independent variable is the one thing deliberately changed; the dependent variable is the outcome measured; the controlled variables are all the other things that could matter, held fixed so they cannot affect the result.**

**2.** (Sub lesson 2) Why does changing two variables in one run destroy the experiment?
**Answer: Because when the outcome changes you cannot tell which of the two changes caused it — the result no longer speaks about either variable on its own, so the test is not fair.**

**3.** (Sub lesson 2) From the guide's answer: list four things that must be controlled in the dissolving investigation.
**Answer: Any four of: temperature, stirring speed, amount of solvent, amount of solute, kind of solvent, kind of solute, impurity/brand effects, pH — all held the same on every run.**

**4.** (Sub lesson 3) What must a finished fair test show for its result to be checkable by someone else?
**Answer: The full record: what was changed, what was measured and how (the same way every run), what was held fixed, the results table, and the graph of the investigated variable against the outcome.**
