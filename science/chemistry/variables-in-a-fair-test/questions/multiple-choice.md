# Variables in a fair test — multiple choice

Pick the one right answer.

**1.** (Sub lesson 1) The independent variable is…
a) What you measure  b) The one thing you choose to change  c) Everything you hold fixed  d) The graph you draw
**Answer: b) The one thing you choose to change**

**2.** (Sub lesson 1) The dependent variable is…
a) What you measure — the result you watch  b) The thing you change  c) The apparatus list  d) A variable you ignore
**Answer: a) What you measure — the result you watch**

**3.** (Sub lesson 1) In the guide's answer to Experiment 1, the independent variable is…
a) Solubility  b) Particle size  c) Temperature  d) pH
**Answer: b) Particle size**

**4.** (Sub lesson 2) A test is fair when…
a) Everything changes at once  b) Only one variable changes and the rest are held fixed  c) The result matches the hypothesis  d) It is done quickly
**Answer: b) Only one variable changes and the rest are held fixed**

**5.** (Sub lesson 2) In the dissolving investigation, the measured outcome is…
a) The colour of the solid  b) The time for complete dissolution  c) The mass of the beaker  d) The smell of the solution
**Answer: b) The time for complete dissolution**

**6.** (Sub lesson 3) The result is presented as…
a) A spoken claim only  b) A results table and a graph of the investigated variable against time  c) A drawing of the beaker  d) Nothing — the test speaks for itself
**Answer: b) A results table and a graph of the investigated variable against time**
