# Hands-on — Variables in a fair test

The lesson with your hands and your feet, not only your eyes.

## Name the variables
For each short investigation, write its independent variable, dependent variable and two controlled variables: (a) does temperature change how fast solid A dissolves? (b) does particle size change how fast solid A dissolves? (c) does stirring change how fast solid A dissolves? Check against sub lesson 1.

## Spot the unfair test
Three learners test dissolving. Learner 1 changes only the temperature. Learner 2 crushes the solid finer and stirs faster. Learner 3 changes only the stirring, but uses more water in one run. Say which tests are fair and exactly what spoils the others, using sub lesson 2.
