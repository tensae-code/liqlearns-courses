Today: **Electron configuration — sublevel notation**.

Configuration is written as coefficient (main level) + letter (sublevel s, p…) + superscript (electrons in the sublevel): lithium 1s²2s¹, sodium 1s²2s²2p⁶3s¹ = (2,8,1)…

Fluorine and chlorine are compared: same outer pattern (…2,7 / …2,8,7), different shell counts — the pattern that explains group similarity (same valence arrangement)…
