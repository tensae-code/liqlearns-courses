# The liquid state — true or false

Say whether each statement is true or false.

**1. ** Where does evaporation happen — At the surface, at any temperature
**Answer: True**

**2. ** Which particles escape in evaporation — In the nucleus
**Answer: False**

**3. ** What causes surface tension — Inward pull on surface particles
**Answer: True**

**4. ** What is viscosity — The –OH position
**Answer: False**
