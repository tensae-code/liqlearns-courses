# Salts that turn basic — matching

Match each question on the left with its answer on the right.

1. Which ion hydrolyses in sodium ethanoate? — d
2. What is left behind in the water? — a
3. What does Kh link to? — b
4. What does the strong base's cation do? — c

**Answer key:** 1–d: The ethanoate (anion) · 2–a: OH⁻ — so the solution is alkaline · 3–b: The parent acid's Ka (via Kw) · 4–c: Nothing — it spectates
