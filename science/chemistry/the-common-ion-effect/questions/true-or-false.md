# The common ion effect — true or false

Say whether each statement is true or false.

**1. ** What does a common ion do to ionisation — Suppresses it
**Answer: True**

**2. ** Which principle explains it — Solvents (and, historically, anaesthetics)
**Answer: False**

**3. ** Where does the equilibrium shift — Back toward the un-ionised form
**Answer: True**

**4. ** What is built on this effect — Electricity and water
**Answer: False**
