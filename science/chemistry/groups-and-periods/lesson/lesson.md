## Groups and periods

Periods are the 7 horizontal rows (same number of shells within a period; lengths 2, 8, 8, 18, 18, 32, 32; periods 1–3 short, 4–6 long;

each period but the first starts with an alkali metal and ends with a noble gas; period number = number of occupied shells). Groups are the vertical columns whose members share outer-electron patterns.

An activity has pupils rebuild the table's logic themselves: sort the first 18 elements by same-outer-configuration (columns appear) and by same shell count (rows appear).3.2).
