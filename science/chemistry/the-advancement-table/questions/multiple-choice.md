# The advancement table — multiple choice

Pick the one right answer.

**1.** (Sub lesson 1) In the advancement table, every row is driven by…
a) The temperature  b) The advancement x  c) The molar mass  d) The volume
**Answer: b) The advancement x**

**2.** (Sub lesson 2) xmax is set by…
a) The first product formed  b) The catalyst  c) The limiting reactant running out  d) The solvent
**Answer: c) The limiting reactant running out**

**3.** (Sub lesson 3) If τ = xf/xmax = 1, the reaction was…
a) Total  b) Reversible  c) Slow  d) Impossible
**Answer: a) Total**

**4.** (Sub lesson 1) A product with coefficient 2 grows, at advancement x, by…
a) x  b) 2x  c) x/2  d) 0
**Answer: b) 2x**

**5.** (Sub lesson 2) To find the limiting reactant the course…
a) Tests each reactant and keeps the larger xmax  b) Tests each reactant and keeps the smaller xmax  c) Weighs the products  d) Reads the colour
**Answer: b) Tests each reactant and keeps the smaller xmax**

**6.** (Sub lesson 3) τ compares the final advancement with…
a) The initial amount  b) The molar volume  c) xmax  d) Avogadro's number
**Answer: c) xmax**
