# Lesson plan — Valence — the combining power of an element

**Course:** Science · **Title:** Chemistry · **Lesson:** Valence — the combining power of an element
**Place in the curriculum:** Chemistry — appended to Unit 17 (CURRICULUM.md)
**The one thing this lesson teaches:** chemical valency — an element's combining power — read the Syrian way off models of water, ammonia and methane: in shared-bond compounds the number of shared pairs an atom forms, in ionic compounds the number of electrons it loses or gains (Syria, Grade 8 — *الفيزياء والكيمياء للصف الثامن الأساسي (Physics & Chemistry, Grade 8 Basic)*, U1 L3, printed p. 19)

## Sub lessons
1. **Valency in shared-bond compounds — shared pairs counted** — Syria reads **chemical valency** off **models of water, ammonia and methane**. In a **shared-bond (covalent) compound**, an atom's valency equals **the number of shared pairs it forms**: oxygen forms two shared pairs in water, so oxygen's valency there is 2; nitrogen forms three in ammonia — valency 3; carbon forms four in methane — valency 4.
2. **Valency in ionic compounds — electrons lost or gained** — In an **ionic compound** there are no shared pairs to count, so the book counts the other transfer: an atom's valency equals **the number of electrons it loses or gains** to complete its outer level. Sodium loses one electron — valency 1; magnesium loses two — valency 2; chlorine gains one — valency 1; oxygen gains two — valency 2.
3. **The element valency table** — The lesson gathers the countings into an **element valency table**: each element with the valency it shows in its compounds, ready to be used. The table is not decoration — it is the tool the next step of the book runs on, writing compound formulas by electrical neutrality, where the two partners' valencies must balance.

## If the learner is stuck
- Counts atoms instead of bonds → valency counts what the ONE atom does: pairs it shares, or electrons it transfers — not how many atoms stand around it.
- Uses the shared-pair counting for ionic compounds → ionic compounds share nothing: count electrons lost or gained instead — same combining power, other counting.
- Thinks the table is to be memorised whole at once → the table is a tool to consult while writing formulas; the countings behind it are what must be understood.
