# Oxygen functional groups — the map — true or false

Say whether each statement is true or false.

**1. ** Which group defines alcohols — –OH (hydroxyl)
**Answer: True**

**2. ** What does the ether group look like — It shrinks
**Answer: False**

**3. ** What group do aldehydes and ketones share — The carbonyl group, C=O
**Answer: True**

**4. ** What group defines carboxylic acids — A carboxylic acid
**Answer: False**
