# Oxygen functional groups — the map — matching

Match each question on the left with its answer on the right.

1. Which group defines alcohols? — c
2. What does the ether group look like? — d
3. What group do aldehydes and ketones share? — a
4. What group defines carboxylic acids? — b

**Answer key:** 1–c: –OH (hydroxyl) · 2–d: R–O–R — oxygen bridging carbons · 3–a: The carbonyl group, C=O · 4–b: –COOH (carboxyl)
