# Using K and Q — which way will it go?

## Do it first
Mix the chemicals in any amounts you like — the mixture is not at equilibrium. Before reading, say how one calculation could tell you which direction it will move.

[Picture 21678 — A Q-versus-K number line.]

The reaction quotient Q is the equilibrium expression filled with the concentrations right now, not at equilibrium.

If Q < K, the reaction moves forward to make more products. If Q > K, it moves in reverse. If Q = K, it is already at equilibrium.

Equilibrium concentrations are found with the ICE method: tabulate Initial, Change and Equilibrium amounts, then solve with Kc.
