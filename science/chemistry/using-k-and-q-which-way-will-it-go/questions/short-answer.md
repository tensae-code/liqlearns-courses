# Using K and Q — which way will it go? — short answer

Answer in a short sentence.

**1. ** What is Q?
**Answer: The mass-action ratio at current concentrations**

**2. ** If Q < K, which way does reaction go?
**Answer: Forward, making products**

**3. ** What does ICE stand for?
**Answer: Initial, Change, Equilibrium**

**4. ** When Q = K, what is true?
**Answer: The system is at equilibrium**
