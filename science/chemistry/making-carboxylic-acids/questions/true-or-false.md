# Making carboxylic acids — true or false

Say whether each statement is true or false.

**1. ** Oxidising an aldehyde gives… — A carboxylic acid
**Answer: True**

**2. ** What is the oxidation ladder — By exactly one proton
**Answer: False**

**3. ** Which alcohol type oxidises to an acid — A primary alcohol
**Answer: True**

**4. ** Name another route to acids. — Source, movement, changes, effects
