# The modern periodic table

## Do it first
Arrange 100+ elements so that a stranger can predict an unknown one's behaviour from its neighbours. Before reading, say what single number the whole table is sorted by.

[Picture 21626 — The table — periods across, groups down.]

The periodic law: properties of the elements repeat periodically when elements are arranged by increasing atomic number.

Rows are periods; columns are groups of elements with similar properties.

The table's order is the organising result of electron structure — the address system of the last lessons, drawn as one chart.

## Say it to your companion
Explain The modern periodic table to your companion in your own words, using the lesson's own examples. Then let your companion ask you the questions from the end of the lesson until you can answer each one without looking.
