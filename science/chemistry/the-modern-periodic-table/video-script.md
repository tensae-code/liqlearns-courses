# Video script — The modern periodic table

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Arrange 100+ elements so that a stranger can predict an unknown one's behaviour from its neighbours.

The periodic law: properties of the elements repeat periodically when elements are arranged by increasing atomic number.

Rows are periods; columns are groups of elements with similar properties.

The table's order is the organising result of electron structure — the address system of the last lessons, drawn as one chart.

Now you. Say it back: By what are elements arranged in the modern table?
Answer: Increasing atomic number.
