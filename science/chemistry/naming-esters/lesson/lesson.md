# Naming esters

## Do it first
An ester's name has two words, like a person's first name and family name — one from each parent. Before reading, say which parent gives which half.

[Picture 21702 — An ester split into its two halves.]

An ester's name has two parts: the alkyl part from the alcohol, then the alkanoate part from the acid.

Ethyl ethanoate, for example, is ethanol's ethyl joined to ethanoic acid's ethanoate.

To name an ester, split it at the ester oxygen: name the alcohol side first, the acid side second.
