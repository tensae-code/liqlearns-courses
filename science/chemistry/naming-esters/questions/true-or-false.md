# Naming esters — true or false

Say whether each statement is true or false.

**1. ** What is an ester's first name-part from — The alcohol (alkyl part)
**Answer: True**

**2. ** What is the second part from — Solid wastes and agrochemicals
**Answer: False**

**3. ** Name ethanol + ethanoic acid's ester. — Ethyl ethanoate
**Answer: True**

**4. ** Where do you split an ester to name it — Change in amount/concentration per unit time
**Answer: False**
