# Greenhouse gases — which and how much — true or false

Say whether each statement is true or false.

**1. ** Name the five greenhouse gases treated. — CO₂, H₂O vapour, CH₄, N₂O, ozone
**Answer: True**

**2. ** Which gas comes from swamps and cattle — An exercise of the same kind
**Answer: False**

**3. ** What is the largest human-driven contributor — CO₂
**Answer: True**

**4. ** N₂O comes notably from… — The hydrosphere
**Answer: False**
