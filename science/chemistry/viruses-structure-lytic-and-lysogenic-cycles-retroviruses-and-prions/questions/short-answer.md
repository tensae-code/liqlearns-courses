# Viruses — structure, lytic and lysogenic cycles, retroviruses and prions — short answer

Answer in a sentence or two.

**1.** State one thing Italy's book teaches in this lesson about lytic.
**Answer: Viruses are obligate parasites built of capsid and envelope, with DNA or RNA genomes; phages run the lytic cycle against the lysogenic cycle.**

**2.** State one thing Italy's book teaches in this lesson about reverse transcriptase.
**Answer: Retroviruses use reverse transcriptase — the exception to the central dogma — and HIV's integration into the host genome explains its latency.**

**3.** State one thing Italy's book teaches in this lesson about Prions.
**Answer: Prions and viroids are smaller pathogens still, and the mobile elements (plasmids, transposons) are presented as viruses' plausible ancestors.**
