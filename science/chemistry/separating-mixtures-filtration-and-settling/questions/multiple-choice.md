# Separating mixtures — filtration and settling — multiple choice

Pick the one right answer.

**1.** (Sub lesson 1) In filtration, the solid that stays on the filter is called the…
a) Filtrate  b) Residue  c) Solution  d) Sediment gas
**Answer: b) Residue**

**2.** (Sub lesson 2) Décantation works by…
a) Boiling the mixture  b) Letting the mixture rest so the solid settles, then pouring the liquid off  c) Shaking hard  d) Adding a chemical
**Answer: b) Letting the mixture rest so the solid settles, then pouring the liquid off**

**3.** (Sub lesson 3) Filtration can separate water + sand because the mixture is…
a) Homogeneous  b) Heterogeneous, with a visible solid phase  c) A gas  d) Pure
**Answer: b) Heterogeneous, with a visible solid phase**

**4.** (Sub lesson 1) For a mixture carrying a lot of solid, the guide's working order is…
a) Filter, and never settle  b) Settle first, then filter the poured-off liquid if it must be fully clear  c) Boil first  d) Add sugar first
**Answer: b) Settle first, then filter the poured-off liquid if it must be fully clear**

**5.** (Sub lesson 2) The wastewater-treatment station's settling stage grows out of…
a) Distillation  b) Décantation  c) The limewater test  d) Electrolysis
**Answer: b) Décantation**

**6.** (Sub lesson 3) The liquid that passes through a filter is the…
a) Residue  b) Filtrate  c) Phase  d) Mixture
**Answer: b) Filtrate**
