# Writing electron configurations — sub lessons and depth

This file is the lesson's depth record, re-expressed as its sub lessons. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Aufbau — lowest first
Sub lesson 1 questions from the type files. Pass mark: The Aufbau principle: electrons fill the lowest-energy orbitals first, in the filling order the diagram gives — stated in the learner's own words and used on one fresh example.

## Sub lesson 2 — Pauli — two per orbital, opposite spins
Sub lesson 2 questions from the type files. Pass mark: The Pauli exclusion principle: one orbital holds at most two electrons, and they must have opposite spins — stated in the learner's own words and used on one fresh example.

## Sub lesson 3 — Hund — singly before pairing
Sub lesson 3 questions from the type files. Pass mark: Hund's rule: in a set of equal-energy orbitals, electrons occupy each singly first, with spins parallel, before pairing up — stated in the learner's own words and used on one fresh example.

## Sub lesson 4 — Configurations, diagrams and the exceptions
Sub lesson 4 questions from the type files. Pass mark: With the three rules you can write the ground-state configuration and the orbital (box) diagram of any atom or ion — including the Cr/Cu-type exceptions, where a half-filled or fully filled subshell wins extra stability — stated in the learner's own words and used on one fresh example.
