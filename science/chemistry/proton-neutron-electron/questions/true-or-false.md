# Proton, neutron, electron — true or false

Say whether each statement is true or false.

**1. ** What is the atomic number Z — The number of protons
**Answer: True**

**2. ** Where are protons and neutrons found — Spontaneous as written
**Answer: False**

**3. ** Which subatomic particle is by far the lightest — The electron
**Answer: True**

**4. ** What charge does the neutron carry — The main energy level (and orbital size)
**Answer: False**
