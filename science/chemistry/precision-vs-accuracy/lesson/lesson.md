## Precision vs accuracy

Accuracy is closeness of a measurement to the true value; precision is closeness of repeated measurements to each other; a set can be either, both or neither, pictured with four archery/dart targets.

The judgement skill is practised on data: Mohammed's gold sample read on three balances (one precise-and-accurate pair, one wildly off), a jeweller's repeatedly heavy diamond weighings, and a penny-composition analysis — pupils must say which results were accurate, which precise, and why.
