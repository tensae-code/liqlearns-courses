# The four quantum numbers — true or false

Say whether each statement is true or false.

**1. ** What does n specify — The main energy level (and orbital size)
**Answer: True**

**2. ** What values can m_s take — A photon
**Answer: False**

**3. ** What does l specify — The subshell (orbital shape)
**Answer: True**

**4. ** What does m_l specify — Solvents (and, historically, anaesthetics)
**Answer: False**
