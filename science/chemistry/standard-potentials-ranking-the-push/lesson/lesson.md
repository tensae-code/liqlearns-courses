# Standard potentials — ranking the push

## Do it first
Every half-reaction has a measurable 'push'. Tabulate them against one chosen zero, and any cell's voltage becomes arithmetic. Before reading, name the zero.

[Picture 21743 — A reduction-potential ladder.]

The standard hydrogen electrode (SHE) is the reference electrode, assigned E° = 0.00 V, under standard conditions (1 mol dm⁻³, 1 atm, 298 K as presented).

Standard electrode potentials E° tabulate each half-reaction as a reduction; more positive means a stronger pull to be reduced.

Cell EMF = E°cathode − E°anode. A positive E°cell means the cell reaction is spontaneous as written. Calculations run through the section.
