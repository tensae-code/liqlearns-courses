# Position isomers — where the group sits — multiple choice

Pick the one right answer.

**1.** (Sub lesson 1) Isomers are molecules with…
a) The same structure and different formulas  b) The same molecular formula but different structures  c) Different numbers of carbon atoms only  d) No functional group
**Answer: b) The same molecular formula but different structures**

**2.** (Sub lesson 2) Position isomers arise when…
a) The functional group's place on the main carbon chain changes  b) A carbon atom is added to the chain  c) The functional group is removed  d) The chain is broken in two
**Answer: a) The functional group's place on the main carbon chain changes**

**3.** (Sub lesson 2) When a compound changes into its position isomer, its molecular formula…
a) Gains a carbon  b) Loses a carbon  c) Stays the same  d) Doubles
**Answer: c) Stays the same**

**4.** (Sub lesson 3) The functional group's place is shown in the compound's name by…
a) A colour  b) Its position number along the main chain  c) The total number of atoms  d) A Greek letter only
**Answer: b) Its position number along the main chain**

**5.** (Sub lesson 3) Two names differing only in the group's position number name…
a) The same compound twice  b) Position isomers  c) A compound and its element  d) An acid and a base
**Answer: b) Position isomers**
