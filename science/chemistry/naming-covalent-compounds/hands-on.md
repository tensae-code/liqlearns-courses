# Hands-on — Naming covalent compounds

The lesson with your hands and your feet, not only your eyes.

## Build the table
Write the prefix run as a table from the lesson: mono 1, di 2, tri 3, tetra 4, penta 5, hexa 6. Pin the book's three closing names under it: CO₂, CO, P₄O₁₀.

## Name the book's formulas
Using only your table, name CCl₄, CS₂, PCl₃, N₂O₃ and SCl₂ out loud, element by element. Check each against the rule: first element keeps its name, second takes -ide, prefixes announce the counts.

## Reverse it
Have a companion read you a name (e.g. sulfur dichloride, carbon tetrachloride) while you write the formula. Swap roles for three names each.
