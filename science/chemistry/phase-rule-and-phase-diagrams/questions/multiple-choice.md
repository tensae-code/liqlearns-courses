# Phase rule and phase diagrams — multiple choice

Pick the one right answer.

**1.** (Sub lesson 1) A phase is…
a) Any substance in the system  b) A physically distinct, mechanically separable part, uniform throughout  c) A chemical component  d) A degree of freedom
**Answer: b) A physically distinct, mechanically separable part, uniform throughout**

**2.** (Sub lesson 1) The water system (ice, liquid, vapour) has how many components?
a) Three  b) One — H₂O writes every phase  c) Two  d) Zero
**Answer: b) One — H₂O writes every phase**

**3.** (Sub lesson 2) Gibbs' phase rule is…
a) F = C + P + 2  b) F = C − P + 2  c) F = P − C + 2  d) F = C × P
**Answer: b) F = C − P + 2**

**4.** (Sub lesson 2) The criteria for phase equilibrium include…
a) Rising temperature  b) Uniform temperature and pressure, and each component's chemical potential equal in every phase  c) Only one phase present  d) Constant stirring
**Answer: b) Uniform temperature and pressure, and each component's chemical potential equal in every phase**

**5.** (Sub lesson 3) At water's triple point, F equals…
a) 2  b) 1  c) 0 — the point is invariant  d) 3
**Answer: c) 0 — the point is invariant**

**6.** (Sub lesson 3) On a two-phase boundary line of a one-component diagram, the system is…
a) Bivariant  b) Univariant — F = 1  c) Invariant  d) Not at equilibrium
**Answer: b) Univariant — F = 1**
