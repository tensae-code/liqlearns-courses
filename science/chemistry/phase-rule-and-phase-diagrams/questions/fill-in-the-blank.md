# Phase rule and phase diagrams — fill in the blank

Fill in the missing word.

**1.** (Sub lesson 1) Ice, liquid water and vapour are three _____ of one component.
**Answer: phases**

**2.** (Sub lesson 2) Gibbs' phase rule reads F = C − P + _____.
**Answer: 2**

**3.** (Sub lesson 2) At phase equilibrium each component's chemical _____ is the same in every phase.
**Answer: potential**

**4.** (Sub lesson 3) At the triple point F = 0, so the point is called _____.
**Answer: invariant**
