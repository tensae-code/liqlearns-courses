# Plastics — additives, recycling codes and plastic waste — short answer

Answer in a sentence or two.

**1.** (Sub lesson 1) List a plastic's formulation from Bulgaria's composition wheel.
**Answer: The polymer, fillers (wood flour, paper, kaolin, chalk — up to 50–60%), plasticisers, stabilisers, accelerators and colourants.**

**2.** (Sub lesson 2) Give the four exits from the plastic-waste reckoning.
**Answer: Recycling, repeated use, reduced use, and biodegradable substitutes.**

**3.** (Sub lesson 2) Why does separate collection by code matter to recycling?
**Answer: Each code is a different polymer with its own processing; mixed plastics cannot be recycled into clean new material, so the codes sort the stream before it is worked.**
