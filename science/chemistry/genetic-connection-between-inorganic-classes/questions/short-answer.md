# The genetic connection between the classes of inorganic substances — short answer

Answer in a sentence or two.

**1.** (Sub lesson 1) Why is the connection between the classes called "genetic"?
**Answer: Because each substance in a chain is generated from the one before it — the classes descend from one another like members of one family, with the same element travelling through every stop.**

**2.** (Sub lesson 2) Write sulfur's chain from the element to sodium sulfite, naming the class at each stop.
**Answer: S (nonmetal) → SO₂ (acidic oxide) → H₂SO₃ (acid) → Na₂SO₃ (salt).**

**3.** (Sub lesson 2) What reaction carries the last arrow of the metal chain, base → salt?
**Answer: Neutralisation — the base reacts with an acid to give the salt and water (Ca(OH)₂ + 2HCl → CaCl₂ + 2H₂O in the lesson's chain).**

**4.** (Sub lesson 3) A learner is given copper(II) oxide and asked to reach copper(II) sulfate in one step. Which chain arrow is used, and with what?
**Answer: The oxide → salt arrow across the meeting point: the basic oxide reacts directly with the acid — CuO with dilute sulfuric acid gives CuSO₄ and water.**

**5.** (Sub lesson 3) Why does Belarus teach this lesson before drilling the classes one by one?
**Answer: Because the connection is the map of the whole system: once the learner knows how the classes change into one another, every later section is a stop on a road already known, not a new list to memorise.**
