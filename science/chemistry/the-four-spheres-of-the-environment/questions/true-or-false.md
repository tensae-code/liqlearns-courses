# The four spheres of the environment — true or false

Say whether each statement is true or false.

**1. ** Which sphere is all the water — The hydrosphere
**Answer: True**

**2. ** Which sphere is living things — They do not react with most solutes
**Answer: False**

**3. ** Which sphere is solid Earth — The lithosphere
**Answer: True**

**4. ** Which sphere is the gas envelope — Inputs (raw materials), process, products
**Answer: False**
