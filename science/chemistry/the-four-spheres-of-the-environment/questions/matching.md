# The four spheres of the environment — matching

Match each question on the left with its answer on the right.

1. Which sphere is all the water? — c
2. Which sphere is living things? — d
3. Which sphere is solid Earth? — a
4. Which sphere is the gas envelope? — b

**Answer key:** 1–c: The hydrosphere · 2–d: The biosphere · 3–a: The lithosphere · 4–b: The atmosphere
