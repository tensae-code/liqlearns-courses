# Oxygen — its properties and tests — depth

This file is the lesson's depth record. This lesson has no sub lessons — it is one whole, single-skill lesson.

Whole-lesson pass mark: the learner can state the one thing this lesson teaches (oxygen is a colourless, odourless gas, a little denser than air, only slightly soluble in water, neutral to litmus — and it is recognised by one sure test: it relights a glowing splint.) and explain each key fact in their own words. Practice deepens by applying the lesson's idea to a new example the learner has not seen, without looking.
