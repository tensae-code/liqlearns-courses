# Lesson plan — Models of the atom — from Dalton to Bohr

## Sub lessons
1. **What a model is — a working picture** — A scientific model is a working picture of a thing too small, too far or too hidden to inspect directly. It is judged by two tests: does it explain what is already known, and does it predict what will be found next? Sri Lanka's 1969 O/L book opens the whole of chemistry this way — its first chapter is Models and Patterns, and its opening figures (figs. 1.1–1.2) set two model pictures side by side, the wave picture and the particle picture, as the frame for everything that follows.
2. **The atom models in sequence — Dalton to Thomson to Rutherford** — Dalton's model made the atom a solid, indivisible ball, one kind for each element. Thomson's measurements forced the first change: the atom contains electrons, pictured as negative particles set in a positive sphere. Rutherford's gold-foil experiment forced the next: nearly all the mass sits in a tiny central nucleus, with the electrons in the space around it — the model changed because the evidence changed, exactly as a model should.
3. **Bohr's repair — electrons in fixed levels** — Rutherford's atom should collapse, as circling electrons ought to radiate and spiral in. Bohr's model repaired it by rule: electrons occupy fixed allowed levels and do not radiate while they stay in them. Each model in the sequence keeps what the earlier one explained and repairs the point where it failed — that is the pattern the Sri Lanka book's opening chapter teaches before any chemistry proper.

## What the learner can do when it ends
1. Explain sub lesson 1 in their own words: What a model is — a working picture.
2. Explain sub lesson 2 in their own words: The atom models in sequence — Dalton to Thomson to Rutherford.
3. Explain sub lesson 3 in their own words: Bohr's repair — electrons in fixed levels.
4. Say, for each model in the sequence, what evidence or failure forced the next model to replace it.
5. Answer the lesson's questions from the lesson text alone.

## If the learner is stuck
- Loses the main idea → return to the first sub lesson: a model is a working picture, judged by explanation and prediction; every later part hangs on that frame.
- Treats a model as a photograph of the real thing → compare the wave and particle pictures in the opening figures: two different pictures, each useful where it works.
- Memorises the model names without the reasons → for each change, name the evidence that forced it (electrons found; foil scattering; the collapse problem).
