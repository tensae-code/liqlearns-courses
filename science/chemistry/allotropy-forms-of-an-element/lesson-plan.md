## Sub lessons
1. **One element, several forms** — **Allotropy** is one element existing in **more than one form** — the same atoms, arranged differently, giving substances with different properties.
2. **Molecular against non-molecular structure** — The guide's way of deepening is a structural sorting: substances of **molecular structure** against substances of **non-molecular structure**.
3. **Ozone among the examples** — **Ozone** is named in the guide **among the examples** of allotropy: oxygen's atoms also form ozone, a different substance from the oxygen of the air, though both are built from the one element.

## If the learner is stuck
- Allotropy confused with isotopes → isotopes are atoms of one element with different masses; allotropes are different forms (substances) of the one element. / Forms treated as different elements → the atoms are the same element throughout; only the arrangement differs.
