# Allotropy — forms of an element — short answer

Answer in your own words, from the lesson.

**1.** (Sub lesson 1) Define allotropy in one sentence.
**Answer:** Allotropy is one element existing in more than one form — the same atoms arranged differently, giving different substances with different properties.

**2.** (Sub lesson 3) How does ozone carry the lesson's point?
**Answer:** Ozone and the oxygen of the air are both built from the one element oxygen, yet they are different substances — same element, different form.
