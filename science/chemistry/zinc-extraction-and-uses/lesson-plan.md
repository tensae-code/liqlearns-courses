## Sub lessons
1. **Zinc's ore — zinc blende** — Zinc is not found free in nature; it is won from its ores.
2. **Extraction — roast, then reduce** — The sulfide ore is first **roasted** — heated strongly in air — converting the blende to **zinc oxide**: 2ZnS + 3O₂ → 2ZnO + 2SO₂.
3. **Uses of zinc** — Zinc works mostly as a protector and a partner.

## If the learner is stuck
- Loses the main idea → return to the first sub lesson and the Do-it-first questions: every later part hangs on that frame.
- Mixes this lesson up with a neighbour lesson → compare the two titles and say what each one is about; each lesson here teaches one thing.
- Confuses roasting with reduction → roasting changes the ore to the oxide using air; reduction takes the oxygen away using carbon. Forgets why zinc distils → its boiling point is low for a metal, so furnace heat sends it off as vapour.
