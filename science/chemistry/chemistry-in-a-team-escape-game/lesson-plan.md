# Lesson plan — Chemistry in a team escape game

**Course:** Science · **Title:** Chemistry · **Lesson:** Chemistry in a team escape game
**Place in the curriculum:** Chemistry — appended to Unit 17 (CURRICULUM.md): Finland's game-format lesson, standing beside Atomic number and mass number and The modern periodic table, whose skills its chemistry case uses
**The one thing this lesson teaches:** Finland's way of carrying chemistry inside a cooperative table escape game — four colour teams solve boxed puzzles in phase 1 and combine jigsaw pieces for a shared final puzzle in phase 2, and the game's one chemistry case is opened by a real chemistry skill: finding the six elements most common in the human body (O, C, H, N, Ca, P) and reading their atomic numbers from a periodic table to build a lock code
**This lesson's own level:** it stands on its own — a learner can land here directly and follow the whole game. Atomic number and mass number and The modern periodic table are recommended first, never forced — the game itself teaches the lookup it needs.

## Sub lessons
1. **The game itself — four teams, two phases, one goal** — the table escape game (pöytäpakopeli) as printed: ~60 minutes, at least 8 players, four colour teams at four tables, three boxed puzzles per team in phase 1 earning jigsaw pieces, then all teams combining pieces for the central final puzzle in phase 2; the game's purpose is group bonding, and its mostly general puzzles (Caesar cipher, flags, matchsticks, health alphabet, football World Cup text, arithmetic) are named as general.
2. **The chemistry case — six elements in the human body** — the red team's case: an article about elements plus a periodic table, with the six elements most common in the human body (O, C, H, N, Ca, P) marked in UV pen; the body fact is taught straight — these six build almost all of you — and the periodic table is met as a working tool lying inside the case.
3. **Atomic numbers open the lock — look up, substitute, solve** — the yellow card's formula takes the six elements' atomic numbers (O 8, C 6, H 1, N 7, Ca 20, P 15), read from the periodic table; substituted in, they form the lock code — atomic number practised as a lookup skill, with the lock itself as the check.

## Before this lesson
- Recommended first: **Atomic number and mass number** and **The modern periodic table**. Recommended, never forced.

## What the learner can do when it ends
1. Describe the game's set-up and two phases, and say why no team can finish alone.
2. Name the six elements most common in the human body, with their symbols.
3. Read any of the six elements' atomic numbers from a periodic table and explain how the six numbers become the lock code.
4. Say honestly what kind of book this is — game instructions, not a textbook, with one chemistry puzzle among general ones — and what Finland's way is.
5. Answer the lesson's questions from the lesson text alone.

## What you need
Paper and a pencil, and a printed periodic table for the lookup work. For the hands-on game: three small boxes or envelopes, simple locks or code strips, colour cards for four teams, jigsaw pieces (a cut-up picture does), a UV pen if one is available — ordinary classroom materials only; no chemicals are used anywhere in this lesson.

## If the learner is stuck
- Loses the game's shape → return to the two phases: alone at your table first (three boxes), together at the centre after (one puzzle). Every detail hangs on that frame.
- Cannot find an atomic number → the number sits in the element's cell in the periodic table, with the symbol; find the symbol first, then read the number — that lookup is the skill the game teaches.
- Thinks the whole game is chemistry → name the other puzzles (cipher, flags, matchsticks, arithmetic): the game is for bonding, and exactly one case carries chemistry. Saying so straight is part of the lesson.
