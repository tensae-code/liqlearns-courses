# Hands-on — Chemistry in a team escape game

The lesson with your hands and your feet, not only your eyes.

## Run the chemistry case on paper
Work in a team of at least four. Take a printed periodic table and a card listing the six elements most common in the human body by name only — oxygen, carbon, hydrogen, nitrogen, calcium, phosphorus. Each team member takes at least one element: find its cell in the table, read its atomic number aloud, and have a second member check it in the table before anyone writes it down. When all six numbers are agreed, the team says them in the order the names were given: 8, 6, 1, 7, 20, 15. The checking step is the point — in the real game, one wrong lookup means a lock that stays shut.

## Build a mini escape game
In your team, set up a three-box game for another team, following the book's shape: three boxed puzzles at your table (envelopes or folded cards do), one of them the chemistry case — an article paragraph about elements, a periodic table, and a yellow formula card whose code is built from atomic numbers you choose. Every solved box earns a piece of a cut-up picture; the pieces from all boxes complete the picture, which is the final puzzle. Write the game-master sheet as Finland's book does: every code written down, so the game can be run and checked. Swap games with another team and play theirs in two phases — your table first, then together.

## Spot the tool in daily life
The periodic table in this game is a working tool, not a wall decoration. Find one other place — a laboratory wall, a textbook's inside cover, a phone app — where the table is kept ready to be looked up in, and describe in three sentences who reaches for it and what they read from it.
