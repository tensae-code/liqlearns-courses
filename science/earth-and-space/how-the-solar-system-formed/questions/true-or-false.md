# How the solar system formed — from cloud to Sun — true or false

Say true or false, and fix the false ones.

**1. (Sub lesson 1)** The solar system is about 4.5 billion years old.
**Answer: True**

**2. (Sub lesson 1)** As the cloud shrank, it spun more slowly.
**Answer: False — it spun faster as it shrank, and flattened into a disk.**

**3. (Sub lesson 2)** Gravity pulled the densest part of the cloud inward to start the collapse.
**Answer: True**
