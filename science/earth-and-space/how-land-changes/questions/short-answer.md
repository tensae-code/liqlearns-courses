# How land changes — short answer

Answer in a sentence or two.

**1.** (Sub lesson 1) What is the first fact of the lesson, before causes?
**Answer: The land's shape changes — the shape a place has today is not the shape it must keep.**

**2.** (Sub lesson 2) Why does a dune keep changing?
**Answer: Because wind and sand keep meeting: the event that built it never stops working, so its shape keeps answering.**
