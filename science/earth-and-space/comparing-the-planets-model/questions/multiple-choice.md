# Comparing the planets — a model of distance, size and behaviour — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** In the guide's way, one model serves —
a) only the distance comparison  b) every comparison — distance, size, position and behaviour  c) only display at exhibitions  d) the teacher's marking
**Answer: b) every comparison — distance, size, position and behaviour.**

**2. (Sub lesson 1)** Before building, the class must first fix —
a) the colours  b) the scale for distances and sizes  c) the planet names in Amharic  d) the exhibition date
**Answer: b) the scale for distances and sizes.**

**3. (Sub lesson 2)** Indoors, the model is built with —
a) a telescope  b) string and a bead  c) a computer only  d) chalk circles only
**Answer: b) string and a bead.**

**4. (Sub lesson 2)** Planet behaviour in this lesson is summarised from —
a) a memorised list  b) the model itself  c) the guide's answer key alone  d) a song
**Answer: b) the model itself.**

**5. (Sub lesson 2)** The correct planet order, keyed from the student book, begins —
a) Mercury, Mars, Earth, Venus  b) Mercury, Venus, Earth, Mars  c) Venus, Mercury, Earth, Mars  d) Earth, Venus, Mercury, Mars
**Answer: b) Mercury, Venus, Earth, Mars.**
