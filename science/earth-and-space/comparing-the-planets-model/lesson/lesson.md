# Comparing the planets — a model of distance, size and behaviour

## Do it first

Stretch a string across the room. Put a ball at one end: the Sun. Before any numbers, place eight beads and balls where YOU think the planets go, at the sizes you think they are. The lesson is fixing that first guess into a true scale.

## Sub lesson 1 — Building one model for every comparison

[Picture 34511 — a playground-scale model]

Constructing a solar-system model is treated as **mandatory** in the guide, because **one model serves every comparison** — distance, size, position and behaviour are all read off the same build. The teacher helps the class **fix the scale** first: one chosen step or one bead-length stands for a set distance, and the planet sizes are scaled to match as nearly as classroom materials allow. Build it **on the playground** if there is one; indoors, build it with **string and a bead** along the classroom.

## Sub lesson 2 — Reading the planets off the model

With the model standing, each planet's **behaviour** is summarised from it: how far out it sits, how big it is against its neighbours, how its position orders it, and how it moves. The comparisons the class defends all come back to the model — point at the string, not at a memorised list. That is the guide's way: the model is the evidence.

## Say it to your companion

Explain the lesson's main facts to your companion in your own words. Then let them ask you one hard question — and answer it from the lesson, not from memory of the words.

## Do It Yourself

1. State the scale your model uses, for distance and for size.
2. Walk your model and name each planet's two nearest neighbours.
3. Summarise one planet's behaviour — position, size, movement — pointing at the model as your evidence.
