# Preventing Sports Injuries and First Aid — sub lessons and depth

This file is the lesson's depth record, re-expressed as its sub lessons. The questions live in the type files; this file is the by-sub-lesson view. The parts run from the youngest book's teaching to the oldest, as the placements stack them.

## Sub lesson 1 — Preventing sports injuries — the causes and the list
Pass mark: name the four diagrammed causes and four items of the prevention list.

## Sub lesson 2 — Sports injuries — the kinds
Pass mark: name the four injury kinds from the guide's list.

## Sub lesson 3 — First aid and RICE
Pass mark: apply the four RICE steps in order to a pretend ankle injury and say what each letter stands for.

## Sub lesson 4 — RICER and the first-aid kit (teacher guide — evidence)
Pass mark: name the kit's five item kinds, RICER's fifth step, and the blood-safety rule.

## Sub lesson 5 — First aid and injury management — the Grade 8 definitions (teacher guide — evidence)
Pass mark: define first aid and injury management in the guide's words, and say what a safe sporting return must not do (damage or compromise the body).
