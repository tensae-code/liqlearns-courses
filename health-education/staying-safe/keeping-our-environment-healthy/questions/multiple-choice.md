# Keeping Our Environment Healthy — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** In Namibia's guide, Session 2 teaches care for the environment through…
a) Recycling groups, the effects of litter, and reusing waste material  b) Only planting trees  c) Ignoring waste
**Answer: a) Recycling groups, the effects of litter, and reusing waste material**

**2. (Sub lesson 1)** A recycling group…
a) Throws all waste in one pile  b) Sorts waste so material can be recycled  c) Burns litter
**Answer: b) Sorts waste so material can be recycled**

**3. (Sub lesson 1)** Reusing waste material means…
a) Using it again instead of throwing it away  b) Hiding it  c) Dropping it outside
**Answer: a) Using it again instead of throwing it away**
