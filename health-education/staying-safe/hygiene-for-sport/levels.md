# Hygiene for Sport — Wash After Exercise — sub lessons and depth

This file is the lesson's depth record, re-expressed as its sub lessons. The questions live in the type files; this file is the by-sub-lesson view. The parts run from the youngest book's teaching to the oldest, as the placements stack them.

## Sub lesson 1 — Wash after exercise — the pupil's lesson
Pass mark: tell the sweat–bacteria chain in order and state the wash rule and the kit rule.

## Sub lesson 2 — Three things, three benefits (teacher guide — evidence)
Pass mark: name the three basic things and one benefit of each kind.

## Sub lesson 3 — Clean after exercise — shower, towel, feet (teacher guide — evidence)
Pass mark: give the guide's shower rule in order (shower soon, clean towel, dry clothes) and the foot rule (water shoes; wash and dry, especially between the toes).
