# Karoora barnootaa — Birsaga Ijaaruu

**Barnoota:** Afaan Oromoo — Afaan Oromootiin · **Mata-duree:** Dubbisuu · **Barnoota:** Birsaga Ijaaruu
**Bakka inni karoora keessatti qabu:** Kutaa 2 — Dubbisuu (CURRICULUM.md).
**Waan barnoonni kun barsiisu isa guddaa:** birsaga — ijaaruu isaanii, qoqqooduu isaanii, walitti makamuu isaanii fi lakkaa'uu isaanii.
**Sadarkaa barnoonni kun mataa isaa qabu:** Kutaa Qubee irratti dhaabbata; furtuu dubbisa jechaa ti.

Karoorri barnootaa **waan gubbaa barnootaa irra taa'u** illee ni jedha: bakka armaan gaditti mallatteeffame irratti, fuulli barnootaa dabalaa qaba — fakkii, GIF, viidiyoo, sagalee. Bakki hundi **"fakkii …" jedhamee jechaan** barreeffama, sarara xiqqaa waan barataan fakkii sanaan godhu ibsu waliin. Jechoonni fakkii sana baatu yeroo barnoonni ijaaramaa jiruu fi yeroo AI kitaabota irraa baratu; marsariitii irratti dabalaan dhugaa bakka sana bu'ee sararri xiqqaan sun qajeelcha barataa ta'ee hafa. Fakkiwwan seera fakkii hordofu (suuraa dhugaa, yookiin aartii dhugaa, madda isaa waliin). GIF tu dursa bakka wanti socho'aa yookiin mul'achaa agarsiifamuu qabu — GIF asitti sekondii 1–2 ti.

## Barnoota xixiqqoo
Qaamolee barnoota kanaa, tartii isaanii tiin — tarree barataan jalqaba irraa argu, fuuldura cufamee, tokkoon tokkoon isaanii yeroo inni duraa mirkanaa'u banamu (balballi: README, "Kutaalee, Barnoota fi Barnoota Xixiqqoo (2026-11-08 murteeffame)"):

1. **Dubbifamaa fi dubbachiiftuu walitti makamuu** — birsagni qaama lama irraa ijaarama: C + a → Ca.
2. **Chaartii birsagaa — gabaabaa fi dheeraa** — chaartii kitaabaa T, Ts, V, W, X, Y, Z dhaaf.
3. **Jechoota qoqqooduu fi walitti makamuu** — dubbisni karaa lamaaniin deema: mala → ma-la; Na+ma = nama.
4. **Birsaga lakkaa'uu** — rukutuun lakkaa'uu; jechoota birsaga sadii fi afurii qoqooduu.

Kuusaan darbuu: gaaffiiwwan barnoota xiqqaa hunda — sadarkaan ciminaa gaaffiiwwan keessatti hin barreeffamne, kanaaf tuutni gaaffii barnoota xiqqaa guutuun kuusaa darbuuti.

## Barnoota kana dura
- Kan dura yaalamu: Qubee; Sagalee — Gabaabaa fi Dheeraa; Qubee Dachaa. Yaalamu malee dirqama miti.

## Waan barataan dhuma irratti gochuu danda'u
1. Birsaga dubbifamaa fi dubbachiiftuu irraa ijaaruu.
2. Tarree chaartii gabaabaa fi dheeraa dubbisuu.
3. Jecha birsagaatti qoqqooduu fi birsaga gara jechaatti walitti makamuu.
4. Birsaga jecha keessatti lakkaa'uu.

## Waan si barbaachisu
Waraqaa fi irraasaa.

## Adeemsa barnootaa (tartii isaan)
1. **Jalqaba ofumaan godhi** — barataan mala qoqqoodee walitti maka.
2. **Ibsa** — walitti makamuu; chaartii; qoqqooduu fi walitti makamuu; lakkaa'uu (lesson/lesson.md).
   - FAKKII DABALI [Picture 9855]: fakkii qaamoleen dubbifamaa fi dubbachiiftuu birsaga ta'uuf walitti makamuu jiran → barataan walitti makamuu afaaniin jedha: C + a → Ca.
   - GIF DABALI [GIF 9900]: fakkii qaamoleen birsagaa walitti siqaa jiran: C + a → Ca → barataan yeroo isaan walitti makaman birsaga jedha.
   - FAKKII DABALI [Picture 9856]: fakkii chaartii birsagaa → barataan tarree dubbisa, birsagni hundi yeroo inni jedhu ifa.
   - GIF DABALI [GIF 9901]: fakkii jechi mala gara ma + la qoqqoodamee irra deebi'ee walitti makamuu jiru → barataan qoqqooda afaaniin jedha, sana booda walitti makamuu.
   - FAKKII DABALI [Picture 9857]: fakkii jechi mala qaama birsagaa lama keessatti → barataan qaama hunda akeekee birsaga jedha.
   - FAKKII DABALI [Picture 9860]: fakkii qaamoleen birsagaa nama ta'uuf walitti makamuu jiran, jechoota lakkoofsaa waliin → barataan walitti maka, sana booda birsaga lakkaa'a.
   - SAGALEE DABALI: sagaleen tarree chaartii fi jechoota qoqqoodaman suuta dubbisu → barataan booda jedha.
3. **Hiriyaa keetti himi** — jecha barreessuu, rukuttaa isaa rukutuu, qoqqooduu wal jijjiiraa.
4. **Gaaffiiwwan** — questions/ irraa: filannoo hedduu, deebii gabaabaa, bakka duwwaa guutuu, walitti fiduu, dhugaa yookiin soba, barreessuu (levels.md).
5. **Harka hojii** — hands-on.md.
6. **Ofumaa Godhi** — tarree W barreessi; jechoota afur qoqoodi; sadii walitti maki; birsaga lakkaa'i.

## Yoo barataan rakkate
- Jechi dheeraan ni cufa → qoqoodi: rukuttaa rukuttaan hojjedhu, jechi kam illee ni bana.
- Tarree dheeraan ni maka → dubbifamaa tokko qofa qabaa, tarree isaa qofa shaakali.
