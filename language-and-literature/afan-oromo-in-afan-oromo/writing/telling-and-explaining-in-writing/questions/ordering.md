# Barreessuudhaan Himuufi Ibsuu — tartiiba qabsiisuu

Wantoota tartiiba sirrii keessa kaa'i.

**1. (Barnoota xiqqaa 2)** Tarkaanfii buna danfisuu tartiiba qabsiisi.
**Deebii: Buna bitachuu → ibidda qabsiisuu → buna miicuu fi waaduu → daakuu → bishaan danfisuu → jabanaa keessa naquu → tasgabbeessuu → kubbaayyaa miicuu → soogiddaa moo sukkaaraa gaafachuu → naquu fi tajaajiluu**

**2. (Barnoota xiqqaa 3)** Hojii gumee irraa tartiiba qabsiisi.
**Deebii: Gumee hojjechuu → damee tokko keeyyata tokko ijaaruu → barreeffama keeyyata sadii**
