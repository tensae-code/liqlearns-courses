# Malleen Dubbii — maddoota

**Barnoota:** Afaan Oromoo — Afaan Oromootiin, Kutaa 3 (Jecha).

Barnoonni kun qajeelchota barsiisotaa Afaan Oromoo harka jiran QOFA irraa ijaarame — kitaabni barataa barnoota kanaaf harka hin jiru. Wanti barnoota kana keessa jiru hundi kitaaba armaan gaditti hordofa: waan qajeelchi mataa isaa barsiisu kuufame; wanti tokkollee hin uumamne, kitaabni biraa yookiin wanti alaa hin fayyadamne. Bakka bu'iinsi yeroo dubbisa Itoophiyaa 2026-11-12 (faayiliin Kutaa 7 guyyaa isuma irra deebii dubbisaatiin xumurame) barreeffame, booda irra deebi'ee hin ijaaramne.

**Kitaaba 1:** *Barnoota Afaan Oromoo, Qajeelcha Barsiisaa Kutaa 7ffaa* (qajeelcha barsiisaa — ragaa; Afaan Oromoo akka afaan dhalootaa barattootaa ti) — Itoophiyaa, Biiroo Barnootaa Bulchiinsa Magaalaa Finfinnee, 2014 A.L.H. / 2022, fuula maxxanfame 1–170. Seera fuulaa: fuulli maxxanfame = fuula PDF − 3. Guutummaatti, fuula fuulaan, dubbifame. Bakka bu'iinsi: liqlearns-courses-work/ethiopia-2026-11-11/afan-oromo/g07-teacher-placements.md.

**Akka barnoonni kitaaba waliin wal qabatu.** Qajeelchi Kutaa 7 malleen dubbii (*malleen dubbii*) tokko tokkoon boqonnaa afwalaloo isaa keessatti barsiisa — boqonnaa isuma gilgaalli walaloo barreessuu isaa (Gilgaala 7) barattoonni isaan akka fayyadaman gaafatu — fakkeenya hojjetame isaan gidduutti Gilgaala 8 keessatti qooda. Barnoonni kun malleen guutummaatti baata, tartiiba barsiisa qajeelchaa tiin, fakkeenya maqaa dhahame qajeelchaa mataa isaa waliin (iddeessa swarm kaannisaa; kuusaa fakkoomii):

| Qaama barnootaa | Madda |
|---|---|
| Barnoota xiqqaa 1 — Wal bira qabuu | Fuula maxxanfame 139–145 (malleen tokko tokkoon barsiifaman) — *iddeessa*, fakkeenya qajeelchaa "Oromoon kaannisa" waliin; *akkasaa*, jechoota akeekaa isaa waliin (akka, amma, fakkaata, caala, gaha) |
| Barnoota xiqqaa 2 — Jireenya kennuu, fi hammeenya diriirsuu | Fuula maxxanfame 139–145 — *nameessa*; *arbeessa* kallattii isaa lamatti, *arbeessuu* ol fi *kineessuu* gad |
| Barnoota xiqqaa 3 — Faallaa, dhaabachuu, fi waamuu | Fuula maxxanfame 139–145 — *habalaka*; *eemitii/fuggisoo*; *fakkoomii*, kuusaa fakkoomii qajeelchaa waliin (odaa = eenyummaa Oromoo, gugee = nagaa, bofa = haxxummaa, madaallii = haqaa, diimaa = qabsoo); *hinjirree dubbisuu*; *dubbiilee qoolaa* |
| Barnoota xiqqaa 4 — Mallattoo maqaa dhahi | Fuula maxxanfame 135–136 — hojii qoodinsaa Gilgaala 8: fakkeenya hojjetame malleen gidduutti qoodame (gosoota maqaa dhahaman: habalaka, arbeessuu, akkasaa, nameessa, bak-buusa-iddeessa); mammaaksi ja'a barnoota xiqqaa kana keessatti qoodame hiika malleen mataa isaanii fi fakkeenya maqaa dhahame qajeelchaa irratti ijaarame, bifa gilgaalaa tiin |
| Picture 12514 | Barnoota kanaaf LiqLearns dhaan hojjetame — malleen sarara fakkii keessatti: mucaa leenca cinaa jiru (akkasaa), waraabessa dubbatu (nameessa), muka odaa (fakkoomii) |

Fakkiin kitaabaa barnoota kana keessatti hin garagalfamu, barreeffamni kitaabaa maqaa malleen qajeelchaa, fakkeenya isaa maqaa dhahame fi wanta gilgaalaa gabatee keessatti maqaa dhahame bira hin garagalfamu, kanneen qabiyyee barsiisaa mataa isaanii ti.

**Lakkoofsi fudhatamaa: biyyoota 0 keessatti barsiifama — barnoonni kun ragaa qajeelcha barsiisotaa qofa irratti dhaabbata (Itoophiyaa), asitti maqaa dhahame, eessattiyyuu hin lakkaa'amu.**
