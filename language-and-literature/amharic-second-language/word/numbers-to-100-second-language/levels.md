# Numbers to 100 (Second Language) — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub Lessons"). Practice is tied to the learner's skill number, as before. The questions live in the type files; this file is the by-sub-lesson view. The sub lessons go: the numbers themselves, the colours of the world the numbers count, and the little words that stand for people so sentences can begin.

## Sub lesson 1 — Numbers 0–100
Sub lesson 1 questions from the type files. Pass mark: read any named number off the chart (Picture 8582), write a spoken number, and run the tens 0–100 without a miss.

## Sub lesson 2 — Colours
Sub lesson 2 questions from the type files. Pass mark: name the colour of each patch on Picture 8583 when pointed at, in any order — saying it, hearing the check, and repairing a wrong one the guide's way.

## Sub lesson 3 — Pronouns and sentences with them
Sub lesson 3 questions from the type files. Pass mark: read the eight pronouns off Picture 8584, point each at who it stands for, and build and read one true sentence with a pronoun (እሱ መጣ / እሷ መጣች shape).
