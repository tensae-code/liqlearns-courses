# Fidel for New Speakers — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub Lessons"). Practice is tied to the learner's skill number, as before. The questions live in the type files; this file is the by-sub-lesson view. The sub lessons follow the guide's own chapter order for a new speaker: the first confusable pairs, the middle pairs, the last families with the double sounds, and finally the whole set in order.

## Sub lesson 1 — The first pairs (በ ሰ ሸ ከ)
Sub lesson 1 questions from the type files. Pass mark: read both pairs' rows aloud in order, match ከ to ከበሮ, sing the በ row's song-path without missing an order, and write one family keeping the line.

## Sub lesson 2 — The middle pairs (ለ አ ዘ ዠ ደ ጀ ጸ ጰ ጠ ጨ)
Sub lesson 2 questions from the type files. Pass mark: read the ten families' rows, tell each confusable pair apart by eye and by ear (ዘ/ዠ, ደ/ጀ, ጸ/ጰ, ጠ/ጨ), and fill a missing order in a row.

## Sub lesson 3 — The last families and the double sounds
Sub lesson 3 questions from the type files. Pass mark: read the remaining families' rows (ገ ነ ኘ ተ ቸ ቀ ኀ ፐ የ ዐ ፀ ወ መ ሀ ሠ ረ ፈ) and read the double-sound fidels (ሏ ሷ ሿ ኳ) as one sound with a w inside, not two letters.

## Sub lesson 4 — All the fidels in order
Sub lesson 4 questions from the type files. Pass mark: read down the full chart (Picture 8580) row by row in order, and write any named family from memory, keeping the line — the Chapter 11 consolidation, proved.
