# Language and Literature

One top-level course (his ruling, 2026-11-11): this folder holds
English, Amharic and every country's own language as parts inside
it — at most about fifty top-level courses on the website, with
subjects nested inside them.

- **English** — the English course, built from the government
  textbooks of every country in the library. Its tree still stands
  at `english/` in this repo (built before this folder existed);
  it is the English part of this course.
- **Amharic** — Ethiopia's own-language course, at `amharic/`
  inside this folder. Built 2026-11-11 onward from Ethiopia's
  Amharic-medium government textbooks (pre-primary workbooks,
  student textbooks and teacher guides, Grades 1–10 as held).
  Inside, the course is organised by LEVELS, not grades (his
  ruling, 2026-11-11): a learner's place is found by what they
  prove. Grades appear only as provenance, in each lesson's
  sources.

Every other country's own language joins this folder the same
way when its turn comes.
