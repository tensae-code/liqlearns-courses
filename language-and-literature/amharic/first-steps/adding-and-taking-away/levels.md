# Adding and Taking Away — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The order is the book's own: addition first,
subtraction later, comparing signs right after subtraction. This
lesson is the pre-primary first meeting — the Maths course owns
the full version.

## Sub lesson 1 — Adding — putting together
Sub lesson 1 questions from the type files. Pass mark: say what
መደመር means, and answer picture additions by counting — the
3-family, the make-ten sums (5+5, 6+4, 3+7), and a tally addition.

## Sub lesson 2 — Taking away
Sub lesson 2 questions from the type files. Pass mark: say what
መቀነስ means, name the − sign, and answer picture subtractions by
counting what is left, tallies included.

## Sub lesson 3 — Comparing — bigger, smaller, equal
Sub lesson 3 questions from the type files. Pass mark: put the
right sign — > ይበልጣል, < ያንሳል, = እኩል ይሆናል — between two
counted sets, and say why.
