# Caring for Books and Shared Things — true or false

Say true or false.

**1. (Sub lesson 1)** You should write your answers inside the textbook itself.
**Answer: False**

**2. (Sub lesson 2)** A small tear in a page should be repaired at once, before it grows.
**Answer: True**

**3. (Sub lesson 3)** If a shared thing breaks, you should hide it and say nothing.
**Answer: False**
