# Manners and Living Together — depth

This lesson is one whole lesson with no sub lessons, so this file
is its depth record for the whole lesson. Pass mark for the whole
lesson: greet and help an elder the respectful way, use the three
kind sentences — sorry, thank you, እባክዎ (please) — correctly, and
name the togetherness acts (playing, studying, eating and helping
together; helping elders; respecting each other). Practice deepens
with harder corners: the manners sayings judged true or false,
including the trap "please is a wrong thing to say" (false), and
new scenes — helping a person with a disability, supporting an
elderly neighbour — judged by the same kind rule.
