# Counting — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons climb the way the books climb:
1–9 first, zero and 10 next, the names and the run to 20 after
that, and Ethiopia's own Ge'ez numerals last.

## Sub lesson 1 — Counting 1 to 9
Sub lesson 1 questions from the type files. Pass mark: count a set
of up to 9 things touching each once, say the whole count, match
a counted set to its numeral, and read the names አንድ … ዘጠኝ.

## Sub lesson 2 — Zero, and counting to 10
Sub lesson 2 questions from the type files. Pass mark: say what
zero means (empty — nothing there), read and write 0, count 0–10
in order, and fill one missing number in a short line.

## Sub lesson 3 — Counting to 20 and number names
Sub lesson 3 questions from the type files. Pass mark: count sets
and write how many up to 20, write the 0–20 line in order, and
match digits to number words both ways (2 = ሁለት, አስር = 10).

## Sub lesson 4 — Ge'ez numerals — Ethiopia's own numbers
Sub lesson 4 questions from the type files. Pass mark: read ፩–፲,
match each Ge'ez numeral to its Western numeral, and fill the
missing Ge'ez numeral in the line ፩ _ ፫ _ ፭ _ ፯ _ ፱.
