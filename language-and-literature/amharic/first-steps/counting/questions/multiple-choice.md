# Counting — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** You count a set of spoons, touching each one once. The last number you say is 5 — አምስት. How many spoons are there?
a) 4  b) 5  c) 6
**Answer: b) 5** — the last number said is the whole count.

**2. (Sub lesson 1)** Which picture set matches the number 3 — ሶስት?
a) a set of 2 cups  b) a set of 4 pencils  c) a set of 3 strawberries
**Answer: c) a set of 3 strawberries** — the book's own set for 3.

**3. (Sub lesson 2)** A jar has nothing in it at all. How many biscuits are in the jar?
a) ዜሮ — 0  b) አንድ — 1  c) ብዙ — many
**Answer: a) ዜሮ — 0** — zero is empty; zero is the number for nothing there.

**4. (Sub lesson 2)** Which line counts in the right order?
a) 0, 1, 2, 3, 4, 5  b) 0, 2, 1, 3, 5, 4  c) 1, 0, 2, 3, 4, 5
**Answer: a) 0, 1, 2, 3, 4, 5** — zero comes first, then the line climbs one by one.

**5. (Sub lesson 3)** Which digit matches the word ስምንት?
a) 7  b) 8  c) 9
**Answer: b) 8** — ስምንት is the name of 8.

**6. (Sub lesson 3)** In counting, the counter (ቆጣሪ) is —
a) the things being counted  b) the one who does the counting  c) the last number said
**Answer: b) the one who does the counting** — the things themselves are the thing counted (ተቆጣሪ).

**7. (Sub lesson 4)** Which Ge'ez numeral means 5?
a) ፬  b) ፭  c) ፮
**Answer: b) ፭** — ፬ is 4 and ፮ is 6.

**8. (Sub lesson 4)** ፲ means —
a) 9  b) 10 — አስር  c) 20
**Answer: b) 10 — አስር.**
