# Nature and Man-Made — writing

Write the names, the book's own writing work.

**1. (Sub lesson 1)** Copy-write the names of the two natural places: ሰሜን ተራራ (Simien Mountains), የአባይ ወንዝ (the Abay river).
**Done when:** each name is copied whole, word by word.

**2. (Sub lesson 2)** Write the names of 3 living things and 3 non-living things.
**Answer shape:** living — for example animal, plant, person (ምሳሌ: እንስሳት, እፅዋት, ሰዎች); non-living — for example car, balloon, chair. Any three true ones of each kind are right.
