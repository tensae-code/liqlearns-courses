# Size and Quantity — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. Two sub lessons because the book teaches two
separate pairs of ideas on two separate pages: size and amount
by eye, then weight by lifting.

## Sub lesson 1 — How big — comparing size and how many
Sub lesson 1 questions from the type files. Pass mark: use
ትልቅ/ትንሽ, ብዙ/ጥቂት, ሰፊ/ጠባብ and ረዥም/አጭር correctly on pictured
and real pairs, and say whether a jar is ሙሉ, ባዶ or ጥቂት.

## Sub lesson 2 — How heavy
Sub lesson 2 questions from the type files. Pass mark: say which
of two things is ከባድ and which is ቀላል after lifting them, and
explain that weight is felt by the arms, not seen by the eyes.
