# Shapes and Patterns — writing

Write and draw with a pencil.

**1. (Sub lesson 1)** Draw a circle, a square and a triangle. Write each shape's name under it.
**Answer: ክብ under the circle, ካሬ under the square, ጎነ ሶስት under the triangle.**

**2. (Sub lesson 1)** Write the names of the shapes that match: the egg's shape, the TV's shape.
**Answer: ሞላላ (oval) for the egg; አራት ማዕዘን (rectangle) for the TV.**

**3. (Sub lesson 2)** Copy this pattern row into empty boxes, then add the next shape: circle, rectangle, circle, rectangle, circle, _, _
**Answer: the copy matches the row exactly; the next shapes are rectangle, then circle.**
