# Colours — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. First the colours themselves, named on real
things; then the mixing that makes the second colours.

## Sub lesson 1 — The first colours
Sub lesson 1 questions from the type files. Pass mark: name ቀይ,
ቢጫ, ሰማያዊ, ጥቁር, ነጭ, አረንጓዴ on sight and on real objects, match
colour to colour, and say which three are the base colours.

## Sub lesson 2 — Mixing colours — the second colours
Sub lesson 2 questions from the type files. Pass mark: say the
three mixes and their child colours — ቀይ + ቢጫ = ብርቱካናማ,
ቢጫ + ሰማያዊ = አረንጓዴ, ሰማያዊ + ቀይ = ወይንጠጅ —
and match the second colours to their names.
