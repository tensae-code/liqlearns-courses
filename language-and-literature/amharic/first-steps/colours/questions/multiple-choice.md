# Colours — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The tomato's colour is —
a) ቢጫ — yellow  b) ቀይ — red  c) ሰማያዊ — blue
**Answer: b) ቀይ — red.**

**2. (Sub lesson 1)** Which list is the base colours (መሰረታዊ ቀለማት)?
a) ቀይ, ቢጫ, ሰማያዊ  b) ጥቁር, ነጭ, አረንጓዴ  c) ብርቱካናማ, ወይንጠጅ, ቀይ
**Answer: a) ቀይ, ቢጫ, ሰማያዊ** — red, yellow, blue stand at the start of all the others.

**3. (Sub lesson 1)** The sky's colour is —
a) አረንጓዴ — green  b) ጥቁር — black  c) ሰማያዊ — blue
**Answer: c) ሰማያዊ — blue.**

**4. (Sub lesson 2)** ቀይ + ቢጫ = _
a) ብርቱካናማ — orange  b) አረንጓዴ — green  c) ወይንጠጅ — purple
**Answer: a) ብርቱካናማ — orange.**

**5. (Sub lesson 2)** Which mix makes ወይንጠጅ (purple)?
a) yellow + blue  b) blue + red  c) red + yellow
**Answer: b) blue + red** — ሰማያዊ + ቀይ = ወይንጠጅ.

**6. (Sub lesson 2)** ቢጫ + ሰማያዊ = _
a) ብርቱካናማ  b) ወይንጠጅ  c) አረንጓዴ
**Answer: c) አረንጓዴ** — yellow + blue = green.
