# Animals — writing

Copy-write each name slowly, the book's own writing work.

**1. (Sub lesson 1)** Copy the home animals' names: ድመት (cat), ውሻ (dog), በግ (sheep).
**Done when:** each word is copied whole, letter by letter.

**2. (Sub lesson 2)** Copy the wild animals' names: አንበሳ (lion), ነብር (tiger), ዝሆን (elephant).
**Done when:** each word is copied whole, letter by letter.

**3. (Sub lesson 3)** Build the walia's name by joining: ዋ + ሊ + ያ = ?
**Answer: ዋሊያ (walia).**

**4. (Sub lesson 4)** Copy the farm animals' names: በሬ (ox), ላም (cow), ዶሮ (hen).
**Done when:** each word is copied whole, letter by letter.
