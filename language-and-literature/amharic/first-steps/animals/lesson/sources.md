Honesty notes. (1) The transliterations of ግልገል (gilgel, foal/young) and ውርንጭላ (wurnch'ila, kitten?) are uncertain: the KG2 placement flags them exactly so — "Transliterations of ግልገል/ውርንጭላ are the reader's best reading; merger to confirm with the Amharic course owner" — and this lesson carries that flag unchanged; the Amharic spellings themselves are copied from the placement. (2) Book 2 (KG2), printed p.25: the printed instruction again says "domestic animals" but the pictures are the wild set (lion, tiger, walia, baboon, elephant, monkey, giraffe, wolf, hyena, kangaroo); the placement follows the pictures, and so does this lesson — the p.25 set is taught as wild animals. (3) The cow song (Book 3, p.170) is taught as a summary plus a "this is a song" audio slot, per the build rule for songs; no lyrics are printed beyond the placements' own one-line fragment, which the summary paraphrases. (4) The KG2 colour set on p.23 includes a pig; the lesson's named home set follows the placements' named sets (KG1 pp.17–18, KG2 p.22, KG3 p.35), which do not name the pig, so the pig is not taught here. (5) Pictures 8060–8062 are generated boards with no text; the first 8060 board drawn showed a two-humped camel and was dropped and remade — the filed board shows Ethiopia's one-humped camel.
