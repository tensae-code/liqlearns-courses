# Ready Hands — Before the Pencil — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons are the depths inside this one
thing — a hand getting ready — first moving freely, then following
a road.

## Sub lesson 1 — Hold and scribble
Sub lesson 1 questions from the type files. Pass mark: pick up the pencil and hold it ready, and fill a big space with free scribble lines steered on purpose — across, bouncing, round.

## Sub lesson 2 — Follow the dotted line (straight, wavy, zigzag)
Sub lesson 2 questions from the type files. Pass mark: travel a dotted path left to right without lifting the pencil and without leaving the dots — straight first, then wavy, then zigzag with a stop-and-turn at each corner.
