# Money — writing

Write or copy-write. For a young child, tracing and copying count in full.

**1. (Sub lesson 1)** Copy-write: አስር ብር — then write the number beside it.

**2. (Sub lesson 1)** Copy-write: ሁለት መቶ ብር — then write the number beside it.

**3. (Sub lesson 2)** Copy-write: ሃምሳ ሳንቲም — then write the number beside it.
