# Descriptive Paragraphs — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons climb the grown-up paragraph ladder: name its power sentence, plan it, choose its building way, then make it paint a picture.

## Sub lesson 1 — The power sentence: ኃይል ቃል and መንደርደሪያ
Sub lesson 1 questions from the type files. Pass mark: in a given paragraph, pick out the topic sentence (ኃይል ቃል / መንደርደሪያ ዓረፍተነገር) and name the supporting sentences (መዘርዝሪያ ዓረፍተነገሮች) that hold it up.

## Sub lesson 2 — Plan first: the outline (ቢጋር)
Sub lesson 2 questions from the type files. Pass mark: before writing, prepare a ቢጋር in ብርዕስ መልክ (topic outline) or በዓረፍተ ነገር መልክ (sentence outline), and unpack a finished paragraph back into its outline (ዋና ሀሳብ + numbered points).

## Sub lesson 3 — Two ways to build a paragraph: ገላጭ and ተራኪ
Sub lesson 3 questions from the type files. Pass mark: classify a given paragraph as ገላጭ (explaining) or ተራኪ (recounting) with a reason, and write a ተራኪ አንቀጽ whose events stand in their true order.

## Sub lesson 4 — The descriptive paragraph: ሥዕላዊ አንቀጽ
Sub lesson 4 questions from the type files. Pass mark: write a descriptive paragraph with imagery words (ምስልከሳች ቃላት) that makes a reader see the scene, in the shape of the Tarmaber model and the ብርሃን task.
