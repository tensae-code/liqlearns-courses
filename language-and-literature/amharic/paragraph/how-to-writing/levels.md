# How-To Writing — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons are the books' two how-to habits: order the steps, and plan before writing.

## Sub lesson 1 — Instructions in order
Sub lesson 1 questions from the type files. Pass mark: put a how-to's steps in their true order, retell them in sequence, and write a how-to piece whose steps a reader could follow.

## Sub lesson 2 — Plan before you write — the outline (ዝርዝር)
Sub lesson 2 questions from the type files. Pass mark: before composing, draft an outline — topic and points in short lines — and then write the full piece from it.

## Sub lesson 3 — A real process in five steps: traditional mediation
Sub lesson 3 questions from the type files. Pass mark: write traditional mediation (ባህላዊ ሽምግልና) as a process text — its five steps numbered and in order (inquiry, consent, mediators, judge, the sitting) — and say why no two steps can change places. This sub lesson stands on teacher-guide evidence only.
