# First Paragraphs — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons climb the books' own paragraph ladder: one idea, then completing, then growing.

## Sub lesson 1 — Sentences together around one idea
Sub lesson 1 questions from the type files. Pass mark: look at sentences and say which belong together in one paragraph, and name the one idea they carry.

## Sub lesson 2 — Completing a paragraph
Sub lesson 2 questions from the type files. Pass mark: finish a given starter paragraph so the completed writing keeps one idea and one flow, with correct punctuation.

## Sub lesson 3 — Continuing and growing a paragraph
Sub lesson 3 questions from the type files. Pass mark: grow a paragraph of at least five lines from a starter sentence, and write a short paragraph from given points.
