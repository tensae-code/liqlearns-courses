# Lesson plan — Grade 3 Using Time

**Course:** Amharic · **Title:** Story · **Lesson:** Grade 3 Using Time
**Place in the curriculum:** Unit 7 — Story (CURRICULUM.md).
**The one thing this lesson teaches:** Time is the one thing everyone has the same amount of. This chapter teaches keeping time, planning the day, and the book's golden saying: ጊዜ ወርቅ ነው — time is gold.
**This lesson's own level:** it stands on the Grade 3 learner's fluent reading and listening: the texts are read twice the fluent way, listened to from the teacher's voice, and answered from what was read and heard.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**.

## Sub lessons
The parts of this lesson, in order:

1. **Listening — not knowing, and human desire** — Listen to **አለማወቅ** — Not Knowing.
2. **Reading — time used well** — Read **ጎበዙ ተማሪ** — The Capable Student.
3. **Reading — time is gold, and a marriage cancelled** — Read the dialogue **ጊዜ ወርቅ ነው** — Time Is Gold.
4. **Time words and sayings** — Match synonyms among the time-keeping words: **ሰዓት ማክበር** — keeping time; **ማርፈድ** — being late.
5. **Writing and reviewing time** — Draw up your own daily timetable — hour by hour — and have friends evaluate it: is anything missing? Is play there as well as study?.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Reading Stories and Listening Stories — this lesson's Grade 3 texts are read and heard the same way, on the chapter theme of using time. Recommended, never forced.

3. Do this chapter's writing tasks — sentences, paragraphs, webs and tables — with correct punctuation.
4. Do this chapter's grammar review work (suffixes, plurals and word-kinds as the chapter names them).

## If the learner is stuck
- A story will not retell → go back to its sequence: first, then, last — three steps carry every tale in this lesson.
- A word set will not stick → say it in a pair, use it in a sentence, then write it: ear, mouth, hand.
- A writing task feels big → the web or table first, sentences after: the book's own order in every chapter.
