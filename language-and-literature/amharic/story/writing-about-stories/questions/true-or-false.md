# Writing About Stories — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** ውጤት (wutet) is the problem of the story.
**Answer: False** — ውጤት is the outcome, how it ends; the problem is ችግር.

**2. (Sub lesson 2)** An ending you write for a stopped story must grow out of the story's shape — the given problem decides what endings can be true.
**Answer: True.**

**3. (Sub lesson 3)** The order of events in a story is part of its meaning.
**Answer: True.**
