# Writing Sentences — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons are the three ways the books teach sentence writing: building, dictation, and ordering.

## Sub lesson 1 — Build a sentence from the given words
Sub lesson 1 questions from the type files. Pass mark: given two or three words, write one whole sentence that carries them and says something true.

## Sub lesson 2 — Dictation — hear it, write it
Sub lesson 2 questions from the type files. Pass mark: write the heard words exactly — the five-word dictation list complete and correct — then read them back.

## Sub lesson 3 — Word order — putting the words in their places
Sub lesson 3 questions from the type files. Pass mark: take a mixed-up sentence and write it whole again, every word in its place, end mark in place.
