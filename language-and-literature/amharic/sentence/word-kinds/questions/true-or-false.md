# The Word Kinds — true or false

Say true or false.

**1. (Sub lesson 16)** ቀይ in ቀይ ቦርሳ describes the bag — a noun — so ቀይ is an adjective there.
**Answer: True**

**2. (Sub lesson 17)** Adverbs lean on verbs by time, place or manner.
**Answer: True**

**3. (Sub lesson 18)** A sentence can carry a noun-modifier and a verb-modifier at the same time.
**Answer: True**

**4. (Sub lesson 22)** The Grade 10 guide teaches that a word's class can change when it enters a sentence.
**Answer: True**
