# The Marks That Help Us Read — depth

This lesson has no sub lessons — it is one short, single-skill
lesson (his ruling 2026-11-09). Whole-lesson pass mark: name all
four marks on sight — ሁለት ነጥብ (two dots), the four dots, ነጠላ
ሰረዝ (comma), የጥያቄ ምልክት (question mark) — say what each one
does, and write the names of the marks. Practice deepens by
mixing the order the marks are asked in, by moving from the big
picture card to small marks inside real sentences, and by asking
for the mark's job, not only its name ("which mark opens a list?
which mark closes the saying?").
