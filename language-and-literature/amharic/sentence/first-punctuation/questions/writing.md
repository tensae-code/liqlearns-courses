# The Marks That Help Us Read — writing

Write each one. Naming the mark in writing is the book's own
work for these marks.

**1.** Write the name of this mark: :
**Answer: ሁለት ነጥብ** (the two dots).

**2.** Write the name of this mark: ፣
**Answer: ነጠላ ሰረዝ** (the comma).

**3.** Write the name of this mark: ?
**Answer: የጥያቄ ምልክት** (the question mark).

**4.** Copy this sentence and put the mark that closes a saying
at its end: ዛፍ ተከልኩ
**Answer: ዛፍ ተከልኩ።** — the four dots close the saying.
