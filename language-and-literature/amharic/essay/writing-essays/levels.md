# Writing Essays — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons run in the order the books
grow the craft: explain, narrate, join cause to effect, argue,
then organise a full essay from one web.

## Sub lesson 1 — The expository essay and its topic sentence
Sub lesson 1 questions from the type files. Pass mark: write a four-paragraph expository essay from an organiser and pick out every paragraph's topic sentence (መንደርደሪያ ዓረፍተነገር).

## Sub lesson 2 — The narrative essay
Sub lesson 2 questions from the type files. Pass mark: write a narrative essay (ተራኪ ድርሰት) whose events keep their time sequence, from one stated narrator's place, held to the end.

## Sub lesson 3 — The cause-and-effect essay
Sub lesson 3 questions from the type files. Pass mark: build the essay from a cause-and-effect organiser and show that every key sentence passes the "did this make that happen?" test.

## Sub lesson 4 — The argumentative paragraph and essay
Sub lesson 4 questions from the type files. Pass mark: state a position, order its reasons as the model does, and hold the position through a three-paragraph essay (ባለ ሦስት አንቀፅ ድርሰት).

## Sub lesson 5 — The organised essay built from a web
Sub lesson 5 questions from the type files. Pass mark: build a web that holds the whole topic, write a complete essay covering every branch, then edit and rewrite it.

## Sub lesson 6 — The explanatory essay, grown up
Sub lesson 6 questions from the type files. Pass mark: state the grown working order (review the craft and the types of essay first; write from a prompt in a pair or group) and explain a technology product by name and use, the model bank's way. This sub lesson stands on teacher-guide evidence only.
