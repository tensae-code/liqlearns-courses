# Problem-and-Solution Essays — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** In the book's problem chain, forest felling leads first to —
a) sufficient rain  b) land stripping  c) prosperity
**Answer: b) land stripping** — felling → stripping → erosion → drought → poverty.

**2. (Sub lesson 1)** The problem chain's third link is —
a) drought  b) soil erosion  c) poverty
**Answer: b) soil erosion** — felling → stripping → erosion → drought → poverty.

**3. (Sub lesson 1)** A solution link that answers no problem link is —
a) the best kind  b) decoration  c) the conclusion
**Answer: b) decoration** — every solution link must answer a problem link.

**4. (Sub lesson 1)** The essay is built from —
a) a poem  b) a bigar with two chains  c) a letter
**Answer: b) a bigar with two chains** — the two-chain bigar is the essay's plan.
