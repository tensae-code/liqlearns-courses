# Letters — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons are the letter kinds themselves, in the books' climbing order: from a friend, to an office, to an invitation.

## Sub lesson 1 — The personal letter (የግል ደብዳቤ)
Sub lesson 1 questions from the type files. Pass mark: write a personal letter in the model's form — sender's name, town and የመ.ሣ.ቁ at top, date, recipient, greeting, body, close and ፊርማ — with the body's own news in it.

## Sub lesson 2 — The greeting letter (የሰላምታ ደብዳቤ) and its parts
Sub lesson 2 questions from the type files. Pass mark: write a greeting letter whose three parts stand in order and do their jobs — የሰላምታ ክፍል (greeting), የጉዳይ ክፍል (body), የመዝጊያ ክፍል (closing) — signed ጓደኛሽ-style as a friend signs.

## Sub lesson 3 — The congratulatory letter (የደስታ መግለጫ ደብዳቤ)
Sub lesson 3 questions from the type files. Pass mark: set out a congratulatory letter with the full official anatomy — heading, number, date, addressee, ጉዳዩ, body, ከሠላምታ ጋር, signature.

## Sub lesson 4 — Official and request letters
Sub lesson 4 questions from the type files. Pass mark: build a request letter on its frame (letterhead left: school, club, town; right: office abbreviated, subject code ደብዳቤዎች = 112, file number, date; then ጉዳዩ), and name the office letter's full list of parts from የራስጌ ማህተም to the round stamp.

## Sub lesson 5 — The appreciation letter (የአድናቆት ደብዳቤ)
Sub lesson 5 questions from the type files. Pass mark: write an appreciation letter on the model — greeting, a body that names what was seen and valued, a warm closing — then edit it and read it aloud.

## Sub lesson 6 — The invitation letter (የግብዣ ጥሪ ደብዳቤ)
Sub lesson 6 questions from the type files. Pass mark: fill the wedding invitation form's blanks correctly and write an invitation letter fitted to its occasion.

## Sub lesson 7 — The application letter (የማመልከቻ ደብዳቤ)
Sub lesson 7 questions from the type files. Pass mark: write an application letter in formal words — date, the office, the ጉዳዩ subject line, a body that states the facts and humbly requests, ከሠላምታ ጋር, signature and name.
