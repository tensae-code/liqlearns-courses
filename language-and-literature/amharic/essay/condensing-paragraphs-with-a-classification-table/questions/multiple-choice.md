# Condensing Paragraphs with a Classification Table — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The classification table's columns are —
a) who / when / why  b) name / service / place / nature / time built  c) big / small / medium
**Answer: b) name / service / place / nature / time built** — name, service, place, nature, time built — the heritage chapter's five.

**2. (Sub lesson 1)** The table's 'time built' column holds —
a) the writer's name  b) when the site was built  c) the paragraph number
**Answer: b) when the site was built** — name / service / place / nature / time built.

**3. (Sub lesson 1)** Condensing keeps —
a) every fact at a third of the length  b) only the first fact  c) all the words
**Answer: a) every fact at a third of the length** — the sieve keeps the facts and drops the repetition.

**4. (Sub lesson 1)** The classification table is a kind of —
a) letter  b) bigar (organiser)  c) poem
**Answer: b) bigar (organiser)** — the book calls the sorting frame a classification bigar.
