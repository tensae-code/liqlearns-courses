# Using the Dictionary — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons run from the tool itself, to
the book's look-up-and-write task, to the dictionary at work
inside real readings.

## Sub lesson 1 — The dictionary as a tool
Sub lesson 1 questions from the type files. Pass mark: say what
መዝገበቃላት is, what it is for, and how using it differs from
reading a story book (you visit it for one word; you do not
read it front to back).

## Sub lesson 2 — Finding a word and writing its meaning
Sub lesson 2 questions from the type files. Pass mark: carry
out the book's task — look up and write the definitions of
ሰገነት, መደዳ, ደርብ and ክፍለዘመን, and give all four meanings
from memory afterwards.

## Sub lesson 3 — Dictionary words inside real readings
Sub lesson 3 questions from the type files. Pass mark: give the
dictionary meanings of ገዳም, ብራና, አምድ and ተዓምር, and state the
five-step habit (read → stop → visit the dictionary → write
the meaning → read on) with ስጦታ and ትጋት as the worked words.
