# One and Many — sub lessons and depth

This file is the lesson's depth record, re-expressed as its sub lessons. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Making many with -ኦች
Pass mark: give ቀሚሶች for ቀሚስ and name -ኦች as the piece that made it many.

## Sub lesson 2 — Making many with -ዎች, and stripping it back

## Sub lesson 3 — One or many? Sorting words
Pass mark: sort words into singular and plural using the box's two questions — how many does it name, and does it carry a plural suffix?
