# Reading-Lesson Cautions — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** In the reading lesson, the guide says the teacher should —
a) read every line aloud beautifully  b) not read the text aloud, nor make learners read aloud  c) have the strongest learner read for all
**Answer: b) not read the text aloud, nor make learners read aloud**

**2. (Sub lesson 2)** When the focus is comprehension, a learner mid-answer should —
a) not be stopped for grammar faults  b) be corrected at every word  c) start again in a full sentence
**Answer: a) not be stopped for grammar faults**

**3. (Sub lesson 1)** Relying only on true/false and multiple choice is cautioned against because —
a) they are too hard to mark  b) learners dislike them  c) comprehension needs varied question types that build the targeted sub-skill
**Answer: c) comprehension needs varied question types that build the targeted sub-skill**

**4. (Sub lesson 2)** A short answer given in speech form should be —
a) rejected until it is a full sentence  b) accepted  c) repeated by the class
**Answer: b) accepted**
