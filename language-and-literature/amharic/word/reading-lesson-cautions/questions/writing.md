# Reading-Lesson Cautions — writing

Write each one on paper.

**1. (Sub lesson 1)** Write the seven cautions from memory as a numbered list, then check against the lesson and repair any missed.
**Answer guide: All seven present after checking; misses repaired.**

**2. (Sub lesson 2)** Describe a reading lesson you know that broke one caution, and write what should have happened instead.
**Answer guide: A real break named, matched to its caution, with the guide's way written beside it.**
