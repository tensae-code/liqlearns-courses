# Study Skills — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons are the books' study tools in the order a reader meets them: chart before reading, webs during, chains for thinking, and the game that drills the fidel themselves.

## Sub lesson 1 — KWL charts
Sub lesson 1 questions from the type files. Pass mark: run the whole cycle on a real text: honest K, real questions in W, and an L column that answers the W questions from the reading.

## Sub lesson 2 — Concept webs
Sub lesson 2 questions from the type files. Pass mark: build a web whose every branch joins the centre, and write sentences from its branches.

## Sub lesson 3 — Cause-and-effect webs
Sub lesson 3 questions from the type files. Pass mark: build chains and cause → problem → solution webs where every arrow passes the 'did this make that happen?' test.

## Sub lesson 4 — The fidel crossword — a game
Sub lesson 4 questions from the type files. Pass mark: complete the book's crossword by the four rules, across and down, using placed letters as starting points.
