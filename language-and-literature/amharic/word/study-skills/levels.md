# Study Skills — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons are the books' study tools in the order a reader meets them: chart before reading, webs during, chains for thinking, and the game that drills the fidel themselves.

## Sub lesson 1 — KWL charts
Sub lesson 1 questions from the type files. Pass mark: run the whole cycle on a real text: honest K, real questions in W, and an L column that answers the W questions from the reading.

## Sub lesson 2 — Concept webs
Sub lesson 2 questions from the type files. Pass mark: build a web whose every branch joins the centre, and write sentences from its branches.

## Sub lesson 3 — Cause-and-effect webs
Sub lesson 3 questions from the type files. Pass mark: build chains and cause → problem → solution webs where every arrow passes the 'did this make that happen?' test.

## Sub lesson 4 — The fidel crossword — a game
Sub lesson 4 questions from the type files. Pass mark: complete the book's crossword by the four rules, across and down, using placed letters as starting points.

## Sub lesson 5 — Reading data tables
Sub lesson 5 questions from the type files. Pass mark: answer table questions from the cells only — find the named row, find the asked column, read the crossing cell — for both the headache table (years, place, age, sex) and the teff table (Kora 500–800 mm; Negus 105 days; Dukem 24–34 q/ha on station).

## Sub lesson 6 — Note-taking while listening
Sub lesson 6 questions from the type files. Pass mark: prepare notebook and pen before listening, and hold the main points at word, phrase and sentence level — nothing more, nothing less.

## Sub lesson 7 — KWL grows up
Sub lesson 7 questions from the type files. Pass mark: run KWL on a higher-book topic (farmers, Fasilides' palace, a biography), with W questions hard enough that the text must work to answer them, and an L column that answers them with facts.

## Sub lesson 8 — Three stages: listening, reading, speaking
Sub lesson 8 questions from the type files. Pass mark: name the three stages of each skill and the learner's job in each — reading held to its shape (2–5 minutes' warm-up that never reveals the message; 10–15 minutes' silent reading with one's own book; the post stage longest). This sub lesson stands on teacher-guide evidence only.

## Sub lesson 9 — Extensive reading: one book, two weeks, a real test
Sub lesson 9 questions from the type files. Pass mark: state the system whole — one short-fiction book, two weeks or more of homework reading (time adjusted to background and reachability), then a content test worth 10 or 15 marks counted like a monthly or semester test. This sub lesson stands on teacher-guide evidence only.

## Sub lesson 10 — Seven ways to listen well
Sub lesson 10 questions from the type files. Pass mark: name all seven strategies of effective listening (ውጤታማ የማዳመጥ ብልሃቶች) and catch yourself using or dropping them in a real conversation. This sub lesson stands on teacher-guide evidence only.

## Sub lesson 11 — Revision questions: the closing check
Sub lesson 11 questions from the type files. Pass mark: close a finished piece of work with oral revision questions (የክለሳ ጥያቄዎች) before moving on, answering in full speech, and re-read exactly where an answer would not come. This sub lesson stands on teacher-guide evidence only.
