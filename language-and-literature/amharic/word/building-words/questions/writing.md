# Building Words — writing

Write your answers.

**1. (Sub lesson 1)** Write ፍኖተሰላም split back into its two words, the way the books first write it.
**Answer:** ፍኖተ-ሰላም — ፍኖተ and ሰላም, joined into one word.

**2. (Sub lesson 3)** On the model ነገር → ነገረኛ, build the -ኛ person-word from ተንኮል (mischief) — the mischievous person. Write the built word.
**Answer:** ተንኮለኛ — the base ተንኮል with -ኛ added, naming
the person who carries the quality.

**3. (Sub lesson 4)** Write three loanwords, each with the language it travelled from.
**Answer:** any three from the table, e.g. ቆጮ — Gurage
(ጉራግኛ); ሰዓት — Arabic (አረብኛ); ባቡር — French (ፈረንሳይኛ).
