# Word Families and Webs — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons run from pairs grown into
systems, to families drawn as webs, to the swap that turns the
families into a writing tool.

## Sub lesson 1 — Synonyms and antonyms as systems
Sub lesson 1 questions from the type files. Pass mark: define
ተመሳሳይ ፍቺ and ተቃራኒ ፍቺ, match the placed antonym and synonym
sets, and give one word (መጉዳት or አስተዋይ) both its synonym and
its antonym.

## Sub lesson 2 — Word webs
Sub lesson 2 questions from the type files. Pass mark: read the
ቤተሰብ web and the እርዝ web from the centre out — name the
centre word and every hanging word — and use one hanging word
in a sentence.

## Sub lesson 3 — Swap the word, keep the sentence
Sub lesson 3 questions from the type files. Pass mark: given a
sentence with one word underlined, replace that word with its
synonym and re-say/write the whole sentence standing, nothing
else moved.
