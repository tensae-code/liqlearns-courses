# Fidel Shapes — Letters With Legs — writing

Write with your pencil. (A teacher or the app checks the writing against the lesson's charts.)

**1. (Sub lesson 1)** Write one fidel for each leg group: one-legged, two-legged, three-legged, legless.
**Answer: any true members, e.g. ቀ (one), ለ (two), ጠ (three), መ (none)** — checked against Picture 8255.

**2. (Sub lesson 2)** Write the families ሀ and ሐ, then write each family's keyword name beside it.
**Answer: ሀ — ሀሌታው · ሐ — ሐመሩ** — checked against Picture 8256.
