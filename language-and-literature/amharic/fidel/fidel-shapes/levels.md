# Fidel Shapes — Letters With Legs — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons climb from sorting shapes to
beating the look-alikes.

## Sub lesson 1 — Sorting by legs
Sub lesson 1 questions from the type files. Pass mark: name the four leg groups, and sort at least four given fidel into their groups by shape — including one form of ሸ or ሐ in the group where it stands.

## Sub lesson 2 — Look-alike fidel
Sub lesson 2 questions from the type files. Pass mark: give the keyword family name for at least six of the nine look-alike families, tell one look-alike pair apart inside a word, and build a word holding a compound fidel.
