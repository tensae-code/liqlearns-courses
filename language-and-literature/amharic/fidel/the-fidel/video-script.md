# Video script — The Fidel

The super-simple voice, for the video that rides on top of the
lesson (lesson-plan.md, add-on list). Made later, when videos are
made; the script is the slot's written form until then. This is the
lesson the whole Amharic course stands on, so the script is full:
the chart, one family, and one built word, all read aloud.

---

Look. This is the chart. የፊደል ገበታ.
Many letters. Do not fear. We go slow.

This is **በ** (ba). በ is for በግ — a sheep.
This is **ሰ** (sa). ሰ is for ሰዓት — a clock.
This is **ሸ** (sha). ሸ is for ሸሚዝ — a shirt.
This is **አ** (a). አ is for አንበሳ — a lion.

Now the secret. One letter has seven shapes.
One letter, one family. ቤተሰብ.

**በ ቡ ቢ ባ ቤ ብ ቦ.**
Say it with me. በ. ቡ. ቢ. ባ. ቤ. ብ. ቦ.
Again. Slow. በ ቡ ቢ ባ ቤ ብ ቦ.
You read a family!

One form is missing. በ ቡ — ባ ቤ ብ ቦ.
What is missing? … **ቢ**! Yes.

Now we build a word.
**በ** + **ለ** + **ጠ** = **በለጠ**.
Three letters. One word. You built it.

One more. **ዳቦ** — bread. ዳቦ.
Read it slow. Then read it whole. ዳቦ.

Now you. Point to a letter. Say its sound.
Read its family. Build a word.
That is the fidel.
