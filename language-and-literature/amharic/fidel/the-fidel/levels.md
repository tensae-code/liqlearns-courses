# The Fidel — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons are the depths inside this one
thing — the fidel — climbing the books' own ladder: single letters,
whole families, using the families, first reading, a word for every
form, and building words.

## Sub lesson 1 — The fidel chart and the first letters
Sub lesson 1 questions from the type files. Pass mark: point to a named letter on the chart and say its sound; match at least four keyword pictures to their starting letters; name the letter a keyword picture starts with.

## Sub lesson 2 — The families — seven forms of one letter
Sub lesson 2 questions from the type files. Pass mark: read one whole family aloud in order, write it from memory with no form wrong, and fill the missing form in a family row.

## Sub lesson 3 — First sounds, matching and the odd one out
Sub lesson 3 questions from the type files. Pass mark: give the first fidel of a pictured word's name, match the same forms to each other, and find the odd fidel out in a family row.

## Sub lesson 4 — First reading — words made of learned letters
Sub lesson 4 questions from the type files. Pass mark: read a short word built only from learned letters — slowly first if needed, then whole — and pick the word that was read aloud from a small set.

## Sub lesson 5 — A word for every form
Sub lesson 5 questions from the type files. Pass mark: for the በ, ሰ and ሸ families, say the word that starts with a named form, and match forms to their words.

## Sub lesson 6 — Building words from fidel
Sub lesson 6 questions from the type files. Pass mark: join given fidel into the word they make, fill the missing fidel inside a word, and build a word that holds a given fidel.
