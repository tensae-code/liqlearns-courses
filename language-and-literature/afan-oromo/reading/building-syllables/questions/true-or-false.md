# Building Syllables — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** A syllable must carry a vowel.
**Answer: True** — no syllable stands without a vowel inside it

**2. (Sub lesson 4)** Konkolaataa has three syllables.
**Answer: False** — it has four — the book sorts it with the four-syllable words
