# Building Syllables — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub Lessons"). Practice is tied to the learner's skill number, as before. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Joining a consonant and a vowel
Sub lesson 1 questions from the type files. Pass mark: build and read the syllables of two consonants, short row and long row.

## Sub lesson 2 — The syllable charts — short and long
Sub lesson 2 questions from the type files. Pass mark: read one full chart row short, then the same row long, without stopping.

## Sub lesson 3 — Splitting words and joining them
Sub lesson 3 questions from the type files. Pass mark: split mala, na-ma and see-naa into syllables, and join three given syllable pairs into words.

## Sub lesson 4 — Counting syllables
Sub lesson 4 questions from the type files. Pass mark: count the syllables in Gamoo, Adurree and Bulbulaa, and sort three words by their counts.
