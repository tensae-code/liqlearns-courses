# Greetings — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** Greetings are the first chapter of the Grade 3 guide.
**True** — Ch. 1 is Nagaa Walgaafachuu, Greeting Each Other.

**2. (Sub lesson 2)** One greeting fits every hour of the day.
**False** — the greeting fits the day's division: ganama, guyyaa or galgala.

**3. (Sub lesson 3)** In dialogue practice, only one person speaks.
**False** — the turns are taken: greet, answer, greet back.
