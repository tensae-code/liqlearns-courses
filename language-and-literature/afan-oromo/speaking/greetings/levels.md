# Greetings — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons are the depths inside this one thing — greeting well: first the act itself, then its timing, then the pair dialogue.

## Sub lesson 1 — Greeting the teacher and each other
Sub lesson 1 questions from the type files. Pass mark: greet the teacher and a classmate, standing, aloud, without being fed the words.

## Sub lesson 2 — Greetings for the times of day
Sub lesson 2 questions from the type files. Pass mark: name the three divisions of the day and give the greeting time each one calls for.

## Sub lesson 3 — Greeting dialogues
Sub lesson 3 questions from the type files. Pass mark: hold a pair greeting dialogue — greet, answer, greet back — for a named time of day, without stopping.
