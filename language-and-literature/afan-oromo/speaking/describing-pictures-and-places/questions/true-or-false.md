# Describing Pictures and Places — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** A description is a list of everything in the picture, in any order.
**False** — it is a built scene: what the place is, what stands where, what is happening — along a road for the eye.

**2. (Sub lesson 2)** Naming things from pictures is part of the Grade 4 surroundings work.
**True** — the compound's things are named from pictures, then described in place.

**3. (Sub lesson 3)** You may describe land in low-to-high order.
**True** — near-to-far and low-to-high are both roads for the eye.
