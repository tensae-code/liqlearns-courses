# The Oromo Marriage Custom — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons are the depths inside this one thing — a living custom spoken: first described from pictures, then acted, then rooted in the family's names.

## Sub lesson 1 — The custom — sirna fuudhaafi heerumaa aadaa Oromoo
Sub lesson 1 questions from the type files. Pass mark: describe the marriage custom from a picture — the gathering, the people, the order — in at least five sentences.

## Sub lesson 2 — Role-playing the ceremony
Sub lesson 2 questions from the type files. Pass mark: take a part in the role-play and carry its order and its words from start to finish.

## Sub lesson 3 — Telling each other relatives' names
Sub lesson 3 questions from the type files. Pass mark: tell a partner your relatives' names — at least six — with where each stands in the family.
