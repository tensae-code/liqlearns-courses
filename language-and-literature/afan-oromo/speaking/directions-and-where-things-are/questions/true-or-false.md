# Directions and Where Things Are — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** Pointing alone is a complete direction.
**False** — pointing is not speaking; the words must carry the way for a listener who cannot see the point.

**2. (Sub lesson 2)** A good direction-teller can change the anchor — from school, then from home.
**True.**

**3. (Sub lesson 3)** A route in words is a description that stands still.
**False** — it moves: the Describing lesson's placing, set walking, leg by leg.
