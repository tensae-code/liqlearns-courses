# Listening to the World — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons are the depths inside this one thing — the ear at work in the world: first the heard weather reported, then worn, then the heard time obeyed.

## Sub lesson 1 — The weather report
Sub lesson 1 questions from the type files. Pass mark: hear a weather report and report its day in your own sentence, with the right weather word.

## Sub lesson 2 — Clothes for the weather
Sub lesson 2 questions from the type files. Pass mark: sort a mixed clothes pile into cold-weather and hot-weather from a heard report alone.

## Sub lesson 3 — Following instructions about time
Sub lesson 3 questions from the type files. Pass mark: carry out three heard instructions about time — set the clock, name the activity, say when — without asking twice.
