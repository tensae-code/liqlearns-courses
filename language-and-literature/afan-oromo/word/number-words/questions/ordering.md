# Number Words — ordering

Put the items in the right order.

**1. (Sub lesson 1)** Put these number words in counting order.
Mixed up: shan · tokko · afur · lama · sadii
**Answer: tokko → lama → sadii → afur → shan**

**2. (Sub lesson 9)** Put these round tens in order.
Mixed up: dhibba · sagaltama · digdama · soddoma
**Answer: digdama → soddoma → sagaltama → dhibba**
