# Alphabet Review — Consonants and Vowels — ordering

Put the items in the right order.

**1.** Put this stretch of the alphabet in its true order.
Mixed up: DH · C · E · CH · D
**Answer: C → CH → D → DH → E**

**2.** Put this stretch in its true order.
Mixed up: TS · SH · T · S · U
**Answer: S → SH → T → TS → U**
