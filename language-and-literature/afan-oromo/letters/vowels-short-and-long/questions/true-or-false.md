# Vowels — Short and Long — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 2)** A short vowel is held for a long time.
**Answer: False** — a short vowel is one clean beat; the long one is held

**2. (Sub lesson 3)** Laafaa is written with two a letters because its sound is long.
**Answer: True**
