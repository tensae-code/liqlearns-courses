# The Qubee Alphabet — short answer

Answer in a word or a short sentence.

**1. (Sub lesson 1)** Which double letter comes right after C in the alphabet?
**Answer: CH**

**2. (Sub lesson 2)** Write the small letters for these capitals: A, G, Q.
**Answer: a, g, q**

**3. (Sub lesson 3)** Letters are built from basic strokes and what?
**Answer: Lines (*sararoota bu'uuraa* — basic strokes/lines)**
