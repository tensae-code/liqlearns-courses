# The Qubee Alphabet — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub Lessons"). Practice is tied to the learner's skill number, as before. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — The capital letters
Sub lesson 1 questions from the type files. Pass mark: read the capitals in order and pick any named capital out of a mixed row.

## Sub lesson 2 — The small letters
Sub lesson 2 questions from the type files. Pass mark: match every capital to its small letter, and write the small letter when the capital is shown.

## Sub lesson 3 — Writing the letters
Sub lesson 3 questions from the type files. Pass mark: write five named letters, capital and small, each formed in the right strokes.
