# Double Letters — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Which of these is a double letter?
a) b  b) sh  c) a  d) k
**Answer: b) sh** — two shapes, one sound

**2. (Sub lesson 1)** How many double letters are there?
a) Five  b) Six  c) Seven  d) Ten
**Answer: c) Seven** — ch dh ny ph sh ts zy

**3. (Sub lesson 2)** Nyaata (food) starts with the double letter —
a) ny  b) sh  c) ts  d) dh
**Answer: a) ny**

**4. (Sub lesson 2)** Dhadhaa (butter) starts with —
a) d  b) dh  c) ch  d) ph
**Answer: b) dh**

**5. (Sub lesson 2)** Which word carries the digraph zy?
a) Shan  b) Tsahaay  c) Televizyiinii  d) Buuphaa
**Answer: c) Televizyiinii** — zy stands inside it
