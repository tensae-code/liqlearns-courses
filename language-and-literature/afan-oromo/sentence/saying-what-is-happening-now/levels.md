LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub

before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons are the depths inside this one thing — the verb's present time: first the sentences whole, from pictures; then the shapes inside them; then the present/habitual time named, and used to narrate.
