# Saying What Is Happening Now — true or false

Sub-lesson markers (2026-11-08 restructure): every item's marker names the sub lesson it belongs to.

Say true or false. If it is false, say why.

**1. (Sub lesson 1)** "Sareen dutaa jira" tells what the dog did yesterday.
**False** — it tells what the dog is doing now.

**2. (Sub lesson 2)** One doer takes jira; many doers take jiru.
**True.**

**3. (Sub lesson 3)** The present time can only tell this second's happenings, never habits.
**False** — hennaa ammeennaa is present *and* habitual time: now, and again-and-again.
