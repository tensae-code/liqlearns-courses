# Doubled Letters in Words — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons are the depths inside this one thing — letters doubled and clustered inside words: first the doubles, then the clusters, then the sound practice they belong to.

## Sub lesson 1 — Doubled letters
Sub lesson 1 questions from the type files. Pass mark: read all ten doubled sets with their words, holding each doubled letter in the sound.

## Sub lesson 2 — Letter clusters
Sub lesson 2 questions from the type files. Pass mark: read all ten cluster words, stepping through each cluster without adding a vowel inside it.

## Sub lesson 3 — Short, long, soft and strong sounds
Sub lesson 3 questions from the type files. Pass mark: take three words from the sets and read each twice — once wrong (double read short) and once right — and say what changed.
