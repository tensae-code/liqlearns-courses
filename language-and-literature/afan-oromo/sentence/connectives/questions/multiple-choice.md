# Connectives — multiple choice

Answer each question. Try them in any order you like — the number shows which sub lesson each question belongs to.

**1. (Sub lesson 1)** A connective (*walqabsiistuu*) joins —
a) only single letters
b) words, phrases, clauses and sentences
c) only pictures
d) only questions
**Answer: b) words, phrases, clauses and sentences** — the guide's own list of what a connective ties together.

**2. (Sub lesson 1)** Complete the book's sentence: "Barataa cimaan ni moo'a moo ni ______?"
a) moo'a
b) kufa
c) rafa
d) fiiga
**Answer: b) kufa** — "Will the strong student win, or lose?" — the guide's printed key.

**3. (Sub lesson 2)** Which connective is a chooser (*filachiistuu*)?
a) fi
b) garuu
c) yookiin
d) dabalees
**Answer: c) yookiin** — it holds up alternatives to choose between; fi adds, garuu opposes, dabalees adds on top.

**4. (Sub lesson 3)** Which list holds subordinating connectives (*hirkatoo*)?
a) fi, garuu, yookiin
b) akkuma, erga, yoo, osoo
c) dabalees, kanamalees
d) kanaa achi, moo
**Answer: b) akkuma, erga, yoo, osoo** — these tie a clause under another one; the other lists belong to the coordinating families.
