# Persons and Pronouns — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons are the depths inside this one thing — the words that stand for people: first the set itself, then the persons, then the set at work in sentences, where the verb agrees.

## Sub lesson 1 — The pronouns
Sub lesson 1 questions from the type files. Pass mark: name all six pronouns with their pointings, and give both shapes of "I" and of "we".

## Sub lesson 2 — The persons — first, second, third
Sub lesson 2 questions from the type files. Pass mark: sort ani, nuti, ati, isa, ishee, isaan by person, and say which of them are qeenxee (one) and which danuu (many).

## Sub lesson 3 — Pronouns in sentences — the verb agrees
Sub lesson 3 questions from the type files. Pass mark: read the five "came" sentences aloud and match each verb ending to its person; build one new sentence with a different pronoun and the ending that fits.
