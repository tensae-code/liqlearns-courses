# Telling and Explaining in Writing — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons are the depths inside this one thing — writing that tells and explains: first the ordered narration, then the explanatory paragraph's two roads, then the outline that plans it all, then the tale continued.

## Sub lesson 1 — Narrating an event in order
Sub lesson 1 questions from the type files. Pass mark: narrate a simple event in writing, in order, with no step out of place.

## Sub lesson 2 — The explanatory paragraph — steps and explanations
Sub lesson 2 questions from the type files. Pass mark: write an explanatory paragraph on one road — steps in order, or reasons in a row — with nothing missing that the doing needs.

## Sub lesson 3 — Making an outline — gumee — before writing
Sub lesson 3 questions from the type files. Pass mark: make a gumee for a given topic with at least three branches, then build one paragraph from one branch.

## Sub lesson 4 — Continuing a folk tale
Sub lesson 4 questions from the type files. Pass mark: continue the folk-tale opening for a short stretch, keeping its road and order, heading for a close.
