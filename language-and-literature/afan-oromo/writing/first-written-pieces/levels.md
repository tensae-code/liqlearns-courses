# First Written Pieces — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons are the depths inside this one thing — the first whole pieces a writer writes: greetings, a tiny story, an introduction, table sentences, and the family's names.

## Sub lesson 1 — First words — writing the greetings
Sub lesson 1 questions from the type files. Pass mark: write the greeting words of the three divisions from memory.

## Sub lesson 2 — A four-sentence story about a friend
Sub lesson 2 questions from the type files. Pass mark: write a friend's story in four sentences or fewer, with a placing, a happening and a close.

## Sub lesson 3 — Introducing yourself in a short text
Sub lesson 3 questions from the type files. Pass mark: write the introduction as a short text with all its parts in order.

## Sub lesson 4 — Sentences about eating and cutting food
Sub lesson 4 questions from the type files. Pass mark: write two happening-now food sentences in the key's shape — one eating, one cutting.

## Sub lesson 5 — Spelling names of relatives
Sub lesson 5 questions from the type files. Pass mark: write at least six relatives' names spelled exactly, without copying.
