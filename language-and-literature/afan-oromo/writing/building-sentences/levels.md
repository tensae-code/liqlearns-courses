# Building Sentences — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB
LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub
Lessons"). Practice is tied to the learner's skill number, as
before. The questions live in the type files; this file is the
by-sub-lesson view. The sub lessons are the depths inside this one thing — the sentence as a built thing: five benches, from columns to completions, each one a way a sentence gets stood up.

## Sub lesson 1 — From three word columns
Sub lesson 1 questions from the type files. Pass mark: build three sentences from three columns, each verb agreeing with its doer.

## Sub lesson 2 — From word groups
Sub lesson 2 questions from the type files. Pass mark: order four word groups into their sentences, and say the order rule you used.

## Sub lesson 3 — From phrases — gaalee into hima
Sub lesson 3 questions from the type files. Pass mark: grow two phrases into sentences by giving each its verb and doer.

## Sub lesson 4 — Around a verb
Sub lesson 4 questions from the type files. Pass mark: build a sentence around a given verb, with a doer whose form the verb agrees with.

## Sub lesson 5 — Completing sentences
Sub lesson 5 questions from the type files. Pass mark: complete three started sentences, each verb agreeing with the subject supplied.
