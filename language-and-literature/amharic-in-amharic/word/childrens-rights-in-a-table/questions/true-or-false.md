# የሕፃናት መብቶች በሠንጠረዥ — እውነት ወይም ሀሰት

እውነት ወይም ሀሰት ተናገር፣ ለምን እንደሆነም ንገር።

**1. (ንዑስ ትምህርት 1)** ለእያንዳንዱ መብት ግዴታው የሚያስከብረው አንድ ሰው አለ።
**መልስ፡ እውነት** — በሠንጠረዥ የተጻፈ መብት ግዴታን ያሳያል።

**2. (ንዑስ ትምህርት 2)** የተፅዕኖ ሠንጠረዡ መምህርንና ጎረቤትን በልጅ ላይ እንደ ተፅዕኖዎች ያካትታል።
**መልስ፡ እውነት** — ከቤተሰብ፣ ከአቻ ጓደኛና ከባህል ጋር።

**3. (ንዑስ ትምህርት 1)** የአረጋዊያን መብቶች (አረጋዊያንን…) በመብቶች ቢጋር ውስጥም ይቆማሉ።
**መልስ፡ እውነት** — ቢጋሩ እነሱንም ይሰይማል።

**4. (ንዑስ ትምህርት 2)** ጎጂ ተፅዕኖ ከመብት ጋር ሊጋጭ ይችላል፣ ሠንጠረዦቹም ግጭቱን ያሳያሉ።
**መልስ፡ እውነት** — ግልጽ እይታ የመፍትሔው መጀመሪያ ነው።
