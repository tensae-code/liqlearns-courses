# በቃላት ላይ ትንንሽ ቁራጮች — ቅጥያ — ክፍተት ሙላ

የጎደለውን ቃል ጻፍ።

**1. (ንዑስ ትምህርት 1)** ልጅ + ______ = ልጅህ።
**መልስ፡ ህ**

**2. (ንዑስ ትምህርት 2)** ______ + በላ = ስለበላ።
**መልስ፡ ስለ**

**3. (ንዑስ ትምህርት 3)** «የእኔ ቤት» ቤት______ ነው።
**መልስ፡ ኤ** — ቤቴ።

**4. (ንዑስ ትምህርት 4)** ድንጋይ + ______ = ድንጋይአማ።
**መልስ፡ -አማ** — የተሞላ ቤተሰብ።

**5. (ንዑስ ትምህርት 4)** ሆድ + ______ = ሆዳም።
**መልስ፡ -ኣም።**

**6. (ንዑስ ትምህርት 5)** ሰፋ → አሰፋ፣ ______፣ ተስፋፋ፣ አስፋፋ።
**መልስ፡ ተሰፋ** — የቤተሰቡ የተ- ቅርፅ።

**7. (ንዑስ ትምህርት 5)** ከአንድ ሥር የግሦች ቤተሰብ ማሳደግ ______ ይባላል።
**መልስ፡ ሥርወቃል።**

**8. (ንዑስ ትምህርት 6)** ______ + ሴት + -ኦች = ከሴቶች።
**መልስ፡ ከ-** — ቅድመ ቅጥያው፣ ከቃሉ በፊት ይገባል።

**9. (ንዑስ ትምህርት 6)** ከ- + ሴት + ______ = ከሴቶች።
**መልስ፡ -ኦች** — ድህረ ቅጥያው፣ ከቃሉ በኋላ ይገባል።
