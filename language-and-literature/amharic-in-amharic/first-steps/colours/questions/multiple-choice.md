# ቀለማት — ብዙ ምርጫ

ትክክለኛውን አንድ መልስ ምረጥ።

**1. (ንዑስ ትምህርት 1)** የቲማቲሙ ቀለም — ነው
ሀ) ቢጫ — ቢጫ  ለ) ቀይ — ቀይ  ሐ) ሰማያዊ — ሰማያዊ
**መልስ፡ ለ) ቀይ — ቀይ።**

**2. (ንዑስ ትምህርት 1)** የቱ ዝርዝር መሰረታዊ ቀለማት (መሰረታዊ ቀለማት) ነው?
ሀ) ቀይ፣ ቢጫ፣ ሰማያዊ  ለ) ጥቁር፣ ነጭ፣ አረንጓዴ  ሐ) ብርቱካናማ፣ ወይንጠጅ፣ ቀይ
**መልስ፡ ሀ) ቀይ፣ ቢጫ፣ ሰማያዊ** — ቀይ፣ ቢጫ፣ ሰማያዊ በሌሎቹ ሁሉ መጀመሪያ ላይ ይቆማሉ።

**3. (ንዑስ ትምህርት 1)** የሰማዩ ቀለም — ነው
ሀ) አረንጓዴ — አረንጓዴ  ለ) ጥቁር — ጥቁር  ሐ) ሰማያዊ — ሰማያዊ
**መልስ፡ ሐ) ሰማያዊ — ሰማያዊ።**

**4. (ንዑስ ትምህርት 2)** ቀይ + ቢጫ = _
ሀ) ብርቱካናማ — ብርቱካናማ  ለ) አረንጓዴ — አረንጓዴ  ሐ) ወይንጠጅ — ወይንጠጅ
**መልስ፡ ሀ) ብርቱካናማ — ብርቱካናማ።**

**5. (ንዑስ ትምህርት 2)** የቱ ቅልቅል ወይንጠጅ (ወይንጠጅ) ያደርጋል?
ሀ) ቢጫ + ሰማያዊ  ለ) ሰማያዊ + ቀይ  ሐ) ቀይ + ቢጫ
**መልስ፡ ለ) ሰማያዊ + ቀይ** — ሰማያዊ + ቀይ = ወይንጠጅ።

**6. (ንዑስ ትምህርት 2)** ቢጫ + ሰማያዊ = _
ሀ) ብርቱካናማ  ለ) ወይንጠጅ  ሐ) አረንጓዴ
**መልስ፡ ሐ) አረንጓዴ** — ቢጫ + ሰማያዊ = አረንጓዴ።
