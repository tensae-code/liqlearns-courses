# የትምህርት እቅድ — ስራ (3ኛ ክፍል)

**ኮርስ፦** አማርኛ (በአማርኛ) · **ርዕስ፦** ተረት · **ትምህርት፦** ስራ (3ኛ ክፍል)
**በሥርዓተ ትምህርቱ ውስጥ ያለው ቦታ፦** ክፍል 7 — ተረት (CURRICULUM.md)።
**ይህ ትምህርት የሚያስተምረው አንድ ነገር፦** የክፍል 3 መጽሐፍ የስራ ምዕራፍ።
**የዚህ ትምህርት የራሱ ደረጃ፦** በ3ኛ ክፍል መጽሐፍ ምዕራፍ ላይ ብቻ ይቆማል — ምዕራፍ 8 — ሥራ።

የትምህርት እቅድ **በታሪኩ ላይ ምን እንደሚቀመጥ** ይነግራል፦ ከታች በተጠቀሱት ትክክለኛ ቦታዎች፣ የትምህርት ገጹ ተጨማሪ ነገር ይሸከማል — ሥዕል፣ GIF፣ ቪዲዮ፣ ድምፅ። እያንዳንዱ ቦታ **«የ… ሥዕል»** በቃላት ተጽፎ፣ ተማሪው በእሱ ምን እንደሚያደርግ የሚነግር አንድ ትንሽ መስመር አብሮት ይጻፋል።

## ንዑስ ትምህርቶች
የዚህ ትምህርት ክፍሎች፣ በቅደም ተከተል — ተማሪው ከመጀመሪያው የሚያያቸው ዝርዝር፣ ወደ ፊት ተቆልፈው፣ እያንዳንዳቸው የቀደመው ሲረጋገጥ የሚከፈቱ፦

1. **ንባብ — አናጺው፣ ንቦቹና አንድ ሕይወት** — የአናጺ ቅርንጫፎችን፣ የንቦች ክፍፍልና የየትነበርሽ ሕይወት መንገር።
2. **ማዳመጥ — የማስተማር ክብርና ፈዋሽ** — የአውራምባ እኩል ክፍፍልና የአበበች እውቀት መንገር።
3. **የሥራ ቃላት — የአናጺ ድር፣ የእንስሳት ምሳሌዎች፣ መደርደር** — ምሳሌዎችን መሥራትና ቅጽልን ከተውሳከ ግስ መለየት።
4. **በሥራ ላይ ሰዋሰው — ስምምነትና ባለቤትነት** — የባለቤትነት ቅጥያዎችን በትክክል ማያያዝ።
5. **ስለ ሥራ መጻፍና መናገር** — ስለ የምትፈልገው ሥራ አንቀጽ መጻፍና በክርክሩ ሐሳብህን መግለጽ።

የበሩ ስብስብ፦ የንዑስ ትምህርቱ ጥያቄዎች ሁሉ — በ questions/ ውስጥ የከባድነት ደረጃ አልተጻፈም፣ ስለዚህ የንዑስ ትምህርቱ የጥያቄ ስብስብ ሁሉ የበሩ ስብስብ ነው።

## ከዚህ ትምህርት በፊት
- መጀመሪያ የሚመከር፦ ግብርና (3ኛ ክፍል)።
- ከዚህ ትምህርት በኋላ፦ ባህል (3ኛ ክፍል)።

## ትምህርቱ ሲያልቅ ተማሪው የሚችለው
1. የአናጺ ሥራ ሁለት ቅርንጫፎችንና መሣሪያዎቹን መዘርዘር።
2. የንቦች የሥራ ክፍፍል መግለጽ።
3. የባለቤትነት ቅጥያዎችን (-ኤ፣ -ህ፣ -ኡ፣ -ኣችን…) መጠቀም።
4. የእንስሳት ምሳሌዎችን መሥራት (እንደንብ ታታሪ)።
5. የየትነበርሽ ንጉሤ ሕይወት ዋና ነጥቦች መንገር።

## የሚያስፈልግህ
የ3ኛ ክፍል የአማርኛ የተማሪ መጽሐፍ (ምዕራፍ 8)፣ ማስታወሻ ደብተርና እርሳስ።

## የትምህርቱ ሂደት (በቅደም ተከተል)
1. **መጀመሪያ ራስህ ሥራ** — ተማሪው የምዕራፉን የቃላት ሰሌዳ ተመልክቶ ቃላቱን ይሰይማል (lesson/lesson.md)።
   - ሥዕል ጨምር [Picture 21607] በመጀመሪያ ራስህ ሥራ ውስጥ፦ የቃላት ሰሌዳ — ሥራ፦ አናጺ፣ ንብ፣ መምህር፣ ሥራ — ተማሪው የሥዕሉን ቃላት በአማርኛ ይሰይማል፣ ንዑስ ትምህርቶቹ ከመጀመራቸው በፊት።
2. **ማብራሪያው** — ንዑስ ትምህርቶቹ በቅደም ተከተል (lesson/lesson.md)።
3. **ለጓደኛህ ንገረው** — ተማሪው የምዕራፉን አንድ ተረት ወይም ንባብ ለጓደኛው ይነግራል (lesson/lesson.md)።
   - ቪዲዮ ጨምር፦ በ video-script.md ውስጥ ያለው ስክሪፕት፣ ተቀርጾ — እጅግ ቀላል ድምፅ (በኋላ፣ ቪዲዮዎች ሲሠሩ ይሠራል)።
4. **ጥያቄዎች** — ከ questions/፦ ብዙ ምርጫ፣ መጻፍ — በተማሪው ደረጃና የትምህርት ድብልቅ ቀርበዋል (levels.md)።
5. **የእጅ ሥራ** — hands-on.md።
6. **ራስህ ሥራ** — የምዕራፉን ሥራ በራስህ ሙላ (lesson/lesson.md)።

## የዚህ ትምህርት ተጨማሪዎች (ሙሉ ዝርዝር)
- ሥዕል [Picture 21607] — የቃላት ሰሌዳ — ሥራ፦ አናጺ፣ ንብ፣ መምህር፣ ሥራ → ተማሪው የሥዕሉን ቃላት በአማርኛ ይሰይማል።
- ቪዲዮ — የ video-script የተቀረጸ (በኋላ ይሠራል) → ተማሪው አብሮ ያዳምጣል፣ አብሮ ይነግራል።

ገንቢው ገና መሙላት ያልቻለው ቦታ በእቅዱ ውስጥ እንደ ቦታ ይቆያል — እቅዱ የግንባታ ወረቀት ነው፣ ስለዚህ ትምህርቱ የሚፈልገው ምንም ነገር አይረሳም።

## ተማሪው ከተገታ
- ተማሪው የንቦቹ ሚናዎች ቢያምኑት → ንግሥት / ሠራተኛ / ዝብኝ ሦስት ካርዶች አድርገህ አዛምድ።
- ቅጥያዎቹ ቢከብዱት → ወንድም፣ ግድብ፣ ባህል፣ አባት በሚሉ ቃላት ላይ ደጋግመህ ሥራ።
