# ተረት (3ኛ ክፍል) — ብዙ ምርጫ

ትክክለኛውን አንድ መልስ ምረጥ.

**1. (ንዑስ ትምህርት 1)** አራት ላሞች ነብሩን ያባረሩት እንዴት ነበር?
ሀ) አብረው ቆመው  ለ) አንድ በአንድ  ሐ) በሩጫ
**መልስ፡ ሀ) አብረው ቆመው** — አብረው ቆመው አሸነፉት።

**2. (ንዑስ ትምህርት 1)** ላሞቹ ለምን ተበሉ?
ሀ) ዝናብ ስላጣ  ለ) ተጣልተው ከተለያዩ በኋላ  ሐ) በሽታ ስለያዛቸው
**መልስ፡ ለ) ተጣልተው ከተለያዩ በኋላ** — ከተለያዩ በኋላ አንድ በአንድ ተበሉ።

**3. (ንዑስ ትምህርት 1)** ጥበበኛው ዛፍ ስለ ጠላት ምን አለ?
ሀ) ጠላታችን መጥረቢያው ነው  ለ) ጠላታችን እጀታ የሚሆነው ጎባጣው ዛፍ ነው  ሐ) ጠላት የለም
**መልስ፡ ለ) ጠላታችን እጀታ የሚሆነው ጎባጣው ዛፍ ነው** — እጀታው ከራሳቸው ዝግጅት እንደሆነ አለ።

**4. (ንዑስ ትምህርት 2)** ልጁ አባቱ ሲወድቅ ምን አደረገ?
ሀ) አባቱን አነሳ  ለ) የአባቱን ደንብ መልሶ ጠቀሰለት  ሐ) ሄደ
**መልስ፡ ለ) የአባቱን ደንብ መልሶ ጠቀሰለት** — ደንቡን መልሶ ጠቀሰለት።

**5. (ንዑስ ትምህርት 2)** ብልሁ ሰው ከጅብ እንዴት አመለጠ?
ሀ) በሩጫ  ለ) ጅቡን አዘግይቶ ወደ ዛፍ በመውጣት  ሐ) በመዋኘት
**መልስ፡ ለ) ጅቡን አዘግይቶ ወደ ዛፍ በመውጣት** — «ዘመዶችህን ጥራ» ብሎ አዘገየው፣ ወደ ዛፍ ወጣ።

**6. (ንዑስ ትምህርት 2)** ዝንጀሮዋ ከአንበሳው እንዴት አመለጠች?
ሀ) በፍጥነት ሮጣ  ለ) አፍንጫዋ ጉንፋን እንዳለበት ብላ  ሐ) በመደበቅ
**መልስ፡ ለ) አፍንጫዋ ጉንፋን እንዳለበት ብላ** — ጉንፋኑ አፍንጫዋን ዘግቷል አለች።

**7. (ንዑስ ትምህርት 3)** KWL ሠንጠረዥ ሦስት ዓምዶች የትኞቹ ናቸው?
ሀ) አውቃለሁ / ማወቅ እፈልጋለሁ / ተማርኩ  ለ) ጀምር / ቀጥል / ጨርስ  ሐ) ሰም / አንብብ / ጻፍ
**መልስ፡ ሀ) አውቃለሁ / ማወቅ እፈልጋለሁ / ተማርኩ** — ሠንጠረዡ ሦስቱ ዓምዶች ናቸው።

**8. (ንዑስ ትምህርት 3)** ተራች ማለት ምንድነው?
ሀ) ተረትን የሚነግር  ለ) ተረትን የሚሰማ ብቻ  ሐ) መጽሐፍ የሚጽፍ
**መልስ፡ ሀ) ተረትን የሚነግር** — ተራች ተረቱን ይነግራል፣ መላሽ ይመልሳል።

**9. (ንዑስ ትምህርት 3)** የማዳመጥ ጽሑፎች በተማሪ መጽሐፉ ውስጥ ለምን የሉም?
ሀ) መምህሩ የሚያነባቸው ስለሆነ  ለ) ጠፍተዋል  ሐ) አልተጻፉም
**መልስ፡ ሀ) መምህሩ የሚያነባቸው ስለሆነ** — ማዳመጥ በመምህሩ ይነበባል።

**10. (ንዑስ ትምህርት 4)** የብልሁ ሰው ሠንጠረዥ የሚያሳየው ቅደም ተከተል ምንድነው?
ሀ) ችግር → መፍትሔ  ለ) ምግብ → ውኃ  ሐ) ጠዋት → ማታ
**መልስ፡ ሀ) ችግር → መፍትሔ** — ችግር + ችግር → መፍትሔ ሠንጠረዥ።

**11. (ንዑስ ትምህርት 4)** የአይጥና የድመት ጋብቻ ታሪክን ስትጽፍ ምን ትለውጣለህ?
ሀ) ርዕሱን  ለ) መጨረሻውን  ሐ) ገፀባሕርያቱን ሁሉ
**መልስ፡ ለ) መጨረሻውን** — መጽሐፉ በተለየ መጨረሻ መልሶ መጻፍን ይጠይቃል።

**12. (ንዑስ ትምህርት 4)** «መልካም ሥነምግባር ብዙ ጥቅም አለው» አንቀጹ የሚጀምረው ከየት ነው?
ሀ) ከመነሻ ሐረግ  ለ) ከጥያቄ  ሐ) ከዘፈን
**መልስ፡ ሀ) ከመነሻ ሐረግ** — አንቀጹ ከተሰጠ መነሻ ይጀምራል።

**13. (ንዑስ ትምህርት 5)** «ድምጽ» ከአንድ በላይ ፍቺው የትኛው ነው?
ሀ) ድምፅም ምርጫም  ለ) ቀለምም ሽታም  ሐ) ምግብም ውኃም
**መልስ፡ ሀ) ድምፅም ምርጫም** — ድምጽ = ድምፅ እና ምርጫ።

**14. (ንዑስ ትምህርት 5)** የትኛው ቃል ስም ነው?
ሀ) ሄደ  ለ) ዛፍ  ሐ) ቶሎ
**መልስ፡ ለ) ዛፍ** — ስም ነገሮችን ይሰይማል፦ ሰው፣ ዛፍ፣ ድመት።

**15. (ንዑስ ትምህርት 5)** የ«ወደቀ» ተቃራኒ ፍቺ የትኛው ነው?
ሀ) ተኛ  ለ) ተነሳ  ሐ) ሮጠ
**መልስ፡ ለ) ተነሳ** — ወደቀ → ተነሳ።

**16. (ንዑስ ትምህርት 6)** የምዕራፍ 3 አንዱ ዓላማ የትኛው ነው?
ሀ) የተረቱን ዋና ገፀ ባህሪያት መሰየም  ለ) መኪና መንዳት  ሐ) ግጥም ብቻ መሥራት
**መልስ፡ ሀ) የተረቱን ዋና ገፀ ባህሪያት መሰየም** — ዓላማዎቹ መካከል ገፀ ባህሪያትን መሰየም አለ።

**17. (ንዑስ ትምህርት 6)** ልጁ እናቱን ለጓደኞቹ እንዴት አስተዋወቃት?
ሀ) «እናቴ ናት» ብሎ  ለ) «ስራተኛዬ ናት» ብሎ  ሐ) «አክስቴ ናት» ብሎ
**መልስ፡ ለ) «ስራተኛዬ ናት» ብሎ** — በፊቷ አፍሮ «ስራተኛዬ ናት» አለ።

**18. (ንዑስ ትምህርት 6)** እናቲቱ ፊቷ የተበላሸው እንዴት ነበር?
ሀ) በበሽታ  ለ) ልጇን ከእሳት ስታወጣ  ሐ) በአደጋ
**መልስ፡ ለ) ልጇን ከእሳት ስታወጣ** — ልጇን በእርጥብ ጨርቅ ጠቅልላ ስታወጣ ተቃጠለች።
