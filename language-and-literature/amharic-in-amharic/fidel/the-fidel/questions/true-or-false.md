# ፊደል — እውነት ወይም ሀሰት

እውነት ወይም ሀሰት ተናገር፣ ለምን እንደሆነም ንገር።

**1. (ንዑስ ትምህርት 2)** በፊደል ገበታው ላይ ያለ እያንዳንዱ ፊደል በቤተሰቡ ውስጥ ሰባት ቅርጾች አሉት።
**መልስ፡ እውነት** — አንድ ፊደል የሰባት ቅርጾች ቤተሰብ ነው።

**2. (ንዑስ ትምህርት 3)** በረድፉ ሸ ሹ ሺ ሻ ሼ ሽ ሾ ውስጥ፣ ቅርፁ ሱ የቤተሰቡ ነው።
**መልስ፡ ሀሰት** — ሱ የሰ ቤተሰብ ነው፤ የሸ ረድፍ ሹ ይይዛል።

**3. (ንዑስ ትምህርት 4)** ሸበሸበ የሚለው ቃል ፊደላቱን በ፣ ሰ እና ሸ ብቻ በመጠቀም ሊነበብ ይችላል።
**መልስ፡ እውነት** — ከተማሩ ፊደላት ብቻ የተገነባ ነው።

**4. (ንዑስ ትምህርት 8)** ሏ የለ የ-ዋ (የከንፈር) ቅርፅ ነው።
**መልስ፡ እውነት** — ለ + ዋ = ሏ።

**5. (ንዑስ ትምህርት 9)** የተገኙ ቤተሰቦች ቈ ኈ ኰ ጐ እያንዳንዳቸው ሰባት ቅርጾች አሏቸው፣ በዋና ገበታው ላይ እንዳሉ ቤተሰቦች።
**መልስ፡ ሀሰት** — እያንዳንዳቸው አምስት ቅርጾች አሏቸው።
