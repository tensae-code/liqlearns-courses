# የፊደል ቅርጾች — እግር ያላቸው ፊደላት — እውነት ወይም ሀሰት

እውነት ወይም ሀሰት ተናገር፣ ለምን እንደሆነም ንገር።

**1. (ንዑስ ትምህርት 1)** ጠ በሦስት እግር ይቆማል (ባለ ሦስት እግር)።
**መልስ፡ እውነት** — ጠ የሦስት እግር ስብስብ ራስ ነው፣ ከጨ እና ሐ ጋር።

**2. (ንዑስ ትምህርት 1)** ሸ በአንድ የእግር ቡድን ውስጥ ብቻ ሊገኝ ይችላል፣ ምክንያቱም ቤተሰብ አንድ ቅርፅ ብቻ አለው።
**መልስ፡ ሀሰት** — መምሪያው እንደሚያትመው፣ ሸ በአንድ እግርም በሁለት እግርም ስብስቦች ውስጥ ይቆማል፤ የምትለየው ፊትህ ያለው ቅርፅ ነው፣ ምክንያቱም የቤተሰብ ሰባት ቅርጾች ሁሉ በአንድ መልኩ አይቆሙም።

**3. (ንዑስ ትምህርት 2)** የሀ ቤተሰብ የቁልፍ ስም ሀሌታው ነው።
**መልስ፡ እውነት** — ሀ–ሀሌታው፣ የ፪ኛ ክፍል መምሪያ ሠንጠረዥ እንደሚያትመው።
