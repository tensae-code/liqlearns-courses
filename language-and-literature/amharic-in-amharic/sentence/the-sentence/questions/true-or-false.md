# ሐረጉ — እውነት ወይም ሀሰት

እውነት ወይም ሀሰት በል።

**1. (ንዑስ ትምህርት 1)** እንደ ዝናብ ያለ ነጠላ ቃል አስቀድሞ ሙሉ ሐረግ ነው።
**መልስ፡ ሀሰት** — ነገር ይሰይማል፣ ነገር ግን ሙሉ ሐሳብ ገና አይሸከምም።

**2. (ንዑስ ትምህርት 2)** «አባትህ መጣ።» እና «አባትህ መጣ?» በተመሳሳይ መንገድ ይነበባሉ።
**መልስ፡ ሀሰት** — ምልክቱ አነባበቡን ይቀይራል፦ በ ። መናገር፣ በ ? መጥየቅ።

**3. (ንዑስ ትምህርት 4)** በድርብ ሐረግ ውስጥ፣ እያንዳንዱ ቀላል ሐረግ ብቻውን ሊቆም ይችላል።
**መልስ፡ እውነት** — አያያዙ ያያይዛቸዋል ብቻ።

**4. (ንዑስ ትምህርት 6)** «ነፍሴ ምንጥቅ! አለች» አጋናኝ ሐረግ ነው — ጠንካራ ስሜት ብቅ ይላል።
**መልስ፡ እውነት።**

**5. (ንዑስ ትምህርት 7)** አዎንታዊ ሐረግ በግሱ ላይ ልዩ ምልክት ይሸከማል።
**መልስ፡ ሀሰት** — ድርጊቱን ሳያፈርስ ይናገራል፣ ልዩ ምልክት የለውም፤ የአል- … -ም ምልክት የአሉታዊው ነው።

**6. (ንዑስ ትምህርት 9)** ልጁ ከትምህርትቤት መጣ። ግሱ ስለታሰረ ውስብስብ ሐረግ ነው።
**መልስ፡ ሀሰት** — ነጠላ፣ ቀላል ነው፦ አንድ የአንቀጽ አሃድ፣ አንድ ግስ፣ ሙሉ ስሜት። (ሲመጣ ታሳሪ ይሆን ነበር፤ ተራ መጣ አይደለም።)

**7. (ንዑስ ትምህርት 10)** በትንተና ሠንጠረዡ ውስጥ፣ ታላቁ የህዳሴ ግድብ የሐረጉ ባለቤት ነው፣ የኤሌክትሪክ ሀይል ማመንጨት ጀመረም ማሰሪያ አንቀጹ ነው።
**መልስ፡ እውነት** — ሐረጉ ስለ ታላቁ የህዳሴ ግድብ ነው፤ «የኤሌክትሪክ ሀይል ማመንጨት ጀመረ» የግስ ክፍሉ ነው።

**8. (ንዑስ ትምህርት 11)** እንደ -ኣቸው ያለ ጥገኛ ምዕላድ ብቻውን እንደ ቃል ሊቆም ይችላል።
**መልስ፡ ሀሰት** — ጥገኛ ምዕላዶች ብቻቸውን ሊቆሙ አይችሉም፤ በነፃ ምዕላድ ላይ መደገፍ አለባቸው፣ -ኣቸው በ ላም + ኦች + ኣቸው ውስጥ እንደሚደገፍ።

**9. (ንዑስ ትምህርት 12)** እያንዳንዱ አሉታዊ ሐረግ ግስን በ አል- … -ም በመጠቅለል ይሠራል።
**መልስ፡ ሀሰት** — የመሆን ሐረግ በ አይደለም ይክዳል፣ የይዞታ ሐረግም በ የላቸውም፤ መጠቅለሉ የድርጊት ግሶች ነው።

**10. (ንዑስ ትምህርት 16)** በሞዴሉ ውስጥ እነአበበ አበበን ከጓደኞቹ ጋር ይሰይማል — የተሰየመ ሰው ብዙ ቁጥር።
**መልስ፡ እውነት**

**11. (ንዑስ ትምህርት 17)** የገጽ 142 ሠንጠረዥ ከእያንዳንዱ ሐረግ ሁለት ነገሮችን ይጠይቃል፦ ሰውና ጊዜ።
**መልስ፡ እውነት**

**12. (ንዑስ ትምህርት 18)** የ8ኛ ክፍል የጥበበኛዋ ሴት ምዕራፍ የራስህን 3 ቀላል እና 3 ድርብ ሐረጎች ይጠይቃል።
**መልስ፡ እውነት**

**13. (ንዑስ ትምህርት 19)** አራቱ ተግባራት ሀተታዊ፣ ጥያቄያዊ፣ ትዕዛዛዊ እና አጋናኝ ናቸው።
**መልስ፡ እውነት**

**14. (ንዑስ ትምህርት 20)** 8ኛ ክፍል ጥያቄዎችን በተገላቢጦሽ መንገድ ይቀይራል — ወደ አዎንታዊና አሉታዊ መግለጫዎች።
**መልስ፡ እውነት**

**15. (ንዑስ ትምህርት 21)** የባለቤት–ግስ የቁጥር ስምምነት የገጽ 46 የስህተት ዓይነቶች አንዱ ነው።
**መልስ፡ እውነት**

**16. (ንዑስ ትምህርት 22)** የስርዓተ ነጥብ ዓይነቶች በ9ኛ ክፍል መምሪያ ማስታወሻ ውስጥ የሥርዓተ ነጥብ ዓይነቶች ርዕስ ነው።
**መልስ፡ እውነት**

**17. (ንዑስ ትምህርት 23)** ሐረግ የመምሪያው የፍሬዝ ቃል ነው።
**መልስ፡ እውነት**
