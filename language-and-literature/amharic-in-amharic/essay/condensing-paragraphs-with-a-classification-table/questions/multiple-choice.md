# አንቀጾችን በምደባ ሠንጠረዥ ማሳጠር — ብዙ ምርጫ

ትክክለኛውን አንድ መልስ ምረጥ።

**1. (ንዑስ ትምህርት 1)** የምደባ ሠንጠረዡ አምዶች እነማን ናቸው?
ሀ) ማን / መቼ / ለምን  ለ) ስም / አገልግሎት / ቦታ / ባሕርይ / የተገነባበት ጊዜ  ሐ) ትልቅ / ትንሽ / መካከለኛ
**መልስ፡ ለ) ስም / አገልግሎት / ቦታ / ባሕርይ / የተገነባበት ጊዜ** — የቅርስ ምዕራፉ አምስቱ።

**2. (ንዑስ ትምህርት 1)** የሠንጠረዡ «የተገነባበት ጊዜ» አምድ ምን ይይዛል?
ሀ) የጸሐፊውን ስም  ለ) ቦታው የተገነባበትን ጊዜ  ሐ) የአንቀጹን ቁጥር
**መልስ፡ ለ) ቦታው የተገነባበትን ጊዜ** — ስም / አገልግሎት / ቦታ / ባሕርይ / የተገነባበት ጊዜ።

**3. (ንዑስ ትምህርት 1)** ማጨመቅ ምን ይይዛል?
ሀ) እያንዳንዱን እውነታ በሦስተኛ ርዝመት  ለ) የመጀመሪያውን እውነታ ብቻ  ሐ) ቃላቱን ሁሉ
**መልስ፡ ሀ) እያንዳንዱን እውነታ በሦስተኛ ርዝመት** — ወንፊቱ እውነታዎቹን ይይዛል፣ ድግግሞሹን ይጥላል።

**4. (ንዑስ ትምህርት 1)** የምደባ ሠንጠረዡ ምን ዓይነት ነው?
ሀ) ደብዳቤ  ለ) ቢጋር (አደራጃ)  ሐ) ግጥም
**መልስ፡ ለ) ቢጋር (አደራጃ)** — መጽሐፉ የመደቢያ ክፈፉን የምደባ ቢጋር ይለዋል።
