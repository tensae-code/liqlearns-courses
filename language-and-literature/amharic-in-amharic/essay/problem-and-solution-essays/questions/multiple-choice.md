# የችግርና የመፍትሔ ድርሰቶች — ብዙ ምርጫ

ትክክለኛውን አንድ መልስ ምረጥ።

**1. (ንዑስ ትምህርት 1)** በመጽሐፉ የችግር ሰንሰለት ውስጥ፣ የደን መጨፍጨፍ መጀመሪያ ወደ ምን ይመራል?
ሀ) በቂ ዝናብ  ለ) መሬት መገፈፍ  ሐ) ብልጽግና
**መልስ፡ ለ) መሬት መገፈፍ** — መጨፍጨፍ → መገፈፍ → መሸርሸር → ድርቅ → ድህነት።

**2. (ንዑስ ትምህርት 1)** የችግር ሰንሰለቱ ሦስተኛው አገናኝ ምንድነው?
ሀ) ድርቅ  ለ) የአፈር መሸርሸር  ሐ) ድህነት
**መልስ፡ ለ) የአፈር መሸርሸር** — መጨፍጨፍ → መገፈፍ → መሸርሸር → ድርቅ → ድህነት።

**3. (ንዑስ ትምህርት 1)** ምንም የችግር አገናኝ የማይመልስ የመፍትሔ አገናኝ ምንድነው?
ሀ) ምርጡ ዓይነት  ለ) ጌጥ  ሐ) መደምደሚያው
**መልስ፡ ለ) ጌጥ** — እያንዳንዱ የመፍትሔ አገናኝ የችግር አገናኝን መመለስ አለበት።

**4. (ንዑስ ትምህርት 1)** ድርሰቱ ከምን ይገነባል?
ሀ) ግጥም  ለ) ሁለት ሰንሰለቶች ያሉት ቢጋር  ሐ) ደብዳቤ
**መልስ፡ ለ) ሁለት ሰንሰለቶች ያሉት ቢጋር** — የሁለት ሰንሰለት ቢጋር የድርሰቱ ዕቅድ ነው።
