# Honey and wax — hive products — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Beeswax is a hive product.
**Answer: True**

**2. (Sub lesson 1)** Honey is the hive's only product.
**Answer: False**

**3. (Sub lesson 2)** Processing affects the value of hive products.
**Answer: True**

**4. (Sub lesson 2)** Honey is sold straight from the frame with no processing.
**Answer: False**
