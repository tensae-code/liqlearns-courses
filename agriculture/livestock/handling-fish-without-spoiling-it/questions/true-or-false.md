# Handling fish without spoiling it — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** The handling clock starts at capture.
**Answer: True**

**2. (Sub lesson 1)** Transport is part of the handling chain.
**Answer: False**

**3. (Sub lesson 2)** Chilling slows spoilage.
**Answer: True**

**4. (Sub lesson 2)** Once caught, handling cannot change a fish's quality.
**Answer: False**
