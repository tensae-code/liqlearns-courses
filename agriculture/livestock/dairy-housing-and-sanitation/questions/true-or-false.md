# Dairy housing and farm sanitation — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Loose housing is one of the two common dairy houses.
**Answer: True**

**2. (Sub lesson 1)** Cows must be confined at all hours to be dairy cattle.
**Answer: False**

**3. (Sub lesson 2)** Handlers are one of the contamination routes sanitation guards.
**Answer: True**

**4. (Sub lesson 2)** Cleaning the byre is a rescue job, done only when disease appears.
**Answer: False**
