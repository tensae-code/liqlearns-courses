# Choosing poultry — layer and broiler breeds — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Layers are chosen for egg production.
**Answer: True**

**2. (Sub lesson 1)** Parent stock is kept mainly for table eggs.
**Answer: False**

**3. (Sub lesson 2)** Most parent-stock eggs are imported.
**Answer: True**

**4. (Sub lesson 2)** No layer breeds were ever imported to Ethiopia.
**Answer: False**
