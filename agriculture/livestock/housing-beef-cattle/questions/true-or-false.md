# Housing beef cattle — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Beef housing needs are simpler than dairy housing needs.
**Answer: True**

**2. (Sub lesson 1)** Beef cattle need a milking routine built into housing.
**Answer: False**

**3. (Sub lesson 2)** Safe handling is part of what a yard must allow.
**Answer: True**

**4. (Sub lesson 2)** A yard that floods every rain is good housing if it was cheap.
**Answer: False**
