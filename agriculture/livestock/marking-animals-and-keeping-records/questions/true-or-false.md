# Marking animals and keeping herd records — true or false

Say true or false.

**1. (Sub lesson 1)** Records expose weak areas of herd performance.
**Answer: True**

**2. (Sub lesson 1)** Good memory replaces records fully.
**Answer: False**

**3. (Sub lesson 2)** Branding is a temporary mark.
**Answer: False**

**4. (Sub lesson 2)** Tattooing is permanent identification.
**Answer: True**
