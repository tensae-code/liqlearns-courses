# Ethiopia's own dairy breeds — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** All Ethiopian local breeds are zebu types.
**Answer: True**

**2. (Sub lesson 1)** Local breeds are all one size and colour.
**Answer: False**

**3. (Sub lesson 2)** Local breeds can survive and produce where exotics struggle.
**Answer: True**

**4. (Sub lesson 2)** A breed can be judged better without asking where it will live.
**Answer: False**
