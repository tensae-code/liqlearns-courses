# Beekeeping in Ethiopia — log, top-bar and frame hives — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** The top-bar hive is a single-storey long box.
**Answer: True**

**2. (Sub lesson 1)** The log hive is the modern system.
**Answer: False**

**3. (Sub lesson 2)** Movable frames allow inspection and harvest.
**Answer: True**

**4. (Sub lesson 2)** Each generation gains control at no cost in skill or money.
**Answer: False**
