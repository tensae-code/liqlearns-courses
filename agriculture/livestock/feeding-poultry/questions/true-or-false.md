# Feeding poultry — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Chicks, growers and layers need stage-matched rations.
**Answer: True**

**2. (Sub lesson 1)** One feed suits every poultry stage equally.
**Answer: False**

**3. (Sub lesson 2)** Protein and energy values guide ration choice.
**Answer: True**

**4. (Sub lesson 2)** Feed composition does not matter if birds look hungry.
**Answer: False**
