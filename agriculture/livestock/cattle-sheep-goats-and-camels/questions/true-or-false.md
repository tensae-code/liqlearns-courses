# Cattle, sheep, goats and camels — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** There are over 1,000 cattle breeds worldwide.
**Answer: True**

**2. (Sub lesson 1)** Cattle give meat, milk, draft power, hides and manure.
**Answer: True**

**3. (Sub lesson 2)** Camels feed on thorny bushes using thick, tough lips.
**Answer: True**

**4. (Sub lesson 2)** Goats have over 3,000 breeds.
**Answer: False**
