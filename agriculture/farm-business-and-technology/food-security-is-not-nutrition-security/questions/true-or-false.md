# Food security is not nutrition security — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Food security in quantity alone is enough for good nutrition.
**Answer: False**

**2. (Sub lesson 1)** Nutrition security includes sanitation as well as food.
**Answer: True**

**3. (Sub lesson 2)** Knowledge of sound household and caring practices is part of nutrition security.
**Answer: True**

**4. (Sub lesson 2)** A full grain store guarantees a household is nutrition-secure.
**Answer: False**
