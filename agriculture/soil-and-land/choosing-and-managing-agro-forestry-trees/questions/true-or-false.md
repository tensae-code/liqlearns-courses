# Choosing and managing agro-forestry trees — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Species are matched to jobs like boundary or fodder.
**Answer: True**

**2. (Sub lesson 1)** Any tree species serves any agro-forestry job equally.
**Answer: False**

**3. (Sub lesson 2)** Pruning can be part of managing system trees.
**Answer: True**

**4. (Sub lesson 2)** System trees are never harvested.
**Answer: False**
