# How water gets polluted — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Pollution can be present even when water looks clear.
**Answer: True**

**2. (Sub lesson 1)** A trace of any substance, however small, is automatically pollution.
**Answer: False**

**3. (Sub lesson 2)** Rain can carry field chemicals into streams.
**Answer: True**

**4. (Sub lesson 2)** Only factories pollute water; farms never do.
**Answer: False**
