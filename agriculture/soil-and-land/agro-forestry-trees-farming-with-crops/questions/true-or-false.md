# Agro-forestry — trees farming with crops — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Trees with crops on the same land can be agro-forestry.
**Answer: True**

**2. (Sub lesson 1)** Agro-forestry means any trees anywhere near a farm.
**Answer: False**

**3. (Sub lesson 2)** The system is managed as one whole.
**Answer: True**

**4. (Sub lesson 2)** Animals can never be part of agro-forestry.
**Answer: False**
