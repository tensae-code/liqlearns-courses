# Natural resources — renewable and not — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** A forest is a renewable resource when use lets it regrow.
**Answer: True**

**2. (Sub lesson 1)** Humans can produce natural resources in workshops.
**Answer: False**

**3. (Sub lesson 2)** Minerals are renewable because the earth is large.
**Answer: False**

**4. (Sub lesson 2)** Overusing a renewable resource can empty it like a mine.
**Answer: True**
