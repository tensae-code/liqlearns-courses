# Words for farming — shifting, settled, subsistence, commercial — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Hunting and gathering still survives where land and climate do not allow farming.
**Answer: True**

**2. (Sub lesson 1)** In shifting cultivation the same plot is farmed continuously for decades.
**Answer: False**

**3. (Sub lesson 2)** Commercial farming grows the harvest to be sold.
**Answer: True**

**4. (Sub lesson 2)** Settled agriculture never uses manure or fertiliser.
**Answer: False**
