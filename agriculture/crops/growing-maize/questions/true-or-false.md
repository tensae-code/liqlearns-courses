# Growing maize — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Maize is planted at the start of the rains, March–April.
**Answer: True**

**2. (Sub lesson 1)** Maize ground is ploughed only once, lightly.
**Answer: False**

**3. (Sub lesson 2)** Fertiliser rates should follow the soil's level.
**Answer: True**

**4. (Sub lesson 2)** Maize gives carbohydrates but no protein or fat.
**Answer: False**
