# Establishing coffee, tea and spice fields — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Shade can be part of establishing a coffee field.
**Answer: True**

**2. (Sub lesson 1)** Perennial fields are replanted from seed every year.
**Answer: False**

**3. (Sub lesson 2)** Weeding and feeding are standing-care jobs.
**Answer: True**

**4. (Sub lesson 2)** Spacing can be fixed later if it was wrong at establishment.
**Answer: False**
