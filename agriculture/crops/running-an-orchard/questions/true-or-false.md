# Running an orchard — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** An orchard's trees occupy their ground for many years.
**Answer: True**

**2. (Sub lesson 1)** Spacing can be changed easily every season.
**Answer: False**

**3. (Sub lesson 2)** Irrigation means water applied by plan and control.
**Answer: True**

**4. (Sub lesson 2)** Irrigation is a new practice, only decades old.
**Answer: False**
