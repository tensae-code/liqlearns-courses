# Sorting vegetables — leaf, flower, root; cool season, warm season — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Asparagus is listed among the leafy vegetables in this classification.
**Answer: True**

**2. (Sub lesson 1)** A vegetable can only be sorted one way.
**Answer: False**

**3. (Sub lesson 2)** Warm-season crops grow best in the coldest weeks.
**Answer: False**

**4. (Sub lesson 2)** Cool-season vegetables are often shallow-rooted.
**Answer: True**
