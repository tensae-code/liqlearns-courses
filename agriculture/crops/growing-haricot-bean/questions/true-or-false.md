# Growing haricot bean — and safe storage — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Haricot bean can be grown mixed with maize and sorghum.
**Answer: True**

**2. (Sub lesson 1)** Haricot bean needs one single soil type only.
**Answer: False**

**3. (Sub lesson 2)** Haricot bean matures in three to four months.
**Answer: True**

**4. (Sub lesson 2)** Wet grain stored quickly is safe from weevils.
**Answer: False**
