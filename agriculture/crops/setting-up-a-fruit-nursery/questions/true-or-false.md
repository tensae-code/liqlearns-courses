# Setting up a fruit nursery — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** A well-drained site is on the nursery checklist.
**Answer: True**

**2. (Sub lesson 1)** A flooding hollow makes a good nursery site.
**Answer: False**

**3. (Sub lesson 2)** The nursery should be near the main field.
**Answer: True**

**4. (Sub lesson 2)** Seedlings can be left uncared-for for weeks without harm.
**Answer: False**
