# Expert systems — a program that imitates an expert — multiple choice

Pick the one right answer.

**1.** (Sub lesson 1) The user interface —
a) takes the query and shows the recommendation  b) stores the rules  c) is the brain  d) prints money
**Answer: a) takes the query and shows the recommendation**

**2.** (Sub lesson 2) The knowledge base stores knowledge as —
a) if–then–else rules  b) photographs  c) songs  d) passwords only
**Answer: a) if–then–else rules**

**3.** (Sub lesson 2) How well the system performs depends on the knowledge base's —
a) completeness and accuracy  b) colour  c) size of screen  d) price
**Answer: a) completeness and accuracy**

**4.** (Sub lesson 3) The inference engine is —
a) the brain that produces the answer  b) the keyboard  c) the rule store  d) the printer
**Answer: a) the brain that produces the answer**

**5.** (Sub lesson 3) MYCIN —
a) identifies bacteria and recommends antibiotics  b) drives cars  c) translates languages  d) cleans floors
**Answer: a) identifies bacteria and recommends antibiotics**
