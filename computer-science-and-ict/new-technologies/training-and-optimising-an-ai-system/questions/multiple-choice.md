# Training and Optimising an AI System — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Test data must be —**
a) Trained on twice  b) Kept unseen until the final measurement  c) Deleted  d) The easiest examples
**Answer: b) Kept unseen until the final measurement** — An unseen set is the only score that practice cannot flatter.

**2. (Sub lesson 1) A label is —**
a) The system's name  b) The correct answer attached to a training example  c) A price tag  d) The test score
**Answer: b) The correct answer attached to a training example** — Labelled examples are what supervised training learns from.

**3. (Sub lesson 1) During training, the learning procedure repeatedly —**
a) Changes the test data  b) Measures the error on training data and adjusts the system to lower it  c) Asks the user  d) Prints the model
**Answer: b) Measures the error on training data and adjusts the system to lower it** — That loop — measure, adjust — is training.

**4. (Sub lesson 2) Overfitting means the system —**
a) Trains too slowly  b) Memorises the training examples and does worse on unseen data  c) Uses too little data  d) Has no labels
**Answer: b) Memorises the training examples and does worse on unseen data** — Perfect practice score, sagging test score: the signature of memorising.

**5. (Sub lesson 2) A training score of 100% should make you ask —**
a) Nothing — perfect is perfect  b) 'On which data — practised or unseen?'  c) For a bigger screen  d) For more labels
**Answer: b) 'On which data — practised or unseen?'** — Only the unseen-data score measures learning rather than memory.

**6. (Sub lesson 2) Which of these is a hyperparameter — a setting the builder tunes around training?**
a) The test examples  b) How long to train / how complex a model to allow  c) The labels  d) The final score
**Answer: b) How long to train / how complex a model to allow** — Optimising tunes such settings and judges by test performance.
