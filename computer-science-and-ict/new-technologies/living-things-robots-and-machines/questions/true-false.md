# Living Things, Robots and Machines — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Born/germinates, feeds, grows, reproduces, dies**
**Answer: True**

**2. (Sub lesson 1) True or false: Born/germinates, feeds, grows, reproduces, dies** — as the answer to: What is le cycle de vie?
**Answer: False — The life cycle — running from itself, powered from within**

**3. (Sub lesson 1) True or false: Yes — it runs the cycle slowly**
**Answer: True**

**4. (Sub lesson 1) True or false: Yes — it runs the cycle slowly** — as the answer to: Name two border cases the activity argues.

**5. (Sub lesson 1) True or false: At the border cases**

**6. (Sub lesson 2) True or false: At the border cases** — as the answer to: What can a robot imitate?

**7. (Sub lesson 2) True or false: Feed itself, grow, reproduce**
**Answer: True**

**8. (Sub lesson 2) True or false: Feed itself, grow, reproduce** — as the answer to: What dies when a robot is switched off?
**Answer: False — Nothing — that is the point**

**9. (Sub lesson 2) True or false: Calling a robot alive because it moves — mistaking imitation for the thing**
**Answer: True**

**10. (Sub lesson 2) True or false: Calling a robot alive because it moves — mistaking imitation for the thing** — as the answer to: What is an automaton in this comparison?
