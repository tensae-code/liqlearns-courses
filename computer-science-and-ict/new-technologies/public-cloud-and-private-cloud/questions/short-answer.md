# Public cloud and private cloud — short answer

Answer in one or two sentences.

**1.** Tell public from private cloud in one line each.
**Answer:** Public: a provider's resources shared across clients, each holding an isolated part. Private: all resources dedicated to one application/owner, with complete control of security and privacy.

**2.** Who is a private cloud's extra protection layer for?
**Answer:** Owners of sensitive, confidential information who need complete control over its security and privacy.
