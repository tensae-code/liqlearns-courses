# Public cloud and private cloud — multiple choice

Pick the one right answer.

**1.** A public cloud is —
a) resources shared across different clients  b) one owner's locked server only  c) a cloud with no provider  d) a printed network
**Answer: a) resources shared across different clients** — the standard model.

**2.** Renting 10 GB of public cloud gives you —
a) the whole storage device  b) a logically divided, isolated part of a bigger shared device  c) a private data centre  d) nothing until others leave
**Answer: b) a logically divided, isolated part of a bigger shared device**

**3.** A private cloud dedicates —
a) a small corner to everyone  b) all resources to your application  c) its resources to the public  d) nothing
**Answer: b) all resources to your application**

**4.** A private cloud can run —
a) only in your own data centre  b) only with a provider  c) with a provider or in your own company data centre  d) only on paper
**Answer: c) with a provider or in your own company data centre**

**5.** The private cloud's extra protection layer serves —
a) games  b) sensitive, confidential information  c) advertising  d) backups of public files
**Answer: b) sensitive, confidential information**
