# Lesson plan — Machine Learning — computers that learn from data

**Course:** Computer Science and ICT · **Title:** New Technologies · **Lesson:** Machine Learning — computers that learn from data
**Place in the curriculum:** Unit 2 — Emerging Technologies (CURRICULUM.md).
**The one thing this lesson teaches:** Machine Learning studies algorithms that let a computer learn from data and improve itself without being explicitly programmed — it trains on sample data, builds a model, and predicts.
**This lesson's own level:** it stands on the Grade 11 Emerging Technologies unit around it. It needs nothing else.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
This lesson is one whole lesson — it has no sub lessons (a short, single-skill lesson; his ruling 2026-11-09).

## Before this lesson
- Recommended first: the other lessons of this unit. Recommended, never forced.

## What the learner can do when it ends
1. Say what Machine Learning is: learning from data without explicit programming.
2. Give the order: train on sample data → build a model → predict for decisions.
3. Name the four applications: fraud detection, recommendations, spam detection, speech recognition.

## What you need
Paper and a pencil. Nothing else.

## If the learner is stuck
- Thinks the model is written by hand → the model is built by the algorithm from the sample data; that is the whole point. Mixes training with predicting → training uses old examples; predicting uses the finished model on new cases.
