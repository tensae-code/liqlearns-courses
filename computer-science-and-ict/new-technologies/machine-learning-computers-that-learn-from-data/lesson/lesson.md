# Machine Learning — computers that learn from data

## Do it first

Think of learning a song by hearing it many times. Nobody writes the song into you note by note — you learn from examples. Try to say how a computer could learn the same way. Then read.

## Learning instead of fixed instructions

In ordinary programming, a person writes **fixed instructions** and the computer follows them. **Machine Learning** is different: it studies **algorithms that let a computer learn from data and improve itself without being explicitly programmed**.

[Picture 16501 — Machine Learning — data in, predictions out]

## Train, model, predict

The order is always the same. The algorithm **trains on sample data** — many examples. From them it **builds a model** — its own picture of the pattern in the data. Then it **uses that model to make predictions**, and those predictions support **decisions**. More and better sample data makes a better model.

[GIF 16502 — a model getting better as more data flows in]

## Where Machine Learning works

The named applications are **fraud detection** (spotting false bank transactions), **recommendation systems** (suggesting what to watch or buy next), **email spam detection** (sorting junk mail away) and **speech recognition** (turning spoken words into text).
