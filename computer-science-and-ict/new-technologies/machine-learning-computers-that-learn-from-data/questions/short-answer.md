# Machine Learning — computers that learn from data — short answer

Answer in a sentence or two.

**1.** How is Machine Learning different from ordinary programming?
**Answer:** Ordinary programs follow fixed instructions; a learning algorithm learns from data and improves without explicit programming.

**2.** Name two applications and what each predicts.
**Answer:** Any two of: fraud (is this transaction false?), recommendations (what will this user like?), spam (is this mail junk?), speech (what words were spoken?).
