# Machine Learning — computers that learn from data — multiple choice

Pick the one right answer.

**1.** Machine Learning lets a computer —
a) learn from data without being explicitly programmed  b) work without data  c) follow only fixed instructions  d) avoid models
**Answer: a) learn from data without being explicitly programmed**

**2.** First, the algorithm —
a) trains on sample data  b) predicts  c) deletes data  d) prints
**Answer: a) trains on sample data**

**3.** The model is used to —
a) make predictions for decisions  b) store paper  c) replace the screen  d) charge the battery
**Answer: a) make predictions for decisions**

**4.** Which is a Machine Learning application?
a) fraud detection  b) handwriting on paper  c) bicycle repair  d) cooking
**Answer: a) fraud detection**

**5.** Speech recognition —
a) turns spoken words into text  b) prints photos  c) sends letters  d) plays drums
**Answer: a) turns spoken words into text**
