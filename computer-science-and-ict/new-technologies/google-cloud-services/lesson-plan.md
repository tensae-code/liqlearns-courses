## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **What Google Cloud is** — **Google Cloud** (Google Cloud Platform, GCP) rents out the infrastructure Google itself runs on: data centres, a private global network, and services for computing, storage, data and AI. Its characteristics as the book presents them: **data and AI strength** (born from search and YouTube's scale), **a fast private network** between its regions, and **openness** (built around open tools like Kubernetes, which Google created and gave away).
2. **Its services — the working set** — The working set mirrors Azure's with Google's names: **Compute Engine** (rented virtual machines — IaaS), **Cloud Storage** (files in the cloud), **Cloud SQL** (managed databases), **App Engine** (hosting apps without servers — PaaS), and the data/AI shelf — **BigQuery** (analysing huge tables with questions) and Google's machine-learning services. Jordan teaches the two clouds side by side so the pupil learns the pattern, not the brand: every cloud rents the same few ideas under its own names.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
