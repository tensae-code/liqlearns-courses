# Virtual Reality — a fully simulated world — true or false

**1.** VR aims to make artificial information feel almost real to the senses.
**Answer: True**

**2.** In VR the view stays fixed when the wearer turns their head.
**Answer: False** — Sensors adjust the view in real time.
