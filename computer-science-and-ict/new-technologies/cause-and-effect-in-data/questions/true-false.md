# Cause and Effect in Data — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Two measures moving together**
**Answer: True**

**2. (Sub lesson 1) True or false: Two measures moving together** — as the answer to: When does X cause Y?
**Answer: False — If changing X changes Y**

**3. (Sub lesson 1) True or false: A third factor, reverse cause, coincidence**
**Answer: True**

**4. (Sub lesson 1) True or false: A third factor, reverse cause, coincidence** — as the answer to: In the ice-cream example, what drives both?
**Answer: False — The summer sun**

**5. (Sub lesson 1) True or false: What else could move both?**
**Answer: True**

**6. (Sub lesson 2) True or false: What else could move both?** — as the answer to: Name the four honest roads.
**Answer: False — Experiment, mechanism, order and dose, ruling out third factors**

**7. (Sub lesson 2) True or false: Experiment — change only X, hold the rest**
**Answer: True**

**8. (Sub lesson 2) True or false: Experiment — change only X, hold the rest** — as the answer to: What is mechanism?
**Answer: False — A believable chain from X to Y, link by link**

**9. (Sub lesson 2) True or false: Cause first; more cause, more effect**
**Answer: True**

**10. (Sub lesson 2) True or false: Cause first; more cause, more effect** — as the answer to: What words are used until cause is earned?
**Answer: False — 'Is linked to'**
