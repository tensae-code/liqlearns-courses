# IoT Layered Architecture — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A system divided into stacked layers, each with its own job**
**Answer: True**

**2. (Sub lesson 1) True or false: A system divided into stacked layers, each with its own job** — as the answer to: What does each layer do for its neighbours?
**Answer: False — Serves the layer above and uses the layer below**

**3. (Sub lesson 1) True or false: Perception, network, processing, application**
**Answer: True**

**4. (Sub lesson 1) True or false: Perception, network, processing, application** — as the answer to: What can be swapped without rewriting the application?
**Answer: False — A better sensor**

**5. (Sub lesson 1) True or false: Layer by layer**
**Answer: True**

**6. (Sub lesson 2) True or false: Layer by layer** — as the answer to: What does the processing layer do?
**Answer: False — Stores, analyses and decides**

**7. (Sub lesson 2) True or false: Services — the dashboard, the alert, the automatic action**
**Answer: True**

**8. (Sub lesson 2) True or false: Services — the dashboard, the alert, the automatic action** — as the answer to: What sits between layers?
**Answer: False — Interfaces — agreed ways of handing work across**

**9. (Sub lesson 2) True or false: Security and management**
**Answer: True**

**10. (Sub lesson 2) True or false: Security and management** — as the answer to: What does the network layer guarantee?
**Answer: False — Reliable transmission and addressing of the data's journey**
