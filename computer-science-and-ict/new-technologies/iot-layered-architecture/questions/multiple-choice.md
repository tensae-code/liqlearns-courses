# IoT Layered Architecture — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a layered architecture?**
a) A system divided into stacked layers, each with its own job  b) Serves the layer above and uses the layer below  c) Perception, network, processing, application  d) A better sensor
**Answer: a**

**2. (Sub lesson 1) What does each layer do for its neighbours?**
a) Serves the layer above and uses the layer below  b) Perception, network, processing, application  c) A better sensor  d) Layer by layer
**Answer: a**

**3. (Sub lesson 1) Name the four layers from the world up.**
a) Perception, network, processing, application  b) A better sensor  c) Layer by layer  d) Stores, analyses and decides
**Answer: a**

**4. (Sub lesson 1) What can be swapped without rewriting the application?**
a) A better sensor  b) Layer by layer  c) Stores, analyses and decides  d) Services — the dashboard, the alert, the automatic action
**Answer: a**

**5. (Sub lesson 1) How is a fault hunted in a layered system?**

**Answer: a**
