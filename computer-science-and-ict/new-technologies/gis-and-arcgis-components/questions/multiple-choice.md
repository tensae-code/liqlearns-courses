# GIS and ArcGIS — Components — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does GIS stand for?**
a) Geographic information system  b) A computer system for capturing, storing, checking and displaying data about places  c) A location on the earth  d) Layers that can be shown, hidden and queried
**Answer: a) Geographic information system**

**2. (Sub lesson 1) What is a GIS?**
a) A location on the earth  b) A computer system for capturing, storing, checking and displaying data about places  c) Layers that can be shown, hidden and queried  d) S1, S2 and S3
**Answer: b) A computer system for capturing, storing, checking and displaying data about places**

**3. (Sub lesson 1) What is every fact in a GIS tied to?**
a) Layers that can be shown, hidden and queried  b) S1, S2 and S3  c) A location on the earth  d) Geographic information system
**Answer: c) A location on the earth**

**4. (Sub lesson 1) What is a GIS map built of?**
a) S1, S2 and S3  b) Geographic information system  c) A computer system for capturing, storing, checking and displaying data about places  d) Layers that can be shown, hidden and queried
**Answer: d) Layers that can be shown, hidden and queried**

**5. (Sub lesson 1) In which Rwanda years is GIS taught?**
a) S1, S2 and S3  b) Geographic information system  c) A computer system for capturing, storing, checking and displaying data about places  d) A location on the earth
**Answer: a) S1, S2 and S3**

**9. (Sub lesson 2) What does each data layer carry with it?**
