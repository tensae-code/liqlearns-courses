# Components of Cloud Computing — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a data centre?**
a) A building of servers, storage and networking, with power and cooling  b) Slices each physical machine into many virtual ones  c) One server serves many customers in isolation  d) Allocates, monitors and bills
**Answer: a**

**2. (Sub lesson 1) What does virtualisation do?**
a) Slices each physical machine into many virtual ones  b) One server serves many customers in isolation  c) Allocates, monitors and bills  d) The platform software over virtualisation
**Answer: a**

**3. (Sub lesson 1) Why does virtualisation matter?**

**4. (Sub lesson 1) What does the platform software do?**
