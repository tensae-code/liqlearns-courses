# Components of Cloud Computing — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A building of servers, storage and networking, with power and cooling**
**Answer: True**

**2. (Sub lesson 1) True or false: A building of servers, storage and networking, with power and cooling** — as the answer to: What does virtualisation do?
**Answer: False — Slices each physical machine into many virtual ones**

**3. (Sub lesson 1) True or false: One server serves many customers in isolation**
**Answer: True**

**4. (Sub lesson 1) True or false: One server serves many customers in isolation** — as the answer to: What does the platform software do?
**Answer: False — Allocates, monitors and bills**

**5. (Sub lesson 1) True or false: The platform software over virtualisation**
**Answer: True**

**6. (Sub lesson 2) True or false: The platform software over virtualisation** — as the answer to: Name the user-side components.
**Answer: False — Client devices, the internet connection, the services**

**7. (Sub lesson 2) True or false: The internet connection**
**Answer: True**

**8. (Sub lesson 2) True or false: The internet connection** — as the answer to: Name the three service models.
**Answer: False — IaaS, PaaS and SaaS**

**9. (Sub lesson 2) True or false: Every link can fail or be attacked**
**Answer: True**

**10. (Sub lesson 2) True or false: Every link can fail or be attacked** — as the answer to: As what is a cloud exactly as strong?
**Answer: False — As its weakest component**
