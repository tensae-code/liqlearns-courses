# Big data in healthcare and education — true or false

Say true or false.

**1.** Big data helps institutions assess applications and shorten selection.
**Answer: True**

**2.** In healthcare, big data raises cost as one of its aims.
**Answer: False** — It improves cost — spending less while caring better.

**3.** Evidence-based decisions are supported by big data in education.
**Answer: True**
