# Data Characteristics and Cyber Concerns — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Copyable without loss, movable at light speed, persistent, searchable**
**Answer: True**

**2. (Sub lesson 1) True or false: Copyable without loss, movable at light speed, persistent, searchable** — as the answer to: What is theft without an empty shelf?
**Answer: False — A stolen copy that leaves the original sitting still**

**3. (Sub lesson 1) True or false: Copies outlive intentions**
**Answer: True**

**4. (Sub lesson 1) True or false: Copies outlive intentions** — as the answer to: For whom is data searchable?
**Answer: False — For the owner and for the thief alike**

**5. (Sub lesson 1) True or false: At light speed — abroad before an alarm rings**
**Answer: True**

**6. (Sub lesson 2) True or false: At light speed — abroad before an alarm rings** — as the answer to: Name the four main concerns.
**Answer: False — Confidentiality, integrity, availability, privacy**

**7. (Sub lesson 2) True or false: Whether data's use respects the people it describes**
**Answer: True**

**8. (Sub lesson 2) True or false: Whether data's use respects the people it describes** — as the answer to: Name an ethical issue of purpose.
**Answer: False — Data collected for one purpose used for another**

**9. (Sub lesson 2) True or false: People profiled without knowing**
**Answer: True**

**10. (Sub lesson 2) True or false: People profiled without knowing** — as the answer to: Where does Jordan place ethics?
**Answer: False — Inside the security lesson, not after it**
