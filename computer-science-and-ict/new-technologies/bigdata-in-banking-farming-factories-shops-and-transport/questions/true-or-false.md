# Big data in banking, farming, factories, shops and transport — true or false

Say true or false.

**1.** Big data eases banks' compliance, auditing and reporting.
**Answer: True**

**2.** Precision farming ignores rainfall data.
**Answer: False** — Granular rainfall data is at its centre.

**3.** Retail uses big data to personalise experiences, sales and service.
**Answer: True**
