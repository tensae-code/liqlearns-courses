# Types of Data Analysis — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Descriptive — what happened; diagnostic — why; predictive — what will happen; prescriptive — what should we do**
**Answer: True**

**2. (Sub lesson 1) True or false: Descriptive — what happened; diagnostic — why; predictive — what will happen; prescriptive — what should we do** — as the answer to: What does descriptive analysis produce?
**Answer: False — Summaries of the past — totals, averages, charts**

**3. (Sub lesson 1) True or false: Drilling in, comparing groups and periods**
**Answer: True**

**4. (Sub lesson 1) True or false: Drilling in, comparing groups and periods** — as the answer to: Why must description precede diagnosis?
**Answer: False — No prediction stands on an unexplained past**

**5. (Sub lesson 1) True or false: Descriptive and diagnostic**
**Answer: True**

**6. (Sub lesson 2) True or false: Descriptive and diagnostic** — as the answer to: What must predictive analysis state with its outcomes?
**Answer: False — Their uncertainty**

**7. (Sub lesson 2) True or false: Possible actions against predicted outcomes**
**Answer: True**

**8. (Sub lesson 2) True or false: Possible actions against predicted outcomes** — as the answer to: Which type spends all the others?
**Answer: False — Prescriptive**

**9. (Sub lesson 2) True or false: Ambition and risk — worth more, wrong more expensively**
**Answer: True**
