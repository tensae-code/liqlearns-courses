# Hands-on — Web 2.0 and Web 3.0 — Evolution of the Web

The lesson with your hands and your feet, not only your eyes.

## Task one
('Sort the generations', 'List six web activities (reading news, posting a photo, asking a question-answering service, commenting, uploading a video, a program joining your calendar and the weather): place each in Web 1.0, 2.0 or 3.0 and defend the placing.')

## Task two
('Your web, two generations', "Take one place you use: say what in it is Web 2.0 participation, and what a Web 3.0 version of the same place would understand that today's does not.")
