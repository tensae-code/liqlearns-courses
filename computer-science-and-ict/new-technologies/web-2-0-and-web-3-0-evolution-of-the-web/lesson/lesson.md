# Web 2.0 and Web 3.0 — Evolution of the Web

## Do it first

Cuba's Grade 12 networks chapter stops inside its Internet section to name the web's own history — *Evolución de la Web* — because a pupil who only knows today's web mistakes it for the only web there could be.

## Sub lesson 1 — Web 2.0 — the web everyone writes

The first web was read-only: pages published by the few, read by the many. **Web 2.0** turned the reader into an **author**: anyone can publish, comment, upload and share, and the web's biggest places — **social networks**, video and photo platforms, blogs, wikis — are built from what their **users** create. Its mark is participation: the value of a Web 2.0 place is the crowd inside it, not the pages its owners wrote.

## Sub lesson 2 — Web 3.0 — the web that understands

**Web 3.0** names the next turn: pages and data **linked by meaning** — the **semantic** web — so programs can **understand what data says** and work with it: answering questions instead of listing links, joining data from many places into one answer, and acting as agents for their users. Where Web 2.0 connected **people**, Web 3.0 connects **meanings**. Cuba places both generations inside the Grade 12 Internet chapter, next to the social networks that are Web 2.0's own proof.
