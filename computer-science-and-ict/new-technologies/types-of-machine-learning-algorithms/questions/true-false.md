**Answer: True**

**5. (Sub lesson 1) True or false: From reward and punishment, by acting**

**8. (Sub lesson 2) True or false: Clustering — grouping by likeness** — as the answer to: Which algorithm can show its reasons?
**Answer: False — A decision tree**

**9. (Sub lesson 2) True or false: The data's size and shape, the need to explain, the cost of errors**
**Answer: True**

**10. (Sub lesson 2) True or false: The data's size and shape, the need to explain, the cost of errors** — as the answer to: What is the chooser's real question?
