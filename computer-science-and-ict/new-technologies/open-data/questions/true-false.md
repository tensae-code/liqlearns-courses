# Open Data — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Data published so anyone may access, use and share it**
**Answer: True**

**2. (Sub lesson 1) True or false: Free to reach, free to use (reuse licence), machine-readable** — as the answer to: Who typically publishes it?
**Answer: False — Governments and public bodies, about the public world**

**3. (Sub lesson 1) True or false: Free to reach, free to use (reuse licence), machine-readable**
**Answer: True**

**4. (Sub lesson 1) True or false: A publisher's decision — not a property of the data** — as the answer to: Give an example.
**Answer: False — A bus timetable (or budget, weather archive, statistics)**

**5. (Sub lesson 1) True or false: A publisher's decision — not a property of the data**
**Answer: True**

**6. (Sub lesson 2) True or false: The published timetable** — as the answer to: Name a civic use.
**Answer: False — Citizens checking the budget (or services built on it, or research/journalism on inspectable evidence)**

**7. (Sub lesson 2) True or false: The published timetable**
**Answer: True**

**8. (Sub lesson 2) True or false: Aggregated and anonymised** — as the answer to: What must never be opened?
**Answer: False — Personal data**

**9. (Sub lesson 2) True or false: Aggregated and anonymised**
**Answer: True**

**10. (Sub lesson 2) True or false: Data published so anyone may access, use and share it** — as the answer to: Openness stands beside which teaching of the same unit?
**Answer: False — Privacy — one lesson's two hands**
