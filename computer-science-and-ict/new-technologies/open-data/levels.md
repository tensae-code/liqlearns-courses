# Open Data — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — What open data is
Sub lesson 1 questions from the type files. Pass mark: Data published so anyone may access, use and share it; Governments and public bodies, about the public world; Free to reach, free to use (reuse licence), machine-readable; A bus timetable (or budget, weather archive, statistics); A publisher's decision — not a property of the data.

Sub lesson 2 questions from the type files. Pass mark: Citizens checking the budget (or services built on it, or research/journalism on inspectable evidence); The published timetable; Personal data; Aggregated and anonymised; Privacy — one lesson's two hands.
