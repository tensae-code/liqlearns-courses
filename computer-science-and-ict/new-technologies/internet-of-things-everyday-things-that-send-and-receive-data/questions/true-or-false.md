# Internet of Things — everyday things that send and receive data — true or false

Say true or false.

**1.** IoT devices can be controlled remotely across a network.
**Answer: True**

**2.** An animal with a tracking device can count as an IoT thing.
**Answer: True**

**3.** A thing must both send AND receive to be smart, per the book's rule.
**Answer: False** — Send and/or receive — either one is enough.
