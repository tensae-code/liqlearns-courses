# Heuristic Search and Evaluation Functions — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does h(n) estimate?**
a) The cost from node n to the goal  b) Straight-line distance, whatever the roads do  c) Tiles out of place  d) Never overestimating the true cost
**Answer: a**

**2. (Sub lesson 1) Give the route heuristic.**
a) Straight-line distance, whatever the roads do  b) Tiles out of place  c) Never overestimating the true cost  d) By promise — most hopeful first
**Answer: a**

**3. (Sub lesson 1) Give the puzzle heuristic.**
a) Tiles out of place  b) Never overestimating the true cost  c) By promise — most hopeful first  d) Scores a node for expanding
**Answer: a**

**4. (Sub lesson 1) What does admissible mean?**
a) Never overestimating the true cost  b) By promise — most hopeful first  c) Scores a node for expanding  d) The cost already spent, and the heuristic estimate ahead
**Answer: a**
