# My Robot Draws Shapes — true or false

Say whether each statement is true or false.

**1. Program the robot to drive a square: equal steps, equal quarter-turns.**
**Answer: True** — This is one of the lesson's own outcomes.

**2. If a robot shape does not close, the mat must be at fault and the program needs no checking.**
**Answer: False** — The lesson teaches the opposite of this.

**3. Change step-counts deliberately to drive a rectangle.**
**Answer: True** — This is one of the lesson's own outcomes.
