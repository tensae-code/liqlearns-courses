# Fog computing — processing at the edge, near the data

## Do it first

Picture a thousand cameras streaming video to one far-away cloud, all day, every day. The road jams — bandwidth congests, answers crawl back late. Now ask: what if most of that video never needed to travel at all? That question, answered, is fog computing.

## Sub lesson 1 — Fog — the cloud brought closer

**Fog computing extends the cloud.** Because **billions of users sending everything to a central cloud congests bandwidth**, **fog nodes sit closer to the data source, with processing and storage capability**, **deciding what must go to the cloud and what can be analysed locally at the edge**.

So **requests are processed quicker, quality of service improves, latency falls and user experience improves** — with **closer proximity to end users, wider reach and better mobility than cloud**, and **direct device connection without always going through the network backbone**.

[Picture 30117 — fog computing, close to the data]

Fog **supports IoT and real-time big data operations across billions of dynamic nodes**. The worked example is **video surveillance, whose continuous streams are large and cumbersome to transfer** — most of the stream can be judged right where it is filmed.

## Sub lesson 2 — Fog as the intelligent gateway (teacher guide — evidence)

The guide sharpens the picture: fog is a **distributed, decentralised infrastructure where cloud is centralised**. It sits **between hardware and remote servers as an intelligent gateway that decides which data should be sent to the server and which processed locally**, offloading cloud workloads.

It **saves bandwidth by not sending every bit of information over cloud channels, but aggregating it at access points**. Keeping processing local gives **better privacy control** — sensitive data can be analysed locally, with the IT team able to monitor and control the collecting devices — **better data security**, and **faster, more agile business processes**.

[GIF 30129 — the fog gateway sorts the data]

Its named fit is **time-sensitive work: video streaming, self-driving cars, smart grids and smart cities**.
