# Fog computing — processing at the edge, near the data — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Fog computing exists because —
a) the cloud is free  b) billions of users sending everything to a central cloud congests bandwidth  c) cameras are cheap  d) the internet ended
**Answer: b) billions of users sending everything to a central cloud congests bandwidth**

**2. (Sub lesson 1)** Fog nodes sit —
a) in a distant data centre only  b) closer to the data source, with processing and storage capability  c) on paper  d) inside the cloud only
**Answer: b) closer to the data source, with processing and storage capability**

**3. (Sub lesson 1)** A fog node decides —
a) what must go to the cloud and what can be analysed locally at the edge  b) the price of internet  c) which users may connect  d) nothing — it only stores
**Answer: a) what must go to the cloud and what can be analysed locally at the edge**

**4. (Sub lesson 1)** Fog brings —
a) higher latency  b) quicker processing and lower latency  c) slower answers  d) no change
**Answer: b) quicker processing and lower latency**

**5. (Sub lesson 1)** The worked example of a stream too large and cumbersome to transfer is —
a) email  b) video surveillance  c) text messages  d) radio
**Answer: b) video surveillance**

**6. (Sub lesson 2)** Per the guide, fog is distributed and decentralised, where cloud is —
a) centralised  b) printed  c) free  d) local only
**Answer: a) centralised** — Teacher guide — evidence.

**7. (Sub lesson 2)** Per the guide, fog saves bandwidth by —
a) sending every bit twice  b) aggregating data at access points instead of sending every bit  c) closing access points  d) slowing all traffic
**Answer: b) aggregating data at access points instead of sending every bit**

**8. (Sub lesson 2)** Per the guide, fog's named fit is time-sensitive work such as —
a) video streaming, self-driving cars, smart grids and smart cities  b) yearly reports only  c) printed letters  d) stored archives
**Answer: a) video streaming, self-driving cars, smart grids and smart cities**
