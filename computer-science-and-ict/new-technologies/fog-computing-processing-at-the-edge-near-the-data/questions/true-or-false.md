# Fog computing — processing at the edge, near the data — true or false

Say true or false.

**1. (Sub lesson 1)** Fog computing replaces the cloud completely.
**Answer: False** — It extends the cloud; what must travel still travels.

**2. (Sub lesson 1)** Fog supports IoT and real-time big data operations.
**Answer: True**

**3. (Sub lesson 2)** Keeping processing local gives better privacy control, per the guide.
**Answer: True** — Sensitive data can be analysed locally. (Teacher guide — evidence.)
