# Fog computing — processing at the edge, near the data — short answer

Answer in one or two sentences.

**1. (Sub lesson 1)** Why does fog bring processing closer to the data source?
**Answer:** Because billions of users sending everything to a central cloud congests bandwidth; nearby fog nodes process and decide locally, so requests are quicker and latency falls.

**2. (Sub lesson 2)** What does the fog gateway decide, and what does its aggregating save? (Teacher guide — evidence.)
**Answer:** It decides which data is sent to the server and which is processed locally; aggregating at access points saves bandwidth by not sending every bit over cloud channels.
