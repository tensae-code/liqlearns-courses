## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Perception and network — feeling and carrying** — The **perception layer** is the bottom floor: sensors and actuators and the tagged things themselves — everything that touches the physical world. Above it, the **network layer** carries the perception layer's data to where it will be processed, over short-range and long-range links, wired and wireless. These two layers answer the system's first two questions: what is happening out there, and how does the news travel?
2. **Application — where value reaches people** — The top floor is the **application layer**: the services built on the carried data — smart-home control, health monitoring, traffic guidance. Processing lives inside this simple map as part of the journey between network and application. Jordan teaches the three-layer model first because it is the skeleton: every richer architecture — five layers, seven layers — is this skeleton with floors split and named more finely, never a different building.
