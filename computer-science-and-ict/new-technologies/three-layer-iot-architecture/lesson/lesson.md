# The Three-Layer IoT Architecture

## Do it first

The smallest honest map of an IoT system has three floors. This lesson learns that map so well that bigger maps become easy.

## Sub lesson 1 — Perception and network — feeling and carrying

The **perception layer** is the bottom floor: sensors and actuators and the tagged things themselves — everything that touches the physical world. Above it, the **network layer** carries the perception layer's data to where it will be processed, over short-range and long-range links, wired and wireless. These two layers answer the system's first two questions: what is happening out there, and how does the news travel?

## Sub lesson 2 — Application — where value reaches people

The top floor is the **application layer**: the services built on the carried data — smart-home control, health monitoring, traffic guidance. Processing lives inside this simple map as part of the journey between network and application. Jordan teaches the three-layer model first because it is the skeleton: every richer architecture — five layers, seven layers — is this skeleton with floors split and named more finely, never a different building.
