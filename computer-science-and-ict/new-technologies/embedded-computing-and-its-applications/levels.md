# Embedded Computing and Its Applications — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — What embedded computing is
Sub lesson 1 questions from the type files. Pass mark: A computer built inside a device to control that device's one job; It runs its fixed program, not whatever the user invents; A late answer is a wrong answer; Reliability, cost and power; The airbag, which cannot compute after the crash.

## Sub lesson 2 — Applications — the hidden majority
Sub lesson 2 questions from the type files. Pass mark: Most computers live inside devices, not on desks; Dozens; Home appliances, cars, medical devices, industrial robots (or smart cards, lifts, printers); An embedded system that gained sensors and a network; Its body — connectivity is its voice.
