# Embedded Computing and Its Applications — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A computer built inside a device to control that device's one job**
**Answer: True**

**2. (Sub lesson 1) True or false: A computer built inside a device to control that device's one job** — as the answer to: How does it differ from a general computer?
**Answer: False — It runs its fixed program, not whatever the user invents**

**3. (Sub lesson 1) True or false: A late answer is a wrong answer**
**Answer: True**

**4. (Sub lesson 1) True or false: A late answer is a wrong answer** — as the answer to: By what three things are embedded systems judged?
**Answer: False — Reliability, cost and power**

**5. (Sub lesson 1) True or false: The airbag, which cannot compute after the crash**
**Answer: True**

**6. (Sub lesson 2) True or false: The airbag, which cannot compute after the crash** — as the answer to: Why is embedded computing the majority of computing?
**Answer: False — Most computers live inside devices, not on desks**

**7. (Sub lesson 2) True or false: Dozens**
**Answer: True**

**8. (Sub lesson 2) True or false: Dozens** — as the answer to: Name four application areas.
**Answer: False — Home appliances, cars, medical devices, industrial robots (or smart cards, lifts, printers)**

**9. (Sub lesson 2) True or false: An embedded system that gained sensors and a network**
**Answer: True**

**10. (Sub lesson 2) True or false: An embedded system that gained sensors and a network** — as the answer to: What is embedded computing to IoT?
**Answer: False — Its body — connectivity is its voice**
