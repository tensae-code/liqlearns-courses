# Embedded Computing and Its Applications — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What is an embedded system?** → **A computer built inside a device to control that device's one job**

**2. (Sub lesson 1) How does it differ from a general computer?** → **It runs its fixed program, not whatever the user invents**

**3. (Sub lesson 1) What does real time mean here?** → **A late answer is a wrong answer**

**4. (Sub lesson 1) By what three things are embedded systems judged?** → **Reliability, cost and power**

**5. (Sub lesson 1) Give the lesson's real-time example.** → **The airbag, which cannot compute after the crash**

**6. (Sub lesson 2) Why is embedded computing the majority of computing?** → **Most computers live inside devices, not on desks**

**7. (Sub lesson 2) How many embedded controllers can a car hold?** → **Dozens**

**8. (Sub lesson 2) Name four application areas.** → **Home appliances, cars, medical devices, industrial robots (or smart cards, lifts, printers)**

**9. (Sub lesson 2) What is an IoT thing, in this lesson's phrase?** → **An embedded system that gained sensors and a network**

**10. (Sub lesson 2) What is embedded computing to IoT?** → **Its body — connectivity is its voice**
