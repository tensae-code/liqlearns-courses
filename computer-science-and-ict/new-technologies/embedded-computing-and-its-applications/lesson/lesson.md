# Embedded Computing and Its Applications

## Do it first

Your washing machine has a computer in it that will never browse the web, and it is perfectly content. This lesson is the computing that hides inside things.

## Sub lesson 1 — What embedded computing is

An **embedded system** is a computer — processor, memory, inputs and outputs — built **inside a device** to control that device's one job. Unlike a general computer, it is not meant to run whatever its user invents; it runs its fixed program, often in **real time**, where a late answer is a wrong answer — the airbag cannot compute after the crash. Embedded systems are judged by reliability, cost and power more than by raw speed.

## Sub lesson 2 — Applications — the hidden majority

Embedded computing is the **majority of all computing**: washing machines, microwaves, cars (with dozens of embedded controllers), medical devices, industrial robots, smart cards, lifts, printers and the IoT things of this whole unit. Jordan's lesson closes the IoT unit here on purpose: an IoT thing is usually an embedded system that gained sensors and a network — embedded computing is IoT's body, connectivity its voice.
