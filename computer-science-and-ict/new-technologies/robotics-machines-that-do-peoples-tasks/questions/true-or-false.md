# Robotics — machines that do people's tasks — true or false

Say true or false.

**1.** Robots work underwater and in space exploration.
**Answer: True**

**2.** Robots only work in factories.
**Answer: False** — Home work — chores, assisting, vacuuming — is named too.

**3.** A robot vacuum needs a person to steer it every second.
**Answer: False** — It sweeps and cleans on its own.
