## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The basic tasks** — NLP's **basic tasks** stack from small to large: **tokenisation** (cutting text into words and pieces), **part-of-speech tagging** (naming each word's job), **parsing** (finding the sentence's structure), **named-entity recognition** (spotting people, places, dates), and the meaning tasks — **sentiment** (the text's feeling) and **summarisation** (its gist in fewer words). Every application is a composition of these tasks; a failure can be hunted to the task that failed.
2. **Techniques and applications** — The **techniques** grew in generations: **rules** written by hand, **statistics** counted from corpora, and **neural models** learning language's patterns from oceans of text — each generation less brittle, more hungry for data. The **applications**: machine **translation**, **chatbots and assistants**, **search** that understands questions, **spam and sentiment** filters, **text summarisation** and **speech** in both directions. Jordan's Arabic-speaking pupils meet the field's honest footnote here: NLP's riches are unevenly spread across languages, and Arabic's share is a research frontier, not a finished gift.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
