# Lesson plan — Big data challenges — growth, people, security, mixing sources

**Course:** Computer Science and ICT · **Title:** New Technologies · **Lesson:** Big data challenges — growth, people, security, mixing sources
**Place in the curriculum:** Unit 2 — Emerging Technologies (CURRICULUM.md).
**The one thing this lesson teaches:** four challenges stand against big data — managing growth, too few data professionals, security left late, and integrating many sources — and the guide adds the limits of leaning on data too hard.
**This lesson's own level:** it stands on the big-data benefits and applications lessons. It needs nothing else.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved (the gate: README, "Units, Lessons and Sub Lessons (ruled 2026-11-08)"):

1. **The four challenges** — growth that outruns storage, professionals in short supply, security postponed, many sources to integrate — with data quality and validation alongside.
2. **The guide's limits — when data misleads (teacher guide — evidence)** — costly traditional storage, privacy risk, long study before benefits, sometimes-false results, and decisions that lean on data and set judgement aside.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: the other lessons of this unit. Recommended, never forced.

## What the learner can do when it ends
1. Name the four challenges of big data.
2. Say why security gets postponed, and what it costs.
3. State the guide's limits, including the too-heavy-leaning warning.

## What you need
Paper and a pencil. Nothing else.

## If the learner is stuck
- Thinks integration means 'collect everything' → the work is choosing what is MOST relevant; collecting everything wastes time and money. Thinks more data always means better decisions → the guide: results are sometimes false, and judgement set aside makes bad choices.
