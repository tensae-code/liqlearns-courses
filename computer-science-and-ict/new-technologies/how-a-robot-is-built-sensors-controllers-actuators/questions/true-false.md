# How a Robot Is Built — Sensors, Controllers, Actuators — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What do a robot's sensors do?" is: Take in information about its surroundings**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does the controller do?" is: As signals through the robot's circuits**
**Answer: False** — Decides what the robot does with sensor information

**3. (Sub lesson 1) True or false: the answer to "What can a light sensor detect?" is: Light and darkness**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How do instructions travel between a robot's parts?" is: Turn controller decisions into movement and action**
**Answer: False** — As signals through the robot's circuits

**5. (Sub lesson 1) True or false: the answer to "Is a sensor an input part or an output part?" is: An input part**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What do actuators do?" is: Its structure or frame**
**Answer: False** — Turn controller decisions into movement and action

**7. (Sub lesson 2) True or false: the answer to "A motor is which kind of robot part?" is: An actuator**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What holds a robot's parts together?" is: Deciding (control), then acting**
**Answer: False** — Its structure or frame

**9. (Sub lesson 2) True or false: the answer to "What supplies a robot's energy?" is: Its power source, such as a battery**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "In the robot's loop, what comes after sensing?" is: Decides what the robot does with sensor information**
**Answer: False** — Deciding (control), then acting
