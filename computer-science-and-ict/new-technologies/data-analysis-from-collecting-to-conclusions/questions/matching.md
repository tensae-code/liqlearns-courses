# Data Analysis — from Collecting to Conclusions — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) Name the five steps of data analysis, in order.** → **Define the problem, collect, organise, analyse, interpret the results**

**2. (Sub lesson 1) What is defining the problem?** → **Stating the exact question the data must answer, in words a collector could obey**

**3. (Sub lesson 1) How is data collected, in the lesson's terms?** → **By counting, measuring or asking — honestly and completely**

**4. (Sub lesson 1) What does organising do?** → **Puts the data in order — tables, groups, tallies — so it can be read**

**5. (Sub lesson 1) What happens to a vague question's data?** → **It collects useless data**

**6. (Sub lesson 2) What does analysis do?** → **Counts, compares, totals and averages until the question's shape shows**

**7. (Sub lesson 2) What is interpretation?** → **Saying what the analysis means for the problem — the conclusion in the question's own terms**

**8. (Sub lesson 2) What honesty belongs in an interpretation?** → **What the data did not cover**

**9. (Sub lesson 2) Which step do masters check twice, and why?** → **Defining the problem — the last step reaches back to it**
