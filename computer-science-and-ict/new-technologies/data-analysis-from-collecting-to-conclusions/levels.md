# Data Analysis — from Collecting to Conclusions — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — The first steps — define, collect, organise
Sub lesson 1 questions from the type files. Pass mark: Define the problem, collect, organise, analyse, interpret the results; Stating the exact question the data must answer, in words a collector could obey; By counting, measuring or asking — honestly and completely; Puts the data in order — tables, groups, tallies — so it can be read; It collects useless data.

Sub lesson 2 questions from the type files. Pass mark: Counts, compares, totals and averages until the question's shape shows; Saying what the analysis means for the problem — the conclusion in the question's own terms; What the data did not cover; Defining the problem — the last step reaches back to it; Kuwait Grade 5 Digital Explorer Term 2, Unit 1 Lesson 2 — The World of Data.
