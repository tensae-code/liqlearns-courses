# Electronics — Development and Use — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What device stands at the head of the book's electronics road?**
a) Edison's lamp  b) Controlling currents  c) A continuously varying wave copying the world  d) A signal stepping between states — a code standing for the world
**Answer: a) Edison's lamp**

**2. (Sub lesson 1) What act does every electronic device still perform?**
a) A continuously varying wave copying the world  b) Controlling currents  c) A signal stepping between states — a code standing for the world  d) The digital side
**Answer: b) Controlling currents**

**3. (Sub lesson 1) What is an analogue signal?**
a) A signal stepping between states — a code standing for the world  b) The digital side  c) A continuously varying wave copying the world  d) Designs circuits, chooses components, tests signals
**Answer: c) A continuously varying wave copying the world**

**4. (Sub lesson 1) What is a digital signal?**
