# Cloud computing — services over the internet, not on your PC — true or false

Say true or false.

**1. (Sub lesson 1)** Cloud access has no location limit.
**Answer: True**

**2. (Sub lesson 1)** Adobe Creative Cloud and Kindle are named as everyday cloud examples.
**Answer: True**

**3. (Sub lesson 2)** The name 'cloud' was chosen because servers are kept in the sky.
**Answer: False** — It comes from engineers' cloud-shaped network diagrams.
