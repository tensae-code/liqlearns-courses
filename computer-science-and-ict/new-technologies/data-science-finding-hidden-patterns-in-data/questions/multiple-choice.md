# Data Science — finding hidden patterns in data — multiple choice

Pick the one right answer.

**1.** Data Science aims to —
a) discover hidden patterns in data  b) hide data  c) delete patterns  d) print data only
**Answer: a) discover hidden patterns in data**

**2.** Data Science draws on —
a) statistics, mathematics and computer science  b) only geography  c) only art  d) music and sport
**Answer: a) statistics, mathematics and computer science**

**3.** A data scientist turns data into —
a) useful insights  b) paper  c) noise  d) passwords
**Answer: a) useful insights**

**4.** Forecasting product demand helps set —
a) raw-material orders  b) school holidays  c) bus fares  d) exam dates
**Answer: a) raw-material orders**

**5.** Preventive medicine is a use of —
a) data science  b) robotics only  c) VR only  d) spam detection
**Answer: a) data science**
