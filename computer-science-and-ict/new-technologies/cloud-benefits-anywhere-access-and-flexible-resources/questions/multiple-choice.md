# Cloud benefits — anywhere access and flexible resources — multiple choice

Pick the one right answer.

**1.** Cloud tools can be reached —
a) only at the office  b) anywhere, at any time, from any device with an internet connection  c) only on one named computer  d) only during lessons
**Answer: b) anywhere, at any time, from any device with an internet connection**

**2.** If your personal service fails, your cloud data survives because of —
a) luck  b) provider backup  c) a bigger screen  d) a second password
**Answer: b) provider backup**

**3.** Which list names the book's inclusive-education tools?
a) voice recognition, mind mapping, word prediction, text-to-speech  b) spelling bees and dictation only  c) printed books only  d) radios and posters
**Answer: a) voice recognition, mind mapping, word prediction, text-to-speech**

**4.** Shared cloud resources let users —
a) collaborate in real time on the same content  b) work only one at a time  c) never meet  d) print everything
**Answer: a) collaborate in real time on the same content**

**5.** Flexibility means resources can be —
a) never changed  b) restricted or enhanced at any time to meet needs  c) only increased  d) only decreased
**Answer: b) restricted or enhanced at any time to meet needs**
