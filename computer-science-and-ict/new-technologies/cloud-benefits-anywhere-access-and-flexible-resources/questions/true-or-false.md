# Cloud benefits — anywhere access and flexible resources — true or false

Say true or false.

**1.** Cloud users must be physically together to communicate through it.
**Answer: False** — The book's point is the opposite.

**2.** Inclusive education means schools for everybody, with support for learners with special needs.
**Answer: True**

**3.** Data stored and retrieved through the cloud sits on distant servers.
**Answer: True**
