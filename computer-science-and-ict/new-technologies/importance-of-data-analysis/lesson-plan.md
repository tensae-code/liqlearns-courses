## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Decisions with evidence** — Data analysis matters first because it replaces **opinion with evidence** in decisions: a shop stocks what the data shows selling, a school helps the pupils the data shows struggling, a ministry funds what the data shows working. It **finds what eyes miss** — patterns too slow, too large or too tangled for watching: the fault that grows for a year in a factory's numbers before any machine sounds wrong.
2. **Foreseeing, saving, serving** — Beyond seeing: analysis **predicts** (demand next month, risk next season — the forecasting lessons' whole point), **saves** (waste, fraud and failure spotted early are cheaper than late), and **serves** (services shaped to actual use, not imagined use). Jordan's importance lesson is the unit's contract with the pupil: every technique after this page is a way of earning one of these — evidence, foresight, savings, service — and a technique that earns none is a parlour trick.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
