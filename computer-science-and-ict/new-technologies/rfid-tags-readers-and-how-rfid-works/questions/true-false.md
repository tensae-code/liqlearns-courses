# RFID — Tags, Readers and How RFID Works — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The tag, the reader and the application system**
**Answer: True**

**2. (Sub lesson 1) True or false: The tag, the reader and the application system** — as the answer to: What does the tag hold?
**Answer: False — The object's identity data**

**3. (Sub lesson 1) True or false: Sends radio waves and receives the tag's answer**
**Answer: True**

**4. (Sub lesson 1) True or false: Sends radio waves and receives the tag's answer** — as the answer to: What does the application system do?
**Answer: False — Records and uses the identity — stock, entry, payment**

**5. (Sub lesson 1) True or false: Passive tags are powered by the reader's wave; active tags carry a battery**
**Answer: True**

**6. (Sub lesson 2) True or false: Passive tags are powered by the reader's wave; active tags carry a battery** — as the answer to: What happens in the write process?
**Answer: False — Data is stored onto the tag**

**7. (Sub lesson 2) True or false: The reader's radio wave**
**Answer: True**

**8. (Sub lesson 2) True or false: The reader's radio wave** — as the answer to: What does the system do with the tag's reply?
**Answer: False — Matches it against its records and acts**

**9. (Sub lesson 2) True or false: No line of sight needed, and many tags read at once**
**Answer: True**

**10. (Sub lesson 2) True or false: No line of sight needed, and many tags read at once** — as the answer to: Name three places RFID has spread.
**Answer: False — Shops, libraries and roads (or warehouses)**
