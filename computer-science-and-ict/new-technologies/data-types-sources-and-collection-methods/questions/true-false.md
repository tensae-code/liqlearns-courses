# Data Types, Sources and Collection Methods — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Quantitative and qualitative**
**Answer: True**

**2. (Sub lesson 1) True or false: Quantitative and qualitative** — as the answer to: What is a primary source?
**Answer: False — Data you collect yourself, for your question**

**3. (Sub lesson 1) True or false: Fresh, fitted, expensive**
**Answer: True**

**4. (Sub lesson 1) True or false: Fresh, fitted, expensive** — as the answer to: What is a secondary source?
**Answer: False — Data collected by others — records, statistics, tables**

**5. (Sub lesson 1) True or false: Someone else's question and someone else's care**
**Answer: True**

**6. (Sub lesson 2) True or false: Someone else's question and someone else's care** — as the answer to: Name the four primary methods.
**Answer: False — Observation, questionnaires/surveys, interviews, experiments/measurements**

**7. (Sub lesson 2) True or false: Reasons**
**Answer: True**

**8. (Sub lesson 2) True or false: Reasons** — as the answer to: What do surveys trade on?
**Answer: False — Breadth, at the mercy of honest answers**

**9. (Sub lesson 2) True or false: Experiments / measurements**
**Answer: True**

**10. (Sub lesson 2) True or false: Experiments / measurements** — as the answer to: When is the collection plan written?
**Answer: False — Before the collecting**
