# Emerging technologies — new, evolving, soon — true or false

Say true or false.

**1.** An old technology that is still evolving can count as emerging.
**Answer: True**

**2.** A technology expected in fifty years fits this lesson's definition.
**Answer: False** — The window is five to ten years.

**3.** Fog computing was already covered in Grade 11.
**Answer: False** — Grade 11 covered data science, AI, VR and AR.
