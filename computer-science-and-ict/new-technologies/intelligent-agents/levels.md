# Intelligent Agents — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — What an agent is — sense, decide, act
Sub lesson 1 questions from the type files. Pass mark: A program that senses its environment, decides, and acts on its own toward a goal; Sense → decide → act → sense again; Sensors for perceiving; effectors for acting; A simple reflex agent — one condition, one action; Build a picture of their world and improve with experience.

Sub lesson 2 questions from the type files.
