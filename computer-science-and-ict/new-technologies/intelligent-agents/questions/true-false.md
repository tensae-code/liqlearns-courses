# Intelligent Agents — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A program that senses its environment, decides, and acts on its own toward a goal**
**Answer: True**

**2. (Sub lesson 1) True or false: Sensors for perceiving; effectors for acting** — as the answer to: What loop defines an agent?
**Answer: False — Sense → decide → act → sense again**

**3. (Sub lesson 1) True or false: Sensors for perceiving; effectors for acting**
**Answer: True**

**4. (Sub lesson 1) True or false: Build a picture of their world and improve with experience** — as the answer to: Name the simplest kind of agent.
**Answer: False — A simple reflex agent — one condition, one action**

**5. (Sub lesson 1) True or false: Build a picture of their world and improve with experience**
**Answer: True**

**6. (Sub lesson 2) True or false: An agent may carry a neural network as eyes and fuzzy logic as judgement** — as the answer to: Name three agents at work.
**Answer: False — An assistant, a spam filter, and a recommender (also robots, game players)**

**7. (Sub lesson 2) True or false: An agent may carry a neural network as eyes and fuzzy logic as judgement**
**Answer: True**

**8. (Sub lesson 2) True or false: Its makers — the agent is a tool with initiative, not a mind with intentions** — as the answer to: What goal does an agent pursue?
**Answer: False — Only the goal it was given**

**9. (Sub lesson 2) True or false: Its makers — the agent is a tool with initiative, not a mind with intentions**
**Answer: True**
