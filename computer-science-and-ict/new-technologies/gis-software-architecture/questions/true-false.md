# GIS Software Architecture — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What are the two GIS architectures the guide names?" is: Project-oriented and database-oriented**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Where does a project-oriented system keep its data?" is: Project-oriented and database-oriented**
**Answer: False** — In its own files, made for that project

**3. (Sub lesson 1) True or false: the answer to "What is the weakness of project-oriented storage?" is: It is hard to share**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Where does a database-oriented system keep data?" is: Project-oriented and database-oriented**
**Answer: False** — In one shared database

**5. (Sub lesson 1) True or false: the answer to "What is the trend the guide names?" is: From projects toward the shared database**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does RDBMS stand for?" is: Geometry**
**Answer: False** — Relational database management system

**7. (Sub lesson 2) True or false: the answer to "What does the RDBMS hold beside attributes?" is: Geometry**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What do features become in the RDBMS?" is: Relational database management system**
**Answer: False** — Rows, with their facts as columns

**9. (Sub lesson 2) True or false: the answer to "What happens when you query the table?" is: The map answers**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What does the architecture decide, in the lesson's words?" is: Relational database management system**
**Answer: False** — Who can use the data, and whether everyone sees the same truth
