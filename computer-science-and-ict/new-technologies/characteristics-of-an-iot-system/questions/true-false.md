# Characteristics of an IoT System — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Connectivity between its things, gateways and the internet**
**Answer: True**

**2. (Sub lesson 1) True or false: Connectivity between its things, gateways and the internet** — as the answer to: What does device heterogeneity mean?
**Answer: False — The things differ in maker, sensors, protocols and power yet work as one**

**3. (Sub lesson 1) True or false: Standards and gateways**
**Answer: True**

**4. (Sub lesson 1) True or false: Standards and gateways** — as the answer to: Is heterogeneity an exception in IoT?
**Answer: False — No — it is the normal condition**

**5. (Sub lesson 1) True or false: Wired or wireless means**
**Answer: True**

**8. (Sub lesson 2) True or false: Addresses, networks and data handling** — as the answer to: Why is every connected thing called a door?
