# The 5 Vs of big data — multiple choice

Pick the one right answer.

**1.** Volume means —
a) huge amounts generated daily  b) many different forms  c) great speed  d) high trust
**Answer: a) huge amounts generated daily**

**2.** Photos, video and audio are examples of —
a) Volume  b) Variety  c) Veracity  d) Value
**Answer: b) Variety** — the forms data takes.

**3.** Velocity is —
a) how trustworthy data is  b) the speed data is created in real time  c) how much is stored  d) the insight gained
**Answer: b) the speed data is created in real time**

**4.** Veracity asks —
a) how fast is it?  b) how much is there?  c) how reliable and trustworthy is it?  d) what colour is it?
**Answer: c) how reliable and trustworthy is it?**

**5.** Value is measured by —
a) how much is stored  b) how much valuable, reliable data can be analysed for insight  c) how fast it arrives  d) how many forms it takes
**Answer: b) how much valuable, reliable data can be analysed for insight**

**6.** Email and PDFs joined spreadsheets and databases under —
a) Velocity  b) Variety  c) Volume  d) Veracity
**Answer: b) Variety**
