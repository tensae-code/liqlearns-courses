# Big data — and the privacy problem — true or false

Say true or false.

**1.** (Sub lesson 1) A petabyte is a million gigabytes, on the book's scale.
**Answer: True**

**2.** (Sub lesson 2) Privacy becomes contentious because uses rest on collecting masses of user data.
**Answer: True**

**3.** (Sub lesson 2) Anonymisation and generalisation increase the insight data gives.
**Answer: False** — Both limit the insight that can be drawn — that is the tension.
