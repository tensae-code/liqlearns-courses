# Big data — too massive for ordinary tools — true or false

Say true or false.

**1. (Sub lesson 1)** Typical processing software can handle big data without difficulty.
**Answer: False** — Handling it is exactly what ordinary tools cannot do.

**2. (Sub lesson 2)** Social-media posts and smartphone location data are sources of big data.
**Answer: True**

**3. (Sub lesson 2)** The pipeline is built before any sources are identified.
**Answer: False** — Sources are identified first.
