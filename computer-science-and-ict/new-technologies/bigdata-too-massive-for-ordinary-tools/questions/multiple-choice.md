# Big data — too massive for ordinary tools — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Big data is data that —
a) ordinary database tools cannot handle  b) fits in one spreadsheet  c) is written on paper  d) nobody collects
**Answer: a) ordinary database tools cannot handle**

**2. (Sub lesson 1)** Big data was born of —
a) the printing press  b) the explosion of data since the digital age  c) a single company's records  d) handwritten surveys only
**Answer: b) the explosion of data since the digital age**

**3. (Sub lesson 1)** Which three convert the real world into digital data?
a) pens, paper, files  b) computers, the internet, sensors  c) radios, letters, posters  d) roads, markets, farms
**Answer: b) computers, the internet, sensors**

**4. (Sub lesson 2)** Point-of-sale data comes from —
a) surveys  b) the till — business transactions  c) phone location  d) weather sensors
**Answer: b) the till — business transactions**

**5. (Sub lesson 2)** The first step of collecting big data is to —
a) buy a bigger computer  b) delete old data  c) identify useful sources  d) build the store
**Answer: c) identify useful sources**

**6. (Sub lesson 2)** A pipeline moves data —
a) from generation to where it is stored for use  b) from paper to a drawer  c) from one phone to another only  d) backwards in time
**Answer: a) from generation to where it is stored for use**

**7. (Sub lesson 2)** Google's worked example reads —
a) only emails  b) search history, location and trends  c) only photographs  d) exam results
**Answer: b) search history, location and trends** — to understand what users want.
