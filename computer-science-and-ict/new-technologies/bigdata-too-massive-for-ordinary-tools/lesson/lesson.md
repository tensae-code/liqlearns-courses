# Big data — too massive for ordinary tools

## Do it first

Think of every sale in every shop, every social-media post, every photo and every phone movement in one city, in one day. Could an ordinary database or a normal spreadsheet handle it? No. That breaking point is where this lesson starts.

## Sub lesson 1 — What big data is — and where it comes from

**Big data** is a **collection of data sources so massive and complex that typical processing software and ordinary database tools cannot handle them**.

It was born of the **explosion of data since the digital age**: **computers, the internet and sensors convert the real world into digital data** — every day, in amounts no ordinary tool was built for.

## Sub lesson 2 — Sources — and the pipeline

The sources include **business transactional data (point-of-sale — the till)**, **IoT endpoint devices**, **marketing firms**, **social-media posts**, **smartphone location data** and **surveys**.

[Picture 30101 — big data sources and pipeline]

Collecting it is a two-step process: **first identify useful sources**, then **build a pipeline that moves the data from where it is generated to where the organisation stores it for use**.

[GIF 30126 — data flowing through the pipeline]

The worked example: **Google reads search history, location and trends to understand what its users want** — sources identified, data pipelined, then used.
