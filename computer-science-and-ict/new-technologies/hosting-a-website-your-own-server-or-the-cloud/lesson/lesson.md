# Hosting a website — your own server or the cloud?

## Do it first

You have built a website. It sits on your school computer, and nobody else on Earth can see it. List everything standing between that file and the whole world reading it: a machine that never sleeps, an address, systems, services. Now read the two roads to 'website live' — and count what each one costs in money and time.

## The old way — your own server

To publish a website the old way, you **buy a physical server, house it, get a public IP address, and install an operating system and web services yourself** — **much money and time** spent before the site is public at all.

## The cloud way — a button, and minutes

With a **cloud hosting service** you **borrow the server capacity cheaply**, the **provider manages the operating system and web services**, you **press a button to upload your content**, and **the site is public in minutes, for much less**.
