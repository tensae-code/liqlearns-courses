# Video script — Hosting a website — your own server or the cloud?

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

You built a website. Nobody can see it. How does it go live?

THE OLD WAY. Step one: buy a physical server. It costs much money.

Step two: house it. It needs a place, power, care.

Step three: get a public IP address — the address the world finds you by.

Step four: install the operating system yourself. Install the web services yourself.

Only then — after much money and much time — is your site public.

Now THE CLOUD WAY. You borrow the server capacity. Cheaply.

The provider manages the operating system. The provider manages the web services.

You press a button. Your content uploads.

Minutes later, your site is public. For much less.

Two roads. Same website. One road builds a server room. The other presses a button.

That is cloud hosting.
