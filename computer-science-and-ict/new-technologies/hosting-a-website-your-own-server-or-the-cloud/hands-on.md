# Hands-on — Hosting a website — your own server or the cloud?

The lesson with your hands and your feet, not only your eyes.

## Cost the two roads
On paper, cost the old way honestly: a server, a room or shelf, power for a year, an address, your own hours installing and maintaining. Then cost cloud hosting for the same site for a year. Put the two totals side by side and write the difference in one sentence.

## The button test
If a free website builder or school hosting is available to you, publish one harmless page — a poem, a club notice — and time the whole journey from finished file to a link someone else can open. Write down each step you actually took.
