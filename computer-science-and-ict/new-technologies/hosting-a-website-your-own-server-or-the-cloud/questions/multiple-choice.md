# Hosting a website — your own server or the cloud? — multiple choice

Pick the one right answer.

**1.** In the old way, the first thing you do is —
a) press a button  b) buy a physical server  c) borrow capacity  d) write the homepage
**Answer: b) buy a physical server**

**2.** A public IP address is needed in the old way so —
a) the site can be found publicly  b) the server stays cool  c) the screen is brighter  d) files print faster
**Answer: a) the site can be found publicly**

**3.** In the old way, the operating system and web services are installed by —
a) the provider  b) you yourself  c) the visitors  d) nobody — they come free
**Answer: b) you yourself**

**4.** In cloud hosting, the provider manages —
a) your content writing  b) the operating system and web services  c) your visitors  d) your school timetable
**Answer: b) the operating system and web services**

**5.** With cloud hosting the site is public —
a) after months of building  b) in minutes, for much less  c) only after buying a server  d) never
**Answer: b) in minutes, for much less**

**6.** The comparison makes visible at once —
a) every cloud benefit  b) only the price of servers  c) how to write HTML  d) how to draw logos
**Answer: a) every cloud benefit**
