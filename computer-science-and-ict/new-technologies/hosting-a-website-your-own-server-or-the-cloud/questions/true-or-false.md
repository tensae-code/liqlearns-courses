# Hosting a website — your own server or the cloud? — true or false

Say true or false.

**1.** The old way costs much money and time before the site is public.
**Answer: True**

**2.** In cloud hosting you borrow the server capacity cheaply.
**Answer: True**

**3.** In the old way, the provider installs everything for you.
**Answer: False** — You install the operating system and web services yourself.
