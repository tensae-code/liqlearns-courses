# Hosting a website — your own server or the cloud? — short answer

Answer in one or two sentences.

**1.** Walk the old way in order.
**Answer:** Buy a physical server; house it; get a public IP address; install an operating system and web services yourself.

**2.** Walk the cloud way in order.
**Answer:** Borrow the server capacity cheaply; the provider manages the operating system and web services; press a button to upload your content; the site is public in minutes.
