# Data Visualisation Tools

## Do it first

The spreadsheet draws a chart in three clicks; the programming library draws it in ten lines; the BI tool draws it live. This lesson learns the tool shelf for drawing data.

## Sub lesson 1 — The tool shelf

Jordan's shelf: **spreadsheet charts** (Excel's — instant, familiar, limited in kinds and polish), **programming libraries** (Python's plotting — any chart, repeatable and automatable, at the price of code), **dedicated/BI tools** (dashboards drawing live from data, shareable to non-analysts), and **online chart makers** (quick, pretty, shallow). The tools divide by the same trade as analysis tools: speed against control, once against repeated, mine against the audience's hands.

## Sub lesson 2 — Choosing the drawing tool

Choosing weighs: **the data's size and liveness** (a dashboard fed hourly expels the hand-made chart), **the chart's rarity** (an unusual form needs the library's freedom), **repeatability** (monthly pictures want code), **the audience** (a minister's dashboard against an analyst's figure), and **honesty controls** (can this tool be made to start the axis at zero and label honestly — the last lesson's rules, enforced or fought by the tool itself). The tool is chosen last in the design and first in the timetable's complaints; Jordan teaches the choosing so the complaints have somewhere better to go.
