# Data Visualisation Tools — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Spreadsheet charts, programming libraries, dedicated/BI tools, online chart makers**
**Answer: True**

**2. (Sub lesson 1) True or false: Spreadsheet charts, programming libraries, dedicated/BI tools, online chart makers** — as the answer to: What are spreadsheet charts?
**Answer: False — Instant, familiar, limited in kinds and polish**

**3. (Sub lesson 1) True or false: Code — for any chart, repeatable and automatable**
**Answer: True**

**4. (Sub lesson 1) True or false: Code — for any chart, repeatable and automatable** — as the answer to: What do BI tools draw?

**5. (Sub lesson 1) True or false: Speed against control, once against repeated, mine against the audience's**

**8. (Sub lesson 2) True or false: Data fed hourly — liveness** — as the answer to: What needs the library's freedom?

**9. (Sub lesson 2) True or false: Code — repeatability**
