# Data Visualisation Tools — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) Name the four tools on the shelf.**
**Answer: Spreadsheet charts, programming libraries, dedicated/BI tools, online chart makers**

**2. (Sub lesson 1) What are spreadsheet charts?**
**Answer: Instant, familiar, limited in kinds and polish**

**3. (Sub lesson 1) What do programming libraries cost and give?**
**Answer: Code — for any chart, repeatable and automatable**

**4. (Sub lesson 1) What do BI tools draw?**
**Answer: Live dashboards from data, shareable to non-analysts**

**5. (Sub lesson 1) By what trade do the tools divide?**
**Answer: Speed against control, once against repeated, mine against the audience's**

**6. (Sub lesson 2) Name the five grounds of choice.**
**Answer: Size and liveness, the chart's rarity, repeatability, audience, honesty controls**

**7. (Sub lesson 2) What expels the hand-made chart?**
**Answer: Data fed hourly — liveness**

**8. (Sub lesson 2) What needs the library's freedom?**
**Answer: An unusual chart form**

**9. (Sub lesson 2) What do monthly pictures want?**
**Answer: Code — repeatability**

**10. (Sub lesson 2) What honesty controls must a tool allow?**
**Answer: Honest axes and labels — the rules enforced, not fought**
