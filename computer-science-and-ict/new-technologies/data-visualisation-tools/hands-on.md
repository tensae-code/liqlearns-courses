# Hands-on — Data Visualisation Tools

The lesson with your hands and your feet, not only your eyes.

## Task one
**Tool for the job** — Choose drawing tools for three jobs (a class poster, a ministry dashboard, a research figure) and name each choice's price.

## Task two
**Same data, two tools** — Draw one dataset in a spreadsheet and on paper-as-code-planned; compare what each tool made easy and what it fought.
