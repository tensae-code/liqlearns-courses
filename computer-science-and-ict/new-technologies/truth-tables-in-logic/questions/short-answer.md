# Truth Tables in Logic — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does a truth table list?**
**Answer: Every combination of the parts' truths**

**2. (Sub lesson 1) How many rows for n propositions?**
**Answer: 2ⁿ rows**

**3. (Sub lesson 1) When is AND true?**
**Answer: Only when both parts are true**

**4. (Sub lesson 1) When is OR false?**
**Answer: Only when both parts are false**

**5. (Sub lesson 1) How many rows do three propositions make?**
**Answer: Eight**

**6. (Sub lesson 2) When are two statements equivalent?**
**Answer: When their table columns are identical**

**7. (Sub lesson 2) How does a table prove an argument valid?**
**Answer: Premises-true rows always give a true conclusion**

**8. (Sub lesson 2) What is a tautology?**
**Answer: A statement true in every row — true by shape alone**

**9. (Sub lesson 2) Why are tables in the AI unit?**
**Answer: Machine reasoning stands on conclusions a table can certify**

**10. (Sub lesson 2) What is a table, in the lesson's phrase?**
**Answer: Logic's multiplication table — finite, checkable, beyond dispute**
