# Truth Tables in Logic — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Every combination of the parts' truths**
**Answer: True**

**2. (Sub lesson 1) True or false: Every combination of the parts' truths** — as the answer to: How many rows for n propositions?
**Answer: False — 2ⁿ rows**

**3. (Sub lesson 1) True or false: Only when both parts are true**
**Answer: True**

**4. (Sub lesson 1) True or false: Only when both parts are true** — as the answer to: When is OR false?
**Answer: False — Only when both parts are false**

**5. (Sub lesson 1) True or false: Eight**
**Answer: True**

**6. (Sub lesson 2) True or false: Eight** — as the answer to: When are two statements equivalent?
**Answer: False — When their table columns are identical**

**7. (Sub lesson 2) True or false: Premises-true rows always give a true conclusion**
**Answer: True**

**8. (Sub lesson 2) True or false: Premises-true rows always give a true conclusion** — as the answer to: What is a tautology?
**Answer: False — A statement true in every row — true by shape alone**

**9. (Sub lesson 2) True or false: Machine reasoning stands on conclusions a table can certify**
**Answer: True**

**10. (Sub lesson 2) True or false: Machine reasoning stands on conclusions a table can certify** — as the answer to: What is a table, in the lesson's phrase?
**Answer: False — Logic's multiplication table — finite, checkable, beyond dispute**
