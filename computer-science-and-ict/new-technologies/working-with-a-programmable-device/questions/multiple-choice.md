# Working with a Programmable Device — multiple choice

Pick the one right answer.

**1. A programmable device is —**
a) a real machine that acts on a program of commands  b) a picture of a robot  c) a program with no machine
**Answer: a) a real machine that acts on a program of commands**

**2. When the device's action is wrong, you correct —**
a) the device, by pushing it  b) the floor  c) the program
**Answer: c) the program**

**3. Commands must be entered —**
a) backwards  b) in order  c) in any order at all
**Answer: b) in order**

**4. This lesson prepares for —**
a) programming the Blue-Bot robot  b) typing lessons  c) the sound gallery
**Answer: a) programming the Blue-Bot robot**
