# Working with a Programmable Device — true or false

Say whether each statement is true or false.

**1. Say what a programmable device is.**
**Answer: True** — This is one of the lesson's own outcomes.

**2. If a programmable device does the wrong thing, the device itself is usually at fault.**
**Answer: False** — The lesson teaches the opposite of this.

**3. Give a device a short program of commands in order.**
**Answer: True** — This is one of the lesson's own outcomes.
