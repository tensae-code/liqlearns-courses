# Working with a Programmable Device — short answer

Answer in a sentence or two.

**1. Explain, in your own words: say what a programmable device is.**
**Answer:** The learner's own explanation, true to the lesson: A programmable device is a real machine that does what a program tells it: give it commands in order, and it acts in the real world — not on a screen.

**2. A classmate gets this lesson's work wrong. What is the most likely fault, and how is it fixed?**
**Answer:** Device does the wrong thing → it did what it was told: read the entered commands back one by one and find the command that says the wrong action.
