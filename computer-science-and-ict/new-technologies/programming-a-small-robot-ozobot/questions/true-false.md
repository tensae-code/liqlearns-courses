# Programming a Small Robot — Ozobot — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A small robot — sensors and wheels in a palm-sized dome — that follows lines and obeys colour codes**
**Answer: True**

**2. (Sub lesson 1) True or false: A small robot — sensors and wheels in a palm-sized dome — that follows lines and obeys colour codes** — as the answer to: What comes before programming, in the book's order?
**Answer: False — Care (perawatan), then calibration (kalibrasi)**

**3. (Sub lesson 1) True or false: This paper's white and this line's black — so its light sensor reads truly here**
**Answer: True**

**4. (Sub lesson 1) True or false: This paper's white and this line's black — so its light sensor reads truly here** — as the answer to: An uncalibrated robot does not disobey; it does what?
**Answer: False — It misreads**

**5. (Sub lesson 1) True or false: Drawn colour codes on a line it follows**
**Answer: True**

**6. (Sub lesson 2) True or false: Drawn colour codes on a line it follows** — as the answer to: What is a colour code?
**Answer: False — A short sequence of coloured segments laid across the line — a command**

**7. (Sub lesson 2) True or false: Direction at crossings, and speed**
**Answer: True**

**8. (Sub lesson 2) True or false: Direction at crossings, and speed** — as the answer to: What is programming, in this medium?
**Answer: False — Drawing the right code at the right place on the track**

**9. (Sub lesson 2) True or false: By watching where the robot's reading and the drawer's intention part**
**Answer: True**

**10. (Sub lesson 2) True or false: By watching where the robot's reading and the drawer's intention part** — as the answer to: Where does Indonesia teach this?
**Answer: False — Grade 8, Bab 3 F — introducing the Ozobot robot**
