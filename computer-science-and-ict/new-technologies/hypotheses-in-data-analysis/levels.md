# Hypotheses in Data Analysis — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — What a hypothesis is
Sub lesson 1 questions from the type files. Pass mark: A clear, testable statement made before the test; Falsifiable and specific; Population, measure and direction; 'No difference' — the sceptical default; Not a hypothesis — a decoration.

## Sub lesson 2 — Testing — data as judge
Sub lesson 2 questions from the type files. Pass mark: Could this difference be chance?; The smaller the chance-explanation; The data supports, or fails to support; Samples vary; one test is one witness; Question, hypothesis, test, honest verdict.
