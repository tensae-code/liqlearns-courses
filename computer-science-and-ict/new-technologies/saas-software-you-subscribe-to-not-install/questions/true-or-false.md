# SaaS — software you subscribe to, not install — true or false

Say true or false.

**1. (Sub lesson 1)** SaaS carries tasks such as accounting, sales, invoicing and planning.
**Answer: True**

**2. (Sub lesson 1)** With SaaS you buy the software upfront and install it yourself.
**Answer: False** — You subscribe; the vendor hosts.

**3. (Sub lesson 2)** Google Classroom and virtual-meeting applications are cloud services pupils already use, per the guide.
**Answer: True** — Teacher guide — evidence.
