# SaaS — software you subscribe to, not install — short answer

Answer in one or two sentences.

**1. (Sub lesson 1)** Define SaaS in one sentence.
**Answer:** A distribution model where a vendor hosts applications and makes them available to customers over a network or the internet, subscribed to monthly or yearly instead of bought upfront and installed.

**2. (Sub lesson 2)** State the chief benefit of each service model, per the guide.
**Answer:** SaaS: ease — only a browser and connection needed, provider manages all technical issues, automatic updates. PaaS: developer productivity — faster development and more frequent releases. IaaS: flexibility — the most flexible and dynamic model, pay-as-you-go, automated hardware deployment.
