# Lesson plan — SaaS — software you subscribe to, not install

**Course:** Computer Science and ICT · **Title:** New Technologies · **Lesson:** SaaS — software you subscribe to, not install
**Place in the curriculum:** Unit 2 — Emerging Technologies (CURRICULUM.md).
**The one thing this lesson teaches:** SaaS is software a vendor hosts and you use over the internet by subscription — and the guide compares all three service models by the benefit each one buys.
**This lesson's own level:** it stands on the cloud doorway and the four cloud types. It needs nothing else.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved (the gate: README, "Units, Lessons and Sub Lessons (ruled 2026-11-08)"):

1. **SaaS — hosted software by subscription** — the vendor hosts the application; you subscribe monthly or yearly instead of buying and installing; it works on any internet-enabled device; the tasks and examples.
2. **The three models compared by benefit (teacher guide — evidence)** — SaaS: just a browser, provider manages everything, automatic updates; PaaS: developer productivity; IaaS: flexibility, pay-as-you-go, automated hardware — plus the cloud services pupils already use.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: the other lessons of this unit. Recommended, never forced.

## What the learner can do when it ends
1. Define SaaS and its subscription shape.
2. Name SaaS examples and the tasks it carries.
3. State each service model's chief benefit (teacher guide — evidence).
4. Name cloud services pupils already use (teacher guide — evidence).

## What you need
Paper and a pencil. Nothing else.

## The run of the lesson (in order)
1. **Do it first** — Think of software you use that you never installed and do not own — it simply opens in a browser and works. Who keeps it running? That arrangement has a name. (lesson/lesson.md).
2. **The explanation** — the parts below, in order (lesson/lesson.md).
   - ADD IMAGE [Picture 30114]: a picture of an application window streamed from a host to many devices, with a subscription ticket — the student traces the stream from host to devices and says what the ticket replaces (buying and installing).

5. **Hands-on** — hands-on.md.

## If the learner is stuck
- Mixes SaaS with buying software → the SaaS mark is the subscription and the vendor's hosting: nothing bought upfront, nothing installed. Mixes the models' benefits → SaaS = ease, PaaS = developer speed, IaaS = flexibility.
