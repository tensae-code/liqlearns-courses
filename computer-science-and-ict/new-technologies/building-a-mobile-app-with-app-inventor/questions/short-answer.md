# Building a Mobile App with App Inventor — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is the Designer?**
**Answer: Where the app's screen is built from components on a phone-shaped canvas**

**2. (Sub lesson 1) Name components.**
**Answer: Buttons, labels, text boxes, images (any three)**

**3. (Sub lesson 1) What else is dragged in?**
**Answer: Invisible workers — sensors, storage, sounds**

**4. (Sub lesson 1) What is set on each component?**
**Answer: Its properties — text, size, colour, name**

**5. (Sub lesson 1) Which unit teaches it?**
**Answer: Greece Grade 9 Pliroforiki C, Unit 4**

**6. (Sub lesson 2) What is the Blocks Editor?**
**Answer: Where the components' behaviour is programmed with blocks**

**7. (Sub lesson 2) Blocks are snapped into what?**
**Answer: Event handlers — when this is clicked, when that sensor shakes**

**8. (Sub lesson 2) Which old habits are spent here?**
**Answer: Scratch's — sequence, selection, variables**

**9. (Sub lesson 2) Where is the app run?**
**Answer: On a real device, or its emulator**

**10. (Sub lesson 2) An application is an interface and a what?**
**Answer: A behaviour**
