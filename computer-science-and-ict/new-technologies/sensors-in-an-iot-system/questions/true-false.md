# Sensors in an IoT System — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Measures a property of the world and turns it into data**
**Answer: True**

**2. (Sub lesson 1) True or false: Measures a property of the world and turns it into data** — as the answer to: Name four things sensors measure.
**Answer: False — Temperature, light, movement and pressure (or moisture)**

**3. (Sub lesson 1) True or false: The perception layer**
**Answer: True**

**4. (Sub lesson 1) True or false: The perception layer** — as the answer to: Why does the book place sensors before networks?
**Answer: False — Bad sensing cannot be repaired by good transmitting**

**5. (Sub lesson 1) True or false: Its first fact**
**Answer: True**

**6. (Sub lesson 2) True or false: Its first fact** — as the answer to: What does a gateway collect?
**Answer: False — Readings from many nearby sensors**

**7. (Sub lesson 2) True or false: First processing and translation between protocols**
**Answer: True**

**8. (Sub lesson 2) True or false: First processing and translation between protocols** — as the answer to: Between what and what does a gateway translate?
**Answer: False — The sensors' short-range protocols and the internet's**

**9. (Sub lesson 2) True or false: A guard post where local traffic is checked**
**Answer: True**

**10. (Sub lesson 2) True or false: A guard post where local traffic is checked** — as the answer to: What can one gateway serve?
