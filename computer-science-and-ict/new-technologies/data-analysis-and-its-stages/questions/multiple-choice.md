# Data Analysis and Its Stages — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is data analysis?**
a) Turning data into findings to discover patterns, answer questions and support decisions  b) Its destination — a decision or an answer — not its tools  c) A notebook, a spreadsheet, Python  d) One stage, done properly
**Answer: a**

**2. (Sub lesson 1) By what is analysis defined?**
a) Its destination — a decision or an answer — not its tools  b) A notebook, a spreadsheet, Python  c) One stage, done properly  d) Inspecting, cleaning, transforming, modelling
**Answer: a**

**3. (Sub lesson 1) Name three tools the same stages run in.**
a) A notebook, a spreadsheet, Python  b) One stage, done properly  c) Inspecting, cleaning, transforming, modelling  d) Define the question, collect, clean and prepare, explore and analyse, present and interpret, decide and act
