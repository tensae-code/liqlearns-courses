# Microsoft Azure Cloud Services — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Microsoft's cloud platform — data centres worldwide offering rented services**
**Answer: True**

**2. (Sub lesson 1) True or false: Microsoft's cloud platform — data centres worldwide offering rented services** — as the answer to: How is Azure paid for?
**Answer: False — By use, through a web portal**

**3. (Sub lesson 1) True or false: Breadth, hybrid strength, enterprise trust**
**Answer: True**

**4. (Sub lesson 1) True or false: Breadth, hybrid strength, enterprise trust** — as the answer to: What does hybrid strength mean?
**Answer: False — Joining an organisation's own servers to the cloud**

**5. (Sub lesson 1) True or false: Microsoft's Windows world**
**Answer: True**

**6. (Sub lesson 2) True or false: Microsoft's Windows world** — as the answer to: What is an Azure virtual machine?
**Answer: False — A rented computer in the cloud**

**7. (Sub lesson 2) True or false: A managed database service**
**Answer: True**

**8. (Sub lesson 2) True or false: A managed database service** — as the answer to: What does App Service do?
**Answer: False — Hosts websites and apps without managing servers**

**9. (Sub lesson 2) True or false: Accounts and sign-in for an organisation**
**Answer: True**

**10. (Sub lesson 2) True or false: Accounts and sign-in for an organisation** — as the answer to: Match VM and App Service to models.
**Answer: False — The VM is IaaS; App Service is PaaS**
