# Hands-on — Microsoft Azure Cloud Services

The lesson with your hands and your feet, not only your eyes.

## Task one
**Service sort** — Sort eight jobs (host the school site, store backups, run a database…) to the Azure service that fits each.

## Task two
**Model hunt** — Find one IaaS, one PaaS and one SaaS offering in Azure's catalogue and write the evidence for each label.
