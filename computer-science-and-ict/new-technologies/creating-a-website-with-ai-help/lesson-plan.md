## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **What the AI does — draft, suggest, generate** — Used as the book directs, AI help in website building does three jobs: it **drafts** (a first version of text or code from a description), it **suggests** (layouts, colour schemes, page structures to choose among), and it **generates** (the repetitive parts — another page in the same pattern, a list in the same format). Each job hands the pupil a **starting point, not a finish**: the draft must be read, the suggestion judged against the design principles — audience, navigation, consistency, simplicity, accessibility — and the generated part checked in the browser like any other code. The pupil's prompt is the steering: the clearer the description of audience and purpose, the closer the draft lands.
2. **What the pupil still owns — judgement and responsibility** — The unit's order is its argument: because the class has already designed a site, formatted pages and built the school project **unaided**, it can now tell a good AI suggestion from a glossy bad one. What AI help never takes is **responsibility**: the site's facts must be true (AI drafts invent confidently), its pages must work (AI code fails silently), and its design must serve its real audience — checks only the maker can run. Egypt pairs this lesson with its AI-and-intellectual-property teaching elsewhere in the course for the same reason: help is welcome, authorship is not transferable, and a website with your school's name on it is yours.
