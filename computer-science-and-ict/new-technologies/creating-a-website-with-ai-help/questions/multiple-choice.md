# Creating a Website with AI Help — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What three jobs does AI help do in website building?**
a) It drafts, suggests and generates  b) A starting point, not a finish  c) The design principles — audience, navigation, consistency, simplicity, accessibility  d) Checked in the browser like any other code
**Answer: a) It drafts, suggests and generates**

**2. (Sub lesson 1) What does each AI job hand the pupil?**
a) The design principles — audience, navigation, consistency, simplicity, accessibility  b) A starting point, not a finish  c) Checked in the browser like any other code  d) The pupil's prompt — the clearer the description, the closer the draft
**Answer: b) A starting point, not a finish**

**3. (Sub lesson 1) Against what is an AI layout suggestion judged?**
