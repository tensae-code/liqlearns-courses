# Creating a Website with AI Help — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What three jobs does AI help do in website building?" is: It drafts, suggests and generates**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does each AI job hand the pupil?" is: The design principles — audience, navigation, consistency, simplicity, accessibility**
**Answer: False** — A starting point, not a finish

**3. (Sub lesson 1) True or false: the answer to "Against what is an AI layout suggestion judged?" is: The design principles — audience, navigation, consistency, simplicity, accessibility**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How must generated code be treated?" is: The pupil's prompt — the clearer the description, the closer the draft**
**Answer: False** — Checked in the browser like any other code

**5. (Sub lesson 1) True or false: the answer to "What steers the AI's draft?" is: The pupil's prompt — the clearer the description, the closer the draft**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Why does Egypt teach this after the unaided school project?" is: Responsibility for the finished site**
**Answer: False** — Only a pupil who has built by hand can tell a good AI suggestion from a glossy bad one

**7. (Sub lesson 2) True or false: the answer to "What does AI help never take?" is: Responsibility for the finished site**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Name two checks only the maker can run?" is: They invent confidently**
**Answer: False** — That the site's facts are true, and that its pages actually work (also: that the design serves its real audience)

**9. (Sub lesson 2) True or false: the answer to "How do AI drafts fail on facts?" is: They invent confidently**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "How does AI code fail?" is: It drafts, suggests and generates**
**Answer: False** — Silently — it must be run to be believed
