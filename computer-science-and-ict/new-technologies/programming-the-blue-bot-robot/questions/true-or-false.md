# Programming the Blue-Bot Robot — true or false

Say whether each statement is true or false.

**1. Name the Blue-Bot movement commands and what each does.**
**Answer: True** — This is one of the lesson's own outcomes.

**2. Blue-Bot steps are the same length as a child's steps, so routes can be planned in human strides.**
**Answer: False** — The lesson teaches the opposite of this.

**3. Plan a route in robot steps and quarter-turns, and enter it.**
**Answer: True** — This is one of the lesson's own outcomes.
