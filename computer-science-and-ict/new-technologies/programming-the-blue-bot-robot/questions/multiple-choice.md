# Programming the Blue-Bot Robot — multiple choice

Pick the one right answer.

**1. Blue-Bot is shaped like —**
a) a bee  b) a cat  c) a car
**Answer: a) a bee**

**2. Before entering a new route you must —**
a) add more commands  b) turn the robot off and on ten times  c) clear the old program
**Answer: c) clear the old program**

**3. The robot turns in —**
a) full spins only  b) quarter-turns  c) tiny random angles
**Answer: b) quarter-turns**

**4. A Blue-Bot route must be planned in —**
a) robot steps, not human strides  b) metres  c) minutes
**Answer: a) robot steps, not human strides**
