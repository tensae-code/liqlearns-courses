# Programming the Blue-Bot Robot — short answer

Answer in a sentence or two.

**1. Explain, in your own words: name the Blue-Bot movement commands and what each does.**
**Answer:** The learner's own explanation, true to the lesson: The Blue-Bot is a bee-shaped floor robot: you program it with its buttons — forward, back, turns, go — or in its control environment, and it drives the route your commands describe.

**2. A classmate gets this lesson's work wrong. What is the most likely fault, and how is it fixed?**
**Answer:** Robot drives a route you did not plan → the old program was never cleared: press clear, re-enter only today's commands, and count the steps aloud as it runs.
