# Propositional Logic and Predicate Logic — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Propositional logic — whole statements, joined
Sub lesson 1 questions from the type files. Pass mark: A whole statement that is true or false; AND, OR, NOT, IF–THEN; Computed from its parts' truths; What is inside statements; 'All birds fly' and 'some birds fly' are unrelated atoms to it.

## Sub lesson 2 — Predicate logic — inside the statement
Sub lesson 2 questions from the type files. Pass mark: Things about objects — Bird(x), Flies(x); All (∀) or some (∃); ∀x (Bird(x) → Flies(x)); Predicate logic; Propositional is simpler and decidable; predicate is expressive but costs more to reason with.
