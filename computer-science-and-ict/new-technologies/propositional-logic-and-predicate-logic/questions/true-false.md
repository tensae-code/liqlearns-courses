# Propositional Logic and Predicate Logic — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A whole statement that is true or false**
**Answer: True**

**2. (Sub lesson 1) True or false: A whole statement that is true or false** — as the answer to: Name the four connectives.
**Answer: False — AND, OR, NOT, IF–THEN**

**3. (Sub lesson 1) True or false: Computed from its parts' truths**
**Answer: True**

**4. (Sub lesson 1) True or false: Computed from its parts' truths** — as the answer to: What is propositional logic blind to?
**Answer: False — What is inside statements**

**5. (Sub lesson 1) True or false: 'All birds fly' and 'some birds fly' are unrelated atoms to it**
**Answer: True**

**6. (Sub lesson 2) True or false: 'All birds fly' and 'some birds fly' are unrelated atoms to it** — as the answer to: What do predicates say?
**Answer: False — Things about objects — Bird(x), Flies(x)**

**7. (Sub lesson 2) True or false: All (∀) or some (∃)**
**Answer: True**

**8. (Sub lesson 2) True or false: All (∀) or some (∃)** — as the answer to: Write 'all birds fly' in predicate form.
**Answer: False — ∀x (Bird(x) → Flies(x))**

**9. (Sub lesson 2) True or false: Predicate logic**
**Answer: True**

**10. (Sub lesson 2) True or false: Predicate logic** — as the answer to: What is the closing trade?
**Answer: False — Propositional is simpler and decidable; predicate is expressive but costs more to reason with**
