# Prompt Design — Writing Instructions for Generative AI — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The instruction given to a generative AI**
**Answer: True**

**2. (Sub lesson 1) True or false: The AI continues the pattern the prompt establishes — literally** — as the answer to: What four things does a designed prompt say?
**Answer: False — What is wanted, for whom, in what form, and with what limits**

**3. (Sub lesson 1) True or false: The AI continues the pattern the prompt establishes — literally**
**Answer: True**

**4. (Sub lesson 1) True or false: The prompt's report card** — as the answer to: Name three working moves of prompt design.
**Answer: False — Be specific where it matters; give an example; ask in steps (also: revise and re-ask)**

**5. (Sub lesson 1) True or false: The prompt's report card**
**Answer: True**

**6. (Sub lesson 2) True or false: Operating a generative system well is part of knowing what it is** — as the answer to: What do you do after reading it?
**Answer: False — Change the instruction and ask again**

**7. (Sub lesson 2) True or false: Operating a generative system well is part of knowing what it is**
**Answer: True**

**8. (Sub lesson 2) True or false: Where variation is welcome** — as the answer to: Give an output shape a prompt may demand.

**9. (Sub lesson 2) True or false: Where variation is welcome**
