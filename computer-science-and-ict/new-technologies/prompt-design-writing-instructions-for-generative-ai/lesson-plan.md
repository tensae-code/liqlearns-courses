## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **A prompt is an instruction, and it is designed** — A **prompt** is the instruction given to a generative AI — and like every instruction, it can be vague or **designed**. A designed prompt says **what** is wanted, **for whom**, **in what form**, and with **what limits**: the topic and its treatment, the audience and their level, the output's shape (a list, a paragraph, a table, code), and the boundaries (length, style, what to avoid). The unit teaches design because the AI's pattern-following is literal: it continues the pattern the prompt establishes, so the prompt's quality is the output's ceiling.
2. **Better prompts, better output — the working moves** — The skills are a craftsman's set: be **specific** where the result matters and loose where variation is welcome; give an **example** of the wanted thing when words about it fail; ask in **steps** when the task is a journey; and **revise** — read the output as the prompt's report card, change the instruction, and ask again. Kuwait places prompt design inside the AI unit, not the writing unit, because it is a technology skill: operating a generative system well is part of knowing what it is.
