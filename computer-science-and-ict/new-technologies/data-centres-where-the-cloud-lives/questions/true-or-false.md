# Data Centres — Where the Cloud Lives — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) The cloud’s data is stored in the sky, not in any particular building.**
**Answer: False — Every cloud service runs in data centres: real buildings, with addresses, guards and electricity meters.**

**2. (Sub lesson 2) Cooling a data centre can consume a large share of energy on top of what the servers themselves use.**
**Answer: True — The heat of computation must be removed by machines that also draw power; the bill is running plus cooling.**
