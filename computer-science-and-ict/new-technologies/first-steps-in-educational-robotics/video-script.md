# Video script — First Steps in Educational Robotics

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A robot is a machine.

It senses. It decides. It acts.

It does what its program says. Nothing more.

So write the steps. In order. Exact.

Run it. Watch what it really does.

Wrong? Change one step. Run it again.

Plan. Run. Watch. Fix.

That is your first step in robotics.
