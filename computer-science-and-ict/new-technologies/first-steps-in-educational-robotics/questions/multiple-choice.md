# First Steps in Educational Robotics — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) A robot's work has three parts. They are —**
a) Read, write, count  b) Sense, decide, act  c) Open, close, save
**Answer: b) Sense, decide, act** — The robot senses the world, decides from its program, and acts in the real world.

**2. (Sub lesson 1) A robot follows —**
a) What you meant  b) What the goal is  c) Exactly the instructions it was given
**Answer: c) Exactly the instructions it was given** — A robot does what it is told, never what you meant.

**3. (Sub lesson 2) After running a robot program, the next step is to —**
a) Watch what the robot really did  b) Write a longer program at once  c) Blame the robot
**Answer: a) Watch what the robot really did** — The run-watch-fix circle starts from what really happened.

**4. (Sub lesson 2) When a robot program goes wrong, you should change —**
a) Everything at once  b) One thing in the instructions, then run again  c) The robot
**Answer: b) One thing in the instructions, then run again** — One change at a time shows which change fixed it.
