# First Steps in Educational Robotics — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) A robot can guess steps that its program leaves out.**
**Answer: False** — A robot follows its instructions exactly; it cannot guess.

**2. (Sub lesson 1) A robot's program moves a real machine in a real room.**
**Answer: True** — Unlike a screen program, its results happen in the real world.

**3. (Sub lesson 2) The order of the steps in a robot program does not matter.**
**Answer: False** — The steps must be exact and in the right order; a turn before the move is a different program.

**4. (Sub lesson 2) Watching what the robot really did is part of programming it.**
**Answer: True** — Run, watch, fix is the circle that finishes every robot program.
