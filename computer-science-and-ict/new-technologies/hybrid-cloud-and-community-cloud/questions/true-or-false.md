# Hybrid cloud and community cloud — true or false

Say true or false.

**1.** Government institutions, healthcare and financial services use community clouds.
**Answer: True**

**2.** In a hybrid cloud, public services run in the private cloud.
**Answer: False** — Public services run in the public cloud; confidential services in the private.

**3.** A community cloud is a collaborative multi-tenant platform.
**Answer: True**
