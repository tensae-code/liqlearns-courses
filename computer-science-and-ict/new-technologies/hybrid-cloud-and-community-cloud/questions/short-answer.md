# Hybrid cloud and community cloud — short answer

Answer in one or two sentences.

**1.** Define hybrid cloud in one sentence.
**Answer:** A combination of public and private cloud — public services in the public cloud, confidential and data services in the private cloud — gaining both models' flexibility.

**2.** Who shares a community cloud, and why can they share?
**Answer:** Several distinct organisations in the same industry, because they share the same applications and the same security, compliance and performance concerns.
