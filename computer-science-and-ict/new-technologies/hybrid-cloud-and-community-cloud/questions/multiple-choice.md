# Hybrid cloud and community cloud — multiple choice

Pick the one right answer.

**1.** A hybrid cloud combines —
a) two public clouds  b) public and private cloud  c) cloud and paper files  d) two providers' bills
**Answer: b) public and private cloud**

**2.** In a hybrid cloud, confidential and data services sit in —
a) the public cloud  b) the private cloud  c) a flash disk  d) no cloud
**Answer: b) the private cloud**

**3.** A hybrid cloud gains —
a) both models' flexibility  b) free storage forever  c) no limitations  d) faster internet
**Answer: a) both models' flexibility**

**4.** A community cloud is shared by —
a) one person  b) several distinct organisations in the same industry  c) random strangers  d) one family
**Answer: b) several distinct organisations in the same industry**

**5.** Community-cloud organisations share concerns about —
a) security, compliance and performance  b) office colours  c) lunch menus  d) holidays
**Answer: a) security, compliance and performance**

**6.** The book describes a community cloud as —
a) a privately managed platform that functions much like a public cloud  b) a single laptop  c) a public notice board  d) an unshared server
**Answer: a) a privately managed platform that functions much like a public cloud**
