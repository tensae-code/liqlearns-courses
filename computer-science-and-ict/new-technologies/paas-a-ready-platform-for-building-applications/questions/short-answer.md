# PaaS — a ready platform for building applications — short answer

Answer in one or two sentences.

**1.** Define PaaS in one sentence.
**Answer:** A service that provides a platform and environment for developers to build applications and services, hosted in the cloud and reached over the internet.

**2.** Tell SaaS from PaaS in one line each.
**Answer:** SaaS hands you a finished application to use by subscription. PaaS hands you a ready platform on which to build your own application.
