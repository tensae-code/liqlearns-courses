# Hands-on — Charts in Python — Line, Bar and Pie

The lesson with your hands and your feet, not only your eyes.

## Task one
**Three charts, one table** — Draw one dataset three ways in Python or by hand; write which question each chart answers and which it betrays.

## Task two
**Pattern reading** — Take any published chart; state its pattern, check one number, and name one rival explanation of its shape.
