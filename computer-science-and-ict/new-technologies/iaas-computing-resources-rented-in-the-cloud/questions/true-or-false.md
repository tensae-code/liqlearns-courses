# IaaS — computing resources rented in the cloud — true or false

Say true or false.

**1.** In IaaS the environment is virtualised — 'the cloud'.
**Answer: True**

**2.** IaaS forces every small business to buy its own servers.
**Answer: False** — Renting the resources instead is the whole point.

**3.** Microsoft Azure appears among the book's IaaS examples.
**Answer: True**
