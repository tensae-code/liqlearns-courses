# IaaS — computing resources rented in the cloud — short answer

Answer in one or two sentences.

**1.** Define IaaS in one sentence.
**Answer:** A service providing access to computing resources in a virtualised environment — the cloud — over the internet.

**2.** Tell the three service models apart in one line each.
**Answer:** SaaS: finished applications by subscription. PaaS: a ready platform for building applications. IaaS: the computing resources themselves — servers, storage, networks — rented virtually.
