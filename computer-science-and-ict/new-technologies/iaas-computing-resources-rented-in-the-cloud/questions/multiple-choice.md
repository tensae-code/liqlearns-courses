# IaaS — computing resources rented in the cloud — multiple choice

Pick the one right answer.

**1.** IaaS provides access to —
a) computing resources in a virtualised environment over the internet  b) finished office software  c) printed reports  d) physical servers delivered to your door
**Answer: a) computing resources in a virtualised environment over the internet**

**2.** IaaS is described as —
a) a complete computing package  b) a single small app  c) a paper form  d) a training course
**Answer: a) a complete computing package**

**3.** IaaS is one solution for small businesses —
a) hiring more staff  b) cutting IT infrastructure costs  c) buying bigger offices  d) printing adverts
**Answer: b) cutting IT infrastructure costs**

**4.** IaaS stands alongside which model as fundamental?
a) SaaS only  b) PaaS  c) email  d) hosting only
**Answer: b) PaaS**

**5.** Which list is all IaaS examples from the book?
a) Amazon Web Services, Cisco Metapod, Microsoft Azure, Google Compute Engine  b) Slack, Concur, Dropbox, GoToMeeting  c) Heroku, Force.com, OpenShift, Stratos  d) Gmail, Maps, Netflix, Spotify
**Answer: a) Amazon Web Services, Cisco Metapod, Microsoft Azure, Google Compute Engine**

**6.** The resources in IaaS are reached —
a) over the internet  b) by delivery truck  c) on paper  d) by radio
**Answer: a) over the internet**
