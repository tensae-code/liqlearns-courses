# Hands-on — Programming a Robot in a Virtual Environment

The lesson with your hands and your feet, not only your eyes.

## Task one
**First drive** — In any simulator or on paper, write the program that drives a robot in a square and back to its start, with distances and turns.

## Task two
**Sensor guard** — Add sensing to your square: stop if a wall is within reach. Write the condition in words, then in blocks or code.
