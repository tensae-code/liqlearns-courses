# Video script — Programming a Robot in a Virtual Environment

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A **virtual robotics simulator** is a program that imitates a robot and its world: the robot's body and sensors behave by the same rules as the real machine's, inside a **playground** — the practice ground with its floors, lines, walls and objects. The pupil writes a program, runs it, and watches the virtual robot obey or fail exactly as a real one would — the failure is the teaching, and here it is free, instant and repeatable.
The basics follow the course's programming pattern in robot form: **movement commands** (forward, turn, stop — with distances and angles), **sensing** (the program asks the virtual sensors: is there a wall? a line? how far?), and **control** (sequences, loops for repeated moves, conditions for sensor-guided choices). Jordan teaches the virtual before the physical on purpose: every pupil has a robot, no robot can be broken, and the program that works here is the same program a real robot runs — the playground is a promise the hardware keeps.
