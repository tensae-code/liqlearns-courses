# Programming a Robot in a Virtual Environment — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — The virtual environment — simulator and playground
Sub lesson 1 questions from the type files. Pass mark: A robot and its world, by the same rules as the real machine's; The practice ground — floors, lines, walls and objects; The failure — free, instant and repeatable; As the real machine's do; The virtual robot obey or fail.

Sub lesson 2 questions from the type files. Pass mark: Movement commands, sensing, control; Distances and angles; Is there a wall? a line? how far?; Every pupil has a robot, and no robot can be broken; The program that works here is the one a real robot runs.
