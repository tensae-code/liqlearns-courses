# The ArcMap Interface — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What draws the layers in ArcMap?**
a) The map display in the centre  b) The layers in drawing order  c) Shows or hides the layer  d) Above the map display
**Answer: a) The map display in the centre**

**2. (Sub lesson 1) What does the table of contents list?**
a) Shows or hides the layer  b) The layers in drawing order  c) Above the map display  d) So every later instruction can point to a part
**Answer: b) The layers in drawing order**

**3. (Sub lesson 1) What does a layer's tick box do?**
a) Above the map display  b) So every later instruction can point to a part  c) Shows or hides the layer  d) The map display in the centre
**Answer: c) Shows or hides the layer**

**4. (Sub lesson 1) Where are the menu bar and toolbars?**
a) So every later instruction can point to a part  b) The map display in the centre  c) The layers in drawing order  d) Above the map display
**Answer: d) Above the map display**

**5. (Sub lesson 1) Why does the book name the parts first?**
a) So every later instruction can point to a part  b) The map display in the centre  c) The layers in drawing order  d) Shows or hides the layer
**Answer: a) So every later instruction can point to a part**

**6. (Sub lesson 2) Which layer sits on top of the drawing?**
a) Drag a layer in the table of contents  b) The top layer in the table of contents  c) Untick its tick box  d) Select it by clicking its name
**Answer: b) The top layer in the table of contents**

**7. (Sub lesson 2) How do you change the drawing order?**
a) Untick its tick box  b) Select it by clicking its name  c) Drag a layer in the table of contents  d) Because controlling it means controlling the map
**Answer: c) Drag a layer in the table of contents**

**8. (Sub lesson 2) How do you hide a layer without removing it?**
a) Select it by clicking its name  b) Because controlling it means controlling the map  c) The top layer in the table of contents  d) Untick its tick box
**Answer: d) Untick its tick box**

**9. (Sub lesson 2) How do you make tools act on one layer?**
a) Select it by clicking its name  b) Because controlling it means controlling the map  c) The top layer in the table of contents  d) Drag a layer in the table of contents
**Answer: a) Select it by clicking its name**

**10. (Sub lesson 2) Why does Rwanda's walkthrough start with the table of contents?**
a) The top layer in the table of contents  b) Because controlling it means controlling the map  c) Drag a layer in the table of contents  d) Untick its tick box
**Answer: b) Because controlling it means controlling the map**
