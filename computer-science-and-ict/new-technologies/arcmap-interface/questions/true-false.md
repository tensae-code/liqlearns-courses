# The ArcMap Interface — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What draws the layers in ArcMap?" is: The map display in the centre**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does the table of contents list?" is: The map display in the centre**
**Answer: False** — The layers in drawing order

**3. (Sub lesson 1) True or false: the answer to "What does a layer's tick box do?" is: Shows or hides the layer**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Where are the menu bar and toolbars?" is: The map display in the centre**
**Answer: False** — Above the map display

**5. (Sub lesson 1) True or false: the answer to "Why does the book name the parts first?" is: So every later instruction can point to a part**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Which layer sits on top of the drawing?" is: Drag a layer in the table of contents**
**Answer: False** — The top layer in the table of contents

**7. (Sub lesson 2) True or false: the answer to "How do you change the drawing order?" is: Drag a layer in the table of contents**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How do you hide a layer without removing it?" is: The top layer in the table of contents**
**Answer: False** — Untick its tick box

**9. (Sub lesson 2) True or false: the answer to "How do you make tools act on one layer?" is: Select it by clicking its name**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why does Rwanda's walkthrough start with the table of contents?" is: The top layer in the table of contents**
**Answer: False** — Because controlling it means controlling the map
