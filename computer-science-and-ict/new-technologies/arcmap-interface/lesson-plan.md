## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The parts of the ArcMap window** — The **ArcMap window** divides into named parts. The **map display** in the centre draws the layers. The **table of contents** at the left lists the layers in drawing order, each with its **tick box** (shown or hidden) and its **symbol**. Above sit the **menu bar** and **toolbars** — the standard tools for opening, saving and printing, and the tools toolbar for working on the map itself. Naming the parts first means every later instruction can point.
2. **Table of contents — the map's control list** — The **table of contents** is more than a list: the **top layer draws last and sits on top**, so order is meaning — labels and towns above the land they name. Dragging a layer changes the drawing order; the tick box **switches a layer without removing it**; clicking a layer's name **selects** it so tools act on it. Rwanda's S1 walkthrough starts here because a learner who controls the table of contents controls the map.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
