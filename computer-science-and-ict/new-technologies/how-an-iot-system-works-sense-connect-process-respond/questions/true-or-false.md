# How an IoT system works — sense, connect, process, respond — true or false

Say true or false.

**1.** The four components run in the order: sense, connect, process, respond.
**Answer: True**

**2.** Humidity, smoke and water quality are sensor types.
**Answer: True**

**3.** The user must always act personally at the final step — the system can never act itself.
**Answer: False** — It can act automatically by predefined rules.
