# How an IoT system works — sense, connect, process, respond — short answer

Answer in one or two sentences.

**1.** Name the four components of an IoT system, in order.
**Answer:** Sensors/devices collect data; connectivity sends it to the cloud; data processing checks it; the user interface makes it useful through alerts and responses.

**2.** Give one simple and one complex example of data processing.
**Answer:** Simple: checking a temperature is within limits. Complex: computer vision spotting intruders on video.
