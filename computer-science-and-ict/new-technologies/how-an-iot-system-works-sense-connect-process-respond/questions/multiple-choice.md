# How an IoT system works — sense, connect, process, respond — multiple choice

Pick the one right answer.

**1.** The first component of an IoT system is —
a) data processing  b) sensors/devices collecting data from the environment  c) the user interface  d) an alert
**Answer: b) sensors/devices collecting data from the environment**

**2.** A phone is a device with many sensors, including —
a) camera and accelerometer  b) a till and a scanner  c) a keyboard only  d) a printer
**Answer: a) camera and accelerometer**

**3.** Connectivity sends data to the cloud by —
a) cellular, satellite, Wi-Fi, Bluetooth or Ethernet  b) post and hand delivery  c) printed reports  d) radio announcements only
**Answer: a) cellular, satellite, Wi-Fi, Bluetooth or Ethernet** — chosen for the application.

**4.** Checking that a temperature is within limits is —
a) complex processing  b) simple processing  c) no processing  d) the user interface
**Answer: b) simple processing**

**5.** Computer vision spotting intruders on video is —
a) simple processing  b) complex processing  c) connectivity  d) a sensor type
**Answer: b) complex processing**

**6.** At the user-interface step, the information becomes useful through —
a) an alert by email, text or notification  b) a printed book  c) a louder sensor  d) a bigger battery
**Answer: a) an alert by email, text or notification**

**7.** When the system acts automatically, it acts by —
a) asking every user first  b) predefined rules  c) chance  d) the weather
**Answer: b) predefined rules** — even notifying authorities about an intruder.
