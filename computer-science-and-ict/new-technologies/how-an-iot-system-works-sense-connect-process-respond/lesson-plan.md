# Lesson plan — How an IoT system works — sense, connect, process, respond

**Course:** Computer Science and ICT · **Title:** New Technologies · **Lesson:** How an IoT system works — sense, connect, process, respond
**Place in the curriculum:** Unit 2 — Emerging Technologies (CURRICULUM.md).
**The one thing this lesson teaches:** a complete IoT system runs four components in order: sensors collect, connectivity carries, software processes, and the user interface responds — by alert, by your action, or by the system's own rules.
**This lesson's own level:** it stands on the IoT doorway and advantages lessons. It needs nothing else. This is a doing-lesson: you will walk a reading through all four steps yourself.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons

## Before this lesson

## What the learner can do when it ends
1. Name the four components in order.
2. Name sensor types and connection kinds.
3. Tell simple from complex processing, with examples.
4. Say how a response happens: user action, or automatic rules.

## What you need
Paper and a pencil. Nothing else.

## If the learner is stuck
- Drops the processing step → raw data is not yet useful; software must CHECK it before any interface can respond. Thinks the user must always act → the system can act by itself, by predefined rules — the intruder example notifies authorities directly.
