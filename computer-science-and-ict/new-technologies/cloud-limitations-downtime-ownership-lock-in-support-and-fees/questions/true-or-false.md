# Cloud limitations — downtime, ownership, lock-in, support and fees — true or false

Say true or false.

**1.** No provider guarantees no interruption.
**Answer: True**

**2.** Saving on on-site infrastructure guarantees the cloud will be cheap overall.
**Answer: False** — Unknown fees can still make it costly.

**3.** Whether the provider's handling of your data is open is part of the ownership and transparency limitation.
**Answer: True**
