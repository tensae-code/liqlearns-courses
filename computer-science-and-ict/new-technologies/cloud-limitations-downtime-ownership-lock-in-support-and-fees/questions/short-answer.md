# Cloud limitations — downtime, ownership, lock-in, support and fees — short answer

Answer in one or two sentences.

**1.** Name the six limitations of cloud computing.
**Answer:** Server downtime; security and privacy risk; data ownership and transparency; inflexibility; lack of support; cost (unknown fees).

**2.** Why does downtime hit cloud users twice?
**Answer:** No provider guarantees no interruption, and the service also depends on the user's internet connection — if the connection goes down, so does the service.
