# Data Security in Cloud Computing — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Encryption, access control, backup and replication, monitoring**
**Answer: True**

**2. (Sub lesson 1) True or false: Encryption, access control, backup and replication, monitoring** — as the answer to: What does encryption at rest protect against?
**Answer: False — Stolen disks yielding only noise**

**3. (Sub lesson 1) True or false: Accounts, permissions, multi-factor sign-in**
**Answer: True**

**4. (Sub lesson 1) True or false: Accounts, permissions, multi-factor sign-in** — as the answer to: Against what do copies in other buildings guard?
**Answer: False — Fire and failure**

**5. (Sub lesson 1) True or false: The intruder's footsteps in the logs**
**Answer: True**

**6. (Sub lesson 2) True or false: The intruder's footsteps in the logs** — as the answer to: What does the provider secure?
**Answer: False — The cloud itself — buildings, machines, platform soundness**

**7. (Sub lesson 2) True or false: What they put in the cloud — accounts, permissions, classification, habits**
**Answer: True**

**8. (Sub lesson 2) True or false: What they put in the cloud — accounts, permissions, classification, habits** — as the answer to: Name three customer-half breaches.
**Answer: False — A public bucket, a phished password, a permission given to everyone**

**9. (Sub lesson 2) True or false: Blaming the provider for the customer's half**
**Answer: True**

**10. (Sub lesson 2) True or false: Blaming the provider for the customer's half** — as the answer to: Who switches much of the machinery on?
**Answer: False — The customer**
