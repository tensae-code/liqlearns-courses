# Data Security in Cloud Computing — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Name the four protections.**
a) Encryption, access control, backup and replication, monitoring  b) Stolen disks yielding only noise  c) Accounts, permissions, multi-factor sign-in  d) Fire and failure
**Answer: a**

**2. (Sub lesson 1) What does encryption at rest protect against?**
a) Stolen disks yielding only noise  b) Accounts, permissions, multi-factor sign-in  c) Fire and failure  d) The intruder's footsteps in the logs
**Answer: a**

**3. (Sub lesson 1) What three things does access control hold?**
a) Accounts, permissions, multi-factor sign-in  b) Fire and failure  c) The intruder's footsteps in the logs  d) The cloud itself — buildings, machines, platform soundness
**Answer: a**
