# Virtual Representation of the Real World — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What is a virtual representation?** → **A digital stand-in — the real thing captured as data inside the computer**

**2. (Sub lesson 1) What does a representation keep, and what does it drop?** → **It keeps the features the task needs and drops the rest**

**3. (Sub lesson 1) How does a map represent a town?** → **By keeping roads (and dropping, for example, individual trees)**

**4. (Sub lesson 1) Why is representation called a bridge?** → **Every program crosses it — the computer can only work with the representation, never the thing itself**

**5. (Sub lesson 1) Where does Armenia's Grade 7 book place this idea?** → **At the opening (1.2), and again when Python begins (6.2 'The real becomes virtual')**

**6. (Sub lesson 2) When is a representation good?** → **When it is faithful where it matters for its task**

**7. (Sub lesson 2) What may a flight simulator simplify, and what must it keep exact?** → **It may simplify the clouds; it must represent the controls exactly**

**8. (Sub lesson 2) Why do representations age?** → **The real thing changes — an un-updated representation quietly becomes wrong**

**9. (Sub lesson 2) What three questions should a user ask of a screen?** → **What does this stand for? What did it leave out? When was it last true?**

**10. (Sub lesson 2) Give an example of a representation in school life.** → **The class register represents the class — names and attendance kept, everything else dropped**
