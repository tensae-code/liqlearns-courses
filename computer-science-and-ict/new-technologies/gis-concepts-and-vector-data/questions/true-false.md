# GIS Concepts and Vector Data — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a feature in GIS?" is: One real thing on the map — a school, a road, a lake**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What are features grouped into?" is: One real thing on the map — a school, a road, a lake**
**Answer: False** — Layers, by kind

**3. (Sub lesson 1) True or false: the answer to "What are attributes?" is: Facts about a feature, kept in the attribute table**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does the map's scale tie together?" is: One real thing on the map — a school, a road, a lake**
**Answer: False** — Map distance and ground distance

**5. (Sub lesson 1) True or false: the answer to "Name the five key words of the lesson." is: Feature, layer, attribute, scale, location**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What are the three kinds of vector data?" is: A place with no size at map scale — a school, a borehole**
**Answer: False** — Points, lines and polygons

**7. (Sub lesson 2) True or false: the answer to "What does a point mark?" is: A place with no size at map scale — a school, a borehole**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does a line follow?" is: Points, lines and polygons**
**Answer: False** — A path — a road, a river

**9. (Sub lesson 2) True or false: the answer to "What does a polygon close?" is: A boundary around an area — a district, a lake, a parcel**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "How can the same village be two shapes?" is: Points, lines and polygons**
**Answer: False** — A point on a national map, a polygon on a district map
