# The Artificial Neuron — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) A negative weight means the input votes against the neuron firing.**
**Answer: True** — Negative weights subtract from the sum — evidence against.

**2. (Sub lesson 1) A neuron with a weight of exactly zero on an input is influenced by that input.**
**Answer: False** — Zero weight multiplies the input away — the neuron ignores that line.

**3. (Sub lesson 2) Smoother activation functions are preferred in real networks because tiny weight changes then change the output a little.**
**Answer: True** — Graded outputs make learning steadier than a hard step alone.

**4. (Sub lesson 2) One artificial neuron can, by itself, recognise faces.**
**Answer: False** — One neuron makes one tiny judgement; face recognition needs networks of many neurons, the next lesson.
