# Neural Networks — Many Neurons Together — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) In a neural network, hidden layers are —**
a) Decorative  b) Layers between input and output whose neurons judge features  c) The output  d) Turned off
**Answer: b) Layers between input and output whose neurons judge features** — Hidden = neither fed directly by the world nor read directly by it.

**2. (Sub lesson 1) For a photograph recogniser, the input layer receives —**
a) The photograph itself  b) One number per pixel  c) The answer  d) Ten digits
**Answer: b) One number per pixel** — The network sees numbers; the picture exists only at the ends.

**3. (Sub lesson 1) The system's answer is read from the output layer as —**
a) The first neuron  b) The output neuron that fires strongest  c) The sum of all layers  d) The input pattern
**Answer: b) The output neuron that fires strongest** — For the digit recogniser: the strongest of the ten digit neurons wins.

**4. (Sub lesson 2) In a trained image network, first hidden layers typically respond to —**
a) Whole faces  b) Simple features — edges and strokes  c) Names  d) Nothing in particular
**Answer: b) Simple features — edges and strokes** — Features upon features: simple first, combinations later, wholes last.

**5. (Sub lesson 2) Who assigns each hidden neuron its feature-detecting job?**
a) The programmer  b) Nobody — training discovers the division of labour  c) The user  d) The output layer
**Answer: b) Nobody — training discovers the division of labour** — The programmer sets the shape; the data sets the jobs.

**6. (Sub lesson 2) Training a whole network adjusts —**
a) Only the output layer  b) Every weight (and bias) in every layer  c) The input data  d) The activation rules
**Answer: b) Every weight (and bias) in every layer** — Millions of dials, all set by the training loop against the error.
