# Neural Networks — Many Neurons Together — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Every neuron in a hidden layer receives the previous layer's outputs as its inputs.**
**Answer: True** — That chaining is what makes layers a network rather than a crowd.

**2. (Sub lesson 2) A neural network stores its knowledge as a list of IF–THEN rules.**
**Answer: False** — Its knowledge is the whole set of weights — the data-based shape, unreadable as rules.

**3. (Sub lesson 2) Deeper networks need more training data, other things equal.**
**Answer: True** — More weights are more dials, and only data can set dials.

**4. (Sub lesson 2) When a network errs, you can always point to the single rule that caused it.**
**Answer: False** — The answer comes from the whole web of weights at once — the interrogation problem named in the lesson.
