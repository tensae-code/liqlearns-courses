# Cloud benefits — provider updates, security and pay-as-you-go — true or false

Say true or false.

**1.** With the cloud, users can focus on their work while the provider maintains the service.
**Answer: True**

**2.** Pay-as-you-go charges the same in a quiet month and a busy month.
**Answer: False** — The bill follows what is used.

**3.** Avoiding buying servers is one way cloud cost is controlled.
**Answer: True**
