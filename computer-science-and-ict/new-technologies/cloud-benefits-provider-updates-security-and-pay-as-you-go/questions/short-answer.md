# Cloud benefits — provider updates, security and pay-as-you-go — short answer

Answer in one or two sentences.

**1.** Name the three ways cloud cost is controlled.
**Answer:** Pay only for what is used (pay as you go); scale allocated resources up or down; avoid buying and maintaining equipment such as servers.

**2.** Why is cloud security presented as stronger than an organisation's own?
**Answer:** Most organisations are limited by time, expertise and budget; the provider specialises in securing the service.
