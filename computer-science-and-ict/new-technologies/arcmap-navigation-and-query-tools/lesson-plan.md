## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Navigation tools — moving on the map** — The **navigation tools** move the view without moving the data: **zoom in and out** to change scale, **pan** to drag the map, **full extent** to see the whole area at once, and **go to XY** to jump to typed coordinates. Beside them sit the asking-with-the-eye tools: **identify** — click a feature and read its attributes; and **measure** — rule a distance or an area on the map. Navigation answers *where am I looking*; the query tools answer *what is true here*.
2. **Query tools — asking the map questions** — A **query** picks features by rule. **Select by attribute** uses the attribute table — Rwanda's S3 practical asks which parcels of Cyiri Cell belong to Birambo Village. **Select by location** uses place — features inside, touching or within a distance of another feature. A **buffer** draws a zone at a set distance around a feature, and **overlay** tools combine layers — **union** keeps everything, **intersect** keeps only what overlaps. The finished work is presented as a **map layout**: legend, north arrow (orientation), scale, title and text, set up on the page and printed or exported.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
