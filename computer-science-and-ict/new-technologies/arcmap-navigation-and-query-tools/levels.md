# ArcMap Navigation and Query Tools — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Navigation tools — moving on the map
Sub lesson 1 questions from the type files. Pass mark: The view, without moving the data; Full extent; Go to XY; Click a feature and read its attributes; Rules a distance or an area on the map.

## Sub lesson 2 — Query tools — asking the map questions
Sub lesson 2 questions from the type files. Pass mark: The attribute table; Place — inside, touching or within a distance; A zone drawn at a set distance around a feature; Union keeps everything; intersect keeps only what overlaps; Legend, north arrow (orientation) and scale — plus title and text.
