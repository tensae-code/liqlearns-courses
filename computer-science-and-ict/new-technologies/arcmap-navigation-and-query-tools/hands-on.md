# Hands-on — ArcMap Navigation and Query Tools

The lesson with your hands and your feet, not only your eyes.

## Task one
('Navigate and ask', 'On a printed map of your district, rehearse the tools in words: write the sequence — full extent, zoom to your school, identify one building, measure the road home — naming the tool at each step.')

## Task two
('Write a query', 'Write one select-by-attribute question and one select-by-location question for a map of Rwanda's provinces, districts and lakes (the S3 practical). Say what answer each should return.')
