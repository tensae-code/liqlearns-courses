# ArcMap Navigation and Query Tools — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What do navigation tools move?" is: The view, without moving the data**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Which tool shows the whole area at once?" is: The view, without moving the data**
**Answer: False** — Full extent

**3. (Sub lesson 1) True or false: the answer to "How do you jump to typed coordinates?" is: Go to XY**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does the identify tool do?" is: The view, without moving the data**
**Answer: False** — Click a feature and read its attributes

**5. (Sub lesson 1) True or false: the answer to "What does the measure tool do?" is: Rules a distance or an area on the map**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does select by attribute use?" is: Place — inside, touching or within a distance**
**Answer: False** — The attribute table

**7. (Sub lesson 2) True or false: the answer to "What does select by location use?" is: Place — inside, touching or within a distance**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is a buffer?" is: The attribute table**
**Answer: False** — A zone drawn at a set distance around a feature

**9. (Sub lesson 2) True or false: the answer to "What is the difference between union and intersect?" is: Union keeps everything; intersect keeps only what overlaps**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Name three things a finished map layout carries." is: The attribute table**
**Answer: False** — Legend, north arrow (orientation) and scale — plus title and text
