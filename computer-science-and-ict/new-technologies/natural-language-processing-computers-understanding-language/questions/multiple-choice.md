# Natural Language Processing — computers understanding language — multiple choice

Pick the one right answer.

**1.** NLP lets computers understand —
a) human language as people do  b) only numbers  c) only code  d) music only
**Answer: a) human language as people do**

**2.** Google Translate is an example of —
a) machine translation  b) spam detection  c) summarisation  d) sentiment analysis
**Answer: a) machine translation**

**3.** Alexa and Siri are —
a) voice virtual assistants  b) spam filters  c) news sites  d) printers
**Answer: a) voice virtual assistants**

**4.** Sentiment analysis sorts opinion into —
a) positive, negative or neutral  b) hot or cold  c) loud or quiet  d) old or new
**Answer: a) positive, negative or neutral**

**5.** Shortening a long document automatically is —
a) automatic summarisation  b) translation  c) spam detection  d) fake news
**Answer: a) automatic summarisation**
