# Inserting Symbols and Equations — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Where do the keyboard's missing signs live in Word?" is: In the Insert Symbol gallery**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Name signs the gallery holds." is: A true character of the text — it copies, formats and prints like a letter**
**Answer: False** — Mathematical signs, arrows, currency marks, Greek letters (any two)

**3. (Sub lesson 1) True or false: the answer to "Once inserted, what is a symbol to the document?" is: A true character of the text — it copies, formats and prints like a letter**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Why must a formula not be typed as plain text?" is: Builds formulas from structures whose boxes are filled and nested**
**Answer: False** — A formula is a structure — fractions, roots and powers — not a line

**5. (Sub lesson 1) True or false: the answer to "What does the Equation editor do?" is: Builds formulas from structures whose boxes are filled and nested**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Which subjects' formulas does the book build?" is: As an object that resizes with the font and can be re-opened and corrected**
**Answer: False** — Maths, physics and chemistry

**7. (Sub lesson 2) True or false: the answer to "How does an equation sit in the document?" is: As an object that resizes with the font and can be re-opened and corrected**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "State the lesson's distinction." is: Insert them as characters, never paste them as pictures**
**Answer: False** — Symbols are characters; equations are constructions

**9. (Sub lesson 2) True or false: the answer to "What is the habit for signs?" is: Insert them as characters, never paste them as pictures**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Which project strand uses this?" is: In the Insert Symbol gallery**
**Answer: False** — Mongolia's Grade 9 Word strand — documents for the other school subjects
