# Indent with the Increase/Decrease buttons — depth

This lesson is one whole lesson with no sub lessons. Pass mark: the learner indents and un-indents selected text by clicks, states the half-inch measure, and sets a custom amount on the Layout tab. Practice deepens by more items and harder corners of the same skill — more examples to sort, longer sequences to put in order, trickier cases of the same idea — never by a new topic.
