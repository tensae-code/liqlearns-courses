# Indent with the Increase/Decrease buttons — ordering

Put each set in the right order.

**1.** The method in order: click Increase Indent / select the text / count the half-inch steps.
**Answer: select the text → click Increase Indent → count the half-inch steps.**

**2.** Three clicks in from the margin: half an inch / one and a half inches / one inch.
**Answer: half an inch → one inch → one and a half inches.**
