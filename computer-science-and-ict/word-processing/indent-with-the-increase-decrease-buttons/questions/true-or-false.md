# Indent with the Increase/Decrease buttons — true or false

Say whether each sentence is true or false.

**1.** Increase and Decrease Indent move by the same step size.
**Answer: True — half an inch a click, both ways.**

**2.** Right indention is measured from the left margin.
**Answer: False — from the right margin.**

**3.** The button method suits several lines or a whole paragraph.
**Answer: True.**
