# Preset headers and footers — and removing them — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A preset header is chosen from —
a) Insert → Header, then a design in the gallery  b) the ruler  c) Print  d) the File tab's Recent list
**Answer: a) Insert → Header, then a design in the gallery.**

**2. (Sub lesson 1)** Placeholder fields in a preset are —
a) printed as they stand  b) clicked and typed over  c) deleted first  d) locked forever
**Answer: b) clicked and typed over.**

**3. (Sub lesson 1)** The placeholder fields named are —
a) name, class, school, town  b) title, author, date, page number  c) chapter and verse  d) file size and type
**Answer: b) title, author, date, page number.**

**4. (Sub lesson 2)** A closed header is —
a) invisible  b) locked but still visible  c) deleted  d) printed only
**Answer: b) locked but still visible.**

**5. (Sub lesson 2)** A header is removed by —
a) Header → Remove Header  b) deleting page one  c) Esc  d) Save As
**Answer: a) Header → Remove Header.**

**6. (Sub lesson 3)** The closing practical's footer reads —
a) "Grade 9"  b) "Prepared by Grade 9 Students"  c) "The End"  d) the school's name
**Answer: b) "Prepared by Grade 9 Students".**
