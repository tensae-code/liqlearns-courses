# Preset headers and footers — and removing them — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Content Control fields hold a preset's standing words until you type over them.
**Answer: True.**

**2. (Sub lesson 2)** Footer removal works the same way as header removal.
**Answer: True — Footer → Remove Footer.**

**3. (Sub lesson 3)** The closing practical is saved into a new Word Project folder in Documents.
**Answer: True.**
