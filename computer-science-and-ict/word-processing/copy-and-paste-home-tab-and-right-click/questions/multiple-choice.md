# Copy and paste — Home tab and right-click ways — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The first move in copy and paste is —
a) click Paste  b) select the text to copy  c) place the cursor  d) close the document
**Answer: b) select the text to copy** — nothing can be copied until it is selected.

**2. (Sub lesson 1)** On the Home tab, after selecting the text, you click —
a) Paste  b) Save  c) Copy  d) Cut
**Answer: c) Copy.**

**3. (Sub lesson 1)** Before clicking Paste, you must —
a) save the document  b) place the cursor where the text should go  c) select more text  d) right-click
**Answer: b) place the cursor where the text should go** — the copy lands at the cursor.

**4. (Sub lesson 2)** In the right-click way, Copy is chosen —
a) from the File tab  b) from the menu that appears when you right-click the selected text  c) from the ribbon's end  d) by pressing Enter
**Answer: b) from the menu that appears when you right-click the selected text** — then left-click Copy in that menu.

**5. (Sub lesson 2)** In the right-click way, the last move is —
a) right-click at the new location and left-click Paste  b) press Spacebar  c) select the text again  d) click Copy again
**Answer: a) right-click at the new location and left-click Paste.**
