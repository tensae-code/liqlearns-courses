# Copy and paste — Home tab and right-click ways — ordering

Put each set in the right order.

**1. (Sub lesson 1)** Home tab way: click Paste / select the text / click Copy / place the cursor where the text should go.
**Answer: select the text → click Copy → place the cursor where the text should go → click Paste.**

**2. (Sub lesson 2)** Right-click way: left-click Paste in the menu / select the text / right-click at the desired location / right-click the selected text and left-click Copy.
**Answer: select the text → right-click the selected text and left-click Copy → right-click at the desired location → left-click Paste in the menu.**
