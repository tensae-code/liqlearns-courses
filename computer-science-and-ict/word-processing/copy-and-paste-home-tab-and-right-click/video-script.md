# Video script — Copy and paste — Home tab and right-click ways

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

One paragraph. You need it twice. Do not type it again.

Way one. Select the text. Home tab — Copy.
Put the cursor where it goes. Home tab — Paste.

Way two. Select the text. Right-click — Copy.
Right-click at the new place — Paste.

The first one stays. A copy stands beside it.
