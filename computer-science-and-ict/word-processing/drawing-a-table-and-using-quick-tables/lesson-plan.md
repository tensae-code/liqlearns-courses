# Lesson plan — Drawing a table — and using Quick Tables

**Course:** Computer Science and ICT · **Title:** Word Processing · **Lesson:** Drawing a table — and using Quick Tables
**Place in the curriculum:** Unit 3 — Application Software, Grade 10 depth, in the Word Processing title of the Computer Science and ICT ladder (TITLES.md). The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** a table can be drawn freehand with the pencil pointer — outer rectangle first, then border-to-border lines — and a ready-made table can be picked from the Quick Tables gallery instead.
**This lesson's own level:** it is a doing-lesson. It stands on Creating a Word table — drag and dialog box; drawing is the third route, Quick Tables the fourth.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Before this lesson
- Recommended first: Creating a Word table — drag and dialog box. Recommended, never forced.

## What the learner can do when it ends
1. Draw a table with the pencil: outer rectangle first, then border-to-border lines.
2. Switch the pencil off with the Draw Table button.
3. Insert a ready-made table from the Quick Tables gallery and update it to fit.
4. Save the drawn table as Table 3 and the calendar as Table4.

## What you need
A computer with Word, with the ruler shown.

## If the learner is stuck
- The pencil will not stop → click the Draw Table button again to switch it off.
- A line lands in the wrong place → undo at once and redraw it border to border.
