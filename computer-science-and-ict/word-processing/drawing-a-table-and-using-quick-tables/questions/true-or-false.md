# Drawing a table — and using Quick Tables — true or false

Say true or false.

**1. (Sub lesson 1)** Before drawing, the ruler is shown.
**Answer: True**

**2. (Sub lesson 2)** A Quick Table still needs editing to fit your own content.
**Answer: True**

**3. (Sub lesson 1)** In Draw Table the row lines are drawn before the outer rectangle.
**Answer: False** — the outer rectangle comes first.
