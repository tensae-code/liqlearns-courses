# Drawing a table — and using Quick Tables — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** In Draw Table, the first thing you draw is —
a) a row line  b) a column line  c) the outer rectangle  d) the title
**Answer: c) the outer rectangle**

**2. (Sub lesson 1)** The internal lines are dragged —
a) anywhere on the page  b) border to border  c) in circles  d) only halfway
**Answer: b) border to border**

**3. (Sub lesson 1)** The pencil is switched off by —
a) pressing Esc only  b) clicking the Draw Table button again  c) saving  d) closing Word
**Answer: b) clicking the Draw Table button again**

**4. (Sub lesson 2)** Quick Tables are —
a) tables you draw  b) ready-made preformatted tables in a gallery  c) tables from the internet only  d) empty grids
**Answer: b) ready-made preformatted tables in a gallery**

**5. (Sub lesson 2)** The book's Quick Tables exercise inserts —
a) Calendar 2  b) an invoice  c) a contact list  d) a timetable
**Answer: a) Calendar 2** — then updated to the current month and year.
