# Drawing a table — and using Quick Tables

## Do it first

Your table does not fit a neat grid: one wide row at the top, small uneven boxes below. Dragging a regular grid will not make it. Draw it instead — with a pencil.

## Sub lesson 1 — Drawing a table with the pencil

The Draw Table route turns the pointer into a **pencil**:

1. Show the **ruler**.
2. Choose **Draw Table** — the pointer becomes a pencil.
3. Draw the **outer rectangle** of the table first.
4. Drag **border-to-border lines** for the rows and columns, exactly where you want them.
5. Switch the pencil off by clicking the **Draw Table button** again.
6. Save the result as **Table 3**.

Because every line is placed by hand, drawn tables can hold uneven rows and columns that a dragged grid cannot.

## Sub lesson 2 — Quick Tables — ready-made tables

Quick Tables are the opposite of drawing: **ready-made, preformatted tables** picked from a built-in gallery and then edited to fit.

1. Open the **Quick Tables gallery** from the Table menu.
2. Pick a ready-made table — the exercise inserts **Calendar 2**.
3. **Update it** to the current month and year.
4. Save it as **Table4**.

The follow-on practical: draw a **15×7 table** by hand, then practise **inserting and deleting rows and columns** inside it.

## Say it to your companion

Tell your companion the drawing order — rectangle first, then lines — how the pencil is switched off, and what a Quick Table saves you from doing.

## Do It Yourself

1. Draw a table: outer rectangle, then lines for uneven rows and columns; save it as Table 3.
2. Insert Calendar 2 from Quick Tables, update it to this month and year, and save it as Table4.
3. Draw a 15×7 table and insert and delete a row and a column inside it.
