# Video script — Drawing a table — and using Quick Tables

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Some tables are not neat. Draw those.
Ruler on. Draw Table. Your pointer is now a pencil.
First, the big rectangle outside.
Then lines — border to border — for rows and columns, just where you want them.
Finished? Click Draw Table again. Pencil off. Save it: Table 3.
No time to draw? Quick Tables are ready-made.
Pick Calendar 2. Change it to this month, this year. Save it: Table4.
Drawn by hand, or picked ready-made — both are real tables.
