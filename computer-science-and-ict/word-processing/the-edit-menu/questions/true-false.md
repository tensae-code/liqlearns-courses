# The Edit Menu — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does the Edit menu work on?" is: Whatever is selected**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does Cut do?" is: Leaves the text where it is and holds a copy on the clipboard**
**Answer: False** — Removes the selected text and holds it on the clipboard

**3. (Sub lesson 1) True or false: the answer to "What does Copy do?" is: Leaves the text where it is and holds a copy on the clipboard**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does Paste do?" is: Cut moves; Copy duplicates**
**Answer: False** — Puts what the clipboard holds at the insertion point

**5. (Sub lesson 1) True or false: the answer to "What is the one difference at the menu's heart?" is: Cut moves; Copy duplicates**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does Undo do?" is: Selects the whole document at once**
**Answer: False** — Takes back the last action

**7. (Sub lesson 2) True or false: the answer to "What does Select All do?" is: Selects the whole document at once**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does Clear do differently from Cut?" is: Find and Replace**
**Answer: False** — Removes the selection without holding it on the clipboard

**9. (Sub lesson 2) True or false: the answer to "Which search commands live in the Edit menu?" is: Find and Replace**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why is editing what makes Word better than a typewriter?" is: Whatever is selected**
**Answer: False** — Text can be moved and fixed instead of retyped
