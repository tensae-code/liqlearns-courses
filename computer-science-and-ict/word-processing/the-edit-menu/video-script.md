# Video script — The Edit Menu

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

The **Edit menu** works on whatever is **selected**.
**Cut** removes the selected text and holds it on the **clipboard**; **Copy** leaves the text where it is and holds a copy; **Paste** puts what the clipboard holds at the insertion point.
Cut moves, Copy duplicates — that one difference is the heart of the menu.
Above them sits **Undo**, which takes back the last action (and **Redo**, which does again what Undo took back).
The Afghanistan books return to this menu in both Grade 10 and Grade 11, because editing — moving and fixing text instead of retyping it — is what makes a word processor better than a typewriter.
**Select All** selects the whole document at once, for one change to everything — a new font for an entire letter in a single move.
**Clear** (Delete) removes the selection without holding it on the clipboard, for when the text is simply to be gone.
The menu ends with **Find** and **Replace**, Word's search commands, which live here because finding is editing's scout: it locates the text the other commands will then work on.
Read top to bottom, the Edit menu is a complete kit: choose (Select All), change (Cut, Copy, Paste, Clear), search (Find, Replace) — and, with Undo, forgive.
