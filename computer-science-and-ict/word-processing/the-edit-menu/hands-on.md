# Hands-on — The Edit Menu

The lesson with your hands and your feet, not only your eyes.

## Move it, don't retype it
Type three sentences in the wrong order. Using only the Edit menu (no retyping, no mouse dragging), Cut and Paste them into the right order. Then Copy one sentence so it appears twice, and Undo your last action.

## One change to everything
Write a short paragraph, then use Select All and change the whole document's font size at once. Then use Find to locate one word, and say why Find belongs in the Edit menu.
