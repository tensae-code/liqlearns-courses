# Lesson plan — The Edit Menu

**Course:** Computer Science and ICT · **Title:** Word Processing · **Lesson:** The Edit Menu
**Place in the curriculum:** ICT expansion — Afghanistan (2026-11-14) — in the title Word Processing on the ICT course ladder (TITLES.md). Built new from Afghanistan's *Computer* Grade 10 and 11, because no existing lesson in the course covers this thing as its own lesson.
**The one thing this lesson teaches:** Word's Edit menu holds the commands that work on selected text while you write: Undo and Redo, Cut, Copy and Paste, Select All, and Find and Replace.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Cut, Copy, Paste — and Undo** — The **Edit menu** works on whatever is **selected**. **Cut** removes the selected text and holds it on the **clipboard**; **Copy** leaves the text where it is and holds a copy; **Paste** puts what the clipboard holds at the insertion point. Cut moves, Copy duplicates — that one difference is the heart of the menu. Above them sits **Undo**, which takes back the last action (and **Redo**, which does again what Undo took back). The Afghanistan books return to this menu in both Grade 10 and Grade 11, because editing — moving and fixing text instead of retyping it — is what makes a word processor better than a typewriter.
2. **Select All, Clear, Find and Replace** — **Select All** selects the whole document at once, for one change to everything — a new font for an entire letter in a single move. **Clear** (Delete) removes the selection without holding it on the clipboard, for when the text is simply to be gone. The menu ends with **Find** and **Replace**, Word's search commands, which live here because finding is editing's scout: it locates the text the other commands will then work on. Read top to bottom, the Edit menu is a complete kit: choose (Select All), change (Cut, Copy, Paste, Clear), search (Find, Replace) — and, with Undo, forgive.
