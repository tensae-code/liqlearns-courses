# Project — Making a Small Book in Word — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is the Grade 7 Word unit organised as?" is: One long project — a printed booklet**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is the booklets' subject?" is: Purpose, audience and structure**
**Answer: False** — "Усаа хайрлая" — Cherish the Water

**3. (Sub lesson 1) True or false: the answer to "Name the three opening decisions." is: Purpose, audience and structure**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does the audience decide?" is: The booklet's parts in order — cover, contents, sections**
**Answer: False** — The reading level and interests that shape every page

**5. (Sub lesson 1) True or false: the answer to "What is sketched in the structure?" is: The booklet's parts in order — cover, contents, sections**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Why is gathered information checked at gathering time?" is: The section it belongs to**
**Answer: False** — A printed book cannot be corrected after the run

**7. (Sub lesson 2) True or false: the answer to "What is each gathered piece marked with?" is: The section it belongs to**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What happens if a book is begun by typing?" is: Type it into Word, set its pages, dress it with pictures and tables, print it**
**Answer: False** — It is rewritten all the way through

**9. (Sub lesson 2) True or false: the answer to "Name the stages that follow planning in the unit." is: Type it into Word, set its pages, dress it with pictures and tables, print it**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What kind of lesson is this, in the course's terms?" is: One long project — a printed booklet**
**Answer: False** — A project-planning lesson — the opening of a book-length project
