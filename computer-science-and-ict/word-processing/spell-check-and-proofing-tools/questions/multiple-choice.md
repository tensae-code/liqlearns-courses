# Spell Check and Proofing Tools — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Find is used to —**
a) Locate specific text anywhere in the document  b) Print the document  c) Count the pages
**Answer: a) Locate specific text anywhere in the document** — It jumps to each appearance of the word or phrase.

**2. (Sub lesson 1) Replace-all should be used when —**
a) You are in a hurry  b) Every appearance of the text should change  c) The document is long
**Answer: b) Every appearance of the text should change** — It changes all of them, including any place where the old text was right.

**3. (Sub lesson 2) When the spell checker suggests a spelling, the writer —**
a) Must accept the first suggestion  b) Chooses — the checker proposes, the writer decides  c) Ignores the checker always
**Answer: b) Chooses — the checker proposes, the writer decides** — Suggestions can be wrong, and right words can be flagged.

**4. (Sub lesson 2) Which mistake can a spell checker pass without flagging?**
a) A word spelled correctly but the wrong word entirely  b) A word with letters in the wrong order  c) A word missing a letter
**Answer: a) A word spelled correctly but the wrong word entirely** — Only a human proofread for meaning catches it.

**5. (Sub lesson 2) The final step in cleaning a document is —**
a) Replace-all  b) Printing  c) The writer's own proofread for meaning
**Answer: c) The writer's own proofread for meaning** — Checker first, proofread last.
