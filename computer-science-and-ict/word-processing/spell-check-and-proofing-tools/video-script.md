# Video script — Spell Check and Proofing Tools

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A name is spelled two ways. A word is wrong three times.

Do not hunt by eye. Find it.

Replace it — carefully. Everywhere only when everywhere is right.

Run the checker. You still decide.

Then read it yourself. That last read is proofreading.
