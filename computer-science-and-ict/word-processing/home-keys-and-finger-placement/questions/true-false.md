# Home Keys and Finger Placement — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What are the home keys for the left hand?" is: A S D F**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What are the home keys for the right hand?" is: The two index (pointing) fingers**
**Answer: False** — J K L ;

**3. (Sub lesson 1) True or false: the answer to "Where do the thumbs rest?" is: On the space bar**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Which fingers start on F and J?" is: The left little finger**
**Answer: False** — The two index (pointing) fingers

**5. (Sub lesson 1) True or false: the answer to "Why do F and J carry raised bumps?" is: So fingers can find home without looking**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Which finger presses A?" is: Back to its home key**
**Answer: False** — The left little finger

**7. (Sub lesson 2) True or false: the answer to "Which finger owns the J column of keys?" is: The right index finger**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Where does a finger go after pressing a key away from home?" is: So every key is reached quickly and accurately**
**Answer: False** — Back to its home key

**9. (Sub lesson 2) True or false: the answer to "Which finger presses the space bar?" is: A thumb**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why keep the fingers on the home keys?" is: J K L ;**
**Answer: False** — So every key is reached quickly and accurately
