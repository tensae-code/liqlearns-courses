# Removing a page break — multiple choice

Pick the one right answer.

**1.** Page breaks are, by default —
a) shown in red  b) invisible  c) printed  d) locked
**Answer: b) invisible.**

**2.** A break is shown with —
a) Home → Show/Hide  b) Insert → Show  c) Ctrl+P  d) the zoom slider
**Answer: a) Home → Show/Hide.**

**3.** The insertion point goes —
a) at the end of the document  b) at the beginning of the dotted Page Break line  c) in the header  d) anywhere
**Answer: b) at the beginning of the dotted Page Break line.**

**4.** The key that removes the break is —
a) Enter  b) Backspace  c) Delete  d) Esc
**Answer: c) Delete.**

**5.** After the break is removed, the text —
a) is deleted  b) flows back  c) prints  d) centres itself
**Answer: b) flows back.**

**6.** The break appears on screen as —
a) a red line  b) a dotted Page Break line  c) a picture  d) a table border
**Answer: b) a dotted Page Break line.**
