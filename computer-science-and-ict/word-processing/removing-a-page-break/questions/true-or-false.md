# Removing a page break — true or false

Say whether each sentence is true or false.

**1.** You must show the break before you can delete it.
**Answer: True.**

**2.** Pressing Delete at the dotted line removes the text of the next page.
**Answer: False — it removes the break; the text flows back.**

**3.** Show/Hide sits on the Home tab.
**Answer: True.**
