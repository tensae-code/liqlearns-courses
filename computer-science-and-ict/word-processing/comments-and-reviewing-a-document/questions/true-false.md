# Comments and Reviewing a Document — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a comment?" is: A note attached to a place in a document**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Where is a comment shown?" is: Nothing — it asks, doubts or proposes**
**Answer: False** — Beside the text, in the margin or a note area

**3. (Sub lesson 1) True or false: the answer to "What does a comment do to the text itself?" is: Nothing — it asks, doubts or proposes**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Who decides after a comment?" is: A second reader's — a classmate's or teacher's**
**Answer: False** — The writer

**5. (Sub lesson 1) True or false: the answer to "Whose comments does a document carry?" is: A second reader's — a classmate's or teacher's**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is reviewing?" is: Answers it — changing the text or replying**
**Answer: False** — Reading a document as its reader will and commenting wherever it is unclear, wrong or weak

**7. (Sub lesson 2) True or false: the answer to "What does the writer do with each comment?" is: Answers it — changing the text or replying**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "When is reviewing done?" is: Right before printing**
**Answer: False** — When no open comment remains

**9. (Sub lesson 2) True or false: the answer to "Where does Cuba place commenting in the chapter?" is: Right before printing**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why is review the last work?" is: A note attached to a place in a document**
**Answer: False** — Because after it the page leaves the screen
