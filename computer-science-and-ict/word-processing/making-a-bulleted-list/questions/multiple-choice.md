# Making a bulleted list — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The first step in making a bulleted list is to —
a) print  b) select the text  c) close Word  d) open the ruler
**Answer: b) select the text.**

**2. (Sub lesson 1)** Hovering over a bullet style —
a) prints it  b) shows a live preview on your text  c) deletes it  d) saves the file
**Answer: b) shows a live preview on your text.**

**3. (Sub lesson 1)** Bullets are removed by —
a) deleting the text  b) selecting the list and clicking the Bulleted list command again  c) pressing Esc  d) closing the document
**Answer: b) selecting the list and clicking the Bulleted list command again.**

**4. (Sub lesson 1)** At the end of a list, Enter twice —
a) deletes the list  b) returns to normal formatting  c) adds two bullets  d) prints
**Answer: b) returns to normal formatting.**

**5. (Sub lesson 2)** A symbol bullet is defined through —
a) Define New Bullet → Symbol  b) the status bar  c) Print Preview  d) the File tab
**Answer: a) Define New Bullet → Symbol.**

**6. (Sub lesson 2)** The fonts recommended for symbol bullets are —
a) Arial and Times  b) Wingdings and Symbol  c) Calibri only  d) none
**Answer: b) Wingdings and Symbol.**
