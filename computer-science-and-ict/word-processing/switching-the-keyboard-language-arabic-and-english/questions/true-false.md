# Switching the Keyboard Language — Arabic and English — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What key pair switches the typing language?" is: Alt+Shift**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Which two languages does this lesson switch between?" is: The letters the keys produce**
**Answer: False** — Arabic and English

**3. (Sub lesson 1) True or false: the answer to "What changes on the keys when the language switches?" is: The letters the keys produce**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Where can you see which language is live?" is: Right to left**
**Answer: False** — The language indicator on the taskbar

**5. (Sub lesson 1) True or false: the answer to "Which way does Arabic run?" is: Right to left**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Which way is English written?" is: The text direction**
**Answer: False** — Left to right

**7. (Sub lesson 2) True or false: the answer to "What changes with the language?" is: The text direction**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Where does the writing point move when direction changes?" is: Yes — each part in its own direction**
**Answer: False** — To the correct side for the new language

**9. (Sub lesson 2) True or false: the answer to "Can one document hold both languages?" is: Yes — each part in its own direction**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What do you press to switch back?" is: Alt+Shift**
**Answer: False** — Alt+Shift again
