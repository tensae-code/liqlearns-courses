# Inserting Charts and Graphs in a Document — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a chart built from?" is: Numbers — a table or typed values**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Which chart compares?" is: A line**
**Answer: False** — Columns

**3. (Sub lesson 1) True or false: the answer to "Which chart shows change over time?" is: A line**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Which chart shows parts of a whole?" is: The drawing corrects itself**
**Answer: False** — A circle (pie) chart

**5. (Sub lesson 1) True or false: the answer to "What happens when a value is corrected?" is: The drawing corrects itself**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Where must a chart sit?" is: A caption naming what it shows**
**Answer: False** — Beside the paragraph that speaks of it

**7. (Sub lesson 2) True or false: the answer to "What must accompany a chart?" is: A caption naming what it shows**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Where do charts sit in the Grade 8 document chapter?" is: Data, drawing and text must agree on one page**
**Answer: False** — Last — after pictures, tables and shapes

**9. (Sub lesson 2) True or false: the answer to "Why is a chart the most demanding object?" is: Data, drawing and text must agree on one page**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "At what size must a chart read?" is: Numbers — a table or typed values**
**Answer: False** — At the page's size
