# Table of Contents and Lists of Tables and Figures — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a table of contents built from?" is: Heading styles**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Which style marks a chapter title?" is: Heading styles**
**Answer: False** — Heading 1

**3. (Sub lesson 1) True or false: the answer to "What does the list gather?" is: The headings in order with their page numbers**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How is the table kept right after edits?" is: Heading styles**
**Answer: False** — Update Table rebuilds it

**5. (Sub lesson 1) True or false: the answer to "How is a table of contents deleted?" is: As one field, never line by line**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is a caption?" is: Word's caption tool (Insert Caption)**
**Answer: False** — The numbered label under a table or figure

**7. (Sub lesson 2) True or false: the answer to "What tool inserts a caption?" is: Word's caption tool (Insert Caption)**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What happens to numbering when a table is added?" is: The numbered label under a table or figure**
**Answer: False** — It renumbers itself

**9. (Sub lesson 2) True or false: the answer to "What two lists are built from captions?" is: The list of tables and the list of figures**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Where do the lists stand in the document?" is: The numbered label under a table or figure**
**Answer: False** — At the front, beside the contents
