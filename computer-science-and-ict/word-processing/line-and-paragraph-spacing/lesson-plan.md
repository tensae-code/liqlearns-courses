# Lesson plan — Line and paragraph spacing

**Course:** Computer Science and ICT · **Title:** Word Processing · **Lesson:** Line and paragraph spacing
**Place in the curriculum:** Title 5 — Word Processing in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 9 book, Unit 3 — Application Software. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** line spacing sets the gap between a paragraph's lines and paragraph spacing sets the gap before and after it — both from the Line and Paragraph Spacing menu on Home, with exact values in the Paragraph dialog.
**This lesson's own level:** it stands on the indentation lessons — spacing is the Paragraph group's last depth: first paragraphs moved sideways, now their lines and gaps opened up.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Line spacing** — Word's defaults stated (1.15 line spacing, 8 points after paragraphs); select, Home → Line and Paragraph Spacing, choose a value — the example chooses 2.0
2. **Paragraph spacing** — the same menu's Add Space Before Paragraph / Remove Space After Paragraph; Line Spacing Options opens the Paragraph dialog for exact before/after control

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Indent with the Paragraph dialog box.  Recommended, never forced.

## What the learner can do when it ends
1. State Word's defaults: 1.15 line spacing, 8 points after paragraphs.
2. Set line spacing to a chosen value from the Line and Paragraph Spacing menu.
3. Add or remove paragraph space from the menu, and open the Paragraph dialog for exact before/after control.

## What you need
A computer with Word and the two Dagu paragraphs typed or opened.

## The run of the lesson (in order)
1. **Do it first** — the learner spreads the Dagu paragraphs to double spacing before the defaults are stated (lesson/lesson.md).
