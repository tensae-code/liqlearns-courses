# Line and paragraph spacing — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Word's default line spacing is —
a) 1.0  b) 1.15  c) 2.0  d) 1.5
**Answer: b) 1.15.**

**2. (Sub lesson 1)** Word's default space after a paragraph is —
a) 0 points  b) 4 points  c) 8 points  d) 12 points
**Answer: c) 8 points.**

**3. (Sub lesson 1)** Line spacing is chosen from —
a) Home → Line and Paragraph Spacing  b) the File tab  c) the ruler  d) the status bar
**Answer: a) Home → Line and Paragraph Spacing.**

**4. (Sub lesson 1)** The worked example chooses line spacing of —
a) 1.0  b) 1.15  c) 1.5  d) 2.0
**Answer: d) 2.0 — double spacing.**

**5. (Sub lesson 2)** Space before a paragraph is added from —
a) the same Line and Paragraph Spacing menu  b) Print  c) the zoom slider  d) a new document
**Answer: a) the same Line and Paragraph Spacing menu — Add Space Before Paragraph.**

**6. (Sub lesson 2)** Exact before/after control lives in —
a) the Paragraph dialog, opened by Line Spacing Options  b) the header  c) the Bullets menu  d) the title bar
**Answer: a) the Paragraph dialog, opened by Line Spacing Options.**
