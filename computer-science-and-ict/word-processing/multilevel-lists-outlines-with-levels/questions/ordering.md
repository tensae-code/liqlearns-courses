# Multilevel lists — outlines with levels — ordering

Put each set in the right order.

**1.** Levels from shallow to deep in the outline: ALU / computer systems (the title) / CPU.
**Answer: computer systems (the title) → CPU → ALU.**

**2.** Building a line at two levels: press Tab a second time / put the line in the list / press Tab once.
**Answer: put the line in the list → press Tab once → press Tab a second time.**
