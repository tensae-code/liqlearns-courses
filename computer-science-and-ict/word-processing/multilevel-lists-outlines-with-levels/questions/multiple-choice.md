# Multilevel lists — outlines with levels — multiple choice

Pick the one right answer.

**1.** A list line is pushed a level in with —
a) Enter  b) Tab  c) Esc  d) Ctrl+S
**Answer: b) Tab.**

**2.** A line is pulled back a level with —
a) Shift+Tab  b) Tab  c) Backspace only  d) the ruler only
**Answer: a) Shift+Tab.**

**3.** In the worked outline, ALU, control unit and registers sit —
a) at the top level  b) one level in  c) two levels in  d) outside the list
**Answer: c) two levels in — Tab twice.**

**4.** Input/output devices and CPU sit —
a) two levels in  b) one level in  c) at the margin as the title only  d) in a table
**Answer: b) one level in.**

**5.** The multilevel style is changed with —
a) the Multilevel List command on Home  b) the File tab  c) Print  d) the zoom slider
**Answer: a) the Multilevel List command on Home.**

**6.** The closing practical builds —
a) a shopping list  b) a nested Office/Laboratory inventory list  c) a timetable  d) an exam
**Answer: b) a nested Office/Laboratory inventory list.**
