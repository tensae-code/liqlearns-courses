# Multilevel lists — outlines with levels — true or false

Say whether each sentence is true or false.

**1.** Only numbered lists can become multilevel.
**Answer: False — any bulleted or numbered list can.**

**2.** The Increase/Decrease Indent commands also change a line's level.
**Answer: True.**

**3.** Memory sits one level in, and internal/external memory two levels in.
**Answer: True.**
