# Multilevel lists — outlines with levels

## Do it first

Type the computer-systems lines flat: computer systems, input/output devices, CPU, ALU, control unit, registers, memory, internal memory, external memory, application software, system software. Flat, they say nothing about what belongs inside what. By the end of this lesson the same lines will stand as an outline — CPU holding ALU, control unit and registers inside it.

## Levels by Tab

Any bulleted or numbered list becomes **multilevel with the Tab key**. In the worked classification: **input/output devices and CPU** are Tabbed **one level in**; **ALU, control unit and registers** go **two levels** (Tab twice); **memory** one level, **internal and external memory** two; **application and system software** one level, and system development and system management software two. **Shift+Tab decreases a level**, and the **Increase/Decrease Indent commands work too**. The style is changed by selecting the list and clicking the **Multilevel List command** on Home.

## The closing practical

The block closes by building a **nested Office/Laboratory inventory list** from a printed model: room by room, item inside category inside room — the same Tab work, on a real school inventory. Build it level by level, checking each line's level against the model before moving on.

## Say it to your companion

Tell your companion how Tab and Shift+Tab move a line between levels, and walk the computer-systems outline level by level.

## Do It Yourself

1. Build the computer-systems outline from the flat lines, Tab for Tab.
2. Demote the memory line one level with Tab, then promote it back with Shift+Tab.
3. Build the Office/Laboratory inventory list from a model your teacher or companion describes.
