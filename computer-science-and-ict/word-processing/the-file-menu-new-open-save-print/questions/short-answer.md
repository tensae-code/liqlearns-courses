# The File Menu — New, Open, Save, Print — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does the File menu work on?**
**Answer: The document as a whole, not on its text**

**2. (Sub lesson 1) What does New do?**
**Answer: Starts a fresh blank document**

**3. (Sub lesson 1) What does Open do?**
**Answer: Brings an existing document back from where it was saved**

**4. (Sub lesson 1) What does Save do?**
**Answer: Keeps the document under the name and place it already has**

**5. (Sub lesson 1) What is Save As for?**
**Answer: Keeping the document under a new name or in a new place, leaving the old copy as it was**

**6. (Sub lesson 2) What is Print Preview for?**
**Answer: Showing the pages exactly as they will come out, before printing**

**7. (Sub lesson 2) What can you choose in the Print dialog?**
**Answer: The printer, which pages, and how many copies**

**8. (Sub lesson 2) What is the difference between Close and Exit?**
**Answer: Close shuts the document; Exit shuts Word itself**

**9. (Sub lesson 2) What is the File menu's safety rule?**
**Answer: Save early, save often — never depend on being asked**

**10. (Sub lesson 2) Save replaces — what does Save As do?**
**Answer: Save As branches, keeping a new copy and leaving the old one**
