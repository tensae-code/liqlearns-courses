# The File Menu — New, Open, Save, Print — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does the File menu work on?**
a) The document as a whole, not on its text  b) Starts a fresh blank document  c) Brings an existing document back from where it was saved  d) Keeps the document under the name and place it already has
**Answer: a) The document as a whole, not on its text**

**2. (Sub lesson 1) What does New do?**
a) Brings an existing document back from where it was saved  b) Starts a fresh blank document  c) Keeps the document under the name and place it already has  d) Keeping the document under a new name or in a new place, leaving the old copy as it was
**Answer: b) Starts a fresh blank document**

**3. (Sub lesson 1) What does Open do?**
a) Keeps the document under the name and place it already has  b) Keeping the document under a new name or in a new place, leaving the old copy as it was  c) Brings an existing document back from where it was saved  d) Showing the pages exactly as they will come out, before printing
**Answer: c) Brings an existing document back from where it was saved**

**4. (Sub lesson 1) What does Save do?**
a) Keeping the document under a new name or in a new place, leaving the old copy as it was  b) Showing the pages exactly as they will come out, before printing  c) The printer, which pages, and how many copies  d) Keeps the document under the name and place it already has
**Answer: d) Keeps the document under the name and place it already has**

**5. (Sub lesson 1) What is Save As for?**
a) Keeping the document under a new name or in a new place, leaving the old copy as it was  b) Showing the pages exactly as they will come out, before printing  c) The printer, which pages, and how many copies  d) Close shuts the document; Exit shuts Word itself
**Answer: a) Keeping the document under a new name or in a new place, leaving the old copy as it was**

**6. (Sub lesson 2) What is Print Preview for?**
a) The printer, which pages, and how many copies  b) Showing the pages exactly as they will come out, before printing  c) Close shuts the document; Exit shuts Word itself  d) Save early, save often — never depend on being asked
**Answer: b) Showing the pages exactly as they will come out, before printing**

**7. (Sub lesson 2) What can you choose in the Print dialog?**
a) Close shuts the document; Exit shuts Word itself  b) Save early, save often — never depend on being asked  c) The printer, which pages, and how many copies  d) Save As branches, keeping a new copy and leaving the old one
**Answer: c) The printer, which pages, and how many copies**

**8. (Sub lesson 2) What is the difference between Close and Exit?**
a) Save early, save often — never depend on being asked  b) Save As branches, keeping a new copy and leaving the old one  c) The document as a whole, not on its text  d) Close shuts the document; Exit shuts Word itself
**Answer: d) Close shuts the document; Exit shuts Word itself**

**9. (Sub lesson 2) What is the File menu's safety rule?**
a) Save early, save often — never depend on being asked  b) Save As branches, keeping a new copy and leaving the old one  c) The document as a whole, not on its text  d) Starts a fresh blank document
**Answer: a) Save early, save often — never depend on being asked**

**10. (Sub lesson 2) Save replaces — what does Save As do?**
a) The document as a whole, not on its text  b) Save As branches, keeping a new copy and leaving the old one  c) Starts a fresh blank document  d) Brings an existing document back from where it was saved
**Answer: b) Save As branches, keeping a new copy and leaving the old one**
