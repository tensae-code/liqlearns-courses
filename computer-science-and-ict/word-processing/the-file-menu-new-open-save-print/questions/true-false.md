# The File Menu — New, Open, Save, Print — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does the File menu work on?" is: The document as a whole, not on its text**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does New do?" is: Brings an existing document back from where it was saved**
**Answer: False** — Starts a fresh blank document

**3. (Sub lesson 1) True or false: the answer to "What does Open do?" is: Brings an existing document back from where it was saved**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does Save do?" is: Keeping the document under a new name or in a new place, leaving the old copy as it was**
**Answer: False** — Keeps the document under the name and place it already has

**5. (Sub lesson 1) True or false: the answer to "What is Save As for?" is: Keeping the document under a new name or in a new place, leaving the old copy as it was**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is Print Preview for?" is: The printer, which pages, and how many copies**
**Answer: False** — Showing the pages exactly as they will come out, before printing

**7. (Sub lesson 2) True or false: the answer to "What can you choose in the Print dialog?" is: The printer, which pages, and how many copies**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is the difference between Close and Exit?" is: Save early, save often — never depend on being asked**
**Answer: False** — Close shuts the document; Exit shuts Word itself

**9. (Sub lesson 2) True or false: the answer to "What is the File menu's safety rule?" is: Save early, save often — never depend on being asked**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Save replaces — what does Save As do?" is: The document as a whole, not on its text**
**Answer: False** — Save As branches, keeping a new copy and leaving the old one
