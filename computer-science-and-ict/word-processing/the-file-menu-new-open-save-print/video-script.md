# Video script — The File Menu — New, Open, Save, Print

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

The **File menu** is the first menu in Word's menu bar, and it works on the whole document, not on its text.
**New** starts a fresh blank document.
**Open** brings an existing document back from where it was saved, so work is never begun twice.
**Save** keeps the document under the name and place it already has — the command to use again and again while you work.
**Save As** keeps it under a *new* name or in a *new* place, leaving the old copy as it was: Save replaces, Save As branches.
The book teaches these four as one lesson because together they are the document's whole life of being kept.
**Print** sends the document to the printer; before it, **Print Preview** shows the pages exactly as they will come out, so a mistake is caught on the screen, not on paper, and the Print dialog lets you choose the printer, which pages, and how many copies.
**Close** shuts the document but leaves Word open for the next one; **Exit** shuts Word itself.
And the safety rule that runs through the whole menu: if you close with unsaved work, Word asks whether to save — but the careful writer never depends on being asked.
Save early, save often: that is the File menu's real lesson.
