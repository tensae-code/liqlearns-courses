# Hands-on — The File Menu — New, Open, Save, Print

The lesson with your hands and your feet, not only your eyes.

## Live the document's life
In Word: start with New, type three lines, Save As with your name, type a fourth line, Save, Close, then Open your document again and check all four lines are there. Write down each File command you used, in order.

## Preview before paper
Open any document, look at it in Print Preview, and find one thing you would fix before printing. Then open the Print dialog and point out — without printing — the printer, pages and copies choices.
