# Intermediate Word Features — WordArt and Wrapping Text — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is WordArt?" is: A short piece of text turned into a styled object — shaped, coloured, outlined or shadowed**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How is a WordArt object treated on the page?" is: One short line — a title or heading that carries the page's name**
**Answer: False** — Like a picture — inserted, moved and resized as an object

**3. (Sub lesson 1) True or false: the answer to "What is WordArt for?" is: One short line — a title or heading that carries the page's name**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Why must WordArt never be used for a whole paragraph?" is: By reopening the WordArt object's text**
**Answer: False** — Decorated text cannot be read at length — decoration serves the title and leaves the text plain

**5. (Sub lesson 1) True or false: the answer to "How do you edit WordArt words?" is: By reopening the WordArt object's text**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is text wrapping?" is: The text flows around the picture's box, leaving it a clear space**
**Answer: False** — The decision about how text flows around a picture placed in the document

**7. (Sub lesson 2) True or false: the answer to "What does square wrapping do?" is: The text flows around the picture's box, leaving it a clear space**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does tight wrapping do?" is: The picture sits in the text line and moves along like one big character**
**Answer: False** — The text hugs the picture's own shape

**9. (Sub lesson 2) True or false: the answer to "What does 'in line with text' mean?" is: The picture sits in the text line and moves along like one big character**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why does Fiji teach these as intermediate features?" is: A short piece of text turned into a styled object — shaped, coloured, outlined or shadowed**
**Answer: False** — Because the learner must arrange objects on a laid-out page, not only type
