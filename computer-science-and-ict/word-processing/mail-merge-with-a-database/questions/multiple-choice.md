# Mail Merge with a Database — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What two parts does a merge have?**
a) The main document and the data source  b) Merge fields  c) The recipients — one record each  d) Fields, matching the merge fields
**Answer: a) The main document and the data source**

**2. (Sub lesson 1) What stands where personal details go?**
a) The recipients — one record each  b) Merge fields  c) Fields, matching the merge fields  d) No — the merge needs both
**Answer: b) Merge fields**

**3. (Sub lesson 1) What are the data source's rows?**
a) Fields, matching the merge fields  b) No — the merge needs both  c) The recipients — one record each  d) Preview a few records
**Answer: c) The recipients — one record each**

**4. (Sub lesson 1) What are its columns in merge language?**
a) No — the merge needs both  b) Preview a few records  c) One personalised copy per record  d) Fields, matching the merge fields
**Answer: d) Fields, matching the merge fields**

**5. (Sub lesson 1) Can either part work alone?**
a) No — the merge needs both  b) Preview a few records  c) One personalised copy per record  d) Labels and envelopes
**Answer: a) No — the merge needs both**

**6. (Sub lesson 2) What should you do before finishing the merge?**
a) One personalised copy per record  b) Preview a few records  c) Labels and envelopes  d) A mis-typed field name — names must match exactly
**Answer: b) Preview a few records**

**7. (Sub lesson 2) What does finishing produce?**
a) Labels and envelopes  b) A mis-typed field name — names must match exactly  c) One personalised copy per record  d) Word processing and databases
**Answer: c) One personalised copy per record**

**8. (Sub lesson 2) Name two merge outputs besides letters.**
a) A mis-typed field name — names must match exactly  b) Word processing and databases  c) The main document and the data source  d) Labels and envelopes
**Answer: d) Labels and envelopes**

**9. (Sub lesson 2) What breaks a field match?**
a) A mis-typed field name — names must match exactly  b) Word processing and databases  c) The main document and the data source  d) Merge fields
**Answer: a) A mis-typed field name — names must match exactly**

**10. (Sub lesson 2) Which two themes of the book meet in mail merge?**
a) The main document and the data source  b) Word processing and databases  c) Merge fields  d) The recipients — one record each
**Answer: b) Word processing and databases**
