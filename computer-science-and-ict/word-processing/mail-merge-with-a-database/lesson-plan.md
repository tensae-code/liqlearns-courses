# Lesson plan — Mail Merge with a Database

**Course:** Computer Science and ICT · **Title:** Word Processing · **Lesson:** Mail Merge with a Database
**Place in the curriculum:** ICT expansion — North Macedonia (2026-11-14) — in the title Word Processing on the ICT course ladder (TITLES.md). Built new from North Macedonia's *Informatics* (2026), because no existing lesson in the course covers this thing as its own lesson.
**The one thing this lesson teaches:** Mail merge writes one letter once and produces a personalised copy for every record in a database or table: the main document holds the fixed text plus merge fields, the data source holds the names and details, and the merge pours each record through the fields to print letters, labels or envelopes in one run.
**This lesson's own level:** It stands on the earlier lessons of its title and on the North Macedonia book's own order — it follows the book's sections in sequence, so its neighbours in the book are its natural companions. It stands alone for a learner landing on it directly.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Two parts — document and data** — A merge has exactly **two parts**: the **main document** (the letter's fixed text, with **merge fields** like «Name» standing where personal details go) and the **data source** — a database table or list whose **fields** (columns) match those merge fields and whose **records** (rows) are the recipients. Neither part alone can do the job.
2. **Running the merge** — Connect the document to the source, place the fields, **preview** a few records to catch layout faults, then **finish the merge** — to a new document, to the printer, or to labels/envelopes. One mis-typed field name breaks the match, so field names in the letter must equal the source's column names exactly. The book teaches merge as the meeting point of its Word and database themes.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
