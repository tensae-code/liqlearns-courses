# Table of Contents and Indexes — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does a table of contents list?" is: The document's styled headings with page numbers**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What must headings carry for contents to work?" is: It cannot update itself when the document changes**
**Answer: False** — Heading styles

**3. (Sub lesson 1) True or false: the answer to "Is a contents table typed text?" is: No — it is a generated field**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does Update Table do?" is: By marking the word in the document**
**Answer: False** — Rebuilds the contents after edits

**5. (Sub lesson 1) True or false: the answer to "Why can't a hand-typed contents match it?" is: It cannot update itself when the document changes**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is an index?" is: Gathers, alphabetises and lists the marked words with pages**
**Answer: False** — An alphabetical list of chosen words with their pages

**7. (Sub lesson 2) True or false: the answer to "How does an index entry begin?" is: By marking the word in the document**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Where does an index usually stand?" is: The document's styled headings with page numbers**
**Answer: False** — At the end of the document

**9. (Sub lesson 2) True or false: the answer to "What does Word do when the index is inserted?" is: Gathers, alphabetises and lists the marked words with pages**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "How is an index kept current?" is: No — it is a generated field**
**Answer: False** — By updating it after changes, like the contents
