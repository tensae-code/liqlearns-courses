# Inserting pictures and screenshots — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** An inserted picture becomes —
a) a linked file  b) an embedded object, part of the document  c) a separate document  d) a footnote
**Answer: b) an embedded object, part of the document**

**2. (Sub lesson 1)** Pictures are inserted from —
a) Insert tab → Pictures, in the Illustrations group  b) View → Pictures  c) File → Pictures  d) Home → Pictures
**Answer: a) Insert tab → Pictures, in the Illustrations group**

**3. (Sub lesson 1)** The picture lands —
a) on a new page  b) at the cursor  c) in the header  d) at the end always
**Answer: b) at the cursor** — and the Picture Tools Format tab appears.

**4. (Sub lesson 2)** Insert → Screenshot first shows —
a) your folders  b) thumbnails of the open windows  c) clip art  d) page styles
**Answer: b) thumbnails of the open windows**

**5. (Sub lesson 2)** Screen Clipping takes —
a) the whole window  b) exactly the rectangle you drag  c) the whole screen  d) the first paragraph
**Answer: b) exactly the rectangle you drag**
