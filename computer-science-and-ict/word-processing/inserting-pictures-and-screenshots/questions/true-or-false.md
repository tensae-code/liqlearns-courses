# Inserting pictures and screenshots — true or false

Say true or false.

**1. (Sub lesson 1)** Before inserting, the book prepares and formats the heading text.
**Answer: True**

**2. (Sub lesson 1)** An inserted picture stays linked to its file and is not part of the document.
**Answer: False** — it is embedded — part of the document.

**3. (Sub lesson 2)** SmartArt and charts count as illustrations in this section.
**Answer: True**
