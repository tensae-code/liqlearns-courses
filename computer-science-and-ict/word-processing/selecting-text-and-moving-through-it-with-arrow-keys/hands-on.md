# Hands-on — Selecting Text and Moving Through It with Arrow Keys

The lesson with your hands and your feet, not only your eyes.

## Walk a small text
In a three-line text, walk the caret from the start to a named letter using only arrow keys, counting the steps.

## Select a large text
Select a whole paragraph two ways — mouse drag, then Shift with the keyboard. Say which felt surer, and why selecting beat walking.
