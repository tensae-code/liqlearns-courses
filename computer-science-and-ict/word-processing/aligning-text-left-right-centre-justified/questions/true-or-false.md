# Aligning text — left, right, centre, justified — true or false

Say whether each sentence is true or false.

**1.** Left alignment is the commonest kind.
**Answer: True.**

**2.** Justified alignment leaves a jagged right edge.
**Answer: False — it spreads each line to both margins, removing the jagged look.**

**3.** One click changes the whole paragraph's alignment.
**Answer: True.**
