# The Word Toolbars — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a toolbar?" is: A row of buttons, each a picture of the job it does**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Why do toolbars exist?" is: The Standard toolbar and the Formatting toolbar**
**Answer: False** — So the commonest commands are one click away, not buried in menus

**3. (Sub lesson 1) True or false: the answer to "Which two toolbars matter in the book's Word?" is: The Standard toolbar and the Formatting toolbar**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How is a toolbar shown or hidden?" is: Rest the pointer on it until its tooltip label appears**
**Answer: False** — From the View menu

**5. (Sub lesson 1) True or false: the answer to "How do you learn an unknown button's name?" is: Rest the pointer on it until its tooltip label appears**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does the Standard toolbar carry?" is: Font, size, Bold, Italic, Underline, alignment, lists, borders and colours**
**Answer: False** — File and editing commands — New, Open, Save, Print, Cut, Copy, Paste, Undo

**7. (Sub lesson 2) True or false: the answer to "What does the Formatting toolbar carry?" is: Font, size, Bold, Italic, Underline, alignment, lists, borders and colours**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is the split between the two toolbars?" is: No — the same commands as the File and Edit menus, as buttons**
**Answer: False** — Standard works on the document and your place in it; Formatting changes how selected text looks

**9. (Sub lesson 2) True or false: the answer to "Are toolbar buttons different commands from the menus?" is: No — the same commands as the File and Edit menus, as buttons**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What should you never do with an unknown button?" is: A row of buttons, each a picture of the job it does**
**Answer: False** — Guess it — hover first and read its name
