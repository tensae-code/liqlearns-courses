# Indent with the Tab key — ordering

Put each set in the right order.

**1.** The method in order: press Tab / put the cursor at the very start / look at what changed.
**Answer: put the cursor at the very start → press Tab → look at what changed.**

**2.** Doing both paragraphs: indent the second paragraph / indent the first paragraph / open the document.
**Answer: open the document → indent the first paragraph → indent the second paragraph.**
