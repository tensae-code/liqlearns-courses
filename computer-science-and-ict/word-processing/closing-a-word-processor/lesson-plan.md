# Lesson plan — Closing a word processor — and first writing practice

**Course:** Computer Science and ICT · **Title:** Word Processing · **Lesson:** Closing a word processor — and first writing practice
**Place in the curriculum:** Title 5 — Word Processing in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 7 book, Unit 3 — Computer Software. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** Word closes two ways — the Close button at the top-right of the title bar, or File → Exit — and the closing practical puts the whole skill together: open, write, save, close.
**This lesson's own level:** it is a doing-lesson that closes the Word practical — half of Ethiopia's Unit 3 by the guide's own period count.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Two ways to close** — the Close button at the top-right of the title bar, or File → Exit
2. **First writing practice** — the book's practical: write your name, save, close; then a short text about yourself saved on the desktop under your first name

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Saving a word document.  Recommended, never forced.

## What the learner can do when it ends
1. Close Word by the Close button and by File → Exit.
2. Do the practical: name document saved and closed.
3. Write the about-yourself text with name, grade and section at the top, saved on the desktop under your first name.
4. Discuss pen-and-pencil writing against word processing.

## What you need
A computer with Word; a partner or class for the discussion.

## If the learner is stuck
- Closes without saving → the finish order is save first, then close; make it one habit.
- Cannot find Exit → it lives in the File menu, at the end of the list.
- Saves the practice text in Documents → the practical says the desktop, under your first name; use Browse to get there.
