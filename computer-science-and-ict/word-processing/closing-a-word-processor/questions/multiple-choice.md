# Closing a word processor — and first writing practice — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Way 1 to close Word is —
a) unplug the computer  b) the Close button at the top-right of the title bar  c) File → Print  d) the Start menu
**Answer: b) the Close button at the top-right of the title bar** — the X at the top-right of the title bar.

**2. (Sub lesson 1)** Way 2 is —
a) File → Exit  b) File → New  c) Home → Close  d) Insert → Exit
**Answer: a) File → Exit** — open File and choose Exit.

**3. (Sub lesson 1)** The right finish order is —
a) close, then save  b) save first, then close  c) print, then delete  d) exit, then type
**Answer: b) save first, then close** — save first, then close — always.

**4. (Sub lesson 2)** The first practical document holds —
a) a poem  b) your full name  c) a table  d) a picture
**Answer: b) your full name** — write your full name, save, close.

**5. (Sub lesson 2)** The about-yourself text must have, at the top —
a) the date only  b) your name, grade and section  c) a drawing  d) the teacher's name
**Answer: b) your name, grade and section** — name, grade and section at the top.

**6. (Sub lesson 2)** The about-yourself text is saved —
a) in Documents  b) on the desktop, under your first name  c) in the Recycle Bin  d) nowhere
**Answer: b) on the desktop, under your first name** — desktop, first name — the book's instruction.
