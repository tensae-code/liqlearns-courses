# Typing text — the blinking insertion point — multiple choice

Pick the one right answer.

**1.** The blinking cursor in the text area is called —
a) the ribbon  b) the insertion point  c) the title bar  d) the scroll bar
**Answer: b) the insertion point** — text is inserted where it blinks.

**2.** The insertion point sits —
a) on the desktop  b) in the text area below the ribbon  c) inside the File tab  d) under the window
**Answer: b) in the text area below the ribbon.**

**3.** As you type, the words appear —
a) on the ribbon  b) in a new window  c) on screen in the text area  d) only after saving
**Answer: c) on screen in the text area** — right where the insertion point stands.

**4.** Which keys move the insertion point?
a) Shift, Alt, Ctrl  b) Spacebar, Enter, Tab  c) F1, F2, F3  d) The arrow keys only, says this lesson
**Answer: b) Spacebar, Enter, Tab** — the three keys this lesson names.

**5.** To start typing, you first —
a) click the word processor icon to open it  b) press Tab ten times  c) click Save  d) close the ribbon
**Answer: a) click the word processor icon to open it** — step one of the book's order.
