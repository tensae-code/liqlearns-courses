# Typing text — the blinking insertion point — true or false

Say whether each sentence is true or false.

**1.** Text lands wherever the insertion point is standing.
**Answer: True** — that is what the insertion point is for.

**2.** The insertion point sits on the ribbon.
**Answer: False** — it sits in the text area below the ribbon.

**3.** Pressing Enter moves the insertion point to a new line.
**Answer: True** — Enter drops the point down a line.
