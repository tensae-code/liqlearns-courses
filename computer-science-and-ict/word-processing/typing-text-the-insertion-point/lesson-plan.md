# Lesson plan — Typing text — the blinking insertion point

**Course:** Computer Science and ICT · **Title:** Word Processing · **Lesson:** Typing text — the blinking insertion point
**Place in the curriculum:** Title 5 — Word Processing in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 8 book, Unit 3 — Computer Software. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** when the word processor opens, the blinking cursor — the insertion point — sits in the text area below the ribbon; as you type, words appear there, and Spacebar, Enter and Tab move the insertion point.
**This lesson's own level:** it is a doing-lesson. It stands on opening a word processor — this is the first thing done inside it.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. ## Before this lesson
- Recommended first: Opening a word processor, and The Word window. Recommended, never forced.

## What the learner can do when it ends
1. Open the word processor and find the insertion point in the text area below the ribbon.
2. Type text and watch the words appear on screen in the text area.
3. Move the insertion point with the Spacebar, Enter and Tab keys, and say what each key does to the text's place.

## What you need
A computer with a word processor — this lesson is learned by doing it.

## If the learner is stuck
- Looks for the cursor on the ribbon → the insertion point sits in the text area, below the ribbon; the ribbon holds tools, not text.
- Types and nothing appears → click in the text area first so the insertion point is sitting there, then type.
