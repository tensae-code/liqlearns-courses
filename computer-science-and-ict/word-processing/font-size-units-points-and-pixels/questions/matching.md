# Font Size Units — Points and Pixels — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What is one point?** → **1/72 of an inch — about 0.35 mm**

**2. (Sub lesson 1) What does a font's size actually measure?** → **The height of its em — roughly tallest-top to lowest-descender, not any single letter**

**3. (Sub lesson 1) Why can two 12 pt fonts look different sizes?** → **Their letters fill the em differently — the unit measures the em, not the letter you see**

**4. (Sub lesson 1) What is a common body-text size in books?** → **10–12 pt**

**5. (Sub lesson 1) Where does Armenia teach font units?** → **Grade 9, §11 — Font measurement units**

**6. (Sub lesson 2) What is a pixel?** → **One of the screen's own dots — the screen's unit of length**

**7. (Sub lesson 2) What is the pt–px bridge?** → **1 pt = 4/3 px (so 12 pt = 16 px) at the CSS reference density**

**8. (Sub lesson 2) Why is a phone's px not a fixed physical size?** → **Screens pack pixels at different densities — the same px count covers different real lengths**

**9. (Sub lesson 2) Which units let web type scale with reader settings?** → **Relative units — em and rem**

**10. (Sub lesson 2) Which unit belongs to print, which to screens?** → **Points for print; pixels (or relative units) for screens**
