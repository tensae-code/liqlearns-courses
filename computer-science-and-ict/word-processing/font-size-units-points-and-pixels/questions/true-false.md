# Font Size Units — Points and Pixels — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: 1/72 of an inch — about 0.35 mm**
**Answer: True**

**2. (Sub lesson 1) True or false: 1/72 of an inch — about 0.35 mm** — as the answer to: What does a font's size actually measure?
**Answer: False — The height of its em — roughly tallest-top to lowest-descender, not any single letter**

**3. (Sub lesson 1) True or false: Their letters fill the em differently — the unit measures the em, not the letter you see**
**Answer: True**

**4. (Sub lesson 1) True or false: Their letters fill the em differently — the unit measures the em, not the letter you see** — as the answer to: What is a common body-text size in books?
**Answer: False — 10–12 pt**

**5. (Sub lesson 1) True or false: Grade 9, §11 — Font measurement units**
**Answer: True**

**6. (Sub lesson 2) True or false: Grade 9, §11 — Font measurement units** — as the answer to: What is a pixel?
**Answer: False — One of the screen's own dots — the screen's unit of length**

**7. (Sub lesson 2) True or false: 1 pt = 4/3 px (so 12 pt = 16 px) at the CSS reference density**
**Answer: True**

**8. (Sub lesson 2) True or false: 1 pt = 4/3 px (so 12 pt = 16 px) at the CSS reference density** — as the answer to: Why is a phone's px not a fixed physical size?
**Answer: False — Screens pack pixels at different densities — the same px count covers different real lengths**

**9. (Sub lesson 2) True or false: Relative units — em and rem**
**Answer: True**

**10. (Sub lesson 2) True or false: Relative units — em and rem** — as the answer to: Which unit belongs to print, which to screens?
**Answer: False — Points for print; pixels (or relative units) for screens**
