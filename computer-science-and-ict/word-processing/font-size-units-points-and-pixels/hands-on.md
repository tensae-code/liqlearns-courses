# Hands-on — Font Size Units — Points and Pixels

The lesson with your hands and your feet, not only your eyes.

## Task one
**Measure the em** — Print or display the same sentence at 12 pt in three different fonts. Measure the height of the letter 'H' in each — same size setting, different letter heights. Explain using the em.

## Task two
**Convert a page** — Take a document set in pt sizes (title 24, headings 14, body 11). Convert every size to px with the 4/3 bridge and set them on a web page. Compare the look.
