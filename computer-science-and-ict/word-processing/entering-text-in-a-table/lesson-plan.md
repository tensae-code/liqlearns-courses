## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Typing into a cell** — Text is entered in a table **cell by cell**: click in a cell (or arrive in it) and type — the text belongs to that cell alone, wrapping inside its width and **growing the row's height** when it needs more room. A cell is a small page of its own: the writing rules of the document (spelling, formatting) apply inside it exactly as outside. Laos's order matters — the book enters text only after the table exists and its merges are made, because typing into a grid that will still change shape wastes the typing.
2. **Moving through the table — Tab** — The traveller's key is **Tab**: it moves the insertion point to the **next cell** — across the row, then down to the next row's start — selecting that cell's contents ready for replacement or typing. Tab in the **last cell creates a new row**, which is both a convenience and the classic accident: a stray Tab at the table's end grows a row nobody wanted, removed by Undo. The careful order the book teaches is the typist's rhythm: type, Tab, type, Tab — filling the grid in its reading order, so no cell is skipped and none is filled twice.
