# Entering Text in a Table — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) How is text entered in a table?**
a) Cell by cell — click or arrive in a cell and type  b) It wraps inside the cell and the row's height grows  c) A small page of its own — the document's rules apply inside it  d) Typing into a grid that will still change shape wastes the typing
**Answer: a**

**2. (Sub lesson 1) What happens when text outgrows a cell's width?**
a) A small page of its own — the document's rules apply inside it  b) It wraps inside the cell and the row's height grows  c) Typing into a grid that will still change shape wastes the typing  d) Tab
**Answer: b**

**3. (Sub lesson 1) What is a cell, for writing?**
a) Typing into a grid that will still change shape wastes the typing  b) Tab  c) A small page of its own — the document's rules apply inside it  d) Across the row, then down to the next row's start
**Answer: c**

**4. (Sub lesson 1) Why does the book enter text after merging?**
