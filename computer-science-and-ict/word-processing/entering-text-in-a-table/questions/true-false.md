# Entering Text in a Table — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Cell by cell — click or arrive in a cell and type**
**Answer: True**

**2. (Sub lesson 1) True or false: A small page of its own — the document's rules apply inside it** — as the answer to: What happens when text outgrows a cell's width?
**Answer: False — It wraps inside the cell and the row's height grows**

**3. (Sub lesson 1) True or false: A small page of its own — the document's rules apply inside it**
**Answer: True**

**4. (Sub lesson 1) True or false: Tab** — as the answer to: Why does the book enter text after merging?
**Answer: False — Typing into a grid that will still change shape wastes the typing**

**5. (Sub lesson 2) True or false: Tab**
**Answer: True**

**6. (Sub lesson 2) True or false: Creates a new row** — as the answer to: In which order does Tab travel?
**Answer: False — Across the row, then down to the next row's start**

**7. (Sub lesson 2) True or false: Creates a new row**
**Answer: True**

**8. (Sub lesson 2) True or false: Type, Tab, type, Tab — filling in reading order** — as the answer to: How is an accidental Tab-row removed?
**Answer: False — By Undo**

**9. (Sub lesson 2) True or false: Type, Tab, type, Tab — filling in reading order**
**Answer: True**

**10. (Sub lesson 1) True or false: Cell by cell — click or arrive in a cell and type** — as the answer to: Which chapter teaches this?
**Answer: False — Laos Grade 9 ICT, Chapter 4 §4.3**
