# Entering Text in a Table — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) How is text entered in a table?** → **Cell by cell — click or arrive in a cell and type**

**2. (Sub lesson 1) What happens when text outgrows a cell's width?** → **It wraps inside the cell and the row's height grows**

**3. (Sub lesson 1) What is a cell, for writing?** → **A small page of its own — the document's rules apply inside it**

**4. (Sub lesson 1) Why does the book enter text after merging?** → **Typing into a grid that will still change shape wastes the typing**

**5. (Sub lesson 2) Which key moves to the next cell?** → **Tab**

**6. (Sub lesson 2) In which order does Tab travel?** → **Across the row, then down to the next row's start**

**7. (Sub lesson 2) What does Tab do in the last cell?** → **Creates a new row**

**8. (Sub lesson 2) How is an accidental Tab-row removed?** → **By Undo**

**9. (Sub lesson 2) What rhythm does the book teach?** → **Type, Tab, type, Tab — filling in reading order**
