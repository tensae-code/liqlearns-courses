# Track Changes — Reviewing a Document Together — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does Track Changes do?" is: It marks every edit on the document instead of silently replacing text**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What kinds of change are marked?" is: A reviewer improves or questions the document without overwriting its author**
**Answer: False** — Insertions, deletions and formatting changes

**3. (Sub lesson 1) True or false: the answer to "How are changes shown?" is: In colour, with the changer's name — underlined, struck through or in the margin**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does a tracked document carry with it?" is: The change becomes plain text in the document**
**Answer: False** — Its own history of changes as it is reviewed

**5. (Sub lesson 1) True or false: the answer to "How is tracking like commenting?" is: A reviewer improves or questions the document without overwriting its author**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Who decides the fate of each tracked change?" is: All together at once, when the review is trusted**
**Answer: False** — The document's author

**7. (Sub lesson 2) True or false: the answer to "What does accepting a change do?" is: The change becomes plain text in the document**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does rejecting a change do?" is: It marks every edit on the document instead of silently replacing text**
**Answer: False** — The original words stand

**9. (Sub lesson 2) True or false: the answer to "How else can changes be accepted?" is: All together at once, when the review is trusted**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "How does Bhutan's Class VII use it at year's end?" is: In colour, with the changer's name — underlined, struck through or in the margin**
**Answer: False** — Peers review the end-of-year presentation with tracked changes and comments sent by email
