# Making a numbered list — multiple choice

Pick the one right answer.

**1.** A numbering style is chosen from —
a) the Bullets command  b) the Numbering command's options  c) the File tab  d) the ruler
**Answer: b) the Numbering command's options.**

**2.** The style families named are —
a) dots, dashes, stars  b) numbers, letters, Roman numerals  c) colours only  d) sizes
**Answer: b) numbers, letters, Roman numerals.**

**3.** Numbering is restarted by —
a) pressing Enter twice  b) right-clicking the list and choosing the restart option  c) saving the file  d) selecting all
**Answer: b) right-clicking the list and choosing the restart option.**

**4.** The restart rule holds for —
a) numeric lists only  b) alphabetical lists only  c) numeric and alphabetical lists alike  d) bulleted lists
**Answer: c) numeric and alphabetical lists alike.**

**5.** Before clicking a style, hovering —
a) saves it  b) shows a live preview  c) prints it  d) deletes the list
**Answer: b) shows a live preview.**

**6.** iii is a —
a) letter style  b) Roman numeral  c) bullet  d) page number format only
**Answer: b) Roman numeral.**
