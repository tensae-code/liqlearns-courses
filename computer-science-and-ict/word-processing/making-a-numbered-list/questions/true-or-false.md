# Making a numbered list — true or false

Say whether each sentence is true or false.

**1.** The same text can be numbered as 1,2,3 or A,B,C or i,ii,iii.
**Answer: True.**

**2.** Numbering can never be restarted once a list has begun.
**Answer: False — right-click the list and choose restart.**

**3.** A numbered list is made with the Bullets command.
**Answer: False — the Numbering command.**
