# Lesson plan — Formatting Word tables — styles and exact sizes

**Course:** Computer Science and ICT · **Title:** Word Processing · **Lesson:** Formatting Word tables — styles and exact sizes
**Place in the curriculum:** Unit 3 — Application Software, Grade 10 depth, in the Word Processing title of the Computer Science and ICT ladder (TITLES.md). The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** a table gets a preformatted look from the Table Styles gallery, and its exact size three ways — ruler markers, the Cell Size group, and the Table Properties dialog.
**This lesson's own level:** it is a doing-lesson. It stands on the table-creation lessons; this one dresses a table that already exists and sets its measurements exactly.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Table styles — a preformatted look in one pick** — pass mark: apply a Table Style from the Design tab gallery, with the insertion point in the table.
2. **Resizing — rulers, Cell Size, Table Properties** — pass mark: resize a table all three ways — ruler markers, typed Cell Size, and Table Properties.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Creating a Word table — drag and dialog box; Drawing a table — and using Quick Tables. Recommended, never forced.

## What the learner can do when it ends
1. Apply a style from the Table Styles gallery on the Table Tools Design tab.
2. Say that a style can be previewed, changed, modified or replaced by a new style.
3. Resize by dragging ruler markers.
4. Type exact sizes in the Cell Size group and in the Table Properties dialog.

## What you need
A computer with Word and a table already made.

## If the learner is stuck
- The Design tab is missing → the insertion point is not in the table; click inside the table first.
- A typed size does not hold → check you typed it in the Cell Size group (Layout tab) or the right row in Table Properties.
