# Formatting Word tables — styles and exact sizes

## Do it first

Your table holds the right words but looks plain and its columns are the wrong widths. Dress it in one pick, then measure it exactly — both jobs in this lesson.

## Sub lesson 1 — Table styles — a preformatted look in one pick

A preformatted look comes from the **Table Styles gallery**:

1. Place the **insertion point in the table**.
2. Open the **Table Tools Design tab** and its **Table Styles gallery** — plain, grid and list families.
3. **Pick a style** — the exercise applies a **grid accent** style. A style can be previewed before it is picked, changed afterwards, itself modified, or replaced by a new style you make.
4. Save the styled table as **Clients Table 5**.

Borders can also be formatted by hand from the **Borders group**, line by line.

## Sub lesson 2 — Resizing — rulers, Cell Size, Table Properties

Resizing is taught three ways:

1. **Ruler markers** — drag the column or row markers on the rulers.
2. **Cell Size group** — on the **Layout tab**, type the width or height; the exercise sets a column to **1.1″**.
3. **Table Properties dialog** — for exact measurements row by row; the exercise sets a row to **0.5″**.

Dragging is quick and seen; typing is exact. Use the dialog when every row must measure the same.

## Say it to your companion

Tell your companion where the Table Styles gallery lives, the three families in it, and the three ways to resize — saying which exercise measurement went with which way.

## Do It Yourself

1. Apply a grid accent style to a table and save it as Clients Table 5.
2. Set one column to 1.1″ in the Cell Size group on the Layout tab.
3. Set one row to 0.5″ in the Table Properties dialog.
