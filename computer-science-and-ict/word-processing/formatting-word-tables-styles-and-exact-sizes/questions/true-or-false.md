# Formatting Word tables — styles and exact sizes — true or false

Say true or false.

**1. (Sub lesson 1)** A table style can be previewed before it is picked.
**Answer: True**

**2. (Sub lesson 1)** Once applied, a style can never be changed.
**Answer: False** — it can be changed, modified, or replaced by a new style.

**3. (Sub lesson 2)** Dragging ruler markers is one of the three resizing ways.
**Answer: True**
