# Formatting Word tables — styles and exact sizes — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The Table Styles gallery is on —
a) the Home tab  b) the Table Tools Design tab  c) the View tab  d) the Mailings tab
**Answer: b) the Table Tools Design tab**

**2. (Sub lesson 1)** Before opening the gallery, place —
a) the mouse outside  b) the insertion point in the table  c) a page break  d) a header
**Answer: b) the insertion point in the table**

**3. (Sub lesson 1)** The style families named are —
a) plain, grid and list  b) bold, italic, underline  c) top, bottom, margins  d) portrait and landscape
**Answer: a) plain, grid and list**

**4. (Sub lesson 2)** Exact row-by-row measurements are set in —
a) the ruler only  b) the Table Properties dialog  c) the Borders group  d) Quick Tables
**Answer: b) the Table Properties dialog**

**5. (Sub lesson 2)** The Cell Size exercise sets a column to —
a) 0.5″  b) 1.1″  c) 2″  d) 5″
**Answer: b) 1.1″**
