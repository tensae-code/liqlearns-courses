# Writing in WordPad — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is WordPad?**
**Answer: A simple word processor built into Windows itself**

**2. (Sub lesson 1) Where is WordPad found?**
**Answer: Under Accessories in the Start menu**

**3. (Sub lesson 1) What does WordPad's window hold?**
**Answer: A menu bar, one toolbar, a ruler and a white page to type on**

**4. (Sub lesson 1) Why does Afghanistan's book teach WordPad before Word?**
**Answer: So the learner meets word processing first in the simplest program that has the ideas**

**5. (Sub lesson 1) What everyday writing can WordPad do?**
**Answer: Type and correct text, change size and boldness, line text up and change its colour**

**6. (Sub lesson 2) Where does typed text appear?**
**Answer: At the insertion point**

**7. (Sub lesson 2) How is text selected in WordPad?**
**Answer: By dragging over it**

**8. (Sub lesson 2) How is a document kept and brought back?**
**Answer: File → Save to keep it, File → Open to bring it back**

**9. (Sub lesson 2) What three things does WordPad not have?**
**Answer: A spell-checker, tables and page numbers**

**10. (Sub lesson 2) When does a job belong in Word instead?**
**Answer: When it needs the things WordPad does not have**
