# Writing in WordPad — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is WordPad?**
a) A simple word processor built into Windows itself  b) Under Accessories in the Start menu  c) A menu bar, one toolbar, a ruler and a white page to type on  d) So the learner meets word processing first in the simplest program that has the ideas
**Answer: a) A simple word processor built into Windows itself**

**2. (Sub lesson 1) Where is WordPad found?**
a) A menu bar, one toolbar, a ruler and a white page to type on  b) Under Accessories in the Start menu  c) So the learner meets word processing first in the simplest program that has the ideas  d) Type and correct text, change size and boldness, line text up and change its colour
**Answer: b) Under Accessories in the Start menu**

**3. (Sub lesson 1) What does WordPad's window hold?**
