# Writing in WordPad — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is WordPad?" is: A simple word processor built into Windows itself**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Where is WordPad found?" is: A menu bar, one toolbar, a ruler and a white page to type on**
**Answer: False** — Under Accessories in the Start menu

**3. (Sub lesson 1) True or false: the answer to "What does WordPad's window hold?" is: A menu bar, one toolbar, a ruler and a white page to type on**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Why does Afghanistan's book teach WordPad before Word?" is: Type and correct text, change size and boldness, line text up and change its colour**
**Answer: False** — So the learner meets word processing first in the simplest program that has the ideas

**5. (Sub lesson 1) True or false: the answer to "What everyday writing can WordPad do?" is: Type and correct text, change size and boldness, line text up and change its colour**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Where does typed text appear?" is: By dragging over it**
**Answer: False** — At the insertion point

**7. (Sub lesson 2) True or false: the answer to "How is text selected in WordPad?" is: By dragging over it**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How is a document kept and brought back?" is: A spell-checker, tables and page numbers**
**Answer: False** — File → Save to keep it, File → Open to bring it back

**9. (Sub lesson 2) True or false: the answer to "What three things does WordPad not have?" is: A spell-checker, tables and page numbers**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "When does a job belong in Word instead?" is: A simple word processor built into Windows itself**
**Answer: False** — When it needs the things WordPad does not have
