# Touch Typing — Correct Finger Placement on the Mongolian Keyboard — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Which keyboard layout does this lesson teach?" is: The Mongolian Cyrillic layout**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Where do the fingers rest?" is: Its own starting keys, returned to after every stroke**
**Answer: False** — On the home row — the middle letter row

**3. (Sub lesson 1) True or false: the answer to "What does each finger have on the home row?" is: Its own starting keys, returned to after every stroke**

**Answer: False** — A finger starting from home reaches its keys by the shortest road, and the eyes stay on the text
