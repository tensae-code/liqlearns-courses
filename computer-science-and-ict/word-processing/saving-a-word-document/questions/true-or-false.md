# Saving a word document — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** You should type the .docx suffix yourself.
**Answer: False** — Word adds it automatically.

**2. (Sub lesson 2)** The Desktop is a place you can save to through Browse.
**Answer: True** — Browse picks any location including the Desktop.

**3. (Sub lesson 1)** Unsaved work survives when the computer is switched off.
**Answer: False** — unsaved work is lost — save first.

**4. (Sub lesson 3)** In the five-step order, you give the file name before choosing where to save it.
**Answer: False** — choose where to save (Documents) first, then give the file name, then click Save.
