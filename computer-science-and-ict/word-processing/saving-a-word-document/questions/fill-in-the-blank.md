# Saving a word document — fill in the blank

Fill each blank with the right word.

**1. (Sub lesson 1)** For a first save: File → Save ______.
**Answer: As**

**2. (Sub lesson 2)** This PC → ______ is one home for a saved document.
**Answer: Documents**

**3. (Sub lesson 2)** Word automatically adds the .______ suffix to the name.
**Answer: docx**
