# Saving a word document — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A first save begins with —
a) File → Save As  b) closing the window  c) printing  d) File → New
**Answer: a) File → Save As** — File, then Save As, for a document with no home yet.

**2. (Sub lesson 1)** Save As asks two questions. They are —
a) who and when  b) where, and under what name  c) how long and how big  d) print or not
**Answer: b) where, and under what name** — place and name.

**3. (Sub lesson 2)** To keep the document with your documents, go —
a) This PC → Documents  b) Recycle Bin  c) Desktop only  d) Pictures
**Answer: a) This PC → Documents** — This PC, then Documents.

**4. (Sub lesson 2)** Browse lets you pick —
a) only Documents  b) any location, including the Desktop  c) only a USB disk  d) the internet
**Answer: b) any location, including the Desktop** — Browse reaches any location.

**5. (Sub lesson 2)** What does Word add to the name automatically?
a) .txt  b) .docx  c) .word  d) nothing
**Answer: b) .docx** — Word adds .docx by itself.

**6. (Sub lesson 1)** The right order for a first save is —
a) name, close, File  b) File → Save As → choose place → name  c) close → File → Save As  d) Desktop → File → Print
**Answer: b) File → Save As → choose place → name** — File, Save As, place, name.
