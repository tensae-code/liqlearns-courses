# Lesson plan — Saving a word document

**Course:** Computer Science and ICT · **Title:** Word Processing · **Lesson:** Saving a word document
**Place in the curriculum:** Title 5 — Word Processing in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 7 book, Unit 3 — Computer Software. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** first save, in the book's order: File → Save As; choose the location or drive; or This PC → Documents; or Browse to any location including the Desktop — and Word adds .docx to the name by itself.
**This lesson's own level:** it is a doing-lesson. It stands on opening Word and knowing its window — and it protects everything the learner writes from now on.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Save As — the first save** — File → Save As opens the saving dialogue for a document that has no home yet
2. **Choosing the place and the name** — choose the drive, or This PC → Documents, or Browse anywhere including the Desktop; Word adds .docx
3. **Saving with Save As — the five steps in order** — the Grade 8 growth, the same saving as one clean order: click the File tab; click Save As; choose where to save (Documents); give it a file name; click Save

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Opening a word processor, and The Word window — naming its parts.  Recommended, never forced.

## What the learner can do when it ends
1. Save a first document by File → Save As, in order.
2. Choose a location: a drive, This PC → Documents, or Browse to anywhere including the Desktop.
3. Say what Word adds to the name by itself: .docx.
4. Say why saving matters: work survives the computer being switched off.
5. Recite the Grade 8 five-step Save As order without looking.

## What you need
A computer with Word open and something typed in it.

## If the learner is stuck
- Closes Word and hopes → unsaved work is lost work; the save must come before the close, every time.
- Hunts for where to type .docx → you never type it; Word adds it automatically.
- Cannot find Documents → go This PC first, then Documents inside it.
