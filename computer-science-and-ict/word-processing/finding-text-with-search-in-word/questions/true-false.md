# Finding Text with Search in Word — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does Find do?" is: Looks through the whole document for the word or phrase you type**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Where is Find opened from?" is: It jumps to it and shows it selected in the text**
**Answer: False** — The Edit menu, or with Ctrl+F

**3. (Sub lesson 1) True or false: the answer to "How does Word show a found word?" is: It jumps to it and shows it selected in the text**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Why can Word promise not to miss an occurrence?" is: Takes you to each further occurrence in turn**
**Answer: False** — Because it compares every character in the document against the search text

**5. (Sub lesson 1) True or false: the answer to "What does Find Next do?" is: Takes you to each further occurrence in turn**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How do you know you have seen them all?" is: Changes each found occurrence into corrected text**
**Answer: False** — Word reports that it has finished searching the document

**7. (Sub lesson 2) True or false: the answer to "What does Replace do?" is: Changes each found occurrence into corrected text**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does Replace All do?" is: Check a few replacements with your own eyes first**
**Answer: False** — Changes all occurrences at once, in one pass

**9. (Sub lesson 2) True or false: the answer to "What is the care rule for Replace All?" is: Check a few replacements with your own eyes first**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why can Replace All go wrong?" is: Looks through the whole document for the word or phrase you type**
**Answer: False** — Word replaces exactly what you typed, including anywhere you did not mean
