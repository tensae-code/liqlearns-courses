# Cut and paste — moving text — ordering

Put each set in the right order.

**1. (Sub lesson 1)** The cut: choose Cut / select the text / the text waits on the clipboard.
**Answer: select the text → choose Cut → the text waits on the clipboard.**

**2. (Sub lesson 2)** The whole move: paste at the new place / select the text / place the insertion point / cut the text.
**Answer: select the text → cut the text → place the insertion point → paste at the new place.**
