# Cut and paste — moving text — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Cut and copy do exactly the same thing.
**Answer: False** — copy leaves the original standing; cut takes it away to move it.

**2. (Sub lesson 1)** Cut text is lost the moment it leaves the page.
**Answer: False** — it waits on the clipboard, ready to be pasted.

**3. (Sub lesson 2)** Cut and paste can move the same portion of text for as long as it remains on the clipboard.
**Answer: True** — that is how the move is carried through the document.
