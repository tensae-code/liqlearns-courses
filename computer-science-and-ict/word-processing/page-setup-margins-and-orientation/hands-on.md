# Hands-on — Page Setup — Margins and Orientation

The lesson with your hands, not only your eyes.

## Turn the page

Take a document with a wide table in it. Set it portrait and note how the table fits; turn it landscape and note the change. Write which orientation you would hand in, and why.

## Frame and columns

In one document, set all four margins, then set them narrower and watch the text area grow. Then put the text into two columns and practise reading it in the right order — down, then across.
