Placement choice: this lesson was built new for the ICT expansion (Uganda, 2026-11-14) because no existing lesson in the course covers this thing as its own lesson — the live tree was checked first: Word Processing holds lessons on opening, typing, formatting and tables, but none teaches page setup — orientation, margins and columns — as its own lesson. The placements file named this slug directly (NEW LESSON NEEDED — word-processing/page-setup-margins-and-orientation). It sits in the Word Processing title (word-processing/). It has three sub lessons: orientation first, then margins, then columns — three distinct sequential parts of setting up one page, each opening by proving the one before.

Uganda's own way: a slim activity-led prototype — every topic is an "Activity" learners do (assembling a real desktop, managing the Recycle Bin, word-processing a letter as the integration task), under Uganda's revised Lower Secondary Curriculum. This lesson keeps that shape: the learner does the thing with a real tool or document in front of them.

Rwanda's own way (S1 ICT Student Book, KLB): competency-based units each opening with a Key Unit Competency and keywords; a full GIS/ArcGIS unit and a Scratch music-making unit sit inside the first secondary year, and ICT use is grounded in Rwandan daily life.

Rwanda's own way (S1 ICT Teacher Guide, KLB): the guide mirrors the student units with content maps, additional teacher content per unit, SEN/multi-ability support, sample lesson plans (Appendix 1) and a glossary (Appendix 2); assessment is framed by Rwanda's competence-based curriculum.
