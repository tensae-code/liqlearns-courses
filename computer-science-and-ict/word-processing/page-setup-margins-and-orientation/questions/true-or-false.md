# Page Setup — Margins and Orientation — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Changing orientation late in a document reflows everything already placed.**
**Answer: True** — That is why orientation is set early, before careful formatting.

**2. (Sub lesson 2) A page has two margins.**
**Answer: False** — It has four: top, bottom, left and right, each set separately.

**3. (Sub lesson 2) Wider margins give the text a narrower area to fill.**
**Answer: True** — More blank frame means less room, so the words take more pages.

**4. (Sub lesson 3) Columns divide the text area inside the margins.**
**Answer: True** — Columns, margins and orientation are one page-setup decision.
