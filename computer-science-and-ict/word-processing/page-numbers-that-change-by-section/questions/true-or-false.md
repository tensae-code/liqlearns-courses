# Page numbers that change by section — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** The cover page carries no page number.
**Answer: True.**

**2. (Sub lesson 2)** Each section's footer must be unlinked from the one before.
**Answer: True — the second of the two tricks.**

**3. (Sub lesson 3)** If a footer stays linked, its section follows the previous section's numbering.
**Answer: True — that is why unlinking comes before formatting.**
