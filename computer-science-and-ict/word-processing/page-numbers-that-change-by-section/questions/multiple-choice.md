# Page numbers that change by section — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The front pages (acknowledgements and contents) are numbered in —
a) Arabic from 1  b) Roman numerals  c) letters  d) no numbers
**Answer: b) Roman numerals — i, ii, iii.**

**2. (Sub lesson 1)** Between each pair of sections must stand a —
a) page break  b) Section Break – Next Page  c) column break  d) table
**Answer: b) Section Break – Next Page.**

**3. (Sub lesson 2)** A section's footer is unlinked by clicking —
a) Link to Previous  b) Remove Header  c) Format Page Numbers  d) Show/Hide
**Answer: a) Link to Previous — on the Header & Footer Tools Design tab.**

**4. (Sub lesson 2)** Before inserting the breaks, you turn on —
a) Print Preview  b) Show/Hide  c) the ruler only  d) Read Mode
**Answer: b) Show/Hide — so the breaks are visible.**

**5. (Sub lesson 3)** Each section's format and starting number are set in —
a) Format Page Numbers  b) the status bar  c) the Bullets dialog  d) Save As
**Answer: a) Format Page Numbers.**

**6. (Sub lesson 3)** The main body's numbering is —
a) Roman continuing from the front pages  b) Arabic starting at 1  c) letters  d) none
**Answer: b) Arabic starting at 1.**
