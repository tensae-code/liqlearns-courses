# Lesson plan — Page numbers that change by section

**Course:** Computer Science and ICT · **Title:** Word Processing · **Lesson:** Page numbers that change by section
**Place in the curriculum:** Title 5 — Word Processing in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 9 book, Unit 3 — Application Software. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** a long document can number its parts differently — cover unnumbered, front pages in Roman numerals, body in Arabic from 1 — by standing a Section Break (Next Page) between sections and unlinking each section's footer from the one before.
**This lesson's own level:** it is the deepest page-number skill in the title, and it stands on teacher-guide evidence only: the student book teaches plain page numbers; this different-numbering craft is the guide's extra practical.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The two tricks and the breaks** — the two tricks stated — a Section Break – Next Page between each pair of sections, and each footer unlinked from the one before; Show/Hide on, cursor at a section's end, Page Layout → Breaks → Next Page
2. **Unlinking the footers** — in the next section's footer, on the Header & Footer Tools Design tab, click the highlighted Link to Previous to unlink it; repeat for the third section; Show/Hide off
3. **Numbering each section** — insert each section's numbers with Page Number, using Format Page Numbers to choose each section's format and starting number — Roman for the front pages, Arabic from 1 for the body, none for the cover

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Adding page numbers.  Recommended, never forced.

## What the learner can do when it ends
1. State the two tricks: section breaks between sections, footers unlinked.
2. Insert a Section Break (Next Page) from Page Layout → Breaks.
3. Unlink a footer with Link to Previous on the Header & Footer Tools Design tab.
4. Set each section's format and starting number in Format Page Numbers.

## What you need
A computer with Word and a document of at least three parts.

## If the learner is stuck
- Changed the cover's numbering and the body's changed too → that section's footer is still linked; click Link to Previous to unlink it before formatting its numbers.
- Cannot see where sections end → turn Show/Hide on; the breaks must be visible to be worked with.
- Body starts at the wrong number → Format Page Numbers sets the starting number as well as the format.
