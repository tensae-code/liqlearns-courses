# Lesson plan — Opening a word processor

**Course:** Computer Science and ICT · **Title:** Word Processing · **Lesson:** Opening a word processor
**Place in the curriculum:** Title 5 — Word Processing in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 7 book, Unit 3 — Computer Software. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** Microsoft Word 2016 opens three ways, in the book's order: Start menu → All Programs → Microsoft Office → Microsoft Word 2016; Search for 'word'; or double-click the desktop shortcut — and a blank document opens ready for text.
**This lesson's own level:** it is a doing-lesson — the first hands-on skill of the Word practical. It stands on knowing what word processing is.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Route 1 — through the Start menu** — Start → All Programs → Microsoft Office folder → Microsoft Word 2016
2. **Route 2 — through Search** — click Search, type 'word', choose Microsoft Word 2016 from the results
3. **Route 3 — the desktop shortcut** — double-click the Word shortcut on the desktop; a blank document opens ready for text
4. **Creating a document — the blank page and its first name** — the Grade 8 growth: clicking the word processor opens a blank document window; a new document's default name is DOCUMENT followed by a number; a saved document can later be opened on another computer

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Word processing — writing on a computer.  Recommended, never forced.

## What the learner can do when it ends
1. Open Word by the Start-menu route, in order.
2. Open Word by Search, typing 'word'.
3. Open Word by double-clicking the desktop shortcut.
4. Say what appears when Word opens: a blank document ready for text.
5. Say a new document's default name — DOCUMENT followed by a number — and that a saved document can later be opened on another computer.

## What you need
A computer with Microsoft Word 2016 — this lesson is learned by doing it.

## If the learner is stuck
- Lost in All Programs → look for the folder name: Microsoft Office; Word 2016 lives inside it.
- Single-clicks the desktop icon and waits → the shortcut needs a double-click: two quick clicks.
- Types the whole program name in Search → the book's search word is just 'word'.
