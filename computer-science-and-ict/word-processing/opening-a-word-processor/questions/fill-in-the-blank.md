# Opening a word processor — fill in the blank

Fill each blank with the right word.

**1. (Sub lesson 1)** Start menu → All ______ → Microsoft Office → Microsoft Word 2016.
**Answer: Programs**

**2. (Sub lesson 2)** Type ______ in Search and choose Microsoft Word 2016.
**Answer: word**

**3. (Sub lesson 3)** ______-click the Word shortcut on the desktop.
**Answer: Double**

**4. (Sub lesson 4)** A word processor lets changes be made ______ in the document.
**Answer: anywhere**

**5. (Sub lesson 5)** Method 1: Start → Microsoft Word ______ → Blank document.
**Answer: tile**
