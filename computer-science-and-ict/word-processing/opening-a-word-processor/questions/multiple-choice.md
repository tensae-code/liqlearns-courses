# Opening a word processor — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Route 1 begins by clicking —
a) Search  b) the Start menu  c) the desktop icon  d) File
**Answer: b) the Start menu** — Start menu first.

**2. (Sub lesson 1)** In route 1, Word 2016 is found inside —
a) the Recycle Bin  b) the Microsoft Office folder  c) the Pictures folder  d) Settings
**Answer: b) the Microsoft Office folder** — All Programs → Microsoft Office folder → Word 2016.

**3. (Sub lesson 2)** In route 2, you type —
a) microsoft word 2016 full name  b) word  c) document  d) letter
**Answer: b) word** — type 'word' and choose Word 2016 from the results.

**4. (Sub lesson 3)** The desktop shortcut opens with —
a) one slow click  b) a double-click  c) three clicks  d) the Enter key only
**Answer: b) a double-click** — double-click the shortcut.

**5. (Sub lesson 3)** When Word opens, you see —
a) an old document  b) a blank document ready for text  c) the desktop  d) a game
**Answer: b) a blank document ready for text** — a blank document, ready for text.

**6. (Sub lesson 1)** The full route 1 order is —
a) Start → Microsoft Office → All Programs → Word  b) Start → All Programs → Microsoft Office → Word 2016  c) Search → Start → Word  d) Desktop → Start → Word
**Answer: b) Start → All Programs → Microsoft Office → Word 2016** — Start, All Programs, Microsoft Office folder, Word 2016.
