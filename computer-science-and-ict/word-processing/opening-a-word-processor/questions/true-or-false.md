# Opening a word processor — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Route 1 goes through All Programs.
**Answer: True** — Start → All Programs → Microsoft Office → Word.

**2. (Sub lesson 2)** In Search you must type the whole name 'Microsoft Word 2016'.
**Answer: False** — the book's search word is 'word'.

**3. (Sub lesson 3)** A blank document opens ready for text.
**Answer: True** — that is what waits at the end of every route.

**4. (Sub lesson 4)** When the word processor is clicked, a blank document window appears.
**Answer: True** — that blank window is the new document.
