# Clip art and shapes in a document — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Clip art is —
a) a drawn shape  b) ready-made imagery  c) a screenshot  d) a page style
**Answer: b) ready-made imagery**

**2. (Sub lesson 1)** In the task pane route you insert a result by —
a) dragging it  b) double-clicking it  c) copying its name  d) saving it first
**Answer: b) double-clicking it**

**3. (Sub lesson 2)** A perfect circle is drawn by holding —
a) Ctrl  b) Alt  c) Shift  d) Esc
**Answer: c) Shift** — while dragging.

**4. (Sub lesson 2)** Lock Drawing Mode keeps —
a) the document locked  b) the chosen shape armed for repeated drawing  c) the shape's size fixed  d) text locked
**Answer: b) the chosen shape armed for repeated drawing**

**5. (Sub lesson 2)** The closing practical is saved as —
a) Table 3  b) Green Legacy  c) Eagle  d) Calendar
**Answer: c) Eagle**
