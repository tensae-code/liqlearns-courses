# Printing a Document — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Where is the Print command?" is: In the File menu**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does the print preview show?" is: The printer, the pages, and the number of copies**
**Answer: False** — The document exactly as it will come out, page by page

**3. (Sub lesson 1) True or false: the answer to "What three choices do you make before printing?" is: The printer, the pages, and the number of copies**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How do you print only pages 2 to 4?" is: Mistakes are caught while they still cost no paper**
**Answer: False** — Enter the range 2–4 in the pages box

**5. (Sub lesson 1) True or false: the answer to "Why check the preview first?" is: Mistakes are caught while they still cost no paper**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What shows that a print job is waiting?" is: The printer is on, it has paper, and it is the one you chose**
**Answer: False** — The printer icon and the print queue

**7. (Sub lesson 2) True or false: the answer to "Name the first checks when nothing prints." is: The printer is on, it has paper, and it is the one you chose**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Where can a mistaken job be cancelled?" is: In order, first page to last**
**Answer: False** — In the print queue

**9. (Sub lesson 2) True or false: the answer to "In what order do the pages come out?" is: In order, first page to last**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why must you not click Print again and again?" is: In the File menu**
**Answer: False** — Each click adds another copy of the job to the queue
