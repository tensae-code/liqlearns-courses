## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Setting the password — the document locks its door** — A document is protected from Word's save and security options: while saving, choose to **encrypt the document with a password** — type the password, type it again to confirm, and save. From then on, opening the file asks for the password first; the words cannot be read, copied or changed without it. Bhutan's food-chain project is protected exactly this way before it is emailed to the teacher.
2. **Keeping the password — the key you must not lose** — A password protects only if it is **kept secret and remembered**: shared with no one who should not read the document, and stored where its owner can recover it. A forgotten document password locks out the owner too — Word cannot open what even its maker cannot unlock. The class rule: protect only what needs protecting, choose a password you can remember, and never write it on the document itself.
