# Video script — Protecting a Word Document with a Password

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A document is protected from Word's save and security options: while saving, choose to **encrypt the document with a password** — type the password, type it again to confirm, and save. From then on, opening the file asks for the password first; the words cannot be read, copied or changed without it. Bhutan's food-chain project is protected exactly this way before it is emailed to the teacher.
A password protects only if it is **kept secret and remembered**: shared with no one who should not read the document, and stored where its owner can recover it. A forgotten document password locks out the owner too — Word cannot open what even its maker cannot unlock. The class rule: protect only what needs protecting, choose a password you can remember, and never write it on the document itself.
