# Protecting a Word Document with a Password — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does a document password do?" is: It stops the file opening for anyone who does not know the password**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Where is the password set?" is: The Class VI food-chain document, before it is emailed to the teacher**
**Answer: False** — In Word's save and security options — encrypt document with a password

**3. (Sub lesson 1) True or false: the answer to "Why is the password typed twice?" is: To confirm it was typed as intended**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What happens when a protected file is opened?" is: The owner is locked out too — the document cannot be opened**
**Answer: False** — It asks for the password before showing anything

**5. (Sub lesson 1) True or false: the answer to "Which Bhutan project is protected this way?" is: The Class VI food-chain document, before it is emailed to the teacher**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Who may a document password be shared with?" is: On the document itself**
**Answer: False** — No one who should not read the document

**7. (Sub lesson 2) True or false: the answer to "What happens if the owner forgets the password?" is: The owner is locked out too — the document cannot be opened**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Which documents should be protected?" is: It stops the file opening for anyone who does not know the password**
**Answer: False** — Only those that need protecting

**9. (Sub lesson 2) True or false: the answer to "Where must a password never be written?" is: On the document itself**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What kind of password should be chosen?" is: To confirm it was typed as intended**
**Answer: False** — One the owner can remember but others cannot guess
