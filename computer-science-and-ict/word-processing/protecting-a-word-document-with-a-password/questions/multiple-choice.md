# Protecting a Word Document with a Password — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does a document password do?**
a) It stops the file opening for anyone who does not know the password  b) In Word's save and security options — encrypt document with a password  c) To confirm it was typed as intended  d) It asks for the password before showing anything
**Answer: a) It stops the file opening for anyone who does not know the password**

**2. (Sub lesson 1) Where is the password set?**
a) To confirm it was typed as intended  b) In Word's save and security options — encrypt document with a password  c) It asks for the password before showing anything  d) The Class VI food-chain document, before it is emailed to the teacher
**Answer: b) In Word's save and security options — encrypt document with a password**

**3. (Sub lesson 1) Why is the password typed twice?**
a) It asks for the password before showing anything  b) The Class VI food-chain document, before it is emailed to the teacher  c) To confirm it was typed as intended  d) No one who should not read the document
**Answer: c) To confirm it was typed as intended**

**4. (Sub lesson 1) What happens when a protected file is opened?**
a) The Class VI food-chain document, before it is emailed to the teacher  b) No one who should not read the document  c) The owner is locked out too — the document cannot be opened  d) It asks for the password before showing anything
**Answer: d) It asks for the password before showing anything**

**5. (Sub lesson 1) Which Bhutan project is protected this way?**
a) The Class VI food-chain document, before it is emailed to the teacher  b) No one who should not read the document  c) The owner is locked out too — the document cannot be opened  d) Only those that need protecting
**Answer: a) The Class VI food-chain document, before it is emailed to the teacher**

**6. (Sub lesson 2) Who may a document password be shared with?**
a) The owner is locked out too — the document cannot be opened  b) No one who should not read the document  c) Only those that need protecting  d) On the document itself
**Answer: b) No one who should not read the document**

**7. (Sub lesson 2) What happens if the owner forgets the password?**
a) Only those that need protecting  b) On the document itself  c) The owner is locked out too — the document cannot be opened  d) One the owner can remember but others cannot guess
**Answer: c) The owner is locked out too — the document cannot be opened**

**8. (Sub lesson 2) Which documents should be protected?**
a) On the document itself  b) One the owner can remember but others cannot guess  c) It stops the file opening for anyone who does not know the password  d) Only those that need protecting
**Answer: d) Only those that need protecting**

**9. (Sub lesson 2) Where must a password never be written?**
a) On the document itself  b) One the owner can remember but others cannot guess  c) It stops the file opening for anyone who does not know the password  d) In Word's save and security options — encrypt document with a password
**Answer: a) On the document itself**

**10. (Sub lesson 2) What kind of password should be chosen?**
a) It stops the file opening for anyone who does not know the password  b) One the owner can remember but others cannot guess  c) In Word's save and security options — encrypt document with a password  d) To confirm it was typed as intended
**Answer: b) One the owner can remember but others cannot guess**
