# Protecting a Word Document with a Password — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does a document password do?**
**Answer: It stops the file opening for anyone who does not know the password**

**2. (Sub lesson 1) Where is the password set?**
**Answer: In Word's save and security options — encrypt document with a password**

**3. (Sub lesson 1) Why is the password typed twice?**
**Answer: To confirm it was typed as intended**

**4. (Sub lesson 1) What happens when a protected file is opened?**
**Answer: It asks for the password before showing anything**

**5. (Sub lesson 1) Which Bhutan project is protected this way?**
**Answer: The Class VI food-chain document, before it is emailed to the teacher**

**6. (Sub lesson 2) Who may a document password be shared with?**
**Answer: No one who should not read the document**

**7. (Sub lesson 2) What happens if the owner forgets the password?**
**Answer: The owner is locked out too — the document cannot be opened**

**8. (Sub lesson 2) Which documents should be protected?**
**Answer: Only those that need protecting**

**9. (Sub lesson 2) Where must a password never be written?**
**Answer: On the document itself**

**10. (Sub lesson 2) What kind of password should be chosen?**
**Answer: One the owner can remember but others cannot guess**
