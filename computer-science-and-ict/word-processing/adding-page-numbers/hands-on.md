# Hands-on — Adding page numbers

The lesson with your hands, not only your eyes.

## Three places

Number the same document three times in a row — Top of Page, then Bottom of Page, then Page Margins — removing each before the next. Write down which you would choose for a school report and why.

## Restart hunt

Find where numbering can be restarted (the Page Number menu's format options) and write the route down. You will need it when a document's parts are numbered differently.

## The Eagle practical (Grade 10 depth)

Reopen your Eagle document. Add page numbers with a header and a footer. Hide the number on the first page only. Save. Then check by scrolling: page one bare, every later page numbered.
