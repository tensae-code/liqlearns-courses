# Adding page numbers — ordering

Put each set in the right order.

**1.** The insertion in order: press Esc / choose Bottom of Page and a style / open Insert → Page Number / make a multi-page document.
**Answer: make a multi-page document → open Insert → Page Number → choose Bottom of Page and a style → press Esc.**

**2.** Editing later: unlock the footer / make the change / lock it again with Esc.
**Answer: unlock the footer → make the change → lock it again with Esc.**
