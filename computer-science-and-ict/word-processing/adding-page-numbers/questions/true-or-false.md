# Adding page numbers — true or false

Say whether each sentence is true or false.

**1.** Page numbers can be restarted where pages must be numbered differently.
**Answer: True.**

**2.** Page numbers are usually placed in the header, footer or side margins.
**Answer: True.**

**3.** You type each page's number by hand at its foot.
**Answer: False — they are inserted once and appear on every page.**
