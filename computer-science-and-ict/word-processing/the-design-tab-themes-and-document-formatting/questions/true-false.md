# The Design Tab — Themes and Document Formatting — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Where is a document's overall look set?" is: On the Design tab**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is a theme?" is: Headings, text and tables**
**Answer: False** — A ready-made matching set of colours, fonts and effects

**3. (Sub lesson 1) True or false: the answer to "How much of the document does a theme apply to?" is: The whole document, in one choice**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What agrees with each other under a theme?" is: The whole document changes with it**
**Answer: False** — Headings, text and tables

**5. (Sub lesson 1) True or false: the answer to "Name two things a theme sets." is: Colours and fonts**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What happens when you change the theme?" is: It formats the whole document at once, not one piece at a time**
**Answer: False** — The whole document changes with it

**7. (Sub lesson 2) True or false: the answer to "What page-level things are set from the Design tab?" is: The page background and borders**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How is the Design tab different from the Home tab?" is: Grade 8**
**Answer: False** — It formats the whole document at once, not one piece at a time

**9. (Sub lesson 2) True or false: the answer to "In which order does Iraq's book teach the tabs?" is: Tab by tab — Home, Insert, Design, Layout**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Which grade's book teaches the Design tab?" is: A ready-made matching set of colours, fonts and effects**
**Answer: False** — Grade 8
