## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Dzongkha on the computer — keyboard software and fonts** — Dzongkha script cannot be typed with an English-only setup: the computer needs **Dzongkha keyboard software**, which maps the keys to Dzongkha characters, and **Dzongkha fonts**, which draw those characters correctly on the screen and on paper. With both installed, the pupil selects Dzongkha as the typing language and the same keys now write Dzongkha — the machine has learned the country's script.
2. **Typing Dzongkha in Word** — In **Word**, a Dzongkha document is made like any document: choose the Dzongkha font, type, save with a clear name. The new cares are script cares — characters must stack and join as Dzongkha writing requires, so the typist checks the screen as they go and corrects at once. Class V ends its year with a Dzongkha story in Word: the national language, typed by the pupil's own hands, filed like every other piece of work.
