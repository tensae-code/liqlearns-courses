# Video script — Creating a Word table — drag and dialog box

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Open Word. Insert tab. Table.
See the grid? Drag across it. Five across, two down.
Let go — there is your table! Rows. Columns. Where they meet: a cell.
Again — the exact way. Insert Table, under the grid.
Type the numbers: nine columns, three rows. Confirm.
A bigger table, exactly the size you typed.
Drag for quick. Type for exact.
Two tables in one page? Leave a blank line between them, or they join.
Save the first as Table 1. Save the second as Table 2.
