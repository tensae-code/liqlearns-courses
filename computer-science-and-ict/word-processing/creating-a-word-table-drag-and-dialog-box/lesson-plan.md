# Lesson plan — Creating a Word table — drag and dialog box

**Course:** Computer Science and ICT · **Title:** Word Processing · **Lesson:** Creating a Word table — drag and dialog box
**Place in the curriculum:** Unit 3 — Application Software, Grade 10 depth, in the Word Processing title of the Computer Science and ICT ladder (TITLES.md). The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** a table is made two ways — dragging over the Insert Table grid to the size wanted, and typing the numbers of columns and rows in the Insert Table dialog box.
**This lesson's own level:** it is a doing-lesson. It stands on the Word window and saving a document — the table is built inside a document and saved under its own name.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Dragging over the grid** — pass mark: create a table by dragging over the grid to a stated size, and name rows, columns and cells.
2. **The Insert Table dialog box** — pass mark: create a table by typing exact column and row numbers in the dialog box, with its AutoFit behaviour set.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: The Word window; Saving a Word document. Recommended, never forced.

## What the learner can do when it ends
1. Say what rows, columns and cells are, and name three jobs tables do.
2. Create a table by dragging over the grid to an exact size.
3. Create a table by typing column and row numbers in the Insert Table dialog box.
4. Keep separate tables apart with blank lines, and save each table under its name.

## What you need
A computer with Word.

## If the learner is stuck
- The grid closes before the size is right → reopen Insert → Table and drag slowly; the size shows as you drag.
- Two tables join into one → there is no blank line between them; click between them and press Enter.
