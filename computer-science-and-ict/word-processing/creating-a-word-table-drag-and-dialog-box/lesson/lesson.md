# Creating a Word table — drag and dialog box

## Do it first

You need a price list: five items across, two rows down — names in one row, prices in the other. Typing it with spaces will never line up. Make it as a table instead — first by dragging, then by numbers.

## Sub lesson 1 — Dragging over the grid

A **table** arranges data in horizontal **rows** and vertical **columns**; where a row and a column meet is a **cell**. Tables organise information, align numbers and build page layouts — calendars, invoices and contact lists are the book's examples.

Make the first table by dragging, in order:

1. Click the **Insert tab**.
2. In the **Tables group**, click the **Table button** — a grid opens.
3. **Drag over the grid** to the size wanted — for the exercise, **5 columns × 2 rows**.
4. Release — the table lands in the document.
5. Save it as **Table 1**.

Keep **blank lines between separate tables** in one document, so two tables do not join into one.

## Sub lesson 2 — The Insert Table dialog box

The second route types the size instead of dragging it:

1. Open **Insert → Table** as before.
2. Under the grid, click **Insert Table** — the dialog box opens.
3. Type the **number of columns** and the **number of rows** — for the exercise, **9 columns × 3 rows**.
4. Set the **AutoFit behaviour** the exercise asks for, and confirm.
5. Save the result as **Table 2**.

Dragging is quicker for a small table you can see; the dialog box is exact when the size is large or known in numbers.
