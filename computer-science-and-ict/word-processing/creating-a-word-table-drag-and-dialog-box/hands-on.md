# Hands-on — Creating a Word table — drag and dialog box

The lesson with your hands, not only your eyes.

## Drag, then numbers

Build one table by dragging and the same table again from the dialog box. Say which route felt exact, and which felt quick — and why.

## A real list

Make a table for something real: five school subjects across, two rows — subject and teacher. Save it under a name that says what it is.
