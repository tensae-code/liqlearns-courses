# Creating a Word table — drag and dialog box — true or false

Say true or false.

**1. (Sub lesson 1)** Separate tables in one document are kept apart by blank lines between them.
**Answer: True**

**2. (Sub lesson 2)** The Insert Table dialog box is found under the grid in Insert → Table.
**Answer: True**

**3. (Sub lesson 1)** A cell is a whole row.
**Answer: False** — a cell is where one row and one column meet.
