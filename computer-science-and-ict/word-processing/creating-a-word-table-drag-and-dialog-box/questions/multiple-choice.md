# Creating a Word table — drag and dialog box — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A table's rows run —
a) up and down  b) across  c) in circles  d) diagonally
**Answer: b) across** — rows are horizontal; columns are vertical.

**2. (Sub lesson 1)** Where a row and a column meet is a —
a) grid  b) tab  c) cell  d) ruler
**Answer: c) cell**

**3. (Sub lesson 1)** The drag route starts on —
a) the Home tab  b) the Insert tab, Tables group, Table button  c) the View tab  d) the File menu
**Answer: b) the Insert tab, Tables group, Table button**

**4. (Sub lesson 2)** In the dialog-box route you type —
a) the table's name only  b) the numbers of columns and rows  c) the page size  d) the font size
**Answer: b) the numbers of columns and rows**

**5. (Sub lesson 2)** The dialog-box exercise in the book makes —
a) 5×2  b) 2×5  c) 9×3  d) 3×9
**Answer: c) 9×3** — saved as Table 2.
