# Templates and Forms — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does a template save?" is: A document's skeleton — layout, styles and standard text**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What happens when you create a document from a template?" is: The pattern keeps every document identical and saves the design work**
**Answer: False** — The skeleton is copied; the template stays untouched

**3. (Sub lesson 1) True or false: the answer to "Can you make your own template?" is: Yes — save any designed document as a template**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Name two things a skeleton can hold." is: Text fields and drop-down lists (any two from the lesson)**
**Answer: False** — Margins and styles (any two from the lesson)

**5. (Sub lesson 1) True or false: the answer to "Why not start from blank each time?" is: The pattern keeps every document identical and saves the design work**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is a form in Word?" is: So it cannot be accidentally broken while completed**
**Answer: False** — A document built to be filled in

**7. (Sub lesson 2) True or false: the answer to "Name two content controls." is: Text fields and drop-down lists (any two from the lesson)**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does protection do in a form?" is: A document's skeleton — layout, styles and standard text**
**Answer: False** — Locks everything except the fill-in fields

**9. (Sub lesson 2) True or false: the answer to "Why must a form resist its filler-in?" is: So it cannot be accidentally broken while completed**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Who uses forms like these?" is: Yes — save any designed document as a template**
**Answer: False** — Schools, offices and clinics
