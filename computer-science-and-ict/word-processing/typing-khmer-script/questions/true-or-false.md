# Typing Khmer Script — true or false

Say whether each statement is true or false.

**1. If Latin letters appear when you type, the computer is already set to Khmer script.**
**Answer: False** — Another script appearing means the switch to Khmer script has not happened yet; switch and test again.

**2. Checking each short part against the copy is part of the typing, not an extra.**
**Answer: True** — Read a part, type it, check it: that is the session's way.

**3. A correct line typed slowly is a better result in this session than a fast line full of mistakes.**
**Answer: True** — Accuracy first; speed follows from practising accurate typing.

**4. Once the whole line is typed, there is no need to read it back against the copy.**
**Answer: False** — The finished line is read back against the copy from the start as the final check.
