# Typing Khmer Script — short answer

Answer in a sentence or two.

**1. A learner types and a different script appears on the page. What has gone wrong, and what should they do?**
**Answer:** The computer's typing is still set to the other script. They should switch the typing to Khmer script and prove the switch by pressing a key and seeing Khmer script appear, before typing the line.

**2. Describe the check-and-correct habit this session teaches.**
**Answer:** Type in short parts; after each part, compare what is on the screen with the copy — same script, same order, nothing missing or extra — and correct a wrong part at once, before moving on.

**3. Why does this session put accuracy before speed?**
**Answer:** Because speed built on mistakes only practises the mistakes; when the typing is accurate and practised, the hands learn the keys and speed follows on its own.
