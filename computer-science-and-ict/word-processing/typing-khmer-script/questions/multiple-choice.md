# Typing Khmer Script — multiple choice

Pick the one right answer.

**1. The first step in typing Khmer script on a computer is —**
a) typing as fast as you can  b) switching the computer's typing to Khmer script  c) opening a picture program
**Answer: b) switching the computer's typing to Khmer script** — The computer types in the script it is set to.

**2. How do you prove the switch worked?**
a) Press a key and check that Khmer script appears on the page  b) Close the program  c) Turn the screen off and on
**Answer: a) Press a key and check that Khmer script appears**

**3. The session's way of typing a practice line is —**
a) all at once without looking  b) in short parts: read a part, type it, check it against the copy, then continue  c) copying only the first and last parts
**Answer: b) in short parts, checking each part against the copy**

**4. A part you typed does not match the copy. You —**
a) leave it and hope  b) delete the whole page  c) correct that part at once, while you know which keys made it
**Answer: c) correct that part at once**

**5. Speed in this session comes —**
a) before accuracy  b) after accuracy, from practising the correct typing day after day  c) from pressing keys harder
**Answer: b) after accuracy, from practice**
