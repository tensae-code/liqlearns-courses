# Lesson plan — Typing Khmer Script

**Course:** Computer Science and ICT · **Title:** Word Processing · **Lesson:** Typing Khmer Script
**Place in the curriculum:** ICT expansion — Cambodia (2026-11-14) — in the title Word Processing on the ICT course ladder (TITLES.md). Built new from Cambodia's *Information and Communication Technology, Grade 10*, because no existing lesson teaches this thing as its own lesson.
**The one thing this lesson teaches:** To type in Khmer script on a computer, you first switch the computer's typing to Khmer script, then type slowly key by key while watching the script build on the screen, checking each part against the copy in front of you and correcting a wrong part at once — the same careful copying habit, practised until the hands know the keys.
**This lesson's own level:** It stands on opening a text-editing program and typing ordinary text; the Khmer-script session itself — switching, typing and checking — is built inside the lesson. It is one short, single-skill lesson.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Before this lesson
- Recommended first: Word Processing and Typing Text — The Insertion Point in Word Processing. Recommended, never forced — a learner may land on this lesson directly, and it stands alone.
- Cambodia's own way is kept: in Cambodia's Grade 10 book this is its own dedicated session (Chapter 1 Lesson 3 Session 3, Typing Khmer) — Khmer script is not an afterthought added to a Latin-script lesson; it is taught in its own right, in the language the learners write at school and at work.

## What the learner can do when it ends
1. Switch the computer's typing to Khmer script before typing, and say how they know the switch worked.
2. Type a given line of Khmer script slowly, watching the script build on the screen.
3. Check what they typed against the copy, part by part, and correct a wrong part at once.
4. Say why accuracy comes before speed in this session, and how speed is earned.

## What you need
A computer with a text-editing program open (the book's course works in OpenOffice Writer) and Khmer-script typing available on it, and a printed line of Khmer script to copy — the practice line in this lesson is the title line of Cambodia's Grade 10 book itself: បច្ចេកវិទ្យាព័ត៌មាន និងសារគមនាគមន៍ ថ្នាក់ទី ១០.

## If the learner is stuck
Types and Latin letters appear → the computer is still set to the other script; switch the typing to Khmer script first, and check by typing one character before going on. Loses their place in the copy → work in short parts: read one part, type it, check it against the copy, only then move on. Chases speed and the errors grow → slow down on purpose; in this session a correct line typed slowly is the pass, and speed only counts when it is accurate.
