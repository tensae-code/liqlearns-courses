# The Word window — naming its parts — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The title bar shows —
a) the page number only  b) the program and document titles  c) the zoom level  d) the ruler
**Answer: b) the program and document titles** — top centre: program and document titles.

**2. (Sub lesson 1)** Save, Undo and Repeat sit by default on the —
a) status bar  b) Quick Access Toolbar  c) ruler  d) File tab only
**Answer: b) Quick Access Toolbar** — the Quick Access Toolbar keeps them always in reach.

**3. (Sub lesson 2)** The Ribbon is —
a) a measuring line  b) a band of buttons grouped in tabs by task  c) the white page  d) the zoom control
**Answer: b) a band of buttons grouped in tabs by task** — buttons grouped by task, changing with the tab.

**4. (Sub lesson 2)** Margins, tabs, indents and columns are set against the —
a) title bar  b) rulers  c) status bar  d) Help
**Answer: b) rulers** — the rulers measure the page.

**5. (Sub lesson 3)** How many view buttons does the book name?
a) Three  b) Five  c) Two  d) Seven
**Answer: b) Five** — Print Layout, Full Screen Reading, Web Layout, Outline, Draft.

**6. (Sub lesson 3)** The File tab holds —
a) only Print  b) Save, Save As, Open, Close, Info, Recent, New, Print  c) only games  d) the rulers
**Answer: b) Save, Save As, Open, Close, Info, Recent, New, Print** — the whole file-handling list lives behind File.

**7. (Sub lesson 4)** The Quick Access Toolbar holds by default —
a) Save, Undo and Redo  b) Print, Close and Exit  c) the rulers  d) the zoom only
**Answer: a) Save, Undo and Redo** — and a pull-down adds more.

**8. (Sub lesson 4)** The blinking line where typed text lands is the —
a) I-beam Pointer  b) Scroll Bar  c) Insertion Point (Cursor)  d) Status Bar
**Answer: c) Insertion Point (Cursor).**

**9. (Sub lesson 4)** On a smaller monitor, the Ribbon —
a) disappears  b) compresses its arrangement  c) prints itself  d) moves to the bottom
**Answer: b) compresses its arrangement.**
