# Lesson plan — The Word window — naming its parts

**Course:** Computer Science and ICT · **Title:** Word Processing · **Lesson:** The Word window — naming its parts
**Place in the curriculum:** Title 5 — Word Processing in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 7 book, Unit 3 — Computer Software. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** every part of the Word window has a name and a job — title bar, tabs, Quick Access Toolbar, Ribbon, view buttons, rulers, Help, zoom, status bar, document area and the File tab.
**This lesson's own level:** it stands on the opening lesson — the window must be open before its parts can be named. It is learned by pointing, on a real window.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The top of the window** — title bar, menu bar / tabs and the Quick Access Toolbar
2. **The working middle** — the Ribbon, the rulers and the document area
3. **The bottom and the File tab** — view buttons, zoom control, status bar — and the File tab's list

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Opening a word processor.  Recommended, never forced.

## What the learner can do when it ends
1. Point to and name: title bar, tabs, Quick Access Toolbar, Ribbon, rulers, document area.
2. Name the three default Quick Access buttons: Save, Undo, Repeat.
3. Name the five views: Print Layout, Full Screen Reading, Web Layout, Outline, Draft.
4. List what the File tab holds: Save, Save As, Open, Close, Info, Recent, New, Print.

## What you need
A computer with Word open — naming is learned by pointing at the real window.

## If the learner is stuck
- Mixes Ribbon and tabs → the tabs are the labels; the Ribbon is the band of buttons that changes when you click a tab.
- Cannot find Save → two homes: the Quick Access Toolbar (always visible) and the File tab.
