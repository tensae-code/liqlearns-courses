# The Layout Tab — Margins and Page Setup — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does the Layout tab hold?" is: Page setup**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is page setup?" is: The page stands tall**
**Answer: False** — How the document sits on its paper

**3. (Sub lesson 1) True or false: the answer to "Name two things page setup decides." is: The paper's size and the page orientation**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is portrait orientation?" is: The blank borders between the text and the paper's edges**
**Answer: False** — The page stands tall

**5. (Sub lesson 1) True or false: the answer to "What is landscape orientation?" is: The page lies wide**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What are margins?" is: Paragraph spacing — the space before and after paragraphs**
**Answer: False** — The blank borders between the text and the paper's edges

**7. (Sub lesson 2) True or false: the answer to "How much of the document do margin settings cover?" is: The whole document at once**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What paragraph setting does the Layout tab also carry?" is: Grade 8**
**Answer: False** — Paragraph spacing — the space before and after paragraphs

**9. (Sub lesson 2) True or false: the answer to "When should page setup be decided?" is: Before printing, not after**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Which grade's book teaches the Layout tab?" is: How the document sits on its paper**
**Answer: False** — Grade 8
