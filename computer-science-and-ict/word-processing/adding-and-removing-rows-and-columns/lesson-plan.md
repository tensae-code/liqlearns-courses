# Lesson plan — Adding and removing rows and columns

**Course:** Computer Science and ICT · **Title:** Word Processing · **Lesson:** Adding and removing rows and columns
**Place in the curriculum:** Unit 3 — Application Software, Grade 10 depth, in the Word Processing title of the Computer Science and ICT ladder (TITLES.md). The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** rows and columns are added with the on-table insert control — grey until focused, blue when live — and removed with the ribbon's Delete tool or the right-click Delete Rows / Delete Columns.
**This lesson's own level:** it is a doing-lesson. It stands on the table-creation lessons; the table already exists and now changes size from inside.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Adding — the insert control** — pass mark: add a row below and a column to the right with the insert control.
2. **Deleting — and resizing the whole table** — pass mark: delete rows and columns both ways, and resize the whole table by its handle.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Creating a Word table — drag and dialog box. Recommended, never forced.

## What the learner can do when it ends
1. Add a row or column with the insert control, without selecting first.
2. Tell grey (not focused) from blue (live) on the insert control.
3. Delete rows and columns from the ribbon Delete tool and from the right-click menu.
4. Resize the whole table by its bottom-right handle.

## What you need
A computer with Word and a table already made.

## If the learner is stuck
- No insert control appears → hover exactly on the left or top border, between two rows or columns.
- Deleted the wrong row → undo at once; the book practises by demonstrating, then undoing.
