# Word processing — writing on a computer — multiple choice

Pick the one right answer.

**1.** A word processor lets users —
a) only type  b) create, edit, format and save documents  c) only print  d) repair hardware
**Answer: b) create, edit, format and save documents** — the four verbs of the definition.

**2.** Which can be added to a document?
a) Images, tables and charts  b) Only more paper  c) Sound only  d) Nothing
**Answer: a) Images, tables and charts** — images, tables and charts are named.

**3.** Compared with pen and paper, word-processed text is —
a) harder to read  b) more readable and clearer, with fewer errors  c) always wrong  d) invisible
**Answer: b) more readable and clearer, with fewer errors** — readable, clearer, fewer errors.

**4.** Correcting an error in a word processor —
a) means rewriting the page  b) is easy — you change the word  c) is impossible  d) needs a new computer
**Answer: b) is easy — you change the word** — easier correction is the named advantage.

**5.** Formatting a document means —
a) deleting it  b) shaping how it looks  c) losing it  d) printing it twice
**Answer: b) shaping how it looks** — format is one of the four verbs — shaping the document.

**6.** Saving a document means —
a) keeping it so it can be opened again  b) throwing it away  c) reading it aloud  d) closing the computer
**Answer: a) keeping it so it can be opened again** — save keeps the work.
