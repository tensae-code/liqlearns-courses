# Word processing — writing on a computer — true or false

Say whether each sentence is true or false.

**1.** A word processor can add a table to a document.
**Answer: True** — tables are named among the additions.

**2.** Pen-and-paper writing is easier to correct than word processing.
**Answer: False** — the advantage runs the other way.

**3.** Editing is part of word processing.
**Answer: True** — create, edit, format, save.

**4.** Word processing can insert illustrations and photographs from other software.
**Answer: True** — inserting illustrations and photographs is a named function.

**5.** Correcting spelling and grammar is part of word processing.
**Answer: True.**
