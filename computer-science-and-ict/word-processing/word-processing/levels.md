# Word processing — writing on a computer — depth

This lesson is one whole lesson with no sub lessons. Pass mark: the learner can do the lesson's one skill and answer its questions from the type files. Practice deepens by more items and harder corners of the same skill — more examples to sort, longer sequences to put in order, trickier cases of the same idea — never by a new topic.

Depth added (Grade 9): practice deepens on the same one skill — naming the five processors, sorting tasks between a word processor and a plain text editor, and listing the full function set (copy, paste, move, delete; tables; illustrations; spelling and grammar; templates) from memory.
