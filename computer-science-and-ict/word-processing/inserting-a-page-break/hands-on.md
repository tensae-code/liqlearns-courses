# Hands-on — Inserting a page break

The lesson with your hands, not only your eyes.

## Break the split

Set up the split: a paragraph ending one page, its picture starting the next. Insert a manual break so both start together on the second page. Then delete a line earlier in the document and show that the pair is still together.

## Enter-press evidence

Push text to a new page with Enter presses in one copy of a document, and with a page break in another. Edit both documents the same way and compare which push survived.
