# Inserting a page break — true or false

Say whether each sentence is true or false.

**1.** Word inserts breaks automatically when text reaches the bottom of a page.
**Answer: True.**

**2.** A manual break is needed when a paragraph would be split from its picture.
**Answer: True.**

**3.** Text after a manual break moves back if earlier text is edited.
**Answer: False — the break holds its place; that is its advantage over Enter presses.**
