# Inserting a page break — multiple choice

Pick the one right answer.

**1.** A page break is —
a) a torn page  b) where one page ends and a new page begins  c) a kind of bullet  d) a print setting only
**Answer: b) where one page ends and a new page begins.**

**2.** Pressing Enter repeatedly instead of a break is rejected because —
a) it is slow  b) later edits would shift everything  c) Word forbids Enter  d) it prints badly
**Answer: b) later edits would shift everything.**

**3.** A page break is inserted from —
a) Home → Break  b) Insert tab → Page Break  c) View → Break  d) the status bar
**Answer: b) Insert tab → Page Break.**

**4.** The keyboard way to insert a page break is —
a) Ctrl+Enter  b) Ctrl+B  c) Alt+Tab  d) Shift+Enter twice
**Answer: a) Ctrl+Enter.**

**5.** Before inserting, you place —
a) the mouse on the ruler  b) the insertion point where the break belongs  c) a picture  d) a new section
**Answer: b) the insertion point where the break belongs.**

**6.** Beside Page, the Breaks menu offers —
a) Line and Word breaks  b) Column and Text Wrapping breaks  c) Table and Chart breaks  d) Header breaks
**Answer: b) Column and Text Wrapping breaks.**
