# Inserting a page break — ordering

Put each set in the right order.

**1.** Inserting a break in order: press Ctrl+Enter / place the insertion point / see the text jump to the next page.
**Answer: place the insertion point → press Ctrl+Enter → see the text jump to the next page.**

**2.** The two routes: Insert tab route second step / Insert tab route first step — open the Insert tab, then click Page Break.
**Answer: open the Insert tab → click Page Break.**
