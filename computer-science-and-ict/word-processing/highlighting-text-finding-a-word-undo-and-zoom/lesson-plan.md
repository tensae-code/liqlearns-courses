**The one thing this lesson teaches:** Four everyday tools in one lesson: highlight marks text with colour, symbols can be inserted where the keyboard has no key for them, Find locates any word in the document, Undo takes back the last action, and the zoom slider changes how big the page looks without changing the document.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Highlight, insert a symbol, find a word** — **Highlighting** paints a colour behind selected text so it stands out — a mark for the reader, not a change to the words. Where the keyboard has no key, **symbols are inserted** from the program's symbol list. **Find** searches the whole document for a **word** and takes you to it — no reading page by page to hunt one word.
2. **Undo — and the zoom slider** — The **Undo button** takes back the **last action** — a deletion, a format, a paste — restoring what was there before; it is the safe net under all editing. The **zoom slider** changes the **size of the page on screen** — slide up to read small text closely, down to see the whole page — while the document itself, and its print, stay exactly as they were.
