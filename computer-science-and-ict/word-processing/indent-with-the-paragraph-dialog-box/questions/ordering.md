# Indent with the Paragraph dialog box — ordering

Put each set in the right order.

**1.** The steps in order: click OK / open the Home tab / click the launcher / select all the paragraphs / make the adjustments.
**Answer: open the Home tab → select all the paragraphs → click the launcher → make the adjustments → click OK.**

**2.** Opening the box: find the Paragraph group / click its corner arrow / see the dialog open.
**Answer: find the Paragraph group → click its corner arrow → see the dialog open.**
