# Indent with the Paragraph dialog box — multiple choice

Pick the one right answer.

**1.** The dialog is opened by clicking —
a) the ruler  b) the Paragraph group's dialog-box launcher  c) the status bar  d) the title bar
**Answer: b) the Paragraph group's dialog-box launcher — the small corner arrow.**

**2.** The launcher sits in —
a) the File tab  b) the corner of the Paragraph group  c) the scroll bar  d) the header
**Answer: b) the corner of the Paragraph group.**

**3.** Before opening the dialog, you —
a) print  b) select all the paragraphs  c) close Word  d) delete a paragraph
**Answer: b) select all the paragraphs.**

**4.** Inside the dialog you adjust —
a) only the file name  b) alignment and line spacing  c) the zoom  d) the margins of the screen
**Answer: b) alignment and line spacing.**

**5.** The steps begin on the —
a) View tab  b) Insert tab  c) Home tab  d) Layout tab
**Answer: c) Home tab.**

**6.** To save the settings and close the dialog, click —
a) Cancel  b) OK  c) the X of Word  d) Print
**Answer: b) OK.**
