# Adding a header and footer — ordering

Put each set in the right order.

**1.** The worked example in order: type the title and date / double-click the top margin / close the header / see it on all pages.
**Answer: double-click the top margin → type the title and date → close the header → see it on all pages.**

**2.** Opening and closing: press Esc / double-click the top margin.
**Answer: double-click the top margin → press Esc.**
