# Basic Document Settings — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What three page settings open the lesson?" is: Size, margins and orientation**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What are margins?" is: Portrait (tall) and landscape (wide)**
**Answer: False** — The blank frame on the page's four sides

**3. (Sub lesson 1) True or false: the answer to "What are the two orientations?" is: Portrait (tall) and landscape (wide)**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Why are page settings set first?" is: The Grade 6 and Grade 8 Informatika books**
**Answer: False** — Every later judgement depends on them

**5. (Sub lesson 1) True or false: the answer to "In which two Uzbekistan books does this lesson appear?" is: The Grade 6 and Grade 8 Informatika books**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Name three text parameters." is: The whole document**
**Answer: False** — Font, font size and line spacing (or alignment)

**7. (Sub lesson 2) True or false: the answer to "What do defaults set at the start keep in one dress?" is: The whole document**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What do mid-way changes make?" is: Decide the parameters once, at the beginning**
**Answer: False** — Patches

**9. (Sub lesson 2) True or false: the answer to "What is the lesson's discipline?" is: Decide the parameters once, at the beginning**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What should carry the rest of the work?" is: Size, margins and orientation**
**Answer: False** — The writing, not the settings
