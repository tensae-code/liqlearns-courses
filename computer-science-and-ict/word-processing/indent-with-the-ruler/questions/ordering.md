# Indent with the Ruler — ordering

Put each set in the right order.

**1.** The method in order: release the marker / select the paragraphs / drag the chosen marker / show the ruler.
**Answer: show the ruler → select the paragraphs → drag the chosen marker → release the marker.**

**2.** Choosing a marker: decide the result you want / drag that marker / look at which lines moved.
**Answer: decide the result you want → drag that marker → look at which lines moved.**
