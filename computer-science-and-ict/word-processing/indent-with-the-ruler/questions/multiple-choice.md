# Indent with the Ruler — multiple choice

Pick the one right answer.

**1.** The ruler is shown from —
a) Home → Ruler  b) View tab, tick Ruler in the Show group  c) Insert → Ruler  d) the status bar
**Answer: b) View tab, tick Ruler in the Show group.**

**2.** The First-line indent marker moves —
a) every line  b) only the first line  c) the rest of the paragraph  d) the page
**Answer: b) only the first line.**

**3.** The Hanging indent marker moves —
a) the first line  b) the title  c) the rest of the paragraph  d) nothing
**Answer: c) the rest of the paragraph.**

**4.** The Left indent marker moves —
a) both markers' lines together — every line  b) one word  c) the margin itself  d) the scroll bar
**Answer: a) both markers' lines together — every line.**

**5.** Ctrl+A —
a) saves the document  b) selects a whole document  c) closes Word  d) prints
**Answer: b) selects a whole document.**

**6.** The method ends by —
a) pressing Enter  b) releasing the dragged marker  c) closing the document  d) double-clicking
**Answer: b) releasing the dragged marker — the paragraphs indent.**
