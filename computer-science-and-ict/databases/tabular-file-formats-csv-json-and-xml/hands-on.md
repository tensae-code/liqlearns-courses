# Hands-on — Tabular File Formats — CSV, JSON and XML

The lesson with your hands and your feet, not only your eyes.

## One table, three writings
Take the three-student table from Do it first. Write it correctly as CSV (header first). Then write one of the students as a JSON object, and the same student as an XML element. Exchange with a partner: can they rebuild the table from each writing without asking you anything?

## The semicolon trap (if a computer is available)
Save a small spreadsheet as CSV, then open the CSV file in a text editor and look at the raw text. If your machine uses French settings, which separator do you see? Open the same file in another program and check the table survives.
