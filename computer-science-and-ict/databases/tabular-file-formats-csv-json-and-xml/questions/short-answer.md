# Tabular File Formats — CSV, JSON and XML — short answer

Answer in your own words, in one or two sentences.

**1. (Sub lesson 2) A weather service must send temperature readings to many different programs every hour. Which format from this lesson fits best, and why?**
**Answer: JSON (or XML) — the readings travel between programs, each value must carry its name and unit with it, and every program can read the format without a spreadsheet; CSV would force all receivers to agree and remember a column order.**
