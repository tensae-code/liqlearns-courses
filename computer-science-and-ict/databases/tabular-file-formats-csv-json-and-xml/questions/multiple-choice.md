# Tabular File Formats — CSV, JSON and XML — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) In a CSV file, the first line holds —**
a) The totals  b) The descriptors’ names (the header)  c) A picture  d) The program’s name
**Answer: b) The descriptors’ names (the header) — Every following line is one row whose values follow the header’s order.**

**2. (Sub lesson 1) French CSV files often use a semicolon as separator because —**
a) Commas are forbidden in France  b) The comma is the decimal mark in French numbers  c) Semicolons are faster  d) Excel requires it
**Answer: b) The comma is the decimal mark in French numbers — Using it as a separator too would make values unreadable.**

**3. (Sub lesson 2) JSON writes an object mainly with —**
a) Tags like <nom>  b) Name–value pairs inside braces  c) Semicolons only  d) Pictures
**Answer: b) Name–value pairs inside braces — For example "nom": "Awa", with lists in square brackets.**

**4. (Sub lesson 2) XML structures data as —**
a) A tree of tagged elements  b) A single line of numbers  c) A spreadsheet grid  d) A sound file
**Answer: a) A tree of tagged elements — Each value is wrapped in a named opening and closing tag, nesting like a page’s DOM.**
