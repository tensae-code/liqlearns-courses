# Tabular File Formats — CSV, JSON and XML — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) A CSV file stores the colours and column widths of the spreadsheet it came from.**
**Answer: False — CSV is values only, as plain text; presentation stays behind, which is why every program can read it.**

**2. (Sub lesson 2) JSON and XML both attach the name of each value to the value itself.**
**Answer: True — That is their advantage over CSV for data exchanged between programs: no header order has to be remembered.**
