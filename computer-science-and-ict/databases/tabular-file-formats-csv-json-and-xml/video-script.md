# Video script — Tabular File Formats — CSV, JSON and XML

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

One table can live in many file shapes.

A spreadsheet file — XLSX or ODS — keeps the data with its colours, widths and formulas. Rich, but tied to its program.

CSV is the table as plain text. First line: the names. Then one line per row, values separated by commas — or by semicolons in France, where the comma belongs to numbers.

JSON names every value: name, colon, value, inside braces. XML wraps every value in a tag, building a tree.

Flat table to a spreadsheet? CSV. Data travelling between programs? JSON or XML. Choosing the format is part of the craft.
