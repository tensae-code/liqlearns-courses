# Characteristics of a Relational Database — Codd's Rules — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Edgar Codd, the relational idea's inventor**
**Answer: True**

**2. (Sub lesson 1) True or false: Edgar Codd, the relational idea's inventor** — as the answer to: How must all information be held, by the rules?
**Answer: False — As values in tables — nothing hidden in pointers**

**3. (Sub lesson 1) True or false: By table name, key and column name**
**Answer: True**

**4. (Sub lesson 1) True or false: By table name, key and column name** — as the answer to: How must nulls be handled?
**Answer: False — Systematically — by rule, not by accident**

**5. (Sub lesson 1) True or false: The comprehensive language — SQL**

**8. (Sub lesson 2) True or false: Data independence from programs, and system-enforced integrity** — as the answer to: What must have no back doors around it?
