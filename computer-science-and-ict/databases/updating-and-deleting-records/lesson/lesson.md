# Updating and Deleting Records — from the Program

## Do it first

Showing data is half a database program; the other half changes it. Kuwait's Grade 12 chapter on adding and editing data teaches the program-side acts: new records born on the form, existing ones modified, records removed. This lesson is that editing.

## Sub lesson 1 — Adding new records from the program

**Adding** in the program means a **new record** is prepared on the form — the boxes emptied for fresh values, the user types the new record's fields — and then **saved** into the table through the connection, joining the store as a row like any other. The discipline is the order: prepare, check the values are complete and of the right kind, then save — a half-typed record saved early is a broken row everyone after must step around.

## Sub lesson 2 — Modifying and deleting — editing what exists

**Modifying** begins by finding and standing on the record (the grid's skill), changing its fields on the form, and saving the change back — the store's row is rewritten with the new values. **Deleting** removes the current record from the table altogether, and Kuwait teaches it beside modifying because both are irreversible in the same way: a saved change and a deletion are facts, so the program asks and the user confirms with the record in view, never from a list half-read.
