# Databases in Everyday Life — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What database does the school office keep?" is: Its pupils — names, classes, fees and marks**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What question does the library database answer?" is: Stock and prices, used at the till**
**Answer: False** — Do we have this book, and who has it?

**3. (Sub lesson 1) True or false: the answer to "What does the shop's database hold?" is: Stock and prices, used at the till**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does the bank's database hold?" is: Recognition — each answers questions from stored records, which is a database's job**
**Answer: False** — Accounts and their balances

**5. (Sub lesson 1) True or false: the answer to "What is Fiji's point in these examples?" is: Recognition — each answers questions from stored records, which is a database's job**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What one shape sits under all the examples?" is: Its title, author and borrower details — the fields every book record shares**
**Answer: False** — Records of one kind of thing, each record in fields, searched to answer questions

**7. (Sub lesson 2) True or false: the answer to "What fields does a book record in a library carry?" is: Its title, author and borrower details — the fields every book record shares**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Give a question a pupil database answers in seconds." is: An airline booking system and a hospital file system (or a phone contact list)**
**Answer: False** — Is this pupil in Year 8?

**9. (Sub lesson 2) True or false: the answer to "Name two more everyday databases beyond Fiji's four." is: An airline booking system and a hospital file system (or a phone contact list)**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why learn the shape, not only the examples?" is: Its pupils — names, classes, fees and marks**
**Answer: False** — So a new system is recognised as the same kind of thing on first meeting
