# The database approach and the DBMS — short answer

Answer in a sentence or two.

**1. (Sub lesson 1)** What is a database, in the database approach?
**Answer:** One shared collection of all of an organisation's logically related data.

**2. (Sub lesson 2)** Describe a query's round trip.
**Answer:** An application sends a query to the DBMS; the DBMS finds and returns the matching data.

**3. (Sub lesson 3)** Name the four advantages of the database approach over files.
**Answer:** Data independence, data sharing, avoided redundancy, and improved security.

**4. (Sub lesson 4)** State the distinction in one sentence.
**Answer:** A database is the schema designed with a DBMS to store data; the DBMS is the software tool used to maintain it.

**5. (Sub lesson 4)** Name two RDBMS tools beyond Access from the guide's landscape.
**Answer:** Any two of: MySQL, Oracle, MS SQL Server, MariaDB.
