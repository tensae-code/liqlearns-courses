# The database approach and the DBMS — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** In the database approach, an organisation's logically related data lives —
a) in each department's own files  b) in one shared collection  c) on paper only
**Answer: b)** — one shared collection: a database.

**2. (Sub lesson 2)** DBMS stands for —
a) Database Management System  b) Data Backup Machine Software  c) Departmental Mail System
**Answer: a)** — Database Management System.

**3. (Sub lesson 2)** An application asks the DBMS for data by sending a —
a) file  b) query  c) password only
**Answer: b)** — a query; the DBMS returns the matching data.

**4. (Sub lesson 3)** “Only authorised users can access or change the data” is the advantage called —
a) data sharing  b) improved security  c) data independence
**Answer: b)** — improved security.

**5. (Sub lesson 3)** Storing the data once, in one central store, gives the advantage of —
a) avoided redundancy  b) more copies  c) slower access
**Answer: a)** — avoided redundancy.

**6. (Sub lesson 4)** A database is —
a) the software tool  b) the schema designed with a DBMS to store data  c) a query  d) a report
**Answer: b) the schema designed with a DBMS to store data** — the guide's distinction, stated outright.

**7. (Sub lesson 4)** The DBMS is —
a) the stored data itself  b) the software tool used to maintain the database  c) the primary key  d) the schema drawing
**Answer: b) the software tool used to maintain the database** — tool, not data.

**8. (Sub lesson 4)** The RDBMS limitation NoSQL addresses is —
a) it is too cheap  b) its schema is not flexible enough for big data  c) it uses tables  d) it needs electricity
**Answer: b) its schema is not flexible enough for big data** — schema inflexibility is the named limitation.

**9. (Sub lesson 4)** Which tool in the guide's list is actually a NoSQL system?
a) MariaDB  b) Oracle  c) MongoDB  d) MS SQL Server
**Answer: c) MongoDB** — MongoDB — the guide's listing of it as an RDBMS is an error.
