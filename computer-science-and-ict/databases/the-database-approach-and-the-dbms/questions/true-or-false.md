# The database approach and the DBMS — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** In the database approach, every department still keeps its own separate copy of the data.
**Answer: False** — the data lives in one shared collection.

**2. (Sub lesson 2)** The DBMS adds, modifies, deletes and retrieves data.
**Answer: True** — those are its four jobs.

**3. (Sub lesson 3)** Data independence means one database serves all users.
**Answer: True** — the data is not tied inside one program.
