# Lesson plan — The database approach and the DBMS

**Course:** Computer Science and ICT · **Title:** Databases · **Lesson:** The database approach and the DBMS
**Place in the curriculum:** Unit 3 — Database Management (Ethiopia Grade 11 Information Technology), in the Databases title of the Computer Science and ICT course. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** in the database approach, all of an organisation's logically related data lives in one shared collection — a database — managed by DBMS software, which is the interface between the database and its users and programs: queries go in, matching data comes back.
**This lesson's own level:** it stands on the lesson before it in this title — the file-based approach and the problems that forced this one into being.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **One shared collection — the database** — all logically related data lives in one shared collection, instead of separate departmental files
2. **The DBMS — the software in the middle** — DBMS software manages the database: it adds, modifies, deletes and retrieves data, and is the interface between the database and its users and programs; applications send queries and the DBMS returns the matching data
3. **The four advantages over files** — data independence, data sharing, avoided redundancy, improved security

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: File-based data management — separate files, duplicated data. Recommended, never forced.

## What the learner can do when it ends
1. Say what a database is in this approach: one shared collection of logically related data.
2. Say what DBMS software does: adds, modifies, deletes and retrieves data, and acts as the interface between the database and its users and programs.
3. Follow a query's round trip: an application sends a query to the DBMS, and the DBMS returns the matching data.
4. Name the four advantages over files: data independence, data sharing, avoided redundancy, improved security.

## If the learner is stuck
- Thinks the DBMS is the database → the database is the data collection; the DBMS is the software that manages it and stands between it and its users.
- Thinks each program keeps its own copy again → in this approach there is one central store; programs ask the DBMS, they do not hold copies.
