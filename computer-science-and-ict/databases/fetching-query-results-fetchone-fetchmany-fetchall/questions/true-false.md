# Fetching Query Results — fetchone, fetchmany, fetchall — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: On the cursor — the query's answer, held by the database side**
**Answer: True**

**2. (Sub lesson 1) True or false: Not the program's — the query was asked but nothing was heard** — as the answer to: What does fetching do?
**Answer: False — Moves rows from the cursor into the program**

**3. (Sub lesson 1) True or false: Not the program's — the query was asked but nothing was heard**
**Answer: True**

**4. (Sub lesson 1) True or false: For questions with a single answer** — as the answer to: What does fetchone take?
**Answer: False — The next one row**

**5. (Sub lesson 1) True or false: For questions with a single answer**
**Answer: True**

**6. (Sub lesson 2) True or false: Every remaining row at once, as a list** — as the answer to: What does fetchmany take?
