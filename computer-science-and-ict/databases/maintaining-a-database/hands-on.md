# Hands-on — Maintaining a Database

The lesson with your hands and your feet, not only your eyes.

## Task one
**Maintenance plan** — Write the maintenance plan for the school library database: compact rhythm, backup rhythm and keeping place, split or not, protection — each with its reason.

## Task two
**Failure drill** — The database file is corrupt on Monday morning: write the recovery paragraph using last Friday's backup, and state what data the weekend's rhythm lost and how the plan changes.
