# Maintaining a Database — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Compact and repair — the file healed and shrunk
Sub lesson 1 questions from the type files. Pass mark: Deleted records and objects leave claimed, empty gaps — the file does not shrink; Rebuilds the file — records in order, gaps dropped, indexes rebuilt, damage repaired where possible; Regularly — weekly in working databases, and always after mass deletions; On a copy kept safe until the compacted file proves sound; A routine — the rescue use is its failure mode.

## Sub lesson 2 — Backup, splitting and protection — the standing care
Sub lesson 2 questions from the type files. Pass mark: A backup — dated copies kept apart from the working machine; A back-end of tables (shared) and front-ends of queries, forms and reports (per user); So many users share the data without sharing the damage; Passwords and permissions over the tables; Unkept — not of hard questions.
