# ALTER TABLE — add, drop and change columns — short answer

Answer in a word, a line of SQL, or one short sentence.

**1. (Sub lesson 1)** Write the ALTER that drops the Room column from COURSE.
**Answer:** ALTER TABLE COURSE DROP COLUMN Room;

**2. (Sub lesson 2)** Write the direct fix for C_Department CHAR(15).
**Answer:** ALTER TABLE COURSE ALTER COLUMN C_Department CHAR(10);

**3. (Sub lesson 3)** Which ALTER shape changes a column's definition without removing it?
**Answer:** ALTER COLUMN.
