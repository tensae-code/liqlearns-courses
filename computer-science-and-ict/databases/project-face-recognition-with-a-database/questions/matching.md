# Project — Face Recognition with a Database — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What is the difference between detection and recognition?** → **Detection finds that a face is present and where; recognition says whose it is**

**2. (Sub lesson 1) What detector does the project use?** → **OpenCV's Haar cascade**

**3. (Sub lesson 1) Where are seen faces logged?** → **In an SQLite database — a face_logs / attendance table**

**4. (Sub lesson 1) Why does a database beat a text file here?** → **The log can be queried, counted and kept honestly**

**5. (Sub lesson 1) What does the log record?** → **Who was seen, and when**

**6. (Sub lesson 2) How does Term 2 grow the project?** → **An employees table linked to a face_log table, with queries and decision reports**

**7. (Sub lesson 2) What library prints the PDF reports?** → **ReportLab**

**8. (Sub lesson 2) What questions do the reports answer? Give one.** → **Who was late how often (or: which door saw whom)**

**9. (Sub lesson 2) What is the product, in the project's own lesson?** → **The integration — a system whose seeing is remembered, questioned and reported**

**10. (Sub lesson 2) Which books build this project?** → **Kuwait Grade 11 Information Technology Terms 1 and 2, Unit 2 of each**
