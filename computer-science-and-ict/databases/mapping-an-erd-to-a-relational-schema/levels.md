# Mapping an ERD to a Relational Schema — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Entities and attributes — the straight mapping
Sub lesson 1 questions from the type files. Pass mark: A table; A column of its entity's table; The table's primary key; As a table of its own — the key plus one value per record; A home in the schema, or a stated reason why not.

## Sub lesson 2 — Relationships — foreign keys and new tables
Sub lesson 2 questions from the type files. Pass mark: By a foreign key — the 'one' side's key placed in the 'many' side's table; As a new table holding both sides' keys as its composite key; The relationship's own attributes — such as a mark; Every relationship in the ERD must be traceable in the schema — as a foreign key or as a table; A picture; the schema is the buildable design.
