# Aggregate Functions in SQL — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does an aggregate function take and return?**
a) A whole column across many records — and one value back  b) Records  c) SUM totals a numeric column; AVG averages it  d) The column's largest and smallest values
**Answer: a) A whole column across many records — and one value back**

**2. (Sub lesson 1) What does COUNT(*) count?**
a) SUM totals a numeric column; AVG averages it  b) Records  c) The column's largest and smallest values  d) A single number — the size of the whole table
**Answer: b) Records**

**3. (Sub lesson 1) What do SUM and AVG do?**
a) The column's largest and smallest values  b) A single number — the size of the whole table  c) SUM totals a numeric column; AVG averages it  d) A WHERE clause selects the records first
**Answer: c) SUM totals a numeric column; AVG averages it**

**4. (Sub lesson 1) What do MAX and MIN return?**
a) A single number — the size of the whole table  b) A WHERE clause selects the records first  c) One summary per group — an average for each class  d) The column's largest and smallest values
**Answer: d) The column's largest and smallest values**

**5. (Sub lesson 1) What does SELECT COUNT(*) FROM Pupil; return?**
a) A single number — the size of the whole table  b) A WHERE clause selects the records first  c) One summary per group — an average for each class  d) Records chosen, then grouped, then each group summarised
**Answer: a) A single number — the size of the whole table**

**6. (Sub lesson 2) How are aggregates pointed at chosen records?**
a) One summary per group — an average for each class  b) A WHERE clause selects the records first  c) Records chosen, then grouped, then each group summarised  d) Expecting both the summary and the records from one plain SELECT
**Answer: b) A WHERE clause selects the records first**

**7. (Sub lesson 2) What does GROUP BY add?**
a) Records chosen, then grouped, then each group summarised  b) Expecting both the summary and the records from one plain SELECT  c) One summary per group — an average for each class  d) SELECT AVG(Mark) FROM Result WHERE Subject = 'Maths';
**Answer: c) One summary per group — an average for each class**

**8. (Sub lesson 2) What is the honest order of reading?**
a) Expecting both the summary and the records from one plain SELECT  b) SELECT AVG(Mark) FROM Result WHERE Subject = 'Maths';  c) A whole column across many records — and one value back  d) Records chosen, then grouped, then each group summarised
**Answer: d) Records chosen, then grouped, then each group summarised**

**9. (Sub lesson 2) What is the common fault?**
a) Expecting both the summary and the records from one plain SELECT  b) SELECT AVG(Mark) FROM Result WHERE Subject = 'Maths';  c) A whole column across many records — and one value back  d) Records
**Answer: a) Expecting both the summary and the records from one plain SELECT**

**10. (Sub lesson 2) Write the query for the average Maths mark.**
a) A whole column across many records — and one value back  b) SELECT AVG(Mark) FROM Result WHERE Subject = 'Maths';  c) Records  d) SUM totals a numeric column; AVG averages it
**Answer: b) SELECT AVG(Mark) FROM Result WHERE Subject = 'Maths';**
