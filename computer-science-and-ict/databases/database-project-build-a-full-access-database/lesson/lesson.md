# Database Project — Build a Full Access Database

## Do it first

A year of databases ends the way Libya ends it: not with a test, but with projects. The final chapter sets three full database projects. This lesson is that closing work — everything the year taught, used at once, on a database of your own.

## Sub lesson 1 — The set projects — the year's skills in one build

Each **set project** asks for a **complete database**: **tables** designed and created, **fields** with their types and a **primary key**, **records entered**, **relationships** between tables, **queries** that answer the project's questions, a **form** for entering data and a **report** for presenting it. Nothing in the project is new — that is the point. The project proves the year's chapters were skills, not readings, by demanding them together, in working order, without a chapter title to hint which one comes next.

In your mind's eye: the set projects — the year's skills in one build.

## Sub lesson 2 — Working a project — plan, build, check

A project is worked in the database's own order: **plan** the tables and their relationships on paper first; **build** tables, then relationships, then entry through forms; **ask** the project's questions as queries; **present** the answers as a report; and **check** every stage against the project's brief before calling it finished. Libya sets **three** projects, not one, so the second and third are worked with the first one's mistakes already understood — the project's real teaching is the repetition with growing independence.

In your mind's eye: working a project — plan, build, check.
