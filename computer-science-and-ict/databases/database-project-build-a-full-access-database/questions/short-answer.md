# Database Project — Build a Full Access Database — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does a set project ask for?**
**Answer: A complete Access database, built end to end**

**2. (Sub lesson 1) Name the parts a project database must contain.**
**Answer: Tables, fields with types and a primary key, records, relationships, queries, a form and a report (any four)**

**3. (Sub lesson 1) Is anything in the project new?**
**Answer: No — the project uses everything the year taught, together**

**4. (Sub lesson 1) What does the project prove?**
**Answer: That the year's chapters were skills, not readings**

**5. (Sub lesson 1) What is the first working stage?**
**Answer: Plan the tables and relationships on paper**

**6. (Sub lesson 2) In what order are the parts built?**
**Answer: Tables, then relationships, then entry through forms, then queries, then a report**

**7. (Sub lesson 2) How is a stage judged finished?**
**Answer: By checking it against the project's brief**

**8. (Sub lesson 2) How many projects does Libya set?**
**Answer: Three**

**9. (Sub lesson 2) Why three, not one?**
**Answer: So the later projects are worked with the first one's mistakes already understood**

**10. (Sub lesson 2) Which book's final chapter sets these projects?**
**Answer: Libya's Grade 10 Information Technology student book, Chapter 12**
