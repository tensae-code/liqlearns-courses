# Hands-on — Database Project — Build a Full Access Database

The lesson with your hands and your feet, not only your eyes.

## Task one
('Build one whole', 'Choose a real collection — books, pupils, shop stock — and build its complete database: tables, key, relationships, entry form, one query, one report.')

## Task two
('Judge a project', 'Swap databases with a partner. Using the brief's parts list, check their database part by part and write what is missing or wrong.')
