# Hands-on — CREATE TABLE — building a table with SQL

The lesson with your hands, not only your eyes.

## Build the three tables
In Access SQL View (or on paper), write CREATE TABLE for Student, Teacher and Grade, each with a primary key, Grade referencing the other two. Run or trace each one.

## Break it, fix it
Deliberately write one CREATE with a missing comma and one with CREATE missing its TABLE. Swap with a partner: find and fix each other's fault.
