# CREATE TABLE — building a table with SQL — true or false

Say true or false.

**1. (Sub lesson 1)** A CREATE TABLE statement may mark one column as the primary key.
**Answer: True** — the general form allows [Primary Key] on a column.

**2. (Sub lesson 2)** Field names may contain spaces, like `First Name`, without any problem.
**Answer: False** — the guide's tip: a space in a field name generates an error — write FirstName.

**3. (Sub lesson 2)** All DBMSs name and size data types in exactly the same way.
**Answer: False** — they may differ — check the documentation.

**4. (Sub lesson 3)** Ending an SQL statement with a semicolon is required, or Access always refuses it.
**Answer: False** — it is optional, but good practice for clarity.
