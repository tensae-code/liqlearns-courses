# CREATE TABLE — building a table with SQL — short answer

Answer in a word, a line of SQL, or one short sentence.

**1. (Sub lesson 1)** Write the CREATE TABLE opening for a table named Book with key BookID INTEGER.
**Answer:** CREATE TABLE Book ( BookID INTEGER PRIMARY KEY, … );

**2. (Sub lesson 2)** A TEXT(12) field receives a 20-character name. How many characters are stored?
**Answer:** 12 — the first 12 only.

**3. (Sub lesson 3)** Name the three faults the diagnosis set teaches you to hunt.
**Answer:** A missing comma (with a wrong closing brace), the missing word TABLE after CREATE, and a misspelt REFERENCES with a missing bracket.
