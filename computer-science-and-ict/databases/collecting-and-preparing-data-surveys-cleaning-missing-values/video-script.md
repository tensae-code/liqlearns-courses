# Video script — Collecting and Preparing Data Surveys Cleaning Missing Values

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

This part of Pakistan (Punjab)'s book teaches **Data Collection and Preparation** — covering: Unit 5 §5.2 Data Collection and Preparation (§5.2.1 methods — surveys (an Islamabad grocery store), observations, experiments; §5.2.2 data preparation; §5.2.3 cleaning and transformation; §5.2.3.3 handling missing data — imputation, flagging, removal; class activity: survey classmates' homework hours and analyse them). The book teaches this as its own named step, in the book's own order, as a skill to be shown — not only named. The learner follows the book's own steps for this part, in order, and practises until the steps can be done without the book open.
**Doing it — Collecting and Preparing Data Surveys Cleaning Missing Values in practice** — the learner now works the lesson's own thing with a real example of their own, following the book's own steps in order, until the steps can be done without the book open.
