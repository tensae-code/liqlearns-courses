# Null — When a Value Is Missing — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does null mean?**
**Answer: No value is stored — unknown, or not applicable**

**2. (Sub lesson 1) Is null the same as zero?**
**Answer: No — zero is a real amount**

**3. (Sub lesson 1) Is null the same as an empty string?**
**Answer: No — an empty string is a real text**

**4. (Sub lesson 1) What does a salary of null say?**
**Answer: We do not know, or the question does not arise**

**5. (Sub lesson 1) What happens when null is compared with anything?**
**Answer: It never comes out true — the result is unknown**

**6. (Sub lesson 2) Which field is never null?**
**Answer: The primary key**

**7. (Sub lesson 2) Why can the key not be null?**
**Answer: A record with a missing identifier cannot be found or told apart**

**8. (Sub lesson 2) What is entity integrity?**
**Answer: Every primary key value exists and is unique**

**9. (Sub lesson 2) Who decides which fields may be null?**
**Answer: The table's designer, field by field**

**10. (Sub lesson 2) Give one field that may honestly be null.**
**Answer: A phone number (any field that can truly be missing)**
