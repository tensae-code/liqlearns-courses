# Video script — Popular Types of Database Management Systems

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A database management system — DBMS — is the software that creates, stores and guards a database; South Sudan's book names the popular types in use, from desktop systems like Microsoft Access to server systems used by whole organisations The learner names the popular DBMS types, says what kind of job each fits, and matches the system to the size of the work — one user on one computer, or many users on a network Because choosing the wrong system costs money and effort: the DBMS must fit the data, the users and the machines available.
