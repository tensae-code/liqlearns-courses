# The Data Hierarchy — Character, Field, Record, Table, Database — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 1) Characters together make a ____.**
**Answer: field — A field is one single fact, built out of characters.**

**2. (Sub lesson 2) A school database might hold a pupils table, a teachers table and a ____ table.**
**Answer: fees — Any related table fits — the point is several related tables kept together.**
