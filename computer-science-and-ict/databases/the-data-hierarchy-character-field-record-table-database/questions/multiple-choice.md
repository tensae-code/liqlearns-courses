# The Data Hierarchy — Character, Field, Record, Table, Database — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) The smallest named piece in the data hierarchy is —**
a) A record  b) A field  c) A character  d) A table
**Answer: c) A character — A character — one letter, digit or symbol; fields are built out of characters.**

**2. (Sub lesson 1) All the fields about one person together make —**
a) A table  b) A record  c) A database  d) A character
**Answer: b) A record — A record — one person's name, number, class and date of birth kept as one unit.**

**3. (Sub lesson 2) A database is —**
a) One very long field  b) A single record  c) A collection of related tables  d) A printed report
**Answer: c) A collection of related tables — A collection of related tables — pupils, teachers and fees tables together form the school database.**
