# The Data Hierarchy — Character, Field, Record, Table, Database — short answer

Answer in your own words, in one or two sentences.

**1. (Sub lesson 1) Break the entry 'Wanjiru — Adm 2210 — Class 5' into the levels of the data hierarchy.**
**Answer: Characters: the single letters and digits, like W or 2. Fields: Name (Wanjiru), Admission Number (2210), Class (5). Those fields together are one record — Wanjiru's record. Many such records form the pupils table, and that table with the school's other tables forms the database.**
