# The Data Hierarchy — Character, Field, Record, Table, Database — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) A field can hold one kind of fact, such as a name or an admission number.**
**Answer: True — One field, one fact — mixing two facts in one field breaks searching and sorting.**

**2. (Sub lesson 2) A table is bigger than a database.**
**Answer: False — The order runs the other way: tables are inside a database, so the database is the bigger level.**
