# Expressions in Access — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — The parts of an expression — fields, operators, functions
Sub lesson 1 questions from the type files. Pass mark: A formula that works out a value from the record's data; In square brackets — [Pret], [Cantitate]; It joins them — concatenation; Sum, Avg, IIf (also: Date, Year); Per record — each row's fields feed its own result.

## Sub lesson 2 — Where expressions live — criteria, calculated fields, controls
Sub lesson 2 questions from the type files. Pass mark: In a query's criteria row; An expression standing as a new column the table never stored — Total: [Pret]*[Cantitate]; It chooses between two answers by a condition; In a form or report control; One — the same expression grammar everywhere in Access.
