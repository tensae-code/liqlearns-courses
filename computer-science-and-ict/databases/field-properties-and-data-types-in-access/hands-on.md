# Hands-on — Field Properties and Data Types in Access

The lesson with your hands and your feet, not only your eyes.

## Type a small table
In design view (or on paper), give the fields of a pupils table a name and a data type each — name, class, marks, joining date, paid or not.

## Set three properties
For one field set a size, a default value and required-or-not, and say what each setting refuses or supplies.
