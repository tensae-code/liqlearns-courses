# Field Properties and Data Types in Access — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) Where is an Access table built?**
**Answer: In design view**

**2. (Sub lesson 1) What two things does every field get first?**
**Answer: A name and a data type**

**3. (Sub lesson 1) Which type holds a pupil's name?**
**Answer: Short Text**

**4. (Sub lesson 1) Which type holds marks?**
**Answer: Number**

**5. (Sub lesson 1) Which type holds the joining day?**
**Answer: Date/Time**

**6. (Sub lesson 2) Why is a data type called a guard?**
**Answer: It refuses values of the wrong kind — a Number field refuses letters**

**7. (Sub lesson 2) Name four field properties.**
**Answer: Field size, format, default value and required**

**8. (Sub lesson 2) What does a default value do?**
**Answer: It appears in the field before anything is typed**

**9. (Sub lesson 2) What does Required decide?**
**Answer: Whether the field must be filled or may stay empty**

**10. (Sub lesson 2) When are types and properties set?**
**Answer: Before a single record is entered — set first, corrected rarely**
