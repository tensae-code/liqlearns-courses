# Field Properties and Data Types in Access — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Where is an Access table built?**
a) In design view  b) A name and a data type  c) Number  d) It refuses values of the wrong kind — a Number field refuses letters
**Answer: a) In design view**

**2. (Sub lesson 1) What two things does every field get first?**
a) Short Text  b) A name and a data type  c) Date/Time  d) Field size, format, default value and required
**Answer: b) A name and a data type**

**3. (Sub lesson 1) Which type holds a pupil's name?**
a) Number  b) It refuses values of the wrong kind — a Number field refuses letters  c) Short Text  d) It appears in the field before anything is typed
**Answer: c) Short Text**

**4. (Sub lesson 1) Which type holds marks?**
a) Date/Time  b) Field size, format, default value and required  c) Whether the field must be filled or may stay empty  d) Number
**Answer: d) Number**

**5. (Sub lesson 1) Which type holds the joining day?**
a) Date/Time  b) It refuses values of the wrong kind — a Number field refuses letters  c) It appears in the field before anything is typed  d) Before a single record is entered — set first, corrected rarely
**Answer: a) Date/Time**

**6. (Sub lesson 2) Why is a data type called a guard?**
a) Field size, format, default value and required  b) It refuses values of the wrong kind — a Number field refuses letters  c) Whether the field must be filled or may stay empty  d) In design view
**Answer: b) It refuses values of the wrong kind — a Number field refuses letters**

**7. (Sub lesson 2) Name four field properties.**
a) It appears in the field before anything is typed  b) Before a single record is entered — set first, corrected rarely  c) Field size, format, default value and required  d) A name and a data type
**Answer: c) Field size, format, default value and required**

**8. (Sub lesson 2) What does a default value do?**
a) Whether the field must be filled or may stay empty  b) In design view  c) Short Text  d) It appears in the field before anything is typed
**Answer: d) It appears in the field before anything is typed**

**9. (Sub lesson 2) What does Required decide?**
a) Whether the field must be filled or may stay empty  b) Before a single record is entered — set first, corrected rarely  c) A name and a data type  d) Number
**Answer: a) Whether the field must be filled or may stay empty**

**10. (Sub lesson 2) When are types and properties set?**
a) In design view  b) Before a single record is entered — set first, corrected rarely  c) Short Text  d) Date/Time
**Answer: b) Before a single record is entered — set first, corrected rarely**
