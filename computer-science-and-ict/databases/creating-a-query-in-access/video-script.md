# Video script — Creating a query in Access

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then. Short script — the placements name no full video for this lesson.

---

The table holds everything. You want only some of it: name and sex, nothing else.

That wanting is a query.

Create menu. Query Design. Choose your table in the Show Table box.

Now pick the fields — name, sex. Only what you pick will show.

Switch the view. There is your answer: a custom view of the table, exactly the data you asked for.

Full walkthrough — writing and running SQL in Access.

Create tab. Query Design. A dialog appears — Show Table. Close it. We are not picking tables today; we are writing.

Top left: the SQL View dropdown. Open it. Choose SQL View. A blank window. This is where SQL lives in Access.

Type your command. SELECT star FROM Student. Every letter matters.

Now run it: Design tab — Results group — Run. The table answers.

Save the query. Give it a name that says what it does. Close it.

Tomorrow, no typing: in the queries view, double-click its name — and it runs again.

If Access refuses, a pop-up names the error's kind. Read it. Hunt the fault it points at. That is writing and running a query.
