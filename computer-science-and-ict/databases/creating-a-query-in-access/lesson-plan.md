# Lesson plan — Creating a query in Access

**Course:** Computer Science and ICT · **Title:** Databases · **Lesson:** Creating a query in Access
**Place in the curriculum:** Unit 3 — Database Management (Ethiopia Grade 11 Information Technology), in the Databases title of the Computer Science and ICT course. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** a query is an object that gives a custom view of data from one or more tables: open the database, Create menu, Query Design, choose the tables in the Show Table box, pick the fields for the Field row, then switch to Datasheet View to see the results.
**This lesson's own level:** it is a doing-lesson, in Access 2010 as the book teaches. It stands on Creating a table and entering records in Access — queries work on tables that exist and hold records. The book builds queries graphically and defers SQL.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. ## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Open Query Design and add the table** — open the database; click the Create menu; click Query Design; in the Show Table box select the table or tables and confirm
2. **Pick the fields for the Field row** — pick the fields for the Field row — only the chosen fields, such as name and sex, will show
3. **See the results — Datasheet View** — switch to Datasheet View to see the results; practice queries display teacher name and specialisation, and student name and grade level

4. **Grade 12 — writing and running SQL in Access: SQL View and Run** — Grade 12 (doing): Create tab → Query Design; close Show Table; SQL View dropdown → SQL View; run via Design → Results → Run, or double-click a saved query; error pop-ups matched to the error type

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Creating a table and entering records in Access. Recommended, never forced.

## What the learner can do when it ends
1. Say what a query is: an object that gives a custom view of data from one or more tables — a way of searching and compiling exactly the data wanted.
2. Build one in the book's order: open the database; Create menu; Query Design; Show Table — select the table or tables and confirm.
3. Pick the fields for the Field row, knowing only the chosen fields (such as name and sex) will show.
4. Switch to Datasheet View to see the results.
5. Name the practice queries: teacher name and specialisation; student name and grade level.

## What you need
A computer with Microsoft Access (the book teaches Access 2010), with the school database and its tables from the lessons before this one.

## If the learner is stuck
- Looks for results in Design view → the design grid is where the query is built; results appear when you switch to Datasheet View.
- Picks every field “ to be safe” → a query's purpose is the custom view: only the chosen fields show.
- Cannot find the table → it is added through the Show Table box right after opening Query Design; select it and confirm.
