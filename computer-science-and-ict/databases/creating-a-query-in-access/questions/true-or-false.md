# Creating a query in Access — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** This unit builds queries in SQL code.
**Answer: False** — queries are built graphically; the book defers SQL.

**2. (Sub lesson 2)** If you pick name and sex, the grade column will also show in the results.
**Answer: False** — only the chosen fields show.

**3. (Sub lesson 3)** One of the practice queries displays teacher name and specialisation.
**Answer: True.**

**4. (Sub lesson 4)** Access reports SQL errors with a pop-up matched to the error type.
**Answer: True** — the pop-up is part of the method — read it.

**5. (Sub lesson 4)** The Show Table dialog must be used before SQL View can open.
**Answer: False** — the book's order closes it.
