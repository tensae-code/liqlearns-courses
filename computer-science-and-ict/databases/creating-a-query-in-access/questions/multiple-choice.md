# Creating a query in Access — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A query is an object that gives —
a) a custom view of data from one or more tables  b) a printed certificate  c) a new database
**Answer: a)** — a custom view of exactly the data wanted.

**2. (Sub lesson 1)** Tables are added to a query through the —
a) File Name box  b) Show Table box  c) Primary Key button
**Answer: b)** — the Show Table box.

**3. (Sub lesson 2)** In the results, the fields that show are —
a) all fields of the table  b) only the fields picked for the Field row  c) only the key field
**Answer: b)** — only the chosen fields show.

**4. (Sub lesson 3)** Results are seen by switching to —
a) Design view  b) Datasheet View  c) a new database
**Answer: b)** — Datasheet View.
