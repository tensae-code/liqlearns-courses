# Creating a query in Access — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A query is an object that gives —
a) a custom view of data from one or more tables  b) a printed certificate  c) a new database
**Answer: a)** — a custom view of exactly the data wanted.

**2. (Sub lesson 1)** Tables are added to a query through the —
a) File Name box  b) Show Table box  c) Primary Key button
**Answer: b)** — the Show Table box.

**3. (Sub lesson 2)** In the results, the fields that show are —
a) all fields of the table  b) only the fields picked for the Field row  c) only the key field
**Answer: b)** — only the chosen fields show.

**4. (Sub lesson 3)** Results are seen by switching to —
a) Design view  b) Datasheet View  c) a new database
**Answer: b)** — Datasheet View.

**5. (Sub lesson 4)** After Create tab → Query Design, the next step is —
a) choose SQL View at once  b) close the Show Table dialog that appears  c) click Run  d) save the database
**Answer: b) close the Show Table dialog that appears** — Show Table is closed before SQL View is opened.

**6. (Sub lesson 4)** SQL commands in Access are written in —
a) Datasheet View  b) the Relationships window  c) SQL View  d) the File Name box
**Answer: c) SQL View** — the SQL View window is the writing place.

**7. (Sub lesson 4)** To run a written query: Design tab → Results group → —
a) Save  b) Run  c) Print  d) Close
**Answer: b) Run** — Run is in the Results group.

**8. (Sub lesson 4)** A saved query is run again by —
a) retyping it  b) double-clicking it in the queries view  c) dropping it  d) altering it
**Answer: b) double-clicking it in the queries view** — the book's saved-query route (example: male students).
