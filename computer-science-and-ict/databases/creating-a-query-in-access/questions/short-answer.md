# Creating a query in Access — short answer

Answer in a sentence or two.

**1. (Sub lesson 1)** What does a query let you do with a table's data?
**Answer:** Search and compile exactly the data wanted — a custom view of data from one or more tables.

**2. (Sub lesson 2)** A teacher wants only student names and grade levels. Which fields go in the Field row?
**Answer:** Name and grade level — only those two will show.

**3. (Sub lesson 3)** Name the book's two practice queries.
**Answer:** Teacher name and specialisation; student name and grade level.
