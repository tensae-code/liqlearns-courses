Placement choice: this lesson was built new for the ICT expansion (Nepal, 2026-11-14) because no existing lesson in the course covers this thing as its own lesson — the live tree was checked first: Databases holds CREATE TABLE (whose syntax names types as it goes) and Programming holds Python's own data types, but no lesson teaches the database column types themselves — the MySQL families and how to choose between them — as its own lesson, which is how Nepal's book teaches it in its own §2.3 section, before the table. The placements file named this slug directly (NEW LESSON NEEDED — databases/data-types-in-a-database). It sits in the Databases title (databases/).

Nepal's own way: a single optional-subject book that runs networks → MySQL databases → multimedia → Python (with Turtle, pandas file handling and data visualisation) → AI and contemporary technologies, ending each unit with curriculum-stated learning outcomes; Python data work with pandas is unusually advanced for Grade 10.

North Macedonia's own way (Year 2): a strikingly current first theme (cybersecurity, cryptography, blockchain, robotics, AI/ML and large language models) precedes deep C++ (data representation, functions, one-dimensional arrays), a full databases theme ending in SQL, multimedia with generative AI for graphics, and HTML web authoring.

Routing note (North Macedonia, 2026-11-14): north-macedonia-placements.md filed this placement as a NEW lesson, but the slug already exists in the live tree — it was built new by Nepal from its own book in this same expansion. North Macedonia's placement was therefore stocked into this existing lesson rather than the lesson being rebuilt.


Kazakhstan's own way (Zhunusov G10 Computer Science, English-medium): the English-medium Grade 10 book is the most technical of the wave: the CIA triad and three separate authentication lessons (passwords twice, biometrics), encoding standards, Python dictionaries, DFS/BFS graph traversal, and a full SQL chapter in MySQL (CREATE, INSERT, SELECT/WHERE, MIN/MAX, JOIN, GROUP BY, SELECT INTO) before a JavaScript chapter. (Its preface is the publisher's generic science template, left over from another book.)
