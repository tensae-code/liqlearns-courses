# Data Types in a Database — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) A data type given to a column decides —**
a) only the column's name  b) what the column may hold, how values are stored, and how they sort and calculate  c) the colour of the table
**Answer: b) what the column may hold, how values are stored, and how they sort and calculate** — That control is the type's whole job.

**2. (Sub lesson 1) The right type for a student's age in whole years is —**
a) INT  b) TEXT  c) DATE
**Answer: a) INT** — Age in years is a whole number you can add and average.

**3. (Sub lesson 1) Money is best kept in DECIMAL because —**
a) it stores the value exactly as written  b) it is the fastest type  c) it refuses all values
**Answer: a) it stores the value exactly as written** — A fee of 1250.50 stays 1250.50.

**4. (Sub lesson 2) The usual type for a student's name is —**
a) VARCHAR  b) INT  c) DATETIME
**Answer: a) VARCHAR** — Names are short text of varying length.

**5. (Sub lesson 2) A whole paragraph of teacher's remarks belongs in —**
a) CHAR  b) INT  c) TEXT
**Answer: c) TEXT** — TEXT is for long writing with no short limit.

**6. (Sub lesson 3) A phone number is stored as text because —**
a) phones are not numbers  b) nobody calculates with it, and a number column would strip its leading zero  c) the database cannot store digits
**Answer: b) nobody calculates with it, and a number column would strip its leading zero** — Digits do not make a value a number; what you do with it decides.
