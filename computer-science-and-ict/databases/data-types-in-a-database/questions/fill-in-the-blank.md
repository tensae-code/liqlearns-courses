# Data Types in a Database — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 1) The MySQL type for whole numbers — counts, ages, marks — is ____.**
**Answer: INT**

**2. (Sub lesson 2) The text type for long writing with no short limit is ____.**
**Answer: TEXT**

**3. (Sub lesson 3) The type that holds a day and a time of day together is ____.**
**Answer: DATETIME**
