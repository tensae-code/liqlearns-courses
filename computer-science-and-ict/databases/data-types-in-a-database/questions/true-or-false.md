# Data Types in a Database — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) An INT column will accept the word "twelve" as a value.**
**Answer: False** — A whole-number column refuses words; the type guards the gate.

**2. (Sub lesson 2) VARCHAR stores only the length each value actually has.**
**Answer: True** — Unlike CHAR, it does not pad every value to one fixed length.

**3. (Sub lesson 3) A date stored as text sorts just as truly as a date stored in a DATE column.**
**Answer: False** — Text sorts character by character and cannot count the days between two dates; a DATE column can.

**4. (Sub lesson 3) The right type for a column follows what the values are and what will be done with them.**
**Answer: True** — That is the choosing rule of this lesson.
