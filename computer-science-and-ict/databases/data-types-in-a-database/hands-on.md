# Hands-on — Data Types in a Database

The lesson with your hands, not only your eyes.

## Type a real table

Take a table you know — a class register, a shop's stock list, a library's book list. Write its columns in a row. Under each column write the data type you would give it in MySQL, and one line saying why that type fits what the column holds.

## Break a type on paper

For one column in your table, write a value the type should refuse (a word in a number column, a date in a name column). Beside it, write what would go wrong if the database had accepted it — a wrong sort, a lost zero, a sum that makes no sense.
