# Video script — Data Types in a Database

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Every column has a type. The type is a promise.

Numbers: INT counts whole things. DECIMAL holds prices exactly.

Text: VARCHAR holds names. TEXT holds long writing.

Dates: DATE holds a day. The database can count days between dates.

A phone number is text. You never add phone numbers.

Right value, right type — the database guards the gate.
