# Hands-on — Collecting Data by Web Scraping with Python

The lesson with your hands and your feet, not only your eyes.

## Task one
**Pattern by eye first** — Open a simple listing page (a results or price page). On paper, mark the repeating pattern: which tag and class holds each field you would take. That marked pattern is a scraper's design.

## Task two
**Harvest and validate** — With a teacher's Colab (or on paper for one page), scrape or copy ten rows into a table. Validate it: count the rows, hunt one wrong value, and write where the table came from.
