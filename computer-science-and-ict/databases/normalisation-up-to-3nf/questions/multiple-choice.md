# Normalisation up to 3NF — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What may 0NF data hold?**
a) Repeating groups — Subject1, Subject2, Subject3, or several facts in one cell  b) Atomic values — one fact per cell — and a key identifying every record  c) Each repeated fact gets its own record — one record per pupil–subject pair  d) Addressability — every fact can be found, counted and updated on its own
**Answer: a) Repeating groups — Subject1, Subject2, Subject3, or several facts in one cell**

**2. (Sub lesson 1) What does 1NF require?**
a) Each repeated fact gets its own record — one record per pupil–subject pair  b) Atomic values — one fact per cell — and a key identifying every record  c) Addressability — every fact can be found, counted and updated on its own  d) When the key is composite
**Answer: b) Atomic values — one fact per cell — and a key identifying every record**

**3. (Sub lesson 1) How is a repeating group removed?**
a) Addressability — every fact can be found, counted and updated on its own  b) When the key is composite  c) Each repeated fact gets its own record — one record per pupil–subject pair  d) Every non-key attribute depends on the whole key, not part of it
**Answer: c) Each repeated fact gets its own record — one record per pupil–subject pair**

**4. (Sub lesson 1) What is 1NF's gain?**
a) When the key is composite  b) Every non-key attribute depends on the whole key, not part of it  c) 2NF — the name depends on part of the key  d) Addressability — every fact can be found, counted and updated on its own
**Answer: d) Addressability — every fact can be found, counted and updated on its own**

**5. (Sub lesson 1) When does 2NF act?**
a) When the key is composite  b) Every non-key attribute depends on the whole key, not part of it  c) 2NF — the name depends on part of the key  d) Transitive dependency — a non-key attribute depending on another non-key attribute
**Answer: a) When the key is composite**

**6. (Sub lesson 2) What does 2NF require?**
a) 2NF — the name depends on part of the key  b) Every non-key attribute depends on the whole key, not part of it  c) Transitive dependency — a non-key attribute depending on another non-key attribute  d) 3NF — the room depends on the teacher, not the pupil
**Answer: b) Every non-key attribute depends on the whole key, not part of it**

**7. (Sub lesson 2) A pupil's name in an enrolment table keyed by PupilID+Subject breaks which form?**
a) Transitive dependency — a non-key attribute depending on another non-key attribute  b) 3NF — the room depends on the teacher, not the pupil  c) 2NF — the name depends on part of the key  d) In exactly one table — updates touch one place
**Answer: c) 2NF — the name depends on part of the key**

**8. (Sub lesson 2) What does 3NF remove?**
a) 3NF — the room depends on the teacher, not the pupil  b) In exactly one table — updates touch one place  c) Repeating groups — Subject1, Subject2, Subject3, or several facts in one cell  d) Transitive dependency — a non-key attribute depending on another non-key attribute
**Answer: d) Transitive dependency — a non-key attribute depending on another non-key attribute**

**9. (Sub lesson 2) A teacher's room stored on pupil records breaks which form?**
a) 3NF — the room depends on the teacher, not the pupil  b) In exactly one table — updates touch one place  c) Repeating groups — Subject1, Subject2, Subject3, or several facts in one cell  d) Atomic values — one fact per cell — and a key identifying every record
**Answer: a) 3NF — the room depends on the teacher, not the pupil**

**10. (Sub lesson 2) At 3NF, where does each fact live?**
a) Repeating groups — Subject1, Subject2, Subject3, or several facts in one cell  b) In exactly one table — updates touch one place  c) Atomic values — one fact per cell — and a key identifying every record  d) Each repeated fact gets its own record — one record per pupil–subject pair
**Answer: b) In exactly one table — updates touch one place**
