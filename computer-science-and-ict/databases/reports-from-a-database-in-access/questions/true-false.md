# Reports from a Database in Access — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a report?" is: A formatted document arranging database records for reading or printing.**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Where do a report's records come from?" is: A reader who will never open the database.**
**Answer: False** — From a table, or from a query that already chose them.

**3. (Sub lesson 1) True or false: the answer to "What is grouping in a report?" is: Records of one kind together — one class, one month — under their own heading.**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What do totals do in a report?" is: Yes — if the arrangement does not match how the reader reads.**
**Answer: False** — Sum amounts within a group and overall.

**5. (Sub lesson 1) True or false: the answer to "Is a report a copy of the data?" is: No — it is a view; printing it again shows the current data in the same arrangement.**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Who is a report made for?" is: No — a report is made to be read, not edited.**
**Answer: False** — A reader who will never open the database.

**7. (Sub lesson 2) True or false: the answer to "What does creating a report involve?" is: Choosing source records, fields, grouping and order, and layout.**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Can perfect data still make a failed report?" is: From a table, or from a query that already chose them.**
**Answer: False** — Yes — if the arrangement does not match how the reader reads.

**9. (Sub lesson 2) True or false: the answer to "What are the Access course's parts, in order?" is: Tables, linking, forms, queries, sorting, then reports.**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Does the reader edit data in a report?" is: Sum amounts within a group and overall.**
**Answer: False** — No — a report is made to be read, not edited.
