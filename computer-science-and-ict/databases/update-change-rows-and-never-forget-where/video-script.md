# Video script — UPDATE — change rows, and never forget WHERE

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then. Short script — the placements name no full video for this lesson.

---

UPDATE changes what is already there. Nothing added. Nothing removed.

SET says the new value. WHERE chooses the rows.

Under ten thousand becomes fifteen thousand — only those rows.

Forget WHERE — and every row changes. Read the WHERE aloud. Every time.
