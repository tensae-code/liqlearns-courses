# Documenting Database Work — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — What the document holds
Sub lesson 1 questions from the type files. Pass mark: The build, in words and diagrams; The need; the design (entities, ERD, tables, keys); the objects built and what each does; the tests and their results; As the work goes — not reconstructed afterwards; A story — it will disagree with the database; The checker, the user, and the future maker.

## Sub lesson 2 — What documentation is for
Sub lesson 2 questions from the type files. Pass mark: Verifies the work against the need without rebuilding it; To change the database without breaking it; A competent stranger can say what every object is for and where a named fact lives; No — it makes the work outlast its maker's memory; Tables, forms, queries, reports and macros — with what each one does.
