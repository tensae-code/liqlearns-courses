# Documenting Database Work — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does documentation record?" is: The build, in words and diagrams**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Name the four parts Malaysia's document holds." is: As the work goes — not reconstructed afterwards**
**Answer: False** — The need; the design (entities, ERD, tables, keys); the objects built and what each does; the tests and their results

**3. (Sub lesson 1) True or false: the answer to "When is it written?" is: As the work goes — not reconstructed afterwards**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is a document written from memory at the end?" is: The checker, the user, and the future maker**
**Answer: False** — A story — it will disagree with the database

**5. (Sub lesson 1) True or false: the answer to "Name the document's three readers." is: The checker, the user, and the future maker**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does the checker do with it?" is: To change the database without breaking it**
**Answer: False** — Verifies the work against the need without rebuilding it

**7. (Sub lesson 2) True or false: the answer to "What does the future maker need it for?" is: To change the database without breaking it**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is Malaysia's practical standard?" is: No — it makes the work outlast its maker's memory**
**Answer: False** — A competent stranger can say what every object is for and where a named fact lives

**9. (Sub lesson 2) True or false: the answer to "Is documentation decoration?" is: No — it makes the work outlast its maker's memory**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What objects must each be explained?" is: The build, in words and diagrams**
**Answer: False** — Tables, forms, queries, reports and macros — with what each one does
