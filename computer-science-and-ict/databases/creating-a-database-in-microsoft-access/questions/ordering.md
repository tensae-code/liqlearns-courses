# Creating a database in Microsoft Access — ordering

Put the steps in the right order.

**1. (Sub lesson 2)** Creating a database — put in order: (a) click Create; (b) open MS Access; (c) type the name in the File Name box; (d) click Blank database.
**Answer:** b, d, c, a.

**2. (Sub lesson 3)** Inside the new database — put in order: (a) build queries and reports on it; (b) create a table.
**Answer:** b, a — the table comes before the other objects.
