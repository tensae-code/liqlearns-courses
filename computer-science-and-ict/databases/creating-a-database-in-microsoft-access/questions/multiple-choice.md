# Creating a database in Microsoft Access — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** An Access database is a container for objects such as —
a) tables, forms, queries and reports  b) printers and scanners  c) cables and disks
**Answer: a)** — tables, forms, queries and reports.

**2. (Sub lesson 1)** The first click after opening MS Access is —
a) Open Recent  b) Blank database  c) Sample templates
**Answer: b)** — Blank database.

**3. (Sub lesson 2)** The database name is typed in the —
a) File Name box  b) first table  c) query grid
**Answer: a)** — the File Name box.

**4. (Sub lesson 3)** Inside a new database, what must be created before the other objects?
a) a report  b) a form  c) a table
**Answer: c)** — a table, before the other objects.
