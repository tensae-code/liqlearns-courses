# Creating a database in Microsoft Access — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** An Access database is a container for objects such as —
a) tables, forms, queries and reports  b) printers and scanners  c) cables and disks
**Answer: a)** — tables, forms, queries and reports.

**2. (Sub lesson 1)** The first click after opening MS Access is —
a) Open Recent  b) Blank database  c) Sample templates
**Answer: b)** — Blank database.

**3. (Sub lesson 2)** The database name is typed in the —
a) File Name box  b) first table  c) query grid
**Answer: a)** — the File Name box.

**4. (Sub lesson 3)** Inside a new database, what must be created before the other objects?
a) a report  b) a form  c) a table
**Answer: c)** — a table, before the other objects.

**5. (Sub lesson 4)** To check Access's version you follow —
a) Create → Query Design  b) Start → All apps → Microsoft Office → Access with its year  c) Database Tools → Relationships  d) the Search box only
**Answer: b) Start → All apps → Microsoft Office → Access with its year** — the book's checking route.

**6. (Sub lesson 4)** The Grade 12 book creates its database —
a) from a template  b) blank, from scratch  c) by copying another  d) from a query
**Answer: b) blank, from scratch** — blank is chosen.

**7. (Sub lesson 4)** A table inside Access can be created in how many ways here?
a) one  b) two  c) three — Design, Datasheet, SQL  d) five
**Answer: c) three — Design, Datasheet, SQL** — three named ways.

**8. (Sub lesson 4)** The way this unit teaches is —
a) Datasheet View  b) Design View  c) the SQL way  d) templates
**Answer: c) the SQL way** — the unit teaches creating tables with SQL.
