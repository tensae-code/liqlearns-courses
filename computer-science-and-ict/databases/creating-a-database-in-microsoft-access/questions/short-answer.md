# Creating a database in Microsoft Access — short answer

Answer in a sentence or two.

**1. (Sub lesson 1)** Why is “Blank” database the right choice here?
**Answer:** You are starting a new, empty container of your own, not opening an existing database.

**2. (Sub lesson 2)** What appears when you click Create?
**Answer:** A new window opens, where the database's objects can be built.

**3. (Sub lesson 3)** Convert the student entity to a table plan: name the two fields the book types, with their types.
**Answer:** Name as Text, grade as Number.
