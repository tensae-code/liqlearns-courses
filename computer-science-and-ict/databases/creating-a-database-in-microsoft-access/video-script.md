---

Today you make your first database. In Microsoft Access. Four steps. Watch them once, then do them with me.

A database is a container. Tables live in it. Forms live in it. Queries and reports live in it. Nothing can live in it until the container exists — so the container comes first.

Step one: open MS Access.

Step two: click Blank database. Blank means empty, new, yours.

Step three: type the name. In the File Name box. Give it a name that describes the data inside — if this database will hold your school's students, name it for your school. A good name tells the next person what is inside before they open it.

Step four: click Create.

A new window opens. That window is your database, empty and ready.

What goes in first? A table. Always a table first — queries, forms and reports all work on tables, so nothing else can be built until a table exists.

Our first table will be the student: field by field, each field with its type. Name — Text. Grade — Number.

That table is the next lesson. For now: open, Blank database, name, Create. Say it back to me — then go and do it.
