# Creating a database in Microsoft Access

## Do it first

Say the four steps out loud before you touch the mouse: **open MS Access — click Blank database — type the name — click Create**. Short enough to hold in your head whole. Now go to the computer and do exactly those four, in that order. The lesson walks each step slowly and shows what the name you choose should do.

## Sub lesson 1 — Open Access and choose Blank database

In Microsoft Access (this unit teaches **Access 2010**), a **database** is **the container for objects such as tables, forms, queries and reports**. Everything you build in the rest of this title lives inside it — so **creating the database comes first**.

The book's order, steps 1–2:

1. **Open MS Access.**
2. **Click Blank database.**

“Blank” is the point: you are starting an empty container, not opening someone else's.

## Sub lesson 2 — Name it and click Create

Steps 3–4:

3. **Type the database name in the File Name box.** Choose a **name that describes the stored data** — a school database named after the school tells the next person what is inside before they open it.
4. **Click Create.**

A **new window then opens**, where the objects can be built.

[GIF 16913 — Blank database, name, Create]

## Sub lesson 3 — What comes first inside — a table

Inside the new database, **a table must be created before the other objects** — forms, queries and reports all work on tables, so the table comes first.

The unit's running example **converts the student entity into a table, field by field, with a data type per field**: the student's **name as Text**, the **grade as Number**. The entity you modelled earlier in this title is becoming a real table — the next lesson builds it, keystroke by keystroke.
