# Hands-on — Creating a database in Microsoft Access

The lesson with your hands, not only your eyes.

## The four steps, for real
On a computer with Access, create a new database named after your school, following the four steps in order. Close it and find it again by its name.

## Name that database
Given three sets of data — a shop's stock, a clinic's patients, a library's books — write a describing File Name for each database, and say what makes each name a good one.
