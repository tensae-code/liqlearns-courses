# Lesson plan — Creating a database in Microsoft Access

**Course:** Computer Science and ICT · **Title:** Databases · **Lesson:** Creating a database in Microsoft Access
**Place in the curriculum:** Unit 3 — Database Management (Ethiopia Grade 11 Information Technology), in the Databases title of the Computer Science and ICT course. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** in Access, a database is the container for objects such as tables, forms, queries and reports, and creating one comes first: open MS Access, click Blank database, type the database name in the File Name box, click Create.
**This lesson's own level:** it is a doing-lesson, in Access 2010 as the book teaches. It stands on the whole model half of this title — the database built here will hold the tables the models described.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Open Access and choose Blank database** — open MS Access; click Blank database — a database is the container for objects such as tables, forms, queries and reports, and creating one comes first
2. **Name it and click Create** — type the database name in the File Name box — a name that describes the stored data — then click Create; a new window opens where the objects can be built
3. **What comes first inside — a table** — a table must be created before the other objects; the running example converts the student entity into a table, field by field, with a data type per field (name as Text, grade as Number)

4. **Grade 12 — checking Access, launching it, and the three ways to make a table** — Grade 12: check Access installed and its version (Start → All apps → Microsoft Office → Access+year); launch by typing “access” in Search; template or blank — blank chosen; tables three ways (Design, Datasheet, SQL), the SQL way taught

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## What the learner can do when it ends
1. Say what an Access database is: the container for objects such as tables, forms, queries and reports.
2. Create a database in the book's order: open MS Access; Blank database; name it in the File Name box; Create.
3. Say what opens next and what must be built first: a table, before the other objects.
4. Convert the student entity into a table plan, field by field, with a data type per field (name as Text, grade as Number).

## What you need
A computer with Microsoft Access (the book teaches Access 2010) — this lesson is learned by doing it.

## If the learner is stuck
- Clicks a template or a recent file → the book's route is Blank database: an empty container of your own.
- Names the file “Database1” → choose a name that describes the stored data.
- Tries to build a query first → a table must be created before the other objects; everything else works on tables.
