# INSERT — adding a record to a table — true or false

Say true or false.

**1. (Sub lesson 1)** Form 1 can leave out a field it does not need.
**Answer: False** — form 1 gives values for all fields; partial inserts are form 2's work.

**2. (Sub lesson 2)** In form 2 the column list and value list must be in matching order.
**Answer: True** — each value answers the column named in its position.

**3. (Sub lesson 3)** Text may be inserted into a numeric field if it looks like a number.
**Answer: False** — each value must match its column's data type.

**4. (Sub lesson 3)** A single-value field given many values at once is a correct insert.
**Answer: False** — the diagnosis set names exactly that shape as broken (an F-or-M field given a multi-value entry).
