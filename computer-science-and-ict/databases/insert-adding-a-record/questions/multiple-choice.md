# INSERT — adding a record to a table — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Form 1 of INSERT requires —
a) a column list  b) values for all fields, in table order  c) only the key value  d) a WHERE clause
**Answer: b) values for all fields, in table order** — no column list — order does the matching.

**2. (Sub lesson 1)** In form 1, a value out of order —
a) is sorted automatically  b) lands in the wrong column  c) is rejected always  d) becomes the key
**Answer: b) lands in the wrong column** — position is the only guide in form 1.

**3. (Sub lesson 2)** Form 2 begins by naming —
a) the values  b) the chosen columns  c) the database  d) the primary key only
**Answer: b) the chosen columns** — columns first, then their values.

**4. (Sub lesson 2)** Form 2's values must match —
a) the table's raw order always  b) the named columns, in their listed order  c) alphabetical order  d) the key order
**Answer: b) the named columns, in their listed order** — values answer the named list.

**5. (Sub lesson 3)** The department value in the COURSE insert is written '105' with quotes because —
a) all numbers are quoted  b) that field is a string type  c) it is the key  d) Access prefers quotes
**Answer: b) that field is a string type** — quoting follows the column's type.

**6. (Sub lesson 3)** Contact hours 30 is written without quotes because —
a) it is short  b) it is an integer value  c) it comes first  d) quotes ran out
**Answer: b) it is an integer value** — numeric values are not quoted.
