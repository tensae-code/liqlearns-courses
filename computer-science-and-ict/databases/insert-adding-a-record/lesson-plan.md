# Lesson plan — INSERT — adding a record to a table

**Course:** Computer Science and ICT · **Title:** Databases · **Lesson:** INSERT — adding a record to a table
**Place in the curriculum:** Unit 3 — Database Management System (Ethiopia Grade 12 Information Technology), in the Databases title of the Computer Science and ICT course. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** INSERT adds a new record in two forms: give values for all fields in table order, or name the chosen columns and then their values — with strings quoted and numbers unquoted.
**This lesson's own level:** it stands on the DDL lessons: the tables stand linked and empty; DML now fills them.

## Before this lesson
- Recommended first: DROP TABLE — and why it cannot be undone (the DDL lessons). Recommended, never forced.

## What the learner can do when it ends
1. Insert a full record in form 1.
2. Insert with a named column list in form 2.
3. Quote strings and leave numbers bare, by type.
4. Keep field and value counts equal.

## If the learner is stuck
- A value lands in the wrong column in form 1 → form 1 has no names; count the table's columns and match the values to them one by one.
- Unsure whether to quote → ask the column's type: text is quoted, numbers are not — '105' quoted here only because its field is a string type.
