# Primary keys and foreign keys — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A primary key is a field whose value is —
a) the longest  b) unique for each record  c) always a name
**Answer: b)** — unique for each record.

**2. (Sub lesson 1)** The book's primary-key example is —
a) a student's address  b) a student ID no two students can share  c) a student's grade
**Answer: b)** — the student ID.

**3. (Sub lesson 2)** A foreign key is an attribute in one table that matches —
a) its own table's name  b) the primary key of a related table  c) any text field
**Answer: b)** — it matches the related table's primary key.

**4. (Sub lesson 3)** Inside the Book_Loan table, the student ID and book ID are —
a) primary keys of Book_Loan  b) foreign keys linking it to Student and Book  c) headings
**Answer: b)** — they link the loan to its student and its book.

**5. (Sub lesson 4)** Sid inside MarkList is —
a) a primary key  b) a foreign key — not unique  c) unique always  d) the table's name
**Answer: b) a foreign key — not unique** — one student has many mark records, so Sid repeats there.

**6. (Sub lesson 4)** How many tables stand in the Grade 12 school database?
a) three  b) four  c) five  d) seven
**Answer: c) five** — Students, MarkList, Subject, SubjectAssigned, Teachers.

**7. (Sub lesson 4)** Which of these is NOT an RDBMS?
a) MySQL  b) PostgreSQL  c) MongoDB  d) SQLite
**Answer: c) MongoDB** — MongoDB is a NoSQL system — the guide's listing of it as an RDBMS is an error.

**8. (Sub lesson 4)** Tables in a relational database are joined by —
a) matching page numbers  b) key-field linking — primary key to foreign key  c) alphabetical order  d) file folders
**Answer: b) key-field linking — primary key to foreign key** — the shared key field is the join.
