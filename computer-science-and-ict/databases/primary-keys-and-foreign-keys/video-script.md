# Video script — Primary keys and foreign keys

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then. Short script — the placements name no full video for this lesson.

---

Two students. The same name. Which record is whose?

The ID knows. No two students share an ID. A field that never repeats is the primary key.

Now the loan table. It holds a student ID — not its own, the Student table's. A borrowed key is a foreign key.

Follow the loan: this ID finds the student. That ID finds the book. Keys join the tables.
