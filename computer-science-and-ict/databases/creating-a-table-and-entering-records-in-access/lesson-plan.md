# Lesson plan — Creating a table and entering records in Access

**Course:** Computer Science and ICT · **Title:** Databases · **Lesson:** Creating a table and entering records in Access
**Place in the curriculum:** Unit 3 — Database Management (Ethiopia Grade 11 Information Technology), in the Databases title of the Computer Science and ICT course. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** a table is created in Table Design on the Create menu — field names in, a data type per field — saved and named, with a primary key set in Design view; then records are typed in, record by record, in Datasheet View.
**This lesson's own level:** it is a doing-lesson, in Access 2010 as the book teaches. It stands on Creating a database in Microsoft Access — the container exists; this lesson builds its first table and fills it.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Create the design — fields and data types** — open the database; click Table Design on the Create menu; enter the field names; set each field's data type — text, number, date/time, currency and so on; the type is itself a check
2. **Save, name — and set the primary key** — save and name the table; a primary key is set by selecting the field in Design view and clicking the Primary Key button
3. **Enter the records — Datasheet View** — open the table in Datasheet View and type the values record by record; the practice builds the Student, Teacher and Grade tables in a database named after your school

4. **Grade 12 — matching types to fields, and the Access SQL type set in detail** — Grade 12: every field needs a name and a data type, matched field by field (telephone as text); the Access SQL types in detail — CHAR, TEXT, INTEGER, DATETIME, CURRENCY, COUNTER, Yes/No with their limits

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Creating a database in Microsoft Access; Primary keys and foreign keys. Recommended, never forced.

## What the learner can do when it ends
1. Create a table in the book's order: open the database; Table Design on the Create menu; field names; a data type per field; save and name the table.
2. State the field rules: field names unique in a table; a table needs at least two fields.
3. Say why the data type is itself a check: a Text field will not accept a number.
4. Set a primary key: select the field in Design view and click the Primary Key button.
5. Enter records in Datasheet View, record by record; name the practice: Student, Teacher and Grade tables in a database named after your school.

## What you need
A computer with Microsoft Access (the book teaches Access 2010), and the database you created in the lesson before this one.

## If the learner is stuck
- Types records into Design view → Design view holds field names and types; records are typed in Datasheet View.
- Two fields with the same name → field names must be unique in a table.
- Forgets the key → set it in Design view: select the field, click the Primary Key button, before you leave the design.
