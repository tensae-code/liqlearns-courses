# Hands-on — Creating a table and entering records in Access

The lesson with your hands, not only your eyes.

## Build the school's three tables
In the database named after your school, build the Student, Teacher and Grade tables exactly in the book's order: Table Design, fields, types, primary key, save — then records in Datasheet view.

## Break the type check on purpose
In a practice table, try typing a number where a Text value belongs in the book's example sense — then try the reverse in a Number field — and watch how the data type guards the column. Say what each attempt teaches.

## Grade 12 — type the school office's fields
A school office keeps: pupil name, birth date, grade level, phone number, fees paid (birr), has a locker (yes/no), and a long conduct note. Assign each field its Access SQL type from Picture 30502 and defend the two traps: the phone number and the conduct note.
