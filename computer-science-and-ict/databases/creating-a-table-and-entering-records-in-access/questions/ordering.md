# Creating a table and entering records in Access — ordering

Put the steps in the right order.

**1. (Sub lesson 1)** Creating a table — put in order: (a) set each field's data type; (b) open the database; (c) enter the field names; (d) click Table Design on the Create menu; (e) save and name the table.
**Answer:** b, d, c, a, e.
