# Creating a table and entering records in Access — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Two fields in one table may share the same name.
**Answer: False** — field names must be unique in a table.

**2. (Sub lesson 1)** A table may be built with only one field.
**Answer: False** — a table needs at least two fields.

**3. (Sub lesson 3)** The practice builds the Student, Teacher and Grade tables in a database named after your school.
**Answer: True.**

**4. (Sub lesson 2)** The Primary Key button is clicked while the table is in Datasheet View.
**Answer: False** — the key is set in Design view: select the field, then click the Primary Key button.
