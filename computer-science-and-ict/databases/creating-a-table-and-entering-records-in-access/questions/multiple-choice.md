# Creating a table and entering records in Access — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** To create a table, you click Table Design on the —
a) Create menu  b) Home menu  c) File Name box
**Answer: a)** — Table Design, on the Create menu.

**2. (Sub lesson 1)** A Text field will not accept —
a) a name  b) a number  c) letters
**Answer: b)** — a number; the data type is itself a check.

**3. (Sub lesson 2)** A primary key is set by selecting the field in Design view and clicking —
a) Create  b) the Primary Key button  c) Datasheet View
**Answer: b)** — the Primary Key button.

**4. (Sub lesson 3)** Records are typed in, record by record, in —
a) Design view  b) Datasheet View  c) the File Name box
**Answer: b)** — Datasheet View.

**5. (Sub lesson 4)** A telephone number is typed as —
a) integer  b) text  c) currency  d) date
**Answer: b) text** — digits, but never calculated with — and its leading zero must survive.

**6. (Sub lesson 4)** CHAR(20) holds at most —
a) 20 characters  b) 255 characters  c) 63,999 characters  d) 20 numbers only
**Answer: a) 20 characters** — the size in brackets is the limit.

**7. (Sub lesson 4)** TEXT in Access SQL holds up to —
a) 255 characters  b) 999 characters  c) 63,999 characters  d) no limit
**Answer: c) 63,999 characters** — lengthy text's stated limit.

**8. (Sub lesson 4)** A unique number Access assigns itself to each new record is —
a) CURRENCY  b) DATETIME  c) COUNTER  d) Yes/No
**Answer: c) COUNTER** — sequential or random, assigned by Access.
