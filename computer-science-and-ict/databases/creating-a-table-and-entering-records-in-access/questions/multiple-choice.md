# Creating a table and entering records in Access — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** To create a table, you click Table Design on the —
a) Create menu  b) Home menu  c) File Name box
**Answer: a)** — Table Design, on the Create menu.

**2. (Sub lesson 1)** A Text field will not accept —
a) a name  b) a number  c) letters
**Answer: b)** — a number; the data type is itself a check.

**3. (Sub lesson 2)** A primary key is set by selecting the field in Design view and clicking —
a) Create  b) the Primary Key button  c) Datasheet View
**Answer: b)** — the Primary Key button.

**4. (Sub lesson 3)** Records are typed in, record by record, in —
a) Design view  b) Datasheet View  c) the File Name box
**Answer: b)** — Datasheet View.
