# Video script — Creating a table and entering records in Access

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

FULL script — the table-building walkthrough named in the placement for this lesson (item 37).

---

Your database is an empty container. Today it gets its first table — and its first real records.

Open your database. Now: the Create menu. Click Table Design.

A grid opens. This grid is the table's plan. Down it, type the field names — one field per row. Student ID. Name. Sex. Grade.

Beside each field, set its data type. Name takes Text. Grade takes Number. The type is a guard: a Text field will not accept a number, so a wrong value is stopped at the door.

Two rules while you type. Field names must be unique — no two fields in one table may share a name. And a table needs at least two fields.

Now the key. Select the student ID field — still in Design view — and click the Primary Key button. That field can now never repeat.

Save the table. Name it: Student.

The plan is built. Now fill it. Switch to Datasheet View — the same table, now as a grid of empty rows. Type the values, record by record, one student per row. Take your time; each value belongs in its own column.

Design view builds. Datasheet view fills. That is the rhythm of every table you will ever make.

Your practice: in the database named after your school, build three tables — Student, Teacher, Grade — design, key, and fill, each one the same way.
