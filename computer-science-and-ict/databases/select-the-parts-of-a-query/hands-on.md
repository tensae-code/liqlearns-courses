# Hands-on — SELECT — the parts of a query

The lesson with your hands, not only your eyes.

## Clause spotting
Take five queries from the following lessons. Underline SELECT, FROM, WHERE and ORDER BY in four colours and name each clause's settle-question.

## Finish the unfinished
You are given only `SELECT FirstName`. Add the missing required clause, then an optional WHERE and ORDER BY of your own.
