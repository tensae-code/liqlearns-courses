# SELECT — the parts of a query — true or false

Say true or false.

**1. (Sub lesson 1)** SELECT can draw records from more than one table.
**Answer: True** — one or more tables.

**2. (Sub lesson 2)** FROM is optional because Access guesses the table.
**Answer: False** — FROM is required — it names the tables holding the fields.

**3. (Sub lesson 2)** A query without WHERE returns only matching rows.
**Answer: False** — without criteria, all rows come back.

**4. (Sub lesson 2)** Calculations can be among the things a SELECT produces.
**Answer: True** — fields or calculations produce the data.
