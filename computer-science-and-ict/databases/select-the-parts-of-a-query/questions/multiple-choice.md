# SELECT — the parts of a query — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** SELECT retrieves —
a) all records only  b) all or a subset of records from one or more tables  c) only keys  d) new records to insert
**Answer: b) all or a subset of records from one or more tables** — subset or all, one table or more.

**2. (Sub lesson 1)** Which is NOT one of the five settle-questions?
a) what criteria data must match  b) whether and how to sort  c) what colour the output is  d) which fields produce the data
**Answer: c) what colour the output is** — colour is never a query question.

**3. (Sub lesson 2)** The required clauses are —
a) WHERE and ORDER BY  b) SELECT and FROM  c) SELECT and WHERE  d) FROM and ORDER BY
**Answer: b) SELECT and FROM** — fields and their tables are indispensable.

**4. (Sub lesson 2)** WHERE is —
a) required  b) optional — it sets the criteria each record must meet  c) the sorting clause  d) the field list
**Answer: b) optional — it sets the criteria each record must meet** — leave it out and all rows qualify.

**5. (Sub lesson 2)** ORDER BY settles —
a) which fields  b) which tables  c) how results are sorted  d) which rows match
**Answer: c) how results are sorted** — sorting is ORDER BY's question.

**6. (Sub lesson 1)** A query with no ORDER BY —
a) is invalid  b) returns rows in no promised order  c) returns nothing  d) sorts by key automatically
**Answer: b) returns rows in no promised order** — unset sorting means any order.
