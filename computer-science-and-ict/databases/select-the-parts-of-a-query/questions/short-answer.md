# SELECT — the parts of a query — short answer

Answer in a word, a line of SQL, or one short sentence.

**1. (Sub lesson 1)** Name the four clauses in their written order.
**Answer:** SELECT, FROM, WHERE, ORDER BY.

**2. (Sub lesson 2)** Which two clauses are required?
**Answer:** SELECT and FROM.

**3. (Sub lesson 1)** List the five things a complete query must settle.
**Answer:** What data a table contains; how data from different sources relate; which fields or calculations produce the data; what criteria data must match; whether and how to sort.
