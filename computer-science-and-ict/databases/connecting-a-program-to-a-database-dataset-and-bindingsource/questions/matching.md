# Connecting a Program to a Database — DataSet and BindingSource — matching

Match each item on the left with the one it belongs to on the right.

**2. (Sub lesson 1) Which database does the book work on?** → **Db_inf**

**3. (Sub lesson 1) What is a DataSet?** → **The database's tables copied into the program's memory**

**5. (Sub lesson 1) What stands between the DataSet and the form's controls?** → **The BindingSource**

**6. (Sub lesson 2) What does binding mean here?** → **Controls show the DataSet's rows / current record, moving together as the record moves**

**7. (Sub lesson 2) What does the BindingSource know when the user edits?** → **What must be saved back**

**8. (Sub lesson 2) Name the three named things of the connection.** → **The connection, the DataSet, and the BindingSource**

**9. (Sub lesson 2) Where does editing happen — on the database or the copy?** → **On the working copy, until it is saved back**
