# Data Governance and Access Control — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Governance — the rules above the tools
Sub lesson 1 questions from the type files. Pass mark: The rule-layer above the tools — who owns data, who decides its uses, how long it is kept, who answers for harm; Confusion, excess and neglect inside the house — tools protect it from attackers; Closing the database's unneeded doors (penguatan database); Database hardening, database security, network security, and the governance of access; For each person and each body of data: may they enter, and to do what — read, add, change, delete.

## Sub lesson 2 — Access control — the governed door
Sub lesson 2 questions from the type files.
