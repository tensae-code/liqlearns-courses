# The relational data model — tables of rows and columns — short answer

Answer in a sentence or two.

**1. (Sub lesson 1)** Give both names for a row and both names for a column.
**Answer:** A row is a record, also called a tuple; a column is an attribute, also called a field.

**2. (Sub lesson 2)** How does one relation link to another in this model?
**Answer:** A shared attribute is placed in one relation to link it to the other — the same attribute stands in both tables.

**3. (Sub lesson 3)** What three things does the guide's worked answer do before printing the joined table? (teacher evidence)
**Answer:** It identifies the linking attribute, gives the field count, and picks out the Kenyan cities.
