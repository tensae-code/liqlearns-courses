# The relational data model — tables of rows and columns — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Each row of a relation holds one unique instance.
**Answer: True.**

**2. (Sub lesson 2)** A relational model is a single table with no relationships.
**Answer: False** — it is a collection of relations with their attributes and relationships.

**3. (Sub lesson 3)** The guide's joined Country–City table covers nine cities in four countries. (teacher evidence)
**Answer: True** — nine cities across Ethiopia, Egypt, Kenya and Sudan.
