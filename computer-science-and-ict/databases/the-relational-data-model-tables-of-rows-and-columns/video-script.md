# Video script — The relational data model — tables of rows and columns

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then. Short script — the placements name no full video for this lesson.

---

A table. Rows going across. Columns going down.

The whole table is a relation.

One row — one student, complete. That row is a record. Its other name is a tuple.

One column — one fact about everybody. That column is an attribute. Its other name is a field.

And when the same attribute stands in two tables, the tables can join — country joins city, and one new table answers.

Grade 12 says it fully: the RDBMS creates, maintains, and controls access.

Column — field. Row — record. One value where they cross.

A patient: name, address, date visited, blood pressure, age — each field with its type.
