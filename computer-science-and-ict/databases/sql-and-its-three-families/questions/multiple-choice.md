# SQL — DDL, DML and DQL — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** SQL stands for —
a) Structured Query Language  b) Standard Question List  c) System Query Logic  d) Stored Query Language
**Answer: a) Structured Query Language** — it is the standard special-purpose language for relational databases.

**2. (Sub lesson 1)** SQL is used for —
a) drawing diagrams only  b) accessing and manipulating relational databases  c) printing reports only  d) designing networks
**Answer: b) accessing and manipulating relational databases** — that is its stated purpose.

**3. (Sub lesson 2)** Which family creates or modifies tables?
a) DQL  b) DML  c) DDL  d) none of them
**Answer: c) DDL** — Data Definition Language defines structure.

**4. (Sub lesson 2)** DROP TABLE belongs to —
a) DDL  b) DML  c) DQL  d) Access only
**Answer: a) DDL** — dropping a table changes structure, not data.

**5. (Sub lesson 3)** INSERT, UPDATE and DELETE belong to —
a) DDL  b) DQL  c) DML  d) the Relationships window
**Answer: c) DML** — Data Manipulation Language changes data.

**6. (Sub lesson 3)** SELECT belongs to —
a) DDL  b) DML  c) DQL  d) DCL
**Answer: c) DQL** — Data Query Language queries data.
