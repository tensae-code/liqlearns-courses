# SQL — DDL, DML and DQL — short answer

Answer in a word, a line of SQL, or one short sentence.

**1. (Sub lesson 1)** Write SQL's full name.
**Answer:** Structured Query Language.

**2. (Sub lesson 2)** Name the three DDL commands taught in this title.
**Answer:** CREATE TABLE, ALTER TABLE, DROP TABLE.

**3. (Sub lesson 3)** A command must remove one record but keep the table. Which family?
**Answer:** DML — the command is DELETE.
