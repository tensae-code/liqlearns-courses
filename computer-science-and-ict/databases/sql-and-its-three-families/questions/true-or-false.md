# SQL — DDL, DML and DQL — true or false

Say true or false.

**1. (Sub lesson 1)** SQL is a language invented only for Microsoft Access.
**Answer: False** — it is the standard language for relational databases; Access is one example.

**2. (Sub lesson 2)** DDL establishes relationships between tables.
**Answer: True** — creating/modifying tables and establishing relationships is DDL's job.

**3. (Sub lesson 3)** SELECT changes the records it shows.
**Answer: False** — SELECT only retrieves; it changes nothing stored.

**4. (Sub lesson 3)** The three SQL families are common to all DBMSs.
**Answer: True** — the unit states this directly.
