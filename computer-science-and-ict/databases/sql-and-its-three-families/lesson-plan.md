# Lesson plan — SQL — DDL, DML and DQL

**Course:** Computer Science and ICT · **Title:** Databases · **Lesson:** SQL — DDL, DML and DQL
**Place in the curriculum:** Unit 3 — Database Management System (Ethiopia Grade 12 Information Technology), in the Databases title of the Computer Science and ICT course. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** SQL is the standard language for relational databases, and its commands fall into three families: DDL defines tables, DML changes data, DQL asks for data.
**This lesson's own level:** it stands on the relational model and on keys: tables exist, and this lesson names the language that builds and questions them.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **SQL — one standard language** — SQL is the standard special-purpose language for accessing and manipulating relational databases
2. **DDL — Data Definition Language** — DDL creates or modifies tables and establishes relationships: CREATE, ALTER, DROP
3. **DML and DQL — changing data, asking for data** — DML inserts, updates, deletes (INSERT, UPDATE, DELETE); DQL queries with SELECT

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: The relational data model — tables of rows and columns; Primary keys and foreign keys. Recommended, never forced.

## What the learner can do when it ends
1. Say what SQL is and what it stands for.
2. Name the three families and the job of each.
3. Place CREATE, ALTER, DROP, INSERT, UPDATE, DELETE and SELECT in their families.

## If the learner is stuck
- Mixes DML and DQL → DML *changes* the data (insert, update, delete); DQL only *asks* — SELECT never changes a stored row.
- Thinks SQL belongs to Access only → it is the standard language for relational databases; Access is one home for it.
