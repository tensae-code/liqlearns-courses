# Organising Data — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What is organising data?** → **Arranging data by a chosen structure — same kind, same place, same shape**

**2. (Sub lesson 1) In a table, what are rows and columns?** → **Rows are records; columns are fields**

**3. (Sub lesson 1) What does each cell hold?** → **One value of its column's kind**

**4. (Sub lesson 1) What can organised data do that unorganised cannot?** → **Be searched, sorted, counted and compared**

**5. (Sub lesson 1) How can unorganised data be used?** → **Only read, slowly, by a human, once**

**6. (Sub lesson 2) Name the four organising decisions.** → **What is a record, which fields, what each field holds, what identifies each record**

**7. (Sub lesson 2) Why only needed fields?** → **Every extra field is collecting and guarding forever**

**8. (Sub lesson 2) What must a field's shape fix?** → **Its type and allowed shape — dates one way, names one way**

**9. (Sub lesson 2) What keeps two same-named pupils distinct?** → **The identifying key**

**10. (Sub lesson 2) What is a database, in the closing definition?** → **Organised data with these decisions enforced by the machine**
