# Organising Data — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Arranging data by a chosen structure — same kind, same place, same shape**
**Answer: True**

**2. (Sub lesson 1) True or false: Arranging data by a chosen structure — same kind, same place, same shape** — as the answer to: In a table, what are rows and columns?
**Answer: False — Rows are records; columns are fields**

**3. (Sub lesson 1) True or false: One value of its column's kind**
**Answer: True**

**4. (Sub lesson 1) True or false: One value of its column's kind** — as the answer to: What can organised data do that unorganised cannot?
**Answer: False — Be searched, sorted, counted and compared**

**5. (Sub lesson 1) True or false: Only read, slowly, by a human, once**
**Answer: True**

**6. (Sub lesson 2) True or false: Only read, slowly, by a human, once** — as the answer to: Name the four organising decisions.
**Answer: False — What is a record, which fields, what each field holds, what identifies each record**

**7. (Sub lesson 2) True or false: Every extra field is collecting and guarding forever**
**Answer: True**

**8. (Sub lesson 2) True or false: Every extra field is collecting and guarding forever** — as the answer to: What must a field's shape fix?
**Answer: False — Its type and allowed shape — dates one way, names one way**

**9. (Sub lesson 2) True or false: The identifying key**
**Answer: True**

**10. (Sub lesson 2) True or false: The identifying key** — as the answer to: What is a database, in the closing definition?
**Answer: False — Organised data with these decisions enforced by the machine**
