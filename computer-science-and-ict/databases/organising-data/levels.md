# Organising Data — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — What organising data means
Sub lesson 1 questions from the type files. Pass mark: Arranging data by a chosen structure — same kind, same place, same shape; Rows are records; columns are fields; One value of its column's kind; Be searched, sorted, counted and compared; Only read, slowly, by a human, once.

## Sub lesson 2 — The organising decisions
Sub lesson 2 questions from the type files. Pass mark: What is a record, which fields, what each field holds, what identifies each record; Every extra field is collecting and guarding forever; Its type and allowed shape — dates one way, names one way; The identifying key; Organised data with these decisions enforced by the machine.
