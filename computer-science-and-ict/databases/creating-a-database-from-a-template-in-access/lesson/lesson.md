# Creating a Database from a Template in Access

## Do it first

Access templates are ready-made databases — structure, tables, forms and reports already designed for a common job — from which a new working database can be created in a few steps

## Sub lesson 1 — Create a database by using a template

Access templates are ready-made databases — structure, tables, forms and reports already designed for a common job — from which a new working database can be created in a few steps The learner starts Access, chooses a template, names the new database, and opens it to find tables and forms already built and ready for data Because not every database must start from a blank page; a template gives a tested design that the learner can study and adapt.
