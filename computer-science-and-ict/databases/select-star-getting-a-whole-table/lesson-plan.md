# Lesson plan — SELECT * — getting a whole table

**Course:** Computer Science and ICT · **Title:** Databases · **Lesson:** SELECT * — getting a whole table
**Place in the curriculum:** Unit 3 — Database Management System (Ethiopia Grade 12 Information Technology), in the Databases title of the Computer Science and ICT course. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** SELECT * FROM a table retrieves all its records and all its columns — the asterisk means every column, exactly as if each field were listed by name.
**This lesson's own level:** it stands on SELECT — the parts of a query: the simplest complete query, taken carefully.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The asterisk means all columns** — SELECT * retrieves all records and columns; * means all columns, equal to listing every field; use * when all fields are wanted
2. **Exact names — the spelling rule** — named fields must be spelled exactly as in the table; (teacher guide — evidence) * as good practice on many-column tables — listing invites naming errors

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: SELECT — the parts of a query. Recommended, never forced.

## What the learner can do when it ends
1. Retrieve a whole table with SELECT *.
2. Explain * as 'all columns', equal to the full field list.
3. Spell named fields exactly as the table does.
4. Choose * deliberately on wide tables.

## What you need
A computer with Microsoft Access (2013 or later), or paper.

## If the learner is stuck
- Thinks * means all rows but chosen columns → * is about columns; rows are all because there is no WHERE.
- A named-field query fails → compare each name letter by letter with the table's design; exact spelling is the rule.
