# SELECT * — getting a whole table — true or false

Say true or false.

**1. (Sub lesson 1)** SELECT * returns the same columns as listing every field.
**Answer: True** — identical result, shorter statement.

**2. (Sub lesson 1)** The asterisk also chooses which rows return.
**Answer: False** — rows are chosen by WHERE (or all rows without it).

**3. (Sub lesson 2)** Field names in SELECT may be spelled approximately.
**Answer: False** — exact spelling is required.

**4. (Sub lesson 2)** Using * on a wide table can prevent naming errors.
**Answer: True** — you cannot misspell a name you never write.
