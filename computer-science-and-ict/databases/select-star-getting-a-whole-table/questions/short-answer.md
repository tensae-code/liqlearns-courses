# SELECT * — getting a whole table — short answer

Answer in a word, a line of SQL, or one short sentence.

**1. (Sub lesson 1)** Write the query showing the whole COURSE table.
**Answer:** SELECT * FROM COURSE;

**2. (Sub lesson 2)** A listed-field query fails while the table is fine. Name the likely fault.
**Answer:** A field name is not spelled exactly as in the table.

**3. (Sub lesson 2)** In one sentence: when is * the better choice?
**Answer:** When all fields are wanted — especially on a many-column table, where listing invites naming errors.
