# Designing a Relational Database — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — From the need to entities and attributes
Sub lesson 1 questions from the type files. Pass mark: From the need — what the database must hold and what questions it must answer; The kinds of thing the database is about — Pupil, Book, Loan; The facts kept about an entity — a pupil's name, class, date of birth; Only if the need asks for it; A question the database must answer.

## Sub lesson 2 — Keys, relationships, and the tables
Sub lesson 2 questions from the type files. Pass mark: The attribute (or added ID) that picks out one record from all others; The relationships between entities, with their cardinality; One per entity, attributes as columns, keys in place; Foreign keys; A guess the data will later pay for.
