# Hands-on — Designing a Relational Database

The lesson with your hands and your feet, not only your eyes.

## Task one
('Design a loans database', 'Need: a school library must answer 'who holds book X?' and 'which books does pupil Y hold?'. Design the database fully on paper: entities, attributes, keys, relationships with cardinality, then the tables.')

## Task two
('Trace the columns', 'Take any database table you have used. For each column, write the question from the need that justifies it. Mark any column no question justifies.')
