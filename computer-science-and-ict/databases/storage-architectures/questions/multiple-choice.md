# Storage Architectures — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is the simplest architecture?**
a) Storage attached to the machine that uses it  b) Stranded — others cannot reach the same data  c) Shelves on the network as a named place any authorised machine may reach  d) Copies scattered per desk that disagree
**Answer: a**

**2. (Sub lesson 1) Its flaw is what?**
a) Shelves on the network as a named place any authorised machine may reach  b) Stranded — others cannot reach the same data  c) Copies scattered per desk that disagree  d) Greece Grade 11 Eisagogi Epistimis H/Y, Ch.3.2
**Answer: b**

**3. (Sub lesson 1) What is network-attached storage?**
a) Copies scattered per desk that disagree  b) Greece Grade 11 Eisagogi Epistimis H/Y, Ch.3.2  c) Shelves on the network as a named place any authorised machine may reach  d) Storage as its own dedicated network behind the servers, shared as pools at machine-room speed
