# Charts from Access Data — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Why chart data where it lives
Sub lesson 1 questions from the type files. Pass mark: A table's or query's records, without leaving the database; Members per class, or sales per month; The comparison at a glance; A chart of raw unsummarised records is noise.

## Sub lesson 2 — Making the chart — source, type, reading
Sub lesson 2 questions from the type files. Pass mark: A query that has already summarised the records; Columns (or bars); A line; A pie; Labels and a title; Laos Grade 12 ICT, Chapter 3 §IV.2.
