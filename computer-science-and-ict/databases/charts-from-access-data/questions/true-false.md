Say true or false, and fix the false ones in your own words.

**Answer: True**

**2. (Sub lesson 1) True or false: The comparison at a glance** — as the answer to: Give two summaries a chart might draw.

**3. (Sub lesson 1) True or false: The comparison at a glance**

**4. (Sub lesson 2) True or false: Columns (or bars)** — as the answer to: What is the best source for a chart?

**5. (Sub lesson 2) True or false: Columns (or bars)**
**Answer: True**

**6. (Sub lesson 2) True or false: A pie** — as the answer to: Which type shows change over time?
