# Charts from Access Data — matching

Match each item on the left with the one it belongs to on the right.

**7. (Sub lesson 2) Which type shows parts of one whole?** → **A pie**

**8. (Sub lesson 2) What must a chart carry to read honestly?** → **Labels and a title**
