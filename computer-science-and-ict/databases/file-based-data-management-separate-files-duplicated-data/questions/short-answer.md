# File-based data management — separate files, duplicated data — short answer

Answer in a sentence or two.

**1. (Sub lesson 1)** Why does each department end up keeping its own files in the file-based approach?
**Answer:** Each file is managed by its own application program built for that department's work, so each department keeps and maintains its own files.

**2. (Sub lesson 2)** What two words does the book use for what duplicated, drifting data becomes?
**Answer:** Inconsistent (the copies disagree) and redundant (the same facts stored more than once).

**3. (Sub lesson 3)** Name the limitation the teacher guide adds to the student book's list. (teacher evidence)
**Answer:** Organisation-wide security — data scattered across separately owned files and programs cannot be put under one security procedure without difficulty and cost.
