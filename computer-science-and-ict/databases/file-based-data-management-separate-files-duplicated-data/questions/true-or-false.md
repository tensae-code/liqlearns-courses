# File-based data management — separate files, duplicated data — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** In the file-based approach, changing the program can mean changing the file structure.
**Answer: True** — file and program are tied together.

**2. (Sub lesson 2)** Duplicated copies in separate files are linked, so they always stay the same.
**Answer: False** — the copies are never linked, and they drift out of step.

**3. (Sub lesson 3)** Scattered files make one organisation-wide security procedure easy and cheap. (teacher evidence)
**Answer: False** — the guide's answer says it becomes difficult and expensive.
