# File-based data management — separate files, duplicated data — fill in the blank

Fill each blank with the right word.

**1. (Sub lesson 1)** In the file-based approach, files have no explicit __________ between them.
**Answer: relationships**

**2. (Sub lesson 2)** Storing the same data in more than one file is called __________.
**Answer: duplication** (the data kept this way is redundant).
