# File-based data management — separate files, duplicated data — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** In the file-based approach, data is stored —
a) in one shared collection  b) in separate files with no explicit relationships  c) only on paper
**Answer: b)** — separate files, and nothing links them.

**2. (Sub lesson 1)** Each file is managed by —
a) its own application program  b) one program for the whole organisation  c) the database software
**Answer: a)** — every file has its own program.

**3. (Sub lesson 2)** The book's example of duplicated data is —
a) employee records kept in both HR and Finance  b) a backup tape  c) a printed report
**Answer: a)** — the same employee records in two departments' files.

**4. (Sub lesson 2)** When copies are updated separately and disagree, the data is —
a) independent  b) inconsistent  c) secure
**Answer: b)** — inconsistent: the copies no longer agree.

**5. (Sub lesson 3)** Pulling together the whole organisation's data from separate files is —
a) automatic  b) very difficult  c) instant
**Answer: b)** — the files were never made to join.
