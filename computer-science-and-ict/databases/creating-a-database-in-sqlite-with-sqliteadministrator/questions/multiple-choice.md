# Creating a Database in SQLite with SQLiteAdministrator — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is SQLite?**
a) A database system that keeps a whole database in one file  b) In a single file on the disk  c) A server or an administrator account  d) The graphical tool for creating and working with SQLite databases
**Answer: a) A database system that keeps a whole database in one file**

**2. (Sub lesson 1) Where does an SQLite database live?**
a) A server or an administrator account  b) In a single file on the disk  c) The graphical tool for creating and working with SQLite databases  d) The programming in LiveCode that follows
**Answer: b) In a single file on the disk**

**3. (Sub lesson 1) What does SQLite not need?**
a) The graphical tool for creating and working with SQLite databases  b) The programming in LiveCode that follows  c) A server or an administrator account  d) The new database file, named
**Answer: c) A server or an administrator account**

**4. (Sub lesson 1) What is SQLiteAdministrator?**
