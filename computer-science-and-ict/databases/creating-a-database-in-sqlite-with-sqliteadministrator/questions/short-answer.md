# Creating a Database in SQLite with SQLiteAdministrator — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is SQLite?**
**Answer: A database system that keeps a whole database in one file**

**2. (Sub lesson 1) Where does an SQLite database live?**
**Answer: In a single file on the disk**

**3. (Sub lesson 1) What does SQLite not need?**
**Answer: A server or an administrator account**

**4. (Sub lesson 1) What is SQLiteAdministrator?**
**Answer: The graphical tool for creating and working with SQLite databases**

**5. (Sub lesson 1) What is the SQLite database preparation for, in Cuba's book?**
**Answer: The programming in LiveCode that follows**

**6. (Sub lesson 2) What is created first?**
**Answer: The new database file, named**

**7. (Sub lesson 2) What is created inside the database?**
**Answer: The tables the data needs**

**8. (Sub lesson 2) What is defined inside each table?**
**Answer: Its fields — name and type for each column**

**9. (Sub lesson 2) What must be settled before the first table is made?**
**Answer: The design — what tables and what fields**

**10. (Sub lesson 2) What does a wrongly defined field cost?**
**Answer: Every record after it pays for it**
