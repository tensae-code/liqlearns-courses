# Hands-on — Creating a Database in SQLite with SQLiteAdministrator

The lesson with your hands and your feet, not only your eyes.

## Task one
('Create a school database', 'In SQLiteAdministrator (or on paper in its shape): create a database file, one table for pupils, and fields for name, grade and mark. Say the type of each field and why.')

## Task two
('Design before tables', "Design a database for a school library — books and loans: name its tables and each table's fields before any tool is opened, and defend one field's type.")
