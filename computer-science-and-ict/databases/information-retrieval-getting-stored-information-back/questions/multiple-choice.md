# Information Retrieval — Getting Stored Information Back — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is information retrieval?**
a) Getting stored information back out of a system to answer a need  b) Because storage was organised — records in fields, in a known order or index  c) Read everything to find anything  d) Stored in one section, retrieved in the next — a store you cannot retrieve from is a hole, not a database
**Answer: a) Getting stored information back out of a system to answer a need**

**2. (Sub lesson 1) Why does retrieval work at all?**
a) Read everything to find anything  b) Because storage was organised — records in fields, in a known order or index  c) Stored in one section, retrieved in the next — a store you cannot retrieve from is a hole, not a database  d) A name looked up; a record found; a list drawn
**Answer: b) Because storage was organised — records in fields, in a known order or index**

**3. (Sub lesson 1) What would the system have to do without organisation?**
a) Stored in one section, retrieved in the next — a store you cannot retrieve from is a hole, not a database  b) A name looked up; a record found; a list drawn  c) Read everything to find anything  d) As a request in the system's terms — the field, the value, the conditions
**Answer: c) Read everything to find anything**
