# Information Retrieval — Getting Stored Information Back — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is information retrieval?" is: Getting stored information back out of a system to answer a need**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Why does retrieval work at all?" is: Read everything to find anything**
**Answer: False** — Because storage was organised — records in fields, in a known order or index

**3. (Sub lesson 1) True or false: the answer to "What would the system have to do without organisation?" is: Read everything to find anything**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How does Fiji pair storage and retrieval?" is: A name looked up; a record found; a list drawn**
**Answer: False** — Stored in one section, retrieved in the next — a store you cannot retrieve from is a hole, not a database

**5. (Sub lesson 1) True or false: the answer to "Give a retrieval in plain words." is: A name looked up; a record found; a list drawn**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How is a retrieval asked?" is: It returns everything that matches, and only what matches**
**Answer: False** — As a request in the system's terms — the field, the value, the conditions

**7. (Sub lesson 2) True or false: the answer to "What are retrieval's two quality tests?" is: It returns everything that matches, and only what matches**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Give Fiji's school example." is: Fast, complete and exact**
**Answer: False** — All Year 11 pupils in Suva — every such pupil, and no Year 12 visitor

**9. (Sub lesson 2) True or false: the answer to "In three words, what is good retrieval?" is: Fast, complete and exact**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Whose promise does retrieval keep?" is: Getting stored information back out of a system to answer a need**
**Answer: False** — Storage's — the promise that what was put in can be got back
