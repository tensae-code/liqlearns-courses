# Sizing a Form or Report in Access — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The size of a form or report — its width and each section's height — decides how much fits on the screen or page, and Access lets the designer set that size exactly or let the form size itself to its content**
**Answer: True**
