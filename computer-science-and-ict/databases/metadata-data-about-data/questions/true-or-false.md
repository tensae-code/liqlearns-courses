# Metadata — Data about Data — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Machines can write metadata automatically, without a person typing it.**
**Answer: True — Cameras stamp EXIF data; computers record a file’s size and creation date by themselves.**

**2. (Sub lesson 2) If an item’s metadata is wrong, the item itself is deleted from the disk.**
**Answer: False — The item is still there; it is lost in plain sight because searches read the wrong record and never find it.**
