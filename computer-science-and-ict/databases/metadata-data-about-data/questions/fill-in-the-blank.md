# Metadata — Data about Data — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 1) Metadata means data ____ data.**
**Answer: about — The record describes the item it belongs to.**

**2. (Sub lesson 2) The metadata a camera hides inside a photo is called ____.**
**Answer: EXIF — Date, device, settings and often the GPS place.**
