# Metadata — Data about Data — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Metadata is —**
a) A kind of password  b) Data that describes other data  c) The largest file on a disk  d) A backup copy
**Answer: b) Data that describes other data — Title, author, date, format: the record about the item, not the item itself.**

**2. (Sub lesson 1) Which of these is administrative metadata for a document?**
a) Its subject  b) Its file format and size  c) Its first sentence  d) Its reader’s opinion
**Answer: b) Its file format and size — Administrative metadata is what a machine or librarian needs to manage the item.**

**3. (Sub lesson 2) When a catalogue search finds "French novels from 2020", it works by —**
a) Opening every book  b) Filtering the metadata records  c) Guessing  d) Reading the last page of each book
**Answer: b) Filtering the metadata records — Searches run on the descriptions, never on the full content of millions of items.**
