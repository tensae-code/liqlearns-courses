# Data Entry Forms in Access — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a form in Access?" is: A layout showing one record at a time in labelled fields, for entering and reading data.**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is wrong with entering straight into a table?" is: With the navigation controls, moving record by record.**
**Answer: False** — The bare grid makes it easy to type into the wrong row or miss a field.

**3. (Sub lesson 1) True or false: the answer to "Does a form hold its own data?" is: No — everything typed into it lands in the underlying table.**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does creating a form involve?" is: Makes correct entry the easy path.**
**Answer: False** — Choosing the table and arranging its fields — which appear, in what order, with what labels.

**5. (Sub lesson 1) True or false: the answer to "What does filling a form involve?" is: Moving to a new blank record and typing each field.**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How do you view earlier records in a form?" is: Yes — navigate to it and edit its fields.**
**Answer: False** — With the navigation controls, moving record by record.

**7. (Sub lesson 2) True or false: the answer to "Who is a form made for?" is: People who use the database without needing to see a table.**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does a well-made form do?" is: The bare grid makes it easy to type into the wrong row or miss a field.**
**Answer: False** — Makes correct entry the easy path.

**9. (Sub lesson 2) True or false: the answer to "Where does this section stand in the Access course?" is: After linking tables — before queries.**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Can a form correct an existing record?" is: Choosing the table and arranging its fields — which appear, in what order, with what labels.**
**Answer: False** — Yes — navigate to it and edit its fields.
