# Data Integrity, Consistency and Redundancy — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does data integrity mean?" is: The data is correct and complete — true values entered under rules**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Give a rule integrity is kept by." is: The database never disagrees with itself — the same fact reads the same everywhere**
**Answer: False** — A mark between 0 and 100 (also: a date that exists)

**3. (Sub lesson 1) True or false: the answer to "What does data consistency mean?" is: The database never disagrees with itself — the same fact reads the same everywhere**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does integrity guard, and what does consistency guard?" is: Integrity and consistency — with redundancy, the three chapter-opening words**
**Answer: False** — Integrity guards each value; consistency guards the agreement between values

**5. (Sub lesson 1) True or false: the answer to "Name the pair Malaysia teaches together here." is: Integrity and consistency — with redundancy, the three chapter-opening words**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is redundancy?" is: The copies can drift apart — update one, miss another, and consistency breaks**
**Answer: False** — Storing the same fact in more than one place

**7. (Sub lesson 2) True or false: the answer to "What is redundancy's deeper harm?" is: The copies can drift apart — update one, miss another, and consistency breaks**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is Malaysia's design answer?" is: No — sometimes accepted knowingly for speed, as a chosen trade**
**Answer: False** — Store each fact once, in its own table, and refer to it by a key

**9. (Sub lesson 2) True or false: the answer to "Is all copying always forbidden?" is: No — sometimes accepted knowingly for speed, as a chosen trade**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What must copying never be?" is: The data is correct and complete — true values entered under rules**
**Answer: False** — An accident of design
