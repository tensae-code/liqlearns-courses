# What a Database Is — Tables of Information — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a database?**
**Answer: Information kept in an organised shape — tables of records and fields — that a computer can work on**

**2. (Sub lesson 1) What is a table's shape?**
**Answer: Rows of records, columns of fields, one kind of thing per table**

**3. (Sub lesson 1) What does the shape make possible? Name two.**
**Answer: Searching the whole store quickly, and sorting it (also: trusting records answer the same questions)**

**4. (Sub lesson 1) Why does a program connect to a database?**
**Answer: The information must outlive the program's run and be shared**

**5. (Sub lesson 1) What happens to records when the program closes?**
**Answer: They stay on disk**

**6. (Sub lesson 2) What is the alternative the database replaces?**
**Answer: Private copies of the data that drift apart**

**7. (Sub lesson 2) What are forms, grids and reports, in this view?**
**Answer: Windows onto tables that live apart from any one program**

**8. (Sub lesson 2) Which year's work does this open?**
**Answer: Kuwait's Grade 12 Visual Basic database book (Book 3, Dealing with Databases)**

**9. (Sub lesson 2) Who holds the data — the program or the database?**
**Answer: The database — the program connects to it**

**10. (Sub lesson 2) Which book teaches this?**
**Answer: Kuwait Grade 12 Information Technology Term 2, Book 3 opening**
