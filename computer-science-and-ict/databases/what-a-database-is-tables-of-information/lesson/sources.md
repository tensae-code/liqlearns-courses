Placement choice: this lesson was built new for the ICT expansion (Kuwait, 2026-11-14) because no existing lesson in the course covers this thing as its own lesson — the live tree was checked for the slug and the live lesson content was checked for near matches before building. The placements file named this slug directly (NEW LESSON NEEDED — databases/what-a-database-is-tables-of-information). It sits in the Databases title (databases/), following the book's own order. Provenance scope note: every counted placement stocked here is from a Kuwait student book. Media slots in lesson/lesson.md are described slots only ([Picture — …]); no picture numbers are invented.

Kuwait's own way (Grade 12 Information Technology Term 2): Term 2 of the legacy Visual Basic year: loops first (definite For…Next, then indefinite Do…Loop), then the richer form controls (data boxes and option tools), and finally real database work — connect a VB program to a database, show its tables in a grid, add and edit records, and print reports. The grade-12 exit skill is a working database application.

Moldova's own way (Grade 12, Informatică): the final year goes deep in three directions at once — real programming technique (complexity, greedy, sifting, recursion vs iteration), numerical modelling (errors, bisection, chord and rectangle methods), and a full Access databases course — the same Pascal/C++ pair carrying the programming chapters, and a closing Extensii chapter that points to CTICE downloads for five advanced topics.


Kazakhstan's own way (Zhunusov G10 Computer Science, English-medium): the English-medium Grade 10 book is the most technical of the wave: the CIA triad and three separate authentication lessons (passwords twice, biometrics), encoding standards, Python dictionaries, DFS/BFS graph traversal, and a full SQL chapter in MySQL (CREATE, INSERT, SELECT/WHERE, MIN/MAX, JOIN, GROUP BY, SELECT INTO) before a JavaScript chapter. (Its preface is the publisher's generic science template, left over from another book.)

Kazakhstan's own way (Adekenova & Pryanichnikova G9 Informatics, NIS): the NIS Grade 9 course is built around databases and object-oriented programming: computer architecture with logic circuits, coding raster images and sound, single-table then multi-table databases in Access (forms, queries, reports), five lessons introducing OOP, nine lessons developing applications in an OOP environment (C#), and a thirteen-lesson capstone — choosing a problem, designing the interface, programming, making a video instruction, testing, documenting and evaluating the project.

Kazakhstan's own way (Kolyeva G9 Informatika): the Mektep Grade 9 book is the Google-cloud book: joint work on documents and presentations in Google services with shared-access settings and network etiquette, a practical chapter on choosing and pricing a computer and its software, databases built inside spreadsheets, then Python lists (search, replace, sort, insert/delete, two-dimensional) and 2D games with PyGame.

Kazakhstan's own way (Yerzhanov G9 Informatics, English-medium): the English-medium twin of the Mektep Grade 9 book — the same four chapters (computer literacy with netiquette and pricing a computer, database basics with pivot tables and a "family shop" mini-project, Python lists, PyGame 2D games ending in a Program Arcade Game) taught in English with trilingual terminology.

Kazakhstan's own way (Mukhametzhanova G9 Informatika): the Atamura Grade 9 book covers the same ground as the Mektep book (information properties and joint document work, choosing a computer, databases, Python lists, PyGame) but in longer, deeper lessons — each topic runs seven to ten pages instead of two to four.

Kazakhstan's own way (Kadirkulov G9 Informatika): Almatykitap's Grade 9 book splits sorting and filtering into separate lessons plus an advanced-filter lesson, gives data input/output in one-dimensional arrays its own lesson, and has the fullest PyGame part of the wave — seven lessons ending in a complete "Footballer" game with sprite-collision detection.

Kazakhstan's own way (Heathcote ICT Grade 10): an imported British ICT course (Express Publishing's Grammar Schools series) adapted for Kazakhstan — ten modules that include two topics the national books do not teach at all: expert and control systems, and developing a mobile app.
