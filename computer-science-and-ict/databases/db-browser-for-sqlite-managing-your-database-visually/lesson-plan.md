## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Meeting DB Browser — menus and the database on screen** — **DB Browser for SQLite** is a program that opens an SQLite database file and shows it **visually**: the tables it holds, each table's structure, and the data inside — without writing code. Its **menus** carry the working acts: open and save the database, create and work on tables, and move between the structure view and the data view. Kuwait teaches it inside the first databases lesson so the pupil always has a way to **see** what their Python code has done.
2. **Modifying structure and browsing data** — Two acts define the tool's daily use. **Modifying a table's structure** — the visual way to change what a table is: its fields and their kinds, adjusted on screen where mistakes are visible before they are saved. And **browsing the data**: walking the records of a table row by row, checking with the eye what an INSERT added or an UPDATE changed. Code builds; the Browser verifies — the pair is the course's working method.
