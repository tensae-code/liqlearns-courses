# DB Browser for SQLite — Managing Your Database Visually — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is DB Browser for SQLite?**
**Answer: A program that opens an SQLite database and shows it visually — tables, structure and data**

**2. (Sub lesson 1) What do its menus carry?**
**Answer: The working acts — open and save, work on tables, move between structure and data views**

**3. (Sub lesson 1) Why does Kuwait teach it in the first databases lesson?**
**Answer: So the pupil can always see what their Python code has done**

**4. (Sub lesson 1) What is modifying a table's structure?**
**Answer: Changing what a table is — its fields and kinds — on screen**

**5. (Sub lesson 1) Why modify visually?**
**Answer: Mistakes are visible before they are saved**

**6. (Sub lesson 2) What is browsing the data?**
**Answer: Walking a table's records row by row, checking with the eye**

**7. (Sub lesson 2) What does browsing verify?**
**Answer: What an INSERT added or an UPDATE changed**

**8. (Sub lesson 2) State the course's working method in four words.**
**Answer: Code builds; the Browser verifies**

**9. (Sub lesson 2) Which database file does the Grade 11 course work on?**
**Answer: Kuwait_landmarks.db — the landmarks database**

**10. (Sub lesson 2) Which book teaches this?**
**Answer: Kuwait Grade 11 Information Technology Term 1, Unit 1 Lesson 1**
