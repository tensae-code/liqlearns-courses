# Hands-on — Records Files and File Types

The lesson with your hands and your feet, not only your eyes.

## Task one
**Work the book's own example** — Chapter 1 §1.2 Traditional File System (record and file; file types by use — master, transaction, backup; by function — program files and data files and their extensions; file organization — sequential, direct/random, indexed sequential) Work it with the book open first, step by step, then close the book and do it again.

## Task two
**Show it to someone else** — Teach records files and file types to a companion in your own words, with your worked example in front of you, and answer their one question from the lesson.
