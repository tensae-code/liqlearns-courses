# Video script — Structured Data — Objects, Descriptors and Collections

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

To store facts about the world, start with one thing. A book. That is an object.

Describe it. Title. Author. Year. Pages. Each of those is a descriptor. For this book, each descriptor has a value.

Now gather many books, all described the same way. That gathering is a collection.

Draw it as a table. One row for each object. One column for each descriptor.

That table is the shape of all structured data. Spreadsheets use it. Files use it. Databases use it. It starts here: object, descriptor, value.
