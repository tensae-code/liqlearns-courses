# Structured Data — Objects, Descriptors and Collections — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 1) One single thing being described — one book, one student — is called an ____.**
**Answer: object — The object is what the data is about.**

**2. (Sub lesson 2) A set of objects described by the same descriptors is a ____.**
**Answer: collection — Drawn as a table of rows and columns.**
