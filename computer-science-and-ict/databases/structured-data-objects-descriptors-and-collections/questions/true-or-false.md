# Structured Data — Objects, Descriptors and Collections — true or false

Say whether each statement is true or false.

**1. (Sub lesson 2) In a collection, each object may be described by its own different set of descriptors.**
**Answer: False — A collection means the SAME descriptors for every object; that is what makes the columns of the table.**

**2. (Sub lesson 1) An empty cell in a collection table means the table is broken.**
**Answer: False — It means that object’s value for that descriptor is missing; the table shows that honestly.**
