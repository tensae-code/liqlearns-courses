# Structured Data — Objects, Descriptors and Collections — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) In structured data, a descriptor is —**
a) One thing being described  b) A named aspect of an object, like its year  c) A whole collection  d) A computer program
**Answer: b) A named aspect of an object, like its year — For each object, the descriptor holds a value.**

**2. (Sub lesson 1) A library and a bookshop describe the same book differently because —**
a) One of them is wrong  b) The purpose chooses the descriptors  c) Books change  d) Descriptors are secret
**Answer: b) The purpose chooses the descriptors — The library wants author and year; the shop wants price and stock.**

**3. (Sub lesson 2) In the table of a collection, each row is —**
a) One descriptor  b) One value  c) One object  d) One file
**Answer: c) One object — And each column is one descriptor shared by all the objects.**
