# Entities, attributes and relationships — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A data model is —
a) the database software  b) the blueprint of a database, showing what data to store  c) a printed report
**Answer: b)** — the blueprint, drawn before building.

**2. (Sub lesson 1)** Which of these is an entity for a library?
a) title  b) book  c) printed
**Answer: b)** — a book is a thing data is kept about; title is one of its attributes.

**3. (Sub lesson 2)** Which list is all attributes of a customer?
a) ID, name, sex, address  b) has, borrows, owns  c) bank, library, school
**Answer: a)** — the customer's properties.

**4. (Sub lesson 2)** One named city, as a single occurrence of the entity *city*, is called —
a) an attribute  b) an instance  c) a relationship
**Answer: b)** — an instance.

**5. (Sub lesson 3)** In “a customer has an account”, the relationship is shown by —
a) customer  b) account  c) has
**Answer: c)** — the verb *has*.
