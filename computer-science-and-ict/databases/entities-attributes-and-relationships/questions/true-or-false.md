# Entities, attributes and relationships — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** When a data model is built, an entity becomes a table.
**Answer: True.**

**2. (Sub lesson 2)** Attributes tell one entity from another.
**Answer: True** — that is what they are for.

**3. (Sub lesson 3)** A relationship is a property of one entity, like its address.
**Answer: False** — a relationship is an association *between* entities; address is an attribute.
