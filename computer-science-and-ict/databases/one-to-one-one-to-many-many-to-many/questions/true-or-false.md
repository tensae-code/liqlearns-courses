# One-to-one, one-to-many, many-to-many — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** In a one-to-one relationship, one instance links to exactly one instance on the other side.
**Answer: True.**

**2. (Sub lesson 2)** “One department, many students” counted back is: one student, many departments, in this model.
**Answer: False** — in the book's model one student belongs to one department here; the many is on the students side.

**3. (Sub lesson 3)** In a many-to-many relationship, only one side has many instances.
**Answer: False** — both sides link to many.
