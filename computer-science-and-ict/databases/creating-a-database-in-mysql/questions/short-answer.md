# Creating a Database in MySQL — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is MySQL?**
**Answer: A database server — a program that holds data and answers other programs' requests**

**2. (Sub lesson 1) How is a server database different from a desktop file?**
**Answer: The website and the database are different programs talking to each other**

**3. (Sub lesson 1) What is created first in MySQL?**
**Answer: The database itself — a named container — before any table exists**

**4. (Sub lesson 1) What does each table column need?**
**Answer: A name, a type, and a length that fits real entries**

**5. (Sub lesson 1) Which column does the dictionary table make its primary key?**
**Answer: The identifier column that no two terms may share**

**6. (Sub lesson 2) What is the primary key for?**
**Answer: So every entry can be found, edited and deleted exactly**

**7. (Sub lesson 2) From what is the table designed, in Egypt's project?**
**Answer: From the Add_Term page's needs, backwards**

**8. (Sub lesson 2) What happens if a text field is made too short?**
**Answer: Real entries will not fit — the project pays for the choice later**

**9. (Sub lesson 2) What project does this database serve?**
**Answer: The Illustrated Dictionary of Computer Terms website**

**10. (Sub lesson 2) Who asks and who answers, in the PHP–MySQL pair?**
**Answer: The PHP pages ask; MySQL answers**
