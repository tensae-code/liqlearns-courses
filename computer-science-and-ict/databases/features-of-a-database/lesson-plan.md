## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Organised and structured — data with a shape** — A database holds data in a **structure**: records of the same kind together, each record built from the same **fields**, so the computer can work on it — search it, sort it, pick from it. That structure is the first feature: the data is **organised**, not stored as loose notes. Fiji's second mark follows from it: because the shape is fixed, the same data can be **searched and retrieved** quickly and exactly — a name found in seconds among thousands.
2. **Shared, single and safe to use together** — The other features are about people. A database is **shared**: many users reach the **same** data instead of keeping private copies that drift apart. It is **central** — held in one place, under one set of rules for who may see and change what — so there is one true version. And it is built for **many jobs at once**: the librarian lends from it while the principal reports from it. Organised, searchable, shared, single, many-job — those features together are what the word database promises.
