# Features of a Database — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is the first feature of a database?" is: Its data is organised in a structure — records built from the same fields**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does the structure let the computer do?" is: Because every record has the same fixed shape of fields**
**Answer: False** — Search the data, sort it and pick from it

**3. (Sub lesson 1) True or false: the answer to "Why can a database be searched quickly?" is: Because every record has the same fixed shape of fields**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is a record built from?" is: Data can be retrieved exactly — a name found in seconds among thousands**
**Answer: False** — Fields — the same fields for every record of its kind

**5. (Sub lesson 1) True or false: the answer to "What follows from the fixed shape?" is: Data can be retrieved exactly — a name found in seconds among thousands**
**Answer: True**

**6. (Sub lesson 1) True or false: the answer to "What does shared mean for a database?" is: Private copies drift apart; the central copy is the one true version**
**Answer: False** — Many users reach the same data instead of keeping private copies

**7. (Sub lesson 2) True or false: the answer to "Why is one central copy better than many private copies?" is: Private copies drift apart; the central copy is the one true version**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Who sets the rules for a database?" is: Yes — it is built for many jobs at once**
**Answer: False** — One set of rules for who may see and change what

**9. (Sub lesson 2) True or false: the answer to "Can two jobs use one database at the same time?" is: Yes — it is built for many jobs at once**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Name the features together." is: Its data is organised in a structure — records built from the same fields**
**Answer: False** — Organised, searchable, shared, single (central), and built for many jobs
