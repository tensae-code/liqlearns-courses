# Features of a Database — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is the first feature of a database?**
**Answer: Its data is organised in a structure — records built from the same fields**

**2. (Sub lesson 1) What does the structure let the computer do?**
**Answer: Search the data, sort it and pick from it**

**3. (Sub lesson 1) Why can a database be searched quickly?**
**Answer: Because every record has the same fixed shape of fields**

**4. (Sub lesson 1) What is a record built from?**
**Answer: Fields — the same fields for every record of its kind**

**5. (Sub lesson 1) What follows from the fixed shape?**
**Answer: Data can be retrieved exactly — a name found in seconds among thousands**

**6. (Sub lesson 1) What does shared mean for a database?**
**Answer: Many users reach the same data instead of keeping private copies**

**7. (Sub lesson 2) Why is one central copy better than many private copies?**
**Answer: Private copies drift apart; the central copy is the one true version**

**8. (Sub lesson 2) Who sets the rules for a database?**
**Answer: One set of rules for who may see and change what**

**9. (Sub lesson 2) Can two jobs use one database at the same time?**
**Answer: Yes — it is built for many jobs at once**

**10. (Sub lesson 2) Name the features together.**
**Answer: Organised, searchable, shared, single (central), and built for many jobs**
