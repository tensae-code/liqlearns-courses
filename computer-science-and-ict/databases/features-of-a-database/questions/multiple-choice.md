# Features of a Database — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is the first feature of a database?**
a) Its data is organised in a structure — records built from the same fields  b) Search the data, sort it and pick from it  c) Because every record has the same fixed shape of fields  d) Fields — the same fields for every record of its kind
**Answer: a) Its data is organised in a structure — records built from the same fields**

**2. (Sub lesson 1) What does the structure let the computer do?**
a) Because every record has the same fixed shape of fields  b) Search the data, sort it and pick from it  c) Fields — the same fields for every record of its kind  d) Data can be retrieved exactly — a name found in seconds among thousands
**Answer: b) Search the data, sort it and pick from it**

**3. (Sub lesson 1) Why can a database be searched quickly?**
a) Fields — the same fields for every record of its kind  b) Data can be retrieved exactly — a name found in seconds among thousands  c) Because every record has the same fixed shape of fields  d) Many users reach the same data instead of keeping private copies
**Answer: c) Because every record has the same fixed shape of fields**

**4. (Sub lesson 1) What is a record built from?**
a) Data can be retrieved exactly — a name found in seconds among thousands  b) Many users reach the same data instead of keeping private copies  c) Private copies drift apart; the central copy is the one true version  d) Fields — the same fields for every record of its kind
**Answer: d) Fields — the same fields for every record of its kind**

**5. (Sub lesson 1) What follows from the fixed shape?**
a) Data can be retrieved exactly — a name found in seconds among thousands  b) Many users reach the same data instead of keeping private copies  c) Private copies drift apart; the central copy is the one true version  d) One set of rules for who may see and change what
**Answer: a) Data can be retrieved exactly — a name found in seconds among thousands**

**6. (Sub lesson 1) What does shared mean for a database?**
a) Private copies drift apart; the central copy is the one true version  b) Many users reach the same data instead of keeping private copies  c) One set of rules for who may see and change what  d) Yes — it is built for many jobs at once
**Answer: b) Many users reach the same data instead of keeping private copies**

**7. (Sub lesson 2) Why is one central copy better than many private copies?**
a) One set of rules for who may see and change what  b) Yes — it is built for many jobs at once  c) Private copies drift apart; the central copy is the one true version  d) Organised, searchable, shared, single (central), and built for many jobs
**Answer: c) Private copies drift apart; the central copy is the one true version**

**8. (Sub lesson 2) Who sets the rules for a database?**
a) Yes — it is built for many jobs at once  b) Organised, searchable, shared, single (central), and built for many jobs  c) Its data is organised in a structure — records built from the same fields  d) One set of rules for who may see and change what
**Answer: d) One set of rules for who may see and change what**

**9. (Sub lesson 2) Can two jobs use one database at the same time?**
a) Yes — it is built for many jobs at once  b) Organised, searchable, shared, single (central), and built for many jobs  c) Its data is organised in a structure — records built from the same fields  d) Search the data, sort it and pick from it
**Answer: a) Yes — it is built for many jobs at once**

**10. (Sub lesson 2) Name the features together.**
a) Its data is organised in a structure — records built from the same fields  b) Organised, searchable, shared, single (central), and built for many jobs  c) Search the data, sort it and pick from it  d) Because every record has the same fixed shape of fields
