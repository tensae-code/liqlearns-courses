# INSERT examples — full rows and partial rows — true or false

Say true or false.

**1. (Sub lesson 1)** 30 in the COURSE insert is a string value.
**Answer: False** — contact hours is an integer, written bare.

**2. (Sub lesson 2)** Form 2 with all columns named can list them in a different order from the table's, if values follow the list.
**Answer: True** — the named list governs the matching.

**3. (Sub lesson 3)** A blank description cell means the insert failed.
**Answer: False** — the record was created; the omitted field is simply blank.

**4. (Sub lesson 3)** A partial insert may omit the primary key's value and still be safe.
**Answer: False** — the key identifies the record; leaving it out is a real problem, unlike an ordinary descriptive field.
