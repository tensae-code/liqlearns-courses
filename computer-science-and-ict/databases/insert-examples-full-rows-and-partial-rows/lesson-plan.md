# Lesson plan — INSERT examples — full rows and partial rows

**Course:** Computer Science and ICT · **Title:** Databases · **Lesson:** INSERT examples — full rows and partial rows
**Place in the curriculum:** Unit 3 — Database Management System (Ethiopia Grade 12 Information Technology), in the Databases title of the Computer Science and ICT course. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** worked inserts show the two forms in action — and a field left out of a form-2 column list is simply left blank (or given a default) in the new record.
**This lesson's own level:** it stands on INSERT — adding a record to a table: the forms are known; this lesson works them and meets the omitted field.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The full COURSE record — form 1 worked** — the full COURSE form-1 insert read value by value, with the '105' quoting explained
2. **The DEPARTMENT record — form 2 worked** — the DEPARTMENT form-2 insert with all columns named
3. **The omitted field — what blank means** — C_Description omitted: the field is left blank (or a default); all unmentioned fields behave the same

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: INSERT — adding a record to a table. Recommended, never forced.

## What the learner can do when it ends
1. Work a full form-1 insert and justify its quoting.
2. Work a form-2 insert with named columns.
3. Predict the blank/default result of omitting a field.
4. Choose form 2 deliberately when a field has no value yet.

## If the learner is stuck
- Thinks an omitted field breaks the insert → it does not; the field is left blank or defaulted. Only a missing *key* value is a real problem.
- Copies '105' unquoted from habit → the field is a string type; the quotes belong to the field's type.
