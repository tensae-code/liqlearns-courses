# Hands-on — A Data Analysis Project — Indonesian Deforestation

The lesson with your hands and your feet, not only your eyes.

## Task one
**Prepare the study** — Write the preparation page for this project as the book runs it: the exact question, the data you would need, where it could come from, and how you would judge it fit.

## Task two
**Two views, one dataset** — Sketch two charts of the same invented deforestation figures — one that accuses, one that excuses — by changing scale or years. Then write the honest third version and say what makes it honest.
