# ORDER BY — ascending and descending results — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** ORDER BY with no direction word sorts —
a) descending  b) ascending — it is the default  c) by key only  d) not at all
**Answer: b) ascending — it is the default** — ASC is the default and may be omitted.

**2. (Sub lesson 1)** The first worked sort takes teachers by salary —
a) descending  b) ascending, lowest first  c) alphabetically by name  d) by department
**Answer: b) ascending, lowest first** — ascending is worked first.

**3. (Sub lesson 2)** To flip the salary list to highest first, add —
a) ASC  b) DESC  c) WHERE  d) TOP
**Answer: b) DESC** — DESC after the field name.

**4. (Sub lesson 2)** ORDER BY can sort —
a) numbers only  b) text only  c) alphabetically or numerically  d) keys only
**Answer: c) alphabetically or numerically** — both kinds of field.

**5. (Sub lesson 3)** Running a DESC query does what to the stored table?
a) reverses it  b) nothing — sorting is output only  c) deletes it  d) locks it
**Answer: b) nothing — sorting is output only** — order lives in the query output.

**6. (Sub lesson 3)** A table whose rows sit in no useful order is —
a) broken  b) normal — order is asked for per query  c) missing its key  d) a non-relational table
**Answer: b) normal — order is asked for per query** — record order inside a table does not matter.
