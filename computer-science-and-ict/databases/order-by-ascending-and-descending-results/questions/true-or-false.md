# ORDER BY — ascending and descending results — true or false

Say true or false.

**1. (Sub lesson 1)** ASC must always be written out, or the sort fails.
**Answer: False** — ASC may be written or left empty — ascending is default.

**2. (Sub lesson 2)** DESC sorts from the largest or last value down.
**Answer: True** — descending is the flipped direction.

**3. (Sub lesson 2)** ORDER BY can sort by a text field alphabetically.
**Answer: True** — alphabetically or numerically.

**4. (Sub lesson 3)** After a descending query, the table's stored rows are stored in descending order.
**Answer: False** — the table never moved; only the output was arranged.
