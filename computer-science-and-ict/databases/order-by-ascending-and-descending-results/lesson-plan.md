# Lesson plan — ORDER BY — ascending and descending results

**Course:** Computer Science and ICT · **Title:** Databases · **Lesson:** ORDER BY — ascending and descending results
**Place in the curriculum:** Unit 3 — Database Management System (Ethiopia Grade 12 Information Technology), in the Databases title of the Computer Science and ICT course. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** ORDER BY sorts a query's output by a named field — ascending by default (ASC), descending with DESC — and sorting changes only the output, never the table itself.
**This lesson's own level:** it stands on SELECT and WHERE: rows are chosen; this lesson arranges the chosen rows.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Ascending — the default** — ORDER BY sorts output by a field, ascending by default (ASC written or omitted); teachers by salary ascending
2. **Descending — DESC** — DESC flips the sort — teachers by salary descending; (teacher guide — evidence) both directions over names, sex, temperature, visit date
3. **Order lives in the output only** — order is a property of the query output only; the table's own order does not matter

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Filtering by date, AND, OR and BETWEEN. Recommended, never forced.

## What the learner can do when it ends
1. Sort results ascending (default) and descending (DESC).
2. Sort alphabetically and numerically by a named field.
3. State that sorting affects output only, not the stored table.
4. Pick the direction that fits the question asked.

## What you need
A computer with Microsoft Access (2013 or later), or paper.

## If the learner is stuck
- Writes DESC in the SELECT list → direction words belong to ORDER BY, after the field name.
- Fears sorting 'damages' the table → the table is untouched; only the output list is arranged.
