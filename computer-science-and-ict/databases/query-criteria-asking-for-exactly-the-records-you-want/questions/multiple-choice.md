# Query criteria — asking for exactly the records you want — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A condition is typed in the —
a) Field row  b) Criteria row, under the right field  c) File Name box
**Answer: b)** — the Criteria row, under the field it tests.

**2. (Sub lesson 1)** Entering M under Sex shows —
a) all students  b) only male students  c) only female students
**Answer: b)** — only the records whose Sex matches M.

**3. (Sub lesson 2)** Sex is stored as a single character. You type the full word “Male” as the criterion. The result is —
a) all male students  b) nothing  c) the whole table
**Answer: b)** — nothing: the criterion must match the stored data exactly.

**4. (Sub lesson 2)** The practice query named in the book is —
a) Female_Students  b) All_Students  c) Teachers_Only
**Answer: a)** — the Female_Students query.
