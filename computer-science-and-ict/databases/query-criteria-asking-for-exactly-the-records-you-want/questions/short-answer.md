# Query criteria — asking for exactly the records you want — short answer

Answer in a sentence or two.

**1. (Sub lesson 1)** Write the book's order for adding criteria to a query.
**Answer:** Open Query Design, add the table, select the display fields, then type the condition in the Criteria row under the right field.

**2. (Sub lesson 2)** Your query returns nothing, though the table has matching-looking records. Give the book's explanation and the fix.
**Answer:** The criterion does not match the stored data exactly — for example the full word typed where a single character is stored. Fix: type the criterion in the exact stored form.

**3. (Sub lesson 2)** Build Female_Students: where does its criterion go, and in what form?
**Answer:** In the Criteria row under Sex, in the exact form the table stores for female — the single character, if that is how it is stored.
