# Hands-on — Query criteria — asking for exactly the records you want

The lesson with your hands, not only your eyes.

## Predict, then run
On paper, write a Student list of eight records. Predict which survive the criterion M under Sex, then build the query in Access and check. Repeat with a grade criterion of your own choosing.

## The empty-answer hunt
Deliberately type the full word where your table stores a single character, run the query, and explain the empty result using the exact-match warning. Then fix the criterion and run it again.
