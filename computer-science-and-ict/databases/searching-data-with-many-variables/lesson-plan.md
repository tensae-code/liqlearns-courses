## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **One variable is rarely the question** — Real questions arrive with **many variables** (banyak variabel): the pupils *in Grade 10, in the science stream, whose marks passed* — three conditions, one answer set. **Searching with many variables** tests a record against all the conditions together: a record is found only if it satisfies every condition joined by AND, and the search widens when conditions are joined by OR. Indonesia's Grade 10 data chapter opens with it because it is the first move of all data work — before scraping, charting or deciding, the analyst must be able to cut a dataset to exactly the records the question is about.
2. **Building the combined search — narrow, check, widen** — The craft is in the building: state each condition on its own variable, combine, then **check the catch** — too many records means a condition is missing or loose; none at all usually means a condition is wrong, not that the world is empty. Widening and narrowing are deliberate acts: drop a condition to widen, add one to narrow, and keep the question beside the search so the catch can be judged against it. The search is a sentence in the data's language; this lesson teaches writing it exactly.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
