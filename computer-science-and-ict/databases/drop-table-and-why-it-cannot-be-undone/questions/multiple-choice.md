# DROP TABLE — and why it cannot be undone — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** DROP TABLE removes —
a) one record  b) the whole table — structure and records  c) only the primary key  d) only empty tables
**Answer: b) the whole table — structure and records** — the table itself goes, entirely.

**2. (Sub lesson 1)** The book's DROP example drops —
a) DEPARTMENT  b) COURSE  c) TEACHER  d) STUDENT
**Answer: b) COURSE** — DROP TABLE COURSE is the worked example.

**3. (Sub lesson 2)** A dropped table that held records —
a) waits in a recycle bin  b) can be restored with UNDO  c) cannot be got back  d) keeps its records elsewhere
**Answer: c) cannot be got back** — the book's caution is explicit.

**4. (Sub lesson 2)** Before a DROP, the first question is —
a) is Access open?  b) does it hold records — and are they needed?  c) is the name long?  d) who wrote it?
**Answer: b) does it hold records — and are they needed?** — records and their need come first.

**5. (Sub lesson 2)** DELETE differs from DROP TABLE because DELETE —
a) drops the table  b) removes records but leaves the table standing  c) creates a table  d) needs no FROM
**Answer: b) removes records but leaves the table standing** — that contrast is the next lessons' ground.

**6. (Sub lesson 1)** The guide's practice pair is —
a) create then drop a School table  b) drop then create COURSE  c) alter then drop TEACHER  d) select then drop DEPARTMENT
**Answer: a) create then drop a School table** — School is created and dropped as the drill.
