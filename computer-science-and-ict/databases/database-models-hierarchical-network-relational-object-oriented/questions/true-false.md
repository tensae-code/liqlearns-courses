# Database Models — Hierarchical, Network, Relational, Object-Oriented — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Name the four models Malaysia compares." is: Hierarchical, network, relational, object-oriented**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How does the hierarchical model organise records?" is: A pupil in two classes has no place in a single tree**
**Answer: False** — As a tree — one parent, many children

**3. (Sub lesson 1) True or false: the answer to "Where does a tree fail honestly?" is: A pupil in two classes has no place in a single tree**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How does the network model loosen the tree?" is: A structure only programmers can navigate, record by record**
**Answer: False** — A record may have several parents, joined by named links — a web

**5. (Sub lesson 1) True or false: the answer to "What is the network model's cost?" is: A structure only programmers can navigate, record by record**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How does the relational model join data?" is: Objects — data together with the actions that belong to it**
**Answer: False** — By matching values — keys — worked out when a question is asked, not by stored links

**7. (Sub lesson 2) True or false: the answer to "What does the object-oriented model store?" is: Objects — data together with the actions that belong to it**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Give an object-oriented example." is: The relational model**
**Answer: False** — A Pupil object holding its marks and able to print its own report

**9. (Sub lesson 2) True or false: the answer to "Which model does Malaysia's course stand on?" is: The relational model**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why relational, for school and business data?" is: Hierarchical, network, relational, object-oriented**
**Answer: False** — It is tabular, shared, and questioned in ways no tree foresaw
