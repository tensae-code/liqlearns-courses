# Database Models — Hierarchical, Network, Relational, Object-Oriented — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) Name the four models Malaysia compares.**
**Answer: Hierarchical, network, relational, object-oriented**

**2. (Sub lesson 1) How does the hierarchical model organise records?**
**Answer: As a tree — one parent, many children**

**3. (Sub lesson 1) Where does a tree fail honestly?**
**Answer: A pupil in two classes has no place in a single tree**

**4. (Sub lesson 1) How does the network model loosen the tree?**
**Answer: A record may have several parents, joined by named links — a web**

**5. (Sub lesson 1) What is the network model's cost?**
**Answer: A structure only programmers can navigate, record by record**

**6. (Sub lesson 2) How does the relational model join data?**
**Answer: By matching values — keys — worked out when a question is asked, not by stored links**

**7. (Sub lesson 2) What does the object-oriented model store?**
**Answer: Objects — data together with the actions that belong to it**

**8. (Sub lesson 2) Give an object-oriented example.**
**Answer: A Pupil object holding its marks and able to print its own report**

**9. (Sub lesson 2) Which model does Malaysia's course stand on?**
**Answer: The relational model**

**10. (Sub lesson 2) Why relational, for school and business data?**
**Answer: It is tabular, shared, and questioned in ways no tree foresaw**
