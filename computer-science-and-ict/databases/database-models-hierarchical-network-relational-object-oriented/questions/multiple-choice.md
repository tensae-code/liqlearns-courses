# Database Models — Hierarchical, Network, Relational, Object-Oriented — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Name the four models Malaysia compares.**
a) Hierarchical, network, relational, object-oriented  b) As a tree — one parent, many children  c) A pupil in two classes has no place in a single tree  d) A record may have several parents, joined by named links — a web
