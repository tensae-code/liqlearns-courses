# Queries across multiple tables — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A field can be picked from a table that was not added to the query.
**Answer: False** — every needed table must be added first.

**2. (Sub lesson 2)** The join line drawn by the drag tells Access which fields match between the tables.
**Answer: True.**

**3. (Sub lesson 3)** The practice includes students scoring above 85 in all subjects, selected across Student and Grade.
**Answer: True.**
