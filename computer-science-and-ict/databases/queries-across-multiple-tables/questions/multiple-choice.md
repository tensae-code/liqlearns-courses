# Queries across multiple tables — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Each needed table is added with Show Table and the —
a) Add button  b) Create button  c) Primary Key button
**Answer: a)** — Show Table, then Add, for each table.

**2. (Sub lesson 2)** The relationship is established by dragging —
a) a table onto the grid  b) the parent table's primary-key field onto the matching field of the child table  c) a result row onto a table
**Answer: b)** — primary key of the parent onto the matching field of the child.

**3. (Sub lesson 3)** In the book's example, subject and grade are taken from —
a) Student  b) Teacher  c) Grade
**Answer: c)** — the Grade table; name comes from Student, teacher name from Teacher.

**4. (Sub lesson 3)** After picking the fields, the query is —
a) deleted  b) saved with a name, and the combined results viewed  c) printed only
**Answer: b)** — saved with a name; view the combined results.
