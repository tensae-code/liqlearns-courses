# Database Security — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Why does a database need special protection?" is: It concentrates an organisation's memory in one place**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is access control?" is: So the system knows who is asking**
**Answer: False** — Controlling who may get in and what they may do — by accounts, passwords and permissions

**3. (Sub lesson 1) True or false: the answer to "Why does every user have their own account?" is: So the system knows who is asking**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What do permissions set?" is: Need — the powers the job needs, and no more**
**Answer: False** — What that user may see, add, change or delete

**5. (Sub lesson 1) True or false: the answer to "What is Fiji's rule for permissions?" is: Need — the powers the job needs, and no more**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is a backup?" is: Fire, theft or a failed disk taking the only copy**
**Answer: False** — A copy of the database kept apart from the original

**7. (Sub lesson 2) True or false: the answer to "Against what losses does a backup guard?" is: Fire, theft or a failed disk taking the only copy**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Why is accuracy part of security?" is: A record of who changed what, and when**
**Answer: False** — Wrong data entered carelessly harms like wrong data entered in malice

**9. (Sub lesson 2) True or false: the answer to "What trail must changes leave?" is: A record of who changed what, and when**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is Fiji's complete picture?" is: It concentrates an organisation's memory in one place**
**Answer: False** — Locks on the door, copies in another house, and a written trail inside
