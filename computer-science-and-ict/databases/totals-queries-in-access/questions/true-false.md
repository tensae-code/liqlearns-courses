# Totals Queries in Access — true or false

Say true or false, and fix the false ones in your own words.

**2. (Sub lesson 1) True or false: The Totals button — adding the Total row to the grid** — as the answer to: What does Group By do?
**Answer: False — It divides the records into groups — one group per value**

**3. (Sub lesson 1) True or false: Sum, Avg, Count, Min and Max**

**4. (Sub lesson 1) True or false: Sum, Avg, Count, Min and Max** — as the answer to: What shape has a totals query's result?

**5. (Sub lesson 1) True or false: They collapse to the aggregate values per group**

**9. (Sub lesson 2) True or false: Confusing before-grouping filtering with after-grouping filtering**
