# Macros and a Switchboard Menu — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a macro?" is: A saved list of actions that runs as one**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Name actions a macro can run." is: By choosing actions from a list — no code is written**
**Answer: False** — Open a form, run a query, print a report, close a window

**3. (Sub lesson 1) True or false: the answer to "How is a macro built?" is: By choosing actions from a list — no code is written**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "To what is a macro attached?" is: The database's separate pieces, into behaviour a user can trigger**
**Answer: False** — To an event — most often a button's click

**5. (Sub lesson 1) True or false: the answer to "What do macros wire together?" is: The database's separate pieces, into behaviour a user can trigger**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is a switchboard?" is: When the database opens**
**Answer: False** — A special form that works as the system's main menu

**7. (Sub lesson 2) True or false: the answer to "When does the switchboard open?" is: When the database opens**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What do its buttons offer?" is: The workshop — tables and design views**
**Answer: False** — The system's whole work, in the user's own words

**9. (Sub lesson 2) True or false: the answer to "What does the switchboard hide?" is: The workshop — tables and design views**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "When is Malaysia's project judged finished?" is: A saved list of actions that runs as one**
**Answer: False** — When a new user can do the system's jobs from the switchboard alone
