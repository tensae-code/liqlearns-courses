# Macros and a Switchboard Menu — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a macro?**
a) A saved list of actions that runs as one  b) Open a form, run a query, print a report, close a window  c) By choosing actions from a list — no code is written  d) To an event — most often a button's click
**Answer: a) A saved list of actions that runs as one**

**2. (Sub lesson 1) Name actions a macro can run.**
a) By choosing actions from a list — no code is written  b) Open a form, run a query, print a report, close a window  c) To an event — most often a button's click  d) The database's separate pieces, into behaviour a user can trigger
**Answer: b) Open a form, run a query, print a report, close a window**

**3. (Sub lesson 1) How is a macro built?**
a) To an event — most often a button's click  b) The database's separate pieces, into behaviour a user can trigger  c) By choosing actions from a list — no code is written  d) A special form that works as the system's main menu
**Answer: c) By choosing actions from a list — no code is written**

**4. (Sub lesson 1) To what is a macro attached?**
a) The database's separate pieces, into behaviour a user can trigger  b) A special form that works as the system's main menu  c) When the database opens  d) To an event — most often a button's click
**Answer: d) To an event — most often a button's click**

**5. (Sub lesson 1) What do macros wire together?**
