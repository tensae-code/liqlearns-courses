# I Know and I Can — Review: Variables — multiple choice

Pick the one right answer.

**1. A variable review is proved by —**
a) watching the value actually change  b) describing a variable nicely  c) naming the balloon
**Answer: a) watching the value actually change**

**2. In the balloon game, the variable holds —**
a) the backdrop  b) a sound  c) the score
**Answer: c) the score**

**3. The score should change —**
a) never  b) each time the balloon is popped  c) once, at the very end
**Answer: b) each time the balloon is popped**

**4. This review also draws in —**
a) the drawing blocks  b) the sound gallery only  c) typing practice
**Answer: a) the drawing blocks**
