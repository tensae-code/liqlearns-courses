# I Know and I Can — Review: Variables — true or false

Say whether each statement is true or false.

**1. Make a variable and change its value as a program runs.**
**Answer: True** — This is one of the lesson's own outcomes.

**2. A variable, once given its first value, keeps that value for the whole program.**
**Answer: False** — The lesson teaches the opposite of this.

**3. Prove the balloon-game work alone: score held, grown, and shown.**
**Answer: True** — This is one of the lesson's own outcomes.
