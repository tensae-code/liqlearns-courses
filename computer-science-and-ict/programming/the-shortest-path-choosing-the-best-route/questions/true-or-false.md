# The Shortest Path — Choosing the Best Route — true or false

Say whether each statement is true or false.

**1. There can be more than one path to the same place.**
**Answer: True** — Long street or short lane — both reach the park.

**2. The shortest path is always the one with the most steps.**
**Answer: False** — It has the least travelling.

**3. This Grade 2 lesson is the same as the older learners' Dijkstra lesson.**
**Answer: False** — Dijkstra works on weighted graphs; this lesson chooses everyday routes by length.
