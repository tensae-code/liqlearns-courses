# The Shortest Path — Choosing the Best Route — multiple choice

Pick the one right answer.

**1. The shortest path is the route with —**
a) the most turns  b) the least travelling  c) the prettiest name
**Answer: b) the least travelling** — Fewest steps, least distance, least time.

**2. To compare routes fairly, they must have —**
a) the same start and the same finish  b) different finishes  c) no finish
**Answer: a) the same start and the same finish** — Only then is the comparison fair.

**3. Route A takes 20 steps, route B takes 35 steps, same start and finish. The shortest path is —**
a) route B  b) route A  c) neither
**Answer: b) route A** — 20 steps is less travelling than 35.

**4. Choosing the shortest path is like the algorithm lessons because it is —**
a) a choosing problem: list, compare, pick the best  b) a riddle  c) a spelling task
**Answer: a) a choosing problem: list, compare, pick the best** — State start and finish, compare, choose.
