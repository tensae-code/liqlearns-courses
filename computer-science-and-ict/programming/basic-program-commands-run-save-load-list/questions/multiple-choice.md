# BASIC Program Commands — RUN, SAVE, LOAD, LIST — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does END do?**
a) Closes the program for good  b) Halts the program mid-way, leaving it where it can be examined  c) A programmer debugging a program  d) SAVE keeps the program on disk under a name; LOAD brings a saved program back
**Answer: a) Closes the program for good**

**2. (Sub lesson 1) What does STOP do?**
a) Sets a stopped program going again — continue  b) Halts the program mid-way, leaving it where it can be examined  c) Starts the program  d) NEW clears memory for a fresh program; CLS clears the screen
**Answer: b) Halts the program mid-way, leaving it where it can be examined**

**3. (Sub lesson 1) What does CONT do?**
a) A programmer debugging a program  b) SAVE keeps the program on disk under a name; LOAD brings a saved program back  c) Sets a stopped program going again — continue  d) The program's lines, to read or check
**Answer: c) Sets a stopped program going again — continue**

**4. (Sub lesson 1) Who lives on STOP and CONT?**
a) Starts the program  b) NEW clears memory for a fresh program; CLS clears the screen  c) Renumbers the program's lines evenly  d) A programmer debugging a program
