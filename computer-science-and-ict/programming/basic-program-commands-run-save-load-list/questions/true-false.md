# BASIC Program Commands — RUN, SAVE, LOAD, LIST — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does END do?" is: Closes the program for good**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does STOP do?" is: A programmer debugging a program**
**Answer: False** — Halts the program mid-way, leaving it where it can be examined

**3. (Sub lesson 1) True or false: the answer to "What does CONT do?" is: Sets a stopped program going again — continue**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Who lives on STOP and CONT?" is: SAVE keeps the program on disk under a name; LOAD brings a saved program back**
**Answer: False** — A programmer debugging a program

**5. (Sub lesson 1) True or false: the answer to "What does RUN do?" is: Starts the program**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What do SAVE and LOAD do?" is: The program's lines, to read or check**
**Answer: False** — SAVE keeps the program on disk under a name; LOAD brings a saved program back

**7. (Sub lesson 2) True or false: the answer to "What do NEW and CLS clear?" is: NEW clears memory for a fresh program; CLS clears the screen**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does LIST show?" is: SYSTEM leaves BASIC for the operating system; the QBASIC screen is where the commands and the program meet**
**Answer: False** — The program's lines, to read or check

**9. (Sub lesson 2) True or false: the answer to "What does RENUM do?" is: Renumbers the program's lines evenly**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What does SYSTEM do — and what screen closes the book's set?" is: Halts the program mid-way, leaving it where it can be examined**
**Answer: False** — SYSTEM leaves BASIC for the operating system; the QBASIC screen is where the commands and the program meet
