# BASIC Program Commands — RUN, SAVE, LOAD, LIST — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does END do?**
**Answer: Closes the program for good**

**2. (Sub lesson 1) What does STOP do?**
**Answer: Halts the program mid-way, leaving it where it can be examined**

**3. (Sub lesson 1) What does CONT do?**
**Answer: Sets a stopped program going again — continue**

**4. (Sub lesson 1) Who lives on STOP and CONT?**
**Answer: A programmer debugging a program**

**5. (Sub lesson 1) What does RUN do?**
**Answer: Starts the program**

**6. (Sub lesson 2) What do SAVE and LOAD do?**
**Answer: SAVE keeps the program on disk under a name; LOAD brings a saved program back**

**7. (Sub lesson 2) What do NEW and CLS clear?**
**Answer: NEW clears memory for a fresh program; CLS clears the screen**

**8. (Sub lesson 2) What does LIST show?**
**Answer: The program's lines, to read or check**

**9. (Sub lesson 2) What does RENUM do?**
**Answer: Renumbers the program's lines evenly**

**10. (Sub lesson 2) What does SYSTEM do — and what screen closes the book's set?**
**Answer: SYSTEM leaves BASIC for the operating system; the QBASIC screen is where the commands and the program meet**
