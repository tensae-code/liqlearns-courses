# Hands-on — BASIC Program Commands — RUN, SAVE, LOAD, LIST

The lesson with your hands and your feet, not only your eyes.

## Run the theatre
Write the command for each job: run the program, see its lines, save it, bring it back tomorrow, start a fresh one.

## STOP or END?
In two small programs, mark where a debugging STOP belongs and where the final END belongs, and say what CONT would do after the STOP.
