# Lesson plan — BASIC Program Commands — RUN, SAVE, LOAD, LIST

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** BASIC Program Commands — RUN, SAVE, LOAD, LIST
**Place in the curriculum:** ICT expansion — Sudan (2026-11-14) — in the title Programming on the ICT course ladder (TITLES.md). Built new from Sudan's Grade 11 Computer Science student book, because no existing lesson in the course covers this thing as its own lesson.
**The one thing this lesson teaches:** A running BASIC program can be halted by its own instructions: END closes the program for good, and STOP halts it mid-way, leaving it where it can be examined — and a stopped program can be set going again with CONT (continue). Around the program stand the commands the programmer gives the machine itself: RUN starts the program; SAVE keeps it on disk under a name; LOAD brings a saved program back; NEW clears memory for a fresh program; CLS clears the screen; LIST prints the program's lines to read or check; RENUM renumbers the lines evenly; and SYSTEM leaves BASIC for the machine's operating system.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Stopping and ending — STOP, END and CONT** — A running BASIC program can be halted by its own instructions: **END** closes the program for good, and **STOP** halts it mid-way, leaving it where it can be examined — and a stopped program can be set going again with **CONT** (continue). Sudan's book teaches the three together because they are the program's own brakes: END is the finish line, STOP is a pause with the engine warm, CONT is the release. A programmer debugging a program lives on STOP and CONT.
2. **The commands around the program — RUN, SAVE, LOAD, NEW, CLS, LIST, RENUM, SYSTEM** — Around the program stand the commands the programmer gives the machine itself: **RUN** starts the program; **SAVE** keeps it on disk under a name; **LOAD** brings a saved program back; **NEW** clears memory for a fresh program; **CLS** clears the screen; **LIST** prints the program's lines to read or check; **RENUM** renumbers the lines evenly; and **SYSTEM** leaves BASIC for the machine's operating system. The book closes the set with the **QBASIC screen** — the window in which these commands and the program meet. Program lines are the play; these commands run the theatre.
