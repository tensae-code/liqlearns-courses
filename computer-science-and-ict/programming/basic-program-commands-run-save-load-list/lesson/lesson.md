# BASIC Program Commands — RUN, SAVE, LOAD, LIST

## Do it first

Your program is typed. Now what? Nothing runs until you order it, nothing survives the switch-off until you save it, and you cannot check a line you cannot see. In this lesson you learn the commands that surround every BASIC program.

## Sub lesson 1 — Stopping and ending — STOP, END and CONT

A running BASIC program can be halted by its own instructions: **END** closes the program for good, and **STOP** halts it mid-way, leaving it where it can be examined — and a stopped program can be set going again with **CONT** (continue). Sudan's book teaches the three together because they are the program's own brakes: END is the finish line, STOP is a pause with the engine warm, CONT is the release. A programmer debugging a program lives on STOP and CONT.

## Sub lesson 2 — The commands around the program — RUN, SAVE, LOAD, NEW, CLS, LIST, RENUM, SYSTEM

Around the program stand the commands the programmer gives the machine itself: **RUN** starts the program; **SAVE** keeps it on disk under a name; **LOAD** brings a saved program back; **NEW** clears memory for a fresh program; **CLS** clears the screen; **LIST** prints the program's lines to read or check; **RENUM** renumbers the lines evenly; and **SYSTEM** leaves BASIC for the machine's operating system. The book closes the set with the **QBASIC screen** — the window in which these commands and the program meet. Program lines are the play; these commands run the theatre.
