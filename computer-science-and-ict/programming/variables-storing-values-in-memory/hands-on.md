# Hands-on - Variables - storing values in memory

The lesson with your hands, not only your eyes.

## Real boxes

Label three small boxes or envelopes with variable names. Put number cards inside by 'assignment' - read each assignment aloud in the right direction ('the right side goes into the left name'). 'Type the name alone' means: open that box and read the card. Then reassign one box and say what happened to its old card.

## Trace the script

On paper, trace the circle script line by line, keeping a box-drawing for pi, radius and area. After each line, write what each box holds. At print(area), read the area box aloud: 28.26.
