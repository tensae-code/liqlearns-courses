# Variables - storing values in memory - multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A variable is -
a) a kind of error  b) a computer memory location for storing data  c) a menu in IDLE  d) the >>> prompt
**Answer: b) a computer memory location for storing data** - a named place that keeps data.

**2. (Sub lesson 1)** Variables are used when -
a) the program must keep user data or intermediate results  b) the screen is off  c) a file is printed  d) a compiler runs
**Answer: a) the program must keep user data or intermediate results** - kept values need a named home.

**3. (Sub lesson 2)** In Python, a variable is created -
a) empty, then filled later  b) together with its value  c) by the compiler only  d) only in the editor
**Answer: b) together with its value** - x = 5 creates x holding 5, in one move.

**4. (Sub lesson 2)** The assignment operator = does this:
a) checks whether two values are equal  b) puts the value or expression on its right into the variable named on its left  c) adds the two sides  d) prints the left side
**Answer: b) puts the value or expression on its right into the variable named on its left** - right side in, left name receives.

**5. (Sub lesson 2)** In total = 4 + 3, the variable total ends up holding -
a) 4  b) 3  c) 7  d) nothing
**Answer: c) 7** - the right side is worked out first, then stored.

**6. (Sub lesson 3)** Typing a variable's name alone at the prompt -
a) deletes it  b) shows its current value  c) creates a new variable  d) raises an error
**Answer: b) shows its current value** - the name alone is the way to look inside.

**7. (Sub lesson 3)** After x = 5 and then x = 9, typing x shows -
a) 5  b) 9  c) 14  d) an error
**Answer: b) 9** - the new assignment replaced the old value.
