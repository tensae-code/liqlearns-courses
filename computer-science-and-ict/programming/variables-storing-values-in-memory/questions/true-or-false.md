# Variables - storing values in memory - true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** A variable can hold an intermediate result - a value the program still needs later.
**Answer: True** - that keeping is the variable's job.

**2. (Sub lesson 3)** Reassigning a variable adds the new value to the old one.
**Answer: False** - it replaces the old value entirely.
