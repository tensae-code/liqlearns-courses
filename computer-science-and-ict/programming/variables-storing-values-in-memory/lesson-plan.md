# Lesson plan - Variables - storing values in memory

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** Variables - storing values in memory
**Place in the curriculum:** Unit 6 - Fundamentals of Programming (CURRICULUM.md).
**The one thing this lesson teaches:** a variable is a memory location for storing data; the assignment operator = puts the value on its right into the variable named on its left, typing the name alone shows its value, and a new assignment replaces the old value.
**This lesson's own level:** it stands on it stands on Writing and running a Python script - the circle script's radius and area were variables; this lesson names what they were doing. It needs nothing else.

## Sub lessons
The parts of this lesson, in order - the list the learner sees from the start, locked ahead, each opening when the one before it is proved (the gate: README, "Units, Lessons and Sub Lessons (ruled 2026-11-08)"):

1. **What a variable is** - A variable is a computer memory location for storing data, used whenever user data or intermediate results must be kept.
2. **Assignment - the = operator** - In Python a variable is created together with its value: = puts the value or expression on its right into the variable named on its left.
3. **Seeing the value - and replacing it** - Typing the variable's name alone at the prompt shows its current value; a variable can later be reassigned a different value, replacing the old one. The GIF shows the box being replaced.

Gate pool: all questions of the sub lesson - no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## What the learner can do when it ends
1. Say what a variable is and when one is used.
2. Use = to create a variable with its value, reading the assignment right-to-left into the named box.
3. Show a variable's current value by typing its name alone at the prompt.
4. Reassign a variable and say what happened to the old value.

## If the learner is stuck
- Reads = as 'equals' in the maths sense -> in Python = is a doing word: it puts the right side into the left name. Read assignments as '... goes into ...'.
- Thinks reassigning adds to the old value -> assignment replaces; the old value is gone, as the GIF's box shows.
