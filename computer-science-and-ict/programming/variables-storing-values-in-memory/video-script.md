# Video script - Variables - storing values in memory

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.
A short video script for this lesson; its placement names no full-script need.

---

Programs must remember things.
A typed number. A half-finished answer.
They keep them in variables.

A variable is a place in memory. A labelled box.

x = 5
The equals sign puts the right side...
into the name on the left.
Five is now inside x.

Want to see it? Type the name alone.
x
5.

Change your mind?
x = 9
The nine REPLACES the five.
One box. One value. The newest one wins.
