# Implementing and Improving Algorithms — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is implementing?**
a) Expressing an algorithm in an executable form without changing its logic  b) The algorithm — same inputs, same outputs, every step accounted  c) A flipped condition, a dropped step, a moved loop end  d) Tracking the implementation against the algorithm, row by row
**Answer: a**

**2. (Sub lesson 1) Against what is an implementation tested?**
a) The algorithm — same inputs, same outputs, every step accounted  b) A flipped condition, a dropped step, a moved loop end  c) Tracking the implementation against the algorithm, row by row  d) The algorithm's logic
