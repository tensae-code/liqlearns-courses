# Initiating Pascal and C++ — Two Languages, One Course

## Do it first

Grade 10 opens with a declaration no other book in this course makes so openly: from here, programming is bilingual. The same algorithm will wear Pascal's words and C++'s words, lesson by lesson, to the last grade.

## Sub lesson 1 — Why two languages — teaching and technology

**Pascal** stands in the course as the **teaching language**: designed for learning, readable, strict about structure — the language in which a concept is clearest. **C++** stands as the **technology language**: the language of real systems and careers, more powerful and less forgiving. Teaching them **in parallel** — the same section giving each concept in both — lets the pupil learn the *concept* once and see that syntax is only its clothing: what changes between languages is the writing, not the thinking.

## Sub lesson 2 — First sight of both — the same program twice

The initiation lesson sets the two side by side on the smallest ground: a first program in Pascal — `program`, declarations, `begin…end.` — and the same program in C++ — `#include`, `main`, braces `{ }`, semicolons ending each instruction, `return 0`. The pupil's first skill is **reading across**: recognising the same parts (input, processing, output) under both spellings. Every chapter after this one is written in the pair's double column — this lesson is its key.
