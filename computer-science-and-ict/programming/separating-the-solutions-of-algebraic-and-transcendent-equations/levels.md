# Separating the Solutions of Algebraic and Transcendent Equations — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — The sign change — a root is in there
Sub lesson 1 questions from the type files. Pass mark: A continuous function changing sign — f(a) and f(b) of opposite signs; The hunt for brackets — one interval isolating each root; Tabulating f at steps and marking sign changes; graphing and reading crossings; An interval holding a sign change; An even number of roots in one interval shows no sign change — finer steps watch for it.

## Sub lesson 2 — One root per interval — separation's discipline
Sub lesson 2 questions from the type files. Pass mark: When each bracket holds exactly one root; By the function's behaviour inside — monotonicity, by graph or derivative sense — and by narrowing; They are local — given a two-root bracket, they converge to one and stay silent about the other; Separate first, refine second; Know how many answers exist before polishing any of them.
