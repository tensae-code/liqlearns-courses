# Repetition and Loops in My Programs — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The same instruction carried out again and again**
**Answer: True**

**2. (Sub lesson 1) True or false: The same instruction carried out again and again** — as the answer to: Give an example from the lesson.
**Answer: False — Forward six times across a corridor (also: four turns around a square)**

**3. (Sub lesson 1) True or false: Programs become long, slow to write and easy to mistype**
**Answer: True**

**4. (Sub lesson 1) True or false: Programs become long, slow to write and easy to mistype** — as the answer to: Where do repetitions appear in the world?
**Answer: False — Fence posts, stairs, song choruses — tasks that repeat**

**5. (Sub lesson 1) True or false: Count them and write the instruction once with its count**
**Answer: True**

**6. (Sub lesson 2) True or false: Count them and write the instruction once with its count** — as the answer to: What is a loop?
**Answer: False — An instruction written once, with the number of times it must repeat**

**7. (Sub lesson 2) True or false: The instruction or block that repeats inside it**
**Answer: True**

**8. (Sub lesson 2) True or false: The instruction or block that repeats inside it** — as the answer to: What does the executor do inside a loop?
**Answer: False — Runs the body, counts, and repeats until the count is reached**

**9. (Sub lesson 2) True or false: The executor moves to what follows the loop**
**Answer: True**

**10. (Sub lesson 2) True or false: The executor moves to what follows the loop** — as the answer to: Why do loops make repetition exact?
**Answer: False — The executor counts — it never loses count the way a writer mistypes**
