# Repetition and Loops in My Programs — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Repetition — the same instruction again and again
Sub lesson 1 questions from the type files. Pass mark: The same instruction carried out again and again; Forward six times across a corridor (also: four turns around a square); Programs become long, slow to write and easy to mistype; Fence posts, stairs, song choruses — tasks that repeat; Count them and write the instruction once with its count.

## Sub lesson 2 — The loop — say it once, with its count
Sub lesson 2 questions from the type files. Pass mark: An instruction written once, with the number of times it must repeat; The instruction or block that repeats inside it; Runs the body, counts, and repeats until the count is reached; The executor moves to what follows the loop; The executor counts — it never loses count the way a writer mistypes.
