# Hands-on — Arithmetic Operations and Expressions in C++

The lesson with your hands and your feet, not only your eyes.

## Work it before you run it
Write five expressions mixing the operators (include one % and one integer division). Work each out on paper step by step, then check with a calculator or a C++ run if you have one.

## Brackets change everything
Take 10 − 2 * 3. Write its value, then add one pair of brackets to change the answer, and write the new working. Do the same for 8 / 4 / 2 read left to right.
