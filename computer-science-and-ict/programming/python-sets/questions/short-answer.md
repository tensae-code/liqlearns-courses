# Python Sets — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What two properties define a set?**
**Answer: Unique values, no fixed order**

**2. (Sub lesson 1) What happens when you add a present value?**
**Answer: Nothing — the set is unchanged**

**3. (Sub lesson 1) Why has a set no index?**
**Answer: There is no order to index by**

**4. (Sub lesson 1) What is the set's native question?**
**Answer: Membership — 'is this value in?'**

**5. (Sub lesson 1) Are sets mutable?**
**Answer: Yes — values can be added and removed**

**6. (Sub lesson 2) Name the four set operations.**
**Answer: Union, intersection, difference, symmetric difference**

**7. (Sub lesson 2) What does intersection keep?**
**Answer: Values in both sets**

**8. (Sub lesson 2) What does difference keep?**
**Answer: In the first, not in the second**

**9. (Sub lesson 2) What symbols carry union and intersection?**
**Answer: | for union, & for intersection**

**10. (Sub lesson 2) Name the chooser's kit of four.**
**Answer: List — order and change; tuple — order fixed; dictionary — named; set — unique**
