# Python Sets — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What two properties define a set?**
a) Unique values, no fixed order  b) Nothing — the set is unchanged  c) There is no order to index by  d) Membership — 'is this value in?'
**Answer: a**

**2. (Sub lesson 1) What happens when you add a present value?**
a) Nothing — the set is unchanged  b) There is no order to index by  c) Membership — 'is this value in?'  d) Yes — values can be added and removed
**Answer: a**

**3. (Sub lesson 1) Why has a set no index?**
a) There is no order to index by  b) Membership — 'is this value in?'  c) Yes — values can be added and removed  d) Union, intersection, difference, symmetric difference
**Answer: a**

**4. (Sub lesson 1) What is the set's native question?**
a) Membership — 'is this value in?'  b) Yes — values can be added and removed  c) Union, intersection, difference, symmetric difference  d) Values in both sets
**Answer: a**

**5. (Sub lesson 1) Are sets mutable?**
a) Yes — values can be added and removed  b) Union, intersection, difference, symmetric difference  c) Values in both sets  d) In the first, not in the second
**Answer: a**

**6. (Sub lesson 2) Name the four set operations.**
a) Union, intersection, difference, symmetric difference  b) Values in both sets  c) In the first, not in the second  d) | for union, & for intersection
**Answer: a**

a) In the first, not in the second  b) | for union, & for intersection  c) List — order and change; tuple — order fixed; dictionary — named; set — unique  d) Unique values, no fixed order

**9. (Sub lesson 2) What symbols carry union and intersection?**
a) | for union, & for intersection  b) List — order and change; tuple — order fixed; dictionary — named; set — unique  c) Unique values, no fixed order  d) Nothing — the set is unchanged

**10. (Sub lesson 2) Name the chooser's kit of four.**
