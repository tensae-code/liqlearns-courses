# Python Sets — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What two properties define a set?** → **Unique values, no fixed order**

**2. (Sub lesson 1) What happens when you add a present value?** → **Nothing — the set is unchanged**

**3. (Sub lesson 1) Why has a set no index?** → **There is no order to index by**

**4. (Sub lesson 1) What is the set's native question?** → **Membership — 'is this value in?'**

**5. (Sub lesson 1) Are sets mutable?** → **Yes — values can be added and removed**

**6. (Sub lesson 2) Name the four set operations.** → **Union, intersection, difference, symmetric difference**

**7. (Sub lesson 2) What does intersection keep?** → **Values in both sets**

**8. (Sub lesson 2) What does difference keep?** → **In the first, not in the second**

**9. (Sub lesson 2) What symbols carry union and intersection?** → **| for union, & for intersection**

**10. (Sub lesson 2) Name the chooser's kit of four.** → **List — order and change; tuple — order fixed; dictionary — named; set — unique**
