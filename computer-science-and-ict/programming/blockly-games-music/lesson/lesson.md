# Blockly Games — Music

## Do it first

Blockly Games Music — programming music with blocks: notes, rhythm and repetition composed in Blockly Games' Music activity

## Sub lesson 1 — Music as a program — notes in order

**Blockly Games** is a set of programming games in the browser, and its **Music** activity makes the program audible: blocks name **notes**, and the program, run, plays them in order. Indonesia's Grade 8 book explores it after the Puzzle and Maze games, because music exposes program structure to the ear — a wrong block is not a wrong picture but a wrong sound, heard at once. The first composition is a sequence: note after note, the melody as a list — the sequence structure of programming wearing its most honest output.

## Sub lesson 2 — Rhythm and repetition — loops you can hear

Music's own structures are programming's: a phrase **repeated** is a loop with a tune inside it, a chorus returning is a block reused, and timing — note lengths and rests — is the program's data. Composing in blocks teaches the ear what the eye misses in code: a loop that runs one time too many is not read, it is *heard*. The activity closes the book's Blockly exploration by showing the same blocks — sequence, repetition, choice — governing a third world after puzzles and mazes: proof the structures are the subject, and the worlds only their costumes.
