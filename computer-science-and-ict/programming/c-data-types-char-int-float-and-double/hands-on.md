# Hands-on — C Data Types — char, int, float and double

The lesson with your hands and your feet, not only your eyes.

## Task one
**Declare the world** — Write declarations for a student record in C: name initial (char), age and marks (int), average (float or double — defend the choice).

## Task two
**Specimen specifiers** — Write printf statements printing one value of each type with its right specifier — then swap two specifiers and observe what the compiler and the output say.
