# C Data Types — char, int, float and double — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does char hold?**
a) One character — stored as its code number  b) As 65, its code  c) Whole numbers  d) It is cut to 3, not rounded
**Answer: a**

**2. (Sub lesson 1) How is 'A' stored in a char?**
a) As 65, its code  b) Whole numbers  c) It is cut to 3, not rounded  d) With their type, before use
**Answer: a**

**3. (Sub lesson 1) What does int hold?**

**Answer: a**

**4. (Sub lesson 1) What happens to 3.9 stored in an int?**
