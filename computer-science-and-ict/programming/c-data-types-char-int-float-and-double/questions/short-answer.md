# C Data Types — char, int, float and double — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does char hold?**
**Answer: One character — stored as its code number**

**2. (Sub lesson 1) How is 'A' stored in a char?**
**Answer: As 65, its code**

**3. (Sub lesson 1) What does int hold?**
**Answer: Whole numbers**

**4. (Sub lesson 1) What happens to 3.9 stored in an int?**
**Answer: It is cut to 3, not rounded**

**5. (Sub lesson 1) When are C variables declared?**
**Answer: With their type, before use**

**6. (Sub lesson 2) What precision has float?**
**Answer: Single — about seven trustworthy digits**

**7. (Sub lesson 2) What precision has double?**
**Answer: Double — about fifteen digits, in eight bytes**

**8. (Sub lesson 2) Which specifier prints an int?**
**Answer: %d**

**9. (Sub lesson 2) Which specifier belongs to char?**
**Answer: %c**

**10. (Sub lesson 2) What does a lying specifier print?**
**Answer: Garbage from honest data**
