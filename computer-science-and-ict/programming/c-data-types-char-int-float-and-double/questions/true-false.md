# C Data Types — char, int, float and double — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: One character — stored as its code number**
**Answer: True**

**2. (Sub lesson 1) True or false: One character — stored as its code number** — as the answer to: How is 'A' stored in a char?
**Answer: False — As 65, its code**

**3. (Sub lesson 1) True or false: Whole numbers**
**Answer: True**

**4. (Sub lesson 1) True or false: Whole numbers** — as the answer to: What happens to 3.9 stored in an int?
**Answer: False — It is cut to 3, not rounded**

**5. (Sub lesson 1) True or false: With their type, before use**
**Answer: True**

**6. (Sub lesson 2) True or false: With their type, before use** — as the answer to: What precision has float?
**Answer: False — Single — about seven trustworthy digits**

**7. (Sub lesson 2) True or false: Double — about fifteen digits, in eight bytes**
**Answer: True**

**8. (Sub lesson 2) True or false: Double — about fifteen digits, in eight bytes** — as the answer to: Which specifier prints an int?
**Answer: False — %d**

**9. (Sub lesson 2) True or false: %c**
**Answer: True**

**10. (Sub lesson 2) True or false: %c** — as the answer to: What does a lying specifier print?
**Answer: False — Garbage from honest data**
