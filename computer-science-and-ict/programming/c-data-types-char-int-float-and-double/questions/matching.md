# C Data Types — char, int, float and double — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What does char hold?** → **One character — stored as its code number**

**2. (Sub lesson 1) How is 'A' stored in a char?** → **As 65, its code**

**3. (Sub lesson 1) What does int hold?** → **Whole numbers**

**4. (Sub lesson 1) What happens to 3.9 stored in an int?** → **It is cut to 3, not rounded**

**5. (Sub lesson 1) When are C variables declared?** → **With their type, before use**

**6. (Sub lesson 2) What precision has float?** → **Single — about seven trustworthy digits**

**7. (Sub lesson 2) What precision has double?** → **Double — about fifteen digits, in eight bytes**

**8. (Sub lesson 2) Which specifier prints an int?** → **%d**

**9. (Sub lesson 2) Which specifier belongs to char?** → **%c**

**10. (Sub lesson 2) What does a lying specifier print?** → **Garbage from honest data**
