# Flowgorithm and Scratch — programming without typing code — multiple choice

Pick the one right answer.

**1.** What is flowchart-based environments?
a) environments that build the algorithm as a flowchart, show execution step by step, and can auto-create program code from the chart  b) a free flowchart-based environment — with Raptor and SFC as the other named examples  c) environments where pre-developed graphic objects are dragged and dropped to build a program  d) a block-based environment — with Blockly as the other named example
**Answer: a) environments that build the algorithm as a flowchart, show execution step by step, and can auto-create program code from the chart**

**2.** What is Flowgorithm?
a) environments that build the algorithm as a flowchart, show execution step by step, and can auto-create program code from the chart  b) environments where pre-developed graphic objects are dragged and dropped to build a program  c) a block-based environment — with Blockly as the other named example  d) a free flowchart-based environment — with Raptor and SFC as the other named examples
**Answer: d) a free flowchart-based environment — with Raptor and SFC as the other named examples**

**3.** What is block-based environments?
a) a free flowchart-based environment — with Raptor and SFC as the other named examples  b) a block-based environment — with Blockly as the other named example  c) environments where pre-developed graphic objects are dragged and dropped to build a program  d) environments that build the algorithm as a flowchart, show execution step by step, and can auto-create program code from the chart
**Answer: c) environments where pre-developed graphic objects are dragged and dropped to build a program**

**4.** What is Scratch?
a) environments where pre-developed graphic objects are dragged and dropped to build a program  b) a block-based environment — with Blockly as the other named example  c) environments that build the algorithm as a flowchart, show execution step by step, and can auto-create program code from the chart  d) a free flowchart-based environment — with Raptor and SFC as the other named examples

**5.** Auto-creating program code from a chart is a power of —
a) block environments only  b) flowchart-based environments  c) the terminator  d) pseudocode paper
**Answer: b) flowchart-based environments**

**6.** The book adopts which pair?
a) Raptor and Blockly  b) Flowgorithm and Scratch  c) SFC and Scratch only  d) typed code and paper
