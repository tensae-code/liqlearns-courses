# Flowgorithm and Scratch — programming without typing code — fill

Fill each blank with the right word or words.

**1.** _____ is a free flowchart-based environment — with Raptor and SFC as the other named examples. (Name the term.)
**Answer: Flowgorithm**

**2.** _____ is environments where pre-developed graphic objects are dragged and dropped to build a program. (Name the term.)
**Answer: block-based environments**

**3.** _____ is a block-based environment — with Blockly as the other named example. (Name the term.)
**Answer: Scratch**
