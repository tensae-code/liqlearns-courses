# Flowgorithm and Scratch — programming without typing code

## Do it first

Two screens. On one, a flowchart that runs, step by step, before your eyes. On the other, colourful blocks that snap together like bricks. Neither asks you to type a programming language. Which would you start with — and what does each one show you that typed code hides?

## Flowchart-based environments

Flowchart-based environments build the algorithm as a flowchart, show execution visually step by step, and can auto-create program code from the chart. The free examples are Flowgorithm, Raptor and SFC — a Structured Flow Chart Editor.

[Picture 20934 — Two environments — a flowchart screen, a block screen]

## Block-based environments

Block-based environments use pre-developed graphic objects, dragged and dropped to build a program — Scratch and Blockly are the names. The book adopts Flowgorithm for flowcharts and Scratch for blocks: the two environments the rest of this unit works in.

## Say it to your companion

Tell your companion, in your own words: two environments make programming accessible without typed code: flowchart-based ones such as Flowgorithm, and block-based ones such as Scratch. Then name the key words of this lesson — flowchart-based environments, Flowgorithm, block-based environments, Scratch — and say what each one means.
