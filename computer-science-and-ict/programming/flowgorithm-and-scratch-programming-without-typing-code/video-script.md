This is **Flowgorithm and Scratch — programming without typing code**.

**flowchart-based environments** — environments that build the algorithm as a flowchart, show execution step by step, and can auto-create program code from the chart.

**Flowgorithm** — a free flowchart-based environment — with Raptor and SFC as the other named examples.

**block-based environments** — environments where pre-developed graphic objects are dragged and dropped to build a program.

**Scratch** — a block-based environment — with Blockly as the other named example.
