# Robot Colour Sensor and Line Following — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Shines light at the surface and reads what returns**
**Answer: True**

**2. (Sub lesson 1) True or false: How much light bounces back, as a number** — as the answer to: What does colour mode report?

**3. (Sub lesson 1) True or false: How much light bounces back, as a number**
