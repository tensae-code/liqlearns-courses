# Robot Colour Sensor and Line Following — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What does the colour sensor do?** → **Shines light at the surface and reads what returns**

**2. (Sub lesson 1) What does colour mode report?** → **The name of the colour it sees**
