# String Functions in Scratch — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a string?" is: A piece of text — letters, spaces and marks held as one value**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does the join operator do?" is: A joined string — such as a greeting joined with a typed name**
**Answer: False** — It glues two strings into one string

**3. (Sub lesson 1) True or false: the answer to "What is join 'Thim' and 'phu'?" is: Thimphu**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does nesting joins build?" is: B**
