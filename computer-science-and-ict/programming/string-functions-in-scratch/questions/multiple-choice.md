# String Functions in Scratch — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a string?**
a) A piece of text — letters, spaces and marks held as one value  b) It glues two strings into one string  c) Thimphu  d) A whole sentence, built piece by piece from joined results
**Answer: a) A piece of text — letters, spaces and marks held as one value**

**2. (Sub lesson 1) What does the join operator do?**
a) Thimphu  b) It glues two strings into one string  c) A whole sentence, built piece by piece from joined results  d) A joined string — such as a greeting joined with a typed name
**Answer: b) It glues two strings into one string**

**3. (Sub lesson 1) What is join 'Thim' and 'phu'?**
a) A whole sentence, built piece by piece from joined results  b) A joined string — such as a greeting joined with a typed name  c) Thimphu  d) Its nth character
**Answer: c) Thimphu**

**4. (Sub lesson 1) What does nesting joins build?**
a) A joined string — such as a greeting joined with a typed name  b) Its nth character  c) B  d) A whole sentence, built piece by piece from joined results
**Answer: d) A whole sentence, built piece by piece from joined results**

**5. (Sub lesson 1) What is often spoken by a say block?**
a) A joined string — such as a greeting joined with a typed name  b) Its nth character  c) B  d) How many characters the string holds, spaces counted
**Answer: a) A joined string — such as a greeting joined with a typed name**

**6. (Sub lesson 2) What does Letter (n) of a string report?**
a) B  b) Its nth character  c) How many characters the string holds, spaces counted  d) Counting the letters in a typed name, or checking an answer letter by letter (any one named)
**Answer: b) Its nth character**

**7. (Sub lesson 2) What is letter 1 of 'Bhutan'?**
a) How many characters the string holds, spaces counted  b) Counting the letters in a typed name, or checking an answer letter by letter (any one named)  c) B  d) The operator blocks
**Answer: c) B**

**8. (Sub lesson 2) What does Length Of report?**
a) Counting the letters in a typed name, or checking an answer letter by letter (any one named)  b) The operator blocks  c) A piece of text — letters, spaces and marks held as one value  d) How many characters the string holds, spaces counted
**Answer: d) How many characters the string holds, spaces counted**

**9. (Sub lesson 2) Name a real tool these two build with ask and variables.**
a) Counting the letters in a typed name, or checking an answer letter by letter (any one named)  b) The operator blocks  c) A piece of text — letters, spaces and marks held as one value  d) It glues two strings into one string
**Answer: a) Counting the letters in a typed name, or checking an answer letter by letter (any one named)**

**10. (Sub lesson 2) Which block family do string functions belong to?**
a) A piece of text — letters, spaces and marks held as one value  b) The operator blocks  c) It glues two strings into one string  d) Thimphu
**Answer: b) The operator blocks**
