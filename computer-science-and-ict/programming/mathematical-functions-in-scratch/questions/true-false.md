# Mathematical Functions in Scratch — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is the mathematical function block?" is: A single operator block: a number goes in, a dropdown chooses the function, and one answer is reported**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does abs return?" is: Sin, cos and tan**
**Answer: False** — The value without its sign — its absolute value

**3. (Sub lesson 1) True or false: the answer to "What do floor and ceiling do?" is: Round a number down and up to a whole number**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does sqrt return?" is: The true distance between sprites, from two squared distances**
**Answer: False** — The number's square root

**5. (Sub lesson 1) True or false: the answer to "Which trigonometric functions does the block offer?" is: Sin, cos and tan**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Where can a reporter block like this one sit?" is: Turns a decimal timer into whole seconds for the display**
**Answer: False** — Inside a say block, a set-variable block, or a bigger calculation

**7. (Sub lesson 2) True or false: the answer to "What does sqrt build in a game?" is: The true distance between sprites, from two squared distances**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does abs measure between two scores?" is: A single operator block: a number goes in, a dropdown chooses the function, and one answer is reported**
**Answer: False** — How far apart they are, whichever is bigger

**9. (Sub lesson 2) True or false: the answer to "What does floor do for a game timer?" is: Turns a decimal timer into whole seconds for the display**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "With which lesson does this one form the operators' advanced family?" is: Round a number down and up to a whole number**
**Answer: False** — String Functions in Scratch — text in one, number in the other
