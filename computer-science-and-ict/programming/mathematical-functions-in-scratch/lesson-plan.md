## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The block — one input, one function, one answer** — The **mathematical function block** is a single operator block with two choices inside it: a **number** goes in, and a **dropdown chooses the function** — **abs** (the value without its sign), **floor** and **ceiling** (rounding down and up), **sqrt** (square root), and the **trigonometric** functions — sin, cos and tan — among others. The block reports one answer, and like every reporter it can sit inside a say block, a set-variable block, or a bigger calculation.
2. **Functions at work — mathematics inside programs** — The functions earn their place inside real builds: **sqrt** turns two squared distances into the true distance between sprites; **abs** measures how far apart two scores are, whichever is bigger; **floor** turns a decimal timer into whole seconds for a game display. Class VIII teaches them with the string functions as the operators' advanced family: text worked by one lesson, number worked by the other.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
