# Sequence, selection, repetition — tf

Say whether each statement is true or false.

**1.** True or false: sequence — execution top-down in the order the instructions are placed.
**Answer: True**

**2.** True or false: selection — execution or a jump depending on a decision's outcome — the condition kind of flow.
**Answer: True**

**3.** True or false: repetition is the opposite: it has nothing to do with execution repeated — a fixed number of times, or until a condition occurs.
**Answer: False** — repetition is about execution repeated — a fixed number of times, or until a condition occurs.
