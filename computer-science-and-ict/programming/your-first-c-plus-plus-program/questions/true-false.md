# Your First C++ Program — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does #include <iostream> do?" is: Brings in the input–output tools the program needs**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Where does a C++ program's running start?" is: Sends output to the screen — prints what it is given**
**Answer: False** — In main() — the function the running starts from

**3. (Sub lesson 1) True or false: the answer to "What does cout do?" is: Sends output to the screen — prints what it is given**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What ends a C++ statement?" is: Inside its braces**
**Answer: False** — A semicolon

**5. (Sub lesson 1) True or false: the answer to "Where do main's statements live?" is: Inside its braces**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Name the three steps of the making." is: Translates the whole program into machine code**
**Answer: False** — Write, compile, run

**7. (Sub lesson 2) True or false: the answer to "What does compiling do?" is: Translates the whole program into machine code**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "When do errors appear, and where?" is: The compiled program executes and cout's line appears**
**Answer: False** — At compiling — reported at exact lines, to be fixed and compiled again

**9. (Sub lesson 2) True or false: the answer to "What happens at running?" is: The compiled program executes and cout's line appears**
**Answer: True**
