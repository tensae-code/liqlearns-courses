# Your First C++ Program — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does #include <iostream> do?**
a) Brings in the input–output tools the program needs  b) In main() — the function the running starts from  c) Sends output to the screen — prints what it is given  d) A semicolon
**Answer: a) Brings in the input–output tools the program needs**

**2. (Sub lesson 1) Where does a C++ program's running start?**
a) Sends output to the screen — prints what it is given  b) In main() — the function the running starts from  c) A semicolon  d) Inside its braces
**Answer: b) In main() — the function the running starts from**

**3. (Sub lesson 1) What does cout do?**
a) A semicolon  b) Inside its braces  c) Sends output to the screen — prints what it is given  d) Write, compile, run
**Answer: c) Sends output to the screen — prints what it is given**

**4. (Sub lesson 1) What ends a C++ statement?**
a) Inside its braces  b) Write, compile, run  c) Translates the whole program into machine code  d) A semicolon
**Answer: d) A semicolon**

**5. (Sub lesson 1) Where do main's statements live?**
a) Inside its braces  b) Write, compile, run  c) Translates the whole program into machine code  d) At compiling — reported at exact lines, to be fixed and compiled again
**Answer: a) Inside its braces**

**6. (Sub lesson 2) Name the three steps of the making.**
a) Translates the whole program into machine code  b) Write, compile, run  c) At compiling — reported at exact lines, to be fixed and compiled again  d) The compiled program executes and cout's line appears
**Answer: b) Write, compile, run**

**7. (Sub lesson 2) What does compiling do?**
a) At compiling — reported at exact lines, to be fixed and compiled again  b) The compiled program executes and cout's line appears  c) Translates the whole program into machine code  d) Pay calculation, grade from mark, and triangle and circle areas — with Fijian student names
**Answer: c) Translates the whole program into machine code**

**8. (Sub lesson 2) When do errors appear, and where?**
a) The compiled program executes and cout's line appears  b) Pay calculation, grade from mark, and triangle and circle areas — with Fijian student names  c) Brings in the input–output tools the program needs  d) At compiling — reported at exact lines, to be fixed and compiled again
**Answer: d) At compiling — reported at exact lines, to be fixed and compiled again**

**9. (Sub lesson 2) What happens at running?**
a) The compiled program executes and cout's line appears  b) Pay calculation, grade from mark, and triangle and circle areas — with Fijian student names  c) Brings in the input–output tools the program needs  d) In main() — the function the running starts from
**Answer: a) The compiled program executes and cout's line appears**
