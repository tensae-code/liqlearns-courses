## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The shape of a C++ program — include, main, cout** — A first C++ program has a shape every later program will repeat. It opens with **`#include <iostream>`** — bringing in the input–output tools. Its body is **`main()`** — the function the running starts from. Inside, **`cout`** sends output to the screen: `cout << "...";` prints what it is given, and the program's statements end with **semicolons** and live inside **braces**. Fiji's first program makes the machine speak a line of the learner's own choosing — with Fijian students' names in the worked programs that follow — because a first program must be *theirs*.
2. **Write, compile, run — the three-step making** — The making has three steps, and Fiji's chapter order is those steps. **Write**: the program is typed in the C++ IDE the chapter installs first. **Compile**: the compiler translates the whole program into machine code — and reports **errors** here, at exact lines, which the learner fixes and compiles again. **Run**: the compiled program executes, and cout's line appears. A learner who has done the three steps once owns the cycle every C++ program in the senior course — pay calculations, grade-from-mark, areas — will travel for the rest of the year.
