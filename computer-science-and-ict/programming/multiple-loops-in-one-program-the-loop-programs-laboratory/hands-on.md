# Hands-on — Multiple Loops in One Program — the Loop Programs Laboratory

The lesson with your hands and your feet, not only your eyes.

## Task one
**Three-part task** — Design a task needing three different loops, write its program part by part, and run it on paper with a counter.

## Task two
**Lab partner** — Swap programs with a partner; run theirs exactly, log every fault, and return it with the faults marked — not fixed — for the author to debug.
