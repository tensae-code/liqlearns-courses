# Data Compression — Making Files Smaller — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Files can be compressed because real data carries —**
a) errors  b) repetition — patterns that occur again and again  c) too many folders  d) electricity
**Answer: b) repetition — patterns that occur again and again** — Store the pattern once, plus its count.

**2. (Sub lesson 1) Lossless compression guarantees that decompressing gives —**
a) a smaller file  b) the original back, bit for bit  c) a clearer photo  d) a new file format
**Answer: b) the original back, bit for bit** — Nothing is lost — only rewritten shorter.

**3. (Sub lesson 1) ZIP is an example of —**
a) lossy compression for music  b) lossless compression  c) sampling  d) encoding
**Answer: b) lossless compression** — Archives must restore files exactly.

**4. (Sub lesson 2) Lossy compression works by —**
a) counting repeats more carefully  b) permanently discarding detail the senses barely miss  c) splitting files in half  d) storing files twice
**Answer: b) permanently discarding detail the senses barely miss** — Slight colour differences; sounds at the edge of hearing.

**5. (Sub lesson 2) Which file should never be lossy-compressed?**
a) A photo to share with friends  b) A song for a phone  c) The class's examination results data  d) A holiday snapshot
**Answer: c) The class's examination results data** — Data must survive exactly — every bit matters.
