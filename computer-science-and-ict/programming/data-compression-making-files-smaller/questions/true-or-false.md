# Data Compression — Making Files Smaller — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) A lossy-compressed photo can be restored to the exact original later.**
**Answer: False** — What lossy compression discards is gone permanently.

**2. (Sub lesson 2) A clear sky compresses better than a crowded market scene.**
**Answer: True** — Long runs of the same colour are repetition a compressor can count.

**3. (Sub lesson 2) Programs should be compressed losslessly.**
**Answer: True** — One changed bit can break a program.
