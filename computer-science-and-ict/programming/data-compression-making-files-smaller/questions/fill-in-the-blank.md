# Data Compression — Making Files Smaller — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 1) Compression stores a repeated pattern once, with a note of how many ____ it runs.**
**Answer: times** — Pattern + count replaces copy after copy.

**2. (Sub lesson 2) JPEG photos and MP3 music use ____ compression.**
**Answer: lossy** — Detail the senses barely miss is discarded.

**3. (Sub lesson 2) ____ compression restores the original bit for bit.**
**Answer: Lossless** — ZIP works this way.
