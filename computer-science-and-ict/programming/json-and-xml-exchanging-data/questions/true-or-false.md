# JSON and XML — Exchanging Data — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) JSON and XML are both plain text that a person can open and read.**
**Answer: True — That openness is a large part of why both formats won their place.**

**2. (Sub lesson 2) A program must know a JSON answer’s values by their position, since JSON values have no names.**
**Answer: False — JSON values carry their names with them; the parsed dictionary is read by name.**
