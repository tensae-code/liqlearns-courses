# JSON and XML — Exchanging Data — short answer

Answer in your own words, in one or two sentences.

**1. (Sub lesson 1) Why do programs exchange JSON instead of sending each other spreadsheet files?**
**Answer: JSON is plain text shaped exactly like the data structures programs use — objects and lists — so any program in any language can parse it directly, with every value named; a spreadsheet file is tied to one family of programs and mixes the data with presentation.**
