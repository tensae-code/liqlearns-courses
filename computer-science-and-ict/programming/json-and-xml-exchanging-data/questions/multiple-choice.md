# JSON and XML — Exchanging Data — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) In Python, a parsed JSON object becomes —**
a) A picture  b) A dictionary  c) A spreadsheet  d) A sound
**Answer: b) A dictionary — And a JSON array becomes a list; that exact fit is why programs exchange JSON.**

**2. (Sub lesson 1) Which module fetches the web service’s answer in the book’s example?**
a) pandas  b) ElementTree  c) urllib  d) Pillow
**Answer: c) urllib — It fetches from the address; the json module then parses the text.**

**3. (Sub lesson 2) ElementTree turns an XML file into —**
a) A tree of elements in memory  b) A CSV file  c) A single string  d) An image
**Answer: a) A tree of elements in memory — Root, children and their children, each with a tag and text, ready to walk.**

**4. (Sub lesson 2) Each XML element carries its tag and its —**
a) Price  b) Text (and possibly attributes)  c) Author’s name  d) Password
**Answer: b) Text (and possibly attributes) — The text is what sits between the opening and closing tags.**
