# Video script — JSON and XML — Exchanging Data

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Programs talk to each other in structured text.

Ask a web service a question, and it answers in JSON: names and values. Python fetches it, the json module unfolds it — objects become dictionaries, lists become lists — and your program reads the values by name. Even the names of the astronauts in space, live.

XML is the older way: everything wrapped in tags, a tree of elements. ElementTree parses the tree, and your program walks it — every film, every title, every year.

Two formats, one idea: data that any program can read.
