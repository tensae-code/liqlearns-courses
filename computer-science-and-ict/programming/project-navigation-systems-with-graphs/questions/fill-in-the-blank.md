# Project — Navigation Systems with Graphs — fill in the blank

Fill each blank with the missing word or words.

**1. The weight of an edge in a 'fastest route' system is measured in ____.**
**Answer: time (minutes)**

**2. A one-way street becomes a ____ edge in the graph.**
**Answer: directed**

**3. Finding the graph node nearest to a typed address is called ____.**
**Answer: geocoding**
