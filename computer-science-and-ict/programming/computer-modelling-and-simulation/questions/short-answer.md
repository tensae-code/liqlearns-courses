# Computer Modelling and Simulation — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a computer model?**
**Answer: An information model written for a computer — features as data, connections as rules or formulas**

**2. (Sub lesson 1) What is the computer's advantage in modelling?**
**Answer: Speed and patience — it can recalculate the model thousands of times with different values**

**3. (Sub lesson 1) What is a simulation?**
**Answer: Running a computer model to watch what happens**

**4. (Sub lesson 1) What questions do simulations answer?**
**Answer: 'What if' questions — what happens when a starting value changes**

**5. (Sub lesson 1) Name a use where the real experiment cannot be run.**
**Answer: Training pilots, testing a bridge design, or forecasting weather**

**6. (Sub lesson 2) What is the building order for a computer model?**
**Answer: Name the purpose, choose features to keep, write them as data and rules, check against known results**

**7. (Sub lesson 2) Why check a model against known results?**
**Answer: To see whether it is faithful before trusting its new answers**

**8. (Sub lesson 2) Why is a simulation only as good as its model?**
**Answer: Features left out cannot affect the answer**

**9. (Sub lesson 2) What is a simulation result a statement about, first of all?**
**Answer: The model — and the world only as far as the model is faithful**

**10. (Sub lesson 2) Can a computer model be re-run with different starting values?**
**Answer: Yes — that is its main strength**
