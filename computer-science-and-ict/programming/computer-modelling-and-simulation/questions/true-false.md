# Computer Modelling and Simulation — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a computer model?" is: An information model written for a computer — features as data, connections as rules or formulas.**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is the computer's advantage in modelling?" is: Name the purpose, choose features to keep, write them as data and rules, check against known results.**
**Answer: False** — Speed and patience — it can recalculate the model thousands of times with different values.

**3. (Sub lesson 1) True or false: the answer to "What is a simulation?" is: Running a computer model to watch what happens.**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What questions do simulations answer?" is: Features left out cannot affect the answer.**
**Answer: False** — 'What if' questions — what happens when a starting value changes.

**5. (Sub lesson 1) True or false: the answer to "Name a use where the real experiment cannot be run." is: Training pilots, testing a bridge design, or forecasting weather.**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is the building order for a computer model?" is: Yes — that is its main strength.**
**Answer: False** — Name the purpose, choose features to keep, write them as data and rules, check against known results.

**7. (Sub lesson 2) True or false: the answer to "Why check a model against known results?" is: To see whether it is faithful before trusting its new answers.**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Why is a simulation only as good as its model?" is: Speed and patience — it can recalculate the model thousands of times with different values.**
**Answer: False** — Features left out cannot affect the answer.

**9. (Sub lesson 2) True or false: the answer to "What is a simulation result a statement about, first of all?" is: The model — and the world only as far as the model is faithful.**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Can a computer model be re-run with different starting values?" is: 'What if' questions — what happens when a starting value changes.**
**Answer: False** — Yes — that is its main strength.
