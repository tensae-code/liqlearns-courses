# Video script — Computer Modelling and Simulation

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A **computer model** is an information model written for a computer: the kept features become data and the connections between them become rules or formulas the computer can work with.
The computer's part is speed and patience — it can recalculate the model thousands of times with different starting values, where a person with paper would finish one run.
Running a computer model to watch what happens is a **simulation**.
Simulations answer 'what if' questions: what if the speed doubles, the price rises, the rain doubles?
