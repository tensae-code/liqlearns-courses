# Lesson plan — Computer Modelling and Simulation

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **From model to computer model** — A **computer model** is an information model written for a computer: the kept features become data and the connections between them become rules or formulas the computer can work with. The computer's part is speed and patience — it can recalculate the model thousands of times with different starting values, where a person with paper would finish one run. Building one follows the modelling order: name the purpose, choose the features to keep, write them as data and rules, and check the model against known results of the real thing before trusting it.
2. **Simulation — running the model** — Running a computer model to watch what happens is a **simulation**. Simulations answer 'what if' questions: what if the speed doubles, the price rises, the rain doubles? They are used where the real experiment cannot be run — training pilots without risking aircraft, testing a bridge design without building it, forecasting weather before it happens. A simulation is only as good as its model: features left out cannot affect the answer, so every simulation result must be read with its model's choices in mind — a result is a statement about the model first, and about the world only as far as the model is faithful.
