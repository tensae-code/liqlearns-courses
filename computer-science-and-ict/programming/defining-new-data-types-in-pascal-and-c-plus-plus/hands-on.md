# Hands-on — Defining New Data Types in Pascal and C++

The lesson with your hands and your feet, not only your eyes.

## Task one
**Define the world** — Write the type definitions for a library program: a book code, a reader's age subrange, a day enumeration, a price — in both languages.

## Task two
**Refactor** — Take a program using raw integer for marks, days and money; introduce TMark, TDay and TMoney definitions and list what each change protected or clarified.
