This lesson: **if…else — one action or the other**.

First, do it. Run the opening program. Watch what it prints.

Then the idea, in order: Exactly one of the two blocks runs, every time. n % 2 == 0 decides even; otherwise odd. The unit's running worked program.

Now you. Run even/odd with 10, 15 and 100. Predict each answer first.

Say it to your companion: Walk your companion down both roads of the even/odd program: which test is asked, and which block runs for 4 and for 7.
