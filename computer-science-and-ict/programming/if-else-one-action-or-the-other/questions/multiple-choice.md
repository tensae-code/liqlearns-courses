# if…else — one action or the other — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** In if…else, when the condition is false, the block that runs is —
a) the if block  b) the else block  c) both blocks
**Answer: b) b) the else block**

**2. (Sub lesson 1)** In one run of an if…else, how many blocks run?
a) 0  b) 1  c) 2
**Answer: b) b) 1** — Exactly one road.

**3. (Sub lesson 2)** `7 % 2` is —
a) 0  b) 1  c) 3
**Answer: b) b) 1** — 7 = 2×3 + 1.

**4. (Sub lesson 2)** With n = 7 the even/odd program prints —
a) 7 is even  b) 7 is odd  c) nothing
**Answer: b) b) 7 is odd** — Verified.

**5. (Sub lesson 2)** A number is even when its remainder on division by 2 is —
a) 1  b) 0  c) 2
**Answer: b) b) 0**

**6. (Sub lesson 1)** The else line needs —
a) a condition after it  b) a colon and its own indented block  c) brackets
**Answer: b) b) a colon and its own indented block** — else carries no condition.
