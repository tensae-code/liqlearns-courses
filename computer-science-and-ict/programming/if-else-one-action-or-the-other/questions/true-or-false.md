# if…else — one action or the other — true or false

Say True or False.

**1. (Sub lesson 1)** Both blocks of an if…else can run in one run.
**Answer: False**

**2. (Sub lesson 1)** The else block runs when the condition is false.
**Answer: True**

**3. (Sub lesson 2)** `10 % 2 == 0` is True.
**Answer: True**

**4. (Sub lesson 2)** Odd numbers have remainder 0 on division by 2.
**Answer: False**
