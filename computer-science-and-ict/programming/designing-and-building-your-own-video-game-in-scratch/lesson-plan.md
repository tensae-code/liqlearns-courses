## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Studios, and the Mystery Number** — The scenario organises the class as **studios** — small game companies with a product to ship. Everyone's apprenticeship is the **Number Mystery game (jeu du Nombre Mystère)**: the computer ‘thinks’ of a number, the player guesses, the program answers higher/lower until the find. Its first steps are the project's template: state the game's rule in one sentence, list what the program must remember (the secret, the guesses, the count), and sketch the play before any block is touched.
2. **From first game to your own game** — With the template in hand, each studio designs **its own game** under the scenario's full discipline: natural-language algorithm, Scratch program, a written brief (cahier des charges), playtesting by other studios, and revision — the Nim studios run the same pipeline in expert mode. The project's lesson is industrial, not just technical: a game is finished when **players** say it works, and the road from idea to players is paved with documents, tests and repairs.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## The run of the lesson (in order)
1. **Do it first** — Your studio has four séances and one deliverable: a game a stranger can play without you standing there explaining. Before reading on, name the first thing your studio should finish — and why it is not the title screen. (lesson/lesson.md).
2. **The explanation** — the lesson text in lesson/lesson.md, in its parts in order.
   - ADD IMAGE: a picture of studios, and the mystery number as the lesson describes it — the student studies the picture and names what each part shows.
   - ADD GIF: a GIF of from first game to your own game in action — the student watches once, then says what changed and why.
   - ADD AUDIO: a voice reading the lesson's key names and definitions aloud, in the order the lesson gives them — the student listens once through, then reads the same lines aloud along with the voice. (Audio is a described slot in this build; no audio file is made.)
3. **Say it to your companion** — the companion block in lesson/lesson.md.
   - ADD VIDEO: the script in video-script.md, filmed — the lesson in the super-simple voice (made later, when videos are made).
4. **Questions** — from questions/: multiple-choice, true-false, matching, short-answer — served at the learner's level and teaching-mix (levels.md).
5. **Hands-on** — hands-on.md.
6. **Do It Yourself** — the doing block at the end of lesson/lesson.md.
