# Primitive and Non-Primitive Data Types — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Name Java's eight primitive types.**
a) byte, short, int, long, float, double, char, boolean  b) The value itself  c) The value — the two boxes then live independently  d) In small letters
**Answer: a) byte, short, int, long, float, double, char, boolean**

**2. (Sub lesson 1) What does a primitive variable hold?**
a) The value — the two boxes then live independently  b) The value itself  c) In small letters  d) boolean
**Answer: b) The value itself**

**3. (Sub lesson 1) Copying a primitive copies what?**
a) In small letters  b) boolean  c) The value — the two boxes then live independently  d) A reference — a way to reach an object in memory
**Answer: c) The value — the two boxes then live independently**

**4. (Sub lesson 1) How are primitive type names written?**
a) boolean  b) A reference — a way to reach an object in memory  c) String, arrays, and classes generally  d) In small letters
**Answer: d) In small letters**

**5. (Sub lesson 1) Which primitive holds true/false?**
a) boolean  b) A reference — a way to reach an object in memory  c) String, arrays, and classes generally  d) The reference — both boxes reach the same object
**Answer: a) boolean**

**6. (Sub lesson 2) What does a non-primitive variable hold?**
a) String, arrays, and classes generally  b) A reference — a way to reach an object in memory  c) The reference — both boxes reach the same object  d) Non-primitive — they share the object through copied references
**Answer: b) A reference — a way to reach an object in memory**

**7. (Sub lesson 2) Name three non-primitive types.**
a) The reference — both boxes reach the same object  b) Non-primitive — they share the object through copied references  c) String, arrays, and classes generally  d) Primitive: the value in the box; non-primitive: a pointer to the value in the box
**Answer: c) String, arrays, and classes generally**

**8. (Sub lesson 2) Copying a reference variable copies what?**
a) Non-primitive — they share the object through copied references  b) Primitive: the value in the box; non-primitive: a pointer to the value in the box  c) byte, short, int, long, float, double, char, boolean  d) The reference — both boxes reach the same object
**Answer: d) The reference — both boxes reach the same object**

**9. (Sub lesson 2) Two variables 'change together'. Which family explains it?**
a) Non-primitive — they share the object through copied references  b) Primitive: the value in the box; non-primitive: a pointer to the value in the box  c) byte, short, int, long, float, double, char, boolean  d) The value itself
**Answer: a) Non-primitive — they share the object through copied references**

**10. (Sub lesson 2) State Malaysia's contrast in one line.**
a) byte, short, int, long, float, double, char, boolean  b) Primitive: the value in the box; non-primitive: a pointer to the value in the box  c) The value itself  d) The value — the two boxes then live independently
**Answer: b) Primitive: the value in the box; non-primitive: a pointer to the value in the box**
