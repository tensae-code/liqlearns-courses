# Primitive and Non-Primitive Data Types — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) Name Java's eight primitive types.**
**Answer: byte, short, int, long, float, double, char, boolean**

**2. (Sub lesson 1) What does a primitive variable hold?**
**Answer: The value itself**

**3. (Sub lesson 1) Copying a primitive copies what?**
**Answer: The value — the two boxes then live independently**

**4. (Sub lesson 1) How are primitive type names written?**
**Answer: In small letters**

**5. (Sub lesson 1) Which primitive holds true/false?**
**Answer: boolean**

**6. (Sub lesson 2) What does a non-primitive variable hold?**
**Answer: A reference — a way to reach an object in memory**

**7. (Sub lesson 2) Name three non-primitive types.**
**Answer: String, arrays, and classes generally**

**8. (Sub lesson 2) Copying a reference variable copies what?**
**Answer: The reference — both boxes reach the same object**

**9. (Sub lesson 2) Two variables 'change together'. Which family explains it?**
**Answer: Non-primitive — they share the object through copied references**

**10. (Sub lesson 2) State Malaysia's contrast in one line.**
**Answer: Primitive: the value in the box; non-primitive: a pointer to the value in the box**
