# Primitive and Non-Primitive Data Types — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Name Java's eight primitive types." is: byte, short, int, long, float, double, char, boolean**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does a primitive variable hold?" is: The value — the two boxes then live independently**
**Answer: False** — The value itself

**3. (Sub lesson 1) True or false: the answer to "Copying a primitive copies what?" is: The value — the two boxes then live independently**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How are primitive type names written?" is: boolean**
**Answer: False** — In small letters

**5. (Sub lesson 1) True or false: the answer to "Which primitive holds true/false?" is: boolean**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does a non-primitive variable hold?" is: String, arrays, and classes generally**
**Answer: False** — A reference — a way to reach an object in memory

**7. (Sub lesson 2) True or false: the answer to "Name three non-primitive types." is: String, arrays, and classes generally**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Copying a reference variable copies what?" is: Non-primitive — they share the object through copied references**
**Answer: False** — The reference — both boxes reach the same object

**9. (Sub lesson 2) True or false: the answer to "Two variables 'change together'. Which family explains it?" is: Non-primitive — they share the object through copied references**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "State Malaysia's contrast in one line." is: byte, short, int, long, float, double, char, boolean**
**Answer: False** — Primitive: the value in the box; non-primitive: a pointer to the value in the box
