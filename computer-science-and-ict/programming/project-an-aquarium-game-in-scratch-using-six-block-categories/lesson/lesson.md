# Project — An Aquarium Game in Scratch Using Six Block Categories

## Do it first

Grade 5 returns to the aquarium of Grade 4 — and makes it a game. The project's own demand is breadth: the finished game must put six block categories to work, the whole palette earning its place in one tank.

## Sub lesson 1 — From aquarium scene to aquarium game

The project begins where Grade 4 ended — an **underwater scene with swimming fish** — and adds the game's layer: something the player **does**, something that can be **won or lost**, and fish whose behaviour the player must **answer**. Planning names the game before the code: the player's action, the fish's answers, and the winning moment. A scene with fish is a picture; this project's first work is turning the picture into a game without losing the tank's life.

## Sub lesson 2 — Six categories at work — the breadth check

The game's scripts must draw on **six block categories** together: **Motion** swims the fish, **Looks** shows their changes, **Sound** voices the tank, **Events** start and restart the game, **Control** waits, repeats and decides, and **Sensing** lets fish and player feel each other — with **Operators and Variables** scoring where the game counts. The project's check is by category: the maker lists, for each of the six, the blocks the game truly uses — a category carried by one token block has not been used, only visited.
