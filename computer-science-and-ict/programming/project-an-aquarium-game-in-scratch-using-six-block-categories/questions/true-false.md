# Project — An Aquarium Game in Scratch Using Six Block Categories — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Where does the project begin?" is: With Grade 4's aquarium — an underwater scene of swimming fish**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What three things turn the scene into a game?" is: Motion, Looks, Sound, Events, Control and Sensing**
**Answer: False** — A player action, a win or loss, and fish behaviour to answer

**3. (Sub lesson 1) True or false: the answer to "What does the planning name first?" is: The player's action, the fish's answers, and the winning moment**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is a scene with fish, before the game layer?" is: Events**
**Answer: False** — A picture

**5. (Sub lesson 1) True or false: the answer to "What must the game layer not lose?" is: The tank's life — its swimming scene**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Name the six categories the game must use.?" is: When one token block is all it carries**
**Answer: False** — Motion, Looks, Sound, Events, Control and Sensing

**7. (Sub lesson 2) True or false: the answer to "What do Operators and Variables add where the game counts?" is: The scoring**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What starts and restarts the game?" is: A player action, a win or loss, and fish behaviour to answer**
**Answer: False** — Events

**9. (Sub lesson 2) True or false: the answer to "How is the breadth checked?" is: By listing, per category, the blocks the game truly uses**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "When has a category not really been used?" is: A picture**
**Answer: False** — When one token block is all it carries
