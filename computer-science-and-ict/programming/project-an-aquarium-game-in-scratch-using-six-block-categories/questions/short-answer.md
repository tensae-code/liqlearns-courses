# Project — An Aquarium Game in Scratch Using Six Block Categories — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) Where does the project begin?**
**Answer: With Grade 4's aquarium — an underwater scene of swimming fish**

**2. (Sub lesson 1) What three things turn the scene into a game?**
**Answer: A player action, a win or loss, and fish behaviour to answer**

**3. (Sub lesson 1) What does the planning name first?**
**Answer: The player's action, the fish's answers, and the winning moment**

**4. (Sub lesson 1) What is a scene with fish, before the game layer?**
**Answer: A picture**

**5. (Sub lesson 1) What must the game layer not lose?**
**Answer: The tank's life — its swimming scene**

**6. (Sub lesson 2) Name the six categories the game must use.**
**Answer: Motion, Looks, Sound, Events, Control and Sensing**

**7. (Sub lesson 2) What do Operators and Variables add where the game counts?**
**Answer: The scoring**

**8. (Sub lesson 2) What starts and restarts the game?**
**Answer: Events**

**9. (Sub lesson 2) How is the breadth checked?**
**Answer: By listing, per category, the blocks the game truly uses**

**10. (Sub lesson 2) When has a category not really been used?**
**Answer: When one token block is all it carries**
