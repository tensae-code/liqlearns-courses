# Hands-on — Project — An Aquarium Game in Scratch Using Six Block Categories

The lesson with your hands and your feet, not only your eyes.

## Name your game
Write the game's plan in three lines: what the player does, how the fish answer, and how the game is won. Under it, list the six categories and one job for each in your game.

## Build and audit it
Build the aquarium game in Scratch. Then audit it: for each of the six categories write the blocks your game uses. Strengthen the weakest category with one real job, and play the game again.
