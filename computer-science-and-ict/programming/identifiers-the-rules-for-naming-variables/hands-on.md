# Hands-on - Identifiers - the rules for naming variables

The lesson with your hands, not only your eyes.

## Name court

Cards carry names - valid ones and one breaker of each rule. A 'judge' pupil reads a card; the class calls VALID or the broken rule. The judge confirms with the picture's tick-and-cross row.

## Rename the program

On paper, a short program uses the names a, b and c for an age, a radius and a name. Rewrite it with self-descriptive identifiers, checking every new name against the four rules written at the top of the page.
