# Identifiers - the rules for naming variables - true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** _mark is a valid identifier.
**Answer: True** - an underscore may open a name.

**2. (Sub lesson 1)** A name may end with & if it starts with a letter.
**Answer: False** - & may not appear anywhere in an identifier.

**3. (Sub lesson 3)** Self-descriptive names make programs harder to understand.
**Answer: False** - they are chosen precisely so programs stay understandable.
