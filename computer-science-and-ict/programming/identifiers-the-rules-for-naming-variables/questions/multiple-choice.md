# Identifiers - the rules for naming variables - multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** An identifier's first character must be -
a) a digit  b) a letter or an underscore  c) any symbol  d) a capital letter only
**Answer: b) a letter or an underscore** - letter or underscore - nothing else may open a name.

**2. (Sub lesson 1)** After the first character, an identifier may contain -
a) letters, numbers and underscores only  b) spaces and symbols  c) letters and &  d) any characters at all
**Answer: a) letters, numbers and underscores only** - letters, numbers, underscores - that is the whole allowed set.

**3. (Sub lesson 1)** Which name is valid?
a) 2age  b) my*name  c) student_name  d) total&
**Answer: c) student_name** - the others break the digit, symbol and ending rules.

**4. (Sub lesson 2)** Keywords are -
a) names pupils invent  b) reserved words with predefined meanings  c) the longest identifiers  d) error messages
**Answer: b) reserved words with predefined meanings** - the language keeps them for itself.

**5. (Sub lesson 2)** Using a keyword as a variable name is -
a) allowed if it is short  b) invalid - keywords are reserved  c) allowed in the editor only  d) good style
**Answer: b) invalid - keywords are reserved** - a keyword can never be an identifier.

**6. (Sub lesson 2)** In Python, x and X are -
a) the same identifier  b) different identifiers - names respect case  c) both invalid  d) both keywords
**Answer: b) different identifiers - names respect case** - case matters in every name.

**7. (Sub lesson 3)** The style rule for names is to -
a) use single letters always  b) choose self-descriptive names so programs stay understandable  c) use keywords  d) avoid underscores
**Answer: b) choose self-descriptive names so programs stay understandable** - a name should say what the variable holds.
