# Approximate Numbers — Absolute and Relative Error — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What is an approximate number?** → **A value used in place of a true value it differs from**

**2. (Sub lesson 1) Name three sources of approximate numbers.** → **Measurements, rounded values, and the machine's stored reals**

**3. (Sub lesson 1) What is the absolute error?** → **The size of the difference |true − approximate| — or a bound on it**

**4. (Sub lesson 1) How is a value with its error bound written?** → **a ± Δa**

**5. (Sub lesson 1) What is rounding's absolute error at most?** → **Half a unit of the last kept decimal place**

**6. (Sub lesson 2) What is the relative error?** → **The absolute error divided by the value's size — δ = Δa / |a|**

**7. (Sub lesson 2) How is it often spoken?** → **As a percentage**

**8. (Sub lesson 2) Why does size decide quality?** → **1 mm of error is excellent in a kilometre and disgraceful in a 3 mm screw**

**9. (Sub lesson 2) What does relative error record through a computation?** → **Its health — how the error grows at each operation**

**10. (Sub lesson 2) What is a number without its error?** → **Only half reported — exactness is a claim, error is the evidence**
