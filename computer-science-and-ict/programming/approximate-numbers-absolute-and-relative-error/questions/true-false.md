# Approximate Numbers — Absolute and Relative Error — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A value used in place of a true value it differs from**
**Answer: True**

**2. (Sub lesson 1) True or false: A value used in place of a true value it differs from** — as the answer to: Name three sources of approximate numbers.
**Answer: False — Measurements, rounded values, and the machine's stored reals**

**3. (Sub lesson 1) True or false: The size of the difference |true − approximate| — or a bound on it**
**Answer: True**

**4. (Sub lesson 1) True or false: The size of the difference |true − approximate| — or a bound on it** — as the answer to: How is a value with its error bound written?
**Answer: False — a ± Δa**

**5. (Sub lesson 1) True or false: Half a unit of the last kept decimal place**
**Answer: True**

**6. (Sub lesson 2) True or false: Half a unit of the last kept decimal place** — as the answer to: What is the relative error?
**Answer: False — The absolute error divided by the value's size — δ = Δa / |a|**

**7. (Sub lesson 2) True or false: As a percentage**
**Answer: True**

**8. (Sub lesson 2) True or false: As a percentage** — as the answer to: Why does size decide quality?
**Answer: False — 1 mm of error is excellent in a kilometre and disgraceful in a 3 mm screw**

**9. (Sub lesson 2) True or false: Its health — how the error grows at each operation**
**Answer: True**

**10. (Sub lesson 2) True or false: Its health — how the error grows at each operation** — as the answer to: What is a number without its error?
**Answer: False — Only half reported — exactness is a claim, error is the evidence**
