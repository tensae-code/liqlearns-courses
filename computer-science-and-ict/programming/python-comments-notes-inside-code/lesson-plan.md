# Lesson plan - Python comments - notes inside code

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** Python comments - notes inside code
**Place in the curriculum:** Unit 6 - Fundamentals of Programming (CURRICULUM.md).
**The one thing this lesson teaches:** lines beginning with the hash symbol # are comments - notes written inside code to explain it, which Python never executes (teacher guide - evidence).

## What the learner can do when it ends
1. Say what a comment is and how it begins.
2. Say what Python does with comment lines - nothing: they are never executed.

## If the learner is stuck
- Thinks comments change the output -> Python never executes them; the worked program prints 28.26 with or without its comments.
- Writes the note but forgets the # -> without the hash, the 'note' is code - and plain English words are a syntax error waiting to happen.
