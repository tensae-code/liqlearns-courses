# Python comments - notes inside code - multiple choice

Pick the one right answer.

**1.** A Python comment begins with -
a) //  b) #  c) --  d) print(
**Answer: b) #** - the hash symbol opens a comment.

**2.** Python treats comment lines by -
a) running them first  b) translating them twice  c) never executing them - they are skipped  d) printing them as output
**Answer: c) never executing them - they are skipped** - comments are for the reader, not the machine.

**3.** Comments are written inside code to -
a) make the program faster  b) explain the code  c) store values  d) replace print()
**Answer: b) explain the code** - they explain, for human readers.

**4.** The commented circle program in this lesson prints -
a) the comments  b) 28.26 - exactly as it would without the comments  c) nothing  d) an error
**Answer: b) 28.26 - exactly as it would without the comments** - comments change nothing the machine does.

**5.** Which line is a comment?
a) radius = 3  b) # Find the area of a circle  c) print(area)  d) area = 3.14 * radius ** 2
**Answer: b) # Find the area of a circle** - the line beginning with #.

**6.** A program still runs exactly the same after its comments are deleted because -
a) comments make it slower  b) Python never executes comments  c) comments are stored elsewhere  d) print() ignores files with comments
**Answer: b) Python never executes comments** - comments are skipped, always.
