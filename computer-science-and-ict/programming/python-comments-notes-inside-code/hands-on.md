# Hands-on - Python comments - notes inside code

The lesson with your hands, not only your eyes.

## Note the script

On paper copies of the circle script, pupils write one # comment per line in their own words, then exchange copies: the reader must explain the program using ONLY the comments before seeing the code.

## Skip the grey

One pupil reads a commented program aloud, raising a hand and staying silent on every comment line - acting out Python skipping them - while a partner tracks which lines 'ran' on a tally sheet.
