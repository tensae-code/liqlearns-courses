## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Assignment puts a value into a variable** — The **assignment statement** is the statement that **puts a value into a variable**: the variable's name goes on one side, the value on the other, and when the statement runs, the variable holds that value. It follows the book's lessons on constants and variables and on input and output: a variable that holds nothing is of no use until a value is assigned to it.
2. **Assignment is not equality** — Assignment is an **action, not an equality**: the computer works out the value on the right side and stores it in the variable on the left, replacing what was there before. Writing x = x + 1 is nonsense as maths equality but a normal assignment — it takes x's old value, adds 1, and stores the result back into x.
