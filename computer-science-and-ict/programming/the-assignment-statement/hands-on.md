# Hands-on — The Assignment Statement

The lesson with your hands and your feet, not only your eyes.

## Trace the boxes
Draw three boxes named a, b and total. Run a = 4, b = 6, total = a + b on paper, writing each new value into its box as the statement runs.

## Spot the action
Write two lines: one maths equality and one assignment that looks like it. Explain to a companion which is which and why.
