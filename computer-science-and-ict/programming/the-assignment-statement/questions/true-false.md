# The Assignment Statement — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does the assignment statement do?" is: It puts a value into a variable**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What goes on one side of an assignment?" is: When the statement runs**
**Answer: False** — The variable's name

**3. (Sub lesson 1) True or false: the answer to "What goes on the other side?" is: The value**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "When does the variable hold the value?" is: No — it is an action**
**Answer: False** — When the statement runs

**5. (Sub lesson 1) True or false: the answer to "Which lessons does assignment follow in the book?" is: Constants and variables, and input and output**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Is assignment an equality?" is: In the variable on the left**
**Answer: False** — No — it is an action

**7. (Sub lesson 2) True or false: the answer to "What does the computer do first in an assignment?" is: It works out the value on the right side**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Where is the result stored?" is: It adds 1 to x's old value and stores the result back into x**
**Answer: False** — In the variable on the left

**9. (Sub lesson 2) True or false: the answer to "What happens to the variable's old value?" is: It is replaced**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What does x = x + 1 do?" is: The variable's name**
**Answer: False** — It adds 1 to x's old value and stores the result back into x
