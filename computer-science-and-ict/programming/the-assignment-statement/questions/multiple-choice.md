# The Assignment Statement — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does the assignment statement do?**
a) It puts a value into a variable  b) The variable's name  c) When the statement runs  d) No — it is an action
**Answer: a) It puts a value into a variable**

**2. (Sub lesson 1) What goes on one side of an assignment?**
a) The value  b) The variable's name  c) Constants and variables, and input and output  d) It works out the value on the right side
**Answer: b) The variable's name**

**3. (Sub lesson 1) What goes on the other side?**
a) When the statement runs  b) No — it is an action  c) The value  d) In the variable on the left
**Answer: c) The value**

**4. (Sub lesson 1) When does the variable hold the value?**
a) Constants and variables, and input and output  b) It works out the value on the right side  c) It is replaced  d) When the statement runs
**Answer: d) When the statement runs**

**5. (Sub lesson 1) Which lessons does assignment follow in the book?**
a) Constants and variables, and input and output  b) No — it is an action  c) In the variable on the left  d) It adds 1 to x's old value and stores the result back into x
**Answer: a) Constants and variables, and input and output**

**6. (Sub lesson 2) Is assignment an equality?**
a) It works out the value on the right side  b) No — it is an action  c) It is replaced  d) It puts a value into a variable
**Answer: b) No — it is an action**

**7. (Sub lesson 2) What does the computer do first in an assignment?**
a) In the variable on the left  b) It adds 1 to x's old value and stores the result back into x  c) It works out the value on the right side  d) The variable's name
**Answer: c) It works out the value on the right side**

**8. (Sub lesson 2) Where is the result stored?**
a) It is replaced  b) It puts a value into a variable  c) The value  d) In the variable on the left
**Answer: d) In the variable on the left**

**9. (Sub lesson 2) What happens to the variable's old value?**
a) It is replaced  b) It adds 1 to x's old value and stores the result back into x  c) The variable's name  d) When the statement runs
**Answer: a) It is replaced**

**10. (Sub lesson 2) What does x = x + 1 do?**
a) It puts a value into a variable  b) It adds 1 to x's old value and stores the result back into x  c) The value  d) Constants and variables, and input and output
**Answer: b) It adds 1 to x's old value and stores the result back into x**
