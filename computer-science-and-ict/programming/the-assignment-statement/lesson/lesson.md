# The Assignment Statement

## Do it first

Write this on paper: score = 10. You have not written an equals sign from maths — you have given an order: put 10 into score. That order has a name, and Iraq's Grade 7 book teaches it as its own lesson. This is that lesson.

## Sub lesson 1 — Assignment puts a value into a variable

The **assignment statement** is the statement that **puts a value into a variable**: the variable's name goes on one side, the value on the other, and when the statement runs, the variable holds that value. It follows the book's lessons on constants and variables and on input and output: a variable that holds nothing is of no use until a value is assigned to it.

## Sub lesson 2 — Assignment is not equality

Assignment is an **action, not an equality**: the computer works out the value on the right side and stores it in the variable on the left, replacing what was there before. Writing x = x + 1 is nonsense as maths equality but a normal assignment — it takes x's old value, adds 1, and stores the result back into x.

## Say it to your companion

Tell your companion, in your own words: The assignment statement is the statement that puts a value into a variable: the variable's name goes on one side, the value on the other, and when the statement runs, the variable holds that value. Assignment is an action, not an equality: the computer works out the value on the right side and stores it in the variable on the left, replacing what was there before. Then let your companion ask you one question about it — and answer from the lesson, not from memory of the book's exact words.
