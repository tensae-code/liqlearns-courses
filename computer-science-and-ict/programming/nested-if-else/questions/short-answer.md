# Nested if-else — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a nested if-else?**
**Answer: A selection inside another selection's branch**

**2. (Sub lesson 1) When does the inner test run?**
**Answer: Only when the outer branch holding it is taken**

**3. (Sub lesson 1) When is nesting the right shape?**
**Answer: When the second question only makes sense after the first**

**4. (Sub lesson 1) Give the lesson's example pair of questions.**
**Answer: Pass the exam? Then distinction or plain pass?**

**5. (Sub lesson 1) How many paths does one run take through a nested selection?**
**Answer: Exactly one**

**6. (Sub lesson 2) Which if does an else pair with?**
**Answer: The nearest unmatched if**

**7. (Sub lesson 2) What must indentation do in nested code?**
**Answer: Honestly mirror the pairing**

**8. (Sub lesson 2) What removes pairing doubt?**
**Answer: Braces around branches**

**9. (Sub lesson 2) How does the book teach nesting?**
**Answer: Through exercises — tracing the one path taken**

**10. (Sub lesson 2) What do you mark when tracing?**
**Answer: The conditions in order and the single path taken**
