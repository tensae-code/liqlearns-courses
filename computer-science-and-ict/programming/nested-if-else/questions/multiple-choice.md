# Nested if-else — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a nested if-else?**
a) A selection inside another selection's branch  b) Only when the outer branch holding it is taken  c) When the second question only makes sense after the first  d) Pass the exam? Then distinction or plain pass?
**Answer: a) A selection inside another selection's branch**

**2. (Sub lesson 1) When does the inner test run?**
a) When the second question only makes sense after the first  b) Only when the outer branch holding it is taken  c) Pass the exam? Then distinction or plain pass?  d) Exactly one
**Answer: b) Only when the outer branch holding it is taken**

**3. (Sub lesson 1) When is nesting the right shape?**
a) Pass the exam? Then distinction or plain pass?  b) Exactly one  c) When the second question only makes sense after the first  d) The nearest unmatched if
**Answer: c) When the second question only makes sense after the first**

**4. (Sub lesson 1) Give the lesson's example pair of questions.**
a) Exactly one  b) The nearest unmatched if  c) Honestly mirror the pairing  d) Pass the exam? Then distinction or plain pass?
**Answer: d) Pass the exam? Then distinction or plain pass?**

**5. (Sub lesson 1) How many paths does one run take through a nested selection?**
a) Exactly one  b) The nearest unmatched if  c) Honestly mirror the pairing  d) Braces around branches
**Answer: a) Exactly one**

**6. (Sub lesson 2) Which if does an else pair with?**
a) Honestly mirror the pairing  b) The nearest unmatched if  c) Braces around branches  d) Through exercises — tracing the one path taken
**Answer: b) The nearest unmatched if**

**7. (Sub lesson 2) What must indentation do in nested code?**
a) Braces around branches  b) Through exercises — tracing the one path taken  c) Honestly mirror the pairing  d) The conditions in order and the single path taken

**8. (Sub lesson 2) What removes pairing doubt?**
a) Through exercises — tracing the one path taken  b) The conditions in order and the single path taken  c) A selection inside another selection's branch  d) Braces around branches
**Answer: d) Braces around branches**

**9. (Sub lesson 2) How does the book teach nesting?**
a) Through exercises — tracing the one path taken  b) The conditions in order and the single path taken  c) A selection inside another selection's branch  d) Only when the outer branch holding it is taken
**Answer: a) Through exercises — tracing the one path taken**

**10. (Sub lesson 2) What do you mark when tracing?**
