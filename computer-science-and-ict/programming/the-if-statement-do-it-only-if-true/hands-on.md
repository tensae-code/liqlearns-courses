# Hands-on — The if statement — do it only if it's true

The lesson with your hands, not only your eyes — every activity is done for real, in IDLE or on paper.

## Human gate
Stand in a doorway. A partner calls numbers: step through and clap only when the number is greater than 0. You are the indented block; the doorway is the if.

## Predict, then run
Write three if programs on paper — one true, one false, one with a line outside the block. Predict every output, then run all three in IDLE and check.
