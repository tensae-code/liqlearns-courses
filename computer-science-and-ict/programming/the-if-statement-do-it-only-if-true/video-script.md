This lesson: **The if statement — do it only if it's true**.

First, do it. Run the opening program. Watch what it prints.

Then the idea, in order: The if, its condition, its colon, and the indented block that runs or is skipped. Lines before or after the if, not indented, run as normal either way; entering 0 or a negative age gives no output.

Now you. Run the age program with age 1, 0 and −1. Write what prints each time before you run it.

Say it to your companion: Explain the if gate to your companion: the condition, the colon, the indented block — and what happens when the test is false.
