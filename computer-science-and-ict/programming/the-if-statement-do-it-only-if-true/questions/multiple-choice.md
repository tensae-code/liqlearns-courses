# The if statement — do it only if it's true — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The if condition must end with —
a) a semicolon  b) a colon  c) a full stop
**Answer: b) b) a colon** — Missing it is a syntax error.

**2. (Sub lesson 1)** If the condition is false, the indented block —
a) runs once  b) is skipped  c) runs twice
**Answer: b) b) is skipped**

**3. (Sub lesson 1)** With `age = -1`, the program in Do it first prints —
a) both lines  b) one line  c) nothing
**Answer: c) c) nothing** — Verified by running it.

**4. (Sub lesson 2)** A non-indented line after the if block —
a) is part of the if  b) runs as normal either way  c) never runs
**Answer: b) b) runs as normal either way**

**5. (Sub lesson 2)** Entering age 0 makes `age > 0` —
a) True  b) False
**Answer: b) b) False** — 0 is not greater than 0.

**6. (Sub lesson 1)** An if must be followed by at least —
a) one indented statement  b) three statements  c) an else
**Answer: a) a) one indented statement**
