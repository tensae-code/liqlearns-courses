# The if statement — do it only if it's true — true or false

Say True or False.

**1. (Sub lesson 1)** The if block runs when its condition is true.
**Answer: True**

**2. (Sub lesson 1)** The colon after the condition is optional.
**Answer: False**

**3. (Sub lesson 2)** Lines outside the if block run whether or not the condition holds.
**Answer: True**

**4. (Sub lesson 2)** With a false condition, Python runs the block but hides its output.
**Answer: False**
