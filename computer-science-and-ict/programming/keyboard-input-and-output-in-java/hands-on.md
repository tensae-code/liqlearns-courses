# Hands-on — Keyboard Input and Output in Java

The lesson with your hands and your feet, not only your eyes.

## Task one
('Write the conversation', 'Write a Java program that prompts for a name and two marks, reads them with a Scanner, and prints the pupil's name with the average mark. Label the prompt, read, process and print lines.')

## Task two
('Match the reader', 'For each value, name the Scanner method: 42, 3.75, 'Aina binti Omar', true-or-false as text 'yes'. Then say what fault follows if nextInt() is used for 3.75.')
