# Keyboard Input and Output in Java — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does System.out.println do?**
a) Prints its value, then moves to a new line  b) It stays on the same line  c) With + — "Mark: " + mark  d) A silent program leaves the user not knowing it waits, or for what
**Answer: a) Prints its value, then moves to a new line**

**2. (Sub lesson 1) How does System.out.print differ?**
a) With + — "Mark: " + mark  b) It stays on the same line  c) A silent program leaves the user not knowing it waits, or for what  d) A Scanner on System.in
**Answer: b) It stays on the same line**

**3. (Sub lesson 1) How are text and a variable joined in one print?**
a) A silent program leaves the user not knowing it waits, or for what  b) A Scanner on System.in  c) With + — "Mark: " + mark  d) nextInt()
**Answer: c) With + — "Mark: " + mark**

**4. (Sub lesson 1) Why do Malaysia's programs print prompts?**
a) A Scanner on System.in  b) nextInt()  c) nextDouble() for a decimal; nextLine() for text  d) A silent program leaves the user not knowing it waits, or for what
**Answer: d) A silent program leaves the user not knowing it waits, or for what**

**5. (Sub lesson 1) What object reads keyboard input in this chapter?**
a) A Scanner on System.in  b) nextInt()  c) nextDouble() for a decimal; nextLine() for text  d) After the user types and presses Enter — the read waits
**Answer: a) A Scanner on System.in**

**6. (Sub lesson 2) Which Scanner method reads a whole number?**
a) nextDouble() for a decimal; nextLine() for text  b) nextInt()  c) After the user types and presses Enter — the read waits  d) A run-time fault — the type promised is broken
**Answer: b) nextInt()**

**7. (Sub lesson 2) Which reads a decimal, and which a line of text?**
a) After the user types and presses Enter — the read waits  b) A run-time fault — the type promised is broken  c) nextDouble() for a decimal; nextLine() for text  d) Prompt, read, process, print — input, process, output
**Answer: c) nextDouble() for a decimal; nextLine() for text**

**8. (Sub lesson 2) When does a read hand its value over?**
a) A run-time fault — the type promised is broken  b) Prompt, read, process, print — input, process, output  c) Prints its value, then moves to a new line  d) After the user types and presses Enter — the read waits
**Answer: d) After the user types and presses Enter — the read waits**

**9. (Sub lesson 2) Asking nextInt() for letters causes what?**
a) A run-time fault — the type promised is broken  b) Prompt, read, process, print — input, process, output  c) Prints its value, then moves to a new line  d) It stays on the same line
**Answer: a) A run-time fault — the type promised is broken**

**10. (Sub lesson 2) What is the chapter's program shape?**
a) Prints its value, then moves to a new line  b) Prompt, read, process, print — input, process, output  c) It stays on the same line  d) With + — "Mark: " + mark
