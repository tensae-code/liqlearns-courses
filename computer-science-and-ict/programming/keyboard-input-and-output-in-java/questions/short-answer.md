# Keyboard Input and Output in Java — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does System.out.println do?**
**Answer: Prints its value, then moves to a new line**

**2. (Sub lesson 1) How does System.out.print differ?**
**Answer: It stays on the same line**

**3. (Sub lesson 1) How are text and a variable joined in one print?**
**Answer: With + — "Mark: " + mark**

**4. (Sub lesson 1) Why do Malaysia's programs print prompts?**
**Answer: A silent program leaves the user not knowing it waits, or for what**

**5. (Sub lesson 1) What object reads keyboard input in this chapter?**
**Answer: A Scanner on System.in**

**6. (Sub lesson 2) Which Scanner method reads a whole number?**
**Answer: nextInt()**

**7. (Sub lesson 2) Which reads a decimal, and which a line of text?**
**Answer: nextDouble() for a decimal; nextLine() for text**

**8. (Sub lesson 2) When does a read hand its value over?**
**Answer: After the user types and presses Enter — the read waits**

**9. (Sub lesson 2) Asking nextInt() for letters causes what?**
**Answer: A run-time fault — the type promised is broken**

**10. (Sub lesson 2) What is the chapter's program shape?**
**Answer: Prompt, read, process, print — input, process, output**
