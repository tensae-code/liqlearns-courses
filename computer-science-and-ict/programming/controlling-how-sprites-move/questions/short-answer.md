# Controlling How Sprites Move — short answer

Answer in a sentence or two.

**1. Explain, in your own words: build a sprite that moves under key or click control.**
**Answer:** The learner's own explanation, true to the lesson: Controlling movement means the user drives the sprite: keys or clicks give the commands, and the sprite moves when and where the user says — the sprite obeys a driver, not only a script.

**2. A classmate gets this lesson's work wrong. What is the most likely fault, and how is it fixed?**
**Answer:** Sprite moves on its own or not at all → check the listening: each command needs its own event script; a move inside the flag script runs once at the start, not on command.
