# Controlling How Sprites Move — multiple choice

Pick the one right answer.

**1. Controlling a sprite's movement means —**
a) the user drives it by keys or clicks  b) the script runs once by itself  c) the sprite moves at random
**Answer: a) the user drives it by keys or clicks**

**2. Each command needs —**
a) the same flag script as everything else  b) no script at all  c) its own listening script
**Answer: c) its own listening script**

**3. A control is proved when —**
a) it looks neat  b) it works every time it is given, and does nothing when not given  c) it works once
**Answer: b) it works every time it is given, and does nothing when not given**

**4. The usual keys for driving a sprite are —**
a) the arrow keys  b) the number keys only  c) the space bar only
**Answer: a) the arrow keys**
