## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Procedures — named work** — A **procedure** is a named block of statements, written once above the main program and **called** by its name wherever the work is needed. It takes **parameters** — values handed in for this call — does its work, and returns control to the caller. The Grade 9 book teaches procedures and functions together, as one lesson with a repetition after it.
2. **Functions — named work that answers a value** — A **function** is a procedure that **returns a value**: it is used inside an expression, like the standard functions, and its name carries the result back. Rule of choice: if the block must give back one value, make it a function; if it does a job — draw, print, sort — make it a procedure. Both keep the main program short enough to read at a glance.
