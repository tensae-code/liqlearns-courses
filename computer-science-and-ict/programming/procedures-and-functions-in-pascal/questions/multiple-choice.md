# Procedures and Functions in Pascal — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a procedure?**
a) A named block of statements, written once and called by name  b) Values handed in for this call  c) Above the main program  d) Control — it hands back where to continue
**Answer: a) A named block of statements, written once and called by name**

**2. (Sub lesson 1) What are parameters?**
a) Above the main program  b) Values handed in for this call  c) Control — it hands back where to continue  d) Together with functions, in one lesson
**Answer: b) Values handed in for this call**

**3. (Sub lesson 1) Where is a procedure written?**
a) Control — it hands back where to continue  b) Together with functions, in one lesson  c) Above the main program  d) A value
**Answer: c) Above the main program**

**4. (Sub lesson 1) What does a procedure return to the caller?**
a) Together with functions, in one lesson  b) A value  c) Inside an expression  d) Control — it hands back where to continue
**Answer: d) Control — it hands back where to continue**

**5. (Sub lesson 1) With what are procedures taught in the book?**
a) Together with functions, in one lesson  b) A value  c) Inside an expression  d) When the block must give back one value
**Answer: a) Together with functions, in one lesson**

**6. (Sub lesson 2) What does a function return?**
a) Inside an expression  b) A value  c) When the block must give back one value  d) When the block does a job — draw, print, sort
**Answer: b) A value**

**7. (Sub lesson 2) Where is a function used?**
a) When the block must give back one value  b) When the block does a job — draw, print, sort  c) Inside an expression  d) The main program
**Answer: c) Inside an expression**

**8. (Sub lesson 2) When do you choose a function over a procedure?**
a) When the block does a job — draw, print, sort  b) The main program  c) A named block of statements, written once and called by name  d) When the block must give back one value
**Answer: d) When the block must give back one value**

**9. (Sub lesson 2) When do you choose a procedure?**
a) When the block does a job — draw, print, sort  b) The main program  c) A named block of statements, written once and called by name  d) Values handed in for this call
**Answer: a) When the block does a job — draw, print, sort**

**10. (Sub lesson 2) What do both keep short?**
a) A named block of statements, written once and called by name  b) The main program  c) Values handed in for this call  d) Above the main program
**Answer: b) The main program**
