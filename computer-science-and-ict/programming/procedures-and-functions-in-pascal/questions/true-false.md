# Procedures and Functions in Pascal — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a procedure?" is: A named block of statements, written once and called by name**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What are parameters?" is: Above the main program**
**Answer: False** — Values handed in for this call

**3. (Sub lesson 1) True or false: the answer to "Where is a procedure written?" is: Above the main program**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does a procedure return to the caller?" is: Together with functions, in one lesson**
**Answer: False** — Control — it hands back where to continue

**5. (Sub lesson 1) True or false: the answer to "With what are procedures taught in the book?" is: Together with functions, in one lesson**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does a function return?" is: Inside an expression**
**Answer: False** — A value

**7. (Sub lesson 2) True or false: the answer to "Where is a function used?" is: Inside an expression**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "When do you choose a function over a procedure?" is: When the block does a job — draw, print, sort**
**Answer: False** — When the block must give back one value

**9. (Sub lesson 2) True or false: the answer to "When do you choose a procedure?" is: When the block does a job — draw, print, sort**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What do both keep short?" is: A named block of statements, written once and called by name**
**Answer: False** — The main program
