# Video script — Scratch — stage, sprite, palette, script

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

This is **Scratch — stage, sprite, palette, script**.

**the Stage** — the top-right area of the Scratch window, where the action shows.

**a sprite** — an actor or main character on the stage, programmed to do things — a cat by default.

**the Palette** — the left-hand Code area holding the block categories: Motion, Looks, Sounds, Events, Control, Sensing, Operators, Variables.

**the Script area** — where blocks taken from the palette tell the actor what to say or do.

Now you try. Say each word. Say what it means.
