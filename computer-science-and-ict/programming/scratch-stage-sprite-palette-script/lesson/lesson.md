# Scratch — stage, sprite, palette, script

## Do it first

A free program from scratch.mit.edu opens, and a cat stands waiting on a small stage. Around it: coloured blocks in families, and an empty space where scripts will grow. Before anything moves, learn the room: four main elements. Find each one in the picture as it is named.

## The stage and the sprite

Scratch is a high-level block-based visual programming language, an educational tool for stories, animations and games, free from scratch.mit.edu. The Stage sits at the top right. On it stands the Sprite — a cat by default. Sprites are the actors, the main characters, programmed to do things.

## The palette and the script area

The programming Palette sits at the left in version 3, labelled Code, with categories: Motion, Looks, Sounds, Events, Control, Sensing, Operators and Variables. And the Script area is where blocks taken from the palette tell the actor what to say or do. Palette chooses, script area builds, sprite acts, stage shows — the four elements in one sentence.

## Say it to your companion

Tell your companion, in your own words: Scratch's first window has four main elements: the Stage, the Sprite on it, the programming Palette, and the Script area where blocks tell the actor what to do. Then name the key words of this lesson — the Stage, a sprite, the Palette, the Script area — and say what each one means.
