# Scratch — stage, sprite, palette, script — tf

Say whether each statement is true or false.

**1.** True or false: the Stage — the top-right area of the Scratch window, where the action shows.
**Answer: True**

**2.** True or false: a sprite — an actor or main character on the stage, programmed to do things — a cat by default.
**Answer: True**

**3.** True or false: the Palette is the opposite: it has nothing to do with the left-hand Code area holding the block categories: Motion, Looks, Sounds, Events, Control, Sensing, Operators, Variables.
**Answer: False** — the Palette is about the left-hand Code area holding the block categories: Motion, Looks, Sounds, Events, Control, Sensing, Operators, Variables.
