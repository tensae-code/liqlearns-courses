# Scratch — stage, sprite, palette, script — fill

Fill each blank with the right word or words.

**1.** _____ is an actor or main character on the stage, programmed to do things — a cat by default. (Name the term.)
**Answer: a sprite**

**2.** _____ is the left-hand Code area holding the block categories: Motion, Looks, Sounds, Events, Control, Sensing, Operators, Variables. (Name the term.)
**Answer: the Palette**

**3.** _____ is where blocks taken from the palette tell the actor what to say or do. (Name the term.)
**Answer: the Script area**
