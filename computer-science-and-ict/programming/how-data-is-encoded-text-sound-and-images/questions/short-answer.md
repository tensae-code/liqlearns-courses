# How Data Is Encoded — Text, Sound and Images — short answer

Answer each question in a few sentences.

**1. (Sub lesson 1) Explain, in three sentences, how the same computer can store a letter, a song and a photo when it only holds numbers.**
**Answer:** The letter is stored by a code table: its character number, in binary. The song is sampled: the wave's height measured thousands of times a second, each measurement a number. The photo is split into pixels, and each pixel's colour is stored as numbers — three codes, all ending in numbers.

**2. (Sub lesson 2) A student records two versions of an interview: one file is four times bigger and sounds much clearer. Explain, using sampling.**
**Answer:** The clearer version was sampled more finely — more measurements per second and/or finer measurement steps — so its numbers rebuild a wave closer to the original voice. More numbers stored means a bigger file: quality was bought with size.
