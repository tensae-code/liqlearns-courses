# How Data Is Encoded — Text, Sound and Images — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Decoding text is the code table read in the opposite direction.**
**Answer: True** — Number in, character out — the same table.

**2. (Sub lesson 2) A computer stores a photograph as one single number.**
**Answer: False** — It stores a number-set for every pixel in the grid.

**3. (Sub lesson 2) A recording with fewer samples per second takes less storage.**
**Answer: True** — Fewer measurements, smaller file — and a poorer copy.
