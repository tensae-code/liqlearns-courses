# How Data Is Encoded — Text, Sound and Images — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) In ASCII, characters are stored as —**
a) tiny drawings of letters  b) their code numbers, in binary  c) sound samples  d) pixel colours
**Answer: b) their code numbers, in binary** — A is 65; the table is read backwards to decode.

**2. (Sub lesson 1) Unicode extends the ASCII idea by —**
a) making files smaller  b) covering the characters of all the world's scripts  c) removing numbers  d) storing only English
**Answer: b) covering the characters of all the world's scripts** — Including Chinese characters — one rule for every language.

**3. (Sub lesson 2) Sampling a sound means —**
a) playing it twice  b) measuring the wave's height at regular moments, thousands of times per second  c) cutting it into pixels  d) writing down its title
**Answer: b) measuring the wave's height at regular moments, thousands of times per second** — Each measurement is stored as a number.

**4. (Sub lesson 2) An image is encoded as —**
a) samples per second  b) a grid of pixels, each stored as colour numbers  c) a code table of letters  d) one long number
**Answer: b) a grid of pixels, each stored as colour numbers** — Red, green and blue amounts per pixel, for example.

**5. (Sub lesson 2) Taking more samples per second gives —**
a) a worse copy and a smaller file  b) a closer copy and a bigger file  c) the same copy and the same file  d) no sound at all
**Answer: b) a closer copy and a bigger file** — Quality against size — the trade every encoding makes.
