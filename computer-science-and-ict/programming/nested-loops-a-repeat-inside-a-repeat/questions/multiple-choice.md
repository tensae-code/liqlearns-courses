# Nested Loops — a Repeat Inside a Repeat — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a nested loop?**
a) A repeat block inside another repeat block  b) Before the outer loop’s next turn  c) The hard plan  d) Ornaments
**Answer: a) A repeat block inside another repeat block**

**2. (Sub lesson 1) When does the inner loop finish?**
a) Easy, medium and hard  b) Before the outer loop’s next turn  c) The wall-building pattern  d) The colour
**Answer: b) Before the outer loop’s next turn**

**3. (Sub lesson 1) What three plan levels does Building the house offer?**
a) The hard plan  b) Ornaments  c) Easy, medium and hard  d) It is asked from the user and stored as the answer
**Answer: c) Easy, medium and hard**

**4. (Sub lesson 1) Which plan level needs the nested repeat?**
a) The wall-building pattern  b) The colour  c) Saved under its own name  d) The hard plan
**Answer: d) The hard plan**

**5. (Sub lesson 1) What does the outer repeat run in the house plan?**
a) The wall-building pattern  b) Ornaments  c) It is asked from the user and stored as the answer  d) The small repeated pattern, repeated
**Answer: a) The wall-building pattern**

**6. (Sub lesson 2) What do Grades 8 and 9 draw with nested repeats?**
a) The colour  b) Ornaments  c) Saved under its own name  d) A repeat block inside another repeat block
**Answer: b) Ornaments**

**7. (Sub lesson 2) What changes inside the loop in the Grade 8 ornament?**
a) It is asked from the user and stored as the answer  b) The small repeated pattern, repeated  c) The colour  d) Before the outer loop’s next turn
**Answer: c) The colour**

**8. (Sub lesson 2) In Grade 9, where does the number of sides come from?**
a) Saved under its own name  b) A repeat block inside another repeat block  c) Easy, medium and hard  d) It is asked from the user and stored as the answer
**Answer: d) It is asked from the user and stored as the answer**

**9. (Sub lesson 2) How is each ornament file kept?**
a) Saved under its own name  b) The small repeated pattern, repeated  c) Before the outer loop’s next turn  d) The hard plan
**Answer: a) Saved under its own name**

**10. (Sub lesson 2) What builds the big pattern in a nested loop?**
a) A repeat block inside another repeat block  b) The small repeated pattern, repeated  c) Easy, medium and hard  d) The wall-building pattern
**Answer: b) The small repeated pattern, repeated**
