# An Algorithm Is a Clear Plan — true or false

Say whether each statement is true or false.

**1. Anyone following a good algorithm carefully gets the same result.**
**Answer: True** — That is the point of a clear plan.

**2. 'Add some water' is a clear step.**
**Answer: False** — 'Some' makes the follower guess.

**3. Algorithms are only for computers.**
**Answer: False** — Recipes and directions are algorithms too — the idea is from everyday life first.
