Placement choice: this lesson was built new for the ICT expansion (Azerbaijan, 2026-11-14) because no existing lesson in the course covers this thing as its own lesson at this Grade 2 level — the live tree was checked first, including the overlap watches named in the merger brief. The placements file named this slug directly (NEW LESSON NEEDED — programming/an-algorithm-is-a-clear-plan). It sits in the Programming title (programming/), where the placements file placed it. It is one whole lesson with no sub lessons — a small Grade 2 lesson running straight through.

Azerbaijan's own way: informatics starts two full years before touching a computer — objects and their features, information in everyday life, and algorithms as daily-life sequences and true/false judgements; the computer itself, WordPad, Paint and Calculator arrive only in the final unit. This lesson keeps that order and that Grade 2 voice.


Uzbekistan's own way (Grade 9): grade 9 is the capstone — computer graphics, Access, Excel, then a nine-lesson algorithms block and a 28-lesson Turbo Pascal 7.0 course that runs from the alphabet of the language to files, procedures and graphics mode, closing with the Internet. Every chapter ends with a dedicated repetition lesson, placed here to that chapter's main lesson.

Bhutan's own way (Class V, Literacy with ICT student book): Word is taught together with typing in Dzongkha, the national language (Dzongkha keyboard software and fonts); communication is taught on the school LAN with Qualia LAN Messenger (chat, file sharing and broadcast with no Internet connection), and the end-of-year folder is sent to the teacher as a LAN-messenger attachment.
