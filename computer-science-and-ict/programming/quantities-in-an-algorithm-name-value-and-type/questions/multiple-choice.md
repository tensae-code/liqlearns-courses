# Quantities in an Algorithm — Name, Value and Type — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Name the three faces of a quantity.**
a) Name, value and type  b) The word the algorithm calls it by  c) What it holds at this moment — which may change as the algorithm runs  d) What operations make sense on it
**Answer: a) Name, value and type**

**2. (Sub lesson 1) What is a quantity's name?**
a) What it holds at this moment — which may change as the algorithm runs  b) The word the algorithm calls it by  c) What operations make sense on it  d) Calling a quantity never named; trusting a value never set; working a text as a number
**Answer: b) The word the algorithm calls it by**

**3. (Sub lesson 1) What is its value?**
a) What operations make sense on it  b) Calling a quantity never named; trusting a value never set; working a text as a number  c) What it holds at this moment — which may change as the algorithm runs  d) A tethered horse's grazing area
**Answer: c) What it holds at this moment — which may change as the algorithm runs**

**4. (Sub lesson 1) What does its type decide?**
a) Calling a quantity never named; trusting a value never set; working a text as a number  b) A tethered horse's grazing area  c) A circle; its radius is the rope  d) What operations make sense on it
