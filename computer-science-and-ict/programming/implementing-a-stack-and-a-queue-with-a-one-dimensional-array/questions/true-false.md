# Implementing a Stack and a Queue with a One-Dimensional Array — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A one-dimensional array of fixed size**
**Answer: True**

**2. (Sub lesson 1) True or false: Check not full, move top up one, store the value there** — as the answer to: What does the top pointer remember?
**Answer: False — The place of the last value pushed**

**3. (Sub lesson 1) True or false: Check not full, move top up one, store the value there**
**Answer: True**

**4. (Sub lesson 1) True or false: Overflow (pushing onto a full stack) and underflow (popping an empty one)** — as the answer to: What are pop's steps?
**Answer: False — Check not empty, take the value at top, move top down one**

**5. (Sub lesson 1) True or false: Overflow (pushing onto a full stack) and underflow (popping an empty one)**
**Answer: True**

**6. (Sub lesson 2) True or false: The line walks along the array** — as the answer to: Why does the queue need two pointers?
**Answer: False — Front where values leave, rear where values join — two moving ends**

**7. (Sub lesson 2) True or false: The line walks along the array**
**Answer: True**

**8. (Sub lesson 2) True or false: Worked implementation examples, step by step, pointer by pointer** — as the answer to: How are full and empty tested?
**Answer: False — By the pointers' positions**

**9. (Sub lesson 2) True or false: Worked implementation examples, step by step, pointer by pointer**
**Answer: True**
