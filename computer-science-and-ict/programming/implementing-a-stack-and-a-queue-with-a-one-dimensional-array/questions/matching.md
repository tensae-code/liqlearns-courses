# Implementing a Stack and a Queue with a One-Dimensional Array — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What holds the pile?** → **A one-dimensional array of fixed size**

**2. (Sub lesson 1) What does the top pointer remember?** → **The place of the last value pushed**

**3. (Sub lesson 1) What are push's steps?** → **Check not full, move top up one, store the value there**

**4. (Sub lesson 1) What are pop's steps?** → **Check not empty, take the value at top, move top down one**

**5. (Sub lesson 1) Name the two edge faults.** → **Overflow (pushing onto a full stack) and underflow (popping an empty one)**

**6. (Sub lesson 2) Why does the queue need two pointers?** → **Front where values leave, rear where values join — two moving ends**

**7. (Sub lesson 2) What happens as the queue works?** → **The line walks along the array**

**8. (Sub lesson 2) How are full and empty tested?** → **By the pointers' positions**

**9. (Sub lesson 2) How does the unit teach the building?** → **Worked implementation examples, step by step, pointer by pointer**
