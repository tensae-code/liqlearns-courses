# Binary Trees — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) How many children may a node of a binary tree have?** → **At most two**

**2. (Sub lesson 1) What are the two child places called?** → **Left child and right child**

**3. (Sub lesson 1) Is a node with only a left child the same as one with only a right child?** → **No — the places have names, so the trees differ**

**4. (Sub lesson 1) What is a leaf?** → **A node with no children**

**5. (Sub lesson 1) What is an empty subtree?** → **A child place left empty — it still counts in the structure**

**6. (Sub lesson 2) What does a node store in the linked representation?** → **Its value, and references to its left and right children**

**7. (Sub lesson 2) In the array representation, where do node i's children sit?** → **At indexes 2i and 2i + 1, with the root at index 1**

**8. (Sub lesson 2) For which trees is the array way neat?** → **Complete trees — it wastes space on crooked ones**

**9. (Sub lesson 2) What is a tree's height?** → **The longest path from the root to a leaf**

**10. (Sub lesson 2) Why does height matter?** → **It decides how much work a walk down the tree can cost**
