# Binary Trees — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: At most two**
**Answer: True**

**2. (Sub lesson 1) True or false: At most two** — as the answer to: What are the two child places called?
**Answer: False — Left child and right child**

**3. (Sub lesson 1) True or false: No — the places have names, so the trees differ**
**Answer: True**

**4. (Sub lesson 1) True or false: No — the places have names, so the trees differ** — as the answer to: What is a leaf?
**Answer: False — A node with no children**

**5. (Sub lesson 1) True or false: A child place left empty — it still counts in the structure**
**Answer: True**

**6. (Sub lesson 2) True or false: A child place left empty — it still counts in the structure** — as the answer to: What does a node store in the linked representation?
**Answer: False — Its value, and references to its left and right children**

**7. (Sub lesson 2) True or false: At indexes 2i and 2i + 1, with the root at index 1**
**Answer: True**

**8. (Sub lesson 2) True or false: At indexes 2i and 2i + 1, with the root at index 1** — as the answer to: For which trees is the array way neat?
**Answer: False — Complete trees — it wastes space on crooked ones**

**9. (Sub lesson 2) True or false: The longest path from the root to a leaf**
**Answer: True**

**10. (Sub lesson 2) True or false: The longest path from the root to a leaf** — as the answer to: Why does height matter?
**Answer: False — It decides how much work a walk down the tree can cost**
