# Flowgorithm practice — input, variables, decisions

## Do it first

Six builds wait, in the book's order: print your name joined to your school's; print three neighbour countries on three lines; add two numbers typed at the keyboard; read your own chart as pseudocode; compute areas; and pay a labourer, taxed. This doing-lesson works them in that order, in three sub lessons. Prove each before the next opens.

## Sub lesson 1 — Strings and output lines

Build 1: output your name and your school's name on one line, joined with the & string connector — observing that no space appears until a space is put at the start of the school's quoted name. Build 2: display the names of three countries neighbouring Ethiopia on three lines using three Output symbols — one instruction in one symbol is a statement. The teacher's key adds: string joining uses deliberate white spaces for readability (its example prints a pupil's name joined to 'Chancho Secondary School'), and variables are introduced through their mathematics meaning — a quantity that may change — with the Variable Watch layout open so pupils see values change as the chart runs (teacher guide — evidence).

## Sub lesson 2 — Input, variables and pseudocode

Build 3: add two numbers from the keyboard. In order: declare the variables first — declaration names where keyboard data will be placed, always before input, and several variables can be declared in one symbol separated by commas; show a 'Please enter two numbers' prompt with an Output symbol before the inputs, because the person must be alerted; then open Layout Windows → Variables & Consoles and use the Step icon to watch each step change the variables and console — the GIF steps exactly this. Build 4: view the chart's pseudocode equivalent through Tools → Source Code Viewer with Auto Pseudocode selected.

[GIF 20951 — stepping through a run while variables change]

## Sub lesson 3 — Areas and the wage decision

Build 5: areas of a circle and a triangle — powers are written with ^, e.g. 6^2, so the circle area for radius 6 is computed as 3.142 * 6^2. Build 6: a wage calculation with a decision — pay over 5,000 birr is taxed at 5% on 50% of the total pay; net pay = total − tax. Keep this wage chart safe: the top-down lesson grows it into wages for ten labourers.

## Say it to your companion

Tell your companion, in your own words: Flowgorithm practice builds: joined strings with &, outputs on separate lines, declared variables receiving keyboard input, the pseudocode viewer, areas with ^ — and a wage decision with tax. Then name the key words of this lesson — declaring variables, the & operator, powers in Flowgorithm, the wage tax rule — and say what each one means.
