# Getting Started with Small Basic — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is Small Basic?" is: Microsoft's small teaching language for beginners**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Why is the language kept small?" is: The code area and the Run toolbar, with help on every word (any two)**

**Answer: True**

**Answer: False** — TextWindow

**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is the .sb file?" is: The runnable program built from the source**

**7. (Sub lesson 2) True or false: the answer to "What is the .exe file?" is: The runnable program built from the source**
