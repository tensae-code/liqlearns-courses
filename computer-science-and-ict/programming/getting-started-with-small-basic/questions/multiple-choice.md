# Getting Started with Small Basic — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is Small Basic?**
a) Microsoft's small teaching language for beginners  b) So the beginner meets programming itself before a professional language's bulk  c) The code area and the Run toolbar, with help on every word (any two)  d) TextWindow
**Answer: a) Microsoft's small teaching language for beginners**

**2. (Sub lesson 1) Why is the language kept small?**
a) The code area and the Run toolbar, with help on every word (any two)  b) So the beginner meets programming itself before a professional language's bulk  c) TextWindow  d) Writes a greeting in the TextWindow
**Answer: b) So the beginner meets programming itself before a professional language's bulk**

**3. (Sub lesson 1) What two things fill its working environment's window?**
a) TextWindow  b) Writes a greeting in the TextWindow  c) The code area and the Run toolbar, with help on every word (any two)  d) The source text the pupil writes and can change
