# Getting Started with Small Basic — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is Small Basic?**
**Answer: Microsoft's small teaching language for beginners**

**2. (Sub lesson 1) Why is the language kept small?**
**Answer: So the beginner meets programming itself before a professional language's bulk**

**3. (Sub lesson 1) What two things fill its working environment's window?**
**Answer: The code area and the Run toolbar, with help on every word (any two)**

**4. (Sub lesson 1) Which object handles text?**
**Answer: TextWindow**

**5. (Sub lesson 1) What does the first program do?**
**Answer: Writes a greeting in the TextWindow**

**6. (Sub lesson 2) What is the .sb file?**
**Answer: The source text the pupil writes and can change**

**7. (Sub lesson 2) What is the .exe file?**
**Answer: The runnable program built from the source**

**8. (Sub lesson 2) What pair do the two files form?**
**Answer: The source/program pair every later language repeats**

**9. (Sub lesson 2) Name two other objects the language offers from the start.**
**Answer: GraphicsWindow and the Turtle (any two of: TextWindow)**

**10. (Sub lesson 2) Which country teaches programming in Small Basic at Grade 11?**
**Answer: Mongolia**
