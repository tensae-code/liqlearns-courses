## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The working environment** — **Small Basic** is Microsoft's teaching language: few keywords, a friendly editor with help on every word, and programs that can show text, draw graphics and move a turtle from the first day. Its **working environment** is one window — the code area where the program is written, the toolbar with Run, and the help that explains each command as it is typed. The language's elements are objects with operations — TextWindow for text, GraphicsWindow for pictures — met one by one in the chapters that follow.
2. **The first program — and its two files** — The first program is the traditional beginning, in the **TextWindow**: a line that writes a greeting on the console and ends. Run it and the text appears — the pupil's first proof that written symbols command the machine. The work is kept in two files: the **.sb file**, the source text the pupil writes and can change, and the **.exe file**, the runnable program Small Basic builds from it — the source/program pair every later language will repeat, met here in its smallest form.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
