# Hands-on — Reading Your Blocks as Python in the Code Viewer

The lesson with your hands and your feet, not only your eyes.

## Read your own code
Build a small block project with one counted loop, open the Code Viewer, and find the for loop and its range(). Point to the line each block became.

## Change the text's number in your head
Look at one block's parameter in the Python text. Say what would change in the program if that number changed — then change the block and check the Viewer agrees.
