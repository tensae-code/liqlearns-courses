# Video script — Reading Your Blocks as Python in the Code Viewer

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

The **Code Viewer** displays the **project as Python**: the blocks you stacked are translated, line by line, into text code. Nothing new is added — it is your program, written the other way. Reading the two forms side by side is the bridge from block programming to text programming.
In the text, each block's settings appear as **Python parameters** — the numbers and choices you picked in the block, written inside the code line. A counted repeat becomes a **for loop with range()**: range gives the count of turns. A condition loop becomes a **while loop** in text — the same condition, guarding the same lines, in Python's spelling.
