# Reading Your Blocks as Python in the Code Viewer — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does the Code Viewer show?**
**Answer: Your block project as Python text**

**2. (Sub lesson 1) How are blocks translated?**
**Answer: Line by line into text code**

**3. (Sub lesson 1) Is anything new added in the Viewer?**
**Answer: No — it is your program, written the other way**

**4. (Sub lesson 1) What is the side-by-side reading a bridge between?**
**Answer: Block programming and text programming**

**5. (Sub lesson 1) Where do a block's settings appear in the text?**
**Answer: As Python parameters inside the code line**

**6. (Sub lesson 2) What does a counted repeat become in Python?**
**Answer: A for loop with range()**

**7. (Sub lesson 2) What does range() give the for loop?**
**Answer: The count of turns**

**8. (Sub lesson 2) What does a condition loop become in text?**
**Answer: A while loop**

**9. (Sub lesson 2) What guards the while loop's lines?**
**Answer: The same condition as the block loop**

**10. (Sub lesson 2) In whose spelling is the text written?**
**Answer: Python's**
