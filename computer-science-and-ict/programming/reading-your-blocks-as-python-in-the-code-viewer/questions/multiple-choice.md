# Reading Your Blocks as Python in the Code Viewer — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does the Code Viewer show?**
a) Your block project as Python text  b) Block programming and text programming  c) A for loop with range()  d) A while loop
**Answer: a) Your block project as Python text**

**2. (Sub lesson 1) How are blocks translated?**
a) As Python parameters inside the code line  b) Line by line into text code  c) The count of turns  d) The same condition as the block loop
