# First Scratch script — move 10 steps and say hello — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is the event block?
a) the Motion block attached under the event block — each click moves the cat 10 more steps right  b) the palette where the speech block is found, dragged in so the sprite says hello  c) clicked on the window or the script, it runs the script  d) 'when flag clicked' from Events — dragged into the script area to start the script
**Answer: d) 'when flag clicked' from Events — dragged into the script area to start the script**

**2. (Sub lesson 1)** Which of these describes the green flag?
a) the Motion block attached under the event block — each click moves the cat 10 more steps right  b) the palette where the speech block is found, dragged in so the sprite says hello  c) clicked on the window or the script, it runs the script  d) 'when flag clicked' from Events — dragged into the script area to start the script
**Answer: c) clicked on the window or the script, it runs the script**

**3. (Sub lesson 2)** What is move 10 steps?
a) the palette where the speech block is found, dragged in so the sprite says hello  b) clicked on the window or the script, it runs the script  c) the Motion block attached under the event block — each click moves the cat 10 more steps right  d) 'when flag clicked' from Events — dragged into the script area to start the script

**4. (Sub lesson 2)** Which of these describes attaching?
a) the palette where the speech block is found, dragged in so the sprite says hello  b) blocks join under the block above them, building the script in order  c) 'when flag clicked' from Events — dragged into the script area to start the script  d) the Motion block attached under the event block — each click moves the cat 10 more steps right

a) the speech added to the moving script — the sprite moves and speaks  b) 'when flag clicked' from Events — dragged into the script area to start the script  c) the Motion block attached under the event block — each click moves the cat 10 more steps right  d) the palette where the speech block is found, dragged in so the sprite says hello

**7. (Sub lesson 3)** A script with no event block —
a) runs twice as fast  b) has no starter: nothing tells it when to begin  c) moves left  d) cannot hold blocks
