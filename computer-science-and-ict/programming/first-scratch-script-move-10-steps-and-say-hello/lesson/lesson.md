# First Scratch script — move 10 steps and say hello

## Do it first

The cat stands still. One click on a green flag must move it 10 steps right — and one more block must make it speak. This doing-lesson builds the script in the book's exact order: event first, motion second, speech last. Prove each sub lesson before the next opens. Watch the GIF: flag, steps, hello.

## Sub lesson 1 — The event block

To move the sprite 10 steps each time the green flag is clicked, the script begins: from Events, drag the 'when flag clicked' block into the script area. Every script needs its starter — this is Scratch's.

[Picture 20938 — First Scratch script — two blocks, a cat mid-stage]

## Sub lesson 2 — The move block

From Motion, drag 'move 10 steps' and attach it under the event block. Clicking the flag on the window or the script then moves the cat 10 steps to the right — each click another 10.

[GIF 20952 — the flag click, the cat stepping right and speaking]

## Sub lesson 3 — Adding speech

Adding speech: find the right block in the Looks palette and drag it into the script, so the sprite also says hello. Two palettes visited, three blocks placed, one running script — movement and speech together.
