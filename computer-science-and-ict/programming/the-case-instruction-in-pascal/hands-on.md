# Hands-on — The Case Instruction in Pascal

The lesson with your hands and your feet, not only your eyes.

## Task one
**Grade words** — Write a case that prints the word for a mark 1–5, with else for an invalid mark; then write the if-chain version and compare.

## Task two
**Month days** — Write a case on month number giving the month's days, using range and list labels (30-day months, 31-day months, February apart).
