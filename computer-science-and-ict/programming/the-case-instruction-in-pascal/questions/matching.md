# The Case Instruction in Pascal — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What begins a case instruction?** → **A selector — an expression of ordinal type**

**2. (Sub lesson 1) How many times is the selector evaluated?** → **Once**

**3. (Sub lesson 1) What does the else part do?** → **It catches every unlisted value**

**4. (Sub lesson 1) Name the three forms of labels.** → **Single values, lists (1, 3, 5:) and ranges (1..5:)**

**5. (Sub lesson 1) What happens with no else and an unlisted value?** → **Case does nothing and passes on**

**6. (Sub lesson 2) What does an if-chain test?** → **Conditions, one by one, each possibly different**

**7. (Sub lesson 2) What does case test?** → **One value against a set of labels**

**8. (Sub lesson 2) What is C++'s version of case called?** → **switch**

**9. (Sub lesson 2) What is switch's classic trap?** → **Forgetting break — execution falls through into the next branch**

**10. (Sub lesson 2) When is case the right chooser?** → **When one value chooses among labelled roads**
