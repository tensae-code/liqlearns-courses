Say true or false, and fix the false ones in your own words.

**Answer: True**

**2. (Sub lesson 1) True or false: A selector — an expression of ordinal type** — as the answer to: How many times is the selector evaluated?

**Answer: True**

**5. (Sub lesson 1) True or false: Case does nothing and passes on**
**Answer: True**

**6. (Sub lesson 2) True or false: Case does nothing and passes on** — as the answer to: What does an if-chain test?

**8. (Sub lesson 2) True or false: One value against a set of labels** — as the answer to: What is C++'s version of case called?
