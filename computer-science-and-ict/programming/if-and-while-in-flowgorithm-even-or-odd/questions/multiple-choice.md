# If and while in Flowgorithm — even or odd — multiple choice

Pick the one right answer.

**1.** What is the modulo operator %?
a) the operator giving the remainder of an integer division — 14 % 3 is 2  b) number % 2 = 0 — remainder 0 means the number is even  c) making a variable hold a value — num is assigned 2 to start the while chart  d) a loop that tests its condition and repeats while it holds — here num < 10, exiting when the test becomes FALSE
**Answer: a) the operator giving the remainder of an integer division — 14 % 3 is 2**

**2.** What is the even test?
a) the operator giving the remainder of an integer division — 14 % 3 is 2  b) making a variable hold a value — num is assigned 2 to start the while chart  c) a loop that tests its condition and repeats while it holds — here num < 10, exiting when the test becomes FALSE  d) number % 2 = 0 — remainder 0 means the number is even
**Answer: d) number % 2 = 0 — remainder 0 means the number is even**

**3.** What is assignment?
a) number % 2 = 0 — remainder 0 means the number is even  b) a loop that tests its condition and repeats while it holds — here num < 10, exiting when the test becomes FALSE  c) making a variable hold a value — num is assigned 2 to start the while chart  d) the operator giving the remainder of an integer division — 14 % 3 is 2
**Answer: c) making a variable hold a value — num is assigned 2 to start the while chart**

**4.** What is a while loop?
a) making a variable hold a value — num is assigned 2 to start the while chart  b) a loop that tests its condition and repeats while it holds — here num < 10, exiting when the test becomes FALSE  c) the operator giving the remainder of an integer division — 14 % 3 is 2  d) number % 2 = 0 — remainder 0 means the number is even
**Answer: b) a loop that tests its condition and repeats while it holds — here num < 10, exiting when the test becomes FALSE**

**5.** 17 % 5 is —
a) 3  b) 2  c) 5  d) 0
**Answer: b) 2** — 17 = 3x5 + 2.

**6.** The even/odd job uses a decision rather than a loop because —
a) loops are forbidden  b) one number needs one question and one fork — nothing repeats  c) Flowgorithm has no loops  d) the number is small
**Answer: b) one number needs one question and one fork — nothing repeats**
