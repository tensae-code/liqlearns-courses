# If and while in Flowgorithm — even or odd — fill

Fill each blank with the right word or words.

**1.** _____ is number % 2 = 0 — remainder 0 means the number is even. (Name the term.)
**Answer: the even test**

**2.** _____ is making a variable hold a value — num is assigned 2 to start the while chart. (Name the term.)
**Answer: assignment**

**3.** _____ is a loop that tests its condition and repeats while it holds — here num < 10, exiting when the test becomes FALSE. (Name the term.)
**Answer: a while loop**
