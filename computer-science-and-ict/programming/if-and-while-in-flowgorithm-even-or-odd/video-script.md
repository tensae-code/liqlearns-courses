This is **If and while in Flowgorithm — even or odd**.

**the modulo operator %** — the operator giving the remainder of an integer division — 14 % 3 is 2.

**the even test** — number % 2 = 0 — remainder 0 means the number is even.

**assignment** — making a variable hold a value — num is assigned 2 to start the while chart.

**a while loop** — a loop that tests its condition and repeats while it holds — here num < 10, exiting when the test becomes FALSE.
