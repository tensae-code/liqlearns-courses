# Drawing Figures with Pascal Graphics — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Which operator lights one point?" is: PutPixel**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does Line take?" is: By centre and radius**
**Answer: False** — Two points — the segment's ends

**3. (Sub lesson 1) True or false: the answer to "How is a circle described to Circle?" is: By centre and radius**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does SetColor do?" is: By changing the numbers — coordinates and sizes**
**Answer: False** — Chooses the drawing colour

**5. (Sub lesson 1) True or false: the answer to "How is a drawn figure changed?" is: By changing the numbers — coordinates and sizes**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is a house, in graphics operators?" is: A repetition lesson**

**7. (Sub lesson 2) True or false: the answer to "What closes this lesson in the book?" is: A repetition lesson**
**Answer: True**

**9. (Sub lesson 2) True or false: the answer to "In what order should a picture be composed?" is: Big figures first, then the small ones**
