## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The drawing operators** — In the Graph unit, **PutPixel** lights one point, **Line** draws a segment between two points, **Rectangle** draws a box by its corners, **Circle** draws a circle by centre and radius, and **SetColor** chooses the drawing colour. Each operator takes numbers — coordinates and sizes — so the picture is computed, not dragged: change a number and the figure obeys.
2. **Composing a picture from figures** — Figures compose: a house is a rectangle, a triangle roof and a circle sun; a flag is rectangles in colours. The book closes the lesson with a repetition, because the graphics operators are the Pascal course's reward — the pupil who has done values, branches and loops now makes the screen show them. Draw big first, then add the small figures.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
