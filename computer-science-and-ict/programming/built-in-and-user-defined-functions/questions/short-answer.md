# Built-In and User-Defined Functions in Visual Basic — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) Name the two families of functions in this lesson.**
**Answer: Built-in (ready-made) functions and user-defined (functional) functions**

**2. (Sub lesson 1) What is a built-in function?**
**Answer: A function ready-made in Visual Basic itself — called by name with a value, returning a result**

**3. (Sub lesson 1) Name the built-in groups the book teaches.**
**Answer: Maths functions, string functions, and date and time functions**

**4. (Sub lesson 1) What shape is every built-in function called with?**
**Answer: A reserved name, values in brackets, one result out**

**5. (Sub lesson 1) What is a user-defined function?**
**Answer: A function the programmer writes — a named block that takes values in and returns one value**

**6. (Sub lesson 2) How does a function differ from a subroutine?**
**Answer: A function returns a value to its caller; a subroutine does a job without returning one**

**7. (Sub lesson 2) When do you write your own function?**
**Answer: When the same working-out is needed in many places, or a calculation deserves its own name (either)**

**8. (Sub lesson 2) When do you use a built-in instead?**
**Answer: When one already exists for the work**

**9. (Sub lesson 2) For every function you call, what should you know?**
**Answer: Which family it came from — built-in or your own**

**10. (Sub lesson 2) Which book and chapter teach both families together?**
**Answer: Libya's Grade 12 IT Science book, Chapter 6 — sub-programs and functions**
