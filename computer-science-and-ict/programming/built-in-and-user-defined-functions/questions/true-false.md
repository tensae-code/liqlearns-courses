# Built-In and User-Defined Functions in Visual Basic — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Name the two families of functions in this lesson." is: Built-in (ready-made) functions and user-defined (functional) functions**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is a built-in function?" is: Maths functions, string functions, and date and time functions**
**Answer: False** — A function ready-made in Visual Basic itself — called by name with a value, returning a result

**3. (Sub lesson 1) True or false: the answer to "Name the built-in groups the book teaches." is: Maths functions, string functions, and date and time functions**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What shape is every built-in function called with?" is: A function the programmer writes — a named block that takes values in and returns one value**
**Answer: False** — A reserved name, values in brackets, one result out

**5. (Sub lesson 1) True or false: the answer to "What is a user-defined function?" is: A function the programmer writes — a named block that takes values in and returns one value**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How does a function differ from a subroutine?" is: When the same working-out is needed in many places, or a calculation deserves its own name (either)**
**Answer: False** — A function returns a value to its caller; a subroutine does a job without returning one

**7. (Sub lesson 2) True or false: the answer to "When do you write your own function?" is: When the same working-out is needed in many places, or a calculation deserves its own name (either)**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "When do you use a built-in instead?" is: Which family it came from — built-in or your own**
**Answer: False** — When one already exists for the work

**9. (Sub lesson 2) True or false: the answer to "For every function you call, what should you know?" is: Which family it came from — built-in or your own**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Which book and chapter teach both families together?" is: Built-in (ready-made) functions and user-defined (functional) functions**
**Answer: False** — Libya's Grade 12 IT Science book, Chapter 6 — sub-programs and functions
