## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Built-in functions — the ready-made toolbox** — **Built-in functions** are **ready-made**: written into Visual Basic itself, called by name with a value, returning a result. The book groups them by their work: **maths functions** that work on numbers, **string functions and statements** that work on text, and **date and time functions** that work on dates and times. A built-in function is recognised by its shape in every family: a reserved name, values in brackets, one result out — the programmer supplies the value, never the method.
2. **User-defined (functional) functions — functions you write** — A **functional (user-defined) function** is a function the **programmer writes**: a named block that takes values in, works, and **returns one value** to its caller — the function counterpart of the chapter's **subroutines**, which do a job without returning a value. Write a function when the same working-out is needed in many places, or when a calculation deserves a name of its own. The chapter's teaching order is the judgement: use a built-in when one exists; write your own when none does; and know, for every function you call, which family it came from.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
