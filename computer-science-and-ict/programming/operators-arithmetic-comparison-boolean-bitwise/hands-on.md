# Hands-on — Operators — Arithmetic, Comparison, Boolean, Bitwise

The lesson with your hands and your feet, not only your eyes.

## Task one
**Family sort** — Write twelve expressions using +, %, ==, !=, &&, ||, !, &, |, <<. Label each with its family and say in words what it computes or asks.

## Task two
**Fault clinic** — A sketch uses = inside an if test, % where / was meant, and & where && was intended. Explain each fault's effect and write the corrected lines.
