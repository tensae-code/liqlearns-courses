# Hands-on — Subrange Data Types in Pascal

The lesson with your hands and your feet, not only your eyes.

## Task one
**Slice design** — Define subranges for: exam marks, month numbers, lowercase letters, and playing-card ranks from an enumeration — stating host type and borders for each.

## Task two
**Guard story** — Write the calendar-corruption story in five lines: where 32 entered, where it exploded, and where the subrange would have stopped it.
