This lesson: **Bugs and debugging — turning on [DEBUG ON]**.

First, do it. Run the opening program. Watch what it prints.

Then the idea, in order: After writing and saving, run the program; a bug is an unexpected problem, and some bugs cannot be caught by reading the code. From the IDLE menu bar: Debug → Debugger; [DEBUG ON] appears before the prompt; running the file opens the debugger window. Testing is quality assurance.

Now you. Open IDLE, choose Debug → Debugger, and screenshot or copy the [DEBUG ON] prompt line.

Say it to your companion: Tell your companion why testing must come before debugging, what a bug is, and the exact menu path that turns [DEBUG ON].
