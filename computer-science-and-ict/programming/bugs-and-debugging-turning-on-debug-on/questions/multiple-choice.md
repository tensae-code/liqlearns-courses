# Bugs and debugging — turning on [DEBUG ON] — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A bug is —
a) an unexpected problem in a program  b) a slow computer  c) a kind of loop
**Answer: a) a) an unexpected problem in a program** — A bug is any undesirable situation in a program, syntax or semantics — review-keyed.

**2. (Sub lesson 1)** Some bugs cannot be caught by —
a) running  b) reading the code  c) testing
**Answer: b) b) reading the code** — That is why we run and debug.

**3. (Sub lesson 2)** The debugger is turned on from —
a) Format → Debugger  b) Debug → Debugger  c) Run → Debugger
**Answer: b) b) Debug → Debugger**

**4. (Sub lesson 2)** When the debugger is on, the prompt is preceded by —
a) [RUN]  b) [DEBUG ON]  c) [TEST]
**Answer: b) b) [DEBUG ON]**

**5. (Sub lesson 2)** Running the file with the debugger on opens —
a) the debugger window  b) a browser  c) nothing new
**Answer: a) a) the debugger window**

**6. (Sub lesson 1)** Debugging means having — over execution
a) no control  b) complete control  c) remote control
**Answer: b) b) complete control**
