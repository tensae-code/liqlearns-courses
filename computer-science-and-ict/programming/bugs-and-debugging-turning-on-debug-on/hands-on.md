# Hands-on — Bugs and debugging — turning on [DEBUG ON]

The lesson with your hands, not only your eyes — every activity is done for real, in IDLE or on paper.

## Debugger on
In IDLE: Debug → Debugger. Write down exactly what changes at the prompt. Run a saved one-line file and name every window now open.

## Bug log
Keep a bug log page: for one crashing program, record the program, what you expected, what actually happened, and the line you suspect. That log is the debugger's starting point.
