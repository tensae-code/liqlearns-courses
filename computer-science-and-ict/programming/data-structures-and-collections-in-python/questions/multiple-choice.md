# Data Structures and Collections in Python — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Name Python's four built-in collections in this lesson**
a) List, tuple, set and dictionary  b) Ordered and changeable  c) Ordered but fixed once made — for things that must not drift, like coordinates  d) Each value held once, unordered — for membership questions
**Answer: a) List, tuple, set and dictionary**

**2. (Sub lesson 1) What is a list?**
a) Ordered but fixed once made — for things that must not drift, like coordinates  b) Ordered and changeable  c) Each value held once, unordered — for membership questions  d) Key–value pairs, found by name (key), not position
**Answer: b) Ordered and changeable**

**3. (Sub lesson 1) What is a tuple, and what is it for?**
a) Each value held once, unordered — for membership questions  b) Key–value pairs, found by name (key), not position  c) Ordered but fixed once made — for things that must not drift, like coordinates  d) A list
**Answer: c) Ordered but fixed once made — for things that must not drift, like coordinates**

**4. (Sub lesson 1) What does a set guarantee?**
a) Key–value pairs, found by name (key), not position  b) A list  c) A set — its membership test is its whole point  d) Each value held once, unordered — for membership questions
**Answer: d) Each value held once, unordered — for membership questions**

**5. (Sub lesson 1) What does a dictionary hold, and how is data found in it?**
a) Key–value pairs, found by name (key), not position  b) A list  c) A set — its membership test is its whole point  d) Counting with len, looping over members, testing with in (any two)
**Answer: a) Key–value pairs, found by name (key), not position**

**6. (Sub lesson 2) Which collection answers 'the marks in order, changeable'?**
a) A set — its membership test is its whole point  b) A list  c) Counting with len, looping over members, testing with in (any two)  d) Order, uniqueness, fixity, or naming

**7. (Sub lesson 2) Which answers 'has this name already been entered?'**
