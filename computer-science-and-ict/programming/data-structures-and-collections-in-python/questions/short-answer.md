# Data Structures and Collections in Python — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) Name Python's four built-in collections in this lesson**
**Answer: List, tuple, set and dictionary**

**2. (Sub lesson 1) What is a list?**
**Answer: Ordered and changeable**

**3. (Sub lesson 1) What is a tuple, and what is it for?**
**Answer: Ordered but fixed once made — for things that must not drift, like coordinates**

**4. (Sub lesson 1) What does a set guarantee?**
**Answer: Each value held once, unordered — for membership questions**

**5. (Sub lesson 1) What does a dictionary hold, and how is data found in it?**
**Answer: Key–value pairs, found by name (key), not position**

**6. (Sub lesson 2) Which collection answers 'the marks in order, changeable'?**
**Answer: A list**

**7. (Sub lesson 2) Which answers 'has this name already been entered?'**
**Answer: A set — its membership test is its whole point**

**8. (Sub lesson 2) Name two operations that rhyme across all four**
**Answer: Counting with len, looping over members, testing with in (any two)**

**9. (Sub lesson 2) What does each collection differently guarantee?**
**Answer: Order, uniqueness, fixity, or naming**

**10. (Sub lesson 2) In which grade does Egypt teach Python collections?**
**Answer: Grade 8 — Term 2, a year before most courses allow them**
