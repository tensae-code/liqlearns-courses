**1. (Sub lesson 1) True or false: the answer to "Name Python's four built-in collections in this lesson?" is: List, tuple, set and dictionary**
**Answer: True**

**3. (Sub lesson 1) True or false: the answer to "What is a tuple, and what is it for?" is: Ordered but fixed once made — for things that must not drift, like coordinates**

**4. (Sub lesson 1) True or false: the answer to "What does a set guarantee?" is: Key–value pairs, found by name (key), not position**
