# Testing Methods and Types — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does black-box testing see?**
a) Inputs and outputs only — the code is unseen; it tests what the program does  b) The code itself — test cases are chosen to walk particular paths, branches and loops  c) An untested inner path  d) A requirement nobody coded — the code can be perfect and the program still wrong
**Answer: a**

**2. (Sub lesson 1) What does white-box testing use?**
a) The code itself — test cases are chosen to walk particular paths, branches and loops  b) An untested inner path  c) A requirement nobody coded — the code can be perfect and the program still wrong  d) They cover each other's blind spots
**Answer: a**

**3. (Sub lesson 1) What can black-box testing miss?**
a) An untested inner path  b) A requirement nobody coded — the code can be perfect and the program still wrong  c) They cover each other's blind spots  d) It re-runs old tests after a change, to catch what the change broke
**Answer: a**
