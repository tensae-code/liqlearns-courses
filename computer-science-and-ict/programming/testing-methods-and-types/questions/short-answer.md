# Testing Methods and Types — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does black-box testing see?**
**Answer: Inputs and outputs only — the code is unseen; it tests what the program does**

**2. (Sub lesson 1) What does white-box testing use?**
**Answer: The code itself — test cases are chosen to walk particular paths, branches and loops**

**3. (Sub lesson 1) What can black-box testing miss?**
**Answer: An untested inner path**

**4. (Sub lesson 1) What can white-box testing miss?**
**Answer: A requirement nobody coded — the code can be perfect and the program still wrong**

**5. (Sub lesson 1) Why use both methods?**
**Answer: They cover each other's blind spots**

**6. (Sub lesson 2) What does regression testing do?**
**Answer: It re-runs old tests after a change, to catch what the change broke**

**7. (Sub lesson 2) Which type checks speed and load?**
**Answer: Performance testing**

**8. (Sub lesson 2) Which type checks people can use the program?**
**Answer: Usability testing**

**9. (Sub lesson 2) Name two more types by aim.**
**Answer: Functional testing and security testing**

**10. (Sub lesson 2) Why is testing called a rhythm, not a final event?**
**Answer: Tests run during building, at joining, before release and after every repair**
