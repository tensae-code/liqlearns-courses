# Hands-on — Testing Methods and Types

The lesson with your hands and your feet, not only your eyes.

## Task one
**Both boxes** — For one small program, write two black-box tests (input/output only) and two white-box tests (one per branch of its condition). Say what each method found that the other could not.

## Task two
**Type the tests** — List six tests for a school program and label each by type (functional, performance, usability, security, regression). Add the moment each should run.
