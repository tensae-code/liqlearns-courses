# Robot Functions — Writing Reusable Robot Code — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a function in the robot program?**
**Answer: A named block of robot code that does one manoeuvre, defined once and called by name**

**2. (Sub lesson 1) Name the book's two example functions.**
**Answer: corner_detection and letterZ**

**3. (Sub lesson 1) What does corner_detection do?**
**Answer: The sensing routine that finds a corner**

**4. (Sub lesson 1) What does a main program of function calls read like?**
**Answer: The mission's plan, not its sweat**

**5. (Sub lesson 1) What project spends the functions?**
**Answer: The Smart Explorer project**

**6. (Sub lesson 2) What manoeuvres does the Explorer repeat?**
**Answer: Advance, sense, turn, mark — at every place it reaches**

**7. (Sub lesson 2) What is the repair gain of functions?**
**Answer: Mend the function once and every call is mended**

**8. (Sub lesson 2) How is a function-built program grown?**
**Answer: By adding calls, not copies**

**9. (Sub lesson 2) Define vs call — which is which?**
**Answer: Define: write the named block once. Call: use its name where needed**

**10. (Sub lesson 2) Which book teaches this?**
**Answer: Kuwait Grade 8 Digital Intelligence Term 1, Unit 3**
