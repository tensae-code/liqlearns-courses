# Lesson plan — Loops in flowcharts — initialise, compute, test, increment

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** Loops in flowcharts — initialise, compute, test, increment
**Place in the curriculum:** Unit 6 — Fundamentals of Programming (CURRICULUM.md).
**The one thing this lesson teaches:** a flowchart loop is built from four parts — initialisation, computation, test and increment — worked in full on summing the first 50 natural numbers, whose decision block sends the flow back round until the counter reaches 50.
**This lesson's own level:** it stands on the flowchart lessons of this title — the learner can draw and read a straight-line flowchart. It needs nothing else.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## What the learner can do when it ends
1. Name the four parts of a loop: initialisation, computation, test, increment.
2. Write the sum-to-50 algorithm in words, in order.
3. Read the looping flowchart: say where the flow goes back, and where it leaves.

## What you need
Paper and a pencil. Nothing else.

## If the learner is stuck
- Draws the loop with no way out → find the test: which block asks the question, and where does its NO arrow go?
- Puts increment before computation → the book's order on this problem: add the counter first, then increase it — the last number added must be 50, not 51.
