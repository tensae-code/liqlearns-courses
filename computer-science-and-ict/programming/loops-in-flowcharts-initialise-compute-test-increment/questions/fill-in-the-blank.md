# Loops in flowcharts — initialise, compute, test, increment — fill in the blank

Fill each blank with the right word.

**1.** Without a ______, a program would loop endlessly.
**Answer: test**

**2.** Setting the variables and exit counter before the loop is ______.
**Answer: initialisation**

**3.** In sum-to-50, the counter increases by ______ each turn.
**Answer: 1 (one)**
