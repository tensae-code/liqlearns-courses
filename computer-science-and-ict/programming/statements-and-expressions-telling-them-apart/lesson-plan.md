# Lesson plan - Statements and expressions - telling them apart

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** Statements and expressions - telling them apart
**Place in the curriculum:** Unit 6 - Fundamentals of Programming (CURRICULUM.md).
**The one thing this lesson teaches:** a statement is an instruction the interpreter executes - an assignment stores silently, a print() statement displays - while an expression is what the interpreter evaluates to a value; in the shell an expression shows its value at once, in the editor it shows nothing unless placed inside print().
**This lesson's own level:** it stands on it stands on Type conversion: the learner now handles values, types and conversions fluently enough to sort whole lines of code into the two kinds. It needs nothing else.

## Sub lessons
The parts of this lesson, in order - the list the learner sees from the start, locked ahead, each opening when the one before it is proved (the gate: README, "Units, Lessons and Sub Lessons (ruled 2026-11-08)"):

1. **Statements - instructions that are executed** - A statement is an instruction the interpreter executes: the assignment statement stores a value and produces no output; the print() statement displays what it is given. Other kinds - if, while, for - are named as Grade 12 material.
2. **Expressions - evaluated to a value** - An expression is what the interpreter evaluates to a value: a literal value, a variable, or a complex combination of literals, variables and operators.
3. **Shell vs editor - where the value shows** - Typed into the shell, an expression shows its value at once; written in the text editor, it shows nothing unless placed inside print().

## What the learner can do when it ends
1. Define a statement and name the two kinds taught here.
2. Define an expression and name its three forms.
3. Predict what a line does in the shell vs in the editor.
4. Sort lines of code into statements and expressions.

## If the learner is stuck
- Calls print(x + 2) an expression because it contains one -> the LINE is a statement (it executes an instruction: display); the expression x + 2 lives inside it. Sort the whole line first.
- Expects a script's bare expression to show -> in the editor nothing shows unless print() carries it; the shell is the only place expressions show themselves.
