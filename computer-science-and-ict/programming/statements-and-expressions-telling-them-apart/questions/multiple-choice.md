# Statements and expressions - telling them apart - multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A statement is -
a) a value  b) an instruction the interpreter executes  c) a data type  d) a keyword list
**Answer: b) an instruction the interpreter executes** - it tells Python to do something.

**2. (Sub lesson 1)** The assignment statement -
a) displays its value  b) stores a value and produces no output  c) evaluates to 5  d) only works in the shell
**Answer: b) stores a value and produces no output** - x = 5 is silent.

**3. (Sub lesson 1)** The print() statement -
a) stores a value  b) displays what it is given  c) defines a type  d) translates the program
**Answer: b) displays what it is given** - print() is the speaking statement.

**4. (Sub lesson 2)** An expression is -
a) an instruction  b) what the interpreter evaluates to a value  c) a menu command  d) a file extension
**Answer: b) what the interpreter evaluates to a value** - an expression is worth a value.

**5. (Sub lesson 2)** Which of these is a complex expression?
a) x = 5  b) print(x)  c) x + 2 - a combination of a variable, an operator and a literal  d) the Run menu
**Answer: c) x + 2 - a combination of a variable, an operator and a literal** - literals, variables and operators combined.

**6. (Sub lesson 2)** A literal value, on its own, is -
a) a statement  b) an expression  c) a keyword  d) an error
**Answer: b) an expression** - 7 and "Selam" are expressions - values themselves.

**7. (Sub lesson 3)** A bare expression typed into the shell -
a) shows nothing  b) shows its value at once  c) is saved as .py  d) raises an error
**Answer: b) shows its value at once** - the shell displays evaluated expressions.

**8. (Sub lesson 3)** The same bare expression written in the text editor -
a) shows its value at once  b) shows nothing unless placed inside print()  c) deletes the script  d) becomes a statement
**Answer: b) shows nothing unless placed inside print()** - in a script, only print() displays.
