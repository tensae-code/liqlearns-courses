## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The stage and its furniture** — The screen's heart is the **stage**: where characters act, on the chosen background, with the **pages** (scenes) of the project beside it. Around it sit the project's furniture: the **character list** (who is in this scene), the **background** chooser, and the buttons that run, present and save. Knowing the stage's geography first means every later instruction — “add a character”, “change the scene” — has a place to land.
2. **Blocks and the script area** — Below the stage lie the **block trays**, sorted by colour and job, and the **script area**, where the selected character's blocks are snapped into scripts. The screen's logic is a sentence: choose **who** (character), choose **what** (blocks), build **where** (script area), watch **on the stage**. The séance's exit test is pure geography: given any element, point to it — a pupil who can find everything can be taught anything on this screen.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## The run of the lesson (in order)
1. **Do it first** — “On trouve sur cet écran…” — “on this screen we find…” Open ScratchJr (or its picture) and let your eyes travel before your fingers do. Name everything you can find. The séance is that naming, made complete. (lesson/lesson.md).
2. **The explanation** — the lesson text in lesson/lesson.md, in its parts in order.
   - ADD IMAGE: a picture of the stage and its furniture as the lesson describes it — the student studies the picture and names what each part shows.
   - ADD GIF: a GIF of blocks and the script area in action — the student watches once, then says what changed and why.
   - ADD AUDIO: a voice reading the lesson's key names and definitions aloud, in the order the lesson gives them — the student listens once through, then reads the same lines aloud along with the voice. (Audio is a described slot in this build; no audio file is made.)
3. **Say it to your companion** — the companion block in lesson/lesson.md.
   - ADD VIDEO: the script in video-script.md, filmed — the lesson in the super-simple voice (made later, when videos are made).
4. **Questions** — from questions/: multiple-choice, true-false, matching, short-answer — served at the learner's level and teaching-mix (levels.md).
5. **Hands-on** — hands-on.md.
6. **Do It Yourself** — the doing block at the end of lesson/lesson.md.
