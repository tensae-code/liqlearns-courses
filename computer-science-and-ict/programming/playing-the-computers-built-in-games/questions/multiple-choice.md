# Playing the Computer's Built-in Games — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What are a computer's built-in games?**
a) Games installed with the system itself, needing no disc or download  b) From the Start menu or the games folder, by name  c) A game is a program the pupil can already run and answer back  d) Card games, puzzle games and board games
**Answer: a) Games installed with the system itself, needing no disc or download**

**2. (Sub lesson 1) How is a built-in game opened?**
a) A game is a program the pupil can already run and answer back  b) From the Start menu or the games folder, by name  c) Card games, puzzle games and board games  d) It answers every move you make
**Answer: b) From the Start menu or the games folder, by name**

**3. (Sub lesson 1) Why does Class IV meet games before Scratch?**
a) Card games, puzzle games and board games  b) It answers every move you make  c) A game is a program the pupil can already run and answer back  d) In the game's rules or help shown on the screen
**Answer: c) A game is a program the pupil can already run and answer back**

**4. (Sub lesson 1) What kinds of built-in games are common?**
a) It answers every move you make  b) In the game's rules or help shown on the screen  c) The score, or reaching the finish  d) Card games, puzzle games and board games
**Answer: d) Card games, puzzle games and board games**

**5. (Sub lesson 1) What does the program do when you play?**
a) It answers every move you make  b) In the game's rules or help shown on the screen  c) The score, or reaching the finish  d) Exact mouse and keyboard control, reading instructions and planning moves
