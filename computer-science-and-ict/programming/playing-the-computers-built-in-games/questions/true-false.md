# Playing the Computer's Built-in Games — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What are a computer's built-in games?" is: Games installed with the system itself, needing no disc or download**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How is a built-in game opened?" is: It answers every move you make**
**Answer: False** — From the Start menu or the games folder, by name

**3. (Sub lesson 1) True or false: the answer to "Why does Class IV meet games before Scratch?" is: A game is a program the pupil can already run and answer back**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What kinds of built-in games are common?" is: The score, or reaching the finish**
**Answer: False** — Card games, puzzle games and board games

**5. (Sub lesson 1) True or false: the answer to "What does the program do when you play?" is: It answers every move you make**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Where can a player read how a game works?" is: Sit well, rest your eyes and stop at the agreed time**
**Answer: False** — In the game's rules or help shown on the screen

**7. (Sub lesson 2) True or false: the answer to "What tells the player how they did?" is: The score, or reaching the finish**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What real skills does playing practise?" is: Games installed with the system itself, needing no disc or download**
**Answer: False** — Exact mouse and keyboard control, reading instructions and planning moves

**9. (Sub lesson 2) True or false: the answer to "What care rules hold while playing?" is: Sit well, rest your eyes and stop at the agreed time**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "How long should a game be played for?" is: A game is a program the pupil can already run and answer back**
**Answer: False** — For a set time agreed before starting
