# Drawing Maze Levels as Backdrops — One Wall Colour — true or false

Say whether each statement is true or false.

**1. Each level's backdrop should be named for its level.**
**Answer: True** — Named levels (Maze 1, Maze 2) keep scripts and readers clear.

**2. Floors and the goal should also use the wall colour to be safe.**
**Answer: False** — Then the touching test would fire everywhere; only walls use that colour.

**3. Level 2 should be a little harder than level 1.**
**Answer: True** — The book's first two mazes rise in difficulty.
