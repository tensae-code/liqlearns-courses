# Drawing Maze Levels as Backdrops — One Wall Colour — multiple choice

Pick the one right answer.

**1. A maze level in Scratch is drawn as a —**
a) Sprite  b) Backdrop  c) Sound
**Answer: b) Backdrop** — One maze per backdrop.

**2. The walls must use —**
a) Many colours  b) One single colour  c) No colour
**Answer: b) One single colour** — One colour, so one test feels every wall.

**3. The one-colour rule exists so the game can test —**
a) Touching that colour  b) The time of day  c) The player's name
**Answer: a) Touching that colour** — Touching-the-wall-colour is the game's sense of touch.

**4. A wall painted in a second colour would —**
a) Be stronger  b) Not be felt by the touching test  c) Win the game
**Answer: b) Not be felt by the touching test** — An unfelt wall is a wall players walk through.
