# Frequently Used Logical Functions — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: NOT-AND — 0 only when both inputs are 1**
**Answer: True**

**2. (Sub lesson 1) True or false: NOT-AND — 0 only when both inputs are 1** — as the answer to: What is NOR?
**Answer: False — NOT-OR — 1 only when both inputs are 0**

**3. (Sub lesson 1) True or false: Each alone can build NOT, AND and OR — whole circuits from one gate kind**
**Answer: True**

**4. (Sub lesson 1) True or false: Each alone can build NOT, AND and OR — whole circuits from one gate kind** — as the answer to: How is NAND's truth table written?
**Answer: False — Take AND's table and flip every output**

**5. (Sub lesson 1) True or false: One universal gate kind simplifies manufacture**
**Answer: True**

**6. (Sub lesson 2) True or false: One universal gate kind simplifies manufacture** — as the answer to: When does XOR give 1?
**Answer: False — When the inputs differ**

**7. (Sub lesson 2) True or false: XOR negated — 1 when the inputs agree**
**Answer: True**

**8. (Sub lesson 2) True or false: XOR negated — 1 when the inputs agree** — as the answer to: Where does XOR work inside arithmetic?
**Answer: False — As the sum bit of an adder (carry aside)**

**9. (Sub lesson 2) True or false: Testing equality of bits**
**Answer: True**

**10. (Sub lesson 2) True or false: Testing equality of bits** — as the answer to: How is any of the four proved?
**Answer: False — By its four-row truth table**
