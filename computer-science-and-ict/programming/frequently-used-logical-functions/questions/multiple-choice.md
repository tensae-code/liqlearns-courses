# Frequently Used Logical Functions — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is NAND?**
a) NOT-AND — 0 only when both inputs are 1  b) NOT-OR — 1 only when both inputs are 0  c) Each alone can build NOT, AND and OR — whole circuits from one gate kind  d) Take AND's table and flip every output
**Answer: a**

**2. (Sub lesson 1) What is NOR?**
a) NOT-OR — 1 only when both inputs are 0  b) Each alone can build NOT, AND and OR — whole circuits from one gate kind  c) Take AND's table and flip every output  d) One universal gate kind simplifies manufacture
**Answer: a**

**3. (Sub lesson 1) What does 'universal' mean for NAND and NOR?**
a) Each alone can build NOT, AND and OR — whole circuits from one gate kind  b) Take AND's table and flip every output  c) One universal gate kind simplifies manufacture  d) When the inputs differ
**Answer: a**

**4. (Sub lesson 1) How is NAND's truth table written?**
a) Take AND's table and flip every output  b) One universal gate kind simplifies manufacture  c) When the inputs differ  d) XOR negated — 1 when the inputs agree

**5. (Sub lesson 1) Why are real chips often NAND chips?**
