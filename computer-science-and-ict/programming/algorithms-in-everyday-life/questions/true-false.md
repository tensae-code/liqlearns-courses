# Algorithms in Everyday Life — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A clear, ordered set of steps that finishes a task**
**Answer: True**

**2. (Sub lesson 1) True or false: A clear, ordered set of steps that finishes a task** — as the answer to: Why is a recipe an algorithm?
**Answer: False — It gives ordered steps that finish a task — making the dish**

**3. (Sub lesson 1) True or false: Socks before shoes — some steps only work in their order**
**Answer: True**

**4. (Sub lesson 1) True or false: Socks before shoes — some steps only work in their order** — as the answer to: Does an algorithm need a computer?
**Answer: False — No — people follow and invent algorithms every day**

**5. (Sub lesson 1) True or false: Right after the concept of an algorithm (§19, after §18)**
**Answer: True**

**6. (Sub lesson 2) True or false: Right after the concept of an algorithm (§19, after §18)** — as the answer to: What makes an everyday algorithm followable?
**Answer: False — Each step is one clear action, in working order, that another person can follow without asking questions**

**7. (Sub lesson 2) True or false: End — it must not loop forever**
**Answer: True**

**8. (Sub lesson 2) True or false: End — it must not loop forever** — as the answer to: How do you test an everyday algorithm?
**Answer: False — Follow it literally, exactly as written, and find the step where the follower gets stuck**

**9. (Sub lesson 2) True or false: The condition that ends a repeated step — for example 'stir until the sugar has dissolved'**
**Answer: True**

**10. (Sub lesson 2) True or false: The condition that ends a repeated step — for example 'stir until the sugar has dissolved'** — as the answer to: What do you fix when a follower gets stuck?
**Answer: False — The unclear or missing step — not the follower**
