## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Everyday steps — where algorithms already live** — An **algorithm** is a clear, ordered set of steps that finishes a task. A **recipe** is an algorithm for cooking; a **route** to school is an algorithm for travelling; getting dressed in the right order (socks before shoes) is an algorithm too. Armenia's Grade 5 book teaches 'Algorithms in everyday life' as its own lesson (§19) right after the concept of an algorithm: the point is that the steps were always there — the lesson names them.
2. **Writing an everyday algorithm well — clear, ordered, finished** — An everyday algorithm is good when another person can follow it **without asking questions**: each step is one clear action, the steps are in working order, and the algorithm **ends** — it does not loop forever (stir the tea, taste, add sugar, taste… needs a stopping rule). Testing an everyday algorithm means following it literally, exactly as written, and fixing the step where the literal follower gets stuck.
