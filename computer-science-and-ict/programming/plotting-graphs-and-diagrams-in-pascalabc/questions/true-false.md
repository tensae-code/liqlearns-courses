# Plotting Graphs and Diagrams in PascalABC — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does the program draw first for a graph?" is: The axes, with a chosen scale.**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is a scale here?" is: Honesty to the numbers — stated axes and scales, even steps, proportional heights.**
**Answer: False** — How many window points stand for one unit.

**3. (Sub lesson 1) True or false: the answer to "How is a curve produced?" is: By calculating y for step-by-step x values, marking each point, and joining the points.**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is a diagram?" is: Window coordinates for the point to be marked.**
**Answer: False** — A picture showing amounts — bars or sectors sized by their values.

**5. (Sub lesson 1) True or false: the answer to "What must be the same across a whole diagram?" is: The scale.**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is the shared discipline of graphs and diagrams?" is: The function and its values — the programmer answers for it.**
**Answer: False** — Honesty to the numbers — stated axes and scales, even steps, proportional heights.

**7. (Sub lesson 2) True or false: the answer to "Why does honesty matter so much in a plotted picture?" is: A picture persuades faster than a table, so a wrong scale persuades wrongly.**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What two things does the program turn a value pair into?" is: How many window points stand for one unit.**
**Answer: False** — Window coordinates for the point to be marked.

**9. (Sub lesson 2) True or false: the answer to "Can the same program plot with another scale?" is: Yes — change the scale and re-run.**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is a graph's picture a claim about?" is: A picture showing amounts — bars or sectors sized by their values.**
**Answer: False** — The function and its values — the programmer answers for it.
