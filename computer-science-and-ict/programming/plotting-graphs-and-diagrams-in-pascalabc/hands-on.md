# Hands-on — Plotting Graphs and Diagrams in PascalABC

The lesson with your hands and your feet, not only your eyes.

## Plot a curve
Write a program that draws axes with a stated scale and plots a chosen function's graph point by point in small steps. Change the scale and re-run; say what the picture gained and lost.

## Diagram the data
Write a program that draws a bar diagram from a short data set (for example class marks or monthly rain). Check every bar's height against its value in the stated scale.
