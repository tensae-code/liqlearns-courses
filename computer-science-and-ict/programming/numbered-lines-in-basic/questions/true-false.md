# Numbered Lines in BASIC — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What begins every line of a BASIC program?" is: A line number**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "In what order does the computer run the lines?" is: Branching and loops — sending the program back to a line by its number**
**Answer: False** — In number order — not in typing order

**3. (Sub lesson 1) True or false: the answer to "What is a line number, in the lesson's word?" is: The line's address**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What do numbers make possible later in BASIC?" is: At 15**
**Answer: False** — Branching and loops — sending the program back to a line by its number

**5. (Sub lesson 1) True or false: the answer to "Why number in steps of ten?" is: To leave gaps so new lines can be inserted without renumbering everything**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Where does an inserted line between 10 and 20 go?" is: The line-numbered shape**
**Answer: False** — At 15

**7. (Sub lesson 2) True or false: the answer to "What has BASIC grown in since 1964?" is: Versions, each adding powers to the standard language**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What shape does every version keep?" is: The numbers, not the typing**
**Answer: False** — The line-numbered shape

**9. (Sub lesson 2) True or false: the answer to "What does Sudan's book teach first — a version or the standard?" is: Standard BASIC**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is the program's true order?" is: In number order — not in typing order**
**Answer: False** — The numbers, not the typing
