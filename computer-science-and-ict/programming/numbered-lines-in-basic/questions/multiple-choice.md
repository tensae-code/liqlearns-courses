# Numbered Lines in BASIC — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What begins every line of a BASIC program?**
a) A line number  b) In number order — not in typing order  c) Branching and loops — sending the program back to a line by its number  d) At 15
**Answer: a) A line number**

**2. (Sub lesson 1) In what order does the computer run the lines?**
a) The line's address  b) In number order — not in typing order  c) To leave gaps so new lines can be inserted without renumbering everything  d) Versions, each adding powers to the standard language
**Answer: b) In number order — not in typing order**

**3. (Sub lesson 1) What is a line number, in the lesson's word?**
a) Branching and loops — sending the program back to a line by its number  b) At 15  c) The line's address  d) The line-numbered shape
**Answer: c) The line's address**

**4. (Sub lesson 1) What do numbers make possible later in BASIC?**
a) To leave gaps so new lines can be inserted without renumbering everything  b) Versions, each adding powers to the standard language  c) Standard BASIC  d) Branching and loops — sending the program back to a line by its number
**Answer: d) Branching and loops — sending the program back to a line by its number**

**5. (Sub lesson 1) Why number in steps of ten?**
a) To leave gaps so new lines can be inserted without renumbering everything  b) At 15  c) The line-numbered shape  d) The numbers, not the typing
**Answer: a) To leave gaps so new lines can be inserted without renumbering everything**

**6. (Sub lesson 2) Where does an inserted line between 10 and 20 go?**
a) Versions, each adding powers to the standard language  b) At 15  c) Standard BASIC  d) A line number
**Answer: b) At 15**

**7. (Sub lesson 2) What has BASIC grown in since 1964?**
a) The line-numbered shape  b) The numbers, not the typing  c) Versions, each adding powers to the standard language  d) In number order — not in typing order
**Answer: c) Versions, each adding powers to the standard language**

**8. (Sub lesson 2) What shape does every version keep?**
a) Standard BASIC  b) A line number  c) The line's address  d) The line-numbered shape
**Answer: d) The line-numbered shape**

**9. (Sub lesson 2) What does Sudan's book teach first — a version or the standard?**
a) Standard BASIC  b) The numbers, not the typing  c) In number order — not in typing order  d) Branching and loops — sending the program back to a line by its number
**Answer: a) Standard BASIC**

**10. (Sub lesson 2) What is the program's true order?**
a) A line number  b) The numbers, not the typing  c) The line's address  d) To leave gaps so new lines can be inserted without renumbering everything
**Answer: b) The numbers, not the typing**
