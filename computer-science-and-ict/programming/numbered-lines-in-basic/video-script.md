# Video script — Numbered Lines in BASIC

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A BASIC program is written in **numbered lines**: every line of the program begins with a **line number**, and the computer runs the lines **in number order** — not in the order they were typed. The number is the line's address: the program can be sent back to a line by its number, which is how branching and loops in BASIC work. Sudan's book teaches standard BASIC and its versions here, at the door of the language, because nothing else in BASIC stands without the numbers.
Programmers number in **steps of ten** — 10, 20, 30 — leaving **gaps** so a forgotten line can be inserted later (a 15 between 10 and 20) without renumbering the whole program. BASIC has also grown in **versions** since 1964, each adding powers to the standard language; the line-numbered shape is the standard the book teaches first, the shape every version keeps. Type the program in any order you like: the numbers, not the typing, are the program's true order.
