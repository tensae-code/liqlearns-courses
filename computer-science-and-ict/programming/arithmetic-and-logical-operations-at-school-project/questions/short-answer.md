# Arithmetic and Logical Operations — the At School Project — short answer

Answer in a sentence or two.

**1. Explain, in your own words: plan a project by naming what it must compute and what it must decide.**
**Answer:** The learner's own explanation, true to the lesson: The "At School" double lesson puts arithmetic blocks, comparisons and logical operators to work together in one school-themed Scratch project — computing and deciding in the same program.

**2. A classmate gets this lesson's work wrong. What is the most likely fault, and how is it fixed?**
**Answer:** Whole project misbehaves → split it: test the computing half alone with known numbers, then the deciding half alone with known answers; the faulty half names itself.
