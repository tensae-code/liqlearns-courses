# Arithmetic and Logical Operations — the At School Project — true or false

Say whether each statement is true or false.

**1. Plan a project by naming what it must compute and what it must decide.**
**Answer: True** — This is one of the lesson's own outcomes.

**2. If a project's arithmetic is right, its decisions are automatically right too.**
**Answer: False** — The lesson teaches the opposite of this.

**3. Build the arithmetic part and check its numbers.**
**Answer: True** — This is one of the lesson's own outcomes.
