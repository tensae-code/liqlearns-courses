# The Pascal Alphabet and Symbols — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What letters does Pascal's alphabet use?" is: The Latin letters A–Z and a–z**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Name three special symbols of Pascal." is: The compiler stops at once**
**Answer: False** — +, := and ; (any three special symbols)

**3. (Sub lesson 1) True or false: the answer to "What happens if a program uses a sign outside the alphabet?" is: The compiler stops at once**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "From what are Pascal's service words built?" is: program and begin (or end)**
**Answer: False** — From the alphabet's letters, kept whole

**5. (Sub lesson 1) True or false: the answer to "Name two service words." is: program and begin (or end)**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is an identifier?" is: A letter**
**Answer: False** — A name the programmer invents

**7. (Sub lesson 2) True or false: the answer to "What must an identifier begin with?" is: A letter**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Why is 1sum not allowed?" is: A service word**
**Answer: False** — It begins with a digit

**9. (Sub lesson 2) True or false: the answer to "What may an identifier not be?" is: A service word**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why does the alphabet lesson stand first?" is: The Latin letters A–Z and a–z**
**Answer: False** — Every later rule is written in these letters and names
