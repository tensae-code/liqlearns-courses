# Building a User Interface — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — The Controls object — buttons and boxes
Sub lesson 1 questions from the type files. Pass mark: Controls — the window's working furniture; The Controls object; AddButton, AddTextBox and AddMultiLineTextBox; By coordinates, sized, and filled with its text; The user chooses what happens; the program must be ready for every choice at once.

## Sub lesson 2 — Events and handlers — the program that waits
Sub lesson 2 questions from the type files. Pass mark: A user's act — a click, a key — arriving in no promised order; Its event handler — the subprogram written for that event; A quadratic-equation solver built as a windowed program; The console program is a road; the windowed program is a room with staff; Deciding what the room offers and training the staff, handler by handler.
