# Building a User Interface — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a graphical interface built from?**
**Answer: Controls — the window's working furniture**

**2. (Sub lesson 1) Which object places the controls?**
**Answer: The Controls object**

**3. (Sub lesson 1) Name the three first controls.**
**Answer: AddButton, AddTextBox and AddMultiLineTextBox**

**4. (Sub lesson 1) How is each control placed?**
**Answer: By coordinates, sized, and filled with its text**

**5. (Sub lesson 1) How does the program's centre of gravity move in a window?**
**Answer: The user chooses what happens; the program must be ready for every choice at once**

**6. (Sub lesson 2) What is an event?**
**Answer: A user's act — a click, a key — arriving in no promised order**

**7. (Sub lesson 2) What meets an event?**
**Answer: Its event handler — the subprogram written for that event**

**8. (Sub lesson 2) What is the book's crown artefact?**
**Answer: A quadratic-equation solver built as a windowed program**

**9. (Sub lesson 2) State the book's contrast.**
**Answer: The console program is a road; the windowed program is a room with staff**

**10. (Sub lesson 2) What does designing the interface mean?**
**Answer: Deciding what the room offers and training the staff, handler by handler**
