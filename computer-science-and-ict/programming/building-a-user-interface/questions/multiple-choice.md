# Building a User Interface — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a graphical interface built from?**
a) Controls — the window's working furniture  b) The Controls object  c) AddButton, AddTextBox and AddMultiLineTextBox  d) By coordinates, sized, and filled with its text
**Answer: a) Controls — the window's working furniture**

**2. (Sub lesson 1) Which object places the controls?**
a) AddButton, AddTextBox and AddMultiLineTextBox  b) The Controls object  c) By coordinates, sized, and filled with its text  d) The user chooses what happens; the program must be ready for every choice at once
**Answer: b) The Controls object**

**3. (Sub lesson 1) Name the three first controls.**
a) By coordinates, sized, and filled with its text  b) The user chooses what happens; the program must be ready for every choice at once  c) AddButton, AddTextBox and AddMultiLineTextBox  d) A user's act — a click, a key — arriving in no promised order
**Answer: c) AddButton, AddTextBox and AddMultiLineTextBox**

**4. (Sub lesson 1) How is each control placed?**
a) The user chooses what happens; the program must be ready for every choice at once  b) A user's act — a click, a key — arriving in no promised order  c) Its event handler — the subprogram written for that event  d) By coordinates, sized, and filled with its text

**5. (Sub lesson 1) How does the program's centre of gravity move in a window?**
