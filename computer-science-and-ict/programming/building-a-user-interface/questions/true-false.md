# Building a User Interface — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a graphical interface built from?" is: Controls — the window's working furniture**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Which object places the controls?" is: AddButton, AddTextBox and AddMultiLineTextBox**
**Answer: False** — The Controls object

**3. (Sub lesson 1) True or false: the answer to "Name the three first controls." is: AddButton, AddTextBox and AddMultiLineTextBox**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How is each control placed?" is: The user chooses what happens; the program must be ready for every choice at once**
**Answer: False** — By coordinates, sized, and filled with its text

**5. (Sub lesson 1) True or false: the answer to "How does the program's centre of gravity move in a window?" is: The user chooses what happens; the program must be ready for every choice at once**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is an event?" is: Its event handler — the subprogram written for that event**
**Answer: False** — A user's act — a click, a key — arriving in no promised order

**7. (Sub lesson 2) True or false: the answer to "What meets an event?" is: Its event handler — the subprogram written for that event**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is the book's crown artefact?" is: The console program is a road; the windowed program is a room with staff**
**Answer: False** — A quadratic-equation solver built as a windowed program

**9. (Sub lesson 2) True or false: the answer to "State the book's contrast." is: The console program is a road; the windowed program is a room with staff**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What does designing the interface mean?" is: Controls — the window's working furniture**
**Answer: False** — Deciding what the room offers and training the staff, handler by handler
