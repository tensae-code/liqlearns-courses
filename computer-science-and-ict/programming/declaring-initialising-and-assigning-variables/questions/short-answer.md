# Declaring, Initialising and Assigning Variables — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What are the three acts of a variable's life?**
**Answer: Declaration, initialisation, assignment**

**2. (Sub lesson 1) What does declaration give a variable?**
**Answer: A type and a name — being**

**3. (Sub lesson 1) What does initialisation give it?**
**Answer: Its first value**

**4. (Sub lesson 1) Can Java use an uninitialised variable?**
**Answer: No — the compiler refuses; reading one is an error**

**5. (Sub lesson 1) How is a constant declared and initialised?**
**Answer: With final, once — final int PASS_MARK = 50;**

**6. (Sub lesson 2) What does assignment do?**
**Answer: Replaces the variable's value while the program runs**

**7. (Sub lesson 2) In score = score + 5, which value does the right side use?**
**Answer: The old value — then the result replaces it**

**8. (Sub lesson 2) How many times may each act happen?**
**Answer: Declaration once; assignment any number of times**

**9. (Sub lesson 2) What error is a missing declaration?**
**Answer: 'cannot find symbol'**

**10. (Sub lesson 2) What does 'cannot assign to final' mean?**
**Answer: An assignment was aimed at a constant**
