# Declaring, Initialising and Assigning Variables — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What are the three acts of a variable's life?**
a) Declaration, initialisation, assignment  b) A type and a name — being  c) Its first value  d) No — the compiler refuses; reading one is an error
**Answer: a) Declaration, initialisation, assignment**

**2. (Sub lesson 1) What does declaration give a variable?**
a) Its first value  b) A type and a name — being  c) No — the compiler refuses; reading one is an error  d) With final, once — final int PASS_MARK = 50;
**Answer: b) A type and a name — being**

**3. (Sub lesson 1) What does initialisation give it?**
a) No — the compiler refuses; reading one is an error  b) With final, once — final int PASS_MARK = 50;  c) Its first value  d) Replaces the variable's value while the program runs
**Answer: c) Its first value**

**4. (Sub lesson 1) Can Java use an uninitialised variable?**
a) With final, once — final int PASS_MARK = 50;  b) Replaces the variable's value while the program runs  c) The old value — then the result replaces it  d) No — the compiler refuses; reading one is an error
**Answer: d) No — the compiler refuses; reading one is an error**

**5. (Sub lesson 1) How is a constant declared and initialised?**
a) With final, once — final int PASS_MARK = 50;  b) Replaces the variable's value while the program runs  c) The old value — then the result replaces it  d) Declaration once; assignment any number of times
**Answer: a) With final, once — final int PASS_MARK = 50;**

**6. (Sub lesson 2) What does assignment do?**
a) The old value — then the result replaces it  b) Replaces the variable's value while the program runs  c) Declaration once; assignment any number of times  d) 'cannot find symbol'
**Answer: b) Replaces the variable's value while the program runs**

**7. (Sub lesson 2) In score = score + 5, which value does the right side use?**
a) Declaration once; assignment any number of times  b) 'cannot find symbol'  c) The old value — then the result replaces it  d) An assignment was aimed at a constant
**Answer: c) The old value — then the result replaces it**

**8. (Sub lesson 2) How many times may each act happen?**
a) 'cannot find symbol'  b) An assignment was aimed at a constant  c) Declaration, initialisation, assignment  d) Declaration once; assignment any number of times
**Answer: d) Declaration once; assignment any number of times**

**9. (Sub lesson 2) What error is a missing declaration?**
a) 'cannot find symbol'  b) An assignment was aimed at a constant  c) Declaration, initialisation, assignment  d) A type and a name — being
**Answer: a) 'cannot find symbol'**

**10. (Sub lesson 2) What does 'cannot assign to final' mean?**
a) Declaration, initialisation, assignment  b) An assignment was aimed at a constant  c) A type and a name — being  d) Its first value
**Answer: b) An assignment was aimed at a constant**
