# Declaring, Initialising and Assigning Variables — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What are the three acts of a variable's life?" is: Declaration, initialisation, assignment**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does declaration give a variable?" is: Its first value**
**Answer: False** — A type and a name — being

**3. (Sub lesson 1) True or false: the answer to "What does initialisation give it?" is: Its first value**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Can Java use an uninitialised variable?" is: With final, once — final int PASS_MARK = 50;**
**Answer: False** — No — the compiler refuses; reading one is an error

**5. (Sub lesson 1) True or false: the answer to "How is a constant declared and initialised?" is: With final, once — final int PASS_MARK = 50;**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does assignment do?" is: The old value — then the result replaces it**
**Answer: False** — Replaces the variable's value while the program runs

**7. (Sub lesson 2) True or false: the answer to "In score = score + 5, which value does the right side use?" is: The old value — then the result replaces it**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How many times may each act happen?" is: 'cannot find symbol'**
**Answer: False** — Declaration once; assignment any number of times

**9. (Sub lesson 2) True or false: the answer to "What error is a missing declaration?" is: 'cannot find symbol'**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What does 'cannot assign to final' mean?" is: Declaration, initialisation, assignment**
**Answer: False** — An assignment was aimed at a constant
