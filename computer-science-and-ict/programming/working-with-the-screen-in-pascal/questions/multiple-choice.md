# Working with the Screen in Pascal — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does ClrScr do?**
a) Clears the text screen  b) The cursor's column and row  c) Lands exactly at the placed position  d) The Crt unit
**Answer: a) Clears the text screen**

**2. (Sub lesson 1) What does GotoXY(x, y) set?**
a) Lands exactly at the placed position  b) The cursor's column and row  c) The Crt unit  d) Dialogue input with readln
**Answer: b) The cursor's column and row**

**3. (Sub lesson 1) What does the next write do after GotoXY?**
a) The Crt unit  b) Dialogue input with readln  c) Lands exactly at the placed position  d) The colours of the letters and of the screen behind them
**Answer: c) Lands exactly at the placed position**

**4. (Sub lesson 1) Which unit holds these operators?**
a) Dialogue input with readln  b) The colours of the letters and of the screen behind them  c) One colour for headings, one for results, the rest plain  d) The Crt unit
**Answer: d) The Crt unit**

**5. (Sub lesson 1) What comes just before this lesson in the book?**
a) Dialogue input with readln  b) The colours of the letters and of the screen behind them  c) One colour for headings, one for results, the rest plain  d) Too many colours hide the work
**Answer: a) Dialogue input with readln**

**6. (Sub lesson 2) What do TextColor and TextBackground set?**
a) One colour for headings, one for results, the rest plain  b) The colours of the letters and of the screen behind them  c) Too many colours hide the work  d) A repetition, then linear programs
**Answer: b) The colours of the letters and of the screen behind them**

**7. (Sub lesson 2) What is the taste rule for screen colours?**
a) Too many colours hide the work  b) A repetition, then linear programs  c) One colour for headings, one for results, the rest plain  d) Present it arranged, not spilled
**Answer: c) One colour for headings, one for results, the rest plain**

**8. (Sub lesson 2) Why is a screen 'read, not decorated'?**
a) A repetition, then linear programs  b) Present it arranged, not spilled  c) Clears the text screen  d) Too many colours hide the work
**Answer: d) Too many colours hide the work**

**9. (Sub lesson 2) What follows this lesson in the book?**
a) A repetition, then linear programs  b) Present it arranged, not spilled  c) Clears the text screen  d) The cursor's column and row
**Answer: a) A repetition, then linear programs**

**10. (Sub lesson 2) What is every later program expected to do with output?**
a) Clears the text screen  b) Present it arranged, not spilled  c) The cursor's column and row  d) Lands exactly at the placed position
**Answer: b) Present it arranged, not spilled**
