# Building a Network Chat System in Python — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 1) The program in the middle of a chat system is the ____.**
**Answer: server** — Clients connect to it; it passes messages on.

**2. (Sub lesson 1) When the server passes a message to all other clients, it ____ it.**
**Answer: broadcasts** — One in, copies out to everyone else.

**3. (Sub lesson 2) ____ is the protocol that keeps a two-way connection open for chat.**
**Answer: WebSocket** — Open once, talk both ways, all the time.
