# Hands-on — Building a Network Chat System in Python

The lesson with your hands and your feet, not only your eyes.

## Trace a message
Draw the ring-and-centre diagram for five clients. Number the steps of one message from Ana's keyboard to Bek's screen. Then write what breaks, and what still works, if the server stops.

## Run the room's chat
Start the server on the teacher's machine. Connect your client, exchange messages with two classmates, and note the moment each message appears. Then read the server code and find the loop that broadcasts — point at the exact lines.
