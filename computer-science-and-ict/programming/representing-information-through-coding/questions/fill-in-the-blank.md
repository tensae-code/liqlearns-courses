# Representing Information Through Coding — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 1) Writing information with a code's rule is called ____.**
**Answer: encoding**

**2. (Sub lesson 2) A code in which one sign never stands for two things is ____.**
**Answer: unambiguous**

**3. (Sub lesson 2) The last digit of a barcode, computed from the others, is a ____ digit.**
**Answer: check**
