# Representing Information Through Coding — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) The information changes when it is encoded.**
**Answer: False** — Only its form changes; decoding returns the same information.

**2. (Sub lesson 2) A sign can mean two different things in a good code, if the reader is clever.**
**Answer: False** — Unambiguous means one sign, one meaning — cleverness is not part of a rule.

**3. (Sub lesson 1) Without the shared rule, the signs of a code mean nothing.**
**Answer: True** — The rule is what the signs stand for; beeps alone are just beeps.

**4. (Sub lesson 1) A QR code and a barcode are codes under the same idea: signs assigned by a rule.**
**Answer: True** — Both pair information with patterns; they differ in channel and capacity.
