# Representing Information Through Coding — short answer

Answer in your own words, in one or two sentences.

**1. (Sub lesson 1) Why must sender and receiver hold the same code rule before a message travels?**
**Answer: Because the signs carry no meaning on their own — the rule is what pairs each sign with its information. Without the shared rule the receiver holds marks, not a message, and decoding is impossible.**

**2. (Sub lesson 2) A code assigns A = 0, B = 01, C = 1 with no gaps allowed. Show it is not uniquely decodable.**
**Answer: The stream 01 can be read as the single sign B, or as A followed by C (0 then 1). Two valid splits of one stream means decoding can guess wrong — the code fails unique decodability.**
