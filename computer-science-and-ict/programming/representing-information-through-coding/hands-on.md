# Hands-on — Representing Information Through Coding

The lesson with your hands and your feet, not only your eyes.

## Torch Morse
Write the Morse for SOS (··· −−− ···) and for your first name. Send both with a torch or phone light to a partner across the room, who writes down what arrived and decodes it. Any letter that fails, blame the code or the gaps — and fix the rule, then resend.

## Invent a jersey code
Design a code that represents every pupil in a class with signs a spectator can read at 50 metres: big, few, unambiguous. Write the rule as a table. Test it: can two pupils ever get the same sign? Can a sign be misread as another? Fix what fails.
