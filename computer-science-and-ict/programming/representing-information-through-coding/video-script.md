# Video script — Representing Information Through Coding

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A code is a rule. This sign stands for that thing.

Stripes on a packet stand for a name and a price. That is a code.

Writing with the rule is encoding. Reading back is decoding.

A good code gives every sign one meaning only.

And a stream of signs must split back in only one way.

Frequent things get short signs. In Morse, E is just one dot.
