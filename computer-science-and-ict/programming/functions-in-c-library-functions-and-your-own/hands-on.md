# Hands-on — Functions in C — Library Functions and Your Own

The lesson with your hands and your feet, not only your eyes.

## Task one
**Call the library** — Write a C program using sqrt and pow to print the hypotenuse of a 3-4 triangle and 2 raised to 10 — headers included, answers checked by hand.

## Task two
**Author one** — Write a function `square(int)` with prototype, definition and three calls from main — then a second function that calls the first.
