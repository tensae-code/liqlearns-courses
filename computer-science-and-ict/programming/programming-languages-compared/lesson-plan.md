# Lesson plan — Programming Languages Compared

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** Programming Languages Compared
**Place in the curriculum:** ICT expansion — North Macedonia (2026-11-14) — in the title Programming on the ICT course ladder (TITLES.md). Built new from North Macedonia's *Informatics* (2026), because no existing lesson in the course covers this thing as its own lesson.
**The one thing this lesson teaches:** Programming languages differ in how close they sit to the machine, what they are built for and how their programs run; North Macedonia's book compares Scratch (blocks for beginners), C++ (compiled, close to the machine), Java and Python (general-purpose, very widely used), PHP (web servers) and Lisp (one of the oldest, built on lists).
**This lesson's own level:** It stands on the earlier lessons of its title and on the North Macedonia book's own order — it follows the book's sections in sequence, so its neighbours in the book are its natural companions. It stands alone for a learner landing on it directly.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Six languages, six characters** — **Scratch** — programs built by snapping **blocks** together; made for first steps, nothing to type wrong. **C++** — a powerful compiled language close to the machine; North Macedonia's own first language. **Java** — general-purpose, its programs run on a virtual machine so the same program travels between systems. **Python** — readable, general-purpose, huge in science and AI. **PHP** — built for **web servers**, generating pages. **Lisp** — among the oldest languages, built around **lists** and famous in AI history.
2. **Choosing a language for a job** — The comparison rests on questions a programmer actually asks: Is it **compiled or interpreted**? How close to the hardware? What is it **used for**, and how easy is it to **learn**? A beginner's block language, a systems language and a web language are not rivals — they are tools shaped by their jobs, and learning one teaches ideas (sequence, choice, loops, data) that carry into all the others.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
