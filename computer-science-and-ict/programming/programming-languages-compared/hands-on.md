# Hands-on — Programming Languages Compared

The lesson with your hands and your feet, not only your eyes.

## Match the job
Write six jobs (first program for a child, a game engine, a school website, a data-science script, a program that must run everywhere, an AI-history study). Match each to a language from the lesson and say why in one line.

## Same idea, two languages
Write the steps of making tea as Scratch-style blocks in words, then as numbered C++-style steps. What stayed the same? That sameness is the point of the comparison.
