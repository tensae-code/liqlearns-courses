# Hands-on — User-Defined Functions in Python

The lesson with your hands, not only your eyes.

## Build one, call it three times

In Python, write a function `square(n)` that returns `n * n`. Call it with three different numbers and print each result. Then change the function once — make it return `n * n + 1` — run again, and see every call change from that one edit.

## Wrap a repeated job

Look at a program you have written before and find lines that repeat. Wrap those lines in a function with a good name, replace each copy with a call, and run the program to check it still does the same job.
