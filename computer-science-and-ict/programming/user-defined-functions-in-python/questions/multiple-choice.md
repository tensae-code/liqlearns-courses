# User-Defined Functions in Python — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) A user-defined function is —**
a) a function the programmer writes themselves, with `def`  b) a function inside the computer's hardware  c) a function only teachers may use
**Answer: a) a function the programmer writes themselves, with `def`** — Built-in functions like `print` come with Python; user-defined ones are yours.

**2. (Sub lesson 1) After you write a `def` block, the function's job runs when —**
a) immediately, as Python reads it  b) only when the function is called by name  c) never — `def` blocks are comments
**Answer: b) only when the function is called by name** — Defining teaches Python the name; calling runs the job.

**3. (Sub lesson 1) The function's body must be —**
a) written in capital letters  b) indented under the `def` line  c) placed before the `def` line
**Answer: b) indented under the `def` line** — Python reads the indentation as "inside the function".

**4. (Sub lesson 2) Parameters are —**
a) the named slots in the `def` line that values are handed in through  b) the answers a function prints  c) errors in a function
**Answer: a) the named slots in the `def` line that values are handed in through** — Arguments fill them at each call.

**5. (Sub lesson 2) `return` does what `print` does not —**
a) shows the value in a bigger font  b) hands the result back so it can be stored and used  c) stops the whole program
**Answer: b) hands the result back so it can be stored and used** — `print` shows a value and it is gone; `return` keeps it in the program's hands.

**6. (Sub lesson 2) Calling `square(3)` and `square(10)` with the body `return number * number` gives —**
a) 9 both times  b) 9 and 100  c) an error, because a function may be called only once
**Answer: b) 9 and 100** — Same body, different arguments, different results.
