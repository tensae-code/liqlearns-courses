# User-Defined Functions in Python — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 1) A user-defined function is written with the keyword ____.**
**Answer: def**

**2. (Sub lesson 1) Writing the name of a function with brackets to make it run is called ____ the function.**
**Answer: calling**

**3. (Sub lesson 2) The word that hands a result back from a function is ____.**
**Answer: return**
