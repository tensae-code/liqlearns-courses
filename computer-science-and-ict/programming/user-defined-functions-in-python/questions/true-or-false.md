# User-Defined Functions in Python — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) A function written once can be called in many places in a program.**
**Answer: True** — That is the function's bargain: write once, call anywhere.

**2. (Sub lesson 1) If a job inside a function must be fixed, every place that copied the job must be fixed separately.**
**Answer: False** — With a function there is one written block; fix it in one place and every call follows.

**3. (Sub lesson 2) The values passed at a call are called the arguments.**
**Answer: True** — Arguments fill the parameter slots for that run.

**4. (Sub lesson 2) A value handed back by `return` disappears at once, like a printed value.**
**Answer: False** — A returned value can be stored in a variable and used in more work.
