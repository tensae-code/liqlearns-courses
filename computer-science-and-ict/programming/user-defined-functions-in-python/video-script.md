# Video script — User-Defined Functions in Python

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Writing the same lines again and again is a trap.

Write the job once. Give it a name. That is a function.

`def` writes it. Calling the name runs it.

Values go in: parameters. A result comes back: `return`.

One fix, in one place, fixes every call.
