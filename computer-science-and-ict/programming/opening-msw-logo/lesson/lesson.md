# Opening MSW Logo

## Do it first

MSW Logo is installed on the computer. Open it — any way you can. If you found it, well done; if you hunted, you are ready for the book's exact route, so Logo is never lost again.

## The book's route — and the shortcut

In the book's order: click the **Start button**; click **Programs**; then click **Microsoft Windows Logo**. Follow the GIF through the same clicks. Or, if the icon is there, click the **MSW Logo icon on the desktop** directly. And one extra the book gives for after you arrive: a demonstration can be run from **Help → Demo** — a good first look at what the turtle can do, before you command it yourself.

Tell your companion the menu route to MSW Logo, in order, and where the Demo lives.

## Do It Yourself

1. Open MSW Logo by the menu route from memory.
2. Open it from the desktop, if the icon is there.
3. Run the Demo and name one drawing from it.
