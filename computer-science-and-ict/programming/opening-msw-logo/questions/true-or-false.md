# Opening MSW Logo — true or false

Say whether each sentence is true or false.

**1.** There are two ways in: the menu route and the desktop icon.
**Answer: True** — both are in the book.

**2.** The Demo is found under the File menu.
**Answer: False** — Help → Demo.

**3.** The Start → Programs route works even without a desktop icon.
**Answer: True** — the menu route is the always-there route.
