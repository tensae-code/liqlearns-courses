# Opening MSW Logo — multiple choice

Pick the one right answer.

**1.** The menu route's order is —
a) Programs → Start → Logo  b) Start → Programs → Microsoft Windows Logo  c) Start → Help → Logo  d) Desktop → Start → Programs
**Answer: b) Start → Programs → Microsoft Windows Logo** — Start, Programs, Microsoft Windows Logo.

**2.** The desktop way is to click —
a) the Recycle Bin  b) the MSW Logo icon  c) any folder  d) the Start button twice
**Answer: b) the MSW Logo icon** — the MSW Logo desktop icon.

**3.** A demonstration is run from —
a) File → Demo  b) Help → Demo  c) Edit → Demo  d) View → Demo
**Answer: b) Help → Demo** — Help → Demo.

**4.** The menu entry is named —
a) MSW Logo Program  b) Microsoft Windows Logo  c) Logo Writer  d) Turtle
**Answer: b) Microsoft Windows Logo** — Microsoft Windows Logo, in Programs.

**5.** MSW Logo must be ______ before it can be opened.
a) downloaded daily  b) installed  c) printed  d) cleaned
**Answer: b) installed** — installed first — from the lesson before.

**6.** The route begins with —
a) Programs  b) the Start button  c) Help  d) the desktop
**Answer: b) the Start button** — click Start first.
