# What Programming Is — Giving Instructions to a Computer — short answer

Answer in a sentence or two.

**1. (Sub lesson 1) Explain the baker story to someone who has never programmed.**
**Answer:** A sound answer: the baker follows the recipe exactly and does not guess missing steps; a computer is the same — it does only what its instructions say, in the order given, so the programmer must say everything clearly.

**2. (Sub lesson 2) A sprite does nothing on screen. Using the five words, say what is missing.**
**Answer:** A sound answer: the sprite has no script — no blocks (commands) joined as code giving it instructions, so there is no program telling it what to do.
