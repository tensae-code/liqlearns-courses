# What Programming Is — Giving Instructions to a Computer — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) A computer knows what you meant, even if your instructions say something else.**
**Answer: False** — It follows the instructions exactly, as given.

**2. (Sub lesson 1) A wrong result can come from a missing step in the instructions.**
**Answer: True** — The fault is in the instructions, not the computer.

**3. (Sub lesson 2) Code and a program mean unrelated things.**
**Answer: False** — A program is the set of instructions; code is those instructions in the computer's form.
