# What Programming Is — Giving Instructions to a Computer — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Programming is —**
a) Giving instructions to a computer  b) Repairing a computer  c) Drawing pictures only
**Answer: a) Giving instructions to a computer** — Programming/coding is giving instructions.

**2. (Sub lesson 1) In the baker story, if a step is missing from the recipe, the baker —**
a) Guesses it correctly every time  b) Does not do it — the instructions are followed exactly  c) Stops being a baker
**Answer: b) Does not do it — the instructions are followed exactly** — A computer follows instructions exactly, as given.

**3. (Sub lesson 2) One single instruction in Scratch, like move or say, is called —**
a) A sprite  b) A command / block  c) A backdrop
**Answer: b) A command / block** — A command is one instruction; in Scratch it is a block.

**4. (Sub lesson 2) Blocks joined together in order form a —**
a) Script  b) Stage  c) Sound
**Answer: a) Script** — A script is blocks joined in order.

**5. (Sub lesson 2) The character on the stage that a script tells what to do is a —**
a) Recipe  b) Sprite  c) Recipe book
**Answer: b) Sprite** — The sprite is who acts; the script is what it is told.
