Finland's own way: programming is taught entirely through Scratch in Finnish, as a gamified two-part path — Part 1 ends in an interactive-story project, Part 2 in a self-built maze game. Every concept is introduced in a short "Luetaan" (Let's read) text, practised in guided "Ohjelmoidaan" (Let's program) challenges, then used in a project; pair work, reflection and peer showing are built in throughout. this placement sits in Finland's two-part Scratch path — Part 1 moves towards the interactive-story project and Part 2 towards the self-built maze game, in the Luetaan (Let's read) then Ohjelmoidaan (Let's program) rhythm, with pair work, reflection and peer showing built in.
