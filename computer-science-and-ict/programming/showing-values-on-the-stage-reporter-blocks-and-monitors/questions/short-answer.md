# Showing Values on the Stage — Reporter Blocks and Monitors — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What do reporter blocks carry?**
**Answer: Values the program can use or show**

**2. (Sub lesson 1) Name four reporters the book lists.**
**Answer: Position, direction, costume number and background name (also size, volume, tempo, answer, timer, loudness, video motion)**

**3. (Sub lesson 1) How is a reporter different from an order block?**
**Answer: A reporter gives a fact, not an order**

**4. (Sub lesson 1) What shape are reporter blocks?**
**Answer: Oval**

**5. (Sub lesson 1) Which reporter holds what the user typed?**
**Answer: Answer**

**6. (Sub lesson 2) How is a reporter shown on the stage?**
**Answer: By ticking it, as a monitor**

**7. (Sub lesson 2) What is a monitor?**
**Answer: A small window on the stage showing the value as it changes**

**8. (Sub lesson 2) What does the timer monitor do?**
**Answer: It keeps counting on the stage**

**9. (Sub lesson 2) How are some monitors shown?**
**Answer: As sliders**

**10. (Sub lesson 2) Can a monitor be hidden again?**
**Answer: Yes — ticked to show or hide**
