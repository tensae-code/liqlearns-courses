# Showing Values on the Stage — Reporter Blocks and Monitors — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What do reporter blocks carry?" is: Values the program can use or show**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Name four reporters the book lists." is: Oval**
**Answer: False** — Position, direction, costume number and background name (also size, volume, tempo, answer, timer, loudness, video motion)

**3. (Sub lesson 1) True or false: the answer to "How is a reporter different from an order block?" is: A reporter gives a fact, not an order**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What shape are reporter blocks?" is: By ticking it, as a monitor**
**Answer: False** — Oval

**5. (Sub lesson 1) True or false: the answer to "Which reporter holds what the user typed?" is: Answer**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How is a reporter shown on the stage?" is: It keeps counting on the stage**
**Answer: False** — By ticking it, as a monitor

**7. (Sub lesson 2) True or false: the answer to "What is a monitor?" is: A small window on the stage showing the value as it changes**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does the timer monitor do?" is: Yes — ticked to show or hide**
**Answer: False** — It keeps counting on the stage

**9. (Sub lesson 2) True or false: the answer to "How are some monitors shown?" is: As sliders**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Can a monitor be hidden again?" is: Position, direction, costume number and background name (also size, volume, tempo, answer, timer, loudness, video motion)**
**Answer: False** — Yes — ticked to show or hide
