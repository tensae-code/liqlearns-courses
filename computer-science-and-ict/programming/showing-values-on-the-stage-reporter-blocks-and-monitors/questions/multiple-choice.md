# Showing Values on the Stage — Reporter Blocks and Monitors — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What do reporter blocks carry?**
a) Values the program can use or show  b) Position, direction, costume number and background name (also size, volume, tempo, answer, timer, loudness, video motion)  c) Oval  d) By ticking it, as a monitor
**Answer: a) Values the program can use or show**

**2. (Sub lesson 1) Name four reporters the book lists.**
a) A reporter gives a fact, not an order  b) Position, direction, costume number and background name (also size, volume, tempo, answer, timer, loudness, video motion)  c) Answer  d) A small window on the stage showing the value as it changes
**Answer: b) Position, direction, costume number and background name (also size, volume, tempo, answer, timer, loudness, video motion)**

**3. (Sub lesson 1) How is a reporter different from an order block?**
a) Oval  b) By ticking it, as a monitor  c) A reporter gives a fact, not an order  d) It keeps counting on the stage
**Answer: c) A reporter gives a fact, not an order**

**4. (Sub lesson 1) What shape are reporter blocks?**
a) Answer  b) A small window on the stage showing the value as it changes  c) As sliders  d) Oval
**Answer: d) Oval**

**5. (Sub lesson 1) Which reporter holds what the user typed?**
a) Answer  b) By ticking it, as a monitor  c) It keeps counting on the stage  d) Yes — ticked to show or hide
**Answer: a) Answer**
