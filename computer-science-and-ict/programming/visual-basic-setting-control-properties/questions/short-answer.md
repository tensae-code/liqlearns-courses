# Visual Basic — Setting Control Properties — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a property?**
**Answer: A characteristic of a control — its text, name, size, colour, visibility — each with a value**

**2. (Sub lesson 1) What does changing a property change?**
**Answer: What the control is like — not what it is**

**3. (Sub lesson 1) What finishes a form, after assembly?**
**Answer: The controls' properties**

**4. (Sub lesson 1) What is design time setting?**
**Answer: Setting the value in the Properties window while building — fixed before the run**

**5. (Sub lesson 1) What is run time setting?**
**Answer: Setting the value by code while the program runs — it can answer to events**

**6. (Sub lesson 2) Give a run-time example.**
**Answer: A label turning red when the answer is wrong**

**7. (Sub lesson 2) Name the book's two worked examples.**
**Answer: Centring a control, and the colour property**

**8. (Sub lesson 2) Why must colours be set deliberately?**
**Answer: A program's colours are read as meaning before its words are**

**9. (Sub lesson 2) Which chapter teaches this?**
**Answer: Part 1, Book 2, Chapter 2 — Setting the Program's Elements**

**10. (Sub lesson 2) Which book teaches this?**
**Answer: Kuwait Grade 12 Information Technology Term 1, Part 1 Book 2 Chapter 2**
