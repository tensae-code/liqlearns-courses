# Building a Number Converter in VB.NET — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does the number-conversion project do?" is: Takes a number in one system and returns it in another**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Name the conversions it covers?" is: A place to type the number, a choice of systems (from, to), a convert action, and a place the answer appears**
**Answer: False** — Decimal to binary, binary to hexadecimal, and their reverses (among the three systems)

**3. (Sub lesson 1) True or false: the answer to "What does the VB.NET form hold?" is: A place to type the number, a choice of systems (from, to), a convert action, and a place the answer appears**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What must the converter refuse?" is: Repeated division, remainders read back**
**Answer: False** — An invalid entry — a 'binary' number containing a 2 is not binary

**5. (Sub lesson 1) True or false: the answer to "How does a program convert decimal to another base?" is: Repeated division, remainders read back**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How does it convert another base to decimal?" is: By groups of four bits**
**Answer: False** — Place values multiplied and added

**7. (Sub lesson 2) True or false: the answer to "How do binary and hexadecimal trade?" is: By groups of four bits**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Against what is the finished converter tested?" is: PHP**
**Answer: False** — Hand-worked conversions

**9. (Sub lesson 2) True or false: the answer to "In what second language is the project rebuilt?" is: PHP**
