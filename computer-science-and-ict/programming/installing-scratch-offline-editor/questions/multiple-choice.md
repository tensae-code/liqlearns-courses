# Installing the Scratch Offline Editor — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is installed so Scratch works without internet?**
a) The Scratch Offline Editor  b) Adobe AIR  c) Once  d) Grades 6, 7, 8 and 9
**Answer: a) The Scratch Offline Editor**

**2. (Sub lesson 1) What must be installed with the editor?**
a) It needs it in order to run  b) Adobe AIR  c) No browser, connection or account  d) Its working home
**Answer: b) Adobe AIR**

**3. (Sub lesson 1) Why does the editor need Adobe AIR?**
a) Once  b) Grades 6, 7, 8 and 9  c) It needs it in order to run  d) That Scratch is on the machine
**Answer: c) It needs it in order to run**

**4. (Sub lesson 1) How often is the install done?**
a) No browser, connection or account  b) Its working home  c) Nothing — the editor and saved projects are already there  d) Once
**Answer: d) Once**

**5. (Sub lesson 1) What is not needed to start working offline?**
a) No browser, connection or account  b) Grades 6, 7, 8 and 9  c) That Scratch is on the machine  d) The computer, like any other program
**Answer: a) No browser, connection or account**

**6. (Sub lesson 2) Which grades’ books repeat the install?**
a) Its working home  b) Grades 6, 7, 8 and 9  c) Nothing — the editor and saved projects are already there  d) The Scratch Offline Editor
**Answer: b) Grades 6, 7, 8 and 9**

**7. (Sub lesson 2) What is the offline editor to the course?**
a) That Scratch is on the machine  b) The computer, like any other program  c) Its working home  d) Adobe AIR
**Answer: c) Its working home**

**8. (Sub lesson 2) What do lessons and projects assume?**
a) Nothing — the editor and saved projects are already there  b) The Scratch Offline Editor  c) It needs it in order to run  d) That Scratch is on the machine
**Answer: d) That Scratch is on the machine**

**9. (Sub lesson 2) What does a class lose if its internet fails?**
a) Nothing — the editor and saved projects are already there  b) The computer, like any other program  c) Adobe AIR  d) Once
**Answer: a) Nothing — the editor and saved projects are already there**

**10. (Sub lesson 2) Where does the installed Scratch open from?**
a) The Scratch Offline Editor  b) The computer, like any other program  c) It needs it in order to run  d) No browser, connection or account
**Answer: b) The computer, like any other program**
