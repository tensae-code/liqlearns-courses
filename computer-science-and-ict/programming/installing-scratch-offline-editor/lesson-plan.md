# Lesson plan — Installing the Scratch Offline Editor

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** Installing the Scratch Offline Editor
**Place in the curriculum:** ICT expansion — Palestine (2026-11-14) — in the title Programming on the ICT course ladder (TITLES.md). Built new from Palestine's Grade 6, Grade 7, Grade 8 and Grade 9 Programming student books, because no existing lesson in the course covers this thing as its own lesson.
**The one thing this lesson teaches:** The Scratch Offline Editor is Scratch installed on the computer itself — installed together with Adobe AIR — so projects can be built, run and saved with no internet connection.
**This lesson's own level:** It stands on the earlier lessons of its title and on the book's own order — it follows the book's lessons in sequence, so its neighbours in the book are its natural companions. It stands alone for a learner landing on it directly.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Installing the editor and Adobe AIR** — The books teach the install as one job with two parts: the **Scratch Offline Editor** and **Adobe AIR**, which the editor needs in order to run. Installed once, Scratch opens from the computer like any other program — no browser, no connection, no account needed to start working.
2. **Why offline — the same first step, four years running** — Grades 6, 7, 8 and 9 all repeat the install, because the offline editor is the course’s working home: lessons, projects and saved files all assume Scratch is **on the machine**. A class whose internet fails loses nothing — the editor, and every saved project, are already there.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

2. **The explanation** — the lesson text in lesson/lesson.md, in its parts in order.
