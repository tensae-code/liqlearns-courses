# Programming Number Sequences — Arithmetic, Geometric and Fibonacci — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "How does an arithmetic sequence grow?" is: By adding the same difference each step**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How does a geometric sequence grow?" is: A list**
**Answer: False** — By multiplying by the same ratio

**3. (Sub lesson 1) True or false: the answer to "What generates the sequences?" is: A loop with the rule inside it**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Where are the terms generated into?" is: Each term is the sum of the two before it**
**Answer: False** — A list

**5. (Sub lesson 1) True or false: the answer to "Does the programmer type the terms?" is: No — the loop generates them**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is the Fibonacci rule?" is: From Arab scholars**
**Answer: False** — Each term is the sum of the two before it

**7. (Sub lesson 2) True or false: the answer to "What are the first six Fibonacci terms?" is: 1, 1, 2, 3, 5, 8**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "From whom did Fibonacci learn his mathematics?" is: The generating rule**
**Answer: False** — From Arab scholars

**9. (Sub lesson 2) True or false: the answer to "What did Fibonacci carry to Europe?" is: The sequence, and much else**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What differs between the three sequences?" is: By multiplying by the same ratio**
**Answer: False** — The generating rule
