# Programming Number Sequences — Arithmetic, Geometric and Fibonacci — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) How does an arithmetic sequence grow?**
a) By adding the same difference each step  b) By multiplying by the same ratio  c) A list  d) Each term is the sum of the two before it
**Answer: a) By adding the same difference each step**

**2. (Sub lesson 1) How does a geometric sequence grow?**
a) A loop with the rule inside it  b) By multiplying by the same ratio  c) No — the loop generates them  d) 1, 1, 2, 3, 5, 8
**Answer: b) By multiplying by the same ratio**

**3. (Sub lesson 1) What generates the sequences?**
a) A list  b) Each term is the sum of the two before it  c) A loop with the rule inside it  d) From Arab scholars
**Answer: c) A loop with the rule inside it**

**4. (Sub lesson 1) Where are the terms generated into?**
a) No — the loop generates them  b) 1, 1, 2, 3, 5, 8  c) The sequence, and much else  d) A list
**Answer: d) A list**

**5. (Sub lesson 1) Does the programmer type the terms?**
a) No — the loop generates them  b) Each term is the sum of the two before it  c) From Arab scholars  d) The generating rule
**Answer: a) No — the loop generates them**

**6. (Sub lesson 2) What is the Fibonacci rule?**
a) 1, 1, 2, 3, 5, 8  b) Each term is the sum of the two before it  c) The sequence, and much else  d) By adding the same difference each step
**Answer: b) Each term is the sum of the two before it**

**7. (Sub lesson 2) What are the first six Fibonacci terms?**
a) From Arab scholars  b) The generating rule  c) 1, 1, 2, 3, 5, 8  d) By multiplying by the same ratio
**Answer: c) 1, 1, 2, 3, 5, 8**

**8. (Sub lesson 2) From whom did Fibonacci learn his mathematics?**
a) The sequence, and much else  b) By adding the same difference each step  c) A loop with the rule inside it  d) From Arab scholars
**Answer: d) From Arab scholars**

**9. (Sub lesson 2) What did Fibonacci carry to Europe?**
a) The sequence, and much else  b) The generating rule  c) By multiplying by the same ratio  d) A list
**Answer: a) The sequence, and much else**

**10. (Sub lesson 2) What differs between the three sequences?**
a) By adding the same difference each step  b) The generating rule  c) A loop with the rule inside it  d) No — the loop generates them
**Answer: b) The generating rule**
