## Sub lesson 1 — The matrix — the graph as a table
Sub lesson 1 questions from the type files. Pass mark: An n × n table — 1 where an edge joins the row and column vertices, else 0; One look — a single cell; They are the 1s in its row; n² cells, however few edges the graph has; It mirrors across the diagonal — cell (u,v) equals cell (v,u).

## Sub lesson 2 — The list — each vertex with its neighbours
Sub lesson 2 questions from the type files. Pass mark: For each vertex, the list of its neighbours; About n + 2E entries — it follows the edges; Sparse graphs — few edges; Testing one pair's edge means searching a neighbour list; Many edges or edge-questions: matrix. Few edges or neighbour-walks: list.
