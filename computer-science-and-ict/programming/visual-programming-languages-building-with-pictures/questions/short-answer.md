# Visual Programming Languages — Building with Pictures — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What are a language's levels measured by?**
**Answer: Its distance from the machine — low-level near the machine's tongue, high-level near the human's**

**2. (Sub lesson 1) What is the low level's bargain?**
**Answer: More control, more labour — fast and exact, hard for humans**

**3. (Sub lesson 1) What translates high-level languages for the machine?**
**Answer: Compilers and interpreters**

**4. (Sub lesson 1) Where does Visual Basic stand?**
**Answer: On the high level**

**5. (Sub lesson 1) What is a visual programming language?**
**Answer: One where the program is built graphically — interface drawn, behaviour partly assembled visually**

**6. (Sub lesson 2) What does the VB pupil see while building?**
**Answer: The program's own window, on the desk during the building**

**7. (Sub lesson 2) Is 'visual' the same axis as 'level'?**
**Answer: No — visual names how the language is worked; a language can be both high-level and visual**

**8. (Sub lesson 2) Give the exemplar.**
**Answer: Visual Basic**
