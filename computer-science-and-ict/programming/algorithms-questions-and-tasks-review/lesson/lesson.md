## Algorithms — Questions and Tasks Review

This is the **review lesson** for the Algorithm unit — the book's own 'questions and tasks' page. Each task set checks one lesson of the unit.

**Task set 1 — sequences and algorithms.** Put jumbled actions into their right order with first, then, next, last. Then judge steps: which step is clear, which makes the follower guess — and fix the unclear step. Write a short algorithm for an everyday task.

**Task set 2 — executing and statements.** Execute a given algorithm exactly, ticking the steps, and say where a fault lies when the result is wrong. Sort statements into true, false and uncertain, and say what would settle each uncertain one.

**Task set 3 — the shortest path.** On a simple map, compare two routes between the same start and finish and choose the shortest, saying both counts. If a task goes wrong, that task names the lesson to visit again.

## Do It Yourself

1. Show it, don't just say it: order a sequence and write a short, clear algorithm.
2. Show it, don't just say it: execute an algorithm exactly and sort statements into true, false and uncertain.
3. Show it, don't just say it: compare routes and choose the shortest path with a reason.
