# Algorithms — Questions and Tasks Review — multiple choice

Pick the one right answer.

**1. Which task belongs to this review?**
a) Executing a given algorithm exactly  b) Formatting a paragraph  c) Naming sense organs
**Answer: a) Executing a given algorithm exactly** — Execution was Unit 3's third lesson.

**2. A step that says 'add some' is —**
a) clear  b) unclear — it makes the follower guess  c) finished
**Answer: b) unclear — it makes the follower guess** — Clear steps need no guessing.

**3. 'It might rain' is —**
a) true  b) false  c) uncertain
**Answer: c) uncertain** — It waits on what happens.

**4. The shortest path is chosen by —**
a) the nicest name  b) comparing routes and picking the least travelling  c) guessing
**Answer: b) comparing routes and picking the least travelling** — Same start, same finish, least travelling wins.
