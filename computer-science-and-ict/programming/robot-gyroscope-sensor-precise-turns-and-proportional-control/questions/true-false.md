# Robot Gyroscope Sensor — Precise Turns and Proportional Control — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The robot's rotation — degrees turned from its start**
**Answer: True**

**2. (Sub lesson 1) True or false: 90 means 90 on any floor, with any battery — the turn is measured, not hoped** — as the answer to: How does a gyro turn end?

**6. (Sub lesson 2) True or false: The constant that sets the proportion of correction** — as the answer to: What does proportional control do with the error?
