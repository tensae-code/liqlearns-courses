# Lesson plan — Downloading Minecraft Hour of Code to Work Offline

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** Downloading Minecraft Hour of Code to Work Offline
**Place in the curriculum:** ICT expansion — Palestine (2026-11-14) — in the title Programming on the ICT course ladder (TITLES.md). Built new from Palestine's Grade 5 Programming student book, because no existing lesson in the course covers this thing as its own lesson.
**The one thing this lesson teaches:** Palestine’s first programming step is getting the tool: the Minecraft Hour of Code adventures are downloaded so the class can code with no internet at all — download once, then every puzzle works offline.
**This lesson's own level:** It stands on the earlier lessons of its title and on the book's own order — it follows the book's lessons in sequence, so its neighbours in the book are its natural companions. It stands alone for a learner landing on it directly.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Downloading the adventures to the computer** — The Grade 5 book opens by **downloading Minecraft (Hour of Code)** to the computer. The adventures come from **code.org’s Hour of Code**, packed so they can be saved once and opened again without a connection. Downloading is treated as part of programming itself: a programmer first makes sure the tool is on the machine and working.
2. **Working offline — plan, run, check** — With the adventures on the computer, the class works **offline**: each puzzle is planned on **squared paper**, run in the adventure, and checked against the **success screen**. No connection is needed at any step — the download at the start is what makes the whole book’s offline way of working possible.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
