# Hands-on — Downloading Minecraft Hour of Code to Work Offline

The lesson with your hands and your feet, not only your eyes.

## Download and open
Download the Minecraft Hour of Code adventures (or open them where they are already saved) and start the first adventure with no internet connection.

## Plan on paper first
Before touching the blocks, draw the first puzzle’s plan on squared paper, then run it and check it against the success screen.
