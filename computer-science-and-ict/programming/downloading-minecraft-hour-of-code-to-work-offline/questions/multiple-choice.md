# Downloading Minecraft Hour of Code to Work Offline — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is downloaded at the start of the Grade 5 course?**
a) The Minecraft Hour of Code adventures  b) Code.org’s Hour of Code  c) The whole adventure pack, saved on the computer  d) Squared paper
**Answer: a) The Minecraft Hour of Code adventures**

**2. (Sub lesson 1) Where do the adventures come from?**
a) So the class can code with no internet  b) Code.org’s Hour of Code  c) An offline course — download once, work offline  d) The success screen
**Answer: b) Code.org’s Hour of Code**

**3. (Sub lesson 1) Why are the adventures downloaded first?**
a) The whole adventure pack, saved on the computer  b) Squared paper  c) So the class can code with no internet  d) No — no connection is needed at any step
**Answer: c) So the class can code with no internet**

**4. (Sub lesson 1) What is downloaded once and then used?**
a) An offline course — download once, work offline  b) The success screen  c) The download at the start  d) The whole adventure pack, saved on the computer
**Answer: d) The whole adventure pack, saved on the computer**

**5. (Sub lesson 1) What kind of book is the Grade 5 Programming book working from?**
a) An offline course — download once, work offline  b) Squared paper  c) No — no connection is needed at any step  d) Steve and Alex
**Answer: a) An offline course — download once, work offline**

**6. (Sub lesson 2) What is each puzzle planned on first?**
a) The success screen  b) Squared paper  c) The download at the start  d) The Minecraft Hour of Code adventures
**Answer: b) Squared paper**

**7. (Sub lesson 2) What is the plan checked against after running?**
a) No — no connection is needed at any step  b) Steve and Alex  c) The success screen  d) Code.org’s Hour of Code
**Answer: c) The success screen**

**8. (Sub lesson 2) Does working offline need a connection at each step?**
a) The download at the start  b) The Minecraft Hour of Code adventures  c) So the class can code with no internet  d) No — no connection is needed at any step
**Answer: d) No — no connection is needed at any step**

**9. (Sub lesson 2) What makes the offline way of working possible?**
a) The download at the start  b) Steve and Alex  c) Code.org’s Hour of Code  d) The whole adventure pack, saved on the computer
**Answer: a) The download at the start**

**10. (Sub lesson 2) Who do the block bricks guide in the adventures?**
a) The Minecraft Hour of Code adventures  b) Steve and Alex  c) So the class can code with no internet  d) An offline course — download once, work offline
**Answer: b) Steve and Alex**
