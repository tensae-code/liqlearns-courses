# Video script — The General Process of Data Processing

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Data processing is a journey with stages.
First, a question. Then collect the data.
Organise it. Clean it. Make it ready.
Analyse it — totals, patterns, comparisons.
Present it, so people can see. Report it, so people can act.
Skip a stage, and every later stage suffers.
