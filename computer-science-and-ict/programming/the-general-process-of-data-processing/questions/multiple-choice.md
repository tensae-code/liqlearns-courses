# The General Process of Data Processing — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) The first thing the process needs, before any collection, is —**
a) a chart  b) a purpose — the question the data must answer  c) a bigger computer  d) a report title
**Answer: b) a purpose — the question the data must answer** — The question decides what data is worth having.

**2. (Sub lesson 1) Data straight from collection is usually —**
a) ready to analyse  b) a heap: mixed formats, missing entries, duplicates, mistakes  c) already a report  d) perfect
**Answer: b) a heap: mixed formats, missing entries, duplicates, mistakes** — Organising and cleaning make it ready.

**3. (Sub lesson 2) Presentation matters because —**
a) charts are pretty  b) findings nobody can see persuade nobody — the display is part of the answer  c) teachers require it  d) numbers are banned
**Answer: b) findings nobody can see persuade nobody — the display is part of the answer** — Analysis must become visible to be believed.

**4. (Sub lesson 2) Dirty data damages the process because —**
a) it looks untidy  b) analysis built on it produces wrong answers, however good the tools  c) it takes longer to print  d) files get bigger
**Answer: b) analysis built on it produces wrong answers, however good the tools** — Each stage inherits the damage of the one before.

**5. (Sub lesson 2) The last stage of the process is —**
a) collection  b) cleaning  c) applying the results and reporting them  d) sampling
**Answer: c) applying the results and reporting them** — A report nobody applies was effort wasted.
