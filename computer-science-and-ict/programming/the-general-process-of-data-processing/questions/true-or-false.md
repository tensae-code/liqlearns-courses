# The General Process of Data Processing — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) The stages of data processing can be done in any order without harm.**
**Answer: False** — Each stage depends on the one before it.

**2. (Sub lesson 1) Collection is guided by the question the data must answer.**
**Answer: True** — Purpose comes first and decides what is worth gathering.

**3. (Sub lesson 2) A beautifully analysed result still fails if nobody presents or applies it.**
**Answer: True** — Invisible findings persuade nobody; unapplied reports waste the journey.
