# Hands-on — Subrange Types in Pascal — and the void Type in C++

The lesson with your hands and your feet, not only your eyes.

## Task one
**Guard translation** — Take a Pascal subrange example and write its C++ version with explicit checks, stating what protection was lost and regained.

## Task two
**Void reading** — In three C++ function headings (void, int, double), say which return values, and match each to its Pascal form — procedure or function.
