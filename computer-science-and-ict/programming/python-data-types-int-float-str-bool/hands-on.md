# Hands-on - Python data types - int, float, str, bool

The lesson with your hands, not only your eyes.

## Type sort

Value cards - 7, -3, 3.14, 2.5, "Selam", "Addis", True, False - are sorted under four type headings. A checker pupil reads type() answers from the lesson to settle disputes.

## Three divisions

Pairs compute 17 / 5, 17 // 5 and 17 % 5 on paper three ways - as a fraction-keeping division, a whole-part division and a remainder hunt (17 counters shared by 5: how many left over?). The three answers - 3.4, 3, 2 - are matched to their operators.
