# Lesson plan - Python data types - int, float, str, bool

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** Python data types - int, float, str, bool
**Place in the curriculum:** Unit 6 - Fundamentals of Programming (CURRICULUM.md).
**The one thing this lesson teaches:** a data type classifies what values a variable can hold and what operations apply; Python's four taught types are int, float, str and bool, a variable takes its type from the assigned value, type() reveals it, and reassignment can change it entirely.
**This lesson's own level:** it stands on it stands on Identifiers - the rules for naming variables: named variables hold values, and every value has a type. It needs nothing else.

## Sub lessons
The parts of this lesson, in order - the list the learner sees from the start, locked ahead, each opening when the one before it is proved (the gate: README, "Units, Lessons and Sub Lessons (ruled 2026-11-08)"):

1. **int and float - the number types** - int holds whole numbers and float holds decimal numbers, both with the arithmetic operators +, -, /, // floor division, * , % modulus and ** exponentiation; / keeps the fraction, // returns only the whole part, % returns the remainder.
2. **str - text, joined with +** - str is a sequence of characters in quotation marks; its + joins strings - concatenation - where for numbers + adds.
3. **bool - True or False** - bool holds True or False, worked with and, or and not.
4. **type() - and a variable changing type** - A variable takes its type from the value assigned; type() reveals it; a variable can change type entirely when reassigned a value of another type.

Gate pool: all questions of the sub lesson - no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## What the learner can do when it ends
1. Say what a data type decides, and how a variable gets its type.
2. Name the four types and give an example value of each.
3. Use each type's operators - including //, % and ** for numbers, + for joining strings, and and/or/not for bool.
4. Reveal a type with type(), and explain how reassignment can change a variable's type.

## If the learner is stuck
- Expects // to round -> floor division returns only the whole part of the quotient; it drops the fraction, it does not round.
- Expects "5" + "3" to give 8 -> on strings + concatenates: "5" + "3" is "53". Type decides what + does.
