# Python data types - int, float, str, bool - multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A data type classifies -
a) the variable's name  b) what values a variable can hold and what operations apply  c) the file's size  d) the screen's colour
**Answer: b) what values a variable can hold and what operations apply** - type decides both the values and the operations.

**2. (Sub lesson 1)** Which value is a float?
a) 7  b) -3  c) 3.14  d) "3.14"
**Answer: c) 3.14** - a decimal number - in quotes it would be a str.

**3. (Sub lesson 1)** 7 // 2 gives -
a) 3.5  b) 3  c) 1  d) 14
**Answer: b) 3** - floor division returns only the whole part.

**4. (Sub lesson 1)** 7 % 2 gives -
a) 3.5  b) 3  c) 1  d) 0
**Answer: c) 1** - modulus returns the remainder.

**5. (Sub lesson 2)** A str is -
a) a whole number  b) a sequence of characters in quotation marks  c) True or False  d) a decimal
**Answer: b) a sequence of characters in quotation marks** - text, held in quotes.

**6. (Sub lesson 2)** "Sel" + "am" gives -
a) an error  b) "Selam" - the strings are joined  c) 0  d) "amSel"
**Answer: b) "Selam" - the strings are joined** - + concatenates strings; it adds only numbers.

**7. (Sub lesson 3)** A bool value is -
a) 7 or 3.14  b) True or False  c) any text  d) a remainder
**Answer: b) True or False** - exactly two values, with and, or, not.

**8. (Sub lesson 4)** type(x) after x = 7 reports -
a) float  b) str  c) int  d) bool
**Answer: c) int** - a variable takes its type from the assigned value.
