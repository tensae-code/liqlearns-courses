# Python data types - int, float, str, bool - true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** / keeps the fraction of a division, while // returns only the whole part.
**Answer: True** - 7 / 2 is 3.5; 7 // 2 is 3.

**2. (Sub lesson 2)** + always adds, whatever the type.
**Answer: False** - on strings, + joins - concatenation.

**3. (Sub lesson 4)** A variable can change type entirely when it is reassigned a value of another type.
**Answer: True** - x = 7 then x = "Selam" makes x a str.

**4. (Sub lesson 3)** The bool operators are and, or and not.
**Answer: True** - bool's whole operator set.
