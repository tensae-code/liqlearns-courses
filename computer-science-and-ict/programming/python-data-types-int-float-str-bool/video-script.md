# Video script - Python data types - int, float, str, bool

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.
A short video script for this lesson; its placement names no full-script need.

---

Every value has a type.
The type says what the value is - and what you may do with it.

int. Whole numbers. 7. 42.
float. Decimals. 3.14.
Numbers divide three ways:
slash keeps the fraction - 3.5.
double slash keeps only the whole part - 3.
percent gives the remainder - 1.

str. Text in quotes. "Selam".
Plus JOINS text. It does not add it.

bool. True. False.
Worked with and, or, not.

And type() tells you the truth about any value.
Assign a new kind of value - and the type changes with it.
