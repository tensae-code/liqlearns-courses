# The Systems Life Cycle — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is the systems life cycle?**
a) The ordered life of an information system from first idea to old age, in six phases  b) Preliminary investigation; systems analysis; system design; system development; system implementation; system maintenance  c) Is there a problem, and is a new system worth it?  d) Exactly what must the new system do?
**Answer: a) The ordered life of an information system from first idea to old age, in six phases**

**2. (Sub lesson 1) Name the six phases in order.**
a) Is there a problem, and is a new system worth it?  b) Preliminary investigation; systems analysis; system design; system development; system implementation; system maintenance  c) Exactly what must the new system do?  d) How will it do it?
**Answer: b) Preliminary investigation; systems analysis; system design; system development; system implementation; system maintenance**

**3. (Sub lesson 1) What question does Phase 1 answer?**
