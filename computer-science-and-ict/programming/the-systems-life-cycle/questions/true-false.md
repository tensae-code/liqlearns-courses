# The Systems Life Cycle — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is the systems life cycle?" is: The ordered life of an information system from first idea to old age, in six phases**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Name the six phases in order." is: Is there a problem, and is a new system worth it?**
**Answer: False** — Preliminary investigation; systems analysis; system design; system development; system implementation; system maintenance

**3. (Sub lesson 1) True or false: the answer to "What question does Phase 1 answer?" is: Is there a problem, and is a new system worth it?**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What question does Phase 2 answer?" is: How will it do it?**
**Answer: False** — Exactly what must the new system do?

**5. (Sub lesson 1) True or false: the answer to "What question does Phase 3 answer?" is: How will it do it?**
**Answer: True**

**6. (Sub lesson 1) True or false: the answer to "What do Phases 4 and 5 do?" is: Keeps the system true as the world changes**
**Answer: False** — Phase 4 builds the system; Phase 5 puts it to work

**7. (Sub lesson 2) True or false: the answer to "What does Phase 6 do?" is: Keeps the system true as the world changes**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Why is it a cycle, not a line?" is: The Viti Group of Companies — one furniture company's system**
**Answer: False** — Maintenance's changes — and the problems it cannot fix — start a new investigation; the wheel turns again

**9. (Sub lesson 2) True or false: the answer to "Which case carries the journey in Fiji's book?" is: The Viti Group of Companies — one furniture company's system**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What alternatives stand at the cycle's side?" is: The ordered life of an information system from first idea to old age, in six phases**
**Answer: False** — Prototyping and rapid application development
