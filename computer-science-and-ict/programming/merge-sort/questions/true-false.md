# Merge Sort — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Split the list down to single items, then merge the pieces back in order**
**Answer: True**

**2. (Sub lesson 1) True or false: Split the list down to single items, then merge the pieces back in order** — as the answer to: When does splitting stop?
**Answer: False — When every piece holds one item**

**3. (Sub lesson 1) True or false: A single item has nothing out of order**
**Answer: True**

**4. (Sub lesson 1) True or false: A single item has nothing out of order** — as the answer to: How much comparing happens during splitting?
**Answer: False — None — splitting is pure division**

**5. (Sub lesson 1) True or false: Divide and conquer**
**Answer: True**

**6. (Sub lesson 2) True or false: Divide and conquer** — as the answer to: How does a merge proceed?
**Answer: False — Repeatedly take the smaller of the two pieces' front items**

**7. (Sub lesson 2) True or false: The other piece's remaining items follow in order**
**Answer: True**

**8. (Sub lesson 2) True or false: The other piece's remaining items follow in order** — as the answer to: Why is the joined list sorted?
**Answer: False — Each half was sorted, and the merge never takes a larger front while a smaller one waits**

**9. (Sub lesson 2) True or false: About n log n — log n levels of splitting, everything merged once per level**
**Answer: True**

**10. (Sub lesson 2) True or false: About n log n — log n levels of splitting, everything merged once per level** — as the answer to: What must the two pieces be before merging?
**Answer: False — Each already sorted**
