# Operators in Scratch — Arithmetic, Comparison and Text — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What arithmetic does the operations lesson list first?**
a) Addition, subtraction, multiplication and division  b) Remainder, rounding and square root  c) It joins pieces into one string  d) It accumulates each new value
**Answer: a) Addition, subtraction, multiplication and division**

**2. (Sub lesson 1) What three extra arithmetic operations are named?**
a) True or false  b) Remainder, rounding and square root  c) Inside say blocks, so the sprite speaks the answer  d) Mean = sum ÷ count
**Answer: b) Remainder, rounding and square root**

**3. (Sub lesson 1) What do comparisons answer?**
a) It joins pieces into one string  b) It accumulates each new value  c) True or false  d) A count of how many values came
**Answer: c) True or false**

**4. (Sub lesson 1) What does joining do to text?**
a) Inside say blocks, so the sprite speaks the answer  b) Mean = sum ÷ count  c) Joined with words  d) It joins pieces into one string
