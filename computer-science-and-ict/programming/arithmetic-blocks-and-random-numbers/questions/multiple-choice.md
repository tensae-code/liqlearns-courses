# Arithmetic Blocks and Random Numbers — multiple choice

Pick the one right answer.

**1. Arithmetic blocks belong to Scratch's —**
a) operator blocks  b) looks blocks  c) sound blocks
**Answer: a) operator blocks**

**2. The answer of an arithmetic block can —**
a) never be used  b) only be printed on paper  c) go into another block, like a move
**Answer: c) go into another block, like a move**

**3. A random block picks a number —**
a) outside its limits  b) by chance, between two limits you set  c) always the same one
**Answer: b) by chance, between two limits you set**

**4. Given a random block from 1 to 6, the answer must be —**
a) between 1 and 6  b) always 6  c) any number at all
**Answer: a) between 1 and 6**
