# Arithmetic Blocks and Random Numbers — short answer

Answer in a sentence or two.

**1. Explain, in your own words: build an arithmetic block and say its answer before running.**
**Answer:** The learner's own explanation, true to the lesson: Operator blocks do arithmetic inside a program — add, subtract, multiply, divide — and a random block picks a number by chance, so a program can count and can surprise.

**2. A classmate gets this lesson's work wrong. What is the most likely fault, and how is it fixed?**
**Answer:** Answer surprises you → the block order is wrong: arithmetic reads like sums — check which two numbers the block holds, and whether a block inside a block must be answered first.
