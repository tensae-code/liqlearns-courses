# Arithmetic Blocks and Random Numbers — true or false

Say whether each statement is true or false.

**1. Build an arithmetic block and say its answer before running.**
**Answer: True** — This is one of the lesson's own outcomes.

**2. A random block from 1 to 6 can answer 9 if the program really needs it.**
**Answer: False** — The lesson teaches the opposite of this.

**3. Put an arithmetic answer to work inside another block.**
**Answer: True** — This is one of the lesson's own outcomes.
