# What Programming Is — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a program?" is: A set of instructions a computer carries out in order**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Does a computer do more than its instructions say?" is: The work of producing instructions a machine can follow**
**Answer: False** — No — exactly what they say, no more, no less

**3. (Sub lesson 1) True or false: the answer to "What three qualities must instructions have?" is: Complete, precise and in the right order**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is a missing or vague step?" is: The worked-out solution method, step by step**
**Answer: False** — An error — the machine cannot guess

**5. (Sub lesson 1) True or false: the answer to "What is programming?" is: The work of producing instructions a machine can follow**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What comes first in programming?" is: It is run and checked**
**Answer: False** — Understanding the problem

**7. (Sub lesson 2) True or false: the answer to "What is an algorithm?" is: The worked-out solution method, step by step**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "After the algorithm, what is written?" is: A set of instructions a computer carries out in order**
**Answer: False** — The program, in a programming language

**9. (Sub lesson 2) True or false: the answer to "What happens after writing the program?" is: It is run and checked**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Which language does North Macedonia's course move into?" is: Complete, precise and in the right order**
**Answer: False** — C++
