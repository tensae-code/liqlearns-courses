# What Programming Is — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a program?**
a) A set of instructions a computer carries out in order  b) No — exactly what they say, no more, no less  c) Complete, precise and in the right order  d) An error — the machine cannot guess
**Answer: a) A set of instructions a computer carries out in order**

**2. (Sub lesson 1) Does a computer do more than its instructions say?**
a) Complete, precise and in the right order  b) No — exactly what they say, no more, no less  c) An error — the machine cannot guess  d) The work of producing instructions a machine can follow
**Answer: b) No — exactly what they say, no more, no less**

**3. (Sub lesson 1) What three qualities must instructions have?**
a) An error — the machine cannot guess  b) The work of producing instructions a machine can follow  c) Complete, precise and in the right order  d) Understanding the problem
**Answer: c) Complete, precise and in the right order**

**4. (Sub lesson 1) What is a missing or vague step?**
a) The work of producing instructions a machine can follow  b) Understanding the problem  c) The worked-out solution method, step by step  d) An error — the machine cannot guess
**Answer: d) An error — the machine cannot guess**

**5. (Sub lesson 1) What is programming?**
a) The work of producing instructions a machine can follow  b) Understanding the problem  c) The worked-out solution method, step by step  d) The program, in a programming language
**Answer: a) The work of producing instructions a machine can follow**

**6. (Sub lesson 2) What comes first in programming?**
a) The worked-out solution method, step by step  b) Understanding the problem  c) The program, in a programming language  d) It is run and checked
**Answer: b) Understanding the problem**

**7. (Sub lesson 2) What is an algorithm?**
a) The program, in a programming language  b) It is run and checked  c) The worked-out solution method, step by step  d) C++
**Answer: c) The worked-out solution method, step by step**

**8. (Sub lesson 2) After the algorithm, what is written?**
a) It is run and checked  b) C++  c) A set of instructions a computer carries out in order  d) The program, in a programming language
**Answer: d) The program, in a programming language**

**9. (Sub lesson 2) What happens after writing the program?**
a) It is run and checked  b) C++  c) A set of instructions a computer carries out in order  d) No — exactly what they say, no more, no less
**Answer: a) It is run and checked**

**10. (Sub lesson 2) Which language does North Macedonia's course move into?**
a) A set of instructions a computer carries out in order  b) C++  c) No — exactly what they say, no more, no less  d) Complete, precise and in the right order
**Answer: b) C++**
