**1. (Sub lesson 1) What is a runtime error?**
a) A fault that appears while the program executes, when the data breaks an operation  b) Division by zero; a file that is not there (also root of a negative, value too large for its type)  c) Syntax is caught by the translator before the run; runtime appears in the run  d) A logic error runs quietly to a wrong answer; a runtime error stops the run
