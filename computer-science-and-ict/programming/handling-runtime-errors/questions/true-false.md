# Handling Runtime Errors — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A fault that appears while the program executes, when the data breaks an operation**
**Answer: True**

**2. (Sub lesson 1) True or false: Syntax is caught by the translator before the run; runtime appears in the run** — as the answer to: Name two runtime errors.
**Answer: False — Division by zero; a file that is not there (also root of a negative, value too large for its type)**

**3. (Sub lesson 1) True or false: Syntax is caught by the translator before the run; runtime appears in the run**
**Answer: True**

**4. (Sub lesson 1) True or false: Abnormal termination** — as the answer to: How does it differ from a logic error?
**Answer: False — A logic error runs quietly to a wrong answer; a runtime error stops the run**

**5. (Sub lesson 1) True or false: Abnormal termination**
**Answer: True**

**6. (Sub lesson 2) True or false: Divisor not zero; file exists; value in range** — as the answer to: What does handling mean?
**Answer: False — Building the program's answer before the blow lands — check the dangerous data first**

**7. (Sub lesson 2) True or false: Divisor not zero; file exists; value in range**
**Answer: True**

**8. (Sub lesson 2) True or false: Every operation that can break on data must be met by its check** — as the answer to: What roads may the program take when a check fails?
**Answer: False — A message naming the trouble, a fresh chance to input, a safe ending**

**9. (Sub lesson 2) True or false: Every operation that can break on data must be met by its check**
**Answer: True**

**10. (Sub lesson 2) True or false: A fault that appears while the program executes, when the data breaks an operation** — as the answer to: Which chapter teaches it?
**Answer: False — Greece Grade 12 Anaptyxi Efarmogon, Chapter 13**
