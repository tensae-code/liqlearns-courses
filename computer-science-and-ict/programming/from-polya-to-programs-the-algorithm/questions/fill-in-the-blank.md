# From Polya to programs — the algorithm — fill

Fill each blank with the right word or words.

**1.** _____ is understand the problem, develop an algorithm, write the program, test the program. (Name the term.)
**Answer: the computing steps**

**2.** _____ is each instruction means exactly one thing — no gaps to fall into. (Name the term.)
**Answer: unambiguous**

**3.** _____ is an algorithm ends — it does not run forever. (Name the term.)
**Answer: finite**

**4.** An algorithm transforms ______ into output.
**Answer: input**

**5.** One definition calls an algorithm a ______ step-by-step procedure.
**Answer: finite**
