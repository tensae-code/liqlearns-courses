# From Polya to programs — the algorithm — multiple choice

Pick the one right answer.

**1.** What is an algorithm?
a) a finite set of unambiguous instructions with a clear start and end — a precise sequence for solving a problem  b) understand the problem, develop an algorithm, write the program, test the program  c) each instruction means exactly one thing — no gaps to fall into  d) an algorithm ends — it does not run forever
**Answer: a) a finite set of unambiguous instructions with a clear start and end — a precise sequence for solving a problem**

**2.** What is the computing steps?
a) a finite set of unambiguous instructions with a clear start and end — a precise sequence for solving a problem  b) each instruction means exactly one thing — no gaps to fall into  c) an algorithm ends — it does not run forever  d) understand the problem, develop an algorithm, write the program, test the program
**Answer: d) understand the problem, develop an algorithm, write the program, test the program**

**3.** What is unambiguous?
a) understand the problem, develop an algorithm, write the program, test the program  b) an algorithm ends — it does not run forever  c) each instruction means exactly one thing — no gaps to fall into  d) a finite set of unambiguous instructions with a clear start and end — a precise sequence for solving a problem
**Answer: c) each instruction means exactly one thing — no gaps to fall into**

**4.** What is finite?
a) each instruction means exactly one thing — no gaps to fall into  b) an algorithm ends — it does not run forever  c) a finite set of unambiguous instructions with a clear start and end — a precise sequence for solving a problem  d) understand the problem, develop an algorithm, write the program, test the program
**Answer: b) an algorithm ends — it does not run forever**

**5.** Which Polya step changes in the computing version?
a) understand  b) make a plan becomes develop an algorithm  c) execute  d) review
**Answer: b) make a plan becomes develop an algorithm**

**6.** Instructions that could mean two different things fail the algorithm test of being —
a) finite  b) unambiguous  c) written  d) numbered
**Answer: b) unambiguous**
