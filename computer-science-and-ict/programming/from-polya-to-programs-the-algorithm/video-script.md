This is **From Polya to programs — the algorithm**.

**an algorithm** — a finite set of unambiguous instructions with a clear start and end — a precise sequence for solving a problem.

**the computing steps** — understand the problem, develop an algorithm, write the program, test the program.

**unambiguous** — each instruction means exactly one thing — no gaps to fall into.

**finite** — an algorithm ends — it does not run forever.

Now you try. Say each word. Say what it means.
