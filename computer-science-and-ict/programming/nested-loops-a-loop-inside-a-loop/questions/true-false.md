# Nested Loops — a Loop Inside a Loop — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: One loop placed inside another loop's body**
**Answer: True**

**2. (Sub lesson 1) True or false: 12 times — 3 multiplied by 4** — as the answer to: State the governing law.
**Answer: False — The inner loop runs to completion for every single turn of the outer loop**

**3. (Sub lesson 1) True or false: 12 times — 3 multiplied by 4**
**Answer: True**

**4. (Sub lesson 1) True or false: For inside for — rows by the outer, columns by the inner** — as the answer to: Name the two family forms taught.
**Answer: False — While inside while, and for inside for**

**5. (Sub lesson 1) True or false: For inside for — rows by the outer, columns by the inner**
**Answer: True**

**6. (Sub lesson 2) True or false: The multiplication table** — as the answer to: How are nested loops read?
**Answer: False — By tracing both counters — the outer's turn, then the inner's whole run beneath it**

**7. (Sub lesson 2) True or false: The multiplication table**
**Answer: True**

**8. (Sub lesson 2) True or false: It closes Grade 10 Term 1's loops lesson (Lesson 5)** — as the answer to: Name the shape of job a nested loop answers.
**Answer: False — 'For each row, for each thing in the row' — timetables, seating plans, star patterns**

**9. (Sub lesson 2) True or false: It closes Grade 10 Term 1's loops lesson (Lesson 5)**
**Answer: True**

**10. (Sub lesson 2) True or false: One loop placed inside another loop's body** — as the answer to: Which book teaches this?
**Answer: False — Kuwait Grade 10 Information Technology Term 1, Unit 2 Lesson 5 — Loops**
