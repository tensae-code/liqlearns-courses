# Indentation in Python — spaces that mean something — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** After an if expression, Python requires —
a) brackets  b) a colon  c) a semicolon
**Answer: b) b) a colon**

**2. (Sub lesson 1)** Parentheses around the if expression in Python are —
a) required  b) forbidden  c) optional
**Answer: c) c) optional**

**3. (Sub lesson 2)** Indentation in Python —
a) is only for readability  b) indicates a block of code  c) is ignored
**Answer: b) b) indicates a block of code**

**4. (Sub lesson 2)** The minimum indentation is —
a) one space  b) eight spaces  c) one tab only
**Answer: a) a) one space** — At least one space.

**5. (Sub lesson 2)** Lines in the same block with different numbers of spaces —
a) are fine  b) cause an error  c) run faster
**Answer: b) b) cause an error**

**6. (Sub lesson 2)** A branching program fails; the usual culprit is —
a) the monitor  b) indentation  c) the file name
**Answer: b) b) indentation** — Teacher-keyed diagnosis.
