# Hands-on — Indentation in Python — spaces that mean something

The lesson with your hands, not only your eyes — every activity is done for real, in IDLE or on paper.

## Ruler lines
Write a program on lined paper with a ruler marking the left edge of each block. Every line of one block must start on the same ruler line.

## Break and mend
Swap programs with a partner. Each partner secretly removes one colon or one indentation, then each must find and mend the other's fault.
