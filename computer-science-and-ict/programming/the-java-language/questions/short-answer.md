# The Java Language — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What kind of language is Java?**
**Answer: A general-purpose, high-level language**

**2. (Sub lesson 1) What are Java programs built from?**
**Answer: Classes and objects**

**3. (Sub lesson 1) What are Java programs compiled to?**
**Answer: Bytecode — an in-between code, not one machine's code**

**4. (Sub lesson 1) What does bytecode run on?**
**Answer: The Java Virtual Machine (JVM)**

**5. (Sub lesson 2) What does the JVM pretend to be?**
**Answer: A standard computer, installed on real computers of every kind**

**6. (Sub lesson 2) What is Java's famous promise?**
**Answer: Write once, run anywhere**

**7. (Sub lesson 2) What is the price of that freedom?**
**Answer: A step of translation at run time**

**8. (Sub lesson 2) Where was Java met in the book's era?**
**Answer: In phones, business systems and on the web**

**9. (Sub lesson 2) What tour does Java complete?**
**Answer: The guide's language tour — languages differ in where their programs can live**

**10. (Sub lesson 1) Which source teaches this lesson?**
