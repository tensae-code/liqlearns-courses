# The Chord Method — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The straight segment joining (a, f(a)) and (b, f(b))**
**Answer: True**

**2. (Sub lesson 1) True or false: The straight segment joining (a, f(a)) and (b, f(b))** — as the answer to: What does the method take from the chord?
**Answer: False — Its crossing with the x-axis — the next estimate c**

**3. (Sub lesson 1) True or false: The end whose f has the same sign as f(c) — so the bracket keeps opposite signs**
**Answer: True**

**4. (Sub lesson 1) True or false: The end whose f has the same sign as f(c) — so the bracket keeps opposite signs** — as the answer to: What do the values add beyond signs?
**Answer: False — They accuse the nearness — the root sits nearer the end whose |f| is smaller**

**5. (Sub lesson 1) True or false: The midpoint was democracy; the chord is cross-examination**
**Answer: True**

**6. (Sub lesson 2) True or false: The midpoint was democracy; the chord is cross-examination** — as the answer to: When is the chord method fast?
**Answer: False — When the function is nearly straight across the bracket**

**7. (Sub lesson 2) True or false: One bracket end sticks — narrowing proceeds from one side only**
**Answer: True**

**8. (Sub lesson 2) True or false: One bracket end sticks — narrowing proceeds from one side only** — as the answer to: Is certainty surrendered then?
**Answer: False — No — the bracket keeps opposite signs throughout**

**9. (Sub lesson 2) True or false: When the bracket, or the step between successive c's, falls under the demanded precision**
**Answer: True**

**10. (Sub lesson 2) True or false: When the bracket, or the step between successive c's, falls under the demanded precision** — as the answer to: Against what is the chord method measured?
**Answer: False — Against bisection — faster when the slope is honest, never less certain**
