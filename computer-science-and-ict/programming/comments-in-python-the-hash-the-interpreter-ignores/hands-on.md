# Hands-on — Comments — the # that the interpreter ignores

The lesson with your hands, not only your eyes — every activity is done for real, in IDLE or on paper.

## Note cards
Write a short program on paper. On sticky notes, write one concise comment per part and stick each above its part. Read the program using only the notes — do they say what each part does?

## On/off lines
In IDLE, take a three-line program. Comment out one line at a time with #, running after each change, and record which output disappears each time.
