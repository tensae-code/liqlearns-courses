# Comments — the # that the interpreter ignores — true or false

Say True or False.

**1. (Sub lesson 1)** Anything after # on a line is ignored.
**Answer: True**

**2. (Sub lesson 2)** Commenting out code is a taught way to test parts of a program.
**Answer: True**

**3. (Sub lesson 2)** Where part of a program is commented out, the commented part still executes.
**Answer: False**

**4. (Sub lesson 1)** Comments make code more readable for humans.
**Answer: True**
