# Comments — the # that the interpreter ignores — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A comment is —
a) executed first  b) ignored by the interpreter  c) printed as output
**Answer: b) b) ignored by the interpreter**

**2. (Sub lesson 1)** Python comments are denoted by —
a) //  b) #  c) --
**Answer: b) b) #**

**3. (Sub lesson 2)** A multi-line comment needs —
a) one # at the very start only  b) every line to start with #  c) brackets
**Answer: b) b) every line to start with #**

**4. (Sub lesson 2)** A fully commented program, when run, prints —
a) the comments  b) an error  c) nothing
**Answer: c) c) nothing** — No executable statement is left — teacher-keyed.

**5. (Sub lesson 2)** A good comment is —
a) long and detailed about everything  b) concise and clear about what the part does  c) written in code
**Answer: b) b) concise and clear about what the part does** — Guide standard.

**6. (Sub lesson 1)** Comments are part of the program's execution.
a) True — they run slowly  b) False — they are not executable
**Answer: b) b) False — they are not executable**
