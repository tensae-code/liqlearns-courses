This lesson: **Comments — the # that the interpreter ignores**.

First, do it. Run the opening program. Watch what it prints.

Then the idea, in order: Descriptive text in source code; not executable, not part of the program; it explains and reminds. Single line or several lines, each starting with #; uses: describe code, improve readability, stop code running while testing. A fully commented program does nothing.

Now you. Add a describing comment above the even/odd program and run — output unchanged.

Say it to your companion: Tell your companion what a comment is, its symbol, its three uses — and what a fully commented program prints.
