# Ones and Twos Complement and Signed Binary Numbers — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) In a signed binary number, the sign is carried by —**
a) The rightmost bit  b) The leftmost (most significant) bit  c) An extra minus character  d) The number of 1s
**Answer: b) The leftmost (most significant) bit — The leftmost (most significant) bit — 0 for positive, 1 for negative.**

**2. (Sub lesson 1) The ones complement of 00000101 is —**
a) 00000110  b) 11111010  c) 11111011  d) 10000101
**Answer: b) 11111010 — 11111010 — flip every bit; adding 1 would make it the twos complement instead.**

**3. (Sub lesson 2) The twos complement is formed by —**
a) Flipping the sign bit only  b) Flipping every bit and adding 1  c) Adding the number to itself  d) Reversing the order of the bits
**Answer: b) Flipping every bit and adding 1 — Flipping every bit and adding 1 — ones complement first, then the extra 1.**
