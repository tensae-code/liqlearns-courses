# Ones and Twos Complement and Signed Binary Numbers — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Ones complement has two different patterns for zero.**
**Answer: True — 00000000 (+0) and 11111111 (−0) — one reason machines prefer twos complement.**

**2. (Sub lesson 2) In twos complement subtraction, a carry that falls beyond the register size is kept as part of the answer.**
**Answer: False — It is discarded — the register holds a fixed number of bits, and dropping the overflow carry leaves the correct answer.**
