# Graphs — Nodes and Edges — short answer

Answer in your own words, in one or two sentences.

**1. (Sub lesson 1) Why can the same graph be drawn in two completely different-looking ways?**
**Answer: Because a graph records only which nodes are joined by edges. Node positions, line lengths and shapes carry no information, so moving the nodes changes the drawing but not the graph.**

**2. (Sub lesson 2) A one-way street network — directed or undirected graph? Say why.**
**Answer: Directed. A one-way street can be travelled in one direction only, so its edges need arrows; an undirected edge would wrongly claim travel both ways.**
