# Graphs — Nodes and Edges — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) A graph must be drawn to scale, like a map.**
**Answer: False** — A graph is not a map — nodes can be moved freely; only connections must stay true.

**2. (Sub lesson 2) A node with degree 0 is connected to nobody.**
**Answer: True** — Degree 0 means no edges meet there — an island node.

**3. (Sub lesson 2) In an undirected graph, every edge works in both directions.**
**Answer: True** — Undirected edges have no arrows and run both ways.

**4. (Sub lesson 2) The length of a path counts the nodes it visits.**
**Answer: False** — Path length counts edges: Ana to Fay in the lesson visits 5 nodes along 4 edges, so its length is 4.
