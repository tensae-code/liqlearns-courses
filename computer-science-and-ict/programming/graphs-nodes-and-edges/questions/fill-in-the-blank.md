# Graphs — Nodes and Edges — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 1) Each thing in a graph is drawn as a point called a ____.**
**Answer: node**

**2. (Sub lesson 1) An edge that leaves a node and returns to the same node is a ____.**
**Answer: loop**

**3. (Sub lesson 2) The number of edges meeting at a node is its ____.**
**Answer: degree**
