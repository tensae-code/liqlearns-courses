# Graphs — Nodes and Edges — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does a graph keep, when it draws a web of relationships?**
a) The exact distances  b) Only the connections — which nodes are joined  c) The colours  d) The sizes of the places
**Answer: b) Only the connections — which nodes are joined** — A graph throws away shape and distance; connection is everything.

**2. (Sub lesson 1) In a graph, a person or place is drawn as —**
a) An edge  b) A loop  c) A node  d) A degree
**Answer: c) A node** — Each thing becomes a node, a point; relationships become edges.

**3. (Sub lesson 1) Two drawings that look different are the same graph when —**
a) They use the same colours  b) The same pairs of nodes are joined by edges  c) They are the same size  d) The nodes are in the same places
**Answer: b) The same pairs of nodes are joined by edges** — Position means nothing in a graph; only which pairs are joined matters.

**4. (Sub lesson 2) A directed edge is drawn as —**
a) A thick line  b) A dotted line  c) An arrow  d) A circle
**Answer: c) An arrow** — Directed edges are arrows: the relationship runs one way only.

**5. (Sub lesson 2) The degree of a node is —**
a) How many edges meet at it  b) How many nodes the graph has  c) The longest path  d) Its age
**Answer: a) How many edges meet at it** — Degree counts the edges at that one node.

**6. (Sub lesson 2) A path that returns to its starting node is —**
a) A loop  b) A degree  c) A cycle  d) An island
**Answer: c) A cycle** — A closed walk back to the start is a cycle.
