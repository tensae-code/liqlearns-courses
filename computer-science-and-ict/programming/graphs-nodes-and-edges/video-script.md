# Video script — Graphs — Nodes and Edges

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Some things are webs. Friends who know friends. Towns joined by roads.

A graph draws a web the tidy way. Every thing becomes a point. That point is a node.

Every connection becomes a line. That line is an edge.

Move the points around — the graph stays the same. Only the connections count.

An arrow on an edge means: this way only. No arrow means: both ways.

Count the edges at one node. That count is its degree.

Walk from node to node along the edges. That walk is a path.
