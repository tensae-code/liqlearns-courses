# Sorting Algorithms — Bogo, Insertion, Selection, Bubble, Quick — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) Name the five sorts.** → **Stupid (bogo), insertion, selection, bubble, quick**

**2. (Sub lesson 1) How does insertion sort grow order?** → **Card by card, slotting each new card into the sorted hand**

**3. (Sub lesson 1) What does selection sort repeatedly pick?** → **The smallest remaining**

**4. (Sub lesson 1) What does bubble sort compare and swap?** → **Neighbours, pass after pass**

**5. (Sub lesson 1) Around what does quick sort partition?** → **A pivot**

**6. (Sub lesson 2) What is a sorting network?** → **Fixed rows of comparators that sort in parallel, whatever the input**

**7. (Sub lesson 2) What is the honest answer to ‘which sort is best’?** → **It depends**

**8. (Sub lesson 2) Name two things it depends on.** → **The number of items; how scrambled they already are (also: what a comparison costs)**

**9. (Sub lesson 2) What superstition does plurality vaccinate against?** → **That every problem has exactly one method with exactly one shape**

**10. (Sub lesson 2) What is a comparator in a network?** → **One fixed compare-and-maybe-swap station**
