# Sorting Algorithms — Bogo, Insertion, Selection, Bubble, Quick — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Stupid (bogo), insertion, selection, bubble, quick**
**Answer: True**

**2. (Sub lesson 1) True or false: Stupid (bogo), insertion, selection, bubble, quick** — as the answer to: How does insertion sort grow order?
**Answer: False — Card by card, slotting each new card into the sorted hand**

**3. (Sub lesson 1) True or false: The smallest remaining**
**Answer: True**

**4. (Sub lesson 1) True or false: The smallest remaining** — as the answer to: What does bubble sort compare and swap?
**Answer: False — Neighbours, pass after pass**

**5. (Sub lesson 1) True or false: A pivot**
**Answer: True**

**6. (Sub lesson 2) True or false: A pivot** — as the answer to: What is a sorting network?
**Answer: False — Fixed rows of comparators that sort in parallel, whatever the input**

**7. (Sub lesson 2) True or false: It depends**
**Answer: True**

**8. (Sub lesson 2) True or false: It depends** — as the answer to: Name two things it depends on.
**Answer: False — The number of items; how scrambled they already are (also: what a comparison costs)**

**9. (Sub lesson 2) True or false: That every problem has exactly one method with exactly one shape**
**Answer: True**

**10. (Sub lesson 2) True or false: That every problem has exactly one method with exactly one shape** — as the answer to: What is a comparator in a network?
**Answer: False — One fixed compare-and-maybe-swap station**
