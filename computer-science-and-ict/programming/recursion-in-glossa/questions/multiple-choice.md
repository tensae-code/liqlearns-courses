# Recursion in ΓΛΩΣΣΑ — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is recursion in ΓΛΩΣΣΑ?**
a) A procedure or function that calls itself  b) A fresh run with its own parameters and local names, stacked on the unfinished calls  c) A stopping case — a call that answers without calling again  d) Move closer to the stopping case
**Answer: a**

**2. (Sub lesson 1) What is each call?**
a) A stopping case — a call that answers without calling again  b) A fresh run with its own parameters and local names, stacked on the unfinished calls  c) Move closer to the stopping case  d) The calls never end and the program fails
**Answer: b**

**3. (Sub lesson 1) What must every recursive subprogram have?**
a) Move closer to the stopping case  b) The calls never end and the program fails  c) A stopping case — a call that answers without calling again  d) On paper, call by call — calls going down, answers coming up
**Answer: c**

**4. (Sub lesson 1) What must every self-call do?**
