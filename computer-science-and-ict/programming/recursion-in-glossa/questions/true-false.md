# Recursion in ΓΛΩΣΣΑ — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A procedure or function that calls itself**
**Answer: True**

**2. (Sub lesson 1) True or false: A stopping case — a call that answers without calling again** — as the answer to: What is each call?
**Answer: False — A fresh run with its own parameters and local names, stacked on the unfinished calls**

**3. (Sub lesson 1) True or false: A stopping case — a call that answers without calling again**
**Answer: True**

**4. (Sub lesson 1) True or false: The calls never end and the program fails** — as the answer to: What must every self-call do?
**Answer: False — Move closer to the stopping case**

**5. (Sub lesson 1) True or false: The calls never end and the program fails**
**Answer: True**

**6. (Sub lesson 2) True or false: n=1 (or 0) answers 1 without calling again** — as the answer to: How does the book trace recursion?
**Answer: False — On paper, call by call — calls going down, answers coming up**

**7. (Sub lesson 2) True or false: n=1 (or 0) answers 1 without calling again**
**Answer: True**

**8. (Sub lesson 2) True or false: Greatest common divisor (or Fibonacci numbers)** — as the answer to: What does unwinding mean?
**Answer: False — The stacked calls each finish with the answer handed back, up to the first call**

**9. (Sub lesson 2) True or false: Greatest common divisor (or Fibonacci numbers)**
**Answer: True**
