# Scratch Movement Blocks — Move, Turn and Point — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does the move block do?" is: Steps the sprite forward by the number in the block**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "In which direction does move carry the sprite?" is: The direction the sprite faces, by degrees**
**Answer: False** — The direction it faces

**3. (Sub lesson 1) True or false: the answer to "What does the turn block change?" is: The direction the sprite faces, by degrees**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What makes a longer walk?" is: Add up its steps and turns and say where the sprite will end**
**Answer: False** — A bigger move number

**5. (Sub lesson 1) True or false: the answer to "What should you do before running a movement script?" is: Add up its steps and turns and say where the sprite will end**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does point do?" is: So the move goes the chosen way**
**Answer: False** — Sets the sprite's direction at once

**7. (Sub lesson 2) True or false: the answer to "Why is direction set before a move?" is: So the move goes the chosen way**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does glide do?" is: A slower journey**
**Answer: False** — Moves the sprite smoothly to a place over a number of seconds

**9. (Sub lesson 2) True or false: the answer to "What does a longer glide time mean?" is: A slower journey**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is the order this lesson teaches?" is: Steps the sprite forward by the number in the block**
**Answer: False** — Face the right way first, then travel
