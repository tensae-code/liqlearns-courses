# Hands-on — The do-while Loop

The lesson with your hands and your feet, not only your eyes.

## Trace it in a row
Write a do-while that prints a counter from 1 while it is below 4. Trace it in a table: run number, what printed, test result. Point at the run where the test fails.

## Validation sketch
Sketch (in words or code) a do-while that keeps asking for a number between 1 and 10 until it gets one. Label the prompt, the read, and the test.
