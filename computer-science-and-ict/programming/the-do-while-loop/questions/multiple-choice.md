# The do-while Loop — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) When is the condition tested in do-while?**
a) After the body has run  b) At least once  c) The first test that comes out false  d) A semicolon
**Answer: a) After the body has run**

**2. (Sub lesson 1) How many times does the body always run?**
a) The first test that comes out false  b) At least once  c) A semicolon  d) A while loop may run zero times
**Answer: b) At least once**

**3. (Sub lesson 1) What ends the loop?**
a) A semicolon  b) A while loop may run zero times  c) The first test that comes out false  d) Asking for input and validating the answer
**Answer: c) The first test that comes out false**

**4. (Sub lesson 1) What punctuation follows the while in do-while?**
a) A while loop may run zero times  b) Asking for input and validating the answer  c) While the answer is invalid  d) A semicolon
**Answer: d) A semicolon**

**5. (Sub lesson 1) How does while differ here?**
a) A while loop may run zero times  b) Asking for input and validating the answer  c) While the answer is invalid  d) Write the body's runs in a row and mark each test result
**Answer: a) A while loop may run zero times**

**6. (Sub lesson 2) What is the classic use of do-while?**
a) While the answer is invalid  b) Asking for input and validating the answer  c) Write the body's runs in a row and mark each test result  d) Something the condition depends on
**Answer: b) Asking for input and validating the answer**

**7. (Sub lesson 2) In the validation pattern, when does the loop repeat?**
a) Write the body's runs in a row and mark each test result  b) Something the condition depends on  c) While the answer is invalid  d) do-while
**Answer: c) While the answer is invalid**

**8. (Sub lesson 2) How does the book tell you to trace its tasks?**
a) Something the condition depends on  b) do-while  c) After the body has run  d) Write the body's runs in a row and mark each test result
**Answer: d) Write the body's runs in a row and mark each test result**

**9. (Sub lesson 2) What must change inside the body for the loop to end?**
a) Something the condition depends on  b) do-while  c) After the body has run  d) At least once
**Answer: a) Something the condition depends on**

**10. (Sub lesson 2) Which loop fits when work must precede any test?**
a) After the body has run  b) do-while  c) At least once  d) The first test that comes out false
**Answer: b) do-while**
