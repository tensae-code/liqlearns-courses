# Video script — Number Systems and Conversions

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

We count in tens. Ten digits: 0 to 9.

Each place is worth ten times the place before it.

A computer counts in twos. Two digits: 0 and 1.

Each 0 or 1 is called a bit. The places are worth 1, 2, 4, 8, 16.

So 1101 in binary is 8 + 4 + 1 — thirteen.

Binary numbers get long. So we write them in sixteens: hexadecimal.

Sixteen digits: 0 to 9, then A, B, C, D, E, F.

One hexadecimal digit is always exactly four bits.

To change decimal into binary: divide by 2, keep the remainders, read them backwards.

Changing the system never changes the number. Only its clothes.
