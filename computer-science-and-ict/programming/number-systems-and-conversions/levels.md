# Number Systems and Conversions — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure). Practice is tied to the learner's skill number, as before. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Decimal, binary and hexadecimal — bases and place values
Sub lesson 1 questions from the type files. Pass mark: name the base and the digits of the decimal, binary and hexadecimal systems, and work out the value of a short binary or hexadecimal number from its place values.

## Sub lesson 2 — Converting between the systems
Sub lesson 2 questions from the type files. Pass mark: convert a number each way — binary to decimal, decimal to binary, binary to hexadecimal and hexadecimal to binary — and check the answer by converting it back.
