# Number Systems and Conversions — short answer

Answer in your own words, in one or two sentences.

**1. (Sub lesson 1) Why do computers use binary instead of decimal?**
**Answer: A computer's switches have only two states, on and off, so two digits — 0 and 1 — are all the machine can hold directly; binary is the number system built on two.**

**2. (Sub lesson 2) Convert 27 to binary, showing the method.**
**Answer: Divide by 2 repeatedly: 27÷2=13 r1; 13÷2=6 r1; 6÷2=3 r0; 3÷2=1 r1; 1÷2=0 r1. Read the remainders backwards: 11011. Check: 16+8+0+2+1 = 27.**
