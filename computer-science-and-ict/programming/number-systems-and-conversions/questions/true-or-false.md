# Number Systems and Conversions — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) The place values in binary are 1, 2, 4, 8, 16 — each one double the one before.**
**Answer: True** — Binary places are powers of two, so each place is worth twice the previous one.

**2. (Sub lesson 1) Hexadecimal needs sixteen different digits, so it uses the letters A to F after 9.**
**Answer: True** — Digits 0–9 give ten; the letters A–F add the six more, for values ten to fifteen.

**3. (Sub lesson 2) When converting decimal to binary by division, the remainders are read from the first one to the last.**
**Answer: False** — The remainders are read backwards — the last remainder found is the first (leftmost) bit.

**4. (Sub lesson 2) Converting a number from binary to hexadecimal changes its value.**
**Answer: False** — Conversion only changes how the value is written; the value itself stays the same.
