# Number Systems and Conversions — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 1) The base of the hexadecimal system is ____.**
**Answer: 16** — Hexadecimal counts in sixteens.

**2. (Sub lesson 1) The binary number 1000 has the decimal value ____.**
**Answer: 8** — Only the place worth 8 carries a 1.

**3. (Sub lesson 2) To turn binary into hexadecimal, group the bits in ____ starting from the right.**
**Answer: fours** — One hexadecimal digit always stands for exactly four bits.

**4. (Sub lesson 2) Decimal 10 written in hexadecimal is the single digit ____.**
**Answer: A** — In hexadecimal the value ten is written A.
