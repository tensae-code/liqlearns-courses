# Number Systems and Conversions — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What fixes a number system — what makes decimal different from binary?**
a) Its digits are prettier  b) Its base: how many different digits it uses  c) It is older  d) It uses letters
**Answer: b) Its base: how many different digits it uses** — The base (radix) is the one choice that fixes the system: decimal has base 10, binary base 2.

**2. (Sub lesson 1) What is a bit?**
a) A group of eight digits  b) One binary digit, 0 or 1  c) The largest place value  d) A hexadecimal letter
**Answer: b) One binary digit, 0 or 1** — Each binary digit is called a bit, and it can only be 0 or 1.

**3. (Sub lesson 1) What is the decimal value of the binary number 1011?**
a) 9  b) 10  c) 11  d) 13
**Answer: c) 11** — Place values 8, 4, 2, 1: 1011 = 8 + 0 + 2 + 1 = 11.

**4. (Sub lesson 1) In hexadecimal, the letter C stands for which value?**
a) 10  b) 11  c) 12  d) 15
**Answer: c) 12** — A = 10, B = 11, C = 12, D = 13, E = 14, F = 15.

**5. (Sub lesson 2) Converting decimal 13 into binary by repeated division by 2 gives —**
a) 1011  b) 1101  c) 1110  d) 1001
**Answer: b) 1101** — 13÷2=6 r1; 6÷2=3 r0; 3÷2=1 r1; 1÷2=0 r1; remainders read backwards: 1101.

**6. (Sub lesson 2) The binary number 11111111 written in hexadecimal is —**
a) FF  b) F8  c) E7  d) 88
**Answer: a) FF** — Group in fours: 1111 = 15 = F, and 1111 again = F, so FF.
