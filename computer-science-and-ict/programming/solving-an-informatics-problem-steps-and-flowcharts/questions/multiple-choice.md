# Solving an Informatics Problem — Steps and Flowcharts — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Name the steps of solving an informatics problem in order.**
a) Understand the problem; name input and output; plan and model mathematically; build the algorithm; test it  b) The input (starting data) and the output (required result)  c) Quantities and relations a machine can work  d) A hope, not a solution
**Answer: a) Understand the problem; name input and output; plan and model mathematically; build the algorithm; test it**

**2. (Sub lesson 1) What must be named before planning?**
a) Quantities and relations a machine can work  b) The input (starting data) and the output (required result)  c) A hope, not a solution  d) Sequence, branching and loops
**Answer: b) The input (starting data) and the output (required result)**
