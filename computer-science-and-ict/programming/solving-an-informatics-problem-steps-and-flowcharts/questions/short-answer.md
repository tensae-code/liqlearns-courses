# Solving an Informatics Problem — Steps and Flowcharts — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) Name the steps of solving an informatics problem in order.**
**Answer: Understand the problem; name input and output; plan and model mathematically; build the algorithm; test it**

**2. (Sub lesson 1) What must be named before planning?**
**Answer: The input (starting data) and the output (required result)**

**3. (Sub lesson 1) What does mathematical modelling turn the situation into?**
**Answer: Quantities and relations a machine can work**

**4. (Sub lesson 1) What is an untested algorithm called in the lesson?**
**Answer: A hope, not a solution**

**5. (Sub lesson 1) Name the three control shapes drawn in flowcharts.**
**Answer: Sequence, branching and loops**

**6. (Sub lesson 2) What is a trace table?**
**Answer: A step-by-step record of each step's effect on every quantity**

**7. (Sub lesson 2) What does a trace table let you point at?**
**Answer: The exact row where the values went wrong**

**8. (Sub lesson 2) What is the flowchart, in the lesson's phrase?**
**Answer: The plan made visible**

**9. (Sub lesson 2) What is the trace table, in the lesson's phrase?**
**Answer: The plan made answerable**

**10. (Sub lesson 2) Which language follows this method in the book?**
**Answer: Microsoft Small Basic**
