# Using a Standard Library — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a standard library?**
**Answer: The ready-made collection of functions and objects that ships with the language itself**

**2. (Sub lesson 1) Does it need installing?**
**Answer: No — it ships with the language**

**3. (Sub lesson 1) Name two JavaScript shelves this chapter uses.**
**Answer: Math and Date**

**4. (Sub lesson 1) Name three Math members.**
**Answer: Math.sqrt, Math.floor, Math.random (and Math.PI)**

**5. (Sub lesson 1) By what is a library member known?**
**Answer: Its documentation — what it takes, what it returns, what it promises**

**6. (Sub lesson 2) What does Math.sqrt(81) give, and what did you write?**
**Answer: 9 — and no root-finding code at all**

**7. (Sub lesson 2) What is the first discipline of use?**
**Answer: Call the library instead of hand-writing what it already does correctly**

**8. (Sub lesson 2) What is the second?**
**Answer: Check the label before calling — know what the member promises**

**9. (Sub lesson 2) Math.floor(3.9) gives what, and why?**
**Answer: 3 — floor promises the whole number below**

**10. (Sub lesson 2) Most library 'faults' are really what?**
**Answer: Labels misread**
