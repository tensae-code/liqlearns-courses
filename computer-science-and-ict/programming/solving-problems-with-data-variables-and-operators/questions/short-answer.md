# Solving Problems with Data, Variables and Operators — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a problem read for first?**
**Answer: Its data — what arrives, what must be worked out, what is announced**

**2. (Sub lesson 1) Which type fits counts, and which fits measures and money?**
**Answer: int for counts; float for measures and money**

**3. (Sub lesson 1) What holds a value as it changes?**
**Answer: A variable, with a clear name**

**4. (Sub lesson 1) What is a constant in a segment?**
**Answer: A value the problem fixes — a rate, a passing mark — named once**

**5. (Sub lesson 1) How are constants often named?**
**Answer: In capitals — PASS_MARK = 50**

**6. (Sub lesson 2) Which operators work out quantities?**
**Answer: The arithmetic operators: + − * /**

**7. (Sub lesson 2) Which operators make decisions together?**
**Answer: Comparison operators, combined by logical operators**

**8. (Sub lesson 2) What shape does Malaysia's combined segment follow?**
**Answer: Input → process → output**

**9. (Sub lesson 2) Where does a fault in any part show up?**
**Answer: In the output**

**10. (Sub lesson 2) Why name a constant once?**
**Answer: So its fixing is visible and changing it is a one-line edit**
