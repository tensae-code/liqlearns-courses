# Solving Problems with Data, Variables and Operators

## Do it first

The parts have been learned one by one: types, variables, constants, operators. Malaysia's Grade 8 book now combines them into problem-solving code. In this lesson you put the four together — choosing types, naming storage, and letting operators do the work.

## Sub lesson 1 — Choosing and naming — types, variables, constants

A problem is first read for its **data**: what values arrive (inputs), what must be worked out, and what is announced (output). Each value gets a **type** that fits it (int for counts, float for measures and money, str for names) and a **variable** with a clear name to hold it as it changes. A value the problem fixes — a rate, a passing mark — is a **constant**, named once (often in capitals, PASS_MARK = 50) so its fixing is visible and its change, if the rules change, is a one-line edit.

## Sub lesson 2 — Operators do the work

The solving itself is **operators at work**: arithmetic operators (+ − * /) work out the quantities, comparison operators compare them against constants and other values, and logical operators combine the comparisons into decisions. Malaysia's combined segment follows the shape input → process → output: read the values in, let the operators process them into results stored in variables, then print the results. A combined segment is judged as a whole: right types, honest constants, correct operators — a fault in any one shows up in the output.
