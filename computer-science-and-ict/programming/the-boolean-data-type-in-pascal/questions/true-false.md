# The Boolean Data Type in Pascal — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Only true and false**
**Answer: True**

**2. (Sub lesson 1) True or false: Only true and false** — as the answer to: Whom is the type named for?
**Answer: False — George Boole**

**3. (Sub lesson 1) True or false: From comparisons — n > 5 works out to true or false**
**Answer: True**

**4. (Sub lesson 1) True or false: From comparisons — n > 5 works out to true or false** — as the answer to: How is a boolean variable declared?
**Answer: False — var ok: boolean;**

**5. (Sub lesson 1) True or false: It decides — if and loop conditions are made of it**
**Answer: True**

**6. (Sub lesson 2) True or false: It decides — if and loop conditions are made of it** — as the answer to: When does and give true?

**7. (Sub lesson 2) True or false: When at least one side is true**

**8. (Sub lesson 2) True or false: When at least one side is true** — as the answer to: What does not do?
**Answer: False — It flips the value — not true is false**

**9. (Sub lesson 2) True or false: age >= 18 and hasTicket**
