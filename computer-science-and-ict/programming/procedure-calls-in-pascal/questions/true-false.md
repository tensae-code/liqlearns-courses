# Procedure Calls in Pascal — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The procedure's name followed by its actual parameters in brackets**
**Answer: True**

**2. (Sub lesson 1) True or false: The procedure's name followed by its actual parameters in brackets** — as the answer to: What happens when a call executes?
**Answer: False — The values are handed over, the body runs, and control returns to the instruction after the call**

**3. (Sub lesson 1) True or false: Yes — a call to the built-in writing procedure**
**Answer: True**

**4. (Sub lesson 1) True or false: Yes — a call to the built-in writing procedure** — as the answer to: How many instructions is a call in the calling program?
**Answer: False — One — however many the called body holds**

**5. (Sub lesson 1) True or false: Actual parameters**
**Answer: True**

**6. (Sub lesson 2) True or false: Actual parameters** — as the answer to: What lets one procedure body serve many data?
**Answer: False — Different actual parameters at each call**

**7. (Sub lesson 2) True or false: A readable plan of named deeds — read, compute, print**
**Answer: True**

**8. (Sub lesson 2) True or false: A readable plan of named deeds — read, compute, print** — as the answer to: A fault inside a procedure is fixed where?
**Answer: False — Once, in its body — repairing every call at a stroke**
