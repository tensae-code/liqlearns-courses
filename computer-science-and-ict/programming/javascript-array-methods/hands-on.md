# Hands-on — JavaScript Array Methods

The lesson with your hands and your feet, not only your eyes.

## Task one
**Method match** — Write the method for each job: add a player at the end; remove the first waiting person; make a comma list of names; keep only scores ≥ 50; double every price.

## Task two
**Rewrite the loop** — Take a hand-written loop that collects the squares of an array's numbers. Rewrite it with map. Then rewrite a loop that collects only the even numbers, using filter.
