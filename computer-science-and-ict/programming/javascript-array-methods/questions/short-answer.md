# JavaScript Array Methods — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) Which method adds at the end of an array?**
**Answer: push**

**2. (Sub lesson 1) Which methods remove — and what do they return?**
**Answer: pop (from the end) and shift (from the start) — each returns the removed element**

**3. (Sub lesson 1) What can splice do that the others cannot?**
**Answer: Remove or insert at any position, not only at the ends**

**4. (Sub lesson 1) What does push return?**
**Answer: The array's new length**

**5. (Sub lesson 1) Where does Armenia keep the array methods?**
**Answer: Grade 12's closing reference section (p. 75)**

**6. (Sub lesson 2) What does join build?**
**Answer: A string from the array's elements**

**7. (Sub lesson 2) map or filter — which keeps only passing elements?**
**Answer: filter — map transforms every element into a new array**

**8. (Sub lesson 2) What does forEach do?**
**Answer: It runs a function on every element**

**9. (Sub lesson 2) Why prefer map/filter to a hand-written loop?**
**Answer: The code says what is wanted; the method does the walking — shorter and clearer**

**10. (Sub lesson 2) Which methods answer 'where is it?' and 'is it there?'**
**Answer: indexOf (the place) and includes (yes or no)**
