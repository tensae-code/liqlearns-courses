# Hands-on — Create Save Compile Link Run the C Workflow

The lesson with your hands and your feet, not only your eyes.

## Task one
**Work the book's own example** — Chapter 8 §8.2.2 Creating and Editing a C Program, §8.2.3 Saving (F2; save with the .c extension, not .cpp), §8.2.4 Compiling (source program to object program), §8.2.5 Linking (the linker joins library files into the .exe) and §8.2.6 Executing (the loader; Run Ctrl+F9; the user screen Alt+F5; setting output and source directories) Work it with the book open first, step by step, then close the book and do it again.

## Task two
**Show it to someone else** — Teach create save compile link run the c workflow to a companion in your own words, with your worked example in front of you, and answer their one question from the lesson.
