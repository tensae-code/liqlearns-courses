# Working with Data in Scratch — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What are instructions on data?**
**Answer: The blocks that set a stored value, change it and use it in a running program**

**2. (Sub lesson 1) Name three ways an instruction uses data.**
**Answer: Showing it on the stage, testing it in a condition, joining it into what a sprite says**

**3. (Sub lesson 1) What does stored data do by itself?**
**Answer: Nothing — the instructions are how a program works with it**

**4. (Sub lesson 1) What order does Sudan's book keep?**
**Answer: First dealing with data (storing), then working with data (the instructions)**

**5. (Sub lesson 1) Give two examples of data at work.**
**Answer: A score that grows when a target is caught, and a counter that ends the game at ten**

**6. (Sub lesson 2) What else can asked-for data do?**
**Answer: A name the program asked for can be used in its greeting**

**7. (Sub lesson 2) What does a project's behaviour turn on?**
**Answer: Its data — the same instructions give different runs when the values differ**

**8. (Sub lesson 2) What step is this, in the book's phrase?**
**Answer: From drawing with blocks to programming with them**

**9. (Sub lesson 2) What stands on this lesson in the book?**
**Answer: The designed Scratch project that follows it**

**10. (Sub lesson 2) How does a score begin?**
**Answer: Set to zero — then changed by the instructions as the project runs**
