## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Instructions on data** — Sudan's Grade 9 Scratch course ends its data work with the **instructions that operate on data**: the blocks that **set** a stored value, **change** it by an amount, and **use** it — showing it on the stage, testing it in a condition, joining it into what a sprite says. Data sitting in a variable does nothing; these instructions are how a program *works* with it. The book places them after dealing with data itself: first the storing, now the working.
2. **Data at work in a running project** — With data instructions, a Scratch project remembers and decides: a **score** that grows when a target is caught, a **counter** that ends the game at ten, a **name** the program asked for and now uses in its greeting. The project's behaviour turns on its data — the same instructions give different runs when the values differ. That is the step from drawing with blocks to programming with them, and the book's designed project after this lesson stands on it.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
