# Hands-on — Naming and Saving a Scratch Project

The lesson with your hands and your feet, not only your eyes.

## Save it properly
Create or open a project, save it into a Scratch projects folder with a describing name. Close Scratch, reopen the project from its folder to prove it survived.

## Name the shelf
Look at three project names (yours or invented). Rewrite any that describe nothing, so each name says what its project is.
