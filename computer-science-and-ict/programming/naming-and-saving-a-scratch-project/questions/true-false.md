# Naming and Saving a Scratch Project — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does saving a project do?" is: Writes it to a file on the computer**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Where are projects kept?" is: So they never scatter among pictures and documents**
**Answer: False** — In their own folder — one home for all Scratch work

**3. (Sub lesson 1) True or false: the answer to "Why keep projects in their own folder?" is: So they never scatter among pictures and documents**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "When do you save?" is: The project's memory**
**Answer: False** — When the project is made, and again as it grows

**5. (Sub lesson 1) True or false: the answer to "What is the saved file called in this lesson?" is: The project's memory**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What kind of name does a project take?" is: Space and Football**
**Answer: False** — A name that describes it

**7. (Sub lesson 2) True or false: the answer to "What are the guide's two example names?" is: Space and Football**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does a describing name let future-you do?" is: A describing name plus its own folder**
**Answer: False** — Pick the project from the folder without opening everything

**9. (Sub lesson 2) True or false: the answer to "What is the whole system, in one line?" is: A describing name plus its own folder**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What happens to unsaved work?" is: Writes it to a file on the computer**
**Answer: False** — It is lost
