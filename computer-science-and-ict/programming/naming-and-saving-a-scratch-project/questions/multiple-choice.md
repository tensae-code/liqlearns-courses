# Naming and Saving a Scratch Project — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does saving a project do?**
a) Writes it to a file on the computer  b) When the project is made, and again as it grows  c) A name that describes it  d) Pick the project from the folder without opening everything

**2. (Sub lesson 1) Where are projects kept?**
a) The project's memory  b) In their own folder — one home for all Scratch work  c) Space and Football  d) A describing name plus its own folder
