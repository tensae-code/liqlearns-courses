## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The shape of a linear program** — A **linear program** runs its statements in order, once each: input with readln, work by assignments and expressions, output with writeln. Its Pascal shape is the full frame — program name, declarations, begin…end — now filled with a real task: read the sides of a rectangle, compute area and perimeter, print both, arranged on a cleared screen.
2. **Composing one alone** — Composing means choosing: which variables, which formulas, which prompts, which order of output. The book's method is the problem-solving road shrunk to one page — say the task, name the data, write the steps, then the code. A linear program is small, but it is complete: everything in it was taught, and nothing in it is decoration.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
