# Writing Linear Programs in Pascal — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a linear program?**
a) A program whose statements run in order, once each — no branches, no loops  b) Input, compute, output  c) readln, assignment, writeln  d) Read a rectangle's sides; compute and print area and perimeter
**Answer: a) A program whose statements run in order, once each — no branches, no loops**

**2. (Sub lesson 1) What are its three beats?**
a) readln, assignment, writeln  b) Input, compute, output  c) Read a rectangle's sides; compute and print area and perimeter  d) Program name, declarations, begin…end
