# Video script — Writing Linear Programs in Pascal

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A **linear program** runs its statements in order, once each: input with readln, work by assignments and expressions, output with writeln. Its Pascal shape is the full frame — program name, declarations, begin…end — now filled with a real task: read the sides of a rectangle, compute area and perimeter, print both, arranged on a cleared screen.
Composing means choosing: which variables, which formulas, which prompts, which order of output. The book's method is the problem-solving road shrunk to one page — say the task, name the data, write the steps, then the code. A linear program is small, but it is complete: everything in it was taught, and nothing in it is decoration.
