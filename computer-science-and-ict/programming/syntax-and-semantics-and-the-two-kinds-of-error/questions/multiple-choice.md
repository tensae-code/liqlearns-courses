# Syntax and semantics - and the two kinds of error - multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Syntax is -
a) the meaning of a program  b) the rules - the structure or grammar - of a language  c) a kind of translator  d) the output of a program
**Answer: b) the rules - the structure or grammar - of a language** - programs must strictly follow it.

**2. (Sub lesson 2)** Semantics is -
a) the grammar of a language  b) the meaning of a program's elements and what they do  c) an error message  d) a memory location
**Answer: b) the meaning of a program's elements and what they do** - meaning, not building.

**3. (Sub lesson 3)** A syntax error happens when -
a) the answer is wrong  b) a syntax rule is broken and the translator produces an error message  c) the computer is slow  d) the formula is wrong
**Answer: b) a syntax rule is broken and the translator produces an error message** - the translator announces it.

**4. (Sub lesson 3)** Who produces the error message for a syntax error?
a) the user  b) the compiler or interpreter  c) the printer  d) nobody
**Answer: b) the compiler or interpreter** - the translator stops and reports it.

**5. (Sub lesson 4)** A logic error is a program that -
a) breaks a grammar rule  b) is syntax-perfect, runs, and still does the wrong thing  c) cannot be typed  d) has no output device
**Answer: b) is syntax-perfect, runs, and still does the wrong thing** - the meaning is wrong, not the building.

**6. (Sub lesson 4)** A logic error is far harder to find and fix because -
a) it is written in binary  b) no translator catches it - the program runs as if nothing were wrong  c) it happens only at night  d) the screen is small
**Answer: b) no translator catches it - the program runs as if nothing were wrong** - only a human watching the behaviour notices (teacher guide - evidence).

**7. (Sub lesson 4)** A circle area computed with the wrong formula, printing a wrong answer with no error message, is -
a) a syntax error  b) a logic error  c) not an error  d) a compiler
**Answer: b) a logic error** - quietly wrong = logic error.

**8. (Sub lesson 2)** Syntax asks 'is it built correctly?'; semantics asks -
a) how fast is it?  b) does it mean the right thing - what do its elements do?  c) who wrote it?  d) what colour is it?
**Answer: b) does it mean the right thing - what do its elements do?** - semantics is meaning - what the elements do.
