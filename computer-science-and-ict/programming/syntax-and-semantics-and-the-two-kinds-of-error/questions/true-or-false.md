# Syntax and semantics - and the two kinds of error - true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Syntax must be followed strictly.
**Answer: True** - it is the language's grammar.

**2. (Sub lesson 3)** A logic error is always announced by an error message.
**Answer: False** - no translator catches it - that is the point.

**3. (Sub lesson 4)** Translators can point to a syntax error's kind and place, but not to a logic error (teacher guide - evidence).
**Answer: True** - the guide's Activity 6.1 answer.

**4. (Sub lesson 1)** A program must strictly follow its language's syntax.
**Answer: True** - syntax is the grammar - strict by definition.
