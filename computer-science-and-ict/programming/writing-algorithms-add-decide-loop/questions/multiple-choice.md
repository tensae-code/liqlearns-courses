# Writing algorithms — add, decide, loop — multiple choice

Pick the one right answer.

**1.** In model 1, the process step is —
a) take the first number  b) add the two numbers  c) display the sum  d) take the second number
**Answer: b) add the two numbers** — taking is input; displaying is output.

**2.** In model 2, entering −4 displays —
a) positive  b) zero  c) negative  d) nothing
**Answer: c) negative** — below zero → negative.

**3.** Entering 0 in model 2 displays —
a) negative  b) positive  c) zero  d) an error
**Answer: c) zero** — otherwise → zero.

**4.** In model 3, the counter i starts at —
a) 0  b) 1  c) 10  d) the sum
**Answer: b) 1** — and sum starts at 0.

**5.** The step that ends model 3's loop is —
a) taking a number  b) adding to the sum  c) checking whether i is still under the limit  d) increasing i
**Answer: c) checking whether i is still under the limit** — the check decides loop-back or finish.
