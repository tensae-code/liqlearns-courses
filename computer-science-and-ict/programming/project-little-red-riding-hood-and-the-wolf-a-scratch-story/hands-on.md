# Hands-on — Project — Little Red Riding Hood and the Wolf: A Scratch Story

The lesson with your hands and your feet, not only your eyes.

## Scene plan
Draw the tale as four boxes in order: setting out, the wood, the meeting, the house. In each box write the backdrop and the sprites it needs.

## Build the journey
Build the project scene by scene in Scratch, changing the backdrop as Riding Hood travels. Run the whole story for a partner and ask them to name each scene as it passes.
