# Hands-on — Variable Scope in Python

The lesson with your hands and your feet, not only your eyes.

## Task one
**Scope map** — Take a small program with two functions and a global; draw each name's scope as a wall diagram and predict three printouts.

## Task two
**Remove the global** — Rewrite a program that uses a global counter to use parameters and returns instead; say what got easier to test.
