# Variable Scope in Python — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What is a local variable?** → **One assigned inside a function — visible only there, gone at return**

**2. (Sub lesson 1) Why can two functions share the name total in peace?** → **Each has its own local total**

**3. (Sub lesson 1) When may a function read an outside name?** → **When it does not assign to it**

**4. (Sub lesson 1) What does assigning do to a name inside a function?** → **Makes it local throughout the function**

**5. (Sub lesson 1) What error names the trap?** → **'Referenced before assignment'**

**6. (Sub lesson 2) What is a global variable?** → **A name assigned at the program's top level, visible everywhere**

**7. (Sub lesson 2) What declaration writes a global from inside?** → **global**

**8. (Sub lesson 2) Why are globals warned against?** → **Any function may change what every function sees**

**9. (Sub lesson 2) What is the craft's preference?** → **Pass values in as parameters, out as returns; keep names local**

**10. (Sub lesson 2) What is scope, in the closing phrase?** → **The function's privacy, and the program's sanity**
