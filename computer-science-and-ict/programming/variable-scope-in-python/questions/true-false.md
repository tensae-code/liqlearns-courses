# Variable Scope in Python — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: One assigned inside a function — visible only there, gone at return**
**Answer: True**

**2. (Sub lesson 1) True or false: One assigned inside a function — visible only there, gone at return** — as the answer to: Why can two functions share the name total in peace?
**Answer: False — Each has its own local total**

**3. (Sub lesson 1) True or false: When it does not assign to it**
**Answer: True**

**4. (Sub lesson 1) True or false: When it does not assign to it** — as the answer to: What does assigning do to a name inside a function?
**Answer: False — Makes it local throughout the function**

**5. (Sub lesson 1) True or false: 'Referenced before assignment'**
**Answer: True**

**6. (Sub lesson 2) True or false: 'Referenced before assignment'** — as the answer to: What is a global variable?
**Answer: False — A name assigned at the program's top level, visible everywhere**

**7. (Sub lesson 2) True or false: global**
**Answer: True**

**8. (Sub lesson 2) True or false: global** — as the answer to: Why are globals warned against?
**Answer: False — Any function may change what every function sees**

**9. (Sub lesson 2) True or false: Pass values in as parameters, out as returns; keep names local**
**Answer: True**

**10. (Sub lesson 2) True or false: Pass values in as parameters, out as returns; keep names local** — as the answer to: What is scope, in the closing phrase?
**Answer: False — The function's privacy, and the program's sanity**
