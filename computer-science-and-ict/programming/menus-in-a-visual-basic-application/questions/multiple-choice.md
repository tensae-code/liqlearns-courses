# Menus in a Visual Basic Application — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a menu?**
a) A named list of commands that drops down when its title is clicked  b) On the menu bar across the top of the window  c) Opening, saving and leaving  d) Dividing groups of commands inside a menu
**Answer: a) A named list of commands that drops down when its title is clicked**

**2. (Sub lesson 1) Where do menu titles sit?**
a) Opening, saving and leaving  b) On the menu bar across the top of the window  c) Dividing groups of commands inside a menu  d) It cannot be used now
**Answer: b) On the menu bar across the top of the window**

**3. (Sub lesson 1) What does the File menu hold?**
a) Dividing groups of commands inside a menu  b) It cannot be used now  c) Opening, saving and leaving  d) The IDE's menu editor
**Answer: c) Opening, saving and leaving**

**4. (Sub lesson 1) What is a separator for?**
a) It cannot be used now  b) The IDE's menu editor  c) Yes — clicking it runs its code, exactly as a button does  d) Dividing groups of commands inside a menu
**Answer: d) Dividing groups of commands inside a menu**

**5. (Sub lesson 1) What does a greyed command mean?**
a) It cannot be used now  b) The IDE's menu editor  c) Yes — clicking it runs its code, exactly as a button does  d) Decide the jobs, group them under titles, enter them in the editor, then give each command its procedure
**Answer: a) It cannot be used now**

**6. (Sub lesson 2) What tool builds menus?**
a) Yes — clicking it runs its code, exactly as a button does  b) The IDE's menu editor  c) Decide the jobs, group them under titles, enter them in the editor, then give each command its procedure  d) Find every job the program can do
**Answer: b) The IDE's menu editor**

**7. (Sub lesson 2) Is a menu command a control?**
a) Decide the jobs, group them under titles, enter them in the editor, then give each command its procedure  b) Find every job the program can do  c) Yes — clicking it runs its code, exactly as a button does  d) The application's table of contents
**Answer: c) Yes — clicking it runs its code, exactly as a button does**

**8. (Sub lesson 2) What is the building order?**
a) Find every job the program can do  b) The application's table of contents  c) A named list of commands that drops down when its title is clicked  d) Decide the jobs, group them under titles, enter them in the editor, then give each command its procedure
**Answer: d) Decide the jobs, group them under titles, enter them in the editor, then give each command its procedure**

**9. (Sub lesson 2) What can a stranger do with a finished menu?**
a) Find every job the program can do  b) The application's table of contents  c) A named list of commands that drops down when its title is clicked  d) On the menu bar across the top of the window
**Answer: a) Find every job the program can do**

**10. (Sub lesson 2) What is a menu, in Fiji's phrase?**
a) A named list of commands that drops down when its title is clicked  b) The application's table of contents  c) On the menu bar across the top of the window  d) Opening, saving and leaving
