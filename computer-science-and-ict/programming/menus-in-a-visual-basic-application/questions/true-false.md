# Menus in a Visual Basic Application — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a menu?" is: A named list of commands that drops down when its title is clicked**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Where do menu titles sit?" is: Opening, saving and leaving**
**Answer: False** — On the menu bar across the top of the window

**3. (Sub lesson 1) True or false: the answer to "What does the File menu hold?" is: Opening, saving and leaving**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is a separator for?" is: It cannot be used now**
**Answer: False** — Dividing groups of commands inside a menu

**5. (Sub lesson 1) True or false: the answer to "What does a greyed command mean?" is: It cannot be used now**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What tool builds menus?" is: Yes — clicking it runs its code, exactly as a button does**
**Answer: False** — The IDE's menu editor

**7. (Sub lesson 2) True or false: the answer to "Is a menu command a control?" is: Yes — clicking it runs its code, exactly as a button does**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is the building order?" is: Find every job the program can do**
**Answer: False** — Decide the jobs, group them under titles, enter them in the editor, then give each command its procedure

**9. (Sub lesson 2) True or false: the answer to "What can a stranger do with a finished menu?" is: Find every job the program can do**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is a menu, in Fiji's phrase?" is: A named list of commands that drops down when its title is clicked**
**Answer: False** — The application's table of contents
