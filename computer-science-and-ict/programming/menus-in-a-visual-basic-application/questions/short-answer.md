# Menus in a Visual Basic Application — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a menu?**
**Answer: A named list of commands that drops down when its title is clicked**

**2. (Sub lesson 1) Where do menu titles sit?**
**Answer: On the menu bar across the top of the window**

**3. (Sub lesson 1) What does the File menu hold?**
**Answer: Opening, saving and leaving**

**4. (Sub lesson 1) What is a separator for?**
**Answer: Dividing groups of commands inside a menu**

**5. (Sub lesson 1) What does a greyed command mean?**
**Answer: It cannot be used now**

**6. (Sub lesson 2) What tool builds menus?**
**Answer: The IDE's menu editor**

**7. (Sub lesson 2) Is a menu command a control?**
**Answer: Yes — clicking it runs its code, exactly as a button does**

**8. (Sub lesson 2) What is the building order?**
**Answer: Decide the jobs, group them under titles, enter them in the editor, then give each command its procedure**

**9. (Sub lesson 2) What can a stranger do with a finished menu?**
**Answer: Find every job the program can do**

**10. (Sub lesson 2) What is a menu, in Fiji's phrase?**
**Answer: The application's table of contents**
