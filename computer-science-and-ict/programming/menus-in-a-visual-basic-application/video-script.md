# Video script — Menus in a Visual Basic Application

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A **menu** is a **named list of commands** that drops down when its title is clicked. Titles sit on the **menu bar** across the top of the window — File, Edit, View in the classic order — and each menu's commands are the program's jobs, grouped by kind: File holds opening, saving and leaving; Edit holds undoing and copying. Commands used often can carry **shortcut keys**; a **separator** line divides groups inside a menu; a command that cannot be used now is shown **greyed**. Fiji's point is organisation: the menu is the application's table of contents.
Menus are built with the IDE's **menu editor**: titles and commands are entered in order, named like controls — for a menu command is a control, and **clicking it runs its code** exactly as clicking a button does. The building order is the designing order: decide the jobs, group them under titles, write the list into the editor, then give each command its procedure. A finished menu lets a user who has never seen the program **find every job it can do** — which is why Fiji gives menus their own section before the chapter's debugging close.
