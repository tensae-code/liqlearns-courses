# Meeting Pascal — a First Programming Language — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A programming language designed for teaching programming properly**
**Answer: True**

**2. (Sub lesson 1) True or false: A programming language designed for teaching programming properly** — as the answer to: Who designed it, and when?
**Answer: False — Niklaus Wirth, around 1970**

**3. (Sub lesson 1) True or false: Precision — clear structure and checked types, no vague shortcuts**
**Answer: True**

**4. (Sub lesson 1) True or false: Precision — clear structure and checked types, no vague shortcuts** — as the answer to: How long does Moldova's course stay with Pascal?
**Answer: False — From Grade 7 through Grade 12 (later beside C++)**

**5. (Sub lesson 1) True or false: A text in the language's exact vocabulary and grammar that the computer can execute**
**Answer: True**

**6. (Sub lesson 2) True or false: A text in the language's exact vocabulary and grammar that the computer can execute** — as the answer to: What word opens a Pascal program?
**Answer: False — program — followed by the program's name**

**7. (Sub lesson 2) True or false: The declarations — the data the program will use**
**Answer: True**

**8. (Sub lesson 2) True or false: The declarations — the data the program will use** — as the answer to: What separates the instructions?
**Answer: False — Semicolons**

**9. (Sub lesson 2) True or false: With end followed by a full stop**
**Answer: True**

**10. (Sub lesson 2) True or false: With end followed by a full stop** — as the answer to: Does a tiny program wear the whole shape?
**Answer: False — Yes — declarations, then a begin…end body, however small the program**
