## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Why Pascal — a language built for teaching** — **Pascal** is a **programming language** designed by Niklaus Wirth around 1970 **for teaching programming properly**: clear structure, checked types, and no shortcuts around good habits. A program in Pascal is a text the computer can execute, written in the language's exact vocabulary and grammar — the machine forgives no vagueness, so the language trains precision. Moldova's course meets it in Grade 7 and stays with it (later beside C++) through Grade 12: one language, learned deeply, rather than many met shallowly.
2. **A first program — its shape** — A Pascal program has a fixed **shape**: it opens with the word **program** and the program's name; then come declarations (the data it will use); then **begin**; then the instructions, separated by semicolons; and it closes with **end** followed by a full stop. Even the smallest program — one that only prints a greeting — wears the whole shape, because the shape is the language's promise: every program, however large, is declarations, then a begin…end body of instructions. The sections after this one fill the shape in, piece by piece.
