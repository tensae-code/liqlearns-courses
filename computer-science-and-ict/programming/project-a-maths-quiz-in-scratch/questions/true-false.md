# Project — A Maths Quiz in Scratch — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is one round of the quiz?" is: Ask, capture the answer, compare, and answer back**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How are the quiz's questions built?" is: A score variable**
**Answer: False** — With operators — random numbers and an operation

**3. (Sub lesson 1) True or false: the answer to "How is the true answer worked out?" is: With the same operators that built the question**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What compares the player's answer with the true one?" is: By one, for every right answer**
**Answer: False** — A condition — if they match, or not

**5. (Sub lesson 1) True or false: the answer to "What happens when the answers do not match?" is: The player is shown the true answer**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What keeps the quiz's count?" is: By reporting the player's score**
**Answer: False** — A score variable

**7. (Sub lesson 2) True or false: the answer to "What is the score set to at the start?" is: Zero**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "When does the score change?" is: With operators — random numbers and an operation**
**Answer: False** — By one, for every right answer

**9. (Sub lesson 2) True or false: the answer to "How do the rounds repeat?" is: By a loop, or by re-asking**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "How does the quiz end?" is: A condition — if they match, or not**
**Answer: False** — By reporting the player's score
