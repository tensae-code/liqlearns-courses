# Video script — Project — A Maths Quiz in Scratch

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

One round of the quiz is a complete circuit: the program asks a maths question — built with operators, so the numbers can change every game, a random pair of numbers and an operation — captures the player's answer, works out the true answer with the same operators, and compares the two with a condition: if they match, the player is told they are right; if not, the true answer is shown. The asking block, the answer reporter and the if–then–else are the round's three moving parts.
A quiz of one question is a moment; the project makes a game of rounds, and a score variable keeps the count: set to zero at the start, changed by one for every right answer, and shown at the end as the player's result. Rounds repeat — by a loop or by re-asking — for the planned number of questions, and the quiz ends by reporting the score with the sprite's words. Set, change, show: the variable's whole life, in the service of a game a classmate can play.
