# Project — Don't Touch! A Ball Game Avoiding Barriers in Scratch — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Which pieces does the game build first?" is: A ball, barriers across the field, and a goal**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Who steers the ball?" is: A touching test**
**Answer: False** — The player

**3. (Sub lesson 1) True or false: the answer to "Where does every attempt begin?" is: At the ball's start position, reset by the starting event**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Why keep the barriers one recognisable kind?" is: Reaching the goal**
**Answer: False** — Because the game's rule is sensed through them

**5. (Sub lesson 1) True or false: the answer to "What must the ball do to win a run?" is: Reach the goal without touching a barrier**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What watches constantly while the ball is steered?" is: Fair to win with care, impossible through a barrier, restartable at once**
**Answer: False** — A touching test

**7. (Sub lesson 2) True or false: the answer to "What happens when the ball touches a barrier?" is: The run ends — back to the start, or the game is lost**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What wins the game?" is: The player**
**Answer: False** — Reaching the goal

**9. (Sub lesson 2) True or false: the answer to "What keeps steering smooth and the test running?" is: Waits and loops**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is the project's check?" is: Because the game's rule is sensed through them**
**Answer: False** — Fair to win with care, impossible through a barrier, restartable at once
