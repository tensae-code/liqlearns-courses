# Hands-on — Project — Don't Touch! A Ball Game Avoiding Barriers in Scratch

The lesson with your hands and your feet, not only your eyes.

## Draw the field
Plan the game on paper: the ball's start, the goal, and the barriers between. Keep the barriers one colour. Mark the hardest passage — is it fair?

## Build and referee it
Build the game in Scratch with the touching test. Play three runs: one careful, one reckless, one straight through a barrier. Write what the game did each time — did its law hold?
