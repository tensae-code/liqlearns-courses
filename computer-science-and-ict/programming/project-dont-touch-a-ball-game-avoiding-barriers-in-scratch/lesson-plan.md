# Lesson plan — Project — Don't Touch! A Ball Game Avoiding Barriers in Scratch

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** Project — Don't Touch! A Ball Game Avoiding Barriers in Scratch
**Place in the curriculum:** ICT expansion — Morocco (2026-11-14) — in the title Programming on the ICT course ladder (TITLES.md). Built new from Morocco's Grade 5 “J'excelle en informatique” teacher guide, because no existing lesson in the course covers this thing as its own lesson. This lesson stands on teacher-guide evidence only (Morocco), named in lesson/sources.md, counted nowhere.
**The one thing this lesson teaches:** The project builds the game's pieces first: a ball sprite the player will steer, barriers drawn or placed across the field — walls, blocks, a maze of obstacles — and a goal the ball must reach. The game runs on sensing: the ball is steered — by keys, or following the pointer — while a touching test watches constantly: if the ball touches a barrier, the run ends — back to the start, or the game declares itself lost — and reaching the goal wins.
