# Python Exceptions — Try and Except — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is an exception?**
**Answer: Python's named failure report when an operation cannot be done**

**2. (Sub lesson 1) Name two exception kinds from the lesson.**
**Answer: ValueError and ZeroDivisionError**

**3. (Sub lesson 1) What does an uncaught exception do?**
**Answer: Ends the program where it stands, mid-work**

**4. (Sub lesson 1) What does try wrap?**
**Answer: The dangerous lines — 'try this'**

**5. (Sub lesson 1) What does except hold?**
**Answer: The rescue — what to do if that failure happens**

**6. (Sub lesson 2) What happens after a caught failure?**
**Answer: The program continues past it**

**7. (Sub lesson 2) What is the book's set build?**
**Answer: The school-trip cost-sharing calculator**

**8. (Sub lesson 2) Why does that build need exceptions?**
**Answer: Its inputs are typed numbers — nonsense entries must earn a message and another chance, not a dead program**

**9. (Sub lesson 2) State the habit in one line.**
**Answer: Dangerous ground is crossed inside try**
