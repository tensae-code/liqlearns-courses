Say true or false, and fix the false ones in your own words.

**Answer: True**

**Answer: True**

**4. (Sub lesson 1) True or false: The algorithm, the data and the solution's shape** — as the answer to: What is the difference between testing and debugging?

**5. (Sub lesson 1) True or false: Putting the program to work in its real place with real users**
