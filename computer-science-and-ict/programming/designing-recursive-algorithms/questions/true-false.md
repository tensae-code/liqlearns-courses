# Designing Recursive Algorithms — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The base case and the recurrence**
**Answer: True**

**2. (Sub lesson 1) True or false: The base case and the recurrence** — as the answer to: What is the base case?
**Answer: False — The smallest version of the problem, answered directly with no further call**

**3. (Sub lesson 1) True or false: The restating of the problem as smaller copies of itself, plus the work of joining their answers**
**Answer: True**

**4. (Sub lesson 1) True or false: The restating of the problem as smaller copies of itself, plus the work of joining their answers** — as the answer to: What happens without a base case?
**Answer: False — The calls never stop — the descent has no floor**

**5. (Sub lesson 1) True or false: The recursive function almost writes itself**
**Answer: True**

**6. (Sub lesson 2) True or false: The recursive function almost writes itself** — as the answer to: What duty does the recurrence carry?
**Answer: False — Every smaller copy must be closer to the base case**

**7. (Sub lesson 2) True or false: Fibonacci — each term from the two before it**
**Answer: True**

**8. (Sub lesson 2) True or false: Fibonacci — each term from the two before it** — as the answer to: Which part is written first?
**Answer: False — The base case**

**9. (Sub lesson 2) True or false: The shrinking — why the copies approach the base case**
**Answer: True**

**10. (Sub lesson 2) True or false: The shrinking — why the copies approach the base case** — as the answer to: What are the checklist's four items?
