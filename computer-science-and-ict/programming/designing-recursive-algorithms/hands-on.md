# Hands-on — Designing Recursive Algorithms

The lesson with your hands and your feet, not only your eyes.

## Task one
**Design, don't code** — For 'count the digits of a number', write the base case and the recurrence, and argue the shrinking in one sentence.

## Task two
**Two copies** — Design a recursive algorithm for the Lucas-like sequence a(n) = a(n−1) + a(n−2) with a(0)=2, a(1)=1. Name both base cases.
