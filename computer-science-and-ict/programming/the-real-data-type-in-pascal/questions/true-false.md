# The Real Data Type in Pascal — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Numbers with fractional parts — measurements, fractions, averages**
**Answer: True**

**2. (Sub lesson 1) True or false: Numbers with fractional parts — measurements, fractions, averages** — as the answer to: What are real's two written forms?
**Answer: False — Fixed form (2.75) and exponent form (2.75E3 = 2750)**

**3. (Sub lesson 1) True or false: var x: real;**
**Answer: True**

**4. (Sub lesson 1) True or false: var x: real;** — as the answer to: Is a real held exactly?
**Answer: False — No — approximately; the type stores a very close neighbour of the true value**

**5. (Sub lesson 1) True or false: In Grade 12's lessons on calculation errors**
**Answer: True**

**6. (Sub lesson 2) True or false: In Grade 12's lessons on calculation errors** — as the answer to: What does 7 / 2 give for reals?
**Answer: False — 3.5 — division that keeps the fraction**

**7. (Sub lesson 2) True or false: abs, sqr and sqrt (also: sin, cos)**
**Answer: True**

**8. (Sub lesson 2) True or false: abs, sqr and sqrt (also: sin, cos)** — as the answer to: Why is testing reals for exact equality unsafe?
**Answer: False — Because reals are held approximately — 0.1 + 0.2 may not sit exactly on 0.3**

**9. (Sub lesson 2) True or false: By closeness, not by identity**
**Answer: True**

**10. (Sub lesson 2) True or false: By closeness, not by identity** — as the answer to: What kind of result do sqrt and sin answer?
**Answer: False — A real result**
