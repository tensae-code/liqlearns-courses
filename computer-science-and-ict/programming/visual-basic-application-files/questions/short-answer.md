# Visual Basic Application Files — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a Visual Basic application saved as?**
**Answer: A project — a project file binding the parts, plus a form file for each window**

**2. (Sub lesson 1) What does the project file do?**
**Answer: Lists and binds the application's parts**

**3. (Sub lesson 1) What does each form file hold?**
**Answer: That window's design — its controls — and its code together**

**4. (Sub lesson 1) What supporting files travel with a project?**
**Answer: Modules of shared code, and resources such as pictures the forms use**

**5. (Sub lesson 1) Why does Fiji open the chapter with files?**
**Answer: The application is this set of files — losing a part loses a piece of the program**

**6. (Sub lesson 2) What is the executable file?**
**Answer: The compiled single file the user runs, without needing Visual Basic**

**7. (Sub lesson 2) What are the project files, in the lesson's image?**
**Answer: The workshop — kept by the programmer, opened to change the application**

**8. (Sub lesson 2) What is the executable, in the same image?**
**Answer: The product — given to users**

**9. (Sub lesson 2) Which can be remade from which?**
**Answer: The executable can be remade from the project; the project can never be remade from the executable**

**10. (Sub lesson 2) What is the programmer's housekeeping oath?**
**Answer: Keep the project safe**
