# Visual Basic Application Files — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a Visual Basic application saved as?**
a) A project — a project file binding the parts, plus a form file for each window  b) Lists and binds the application's parts  c) That window's design — its controls — and its code together  d) Modules of shared code, and resources such as pictures the forms use
**Answer: a) A project — a project file binding the parts, plus a form file for each window**

**2. (Sub lesson 1) What does the project file do?**
a) That window's design — its controls — and its code together  b) Lists and binds the application's parts  c) Modules of shared code, and resources such as pictures the forms use  d) The application is this set of files — losing a part loses a piece of the program
**Answer: b) Lists and binds the application's parts**

**3. (Sub lesson 1) What does each form file hold?**
a) Modules of shared code, and resources such as pictures the forms use  b) The application is this set of files — losing a part loses a piece of the program  c) That window's design — its controls — and its code together  d) The compiled single file the user runs, without needing Visual Basic
**Answer: c) That window's design — its controls — and its code together**

**4. (Sub lesson 1) What supporting files travel with a project?**
a) The application is this set of files — losing a part loses a piece of the program  b) The compiled single file the user runs, without needing Visual Basic  c) The workshop — kept by the programmer, opened to change the application  d) Modules of shared code, and resources such as pictures the forms use
**Answer: d) Modules of shared code, and resources such as pictures the forms use**

**5. (Sub lesson 1) Why does Fiji open the chapter with files?**
a) The application is this set of files — losing a part loses a piece of the program  b) The compiled single file the user runs, without needing Visual Basic  c) The workshop — kept by the programmer, opened to change the application  d) The product — given to users
**Answer: a) The application is this set of files — losing a part loses a piece of the program**

**6. (Sub lesson 2) What is the executable file?**
a) The workshop — kept by the programmer, opened to change the application  b) The compiled single file the user runs, without needing Visual Basic  c) The product — given to users  d) The executable can be remade from the project; the project can never be remade from the executable

**7. (Sub lesson 2) What are the project files, in the lesson's image?**

**8. (Sub lesson 2) What is the executable, in the same image?**
