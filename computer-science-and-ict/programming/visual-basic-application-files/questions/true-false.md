# Visual Basic Application Files — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a Visual Basic application saved as?" is: A project — a project file binding the parts, plus a form file for each window**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does the project file do?" is: That window's design — its controls — and its code together**
**Answer: False** — Lists and binds the application's parts

**3. (Sub lesson 1) True or false: the answer to "What does each form file hold?" is: That window's design — its controls — and its code together**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What supporting files travel with a project?" is: The application is this set of files — losing a part loses a piece of the program**
**Answer: False** — Modules of shared code, and resources such as pictures the forms use

**5. (Sub lesson 1) True or false: the answer to "Why does Fiji open the chapter with files?" is: The application is this set of files — losing a part loses a piece of the program**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is the executable file?" is: The workshop — kept by the programmer, opened to change the application**
**Answer: False** — The compiled single file the user runs, without needing Visual Basic

**7. (Sub lesson 2) True or false: the answer to "What are the project files, in the lesson's image?" is: The workshop — kept by the programmer, opened to change the application**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is the executable, in the same image?" is: The executable can be remade from the project; the project can never be remade from the executable**
**Answer: False** — The product — given to users

**9. (Sub lesson 2) True or false: the answer to "Which can be remade from which?" is: The executable can be remade from the project; the project can never be remade from the executable**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is the programmer's housekeeping oath?" is: A project — a project file binding the parts, plus a form file for each window**
**Answer: False** — Keep the project safe
