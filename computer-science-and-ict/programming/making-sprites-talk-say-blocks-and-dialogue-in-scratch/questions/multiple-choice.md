# Making Sprites Talk — Say Blocks and Dialogue in Scratch — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does the say block do?**
a) It puts words in a speech bubble above the sprite  b) It holds the line for a set time  c) So it can be read  d) Say-for-seconds plus waits
**Answer: a) It puts words in a speech bubble above the sprite**

**2. (Sub lesson 1) What does say for seconds add?**
a) “I am the lion”  b) It holds the line for a set time  c) Because Scratch writes left-to-right  d) Abby and Maya’s
**Answer: b) It holds the line for a set time**

**3. (Sub lesson 1) What is Grade 7’s lion’s line?**
a) So it can be read  b) Say-for-seconds plus waits  c) “I am the lion”  d) A dialogue project on love of the homeland
**Answer: c) “I am the lion”**

**4. (Sub lesson 1) Why is long speech spaced?**
a) Because Scratch writes left-to-right  b) Abby and Maya’s  c) Broadcasts  d) So it can be read
**Answer: d) So it can be read**

**5. (Sub lesson 1) Why does Arabic appear reversed in Scratch?**
a) Because Scratch writes left-to-right  b) Say-for-seconds plus waits  c) A dialogue project on love of the homeland  d) Its recorded line
**Answer: a) Because Scratch writes left-to-right**

**6. (Sub lesson 2) What keeps speakers from overlapping?**
a) Abby and Maya’s  b) Say-for-seconds plus waits  c) Broadcasts  d) It puts words in a speech bubble above the sprite
**Answer: b) Say-for-seconds plus waits**

**7. (Sub lesson 2) Whose conversation scripts the turn-taking?**
a) A dialogue project on love of the homeland  b) Its recorded line  c) Abby and Maya’s  d) It holds the line for a set time
**Answer: c) Abby and Maya’s**

**8. (Sub lesson 2) What project uses the homeland dialogue?**
a) Broadcasts  b) It puts words in a speech bubble above the sprite  c) “I am the lion”  d) A dialogue project on love of the homeland
**Answer: d) A dialogue project on love of the homeland**

**9. (Sub lesson 2) In Grade 9’s race story, what runs the turns?**
a) Broadcasts  b) Its recorded line  c) It holds the line for a set time  d) So it can be read
**Answer: a) Broadcasts**

**10. (Sub lesson 2) What plays on each sprite’s cue in the race?**
a) It puts words in a speech bubble above the sprite  b) Its recorded line  c) “I am the lion”  d) Because Scratch writes left-to-right
**Answer: b) Its recorded line**
