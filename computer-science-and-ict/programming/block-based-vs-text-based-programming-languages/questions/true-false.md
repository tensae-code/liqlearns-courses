# Block-Based and Text-Based Programming Languages — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: As shapes that snap together — only fitting joins possible**
**Answer: True**

**2. (Sub lesson 1) True or false: As shapes that snap together — only fitting joins possible** — as the answer to: What error can blocks not make?
**Answer: False — Syntax errors cannot be typed**

**3. (Sub lesson 1) True or false: Every command the language has**
**Answer: True**

**4. (Sub lesson 1) True or false: Every command the language has** — as the answer to: What lives in text languages?
**Answer: False — The whole literature of programming — libraries, idioms, tools**

**5. (Sub lesson 1) True or false: The concepts — sequence, selection, repetition**

**6. (Sub lesson 2) True or false: The concepts — sequence, selection, repetition** — as the answer to: What sits beneath both faces?
