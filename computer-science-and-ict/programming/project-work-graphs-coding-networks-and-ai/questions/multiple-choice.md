# Project Work — Graphs, Coding, Networks and AI — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) A project goal is well written when it —**
a) Names a topic  b) Is one checkable sentence: a product plus the test it must pass  c) Is long  d) Mentions the grade
**Answer: b) Is one checkable sentence: a product plus the test it must pass** — Uncheckable goals cannot be finished, only abandoned.

**2. (Sub lesson 1) A milestone is —**
a) A celebration  b) A dated point where a named piece of the work must exist  c) The final lesson  d) A kind of graph
**Answer: b) A dated point where a named piece of the work must exist** — Milestones make lateness visible while fixing is still cheap.

**3. (Sub lesson 1) Roles in a project plan should be —**
a) 'The group'  b) Named people owning named steps  c) Rotated hourly  d) Secret
**Answer: b) Named people owning named steps** — An unowned step is an undone step.

**4. (Sub lesson 2) The AI menu build's honesty rule, from the training lesson, is —**
a) Use all data for training  b) Hold back a test set and report the unseen-data score, failures named  c) Train until 100% on practice  d) Skip testing
**Answer: b) Hold back a test set and report the unseen-data score, failures named** — The strand's discipline, applied in the team's own build.

**5. (Sub lesson 2) A rule-based social bot answers a message by —**
a) Learning from it  b) Matching it against patterns and using the prepared answer  c) Asking a teacher  d) Searching the web
**Answer: b) Matching it against patterns and using the prepared answer** — Patterns in, prepared answers out — with a fallback for the unmatched.

**6. (Sub lesson 2) A message no pattern fits teaches the builders —**
a) Nothing  b) The border of rule-based systems: they answer only what was foreseen  c) That bots are useless  d) That more colours are needed
**Answer: b) The border of rule-based systems: they answer only what was foreseen** — The failure log is the project's real finding.
