# Project Work — Graphs, Coding, Networks and AI — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Writing down a project's failures beside its successes is part of honest project work.**
**Answer: True** — A project that hides its failures teaches nothing.

**2. (Sub lesson 1) A three-line log per session is a waste of project time.**
**Answer: False** — The log is what keeps the project honest while memories are fresh.

**3. (Sub lesson 2) A social bot's fallback answers are used for messages that match a pattern.**
**Answer: False** — The fallback is exactly for messages no pattern matches.

**4. (Sub lesson 2) The social-bot build draws on the course's knowledge-based AI lesson.**
**Answer: True** — Prepared pattern rules are knowledge-based design — foreseen cases only.
