# Hands-on — Control Structures in JavaScript

The lesson with your hands and your feet, not only your eyes.

('Judge and repeat', 'Write a JavaScript fragment for a marks page: read a mark, use if…else if…else to print its grade band, then use a for loop to print the bands for an array of five marks.')

## Task two
