# Control Structures in JavaScript — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does JavaScript choose with?**
**Answer: if … else if … else — condition in brackets, branches in braces**

**2. (Sub lesson 1) Name JavaScript's comparison operators.**
**Answer: ==, !=, >, <, >=, <=**

**3. (Sub lesson 1) Name its logical operators.**
**Answer: && (AND), || (OR), ! (NOT)**

**4. (Sub lesson 1) What are client-side choices, in the page?**
**Answer: Its judgements — which message an answer earns, which menu a level opens**

**5. (Sub lesson 1) What is a condition tested as?**
**Answer: True or false**

**6. (Sub lesson 2) When is for used, against while?**
**Answer: for: a count known in advance; while: a count known only by the running**

**7. (Sub lesson 2) What does for's line gather?**
**Answer: Start, test and step in one line — let i = 1; i <= 5; i++**

**8. (Sub lesson 2) What must a loop's body do?**
**Answer: Move the test toward ending**

**9. (Sub lesson 2) What happens if it does not?**
**Answer: An endless loop — the page hangs**

**10. (Sub lesson 2) Name repetitive page work Malaysia's scripts do.**
**Answer: Listing items; checking each field of a form; totalling a column of marks**
