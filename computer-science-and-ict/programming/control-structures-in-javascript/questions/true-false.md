# Control Structures in JavaScript — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does JavaScript choose with?" is: if … else if … else — condition in brackets, branches in braces**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Name JavaScript's comparison operators." is: && (AND), || (OR), ! (NOT)**
**Answer: False** — ==, !=, >, <, >=, <=

**3. (Sub lesson 1) True or false: the answer to "Name its logical operators." is: && (AND), || (OR), ! (NOT)**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What are client-side choices, in the page?" is: True or false**
**Answer: False** — Its judgements — which message an answer earns, which menu a level opens

**5. (Sub lesson 1) True or false: the answer to "What is a condition tested as?" is: True or false**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "When is for used, against while?" is: Start, test and step in one line — let i = 1; i <= 5; i++**
**Answer: False** — for: a count known in advance; while: a count known only by the running

**7. (Sub lesson 2) True or false: the answer to "What does for's line gather?" is: Start, test and step in one line — let i = 1; i <= 5; i++**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What must a loop's body do?" is: An endless loop — the page hangs**
**Answer: False** — Move the test toward ending

**9. (Sub lesson 2) True or false: the answer to "What happens if it does not?" is: An endless loop — the page hangs**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Name repetitive page work Malaysia's scripts do." is: if … else if … else — condition in brackets, branches in braces**
