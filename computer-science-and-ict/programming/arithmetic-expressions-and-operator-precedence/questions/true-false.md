# Arithmetic Expressions and Operator Precedence — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is an arithmetic expression?" is: A piece of a program that works out a number**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What joins the values in an expression?" is: The number the expression worked out to**
**Answer: False** — Operators

**3. (Sub lesson 1) True or false: the answer to "What happens when an expression is evaluated?" is: It is replaced by the single number it works out to**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does the rest of the program use?" is: Which operation is done first**
**Answer: False** — The number the expression worked out to

**5. (Sub lesson 1) True or false: the answer to "Give the example expression the book's teaching uses." is: 2 + 3 × 4**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does precedence fix?" is: The part inside brackets is worked out first**
**Answer: False** — Which operation is done first

**7. (Sub lesson 2) True or false: the answer to "Which operations come before addition and subtraction?" is: Multiplication and division**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How does grouping change the order?" is: 20 — the brackets**
**Answer: False** — The part inside brackets is worked out first

**9. (Sub lesson 2) True or false: the answer to "What is 2 + 3 × 4?" is: 14**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is (2 + 3) × 4, and what made the difference?" is: Operators**
