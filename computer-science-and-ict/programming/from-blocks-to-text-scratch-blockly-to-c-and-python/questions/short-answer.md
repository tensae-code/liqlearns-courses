# From Blocks to Text — Scratch and Blockly to C and Python — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is the transition this lesson teaches?**
**Answer: From visual block programming (Scratch, Blockly) to textual programming (C, Python)**

**2. (Sub lesson 1) What does not change across the crossing?**
**Answer: The structures — sequence, selection, repetition, variables, procedures — with the same meaning**

**3. (Sub lesson 1) What changes?**
**Answer: The spelling — shapes become syntax: words, punctuation and indentation that must be exact**

**4. (Sub lesson 1) Why can text fail where blocks cannot?**
**Answer: No palette prevents a malformed program in text; the text simply fails**

**5. (Sub lesson 1) How is the crossing made?**
**Answer: Translation first — rewrite a working block program line by line in text, running both until they agree**

**6. (Sub lesson 2) What is a translated block program, for the text version?**
**Answer: A known-correct plan**

**7. (Sub lesson 2) What block habits must be kept in text?**
**Answer: One structure at a time, meaningful names, testing as you go**

**8. (Sub lesson 2) The learner leaves owning the structures how many times?**
**Answer: Twice — once by shape, once by spelling**

**9. (Sub lesson 2) Which ownership do later languages ask for?**
**Answer: The second — by spelling**

**10. (Sub lesson 2) Where does Indonesia teach this?**
**Answer: Grade 9, Bab II B.1 — transition from block to textual programming**
