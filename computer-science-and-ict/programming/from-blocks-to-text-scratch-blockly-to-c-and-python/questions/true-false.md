# From Blocks to Text — Scratch and Blockly to C and Python — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: From visual block programming (Scratch, Blockly) to textual programming (C, Python)**
**Answer: True**

**2. (Sub lesson 1) True or false: From visual block programming (Scratch, Blockly) to textual programming (C, Python)** — as the answer to: What does not change across the crossing?
**Answer: False — The structures — sequence, selection, repetition, variables, procedures — with the same meaning**

**3. (Sub lesson 1) True or false: The spelling — shapes become syntax: words, punctuation and indentation that must be exact**
**Answer: True**

**4. (Sub lesson 1) True or false: The spelling — shapes become syntax: words, punctuation and indentation that must be exact** — as the answer to: Why can text fail where blocks cannot?
**Answer: False — No palette prevents a malformed program in text; the text simply fails**

**5. (Sub lesson 1) True or false: Translation first — rewrite a working block program line by line in text, running both until they agree**
**Answer: True**

**6. (Sub lesson 2) True or false: Translation first — rewrite a working block program line by line in text, running both until they agree** — as the answer to: What is a translated block program, for the text version?
**Answer: False — A known-correct plan**

**7. (Sub lesson 2) True or false: One structure at a time, meaningful names, testing as you go**
**Answer: True**

**8. (Sub lesson 2) True or false: One structure at a time, meaningful names, testing as you go** — as the answer to: The learner leaves owning the structures how many times?
**Answer: False — Twice — once by shape, once by spelling**

**9. (Sub lesson 2) True or false: The second — by spelling**
**Answer: True**

**10. (Sub lesson 2) True or false: The second — by spelling** — as the answer to: Where does Indonesia teach this?
