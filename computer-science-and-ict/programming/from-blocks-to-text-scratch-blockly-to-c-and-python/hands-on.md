# Hands-on — From Blocks to Text — Scratch and Blockly to C and Python

The lesson with your hands and your feet, not only your eyes.

## Task one
**Translate a program** — Take a Scratch or Blockly program you know (or design one on paper with a loop and a choice). Rewrite it in Python or C on paper, line by line, and mark where each block went.

## Task two
**Same thought, two spellings** — Write one small behaviour (count to ten, saying 'even' at even numbers) as a block diagram and as text. Circle the parts that are identical in meaning and box the parts that are only spelling.
