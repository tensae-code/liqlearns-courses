# Systems Phase 5 — System Implementation — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does system implementation do?" is: Installs the developed system in the organisation's real work**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is implementation's heart?" is: It is converted and carried into the new files**
**Answer: False** — The changeover — old way handing over to new

**3. (Sub lesson 1) True or false: the answer to "What happens to the old system's data?" is: It is converted and carried into the new files**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Name the three changeover strategies." is: Parallel — both systems run together until the new is trusted; safest but dearest**
**Answer: False** — Direct, parallel, and phased or pilot

**5. (Sub lesson 1) True or false: the answer to "Which is safest, and what is its cost?" is: Parallel — both systems run together until the new is trusted; safest but dearest**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "When are users trained?" is: Documents that say how the new way runs**
**Answer: False** — Before the switch — and helped through the first days

**7. (Sub lesson 2) True or false: the answer to "What documents must users be given?" is: Documents that say how the new way runs**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What are most changeover 'system failures'?" is: When the new way is simply the way — old system retired, data safe, users at home**
**Answer: False** — People meeting an unpractised way of working on a busy morning

**9. (Sub lesson 2) True or false: the answer to "When does the phase end?" is: When the new way is simply the way — old system retired, data safe, users at home**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why does Fiji count training inside the phase?" is: Installs the developed system in the organisation's real work**
**Answer: False** — Because a system is not implemented until its people can work it
