# Events in Scratch — When a Key Is Pressed or a Sprite Clicked — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does an event block do?" is: It starts a script when its event happens**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Where does an event block sit?" is: Arrows, letters and numbers**
**Answer: False** — At the top of a script

**3. (Sub lesson 1) True or false: the answer to "What happens to a stack with no event at its top?" is: It has no moment to run at**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What keys does the book use for key events?" is: With the keyboard, one script per key**
**Answer: False** — Arrows, letters and numbers

**5. (Sub lesson 1) True or false: the answer to "What is Grade 7’s plain rule about events?" is: Event blocks are what start a script**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How is a sprite driven in Grade 6’s lesson?" is: Its own small script**
**Answer: False** — With the keyboard, one script per key

**7. (Sub lesson 2) True or false: the answer to "What other event starts a script?" is: The sprite being clicked**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How many scripts does each key get?" is: The user**
**Answer: False** — Its own small script

**9. (Sub lesson 2) True or false: the answer to "What is each key’s script doing until its key is pressed?" is: Waiting for its event**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Who drives the sprite once events are built?" is: At the top of a script**
**Answer: False** — The user
