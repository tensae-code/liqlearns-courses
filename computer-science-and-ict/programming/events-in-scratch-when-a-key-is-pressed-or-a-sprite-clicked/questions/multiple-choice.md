# Events in Scratch — When a Key Is Pressed or a Sprite Clicked — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does an event block do?**
a) It starts a script when its event happens  b) At the top of a script  c) Arrows, letters and numbers  d) With the keyboard, one script per key
**Answer: a) It starts a script when its event happens**

**2. (Sub lesson 1) Where does an event block sit?**
a) It has no moment to run at  b) At the top of a script  c) Event blocks are what start a script  d) The sprite being clicked
**Answer: b) At the top of a script**

**3. (Sub lesson 1) What happens to a stack with no event at its top?**
a) Arrows, letters and numbers  b) With the keyboard, one script per key  c) It has no moment to run at  d) Its own small script
**Answer: c) It has no moment to run at**

**4. (Sub lesson 1) What keys does the book use for key events?**
a) Event blocks are what start a script  b) The sprite being clicked  c) Waiting for its event  d) Arrows, letters and numbers
**Answer: d) Arrows, letters and numbers**

**5. (Sub lesson 1) What is Grade 7’s plain rule about events?**
a) Event blocks are what start a script  b) With the keyboard, one script per key  c) Its own small script  d) The user
**Answer: a) Event blocks are what start a script**

**6. (Sub lesson 2) How is a sprite driven in Grade 6’s lesson?**
a) The sprite being clicked  b) With the keyboard, one script per key  c) Waiting for its event  d) It starts a script when its event happens
**Answer: b) With the keyboard, one script per key**

**7. (Sub lesson 2) What other event starts a script?**
a) Its own small script  b) The user  c) The sprite being clicked  d) At the top of a script
**Answer: c) The sprite being clicked**

**8. (Sub lesson 2) How many scripts does each key get?**
a) Waiting for its event  b) It starts a script when its event happens  c) It has no moment to run at  d) Its own small script
**Answer: d) Its own small script**

**9. (Sub lesson 2) What is each key’s script doing until its key is pressed?**
a) Waiting for its event  b) The user  c) At the top of a script  d) Arrows, letters and numbers
**Answer: a) Waiting for its event**

**10. (Sub lesson 2) Who drives the sprite once events are built?**
a) It starts a script when its event happens  b) The user  c) It has no moment to run at  d) Event blocks are what start a script
**Answer: b) The user**
