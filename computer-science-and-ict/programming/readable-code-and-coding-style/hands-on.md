# Hands-on — Readable Code and Coding Style

The lesson with your hands and your feet, not only your eyes.

## Task one
**Rename the mystery** — Take a page of code with short names (a, b, x1, f). Rename every name to say what it holds or does. Read both versions aloud to a partner — which one can they explain back?

## Task two
**Style sheet** — Write a one-page style sheet for your class: naming shape, indentation width, brace place, comment rules, line length. Format one old program to obey it.
