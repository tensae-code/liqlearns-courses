**8. (Sub lesson 2) Is one style magically best?** → **No — an agreed, kept style beats a 'better' style kept only sometimes**

**9. (Sub lesson 2) Name two things that keep a style.** → **Code review, and automatic formatting tools (plus the team's agreement)**
