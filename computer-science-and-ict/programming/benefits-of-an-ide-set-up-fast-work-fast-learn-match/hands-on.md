# Hands-on — Benefits of an IDE — set up fast, work fast, learn, match

The lesson with your hands, not only your eyes.

## Badge match race
Four badges drawn on cards, four benefit descriptions on others. Pairs race to match them correctly — then check against Picture 15732.

## Instant flag demo
Write a line of pseudocode with a deliberate syntax error on the board. A partner plays the IDE: the moment the error is written, they raise a red card. That instant flag is benefit two.
