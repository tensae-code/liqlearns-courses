## The goal, and the first two benefits

The overall goal and main benefit of an IDE is **improved developer productivity**. It arrives four ways. The first two:

1. **Faster setup** — one integrated place instead of configuring and switching among separate tools.
2. **Faster development tasks** — tight integration: code is **parsed and syntax-checked while it is edited**, so **errors are flagged instantly**; resources are organised, mistakes prevented, shortcuts offered — and developers are pushed to think in **whole development lifecycle** rather than discrete tasks.

## The second two benefits

3. **Continual learning** — constantly updated **help topics, samples and project templates** keep programmers current.
4. **Standardisation** — **one interface**, so developers work together smoothly and **new hires get up to speed quickly**.
