# Benefits of an IDE — set up fast, work fast, learn, match — multiple choice

Pick the one right answer.

**1.** The main benefit of an IDE is —
a) cheaper computers  b) improved developer productivity  c) free internet  d) smaller files
**Answer: b) improved developer productivity** — the overall goal, served four ways.

**2.** Faster setup comes from —
a) one integrated place instead of configuring separate tools  b) typing faster  c) a bigger screen  d) working at night
**Answer: a) one integrated place instead of configuring separate tools** — no switching among tools.

**3.** Errors are flagged instantly because —
a) the teacher watches  b) code is parsed and syntax-checked while it is edited  c) the IDE deletes mistakes silently  d) programs have no errors
**Answer: b) code is parsed and syntax-checked while it is edited** — tight integration at work.

**4.** Continual learning is kept up by —
a) exams  b) constantly updated help topics, samples and project templates  c) new computers yearly  d) longer hours
**Answer: b) constantly updated help topics, samples and project templates** — programmers stay current.

**5.** Standardisation helps most directly by —
a) making screens prettier  b) letting developers work together smoothly and new hires speed up quickly  c) using one language only  d) removing the debugger
**Answer: b) letting developers work together smoothly and new hires speed up quickly** — one interface for all.
