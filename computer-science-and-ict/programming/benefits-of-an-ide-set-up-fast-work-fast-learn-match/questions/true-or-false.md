# Benefits of an IDE — set up fast, work fast, learn, match — true or false

Say whether each sentence is true or false.

**1.** Developers in an IDE are pushed to think in discrete tasks only.
**Answer: False** — in whole development lifecycle, not discrete tasks.

**2.** Shortcuts and organised resources are part of faster development tasks.
**Answer: True** — with mistakes prevented.

**3.** There are four benefits named in this lesson.
**Answer: True** — setup, work, learning, standardisation.
