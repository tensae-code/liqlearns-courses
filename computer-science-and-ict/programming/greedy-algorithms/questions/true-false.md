# Greedy Algorithms — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Takes the locally best choice — and never looks back or reconsiders**
**Answer: True**

**2. (Sub lesson 1) True or false: Takes the locally best choice — and never looks back or reconsiders** — as the answer to: What three 'best now' examples does the lesson name?
**Answer: False — The largest coin, the earliest-finishing activity, the nearest city**

**3. (Sub lesson 1) True or false: No table and no backtracking — just a rule for 'best now'**
**Answer: True**

**4. (Sub lesson 1) True or false: No table and no backtracking — just a rule for 'best now'** — as the answer to: What is its school example?
**Answer: False — Coin change — always take the largest coin that fits**

**5. (Sub lesson 1) True or false: The best now can poison the whole**
**Answer: True**

**6. (Sub lesson 2) True or false: The best now can poison the whole** — as the answer to: Give the failing coin example.
**Answer: False — Coins 1, 3, 4 making 6: greedy takes 4+1+1 (three coins); 3+3 needs two**

**7. (Sub lesson 2) True or false: Asking whether a locally best choice can ever block a globally best answer**
**Answer: True**

**8. (Sub lesson 2) True or false: Asking whether a locally best choice can ever block a globally best answer** — as the answer to: For which problems is greedy a proof, not a gamble?
**Answer: False — Problems built so a local best can never close a needed door**

**9. (Sub lesson 2) True or false: Between recursion and dynamic programming**
**Answer: True**

**10. (Sub lesson 2) True or false: Between recursion and dynamic programming** — as the answer to: Where does Indonesia teach this?
**Answer: False — Grade 11, Bab III B.2 — greedy algorithms**
