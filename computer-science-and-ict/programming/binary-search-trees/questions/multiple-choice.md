# Binary Search Trees — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What rule rules a binary search tree?**
a) At every node, the left subtree holds smaller values and the right subtree larger ones  b) Compare with the node: smaller goes left, larger goes right, equal is found  c) Half the remaining tree  d) Grow — new values are inserted into their place in the structure
**Answer: a**

**Answer: a**
