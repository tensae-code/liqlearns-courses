# Binary Search Trees — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: At every node, the left subtree holds smaller values and the right subtree larger ones**
**Answer: True**

**2. (Sub lesson 1) True or false: At every node, the left subtree holds smaller values and the right subtree larger ones** — as the answer to: How is a value searched for?
**Answer: False — Compare with the node: smaller goes left, larger goes right, equal is found**

**3. (Sub lesson 1) True or false: Half the remaining tree**
**Answer: True**

**4. (Sub lesson 1) True or false: Half the remaining tree** — as the answer to: What can a BST do that a sorted list cannot easily do?
**Answer: False — Grow — new values are inserted into their place in the structure**

**5. (Sub lesson 1) True or false: The first comparison — its value sends the search left or right**
**Answer: True**

**6. (Sub lesson 2) True or false: The first comparison — its value sends the search left or right** — as the answer to: How is a value inserted?
**Answer: False — Walk the search path and attach it as a leaf where the path runs out**

**7. (Sub lesson 2) True or false: It is simply removed**
**Answer: True**

**8. (Sub lesson 2) True or false: It is simply removed** — as the answer to: How is a node with two children deleted?
**Answer: False — Its value is replaced by a value from below — its successor — so the ordering rule survives**

**9. (Sub lesson 2) True or false: Its shape — a balanced tree is fast, a crooked line is a list**
**Answer: True**

**10. (Sub lesson 2) True or false: Its shape — a balanced tree is fast, a crooked line is a list** — as the answer to: What insertion order ruins the shape?
**Answer: False — Already-sorted values, one after another**
