# Hands-on — Assigning a Value to a Variable

The lesson with your hands and your feet, not only your eyes.

## Trace the stores
Trace: int a = 3; int b = a; a = a + 2; b = b + a;. Write the value of a and b after every line, and point at the line where an old value was destroyed.

## Swap them
Write the three assignments that swap x and y using a temporary variable. Trace them with x = 4, y = 9 to prove the swap works.
