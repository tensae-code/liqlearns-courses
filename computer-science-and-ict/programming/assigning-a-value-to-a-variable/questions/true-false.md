# Assigning a Value to a Variable — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is evaluated first in an assignment?" is: The right-hand side, completely**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What happens to the variable's old value?" is: With the declaration — int x = 0;**
**Answer: False** — It is replaced — destroyed

**3. (Sub lesson 1) True or false: the answer to "What does a declared-but-unassigned variable hold?" is: Garbage, until assignment or input**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is initialisation?" is: Adds 1 to x's current value and stores it back**
**Answer: False** — A variable's first assignment

**5. (Sub lesson 1) True or false: the answer to "How is initialisation often written?" is: With the declaration — int x = 0;**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does a single = mean in C++?" is: The first store would destroy a value the swap still needs**
**Answer: False** — Store — not equals

**7. (Sub lesson 2) True or false: the answer to "What does x = x + 1 do?" is: Adds 1 to x's current value and stores it back**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What job does x = x + 1 do in loops?" is: The right-hand side, completely**
**Answer: False** — The counter step

**9. (Sub lesson 2) True or false: the answer to "Why does swapping need a third variable?" is: The first store would destroy a value the swap still needs**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Which sign tests equality instead?" is: Garbage, until assignment or input**
**Answer: False** — == (double equals)
