# Assigning a Value to a Variable — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is evaluated first in an assignment?**
a) The right-hand side, completely  b) It is replaced — destroyed  c) Garbage, until assignment or input  d) A variable's first assignment
**Answer: a) The right-hand side, completely**

**2. (Sub lesson 1) What happens to the variable's old value?**
a) Garbage, until assignment or input  b) It is replaced — destroyed  c) A variable's first assignment  d) With the declaration — int x = 0;
**Answer: b) It is replaced — destroyed**

**3. (Sub lesson 1) What does a declared-but-unassigned variable hold?**
a) A variable's first assignment  b) With the declaration — int x = 0;  c) Garbage, until assignment or input  d) Store — not equals
**Answer: c) Garbage, until assignment or input**

**4. (Sub lesson 1) What is initialisation?**
a) With the declaration — int x = 0;  b) Store — not equals  c) Adds 1 to x's current value and stores it back  d) A variable's first assignment
**Answer: d) A variable's first assignment**

**5. (Sub lesson 1) How is initialisation often written?**
a) With the declaration — int x = 0;  b) Store — not equals  c) Adds 1 to x's current value and stores it back  d) The counter step
**Answer: a) With the declaration — int x = 0;**

**6. (Sub lesson 2) What does a single = mean in C++?**
a) Adds 1 to x's current value and stores it back  b) Store — not equals  c) The counter step  d) The first store would destroy a value the swap still needs
**Answer: b) Store — not equals**

**7. (Sub lesson 2) What does x = x + 1 do?**
a) The counter step  b) The first store would destroy a value the swap still needs  c) Adds 1 to x's current value and stores it back  d) == (double equals)
**Answer: c) Adds 1 to x's current value and stores it back**

**8. (Sub lesson 2) What job does x = x + 1 do in loops?**
a) The first store would destroy a value the swap still needs  b) == (double equals)  c) The right-hand side, completely  d) The counter step
**Answer: d) The counter step**

**9. (Sub lesson 2) Why does swapping need a third variable?**
a) The first store would destroy a value the swap still needs  b) == (double equals)  c) The right-hand side, completely  d) It is replaced — destroyed
**Answer: a) The first store would destroy a value the swap still needs**

**10. (Sub lesson 2) Which sign tests equality instead?**
a) The right-hand side, completely  b) == (double equals)  c) It is replaced — destroyed  d) Garbage, until assignment or input
**Answer: b) == (double equals)**
