# Visual Basic — Starting a Project and Adding Controls — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is the first stage of building a program?**
**Answer: Planning — what it is for, what its window shows, what its user will do**

**2. (Sub lesson 1) Where is the plan made?**
**Answer: On paper, before a project is created**

**3. (Sub lesson 1) What does an unplanned form collect?**
**Answer: Controls the way a desk collects papers — without purpose**

**4. (Sub lesson 1) What is created from the plan?**
**Answer: A new project in the environment**

**5. (Sub lesson 1) What is the form?**
**Answer: The program's window**

**6. (Sub lesson 2) How are controls added?**
**Answer: Taken from the toolbox, placed on the form, positioned and sized**

**7. (Sub lesson 2) What is 'adding' called in the lesson's terms?**
**Answer: The visual language's core verb — the interface is assembled**

**8. (Sub lesson 2) Does the placed form already behave?**
**Answer: No — code gives it behaviour later; the look comes first**

**9. (Sub lesson 2) Which book of the course is this?**
**Answer: Part 1, Book 2 — Stages of Building a Program, Chapter 1**

**10. (Sub lesson 2) Which book teaches this?**
**Answer: Kuwait Grade 12 Information Technology Term 1, Part 1 Book 2 Chapter 1**
