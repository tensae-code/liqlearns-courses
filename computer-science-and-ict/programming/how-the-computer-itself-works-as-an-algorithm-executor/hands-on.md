# Hands-on — How the Computer Itself Works as an Algorithm Executor

The lesson with your hands and your feet, not only your eyes.

## Task one
**Cycle acting** — Act the cycle with cards: one pupil is memory holding instructions, one the program counter, one the processor fetching-decoding-executing a five-instruction program with a loop.

## Task two
**Executor table** — Build a comparison table — command set, obedience, speed, judgement — for a person, the Kangaroo and the computer, from the chapter.
