# Visual Basic — Hands-on Programming Examples — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "How many hands-on examples does Fiji build into the chapter?" is: Two — one after the controls, one after variables and data types**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does the first example gather?" is: Surface first — form and controls — behaviour (code) behind it**
**Answer: False** — The IDE, good-application habits and the wider controls, into one small working application

**3. (Sub lesson 1) True or false: the answer to "In what order is a Visual Basic program assembled?" is: Surface first — form and controls — behaviour (code) behind it**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What are the first build's steps?" is: That the separately described parts work as one thing when assembled**
**Answer: False** — Form laid out, controls placed and named, code written, program run and corrected

**5. (Sub lesson 1) True or false: the answer to "What is the first build's lesson?" is: That the separately described parts work as one thing when assembled**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Why does the second build follow the variables chapter?" is: Input–process–output, inside a real window**
**Answer: False** — It puts variables and data types to work — values in, stored, processed, results shown

**7. (Sub lesson 2) True or false: the answer to "What shape does the second build follow?" is: Input–process–output, inside a real window**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What do controls without data make?" is: A face — no window for the user**
**Answer: False** — Posters

**9. (Sub lesson 2) True or false: the answer to "What does data without controls lack?" is: A face — no window for the user**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What has a learner who did both builds gained?" is: Two — one after the controls, one after variables and data types**
**Answer: False** — The course's two hands — not only its reading
