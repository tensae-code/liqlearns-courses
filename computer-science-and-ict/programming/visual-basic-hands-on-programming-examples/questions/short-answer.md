# Visual Basic — Hands-on Programming Examples — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) How many hands-on examples does Fiji build into the chapter?**
**Answer: Two — one after the controls, one after variables and data types**

**2. (Sub lesson 1) What does the first example gather?**
**Answer: The IDE, good-application habits and the wider controls, into one small working application**

**3. (Sub lesson 1) In what order is a Visual Basic program assembled?**
**Answer: Surface first — form and controls — behaviour (code) behind it**

**4. (Sub lesson 1) What are the first build's steps?**
**Answer: Form laid out, controls placed and named, code written, program run and corrected**

**5. (Sub lesson 1) What is the first build's lesson?**
**Answer: That the separately described parts work as one thing when assembled**

**6. (Sub lesson 2) Why does the second build follow the variables chapter?**
**Answer: It puts variables and data types to work — values in, stored, processed, results shown**

**7. (Sub lesson 2) What shape does the second build follow?**
**Answer: Input–process–output, inside a real window**

**8. (Sub lesson 2) What do controls without data make?**
**Answer: Posters**

**9. (Sub lesson 2) What does data without controls lack?**
**Answer: A face — no window for the user**

**10. (Sub lesson 2) What has a learner who did both builds gained?**
**Answer: The course's two hands — not only its reading**
