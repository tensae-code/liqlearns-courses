# Visual Basic — Hands-on Programming Examples

## Do it first

Fiji's Year 12 Visual Basic course does not leave its teaching in descriptions: twice it stops and builds — 'Trying a hands-on Programming Example', first after the controls, then again after variables and data types. This lesson is that pair of worked builds, taught the way Fiji teaches them: by doing.

## Sub lesson 1 — First build — a working window from the controls

The first hands-on example (printed p. 88) gathers everything before it — the IDE, good-application habits and the wider controls — into **one small working application built step by step**: form laid out, controls placed and named, code written behind them, program run and corrected. Its lesson is the course's method: a Visual Basic program is *assembled* — surface first, behaviour behind it — and every part the chapters described separately is felt working as one thing.

[Picture — First build — a working window from the controls]

## Sub lesson 2 — Second build — variables and data types at work

The second example (printed p. 99) follows the variables chapter for a reason: it builds a program that **takes in values, stores them in variables of chosen types, works on them and shows the result** — the input–process–output shape inside a real window. Fiji's two builds frame the whole chapter: controls without data make posters; data without controls has no face. A learner who has done both builds has not only read the course — they have its two hands.
