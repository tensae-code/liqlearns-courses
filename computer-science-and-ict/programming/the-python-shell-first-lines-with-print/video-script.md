Open IDLE. This is the Python shell.

See the three signs? >>>
That is the prompt. That is where you type.

Type: 5 + 6
Press Enter.
Look - 11. The shell worked it out and showed the value.
And the prompt is back. >>> Ready again.

Now type: 5 +
Press Enter.
An error! A syntax error.
The line broke the rules, so there is no answer.

Now the printing function. Type:
print("Selam")
Press Enter.
Selam - on the screen, with no quotes.
print() displays what is inside.

Watch the colours as you type.
Output - blue. Functions - purple. Strings - green.
IDLE is helping your eyes.

Your turn. Print YOUR full name.
Type it. Enter. There it is.
