# The Python shell - first lines with print() - true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** After a line runs, the >>> prompt comes back, ready for the next line.
**Answer: True** - that is the shell's rhythm.

**2. (Sub lesson 2)** An invalid expression like 5 + still shows a value.
**Answer: False** - it raises a syntax error - there is no value to show.

**3. (Sub lesson 3)** print() displays the quotation marks as part of the output.
**Answer: False** - the quotes mark the string in code; the displayed text has none.
