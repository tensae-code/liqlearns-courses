# The Python shell - first lines with print() - multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** In the Python shell, code is typed at -
a) the Run menu  b) the >>> prompt  c) the title bar  d) the print() function
**Answer: b) the >>> prompt** - the prompt is the shell's typing place.

**2. (Sub lesson 1)** After you type a line, it runs when you -
a) save the file  b) press Enter  c) close IDLE  d) click print
**Answer: b) press Enter** - Enter runs it - and brings the prompt back.

**3. (Sub lesson 2)** Typing 5 + 6 in the shell shows -
a) an error  b) 11  c) 5 + 6 again  d) nothing
**Answer: b) 11** - a valid expression is evaluated and its value shown.

**4. (Sub lesson 2)** Typing 5 + in the shell -
a) shows 5  b) shows 0  c) raises a syntax error  d) prints a string
**Answer: c) raises a syntax error** - the line is invalid - it breaks the rules.

**5. (Sub lesson 3)** print() is used to -
a) store a value  b) display output - here, a string  c) open a file  d) translate a program
**Answer: b) display output - here, a string** - print() displays what it is given.

**6. (Sub lesson 3)** In IDLE's colour code, output is shown in -
a) green  b) purple  c) blue  d) red
**Answer: c) blue** - output blue, functions purple, strings green.

**7. (Sub lesson 3)** In print("Selam"), IDLE colours the string -
a) blue  b) purple  c) green  d) black
**Answer: c) green** - strings are green; the function name is purple.
