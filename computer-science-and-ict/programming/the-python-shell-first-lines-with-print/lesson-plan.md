# Lesson plan - The Python shell - first lines with print()

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** The Python shell - first lines with print()
**Place in the curriculum:** Unit 6 - Fundamentals of Programming (CURRICULUM.md).
**The one thing this lesson teaches:** in the Python shell you type at the >>> prompt and press Enter to run a line; a valid expression shows its value, an invalid one raises a syntax error, and print() displays output such as a string.
**This lesson's own level:** it stands on it stands on Python and IDLE - where Python code is written: this lesson works in the first of IDLE's two places, the interactive interpreter. It needs nothing else.

## Sub lessons
The parts of this lesson, in order - the list the learner sees from the start, locked ahead, each opening when the one before it is proved (the gate: README, "Units, Lessons and Sub Lessons (ruled 2026-11-08)"):

1. **The >>> prompt - type, Enter, answer** - The shell's >>> prompt is where code is typed; pressing Enter runs the line and brings the prompt back. The GIF shows the typing rhythm.
2. **Expressions in the shell - valid and invalid** - A valid expression is evaluated and its value shown (5+6 gives 11); an invalid one (5+) raises a syntax error.
3. **print() - displaying output, and IDLE's colours** - Output is produced with the print() function, used here to display a string; IDLE colours output blue, functions purple and strings green. Practice: display your own full name.

Gate pool: all questions of the sub lesson - no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## What the learner can do when it ends
1. Type a line at the >>> prompt and run it with Enter, and say what happens next.
2. Say what the shell does with a valid expression, and with an invalid one.
3. Use print() to display a string - including your own full name.
4. Read IDLE's colours: output in blue, functions in purple, strings in green.

## If the learner is stuck
- Waits for something to happen after typing -> nothing runs until Enter is pressed; Enter is the run command of the shell.
- Surprised that print() drops the quotes -> the quotes mark the string in the code; print() displays the text itself, without them.
