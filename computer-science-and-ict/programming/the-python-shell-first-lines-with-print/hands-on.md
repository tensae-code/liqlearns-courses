# Hands-on - The Python shell - first lines with print()

The lesson with your hands, not only your eyes.

## Paper shell

One pupil is the shell, one is the typist. The typist 'types' a line on paper and slides it across; the shell pupil writes the value - or 'SyntaxError' - and slides back a fresh >>> prompt. Five rounds, then swap. Use 5 + 6, 5 +, and print() with a name.

## Colour hunt

On a printed or drawn shell session, colour the parts with three pencils: blue for output, purple for the function name, green for the string - IDLE's own colour code, by hand.
