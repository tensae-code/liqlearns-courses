# Assignment and Output in Pascal — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "How is assignment written in Pascal?" is: With := **
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does x := 5 do?" is: The left side — the variable**
**Answer: False** — Puts 5 into the variable x, replacing what was there

**3. (Sub lesson 1) True or false: the answer to "Which side receives the value?" is: The left side — the variable**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What may the right side be?" is: Assignment is not equality — the right side is worked out, then stored**
**Answer: False** — A number, another variable, or an expression

**5. (Sub lesson 1) True or false: the answer to "Why is x := x + 1 allowed?" is: Assignment is not equality — the right side is worked out, then stored**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Which two words write output in Pascal?" is: A move to a new line**
**Answer: False** — write and writeln

**7. (Sub lesson 2) True or false: the answer to "What does writeln add after the output?" is: A move to a new line**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How is text shown in an output statement?" is: The value of x**
**Answer: False** — In apostrophes

**9. (Sub lesson 2) True or false: the answer to "What does writeln(x) show?" is: The value of x**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is the book's next lesson after this one?" is: With := **
