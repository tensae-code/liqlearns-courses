# The Char Type in Pascal and C++ — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What does char hold?** → **Exactly one character — letter, digit-character, mark or space**

**2. (Sub lesson 1) How is a char written in the two languages?** → **In apostrophes in both — 'A'**

**3. (Sub lesson 1) What is "A" in C++?** → **A string of length 1 — a different type from the char 'A'**

**4. (Sub lesson 1) How is a character stored?** → **As its code number in the code table**

**5. (Sub lesson 1) Which earlier lessons built the code idea?** → **Grade 7's encoding lessons**

**6. (Sub lesson 2) By what do characters compare?** → **By their code numbers — 'A' < 'B'**

**7. (Sub lesson 2) What do ord and chr do?** → **ord gives a character's code; chr turns a code back into its character**

**8. (Sub lesson 2) Is '7' the number 7?** → **No — it is the character with code 55**

**9. (Sub lesson 2) How is a digit-character turned into its value?** → **ord('7') − ord('0') = 7**

**10. (Sub lesson 2) Why does case arithmetic work?** → **Capitals and smalls stand a fixed distance apart in the table**
