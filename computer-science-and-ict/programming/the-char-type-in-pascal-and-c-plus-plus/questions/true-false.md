# The Char Type in Pascal and C++ — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Exactly one character — letter, digit-character, mark or space**
**Answer: True**

**2. (Sub lesson 1) True or false: Exactly one character — letter, digit-character, mark or space** — as the answer to: How is a char written in the two languages?
**Answer: False — In apostrophes in both — 'A'**

**3. (Sub lesson 1) True or false: A string of length 1 — a different type from the char 'A'**
**Answer: True**

**4. (Sub lesson 1) True or false: A string of length 1 — a different type from the char 'A'** — as the answer to: How is a character stored?
**Answer: False — As its code number in the code table**

**5. (Sub lesson 1) True or false: Grade 7's encoding lessons**
**Answer: True**

**6. (Sub lesson 2) True or false: Grade 7's encoding lessons** — as the answer to: By what do characters compare?
**Answer: False — By their code numbers — 'A' < 'B'**

**7. (Sub lesson 2) True or false: ord gives a character's code; chr turns a code back into its character**
**Answer: True**

**8. (Sub lesson 2) True or false: ord gives a character's code; chr turns a code back into its character** — as the answer to: Is '7' the number 7?
**Answer: False — No — it is the character with code 55**

**9. (Sub lesson 2) True or false: ord('7') − ord('0') = 7**
**Answer: True**

**10. (Sub lesson 2) True or false: ord('7') − ord('0') = 7** — as the answer to: Why does case arithmetic work?
**Answer: False — Capitals and smalls stand a fixed distance apart in the table**
