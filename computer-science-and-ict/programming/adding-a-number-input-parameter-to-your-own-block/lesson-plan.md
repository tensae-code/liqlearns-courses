**The one thing this lesson teaches:** A My Block grows stronger with an input parameter: add a number input and the same block takes a size each time it is used — one square block drawing any square, one Petal block drawing flowers of different sizes.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Adding a number input** — An **input parameter** is a value the block **receives when it is used**. Add a **number input** to a My Block and a hole appears in the block for the number; inside the definition, that input can be used anywhere a number can — the block's code now works for the given value instead of one fixed value.
2. **A square of any size — flowers of different sizes** — Give the square block a **size input**: the drive distance inside reads the input, so one block draws a **square of any size** the caller names. The guide does the same to the **Petal block**: with a size input, the same petal definition draws **flowers of different sizes** — one definition, a garden of sizes.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
