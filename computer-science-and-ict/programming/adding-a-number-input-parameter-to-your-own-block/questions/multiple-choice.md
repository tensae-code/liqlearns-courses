# Adding a Number Input Parameter to Your Own Block — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is an input parameter?**
a) A value the block receives when it is used  b) A block that works for the given value  c) One  d) The definition
**Answer: a) A value the block receives when it is used**

**2. (Sub lesson 1) What appears in the block when you add a number input?**
a) The drive distance inside  b) A hole for the number  c) Drawing flowers of different sizes  d) The caller, at each use
**Answer: b) A hole for the number**

**3. (Sub lesson 1) Where can the input be used inside the definition?**
a) One  b) The definition  c) Anywhere a number can  d) One Petal definition used at different sizes
**Answer: c) Anywhere a number can**

**4. (Sub lesson 1) What did the fixed block become?**
a) Drawing flowers of different sizes  b) The caller, at each use  c) A value the block receives when it is used  d) A block that works for the given value
**Answer: d) A block that works for the given value**

**5. (Sub lesson 1) What does the square block's size input control?**
a) The drive distance inside  b) The definition  c) One Petal definition used at different sizes  d) A hole for the number
**Answer: a) The drive distance inside**

**6. (Sub lesson 2) How many blocks draw a square of any size now?**
a) The caller, at each use  b) One  c) A value the block receives when it is used  d) Anywhere a number can
**Answer: b) One**

**7. (Sub lesson 2) What does the Petal block gain a size input for?**
a) One Petal definition used at different sizes  b) A hole for the number  c) Drawing flowers of different sizes  d) A block that works for the given value
**Answer: c) Drawing flowers of different sizes**

**8. (Sub lesson 2) What stays one, while sizes vary?**
a) A value the block receives when it is used  b) Anywhere a number can  c) The drive distance inside  d) The definition
**Answer: d) The definition**

**9. (Sub lesson 2) Who names the size — the definition or the caller?**
a) The caller, at each use  b) A hole for the number  c) A block that works for the given value  d) One
**Answer: a) The caller, at each use**

**10. (Sub lesson 2) What is the garden in the guide's project made by?**
a) Anywhere a number can  b) One Petal definition used at different sizes  c) The drive distance inside  d) Drawing flowers of different sizes
**Answer: b) One Petal definition used at different sizes**
