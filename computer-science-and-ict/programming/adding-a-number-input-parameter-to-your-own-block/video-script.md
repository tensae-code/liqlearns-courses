# Video script — Adding a Number Input Parameter to Your Own Block

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

An **input parameter** is a value the block **receives when it is used**. Add a **number input** to a My Block and a hole appears in the block for the number; inside the definition, that input can be used anywhere a number can — the block's code now works for the given value instead of one fixed value.
Give the square block a **size input**: the drive distance inside reads the input, so one block draws a **square of any size** the caller names. The guide does the same to the **Petal block**: with a size input, the same petal definition draws **flowers of different sizes** — one definition, a garden of sizes.
