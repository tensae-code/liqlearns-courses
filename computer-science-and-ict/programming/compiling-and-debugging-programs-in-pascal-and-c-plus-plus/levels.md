# Compiling and Debugging Programs in Pascal and C++ — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Compiling — from text to running program
Sub lesson 1 questions from the type files. Pass mark: It translates the whole program text into machine language before any of it runs; It stops compilation — the compiler lists errors by line; The libraries' ready pieces, joined into one executable file; That the text is legal — not yet that the program is right; By line, in terse messages the annexes teach to read.

## Sub lesson 2 — Debugging — hunting the errors the compiler cannot see
Sub lesson 2 questions from the type files. Pass mark: Runtime errors (division by zero, endless loops) and logic errors (wrong answers); Reproduce small, watch the values, locate the first wrong moment, fix, test again; A chosen line where the run pauses so the state can be inspected; Inserted print statements, and the debugger's stepping with breakpoints; It is half the craft — practised by method, not by staring.
