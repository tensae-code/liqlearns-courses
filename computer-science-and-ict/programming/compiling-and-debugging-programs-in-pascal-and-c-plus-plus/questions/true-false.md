# Compiling and Debugging Programs in Pascal and C++ — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: It translates the whole program text into machine language before any of it runs**
**Answer: True**

**2. (Sub lesson 1) True or false: It translates the whole program text into machine language before any of it runs** — as the answer to: What does a syntax error do?
**Answer: False — It stops compilation — the compiler lists errors by line**

**3. (Sub lesson 1) True or false: The libraries' ready pieces, joined into one executable file**
**Answer: True**

**4. (Sub lesson 1) True or false: The libraries' ready pieces, joined into one executable file** — as the answer to: What does a clean compile prove?
**Answer: False — That the text is legal — not yet that the program is right**

**5. (Sub lesson 1) True or false: By line, in terse messages the annexes teach to read**
**Answer: True**

**6. (Sub lesson 2) True or false: By line, in terse messages the annexes teach to read** — as the answer to: Which errors survive compilation?
**Answer: False — Runtime errors (division by zero, endless loops) and logic errors (wrong answers)**

**7. (Sub lesson 2) True or false: Reproduce small, watch the values, locate the first wrong moment, fix, test again**

**8. (Sub lesson 2) True or false: Reproduce small, watch the values, locate the first wrong moment, fix, test again** — as the answer to: What is a breakpoint?
**Answer: False — A chosen line where the run pauses so the state can be inspected**

**Answer: True**
