# Visual Basic — the INPUTBOX Function — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is INPUTBOX?**
**Answer: Visual Basic's input function — a ready-made box that asks the user for a value while the program runs**

**2. (Sub lesson 1) What happens when INPUTBOX runs?**
**Answer: The program pauses and shows a small box with a prompt and a space to type in**

**3. (Sub lesson 1) What is the prompt?**
**Answer: The question written for the user, passed as the function's argument**

**4. (Sub lesson 1) What does the user do?**
**Answer: Types an answer and confirms; the program then continues**

**5. (Sub lesson 1) What does INPUTBOX hand back?**
**Answer: What the user typed, as the function's result**

**6. (Sub lesson 2) Where must the result go?**
**Answer: Into a variable, assigned in the same line**

**7. (Sub lesson 2) What happens if the result is not assigned?**
**Answer: The answer is shown and lost**

**8. (Sub lesson 2) Write the shape of an INPUTBOX line.**
**Answer: variable = INPUTBOX("prompt") — e.g. name = INPUTBOX("What is your name?")**

**9. (Sub lesson 2) Which chapter of Libya's book teaches INPUTBOX?**
**Answer: The 'interacting with the computer' chapter, Grade 11 Term 1, Chapter 6**

**10. (Sub lesson 2) Which statement is INPUTBOX's partner — the showing half?**
**Answer: PRINT**
