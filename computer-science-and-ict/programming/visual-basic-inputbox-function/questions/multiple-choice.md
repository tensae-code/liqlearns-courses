# Visual Basic — the INPUTBOX Function — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is INPUTBOX?**
a) Visual Basic's input function — a ready-made box that asks the user for a value while the program runs  b) The program pauses and shows a small box with a prompt and a space to type in  c) The question written for the user, passed as the function's argument  d) Types an answer and confirms; the program then continues
**Answer: a) Visual Basic's input function — a ready-made box that asks the user for a value while the program runs**

**2. (Sub lesson 1) What happens when INPUTBOX runs?**
a) The question written for the user, passed as the function's argument  b) The program pauses and shows a small box with a prompt and a space to type in  c) Types an answer and confirms; the program then continues  d) What the user typed, as the function's result
**Answer: b) The program pauses and shows a small box with a prompt and a space to type in**

**3. (Sub lesson 1) What is the prompt?**
a) Types an answer and confirms; the program then continues  b) What the user typed, as the function's result  c) The question written for the user, passed as the function's argument  d) Into a variable, assigned in the same line
**Answer: c) The question written for the user, passed as the function's argument**

**4. (Sub lesson 1) What does the user do?**
a) What the user typed, as the function's result  b) Into a variable, assigned in the same line  c) The answer is shown and lost  d) Types an answer and confirms; the program then continues
**Answer: d) Types an answer and confirms; the program then continues**
