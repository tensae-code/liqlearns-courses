# Visual Basic — the INPUTBOX Function — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is INPUTBOX?" is: Visual Basic's input function — a ready-made box that asks the user for a value while the program runs**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What happens when INPUTBOX runs?" is: The question written for the user, passed as the function's argument**
**Answer: False** — The program pauses and shows a small box with a prompt and a space to type in

**3. (Sub lesson 1) True or false: the answer to "What is the prompt?" is: The question written for the user, passed as the function's argument**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does the user do?" is: What the user typed, as the function's result**
**Answer: False** — Types an answer and confirms; the program then continues

**5. (Sub lesson 1) True or false: the answer to "What does INPUTBOX hand back?" is: What the user typed, as the function's result**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Where must the result go?" is: The answer is shown and lost**
**Answer: False** — Into a variable, assigned in the same line

**7. (Sub lesson 2) True or false: the answer to "What happens if the result is not assigned?" is: The answer is shown and lost**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Write the shape of an INPUTBOX line." is: The 'interacting with the computer' chapter, Grade 11 Term 1, Chapter 6**
**Answer: False** — variable = INPUTBOX("prompt") — e.g. name = INPUTBOX("What is your name?")

**9. (Sub lesson 2) True or false: the answer to "Which chapter of Libya's book teaches INPUTBOX?" is: The 'interacting with the computer' chapter, Grade 11 Term 1, Chapter 6**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Which statement is INPUTBOX's partner — the showing half?" is: Visual Basic's input function — a ready-made box that asks the user for a value while the program runs**
**Answer: False** — PRINT
