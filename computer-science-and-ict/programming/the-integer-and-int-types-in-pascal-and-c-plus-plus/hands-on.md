# Hands-on — The Integer and int Types in Pascal and C++

The lesson with your hands and your feet, not only your eyes.

## Task one
**Family table** — Build the table of both families: type, bytes (from the book), signed range, unsigned range — and mark the school-default type of each language.

## Task two
**Division drill** — Compute, in both languages: 17/5, 17 div 5, 17 mod 5, 17%5, −17/5 — and explain the negative case by each language's rule.
