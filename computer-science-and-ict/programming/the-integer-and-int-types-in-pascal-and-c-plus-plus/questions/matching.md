# The Integer and int Types in Pascal and C++ — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) Name Pascal's whole-number family members.** → **shortint, byte, integer, longint**

**2. (Sub lesson 1) Name C++'s.** → **short, int, long**

**3. (Sub lesson 1) What does each size fix?** → **A range — 2ⁿ patterns**

**4. (Sub lesson 1) What does an unsigned twin spend its patterns on?** → **0 and positives only — doubling the top at the price of negatives**

**5. (Sub lesson 1) What is chosen when a whole-number type is chosen?** → **Range and sign, together**

**6. (Sub lesson 2) What are Pascal's three division answers?** → **/ gives a real; div the whole quotient; mod the remainder**

**7. (Sub lesson 2) What is 7 / 2 in C++ integer arithmetic?** → **3 — the whole quotient, fraction discarded**

**8. (Sub lesson 2) What is C++'s % ?** → **Its mod — the remainder (7 % 2 = 1)**

**9. (Sub lesson 2) What fixes what an operator does?** → **The language and the operands' types together — never the symbol alone**
