# The Integer and int Types in Pascal and C++ — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: shortint, byte, integer, longint**
**Answer: True**

**2. (Sub lesson 1) True or false: shortint, byte, integer, longint** — as the answer to: Name C++'s.
**Answer: False — short, int, long**

**3. (Sub lesson 1) True or false: A range — 2ⁿ patterns**
**Answer: True**

**4. (Sub lesson 1) True or false: A range — 2ⁿ patterns** — as the answer to: What does an unsigned twin spend its patterns on?
**Answer: False — 0 and positives only — doubling the top at the price of negatives**

**5. (Sub lesson 1) True or false: Range and sign, together**
**Answer: True**

**6. (Sub lesson 2) True or false: Range and sign, together** — as the answer to: What are Pascal's three division answers?
**Answer: False — / gives a real; div the whole quotient; mod the remainder**

**7. (Sub lesson 2) True or false: 3 — the whole quotient, fraction discarded**
**Answer: True**

**8. (Sub lesson 2) True or false: 3 — the whole quotient, fraction discarded** — as the answer to: What is C++'s % ?
**Answer: False — Its mod — the remainder (7 % 2 = 1)**

**9. (Sub lesson 2) True or false: The language and the operands' types together — never the symbol alone**
**Answer: True**

**10. (Sub lesson 2) True or false: The language and the operands' types together — never the symbol alone** — as the answer to: Which is the course's recurring lesson from this section?
**Answer: False — Syntax is clothing; the concept — and its contract — is what must be known**
