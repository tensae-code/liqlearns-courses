# Video script — The Adjacency Matrix

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A computer cannot store a drawing. It stores numbers.

So we write the graph as a table. One row and one column for every node.

Edge between two nodes? Write 1. No edge? Write 0.

Look at one row. The 1s are that node's neighbours.

Add the row. The sum is the node's degree.

Undirected graph? The table mirrors down the middle. Directed graph? It does not.
