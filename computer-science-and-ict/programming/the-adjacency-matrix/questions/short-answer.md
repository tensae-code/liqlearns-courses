# The Adjacency Matrix — short answer

Answer in your own words, in one or two sentences.

**1. (Sub lesson 2) Why is the adjacency matrix useful to a computer, when the drawing is easier for a person?**
**Answer: A computer cannot work with a drawing but can store and search numbers. In the matrix, neighbours, degrees and connections become arithmetic — row sums and cell lookups — that a program can do at speed.**

**2. (Sub lesson 2) A 5-node undirected graph's matrix entries add up to 14. How many edges has the graph, and how do you know?**
**Answer: 7 edges. Every undirected edge is stored twice, once at each end, so the entry total is twice the edge count: 14 ÷ 2 = 7.**
