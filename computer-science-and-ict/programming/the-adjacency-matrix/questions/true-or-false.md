# The Adjacency Matrix — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) The adjacency matrix has one row and one column for every node.**
**Answer: True** — Rows and columns are both labelled by the nodes, in the same order.

**2. (Sub lesson 1) A loop at a node writes a 1 on the matrix's diagonal.**
**Answer: True** — The diagonal holds the self-connections; a loop is exactly that.

**3. (Sub lesson 2) In a directed graph the adjacency matrix is always symmetric.**
**Answer: False** — Directed edges are stored one way only, so the mirror generally breaks.

**4. (Sub lesson 2) The neighbours of a node are the 1s in its column only, never its row.**
**Answer: False** — The node's row lists its neighbours (in an undirected graph row and column agree).
