# The Adjacency Matrix — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 1) The table that stores a graph is called the adjacency ____.**
**Answer: matrix**

**2. (Sub lesson 1) In a weighted graph's matrix, the cell holds the edge's ____ instead of 1.**
**Answer: weight**

**3. (Sub lesson 2) An undirected graph's matrix is ____ across the diagonal.**
**Answer: symmetric**
