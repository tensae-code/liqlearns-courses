# Switching to Graphics Mode in Pascal — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Which unit must be named for graphics work?**
a) The Graph unit  b) Loads the graphics driver and switches the screen to graphics mode  c) A grid of points the program can light one by one  d) A canvas
**Answer: a) The Graph unit**

**2. (Sub lesson 1) What does InitGraph do?**
a) A grid of points the program can light one by one  b) Loads the graphics driver and switches the screen to graphics mode  c) A canvas  d) As its own lesson, before any figure is drawn
**Answer: b) Loads the graphics driver and switches the screen to graphics mode**

**3. (Sub lesson 1) What is graphics mode's screen?**
a) A canvas  b) As its own lesson, before any figure is drawn  c) A grid of points the program can light one by one  d) The top-left corner
**Answer: c) A grid of points the program can light one by one**

**4. (Sub lesson 1) What do drawing operators lack before InitGraph?**
a) As its own lesson, before any figure is drawn  b) The top-left corner  c) Downward  d) A canvas
**Answer: d) A canvas**

**5. (Sub lesson 1) Where does the switch sit in the book?**
a) As its own lesson, before any figure is drawn  b) The top-left corner  c) Downward  d) There y grows upward
**Answer: a) As its own lesson, before any figure is drawn**

**6. (Sub lesson 2) From where do graphics coordinates start?**
a) Downward  b) The top-left corner  c) There y grows upward  d) Returns the screen to text mode
**Answer: b) The top-left corner**

**7. (Sub lesson 2) Which way does y grow?**
a) There y grows upward  b) Returns the screen to text mode  c) Downward  d) Once — draw everything, then close it once
**Answer: c) Downward**

**8. (Sub lesson 2) How does that differ from the maths graph?**
a) Returns the screen to text mode  b) Once — draw everything, then close it once  c) The Graph unit  d) There y grows upward
**Answer: d) There y grows upward**

**9. (Sub lesson 2) What does CloseGraph do?**
a) Returns the screen to text mode  b) Once — draw everything, then close it once  c) The Graph unit  d) Loads the graphics driver and switches the screen to graphics mode
**Answer: a) Returns the screen to text mode**

**10. (Sub lesson 2) How many times is the mode opened in one program?**
a) The Graph unit  b) Once — draw everything, then close it once  c) Loads the graphics driver and switches the screen to graphics mode  d) A grid of points the program can light one by one
**Answer: b) Once — draw everything, then close it once**
