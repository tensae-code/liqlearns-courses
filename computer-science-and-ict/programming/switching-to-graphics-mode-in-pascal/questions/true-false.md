# Switching to Graphics Mode in Pascal — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Which unit must be named for graphics work?" is: The Graph unit**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does InitGraph do?" is: A grid of points the program can light one by one**
**Answer: False** — Loads the graphics driver and switches the screen to graphics mode

**3. (Sub lesson 1) True or false: the answer to "What is graphics mode's screen?" is: A grid of points the program can light one by one**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What do drawing operators lack before InitGraph?" is: As its own lesson, before any figure is drawn**
**Answer: False** — A canvas

**5. (Sub lesson 1) True or false: the answer to "Where does the switch sit in the book?" is: As its own lesson, before any figure is drawn**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "From where do graphics coordinates start?" is: Downward**
**Answer: False** — The top-left corner

**7. (Sub lesson 2) True or false: the answer to "Which way does y grow?" is: Downward**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How does that differ from the maths graph?" is: Returns the screen to text mode**
**Answer: False** — There y grows upward

**9. (Sub lesson 2) True or false: the answer to "What does CloseGraph do?" is: Returns the screen to text mode**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "How many times is the mode opened in one program?" is: The Graph unit**
**Answer: False** — Once — draw everything, then close it once
