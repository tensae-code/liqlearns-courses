# Turtle Graphics in Small Basic — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — The Turtle's four acts — move, turn, pen up, pen down
Sub lesson 1 questions from the type files. Pass mark: A drawing agent that walks on the canvas carrying a pen; Move, Turn, PenUp and PenDown; Lifts the pen so the turtle travels without marking; A journey told in moves, turns and pen acts; Move, turn 90 — four times.

## Sub lesson 2 — Polygons, spirals and the ulzii knot
Sub lesson 2 questions from the type files. Pass mark: 360 divided by the number of sides; Grow the step each round of a polygon walk; The endless knot — Mongolia's symbol of eternity; The same four — move, turn, pen up, pen down; Think like the agent — stand where it stands, face where it faces.
