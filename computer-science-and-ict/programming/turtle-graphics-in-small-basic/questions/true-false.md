# Turtle Graphics in Small Basic — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is the Turtle?" is: A drawing agent that walks on the canvas carrying a pen**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Name its four first commands." is: Lifts the pen so the turtle travels without marking**
**Answer: False** — Move, Turn, PenUp and PenDown

**3. (Sub lesson 1) True or false: the answer to "What does PenUp do?" is: Lifts the pen so the turtle travels without marking**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is every turtle picture, in the lesson's phrase?" is: Move, turn 90 — four times**
**Answer: False** — A journey told in moves, turns and pen acts

**5. (Sub lesson 1) True or false: the answer to "How is a square drawn?" is: Move, turn 90 — four times**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is the turn angle for a polygon?" is: Grow the step each round of a polygon walk**
**Answer: False** — 360 divided by the number of sides

**7. (Sub lesson 2) True or false: the answer to "How is a spiral made?" is: Grow the step each round of a polygon walk**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is the ulzii?" is: The same four — move, turn, pen up, pen down**
**Answer: False** — The endless knot — Mongolia's symbol of eternity

**9. (Sub lesson 2) True or false: the answer to "By what acts is the ulzii drawn?" is: The same four — move, turn, pen up, pen down**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What habit does turtle graphics teach?" is: A drawing agent that walks on the canvas carrying a pen**
**Answer: False** — Think like the agent — stand where it stands, face where it faces
