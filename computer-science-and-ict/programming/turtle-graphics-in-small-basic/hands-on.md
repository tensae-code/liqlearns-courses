# Hands-on — Turtle Graphics in Small Basic

The lesson with your hands and your feet, not only your eyes.

## Task one
('Walk the polygon', 'Write turtle programs for a triangle and a hexagon. Before running, predict each turn angle and write it beside the code.')

## Task two
('Plan the knot', 'Sketch the ulzii's path on squared paper as a list of moves and turns. Code the first quarter and run it; then complete the knot.')
