# SDLC Models — Waterfall, Spiral and Agile — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Once, in order, each finished before the next begins**
**Answer: True**

**2. (Sub lesson 1) True or false: Once, in order, each finished before the next begins** — as the answer to: When is Waterfall right?
**Answer: False — When requirements are fixed and known**

**3. (Sub lesson 1) True or false: Repeatedly — each loop planning, weighing risks, building, evaluating**
**Answer: True**

**4. (Sub lesson 1) True or false: Repeatedly — each loop planning, weighing risks, building, evaluating** — as the answer to: When is Spiral right?
**Answer: False — When risks are large and the destination is learned by travelling**

**5. (Sub lesson 1) True or false: Risks**
**Answer: True**

**6. (Sub lesson 2) True or false: Risks** — as the answer to: What is a sprint?
**Answer: False — A short iteration producing a small working part**

**7. (Sub lesson 2) True or false: Change welcomed, working software over documents, people over rigid process**
**Answer: True**

**8. (Sub lesson 2) True or false: Change welcomed, working software over documents, people over rigid process** — as the answer to: How often does the customer react in Agile?
**Answer: False — Every few weeks, each round**

**9. (Sub lesson 2) True or false: How fixed the requirements, how costly a wrong turn, how present the customer**
**Answer: True**

**10. (Sub lesson 2) True or false: How fixed the requirements, how costly a wrong turn, how present the customer** — as the answer to: What is a model, in the closing phrase?
**Answer: False — A bet about the future of the project**
