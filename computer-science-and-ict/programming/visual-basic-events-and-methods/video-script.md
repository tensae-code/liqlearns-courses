# Video script — Visual Basic — Events and Methods

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

An **event** is a **happening the program can respond to**: the user **clicks** a button, a form **loads**, a key is pressed, a value changes. The programmer writes the code for an event in that event's **procedure**, and the program runs it **when the event happens** — event-driven programming, the shape every Visual Basic form already taught in this course has been using. Naming the event is naming **when** the code runs.
A **method** is an **action an object can be told to perform** — told in code, with the object's name: the object does something. A **property**, by contrast, is a **characteristic** an object has — its text, colour, position — a value it holds, not an action it does. And the book draws the second line plainly: a **property holds**; a **function works out and returns a value**. Event (when), method (do), property (has), function (returns) — four words, four different kinds of thing, and confusion between them is the beginner's main fog in this course.
