# Visual Basic — Events and Methods — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is an event?**
**Answer: A happening the program can respond to — a click, a form loading, a key press, a value changing**

**2. (Sub lesson 1) Where is an event's code written?**
**Answer: In that event's procedure; it runs when the event happens**

**3. (Sub lesson 1) What kind of programming is this called?**
**Answer: Event-driven programming**

**4. (Sub lesson 1) What is a method?**
**Answer: An action an object can be told to perform, told in code with the object's name**

**5. (Sub lesson 1) What is a property?**
**Answer: A characteristic an object has — its text, colour, position — a value it holds**

**6. (Sub lesson 2) Say the difference in short: a property… a method…**
**Answer: A property holds (a value); a method does (an action)**

**7. (Sub lesson 2) How does a function differ from a property?**
**Answer: A property holds a value; a function works out and returns a value**

**8. (Sub lesson 2) Name the four words of this lesson and their kinds.**
**Answer: Event (when), method (do), property (has), function (returns)**

**9. (Sub lesson 2) Give two examples of events.**
**Answer: Clicking a button and a form loading (any two of: key press, value change)**

**10. (Sub lesson 2) Which book opens its VB course with events and methods?**
**Answer: Libya's Grade 12 IT Science book, Chapter 4**
