# Visual Basic — Events and Methods — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is an event?" is: A happening the program can respond to — a click, a form loading, a key press, a value changing**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Where is an event's code written?" is: Event-driven programming**
**Answer: False** — In that event's procedure; it runs when the event happens

**3. (Sub lesson 1) True or false: the answer to "What kind of programming is this called?" is: Event-driven programming**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is a method?" is: A characteristic an object has — its text, colour, position — a value it holds**
**Answer: False** — An action an object can be told to perform, told in code with the object's name

**5. (Sub lesson 1) True or false: the answer to "What is a property?" is: A characteristic an object has — its text, colour, position — a value it holds**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Say the difference in short: a property… a method…" is: A property holds a value; a function works out and returns a value**
**Answer: False** — A property holds (a value); a method does (an action)

**7. (Sub lesson 2) True or false: the answer to "How does a function differ from a property?" is: A property holds a value; a function works out and returns a value**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Name the four words of this lesson and their kinds." is: Clicking a button and a form loading (any two of: key press, value change)**
**Answer: False** — Event (when), method (do), property (has), function (returns)

**9. (Sub lesson 2) True or false: the answer to "Give two examples of events." is: Clicking a button and a form loading (any two of: key press, value change)**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Which book opens its VB course with events and methods?" is: A happening the program can respond to — a click, a form loading, a key press, a value changing**
**Answer: False** — Libya's Grade 12 IT Science book, Chapter 4
