# Visual Basic — Events and Methods — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is an event?**
a) A happening the program can respond to — a click, a form loading, a key press, a value changing  b) In that event's procedure; it runs when the event happens  c) Event-driven programming  d) An action an object can be told to perform, told in code with the object's name
**Answer: a) A happening the program can respond to — a click, a form loading, a key press, a value changing**

**2. (Sub lesson 1) Where is an event's code written?**
a) Event-driven programming  b) In that event's procedure; it runs when the event happens  c) An action an object can be told to perform, told in code with the object's name  d) A characteristic an object has — its text, colour, position — a value it holds
**Answer: b) In that event's procedure; it runs when the event happens**

**3. (Sub lesson 1) What kind of programming is this called?**
a) An action an object can be told to perform, told in code with the object's name  b) A characteristic an object has — its text, colour, position — a value it holds  c) Event-driven programming  d) A property holds (a value); a method does (an action)
**Answer: c) Event-driven programming**

**4. (Sub lesson 1) What is a method?**
a) A characteristic an object has — its text, colour, position — a value it holds  b) A property holds (a value); a method does (an action)  c) A property holds a value; a function works out and returns a value  d) An action an object can be told to perform, told in code with the object's name
**Answer: d) An action an object can be told to perform, told in code with the object's name**

**5. (Sub lesson 1) What is a property?**
a) A characteristic an object has — its text, colour, position — a value it holds  b) A property holds (a value); a method does (an action)  c) A property holds a value; a function works out and returns a value  d) Event (when), method (do), property (has), function (returns)
**Answer: a) A characteristic an object has — its text, colour, position — a value it holds**

**6. (Sub lesson 2) Say the difference in short: a property… a method…**
a) A property holds a value; a function works out and returns a value  b) A property holds (a value); a method does (an action)  c) Event (when), method (do), property (has), function (returns)  d) Clicking a button and a form loading (any two of: key press, value change)

**7. (Sub lesson 2) How does a function differ from a property?**
