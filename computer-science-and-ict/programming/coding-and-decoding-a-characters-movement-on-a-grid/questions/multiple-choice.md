# Coding and Decoding a Character's Movement on a Grid — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) How does the character move on the grid?**
a) Square by square — one square per move  b) Writing the journey as a row of move signs, in order  c) Arrows or agreed marks — one per move  d) Walks the path with a finger, square by square
**Answer: a) Square by square — one square per move**

**2. (Sub lesson 1) What is coding a movement?**
a) Arrows or agreed marks — one per move  b) Writing the journey as a row of move signs, in order  c) Walks the path with a finger, square by square  d) The journey, written down
**Answer: b) Writing the journey as a row of move signs, in order**

**3. (Sub lesson 1) What signs does the code use?**
a) Walks the path with a finger, square by square  b) The journey, written down  c) Arrows or agreed marks — one per move  d) Reading a code of moves back into the journey
**Answer: c) Arrows or agreed marks — one per move**

**4. (Sub lesson 1) What does the writer do before writing?**
a) The journey, written down  b) Reading a code of moves back into the journey  c) Start on the named square and follow the signs one by one  d) Walks the path with a finger, square by square
**Answer: d) Walks the path with a finger, square by square**

**5. (Sub lesson 1) What is the code, in one line?**
a) The journey, written down  b) Reading a code of moves back into the journey  c) Start on the named square and follow the signs one by one  d) Match exactly
**Answer: a) The journey, written down**

**6. (Sub lesson 2) What is decoding?**
a) Start on the named square and follow the signs one by one  b) Reading a code of moves back into the journey  c) Match exactly  d) A fault in the code or in the reading
**Answer: b) Reading a code of moves back into the journey**

**7. (Sub lesson 2) How is a code decoded?**
a) Match exactly  b) A fault in the code or in the reading  c) Start on the named square and follow the signs one by one  d) By comparing the path square by square
**Answer: c) Start on the named square and follow the signs one by one**

**8. (Sub lesson 2) What must a code and its journey do?**
a) A fault in the code or in the reading  b) By comparing the path square by square  c) Square by square — one square per move  d) Match exactly
**Answer: d) Match exactly**

**9. (Sub lesson 2) What does a wrong ending square mean?**
a) A fault in the code or in the reading  b) By comparing the path square by square  c) Square by square — one square per move  d) Writing the journey as a row of move signs, in order
**Answer: a) A fault in the code or in the reading**

**10. (Sub lesson 2) How is the fault found?**
a) Square by square — one square per move  b) By comparing the path square by square  c) Writing the journey as a row of move signs, in order  d) Arrows or agreed marks — one per move
**Answer: b) By comparing the path square by square**
