# Coding and Decoding a Character's Movement on a Grid — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) How does the character move on the grid?**
**Answer: Square by square — one square per move**

**2. (Sub lesson 1) What is coding a movement?**
**Answer: Writing the journey as a row of move signs, in order**

**3. (Sub lesson 1) What signs does the code use?**
**Answer: Arrows or agreed marks — one per move**

**4. (Sub lesson 1) What does the writer do before writing?**
**Answer: Walks the path with a finger, square by square**

**5. (Sub lesson 1) What is the code, in one line?**
**Answer: The journey, written down**

**6. (Sub lesson 2) What is decoding?**
**Answer: Reading a code of moves back into the journey**

**7. (Sub lesson 2) How is a code decoded?**
**Answer: Start on the named square and follow the signs one by one**

**8. (Sub lesson 2) What must a code and its journey do?**
**Answer: Match exactly**

**9. (Sub lesson 2) What does a wrong ending square mean?**
**Answer: A fault in the code or in the reading**

**10. (Sub lesson 2) How is the fault found?**
**Answer: By comparing the path square by square**
