# Coding and Decoding a Character's Movement on a Grid — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "How does the character move on the grid?" is: Square by square — one square per move**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is coding a movement?" is: Reading a code of moves back into the journey**
**Answer: False** — Writing the journey as a row of move signs, in order

**3. (Sub lesson 1) True or false: the answer to "What signs does the code use?" is: Arrows or agreed marks — one per move**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does the writer do before writing?" is: Match exactly**
**Answer: False** — Walks the path with a finger, square by square

**5. (Sub lesson 1) True or false: the answer to "What is the code, in one line?" is: The journey, written down**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is decoding?" is: By comparing the path square by square**
**Answer: False** — Reading a code of moves back into the journey

**7. (Sub lesson 2) True or false: the answer to "How is a code decoded?" is: Start on the named square and follow the signs one by one**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What must a code and its journey do?" is: Writing the journey as a row of move signs, in order**
**Answer: False** — Match exactly

**9. (Sub lesson 2) True or false: the answer to "What does a wrong ending square mean?" is: A fault in the code or in the reading**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "How is the fault found?" is: Walks the path with a finger, square by square**
**Answer: False** — By comparing the path square by square
