# Hands-on — Coding and Decoding a Character's Movement on a Grid

The lesson with your hands and your feet, not only your eyes.

## Code a journey
On squared paper, draw a grid, a start square and a treasure square. Walk a path with your finger, then write its code in arrows. Count your moves: does the code have exactly that many signs?

## Decode and check
Swap codes with your partner — no grids shown. Decode their code on your own grid and mark where you end. Compare end squares: if they differ, compare the paths square by square and find the fault together.
