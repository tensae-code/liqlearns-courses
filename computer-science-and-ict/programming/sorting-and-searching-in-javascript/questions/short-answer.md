# Sorting and Searching in JavaScript — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does a JavaScript sort work on?**
**Answer: An array, with nested loops**

**2. (Sub lesson 1) How is a swap written in JavaScript?**
**Answer: Through a temporary variable — let t = a[j]; a[j] = a[j+1]; a[j+1] = t;**

**3. (Sub lesson 1) What does selection sort search for each pass?**
**Answer: The smallest remaining value, to swap into place**

**4. (Sub lesson 1) Selection sort is an example of what weaving?**
**Answer: Search inside sort**

**5. (Sub lesson 1) Why does Malaysia code sorts by hand before the built-in?**
**Answer: The built-in sort method is trusted only after its hand-written ancestors are understood**

**6. (Sub lesson 2) What does binary search code track?**
**Answer: low, high and mid over the array's indexes**

**7. (Sub lesson 2) When does its loop run?**
**Answer: While low <= high**

**8. (Sub lesson 2) What does the code return when the target is found?**
**Answer: The index where it was found**

**9. (Sub lesson 2) What does it return for not found?**
**Answer: −1 — the convention JavaScript programs use**

**10. (Sub lesson 2) What are pseudocode, flowchart and JavaScript, for one algorithm?**
**Answer: Three writings of one algorithm — the language is only its clothing**
