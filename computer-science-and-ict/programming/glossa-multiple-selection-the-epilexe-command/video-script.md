# Video script — ΓΛΩΣΣΑ Multiple Selection — the ΕΠΙΛΕΞΕ Command

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

**ΕΠΙΛΕΞΕ** opens with an expression whose value decides; each **ΠΕΡΙΠΤΩΣΗ** (case) names a value, a range, or a list of values and holds the commands for that case; **ΠΕΡΙΠΤΩΣΗ ΑΛΛΙΩΣ** (case otherwise) catches every value no case named; **ΤΕΛΟΣ_ΕΠΙΛΟΓΩΝ** closes the command. Exactly one case runs — the first whose value matches — and then the program continues after the command. The book works it beside the nested ΑΝ...ΑΛΛΙΩΣ_ΑΝ chains it replaces: the same choosing, written so the cases stand in a row and can be read at a glance.
ΕΠΙΛΕΞΕ fits choosing **by one expression's value** — a code, a grade band, a menu number; nested ΑΝ fits choosing by **different conditions** on different values. The supplementary material works the command through graded examples: days-in-month by month number, ticket price by age band, a calculator by operation code — each time reading the case list as a table and checking the ΑΛΛΙΩΣ case is the honest remainder, never a hiding place for a case the writer forgot.
