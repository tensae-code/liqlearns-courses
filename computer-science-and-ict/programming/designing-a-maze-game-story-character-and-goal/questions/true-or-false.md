# Designing a Maze Game — Story, Character and Goal — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Programming the maze comes before designing the game in this project.**
**Answer: False** — Design — story, character, goal — comes first.

**2. (Sub lesson 2) A gradient fill shades a colour from one tone to another.**
**Answer: True** — That shading makes the character look rounded.

**3. (Sub lesson 3) The character may safely use the same colour as the maze walls.**
**Answer: False** — It must be easy to see against the walls.
