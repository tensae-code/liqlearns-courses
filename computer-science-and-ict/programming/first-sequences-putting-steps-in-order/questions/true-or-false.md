# First Sequences — Putting Steps in Order — true or false

Say whether each statement is true or false.

**1. Build a sequence of steps that moves a character to a goal.**
**Answer: True** — This is one of the lesson's own outcomes.

**2. In a sequence, the steps can be done in any order and the result stays the same.**
**Answer: False** — The lesson teaches the opposite of this.

**3. Say why the order of the steps matters as much as the steps themselves.**
**Answer: True** — This is one of the lesson's own outcomes.
