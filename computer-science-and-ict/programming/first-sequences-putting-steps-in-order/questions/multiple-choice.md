# First Sequences — Putting Steps in Order — multiple choice

Pick the one right answer.

**1. What is a sequence?**
a) Actions done one after another in an order  b) Actions done all at the same time  c) A picture with no steps
**Answer: a) Actions done one after another in an order**

**2. In a sequence, what decides the result besides the steps themselves?**
a) The colour of the steps  b) How loud you read them  c) The order of the steps
**Answer: c) The order of the steps**

**3. A character ends in the wrong place, but every step was a good step. What is the likely fault?**
a) There are no steps  b) The steps are in the wrong order  c) The steps are too short
**Answer: b) The steps are in the wrong order**

**4. Where does Bulgaria's Grade 3 book first teach sequences?**
a) In code.org Course 1 puzzles  b) In a word processor  c) In a painting program
**Answer: a) In code.org Course 1 puzzles**
