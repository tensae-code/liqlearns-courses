# First Sequences — Putting Steps in Order — fill in the blank

Fill each blank with the missing word or words.

**1. A row of actions done one after another, in order, is a ____.**
**Answer: sequence**

**2. In a sequence, each step is done exactly ____, in its turn.**
**Answer: once**

**3. If the ____ of the steps is wrong, the character ends in the wrong place.**
**Answer: order**
