# The Concept of an Action in a Program — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: One elementary operation the executor performs while the program runs**
**Answer: True**

**2. (Sub lesson 1) True or false: One elementary operation the executor performs while the program runs** — as the answer to: How do actions differ from the program's text?
**Answer: False — The text stands still; actions happen in time, one after another**

**3. (Sub lesson 1) True or false: The program's state — the values in memory**
**Answer: True**

**4. (Sub lesson 1) True or false: The program's state — the values in memory** — as the answer to: Name three actions from the lesson.
**Answer: False — Taking a value, computing, storing (also: showing, choosing)**

**5. (Sub lesson 1) True or false: To follow its actions — what happens first, what changes, what happens next**
**Answer: True**

**6. (Sub lesson 2) True or false: To follow its actions — what happens first, what changes, what happens next** — as the answer to: What is an elementary action?
**Answer: False — One command done at once by the executor — like adding two numbers**

**7. (Sub lesson 2) True or false: A named block that unfolds into many elementary actions when executed**
**Answer: True**

**8. (Sub lesson 2) True or false: A named block that unfolds into many elementary actions when executed** — as the answer to: Can one deed be both elementary and composed?
**Answer: False — Yes — elementary to the caller, composed inside (print the table: one action above, a hundred below)**

**9. (Sub lesson 2) True or false: Largely the art of composing — building big actions from small ones**
**Answer: True**

**10. (Sub lesson 2) True or false: Largely the art of composing — building big actions from small ones** — as the answer to: What is the state an action acts on?
**Answer: False — The values held in memory at that moment**
