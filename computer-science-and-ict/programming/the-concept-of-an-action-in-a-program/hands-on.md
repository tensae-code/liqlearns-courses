# Hands-on — The Concept of an Action in a Program

The lesson with your hands and your feet, not only your eyes.

## Task one
**Action tracing** — Take a five-line Pascal program and list its actions in time order, with the memory change each one makes.

## Task two
**Compose a deed** — Write 'make tea' as one composed action, unfold it into elementary actions, then unfold one of those once more.
