# Hands-on — and / or — combining tests in one if

The lesson with your hands, not only your eyes — every activity is done for real, in IDLE or on paper.

## Switch boards
Draw two switches in series and two in parallel. A partner calls switch positions; you say whether current flows — series is AND, parallel is OR.

## Rule writer
Write three real rules as code shapes: one AND rule (both needed) and two OR rules (any one enough). Read them aloud exactly as Python would test them.
