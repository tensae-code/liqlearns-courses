# and / or — combining tests in one if — true or false

Say True or False.

**1. (Sub lesson 1)** `True and True` is True.
**Answer: True**

**2. (Sub lesson 2)** `True or False` is False.
**Answer: False**

**3. (Sub lesson 2)** OR is false only when both sides are false.
**Answer: True**

**4. (Sub lesson 1)** One false side makes an AND test true.
**Answer: False**
