# and / or — combining tests in one if — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** `True and False` is —
a) True  b) False
**Answer: b) b) False** — AND needs both.

**2. (Sub lesson 1)** The clinic program prints when —
a) either sign is true  b) both signs are true  c) neither is true
**Answer: b) b) both signs are true**

**3. (Sub lesson 2)** `False or False` is —
a) True  b) False
**Answer: b) b) False** — OR is false only when both are false.

**4. (Sub lesson 2)** With subject Biology, the subject program prints —
a) science  b) not listed
**Answer: b) b) not listed** — Verified.

**5. (Sub lesson 2)** OR is true when —
a) both sides are true only  b) any one side is true  c) no side is true
**Answer: b) b) any one side is true**

**6. (Sub lesson 1)** AND is true only when —
a) both sides are true  b) one side is true  c) one side is false
**Answer: a) a) both sides are true** — Teacher-keyed truth table.
