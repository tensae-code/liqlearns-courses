# Bubble Sort — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Neighbours compared, neighbours swapped
Sub lesson 1 questions from the type files. Pass mark: Neighbouring pairs, from the start of the list; When they are out of order — the left bigger than the right, for ascending order; The biggest unsorted value has reached the end; The biggest value rises step by step to the end, like a bubble; The still-unsorted front — the sorted tail is left alone.

## Sub lesson 2 — Pass after pass, until a clean pass
Sub lesson 2 questions from the type files. Pass mark: Each pass parks one more biggest value at the end; A whole pass makes no swaps; An outer loop for passes, an inner loop for comparisons, and a swapped flag; No — simple and slow; Every swap can be watched and counted.
