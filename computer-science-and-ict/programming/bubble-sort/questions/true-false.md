# Bubble Sort — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does bubble sort compare?" is: Neighbouring pairs, from the start of the list**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "When are two neighbours swapped?" is: The biggest unsorted value has reached the end**
**Answer: False** — When they are out of order — the left bigger than the right, for ascending order

**3. (Sub lesson 1) True or false: the answer to "What does one pass guarantee?" is: The biggest unsorted value has reached the end**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Why is it called bubble sort?" is: The still-unsorted front — the sorted tail is left alone**
**Answer: False** — The biggest value rises step by step to the end, like a bubble

**5. (Sub lesson 1) True or false: the answer to "Over what part do later passes run?" is: The still-unsorted front — the sorted tail is left alone**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Why do the passes get shorter?" is: A whole pass makes no swaps**
**Answer: False** — Each pass parks one more biggest value at the end

**7. (Sub lesson 2) True or false: the answer to "How does the sort know it is finished?" is: A whole pass makes no swaps**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is the pseudocode's shape?" is: No — simple and slow**
**Answer: False** — An outer loop for passes, an inner loop for comparisons, and a swapped flag

**9. (Sub lesson 2) True or false: the answer to "Is bubble sort fast?" is: No — simple and slow**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is its teaching worth?" is: Neighbouring pairs, from the start of the list**
**Answer: False** — Every swap can be watched and counted
