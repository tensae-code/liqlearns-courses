# Bubble Sort — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does bubble sort compare?**
a) Neighbouring pairs, from the start of the list  b) When they are out of order — the left bigger than the right, for ascending order  c) The biggest unsorted value has reached the end  d) The biggest value rises step by step to the end, like a bubble
**Answer: a) Neighbouring pairs, from the start of the list**

**2. (Sub lesson 1) When are two neighbours swapped?**
a) The biggest unsorted value has reached the end  b) When they are out of order — the left bigger than the right, for ascending order  c) The biggest value rises step by step to the end, like a bubble  d) The still-unsorted front — the sorted tail is left alone
**Answer: b) When they are out of order — the left bigger than the right, for ascending order**

**3. (Sub lesson 1) What does one pass guarantee?**
a) The biggest value rises step by step to the end, like a bubble  b) The still-unsorted front — the sorted tail is left alone  c) The biggest unsorted value has reached the end  d) Each pass parks one more biggest value at the end
**Answer: c) The biggest unsorted value has reached the end**

**4. (Sub lesson 1) Why is it called bubble sort?**
a) The still-unsorted front — the sorted tail is left alone  b) Each pass parks one more biggest value at the end  c) A whole pass makes no swaps  d) The biggest value rises step by step to the end, like a bubble
**Answer: d) The biggest value rises step by step to the end, like a bubble**

**5. (Sub lesson 1) Over what part do later passes run?**
a) The still-unsorted front — the sorted tail is left alone  b) Each pass parks one more biggest value at the end  c) A whole pass makes no swaps  d) An outer loop for passes, an inner loop for comparisons, and a swapped flag
**Answer: a) The still-unsorted front — the sorted tail is left alone**

**6. (Sub lesson 2) Why do the passes get shorter?**
a) A whole pass makes no swaps  b) Each pass parks one more biggest value at the end  c) An outer loop for passes, an inner loop for comparisons, and a swapped flag  d) No — simple and slow
**Answer: b) Each pass parks one more biggest value at the end**

**7. (Sub lesson 2) How does the sort know it is finished?**
a) An outer loop for passes, an inner loop for comparisons, and a swapped flag  b) No — simple and slow  c) A whole pass makes no swaps  d) Every swap can be watched and counted
**Answer: c) A whole pass makes no swaps**

**8. (Sub lesson 2) What is the pseudocode's shape?**
a) No — simple and slow  b) Every swap can be watched and counted  c) Neighbouring pairs, from the start of the list  d) An outer loop for passes, an inner loop for comparisons, and a swapped flag
**Answer: d) An outer loop for passes, an inner loop for comparisons, and a swapped flag**

**9. (Sub lesson 2) Is bubble sort fast?**
a) No — simple and slow  b) Every swap can be watched and counted  c) Neighbouring pairs, from the start of the list  d) When they are out of order — the left bigger than the right, for ascending order
**Answer: a) No — simple and slow**

**10. (Sub lesson 2) What is its teaching worth?**
a) Neighbouring pairs, from the start of the list  b) Every swap can be watched and counted  c) When they are out of order — the left bigger than the right, for ascending order  d) The biggest unsorted value has reached the end
**Answer: b) Every swap can be watched and counted**
