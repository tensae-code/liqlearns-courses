# SELECT CASE — Multi-Way Choice in Visual Basic — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — SELECT CASE — one value, many cases
Sub lesson 1 questions from the type files. Pass mark: One value or expression, matched against a list of cases; Once against each case, in order, until a case matches; That case's statements — and no later case runs; As a range (Case 1 To 5) or a list (Case 2, 4, 6); With END SELECT.

## Sub lesson 2 — CASE ELSE and choosing SELECT CASE over IF
Sub lesson 2 questions from the type files. Pass mark: The case for every value no other case matched — the safety net; When the choice turns on one value with many named possibilities, like a menu number or a mark band; For tests about conditions — different conditions on different values — and for a simple two-way choice; IF, IF with AND/OR connectors, and SELECT CASE; Choosing an action by menu number (any one of: grade by mark band; action by day of week).
