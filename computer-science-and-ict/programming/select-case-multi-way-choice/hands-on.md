# Hands-on — SELECT CASE — Multi-Way Choice in Visual Basic

The lesson with your hands and your feet, not only your eyes.

## Task one
('Grade by band', 'Write a SELECT CASE that turns a mark into a word — Excellent, Good, Pass, Fail — using ranges, with Case Else for a mark outside 0–100.')

## Task two
('Rewrite the chain', 'Take a chain of four IFs all testing the same variable and rewrite it as one SELECT CASE. Say which version is easier to check, and why.')
