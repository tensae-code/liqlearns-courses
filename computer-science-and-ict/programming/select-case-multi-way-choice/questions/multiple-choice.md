# SELECT CASE — Multi-Way Choice in Visual Basic — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does SELECT CASE test?**
a) One value or expression, matched against a list of cases  b) Once against each case, in order, until a case matches  c) That case's statements — and no later case runs  d) As a range (Case 1 To 5) or a list (Case 2, 4, 6)
**Answer: a) One value or expression, matched against a list of cases**

**2. (Sub lesson 1) How many times is the value compared?**
a) That case's statements — and no later case runs  b) Once against each case, in order, until a case matches  c) As a range (Case 1 To 5) or a list (Case 2, 4, 6)  d) With END SELECT
**Answer: b) Once against each case, in order, until a case matches**

**3. (Sub lesson 1) What runs when a case matches?**
a) As a range (Case 1 To 5) or a list (Case 2, 4, 6)  b) With END SELECT  c) That case's statements — and no later case runs  d) The case for every value no other case matched — the safety net
**Answer: c) That case's statements — and no later case runs**

**4. (Sub lesson 1) How can a case name more than one value?**
a) With END SELECT  b) The case for every value no other case matched — the safety net  c) When the choice turns on one value with many named possibilities, like a menu number or a mark band  d) As a range (Case 1 To 5) or a list (Case 2, 4, 6)
**Answer: d) As a range (Case 1 To 5) or a list (Case 2, 4, 6)**

**5. (Sub lesson 1) How does the statement close?**
a) With END SELECT  b) The case for every value no other case matched — the safety net  c) When the choice turns on one value with many named possibilities, like a menu number or a mark band  d) For tests about conditions — different conditions on different values — and for a simple two-way choice
**Answer: a) With END SELECT**

**6. (Sub lesson 2) What is Case Else?**
a) When the choice turns on one value with many named possibilities, like a menu number or a mark band  b) The case for every value no other case matched — the safety net  c) For tests about conditions — different conditions on different values — and for a simple two-way choice  d) IF, IF with AND/OR connectors, and SELECT CASE
**Answer: b) The case for every value no other case matched — the safety net**

**7. (Sub lesson 2) When is SELECT CASE the right tool?**
a) For tests about conditions — different conditions on different values — and for a simple two-way choice  b) IF, IF with AND/OR connectors, and SELECT CASE  c) When the choice turns on one value with many named possibilities, like a menu number or a mark band  d) Choosing an action by menu number (any one of: grade by mark band; action by day of week)
**Answer: c) When the choice turns on one value with many named possibilities, like a menu number or a mark band**

**8. (Sub lesson 2) When is IF better?**
a) IF, IF with AND/OR connectors, and SELECT CASE  b) Choosing an action by menu number (any one of: grade by mark band; action by day of week)  c) One value or expression, matched against a list of cases  d) For tests about conditions — different conditions on different values — and for a simple two-way choice
**Answer: d) For tests about conditions — different conditions on different values — and for a simple two-way choice**

**9. (Sub lesson 2) Name the three shapes of choosing in Libya's chapter, in order.**
a) IF, IF with AND/OR connectors, and SELECT CASE  b) Choosing an action by menu number (any one of: grade by mark band; action by day of week)  c) One value or expression, matched against a list of cases  d) Once against each case, in order, until a case matches

**10. (Sub lesson 2) Give an example fit for SELECT CASE.**
