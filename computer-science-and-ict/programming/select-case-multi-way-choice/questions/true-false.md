# SELECT CASE — Multi-Way Choice in Visual Basic — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does SELECT CASE test?" is: One value or expression, matched against a list of cases**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How many times is the value compared?" is: That case's statements — and no later case runs**
**Answer: False** — Once against each case, in order, until a case matches

**3. (Sub lesson 1) True or false: the answer to "What runs when a case matches?" is: That case's statements — and no later case runs**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How can a case name more than one value?" is: With END SELECT**
**Answer: False** — As a range (Case 1 To 5) or a list (Case 2, 4, 6)

**5. (Sub lesson 1) True or false: the answer to "How does the statement close?" is: With END SELECT**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is Case Else?" is: When the choice turns on one value with many named possibilities, like a menu number or a mark band**
**Answer: False** — The case for every value no other case matched — the safety net

**7. (Sub lesson 2) True or false: the answer to "When is SELECT CASE the right tool?" is: When the choice turns on one value with many named possibilities, like a menu number or a mark band**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "When is IF better?" is: IF, IF with AND/OR connectors, and SELECT CASE**
**Answer: False** — For tests about conditions — different conditions on different values — and for a simple two-way choice

**9. (Sub lesson 2) True or false: the answer to "Name the three shapes of choosing in Libya's chapter, in order." is: IF, IF with AND/OR connectors, and SELECT CASE**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Give an example fit for SELECT CASE." is: One value or expression, matched against a list of cases**
**Answer: False** — Choosing an action by menu number (any one of: grade by mark band; action by day of week)
