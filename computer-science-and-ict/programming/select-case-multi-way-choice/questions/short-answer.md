# SELECT CASE — Multi-Way Choice in Visual Basic — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does SELECT CASE test?**
**Answer: One value or expression, matched against a list of cases**

**2. (Sub lesson 1) How many times is the value compared?**
**Answer: Once against each case, in order, until a case matches**

**3. (Sub lesson 1) What runs when a case matches?**
**Answer: That case's statements — and no later case runs**

**4. (Sub lesson 1) How can a case name more than one value?**
**Answer: As a range (Case 1 To 5) or a list (Case 2, 4, 6)**

**5. (Sub lesson 1) How does the statement close?**
**Answer: With END SELECT**

**6. (Sub lesson 2) What is Case Else?**
**Answer: The case for every value no other case matched — the safety net**

**7. (Sub lesson 2) When is SELECT CASE the right tool?**
**Answer: When the choice turns on one value with many named possibilities, like a menu number or a mark band**

**8. (Sub lesson 2) When is IF better?**
**Answer: For tests about conditions — different conditions on different values — and for a simple two-way choice**

**9. (Sub lesson 2) Name the three shapes of choosing in Libya's chapter, in order.**
**Answer: IF, IF with AND/OR connectors, and SELECT CASE**

**10. (Sub lesson 2) Give an example fit for SELECT CASE.**
**Answer: Choosing an action by menu number (any one of: grade by mark band; action by day of week)**
