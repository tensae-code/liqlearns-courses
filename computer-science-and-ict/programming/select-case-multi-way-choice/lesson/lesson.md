# SELECT CASE — Multi-Way Choice in Visual Basic

## Do it first

IF asks about one test. A menu, a grade band, a day number ask about one value with many possible answers. Libya's Grade 11 book gives that choice its own statement: SELECT CASE. This lesson is its shape and its judgement.

## Sub lesson 1 — SELECT CASE — one value, many cases

**SELECT CASE** names **one value or expression** to test, then lists **cases**: `Case 1`, `Case 2`, a **range** such as `Case 1 To 5`, or a **list** such as `Case 2, 4, 6`. The value is compared **once** against each case in order; the **first matching case's** statements run, and the statement ends — no later case runs. The whole structure closes with **END SELECT**, as IF closes with END IF.

## Sub lesson 2 — CASE ELSE and choosing SELECT CASE over IF

**Case Else** is the case for **every value no other case matched** — the safety net, as Else is for IF. Choose SELECT CASE when the choice turns on **one value with many named possibilities** — a menu number, a mark band, a day of the week; keep IF for tests that are **about conditions**, especially different conditions on different values, and for the two-way choice. Libya teaches SELECT CASE inside its conditional-control chapter, after IF and the AND/OR connectors, as the third shape of choosing.
