# Lesson plan - Python and IDLE - where Python code is written

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** Python and IDLE - where Python code is written
**Place in the curriculum:** Unit 6 - Fundamentals of Programming (CURRICULUM.md).
**The one thing this lesson teaches:** Python is a popular high-level language considered much easier to learn; its free environment IDLE offers two places to write code - the interactive interpreter and the text editor.
**This lesson's own level:** it stands on it stands on the whole language story so far - low-level, high-level, translators, syntax - and lands on the one language this unit actually uses: Python.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on - an image, a GIF, a video, an audio. Every slot is written as **"a picture of ..." in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps - a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order - the list the learner sees from the start, locked ahead, each opening when the one before it is proved (the gate: README, "Units, Lessons and Sub Lessons (ruled 2026-11-08)"):

1. **Python - the beginner-friendly language** - Python is a popular high-level language, widely considered much easier to learn, which is why it is often chosen for teaching beginners.
2. **IDLE and its two places to write code** - IDLE (Integrated Development and Learning Environment) is Python's free environment, offering the interactive interpreter for one line at a time and the text editor for any amount of code, run with a single command.

Gate pool: all questions of the sub lesson - no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## What the learner can do when it ends
1. Say what Python is and why it is often chosen for teaching beginners.
2. Say what IDLE stands for and that it is Python's free environment.
3. Name IDLE's two places to write code and what each is for.
