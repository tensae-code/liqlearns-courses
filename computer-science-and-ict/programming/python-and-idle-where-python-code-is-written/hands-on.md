# Hands-on - Python and IDLE - where Python code is written

The lesson with your hands, not only your eyes.

## Two rooms

Draw IDLE as a house with two rooms on paper. In the interpreter room, draw a speech bubble exchange - one line, one answer. In the editor room, draw a full page of lines with one big RUN button. Label each room with what it is for.

## Which room?

A partner reads out jobs - 'test one line', 'write a whole program', 'see a line's effect at once', 'run everything with one command'. For each job, point at the room on your drawing and say its name.
