# Python and IDLE - where Python code is written - multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Python is -
a) a low-level language  b) a popular high-level language considered much easier to learn  c) a part of the computer  d) a compiler
**Answer: b) a popular high-level language considered much easier to learn** - that ease is why beginners start with it.

**2. (Sub lesson 1)** Python is often chosen for -
a) teaching beginners  b) printing documents  c) repairing hardware  d) drawing pictures
**Answer: a) teaching beginners** - it is widely considered much easier to learn.

**3. (Sub lesson 2)** IDLE stands for -
a) Integrated Development and Learning Environment  b) Internal Data Logic Engine  c) Interactive Drawing and Layout Editor  d) Internet Development Learning Example
**Answer: a) Integrated Development and Learning Environment** - Python's free environment.

**4. (Sub lesson 2)** IDLE is -
a) a paid program from a shop  b) Python's free environment  c) a programming language  d) a type of variable
**Answer: b) Python's free environment** - free, and it comes with Python.

**5. (Sub lesson 2)** The interactive interpreter is for -
a) writing whole books  b) one line at a time  c) printing pages  d) saving files only
**Answer: b) one line at a time** - type a line, see what it does.

**6. (Sub lesson 2)** The text editor is for -
a) one line only  b) writing any amount of code and running it with a single command  c) chatting  d) drawing
**Answer: b) writing any amount of code and running it with a single command** - whole programs live here.
