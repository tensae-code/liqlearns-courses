# Python and IDLE - where Python code is written - true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Python is a high-level language.
**Answer: True** - popular, and close to human language.

**2. (Sub lesson 2)** IDLE offers only one place to write code.
**Answer: False** - two places - the interactive interpreter and the text editor.

**3. (Sub lesson 2)** Code in the text editor is run with a single command.
**Answer: True** - that is the editor's way, against the interpreter's line at a time.
