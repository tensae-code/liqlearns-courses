## Sub lesson 1 - Python - the beginner-friendly language

**Python** is a **popular high-level language**. It is widely considered **much easier to learn** than most - and that is exactly why it is **often chosen for teaching beginners**. It is the language of the rest of this unit.

## Sub lesson 2 - IDLE and its two places to write code

Python's free environment is **IDLE** - the **Integrated Development and Learning Environment**.

IDLE offers **two places to write code**:

- The **interactive interpreter** - for **one line at a time**: type a line, see what it does, type the next.
- The **text editor** - for writing **any amount of code** and **running it with a single command**.

The next two lessons take one place each, in that order.
