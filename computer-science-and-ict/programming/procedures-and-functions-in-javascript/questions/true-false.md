# Procedures and Functions in JavaScript — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "How is a JavaScript function declared?" is: Once, with the function keyword — name, parameters in brackets, body in braces**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is handed in at a call?" is: A procedure**
**Answer: False** — Arguments, for the parameters

**3. (Sub lesson 1) True or false: the answer to "A JavaScript function that only does a job works as what?" is: A procedure**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Where do declarations sit, against calls?" is: The job the function does**
**Answer: False** — Apart — definitions gathered, then the story that uses them

**5. (Sub lesson 1) True or false: the answer to "What does a declaration's name promise?" is: The job the function does**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How does a function answer?" is: Stored, printed, or used inside a larger expression**
**Answer: False** — Through return — which ends the function at once and hands the value to the caller

**7. (Sub lesson 2) True or false: the answer to "Where can a returned value go?" is: Stored, printed, or used inside a larger expression**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "A function with no return hands back what?" is: When the function's answer is used — in a sum, for instance**
**Answer: False** — undefined

**9. (Sub lesson 2) True or false: the answer to "When is no return a silent fault?" is: When the function's answer is used — in a sum, for instance**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What must a function take through parameters?" is: Once, with the function keyword — name, parameters in brackets, body in braces**
**Answer: False** — Everything its job needs from outside — so it can be tested alone
