10. (Sub lesson 2) What must a function take through parameters?

a) Arguments, for the parameters
b) Apart — definitions gathered, then the story that uses them
c) Once, with the function keyword — name, parameters in brackets, body in braces
d) The job the function does
e) A procedure
f) Stored, printed, or used inside a larger expression
g) When the function's answer is used — in a sum, for instance
h) Through return — which ends the function at once and hands the value to the caller
i) Everything its job needs from outside — so it can be tested alone
j) undefined
