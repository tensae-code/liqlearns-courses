# Procedures and Functions in JavaScript — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) How is a JavaScript function declared?**
a) Once, with the function keyword — name, parameters in brackets, body in braces  b) Arguments, for the parameters  c) A procedure  d) Apart — definitions gathered, then the story that uses them
**Answer: a) Once, with the function keyword — name, parameters in brackets, body in braces**

**2. (Sub lesson 1) What is handed in at a call?**
a) A procedure  b) Arguments, for the parameters  c) Apart — definitions gathered, then the story that uses them  d) The job the function does
**Answer: b) Arguments, for the parameters**

**3. (Sub lesson 1) A JavaScript function that only does a job works as what?**
a) Apart — definitions gathered, then the story that uses them  b) The job the function does  c) A procedure  d) Through return — which ends the function at once and hands the value to the caller
**Answer: c) A procedure**

**4. (Sub lesson 1) Where do declarations sit, against calls?**
a) The job the function does  b) Through return — which ends the function at once and hands the value to the caller  c) Stored, printed, or used inside a larger expression  d) Apart — definitions gathered, then the story that uses them
**Answer: d) Apart — definitions gathered, then the story that uses them**

**5. (Sub lesson 1) What does a declaration's name promise?**
a) The job the function does  b) Through return — which ends the function at once and hands the value to the caller  c) Stored, printed, or used inside a larger expression  d) undefined
**Answer: a) The job the function does**

**6. (Sub lesson 2) How does a function answer?**
a) Stored, printed, or used inside a larger expression  b) Through return — which ends the function at once and hands the value to the caller  c) undefined  d) When the function's answer is used — in a sum, for instance
**Answer: b) Through return — which ends the function at once and hands the value to the caller**

**7. (Sub lesson 2) Where can a returned value go?**
a) undefined  b) When the function's answer is used — in a sum, for instance  c) Stored, printed, or used inside a larger expression  d) Everything its job needs from outside — so it can be tested alone
**Answer: c) Stored, printed, or used inside a larger expression**

**8. (Sub lesson 2) A function with no return hands back what?**
a) When the function's answer is used — in a sum, for instance  b) Everything its job needs from outside — so it can be tested alone  c) Once, with the function keyword — name, parameters in brackets, body in braces  d) undefined
**Answer: d) undefined**

**9. (Sub lesson 2) When is no return a silent fault?**
a) When the function's answer is used — in a sum, for instance  b) Everything its job needs from outside — so it can be tested alone  c) Once, with the function keyword — name, parameters in brackets, body in braces  d) Arguments, for the parameters
**Answer: a) When the function's answer is used — in a sum, for instance**

**10. (Sub lesson 2) What must a function take through parameters?**
a) Once, with the function keyword — name, parameters in brackets, body in braces  b) Everything its job needs from outside — so it can be tested alone  c) Arguments, for the parameters  d) A procedure
**Answer: b) Everything its job needs from outside — so it can be tested alone**
