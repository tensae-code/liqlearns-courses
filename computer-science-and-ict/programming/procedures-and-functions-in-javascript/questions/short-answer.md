# Procedures and Functions in JavaScript — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) How is a JavaScript function declared?**
**Answer: Once, with the function keyword — name, parameters in brackets, body in braces**

**2. (Sub lesson 1) What is handed in at a call?**
**Answer: Arguments, for the parameters**

**3. (Sub lesson 1) A JavaScript function that only does a job works as what?**
**Answer: A procedure**

**4. (Sub lesson 1) Where do declarations sit, against calls?**
**Answer: Apart — definitions gathered, then the story that uses them**

**5. (Sub lesson 1) What does a declaration's name promise?**
**Answer: The job the function does**

**6. (Sub lesson 2) How does a function answer?**
**Answer: Through return — which ends the function at once and hands the value to the caller**

**7. (Sub lesson 2) Where can a returned value go?**
**Answer: Stored, printed, or used inside a larger expression**

**8. (Sub lesson 2) A function with no return hands back what?**
**Answer: undefined**

**9. (Sub lesson 2) When is no return a silent fault?**
**Answer: When the function's answer is used — in a sum, for instance**

**10. (Sub lesson 2) What must a function take through parameters?**
**Answer: Everything its job needs from outside — so it can be tested alone**
