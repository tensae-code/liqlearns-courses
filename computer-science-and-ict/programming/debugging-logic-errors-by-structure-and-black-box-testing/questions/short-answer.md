# Debugging Logic Errors by Structure — and Black-Box Testing — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) How does the unit sort the hunt?**
**Answer: By structure — selection, repetition, arrays, subprograms**

**2. (Sub lesson 1) Where do selection errors hide?**
**Answer: The condition's edges and the branch never taken in testing**

**3. (Sub lesson 1) Name a repetition hiding place.**
**Answer: A loop running once too few or too many (or a variable never updated inside it)**

**4. (Sub lesson 1) Name an array hiding place.**
**Answer: An index one place too far (or a bound skipping the last place)**

**5. (Sub lesson 1) Name a subprogram hiding place.**
**Answer: A parameter passed in the wrong order (or a local name shadowing the caller's)**

**6. (Sub lesson 2) What is black-box testing?**
**Answer: Testing from the program's statement alone — inputs and hand-computed expected answers, without reading the code**

**7. (Sub lesson 2) Which inputs does the tester choose?**
**Answer: Typical, boundary and hostile**

**8. (Sub lesson 2) A mismatch convicts whom?**
**Answer: The program, not the test**

**9. (Sub lesson 2) Why does it find logic errors?**
**Answer: It refuses to be told where to look kindly — it never reads the code**

**10. (Sub lesson 2) Which unit teaches it?**
**Answer: Greece Grade 12 supplementary material, Unit 5**
