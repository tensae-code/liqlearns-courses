# Synchronising Sprites' Actions — true or false

Say whether each statement is true or false.

**1. Make one sprite start exactly when another finishes, using a message.**
**Answer: True** — This is one of the lesson's own outcomes.

**2. Synchronised sprites each keep their own timing and never need signals.**
**Answer: False** — The lesson teaches the opposite of this.

**3. Start two sprites together on one broadcast.**
**Answer: True** — This is one of the lesson's own outcomes.
