# Synchronising Sprites' Actions — short answer

Answer in a sentence or two.

**1. Explain, in your own words: make one sprite start exactly when another finishes, using a message.**
**Answer:** The learner's own explanation, true to the lesson: Synchronising means sprites act together in time: messages and waits line their actions up, so one sprite starts exactly when another finishes — no gaps, no pile-ups.

**2. A classmate gets this lesson's work wrong. What is the most likely fault, and how is it fixed?**
**Answer:** Actions overlap or gap → ask "what is the signal, and who waits for it?" A pile-up means a missing signal; a gap means a wait doing a signal's job badly.
