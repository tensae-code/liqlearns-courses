# For loops over a list and over a string — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** In the regions program, the first value printed is —
a) Sidama  b) Afar  c) Oromia
**Answer: b) b) Afar** — First element first.

**2. (Sub lesson 1)** The temporary variable in the regions program holds —
a) the whole list at once  b) one region per pass  c) a number
**Answer: b) b) one region per pass**

**3. (Sub lesson 2)** for over "Hi" prints —
a) Hi on one line  b) H then i, one per line  c) nothing
**Answer: b) b) H then i, one per line** — Verified.

**4. (Sub lesson 2)** Over a string, each iteration stores —
a) one character  b) one word  c) the whole string
**Answer: a) a) one character**

**5. (Sub lesson 1)** A loop with no early-stop condition prints —
a) the first item only  b) everything in the list  c) the last item only
**Answer: b) b) everything in the list** — Teacher-keyed.

**6. (Sub lesson 2)** Printing letters on one line instead of per line is done by changing the print —
a) ending  b) variable  c) colon
**Answer: a) a) ending** — end=' ' — review-keyed.
