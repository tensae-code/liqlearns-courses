This lesson: **For loops over a list and over a string**.

First, do it. Run the opening program. Watch what it prints.

Then the idea, in order: The region program: each element in turn is assigned to the temporary variable and printed, first Afar, last Sidama. Each iteration stores one character in the letter variable and prints it, to the string's last character.

Now you. Run the regions program and add one more region to the list. Predict the new last line.

Say it to your companion: Tell your companion how the same for shape walks a list of names and a string of letters — and what the temporary variable holds on each pass.
