# Hands-on — For loops over a list and over a string

The lesson with your hands, not only your eyes — every activity is done for real, in IDLE or on paper.

## Name letters
Write your name in big letters on cards, one letter per card. Deal them out one at a time, saying each — you are the for loop over a string.

## List walk
Write a list of five local places on a strip. Walk a finger along it, reading each aloud in turn, first to last — then say what changes if the loop stopped early (it would not: no stop condition here).
