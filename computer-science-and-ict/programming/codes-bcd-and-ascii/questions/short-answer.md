# Codes — BCD and ASCII — short answer

Answer in your own words, in one or two sentences.

**1. (Sub lesson 1) Why does BCD use more bits than plain binary for the same number?**
**Answer: Because each decimal digit takes its own four bits and six of the sixteen patterns are wasted on every digit; plain binary uses every pattern, so it packs the same value into fewer bits (47 needs 8 bits in BCD, 6 in binary).**

**2. (Sub lesson 2) A file holds the ASCII numbers 72, 105. What text is it?**
**Answer: 72 is H (capitals from A = 65, so H = 72) and 105 is i (small letters from a = 97, so i = 105): the text is 'Hi'.**
