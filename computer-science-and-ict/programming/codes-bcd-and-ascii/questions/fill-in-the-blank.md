# Codes — BCD and ASCII — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 1) BCD stands for binary-coded ____.**
**Answer: decimal** — Each decimal digit is coded separately in binary.

**2. (Sub lesson 1) The decimal digit 6 in BCD is written ____.**
**Answer: 0110** — Six is 0110 in four bits — leading zero kept, because the group is always four bits.

**3. (Sub lesson 2) In ASCII, the space character has the code ____.**
**Answer: 32** — The printable characters start at the space, code 32.

**4. (Sub lesson 2) The ASCII code of the small letter a is ____.**
**Answer: 97** — Small letters run from a = 97, so b = 98, c = 99, in order.
