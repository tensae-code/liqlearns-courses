# Codes — BCD and ASCII — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) In BCD, the decimal number 93 is written —**
a) 1011101  b) 1001 0011  c) 1001 011  d) 1111 0011
**Answer: b) 1001 0011** — Each digit separately in four bits: 9 = 1001, 3 = 0011, so 93 is 1001 0011.

**2. (Sub lesson 1) How many of the sixteen four-bit patterns does BCD never use?**
a) None  b) Two  c) Six  d) Ten
**Answer: c) Six** — Only ten patterns (0000–1001) are decimal digits; 1010 to 1111 — six patterns — are never used.

**3. (Sub lesson 1) BCD is chosen instead of plain binary when —**
a) The number is very large  b) Each decimal digit must be handled and shown on its own, as in displays and instruments  c) The computer has no memory  d) Letters must be stored
**Answer: b) Each decimal digit must be handled and shown on its own, as in displays and instruments** — BCD matches digit-by-digit work: displays, measuring instruments, money amounts.

**4. (Sub lesson 2) How many characters does the 7-bit ASCII code hold?**
a) 64  b) 100  c) 128  d) 256
**Answer: c) 128** — Seven bits give 2⁷ = 128 different codes.

**5. (Sub lesson 2) The ASCII code of the capital letter A is 65. The code of C is —**
a) 66  b) 67  c) 68  d) 97
**Answer: b) 67** — Capitals run in order from A = 65, so B = 66 and C = 67.

**6. (Sub lesson 2) The ASCII character '5' has code 53, not 5, because —**
a) ASCII counts from 10  b) The character is a picture of a digit, and its code number is its place in the table  c) Five is written 101 in binary  d) Digits have no codes
**Answer: b) The character is a picture of a digit, and its code number is its place in the table** — Digit characters run from '0' = 48, so '5' = 48 + 5 = 53. A character is a symbol, not a value.
