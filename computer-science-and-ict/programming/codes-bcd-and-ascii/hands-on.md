# Hands-on — Codes — BCD and ASCII

The lesson with your hands and your feet, not only your eyes.

## Code a price
Write these prices in BCD: 8, 39, 250, 2026. Then write a BCD pattern for a classmate — 1001 0010 0101 — and have them read it back as a decimal number. If a group like 1100 appears, say what is wrong with it.

## Write your name in ASCII
Using the runs from the lesson (A = 65 in order, a = 97 in order), write your first name as ASCII numbers, then as 7-bit patterns. Swap with a classmate and decode theirs. Finish by writing the codes for 'A1' and saying why the '1' in it is not the number one.

## In the simulator
In TINA or Circuit Wizard (or any seven-segment display demo your school uses), drive a display digit by digit with four-bit groups. Say the BCD group for each digit before you set it — this is exactly why BCD exists: one group, one visible digit.
