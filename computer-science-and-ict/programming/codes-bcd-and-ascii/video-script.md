# Video script — Codes — BCD and ASCII

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Inside a computer there are only bits. 0 and 1.

So we must agree: this pattern means this digit. That agreement is a code.

First code: BCD. Each decimal digit gets its own four bits.

47 in BCD is 0100 0111. Four for the 4, seven for the 7 — digit by digit.

Second code: ASCII. Every letter and sign gets a fixed number.

A is 65. Small a is 97. The character '0' is 48. Space is 32.

Same table everywhere — so text written on one machine reads the same on all machines.
