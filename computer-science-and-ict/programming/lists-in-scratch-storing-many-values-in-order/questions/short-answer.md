# Lists in Scratch — Storing Many Values in Order — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a list?**
**Answer: Ordered data, every item with a position number**

**2. (Sub lesson 1) Name the list operations.**
**Answer: Add, insert, item number of, replace, delete, length of, contains**

**3. (Sub lesson 1) What happens when an item is deleted?**
**Answer: The rest are renumbered**

**4. (Sub lesson 1) What do the first lists hold?**
**Answer: Names, fathers’ names and family names**

**5. (Sub lesson 1) How many parallel lists run the quiz?**
**Answer: Three — questions, correct answers, the student’s answers**

**6. (Sub lesson 2) What two counters does the quiz keep?**
**Answer: Counters for right and wrong**

**7. (Sub lesson 2) How many parallel lists run the address book?**
**Answer: Six**

**8. (Sub lesson 2) What entry checks does the address book make?**
**Answer: Age must be 0–120; a mobile must be ten digits starting 05**

**9. (Sub lesson 2) How is the expense total found?**
**Answer: By looping over the list with a counter**

**10. (Sub lesson 2) What must updating a task check first?**
**Answer: That the position is inside the list**
