# Lists in Scratch — Storing Many Values in Order — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a list?**
a) Ordered data, every item with a position number  b) Add, insert, item number of, replace, delete, length of, contains  c) Names, fathers’ names and family names  d) Counters for right and wrong
**Answer: a) Ordered data, every item with a position number**

**2. (Sub lesson 1) Name the list operations.**
a) The rest are renumbered  b) Add, insert, item number of, replace, delete, length of, contains  c) Three — questions, correct answers, the student’s answers  d) Six
**Answer: b) Add, insert, item number of, replace, delete, length of, contains**

**3. (Sub lesson 1) What happens when an item is deleted?**
a) Names, fathers’ names and family names  b) Counters for right and wrong  c) The rest are renumbered  d) Age must be 0–120; a mobile must be ten digits starting 05

**4. (Sub lesson 1) What do the first lists hold?**
