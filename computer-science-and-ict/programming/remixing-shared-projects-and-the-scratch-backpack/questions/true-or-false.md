# Remixing Shared Projects — and the Scratch Backpack — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Scratch keeps a remix connected to the project it came from.**
**Answer: True** — The line of credit back to the original stays visible.

**2. (Sub lesson 2) The Backpack rebuilds a script automatically in every project.**
**Answer: False** — You carry and drag pieces yourself; nothing is rebuilt.

**3. (Sub lesson 2) Only sounds can travel in the Backpack.**
**Answer: False** — Block stacks, sounds, sprites and costumes all travel.
