# Lesson plan — Remixing Shared Projects — and the Scratch Backpack

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** Remixing Shared Projects — and the Scratch Backpack
**Place in the curriculum:** ICT expansion — Finland (2026-11-14) — in the title Programming on the ICT course ladder (TITLES.md). Built new from Finland's *Ensiaskeleet ohjelmointiin* (teacher guide, Opettajan opas, Versio 2.0 — teacher notes only), because no existing lesson teaches this thing as its own lesson.
**The one thing this lesson teaches:** Scratch is built for building on others' work: a shared project can be remixed — taken, changed and built further as your own version — and the Backpack carries your own blocks, sounds and sprites from one project into another, so good pieces are never rebuilt from nothing. This lesson stands on teacher-guide evidence only.
**This lesson's own level:** It stands on building Scratch projects of your own; sharing, remixing and the Backpack are built inside the lesson from the teacher guide's notes.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Sharing and remixing — building on others' projects** — Share a project and explain what a remix is.
2. **The Backpack — carrying pieces between your projects** — Carry blocks, sounds and sprites between projects with the Backpack.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: First Scratch Script — Move 10 Steps and Say Hello in Programming. Recommended, never forced — a learner may land on this lesson directly, and it stands alone.
- Finland's own way is kept: this placement sits in Finland's two-part Scratch path — Part 1 moves towards the interactive-story project and Part 2 towards the self-built maze game, in the Luetaan (Let's read) then Ohjelmoidaan (Let's program) rhythm, with pair work, reflection and peer showing built in.

## What the learner can do when it ends
1. Say what sharing a Scratch project lets others do.
2. Say what a remix is, and how it differs from simply copying.
3. Use the Backpack to carry a block stack, a sound or a sprite into another project.

## What you need
A computer with Scratch.

## If the learner is stuck
Treats remixing as copying to submit unchanged → a remix changes and builds; the original stays credited. Rebuilds the same script weekly → put it in the Backpack once and carry it. Backpack piece missing in the new project → it must be dragged out into that project; carrying is not automatic.
