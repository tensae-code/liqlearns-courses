# Recursive procedures — a procedure that calls itself — true or false

Say true or false for each one.

**1.** A recursive procedure invokes a copy of itself.
**Answer: True.**

**2.** The word star appears inside the body of the star procedure, calling itself.
**Answer: False** — the body holds only REPEAT 100 [fd 100 rt 144]; the procedure repeats, it does not call itself.

**3.** Everyday waking steps — dress, eat breakfast, brush teeth — are an example of a procedure.
**Answer: True.**
