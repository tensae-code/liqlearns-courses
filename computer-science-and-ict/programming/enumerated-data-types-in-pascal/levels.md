# Enumerated Data Types in Pascal — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Defining a type by listing its values
Sub lesson 1 questions from the type files. Pass mark: By listing its values in brackets in a type definition; Mon, Tue, Wed, Thu, Fri, Sat, Sun — the type TDay; No — they are names, not texts in apostrophes; The compiler checks assignments — a value outside the list is an error at once; d := Wed; — with the bare name.

## Sub lesson 2 — Order from the list — ord, succ, pred
Sub lesson 2 questions from the type files. Pass mark: An order — they can be compared and stepped through; The next and the previous value — succ(Wed) = Thu; The value's position counted from 0 — ord(Mon) = 0; Yes — enumerated values compare by their list order; Closed lists that do not grow — months, suits, directions, grades.
