# Hands-on — Enumerated Data Types in Pascal

The lesson with your hands and your feet, not only your eyes.

## Task one
**Build a type** — Define an enumerated type for the four compass directions and one for school subjects; declare a variable of each and assign a value.

## Task two
**Order drill** — For the TDay type, write succ(Fri), pred(Tue), ord(Sun) and the truth of Wed < Sat, proving each from the list.
