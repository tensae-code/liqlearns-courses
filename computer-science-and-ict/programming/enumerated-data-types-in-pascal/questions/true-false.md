# Enumerated Data Types in Pascal — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: By listing its values in brackets in a type definition**
**Answer: True**

**2. (Sub lesson 1) True or false: By listing its values in brackets in a type definition** — as the answer to: What values has the lesson's example?
**Answer: False — Mon, Tue, Wed, Thu, Fri, Sat, Sun — the type TDay**

**3. (Sub lesson 1) True or false: No — they are names, not texts in apostrophes**
**Answer: True**

**4. (Sub lesson 1) True or false: No — they are names, not texts in apostrophes** — as the answer to: What protection does enumeration give?
**Answer: False — The compiler checks assignments — a value outside the list is an error at once**

**5. (Sub lesson 1) True or false: d := Wed; — with the bare name**
**Answer: True**

**6. (Sub lesson 2) True or false: d := Wed; — with the bare name** — as the answer to: What does the list's order give the values?
**Answer: False — An order — they can be compared and stepped through**

**7. (Sub lesson 2) True or false: The next and the previous value — succ(Wed) = Thu**
**Answer: True**

**8. (Sub lesson 2) True or false: The next and the previous value — succ(Wed) = Thu** — as the answer to: What does ord give?
**Answer: False — The value's position counted from 0 — ord(Mon) = 0**

**9. (Sub lesson 2) True or false: Yes — enumerated values compare by their list order**
**Answer: True**

**10. (Sub lesson 2) True or false: Yes — enumerated values compare by their list order** — as the answer to: What kind of sets suit enumeration?
**Answer: False — Closed lists that do not grow — months, suits, directions, grades**
