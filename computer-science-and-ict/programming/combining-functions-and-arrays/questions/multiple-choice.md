# Combining Functions and Arrays — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) How is an array parameter declared?**
a) int a[] — with the size left open  b) The live count, n  c) The function cannot see how many elements are live  d) No — the function works on the caller's elements
