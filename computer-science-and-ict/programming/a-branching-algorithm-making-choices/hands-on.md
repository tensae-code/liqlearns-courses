# Hands-on — A Branching Algorithm — Making Choices

The lesson with your hands, not only your eyes.

## Plan a branched journey
On paper, plan a journey with one decision: the question, the yes-way, the no-way. A partner must follow both ways and arrive somewhere sensible both times.

## Both ways test
Build your branched journey in Scratch. Run it answering yes, then run it answering no — both runs must work.
