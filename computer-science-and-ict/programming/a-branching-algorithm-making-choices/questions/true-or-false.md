# A Branching Algorithm — Making Choices — true or false

Say whether each statement is true or false.

**1. Say what makes an algorithm branching.**
**Answer: True** — This is one of the lesson's own outcomes.

**2. In a branching algorithm, only the yes-way needs writing, because the no-way takes care of itself.**
**Answer: False** — The lesson teaches the opposite of this.

**3. Write a branching algorithm whose question can be answered yes or no.**
**Answer: True** — This is one of the lesson's own outcomes.
