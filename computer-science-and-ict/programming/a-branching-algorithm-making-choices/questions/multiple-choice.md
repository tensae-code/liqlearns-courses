# A Branching Algorithm — Making Choices — multiple choice

Pick the one right answer.

**1. An algorithm is branching when it —**
a) splits at a yes/no question  b) has many steps  c) uses a pen
**Answer: a) splits at a yes/no question**

**2. The question in a branch must be —**
a) answerable with a story  b) impossible to answer  c) answerable yes or no
**Answer: c) answerable yes or no**

**3. The book's branching lesson is themed on —**
a) football only  b) journeys  c) cooking
**Answer: b) journeys**

**4. A branch is finished only when —**
a) both ways are written and end somewhere  b) the yes-way is written  c) the question is long
**Answer: a) both ways are written and end somewhere**
