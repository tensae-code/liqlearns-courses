# A Branching Algorithm — Making Choices — short answer

Answer in a sentence or two.

**1. Explain, in your own words: say what makes an algorithm branching.**
**Answer:** The learner's own explanation, true to the lesson: A branching algorithm does not march straight: at a question it splits — one way if the answer is yes, the other way if no — like choosing a journey by the weather.

**2. A classmate gets this lesson's work wrong. What is the most likely fault, and how is it fixed?**
**Answer:** Branch jams → the question is not yes/no: rewrite it until it can only be answered yes or no, and check the no-way is written as carefully as the yes-way.
