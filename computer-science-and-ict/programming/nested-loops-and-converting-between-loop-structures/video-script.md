# Video script — Nested Loops — and Converting Between Loop Structures

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A **nested loop (εμφωλευμένος βρόχος)** is a loop inside a loop: the inner loop runs **to its end for every single step** of the outer — the pattern of tables (a ΓΙΑ for rows holding a ΓΙΑ for columns) and of work over arrays of arrays. The same chapter works the standing **minimum/maximum patterns**: set the champion to the **first** value, then let every later value challenge it — the pattern whose classic fault is seeding the champion with 0 instead of the first value, a fault the guide names so it can be recognised in an exam script.
ΓΛΩΣΣΑ's three structures — **ΟΣΟ…ΕΠΑΝΑΛΑΒΕ** (while), **ΑΡΧΗ_ΕΠΑΝΑΛΗΨΗΣ…ΜΕΧΡΙΣ_ΟΤΟΥ** (repeat-until) and **ΓΙΑ…ΑΠΟ…ΜΕΧΡΙ** (for) — can each be **converted** into the others: a ΓΙΑ becomes an ΟΣΟ with its counter handled openly; an ΟΣΟ becomes a ΜΕΧΡΙΣ_ΟΤΟΥ only with care, because ΜΕΧΡΙΣ_ΟΤΟΥ **always runs at least once** while ΟΣΟ may run **never**. The guide drills conversions because exams ask them directly — and because choosing the structure that *fits* a job, then proving the translation equal, is what mastery of repetition means.
