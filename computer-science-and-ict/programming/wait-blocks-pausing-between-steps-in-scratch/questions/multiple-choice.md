# Wait Blocks — Pausing Between Steps in Scratch — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does a wait block do?**
a) It pauses the script for a set time  b) Only when the wait ends  c) The speed the story is told at  d) Wait
**Answer: a) It pauses the script for a set time**

**2. (Sub lesson 1) When does the next block run?**
a) The timing of execution  b) Only when the wait ends  c) The repetitions (loop) lesson  d) Wait blocks
**Answer: b) Only when the wait ends**

**3. (Sub lesson 1) What do waits control?**
a) The speed the story is told at  b) Wait  c) The timing of execution  d) A wait inside the repeat
**Answer: c) The timing of execution**

**4. (Sub lesson 1) What changes when the waits change in the same script?**
a) The repetitions (loop) lesson  b) Wait blocks  c) How long it should be  d) The speed the story is told at
**Answer: d) The speed the story is told at**

**5. (Sub lesson 1) In which Grade 7 lesson is the wait taught?**
a) The repetitions (loop) lesson  b) Wait  c) A wait inside the repeat  d) Long enough to read, short enough to keep the story alive
**Answer: a) The repetitions (loop) lesson**

**6. (Sub lesson 2) What do speakers do while the other talks?**
a) Wait blocks  b) Wait  c) How long it should be  d) It pauses the script for a set time
**Answer: b) Wait**

**7. (Sub lesson 2) What paces the travelling parrot’s journey?**
a) A wait inside the repeat  b) Long enough to read, short enough to keep the story alive  c) Wait blocks  d) Only when the wait ends
**Answer: c) Wait blocks**

**8. (Sub lesson 2) What makes repeated drawing watchable?**
a) How long it should be  b) It pauses the script for a set time  c) The timing of execution  d) A wait inside the repeat
**Answer: d) A wait inside the repeat**

**9. (Sub lesson 2) What is the real question about a wait?**
a) How long it should be  b) Long enough to read, short enough to keep the story alive  c) Only when the wait ends  d) The speed the story is told at
**Answer: a) How long it should be**

**10. (Sub lesson 2) How long should a wait be?**
a) It pauses the script for a set time  b) Long enough to read, short enough to keep the story alive  c) The timing of execution  d) The repetitions (loop) lesson
**Answer: b) Long enough to read, short enough to keep the story alive**
