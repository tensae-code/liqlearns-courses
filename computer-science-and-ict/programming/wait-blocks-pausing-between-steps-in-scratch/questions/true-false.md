# Wait Blocks — Pausing Between Steps in Scratch — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does a wait block do?" is: It pauses the script for a set time**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "When does the next block run?" is: The speed the story is told at**
**Answer: False** — Only when the wait ends

**3. (Sub lesson 1) True or false: the answer to "What do waits control?" is: The timing of execution**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What changes when the waits change in the same script?" is: Wait**
**Answer: False** — The speed the story is told at

**5. (Sub lesson 1) True or false: the answer to "In which Grade 7 lesson is the wait taught?" is: The repetitions (loop) lesson**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What do speakers do while the other talks?" is: A wait inside the repeat**
