# Pointing a Sprite in a Direction in Scratch — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a sprite's direction?**
**Answer: Where it faces, measured as a number**

**2. (Sub lesson 1) Which direction number is to the right?**
**Answer: 90**

**3. (Sub lesson 1) Which numbers point the sprite up and down?**
**Answer: 0 is up, and 180 is down**

**4. (Sub lesson 1) What does the direction number name?**
**Answer: A facing — not a movement**

**5. (Sub lesson 1) Why set direction before moving?**
**Answer: Because every move goes the way the sprite points**

**6. (Sub lesson 2) What does the point-in-direction block do?**
**Answer: It sets the sprite's facing at once to the given number**

**7. (Sub lesson 2) How does pointing differ from turning?**
**Answer: Turning adds an amount; pointing replaces the facing**

**8. (Sub lesson 2) Does pointing depend on the old facing?**
**Answer: No — the named direction replaces whatever it was**

**9. (Sub lesson 2) What kind of journey uses pointing?**
**Answer: One named facing per leg — right, then down, then left**

**10. (Sub lesson 2) When is the new facing true from?**
**Answer: From the moment the block runs**
