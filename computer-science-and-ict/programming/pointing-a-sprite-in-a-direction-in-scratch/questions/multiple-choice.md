# Pointing a Sprite in a Direction in Scratch — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a sprite's direction?**
a) Where it faces, measured as a number  b) 90  c) 0 is up, and 180 is down  d) A facing — not a movement
**Answer: a) Where it faces, measured as a number**

**2. (Sub lesson 1) Which direction number is to the right?**
a) 0 is up, and 180 is down  b) 90  c) A facing — not a movement  d) Because every move goes the way the sprite points
**Answer: b) 90**

**3. (Sub lesson 1) Which numbers point the sprite up and down?**
a) A facing — not a movement  b) Because every move goes the way the sprite points  c) 0 is up, and 180 is down  d) It sets the sprite's facing at once to the given number
**Answer: c) 0 is up, and 180 is down**

**4. (Sub lesson 1) What does the direction number name?**
a) Because every move goes the way the sprite points  b) It sets the sprite's facing at once to the given number  c) Turning adds an amount; pointing replaces the facing  d) A facing — not a movement
**Answer: d) A facing — not a movement**

**5. (Sub lesson 1) Why set direction before moving?**
a) Because every move goes the way the sprite points  b) It sets the sprite's facing at once to the given number  c) Turning adds an amount; pointing replaces the facing  d) No — the named direction replaces whatever it was
**Answer: a) Because every move goes the way the sprite points**

**6. (Sub lesson 2) What does the point-in-direction block do?**
a) Turning adds an amount; pointing replaces the facing  b) It sets the sprite's facing at once to the given number  c) No — the named direction replaces whatever it was  d) One named facing per leg — right, then down, then left
**Answer: b) It sets the sprite's facing at once to the given number**

**7. (Sub lesson 2) How does pointing differ from turning?**
a) No — the named direction replaces whatever it was  b) One named facing per leg — right, then down, then left  c) Turning adds an amount; pointing replaces the facing  d) From the moment the block runs
**Answer: c) Turning adds an amount; pointing replaces the facing**

**8. (Sub lesson 2) Does pointing depend on the old facing?**
a) One named facing per leg — right, then down, then left  b) From the moment the block runs  c) Where it faces, measured as a number  d) No — the named direction replaces whatever it was
**Answer: d) No — the named direction replaces whatever it was**

**9. (Sub lesson 2) What kind of journey uses pointing?**
a) One named facing per leg — right, then down, then left  b) From the moment the block runs  c) Where it faces, measured as a number  d) 90
**Answer: a) One named facing per leg — right, then down, then left**

**10. (Sub lesson 2) When is the new facing true from?**
a) Where it faces, measured as a number  b) From the moment the block runs  c) 90  d) 0 is up, and 180 is down
**Answer: b) From the moment the block runs**
