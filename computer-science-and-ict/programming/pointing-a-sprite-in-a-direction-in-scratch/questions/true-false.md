# Pointing a Sprite in a Direction in Scratch — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a sprite's direction?" is: Where it faces, measured as a number**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Which direction number is to the right?" is: It sets the sprite's facing at once to the given number**
**Answer: False** — 90

**3. (Sub lesson 1) True or false: the answer to "Which numbers point the sprite up and down?" is: 0 is up, and 180 is down**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does the direction number name?" is: No — the named direction replaces whatever it was**
**Answer: False** — A facing — not a movement

**5. (Sub lesson 1) True or false: the answer to "Why set direction before moving?" is: Because every move goes the way the sprite points**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does the point-in-direction block do?" is: From the moment the block runs**
**Answer: False** — It sets the sprite's facing at once to the given number

**7. (Sub lesson 2) True or false: the answer to "How does pointing differ from turning?" is: Turning adds an amount; pointing replaces the facing**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Does pointing depend on the old facing?" is: 90**
**Answer: False** — No — the named direction replaces whatever it was

**9. (Sub lesson 2) True or false: the answer to "What kind of journey uses pointing?" is: One named facing per leg — right, then down, then left**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "When is the new facing true from?" is: A facing — not a movement**
**Answer: False** — From the moment the block runs
