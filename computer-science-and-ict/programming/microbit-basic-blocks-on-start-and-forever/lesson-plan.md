**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** micro:bit Basic Blocks — On Start and Forever

**The one thing this lesson teaches:** The micro:bit's Basic block family — on start and forever — and lighting the LED grid into shapes
**This lesson's own level:** It stands on the earlier lessons of its title and on the book's own order — it follows the book's lessons in sequence, so its neighbours in the book are its natural companions. It stands alone for a learner landing on it directly.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **On start — what runs once, at the waking** — **On start** holds the blocks that run **once**, when the program begins: the setting-up — a greeting on the LEDs, a starting value, the first picture. Read it as the program's first sentence: everything in it happens before anything else, and never again. Kuwait begins here because a beginner must be able to point at a program and say what happens first.
2. **Forever — what runs while the board lives, and lighting shapes** — **Forever** holds the blocks that run **again and again** for as long as the board is on: the program's heartbeat. Between the two frames, the LED grid becomes a canvas: blocks light chosen LEDs into **shapes** — a heart, a face, an arrow — and a shape inside Forever with pauses becomes simple animation. On start sets the stage once; Forever keeps the show running.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
