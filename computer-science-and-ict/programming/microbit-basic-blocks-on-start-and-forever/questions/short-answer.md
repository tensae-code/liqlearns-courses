# micro:bit Basic Blocks — On Start and Forever — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does On start hold?**
**Answer: The blocks that run once, when the program begins**

**2. (Sub lesson 1) Give an example of an On start job.**
**Answer: A greeting on the LEDs or a starting value (any sensible example)**

**3. (Sub lesson 1) Does On start run again later?**
**Answer: No — once, before anything else**

**4. (Sub lesson 1) What does Forever hold?**
**Answer: Blocks that run again and again while the board is on**

**5. (Sub lesson 1) What is Forever called in the lesson's image?**
**Answer: The program's heartbeat**

**6. (Sub lesson 2) What do LED blocks light the grid into?**
**Answer: Shapes — a heart, a face, an arrow**

**7. (Sub lesson 2) How does a still shape become animation?**
**Answer: Place it in Forever with pauses, changing as it repeats**

**8. (Sub lesson 2) Which family do both frame blocks belong to?**
**Answer: The Basic block family (the Toolbox's Basic blocks)**

**9. (Sub lesson 2) In what order are the two frames taught?**
**Answer: On start first, then Forever**

**10. (Sub lesson 2) Which book teaches this?**
**Answer: Kuwait Grade 5 Digital Explorer Term 2, Unit 2 Lesson 8**
