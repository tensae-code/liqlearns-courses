# micro:bit Basic Blocks — On Start and Forever — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The blocks that run once, when the program begins**
**Answer: True**

**2. (Sub lesson 1) True or false: No — once, before anything else** — as the answer to: Give an example of an On start job.
**Answer: False — A greeting on the LEDs or a starting value (any sensible example)**

**3. (Sub lesson 1) True or false: No — once, before anything else**
**Answer: True**

**4. (Sub lesson 1) True or false: The program's heartbeat** — as the answer to: What does Forever hold?
**Answer: False — Blocks that run again and again while the board is on**

**5. (Sub lesson 1) True or false: The program's heartbeat**
**Answer: True**

**6. (Sub lesson 2) True or false: Place it in Forever with pauses, changing as it repeats** — as the answer to: What do LED blocks light the grid into?
**Answer: False — Shapes — a heart, a face, an arrow**

**7. (Sub lesson 2) True or false: Place it in Forever with pauses, changing as it repeats**
**Answer: True**

**8. (Sub lesson 2) True or false: On start first, then Forever** — as the answer to: Which family do both frame blocks belong to?
**Answer: False — The Basic block family (the Toolbox's Basic blocks)**

**9. (Sub lesson 2) True or false: On start first, then Forever**
**Answer: True**

**10. (Sub lesson 2) True or false: The blocks that run once, when the program begins** — as the answer to: Which book teaches this?
