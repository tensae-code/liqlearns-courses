# Python Tuples — Immutable Sequences — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a tuple?**
**Answer: An ordered collection, written in round brackets, that cannot be changed after creation**

**2. (Sub lesson 1) What three changes are forbidden?**
**Answer: Changing, adding and removing items**

**3. (Sub lesson 1) Does indexing work on tuples?**
**Answer: Yes — reading is as for lists; only writing is forbidden**

**4. (Sub lesson 1) What happens if a program tries to change a tuple?**
**Answer: Python raises an error — loudly, not quietly**

**5. (Sub lesson 1) Name two data that suit a tuple.**
**Answer: The days of the week; a point's coordinates (any fixed data)**

**6. (Sub lesson 2) Why is immutability a feature?**
**Answer: Data that must not change is protected from accidental changes the program could not see**

**7. (Sub lesson 2) State the course's rule of choice.**
**Answer: A list for a collection the program builds and changes; a tuple where changing would be a mistake**

**8. (Sub lesson 2) Which brackets for list, which for tuple?**
**Answer: Square for lists, round for tuples**

**9. (Sub lesson 2) Which course position is this?**
**Answer: Python data structures 2 — after lists, before dictionaries**

**10. (Sub lesson 2) Which book teaches this?**
**Answer: Kuwait Grade 10 Information Technology Term 2 (Book L1), Unit 1 — Tuples**
