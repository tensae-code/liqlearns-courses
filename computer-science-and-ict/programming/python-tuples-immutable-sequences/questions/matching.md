**1. (Sub lesson 1) What is a tuple?** → **An ordered collection, written in round brackets, that cannot be changed after creation**

**2. (Sub lesson 1) What three changes are forbidden?** → **Changing, adding and removing items**

**3. (Sub lesson 1) Does indexing work on tuples?** → **Yes — reading is as for lists; only writing is forbidden**

**4. (Sub lesson 1) What happens if a program tries to change a tuple?** → **Python raises an error — loudly, not quietly**

**5. (Sub lesson 1) Name two data that suit a tuple.** → **The days of the week; a point's coordinates (any fixed data)**

**6. (Sub lesson 2) Why is immutability a feature?** → **Data that must not change is protected from accidental changes the program could not see**

**7. (Sub lesson 2) State the course's rule of choice.** → **A list for a collection the program builds and changes; a tuple where changing would be a mistake**

**8. (Sub lesson 2) Which brackets for list, which for tuple?** → **Square for lists, round for tuples**
