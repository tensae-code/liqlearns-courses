# More Controls in Visual Basic — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does a check box do?**
a) Switches a thing on or off — several can be on together  b) Picks exactly one from a group — choosing one switches the others off  c) A list to pick from  d) The user can pick from the list or type their own entry
**Answer: a) Switches a thing on or off — several can be on together**

**2. (Sub lesson 1) What does an option (radio) button do?**
a) A list to pick from  b) Picks exactly one from a group — choosing one switches the others off  c) The user can pick from the list or type their own entry  d) Fitness — the control is chosen to match the shape of the choice
**Answer: b) Picks exactly one from a group — choosing one switches the others off**

**3. (Sub lesson 1) What does a list box offer?**
a) The user can pick from the list or type their own entry  b) Fitness — the control is chosen to match the shape of the choice  c) A list to pick from  d) An image on the form
**Answer: c) A list to pick from**

**4. (Sub lesson 1) How does a combo box differ?**
a) Fitness — the control is chosen to match the shape of the choice  b) An image on the form  c) Makes things happen by the clock, without the user touching anything  d) The user can pick from the list or type their own entry
**Answer: d) The user can pick from the list or type their own entry**

**5. (Sub lesson 1) What is Fiji's teaching point about controls?**
a) Fitness — the control is chosen to match the shape of the choice  b) An image on the form  c) Makes things happen by the clock, without the user touching anything  d) Animation and automatic updates
**Answer: a) Fitness — the control is chosen to match the shape of the choice**

**6. (Sub lesson 2) What does a picture box hold?**
a) Makes things happen by the clock, without the user touching anything  b) An image on the form  c) Animation and automatic updates  d) Let a value or a view be slid through a range

**7. (Sub lesson 2) What does the timer do?**

**8. (Sub lesson 2) What is the timer behind?**
a) Let a value or a view be slid through a range  b) Response, movement and time-keeping — it stops being a poster  c) Switches a thing on or off — several can be on together  d) Animation and automatic updates

**9. (Sub lesson 2) What do scroll bars do?**
a) Let a value or a view be slid through a range  b) Response, movement and time-keeping — it stops being a poster  c) Switches a thing on or off — several can be on together  d) Picks exactly one from a group — choosing one switches the others off
