# More Controls in Visual Basic — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does a check box do?" is: Switches a thing on or off — several can be on together**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does an option (radio) button do?" is: A list to pick from**
**Answer: False** — Picks exactly one from a group — choosing one switches the others off

**3. (Sub lesson 1) True or false: the answer to "What does a list box offer?" is: A list to pick from**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How does a combo box differ?" is: Fitness — the control is chosen to match the shape of the choice**
**Answer: False** — The user can pick from the list or type their own entry

**5. (Sub lesson 1) True or false: the answer to "What is Fiji's teaching point about controls?" is: Fitness — the control is chosen to match the shape of the choice**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does a picture box hold?" is: Makes things happen by the clock, without the user touching anything**
**Answer: False** — An image on the form

**7. (Sub lesson 2) True or false: the answer to "What does the timer do?" is: Makes things happen by the clock, without the user touching anything**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is the timer behind?" is: Let a value or a view be slid through a range**
**Answer: False** — Animation and automatic updates

**9. (Sub lesson 2) True or false: the answer to "What do scroll bars do?" is: Let a value or a view be slid through a range**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What do the second family of controls give a window?" is: Switches a thing on or off — several can be on together**
**Answer: False** — Response, movement and time-keeping — it stops being a poster
