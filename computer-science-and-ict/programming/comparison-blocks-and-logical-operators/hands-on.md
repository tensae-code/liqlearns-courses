# Hands-on — Comparison Blocks and Logical Operators

The lesson with your hands, not only your eyes.

## True or false first
Build three comparison blocks with numbers you choose. Write true or false beside each before running, then check by putting each in a branching block.

## Join the tests
Join two comparisons with and, then with or. For the same two tests, show a case where and says false but or says true.
