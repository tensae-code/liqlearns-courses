# Comparison Blocks and Logical Operators — multiple choice

Pick the one right answer.

**1. A comparison block answers —**
a) true or false  b) a colour  c) a costume
**Answer: a) true or false**

**2. AND joins two tests so the joined answer is true when —**
a) only the first is true  b) neither is true  c) both tests are true
**Answer: c) both tests are true**

**3. OR joins two tests so the joined answer is true when —**
a) the tests are long  b) at least one test is true  c) both are false
**Answer: b) at least one test is true**

**4. NOT does what to an answer?**
a) Flips true to false and false to true  b) Doubles it  c) Deletes it
**Answer: a) Flips true to false and false to true**
