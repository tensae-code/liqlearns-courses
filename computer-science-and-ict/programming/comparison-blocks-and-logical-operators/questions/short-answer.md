# Comparison Blocks and Logical Operators — short answer

Answer in a sentence or two.

**1. Explain, in your own words: build a comparison block and say whether it answers true or false.**
**Answer:** The learner's own explanation, true to the lesson: Comparison blocks ask how two numbers stand — greater, less, equal — and logical operators join tests with and, or and not, so a branch can ask a compound question.

**2. A classmate gets this lesson's work wrong. What is the most likely fault, and how is it fixed?**
**Answer:** Compound answer surprises you → split it: write each small test's answer (true/false) on paper first, then join them; never guess the whole question at once.
