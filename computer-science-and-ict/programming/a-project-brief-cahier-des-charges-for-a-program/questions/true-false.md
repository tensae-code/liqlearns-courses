# A Project Brief — Cahier des Charges for a Program — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The written brief a project is built against**
**Answer: True**

**2. (Sub lesson 1) True or false: The written brief a project is built against** — as the answer to: Name its five contents.
**Answer: False — Product, players, required behaviours, limits, acceptance**

**3. (Sub lesson 1) True or false: How ‘done’ will be judged**
**Answer: True**

**4. (Sub lesson 1) True or false: How ‘done’ will be judged** — as the answer to: Why write it?
**Answer: False — So studios argue once, on paper, instead of at delivery**

**5. (Sub lesson 1) True or false: Scénario 7, Fiche 4**
**Answer: True**

**6. (Sub lesson 2) True or false: Scénario 7, Fiche 4** — as the answer to: How are scope questions answered mid-build?
**Answer: False — By reading the brief, not by enthusiasm**

**7. (Sub lesson 2) True or false: ‘Brief broken’ (must fix) and ‘brief silent’ (choice or written amendment)**
**Answer: True**

**8. (Sub lesson 2) True or false: ‘Brief broken’ (must fix) and ‘brief silent’ (choice or written amendment)** — as the answer to: Against what is the delivered game judged?
**Answer: False — The delivered brief**

**9. (Sub lesson 2) True or false: ‘I like it’ against ‘it meets its charges’**
**Answer: True**

**10. (Sub lesson 2) True or false: ‘I like it’ against ‘it meets its charges’** — as the answer to: What must a brief amendment be?
**Answer: False — Written and agreed**
