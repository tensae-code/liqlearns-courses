# Basic Algorithmic Operations on Data Structures — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) Name the three content operations.**
**Answer: Insertion, deletion, and search**

**2. (Sub lesson 1) Where does insertion put a value?**
**Answer: At the place the structure's order demands**

**3. (Sub lesson 1) What must deletion do honestly?**
**Answer: Close the gap, so no later operation trips on the hole**

**4. (Sub lesson 1) Which operation's cost differs most between structures?**
**Answer: Search**

**5. (Sub lesson 1) Which unit teaches them?**
**Answer: Greece Grade 11 Eisagogi Epistimis H/Y, Ch.2.2**

**6. (Sub lesson 2) What is traversal?**
**Answer: Visiting every value of the structure once, in its order**

**7. (Sub lesson 2) Give traversal wearing a purpose.**
**Answer: Printing the list (or summing the array, or counting the chain)**

**8. (Sub lesson 2) What must sorting never do?**
**Answer: Lose or add a value while rearranging into order**

**9. (Sub lesson 2) What is the chapter's checklist for a new structure?**
**Answer: How it inserts, deletes, searches, traverses, sorts — and what each costs**

**10. (Sub lesson 2) An array search by index against a chain search is what contrast?**
**Answer: One look against a walk along the chain**
