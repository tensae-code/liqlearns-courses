# Algorithm Efficiency and Optimisation — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is efficiency judged by?**
a) How the work grows as the input grows  b) It measures one machine on one day, not the algorithm  c) It quadruples  d) The growth shape, not the constant
**Answer: a) How the work grows as the input grows**

**2. (Sub lesson 1) Why not judge by a stopwatch?**
a) It quadruples  b) It measures one machine on one day, not the algorithm  c) The growth shape, not the constant  d) About n operations
**Answer: b) It measures one machine on one day, not the algorithm**

**3. (Sub lesson 1) What happens to n² work when n doubles?**
a) The growth shape, not the constant  b) About n operations  c) It quadruples  d) Recalculating inside a loop and needless extra passes (any two from the lesson)
**Answer: c) It quadruples**

**4. (Sub lesson 1) What decides survival on big data?**
a) About n operations  b) Recalculating inside a loop and needless extra passes (any two from the lesson)  c) Once, before the loop  d) The growth shape, not the constant

**5. (Sub lesson 1) About how much work is a simple pass over n items?**
a) About n operations  b) Recalculating inside a loop and needless extra passes (any two from the lesson)  c) Once, before the loop  d) Halving the search space each step

**6. (Sub lesson 2) Name two kinds of avoidable work.**

**7. (Sub lesson 2) Where should a repeated calculation move?**

a) The growth — then the details  b) Correctness (and readability)  c) How the work grows as the input grows  d) It measures one machine on one day, not the algorithm
