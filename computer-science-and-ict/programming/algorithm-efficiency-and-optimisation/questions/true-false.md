# Algorithm Efficiency and Optimisation — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is efficiency judged by?" is: How the work grows as the input grows**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Why not judge by a stopwatch?" is: About n operations**
**Answer: False** — It measures one machine on one day, not the algorithm

**3. (Sub lesson 1) True or false: the answer to "What happens to n² work when n doubles?" is: It quadruples**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What decides survival on big data?" is: Once, before the loop**
**Answer: False** — The growth shape, not the constant

**5. (Sub lesson 1) True or false: the answer to "About how much work is a simple pass over n items?" is: About n operations**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Name two kinds of avoidable work." is: The growth — then the details**
**Answer: False** — Recalculating inside a loop and needless extra passes (any two from the lesson)

**7. (Sub lesson 2) True or false: the answer to "Where should a repeated calculation move?" is: Once, before the loop**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does sorted data allow in searching?" is: How the work grows as the input grows**
**Answer: False** — Halving the search space each step

**9. (Sub lesson 2) True or false: the answer to "What is optimised first?" is: The growth — then the details**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What must an optimisation never sacrifice?" is: It quadruples**
**Answer: False** — Correctness (and readability)
