# Hands-on — Algorithm Efficiency and Optimisation

The lesson with your hands and your feet, not only your eyes.

## Count, don't time
Write two ways to find whether a name is in a list: check every item, and (for a sorted list) halve each time. Count the worst-case checks for 16, 64 and 1024 items for both.

## Spot the waste
Write a small loop that recomputes something unchanging on every pass. Rewrite it with the computation moved before the loop, and count the operations saved for 1000 passes.
