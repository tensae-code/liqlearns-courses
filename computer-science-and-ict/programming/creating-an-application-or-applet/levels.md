# Creating an Application or Applet — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — The application — a program that stands alone
Sub lesson 1 questions from the type files. Pass mark: A standalone application, and an applet inside a web page; Its main method — public static void main(String[] args); Nothing else — it stands alone, carrying its own start and finish; Run from NetBeans or the command line; Building the project and writing its classes with their main method.

## Sub lesson 2 — The applet — a program that lives in a page
Sub lesson 2 questions from the type files. Pass mark: Inside a web page, hosted by the browser; No — the browser calls its life-cycle methods; Initialised, started, painted, stopped — as the page is visited and left; Its class is named in the page that hosts it; By where the users will meet the program.
