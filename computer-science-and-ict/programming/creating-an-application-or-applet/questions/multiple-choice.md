# Creating an Application or Applet — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What are the two shapes of a finished Java program here?**
a) A standalone application, and an applet inside a web page  b) Its main method — public static void main(String[] args)  c) Nothing else — it stands alone, carrying its own start and finish  d) Run from NetBeans or the command line
**Answer: a) A standalone application, and an applet inside a web page**

**2. (Sub lesson 1) By what method does every application enter?**
a) Nothing else — it stands alone, carrying its own start and finish  b) Its main method — public static void main(String[] args)  c) Run from NetBeans or the command line  d) Building the project and writing its classes with their main method
**Answer: b) Its main method — public static void main(String[] args)**

**3. (Sub lesson 1) Who hosts an application?**
a) Run from NetBeans or the command line  b) Building the project and writing its classes with their main method  c) Nothing else — it stands alone, carrying its own start and finish  d) Inside a web page, hosted by the browser
**Answer: c) Nothing else — it stands alone, carrying its own start and finish**

**4. (Sub lesson 1) How is an application started in this course?**
a) Building the project and writing its classes with their main method  b) Inside a web page, hosted by the browser  c) No — the browser calls its life-cycle methods  d) Run from NetBeans or the command line
**Answer: d) Run from NetBeans or the command line**

**5. (Sub lesson 1) What does creating an application include?**
a) Building the project and writing its classes with their main method  b) Inside a web page, hosted by the browser  c) No — the browser calls its life-cycle methods  d) Initialised, started, painted, stopped — as the page is visited and left
**Answer: a) Building the project and writing its classes with their main method**

**6. (Sub lesson 2) Where does an applet run?**
a) No — the browser calls its life-cycle methods  b) Inside a web page, hosted by the browser  c) Initialised, started, painted, stopped — as the page is visited and left  d) Its class is named in the page that hosts it
**Answer: b) Inside a web page, hosted by the browser**

**7. (Sub lesson 2) Does an applet have a main method?**
a) Initialised, started, painted, stopped — as the page is visited and left  b) Its class is named in the page that hosts it  c) No — the browser calls its life-cycle methods  d) By where the users will meet the program
**Answer: c) No — the browser calls its life-cycle methods**

**8. (Sub lesson 2) Name the applet's life-cycle moments.**
a) Its class is named in the page that hosts it  b) By where the users will meet the program  c) A standalone application, and an applet inside a web page  d) Initialised, started, painted, stopped — as the page is visited and left
**Answer: d) Initialised, started, painted, stopped — as the page is visited and left**

**9. (Sub lesson 2) How is an applet placed for use?**
a) Its class is named in the page that hosts it  b) By where the users will meet the program  c) A standalone application, and an applet inside a web page  d) Its main method — public static void main(String[] args)
**Answer: a) Its class is named in the page that hosts it**

**10. (Sub lesson 2) How does the creator choose between the shapes?**
a) A standalone application, and an applet inside a web page  b) By where the users will meet the program  c) Its main method — public static void main(String[] args)  d) Nothing else — it stands alone, carrying its own start and finish
**Answer: b) By where the users will meet the program**
