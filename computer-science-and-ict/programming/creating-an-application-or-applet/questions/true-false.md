# Creating an Application or Applet — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What are the two shapes of a finished Java program here?" is: A standalone application, and an applet inside a web page**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "By what method does every application enter?" is: Nothing else — it stands alone, carrying its own start and finish**
**Answer: False** — Its main method — public static void main(String[] args)

**3. (Sub lesson 1) True or false: the answer to "Who hosts an application?" is: Nothing else — it stands alone, carrying its own start and finish**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How is an application started in this course?" is: Building the project and writing its classes with their main method**
**Answer: False** — Run from NetBeans or the command line

**5. (Sub lesson 1) True or false: the answer to "What does creating an application include?" is: Building the project and writing its classes with their main method**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Where does an applet run?" is: No — the browser calls its life-cycle methods**
**Answer: False** — Inside a web page, hosted by the browser

**7. (Sub lesson 2) True or false: the answer to "Does an applet have a main method?" is: No — the browser calls its life-cycle methods**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Name the applet's life-cycle moments." is: Its class is named in the page that hosts it**
**Answer: False** — Initialised, started, painted, stopped — as the page is visited and left

**9. (Sub lesson 2) True or false: the answer to "How is an applet placed for use?" is: Its class is named in the page that hosts it**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "How does the creator choose between the shapes?" is: A standalone application, and an applet inside a web page**
**Answer: False** — By where the users will meet the program
