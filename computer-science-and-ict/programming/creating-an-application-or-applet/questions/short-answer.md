# Creating an Application or Applet — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What are the two shapes of a finished Java program here?**
**Answer: A standalone application, and an applet inside a web page**

**2. (Sub lesson 1) By what method does every application enter?**
**Answer: Its main method — public static void main(String[] args)**

**3. (Sub lesson 1) Who hosts an application?**
**Answer: Nothing else — it stands alone, carrying its own start and finish**

**4. (Sub lesson 1) How is an application started in this course?**
**Answer: Run from NetBeans or the command line**

**5. (Sub lesson 1) What does creating an application include?**
**Answer: Building the project and writing its classes with their main method**

**6. (Sub lesson 2) Where does an applet run?**
**Answer: Inside a web page, hosted by the browser**

**7. (Sub lesson 2) Does an applet have a main method?**
**Answer: No — the browser calls its life-cycle methods**

**8. (Sub lesson 2) Name the applet's life-cycle moments.**
**Answer: Initialised, started, painted, stopped — as the page is visited and left**

**9. (Sub lesson 2) How is an applet placed for use?**
**Answer: Its class is named in the page that hosts it**

**10. (Sub lesson 2) How does the creator choose between the shapes?**
**Answer: By where the users will meet the program**
