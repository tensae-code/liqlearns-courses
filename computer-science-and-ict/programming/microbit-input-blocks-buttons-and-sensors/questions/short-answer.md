# micro:bit Input Blocks — Buttons and Sensors — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What family do button and sensor blocks belong to?**
**Answer: The Input block family**

**2. (Sub lesson 1) What runs a button script?**
**Answer: Pressing the named button — A, B, or both together**

**3. (Sub lesson 1) Give a button program example.**
**Answer: Press A to count up, B to count down (any sensible example)**

**4. (Sub lesson 1) Why are buttons taught first among inputs?**
**Answer: The cause is visible — a finger presses and the board answers**

**5. (Sub lesson 1) Name two things the board's sensors sense.**
**Answer: Movement/shake and light (also direction, temperature)**

**6. (Sub lesson 2) What program shape do sensors allow?**
**Answer: Reacting to the board's surroundings — when shaken, when tilted**

**7. (Sub lesson 2) What changes when a program uses sensors?**
**Answer: It becomes about the world the board is in, not only the hands holding it**

**8. (Sub lesson 2) Is a sensor an input or an output?**
**Answer: An input — the board reads through it**

**9. (Sub lesson 2) What is the LED grid, by contrast?**
**Answer: An output — the board shows through it**

**10. (Sub lesson 2) Which book teaches this?**
**Answer: Kuwait Grade 5 Digital Explorer Term 2, Unit 2 Lesson 9**
