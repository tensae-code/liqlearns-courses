# Video script — micro:bit Input Blocks — Buttons and Sensors

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

The micro:bit's **A and B buttons** are its simplest inputs: an Input block runs its script **when a named button is pressed** — A, B, or both together. The program stops being a fixed performance and becomes a response: press A and count up, press B and count down. Kuwait teaches buttons first among inputs because the cause is visible — a finger presses, the board answers, and input stops being an abstraction.
The board's **sensors** are inputs that need no finger: it senses **movement** (shake, tilt), **direction**, **light** and **temperature**, and Input blocks let a program react — do this **when shaken**, show the temperature, answer a tilt. With sensors, the micro:bit reads its surroundings and the program becomes about the world the board is in, not only the hands that hold it.
