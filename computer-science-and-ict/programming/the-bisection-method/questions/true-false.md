# The Bisection Method — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Halves the bracket and keeps the half whose ends still change sign**
**Answer: True**

**2. (Sub lesson 1) True or false: Halves the bracket and keeps the half whose ends still change sign** — as the answer to: How is the kept half decided?
**Answer: False — By the sign of f at the midpoint — f(a)·f(c) < 0 keeps [a, c]**

**3. (Sub lesson 1) True or false: No — it is cornered; a cage-point is reported with the cage's width as error bound**
**Answer: True**

**4. (Sub lesson 1) True or false: No — it is cornered; a cage-point is reported with the cage's width as error bound** — as the answer to: What starts the method?
**Answer: False — A bracket from separation — f of opposite signs at the ends**

**5. (Sub lesson 1) True or false: Any point of the final bracket (say its midpoint), with the bracket's width as the error**
**Answer: True**

**6. (Sub lesson 2) True or false: Any point of the final bracket (say its midpoint), with the bracket's width as the error** — as the answer to: What is the bracket's width after n steps?
**Answer: False — (b − a) / 2ⁿ**

**7. (Sub lesson 2) True or false: 10 — because 2¹⁰ = 1024**
**Answer: True**

**8. (Sub lesson 2) True or false: 10 — because 2¹⁰ = 1024** — as the answer to: What can bisection never do?
**Answer: False — Run away, divide by a slope, or be fooled by the function's shape**

**9. (Sub lesson 2) True or false: A fixed rate — one binary digit of precision per step**
**Answer: True**

**10. (Sub lesson 2) True or false: A fixed rate — one binary digit of precision per step** — as the answer to: What is bisection, in the chapter's verdict?
**Answer: False — The benchmark of honesty — certainty first, speed as a luxury**
