# Depth-First Search — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Follow one path as deep as it goes, then backtrack and plunge down the next**
**Answer: True**

**2. (Sub lesson 1) True or false: Follow one path as deep as it goes, then backtrack and plunge down the next** — as the answer to: When do you backtrack?
**Answer: False — When the current path can reach no new vertex**

**3. (Sub lesson 1) True or false: The last vertex with an untried edge**
**Answer: True**

**4. (Sub lesson 1) True or false: The last vertex with an untried edge** — as the answer to: Why are vertices marked visited?
**Answer: False — So no vertex is explored twice**

**5. (Sub lesson 1) True or false: The path back — the vertices it may have to return to**
**Answer: True**

**6. (Sub lesson 2) True or false: The path back — the vertices it may have to return to** — as the answer to: What structure is DFS's memory?
**Answer: False — A stack — pushed descending, popped retreating**

**7. (Sub lesson 2) True or false: The procedure calls themselves**
**Answer: True**

**8. (Sub lesson 2) True or false: The procedure calls themselves** — as the answer to: Name two jobs DFS suits.
**Answer: False — Checking reachability or connectedness, and finding cycles or an ordering of dependent tasks**

**9. (Sub lesson 2) True or false: It may dive deep past a solution that lay near the start**
**Answer: True**

**10. (Sub lesson 2) True or false: It may dive deep past a solution that lay near the start** — as the answer to: Which search hunts level by level instead?
**Answer: False — Breadth-first search**
