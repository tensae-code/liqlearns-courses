# Depth-First Search — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is depth-first search's way of exploring?**
a) Follow one path as deep as it goes, then backtrack and plunge down the next  b) When the current path can reach no new vertex  c) The last vertex with an untried edge  d) So no vertex is explored twice
**Answer: a**

**2. (Sub lesson 1) When do you backtrack?**
a) When the current path can reach no new vertex  b) The last vertex with an untried edge  c) So no vertex is explored twice  d) The path back — the vertices it may have to return to
**Answer: a**

**3. (Sub lesson 1) Where do you backtrack to?**
a) The last vertex with an untried edge  b) So no vertex is explored twice  c) The path back — the vertices it may have to return to  d) A stack — pushed descending, popped retreating
**Answer: a**

**4. (Sub lesson 1) Why are vertices marked visited?**
a) So no vertex is explored twice  b) The path back — the vertices it may have to return to  c) A stack — pushed descending, popped retreating  d) The procedure calls themselves
**Answer: a**

**5. (Sub lesson 1) What does DFS need to remember?**
a) The path back — the vertices it may have to return to  b) A stack — pushed descending, popped retreating  c) The procedure calls themselves  d) Checking reachability or connectedness, and finding cycles or an ordering of dependent tasks
**Answer: a**

**6. (Sub lesson 2) What structure is DFS's memory?**
a) A stack — pushed descending, popped retreating  b) The procedure calls themselves  c) Checking reachability or connectedness, and finding cycles or an ordering of dependent tasks  d) It may dive deep past a solution that lay near the start
**Answer: a**

**7. (Sub lesson 2) What hides the same stack in a recursive DFS?**
a) The procedure calls themselves  b) Checking reachability or connectedness, and finding cycles or an ordering of dependent tasks  c) It may dive deep past a solution that lay near the start  d) Breadth-first search
**Answer: a**

**8. (Sub lesson 2) Name two jobs DFS suits.**
a) Checking reachability or connectedness, and finding cycles or an ordering of dependent tasks  b) It may dive deep past a solution that lay near the start  c) Breadth-first search  d) Follow one path as deep as it goes, then backtrack and plunge down the next
**Answer: a**

**9. (Sub lesson 2) What is DFS's weakness?**
a) It may dive deep past a solution that lay near the start  b) Breadth-first search  c) Follow one path as deep as it goes, then backtrack and plunge down the next  d) When the current path can reach no new vertex
**Answer: a**

**10. (Sub lesson 2) Which search hunts level by level instead?**
a) Breadth-first search  b) Follow one path as deep as it goes, then backtrack and plunge down the next  c) When the current path can reach no new vertex  d) The last vertex with an untried edge
**Answer: a**
