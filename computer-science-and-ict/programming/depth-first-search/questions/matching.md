# Depth-First Search — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What is depth-first search's way of exploring?** → **Follow one path as deep as it goes, then backtrack and plunge down the next**

**2. (Sub lesson 1) When do you backtrack?** → **When the current path can reach no new vertex**

**3. (Sub lesson 1) Where do you backtrack to?** → **The last vertex with an untried edge**

**4. (Sub lesson 1) Why are vertices marked visited?** → **So no vertex is explored twice**

**5. (Sub lesson 1) What does DFS need to remember?** → **The path back — the vertices it may have to return to**

**6. (Sub lesson 2) What structure is DFS's memory?** → **A stack — pushed descending, popped retreating**

**7. (Sub lesson 2) What hides the same stack in a recursive DFS?** → **The procedure calls themselves**

**8. (Sub lesson 2) Name two jobs DFS suits.** → **Checking reachability or connectedness, and finding cycles or an ordering of dependent tasks**

**9. (Sub lesson 2) What is DFS's weakness?** → **It may dive deep past a solution that lay near the start**

**10. (Sub lesson 2) Which search hunts level by level instead?** → **Breadth-first search**
