# Programming languages — and why LOGO

## Do it first

Your partner has a pencil and paper but cannot see you. Give spoken instructions to make them draw a square — no showing, only words. Where did it go wrong? Human language is loose. Computers need a language with no looseness. This lesson names that kind of language — and the friendly one this unit teaches.

## Programming languages

A **programming language** is an **artificial language for instructing a computer**. The book names **C++, Python, Java and LOGO**. The teacher guide's key adds the sharpest contrast: natural languages such as Amharic and English are easy for people but not for machines; a programming language is built the other way — for machines to follow exactly. And its purpose, in the guide's words: **to instruct the computer, and to automate processes**.

## Why LOGO

LOGO was **designed for ease of use and graphics** — originally to **introduce children to programming**. Its graphics are called **turtle graphics**: complex pictures built from **minimal coding**. Pupils learn LOGO, the book says, because **it is fun, it sharpens logical sense, and it develops programming skills**. One name to know whole: the unit's title expands LOGO as **'Logic Oriented Graphics Oriented'** — that is Ethiopia's own expansion of the name, and this course keeps the book's wording. The software used is **MSW Logo**, and it **must be installed first**, before any of the doing that follows.
