# Programming languages — and why LOGO — multiple choice

Pick the one right answer.

**1.** A programming language is —
a) a natural language  b) an artificial language for instructing a computer  c) a kind of hardware  d) a drawing only
**Answer: b) an artificial language for instructing a computer** — artificial, built for machines to follow.

**2.** Which list matches the book's named languages?
a) C++, Python, Java, LOGO  b) Amharic, English, French  c) Word, Excel, Access  d) HTML only
**Answer: a) C++, Python, Java, LOGO** — the book's four.

**3.** Natural languages are easy for —
a) machines only  b) people, but not machines  c) nobody  d) printers
**Answer: b) people, but not machines** — the guide's contrast.

**4.** LOGO was designed for —
a) speed only  b) ease of use and graphics  c) accounting  d) cleaning computers
**Answer: b) ease of use and graphics** — ease and graphics — to introduce children to programming.

**5.** Turtle graphics means —
a) drawing by hand  b) complex pictures from minimal coding  c) photographs of turtles  d) slow pictures
**Answer: b) complex pictures from minimal coding** — big pictures, little code.

**6.** Before MSW Logo can be used, it must be —
a) printed  b) installed  c) cleaned  d) password-protected
**Answer: b) installed** — installed first.
