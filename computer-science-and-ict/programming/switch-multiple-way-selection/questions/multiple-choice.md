# switch — Multiple-Way Selection — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does switch compare?**
a) One tested value against each case label  b) When its label matches the value  c) One value with many named possibilities — menus, day numbers, grade letters  d) A clumsy if-elif chain repeating the same test
**Answer: a) One tested value against each case label**

**2. (Sub lesson 1) When do a case's statements run?**
a) One value with many named possibilities — menus, day numbers, grade letters  b) When its label matches the value  c) A clumsy if-elif chain repeating the same test  d) Yes — named constant values
**Answer: b) When its label matches the value**

**3. (Sub lesson 1) What jobs suit switch?**
a) A clumsy if-elif chain repeating the same test  b) Yes — named constant values  c) One value with many named possibilities — menus, day numbers, grade letters  d) Leaves the switch
**Answer: c) One value with many named possibilities — menus, day numbers, grade letters**

**4. (Sub lesson 1) What does switch replace here?**
a) Yes — named constant values  b) Leaves the switch  c) Fall-through — the next case runs too  d) A clumsy if-elif chain repeating the same test
**Answer: d) A clumsy if-elif chain repeating the same test**

**5. (Sub lesson 1) Must case labels be constants?**
