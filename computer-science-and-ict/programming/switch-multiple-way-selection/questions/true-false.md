# switch — Multiple-Way Selection — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does switch compare?" is: One tested value against each case label**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "When do a case's statements run?" is: Yes — named constant values**
**Answer: False** — When its label matches the value

**3. (Sub lesson 1) True or false: the answer to "What jobs suit switch?" is: One value with many named possibilities — menus, day numbers, grade letters**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does switch replace here?" is: Fall-through — the next case runs too**
**Answer: False** — A clumsy if-elif chain repeating the same test

**5. (Sub lesson 1) True or false: the answer to "Must case labels be constants?" is: Yes — named constant values**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does break do in a switch?" is: Usually — occasionally it is wanted deliberately**
**Answer: False** — Leaves the switch

**7. (Sub lesson 2) True or false: the answer to "What happens without break?" is: Fall-through — the next case runs too**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is default?" is: One tested value against each case label**
**Answer: False** — The case for every unmatched value — the switch's else

**9. (Sub lesson 2) True or false: the answer to "Is fall-through always a bug?" is: Usually — occasionally it is wanted deliberately**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "How does the book say to trace its exercises?" is: One value with many named possibilities — menus, day numbers, grade letters**
**Answer: False** — Name the matched case and every statement run before a break
