# switch — Multiple-Way Selection — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does switch compare?**
**Answer: One tested value against each case label**

**2. (Sub lesson 1) When do a case's statements run?**
**Answer: When its label matches the value**

**3. (Sub lesson 1) What jobs suit switch?**
**Answer: One value with many named possibilities — menus, day numbers, grade letters**

**4. (Sub lesson 1) What does switch replace here?**
**Answer: A clumsy if-elif chain repeating the same test**

**5. (Sub lesson 1) Must case labels be constants?**
**Answer: Yes — named constant values**

**6. (Sub lesson 2) What does break do in a switch?**
**Answer: Leaves the switch**

**7. (Sub lesson 2) What happens without break?**
**Answer: Fall-through — the next case runs too**

**8. (Sub lesson 2) What is default?**
**Answer: The case for every unmatched value — the switch's else**

**9. (Sub lesson 2) Is fall-through always a bug?**
**Answer: Usually — occasionally it is wanted deliberately**

**10. (Sub lesson 2) How does the book say to trace its exercises?**
**Answer: Name the matched case and every statement run before a break**
