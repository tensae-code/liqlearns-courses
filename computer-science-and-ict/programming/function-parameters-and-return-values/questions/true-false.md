# Function Parameters and Return Values — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What must arguments match?" is: The parameters in number, type and order**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is copied into a parameter in C++?" is: A type and a name**
**Answer: False** — The argument's value (pass by value)

**3. (Sub lesson 1) True or false: the answer to "Do changes to a parameter reach the caller's variable?" is: No — the function works on a copy**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How long does a parameter exist?" is: Ends the function at once**
**Answer: False** — Only inside the function, for the length of the call

**5. (Sub lesson 1) True or false: the answer to "What does each parameter declare?" is: A type and a name**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How many values can a function return?" is: Nothing — it is called for what it does**
**Answer: False** — At most one

**7. (Sub lesson 2) True or false: the answer to "What else does return do besides giving the value?" is: Ends the function at once**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Name two things a caller can do with a returned value." is: The parameters in number, type and order**
**Answer: False** — Store it and print it (using it in an expression also counts)

**9. (Sub lesson 2) True or false: the answer to "What does a void function return?" is: Nothing — it is called for what it does**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is a function's signature?" is: No — the function works on a copy**
**Answer: False** — Its return type plus its parameter list
