# Function Parameters and Return Values — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What must arguments match?**
a) The parameters in number, type and order  b) The argument's value (pass by value)  c) No — the function works on a copy  d) Only inside the function, for the length of the call
**Answer: a) The parameters in number, type and order**

**2. (Sub lesson 1) What is copied into a parameter in C++?**
a) No — the function works on a copy  b) The argument's value (pass by value)  c) Only inside the function, for the length of the call  d) A type and a name
**Answer: b) The argument's value (pass by value)**

**3. (Sub lesson 1) Do changes to a parameter reach the caller's variable?**
a) Only inside the function, for the length of the call  b) A type and a name  c) No — the function works on a copy  d) At most one
**Answer: c) No — the function works on a copy**

**4. (Sub lesson 1) How long does a parameter exist?**
a) A type and a name  b) At most one  c) Ends the function at once  d) Only inside the function, for the length of the call
**Answer: d) Only inside the function, for the length of the call**

**5. (Sub lesson 1) What does each parameter declare?**
a) A type and a name  b) At most one  c) Ends the function at once  d) Store it and print it (using it in an expression also counts)
**Answer: a) A type and a name**

**6. (Sub lesson 2) How many values can a function return?**
a) Ends the function at once  b) At most one  c) Store it and print it (using it in an expression also counts)  d) Nothing — it is called for what it does
**Answer: b) At most one**

**7. (Sub lesson 2) What else does return do besides giving the value?**
a) Store it and print it (using it in an expression also counts)  b) Nothing — it is called for what it does  c) Ends the function at once  d) Its return type plus its parameter list
**Answer: c) Ends the function at once**

**8. (Sub lesson 2) Name two things a caller can do with a returned value.**
a) Nothing — it is called for what it does  b) Its return type plus its parameter list  c) The parameters in number, type and order  d) Store it and print it (using it in an expression also counts)
**Answer: d) Store it and print it (using it in an expression also counts)**

**9. (Sub lesson 2) What does a void function return?**
a) Nothing — it is called for what it does  b) Its return type plus its parameter list  c) The parameters in number, type and order  d) The argument's value (pass by value)
**Answer: a) Nothing — it is called for what it does**

**10. (Sub lesson 2) What is a function's signature?**
a) The parameters in number, type and order  b) Its return type plus its parameter list  c) The argument's value (pass by value)  d) No — the function works on a copy
**Answer: b) Its return type plus its parameter list**
