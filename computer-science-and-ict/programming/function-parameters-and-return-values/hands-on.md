# Hands-on — Function Parameters and Return Values

The lesson with your hands and your feet, not only your eyes.

## Copy proof
Write a function that adds 10 to its parameter and prints it. Call it with a variable holding 5, then print the variable after the call. Explain both printed values in one sentence each.

## Contract writing
For three small jobs (double a number; print a greeting for a name; decide if a number is even), write each function's signature and one sentence: what goes in, what comes back.
