# Hands-on — Processing CSV Files with Python Pandas

The lesson with your hands and your feet, not only your eyes.

## Beat your own time
Load the weather CSV from Do it first with pandas. Answer the same three questions with code — hottest day, rainy days in one town, average temperature — and compare the answers and the time with your hand work. Then find a bigger CSV (your teacher may provide one) and run the same lines on it unchanged.

## The flight log
Load the drone flight CSV. Print its columns and its first rows. Select only the rows above a chosen altitude. Then compute the drone’s speed between the first two recorded points: distance from the positions, divided by the difference of the times. Write one sentence on what the number tells you about the flight.
