# Processing CSV Files with Python Pandas — short answer

Answer in your own words, in one or two sentences.

**1. (Sub lesson 2) Why is answering the three weather questions by hand a bad plan for a real data file, and what changes with pandas?**
**Answer: Real files hold hundreds of thousands of rows; hand work is slow and mistakes creep in unnoticed. With pandas the file loads once into a DataFrame and each question is a single selection or computation line — fast, exact, and repeatable on the next file.**
