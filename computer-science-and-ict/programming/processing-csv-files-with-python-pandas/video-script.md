# Video script — Processing CSV Files with Python Pandas

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A CSV file is a table as text. pandas turns it back into a table — inside Python.

One line loads it: read_csv. The first line of the file becomes the column names. Every other line becomes a row.

Now ask questions. Select the rows where a town matches, or a temperature passes a test. Take one column and ask for its maximum, its mean, its count.

Twenty rows or two hundred thousand — the same lines work.

Even a drone's flight log is just another table: times and positions, row after row. Divide distance by time, and you have its speed.
