## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Understand the trickster's method** — The activity's first move is demystification: **understand the magicians' tricks (comprendre les astuces)** by demanding the method. A card trick works like a program: a **prepared setup** (the deck's hidden order), **exact steps** the performer must not vary, and a **forced outcome** the audience experiences as freedom. Nothing supernatural survives the write-up: once the steps are written plainly, anyone performing them gets the ‘miracle’ — the secret was an algorithm all along.
2. **Writing the trick as a logigramme** — Temps 1.2 writes the trick's steps into a **logigramme** (flowchart): the choices the spectator ‘freely’ makes become branches that reconverge; the performer's questions become tests; the reveal sits at the chart's single exit. Drawn this way, the class sees the family resemblance in full: the magic trick, the Deviner la carte conditional, and every deterministic program share one skeleton — arrange the steps so the desired end cannot escape.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
