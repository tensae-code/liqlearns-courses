# Typical Array Processing — Sorting, Searching, Merging, Parallel Arrays — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does sorting do to an array?**
a) Puts its elements in order in place  b) The element's position — or that it is absent  c) Both already in order  d) Repeatedly take the smaller of the two front values into the new array
**Answer: a**

**2. (Sub lesson 1) What does searching answer?**
a) Both already in order  b) The element's position — or that it is absent  c) Repeatedly take the smaller of the two front values into the new array  d) Join and re-sort — wasting the order both arrays brought
**Answer: b**

**3. (Sub lesson 1) What does merging require of its two arrays?**
a) Repeatedly take the smaller of the two front values into the new array  b) Join and re-sort — wasting the order both arrays brought  c) Both already in order  d) Arrays whose same index describes one thing — names in one, marks in the other
**Answer: c**

**4. (Sub lesson 1) How does merging proceed?**
a) Join and re-sort — wasting the order both arrays brought  b) Arrays whose same index describes one thing — names in one, marks in the other  c) Move the companions together  d) Repeatedly take the smaller of the two front values into the new array
**Answer: d**

**5. (Sub lesson 1) What must merging never do?**
a) Join and re-sort — wasting the order both arrays brought  b) Arrays whose same index describes one thing — names in one, marks in the other  c) Move the companions together  d) Sorting one array without swapping the other — the pair starts lying
**Answer: a**
