## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Sorting, searching, merging** — **Sorting** an array puts its elements in order in place — the guide works the exchange passes until no neighbouring pair stands wrong. **Searching** looks for a named element and answers its **position** — or that it is absent (the honest answer the algorithm lessons demand). **Merging (συγχώνευση)** takes two arrays **already in order** and pours them into one array still in order, by repeatedly taking the smaller of the two front values — never by joining and re-sorting, which wastes the order both arrays brought with them.
2. **Parallel arrays — companions in step** — **Parallel arrays (παράλληλοι πίνακες)** are two or more arrays whose **same index describes one thing**: names in one, marks in the other, so Π[ i ]'s mark stands in the second array at the same i. Every operation must move the companions **together** — sort the marks and the names must be swapped in the same exchanges, or the array pair starts lying about who earned what. The guide works parallel arrays through solved and unsolved exercises because the exam's favourite array fault is exactly that broken companionship.
