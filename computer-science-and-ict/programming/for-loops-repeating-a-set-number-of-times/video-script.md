# Video script — For Loops — Repeating a Set Number of Times (Visual Basic)

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

The **For…Next** loop repeats its block a **set number of times**, governed by a **counter**: `For counter = start To end` opens it, the block runs, and **Next** returns control to the top with the counter **stepped** onward, until the counter passes the end and the loop finishes. The counter is visible in the code — its start, its end, and its step are all written — so a For loop can be **counted by reading**, before it is run: the programmer states the repetitions, the machine performs them.
A loop is **definite** when the **number of repetitions is known before it starts** — print the table of 7, visit each of the 30 pupils, deal 52 cards. For…Next is the definite shape, and its counter doubles as a **value the block can use**: the table's multiplier, the pupil's number — each turn knows **which** turn it is. Kuwait opens its loops book here because definiteness is the safe first country: the loop's whole journey can be traced on paper, turn by turn, counter by counter.
