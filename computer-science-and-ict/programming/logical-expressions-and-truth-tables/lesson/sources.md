**Acceptance count: taught in 7 countries (Iraq, Uzbekistan, Malaysia, Moldova, Bangladesh, Pakistan, Kazakhstan).**

Placement choice: this lesson was built new for the ICT expansion (Iraq, 2026-11-14) because no existing lesson in the course covers this thing as its own lesson — the live tree was checked for the slug and for near matches before building. The placements file named this slug directly (NEW LESSON NEEDED — programming/logical-expressions-and-truth-tables). It sits in the Programming title (programming/), following the book's own order.

Iraq's own way (Grade 8): the same four-unit spiral one year on — the hardware unit becomes “the computer platform” and opens with choosing a computer's specifications before buying; Word is taught tab by tab (Home, Insert, Design, Layout); the algorithms unit advances to selection statements and logic truth tables, still landing in Scratch; the internet unit ends with writing a report from web research.


Uzbekistan's own way (Grade 8): grade 8 is theory-first — number systems, coding and Boolean logic before the machine's own story — then a full operating-system chapter and a five-lesson Word course; safety rules return as a closing appendix.

Malaysia's own way (Grade 11, SK Tingkatan 5): the final-year elective is exam-level computer science — computer architecture (fetch-decode-execute, Von Neumann, pipelining) and logic gates with Boolean expressions, a 57-page advanced SQL chapter that starts from ERD and normalisation, and a full web-programming chapter pair: client-side JavaScript (including sorting/searching, standard library, arrays) and server-side PHP working with text files, validation, queries, sign-up/login, ending in an interactive website build.

Moldova's own way (Grade 11, Informatică): Grade 11 is the theory year — how numbers, logic and circuits actually work inside the machine (Boolean algebra, adders, flip-flops, instruction formats, assembly language) — with structured programming (arrays, records, sets, files) carried over from Grade 10's languages; some sections are profile-specific (Real/Umanist).

Bangladesh's own way (HSC ICT, Classes XI–XII and Alim): one compulsory ICT book for every HSC and Alim student in the country, saturated with Bangladesh itself: Bangabandhu Satellite-1 and its ground stations, bdjobs and chakri.com job portals, Daraz and Bikroy e-commerce, the Walton factory's automated production line, the National ID card used to teach primary keys and its database used to teach RDBMS at work, a full Bangla Unicode table and a worked example of putting Bangla text on a web page with meta charset, the national letter-grade scale (A+ from 80) as the else-if programme, "I Love Bangladesh" as the loop example text, an algorithm for reaching college by bicycle or rickshaw, and the Digital Bangladesh programme — National Data Centre, hi-tech parks, Startup Bangladesh and Bangladesh Bank's QR-based Cashless Bangladesh. C is the HSC programming language, taught with scanf/printf in Code::Blocks.


Pakistan's own way (Grade 9 Computer Science 9): Grade 9 is a full problem-solving course before any coding — candid solutions, the 5 Ws of problem analysis, test data in five types, trace tables, verification vs validation — then number systems carried through to Boolean algebra with truth tables, networks taught through the postal-system analogy for TCP/IP layers, a data-and-privacy unit built on Code.org cipher widgets, NADRA and Pakistan's NR3C cybercrime centre, and a first website built page by page as "Pakistan.html".

Pakistan's own way (Grade 10 Computer Science 10): Grade 10 is a complete first course in C, taught in Code::Blocks: environment and program structure first, then user interaction (printf/scanf), conditional logic, data and repetition (arrays and for-loops), and functions — every idea carried by short English example programs with Urdu explanation, and each unit closing with Programming Time practice (salary, electricity-bill and discount programs from Pakistani everyday life).

Kazakhstan's own way (Kobdikova G4 ICT): Grade 4 ICT deepens every primary strand at once: Scratch grows variables, logical and comparison operators on the way to "My game"; EV3 robotics is taught through its sensors (colour, ultrasonic) towards labyrinth and kegeling; video is a real subject in the NCH VideoPad editor; and the final part pairs e-mail file exchange with password reliability and "computers of the future". Augmented-reality markers (the AR+ app from arman-pv.kz) animate pictures through a phone.

Kazakhstan's own way (Salgaraeva G10 Informatika, natural-science track): in Grade 10 the subject splits by track; this natural-science book is the deepest in the set — networks with IP, domains and VPN, number systems and logic with truth tables and the computer's logical elements, procedures/functions, strings, files, sorting methods and graph algorithms, a full HTML/CSS/scripts web part, and information systems from Big Data to linking web pages with a database. Every topic is doubled with a practicum paragraph.

Kazakhstan's own way (Zhunusov G10 Computer Science, English-medium): the English-medium Grade 10 book is the most technical of the wave: the CIA triad and three separate authentication lessons (passwords twice, biometrics), encoding standards, Python dictionaries, DFS/BFS graph traversal, and a full SQL chapter in MySQL (CREATE, INSERT, SELECT/WHERE, MIN/MAX, JOIN, GROUP BY, SELECT INTO) before a JavaScript chapter. (Its preface is the publisher's generic science template, left over from another book.)

Kazakhstan's own way (Adekenova & Pryanichnikova G9 Informatics, NIS): the NIS Grade 9 course is built around databases and object-oriented programming: computer architecture with logic circuits, coding raster images and sound, single-table then multi-table databases in Access (forms, queries, reports), five lessons introducing OOP, nine lessons developing applications in an OOP environment (C#), and a thirteen-lesson capstone — choosing a problem, designing the interface, programming, making a video instruction, testing, documenting and evaluating the project.

Kazakhstan's own way (Mukametzhanova G5 «Информатика» 2017 edition): the 2017 Atamura Grade 5 book opens with computer safety and a mini-project «Открытия, изменившие мир» (Discoveries that changed the world), teaches algorithms as following commands and escaping labyrinths (real and virtual), and the first program in Scratch with "graphics come alive".

Kazakhstan's own way (Pryanichnikova team G9 «Информатика» NIS): the NIS Grade 9 book is a step up in level: logic expressions, truth tables and logic circuits inside "computer architecture"; sound encoding beside raster encoding; single-table then multi-table databases in Access with forms, queries and reports; and a full object-oriented programming course in C# — components of OOP, multimedia applications, and a software-solution project with a video instruction and a slide show.
