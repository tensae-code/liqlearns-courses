# Logical Expressions and Truth Tables — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does a logical expression join?**
a) Conditions  b) Logical words — AND, OR and NOT  c) When both sides are true  d) It turns true into false and false into true
**Answer: a) Conditions**

**2. (Sub lesson 1) With what are conditions joined?**
a) True or false  b) Logical words — AND, OR and NOT  c) When at least one side is true  d) Every possible combination of truth values and the result for each
**Answer: b) Logical words — AND, OR and NOT**

**3. (Sub lesson 1) What two values can a condition take?**
a) When both sides are true  b) It turns true into false and false into true  c) True or false  d) Four rows
**Answer: c) True or false**

**4. (Sub lesson 1) When is an AND expression true?**
a) When at least one side is true  b) Every possible combination of truth values and the result for each  c) True/true, true/false, false/true, false/false  d) When both sides are true
**Answer: d) When both sides are true**

**5. (Sub lesson 1) When is an OR expression true?**
a) When at least one side is true  b) It turns true into false and false into true  c) Four rows  d) Exactly when the expression is true
**Answer: a) When at least one side is true**

**6. (Sub lesson 2) What does NOT do?**
a) Every possible combination of truth values and the result for each  b) It turns true into false and false into true  c) True/true, true/false, false/true, false/false  d) Conditions
**Answer: b) It turns true into false and false into true**

**7. (Sub lesson 2) What does a truth table list?**
a) Four rows  b) Exactly when the expression is true  c) Every possible combination of truth values and the result for each  d) Logical words — AND, OR and NOT
**Answer: c) Every possible combination of truth values and the result for each**

**8. (Sub lesson 2) How many rows does a truth table for two conditions have?**
a) True/true, true/false, false/true, false/false  b) Conditions  c) True or false  d) Four rows
**Answer: d) Four rows**

**9. (Sub lesson 2) Name the four rows for two conditions.**
a) True/true, true/false, false/true, false/false  b) Exactly when the expression is true  c) Logical words — AND, OR and NOT  d) When both sides are true
**Answer: a) True/true, true/false, false/true, false/false**

**10. (Sub lesson 2) What does filling a truth table prove?**
a) Conditions  b) Exactly when the expression is true  c) True or false  d) When at least one side is true
**Answer: b) Exactly when the expression is true**
