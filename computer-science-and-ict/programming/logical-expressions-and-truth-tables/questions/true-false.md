# Logical Expressions and Truth Tables — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does a logical expression join?" is: Conditions**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "With what are conditions joined?" is: When both sides are true**
**Answer: False** — Logical words — AND, OR and NOT

**3. (Sub lesson 1) True or false: the answer to "What two values can a condition take?" is: True or false**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "When is an AND expression true?" is: It turns true into false and false into true**
**Answer: False** — When both sides are true

**5. (Sub lesson 1) True or false: the answer to "When is an OR expression true?" is: When at least one side is true**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does NOT do?" is: Four rows**
**Answer: False** — It turns true into false and false into true

**7. (Sub lesson 2) True or false: the answer to "What does a truth table list?" is: Every possible combination of truth values and the result for each**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How many rows does a truth table for two conditions have?" is: Exactly when the expression is true**
**Answer: False** — Four rows

**9. (Sub lesson 2) True or false: the answer to "Name the four rows for two conditions." is: True/true, true/false, false/true, false/false**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What does filling a truth table prove?" is: Logical words — AND, OR and NOT**
**Answer: False** — Exactly when the expression is true
