# Programming a Robot Unplugged — With Cards — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does unplugged programming separate?**
**Answer: Composing the program (with cards) from entering and running it**

**2. (Sub lesson 1) Where is the card program composed?**
**Answer: On the table, away from the robot**

**3. (Sub lesson 1) What must programmers state before the run?**
**Answer: Where the robot will finish, and how it will face**

**4. (Sub lesson 1) What does the run judge?**
**Answer: The prediction**

**5. (Sub lesson 1) What is mode débranché in English?**
**Answer: Unplugged mode — programming with the machine switched off**

**6. (Sub lesson 2) What does unplugged work kill?**
**Answer: Trial-and-error button pressing**

**7. (Sub lesson 2) What replaces it?**
**Answer: Reading — tracing by finger, partner checking, repairing before running**

**8. (Sub lesson 2) What does the robot's run become?**
**Answer: A test of a written thing**

**9. (Sub lesson 2) State the professional shape.**
**Answer: Write it whole, read it hard, then let the machine judge**

**10. (Sub lesson 2) When is the program repaired in this mode?**
**Answer: Before any wheel turns**
