# Programming a Robot Unplugged — With Cards

## Do it first

The robot is across the room, asleep. Your program must be finished — complete and correct — before you may wake it. All you have is cards and the mat's picture. This is programming with the machine switched off: débranché.

## Sub lesson 1 — Planning away from the machine

**Unplugged programming (mode débranché)** separates the two halves of the craft: **compose** the program with cards on the table — where it can be read, argued over, rearranged — and only then **enter** it into Blue-Bot and run. The séance's discipline is prediction: before the robot moves, the programmers state where it will finish and how it will face. The run then judges the prediction, not the programmers' hopes.

## Sub lesson 2 — Why unplugged makes programmers

Working away from the robot kills the trial-and-error shuffle — pressing buttons until it sort of works — and replaces it with **reading**: a card program can be traced by finger, checked by a partner, and repaired before any wheel turns. The robot's run becomes a test of a written thing. That is the professional shape of programming, met at age seven: write it whole, read it hard, then let the machine judge.
