# Hands-on — Programming a Robot Unplugged — With Cards

The lesson with your hands and your feet, not only your eyes.

## Task one
**Compose, predict, run** — In pairs: compose a card program for a mat route, write your predicted finish (square + facing), then enter and run it on Blue-Bot. Score the prediction, not just the arrival.

## Task two
**Card review** — Swap card programs (no robots). Trace each other's by finger and mark the card you would change. Only then run both and compare with the marks.
