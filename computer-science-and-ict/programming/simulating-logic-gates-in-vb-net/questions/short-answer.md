# Simulating Logic Gates in VB.NET — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a gate simulation?**
**Answer: A small program that behaves as the gate behaves — inputs set, logic applied, output shown**

**2. (Sub lesson 1) How are inputs and output shown in the VB.NET project?**
**Answer: Inputs as switches or similar controls; the output as a lamp, label or colour**

**3. (Sub lesson 1) What does the code behind the controls do?**
**Answer: Recomputes the output whenever an input changes**

**4. (Sub lesson 1) How is the simulation tested?**
**Answer: Set the inputs to every row of the gate's truth table — the program must agree every time**

**5. (Sub lesson 1) How many times does Egypt build the VB.NET project?**
**Answer: Three — once per gate: AND, OR and NOT**

**6. (Sub lesson 2) What changes between the three builds?**
**Answer: Only the gate's logic — the form, switches, lamp and refresh machinery stay the same**

**7. (Sub lesson 2) What is AND's output rule?**
**Answer: The output is on only when both inputs are on**

**8. (Sub lesson 2) What is NOT's rule?**
**Answer: The single input is inverted**

**9. (Sub lesson 2) What does the pupil own by the third build?**
**Answer: The pattern — a new gate needs a new logic line and nothing else**

**10. (Sub lesson 2) In what second language is the same project then built?**
**Answer: PHP — the same logic wearing a web page**
