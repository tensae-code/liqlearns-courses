# Hands-on — Simulating Logic Gates in VB.NET

The lesson with your hands and your feet, not only your eyes.

## Task one
('Build the AND form', 'In VB.NET (or a careful form sketch), build the AND simulation: two input switches, one lamp, code that refreshes the lamp on every change. Test all four truth-table rows.')

## Task two
('Swap the gate', "Copy your project and change only the logic line to make it OR, then NOT. Write down exactly which line changed each time.")
