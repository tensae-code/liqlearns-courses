# Hands-on — Program flow control — the order code runs in

The lesson with your hands, not only your eyes — every activity is done for real, in IDLE or on paper.

## Morning-routine cards
Write each step of your morning on its own card. Lay them in order — that is sequential flow. Add one card that says IF, and one loop card that sends you back. Walk a finger along the cards as the program's execution dot would.

## Spot the construct
With a partner, act out three scenes: straight-line steps, a fork in the road, and circling back. Your partner names the construct in each scene.
