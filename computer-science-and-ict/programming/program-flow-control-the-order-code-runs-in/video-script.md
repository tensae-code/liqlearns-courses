This lesson: **Program flow control — the order code runs in**.

First, do it. Run the opening program. Watch what it prints.

Then the idea, in order: Sequential, branching and loop — the three constructs that regulate execution order. Syntax is the rules for writing instructions; semantics is their meaning; Python uses indentation for scope and new lines to end a command.

Now you. Sort six morning actions into order and say which flow construct a plain morning uses.

Say it to your companion: Tell your companion the three constructs in order, give a morning-routine example of sequential flow, and explain syntax versus semantics with the full-stop example.
