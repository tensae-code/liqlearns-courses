# Program flow control — the order code runs in — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Flow control is —
a) the order in which code executes  b) the colour of the screen  c) the speed of the computer
**Answer: a) a) the order in which code executes** — It regulates execution order.

**2. (Sub lesson 1)** Statements run one after another, in the order given, in —
a) branching  b) sequential flow  c) a loop
**Answer: b) b) sequential flow** — That is sequential flow.

**3. (Sub lesson 1)** Repeating a block until a condition is satisfied is —
a) sequential flow  b) branching  c) a loop
**Answer: c) c) a loop** — Loop / iteration.

**4. (Sub lesson 2)** Syntax is —
a) the meaning of an instruction  b) the rules for writing instructions  c) the output of a program
**Answer: b) b) the rules for writing instructions** — Rules = syntax; meaning = semantics.

**5. (Sub lesson 2)** In Python, scope — which lines belong to a block — is shown by —
a) brackets  b) indentation  c) capital letters
**Answer: b) b) indentation** — Python uses indentation.

**6. (Sub lesson 2)** `3 + 4` is an expression because it —
a) evaluates to a value  b) prints text  c) ends with a colon
**Answer: a) a) evaluates to a value** — It evaluates to 7.
