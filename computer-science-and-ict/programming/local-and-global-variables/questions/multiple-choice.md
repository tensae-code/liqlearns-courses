# Local and Global Variables in Functions — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Where is a local variable declared?**
a) Inside a function  b) From the call until the return  c) No — it is invisible outside its function  d) Its own fresh copies of the locals
**Answer: a) Inside a function**

**2. (Sub lesson 1) How long does a local variable live?**
a) No — it is invisible outside its function  b) From the call until the return  c) Its own fresh copies of the locals  d) Functions cannot wreck each other's working values
**Answer: b) From the call until the return**

**3. (Sub lesson 1) Can another function see a local variable?**
a) Its own fresh copies of the locals  b) Functions cannot wreck each other's working values  c) No — it is invisible outside its function  d) Outside all functions
**Answer: c) No — it is invisible outside its function**

**4. (Sub lesson 1) What does each call get?**
a) Functions cannot wreck each other's working values  b) Outside all functions  c) For the whole run of the program  d) Its own fresh copies of the locals
**Answer: d) Its own fresh copies of the locals**

**5. (Sub lesson 1) Why is locality a feature?**
a) Functions cannot wreck each other's working values  b) Outside all functions  c) For the whole run of the program  d) Every function
**Answer: a) Functions cannot wreck each other's working values**

**6. (Sub lesson 2) Where is a global variable declared?**
a) For the whole run of the program  b) Outside all functions  c) Every function  d) A change anywhere shows everywhere — bugs can come from any function
**Answer: b) Outside all functions**

**7. (Sub lesson 2) How long does a global live?**
a) Every function  b) A change anywhere shows everywhere — bugs can come from any function  c) For the whole run of the program  d) The local one — the global is shadowed
**Answer: c) For the whole run of the program**

**8. (Sub lesson 2) Who can change a global?**
a) A change anywhere shows everywhere — bugs can come from any function  b) The local one — the global is shadowed  c) Inside a function  d) Every function
**Answer: d) Every function**

**9. (Sub lesson 2) What is the danger of globals?**
a) A change anywhere shows everywhere — bugs can come from any function  b) The local one — the global is shadowed  c) Inside a function  d) From the call until the return
**Answer: a) A change anywhere shows everywhere — bugs can come from any function**

**10. (Sub lesson 2) If a local and a global share a name, which wins inside the function?**
a) Inside a function  b) The local one — the global is shadowed  c) From the call until the return  d) No — it is invisible outside its function
**Answer: b) The local one — the global is shadowed**
