# Hands-on — Local and Global Variables in Functions

The lesson with your hands and your feet, not only your eyes.

## Two counters
Write a program with a global counter and a function that also declares a local counter of the same name and prints both ideas clearly labelled. Run calls and explain every printed value.

## Make it local
Take a short program sketch that uses a global for one function's scratch work. Rewrite the sketch with that variable local, and write one sentence on what got safer.
