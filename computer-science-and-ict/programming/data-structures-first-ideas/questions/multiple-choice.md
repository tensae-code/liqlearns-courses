# Data Structures — First Ideas — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a data structure?**
a) An organised way of holding a collection of data  b) How items are added, found and taken out  c) With large collections — hundreds of values  d) What the program can easily do with the data
**Answer: a) An organised way of holding a collection of data**

**2. (Sub lesson 1) What do a structure's rules say?**
a) With large collections — hundreds of values  b) How items are added, found and taken out  c) What the program can easily do with the data  d) Collections
**Answer: b) How items are added, found and taken out**

**3. (Sub lesson 1) When are separate variables hopeless?**
a) What the program can easily do with the data  b) Collections  c) With large collections — hundreds of values  d) By position
**Answer: c) With large collections — hundreds of values**

**4. (Sub lesson 1) What is choosing a structure really choosing?**
a) Collections  b) By position  c) Last in, first out  d) What the program can easily do with the data
**Answer: d) What the program can easily do with the data**

**5. (Sub lesson 1) Do programs usually hold one value or collections?**
a) Collections  b) By position  c) Last in, first out  d) First in, first out
**Answer: a) Collections**

**6. (Sub lesson 2) How is an array picked from?**
a) Last in, first out  b) By position  c) First in, first out  d) Every later data lesson is a structure lesson in disguise
**Answer: b) By position**

**7. (Sub lesson 2) What order does a stack serve?**
a) First in, first out  b) Every later data lesson is a structure lesson in disguise  c) Last in, first out  d) The array
**Answer: c) Last in, first out**

**8. (Sub lesson 2) What order does a queue serve?**
a) Every later data lesson is a structure lesson in disguise  b) The array  c) An organised way of holding a collection of data  d) First in, first out
**Answer: d) First in, first out**

**9. (Sub lesson 2) Why does the book plant the idea early?**
a) Every later data lesson is a structure lesson in disguise  b) The array  c) An organised way of holding a collection of data  d) How items are added, found and taken out
**Answer: a) Every later data lesson is a structure lesson in disguise**

**10. (Sub lesson 2) Which structure does this course work with most?**
a) An organised way of holding a collection of data  b) The array  c) How items are added, found and taken out  d) With large collections — hundreds of values
**Answer: b) The array**
