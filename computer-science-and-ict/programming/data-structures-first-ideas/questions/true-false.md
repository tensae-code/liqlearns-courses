# Data Structures — First Ideas — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a data structure?" is: An organised way of holding a collection of data**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What do a structure's rules say?" is: Collections**
**Answer: False** — How items are added, found and taken out

**3. (Sub lesson 1) True or false: the answer to "When are separate variables hopeless?" is: With large collections — hundreds of values**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is choosing a structure really choosing?" is: Last in, first out**
**Answer: False** — What the program can easily do with the data

**5. (Sub lesson 1) True or false: the answer to "Do programs usually hold one value or collections?" is: Collections**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How is an array picked from?" is: Every later data lesson is a structure lesson in disguise**
**Answer: False** — By position

**7. (Sub lesson 2) True or false: the answer to "What order does a stack serve?" is: Last in, first out**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What order does a queue serve?" is: An organised way of holding a collection of data**
**Answer: False** — First in, first out

**9. (Sub lesson 2) True or false: the answer to "Why does the book plant the idea early?" is: Every later data lesson is a structure lesson in disguise**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Which structure does this course work with most?" is: With large collections — hundreds of values**
**Answer: False** — The array
