# Hands-on — Data Structures — First Ideas

The lesson with your hands and your feet, not only your eyes.

## Structure hunt
List five collections in school life (a class register, a library shelf, a lunch queue, a pile of exercise books, a timetable). For each, name the structure it resembles and its in/out rule.

## Scatter versus structure
Write down how you would hold 200 temperature readings with separate variables, then with an array. Count the names you must invent in each version.
