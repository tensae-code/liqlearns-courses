# Lesson plan — Starting a Script with an Event — the Green Flag

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** Starting a Script with an Event — the Green Flag
**Place in the curriculum:** ICT expansion — Finland (2026-11-14) — in the title Programming on the ICT course ladder (TITLES.md). Built new from Finland's *Ensiaskeleet ohjelmointiin* (student book, Oppilaan kirja, Versio 2.0), because no existing lesson teaches this thing as its own lesson.
**The one thing this lesson teaches:** A Scratch script needs a start signal: an event block at the top — when the green flag is clicked, or when this sprite is clicked — and the script runs only when that event happens.
**This lesson's own level:** It stands on the first Scratch script — dragging move and say blocks and clicking a script to run it — and adds the proper way to start a script: with an event.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

- Finland's own way is kept: this placement sits in Finland's two-part Scratch path — Part 1 moves towards the interactive-story project and Part 2 towards the self-built maze game, in the Luetaan (Let's read) then Ohjelmoidaan (Let's program) rhythm, with pair work, reflection and peer showing built in.

## What the learner can do when it ends
1. Say what an event block does at the top of a script.
2. Start a script with when green flag clicked, and say when it runs.
3. Start a script with when this sprite clicked, and say how that differs.
4. Fix a script that never runs because it has no event at its top.

## What you need
A computer with Scratch.

## The run of the lesson (in order)
1. **Do it first** — Build two blocks: move 10 steps and say hello. Click the blocks — they run. Now press nothing and wait. Nothing happens by itself. A program needs a signal that says: start now. This lesson gives your script that signal. (lesson/lesson.md).
2. **The explanation** — the lesson text in lesson/lesson.md, in its parts in order.

## If the learner is stuck
Script never runs in the finished project → check the top: is there an event block? Clicking blocks to test is not the project start. All sprites move when only one should → the others also carry the flag event; give the clicked-only action the sprite-clicked event instead.
