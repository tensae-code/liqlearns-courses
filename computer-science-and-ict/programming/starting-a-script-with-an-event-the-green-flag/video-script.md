# Video script — Starting a Script with an Event — the Green Flag


The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.


---


A script needs a start signal.

That signal is an event block on top.

Green flag clicked: the whole project starts.

Sprite clicked: only that sprite's script runs.
