# Starting a Script with an Event — the Green Flag — short answer

Answer in a sentence or two.

**1. Your friend's project does nothing when the green flag is clicked, though the blocks work when clicked. What do you tell them?**
**Answer:** A sound answer: the script has no event block at its top; add when-green-flag-clicked above the action blocks so the flag starts it.

**2. When would you choose when-this-sprite-clicked instead of the green flag?**
**Answer:** A sound answer: when that action should happen only when the player clicks that sprite — for example a character that speaks when clicked — not at the project's start.
