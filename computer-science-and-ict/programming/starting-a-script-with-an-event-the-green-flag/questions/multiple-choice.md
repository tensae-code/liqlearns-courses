# Starting a Script with an Event — the Green Flag — multiple choice

Pick the one right answer.

**1. An event block goes —**
a) At the top of the script  b) Under the stage  c) Inside a sound
**Answer: a) At the top of the script** — The event block tops the script and starts it.

**2. When the green flag is clicked, scripts starting with when-green-flag-clicked —**
a) Never run  b) Run, all of them together  c) Delete themselves
**Answer: b) Run, all of them together** — The flag is the project's start button.

**3. A when-this-sprite-clicked script runs when —**
a) The flag is clicked  b) That sprite is clicked on the stage  c) The computer is switched on
**Answer: b) That sprite is clicked on the stage** — It answers to the sprite itself being clicked.

**4. A script with no event block in a finished project —**
a) Runs by itself  b) Waits forever unless its blocks are clicked  c) Runs twice
**Answer: b) Waits forever unless its blocks are clicked** — Without an event, nothing in the project starts it.
