# Starting a Script with an Event — the Green Flag — true or false

Say whether each statement is true or false.

**1. Every script in Scratch must start at the same moment.**
**Answer: False** — Different events start scripts at different moments — flag, sprite click, and more.

**2. The green flag is the start button for the whole project.**
**Answer: True** — All flag scripts start together when it is clicked.

**3. Clicking the blocks themselves is a good final way to start a finished project.**
**Answer: False** — That is for testing; a finished project starts with events.
