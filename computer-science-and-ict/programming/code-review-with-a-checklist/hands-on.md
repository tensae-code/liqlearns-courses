# Hands-on — Code Review With a Checklist

The lesson with your hands and your feet, not only your eyes.

## Task one
**Review with the list** — Exchange programs with a partner. Review theirs using a four-section checklist you write first (three items per section). Hand back the list with every 'no' explained in one line.

## Task two
**Grow the list** — Find a fault in an old program of yours that a review should have caught. Write the checklist item that would have caught it, and add it to your class list.
