# Controlling a Robot Arm with an HMI — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 1) Commands travel from the computer to the Arduino over the ____ link (the USB cable).**
**Answer: serial — The USB connection is used as a serial link between the two programs.**

**2. (Sub lesson 2) HMI stands for human–____ interface.**
**Answer: machine — In French, IHM: interface homme-machine.**
