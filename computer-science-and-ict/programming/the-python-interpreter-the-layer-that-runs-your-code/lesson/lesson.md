# The interpreter — the layer that runs your Python

## Do it first

Write one line — `print(2 + 3)` — and it answers 5 at once. No separate build step, no waiting for a whole translation. Something read your line and carried it out on the spot. That something is the **interpreter** — the layer between your program and the computer's hardware. This lesson names it, and its family.

## Sub lesson 1 — Interpreted, not compiled — with one compilation step inside

Python is an **interpreted language, not a compiled one** — although compilation is **one step inside** its interpreter process (the next lesson opens that process up).

The **interpreter** is the program that **executes each line of statements** and runs Python code or a **script** — a simple program in a plain text file. It acts as a **layer between your program and the computer hardware**: your code speaks to the interpreter, the interpreter speaks to the machine.

## Sub lesson 2 — The family of interpreters — and installing one

Python has a **wide range of interpreters**:

- **IDLE** — the environment this course writes and debugs in;
- **CPython**, **Jython**, **PyPy** and **IronPython**;
- plus **online Python editors**.

Whichever you use, the **first practical step is making sure one is correctly installed** — no interpreter, no run.
