# The interpreter — the layer that runs your Python — fill in the blank

Fill in the blank with the right word or symbol.

**1. (Sub lesson 1)** The program that runs your Python is the ____.
**Answer: interpreter**

**2. (Sub lesson 1)** A simple program in a plain text file is a ____.
**Answer: script**

**3. (Sub lesson 2)** ____, CPython, Jython, PyPy, IronPython — a family of interpreters.
**Answer: IDLE**
