# The interpreter — the layer that runs your Python — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Python is a —
a) compiled language only  b) interpreted language  c) hardware language
**Answer: b) b) interpreted language**

**2. (Sub lesson 1)** The interpreter executes —
a) each line of statements  b) only the first line  c) the file name
**Answer: a) a) each line of statements**

**3. (Sub lesson 1)** A script is —
a) a simple program in a plain text file  b) a picture  c) a keyboard
**Answer: a) a) a simple program in a plain text file**

**4. (Sub lesson 2)** Which of these is a Python interpreter?
a) PyPy  b) Photoshop  c) Access
**Answer: a) a) PyPy**

**5. (Sub lesson 2)** The first practical step is —
a) buying a computer  b) making sure an interpreter is correctly installed  c) printing the code
**Answer: b) b) making sure an interpreter is correctly installed**

**6. (Sub lesson 2)** IDLE is —
a) one of Python's interpreters/environments  b) a loop keyword  c) a data type
**Answer: a) a) one of Python's interpreters/environments**
