# The interpreter — the layer that runs your Python — true or false

Say True or False.

**1. (Sub lesson 1)** Compilation plays no part at all in Python.
**Answer: False**

**Answer: True**

**4. (Sub lesson 2)** Online Python editors do not exist.
**Answer: False**
