# Hands-on — The interpreter — the layer that runs your Python

The lesson with your hands, not only your eyes — every activity is done for real, in IDLE or on paper.

## Layer drawing
Draw the three-layer stack — program, interpreter, hardware — and arrows showing a print line's journey down and the answer's journey up.

## Install check
On your machine, open IDLE (or an online editor), run print(2 + 3), and record: interpreter used, and the answer it gave (5).
