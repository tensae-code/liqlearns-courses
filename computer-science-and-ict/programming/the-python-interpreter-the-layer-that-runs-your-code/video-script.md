This lesson: **The interpreter — the layer that runs your Python**.

First, do it. Run the opening program. Watch what it prints.

Then the idea, in order: Python is an interpreted language; the interpreter executes each line of statements and runs code or scripts. IDLE, CPython, Jython, PyPy, IronPython and online editors; the first practical step is a correctly installed interpreter.

Now you. Name the layer stack aloud: program, interpreter, hardware.

Say it to your companion: Tell your companion what the interpreter does, why Python is called interpreted, and name three interpreters.
