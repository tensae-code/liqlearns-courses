# Video script — Programming Paradigms and Structured Programming

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A **programming paradigm (παράδειγμα)** is a way of organising a program's thought. The **imperative** paradigm writes **commands in order** — do this, then this — the way of the course's own languages. The **declarative** paradigm states **what is wanted** and lets the machine find the how. Inside and beside them stand the families the book names — **procedural** (imperative organised into procedures), **object-oriented** (programs as objects that act), **functional** and **logical** — each a different answer to 'what is a program made of?'
**Structured programming (δομημένος προγραμματισμός)** is the imperative discipline the whole Greek course obeys: every program is built from exactly three structures — **sequence, selection and repetition** — each with **one way in and one way out**, and the unrestricted jump (the goto that lands anywhere) is banished. Its fruit is provable order: a structured program can be read top to bottom, tested structure by structure, and trusted the way a building of beams is trusted — which is why ΓΛΩΣΣΑ itself is a structured language.
