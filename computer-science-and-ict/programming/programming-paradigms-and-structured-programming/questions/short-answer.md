# Programming Paradigms and Structured Programming — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a programming paradigm?**
**Answer: A way of organising a program's thought — what a program is taken to be**

**2. (Sub lesson 1) What does the imperative paradigm write?**
**Answer: Commands in order — do this, then this**

**3. (Sub lesson 1) What does the declarative paradigm state?**
**Answer: What is wanted, letting the machine find the how**

**4. (Sub lesson 1) Name two more families the book names.**
**Answer: Procedural and object-oriented (also functional and logical)**

**5. (Sub lesson 1) Which paradigm is the course's own way?**
**Answer: Imperative — organised procedurally**

**6. (Sub lesson 2) Name structured programming's three structures.**
**Answer: Sequence, selection and repetition**

**7. (Sub lesson 2) What does each structure have?**
**Answer: One way in and one way out**

**8. (Sub lesson 2) What is banished?**
**Answer: The unrestricted jump — the goto that lands anywhere**

**9. (Sub lesson 2) What is structured programming's fruit?**
**Answer: A program readable top to bottom and testable structure by structure**

**10. (Sub lesson 2) Which language here is structured by design?**
**Answer: ΓΛΩΣΣΑ**
