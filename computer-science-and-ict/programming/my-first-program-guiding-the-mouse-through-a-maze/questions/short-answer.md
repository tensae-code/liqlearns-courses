# My First Program — Guiding the Mouse Through a Maze — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is one arrow in the program?**
**Answer: One instruction — move one square in the arrow's direction**

**2. (Sub lesson 1) How are the arrows laid?**
**Answer: In a row, in order — first, second, to the last**

**3. (Sub lesson 1) When is the road planned?**
**Answer: Before moving — the whole path is found first**

**4. (Sub lesson 1) What does the mouse do with the program?**
**Answer: It follows the arrows exactly as laid**

**5. (Sub lesson 1) What comes first, thinking or running?**
**Answer: Thinking — a program is thought first and run second**

**6. (Sub lesson 2) What does running the program mean?**
**Answer: The mouse walks it — read an arrow, move, read the next, move**

**7. (Sub lesson 2) What stops the walk besides the last arrow?**
**Answer: A wall — a wrong arrow in the program**

**8. (Sub lesson 2) What are the guided online stages?**
**Answer: The same arrow programs in slightly harder mazes, checked at once on screen**

**9. (Sub lesson 2) Whose fault is a wall hit?**
**Answer: The program's — not the mouse's**

**10. (Sub lesson 2) Name the discipline in order.**
**Answer: Plan, write, run — then fix the program when it fails**
