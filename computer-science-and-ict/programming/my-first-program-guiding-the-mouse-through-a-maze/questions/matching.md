# My First Program — Guiding the Mouse Through a Maze — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What is one arrow in the program?** → **One instruction — move one square in the arrow's direction**

**2. (Sub lesson 1) How are the arrows laid?** → **In a row, in order — first, second, to the last**

**3. (Sub lesson 1) When is the road planned?** → **Before moving — the whole path is found first**

**4. (Sub lesson 1) What does the mouse do with the program?** → **It follows the arrows exactly as laid**

**5. (Sub lesson 1) What comes first, thinking or running?** → **Thinking — a program is thought first and run second**

**6. (Sub lesson 2) What does running the program mean?** → **The mouse walks it — read an arrow, move, read the next, move**

**7. (Sub lesson 2) What stops the walk besides the last arrow?** → **A wall — a wrong arrow in the program**

**8. (Sub lesson 2) What are the guided online stages?** → **The same arrow programs in slightly harder mazes, checked at once on screen**

**9. (Sub lesson 2) Whose fault is a wall hit?** → **The program's — not the mouse's**
