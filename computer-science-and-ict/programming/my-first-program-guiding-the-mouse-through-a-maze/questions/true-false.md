# My First Program — Guiding the Mouse Through a Maze — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: One instruction — move one square in the arrow's direction**
**Answer: True**

**2. (Sub lesson 1) True or false: One instruction — move one square in the arrow's direction** — as the answer to: How are the arrows laid?
**Answer: False — In a row, in order — first, second, to the last**

**3. (Sub lesson 1) True or false: Before moving — the whole path is found first**
**Answer: True**

**4. (Sub lesson 1) True or false: Before moving — the whole path is found first** — as the answer to: What does the mouse do with the program?
**Answer: False — It follows the arrows exactly as laid**

**5. (Sub lesson 1) True or false: Thinking — a program is thought first and run second**
**Answer: True**

**6. (Sub lesson 2) True or false: Thinking — a program is thought first and run second** — as the answer to: What does running the program mean?
**Answer: False — The mouse walks it — read an arrow, move, read the next, move**

**7. (Sub lesson 2) True or false: A wall — a wrong arrow in the program**
**Answer: True**

**8. (Sub lesson 2) True or false: A wall — a wrong arrow in the program** — as the answer to: What are the guided online stages?
**Answer: False — The same arrow programs in slightly harder mazes, checked at once on screen**

**9. (Sub lesson 2) True or false: The program's — not the mouse's**
**Answer: True**

**10. (Sub lesson 2) True or false: The program's — not the mouse's** — as the answer to: Name the discipline in order.
**Answer: False — Plan, write, run — then fix the program when it fails**
