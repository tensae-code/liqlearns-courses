# My First Program — Guiding the Mouse Through a Maze — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Arrow instructions — the program's words
Sub lesson 1 questions from the type files. Pass mark: One instruction — move one square in the arrow's direction; In a row, in order — first, second, to the last; Before moving — the whole path is found first; It follows the arrows exactly as laid; Thinking — a program is thought first and run second.

## Sub lesson 2 — Running the program — and the guided stages
Sub lesson 2 questions from the type files. Pass mark: The mouse walks it — read an arrow, move, read the next, move; A wall — a wrong arrow in the program; The same arrow programs in slightly harder mazes, checked at once on screen; The program's — not the mouse's; Plan, write, run — then fix the program when it fails.
