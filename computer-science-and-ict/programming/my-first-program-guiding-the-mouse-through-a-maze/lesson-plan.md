## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Arrow instructions — the program's words** — The program is written in **arrows**: each arrow is one instruction — move one square forward in the arrow's direction. The arrows are laid **in a row, in order**, and the mouse will follow them exactly as laid: first the first, then the second, to the last. Writing the program means **planning the whole road before moving**: look at the maze, find the path from start to cheese, and only then lay the arrows. A program is thought first and run second.
2. **Running the program — and the guided stages** — To **run** the program, the mouse walks it: read the first arrow, move; read the next, move — until the last arrow or a wall stops the walk. The book then moves the same skill onto the screen in **guided online stages**: the same arrow programs, slightly harder mazes, each stage checking the walk at once. Whether on paper or on screen, the discipline is one: plan, write, run, and when the mouse hits a wall, the program — not the mouse — is wrong.

## What the learner can do when it ends
1. One instruction — move one square in the arrow's direction
2. In a row, in order — first, second, to the last
3. Before moving — the whole path is found first
4. It follows the arrows exactly as laid
