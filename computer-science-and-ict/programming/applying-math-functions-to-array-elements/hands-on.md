# Hands-on — Applying Math Functions to Array Elements

The lesson with your hands and your feet, not only your eyes.

## Root table
For {1, 4, 9, 16, 25}, write the per-element sqrt transform into a second array by hand, then the sum of both arrays. State which pass each sum needed.

## Guard the domain
Sketch the loop that prints the square root of every element of an array that may contain negatives, skipping (and counting) the negatives. Name the test and where it sits.
