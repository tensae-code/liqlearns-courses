# Video script - High-level languages - compilers and interpreters

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.
A short video script for this lesson; its placement names no full-script need.

---

Some languages are close to our own language.
High-level languages.
C. Java. Python. Ruby.

But the computer needs machine language.
So the program must be translated.

A compiler translates the WHOLE program at once.
Then it runs.
C, C++, Java and C# work this way.

An interpreter translates ONE statement at a time.
Translate. Run. Next line.
Python, Perl and Ruby work this way.

Whole book first - or sentence by sentence?
