# High-level languages - compilers and interpreters - multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A high-level language is one that -
a) is written in binary  b) sits closer to human language  c) needs no translation  d) runs only on one computer
**Answer: b) sits closer to human language** - the programmer can concentrate on the problem.

**2. (Sub lesson 1)** Which list is all high-level languages named in this lesson?
a) C, Python, Java, Ruby  b) Binary, Assembly, C  c) Mnemonics, C++, Perl  d) Machine code, Java, C#
**Answer: a) C, Python, Java, Ruby** - C, C++, Java, C#, Python, Perl and Ruby are the named set.

**3. (Sub lesson 2)** A compiler translates -
a) one statement, then runs it  b) the whole program at once, and the translated form is then executed  c) only the first line  d) nothing - it runs the program directly
**Answer: b) the whole program at once, and the translated form is then executed** - whole program first, execution after.

**4. (Sub lesson 2)** Which languages work with a compiler?
a) Python and Perl  b) C, C++, Java and C#  c) Ruby and Python  d) Perl and Ruby
**Answer: b) C, C++, Java and C#** - the book's compiler set.

**5. (Sub lesson 3)** An interpreter -
a) translates the whole program before running anything  b) translates and executes one statement at a time  c) never translates  d) works only for C
**Answer: b) translates and executes one statement at a time** - translate a statement, run it, move on.

**6. (Sub lesson 3)** Which languages work with an interpreter?
a) C and Java  b) C++ and C#  c) Python, Perl and Ruby  d) Java and C
**Answer: c) Python, Perl and Ruby** - Python - this unit's language - is interpreted.

**7. (Sub lesson 3)** Python needs an interpreter because -
a) it is a high-level language and the computer understands only machine language directly  b) interpreters are free  c) compilers are too slow  d) Python has no syntax
**Answer: a) it is a high-level language and the computer understands only machine language directly** - translation is still needed; the interpreter organises it line by line.
