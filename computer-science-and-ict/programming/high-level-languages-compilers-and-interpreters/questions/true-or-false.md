# High-level languages - compilers and interpreters - true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** High-level languages let the programmer concentrate on the problem rather than the language.
**Answer: True** - that closeness to human language is their gift.

**2. (Sub lesson 2)** A compiler executes each statement as soon as it is translated.
**Answer: False** - a compiler translates the whole program at once; execution comes after.

**3. (Sub lesson 3)** Python is an interpreted language.
**Answer: True** - Python, Perl and Ruby are the book's interpreter set.
