# High-level languages - compilers and interpreters

## Do it first

Read this instruction: "1011 0001". Now read this one: `print("Selam")`. Which one could you guess the meaning of? The second is a high-level language - close to human language. But the computer still only understands machine language, so high-level programs must be translated too. This lesson is about the two ways that translation happens.

## Sub lesson 1 - High-level languages - close to human language

**High-level languages** sit **closer to human language**. Their gift: the programmer can **concentrate on the problem** rather than fighting the language itself.

The named examples are **C, C++, Java, C#, Python, Perl and Ruby**.

But a high-level program is still not machine language. It must be **translated** - and there are two kinds of translator.

## Sub lesson 2 - Compilers - the whole program at once

A **compiler** translates the **whole program at once**. Only when the translation is finished is the translated form **executed** - run.

Think of a whole book translated first, then read. The languages that work this way are **C, C++, Java and C#**.

## Sub lesson 3 - Interpreters - one statement at a time

An **interpreter** works differently: it **translates and executes one statement at a time** - translate a line, run it, move to the next line.

Think of a speaker translated sentence by sentence, live. The languages that work this way are **Python, Perl and Ruby**. Python - the language of the rest of this unit - is an interpreted language.
