# Hands-on — String Procedures and Functions

The lesson with your hands and your feet, not only your eyes.

## Find and copy
Write a program that stores a full name in one string, finds the space in it with a string function, and copies out the part before the space. Print both the position found and the copied part.

## Insert and delete
Write a program that inserts a word into the middle of a stored sentence with a procedure, prints the result, then deletes that same word again and prints the restored sentence.
