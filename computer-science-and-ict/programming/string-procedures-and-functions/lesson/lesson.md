# String Procedures and Functions

## Do it first

A name is stored as 'Family, First' and you need 'First Family'. Cutting, finding and joining text by hand, character by character, is slow and error-prone — in this lesson you call PascalABC's ready string tools that do each cut exactly.

## Sub lesson 1 — The ready tools for strings

**Processing** a string variable means changing it or learning something about it: how long it is, what part of it says, where a piece occurs. PascalABC provides ready **procedures and functions** for these standard jobs. A **function** hands back an answer — the length of a string, a copied part of it, the position where a searched piece begins. A **procedure** does a job on the variable itself — inserting a piece into it or deleting a piece from it, so the variable holds the changed text afterwards.

[Picture — a toolbox labelled string tools with five tools inside — measure length, copy part, find part, join, insert and delete]

## Sub lesson 2 — Using the tools in a program

The working method is the same for every tool: know what the tool needs (the string, and usually a position or a piece of text), know what it gives back or changes, and check the edges — a position beyond the string's length, a searched piece that is not there, an empty string. Joining strings end to end builds longer text from shorter pieces, and most real text tasks are a chain of these small tools: find a piece, copy it out, join it to something else, delete what is not needed. The next section of the book sets practical tasks that are solved exactly this way.
