# String Procedures and Functions — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does processing a string mean?" is: Changing it, or learning something about it — its length, a part of it, where a piece occurs.**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does a function hand back here?" is: Builds longer text from shorter pieces, end to end.**
**Answer: False** — An answer — for example a length, a copied part, or a found position.

**3. (Sub lesson 1) True or false: the answer to "What does a procedure do here?" is: A job on the variable itself, such as inserting or deleting a piece, so the variable holds the changed text.**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What must you know before calling a string tool?" is: The position where the piece begins.**
**Answer: False** — What it needs, and what it gives back or changes.

**5. (Sub lesson 1) True or false: the answer to "Name an edge case to check." is: A position beyond the string's length, a searched piece that is not there, or an empty string.**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does joining strings do?" is: They are tested and do each standard job exactly.**
**Answer: False** — Builds longer text from shorter pieces, end to end.

**7. (Sub lesson 2) True or false: the answer to "What are most real text tasks, in this section's view?" is: A chain of small tools — find, copy out, join, delete.**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Where does a searched piece's answer come as?" is: An answer — for example a length, a copied part, or a found position.**
**Answer: False** — The position where the piece begins.

**9. (Sub lesson 2) True or false: the answer to "Does deleting a piece change the original variable?" is: Yes — the procedure changes the variable itself.**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why use ready tools instead of rebuilding them?" is: What it needs, and what it gives back or changes.**
**Answer: False** — They are tested and do each standard job exactly.
