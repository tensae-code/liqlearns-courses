# ScratchJr Project — the Maze, Traffic, Jump and Moon Games — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) How many games does the project set?**
**Answer: Four**

**2. (Sub lesson 1) Name the four games.**
**Answer: The maze game, the safe-traffic game, the obstacle-jump game and the moon-orbit game**

**3. (Sub lesson 1) What skill does the maze game exercise?**
**Answer: Steering a sprite carefully through passages, with walls that matter**

**4. (Sub lesson 1) What rule does the safe-traffic game teach?**
**Answer: Crossing when it is safe**

**5. (Sub lesson 1) What do the first two games share?**
**Answer: Control — small moves at the right moment, in a world with edges**

**6. (Sub lesson 2) What is the jump game's deciding skill?**
**Answer: Timing**

**7. (Sub lesson 2) What movement does the moon-orbit game demand?**
**Answer: Movement bent into an orbit around the moon**

**8. (Sub lesson 2) Name the four games' four tempers.**
**Answer: Steer, judge, time, and circle**

**9. (Sub lesson 2) What is this project in the unit?**
**Answer: Project (1) — the ScratchJr unit's closing project**

**10. (Sub lesson 2) Which book sets this project?**
**Answer: Kuwait Grade 4 Digital Explorer Term 1, Unit 2 Lesson 6**
