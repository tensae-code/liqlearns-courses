## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The inquiry's review — three methods on trial** — The Grade 7 inquiry ends in a **review (bilan)**: **bubble sort (tri à bulles)**, **merge sort (tri fusion)** and **quick sort (tri rapide)** are ‘passed in review’ — the same data given to each, their work counted and compared. Merge sort splits the pile in half, sorts the halves, and merges — steady and predictable. Quick sort partitions around a pivot — usually the fastest, with bad days when the pivot is unlucky. Bubble sort, the beginner's friend, drowns as piles grow.
2. **Best for what, best for whom** — The bilan's verdict is a template for all algorithm judgement: state the **situation** (how many items? how scrambled? what does one comparison cost? how bad is the worst case?), run or reason **trials at several sizes**, and let the crown move with the situation. A method best on tiny, nearly-sorted piles may be worst at scale. Comparing algorithms is thus a grown-up skill disguised as a sorting lesson: evidence first, adjectives last.
