# The Program Development Life Cycle — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) The stage that states the program's inputs, outputs and limits is —**
a) Coding  b) Problem definition  c) Maintenance  d) Implementation
**Answer: b) Problem definition — Problem definition — agreed with the users before any design or code.**

**2. (Sub lesson 1) An algorithm written in a language-neutral, step-by-step form belongs to —**
a) Program design  b) Testing  c) Debugging  d) Implementation
**Answer: a) Program design — Program design — pseudocode and flowcharts plan the solution before coding.**

**3. (Sub lesson 2) Debugging means —**
a) Running the program on test data  b) Locating and fixing errors that testing exposed  c) Training the users  d) Installing the program
**Answer: b) Locating and fixing errors that testing exposed — Locating and fixing errors — testing exposes them; debugging removes them.**
