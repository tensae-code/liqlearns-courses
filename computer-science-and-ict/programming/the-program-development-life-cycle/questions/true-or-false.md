# The Program Development Life Cycle — true or false

Say whether each statement is true or false.

**1. (Sub lesson 2) A logic error stops the program from being translated.**
**Answer: False — A logic error lets the program run but gives wrong answers; syntax errors are the ones that stop translation.**

**2. (Sub lesson 2) Maintenance is usually the longest stage of a program's life.**
**Answer: True — Correcting, improving and adapting the program in use goes on for years — far longer than writing it.**
