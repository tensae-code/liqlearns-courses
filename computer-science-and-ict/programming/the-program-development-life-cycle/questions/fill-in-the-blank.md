# The Program Development Life Cycle — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 1) The first stage of the cycle, noticing that a task needs a program, is problem ____.**
**Answer: recognition — Recognition comes before definition — you cannot define a problem you have not noticed.**

**2. (Sub lesson 2) Putting the finished program into real use, with data converted and users trained, is ____.**
**Answer: implementation — Implementation follows successful testing and precedes maintenance.**
