# The Program Development Life Cycle — short answer

Answer in your own words, in one or two sentences.

**1. (Sub lesson 1) A school asks for 'a program for fees' and a programmer codes immediately; the result cannot handle part-payments, which half the pupils use. Which stages were skipped, and what did skipping them cost?**
**Answer: Problem definition (and with it, design): the inputs, outputs and limits were never agreed with the users, so the part-payment case — known to every fees clerk — never reached the programmer. The cost is rework after coding, the most expensive place to discover a missing requirement; defining the problem first would have caught it on paper.**
