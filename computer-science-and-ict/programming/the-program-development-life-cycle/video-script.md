# Video script — The Program Development Life Cycle

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Good programs start on paper, not on the keyboard. Recognise the problem. Define it. Design it.

Then code it, test it, debug it — testing finds the errors, debugging fixes them.

Install it, train the users, and maintain it. The cycle loops, because needs never stop changing.
