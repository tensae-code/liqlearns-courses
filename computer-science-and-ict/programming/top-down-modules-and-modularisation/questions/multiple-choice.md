# Top-down — modules and modularisation — multiple choice

Pick the one right answer.

**1.** What is top-down solving?
a) starting with the most general modules and working toward the specific — decomposing a big problem into smaller sub-problems  b) dividing a problem into modules, each solved individually, then integrated into the complete solution  c) a sub-problem solved individually as one part of a larger solution  d) the subroutine module computing one net pay, called ten times by the main module in the wage example
**Answer: a) starting with the most general modules and working toward the specific — decomposing a big problem into smaller sub-problems**

**2.** What is modularisation?
a) starting with the most general modules and working toward the specific — decomposing a big problem into smaller sub-problems  b) a sub-problem solved individually as one part of a larger solution  c) the subroutine module computing one net pay, called ten times by the main module in the wage example  d) dividing a problem into modules, each solved individually, then integrated into the complete solution
**Answer: d) dividing a problem into modules, each solved individually, then integrated into the complete solution**

**3.** What is a module?
a) dividing a problem into modules, each solved individually, then integrated into the complete solution  b) the subroutine module computing one net pay, called ten times by the main module in the wage example  c) a sub-problem solved individually as one part of a larger solution  d) starting with the most general modules and working toward the specific — decomposing a big problem into smaller sub-problems
**Answer: c) a sub-problem solved individually as one part of a larger solution**

**4.** What is CalculateWage?
a) a sub-problem solved individually as one part of a larger solution  b) the subroutine module computing one net pay, called ten times by the main module in the wage example  c) starting with the most general modules and working toward the specific — decomposing a big problem into smaller sub-problems  d) dividing a problem into modules, each solved individually, then integrated into the complete solution
**Answer: b) the subroutine module computing one net pay, called ten times by the main module in the wage example**

**5.** The main module in the wage example —
a) computes all wages itself in one box  b) loops, calling CalculateWage ten times  c) pays the labourers  d) declares no variables
**Answer: b) loops, calling CalculateWage ten times**

**6.** A subroutine is called with the flowchart's —
a) terminator  b) CALL / subroutine symbol  c) connector only  d) parallelogram
**Answer: b) CALL / subroutine symbol**
