# Top-down — modules and modularisation — tf

Say whether each statement is true or false.

**1.** True or false: top-down solving — starting with the most general modules and working toward the specific — decomposing a big problem into smaller sub-problems.
**Answer: True**

**2.** True or false: modularisation — dividing a problem into modules, each solved individually, then integrated into the complete solution.
**Answer: True**

**3.** True or false: a module is the opposite: it has nothing to do with a sub-problem solved individually as one part of a larger solution.
**Answer: False** — a module is about a sub-problem solved individually as one part of a larger solution.
