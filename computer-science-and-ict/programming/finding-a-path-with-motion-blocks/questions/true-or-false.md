# Finding a Path with Motion Blocks — true or false

Say whether each statement is true or false.

**1. Plan a whole route with a finger or eye before building any blocks.**
**Answer: True** — This is one of the lesson's own outcomes.

**2. The best way to find a path is to snap blocks together at random and hope the hero arrives.**
**Answer: False** — The lesson teaches the opposite of this.

**3. Build a path that spells a word, block by block.**
**Answer: True** — This is one of the lesson's own outcomes.
