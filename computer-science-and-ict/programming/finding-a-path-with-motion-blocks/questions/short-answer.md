# Finding a Path with Motion Blocks — short answer

Answer in a sentence or two.

**1. Explain, in your own words: plan a whole route with a finger or eye before building any blocks.**
**Answer:** The learner's own explanation, true to the lesson: Finding a path means planning the hero's route first — spelling a word and reaching a goal — then building exactly that route out of motion blocks, and testing it in a dice game of moves.

**2. A classmate gets this lesson's work wrong. What is the most likely fault, and how is it fixed?**
**Answer:** Hero misses the goal → walk the path with a finger and mark the exact corner where finger and hero part ways; only the blocks after that mark need changing.
