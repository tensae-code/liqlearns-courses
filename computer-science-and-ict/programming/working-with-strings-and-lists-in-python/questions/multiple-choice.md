# Working with Strings and Lists in Python — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) How is a string's length counted in Python?**
a) With len  b) Cuts out a run of characters by their positions  c) By concatenation — building a longer string from parts  d) From zero
**Answer: a) With len**

**2. (Sub lesson 1) What does a slice do?**
a) By concatenation — building a longer string from parts  b) Cuts out a run of characters by their positions  c) From zero  d) No — every operation returns a new string, which must be kept
**Answer: b) Cuts out a run of characters by their positions**

**3. (Sub lesson 1) How are two strings joined?**
a) From zero  b) No — every operation returns a new string, which must be kept  c) By concatenation — building a longer string from parts  d) In place — items appended, inserted and removed
**Answer: c) By concatenation — building a longer string from parts**

**4. (Sub lesson 1) From what number do positions count?**
a) No — every operation returns a new string, which must be kept  b) In place — items appended, inserted and removed  c) Sorting and reversing  d) From zero
**Answer: d) From zero**

**5. (Sub lesson 1) Can an operation change a string itself?**
a) No — every operation returns a new string, which must be kept  b) In place — items appended, inserted and removed  c) Sorting and reversing  d) Whether an item is in the list, and at which index it stands
**Answer: a) No — every operation returns a new string, which must be kept**

**6. (Sub lesson 2) How can a list be changed?**
a) Sorting and reversing  b) In place — items appended, inserted and removed  c) Whether an item is in the list, and at which index it stands  d) The list shrinks under the loop, so the next item slides into the skipped place
**Answer: b) In place — items appended, inserted and removed**

**7. (Sub lesson 2) Name two whole-list operations**
a) Whether an item is in the list, and at which index it stands  b) The list shrinks under the loop, so the next item slides into the skipped place  c) Sorting and reversing  d) Python treats them as cousins — both sequences, counted, sliced and looped the same way
**Answer: c) Sorting and reversing**

**8. (Sub lesson 2) What two finding questions does a list answer?**
a) The list shrinks under the loop, so the next item slides into the skipped place  b) Python treats them as cousins — both sequences, counted, sliced and looped the same way  c) With len  d) Whether an item is in the list, and at which index it stands
**Answer: d) Whether an item is in the list, and at which index it stands**

**9. (Sub lesson 2) Why does removing while looping skip items?**
a) The list shrinks under the loop, so the next item slides into the skipped place  b) Python treats them as cousins — both sequences, counted, sliced and looped the same way  c) With len  d) Cuts out a run of characters by their positions
**Answer: a) The list shrinks under the loop, so the next item slides into the skipped place**

**10. (Sub lesson 2) Why does Egypt pair strings and lists in one lesson?**
a) With len  b) Python treats them as cousins — both sequences, counted, sliced and looped the same way  c) Cuts out a run of characters by their positions  d) By concatenation — building a longer string from parts
**Answer: b) Python treats them as cousins — both sequences, counted, sliced and looped the same way**
