# Working with Strings and Lists in Python — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) How is a string's length counted in Python?**
**Answer: With len**

**2. (Sub lesson 1) What does a slice do?**
**Answer: Cuts out a run of characters by their positions**

**3. (Sub lesson 1) How are two strings joined?**
**Answer: By concatenation — building a longer string from parts**

**4. (Sub lesson 1) From what number do positions count?**
**Answer: From zero**

**5. (Sub lesson 1) Can an operation change a string itself?**
**Answer: No — every operation returns a new string, which must be kept**

**6. (Sub lesson 2) How can a list be changed?**
**Answer: In place — items appended, inserted and removed**

**7. (Sub lesson 2) Name two whole-list operations**
**Answer: Sorting and reversing**

**8. (Sub lesson 2) What two finding questions does a list answer?**
**Answer: Whether an item is in the list, and at which index it stands**

**9. (Sub lesson 2) Why does removing while looping skip items?**
**Answer: The list shrinks under the loop, so the next item slides into the skipped place**

**10. (Sub lesson 2) Why does Egypt pair strings and lists in one lesson?**
**Answer: Python treats them as cousins — both sequences, counted, sliced and looped the same way**
