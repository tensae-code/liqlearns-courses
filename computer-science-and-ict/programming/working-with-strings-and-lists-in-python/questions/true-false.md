# Working with Strings and Lists in Python — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "How is a string's length counted in Python?" is: With len**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does a slice do?" is: By concatenation — building a longer string from parts**
**Answer: False** — Cuts out a run of characters by their positions

**3. (Sub lesson 1) True or false: the answer to "How are two strings joined?" is: By concatenation — building a longer string from parts**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "From what number do positions count?" is: No — every operation returns a new string, which must be kept**
**Answer: False** — From zero

**5. (Sub lesson 1) True or false: the answer to "Can an operation change a string itself?" is: No — every operation returns a new string, which must be kept**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How can a list be changed?" is: Sorting and reversing**
**Answer: False** — In place — items appended, inserted and removed

**7. (Sub lesson 2) True or false: the answer to "Name two whole-list operations?" is: Sorting and reversing**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What two finding questions does a list answer?" is: The list shrinks under the loop, so the next item slides into the skipped place**
**Answer: False** — Whether an item is in the list, and at which index it stands

**9. (Sub lesson 2) True or false: the answer to "Why does removing while looping skip items?" is: The list shrinks under the loop, so the next item slides into the skipped place**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why does Egypt pair strings and lists in one lesson?" is: With len**
**Answer: False** — Python treats them as cousins — both sequences, counted, sliced and looped the same way
