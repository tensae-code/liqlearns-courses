# Sets and Venn Diagrams in Computing — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a set?**
a) A collection of distinct things — its members — where order does not matter and nothing appears twice  b) Himpunan  c) A search result, and a list with duplicates removed  d) Its members inside braces
**Answer: a**

**2. (Sub lesson 1) What is the Indonesian word?**
a) Himpunan  b) A search result, and a list with duplicates removed  c) Its members inside braces  d) Overlapping circles
**Answer: a**

**3. (Sub lesson 1) Name two sets a program thinks in.**
a) A search result, and a list with duplicates removed  b) Its members inside braces  c) Overlapping circles  d) The overlap — members in both sets
**Answer: a**

**4. (Sub lesson 1) How is a set written when listed?**

**5. (Sub lesson 1) What does a Venn diagram draw sets as?**
