# Hands-on — Strings in C — Character Arrays and the Null Character

The lesson with your hands and your feet, not only your eyes.

## Task one
**Draw the table** — Draw the storage table for your own first name as a C string: rooms, letters, indices, and the terminator in its room.

## Task two
**Size the arrays** — For five given words, state the smallest char array that holds each as a true C string — and the fault that follows from one room less.
