**3. (Sub lesson 1) What builds the row when a literal is declared?** → **The compiler**

**6. (Sub lesson 2) What ends every C string?** → **The null character '\0'**

**8. (Sub lesson 2) How many rooms does 'Bangla' occupy?** → **Seven — six letters and the terminator**

**9. (Sub lesson 2) What happens when functions read a string with no terminator?** → **They march past its end into foreign memory**
