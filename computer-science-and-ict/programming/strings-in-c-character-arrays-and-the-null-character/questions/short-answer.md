# Strings in C — Character Arrays and the Null Character — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a string in C?**
**Answer: An array of char**

**2. (Sub lesson 1) Where does 'B' of 'Bangla' live?**
**Answer: In room 0**

**3. (Sub lesson 1) What builds the row when a literal is declared?**
**Answer: The compiler**

**4. (Sub lesson 1) What does each room hold?**
**Answer: One character**

**5. (Sub lesson 1) By what are the rooms reached?**
**Answer: The array's indexing**

**6. (Sub lesson 2) What ends every C string?**
**Answer: The null character '\0'**

**7. (Sub lesson 2) What is the null character's code?**
**Answer: Zero**

**8. (Sub lesson 2) How many rooms does 'Bangla' occupy?**
**Answer: Seven — six letters and the terminator**

**9. (Sub lesson 2) What happens when functions read a string with no terminator?**
**Answer: They march past its end into foreign memory**

**10. (Sub lesson 2) What is the sizing rule?**
**Answer: Letters + 1 — always size for the terminator**
