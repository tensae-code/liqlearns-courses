# Strings in C — Character Arrays and the Null Character — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a string in C?**
a) An array of char  b) In room 0  c) The compiler  d) One character
**Answer: a**

**2. (Sub lesson 1) Where does 'B' of 'Bangla' live?**
a) In room 0  b) The compiler  c) One character  d) The array's indexing
**Answer: a**

**3. (Sub lesson 1) What builds the row when a literal is declared?**
a) The compiler  b) One character  c) The array's indexing  d) The null character '\0'
**Answer: a**

**4. (Sub lesson 1) What does each room hold?**
a) One character  b) The array's indexing  c) The null character '\0'  d) Zero
**Answer: a**

**5. (Sub lesson 1) By what are the rooms reached?**
a) The array's indexing  b) The null character '\0'  c) Zero  d) Seven — six letters and the terminator
**Answer: a**
