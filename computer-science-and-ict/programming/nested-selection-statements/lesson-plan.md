**The one thing this lesson teaches:** A nested selection statement is a selection statement placed inside another selection statement — an if inside an if. ## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **A selection inside a selection** — A **nested selection statement** is a **selection statement placed inside another selection statement** — an if inside an if. The inner selection is only reached when the **outer condition** has already been decided, so the program asks its questions in order: first the outer one, then, only if the path leads there, the inner one.
2. **Working through nested selection** — Reading a nested selection means following **one path at a time**: fix the outer condition true or false, then meet the inner selection only on the branch that contains it. Nesting lets a program handle **cases inside cases** — the book's name for the structure is the **Nested Selection Structure** — without repeating the outer test on every line.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
