# Nested Selection Statements — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a nested selection statement?**
a) A selection statement placed inside another selection statement  b) An if inside an if  c) First the outer condition, then the inner one  d) Cases inside cases
**Answer: a) A selection statement placed inside another selection statement**

**2. (Sub lesson 1) In short, what is nesting here?**
a) Only when the outer condition's path leads there  b) An if inside an if  c) By following one path at a time  d) The Nested Selection Structure
**Answer: b) An if inside an if**

**3. (Sub lesson 1) When is the inner selection reached?**
a) First the outer condition, then the inner one  b) Cases inside cases  c) Only when the outer condition's path leads there  d) The outer test on every line
**Answer: c) Only when the outer condition's path leads there**

**4. (Sub lesson 1) In what order does the program ask its questions?**
a) By following one path at a time  b) The Nested Selection Structure  c) Selection statements — if, and if-else  d) First the outer condition, then the inner one
**Answer: d) First the outer condition, then the inner one**

**5. (Sub lesson 1) How do you read a nested selection?**
a) By following one path at a time  b) Cases inside cases  c) The outer test on every line  d) Grade 8
**Answer: a) By following one path at a time**

**6. (Sub lesson 2) What does nesting let a program handle?**
a) The Nested Selection Structure  b) Cases inside cases  c) Selection statements — if, and if-else  d) A selection statement placed inside another selection statement
**Answer: b) Cases inside cases**

**7. (Sub lesson 2) What is the book's name for the structure?**
a) The outer test on every line  b) Grade 8  c) The Nested Selection Structure  d) An if inside an if
**Answer: c) The Nested Selection Structure**

**8. (Sub lesson 2) What does nesting avoid repeating?**
a) Selection statements — if, and if-else  b) A selection statement placed inside another selection statement  c) Only when the outer condition's path leads there  d) The outer test on every line
**Answer: d) The outer test on every line**

**9. (Sub lesson 2) Which earlier statements does nesting build on?**
a) Selection statements — if, and if-else  b) Grade 8  c) An if inside an if  d) First the outer condition, then the inner one
**Answer: a) Selection statements — if, and if-else**

**10. (Sub lesson 2) Which grade's book teaches nested selection?**
a) A selection statement placed inside another selection statement  b) Grade 8  c) Only when the outer condition's path leads there  d) By following one path at a time
**Answer: b) Grade 8**
