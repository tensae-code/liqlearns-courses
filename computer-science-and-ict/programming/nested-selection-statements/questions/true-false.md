# Nested Selection Statements — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a nested selection statement?" is: A selection statement placed inside another selection statement**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "In short, what is nesting here?" is: First the outer condition, then the inner one**
**Answer: False** — An if inside an if

**3. (Sub lesson 1) True or false: the answer to "When is the inner selection reached?" is: Only when the outer condition's path leads there**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "In what order does the program ask its questions?" is: Cases inside cases**
**Answer: False** — First the outer condition, then the inner one

**5. (Sub lesson 1) True or false: the answer to "How do you read a nested selection?" is: By following one path at a time**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does nesting let a program handle?" is: The outer test on every line**
**Answer: False** — Cases inside cases

**7. (Sub lesson 2) True or false: the answer to "What is the book's name for the structure?" is: The Nested Selection Structure**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does nesting avoid repeating?" is: Grade 8**
**Answer: False** — The outer test on every line

**9. (Sub lesson 2) True or false: the answer to "Which earlier statements does nesting build on?" is: Selection statements — if, and if-else**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Which grade's book teaches nested selection?" is: An if inside an if**
**Answer: False** — Grade 8
