# Nested Selection Statements — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a nested selection statement?**
**Answer: A selection statement placed inside another selection statement**

**2. (Sub lesson 1) In short, what is nesting here?**
**Answer: An if inside an if**

**3. (Sub lesson 1) When is the inner selection reached?**
**Answer: Only when the outer condition's path leads there**

**4. (Sub lesson 1) In what order does the program ask its questions?**
**Answer: First the outer condition, then the inner one**

**5. (Sub lesson 1) How do you read a nested selection?**
**Answer: By following one path at a time**

**6. (Sub lesson 2) What does nesting let a program handle?**
**Answer: Cases inside cases**

**7. (Sub lesson 2) What is the book's name for the structure?**
**Answer: The Nested Selection Structure**

**8. (Sub lesson 2) What does nesting avoid repeating?**
**Answer: The outer test on every line**

**9. (Sub lesson 2) Which earlier statements does nesting build on?**
**Answer: Selection statements — if, and if-else**

**10. (Sub lesson 2) Which grade's book teaches nested selection?**
**Answer: Grade 8**
