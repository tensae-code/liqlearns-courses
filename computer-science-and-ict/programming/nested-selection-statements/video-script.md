# Video script — Nested Selection Statements

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A **nested selection statement** is a **selection statement placed inside another selection statement** — an if inside an if. The inner selection is only reached when the **outer condition** has already been decided, so the program asks its questions in order: first the outer one, then, only if the path leads there, the inner one.
Reading a nested selection means following **one path at a time**: fix the outer condition true or false, then meet the inner selection only on the branch that contains it. Nesting lets a program handle **cases inside cases** — the book's name for the structure is the **Nested Selection Structure** — without repeating the outer test on every line.
