# Doing My Own Work — With a Computer's Help — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — My work — the jobs of my day
Sub lesson 1 questions from the type files. Pass mark: The pupil's own work — the jobs of their own day; The jobs — what I do, in what order; The parts that are hard, slow, or easy to get wrong; Because before a school subject, the computer is a helper beside a real child's real work; Learning lessons, doing homework, drawing (any real jobs of the pupil's day).

Sub lesson 2 questions from the type files. Pass mark: Holding and searching information, showing and playing, practising with you, keeping work safe; Understand for you, decide for you, or do the learning itself; Chooses one job, works it with the computer's help, and shows before and after; The work stays mine — the computer carries the parts it is good at; The hard, slow or error-prone parts it is good at — not the learning itself.
