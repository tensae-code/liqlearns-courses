# Doing My Own Work — With a Computer's Help — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The pupil's own work — the jobs of their own day**
**Answer: True**

**2. (Sub lesson 1) True or false: The pupil's own work — the jobs of their own day** — as the answer to: What is listed first?
**Answer: False — The jobs — what I do, in what order**

**3. (Sub lesson 1) True or false: The parts that are hard, slow, or easy to get wrong**
**Answer: True**

**4. (Sub lesson 1) True or false: The parts that are hard, slow, or easy to get wrong** — as the answer to: Why does the first book end with this project?
**Answer: False — Because before a school subject, the computer is a helper beside a real child's real work**

**5. (Sub lesson 1) True or false: Learning lessons, doing homework, drawing (any real jobs of the pupil's day)**
**Answer: True**

**6. (Sub lesson 2) True or false: Learning lessons, doing homework, drawing (any real jobs of the pupil's day)** — as the answer to: What can a computer help with?
**Answer: False — Holding and searching information, showing and playing, practising with you, keeping work safe**

**7. (Sub lesson 2) True or false: Understand for you, decide for you, or do the learning itself**
**Answer: True**

**8. (Sub lesson 2) True or false: Understand for you, decide for you, or do the learning itself** — as the answer to: What does each pupil do in the project?
**Answer: False — Chooses one job, works it with the computer's help, and shows before and after**

**9. (Sub lesson 2) True or false: The work stays mine — the computer carries the parts it is good at**
**Answer: True**

**10. (Sub lesson 2) True or false: The work stays mine — the computer carries the parts it is good at** — as the answer to: Which parts should the computer carry?
**Answer: False — The hard, slow or error-prone parts it is good at — not the learning itself**
