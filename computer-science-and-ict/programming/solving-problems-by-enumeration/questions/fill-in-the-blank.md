# Solving Problems by Enumeration — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 1) The mesh of the sieve in this lesson stands for the problem's ____, testing every candidate.**
**Answer: conditions** — Candidates that satisfy all of them are kept.

**2. (Sub lesson 2) Enumeration's great limit is that the candidate list can ____ in size.**
**Answer: explode** — Ten digits is minutes; a long password is more than a lifetime.

**3. (Sub lesson 1) Generate candidates in ____ order so none is repeated or skipped.**
**Answer: counting** — Order is the guarantee, not decoration.
