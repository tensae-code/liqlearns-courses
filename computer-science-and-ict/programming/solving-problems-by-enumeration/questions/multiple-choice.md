# Solving Problems by Enumeration — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Enumeration solves a problem by —**
a) deriving a formula  b) listing every candidate and testing each against the conditions  c) guessing once, luckily  d) asking a bigger computer
**Answer: b) listing every candidate and testing each against the conditions** — Generate, test, collect.

**2. (Sub lesson 1) The three parts of an enumeration algorithm are —**
a) model, derive, compute  b) generate, test, collect  c) read, write, print  d) start, stop, save
**Answer: b) generate, test, collect** — Every candidate generated, every candidate tested, passers kept.

**3. (Sub lesson 1) Enumeration's certainty comes from —**
a) the formula being right  b) every candidate in the list being tested, so no solution inside it is missed  c) using a fast computer  d) luck
**Answer: b) every candidate in the list being tested, so no solution inside it is missed** — Certainty is the method's beauty.

**4. (Sub lesson 2) Why generate candidates in counting order?**
a) It looks neat  b) So none is repeated and none is skipped  c) It is faster to write  d) Computers demand it
**Answer: b) So none is repeated and none is skipped** — Disorder is how solutions get missed.

**5. (Sub lesson 2) A forgotten six-digit code has how many candidates?**
a) 60  b) 600  c) 1,000,000  d) 6,000
**Answer: c) 1,000,000** — 10 × 10 × 10 × 10 × 10 × 10 — the list explodes.
