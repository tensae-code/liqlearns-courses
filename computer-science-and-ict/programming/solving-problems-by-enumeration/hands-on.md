# Hands-on — Solving Problems by Enumeration

The lesson with your hands and your feet, not only your eyes.

## Enumerate a lock
A school locker code is two digits; you remember the first digit is even and the two digits add to 9. Write the shrunken candidate list in counting order, then test each against both conditions. How many candidates did the conditions save you from the full 100?

## Count before you search
For each: a 3-digit code, a 4-letter password from 26 letters, a 6-digit code — write the size of the candidate list. Beside each, write 'fine to enumerate' or 'explodes', and why.
