# The Alphabet, Vocabulary and Keywords of Pascal and C++ — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The set of characters its texts may use — letters, digits and special symbols**
**Answer: True**

**2. (Sub lesson 1) True or false: The set of characters its texts may use — letters, digits and special symbols** — as the answer to: Name symbols C++ has that Pascal lacks.
**Answer: False — #, %, &, |, ~ — for C++'s own operations**

**3. (Sub lesson 1) True or false: Separators and blanks**
**Answer: True**

**4. (Sub lesson 1) True or false: Separators and blanks** — as the answer to: May a character outside the alphabet appear?
**Answer: False — No — it is the compiler's first and simplest error**

**5. (Sub lesson 1) True or false: The Latin letters, the digits, and the common special symbols**
**Answer: True**

**6. (Sub lesson 2) True or false: The Latin letters, the digits, and the common special symbols** — as the answer to: What are keywords?
**Answer: False — Reserved words with a fixed meaning in the language, unusable as identifiers**

**7. (Sub lesson 2) True or false: program, begin, end (also: var, if, while)**
**Answer: True**

**8. (Sub lesson 2) True or false: program, begin, end (also: var, if, while)** — as the answer to: Name three C++ keywords.
**Answer: False — int, return, if (also: while, class)**

**9. (Sub lesson 2) True or false: Dozens, not thousands**
**Answer: True**

**10. (Sub lesson 2) True or false: Dozens, not thousands** — as the answer to: What is the pair's first practical difference?
**Answer: False — Case — Pascal ignores it in keywords; C++ distinguishes Main from main**
