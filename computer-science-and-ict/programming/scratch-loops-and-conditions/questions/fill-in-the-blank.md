# Scratch loops and conditions — fill

Fill each blank with the right word or words.

**1. (Sub lesson 1)** _____ is if the sprite touches the rightmost edge, set its x position to −100; otherwise move 10 steps right. (Name the term.)
**Answer: the worked if…else**

**2. (Sub lesson 2)** _____ is built inside a forever loop from 'when key … pressed' sensing blocks for the four arrow keys, each moving the sprite 10 steps. (Name the term.)
**Answer: keyboard control**

**3. (Sub lesson 3)** _____ is a loop that does not know its count in advance — here a count variable set to 0, meowing and adding 1 until count reaches 12 (the book's practical). (Name the term.)
**Answer: repeat until**
