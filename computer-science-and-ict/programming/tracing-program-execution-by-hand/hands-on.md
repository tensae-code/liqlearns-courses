# Hands-on — Tracing Program Execution by Hand

The lesson with your hands and your feet, not only your eyes.

## Task one
**Full trace** — Trace a loop that tests primes (or sums digits) for one input, every iteration in writing, predicting the output before 'running' your trace.

## Task two
**First wrong row** — A partner plants one wrong value in a trace; find the first wrong line and the step that produced it.
