# Tracing Program Execution by Hand — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does tracing follow?**
**Answer: The program's execution, line by line, with real values**

**2. (Sub lesson 1) What is each loop iteration in the trace?**
**Answer: A fresh line — the variable's biography grows**

**3. (Sub lesson 1) Name the guide's two traced programs.**
**Answer: The prime-number program and the task-manager program**

**4. (Sub lesson 1) Why is a loop's effect invisible in code alone?**
**Answer: The same line works ten times with ten different values**

**5. (Sub lesson 1) What must each assignment do in a trace?**
**Answer: Update the traced value in writing**

**6. (Sub lesson 2) Name tracing's three uses.**
**Answer: Predict output, find the first wrong iteration, teach what the machine does**

**7. (Sub lesson 2) What is hand tracing called in the lesson?**
**Answer: The programmer's X-ray**

**8. (Sub lesson 2) What is a guessed value in a trace?**
**Answer: A forged witness**

**9. (Sub lesson 2) What is the trace's discipline?**
**Answer: No step skipped, no value guessed**

**10. (Sub lesson 2) Why does the guide build tracing into solutions?**
**Answer: So teachers can show, not merely state, why a program answers as it does**
