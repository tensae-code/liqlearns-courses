# Controlling a Virtual Robot's Movement with Variables — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What can movement blocks take their speed from?**
**Answer: A variable, instead of a number typed into each block**

**2. (Sub lesson 1) When is the speed variable set?**
**Answer: Once, before the drive**

**3. (Sub lesson 1) What obeys the speed variable?**
**Answer: Every movement that reads it**

**4. (Sub lesson 1) How do you change the robot's pace everywhere?**
**Answer: Change one value in one place**

**5. (Sub lesson 1) What does the Monitor console show?**
**Answer: The program's variables while it runs**

**6. (Sub lesson 2) What can you watch in the Monitor?**
**Answer: A variable's value changing as blocks assign and use it**

**7. (Sub lesson 2) What does the Monitor make visible?**
**Answer: An invisible thing — the variable's value**

**8. (Sub lesson 2) How does the Monitor help when the robot misbehaves?**
**Answer: The watched values show whether the variable held what you thought**

**9. (Sub lesson 2) Which robot and program is this lesson about?**
**Answer: The virtual robot in VEXcode VR**

**10. (Sub lesson 2) Where is the variable set — in each block, or before?**
**Answer: Before — once**
