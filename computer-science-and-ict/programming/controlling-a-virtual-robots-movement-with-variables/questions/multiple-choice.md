# Controlling a Virtual Robot's Movement with Variables — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What can movement blocks take their speed from?**
a) A variable, instead of a number typed into each block  b) Change one value in one place  c) A variable's value changing as blocks assign and use it  d) The watched values show whether the variable held what you thought

**2. (Sub lesson 1) When is the speed variable set?**
