# Hands-on — Controlling a Virtual Robot's Movement with Variables

The lesson with your hands and your feet, not only your eyes.

## One value, new pace
Drive the virtual robot with a speed variable. Run it, then change only the variable and run again — note every movement obeyed.

## Watch it live
Open the Monitor console and run a program that changes the speed variable mid-drive. Write down the values you saw, in order.
