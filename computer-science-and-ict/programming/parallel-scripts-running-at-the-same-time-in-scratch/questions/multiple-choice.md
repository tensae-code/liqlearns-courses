# Parallel Scripts — Running at the Same Time in Scratch — multiple choice

Pick the one right answer.

**1. Parallel scripts are scripts that —**
a) Run at the same time, started by the same event  b) Never run  c) Run one per day
**Answer: a) Run at the same time, started by the same event** — Same event, same time.

**2. Background music belongs in —**
a) The middle of the action script  b) Its own script started by the same event  c) A backdrop
**Answer: b) Its own script started by the same event** — Its own flag script, running alongside the action.

**3. Inside one script, blocks run —**
a) All at once randomly  b) In order, one after another  c) Backwards
**Answer: b) In order, one after another** — In order — which is why two jobs need two scripts.

**4. Two scripts run in parallel when —**
a) They have the same event starting them  b) They are different colours  c) One is hidden
**Answer: a) They have the same event starting them** — The same event starts both.
