# Parallel Scripts — Running at the Same Time in Scratch — short answer

Answer in a sentence or two.

**1. Why can't one script play a long piece of music and move the sprite at the same time?**
**Answer:** A sound answer: inside one script each block waits for the one before it, so the movement would wait for the whole music block; parallel scripts remove the waiting.

**2. Give one use of parallel scripts besides music.**
**Answer:** Any sound use, e.g. a character walks in one script while its costume animates in another, or an enemy moves while a timer counts down.
