# Parallel Scripts — Running at the Same Time in Scratch — true or false

Say whether each statement is true or false.

**1. The action must wait for the music to finish in a parallel-scripts project.**
**Answer: False** — They run side by side; neither waits.

**2. A sprite can hold more than one script.**
**Answer: True** — That is what makes parallel scripts possible.

**3. Parallel scripts must be on different sprites.**
**Answer: False** — They can be two scripts of the same sprite or project.
