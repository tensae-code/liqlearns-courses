# Visual Basic 2008 — Meeting the IDE — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is Visual Basic 2008 Express Edition?**
**Answer: Microsoft's environment for building Windows programs visually**

**2. (Sub lesson 1) Name two of its advantages, as the book presents them.**
**Answer: The look is built by placing, not describing; results are run and seen at once (also: statements close to English)**

**3. (Sub lesson 1) What is a project?**
**Answer: The whole application's kept form — begun new or opened existing**

**4. (Sub lesson 1) Name the screen's windows taught here.**
**Answer: The form designer, the toolbox, the solution's file list, and the Properties window**

**5. (Sub lesson 1) What does the Properties window do?**
**Answer: Shows and edits the selected object's properties**

**6. (Sub lesson 2) Where is the program drawn?**
**Answer: The form designer**

**7. (Sub lesson 2) Why does the course spend a chapter on the meeting?**
**Answer: A programmer who can name the windows can follow every later instruction**

**8. (Sub lesson 2) What two acts open any VB working session?**
**Answer: Start Visual Basic; open (or begin) the project**

**9. (Sub lesson 2) Which edition does the book use?**
**Answer: Visual Basic 2008 Express Edition**

**10. (Sub lesson 2) Which book teaches this?**
**Answer: Kuwait Grade 12 Information Technology Term 1, Part 1 Book 1 Chapter 2**
