## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Visual Basic 2008 — what it is, and its advantages** — **Visual Basic 2008 Express Edition** is Microsoft's environment for building **Windows programs visually**: the form is drawn, the controls are placed, and event code is written in Basic — the course's language since its first concepts chapter. Its **advantages**, as the book presents them, are the school-programmer's: a program's look is built by **placing**, not by describing; results are **run and seen** at once; and the language's statements stay close to the English of the problems they solve.
2. **Starting, opening a project, and the windows** — The working acts are the chapter's craft: **start** Visual Basic; **open a project** — a new one begun or an existing one brought back, the project being the whole application's kept form; and read the screen's **windows**: the form designer where the program is drawn, the toolbox of controls, the solution's file list, and the **Properties window** — the panel that shows and edits the **selected object's properties**, the place the next chapter's property craft will live. A programmer who can name the windows can follow every instruction the book gives after this chapter.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
