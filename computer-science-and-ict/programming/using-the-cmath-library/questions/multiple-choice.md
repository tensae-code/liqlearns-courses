# Using the cmath Library — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What makes cmath functions available?**
a) #include <cmath> at the top  b) 9  c) Stored, printed, or inside a bigger expression  d) Decimal (double) values

**2. (Sub lesson 1) What is sqrt(81)?**
a) Stored, printed, or inside a bigger expression  b) 9  c) Decimal (double) values  d) No — it comes from the library
