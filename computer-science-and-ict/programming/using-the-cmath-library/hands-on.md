# Hands-on — Using the cmath Library

The lesson with your hands and your feet, not only your eyes.

## Toolbox tour
Write a program that asks for one number and prints its square root, its square (via pow), its absolute value and its floor and ceil. Test it on 2.5 and on −7.25.

## Right tool, one line each
Write the single cmath call for: the hypotenuse from legs a and b; 2 to the power 10; the distance of −42 from zero. Check each result by hand or calculator.
