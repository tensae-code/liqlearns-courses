# Lesson plan - Machine language and assembly language

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** Machine language and assembly language
**Place in the curriculum:** Unit 6 - Fundamentals of Programming (CURRICULUM.md).
**The one thing this lesson teaches:** a program is a set of instructions in a programming language; machine language is binary the computer understands directly, and assembly language uses mnemonics that an assembler must translate.
**This lesson's own level:** it stands on it stands on nothing but the idea of a computer following instructions. It is the first lesson of Unit 6, Fundamentals of Programming.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on - an image, a GIF, a video, an audio. ## Sub lessons
The parts of this lesson, in order - the list the learner sees from the start, locked ahead, each opening when the one before it is proved (the gate: README, "Units, Lessons and Sub Lessons (ruled 2026-11-08)"):

1. **Machine language - binary the computer understands** - What a program is; machine language writes instructions, numbers and memory locations in binary 1s and 0s; it is the only language the computer understands directly, so it is very fast and memory-efficient, but very hard to write.
2. **Assembly language and the assembler** - Assembly replaces binary with symbols called mnemonics - easier, still difficult; it is not understood directly, so an Assembler program translates it into machine language.

Gate pool: all questions of the sub lesson - no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: None needed - this lesson opens the unit. The next door is High-level languages - compilers and interpreters.

## What the learner can do when it ends
1. Say what a program and a programming language are.
2. Say what machine language is written in, and why it is fast but hard to write.
3. Say what mnemonics are, and why assembly language still needs an assembler.
4. Name the program that translates assembly language into machine language.

## If the learner is stuck
- Thinks assembly runs directly -> only machine language is understood directly; assembly always passes through the assembler first.
- Mixes up fast and easy -> machine language is fast for the computer and hard for the person; both halves travel together.
