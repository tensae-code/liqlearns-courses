# Video script - Machine language and assembly language

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.
A short video script for this lesson; its placement names no full-script need.

---

A program tells a computer what to do.

The first language is machine language.
Only ones and zeros. Binary.
The computer understands it directly. Fast!
But very, very hard for people to write.

So people made assembly language.
Symbols instead of binary. Mnemonics.
Easier - but still hard.
And the computer cannot run it directly.

An assembler translates it into machine language.
Then the computer can run it.
