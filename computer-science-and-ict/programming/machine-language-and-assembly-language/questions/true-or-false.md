# Machine language and assembly language - true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Machine language is the only language the computer understands directly.
**Answer: True** - that is why it needs no translation.

**2. (Sub lesson 2)** The computer can run assembly language with no translation at all.
**Answer: False** - an Assembler must translate it into machine language first.

**3. (Sub lesson 2)** Assembly language is easier to write than machine language.
**Answer: True** - mnemonics replace raw binary - though it stays difficult.
