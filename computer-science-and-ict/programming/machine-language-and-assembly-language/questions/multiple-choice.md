# Machine language and assembly language - multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A program is -
a) a set of instructions telling a computer what to do  b) a part inside the computer  c) a list of student names  d) the computer's power cable
**Answer: a) a set of instructions telling a computer what to do** - it is instructions, written in a programming language.

**2. (Sub lesson 1)** Machine language is written in -
a) English words  b) binary - 1s and 0s  c) pictures  d) mnemonics
**Answer: b) binary - 1s and 0s** - everything - instructions, numbers, memory locations - is binary.

**3. (Sub lesson 1)** Machine language is very fast because -
a) it uses short words  b) the computer understands it directly, with no translation  c) it is written by experts  d) it uses little paper
**Answer: b) the computer understands it directly, with no translation** - no translator stands between it and the computer.

**4. (Sub lesson 1)** The hard side of machine language is that it is -
a) slow  b) very hard to write  c) not understood by the computer  d) too colourful
**Answer: b) very hard to write** - a person must think in strings of 1s and 0s.

**5. (Sub lesson 2)** Mnemonics are -
a) binary numbers  b) symbols used in assembly language instead of binary  c) error messages  d) memory locations
**Answer: b) symbols used in assembly language instead of binary** - short word-like codes standing for operations.

**6. (Sub lesson 2)** Assembly language compared with machine language is -
a) harder  b) easier, but still difficult  c) understood directly  d) slower to translate
**Answer: b) easier, but still difficult** - symbols help people, but the work is still difficult.

**7. (Sub lesson 2)** The program that translates assembly language into machine language is -
a) a compiler  b) an interpreter  c) an Assembler  d) a browser
**Answer: c) an Assembler** - the Assembler does this one translation job.

**8. (Sub lesson 2)** Before the computer can run an assembly program, it must -
a) be printed  b) be translated into machine language by an Assembler  c) be saved as .py  d) be read aloud
**Answer: b) be translated into machine language by an Assembler** - the computer understands machine language directly - nothing else.
