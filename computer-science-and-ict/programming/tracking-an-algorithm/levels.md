# Tracking an Algorithm — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — What tracking is
Sub lesson 1 questions from the type files. Pass mark: Working through it step by step with chosen values, recording the state; A row per step, a column per variable; Honestly — no skipping, every step's arithmetic done and written; Algorithms, before a computer is touched; The row where the table first goes wrong.

## Sub lesson 2 — Tracking loops and conditions
Sub lesson 2 questions from the type files. Pass mark: A row per turn, until the condition fails; The counter and the accumulator; By marking the branch taken at each meeting; The loop's whole story at a glance; The writer composes steps the tracker can follow; the tracker reads steps the writer answers for.
