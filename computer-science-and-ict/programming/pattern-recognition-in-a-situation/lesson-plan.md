## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Looking for what repeats** — **Pattern recognition** (pengecaman corak) means examining a situation for **repeating shapes**: things that happen again and again, quantities that grow by the same step, arrangements with the same structure. In Malaysia's popia example, every wrap is the same motions with a different filling spoonful — the repetition is the pattern. The hunt has a discipline: name what repeats in words, then test the name against every case you have — a pattern that fails one case is a guess, not a pattern.
2. **Using the pattern — solve once, apply many times** — A found pattern **pays**: the repeated part needs solving **once**, and that one solution is then **applied** to every case the pattern covers. Patterns also predict — if wraps take the same time each, ten wraps take ten times one wrap. Malaysia keeps the caution with the gain: what **changes** between cases must be named too, because the changing part is exactly where the one solution must be fed different values.
