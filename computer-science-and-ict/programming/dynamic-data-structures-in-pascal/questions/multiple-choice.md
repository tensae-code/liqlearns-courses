# Dynamic Data Structures in Pascal — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does a pointer hold?**
a) The address of a value in memory, not the value  b) new reserves a fresh cell and points at it; dispose frees the cell  c) The value at the pointer's address — the dereferenced pointer  d) The pointer that points nowhere — the honest empty
**Answer: a**

**2. (Sub lesson 1) What do new and dispose do?**
a) new reserves a fresh cell and points at it; dispose frees the cell  b) The value at the pointer's address — the dereferenced pointer  c) The pointer that points nowhere — the honest empty  d) Only through its pointer — it has no name of its own
**Answer: a**

**3. (Sub lesson 1) What does p^ name?**
a) The value at the pointer's address — the dereferenced pointer  b) The pointer that points nowhere — the honest empty  c) Only through its pointer — it has no name of its own  d) A record holding a value and a pointer to the next node
**Answer: a**

**4. (Sub lesson 1) What is nil?**
a) The pointer that points nowhere — the honest empty  b) Only through its pointer — it has no name of its own  c) A record holding a value and a pointer to the next node  d) By new for an inserted node, by dispose for a removed one
**Answer: a**

**5. (Sub lesson 1) How is a new-made variable reached?**
a) Only through its pointer — it has no name of its own  b) A record holding a value and a pointer to the next node  c) By new for an inserted node, by dispose for a removed one  d) Fit its memory exactly to its data at run time — neither wasting nor overflowing a declared size
**Answer: a**

**6. (Sub lesson 2) What is a linked list node?**
a) A record holding a value and a pointer to the next node  b) By new for an inserted node, by dispose for a removed one  c) Fit its memory exactly to its data at run time — neither wasting nor overflowing a declared size  d) No index — the fifth node is reached by walking four links
**Answer: a**

**7. (Sub lesson 2) How does a list grow and shrink?**
a) By new for an inserted node, by dispose for a removed one  b) Fit its memory exactly to its data at run time — neither wasting nor overflowing a declared size  c) No index — the fifth node is reached by walking four links  d) Leaking (a lost pointer keeps its cell forever) and following a disposed pointer (a crash)
**Answer: a**

**8. (Sub lesson 2) What can an array not do that a list can?**
a) Fit its memory exactly to its data at run time — neither wasting nor overflowing a declared size  b) No index — the fifth node is reached by walking four links  c) Leaking (a lost pointer keeps its cell forever) and following a disposed pointer (a crash)  d) The address of a value in memory, not the value
**Answer: a**

**9. (Sub lesson 2) What is a list's price in access?**
a) No index — the fifth node is reached by walking four links  b) Leaking (a lost pointer keeps its cell forever) and following a disposed pointer (a crash)  c) The address of a value in memory, not the value  d) new reserves a fresh cell and points at it; dispose frees the cell
**Answer: a**

a) Leaking (a lost pointer keeps its cell forever) and following a disposed pointer (a crash)  b) The address of a value in memory, not the value  c) new reserves a fresh cell and points at it; dispose frees the cell  d) The value at the pointer's address — the dereferenced pointer
