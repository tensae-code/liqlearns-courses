# Dynamic Data Structures in Pascal — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Pointers — variables that hold addresses
Sub lesson 1 questions from the type files. Pass mark: The address of a value in memory, not the value; new reserves a fresh cell and points at it; dispose frees the cell; The value at the pointer's address — the dereferenced pointer; The pointer that points nowhere — the honest empty; Only through its pointer — it has no name of its own.

## Sub lesson 2 — Linked lists — structure built at run time
Sub lesson 2 questions from the type files. Pass mark: A record holding a value and a pointer to the next node; By new for an inserted node, by dispose for a removed one; Fit its memory exactly to its data at run time — neither wasting nor overflowing a declared size; No index — the fifth node is reached by walking four links; Leaking (a lost pointer keeps its cell forever) and following a disposed pointer (a crash).
