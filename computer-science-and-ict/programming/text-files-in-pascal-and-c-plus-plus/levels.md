## Sub lesson 1 — A file of characters and lines
Sub lesson 1 questions from the type files. Pass mark: Characters, organised into lines ended by an end-of-line mark; As a variable of type text; By naming it first — writeln(f, x) writes to f; As their printed characters, not their binary values; Any editor and any program can read characters.

## Sub lesson 2 — Ends of things — eof and eoln
Sub lesson 2 questions from the type files. Pass mark: eof: the end of the file; eoln: the end of the current line; while not eof(f) do — readln(f, line), process, repeat; eof becomes true after the last line; Reading past the end, and numbers misread when spaces are handled wrongly; close — after the last writeln.
