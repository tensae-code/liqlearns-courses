# Text Files in Pascal and C++ — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Characters, organised into lines ended by an end-of-line mark**
**Answer: True**

**2. (Sub lesson 1) True or false: Characters, organised into lines ended by an end-of-line mark** — as the answer to: How is a text file declared in Pascal?
**Answer: False — As a variable of type text**

**3. (Sub lesson 1) True or false: By naming it first — writeln(f, x) writes to f**
**Answer: True**

**4. (Sub lesson 1) True or false: By naming it first — writeln(f, x) writes to f** — as the answer to: How are numbers stored in a text file?
**Answer: False — As their printed characters, not their binary values**

**5. (Sub lesson 1) True or false: Any editor and any program can read characters**
**Answer: True**

**6. (Sub lesson 2) True or false: Any editor and any program can read characters** — as the answer to: What do eof and eoln test?
**Answer: False — eof: the end of the file; eoln: the end of the current line**

**7. (Sub lesson 2) True or false: while not eof(f) do — readln(f, line), process, repeat**
**Answer: True**

**8. (Sub lesson 2) True or false: while not eof(f) do — readln(f, line), process, repeat** — as the answer to: What stops the loop exactly right?
**Answer: False — eof becomes true after the last line**

**9. (Sub lesson 2) True or false: Reading past the end, and numbers misread when spaces are handled wrongly**
**Answer: True**

**10. (Sub lesson 2) True or false: Reading past the end, and numbers misread when spaces are handled wrongly** — as the answer to: What seals a written file?
**Answer: False — close — after the last writeln**
