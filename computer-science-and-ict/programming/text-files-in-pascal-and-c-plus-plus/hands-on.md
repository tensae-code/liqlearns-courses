# Hands-on — Text Files in Pascal and C++

The lesson with your hands and your feet, not only your eyes.

## Task one
**Notebook build** — Write the Pascal that creates a text file of five names (one per line) and the second program that reads it back and numbers the lines.

## Task two
**Loop audit** — Take a reading loop that crashes on an empty file and repair it using eof correctly; state what the empty file does to each version.
