It sits in the Programming title (programming/), where the placements file placed it. It is one whole lesson with no sub lessons — a small Grade 2 lesson running straight through.

Azerbaijan's own way: informatics starts two full years before touching a computer — objects and their features, information in everyday life, and algorithms as daily-life sequences and true/false judgements; the computer itself, WordPad, Paint and Calculator arrive only in the final unit. This lesson keeps that order and that Grade 2 voice.

Malaysia's own way (Grade 10, SK Tingkatan 4): the upper-secondary Sains Komputer (SK — Computer Science) elective switches language to Java (NetBeans) and is organised as three big project-style chapters — Programming, Relational Databases (Access, ERD, normalisation to 3NF, macros/switchboard, a full SDLC database project), and Human-Computer Interaction with screen-design prototyping and quantitative evaluation (prototypes built in Java NetBeans).
