## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Reading before changing** — The séance's title is its ethic: **“Ce n'est pas moi qui l'ai fait, mais je peux le modifier”** — ‘It wasn't me who made it, but I can modify it.’ **Remixing** starts with **reading**: run the program, predict each script's job, name the parts (initialisation, movement, scoring) before touching anything. A change made without a map is vandalism with good intentions; the same change, mapped, is engineering.
2. **Change one thing, keep the rest alive** — The remix discipline is surgical: choose **one behaviour** to change, find the **smallest set of blocks** that owns it, change, and **retest everything** — the new behaviour, and every old one you promised to keep. Credit travels with the work: a remix names its original (‘after X's program’), because programs, like stories, have authors — and the remix culture Scratch is built on runs on that honesty.

## The run of the lesson (in order)
1. **Do it first** — A stranger's program lands in front of you: it works, it is clever, it is not yours. Your job: make it do one new thing without breaking the old. Before reading on, say your first move — and why it is not ‘start deleting blocks’. (lesson/lesson.md).
2. **The explanation** — the lesson text in lesson/lesson.md, in its parts in order.
   - ADD IMAGE: a picture of reading before changing as the lesson describes it — the student studies the picture and names what each part shows.
   - ADD GIF: a GIF of change one thing, keep the rest alive in action — the student watches once, then says what changed and why.
   - ADD AUDIO: a voice reading the lesson's key names and definitions aloud, in the order the lesson gives them — the student listens once through, then reads the same lines aloud along with the voice. (Audio is a described slot in this build; no audio file is made.)
3. **Say it to your companion** — the companion block in lesson/lesson.md.
   - ADD VIDEO: the script in video-script.md, filmed — the lesson in the super-simple voice (made later, when videos are made).
4. **Questions** — from questions/: multiple-choice, true-false, matching, short-answer — served at the learner's level and teaching-mix (levels.md).
5. **Hands-on** — hands-on.md.
6. **Do It Yourself** — the doing block at the end of lesson/lesson.md.
