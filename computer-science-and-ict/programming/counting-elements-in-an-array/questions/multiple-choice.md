# Counting Elements in an Array — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does the counter start at?**
a) Zero  b) Exactly when an element passes the test  c) Nothing — its product is the single count  d) a[i] % 2 == 0
**Answer: a) Zero**

**2. (Sub lesson 1) When does the counter rise?**
a) Nothing — its product is the single count  b) Exactly when an element passes the test  c) a[i] % 2 == 0  d) The question's exact words, edges included
**Answer: b) Exactly when an element passes the test**

**3. (Sub lesson 1) What does the walk store?**
a) a[i] % 2 == 0  b) The question's exact words, edges included  c) Nothing — its product is the single count  d) No — 'at least 10' includes it
**Answer: c) Nothing — its product is the single count**

**4. (Sub lesson 1) What is the test for even elements?**
a) The question's exact words, edges included  b) No — 'at least 10' includes it  c) One in the condition, not the loop  d) a[i] % 2 == 0
**Answer: d) a[i] % 2 == 0**

**5. (Sub lesson 1) What must the test match?**
a) The question's exact words, edges included  b) No — 'at least 10' includes it  c) One in the condition, not the loop  d) The average must exist before elements can be compared with it
**Answer: a) The question's exact words, edges included**

**6. (Sub lesson 2) Does 'above 10' include 10?**
a) One in the condition, not the loop  b) No — 'at least 10' includes it  c) The average must exist before elements can be compared with it  d) The total (and so the average)
**Answer: b) No — 'at least 10' includes it**

**7. (Sub lesson 2) What kind of off-by-one hides in counting tasks?**
a) The average must exist before elements can be compared with it  b) The total (and so the average)  c) One in the condition, not the loop  d) No
**Answer: c) One in the condition, not the loop**

**8. (Sub lesson 2) Why is above-the-average a two-pass question?**
a) The total (and so the average)  b) No  c) Zero  d) The average must exist before elements can be compared with it
**Answer: d) The average must exist before elements can be compared with it**

**9. (Sub lesson 2) What does the first pass compute there?**
a) The total (and so the average)  b) No  c) Zero  d) Exactly when an element passes the test
**Answer: a) The total (and so the average)**

**10. (Sub lesson 2) Does counting change the array?**
a) Zero  b) No  c) Exactly when an element passes the test  d) Nothing — its product is the single count
**Answer: b) No**
