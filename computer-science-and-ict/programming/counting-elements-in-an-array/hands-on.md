# Hands-on — Counting Elements in an Array

The lesson with your hands and your feet, not only your eyes.

## Three counts
For {4, −1, 10, 7, 0, −3, 12}, hand-count: negatives, evens, and values at least 10. Write the test you used for each before counting.

## Two-pass plan
Write the plan (passes, what each computes) for: how many elements are below the array's average? Then run it by hand on {2, 4, 9}.
