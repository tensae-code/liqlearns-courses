# The IDE — one home for editing, compiling, debugging

## Do it first

To make one program you must write code, turn it into a form the computer can run, and hunt its mistakes. Without one special kind of application, those are three separate tools on three separate desks. Name the three jobs first — then read what an IDE does with them.

## What an IDE is

An **integrated development environment (IDE)** is the application that **puts everything needed to create software in one place**: it consolidates **editing source code, building executables and debugging** into a **single application and interface**, raising programmer productivity.

An IDE may **stand alone**, or be **part of a larger compatible application**.

## Inside the IDE — the typical contents

Through **one graphical interface**, a typical IDE carries:

- a **code editor** — a text editor that enhances and simplifies writing code (every IDE also carries a plain **text editor** for writing and manipulating source code);
- a **compiler or interpreter** — the compiler transforms human-readable source code into a form the computer can execute;
- a **debugger** — for testing and hunting bugs;
- **build automation tools**;
- and in some IDEs a **class browser**, an **object browser** and a **class-hierarchy diagram**, for object-oriented work.
