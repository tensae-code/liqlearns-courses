# Lesson plan — The IDE — one home for editing, compiling, debugging

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** The IDE — one home for editing, compiling, debugging
**Place in the curriculum:** Unit 6 — Fundamentals of Programming (CURRICULUM.md).
**The one thing this lesson teaches:** an integrated development environment is the application that puts everything needed to create software in one place — a code editor, a compiler or interpreter, and a debugger, through one graphical interface.
**This lesson's own level:** it stands on the algorithm and representation lessons of this unit — the learner has written algorithms, flowcharts and pseudocode, and now meets the tool programs are made in. It needs nothing else.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
This lesson is one whole lesson — it has no sub lessons (a short, single-skill lesson; his ruling 2026-11-09).

## Before this lesson
- Recommended first: Pseudocode — algorithms in structured English (the Grade 10 growth of Flowchart or pseudocode). Recommended, never forced.

## What the learner can do when it ends
1. Define an IDE: one application consolidating editing, building executables and debugging.
2. Name the typical contents and what each does.
3. Say what a compiler does to source code.
4. State that an IDE may stand alone or be part of a larger application.

## What you need
Paper and a pencil. Nothing else.

## If the learner is stuck
- Thinks the IDE is a programming language → a language is what you write IN; the IDE is the one place you write, build and debug it.
- Mixes compiler and editor → the editor is where code is written; the compiler transforms it into executable form.
