# The IDE — one home for editing, compiling, debugging — true or false

Say whether each sentence is true or false.

**1.** An IDE may stand alone or be part of a larger compatible application.
**Answer: True** — both forms are named.

**2.** Build automation tools are never part of an IDE.
**Answer: False** — they are listed among its contents.

**3.** The class browser and class-hierarchy diagram serve object-oriented work.
**Answer: True** — in some IDEs.
