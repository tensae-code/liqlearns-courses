# The IDE — one home for editing, compiling, debugging — multiple choice

Pick the one right answer.

**1.** An IDE consolidates —
a) editing source code, building executables and debugging  b) only typing  c) printing and scanning  d) email and browsing
**Answer: a) editing source code, building executables and debugging** — the three jobs in one application.

**2.** A compiler —
a) transforms human-readable source code into a form the computer can execute  b) writes the code for you  c) draws flowcharts  d) stores passwords
**Answer: a) transforms human-readable source code into a form the computer can execute** — the book's wording.

**3.** The debugger is for —
a) deleting files  b) testing and hunting bugs  c) connecting to the internet  d) formatting disks
**Answer: b) testing and hunting bugs** — test and debug in one part.

**4.** A code editor differs from a plain text editor because it —
a) is more expensive  b) enhances and simplifies writing code  c) cannot save files  d) only works online
**Answer: b) enhances and simplifies writing code** — both are carried by the IDE.

**5.** An IDE reaches the programmer through —
a) three separate windows that never meet  b) one graphical interface  c) a printed book  d) voice only
**Answer: b) one graphical interface** — a single application and interface.
