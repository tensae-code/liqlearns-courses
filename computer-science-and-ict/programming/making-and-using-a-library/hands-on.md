# Hands-on — Making and Using a Library

The lesson with your hands and your feet, not only your eyes.

## Task one
**Make a shelf** — Take a program with three procedures you wrote (or design them). Package them as a named library: give the shelf a name, and write the one-line document for each procedure — what it takes, what it does.

## Task two
**Use a stranger's shelf** — Choose an Arduino library (Servo or LiquidCrystal). Write a sketch plan that includes it and calls two of its functions, noting what you did not have to write because the library exists.
