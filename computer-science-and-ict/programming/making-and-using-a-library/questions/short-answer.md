# Making and Using a Library — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a library?**
**Answer: A collection of ready procedures and functions, packaged under one name for programs to call**

**2. (Sub lesson 1) What does Grade 9 teach about libraries?**
**Answer: Developing one — gathering your own Scratch/Blockly blocks, named and kept for the next project**

**3. (Sub lesson 1) A library is modularisation with what?**
**Answer: An address — a shelf other programs visit**

**4. (Sub lesson 1) What do Arduino's libraries cover?**
**Answer: Its common parts — a library to run the servo, one to write the LCD**

**5. (Sub lesson 1) What does the Library Manager do?**
**Answer: Installs libraries in the Arduino IDE**

**6. (Sub lesson 2) What does Include Library do?**
**Answer: Adds a library to a sketch, so its functions can be called**

**7. (Sub lesson 2) After inclusion, how are a library's functions called?**
**Answer: Like the language's own**

**8. (Sub lesson 2) Every library in use was once what?**
**Answer: Made — packaged by someone for strangers to call**

**9. (Sub lesson 2) What three marks make a library well made?**
**Answer: Named clearly, documented honestly, built to be called by strangers**

**10. (Sub lesson 2) Where does Indonesia teach this?**
**Answer: Grade 9 Bab II A.2–A.3 (making) and Grade 12 Bab 3 O (using Arduino libraries)**
