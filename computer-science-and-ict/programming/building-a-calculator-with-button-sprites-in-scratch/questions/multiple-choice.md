# Building a Calculator with Button Sprites in Scratch — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is the calculator’s face made of?**
a) Drawn digit and operation button sprites  b) By joining each digit pressed  c) An operation variable  d) An if-chain on the operation variable
**Answer: a) Drawn digit and operation button sprites**

**2. (Sub lesson 1) How is the first number built?**
a) The secret PIN lock  b) By joining each digit pressed  c) + − × ÷  d) It adds
**Answer: b) By joining each digit pressed**

**3. (Sub lesson 1) Which earlier lesson built an entry the same way?**
a) An operation variable  b) An if-chain on the operation variable  c) The secret PIN lock  d) In a large stage display
**Answer: c) The secret PIN lock**

**4. (Sub lesson 1) What remembers the operation?**
a) + − × ÷  b) It adds  c) Chaining operations and keyboard input (also square root and remainder)  d) An operation variable
**Answer: d) An operation variable**

**5. (Sub lesson 1) What four operations does it remember?**
a) + − × ÷  b) An if-chain on the operation variable  c) In a large stage display  d) The book’s biggest single build
**Answer: a) + − × ÷**

**6. (Sub lesson 2) What does equals run?**
a) It adds  b) An if-chain on the operation variable  c) Chaining operations and keyboard input (also square root and remainder)  d) Drawn digit and operation button sprites
**Answer: b) An if-chain on the operation variable**

**7. (Sub lesson 2) If the variable holds +, what does equals do?**
a) In a large stage display  b) The book’s biggest single build  c) It adds  d) By joining each digit pressed
**Answer: c) It adds**

**8. (Sub lesson 2) Where is the result shown?**
a) Chaining operations and keyboard input (also square root and remainder)  b) Drawn digit and operation button sprites  c) The secret PIN lock  d) In a large stage display
**Answer: d) In a large stage display**

**9. (Sub lesson 2) Name two project extensions.**
a) Chaining operations and keyboard input (also square root and remainder)  b) The book’s biggest single build  c) By joining each digit pressed  d) An operation variable
**Answer: a) Chaining operations and keyboard input (also square root and remainder)**

**10. (Sub lesson 2) What kind of build is the calculator?**
a) Drawn digit and operation button sprites  b) The book’s biggest single build  c) The secret PIN lock  d) + − × ÷
**Answer: b) The book’s biggest single build**
