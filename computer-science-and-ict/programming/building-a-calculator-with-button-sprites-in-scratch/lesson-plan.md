# Lesson plan — Building a Calculator with Button Sprites in Scratch

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** Building a Calculator with Button Sprites in Scratch
**Place in the curriculum:** ICT expansion — Palestine (2026-11-14) — in the title Programming on the ICT course ladder (TITLES.md). Built new from Palestine's Grade 9 Programming student book, because no existing lesson in the course covers this thing as its own lesson.
**The one thing this lesson teaches:** The calculator is built from drawn digit and operation button sprites: the first number is built by joining each digit pressed; an operation variable remembers + − × ÷; equals runs an if-chain and shows the result in a large stage display.
**This lesson's own level:** It stands on the earlier lessons of its title and on the book's own order — it follows the book's lessons in sequence, so its neighbours in the book are its natural companions. It stands alone for a learner landing on it directly.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Buttons and the joined number** — The calculator’s face is **drawn digit and operation button sprites**. Pressing digits builds the number as text: **the first number is built by joining each digit pressed**, exactly as the PIN lock built its entry. An **operation variable remembers + − × ÷** — the sign waits in its variable while the second number is entered.
2. **Equals — the if-chain and the big display** — Equals is a decision: it **runs an if-chain** on the operation variable — if +, add; if −, subtract; and so on — and **shows the result in a large stage display**. The projects extend the machine: **chaining operations, keyboard input, square root and remainder**.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
