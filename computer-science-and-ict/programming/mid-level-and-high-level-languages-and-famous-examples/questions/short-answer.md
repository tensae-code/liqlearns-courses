# Mid-Level and High-Level Languages — and Famous Examples — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What makes a language mid-level?**
**Answer: Human words above, machine reach below — both in one**

**2. (Sub lesson 1) Which language is the standing mid-level example?**
**Answer: C**

**3. (Sub lesson 1) Name two jobs needing the middle rung.**
**Answer: Operating systems and embedded controllers (also the fastest engines)**

**4. (Sub lesson 1) What does C keep from the low level?**
**Answer: Reach — memory addresses, bits, hardware**

**5. (Sub lesson 1) What does C keep from the high level?**
**Answer: Portability and human-readable writing**

**6. (Sub lesson 2) What do high-level languages hide?**
**Answer: The machine — one statement does many instructions' work**

**7. (Sub lesson 2) Profile C++ in one line.**
**Answer: C grown with objects — systems and games**

**8. (Sub lesson 2) Profile Java in one line.**
**Answer: Write once, run anywhere its virtual machine lives**

**9. (Sub lesson 2) Profile Python in one line.**
**Answer: The readable language — first lessons to AI**

**10. (Sub lesson 2) What do fourth-generation languages state?**
**Answer: What result is wanted — the system finds how**
