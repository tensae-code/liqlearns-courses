# Mid-Level and High-Level Languages — and Famous Examples

## Do it first

Languages climb a ladder away from the machine: machine code, assembly, and then — what? The rungs above assembly are not one rung. Bangladesh's chapter stops on the middle rung that most books skip, because the language standing on it, C, is the one its own programming course teaches.

## Sub lesson 1 — Mid-level — C between the worlds

A **mid-level language** stands between low and high: it writes in human words like a high-level language, yet reaches down to the machine's own affairs — memory addresses, bits, hardware — when the programmer demands it. **C** is the standing example: portable across machines like a high-level language, close to the metal like a low one. The middle rung exists because some work — operating systems, embedded controllers, the fastest engines — needs both the human's ease and the machine's obedience at once.

In your mind's eye: mid-level — C between the worlds.

## Sub lesson 2 — High-level — C++, Java, Python; and the fourth generation

**High-level languages** hide the machine almost wholly: one statement does the work of many machine instructions, and the same program can run on many machines. The book profiles its famous three: **C++** — C grown with objects, for systems and games; **Java** — written once, run anywhere its virtual machine lives, for enterprise and Android; **Python** — the readable language of this course's own earlier chapters, for everything from first lessons to artificial intelligence. Beyond them the book names the **fourth generation**: languages that state *what* result is wanted and let the system find the *how* — the ladder still climbing.

In your mind's eye: high-level — C++, Java, Python; and the fourth generation.
