# Testing an Algorithm — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does testing an algorithm mean?" is: Running it step by step on chosen values and comparing with the known right result**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is an algorithm tested against?" is: To the step where the trace leaves the right path**
**Answer: False** — The result you already know is right

**3. (Sub lesson 1) True or false: the answer to "Where does a failed test point?" is: To the step where the trace leaves the right path**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "When is testing done?" is: Pencil, paper and patience — a step-by-step trace**
**Answer: False** — Before any computer sees the algorithm

**5. (Sub lesson 1) True or false: the answer to "What do you test with?" is: Pencil, paper and patience — a step-by-step trace**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What three kinds of test values should be chosen?" is: The smallest and the largest values allowed**
**Answer: False** — An ordinary value, the edges of the range, and a special or refused value

**7. (Sub lesson 2) True or false: the answer to "What are the edges of a range?" is: The smallest and the largest values allowed**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does each written test record?" is: The algorithm may still break at the edges**
**Answer: False** — Input, expected result, the algorithm's result, and the verdict

**9. (Sub lesson 2) True or false: the answer to "Why are ordinary values alone not enough?" is: The algorithm may still break at the edges**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Where do faults like to hide?" is: Running it step by step on chosen values and comparing with the known right result**
**Answer: False** — At the edges of the range
