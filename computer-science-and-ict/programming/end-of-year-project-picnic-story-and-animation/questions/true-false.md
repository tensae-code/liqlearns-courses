# End-of-Year Project — Picnic Story and Animation — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What three skills does the picnic project join?" is: Typing a story in Notepad, drawing in Scratch and animating in Scratch**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Where is the picnic story typed?" is: Saved as a file with a clear name in the class folder**
**Answer: False** — In Notepad, the plain text program

**3. (Sub lesson 1) True or false: the answer to "Why Notepad for the story?" is: So the words come first, with no formatting to hide behind**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is planned before typing?" is: The people and things in the story**
**Answer: False** — Who went, where the picnic was and what happened

**5. (Sub lesson 1) True or false: the answer to "How is the finished story kept?" is: Saved as a file with a clear name in the class folder**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does the Scratch part begin with?" is: It is shown to the class — story file and animation together**
**Answer: False** — A backdrop for the picnic place

**7. (Sub lesson 2) True or false: the answer to "Who and what appear as sprites?" is: The people and things in the story**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Which blocks make the scene move?" is: Typing a story in Notepad, drawing in Scratch and animating in Scratch**
**Answer: False** — Motion and looks blocks

**9. (Sub lesson 2) True or false: the answer to "How is the project finished?" is: It is shown to the class — story file and animation together**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What does the project prove?" is: So the words come first, with no formatting to hide behind**
**Answer: False** — That the year's separate skills work together in one finished piece
