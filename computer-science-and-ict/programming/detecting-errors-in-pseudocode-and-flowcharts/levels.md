# Detecting Errors in Pseudocode and Flowcharts — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Tracing — running the algorithm by hand
Sub lesson 1 questions from the type files. Pass mark: A trace — running the algorithm by hand, step by step on paper; Every variable's value after every step; A value that never changes; a step using a value before it exists (also: a path never reached); In the algorithm's own order — never the order you expect; You see what you meant, not what the steps say.

## Sub lesson 2 — The faults a trace exposes — and fixing them
Sub lesson 2 questions from the type files. Pass mark: A loop with no way out — its test can never become false; The increment or change that moves the test toward ending; A decision missing a path; steps in the wrong order (also: a wrong test, = for ≥); In the algorithm — the pseudocode line or flowchart box; It is re-run from the top.
