# Detecting Errors in Pseudocode and Flowcharts — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does detecting errors begin with?**
a) A trace — running the algorithm by hand, step by step on paper  b) Every variable's value after every step  c) A value that never changes; a step using a value before it exists (also: a path never reached)  d) In the algorithm's own order — never the order you expect
**Answer: a) A trace — running the algorithm by hand, step by step on paper**

**2. (Sub lesson 1) What do you write during a trace?**
a) A value that never changes; a step using a value before it exists (also: a path never reached)  b) Every variable's value after every step  c) In the algorithm's own order — never the order you expect  d) You see what you meant, not what the steps say
**Answer: b) Every variable's value after every step**

**3. (Sub lesson 1) Name two things a trace exposes.**
a) In the algorithm's own order — never the order you expect  b) You see what you meant, not what the steps say  c) A value that never changes; a step using a value before it exists (also: a path never reached)  d) A loop with no way out — its test can never become false
**Answer: c) A value that never changes; a step using a value before it exists (also: a path never reached)**

**4. (Sub lesson 1) In what order is the trace worked?**
a) You see what you meant, not what the steps say  b) A loop with no way out — its test can never become false  c) The increment or change that moves the test toward ending  d) In the algorithm's own order — never the order you expect
**Answer: d) In the algorithm's own order — never the order you expect**

**5. (Sub lesson 1) Why does expectation hide faults?**
a) You see what you meant, not what the steps say  b) A loop with no way out — its test can never become false  c) The increment or change that moves the test toward ending  d) A decision missing a path; steps in the wrong order (also: a wrong test, = for ≥)
**Answer: a) You see what you meant, not what the steps say**

**6. (Sub lesson 2) Name the loop fault a trace exposes.**
a) The increment or change that moves the test toward ending  b) A loop with no way out — its test can never become false  c) A decision missing a path; steps in the wrong order (also: a wrong test, = for ≥)  d) In the algorithm — the pseudocode line or flowchart box

**7. (Sub lesson 2) What is missing in that loop fault, usually?**

**8. (Sub lesson 2) Name two more common faults.**
