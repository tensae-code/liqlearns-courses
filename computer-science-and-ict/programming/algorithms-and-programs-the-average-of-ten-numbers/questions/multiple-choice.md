# Algorithms and programs — the average of ten numbers — multiple choice

Pick the one right answer.

**1.** What is the average algorithm?
a) get the 10 numbers; get SUM by adding them; get AVERAGE by dividing SUM by 10; report AVERAGE  b) a sequence of instructions written using a programming language, executed by a computer  c) the computer's own special language — computers do not understand human languages  d) what must happen to an algorithm before a computer can execute it: it must become a program
**Answer: a) get the 10 numbers; get SUM by adding them; get AVERAGE by dividing SUM by 10; report AVERAGE**

**2.** What is a program?
a) get the 10 numbers; get SUM by adding them; get AVERAGE by dividing SUM by 10; report AVERAGE  b) the computer's own special language — computers do not understand human languages  c) what must happen to an algorithm before a computer can execute it: it must become a program  d) a sequence of instructions written using a programming language, executed by a computer
**Answer: d) a sequence of instructions written using a programming language, executed by a computer**

**3.** What is a programming language?
a) a sequence of instructions written using a programming language, executed by a computer  b) what must happen to an algorithm before a computer can execute it: it must become a program  c) the computer's own special language — computers do not understand human languages  d) get the 10 numbers; get SUM by adding them; get AVERAGE by dividing SUM by 10; report AVERAGE
**Answer: c) the computer's own special language — computers do not understand human languages**

**4.** What is transforming?
a) the computer's own special language — computers do not understand human languages  b) what must happen to an algorithm before a computer can execute it: it must become a program  c) get the 10 numbers; get SUM by adding them; get AVERAGE by dividing SUM by 10; report AVERAGE  d) a sequence of instructions written using a programming language, executed by a computer
**Answer: b) what must happen to an algorithm before a computer can execute it: it must become a program**

**5.** Why must the algorithm be transformed?
a) computers prefer short text  b) computers do not understand English, Amharic or Afaan Oromo — they use a programming language  c) paper is not allowed  d) averages need it
**Answer: b) computers do not understand English, Amharic or Afaan Oromo — they use a programming language**

**6.** SUM divided by 10 gives —
a) the total  b) AVERAGE  c) the count  d) the program
**Answer: b) AVERAGE**
