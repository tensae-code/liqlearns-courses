# Algorithms and programs — the average of ten numbers — tf

Say whether each statement is true or false.

**1.** True or false: the average algorithm — get the 10 numbers; get SUM by adding them; get AVERAGE by dividing SUM by 10; report AVERAGE.
**Answer: True**

**2.** True or false: a program — a sequence of instructions written using a programming language, executed by a computer.
**Answer: True**

**3.** True or false: a programming language is the opposite: it has nothing to do with the computer's own special language — computers do not understand human languages.
**Answer: False** — a programming language is about the computer's own special language — computers do not understand human languages.
