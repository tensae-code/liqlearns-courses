## The worked algorithm

The example algorithm finds the average of 10 numbers: get the 10 numbers; get SUM by adding them; get AVERAGE by dividing SUM by 10; report AVERAGE. Four steps — finite, unambiguous, with a clear start and end, exactly as the last lesson defined.

## From algorithm to program

An algorithm must be transformed into a computer program to be executed, because computers do not understand English, Amharic, Afaan Oromo or other human languages — they have their own special language, a programming language. A program is a sequence of instructions written using a programming language, executed by a computer to solve a problem or perform a task. Steps 3 and 4 — writing and testing programs — are promised for the later grades; this grade builds the algorithms they will come from.
