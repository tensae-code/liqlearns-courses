# Hands-on — What a Programming Language Is — Orders the Computer Understands

The lesson with your hands and your feet, not only your eyes.

## Spot the orders
List three machines in your home that follow written orders. For each, write the order it obeys in one sentence.

## Write fixed-rule orders
Write five orders for a classmate-robot using fixed rules only — the same words in the same order every time — and have them carried out exactly.
