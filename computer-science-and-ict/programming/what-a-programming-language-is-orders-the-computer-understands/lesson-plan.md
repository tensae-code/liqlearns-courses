# Lesson plan — What a Programming Language Is — Orders the Computer Understands

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** What a Programming Language Is — Orders the Computer Understands
**Place in the curriculum:** ICT expansion — Palestine (2026-11-14) — in the title Programming on the ICT course ladder (TITLES.md). Built new from Palestine's Grade 6 and Grade 8 Programming student books, because no existing lesson in the course covers this thing as its own lesson.
**The one thing this lesson teaches:** A programming language is orders written by fixed rules that a computer or machine executes; a programmer writes those orders — Scratch, Java, Visual Basic, C and HTML are the book’s named examples.
**This lesson's own level:** It stands on the earlier lessons of its title and on the book's own order — it follows the book's lessons in sequence, so its neighbours in the book are its natural companions. It stands alone for a learner landing on it directly.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Orders written by fixed rules** — Grade 6 defines it first: a **programming language** is **orders written by fixed rules** that the computer understands and carries out. The book names its examples — **Scratch, Java, Visual Basic, C, HTML** — and starts with Scratch, whose orders are blocks. Break the rules and the order is not understood.
2. **Programming around us** — Grade 8 opens the same idea wider: **programming around us** — the **programmer writes the controlling orders**, and programming is lines of orders a machine executes. The book’s witnesses are everyday: a **remote-control TV**, a **phone ringing when called**, and **electronic games** — each one runs orders somebody wrote.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## The run of the lesson (in order)
1. **Do it first** — A television obeys a remote, a phone rings when it is called, a game obeys its player. Who wrote the orders those machines follow? Palestine opens its Scratch years by answering: a programmer, in a programming language. (lesson/lesson.md).
2. **The explanation** — the lesson text in lesson/lesson.md, in its parts in order.
   - ADD IMAGE: a picture of orders written by fixed rules as the lesson describes it — the student studies the picture and names what each part shows.
