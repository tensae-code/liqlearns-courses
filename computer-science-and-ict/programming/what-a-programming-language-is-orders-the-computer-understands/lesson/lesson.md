# What a Programming Language Is — Orders the Computer Understands

## Do it first

A television obeys a remote, a phone rings when it is called, a game obeys its player. Who wrote the orders those machines follow? Palestine opens its Scratch years by answering: a programmer, in a programming language.

## Sub lesson 1 — Orders written by fixed rules

Grade 6 defines it first: a **programming language** is **orders written by fixed rules** that the computer understands and carries out. The book names its examples — **Scratch, Java, Visual Basic, C, HTML** — and starts with Scratch, whose orders are blocks. Break the rules and the order is not understood.

[Picture — orders written by fixed rules]

## Sub lesson 2 — Programming around us

Grade 8 opens the same idea wider: **programming around us** — the **programmer writes the controlling orders**, and programming is lines of orders a machine executes. The book’s witnesses are everyday: a **remote-control TV**, a **phone ringing when called**, and **electronic games** — each one runs orders somebody wrote.

[Picture — programming around us]

## Say it to your companion

Tell your companion, in your own words: A programming language is orders written by fixed rules that a computer or machine executes; a programmer writes those orders — Scratch, Java, Visual Basic, C and HTML are the book’s named examples. Then let your companion ask you one question about it — and answer from the lesson, not from memory of the book's exact words.
