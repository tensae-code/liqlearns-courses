# What a Programming Language Is — Orders the Computer Understands — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a programming language?**
**Answer: Orders written by fixed rules the computer understands**

**2. (Sub lesson 1) What does the computer do with the orders?**
**Answer: It carries them out**

**3. (Sub lesson 1) Which language does the book start with?**
**Answer: Scratch**

**4. (Sub lesson 1) Name two other languages the book names.**
**Answer: Java and Visual Basic (also C and HTML)**

**5. (Sub lesson 1) What happens if the fixed rules are broken?**
**Answer: The order is not understood**

**6. (Sub lesson 2) Who writes the controlling orders?**
**Answer: The programmer**

**7. (Sub lesson 2) What is programming, in Grade 8’s words?**
**Answer: Lines of orders a machine executes**

**8. (Sub lesson 2) What everyday machine does the book give first?**
**Answer: A remote-control TV**

**9. (Sub lesson 2) What phone event does the book give as programmed?**
**Answer: Ringing when called**

**10. (Sub lesson 2) What third everyday example does Grade 8 give?**
**Answer: Electronic games**
