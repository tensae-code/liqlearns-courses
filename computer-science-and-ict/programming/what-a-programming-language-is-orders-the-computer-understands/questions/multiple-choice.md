# What a Programming Language Is — Orders the Computer Understands — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a programming language?**
a) Orders written by fixed rules the computer understands  b) It carries them out  c) Java and Visual Basic (also C and HTML)  d) The programmer
**Answer: a) Orders written by fixed rules the computer understands**

**2. (Sub lesson 1) What does the computer do with the orders?**
a) Scratch  b) It carries them out  c) The order is not understood  d) Lines of orders a machine executes
**Answer: b) It carries them out**

**3. (Sub lesson 1) Which language does the book start with?**
a) Java and Visual Basic (also C and HTML)  b) The programmer  c) Scratch  d) A remote-control TV
**Answer: c) Scratch**

**4. (Sub lesson 1) Name two other languages the book names.**
a) The order is not understood  b) Lines of orders a machine executes  c) Ringing when called  d) Java and Visual Basic (also C and HTML)
**Answer: d) Java and Visual Basic (also C and HTML)**

**5. (Sub lesson 1) What happens if the fixed rules are broken?**
a) The order is not understood  b) The programmer  c) A remote-control TV  d) Electronic games
**Answer: a) The order is not understood**

**6. (Sub lesson 2) Who writes the controlling orders?**
a) Lines of orders a machine executes  b) The programmer  c) Ringing when called  d) Orders written by fixed rules the computer understands
**Answer: b) The programmer**

**7. (Sub lesson 2) What is programming, in Grade 8’s words?**
a) A remote-control TV  b) Electronic games  c) Lines of orders a machine executes  d) It carries them out
**Answer: c) Lines of orders a machine executes**

**8. (Sub lesson 2) What everyday machine does the book give first?**
a) Ringing when called  b) Orders written by fixed rules the computer understands  c) Scratch  d) A remote-control TV
**Answer: d) A remote-control TV**

**9. (Sub lesson 2) What phone event does the book give as programmed?**
a) Ringing when called  b) Electronic games  c) It carries them out  d) Java and Visual Basic (also C and HTML)
**Answer: a) Ringing when called**

**10. (Sub lesson 2) What third everyday example does Grade 8 give?**
a) Orders written by fixed rules the computer understands  b) Electronic games  c) Scratch  d) The order is not understood
**Answer: b) Electronic games**
