# What a Programming Language Is — Orders the Computer Understands — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a programming language?" is: Orders written by fixed rules the computer understands**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does the computer do with the orders?" is: Java and Visual Basic (also C and HTML)**
**Answer: False** — It carries them out

**3. (Sub lesson 1) True or false: the answer to "Which language does the book start with?" is: Scratch**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Name two other languages the book names." is: The programmer**
**Answer: False** — Java and Visual Basic (also C and HTML)

**5. (Sub lesson 1) True or false: the answer to "What happens if the fixed rules are broken?" is: The order is not understood**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Who writes the controlling orders?" is: A remote-control TV**
**Answer: False** — The programmer

**7. (Sub lesson 2) True or false: the answer to "What is programming, in Grade 8’s words?" is: Lines of orders a machine executes**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What everyday machine does the book give first?" is: Electronic games**
**Answer: False** — A remote-control TV

**9. (Sub lesson 2) True or false: the answer to "What phone event does the book give as programmed?" is: Ringing when called**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What third everyday example does Grade 8 give?" is: It carries them out**
**Answer: False** — Electronic games
