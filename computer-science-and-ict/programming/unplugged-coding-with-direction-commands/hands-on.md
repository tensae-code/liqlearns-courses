# Hands-on — Unplugged Coding With Direction Commands

The lesson with your hands and your feet, not only your eyes.

## Task one
**Human robot** — In pairs: one is the character, one the programmer. Cross the room (or a taped maze) by direction commands alone; swap roles and count each pair's commands.

## Task two
**Write the route** — On a maze worksheet, write the full command sequence from start to finish, then trace it with a finger, fixing the sequence where the trace fails.
