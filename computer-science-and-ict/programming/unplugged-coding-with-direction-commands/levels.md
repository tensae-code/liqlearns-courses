# Unplugged Coding With Direction Commands — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Following instructions step by step
Sub lesson 1 questions from the type files. Pass mark: Instructions followed in order, one step at a time; Exactly as said — no guessing, no kindness; In the instructions, never in the character; Finding the fault in the instructions; A grid or a maze.

## Sub lesson 2 — Direction commands — forward, turn left, turn right
Sub lesson 2 questions from the type files. Pass mark: Forward (a number of steps), turn left, turn right; A sequence of direction commands; Writing a program in speech; Print the pictures and do the direction work on paper; The thinking, not the device.
