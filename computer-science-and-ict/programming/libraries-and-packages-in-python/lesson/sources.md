Placement choice: this lesson was built new for the ICT expansion (Nepal, 2026-11-14) because no existing lesson in the course covers this thing as its own lesson — the live tree was checked first: Programming holds lessons on writing your own code (scripts, LOGO procedures, Python basics) but no lesson on Python's modules, packages and libraries or on `import`, which is how Nepal's book teaches it in its own §4.3 section, between user-defined functions and the pandas file work that depends on it. The placements file named this slug directly (NEW LESSON NEEDED — programming/libraries-and-packages-in-python). It sits in the Programming title (programming/).

Nepal's own way: a single optional-subject book that runs networks → MySQL databases → multimedia → Python (with Turtle, pandas file handling and data visualisation) → AI and contemporary technologies, ending each unit with curriculum-stated learning outcomes; Python data work with pandas is unusually advanced for Grade 10.

Vietnam's own way (Grade 11 Tin học 11 Khoa học máy tính): from Grade 11 the two orientations are separate books but share a common core (Bài 1–16 here: operating systems, inside the computer, and a full databases strand ending at SQL); the CS-only second half is algorithm engineering in Python — arrays, search and sort, time complexity, stepwise refinement, modular design and building code libraries.


Pakistan's own way (Grade 11 Computer Science and Entrepreneurship 11): the new-curriculum Grade 11 book runs the whole arc from making software to selling it: SDLC with UML and design patterns, a full Python course (through OOP, files and exceptions), algorithms with complexity classes (P, NP, NP-hard), data analytics with regression and clustering, cloud and blockchain, and a closing entrepreneurship unit — every unit grounded in Pakistani examples (Daraz, Foodpanda, Careem, Pakola, NADRA, the Personal Data Protection Bill, NR3C-FIA).
