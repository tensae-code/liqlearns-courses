# Hands-on — Libraries and Packages in Python

The lesson with your hands, not only your eyes.

## Work from the standard library

Write a short program that imports `math` and uses two of its functions — for example `math.sqrt(81)` and `math.pi` in a circle calculation. Run it. Then rewrite one call using `from math import sqrt` and run it again; write one line on what changed in the call and what did not change in the answer.

## Tour the shelves

Open Python's help for one standard-library module you have met (for example `turtle` or `random`): list three functions it offers and write, for each, one job it would save you writing yourself.
