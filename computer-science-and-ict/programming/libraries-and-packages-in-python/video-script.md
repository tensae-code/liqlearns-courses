# Video script — Libraries and Packages in Python

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

You do not write everything yourself.

One file of ready code: a module.

A folder of modules: a package.

A whole collection: a library.

Say `import`, and the code comes to your program.

`math.sqrt(16)` — the module's name, then the function's.
