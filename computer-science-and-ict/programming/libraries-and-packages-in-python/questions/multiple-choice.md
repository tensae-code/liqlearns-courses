# Libraries and Packages in Python — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) A module is —**
a) a single Python file holding functions and other code on one theme  b) a folder of many files  c) a kind of computer
**Answer: a) a single Python file holding functions and other code on one theme** — `math` is one such file.

**2. (Sub lesson 1) A package is —**
a) one line of code  b) an organised folder of related modules  c) a box a computer is shipped in
**Answer: b) an organised folder of related modules** — The next bundle size up from a module.

**3. (Sub lesson 1) The standard library is —**
a) a library building in the capital  b) the collection of modules and packages that arrives already installed with Python  c) a book every student must buy
**Answer: b) the collection of modules and packages that arrives already installed with Python** — `math`, `turtle` and `random` live there.

**4. (Sub lesson 2) After `import math`, the square-root function is called as —**
a) `sqrt.math(16)`  b) `math.sqrt(16)`  c) `import sqrt(16)`
**Answer: b) `math.sqrt(16)`** — The module's name, a dot, then the function's name.

**5. (Sub lesson 2) `from math import sqrt` lets you call the function as —**
a) `sqrt(16)`, by its bare name  b) `from.sqrt(16)`  c) it cannot be called at all
**Answer: a) `sqrt(16)`, by its bare name** — The `from ... import` form brings the one function in by name.

**6. (Sub lesson 2) The point of libraries is —**
a) every programmer writes every job from nothing  b) code written once is shared, so programmers build on each other's work  c) programs become longer
**Answer: b) code written once is shared, so programmers build on each other's work** — Importing pandas saves writing a whole file-handling tool yourself.
