# Libraries and Packages in Python — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 1) A folder of related modules, kept together under one name, is a ____.**
**Answer: package**

**2. (Sub lesson 1) The collection that arrives already installed with Python is the ____ library.**
**Answer: standard**

**3. (Sub lesson 2) The word that brings a module into your program is ____.**
**Answer: import**
