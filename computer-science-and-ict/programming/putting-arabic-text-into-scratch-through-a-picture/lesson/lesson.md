# Putting Arabic Text into Scratch Through a Picture

## Do it first

You type your name in Arabic into Scratch’s painter — and the letters will not come. Scratch 2’s painter cannot type Arabic. Palestine’s Grade 9 book does not give up: it writes the words somewhere else, and brings them in as a picture.

## Sub lesson 1 — The problem — the painter cannot type Arabic

The lesson starts from the limit, stated plainly: **Scratch 2’s painter cannot type Arabic**. Any Arabic headline, name or title a project needs must arrive another way — the limit is in the tool, not in the language.

[Picture — the problem — the painter cannot type Arabic]

## Sub lesson 2 — The workaround — write in MS Paint, save as a picture, upload

The book’s route goes around the limit in three steps: write the text in **MS Paint**, **save it as a picture** — **JPEG, PNG or GIF** — and **upload** the picture into Scratch, where it works as a sprite or costume. The project proves it: **your full name, each word a different colour**.

[Picture — the workaround — write in MS Paint, save as a picture, upload]

## Say it to your companion

Tell your companion, in your own words: Scratch 2’s paint editor cannot type Arabic, so Arabic text is written in MS Paint, saved as a picture file (JPEG/PNG/GIF), and uploaded into Scratch — the project writes your full name, each word in a different colour. Then let your companion ask you one question about it — and answer from the lesson, not from memory of the book's exact words.
