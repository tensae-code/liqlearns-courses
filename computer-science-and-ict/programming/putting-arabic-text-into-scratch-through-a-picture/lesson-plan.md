# Lesson plan — Putting Arabic Text into Scratch Through a Picture

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** Putting Arabic Text into Scratch Through a Picture
**Place in the curriculum:** ICT expansion — Palestine (2026-11-14) — in the title Programming on the ICT course ladder (TITLES.md). Built new from Palestine's Grade 9 Programming student book, because no existing lesson in the course covers this thing as its own lesson.
**The one thing this lesson teaches:** Scratch 2’s paint editor cannot type Arabic, so Arabic text is written in MS Paint, saved as a picture file (JPEG/PNG/GIF), and uploaded into Scratch — the project writes your full name, each word in a different colour.
**This lesson's own level:** It stands on the earlier lessons of its title and on the book's own order — it follows the book's lessons in sequence, so its neighbours in the book are its natural companions. It stands alone for a learner landing on it directly.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The problem — the painter cannot type Arabic** — The lesson starts from the limit, stated plainly: **Scratch 2’s painter cannot type Arabic**. Any Arabic headline, name or title a project needs must arrive another way — the limit is in the tool, not in the language.
2. **The workaround — write in MS Paint, save as a picture, upload** — The book’s route goes around the limit in three steps: write the text in **MS Paint**, **save it as a picture** — **JPEG, PNG or GIF** — and **upload** the picture into Scratch, where it works as a sprite or costume. The project proves it: **your full name, each word a different colour**.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## The run of the lesson (in order)
1. **Do it first** — You type your name in Arabic into Scratch’s painter — and the letters will not come. Scratch 2’s painter cannot type Arabic. Palestine’s Grade 9 book does not give up: it writes the words somewhere else, and brings them in as a picture. (lesson/lesson.md).
2. **The explanation** — the lesson text in lesson/lesson.md, in its parts in order.
   - ADD IMAGE: a picture of the problem — the painter cannot type Arabic as the lesson describes it — the student studies the picture and names what each part shows.
   - ADD GIF: a GIF of the workaround — write in MS Paint, save as a picture, upload in action — the student watches once, then says what changed and why.
   - ADD AUDIO: a voice reading the lesson's key names and definitions aloud, in the order the lesson gives them — the student listens once through, then reads the same lines aloud along with the voice. (Audio is a described slot in this build; no audio file is made.)
