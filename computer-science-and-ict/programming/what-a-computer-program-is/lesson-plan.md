## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **A program — an algorithm the computer can follow** — A **computer program** (chương trình máy tính) is an **algorithm written in a programming language** — a set of instructions, in an exact order, that the computer follows to do a job. The chain matters to Vietnam's Grade 6 book, which ends its algorithms theme here: a **problem** asks, an **algorithm** plans the steps, and a **program** writes those steps in a language the computer understands. The computer contributes no understanding of its own — it follows the program, exactly, for better or worse.
2. **Programs everywhere — and the human's share** — Programs run more than computers on desks: the washing machine's cycles, the phone's alarm, the game's rules are all programs someone wrote. The human's share stays the same at every size: **choose the problem, design the algorithm, write and test the program** — because a program faithfully doing the wrong steps is worse than no program. Grade 6's closing judgement is the course's: the machine is exact and tireless; the thinking is ours.
