## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **A first Scratch script for a real robot** — The activity opens with the **instructions (consignes)**: Thymio's Scratch extension adds **motor blocks** — set the wheels' speeds, run, stop — to the familiar palette. A **first script** is deliberately tiny: one event, motors forward, wait, stop. Then the robot **draws a square** in the next séance: move, turn, move, turn — the screen's program judged by chalk on the floor, where every error is centimetres, visible to all.
2. **Loops and the two programming kinds** — The square's four sides beg for the **“repeat forever” / repeat block**: Séance 1 already adds “répéter indéfiniment” to create a loop, collapsing four sides into one instruction repeated. Séance 2 then names the course's pair: **sequential programming** (the script runs top to bottom) against **event programming** (scripts waiting for sensor events) — Thymio drawing its square both ways, so the kinds are felt in behaviour, not just defined.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
