# Programming Thymio With Scratch Blocks — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does Thymio's Scratch extension add?**
**Answer: Motor blocks — set wheel speeds, run, stop**

**2. (Sub lesson 1) What does a first script contain?**
**Answer: One event, motors forward, wait, stop**

**3. (Sub lesson 1) What does Thymio draw in Séance 2?**
**Answer: A square — move, turn, move, turn**

**4. (Sub lesson 1) How are errors judged here?**
**Answer: In centimetres, on the floor, visible to all**

**5. (Sub lesson 1) What are the activity's opening instructions called?**
**Answer: Les consignes — the motor-block instructions**

**6. (Sub lesson 2) Which block collapses the square's four sides?**
**Answer: The repeat block (répéter indéfiniment — repeat forever)**

**7. (Sub lesson 2) What are the two programming kinds named?**
**Answer: Sequential and event programming**

**8. (Sub lesson 2) How does a sequential program run?**
**Answer: Top to bottom**

**9. (Sub lesson 2) What does an event program do?**
**Answer: Waits for sensor events, then answers**

**10. (Sub lesson 2) How are the kinds taught here?**
**Answer: Felt in behaviour — Thymio draws its square both ways**
