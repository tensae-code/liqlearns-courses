# Hands-on — Programming Thymio With Scratch Blocks

The lesson with your hands and your feet, not only your eyes.

## Task one
**Square, two ways** — Program Thymio in Scratch to draw a square: first with plain sequence, then with a repeat loop. Compare script lengths and floor accuracy.

## Task two
**Event upgrade** — Add one event script: when the front sensor sees a hand, Thymio stops mid-square. Run the square into a “hand obstacle” and verify the stop.
