# Comments in C — Single-Line and Multi-Line — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What begins a single-line comment in C?**
a) //  b) To the end of the line  c) /* and */  d) No — they are removed before compilation
**Answer: a**

**2. (Sub lesson 1) How far does a single-line comment run?**
a) To the end of the line  b) /* and */  c) No — they are removed before compilation  d) The single-line //
**Answer: a**

**3. (Sub lesson 1) What opens and closes a multi-line comment?**
a) /* and */  b) No — they are removed before compilation  c) The single-line //  d) Why — or what must never break
**Answer: a**

**4. (Sub lesson 1) Does the compiler ever see comments?**
a) No — they are removed before compilation  b) The single-line //  c) Why — or what must never break  d) Noise wearing a comment's coat
**Answer: a**

**5. (Sub lesson 1) Which comment is the margin note?**
a) The single-line //  b) Why — or what must never break  c) Noise wearing a comment's coat  d) Silencing a block while debugging, without deleting it
**Answer: a**

**6. (Sub lesson 2) What should a good comment say?**
a) Why — or what must never break  b) Noise wearing a comment's coat  c) Silencing a block while debugging, without deleting it  d) A rotten comment — one that lies about the code
**Answer: a**

**7. (Sub lesson 2) What is a comment that repeats the code?**
a) Noise wearing a comment's coat  b) Silencing a block while debugging, without deleting it  c) A rotten comment — one that lies about the code  d) Like code — changed when the code changes
**Answer: a**

**8. (Sub lesson 2) What is commenting out for?**
a) Silencing a block while debugging, without deleting it  b) A rotten comment — one that lies about the code  c) Like code — changed when the code changes  d) //
**Answer: a**

**9. (Sub lesson 2) What is worse than no comment?**
a) A rotten comment — one that lies about the code  b) Like code — changed when the code changes  c) //  d) To the end of the line
**Answer: a**

**10. (Sub lesson 2) How are comments maintained?**
a) Like code — changed when the code changes  b) //  c) To the end of the line  d) /* and */
**Answer: a**
