# Comments in C — Single-Line and Multi-Line — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What begins a single-line comment in C?**
**Answer: //**

**2. (Sub lesson 1) How far does a single-line comment run?**
**Answer: To the end of the line**

**3. (Sub lesson 1) What opens and closes a multi-line comment?**
**Answer: /* and */**

**4. (Sub lesson 1) Does the compiler ever see comments?**
**Answer: No — they are removed before compilation**

**5. (Sub lesson 1) Which comment is the margin note?**
**Answer: The single-line //**

**6. (Sub lesson 2) What should a good comment say?**
**Answer: Why — or what must never break**

**7. (Sub lesson 2) What is a comment that repeats the code?**
**Answer: Noise wearing a comment's coat**

**8. (Sub lesson 2) What is commenting out for?**
**Answer: Silencing a block while debugging, without deleting it**

**9. (Sub lesson 2) What is worse than no comment?**
**Answer: A rotten comment — one that lies about the code**

**10. (Sub lesson 2) How are comments maintained?**
**Answer: Like code — changed when the code changes**
