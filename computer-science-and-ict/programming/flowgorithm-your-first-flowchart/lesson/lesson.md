# Flowgorithm — your first flowchart

## Do it first

Flowgorithm opens with two symbols already waiting: Main and End, joined by one arrow. Your chart must do one thing — display 'Welcome!' This doing-lesson inserts the symbol, types the words and runs the chart, in the book's exact order. Prove each sub lesson before the next opens.

## Sub lesson 1 — Opening Flowgorithm

Flowgorithm is a free beginner's language based on simple graphical flowcharts, combining the classic symbols with a few more for repetition flows, and programs can be run directly in it. Opening it shows a Main (start) and End symbol already created, with an arrow connector between them. Links to Flowgorithm's resources and Wikiversity notes are given in the book for learning more.

[Picture 20935 — Flowgorithm — Main, an Output symbol, End]

## Sub lesson 2 — Inserting the Output symbol

To display 'Welcome!', in the book's order: right-click the arrow connector to open the symbol pop-up; choose the Output symbol — it is inserted between start and end; double-click it and type 'Welcome!' in the 'Enter an Expression Below' box. Watch the GIF: the insertion gesture — right-click the arrow, pick Output — is the skill.

[GIF 20950 — right-clicking the arrow and slotting Output in]

## Sub lesson 3 — Running the chart

Then click the Run icon on the toolbar to see the output: 'Welcome!' Your first flowchart has run — an algorithm as a chart, executed step by step, exactly as the environments lesson promised.
