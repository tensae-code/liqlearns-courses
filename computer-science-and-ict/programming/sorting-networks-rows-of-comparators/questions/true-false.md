# Sorting Networks — Rows of Comparators — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A fixed pattern of comparators that sorts any input**
**Answer: True**

**2. (Sub lesson 1) True or false: A fixed pattern of comparators that sorts any input** — as the answer to: What does one comparator do?
**Answer: False — Joins two wires and leaves the smaller value on the agreed wire**

**3. (Sub lesson 1) True or false: Comparators on separate wires — a whole row at once**
**Answer: True**

**4. (Sub lesson 1) True or false: Comparators on separate wires — a whole row at once** — as the answer to: What does a network need none of?
**Answer: False — Decisions, memory, control — the pattern is the program**

**5. (Sub lesson 1) True or false: Place comparators, test with shuffled inputs, watch order emerge**
**Answer: True**

**6. (Sub lesson 2) True or false: Place comparators, test with shuffled inputs, watch order emerge** — as the answer to: What is a panne here?
