# Hands-on — Analysis of Situations and System Diagrams in Programming

The lesson with your hands and your feet, not only your eyes.

## Task one
**Do the book's steps** — Work through Aspects of programming 3 — Analysis of situations: system diagrams and data flow exactly as South Sudan's book orders it, on a real computer if one is available; otherwise write the steps in order and check them against the book's order.

## Task two
**Show it to someone** — Take Doing it — Aspects of programming 3 — Analysis of situations: system diagrams and data flow in practice and show a partner what it does: do it once slowly, naming each step, then let the partner do it while you only watch and correct.
