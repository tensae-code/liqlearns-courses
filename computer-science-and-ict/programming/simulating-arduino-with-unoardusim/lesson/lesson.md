# Simulating Arduino with UnoArduSim

## Do it first

Simulating Arduino with UnoArduSim — running an Arduino program on a simulated board: choosing I/O devices, editing the program and lighting the LED without touching hardware

## Sub lesson 1 — A board inside the computer — why simulate

A **simulator** is a program that behaves as the board behaves. **UnoArduSim** simulates the Arduino Uno on an ordinary computer: the sketch runs, the pins answer, and the connected devices appear on screen — no board, no wires, no burnt LEDs. Indonesia's Grade 12 course teaches it inside the Arduino chapter because simulation changes what a beginner can risk: a program can be run, broken and repaired a hundred times in an hour, and a class with one board — or none — can still do the whole practical course.

## Sub lesson 2 — Working in the simulator — run, edit, choose devices

The simulator's working acts mirror the bench's: **run** the program and watch it behave; **edit** the sketch and run it again — the repair loop at keyboard speed; and **choose the I/O devices** the simulated board is wired to — the LED to light, the button to press, the instruments to watch — from the simulator's device panels. The chapter's standing exercise is the first light: wire the simulated LED, write the sketch that lights it, and prove the whole road — code, compile, run, light — inside the computer before the same road is walked on the real board.
