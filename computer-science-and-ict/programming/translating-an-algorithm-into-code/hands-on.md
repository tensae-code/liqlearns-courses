# Hands-on — Translating an Algorithm into Code

The lesson with your hands and your feet, not only your eyes.

## Task one
('Translate it', 'Translate this pseudocode into Java: READ mark; IF mark ≥ 50 THEN PRINT 'Pass' ELSE PRINT 'Fail' ENDIF. Declare every variable, then parallel-trace both with marks 50 and 49.')

## Task two
('Find the translation fault', 'An algorithm says WHILE count < 10; its Java says while (count > 10). Parallel-trace count starting at 0 through both, name the fault, and repair the code.')
