# Translating an Algorithm into Code — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Structure by structure
Sub lesson 1 questions from the type files. Pass mark: Structure by structure — not line by wandering line; Statements in the same order; if…else — the condition in brackets, the branches in braces; Declared in the code before first use, with the types their values need; The code's order and nesting.

## Sub lesson 2 — What translation must never change
Sub lesson 2 questions from the type files. Pass mark: The logic — same steps, same tests, same order; A parallel trace — test values through algorithm and program must agree at every step; A dropped branch; a swapped comparison (also: a loop test turned upside down); In the code, against the algorithm — the algorithm remains the authority; It could not be checked by parallel trace.
