# Translating an Algorithm into Code — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) How is translation worked?**
a) Structure by structure — not line by wandering line  b) Statements in the same order  c) if…else — the condition in brackets, the branches in braces  d) Declared in the code before first use, with the types their values need
**Answer: a) Structure by structure — not line by wandering line**

**2. (Sub lesson 1) A pseudocode sequence becomes what?**
a) if…else — the condition in brackets, the branches in braces  b) Statements in the same order  c) Declared in the code before first use, with the types their values need  d) The code's order and nesting
**Answer: b) Statements in the same order**

**3. (Sub lesson 1) IF…THEN…ELSE becomes what in Java?**
a) Declared in the code before first use, with the types their values need  b) The code's order and nesting  c) if…else — the condition in brackets, the branches in braces  d) The logic — same steps, same tests, same order
**Answer: c) if…else — the condition in brackets, the branches in braces**

**4. (Sub lesson 1) What happens to the algorithm's variables?**
a) The code's order and nesting  b) The logic — same steps, same tests, same order  c) A parallel trace — test values through algorithm and program must agree at every step  d) Declared in the code before first use, with the types their values need
**Answer: d) Declared in the code before first use, with the types their values need**

**5. (Sub lesson 1) In a flowchart, what do the arrows become?**
a) The code's order and nesting  b) The logic — same steps, same tests, same order  c) A parallel trace — test values through algorithm and program must agree at every step  d) A dropped branch; a swapped comparison (also: a loop test turned upside down)
**Answer: a) The code's order and nesting**

**6. (Sub lesson 2) What must translation never change?**
a) A parallel trace — test values through algorithm and program must agree at every step  b) The logic — same steps, same tests, same order  c) A dropped branch; a swapped comparison (also: a loop test turned upside down)  d) In the code, against the algorithm — the algorithm remains the authority
**Answer: b) The logic — same steps, same tests, same order**

**7. (Sub lesson 2) What is Malaysia's check?**
a) A dropped branch; a swapped comparison (also: a loop test turned upside down)  b) In the code, against the algorithm — the algorithm remains the authority  c) A parallel trace — test values through algorithm and program must agree at every step  d) It could not be checked by parallel trace
**Answer: c) A parallel trace — test values through algorithm and program must agree at every step**

**8. (Sub lesson 2) Name two translation faults.**
a) In the code, against the algorithm — the algorithm remains the authority  b) It could not be checked by parallel trace  c) Structure by structure — not line by wandering line  d) A dropped branch; a swapped comparison (also: a loop test turned upside down)
**Answer: d) A dropped branch; a swapped comparison (also: a loop test turned upside down)**

**9. (Sub lesson 2) Where is a disagreement repaired, and against what?**
a) In the code, against the algorithm — the algorithm remains the authority  b) It could not be checked by parallel trace  c) Structure by structure — not line by wandering line  d) Statements in the same order
**Answer: a) In the code, against the algorithm — the algorithm remains the authority**

**10. (Sub lesson 2) Why does this course not write code without an algorithm?**
