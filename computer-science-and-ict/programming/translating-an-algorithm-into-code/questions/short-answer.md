# Translating an Algorithm into Code — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) How is translation worked?**
**Answer: Structure by structure — not line by wandering line**

**2. (Sub lesson 1) A pseudocode sequence becomes what?**
**Answer: Statements in the same order**

**3. (Sub lesson 1) IF…THEN…ELSE becomes what in Java?**
**Answer: if…else — the condition in brackets, the branches in braces**

**4. (Sub lesson 1) What happens to the algorithm's variables?**
**Answer: Declared in the code before first use, with the types their values need**

**5. (Sub lesson 1) In a flowchart, what do the arrows become?**
**Answer: The code's order and nesting**

**6. (Sub lesson 2) What must translation never change?**
**Answer: The logic — same steps, same tests, same order**

**7. (Sub lesson 2) What is Malaysia's check?**
**Answer: A parallel trace — test values through algorithm and program must agree at every step**

**8. (Sub lesson 2) Name two translation faults.**
**Answer: A dropped branch; a swapped comparison (also: a loop test turned upside down)**

**9. (Sub lesson 2) Where is a disagreement repaired, and against what?**
**Answer: In the code, against the algorithm — the algorithm remains the authority**

**10. (Sub lesson 2) Why does this course not write code without an algorithm?**
**Answer: It could not be checked by parallel trace**
