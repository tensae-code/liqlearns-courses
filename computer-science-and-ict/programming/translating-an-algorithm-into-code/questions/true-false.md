# Translating an Algorithm into Code — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "How is translation worked?" is: Structure by structure — not line by wandering line**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "A pseudocode sequence becomes what?" is: if…else — the condition in brackets, the branches in braces**
**Answer: False** — Statements in the same order

**3. (Sub lesson 1) True or false: the answer to "IF…THEN…ELSE becomes what in Java?" is: if…else — the condition in brackets, the branches in braces**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What happens to the algorithm's variables?" is: The code's order and nesting**
**Answer: False** — Declared in the code before first use, with the types their values need

**5. (Sub lesson 1) True or false: the answer to "In a flowchart, what do the arrows become?" is: The code's order and nesting**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What must translation never change?" is: A parallel trace — test values through algorithm and program must agree at every step**

**7. (Sub lesson 2) True or false: the answer to "What is Malaysia's check?" is: A parallel trace — test values through algorithm and program must agree at every step**
