# Recursion and Recursive Functions in Python — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Itself, on a smaller piece of the problem**
**Answer: True**

**2. (Sub lesson 1) True or false: Itself, on a smaller piece of the problem** — as the answer to: Name the two parts of every working recursion.
**Answer: False — The base case and the recursive case**

**3. (Sub lesson 1) True or false: The smallest piece, answered directly, where calls stop**
**Answer: True**

**4. (Sub lesson 1) True or false: The smallest piece, answered directly, where calls stop** — as the answer to: Give factorial's two parts.
**Answer: False — n! = n × (n−1)!; base 0! = 1**

**5. (Sub lesson 1) True or false: Recursion defines a thing by a smaller piece of itself**
**Answer: True**

**6. (Sub lesson 2) True or false: Recursion defines a thing by a smaller piece of itself** — as the answer to: Where do waiting calls wait?
**Answer: False — On the call-stack**

**7. (Sub lesson 2) True or false: The base case answers, and each waiting call completes in turn**
**Answer: True**

**8. (Sub lesson 2) True or false: The base case answers, and each waiting call completes in turn** — as the answer to: What fault gives endless calls?
**Answer: False — No base case, or one never reached**

**9. (Sub lesson 2) True or false: A recursive step that does not shrink the problem**
**Answer: True**

**10. (Sub lesson 2) True or false: A recursive step that does not shrink the problem** — as the answer to: On what data does recursion do its finest work?
**Answer: False — Trees and nested lists — smaller-piece-shaped by nature**
