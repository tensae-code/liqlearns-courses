# DO UNTIL Loop in Visual Basic — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "When does a DO..UNTIL loop repeat?" is: While its condition is false**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "When does it stop?" is: At the top, before each run of the block**
**Answer: False** — The moment its condition becomes true

**3. (Sub lesson 1) True or false: the answer to "Where does the test stand?" is: At the top, before each run of the block**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What happens if the condition is already true at the start?" is: By naming its stopping truth — 'this repeats until …'**
**Answer: False** — The block never runs

**5. (Sub lesson 1) True or false: the answer to "How do you read an UNTIL loop?" is: By naming its stopping truth — 'this repeats until …'**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "State the mirror: DO..WHILE repeats while…" is: By negating the condition — While count <= 10 is Until count > 10**
**Answer: False** — Its condition is true, and stops when it turns false

**7. (Sub lesson 2) True or false: the answer to "How can the same loop be written in the other form?" is: By negating the condition — While count <= 10 is Until count > 10**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "When does UNTIL read more naturally?" is: FOR..NEXT, DO..WHILE, DO..UNTIL**
**Answer: False** — When the loop hunts until a finishing state — until found, until the total reaches the target

**9. (Sub lesson 2) True or false: the answer to "Name Libya's three repetition shapes, in the book's order." is: FOR..NEXT, DO..WHILE, DO..UNTIL**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Write the shape of a DO..UNTIL loop." is: While its condition is false**
**Answer: False** — Do Until condition … Loop
