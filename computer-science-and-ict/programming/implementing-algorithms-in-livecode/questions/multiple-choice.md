# Implementing Algorithms in LiveCode — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a LiveCode program built as?**
a) A stack of cards carrying controls  b) Buttons and fields  c) A script — code answering its events  d) Near-English commands
**Answer: a) A stack of cards carrying controls**

**2. (Sub lesson 1) Name two controls.**
a) A script — code answering its events  b) Buttons and fields  c) Near-English commands  d) The database created earlier in SQLite
**Answer: b) Buttons and fields**

**3. (Sub lesson 1) What does every control hold?**
a) Near-English commands  b) The database created earlier in SQLite  c) A script — code answering its events  d) Translating an algorithm's steps into the tool's objects and scripts
**Answer: c) A script — code answering its events**

**4. (Sub lesson 1) What is LiveCode's language like?**
a) The database created earlier in SQLite  b) Translating an algorithm's steps into the tool's objects and scripts  c) A field  d) Near-English commands
**Answer: d) Near-English commands**

**5. (Sub lesson 1) What stands behind the cards?**
a) The database created earlier in SQLite  b) Translating an algorithm's steps into the tool's objects and scripts  c) A field  d) A script that tests
**Answer: a) The database created earlier in SQLite**

**6. (Sub lesson 2) What does implementing mean?**
a) A field  b) Translating an algorithm's steps into the tool's objects and scripts  c) A script that tests  d) Cases whose answers are known from the algorithm worked by hand
**Answer: b) Translating an algorithm's steps into the tool's objects and scripts**

**7. (Sub lesson 2) What does an input step become?**
a) A script that tests  b) Cases whose answers are known from the algorithm worked by hand  c) A field  d) The implementation, not the algorithm
**Answer: c) A field**

**8. (Sub lesson 2) What becomes of a decision step?**
a) Cases whose answers are known from the algorithm worked by hand  b) The implementation, not the algorithm  c) A stack of cards carrying controls  d) A script that tests
**Answer: d) A script that tests**

**9. (Sub lesson 2) Against what is the program tested?**
a) Cases whose answers are known from the algorithm worked by hand  b) The implementation, not the algorithm  c) A stack of cards carrying controls  d) Buttons and fields
**Answer: a) Cases whose answers are known from the algorithm worked by hand**

**10. (Sub lesson 2) What is debugged first when answers differ?**
a) A stack of cards carrying controls  b) The implementation, not the algorithm  c) Buttons and fields  d) A script — code answering its events
**Answer: b) The implementation, not the algorithm**
