# Program Documentation and the Software Life Cycle — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) Why document a program?**
**Answer: Programs outlive their writers' memories; others must maintain them; users must be told truly what it does**

**2. (Sub lesson 1) Name documentation's categories.**
**Answer: Inside the program (comments, names), the program file, and the user's documentation**

**3. (Sub lesson 1) What is the program file?**
**Answer: The standing dossier — statement, design, code, tests and history**

**4. (Sub lesson 1) Where does Grade 11 teach documentation?**
**Answer: In its algorithms chapter, beside debugging logic errors**

**5. (Sub lesson 1) Which exam chapter assembles it fully?**
**Answer: Greece Grade 12 Anaptyxi Efarmogon, Chapter 14**

**6. (Sub lesson 2) Name the life cycle's stages.**
**Answer: Analysis, design, implementation, testing, release into use, maintenance**

**7. (Sub lesson 2) Which stage is the longest?**
**Answer: Maintenance — fixing faults while the world changes around the program**

**8. (Sub lesson 2) What starts the cycle again?**
**Answer: Replacement**

**9. (Sub lesson 2) What runs through every stage?**
**Answer: Documentation**

**10. (Sub lesson 2) Every earlier chapter of the course is what, in this frame?**
**Answer: One stage's craft**
