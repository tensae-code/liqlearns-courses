# Hands-on — Set Types in Pascal

The lesson with your hands and your feet, not only your eyes.

## Task one
**Membership work** — With vowels as a set of char, trace [a,e,i] + [o] − [e] and the test of 'u' in the result, step by step.

## Task two
**Choose the structure** — For five data (days a course meets, a word's distinct letters, a queue of pupils, the options a buyer ticked, temperatures by hour), choose set, array or record — with the question each must answer.
