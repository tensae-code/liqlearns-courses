# Set Types in Pascal — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a set in Pascal?**
**Answer: A collection of values of one ordinal base type, each present at most once, in no order**

**2. (Sub lesson 1) How is a set type written?**
**Answer: set of <base type> — type TDays = set of TDay;**

**3. (Sub lesson 1) How is a set value written?**
**Answer: In brackets — [Mon, Wed, Fri]; the empty set is []**

**4. (Sub lesson 1) How many different sets can a 7-day base make?**
**Answer: 2⁷ = 128 — every sub-collection**

**5. (Sub lesson 1) What is the only question a set answers?**
**Answer: Membership — whether a value is in it**

**6. (Sub lesson 2) What do +, − and * mean on sets?**
**Answer: Union, difference and intersection**

**7. (Sub lesson 2) What does <= test between sets?**
**Answer: Inclusion — the first is a subset of the second**

**8. (Sub lesson 2) How is membership asked?**
**Answer: With in — if Wed in openDays then …**

**9. (Sub lesson 2) When do sets suit a problem?**
**Answer: When the question is 'which of these?' — not 'how many, in what order?'**

**10. (Sub lesson 2) How does C++ handle sets?**
**Answer: By library classes — it has no built-in set type**
