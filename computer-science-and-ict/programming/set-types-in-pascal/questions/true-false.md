# Set Types in Pascal — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A collection of values of one ordinal base type, each present at most once, in no order**
**Answer: True**

**2. (Sub lesson 1) True or false: A collection of values of one ordinal base type, each present at most once, in no order** — as the answer to: How is a set type written?
**Answer: False — set of <base type> — type TDays = set of TDay;**

**3. (Sub lesson 1) True or false: In brackets — [Mon, Wed, Fri]; the empty set is []**
**Answer: True**

**4. (Sub lesson 1) True or false: In brackets — [Mon, Wed, Fri]; the empty set is []** — as the answer to: How many different sets can a 7-day base make?
**Answer: False — 2⁷ = 128 — every sub-collection**

**5. (Sub lesson 1) True or false: Membership — whether a value is in it**
**Answer: True**

**6. (Sub lesson 2) True or false: Membership — whether a value is in it** — as the answer to: What do +, − and * mean on sets?
**Answer: False — Union, difference and intersection**

**7. (Sub lesson 2) True or false: Inclusion — the first is a subset of the second**
**Answer: True**

**8. (Sub lesson 2) True or false: Inclusion — the first is a subset of the second** — as the answer to: How is membership asked?
**Answer: False — With in — if Wed in openDays then …**

**9. (Sub lesson 2) True or false: When the question is 'which of these?' — not 'how many, in what order?'**
**Answer: True**

**10. (Sub lesson 2) True or false: When the question is 'which of these?' — not 'how many, in what order?'** — as the answer to: How does C++ handle sets?
