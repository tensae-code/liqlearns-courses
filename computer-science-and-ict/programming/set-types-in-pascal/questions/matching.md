# Set Types in Pascal — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What is a set in Pascal?** → **A collection of values of one ordinal base type, each present at most once, in no order**

**2. (Sub lesson 1) How is a set type written?** → **set of <base type> — type TDays = set of TDay;**

**3. (Sub lesson 1) How is a set value written?** → **In brackets — [Mon, Wed, Fri]; the empty set is []**

**4. (Sub lesson 1) How many different sets can a 7-day base make?** → **2⁷ = 128 — every sub-collection**

**5. (Sub lesson 1) What is the only question a set answers?** → **Membership — whether a value is in it**

**6. (Sub lesson 2) What do +, − and * mean on sets?** → **Union, difference and intersection**

**7. (Sub lesson 2) What does <= test between sets?** → **Inclusion — the first is a subset of the second**

**8. (Sub lesson 2) How is membership asked?** → **With in — if Wed in openDays then …**

**9. (Sub lesson 2) When do sets suit a problem?** → **When the question is 'which of these?' — not 'how many, in what order?'**

**10. (Sub lesson 2) How does C++ handle sets?** → **By library classes — it has no built-in set type**
