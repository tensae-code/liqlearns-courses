## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Repetition is a pattern begging to fold** — A passage that **repeats the same blocks** is a pattern, and a pattern can **fold**: ScratchJr's ‘Raccourcir le programme’ séance and Scratch's ‘Raccourcir un programme’ both hunt the same prey — a repeated group, counted, lifted into a **repeat** block with its count. The folded program is not a different program: run both, and the character does exactly the same dance. Shortening is refactoring in miniature: same behaviour, less text, clearer shape.
2. **Why shorter is better — and when it isn't** — Shorter programs are **read at a glance**, **repaired in one place** (fix the group once, not twelve times), and **extended by changing a number**. The séances keep the honesty clause: folding pays only when the repetition is real — different blocks wearing similar shapes must not be forced into one repeat with patches. The programmer's eye trained here — spot repetition, verify sameness, fold — is the same eye that later finds loops, sub-programs and patterns everywhere.
