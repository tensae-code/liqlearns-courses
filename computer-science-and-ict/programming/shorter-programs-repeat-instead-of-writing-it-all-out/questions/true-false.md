# Shorter Programs — Repeat Instead of Writing It All Out — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A passage that repeats the same blocks**
**Answer: True**

**2. (Sub lesson 1) True or false: A passage that repeats the same blocks** — as the answer to: What three steps fold it?
**Answer: False — Find the repeated group, count it, lift it into a repeat block with its count**

**3. (Sub lesson 1) True or false: No — the behaviour is exactly the same**
**Answer: True**

**4. (Sub lesson 1) True or false: No — the behaviour is exactly the same** — as the answer to: What is shortening, in one word?
**Answer: False — Refactoring in miniature**

**5. (Sub lesson 1) True or false: ScratchJr (3e–4e) and Scratch (Grade 7)**
**Answer: True**

**6. (Sub lesson 2) True or false: ScratchJr (3e–4e) and Scratch (Grade 7)** — as the answer to: Name three gains of shorter programs.
**Answer: False — Read at a glance; repaired in one place; extended by changing a number**

**7. (Sub lesson 2) True or false: When the ‘repetition’ is not real — different blocks in similar shapes**
**Answer: True**

**8. (Sub lesson 2) True or false: When the ‘repetition’ is not real — different blocks in similar shapes** — as the answer to: What eye is trained here?
**Answer: False — Spot repetition, verify sameness, fold**

**9. (Sub lesson 2) True or false: Loops, sub-programs and patterns everywhere**
**Answer: True**

**10. (Sub lesson 2) True or false: Loops, sub-programs and patterns everywhere** — as the answer to: How is a repair cheaper after folding?
**Answer: False — Fix the group once, not twelve times**
