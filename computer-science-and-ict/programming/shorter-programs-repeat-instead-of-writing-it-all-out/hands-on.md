# Hands-on — Shorter Programs — Repeat Instead of Writing It All Out

The lesson with your hands and your feet, not only your eyes.

## Task one
**Fold the tail** — Given a long block program with two repeated passages, rewrite it folded with repeats. Run both versions side by side (two tablets/characters) and prove the behaviour identical.

## Task two
**Refuse a fold** — Present a program whose look-alike passages differ subtly (one step differs in the third repetition). Find the difference and write why this one must stay unfolded.
