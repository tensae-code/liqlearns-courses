# Visual Basic — Data Box Controls — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) Name the four data boxes.** → **TextBox, PictureBox, RichTextBox, ImageList**

**2. (Sub lesson 1) What does each hold?** → **TextBox: a typed line. PictureBox: a picture. RichTextBox: rich text. ImageList: a collection of images**

**3. (Sub lesson 1) What file kind does the RichTextBox save and load?** → **RTF files**

**4. (Sub lesson 1) Where does the ImageList keep its images?** → **Off-stage — a store other controls draw from**

**5. (Sub lesson 1) What is the Common Dialog?** → **The familiar window through which the user chooses files for the program**

**6. (Sub lesson 2) What do its Open and saving forms do?** → **Open: choose a file to load. Saving: write the box's content to a named file**

**7. (Sub lesson 2) Why is the dialog taught beside the boxes?** → **A data box without files is a bowl never filled — the data lives on disk**

**8. (Sub lesson 2) Who chooses the file, the program or the user?** → **The user, by their own hand in the dialog**
