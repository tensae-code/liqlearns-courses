# Visual Basic — Data Box Controls — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) Name the four data boxes.**
**Answer: TextBox, PictureBox, RichTextBox, ImageList**

**2. (Sub lesson 1) What does each hold?**
**Answer: TextBox: a typed line. PictureBox: a picture. RichTextBox: rich text. ImageList: a collection of images**

**3. (Sub lesson 1) What file kind does the RichTextBox save and load?**
**Answer: RTF files**

**4. (Sub lesson 1) Where does the ImageList keep its images?**
**Answer: Off-stage — a store other controls draw from**

**5. (Sub lesson 1) What is the Common Dialog?**
**Answer: The familiar window through which the user chooses files for the program**

**6. (Sub lesson 2) What do its Open and saving forms do?**
**Answer: Open: choose a file to load. Saving: write the box's content to a named file**

**7. (Sub lesson 2) Why is the dialog taught beside the boxes?**
**Answer: A data box without files is a bowl never filled — the data lives on disk**

**8. (Sub lesson 2) Who chooses the file, the program or the user?**
**Answer: The user, by their own hand in the dialog**

**9. (Sub lesson 2) Which book and chapter teach this?**
**Answer: Grade 12 Term 2, Book 2 (Controls), Chapter 1 — Data Boxes**

**10. (Sub lesson 2) Which book teaches this?**
**Answer: Kuwait Grade 12 Information Technology Term 2, Book 2 Chapter 1**
