# Visual Basic — Data Box Controls — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: TextBox, PictureBox, RichTextBox, ImageList**
**Answer: True**

**2. (Sub lesson 1) True or false: RTF files** — as the answer to: What does each hold?
**Answer: False — TextBox: a typed line. PictureBox: a picture. RichTextBox: rich text. ImageList: a collection of images**

**3. (Sub lesson 1) True or false: RTF files**
**Answer: True**

**4. (Sub lesson 1) True or false: The familiar window through which the user chooses files for the program** — as the answer to: Where does the ImageList keep its images?
**Answer: False — Off-stage — a store other controls draw from**

**5. (Sub lesson 1) True or false: The familiar window through which the user chooses files for the program**
**Answer: True**

**6. (Sub lesson 2) True or false: A data box without files is a bowl never filled — the data lives on disk** — as the answer to: What do its Open and saving forms do?
**Answer: False — Open: choose a file to load. Saving: write the box's content to a named file**

**7. (Sub lesson 2) True or false: A data box without files is a bowl never filled — the data lives on disk**
**Answer: True**

**8. (Sub lesson 2) True or false: Grade 12 Term 2, Book 2 (Controls), Chapter 1 — Data Boxes** — as the answer to: Who chooses the file, the program or the user?
**Answer: False — The user, by their own hand in the dialog**

**9. (Sub lesson 2) True or false: Grade 12 Term 2, Book 2 (Controls), Chapter 1 — Data Boxes**
**Answer: True**

**10. (Sub lesson 2) True or false: TextBox, PictureBox, RichTextBox, ImageList** — as the answer to: Which book teaches this?
**Answer: False — Kuwait Grade 12 Information Technology Term 2, Book 2 Chapter 1**
