# Video script — Recursion in Nature and Daily Life

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

**Recursion** in the world is the pattern that **contains a smaller copy of itself**: a set of nesting dolls (each doll holds a smaller doll), a tree (each branch splits like a small tree), a river system (each tributary is a small river system), a family tree (each person's ancestors form the same shape), two mirrors facing each other. Armenia teaches the idea of recursion from nature first — Grade 11's Lesson 11 is 'The idea of recursion. Recursion in nature', and Grade 10 gives everyday examples (Lesson 27) before the divide-and-conquer lesson that uses it.
Every worldly recursion **bottoms out**: the innermost doll is solid; the branch ends in twigs and leaves; the ancestor chain reaches people whose parents the tree does not record. That smallest case — the **base case** — is what makes the pattern finite and useful, in nature and in code alike: a recursive program without a base case runs forever, exactly as a family tree with no first generation would. Seeing recursion in the world is therefore not decoration; it is how the two code rules — smaller copy, base case — become unforgettable.
