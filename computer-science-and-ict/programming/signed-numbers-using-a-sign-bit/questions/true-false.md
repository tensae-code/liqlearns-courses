# Signed Numbers — Using a Sign Bit — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The first bit, given to the sign — 0 positive, 1 negative**
**Answer: True**

**2. (Sub lesson 1) True or false: The first bit, given to the sign — 0 positive, 1 negative** — as the answer to: What do the other bits hold?
**Answer: False — The number's magnitude — its size**

**3. (Sub lesson 1) True or false: 10000101**
**Answer: True**

**4. (Sub lesson 1) True or false: 10000101** — as the answer to: How does a reader read a signed register?
**Answer: False — Sign first, then the size**

**5. (Sub lesson 1) True or false: Sign-and-magnitude**
**Answer: True**

**6. (Sub lesson 2) True or false: Sign-and-magnitude** — as the answer to: What are the two zeros?
**Answer: False — +0 (00000000) and −0 (10000000)**

**7. (Sub lesson 2) True or false: A wasted pattern, and confused comparisons**
**Answer: True**

**8. (Sub lesson 2) True or false: A wasted pattern, and confused comparisons** — as the answer to: Why does ordinary addition fail here?
**Answer: False — The sign bit gets added as if it were size**

**9. (Sub lesson 2) True or false: Serve positive and negative arithmetic alike**
**Answer: True**

**10. (Sub lesson 2) True or false: Serve positive and negative arithmetic alike** — as the answer to: Which lesson answers this need?
**Answer: False — The two's complement lesson**
