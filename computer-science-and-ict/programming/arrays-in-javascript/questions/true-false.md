# Arrays in JavaScript — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does a JavaScript array hold?" is: Many values under one name, in order**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "From what number are indexes counted?" is: 60**
**Answer: False** — From 0 — marks[0] is the first value

**3. (Sub lesson 1) True or false: the answer to "In [70, 85, 60, 92], what is marks[2]?" is: 60**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does length count, and what is the last index?" is: undefined — the script does not stop**
**Answer: False** — length counts the values; the last index is length − 1

**5. (Sub lesson 1) True or false: the answer to "An index outside the array answers what?" is: undefined — the script does not stop**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How is every value visited?" is: By assignment — marks[2] = 65;**
**Answer: False** — By a for loop running i from 0 to length − 1

**7. (Sub lesson 2) True or false: the answer to "How is a value replaced?" is: By assignment — marks[2] = 65;**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What do push and pop do?" is: Totalling a class's marks; printing a list of names; finding a highest mark**
**Answer: False** — push adds a value at the end; pop removes from the end

**9. (Sub lesson 2) True or false: the answer to "Name page work Malaysia's scripts do with arrays and loops." is: Totalling a class's marks; printing a list of names; finding a highest mark**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "The array is the script's what, and the loop its what?" is: Many values under one name, in order**
