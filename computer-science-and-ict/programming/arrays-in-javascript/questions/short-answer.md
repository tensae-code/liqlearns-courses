# Arrays in JavaScript — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does a JavaScript array hold?**
**Answer: Many values under one name, in order**

**2. (Sub lesson 1) From what number are indexes counted?**
**Answer: From 0 — marks[0] is the first value**

**3. (Sub lesson 1) In [70, 85, 60, 92], what is marks[2]?**
**Answer: 60**

**4. (Sub lesson 1) What does length count, and what is the last index?**
**Answer: length counts the values; the last index is length − 1**

**5. (Sub lesson 1) An index outside the array answers what?**
**Answer: undefined — the script does not stop**

**6. (Sub lesson 2) How is every value visited?**
**Answer: By a for loop running i from 0 to length − 1**

**7. (Sub lesson 2) How is a value replaced?**
**Answer: By assignment — marks[2] = 65;**

**8. (Sub lesson 2) What do push and pop do?**
**Answer: push adds a value at the end; pop removes from the end**

**9. (Sub lesson 2) Name page work Malaysia's scripts do with arrays and loops.**
**Answer: Totalling a class's marks; printing a list of names; finding a highest mark**

**10. (Sub lesson 2) The array is the script's what, and the loop its what?**
**Answer: Its memory of many — and its way of visiting them all**
