# Arrays in JavaScript — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does a JavaScript array hold?**
a) Many values under one name, in order  b) From 0 — marks[0] is the first value  c) 60  d) length counts the values; the last index is length − 1
**Answer: a) Many values under one name, in order**

**2. (Sub lesson 1) From what number are indexes counted?**
a) 60  b) From 0 — marks[0] is the first value  c) length counts the values; the last index is length − 1  d) undefined — the script does not stop
**Answer: b) From 0 — marks[0] is the first value**

**3. (Sub lesson 1) In [70, 85, 60, 92], what is marks[2]?**
a) length counts the values; the last index is length − 1  b) undefined — the script does not stop  c) 60  d) By a for loop running i from 0 to length − 1
**Answer: c) 60**

**4. (Sub lesson 1) What does length count, and what is the last index?**
a) undefined — the script does not stop  b) By a for loop running i from 0 to length − 1  c) By assignment — marks[2] = 65;  d) length counts the values; the last index is length − 1
**Answer: d) length counts the values; the last index is length − 1**

**5. (Sub lesson 1) An index outside the array answers what?**
a) undefined — the script does not stop  b) By a for loop running i from 0 to length − 1  c) By assignment — marks[2] = 65;  d) push adds a value at the end; pop removes from the end
**Answer: a) undefined — the script does not stop**

**6. (Sub lesson 2) How is every value visited?**
a) By assignment — marks[2] = 65;  b) By a for loop running i from 0 to length − 1  c) push adds a value at the end; pop removes from the end  d) Totalling a class's marks; printing a list of names; finding a highest mark
**Answer: b) By a for loop running i from 0 to length − 1**

**7. (Sub lesson 2) How is a value replaced?**
a) push adds a value at the end; pop removes from the end  b) Totalling a class's marks; printing a list of names; finding a highest mark  c) By assignment — marks[2] = 65;  d) Its memory of many — and its way of visiting them all
**Answer: c) By assignment — marks[2] = 65;**

**8. (Sub lesson 2) What do push and pop do?**
a) Totalling a class's marks; printing a list of names; finding a highest mark  b) Its memory of many — and its way of visiting them all  c) Many values under one name, in order  d) push adds a value at the end; pop removes from the end
**Answer: d) push adds a value at the end; pop removes from the end**

**9. (Sub lesson 2) Name page work Malaysia's scripts do with arrays and loops.**
a) Totalling a class's marks; printing a list of names; finding a highest mark  b) Its memory of many — and its way of visiting them all  c) Many values under one name, in order  d) From 0 — marks[0] is the first value
**Answer: a) Totalling a class's marks; printing a list of names; finding a highest mark**

**10. (Sub lesson 2) The array is the script's what, and the loop its what?**
a) Many values under one name, in order  b) Its memory of many — and its way of visiting them all  c) From 0 — marks[0] is the first value  d) 60
