# Video script — Cleaning and Organising Data

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Real data arrives dirty.
Blanks where values should be. Ages written as words.
The same record twice. A village with three names.
Cleaning repairs each fault by one rule, applied everywhere.
Never invent a value. Mark it missing — honestly.
Clean data is data you can sign your name under.
