# Cleaning and Organising Data — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) The same pupil entered twice is harmless because the data is 'the same'.**
**Answer: False** — A duplicate quietly doubles that record's weight in every count.

**2. (Sub lesson 1) Three spellings of one village will be counted as three villages by a program.**
**Answer: True** — Programs count spellings, not intentions — standardise them.

**3. (Sub lesson 2) Cleaning data is skilled work that decides whether later results can be trusted.**
**Answer: True** — Analysis inherits whatever cleaning did — or failed to do.
