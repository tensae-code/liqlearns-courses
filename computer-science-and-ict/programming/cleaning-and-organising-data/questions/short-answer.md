# Cleaning and Organising Data — short answer

Answer each question in a few sentences.

**1. (Sub lesson 1) A table lists: 'Amina, 15', 'Amina, fifteen', 'Bereket, 32/13/2024', 'Chen, ' (age blank). Name each fault and its repair.**
**Answer:** 'Amina, fifteen' — wrong format: write all ages as numbers (15). The two Amina rows are likely a duplicate: check identifying details and merge/remove one. '32/13/2024' — impossible entry (no 32nd day, no 13th month): return to the source; if unrecoverable, mark missing. Chen's blank age — missing value: recover from the source if possible, otherwise mark clearly as missing — never invent one.

**2. (Sub lesson 2) Why is inventing a plausible value for a missing entry worse than leaving it marked missing?**
**Answer:** Because the invented value enters every later total, average and chart as if it were measured fact — the analysis will repeat the lie with confidence, and nobody can later tell which values were real. A marked gap stays honest: results can note it, and readers can judge how much it matters.
