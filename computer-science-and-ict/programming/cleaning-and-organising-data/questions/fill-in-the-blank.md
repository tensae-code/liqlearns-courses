# Cleaning and Organising Data — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 1) Data with the five faults is called ____ data.**
**Answer: dirty** — 脏数据 — the book's own vivid name.

**2. (Sub lesson 2) The same record entered twice is a ____.**
**Answer: duplicate** — Hunt duplicates by their identifying columns.

**3. (Sub lesson 2) One ____ per record, one column per kind of value — that is an organised table.**
**Answer: row** — Rows are records; columns are kinds.
