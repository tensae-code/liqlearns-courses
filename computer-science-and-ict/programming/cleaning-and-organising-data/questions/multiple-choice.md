# Cleaning and Organising Data — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Which list names faults of dirty data?**
a) Missing values, wrong formats, duplicates, impossible entries, inconsistent spellings  b) Too many charts, slow computers, long files  c) Hard questions, strict teachers, short lessons  d) Old data, new data, foreign data
**Answer: a) Missing values, wrong formats, duplicates, impossible entries, inconsistent spellings** — The five recurring faults.

**2. (Sub lesson 1) An age recorded as 150 is an example of —**
a) a missing value  b) a duplicate  c) an impossible entry  d) a spelling fault
**Answer: c) an impossible entry** — It cannot be true — a slip at entry.

**3. (Sub lesson 2) Cleaning rules should be —**
a) invented cell by cell while working  b) decided before touching the data and applied the same way everywhere  c) kept secret  d) applied only to half the rows
**Answer: b) decided before touching the data and applied the same way everywhere** — Uniform rules are what make the result consistent.

**4. (Sub lesson 2) A value that cannot be recovered from the source should be —**
a) replaced with a likely guess  b) marked clearly as missing  c) set to the average without a note  d) hidden by deleting the row silently
**Answer: b) marked clearly as missing** — An invented value is a lie the analysis repeats with confidence.

**5. (Sub lesson 2) A well-organised dataset has —**
a) many small tables with different shapes  b) one row per record and one column per kind of value  c) no headings  d) mixed formats kept for variety
**Answer: b) one row per record and one column per kind of value** — The shape every later tool expects.
