# Hands-on — Cleaning and Organising Data

The lesson with your hands and your feet, not only your eyes.

## Fault hunt
Take the teacher's messy table. Highlight every fault and label it M (missing), F (format), D (duplicate), I (impossible) or S (spelling). Count how many of each kind the table holds.

## Clean it for real
Write the cleaning rules for that table in five lines — one per fault kind — then apply them and produce the clean table: one row per record, one column per kind of value, missing values marked, nothing invented.
