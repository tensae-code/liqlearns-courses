# Logic of Programming — Foundations

## Do it first

Cuba's Grade 9 programming year opens its second chapter with a question — *¿Qué es la lógica de programación?*, what is programming logic? — before data, variables or flowcharts. The logic is the foundation; everything after it in the book stands on it.

## Sub lesson 1 — What programming logic is

**Programming logic** is the **way of thinking** that turns a problem into something a computer can carry out: state the problem exactly, split it into **steps small enough to be exact**, and put the steps in a **working order**. A logical solution has no gaps and no maybe-steps — every case the problem can meet is decided by the steps themselves. Cuba teaches this as a thing in its own right, language-independent: the same logic is later written as a flowchart, as pseudocode, or in any language.

## Sub lesson 2 — Logic at work — order, exactness, completeness

Logic shows itself in three habits. **Order**: a step that uses a result comes after the step that makes it. **Exactness**: each step names one action the computer can do, with nothing left to guess. **Completeness**: the steps cover the problem's cases — including the awkward ones — not only the easy path. Cuba's chapter order is the logic applied to itself: logic first, then data and types, then variables, then expressions, then counters — each idea standing on the one before.
