# Hands-on — Logic of Programming — Foundations

The lesson with your hands and your feet, not only your eyes.

## Task one
('Logic without a computer', 'Write the exact steps for a daily job (making tea, lending a book) so that someone who has never done it meets no gap and no maybe-step. Trade papers: any step your partner must guess at is a logic fault — fix it.')

## Task two
('Find the missing case', "Take a set of steps that works on the easy path only (for example, steps for dividing sweets among friends): find the awkward case it misses and add the steps that cover it.")
