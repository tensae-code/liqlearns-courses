# Logic of Programming — Foundations — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is programming logic?" is: The clear, ordered thinking a program is built from**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What three things does it do to a problem?" is: Gaps and maybe-steps**
**Answer: False** — States it exactly, splits it into exact steps, orders the steps

**3. (Sub lesson 1) True or false: the answer to "What does a logical solution have none of?" is: Gaps and maybe-steps**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What decides every case in a logical solution?" is: A flowchart, pseudocode, or any language**
**Answer: False** — The steps themselves

**5. (Sub lesson 1) True or false: the answer to "In what forms is the same logic later written?" is: A flowchart, pseudocode, or any language**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Name the three habits of logic at work." is: A step that uses a result comes after the step that makes it**
**Answer: False** — Order, exactness and completeness

**7. (Sub lesson 2) True or false: the answer to "What is the order rule?" is: A step that uses a result comes after the step that makes it**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does exactness demand of each step?" is: All the problem's cases, including the awkward ones**
**Answer: False** — One action the computer can do, nothing left to guess

**9. (Sub lesson 2) True or false: the answer to "What does completeness cover?" is: All the problem's cases, including the awkward ones**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What comes after logic in Cuba's chapter?" is: The clear, ordered thinking a program is built from**
**Answer: False** — Data and types, then variables, expressions and counters
