# The Crane Game — Precise Instructions to Move Things — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The crane (who obeys) and the operator (who instructs)**
**Answer: True**

**2. (Sub lesson 1) True or false: The crane (who obeys) and the operator (who instructs)** — as the answer to: What is the machine's first law here?
**Answer: False — A machine does only what it is told**

**3. (Sub lesson 1) True or false: No — it obeys literally**
**Answer: True**

**4. (Sub lesson 1) True or false: No — it obeys literally** — as the answer to: What plays the crane's jib and claw?
**Answer: False — The pupil's arm and hand**

**5. (Sub lesson 1) True or false: The operator, through the instructions**
**Answer: True**

**6. (Sub lesson 2) True or false: The operator, through the instructions** — as the answer to: What fixes “go down”?
**Answer: False — An amount — “down ten centimetres”**

**7. (Sub lesson 2) True or false: Direction, amount, order**
**Answer: True**

**8. (Sub lesson 2) True or false: Direction, amount, order** — as the answer to: How is a failure repaired?
**Answer: False — Name its vagueness and rewrite the instruction**

**9. (Sub lesson 2) True or false: Debugging**
**Answer: True**

**10. (Sub lesson 2) True or false: Debugging** — as the answer to: In a failure, what was wrong — crane or program?
**Answer: False — The program — never the crane**
