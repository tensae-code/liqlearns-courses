## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The crane obeys literally** — In the **crane game (jeu de la grue)**, one pupil is the crane: eyes perhaps closed, arm as jib, hand as claw, moving only as instructed. The other is the operator, whose instructions must do all the seeing and thinking. The crane teaches the machine's first law in the body: **a machine does only what it is told** — it does not guess what you meant, forgive a vague word, or see the target you forgot to mention.
2. **Precision is a learnable craft** — Failed pickups are the curriculum: “go down” fails where “down ten centimetres” lands; “turn” fails where “turn left” lands. The class repairs each failure by naming its vagueness and rewriting the instruction — direction, amount, order — until the crane succeeds. That repair loop, played at age six, is debugging before the word: the program was wrong, never the crane.
