# Bottom-up — assembling a solution from modules — multiple choice

Pick the one right answer.

**1.** What is bottom-up solving?
a) designing and solving the most fundamental modules first, then integrating them upward into the complete solution  b) if modules with the needed functionality already exist, they are brought together  c) building piece by piece — a habit both approaches rest on  d) testing each piece before moving to the next — a habit both approaches rest on
**Answer: a) designing and solving the most fundamental modules first, then integrating them upward into the complete solution**

**2.** What is existing modules?
a) designing and solving the most fundamental modules first, then integrating them upward into the complete solution  b) building piece by piece — a habit both approaches rest on  c) testing each piece before moving to the next — a habit both approaches rest on  d) if modules with the needed functionality already exist, they are brought together
**Answer: d) if modules with the needed functionality already exist, they are brought together**

**3.** What is incremental development?
a) if modules with the needed functionality already exist, they are brought together  b) testing each piece before moving to the next — a habit both approaches rest on  c) building piece by piece — a habit both approaches rest on  d) designing and solving the most fundamental modules first, then integrating them upward into the complete solution
**Answer: c) building piece by piece — a habit both approaches rest on**

**4.** What is unit testing?
a) building piece by piece — a habit both approaches rest on  b) testing each piece before moving to the next — a habit both approaches rest on  c) designing and solving the most fundamental modules first, then integrating them upward into the complete solution  d) if modules with the needed functionality already exist, they are brought together
**Answer: b) testing each piece before moving to the next — a habit both approaches rest on**

**5.** Bottom-up is the opposite of top-down because it —
a) uses no modules  b) starts with the fundamental modules and builds up  c) tests nothing  d) starts with the whole problem
**Answer: b) starts with the fundamental modules and builds up**

**6.** Most real programs —
a) use top-down only  b) use bottom-up only  c) combine both strategies  d) use neither
**Answer: c) combine both strategies**
