# Bottom-up — assembling a solution from modules — tf

Say whether each statement is true or false.

**1.** True or false: bottom-up solving — designing and solving the most fundamental modules first, then integrating them upward into the complete solution.
**Answer: True**

**2.** True or false: existing modules — if modules with the needed functionality already exist, they are brought together.
**Answer: True**

**3.** True or false: incremental development is the opposite: it has nothing to do with building piece by piece — a habit both approaches rest on.
**Answer: False** — incremental development is about building piece by piece — a habit both approaches rest on.
