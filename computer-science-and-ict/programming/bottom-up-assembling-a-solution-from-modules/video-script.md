# Video script — Bottom-up — assembling a solution from modules

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

This is **Bottom-up — assembling a solution from modules**.

**bottom-up solving** — designing and solving the most fundamental modules first, then integrating them upward into the complete solution.

**existing modules** — if modules with the needed functionality already exist, they are brought together.

**incremental development** — building piece by piece — a habit both approaches rest on.

**unit testing** — testing each piece before moving to the next — a habit both approaches rest on.
