# Algorithms and Their Executors — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What is an executor?** → **The one who carries out an algorithm's instructions**

**2. (Sub lesson 1) What is an executor's command system?** → **The fixed set of commands it understands**

**3. (Sub lesson 1) Name the books' two teaching executors.** → **The Kangaroo and the Ant**

**4. (Sub lesson 1) What is an instruction outside the executor's set?** → **Meaningless to it — the algorithm fails at that line**

**5. (Sub lesson 1) Name two other executors from the lesson.** → **A person following a recipe, and a computer running a program**

**6. (Sub lesson 2) What is manual control?** → **A human gives each command one by one, watching each result**

**7. (Sub lesson 2) What is program control?** → **The whole sequence is written in advance and the executor runs it alone**

**8. (Sub lesson 2) Which is faster and tireless?** → **Program control**

**9. (Sub lesson 2) What is program control's price?** → **Everything must be thought of beforehand — it is only as right as the written sequence**

**10. (Sub lesson 2) Why does programming exist, in the lesson's terms?** → **It frees the human from commanding, step by step**
