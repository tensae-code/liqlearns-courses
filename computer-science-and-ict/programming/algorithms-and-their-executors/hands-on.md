# Hands-on — Algorithms and Their Executors

The lesson with your hands and your feet, not only your eyes.

## Task one
**Executor limits** — Write an algorithm for the Kangaroo using only jump/turn commands; mark any instruction you first wrote that its command set does not hold.

## Task two
**Two controls** — Give a partner a task manually, command by command; then write the same task as a program and compare time, errors and your own effort.
