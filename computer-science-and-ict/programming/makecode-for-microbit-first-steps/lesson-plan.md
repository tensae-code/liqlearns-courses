## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The micro:bit — a small board with features to program** — The **micro:bit** is a small programmable **board**: a grid of **LED lights** it can display pictures and text on, **buttons** it can be pressed by, and **sensors** that feel movement, direction, light and temperature. Every feature is something a program can use — the board is not a toy that happens to light up; it is a computer whose inputs and outputs are visible and touchable.
2. **MakeCode — the browser editor and its simulator** — **MakeCode** is where micro:bit programs are written: it opens **in the browser**, with block families on one side and the program built by dragging them together. Beside the blocks stands the **simulator** — a picture-board on screen that runs the program exactly as the real board would, so work is tested before it is downloaded. Projects are **saved and opened** by name, like any real work: a saved project can be returned to, improved, and finally sent to the board.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
