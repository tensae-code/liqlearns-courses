# MakeCode for micro:bit — First Steps — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A small programmable board — a computer whose inputs and outputs are visible and touchable**
**Answer: True**

**2. (Sub lesson 1) True or false: Displays pictures and text** — as the answer to: Name three of its features a program can use.
**Answer: False — The LED grid, the buttons, and its sensors (any three)**

**3. (Sub lesson 1) True or false: Displays pictures and text**
**Answer: True**

**4. (Sub lesson 1) True or false: In the browser** — as the answer to: What do its sensors feel?
**Answer: False — Movement, direction, light and temperature (any of these)**

**5. (Sub lesson 1) True or false: In the browser**
**Answer: True**

**6. (Sub lesson 2) True or false: A picture-board on screen that runs the program as the real board would** — as the answer to: How are MakeCode programs built?
**Answer: False — By dragging blocks from the block families together**

**7. (Sub lesson 2) True or false: A picture-board on screen that runs the program as the real board would**
**Answer: True**

**8. (Sub lesson 2) True or false: Saved and opened by name** — as the answer to: Why test on the simulator first?
**Answer: False — So work is checked before it is downloaded to the board**

**9. (Sub lesson 2) True or false: Saved and opened by name**
**Answer: True**

**10. (Sub lesson 2) True or false: A small programmable board — a computer whose inputs and outputs are visible and touchable** — as the answer to: Which book teaches this?
**Answer: False — Kuwait Grade 5 Digital Explorer Term 2, Unit 2 Lesson 7**
