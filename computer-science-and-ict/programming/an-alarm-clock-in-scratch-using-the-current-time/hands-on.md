# Hands-on — An Alarm Clock in Scratch — Using the Current Time

The lesson with your hands and your feet, not only your eyes.

## Set an alarm
Build the alarm with its three buttons and set it two minutes ahead. Snooze it once and time the ten minutes’ promise in the code.

## Point the hands
Draw one hand sprite, centre at its end, and point it by the seconds formula; watch it sweep a full circle in a minute.
