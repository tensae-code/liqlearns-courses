# Procedures and Functions — Actual and Formal Parameters — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Does a job — called as a command in its own line; results return through its parameters**
**Answer: True**

**2. (Sub lesson 1) True or false: ΚΑΛΕΣΕ — as a command in its own line** — as the answer to: What does a function do?
**Answer: False — Answers one value — called inside an expression, where a value could stand**

**3. (Sub lesson 1) True or false: ΚΑΛΕΣΕ — as a command in its own line**
**Answer: True**

**4. (Sub lesson 1) True or false: Worked side by side on the same jobs** — as the answer to: How does a procedure hand results back?
**Answer: False — Through its parameters**

**5. (Sub lesson 1) True or false: Worked side by side on the same jobs**
**Answer: True**

**6. (Sub lesson 2) True or false: The caller's variables or values supplied in the call, matched in order** — as the answer to: What are formal parameters?
**Answer: False — The names in the subprogram's heading for the values it will receive**

**7. (Sub lesson 2) True or false: The caller's variables or values supplied in the call, matched in order**
**Answer: True**

**8. (Sub lesson 2) True or false: Formals bound to actuals one by one, by hand** — as the answer to: What must match?
**Answer: False — The counts and the types of actuals and formals**

**9. (Sub lesson 2) True or false: Formals bound to actuals one by one, by hand**
**Answer: True**
