Sub lesson 1 questions from the type files. ## Sub lesson 2 — Costs and the choice — stack depth against clarity
Sub lesson 2 questions from the type files. Pass mark: A stack frame for every pending call — deep recursions can overflow the stack; Overlapping subcalls — the same values recomputed exponentially often; When the problem is self-similar, division is clean and depth is modest; When depth is huge, overlap would repeat work, or the loop is simply plain; By the problem's structure — not by fashion.
