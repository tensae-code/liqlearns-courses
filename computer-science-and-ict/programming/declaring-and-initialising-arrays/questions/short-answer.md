# Declaring and Initialising Arrays — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What three things does an array declaration state?**
**Answer: Type, name and size**

**2. (Sub lesson 1) What kind of value must the size be?**
**Answer: A whole number (a constant in this book's C++)**

**3. (Sub lesson 1) What do uninitialised elements hold?**
**Answer: Whatever was in memory — garbage**

**4. (Sub lesson 1) What must a careful program never do?**
**Answer: Read an element before giving it a value**

**5. (Sub lesson 1) Where does the size sit in the declaration?**
**Answer: In square brackets after the name**

**6. (Sub lesson 2) How does an initialiser list fill the array?**
**Answer: In order, from the first element**

**7. (Sub lesson 2) What happens with a shorter list?**
**Answer: The front is filled and the rest are zeroed**

**8. (Sub lesson 2) What does int a[] = {7, 8, 9} make?**
**Answer: An array of size 3**

**9. (Sub lesson 2) What is listing more values than the size?**
**Answer: An error the compiler catches**

**10. (Sub lesson 2) What values do the unfilled tail elements get?**
**Answer: Zero**
