# Declaring and Initialising Arrays — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What three things does an array declaration state?" is: Type, name and size**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What kind of value must the size be?" is: In square brackets after the name**
**Answer: False** — A whole number (a constant in this book's C++)

**3. (Sub lesson 1) True or false: the answer to "What do uninitialised elements hold?" is: Whatever was in memory — garbage**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What must a careful program never do?" is: The front is filled and the rest are zeroed**
**Answer: False** — Read an element before giving it a value

**5. (Sub lesson 1) True or false: the answer to "Where does the size sit in the declaration?" is: In square brackets after the name**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How does an initialiser list fill the array?" is: An error the compiler catches**
**Answer: False** — In order, from the first element

**7. (Sub lesson 2) True or false: the answer to "What happens with a shorter list?" is: The front is filled and the rest are zeroed**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does int a[] = {7, 8, 9} make?" is: Type, name and size**
**Answer: False** — An array of size 3

**9. (Sub lesson 2) True or false: the answer to "What is listing more values than the size?" is: An error the compiler catches**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What values do the unfilled tail elements get?" is: Whatever was in memory — garbage**
**Answer: False** — Zero
