# Declaring and Initialising Arrays — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What three things does an array declaration state?**
a) Type, name and size  b) A whole number (a constant in this book's C++)  c) Whatever was in memory — garbage  d) Read an element before giving it a value
**Answer: a) Type, name and size**

**2. (Sub lesson 1) What kind of value must the size be?**
a) Whatever was in memory — garbage  b) A whole number (a constant in this book's C++)  c) Read an element before giving it a value  d) In square brackets after the name
**Answer: b) A whole number (a constant in this book's C++)**

**3. (Sub lesson 1) What do uninitialised elements hold?**
a) Read an element before giving it a value  b) In square brackets after the name  c) Whatever was in memory — garbage  d) In order, from the first element
**Answer: c) Whatever was in memory — garbage**

**4. (Sub lesson 1) What must a careful program never do?**
a) In square brackets after the name  b) In order, from the first element  c) The front is filled and the rest are zeroed  d) Read an element before giving it a value
**Answer: d) Read an element before giving it a value**

**5. (Sub lesson 1) Where does the size sit in the declaration?**
a) In square brackets after the name  b) In order, from the first element  c) The front is filled and the rest are zeroed  d) An array of size 3
**Answer: a) In square brackets after the name**

**6. (Sub lesson 2) How does an initialiser list fill the array?**
a) The front is filled and the rest are zeroed  b) In order, from the first element  c) An array of size 3  d) An error the compiler catches
**Answer: b) In order, from the first element**

**7. (Sub lesson 2) What happens with a shorter list?**
a) An array of size 3  b) An error the compiler catches  c) The front is filled and the rest are zeroed  d) Zero
**Answer: c) The front is filled and the rest are zeroed**

**8. (Sub lesson 2) What does int a[] = {7, 8, 9} make?**
a) An error the compiler catches  b) Zero  c) Type, name and size  d) An array of size 3
**Answer: d) An array of size 3**

**9. (Sub lesson 2) What is listing more values than the size?**
a) An error the compiler catches  b) Zero  c) Type, name and size  d) A whole number (a constant in this book's C++)
**Answer: a) An error the compiler catches**

**10. (Sub lesson 2) What values do the unfilled tail elements get?**
a) Type, name and size  b) Zero  c) A whole number (a constant in this book's C++)  d) Whatever was in memory — garbage
**Answer: b) Zero**
