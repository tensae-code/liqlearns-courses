# Hands-on — Declaring and Initialising Arrays

The lesson with your hands and your feet, not only your eyes.

## Three births
Write declarations for: an empty double array of 10; an int array of 4 initialised to 5, 15, 25, 35; an array whose size comes from the list {2, 4, 6, 8, 10}. State every element of the last two.

## Zero-fill check
Predict every element of int b[6] = {3, 1}; then check by printing the array in a run or by the lesson's rule. Write the rule in your own words.
