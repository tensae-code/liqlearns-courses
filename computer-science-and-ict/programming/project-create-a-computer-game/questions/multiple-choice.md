# Project — Create a Computer Game — multiple choice

Pick the one right answer.

**1. A game plan must name —**
a) what the player does, what is scored, and what ends the game  b) only the title  c) the colours only
**Answer: a) what the player does, what is scored, and what ends the game**

**2. The score in the game is held by —**
a) a backdrop  b) a sound  c) a variable
**Answer: c) a variable**

**3. Testing a game means —**
a) never pressing wrong keys  b) playing it as a player, including trying to break it  c) only watching it run once
**Answer: b) playing it as a player, including trying to break it**

**4. The two stocked parts of this project are —**
a) one continuing game build, not two games  b) two unrelated games  c) a game and a typing test
**Answer: a) one continuing game build, not two games**
