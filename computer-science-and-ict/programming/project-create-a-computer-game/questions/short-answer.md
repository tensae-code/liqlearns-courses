# Project — Create a Computer Game — short answer

Answer in a sentence or two.

**1. Explain, in your own words: plan a game: the player's job, the score, and what ends the game.**
**Answer:** The learner's own explanation, true to the lesson: Creating a computer game is Grade 4's long project arc: a school-themed Scratch game planned in parts — sprites under control, variables for score, branches and operators deciding — built, tested and improved over several lessons.

**2. A classmate gets this lesson's work wrong. What is the most likely fault, and how is it fixed?**
**Answer:** Game breaks under testing → that break is the next build task: name the part (control, score, decision), fix that part alone, and test the whole game again.
