# Project — Create a Computer Game — true or false

Say whether each statement is true or false.

**1. Plan a game: the player's job, the score, and what ends the game.**
**Answer: True** — This is one of the lesson's own outcomes.

**2. A game is finished as soon as its parts are built, whether or not anyone has tested playing it.**
**Answer: False** — The lesson teaches the opposite of this.

**3. Build the game in parts from control, variables and decisions.**
**Answer: True** — This is one of the lesson's own outcomes.
