# Hands-on — Project — Create a Computer Game

The lesson with your hands, not only your eyes.

## Plan the game
Write the game plan in three lines: the player does __; the score counts __; the game ends when __. Build part one from the plan and test it as a player.

## Break it kindly
Swap games with a partner and test theirs as a hard player: press wrong keys, miss on purpose. Report one break kindly — then fix one break in your own game.
