# The BASIC Language and the C Language — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: BASIC and C**
**Answer: True**

**2. (Sub lesson 1) True or false: So beginners could write programs at once** — as the answer to: What does BASIC's name stand for?
**Answer: False — Beginner's All-purpose Symbolic Instruction Code**

**3. (Sub lesson 1) True or false: So beginners could write programs at once**
**Answer: True**

**4. (Sub lesson 1) True or false: Visual Basic** — as the answer to: How do BASIC programs usually run?
**Answer: False — Through an interpreter that answers immediately**

**5. (Sub lesson 1) True or false: Visual Basic**
**Answer: True**

**6. (Sub lesson 2) True or false: Direct command of the machine's memory and parts** — as the answer to: What was written in C, first among systems?
**Answer: False — Unix — operating systems are written in C**

**7. (Sub lesson 2) True or false: Direct command of the machine's memory and parts**
**Answer: True**

**8. (Sub lesson 2) True or false: Compiled — translated whole before running** — as the answer to: What does C demand in return?
**Answer: False — Exactness — mistakes at that depth are the programmer's alone**

**9. (Sub lesson 2) True or false: Compiled — translated whole before running**
**Answer: True**

**10. (Sub lesson 2) True or false: BASIC and C** — as the answer to: Which source teaches this lesson?
**Answer: False — Laos Grade 7 ICT teacher guide, Activity 18 (teacher guide — evidence)**
