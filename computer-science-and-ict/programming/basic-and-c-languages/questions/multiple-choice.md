# The BASIC Language and the C Language — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Which two languages share this lesson?**
a) BASIC and C  b) Beginner's All-purpose Symbolic Instruction Code  c) So beginners could write programs at once  d) Through an interpreter that answers immediately

**2. (Sub lesson 1) What does BASIC's name stand for?**
a) So beginners could write programs at once  b) Beginner's All-purpose Symbolic Instruction Code  c) Through an interpreter that answers immediately  d) Visual Basic
**Answer: b**

**3. (Sub lesson 1) What was BASIC designed for?**

**4. (Sub lesson 1) How do BASIC programs usually run?**
