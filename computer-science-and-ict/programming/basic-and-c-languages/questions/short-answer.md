# The BASIC Language and the C Language — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) Which two languages share this lesson?**
**Answer: BASIC and C**

**2. (Sub lesson 1) What does BASIC's name stand for?**
**Answer: Beginner's All-purpose Symbolic Instruction Code**

**3. (Sub lesson 1) What was BASIC designed for?**
**Answer: So beginners could write programs at once**

**4. (Sub lesson 1) How do BASIC programs usually run?**
**Answer: Through an interpreter that answers immediately**

**5. (Sub lesson 1) Which BASIC descendant fills offices?**
**Answer: Visual Basic**

**6. (Sub lesson 2) What was written in C, first among systems?**
**Answer: Unix — operating systems are written in C**

**7. (Sub lesson 2) What does C give the programmer?**
**Answer: Direct command of the machine's memory and parts**

**8. (Sub lesson 2) What does C demand in return?**
**Answer: Exactness — mistakes at that depth are the programmer's alone**

**9. (Sub lesson 2) How do C programs run?**
**Answer: Compiled — translated whole before running**

**10. (Sub lesson 2) Which source teaches this lesson?**
**Answer: Laos Grade 7 ICT teacher guide, Activity 18 (teacher guide — evidence)**
