# Video script — Python Strings — Indexing, Slicing and Methods

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A **string** is text held as a **sequence of characters**, so it is **indexed** from 0 like a list: the first character, the last (counted from the end), each reachable by its number. **Slicing** cuts a **run** of characters out — from this index to before that one — and the book's set work spends it on a real string: **splitting the civil ID number** into its meaningful parts by their positions, the state's own numbers read by the pupil's program.
Strings carry **built-in methods** — named operations the course teaches by set: **capitalize** and **lower** for the text's case, **replace** for swapping one piece for another, **center** for padding a string into a width. And **f-string formatting** builds presentable text by placing **values inside the string itself**, in braces, so a sentence is written once with its numbers living in it — the program's speech, formatted where it is spoken.
