# End-of-Year Project — Flower Animation and Dzongkha Story — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What three things make up the Class V end-of-year piece?**
a) A Scratch flower animation, a Dzongkha story in Word and the year's folder sent by LAN messenger  b) The pen blocks  c) The stem and the petals  d) The looks blocks
**Answer: a) A Scratch flower animation, a Dzongkha story in Word and the year's folder sent by LAN messenger**

**2. (Sub lesson 1) Which block family draws the flower?**
a) The stem and the petals  b) The pen blocks  c) The looks blocks  d) The control blocks
**Answer: b) The pen blocks**

**3. (Sub lesson 1) What do the pen blocks draw as the sprite moves?**
a) The looks blocks  b) The control blocks  c) The stem and the petals  d) Every petal is a planned path drawn by chosen blocks
**Answer: c) The stem and the petals**

**4. (Sub lesson 1) Which blocks change the flower as it opens?**
a) The control blocks  b) Every petal is a planned path drawn by chosen blocks  c) Dzongkha  d) The looks blocks
**Answer: d) The looks blocks**

**5. (Sub lesson 1) Which blocks repeat the drawing until the flower is complete?**
a) The control blocks  b) Every petal is a planned path drawn by chosen blocks  c) Dzongkha  d) Dzongkha keyboard software and Dzongkha fonts
**Answer: a) The control blocks**

**6. (Sub lesson 2) Why is a flower an honest test of the pen?**
a) Dzongkha  b) Every petal is a planned path drawn by chosen blocks  c) Dzongkha keyboard software and Dzongkha fonts  d) In the pupil's own folder
**Answer: b) Every petal is a planned path drawn by chosen blocks**

**7. (Sub lesson 2) In what language is the year's story typed?**
a) Dzongkha keyboard software and Dzongkha fonts  b) In the pupil's own folder  c) Dzongkha  d) As a LAN-messenger attachment
**Answer: c) Dzongkha**

**8. (Sub lesson 2) What software and fonts does the story need?**
a) In the pupil's own folder  b) As a LAN-messenger attachment  c) A Scratch flower animation, a Dzongkha story in Word and the year's folder sent by LAN messenger  d) Dzongkha keyboard software and Dzongkha fonts
**Answer: d) Dzongkha keyboard software and Dzongkha fonts**

**9. (Sub lesson 2) Where is the story saved?**
a) In the pupil's own folder  b) As a LAN-messenger attachment  c) A Scratch flower animation, a Dzongkha story in Word and the year's folder sent by LAN messenger  d) The pen blocks
**Answer: a) In the pupil's own folder**

**10. (Sub lesson 2) How is the folder handed to the teacher?**
a) A Scratch flower animation, a Dzongkha story in Word and the year's folder sent by LAN messenger  b) As a LAN-messenger attachment  c) The pen blocks  d) The stem and the petals
**Answer: b) As a LAN-messenger attachment**
