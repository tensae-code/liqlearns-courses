# End-of-Year Project — Flower Animation and Dzongkha Story — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What three things make up the Class V end-of-year piece?" is: A Scratch flower animation, a Dzongkha story in Word and the year's folder sent by LAN messenger**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Which block family draws the flower?" is: The control blocks**
**Answer: False** — The pen blocks

**3. (Sub lesson 1) True or false: the answer to "What do the pen blocks draw as the sprite moves?" is: The stem and the petals**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Which blocks change the flower as it opens?" is: Dzongkha**
**Answer: False** — The looks blocks

**5. (Sub lesson 1) True or false: the answer to "Which blocks repeat the drawing until the flower is complete?" is: The control blocks**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Why is a flower an honest test of the pen?" is: In the pupil's own folder**
**Answer: False** — Every petal is a planned path drawn by chosen blocks

**7. (Sub lesson 2) True or false: the answer to "In what language is the year's story typed?" is: Dzongkha**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What software and fonts does the story need?" is: A Scratch flower animation, a Dzongkha story in Word and the year's folder sent by LAN messenger**
**Answer: False** — Dzongkha keyboard software and Dzongkha fonts

**9. (Sub lesson 2) True or false: the answer to "Where is the story saved?" is: In the pupil's own folder**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "How is the folder handed to the teacher?" is: The stem and the petals**
**Answer: False** — As a LAN-messenger attachment
