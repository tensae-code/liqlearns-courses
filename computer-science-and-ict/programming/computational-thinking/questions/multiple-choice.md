# Computational thinking — multiple choice

Pick the one right answer.

**1.** What is computational thinking?
a) formulating a problem and expressing its solution so a computer, human or machine can carry it out  b) critical thinking, creativity, collaboration, communication — the learning skills  c) information literacy, media literacy, technology literacy — the literacy skills  d) flexibility, leadership, initiative, productivity, social skills — the life skills
**Answer: a) formulating a problem and expressing its solution so a computer, human or machine can carry it out**

**2.** What is the four Cs?
a) formulating a problem and expressing its solution so a computer, human or machine can carry it out  b) information literacy, media literacy, technology literacy — the literacy skills  c) flexibility, leadership, initiative, productivity, social skills — the life skills  d) critical thinking, creativity, collaboration, communication — the learning skills
**Answer: d) critical thinking, creativity, collaboration, communication — the learning skills**

**3.** What is IMT?
a) critical thinking, creativity, collaboration, communication — the learning skills  b) flexibility, leadership, initiative, productivity, social skills — the life skills  c) information literacy, media literacy, technology literacy — the literacy skills  d) formulating a problem and expressing its solution so a computer, human or machine can carry it out
**Answer: c) information literacy, media literacy, technology literacy — the literacy skills**

**4.** What is FLIPS?
a) information literacy, media literacy, technology literacy — the literacy skills  b) flexibility, leadership, initiative, productivity, social skills — the life skills  c) formulating a problem and expressing its solution so a computer, human or machine can carry it out  d) critical thinking, creativity, collaboration, communication — the learning skills
**Answer: b) flexibility, leadership, initiative, productivity, social skills — the life skills**

**5.** Breaking a problem into simple steps and building them into bigger solutions is —
a) phishing  b) computational thinking  c) data entry  d) optimisation only
**Answer: b) computational thinking**

**6.** Separating trustworthy sources from misinformation is part of —
a) FLIPS  b) the four Cs  c) IMT literacy skills  d) none of them
**Answer: c) IMT literacy skills**
