# Computational thinking — tf

Say whether each statement is true or false.

**1.** True or false: computational thinking — formulating a problem and expressing its solution so a computer, human or machine can carry it out.
**Answer: True**

**2.** True or false: the four Cs — critical thinking, creativity, collaboration, communication — the learning skills.
**Answer: True**

**3.** True or false: IMT is the opposite: it has nothing to do with information literacy, media literacy, technology literacy — the literacy skills.
**Answer: False** — IMT is about information literacy, media literacy, technology literacy — the literacy skills.
