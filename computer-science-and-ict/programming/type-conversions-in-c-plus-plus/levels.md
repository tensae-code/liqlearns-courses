## Sub lesson 1 — Implicit conversion — the compiler's quiet road
Sub lesson 1 questions from the type files. Pass mark: It is widened to double before the operation — 5 + 2.0 = 7.0; An int — its code number; Narrowing — the fraction is cut off: 7.9 becomes 7; Widening; narrowing destroys it — silently; No — at default settings it neither errors nor warns.

## Sub lesson 2 — Explicit conversion — the cast, the programmer's signature
Sub lesson 2 questions from the type files. Pass mark: As a cast — (double) n or double(n); 3.5 — the real division, not the integer 3; Visibility — it signs the intended conversion in the text; No — it converts the value for this operation; the variable keeps its type; Let widening happen; cast every narrowing you mean; never let one happen unmeant.
