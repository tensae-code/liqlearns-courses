# Type Conversions in C++ — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: It is widened to double before the operation — 5 + 2.0 = 7.0**
**Answer: True**

**2. (Sub lesson 1) True or false: It is widened to double before the operation — 5 + 2.0 = 7.0** — as the answer to: What does a char promote to?
**Answer: False — An int — its code number**

**3. (Sub lesson 1) True or false: Narrowing — the fraction is cut off: 7.9 becomes 7**
**Answer: True**

**4. (Sub lesson 1) True or false: Narrowing — the fraction is cut off: 7.9 becomes 7** — as the answer to: Which direction keeps information?
**Answer: False — Widening; narrowing destroys it — silently**

**5. (Sub lesson 1) True or false: No — at default settings it neither errors nor warns**
**Answer: True**

**6. (Sub lesson 2) True or false: No — at default settings it neither errors nor warns** — as the answer to: How is an explicit conversion written?
**Answer: False — As a cast — (double) n or double(n)**

**7. (Sub lesson 2) True or false: 3.5 — the real division, not the integer 3**
**Answer: True**

**8. (Sub lesson 2) True or false: 3.5 — the real division, not the integer 3** — as the answer to: What is the cast's virtue?
**Answer: False — Visibility — it signs the intended conversion in the text**

**9. (Sub lesson 2) True or false: No — it converts the value for this operation; the variable keeps its type**
**Answer: True**

**10. (Sub lesson 2) True or false: No — it converts the value for this operation; the variable keeps its type** — as the answer to: State the section's rule.
**Answer: False — Let widening happen; cast every narrowing you mean; never let one happen unmeant**
