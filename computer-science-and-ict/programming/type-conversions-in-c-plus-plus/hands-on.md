# Hands-on — Type Conversions in C++

The lesson with your hands and your feet, not only your eyes.

## Task one
**Conversion table** — Predict and explain the results: 7/2; 7/2.0; (double)7/2; int x = 9.99; char c = 'A'; int(c) — in a table with the conversion used in each.

## Task two
**Find the loss** — In a program computing an average of integer marks stored into an int, find the conversion that loses the fraction and repair it with a cast.
