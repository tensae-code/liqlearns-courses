# How Computers Represent Data — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is everything represented as inside the computer?" is: Binary patterns of bits**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How many patterns can one byte hold?" is: Its bytes**
**Answer: False** — 256

**3. (Sub lesson 1) True or false: the answer to "What can one byte stand for?" is: A letter, a small number, or part of a bigger value**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Name the size ladder from the lesson." is: By pixels with coded colours**
**Answer: False** — Kilobyte, megabyte, gigabyte

**5. (Sub lesson 1) True or false: the answer to "What is a file's size a count of?" is: Its bytes**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How are characters represented?" is: The same byte can be different things under different schemes**
**Answer: False** — By a character code — each letter a number, stored in binary

**7. (Sub lesson 2) True or false: the answer to "How are images represented?" is: By pixels with coded colours**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How is sound represented?" is: Binary patterns of bits**
**Answer: False** — By coded samples of the wave

**9. (Sub lesson 2) True or false: the answer to "Why is a pattern alone meaningless?" is: The same byte can be different things under different schemes**
**Answer: True**
