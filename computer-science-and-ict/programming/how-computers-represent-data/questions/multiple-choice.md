# How Computers Represent Data — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is everything represented as inside the computer?**
a) Binary patterns of bits  b) 256  c) A letter, a small number, or part of a bigger value  d) Kilobyte, megabyte, gigabyte
**Answer: a) Binary patterns of bits**

**2. (Sub lesson 1) How many patterns can one byte hold?**
a) A letter, a small number, or part of a bigger value  b) 256  c) Kilobyte, megabyte, gigabyte  d) Its bytes
**Answer: b) 256**

**3. (Sub lesson 1) What can one byte stand for?**
a) Kilobyte, megabyte, gigabyte  b) Its bytes  c) A letter, a small number, or part of a bigger value  d) By a character code — each letter a number, stored in binary
**Answer: c) A letter, a small number, or part of a bigger value**

**4. (Sub lesson 1) Name the size ladder from the lesson.**
a) Its bytes  b) By a character code — each letter a number, stored in binary  c) By pixels with coded colours  d) Kilobyte, megabyte, gigabyte
**Answer: d) Kilobyte, megabyte, gigabyte**

**5. (Sub lesson 1) What is a file's size a count of?**
a) Its bytes  b) By a character code — each letter a number, stored in binary  c) By pixels with coded colours  d) By coded samples of the wave
**Answer: a) Its bytes**

**6. (Sub lesson 2) How are characters represented?**
a) By pixels with coded colours  b) By a character code — each letter a number, stored in binary  c) By coded samples of the wave  d) The same byte can be different things under different schemes
**Answer: b) By a character code — each letter a number, stored in binary**

**7. (Sub lesson 2) How are images represented?**
a) By coded samples of the wave  b) The same byte can be different things under different schemes  c) By pixels with coded colours  d) The scheme the program expects
**Answer: c) By pixels with coded colours**

**8. (Sub lesson 2) How is sound represented?**
a) The same byte can be different things under different schemes  b) The scheme the program expects  c) Binary patterns of bits  d) By coded samples of the wave
**Answer: d) By coded samples of the wave**

**9. (Sub lesson 2) Why is a pattern alone meaningless?**
a) The same byte can be different things under different schemes  b) The scheme the program expects  c) Binary patterns of bits  d) 256
**Answer: a) The same byte can be different things under different schemes**

**10. (Sub lesson 2) What decides what a byte means?**
a) Binary patterns of bits  b) The scheme the program expects  c) 256  d) A letter, a small number, or part of a bigger value
**Answer: b) The scheme the program expects**
