# Linear Search — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) How does linear search move?**
a) In order, one item at a time, comparing each with the target  b) The moment an item matches — or the list ends  c) Not found  d) No — linear search works on any list
**Answer: a) In order, one item at a time, comparing each with the target**

**2. (Sub lesson 1) When does the hunt stop?**
a) Not found  b) The moment an item matches — or the list ends  c) No — linear search works on any list  d) Every item is checked — the target last, or absent
**Answer: b) The moment an item matches — or the list ends**

**3. (Sub lesson 1) What is the answer if the end is reached with no match?**
a) No — linear search works on any list  b) Every item is checked — the target last, or absent  c) Not found  d) Position (starting at 1) and found (starting false)
**Answer: c) Not found**

**4. (Sub lesson 1) Must the list be in order?**
a) Every item is checked — the target last, or absent  b) Position (starting at 1) and found (starting false)  c) Found is true, or position passes the list's end  d) No — linear search works on any list
**Answer: d) No — linear search works on any list**

**5. (Sub lesson 1) What is the worst case?**
a) Every item is checked — the target last, or absent  b) Position (starting at 1) and found (starting false)  c) Found is true, or position passes the list's end  d) The comparison — item equals target?
**Answer: a) Every item is checked — the target last, or absent**

**6. (Sub lesson 2) What two values does the pseudocode track?**
a) Found is true, or position passes the list's end  b) Position (starting at 1) and found (starting false)  c) The comparison — item equals target?  d) A trap, not an algorithm
**Answer: b) Position (starting at 1) and found (starting false)**

**7. (Sub lesson 2) What are the loop's two exits?**
a) The comparison — item equals target?  b) A trap, not an algorithm  c) Found is true, or position passes the list's end  d) Position 1
**Answer: c) Found is true, or position passes the list's end**

**8. (Sub lesson 2) What is the decision diamond in the flowchart?**
a) A trap, not an algorithm  b) Position 1  c) In order, one item at a time, comparing each with the target  d) The comparison — item equals target?
**Answer: d) The comparison — item equals target?**

**9. (Sub lesson 2) A search that can only exit on success is what?**
a) A trap, not an algorithm  b) Position 1  c) In order, one item at a time, comparing each with the target  d) The moment an item matches — or the list ends
**Answer: a) A trap, not an algorithm**

**10. (Sub lesson 2) What position does the first item have in Malaysia's pseudocode?**
a) In order, one item at a time, comparing each with the target  b) Position 1  c) The moment an item matches — or the list ends  d) Not found
**Answer: b) Position 1**
