# Choosing the Right Data Type — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What are the first questions of type choice about?**
**Answer: The value — whole or decimal, character or text, truth or not**

**2. (Sub lesson 1) What settles the member within a family?**
**Answer: The value's range**

**3. (Sub lesson 1) What happens when a type is too small?**
**Answer: It overflows — silently wrapping or failing**

**4. (Sub lesson 1) What does too large a type cost?**
**Answer: Merely wasted space**

**5. (Sub lesson 1) State Malaysia's order of choice.**
**Answer: Value first (the family), range second (the member)**

**6. (Sub lesson 2) A phone number belongs in which type, and why?**
**Answer: String — as int it loses its leading zero and invites arithmetic it never needs**

**7. (Sub lesson 2) A mark kept as String cannot be what?**
**Answer: Averaged — it is text, not a number**

**8. (Sub lesson 2) Name a rent wrong choices charge.**
**Answer: Conversions at every use (also: text sorting — '10' before '9'; totals that refuse to add)**

**9. (Sub lesson 2) What is choosing a type, in the lesson's rule?**
**Answer: Choosing what the value can do**

**10. (Sub lesson 2) When and from what is the type decided?**
**Answer: Once, at declaration — from the value's kind and career, not its first value**
