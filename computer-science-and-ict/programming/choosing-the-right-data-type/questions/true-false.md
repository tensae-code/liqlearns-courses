# Choosing the Right Data Type — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What are the first questions of type choice about?" is: The value — whole or decimal, character or text, truth or not**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What settles the member within a family?" is: It overflows — silently wrapping or failing**
**Answer: False** — The value's range

**3. (Sub lesson 1) True or false: the answer to "What happens when a type is too small?" is: It overflows — silently wrapping or failing**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does too large a type cost?" is: Value first (the family), range second (the member)**
**Answer: False** — Merely wasted space

**5. (Sub lesson 1) True or false: the answer to "State Malaysia's order of choice." is: Value first (the family), range second (the member)**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "A phone number belongs in which type, and why?" is: Averaged — it is text, not a number**
**Answer: False** — String — as int it loses its leading zero and invites arithmetic it never needs

**7. (Sub lesson 2) True or false: the answer to "A mark kept as String cannot be what?" is: Averaged — it is text, not a number**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Name a rent wrong choices charge." is: Choosing what the value can do**
**Answer: False** — Conversions at every use (also: text sorting — '10' before '9'; totals that refuse to add)

**9. (Sub lesson 2) True or false: the answer to "What is choosing a type, in the lesson's rule?" is: Choosing what the value can do**
**Answer: True**
