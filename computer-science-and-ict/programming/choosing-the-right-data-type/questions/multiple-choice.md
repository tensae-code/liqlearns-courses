# Choosing the Right Data Type — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What are the first questions of type choice about?**
a) The value — whole or decimal, character or text, truth or not  b) The value's range  c) It overflows — silently wrapping or failing  d) Merely wasted space
**Answer: a) The value — whole or decimal, character or text, truth or not**

**2. (Sub lesson 1) What settles the member within a family?**
a) It overflows — silently wrapping or failing  b) The value's range  c) Merely wasted space  d) Value first (the family), range second (the member)
**Answer: b) The value's range**

**3. (Sub lesson 1) What happens when a type is too small?**
a) Merely wasted space  b) Value first (the family), range second (the member)  c) It overflows — silently wrapping or failing  d) String — as int it loses its leading zero and invites arithmetic it never needs
**Answer: c) It overflows — silently wrapping or failing**

**4. (Sub lesson 1) What does too large a type cost?**
