This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Choose by the value and its range
Sub lesson 1 questions from the type files. Pass mark: The value — whole or decimal, character or text, truth or not; The value's range; It overflows — silently wrapping or failing; Merely wasted space; Value first (the family), range second (the member).

## Sub lesson 2 — Choose by the job — and pay for wrong choices
Sub lesson 2 questions from the type files. Pass mark: String — as int it loses its leading zero and invites arithmetic it never needs; Averaged — it is text, not a number; Conversions at every use (also: text sorting — '10' before '9'; totals that refuse to add); Choosing what the value can do; Once, at declaration — from the value's kind and career, not its first value.
