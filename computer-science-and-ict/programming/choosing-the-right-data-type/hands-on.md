# Hands-on — Choosing the Right Data Type

The lesson with your hands and your feet, not only your eyes.

## Task one
('Choose for a register', 'Choose a Java type for each and defend it: age in years, height in metres, phone number, exam mark out of 100, population of Malaysia, first initial, hasPaid (yes/no), account balance.')

## Task two
('Find the wrong choices', 'A program stores price as String, quantity as double, and a counter of clicks (millions a day) as byte. Name each fault and the repair.')
