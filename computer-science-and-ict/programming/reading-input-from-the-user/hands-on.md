# Hands-on — Reading Input from the User

The lesson with your hands and your feet, not only your eyes.

## Interview program
Write a program that prompts for a name (one word), an age and a mark, then prints one sentence using all three. List the prompt, read and print statements in order.

## Trace the typing
A program runs cin >> a >> b; with int a, b. The user types '7 12' then Enter. State a and b, then say what changes if the user presses Enter between the 7 and the 12 (nothing — explain why).
