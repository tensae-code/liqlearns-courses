# Reading Input from the User — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does cin >> variable do?**
a) Pulls the next typed value into the variable  b) A prompt saying what is expected  c) It is converted to the variable's type  d) From the keyboard stream into the variable
**Answer: a) Pulls the next typed value into the variable**

**2. (Sub lesson 1) What is printed before a read?**
a) It is converted to the variable's type  b) A prompt saying what is expected  c) From the keyboard stream into the variable  d) The program waits in silence; the user cannot tell
**Answer: b) A prompt saying what is expected**

**3. (Sub lesson 1) What happens to the typed text?**
a) From the keyboard stream into the variable  b) The program waits in silence; the user cannot tell  c) It is converted to the variable's type  d) Chained — cin >> a >> b;
**Answer: c) It is converted to the variable's type**

**4. (Sub lesson 1) Which way does >> point?**
a) The program waits in silence; the user cannot tell  b) Chained — cin >> a >> b;  c) By spaces or new lines  d) From the keyboard stream into the variable
**Answer: d) From the keyboard stream into the variable**

**5. (Sub lesson 1) What goes wrong without a prompt?**
a) The program waits in silence; the user cannot tell  b) Chained — cin >> a >> b;  c) By spaces or new lines  d) Prompt, read, decide
**Answer: a) The program waits in silence; the user cannot tell**

**6. (Sub lesson 2) How are two values read in one statement?**
a) By spaces or new lines  b) Chained — cin >> a >> b;  c) Prompt, read, decide  d) After the if-else work (§3.23)
**Answer: b) Chained — cin >> a >> b;**

**7. (Sub lesson 2) How must chained values be separated?**
a) Prompt, read, decide  b) After the if-else work (§3.23)  c) By spaces or new lines  d) Reading a value and deciding on it
**Answer: c) By spaces or new lines**

**8. (Sub lesson 2) What rhythm does the practice set drill?**
a) After the if-else work (§3.23)  b) Reading a value and deciding on it  c) Pulls the next typed value into the variable  d) Prompt, read, decide
**Answer: d) Prompt, read, decide**

**9. (Sub lesson 2) Where does the book place the further practice?**
a) After the if-else work (§3.23)  b) Reading a value and deciding on it  c) Pulls the next typed value into the variable  d) A prompt saying what is expected
**Answer: a) After the if-else work (§3.23)**

**10. (Sub lesson 2) What is the first shape of interactive programs?**
a) Pulls the next typed value into the variable  b) Reading a value and deciding on it  c) A prompt saying what is expected  d) It is converted to the variable's type
**Answer: b) Reading a value and deciding on it**
