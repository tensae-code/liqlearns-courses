# Reading Input from the User — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does cin >> variable do?**
**Answer: Pulls the next typed value into the variable**

**2. (Sub lesson 1) What is printed before a read?**
**Answer: A prompt saying what is expected**

**3. (Sub lesson 1) What happens to the typed text?**
**Answer: It is converted to the variable's type**

**4. (Sub lesson 1) Which way does >> point?**
**Answer: From the keyboard stream into the variable**

**5. (Sub lesson 1) What goes wrong without a prompt?**
**Answer: The program waits in silence; the user cannot tell**

**6. (Sub lesson 2) How are two values read in one statement?**
**Answer: Chained — cin >> a >> b;**

**7. (Sub lesson 2) How must chained values be separated?**
**Answer: By spaces or new lines**

**8. (Sub lesson 2) What rhythm does the practice set drill?**
**Answer: Prompt, read, decide**

**9. (Sub lesson 2) Where does the book place the further practice?**
**Answer: After the if-else work (§3.23)**

**10. (Sub lesson 2) What is the first shape of interactive programs?**
**Answer: Reading a value and deciding on it**
