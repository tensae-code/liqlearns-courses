**The one thing this lesson teaches:** The great division of data: simple data — one value under one name (integer, real, char, boolean) — against structured data, built of many values under one name (arrays, strings, records, sets, files) (Moldova Grade 11, Informatică, §1.1).

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Simple data — one value, one name** — **Simple (scalar) data** holds **one value under one name**: an integer variable holds one whole number, a char one character, a boolean one truth. The simple types met in Grades 7 and 10 — integer, real, char, boolean, the enumerations and subranges — are all simple in this sense, however subtle their internals. A simple value is used **whole**: assigned, compared, computed in one act. Its opposite is not 'easy' but 'assembled' — the division is of structure, not of difficulty.
2. **Structured data — many values, one name, inner order** — **Structured data** gathers **many values under one name**, organised by an inner order the type fixes: an **array** by index, a **string** by position, a **record** by named fields, a **set** by membership, a **file** by sequence. A structured variable is therefore worked **whole or by parts** — the whole array assigned, or its third element singled out. Grade 11's first chapter is the tour of these structures; this section is their map: whenever one name must hold a classful, a text or a table, a structure, not a simple type, is the tool.
