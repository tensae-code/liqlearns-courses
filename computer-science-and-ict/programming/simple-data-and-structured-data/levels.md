# Simple Data and Structured Data — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Simple data — one value, one name
Sub lesson 1 questions from the type files. Pass mark: One value held under one name; Integer, real, char, boolean (and enumerations and subranges); Whole — assigned, compared, computed in one act; No — of 'assembled'; the division is of structure, not difficulty; One.

## Sub lesson 2 — Structured data — many values, one name, inner order
Sub lesson 2 questions from the type files. Pass mark: Many values under one name, organised by an inner order; Arrays, strings, records, sets and files; Array by index, string by position, record by fields, set by membership, file by sequence; Whole, or by parts — its elements singled out; When one name must hold a classful, a text or a table.
