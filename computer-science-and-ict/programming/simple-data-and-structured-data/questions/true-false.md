# Simple Data and Structured Data — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: One value held under one name**
**Answer: True**

**2. (Sub lesson 1) True or false: One value held under one name** — as the answer to: Name the simple types from earlier grades.
**Answer: False — Integer, real, char, boolean (and enumerations and subranges)**

**3. (Sub lesson 1) True or false: Whole — assigned, compared, computed in one act**
**Answer: True**

**4. (Sub lesson 1) True or false: Whole — assigned, compared, computed in one act** — as the answer to: Is 'simple' the opposite of 'hard'?
**Answer: False — No — of 'assembled'; the division is of structure, not difficulty**

**5. (Sub lesson 1) True or false: One**
**Answer: True**

**6. (Sub lesson 2) True or false: One** — as the answer to: What is structured data?
**Answer: False — Many values under one name, organised by an inner order**

**7. (Sub lesson 2) True or false: Arrays, strings, records, sets and files**
**Answer: True**

**8. (Sub lesson 2) True or false: Arrays, strings, records, sets and files** — as the answer to: How is each one organised inside?
**Answer: False — Array by index, string by position, record by fields, set by membership, file by sequence**

**9. (Sub lesson 2) True or false: Whole, or by parts — its elements singled out**
**Answer: True**

**10. (Sub lesson 2) True or false: Whole, or by parts — its elements singled out** — as the answer to: When is a structure the tool?
**Answer: False — When one name must hold a classful, a text or a table**
