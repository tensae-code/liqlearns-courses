# Simple Data and Structured Data — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is simple data?**
**Answer: One value held under one name**

**2. (Sub lesson 1) Name the simple types from earlier grades.**
**Answer: Integer, real, char, boolean (and enumerations and subranges)**

**3. (Sub lesson 1) How is a simple value used?**
**Answer: Whole — assigned, compared, computed in one act**

**4. (Sub lesson 1) Is 'simple' the opposite of 'hard'?**
**Answer: No — of 'assembled'; the division is of structure, not difficulty**

**5. (Sub lesson 1) How many values can a char variable hold at once?**
**Answer: One**

**6. (Sub lesson 2) What is structured data?**
**Answer: Many values under one name, organised by an inner order**

**7. (Sub lesson 2) Name the five structures of the chapter.**
**Answer: Arrays, strings, records, sets and files**

**8. (Sub lesson 2) How is each one organised inside?**
**Answer: Array by index, string by position, record by fields, set by membership, file by sequence**

**9. (Sub lesson 2) How can a structured variable be worked?**
**Answer: Whole, or by parts — its elements singled out**

**10. (Sub lesson 2) When is a structure the tool?**
**Answer: When one name must hold a classful, a text or a table**
