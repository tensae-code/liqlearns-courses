# Character Strings in Pascal and C++ — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A sequence of characters treated as one value**
**Answer: True**

**2. (Sub lesson 1) True or false: A sequence of characters treated as one value** — as the answer to: How is a string written in Pascal and in C++?
**Answer: False — In apostrophes in Pascal ('Ana'); in double quotes in C++ ("Ana")**

**3. (Sub lesson 1) True or false: Its character count — spaces and punctuation included**
**Answer: True**

**4. (Sub lesson 1) True or false: Its character count — spaces and punctuation included** — as the answer to: Is the empty string a proper value?
**Answer: False — Yes — length 0, a value like any other**

**5. (Sub lesson 1) True or false: By their positions — numbered along the string**
**Answer: True**

**6. (Sub lesson 2) True or false: By their positions — numbered along the string** — as the answer to: What is concatenation?
**Answer: False — Joining strings end to end — 'An' + 'a' = 'Ana'**

**7. (Sub lesson 2) True or false: By their characters' codes, position by position — alphabetical order**
**Answer: True**

**8. (Sub lesson 2) True or false: By their characters' codes, position by position — alphabetical order** — as the answer to: What is a substring?
**Answer: False — A part taken from a string — the first letter, the last three characters**

**9. (Sub lesson 2) True or false: Finding a text inside another, and measuring length**
**Answer: True**

**10. (Sub lesson 2) True or false: Finding a text inside another, and measuring length** — as the answer to: Which grade gives the type's full treatment?
**Answer: False — Grade 11 — declarations and library procedures in both languages**
