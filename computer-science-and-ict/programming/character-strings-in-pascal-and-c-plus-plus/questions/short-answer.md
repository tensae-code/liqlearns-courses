# Character Strings in Pascal and C++ — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a character string?**
**Answer: A sequence of characters treated as one value**

**2. (Sub lesson 1) How is a string written in Pascal and in C++?**
**Answer: In apostrophes in Pascal ('Ana'); in double quotes in C++ ("Ana")**

**3. (Sub lesson 1) What is a string's length?**
**Answer: Its character count — spaces and punctuation included**

**4. (Sub lesson 1) Is the empty string a proper value?**
**Answer: Yes — length 0, a value like any other**

**5. (Sub lesson 1) How are a string's characters reached?**
**Answer: By their positions — numbered along the string**

**6. (Sub lesson 2) What is concatenation?**
**Answer: Joining strings end to end — 'An' + 'a' = 'Ana'**

**7. (Sub lesson 2) How are strings compared?**
**Answer: By their characters' codes, position by position — alphabetical order**

**8. (Sub lesson 2) What is a substring?**
**Answer: A part taken from a string — the first letter, the last three characters**

**9. (Sub lesson 2) Name two more string works from the lesson.**
**Answer: Finding a text inside another, and measuring length**

**10. (Sub lesson 2) Which grade gives the type's full treatment?**
**Answer: Grade 11 — declarations and library procedures in both languages**
