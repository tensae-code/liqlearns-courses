# Character Strings in Pascal and C++

## Do it first

Programs speak. Their words are strings — sequences of characters held and worked as single values. Two Moldova books build the string work: Grade 10 writes the string as a vocabulary item, Grade 11 as a full data type.

## Sub lesson 1 — The string — a sequence held as one value

A **character string** is a **sequence of characters treated as one value**: a name, a word, a sentence. It is written between marks — **apostrophes in Pascal** ('Ana'), **double quotes in C++** ("Ana"). Every string has a **length** — its character count, spaces and punctuation included — and the **empty string** ('' or "") of length 0 is a proper value. Its characters stand in **positions**, numbered so each can be reached: the string is one value with reachable parts, like Grade 11's arrays of characters underneath.

## Sub lesson 2 — Working with strings — joining, comparing, taking parts

Strings are **joined** (concatenated) end to end — 'An' + 'a' makes 'Ana' — and **compared** by their characters' codes, position by position, which is alphabetical order for texts. Programs take **parts** of strings (a substring — the first letter, the last three characters), find a text **inside** another, and measure **length** before trusting positions. Grade 11's full treatment adds the type's declarations and its library procedures in both languages; Grade 10's vocabulary section fixes the writing every later use obeys.
