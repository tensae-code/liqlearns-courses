## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Bubble sort — pass by pass** — **Bubble sort** orders an array by **passes**: each pass walks along the array comparing **neighbouring pairs** and **swapping** any pair standing out of order, so the largest unplaced value **bubbles** to its place at the end. Pass follows pass — each shorter than the last, since the tail already stands sorted — until a pass makes **no swaps**, the array's own signal that order is complete. The method is taught by watching it think: trace a five-value array on paper and the sort's patience becomes visible — many small honest steps, none of them clever, arriving together at order.
2. **The full program — and selection sort as your task** — The book writes bubble sort as a **full program**: fill the array, sort it by the pass method, and **print it by a print subprogram** — the subprogram habit of the earlier chapter carrying the sorted result out. Then the book changes its voice: **selection sort** — repeatedly select the smallest remaining value and place it next — is **set as a task**, described by its idea and left to the pupil to build. Mongolia's two-step is the strand's teaching method in miniature: the first algorithm is given whole, traced and understood; the second is earned — the pupil who sorts by selection has stopped copying sorting and started knowing it.
