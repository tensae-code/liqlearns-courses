# Sorting an Array — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does one pass of bubble sort do?**
a) Walks the array swapping neighbouring pairs that stand out of order  b) The largest unplaced value — it bubbles to its place  c) The tail already stands sorted  d) A pass with no swaps
**Answer: a) Walks the array swapping neighbouring pairs that stand out of order**

**2. (Sub lesson 1) Which value settles at each pass's end?**
a) The tail already stands sorted  b) The largest unplaced value — it bubbles to its place  c) A pass with no swaps  d) By tracing it — watching it think on a small array
**Answer: b) The largest unplaced value — it bubbles to its place**

**3. (Sub lesson 1) Why is each pass shorter?**
a) A pass with no swaps  b) By tracing it — watching it think on a small array  c) The tail already stands sorted  d) Fill the array, sort it, print it by a print subprogram
**Answer: c) The tail already stands sorted**

**4. (Sub lesson 1) What signals that sorting is complete?**
a) By tracing it — watching it think on a small array  b) Fill the array, sort it, print it by a print subprogram  c) Repeatedly select the smallest remaining value and place it next  d) A pass with no swaps
**Answer: d) A pass with no swaps**

**5. (Sub lesson 1) How is bubble sort best learned, by the book?**
a) By tracing it — watching it think on a small array  b) Fill the array, sort it, print it by a print subprogram  c) Repeatedly select the smallest remaining value and place it next  d) As the pupil's own task — its idea given, its building left to them
**Answer: a) By tracing it — watching it think on a small array**

**6. (Sub lesson 2) What three parts has the full program?**
a) Repeatedly select the smallest remaining value and place it next  b) Fill the array, sort it, print it by a print subprogram  c) As the pupil's own task — its idea given, its building left to them  d) The first algorithm given whole; the second earned
**Answer: b) Fill the array, sort it, print it by a print subprogram**

**7. (Sub lesson 2) What is selection sort's idea?**
a) As the pupil's own task — its idea given, its building left to them  b) The first algorithm given whole; the second earned  c) Repeatedly select the smallest remaining value and place it next  d) Small Basic
**Answer: c) Repeatedly select the smallest remaining value and place it next**

**8. (Sub lesson 2) How is selection sort set?**
a) The first algorithm given whole; the second earned  b) Small Basic  c) Walks the array swapping neighbouring pairs that stand out of order  d) As the pupil's own task — its idea given, its building left to them
**Answer: d) As the pupil's own task — its idea given, its building left to them**

**9. (Sub lesson 2) State the book's two-step teaching method.**
a) The first algorithm given whole; the second earned  b) Small Basic  c) Walks the array swapping neighbouring pairs that stand out of order  d) The largest unplaced value — it bubbles to its place
**Answer: a) The first algorithm given whole; the second earned**

**10. (Sub lesson 2) Which language are these sorts written in?**
a) Walks the array swapping neighbouring pairs that stand out of order  b) Small Basic  c) The largest unplaced value — it bubbles to its place  d) The tail already stands sorted
**Answer: b) Small Basic**
