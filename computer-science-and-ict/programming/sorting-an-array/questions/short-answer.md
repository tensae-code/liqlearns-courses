# Sorting an Array — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does one pass of bubble sort do?**
**Answer: Walks the array swapping neighbouring pairs that stand out of order**

**2. (Sub lesson 1) Which value settles at each pass's end?**
**Answer: The largest unplaced value — it bubbles to its place**

**3. (Sub lesson 1) Why is each pass shorter?**
**Answer: The tail already stands sorted**

**4. (Sub lesson 1) What signals that sorting is complete?**
**Answer: A pass with no swaps**

**5. (Sub lesson 1) How is bubble sort best learned, by the book?**
**Answer: By tracing it — watching it think on a small array**

**6. (Sub lesson 2) What three parts has the full program?**
**Answer: Fill the array, sort it, print it by a print subprogram**

**7. (Sub lesson 2) What is selection sort's idea?**
**Answer: Repeatedly select the smallest remaining value and place it next**

**8. (Sub lesson 2) How is selection sort set?**
**Answer: As the pupil's own task — its idea given, its building left to them**

**9. (Sub lesson 2) State the book's two-step teaching method.**
**Answer: The first algorithm given whole; the second earned**

**10. (Sub lesson 2) Which language are these sorts written in?**
**Answer: Small Basic**
