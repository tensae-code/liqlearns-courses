# Sorting an Array — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does one pass of bubble sort do?" is: Walks the array swapping neighbouring pairs that stand out of order**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Which value settles at each pass's end?" is: The tail already stands sorted**
**Answer: False** — The largest unplaced value — it bubbles to its place

**3. (Sub lesson 1) True or false: the answer to "Why is each pass shorter?" is: The tail already stands sorted**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What signals that sorting is complete?" is: By tracing it — watching it think on a small array**
**Answer: False** — A pass with no swaps

**5. (Sub lesson 1) True or false: the answer to "How is bubble sort best learned, by the book?" is: By tracing it — watching it think on a small array**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What three parts has the full program?" is: Repeatedly select the smallest remaining value and place it next**
**Answer: False** — Fill the array, sort it, print it by a print subprogram

**7. (Sub lesson 2) True or false: the answer to "What is selection sort's idea?" is: Repeatedly select the smallest remaining value and place it next**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How is selection sort set?" is: The first algorithm given whole; the second earned**
**Answer: False** — As the pupil's own task — its idea given, its building left to them

**9. (Sub lesson 2) True or false: the answer to "State the book's two-step teaching method." is: The first algorithm given whole; the second earned**
**Answer: True**
