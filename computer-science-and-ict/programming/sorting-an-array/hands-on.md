# Hands-on — Sorting an Array

The lesson with your hands and your feet, not only your eyes.

## Task one
('Trace the bubbles', 'Trace bubble sort on the array 5, 2, 4, 1 by hand, pass by pass, writing the array after every swap. Count the passes and the swaps.')

## Task two
('Earn the second sort', 'Write selection sort as a full program with a print subprogram. Run both sorts on the same ten values and verify the outputs agree.')
