# Hands-on — Built-In Functions — Ready-Made Tools

The lesson with your hands and your feet, not only your eyes.

## Task one
**Toolbox census** — In your language, list ten built-in functions and sort them into the four families (mathematics, text, conversion, input/output). Mark the three you use most.

## Task two
**Nest three deep** — Write one line that nests three built-in calls. Under it, write the inside-out order in which they run, with the value each hands to the next.
