## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **What a built-in function is — the language's own toolbox** — A **built-in function** is a function the language itself provides: it exists before your program starts, is called by name with **arguments**, and hands back a **result**. Every language's toolbox differs, but the families repeat: mathematics (`abs`, `round`, `sqrt`), text (`len`, `upper`), conversion (`int`, `str`), and input/output (`print`, `input`). Armenia meets predefined functions in the Grade 7 guide's programme (§21) and opens Grade 12 with them: built-in functions in JavaScript (Lesson 1).
2. **Using them well — nesting, trusting, checking** — Built-ins compose: a result can feed the next call — `int(round(x))` — **nesting** calls inside-out. They are also **trusted but verified**: a built-in does exactly its documented job, so the programmer's duty is to call it with the right kind of argument and to know its edges (what `round` does at .5, what `int` does with text). The professional habit: reach for a built-in before writing your own — a tested tool beats a fresh invention — and read its documentation line before first use, not after the surprise.
