# Built-In Functions — Ready-Made Tools — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a built-in function?**
**Answer: A function the language itself provides — it exists before your program starts**

**2. (Sub lesson 1) How is a built-in function used?**
**Answer: Called by name, with arguments; it hands back a result**

**3. (Sub lesson 1) Name the four families that repeat across languages.**
**Answer: Mathematics, text, conversion, and input/output**

**4. (Sub lesson 1) Give one built-in from the mathematics family.**
**Answer: abs (or round, or sqrt)**

**5. (Sub lesson 1) Where does Armenia open Grade 12?**
**Answer: With built-in functions in JavaScript (Lesson 1)**

**6. (Sub lesson 2) What is nesting?**
**Answer: Feeding one call's result into the next call — int(round(x)) works inside-out**

**7. (Sub lesson 2) What is the programmer's duty with a built-in?**
**Answer: Call it with the right kind of argument, and know its documented edges**

**8. (Sub lesson 2) Why reach for a built-in before writing your own?**
**Answer: It is already tested — a tested tool beats a fresh invention**

**9. (Sub lesson 2) When should you read a built-in's documentation?**
**Answer: Before first use — not after the surprise**

**10. (Sub lesson 2) Give an edge worth knowing.**
**Answer: What round does at exactly .5, or what int does when given text instead of digits**
