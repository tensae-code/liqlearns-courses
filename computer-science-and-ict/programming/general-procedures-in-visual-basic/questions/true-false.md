# General Procedures in Visual Basic — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a procedure?" is: A named block of code that does one job, written once and called by name**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does a Sub procedure do?" is: Works out a value and returns it to the caller**
**Answer: False** — Does the job and returns nothing

**3. (Sub lesson 1) True or false: the answer to "What does a Function procedure do?" is: Works out a value and returns it to the caller**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How does a procedure get the values it needs?" is: So the same procedure works on different data at each call**
**Answer: False** — They are passed in as the call's arguments

**5. (Sub lesson 1) True or false: the answer to "Why pass values in?" is: So the same procedure works on different data at each call**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What are procedures' three gains?" is: Correct the procedure and every call is corrected with it**
**Answer: False** — Write once, fix once, and read clearly

**7. (Sub lesson 2) True or false: the answer to "What does 'fix once' mean?" is: Correct the procedure and every call is corrected with it**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does the calling program say?" is: How the job is done**
**Answer: False** — What happens — the procedure's name

**9. (Sub lesson 2) True or false: the answer to "What does the procedure itself say?" is: How the job is done**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What do procedures turn event code into?" is: A named block of code that does one job, written once and called by name**
**Answer: False** — An organised program
