# General Procedures in Visual Basic — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a procedure?**
**Answer: A named block of code that does one job, written once and called by name**

**2. (Sub lesson 1) What does a Sub procedure do?**
**Answer: Does the job and returns nothing**

**3. (Sub lesson 1) What does a Function procedure do?**
**Answer: Works out a value and returns it to the caller**

**4. (Sub lesson 1) How does a procedure get the values it needs?**
**Answer: They are passed in as the call's arguments**

**5. (Sub lesson 1) Why pass values in?**
**Answer: So the same procedure works on different data at each call**

**6. (Sub lesson 2) What are procedures' three gains?**
**Answer: Write once, fix once, and read clearly**

**7. (Sub lesson 2) What does 'fix once' mean?**
**Answer: Correct the procedure and every call is corrected with it**

**8. (Sub lesson 2) What does the calling program say?**
**Answer: What happens — the procedure's name**

**9. (Sub lesson 2) What does the procedure itself say?**
**Answer: How the job is done**

**10. (Sub lesson 2) What do procedures turn event code into?**
**Answer: An organised program**
