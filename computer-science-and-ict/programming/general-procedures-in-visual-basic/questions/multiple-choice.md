# General Procedures in Visual Basic — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a procedure?**
a) A named block of code that does one job, written once and called by name  b) Does the job and returns nothing  c) Works out a value and returns it to the caller  d) They are passed in as the call's arguments
**Answer: a) A named block of code that does one job, written once and called by name**

**2. (Sub lesson 1) What does a Sub procedure do?**
a) Works out a value and returns it to the caller  b) Does the job and returns nothing  c) They are passed in as the call's arguments  d) So the same procedure works on different data at each call
**Answer: b) Does the job and returns nothing**

**3. (Sub lesson 1) What does a Function procedure do?**
a) They are passed in as the call's arguments  b) So the same procedure works on different data at each call  c) Works out a value and returns it to the caller  d) Write once, fix once, and read clearly
**Answer: c) Works out a value and returns it to the caller**

**4. (Sub lesson 1) How does a procedure get the values it needs?**
a) So the same procedure works on different data at each call  b) Write once, fix once, and read clearly  c) Correct the procedure and every call is corrected with it  d) They are passed in as the call's arguments
**Answer: d) They are passed in as the call's arguments**

**5. (Sub lesson 1) Why pass values in?**
a) So the same procedure works on different data at each call  b) Write once, fix once, and read clearly  c) Correct the procedure and every call is corrected with it  d) What happens — the procedure's name
**Answer: a) So the same procedure works on different data at each call**

**6. (Sub lesson 2) What are procedures' three gains?**
a) Correct the procedure and every call is corrected with it  b) Write once, fix once, and read clearly  c) What happens — the procedure's name  d) How the job is done
**Answer: b) Write once, fix once, and read clearly**

**7. (Sub lesson 2) What does 'fix once' mean?**
a) What happens — the procedure's name  b) How the job is done  c) Correct the procedure and every call is corrected with it  d) An organised program
**Answer: c) Correct the procedure and every call is corrected with it**

**8. (Sub lesson 2) What does the calling program say?**
a) How the job is done  b) An organised program  c) A named block of code that does one job, written once and called by name  d) What happens — the procedure's name
**Answer: d) What happens — the procedure's name**

**9. (Sub lesson 2) What does the procedure itself say?**
a) How the job is done  b) An organised program  c) A named block of code that does one job, written once and called by name  d) Does the job and returns nothing
**Answer: a) How the job is done**

**10. (Sub lesson 2) What do procedures turn event code into?**
a) A named block of code that does one job, written once and called by name  b) An organised program  c) Does the job and returns nothing  d) Works out a value and returns it to the caller
**Answer: b) An organised program**
