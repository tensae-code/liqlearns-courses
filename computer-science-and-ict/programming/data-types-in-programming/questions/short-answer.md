# Data Types in Programming — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a data type?**
**Answer: The kind of a value — what it is and what may be done with it**

**2. (Sub lesson 1) How do numbers split?**
**Answer: Into whole numbers and decimals**

**3. (Sub lesson 1) What is text held as?**
**Answer: Letters, words and symbols as characters**

**4. (Sub lesson 1) What values can a logical value take?**
**Answer: Only true or false**

**5. (Sub lesson 1) Where does Cuba place data types?**
**Answer: After data itself and before variables**

**6. (Sub lesson 2) What is a type, as a contract?**
**Answer: The decision of which operations fit a value**

**7. (Sub lesson 2) What can texts do that numbers do differently?**
**Answer: Be joined, where numbers are added**

**8. (Sub lesson 2) What error does the type prevent?**
**Answer: Treating one kind as another, like adding a text as a number**

**9. (Sub lesson 2) What else does the type decide?**
**Answer: How the value is stored in memory**

**10. (Sub lesson 2) What may a variable hold?**
**Answer: Only values of its declared type**
