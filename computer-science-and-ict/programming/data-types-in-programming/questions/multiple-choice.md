# Data Types in Programming — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a data type?**
a) The kind of a value — what it is and what may be done with it  b) Into whole numbers and decimals  c) Letters, words and symbols as characters  d) Only true or false
**Answer: a) The kind of a value — what it is and what may be done with it**

**2. (Sub lesson 1) How do numbers split?**
a) Letters, words and symbols as characters  b) Into whole numbers and decimals  c) Only true or false  d) After data itself and before variables
**Answer: b) Into whole numbers and decimals**

**3. (Sub lesson 1) What is text held as?**
a) Only true or false  b) After data itself and before variables  c) Letters, words and symbols as characters  d) The decision of which operations fit a value
**Answer: c) Letters, words and symbols as characters**

**4. (Sub lesson 1) What values can a logical value take?**
a) After data itself and before variables  b) The decision of which operations fit a value  c) Be joined, where numbers are added  d) Only true or false
**Answer: d) Only true or false**

**5. (Sub lesson 1) Where does Cuba place data types?**
a) After data itself and before variables  b) The decision of which operations fit a value  c) Be joined, where numbers are added  d) Treating one kind as another, like adding a text as a number
**Answer: a) After data itself and before variables**

**6. (Sub lesson 2) What is a type, as a contract?**
a) Be joined, where numbers are added  b) The decision of which operations fit a value  c) Treating one kind as another, like adding a text as a number  d) How the value is stored in memory
**Answer: b) The decision of which operations fit a value**

**7. (Sub lesson 2) What can texts do that numbers do differently?**
a) Treating one kind as another, like adding a text as a number  b) How the value is stored in memory  c) Be joined, where numbers are added  d) Only values of its declared type
**Answer: c) Be joined, where numbers are added**

**8. (Sub lesson 2) What error does the type prevent?**
a) How the value is stored in memory  b) Only values of its declared type  c) The kind of a value — what it is and what may be done with it  d) Treating one kind as another, like adding a text as a number
**Answer: d) Treating one kind as another, like adding a text as a number**

**9. (Sub lesson 2) What else does the type decide?**
a) How the value is stored in memory  b) Only values of its declared type  c) The kind of a value — what it is and what may be done with it  d) Into whole numbers and decimals
**Answer: a) How the value is stored in memory**

**10. (Sub lesson 2) What may a variable hold?**
a) The kind of a value — what it is and what may be done with it  b) Only values of its declared type  c) Into whole numbers and decimals  d) Letters, words and symbols as characters
**Answer: b) Only values of its declared type**
