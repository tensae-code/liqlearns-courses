# Data Types in Programming — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a data type?" is: The kind of a value — what it is and what may be done with it**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How do numbers split?" is: Letters, words and symbols as characters**
**Answer: False** — Into whole numbers and decimals

**3. (Sub lesson 1) True or false: the answer to "What is text held as?" is: Letters, words and symbols as characters**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What values can a logical value take?" is: After data itself and before variables**
**Answer: False** — Only true or false

**5. (Sub lesson 1) True or false: the answer to "Where does Cuba place data types?" is: After data itself and before variables**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is a type, as a contract?" is: Be joined, where numbers are added**
**Answer: False** — The decision of which operations fit a value

**7. (Sub lesson 2) True or false: the answer to "What can texts do that numbers do differently?" is: Be joined, where numbers are added**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What error does the type prevent?" is: How the value is stored in memory**
**Answer: False** — Treating one kind as another, like adding a text as a number

**9. (Sub lesson 2) True or false: the answer to "What else does the type decide?" is: How the value is stored in memory**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What may a variable hold?" is: The kind of a value — what it is and what may be done with it**
**Answer: False** — Only values of its declared type
