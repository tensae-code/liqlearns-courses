# Video script — Data Types in Programming

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Programs meet the world as **data**, and data comes in kinds. **Numbers** split into whole numbers and decimals — a count of pupils and a measurement are not the same kind. **Text** is letters, words and symbols held as characters. A **logical** value is only ever true or false — the answer to a question the program asks. Cuba names these as *tipos de datos*, the data types, in the same chapter that defines data itself: kind first, then the boxes that hold each kind.
The type is a **contract**. It decides which **operations** fit: numbers can be added, texts can be joined, logical values can be tested — and adding a text as if it were a number is an error the type exists to prevent. It decides how the value is **stored**: each kind takes its own form in memory. And it decides what a **variable** may hold: declare the type, and the box refuses other kinds. Naming the type of every value before writing steps is programming logic doing its work.
