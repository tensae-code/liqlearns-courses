# Hands-on — LOGO procedures — giving a name to a set of commands

The lesson with your hands, not only your eyes.

## Vocabulary game
On paper, invent a procedure name for a job in your home — TEA, SWEEP, GATE — and write its instruction list underneath. Read only the name to a partner; they guess the job from the list you then reveal. Names that describe their job win.

## Retype count
Write the square sequence in full. Count its commands. Now write how many commands five squares would cost with retyping, against five with the word SQUARE defined once. The saving is the procedure's whole point.
