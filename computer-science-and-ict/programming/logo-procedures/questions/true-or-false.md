# LOGO procedures — giving a name to a set of commands — true or false

Say whether each sentence is true or false.

**1.** A procedure name should describe its job.
**Answer: True** — a descriptive one-word name.

**2.** Primitives are procedures the pupil invents.
**Answer: False** — primitives are built in; pupils add their own.

**3.** SQUARE can be run before it is defined.
**Answer: False** — define before use — always.

**4.** Typing commands one by one makes the turtle remember how a shape was made.
**Answer: False** — typing moves the turtle at once but remembers nothing; a procedure makes it remember (Grade 8 growth).
