# LOGO procedures — giving a name to a set of commands — multiple choice

Pick the one right answer.

**1.** A procedure is —
a) one built-in command only  b) a set of instructions given a descriptive one-word name  c) a drawing  d) a password
**Answer: b) a set of instructions given a descriptive one-word name** — a named set of instructions.

**2.** FORWARD is an example of —
a) your own procedure  b) a primitive procedure  c) an error  d) a shape
**Answer: b) a primitive procedure** — built-in commands are primitives.

**3.** Defining a procedure adds —
a) pictures only  b) new words to the language  c) files to the desktop  d) users to the computer
**Answer: b) new words to the language** — you teach Logo new words.

**4.** REPEAT 4 [FORWARD 100 RIGHT 90] draws —
a) a triangle  b) a square  c) a circle  d) a line
**Answer: b) a square** — four equal sides, four right angles.

**5.** If you use a procedure before defining it, LOGO answers —
a) nothing at all  b) that the procedure is not in its vocabulary yet  c) with a drawing anyway  d) by closing
**Answer: b) that the procedure is not in its vocabulary yet** — define before use.

**6.** The point of a procedure is —
a) more typing  b) sparing the typing of the whole set each time  c) hiding commands  d) slowing Logo
**Answer: b) sparing the typing of the whole set each time** — the guide's keyed reason.

**7.** Procedures live in memory as part of a LOGO —
a) printer  b) workspace, which can be saved and loaded like other documents  c) password  d) screen saver
**Answer: b) workspace, which can be saved and loaded like other documents** (Grade 8 growth).

**8.** Every procedure is made with —
a) the word TO plus the name  b) the word GO plus the name  c) PRINT plus the name  d) a space in the name
**Answer: a) the word TO plus the name** — TO SQUARE, TO HOUSE; names have no spaces (Grade 8 growth).
