# LOGO procedures — giving a name to a set of commands — fill in the blank

Fill each blank with the right word.

**1.** A ______ is a set of instructions with one descriptive name.
**Answer: procedure**

**2.** Built-in commands like FORWARD are ______ procedures.
**Answer: primitive**

**3.** ______ 4 [FORWARD 100 RIGHT 90] draws a square.
**Answer: REPEAT**
