# Drawing Shapes with the Graphics Window — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Name the four Draw operations." is: DrawLine, DrawRectangle, DrawTriangle, DrawEllipse**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does DrawTriangle need?" is: Inside a given rectangle's frame**
**Answer: False** — Three given points to join

**3. (Sub lesson 1) True or false: the answer to "Inside what is an ellipse drawn?" is: Inside a given rectangle's frame**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does a Fill operation do?" is: The outlines — their colour and thickness**
**Answer: False** — Paints the shape's inside solid

**5. (Sub lesson 1) True or false: the answer to "What do PenColor and PenWidth rule?" is: The outlines — their colour and thickness**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does BrushColor rule?" is: Before the operation they should dress**
**Answer: False** — The fills

**7. (Sub lesson 2) True or false: the answer to "When must pen and brush be set?" is: Before the operation they should dress**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Does the window remember the settings?" is: A list of shapes, each named, each placed by numbers**
**Answer: False** — Yes — until they are changed

**9. (Sub lesson 2) True or false: the answer to "What is a drawing program, in the lesson's phrase?" is: A list of shapes, each named, each placed by numbers**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is the book's drawing order?" is: DrawLine, DrawRectangle, DrawTriangle, DrawEllipse**
**Answer: False** — Plan shapes, set pen and brush, draw outlines, fill insides
