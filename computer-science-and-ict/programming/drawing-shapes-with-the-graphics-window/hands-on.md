# Hands-on — Drawing Shapes with the Graphics Window

The lesson with your hands and your feet, not only your eyes.

## Task one
('Four shapes', 'Draw a house using all four operations: rectangle walls, triangle roof, ellipse sun, line path. Set a different PenColor for the roof.')

## Task two
('Fill the flag', 'Draw a rectangle, fill it with BrushColor, then outline it with a thick pen. Say which setting dressed which part.')
