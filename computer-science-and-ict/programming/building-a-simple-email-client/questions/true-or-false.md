# Building a Simple Email Client — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Email travels directly from the sender's computer to the receiver's computer with no servers between.**
**Answer: False** — Servers pass it on and hold it in the mailbox.

**2. (Sub lesson 1) POP3 and IMAP are both receiving protocols.**
**Answer: True** — Both pull mail in; SMTP pushes it out.

**3. (Sub lesson 2) A Python email client can be built from the standard library alone.**
**Answer: True** — smtplib, poplib and the email module ship with Python.
