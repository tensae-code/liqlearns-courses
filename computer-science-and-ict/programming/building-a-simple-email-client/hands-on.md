# Hands-on — Building a Simple Email Client

The lesson with your hands and your feet, not only your eyes.

## Sketch the journey
Draw the four stops of an email's journey and label which protocol works at each hop. Then write, under the sketch, where the message waits if the receiver's computer is off for a week — and why it is not lost.

## Build and send
With the teacher's test account, run the sending program: connect, log in, compose a message with subject and body, send it to a classmate's test account. Then run the fetching program on that account and read the message back from your own code.
