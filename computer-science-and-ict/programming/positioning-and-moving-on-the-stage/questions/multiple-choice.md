# Positioning and Moving on the Stage — multiple choice

Pick the one right answer.

**1. Positioning a sprite means —**
a) putting it at an exact chosen place  b) letting it stop anywhere  c) spinning it forever
**Answer: a) putting it at an exact chosen place**

**2. Why place sprites at the start of a scene?**
a) To make the stage bigger  b) To delete the backdrop  c) So the scene starts the same right way every time
**Answer: c) So the scene starts the same right way every time**

**3. A sprite's planned move goes —**
a) off the screen only  b) from one named place to another  c) anywhere at random
**Answer: b) from one named place to another**

**4. If a sprite starts in the wrong place, the fix is —**
a) add the placing step at the script's start  b) buy a bigger screen  c) remove all motion blocks
**Answer: a) add the placing step at the script's start**
