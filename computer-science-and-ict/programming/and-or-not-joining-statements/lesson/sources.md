Placement choice: this lesson was built new for the ICT expansion (Turkmenistan, 2026-11-14) because no existing lesson in the course covers this thing as its own lesson — the live tree was checked first: AND, OR Combining Tests in One If teaches AND/OR inside code for older learners, but no lesson teaches AND, OR and NOT as joining words in plain statements, for a child meeting logic before code. The placements file named this slug directly (NEW LESSON NEEDED — programming/and-or-not-joining-statements). It sits in the Programming title (programming/), where the placements file placed it.

Turkmenistan's own way: in Grade 1's Chapter VI, Logic, the joining words are learned as statements with И, ИЛИ, НЕ (AND, OR, NOT) in plain speech — a child masters 'both', 'at least one' and 'the opposite' years before meeting them inside a program. This lesson keeps that plain-speech order.
