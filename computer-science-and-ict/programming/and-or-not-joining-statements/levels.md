# AND, OR, NOT — Joining Statements — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure). Practice is tied to the learner's skill number, as before. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — AND and OR — joining two statements
Sub lesson 1 questions from the type files. Pass mark: AND joins two statements and needs both of them true — one false part spoils the whole; OR joins two statements and is happy with at least one true part — one true part saves the whole.
## Sub lesson 2 — NOT — the opposite statement
Sub lesson 2 questions from the type files. Pass mark: NOT stands in front of a statement and flips it: if the statement is true, NOT makes it false; if it is false, NOT makes it true — 'the door is open' becomes 'the door is NOT open'.
