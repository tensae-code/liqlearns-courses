# Kinds of IDE — multi-language, mobile, HTML, cloud — true or false

Say whether each sentence is true or false.

**1.** Eclipse and NetBeans are both free and open-source.
**Answer: True** — stated for both.

**2.** Dreamweaver is a multi-language IDE.
**Answer: False** — it is named for HTML/web development.

**3.** IDEs customised for Apple or Microsoft development exist.
**Answer: True** — noted at the section's end.
