# Kinds of IDE — multi-language, mobile, HTML, cloud — fill in the blank

Fill each blank with the right word.

**1.** HomeSite, Dreamweaver and FrontPage serve ______ development.
**Answer: HTML/web**

**2.** Eclipse is directed by the Eclipse.org ______.
**Answer: Consortium**

**3.** Cloud-based IDEs give access to code from ______.
