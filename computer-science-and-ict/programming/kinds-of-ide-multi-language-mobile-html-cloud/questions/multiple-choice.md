# Kinds of IDE — multi-language, mobile, HTML, cloud — multiple choice

Pick the one right answer.

**1.** IDEs divide by —
a) price  b) scope  c) colour  d) age
**Answer: b) scope** — multi-language vs single-purpose.

**2.** Eclipse grows through —
a) modules  b) plugins  c) new computers  d) subscriptions
**Answer: b) plugins** — from its Java beginnings.

**3.** In NetBeans, new languages are added by —
a) installing modules  b) buying a new IDE  c) rewriting it  d) plugins only
**Answer: a) installing modules** — every function comes from interchangeable modules.

**4.** Android Studio serves —
a) mobile development  b) HTML development  c) cloud access  d) all languages equally
**Answer: a) mobile development** — a single-purpose IDE.

**5.** Nitrous is a —
a) mobile IDE  b) cloud-based IDE supporting over 40 languages  c) textbook  d) programming language
**Answer: b) cloud-based IDE supporting over 40 languages** — code from anywhere.
