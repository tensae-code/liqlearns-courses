# Hands-on — Kinds of IDE — multi-language, mobile, HTML, cloud

The lesson with your hands, not only your eyes.

## Bench sort
Cards carry the nine named IDEs. Pupils sort them onto four drawn benches — multi-language, mobile, HTML, cloud — and read one fact per card aloud as it lands.

## Pick for the job
Three job cards: a phone-app maker, a school-website maker, a club coding from many homes. Groups pick an IDE kind and a named IDE for each and defend the picks.
