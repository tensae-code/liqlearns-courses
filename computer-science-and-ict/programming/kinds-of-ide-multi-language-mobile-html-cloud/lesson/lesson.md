# Kinds of IDE — multi-language, mobile, HTML, cloud

## Do it first

Five names: Eclipse, Android Studio, NetBeans, Dreamweaver, Nitrous. Guess a sort: which serve **many languages**, and which serve **one kind of job**? Write your guess with a reason for each. Then read the division and mark your guesses.

## Multi-language IDEs

**Multi-language IDEs** support many languages:

- **Eclipse** — C++, Python, PHP, Java and more; **free and open-source**, grown through **plugins** from its Java beginnings, directed by the **Eclipse.org Consortium**.
- **NetBeans** — Java, JavaScript, PHP, Python, Ruby, C, C++ and more; **free and open-source**; every function is provided by **interchangeable modules**, and new languages are added by installing modules.
- **Komodo** — named in the same family.

## Single-purpose IDEs — one kind of work each

**Single-purpose IDEs** serve one kind of work:

- **Mobile development** — **Android Studio** and **Visual Studio**.
- **HTML/web development** — **HomeSite, Dreamweaver and FrontPage**, automating website tasks.
- **Cloud-based IDEs** — giving access to code **from anywhere**; **Nitrous** is named, supporting **over 40 languages** including PHP, Ruby, Python, JavaScript with Node.js, and Go.

IDEs **customised for Apple or Microsoft development** are also noted.
