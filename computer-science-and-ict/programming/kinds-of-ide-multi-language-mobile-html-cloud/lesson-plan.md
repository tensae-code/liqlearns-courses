# Lesson plan — Kinds of IDE — multi-language, mobile, HTML, cloud

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** Kinds of IDE — multi-language, mobile, HTML, cloud
**Place in the curriculum:** Unit 6 — Fundamentals of Programming (CURRICULUM.md).
**The one thing this lesson teaches:** IDEs divide by scope: multi-language IDEs such as Eclipse and NetBeans serve many languages, while single-purpose IDEs serve one kind of work — mobile, HTML/web, or cloud-based development.
**This lesson's own level:** it stands on the two IDE lessons before it — what an IDE is, and why it is used. It needs nothing else.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons

## Before this lesson
- Recommended first: The IDE — one home for editing, compiling, debugging, and Benefits of an IDE. Recommended, never forced.

## What the learner can do when it ends
1. Divide IDEs by scope: multi-language vs single-purpose.
2. Name Eclipse and NetBeans with their growth mechanism (plugins; modules) and free/open-source standing.
3. Name the single-purpose families: mobile, HTML/web, cloud — with their example IDEs.

## What you need
Paper and a pencil. Nothing else.

## If the learner is stuck
- Sorts by price → the division taught is by scope: how many languages / what kind of work — and both named multi-language IDEs happen to be free.
- Thinks cloud IDEs support few languages → Nitrous alone supports over 40; cloud is about where the code is reached from, not how much it holds.
