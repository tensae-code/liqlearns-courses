# Hands-on — One-Dimensional Arrays

The lesson with your hands and your feet, not only your eyes.

## Replace the crowd
Write the five-variable version of storing five scores and printing their total. Then write the array-and-loop version. Count the lines of each and state the difference.

## Element map
Draw int a[6] as six boxes. Put values in them, then write down what a[0], a[3] and a[5] hold and what the array's name and size are.
