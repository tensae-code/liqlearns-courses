# One-Dimensional Arrays — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does an array declaration give?" is: A type, one name and a size**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is one value in an array called?" is: Yes — it can be assigned, read and computed with**
**Answer: False** — An element

**3. (Sub lesson 1) True or false: the answer to "How are elements stored?" is: Side by side in memory, in one row**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What can select an element that separate names cannot?" is: Read all, print all, total all (any three loop jobs)**
**Answer: False** — A variable holding the position

**5. (Sub lesson 1) True or false: the answer to "Is each element a full variable?" is: Yes — it can be assigned, read and computed with**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What visits every element with the same code?" is: A data structure**
**Answer: False** — A loop

**7. (Sub lesson 2) True or false: the answer to "Name three jobs one loop can do over an array." is: Read all, print all, total all (any three loop jobs)**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How many lines serve five thousand elements?" is: A type, one name and a size**
**Answer: False** — The same few lines that serve five

**9. (Sub lesson 2) True or false: the answer to "What is an array in the family of programming ideas?" is: A data structure**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why does the book spend many sections on arrays?" is: Side by side in memory, in one row**
**Answer: False** — They change what programs can do with collections
