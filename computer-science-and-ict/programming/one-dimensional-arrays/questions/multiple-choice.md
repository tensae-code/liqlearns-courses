# One-Dimensional Arrays — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does an array declaration give?**
a) A type, one name and a size  b) An element  c) Side by side in memory, in one row  d) A variable holding the position
**Answer: a) A type, one name and a size**

**2. (Sub lesson 1) What is one value in an array called?**
a) Side by side in memory, in one row  b) An element  c) A variable holding the position  d) Yes — it can be assigned, read and computed with
**Answer: b) An element**

**3. (Sub lesson 1) How are elements stored?**
a) A variable holding the position  b) Yes — it can be assigned, read and computed with  c) Side by side in memory, in one row  d) A loop
**Answer: c) Side by side in memory, in one row**

**4. (Sub lesson 1) What can select an element that separate names cannot?**
a) Yes — it can be assigned, read and computed with  b) A loop  c) Read all, print all, total all (any three loop jobs)  d) A variable holding the position
**Answer: d) A variable holding the position**

**5. (Sub lesson 1) Is each element a full variable?**
a) Yes — it can be assigned, read and computed with  b) A loop  c) Read all, print all, total all (any three loop jobs)  d) The same few lines that serve five
**Answer: a) Yes — it can be assigned, read and computed with**

**6. (Sub lesson 2) What visits every element with the same code?**
a) Read all, print all, total all (any three loop jobs)  b) A loop  c) The same few lines that serve five  d) A data structure
**Answer: b) A loop**

**7. (Sub lesson 2) Name three jobs one loop can do over an array.**
a) The same few lines that serve five  b) A data structure  c) Read all, print all, total all (any three loop jobs)  d) They change what programs can do with collections
**Answer: c) Read all, print all, total all (any three loop jobs)**

**8. (Sub lesson 2) How many lines serve five thousand elements?**
a) A data structure  b) They change what programs can do with collections  c) A type, one name and a size  d) The same few lines that serve five
**Answer: d) The same few lines that serve five**

**9. (Sub lesson 2) What is an array in the family of programming ideas?**
a) A data structure  b) They change what programs can do with collections  c) A type, one name and a size  d) An element
**Answer: a) A data structure**

**10. (Sub lesson 2) Why does the book spend many sections on arrays?**
a) A type, one name and a size  b) They change what programs can do with collections  c) An element  d) Side by side in memory, in one row
**Answer: b) They change what programs can do with collections**
