# Making Your Own Blocks in Scratch — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is defining your own block?**
a) Naming a stack and keeping it as a block  b) “Square” and “sum”  c) Draw any size, or add any pair  d) “Draw the triangle”
**Answer: a) Naming a stack and keeping it as a block**

**2. (Sub lesson 1) Which two blocks does the book define?**
a) Number inputs  b) “Square” and “sum”  c) Like any built-in block  d) The two sides
**Answer: b) “Square” and “sum”**

**3. (Sub lesson 1) What do the defined blocks take?**
a) Draw any size, or add any pair  b) “Draw the triangle”  c) Number inputs  d) Any right-angled triangle the program names
**Answer: c) Number inputs**

**4. (Sub lesson 1) What does an input let one block do?**
a) Like any built-in block  b) The two sides  c) In the if-statement lesson’s program  d) Draw any size, or add any pair
**Answer: d) Draw any size, or add any pair**

**5. (Sub lesson 1) How is your block used once defined?**
a) Like any built-in block  b) “Draw the triangle”  c) Any right-angled triangle the program names  d) Inside the custom block
**Answer: a) Like any built-in block**

**6. (Sub lesson 2) What is the triangle block called?**
