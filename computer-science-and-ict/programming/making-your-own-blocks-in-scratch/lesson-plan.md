# Lesson plan — Making Your Own Blocks in Scratch

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** Making Your Own Blocks in Scratch
**Place in the curriculum:** ICT expansion — Palestine (2026-11-14) — in the title Programming on the ICT course ladder (TITLES.md). Built new from Palestine's Grade 9 Programming student book, because no existing lesson in the course covers this thing as its own lesson.
**The one thing this lesson teaches:** Your own block is defined once — a name, and number inputs if it needs them — and then used like any built-in block: the book defines “square” and “sum”, and a “draw the triangle” block taking the two sides as inputs.
**This lesson's own level:** It stands on the earlier lessons of its title and on the book's own order — it follows the book's lessons in sequence, so its neighbours in the book are its natural companions. It stands alone for a learner landing on it directly.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Defining your own block — “square” and “sum”** — **Defining your own block** means naming a stack and keeping it as a block: the book defines **“square”** and **“sum”**, each **with number inputs**, so the same block draws any size of square or adds any pair. Once defined, your block is **used like any built-in block**.
2. **A custom block with inputs — draw the triangle** — The triangle build shows why inputs matter: a custom **“draw the triangle” block taking the two sides as inputs** draws any right-angled triangle the main program names — the checking of Pythagoras happens in the lesson on the if statement, and the drawing lives inside the custom block, called with each new pair of sides.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## The run of the lesson (in order)
1. **Do it first** — You have drawn the same square eleven times. Scratch lets you name that stack once — “square” — with a hole for the side’s size, and then use your own block like any block Scratch came with. Grade 9’s additional-blocks lesson is the course’s graduation in tool-making. (lesson/lesson.md).
2. **The explanation** — the lesson text in lesson/lesson.md, in its parts in order.
   - ADD IMAGE: a picture of defining your own block — “square” and “sum” as the lesson describes it — the student studies the picture and names what each part shows.
   - ADD GIF: a GIF of a custom block with inputs — draw the triangle in action — the student watches once, then says what changed and why.
   - ADD AUDIO: a voice reading the lesson's key names and definitions aloud, in the order the lesson gives them — the student listens once through, then reads the same lines aloud along with the voice. (Audio is a described slot in this build; no audio file is made.)
