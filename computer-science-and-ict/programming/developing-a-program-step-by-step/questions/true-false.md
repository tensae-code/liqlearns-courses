# Developing a Program Step by Step — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What are the development steps, in order?" is: Understand the problem, plan the steps, build the program, test it, fix what the tests expose**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What must be understood first?" is: Pseudocode or flowchart — the algorithm**
**Answer: False** — What the program must do — what goes in and what must come out

**3. (Sub lesson 1) True or false: the answer to "In what forms is the plan written?" is: Pseudocode or flowchart — the algorithm**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Why build from a plan?" is: After understanding and planning — third, not first**
**Answer: False** — A planned program can be checked against its plan; a guessed one only against another guess

**5. (Sub lesson 1) True or false: the answer to "When is the program built?" is: After understanding and planning — third, not first**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How is a program tested?" is: A fault found — located and fixed, not a failure of the whole work**
**Answer: False** — Run with known inputs whose right outputs are worked out by hand, and compare

**7. (Sub lesson 2) True or false: the answer to "What is a mismatch in testing?" is: A fault found — located and fixed, not a failure of the whole work**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "After a fix, which tests are run again?" is: When the tests pass and the program does the understood problem's job**
**Answer: False** — All of them — including ones that passed, because a fix can break a neighbour

**9. (Sub lesson 2) True or false: the answer to "When does development end?" is: When the tests pass and the program does the understood problem's job**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What does skipping steps cause?" is: Understand the problem, plan the steps, build the program, test it, fix what the tests expose**
**Answer: False** — Programs that fail — the staircase exists because each step feeds the next
