# Developing a Program Step by Step — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Understand and plan before building
Sub lesson 1 questions from the type files. Pass mark: Understand the problem, plan the steps, build the program, test it, fix what the tests expose; What the program must do — what goes in and what must come out; Pseudocode or flowchart — the algorithm; A planned program can be checked against its plan; a guessed one only against another guess; After understanding and planning — third, not first.

## Sub lesson 2 — Test, fix, and test again
Sub lesson 2 questions from the type files. Pass mark: Run with known inputs whose right outputs are worked out by hand, and compare; A fault found — located and fixed, not a failure of the whole work; All of them — including ones that passed, because a fix can break a neighbour; When the tests pass and the program does the understood problem's job; Programs that fail — the staircase exists because each step feeds the next.
