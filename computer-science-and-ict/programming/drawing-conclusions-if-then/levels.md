# Drawing Conclusions — If… Then… — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure). Practice is tied to the learner's skill number, as before. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — If… then… — a conclusion that follows
Sub lesson 1 questions from the type files. Pass mark: A conclusion joins two judgements with if and then: if the first judgement is so, then the second follows — 'if it rains, then the ground gets wet' — and the conclusion is only as good as its first part.
## Sub lesson 2 — Composing judgements from pictures
Sub lesson 2 questions from the type files. Pass mark: A picture shows judgements waiting to be said: look at what is in the picture, say the judgement it shows, then draw the conclusion — from a child holding an umbrella under dark clouds: if the clouds bring rain, then the umbrella keeps the child dry.
