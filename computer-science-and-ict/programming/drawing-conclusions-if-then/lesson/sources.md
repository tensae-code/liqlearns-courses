Placement choice: this lesson was built new for the ICT expansion (Turkmenistan, 2026-11-14) because no existing lesson in the course covers this thing as its own lesson — the live tree was checked first: The If Statement — Do It Only If True teaches the if of Python code for older learners, but no lesson teaches drawing conclusions with if… then… in words and from pictures, as a first logic step. The placements file named this slug directly (NEW LESSON NEEDED — programming/drawing-conclusions-if-then). It sits in the Programming title (programming/), where the placements file placed it.

Turkmenistan's own way: Chapter VI, Logic, closes by drawing conclusions — logical judgements and conclusions in plain words, and judgements composed from pictures — so a six-year-old practises if… then… thinking long before meeting an if in code; the same chapter's closing exercises even play IF… THEN… ELSE with pen and pencil choices. This lesson keeps the words-and-pictures order.
