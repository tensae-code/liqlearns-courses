# Drawing Conclusions — If… Then… — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) In 'if it rains, then the ground gets wet', the rain is the if part.**
**Answer: True** — Rain comes first; wet ground follows it.

**2. (Sub lesson 1) The then part can be anything you like, even if it does not follow.**
**Answer: False** — A conclusion's then part must truly follow from its if part.

**3. (Sub lesson 2) A picture can be read by composing judgements from what it shows.**
**Answer: True** — Name what is shown, say the judgement, then conclude.

**4. (Sub lesson 2) Swapping the if and then parts never changes a conclusion.**
**Answer: False** — Order is the conclusion's spine: poured water also makes ground wet, so the swapped version can be wrong.
