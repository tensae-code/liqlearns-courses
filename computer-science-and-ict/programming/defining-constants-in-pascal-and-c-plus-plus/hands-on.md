# Hands-on — Defining Constants in Pascal and C++

The lesson with your hands and your feet, not only your eyes.

## Task one
**Constant census** — Rewrite a given program replacing every repeated bare fact (π, class size, pass mark) with named constants in both languages.

## Task two
**One-edit test** — Take a program with a tax rate written in six places; convert it to a const, change the rate once, and list what would have been missed the old way.
