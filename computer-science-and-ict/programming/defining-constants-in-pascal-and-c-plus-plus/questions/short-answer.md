# Defining Constants in Pascal and C++ — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a constant definition?**
**Answer: A name bound to a value that never changes in the run**

**2. (Sub lesson 1) Where does Pascal gather constants?**
**Answer: In a const section**

**3. (Sub lesson 1) How does C++ declare a typed constant?**
**Answer: With const before the declaration — const double pi = 3.14159;**

**4. (Sub lesson 1) What happens if a program assigns to a constant?**
**Answer: A compile error — the compiler guards the name**

**5. (Sub lesson 1) What is #define's weakness for constants?**
**Answer: It names without a type**

**6. (Sub lesson 2) Name the three reasons for constants.**
**Answer: Readability, one place of truth, safety**

**7. (Sub lesson 2) What does 'one place of truth' prevent?**
**Answer: Hunting forty lines when a fact changes — and missing one**

**8. (Sub lesson 2) What do const, type and var sections form together?**
**Answer: The program's front matter — its data's constitution**

**9. (Sub lesson 2) Can a constant's value differ between runs?**
**Answer: No — it is fixed in the text (unlike input data)**

**10. (Sub lesson 2) What does a bare 10 not say that maxMark says?**
**Answer: What the number means — its role in the problem**
