Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What is a constant definition?** → **A name bound to a value that never changes in the run**

**3. (Sub lesson 1) How does C++ declare a typed constant?** → **With const before the declaration — const double pi = 3.14159;**

**4. (Sub lesson 1) What happens if a program assigns to a constant?** → **A compile error — the compiler guards the name**

**5. (Sub lesson 1) What is #define's weakness for constants?** → **It names without a type**
