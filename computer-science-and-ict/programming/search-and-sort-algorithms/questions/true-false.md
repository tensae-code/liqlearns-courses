# Search and Sort Algorithms — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What two jobs does this chapter study?" is: Searching — finding where a value is; sorting — putting values in order**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does a search take, and what does it answer?" is: Yes — a good search can always give it and never hunts forever**
**Answer: False** — A list and a target value; it answers the target's position, or that it is not there

**3. (Sub lesson 1) True or false: the answer to "Is 'not found' a complete answer?" is: Yes — a good search can always give it and never hunts forever**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "By what is a search characterised?" is: One by one from the start; or by halving the field**
**Answer: False** — What it may assume (such as an ordered list) and how it moves

**5. (Sub lesson 1) True or false: the answer to "Name two ways a search can move." is: One by one from the start; or by halving the field**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does a sort do?" is: Exactly the values it started with — nothing lost, nothing added**
**Answer: False** — Rearranges a list into order — ascending or descending

**7. (Sub lesson 2) True or false: the answer to "What must a sorted list still hold?" is: Exactly the values it started with — nothing lost, nothing added**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "By what is a sort characterised?" is: They are partners — the fastest searches require an ordered list**
**Answer: False** — Its movement pattern — comparisons, swaps, what is set aside and reinserted

**9. (Sub lesson 2) True or false: the answer to "Why are search and sort taught together?" is: They are partners — the fastest searches require an ordered list**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What can pay for many searches?" is: Searching — finding where a value is; sorting — putting values in order**
**Answer: False** — Sorting once
