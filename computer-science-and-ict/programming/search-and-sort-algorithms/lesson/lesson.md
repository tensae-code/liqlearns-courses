# Search and Sort Algorithms

## Do it first

Two jobs return in almost every program: find the thing, and put things in order. Malaysia's Grade 9 algorithms chapter studies searching and sorting as families with characters of their own. In this lesson you learn what each family does — and how an algorithm's character is described.

## Sub lesson 1 — Search — finding where a value is

A **search algorithm** takes a **list** and a **target value** and answers: **where** is the target — its position — or that it is **not there**. Searching is characterised by what it may assume (must the list already be in order for this method to work?) and by how it moves (one by one from the start, or by halving the field). The answer's shape matters: 'not found' is a complete answer, and a good search can always give it — it never hunts forever.

## Sub lesson 2 — Sort — putting values in order

A **sort algorithm** rearranges a list into **order** — ascending or descending — moving nothing out and losing nothing: the sorted list holds exactly the values it started with, re-sequenced. Sorting is characterised by its **movement pattern**: which neighbours are compared, what is swapped, what is set aside and reinserted. Malaysia teaches search and sort together because they are partners: an ordered list is what the fastest searches require, so sorting once can pay for many searches.
