# Hands-on — Programming a Robot From a Distance — Bugs and Telegraphy

The lesson with your hands and your feet, not only your eyes.

## Task one
**Telegraph a robot** — One pair operates a “robot” pupil behind a screen, by written order slips only, one batch per run. Keep every slip. Afterwards, reconstruct from the log where the fault entered.

## Task two
**One change per message** — Continue the mission: each new batch may change exactly one instruction. The class watches whether diagnosis speeds up or slows down.
