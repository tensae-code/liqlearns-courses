# Programming a Robot From a Distance — Bugs and Telegraphy — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Commanding an automaton from a distance, by sent messages**
**Answer: True**

**2. (Sub lesson 1) True or false: Commanding an automaton from a distance, by sent messages** — as the answer to: What can you not do at a distance?
**Answer: False — Point, or correct mid-run**

**3. (Sub lesson 1) True or false: The whole intention**
**Answer: True**

**8. (Sub lesson 2) True or false: The sent program — your copy** — as the answer to: How many things change per new message?
