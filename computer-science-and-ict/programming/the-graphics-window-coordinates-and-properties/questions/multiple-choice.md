# The Graphics Window — Coordinates and Properties — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is the GraphicsWindow?**
a) Small Basic's drawing object — the program's canvas  b) x (rightward) and y (downward)  c) At the top-left corner  d) Downwards — the screen's way
**Answer: a) Small Basic's drawing object — the program's canvas**

**2. (Sub lesson 1) What two coordinates name a point?**
a) At the top-left corner  b) x (rightward) and y (downward)  c) Downwards — the screen's way  d) As an order in x and y coordinates
**Answer: b) x (rightward) and y (downward)**

**3. (Sub lesson 1) Where is the origin (0, 0)?**
a) Downwards — the screen's way  b) As an order in x and y coordinates  c) At the top-left corner  d) Width, Height and Title (any three of: BackgroundColor)
**Answer: c) At the top-left corner**

**4. (Sub lesson 1) Which way does y grow?**
a) As an order in x and y coordinates  b) Width, Height and Title (any three of: BackgroundColor)  c) Pixels  d) Downwards — the screen's way
**Answer: d) Downwards — the screen's way**

**5. (Sub lesson 1) How is every drawing command given?**
a) As an order in x and y coordinates  b) Width, Height and Title (any three of: BackgroundColor)  c) Pixels  d) Like variables of the window — GraphicsWindow.Width = 600
**Answer: a) As an order in x and y coordinates**

**6. (Sub lesson 2) Name three window properties set before drawing.**
a) Pixels  b) Width, Height and Title (any three of: BackgroundColor)  c) Like variables of the window — GraphicsWindow.Width = 600  d) No drawing command can be understood until the grid it lands on is
**Answer: b) Width, Height and Title (any three of: BackgroundColor)**

**7. (Sub lesson 2) In what unit are Width and Height measured?**
a) Like variables of the window — GraphicsWindow.Width = 600  b) No drawing command can be understood until the grid it lands on is  c) Pixels  d) The paper the draughtsman chooses before the picture

**8. (Sub lesson 2) How are properties written in code?**
a) No drawing command can be understood until the grid it lands on is  b) The paper the draughtsman chooses before the picture  c) Small Basic's drawing object — the program's canvas  d) Like variables of the window — GraphicsWindow.Width = 600

**9. (Sub lesson 2) Why are canvas and coordinates taught before shapes?**
a) No drawing command can be understood until the grid it lands on is  b) The paper the draughtsman chooses before the picture  c) Small Basic's drawing object — the program's canvas  d) x (rightward) and y (downward)

**10. (Sub lesson 2) What is the canvas, in the lesson's phrase?**
