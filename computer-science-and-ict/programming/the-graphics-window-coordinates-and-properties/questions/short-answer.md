# The Graphics Window — Coordinates and Properties — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is the GraphicsWindow?**
**Answer: Small Basic's drawing object — the program's canvas**

**2. (Sub lesson 1) What two coordinates name a point?**
**Answer: x (rightward) and y (downward)**

**3. (Sub lesson 1) Where is the origin (0, 0)?**
**Answer: At the top-left corner**

**4. (Sub lesson 1) Which way does y grow?**
**Answer: Downwards — the screen's way**

**5. (Sub lesson 1) How is every drawing command given?**
**Answer: As an order in x and y coordinates**

**6. (Sub lesson 2) Name three window properties set before drawing.**
**Answer: Width, Height and Title (any three of: BackgroundColor)**

**7. (Sub lesson 2) In what unit are Width and Height measured?**
**Answer: Pixels**

**8. (Sub lesson 2) How are properties written in code?**
**Answer: Like variables of the window — GraphicsWindow.Width = 600**

**9. (Sub lesson 2) Why are canvas and coordinates taught before shapes?**
**Answer: No drawing command can be understood until the grid it lands on is**

**10. (Sub lesson 2) What is the canvas, in the lesson's phrase?**
**Answer: The paper the draughtsman chooses before the picture**
