# Binary Arithmetic — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure). Practice is tied to the learner's skill number, as before. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Binary addition, complements and negative numbers
Sub lesson 1 questions from the type files. Pass mark: add two binary numbers of four or more bits with carries, form the ones' and two's complement of a number, and write a negative number in two's complement for a stated bit length.

## Sub lesson 2 — Subtraction, multiplication and division
Sub lesson 2 questions from the type files. Pass mark: subtract by adding the two's complement and discarding the final carry, multiply two binary numbers by shift-and-add, and divide a binary number by another showing quotient and remainder.
