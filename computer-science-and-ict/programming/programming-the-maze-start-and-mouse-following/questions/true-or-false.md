# Programming the Maze — Start, and Mouse Following — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) The backdrop switches to Maze 1 as part of the start.**
**Answer: True** — Position and backdrop together make the reset.

**2. (Sub lesson 2) The player steers the character with the mouse pointer.**
**Answer: True** — The character follows the pointer.

**3. (Sub lesson 2) The wall test needs checking only once, at the start.**
**Answer: False** — It must watch while the character follows the pointer.
