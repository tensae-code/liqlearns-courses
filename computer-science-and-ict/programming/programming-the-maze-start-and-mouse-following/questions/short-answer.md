# Programming the Maze — Start, and Mouse Following — short answer

Answer in a sentence or two.

**1. (Sub lesson 1) A game ends with the character deep in Maze 2. The player clicks the flag. Describe exactly what resets and why.**
**Answer:** A sound answer: the character goes to its start position and the stage switches to Maze 1, so the new game begins in the same known state as every other run.

**2. (Sub lesson 2) Why does the character wait for the mouse before following?**
**Answer:** A sound answer: so the game does not start moving before the player is ready and has brought the pointer to the character; the wait makes the start of play the player's act.
