# Programming the Maze — Start, and Mouse Following — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) The start situation on the green flag does two things —**
a) Character to start position, stage to Maze 1  b) Deletes Maze 2, adds sound  c) Hides the character, stops music
**Answer: a) Character to start position, stage to Maze 1** — Reset position and backdrop, every run.

**2. (Sub lesson 1) Resetting on the flag matters because —**
a) Every new game must begin in the same state  b) The flag is decorative  c) Mazs cannot be replayed
**Answer: a) Every new game must begin in the same state** — Identical beginnings make replays fair.

**3. (Sub lesson 2) Before following, the character —**
a) Waits for the mouse pointer  b) Wins  c) Changes costume
**Answer: a) Waits for the mouse pointer** — It waits at the start for the pointer.

**4. (Sub lesson 2) Touching a wall —**
a) Scores a point  b) Ends the game  c) Opens Maze 2
**Answer: b) Ends the game** — The wall touch ends the game.

**5. (Sub lesson 2) Touching the goal —**
a) Ends the game as a loss  b) Changes the level  c) Hides the goal
**Answer: b) Changes the level** — Goal touch advances to the next maze.
