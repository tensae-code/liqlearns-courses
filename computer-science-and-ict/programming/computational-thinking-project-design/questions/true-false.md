# Computational Thinking — Designing a Project — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A problem worth solving, stated in one sentence**
**Answer: True**

**2. (Sub lesson 1) True or false: A problem worth solving, stated in one sentence** — as the answer to: What does decomposition do to a project?
**Answer: False — It breaks it into parts small enough to build one at a time**

**3. (Sub lesson 1) True or false: Repeated parts — one solution can serve every place the pattern appears**
**Answer: True**

**4. (Sub lesson 1) True or false: Repeated parts — one solution can serve every place the pattern appears** — as the answer to: What does abstraction decide for each part?
**Answer: False — What the part must show to others, and what it may hide inside**

**5. (Sub lesson 1) True or false: The design — computational thinking is used to design the project before building**
**Answer: True**

**6. (Sub lesson 2) True or false: The design — computational thinking is used to design the project before building** — as the answer to: What should the written design list?
**Answer: False — The parts in build order, what each part needs from the others, and how the result will be checked**

**7. (Sub lesson 2) True or false: Against the problem it set out to solve**
**Answer: True**

**8. (Sub lesson 2) True or false: Against the problem it set out to solve** — as the answer to: When should parts be tested?
**Answer: False — As they are built — not only at the end**

**9. (Sub lesson 2) True or false: Who does what, and what 'finished' looks like for each part**
**Answer: True**

**10. (Sub lesson 2) True or false: Who does what, and what 'finished' looks like for each part** — as the answer to: Why write the design down at all?
**Answer: False — So the plan can be shared, checked and followed — not held in one head**
