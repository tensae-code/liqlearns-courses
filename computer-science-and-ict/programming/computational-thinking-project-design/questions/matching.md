# Computational Thinking — Designing a Project — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What does a project design start with?** → **A problem worth solving, stated in one sentence**

**2. (Sub lesson 1) What does decomposition do to a project?** → **It breaks it into parts small enough to build one at a time**

**3. (Sub lesson 1) What does pattern recognition save?** → **Repeated parts — one solution can serve every place the pattern appears**

**4. (Sub lesson 1) What does abstraction decide for each part?** → **What the part must show to others, and what it may hide inside**

**5. (Sub lesson 1) In Armenia's Grade 5 book, what comes first — the design or the building?** → **The design — computational thinking is used to design the project before building**

**6. (Sub lesson 2) What should the written design list?** → **The parts in build order, what each part needs from the others, and how the result will be checked**

**7. (Sub lesson 2) Against what is the finished project checked?** → **Against the problem it set out to solve**

**8. (Sub lesson 2) When should parts be tested?** → **As they are built — not only at the end**

**9. (Sub lesson 2) What does a good design say about team work?** → **Who does what, and what 'finished' looks like for each part**

**10. (Sub lesson 2) Why write the design down at all?** → **So the plan can be shared, checked and followed — not held in one head**
