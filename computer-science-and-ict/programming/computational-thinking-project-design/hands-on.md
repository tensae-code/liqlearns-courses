# Hands-on — Computational Thinking — Designing a Project

The lesson with your hands and your feet, not only your eyes.

## Task one
**Design a class project** — Choose a small real problem (a lost-property box list, a class library). Write its one-sentence problem, decompose it into at most five parts, and mark any pattern that repeats.

## Task two
**Check plan** — For your design, write how you will check the finished project against the problem — three checks a user can actually do.
