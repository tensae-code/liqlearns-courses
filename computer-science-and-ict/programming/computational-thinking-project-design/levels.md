# Computational Thinking — Designing a Project — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — From a problem to a design — decompose and pattern-spot
Sub lesson 1 questions from the type files. Pass mark: A problem worth solving, stated in one sentence; It breaks it into parts small enough to build one at a time; Repeated parts — one solution can serve every place the pattern appears; What the part must show to others, and what it may hide inside; The design — computational thinking is used to design the project before building.

## Sub lesson 2 — The design on paper — steps, parts and a check
Sub lesson 2 questions from the type files. Pass mark: The parts in build order, what each part needs from the others, and how the result will be checked; Against the problem it set out to solve; As they are built — not only at the end; Who does what, and what 'finished' looks like for each part; So the plan can be shared, checked and followed — not held in one head.
