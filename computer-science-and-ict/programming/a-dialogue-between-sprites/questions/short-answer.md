# A Dialogue Between Sprites — short answer

Answer in a sentence or two.

**1. Explain, in your own words: build a two-sprite dialogue where the sprites speak in turn.**
**Answer:** The learner's own explanation, true to the lesson: A dialogue is sprites speaking in turn: one says its line, waits, the other answers — timed say blocks and waits make a conversation, like the dolphins' talk.

**2. A classmate gets this lesson's work wrong. What is the most likely fault, and how is it fixed?**
**Answer:** Sprites talk over each other → a wait is missing or too short: set each wait to match the partner's speaking time, then read the whole dialogue aloud as it runs.
