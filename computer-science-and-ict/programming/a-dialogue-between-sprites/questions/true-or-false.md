# A Dialogue Between Sprites — true or false

Say whether each statement is true or false.

**1. Build a two-sprite dialogue where the sprites speak in turn.**
**Answer: True** — This is one of the lesson's own outcomes.

**2. A dialogue works best when both sprites say all their lines at the same time.**
**Answer: False** — The lesson teaches the opposite of this.

**3. Use timed say blocks and waits so nobody talks over anyone.**
**Answer: True** — This is one of the lesson's own outcomes.
