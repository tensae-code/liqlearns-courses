# A Dialogue Between Sprites — multiple choice

Pick the one right answer.

**1. A dialogue needs sprites to speak —**
a) in turn  b) all at once  c) never
**Answer: a) in turn**

**2. The block that keeps the second sprite silent while the first speaks is —**
a) pen down  b) switch costume  c) wait
**Answer: c) wait**

**3. Lines in a say block for a dialogue should last —**
a) forever  b) long enough to read  c) as short as possible
**Answer: b) long enough to read**

**4. The book's dialogue example is a conversation between —**
a) dolphins  b) robots  c) footballers
**Answer: a) dolphins**
