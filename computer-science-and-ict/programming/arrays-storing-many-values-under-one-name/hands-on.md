# Hands-on — Arrays — Storing Many Values Under One Name

The lesson with your hands and your feet, not only your eyes.

## One name, thirty marks
On paper, draw an array of six boxes under one name for six pupils' marks. Fill it, then read out the mark at each position number your companion calls.

## Walk the row
Write out, step by step, how a program would add up every value in your six-box array — the pattern the book's solved examples use.
