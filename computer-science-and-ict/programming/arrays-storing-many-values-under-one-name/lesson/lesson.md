# Arrays — Storing Many Values Under One Name

## Do it first

A class has thirty pupils and thirty marks. Would you make thirty separately named variables — mark1, mark2, mark3…? Iraq's Grade 11 book says there is a better tool, the first data structure of the whole series. This lesson builds it.

## Sub lesson 1 — What an array is

An **array** (the book also calls it a **vector** in one dimension) is **one variable holding many values** under a single name. The array has a **size — its length**: how many values it can hold. Instead of a new name for every value, the program keeps one name and reaches each value by its place in the array.

## Sub lesson 2 — One-dimensional arrays and worked examples

A **one-dimensional array** is a single row of values, each reached by its **position number**. The book represents arrays on paper first, then works **solved examples** on one-dimensional arrays — filling them, reading values out, and working through every value in turn — the pattern every later array lesson, and the two-dimensional arrays after it, stand on.

## Do It Yourself

1. Show it, don't just say it: One variable holding many values under a single name. Do this with a real example of your own and write or say how you know it is right.
2. Show it, don't just say it: Its length — how many values it can hold. Do this with a real example of your own and write or say how you know it is right.
3. Show it, don't just say it: A single row of values. Do this with a real example of your own and write or say how you know it is right.
4. Show it, don't just say it: Filling them and reading values out. Do this with a real example of your own and write or say how you know it is right.
