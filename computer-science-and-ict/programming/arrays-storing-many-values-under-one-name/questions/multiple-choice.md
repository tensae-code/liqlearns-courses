# Arrays — Storing Many Values Under One Name — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is an array?**
a) One variable holding many values under a single name  b) A vector  c) By its place — its position number in the array  d) A single row of values
**Answer: a) One variable holding many values under a single name**

**2. (Sub lesson 1) What does the book also call a one-dimensional array?**
a) Its length — how many values it can hold  b) A vector  c) Instead of a new name for every value  d) It represents arrays on paper
**Answer: b) A vector**

**3. (Sub lesson 1) What is an array's size?**
a) By its place — its position number in the array  b) A single row of values  c) Its length — how many values it can hold  d) Filling them and reading values out
**Answer: c) Its length — how many values it can hold**

**4. (Sub lesson 1) How is each value in an array reached?**
a) Instead of a new name for every value  b) It represents arrays on paper  c) The array  d) By its place — its position number in the array
**Answer: d) By its place — its position number in the array**

**5. (Sub lesson 1) Instead of what does an array keep one name?**
a) Instead of a new name for every value  b) A single row of values  c) Filling them and reading values out  d) Grade 11
**Answer: a) Instead of a new name for every value**

**6. (Sub lesson 2) What is a one-dimensional array?**
a) It represents arrays on paper  b) A single row of values  c) The array  d) One variable holding many values under a single name
**Answer: b) A single row of values**

**7. (Sub lesson 2) What does the book do before the worked examples?**
a) Filling them and reading values out  b) Grade 11  c) It represents arrays on paper  d) A vector
**Answer: c) It represents arrays on paper**

**8. (Sub lesson 2) Name two things the solved examples do with arrays.**
a) The array  b) One variable holding many values under a single name  c) Its length — how many values it can hold  d) Filling them and reading values out
**Answer: d) Filling them and reading values out**

**9. (Sub lesson 2) What is the series' first data structure?**
a) The array  b) Grade 11  c) A vector  d) By its place — its position number in the array
**Answer: a) The array**

**10. (Sub lesson 2) Which grade's book introduces arrays?**
a) One variable holding many values under a single name  b) Grade 11  c) Its length — how many values it can hold  d) Instead of a new name for every value
**Answer: b) Grade 11**
