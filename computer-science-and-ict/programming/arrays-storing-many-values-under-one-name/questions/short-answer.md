# Arrays — Storing Many Values Under One Name — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is an array?**
**Answer: One variable holding many values under a single name**

**2. (Sub lesson 1) What does the book also call a one-dimensional array?**
**Answer: A vector**

**3. (Sub lesson 1) What is an array's size?**
**Answer: Its length — how many values it can hold**

**4. (Sub lesson 1) How is each value in an array reached?**
**Answer: By its place — its position number in the array**

**5. (Sub lesson 1) Instead of what does an array keep one name?**
**Answer: Instead of a new name for every value**

**6. (Sub lesson 2) What is a one-dimensional array?**
**Answer: A single row of values**

**7. (Sub lesson 2) What does the book do before the worked examples?**
**Answer: It represents arrays on paper**

**8. (Sub lesson 2) Name two things the solved examples do with arrays.**
**Answer: Filling them and reading values out**

**9. (Sub lesson 2) What is the series' first data structure?**
**Answer: The array**

**10. (Sub lesson 2) Which grade's book introduces arrays?**
**Answer: Grade 11**
