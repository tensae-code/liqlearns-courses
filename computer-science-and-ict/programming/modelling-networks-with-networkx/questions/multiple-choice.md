# Modelling Networks with NetworkX — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) For a network of Twitter-style followings, the right networkx class is —**
a) nx.Graph  b) nx.DiGraph  c) nx.List  d) nx.Table
**Answer: b) nx.DiGraph — Following is one-way: A follows B does not imply B follows A.**

**2. (Sub lesson 1) An edge added to an undirected nx.Graph between A and B means —**
a) Only A reaches B  b) Only B reaches A  c) Each reaches the other — the relation is mutual  d) Nothing until measured
**Answer: c) Each reaches the other — the relation is mutual — Friendship joins symmetrically.**

**3. (Sub lesson 2) Which call returns the graph’s centre?**
a) nx.middle(G)  b) nx.center(G)  c) nx.core(G)  d) nx.hub(G)
**Answer: b) nx.center(G) — Alongside nx.radius(G) and nx.diameter(G) for the other measures.**
