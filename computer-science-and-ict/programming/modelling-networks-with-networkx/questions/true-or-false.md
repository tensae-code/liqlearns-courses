# Modelling Networks with NetworkX — true or false

Say whether each statement is true or false.

**1. (Sub lesson 2) Once networkx is available, hand-measuring a small graph first is wasted time.**
**Answer: False — The hand measurement is the check: you verify the machine on the small graph before trusting it on one too big to check.**

**2. (Sub lesson 1) The same people and pairs can correctly become a Graph in one model and a DiGraph in another.**
**Answer: True — The relation decides: friendships are mutual (Graph); followings are one-way (DiGraph).**
