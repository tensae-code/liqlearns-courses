**1. (Sub lesson 2) Why does the lesson insist on checking networkx’s answers against a hand-measured graph?**
**Answer: Because the library will faithfully measure whatever graph the code actually built — including one with a wrong or missing edge. The hand-measured small graph is known ground truth; agreement there is the evidence that the code models the network correctly before it is trusted on a large one.**
