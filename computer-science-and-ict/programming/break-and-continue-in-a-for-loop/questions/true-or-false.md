# break and continue — leave early, or skip one — true or false

Say True or False.

**1. (Sub lesson 1)** After break, the loop visits the remaining items.
**Answer: False**

**2. (Sub lesson 2)** After continue, the loop moves to the next item.
**Answer: True**

**3. (Sub lesson 1)** break stops a loop before it has looped through all items.
**Answer: True**

**4. (Sub lesson 2)** continue ends the whole loop.
**Answer: False**
