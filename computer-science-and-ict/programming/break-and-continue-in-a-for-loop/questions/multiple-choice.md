# break and continue — leave early, or skip one — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** break does what to a loop?
a) pauses it  b) stops it completely  c) restarts it
**Answer: b) b) stops it completely**

**2. (Sub lesson 1)** In the break program, English is —
a) printed  b) never visited  c) printed twice
**Answer: b) b) never visited** — The loop left at Python.

**3. (Sub lesson 2)** continue does what?
a) ends the loop  b) skips the rest of the current iteration only  c) skips all remaining items
**Answer: b) b) skips the rest of the current iteration only**

**4. (Sub lesson 2)** In the continue program the output is —
a) Amharic only  b) Amharic and English  c) English only
**Answer: b) b) Amharic and English** — Verified.

**5. (Sub lesson 1)** With break at the first item, the loop prints —
a) the first item  b) nothing  c) all items
**Answer: b) b) nothing** — break fires before the print.

**6. (Sub lesson 2)** break and continue differ because —
a) break exits, continue skips one  b) they are the same  c) continue exits, break skips
**Answer: a) a) break exits, continue skips one**
