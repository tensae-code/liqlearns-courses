This lesson: **break and continue inside while**.

First, do it. Run the opening program. Watch what it prints.

Then the idea, in order: The program terminates when the count reaches 5, in the fifth iteration — before printing it. Set to iterate nine times, the program prints eight values: the print is escaped when the count equals the escape value.

Now you. Change the break value to 3 and predict the output before running.

Say it to your companion: Trace both programs aloud for your companion: where break fires, which turn continue escapes, and why eight prints come from nine turns.
