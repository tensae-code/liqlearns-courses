**Acceptance count: taught in 5 countries (Ethiopia, North Macedonia, Kuwait, Jordan, Kazakhstan).**

No book error touches this lesson. The while-continue programs are traced exactly as placed (nine iterations, eight printed values, escape at the count's escape value); the increment-before-continue warning is the direct consequence of the placed shape and is taught as tracing care, not as extra book content. All code in this lesson was run in Python 3 and its output matches the lesson text. The teacher guide's answer keys were used as the verified answer source for this lesson's questions (guide item 40).

North Macedonia's own way (Year 1): five themes move from modern digital technology and online living into a full structured-programming course taught in C++ (with Scratch/C++/Java/Python/PHP/Lisp compared), then advanced Word work (styles, contents, templates) and spreadsheets up to pivot tables.

Kuwait's own way (Grade 10 Information Technology Term 1): secondary school switches to the subject name Information Technology and a more academic register: a full cyber-security unit built on the CIA triad (with hands-on two-factor authentication in Google Authenticator and the Ministry app), then a complete first Python course in PyCharm — variables, strings, conditions, loops, debugging and exceptions — and a team-built digital product.

Jordan's own way (Jordan Grade 11 G11T1 Student): Python is taught through IDLE and the command line, with draw.io flowcharts and Google Slides presentations; Unit 2 grounds computing-and-life topics in Jordan itself (green computing in Jordan). End-of-unit projects: a Python number-guessing game and a puzzle game.


Kazakhstan's own way (Shaniev G8 «INFORMATICS»): an English-medium course in four chapters that runs spreadsheets and Python programming side by side, with «Check yourself» after every chapter and three full game projects at the end (Guess the Number, a quiz game, Rock–Scissors–Paper).

Kazakhstan's own way (Kadirkulov G8 «Информатика» 2023 edition): the 2023 re-issue keeps the 2019 book's first three sections but replaces the Pascal IDE programming with a Python loops course: for, nested loops, while, then a full unit each on continue, break and the loop else clause, closing with olympiad preparation tasks.

Kazakhstan's own way (Salgaraeva G8 «Информатика» 2021 edition): the 2021 Arman-PV revision of the Grade 8 book (Book 19 is the 2018 original) keeps sections 1–3 but replaces the C++ IDE section with Python loop control — while, for, continue, break and the loop else — plus tracing and a practicum on errors that arise in programming.

Kazakhstan's own way (Mukametzhanova G8 «Информатика» 2021 edition): the 2021 Atamura revision of the Grade 8 book (Book 11 is the 2018 original) compresses the course — no separate software-classification or IDE units — and teaches Python loop control directly: while, for, break, continue, else and tracing, with an extra-tasks block closing each section.

Kazakhstan's own way (Zhunusov G8 «INFORMATICS»): the Astana-kitap English-medium Grade 8 book (2nd edition) opens with measuring information by Hartley's formula worked on the Kazakh alphabet in Cyrillic (42) and Latin (32) scripts, and its practical-programming chapter builds one game — the "Melting Snowman" — across four parts from algorithm design to testing.
