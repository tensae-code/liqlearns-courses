# break and continue inside while — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** break in a while loop works —
a) only when the condition is false  b) even while the condition is still true  c) never
**Answer: b) b) even while the condition is still true**

**2. (Sub lesson 1)** In the break program, the loop ends when count reaches —
a) 4  b) 5  c) 9
**Answer: b) b) 5** — Fifth iteration.

**3. (Sub lesson 1)** The break program prints —
a) 1 to 5  b) 1 to 4  c) 5 only
**Answer: b) b) 1 to 4** — Verified — break is before the print.

**4. (Sub lesson 2)** The continue program iterates nine times and prints —
a) nine values  b) eight values  c) five values
**Answer: b) b) eight values** — One print is escaped.

**5. (Sub lesson 2)** The escaped value in the continue program is —
a) 9  b) 1  c) 5
**Answer: c) c) 5**

**6. (Sub lesson 2)** In a while loop, the increment must be placed so continue cannot —
a) skip past it forever  b) print it  c) rename it
**Answer: a) a) skip past it forever** — Otherwise the counter sticks.
