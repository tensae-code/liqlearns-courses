# Combining Search and Sort — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What are the combination's two stages?**
a) Sort the list, then binary-search it  b) The sort's guarantee — binary search demands order, and the sort supplies it  c) Binary search — the ordered list is what it needs  d) The two algorithms one after the other, the sorted list handed over
**Answer: a) Sort the list, then binary-search it**

**2. (Sub lesson 1) What joins the stages?**
a) Binary search — the ordered list is what it needs  b) The sort's guarantee — binary search demands order, and the sort supplies it  c) The two algorithms one after the other, the sorted list handed over  d) Sorting is done once; searching is done per question
**Answer: b) The sort's guarantee — binary search demands order, and the sort supplies it**

**3. (Sub lesson 1) Which searches can the second stage use?**
a) The two algorithms one after the other, the sorted list handed over  b) Sorting is done once; searching is done per question  c) Binary search — the ordered list is what it needs  d) When many searches follow one sort
**Answer: c) Binary search — the ordered list is what it needs**

**4. (Sub lesson 1) In pseudocode, how is the combination written?**
a) Sorting is done once; searching is done per question  b) When many searches follow one sort  c) Sorting the whole list costs more than one linear search  d) The two algorithms one after the other, the sorted list handed over
**Answer: d) The two algorithms one after the other, the sorted list handed over**

**5. (Sub lesson 1) What is done once, and what per question?**
a) Sorting is done once; searching is done per question  b) When many searches follow one sort  c) Sorting the whole list costs more than one linear search  d) Count the questions first — one question, search as it stands; a season of questions, sort once
**Answer: a) Sorting is done once; searching is done per question**

**6. (Sub lesson 2) When does the combination pay?**
a) Sorting the whole list costs more than one linear search  b) When many searches follow one sort  c) Count the questions first — one question, search as it stands; a season of questions, sort once  d) Halving-work instead of whole-list work
**Answer: b) When many searches follow one sort**

**7. (Sub lesson 2) Why does it lose for a single search?**
a) Count the questions first — one question, search as it stands; a season of questions, sort once  b) Halving-work instead of whole-list work  c) Sorting the whole list costs more than one linear search  d) All the searches that follow it
**Answer: c) Sorting the whole list costs more than one linear search**

**8. (Sub lesson 2) What is Malaysia's judgement rule?**
a) Halving-work instead of whole-list work  b) All the searches that follow it  c) Sort the list, then binary-search it  d) Count the questions first — one question, search as it stands; a season of questions, sort once
**Answer: d) Count the questions first — one question, search as it stands; a season of questions, sort once**

**9. (Sub lesson 2) What does each later search cost after sorting?**
a) Halving-work instead of whole-list work  b) All the searches that follow it  c) Sort the list, then binary-search it  d) The sort's guarantee — binary search demands order, and the sort supplies it
**Answer: a) Halving-work instead of whole-list work**

**10. (Sub lesson 2) What does the sort's cost get shared across?**
a) Sort the list, then binary-search it  b) All the searches that follow it  c) The sort's guarantee — binary search demands order, and the sort supplies it  d) Binary search — the ordered list is what it needs
**Answer: b) All the searches that follow it**
