# Combining Search and Sort — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What are the combination's two stages?" is: Sort the list, then binary-search it**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What joins the stages?" is: Binary search — the ordered list is what it needs**
**Answer: False** — The sort's guarantee — binary search demands order, and the sort supplies it

**3. (Sub lesson 1) True or false: the answer to "Which searches can the second stage use?" is: Binary search — the ordered list is what it needs**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "In pseudocode, how is the combination written?" is: Sorting is done once; searching is done per question**
**Answer: False** — The two algorithms one after the other, the sorted list handed over

**5. (Sub lesson 1) True or false: the answer to "What is done once, and what per question?" is: Sorting is done once; searching is done per question**
