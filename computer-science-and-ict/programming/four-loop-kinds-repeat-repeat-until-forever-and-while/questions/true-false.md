# Four Loop Kinds — Repeat, Repeat Until, Forever and While — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "How many loop kinds does VEXcode VR have in this lesson?" is: Four — repeat, repeat until, forever and while**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "When does repeat stop?" is: When you know the count in advance**
**Answer: False** — After a counted number of times

**3. (Sub lesson 1) True or false: the answer to "When is repeat the right loop?" is: When you know the count in advance**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "When does repeat until stop?" is: An if**
**Answer: False** — When its condition becomes true

**5. (Sub lesson 1) True or false: the answer to "What can sit inside a loop to let each turn decide?" is: An if**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "When does forever stop?" is: The moment its condition turns false**
**Answer: False** — Never on its own — it is stopped from outside

**7. (Sub lesson 2) True or false: the answer to "When does while stop?" is: The moment its condition turns false**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What can end a loop from inside?" is: A square and an octagon**
**Answer: False** — A counter variable counting the turns

**9. (Sub lesson 2) True or false: the answer to "What does the robot draw on the Art Canvas with these loops?" is: A square and an octagon**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "How many sides does the counted octagon repeat draw?" is: Four — repeat, repeat until, forever and while**
**Answer: False** — Eight
