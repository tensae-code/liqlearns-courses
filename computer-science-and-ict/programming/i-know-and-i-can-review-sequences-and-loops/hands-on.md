# Hands-on — I Know and I Can — Review: Sequences and Loops

The lesson with your hands, not only your eyes.

## Prove the five
Work the five review kinds in order: sequence, motion blocks, path, repeating part, loop. Tick each only when it is done alone and checked.

## Name the gap
Write one line: "Not yet proved: ___." Practise exactly that skill for ten minutes, then prove it on a fresh example.
