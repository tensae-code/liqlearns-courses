# I Know and I Can — Review: Sequences and Loops — multiple choice

Pick the one right answer.

**1. What is a "Знам и мога" lesson?**
a) The book's own mastery review  b) A brand-new topic  c) A drawing lesson
**Answer: a) The book's own mastery review**

**2. In this review, tasks should be done —**
a) by copying a partner  b) by skipping the hard ones  c) alone, then checked
**Answer: c) alone, then checked**

**3. A review task stops you. What next?**
a) Tick it anyway  b) Practise that one earlier skill, then return  c) Give up the whole review
**Answer: b) Practise that one earlier skill, then return**

**4. This review proves the programming learned —**
a) before Scratch: sequences, paths, repeats and loops  b) in a word processor  c) in the sound gallery
**Answer: a) before Scratch: sequences, paths, repeats and loops**
