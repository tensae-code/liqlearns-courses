# Nested Loops — Working Through a 2D Array — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a nested loop?" is: A loop placed inside another loop**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How far does the inner loop run?" is: A table has rows and columns — two rounds of repeating**
**Answer: False** — All the way through, for every single turn of the outer loop

**3. (Sub lesson 1) True or false: the answer to "In which unit does the book teach nested loops?" is: The arrays unit**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Why can one loop alone not work through a table?" is: The columns**
**Answer: False** — A table has rows and columns — two rounds of repeating

**5. (Sub lesson 1) True or false: the answer to "What does the outer loop take on a 2D array?" is: The rows**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does the inner loop take?" is: Rows times columns**
**Answer: False** — The columns

**7. (Sub lesson 2) True or false: the answer to "When does the outer loop move to the next row?" is: After the inner loop has visited every column in the current row**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How do you count the innermost visits?" is: Grade 11**
**Answer: False** — Rows times columns

**9. (Sub lesson 2) True or false: the answer to "For a 3-row, 4-column table, how many innermost visits are there?" is: 12**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Which grade's book teaches nested loops on arrays?" is: All the way through, for every single turn of the outer loop**
**Answer: False** — Grade 11
