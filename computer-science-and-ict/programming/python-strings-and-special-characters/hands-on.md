# Hands-on — Python Strings and Special Characters

The lesson with your hands and your feet, not only your eyes.

## Task one
**Escape hunt** — Write a string that prints a three-line address with a quoted name inside it; mark every escape and its effect.

## Task two
**Fault repair** — Given three strings with escape faults (a path, a quote, a vanished backslash), repair each and name the fault.
