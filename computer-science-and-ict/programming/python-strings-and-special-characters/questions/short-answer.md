# Python Strings and Special Characters — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a string?**
**Answer: Text held as a value — letters, digits, spaces and marks in quotes**

**2. (Sub lesson 1) Name three things a program can do with strings.**
**Answer: Join them, repeat them, measure them with len**

**3. (Sub lesson 1) Are strings mutable?**
**Answer: No — programs build new strings rather than editing old ones**

**4. (Sub lesson 1) Why is a string called a quiet sequence?**
**Answer: Its characters have positions**

**5. (Sub lesson 1) In what run does Jordan meet strings?**
**Answer: The data-structures run of Grade 11**

**6. (Sub lesson 2) What do backslash-n and backslash-t write?**
**Answer: A new line; a tab**

**7. (Sub lesson 2) How is a literal backslash written?**
**Answer: Doubled — two backslashes in the string**

**8. (Sub lesson 2) What does the backslash announce?**
**Answer: The next character is special, not literal**

**9. (Sub lesson 2) What is the classic path fault?**
**Answer: A path whose letters after backslashes run away into newline and tab escapes**

**10. (Sub lesson 2) When are raw strings used?**
**Answer: Where the text is mostly literal, as with file paths**
