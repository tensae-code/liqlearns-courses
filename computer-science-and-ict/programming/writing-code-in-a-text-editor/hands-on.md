# Hands-on — Writing Code in a Text Editor

The lesson with your hands and your feet, not only your eyes.

## Task one
**Work the book's own example** — Unit 1 §1.1.2 Text Editor (writing "Hello World" in the Code::Blocks editor; build and run) Work it with the book open first, step by step, then close the book and do it again.

## Task two
**Show it to someone else** — Teach writing code in a text editor to a companion in your own words, with your worked example in front of you, and answer their one question from the lesson.
