# Programming the Thymio Robot With VPL — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Visual Programming Language**
**Answer: True**

**2. (Sub lesson 1) True or false: Visual Programming Language** — as the answer to: What is a VPL program made of?
**Answer: False — Pairs — event cards joined to action cards**

**3. (Sub lesson 1) True or false: A hand near; a button pressed (also: a clap, a slope)**
**Answer: True**

**4. (Sub lesson 1) True or false: A hand near; a button pressed (also: a clap, a slope)** — as the answer to: Name two actions Thymio can take.
**Answer: False — Motors (move); lights (also: sounds)**

**5. (Sub lesson 1) True or false: All at once — reacting whenever an event fires**
**Answer: True**

**6. (Sub lesson 2) True or false: All at once — reacting whenever an event fires** — as the answer to: What rows does the VPL interface show?
**Answer: False — An event row and an action row, with the pair-building space**

**7. (Sub lesson 2) True or false: Obstacle avoidance; communication in simplified Morse (also: driving challenges)**
**Answer: True**

**8. (Sub lesson 2) True or false: Obstacle avoidance; communication in simplified Morse (also: driving challenges)** — as the answer to: What does advanced mode add?
**Answer: False — Rarer sensor cards — the gyroscope (pitch) card and finer-grained cards**

**9. (Sub lesson 2) True or false: Pitch — tangage, tilting forward/back**
**Answer: True**

**10. (Sub lesson 2) True or false: Pitch — tangage, tilting forward/back** — as the answer to: Where is every mission tested?
**Answer: False — On the floor, not the screen**
