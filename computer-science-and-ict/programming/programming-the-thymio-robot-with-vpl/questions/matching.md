# Programming the Thymio Robot With VPL — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What does VPL stand for?** → **Visual Programming Language**

**2. (Sub lesson 1) What is a VPL program made of?** → **Pairs — event cards joined to action cards**

**3. (Sub lesson 1) Name two events Thymio can feel.** → **A hand near; a button pressed (also: a clap, a slope)**

**4. (Sub lesson 1) Name two actions Thymio can take.** → **Motors (move); lights (also: sounds)**

**5. (Sub lesson 1) How does the robot live its pairs?** → **All at once — reacting whenever an event fires**

**6. (Sub lesson 2) What rows does the VPL interface show?** → **An event row and an action row, with the pair-building space**

**7. (Sub lesson 2) Name two Grade 7 missions.** → **Obstacle avoidance; communication in simplified Morse (also: driving challenges)**

**8. (Sub lesson 2) What does advanced mode add?** → **Rarer sensor cards — the gyroscope (pitch) card and finer-grained cards**

**9. (Sub lesson 2) What does the gyroscope card read?** → **Pitch — tangage, tilting forward/back**

**10. (Sub lesson 2) Where is every mission tested?** → **On the floor, not the screen**
