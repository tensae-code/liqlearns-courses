# Programming the Thymio Robot With VPL

## Do it first

Thymio sits on the table, patient as furniture. You hold cards: “when a hand comes near” + “back away”. Snap the pair together and the furniture becomes an animal. Before reading on, invent one more pair you would like it to obey.

## Sub lesson 1 — Event–action pairs — the VPL idea

**VPL (Visual Programming Language)** programs Thymio with **pairs**: an **event card** (a sensor situation: hand near, button pressed, clap heard, slope felt) joined to **action cards** (motors, lights, sounds). The program is the set of pairs; the robot lives them all at once, reacting whenever an event fires. The livrets present Thymio whole first — body, sensors, behaviours — so pupils program a creature they understand, not a box they poke.

## Sub lesson 2 — Missions, interfaces and advanced cards

The scenarios climb: discover the **VPL interface** (the event row, the action row, the pair-building space), write a first pair, then the **complete program (programme complet)** of the Grade 5 scenario and the **missions** of Grade 7 — obstacle avoidance, communication in simplified Morse, driving challenges. **Advanced mode** adds rarer sensor cards — the **gyroscope** card reading pitch (tangage), horizontal and ground cards at finer grain — so the event vocabulary grows with the missions' ambition. Every mission is tested on the floor, not the screen: Thymio's verdict is physical.
