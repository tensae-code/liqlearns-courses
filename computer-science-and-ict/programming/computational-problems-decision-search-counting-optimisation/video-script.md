This is **Computational problems — decision, search, counting, optimisation**.

**a computational problem** — a problem that can be solved systematically, step by step, with a computer, with well-defined inputs, constraints and output conditions.

**a decision problem** — a problem whose answer is Yes or No.

**a counting problem** — a problem whose answer is the number of solutions to a search problem.

**an optimisation problem** — a problem whose solution is the best possible — such as the fastest route.
