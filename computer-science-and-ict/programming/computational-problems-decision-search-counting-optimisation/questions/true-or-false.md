# Computational problems — decision, search, counting, optimisation — tf

Say whether each statement is true or false.

**1.** True or false: a computational problem — a problem that can be solved systematically, step by step, with a computer, with well-defined inputs, constraints and output conditions.
**Answer: True**

**2.** True or false: a decision problem — a problem whose answer is Yes or No.
**Answer: True**

**3.** True or false: a counting problem is the opposite: it has nothing to do with a problem whose answer is the number of solutions to a search problem.
**Answer: False** — a counting problem is about a problem whose answer is the number of solutions to a search problem.
