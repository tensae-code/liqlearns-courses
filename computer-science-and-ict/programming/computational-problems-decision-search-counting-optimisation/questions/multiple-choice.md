# Computational problems — decision, search, counting, optimisation — multiple choice

Pick the one right answer.

**1.** What is a computational problem?
a) a problem that can be solved systematically, step by step, with a computer, with well-defined inputs, constraints and output conditions  b) a problem whose answer is Yes or No  c) a problem whose answer is the number of solutions to a search problem  d) a problem whose solution is the best possible — such as the fastest route
**Answer: a) a problem that can be solved systematically, step by step, with a computer, with well-defined inputs, constraints and output conditions**

**2.** What is a decision problem?
a) a problem that can be solved systematically, step by step, with a computer, with well-defined inputs, constraints and output conditions  b) a problem whose answer is the number of solutions to a search problem  c) a problem whose solution is the best possible — such as the fastest route  d) a problem whose answer is Yes or No
**Answer: d) a problem whose answer is Yes or No**

**3.** What is a counting problem?
a) a problem whose answer is Yes or No  b) a problem whose solution is the best possible — such as the fastest route  c) a problem whose answer is the number of solutions to a search problem  d) a problem that can be solved systematically, step by step, with a computer, with well-defined inputs, constraints and output conditions
**Answer: c) a problem whose answer is the number of solutions to a search problem**

**4.** What is an optimisation problem?
a) a problem whose answer is the number of solutions to a search problem  b) a problem whose solution is the best possible — such as the fastest route  c) a problem that can be solved systematically, step by step, with a computer, with well-defined inputs, constraints and output conditions  d) a problem whose answer is Yes or No
**Answer: b) a problem whose solution is the best possible — such as the fastest route**

**5.** 'Find a name in the Grade 9 list' is a —
a) decision problem  b) search problem  c) counting problem  d) optimisation problem
**Answer: b) search problem**

**6.** A router choosing the best path for a packet is solving —
a) a counting problem  b) an optimisation problem  c) a decision problem only  d) no problem
**Answer: b) an optimisation problem**
