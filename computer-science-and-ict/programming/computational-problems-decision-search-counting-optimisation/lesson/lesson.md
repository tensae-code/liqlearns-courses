# Computational problems — decision, search, counting, optimisation

## Do it first

Four questions. Is this number even? Find a name in this class list. How many girls are in Grade 9? Which road to the market is fastest? Each question wants a different kind of answer — a yes/no, a found thing, a number, a best. Sort them before the four types are named.

## What makes a problem computational

A computational problem can be solved systematically, step by step, with a computer. It usually has well-defined inputs, constraints, and conditions the output must satisfy — you can say exactly what goes in, what rules bind it, and what a correct answer looks like. That exactness is what the big human problems of the last lesson lack.

## The four types

Decision problems: the answer is Yes or No — 'given an integer n, is n even?' Search problems: the solution is one or more values satisfying a condition — a path between two places on a map, a name from a spreadsheet column. Counting problems: the answer is the number of solutions to a search problem — counting the female students in a Grade 9 list. Optimisation problems: the solution is the 'best' possible — the fastest route between two places, linking back to the router choosing the best path for a packet.
