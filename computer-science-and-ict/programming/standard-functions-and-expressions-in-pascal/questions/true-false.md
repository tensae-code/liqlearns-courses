# Standard Functions and Expressions in Pascal — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Name three standard functions." is: abs, sqr and sqrt (any three)**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does abs do?" is: 3**
**Answer: False** — Gives a value without its sign

**3. (Sub lesson 1) True or false: the answer to "What is sqrt(9)?" is: 3**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What do trunc and round do?" is: By name, with the value in brackets**
**Answer: False** — Turn real numbers into integers

**5. (Sub lesson 1) True or false: the answer to "How is a standard function called?" is: By name, with the value in brackets**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What joins values in an expression?" is: Brackets**
**Answer: False** — Operations — + - * / and div and mod

**7. (Sub lesson 2) True or false: the answer to "What is worked out first?" is: Brackets**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What do div and mod serve?" is: As a division in brackets, written flat**
**Answer: False** — Integer division and its remainder

**9. (Sub lesson 2) True or false: the answer to "How is a school fraction written in Pascal?" is: As a division in brackets, written flat**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What takes an expression's place once worked out?" is: abs, sqr and sqrt (any three)**
**Answer: False** — Its result
