## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Blocks that act** — ScratchJr programs are built by **snapping blocks**: yellow **trigger** blocks start a script (tap, green flag), blue **motion** blocks move the character, purple **looks** blocks change what it says and shows, and orange **control** blocks wait and repeat. The first programs stay small and honest: one trigger, a few actions, run, watch. A program is “written” (écriture du programme) the same way a sentence is — blocks in the order of the doing.
2. **Scene by scene from the story** — The scenarios build **scene by scene**: each written scene becomes one ScratchJr page, its characters placed, its script staged from the storyboard — nothing in the program that the story did not ask for. Changing scene, changing background and characters, is the program growing the way the story grows: page by page. The discipline travels to all later programming: the plan decides, the blocks obey.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## The run of the lesson (in order)
1. **Do it first** — Your story is written. The tablet shows a cat, a stage, and trays of coloured blocks. Before reading on, find by eye: which block could make the cat move? Which could start everything? First programs begin with exactly those two finds. (lesson/lesson.md).
2. **The explanation** — the lesson text in lesson/lesson.md, in its parts in order.
   - ADD IMAGE: a picture of blocks that act as the lesson describes it — the student studies the picture and names what each part shows.
   - ADD GIF: a GIF of scene by scene from the story in action — the student watches once, then says what changed and why.
   - ADD AUDIO: a voice reading the lesson's key names and definitions aloud, in the order the lesson gives them — the student listens once through, then reads the same lines aloud along with the voice. (Audio is a described slot in this build; no audio file is made.)
3. **Say it to your companion** — the companion block in lesson/lesson.md.
   - ADD VIDEO: the script in video-script.md, filmed — the lesson in the super-simple voice (made later, when videos are made).
4. **Questions** — from questions/: multiple-choice, true-false, matching, short-answer — served at the learner's level and teaching-mix (levels.md).
5. **Hands-on** — hands-on.md.
6. **Do It Yourself** — the doing block at the end of lesson/lesson.md.
