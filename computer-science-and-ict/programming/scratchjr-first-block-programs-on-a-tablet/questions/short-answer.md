# ScratchJr — First Block Programs on a Tablet — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What starts a ScratchJr script?**
**Answer: A yellow trigger block (tap, green flag)**

**2. (Sub lesson 1) Which colour moves the character?**
**Answer: Blue — motion blocks**

**3. (Sub lesson 1) Which colour changes looks and speech?**
**Answer: Purple — looks blocks**

**4. (Sub lesson 1) What do orange control blocks do?**
**Answer: Wait and repeat**

**5. (Sub lesson 1) How is a program like a sentence?**
**Answer: Blocks in the order of the doing**

**6. (Sub lesson 2) What does each written scene become?**
**Answer: One ScratchJr page**

**7. (Sub lesson 2) From what is each script staged?**
**Answer: The storyboard**

**8. (Sub lesson 2) What changes between pages?**
**Answer: Background and characters — the story's scenes**

**9. (Sub lesson 2) What may the program not contain?**
**Answer: Anything the story did not ask for**

**10. (Sub lesson 2) State the discipline.**
**Answer: The plan decides, the blocks obey**
