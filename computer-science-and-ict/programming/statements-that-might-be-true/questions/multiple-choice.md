# Statements That Might Be True — Uncertain Statements — multiple choice

Pick the one right answer.

**1. An uncertain statement is one that —**
a) is always false  b) might be true — we do not know yet  c) is a question
**Answer: b) might be true — we do not know yet** — It waits to be settled.

**2. 'It will rain tomorrow' is —**
a) true  b) false  c) uncertain
**Answer: c) uncertain** — Nobody knows until tomorrow comes.

**3. An uncertain statement becomes true or false when —**
a) we shout it  b) we learn more or the event happens  c) we write it down
**Answer: b) we learn more or the event happens** — Opening the box, or waiting for the day, settles it.

**4. 'Fish can fly' is —**
a) true  b) false  c) uncertain
**Answer: b) false** — That one is settled: it is false.
