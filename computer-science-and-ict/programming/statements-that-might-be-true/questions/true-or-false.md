# Statements That Might Be True — Uncertain Statements — true or false

Say whether each statement is true or false.

**1. An uncertain statement is a mistake and should never be said.**
**Answer: False** — It is careful speech about what is not yet known.

**2. 'Our team will win' is uncertain before the game.**
**Answer: True** — The game has not happened yet.

**3. Unknown means the same as false.**
**Answer: False** — Unknown means uncertain until it is checked.
