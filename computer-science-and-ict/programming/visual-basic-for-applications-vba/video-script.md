Visual Basic for Applications — VBA — is the programming language built inside Microsoft Office: it lets a user write small programs, called macros, that make Word, Excel and Access do repeated work automatically The learner meets VBA where the book places it — inside Excel: how VBA is used, what it is applied to, how code is inserted into a workbook, and how a macro is run Because Office work is full of repeated steps; a macro records or writes those steps once and repeats them exactly, in a second.
