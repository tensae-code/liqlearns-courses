# Hands-on — A First C Program — Hello World and the main Function

The lesson with your hands and your feet, not only your eyes.

## Task one
**Write the skeleton from memory** — Close the lesson. Write the complete Hello World program from memory, then check it bone by bone against the lesson's skeleton.

## Task two
**Break and mend** — Take the working program and remove, in turn: the semicolon, a brace, the header. Build after each and record the compiler's exact complaint.
