# Hands-on — Conditional expressions — == is not =

The lesson with your hands, not only your eyes — every activity is done for real, in IDLE or on paper.

## Sign cards
Make two big cards: `=` and `==`. A partner reads actions aloud — 'put 5 into x', 'ask if x is 5' — and you hold up the right card each time.

## Shell test race
In the Python shell, predict each result BEFORE pressing Enter: `4 == 4`, `4 != 4`, `2 < 2`, `2 <= 2`, `9 > 10`. Score one point per correct prediction.
