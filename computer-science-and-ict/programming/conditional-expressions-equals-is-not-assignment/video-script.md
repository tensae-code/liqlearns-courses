This lesson: **Conditional expressions — == is not =**.

First, do it. Run the opening program. Watch what it prints.

Then the idea, in order: Conditional expressions use comparison and Boolean operators and always answer True or False. == compares; = assigns. The operator table, Python against mathematics.

Now you. Run `3 == 4`, `5 != 5` and `7 >= 9` in the shell and write each result.

Say it to your companion: Tell your companion why `=` and `==` are different signs doing different jobs, then test them: give a value with `=`, and ask a question with `==`.
