# Conditional expressions — == is not = — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** `3 == 4` gives —
a) True  b) False  c) an error
**Answer: b) b) False** — 3 does not equal 4.

**2. (Sub lesson 1)** A conditional expression always answers —
a) a number  b) True or False  c) a word
**Answer: b) b) True or False** — Tests answer True/False.

**3. (Sub lesson 2)** In Python, 'not equals' is written —
a) ==  b) !=  c) <>
**Answer: b) b) !=**

**4. (Sub lesson 2)** `height = 2.5` — the single `=` —
a) compares height with 2.5  b) assigns 2.5 to height  c) tests height
**Answer: b) b) assigns 2.5 to height** — Single = assigns.

**5. (Sub lesson 2)** `5 != 5` gives —
a) True  b) False
**Answer: b) b) False** — They ARE equal, so 'not equal' is False.

**6. (Sub lesson 1)** Conditionals are used most commonly in —
a) if statements and loops  b) comments  c) file names
**Answer: a) a) if statements and loops**
