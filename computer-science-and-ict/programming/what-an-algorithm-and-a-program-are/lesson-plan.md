## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **An algorithm — the plan in the right order** — An **algorithm** is a plan of instructions **in the right order** for finishing a task. The book's example is tying a shoe: cross the laces, make the loop, pass the second lace around, pull tight — do the steps out of order and the knot fails. An algorithm must be **complete** (no step missing), **in order** (each step in its place) and **finished** (it ends with the task done). Recipes, morning routines and the way home are all algorithms of daily life.
2. **A program — the plan written for an executor** — A **program** is an algorithm **written down for an executor** — in the book's lesson, the plan that guides a character to the treasure: forward, forward, turn, forward, drawn as arrows on the map. The writer of the program and its executor are different: the writer thinks and orders; the executor (a person, a character, later a computer) **follows exactly**. If the plan is wrong, the executor still follows it — which is why the next lesson exists: finding the wrong instruction.
