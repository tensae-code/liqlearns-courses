# What an Algorithm and a Program Are — multiple choice

Pick the one right answer.

a) A plan of instructions in the right order for finishing a task  b) Tying a shoe — cross, loop, pass around, pull tight  c) The knot fails — the task is not finished  d) It must be complete, in order, and finished
**Answer: a**
