# What an Algorithm and a Program Are — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A plan of instructions in the right order for finishing a task**
**Answer: True**

**2. (Sub lesson 1) True or false: A plan of instructions in the right order for finishing a task** — as the answer to: What is the book's example?
**Answer: False — Tying a shoe — cross, loop, pass around, pull tight**

**3. (Sub lesson 1) True or false: The knot fails — the task is not finished**
**Answer: True**

**4. (Sub lesson 1) True or false: The knot fails — the task is not finished** — as the answer to: What three marks must an algorithm have?
**Answer: False — It must be complete, in order, and finished**

**5. (Sub lesson 1) True or false: A recipe (also: a morning routine, the way home)**
**Answer: True**

**6. (Sub lesson 2) True or false: A recipe (also: a morning routine, the way home)** — as the answer to: What is a program?

**7. (Sub lesson 2) True or false: The arrow plan that guides a character to the treasure**

**8. (Sub lesson 2) True or false: The arrow plan that guides a character to the treasure** — as the answer to: Who writes a program, and who follows it?

**9. (Sub lesson 2) True or false: It still follows it — the fault is in the plan**
