# What an Algorithm and a Program Are — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What is an algorithm?** → **A plan of instructions in the right order for finishing a task**

**2. (Sub lesson 1) What is the book's example?** → **Tying a shoe — cross, loop, pass around, pull tight**

**3. (Sub lesson 1) What happens if the steps are done out of order?** → **The knot fails — the task is not finished**

**4. (Sub lesson 1) What three marks must an algorithm have?** → **It must be complete, in order, and finished**

**5. (Sub lesson 1) Name an algorithm of daily life.** → **A recipe (also: a morning routine, the way home)**

**6. (Sub lesson 2) What is a program?** → **An algorithm written down for an executor to follow**

**7. (Sub lesson 2) What is the book's program example?** → **The arrow plan that guides a character to the treasure**

**8. (Sub lesson 2) Who writes a program, and who follows it?** → **The writer orders it; the executor follows it exactly**

**9. (Sub lesson 2) What does the executor do with a wrong plan?** → **It still follows it — the fault is in the plan**

**10. (Sub lesson 2) How is the treasure plan written?** → **As arrows on the map — forward, forward, turn, forward**
