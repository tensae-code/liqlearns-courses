# Hands-on — What an Algorithm and a Program Are

The lesson with your hands and your feet, not only your eyes.

## Task one
**Shoe algorithm** — Write the shoe-tying algorithm in four ordered steps, then follow a partner's written version exactly — no helping — and report any missing step.

## Task two
**Treasure map** — Draw a small map with a treasure and write its program in arrows; swap maps and follow each other's programs to the end.
