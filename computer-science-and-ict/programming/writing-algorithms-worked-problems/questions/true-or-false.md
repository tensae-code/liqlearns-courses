# Writing algorithms — worked problems — true or false

Say whether each sentence is true or false.

**1.** 2 is the only even prime.
**Answer: True** — the key's own note.

**2.** The prime check counts divisors by looping from 2 to N.
**Answer: True** — adding 1 to the count for each exact divisor.

**3.** A discriminant above zero gives equal roots.
**Answer: False** — above zero gives two real, different roots.
