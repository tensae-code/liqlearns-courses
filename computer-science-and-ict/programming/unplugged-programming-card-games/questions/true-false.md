# Unplugged Programming — Card Games — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Teaching computing with no computer — the ideas carried by bodies, paper and cards**
**Answer: True**

**2. (Sub lesson 1) True or false: Teaching computing with no computer — the ideas carried by bodies, paper and cards** — as the answer to: What two card kinds does the game use?
**Answer: False — Character cards (the figures who act) and command cards (the instructions they obey)**

**3. (Sub lesson 1) True or false: A player, playing the character — exactly, step by step, as a machine would**
**Answer: True**

**4. (Sub lesson 1) True or false: A player, playing the character — exactly, step by step, as a machine would** — as the answer to: What may the executing player not do?
**Answer: False — Guess what was meant — only do what was written**

**5. (Sub lesson 1) True or false: It will be — read the other way, honestly and literally**
**Answer: True**

**6. (Sub lesson 2) True or false: It will be — read the other way, honestly and literally** — as the answer to: What can intention not patch?
**Answer: False — A missing step**

**7. (Sub lesson 2) True or false: The pupil who has been the computer meets the real machine already knowing what it asks**
**Answer: True**

**8. (Sub lesson 2) True or false: The pupil who has been the computer meets the real machine already knowing what it asks** — as the answer to: Being debugged by friends teaches what?
**Answer: False — Exactness — faster than an error message**

**9. (Sub lesson 2) True or false: Grade 7, Bab 1 B.2a — unplugged programming card games**
**Answer: True**

**10. (Sub lesson 2) True or false: Grade 7, Bab 1 B.2a — unplugged programming card games** — as the answer to: What carries the ideas in unplugged work?
**Answer: False — Bodies, paper and cards — nothing about a screen can hide them**
