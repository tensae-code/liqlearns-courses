## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Programming without a computer — the unplugged idea** — **Unplugged** activities teach computing with no computer at all: the ideas are carried by bodies, paper and cards, so nothing about a screen can hide them. Indonesia's Grade 7 programming chapter includes a **card game** (kartu permainan pemrograman): **character cards** — the figures who will act — and **command cards** — the instructions they obey. One player lays a program of command cards; another plays the character and executes it exactly, step by step, as a machine would — no guessing what was meant, only doing what was written.
2. **What the game teaches — exactness you can feel** — The game makes programming's first truths physical. A command that can be read two ways **will** be — by your friend's honest literalness, in front of everyone, to laughter that teaches faster than a red error message. A missing step cannot be patched by intention. And a program that works is a small triumph the whole table can see. The book places the game inside its first programming chapter, beside Scratch, on purpose: the pupil who has *been* the computer — executing, faulting, being debugged by friends — meets the real machine already knowing what it will ask of them.
