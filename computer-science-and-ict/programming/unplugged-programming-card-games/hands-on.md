# Hands-on — Unplugged Programming — Card Games

The lesson with your hands and your feet, not only your eyes.

## Task one
**Play the machine** — Make five command cards (forward, turn, repeat, pick up, put down) and one character card. Lay a program to cross your table; have a companion execute it literally, then debug the program — not the companion.

## Task two
**Write an unbreakable program** — Rewrite your program so no step can be read two ways. Test it on a second companion who has not seen it before.
