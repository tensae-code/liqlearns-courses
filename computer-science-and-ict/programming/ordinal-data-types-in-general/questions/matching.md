# Ordinal Data Types in General — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What makes a type ordinal?** → **Its values can be counted in a fixed order — each has a definite next**

**2. (Sub lesson 1) Name the five ordinal types of the chapter.** → **Integer, char, boolean, enumerations and subranges**

**3. (Sub lesson 1) Why is real not ordinal?** → **Between any two reals there is another — no 'next real' exists**

**4. (Sub lesson 1) What order has boolean?** → **false < true**

**5. (Sub lesson 1) How does a subrange get its order?** → **It inherits its host ordinal type's order**

**6. (Sub lesson 2) Name the ord-family's three functions.** → **ord (position number), succ (next value), pred (previous value)**

**7. (Sub lesson 2) Which constructions demand ordinal types?** → **for control variables and case selectors**

**8. (Sub lesson 2) Why do they demand it?** → **They count — so their steersman must be countable**

**9. (Sub lesson 2) What follows from knowing a type is ordinal?** → **Its allowed tools — ord/succ/pred, for, case, comparisons — without memorising lists**

**10. (Sub lesson 2) What is ord(Mon) in the week enumeration?** → **0 — positions count from 0**
