# Ordinal Data Types in General — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Its values can be counted in a fixed order — each has a definite next**
**Answer: True**

**2. (Sub lesson 1) True or false: Its values can be counted in a fixed order — each has a definite next** — as the answer to: Name the five ordinal types of the chapter.
**Answer: False — Integer, char, boolean, enumerations and subranges**

**3. (Sub lesson 1) True or false: Between any two reals there is another — no 'next real' exists**
**Answer: True**

**4. (Sub lesson 1) True or false: Between any two reals there is another — no 'next real' exists** — as the answer to: What order has boolean?
**Answer: False — false < true**

**5. (Sub lesson 1) True or false: It inherits its host ordinal type's order**
**Answer: True**

**6. (Sub lesson 2) True or false: It inherits its host ordinal type's order** — as the answer to: Name the ord-family's three functions.
**Answer: False — ord (position number), succ (next value), pred (previous value)**

**7. (Sub lesson 2) True or false: for control variables and case selectors**
**Answer: True**

**8. (Sub lesson 2) True or false: for control variables and case selectors** — as the answer to: Why do they demand it?
**Answer: False — They count — so their steersman must be countable**

**9. (Sub lesson 2) True or false: Its allowed tools — ord/succ/pred, for, case, comparisons — without memorising lists**
**Answer: True**

**10. (Sub lesson 2) True or false: Its allowed tools — ord/succ/pred, for, case, comparisons — without memorising lists** — as the answer to: What is ord(Mon) in the week enumeration?
**Answer: False — 0 — positions count from 0**
