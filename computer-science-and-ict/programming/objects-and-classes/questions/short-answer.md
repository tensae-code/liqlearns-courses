# Objects and Classes — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a class?**
**Answer: A plan — it names the data (attributes) a kind of thing holds and the actions (methods) it can do**

**2. (Sub lesson 1) What is an object?**
**Answer: One thing made from the plan — an instance of the class, with its own values**

**3. (Sub lesson 1) One class, how many objects?**
**Answer: Many — one Pupil class, forty pupil objects**

**4. (Sub lesson 1) What is the class/instance relation also called?**
**Answer: The object is an instance of its class**

**5. (Sub lesson 1) Across which Armenia books do objects and classes run?**
**Answer: Grade 7 (Python), Grade 11 (the OOP theme) and Grade 12 (JavaScript objects)**

**6. (Sub lesson 2) How does code read an object's data?**
**Answer: Through its properties — for example pupil.name**

**7. (Sub lesson 2) How does code make an object act?**
**Answer: By calling its methods — for example pupil.average()**

**8. (Sub lesson 2) What travels together in an object?**
**Answer: Data and the actions that belong to it**

**9. (Sub lesson 2) Name two advantages of objects and classes.**
**Answer: They model the real world directly, and a class can be reused in every program needing that kind of thing (also: inner detail hides behind methods)**

**10. (Sub lesson 2) Where does Armenia name the advantages?**
**Answer: Grade 7, 6.12 — Advantages of object and class**
