## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Changing the sprite — choosing a new actor** — A sprite is **changed** by choosing another: open the **sprite library**, pick the character the story needs, and it appears on the stage and in the sprite list with its own empty script area. The old sprite can be kept for another scene or removed. Bhutan's Class IV book teaches the steps in order — open the library, choose, check the stage — because every later Scratch project begins with casting the right actors.
2. **Deleting a sprite — removing an actor cleanly** — A sprite is **deleted** from the sprite list: select the sprite and use its **delete** command (the small cross or right-click delete), and the sprite leaves the stage and the project — its scripts and costumes go with it. Deleting is for actors the project truly does not need; a sprite wanted later should be hidden, not deleted. The rule before deleting: check the sprite carries no script another part of the story depends on.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
