# Changing and Deleting a Scratch Sprite — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "How is a sprite changed?" is: By choosing another sprite from the sprite library**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Where does a newly chosen sprite appear?" is: When another scene still needs it**
**Answer: False** — On the stage and in the sprite list

**3. (Sub lesson 1) True or false: the answer to "What does a new sprite start with?" is: Its own empty script area**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What order do the book's steps follow?" is: The sprite with its scripts and costumes**
**Answer: False** — Open the library, choose the sprite, check the stage

**5. (Sub lesson 1) True or false: the answer to "When might the old sprite be kept?" is: When another scene still needs it**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How is a sprite deleted?" is: That no other part of the story depends on its scripts**
**Answer: False** — Select it in the sprite list and use its delete command

**7. (Sub lesson 2) True or false: the answer to "What leaves the project when a sprite is deleted?" is: The sprite with its scripts and costumes**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What should you do instead of deleting a sprite needed later?" is: By choosing another sprite from the sprite library**
**Answer: False** — Hide it

**9. (Sub lesson 2) True or false: the answer to "What check comes before deleting?" is: That no other part of the story depends on its scripts**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Who is like a stage manager in a Scratch project?" is: Its own empty script area**
**Answer: False** — The maker, casting and removing the actors — the sprites
