# Algorithm Performance — Worst Case, Input Size and Run Time — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is performance measured against?**
**Answer: The input size — how much data the algorithm is given**

**2. (Sub lesson 1) What grows with input size?**
**Answer: The execution time**

**3. (Sub lesson 1) What is the honest measure?**
**Answer: The shape of growth — double the input and time doubles, or quadruples**

**4. (Sub lesson 1) What is not the measure?**
**Answer: One stopwatch reading on one machine**

**5. (Sub lesson 1) What Greek word names efficiency here?**
**Answer: Αποδοτικότητα**

**6. (Sub lesson 2) What is the worst case?**
**Answer: The allowed input that makes the algorithm work hardest**

**7. (Sub lesson 2) Why judge by it?**
**Answer: A promise that holds in the worst case holds always**

**8. (Sub lesson 2) Give a worst case for searching.**
**Answer: The name that stands last in the list**

**9. (Sub lesson 2) Give a worst case for sorting.**
**Answer: The list that arrives in reverse order**

**10. (Sub lesson 2) When can the judgement be written?**
**Answer: Before any machine is switched on**
