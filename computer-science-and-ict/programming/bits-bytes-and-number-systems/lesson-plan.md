# Lesson plan — Bits, Bytes and Number Systems

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** Bits, Bytes and Number Systems
**Place in the curriculum:** ICT expansion — Germany (2026-11-14) — in the title Programming on the ICT course ladder (TITLES.md). Built new from Germany's *Informatik 5 (Bayern NTG)*, because no existing lesson covers this thing as its own lesson.
**The one thing this lesson teaches:** the computer's own code is the bit — one of two signs, 0 or 1 — grouped eight at a time into a byte; and because the machine counts in twos, its quantities are read in number systems built on place values: binary, decimal, and the shorthand hexadecimal.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Bits and bytes — the computer's two-sign code** — A bit is one binary digit, 0 or 1 — the smallest unit, one switch on or off. Eight bits make one byte, which holds 256 different patterns — enough for one character under codes like ASCII. From the byte upward: KB, MB, GB, TB, each step about a thousand (1,024) of the one below.
2. **Number systems — counting in twos, tens and sixteens** — Place value generalised: a system is set by its base; binary places are 1, 2, 4, 8…; reading a binary number by adding the places carrying 1; writing a decimal number in binary by taking away the largest power of two; hexadecimal (0–9, A–F) as shorthand — one hex digit is exactly four bits.

## Before this lesson

## What the learner can do when it ends
1. Say what a bit and a byte are, and count in binary up to at least 31.
2. Convert small numbers between binary and decimal using place values.
3. Climb the size staircase — bit, byte, KB, MB, GB, TB — and say roughly what each holds.

## What you need
Paper and a pencil. Five fingers of one hand are the first binary counter — the hands-on uses them.

## If the learner is stuck
Thinks a byte is 'a small bit' → a byte is a bundle: eight bits, 256 patterns, one character's worth. Reads binary places as tens → write the places 1, 2, 4, 8 over the digits first, every time, until the hand does it alone.
