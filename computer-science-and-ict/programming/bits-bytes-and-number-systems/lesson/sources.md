Placement choice: this lesson was built new for the ICT expansion (Germany, 2026-11-14) because no existing lesson in the course covers this thing as its own lesson — the live tree was checked for the slug and for near matches before building. Routing note (overlap watch): Montenegro's Programming lesson Number Systems and Conversions teaches binary/decimal/hexadecimal conversions as its own lesson but does not teach bytes or the size staircase, and Ethiopia's Hardware lesson Units of Data Storage teaches bit/byte/KB–TB but no number systems — neither covers bits, bytes and number systems together as one lesson, so Germany's §2.2 was built new at its filed slug, exactly as Germany's book teaches the three together.

Germany's own way: a Bavarian NTG Gymnasium book built on four deep strands — graph theory (adjacency matrices, breadth-first search, Dijkstra), coding and cryptography (symmetric/asymmetric encryption, signatures), network communication, and AI up to neural networks — closing with student projects including programming a social bot. This lesson keeps that depth: the idea is taught whole, with the book's own worked way, not thinned down.
