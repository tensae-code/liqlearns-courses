# Bits, Bytes and Number Systems — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) A kilobyte is exactly 1,000 bytes.**
**Answer: False** — Each staircase step is 1,024 of the one below — about a thousand, not exactly.

**2. (Sub lesson 1) The letter A is stored in a computer as a pattern of bits.**
**Answer: True** — Character codes like ASCII give each character a byte pattern — A is 01000001.

**3. (Sub lesson 2) Converting a number from binary to hexadecimal changes its value.**
**Answer: False** — Conversion changes only the writing; the value stays the same.

**4. (Sub lesson 2) Binary place values are 1, 10, 100, 1000.**
**Answer: False** — Binary places are powers of two: 1, 2, 4, 8, 16.
