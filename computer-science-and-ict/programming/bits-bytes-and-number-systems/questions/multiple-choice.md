# Bits, Bytes and Number Systems — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) A bit is —**
a) Eight digits  b) One binary digit — 0 or 1  c) A small byte  d) A letter
**Answer: b) One binary digit — 0 or 1** — The bit is the computer's single two-way sign.

**2. (Sub lesson 1) One byte is —**
a) 2 bits  b) 10 bits  c) 8 bits  d) 100 bits
**Answer: c) 8 bits** — Eight bits bundle into one byte.

**3. (Sub lesson 1) How many different patterns can one byte hold?**
a) 8  b) 64  c) 100  d) 256
**Answer: d) 256** — 2⁸ = 256 patterns — enough for every character its own pattern.

**4. (Sub lesson 2) The binary number 1010 is, in decimal —**
a) 8  b) 10  c) 12  d) 20
**Answer: b) 10** — Places 8, 4, 2, 1: 8 + 0 + 2 + 0 = 10.

**5. (Sub lesson 2) Decimal 9 written in binary is —**
a) 1001  b) 0110  c) 1010  d) 1111
**Answer: a) 1001** — 9 = 8 + 1, so the 8-place and the 1-place carry 1: 1001.

**6. (Sub lesson 2) One hexadecimal digit always stands for exactly —**
a) Two bits  b) Eight bits  c) Four bits  d) Ten bits
**Answer: c) Four bits** — 2⁴ = 16 — one hex digit covers exactly four bits, so a byte is two hex digits.
