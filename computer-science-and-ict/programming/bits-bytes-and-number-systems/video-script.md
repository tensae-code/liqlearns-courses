# Video script — Bits, Bytes and Number Systems

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Inside a computer there are only two signs: 0 and 1.

One sign alone is a bit. Eight bits together are a byte.

A byte can make 256 different patterns. Enough for every letter.

Then the staircase: kilobytes, megabytes, gigabytes, terabytes.

The machine counts in twos. Places worth 1, 2, 4, 8, 16.

And hexadecimal writes four bits as a single digit. Same value — shorter clothes.
