# Lesson plan — Computer — Questions and Tasks Review

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** Computer — Questions and Tasks Review
**Place in the curriculum:** ICT expansion — Azerbaijan (2026-11-14) — in the title Programming on the ICT course ladder (TITLES.md). Built new from Azerbaijan's *İnformatika 2, Grade 2*, because no existing lesson teaches this thing as its own lesson at this level.
**The one thing this lesson teaches:** This review checks the whole Computer unit: the computer and its parts, lab behaviour rules, keyboard and mouse, the desktop and windows, WordPad, formatting, Paint, pictures with text, and Calculator.
**This lesson's own level:** Grade 2 simple — it stands on the child's own everyday world and on the lessons named below; every new word is built inside the lesson from things the child can do at once.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
This lesson is one whole lesson — it has no sub lessons (a short, single-skill Grade 2 lesson; the 2026-11-09 ruling: sub lessons only where a lesson genuinely has distinct sequential parts).

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: the Computer lessons of Unit 4, from Computer Hardware to The Calculator Program. Recommended, never forced — a learner may land on this review directly, and each task names the lesson it checks.

## What the learner can do when it ends
1. Name the computer's parts, the lab rules, and the keyboard and mouse work of the unit.
2. Write and format a short text in WordPad, naming the desktop and a window.
3. Draw and caption a Paint picture, and calculate short sums in Calculator.

## What you need
A computer with WordPad (or another text editor), Paint and Calculator for the doing tasks.

## If the learner is stuck
Formatting task fails → revisit Formatting — Bold, Italic, Underline, Font and Colour: select the text first, then press the formatting button. Calculator answers mix → revisit The Calculator Program: clear before every new calculation.
