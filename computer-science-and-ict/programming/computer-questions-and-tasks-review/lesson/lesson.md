# Computer — Questions and Tasks Review

## Do it first

Quick check: point (in your mind) to the screen, the keyboard and the mouse of a computer, and name one rule of the computer classroom. This lesson is the Computer unit's own questions and tasks — its check-yourself review, filed in Programming with the book's other unit reviews.

## Computer — Questions and Tasks Review

This is the **review lesson** for the Computer unit — the book's own 'questions and tasks' page for the unit where the computer itself finally arrives. Each task set checks part of the unit.

**Task set 1 — the machine and its rules.** Name the computer and its parts, say the behaviour rules of the computer classroom, and show the keyboard and mouse work: letters, numbers and clicks.

**Task set 2 — programs on the desktop.** Name the desktop and a program window. In the text editor (WordPad), write a short text and format it: bold, italic, underline, font and colour.

**Task set 3 — Paint and Calculator.** Draw a picture in Paint and put text inside it. Work out short calculations in the Calculator program: number, sign, number, equals — clearing before each new one. If a task goes wrong, that task names the lesson to visit again.

## Say it to your companion

Tell your companion, in your own words: This review checks the whole Computer unit: the computer and its parts, lab behaviour rules, keyboard and mouse, the desktop and windows, WordPad, formatting, Paint, pictures with text, and Calculator. Then let your companion ask you one question about it — and answer from the lesson, not from memory of the book's exact words.

## Do It Yourself

1. Show it, don't just say it: name the computer's parts, the lab rules, and the keyboard and mouse work of the unit.
2. Show it, don't just say it: write and format a short text in WordPad, naming the desktop and a window.
3. Show it, don't just say it: draw and caption a Paint picture, and calculate short sums in Calculator.
