# Computer — Questions and Tasks Review — short answer

Answer in a sentence or two.

**1. Name one check from each of the three task sets.**
**Answer:** Machine/rules (parts, lab rules, keyboard and mouse); programs (desktop/window, WordPad writing and formatting); Paint text picture and Calculator sums (one per set).

**2. What do you do after a review task goes wrong?**
**Answer:** Visit the lesson that task checks, practise it, and try the task again.
