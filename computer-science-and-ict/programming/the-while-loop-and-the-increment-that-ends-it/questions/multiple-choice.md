# The while loop — and the increment that ends it — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** In a while loop the condition is checked —
a) only once at the end  b) at the beginning of every loop  c) never
**Answer: b) b) at the beginning of every loop**

**2. (Sub lesson 1)** The first time the condition is false, the loop —
a) runs once more  b) stops  c) restarts
**Answer: b) b) stops**

**3. (Sub lesson 2)** `count += 1` is called the —
a) decrement  b) increment  c) condition
**Answer: b) b) increment**

**4. (Sub lesson 2)** The count program prints —
a) 1 to 5  b) 0 to 5  c) 0 to 4
**Answer: c) c) 0 to 4** — Verified.

**5. (Sub lesson 2)** Without the increment, the loop —
a) stops sooner  b) continues forever  c) prints once
**Answer: b) b) continues forever** — The condition can never turn false.

**6. (Sub lesson 2)** A for loop and a while loop on the same problem can give —
a) never the same output  b) the same output  c) an error
**Answer: b) b) the same output** — Teacher-keyed teaching point.
