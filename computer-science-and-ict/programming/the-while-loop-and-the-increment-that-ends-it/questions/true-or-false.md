# The while loop — and the increment that ends it — true or false

Say True or False.

**1. (Sub lesson 1)** The while block runs while its condition is true.
**Answer: True**

**2. (Sub lesson 2)** The increment can safely live outside the loop block.
**Answer: False**

**3. (Sub lesson 1)** while needs a colon after its expression.
**Answer: True**

**4. (Sub lesson 2)** An infinite loop is one whose condition can never turn false.
**Answer: True**
