This lesson: **The while loop — and the increment that ends it**.

First, do it. Run the opening program. Watch what it prints.

Then the idea, in order: while, an expression, a colon, an indented block; the expression is checked at the beginning of every loop. The worked count program prints 0 to 4. Forget the increment and the loop continues forever. for and while can solve the same problem.

Now you. Run the count program; change the gate to count < 3 and predict before running.

Say it to your companion: Explain the while gate to your companion — tested first, every time — and why the increment line must live inside the block.
