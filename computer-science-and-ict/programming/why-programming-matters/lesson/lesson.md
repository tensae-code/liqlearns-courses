# Why Programming Matters

## Do it first

Why learn to program at all — why not just use programs? Sudan's Grade 9 book answers before it teaches a single command. This lesson is its answer.

## Sub lesson 1 — Programs run the world the pupil lives in

Sudan's Grade 9 book gives programming a lesson of honour before its mechanics: programming **matters** because the modern world runs on programs. The bank's accounts, the school's results, the phone's messages, the hospital's records — each is a task a program does, written by a programmer who first understood it. A person who cannot program uses these systems as a passenger; the book's pupils are being taught to drive.

## Sub lesson 2 — What programming gives the learner

For the learner the importance is personal: programming teaches **solving problems in exact steps** — the same thinking the algorithm lessons build; it turns the computer from a machine with fixed jobs into a tool that does **new jobs the learner invents**; and it is a **skill the world pays for**, standing behind the systems every institution now needs. The book's order is the argument: importance first, so every hard lesson after it has a reason.
