# Lesson plan — Why Programming Matters

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** Why Programming Matters
**Place in the curriculum:** ICT expansion — Sudan (2026-11-14) — in the title Programming on the ICT course ladder (TITLES.md). Built new from Sudan's Grade 9 ICT student book, because no existing lesson in the course covers this thing as its own lesson.
**The one thing this lesson teaches:** Sudan's Grade 9 book gives programming a lesson of honour before its mechanics: programming matters because the modern world runs on programs. For the learner the importance is personal: programming teaches solving problems in exact steps — the same thinking the algorithm lessons build; it turns the computer from a machine with fixed jobs into a tool that does new jobs the learner invents; and it is a skill the world pays for, standing behind the systems every institution now needs.
**This lesson's own level:** It stands on the earlier lessons of its title and on the book's own order — it follows the book's lessons in sequence, so its neighbours in the book are its natural companions. It stands alone for a learner landing on it directly.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Programs run the world the pupil lives in** — Sudan's Grade 9 book gives programming a lesson of honour before its mechanics: programming **matters** because the modern world runs on programs. The bank's accounts, the school's results, the phone's messages, the hospital's records — each is a task a program does, written by a programmer who first understood it. A person who cannot program uses these systems as a passenger; the book's pupils are being taught to drive.
2. **What programming gives the learner** — For the learner the importance is personal: programming teaches **solving problems in exact steps** — the same thinking the algorithm lessons build; it turns the computer from a machine with fixed jobs into a tool that does **new jobs the learner invents**; and it is a **skill the world pays for**, standing behind the systems every institution now needs. The book's order is the argument: importance first, so every hard lesson after it has a reason.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
