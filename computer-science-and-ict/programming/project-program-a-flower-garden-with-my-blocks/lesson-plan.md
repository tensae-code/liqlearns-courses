## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The garden is built from your own blocks** — The group's **flower garden** is programmed **using My Blocks**: the petal (and any stem or leaf pattern) is defined **once** as a block, with a **size input** where sizes must vary. The garden program itself then stays short and readable — a list of plantings, each one a use of the group's blocks.
2. **Working as a group of programmers** — The group divides the work as programmers do: agree the blocks' names and inputs first, define them, test each block alone, then plant the garden together. A garden that grows crooked is debugged at the definition — fix the block once and every flower it planted stands straight.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
