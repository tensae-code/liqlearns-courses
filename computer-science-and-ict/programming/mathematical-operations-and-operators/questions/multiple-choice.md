# Mathematical Operations and Operators — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What four operations does this lesson start with?**
a) Addition, subtraction, multiplication and division  b) The sign that orders an operation  c) Relational operations  d) Two values
**Answer: a) Addition, subtraction, multiplication and division**

**2. (Sub lesson 1) What is an operator?**
a) The + sign  b) The sign that orders an operation  c) Compare two values — bigger, smaller or equal  d) One value
**Answer: b) The sign that orders an operation**

**3. (Sub lesson 1) What sign orders addition?**
a) Relational operations  b) Two values  c) The + sign  d) Changing a number's sign
**Answer: c) The + sign**

**4. (Sub lesson 1) What kind of operations does Grade 8's book add?**
a) Compare two values — bigger, smaller or equal  b) One value  c) How many values it needs before it can run  d) Relational operations
**Answer: d) Relational operations**

**5. (Sub lesson 1) What do relational operations do?**
a) Compare two values — bigger, smaller or equal  b) Two values  c) Changing a number's sign  d) Grade 7 and Grade 8
**Answer: a) Compare two values — bigger, smaller or equal**

**6. (Sub lesson 2) How many values does a binary operation take?**
a) One value  b) Two values  c) How many values it needs before it can run  d) Addition, subtraction, multiplication and division
**Answer: b) Two values**

**7. (Sub lesson 2) How many values does a unary operation work on?**
a) Changing a number's sign  b) Grade 7 and Grade 8  c) One value  d) The sign that orders an operation
**Answer: c) One value**

**8. (Sub lesson 2) What is an example of a unary operation?**
a) How many values it needs before it can run  b) Addition, subtraction, multiplication and division  c) The + sign  d) Changing a number's sign
**Answer: d) Changing a number's sign**

**9. (Sub lesson 2) What does naming an operation unary or binary tell you?**
a) How many values it needs before it can run  b) Grade 7 and Grade 8  c) The sign that orders an operation  d) Relational operations
**Answer: a) How many values it needs before it can run**

**10. (Sub lesson 2) In which grades does Iraq teach these operations?**
a) Addition, subtraction, multiplication and division  b) Grade 7 and Grade 8  c) The + sign  d) Compare two values — bigger, smaller or equal
**Answer: b) Grade 7 and Grade 8**
