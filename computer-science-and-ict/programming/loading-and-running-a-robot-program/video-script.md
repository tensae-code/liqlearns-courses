# Video script — Loading and Running a Robot Program

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

This part of Kazakhstan's book teaches **Запуск программы для робота** — covering: §22 Запуск программы для робота. The book teaches this as its own named step, in the book's own order, as a skill to be shown — not only named. The learner follows the book's own steps for this part, in order, and practises until the steps can be done without the book open.
