Now we write a whole program. One that talks.

A function is code that does a task. You call it by name.
You know print(). Meet input().

input shows a prompt... and WAITS.
You type. You press Enter.
And what you typed comes back - always as a STRING.
Even a number! So a number for maths must be converted.
Remember that. It is the trap of this lesson.

Write the circle program with me.

radius = float(input("Enter the radius: "))
One line: ask, wait, convert, store.

area = 3.14 * radius ** 2
circumference = 2 * 3.14 * radius

print(area)
print(circumference)
Separate lines first.

Run it. Type 3.
28.26. 18.84.

Now make it friendly - labels on the same line:
print("Area:", area)
print("Circumference:", circumference)
Area: 28.26. Circumference: 18.84.

Input. Process. Print.
That is a program - YOUR program.
