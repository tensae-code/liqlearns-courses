# Writing a simple Python program - input, process, print - multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A function is -
a) a variable  b) a piece of code that does a task, called by name, taking input data and optionally returning output  c) a data type  d) an error
**Answer: b) a piece of code that does a task, called by name, taking input data and optionally returning output** - called by name; takes input; may return output.

**2. (Sub lesson 1)** input() returns what was typed -
a) as a number, always  b) as a float  c) always as a string  d) as a bool
**Answer: c) always as a string** - that is why numbers must be converted.

**3. (Sub lesson 1)** input() works in this order:
a) prints the answer, then asks  b) shows its prompt string, waits for typing and Enter, returns what was typed  c) runs the whole program  d) converts automatically to float
**Answer: b) shows its prompt string, waits for typing and Enter, returns what was typed** - prompt - wait - Enter - string back.

**4. (Sub lesson 1)** print("Area:", 28.26) shows -
a) two lines  b) Area: 28.26 - comma-separated values print on one line  c) an error  d) only 28.26
**Answer: b) Area: 28.26 - comma-separated values print on one line** - commas keep values together on one line.

**5. (Sub lesson 2)** In radius = float(input("Enter the radius: ")), the float() is there because -
a) input() is slow  b) input() returns a string, and the radius is needed as a number  c) float is a keyword  d) the prompt must be a float
**Answer: b) input() returns a string, and the radius is needed as a number** - conversion inside the input line - the worked pattern.

**6. (Sub lesson 2)** Running the circle program with radius 3 prints -
a) 28.26 and 18.84  b) 9.42 and 28.26  c) 3 and 3.14  d) an error
**Answer: a) 28.26 and 18.84** - area = 3.14 * 3 ** 2; circumference = 2 * 3.14 * 3.

**7. (Sub lesson 3)** The combined form print("Circumference:", circumference) prints -
a) Circumference: on one line, the value on the next  b) Circumference: 18.84 - label and value on one line  c) only the label  d) only the value
**Answer: b) Circumference: 18.84 - label and value on one line** - one print() call, one line out.
