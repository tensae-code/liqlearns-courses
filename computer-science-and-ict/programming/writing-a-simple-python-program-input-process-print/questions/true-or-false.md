# Writing a simple Python program - input, process, print - true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** A function optionally returns output - not every function must.
**Answer: True** - the definition says optionally.

**2. (Sub lesson 2)** If the user types 3 at an input() prompt, the program receives the number 3 ready for maths.
**Answer: False** - it receives the string "3" - conversion is the programmer's job.

**3. (Sub lesson 3)** In the separate-lines form, area and circumference are printed by two print() statements.
**Answer: True** - print(area) then print(circumference).
