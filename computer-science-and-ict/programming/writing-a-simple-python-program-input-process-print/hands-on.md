# Hands-on - Writing a simple Python program - input, process, print

The lesson with your hands, not only your eyes.

## Human program

One pupil is the program, one is the user. The program pupil holds three cards - INPUT, PROCESS, PRINT - and works the circle run aloud: prompt spoken, the user answers, the program computes on paper (converting the 'string' answer card by flipping it to a number card), then speaks the two results. Swap roles with radius 2.

## Build the closing practice

In pairs, write the product-of-two-numbers program and the BMI program (weight and height from the keyboard) on paper in this lesson's exact shape - input with conversion, process, print - then trace each with sample values and write the expected outputs.
