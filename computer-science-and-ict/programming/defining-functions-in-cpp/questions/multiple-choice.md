# Defining Functions in C++ — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What are the four parts of a function definition?**
a) Return type, name, parameters and body  b) void  c) In round brackets after the name  d) Only when it is called
**Answer: a) Return type, name, parameters and body**

**2. (Sub lesson 1) What return type means the function gives back nothing?**
a) In round brackets after the name  b) void  c) Only when it is called  d) return
**Answer: b) void**

**3. (Sub lesson 1) Where do the parameters sit?**
a) Only when it is called  b) return  c) In round brackets after the name  d) The real values given for the parameters at a call
**Answer: c) In round brackets after the name**

**4. (Sub lesson 1) When does a defined function run?**
a) return  b) The real values given for the parameters at a call  c) Back to the exact place of the call  d) Only when it is called
**Answer: d) Only when it is called**

**5. (Sub lesson 1) What keyword sends a value back?**
a) return  b) The real values given for the parameters at a call  c) Back to the exact place of the call  d) One fix in the body fixes every call
**Answer: a) return**

**6. (Sub lesson 2) What are arguments?**
a) Back to the exact place of the call  b) The real values given for the parameters at a call  c) One fix in the body fixes every call  d) main()
**Answer: b) The real values given for the parameters at a call**

**7. (Sub lesson 2) Where does control go after a call finishes?**
a) One fix in the body fixes every call  b) main()  c) Back to the exact place of the call  d) That value, to the calling place
**Answer: c) Back to the exact place of the call**

**8. (Sub lesson 2) Why define a repeated job once?**
a) main()  b) That value, to the calling place  c) Return type, name, parameters and body  d) One fix in the body fixes every call
**Answer: d) One fix in the body fixes every call**

**9. (Sub lesson 2) Which function does the system call first?**
a) main()  b) That value, to the calling place  c) Return type, name, parameters and body  d) void
**Answer: a) main()**

**10. (Sub lesson 2) What does a call carry back when the function returns a value?**
a) Return type, name, parameters and body  b) That value, to the calling place  c) void  d) In round brackets after the name
**Answer: b) That value, to the calling place**
