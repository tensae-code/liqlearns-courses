# Defining Functions in C++ — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What are the four parts of a function definition?" is: Return type, name, parameters and body**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What return type means the function gives back nothing?" is: return**
**Answer: False** — void

**3. (Sub lesson 1) True or false: the answer to "Where do the parameters sit?" is: In round brackets after the name**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "When does a defined function run?" is: Back to the exact place of the call**
**Answer: False** — Only when it is called

**5. (Sub lesson 1) True or false: the answer to "What keyword sends a value back?" is: return**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What are arguments?" is: main()**
**Answer: False** — The real values given for the parameters at a call

**7. (Sub lesson 2) True or false: the answer to "Where does control go after a call finishes?" is: Back to the exact place of the call**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Why define a repeated job once?" is: Return type, name, parameters and body**
**Answer: False** — One fix in the body fixes every call

**9. (Sub lesson 2) True or false: the answer to "Which function does the system call first?" is: main()**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What does a call carry back when the function returns a value?" is: In round brackets after the name**
**Answer: False** — That value, to the calling place
