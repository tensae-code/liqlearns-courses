# Defining Functions in C++ — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What are the four parts of a function definition?**
**Answer: Return type, name, parameters and body**

**2. (Sub lesson 1) What return type means the function gives back nothing?**
**Answer: void**

**3. (Sub lesson 1) Where do the parameters sit?**
**Answer: In round brackets after the name**

**4. (Sub lesson 1) When does a defined function run?**
**Answer: Only when it is called**

**5. (Sub lesson 1) What keyword sends a value back?**
**Answer: return**

**6. (Sub lesson 2) What are arguments?**
**Answer: The real values given for the parameters at a call**

**7. (Sub lesson 2) Where does control go after a call finishes?**
**Answer: Back to the exact place of the call**

**8. (Sub lesson 2) Why define a repeated job once?**
**Answer: One fix in the body fixes every call**

**9. (Sub lesson 2) Which function does the system call first?**
**Answer: main()**

**10. (Sub lesson 2) What does a call carry back when the function returns a value?**
**Answer: That value, to the calling place**
