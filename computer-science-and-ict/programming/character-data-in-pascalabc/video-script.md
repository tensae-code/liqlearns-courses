# Video script — Character Data in PascalABC

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A variable of the **char** type holds exactly **one character**: a letter, a digit, a punctuation mark or a space.
Inside the computer the character is stored as a **code number**, and a coding table says which number belongs to which character.
PascalABC gives ready **procedures and functions** for character variables, so a program does not have to work with raw codes by hand.
They answer questions like: what is the character for this code, what is the code of this character, is this character a letter or a digit, and what is the same letter in the other case — capital for small, small for capital.
