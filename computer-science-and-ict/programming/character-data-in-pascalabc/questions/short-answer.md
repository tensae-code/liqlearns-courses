# Character Data in PascalABC — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does a char variable hold?**
**Answer: Exactly one character**

**2. (Sub lesson 1) How is a character stored inside the computer?**
**Answer: As a code number**

**3. (Sub lesson 1) What does a coding table do?**
**Answer: It says which code number belongs to which character**

**4. (Sub lesson 1) What is ASCII?**
**Answer: The classic coding table fixing codes for Latin letters, digits and common marks**

**5. (Sub lesson 1) Why do national codings exist?**
**Answer: So letters of other alphabets also have codes**

**6. (Sub lesson 2) When is one character 'greater' than another?**
**Answer: When its code number is greater**

**7. (Sub lesson 2) What do PascalABC's character functions hand back?**
**Answer: A value the program can store, print or compare**

**8. (Sub lesson 2) Name one job of a character function.**
**Answer: Turning a code into its character (or a character into its code)**

**9. (Sub lesson 2) What other case change can a character function do?**
**Answer: Change a letter between small and capital**

**10. (Sub lesson 2) What puts characters into alphabetical order?**
**Answer: Comparing their code numbers**
