# Character Data in PascalABC — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does a char variable hold?**
a) Exactly one character  b) The classic coding table fixing codes for Latin letters, digits and common marks  c) When its code number is greater  d) Turning a code into its character (or a character into its code)
**Answer: a) Exactly one character**

**2. (Sub lesson 1) How is a character stored inside the computer?**
a) So letters of other alphabets also have codes  b) As a code number  c) A value the program can store, print or compare  d) Change a letter between small and capital
**Answer: b) As a code number**

**3. (Sub lesson 1) What does a coding table do?**
a) When its code number is greater  b) Turning a code into its character (or a character into its code)  c) It says which code number belongs to which character  d) Comparing their code numbers
**Answer: c) It says which code number belongs to which character**

**4. (Sub lesson 1) What is ASCII?**
a) A value the program can store, print or compare  b) Change a letter between small and capital  c) Exactly one character  d) The classic coding table fixing codes for Latin letters, digits and common marks
**Answer: d) The classic coding table fixing codes for Latin letters, digits and common marks**

**5. (Sub lesson 1) Why do national codings exist?**
a) So letters of other alphabets also have codes  b) Turning a code into its character (or a character into its code)  c) Comparing their code numbers  d) As a code number
**Answer: a) So letters of other alphabets also have codes**

**6. (Sub lesson 2) When is one character 'greater' than another?**
a) Change a letter between small and capital  b) When its code number is greater  c) Exactly one character  d) It says which code number belongs to which character
**Answer: b) When its code number is greater**

**7. (Sub lesson 2) What do PascalABC's character functions hand back?**

**9. (Sub lesson 2) What other case change can a character function do?**
a) Change a letter between small and capital  b) As a code number  c) The classic coding table fixing codes for Latin letters, digits and common marks  d) When its code number is greater
**Answer: a) Change a letter between small and capital**
