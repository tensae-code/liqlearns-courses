# Character Data in PascalABC — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does a char variable hold?" is: Exactly one character.**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How is a character stored inside the computer?" is: When its code number is greater.**
**Answer: False** — As a code number.

**3. (Sub lesson 1) True or false: the answer to "What does a coding table do?" is: It says which code number belongs to which character.**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is ASCII?" is: Turning a code into its character (or a character into its code).**
**Answer: False** — The classic coding table fixing codes for Latin letters, digits and common marks.

**5. (Sub lesson 1) True or false: the answer to "Why do national codings exist?" is: So letters of other alphabets also have codes.**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "When is one character 'greater' than another?" is: Comparing their code numbers.**
**Answer: False** — When its code number is greater.

**7. (Sub lesson 2) True or false: the answer to "What do PascalABC's character functions hand back?" is: A value the program can store, print or compare.**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Name one job of a character function." is: As a code number.**
**Answer: False** — Turning a code into its character (or a character into its code).

**9. (Sub lesson 2) True or false: the answer to "What other case change can a character function do?" is: Change a letter between small and capital.**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What puts characters into alphabetical order?" is: The classic coding table fixing codes for Latin letters, digits and common marks.**
**Answer: False** — Comparing their code numbers.
