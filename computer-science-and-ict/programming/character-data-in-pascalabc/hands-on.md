# Hands-on — Character Data in PascalABC

The lesson with your hands and your feet, not only your eyes.

## Code detective
Write a short PascalABC program that prints the code of a letter you choose, then prints the character belonging to a code you choose. Try one Latin letter and one letter from your own alphabet and compare the codes.

## Case swap
Write a program that reads one small letter and prints the capital of the same letter using the language's character functions. Test it on three different letters.
