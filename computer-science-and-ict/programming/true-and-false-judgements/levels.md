# True and False Judgements — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure). Practice is tied to the learner's skill number, as before. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — What a judgement is
Sub lesson 1 questions from the type files. Pass mark: A judgement is a sentence that says something that could be so or not so: 'The sky is blue', 'A fish can fly' — a question or an order is not a judgement, because it does not say something that can be checked.
## Sub lesson 2 — True judgements and false judgements
Sub lesson 2 questions from the type files. Pass mark: Hold the judgement up against the world: if the world agrees, the judgement is true; if the world disagrees, it is false — 'A fish lives in water' is true, 'A fish can fly' is false, and your job is always to check, not to guess.
