Placement choice: this lesson was built new for the ICT expansion (Turkmenistan, 2026-11-14) because no existing lesson in the course covers this thing as its own lesson — the live tree was checked first: the Programming lessons on statements, expressions and the if statement are written for older learners in code, and none teaches judgements and their truth as a first, pre-code idea. The placements file named this slug directly (NEW LESSON NEEDED — programming/true-and-false-judgements). It sits in the Programming title (programming/), where the placements file placed it.

Turkmenistan's own way: logic is taught in Grade 1 as its own chapter (Chapter VI, Logic) — judgements that are true or false, checked against the world in front of the child, years before any code is written. This lesson keeps that pre-code order: the thinking first, the machine later.
