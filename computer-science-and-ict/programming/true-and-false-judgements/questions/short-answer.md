# True and False Judgements — short answer

Answer in a sentence or two.

**1. (Sub lesson 1) Give one true judgement and one false judgement about a cat.**
**Answer:** True examples: a cat has four legs; a cat has ears. False examples: a cat can fly; a cat has six legs — checked against a real cat.

**2. (Sub lesson 2) Why is 'What is your name?' not a judgement?**
**Answer:** Because it asks something instead of saying something; there is nothing in it to check as true or false.

**3. (Sub lesson 2) A friend says: 'Our classroom has ten windows.' How do you decide if the judgement is true?**
**Answer:** Hold it against the world: look at the classroom and count the windows — ten means true, any other number means false.
