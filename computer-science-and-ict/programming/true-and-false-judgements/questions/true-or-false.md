# True and False Judgements — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) An order like 'Please sit down' is a judgement.**
**Answer: False** — An order does not say something that can be checked.

**2. (Sub lesson 2) 'A fish lives in water' is a true judgement.**
**Answer: True** — Fish do live in water — the judgement matches the world.

**3. (Sub lesson 2) 'A fish can fly' is a true judgement.**
**Answer: False** — Fish swim; they do not fly — the judgement does not match the world.

**4. (Sub lesson 2) Every judgement is either true or false.**
**Answer: True** — Those are the two kinds of judgements.
