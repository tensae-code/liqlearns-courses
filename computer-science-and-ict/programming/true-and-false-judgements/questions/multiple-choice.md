# True and False Judgements — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Which of these is a judgement?**
a) Please sit down  b) The sky is blue  c) What time is it?
**Answer: b) The sky is blue** — A judgement says something that can be checked; the others are an order and a question.

**2. (Sub lesson 1) A question is a judgement because —**
a) it says something true  b) it is not a judgement at all  c) it has words in it
**Answer: b) it is not a judgement at all** — A question asks; it does not say something that can be checked.

**3. (Sub lesson 2) The judgement 'Sugar is salty' is —**
a) true  b) false  c) neither
**Answer: b) false** — Sugar is sweet, not salty — the world disagrees, so the judgement is false.

**4. (Sub lesson 2) How do you decide if a judgement is true or false?**
a) Guess  b) Say the one that sounds nice  c) Hold it up against the world and check
**Answer: c) Hold it up against the world and check** — Look, count, check — then say true or false.
