# Hands-on — Abstract Data Types

The lesson with your hands and your feet, not only your eyes.

## Task one
**Write a contract** — Write the ADT contract for a queue of a school canteen: operations, and what each guarantees — no implementation words allowed.

## Task two
**Swap the inside** — Take one small program using a list as a stack; describe a second inside for the same contract and prove no user code changes.
