# Hands-on — Exporting a Sprite with Its Scripts to Use in Another Project

The lesson with your hands and your feet, not only your eyes.

## Carry a sprite
Build a sprite with a script and a second costume, save it to a file, and load it into a new empty project.

## Prove it travelled whole
In the new project, run the loaded sprite’s script and switch its costumes — write what survived the journey.
