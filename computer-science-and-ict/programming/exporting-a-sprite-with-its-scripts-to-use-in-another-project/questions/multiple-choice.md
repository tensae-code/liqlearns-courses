# Exporting a Sprite with Its Scripts to Use in Another Project — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) From which menu is a sprite saved?**
a) Its right-click menu  b) A file  c) Its costumes and its sounds  d) The file is loaded
**Answer: a) Its right-click menu**

**2. (Sub lesson 1) What is the sprite saved to?**
a) All the sprite’s properties and scripts  b) A file  c) It stays where it was — the file is a copy  d) Its looks, properties and programming, whole
**Answer: b) A file**

**3. (Sub lesson 1) What travels inside the file?**
a) Its costumes and its sounds  b) The file is loaded  c) All the sprite’s properties and scripts  d) No
**Answer: c) All the sprite’s properties and scripts**

**4. (Sub lesson 1) Name two things packed besides the blocks.**
a) It stays where it was — the file is a copy  b) Its looks, properties and programming, whole  c) Build well once, carry it anywhere  d) Its costumes and its sounds
**Answer: d) Its costumes and its sounds**

**5. (Sub lesson 1) What happens to the sprite on the stage when it is saved?**
a) It stays where it was — the file is a copy  b) The file is loaded  c) No  d) A sprite with its programming, to another sprite/project
**Answer: a) It stays where it was — the file is a copy**

**6. (Sub lesson 2) How does the sprite enter the other program?**
a) Its looks, properties and programming, whole  b) The file is loaded  c) Build well once, carry it anywhere  d) Its right-click menu
**Answer: b) The file is loaded**

**7. (Sub lesson 2) What arrives with the sprite?**
a) No  b) A sprite with its programming, to another sprite/project  c) Its looks, properties and programming, whole  d) A file
**Answer: c) Its looks, properties and programming, whole**

**8. (Sub lesson 2) Must the sprite be rebuilt in the new project?**
a) Build well once, carry it anywhere  b) Its right-click menu  c) All the sprite’s properties and scripts  d) No
**Answer: d) No**

**9. (Sub lesson 2) What is the lesson’s rule?**
a) Build well once, carry it anywhere  b) A sprite with its programming, to another sprite/project  c) A file  d) Its costumes and its sounds
**Answer: a) Build well once, carry it anywhere**

**10. (Sub lesson 2) What is copied by this lesson’s method?**
a) Its right-click menu  b) A sprite with its programming, to another sprite/project  c) All the sprite’s properties and scripts  d) It stays where it was — the file is a copy
**Answer: b) A sprite with its programming, to another sprite/project**
