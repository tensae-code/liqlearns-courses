# The With Instruction for Records in Pascal — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: It opens a record so its fields can be named bare inside the block**
**Answer: True**

**2. (Sub lesson 1) True or false: It opens a record so its fields can be named bare inside the block** — as the answer to: Write a with block for pupil p.
**Answer: False — with p do begin name := 'Ana'; mark := 9; paid := true; end;**

**3. (Sub lesson 1) True or false: Yes — with p, q do — fields nested by the order given**
**Answer: True**

**4. (Sub lesson 1) True or false: Yes — with p, q do — fields nested by the order given** — as the answer to: Does with change what the program does?
**Answer: False — No — it is a writing shorthand; only the text changes**

**5. (Sub lesson 1) True or false: The p. prefix on each field**
**Answer: True**

**6. (Sub lesson 2) True or false: The p. prefix on each field** — as the answer to: Which name wins inside with — field or outside variable?
**Answer: False — The field — it shadows the outside variable, silently**

**7. (Sub lesson 2) True or false: The program compiles and runs; only the meaning differs from the intent**
**Answer: True**

**8. (Sub lesson 2) True or false: The program compiles and runs; only the meaning differs from the intent** — as the answer to: When is with counselled?
**Answer: False — For short, single-record work**

**9. (Sub lesson 2) True or false: Write the prefixes — keep every name honest**
**Answer: True**

**10. (Sub lesson 2) True or false: Write the prefixes — keep every name honest** — as the answer to: What is with's trap in one phrase?
**Answer: False — A bare name that lies — it names the field when you meant the variable**
