# Dynamic Programming — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What shape of problem fits dynamic programming?** → **A problem whose pieces overlap — the pieces share smaller pieces**

**2. (Sub lesson 1) What waste does a plain recursive attack commit there?** → **Solving the same small problem again and again**

**3. (Sub lesson 1) What does dynamic programming do instead?** → **Solves each distinct small piece once, stores its answer in a table, and reads it back**

**4. (Sub lesson 1) What is the joining rule?** → **How a piece's answer is built from the smaller answers beneath it**

**5. (Sub lesson 1) In what order are the subproblems solved?** → **Smallest first — so every needed answer is already in the table**

**6. (Sub lesson 2) What is the method's price and profit?** → **Memory (the table) buys time (each piece solved once)**

**7. (Sub lesson 2) What question is the method's tell?** → **'Am I solving this piece before?'**

**8. (Sub lesson 2) Between which strategies does Grade 11 place it?** → **After recursion and greedy algorithms**

**9. (Sub lesson 2) What is the Indonesian term?** → **Pemrograman dinamis**

**10. (Sub lesson 2) Where does Indonesia teach this?** → **Grade 11, Bab III B.3 — dynamic programming**
