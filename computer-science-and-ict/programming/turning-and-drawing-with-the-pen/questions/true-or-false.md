# Turning and Drawing with the Pen — true or false

Say whether each statement is true or false.

**1. Turn a sprite by a chosen number of degrees.**
**Answer: True** — This is one of the lesson's own outcomes.

**2. With the pen up, a moving sprite still leaves a line behind it.**
**Answer: False** — The lesson teaches the opposite of this.

**3. Put the pen down and draw a shape by moving and turning.**
**Answer: True** — This is one of the lesson's own outcomes.
