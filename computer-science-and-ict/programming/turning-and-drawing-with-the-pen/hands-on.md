# Hands-on — Turning and Drawing with the Pen

The lesson with your hands, not only your eyes.

## Pen-down square
In Scratch, draw a square with move and turn blocks and the pen down. Change one side's length and say what shape you get instead.

## Turn by degrees
Set a sprite turning 90, then 45, then 180 degrees, running each time. Write what each turn looks like before you run it.
