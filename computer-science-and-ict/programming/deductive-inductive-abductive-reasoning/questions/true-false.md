# Deductive, Inductive and Abductive Reasoning — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: From a rule to a case**
**Answer: True**

**2. (Sub lesson 1) True or false: From a rule to a case** — as the answer to: How strong is a deductive conclusion?
**Answer: False — Certain — if the rule is true and the case falls under it**

**3. (Sub lesson 1) True or false: From cases to a rule**
**Answer: True**

**4. (Sub lesson 1) True or false: From cases to a rule** — as the answer to: How strong is an inductive conclusion?
**Answer: False — Likely, never certain**

**5. (Sub lesson 1) True or false: From a result to its most likely cause — the best explanation**
**Answer: True**

**6. (Sub lesson 2) True or false: From a result to its most likely cause — the best explanation** — as the answer to: Whose reasoning is abduction?
**Answer: False — The diagnoser's — technician, doctor, debugger**

**7. (Sub lesson 2) True or false: Another cause may explain the same result**
**Answer: True**

**8. (Sub lesson 2) True or false: Another cause may explain the same result** — as the answer to: What is abduction's strength?
**Answer: False — It proposes what to check first**

**9. (Sub lesson 2) True or false: Discovers**
**Answer: True**
