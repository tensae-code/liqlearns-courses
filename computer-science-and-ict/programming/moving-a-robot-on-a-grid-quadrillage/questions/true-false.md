# Moving a Robot on a Grid — Quadrillage — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A square**
**Answer: True**

**2. (Sub lesson 1) True or false: A square** — as the answer to: In what unit are movements counted?
**Answer: False — Squares — the robot's own steps**

**3. (Sub lesson 1) True or false: Where the robot is, and which way it faces**
**Answer: True**

**4. (Sub lesson 1) True or false: Where the robot is, and which way it faces** — as the answer to: When is a route correct?
**Answer: False — On the grid, before it is run on the mat**

**5. (Sub lesson 1) True or false: None beyond the grid**
**Answer: True**

**6. (Sub lesson 2) True or false: None beyond the grid** — as the answer to: What does a turn change?
**Answer: False — Facing, not place**

**7. (Sub lesson 2) True or false: Planning turns as moves, or forgetting forward changes meaning after a turn**
**Answer: True**

**8. (Sub lesson 2) True or false: Planning turns as moves, or forgetting forward changes meaning after a turn** — as the answer to: How many counts does a grid program keep?
**Answer: False — Two — squares and facings**

**9. (Sub lesson 2) True or false: On its square, in place**
**Answer: True**

**10. (Sub lesson 2) True or false: On its square, in place** — as the answer to: What must be tracked as carefully as position?
**Answer: False — Facing**
