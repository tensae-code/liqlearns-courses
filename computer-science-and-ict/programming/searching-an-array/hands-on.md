# Hands-on — Searching an Array

The lesson with your hands and your feet, not only your eyes.

## Task one
('Search by hand', 'Search the array 4, 9, 2, 9, 5 for 9 and then for 7, tracing each test. Record the found-index (or the absence sign) for both.')

## Task two
('Improve it', 'Write linear search in its first form, then improve it to stop at the first match. Run both on a 100-element array searching for the first element's twin at the end, and compare the tests made.')
