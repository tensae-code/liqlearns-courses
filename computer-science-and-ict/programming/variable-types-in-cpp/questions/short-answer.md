# Variable Types in C++ — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does a variable's type fix?**
**Answer: The kind of value it holds and its memory size**

**2. (Sub lesson 1) Which type holds whole numbers?**
**Answer: int**

**3. (Sub lesson 1) Which type holds one character?**
**Answer: char**

**4. (Sub lesson 1) What two values can a bool hold?**
**Answer: true and false**

**5. (Sub lesson 1) What kind of number does double hold?**
**Answer: Numbers with fractions, approximately**

**6. (Sub lesson 2) What does int division do to fractions?**
**Answer: Drops them**

**7. (Sub lesson 2) What is 'A' + 1 in char terms?**
**Answer: 'B' — adding moves the character's code**

**8. (Sub lesson 2) What do conditions test?**
**Answer: A bool — true or false**

**9. (Sub lesson 2) What happens to 3.9 poured into an int?**
**Answer: It becomes 3**

**10. (Sub lesson 2) What is choosing a type called in the lesson?**
**Answer: The first design decision for every value**
