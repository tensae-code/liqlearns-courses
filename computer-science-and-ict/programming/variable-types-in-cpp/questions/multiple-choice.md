# Variable Types in C++ — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does a variable's type fix?**
a) The kind of value it holds and its memory size  b) int  c) char  d) true and false
**Answer: a) The kind of value it holds and its memory size**

**2. (Sub lesson 1) Which type holds whole numbers?**
a) char  b) int  c) true and false  d) Numbers with fractions, approximately
**Answer: b) int**

**3. (Sub lesson 1) Which type holds one character?**
a) true and false  b) Numbers with fractions, approximately  c) char  d) Drops them
**Answer: c) char**

**4. (Sub lesson 1) What two values can a bool hold?**
a) Numbers with fractions, approximately  b) Drops them  c) 'B' — adding moves the character's code  d) true and false
**Answer: d) true and false**

**5. (Sub lesson 1) What kind of number does double hold?**
a) Numbers with fractions, approximately  b) Drops them  c) 'B' — adding moves the character's code  d) A bool — true or false
**Answer: a) Numbers with fractions, approximately**

**6. (Sub lesson 2) What does int division do to fractions?**
a) 'B' — adding moves the character's code  b) Drops them  c) A bool — true or false  d) It becomes 3
**Answer: b) Drops them**

**7. (Sub lesson 2) What is 'A' + 1 in char terms?**
a) A bool — true or false  b) It becomes 3  c) 'B' — adding moves the character's code  d) The first design decision for every value
**Answer: c) 'B' — adding moves the character's code**

**8. (Sub lesson 2) What do conditions test?**
a) It becomes 3  b) The first design decision for every value  c) The kind of value it holds and its memory size  d) A bool — true or false
**Answer: d) A bool — true or false**

**9. (Sub lesson 2) What happens to 3.9 poured into an int?**
a) It becomes 3  b) The first design decision for every value  c) The kind of value it holds and its memory size  d) int
**Answer: a) It becomes 3**

**10. (Sub lesson 2) What is choosing a type called in the lesson?**
a) The kind of value it holds and its memory size  b) The first design decision for every value  c) int  d) char
**Answer: b) The first design decision for every value**
