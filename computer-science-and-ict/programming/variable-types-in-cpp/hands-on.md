# Hands-on — Variable Types in C++

The lesson with your hands and your feet, not only your eyes.

## Type the values
Give the right C++ type for: a person's age, a price, a first initial, whether a door is open, a temperature with decimals, the number of students. Defend two of your choices in a sentence each.

## Predict the pour
Predict what each holds after assignment: int x = 7.8; double y = 5; char c = '7';. Then check with a run or the lesson's rules, and explain any surprise.
