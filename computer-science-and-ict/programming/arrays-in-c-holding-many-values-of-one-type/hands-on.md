# Hands-on — Arrays in C — Holding Many Values of One Type

The lesson with your hands and your feet, not only your eyes.

## Task one
**Fill and sum** — Write a C program that reads ten marks into an array, then prints their sum and average — one loop to fill, one to total.

## Task two
**Find the fence fault** — Examine a program that loops i <= 30 over a 30-array. Explain, in memory terms, what its last step does and rewrite the condition.
