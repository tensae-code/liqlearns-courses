# Arrays in C — Holding Many Values of One Type — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does an array hold?**
**Answer: Many values of one type under one name**

**2. (Sub lesson 1) Write the declaration of 30 int marks.**
**Answer: int marks[30];**

**3. (Sub lesson 1) Can a C array grow after declaration?**
**Answer: No — its size is fixed**

**4. (Sub lesson 1) What may initialise an array at birth?**
**Answer: A list of values in braces**

**5. (Sub lesson 1) What is the array's bargain?**
**Answer: Order and speed in exchange for sameness of type**

**6. (Sub lesson 2) What is the first room's index?**
**Answer: 0**

**7. (Sub lesson 2) What is the last index of a 30-array?**
**Answer: 29 — always size − 1**

**8. (Sub lesson 2) Which loop walks an array best?**
**Answer: A for loop from 0 to size−1**

**9. (Sub lesson 2) Does C check an index for you?**
**Answer: No — an out-of-range index reaches foreign memory silently**

**10. (Sub lesson 2) What is the fence at the array's edge?**
**Answer: The loop's condition — the programmer's discipline**
