# Compound Instructions — begin and end in Pascal — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A sequence of instructions in begin…end, treated as one instruction**
**Answer: True**

**2. (Sub lesson 1) True or false: A sequence of instructions in begin…end, treated as one instruction** — as the answer to: How are the inside instructions separated?
**Answer: False — By semicolons — none is needed after the last, before end**

**3. (Sub lesson 1) True or false: Braces { }**
**Answer: True**

**4. (Sub lesson 1) True or false: Braces { }** — as the answer to: Where can a compound instruction stand?
**Answer: False — Wherever the grammar asks for one instruction — if branches, loop bodies, case labels**

**5. (Sub lesson 1) True or false: Only an empty instruction — harmless but needless**
**Answer: True**

**6. (Sub lesson 2) True or false: Only an empty instruction — harmless but needless** — as the answer to: In 'if x > 0 then a := 1; b := 2;', what is conditional?
**Answer: False — Only a := 1 — b := 2 runs always**

**7. (Sub lesson 2) True or false: Wrap both in begin…end as the if's one instruction**
**Answer: True**

**8. (Sub lesson 2) True or false: Wrap both in begin…end as the if's one instruction** — as the answer to: What reading habit does the lesson teach?
**Answer: False — Find the governing instruction's one instruction and draw its border before judging**

**9. (Sub lesson 2) True or false: Border errors — mistaking what a governing instruction commands**
**Answer: True**

**10. (Sub lesson 2) True or false: Border errors — mistaking what a governing instruction commands** — as the answer to: Does begin…end itself execute anything?
**Answer: False — No — it groups; the inside instructions execute in order**
