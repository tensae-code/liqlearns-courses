# Expressions and Arithmetic in Small Basic — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is an expression?" is: A written working-out the machine evaluates to a single result**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does ReadNumber do?" is: Read the quantities, work the expression, keep the result**
**Answer: False** — Pauses, takes a typed number from the user, and hands it to a variable

**3. (Sub lesson 1) True or false: the answer to "What is the rhythm of a numeric program?" is: Read the quantities, work the expression, keep the result**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Name the basic arithmetic operators." is: No — by operator precedence**
**Answer: False** — +, −, * and /

**5. (Sub lesson 1) True or false: the answer to "Are operators worked strictly left to right?" is: No — by operator precedence**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Which operators are worked first?" is: Parentheses — the bracketed part is worked first**
**Answer: False** — Multiplication and division, before addition and subtraction

**7. (Sub lesson 2) True or false: the answer to "What stands above all in precedence?" is: Parentheses — the bracketed part is worked first**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is 2 + 3 * 4, and why?" is: Write the brackets: (2 + 3) * 4**
**Answer: False** — 14 — multiplication is worked before addition

**9. (Sub lesson 2) True or false: the answer to "How do you force the answer 20?" is: Write the brackets: (2 + 3) * 4**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Where do remainder and powers live in Small Basic?" is: A written working-out the machine evaluates to a single result**
**Answer: False** — Through the Math object
