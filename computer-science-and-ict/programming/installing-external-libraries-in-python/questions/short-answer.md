# Installing External Libraries in Python — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What are external libraries?**
**Answer: Packages by others, beyond the standard library**

**2. (Sub lesson 1) Where do they live?**
**Answer: In a public index — PyPI**

**3. (Sub lesson 1) What does installing make a package?**
**Answer: Importable like any standard module**

**4. (Sub lesson 1) How do standard and external modules differ?**
**Answer: Standard arrive with Python; external are fetched and trusted by you**

**5. (Sub lesson 1) Which libraries does the data unit need?**
**Answer: The table and charting libraries**

**6. (Sub lesson 2) What is the installer called?**
**Answer: pip**

**7. (Sub lesson 2) Write the install command's shape.**
**Answer: pip install <name>**

**8. (Sub lesson 2) What is the sound-alike trap?**
**Answer: A mistyped name can fetch a stranger's — even hostile — package**

**9. (Sub lesson 2) Why mind versions?**
**Answer: A program may need the version its book used**

**10. (Sub lesson 2) Why record what was installed?**
**Answer: So the work can be rebuilt on another machine**
