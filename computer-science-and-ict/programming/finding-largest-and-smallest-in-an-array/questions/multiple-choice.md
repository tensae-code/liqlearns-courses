# Finding the Largest and Smallest in an Array — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does the walk keep?**
a) The best-so-far — the largest seen yet  b) The first element, a[0]  c) When an element beats it — a[i] > max  d) All-negative arrays would break it
**Answer: a) The best-so-far — the largest seen yet**

**2. (Sub lesson 1) What does max start from?**
a) When an element beats it — a[i] > max  b) The first element, a[0]  c) All-negative arrays would break it  d) The largest value in the array
**Answer: b) The first element, a[0]**

**3. (Sub lesson 1) When is max replaced?**
a) All-negative arrays would break it  b) The largest value in the array  c) When an element beats it — a[i] > max  d) The comparison flips to <
**Answer: c) When an element beats it — a[i] > max**

**4. (Sub lesson 1) Why not start max at 0?**
a) The largest value in the array  b) The comparison flips to <  c) imax, updated together with max  d) All-negative arrays would break it
**Answer: d) All-negative arrays would break it**

**5. (Sub lesson 1) After the walk, what does max hold?**
a) The largest value in the array  b) The comparison flips to <  c) imax, updated together with max  d) Largest is 9, at index 4
**Answer: a) The largest value in the array**

**6. (Sub lesson 2) What changes for the smallest?**
a) imax, updated together with max  b) The comparison flips to <  c) Largest is 9, at index 4  d) The first — strict comparison replaces only on a beating
**Answer: b) The comparison flips to <**

**7. (Sub lesson 2) What extra variable reports the position?**
a) Largest is 9, at index 4  b) The first — strict comparison replaces only on a beating  c) imax, updated together with max  d) No — it only reads it
**Answer: c) imax, updated together with max**

**8. (Sub lesson 2) What does a position report look like?**
a) The first — strict comparison replaces only on a beating  b) No — it only reads it  c) The best-so-far — the largest seen yet  d) Largest is 9, at index 4
**Answer: d) Largest is 9, at index 4**

**9. (Sub lesson 2) Which position wins a tie?**
a) The first — strict comparison replaces only on a beating  b) No — it only reads it  c) The best-so-far — the largest seen yet  d) The first element, a[0]
**Answer: a) The first — strict comparison replaces only on a beating**

**10. (Sub lesson 2) Does the walk change the array?**
a) The best-so-far — the largest seen yet  b) No — it only reads it  c) The first element, a[0]  d) When an element beats it — a[i] > max
**Answer: b) No — it only reads it**
