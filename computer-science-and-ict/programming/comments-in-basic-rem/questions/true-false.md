# Comments in BASIC — REM — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does REM stand for?" is: Remark**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is a REM line?" is: The people — the programmer later, or another programmer reading the program**
**Answer: False** — A comment — a note to the program's human readers

**3. (Sub lesson 1) True or false: the answer to "What does the computer do with REM lines?" is: Ignores them completely — they change, print and compute nothing**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Who are comments for?" is: Why — not a repetition of what the line does**
**Answer: False** — The people — the programmer later, or another programmer reading the program

**5. (Sub lesson 1) True or false: the answer to "Why does the book give comments their own section?" is: Because a program nobody can read is a program nobody can fix**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What should a good comment say?" is: The program's name, its job and its writer**
**Answer: False** — Why — not a repetition of what the line does

**7. (Sub lesson 2) True or false: the answer to "Where do comments belong?" is: At the head of the program and before any part whose purpose is not obvious**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What goes in the head comment?" is: It hides its own code**
**Answer: False** — The program's name, its job and its writer

**9. (Sub lesson 2) True or false: the answer to "What is the rule of proportion?" is: Comment the thinking, not every line**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What does a program drowned in remarks do?" is: A comment — a note to the program's human readers**
**Answer: False** — It hides its own code
