## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **What a string is** — Where **char** holds one character, the **string** type holds a **sequence of characters** as a single value: a word, a name, a sentence. A string value is written in the program between apostrophes. Every string has a **length** — the number of characters it holds, spaces and punctuation included — and an empty string, with length zero, is a proper string value too. A string variable is declared like any other variable, and it can be read in, printed out, assigned and compared as one whole piece of text.
2. **Reaching inside a string** — A string is a whole, but it is built from numbered parts: the characters sit in **positions**, counted from the first character. Writing the position after the string reaches that one character, so a program can pick out the first letter of a name or the last mark of a sentence. Comparing two strings uses the characters' codes position by position — the same code order that ordered single characters — which is how programs sort names into alphabetical order. Length, positions and comparison are the three handles this section gives for every later string task.
