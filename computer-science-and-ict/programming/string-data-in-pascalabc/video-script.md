# Video script — String Data in PascalABC

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Where **char** holds one character, the **string** type holds a **sequence of characters** as a single value: a word, a name, a sentence.
A string value is written in the program between apostrophes.
A string is a whole, but it is built from numbered parts: the characters sit in **positions**, counted from the first character.
Writing the position after the string reaches that one character, so a program can pick out the first letter of a name or the last mark of a sentence.
