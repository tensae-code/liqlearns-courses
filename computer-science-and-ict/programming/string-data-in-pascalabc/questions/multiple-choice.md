# String Data in PascalABC — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does the string type hold?**
a) A sequence of characters as a single value  b) Yes — it is a string of length zero  c) Character by character, using the characters' codes position by position  d) Yes — as one whole piece of text
**Answer: a) A sequence of characters as a single value**

**2. (Sub lesson 1) How is a string value written in a program?**
a) By their positions, counted from the first character  b) Between apostrophes  c) Sorting names into alphabetical order  d) char holds one character; string holds a sequence of characters
**Answer: b) Between apostrophes**

**3. (Sub lesson 1) What is a string's length?**
a) Character by character, using the characters' codes position by position  b) Yes — as one whole piece of text  c) The number of characters it holds, spaces and punctuation included  d) Length, positions and comparison
**Answer: c) The number of characters it holds, spaces and punctuation included**

**4. (Sub lesson 1) Is an empty string a proper value?**
a) Sorting names into alphabetical order  b) char holds one character; string holds a sequence of characters  c) A sequence of characters as a single value  d) Yes — it is a string of length zero
**Answer: d) Yes — it is a string of length zero**

**5. (Sub lesson 1) How are a string's characters reached one by one?**
a) By their positions, counted from the first character  b) Yes — as one whole piece of text  c) Length, positions and comparison  d) Between apostrophes
**Answer: a) By their positions, counted from the first character**

**6. (Sub lesson 2) How are two strings compared?**
a) char holds one character; string holds a sequence of characters  b) Character by character, using the characters' codes position by position  c) A sequence of characters as a single value  d) The number of characters it holds, spaces and punctuation included

**7. (Sub lesson 2) What does comparing strings make possible?**
a) Length, positions and comparison  b) Between apostrophes  c) Sorting names into alphabetical order  d) Yes — it is a string of length zero
**Answer: c) Sorting names into alphabetical order**

**8. (Sub lesson 2) Can a string variable be read in and printed out?**
a) A sequence of characters as a single value  b) The number of characters it holds, spaces and punctuation included  c) By their positions, counted from the first character  d) Yes — as one whole piece of text

**9. (Sub lesson 2) How does string differ from char?**
a) char holds one character; string holds a sequence of characters  b) Between apostrophes  c) Yes — it is a string of length zero  d) Character by character, using the characters' codes position by position
