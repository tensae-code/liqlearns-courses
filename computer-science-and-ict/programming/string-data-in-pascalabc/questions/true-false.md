# String Data in PascalABC — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does the string type hold?" is: A sequence of characters as a single value.**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How is a string value written in a program?" is: Character by character, using the characters' codes position by position.**
**Answer: False** — Between apostrophes.

**3. (Sub lesson 1) True or false: the answer to "What is a string's length?" is: The number of characters it holds, spaces and punctuation included.**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Is an empty string a proper value?" is: Yes — as one whole piece of text.**
**Answer: False** — Yes — it is a string of length zero.

**5. (Sub lesson 1) True or false: the answer to "How are a string's characters reached one by one?" is: By their positions, counted from the first character.**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How are two strings compared?" is: Length, positions and comparison.**
**Answer: False** — Character by character, using the characters' codes position by position.

**7. (Sub lesson 2) True or false: the answer to "What does comparing strings make possible?" is: Sorting names into alphabetical order.**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Can a string variable be read in and printed out?" is: Between apostrophes.**
**Answer: False** — Yes — as one whole piece of text.

**9. (Sub lesson 2) True or false: the answer to "How does string differ from char?" is: char holds one character; string holds a sequence of characters.**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What three handles does this section give for strings?" is: Yes — it is a string of length zero.**
**Answer: False** — Length, positions and comparison.
