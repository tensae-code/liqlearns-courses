# String Data in PascalABC — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does the string type hold?**
**Answer: A sequence of characters as a single value**

**2. (Sub lesson 1) How is a string value written in a program?**
**Answer: Between apostrophes**

**3. (Sub lesson 1) What is a string's length?**
**Answer: The number of characters it holds, spaces and punctuation included**

**4. (Sub lesson 1) Is an empty string a proper value?**
**Answer: Yes — it is a string of length zero**

**5. (Sub lesson 1) How are a string's characters reached one by one?**
**Answer: By their positions, counted from the first character**

**6. (Sub lesson 2) How are two strings compared?**
**Answer: Character by character, using the characters' codes position by position**

**7. (Sub lesson 2) What does comparing strings make possible?**
**Answer: Sorting names into alphabetical order**

**8. (Sub lesson 2) Can a string variable be read in and printed out?**
**Answer: Yes — as one whole piece of text**

**9. (Sub lesson 2) How does string differ from char?**
**Answer: char holds one character; string holds a sequence of characters**

**10. (Sub lesson 2) What three handles does this section give for strings?**
**Answer: Length, positions and comparison**
