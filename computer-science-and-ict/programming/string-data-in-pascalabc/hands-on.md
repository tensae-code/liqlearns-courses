# Hands-on — String Data in PascalABC

The lesson with your hands and your feet, not only your eyes.

## Name in pieces
Write a PascalABC program that stores your name in a string variable, prints its length, then prints its first and last characters by position.

## Which name first?
Write a program that compares two names as strings and prints the one that comes first in alphabetical order. Test it with names that start with the same letter.
