# Repeat Blocks — Looping a Set Number of Times

## Do it first

Steve must plant the same seed four times, then forty times. Will you snap forty blocks? Palestine’s Grade 5 book answers with one block that repeats — and this lesson teaches it three times over: the idea, the farming, and the railway.

## Sub lesson 1 — The repeat block — the idea of a loop

The book introduces the **loop** with a **repeat block**: the commands inside run again and again, **a set number of times**, and the number is written on the block. **Changing the repeat count** changes how much work the same program does. The lesson draws a rectangle four ways to show that a loop and a long sequence can reach the same result — the loop is the shorter writing.

[Picture — the repeat block — the idea of a loop]

## Sub lesson 2 — Loops at work — farming and the railway

The loop is then put to work. In **Farming on the river banks** the pupil counts repeats and plant commands and debugs a program that drops the character into the river. In **The railway**, repeat blocks take **entered values**, and three different correct solutions are compared side by side — a loop program, like any program, can be right in more than one way.

## Say it to your companion

Tell your companion, in your own words: A repeat block runs the blocks inside it a set number of times; the count is part of the program — change the count and the same blocks do more or less work. Then let your companion ask you one question about it — and answer from the lesson, not from memory of the book's exact words.
