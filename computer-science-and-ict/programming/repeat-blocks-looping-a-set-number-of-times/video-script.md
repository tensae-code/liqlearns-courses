# Video script — Repeat Blocks — Looping a Set Number of Times

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

The book introduces the **loop** with a **repeat block**: the commands inside run again and again, **a set number of times**, and the number is written on the block. **Changing the repeat count** changes how much work the same program does. The lesson draws a rectangle four ways to show that a loop and a long sequence can reach the same result — the loop is the shorter writing.
The loop is then put to work. In **Farming on the river banks** the pupil counts repeats and plant commands and debugs a program that drops the character into the river. In **The railway**, repeat blocks take **entered values**, and three different correct solutions are compared side by side — a loop program, like any program, can be right in more than one way.
