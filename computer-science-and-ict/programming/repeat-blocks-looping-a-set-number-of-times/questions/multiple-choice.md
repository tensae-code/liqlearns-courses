# Repeat Blocks — Looping a Set Number of Times — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does a repeat block do?**
a) It runs the blocks inside it a set number of times  b) On the repeat block itself  c) A rectangle  d) Repeats and plant commands
**Answer: a) It runs the blocks inside it a set number of times**

**2. (Sub lesson 1) Where is the number of times written?**
a) How much work the same program does  b) On the repeat block itself  c) They can reach the same result — the loop is the shorter writing  d) The character falls into the river
**Answer: b) On the repeat block itself**

**3. (Sub lesson 1) What does changing the repeat count change?**
a) A rectangle  b) Repeats and plant commands  c) How much work the same program does  d) Entered values
**Answer: c) How much work the same program does**

**4. (Sub lesson 1) What shape does the book draw four ways to teach loops?**
a) They can reach the same result — the loop is the shorter writing  b) The character falls into the river  c) Three different correct solutions  d) A rectangle
**Answer: d) A rectangle**

**5. (Sub lesson 1) How do a loop and a long sequence compare?**
a) They can reach the same result — the loop is the shorter writing  b) Repeats and plant commands  c) Entered values  d) Yes — like any program
**Answer: a) They can reach the same result — the loop is the shorter writing**

**6. (Sub lesson 2) In Farming on the river banks, what does the pupil count?**
a) The character falls into the river  b) Repeats and plant commands  c) Three different correct solutions  d) It runs the blocks inside it a set number of times
**Answer: b) Repeats and plant commands**

**7. (Sub lesson 2) What goes wrong in the farming program to debug?**
a) Entered values  b) Yes — like any program  c) The character falls into the river  d) On the repeat block itself
**Answer: c) The character falls into the river**

**8. (Sub lesson 2) What do the railway’s repeat blocks take?**
a) Three different correct solutions  b) It runs the blocks inside it a set number of times  c) How much work the same program does  d) Entered values
**Answer: d) Entered values**

**9. (Sub lesson 2) How many correct railway solutions does the book compare?**
a) Three different correct solutions  b) Yes — like any program  c) On the repeat block itself  d) A rectangle
**Answer: a) Three different correct solutions**

**10. (Sub lesson 2) Can a loop program be right in more than one way?**
a) It runs the blocks inside it a set number of times  b) Yes — like any program  c) How much work the same program does  d) They can reach the same result — the loop is the shorter writing
