# Descriptive Naming of Sprites, Costumes and Backdrops — multiple choice

Pick the one right answer.

**1. A descriptive name for the enemy sprite is —**
a) Sprite4  b) Chaser  c) costume2
**Answer: b) Chaser** — Names say what the thing is.

**2. Level backdrops should be named —**
a) backdrop1, backdrop2  b) Maze 1, Maze 2, in order  c) All 'maze'
**Answer: b) Maze 1, Maze 2, in order** — Numbered in order, scripts read clearly.

**3. Descriptive naming mainly helps —**
a) The computer run faster  b) Anyone reading the project — partners, teacher, and yourself later  c) Sounds play louder
**Answer: b) Anyone reading the project — partners, teacher, and yourself later** — Code is read by people; names serve the readers.

**4. The time to name a thing is —**
a) Never  b) At the moment of making it  c) After the exam only
**Answer: b) At the moment of making it** — Seconds at making, saved at every reading.
