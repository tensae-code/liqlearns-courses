# Debugging — Finding and Fixing the Wrong Instruction — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is debugging?**
**Answer: Finding and fixing the wrong instruction in a program**

**2. (Sub lesson 1) How is the wrong instruction found?**
**Answer: Run the program slowly, watching each step, until the mouse goes wrong**

**3. (Sub lesson 1) Name the three kinds of wrongness.**
**Answer: Wrong direction, wrong count (too many or too few), wrong place in the row**

**4. (Sub lesson 1) What do you watch while running slowly?**
**Answer: Each step, against what the plan intended**

**5. (Sub lesson 1) Is a failed run the end of the work?**
**Answer: No — it is the start of debugging**

**6. (Sub lesson 2) How is a step too many fixed?**
**Answer: It is removed**

**7. (Sub lesson 2) How is a wrong-direction arrow fixed?**
**Answer: It is replaced with the right one**

**8. (Sub lesson 2) How are steps in the wrong place fixed?**
**Answer: They are reordered — swapped into their right places**

**9. (Sub lesson 2) What must happen after every fix?**
**Answer: Run the program again, from the start, all the way**

**10. (Sub lesson 2) When is a fix proved?**
**Answer: When the mouse reaches the cheese by the corrected program**
