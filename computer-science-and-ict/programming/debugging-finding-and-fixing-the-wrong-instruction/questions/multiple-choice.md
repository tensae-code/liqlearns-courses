# Debugging — Finding and Fixing the Wrong Instruction — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is debugging?**
a) Finding and fixing the wrong instruction in a program  b) Run the program slowly, watching each step, until the mouse goes wrong  c) Wrong direction, wrong count (too many or too few), wrong place in the row  d) Each step, against what the plan intended
