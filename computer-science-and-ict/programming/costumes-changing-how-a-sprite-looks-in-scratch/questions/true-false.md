# Costumes — Changing How a Sprite Looks in Scratch — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a costume?" is: One of a sprite’s looks**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does the next-costume block do?" is: Avery’s**
**Answer: False** — It steps to the following look

**3. (Sub lesson 1) True or false: the answer to "What makes walking look real?" is: Repeating movement while changing costume**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Whose walk is Grade 7’s example?" is: It picks exactly the look the moment needs**
**Answer: False** — Avery’s

**5. (Sub lesson 1) True or false: the answer to "Can a sprite hold more than one costume?" is: Yes — the same character in different poses**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does switch to a named costume do?" is: Its timing — the waits between switches**
**Answer: False** — It picks exactly the look the moment needs

**7. (Sub lesson 2) True or false: the answer to "What loop runs an endless animation?" is: Repeat-forever**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What gives the animation its life, besides the costumes?" is: No — they change how the sprite looks**
**Answer: False** — Its timing — the waits between switches

**9. (Sub lesson 2) True or false: the answer to "What can repeat-forever costume switching make?" is: A character that walks, flaps or dances**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Do costumes change the sprite’s scripts?" is: It steps to the following look**
**Answer: False** — No — they change how the sprite looks
