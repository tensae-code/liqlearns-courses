# Hands-on — Enumerated Types in Pascal and C++

The lesson with your hands and your feet, not only your eyes.

## Task one
**Pair definition** — Define an enumeration for traffic-light states in both languages, declare a variable of each, and assign the middle state.

## Task two
**Protection test** — List three errors a Pascal compiler catches in enum work that a classic C++ compiler lets pass, and how enum class changes each verdict.
