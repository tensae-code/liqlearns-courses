# Traversing a Binary Search Tree — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Visiting every node of a tree in a fixed, recursive order**
**Answer: True**

**2. (Sub lesson 1) True or false: Visiting every node of a tree in a fixed, recursive order** — as the answer to: What is the inorder order?
**Answer: False — Left subtree, root, right subtree**

**3. (Sub lesson 1) True or false: Root first, then left subtree, then right subtree**
**Answer: True**

**4. (Sub lesson 1) True or false: Root first, then left subtree, then right subtree** — as the answer to: What is the postorder order?
**Answer: False — Left subtree, right subtree, root last**

**5. (Sub lesson 1) True or false: Where the visit sits — before, between, or after the subtree walks**
**Answer: True**

**6. (Sub lesson 2) True or false: Where the visit sits — before, between, or after the subtree walks** — as the answer to: What is special about inorder on a BST?
**Answer: False — It visits the values in sorted order**

**7. (Sub lesson 2) True or false: Left subtrees hold smaller values, right subtrees larger, and inorder reads left–root–right**
**Answer: True**

**8. (Sub lesson 2) True or false: Left subtrees hold smaller values, right subtrees larger, and inorder reads left–root–right** — as the answer to: What is preorder good for?
**Answer: False — Copying the tree — the root arrives before its subtrees**

**9. (Sub lesson 2) True or false: Evaluating expressions, and deleting safely — children before their parent**
**Answer: True**

**10. (Sub lesson 2) True or false: Evaluating expressions, and deleting safely — children before their parent** — as the answer to: What two jobs does the book say the BST joins?
**Answer: False — Sorting and searching**
