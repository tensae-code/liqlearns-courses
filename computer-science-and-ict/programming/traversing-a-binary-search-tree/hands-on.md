# Hands-on — Traversing a Binary Search Tree

The lesson with your hands and your feet, not only your eyes.

## Task one
**Three orders** — Draw the BST built from 50, 30, 70, 20, 40. Write its inorder, preorder and postorder lists, and check the inorder list is sorted.

## Task two
**Which walk?** — A program must print a BST's values in ascending order, and another must delete the whole tree. Name the walk for each, with the reason.
