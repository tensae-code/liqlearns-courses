# Repeating Actions — Do It Again — true or false

Say whether each statement is true or false.

**1. Find the repeating part inside a long row of actions.**
**Answer: True** — This is one of the lesson's own outcomes.

**2. A repeating part is a fault in a program and should always be deleted.**
**Answer: False** — The lesson teaches the opposite of this.

**3. Say how many times the repeating part comes.**
**Answer: True** — This is one of the lesson's own outcomes.
