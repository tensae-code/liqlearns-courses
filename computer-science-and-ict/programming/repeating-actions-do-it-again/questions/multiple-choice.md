# Repeating Actions — Do It Again — multiple choice

Pick the one right answer.

**1. What is a repeating action?**
a) An action or group that comes again  b) An action done only once  c) An action nobody chose
**Answer: a) An action or group that comes again**

**2. The first step before writing a loop is —**
a) deleting the path  b) changing the goal  c) noticing which actions repeat
**Answer: c) noticing which actions repeat**

**3. A group of actions repeats 3 times. How many times do you perform it?**
a) Ten times  b) Three times  c) Once
**Answer: b) Three times**

**4. Why mark the repeating part in a long row?**
a) So the row can be understood and later shortened  b) To make the row longer  c) To hide the path
**Answer: a) So the row can be understood and later shortened**
