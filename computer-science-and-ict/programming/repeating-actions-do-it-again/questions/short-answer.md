# Repeating Actions — Do It Again — short answer

Answer in a sentence or two.

**1. Explain, in your own words: find the repeating part inside a long row of actions.**
**Answer:** The learner's own explanation, true to the lesson: Some actions in a path repeat: the same move comes again and again, and noticing the repeating part is the step before loops.

**2. A classmate gets this lesson's work wrong. What is the most likely fault, and how is it fixed?**
**Answer:** Cannot see the repeat → chant the actions aloud in a steady beat; the place where the chant starts to sound the same again is where the repeating part begins.
