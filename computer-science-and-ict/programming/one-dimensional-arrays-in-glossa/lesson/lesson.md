# One-Dimensional Arrays in ΓΛΩΣΣΑ

## Do it first

Thirty pupils, thirty marks. In ΓΛΩΣΣΑ you do not declare thirty variables — you declare one array and let a loop walk it. This lesson is that array: the AEPP course's most-used structure.

## Sub lesson 1 — Declaring and reaching an array

A **one-dimensional array (μονοδιάστατος πίνακας)** is a row of places of one type under one name, declared in ΓΛΩΣΣΑ as **ΠΙΝΑΚΑΣ[μέγεθος]** — name, then the count in brackets. Each place is reached by its **index**: Π[1] is the first place, Π[i] the place the variable i names — which is the whole power of the structure, because a **ΓΙΑ loop** counting i from 1 to the size can visit every place with the same commands: fill the array, print the array, search the array.

## Sub lesson 2 — When an array should be used — filling, reading, first work

The book's rule: reach for an array **when many values of one kind must all be kept** — because later commands need them again (to search, to sort, to compare against a second run), not merely passed once. The study guide and workbook work the standard first patterns: **input** into an array inside a loop, **output** of the whole array, the **sum and count** over its places, and input into **two-dimensional** arrays beside it — the graded exercises mark which are medium and which advanced, so the learner climbs the structure in the book's own order.
