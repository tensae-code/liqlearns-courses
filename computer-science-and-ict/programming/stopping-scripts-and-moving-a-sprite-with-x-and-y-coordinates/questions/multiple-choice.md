# Stopping Scripts — and Moving a Sprite with X and Y Coordinates — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Stop all ends —**
a) One script  b) Every script in the project  c) One sound
**Answer: b) Every script in the project** — Stop all is the full stop.

**2. (Sub lesson 1) One job finished but the sprite's other script must keep running — use —**
a) Stop all  b) Stop this script  c) Delete the sprite
**Answer: b) Stop this script** — Stop this script ends only its own script.

**3. (Sub lesson 2) A sprite's x coordinate tells —**
a) How far up it is  b) How far left or right it is  c) Its colour
**Answer: b) How far left or right it is** — X is the sideways number.

**4. (Sub lesson 2) To move a sprite up, you —**
a) Make y bigger  b) Make x smaller  c) Hide it
**Answer: a) Make y bigger** — Bigger y is up; smaller y is down.
