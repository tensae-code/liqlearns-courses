# Stopping Scripts — and Moving a Sprite with X and Y Coordinates — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Stop other scripts in this sprite keeps the containing script running.**
**Answer: True** — That is exactly its mirror-image job.

**2. (Sub lesson 2) Dragging is more exact than giving a sprite's coordinates.**
**Answer: False** — Coordinates land on the same exact place every time.

**3. (Sub lesson 2) Smaller x moves a sprite to the right.**
**Answer: False** — Smaller x is left; bigger x is right.
