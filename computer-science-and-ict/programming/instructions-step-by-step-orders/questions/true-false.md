# Instructions — Step-by-Step Orders — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: An order that tells an executor exactly one thing to do**
**Answer: True**

**2. (Sub lesson 1) True or false: An order that tells an executor exactly one thing to do** — as the answer to: What three tests must a good instruction pass?
**Answer: False — It must be clear, exact and doable**

**3. (Sub lesson 1) True or false: It is not clear or exact — the executor cannot know what is wanted**
**Answer: True**

**4. (Sub lesson 1) True or false: It is not clear or exact — the executor cannot know what is wanted** — as the answer to: Give a passing instruction from the lesson.
**Answer: False — 'Bring me the blue book from the table'**

**5. (Sub lesson 1) True or false: Every algorithm and every program**
**Answer: True**

**6. (Sub lesson 2) True or false: Every algorithm and every program** — as the answer to: In what forms can instructions come?
**Answer: False — Pictures, spoken words, written words, signs and arrows, and sounds**

**7. (Sub lesson 2) True or false: An instruction to stop**
**Answer: True**

**8. (Sub lesson 2) True or false: An instruction to stop** — as the answer to: Do instructions live only in pictures?
**Answer: False — No — pictures are only one of their forms**

**9. (Sub lesson 2) True or false: One order, for one executor, to be carried out exactly**
**Answer: True**

**10. (Sub lesson 2) True or false: One order, for one executor, to be carried out exactly** — as the answer to: Who or what carries out an instruction?
**Answer: False — Its executor**
