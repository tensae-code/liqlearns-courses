## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Stage, sprites, and the project's cast** — The **stage** (right) is where the project performs, with its backdrop; beneath and beside it, the **sprite list** holds the project's cast — every character/object (lutin) — and the **stage's own scripts and backdrops** live one click away. Selecting a sprite selects its scripts, costumes and sounds: in Scratch, everything belongs to someone — sprite or stage — and the interface's first lesson is asking “whose is this?” before editing anything.
2. **Palette and script area** — The **block palette** (left/centre) sorts blocks by category and colour — motion, looks, sound, events, control, sensing, operators, variables — and the **script area** is the bench where blocks snap into scripts for the selected sprite. Discovery ends with the interface read as a workflow: pick the **who** (sprite), take the **what** (blocks), build on the **bench**, watch on the **stage**. Pupils who own the geography can spend every later séance on ideas instead of hunting.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## The run of the lesson (in order)
1. **Do it first** — Scratch opens and everything is visible at once: a cat on a stage, towers of coloured blocks, lists and panes. New pupils freeze here. Before reading on, divide the screen into regions by eye — the discovery séance does exactly that, with names. (lesson/lesson.md).
2. **The explanation** — the lesson text in lesson/lesson.md, in its parts in order.
   - ADD IMAGE: a picture of stage, sprites, and the project's cast as the lesson describes it — the student studies the picture and names what each part shows.
   - ADD GIF: a GIF of palette and script area in action — the student watches once, then says what changed and why.
   - ADD AUDIO: a voice reading the lesson's key names and definitions aloud, in the order the lesson gives them — the student listens once through, then reads the same lines aloud along with the voice. (Audio is a described slot in this build; no audio file is made.)
3. **Say it to your companion** — the companion block in lesson/lesson.md.
   - ADD VIDEO: the script in video-script.md, filmed — the lesson in the super-simple voice (made later, when videos are made).
4. **Questions** — from questions/: multiple-choice, true-false, matching, short-answer — served at the learner's level and teaching-mix (levels.md).
5. **Hands-on** — hands-on.md.
6. **Do It Yourself** — the doing block at the end of lesson/lesson.md.
