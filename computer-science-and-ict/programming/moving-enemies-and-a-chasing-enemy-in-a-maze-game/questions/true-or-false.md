# Moving Enemies — and a Chasing Enemy — in a Maze Game — true or false

Say whether each statement is true or false.

**1. A patrol's route can be learned and timed.**
**Answer: True** — Its path between two points never changes.

**2. Standing still is a safe answer to a chasing enemy.**
**Answer: False** — It keeps steering at the player, so the distance shrinks.

**3. The three enemies are a difficulty order: patrol, random, chaser.**
**Answer: True** — Rising danger in that order.
