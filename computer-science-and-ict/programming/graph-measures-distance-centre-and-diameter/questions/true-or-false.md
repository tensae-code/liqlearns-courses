# Graph Measures — Distance, Centre and Diameter — true or false

Say whether each statement is true or false.

**1. (Sub lesson 2) The centre of a graph is always the node with the most edges.**
**Answer: False — The centre is the node of smallest eccentricity; a high-degree node on a stalk can still be far from one end.**

**2. (Sub lesson 1) In the wave method, a node’s first label is its true distance because the wave expands one edge at a time.**
**Answer: True — The wave cannot reach a node later by a shorter road; first arrival is the shortest.**
