# The Empty Instruction in Pascal — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Nothing, in an instruction's place
Sub lesson 1 questions from the type files. Pass mark: The absence of an instruction where one is grammatically allowed — it does nothing; Between two semicolons, after begin, or before end; No — it is a separator between instructions; A loop whose work is all in its condition (or a placeholder while building); No — no action, no state change.

## Sub lesson 2 — The classic trap — the stray semicolon
Sub lesson 2 questions from the type files. Pass mark: The empty instruction — so writeln runs always; Its body is empty, so nothing ever changes its condition; Reading with attention — a semicolon before a body that matters should ring a bell; No — it is legal; that is what makes it a trap; The writer — the machine executes what is written.
