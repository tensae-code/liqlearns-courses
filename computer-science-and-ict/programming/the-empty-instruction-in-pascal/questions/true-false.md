# The Empty Instruction in Pascal — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The absence of an instruction where one is grammatically allowed — it does nothing**
**Answer: True**

**2. (Sub lesson 1) True or false: The absence of an instruction where one is grammatically allowed — it does nothing** — as the answer to: Where can it appear?
**Answer: False — Between two semicolons, after begin, or before end**

**3. (Sub lesson 1) True or false: No — it is a separator between instructions**
**Answer: True**

**4. (Sub lesson 1) True or false: No — it is a separator between instructions** — as the answer to: Name an honest use of the empty instruction.
**Answer: False — A loop whose work is all in its condition (or a placeholder while building)**

**5. (Sub lesson 1) True or false: No — no action, no state change**
**Answer: True**

**6. (Sub lesson 2) True or false: No — no action, no state change** — as the answer to: In 'if x > 0 then ; writeln(x)', what is the if's body?
**Answer: False — The empty instruction — so writeln runs always**

**7. (Sub lesson 2) True or false: Its body is empty, so nothing ever changes its condition**
**Answer: True**

**8. (Sub lesson 2) True or false: Its body is empty, so nothing ever changes its condition** — as the answer to: What is the defence against the trap?
**Answer: False — Reading with attention — a semicolon before a body that matters should ring a bell**

**9. (Sub lesson 2) True or false: No — it is legal; that is what makes it a trap**
**Answer: True**

**10. (Sub lesson 2) True or false: No — it is legal; that is what makes it a trap** — as the answer to: Who is at fault in the trap — machine or writer?
**Answer: False — The writer — the machine executes what is written**
