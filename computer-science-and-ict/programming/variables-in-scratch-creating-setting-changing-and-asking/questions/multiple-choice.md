# Variables in Scratch — Creating, Setting, Changing and Asking — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does a variable hold?**
a) One value — a number or text — until changed  b) Create, set, change by, show and hide  c) Constants, expressions, and other variables  d) Square area and rectangle perimeter
**Answer: a) One value — a number or text — until changed**

**2. (Sub lesson 1) What are the variable blocks the book counts?**
a) The last value set, until it is set again  b) Create, set, change by, show and hide  c) The user’s typed answer, as the value  d) It can be deleted and renamed
**Answer: b) Create, set, change by, show and hide**

**3. (Sub lesson 1) What value does a variable keep?**
a) Constants, expressions, and other variables  b) Square area and rectangle perimeter  c) The last value set, until it is set again  d) Its own variable
**Answer: c) The last value set, until it is set again**

**4. (Sub lesson 1) What three kinds of value can be assigned?**
a) The user’s typed answer, as the value  b) It can be deleted and renamed  c) Totals multiplied out and added together  d) Constants, expressions, and other variables
**Answer: d) Constants, expressions, and other variables**

**5. (Sub lesson 1) What does ask-and-answer take from the keyboard?**
a) The user’s typed answer, as the value  b) Square area and rectangle perimeter  c) Its own variable  d) Meaningful variable names
**Answer: a) The user’s typed answer, as the value**

**6. (Sub lesson 2) What two programs does Grade 8 run on ask-and-answer?**
a) It can be deleted and renamed  b) Square area and rectangle perimeter  c) Totals multiplied out and added together  d) One value — a number or text — until changed
**Answer: b) Square area and rectangle perimeter**

**7. (Sub lesson 2) What can be done to a variable besides setting it?**
a) Its own variable  b) Meaningful variable names  c) It can be deleted and renamed  d) Create, set, change by, show and hide
**Answer: c) It can be deleted and renamed**

**8. (Sub lesson 2) In the fruit shop, what does each price and quantity get?**
a) Totals multiplied out and added together  b) One value — a number or text — until changed  c) The last value set, until it is set again  d) Its own variable
**Answer: d) Its own variable**

**9. (Sub lesson 2) How is the grand total built?**
a) Totals multiplied out and added together  b) Meaningful variable names  c) Create, set, change by, show and hide  d) Constants, expressions, and other variables
**Answer: a) Totals multiplied out and added together**

**10. (Sub lesson 2) What makes the shop program readable?**
a) One value — a number or text — until changed  b) Meaningful variable names  c) The last value set, until it is set again  d) The user’s typed answer, as the value
**Answer: b) Meaningful variable names**
