# Variables in Scratch — Creating, Setting, Changing and Asking — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does a variable hold?" is: One value — a number or text — until changed**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What are the variable blocks the book counts?" is: Constants, expressions, and other variables**
**Answer: False** — Create, set, change by, show and hide

**3. (Sub lesson 1) True or false: the answer to "What value does a variable keep?" is: The last value set, until it is set again**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What three kinds of value can be assigned?" is: Square area and rectangle perimeter**
**Answer: False** — Constants, expressions, and other variables

**5. (Sub lesson 1) True or false: the answer to "What does ask-and-answer take from the keyboard?" is: The user’s typed answer, as the value**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What two programs does Grade 8 run on ask-and-answer?" is: Its own variable**
**Answer: False** — Square area and rectangle perimeter

**7. (Sub lesson 2) True or false: the answer to "What can be done to a variable besides setting it?" is: It can be deleted and renamed**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "In the fruit shop, what does each price and quantity get?" is: Meaningful variable names**
