# Variables in Scratch — Creating, Setting, Changing and Asking

## Do it first

The shop needs a price for every kilo and a total at the end. Where does Scratch keep a number while the program runs? In a variable — a named box that holds one value until it is changed. Three Palestine books teach it; the Grade 9 fruit shop spends it.

## Sub lesson 1 — Creating, setting, changing — and asking the user

The variable blocks are five in Grade 9’s count: **create** a named variable, **set** it, **change** it by an amount, **show and hide** it — and a variable **keeps the last value** in memory until set again. Values can be **constants, expressions, or other variables**. Grade 8 adds **ask-and-answer**: the program asks, the keyboard’s typed answer becomes the value — the square-area and rectangle-perimeter programs run on it. Variables can be **deleted and renamed**.

## Sub lesson 2 — Variables at work — the fruit shop’s arithmetic

Grade 9’s fruit seller runs its shop on variables: **a variable for each price per kilo and each quantity**, totals **multiplied out and added into one grand total**. The discipline is in the names: variables are given **meaningful names**, so the program can be read like the shop’s own notebook. Seller and buyer sprites greet each other by broadcast while the arithmetic runs.

## Say it to your companion

Tell your companion, in your own words: A variable holds one value — a number or text — until changed: create it and name it, set it, change it by an amount, show or hide it; ask-and-answer takes input from the keyboard into a variable; meaningful names and one variable per price and quantity run the shop’s arithmetic. Then let your companion ask you one question about it — and answer from the lesson, not from memory of the book's exact words.

## Do It Yourself

1. Show it, don't just say it: One value — a number or text — until changed. Do this with a real example of your own and write or say how you know it is right.
2. Show it, don't just say it: Create, set, change by, show and hide. Do this with a real example of your own and write or say how you know it is right.
3. Show it, don't just say it: The last value set, until it is set again. Do this with a real example of your own and write or say how you know it is right.
4. Show it, don't just say it: Constants, expressions, and other variables. Do this with a real example of your own and write or say how you know it is right.
