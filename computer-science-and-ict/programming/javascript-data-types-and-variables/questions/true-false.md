# JavaScript Data Types and Variables — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Name JavaScript's main types." is: number, string, boolean — with undefined and null as empty markers**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Are 42 and 3.14 different types in JavaScript?" is: undefined: declared but given nothing; null: deliberately nothing**
**Answer: False** — No — both are number

**3. (Sub lesson 1) True or false: the answer to "What is undefined, against null?" is: undefined: declared but given nothing; null: deliberately nothing**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does loosely typed mean?" is: '53' as text (joining) and 2 as a calculation — the operator follows the types it meets**
**Answer: False** — A variable's type is its current value's type — it may hold a number, later a string

**5. (Sub lesson 1) True or false: the answer to "'5' + 3 and '5' − 3 give what, and why?" is: '53' as text (joining) and 2 as a calculation — the operator follows the types it meets**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Which word declares a changeable variable, modern style?" is: const — its assignment cannot be replaced**
**Answer: False** — let

**7. (Sub lesson 2) True or false: the answer to "Which declares a constant?" is: const — its assignment cannot be replaced**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is var?" is: let promises change; const promises fixity**
**Answer: False** — The older declaring word, with wider scope — met in older scripts

**9. (Sub lesson 2) True or false: the answer to "What do let and const each promise?" is: let promises change; const promises fixity**
**Answer: True**
