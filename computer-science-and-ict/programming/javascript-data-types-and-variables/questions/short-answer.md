# JavaScript Data Types and Variables — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) Name JavaScript's main types.**
**Answer: number, string, boolean — with undefined and null as empty markers**

**2. (Sub lesson 1) Are 42 and 3.14 different types in JavaScript?**
**Answer: No — both are number**

**3. (Sub lesson 1) What is undefined, against null?**
**Answer: undefined: declared but given nothing; null: deliberately nothing**

**4. (Sub lesson 1) What does loosely typed mean?**
**Answer: A variable's type is its current value's type — it may hold a number, later a string**

**5. (Sub lesson 1) '5' + 3 and '5' − 3 give what, and why?**
**Answer: '53' as text (joining) and 2 as a calculation — the operator follows the types it meets**

**6. (Sub lesson 2) Which word declares a changeable variable, modern style?**
**Answer: let**

**7. (Sub lesson 2) Which declares a constant?**
**Answer: const — its assignment cannot be replaced**

**8. (Sub lesson 2) What is var?**
**Answer: The older declaring word, with wider scope — met in older scripts**

**9. (Sub lesson 2) What do let and const each promise?**
**Answer: let promises change; const promises fixity**

**10. (Sub lesson 2) Why police loose typing yourself?**
**Answer: Because the same variable can silently change type between uses**
