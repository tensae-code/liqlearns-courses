# Counters and Accumulators — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does a counter do?**
a) Counts by adding 1 each time an event happens  b) At zero  c) Exactly 1  d) How many times the event has happened so far
**Answer: a) Counts by adding 1 each time an event happens**

**2. (Sub lesson 1) Where does a counter usually start?**
a) Exactly 1  b) At zero  c) How many times the event has happened so far  d) Starting it at the wrong value, or not starting it
**Answer: b) At zero**

**3. (Sub lesson 1) By how much does a counter grow each time?**
a) How many times the event has happened so far  b) Starting it at the wrong value, or not starting it  c) Exactly 1  d) Adds each arriving value into a running total
**Answer: c) Exactly 1**

**4. (Sub lesson 1) What does a counter tell at any moment?**
a) Starting it at the wrong value, or not starting it  b) Adds each arriving value into a running total  c) By the value that arrives, not by 1  d) How many times the event has happened so far
**Answer: d) How many times the event has happened so far**

**5. (Sub lesson 1) What is the classic counter fault?**
a) Starting it at the wrong value, or not starting it  b) Adds each arriving value into a running total  c) By the value that arrives, not by 1  d) How much altogether
**Answer: a) Starting it at the wrong value, or not starting it**

**6. (Sub lesson 2) What does an accumulator do?**
a) By the value that arrives, not by 1  b) Adds each arriving value into a running total  c) How much altogether  d) The counter counts the values, the accumulator totals them
**Answer: b) Adds each arriving value into a running total**

**7. (Sub lesson 2) By how much does an accumulator grow?**
a) How much altogether  b) The counter counts the values, the accumulator totals them  c) By the value that arrives, not by 1  d) The average — total divided by count
**Answer: c) By the value that arrives, not by 1**

**8. (Sub lesson 2) What question does an accumulator answer?**
a) The counter counts the values, the accumulator totals them  b) The average — total divided by count  c) Counts by adding 1 each time an event happens  d) How much altogether
**Answer: d) How much altogether**

**9. (Sub lesson 2) What two jobs work side by side in a loop?**
a) The counter counts the values, the accumulator totals them  b) The average — total divided by count  c) Counts by adding 1 each time an event happens  d) At zero
**Answer: a) The counter counts the values, the accumulator totals them**

**10. (Sub lesson 2) What do counter and accumulator give together?**
a) Counts by adding 1 each time an event happens  b) The average — total divided by count  c) At zero  d) Exactly 1
**Answer: b) The average — total divided by count**
