# Counters and Accumulators — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does a counter do?" is: Counts by adding 1 each time an event happens**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Where does a counter usually start?" is: Exactly 1**
**Answer: False** — At zero

**3. (Sub lesson 1) True or false: the answer to "By how much does a counter grow each time?" is: Exactly 1**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does a counter tell at any moment?" is: Starting it at the wrong value, or not starting it**
**Answer: False** — How many times the event has happened so far

**5. (Sub lesson 1) True or false: the answer to "What is the classic counter fault?" is: Starting it at the wrong value, or not starting it**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does an accumulator do?" is: By the value that arrives, not by 1**
**Answer: False** — Adds each arriving value into a running total

**7. (Sub lesson 2) True or false: the answer to "By how much does an accumulator grow?" is: By the value that arrives, not by 1**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What question does an accumulator answer?" is: The counter counts the values, the accumulator totals them**
**Answer: False** — How much altogether

**9. (Sub lesson 2) True or false: the answer to "What two jobs work side by side in a loop?" is: The counter counts the values, the accumulator totals them**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What do counter and accumulator give together?" is: Counts by adding 1 each time an event happens**
**Answer: False** — The average — total divided by count
