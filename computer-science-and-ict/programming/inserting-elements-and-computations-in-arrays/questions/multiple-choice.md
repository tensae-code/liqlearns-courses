# Inserting Elements and Computations in Arrays — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What records how many elements are live?**
a) A counter, n  b) One by one, in a fill loop  c) No — the array may hold 100 and contain 7  d) n — the live count
**Answer: a) A counter, n**

**2. (Sub lesson 1) How do typed values enter an array?**
a) No — the array may hold 100 and contain 7  b) One by one, in a fill loop  c) n — the live count  d) The empty tail
**Answer: b) One by one, in a fill loop**

**3. (Sub lesson 1) Are capacity and live count the same?**
a) n — the live count  b) The empty tail  c) No — the array may hold 100 and contain 7  d) The sum divided by the live count n
**Answer: c) No — the array may hold 100 and contain 7**

**4. (Sub lesson 1) What limit do later walks use?**
a) The empty tail  b) The sum divided by the live count n  c) Computing a second array from the first, element by element  d) n — the live count
**Answer: d) n — the live count**

**5. (Sub lesson 1) What is the unfilled part of the array called here?**
a) The empty tail  b) The sum divided by the live count n  c) Computing a second array from the first, element by element  d) Dividing by the capacity instead of n
**Answer: a) The empty tail**

**6. (Sub lesson 2) What is an average over an array?**
a) Computing a second array from the first, element by element  b) The sum divided by the live count n  c) Dividing by the capacity instead of n  d) Garbage values
**Answer: b) The sum divided by the live count n**

**7. (Sub lesson 2) What is a transformation in this lesson?**
a) Dividing by the capacity instead of n  b) Garbage values  c) Computing a second array from the first, element by element  d) Capacity and live count
**Answer: c) Computing a second array from the first, element by element**

**8. (Sub lesson 2) What is the classic fault with averages?**
a) Garbage values  b) Capacity and live count  c) A counter, n  d) Dividing by the capacity instead of n
**Answer: d) Dividing by the capacity instead of n**

**9. (Sub lesson 2) What waits in the unfilled tail?**
a) Garbage values  b) Capacity and live count  c) A counter, n  d) One by one, in a fill loop
**Answer: a) Garbage values**

**10. (Sub lesson 2) Which two numbers must every array program keep apart?**
a) A counter, n  b) Capacity and live count  c) One by one, in a fill loop  d) No — the array may hold 100 and contain 7
**Answer: b) Capacity and live count**
