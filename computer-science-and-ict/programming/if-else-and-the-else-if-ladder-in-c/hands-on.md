# Hands-on — If Else and the Else If Ladder in C

The lesson with your hands and your feet, not only your eyes.

## Task one
**Work the book's own example** — Unit 3 §3.2.2 If-else statement (the else-without-if error; DIGIT / NOT DIGIT program; the if–else–if ladder; grade-from-percentage program) Work it with the book open first, step by step, then close the book and do it again.

## Task two
**Show it to someone else** — Teach if else and the else if ladder in c to a companion in your own words, with your worked example in front of you, and answer their one question from the lesson.
