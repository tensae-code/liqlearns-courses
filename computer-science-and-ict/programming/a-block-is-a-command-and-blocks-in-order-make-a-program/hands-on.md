# Hands-on — A Block Is a Command — and Blocks in Order Make a Program

The lesson with your hands and your feet, not only your eyes.

## Reach the sheep
Build the shortest program that guides Steve or Alex to the sheep. Run it and watch each block obeyed in order.

## Break the wood, then show the code
Solve Breaking the wood, then open the show-code view and read your blocks as JavaScript lines.
