# A Block Is a Command — and Blocks in Order Make a Program — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is one block in the Minecraft adventures?**
a) One command the character obeys  b) A program  c) JavaScript code, in the show-code view  d) Move, turn and destroy
**Answer: a) One command the character obeys**

**2. (Sub lesson 1) What do blocks snapped together in order make?**
a) The run button  b) A program  c) Reaching the sheep  d) It makes the program do a different thing
**Answer: b) A program**

**3. (Sub lesson 1) What starts the commands running?**
a) JavaScript code, in the show-code view  b) Move, turn and destroy  c) The run button  d) The plan itself
**Answer: c) The run button**

**4. (Sub lesson 1) What can the same program be shown as?**
a) Reaching the sheep  b) It makes the program do a different thing  c) From the first block to the last  d) JavaScript code, in the show-code view
**Answer: d) JavaScript code, in the show-code view**

**5. (Sub lesson 1) What is the first puzzle of the book?**
a) Reaching the sheep  b) Move, turn and destroy  c) The plan itself  d) No — exactly the block given, nothing more
**Answer: a) Reaching the sheep**

**6. (Sub lesson 2) What three commands does Breaking the wood string together?**
a) It makes the program do a different thing  b) Move, turn and destroy  c) From the first block to the last  d) One command the character obeys
**Answer: b) Move, turn and destroy**

**7. (Sub lesson 2) What does changing the order of the blocks do?**
a) The plan itself  b) No — exactly the block given, nothing more  c) It makes the program do a different thing  d) A program
**Answer: c) It makes the program do a different thing**

**8. (Sub lesson 2) What is the order of the blocks, in the book’s teaching?**
a) From the first block to the last  b) One command the character obeys  c) The run button  d) The plan itself
**Answer: d) The plan itself**

**9. (Sub lesson 2) How does a program run?**
a) From the first block to the last  b) No — exactly the block given, nothing more  c) A program  d) JavaScript code, in the show-code view
**Answer: a) From the first block to the last**

**10. (Sub lesson 2) Does the character obey more than the block given?**
a) One command the character obeys  b) No — exactly the block given, nothing more  c) The run button  d) Reaching the sheep
**Answer: b) No — exactly the block given, nothing more**
