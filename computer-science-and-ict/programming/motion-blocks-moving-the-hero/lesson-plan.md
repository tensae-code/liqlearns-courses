# Lesson plan — Motion Blocks — Moving the Hero

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** Motion Blocks — Moving the Hero
**Place in the curriculum:** ICT expansion — Bulgaria (2026-11-14) — in the title Programming on the ICT course ladder (TITLES.md). Built new from Bulgaria's *Компютърно моделиране* (Computer Modelling), Grade 3, because no existing lesson teaches this thing as its own lesson at this level.
**The one thing this lesson teaches:** Motion blocks are the blocks that move the hero: each block is one movement, and snapping motion blocks together builds the hero's whole path.
**This lesson's own level:** Grade 3 simple — it stands on the child's own everyday world and on the lessons named below; every new word is built inside the lesson from things the child can do at once.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Before this lesson
- Recommended first: the earlier lessons in Programming on the ladder. Recommended, never forced — a learner may land on this lesson directly, and it stands alone.

## What the learner can do when it ends
1. Say what a motion block does
2. Build a short path for the hero out of motion blocks
3. Read a row of motion blocks and say where the hero will end before running it

## What you need
The code.org Course 1 puzzles on a computer, or motion-block cards on paper.

## The run of the lesson (in order)
1. **Do it first** — Point to the way you want a character on the screen to go. Say the moves out loud — forward, forward, turn. Each move you named can be a block: that is what motion blocks are. (lesson/lesson.md).
2. **The explanation** — the lesson text in lesson/lesson.md, in its parts in order.
   - ADD IMAGE: a picture of a picture of three motion blocks snapped in a row — move, turn, move — with the hero character following the same path on a small map beside them — the student names what the picture shows and ties each part of it to the lesson's one thing.
   - ADD AUDIO: a voice reading the lesson's key names and definitions aloud, in the order the lesson gives them — the student listens once through, then reads the same lines aloud along with the voice. (Audio is a described slot in this build; no audio file is made.)
3. **Say it to your companion** — the companion block in lesson/lesson.md.
   - ADD VIDEO: the script in video-script.md, filmed — the lesson in the super-simple voice (made later, when videos are made).
4. **Questions** — from questions/: multiple-choice, true-or-false, fill-in-the-blank, short-answer — served at the learner's level and teaching-mix (levels.md).
5. **Hands-on** — hands-on.md.
6. **Do It Yourself** — the doing block at the end of lesson/lesson.md.

## If the learner is stuck
Hero stops short or goes too far → count the blocks and check the number in the move block: the hero does exactly what the blocks say, no more.
