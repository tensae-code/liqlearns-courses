# Hands-on — Motion Blocks — Moving the Hero

The lesson with your hands, not only your eyes.

## Read before you run
Build a row of motion blocks for a partner. Before anyone runs it, the partner must point to where the hero will end. Run it and check.

## One block, one move
Act out a row of motion blocks with your body: a classmate reads the blocks one at a time and you move only when a block is read.
