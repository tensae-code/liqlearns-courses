# Motion Blocks — Moving the Hero — true or false

Say whether each statement is true or false.

**1. Say what a motion block does.**
**Answer: True** — This is one of the lesson's own outcomes.

**2. A motion block can make the hero do three movements at once, in any order.**
**Answer: False** — The lesson teaches the opposite of this.

**3. Build a short path for the hero out of motion blocks.**
**Answer: True** — This is one of the lesson's own outcomes.
