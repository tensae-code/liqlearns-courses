# Hands-on — Array Indexing and Access

The lesson with your hands and your feet, not only your eyes.

## Index drill
For double t[8], write: the index of the first, fifth and last elements; a loop printing all eight; the two indexes that would be out of bounds at each end.

## Find the bug
A program declares int a[5] and loops for (i = 0; i <= 5; i++) a[i] = i;. Find the fault, name the iteration where it strikes, and fix the loop.
