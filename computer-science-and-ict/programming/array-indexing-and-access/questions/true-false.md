# Array Indexing and Access — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What index does the first element have?" is: 0**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What index does the last element of size n have?" is: In square brackets after the array name**
**Answer: False** — n − 1

**3. (Sub lesson 1) True or false: the answer to "What can an index be?" is: Any integer expression — literal, variable or calculation**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Which loop visits each element exactly once?" is: No — no bounds checking is done**
**Answer: False** — for (i = 0; i < n; i++)

**5. (Sub lesson 1) True or false: the answer to "Where is the index written?" is: In square brackets after the array name**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Does a[n] exist in an array of size n?" is: i < n, never i <= n**
**Answer: False** — No — it is past the last element

**7. (Sub lesson 2) True or false: the answer to "Does C++ check array bounds?" is: No — no bounds checking is done**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What can writing out of bounds do?" is: 0**
**Answer: False** — Damage whatever lives in that memory

**9. (Sub lesson 2) True or false: the answer to "What loop condition guards the edge?" is: i < n, never i <= n**
**Answer: True**
