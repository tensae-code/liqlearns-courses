# Array Indexing and Access — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What index does the first element have?**
a) 0  b) n − 1  c) Any integer expression — literal, variable or calculation  d) for (i = 0; i < n; i++)
**Answer: a) 0**

**2. (Sub lesson 1) What index does the last element of size n have?**
a) Any integer expression — literal, variable or calculation  b) n − 1  c) for (i = 0; i < n; i++)  d) In square brackets after the array name
**Answer: b) n − 1**

**3. (Sub lesson 1) What can an index be?**
a) for (i = 0; i < n; i++)  b) In square brackets after the array name  c) Any integer expression — literal, variable or calculation  d) No — it is past the last element
**Answer: c) Any integer expression — literal, variable or calculation**

**4. (Sub lesson 1) Which loop visits each element exactly once?**
a) In square brackets after the array name  b) No — it is past the last element  c) No — no bounds checking is done  d) for (i = 0; i < n; i++)
**Answer: d) for (i = 0; i < n; i++)**

**5. (Sub lesson 1) Where is the index written?**
a) In square brackets after the array name  b) No — it is past the last element  c) No — no bounds checking is done  d) Damage whatever lives in that memory
**Answer: a) In square brackets after the array name**

**6. (Sub lesson 2) Does a[n] exist in an array of size n?**
a) No — no bounds checking is done  b) No — it is past the last element  c) Damage whatever lives in that memory  d) i < n, never i <= n
**Answer: b) No — it is past the last element**

**7. (Sub lesson 2) Does C++ check array bounds?**
a) Damage whatever lives in that memory  b) i < n, never i <= n  c) No — no bounds checking is done  d) Off-by-one at the array's edge
**Answer: c) No — no bounds checking is done**

**8. (Sub lesson 2) What can writing out of bounds do?**
a) i < n, never i <= n  b) Off-by-one at the array's edge  c) 0  d) Damage whatever lives in that memory
**Answer: d) Damage whatever lives in that memory**

**9. (Sub lesson 2) What loop condition guards the edge?**
a) i < n, never i <= n  b) Off-by-one at the array's edge  c) 0  d) n − 1
**Answer: a) i < n, never i <= n**

**10. (Sub lesson 2) What is the classic array bug called?**
a) 0  b) Off-by-one at the array's edge  c) n − 1  d) Any integer expression — literal, variable or calculation
**Answer: b) Off-by-one at the array's edge**
