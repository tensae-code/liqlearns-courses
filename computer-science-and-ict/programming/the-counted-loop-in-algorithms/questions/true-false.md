# The Counted Loop in Algorithms — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Its repetitions are known in number before it starts**
**Answer: True**

**2. (Sub lesson 1) True or false: Its repetitions are known in number before it starts** — as the answer to: What is the counter?
**Answer: False — A variable that starts at an initial value and increases by a step after each pass**

**3. (Sub lesson 1) True or false: When the counter passes the final value**
**Answer: True**

**4. (Sub lesson 1) True or false: When the counter passes the final value** — as the answer to: Name the counted loop's three parts.
**Answer: False — Body, counter, limit**

**5. (Sub lesson 1) True or false: Start 1, step 1**
**Answer: True**

**6. (Sub lesson 2) True or false: Start 1, step 1** — as the answer to: Name counted-loop work from the lesson.
**Answer: False — A fence of n posts, reading n marks, summing the first n numbers**

**7. (Sub lesson 2) True or false: 1, then 3, then 6, as the counter walks 1, 2, 3**
**Answer: True**

**8. (Sub lesson 2) True or false: 1, then 3, then 6, as the counter walks 1, 2, 3** — as the answer to: Why must a counted loop end?
**Answer: False — The counter climbs by its step to the limit without fail**

**9. (Sub lesson 2) True or false: A variable gathering the running total across the loop's passes**
**Answer: True**

**10. (Sub lesson 2) True or false: A variable gathering the running total across the loop's passes** — as the answer to: Why does each value enter exactly once?
**Answer: False — The counter visits each value in its climb exactly once**
