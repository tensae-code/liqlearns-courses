# The Counted Loop in Algorithms — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What makes a loop counted?** → **Its repetitions are known in number before it starts**

**2. (Sub lesson 1) What is the counter?** → **A variable that starts at an initial value and increases by a step after each pass**

**3. (Sub lesson 1) When does a counted loop end?** → **When the counter passes the final value**

**4. (Sub lesson 1) Name the counted loop's three parts.** → **Body, counter, limit**

**5. (Sub lesson 1) What is the usual start and step?** → **Start 1, step 1**

**6. (Sub lesson 2) Name counted-loop work from the lesson.** → **A fence of n posts, reading n marks, summing the first n numbers**

**7. (Sub lesson 2) Trace the sum 1+2+3: how does the sum grow?** → **1, then 3, then 6, as the counter walks 1, 2, 3**

**8. (Sub lesson 2) Why must a counted loop end?** → **The counter climbs by its step to the limit without fail**

**9. (Sub lesson 2) What is an accumulator?** → **A variable gathering the running total across the loop's passes**

**10. (Sub lesson 2) Why does each value enter exactly once?** → **The counter visits each value in its climb exactly once**
