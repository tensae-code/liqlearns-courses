# Hands-on — The Counted Loop in Algorithms

The lesson with your hands and your feet, not only your eyes.

## Task one
**Trace table** — Build the full trace table (counter, sum) for summing the first 5 numbers with a counted loop, and mark the pass where the loop test first fails.

## Task two
**Fence program** — Write the fence algorithm — post, rail, repeat — as a counted loop for n posts, then change it to plant a row of 12 trees.
