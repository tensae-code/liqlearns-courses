# Hands-on — Project Work — Build Your Own Scratch Project

The lesson with your hands, not only your eyes.

## Plan, build, show
Write a five-line plan for your own project. Build it in steps, ticking each working part, then show it to the class and name the skills it uses.

## Grow a project
Take the finished project and add exactly one new part — a line of dialogue, a costume switch, a sound. Run it and check nothing old broke.
