# Project Work — Build Your Own Scratch Project

## Do it first

Think of everything you can now do in Scratch: move, draw, speak, change places and looks. A project is where you stop practising one skill and start using them all on an idea of your own.

## Project Work — Build Your Own Scratch Project

Twice in Grade 3 the book stops teaching new blocks and sets **project work (Работа по проект)**: build a Scratch project of your own. A project starts with an **idea and a short plan** — what happens, which sprites, which place, what is said — and is then built **step by step** from the skills already proved: positioning and movement, backdrops and costumes, say and think blocks, dialogues, loops and sound. Working in steps matters: build one part, run it, fix it, then add the next. A finished project is **shown** — run for others, who can say what happens in it. Both of the book's project blocks (Урок 24–25 and Урок 28–29) stock this one lesson: the second project goes further because the learner's toolbox is bigger by then, not because the work is a different thing.

## Say it to your companion

Tell your companion, in your own words: Project work means building a Scratch project of your own from the skills already learned — your own sprites, backdrops, movement, speech and sound, planned first and built step by step. Then let your companion ask you one question about it — and answer from the lesson, not from memory of the book's exact words.

## Do It Yourself

1. Show it, don't just say it: plan a Scratch project: idea, sprites, place, and what is said. Do this with a real example from your own work or your own school day, and write or say how you know it is right.
2. Show it, don't just say it: build the project step by step, running and fixing each part. Do this with a real example from your own work or your own school day, and write or say how you know it is right.
3. Show it, don't just say it: show the finished project and say how it was built. Do this with a real example from your own work or your own school day, and write or say how you know it is right.
