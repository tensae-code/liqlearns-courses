# Project Work — Build Your Own Scratch Project — short answer

Answer in a sentence or two.

**1. Explain, in your own words: plan a Scratch project: idea, sprites, place, and what is said.**
**Answer:** The learner's own explanation, true to the lesson: Project work means building a Scratch project of your own from the skills already learned — your own sprites, backdrops, movement, speech and sound, planned first and built step by step.

**2. A classmate gets this lesson's work wrong. What is the most likely fault, and how is it fixed?**
**Answer:** Project feels too big → shrink the first step: one sprite, one backdrop, one action, run and working — then grow it part by part.
