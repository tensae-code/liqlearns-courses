# Project Work — Build Your Own Scratch Project — multiple choice

Pick the one right answer.

**1. Project work starts with —**
a) an idea and a short plan  b) the sound gallery  c) a finished project
**Answer: a) an idea and a short plan**

**2. A project is built —**
a) all at once without running  b) by copying a partner exactly  c) step by step, running and fixing each part
**Answer: c) step by step, running and fixing each part**

**3. A finished project is —**
a) deleted at once  b) shown and explained  c) hidden away
**Answer: b) shown and explained**

**4. The two project blocks in the book stock one lesson because —**
a) the work is the same thing, with a bigger toolbox the second time  b) they are on the same page  c) projects need no plan
**Answer: a) the work is the same thing, with a bigger toolbox the second time**
