# Actions in Sequence — First, Then, Next — multiple choice

Pick the one right answer.

**1. A sequence is —**
a) actions in an order, one after another  b) one action only  c) a group of objects
**Answer: a) actions in an order, one after another** — First, then, next, last.

**2. Which order word comes at the start?**
a) Last  b) Next  c) First
**Answer: c) First** — A sequence begins with 'first'.

**3. Planting a seed, the right order is —**
a) water, dig, seed, cover  b) dig, seed, cover, water  c) seed, water, dig, cover
**Answer: b) dig, seed, cover, water** — Each action waits for the one before.

**4. A missing step in a sequence —**
a) does no harm  b) can break the sequence  c) makes it faster
**Answer: b) can break the sequence** — Nothing skipped — every action must be there.
