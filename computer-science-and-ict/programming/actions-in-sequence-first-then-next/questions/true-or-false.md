# Actions in Sequence — First, Then, Next — true or false

Say whether each statement is true or false.

**1. Changing the order of actions can break the result.**
**Answer: True** — Rinsing before soaping does not wash hands.

**2. Every action in a sequence can swap places freely.**
**Answer: False** — Many actions must stay in their order.

**3. 'First, then, next, last' are order words.**
**Answer: True** — They say the place of each action.
