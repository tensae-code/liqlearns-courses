# The Stack Data Structure — and Postfix — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A data structure keeping values in a pile with one open end — the top**
**Answer: True**

**2. (Sub lesson 1) True or false: A data structure keeping values in a pile with one open end — the top** — as the answer to: What do push and pop do?
**Answer: False — Push puts a value on top; pop takes the top value off**

**3. (Sub lesson 1) True or false: Last in, first out — the stack's law**
**Answer: True**

**4. (Sub lesson 1) True or false: Last in, first out — the stack's law** — as the answer to: Name two everyday stacks.
**Answer: False — A pile of plates, and an editor's undo history**

**5. (Sub lesson 1) True or false: Its restriction — only the top may be touched**
**Answer: True**

**6. (Sub lesson 2) True or false: Its restriction — only the top may be touched** — as the answer to: What is postfix notation?
**Answer: False — The operator follows its values — 3 4 + instead of 3 + 4**

**7. (Sub lesson 2) True or false: Push numbers; at an operator, pop two values, apply it, push the result**
**Answer: True**

**8. (Sub lesson 2) True or false: Push numbers; at an operator, pop two values, apply it, push the result** — as the answer to: What remains on the stack at the end?
**Answer: False — The single answer**

**9. (Sub lesson 2) True or false: Brackets or precedence rules — the stack's order does the grammar**
**Answer: True**

**10. (Sub lesson 2) True or false: Brackets or precedence rules — the stack's order does the grammar** — as the answer to: How does the queue differ?
**Answer: False — First in, first out — Grade 10 teaches choosing between stack and queue by the problem's shape**
