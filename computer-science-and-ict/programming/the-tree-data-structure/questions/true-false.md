# The Tree Data Structure — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Data arranged as a branching hierarchy under one root**
**Answer: True**

**2. (Sub lesson 1) True or false: Data arranged as a branching hierarchy under one root** — as the answer to: What is the root?
**Answer: False — The single starting node at the top**

**3. (Sub lesson 1) True or false: Nodes with no children**
**Answer: True**

**4. (Sub lesson 1) True or false: Nodes with no children** — as the answer to: How many parents has every non-root node?
**Answer: False — Exactly one**

**5. (Sub lesson 1) True or false: Loops — following branches never returns to a node twice**
**Answer: True**

**6. (Sub lesson 2) True or false: Loops — following branches never returns to a node twice** — as the answer to: What is a node's depth?
**Answer: False — The number of edges down from the root**

**7. (Sub lesson 2) True or false: Its longest root-to-leaf road**
**Answer: True**

**8. (Sub lesson 2) True or false: Its longest root-to-leaf road** — as the answer to: What is a subtree?
**Answer: False — Any node taken with all its descendants — itself a complete tree**

**9. (Sub lesson 2) True or false: A tree is made of smaller trees — the subtree has the same shape as the whole**
**Answer: True**

**10. (Sub lesson 2) True or false: A tree is made of smaller trees — the subtree has the same shape as the whole** — as the answer to: Name three uses of trees.
**Answer: False — File systems, organisation charts, family descent, classification, decision trees (any three)**
