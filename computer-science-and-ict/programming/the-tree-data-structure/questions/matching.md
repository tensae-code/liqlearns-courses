# The Tree Data Structure — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What is a tree, as a data structure?** → **Data arranged as a branching hierarchy under one root**

**2. (Sub lesson 1) What is the root?** → **The single starting node at the top**

**3. (Sub lesson 1) What are leaves?** → **Nodes with no children**

**4. (Sub lesson 1) How many parents has every non-root node?** → **Exactly one**

**5. (Sub lesson 1) What do trees never contain?** → **Loops — following branches never returns to a node twice**

**6. (Sub lesson 2) What is a node's depth?** → **The number of edges down from the root**

**7. (Sub lesson 2) What is a tree's height?** → **Its longest root-to-leaf road**

**8. (Sub lesson 2) What is a subtree?** → **Any node taken with all its descendants — itself a complete tree**

**9. (Sub lesson 2) Why are tree programs often recursive?** → **A tree is made of smaller trees — the subtree has the same shape as the whole**

**10. (Sub lesson 2) Name three uses of trees.** → **File systems, organisation charts, family descent, classification, decision trees (any three)**
