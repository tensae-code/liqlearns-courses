# The Tree Data Structure — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a tree, as a data structure?**
a) Data arranged as a branching hierarchy under one root  b) The single starting node at the top  c) Nodes with no children  d) Exactly one
**Answer: a**

**2. (Sub lesson 1) What is the root?**
a) The single starting node at the top  b) Nodes with no children  c) Exactly one  d) Loops — following branches never returns to a node twice
**Answer: a**

**3. (Sub lesson 1) What are leaves?**
a) Nodes with no children  b) Exactly one  c) Loops — following branches never returns to a node twice  d) The number of edges down from the root
**Answer: a**

**4. (Sub lesson 1) How many parents has every non-root node?**
a) Exactly one  b) Loops — following branches never returns to a node twice  c) The number of edges down from the root  d) Its longest root-to-leaf road
**Answer: a**

**5. (Sub lesson 1) What do trees never contain?**

**Answer: a**
