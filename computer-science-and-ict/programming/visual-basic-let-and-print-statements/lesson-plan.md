## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **LET — the assignment statement** — **LET** assigns a value to a variable: `LET X = 5` puts 5 into X. The variable stands on the **left**, the value or expression on the **right**, and the equals sign here means **'becomes'**, not 'is equal to'. The book names the **common errors** with LET plainly: putting the variable on the right, trying to assign to a constant, and confusing assignment with a test of equality — the three mistakes every beginner makes, named before they harden.
2. **PRINT — showing what the program holds** — **PRINT** shows output: a **number** (`PRINT 7`), a **text constant** in quotation marks, a **variable's value** (`PRINT X` shows what X holds, not the letter X), **string variables**, the **joining of two text variables**, and the **result of a maths expression** — PRINT works the expression out and shows the answer. Read a PRINT line by asking one question: is this item in quotes (shown as it stands), a variable (its value is shown), or an expression (its result is shown)?

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
