# Visual Basic — LET and PRINT Statements — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does LET do?**
**Answer: Assigns a value to a variable**

**2. (Sub lesson 1) In LET X = 5, what does the equals sign mean?**
**Answer: Becomes — X becomes 5; it is assignment, not a test of equality**

**3. (Sub lesson 1) Which side does the variable stand on?**
**Answer: The left; the value or expression stands on the right**

**4. (Sub lesson 1) Name a common error with LET.**
**Answer: Putting the variable on the right (any one of: assigning to a constant; confusing assignment with equality)**

**5. (Sub lesson 1) What does PRINT do?**
**Answer: Shows output — values and results**

**6. (Sub lesson 2) What does PRINT X show?**
**Answer: The value X holds, not the letter X**

**7. (Sub lesson 2) How is a text constant shown by PRINT?**
**Answer: As it stands — it is written in quotation marks**

**8. (Sub lesson 2) What does PRINT show for a maths expression?**
**Answer: Its result — PRINT works the expression out**

**9. (Sub lesson 2) How do you read any PRINT line?**
**Answer: Ask: quotes (shown as-is), variable (value shown), or expression (result shown)**

**10. (Sub lesson 2) Which language and book teach LET and PRINT this way?**
**Answer: Visual Basic, in Libya's Grade 11 Information Technology book, Chapter 4**
