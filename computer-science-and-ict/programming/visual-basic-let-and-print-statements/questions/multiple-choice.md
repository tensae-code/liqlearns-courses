# Visual Basic — LET and PRINT Statements — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does LET do?**
a) Assigns a value to a variable  b) Becomes — X becomes 5; it is assignment, not a test of equality  c) The left; the value or expression stands on the right  d) Putting the variable on the right (any one of: assigning to a constant; confusing assignment with equality)

**2. (Sub lesson 1) In LET X = 5, what does the equals sign mean?**
a) The left; the value or expression stands on the right  b) Becomes — X becomes 5; it is assignment, not a test of equality  c) Putting the variable on the right (any one of: assigning to a constant; confusing assignment with equality)  d) Shows output — values and results
