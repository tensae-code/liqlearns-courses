# Visual Basic — LET and PRINT Statements — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does LET do?" is: Assigns a value to a variable**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "In LET X = 5, what does the equals sign mean?" is: The left; the value or expression stands on the right**
**Answer: False** — Becomes — X becomes 5; it is assignment, not a test of equality

**3. (Sub lesson 1) True or false: the answer to "Which side does the variable stand on?" is: The left; the value or expression stands on the right**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Name a common error with LET." is: Shows output — values and results**
**Answer: False** — Putting the variable on the right (any one of: assigning to a constant; confusing assignment with equality)

**5. (Sub lesson 1) True or false: the answer to "What does PRINT do?" is: Shows output — values and results**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does PRINT X show?" is: As it stands — it is written in quotation marks**
**Answer: False** — The value X holds, not the letter X

**7. (Sub lesson 2) True or false: the answer to "How is a text constant shown by PRINT?" is: As it stands — it is written in quotation marks**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does PRINT show for a maths expression?" is: Ask: quotes (shown as-is), variable (value shown), or expression (result shown)**
**Answer: False** — Its result — PRINT works the expression out

**9. (Sub lesson 2) True or false: the answer to "How do you read any PRINT line?" is: Ask: quotes (shown as-is), variable (value shown), or expression (result shown)**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Which language and book teach LET and PRINT this way?" is: Assigns a value to a variable**
**Answer: False** — Visual Basic, in Libya's Grade 11 Information Technology book, Chapter 4
