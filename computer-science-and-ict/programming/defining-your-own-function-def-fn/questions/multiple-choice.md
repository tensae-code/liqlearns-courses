# Defining Your Own Function — DEF FN — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does DEF FN do?**
a) Defines a function of the programmer's own — a name, a variable and the formula it stands for  b) FN  c) The programmer writes it; built-ins come with the language  d) In the one DEF line only
**Answer: a) Defines a function of the programmer's own — a name, a variable and the formula it stands for**

**2. (Sub lesson 1) What must a defined function's name begin with?**
a) 10  b) FN  c) The formula  d) A fresh value each time — a number or a variable
**Answer: b) FN**

**3. (Sub lesson 1) In `DEF FNA(X) = X * X + 1`, what is FNA(3)?**
a) The programmer writes it; built-ins come with the language  b) In the one DEF line only  c) 10  d) Readability — the program reads like its subject
**Answer: c) 10**

**4. (Sub lesson 1) How does a defined function differ from a built-in one?**

**5. (Sub lesson 1) What is written once and used many times?**
