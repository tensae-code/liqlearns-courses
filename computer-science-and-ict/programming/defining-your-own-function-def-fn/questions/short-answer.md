# Defining Your Own Function — DEF FN — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does DEF FN do?**
**Answer: Defines a function of the programmer's own — a name, a variable and the formula it stands for**

**2. (Sub lesson 1) What must a defined function's name begin with?**
**Answer: FN**

**3. (Sub lesson 1) In `DEF FNA(X) = X * X + 1`, what is FNA(3)?**
**Answer: 10**

**4. (Sub lesson 1) How does a defined function differ from a built-in one?**
**Answer: The programmer writes it; built-ins come with the language**

**5. (Sub lesson 1) What is written once and used many times?**
**Answer: The formula**

**6. (Sub lesson 2) If the formula changes, where is it changed?**
**Answer: In the one DEF line only**

**7. (Sub lesson 2) What values can a call use?**
**Answer: A fresh value each time — a number or a variable**

**8. (Sub lesson 2) What does a good FN name give a program?**
**Answer: Readability — the program reads like its subject**

**9. (Sub lesson 2) Where does Sudan's book place defined functions?**
**Answer: As the final section of its BASIC course**

**10. (Sub lesson 2) What is the learner doing by the end of the course?**
**Answer: Extending the language, not only using it**
