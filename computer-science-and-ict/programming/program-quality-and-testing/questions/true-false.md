# Program Quality and Testing — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Correctness, readability, reliability (also efficiency and usability)**
**Answer: True**

**2. (Sub lesson 1) True or false: Correctness, readability, reliability (also efficiency and usability)** — as the answer to: What does correctness demand?
**Answer: False — Right answers for all honest inputs — not just the ones tried**

**3. (Sub lesson 1) True or false: The program behaves under stress and bad input, not only in the easy case**
**Answer: True**

**4. (Sub lesson 1) True or false: The program behaves under stress and bad input, not only in the easy case** — as the answer to: Why is readability a quality feature?
**Answer: False — Programs are read and fixed by people — code nobody can follow cannot be trusted or repaired**

**5. (Sub lesson 1) True or false: Grade 6 (prerequisites), Grade 10 (quality features) and Grade 12 (testing as the proof)**
**Answer: True**

**6. (Sub lesson 2) True or false: Grade 6 (prerequisites), Grade 10 (quality features) and Grade 12 (testing as the proof)** — as the answer to: What is a test case?
**Answer: False — One chosen input with its expected result written down before running**

**7. (Sub lesson 2) True or false: Unit (parts alone), integration (parts together), system (the whole program), acceptance (the user's check)**
**Answer: True**

**8. (Sub lesson 2) True or false: Unit (parts alone), integration (parts together), system (the whole program), acceptance (the user's check)** — as the answer to: What can testing prove?
**Answer: False — That faults are present — never that none remain**

**9. (Sub lesson 2) True or false: Before running the test — otherwise the tester just accepts whatever comes out**
**Answer: True**

**10. (Sub lesson 2) True or false: Before running the test — otherwise the tester just accepts whatever comes out** — as the answer to: Why is quality 'built in, not only tested in'?
**Answer: False — Because testing cannot prove a program fault-free, quality must be made during building, with testing as the check**
