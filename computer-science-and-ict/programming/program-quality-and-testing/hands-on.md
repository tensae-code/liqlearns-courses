# Hands-on — Program Quality and Testing

The lesson with your hands and your feet, not only your eyes.

## Task one
**Quality audit** — Take a program you wrote. Score it 1–3 on correctness, readability, reliability, efficiency and usability, with evidence for the lowest score.

## Task two
**Five test cases** — For the same program, write five test cases (input + expected result) covering one normal, one border and one bad input. Run them and record what each exposed.
