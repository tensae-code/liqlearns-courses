# Breadth-First Search — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) In a queue, the last node to join is the next one taken out.**
**Answer: False** — A queue is first in, first out — the front node leaves next.

**2. (Sub lesson 1) Breadth-first search can visit the same node many times.**
**Answer: False** — Nodes are marked on entry and visited once.

**3. (Sub lesson 2) The first path breadth-first search finds to a node is a shortest path in edges.**
**Answer: True** — That is the search's guarantee, because it works layer by layer.

**4. (Sub lesson 2) Depth-first search also guarantees shortest paths.**
**Answer: False** — Depth-first may find a long way round first; it makes no shortest-path promise.
