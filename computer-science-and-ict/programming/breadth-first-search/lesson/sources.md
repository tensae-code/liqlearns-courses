**Acceptance count: taught in 4 countries (Germany, Vietnam, Pakistan, Kazakhstan).**

Germany is counted from a partially-held copy: the held PDF is a PARTIAL, disordered screenshot compilation (see the book entry above), and this placement rests on the book's verified complete contents and sampled pages.

Placement choice: this lesson was built new for the ICT expansion (Germany, 2026-11-14) because no existing lesson in the course covers this thing as its own lesson — the live tree was checked for the slug and for near matches before building. 

Germany's own way: a Bavarian NTG Gymnasium book built on four deep strands — graph theory (adjacency matrices, breadth-first search, Dijkstra), coding and cryptography (symmetric/asymmetric encryption, signatures), network communication, and AI up to neural networks — closing with student projects including programming a social bot. This lesson keeps that depth: the idea is taught whole, with the book's own worked way, not thinned down.

Vietnam's own way (Grade 12 Chuyên đề Tin học 12 Khoa học máy tính): the final CS study-topics book is a data-structures course in Python — stacks and queues (LIFO/FIFO met through a plate stack and an ATM queue), binary search trees for sorting and searching, and graphs with depth-first and breadth-first traversal.


Pakistan's own way (Grade 11 Computer Science and Entrepreneurship 11): the new-curriculum Grade 11 book runs the whole arc from making software to selling it: SDLC with UML and design patterns, a full Python course (through OOP, files and exceptions), algorithms with complexity classes (P, NP, NP-hard), data analytics with regression and clustering, cloud and blockchain, and a closing entrepreneurship unit — every unit grounded in Pakistani examples (Daraz, Foodpanda, Careem, Pakola, NADRA, the Personal Data Protection Bill, NR3C-FIA).

Kazakhstan's own way (Salgaraeva G10 Informatika, natural-science track): in Grade 10 the subject splits by track; this natural-science book is the deepest in the set — networks with IP, domains and VPN, number systems and logic with truth tables and the computer's logical elements, procedures/functions, strings, files, sorting methods and graph algorithms, a full HTML/CSS/scripts web part, and information systems from Big Data to linking web pages with a database. Every topic is doubled with a practicum paragraph.

Kazakhstan's own way (Zhunusov G10 Computer Science, English-medium): the English-medium Grade 10 book is the most technical of the wave: the CIA triad and three separate authentication lessons (passwords twice, biometrics), encoding standards, Python dictionaries, DFS/BFS graph traversal, and a full SQL chapter in MySQL (CREATE, INSERT, SELECT/WHERE, MIN/MAX, JOIN, GROUP BY, SELECT INTO) before a JavaScript chapter. (Its preface is the publisher's generic science template, left over from another book.)
