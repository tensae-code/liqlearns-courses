# Video script — Breadth-First Search

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

We search a graph fairly: near things first, far things later.

The start node goes into a line. The line is called a queue.

Take the front node. Its new neighbours join the back of the line.

Mark every node the moment it joins the line. No node is visited twice.

Ring by ring, like ripples — that is breadth-first search.

The ring a node is found in is its shortest distance from the start.
