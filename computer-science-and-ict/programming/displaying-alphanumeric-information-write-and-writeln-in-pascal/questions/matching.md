# Displaying Alphanumeric Information — write and writeln in Pascal — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What is the difference between write and writeln?** → **write leaves the cursor where it stopped; writeln moves to a new line after displaying**

**2. (Sub lesson 1) What kinds of parameters can they display?** → **Numbers, characters, strings in apostrophes, and whole expressions**

**3. (Sub lesson 1) What does writeln('Sum = ', s) print?** → **The text 'Sum = ', then the value of s**

**4. (Sub lesson 1) What is alphanumeric information?** → **Letters and digits together — everything the screen can show as text**

**5. (Sub lesson 1) What does C++ use for the same work?** → **cout <<**

**6. (Sub lesson 2) What does write(x:8) do?** → **Reserves 8 positions for x, right-aligned in its field**

**7. (Sub lesson 2) What does write(r:8:2) add?** → **Two decimal places for the real value**

**8. (Sub lesson 2) Why do tables need width formats?** → **They align values into straight columns**

**9. (Sub lesson 2) How do unformatted reals print?** → **In long exponent form — hard to read**

**10. (Sub lesson 2) How are labels joined to values?** → **With spaces and text inside the string parameters, e.g. 'Sum = '**
