# Displaying Alphanumeric Information — write and writeln in Pascal — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: write leaves the cursor where it stopped; writeln moves to a new line after displaying**
**Answer: True**

**2. (Sub lesson 1) True or false: write leaves the cursor where it stopped; writeln moves to a new line after displaying** — as the answer to: What kinds of parameters can they display?
**Answer: False — Numbers, characters, strings in apostrophes, and whole expressions**

**3. (Sub lesson 1) True or false: The text 'Sum = ', then the value of s**
**Answer: True**

**4. (Sub lesson 1) True or false: The text 'Sum = ', then the value of s** — as the answer to: What is alphanumeric information?
**Answer: False — Letters and digits together — everything the screen can show as text**

**5. (Sub lesson 1) True or false: cout <<**
**Answer: True**

**6. (Sub lesson 2) True or false: cout <<** — as the answer to: What does write(x:8) do?
**Answer: False — Reserves 8 positions for x, right-aligned in its field**

**7. (Sub lesson 2) True or false: Two decimal places for the real value**
**Answer: True**

**8. (Sub lesson 2) True or false: Two decimal places for the real value** — as the answer to: Why do tables need width formats?
**Answer: False — They align values into straight columns**

**9. (Sub lesson 2) True or false: In long exponent form — hard to read**
**Answer: True**

**10. (Sub lesson 2) True or false: In long exponent form — hard to read** — as the answer to: How are labels joined to values?
**Answer: False — With spaces and text inside the string parameters, e.g. 'Sum = '**
