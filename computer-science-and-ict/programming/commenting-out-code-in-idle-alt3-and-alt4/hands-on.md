# Hands-on — Commenting out code in IDLE — Alt+3 and Alt+4

The lesson with your hands, not only your eyes — every activity is done for real, in IDLE or on paper.

## Key drill
On a keyboard (real or drawn), drill the pair ten times with a partner calling 'out!' and 'back!' — Alt+3, Alt+4 — until the fingers know them without looking.

## Fragment swap
Take a two-fragment program in IDLE. Comment out fragment 1, run and record. Alt+4 it back, comment out fragment 2, run and record. Write one describing comment for each fragment.
