# Commenting out code in IDLE — Alt+3 and Alt+4 — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Comment Out Region lives under the —
a) Debug menu  b) Format menu  c) Run menu
**Answer: b) b) Format menu**

**2. (Sub lesson 1)** The shortcut to comment out a region is —
a) Alt+3  b) Alt+4  c) Ctrl+C
**Answer: a) a) Alt+3**

**3. (Sub lesson 2)** The shortcut to uncomment a region is —
a) Alt+3  b) Alt+4  c) Alt+F4
**Answer: b) b) Alt+4**

**4. (Sub lesson 2)** Before using either command you must —
a) save twice  b) select the part of the code  c) close IDLE
**Answer: b) b) select the part of the code**

**5. (Sub lesson 2)** Commenting out new lines helps to —
a) hunt which lines introduced an error  b) make the program faster  c) print comments
**Answer: a) a) hunt which lines introduced an error**

**6. (Sub lesson 1)** After Alt+3 on every line, running the file gives —
a) normal output  b) no output  c) the comments as output
**Answer: b) b) no output**
