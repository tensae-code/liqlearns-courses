# Commenting out code in IDLE — Alt+3 and Alt+4 — true or false

Say True or False.

**1. (Sub lesson 1)** Alt+3 and Alt+4 do the same thing.
**Answer: False**

**2. (Sub lesson 2)** Uncomment Region restores commented lines to code.
**Answer: True**

**3. (Sub lesson 2)** Commenting out is only for hiding code permanently.
**Answer: False**

**4. (Sub lesson 1)** The Format menu holds IDLE's commenting features.
**Answer: True**
