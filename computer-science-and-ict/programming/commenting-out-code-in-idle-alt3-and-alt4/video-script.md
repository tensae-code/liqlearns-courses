This lesson: **Commenting out code in IDLE — Alt+3 and Alt+4**.

First, do it. Run the opening program. Watch what it prints.

Then the idea, in order: Select the part, Format → Comment Out Region (or Alt+3): # marks appear on the selected lines at once. Format → Uncomment Region (or Alt+4) restores the lines; commenting out new lines hunts which lines introduced an error.

Now you. In IDLE, comment out the first fragment of a two-fragment program with Alt+3, run, then swap with Alt+4.

Say it to your companion: Show your companion the two keys — Alt+3 out, Alt+4 back — and explain how commenting out new lines hunts an error.
