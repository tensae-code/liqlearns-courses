# Simple Data Types and Their Ranges — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: One value of one kind**
**Answer: True**

**2. (Sub lesson 1) True or false: One value of one kind** — as the answer to: Name the working family of simple types.
**Answer: False — Integer, real/floating, character/string, and Boolean/logical**

**3. (Sub lesson 1) True or false: Range and precision against memory — smaller types hold less, larger types hold more**
**Answer: True**

**4. (Sub lesson 1) True or false: Range and precision against memory — smaller types hold less, larger types hold more** — as the answer to: Which simple type holds exactly two values?
**Answer: False — Boolean (logical) — true and false**

**5. (Sub lesson 1) True or false: The composite types — array and structure**
**Answer: True**

**6. (Sub lesson 2) True or false: The composite types — array and structure** — as the answer to: What is a type's range?
**Answer: False — The smallest and largest values it can hold**

**7. (Sub lesson 2) True or false: −128 to 127**
**Answer: True**

**8. (Sub lesson 2) True or false: −128 to 127** — as the answer to: What is overflow?
**Answer: False — Passing the type's edge — the value wraps or behaves wrongly, silently**

**9. (Sub lesson 2) True or false: Precision — digits beyond the type's count are rounded away**
**Answer: True**

**10. (Sub lesson 2) True or false: Precision — digits beyond the type's count are rounded away** — as the answer to: How should a type be chosen?
**Answer: False — Big enough for the honest largest value with room to spare, small enough not to waste memory — and its edges tested**
