# Simple Data Types and Their Ranges — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does a simple type hold?**
**Answer: One value of one kind**

**2. (Sub lesson 1) Name the working family of simple types.**
**Answer: Integer, real/floating, character/string, and Boolean/logical**

**3. (Sub lesson 1) What do C++'s short/long and float/double trade?**
**Answer: Range and precision against memory — smaller types hold less, larger types hold more**

**4. (Sub lesson 1) Which simple type holds exactly two values?**
**Answer: Boolean (logical) — true and false**

**5. (Sub lesson 1) What is built from simple types next in Armenia's Grade 10 theme?**
**Answer: The composite types — array and structure**

**6. (Sub lesson 2) What is a type's range?**
**Answer: The smallest and largest values it can hold**

**7. (Sub lesson 2) What range does an 8-bit signed integer hold?**
**Answer: −128 to 127**

**8. (Sub lesson 2) What is overflow?**
**Answer: Passing the type's edge — the value wraps or behaves wrongly, silently**

**9. (Sub lesson 2) What do real types trade for their huge range?**
**Answer: Precision — digits beyond the type's count are rounded away**

**10. (Sub lesson 2) How should a type be chosen?**
**Answer: Big enough for the honest largest value with room to spare, small enough not to waste memory — and its edges tested**
