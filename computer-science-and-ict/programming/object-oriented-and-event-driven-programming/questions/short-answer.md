# Object-Oriented and Event-Driven Programming — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is an object?**
**Answer: A thing of the program holding its own data and actions**

**2. (Sub lesson 1) What are an object's properties?**
**Answer: The data that describes it**

**3. (Sub lesson 1) What are an object's methods?**
**Answer: The actions it can do**

**4. (Sub lesson 1) How does object-oriented programming model a problem?**
**Answer: As objects that work together**

**5. (Sub lesson 1) What can be used many times once made?**
**Answer: The same object design — one class, many pupils**

**6. (Sub lesson 2) What does an event-driven program do most of the time?**
**Answer: Waits for events**

**7. (Sub lesson 2) Name two events.**
**Answer: A button click and a key press (or a timer firing)**

**8. (Sub lesson 2) What runs when an event happens?**
**Answer: The handler — the code attached to that event**

**9. (Sub lesson 2) Who decides the order of happenings?**
**Answer: The user, not the program**

**10. (Sub lesson 2) Which tool in Cuba's book works this way?**
**Answer: LiveCode — objects on a card with scripts answering events**
