# Object-Oriented and Event-Driven Programming — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is an object?**
a) A thing of the program holding its own data and actions  b) The data that describes it  c) The actions it can do  d) As objects that work together
**Answer: a) A thing of the program holding its own data and actions**

**2. (Sub lesson 1) What are an object's properties?**
a) The actions it can do  b) The data that describes it  c) As objects that work together  d) The same object design — one class, many pupils
**Answer: b) The data that describes it**

**3. (Sub lesson 1) What are an object's methods?**
a) As objects that work together  b) The same object design — one class, many pupils  c) The actions it can do  d) Waits for events
**Answer: c) The actions it can do**

**4. (Sub lesson 1) How does object-oriented programming model a problem?**
a) The same object design — one class, many pupils  b) Waits for events  c) A button click and a key press (or a timer firing)  d) As objects that work together
**Answer: d) As objects that work together**

**5. (Sub lesson 1) What can be used many times once made?**
a) The same object design — one class, many pupils  b) Waits for events  c) A button click and a key press (or a timer firing)  d) The handler — the code attached to that event
**Answer: a) The same object design — one class, many pupils**

**6. (Sub lesson 2) What does an event-driven program do most of the time?**
a) A button click and a key press (or a timer firing)  b) Waits for events  c) The handler — the code attached to that event  d) The user, not the program
**Answer: b) Waits for events**

**7. (Sub lesson 2) Name two events.**
a) The handler — the code attached to that event  b) The user, not the program  c) A button click and a key press (or a timer firing)  d) LiveCode — objects on a card with scripts answering events
**Answer: c) A button click and a key press (or a timer firing)**

**8. (Sub lesson 2) What runs when an event happens?**
a) The user, not the program  b) LiveCode — objects on a card with scripts answering events  c) A thing of the program holding its own data and actions  d) The handler — the code attached to that event
**Answer: d) The handler — the code attached to that event**

**9. (Sub lesson 2) Who decides the order of happenings?**
a) The user, not the program  b) LiveCode — objects on a card with scripts answering events  c) A thing of the program holding its own data and actions  d) The data that describes it
**Answer: a) The user, not the program**

**10. (Sub lesson 2) Which tool in Cuba's book works this way?**
a) A thing of the program holding its own data and actions  b) LiveCode — objects on a card with scripts answering events  c) The data that describes it  d) The actions it can do
**Answer: b) LiveCode — objects on a card with scripts answering events**
