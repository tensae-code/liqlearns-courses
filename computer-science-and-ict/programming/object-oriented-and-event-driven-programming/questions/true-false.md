# Object-Oriented and Event-Driven Programming — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is an object?" is: A thing of the program holding its own data and actions**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What are an object's properties?" is: The actions it can do**
**Answer: False** — The data that describes it

**3. (Sub lesson 1) True or false: the answer to "What are an object's methods?" is: The actions it can do**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How does object-oriented programming model a problem?" is: The same object design — one class, many pupils**
**Answer: False** — As objects that work together

**5. (Sub lesson 1) True or false: the answer to "What can be used many times once made?" is: The same object design — one class, many pupils**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does an event-driven program do most of the time?" is: A button click and a key press (or a timer firing)**
**Answer: False** — Waits for events

**7. (Sub lesson 2) True or false: the answer to "Name two events." is: A button click and a key press (or a timer firing)**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What runs when an event happens?" is: The user, not the program**
**Answer: False** — The handler — the code attached to that event

**9. (Sub lesson 2) True or false: the answer to "Who decides the order of happenings?" is: The user, not the program**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Which tool in Cuba's book works this way?" is: A thing of the program holding its own data and actions**
**Answer: False** — LiveCode — objects on a card with scripts answering events
