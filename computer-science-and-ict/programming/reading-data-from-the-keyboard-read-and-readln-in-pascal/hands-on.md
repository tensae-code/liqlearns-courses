# Hands-on — Reading Data from the Keyboard — read and readln in Pascal

The lesson with your hands and your feet, not only your eyes.

## Task one
**Dialogue script** — Write a program's full dialogue: prompt for a name and two marks, read them with readln, and echo a sentence using all three.

## Task two
**Read trap** — Predict what read(a); read(b); readln(c) takes from the typed line '5 7 9' versus readln for each — then say which pattern the book recommends and why.
