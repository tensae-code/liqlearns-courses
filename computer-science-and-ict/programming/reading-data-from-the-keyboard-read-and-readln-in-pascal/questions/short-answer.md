# Reading Data from the Keyboard — read and readln in Pascal — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does read(a, b) do?**
**Answer: It waits for two typed values and stores them into a and b**

**2. (Sub lesson 1) What extra does readln do?**
**Answer: It skips to the end of the input line, discarding the rest of that line**

**3. (Sub lesson 1) What does the program do while a read executes?**
**Answer: It waits — execution pauses until the user types and presses Enter**

**4. (Sub lesson 1) What does C++ read with?**
**Answer: cin >>**

**5. (Sub lesson 1) Which is the safer default for line-by-line data?**
**Answer: readln**

**6. (Sub lesson 2) What is the courtesy protocol's order?**
**Answer: Prompt first, read second, echo or use third**

**7. (Sub lesson 2) Why prompt before reading?**
**Answer: The user cannot guess what the program expects**

**8. (Sub lesson 2) How are several numbers typed for one read?**
**Answer: Separated by spaces or by Enter**

**9. (Sub lesson 2) How are characters read?**
**Answer: Raw, one by one — spaces included**

**10. (Sub lesson 2) What is input, in the lesson's phrase?**
**Answer: A contract — the program states order and kinds; the user supplies exactly those**
