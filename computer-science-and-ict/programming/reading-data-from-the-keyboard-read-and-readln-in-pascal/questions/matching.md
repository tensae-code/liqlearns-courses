**1. (Sub lesson 1) What does read(a, b) do?** → **It waits for two typed values and stores them into a and b**

**2. (Sub lesson 1) What extra does readln do?** → **It skips to the end of the input line, discarding the rest of that line**

**3. (Sub lesson 1) What does the program do while a read executes?** → **It waits — execution pauses until the user types and presses Enter**

**5. (Sub lesson 1) Which is the safer default for line-by-line data?** → **readln**

**6. (Sub lesson 2) What is the courtesy protocol's order?** → **Prompt first, read second, echo or use third**

**7. (Sub lesson 2) Why prompt before reading?** → **The user cannot guess what the program expects**

**8. (Sub lesson 2) How are several numbers typed for one read?** → **Separated by spaces or by Enter**

**9. (Sub lesson 2) How are characters read?** → **Raw, one by one — spaces included**
