# Practical Tasks with Characters and Strings — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What joins the earlier sections together?**
**Answer: A practical task — one job with an input and a required result**

**2. (Sub lesson 1) What is the first step of a practical task?**
**Answer: Saying exactly what goes in, what must come out, and which tools do each part**

**3. (Sub lesson 1) Name a typical practical string task.**
**Answer: Counting letters in a text, or building initials from a full name**

**4. (Sub lesson 1) What does testing mean?**
**Answer: Running the program on chosen cases and comparing its results with results worked out by hand**

**5. (Sub lesson 1) Name the three kinds of test case in this lesson.**
**Answer: An ordinary case, a short case, and an awkward case**

**6. (Sub lesson 2) Give an awkward case.**
**Answer: An empty text, extra spaces, or a piece that is not found**

**7. (Sub lesson 2) Where is a fault hunted first?**
**Answer: In the plan — the wrong tool, a position off by one, a forgotten edge**

**8. (Sub lesson 2) When is a task finished?**
**Answer: When its tests pass — not when the program merely runs**

**9. (Sub lesson 2) Which tools does a practical task use?**
**Answer: The char, string, and string procedure/function tools from the earlier sections**

**10. (Sub lesson 2) Why work a test result out by hand?**
**Answer: So there is a trusted answer to compare the program against**
