# Hands-on — Practical Tasks with Characters and Strings

The lesson with your hands and your feet, not only your eyes.

## Initials task
Write a program that takes a full name (family name and first name) as one string and prints the initials with dots. Test it on a normal name, a one-letter name, and a name typed with an extra space.

## Letter count
Write a program that counts how many times a chosen letter appears in a sentence. Work out the count by hand for two test sentences first, then check the program against them.
