# Video script — ΓΛΩΣΣΑ — Operators, Functions, Expressions and Assignment

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

ΓΛΩΣΣΑ calculates with the arithmetic operators **+ − * /**, the integer division **DIV** and the remainder **MOD**, and raises powers with **^**. An **expression** joins values, variables and operators into one value to be worked out; the language's order of working — powers, then multiplications/divisions, then additions/subtractions, brackets first — decides what an expression means, exactly as in school arithmetic. Comparison operators (=, <>, <, >, <=, >=) and the logical operators **ΚΑΙ** (and), **Η** (or) and **ΟΧΙ** (not) build the conditions selection commands will test.
ΓΛΩΣΣΑ keeps ready **functions** the program may call: **Α_Τ** (absolute value), **Τ_Ρ** (square root), **ΗΜ/ΣΥΝ/ΕΦ** (sine/cosine/tangent), **ΛΟΓ** (logarithm), **Ε** (exponential), **Α_Μ** (integer part) and more — each takes a value in and hands a value back. The **assignment command** is the language's arrow: **name ← expression** works the expression out and stores the answer in the name — the arrow points at the place that receives, which is why ΓΛΩΣΣΑ writes assignment with ← and never confuses it with the = of comparison.
