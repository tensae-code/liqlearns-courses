# ΓΛΩΣΣΑ — Operators, Functions, Expressions and Assignment — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: + − * /, DIV (integer division), MOD (remainder) and ^ (power)**
**Answer: True**

**2. (Sub lesson 1) True or false: The order of working — brackets, powers, ×/÷, then +/−** — as the answer to: What is an expression?
**Answer: False — Values, variables and operators joined into one value to be worked out**

**3. (Sub lesson 1) True or false: The order of working — brackets, powers, ×/÷, then +/−**
**Answer: True**

**4. (Sub lesson 1) True or false: ΚΑΙ (and), Η (or), ΟΧΙ (not)** — as the answer to: Name the comparison operators.
**Answer: False — =, <>, <, >, <=, >=**

**5. (Sub lesson 1) True or false: ΚΑΙ (and), Η (or), ΟΧΙ (not)**
**Answer: True**

**6. (Sub lesson 2) True or false: Takes a value in and hands a value back** — as the answer to: Name three ΓΛΩΣΣΑ functions.
**Answer: False — Α_Τ (absolute value), Τ_Ρ (square root), Α_Μ (integer part) — any three from the lesson**

**7. (Sub lesson 2) True or false: Takes a value in and hands a value back**
**Answer: True**

**8. (Sub lesson 2) True or false: The arrow points at the place that receives; = stays the sign of comparison** — as the answer to: What is the assignment command?
**Answer: False — name ← expression — work the expression out and store the answer in the name**

**9. (Sub lesson 2) True or false: The arrow points at the place that receives; = stays the sign of comparison**
**Answer: True**
