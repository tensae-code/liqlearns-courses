# Swapping Two Values — and Reversing an Array — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) How many moves is a swap?**
**Answer: Three**

**2. (Sub lesson 1) Write the three moves.**
**Answer: temp = a; a = b; b = temp;**

**3. (Sub lesson 1) Why does the two-move version fail?**
**Answer: a's value is overwritten before it is saved**

**4. (Sub lesson 1) What is the temporary variable, in the lesson's image?**
**Answer: The third glass**

**5. (Sub lesson 1) What great operation is built from swaps?**
**Answer: Sorting**

**6. (Sub lesson 2) How is an array reversed?**
**Answer: Swap first with last, walking inward to the middle**

**7. (Sub lesson 2) What happens to the middle of an odd array?**
**Answer: It stays — already home**

**8. (Sub lesson 2) How many swaps reverse 100 elements?**
**Answer: 50 — half the size**

**9. (Sub lesson 2) When does the reversing loop stop?**
**Answer: When i is no longer less than j**

**10. (Sub lesson 2) What discipline does reversing teach?**
**Answer: The array's edge discipline — off-by-one care**
