# Hands-on — Swapping Two Values — and Reversing an Array

The lesson with your hands and your feet, not only your eyes.

## Task one
**Swap and reverse by hand** — Write a 7-element array on paper. Perform the reversal with written swaps only, showing the array after each swap.

## Task two
**Code both** — Write C programs: one swapping two input values, one reversing an input array — then join them: the reversal must call the swap's three moves, not rewrite them.
