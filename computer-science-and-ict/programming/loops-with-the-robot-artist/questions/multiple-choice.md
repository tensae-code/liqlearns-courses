# Loops with the Robot Artist — multiple choice

Pick the one right answer.

**1. What does a loop do?**
a) Repeats a group of actions a set number of times  b) Deletes a group of actions  c) Draws only one line ever
**Answer: a) Repeats a group of actions a set number of times**

**2. The robot artist in this lesson draws —**
a) photographs  b) maps  c) letters
**Answer: c) letters**

**3. Where does the number of repeats live?**
a) Under the screen  b) On the loop  c) In the goal
**Answer: b) On the loop**

**4. Why is a letter a good loop job?**
a) Its stroke pattern repeats  b) It has no strokes  c) It never repeats
**Answer: a) Its stroke pattern repeats**
