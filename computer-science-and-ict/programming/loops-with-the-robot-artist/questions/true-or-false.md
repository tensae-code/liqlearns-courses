# Loops with the Robot Artist — true or false

Say whether each statement is true or false.

**1. Say what a loop does, in your own words.**
**Answer: True** — This is one of the lesson's own outcomes.

**2. A loop runs its inside actions once only, whatever number it carries.**
**Answer: False** — The lesson teaches the opposite of this.

**3. Wrap a repeating group of actions in a loop with the right count.**
**Answer: True** — This is one of the lesson's own outcomes.
