# Loops with the Robot Artist — short answer

Answer in a sentence or two.

**1. Explain, in your own words: say what a loop does, in your own words.**
**Answer:** The learner's own explanation, true to the lesson: A loop says "do these actions this many times" in one block — and the robot artist uses a loop to draw letters, repeating its strokes without writing each stroke out.

**2. A classmate gets this lesson's work wrong. What is the most likely fault, and how is it fixed?**
**Answer:** Drawing comes out wrong → count first: say the loop's number aloud and tap the desk once for each repeat as the drawing runs; a wrong count shows itself at once.
