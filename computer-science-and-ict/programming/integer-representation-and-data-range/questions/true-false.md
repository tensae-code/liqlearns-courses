# Integer Representation and Data Range — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What fixes an integer type's range?" is: Its fixed number of bits**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How many patterns do n bits hold?" is: Choosing a range big enough for the job**
**Answer: False** — 2 to the power n

**3. (Sub lesson 1) True or false: the answer to "What is the unsigned 8-bit range?" is: 0 to 255**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is the signed 8-bit range?" is: The same addition circuits work for negatives and positives**
**Answer: False** — −128 to 127

**5. (Sub lesson 1) True or false: the answer to "What is choosing a type, in the lesson's words?" is: Choosing a range big enough for the job**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Which scheme stores negative integers?" is: −128**
**Answer: False** — Two's complement

**7. (Sub lesson 2) True or false: the answer to "Why two's complement?" is: The same addition circuits work for negatives and positives**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is overflow?" is: Its fixed number of bits**
**Answer: False** — Passing the end of the range and wrapping around

**9. (Sub lesson 2) True or false: the answer to "What does 127 + 1 give in a signed byte?" is: −128**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Does overflow raise an error?" is: 0 to 255**
**Answer: False** — No — the wrong value appears silently
