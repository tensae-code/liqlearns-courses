# Integer Representation and Data Range — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What fixes an integer type's range?**
a) Its fixed number of bits  b) 2 to the power n  c) 0 to 255  d) −128 to 127
**Answer: a) Its fixed number of bits**

**2. (Sub lesson 1) How many patterns do n bits hold?**
a) 0 to 255  b) 2 to the power n  c) −128 to 127  d) Choosing a range big enough for the job
**Answer: b) 2 to the power n**

**3. (Sub lesson 1) What is the unsigned 8-bit range?**
a) −128 to 127  b) Choosing a range big enough for the job  c) 0 to 255  d) Two's complement
**Answer: c) 0 to 255**

**4. (Sub lesson 1) What is the signed 8-bit range?**
a) Choosing a range big enough for the job  b) Two's complement  c) The same addition circuits work for negatives and positives  d) −128 to 127
**Answer: d) −128 to 127**

**5. (Sub lesson 1) What is choosing a type, in the lesson's words?**
a) Choosing a range big enough for the job  b) Two's complement  c) The same addition circuits work for negatives and positives  d) Passing the end of the range and wrapping around
**Answer: a) Choosing a range big enough for the job**

**6. (Sub lesson 2) Which scheme stores negative integers?**
a) The same addition circuits work for negatives and positives  b) Two's complement  c) Passing the end of the range and wrapping around  d) −128
**Answer: b) Two's complement**

**7. (Sub lesson 2) Why two's complement?**
a) Passing the end of the range and wrapping around  b) −128  c) The same addition circuits work for negatives and positives  d) No — the wrong value appears silently
**Answer: c) The same addition circuits work for negatives and positives**

**8. (Sub lesson 2) What is overflow?**
a) −128  b) No — the wrong value appears silently  c) Its fixed number of bits  d) Passing the end of the range and wrapping around
**Answer: d) Passing the end of the range and wrapping around**

**9. (Sub lesson 2) What does 127 + 1 give in a signed byte?**
a) −128  b) No — the wrong value appears silently  c) Its fixed number of bits  d) 2 to the power n
**Answer: a) −128**

**10. (Sub lesson 2) Does overflow raise an error?**
a) Its fixed number of bits  b) No — the wrong value appears silently  c) 2 to the power n  d) 0 to 255
**Answer: b) No — the wrong value appears silently**
