# Lesson plan — Each Sprite Has Its Own Scripts in Scratch

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** Each Sprite Has Its Own Scripts in Scratch
**Place in the curriculum:** ICT expansion — Palestine (2026-11-14) — in the title Programming on the ICT course ladder (TITLES.md). Built new from Palestine's Grade 7 and Grade 8 Programming student books, because no existing lesson in the course covers this thing as its own lesson.
**The one thing this lesson teaches:** Every sprite on the stage has its own script area: selecting a sprite shows its own scripts; each sprite’s program starts with an event block; the green flag runs them all — and scripts can be copied between sprites, with sprite size telling near from far.
**This lesson's own level:** It stands on the earlier lessons of its title and on the book's own order — it follows the book's lessons in sequence, so its neighbours in the book are its natural companions. It stands alone for a learner landing on it directly.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Selecting a sprite shows its own script area** — Grade 7’s rule: with **more than one sprite on the stage**, **selecting a sprite shows its own script area** — the blocks you see belong to the sprite you selected. **Each program starts with an event block**. Edit the wrong sprite and the story breaks in a confusing place, so checking the selection is the first debugging habit.
2. **Stories and plays — many sprites, one flag** — Grade 8 builds plays on the rule: **several sprites on one stage, each with its own script area**; scripts can be **copied between sprites** when two characters share a move; **the green flag runs them all** together; and **sprite size** plays its part — bigger for near characters, smaller for far ones.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
