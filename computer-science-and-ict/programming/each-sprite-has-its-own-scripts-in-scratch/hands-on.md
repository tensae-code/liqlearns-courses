# Hands-on — Each Sprite Has Its Own Scripts in Scratch

The lesson with your hands and your feet, not only your eyes.

## Whose blocks?
Put three sprites on a stage, give each a different say script, and practise: select, name whose blocks you see, then run the flag.

## Copy and cast
Copy one sprite’s movement script to a second sprite, then set sizes so one character stands near and one far.
