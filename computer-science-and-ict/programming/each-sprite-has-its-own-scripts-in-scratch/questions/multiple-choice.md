# Each Sprite Has Its Own Scripts in Scratch — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does selecting a sprite show?**
a) Its own script area  b) The selected sprite’s  c) Checking which sprite is selected  d) It can be copied between sprites
**Answer: a) Its own script area**

**2. (Sub lesson 1) Whose blocks are on screen?**
a) An event block  b) The selected sprite’s  c) The story breaks in a confusing place  d) The green flag
**Answer: b) The selected sprite’s**

**3. (Sub lesson 1) What does each sprite’s program start with?**
a) Checking which sprite is selected  b) It can be copied between sprites  c) An event block  d) A bigger sprite size
**Answer: c) An event block**

**4. (Sub lesson 1) What is the first debugging habit on a crowded stage?**
a) The story breaks in a confusing place  b) The green flag  c) A smaller sprite size  d) Checking which sprite is selected
**Answer: d) Checking which sprite is selected**

**5. (Sub lesson 1) What breaks if you edit the wrong sprite?**
a) The story breaks in a confusing place  b) It can be copied between sprites  c) A bigger sprite size  d) As several sprites on one stage, each with its own scripts
**Answer: a) The story breaks in a confusing place**

**6. (Sub lesson 2) What can be done with a script two characters share?**
a) The green flag  b) It can be copied between sprites  c) A smaller sprite size  d) Its own script area
**Answer: b) It can be copied between sprites**

**7. (Sub lesson 2) What runs all the sprites’ scripts together?**
a) A bigger sprite size  b) As several sprites on one stage, each with its own scripts  c) The green flag  d) The selected sprite’s
**Answer: c) The green flag**

**8. (Sub lesson 2) How is “near” shown on the stage?**
a) A smaller sprite size  b) Its own script area  c) An event block  d) A bigger sprite size
**Answer: d) A bigger sprite size**

**9. (Sub lesson 2) How is “far” shown?**
a) A smaller sprite size  b) As several sprites on one stage, each with its own scripts  c) The selected sprite’s  d) Checking which sprite is selected
**Answer: a) A smaller sprite size**

**10. (Sub lesson 2) Where does a play’s cast live?**
a) Its own script area  b) As several sprites on one stage, each with its own scripts  c) An event block  d) The story breaks in a confusing place
**Answer: b) As several sprites on one stage, each with its own scripts**
