# Hands-on — Arduino C Program Structure — setup() and loop()

The lesson with your hands and your feet, not only your eyes.

## Task one
**File the commands** — Given eight Arduino commands (set a pin mode, read a sensor, light an LED, start serial, sound a beep, check a button, print a value, set a motor speed), file each into setup() or loop() and defend the two hardest.

## Task two
**Read a sketch** — Take a short printed sketch. Mark its two rooms, list what happens once and what repeats, and predict the board's behaviour in one sentence.
