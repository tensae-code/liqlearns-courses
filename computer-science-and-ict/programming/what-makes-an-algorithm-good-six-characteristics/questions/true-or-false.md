# What makes an algorithm good — six characteristics — true or false

Say whether each sentence is true or false.

**1.** An algorithm must state its inputs and outputs exactly.
**Answer: True** — well-defined inputs AND well-defined outputs.

**2.** Language-independent means the algorithm is written in no language at all.
**Answer: False** — it means not tied to one language.

**3.** Breaking a problem into smaller pieces is an advantage of algorithms.
**Answer: True** — the pieces convert readily into a program.
