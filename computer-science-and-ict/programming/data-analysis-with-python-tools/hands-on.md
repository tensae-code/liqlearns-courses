# Hands-on — Data Analysis with Python Tools

The lesson with your hands and your feet, not only your eyes.

## Ask the table
Take the teacher's clean table. Write five questions — one of each kind: total, average, grouping, comparison, pattern. Beside each, write the grouping and summary it needs.

## Run and read
In Python, load the table, group it by the column your main question needs, compute the averages, sort them, and write the finding as one finished sentence beginning 'This means that…'.
