# Data Analysis with Python Tools — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Analysis can begin on dirty data if the Python tools are powerful enough.**
**Answer: False** — Dirty data poisons analysis regardless of the tool — cleaning comes first.

**2. (Sub lesson 2) The same table can give different findings depending on the grouping chosen.**
**Answer: True** — Grouping by class vs by subject answers different questions.

**3. (Sub lesson 2) A table of computed averages is, by itself, a finished analysis.**
**Answer: False** — The analyst must still read it: state in words what the numbers mean.
