# Data Analysis with Python Tools — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 1) Splitting data by a column and summarising each part is called ____.**
**Answer: grouping** — By class, by subject, by month…

**2. (Sub lesson 2) The typical value question is answered by the ____.**
**Answer: average** — Totals count; averages typify.

**3. (Sub lesson 2) In the Python rhythm, the last step is to ____ the results — state what they mean.**
**Answer: read** — Numbers become a finding only when read.
