# Data Analysis with Python Tools — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Which of these is a grouping question?**
a) What is the total of all marks?  b) What is the average mark in each class?  c) How many pupils are there?  d) What is the highest mark?
**Answer: b) What is the average mark in each class?** — Splitting by a column and summarising each group is grouping.

**2. (Sub lesson 1) A finding someone can act on sounds like —**
a) results fell  b) results fell in mathematics, in Grade 9, in the second term  c) marks are marks  d) school is hard
**Answer: b) results fell in mathematics, in Grade 9, in the second term** — Specific groupings turn a complaint into a finding.

**3. (Sub lesson 2) The Python rhythm for analysis runs —**
a) load, select, group, compute, sort, read  b) read, guess, print, delete  c) ask, wait, hope, submit  d) open, panic, close, repeat
**Answer: a) load, select, group, compute, sort, read** — Tool counts; human reads.

**4. (Sub lesson 2) Sorting the grouped results is done so that —**
a) the file looks tidy  b) the biggest fall or highest group stands first and is seen  c) the computer works less  d) columns align
**Answer: b) the biggest fall or highest group stands first and is seen** — Order makes the pattern visible.

**5. (Sub lesson 2) The part of analysis that stays human is —**
a) the counting  b) choosing the question, the grouping, and stating what the answer means  c) the loading  d) the typing
**Answer: b) choosing the question, the grouping, and stating what the answer means** — Tools compute; people decide what matters.
