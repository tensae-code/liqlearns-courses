# Input, process, output — tf

Say whether each statement is true or false.

**1.** True or false: input — what the computer obtains — keyboard and mouse information, game-control movements, data from memory or network devices.
**Answer: True**

**2.** True or false: process — the working the computer does on the input.
**Answer: True**

**3.** True or false: output is the opposite: it has nothing to do with what the computer produces — images, text and sound.
**Answer: False** — output is about what the computer produces — images, text and sound.
