# Input, process, output — multiple choice

Pick the one right answer.

**1.** What is input?
a) what the computer obtains — keyboard and mouse information, game-control movements, data from memory or network devices  b) the working the computer does on the input  c) what the computer produces — images, text and sound  d) the single-CPU information-processing model framing all the unit's problem solving
**Answer: a) what the computer obtains — keyboard and mouse information, game-control movements, data from memory or network devices**

**2.** What is process?
a) what the computer obtains — keyboard and mouse information, game-control movements, data from memory or network devices  b) what the computer produces — images, text and sound  c) the single-CPU information-processing model framing all the unit's problem solving  d) the working the computer does on the input
**Answer: d) the working the computer does on the input**

**3.** What is output?
a) the working the computer does on the input  b) the single-CPU information-processing model framing all the unit's problem solving  c) what the computer produces — images, text and sound  d) what the computer obtains — keyboard and mouse information, game-control movements, data from memory or network devices
**Answer: c) what the computer produces — images, text and sound**

**4.** What is the IPO model?
a) what the computer produces — images, text and sound  b) the single-CPU information-processing model framing all the unit's problem solving  c) what the computer obtains — keyboard and mouse information, game-control movements, data from memory or network devices  d) the working the computer does on the input
**Answer: b) the single-CPU information-processing model framing all the unit's problem solving**

**5.** In the average example, dividing SUM by 10 is —
a) input  b) process  c) output  d) storage
**Answer: b) process**

**6.** A result shown on screen is —
a) input  b) process  c) output  d) an algorithm
**Answer: c) output**

**7.** The first of the seven problem-solving steps is —
a) feed the program in  b) analyse the problem thoroughly  c) write the algorithm  d) run the program
**Answer: b) analyse the problem thoroughly** — before breaking anything down.

**8.** Step 3 of the seven is —
a) prepare an algorithm from the analysis  b) execute the instructions  c) design the program  d) break the method into tasks
**Answer: a) prepare an algorithm from the analysis** — steps: analyse, break down, algorithm, notation, program, feed, execute.

**9.** The guide's five steps begin —
a) implement, review, define  b) define the problem, brainstorm ideas…  c) code first, think later  d) test, then define
**Answer: b) define the problem, brainstorm ideas…** — then decide, implement, review.

**10.** Every algorithm's skeleton, in the guide's fixed order, is —
a) output, process, input  b) input, output, process  c) data input, data processing, results output  d) process only
**Answer: c) data input, data processing, results output** — in that order and no other.
