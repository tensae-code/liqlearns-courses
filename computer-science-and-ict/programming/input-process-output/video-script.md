This is **Input, process, output**.

**input** — what the computer obtains — keyboard and mouse information, game-control movements, data from memory or network devices.

**process** — the working the computer does on the input.

**output** — what the computer produces — images, text and sound.

**the IPO model** — the single-CPU information-processing model framing all the unit's problem solving.
