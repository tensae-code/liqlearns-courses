# Input, process, output

## Do it first

Take the average lesson apart. Getting the ten numbers — which part is that? The adding and dividing? The reporting? Three jobs, and every program you will ever meet is built from them. Name the three before the model is drawn.

## The model

A simplified single-CPU information-processing model frames all the unit's problem solving: the computer obtains user input — keyboard and mouse information, game-control movements, sometimes data from secondary memory or network devices — processes it, and produces output: images, text, sound.

## Mapped onto the average

Step 1 of the average algorithm (getting the numbers, e.g. by keyboard) is input. Steps 2–3 (sum and average) are process. Reporting the result, e.g. on screen, is output. Every flowchart and script in the rest of this unit can be read with these three labels — look for them from here on.

## Grade 10 depth — solving problems with a computer: the seven steps

Grade 10 opens the unit by fixing the discipline. A computer **only does what it is told**, so a problem is solved in seven steps:

1. **Analyse** the problem thoroughly.
2. **Break** the solution method into a **sequence of small tasks**.
3. **Prepare an algorithm** from that analysis.
4. **Express** the algorithm in **precise notation**.
5. **Design the computer program** in a high-level language (the book names Basic, C, C++, Java and Python).
6. **Feed** the program into the computer.
7. Let its instructions **execute one after another** to output the **expected result**.

The shape of every solution stays input → process → output — shown on **adding two numbers A and B into C**. And the opening activity discovers the idea in ordinary life: write the steps of **riding a bike, making a sandwich, or cooking shiro wot** — and you have written an algorithm.

## Grade 10 depth — the five problem-solving steps, and the skeleton every algorithm follows (teacher guide — evidence)

The teacher guide keys the same discipline as **five steps to observe for**: **define the problem, brainstorm ideas, decide on a solution, implement the solution, review the results**.

And it fixes the **skeleton every algorithm follows: data input, data processing, results output — in that order and no other** — worked on **finding the average of three numbers**: the three numbers enter, the averaging happens, the one answer leaves. The guide also budgets this unit at **15 periods**, weighted to representation and tools.
