# Solving Problems with Analytic Algorithms — short answer

Answer each question in a few sentences.

**1. (Sub lesson 1) A printing shop charges a fixed setup fee of 50 plus 3 per poster. A school orders 40 posters. Solve it analytically, showing the four moves.**
**Answer:** Model: total cost = fixed setup fee plus per-poster price times number of posters. Derive: C = 50 + 3 × N. Compute: N = 40 gives C = 50 + 120 = 170. Check: N = 0 must give exactly the setup fee, 50 — it does.

**2. (Sub lesson 2) How is an analytic algorithm different from solving by trying cases? Give the difference in one or two sentences.**
**Answer:** An analytic algorithm finds the relationship inside the problem and derives a formula, so the answer is calculated directly. Trying cases searches through possibilities one by one until one fits — it never needs the relationship, but it may take far longer.
