# Solving Problems with Analytic Algorithms — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) An analytic algorithm tries cases one by one until one works.**
**Answer: False** — That is enumeration — the next lesson. Analytic means deriving the formula.

**2. (Sub lesson 2) Once the formula is derived, many questions can be answered by substitution.**
**Answer: True** — One derivation, endless calculations.

**3. (Sub lesson 2) The check move can be skipped when the arithmetic looks neat.**
**Answer: False** — Neat arithmetic on a wrong model still gives a wrong answer.
