# Adding and Switching a Scratch Backdrop — true or false

Say whether each statement is true or false.

**1. A backdrop is edited in the paint editor, like a costume.**
**Answer: True** — Both costumes and backdrops are painted looks.

**2. To change the backdrop you must select a sprite first.**
**Answer: False** — Select the stage — the backdrop is the stage's.

**3. Switching backdrops can move a story to a new place.**
**Answer: True** — That is what a second backdrop is for.
