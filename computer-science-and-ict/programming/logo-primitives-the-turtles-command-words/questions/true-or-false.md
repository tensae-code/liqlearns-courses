# LOGO primitives — the turtle's command words — true or false

Say true or false for each one.

**1.** The LOGO turtle is triangle-shaped.
**Answer: True.**

**2.** CS clears the text in the recall list box.
**Answer: False** — CT clears the text; CS clears the screen and sends the turtle home.

**3.** SQRT gives the square root of a non-negative number.
**Answer: True.**
