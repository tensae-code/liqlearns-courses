# LOGO primitives — the turtle's command words — multiple choice

Pick the one right answer.

**1.** LOGO commands are called —
a) procedures  b) primitives  c) variables  d) windows
**Answer: b) primitives.**

**2.** Commands are entered in the —
a) recall list box  b) command input box  c) editor only  d) title bar
**Answer: b) command input box.**

**3.** PU means —
a) pen up — move without a line  b) print up  c) pen under  d) pause
**Answer: a) pen up — move without a line.**

**4.** Which primitive clears all the commands in the recall list box?
a) CS  b) HOME  c) CT  d) ST
**Answer: c) CT** — clear text; CS clears the screen drawing.

**5.** PRODUCT 6 3 gives —
a) 9  b) 2  c) 18  d) 3
**Answer: c) 18** — PRODUCT multiplies two numbers.

**6.** EXP uses the number e, which is about —
a) 3.14  b) 2.718281828  c) 1.618  d) 10
**Answer: b) 2.718281828.**
