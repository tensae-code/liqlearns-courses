# Hands-on — LOGO primitives — the turtle's command words

The lesson with your hands, not only your eyes.

## Primitive pairs
On cards, write each primitive on one card and its meaning on another — eighteen pairs. Shuffle and match them against the clock; a partner checks each match against the lesson's table.

## Pen-up journey
On squared paper, be the turtle: start home. FD 4, PU, FD 3, PD, FD 2 — draw only where the pen is down. Mark where the turtle travelled invisibly. Then run the same journey in MSW LOGO and compare.
