# LOGO primitives — the turtle's command words

## Do it first

Write down every LOGO command word you already know, and what each one does. Count them. The Grade 7 lessons gave you the drawing words — this lesson holds the whole table. How many of the eighteen below are new to you?

## Primitives — the turtle's words

LOGO works through a **triangle-shaped turtle** on the MSW LOGO screen. The turtle draws and acts when given a command. Commands are called **primitives**, and they are entered in the **command input box**. This book uses **MSW LOGO version 6.5b**. The full table:

| Primitive | What it does |
|---|---|
| FD | forward |
| BK | back |
| RT | right |
| LT | left |
| HT | hide turtle |
| ST | show turtle |
| CS | clear screen (and send the turtle home) |
| CT | clear text (clear all commands in the recall list box) |
| HOME | bring the turtle to its home position |
| PRINT | write |
| SUM | add two numbers |
| DIFFERENCE | subtract one number from another |
| PRODUCT | multiply two numbers |
| PU | pen up (move without a line) |
| PD | pen down (start drawing again) |
| SQRT | square root of a non-negative number |
| EXP | e to the power of the argument (e is about 2.718281828) |
