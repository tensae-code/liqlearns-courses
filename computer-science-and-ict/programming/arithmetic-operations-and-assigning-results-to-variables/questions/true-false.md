# Arithmetic Operations and Assigning Results to Variables — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What are the four arithmetic operations in blocks?" is: Addition, subtraction, multiplication and division**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does an arithmetic block take and produce?" is: The sum, the difference, the product, the quotient**
**Answer: False** — Two values in; their result out

**3. (Sub lesson 1) True or false: the answer to "Name the four results." is: The sum, the difference, the product, the quotient**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How is a bigger calculation built?" is: It is lost**
**Answer: False** — Blocks feeding blocks, step by step

**5. (Sub lesson 1) True or false: the answer to "What happens to a result that is not kept?" is: It is lost**
