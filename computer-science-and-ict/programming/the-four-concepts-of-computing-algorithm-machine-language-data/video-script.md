# Video script — The Four Concepts of Computing — Algorithm, Machine, Language, Data

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

An **algorithm** is the plan: a finite, precise sequence of instructions that solves a problem or completes a task — the recipe, the route, the method. A **machine** is what executes plans without understanding them: the **computer**, a universal machine for processing information, follows instructions exactly as given — which is why the plan must be exact. Algorithm without machine is a wish; machine without algorithm is furniture.
A **language** is how plan and machine meet: the agreed system of signs — blocks, cards, or text like Scratch and Python — in which algorithms are written so both human and machine can read them. **Data (les données)** is what algorithms work on: the information, represented in forms the machine can store and transform — numbers, letters, pixels, sounds. Four concepts, one scene: data is worked on, by an algorithm, written in a language, run by a machine.
