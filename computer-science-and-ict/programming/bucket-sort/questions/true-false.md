# Bucket Sort — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a bucket?" is: A range that the values are scattered into — such as 0–9, 10–19 for marks**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How does a value find its bucket?" is: No — the value's size names its bucket**
**Answer: False** — By its own size — 37 goes in the 30s bucket

**3. (Sub lesson 1) True or false: the answer to "Do values get compared during scattering?" is: No — the value's size names its bucket**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "When does scattering work well?" is: Ages, marks, prices — values with a known range**
**Answer: False** — When ranges are known in advance and values spread across them

**5. (Sub lesson 1) True or false: the answer to "Name data that fits bucket sort." is: Ages, marks, prices — values with a known range**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What happens inside each bucket?" is: The buckets are small**
**Answer: False** — Its few values are put in order — by a simple sort

**7. (Sub lesson 2) True or false: the answer to "Why is even bubble sort quick inside a bucket?" is: The buckets are small**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How is the sorted list produced?" is: Bubble sort compares neighbours; bucket sort places values by size**
**Answer: False** — Gather the buckets in bucket order, one after another

**9. (Sub lesson 2) True or false: the answer to "What is the contrast with bubble sort?" is: Bubble sort compares neighbours; bucket sort places values by size**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What data does bucket sort not suit?" is: A range that the values are scattered into — such as 0–9, 10–19 for marks**
**Answer: False** — A list with no known range
