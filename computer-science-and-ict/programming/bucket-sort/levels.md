# Bucket Sort — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Scatter — values into their buckets
Sub lesson 1 questions from the type files. Pass mark: A range that the values are scattered into — such as 0–9, 10–19 for marks; By its own size — 37 goes in the 30s bucket; No — the value's size names its bucket; When ranges are known in advance and values spread across them; Ages, marks, prices — values with a known range.

Sub lesson 2 questions from the type files. Pass mark: Its few values are put in order — by a simple sort; The buckets are small; Gather the buckets in bucket order, one after another; Bubble sort compares neighbours; bucket sort places values by size; A list with no known range.
