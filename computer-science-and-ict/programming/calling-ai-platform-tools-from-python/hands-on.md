# Hands-on — Calling AI Platform Tools from Python

The lesson with your hands and your feet, not only your eyes.

## Trace the call
Draw the counter diagram for one chatbot exchange: friend, WeChat, your program, platform tool, and back. Label every arrow with what travels on it (message text, request, response, reply).

## Run the loop
With the teacher's accounts, run the chatbot program, send it three messages from a phone, and watch the program's side. Then change one thing the program controls — for example, add a greeting before the tool's answer — and test again. That change is yours; the intelligence is borrowed; the composition is the skill.
