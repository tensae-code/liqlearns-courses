# Calling AI Platform Tools from Python — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) An AI platform tool is —**
a) a program the student must write from nothing  b) a ready-made trained AI ability that other programs can call through an interface  c) a kind of sensor  d) a textbook chapter
**Answer: b) a ready-made trained AI ability that other programs can call through an interface** — Speech recognition, language understanding, question answering — offered for calling.

**2. (Sub lesson 1) In a tool call, the request carries —**
a) only the program's name  b) the data to work on (such as the text) and the key identifying the caller  c) the platform's whole database  d) nothing
**Answer: b) the data to work on (such as the text) and the key identifying the caller** — And the response carries the tool's result back.

**3. (Sub lesson 1) In this pattern, your program is like the —**
a) server  b) client — the platform's tool is the server, and the intelligence lives across the call  c) database  d) network cable
**Answer: b) client — the platform's tool is the server, and the intelligence lives across the call** — The same shape as email and chat, one level up.

**4. (Sub lesson 2) The chatbot's loop runs —**
a) log in once and stop  b) receive a message, call the tool with it, take the answer, reply  c) train the AI, then chat  d) ask the teacher, then reply
**Answer: b) receive a message, call the tool with it, take the answer, reply** — A few lines of Python carrying messages both ways.

**5. (Sub lesson 2) The library the book uses to connect the Python program to WeChat is —**
a) smtplib  b) BeautifulSoup  c) itchat  d) poplib
**Answer: c) itchat** — itchat logs in, notices messages, and sends replies.
