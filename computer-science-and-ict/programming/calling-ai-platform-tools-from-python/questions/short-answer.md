# Calling AI Platform Tools from Python — short answer

Answer each question in a few sentences.

**1. (Sub lesson 1) Explain to a classmate how the WeChat account 'answers by itself', in three sentences, without using the word 'magic'.**
**Answer:** A Python program using itchat is logged in to the account and notices each arriving message. It sends the message text as a request to an AI platform's tool, which produces an answer and returns it as the response. The program then sends that answer back as the reply — so the account converses, though the understanding lives in the platform's tool.

**2. (Sub lesson 2) Name one thing this way of building gives a student programmer, and one limit it keeps.**
**Answer:** It gives reach: abilities that took teams years and mountains of data — speech, language, recognition — become usable in an afternoon's code. The limit: the program has only the powers the tools offer, called the way the platform allows; if the platform changes or closes a tool, the composition breaks, and the student cannot repair the intelligence itself.
