# Calling AI Platform Tools from Python — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) The student's chatbot program itself understands language the way the platform's AI does.**
**Answer: False** — The program carries messages; the understanding lives in the platform's trained tool.

**2. (Sub lesson 2) Composing means joining ready tools with a little of your own code into something new.**
**Answer: True** — That composition is the practical's real lesson.

**3. (Sub lesson 2) A chatbot built this way is exactly as good as the tool it calls and the requests it sends.**
**Answer: True** — Calling joins powers; it does not create new ones.
