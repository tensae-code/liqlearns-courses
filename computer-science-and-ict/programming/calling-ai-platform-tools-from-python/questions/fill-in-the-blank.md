# Calling AI Platform Tools from Python — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 1) A program uses a platform tool by sending a ____ and receiving a response.**
**Answer: request** — Request out — data plus caller key; response back — the result.

**2. (Sub lesson 2) The door through which a tool is called is its ____.**
**Answer: interface** — A defined way in and out, made for programs.

**3. (Sub lesson 1) In the call pattern, the intelligence lives on the far side of the ____.**
**Answer: call** — Your program is the client; the tool is across the call.
