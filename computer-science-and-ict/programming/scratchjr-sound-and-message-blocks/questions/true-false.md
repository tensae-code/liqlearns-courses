# ScratchJr — Sound and Message Blocks — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The Pop block and recorded sound**
**Answer: True**

**2. (Sub lesson 1) True or false: At the moment the script reaches its block** — as the answer to: What is recorded sound?
**Answer: False — The pupil's own voice or a real sound, captured with the device**

**3. (Sub lesson 1) True or false: At the moment the script reaches its block**
**Answer: True**

**4. (Sub lesson 1) True or false: Sends a coloured signal out to other sprites** — as the answer to: What is a message in ScratchJr?
**Answer: False — A coloured signal sent between sprites**

**5. (Sub lesson 1) True or false: Sends a coloured signal out to other sprites**
**Answer: True**

**6. (Sub lesson 2) True or false: Dialogue and turn-taking — one sprite waking the next speaker** — as the answer to: What does Start on Message do?
**Answer: False — Starts the script of a sprite waiting for that message colour**

**7. (Sub lesson 2) True or false: Dialogue and turn-taking — one sprite waking the next speaker**
**Answer: True**

**8. (Sub lesson 2) True or false: No — the sprites set each other going** — as the answer to: Do messages need to match?
**Answer: False — Yes — by colour; red sent is not heard by a script waiting on blue**

**9. (Sub lesson 2) True or false: No — the sprites set each other going**
**Answer: True**

**10. (Sub lesson 2) True or false: The Pop block and recorded sound** — as the answer to: Which book teaches this?
**Answer: False — Kuwait Grade 4 Digital Explorer Term 1, Unit 2 Lesson 4**
