# ScratchJr — Sound and Message Blocks — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) Name ScratchJr's two sound kinds in this lesson.** → **The Pop block and recorded sound**

**2. (Sub lesson 1) What is recorded sound?** → **The pupil's own voice or a real sound, captured with the device**

**3. (Sub lesson 1) Where does a sound land in time?** → **At the moment the script reaches its block**

**4. (Sub lesson 1) What is a message in ScratchJr?** → **A coloured signal sent between sprites**

**5. (Sub lesson 1) What does Send Message do?** → **Sends a coloured signal out to other sprites**

**6. (Sub lesson 2) What does Start on Message do?** → **Starts the script of a sprite waiting for that message colour**

**7. (Sub lesson 2) What is messages' best story use?** → **Dialogue and turn-taking — one sprite waking the next speaker**

**8. (Sub lesson 2) Do messages need to match?** → **Yes — by colour; red sent is not heard by a script waiting on blue**

**9. (Sub lesson 2) Who acts in a message exchange — the reader?** → **No — the sprites set each other going**
