# ScratchJr — Sound and Message Blocks — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Sound blocks — Pop and your own recorded sound
Sub lesson 1 questions from the type files. Pass mark: The Pop block and recorded sound; The pupil's own voice or a real sound, captured with the device; At the moment the script reaches its block; A coloured signal sent between sprites; Sends a coloured signal out to other sprites.
