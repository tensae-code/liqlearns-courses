# Hands-on — Reading and Printing Array Elements

The lesson with your hands and your feet, not only your eyes.

## Fill and show
Write a program that reads 6 numbers into an array and prints them back in the same order, one per line with its index. Test it and check every value lands where it should.

## Reverse the walk
Change the printing loop to walk from the last element to the first. State the loop's start, condition and step, and predict the output for the array {4, 8, 15}.
