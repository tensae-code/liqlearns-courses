# Reading and Printing Array Elements — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What selects each element in the input loop?**
**Answer: The loop counter, used as the index**

**2. (Sub lesson 1) Where does a typed value land?**
**Answer: In the element a[i] for the current i**

**3. (Sub lesson 1) Why print a prompt per element?**
**Answer: So the user knows what the program waits for**

**4. (Sub lesson 1) What are the loop's bounds for size n?**
**Answer: i from 0 while i < n**

**5. (Sub lesson 1) Does one read statement fill a whole array?**
**Answer: No — the loop repeats the read per element**

**6. (Sub lesson 2) What does the output loop print?**
**Answer: Every element, in turn**

**7. (Sub lesson 2) Why add spaces or new lines between printed elements?**
**Answer: So values do not fuse into one digit string**

**8. (Sub lesson 2) What are the two loops together?**
**Answer: The standard frame: fill the array, then show it**

**9. (Sub lesson 2) What must match across all the program's array loops?**
**Answer: The count n**

**10. (Sub lesson 2) Which statement shows an element?**
**Answer: cout << a[i]**
