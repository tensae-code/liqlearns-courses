# Reading and Printing Array Elements — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What selects each element in the input loop?**
a) The loop counter, used as the index  b) In the element a[i] for the current i  c) So the user knows what the program waits for  d) i from 0 while i < n
**Answer: a) The loop counter, used as the index**

**2. (Sub lesson 1) Where does a typed value land?**
a) So the user knows what the program waits for  b) In the element a[i] for the current i  c) i from 0 while i < n  d) No — the loop repeats the read per element
**Answer: b) In the element a[i] for the current i**

**3. (Sub lesson 1) Why print a prompt per element?**
a) i from 0 while i < n  b) No — the loop repeats the read per element  c) So the user knows what the program waits for  d) Every element, in turn
**Answer: c) So the user knows what the program waits for**

**4. (Sub lesson 1) What are the loop's bounds for size n?**
a) No — the loop repeats the read per element  b) Every element, in turn  c) So values do not fuse into one digit string  d) i from 0 while i < n

**5. (Sub lesson 1) Does one read statement fill a whole array?**
a) No — the loop repeats the read per element  b) Every element, in turn  c) So values do not fuse into one digit string  d) The standard frame: fill the array, then show it

**6. (Sub lesson 2) What does the output loop print?**

**7. (Sub lesson 2) Why add spaces or new lines between printed elements?**
a) The standard frame: fill the array, then show it  b) The count n  c) So values do not fuse into one digit string  d) cout << a[i]
