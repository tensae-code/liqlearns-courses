# Binary Numbers and Logic in a Machine

## Do it first

A light switch knows two things: on and off. Grade 8's programming experience begins by noticing that this poverty is a power: a machine built of on/off parts can count, compare and decide — if you learn to think in its two values. This lesson is the doorway into the book's Python work, and it opens with the machine's own numbers.

## Sub lesson 1 — Binary — the machine's two values

A machine's parts are **on or off** — current flowing or not — so its numbers are **binary**: built from the digits **1 (on) and 0 (off)** alone. Every value the machine holds — numbers, letters, pictures — is patterns of these two states, as the first-steps lessons taught; Grade 8 meets the idea where it will be used: inside programming, where the machine's two values become the programmer's true and false, yes and no, pass and fail.

In your mind's eye: binary — the machine's two values.

## Sub lesson 2 — Logic with inputs — the machine decides

Give the machine **inputs** and its states can be **combined by logic**: this input AND that one, this OR that, NOT this — and the combination decides the output, as the logic lessons formalise. A machine that senses 'door closed AND code correct' and only then unlocks is doing Grade 8's opening session with wires. Programming, when it arrives in the next sessions, is this same deciding written in words the machine obeys: inputs, logic, output — the shape of every program in the book and beyond it.

In your mind's eye: logic with inputs — the machine decides.
