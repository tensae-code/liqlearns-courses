# Counting with range() — start, stop-before, step — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** range(5) gives —
a) 1 to 5  b) 0 to 5  c) 0 to 4
**Answer: c) c) 0 to 4** — Verified.

**2. (Sub lesson 1)** range(2, 5) gives —
a) 2, 3, 4  b) 2, 3, 4, 5  c) 0, 1, 2, 3, 4
**Answer: a) a) 2, 3, 4**

**3. (Sub lesson 1)** range(1, 10, 2) gives —
a) 1, 2, 3 … 9  b) 1, 3, 5, 7, 9  c) 2, 4, 6, 8, 10
**Answer: b) b) 1, 3, 5, 7, 9** — Step 2.

**4. (Sub lesson 1)** By default range starts at —
a) 1  b) 0  c) the end value
**Answer: b) b) 0**

**5. (Sub lesson 2)** Keyboard input arrives as —
a) an integer  b) a string  c) a list
**Answer: b) b) a string** — Always text.

**6. (Sub lesson 2)** To print 1 up to a typed number n itself, the range end must be —
a) n  b) n + 1  c) n − 1
**Answer: b) b) n + 1** — Because range stops before its end.
