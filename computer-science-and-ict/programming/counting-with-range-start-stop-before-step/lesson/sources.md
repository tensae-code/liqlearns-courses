GUIDE ERROR flagged and taught corrected: the teacher guide's Activity 6.9 direction words the int() cast backwards — it says keyboard input must be 'cast/change to string first … using int()'. int() casts TO integer, not to string. Sub lesson 2 teaches it correctly: input arrives as a string and int() converts it to a number (guide printed pp. 134–139; error recorded in the guide placements' Book errors). A second guide fault touches this lesson's counting: the guide's keyed review counting program uses range(1, user_input), which stops one short of the number the student question asks to reach; the lesson follows the STUDENT question and uses range(1, n + 1) — verified to print up to n itself. All code in this lesson was run in Python 3 and its output matches the lesson text.
