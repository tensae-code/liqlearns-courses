# LOGO loops with do.until and do.while — predicting outputs — true or false

Say true or false for each one.

**1.** do.while [action][condition] puts the action before the condition.
**Answer: True.**

**2.** do.until and do.while always print the same numbers from the same start.
**Answer: False** — their guards differ; the book's examples print 1–10 and 1–9.

**3.** Predicting a program's output before running it is part of this unit's closing activity.
**Answer: True.**
