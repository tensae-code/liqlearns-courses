# Correctness and Complexity of Algorithms — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What makes an algorithm correct?**
**Answer: For every allowed input it ends and gives the answer the problem asks for**

**2. (Sub lesson 1) How does the book test correctness?**
**Answer: Trace it on chosen inputs — smallest, largest, awkward middle — and check each answer**

**3. (Sub lesson 1) What beats a hundred easy successes?**
**Answer: One honest counterexample**

**4. (Sub lesson 1) Correct always means what?**
**Answer: Correct for this problem's statement**

**6. (Sub lesson 2) What does complexity count?**
**Answer: Steps (and memory held) as the input size grows — not seconds on one machine**

**8. (Sub lesson 2) Whose work follows the list's length?**
**Answer: Linear search's**

**9. (Sub lesson 2) What survives every faster machine?**
