# Writing a Program with Best Practices — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Names and comments — the program explains itself
Sub lesson 1 questions from the type files. Pass mark: Meaningful names, comments, and named constants; Say what the thing is for — totalMark, not x2; Why a part exists and what a non-obvious step does — not what the code plainly says; So no unexplained numbers wander the code; Its writer, months later, when something must change.

## Sub lesson 2 — Layout and structure — the program shows its shape
Sub lesson 2 questions from the type files. Pass mark: Shape — layout and structure; Nesting — so bodies and branches are seen at a glance; Jumps that tangle the flow — structures stay in their standard shapes; Algorithm first, code translated from it, tests planned and run; The program passes its tests and can be handed to another programmer without apology or tour.
