# Writing a Program with Best Practices — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Name the first family of best practices.**
a) Meaningful names, comments, and named constants  b) Say what the thing is for — totalMark, not x2  c) Why a part exists and what a non-obvious step does — not what the code plainly says  d) So no unexplained numbers wander the code
