# LOGO conditionals — ifelse — multiple choice

Pick the one right answer.

**1.** The general form of the conditional is —
a) ifelse [condition][action if true][action if false]  b) repeat [condition][action]  c) make [condition][value]  d) to [condition][action]
**Answer: a) ifelse [condition][action if true][action if false].**

**2.** If the else part is left out and the condition is false, the application —
a) repeats the action  b) does nothing  c) prints an error and stops the unit  d) guesses
**Answer: b) does nothing.**

**3.** In worked example 1, both variables are 23, so the program prints —
a) It's FALSE  b) nothing  c) It's TRUE  d) 23
**Answer: c) It's TRUE** — the test :variable1 = :variable2 is true.

**4.** In worked example 2, the variables are 23 and 25, so the program prints —
a) It's TRUE  b) It's FALSE  c) 25  d) nothing
**Answer: b) It's FALSE.**

**5.** The condition in both worked examples tests —
a) whether :variable1 is bigger than 100  b) whether :variable1 equals :variable2  c) whether the turtle is home  d) whether a variable exists
**Answer: b) whether :variable1 equals :variable2.**
