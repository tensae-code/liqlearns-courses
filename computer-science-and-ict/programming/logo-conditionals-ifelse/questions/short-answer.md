# LOGO conditionals — ifelse — short answer

Answer in one or two sentences.

**1.** Variables are set to 50 and 51 and tested with :variable1 = :variable2 in an ifelse that prints "It's TRUE" or "It's FALSE". What prints, and why?
**Answer: "It's FALSE" prints — 50 is not equal to 51, so the condition is false and the else action runs. (This is the unit's closing activity, first program; the teacher guide's key agrees.)**

**2.** In the book's second worked example, the value 25 belongs to which variable?
**Answer: variable2 — the book's comment says "variable 1" where variable2 is meant (see the lesson's sources).**
