# Prototyping and Rapid Application Development — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a prototype?" is: A quick, rough, working version of a system, built so users can try it and react**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Why build one?" is: The version is shown, corrected and shown again**
**Answer: False** — Users who cannot describe what they want can say it at once from a prototype

**3. (Sub lesson 1) True or false: the answer to "What happens in prototype rounds?" is: The version is shown, corrected and shown again**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What else can a prototype become?" is: Reaction is easier than imagination**
**Answer: False** — The clearest possible requirements statement for a full build

**5. (Sub lesson 1) True or false: the answer to "What is Fiji's insight about prototyping?" is: Reaction is easier than imagination**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is RAD?" is: Users and builders, in short cycles**
**Answer: False** — Rapid Application Development — building the whole system by short prototype cycles with users

**7. (Sub lesson 2) True or false: the answer to "Who works together in RAD?" is: Users and builders, in short cycles**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What are RAD's gains?" is: Wandering — a loosely run build ends half-documented and hard to maintain**
**Answer: False** — Speed and fit — a system its users helped shape

**9. (Sub lesson 2) True or false: the answer to "What is RAD's risk?" is: Wandering — a loosely run build ends half-documented and hard to maintain**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "When does Fiji choose the full life cycle instead?" is: A quick, rough, working version of a system, built so users can try it and react**
**Answer: False** — For systems that must be right — where being right matters more than learning fast
