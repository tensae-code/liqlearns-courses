# Hands-on — C File Handling Streams and Opening Modes

The lesson with your hands and your feet, not only your eyes.

## Task one
**Work the book's own example** — Chapter 14 §14.1 Overview (permanent storage in files), §14.2 The Stream (text stream vs binary stream), §14.3 Newline and EOF Marker, Opening a File (fopen; the NULL check) and §14.4.1 File Opening Modes (r, w, a, r+, w+, a+) Work it with the book open first, step by step, then close the book and do it again.

## Task two
**Show it to someone else** — Teach c file handling streams and opening modes to a companion in your own words, with your worked example in front of you, and answer their one question from the lesson.
