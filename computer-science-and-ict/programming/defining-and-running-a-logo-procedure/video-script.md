The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Two ways to teach Logo a word.

TO route. Click the input box. Type: TO SQUARE. Enter.
Type the commands. Enter after each. Type END.
Editor route. Type: Edit Square. Enter.
Blank line. Commands. File — Save and Exit.

Remembered — not run. Teaching is not drawing.
Now run it. Type SQUARE. Enter.
Four sides draw themselves. You are a programmer.
