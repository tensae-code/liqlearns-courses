# Lesson plan — Defining and running a LOGO procedure

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** Defining and running a LOGO procedure
**Place in the curriculum:** Title 12 — Programming in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 7 book, Unit 6 — Logic Oriented Graphics Oriented (LOGO) Programming. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** a procedure is defined two ways, in the book's order — the TO route (TO name, Enter, commands, END) and the Editor route (Edit "Square", commands, File → Save and Exit) — typed instructions are remembered, not run; typing the name runs it.
**This lesson's own level:** it is a doing-lesson, the last of the book — it stands on the procedures and commands lessons, and completes Grade 7's LOGO.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The TO route** — click in the Command Input Box; type TO + name; Enter; in the To Mode Input box, type the commands one after another, Enter after each; type END
2. **The Editor route** — type Edit "Square" and Enter; in the Editor Window insert a blank line after TO SQUARE; type the commands; File → Save and Exit
3. **Running — and the circle (teacher guide — evidence)** — type the name, press Enter; typed instructions are remembered, not run at once; the guide's circle: 360 tiny steps of one degree; closing activity: a 10 by 5 rectangle
4. **Creating a procedure with EDIT — the Grade 8 worked example** — EDIT with no space after the quote and no quote after the name; File → Edit; "square" on the Edit Procedure form; commands between TO SQUARE and END; Save and Exit; run from the Commander with Execute

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: LOGO procedures — giving a name to a set of commands, and LOGO drawing commands — fd, bk, rt, lt, cs.  Recommended, never forced.

## What the learner can do when it ends
1. Define SQUARE by the TO route, in order.
2. Define a procedure by the Editor route, leaving by Save and Exit.
3. Explain remembered-not-run, and run a procedure by its name.
4. Describe the 360-step circle, and define a 10 by 5 rectangle procedure.
5. Create a procedure by the Grade 8 EDIT route, in the book's order, and run it from the Commander (Grade 8 growth).

## If the learner is stuck
- Expects the square while still defining → defining remembers; running draws. If nothing drew, you were teaching, not commanding — type the name now.
- Loses the Editor work → the exit is File → Save and Exit; closing the window any other way throws the teaching away.
- Copies the guide's printed rectangle key → it is wrong as printed (see sources); build the rectangle from the turns: four sides, four right angles.
