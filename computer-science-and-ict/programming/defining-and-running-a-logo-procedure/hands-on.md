# Hands-on — Defining and running a LOGO procedure

The lesson with your hands, not only your eyes.

## Both routes, one square
Define SQUARE by the TO route and run it. Clear with cs. Define it again (as SQUARE2) in the Editor and run it. Same square, two teachings — you now own both routes.

## The Grade 8 worked example, for real
Follow the worked example exactly: open MSW LOGO; File → Edit; type "square" on the Edit Procedure form; click OK; type fd 100 rt 90 fd 100 between TO SQUARE and END; File → Save and Exit; then type "square" in the Commander and click Execute. Then do the closing activity: the two given square procedures — one with three sides' commands, one complete — and view both outputs.

## Rectangle challenge
Do the book's closing activity: define a procedure drawing a 10 by 5 rectangle — forward 10, turn, forward 5, turn, forward 10, turn, forward 5. Predict it on paper first, then run and compare.

## If it is hard
The guide's support instruction for LOGO practicals applies here at its strongest: teachers encourage pupils who lag behind and support those with special needs while observing this work — defining a first procedure is the hardest step of the unit, and it is a watched, helped step.
