# Defining and running a LOGO procedure

## Do it first

On paper, write what SQUARE should hold: the commands, in order, that draw a square of side 100. Keep the paper. This lesson teaches both of the book's routes for teaching that list to Logo — and how to run it. Your paper list is the content; the routes are just the delivery.

## Sub lesson 1 — The TO route

In the book's order: **click in the Command Input Box**; type **TO** followed by the name — **TO SQUARE**; press **Enter**. In the **To Mode Input box** that appears, **click inside** it; type the commands **one after another, pressing Enter after each**; finally type **END**. The procedure is now Logo's: remembered, ready, not yet run.

[Picture 10531 — defining a procedure]

## Sub lesson 2 — The Editor route

The second route: type **Edit "Square"** in the Command Input Box and press **Enter**. In the **Editor Window**, **insert a blank line after the TO SQUARE line**; type the procedure's commands there; then **File menu → Save and Exit**. The Editor suits longer procedures — you can see the whole list at once, and fix a line without retyping the whole teaching.

## Sub lesson 3 — Running — and the circle (teacher guide — evidence)

Understand this first: **typed instructions are remembered, not run at once** — defining is teaching, not drawing. **Running** is separate: **type the procedure's name in the command input box and press Enter** — SQUARE draws its square, as the GIF shows. The teacher guide adds one jewel of content: its review key builds a **circle from 360 tiny forward steps, each with a one-degree turn** — tiny straight lines, bending a degree at a time, until the line closes on itself. And the book's closing activity is yours to finish with: **define a procedure that draws a 10 by 5 rectangle.**

Tell your companion both defining routes in order, the difference between defining and running, and how a circle can be built from straight steps.

## Do It Yourself

1. Define and run SQUARE by the TO route, alone.

3. Write out the 10 by 5 rectangle procedure you defined, commands in order.
