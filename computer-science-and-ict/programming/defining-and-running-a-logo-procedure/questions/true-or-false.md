# Defining and running a LOGO procedure — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 2)** The Editor route leaves by File → Save and Exit.
**Answer: True** — that exit keeps the teaching.

**2. (Sub lesson 3)** Typing SQUARE in the input box and pressing Enter runs the procedure.
**Answer: True** — name + Enter = the run.

**3. (Sub lesson 3)** A circle in LOGO is drawn with one single curve command in the guide's key.
**Answer: False** — 360 tiny straight steps, one degree at a time.
