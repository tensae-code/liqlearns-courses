# Defining and running a LOGO procedure — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The TO route begins by —
a) opening the Editor  b) clicking in the Command Input Box and typing TO + the name  c) typing END  d) running SQUARE
**Answer: b) clicking in the Command Input Box and typing TO + the name** — input box, TO SQUARE, Enter.

**2. (Sub lesson 1)** In To Mode, commands are typed —
a) all on one line  b) one after another, Enter after each, ending with END  c) only once ever  d) in the graphics screen
**Answer: b) one after another, Enter after each, ending with END** — one after another, then END.

**3. (Sub lesson 1)** The last word of the TO route is —
a) RUN  b) END  c) EXIT  d) GO
**Answer: b) END** — type END to finish the teaching.

**4. (Sub lesson 2)** The Editor route opens with —
a) Edit "Square" in the Command Input Box  b) TO SQUARE only  c) File → Open  d) Help → Demo
**Answer: a) Edit "Square" in the Command Input Box** — Edit "Square", then Enter.

**5. (Sub lesson 2)** In the Editor you insert —
a) a picture  b) a blank line after the TO SQUARE line  c) your name only  d) a password
**Answer: b) a blank line after the TO SQUARE line** — blank line after TO SQUARE, then the commands.

**6. (Sub lesson 3)** Typed instructions in a definition are —
a) run at once  b) remembered, not run at once  c) deleted  d) printed
**Answer: b) remembered, not run at once** — defining is teaching; running is separate.

**7. (Sub lesson 4)** In the Grade 8 EDIT route, the menu path that opens the Edit Procedure form is —
a) File → Edit  b) Edit → File  c) View → Edit  d) Tools → Run
**Answer: a) File → Edit** — then type "square" on the form and click OK.

**8. (Sub lesson 4)** After Save and Exit, the procedure is run by —
a) closing LOGO  b) typing "square" in the Commander command input box and clicking Execute  c) pressing Print  d) typing END again
**Answer: b) typing "square" in the Commander command input box and clicking Execute.**
