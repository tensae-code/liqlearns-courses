## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Look first — the problem, stated plainly** — The **preliminary investigation** is a **short, first look** at the present system and its troubles, done before any promise is made. It asks three questions. **What is the problem** — stated plainly, in the users' own experience (not 'we need a computer' but 'stock figures are three weeks late')? **Is a new system feasible** — could it be built and run with the money, people, skills and time actually available? And **is it worth it** — would its gains outweigh its whole cost? Fiji's phase is deliberately small: a look, not a study.
2. **The decision Phase 1 hands on** — The phase ends in a **decision and a report**: go ahead to full analysis, change the idea, or **stop** — stopping is a success of this phase, not a failure, when it saves an organisation from building the wrong system. If the answer is go, the investigation hands analysis its starting gift: the problem stated, the present system sketched, and the limits — money, time, people — written down. At Viti, Phase 1 is where 'the stock cards are always wrong' becomes a bounded question the rest of the cycle can work on.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## The run of the lesson (in order)
1. **Do it first** — Every system begins as a complaint: the records are slow, the stock is wrong, the office is drowning. Fiji's Year 13 life cycle opens with the phase that listens to the complaint before believing it — the preliminary investigation. This lesson is Phase 1. (lesson/lesson.md).
2. **The explanation** — the lesson text in lesson/lesson.md, in its parts in order.
   - ADD IMAGE: a picture of look first — the problem, stated plainly as the lesson describes it — the student studies the picture and names what each part shows.
   - ADD GIF: a GIF of the decision phase 1 hands on in action — the student watches once, then says what changed and why.
   - ADD AUDIO: a voice reading the lesson's key names and definitions aloud, in the order the lesson gives them — the student listens once through, then reads the same lines aloud along with the voice. (Audio is a described slot in this build; no audio file is made.)
3. **Say it to your companion** — the companion block in lesson/lesson.md.
   - ADD VIDEO: the script in video-script.md, filmed — the lesson in the super-simple voice (made later, when videos are made).
4. **Questions** — from questions/: multiple-choice, true-false, matching, short-answer — served at the learner's level and teaching-mix (levels.md).
5. **Hands-on** — hands-on.md.
6. **Do It Yourself** — the doing block at the end of lesson/lesson.md.
