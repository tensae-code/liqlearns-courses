# Constants — TRUE/FALSE, HIGH/LOW, INPUT/OUTPUT — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What is a constant?** → **A name whose value is fixed before the program runs and never changes inside it**

**2. (Sub lesson 1) Why does the course name the constants as their own lesson?** → **Sketches are unreadable without them**

**3. (Sub lesson 1) What are TRUE and FALSE?** → **The two answers of every test in the program — standing for 1 and 0**

**4. (Sub lesson 1) What do HIGH and LOW name?** → **A pin's two levels — voltage present or absent**

**5. (Sub lesson 1) Which commands use HIGH and LOW?** → **digitalWrite sets them; digitalRead returns them**

**6. (Sub lesson 2) What do INPUT and OUTPUT name?** → **A pin's two directions — given to pinMode**

**7. (Sub lesson 2) Why use the names instead of bare numbers?** → **The names read as they mean — and mean the same in every sketch**

**8. (Sub lesson 2) Constants are the language keeping what?** → **Its promises**

**9. (Sub lesson 2) Write the pin conversation in constants.** → **Set this pin OUTPUT, write it HIGH, read that INPUT pin**
