# Constants — TRUE/FALSE, HIGH/LOW, INPUT/OUTPUT — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a constant?**
**Answer: A name whose value is fixed before the program runs and never changes inside it**

**2. (Sub lesson 1) Why does the course name the constants as their own lesson?**
**Answer: Sketches are unreadable without them**

**3. (Sub lesson 1) What are TRUE and FALSE?**
**Answer: The two answers of every test in the program — standing for 1 and 0**

**4. (Sub lesson 1) What do HIGH and LOW name?**
**Answer: A pin's two levels — voltage present or absent**

**5. (Sub lesson 1) Which commands use HIGH and LOW?**
**Answer: digitalWrite sets them; digitalRead returns them**

**6. (Sub lesson 2) What do INPUT and OUTPUT name?**
**Answer: A pin's two directions — given to pinMode**

**7. (Sub lesson 2) Why use the names instead of bare numbers?**
**Answer: The names read as they mean — and mean the same in every sketch**

**8. (Sub lesson 2) Constants are the language keeping what?**
**Answer: Its promises**

**9. (Sub lesson 2) Write the pin conversation in constants.**
**Answer: Set this pin OUTPUT, write it HIGH, read that INPUT pin**

**10. (Sub lesson 2) Where does Indonesia teach this?**
**Answer: Grade 12, Bab 3 I — constant values in Arduino programs**
