# Constants — TRUE/FALSE, HIGH/LOW, INPUT/OUTPUT — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A name whose value is fixed before the program runs and never changes inside it**
**Answer: True**

**2. (Sub lesson 1) True or false: A name whose value is fixed before the program runs and never changes inside it** — as the answer to: Why does the course name the constants as their own lesson?

**3. (Sub lesson 1) True or false: The two answers of every test in the program — standing for 1 and 0**
**Answer: True**

**4. (Sub lesson 1) True or false: The two answers of every test in the program — standing for 1 and 0** — as the answer to: What do HIGH and LOW name?

**5. (Sub lesson 1) True or false: digitalWrite sets them; digitalRead returns them**

**7. (Sub lesson 2) True or false: The names read as they mean — and mean the same in every sketch**

**8. (Sub lesson 2) True or false: The names read as they mean — and mean the same in every sketch** — as the answer to: Constants are the language keeping what?
