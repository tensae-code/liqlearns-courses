# Drawing with Loops — and Jump Instructions — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A drawing with a repeating part — a row of houses, a fence, a pattern**
**Answer: True**

**2. (Sub lesson 1) True or false: A drawing with a repeating part — a row of houses, a fence, a pattern** — as the answer to: What decides how long a pattern runs?
**Answer: False — The loop's count**

**3. (Sub lesson 1) True or false: The length of the pattern — the same program draws more or fewer repeats**
**Answer: True**

**4. (Sub lesson 1) True or false: The length of the pattern — the same program draws more or fewer repeats** — as the answer to: What two things does a loop separate?
**Answer: False — What repeats, and how many times**

**5. (Sub lesson 1) True or false: Fence planks (also: window rows, roof tiles, dotted borders)**
**Answer: True**

**6. (Sub lesson 2) True or false: Fence planks (also: window rows, roof tiles, dotted borders)** — as the answer to: What is a jump instruction?
**Answer: False — A move without drawing — the pen lifted, no line made**

**7. (Sub lesson 2) True or false: Without it every move drags a line and separate drawings smear together**
**Answer: True**

**8. (Sub lesson 2) True or false: Without it every move drags a line and separate drawings smear together** — as the answer to: How is a dotted line drawn with loops and jumps?
**Answer: False — Draw, jump, draw, jump — repeated in a loop**

**9. (Sub lesson 2) True or false: The silence between words**
**Answer: True**

**10. (Sub lesson 2) True or false: The silence between words** — as the answer to: Does the jump appear in the finished drawing?
**Answer: False — No — it makes nothing, on purpose; only its effect (the gap) shows**
