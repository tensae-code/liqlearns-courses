# Hands-on — Drawing with Loops — and Jump Instructions

The lesson with your hands and your feet, not only your eyes.

## Task one
**Pattern row** — Program a row of five identical simple houses using one loop; then change only the count and draw eight.

## Task two
**Dotted road** — Write a draw-jump loop program for a dotted path across the page, and a second program that draws two separate pictures with a jump between them.
