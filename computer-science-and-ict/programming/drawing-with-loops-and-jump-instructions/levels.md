# Drawing with Loops — and Jump Instructions — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Loops that draw — patterns from repetition
Sub lesson 1 questions from the type files. Pass mark: A drawing with a repeating part — a row of houses, a fence, a pattern; The loop's count; The length of the pattern — the same program draws more or fewer repeats; What repeats, and how many times; Fence planks (also: window rows, roof tiles, dotted borders).

## Sub lesson 2 — The jump instruction — moving without drawing
Sub lesson 2 questions from the type files. Pass mark: A move without drawing — the pen lifted, no line made; Without it every move drags a line and separate drawings smear together; Draw, jump, draw, jump — repeated in a loop; The silence between words; No — it makes nothing, on purpose; only its effect (the gap) shows.
