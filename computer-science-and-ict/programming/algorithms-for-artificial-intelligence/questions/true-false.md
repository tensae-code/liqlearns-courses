# Algorithms for Artificial Intelligence — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is an AI algorithm, in the course's own shape?" is: Inputs, steps and outputs — a procedure, like every algorithm**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How do AI algorithms differ from ordinary ones?" is: Where the rules cannot all be written down — recognising, predicting, choosing**
**Answer: False** — They handle cases nobody enumerated, following a pattern from examples instead of a rule for every case

**3. (Sub lesson 1) True or false: the answer to "Where do AI algorithms work?" is: Where the rules cannot all be written down — recognising, predicting, choosing**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does a search algorithm do?" is: Applies a fitted pattern to new data**
**Answer: False** — Finds a path or a best move by trying possibilities in an order

**5. (Sub lesson 1) True or false: the answer to "What does a prediction algorithm do?" is: Applies a fitted pattern to new data**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does a learning algorithm do?" is: It explodes when the possibilities multiply**
**Answer: False** — Adjusts its own pattern from results, improving as examples accumulate

**7. (Sub lesson 2) True or false: the answer to "How does search fail?" is: It explodes when the possibilities multiply**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How does prediction fail?" is: The results it is fed**
**Answer: False** — It inherits its data's blind spots

**9. (Sub lesson 2) True or false: the answer to "What is learning only as honest as?" is: The results it is fed**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why does Egypt teach AI algorithms inside the Python unit?" is: Inputs, steps and outputs — a procedure, like every algorithm**
**Answer: False** — The pupil is about to write algorithms and should know which kind AI's are
