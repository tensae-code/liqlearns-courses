# Two-Dimensional Arrays — Tables of Values — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) In what shape does a two-dimensional array hold values?**
a) In rows and columns, like a table  b) By two position numbers — which row, which column  c) On paper, as a drawn table with rows and columns named  d) Filling a table of values
**Answer: a) In rows and columns, like a table**

**2. (Sub lesson 1) How is a value in a 2D array reached?**
a) Only one  b) By two position numbers — which row, which column  c) Two-dimensional arrays  d) Reading the value at a given row and column
**Answer: b) By two position numbers — which row, which column**

**3. (Sub lesson 1) How many position numbers does a 1D array need?**
a) On paper, as a drawn table with rows and columns named  b) Filling a table of values  c) Only one  d) A loop inside a loop — nested loops
**Answer: c) Only one**

**4. (Sub lesson 1) How does the book first represent a 2D array?**
a) Two-dimensional arrays  b) Reading the value at a given row and column  c) One loop for the rows, one for the columns  d) On paper, as a drawn table with rows and columns named
**Answer: d) On paper, as a drawn table with rows and columns named**

**5. (Sub lesson 1) What do the unit's closing examples work on?**
a) Two-dimensional arrays  b) Filling a table of values  c) A loop inside a loop — nested loops  d) Grade 11
**Answer: a) Two-dimensional arrays**

**6. (Sub lesson 2) Name one thing the solved examples do.**
a) Reading the value at a given row and column  b) Filling a table of values  c) One loop for the rows, one for the columns  d) In rows and columns, like a table
**Answer: b) Filling a table of values**

**7. (Sub lesson 2) Name another thing they do.**
a) A loop inside a loop — nested loops  b) Grade 11  c) Reading the value at a given row and column  d) By two position numbers — which row, which column
**Answer: c) Reading the value at a given row and column**

**8. (Sub lesson 2) What does working through the whole table need?**
a) One loop for the rows, one for the columns  b) In rows and columns, like a table  c) Only one  d) A loop inside a loop — nested loops
**Answer: d) A loop inside a loop — nested loops**

**9. (Sub lesson 2) What is one loop for, and what is the other for?**
a) One loop for the rows, one for the columns  b) Grade 11  c) By two position numbers — which row, which column  d) On paper, as a drawn table with rows and columns named
**Answer: a) One loop for the rows, one for the columns**

**10. (Sub lesson 2) Which grade's book teaches two-dimensional arrays?**
a) In rows and columns, like a table  b) Grade 11  c) Only one  d) Two-dimensional arrays
**Answer: b) Grade 11**
