# Video script — Two-Dimensional Arrays — Tables of Values

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A **two-dimensional array** holds values in **rows and columns**, like a table. A value is reached by **two position numbers** — which row, which column — where the one-dimensional array needed only one. The book represents the two-dimensional array on paper first, as a drawn table with its rows and columns named.
The book closes the arrays unit with **solved examples on two-dimensional arrays**: filling a table of values, reading the value at a given row and column, and working through the whole table — which needs a **loop inside a loop**, the nested loops of the lesson before this one, one loop for the rows and one for the columns.
