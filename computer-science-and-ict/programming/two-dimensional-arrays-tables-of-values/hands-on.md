# Hands-on — Two-Dimensional Arrays — Tables of Values

The lesson with your hands and your feet, not only your eyes.

## Draw the table
Draw a 3-by-4 two-dimensional array for three classes' marks in four subjects. Fill it, then read out the values your companion asks for by row and column.

## Address every cell
Write the list of (row, column) addresses in the order nested loops would visit them — rows first, across each row.
