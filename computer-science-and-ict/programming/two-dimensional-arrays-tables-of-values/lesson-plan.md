# Lesson plan — Two-Dimensional Arrays — Tables of Values

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** Two-Dimensional Arrays — Tables of Values
**Place in the curriculum:** ICT expansion — Iraq (2026-11-14) — in the title Programming on the ICT course ladder (TITLES.md). Built new from Iraq's Grade 11 Computer student book, because no existing lesson in the course covers this thing as its own lesson.
**The one thing this lesson teaches:** A two-dimensional array holds values in rows and columns, like a table. The book closes the arrays unit with solved examples on two-dimensional arrays: filling a table of values, reading the value at a given row and column, and working through the whole table — which needs a loop inside a loop, the nested loops of the lesson before this one, one loop for the rows and one for the columns..
**This lesson's own level:** It stands on the earlier lessons of its title and on the book's own order — it follows the book's lessons in sequence, so its neighbours in the book are its natural companions. It stands alone for a learner landing on it directly.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Representing two-dimensional arrays** — A **two-dimensional array** holds values in **rows and columns**, like a table. A value is reached by **two position numbers** — which row, which column — where the one-dimensional array needed only one. The book represents the two-dimensional array on paper first, as a drawn table with its rows and columns named.
2. **Worked examples on two-dimensional arrays** — The book closes the arrays unit with **solved examples on two-dimensional arrays**: filling a table of values, reading the value at a given row and column, and working through the whole table — which needs a **loop inside a loop**, the nested loops of the lesson before this one, one loop for the rows and one for the columns.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
