# Broadcasting Messages Between Sprites in Scratch — multiple choice

Pick the one right answer.

**1. Broadcast does what?**
a) Sends a named message to the whole project  b) Deletes a message  c) Plays a sound
**Answer: a) Sends a named message to the whole project** — A broadcast shouts a name project-wide.

**2. A script that starts on a message is topped by —**
a) When I receive  b) When flag clicked only  c) Forever
**Answer: a) When I receive** — When I receive + the message's name.

**3. A receiver waiting on 'go' when 'stop' is broadcast —**
a) Runs anyway  b) Hears nothing and stays asleep  c) Changes name
**Answer: b) Hears nothing and stays asleep** — Names must match exactly.

**4. The book's advanced use of messages is —**
a) Running a whole game by messages instead of backdrop changes  b) Making sprites invisible  c) Drawing mazes
**Answer: a) Running a whole game by messages instead of backdrop changes** — Messages as the game's whole control system.
