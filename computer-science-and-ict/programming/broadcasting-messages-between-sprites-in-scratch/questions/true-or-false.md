# Broadcasting Messages Between Sprites in Scratch — true or false

Say whether each statement is true or false.

**1. One broadcast can wake scripts on several sprites at once.**
**Answer: True** — Any script receiving that name starts.

**2. Messages are weaker than backdrop switching in every way.**
**Answer: False** — They are looser and more powerful — and easier to tangle; the book files them as advanced.

**3. Broadcast and when-I-receive are two halves of one system.**
**Answer: True** — One sends, the other answers.
