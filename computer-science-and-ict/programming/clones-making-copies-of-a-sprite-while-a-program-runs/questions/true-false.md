# Clones — Making Copies of a Sprite While a Program Runs — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a clone?" is: A copy a sprite makes of itself while the program runs**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What block makes a clone?" is: The original sprite’s**
**Answer: False** — “Create a copy of myself”

**3. (Sub lesson 1) True or false: the answer to "When is a clone made?" is: While the program runs, not in the editor**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Whose scripts make the copies?" is: The fruit seller**
**Answer: False** — The original sprite’s

**5. (Sub lesson 1) True or false: the answer to "Where do the copies go?" is: Where the program sends them**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is the lesson’s build?" is: By a loop of copying and placing**
**Answer: False** — The fruit seller

**7. (Sub lesson 2) True or false: the answer to "What do the clone blocks show in the build?" is: Rows of fruit**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How is the stall stocked?" is: The shop’s variables (the lesson beside this one)**
**Answer: False** — By a loop of copying and placing

**9. (Sub lesson 2) True or false: the answer to "How many fruit sprites start the stall?" is: One sprite, cloned**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What prices the cloned stall?" is: “Create a copy of myself”**
**Answer: False** — The shop’s variables (the lesson beside this one)
