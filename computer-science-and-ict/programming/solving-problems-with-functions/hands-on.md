# Hands-on — Solving Problems with Functions

The lesson with your hands and your feet, not only your eyes.

## Split a problem
Take the problem: read three marks, drop the lowest, average the other two, say pass or fail. Write the function plan (names, inputs, outputs), then write and hand-test each function.

## Hand-known tests
For one function from your plan, invent three test inputs whose outputs you can compute by hand — including one edge case — and show the function passes all three.
