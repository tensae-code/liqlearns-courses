# Solving Problems with Functions

## Do it first

You already know what a function is. This lesson is the craft the definitions were for: taking a whole problem apart into functions that solve it together.

## Sub lesson 1 — From word problem to function list

Start from the **problem text**: underline what is **given** (the future arguments) and what is **asked** (the future return values). Each natural sub-job — read the data, compute a part, check a condition, print the result — becomes **one function**. The plan is a list: function names with their inputs and outputs, before any body is written.

## Sub lesson 2 — Write, test, combine — and practise

Each function is written and **tested alone** with values whose answers are known by hand; only then are they **combined**, with main calling them in the planned order. The book follows this with a dedicated **exercises** set (§ Theme 2, exercises on functions): the drill is always the same round — plan the split, test the parts, assemble, and check the whole against a hand-worked example.

## Say it to your companion

Tell your companion, in your own words: Real problems are solved by splitting them: each sub-job becomes a function with clear inputs and one output, the main program calls the functions in order and combines their results — so a word problem is first planned as a list of functions, then each function is written and tested on its own. Then let your companion ask you one question about it — and answer from the lesson, not from memory of the book's exact words.

## Do It Yourself

1. Show it, don't just say it: What is given and what is asked. Do this with a real example of your own and write or say how you know it is right.
2. Show it, don't just say it: A return value. Do this with a real example of your own and write or say how you know it is right.
3. Show it, don't just say it: Alone, with values whose answers are known by hand. Do this with a real example of your own and write or say how you know it is right.
4. Show it, don't just say it: Calls the functions in the planned order. Do this with a real example of your own and write or say how you know it is right.
