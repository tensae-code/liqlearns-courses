# Solving Problems with Functions — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is underlined first in a word problem?**
a) What is given and what is asked  b) The functions' arguments  c) A return value  d) One natural sub-job
**Answer: a) What is given and what is asked**

**2. (Sub lesson 1) What do the givens become?**
a) A return value  b) The functions' arguments  c) One natural sub-job  d) The plan — names with inputs and outputs
**Answer: b) The functions' arguments**

**3. (Sub lesson 1) What does the asked-for result become?**
a) One natural sub-job  b) The plan — names with inputs and outputs  c) A return value  d) Alone, with values whose answers are known by hand
**Answer: c) A return value**

**4. (Sub lesson 1) How many jobs should one function take?**
a) The plan — names with inputs and outputs  b) Alone, with values whose answers are known by hand  c) Only after each passes its own test  d) One natural sub-job
**Answer: d) One natural sub-job**
