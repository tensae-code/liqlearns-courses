# Solving Problems with Functions — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is underlined first in a word problem?**
**Answer: What is given and what is asked**

**2. (Sub lesson 1) What do the givens become?**
**Answer: The functions' arguments**

**3. (Sub lesson 1) What does the asked-for result become?**
**Answer: A return value**

**4. (Sub lesson 1) How many jobs should one function take?**
**Answer: One natural sub-job**

**5. (Sub lesson 1) What is written before any function body?**
**Answer: The plan — names with inputs and outputs**

**6. (Sub lesson 2) How is each function first tested?**
**Answer: Alone, with values whose answers are known by hand**

**7. (Sub lesson 2) When are functions combined?**
**Answer: Only after each passes its own test**

**8. (Sub lesson 2) What does main do in the combined program?**
**Answer: Calls the functions in the planned order**

**9. (Sub lesson 2) Against what is the whole program finally checked?**
**Answer: A hand-worked example**

**10. (Sub lesson 2) What round do the book's exercises drill?**
**Answer: Plan the split, test the parts, assemble, check**
