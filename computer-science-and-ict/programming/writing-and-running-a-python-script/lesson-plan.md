# Lesson plan - Writing and running a Python script

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** Writing and running a Python script
**Place in the curriculum:** Unit 6 - Fundamentals of Programming (CURRICULUM.md).
**The one thing this lesson teaches:** code written in IDLE's text editor is a script saved with the .py extension; File - New File, write, save with .py, then Run - Run Module, and the output appears in the IDLE shell.
**This lesson's own level:** it stands on it stands on The Python shell - first lines with print(): the shell is where this lesson's script output lands. It needs nothing else.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on - an image, a GIF, a video, an audio. Every slot is written as **"a picture of ..." in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps - a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order - the list the learner sees from the start, locked ahead, each opening when the one before it is proved (the gate: README, "Units, Lessons and Sub Lessons (ruled 2026-11-08)"):

1. **New File - writing in the editor** - Choose New File from the File menu of the interpreter window; the editor window opens with no >>> prompt; write the code there.
2. **Saving the script as a .py file** - Save from the File menu with the .py extension; editor code so kept is a script in a script file.
3. **Run Module - the output appears in the shell** - Run with Run Module from the Run menu; the output appears back in the IDLE shell. The worked script - circle area, radius 3 - runs four statements with one command and only the last produces output.

Gate pool: all questions of the sub lesson - no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## What the learner can do when it ends
1. Open the editor with File - New File, and say how its window differs from the shell.
2. Write a script in the editor - with no >>> prompt.
3. Save the script with the .py extension.
4. Run it with Run - Run Module and find the output in the IDLE shell.
5. Run the circle script (radius 3) and give its one output: 28.26.
