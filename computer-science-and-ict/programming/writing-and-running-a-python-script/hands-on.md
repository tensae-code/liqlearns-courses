# Hands-on - Writing and running a Python script

The lesson with your hands, not only your eyes.

## Step cards

Four cards carry the steps - New File, Write, Save as .py, Run Module. Shuffle them; a partner must lay them in the book's order and say what each step does, including where the output appears.

## Paper run

Write the circle script on paper. A partner 'runs' it with one finger-sweep (the single command), working each statement in order on paper, and 'prints' only the last statement's value onto a second sheet labelled SHELL: 28.26.
