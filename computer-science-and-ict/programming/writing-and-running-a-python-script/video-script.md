# Video script - Writing and running a Python script

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.
The FULL video script for this lesson, as its placement names a video-script need.

---

The shell runs one line at a time.
A script runs everything at once. Watch.

Step one. In the shell window: File menu... New File.
A new window opens - the editor.
No >>> here. This is a document.

Step two. Write the code.
pi equals 3.14.
radius equals 3.
area equals pi times radius times radius.
print area.
Four lines. Nothing has run yet.

Step three. Save it. File menu... Save.
Give it the Python ending: .py
circle.py. Saved.

Step four. Run menu... Run Module.
ONE command - and look at the shell!
28.26
The output appears back in the IDLE shell.

Four statements ran. Only the last one printed.
That is a script: write it once, save it, run it whole.
