# Writing and running a Python script - true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** A script file holds code written in the text editor.
**Answer: True** - script, script file - the editor's pair of words.

**2. (Sub lesson 3)** Every statement in a script produces output when it runs.
**Answer: False** - only print() produces output; the rest store and compute silently.
