# Writing and running a Python script - multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The editor window is opened by choosing -
a) Run - Run Module  b) File - New File  c) File - Save  d) Run - New Window
**Answer: b) File - New File** - from the File menu of the interpreter window.

**2. (Sub lesson 1)** In the editor window -
a) a >>> prompt waits on every line  b) no >>> prompt appears  c) output appears in blue  d) you type one line at a time
**Answer: b) no >>> prompt appears** - the editor is a document, not a conversation.

**3. (Sub lesson 1)** Code written in the text editor is called -
a) a mnemonic  b) a script  c) a compiler  d) an expression
**Answer: b) a script** - kept in a script file.

**4. (Sub lesson 2)** A Python script is saved with the extension -
a) .txt  b) .doc  c) .py  d) .exe
**Answer: c) .py** - .py marks a Python file.

**5. (Sub lesson 2)** Before a script can be run, it must be -
a) printed  b) saved  c) translated by hand  d) typed in the shell
**Answer: b) saved** - save first, then run.

**6. (Sub lesson 3)** A script is run with -
a) File - New File  b) Run - Run Module  c) File - Save  d) the >>> prompt
**Answer: b) Run - Run Module** - one command runs the whole script.

**7. (Sub lesson 3)** When a script runs, its output appears -
a) in the editor window  b) in a new file  c) back in the IDLE shell  d) on the printer
**Answer: c) back in the IDLE shell** - the shell is where results land.

**8. (Sub lesson 3)** The circle script (radius 3) prints -
a) 3  b) 3.14  c) 28.26  d) four values, one per statement
**Answer: c) 28.26** - only the last statement - print(area) - produces output.
