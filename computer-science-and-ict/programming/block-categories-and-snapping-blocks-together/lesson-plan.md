**The one thing this lesson teaches:** Scratch blocks are sorted into categories by colour — each colour a family of jobs — and a script is built by snapping blocks together, each one under the one before it, starting every script with an Events block that says when it runs.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Block categories by colour** — The **block palette** sorts blocks into **categories by colour**: each **category** is a family — Motion blocks move the sprite, Looks blocks change how it appears and speaks, Sound blocks play sounds, Events blocks start scripts. To find a block, first name its job, then go to its colour.
2. **Snapping blocks — and the Events block first** — Blocks **snap together**: drag a block **under the one before it** and it clicks into the stack, so the script reads and runs from the **top to the bottom**. **Every script starts with an Events block** — such as when the green flag is clicked — because a stack with no event at its head never knows when to run.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
