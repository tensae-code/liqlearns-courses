# Block Categories and Snapping Blocks Together — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "How are blocks sorted in the palette?" is: Into categories by colour**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is a category?" is: Move the sprite**
**Answer: False** — A family of blocks with one kind of job

**3. (Sub lesson 1) True or false: the answer to "What do Motion blocks do?" is: Move the sprite**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What do Looks blocks do?" is: Play sounds**
**Answer: False** — Change how the sprite appears and speaks

**5. (Sub lesson 1) True or false: the answer to "What do Sound blocks do?" is: Play sounds**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How do you find a block?" is: Snapped together — each under the one before it**
**Answer: False** — Name its job first, then go to its colour

**7. (Sub lesson 2) True or false: the answer to "How are blocks joined?" is: Snapped together — each under the one before it**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "In what order does a script run?" is: An Events block**
**Answer: False** — From the top to the bottom

**9. (Sub lesson 2) True or false: the answer to "What starts every script?" is: An Events block**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What happens to a stack with no Events block at its head?" is: Into categories by colour**
**Answer: False** — It never knows when to run
