# Block Categories and Snapping Blocks Together

## Do it first

A pile of blocks is not a program. In this lesson the pile gets its order: colours, snapping, and the block that starts it all. (teacher guide — evidence; PARTIAL — Term 1 only)

## Sub lesson 1 — Block categories by colour

The **block palette** sorts blocks into **categories by colour**: each **category** is a family — Motion blocks move the sprite, Looks blocks change how it appears and speaks, Sound blocks play sounds, Events blocks start scripts. To find a block, first name its job, then go to its colour.

[Picture — block categories by colour]

## Sub lesson 2 — Snapping blocks — and the Events block first

Blocks **snap together**: drag a block **under the one before it** and it clicks into the stack, so the script reads and runs from the **top to the bottom**. **Every script starts with an Events block** — such as when the green flag is clicked — because a stack with no event at its head never knows when to run.
