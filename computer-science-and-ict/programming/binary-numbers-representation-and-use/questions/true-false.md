# Binary Numbers — Representation and Use — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Which digits does binary use?" is: 0 and 1 only**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is one binary digit called?" is: 8 bits**
**Answer: False** — A bit

**3. (Sub lesson 1) True or false: the answer to "What are the first place values from the right?" is: 1, 2, 4, 8, 16, 32**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is 1011 in decimal?" is: Letters, pictures and sound**
**Answer: False** — 11 — 8 + 2 + 1

**5. (Sub lesson 1) True or false: the answer to "How many bits make a byte?" is: 8 bits**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Why do computers use binary?" is: By grouping bits, for example in hexadecimal**
**Answer: False** — Their circuits have two states — on or off

**7. (Sub lesson 2) True or false: the answer to "What else is stored as bit patterns besides numbers?" is: Letters, pictures and sound**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is binary's drawback when written out?" is: 0 and 1 only**
**Answer: False** — The numbers get long

**9. (Sub lesson 2) True or false: the answer to "How do programmers make machine values easier to read?" is: By grouping bits, for example in hexadecimal**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What does a 1 in a place mean?" is: 1, 2, 4, 8, 16, 32**
**Answer: False** — That place's value is counted in the total
