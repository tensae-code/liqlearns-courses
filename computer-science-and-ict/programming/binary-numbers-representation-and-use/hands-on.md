# Hands-on — Binary Numbers — Representation and Use

The lesson with your hands and your feet, not only your eyes.

## Read five numbers
Write 110, 1010, 1111, 10000 and 10101. Under each, write its place values and its decimal total. Check one of them by building it back up from the decimal.

## Count like a machine
Count from 0 to 15 in binary on paper, one number per line. Mark where each new place is used for the first time.
