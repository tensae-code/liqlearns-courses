# From Algorithm to Program — Writing the Code

## Do it first

On paper: ‘Repeat: ask a guess; if too low, say higher; if too high, say lower — until the guess equals the secret.’ On screen: an empty script area. Before reading on, point at the sentence part that will become a loop. That pointing is the whole craft.

## Sub lesson 1 — Translation, not invention

The séance's movement has two named steps: first the **algorithm in natural language** (written in the video-game project's earlier work), then **the program** — and the second step is **translation**: every sentence of the algorithm must find its blocks, and no block may sneak in that the algorithm did not order. Translating faithfully is a discipline: when program and algorithm disagree, one of them is wrong, and the séance teaches pupils to say which — and repair that one.

[Picture — Translation, not invention]

## Sub lesson 2 — The dictionary between words and blocks

Translation runs on a small dictionary: ‘repeat until…’ becomes the repeat-until loop; ‘if… then… otherwise…’ becomes the if-else block; ‘remember the secret’ becomes a variable made once and set in secret; ‘ask’ and ‘say’ become the ask and say blocks. Fluency is the goal: an algorithm written well reads like a program waiting for its blocks, and a program read aloud should sound like its algorithm — the two texts are one thought in two tongues.
