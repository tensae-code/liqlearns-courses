## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Translation, not invention** — The séance's movement has two named steps: first the **algorithm in natural language** (written in the video-game project's earlier work), then **the program** — and the second step is **translation**: every sentence of the algorithm must find its blocks, and no block may sneak in that the algorithm did not order. Translating faithfully is a discipline: when program and algorithm disagree, one of them is wrong, and the séance teaches pupils to say which — and repair that one.
2. **The dictionary between words and blocks** — Translation runs on a small dictionary: ‘repeat until…’ becomes the repeat-until loop; ‘if… then… otherwise…’ becomes the if-else block; ‘remember the secret’ becomes a variable made once and set in secret; ‘ask’ and ‘say’ become the ask and say blocks. Fluency is the goal: an algorithm written well reads like a program waiting for its blocks, and a program read aloud should sound like its algorithm — the two texts are one thought in two tongues.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## The run of the lesson (in order)
1. **Do it first** — On paper: ‘Repeat: ask a guess; if too low, say higher; if too high, say lower — until the guess equals the secret.’ On screen: an empty script area. Before reading on, point at the sentence part that will become a loop. That pointing is the whole craft. (lesson/lesson.md).
2. **The explanation** — the lesson text in lesson/lesson.md, in its parts in order.
   - ADD IMAGE: a picture of translation, not invention as the lesson describes it — the student studies the picture and names what each part shows.
   - ADD GIF: a GIF of the dictionary between words and blocks in action — the student watches once, then says what changed and why.
   - ADD AUDIO: a voice reading the lesson's key names and definitions aloud, in the order the lesson gives them — the student listens once through, then reads the same lines aloud along with the voice. (Audio is a described slot in this build; no audio file is made.)
