# Hands-on — From Algorithm to Program — Writing the Code

The lesson with your hands and your feet, not only your eyes.

## Task one
**Translate the game** — Take the provided natural-language algorithm for the Number Mystery. Translate it into Scratch, keeping a margin note per block naming its source sentence. Any block without a sentence gets challenged.

## Task two
**Read it back** — Swap programs. Read your partner's program aloud as natural language, sentence per structure. Compare with their original algorithm: every drift is a translation fault — locate it together.
