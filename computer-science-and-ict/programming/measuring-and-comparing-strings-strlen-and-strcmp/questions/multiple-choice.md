# Measuring and Comparing Strings — strlen and strcmp — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does strlen return?**
a) The count of characters before the null  b) 6  c) 0  d) The first string comes first in dictionary order
**Answer: a**

**2. (Sub lesson 1) What does strlen("Bangla") return?**
a) 6  b) 0  c) The first string comes first in dictionary order  d) It compares addresses, not contents
**Answer: a**

**3. (Sub lesson 1) What does strcmp return for equal strings?**
a) 0  b) The first string comes first in dictionary order  c) It compares addresses, not contents  d) Appends one string onto another's end
**Answer: a**

**4. (Sub lesson 1) What does a negative strcmp result mean?**
a) The first string comes first in dictionary order  b) It compares addresses, not contents  c) Appends one string onto another's end  d) Room for the grown length plus the terminator
**Answer: a**

**5. (Sub lesson 1) Why does a == b lie for strings?**
a) It compares addresses, not contents  b) Appends one string onto another's end  c) Room for the grown length plus the terminator  d) The string, terminator included
**Answer: a**

**6. (Sub lesson 2) What does strcat do?**
a) Appends one string onto another's end  b) Room for the grown length plus the terminator  c) The string, terminator included  d) <string.h>
**Answer: a**

**7. (Sub lesson 2) What must the destination have before strcat?**
a) Room for the grown length plus the terminator  b) The string, terminator included  c) <string.h>  d) The caller's — never the function's

**8. (Sub lesson 2) What does strcpy copy?**
a) The string, terminator included  b) <string.h>  c) The caller's — never the function's  d) The count of characters before the null
**Answer: a**

**9. (Sub lesson 2) Which header holds the four functions?**
