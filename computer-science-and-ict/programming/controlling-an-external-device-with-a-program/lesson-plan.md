## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Connecting a device to the computer** — An **external device** is a device **outside the computer box, connected to it**. The program reaches it **through the connection — its port or interface**. The case study follows **one real connection from set-up to working**, and its first check, when the device does not respond, is always the connection.
2. **Writing the program that controls it** — The device does what **the program's instructions** tell it — switching a device such as a **motor-driven device** on and off, or moving it. The control is **tested in small steps** so faults are found where they happen, and after testing, the program — or the connection — is adjusted. Before running the case, the person in charge checks safety.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
