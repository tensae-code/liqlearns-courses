# Controlling an External Device with a Program — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is an external device?" is: A device outside the computer box, connected to it**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How does a program reach an external device?" is: The program's instructions**
**Answer: False** — Through the connection — its port or interface

**3. (Sub lesson 1) True or false: the answer to "What is the first check when a device does not respond?" is: The connection**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What tells an external device what to do?" is: The device's actions — on/off, or movement**
**Answer: False** — The program's instructions

**5. (Sub lesson 1) True or false: the answer to "What does the case study follow?" is: One real connection from set-up to working**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What can a control program switch or move?" is: The program, or the connection**
**Answer: False** — The device's actions — on/off, or movement

**7. (Sub lesson 2) True or false: the answer to "Why test a control program in small steps?" is: To find faults where they happen**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is adjusted after testing?" is: The person in charge of the case study**
**Answer: False** — The program, or the connection

**9. (Sub lesson 2) True or false: the answer to "Name a device that can be controlled this way." is: A motor-driven device**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Who checks safety before the case study runs?" is: Through the connection — its port or interface**
**Answer: False** — The person in charge of the case study
