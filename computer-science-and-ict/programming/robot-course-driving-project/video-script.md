# Video script — Robot Course Driving Project

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

The project drives the class's educational robot around a **test course (sa bàn)** — a marked ground with straights, turns, a line to follow and obstacles to avoid. The work starts **off the robot**: walk the course, list its **stages** in order, and for each stage name the movement or sense it demands and the commands that answer it. Only then is the program written, stage by stage — the project teaches what every later practical in the book assumes: a run is planned on paper before it is driven on the ground.
No first run survives the real course: wheels slip, light changes, distances drift. The project's method is the **refining loop** — run the course, **watch where the robot fails**, change **one thing** (a speed, a turn time, a sensor threshold), and run again. The final project run is judged whole: the robot completes the course **by its program alone**, and the group's report names what each tuning changed. The loop, not the lucky run, is the skill being certified.
