# Robot Course Driving Project — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The test course — marked ground with straights, turns, a line and obstacles**
**Answer: True**

**2. (Sub lesson 1) True or false: The test course — marked ground with straights, turns, a line and obstacles** — as the answer to: What is done before any programming?
**Answer: False — Walk the course and list its stages in order**

**3. (Sub lesson 1) True or false: The movement or sense it demands, and the commands that answer it**
**Answer: True**

**4. (Sub lesson 1) True or false: The movement or sense it demands, and the commands that answer it** — as the answer to: How is the program written?
**Answer: False — Stage by stage, from the plan**

**5. (Sub lesson 1) True or false: A run is planned on paper before it is driven on the ground**
**Answer: True**

**6. (Sub lesson 2) True or false: A run is planned on paper before it is driven on the ground** — as the answer to: Why does no first run survive?
**Answer: False — Wheels slip, light changes, distances drift — the real course differs from the plan**

**7. (Sub lesson 2) True or false: Run, watch where it fails, change one thing, run again**
**Answer: True**

**8. (Sub lesson 2) True or false: Run, watch where it fails, change one thing, run again** — as the answer to: Why change only one thing at a time?
**Answer: False — So the next run shows what that change did**

**9. (Sub lesson 2) True or false: The robot completes the course by its program alone**
**Answer: True**

**10. (Sub lesson 2) True or false: The robot completes the course by its program alone** — as the answer to: What does the group's report name?
**Answer: False — What each tuning change did**
