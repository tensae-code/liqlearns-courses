# Robot Course Driving Project — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is the sa bàn?**
**Answer: The test course — marked ground with straights, turns, a line and obstacles**

**2. (Sub lesson 1) What is done before any programming?**
**Answer: Walk the course and list its stages in order**

**3. (Sub lesson 1) What is named for each stage?**
**Answer: The movement or sense it demands, and the commands that answer it**

**4. (Sub lesson 1) How is the program written?**
**Answer: Stage by stage, from the plan**

**5. (Sub lesson 1) What does the project teach above the driving?**
**Answer: A run is planned on paper before it is driven on the ground**

**6. (Sub lesson 2) Why does no first run survive?**
**Answer: Wheels slip, light changes, distances drift — the real course differs from the plan**

**7. (Sub lesson 2) What is the refining loop?**
**Answer: Run, watch where it fails, change one thing, run again**

**8. (Sub lesson 2) Why change only one thing at a time?**
**Answer: So the next run shows what that change did**

**9. (Sub lesson 2) How is the final run judged?**
**Answer: The robot completes the course by its program alone**

**10. (Sub lesson 2) What does the group's report name?**
**Answer: What each tuning change did**
