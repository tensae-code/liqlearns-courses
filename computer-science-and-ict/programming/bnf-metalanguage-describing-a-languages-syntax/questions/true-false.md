# BNF Metalanguage — Describing a Language's Syntax — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A language used to describe another language**
**Answer: True**

**2. (Sub lesson 1) True or false: A language used to describe another language** — as the answer to: What does BNF stand for, and what does it describe?
**Answer: False — Backus–Naur Form — it describes a language's syntax**

**3. (Sub lesson 1) True or false: 'Is defined as' — it joins a construction's name to its definition**
**Answer: True**

**4. (Sub lesson 1) True or false: 'Is defined as' — it joins a construction's name to its definition** — as the answer to: What are nonterminals?
**Answer: False — Constructions in angle brackets that unfold further, like <identifier>**

**5. (Sub lesson 1) True or false: The language's own symbols, standing as themselves**
**Answer: True**

**6. (Sub lesson 2) True or false: The language's own symbols, standing as themselves** — as the answer to: What does | separate in a production?
**Answer: False — Alternatives — the choices for one construction**

**7. (Sub lesson 2) True or false: By unfolding — replacing nonterminals by alternatives until only terminals remain**
**Answer: True**

**8. (Sub lesson 2) True or false: By unfolding — replacing nonterminals by alternatives until only terminals remain** — as the answer to: What does the recursive <identifier> production allow?
**Answer: False — Names of any length — a finite grammar describing infinitely many texts**

**9. (Sub lesson 2) True or false: <digit> ::= 0 | 1 | … | 9**
**Answer: True**

**10. (Sub lesson 2) True or false: <digit> ::= 0 | 1 | … | 9** — as the answer to: What is a production?
**Answer: False — One definition — a name, ::=, and its definition**
