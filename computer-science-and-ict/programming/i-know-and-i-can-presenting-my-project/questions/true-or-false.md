# I Know and I Can — Presenting My Project — true or false

Say whether each statement is true or false.

**1. Present a finished project to an audience, running it so they can follow.**
**Answer: True** — This is one of the lesson's own outcomes.

**2. A presentation proves mastery even if the presenter cannot explain how any part of the project works.**
**Answer: False** — The lesson teaches the opposite of this.

**3. Explain how each part of the project works, naming the skills inside it.**
**Answer: True** — This is one of the lesson's own outcomes.
