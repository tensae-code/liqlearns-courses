# I Know and I Can — Presenting My Project — short answer

Answer in a sentence or two.

**1. Explain, in your own words: present a finished project to an audience, running it so they can follow.**
**Answer:** The learner's own explanation, true to the lesson: The year ends with "Знам и мога. Представям проект" — the mastery check as a presentation: run your project for an audience, explain how it works, and answer for every part of it.

**2. A classmate gets this lesson's work wrong. What is the most likely fault, and how is it fixed?**
**Answer:** A question exposes a part you cannot explain → that part is the last gap: go back into the project, read that part's blocks until you can explain them, then present again.
