# I Know and I Can — Presenting My Project — multiple choice

Pick the one right answer.

**1. The final mastery check takes the form of —**
a) a project presentation  b) a spelling test  c) a new topic lesson
**Answer: a) a project presentation**

**2. Presenting is a stricter proof than building because —**
a) audiences are loud  b) projects are long  c) a copied part cannot be explained
**Answer: c) a copied part cannot be explained**

**3. In the presentation you must name —**
a) next year's topics  b) the skills inside each part  c) only the project's title
**Answer: b) the skills inside each part**

**4. The presentation finishes by saying —**
a) what you would improve next  b) that nothing could improve  c) the lesson is cancelled
**Answer: a) what you would improve next**
