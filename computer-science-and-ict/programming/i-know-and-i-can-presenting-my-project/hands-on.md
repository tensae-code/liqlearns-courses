# Hands-on — I Know and I Can — Presenting My Project

The lesson with your hands, not only your eyes.

## Present and explain
Present your project in three moves: say the plan, run it slowly, name the skill inside each part. The audience must be able to retell how it works.

## Answer and improve
Take two audience questions. Afterwards, write one line: "Next I would improve ___" — and say why that improvement matters.
