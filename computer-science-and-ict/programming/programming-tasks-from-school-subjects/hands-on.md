# Hands-on — Programming Tasks from School Subjects

The lesson with your hands and your feet, not only your eyes.

## Translate a rule
Take one rule from physics or geography (a formula or a comparison). Write a PascalABC program that applies it to given data, and test it on two cases whose answers you know from the subject.

## Hunt in both subjects
Take a program (yours or a provided one) whose answer to a subject task is wrong. Decide, with evidence, whether the fault is in the translated rule or in the code — and fix only that part.
