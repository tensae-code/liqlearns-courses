# Project — a Journey Through Bulgaria — multiple choice

Pick the one right answer.

**1. The journey project is planned first as —**
a) a route: places in order, with what happens at each  b) a single backdrop  c) a sound list
**Answer: a) a route: places in order, with what happens at each**

**2. Places in the journey are carried by —**
a) variables only  b) the pen  c) backdrops
**Answer: c) backdrops**

**3. Decision points on the road use —**
a) the clear button  b) branching  c) printing
**Answer: b) branching**

**4. The project closes the Scratch year by aiming the skills at —**
a) the learner's own country  b) a typing test  c) the sound gallery only
**Answer: a) the learner's own country**
