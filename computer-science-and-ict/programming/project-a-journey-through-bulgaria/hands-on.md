# Hands-on — Project — a Journey Through Bulgaria

The lesson with your hands, not only your eyes.

## Plan the route
Draw the journey: start, three places, end — with one happening and one line of speech per place. Build the first place fully in Scratch.

## Build place by place
Add the second and third places with their backdrop changes and a branching decision on one road. Run the whole journey through for a partner-traveller.
