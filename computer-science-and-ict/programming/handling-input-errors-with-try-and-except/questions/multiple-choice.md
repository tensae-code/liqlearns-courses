# Handling Input Errors with Try and Except — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is validation?**
a) Checking input before the program trusts it  b) Something is there, it is the right kind, and it is in the allowed range  c) A clear message and another chance  d) It corrupts — the program continues on bad data as if it were good

**2. (Sub lesson 1) Name validation's three checks**
a) A clear message and another chance  b) Something is there, it is the right kind, and it is in the allowed range  c) It corrupts — the program continues on bad data as if it were good  d) Runs risky lines in a try block and jumps to the except block if one raises an error, instead of crashing
