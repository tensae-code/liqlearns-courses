## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Start on Bump — a script woken by a meeting** — **Start on Bump** is a trigger block: the script under it **sleeps until this sprite bumps into another sprite**, then runs. It is ScratchJr's way of making characters react to each other — the cat reaches the mouse and only then speaks; the car reaches the sign and only then turns. The programmer's question changes: not 'what runs first?' but 'what meeting wakes this script?'
2. **The Stop block — ending on purpose** — The **Stop block** ends a sprite's running script at the point where it stands. Paired with Start on Bump it closes the interaction's shape: a meeting starts the reaction, the reaction plays, and Stop ends it cleanly instead of letting it wander. A program that can start on a meeting and stop on purpose is a program whose meetings mean something.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
