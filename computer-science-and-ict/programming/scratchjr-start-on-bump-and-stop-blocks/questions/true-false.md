Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A trigger that starts a script when this sprite bumps into another sprite**
**Answer: True**

**2. (Sub lesson 1) True or false: The cat reaches the mouse and only then speaks (any sensible example)** — as the answer to: What does the script do before the bump?
**Answer: False — It sleeps — it does not run**

**3. (Sub lesson 1) True or false: The cat reaches the mouse and only then speaks (any sensible example)**

**5. (Sub lesson 1) True or false: So characters react to each other, not only to the green flag**

**6. (Sub lesson 2) True or false: A meeting starts the reaction, the reaction plays, and Stop ends it cleanly** — as the answer to: What does the Stop block do?
