# ScratchJr — Start on Bump and the Stop Block — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is Start on Bump?**
a) A trigger that starts a script when this sprite bumps into another sprite  b) It sleeps — it does not run  c) The cat reaches the mouse and only then speaks (any sensible example)  d) 'What meeting wakes this script?'
**Answer: a**

**2. (Sub lesson 1) What does the script do before the bump?**
a) The cat reaches the mouse and only then speaks (any sensible example)  b) It sleeps — it does not run  c) 'What meeting wakes this script?'  d) So characters react to each other, not only to the green flag
**Answer: b**

**3. (Sub lesson 1) Give an example of a bump reaction.**
a) 'What meeting wakes this script?'  b) So characters react to each other, not only to the green flag  c) The cat reaches the mouse and only then speaks (any sensible example)  d) Ends a sprite's running script at the point where it stands
**Answer: c**

**4. (Sub lesson 1) What question replaces 'what runs first?'**
a) So characters react to each other, not only to the green flag  b) Ends a sprite's running script at the point where it stands  c) A meeting starts the reaction, the reaction plays, and Stop ends it cleanly  d) 'What meeting wakes this script?'
**Answer: d**
