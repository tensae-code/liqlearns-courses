# ScratchJr — Start on Bump and the Stop Block — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is Start on Bump?**
**Answer: A trigger that starts a script when this sprite bumps into another sprite**

**2. (Sub lesson 1) What does the script do before the bump?**
**Answer: It sleeps — it does not run**

**3. (Sub lesson 1) Give an example of a bump reaction.**
**Answer: The cat reaches the mouse and only then speaks (any sensible example)**

**4. (Sub lesson 1) What question replaces 'what runs first?'**
**Answer: 'What meeting wakes this script?'**

**5. (Sub lesson 1) Why pair triggers with reactions?**
**Answer: So characters react to each other, not only to the green flag**

**6. (Sub lesson 2) What does the Stop block do?**
**Answer: Ends a sprite's running script at the point where it stands**

**7. (Sub lesson 2) What shape do Bump and Stop make together?**
**Answer: A meeting starts the reaction, the reaction plays, and Stop ends it cleanly**

**8. (Sub lesson 2) What happens without a stop?**
**Answer: The reaction wanders instead of ending on purpose**

**9. (Sub lesson 2) Name the two new blocks of this lesson.**
**Answer: Start on Bump and Stop**

**10. (Sub lesson 2) Which book teaches this?**
**Answer: Kuwait Grade 4 Digital Explorer Term 1, Unit 2 Lesson 2**
