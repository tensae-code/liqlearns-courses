# The N-Queens Problem — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Any two queens sharing a row, a column, or a diagonal**
**Answer: True**

**2. (Sub lesson 1) True or false: Any two queens sharing a row, a column, or a diagonal** — as the answer to: Which small boards have no solution?
**Answer: False — N = 2 and N = 3**

**3. (Sub lesson 1) True or false: 92**
**Answer: True**

**4. (Sub lesson 1) True or false: 92** — as the answer to: Why does the book close the strand with this problem?
**Answer: False — Every part of backtracking is visible in it — choices, conditions, stepping back**

**5. (Sub lesson 1) True or false: Her row, her column, and both diagonals**
**Answer: True**

**6. (Sub lesson 2) True or false: Her row, her column, and both diagonals** — as the answer to: What decision simplifies the search?
**Answer: False — Place one queen per row, row by row — rows then can never clash**

**7. (Sub lesson 2) True or false: The column and both diagonals**
**Answer: True**

**8. (Sub lesson 2) True or false: The column and both diagonals** — as the answer to: What happens when a row has no safe column?
**Answer: False — Backtrack — move the previous row's queen to her next column and descend again**

**9. (Sub lesson 2) True or false: When a full board stands — every row holding a safe queen**
**Answer: True**

**10. (Sub lesson 2) True or false: When a full board stands — every row holding a safe queen** — as the answer to: When is 'no solution' proven?
**Answer: False — When row one's columns are exhausted**
