# Working with Files in Pascal — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What joins a file variable to a real file?" is: assign**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Which opens an existing file for reading?" is: rewrite**
**Answer: False** — reset

**3. (Sub lesson 1) True or false: the answer to "Which creates or empties a file for writing?" is: rewrite**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How do values move once a file is open?" is: Two names for one stream of data**
**Answer: False** — Value by value, with read and write on the file

**5. (Sub lesson 1) True or false: the answer to "What are the disk name and program name?" is: Two names for one stream of data**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What test ends a reading loop?" is: The file was written by earlier runs or other programs**
**Answer: False** — eof — the end-of-file test

**7. (Sub lesson 2) True or false: the answer to "Why can't a reading program know a file's length in advance?" is: The file was written by earlier runs or other programs**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does close do?" is: After graphics, before procedures and functions**
