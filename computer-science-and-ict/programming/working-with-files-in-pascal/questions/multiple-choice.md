# Working with Files in Pascal — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What joins a file variable to a real file?**
a) assign  b) reset  c) rewrite  d) Value by value, with read and write on the file
**Answer: a) assign**

**2. (Sub lesson 1) Which opens an existing file for reading?**
a) rewrite  b) reset  c) Value by value, with read and write on the file  d) Two names for one stream of data
**Answer: b) reset**

**3. (Sub lesson 1) Which creates or empties a file for writing?**
a) Value by value, with read and write on the file  b) Two names for one stream of data  c) rewrite  d) eof — the end-of-file test
**Answer: c) rewrite**

**4. (Sub lesson 1) How do values move once a file is open?**
a) Two names for one stream of data  b) eof — the end-of-file test  c) The file was written by earlier runs or other programs  d) Value by value, with read and write on the file
**Answer: d) Value by value, with read and write on the file**

**5. (Sub lesson 1) What are the disk name and program name?**
a) Two names for one stream of data  b) eof — the end-of-file test  c) The file was written by earlier runs or other programs  d) Writes the last values safely and frees the file
**Answer: a) Two names for one stream of data**

**6. (Sub lesson 2) What test ends a reading loop?**
a) The file was written by earlier runs or other programs  b) eof — the end-of-file test  c) Writes the last values safely and frees the file  d) After graphics, before procedures and functions
**Answer: b) eof — the end-of-file test**

**7. (Sub lesson 2) Why can't a reading program know a file's length in advance?**
a) Writes the last values safely and frees the file  b) After graphics, before procedures and functions  c) The file was written by earlier runs or other programs  d) Its data, kept in files
**Answer: c) The file was written by earlier runs or other programs**

**8. (Sub lesson 2) What does close do?**
a) After graphics, before procedures and functions  b) Its data, kept in files  c) assign  d) Writes the last values safely and frees the file
**Answer: d) Writes the last values safely and frees the file**

**9. (Sub lesson 2) Where does the files lesson sit in the book?**
a) After graphics, before procedures and functions  b) Its data, kept in files  c) assign  d) reset
**Answer: a) After graphics, before procedures and functions**

**10. (Sub lesson 2) What now outlives the program?**
a) assign  b) Its data, kept in files  c) reset  d) rewrite
**Answer: b) Its data, kept in files**
