# From User Requirements to Technical Specification — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) User requirements state what?**
a) What the users need the system to do  b) The users or client  c) Turning needs into technical language  d) An exact written statement of what will be built
**Answer: a) What the users need the system to do**

**2. (Sub lesson 1) User requirements come from whom?**
a) Turning needs into technical language  b) The users or client  c) An exact written statement of what will be built  d) The programmers and builders
**Answer: b) The users or client**

**3. (Sub lesson 1) Translating requirements means what?**
a) An exact written statement of what will be built  b) The programmers and builders  c) Turning needs into technical language  d) A measured limit — for example a set response time
**Answer: c) Turning needs into technical language**

**4. (Sub lesson 1) What is a technical specification?**
a) The programmers and builders  b) A measured limit — for example a set response time  c) So builders and users agree what is made  d) An exact written statement of what will be built
**Answer: d) An exact written statement of what will be built**

**5. (Sub lesson 1) Who builds from the specification?**
a) The programmers and builders  b) A measured limit — for example a set response time  c) So builders and users agree what is made  d) A system that does not fit its users
**Answer: a) The programmers and builders**

**6. (Sub lesson 2) A requirement like 'fast' becomes what in a specification?**
a) So builders and users agree what is made  b) A measured limit — for example a set response time  c) A system that does not fit its users  d) The user requirements
**Answer: b) A measured limit — for example a set response time**

**7. (Sub lesson 2) Why must a specification be exact?**
a) A system that does not fit its users  b) The user requirements  c) So builders and users agree what is made  d) Costs more — so translation is done first
**Answer: c) So builders and users agree what is made**

**8. (Sub lesson 2) Missing requirements cause what?**
a) The user requirements  b) Costs more — so translation is done first  c) What the users need the system to do  d) A system that does not fit its users
**Answer: d) A system that does not fit its users**

**9. (Sub lesson 2) The specification is checked against what?**
a) The user requirements  b) Costs more — so translation is done first  c) What the users need the system to do  d) The users or client
**Answer: a) The user requirements**

**10. (Sub lesson 2) Changing requirements after building does what?**
a) What the users need the system to do  b) Costs more — so translation is done first  c) The users or client  d) Turning needs into technical language
**Answer: b) Costs more — so translation is done first**
