# From User Requirements to Technical Specification — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) User requirements state what?**
**Answer: What the users need the system to do**

**2. (Sub lesson 1) User requirements come from whom?**
**Answer: The users or client**

**3. (Sub lesson 1) Translating requirements means what?**
**Answer: Turning needs into technical language**

**4. (Sub lesson 1) What is a technical specification?**
**Answer: An exact written statement of what will be built**

**5. (Sub lesson 1) Who builds from the specification?**
**Answer: The programmers and builders**

**6. (Sub lesson 2) A requirement like 'fast' becomes what in a specification?**
**Answer: A measured limit — for example a set response time**

**7. (Sub lesson 2) Why must a specification be exact?**
**Answer: So builders and users agree what is made**

**8. (Sub lesson 2) Missing requirements cause what?**
**Answer: A system that does not fit its users**

**9. (Sub lesson 2) The specification is checked against what?**
**Answer: The user requirements**

**10. (Sub lesson 2) Changing requirements after building does what?**
**Answer: Costs more — so translation is done first**
