# Hands-on — Working with Array Elements — Operations, Largest, Smallest, Counting

The lesson with your hands and your feet, not only your eyes.

## Three walks, one array
For the array {7, −2, 9, 4, 9, 0, −5, 3}, hand-trace: the total, the largest, and the count of negative elements. Write each walk's running answer after every element.

## Break the starter
Show with a hand trace what goes wrong if max starts at 0 for the array {−4, −9, −1}. Then give the correct largest and the correct starting rule.
