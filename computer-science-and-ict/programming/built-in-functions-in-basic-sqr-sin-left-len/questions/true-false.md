# Built-In Functions in BASIC — SQR, SIN, LEFT$ and LEN — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a built-in function?" is: A named piece of work the language itself performs — you give a value, it hands back a result**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Why are they called reserved?" is: A number's (an angle's) sine**
**Answer: False** — Their names belong to the language — they are the language's own words

**3. (Sub lesson 1) True or false: the answer to "What does SQR(81) return?" is: 9 — the square root of 81**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does SIN give?" is: 8 — the count of the string's characters**
**Answer: False** — A number's (an angle's) sine

**5. (Sub lesson 1) True or false: the answer to "Name three more mathematical built-ins the book's family holds." is: Cosine, tangent and absolute value (with whole part)**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does LEN("KHARTOUM") return?" is: A reserved name, a value in brackets, a single result out**
**Answer: False** — 8 — the count of the string's characters

**7. (Sub lesson 2) True or false: the answer to "What does LEFT$("KHARTOUM", 4) return?" is: "KHAR" — the first four characters**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What marks a built-in function in both families?" is: Functions the programmer defines for herself**
**Answer: False** — A reserved name, a value in brackets, a single result out

**9. (Sub lesson 2) True or false: the answer to "What is a string?" is: Text held in a string variable**
**Answer: True**
