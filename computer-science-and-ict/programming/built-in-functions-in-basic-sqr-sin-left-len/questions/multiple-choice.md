# Built-In Functions in BASIC — SQR, SIN, LEFT$ and LEN — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a built-in function?**
a) A named piece of work the language itself performs — you give a value, it hands back a result  b) Their names belong to the language — they are the language's own words  c) A number's (an angle's) sine  d) 8 — the count of the string's characters
**Answer: a) A named piece of work the language itself performs — you give a value, it hands back a result**

**2. (Sub lesson 1) Why are they called reserved?**
a) 9 — the square root of 81  b) Their names belong to the language — they are the language's own words  c) Cosine, tangent and absolute value (with whole part)  d) "KHAR" — the first four characters
**Answer: b) Their names belong to the language — they are the language's own words**

**3. (Sub lesson 1) What does SQR(81) return?**
a) A number's (an angle's) sine  b) 8 — the count of the string's characters  c) 9 — the square root of 81  d) A reserved name, a value in brackets, a single result out
**Answer: c) 9 — the square root of 81**

**4. (Sub lesson 1) What does SIN give?**
a) Cosine, tangent and absolute value (with whole part)  b) "KHAR" — the first four characters  c) Text held in a string variable  d) A number's (an angle's) sine
**Answer: d) A number's (an angle's) sine**

**5. (Sub lesson 1) Name three more mathematical built-ins the book's family holds.**
a) Cosine, tangent and absolute value (with whole part)  b) 8 — the count of the string's characters  c) A reserved name, a value in brackets, a single result out  d) Functions the programmer defines for herself
**Answer: a) Cosine, tangent and absolute value (with whole part)**

**6. (Sub lesson 2) What does LEN("KHARTOUM") return?**
a) "KHAR" — the first four characters  b) 8 — the count of the string's characters  c) Text held in a string variable  d) A named piece of work the language itself performs — you give a value, it hands back a result
**Answer: b) 8 — the count of the string's characters**

**7. (Sub lesson 2) What does LEFT$("KHARTOUM", 4) return?**
a) A reserved name, a value in brackets, a single result out  b) Functions the programmer defines for herself  c) "KHAR" — the first four characters  d) Their names belong to the language — they are the language's own words
**Answer: c) "KHAR" — the first four characters**

**8. (Sub lesson 2) What marks a built-in function in both families?**
a) Text held in a string variable  b) A named piece of work the language itself performs — you give a value, it hands back a result  c) 9 — the square root of 81  d) A reserved name, a value in brackets, a single result out
**Answer: d) A reserved name, a value in brackets, a single result out**

**9. (Sub lesson 2) What is a string?**
a) Text held in a string variable  b) Functions the programmer defines for herself  c) Their names belong to the language — they are the language's own words  d) A number's (an angle's) sine
**Answer: a) Text held in a string variable**
