## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Exponential growth — multiplying by the same factor** — A spread is **exponential** when each step **multiplies** the count by the same factor: 1, 2, 4, 8… when each holder passes it to **two** new people; the count after n steps is the starting count times the factor n times over. Its character is the lesson's shock: the growth looks sleepy for many steps and then stands enormous almost at once — the second half of the chessboard — because **the new spreaders are made by the spreading itself**.
2. **Modelling it — a program that watches the spread** — A **model** of the spread is a program holding the model's levers — **start count, factor per step, steps** — and **computing the table** the hand cannot extend: thirty steps, fifty steps, the step where the count passes the school, the city, the country. Changing a lever and re-running is the modelling craft: what if each tells **three**? what if only **half** pass it on? The lesson's point is civic as much as mathematical — exponential spread is how messages and infections truly move, and the person who has run the model is not surprised by the curve.
