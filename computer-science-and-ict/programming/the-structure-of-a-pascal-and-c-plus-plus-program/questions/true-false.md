# The Structure of a Pascal and C++ Program — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The heading — program Name;**
**Answer: True**

**2. (Sub lesson 1) True or false: The heading — program Name;** — as the answer to: What sections form the declaration part?
**Answer: False — label, const, type and var — then the subprogram declarations**

**3. (Sub lesson 1) True or false: The instructions between begin and the final end.**
**Answer: True**

**4. (Sub lesson 1) True or false: The instructions between begin and the final end.** — as the answer to: May parts appear out of order?
**Answer: False — No — declarations stand before use, always**

**5. (Sub lesson 1) True or false: A small program in itself — its own heading, declarations and body**
**Answer: True**

**6. (Sub lesson 2) True or false: A small program in itself — its own heading, declarations and body** — as the answer to: What comes first in a C++ program?
**Answer: False — Preprocessor directives — #include for the libraries**

**7. (Sub lesson 2) True or false: The function where execution begins — one function among the program's set**
**Answer: True**

**8. (Sub lesson 2) True or false: The function where execution begins — one function among the program's set** — as the answer to: How do the two anatomies differ in image?
**Answer: False — Pascal is one document in fixed order; C++ is a workshop of named tools with main as the door**

**9. (Sub lesson 2) True or false: Everything used is declared, and execution starts at a known place**
**Answer: True**

**10. (Sub lesson 2) True or false: Everything used is declared, and execution starts at a known place** — as the answer to: Does C++ have a var section?
**Answer: False — No — declarations stand with their functions and blocks**
