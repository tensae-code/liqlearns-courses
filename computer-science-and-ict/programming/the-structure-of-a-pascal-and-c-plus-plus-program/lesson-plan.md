## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Pascal's anatomy — front matter, then the body** — A Pascal program stands in fixed order: the **heading** (`program Name;`), then the **declaration part** — label, const, type, var sections, and the **subprogram declarations** (procedures and functions, each a small program in shape) — then the **main body** between begin and end. Nothing may appear out of its place: the compiler reads the program as it is built, declarations before use, always. The structure is the discipline made visible — the program as a document with a constitution and then its acts.
2. **C++'s anatomy — includes, functions, main** — A C++ program is a **set of functions** with no fixed gathering: **preprocessor directives** (#include for the libraries) come first; **global declarations** and **function definitions** follow in any order the compiler can resolve; and **main** is the function where execution begins — one function among the set, marked by its name. Where Pascal is one document in fixed order, C++ is a **workshop of named tools** with main as the door. Both anatomies serve the same law: **everything used is declared, and execution starts at a known place**.
