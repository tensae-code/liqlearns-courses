# Adding and Drawing Your Own Scratch Sprite — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) The cat is the only sprite Scratch allows.**
**Answer: False** — The library holds many sprites, and you can draw more.

**2. (Sub lesson 2) The eraser tool adds colour to a costume.**
**Answer: False** — The eraser rubs parts away; fill adds colour.

**3. (Sub lesson 2) Text is one of the paint tools.**
**Answer: True** — Text writes letters on the picture.
