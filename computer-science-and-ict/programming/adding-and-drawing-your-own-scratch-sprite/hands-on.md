# Hands-on — Adding and Drawing Your Own Scratch Sprite

The lesson with your hands, not only your eyes.

## Library plus one edit

Add a library sprite, then open its costume and make one clear edit with a paint tool — a new colour, a hat, a name in text. Show a partner the before and after.

## Drawn from shapes

Draw a simple character using only circle, rectangle and line shapes, filled with colour. Name every tool you used.
