# Visual Basic Form Controls — Label, TextBox and Command Buttons

## Do it first

A Visual Basic program is met through its form, and a form is built from tools. Libya's Grade 12 Science book teaches the toolbox in full, in two chapters. This lesson is that toolbox, in the book's order.

## Sub lesson 1 — The standard tools — Label, TextBox, command buttons

The **standard tools** begin every form. The **Label** shows **text the user reads** — a title, a caption, an answer displayed. The **TextBox** is where the user **types** — the program's ear. The **command button** is **clicked to make something happen** — the program's trigger. Each tool placed on a form is **named** — given a name that says its job — because code will speak to the tools by name. The chapter ends its first build with **storing the project**: a designed form is work, and work is saved.

## Sub lesson 2 — Frames and choosing tools — check boxes and option buttons

The **Frame** **groups** controls that belong together, drawing a border and a caption around a family. Inside such groups live the choosing tools: **check boxes**, each ticked or not **independently** — several may be on together; and **option buttons**, which choose **exactly one** from their group — picking one releases the others. The frame is what makes an option-button group a group: buttons in one frame choose against each other, and against no others.

[Picture — Frames and choosing tools — check boxes and option buttons]

## Sub lesson 3 — Lists to pick from — list box and combo box

The **list box** shows a **list of items to pick from**, all visible, one (or more) chosen by clicking. The **combined box (combo box)** folds the list into a **drop-down** and lets the user **pick from the list or type their own value** — a list box with a TextBox's freedom, in a fraction of the space. Libya closes the toolbox here: show with Label, ask with TextBox, trigger with buttons, group with Frame, choose with checks and options, and offer with lists — a form for any conversation a program must hold.
