# Hands-on — Visual Basic Form Controls — Label, TextBox and Command Buttons

The lesson with your hands and your feet, not only your eyes.

## Task one
('Build the standard form', 'Design a form with a Label, a TextBox and a command button, name all three for their jobs, and store the project. Say what each name tells the code reader.')

## Task two
('Choose the chooser', 'For three questions — toppings (many), size (one only), city (a long list) — place a check box group in a Frame, an option group in a Frame, and a combo box. Defend each choice.')
