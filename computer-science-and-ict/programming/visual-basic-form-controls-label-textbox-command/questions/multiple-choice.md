# Visual Basic Form Controls — Label, TextBox and Command Buttons — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does a Label do?**
a) Shows text the user reads — a title, a caption, a displayed answer  b) It is where the user types — the program's ear  c) It is clicked to make something happen — the program's trigger  d) Because code speaks to the tools by name; the name says the tool's job

**2. (Sub lesson 1) What does a TextBox do?**

**3. (Sub lesson 1) What does a command button do?**
