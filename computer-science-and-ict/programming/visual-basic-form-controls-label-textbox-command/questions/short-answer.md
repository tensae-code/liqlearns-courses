# Visual Basic Form Controls — Label, TextBox and Command Buttons — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does a Label do?**
**Answer: Shows text the user reads — a title, a caption, a displayed answer**

**2. (Sub lesson 1) What does a TextBox do?**
**Answer: It is where the user types — the program's ear**

**3. (Sub lesson 1) What does a command button do?**
**Answer: It is clicked to make something happen — the program's trigger**

**4. (Sub lesson 1) Why is every tool named?**
**Answer: Because code speaks to the tools by name; the name says the tool's job**

**5. (Sub lesson 1) What does storing the project protect?**
**Answer: The designed form — a built form is work, and work is saved**

**6. (Sub lesson 2) What does a Frame do?**
**Answer: Groups controls that belong together, with a border and a caption**

**7. (Sub lesson 2) How do check boxes choose?**
**Answer: Each independently — several may be on together**

**8. (Sub lesson 2) How do option buttons choose?**
**Answer: Exactly one from their group — picking one releases the others**

**9. (Sub lesson 3) What does a list box show?**
**Answer: A list of items to pick from, all visible**

**10. (Sub lesson 3) How does a combo box differ from a list box?**
**Answer: It folds the list into a drop-down and lets the user pick from the list or type their own value**
