# Visual Basic Form Controls — Label, TextBox and Command Buttons — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does a Label do?" is: Shows text the user reads — a title, a caption, a displayed answer**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does a TextBox do?" is: It is clicked to make something happen — the program's trigger**
**Answer: False** — It is where the user types — the program's ear

**3. (Sub lesson 1) True or false: the answer to "What does a command button do?" is: It is clicked to make something happen — the program's trigger**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Why is every tool named?" is: The designed form — a built form is work, and work is saved**
**Answer: False** — Because code speaks to the tools by name; the name says the tool's job

**5. (Sub lesson 1) True or false: the answer to "What does storing the project protect?" is: The designed form — a built form is work, and work is saved**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does a Frame do?" is: Each independently — several may be on together**
**Answer: False** — Groups controls that belong together, with a border and a caption

**7. (Sub lesson 2) True or false: the answer to "How do check boxes choose?" is: Each independently — several may be on together**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How do option buttons choose?" is: A list of items to pick from, all visible**
**Answer: False** — Exactly one from their group — picking one releases the others

**9. (Sub lesson 3) True or false: the answer to "What does a list box show?" is: A list of items to pick from, all visible**
**Answer: True**

**10. (Sub lesson 3) True or false: the answer to "How does a combo box differ from a list box?" is: Shows text the user reads — a title, a caption, a displayed answer**
**Answer: False** — It folds the list into a drop-down and lets the user pick from the list or type their own value
