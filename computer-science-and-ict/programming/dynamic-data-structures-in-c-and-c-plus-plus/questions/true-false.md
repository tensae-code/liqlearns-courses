# Dynamic Data Structures in C and C++ — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The address of a fresh cell**
**Answer: True**

**2. (Sub lesson 1) True or false: The address of a fresh cell** — as the answer to: How is the pointed value written?
**Answer: False — *p — the dereferenced pointer**

**3. (Sub lesson 1) True or false: Born with new int[n] — n decided at run time; freed with delete[]**
**Answer: True**

**4. (Sub lesson 1) True or false: Born with new int[n] — n decided at run time; freed with delete[]** — as the answer to: What is every new, in the lesson's phrase?
**Answer: False — A loan — the system's memory, held until delete**

**5. (Sub lesson 1) True or false: With * on the type or name — int* p;**
**Answer: True**

**6. (Sub lesson 2) True or false: With * on the type or name — int* p;** — as the answer to: Name the three classic wounds.
**Answer: False — Memory leaks, dangling pointers, and wild (unset) pointers**

**7. (Sub lesson 2) True or false: Stepping a pointer by cells — p + 1 names the next cell**
**Answer: True**

**8. (Sub lesson 2) True or false: Stepping a pointer by cells — p + 1 names the next cell** — as the answer to: Which language fences pointers more?
**Answer: False — Pascal — typed pointers and no pointer arithmetic**

**9. (Sub lesson 2) True or false: Every new pairs with a delete; every pointer is nil-or-valid; a freed pointer is set to nullptr at once**
**Answer: True**

**10. (Sub lesson 2) True or false: Every new pairs with a delete; every pointer is nil-or-valid; a freed pointer is set to nullptr at once** — as the answer to: What does a dangling pointer point at?
**Answer: False — Freed memory — possibly already reused for other data**
