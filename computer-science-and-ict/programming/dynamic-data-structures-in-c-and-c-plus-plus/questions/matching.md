**1. (Sub lesson 1) What does new return?** → **The address of a fresh cell**

**2. (Sub lesson 1) How is the pointed value written?** → ***p — the dereferenced pointer**

**3. (Sub lesson 1) How is a dynamic array born and freed?** → **Born with new int[n] — n decided at run time; freed with delete[]**

**4. (Sub lesson 1) What is every new, in the lesson's phrase?** → **A loan — the system's memory, held until delete**

**5. (Sub lesson 1) How is a pointer declared in C++?** → **With * on the type or name — int* p;**

**6. (Sub lesson 2) Name the three classic wounds.** → **Memory leaks, dangling pointers, and wild (unset) pointers**

**7. (Sub lesson 2) What is pointer arithmetic?** → **Stepping a pointer by cells — p + 1 names the next cell**

**8. (Sub lesson 2) Which language fences pointers more?** → **Pascal — typed pointers and no pointer arithmetic**

**9. (Sub lesson 2) State the elective's closing rule.** → **Every new pairs with a delete; every pointer is nil-or-valid; a freed pointer is set to nullptr at once**

**10. (Sub lesson 2) What does a dangling pointer point at?** → **Freed memory — possibly already reused for other data**
