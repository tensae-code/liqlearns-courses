# Python Functions — Defining, Calling and Returning — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a function?**
**Answer: A named block of code that does one job**

**2. (Sub lesson 1) Which keyword defines one in Python?**
**Answer: def**

**3. (Sub lesson 1) What do parameters name?**
**Answer: The values the job needs, carried in when called**

**4. (Sub lesson 1) Does defining a function run it?**
**Answer: No — defining teaches the job; calling makes it happen**

**5. (Sub lesson 1) What are arguments?**
**Answer: The values given in a particular call**

**6. (Sub lesson 2) What does return do?**
**Answer: Hands the job's result back to the caller**

**7. (Sub lesson 2) Which carries values in, which out?**
**Answer: Parameters in; return out**

**8. (Sub lesson 2) Name the pattern's two fruits.**
**Answer: Write once, fix once (and a program that reads as a plan)**

**9. (Sub lesson 2) What structures precede functions in the course?**
**Answer: Lists, tuples and dictionaries**

**10. (Sub lesson 2) Which book teaches this?**
**Answer: Kuwait Grade 10 Information Technology Term 2 (Book L1), Unit 1 — Functions**
