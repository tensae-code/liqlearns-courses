# Lesson plan — Composing Music with Note Blocks in Scratch

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** Composing Music with Note Blocks in Scratch
**Place in the curriculum:** ICT expansion — Palestine (2026-11-14) — in the title Programming on the ICT course ladder (TITLES.md). Built new from Palestine's Grade 8 Programming student book, because no existing lesson in the course covers this thing as its own lesson.
**The one thing this lesson teaches:** Music is composed in Scratch with note blocks: set the instrument, play a note for a number of beats, rest for beats in silence — and loop the sequence to make a tune that repeats.
**This lesson's own level:** It stands on the earlier lessons of its title and on the book's own order — it follows the book's lessons in sequence, so its neighbours in the book are its natural companions. It stands alone for a learner landing on it directly.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Set instrument, play note, rest** — The composing blocks work in threes: **set instrument** chooses the voice, **play note for beats** sounds a chosen note for a chosen length, and **rest** holds silence for its beats. A melody is these blocks in order — notes and rests together make the rhythm.
2. **Looping a tune** — A short composed sequence becomes a tune when it is **looped**: the same notes return, the listener recognises the pattern, and small changes between repeats can grow the tune. Composing is programming with the ears — every block is heard the moment the program runs.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
