# Composing Music with Note Blocks in Scratch — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does set instrument choose?" is: The voice the notes play in**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does play note for beats sound?" is: Notes and rests together — the rhythm**
**Answer: False** — A chosen note for a chosen length

**3. (Sub lesson 1) True or false: the answer to "What does a rest hold?" is: Silence for its beats**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What makes a melody, beyond the notes?" is: Looping it**
**Answer: False** — Notes and rests together — the rhythm

**5. (Sub lesson 1) True or false: the answer to "What three blocks open the composing lesson?" is: Set instrument, play note, rest**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What turns a short sequence into a tune?" is: With small changes**
**Answer: False** — Looping it

**7. (Sub lesson 2) True or false: the answer to "What does the listener recognise when a tune loops?" is: The pattern**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How can a tune grow between repeats?" is: The moment the program runs**
**Answer: False** — With small changes

**9. (Sub lesson 2) True or false: the answer to "What is composing, in this lesson’s words?" is: Programming with the ears**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "When is every composing block heard?" is: A chosen note for a chosen length**
**Answer: False** — The moment the program runs
