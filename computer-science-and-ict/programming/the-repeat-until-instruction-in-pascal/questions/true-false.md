# The Repeat-Until Instruction in Pascal — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: repeat <instructions> until <condition>**
**Answer: True**

**2. (Sub lesson 1) True or false: repeat <instructions> until <condition>** — as the answer to: When is the condition tested?
**Answer: False — After the body runs**

**3. (Sub lesson 1) True or false: On true — it repeats while the condition is false**
**Answer: True**

**4. (Sub lesson 1) True or false: On true — it repeats while the condition is false** — as the answer to: Does repeat need begin…end for several instructions?
**Answer: False — No — repeat and until are themselves the brackets**

**5. (Sub lesson 1) True or false: Once, always**
**Answer: True**

**6. (Sub lesson 2) True or false: Once, always** — as the answer to: When may while run zero times?
**Answer: False — When its condition is false at the first test — it tests before the body**

**7. (Sub lesson 2) True or false: The negation — repeat until x = 0 matches while x <> 0 continued**
**Answer: True**

**8. (Sub lesson 2) True or false: The negation — repeat until x = 0 matches while x <> 0 continued** — as the answer to: What is repeat called in C++?
**Answer: False — do…while**

**9. (Sub lesson 2) True or false: Reading a value, showing a menu — the test needs the body's result**
**Answer: True**

**10. (Sub lesson 2) True or false: Reading a value, showing a menu — the test needs the body's result** — as the answer to: Which loop guards even the first entry?
**Answer: False — while — its test stands at the door**
