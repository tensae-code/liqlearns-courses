# The Repeat-Until Instruction in Pascal — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) Write the repeat instruction's shape.** → **repeat <instructions> until <condition>**

**2. (Sub lesson 1) When is the condition tested?** → **After the body runs**

**3. (Sub lesson 1) Does the loop end on true or on false?** → **On true — it repeats while the condition is false**

**4. (Sub lesson 1) Does repeat need begin…end for several instructions?** → **No — repeat and until are themselves the brackets**

**5. (Sub lesson 1) How many times does the body run at least?** → **Once, always**

**6. (Sub lesson 2) When may while run zero times?** → **When its condition is false at the first test — it tests before the body**

**7. (Sub lesson 2) What is repeat's ending condition against while's?** → **The negation — repeat until x = 0 matches while x <> 0 continued**

**8. (Sub lesson 2) What is repeat called in C++?** → **do…while**

**9. (Sub lesson 2) Give work that must run before testing.** → **Reading a value, showing a menu — the test needs the body's result**

**10. (Sub lesson 2) Which loop guards even the first entry?** → **while — its test stands at the door**
