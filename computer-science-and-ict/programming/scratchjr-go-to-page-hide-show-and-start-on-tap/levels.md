This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

Sub lesson 1 questions from the type files. Pass mark: Moves the story to another page (scene) of the project; One scene or room of the story; Make a sprite invisible, then visible again; No — present but invisible; A surprise, an entrance or a disappearance (any one).
