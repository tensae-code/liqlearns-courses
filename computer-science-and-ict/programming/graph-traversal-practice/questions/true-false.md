# Graph Traversal Practice — Depth and Breadth Together — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Both traversals — depth-first and breadth-first**
**Answer: True**

**2. (Sub lesson 1) True or false: Both traversals — depth-first and breadth-first** — as the answer to: How does the depth-first order look?
**Answer: False — A deep chain first — one path followed to its end**

**3. (Sub lesson 1) True or false: Ring by ring — the near vertices first**
**Answer: True**

**4. (Sub lesson 1) True or false: Ring by ring — the near vertices first** — as the answer to: What memory does each walk use?
**Answer: False — A stack for depth-first; a queue for breadth-first**

**5. (Sub lesson 1) True or false: Yes — same graph, same start, two complete and correct orders**
**Answer: True**

**6. (Sub lesson 2) True or false: Yes — same graph, same start, two complete and correct orders** — as the answer to: Which walk answers 'nearest' questions?
**Answer: False — Breadth-first — its rings are distances in edges**

**7. (Sub lesson 2) True or false: It explores in rings of increasing edge-count**
**Answer: True**

**8. (Sub lesson 2) True or false: It explores in rings of increasing edge-count** — as the answer to: Which walk answers connectedness and cycle questions?
**Answer: False — Depth-first**

**9. (Sub lesson 2) True or false: The vertices of one path — the stack**
**Answer: True**

**10. (Sub lesson 2) True or false: The vertices of one path — the stack** — as the answer to: When is the walk chosen?
**Answer: False — Before running it — by the question the problem asks**
