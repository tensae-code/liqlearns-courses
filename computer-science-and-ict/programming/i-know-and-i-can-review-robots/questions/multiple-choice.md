# I Know and I Can — Review: Robots — multiple choice

Pick the one right answer.

**1. A robot route is proved when —**
a) the robot arrives where the program said  b) the plan looks neat  c) the robot moves fast
**Answer: a) the robot arrives where the program said**

**2. A shape is proved when —**
a) it is large  b) it uses many steps  c) it closes
**Answer: c) it closes**

**3. No tick is given for —**
a) an arrived route  b) a plan the robot cannot drive  c) a cleared program
**Answer: b) a plan the robot cannot drive**

**4. A stride-counted route — planned in human steps — is —**
a) a named gap to practise  b) the right way  c) a Blue-Bot command
**Answer: a) a named gap to practise**
