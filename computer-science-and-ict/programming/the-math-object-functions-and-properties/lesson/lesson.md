# The Math Object — Functions and Properties

## Do it first

Small Basic keeps its mathematics in one toolbox: the Math object. Mongolia's Grade 11 book opens the toolbox fully — every function named, then two real jobs done with them. This lesson is the toolbox and the jobs.

## Sub lesson 1 — The functions — rounding, powers, roots and chance

The **Math object** supplies the functions expressions cannot write alone. **Abs** gives a number's absolute value. **Floor** rounds down and **Ceiling** rounds up to the whole number. **Power** raises to a power and **SquareRoot** takes the root; the **logarithm** functions run powers backwards. **Sin** and **Cos** carry trigonometry, and **GetRandomNumber** hands out chance within a limit the programmer sets. Beside the functions stand the **properties** — fixed values the object holds, above all **Pi**. A function is called with its argument and returns its result into the expression that called it.

## Sub lesson 2 — The jobs — a cosine graph and palindrome hunting

The book spends the toolbox on two worked jobs. First, **plotting a cosine graph**: loop over x, take Cos of each, and plot the points in the GraphicsWindow — a curve computed point by point, mathematics made visible. Second, **finding palindromes** — numbers that read the same both ways — by pulling digits apart with Floor and remainder arithmetic and rebuilding them reversed. Mongolia's choice of jobs is the point: the Math object is not a list to memorise but a kit to spend, and every function in it is bought back by a program that needed it.
