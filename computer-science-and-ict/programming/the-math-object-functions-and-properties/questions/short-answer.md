# The Math Object — Functions and Properties — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) Where does Small Basic keep its mathematics?**
**Answer: In the Math object**

**2. (Sub lesson 1) What does Floor do, and Ceiling?**
**Answer: Floor rounds down; Ceiling rounds up — to the whole number**

**3. (Sub lesson 1) What does Abs return?**
**Answer: A number's absolute value**

**4. (Sub lesson 1) Which functions run powers each way?**
**Answer: Power raises to a power; SquareRoot takes the root; logarithms run powers backwards**

**5. (Sub lesson 1) What does GetRandomNumber do?**
**Answer: Hands out a random number within a limit the programmer sets**

**6. (Sub lesson 2) Name the object's famous property.**
**Answer: Pi**

**7. (Sub lesson 2) How is the cosine graph plotted?**
**Answer: Loop over x, take Cos of each value, plot the points**

**8. (Sub lesson 2) What is a palindrome number?**
**Answer: A number that reads the same both ways**

**9. (Sub lesson 2) Which operations pull a number's digits apart?**
**Answer: Floor and remainder arithmetic**

**10. (Sub lesson 2) What is the Math object, in the lesson's closing phrase?**
**Answer: Not a list to memorise but a kit to spend**
