**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** The Math Object — Functions and Properties
**Place in the curriculum:** ICT expansion — Mongolia (2026-11-14) — in the title Programming on the ICT course ladder (TITLES.md). **The one thing this lesson teaches:** The Math object in Small Basic — its functions (Abs, Floor, Ceiling, Power, SquareRoot, logarithms, Sin and Cos, GetRandomNumber) and its property Pi, put to work plotting a cosine graph and hunting palindromes

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The functions — rounding, powers, roots and chance** — The **Math object** supplies the functions expressions cannot write alone. **Abs** gives a number's absolute value. **Floor** rounds down and **Ceiling** rounds up to the whole number. **Power** raises to a power and **SquareRoot** takes the root; the **logarithm** functions run powers backwards. **Sin** and **Cos** carry trigonometry, and **GetRandomNumber** hands out chance within a limit the programmer sets. Beside the functions stand the **properties** — fixed values the object holds, above all **Pi**. A function is called with its argument and returns its result into the expression that called it.
2. **The jobs — a cosine graph and palindrome hunting** — The book spends the toolbox on two worked jobs. First, **plotting a cosine graph**: loop over x, take Cos of each, and plot the points in the GraphicsWindow — a curve computed point by point, mathematics made visible. Second, **finding palindromes** — numbers that read the same both ways — by pulling digits apart with Floor and remainder arithmetic and rebuilding them reversed. Mongolia's choice of jobs is the point: the Math object is not a list to memorise but a kit to spend, and every function in it is bought back by a program that needed it.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
