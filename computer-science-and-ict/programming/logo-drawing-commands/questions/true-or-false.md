# LOGO drawing commands — fd, bk, rt, lt, cs — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** lt takes a number of steps as its argument.
**Answer: False** — lt takes an angle; fd and bk take steps.

**2. (Sub lesson 1)** bk 10 moves the turtle back 10 steps.
**Answer: True** — the book's example.

**3. (Sub lesson 2)** Drawing the predicted path on paper first is part of the guide's method.
**Answer: True** — predict, then run.
