# Hands-on — LOGO drawing commands — fd, bk, rt, lt, cs

The lesson with your hands, not only your eyes.

## Prediction league
In pairs: one writes a three-command sequence, the other draws its predicted path on paper. Run it in Logo. Score one point per correct segment. Swap roles each round — and always predict before you run.

## Home and clear
Draw anything messy with five commands. Then run cs. Watch the screen clear and the turtle return to the centre — home — ready for the next drawing.
