# Lesson plan — LOGO drawing commands — fd, bk, rt, lt, cs

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** LOGO drawing commands — fd, bk, rt, lt, cs
**Place in the curriculum:** Title 12 — Programming in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 7 book, Unit 6 — Logic Oriented Graphics Oriented (LOGO) Programming. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** the four basic commands move the turtle — fd and bk take a number of steps, rt and lt take an angle — home is the centre of the screen, and cs clears the drawings and returns the turtle home.
**This lesson's own level:** it is a doing-lesson — the first commanding lesson, standing on the Logo screen lesson's names.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The four commands** — forward, backward, right, left — fd, bk, rt, lt — steps for fd/bk, angles for rt/lt; home is the centre; the book's examples fd 10, rt 90, lt 90, bk 10; cs clears and homes
2. **Chaining commands — the guide's worked sequence (teacher guide — evidence)** — forward 20, left-turn 50, forward 20 — commands in sequence draw a bent path; draw the result on paper first

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: The MSW Logo screen — graphics window and Commander.  Recommended, never forced.

## What the learner can do when it ends
1. Give fd, bk, rt, lt with correct arguments: steps and angles.
2. Run the book's four examples.
3. Use cs to clear and return home.
4. Predict a chained path on paper, then run it and compare.

## What you need
A computer with MSW Logo open; paper and a pencil for predictions.

## If the learner is stuck
- Gives rt a number of steps → turns take angles (degrees), moves take steps; the argument's kind is part of the command.
- Forgets where the turtle starts → home: the centre of the screen, every time, and cs returns it there.
