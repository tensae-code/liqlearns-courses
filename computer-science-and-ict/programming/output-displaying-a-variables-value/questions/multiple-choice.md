# Output — Displaying a Variable's Value — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does cout send items to?**
a) The screen  b) The text exactly as written  c) Its current value  d) Quoting a variable's name, printing the word instead of the value
**Answer: a) The screen**

**2. (Sub lesson 1) What do quotes make cout print?**
a) Its current value  b) The text exactly as written  c) Quoting a variable's name, printing the word instead of the value  d) The << operator, chained in order
**Answer: b) The text exactly as written**

**3. (Sub lesson 1) What does cout print for a variable without quotes?**
a) Quoting a variable's name, printing the word instead of the value  b) The << operator, chained in order  c) Its current value  d) Ends the line — the next output starts a new line
**Answer: c) Its current value**

**4. (Sub lesson 1) What is the classic first output bug?**
a) The << operator, chained in order  b) Ends the line — the next output starts a new line  c) The '\n' character in the text  d) Quoting a variable's name, printing the word instead of the value
**Answer: d) Quoting a variable's name, printing the word instead of the value**

**5. (Sub lesson 1) What links items in one cout statement?**
a) The << operator, chained in order  b) Ends the line — the next output starts a new line  c) The '\n' character in the text  d) So results do not run together unreadably
**Answer: a) The << operator, chained in order**

**6. (Sub lesson 2) What does endl do?**
a) The '\n' character in the text  b) Ends the line — the next output starts a new line  c) So results do not run together unreadably  d) Disciplined layout — label, value, new line, repeated
**Answer: b) Ends the line — the next output starts a new line**

**7. (Sub lesson 2) What else makes a new line?**
a) So results do not run together unreadably  b) Disciplined layout — label, value, new line, repeated  c) The '\n' character in the text  d) Its own section, after assigning values and before expressions
**Answer: c) The '\n' character in the text**

**8. (Sub lesson 2) Why separate printed values?**
a) Disciplined layout — label, value, new line, repeated  b) Its own section, after assigning values and before expressions  c) The screen  d) So results do not run together unreadably
**Answer: d) So results do not run together unreadably**

**9. (Sub lesson 2) What is a result table in output terms?**
a) Disciplined layout — label, value, new line, repeated  b) Its own section, after assigning values and before expressions  c) The screen  d) The text exactly as written
**Answer: a) Disciplined layout — label, value, new line, repeated**

**10. (Sub lesson 2) Where does the book place output?**
a) The screen  b) Its own section, after assigning values and before expressions  c) The text exactly as written  d) Its current value
**Answer: b) Its own section, after assigning values and before expressions**
