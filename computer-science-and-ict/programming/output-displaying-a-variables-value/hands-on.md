# Hands-on — Output — Displaying a Variable's Value

The lesson with your hands and your feet, not only your eyes.

## Fix the print
A program with int score = 9; runs cout << "score";. Say what prints, why, and the two corrected versions — printing the label with the value, and printing the value alone.

## Lay out a receipt
Write the cout statements that print a three-line mini receipt: an item name and price per line, then a total line. Mark every endl and every quoted space.
