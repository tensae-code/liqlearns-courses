# Lesson plan — An Algorithm Is a Plan of Steps — Named for al-Khwarizmi

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** An Algorithm Is a Plan of Steps — Named for al-Khwarizmi
**Place in the curriculum:** ICT expansion — Palestine (2026-11-14) — in the title Programming on the ICT course ladder (TITLES.md). Built new from Palestine's Grade 5 Programming student book, because no existing lesson in the course covers this thing as its own lesson.
**The one thing this lesson teaches:** An algorithm is the plan of steps a program follows, written so the steps and their order are clear; the word comes from al-Khwarizmi, and a good algorithm uses the fewest steps that still reach the goal.
**This lesson's own level:** It stands on the earlier lessons of its title and on the book's own order — it follows the book's lessons in sequence, so its neighbours in the book are its natural companions. It stands alone for a learner landing on it directly.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The plan gets its name — extracting coal** — In **Extracting coal from the mine** the book defines it plainly: the **algorithm** is **the program’s plan of steps**, and the word is **named for al-Khwarizmi**, the scholar whose name gave the world the word. Every Minecraft puzzle solved so far was an algorithm first and blocks second.
2. **Writing the algorithm in words — crossing the lava** — In **Crossing the molten lava** the pupil writes the **algorithm in words beside each block**, so plan and program can be checked against each other line by line. Two rules hold the lesson together: **order matters** — steps out of order fail — and the best algorithm reaches the goal in the **fewest steps**.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
