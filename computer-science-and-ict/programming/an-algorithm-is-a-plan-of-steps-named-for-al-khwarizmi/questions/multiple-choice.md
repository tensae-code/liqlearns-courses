# An Algorithm Is a Plan of Steps — Named for al-Khwarizmi — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is an algorithm?**
a) The program’s plan of steps  b) Al-Khwarizmi  c) In words beside each block  d) They fail — order matters
**Answer: a) The program’s plan of steps**

**2. (Sub lesson 1) Who is the word “algorithm” named for?**
a) An algorithm first  b) Al-Khwarizmi  c) So plan and program can be checked against each other  d) Reaching the goal in the fewest steps
**Answer: b) Al-Khwarizmi**

**3. (Sub lesson 1) What was every solved puzzle, before it was blocks?**
a) In words beside each block  b) They fail — order matters  c) An algorithm first  d) The algorithm
**Answer: c) An algorithm first**

**4. (Sub lesson 1) In Crossing the molten lava, where is the algorithm written?**
a) So plan and program can be checked against each other  b) Reaching the goal in the fewest steps  c) Steps in a clear order  d) In words beside each block
**Answer: d) In words beside each block**

**5. (Sub lesson 1) Why write the plan beside the blocks?**
a) So plan and program can be checked against each other  b) They fail — order matters  c) The algorithm  d) Extracting coal from the mine
**Answer: a) So plan and program can be checked against each other**

**6. (Sub lesson 2) What happens to steps out of order?**
a) Reaching the goal in the fewest steps  b) They fail — order matters  c) Steps in a clear order  d) The program’s plan of steps
**Answer: b) They fail — order matters**

**7. (Sub lesson 2) What makes the best algorithm in the lava lesson?**
a) The algorithm  b) Extracting coal from the mine  c) Reaching the goal in the fewest steps  d) Al-Khwarizmi
**Answer: c) Reaching the goal in the fewest steps**

**8. (Sub lesson 2) What comes first, the algorithm or the blocks?**
a) Steps in a clear order  b) The program’s plan of steps  c) An algorithm first  d) The algorithm
**Answer: d) The algorithm**

**9. (Sub lesson 2) What kind of steps does an algorithm hold?**
a) Steps in a clear order  b) Extracting coal from the mine  c) Al-Khwarizmi  d) In words beside each block
**Answer: a) Steps in a clear order**

**10. (Sub lesson 2) Which lesson names the algorithm?**
a) The program’s plan of steps  b) Extracting coal from the mine  c) An algorithm first  d) So plan and program can be checked against each other
