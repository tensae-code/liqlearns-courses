# if…elif…else — a chain of choices — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** elif means —
a) end the program  b) if the previous conditions are not true, try this one  c) repeat the if
**Answer: b) b) if the previous conditions are not true, try this one**

**2. (Sub lesson 1)** In a chain, the block that runs is —
a) the last true one  b) every true one  c) the first true one
**Answer: c) c) the first true one**

**3. (Sub lesson 1)** If no condition in the chain is true, the block that runs is —
a) the if block  b) the else block  c) none
**Answer: b) b) the else block**

**4. (Sub lesson 2)** Mark 85 in the marks chain prints —
a) Excellent  b) Very Good  c) Good
**Answer: b) b) Very Good** — Verified.

**5. (Sub lesson 2)** Age 80 in the age chain prints —
a) adult  b) adolescent  c) senior adult
**Answer: c) c) senior adult** — It lands in else — verified.

**6. (Sub lesson 2)** A chain using type() on a price of 2.5 reports a —
a) floating number  b) string  c) integer
**Answer: a) a) floating number**
