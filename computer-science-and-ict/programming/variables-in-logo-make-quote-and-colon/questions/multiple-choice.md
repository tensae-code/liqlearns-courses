# Variables in LOGO — MAKE, "name and :value — multiple choice

Pick the one right answer.

**1.** A variable is —
a) a drawing  b) the name of a memory location that can contain a value  c) a primitive  d) a window
**Answer: b) the name of a memory location that can contain a value.**

**2.** Which command gives the variable size the value 10?
a) print :size 10  b) make "size 10  c) size = 10  d) make size :10
**Answer: b) make "size 10** — MAKE with the quoted name.

**3.** After make "size 60, what does print :size + 2 print?
a) 60  b) 62  c) size2  d) 120
**Answer: b) 62.**

**4.** The quote before a name tells LOGO —
a) to evaluate the word  b) not to evaluate it — take it as the name itself  c) to print it twice  d) to delete it
**Answer: b) not to evaluate it — take it as the name itself.**

**5.** Variable names can contain —
a) spaces only  b) letters, digits and underscore  c) no digits  d) only capital letters
**Answer: b) letters, digits and underscore.**

**6.** LOGO variables —
a) must be declared with a type first  b) have no types and need not be declared before use  c) hold only words  d) hold only numbers
**Answer: b) have no types and need not be declared before use.**
