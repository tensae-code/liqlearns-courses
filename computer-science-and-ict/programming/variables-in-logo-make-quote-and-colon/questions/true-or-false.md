# Variables in LOGO — MAKE, "name and :value — true or false

Say true or false for each one.

**1.** Plain "size, without the colon, is treated as text, not the value.
**Answer: True.**

**2.** After make "size 60, print :size/2 prints 30.
**Answer: True.**

**3.** A variable must be declared before it is used.
**Answer: False** — variables need not be declared before use.
