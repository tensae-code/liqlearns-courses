# Lesson plan — Variables in LOGO — MAKE, "name and :value

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** Variables in LOGO — MAKE, "name and :value
**Place in the curriculum:** Title 12 — Programming in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 8 book, Unit 6 — Logic Oriented Graphics Oriented (LOGO) Programming. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** a LOGO variable is a named memory location holding a value: MAKE with a quoted name puts a value in, and a colon in front of the name reads the value out.
**This lesson's own level:** it stands on the primitives lesson — PRINT and the arithmetic primitives are known; variables let the turtle remember numbers and words.

## What the learner can do when it ends
1. Define a variable and say what names are allowed (letters, digits, underscore; no types, no declaring first).
2. Give a variable a value with MAKE and the quoted name — make "size 10.
3. Read a value back with the colon — :size — and say what plain "size without the colon means.
4. Work the book's examples: print :size/2, :size + 2, :size − 2 after make "size 60, and the word variable that prints Hello.

## What you need
A computer with MSW LOGO open; paper and a pencil.

## If the learner is stuck
- Writes print size and gets the word, not the value → the colon is the reading tool: no colon, no value. Check for the colon first.
- Tries to declare a type first → LOGO variables have no types and need not be declared before use; MAKE is enough.
