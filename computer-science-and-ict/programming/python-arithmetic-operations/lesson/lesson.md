# Python Arithmetic Operations

## Do it first

Your Python program can hold values in variables — now make it work for its living. The four operations of school arithmetic exist in Python with almost the same faces, and one famous difference hiding in the division sign. Two Bangladeshi grades teach this session; this lesson is their shared craft.

## Sub lesson 1 — The four operations — + − * /

Python writes arithmetic with the signs of the keyboard: **+** adds, **−** subtracts, **\*** multiplies (the × of mathematics is a letter on the keyboard, so the star serves), and **/** divides. Expressions follow mathematics' order — brackets first, then × and ÷, then + and − — and can mix literals and variables freely: `total = price * quantity + delivery`. In the Thonny editor of the Grade 9 book, each expression can be tried in the shell the moment it is written, which is how this session is learned: type, predict, run, compare.

## Sub lesson 2 — Division's two answers — and the types that follow

Division in Python returns a **decimal (float)** even when it divides evenly — 10 / 2 is 5.0 — while +, − and * on whole numbers stay **whole (int)** until a decimal joins them. The type of the result follows the types of the ingredients, and the programmer who forgets it meets money printed as 5.0 and ages as 12.0000001's cousins in rounding. The sessions practise the four operations on real errands — totals, change, averages — because arithmetic in a program is never for its own sake: it is the school's mathematics, hired.
