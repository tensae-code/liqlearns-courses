# Separators in Pascal and C++ — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What do separators do?** → **They divide program text into its units — words, lists, groups, instructions**

**2. (Sub lesson 1) What separates words?** → **Blanks and line breaks**

**3. (Sub lesson 1) What is the semicolon's job in Pascal?** → **It separates instructions from each other**

**4. (Sub lesson 1) What is the semicolon's job in C++?** → **It terminates — ends — each instruction**

**5. (Sub lesson 1) Does indentation change a program?** → **No — whitespace beyond separation is free; it is written for people**

**6. (Sub lesson 2) Why does Pascal's last instruction before end need no semicolon?** → **Because the semicolon separates instructions — there is nothing after it to separate from**

**7. (Sub lesson 2) What is a missing semicolon in C++?** → **An immediate error — the instruction is unterminated**

**8. (Sub lesson 2) What is an extra semicolon in C++?** → **An empty statement — with the same traps as Pascal's empty instruction**

**9. (Sub lesson 2) State the emblematic difference in one line.** → **Pascal's semicolon separates; C++'s terminates**

**10. (Sub lesson 2) What does the chapter conclude from separators?** → **That syntax is real — the same text, cut differently, means differently**
