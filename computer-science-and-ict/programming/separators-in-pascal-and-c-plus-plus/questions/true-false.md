# Separators in Pascal and C++ — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: They divide program text into its units — words, lists, groups, instructions**
**Answer: True**

**2. (Sub lesson 1) True or false: They divide program text into its units — words, lists, groups, instructions** — as the answer to: What separates words?
**Answer: False — Blanks and line breaks**

**3. (Sub lesson 1) True or false: It separates instructions from each other**
**Answer: True**

**4. (Sub lesson 1) True or false: It separates instructions from each other** — as the answer to: What is the semicolon's job in C++?
**Answer: False — It terminates — ends — each instruction**

**5. (Sub lesson 1) True or false: No — whitespace beyond separation is free; it is written for people**
**Answer: True**

**6. (Sub lesson 2) True or false: No — whitespace beyond separation is free; it is written for people** — as the answer to: Why does Pascal's last instruction before end need no semicolon?
**Answer: False — Because the semicolon separates instructions — there is nothing after it to separate from**

**7. (Sub lesson 2) True or false: An immediate error — the instruction is unterminated**
**Answer: True**

**8. (Sub lesson 2) True or false: An immediate error — the instruction is unterminated** — as the answer to: What is an extra semicolon in C++?
**Answer: False — An empty statement — with the same traps as Pascal's empty instruction**

**9. (Sub lesson 2) True or false: Pascal's semicolon separates; C++'s terminates**
**Answer: True**

**10. (Sub lesson 2) True or false: Pascal's semicolon separates; C++'s terminates** — as the answer to: What does the chapter conclude from separators?
**Answer: False — That syntax is real — the same text, cut differently, means differently**
