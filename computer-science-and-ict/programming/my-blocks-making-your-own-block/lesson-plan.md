**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** My Blocks — Making Your Own Block

**The one thing this lesson teaches:** When the same stack of blocks is needed again and again, you make it once as a My Block: name the new block, define its code inside it — the zigzag stairs pattern, a flower petal — and then use your own block anywhere, like a block the program came with.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Creating a My Block** — A **My Block** is **your own block**, made from a stack you find yourself repeating. **Create** it by naming it for what it does, and the program gives you a definition stack to fill. Everywhere the pattern is needed, you now drop in your one block instead of rebuilding the stack — shorter programs, and a fix made inside the definition fixes every use.
2. **Defining its code — stairs and a petal** — **Defining** the block means writing the code it stands for: for the **zigzag "stairs"**, the repeated up-and-across pattern goes inside the definition once, however many stairs the program climbs. The guide then defines a block that draws a **flower petal** — one petal in the definition becomes a whole flower when the block is used turn after turn.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
