# My Blocks — Making Your Own Block

## Do it first

You have built the same zigzag three times already. In this lesson you build it once — and keep it forever as your own block. (teacher guide — evidence)

## Sub lesson 1 — Creating a My Block

A **My Block** is **your own block**, made from a stack you find yourself repeating. **Create** it by naming it for what it does, and the program gives you a definition stack to fill. Everywhere the pattern is needed, you now drop in your one block instead of rebuilding the stack — shorter programs, and a fix made inside the definition fixes every use.

[Picture — creating a my block]

## Sub lesson 2 — Defining its code — stairs and a petal

**Defining** the block means writing the code it stands for: for the **zigzag "stairs"**, the repeated up-and-across pattern goes inside the definition once, however many stairs the program climbs. The guide then defines a block that draws a **flower petal** — one petal in the definition becomes a whole flower when the block is used turn after turn.

[Picture — defining its code — stairs and a petal]

## Say it to your companion

Tell your companion, in your own words: When the same stack of blocks is needed again and again, you make it once as a My Block: name the new block, define its code inside it — the zigzag stairs pattern, a flower petal — and then use your own block anywhere, like a block the program came with. Then let your companion ask you one question about it — and answer from the lesson, not from memory of the book's exact words.
