# Characters and Strings — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: One symbol — a letter, digit, space or punctuation mark**
**Answer: True**

**2. (Sub lesson 1) True or false: One symbol — a letter, digit, space or punctuation mark** — as the answer to: How is a character stored?
**Answer: False — As a code number from the agreed character set**

**3. (Sub lesson 1) True or false: Because it is a code number underneath**
**Answer: True**

**4. (Sub lesson 1) True or false: Because it is a code number underneath** — as the answer to: What is a string?
**Answer: False — A sequence of characters kept as one value**

**5. (Sub lesson 1) True or false: Length, order, and parts that can be cut out and joined**
**Answer: True**

**6. (Sub lesson 2) True or false: Length, order, and parts that can be cut out and joined** — as the answer to: Why does the book place characters after arrays?

**7. (Sub lesson 2) True or false: Cutting out parts and joining them (and searching and comparing)**
