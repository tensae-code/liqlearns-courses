# Characters and Strings — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What is a character?** → **One symbol — a letter, digit, space or punctuation mark**

**2. (Sub lesson 1) How is a character stored?** → **As a code number from the agreed character set**

**3. (Sub lesson 1) A character can be counted with because of what?** → **Because it is a code number underneath**

**4. (Sub lesson 1) What is a string?** → **A sequence of characters kept as one value**

**5. (Sub lesson 1) What three properties follow from the row?** → **Length, order, and parts that can be cut out and joined**

**6. (Sub lesson 2) Why does the book place characters after arrays?** → **A string is the array's closest relative — characters in a row**

**7. (Sub lesson 2) What operations is every text program built from?** → **Cutting out parts and joining them (and searching and comparing)**

**8. (Sub lesson 2) When is a value's kind named?** → **In the design — before the program is written, not after it breaks**

**9. (Sub lesson 2) Which values belong in strings?** → **Text that must be searched, compared or taken apart**
