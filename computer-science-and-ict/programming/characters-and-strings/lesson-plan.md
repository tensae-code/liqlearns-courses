## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The character — one symbol, one code** — Text enters a program one **character** at a time: a letter, a digit, a space, a punctuation mark — each a single symbol, stored as a **code number** from the character set the machine agrees on. The character is a data type of its own (in the book's C-flavoured world, `char`): it can be stored, compared and printed, and — because it is a code underneath — even counted with. Indonesia's Grade 11 data-structure design places characters right after arrays for a reason the next sub lesson collects: a string is the array's closest relative.
2. **The string — characters in a row** — A **string** is a **sequence of characters** kept as one value: a name, a word, a whole sentence. Its properties follow from the row: it has a **length** (how many characters), an **order** (first character, second, …), and parts that can be cut out and joined — the operations every text program is built from. Designing with strings means choosing them deliberately: text that must be searched, compared or taken apart belongs in strings, and the designer names a value's kind — number, character, string — before the program is written, not after it breaks.
