## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Objects you can see** — In the 3D environment every character and prop on the stage is an **object** of a **class** the gallery offers (a person, an animal, a vehicle), carrying the class's **properties** (its size, colour, position) which the learner sets, and its **methods** (its ready actions — move, turn, say) which the learner calls. Because the object stands visible, the OOP vocabulary stops being vocabulary: a property is the slider you just changed; a method is the movement you just watched.
2. **Directing the play — methods in order, worlds that answer** — The learner builds a small **scene as a program**: objects placed, then methods called **in sequence** — and, as the environment grows, in answer to events — so the 3D world becomes the gentlest first meeting with the two great ideas of the senior course: **object-orientation** (the world as acting things) and **event-driven** working (the world answering what happens). Greece places this chapter beside mobile-app programming in the same unit, 'creating applications', so Grade 10's learners meet modern programming's shapes by making worlds before they meet its text.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## The run of the lesson (in order)
1. **Do it first** — Grade 10 meets object-oriented programming standing inside a world: characters on a stage, each an object, each answering methods — wave, turn, move — that you can watch happening. The abstract idea becomes a play you direct. (lesson/lesson.md).
2. **The explanation** — the lesson text in lesson/lesson.md, in its parts in order.
   - ADD IMAGE: a picture of objects you can see as the lesson describes it — the student studies the picture and names what each part shows.
   - ADD GIF: a GIF of directing the play — methods in order, worlds that answer in action — the student watches once, then says what changed and why.
   - ADD AUDIO: a voice reading the lesson's key names and definitions aloud, in the order the lesson gives them — the student listens once through, then reads the same lines aloud along with the voice. (Audio is a described slot in this build; no audio file is made.)
3. **Say it to your companion** — the companion block in lesson/lesson.md.
   - ADD VIDEO: the script in video-script.md, filmed — the lesson in the super-simple voice (made later, when videos are made).
4. **Questions** — from questions/: multiple-choice, true-false, matching, short-answer — served at the learner's level and teaching-mix (levels.md).
5. **Hands-on** — hands-on.md.
6. **Do It Yourself** — the doing block at the end of lesson/lesson.md.
