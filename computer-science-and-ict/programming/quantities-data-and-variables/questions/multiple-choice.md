# Quantities, Data and Variables — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a quantity?**
a) Anything a program works with — a number, a text, a measurement  b) May the value change while the program runs?  c) A quantity that keeps one value from start to end  d) A named store whose value can change during the program
**Answer: a) Anything a program works with — a number, a text, a measurement**

**2. (Sub lesson 1) By what question do quantities divide?**
a) A quantity that keeps one value from start to end  b) May the value change while the program runs?  c) A named store whose value can change during the program  d) The values themselves — what constants and variables hold
**Answer: b) May the value change while the program runs?**
