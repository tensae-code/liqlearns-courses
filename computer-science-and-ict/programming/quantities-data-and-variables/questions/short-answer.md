# Quantities, Data and Variables — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a quantity?**
**Answer: Anything a program works with — a number, a text, a measurement**

**2. (Sub lesson 1) By what question do quantities divide?**
**Answer: May the value change while the program runs?**

**3. (Sub lesson 1) What is a constant?**
**Answer: A quantity that keeps one value from start to end**

**4. (Sub lesson 1) What is a variable?**
**Answer: A named store whose value can change during the program**

**5. (Sub lesson 1) What is data?**
**Answer: The values themselves — what constants and variables hold**

**6. (Sub lesson 2) State the naming rules for a variable.**
**Answer: Begin with a letter; letters, digits and underscore; no spaces; not a reserved word**

**7. (Sub lesson 2) Why choose names carefully?**
**Answer: A name should say what the variable holds**

**8. (Sub lesson 2) Name the two chief data types in this lesson.**
**Answer: Numbers and text (strings)**

**9. (Sub lesson 2) What does a value's type decide?**
**Answer: What may be done with it — calculate, or join and compare**

**10. (Sub lesson 2) What is the book's discipline before writing?**
**Answer: Name the quantity, fix its type, then write the program**
