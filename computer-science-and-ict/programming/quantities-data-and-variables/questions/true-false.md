# Quantities, Data and Variables — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a quantity?" is: Anything a program works with — a number, a text, a measurement**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "By what question do quantities divide?" is: A quantity that keeps one value from start to end**
**Answer: False** — May the value change while the program runs?

**3. (Sub lesson 1) True or false: the answer to "What is a constant?" is: A quantity that keeps one value from start to end**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is a variable?" is: The values themselves — what constants and variables hold**
**Answer: False** — A named store whose value can change during the program

**5. (Sub lesson 1) True or false: the answer to "What is data?" is: The values themselves — what constants and variables hold**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "State the naming rules for a variable." is: A name should say what the variable holds**
**Answer: False** — Begin with a letter; letters, digits and underscore; no spaces; not a reserved word

**7. (Sub lesson 2) True or false: the answer to "Why choose names carefully?" is: A name should say what the variable holds**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Name the two chief data types in this lesson." is: What may be done with it — calculate, or join and compare**
**Answer: False** — Numbers and text (strings)

**9. (Sub lesson 2) True or false: the answer to "What does a value's type decide?" is: What may be done with it — calculate, or join and compare**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is the book's discipline before writing?" is: Anything a program works with — a number, a text, a measurement**
**Answer: False** — Name the quantity, fix its type, then write the program
