# Quantities, Data and Variables — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Constants and variables — what may change
Sub lesson 1 questions from the type files. Pass mark: Anything a program works with — a number, a text, a measurement; May the value change while the program runs?; A quantity that keeps one value from start to end; A named store whose value can change during the program; The values themselves — what constants and variables hold.

## Sub lesson 2 — Naming rules and data types
Sub lesson 2 questions from the type files. Pass mark: Begin with a letter; letters, digits and underscore; no spaces; not a reserved word; A name should say what the variable holds; Numbers and text (strings); What may be done with it — calculate, or join and compare; Name the quantity, fix its type, then write the program.
