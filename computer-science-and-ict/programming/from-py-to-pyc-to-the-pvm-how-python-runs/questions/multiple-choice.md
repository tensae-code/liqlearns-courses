# From .py to .pyc to the PVM — how Python runs — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Source code is saved with the extension —
a) .pyc  b) .py  c) .pvm
**Answer: b) b) .py**

**2. (Sub lesson 1)** Source compiles into —
a) hardware  b) bytecode  c) a comment
**Answer: b) b) bytecode** — A simple translation.

**3. (Sub lesson 1)** Bytecode is usually stored in a file ending —
a) .py  b) .txt  c) .pyc
**Answer: c) c) .pyc**

**4. (Sub lesson 2)** PVM stands for —
a) Python Virtual Machine  b) Program Value Meter  c) Python Voice Module
**Answer: a) a) Python Virtual Machine**

**5. (Sub lesson 2)** The PVM reads bytecode instructions —
a) all at once  b) one by one  c) backwards
**Answer: b) b) one by one**

**6. (Sub lesson 2)** Bytecode interpretation is —
a) manual  b) automatic  c) done by the user
**Answer: b) b) automatic**
