This lesson: **From .py to .pyc to the PVM — how Python runs**.

First, do it. Run the opening program. Watch what it prints.

Then the idea, in order: You write and save source code with the .py extension; it compiles — a simple translation — into bytecode, usually stored in a .pyc file. Bytecode loads into the runtime; the Python Virtual Machine reads each instruction one by one and executes it. Automatic, part of the installed system; running is the last step.

Now you. Draw the pipeline .py → .pyc → PVM → output and label who does each step.

Say it to your companion: Walk your companion through the pipeline with the GIF: source saved, bytecode compiled, PVM executing one instruction at a time.
