# Hands-on — From .py to .pyc to the PVM — how Python runs

The lesson with your hands, not only your eyes — every activity is done for real, in IDLE or on paper.

## Pipeline cards
Make four cards — .py source, compiler step, .pyc bytecode, PVM — and lay the pipeline. A partner scrambles them; you restore the order and narrate each handover.

## Find the bytecode
Run a saved .py file in IDLE, then look for the __pycache__ folder it creates nearby — the .pyc lives there. Write down its full file name.
