# Character Codes — EBCDIC, ASCII and Unicode — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The 8-bit character code of IBM's mainframe world**
**Answer: True**

**2. (Sub lesson 1) True or false: The 8-bit character code of IBM's mainframe world** — as the answer to: How many characters has ASCII?
**Answer: False — 128, in 7 bits**

**3. (Sub lesson 1) True or false: Control codes, digits, English letters and signs**
**Answer: True**

**4. (Sub lesson 1) True or false: Control codes, digits, English letters and signs** — as the answer to: What is ASCII's written-on-its-face limit?
**Answer: False — Too few places for the world's scripts**

**5. (Sub lesson 1) True or false: Punched cards**
**Answer: True**

**6. (Sub lesson 2) True or false: Punched cards** — as the answer to: What does Unicode give every character?
**Answer: False — Its own number — every script included**

**8. (Sub lesson 2) True or false: UTF-8, UTF-16 and UTF-32** — as the answer to: Which form rules the web?
