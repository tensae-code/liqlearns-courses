# Character Codes — EBCDIC, ASCII and Unicode — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What is EBCDIC?** → **The 8-bit character code of IBM's mainframe world**

**2. (Sub lesson 1) How many characters has ASCII?** → **128, in 7 bits**

**3. (Sub lesson 1) What fills ASCII's table?** → **Control codes, digits, English letters and signs**

**4. (Sub lesson 1) What is ASCII's written-on-its-face limit?** → **Too few places for the world's scripts**

**5. (Sub lesson 1) Which ancestry marks EBCDIC's letter order?** → **Punched cards**

**6. (Sub lesson 2) What does Unicode give every character?** → **Its own number — every script included**

**7. (Sub lesson 2) Name Unicode's three storage forms.** → **UTF-8, UTF-16 and UTF-32**

**8. (Sub lesson 2) Which form rules the web?** → **UTF-8**

**9. (Sub lesson 2) Where do Bangla's letters live in Unicode?** → **In the Bangla block — the book's printed Bangla table**

**10. (Sub lesson 2) Which web line declares Unicode for a page?** → **The meta charset line — utf-8**
