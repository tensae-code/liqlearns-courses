# Character Codes — EBCDIC, ASCII and Unicode — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is EBCDIC?**
a) The 8-bit character code of IBM's mainframe world  b) 128, in 7 bits  c) Control codes, digits, English letters and signs  d) Too few places for the world's scripts
**Answer: a**

**2. (Sub lesson 1) How many characters has ASCII?**
a) 128, in 7 bits  b) Control codes, digits, English letters and signs  c) Too few places for the world's scripts  d) Punched cards
**Answer: a**

**3. (Sub lesson 1) What fills ASCII's table?**
a) Control codes, digits, English letters and signs  b) Too few places for the world's scripts  c) Punched cards  d) Its own number — every script included
**Answer: a**

**4. (Sub lesson 1) What is ASCII's written-on-its-face limit?**
a) Too few places for the world's scripts  b) Punched cards  c) Its own number — every script included  d) UTF-8, UTF-16 and UTF-32
**Answer: a**

**5. (Sub lesson 1) Which ancestry marks EBCDIC's letter order?**
a) Punched cards  b) Its own number — every script included  c) UTF-8, UTF-16 and UTF-32  d) UTF-8
**Answer: a**

**6. (Sub lesson 2) What does Unicode give every character?**
a) Its own number — every script included  b) UTF-8, UTF-16 and UTF-32  c) UTF-8  d) In the Bangla block — the book's printed Bangla table
**Answer: a**

**7. (Sub lesson 2) Name Unicode's three storage forms.**
a) UTF-8, UTF-16 and UTF-32  b) UTF-8  c) In the Bangla block — the book's printed Bangla table  d) The meta charset line — utf-8

**8. (Sub lesson 2) Which form rules the web?**
a) UTF-8  b) In the Bangla block — the book's printed Bangla table  c) The meta charset line — utf-8  d) The 8-bit character code of IBM's mainframe world

**9. (Sub lesson 2) Where do Bangla's letters live in Unicode?**
a) In the Bangla block — the book's printed Bangla table  b) The meta charset line — utf-8  c) The 8-bit character code of IBM's mainframe world  d) 128, in 7 bits

**10. (Sub lesson 2) Which web line declares Unicode for a page?**
