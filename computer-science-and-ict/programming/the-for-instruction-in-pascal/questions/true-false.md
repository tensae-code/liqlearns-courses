# The For Instruction in Pascal — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: for i := 1 to n do <instruction>**
**Answer: True**

**2. (Sub lesson 1) True or false: for i := 1 to n do <instruction>** — as the answer to: By how much does the control variable climb each pass?
**Answer: False — By one (or descend by one with downto)**

**3. (Sub lesson 1) True or false: Once, before the first pass**
**Answer: True**

**4. (Sub lesson 1) True or false: Once, before the first pass** — as the answer to: What type must the control variable be?
**Answer: False — An ordinal type**

**5. (Sub lesson 1) True or false: When the count is known in advance**
**Answer: True**

**6. (Sub lesson 2) True or false: When the count is known in advance** — as the answer to: May the body assign to the control variable?
**Answer: False — No — it is forbidden; the loop's counting would break**

**7. (Sub lesson 2) True or false: Undefined — it must not be used (except after a goto exit)**
**Answer: True**

**8. (Sub lesson 2) True or false: Undefined — it must not be used (except after a goto exit)** — as the answer to: How does for repeat several instructions?
**Answer: False — Its one instruction is made compound — begin…end**

**9. (Sub lesson 2) True or false: The direction — the control variable descends from start to final**
**Answer: True**

**10. (Sub lesson 2) True or false: The direction — the control variable descends from start to final** — as the answer to: Who changes the control variable?
**Answer: False — The for instruction itself, never the body**
