# The For Instruction in Pascal — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) Write the for instruction's shape.** → **for i := 1 to n do <instruction>**

**2. (Sub lesson 1) By how much does the control variable climb each pass?** → **By one (or descend by one with downto)**

**3. (Sub lesson 1) When are start and final evaluated?** → **Once, before the first pass**

**4. (Sub lesson 1) What type must the control variable be?** → **An ordinal type**

**5. (Sub lesson 1) When is for the exact instrument?** → **When the count is known in advance**

**6. (Sub lesson 2) May the body assign to the control variable?** → **No — it is forbidden; the loop's counting would break**

**7. (Sub lesson 2) What is the control variable's value after the loop?** → **Undefined — it must not be used (except after a goto exit)**

**8. (Sub lesson 2) How does for repeat several instructions?** → **Its one instruction is made compound — begin…end**

**9. (Sub lesson 2) What does downto change?** → **The direction — the control variable descends from start to final**

**10. (Sub lesson 2) Who changes the control variable?** → **The for instruction itself, never the body**
