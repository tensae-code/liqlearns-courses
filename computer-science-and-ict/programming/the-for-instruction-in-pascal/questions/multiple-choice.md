# The For Instruction in Pascal — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Write the for instruction's shape.**
a) for i := 1 to n do <instruction>  b) By one (or descend by one with downto)  c) Once, before the first pass  d) An ordinal type
**Answer: a**

**2. (Sub lesson 1) By how much does the control variable climb each pass?**
a) By one (or descend by one with downto)  b) Once, before the first pass  c) An ordinal type  d) When the count is known in advance
**Answer: a**

**3. (Sub lesson 1) When are start and final evaluated?**
a) Once, before the first pass  b) An ordinal type  c) When the count is known in advance  d) No — it is forbidden; the loop's counting would break
**Answer: a**

**4. (Sub lesson 1) What type must the control variable be?**
a) An ordinal type  b) When the count is known in advance  c) No — it is forbidden; the loop's counting would break  d) Undefined — it must not be used (except after a goto exit)
**Answer: a**

**5. (Sub lesson 1) When is for the exact instrument?**
a) When the count is known in advance  b) No — it is forbidden; the loop's counting would break  c) Undefined — it must not be used (except after a goto exit)  d) Its one instruction is made compound — begin…end
**Answer: a**

**6. (Sub lesson 2) May the body assign to the control variable?**
a) No — it is forbidden; the loop's counting would break  b) Undefined — it must not be used (except after a goto exit)  c) Its one instruction is made compound — begin…end  d) The direction — the control variable descends from start to final
**Answer: a**

**7. (Sub lesson 2) What is the control variable's value after the loop?**
a) Undefined — it must not be used (except after a goto exit)  b) Its one instruction is made compound — begin…end  c) The direction — the control variable descends from start to final  d) The for instruction itself, never the body
**Answer: a**

**8. (Sub lesson 2) How does for repeat several instructions?**
a) Its one instruction is made compound — begin…end  b) The direction — the control variable descends from start to final  c) The for instruction itself, never the body  d) for i := 1 to n do <instruction>
**Answer: a**

**9. (Sub lesson 2) What does downto change?**
a) The direction — the control variable descends from start to final  b) The for instruction itself, never the body  c) for i := 1 to n do <instruction>  d) By one (or descend by one with downto)
**Answer: a**

**10. (Sub lesson 2) Who changes the control variable?**
a) The for instruction itself, never the body  b) for i := 1 to n do <instruction>  c) By one (or descend by one with downto)  d) Once, before the first pass
**Answer: a**
