The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A program is not its algorithm alone: the **way its data is organised decides what the algorithm can do cheaply**. Greece meets the formula twice — as Grade 8's founding equation (Algorithm + Data Structures = Program) and as Ch.3 of the exam book. The first structure is the **array (πίνακας)**: a fixed row of places of one type under one name, reached by index — the structure for keeping many values of a kind so order, position and the whole set stay available to every later command.
The **stack (στοίβα)** keeps its values in a pile: **push** adds on top, **pop** takes from the top — the last value pushed is the first value out (**LIFO**), like a pile of plates. The **queue (ουρά)** keeps a line: values **join at the rear and leave from the front** — the first value in is the first value out (**FIFO**), like a queue at a desk. Each structure is its access rule; choosing between them is choosing which end of time the program cares about.
