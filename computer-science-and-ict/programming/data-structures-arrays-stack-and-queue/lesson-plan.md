## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Algorithms + Data Structures = Programs — and the array** — A program is not its algorithm alone: the **way its data is organised decides what the algorithm can do cheaply**. Greece meets the formula twice — as Grade 8's founding equation (Algorithm + Data Structures = Program) and as Ch.3 of the exam book. The first structure is the **array (πίνακας)**: a fixed row of places of one type under one name, reached by index — the structure for keeping many values of a kind so order, position and the whole set stay available to every later command.
2. **Stack and queue — last-in-first-out, first-in-first-out** — The **stack (στοίβα)** keeps its values in a pile: **push** adds on top, **pop** takes from the top — the last value pushed is the first value out (**LIFO**), like a pile of plates. The **queue (ουρά)** keeps a line: values **join at the rear and leave from the front** — the first value in is the first value out (**FIFO**), like a queue at a desk. Each structure is its access rule; choosing between them is choosing which end of time the program cares about.
