# Data Structures — Arrays, Stack and Queue — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) State the formula.**
**Answer: Algorithms + Data Structures = Programs**

**2. (Sub lesson 1) What decides what an algorithm can do cheaply?**
**Answer: The way its data is organised — its data structures**

**3. (Sub lesson 1) What is an array?**
**Answer: A fixed row of places of one type under one name, reached by index**

**4. (Sub lesson 1) Where does Greece meet the formula first?**
**Answer: Grade 8 — Algorithm + Data Structures = Program**

**5. (Sub lesson 1) Which exam chapter teaches the structures?**
**Answer: Greece Grade 12 Anaptyxi Efarmogon, Chapter 3**

**6. (Sub lesson 2) What is a stack?**
**Answer: A pile — push adds on top, pop takes from the top**

**7. (Sub lesson 2) What does LIFO mean?**
**Answer: Last In, First Out — the last value pushed is the first out**

**8. (Sub lesson 2) What is a queue?**
**Answer: A line — values join at the rear and leave from the front**

**9. (Sub lesson 2) What does FIFO mean?**
**Answer: First In, First Out**

**10. (Sub lesson 2) What is each structure, in one phrase?**
**Answer: Its access rule**
