# Visual Basic — Variable Types and Constants — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a variable, in the book's definition?**
**Answer: A named place in memory whose value changes as the program runs**

**2. (Sub lesson 1) What does a type declare?**
**Answer: The kind of value the variable may hold**

**3. (Sub lesson 1) Name the book's type set.**
**Answer: Boolean, String, Date, Byte, Integer, Double**

**4. (Sub lesson 1) Which types hold whole numbers? Which holds fractions?**
**Answer: Byte and Integer hold whole numbers; Double holds fractions**

**5. (Sub lesson 1) What does declaring do?**
**Answer: Names the variable and its type before use — stating what the memory place is for**

**6. (Sub lesson 2) What is assigning?**
**Answer: Putting a value — of the variable's own kind — into it**

**7. (Sub lesson 2) What is a constant?**
**Answer: A named value declared once and never changed in the run**

**8. (Sub lesson 2) Why name a constant instead of writing its number?**
**Answer: The name says what the number means, and its constancy is enforced**

**9. (Sub lesson 2) Who enforces types and constancy?**
**Answer: The compiler**

**10. (Sub lesson 2) Which book teaches this?**
**Answer: Kuwait Grade 12 Information Technology Term 1, Part 2 Book 3 Chapter 1**
