# Visual Basic — Variable Types and Constants — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A named place in memory whose value changes as the program runs**
**Answer: True**

**2. (Sub lesson 1) True or false: Boolean, String, Date, Byte, Integer, Double** — as the answer to: What does a type declare?
**Answer: False — The kind of value the variable may hold**

**3. (Sub lesson 1) True or false: Boolean, String, Date, Byte, Integer, Double**
**Answer: True**

**4. (Sub lesson 1) True or false: Names the variable and its type before use — stating what the memory place is for** — as the answer to: Which types hold whole numbers? Which holds fractions?
**Answer: False — Byte and Integer hold whole numbers; Double holds fractions**

**5. (Sub lesson 1) True or false: Names the variable and its type before use — stating what the memory place is for**
**Answer: True**

**6. (Sub lesson 2) True or false: A named value declared once and never changed in the run** — as the answer to: What is assigning?
**Answer: False — Putting a value — of the variable's own kind — into it**

**7. (Sub lesson 2) True or false: A named value declared once and never changed in the run**
**Answer: True**

**8. (Sub lesson 2) True or false: The compiler** — as the answer to: Why name a constant instead of writing its number?
**Answer: False — The name says what the number means, and its constancy is enforced**

**9. (Sub lesson 2) True or false: The compiler**
**Answer: True**
