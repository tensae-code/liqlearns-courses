# Arrays in Pascal and C++ — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A fixed row of values of one type under one name, reached by index**
**Answer: True**

**2. (Sub lesson 1) True or false: A fixed row of values of one type under one name, reached by index** — as the answer to: How does Pascal declare 30 integers?
**Answer: False — var a: array[1..30] of integer;**

**3. (Sub lesson 1) True or false: int a[30]; — indexes 0..29**
**Answer: True**

**4. (Sub lesson 1) True or false: int a[30]; — indexes 0..29** — as the answer to: Is a[i] an ordinary variable?
**Answer: False — Yes — of the element type: assignable, readable, computable**

**5. (Sub lesson 1) True or false: So a loop can compute which element to touch — the array's whole power**
**Answer: True**

**6. (Sub lesson 2) True or false: So a loop can compute which element to touch — the array's whole power** — as the answer to: What walks an array in almost all its work?
**Answer: False — A for loop carrying the index across the whole range**

**7. (Sub lesson 2) True or false: Summing, searching for a value, finding the greatest element (also: reading in, printing out)**
**Answer: True**

**8. (Sub lesson 2) True or false: Summing, searching for a value, finding the greatest element (also: reading in, printing out)** — as the answer to: What is the border danger?
**Answer: False — An out-of-range index touches memory that is not the array's**

**9. (Sub lesson 2) True or false: Pascal's range checking catches it; C++ lets it pass silently**
**Answer: True**

**10. (Sub lesson 2) True or false: Pascal's range checking catches it; C++ lets it pass silently** — as the answer to: What gathers a sum across the walk?
**Answer: False — An accumulator**
