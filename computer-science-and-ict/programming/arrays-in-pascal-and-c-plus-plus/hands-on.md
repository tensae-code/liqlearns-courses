# Hands-on — Arrays in Pascal and C++

The lesson with your hands and your feet, not only your eyes.

## Task one
**First array** — Declare a 10-mark array in both languages; write the loops that read the marks, print them in reverse order, and sum them.

## Task two
**Border case** — Write what happens, in each language, when a program reads a[31] of a 1..30 array and a[30] of a C++ 30-array — and the guard each program should carry.
