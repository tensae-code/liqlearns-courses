# Hands-on — The Boolean and bool Types in Pascal and C++

The lesson with your hands and your feet, not only your eyes.

## Task one
**Operator translation** — Translate five boolean expressions from Pascal to C++ and back, including a not-or pair needing brackets in one language.

## Task two
**Trap court** — Judge four C++ fragments (x == 5; x = 5; if (count); if (ok)) — legal, intended, and safe or trapped — with reasons.
