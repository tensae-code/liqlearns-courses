# Modular Programs with Arrays — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does a modular program divide its work among?**
a) Subprograms — each doing one job well  b) Fill it, process it, print it — the array's career  c) On its own, with the array handed to it  d) A fault would have two homes and a test could not tell them apart
**Answer: a) Subprograms — each doing one job well**

**2. (Sub lesson 1) What are the natural modules around an array?**

**Answer: b) Fill it, process it, print it — the array's career**

**3. (Sub lesson 1) How is each module tested?**
