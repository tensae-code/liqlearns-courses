# Hands-on — Modular Programs with Arrays

The lesson with your hands and your feet, not only your eyes.

## Task one
('Build in modules', 'Write the plan (modules, calls, what each receives and returns) for a program over an array of 10 temperatures: fill, find the average, count days above the average, print all three results. Name the module each job lives in.')

## Task two
('Fault's home', 'A modular marks program prints a wrong average but the printed marks are right. Say which module you open first, which you do not open, and what single-module test settles it.')
