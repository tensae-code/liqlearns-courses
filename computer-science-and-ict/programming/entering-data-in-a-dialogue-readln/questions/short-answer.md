# Entering Data in a Dialogue — Readln — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What do read and readln do?**
**Answer: Take typed values and put them into variables**

**2. (Sub lesson 1) What does readln(a) wait for?**
**Answer: The user typing a value and pressing Enter**

**3. (Sub lesson 1) What should a program write before reading?**
**Answer: A prompt saying what it wants**

**4. (Sub lesson 1) Where does the typed value go?**
**Answer: Into the named variable**

**5. (Sub lesson 1) What happens with no prompt?**
**Answer: The screen waits and the user cannot know why**

**6. (Sub lesson 2) What is a dialogue program's rhythm?**
**Answer: Prompt, read, compute, answer**

**7. (Sub lesson 2) Give the book's first dialogue shape.**
**Answer: Read two numbers, print their sum**

**8. (Sub lesson 2) What is file input, in this picture?**
**Answer: The same conversation, written once instead of every run**

**9. (Sub lesson 2) How should a dialogue be tested?**
**Answer: With easy numbers checkable in your head**

**10. (Sub lesson 2) In which mode does the book name this input?**
**Answer: Dialogue mode (ввод в режиме диалога)**
