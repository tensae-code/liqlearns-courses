# Entering Data in a Dialogue — Readln — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What do read and readln do?**
a) Take typed values and put them into variables  b) The user typing a value and pressing Enter  c) A prompt saying what it wants  d) Into the named variable
**Answer: a) Take typed values and put them into variables**

**2. (Sub lesson 1) What does readln(a) wait for?**
a) A prompt saying what it wants  b) The user typing a value and pressing Enter  c) Into the named variable  d) The screen waits and the user cannot know why
**Answer: b) The user typing a value and pressing Enter**

**3. (Sub lesson 1) What should a program write before reading?**
a) Into the named variable  b) The screen waits and the user cannot know why  c) A prompt saying what it wants  d) Prompt, read, compute, answer
**Answer: c) A prompt saying what it wants**

**4. (Sub lesson 1) Where does the typed value go?**
a) The screen waits and the user cannot know why  b) Prompt, read, compute, answer  c) Read two numbers, print their sum  d) Into the named variable
**Answer: d) Into the named variable**

**5. (Sub lesson 1) What happens with no prompt?**
a) The screen waits and the user cannot know why  b) Prompt, read, compute, answer  c) Read two numbers, print their sum  d) The same conversation, written once instead of every run
**Answer: a) The screen waits and the user cannot know why**
