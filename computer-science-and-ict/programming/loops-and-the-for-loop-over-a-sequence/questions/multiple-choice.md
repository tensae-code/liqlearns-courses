# Loops — and the for loop over a sequence — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A loop repeats —
a) a file name  b) a statement or group of statements  c) the whole computer
**Answer: b) b) a statement or group of statements**

**2. (Sub lesson 1)** A loop runs either a fixed number of times or —
a) until a condition is satisfied  b) until the screen sleeps  c) twice only
**Answer: a) a) until a condition is satisfied**

**3. (Sub lesson 2)** Python's two built-in loops are —
a) for and while  b) if and else  c) print and input
**Answer: a) a) for and while**

**4. (Sub lesson 2)** In a for loop, the temporary variable —
a) never changes  b) takes each item's value in turn  c) holds the whole sequence at once
**Answer: b) b) takes each item's value in turn**

**5. (Sub lesson 2)** A for loop can iterate over —
a) lists and strings  b) tuples and dictionaries  c) both of these
**Answer: c) c) both of these** — Any sequence.

**6. (Sub lesson 1)** One pass through the loop block is called an —
a) iteration  b) indentation  c) expression
**Answer: a) a) iteration**
