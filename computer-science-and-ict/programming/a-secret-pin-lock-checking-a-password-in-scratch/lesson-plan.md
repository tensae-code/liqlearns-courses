# Lesson plan — A Secret PIN Lock — Checking a Password in Scratch

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** A Secret PIN Lock — Checking a Password in Scratch
**Place in the curriculum:** ICT expansion — Palestine (2026-11-14) — in the title Programming on the ICT course ladder (TITLES.md). Built new from Palestine's Grade 9 Programming student book, because no existing lesson in the course covers this thing as its own lesson.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The keypad — ten buttons by duplicating** — The lesson opens with the reason: phones use PINs and passwords for **privacy and security**. The lock’s face is a **keypad of ten button sprites made by duplicating** — one digit button drawn, then copied and renumbered until all ten stand in their grid.
2. **Building the entered number — and the length check** — Each press adds its digit: the **entered number is built digit by digit with join**. A **hidden variable keeps the saved PIN**, and the program’s care is in its timing — **the check runs only when the entered length equals the PIN length**, so half-typed numbers are never judged.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
