# A Secret PIN Lock — Checking a Password in Scratch — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Why do phones use PINs and passwords?" is: For privacy and security**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How many button sprites form the keypad?" is: They are renumbered**
**Answer: False** — Ten

**3. (Sub lesson 1) True or false: the answer to "How are the ten buttons made?" is: By duplicating one drawn button**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What happens to the copied buttons?" is: Join**
**Answer: False** — They are renumbered

**5. (Sub lesson 1) True or false: the answer to "How is the entered number built?" is: Digit by digit, with join**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What block joins the digits?" is: So the secret is not shown on the stage**
**Answer: False** — Join

**7. (Sub lesson 2) True or false: the answer to "Where is the saved PIN kept?" is: In a hidden variable**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Why is the PIN variable hidden?" is: No — never**
**Answer: False** — So the secret is not shown on the stage

**9. (Sub lesson 2) True or false: the answer to "When does the check run?" is: Only when the entered length equals the PIN length**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Are half-typed numbers judged?" is: Ten**
**Answer: False** — No — never
