# A Secret PIN Lock — Checking a Password in Scratch — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Why do phones use PINs and passwords?**
a) For privacy and security  b) Ten  c) They are renumbered  d) Join
**Answer: a) For privacy and security**

**2. (Sub lesson 1) How many button sprites form the keypad?**
a) By duplicating one drawn button  b) Ten  c) Digit by digit, with join  d) In a hidden variable
**Answer: b) Ten**

**3. (Sub lesson 1) How are the ten buttons made?**
a) They are renumbered  b) Join  c) By duplicating one drawn button  d) So the secret is not shown on the stage
**Answer: c) By duplicating one drawn button**

**4. (Sub lesson 1) What happens to the copied buttons?**
a) Digit by digit, with join  b) In a hidden variable  c) Only when the entered length equals the PIN length  d) They are renumbered
**Answer: d) They are renumbered**

**5. (Sub lesson 1) How is the entered number built?**
a) Digit by digit, with join  b) Join  c) So the secret is not shown on the stage  d) No — never
**Answer: a) Digit by digit, with join**

**6. (Sub lesson 2) What block joins the digits?**
a) In a hidden variable  b) Join  c) Only when the entered length equals the PIN length  d) For privacy and security
**Answer: b) Join**

**7. (Sub lesson 2) Where is the saved PIN kept?**
a) So the secret is not shown on the stage  b) No — never  c) In a hidden variable  d) Ten
**Answer: c) In a hidden variable**

**8. (Sub lesson 2) Why is the PIN variable hidden?**
a) Only when the entered length equals the PIN length  b) For privacy and security  c) By duplicating one drawn button  d) So the secret is not shown on the stage
**Answer: d) So the secret is not shown on the stage**

**9. (Sub lesson 2) When does the check run?**
a) Only when the entered length equals the PIN length  b) No — never  c) Ten  d) They are renumbered
**Answer: a) Only when the entered length equals the PIN length**

**10. (Sub lesson 2) Are half-typed numbers judged?**
a) For privacy and security  b) No — never  c) By duplicating one drawn button  d) Digit by digit, with join
**Answer: b) No — never**
