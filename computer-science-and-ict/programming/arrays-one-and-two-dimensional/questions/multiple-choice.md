# Arrays in Visual Basic — One- and Two-Dimensional — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does an array hold?**
a) Many values under one name, each reached by its position (index)  b) A single row of values  c) The array's name, how many elements it holds, and what type they are  d) Before any value is stored in it
**Answer: a) Many values under one name, each reached by its position (index)**

**2. (Sub lesson 1) What shape is a one-dimensional array?**
a) The array's name, how many elements it holds, and what type they are  b) A single row of values  c) Before any value is stored in it  d) With a FOR..NEXT loop over its indexes
**Answer: b) A single row of values**

**3. (Sub lesson 1) What does the declaration statement say?**
a) Before any value is stored in it  b) With a FOR..NEXT loop over its indexes  c) The array's name, how many elements it holds, and what type they are  d) Rows and columns, like a table — a matrix
**Answer: c) The array's name, how many elements it holds, and what type they are**

**4. (Sub lesson 1) When is an array declared?**
a) With a FOR..NEXT loop over its indexes  b) Rows and columns, like a table — a matrix  c) By two indexes — row, then column  d) Before any value is stored in it
**Answer: d) Before any value is stored in it**

**5. (Sub lesson 1) How is a whole one-dimensional array walked?**
a) With a FOR..NEXT loop over its indexes  b) Rows and columns, like a table — a matrix  c) By two indexes — row, then column  d) With a loop inside a loop — one for rows, one for columns
**Answer: a) With a FOR..NEXT loop over its indexes**
