# Arrays in Visual Basic — One- and Two-Dimensional — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does an array hold?**
**Answer: Many values under one name, each reached by its position (index)**

**2. (Sub lesson 1) What shape is a one-dimensional array?**
**Answer: A single row of values**

**3. (Sub lesson 1) What does the declaration statement say?**
**Answer: The array's name, how many elements it holds, and what type they are**

**4. (Sub lesson 1) When is an array declared?**
**Answer: Before any value is stored in it**

**5. (Sub lesson 1) How is a whole one-dimensional array walked?**
**Answer: With a FOR..NEXT loop over its indexes**

**6. (Sub lesson 2) What shape is a two-dimensional array?**
**Answer: Rows and columns, like a table — a matrix**

**7. (Sub lesson 2) How is a value in a two-dimensional array reached?**
**Answer: By two indexes — row, then column**

**8. (Sub lesson 2) How is a whole two-dimensional array walked?**
**Answer: With a loop inside a loop — one for rows, one for columns**

**9. (Sub lesson 2) How does Libya's chapter close?**
**Answer: With two sets of applications — full worked programs on arrays**

**10. (Sub lesson 2) What language are these arrays taught in?**
**Answer: Visual Basic, in Libya's Grade 12 IT Science book, Chapter 5**
