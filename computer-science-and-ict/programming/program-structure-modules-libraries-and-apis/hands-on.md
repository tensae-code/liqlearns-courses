# Hands-on — Program Structure — Modules, Libraries and APIs

The lesson with your hands and your feet, not only your eyes.

## Task one
**Draw the structure** — Take a program you know (a game, a school app). Draw it as modules in boxes, name each module's one job, and mark which boxes are libraries rather than the team's own.

## Task two
**Write a tiny API** — For a module that handles dates, write its API on paper: three operations, what each needs, what each returns. Add one promise ('dates are always given as…').
