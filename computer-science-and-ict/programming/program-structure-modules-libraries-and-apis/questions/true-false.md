# Program Structure — Modules, Libraries and APIs — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A named part of a program with one job, hiding its insides and showing a small surface**
**Answer: True**

**2. (Sub lesson 1) True or false: A named part of a program with one job, hiding its insides and showing a small surface** — as the answer to: What is a library?
**Answer: False — A collection of ready modules written by others, imported instead of invented**

**3. (Sub lesson 1) True or false: Each part can be built, tested and fixed on its own — and reused**
**Answer: True**

**4. (Sub lesson 1) True or false: Each part can be built, tested and fixed on its own — and reused** — as the answer to: What does a module hide, and what does it show?
**Answer: False — It hides its insides; it shows a small surface the rest may use**

**5. (Sub lesson 1) True or false: The Grade 11 programme outcomes in the teacher guide (p. 44)**
**Answer: True**

**6. (Sub lesson 2) True or false: The Grade 11 programme outcomes in the teacher guide (p. 44)** — as the answer to: What is an API?
**Answer: False — The written agreement at a part's surface — the operations offered, what each needs, and what each returns**

**7. (Sub lesson 2) True or false: Callers ask only through the API; makers may change the insides while the API holds**
**Answer: True**

**8. (Sub lesson 2) True or false: Callers ask only through the API; makers may change the insides while the API holds** — as the answer to: Why does the API promise matter?
**Answer: False — It lets parts be improved or rebuilt without breaking everyone who uses them**

**9. (Sub lesson 2) True or false: A counter in a shop: you ask at the counter by the menu; the kitchen behind it may reorganise freely**
**Answer: True**

**10. (Sub lesson 2) True or false: A counter in a shop: you ask at the counter by the menu; the kitchen behind it may reorganise freely** — as the answer to: Name one API you have used without coding.
**Answer: False — Any service's public interface — for example a weather service other programs query**
