Sub lesson 1 questions from the type files. ## Sub lesson 2 — APIs — the agreement between parts
Sub lesson 2 questions from the type files. Pass mark: The written agreement at a part's surface — the operations offered, what each needs, and what each returns; Callers ask only through the API; makers may change the insides while the API holds; It lets parts be improved or rebuilt without breaking everyone who uses them; A counter in a shop: you ask at the counter by the menu; the kitchen behind it may reorganise freely; Any service's public interface — for example a weather service other programs query.
