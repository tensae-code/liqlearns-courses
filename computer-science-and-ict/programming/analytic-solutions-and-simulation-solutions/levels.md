# Analytic Solutions and Simulation Solutions — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — The analytic solution — exact, when it exists
Sub lesson 1 questions from the type files. Pass mark: An exact formula derived by mathematics, giving the result from the data; Exactness for every input, instant computation, and insight into dependencies; The quadratic formula (also: the compound-interest formula); Existence — most real models have no formula; How the answer depends on each datum.

## Sub lesson 2 — The simulation solution — the model enacted
Sub lesson 2 questions from the type files. Pass mark: The computer plays the model step by step by its rules, and the answer is read from the play; Where no formula exists — weather, epidemics, traffic behaviour; It is one run's story — sensitive to starting values; random models need repeated, averaged runs; Where both exist, each checks the other; Analytic where a formula lives; simulation where behaviour must be watched.
