# Analytic Solutions and Simulation Solutions — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: An exact formula derived by mathematics, giving the result from the data**
**Answer: True**

**2. (Sub lesson 1) True or false: An exact formula derived by mathematics, giving the result from the data** — as the answer to: Name its three virtues.
**Answer: False — Exactness for every input, instant computation, and insight into dependencies**

**3. (Sub lesson 1) True or false: The quadratic formula (also: the compound-interest formula)**
**Answer: True**

**4. (Sub lesson 1) True or false: The quadratic formula (also: the compound-interest formula)** — as the answer to: What is the analytic road's limit?
**Answer: False — Existence — most real models have no formula**

**5. (Sub lesson 1) True or false: How the answer depends on each datum**
**Answer: True**

**6. (Sub lesson 2) True or false: How the answer depends on each datum** — as the answer to: What is a simulation solution?
**Answer: False — The computer plays the model step by step by its rules, and the answer is read from the play**

**7. (Sub lesson 2) True or false: Where no formula exists — weather, epidemics, traffic behaviour**
**Answer: True**

**8. (Sub lesson 2) True or false: Where no formula exists — weather, epidemics, traffic behaviour** — as the answer to: What is its price?
**Answer: False — It is one run's story — sensitive to starting values; random models need repeated, averaged runs**

**9. (Sub lesson 2) True or false: Where both exist, each checks the other**
**Answer: True**

**10. (Sub lesson 2) True or false: Where both exist, each checks the other** — as the answer to: State the chapter's judgement.
**Answer: False — Analytic where a formula lives; simulation where behaviour must be watched**
