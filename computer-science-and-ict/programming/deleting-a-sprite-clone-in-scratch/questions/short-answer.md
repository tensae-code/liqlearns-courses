# Deleting a Sprite Clone in Scratch — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does delete this clone remove?**
**Answer: The clone that runs the block — that one copy**

**2. (Sub lesson 1) What happens to the original sprite?**
**Answer: It carries on — the block never deletes it**

**3. (Sub lesson 1) Where does the block belong?**
**Answer: At the end of the clone's own script**

**4. (Sub lesson 1) Which script holds a clone's work?**
**Answer: The one beginning “when I start as a clone”**

**5. (Sub lesson 1) Can a sprite delete another sprite's clones?**
**Answer: No — only the running clone deletes itself**

**6. (Sub lesson 2) When does a clone delete itself?**
**Answer: When its job is finished**

**7. (Sub lesson 2) Give the three finishing moments named.**
**Answer: Landing, being caught, and having crossed the stage**

**8. (Sub lesson 2) What happens without deleting?**
**Answer: Clones crowd the stage and every new run starts cluttered**

**9. (Sub lesson 2) When is deleting designed?**
**Answer: From the start — as part of the clone's design**

**10. (Sub lesson 2) What is the whole clone pattern?**
**Answer: Create the clone, work as the clone, delete the clone**
