# Deleting a Sprite Clone in Scratch — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does delete this clone remove?" is: The clone that runs the block — that one copy**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What happens to the original sprite?" is: When its job is finished**
**Answer: False** — It carries on — the block never deletes it

**3. (Sub lesson 1) True or false: the answer to "Where does the block belong?" is: At the end of the clone's own script**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Which script holds a clone's work?" is: Clones crowd the stage and every new run starts cluttered**
**Answer: False** — The one beginning “when I start as a clone”

**5. (Sub lesson 1) True or false: the answer to "Can a sprite delete another sprite's clones?" is: No — only the running clone deletes itself**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "When does a clone delete itself?" is: Create the clone, work as the clone, delete the clone**
**Answer: False** — When its job is finished

**7. (Sub lesson 2) True or false: the answer to "Give the three finishing moments named.?" is: Landing, being caught, and having crossed the stage**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What happens without deleting?" is: It carries on — the block never deletes it**
**Answer: False** — Clones crowd the stage and every new run starts cluttered

**9. (Sub lesson 2) True or false: the answer to "When is deleting designed?" is: From the start — as part of the clone's design**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is the whole clone pattern?" is: The one beginning “when I start as a clone”**
**Answer: False** — Create the clone, work as the clone, delete the clone
