# Deleting a Sprite Clone in Scratch — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does delete this clone remove?**
a) The clone that runs the block — that one copy  b) It carries on — the block never deletes it  c) At the end of the clone's own script  d) The one beginning “when I start as a clone”
**Answer: a) The clone that runs the block — that one copy**

**2. (Sub lesson 1) What happens to the original sprite?**
a) At the end of the clone's own script  b) It carries on — the block never deletes it  c) The one beginning “when I start as a clone”  d) No — only the running clone deletes itself
**Answer: b) It carries on — the block never deletes it**

**3. (Sub lesson 1) Where does the block belong?**
a) The one beginning “when I start as a clone”  b) No — only the running clone deletes itself  c) At the end of the clone's own script  d) When its job is finished
**Answer: c) At the end of the clone's own script**

**4. (Sub lesson 1) Which script holds a clone's work?**
a) No — only the running clone deletes itself  b) When its job is finished  c) Landing, being caught, and having crossed the stage  d) The one beginning “when I start as a clone”
**Answer: d) The one beginning “when I start as a clone”**

**5. (Sub lesson 1) Can a sprite delete another sprite's clones?**
a) No — only the running clone deletes itself  b) When its job is finished  c) Landing, being caught, and having crossed the stage  d) Clones crowd the stage and every new run starts cluttered
**Answer: a) No — only the running clone deletes itself**

**6. (Sub lesson 2) When does a clone delete itself?**
a) Landing, being caught, and having crossed the stage  b) When its job is finished  c) Clones crowd the stage and every new run starts cluttered  d) From the start — as part of the clone's design
**Answer: b) When its job is finished**

**7. (Sub lesson 2) Give the three finishing moments named.**
a) Clones crowd the stage and every new run starts cluttered  b) From the start — as part of the clone's design  c) Landing, being caught, and having crossed the stage  d) Create the clone, work as the clone, delete the clone
**Answer: c) Landing, being caught, and having crossed the stage**

**8. (Sub lesson 2) What happens without deleting?**
a) From the start — as part of the clone's design  b) Create the clone, work as the clone, delete the clone  c) The clone that runs the block — that one copy  d) Clones crowd the stage and every new run starts cluttered
**Answer: d) Clones crowd the stage and every new run starts cluttered**

**9. (Sub lesson 2) When is deleting designed?**
a) From the start — as part of the clone's design  b) Create the clone, work as the clone, delete the clone  c) The clone that runs the block — that one copy  d) It carries on — the block never deletes it
**Answer: a) From the start — as part of the clone's design**

**10. (Sub lesson 2) What is the whole clone pattern?**
a) The clone that runs the block — that one copy  b) Create the clone, work as the clone, delete the clone  c) It carries on — the block never deletes it  d) At the end of the clone's own script
**Answer: b) Create the clone, work as the clone, delete the clone**
