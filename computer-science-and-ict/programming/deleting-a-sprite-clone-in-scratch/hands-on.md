# Hands-on — Deleting a Sprite Clone in Scratch

The lesson with your hands and your feet, not only your eyes.

## Rain that lands
Make a sprite create clones of a raindrop that fall. End each clone's script with delete this clone when it touches the ground. Run it: the stage must stay clear while the rain keeps falling.

## Count the copies
Run a clone-making script without deleting and count the copies after ten seconds. Add deleting at each job's end and run again. Write what changed.
