# Video script — Deleting a Sprite Clone in Scratch

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

The delete this clone block removes the clone that runs it — that one copy disappears from the stage, while the original sprite and its other clones carry on. The block belongs at the end of the clone's own script: the script that begins when I start as a clone does the clone's work, and its last act is to delete the clone that did it. A sprite cannot delete another sprite's clones, and the original is never deleted by this block — only the running copy.
A clone deletes itself when its job is finished: a raindrop when it lands, a game piece when it is caught, a letter when it has been read across the stage. Without deleting, every run of the program would leave its clones behind and the next run would start on a crowded stage — so deleting is part of the clone's design from the start, not a tidying afterthought. The pattern of the two séances together: create the clone, work as the clone, delete the clone.
