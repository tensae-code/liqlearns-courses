# Records in Pascal and C++ — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A structured type whose named fields may be of different types**
**Answer: True**

**2. (Sub lesson 1) True or false: A structured type whose named fields may be of different types** — as the answer to: How is a field reached?
**Answer: False — Through the record variable with a dot — p.mark**

**3. (Sub lesson 1) True or false: type TPupil = record name: string; mark: integer; paid: boolean; end;**
**Answer: True**

**4. (Sub lesson 1) True or false: type TPupil = record name: string; mark: integer; paid: boolean; end;** — as the answer to: What is C++'s record called?
**Answer: False — struct**

**5. (Sub lesson 1) True or false: Copies every field at once**
**Answer: True**

**6. (Sub lesson 2) True or false: Copies every field at once** — as the answer to: What is a class of pupils, as data?
**Answer: False — An array of records**

**7. (Sub lesson 2) True or false: Loop the array, test a field, gather by another — names of pupils with mark ≥ 9 and paid = true**
**Answer: True**

**8. (Sub lesson 2) True or false: Loop the array, test a field, gather by another — names of pupils with mark ≥ 9 and paid = true** — as the answer to: model a date as a record.
**Answer: False — Three fields — day, month, year — of fitting subrange types**

**9. (Sub lesson 2) True or false: The datum's anatomy, written down**
**Answer: True**

**10. (Sub lesson 2) True or false: The datum's anatomy, written down** — as the answer to: Where do records meet files?
**Answer: False — A library (or register) kept as a file of records**
