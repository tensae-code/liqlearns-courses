# Propositions and Logical Connectives — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A statement that is true or false**
**Answer: True**

**2. (Sub lesson 1) True or false: A statement that is true or false** — as the answer to: Which of these is not a proposition: 'the lab has twenty computers', 'open the lab'?
**Answer: False — 'Open the lab' — a command cannot be judged true or false**

**3. (Sub lesson 1) True or false: A truth value**
**Answer: True**

**4. (Sub lesson 1) True or false: A truth value** — as the answer to: What is negation?
**Answer: False — The connective that flips a proposition's value — NOT p**

**5. (Sub lesson 1) True or false: Only when both joined parts are true**
**Answer: True**

**6. (Sub lesson 2) True or false: Only when both joined parts are true** — as the answer to: When is a disjunction true?
**Answer: False — When at least one joined part is true**

**7. (Sub lesson 2) True or false: Only when the first part is true and the second false**
**Answer: True**

**8. (Sub lesson 2) True or false: Only when the first part is true and the second false** — as the answer to: What does biimplication say?
**Answer: False — The two propositions stand or fall together**

**9. (Sub lesson 2) True or false: Negation, conjunction, disjunction, implication (and biimplication)**
**Answer: True**

**10. (Sub lesson 2) True or false: Negation, conjunction, disjunction, implication (and biimplication)** — as the answer to: Where does Indonesia teach this?
**Answer: False — Grade 10 SMK Semester 1, Bab 1 A–B — propositions and connectives**
