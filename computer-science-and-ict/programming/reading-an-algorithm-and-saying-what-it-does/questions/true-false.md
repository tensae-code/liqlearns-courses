# Reading an Algorithm and Saying What It Does — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What do you note first in an unfamiliar algorithm?" is: Its inputs — what it asks for at the start**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is a trace?" is: Small, easy values**
**Answer: False** — Writing down each variable's value as it changes, step by step

**3. (Sub lesson 1) True or false: the answer to "Which values should a first trace use?" is: Small, easy values**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What two structures must you note as you read?" is: Guessing**
**Answer: False** — Every decision and its branch condition, and every loop and what stops it

**5. (Sub lesson 1) True or false: the answer to "Reading without a trace is…" is: Guessing**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How do you find the task an algorithm performs?" is: In one plain sentence naming the inputs and the result**
**Answer: False** — Compare what went in with what came out, across several traces

**7. (Sub lesson 2) True or false: the answer to "How should the task be said?" is: In one plain sentence naming the inputs and the result**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How do you check your sentence about the task?" is: One trace shows one case; the pattern across traces shows the task**
**Answer: False** — Run one more value and see whether the algorithm does exactly what it promises

**9. (Sub lesson 2) True or false: the answer to "Why trace more than one input?" is: One trace shows one case; the pattern across traces shows the task**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What must your sentence not claim?" is: Its inputs — what it asks for at the start**
**Answer: False** — More — or less — than the algorithm actually does
