# Open Roberta Lab — Programming a Virtual Robot — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is Open Roberta Lab?**
**Answer: A browser home for programming a virtual (simulated LEGO) robot**

**2. (Sub lesson 1) What is the robot idea, in the book's terms?**
**Answer: A machine that senses, decides and acts**

**3. (Sub lesson 1) Why begin in simulation?**
**Answer: Mistakes cost nothing — a crash is a lesson, not a repair bill**

**4. (Sub lesson 1) Name the three block families taught first.**
**Answer: Action, Logic and Math**

**5. (Sub lesson 1) What do Action blocks hold?**
**Answer: What the robot does — drive, turn, stop**

**6. (Sub lesson 2) Name the two first missions.**
**Answer: Move and Rectangular**

**7. (Sub lesson 2) What is a mission?**
**Answer: A set task in the simulation the robot must drive truly**

**8. (Sub lesson 2) What do export and import do?**
**Answer: Save a program as a file, share it, and bring it back**

**9. (Sub lesson 2) Where does this unit sit in the series?**
**Answer: Grade 6's robotics unit — every later robotics lesson works in this lab**

**10. (Sub lesson 2) Which book teaches this?**
**Answer: Kuwait Grade 6 Digital Intelligence Term 1, Unit 3**
