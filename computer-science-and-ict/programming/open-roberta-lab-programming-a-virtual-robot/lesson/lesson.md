# Open Roberta Lab — Programming a Virtual Robot

## Do it first

Kuwait's robotics strand begins off the floor: in a simulation, where the robot is virtual and mistakes cost nothing. The Grade 6 book opens its robotics unit in Open Roberta Lab. This lesson is that world and its first missions.

## Sub lesson 1 — The virtual robot — LEGO simulation in Open Roberta Lab

**Open Roberta Lab (ORL)** is a browser home for programming a **virtual robot** — a LEGO robot that lives in a **simulation**: it drives, turns and senses on screen exactly as its program commands, and a crash is a lesson, not a repair bill. The unit begins with the **robot idea** itself — a machine that senses, decides and acts — then meets the lab where every later robotics lesson in the series will work.

[Picture — The virtual robot — LEGO simulation in Open Roberta Lab]

## Sub lesson 2 — Block families and first missions — Move and Rectangular, export and import

ORL programs are built from block families the book names: **Action** blocks (what the robot does — drive, turn, stop), **Logic** blocks (its decisions) and **Math** blocks (its numbers). The first **missions** are set tasks in the simulation — **Move** and **Rectangular** — each a small course the robot must drive truly. Programs are **exported and imported** as files, so a mission's solution can be saved, shared and brought back — real program handling from the first lesson.
