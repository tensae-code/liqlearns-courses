# Information Models — Describing the World — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a model?" is: A stand-in for a real thing, made to be studied instead of it.**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is an information model?" is: How the thing looks, in images or film.**
**Answer: False** — A stand-in made of information, keeping only the features that matter for the purpose.

**3. (Sub lesson 1) True or false: the answer to "Can the same original have many information models?" is: Yes — different purposes keep different features.**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does a verbal model do?" is: By the purpose it must serve.**
**Answer: False** — Describes the thing in words.

**5. (Sub lesson 1) True or false: the answer to "What does a formula model do?" is: Describes with mathematical formulas, so values can be calculated.**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does a video/pictorial model keep?" is: The features that do not matter for its purpose.**
**Answer: False** — How the thing looks, in images or film.

**7. (Sub lesson 2) True or false: the answer to "What does a scheme model show?" is: The structure — parts and connections — while dropping appearance.**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How is the model's form chosen?" is: A stand-in made of information, keeping only the features that matter for the purpose.**
**Answer: False** — By the purpose it must serve.

**9. (Sub lesson 2) True or false: the answer to "Give an example of an information model." is: A timetable, a map, or a formula.**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What does a model leave out?" is: Describes the thing in words.**
**Answer: False** — The features that do not matter for its purpose.
