# Hands-on — Programming a Tic-Tac-Toe Game in Python

The lesson with your hands and your feet, not only your eyes.

## Task one
**Build the board game** — Program two-player tic-tac-toe in Python: board display, legal-move checks, win and draw tests.

## Task two
**Add the brain** — Add the minimax opponent; play ten games against it and record the outcomes as evidence for or against 'never loses'.
