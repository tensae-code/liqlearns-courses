# Programming a Tic-Tac-Toe Game in Python — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Nine cells in a list — empty, X or O**
**Answer: True**

**2. (Sub lesson 1) True or false: Nine cells in a list — empty, X or O** — as the answer to: Name the program's five workings.
**Answer: False — Display, take a move, place the mark, test the end, change the turn**

**3. (Sub lesson 1) True or false: Occupied cells and moves outside the board**
**Answer: True**

**4. (Sub lesson 1) True or false: Occupied cells and moves outside the board** — as the answer to: What lines win?
**Answer: False — Rows, columns and diagonals**

**5. (Sub lesson 1) True or false: A draw**
**Answer: True**

**6. (Sub lesson 2) True or false: A draw** — as the answer to: What chooses the computer's move?
**Answer: False — Adversarial search — minimax**

**7. (Sub lesson 2) True or false: The computer is MAX; the player is MIN**
**Answer: True**

**8. (Sub lesson 2) True or false: The computer is MAX; the player is MIN** — as the answer to: Why can this tree be searched whole?
**Answer: False — Tic-tac-toe is small enough**

**9. (Sub lesson 2) True or false: The minimax opponent never loses**
**Answer: True**

**10. (Sub lesson 2) True or false: The minimax opponent never loses** — as the answer to: Why does Jordan choose this game?
**Answer: False — The search theory becomes an opponent testable by your own hand**
