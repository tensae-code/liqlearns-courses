# Controlling a Program by Changing the Backdrop — true or false

Say whether each statement is true or false.

**1. A backdrop switch can start scripts without any click.**
**Answer: True** — The change of backdrop is itself an event.

**2. Every backdrop-switch script runs on every switch.**
**Answer: False** — Each names one backdrop and runs only on that switch.

**3. Backdrop control replaces scenes having their own sprites appear and act.**
**Answer: False** — It is what makes a scene's sprites appear and act at the right moment.
