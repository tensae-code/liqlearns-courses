# Controlling a Program by Changing the Backdrop — multiple choice

Pick the one right answer.

**1. The when-backdrop-switches event starts its script when —**
a) The green flag is clicked  b) The stage switches to the named backdrop  c) A sound ends
**Answer: b) The stage switches to the named backdrop** — The backdrop change itself is the signal.

**2. Scripts waiting on a different backdrop's event, when the stage switches elsewhere, —**
a) All run anyway  b) Stay asleep  c) Are deleted
**Answer: b) Stay asleep** — Only the named backdrop's scripts wake.

**3. Backdrop control is most useful in a project with —**
a) One still picture  b) Several scenes or places  c) No sprites
**Answer: b) Several scenes or places** — One switch per scene controls each scene.

**4. To wake the forest scripts, the stage must —**
a) Switch to the forest backdrop  b) Stop all sounds  c) Hide every sprite
**Answer: a) Switch to the forest backdrop** — The switch to that backdrop is their event.
