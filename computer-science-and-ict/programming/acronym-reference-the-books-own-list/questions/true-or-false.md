# Acronym reference — the book's own list — tf

Say whether each statement is true or false.

**1.** True or false: INSA — Information Network Security Agency.
**Answer: True**

**2.** True or false: SQL — Structured Query Language.
**Answer: True**

**3.** True or false: NIC is the opposite: it has nothing to do with Network Interface Card.
**Answer: False** — NIC is about Network Interface Card.
