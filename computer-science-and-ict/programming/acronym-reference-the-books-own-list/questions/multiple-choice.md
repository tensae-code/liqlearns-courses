# Acronym reference — the book's own list — multiple choice

Pick the one right answer.

**1.** What is INSA?
a) Information Network Security Agency  b) Structured Query Language  c) Network Interface Card  d) Network-attached storage
**Answer: a) Information Network Security Agency**

**2.** What is SQL?
a) Information Network Security Agency  b) Network Interface Card  c) Network-attached storage  d) Structured Query Language
**Answer: d) Structured Query Language**

**3.** What is NIC?
a) Structured Query Language  b) Network-attached storage  c) Network Interface Card  d) Information Network Security Agency
**Answer: c) Network Interface Card**

**4.** What is NAS?
a) Network Interface Card  b) Network-attached storage  c) Information Network Security Agency  d) Structured Query Language
**Answer: b) Network-attached storage**

**5.** CBE expands to —
a) Central Bank of Ethiopia  b) Commercial Bank of Ethiopia  c) Computer Bureau of Ethiopia  d) Communication Bank of Ethiopia
**Answer: b) Commercial Bank of Ethiopia** — the annex prints Commercial Bank of Ethiopia.

**6.** PPI is —
a) Pixels Per Image  b) Pixel Per Inch  c) Points Per Inch  d) Picture Print Index
**Answer: b) Pixel Per Inch**
