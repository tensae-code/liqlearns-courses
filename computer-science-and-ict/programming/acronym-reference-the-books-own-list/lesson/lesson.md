# Acronym reference — the book's own list

## Do it first

Seventeen short names have followed you through this course — in banks, networks, security and databases. Some you could expand in your sleep; some you have only ever met as letters. This reference lesson gathers the book's own annex list in one place, so every short name can be opened.

## The list, first part

ATM — Automated Teller Machine. CBE — Commercial Bank of Ethiopia. CIA — confidentiality, integrity and availability. CPU — Central Processing Unit. DVD — Digital Video Disc / Digital Versatile Disc. HTTP — Hypertext Transfer Protocol. ICT — Information Communication Technology. INSA — Information Network Security Agency.

## The list, second part

LAN — Local Area Network. MAN — Metropolitan Area Network. NAS — Network-attached storage. NIC — Network Interface Card. PAN — Personal Area Network. PPI — Pixel Per Inch. SQL — Structured Query Language. USB — Universal Serial Bus. UTP — Unshielded Twisted Pair. WAN — Wide Area Network. Keep this lesson as the course's pocket card: when a short name stops you in any lesson, it opens here.

## Say it to your companion

Tell your companion, in your own words: the book's closing annex expands its own abbreviations — ATM, CBE, CIA, CPU, INSA, SQL and the rest — as a pocket reference for the whole course. Then name the key words of this lesson — INSA, SQL, NIC, NAS — and say what each one means.

## Do It Yourself

1. Write the full list from memory, then check it against the lesson.
2. Match each acronym to its unit: files, networks, security, programming, images.
3. Explain DVD's two printed expansions.
