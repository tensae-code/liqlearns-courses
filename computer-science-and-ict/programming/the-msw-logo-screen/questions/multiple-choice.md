# The MSW Logo screen — graphics window and Commander — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The graphics screen is where —
a) commands are typed  b) pictures are drawn  c) files are saved  d) passwords are kept
**Answer: b) pictures are drawn** — drawing happens on the main screen.

**2. (Sub lesson 1)** Commands are given in the —
a) graphics screen  b) Commander window  c) title bar  d) button bar
**Answer: b) Commander window** — the Commander window.

**3. (Sub lesson 2)** The turtle is —
a) a real animal  b) the triangle at the centre of the graphics screen  c) a menu  d) a file
**Answer: b) the triangle at the centre of the graphics screen** — the triangle at the centre.

**4. (Sub lesson 2)** A command is typed in the —
a) list box  b) command input box  c) title bar  d) graphics screen
**Answer: b) command input box** — the input box, run with Execute or Enter.

**5. (Sub lesson 2)** The list box records —
a) only errors  b) executed commands and messages  c) passwords  d) pictures
**Answer: b) executed commands and messages** — the output/command-recall list.

**6. (Sub lesson 2)** Another name for a LOGO command is —
a) a primitive  b) a procedure only  c) a pixel  d) a listener
**Answer: a) a primitive** — primitive — the guide's fact.
