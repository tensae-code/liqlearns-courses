# The MSW Logo screen — graphics window and Commander — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** The Commander window is where pictures are drawn.
**Answer: False** — pictures are drawn on the graphics screen; the Commander gives commands.

**2. (Sub lesson 2)** Commands can be run with the Execute button or Enter.
**Answer: True** — both run a typed command.

**3. (Sub lesson 2)** A hidden turtle can be brought back with the show-turtle command.
**Answer: True** — the guide's keyed fact.
