# Hands-on — CSS — Styling a Web Page

The lesson with your hands and your feet, not only your eyes.

## Task one
('One rule, many changes', 'Take a plain HTML page. Write one external CSS rule for its headings and one for its background. Change the rule's value and watch every heading obey.')

## Task two
('Three homes', 'Style the same paragraph three ways — inline, internal and external. Say which won, and explain the order of strength.')
