## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The style rule — selector, property, value** — A CSS **style rule** has three parts: the **selector** names what is styled (a tag, a class, an id), the **property** names the feature (colour, size, background), and the **value** says how (red, 14 points, an image). Written `selector { property: value; }`, one rule can restyle every matching element on the page at once — the whole power of CSS is in that 'at once': change the rule, and every paragraph wearing it changes together.
2. **Three homes for styles — and the first properties** — Styles can live in three places: **inline**, inside one element's own attribute — strongest, but scattered; **internal**, in a style block in the page's head — ruling that page only; and **external**, in a separate .css file linked by many pages — the way a whole site is dressed from one file. The book's first working properties are **font** properties (family, size, style, weight) and **background** properties (colour and image) — enough to take a page from default grey to designed, which is where the pupils' sites go next.
