# CSS — Styling a Web Page — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What three parts has a style rule?" is: Selector, property and value**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does the selector name?" is: One rule restyles every matching element at once**
**Answer: False** — What is styled — a tag, a class or an id

**3. (Sub lesson 1) True or false: the answer to "What is CSS's whole power, in the lesson's phrase?" is: One rule restyles every matching element at once**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Name the three places styles can live." is: Internal — a style block in the page's head**
**Answer: False** — Inline, internal and external

**5. (Sub lesson 1) True or false: the answer to "Which style home rules only one page?" is: Internal — a style block in the page's head**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Which style home dresses a whole site from one file?" is: Inline styles**
**Answer: False** — External — a separate .css file linked by many pages

**7. (Sub lesson 2) True or false: the answer to "Which is strongest but scattered?" is: Inline styles**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Name the book's first property families." is: Family, size, style and weight of text**
**Answer: False** — Font properties and background properties

**9. (Sub lesson 2) True or false: the answer to "What do font properties govern?" is: Family, size, style and weight of text**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "In which book does CSS appear?" is: Selector, property and value**
**Answer: False** — Mongolia's Grade 11 IT book, in its web-technology chapter
