# CSS — Styling a Web Page — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What three parts has a style rule?**
a) Selector, property and value  b) What is styled — a tag, a class or an id  c) One rule restyles every matching element at once  d) Inline, internal and external
**Answer: a) Selector, property and value**

**2. (Sub lesson 1) What does the selector name?**
a) One rule restyles every matching element at once  b) What is styled — a tag, a class or an id  c) Inline, internal and external  d) Internal — a style block in the page's head
**Answer: b) What is styled — a tag, a class or an id**

**3. (Sub lesson 1) What is CSS's whole power, in the lesson's phrase?**
a) Inline, internal and external  b) Internal — a style block in the page's head  c) One rule restyles every matching element at once  d) External — a separate .css file linked by many pages
**Answer: c) One rule restyles every matching element at once**

**4. (Sub lesson 1) Name the three places styles can live.**
a) Internal — a style block in the page's head  b) External — a separate .css file linked by many pages  c) Inline styles  d) Inline, internal and external
**Answer: d) Inline, internal and external**

**5. (Sub lesson 1) Which style home rules only one page?**
a) Internal — a style block in the page's head  b) External — a separate .css file linked by many pages  c) Inline styles  d) Font properties and background properties
**Answer: a) Internal — a style block in the page's head**

**6. (Sub lesson 2) Which style home dresses a whole site from one file?**
a) Inline styles  b) External — a separate .css file linked by many pages  c) Font properties and background properties  d) Family, size, style and weight of text
**Answer: b) External — a separate .css file linked by many pages**

**7. (Sub lesson 2) Which is strongest but scattered?**
a) Font properties and background properties  b) Family, size, style and weight of text  c) Inline styles  d) Mongolia's Grade 11 IT book, in its web-technology chapter
**Answer: c) Inline styles**

**8. (Sub lesson 2) Name the book's first property families.**
a) Family, size, style and weight of text  b) Mongolia's Grade 11 IT book, in its web-technology chapter  c) Selector, property and value  d) Font properties and background properties
**Answer: d) Font properties and background properties**

**9. (Sub lesson 2) What do font properties govern?**
a) Family, size, style and weight of text  b) Mongolia's Grade 11 IT book, in its web-technology chapter  c) Selector, property and value  d) What is styled — a tag, a class or an id
**Answer: a) Family, size, style and weight of text**

**10. (Sub lesson 2) In which book does CSS appear?**
a) Selector, property and value  b) Mongolia's Grade 11 IT book, in its web-technology chapter  c) What is styled — a tag, a class or an id  d) One rule restyles every matching element at once
