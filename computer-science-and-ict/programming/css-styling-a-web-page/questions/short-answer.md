# CSS — Styling a Web Page — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What three parts has a style rule?**
**Answer: Selector, property and value**

**2. (Sub lesson 1) What does the selector name?**
**Answer: What is styled — a tag, a class or an id**

**3. (Sub lesson 1) What is CSS's whole power, in the lesson's phrase?**
**Answer: One rule restyles every matching element at once**

**4. (Sub lesson 1) Name the three places styles can live.**
**Answer: Inline, internal and external**

**5. (Sub lesson 1) Which style home rules only one page?**
**Answer: Internal — a style block in the page's head**

**6. (Sub lesson 2) Which style home dresses a whole site from one file?**
**Answer: External — a separate .css file linked by many pages**

**7. (Sub lesson 2) Which is strongest but scattered?**
**Answer: Inline styles**

**8. (Sub lesson 2) Name the book's first property families.**
**Answer: Font properties and background properties**

**9. (Sub lesson 2) What do font properties govern?**
**Answer: Family, size, style and weight of text**

**10. (Sub lesson 2) In which book does CSS appear?**
**Answer: Mongolia's Grade 11 IT book, in its web-technology chapter**
