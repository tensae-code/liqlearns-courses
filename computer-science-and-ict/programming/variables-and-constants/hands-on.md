# Hands-on — Variables and Constants

The lesson with your hands and your feet, not only your eyes.

## Task one
('Sort the stores', 'For a quiz program, sort these into variable or constant and defend each: current question number, questions per game, player's name, points per correct answer, player's score, highest possible score.')

## Task two
('One home', 'Write a segment that uses the passing mark three times as a bare 50, then rewrite it with PASS_MARK named once. Change the mark to 60 in both versions and count the edits.')
