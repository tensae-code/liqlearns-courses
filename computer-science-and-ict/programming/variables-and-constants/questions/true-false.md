# Variables and Constants — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a variable?" is: A named store whose value can change while the program runs**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is a constant (pemalar)?" is: By assigning — score = 0; its type follows the value**
**Answer: False** — A named store whose value is fixed when set and must not change during the run

**3. (Sub lesson 1) True or false: the answer to "How is a variable made in Python?" is: By assigning — score = 0; its type follows the value**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How is a variable declared in Java?" is: It is replaced entirely — gone unless copied elsewhere first**
**Answer: False** — With its type — int score = 0;

**5. (Sub lesson 1) True or false: the answer to "What happens to a variable's old value on assignment?" is: It is replaced entirely — gone unless copied elsewhere first**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Give two examples of constants." is: By the capital-name convention — a programmer's promise**
**Answer: False** — Pi; the passing mark (also: days in a week)

**7. (Sub lesson 2) True or false: the answer to "How does Python mark a constant?" is: By the capital-name convention — a programmer's promise**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How does Java guard a constant?" is: So fixed values have one home — change the rule once and every use follows**
**Answer: False** — With the keyword final — enforced by the compiler

**9. (Sub lesson 2) True or false: the answer to "Why do constants exist?" is: So fixed values have one home — change the rule once and every use follows**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What would a changeable constant be?" is: A named store whose value can change while the program runs**
**Answer: False** — A variable wearing a false name
