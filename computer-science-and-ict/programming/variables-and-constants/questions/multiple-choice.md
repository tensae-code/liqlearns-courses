# Variables and Constants — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a variable?**
a) A named store whose value can change while the program runs  b) A named store whose value is fixed when set and must not change during the run  c) By assigning — score = 0; its type follows the value  d) With its type — int score = 0;
