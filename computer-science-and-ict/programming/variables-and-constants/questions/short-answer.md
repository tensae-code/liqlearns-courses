# Variables and Constants — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a variable?**
**Answer: A named store whose value can change while the program runs**

**2. (Sub lesson 1) What is a constant (pemalar)?**
**Answer: A named store whose value is fixed when set and must not change during the run**

**3. (Sub lesson 1) How is a variable made in Python?**
**Answer: By assigning — score = 0; its type follows the value**

**4. (Sub lesson 1) How is a variable declared in Java?**
**Answer: With its type — int score = 0;**

**5. (Sub lesson 1) What happens to a variable's old value on assignment?**
**Answer: It is replaced entirely — gone unless copied elsewhere first**

**6. (Sub lesson 2) Give two examples of constants.**
**Answer: Pi; the passing mark (also: days in a week)**

**7. (Sub lesson 2) How does Python mark a constant?**
**Answer: By the capital-name convention — a programmer's promise**

**8. (Sub lesson 2) How does Java guard a constant?**
**Answer: With the keyword final — enforced by the compiler**

**9. (Sub lesson 2) Why do constants exist?**
**Answer: So fixed values have one home — change the rule once and every use follows**

**10. (Sub lesson 2) What would a changeable constant be?**
**Answer: A variable wearing a false name**
