# Abstraction — Choosing the Important Aspects — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What problem does abstraction answer?" is: A situation carries more detail than any decision needs**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is abstraction?" is: Eater numbers and spoon size — not the colour of the stall cloth**
**Answer: False** — Deliberately choosing the important aspects for the purpose at hand and setting the rest aside

**3. (Sub lesson 1) True or false: the answer to "In the filling decision, which aspects matter?" is: Eater numbers and spoon size — not the colour of the stall cloth**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Is the choice of aspects the same for every decision?" is: Holding all details at once makes the problem unsolvable**
**Answer: False** — No — it is purpose-shaped; a different decision chooses differently

**5. (Sub lesson 1) True or false: the answer to "What makes clutter dangerous?" is: Holding all details at once makes the problem unsolvable**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "On what is the decision then made?" is: Only if changing it would change the decision**
**Answer: False** — On the chosen aspects alone

**7. (Sub lesson 2) True or false: the answer to "When is an aspect kept?" is: Only if changing it would change the decision**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is done with the dropped aspects?" is: So a wrong outcome can be traced to a wrong choice of aspects and repaired**
**Answer: False** — They are named as dropped — the choice stays on record

**9. (Sub lesson 2) True or false: the answer to "Why keep the choice on record?" is: So a wrong outcome can be traced to a wrong choice of aspects and repaired**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Is abstraction ignoring the world?" is: A situation carries more detail than any decision needs**
**Answer: False** — No — it is choosing which parts of the world this decision will stand on
