# Flowchart or pseudocode — two notations for one algorithm — tf

Say whether each statement is true or false.

**1.** True or false: a flowchart — an algorithm written in special shapes for different actions, with lines and arrows showing sequence and relationships.
**Answer: True**

**2.** True or false: pseudocode — a simple, concise sequence of English-like instructions.
**Answer: True**

**3.** True or false: flowchart's strength is the opposite: it has nothing to do with visually appealing and can be easier to understand.
**Answer: False** — flowchart's strength is about visually appealing and can be easier to understand.
