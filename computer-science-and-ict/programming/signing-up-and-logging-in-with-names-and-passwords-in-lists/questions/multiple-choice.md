# Signing Up and Logging In — Names and Passwords in Lists — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Where are subscriber names kept?**
a) In one list  b) In a second list, at the same positions  c) It is refused  d) The name’s position in the names list
**Answer: a) In one list**

**2. (Sub lesson 1) Where are their passwords kept?**
a) Position 4’s password belongs to position 4’s name  b) In a second list, at the same positions  c) Because one position must mean one person  d) The password stored at that position
**Answer: b) In a second list, at the same positions**

**3. (Sub lesson 1) What does “same positions” mean?**
a) It is refused  b) The name’s position in the names list  c) Position 4’s password belongs to position 4’s name  d) The background
**Answer: c) Position 4’s password belongs to position 4’s name**

**4. (Sub lesson 1) What happens to a name already taken?**
a) Because one position must mean one person  b) The password stored at that position  c) They delete the name and force a new registration  d) It is refused
**Answer: d) It is refused**

**5. (Sub lesson 1) Why must a taken name be refused?**
a) Because one position must mean one person  b) The name’s position in the names list  c) The background  d) A library sign-up and login system
**Answer: a) Because one position must mean one person**

**6. (Sub lesson 2) What does login find first?**

**7. (Sub lesson 2) What does login check next?**

a) They delete the name and force a new registration  b) In one list  c) Position 4’s password belongs to position 4’s name  d) The background

a) They delete the name and force a new registration  b) A library sign-up and login system  c) In a second list, at the same positions  d) It is refused

**10. (Sub lesson 2) What kind of system is this lesson’s build?**
