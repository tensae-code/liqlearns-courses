# Signing Up and Logging In — Names and Passwords in Lists — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Where are subscriber names kept?" is: In one list**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Where are their passwords kept?" is: It is refused**
**Answer: False** — In a second list, at the same positions

**3. (Sub lesson 1) True or false: the answer to "What does “same positions” mean?" is: Position 4’s password belongs to position 4’s name**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What happens to a name already taken?" is: The name’s position in the names list**
**Answer: False** — It is refused

**5. (Sub lesson 1) True or false: the answer to "Why must a taken name be refused?" is: Because one position must mean one person**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does login find first?" is: The background**
