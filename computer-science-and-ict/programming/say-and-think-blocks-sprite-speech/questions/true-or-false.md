# Say and Think Blocks — Sprite Speech — true or false

Say whether each statement is true or false.

**1. Make a sprite say a typed sentence in a speech bubble.**
**Answer: True** — This is one of the lesson's own outcomes.

**2. Say and think blocks do the same thing, so it never matters which one you pick.**
**Answer: False** — The lesson teaches the opposite of this.

**3. Make a sprite think a sentence in a thought bubble.**
**Answer: True** — This is one of the lesson's own outcomes.
