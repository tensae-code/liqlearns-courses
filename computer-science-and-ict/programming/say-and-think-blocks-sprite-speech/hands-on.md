# Hands-on — Say and Think Blocks — Sprite Speech

The lesson with your hands, not only your eyes.

## Say it, think it
Write one line for a sprite to say and one to think. Run them and have a partner read both aloud — then say which the other characters "heard".

## Type the exact words
Type a sentence with a name in it into a say block. Change only the name, run again, and check the bubble changed exactly as typed.
