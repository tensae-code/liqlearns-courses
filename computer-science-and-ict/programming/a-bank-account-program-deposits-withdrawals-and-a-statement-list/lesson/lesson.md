# A Bank Account Program — Deposits, Withdrawals and a Statement List

## Do it first

Deposit, withdraw, and prove it. Grade 9 builds a working current account in Scratch — with the bank’s own rule enforced first: no withdrawal the balance cannot cover.

## Sub lesson 1 — Amount, deposit, balance, choice — and the balance check

Four variables run the account: **amount, deposit, balance, choice**. The deposit adds; the withdrawal is guarded — it **first checks the balance covers it**, and if it does not, the program answers **“insufficient balance”** and pays nothing. The check comes before the money moves, as in a real bank.

## Sub lesson 2 — The statement list

**Every operation is recorded in a statement list**, **withdrawals as negative amounts**, deposits as positive — so the list reads as the account’s history in order. On request the program shows **an account statement**: the recorded operations, presented to the account holder.

## Say it to your companion

Tell your companion, in your own words: The bank program runs on variables amount, deposit, balance and choice: a withdrawal first checks the balance covers it, else reports “insufficient balance”; every operation is recorded in a statement list, withdrawals as negative amounts, and a statement is shown on request. Then let your companion ask you one question about it — and answer from the lesson, not from memory of the book's exact words.
