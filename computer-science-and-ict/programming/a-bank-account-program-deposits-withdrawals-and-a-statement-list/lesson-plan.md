# Lesson plan — A Bank Account Program — Deposits, Withdrawals and a Statement List

**Course:** Computer Science and ICT · **Title:** Programming · **Lesson:** A Bank Account Program — Deposits, Withdrawals and a Statement List
**Place in the curriculum:** ICT expansion — Palestine (2026-11-14) — in the title Programming on the ICT course ladder (TITLES.md). Built new from Palestine's Grade 9 Programming student book, because no existing lesson in the course covers this thing as its own lesson.
**The one thing this lesson teaches:** The bank program runs on variables amount, deposit, balance and choice: a withdrawal first checks the balance covers it, else reports “insufficient balance”; every operation is recorded in a statement list, withdrawals as negative amounts, and a statement is shown on request.
**This lesson's own level:** It stands on the earlier lessons of its title and on the book's own order — it follows the book's lessons in sequence, so its neighbours in the book are its natural companions. It stands alone for a learner landing on it directly.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Amount, deposit, balance, choice — and the balance check** — Four variables run the account: **amount, deposit, balance, choice**. The deposit adds; the withdrawal is guarded — it **first checks the balance covers it**, and if it does not, the program answers **“insufficient balance”** and pays nothing. The check comes before the money moves, as in a real bank.
2. **The statement list** — **Every operation is recorded in a statement list**, **withdrawals as negative amounts**, deposits as positive — so the list reads as the account’s history in order. On request the program shows **an account statement**: the recorded operations, presented to the account holder.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
