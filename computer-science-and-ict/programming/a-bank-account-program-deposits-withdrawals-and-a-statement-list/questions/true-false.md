# A Bank Account Program — Deposits, Withdrawals and a Statement List — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What four variables run the account?" is: Amount, deposit, balance and choice**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does a withdrawal check first?" is: No — it pays nothing**
**Answer: False** — That the balance covers it

**3. (Sub lesson 1) True or false: the answer to "What does the program answer if it does not?" is: “Insufficient balance”**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Does the money move when the check fails?" is: In a statement list**
**Answer: False** — No — it pays nothing

**5. (Sub lesson 1) True or false: the answer to "When does the check happen?" is: Before the money moves**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Where is every operation recorded?" is: As positive amounts**
**Answer: False** — In a statement list

**7. (Sub lesson 2) True or false: the answer to "How are withdrawals recorded?" is: As negative amounts**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How are deposits recorded?" is: An account statement**
**Answer: False** — As positive amounts

**9. (Sub lesson 2) True or false: the answer to "What does the statement list read as?" is: The account’s history in order**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is shown on request?" is: That the balance covers it**
**Answer: False** — An account statement
