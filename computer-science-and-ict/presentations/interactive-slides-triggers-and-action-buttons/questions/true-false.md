# Interactive Slides — Triggers and Action Buttons — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A shape on a slide that does something when clicked during the show**
**Answer: True**

**2. (Sub lesson 1) True or false: A shape on a slide that does something when clicked during the show** — as the answer to: What can a click do?
**Answer: False — Jump to another slide, return home, open a link, or play a sound**

**3. (Sub lesson 1) True or false: The ready-made action shapes — and any picture or shape**
**Answer: True**

**4. (Sub lesson 1) True or false: The ready-made action shapes — and any picture or shape** — as the answer to: What does interactivity turn a presentation into?
**Answer: False — A stand the visitor drives, not a lecture**

**5. (Sub lesson 1) True or false: When the button is clicked while the show runs**
**Answer: True**

**6. (Sub lesson 2) True or false: When the button is clicked while the show runs** — as the answer to: What is a trigger?
**Answer: False — An animation set to start when a chosen object is clicked**

**7. (Sub lesson 2) True or false: An interactive game on slides — attracting customers at the tourism fair**
**Answer: True**

**8. (Sub lesson 2) True or false: An interactive game on slides — attracting customers at the tourism fair** — as the answer to: What happens on a wrong choice in the game?
**Answer: False — It shakes or vanishes; the right one celebrates**

**9. (Sub lesson 2) True or false: Add the animation, then set it to start on click of the chosen object**
**Answer: True**

**10. (Sub lesson 2) True or false: Add the animation, then set it to start on click of the chosen object** — as the answer to: What must the audience always know?
**Answer: False — What can be clicked — unseen interactivity is only decoration**
