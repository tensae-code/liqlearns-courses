# Tables and charts on slides — multiple choice

Pick the one right answer.

**1.** In the Insert Table dialog you set —
a) the theme and fonts  b) the columns and rows  c) the timings  d) the background
**Answer: b) the columns and rows** — Then click OK.

**2.** Table design and layout are edited on —
a) Chart Tools  b) Table Tools  c) SmartArt Tools  d) Drawing Tools only
**Answer: b) Table Tools** — A contextual tab.

**3.** To insert a chart you first —
a) type all the data  b) choose the chart type and click OK  c) hide the slide  d) print the deck
**Answer: b) choose the chart type and click OK**

**4.** Clicking a chart on the slide activates —
a) Table Tools  b) Chart Tools  c) the Slide Show  d) Notes Page
**Answer: b) Chart Tools** — For editing data and changing layouts and styles.
