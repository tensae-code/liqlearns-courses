# Creating a slide master — multiple choice

Pick the one right answer.

**1.** The slide master is —
a) the last slide  b) the top slide of the hierarchy  c) a handout  d) a chart
**Answer: b) the top slide of the hierarchy**

**2.** Slide Master view is opened from —
a) the Insert tab  b) the View tab  c) the Data tab  d) the Home tab
**Answer: b) the View tab**

**3.** An unwanted built-in layout is removed by —
a) Delete Layout in the right-click menu  b) Esc  c) Save As  d) Apply to All
**Answer: a) Delete Layout in the right-click menu**

**4.** The master is saved with type —
a) PDF  b) PowerPoint Template  c) Word document  d) Picture
**Answer: b) PowerPoint Template**

**5.** One edit on the master governs —
a) one slide  b) every slide  c) only the title slide  d) the notes only
**Answer: b) every slide**
