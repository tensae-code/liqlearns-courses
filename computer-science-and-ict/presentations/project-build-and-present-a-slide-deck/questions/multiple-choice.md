# Project: build and present a slide deck — multiple choice

Pick the one right answer.

**1.** In the book's example, the group presentation's theme is changed to —
a) Integral  b) Damask  c) Facet  d) Metro
**Answer: b) Damask** — The tourism project's theme is Integral.

**2.** The outline goes on —
a) slide 1  b) slide 2  c) the last slide  d) a notes page only
**Answer: b) slide 2** — The first slide's layout is changed.

**3.** The group presentation's background is —
a) black, Style 2  b) white, Style 1  c) a photograph  d) a gradient
**Answer: b) white, Style 1**

**4.** The tourism deck uses the ___ theme.
a) Damask  b) Integral  c) Office  d) Wood
**Answer: b) Integral** — With Background Style 2 and a two-content layout.

**5.** The tourism list is converted with SmartArt to —
a) a timeline  b) a Vertical Bulleted List  c) an organisation chart  d) a cycle
**Answer: b) a Vertical Bulleted List**

**6.** The finished file is saved in —
a) Desktop  b) a new Presentation Project folder in Documents  c) Downloads  d) the Recycle Bin
**Answer: b) a new Presentation Project folder in Documents** — Sources are acknowledged, too.
