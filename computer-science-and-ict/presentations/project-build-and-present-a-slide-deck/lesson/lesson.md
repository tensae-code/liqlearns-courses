# Project: build and present a slide deck

## Do it first

Everything in the presentation lessons now comes together in two real builds. First, a group presentation on a topic your group chooses — road traffic and safety, a local tourism resource, child trafficking, or consumer protection. Then one deck built to an exact specification: Tourism Resources of Ethiopia. Build both, then stand up and run them.

## The group presentation — Practical Exercise 3.7

Choose the group's topic, then complete the set tasks:

1. **Change the first slide's layout.**
2. Put the **outline on slide 2**.
3. **Change the theme** (to **Damask** in the book's example).
4. Set the **background — white, Style 1**.
5. Use **Arrow Bullets** for the list.
6. **Insert a downloaded related image.**
7. **Acknowledge your sources.**
8. **Save the file in a new Presentation Project folder in Documents.**

## The Mini Project — Tourism Resources of Ethiopia

Build the deck to this full specification:

- **Two-content layout** — text plus picture.
- **Integral theme**.
- **Background Style 2**.
- A **bulleted list converted with SmartArt to a Vertical Bulleted List**.

## Running the finished deck

Run it **from the Slide Show tab**, advancing with **click, spacebar or Enter**, and exit with **Esc**.

## Say it to your companion

Tell your companion, in your own words: two builds close the unit: a group presentation to a set task list, and "Tourism Resources of Ethiopia" built to a full specification — then run from the Slide Show tab. Use the lesson's own words for the key names.

## Do It Yourself

1. Do the lesson's central doing again from the start, without looking — then check each step against the lesson.
2. Teach the doing to someone else, steps in order, while they follow on a real computer or phone.
3. Write the key steps from memory, numbered, in order.
