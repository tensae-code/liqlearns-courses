# Lesson plan — Project: build and present a slide deck

**Course:** Computer Science and ICT · **Title:** Presentations · **Lesson:** Project: build and present a slide deck
**Place in the curriculum:** Title — Presentations in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 9 book, Unit 3 — Application Software. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** two builds close the unit: a group presentation to a set task list, and "Tourism Resources of Ethiopia" built to a full specification — then run from the Slide Show tab.
**This lesson's own level:** it is a doing-lesson. It stands on Running a slide show; changing slide order.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
This lesson is one whole lesson — it has no sub lessons (a short, single-skill lesson; his ruling 2026-11-09).

## Before this lesson
- Recommended first: Running a slide show; changing slide order. Recommended, never forced.

## What the learner can do when it ends
1. Build the group presentation: change the first slide's layout, put the outline on slide 2, change the theme, set a background, use Arrow Bullets, insert a downloaded related image, acknowledge sources, and save into a new Presentation Project folder in Documents.
2. Build "Tourism Resources of Ethiopia" to its specification: two-content layout, Integral theme, Background Style 2, a bulleted list converted with SmartArt to a Vertical Bulleted List.
3. Run the finished deck from the Slide Show tab — advancing with click, spacebar or Enter, exiting with Esc.
## What you need
A computer with PowerPoint; a group for the first build.

## If the learner is stuck
- Loses the order of the steps → go back to the numbered steps in lesson/lesson.md and do them one at a time, saying each step aloud before doing it; the steps are never reordered.
- Works from memory instead of the screen → every result in this lesson can be checked on screen (a formula in its bar, a view by its name); check, do not guess.
