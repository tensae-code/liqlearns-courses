# Printing Handouts of Your Slides — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a handout?" is: The printed form of a presentation — slides set several to a page**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How many slides can a handout page hold?" is: It prints ruled lines beside each slide for the listener's notes**
**Answer: False** — One, two, three, four, six or nine

**3. (Sub lesson 1) True or false: the answer to "Why is three-per-page the classroom favourite?" is: It prints ruled lines beside each slide for the listener's notes**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is a handout chosen for?" is: No — its layout is designed for the reader, not only printed from the deck**
**Answer: False** — The audience's job — following the talk, taking notes, keeping a copy

**5. (Sub lesson 1) True or false: the answer to "Is a handout just the slides printed?" is: No — its layout is designed for the reader, not only printed from the deck**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is chosen first in the print settings?" is: Across then down, or down then across**
**Answer: False** — Handouts, instead of full-page slides

**7. (Sub lesson 2) True or false: the answer to "What order choice do multi-slide pages offer?" is: Across then down, or down then across**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is checked in the preview?" is: To catch mistakes before a whole class set spends paper and ink**
**Answer: False** — That slides are big enough to read and the header and footer are right

**9. (Sub lesson 2) True or false: the answer to "Why print one test page first?" is: To catch mistakes before a whole class set spends paper and ink**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What does Fiji close its presentation unit with?" is: The printed form of a presentation — slides set several to a page**
**Answer: False** — Printing the handouts
