# Building an Interactive Game With Hyperlinks

## Do it first

A presentation that only moves forward is a lecture. Link its slides by choices, and it becomes a game the player steers. This lesson builds that game. (This lesson stands on teacher-guide evidence only.)

## Sub lesson 1 — The game idea — slides as rooms, links as doors

In the Grade 4 guide's environment project, a PowerPoint presentation becomes an **interactive game**: each slide is a **place or a question**, and **hyperlinks** on its buttons, pictures or words are the **doors** — a chosen answer jumps to the slide that answers back (right: onward; wrong: a hint and a way back). The game's map is drawn first — slides as boxes, links as arrows — because a game whose map is not drawn will strand its players in rooms with no doors.

## Sub lesson 2 — Building it — links, fairness and testing

Building places a hyperlink on an object (select it, insert the link, choose the slide), keeps a **home slide** every path can return to, and makes wrong answers **teach rather than punish** (a hint, not a dead end). The project is tested as its players will play it — clicking everything, including the wrong things, in the wrong order — because an interactive game's faults live in its links, and only clicking finds them. The guide sets the project inside a maths environment (patterns and equations): the game is the subject practised by playing, which is the whole design's point.
