# Saving a Presentation in Other Formats — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Why save a presentation in other formats?" is: Because its own format opens only in its own program — other readers need forms they can open**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Which command saves in a new format?" is: The file opens straight into the slide show**
**Answer: False** — Save As

**3. (Sub lesson 1) True or false: the answer to "What does a PDF saving give the reader?" is: A document any computer can read and print, with the slides fixed as designed**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does saving as pictures give?" is: Someone who needs the slide inside other work**
**Answer: False** — Each slide as an image that can be placed in other work

**5. (Sub lesson 1) True or false: the answer to "What does saving as a show do?" is: The file opens straight into the slide show**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Who should receive a PDF?" is: The original editable deck — the master**
**Answer: False** — A reader who must only read the deck

**7. (Sub lesson 2) True or false: the answer to "Who should receive a slide as a picture?" is: Someone who needs the slide inside other work**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Who should receive the show format?" is: Because its own format opens only in its own program — other readers need forms they can open**
**Answer: False** — An audience, with no editing tools in the way

**9. (Sub lesson 2) True or false: the answer to "What is always kept besides the copies sent out?" is: The original editable deck — the master**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why keep the master?" is: A document any computer can read and print, with the slides fixed as designed**
**Answer: False** — So the deck can still be changed for next time
