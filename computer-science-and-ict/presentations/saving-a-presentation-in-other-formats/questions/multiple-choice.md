# Saving a Presentation in Other Formats — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Why save a presentation in other formats?**
a) Because its own format opens only in its own program — other readers need forms they can open  b) Save As  c) A document any computer can read and print, with the slides fixed as designed  d) Each slide as an image that can be placed in other work
**Answer: a) Because its own format opens only in its own program — other readers need forms they can open**

**2. (Sub lesson 1) Which command saves in a new format?**
a) A document any computer can read and print, with the slides fixed as designed  b) Save As  c) Each slide as an image that can be placed in other work  d) The file opens straight into the slide show
**Answer: b) Save As**

**3. (Sub lesson 1) What does a PDF saving give the reader?**
a) Each slide as an image that can be placed in other work  b) The file opens straight into the slide show  c) A document any computer can read and print, with the slides fixed as designed  d) A reader who must only read the deck
**Answer: c) A document any computer can read and print, with the slides fixed as designed**

**4. (Sub lesson 1) What does saving as pictures give?**
a) The file opens straight into the slide show  b) A reader who must only read the deck  c) Someone who needs the slide inside other work  d) Each slide as an image that can be placed in other work
**Answer: d) Each slide as an image that can be placed in other work**

**5. (Sub lesson 1) What does saving as a show do?**
a) The file opens straight into the slide show  b) A reader who must only read the deck  c) Someone who needs the slide inside other work  d) An audience, with no editing tools in the way
**Answer: a) The file opens straight into the slide show**

**6. (Sub lesson 2) Who should receive a PDF?**
a) Someone who needs the slide inside other work  b) A reader who must only read the deck  c) An audience, with no editing tools in the way  d) The original editable deck — the master
**Answer: b) A reader who must only read the deck**

**7. (Sub lesson 2) Who should receive a slide as a picture?**
a) An audience, with no editing tools in the way  b) The original editable deck — the master  c) Someone who needs the slide inside other work  d) So the deck can still be changed for next time
**Answer: c) Someone who needs the slide inside other work**

**8. (Sub lesson 2) Who should receive the show format?**
a) The original editable deck — the master  b) So the deck can still be changed for next time  c) Because its own format opens only in its own program — other readers need forms they can open  d) An audience, with no editing tools in the way
**Answer: d) An audience, with no editing tools in the way**

**9. (Sub lesson 2) What is always kept besides the copies sent out?**
a) The original editable deck — the master  b) So the deck can still be changed for next time  c) Because its own format opens only in its own program — other readers need forms they can open  d) Save As
**Answer: a) The original editable deck — the master**

**10. (Sub lesson 2) Why keep the master?**
a) Because its own format opens only in its own program — other readers need forms they can open  b) So the deck can still be changed for next time  c) Save As  d) A document any computer can read and print, with the slides fixed as designed
**Answer: b) So the deck can still be changed for next time**
