**The one thing this lesson teaches:** Hyperlinks in a presentation — jumping from a slide to another slide, a file or a web page (Laos Grade 12, Ch.5 §V)

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **What a hyperlink on a slide does** — A **hyperlink** on a slide is a **piece of text or a picture that, when clicked during the show, jumps** — to **another slide** in the same presentation, to **another file** on the computer, or to a **web page**. It turns the deck from a single road into a small network: the presenter follows the audience's question, not only the plan. The link is recognised the way web links are — coloured, underlined text, or a picture the presenter names as a door — and it works **only while the show is running**, not while editing.
2. **Making links — and keeping them honest** — A link is made by **selecting the text or picture, giving the Insert Hyperlink command, and choosing the target** — place in this document, existing file, or web address. Laos teaches the making beside its discipline: a link is a **promise** — its words must say where it goes, its target must be **tested in the show before the audience arrives**, and a link to a file or the web is only as reliable as that file's place and that connection. A broken promise mid-talk costs more than no link at all, so the book's presenters test every jump twice.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## The run of the lesson (in order)
1. **Do it first** — A presentation normally walks in a straight line. Laos's Grade 12 PowerPoint course breaks the line on purpose: hyperlinks that let a talk jump — to a detail slide, a document, a page on the web. This lesson builds the jumps. (lesson/lesson.md).
2. **The explanation** — the lesson text in lesson/lesson.md, in its parts in order.
   - ADD IMAGE: a picture of what a hyperlink on a slide does as the lesson describes it — the student studies the picture and names what each part shows.

   - ADD AUDIO: a voice reading the lesson's key names and definitions aloud, in the order the lesson gives them — the student listens once through, then reads the same lines aloud along with the voice. (Audio is a described slot in this build; no audio file is made.)
