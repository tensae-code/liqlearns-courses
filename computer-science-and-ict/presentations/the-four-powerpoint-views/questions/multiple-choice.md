# The four PowerPoint views — multiple choice

Pick the one right answer.

**1.** The creating and editing view is —
a) Slide Sorter  b) Normal view  c) Notes Page  d) Reading view
**Answer: b) Normal view** — One slide, thumbnails, outline, notes at the bottom.

**2.** All slides as thumbnails for reordering is —
a) Normal view  b) Notes Page  c) Slide Sorter  d) Reading view
**Answer: c) Slide Sorter** — The guide's answer key misprints it once as "Slide shorter view".

**3.** A hidden slide —
a) is deleted from the file  b) stays in the file but is not shown  c) prints twice  d) becomes the title slide
**Answer: b) stays in the file but is not shown**

**4.** Printable speaker notes for each slide are in —
a) Notes Page  b) Slide Sorter  c) Normal view only  d) the File tab
**Answer: a) Notes Page**

**5.** In Reading/Slide Show view, Esc —
a) prints  b) returns to Normal view  c) deletes the slide  d) opens Notes Page
**Answer: b) returns to Normal view** — Arrows advance the slides.

**6.** Views are reached from —
a) the status bar buttons or the View tab  b) the Insert tab only  c) right-clicking the desktop  d) the Recycle Bin
**Answer: a) the status bar buttons or the View tab**
