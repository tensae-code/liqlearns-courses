# Hands-on — The four PowerPoint views

The lesson with your hands, not only your eyes. Where there is no computer laboratory, do the screen work on a teacher's or your own phone, as the course's teaching pattern provides.

## Four-way tour
Open one deck and visit all four views in order, saying each view's job aloud as it appears. End in Normal — the view you build in.

## Hide and seek
Hide one slide in Slide Sorter, run the show, and confirm it is skipped. Unhide it. The file kept it the whole time — hiding is not deleting.
