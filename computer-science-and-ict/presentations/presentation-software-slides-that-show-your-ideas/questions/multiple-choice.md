# Presentation software — slides that show your ideas — multiple choice

Pick the one right answer.

**1.** Presentation software displays —
a) spreadsheets  b) slides during a presentation  c) databases  d) letters
**Answer: b) slides during a presentation**

**2.** Which is NOT one of the three programs named?
a) MS PowerPoint  b) Google Slides  c) LibreOffice Impress  d) MS Excel
**Answer: d) MS Excel** — Excel is spreadsheet software.

**3.** A presentation is —
a) one long page  b) a set of individual pages — slides  c) a single picture  d) a printed book
**Answer: b) a set of individual pages — slides**

**4.** A slide can hold all of these EXCEPT —
a) text  b) graphics  c) sound and movies  d) a spreadsheet formula bar
**Answer: d) a spreadsheet formula bar** — Slides hold text, graphics, sound, movies and other objects, freely arranged.
