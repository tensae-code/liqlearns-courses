# Microsoft Publisher — Making Posters and Cards — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is Microsoft Publisher for?" is: Making publications — posters, cards, invitations and booklets**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Name two things Publisher makes." is: Its main interface and the File menu**
**Answer: False** — Posters and business cards

**3. (Sub lesson 1) True or false: the answer to "Name two more things Publisher makes." is: Invitations and booklets**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What opens the Publisher unit?" is: The Home and Insert tabs**
**Answer: False** — Its main interface and the File menu

**5. (Sub lesson 1) True or false: the answer to "In what way is Publisher taught?" is: Tab by tab, like PowerPoint before it**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Which tabs does the second Publisher lesson work?" is: The everyday text and object tools**
**Answer: False** — The Home and Insert tabs

**7. (Sub lesson 2) True or false: the answer to "What real job does the second lesson design?" is: A school-festival publicity leaflet**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does the Home tab hold?" is: Printing and handing out**
**Answer: False** — The everyday text and object tools

**Answer: True**
