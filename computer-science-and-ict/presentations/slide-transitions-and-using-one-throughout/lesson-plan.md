# Lesson plan — Slide transitions — and using one throughout

**Course:** Computer Science and ICT · **Title:** Presentations · **Lesson:** Slide transitions — and using one throughout
**Place in the curriculum:** Unit 3 — Application Software, Grade 10 depth, in the Presentations title of the Computer Science and ICT ladder (TITLES.md). The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** a transition is the animated effect between slides — chosen on the Transitions tab, set with Effect Options, Duration and Sound, run with F5 — and the craft rule is one transition, applied to all.
**This lesson's own level:** it is a doing-lesson. It stands on the slide lessons; the deck exists, and this lesson moves between its slides well.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

2. **The craft rule — one transition throughout** — pass mark: apply the one-transition-throughout rule in the book's order.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Themes and readable slide design. Recommended, never forced.

## What the learner can do when it ends
1. Say that transitions act between slides, animations within a slide.
2. Add a transition and set its direction, duration and sound.
3. Set a slide to advance automatically, save with Ctrl+S, run with F5 and stop with Esc.
4. Apply the craft rule: one transition throughout, by None → Apply to All, choose one, Apply to All.

## What you need
A computer with PowerPoint and a presentation of several slides.

## If the learner is stuck
- No star beside the slide → the effect was previewed but not chosen; click the effect itself on the Transitions tab.
- The show will not stop → press Esc; F5 runs, Esc stops.
