# Adding slides — multiple choice

Pick the one right answer.

**1.** A new presentation opens with —
a) a blank white page  b) a Title Slide  c) a chart slide  d) Slide Sorter
**Answer: b) a Title Slide**

**2.** The two placeholders say —
a) Type here / Type there  b) Click to Add Title / Click to Add Subtitle  c) Title / Author  d) Start / End
**Answer: b) Click to Add Title / Click to Add Subtitle**

**3.** The top part of the New Slide button —
a) opens the layout gallery  b) inserts a slide with the default layout at once  c) deletes a slide  d) runs the show
**Answer: b) inserts a slide with the default layout at once**

**4.** The bottom part of the New Slide button —
a) opens the layout gallery  b) inserts at once  c) saves the file  d) changes the theme
**Answer: a) opens the layout gallery**

**5.** The new-slide shortcut is —
a) Ctrl+N  b) Ctrl+M  c) Ctrl+S  d) Ctrl+P
**Answer: b) Ctrl+M**
