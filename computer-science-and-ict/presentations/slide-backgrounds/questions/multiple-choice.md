# Slide backgrounds — multiple choice

Pick the one right answer.

**1.** Format Background offers all of these EXCEPT —
a) fill colours  b) gradients and textures  c) pictures  d) new slide layouts
**Answer: d) new slide layouts** — Layouts are a different tool.

**2.** Apply to the selected slide only with —
a) Apply to All  b) Close  c) Create  d) Esc
**Answer: b) Close**

**3.** Apply to All applies the background to —
a) one slide  b) the whole presentation  c) the notes only  d) the title slide only
**Answer: b) the whole presentation**

**4.** To select several slides, click one, then —
a) Shift-click all files  b) Ctrl-click the others  c) double-click the deck  d) press Ctrl+M
**Answer: b) Ctrl-click the others** — In the Thumbnail pane.
