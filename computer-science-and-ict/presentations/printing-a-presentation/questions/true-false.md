# Printing a Presentation — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What choice begins printing a presentation?" is: The form — full-page slides, handouts, or notes pages**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What are full-page slides printed for?" is: The printer, which slides to print, and the number of copies**
**Answer: False** — A record of each slide, large

**3. (Sub lesson 1) True or false: the answer to "What are handouts?" is: Several slides to a page, for the audience to keep**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What do notes pages carry?" is: A wrong layout, wrong order, or text cut or too small to read**
**Answer: False** — The speaker's notes under each slide

**5. (Sub lesson 1) True or false: the answer to "What else does the Print command choose?" is: The printer, which slides to print, and the number of copies**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does Print Preview show?" is: So a mistake costs one sheet, not a whole class set**
**Answer: False** — The pages exactly as they will come out

**7. (Sub lesson 2) True or false: the answer to "What can the preview reveal?" is: A wrong layout, wrong order, or text cut or too small to read**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is the order taught for printing?" is: The form — full-page slides, handouts, or notes pages**
**Answer: False** — Preview, fix, then print

**9. (Sub lesson 2) True or false: the answer to "Why print one test copy first?" is: So a mistake costs one sheet, not a whole class set**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Who goes home with the printed presentation?" is: Several slides to a page, for the audience to keep**
**Answer: False** — The audience — slides live on screen, paper travels
