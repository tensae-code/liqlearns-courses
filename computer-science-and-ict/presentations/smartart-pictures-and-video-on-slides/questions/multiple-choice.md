# SmartArt, pictures and video on slides — multiple choice

Pick the one right answer.

**1.** SmartArt graphics show —
a) spelling errors  b) relationships between things or people  c) file sizes  d) slide numbers
**Answer: b) relationships between things or people** — An organisation chart or a timeline.

**2.** Extra text that will not fit a slide should go —
a) on the next slide in tiny type  b) in the Notes section, to speak from  c) in the file name  d) nowhere — delete it
**Answer: b) in the Notes section, to speak from** — Pictures carry the slide instead.

**3.** Online Pictures replaced —
a) photographs  b) Clip Art  c) SmartArt  d) charts
**Answer: b) Clip Art** — Search by word or phrase, or browse categories via Bing Image Search.

**4.** Linking a video instead of embedding it —
a) makes the picture bigger  b) limits the file size  c) deletes the video  d) hides the slide
**Answer: b) limits the file size**

**5.** Video and audio options sit on —
a) Insert, in the Media group  b) the View tab  c) the File tab  d) Slide Sorter
**Answer: a) Insert, in the Media group**
