# Planning and Preparing a Presentation — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Name the five stages in order." is: Fix the aim; choose the topic; gather material; plan the slides; rehearse**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What question fixes the aim?" is: More than the talk needs, so the plan can choose**
**Answer: False** — What must the listeners leave able to do or ready to decide?

**3. (Sub lesson 1) True or false: the answer to "How much material is gathered?" is: More than the talk needs, so the plan can choose**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does each stage do to the next?" is: One idea per slide, in the talk's order**
**Answer: False** — Narrows it

**5. (Sub lesson 1) True or false: the answer to "What does the slide plan assign?" is: One idea per slide, in the talk's order**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How is a slide first sketched?" is: The talk is spoken aloud, timed, and its stumbles repaired in the plan**
**Answer: False** — On paper — title, picture or chart, few words — before the program opens

**7. (Sub lesson 2) True or false: the answer to "What happens in rehearsal?" is: The talk is spoken aloud, timed, and its stumbles repaired in the plan**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does rehearsal reveal?" is: A prepared act, not a file**
**Answer: False** — Where the audience will ask

**9. (Sub lesson 2) True or false: the answer to "What is a presentation, in the book's judgement?" is: A prepared act, not a file**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Which Grade 8 project is prepared this way?" is: Fix the aim; choose the topic; gather material; plan the slides; rehearse**
**Answer: False** — The air-pollution presentation built from the leaflet project
