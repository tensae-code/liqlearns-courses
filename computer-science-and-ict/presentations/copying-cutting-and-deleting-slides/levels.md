# Copying, cutting and deleting slides — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure). Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Copy and paste a slide
Sub lesson 1 questions from the type files. Pass mark: click the slide and select Copy from the Home tab, then right-click and select Paste — the slide gains a twin

## Sub lesson 2 — Cut and paste a slide
Sub lesson 2 questions from the type files. Pass mark: select the slide to cut; right-click on the slide; click Cut; then click Paste to paste it — the slide moves

## Sub lesson 3 — Delete a slide — and the closing presentation
Sub lesson 3 questions from the type files. Pass mark: right-click the slide and choose Delete; the closing activity presents a village tale with its topic bolded, italicised and underlined, page numbers inserted, a colour of choice used, and the file saved under your own name
