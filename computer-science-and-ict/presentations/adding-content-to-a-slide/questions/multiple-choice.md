# Adding content to a slide — multiple choice

Pick the one right answer.

**1.** The default content of a slide is —
a) a chart  b) text — a bulleted list  c) a video  d) a table
**Answer: b) text — a bulleted list** — Click and type.

**2.** How many standard graphical elements are there?
a) four  b) five  c) six  d) eight
**Answer: c) six** — Table, Chart, SmartArt, Pictures, Online Pictures, Video.

**3.** Clicking an icon in the content placeholder opens —
a) the File menu  b) its dialog or the Drawing Tools contextual tab  c) Slide Sorter  d) the Recycle Bin
**Answer: b) its dialog or the Drawing Tools contextual tab**

**4.** The same content options also live on —
a) the View tab  b) the Insert tab  c) the Design tab only  d) the status bar
**Answer: b) the Insert tab**

**5.** Which is one of the six elements?
a) Spell Check  b) SmartArt  c) WordArt styles  d) Page Number
**Answer: b) SmartArt**
