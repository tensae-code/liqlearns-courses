# Running a slide show; changing slide order — true or false

Say true or false.

**1.** You click and hold a slide, drag it, and release it in its new place.
**Answer: True**

**2.** Reordering a slide deletes its content.
**Answer: False — only its position changes.**

**3.** The Slide Show tab can run the show from the current slide.
**Answer: True**
