# Running a slide show; changing slide order — multiple choice

Pick the one right answer.

**1.** The Slide Show tab can run the show —
a) only from the beginning  b) from the beginning or from the current slide  c) only in Notes Page  d) only when printed
**Answer: b) from the beginning or from the current slide**

**2.** Timings are rehearsed through —
a) Format Background  b) Set Up Slide Show  c) Bullets and Numbering  d) Insert Table
**Answer: b) Set Up Slide Show**

**3.** While dragging a slide to a new place, what shows where it will land?
a) a red cross  b) a line  c) a dialog box  d) nothing
**Answer: b) a line**

**4.** Reordering is done in —
a) Notes Page  b) Slide Sorter view (or the Thumbnail pane)  c) the Insert Table dialog  d) Reading view only
**Answer: b) Slide Sorter view (or the Thumbnail pane)**
