# PowerPoint bullets — size, colour, shape — multiple choice

Pick the one right answer.

**1.** Bullets and Numbering opens from —
a) the File tab  b) the Bullets button's drop-down in the Paragraph group  c) Slide Sorter  d) the status bar
**Answer: b) the Bullets button's drop-down in the Paragraph group**

**2.** In Bullets and Numbering you can change the bullet's —
a) size relative to the text  b) colour  c) shape — picture or character  d) all of these
**Answer: d) all of these**

**3.** Line Spacing Options opens —
a) the Insert Table dialog  b) the Indents and Spacing dialog  c) Format Background  d) the layout gallery
**Answer: b) the Indents and Spacing dialog**

**4.** A bullet's shape can be —
a) only a round dot  b) a picture or a character  c) only a number  d) only an arrow drawn by hand
**Answer: b) a picture or a character**
