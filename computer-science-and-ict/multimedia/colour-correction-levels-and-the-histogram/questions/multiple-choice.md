# Colour correction — Levels and the histogram — multiple choice

Pick the one right answer.

**1.** Every image mixes shadows, highlights and —
a) pixels  b) midtones  c) layers  d) curves
**Answer: b) midtones** — midtones — everything between.

**2.** A gap with no information on the RIGHT of the histogram means the image is —
a) overexposed  b) underexposed  c) sharpened  d) cropped
**Answer: b) underexposed** — underexposed.

**3.** The white Input Levels slider is dragged —
a) right, past the edge  b) left, to the histogram's right-most edge  c) down  d) off the panel
**Answer: b) left, to the histogram's right-most edge** — left, to the data's edge.

**4.** Dragging a slider past the data's edge —
a) improves detail  b) loses detail — clipping  c) adds colour  d) does nothing
**Answer: b) loses detail — clipping** — clipping loses detail.

**5.** A Levels adjustment layer is non-destructive because —
a) it deletes the original  b) it changes nothing in the original and can be re-tweaked  c) it prints the photo  d) it locks the file
**Answer: b) it changes nothing in the original and can be re-tweaked** — the original is untouched.

**6.** In GIMP, Levels is found —
a) under the Colour menu  b) in the File menu  c) on the canvas  d) under Filters → Blur
**Answer: a) under the Colour menu** — the Colour menu.

**7.** The black slider is dragged right —
a) always  b) only if the shadows are too bright  c) never  d) before the white slider
**Answer: b) only if the shadows are too bright** — only if shadows are too bright.
