# Steganography — Hiding Messages in Images — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) The least significant bit of a colour value changes the value by at most —**
a) 128  b) 16  c) 1  d) 255
**Answer: c) 1 — The last bit is the 1s place; setting or clearing it moves the number by one at most, invisible to the eye.**

**2. (Sub lesson 1) Steganography differs from encryption because it —**
a) Is faster  b) Hides that a message exists at all  c) Uses no computer  d) Cannot be read by anyone
**Answer: b) Hides that a message exists at all — Encryption scrambles a message everyone can see; steganography tucks it out of sight.**

**3. (Sub lesson 2) Why must the carrier image be saved as PNG and not JPEG?**
a) PNG is prettier  b) JPEG compression rewrites the colour values and destroys the hidden bits  c) JPEG files are larger  d) PNG opens faster
**Answer: b) JPEG compression rewrites the colour values and destroys the hidden bits — Lossy compression does not preserve least significant bits.**
