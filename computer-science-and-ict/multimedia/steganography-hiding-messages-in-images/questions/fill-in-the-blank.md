# Steganography — Hiding Messages in Images — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 1) In the SNT book’s scheme, each character is coded on ____ bits.**
**Answer: 6 — A base-64 code: 64 possible characters, each written with exactly six bits.**

**2. (Sub lesson 2) The bits are hidden in the ____ significant bit of each colour value.**
**Answer: least — The last bit, worth 1, is the invisible hiding place.**
