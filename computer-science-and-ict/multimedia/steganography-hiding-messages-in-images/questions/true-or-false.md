# Steganography — Hiding Messages in Images — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Changing the least significant bit of every colour value makes a visible pattern appear on the photo.**
**Answer: False — Each value moves by at most one in 255; the eye cannot see it.**

**2. (Sub lesson 2) If a message is hidden with steganography, nobody who suspects the scheme needs a key to read it.**
**Answer: True — Hiding is not encrypting: knowing the scheme and the order is enough to read the bits back.**
