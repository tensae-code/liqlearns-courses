# Video script — Steganography — Hiding Messages in Images

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Here is a secret hidden in plain sight. Steganography hides a message inside an ordinary photo.

Every colour number ends in a last bit. Change it, and the number moves by one. No eye can see that.

So write the message's bits into those last bits, pixel after pixel. The photo looks innocent. It carries a text.

A program reads the last bits back, groups them, and the message steps out.

But handle the photo gently. Compress it, and the message dies. And remember: hiding is not encrypting. It hides that a message exists — not what it says.
