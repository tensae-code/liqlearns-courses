# Cropping with the Crop Tool — true or false

Say whether each statement is true or false.

**1.** Cropping removes portions of a photo.
**Answer: True** — that is what cropping is.

**2.** You must select the image yourself after choosing the Crop Tool.
**Answer: False** — the whole image is selected automatically.

**3.** A crop can strengthen a photo's composition.
**Answer: True** — focus or composition — the book's two reasons.
