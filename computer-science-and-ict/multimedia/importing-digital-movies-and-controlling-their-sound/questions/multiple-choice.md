# Importing digital movies — and controlling their sound — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Digital video records with —
a) an analogue signal  b) a digital signal  c) no signal  d) a printed signal
**Answer: b) a digital signal** — digital, not analogue.

**2. (Sub lesson 1)** Which is NOT among the accepted formats listed?
a) MP4  b) AVI  c) WMV  d) PSD
**Answer: d) PSD** — the list is MP3, MP4, AVI, MPG, WAV, WMV.

**3. (Sub lesson 1)** A movie is imported —
a) like sound, by Organize → Get Media → Files and Folders  b) only by scanning  c) by File → Open as Library  d) by typing its name
**Answer: a) like sound, by Organize → Get Media → Files and Folders** — the same route as sound.

**4. (Sub lesson 1)** Premiere work on a movie includes —
a) trimming, motion, audio enhancing and transitions  b) only printing  c) only renaming  d) only saving
**Answer: a) trimming, motion, audio enhancing and transitions** — the four kinds of work named.

**5. (Sub lesson 2)** Playback conditions are set from —
a) the menu bar  b) right-click timeline audio → Show Properties  c) Color Swatches  d) the Stage
**Answer: b) right-click timeline audio → Show Properties** — the properties route.

**6. (Sub lesson 2)** Silencing a clip is done by —
a) deleting its audio  b) toggling the Volume effect off in the properties dialogue  c) removing the clip  d) muting the computer forever
**Answer: b) toggling the Volume effect off in the properties dialogue** — a toggle, not a deletion.
