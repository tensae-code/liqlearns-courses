# Removing hot spots with the Clone Stamp — true or false

Say whether each statement is true or false.

**1.** Hot spots are light pixels.
**Answer: True** — that is why Darken mode catches them.

**2.** The cursor becomes an eyedropper when you Alt-click to sample.
**Answer: True** — the book's step 6.

**3.** You should sample FROM the hot spot itself.
**Answer: False** — sample a clean, non-hot-spot area.
