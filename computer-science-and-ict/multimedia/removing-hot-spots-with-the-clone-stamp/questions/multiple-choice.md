# Removing hot spots with the Clone Stamp — multiple choice

Pick the one right answer.

**1.** A hot spot is —
a) a dark shadow  b) a shiny light patch caused by flash  c) a red pupil  d) a scratch
**Answer: b) a shiny light patch caused by flash** — a shiny patch from flash.

**2.** The Blend Mode is changed from Normal to —
a) Lighten  b) Darken  c) Overlay  d) Multiply
**Answer: b) Darken** — Darken.

**3.** Darken mode means —
a) everything darkens  b) only pixels lighter than the sample will change  c) only the background changes  d) colours invert
**Answer: b) only pixels lighter than the sample will change** — hot spots are light pixels, so only they change.

**4.** The brush chosen is —
a) hard-edged, size 10  b) soft-edged, diameter 40–50  c) soft-edged, diameter 200  d) a pencil
**Answer: b) soft-edged, diameter 40–50** — soft-edged, 40–50.

**5.** The sample point is set by —
a) clicking the hot spot  b) Alt-clicking a clean, non-hot-spot area  c) pressing Enter  d) double-clicking the layer
**Answer: b) Alt-clicking a clean, non-hot-spot area** — Alt-click a clean area.

**6.** The work is done on —
a) the background layer  b) a duplicate of the layer  c) a new document  d) the canvas only
**Answer: b) a duplicate of the layer** — duplicate the layer; work on the copy.
