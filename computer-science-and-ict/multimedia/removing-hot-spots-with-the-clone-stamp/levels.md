# Removing hot spots with the Clone Stamp — depth

This lesson is one whole lesson with no sub lessons. Pass mark: the learner can do and explain the lesson's one thing — a flash hot spot is painted away with the Clone Stamp in Darken mode: Alt-click a clean area to sample it, then paint over the shine — only pixels lighter than the sample change. Practice deepens with more items from the question files and harder corners of the same skill (new images, new values, the same steps), never with new content the lesson does not teach.
