# Video script — Creating and Editing Vector and Raster Graphics

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

**Vector graphics are created** by drawing with the editor's **shapes, lines and paths** — each object named and kept, so it can be **selected, moved, reshaped, recoloured and scaled** without loss, because the drawing is stored as the objects' descriptions. **Editing** a vector is re-deciding those descriptions: drag a path's point, change a fill, group objects into one. It is the graphics of logos, diagrams and type — anything that must stay sharp at every size.
**Raster graphics arrive by capture** — photograph, scan, screenshot — already a grid of pixels, and **editing** them works the grid: **crop** to the wanted part, correct **brightness, contrast and colour**, **retouch** faults away, and **resize** knowing the trade the representation lesson taught (fewer pixels, smaller file, less detail — a one-way door). The editor's skill the chapter builds is choosing per job: draw it vector if it must scale; capture and repair it raster if it must show the real world.
