# Preparing Images for the Web — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What must happen to an image before it is published on the web?" is: It must be prepared — sized, formatted, and made light enough to load quickly.**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What size should a web image be stored at?" is: One made for photographs, which squeezes by dropping detail the eye barely misses.**
**Answer: False** — No bigger than the place it will fill on the page.

**3. (Sub lesson 1) True or false: the answer to "What is an image's weight?" is: Its file size in bytes, which decides how long a visitor waits.**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is preparation a trade between?" is: A bloated photograph, or a sharp diagram gone fuzzy.**
**Answer: False** — Looking right and loading fast.

**5. (Sub lesson 1) True or false: the answer to "Which way does the balance lean for the web?" is: Toward the visitor's wait — loading fast.**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What format suits photographs?" is: It is made for printing and keeping, far beyond display size and weight.**
**Answer: False** — One made for photographs, which squeezes by dropping detail the eye barely misses.

**7. (Sub lesson 2) True or false: the answer to "What format suits logos and sharp diagrams?" is: One that keeps edges exact, even at few colours.**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does the wrong format show as?" is: No bigger than the place it will fill on the page.**
**Answer: False** — A bloated photograph, or a sharp diagram gone fuzzy.

**9. (Sub lesson 2) True or false: the answer to "Where is finished preparation checked?" is: On the page itself — size on screen, weight in the folder, nothing needed lost.**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why is a camera photo too big for its page?" is: Looking right and loading fast.**
**Answer: False** — It is made for printing and keeping, far beyond display size and weight.
