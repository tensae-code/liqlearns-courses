# Preparing Images for the Web — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What must happen to an image before it is published on the web?**
a) It must be prepared — sized, formatted, and made light enough to load quickly  b) Looking right and loading fast  c) One made for photographs, which squeezes by dropping detail the eye barely misses  d) A bloated photograph, or a sharp diagram gone fuzzy
**Answer: a) It must be prepared — sized, formatted, and made light enough to load quickly**

**2. (Sub lesson 1) What size should a web image be stored at?**
a) Toward the visitor's wait — loading fast  b) No bigger than the place it will fill on the page  c) One that keeps edges exact, even at few colours  d) On the page itself — size on screen, weight in the folder, nothing needed lost
**Answer: b) No bigger than the place it will fill on the page**

**3. (Sub lesson 1) What is an image's weight?**
a) One made for photographs, which squeezes by dropping detail the eye barely misses  b) A bloated photograph, or a sharp diagram gone fuzzy  c) Its file size in bytes, which decides how long a visitor waits  d) It is made for printing and keeping, far beyond display size and weight
**Answer: c) Its file size in bytes, which decides how long a visitor waits**

**4. (Sub lesson 1) What is preparation a trade between?**
a) One that keeps edges exact, even at few colours  b) On the page itself — size on screen, weight in the folder, nothing needed lost  c) It must be prepared — sized, formatted, and made light enough to load quickly  d) Looking right and loading fast
