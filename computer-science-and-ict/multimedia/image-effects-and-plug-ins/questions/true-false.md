# Image Effects and Plug-Ins — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "On what does Grade 9 apply the Effects menu?" is: Ready photographs**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is an effect on a photograph, ethically?" is: On their own layer, chosen and owned**
**Answer: False** — A claim about it — an undeclared effect on a documentary photo crosses the ethics line

**3. (Sub lesson 1) True or false: the answer to "Where are effects placed?" is: On their own layer, chosen and owned**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is a plug-in?" is: Its file is placed where the program reads extensions, and the program is restarted**
**Answer: False** — An added module that gives the editor new powers

**5. (Sub lesson 1) True or false: the answer to "How is a plug-in installed?" is: Its file is placed where the program reads extensions, and the program is restarted**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How do a plug-in's effects appear?" is: 3D text — letters given depth, light and shadow**
**Answer: False** — They join the menu as citizens

**7. (Sub lesson 2) True or false: the answer to "What is the book's set project with plug-ins?" is: 3D text — letters given depth, light and shadow**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is an editor, in the lesson's closing phrase?" is: The pupil who installed them**
**Answer: False** — Not a fixed shelf but a growing bench

**9. (Sub lesson 2) True or false: the answer to "Who is responsible for the bench's tools?" is: The pupil who installed them**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Which editor is extended this way?" is: Ready photographs**
**Answer: False** — Paint.NET
