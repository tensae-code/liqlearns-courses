# Image Effects and Plug-Ins — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) On what does Grade 9 apply the Effects menu?**
a) Ready photographs  b) A claim about it — an undeclared effect on a documentary photo crosses the ethics line  c) On their own layer, chosen and owned  d) An added module that gives the editor new powers
**Answer: a) Ready photographs**

**2. (Sub lesson 1) What is an effect on a photograph, ethically?**
a) On their own layer, chosen and owned  b) A claim about it — an undeclared effect on a documentary photo crosses the ethics line  c) An added module that gives the editor new powers  d) Its file is placed where the program reads extensions, and the program is restarted
**Answer: b) A claim about it — an undeclared effect on a documentary photo crosses the ethics line**

**3. (Sub lesson 1) Where are effects placed?**
a) An added module that gives the editor new powers  b) Its file is placed where the program reads extensions, and the program is restarted  c) On their own layer, chosen and owned  d) They join the menu as citizens
**Answer: c) On their own layer, chosen and owned**

**4. (Sub lesson 1) What is a plug-in?**
a) Its file is placed where the program reads extensions, and the program is restarted  b) They join the menu as citizens  c) 3D text — letters given depth, light and shadow  d) An added module that gives the editor new powers
**Answer: d) An added module that gives the editor new powers**
