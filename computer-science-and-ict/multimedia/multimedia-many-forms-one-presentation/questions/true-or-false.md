# Multimedia — many forms, one presentation — true or false

Say whether each statement is true or false.

**1.** Television came before newspapers as a mass medium.
**Answer: False** — newspapers first, then radio, then television.

**2.** A multimedia presentation can combine text with video and audio.
**Answer: True** — all five forms can combine.

**3.** Multimedia is only about storing files.
**Answer: False** — it presents, stores, transmits and combines forms — and lets the user interact.
