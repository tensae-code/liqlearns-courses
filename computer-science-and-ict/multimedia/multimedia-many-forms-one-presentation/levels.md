# Multimedia — many forms, one presentation — depth

This lesson is one whole lesson with no sub lessons. Pass mark: the learner can do and explain the lesson's one thing — multimedia combines different content forms — text, audio, image, animation and video — into a single interactive presentation. Practice deepens with more items from the question files and harder corners of the same skill (new images, new values, the same steps), never with new content the lesson does not teach.
