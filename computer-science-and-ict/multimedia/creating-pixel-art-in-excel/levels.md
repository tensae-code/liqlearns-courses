# Creating Pixel Art in Excel — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Pixels in a grid — the cell as a dot
Sub lesson 1 questions from the type files. Pass mark: A tiny coloured dot in a grid; Columns narrow and equal so cells are square, then filled with colour; One; A plan — the drawing counted out on paper; A flag, a flower, a character.

## Sub lesson 2 — Controlling the picture's dimensions
Sub lesson 2 questions from the type files. Pass mark: The number of cells across and down; The cell size; The plan's counting; How wide the picture is — in cells and in centimetres; Plan the grid, fill the grid, check against the plan.
