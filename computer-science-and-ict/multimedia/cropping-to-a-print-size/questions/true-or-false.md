# Cropping to a print size — true or false

Say whether each statement is true or false.

**1.** Whatever size the border is dragged to, the inside area keeps the 8×10 proportions.
**Answer: True** — constrained proportions.

**2.** You must press Enter; there is no other way to confirm.
**Answer: False** — the confirm tick at the right of the options bar also works.

**3.** The size values are typed after the crop is finished.
**Answer: False** — they are entered before dragging the border.
