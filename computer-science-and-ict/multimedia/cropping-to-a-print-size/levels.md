# Cropping to a print size — depth

This lesson is one whole lesson with no sub lessons. Pass mark: the learner can do and explain the lesson's one thing — to crop for standard photo paper, enter the Width and Height in the Crop Tool's options bar — the border then stays locked to those proportions whatever size it is dragged to. Practice deepens with more items from the question files and harder corners of the same skill (new images, new values, the same steps), never with new content the lesson does not teach.
