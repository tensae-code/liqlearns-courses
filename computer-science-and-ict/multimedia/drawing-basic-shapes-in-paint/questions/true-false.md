# Drawing Basic Shapes in Paint — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Where are Paint's ready shapes found?" is: In the shapes gallery**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Name three basic shapes Paint can draw." is: The shape is exact — straight edges stay straight and corners stay square**
**Answer: False** — A line, an oval and a rectangle

**3. (Sub lesson 1) True or false: the answer to "How is a shape drawn?" is: Pick the shape, then drag across the canvas from press to release**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Why draw with shapes instead of freehand?" is: The colour of its edge**
**Answer: False** — The shape is exact — straight edges stay straight and corners stay square

**5. (Sub lesson 1) True or false: the answer to "When does an oval become a circle?" is: When it is dragged evenly**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is the outline of a shape?" is: Draw, colour, save**
**Answer: False** — The colour of its edge

**7. (Sub lesson 2) True or false: the answer to "What is the fill of a shape?" is: The colour of its inside**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is the order of a Paint job in this lesson?" is: A file with a name, kept like every other file**
**Answer: False** — Draw, colour, save

**9. (Sub lesson 2) True or false: the answer to "Why save the drawing?" is: So it can be opened again, printed or put into a document**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What does the saved drawing become?" is: A line, an oval and a rectangle**
**Answer: False** — A file with a name, kept like every other file
