# Pixels, Bitmaps and Colour Depth — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a bitmap picture?**
a) A grid of pixels, with a number stored for each pixel's colour  b) A number saying its colour  c) The grid of pixels  d) The picture softens
**Answer: a) A grid of pixels, with a number stored for each pixel's colour**

**2. (Sub lesson 1) What does the file store for each pixel?**
a) The grid of pixels  b) A number saying its colour  c) The picture softens  d) After the graphics editor, inside working with graphic information
**Answer: b) A number saying its colour**

**3. (Sub lesson 1) What shows when you zoom far in?**
a) The picture softens  b) After the graphics editor, inside working with graphic information  c) The grid of pixels  d) How many bits describe one pixel
**Answer: c) The grid of pixels**

**4. (Sub lesson 1) What happens when a bitmap is printed big?**
a) After the graphics editor, inside working with graphic information  b) How many bits describe one pixel  c) Two — black and white  d) The picture softens
**Answer: d) The picture softens**

**5. (Sub lesson 1) Where does this lesson sit in the Grade 9 book?**
a) After the graphics editor, inside working with graphic information  b) How many bits describe one pixel  c) Two — black and white  d) Millions — true colour
**Answer: a) After the graphics editor, inside working with graphic information**

**6. (Sub lesson 2) What is colour depth?**
a) Two — black and white  b) How many bits describe one pixel  c) Millions — true colour  d) Doubles them
**Answer: b) How many bits describe one pixel**

**7. (Sub lesson 2) How many colours does 1 bit give?**
a) Millions — true colour  b) Doubles them  c) Two — black and white  d) Truth of colour and file size
**Answer: c) Two — black and white**

**8. (Sub lesson 2) How many colours do 24 bits give?**
a) Doubles them  b) Truth of colour and file size  c) A grid of pixels, with a number stored for each pixel's colour  d) Millions — true colour
**Answer: d) Millions — true colour**

**9. (Sub lesson 2) What does every added bit do to the colours?**
a) Doubles them  b) Truth of colour and file size  c) A grid of pixels, with a number stored for each pixel's colour  d) A number saying its colour
**Answer: a) Doubles them**

**10. (Sub lesson 2) What is choosing a depth a balance between?**
a) A grid of pixels, with a number stored for each pixel's colour  b) Truth of colour and file size  c) A number saying its colour  d) The grid of pixels
**Answer: b) Truth of colour and file size**
