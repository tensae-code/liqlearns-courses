# Composing a Picture from Several Images — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a composition?" is: A new picture made by combining several pictures into one scene**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What must the combined parts agree on?" is: Drawing, selecting, copying and resizing**
**Answer: False** — Light from the same side, colours that sit together, sizes that fit their places

**3. (Sub lesson 1) True or false: the answer to "Which earlier skills does composition join?" is: Drawing, selecting, copying and resizing**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How is depth shown in a composition?" is: Resizing**
**Answer: False** — Near things drawn larger, far things smaller — perspective

**5. (Sub lesson 1) True or false: the answer to "Which tool builds the depth?" is: Resizing**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is added last to finish a composition?" is: Where it finishes the scene without covering it**
**Answer: False** — Text — a title or a label

**7. (Sub lesson 2) True or false: the answer to "Where should the text be placed?" is: Where it finishes the scene without covering it**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How is a composition judged?" is: A Mongolian scene — ger, horse, mountains and sky**
**Answer: False** — As one picture, not as the sum of its parts

**9. (Sub lesson 2) True or false: the answer to "Give the book's kind of scene for a composition." is: A Mongolian scene — ger, horse, mountains and sky**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Which unit does this lesson close?" is: A new picture made by combining several pictures into one scene**
**Answer: False** — The Paint (image-processing) unit of Mongolia's Grade 6 IT book
