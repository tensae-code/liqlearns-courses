# Gradients and Shadows That Make Depth in a Game — true or false

Say whether each statement is true or false.

**1. Depth in the maze is drawn, not programmed.**
**Answer: True** — Shadow shapes and layer order do the work.

**2. The depth effect should be built before the game works.**
**Answer: False** — It is an advanced finishing tip, added after the game works.

**3. A flat single-colour shadow gives the same effect as a gradient one.**
**Answer: False** — The fading gradient is what imitates a real shadow.
