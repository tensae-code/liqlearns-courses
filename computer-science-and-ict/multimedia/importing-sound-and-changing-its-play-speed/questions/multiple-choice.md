# Importing sound and changing its play speed — multiple choice

Pick the one right answer.

**1.** A sound icon is —
a) a speaker  b) the graphical stand-in for an audio file in a project or library  c) a file format  d) a transition
**Answer: b) the graphical stand-in for an audio file in a project or library** — the picture standing for the sound.

**2.** Sound is imported by —
a) Organize → Get Media → Files and Folders  b) File → Open as Library  c) Control → Test Movie  d) Edit → Transitions
**Answer: a) Organize → Get Media → Files and Folders** — the Organize route.

**3.** Play speed is changed by right-clicking —
a) the Stage  b) the waveform on the Timeline  c) the library  d) the menu bar
**Answer: b) the waveform on the Timeline** — on the Timeline waveform.

**4.** The speed is set in the —
a) Properties panel  b) Time Stretch dialogue  c) Task panel  d) Monitor panel
**Answer: b) Time Stretch dialogue** — then OK.

**5.** In Flash, the guide's audio routes are Import to —
a) Stage or Library  b) Timeline or Stage only  c) Desktop  d) Clipboard
**Answer: a) Stage or Library** — both Flash routes, teacher evidence.
