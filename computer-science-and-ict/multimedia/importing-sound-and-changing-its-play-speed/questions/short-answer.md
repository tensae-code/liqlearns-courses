# Importing sound and changing its play speed — short answer

Answer in one or two sentences.

**1.** Give the full speed-changing sequence in order.
**Answer:** Drag the audio to the Timeline, right-click the waveform, choose Time Stretch, set the playback speed in the dialogue, then OK.

**2.** Name the guide's two Flash audio-import routes.
**Answer:** File → Import → Import to Library, and File → Import → Import to Stage, then choose the audio file.
