# Importing sound and changing its play speed

## Do it first

Clap a steady rhythm. Now clap it twice as fast, then half as fast. Before reading on — the claps are the same claps; only their speed changed. This lesson does exactly that to a sound file, without re-recording it.

## Importing sound and changing its speed

A **sound icon** is the graphical stand-in for an audio file in a project or library — the picture you click, standing for the sound you hear.

Sound is **imported** in Premiere Elements by **Organize → Get Media → Files and Folders**, browsing to the audio file and opening it into the project.

Its **play speed** is changed by dragging the audio to the **Timeline**, **right-clicking the waveform → Time Stretch**, and setting the playback speed in the **Time Stretch dialogue** before **OK**.

[Picture 15315 — a waveform with the Time Stretch dialogue]

The guide's Flash route stands beside this one: in Flash, audio is imported by File → Import → Import to Library, or File → Import → Import to Stage, then choosing the audio file (teacher guide — evidence). Two programs, one idea: the sound must be brought in before it can be worked on.
