# Measuring Digital Image and Audio — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a digital image made of?**
a) A grid of pixels — single-colour dots  b) In pixels — width × height, such as 1920 × 1080  c) How finely pixels are packed — pixels per inch (ppi) when printed  d) A million pixels
**Answer: a) A grid of pixels — single-colour dots**

**2. (Sub lesson 1) How are an image's dimensions stated?**
a) How finely pixels are packed — pixels per inch (ppi) when printed  b) In pixels — width × height, such as 1920 × 1080  c) A million pixels  d) Width × height in pixels
**Answer: b) In pixels — width × height, such as 1920 × 1080**

**3. (Sub lesson 1) What does resolution count?**
a) A million pixels  b) Width × height in pixels  c) How finely pixels are packed — pixels per inch (ppi) when printed  d) Samples per second — in hertz (Hz)
**Answer: c) How finely pixels are packed — pixels per inch (ppi) when printed**

**4. (Sub lesson 1) What is a megapixel?**
a) Width × height in pixels  b) Samples per second — in hertz (Hz)  c) 44,100 Hz  d) A million pixels
**Answer: d) A million pixels**

**5. (Sub lesson 1) How is an image's total pixel count found?**
a) Width × height in pixels  b) Samples per second — in hertz (Hz)  c) 44,100 Hz  d) The bits kept per sample
**Answer: a) Width × height in pixels**

**6. (Sub lesson 2) What does the sample rate count?**
a) 44,100 Hz  b) Samples per second — in hertz (Hz)  c) The bits kept per sample  d) Sample rate × bit depth × seconds
**Answer: b) Samples per second — in hertz (Hz)**

**7. (Sub lesson 2) What sample rate does CD audio use?**
a) The bits kept per sample  b) Sample rate × bit depth × seconds  c) 44,100 Hz  d) Every later claim about quality and file size is built from them
**Answer: c) 44,100 Hz**

**8. (Sub lesson 2) What does bit depth count?**
a) Sample rate × bit depth × seconds  b) Every later claim about quality and file size is built from them  c) A grid of pixels — single-colour dots  d) The bits kept per sample
**Answer: d) The bits kept per sample**

**9. (Sub lesson 2) What three factors give an audio file's data size?**
a) Sample rate × bit depth × seconds  b) Every later claim about quality and file size is built from them  c) A grid of pixels — single-colour dots  d) In pixels — width × height, such as 1920 × 1080
**Answer: a) Sample rate × bit depth × seconds**

**10. (Sub lesson 2) Why does Malaysia teach the units first?**
a) A grid of pixels — single-colour dots  b) Every later claim about quality and file size is built from them  c) In pixels — width × height, such as 1920 × 1080  d) How finely pixels are packed — pixels per inch (ppi) when printed
**Answer: b) Every later claim about quality and file size is built from them**
