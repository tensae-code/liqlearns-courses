# Measuring Digital Image and Audio — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a digital image made of?" is: A grid of pixels — single-colour dots**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How are an image's dimensions stated?" is: How finely pixels are packed — pixels per inch (ppi) when printed**
**Answer: False** — In pixels — width × height, such as 1920 × 1080

**3. (Sub lesson 1) True or false: the answer to "What does resolution count?" is: How finely pixels are packed — pixels per inch (ppi) when printed**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is a megapixel?" is: Width × height in pixels**
**Answer: False** — A million pixels

**5. (Sub lesson 1) True or false: the answer to "How is an image's total pixel count found?" is: Width × height in pixels**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does the sample rate count?" is: 44,100 Hz**
**Answer: False** — Samples per second — in hertz (Hz)

**7. (Sub lesson 2) True or false: the answer to "What sample rate does CD audio use?" is: 44,100 Hz**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does bit depth count?" is: Sample rate × bit depth × seconds**
**Answer: False** — The bits kept per sample

**9. (Sub lesson 2) True or false: the answer to "What three factors give an audio file's data size?" is: Sample rate × bit depth × seconds**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why does Malaysia teach the units first?" is: A grid of pixels — single-colour dots**
**Answer: False** — Every later claim about quality and file size is built from them
