# Measuring Digital Image and Audio — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Measuring an image — pixels and resolution
Sub lesson 1 questions from the type files. Pass mark: A grid of pixels — single-colour dots; In pixels — width × height, such as 1920 × 1080; How finely pixels are packed — pixels per inch (ppi) when printed; A million pixels; Width × height in pixels.

## Sub lesson 2 — Measuring audio — sample rate and bit depth
Sub lesson 2 questions from the type files. Pass mark: Samples per second — in hertz (Hz); 44,100 Hz; The bits kept per sample; Sample rate × bit depth × seconds; Every later claim about quality and file size is built from them.
