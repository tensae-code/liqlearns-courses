# Motion guides — moving a symbol along a path — multiple choice

Pick the one right answer.

**1.** The guide layer is added by —
a) File → New  b) right-clicking the layer label → Add Motion Guide  c) pressing F6  d) Edit → Paste
**Answer: b) right-clicking the layer label → Add Motion Guide** — the book's step 2.

**2.** The path is drawn —
a) on the Graphic layer  b) in the guide layer  c) in the Timeline  d) in a panel
**Answer: b) in the guide layer** — the guide layer holds the path.

**3.** Frames are inserted on the guide layer at frame 60 by pressing —
a) F6  b) Enter  c) F5  d) Ctrl+Enter
**Answer: c) F5** — F5 inserts frames.

**4.** The new keyframe at frame 60 of the Graphic layer is made with —
a) F5  b) F6  c) Ctrl+S  d) Esc
**Answer: b) F6** — F6 makes the keyframe.

**5.** The symbol's bubble must sit —
a) above the path  b) beside the path  c) right below the path  d) anywhere on the stage
**Answer: c) right below the path** — at both ends.

**6.** The tween is created by —
a) File → Save  b) right-clicking any frame between 1 and 60 → Create Motion Tween  c) pressing Enter  d) double-clicking the symbol
**Answer: b) right-clicking any frame between 1 and 60 → Create Motion Tween** — the joining step.
