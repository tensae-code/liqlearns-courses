# Motion guides — moving a symbol along a path — ordering

Put these steps in the right order.

1. Drag the symbol to the path's other end at frame 60 (F6)
2. Draw the path in the guide layer
3. Add Motion Guide above the Graphic layer
4. Create Motion Tween between frames 1 and 60
5. Place the symbol and name its layer Graphic

**Answer:** Graphic layer → Add Motion Guide → draw the path → symbol to the other end at frame 60 → Create Motion Tween.
