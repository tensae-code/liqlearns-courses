# Lesson plan — Motion guides — moving a symbol along a path

**Course:** Computer Science and ICT · **Title:** Multimedia · **Lesson:** Motion guides — moving a symbol along a path
**Place in the curriculum:** Ethiopia Grade 10, Unit 4 — Image Processing and Multimedia (printed pp. 139–181).
**The one thing this lesson teaches:** a motion guide moves a symbol along a drawn path: a guide layer is added above the Graphic layer, the path is drawn, frames are stretched to frame 60, the symbol is set at both ends, and Create Motion Tween joins them.
**This lesson's own level:** it stands on Keyframe animation: a tween fills the frames between two set positions — here, two ends of a drawn path.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 2 seconds, looping.

## Before this lesson
- Recommended first: Keyframe animation — and editing an icon. Recommended, never forced. A learner can land here directly; the lesson stands alone.

## What the learner can do when it ends
1. Add a motion guide layer and draw a path in it.
2. Set the symbol at both path ends, at frames 1 and 60, bubble below the path.
3. Create the motion tween and view the result with Ctrl+Enter.
## What you need
A computer with Flash for the real doing; paper, a drawn circle and a coin for the rehearsal.

## If the learner is stuck
- Draws the path on the Graphic layer → the path belongs on the guide layer above it; the Graphic layer holds the symbol.
- Forgets F5 on the guide layer → the guide must stretch to frame 60 or the path ends before the journey does.
- Bubble beside or above the path → the bubble sits right below the path at both ends, or the symbol will not lock on.
