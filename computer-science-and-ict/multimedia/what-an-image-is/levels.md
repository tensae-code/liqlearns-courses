# What an image is — depth

This lesson is one whole lesson with no sub lessons. Pass mark: the learner can do and explain the lesson's one thing — an image is a visual representation of a person, animal or thing — a painting, a camera photograph, a picture created or copied and stored in electronic form, or a picture scanned through an image scanner. Practice deepens with more items from the question files and harder corners of the same skill (new images, new values, the same steps), never with new content the lesson does not teach.
