# What an image is — true or false

Say whether each statement is true or false.

**1.** A painting is one form of an image.
**Answer: True** — the first form.

**2.** An image can only be a photograph.
**Answer: False** — there are four forms — painting, photograph, stored picture, scanned picture.

**3.** A scanned picture starts as a picture on paper.
**Answer: True** — the scanner turns a paper picture into an electronic one.
