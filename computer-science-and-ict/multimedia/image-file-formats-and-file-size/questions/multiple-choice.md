# Image File Formats and File Size — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is an image file format?**
a) A rule for storing the picture's pixels  b) Plainly, with no squeezing — simple and large  c) It discards fine detail the eye barely misses  d) Everything — it compresses without discarding, and keeps transparency
**Answer: a) A rule for storing the picture's pixels**

**2. (Sub lesson 1) How does BMP store a picture?**
a) It discards fine detail the eye barely misses  b) Plainly, with no squeezing — simple and large  c) Everything — it compresses without discarding, and keeps transparency  d) 256 — it suits simple graphics
**Answer: b) Plainly, with no squeezing — simple and large**

**3. (Sub lesson 1) What does JPEG do to shrink a file?**
a) Everything — it compresses without discarding, and keeps transparency  b) 256 — it suits simple graphics  c) It discards fine detail the eye barely misses  d) JPEG
**Answer: c) It discards fine detail the eye barely misses**

**4. (Sub lesson 1) What does PNG keep that JPEG does not?**
a) 256 — it suits simple graphics  b) JPEG  c) No — of picture and format together  d) Everything — it compresses without discarding, and keeps transparency
**Answer: d) Everything — it compresses without discarding, and keeps transparency**

**5. (Sub lesson 1) How many colours can GIF use?**
a) 256 — it suits simple graphics  b) JPEG  c) No — of picture and format together  d) A file size
**Answer: a) 256 — it suits simple graphics**

**6. (Sub lesson 2) For a photograph, which format is usually smallest?**
a) No — of picture and format together  b) JPEG  c) A file size  d) By purpose — print, web, or archive
**Answer: b) JPEG**

**7. (Sub lesson 2) Is file size a property of the picture alone?**
a) A file size  b) By purpose — print, web, or archive  c) No — of picture and format together  d) BMP — stored plainly
**Answer: c) No — of picture and format together**

**8. (Sub lesson 2) What is choosing a format also choosing?**
a) By purpose — print, web, or archive  b) BMP — stored plainly  c) A rule for storing the picture's pixels  d) A file size
**Answer: d) A file size**

**9. (Sub lesson 2) By what should the format be chosen?**
a) By purpose — print, web, or archive  b) BMP — stored plainly  c) A rule for storing the picture's pixels  d) Plainly, with no squeezing — simple and large
**Answer: a) By purpose — print, web, or archive**

**10. (Sub lesson 2) Which format is biggest for the same image, typically?**
a) A rule for storing the picture's pixels  b) BMP — stored plainly  c) Plainly, with no squeezing — simple and large  d) It discards fine detail the eye barely misses
**Answer: b) BMP — stored plainly**
