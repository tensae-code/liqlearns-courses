# Image File Formats and File Size — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is an image file format?" is: A rule for storing the picture's pixels**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How does BMP store a picture?" is: It discards fine detail the eye barely misses**
**Answer: False** — Plainly, with no squeezing — simple and large

**3. (Sub lesson 1) True or false: the answer to "What does JPEG do to shrink a file?" is: It discards fine detail the eye barely misses**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does PNG keep that JPEG does not?" is: 256 — it suits simple graphics**
**Answer: False** — Everything — it compresses without discarding, and keeps transparency

**5. (Sub lesson 1) True or false: the answer to "How many colours can GIF use?" is: 256 — it suits simple graphics**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "For a photograph, which format is usually smallest?" is: No — of picture and format together**
**Answer: False** — JPEG

**7. (Sub lesson 2) True or false: the answer to "Is file size a property of the picture alone?" is: No — of picture and format together**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is choosing a format also choosing?" is: By purpose — print, web, or archive**
**Answer: False** — A file size

**9. (Sub lesson 2) True or false: the answer to "By what should the format be chosen?" is: By purpose — print, web, or archive**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Which format is biggest for the same image, typically?" is: A rule for storing the picture's pixels**
**Answer: False** — BMP — stored plainly
