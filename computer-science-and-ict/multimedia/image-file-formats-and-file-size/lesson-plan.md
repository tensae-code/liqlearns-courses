## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Formats store the picture differently** — An **image file format** is a rule for storing the picture's pixels. **BMP** stores the pixels plainly, with no squeezing — simple and large. **JPEG** compresses by discarding fine detail the eye barely misses — much smaller, at a small quality cost. **PNG** compresses without discarding anything, and also keeps transparency. **GIF** is limited to 256 colours, so it suits simple graphics. The format is a choice about how the picture is kept, made before any particular picture is saved.
2. **The same image, different sizes** — Because the formats store differently, **the same image** saved in each format has a **different file size**: plainly stored BMP is biggest, losslessly squeezed PNG is smaller, detail-discarding JPEG is usually smallest for a photograph. Malaysia's relation is the lesson: file size is not a property of the picture alone — it is a property of picture **and format together**. Choosing a format is choosing a size, which is why the choice is made by purpose: print, web, or archive.
