# Colour Depth, Resolution and Image Quality — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is colour depth?" is: The number of bits per pixel — how many colours one pixel can choose from**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How many colours does 1 bit per pixel give?" is: About 16.7 million**
**Answer: False** — 2 — black or white

**3. (Sub lesson 1) True or false: the answer to "How many colours do 24 bits give?" is: About 16.7 million**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does more colour depth do to quality?" is: Makes it bigger — every pixel carries more bits**
**Answer: False** — Smoother shading and richer colour — higher quality

**5. (Sub lesson 1) True or false: the answer to "What does more colour depth do to file size?" is: Makes it bigger — every pixel carries more bits**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is resolution?" is: Sharper edges and smaller detail**
**Answer: False** — How many pixels the image has — the fineness of its grid

**7. (Sub lesson 2) True or false: the answer to "What does a finer grid show?" is: Sharper edges and smaller detail**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How do quality, colour depth, resolution and size relate?" is: Print and archive work**
**Answer: False** — They rise together

**9. (Sub lesson 2) True or false: the answer to "Which work pays for both numbers to be high?" is: Print and archive work**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Can screen images be lighter?" is: The number of bits per pixel — how many colours one pixel can choose from**
**Answer: False** — Yes — screens need less than print, so the balance can be lower
