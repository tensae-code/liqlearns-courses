## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Colour depth — how many colours a pixel can be** — **Colour depth** is the number of **bits per pixel** — how many different colours one pixel can choose from. 1 bit gives 2 colours (black or white); 8 bits give 256 colours; 24 bits give about 16.7 million colours, more shades than the eye separates. More bits per pixel means smoother shading and richer colour — higher quality — and, because every pixel carries more bits, a bigger data size for the same grid.
2. **Resolution — how fine the grid is** — **Resolution** is how many pixels the image has — its grid's fineness (and, when printed, pixels per inch). A finer grid shows sharper edges and smaller detail: higher quality again — and again more data, because there are more pixels to store. Malaysia's relation joins the two: **quality, colour depth, resolution and size rise together**. A maker chooses the balance the purpose needs — screen images can be lighter; print and archive work pays for both numbers to be high.
