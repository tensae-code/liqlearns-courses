# Hands-on — Multimedia Programming — Sound, Image and Animation in Code

The lesson with your hands and your feet, not only your eyes.

## Task one
('Move the shape', 'Add one shape and animate it across the window by repeated moving, with one rotation and one fade. Then make it bounce off the window's edge by a condition.')

## Task two
('Build the game', 'Build the Bouncing Ball game step by step: window, ball in flight, paddle on the mouse, wall bounces, a sound on each hit. Play it and record one improvement you would make next.')
