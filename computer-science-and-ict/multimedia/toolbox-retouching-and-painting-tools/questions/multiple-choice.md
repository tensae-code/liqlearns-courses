# Toolbox — retouching and painting tools — multiple choice

Pick the one right answer.

**1.** The Clone Stamp —
a) erases pixels  b) samples pixels from one area and paints them over another  c) samples colours only  d) draws shapes
**Answer: b) samples pixels from one area and paints them over another** — sample here, paint there.

**2.** Which tool removes blemishes quickly?
a) Spot Healing Brush  b) Eraser  c) Zoom  d) Pen
**Answer: a) Spot Healing Brush** — Spot Healing Brush — the teacher guide's key names the healing tool's job: removing blemishes.

**3.** The Eyedropper —
a) paints lines  b) samples colours  c) crops images  d) adds text
**Answer: b) samples colours** — samples colours; raise Sample Size for a better average.

**4.** Dodge does what, and Burn?
a) both darken  b) Dodge lightens, Burn darkens  c) Dodge darkens, Burn lightens  d) both lighten
**Answer: b) Dodge lightens, Burn darkens** — Dodge lightens; Burn darkens.

**5.** A gradual blend between colours is made with —
a) Gradient  b) Eraser  c) Crop  d) Count
**Answer: a) Gradient** — Gradient.

**6.** The History Brush —
a) deletes history  b) restores part of an image to an earlier state  c) draws paths  d) measures colour
**Answer: b) restores part of an image to an earlier state** — paints back an earlier state.
