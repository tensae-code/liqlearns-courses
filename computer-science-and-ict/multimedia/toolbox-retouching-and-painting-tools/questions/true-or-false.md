# Toolbox — retouching and painting tools — true or false

Say whether each statement is true or false.

**1.** The Eraser can paint back an earlier state of the image.
**Answer: True** — it erases permanently OR paints back an earlier state.

**2.** The Blur tool sharpens edges.
**Answer: False** — Blur softens; Sharpen is in its family for the opposite job.

**3.** The Frame tool places an image into rectangular or elliptical shapes.
**Answer: True** — that is the Frame tool's job.
