# Toolbox — retouching and painting tools — depth

This lesson is one whole lesson with no sub lessons. Pass mark: the learner can do and explain the lesson's one thing — the Toolbox's middle families fix and paint: Crop, Eyedropper, the Healing brushes, Brush, Clone Stamp, History Brush, Eraser, Gradient, Blur and Dodge families. Practice deepens with more items from the question files and harder corners of the same skill (new images, new values, the same steps), never with new content the lesson does not teach.
