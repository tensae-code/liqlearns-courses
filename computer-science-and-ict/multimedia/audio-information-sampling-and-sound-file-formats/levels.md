This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Sampling — the wave measured into numbers
Sub lesson 1 questions from the type files. Pass mark: A continuous wave; the computer holds only numbers; Measuring the wave at regular instants and keeping each measurement as a number; A wave near enough to the original for the ear; A larger file; The samples themselves, full and uncompressed.
