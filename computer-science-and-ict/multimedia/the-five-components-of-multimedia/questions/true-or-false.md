# The five components of multimedia — true or false

Say whether each sentence is true or false.

**1.** Text is the backbone of electronic books and reference works.
**Answer: True** — as taught.

**2.** In interactive multimedia, users only receive video and never control it.
**Answer: False** — users respond and control elements.

**3.** Animation is photographic images played at speed.
**Answer: False** — that is video; animation is drawn images that change or move.
