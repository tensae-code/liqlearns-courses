# Multimedia production — the eight roles — true or false

Say whether each sentence is true or false.

**1.** The content specialist researches the content.
**Answer: True** — as tabled.

**2.** The text editor captures and digitises video.
**Answer: False** — that is the audio-video specialist.

**3.** Production can aim to educate, sell, narrate or make art.
**Answer: True** — the four aims taught.
