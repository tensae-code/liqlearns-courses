# Multimedia production — the eight roles — multiple choice

Pick the one right answer.

**1.** Multimedia production begins by —
a) selling the product  b) gathering content elements and integrating them  c) writing code first  d) printing the result
**Answer: b) gathering content elements and integrating them** — gather, then integrate.

**2.** The production manager —
a) revises all text  b) defines, coordinates and facilitates  c) records narration  d) writes all code
**Answer: b) defines, coordinates and facilitates** — the coordinating role.

**3.** Logos, collages and 3D objects are made by the —
a) content specialist  b) text editor  c) computer graphic artist  d) programmer
**Answer: c) computer graphic artist** — the artist's list.

**4.** The scriptwriter —
a) visualises the environment and its virtual-reality integration  b) edits video  c) researches facts only  d) manages the budget
**Answer: a) visualises the environment and its virtual-reality integration** — as tabled.

**5.** Code and scripts in the authoring language are written by the —
a) architect  b) programmer  c) manager  d) audio-video specialist
**Answer: b) programmer** — the programmer's job.
