# Layers in Graphics Editing — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a layer?" is: A transparent sheet holding part of the picture**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is the visible picture?" is: The picture — upper paint covers lower**
**Answer: False** — The stack seen from above, through all sheets

**3. (Sub lesson 1) True or false: the answer to "What does the top layer do where its paint is opaque?" is: Covers what is below**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does the eye toggle do?" is: Editing while the wrong layer is active**
**Answer: False** — Shows or hides that layer

**5. (Sub lesson 1) True or false: the answer to "What changes when the stack is reordered?" is: The picture — upper paint covers lower**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is the working habit for elements?" is: Merges the stack into one layer**
**Answer: False** — One element per layer, named

**7. (Sub lesson 2) True or false: the answer to "What causes most wrong-thing-changed accidents?" is: Editing while the wrong layer is active**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does opacity fade?" is: A transparent sheet holding part of the picture**
**Answer: False** — A whole layer

**9. (Sub lesson 2) True or false: the answer to "What does flattening do?" is: Merges the stack into one layer**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "When and how should flattening happen?" is: Covers what is below**
**Answer: False** — Last, on a copy — it cannot be undone into parts
