# Bitmap Pictures and Vector Pictures in the Paint Editor — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) A vector shape stays sharp when enlarged.**
**Answer: True** — It is recalculated as a shape at the new size.

**2. (Sub lesson 1) Grouped shapes can be ungrouped again.**
**Answer: True** — Group to move as one; ungroup for the parts.

**3. (Sub lesson 2) Converting bitmap back to vector restores the lost shapes.**
**Answer: False** — The flattening to dots is a one-way loss.
