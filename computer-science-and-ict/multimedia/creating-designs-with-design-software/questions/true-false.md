# Creating Designs with Design Software — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is design software used for?" is: To create designs on a computer**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "A design in software starts as what?" is: Files, for later use and sharing**
**Answer: False** — An idea — from the design brief

**3. (Sub lesson 1) True or false: the answer to "What do design software tools let you do?" is: Draw and change shapes and lines**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Designs made in software can be saved as what?" is: The design brief**
**Answer: False** — Files, for later use and sharing

**5. (Sub lesson 1) True or false: the answer to "Why design on a computer?" is: Changes are quick and exact copies are easy**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Before it is final, a design is checked against what?" is: To a printer, a maker, or a machine**
**Answer: False** — The design brief

**7. (Sub lesson 2) True or false: the answer to "Measurements in a design must be what?" is: Accurate**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "A design file can be sent where?" is: The design brief or plan**
**Answer: False** — To a printer, a maker, or a machine

**9. (Sub lesson 2) True or false: the answer to "What does the undo tool let a designer do?" is: Take back a change**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Good design software work begins with what?" is: An idea — from the design brief**
**Answer: False** — The design brief or plan
