# Digitising an Analogue Signal — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Between two samples, the digitised copy preserves exactly what the signal did.**
**Answer: False** — Nothing between samples is recorded; the copy holds only the sampled values.

**2. (Sub lesson 1) Sampling slower than twice the highest frequency can create false lower patterns called aliasing.**
**Answer: True** — Fast changes slip between samples and reappear disguised — the wagon-wheel effect in sound form.

**3. (Sub lesson 2) Increasing the bit depth decreases quantisation error.**
**Answer: True** — More bits mean more levels, smaller steps between rungs, and a smaller rounding gap for each sample.

**4. (Sub lesson 2) Coding is the step where the signal's values are rounded to levels.**
**Answer: False** — Rounding to levels is quantisation. Coding is the final step: writing each chosen level's number in binary.
