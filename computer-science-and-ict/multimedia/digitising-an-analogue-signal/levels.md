# Digitising an Analogue Signal — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure). Practice is tied to the learner's skill number, as before. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Sampling — measuring at regular instants
Sub lesson 1 questions from the type files. Pass mark: say what a sample is and what the sampling rate measures, state the Nyquist rule (at least twice the highest frequency), and explain in words what goes wrong when the rate is too low.

## Sub lesson 2 — Quantisation and coding — levels, bits and the size of the copy
Sub lesson 2 questions from the type files. Pass mark: say what quantisation does and what error it introduces, compute the levels for a given bit depth, and estimate a recording's size from rate, depth and length.
