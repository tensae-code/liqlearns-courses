# Multimedia and hypermedia — linear vs linked — multiple choice

Pick the one right answer.

**1.** Multimedia is the integration of —
a) text only  b) text, pictures, graphics, audio, animation and video, processed digitally  c) printed media  d) audio and video only
**Answer: b) text, pictures, graphics, audio, animation and video, processed digitally** — the closing definition.

**2.** Hypermedia differs from multimedia because it is —
a) louder  b) non-linear — material linked by a hypertext program  c) older  d) silent
**Answer: b) non-linear — material linked by a hypertext program** — links change the journey.

**3.** The best example of hypermedia given is —
a) a film  b) the World Wide Web  c) a radio play  d) a printed book
**Answer: b) the World Wide Web** — the Web.

**4.** In hypermedia, the user moves —
a) only forwards  b) non-linearly through linked material  c) backwards only  d) not at all
**Answer: b) non-linearly through linked material** — the user's path is chosen.

**5.** Computer animation is —
a) filming real actors  b) creating moving images by computer  c) printing flip books only  d) recording sound
**Answer: b) creating moving images by computer** — the unit summary's definition.
