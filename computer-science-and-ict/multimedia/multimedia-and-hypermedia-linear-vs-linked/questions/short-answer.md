# Multimedia and hypermedia — linear vs linked — short answer

Answer in one or two sentences.

**1.** State the one difference between multimedia and hypermedia in a sentence.
**Answer:** Hypermedia links the multimedia material together (by a hypertext program) so the user moves through it non-linearly, instead of following one straight line.

**2.** Why does the guide's key call hypermedia media you can 'interact with at the same time'?
**Answer:** Because its links let the user act on the media — choosing and following links — while seeing and hearing it, not only receiving it.
