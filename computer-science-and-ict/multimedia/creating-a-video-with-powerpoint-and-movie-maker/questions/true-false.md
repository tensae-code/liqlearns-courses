# Creating a Video with PowerPoint and Movie Maker — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "How does a presentation become a video?" is: By exporting it**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is recorded over the slides?" is: By exporting it**
**Answer: False** — A narration

**3. (Sub lesson 1) True or false: the answer to "What do timings set?" is: How long each slide stays**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does the exported video not need?" is: By exporting it**
**Answer: False** — A presenter, or PowerPoint

**5. (Sub lesson 1) True or false: the answer to "What does the slide show become on export?" is: An object that can be sent, stored and replayed**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is added to a Movie Maker project?" is: Cuts a clip's ends**
**Answer: False** — Videos, photos and music

**7. (Sub lesson 2) True or false: the answer to "What does trim do?" is: Cuts a clip's ends**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does split do?" is: Videos, photos and music**
**Answer: False** — Divides a clip so its middle can be removed or moved

**9. (Sub lesson 2) True or false: the answer to "Name two more shaping tools from the lesson." is: Fade and speed change**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is the editor's order in the book?" is: Videos, photos and music**
**Answer: False** — Gather, arrange, trim, then polish
