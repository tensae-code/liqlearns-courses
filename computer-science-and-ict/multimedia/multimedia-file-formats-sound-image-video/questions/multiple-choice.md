# Multimedia file formats — sound, image, video — multiple choice

Pick the one right answer.

**1.** A file format is —
a) a folder name  b) the structure in which information is stored or encoded in a file  c) a program menu  d) a screen size
**Answer: b) the structure in which information is stored or encoded in a file** — the definition taught.

**2.** Which set is all sound formats?
a) WAV, MIDI, WMA  b) JPEG, PNG, GIF  c) AVI, MPEG, WAV  d) TIFF, BMP, PNG
**Answer: a) WAV, MIDI, WMA** — the sound shelf.

**3.** Which set is all image formats?
a) AVI, MPEG  b) WAV, WMA  c) TIFF, JPEG, GIF, PNG, BMP  d) MIDI, GIF, AVI
**Answer: c) TIFF, JPEG, GIF, PNG, BMP** — the image shelf — five formats.

**4.** The video formats named are —
a) AVI and MPEG  b) WAV and WMA  c) GIF and PNG  d) TIFF and BMP
**Answer: a) AVI and MPEG** — the video shelf.

**5.** An image file can be _____ a document.
a) only printed from  b) inserted into or linked to  c) deleted by  d) renamed by
**Answer: b) inserted into or linked to** — inserted or linked.
