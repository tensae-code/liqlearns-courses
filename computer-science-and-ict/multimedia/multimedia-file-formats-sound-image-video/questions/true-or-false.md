# Multimedia file formats — sound, image, video — true or false

Say whether each sentence is true or false.

**1.** MIDI is an image format.
**Answer: False** — MIDI is on the sound shelf.

**2.** There are five image formats named in this lesson.
**Answer: True** — TIFF, JPEG, GIF, PNG, BMP.

**3.** A format only matters for text files.
**Answer: False** — multimedia work needs formats for text, image, audio and video.
