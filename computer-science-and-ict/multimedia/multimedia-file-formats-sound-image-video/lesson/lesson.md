# Multimedia file formats — sound, image, video

## Do it first

Look at the end of any media file name you know — a song, a photo, a film. Before reading on, write down the endings you can remember. This lesson sorts the multimedia endings by medium.

## What a file format is

A **file format** is the structure in which information is stored or encoded in a file. Multimedia work needs the current formats for text, image, audio and video — and an image file, for example, is either **inserted** into a document or **linked** to it.

## The three shelves

**Sound:** WAV, MIDI, WMA. **Image:** TIFF, JPEG, GIF, PNG, BMP. **Video:** AVI, MPEG.

Each format name is short for a fuller name, and the placements of this course keep the full expansions with the formats: for example JPEG is the photographic image format, GIF the graphics interchange format, and MPEG the moving-picture video format. Learn the shelves first — medium first, format second — and a strange ending can be placed even before it is known well.

## Say it to your companion

Read the three shelves aloud to your companion — medium, then its formats — until you can say all ten formats under the right medium without looking.

## Do It Yourself

1. Sort these endings under sound, image or video: WAV, PNG, AVI, MIDI, BMP, MPEG, WMA, TIFF, GIF, JPEG.
2. Say what a file format is, in one sentence.
3. Say the two ways an image file can sit with a document.
