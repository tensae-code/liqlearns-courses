# Designing Characters for Animation — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — A character is a drawing that must survive movement
Sub lesson 1 questions from the type files. Pass mark: Being drawn again, in any pose, hundreds of times; Simple shapes — circles and ovals; Cover the character in black — if it is still recognisably itself, the design works; Young and comic; On paper, before any film is made.

## Sub lesson 2 — Face, colour and personality — the model sheet
Sub lesson 2 questions from the type files. Pass mark: The fixed record of the character — front and side views, expressions, and colours; They are drawn with the same shapes as the character itself; Few — and constant through the film; It is drawn — posture, eye size, a signature item of clothing; Every scene is drawn from the model sheet.
