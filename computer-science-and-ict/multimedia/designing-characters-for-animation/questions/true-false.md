# Designing Characters for Animation — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Being drawn again, in any pose, hundreds of times**
**Answer: True**

**2. (Sub lesson 1) True or false: Being drawn again, in any pose, hundreds of times** — as the answer to: What is a character built from?
**Answer: False — Simple shapes — circles and ovals**

**3. (Sub lesson 1) True or false: Cover the character in black — if it is still recognisably itself, the design works**
**Answer: True**

**4. (Sub lesson 1) True or false: Cover the character in black — if it is still recognisably itself, the design works** — as the answer to: What does a big head read as?
**Answer: False — Young and comic**

**5. (Sub lesson 1) True or false: On paper, before any film is made**
**Answer: True**

**6. (Sub lesson 2) True or false: On paper, before any film is made** — as the answer to: What is a model sheet?
**Answer: False — The fixed record of the character — front and side views, expressions, and colours**

**7. (Sub lesson 2) True or false: They are drawn with the same shapes as the character itself**
**Answer: True**

**8. (Sub lesson 2) True or false: They are drawn with the same shapes as the character itself** — as the answer to: How many colours does a character get?
**Answer: False — Few — and constant through the film**

**9. (Sub lesson 2) True or false: It is drawn — posture, eye size, a signature item of clothing**
**Answer: True**

**10. (Sub lesson 2) True or false: It is drawn — posture, eye size, a signature item of clothing** — as the answer to: What keeps a character the same through a whole film?
**Answer: False — Every scene is drawn from the model sheet**
