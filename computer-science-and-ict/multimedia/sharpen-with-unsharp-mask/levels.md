# Sharpen with Unsharp Mask — depth

This lesson is one whole lesson with no sub lessons. Pass mark: the learner can do and explain the lesson's one thing — duplicate the background layer as Sharpen Layer, zoom to 100%, then Filter → Sharpen → Unsharp Mask — set Radius and Amount while watching the preview, toggling before/after until satisfied, then OK and save. Practice deepens with more items from the question files and harder corners of the same skill (new images, new values, the same steps), never with new content the lesson does not teach.
