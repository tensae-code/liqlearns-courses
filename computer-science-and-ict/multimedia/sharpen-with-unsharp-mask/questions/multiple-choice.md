# Sharpen with Unsharp Mask — multiple choice

Pick the one right answer.

**1.** The duplicated layer is renamed —
a) Layer 1  b) Sharpen Layer  c) Sharp Copy  d) Background 2
**Answer: b) Sharpen Layer** — Sharpen Layer.

**2.** Before opening the dialog, zoom to —
a) 50%  b) 100%  c) 200%  d) fit screen
**Answer: b) 100%** — 100%.

**3.** The Unsharp Mask dialog is reached by —
a) Image → Adjustments  b) Filter → Sharpen → Unsharp Mask  c) Layer → Duplicate  d) File → Export
**Answer: b) Filter → Sharpen → Unsharp Mask** — Filter → Sharpen → Unsharp Mask.

**4.** In the dialog you set —
a) Width and Height  b) Radius and Amount  c) Colour and Saturation  d) Font and Size
**Answer: b) Radius and Amount** — Radius and Amount (Threshold as taught).

**5.** Clicking the preview —
a) saves the file  b) toggles before/after  c) closes the dialog  d) deletes the layer
**Answer: b) toggles before/after** — toggle before/after.

**6.** Dragging inside the preview —
a) moves the dialog  b) inspects different parts of the image  c) changes Radius  d) zooms the canvas
**Answer: b) inspects different parts of the image** — inspect different parts.
