# Drawing and filling a first Flash piece — true or false

Say whether each sentence is true or false.

**1.** The Paint Bucket is used before the rectangle is drawn.
**Answer: False** — draw first, fill second.

**2.** Line and Oval are also toolbox drawing tools.
**Answer: True** — named with Rectangle.

**3.** Ctrl+S saves the piece.
**Answer: True** — the keyboard route.
