# Drawing and filling a first Flash piece — multiple choice

Pick the one right answer.

**1.** A new Flash project starts with —
a) File → Save  b) File → New  c) Control → Test Movie  d) File → Import
**Answer: b) File → New** — File → New.

**2.** The first tool clicked is the —
a) Paint Bucket Tool  b) Rectangle Tool  c) Text Tool  d) Free Transform Tool
**Answer: b) Rectangle Tool** — outline first.

**3.** The fill colour is picked from —
a) the Timeline  b) Color Swatches  c) the layer panel  d) the Properties panel only
**Answer: b) Color Swatches** — from Color Swatches at the bucket step.

**4.** To fill, you click —
a) on the outline  b) outside the rectangle  c) inside the rectangle  d) on the toolbox
**Answer: c) inside the rectangle** — inside the shape.

**5.** Saving is done by —
a) Ctrl+Enter only  b) File → Save or Ctrl+S  c) File → Import  d) pressing Enter
**Answer: b) File → Save or Ctrl+S** — the two saving routes.
