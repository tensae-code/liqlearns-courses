# Brightening a dark photo — multiple choice

Pick the one right answer.

**1.** A photo taken indoors without flash comes out —
a) overexposed  b) underexposed and dark  c) blurred  d) red-eyed
**Answer: b) underexposed and dark** — underexposed.

**2.** The layer is duplicated with —
a) Ctrl+C  b) Ctrl+J  c) Ctrl+V  d) Ctrl+Z
**Answer: b) Ctrl+J** — right-click → Duplicate, or Ctrl+J.

**3.** The copy is named —
a) Background 2  b) Layer 1  c) Copy A  d) Exposure
**Answer: b) Layer 1** — Layer 1.

**4.** Exposure is applied from —
a) Filter → Sharpen  b) Image → Adjustments → Exposure  c) Layer → New  d) File → Save As
**Answer: b) Image → Adjustments → Exposure** — Image → Adjustments → Exposure.

**5.** If the photo is still too dark, you —
a) start again  b) keep duplicating Layer 1 until satisfied  c) crop it  d) delete Layer 1
**Answer: b) keep duplicating Layer 1 until satisfied** — duplicate again until satisfied.

**6.** The GIMP pointer for this job is —
a) Filters → Enhance  b) Adjust Colour Levels (Colours → Levels)  c) Image → Image Size  d) Tools → Paint
**Answer: b) Adjust Colour Levels (Colours → Levels)** — Colours → Levels → Adjust Colour Levels.
