# Fixing red eye — true or false

Say whether each statement is true or false.

**1.** The foreground/background colours should be the default black and white for this fix.
**Answer: True** — step 3 of the book's order.

**2.** Red eye comes from sunlight.
**Answer: False** — from the camera flash above the lens.

**3.** In GIMP you first select the boundary of the iris with the red pupil.
**Answer: True** — then Filters → Enhance → Red Eye Removal.
