# The Photoshop window — naming its parts — multiple choice

Pick the one right answer.

**1.** The Tool Options Bar shows —
a) the document size  b) options attached to the selected tool  c) the layer stack  d) the menus
**Answer: b) options attached to the selected tool** — a brush shows size, softness and more.

**2.** The Layer Palette holds —
a) the menus  b) the layer stack, top layer above those below  c) the rulers  d) the search box
**Answer: b) the layer stack, top layer above those below** — the layer stack.

**3.** Guidelines are dragged from —
a) the Menu Bar  b) the Rulers  c) the Canvas  d) the Layer Options
**Answer: b) the Rulers** — from the rulers.

**4.** Document Details shows —
a) the compressed and real size  b) the tool options  c) the colour mode only  d) the file name only
**Answer: a) the compressed and real size** — compressed and real size.

**5.** Palettes are reached from —
a) the File menu  b) the Window menu  c) the Crop Tool  d) the Zoom Tool
**Answer: b) the Window menu** — Window menu.

**6.** The Active Image is —
a) a small thumbnail  b) the large working area  c) the top menu  d) a ruler
**Answer: b) the large working area** — the large working area.
