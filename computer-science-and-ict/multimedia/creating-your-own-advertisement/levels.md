# Creating Your Own Advertisement — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Plan before making
Sub lesson 1 questions from the type files. Pass mark: Product, audience, promise, action; The one feeling or gain you offer; Before touching materials; It persuades no one, however pretty; One sentence each.

## Sub lesson 2 — Making it — and answering for it
Sub lesson 2 questions from the type files. Pass mark: An image picturing the promise; a short slogan; the product shown at its best (also: repetition of the name); Names the tools it can spot in the other groups' ads; An honest one — for a real thing, with tools openly named; Makers who have used the tools can never unsee them; Short enough to stick.
