# Creating Your Own Advertisement — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Product, audience, promise, action**
**Answer: True**

**2. (Sub lesson 1) True or false: Product, audience, promise, action** — as the answer to: What is the promise?
**Answer: False — The one feeling or gain you offer**

**3. (Sub lesson 1) True or false: Before touching materials**
**Answer: True**

**4. (Sub lesson 1) True or false: Before touching materials** — as the answer to: What happens to an ad that cannot state its audience and promise?
**Answer: False — It persuades no one, however pretty**

**5. (Sub lesson 1) True or false: One sentence each**
**Answer: True**

**6. (Sub lesson 2) True or false: One sentence each** — as the answer to: Name three tools the makers spend.
**Answer: False — An image picturing the promise; a short slogan; the product shown at its best (also: repetition of the name)**

**7. (Sub lesson 2) True or false: Names the tools it can spot in the other groups' ads**
**Answer: True**

**8. (Sub lesson 2) True or false: Names the tools it can spot in the other groups' ads** — as the answer to: What kind of ad does the parcours make?
**Answer: False — An honest one — for a real thing, with tools openly named**

**9. (Sub lesson 2) True or false: Makers who have used the tools can never unsee them**
**Answer: True**

**10. (Sub lesson 2) True or false: Makers who have used the tools can never unsee them** — as the answer to: What must the slogan be?
**Answer: False — Short enough to stick**
