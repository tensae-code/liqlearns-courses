# Image processing software — meeting Photoshop — true or false

Say whether each statement is true or false.

**1.** Image processing software can crop out unwanted things from an image.
**Answer: True** — cropping out is named, with red eye as an example.

**2.** All image processing software is commercial.
**Answer: False** — it can be commercial or free — GIMP is free.

**3.** Photoshop is used by photographers and graphic designers.
**Answer: True** — both are named users.
