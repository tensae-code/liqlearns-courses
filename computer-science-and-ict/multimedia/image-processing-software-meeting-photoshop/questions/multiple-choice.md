# Image processing software — meeting Photoshop — multiple choice

Pick the one right answer.

**1.** Image processing software is used to —
a) type letters  b) organise, retouch and edit images  c) send email  d) play music
**Answer: b) organise, retouch and edit images** — organise, retouch, edit.

**2.** Which of these is FREE image software named in the lesson?
a) GIMP  b) Photoshop  c) Photo Explosion  d) Photo Styler
**Answer: a) GIMP** — GIMP is the free alternative named throughout the unit.

**3.** Photoshop is a general-purpose program for —
a) spreadsheets  b) raster images and vector graphics  c) databases  d) presentations only
**Answer: b) raster images and vector graphics** — raster (pixel-based) images and vector graphics.

**4.** A raster image is —
a) made of paths  b) pixel-based  c) text only  d) a sound file
**Answer: b) pixel-based** — raster = pixel-based.

**5.** Which of these can Photoshop build?
a) a business card  b) a spreadsheet formula  c) an email account  d) a network cable
**Answer: a) a business card** — website layouts, posters, business cards, greeting cards.
