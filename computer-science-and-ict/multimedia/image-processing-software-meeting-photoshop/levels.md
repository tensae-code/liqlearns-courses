# Image processing software — meeting Photoshop — depth

This lesson is one whole lesson with no sub lessons. Pass mark: the learner can do and explain the lesson's one thing — image processing software organises, retouches and edits images — and Photoshop, a general-purpose program for raster images and vector graphics, is the one this unit teaches. Practice deepens with more items from the question files and harder corners of the same skill (new images, new values, the same steps), never with new content the lesson does not teach.
