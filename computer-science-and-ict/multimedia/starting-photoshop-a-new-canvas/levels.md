# Starting Photoshop — a new canvas — depth

This lesson is one whole lesson with no sub lessons. Pass mark: the learner can do and explain the lesson's one thing — launch Photoshop, click Create New, set the project's properties — name, width, height, orientation, resolution, colour mode — and click Create to open a blank canvas. Practice deepens with more items from the question files and harder corners of the same skill (new images, new values, the same steps), never with new content the lesson does not teach.
