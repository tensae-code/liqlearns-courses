Today: **Starting Photoshop — a new canvas**.

First, what we are doing: launch Photoshop, click Create New, set the project's properties — name, width, height, orientation, resolution, colour mode — and click Create to open a blank canvas.

Launching Photoshop follows the same mechanism as other application software. Then, in the book's order:
1. Click Create New on the Home screen.
2. Choose a template.
3. Set the properties on the right: project name, width, height, orientation, resolution, colour mode.
4. Click Create.
The new project's workspace area is the Canvas — full of pixels you can change.
Resolution is described in pixels per inch (PPI): more PPI means more pixel information and a higher-quality, crisper image.
Opening an existing image instead is done from the File menu.
