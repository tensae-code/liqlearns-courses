# Starting Photoshop — a new canvas — true or false

Say whether each statement is true or false.

**1.** You set the properties before clicking Create.
**Answer: True** — properties on the right, then Create.

**2.** A higher PPI gives a lower-quality image.
**Answer: False** — more PPI = more pixel information = higher quality.

**3.** The canvas is full of pixels you can change.
**Answer: True** — that is the workspace.
