# Starting Photoshop — a new canvas — short answer

Answer in a sentence or a short list.

**1.** List the properties set when creating a new document.
**Answer:** Project name, width, height, orientation, resolution, colour mode.

**2.** Why does a higher resolution make an image crisper?
**Answer:** More pixels per inch means more pixel information is held, so the image is higher-quality and crisper.
