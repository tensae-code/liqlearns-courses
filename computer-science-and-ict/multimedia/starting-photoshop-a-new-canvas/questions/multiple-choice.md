# Starting Photoshop — a new canvas — multiple choice

Pick the one right answer.

**1.** The first step to a new Photoshop image is clicking —
a) Save  b) Create New on the Home screen  c) Print  d) Crop
**Answer: b) Create New on the Home screen** — Create New.

**2.** Which is NOT one of the properties set on the right?
a) width  b) height  c) resolution  d) printer name
**Answer: d) printer name** — name, width, height, orientation, resolution, colour mode.

**3.** The workspace area of a new project is called —
a) the Palette  b) the Canvas  c) the Ruler  d) the Layer
**Answer: b) the Canvas** — the Canvas.

**4.** Resolution is described in —
a) pixels per inch (PPI)  b) pages per inch  c) points per image  d) photos per inch
**Answer: a) pixels per inch (PPI)** — PPI.

**5.** More PPI means —
a) a smaller file only  b) more pixel information and a crisper image  c) fewer colours  d) a darker image
**Answer: b) more pixel information and a crisper image** — higher quality, crisper.

**6.** An existing image is opened from —
a) the File menu  b) the Crop Tool  c) the Layer Palette  d) the Zoom Tool
**Answer: a) the File menu** — File menu.
