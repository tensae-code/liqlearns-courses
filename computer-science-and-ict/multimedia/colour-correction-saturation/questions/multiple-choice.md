# Colour correction — Saturation — multiple choice

Pick the one right answer.

**1.** Increasing saturation makes colours —
a) darker  b) brighter and more vivid  c) sharper  d) bigger
**Answer: b) brighter and more vivid** — more vivid.

**2.** Removing saturation completely gives —
a) a red image  b) a black-and-white (grey-scale) image  c) an inverted image  d) a blank canvas
**Answer: b) a black-and-white (grey-scale) image** — grey-scale.

**3.** The adjustment layer added is —
a) Levels  b) Curves  c) Hue/Saturation  d) Exposure
**Answer: c) Hue/Saturation** — Hue/Saturation.

**4.** Too much saturation makes colours look —
a) natural  b) unnatural  c) darker  d) sharper
**Answer: b) unnatural** — unnatural — the book's warning.

**5.** The slider is dragged —
a) in the Properties panel  b) on the canvas  c) in the File menu  d) on the Ruler
**Answer: a) in the Properties panel** — Properties panel.
