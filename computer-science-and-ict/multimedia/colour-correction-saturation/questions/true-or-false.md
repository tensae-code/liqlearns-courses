# Colour correction — Saturation — true or false

Say whether each statement is true or false.

**1.** Decreasing saturation makes colours less vivid.
**Answer: True** — down = muted.

**2.** Saturation and brightness are the same thing.
**Answer: False** — saturation is colour vividness, not brightness.

**3.** A grey-scale image has no saturation.
**Answer: True** — removing it completely gives black-and-white.
