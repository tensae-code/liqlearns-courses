# Vector Graphics Design Software — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A grid of coloured dots — pixels**
**Answer: True**

**2. (Sub lesson 1) True or false: A grid of coloured dots — pixels** — as the answer to: What happens when a bitmap is enlarged?
**Answer: False — It tears into visible squares — it loses quality**

**3. (Sub lesson 1) True or false: A description — shapes, lines and curves held as objects with positions and properties**
**Answer: True**

**4. (Sub lesson 1) True or false: A description — shapes, lines and curves held as objects with positions and properties** — as the answer to: What happens when a vector picture is enlarged?
**Answer: False — Nothing is lost — it scales cleanly, from a stamp to a banner**

**5. (Sub lesson 1) True or false: Inkscape — free, open-source vector design software**
**Answer: True**

**6. (Sub lesson 2) True or false: Inkscape — free, open-source vector design software** — as the answer to: What is everything in a vector editor?
**Answer: False — An object — a shape, a path, or a piece of text**

**7. (Sub lesson 2) True or false: Selected, moved, resized, rotated, recoloured and layered**
**Answer: True**

**8. (Sub lesson 2) True or false: Selected, moved, resized, rotated, recoloured and layered** — as the answer to: What stays true of an object after drawing?
**Answer: False — It stays editable — its fill and outline can be changed later**

**9. (Sub lesson 2) True or false: Arranging objects into the finished product**
**Answer: True**

**10. (Sub lesson 2) True or false: Arranging objects into the finished product** — as the answer to: What product does the specialist book design?
**Answer: False — A decorative postcard, for a national tourism-design contest**
