# Choosing Content for a Target Audience — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Text, image, video and music**
**Answer: True**

**2. (Sub lesson 1) True or false: Text, image, video and music** — as the answer to: What is a target group?
**Answer: False — The people a piece of content is made for**

**3. (Sub lesson 1) True or false: Age, language and place (also knowledge, loves, abilities)**
**Answer: True**

**4. (Sub lesson 1) True or false: Age, language and place (also knowledge, loves, abilities)** — as the answer to: Why is 'everyone' not a target group?
**Answer: False — A gift for everyone fits no one in particular**

**5. (Sub lesson 1) True or false: Chooses blindly**
**Answer: True**

**6. (Sub lesson 2) True or false: Chooses blindly** — as the answer to: Name three choices the audience decides.
**Answer: False — The form, the language and the length (also the examples)**

**7. (Sub lesson 2) True or false: A digital gift for a named person or group**
**Answer: True**

**8. (Sub lesson 2) True or false: A digital gift for a named person or group** — as the answer to: How must each choice be defended?
**Answer: False — By the audience — 'she watches video', not 'I like video'**

**9. (Sub lesson 2) True or false: The plan's ruler — every choice is measured against it**
**Answer: True**

**10. (Sub lesson 2) True or false: The plan's ruler — every choice is measured against it** — as the answer to: Whose world should the examples come from?
**Answer: False — The audience's, not the maker's**
