# Audio Bit Depth and File Size — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a sample?" is: A measurement of the sound wave, taken thousands of times a second**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is bit depth?" is: 256 possible levels for the wave's height**
**Answer: False** — How many bits each sample is kept in

**3. (Sub lesson 1) True or false: the answer to "How many levels do 8 bits give?" is: 256 possible levels for the wave's height**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How many levels do 16 bits give?" is: A more exact trace of the wave — cleaner sound, less hiss**
**Answer: False** — 65,536 — CD quality

**5. (Sub lesson 1) True or false: the answer to "What does greater bit depth buy?" is: A more exact trace of the wave — cleaner sound, less hiss**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is the uncompressed audio size formula?" is: Doubles it, for the same recording**
**Answer: False** — Sample rate × bit depth × channels × seconds

**7. (Sub lesson 2) True or false: the answer to "What does doubling bit depth do to the file?" is: Doubles it, for the same recording**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "About how big is one minute of CD audio?" is: By purpose — low for voice notes, deep for music worth keeping**
**Answer: False** — About 10 MB

**9. (Sub lesson 2) True or false: the answer to "How is bit depth set, in Malaysia's teaching?" is: By purpose — low for voice notes, deep for music worth keeping**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Is bit depth an add-on or a multiplier in the sum?" is: A measurement of the sound wave, taken thousands of times a second**
**Answer: False** — A multiplier
