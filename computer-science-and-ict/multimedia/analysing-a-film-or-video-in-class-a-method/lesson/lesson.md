# Analysing a Film or Video in Class — A Method

## Do it first

The class watches a film and the first voice says “boring!” — judgement before anyone has actually said what was on the screen. Before reading on, say what a class should do first instead of judging.

## Sub lesson 1 — The method's order — describe, analyse, interpret

The livret's **method (démarche)** has a strict order. First **watch whole**, without stopping. Then **describe**: what is literally there — shots, sounds, words — with no opinions allowed. Then **analyse**: how the elements work (framing, point of view, editing, sound) and what effects they build. Only last **interpret**: what the film means, what it wants, whether it succeeds. The order is the method: judgement built on description survives argument; judgement without it is weather.

## Sub lesson 2 — Working the method as a class

In class the method is shared work: the description is built together on the board (any pupil may add, any pupil may challenge “show me where”), the analysis assigns elements to groups, and the interpretation is debated with evidence pointed back at the screen — a second viewing of the contested moment settles what memory argues about. The livret gives the démarche so any class can analyse any film the same disciplined way, not only films about school topics.
