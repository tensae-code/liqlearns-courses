# Analysing a Film or Video in Class — A Method — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Watch whole, describe, analyse, interpret**
**Answer: True**

**2. (Sub lesson 1) True or false: Watch whole, describe, analyse, interpret** — as the answer to: What is banned during describing?
**Answer: False — Opinions — only what is literally there**

**3. (Sub lesson 1) True or false: How the elements work and what effects they build**
**Answer: True**

**4. (Sub lesson 1) True or false: How the elements work and what effects they build** — as the answer to: When may the class judge the film?
**Answer: False — Last — at interpretation**

**5. (Sub lesson 1) True or false: Judgement built on description**
**Answer: True**

**6. (Sub lesson 2) True or false: Judgement built on description** — as the answer to: How is the description built?
**Answer: False — Together, on the board — any pupil may add or challenge**

**7. (Sub lesson 2) True or false: A second viewing of the contested moment**
**Answer: True**

**8. (Sub lesson 2) True or false: A second viewing of the contested moment** — as the answer to: How is the analysis shared out?
**Answer: False — Elements assigned to groups**

**9. (Sub lesson 2) True or false: Evidence on the screen**
**Answer: True**

**10. (Sub lesson 2) True or false: Evidence on the screen** — as the answer to: What does the démarche make possible?
**Answer: False — Any class analysing any film the same disciplined way**
