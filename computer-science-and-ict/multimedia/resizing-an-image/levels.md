# Resizing an image — depth

This lesson is one whole lesson with no sub lessons. Pass mark: the learner can do and explain the lesson's one thing — resizing changes an image's size through Image → Image Size: choose the size in the window, click OK, and save — for standard print sizes, for photo quality, and for enlarging small images to posters. Practice deepens with more items from the question files and harder corners of the same skill (new images, new values, the same steps), never with new content the lesson does not teach.
