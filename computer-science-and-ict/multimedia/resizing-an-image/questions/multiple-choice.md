# Resizing an image — multiple choice

Pick the one right answer.

**1.** Resizing is also called —
a) cropping  b) scaling  c) sampling  d) sharpening
**Answer: b) scaling** — scaling.

**2.** The Image Size window is reached from —
a) the File menu  b) the Image menu  c) the Layer Palette  d) the Toolbar
**Answer: b) the Image menu** — Image → Image Size.

**3.** Which is NOT a purpose of resizing named in the lesson?
a) printing in standard photo sizes  b) preserving the quality of digital photos  c) enlarging small images to poster size  d) removing red eye
**Answer: d) removing red eye** — red eye is a different lesson.

**4.** After choosing the size and clicking OK, you —
a) delete the file  b) save the file  c) restart Photoshop  d) crop again
**Answer: b) save the file** — save the file.

**5.** The size is chosen —
a) in the Image Size window  b) on the canvas  c) in the Layer Palette  d) with the Zoom Tool
**Answer: a) in the Image Size window** — in the Image Size window.
