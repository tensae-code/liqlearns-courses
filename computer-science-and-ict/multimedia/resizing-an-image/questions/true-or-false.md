# Resizing an image — true or false

Say whether each statement is true or false.

**1.** Resizing keeps the whole image and changes its size.
**Answer: True** — unlike cropping, nothing is cut away.

**2.** Resizing can enlarge a small image to poster size.
**Answer: True** — one of its three purposes.

**3.** The Image Size command is in the File menu.
**Answer: False** — it is in the Image menu.
