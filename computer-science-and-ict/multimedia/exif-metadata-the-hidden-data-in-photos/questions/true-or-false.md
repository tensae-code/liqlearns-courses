# EXIF Metadata — the Hidden Data in Photos — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) You must switch EXIF on and fill it in by hand for each photo.**
**Answer: False — The device writes the EXIF block automatically at the moment of capture.**

**2. (Sub lesson 2) Sending an original photo file can share your location even if the picture itself shows nothing about the place.**
**Answer: True — The coordinates ride inside the file’s EXIF block, invisible in the picture.**
