# Auto Colour and the automatic fixes — depth

This lesson is one whole lesson with no sub lessons. Pass mark: the learner can do and explain the lesson's one thing — the Image menu's automatic tools — Auto Colour among them — improve an image in one command, instead of manual Levels, Curves or Saturation work. Practice deepens with more items from the question files and harder corners of the same skill (new images, new values, the same steps), never with new content the lesson does not teach.
