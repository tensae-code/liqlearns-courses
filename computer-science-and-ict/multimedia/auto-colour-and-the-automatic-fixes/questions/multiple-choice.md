# Auto Colour and the automatic fixes — multiple choice

Pick the one right answer.

**1.** The automatic tools are found in —
a) the Image menu  b) the Layer Palette  c) the Toolbar  d) the File menu
**Answer: a) the Image menu** — the Image menu.

**2.** The automatic tool the book pictures is —
a) Auto Crop  b) Auto Colour  c) Auto Save  d) Auto Type
**Answer: b) Auto Colour** — Auto Colour.

**3.** An automatic tool improves an image —
a) in one command  b) in ten steps  c) only after printing  d) never
**Answer: a) in one command** — one command.

**4.** The auto tools stand instead of manual work with —
a) Crop and Marquee  b) Levels, Curves or Saturation  c) Pen and Type  d) Zoom and Hand
**Answer: b) Levels, Curves or Saturation** — the manual colour corrections.

**5.** Automatic tools are offered for images needing —
a) no correction  b) more specialised correction  c) deleting  d) resizing only
**Answer: b) more specialised correction** — specialised correction.
