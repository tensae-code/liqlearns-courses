# Auto Colour and the automatic fixes — true or false

Say whether each statement is true or false.

**1.** Auto Colour does in one command what manual correction does in steps.
**Answer: True** — that is its point.

**2.** The automatic tools are in the Filter menu.
**Answer: False** — the Image menu.

**3.** Manual Levels work is sometimes still the better choice.
**Answer: True** — the hand methods stay for when one command does not get it right.
