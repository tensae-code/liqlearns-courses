## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The elements of the moving image** — An audiovisual message is built from elements a reader can name: the **image** (framing, angle, movement), the **sound** (words, music, silence), the **editing** (what follows what, what is cut), and the **text** it carries (titles, captions). The activity's analysis takes a message apart element by element, because a message you can dismantle is a message you can judge — nothing in it is “just there”; every element was placed.
2. **Point of view — whose eyes?** — Every story is told from a **point of view (point de vue)**: the camera stands somewhere, the narration speaks as someone, and the viewer is lent those eyes. Change the point of view and sympathies move — the activity uses this on a message about bullying between pupils, where whose side the camera takes decides who the audience blames. The reader's standing question: whose eyes am I watching through, and what would this look like from the other side?

## The run of the lesson (in order)
1. **Do it first** — A schoolyard quarrel, filmed twice: once over one child's shoulder, once over the other's. Same quarrel, two different villains. Before reading on, say why the camera's place is an opinion. (lesson/lesson.md).
2. **The explanation** — the lesson text in lesson/lesson.md, in its parts in order.
   - ADD IMAGE: a picture of the elements of the moving image as the lesson describes it — the student studies the picture and names what each part shows.
   - ADD GIF: a GIF of point of view — whose eyes? in action — the student watches once, then says what changed and why.
   - ADD AUDIO: a voice reading the lesson's key names and definitions aloud, in the order the lesson gives them — the student listens once through, then reads the same lines aloud along with the voice. (Audio is a described slot in this build; no audio file is made.)
3. **Say it to your companion** — the companion block in lesson/lesson.md.
   - ADD VIDEO: the script in video-script.md, filmed — the lesson in the super-simple voice (made later, when videos are made).
4. **Questions** — from questions/: multiple-choice, true-false, matching, short-answer — served at the learner's level and teaching-mix (levels.md).
5. **Hands-on** — hands-on.md.
6. **Do It Yourself** — the doing block at the end of lesson/lesson.md.
