# Downloading and Managing Images — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Which command saves a picture from a web page?" is: Save image as, from the right-click menu**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What do you choose before the saving finishes?" is: Its format and its size**
**Answer: False** — The folder and the file name

**3. (Sub lesson 1) True or false: the answer to "What does the save box show about the image?" is: Its format and its size**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Who does an image found online belong to?" is: Permission — and the source named for school work**
**Answer: False** — Its maker

**5. (Sub lesson 1) True or false: the answer to "What is the rule for using an image in public work?" is: Permission — and the source named for school work**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How should image folders be organised?" is: One that says what the image is — not a camera code**
**Answer: False** — By subject or by project

**7. (Sub lesson 2) True or false: the answer to "What makes a good image file name?" is: One that says what the image is — not a camera code**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How can a big folder be sorted?" is: Delete them and keep the best copy**
**Answer: False** — By date or by name

**9. (Sub lesson 2) True or false: the answer to "What do you do with blurred and doubled images?" is: Delete them and keep the best copy**
**Answer: True**
