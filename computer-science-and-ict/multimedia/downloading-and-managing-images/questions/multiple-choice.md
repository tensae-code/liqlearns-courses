# Downloading and Managing Images — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Which command saves a picture from a web page?**
a) Save image as, from the right-click menu  b) The folder and the file name  c) Permission — and the source named for school work  d) By date or by name
**Answer: a) Save image as, from the right-click menu**

**2. (Sub lesson 1) What do you choose before the saving finishes?**
a) Its format and its size  b) The folder and the file name  c) By subject or by project  d) Delete them and keep the best copy
**Answer: b) The folder and the file name**

**3. (Sub lesson 1) What does the save box show about the image?**
a) Its maker  b) One that says what the image is — not a camera code  c) Its format and its size  d) They should be backed up
**Answer: c) Its format and its size**

**4. (Sub lesson 1) Who does an image found online belong to?**
a) Permission — and the source named for school work  b) By date or by name  c) Save image as, from the right-click menu  d) Its maker
**Answer: d) Its maker**

**5. (Sub lesson 1) What is the rule for using an image in public work?**
a) Permission — and the source named for school work  b) By subject or by project  c) Delete them and keep the best copy  d) The folder and the file name
**Answer: a) Permission — and the source named for school work**

**6. (Sub lesson 2) How should image folders be organised?**
a) One that says what the image is — not a camera code  b) By subject or by project  c) They should be backed up  d) Its format and its size
**Answer: b) By subject or by project**

**7. (Sub lesson 2) What makes a good image file name?**
a) By date or by name  b) Save image as, from the right-click menu  c) One that says what the image is — not a camera code  d) Its maker
**Answer: c) One that says what the image is — not a camera code**

**8. (Sub lesson 2) How can a big folder be sorted?**
a) Delete them and keep the best copy  b) The folder and the file name  c) Permission — and the source named for school work  d) By date or by name
**Answer: d) By date or by name**

**9. (Sub lesson 2) What do you do with blurred and doubled images?**
a) Delete them and keep the best copy  b) They should be backed up  c) Its format and its size  d) By subject or by project
**Answer: a) Delete them and keep the best copy**

**10. (Sub lesson 2) What should happen to the images that matter?**
a) Save image as, from the right-click menu  b) They should be backed up  c) Its maker  d) One that says what the image is — not a camera code
**Answer: b) They should be backed up**
