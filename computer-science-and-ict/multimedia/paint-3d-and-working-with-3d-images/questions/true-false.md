# Paint 3D — and Working with 3D Images — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A 3D library — ready objects placed, rotated and painted in space**
**Answer: True**

**2. (Sub lesson 1) True or false: A 3D library — ready objects placed, rotated and painted in space** — as the answer to: How is a 3D object different from a flat picture of the thing?
**Answer: False — It is a model with a back — it can be turned and viewed from any angle**

**3. (Sub lesson 1) True or false: Yes — the mixed canvas is the application's signature**
**Answer: True**

**4. (Sub lesson 1) True or false: Yes — the mixed canvas is the application's signature** — as the answer to: How is a 3D object painted?
**Answer: False — With the same brushes and colours as the 2D tools**

**5. (Sub lesson 1) True or false: It can be rotated — seen from any angle**
**Answer: True**

**6. (Sub lesson 2) True or false: It can be rotated — seen from any angle** — as the answer to: What is the practical product?
**Answer: False — A composed 3D scene — background, placed objects, painted surfaces, stickers and text**

**7. (Sub lesson 2) True or false: By size and overlap — nearer objects overlap farther ones**
**Answer: True**

**8. (Sub lesson 2) True or false: By size and overlap — nearer objects overlap farther ones** — as the answer to: Name the book's working order.
**Answer: False — Plan on paper, place big before small, check from two angles, save as you go**

**9. (Sub lesson 2) True or false: By exporting it as a flat image**
**Answer: True**

**10. (Sub lesson 2) True or false: By exporting it as a flat image** — as the answer to: Why save as you go, in the book's warning?
**Answer: False — 3D scenes are heavier files — lost work costs more**
