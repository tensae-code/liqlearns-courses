# Paint 3D — and Working with 3D Images — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does Paint 3D add to Paint?**
**Answer: A 3D library — ready objects placed, rotated and painted in space**

**2. (Sub lesson 1) How is a 3D object different from a flat picture of the thing?**
**Answer: It is a model with a back — it can be turned and viewed from any angle**

**3. (Sub lesson 1) Can 3D objects stand in a 2D scene?**
**Answer: Yes — the mixed canvas is the application's signature**

**4. (Sub lesson 1) How is a 3D object painted?**
**Answer: With the same brushes and colours as the 2D tools**

**5. (Sub lesson 1) What can be done with an object's view?**
**Answer: It can be rotated — seen from any angle**

**6. (Sub lesson 2) What is the practical product?**
**Answer: A composed 3D scene — background, placed objects, painted surfaces, stickers and text**

**7. (Sub lesson 2) How is depth shown between objects?**
**Answer: By size and overlap — nearer objects overlap farther ones**

**8. (Sub lesson 2) Name the book's working order.**
**Answer: Plan on paper, place big before small, check from two angles, save as you go**

**9. (Sub lesson 2) How can a 3D scene be shared into a document?**
**Answer: By exporting it as a flat image**

**10. (Sub lesson 2) Why save as you go, in the book's warning?**
**Answer: 3D scenes are heavier files — lost work costs more**
