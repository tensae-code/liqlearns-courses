# Animated GIFs — Timing and Moving Text — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A row of still frames shown one after another**
**Answer: True**

**2. (Sub lesson 1) True or false: A row of still frames shown one after another** — as the answer to: What sets the speed of the motion?
**Answer: False — Each frame's delay — the time that frame stays on screen**

**3. (Sub lesson 1) True or false: Fast, smooth motion**
**Answer: True**

**4. (Sub lesson 1) True or false: Fast, smooth motion** — as the answer to: Why give one frame a long delay?
**Answer: False — To hold the picture — letting the eye rest at a chosen moment**

**5. (Sub lesson 1) True or false: By watching the preview, then re-setting — not by numbers alone**
**Answer: True**

**6. (Sub lesson 2) True or false: By watching the preview, then re-setting — not by numbers alone** — as the answer to: How is moving text made?
**Answer: False — The text layer is copied across frames, shifted a little in each frame**

**7. (Sub lesson 2) True or false: Small, equal steps between frames**
**Answer: True**

**8. (Sub lesson 2) True or false: Small, equal steps between frames** — as the answer to: Why do text frames get longer delays?
**Answer: False — So the words stay on screen long enough to be read**

**9. (Sub lesson 2) True or false: Entering from an edge, crossing the picture, or rising — any steady path**
**Answer: True**

**10. (Sub lesson 2) True or false: Entering from an edge, crossing the picture, or rising — any steady path** — as the answer to: What must the text's motion serve?
**Answer: False — The message — motion that fights the message is cut**
