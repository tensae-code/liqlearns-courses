# Inserting and styling text in a multimedia project — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Inserting text begins with the —
a) Paint Bucket  b) Text Tool  c) Free Transform Tool  d) Eraser
**Answer: b) Text Tool** — then drag the field.

**2. (Sub lesson 1)** After typing, you deactivate the field by —
a) saving  b) clicking away from it  c) pressing Ctrl+Enter  d) closing the project
**Answer: b) clicking away from it** — click away.

**3. (Sub lesson 1)** Importing text runs —
a) Edit → Paste only  b) File → Import, choose the file, Open  c) Control → Test Movie  d) File → Save As
**Answer: b) File → Import, choose the file, Open** — the import route.

**4. (Sub lesson 1)** Pasting copied text uses —
a) Ctrl+S  b) Ctrl+Enter  c) Edit → Paste / Ctrl+V  d) F6
**Answer: c) Edit → Paste / Ctrl+V** — the paste route.

**5. (Sub lesson 2)** To style before typing, set type, position and spacing —
a) after saving  b) in the Properties panel before drawing the field  c) in the Timeline  d) in Color Swatches
**Answer: b) in the Properties panel before drawing the field** — style first, then the field.

**6. (Sub lesson 2)** If the Properties panel is hidden, bring it up by —
a) restarting Flash  b) right-clicking the work area → Properties  c) pressing Enter  d) opening the library
**Answer: b) right-clicking the work area → Properties** — the book's recovery route.
