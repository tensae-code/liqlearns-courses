# Inserting and styling text in a multimedia project — short answer

Answer in one or two sentences.

**1. (Sub lesson 1)** Give the three routes by which text enters a project.
**Answer:** Insert with the Text Tool (drag a field and type), import with File → Import, or paste copied text with Edit → Paste / Ctrl+V.

**2. (Sub lesson 2)** When is styling before typing better than styling after?
**Answer:** When a whole new field is being made — the style is set first, so it applies as you type, with no re-selecting afterwards.
