# Lesson plan — Inserting and styling text in a multimedia project

**Course:** Computer Science and ICT · **Title:** Multimedia · **Lesson:** Inserting and styling text in a multimedia project
**Place in the curriculum:** Ethiopia Grade 10, Unit 4 — Image Processing and Multimedia (printed pp. 139–181).
**The one thing this lesson teaches:** text enters a multimedia project by the Text Tool, by importing, or by pasting — and its style is set in the Properties panel before typing or changed afterwards.
**This lesson's own level:** it stands on Authoring tools — naming the Flash screen: the Properties panel and the work area are the stage for every move here.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 2 seconds, looping.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Getting text in — insert, import, paste** — Text Tool and drag a field; File → Import; Edit → Paste / Ctrl+V.
2. **Styling text — before and after** — set type, position and spacing in the Properties panel before drawing the field, or select typed text and set font, alignment and colour afterwards.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Authoring tools — naming the Flash screen. Recommended, never forced. A learner can land here directly; the lesson stands alone.

## What the learner can do when it ends
1. Insert text with the Text Tool, import it, and paste it — each in the book's steps.
2. Set text style before typing from the Properties panel.
3. Re-format typed text: font, alignment, colour.
## What you need
A computer with Flash for the real doing; paper for the route work.

## If the learner is stuck
- Types first, then hunts for where style lives → both orders work, but the panel is the one home for style in both; find it first.
- Leaves the text field active → click away from the field to deactivate it when typing is done.
