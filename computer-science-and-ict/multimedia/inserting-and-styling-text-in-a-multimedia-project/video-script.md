# Video script — Inserting and styling text in a multimedia project

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Today: **Text in a project**.

Three ways in. Text Tool — drag a box — type — click away.
File, Import — the text lands.
Or copy it, and paste: Control V.

Style it two ways. Before you type — set it in Properties.
After you type — select it, then set font, alignment, colour.

In first. Styled right. Done.
