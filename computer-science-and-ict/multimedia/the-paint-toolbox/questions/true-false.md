# The Paint Toolbox — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is the Paint toolbox?" is: The panel of drawing tools**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Which tools draw free lines?" is: Pours colour into a closed area**
**Answer: False** — Pencil and brush

**3. (Sub lesson 1) True or false: the answer to "What does the fill do?" is: Pours colour into a closed area**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does the picker do?" is: Knowing where each tool lives**
**Answer: False** — Takes a colour from the picture

**5. (Sub lesson 1) True or false: the answer to "What does Grade 5 spend the whole lesson on?" is: Knowing where each tool lives**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Which four parts make the editor's interface?" is: The face of the graphics editor**
**Answer: False** — Toolbox, colour palette, drawing canvas and menus

**7. (Sub lesson 2) True or false: the answer to "What is the interface called in the Grade 9 lesson?" is: The face of the graphics editor**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What must the Grade 9 pupil do with the parts?" is: The same four parts under new drawings**
**Answer: False** — Name them and say what each is for

**9. (Sub lesson 2) True or false: the answer to "What do later graphics programs keep?" is: The same four parts under new drawings**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Which book teaches the toolbox first?" is: The panel of drawing tools**
