# The Paint Toolbox — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is the Paint toolbox?**
a) The panel of drawing tools  b) Pencil and brush  c) Pours colour into a closed area  d) Takes a colour from the picture
**Answer: a) The panel of drawing tools**

**2. (Sub lesson 1) Which tools draw free lines?**
a) Pours colour into a closed area  b) Pencil and brush  c) Takes a colour from the picture  d) Knowing where each tool lives
**Answer: b) Pencil and brush**

**3. (Sub lesson 1) What does the fill do?**
a) Takes a colour from the picture  b) Knowing where each tool lives  c) Pours colour into a closed area  d) Toolbox, colour palette, drawing canvas and menus
**Answer: c) Pours colour into a closed area**

**4. (Sub lesson 1) What does the picker do?**
a) Knowing where each tool lives  b) Toolbox, colour palette, drawing canvas and menus  c) The face of the graphics editor  d) Takes a colour from the picture
**Answer: d) Takes a colour from the picture**

**5. (Sub lesson 1) What does Grade 5 spend the whole lesson on?**
a) Knowing where each tool lives  b) Toolbox, colour palette, drawing canvas and menus  c) The face of the graphics editor  d) Name them and say what each is for
**Answer: a) Knowing where each tool lives**

**6. (Sub lesson 2) Which four parts make the editor's interface?**
a) The face of the graphics editor  b) Toolbox, colour palette, drawing canvas and menus  c) Name them and say what each is for  d) The same four parts under new drawings
**Answer: b) Toolbox, colour palette, drawing canvas and menus**

**7. (Sub lesson 2) What is the interface called in the Grade 9 lesson?**
a) Name them and say what each is for  b) The same four parts under new drawings  c) The face of the graphics editor  d) Uzbekistan's Grade 5 Informatika
**Answer: c) The face of the graphics editor**

**8. (Sub lesson 2) What must the Grade 9 pupil do with the parts?**
a) The same four parts under new drawings  b) Uzbekistan's Grade 5 Informatika  c) The panel of drawing tools  d) Name them and say what each is for
**Answer: d) Name them and say what each is for**

**9. (Sub lesson 2) What do later graphics programs keep?**
a) The same four parts under new drawings  b) Uzbekistan's Grade 5 Informatika  c) The panel of drawing tools  d) Pencil and brush
**Answer: a) The same four parts under new drawings**

**10. (Sub lesson 2) Which book teaches the toolbox first?**
a) The panel of drawing tools  b) Uzbekistan's Grade 5 Informatika  c) Pencil and brush  d) Pours colour into a closed area
**Answer: b) Uzbekistan's Grade 5 Informatika**
