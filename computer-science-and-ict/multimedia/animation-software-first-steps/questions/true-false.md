# Animation Software — First Steps — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The picture the audience sees — the film's canvas**
**Answer: True**

**2. (Sub lesson 1) True or false: The picture the audience sees — the film's canvas** — as the answer to: What is the timeline?
**Answer: False — The film's length, cut into frames, under the stage**

**3. (Sub lesson 1) True or false: One still picture in the row**
**Answer: True**

**4. (Sub lesson 1) True or false: One still picture in the row** — as the answer to: How do frames become motion?
**Answer: False — Played in order at speed, the still pictures become movement**

**5. (Sub lesson 1) True or false: Set the stage size, add frames, draw on a frame, and play the row**
**Answer: True**

**6. (Sub lesson 2) True or false: Set the stage size, add frames, draw on a frame, and play the row** — as the answer to: Why are layers used?
**Answer: False — So the background and each character can change without redrawing the rest**

**7. (Sub lesson 2) True or false: One thing, simply — a bouncing ball, a blinking face**
**Answer: True**

**8. (Sub lesson 2) True or false: One thing, simply — a bouncing ball, a blinking face** — as the answer to: What are the two ways to make the change?
**Answer: False — Draw it frame by frame, or set key positions the software fills between**

**9. (Sub lesson 2) True or false: Few frames, one moving thing, play it often**
**Answer: True**

**10. (Sub lesson 2) True or false: Few frames, one moving thing, play it often** — as the answer to: Why play often?
**Answer: False — So no error grows too big to find**
