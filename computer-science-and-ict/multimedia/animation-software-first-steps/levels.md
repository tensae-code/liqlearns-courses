# Animation Software — First Steps — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — The animator's workplace — stage, timeline, frames
Sub lesson 1 questions from the type files. Pass mark: The picture the audience sees — the film's canvas; The film's length, cut into frames, under the stage; One still picture in the row; Played in order at speed, the still pictures become movement; Set the stage size, add frames, draw on a frame, and play the row.

## Sub lesson 2 — Layers and the first moving scene
Sub lesson 2 questions from the type files. Pass mark: So the background and each character can change without redrawing the rest; One thing, simply — a bouncing ball, a blinking face; Draw it frame by frame, or set key positions the software fills between; Few frames, one moving thing, play it often; So no error grows too big to find.
