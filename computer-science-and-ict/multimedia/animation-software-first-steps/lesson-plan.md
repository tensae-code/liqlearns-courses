## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The animator's workplace — stage, timeline, frames** — Animation software shows the film as a **stage** (the picture the audience sees) standing over a **timeline** (the film's length, cut into **frames**). Each frame is one still picture; played in order at speed, the frames become motion. The first steps are orientation: open the software, set the stage's size, add frames, draw on one, and **play** the row to see the film so far. Vietnam's specialist volume opens its cartoon craft here, because every later technique — characters, scenes, sound — lives on this timeline.
2. **Layers and the first moving scene** — Work is organised in **layers**: the background on one layer, a character on another, so each can change without redrawing the rest. A first animation moves one thing simply — a ball bouncing, a face blinking — by **drawing the change frame by frame** (or setting key positions the software fills between). The discipline of the first steps: **few frames, one moving thing, play it often** — the beginner who plays every three frames never builds an error too big to find.
