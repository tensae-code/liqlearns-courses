# Digital Audio — What Recorded Sound Is — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is digital audio?" is: Sound recorded and stored as data in an audio file**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What turns sound into a signal the computer can take in?" is: Every machine plays the same stored pattern**
**Answer: False** — A microphone

**3. (Sub lesson 1) True or false: the answer to "What does the computer do with the signal?" is: It samples it into numbers it can keep**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does an audio file actually hold?" is: It is recorded, or imported**
**Answer: False** — The counted pattern of the sound, not the sound itself

**5. (Sub lesson 1) True or false: the answer to "Why does the same file sound the same everywhere?" is: Every machine plays the same stored pattern**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Why can an audio file be copied perfectly?" is: Exporting and sharing the audio in a playable format**
**Answer: False** — Because it is data — numbers, copied exactly

**7. (Sub lesson 2) True or false: the answer to "What are the two ways sound enters an editor?" is: It is recorded, or imported**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is done to audio in editing?" is: Sound recorded and stored as data in an audio file**
**Answer: False** — It is cut, joined and cleaned

**9. (Sub lesson 2) True or false: the answer to "What two things finish the unit's road?" is: Exporting and sharing the audio in a playable format**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Which program does Class VIII use for the whole road?" is: It samples it into numbers it can keep**
**Answer: False** — Audacity
