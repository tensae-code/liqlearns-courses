# Digital Audio — What Recorded Sound Is — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is digital audio?**
a) Sound recorded and stored as data in an audio file  b) A microphone  c) It samples it into numbers it can keep  d) The counted pattern of the sound, not the sound itself
**Answer: a) Sound recorded and stored as data in an audio file**

**2. (Sub lesson 1) What turns sound into a signal the computer can take in?**
a) It samples it into numbers it can keep  b) A microphone  c) The counted pattern of the sound, not the sound itself  d) Every machine plays the same stored pattern
**Answer: b) A microphone**

**3. (Sub lesson 1) What does the computer do with the signal?**
a) The counted pattern of the sound, not the sound itself  b) Every machine plays the same stored pattern  c) It samples it into numbers it can keep  d) Because it is data — numbers, copied exactly
**Answer: c) It samples it into numbers it can keep**

**4. (Sub lesson 1) What does an audio file actually hold?**
a) Every machine plays the same stored pattern  b) Because it is data — numbers, copied exactly  c) It is recorded, or imported  d) The counted pattern of the sound, not the sound itself
**Answer: d) The counted pattern of the sound, not the sound itself**

**5. (Sub lesson 1) Why does the same file sound the same everywhere?**
a) Every machine plays the same stored pattern  b) Because it is data — numbers, copied exactly  c) It is recorded, or imported  d) It is cut, joined and cleaned
**Answer: a) Every machine plays the same stored pattern**

**6. (Sub lesson 2) Why can an audio file be copied perfectly?**
a) It is recorded, or imported  b) Because it is data — numbers, copied exactly  c) It is cut, joined and cleaned  d) Exporting and sharing the audio in a playable format
**Answer: b) Because it is data — numbers, copied exactly**

**7. (Sub lesson 2) What are the two ways sound enters an editor?**
a) It is cut, joined and cleaned  b) Exporting and sharing the audio in a playable format  c) It is recorded, or imported  d) Audacity
**Answer: c) It is recorded, or imported**

**8. (Sub lesson 2) What is done to audio in editing?**
a) Exporting and sharing the audio in a playable format  b) Audacity  c) Sound recorded and stored as data in an audio file  d) It is cut, joined and cleaned
**Answer: d) It is cut, joined and cleaned**

**9. (Sub lesson 2) What two things finish the unit's road?**
a) Exporting and sharing the audio in a playable format  b) Audacity  c) Sound recorded and stored as data in an audio file  d) A microphone
**Answer: a) Exporting and sharing the audio in a playable format**

**10. (Sub lesson 2) Which program does Class VIII use for the whole road?**
a) Sound recorded and stored as data in an audio file  b) Audacity  c) A microphone  d) It samples it into numbers it can keep
**Answer: b) Audacity**
