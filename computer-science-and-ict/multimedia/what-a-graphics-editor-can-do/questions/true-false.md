# What a Graphics Editor Can Do — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What are a graphics editor's three tasks?" is: Create, edit and prepare pictures**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Name two editing jobs." is: Sizing it and saving it in the needed form**
**Answer: False** — Fix and crop (or recolour, combine)

**3. (Sub lesson 1) True or false: the answer to "What does preparing a picture include?" is: Sizing it and saving it in the needed form**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "In the book's order, what comes before the interface?" is: So the pupil knows the job before the tools**
**Answer: False** — The tasks and possibilities

**5. (Sub lesson 1) True or false: the answer to "Why state the tasks first?" is: So the pupil knows the job before the tools**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Name two possibilities beyond drawing." is: Print or screen**
**Answer: False** — Work with photographs; join pieces into one picture (or add text)

**7. (Sub lesson 2) True or false: the answer to "Where can a finished picture be prepared for?" is: Print or screen**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "When does a possibility count as learned?" is: Text**
**Answer: False** — When the pupil can say which task it serves and try it

**9. (Sub lesson 2) True or false: the answer to "What can be added to an image?" is: Text**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Which book teaches this lesson?" is: Create, edit and prepare pictures**
**Answer: False** — Uzbekistan's Grade 9 Basics of Informatics
