# What a Graphics Editor Can Do — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What are a graphics editor's three tasks?**
a) Create, edit and prepare pictures  b) Fix and crop (or recolour, combine)  c) Sizing it and saving it in the needed form  d) The tasks and possibilities
**Answer: a) Create, edit and prepare pictures**

**2. (Sub lesson 1) Name two editing jobs.**
a) Sizing it and saving it in the needed form  b) Fix and crop (or recolour, combine)  c) The tasks and possibilities  d) So the pupil knows the job before the tools
**Answer: b) Fix and crop (or recolour, combine)**

**3. (Sub lesson 1) What does preparing a picture include?**
a) The tasks and possibilities  b) So the pupil knows the job before the tools  c) Sizing it and saving it in the needed form  d) Work with photographs; join pieces into one picture (or add text)
**Answer: c) Sizing it and saving it in the needed form**

**4. (Sub lesson 1) In the book's order, what comes before the interface?**
a) So the pupil knows the job before the tools  b) Work with photographs; join pieces into one picture (or add text)  c) Print or screen  d) The tasks and possibilities
**Answer: d) The tasks and possibilities**

**5. (Sub lesson 1) Why state the tasks first?**
a) So the pupil knows the job before the tools  b) Work with photographs; join pieces into one picture (or add text)  c) Print or screen  d) When the pupil can say which task it serves and try it
**Answer: a) So the pupil knows the job before the tools**

**6. (Sub lesson 2) Name two possibilities beyond drawing.**
a) Print or screen  b) Work with photographs; join pieces into one picture (or add text)  c) When the pupil can say which task it serves and try it  d) Text
**Answer: b) Work with photographs; join pieces into one picture (or add text)**

**7. (Sub lesson 2) Where can a finished picture be prepared for?**
a) When the pupil can say which task it serves and try it  b) Text  c) Print or screen  d) Uzbekistan's Grade 9 Basics of Informatics
**Answer: c) Print or screen**

**8. (Sub lesson 2) When does a possibility count as learned?**
a) Text  b) Uzbekistan's Grade 9 Basics of Informatics  c) Create, edit and prepare pictures  d) When the pupil can say which task it serves and try it
**Answer: d) When the pupil can say which task it serves and try it**

**9. (Sub lesson 2) What can be added to an image?**
a) Text  b) Uzbekistan's Grade 9 Basics of Informatics  c) Create, edit and prepare pictures  d) Fix and crop (or recolour, combine)
**Answer: a) Text**

**10. (Sub lesson 2) Which book teaches this lesson?**
a) Create, edit and prepare pictures  b) Uzbekistan's Grade 9 Basics of Informatics  c) Fix and crop (or recolour, combine)  d) Sizing it and saving it in the needed form
