# Vector Graphics Editing in Illustrator — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Nodes and control points — the handles of a vector shape
Sub lesson 1 questions from the type files. Pass mark: Nodes (anchor points) joined by segments; Bend the segment into a curve; Move its node; Pull the node's handle (control point); It is re-described, not repainted.

## Sub lesson 2 — Effects, fills and text in shapes
Sub lesson 2 questions from the type files. Pass mark: Colours the inside of a closed shape; Flat colour and gradient (or pattern); Bend and shadow the whole object; Set inside it, flowing to its boundary, or along a path; Shape first with nodes, then fill, then effects, then words.
