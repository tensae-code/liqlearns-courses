# Blender — Modifiers and Multiple Materials — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A standing instruction applied over the mesh — the mesh keeps its simple form; the effect can be changed or removed**
**Answer: True**

**2. (Sub lesson 1) True or false: One post, arrayed** — as the answer to: What does Array do?
**Answer: False — Repeats the object in a row or grid**

**3. (Sub lesson 1) True or false: One post, arrayed**
**Answer: True**

**4. (Sub lesson 1) True or false: The magnet** — as the answer to: What does Mirror do?
**Answer: False — Reflects the object across an axis — model half, both halves stay identical**

**5. (Sub lesson 1) True or false: The magnet**
**Answer: True**

**6. (Sub lesson 2) True or false: Parts of its mesh are assigned different materials** — as the answer to: What does Wireframe do?

**7. (Sub lesson 2) True or false: Parts of its mesh are assigned different materials**

**9. (Sub lesson 2) True or false: One object, one material — surface as a single coat**
**Answer: True**
