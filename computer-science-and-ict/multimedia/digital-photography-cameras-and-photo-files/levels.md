# Digital Photography — Cameras and Photo Files — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — The camera — light onto a sensor
Sub lesson 1 questions from the type files. Pass mark: A sensor — a grid of light-sensitive elements, one per pixel; The grid's size — width × height in pixels, counted in megapixels; Bigger files (and it buys finer detail); The lens (gathering/focusing), the shutter time, and the sensitivity (ISO); Brightness for noise — grain in the picture.

## Sub lesson 2 — Photo files — JPEG, RAW and the photograph's data
Sub lesson 2 questions from the type files. Pass mark: It compresses it — discarding fine detail — into a small, universal file; The sensor's measurements nearly untouched — everything, for later developing; JPEG for sharing; RAW for working; Data about the photo inside its file — camera, date, settings; What to keep — convenience, or everything.
