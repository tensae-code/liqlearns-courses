# Digital Photography — Cameras and Photo Files — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A sensor — a grid of light-sensitive elements, one per pixel**
**Answer: True**

**2. (Sub lesson 1) True or false: A sensor — a grid of light-sensitive elements, one per pixel** — as the answer to: What is a picture's resolution?
**Answer: False — The grid's size — width × height in pixels, counted in megapixels**

**3. (Sub lesson 1) True or false: Bigger files (and it buys finer detail)**
**Answer: True**

**4. (Sub lesson 1) True or false: Bigger files (and it buys finer detail)** — as the answer to: Name the three controls over light.
**Answer: False — The lens (gathering/focusing), the shutter time, and the sensitivity (ISO)**

**5. (Sub lesson 1) True or false: Brightness for noise — grain in the picture**
**Answer: True**

**6. (Sub lesson 2) True or false: Brightness for noise — grain in the picture** — as the answer to: What does JPEG do to a picture?
**Answer: False — It compresses it — discarding fine detail — into a small, universal file**

**7. (Sub lesson 2) True or false: The sensor's measurements nearly untouched — everything, for later developing**
**Answer: True**

**8. (Sub lesson 2) True or false: The sensor's measurements nearly untouched — everything, for later developing** — as the answer to: Which format is for sharing, which for working?
**Answer: False — JPEG for sharing; RAW for working**

**9. (Sub lesson 2) True or false: Data about the photo inside its file — camera, date, settings**
**Answer: True**

**10. (Sub lesson 2) True or false: Data about the photo inside its file — camera, date, settings** — as the answer to: What is chosen when a format is chosen?
**Answer: False — What to keep — convenience, or everything**
