# Multimedia hardware and software requirements — multiple choice

Pick the one right answer.

**1.** The stated RAM floor for a multimedia system is —
a) 256 MB  b) 1 GB  c) 16 GB  d) 1 TB
**Answer: b) 1 GB** — as printed in the book.

**2.** Which part serves audio directly?
a) video card  b) SVGA monitor  c) sound card  d) CD-ROM drive
**Answer: c) sound card** — sound card → audio.

**3.** Photoshop and CorelDraw are named as —
a) sound software  b) animation creators  c) image processing software  d) word processors
**Answer: c) image processing software** — image processing software.

**4.** 3D Max and Flash are named as —
a) animation creators  b) video software only  c) word processors  d) sound software
**Answer: a) animation creators** — the animation creators.

**5.** Virtual reality is worked through —
a) a printer and scanner  b) stereo headphones, head-mounted goggles and data gloves  c) a mouse only  d) a CD-ROM
**Answer: b) stereo headphones, head-mounted goggles and data gloves** — the three named pieces.
