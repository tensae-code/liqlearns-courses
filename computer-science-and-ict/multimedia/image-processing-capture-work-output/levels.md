# Image processing — capture, work, output — depth

This lesson is one whole lesson with no sub lessons. Pass mark: the learner can do and explain the lesson's one thing — image processing runs in three stages — input/import, analysis and manipulation in specialised software, output — to get an enhanced image or extract useful information from it. Practice deepens with more items from the question files and harder corners of the same skill (new images, new values, the same steps), never with new content the lesson does not teach.
