# Image processing — capture, work, output — true or false

Say whether each statement is true or false.

**1.** Image processing improves pictorial information for human perception.
**Answer: True** — that is its purpose.

**2.** The output stage comes before the input stage.
**Answer: False** — input first, then analysis and manipulation, then output.

**3.** Compressing an image is one of the operations image processing can do.
**Answer: True** — analysing, enhancing, compressing, reconstructing — all named.
