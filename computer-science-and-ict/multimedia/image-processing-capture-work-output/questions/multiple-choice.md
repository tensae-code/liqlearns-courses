# Image processing — capture, work, output — multiple choice

Pick the one right answer.

**1.** The first stage of image processing is —
a) output  b) input/import  c) printing  d) saving
**Answer: b) input/import** — the image is captured first.

**2.** Input/import is done by —
a) a printer  b) a scanner or digital camera  c) a monitor  d) a speaker
**Answer: b) a scanner or digital camera** — scanner or camera.

**3.** Analysis and manipulation happen —
a) in specialised software  b) on paper  c) inside the camera only  d) at the printer
**Answer: a) in specialised software** — in specialised software.

**4.** The output of image processing goes to —
a) a scanner  b) a keyboard  c) a printer or monitor  d) a camera
**Answer: c) a printer or monitor** — printer or monitor.

**5.** One goal of image processing is —
a) to delete images  b) to extract useful information from an image  c) to make images smaller only  d) to hide images
**Answer: b) to extract useful information from an image** — an enhanced image, or useful information extracted.
