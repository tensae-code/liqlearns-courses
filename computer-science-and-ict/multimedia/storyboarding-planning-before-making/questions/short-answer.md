# Storyboarding — planning before making — short answer

Answer in a sentence or a short list.

**1. (Sub lesson 1)** What is pre-visualisation, as storyboarding uses it?
**Answer:** Seeing the product before it is made — the storyboard shows the scenes in advance, using sketches, photos, text, audio or prototypes.

**2. (Sub lesson 2)** List the six production-planning steps in order.
**Answer:** 1 Define goals and objectives; 2 describe the content; 3 develop the application script; 4 translate the script into an outline; 5 translate the outline into a logic flow chart; 6 develop the storyboard.
