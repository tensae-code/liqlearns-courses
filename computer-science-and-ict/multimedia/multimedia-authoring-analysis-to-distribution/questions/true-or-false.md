# Multimedia authoring — analysis to distribution — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 3)** A prototype is built during Evaluation.
**Answer: False** — the prototype is Development's work; Evaluation tests it.

**2. (Sub lesson 5)** Distribution packages the finished work.
**Answer: True** — the last stage.

**3. (Sub lesson 1)** Authoring uses software tools to join the media contents.
**Answer: True** — as defined.

**4. (Sub lesson 2)** Design produces the finished, packaged work.
**Answer: False** — Design storyboards the story; packaging belongs to Distribution.
