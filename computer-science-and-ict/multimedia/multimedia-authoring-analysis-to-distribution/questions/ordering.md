# Multimedia authoring — analysis to distribution — ordering

Put these steps in the right order.

1. Evaluation — test and fine-tune
2. Distribution — package and hand out
3. Analysis — decide what to do
4. Development — build the prototype
5. Design — storyboard the story

**Answer:** Analysis → Design → Development → Evaluation → Distribution.

**(Sub lesson 6)** Put the guide's fuller production road in order:

1. Delivery
2. Project conceptualisation
3. Testing
4. Planning and costing
5. Design and production

**Answer:** Project conceptualisation → Planning and costing → Design and production → Testing → Delivery.
