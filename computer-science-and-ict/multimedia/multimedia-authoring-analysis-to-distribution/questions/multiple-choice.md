# Multimedia authoring — analysis to distribution — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Authoring assembles media contents into —
a) five separate files  b) a single stream of information  c) a printed book  d) a folder of pictures
**Answer: b) a single stream of information** — the definition taught.

**2. (Sub lesson 1)** The first stage, Analysis, decides —
a) the price only  b) what to do and what to use  c) who buys it  d) the file format
**Answer: b) what to do and what to use** — what to do, what to use.

**3. (Sub lesson 2)** Design means —
a) testing the prototype  b) storyboarding the project's story  c) packaging the work  d) writing code only
**Answer: b) storyboarding the project's story** — the storyboard stage.

**4. (Sub lesson 3)** Development sets up —
a) the budget  b) a prototype with the data incorporated  c) the distribution list  d) the review meeting
**Answer: b) a prototype with the data incorporated** — the working prototype.

**5. (Sub lesson 4)** Evaluation does all of these EXCEPT —
a) test the prototype  b) fine-tune  c) package and distribute  d) review
**Answer: c) package and distribute** — packaging belongs to Distribution.

**6. (Sub lesson 5)** The final stage is —
a) Analysis  b) Evaluation  c) Distribution  d) Design
**Answer: c) Distribution** — package and distribute.

**7. (Sub lesson 3)** A prototype is —
a) the packaged final work  b) a working first version of the whole project, with the data incorporated  c) the storyboard  d) the budget
**Answer: b) a working first version of the whole project, with the data incorporated** — Development's product.
