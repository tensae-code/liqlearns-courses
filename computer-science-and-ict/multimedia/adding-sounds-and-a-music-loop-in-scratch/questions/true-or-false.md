# Adding Sounds and a Music Loop in Scratch — true or false

Say whether each statement is true or false.

**1. Play sound and play sound until done do exactly the same thing.**
**Answer: False** — One moves on, the other waits — that difference is the lesson.

**2. Speech that must be heard whole should use play sound until done.**
**Answer: True** — The script waits, so nothing cuts the speech.

**3. Background music should sit in the main action script so it blocks the action.**
**Answer: False** — It loops in its own parallel script so the action runs alongside.
