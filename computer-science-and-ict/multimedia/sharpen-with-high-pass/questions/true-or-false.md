# Sharpen with High Pass — true or false

Say whether each statement is true or false.

**1.** At the lowest Radius the High Pass image is solid grey with no edges.
**Answer: True** — raise it until edges highlight, about 2–5.

**2.** Soft Light is stronger than Overlay.
**Answer: False** — Overlay is the stronger; Soft Light is subtler.

**3.** The Smart Object conversion keeps the original unharmed.
**Answer: True** — sharpening applies to the smart object.
