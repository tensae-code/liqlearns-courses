# Sharpen with High Pass — multiple choice

Pick the one right answer.

**1.** First, the background layer is converted to —
a) a text layer  b) a Smart Object  c) a selection  d) a mask
**Answer: b) a Smart Object** — a Smart Object — the original stays unharmed.

**2.** High Pass is found at —
a) Filter → Sharpen  b) Filter → Other → High Pass  c) Image → Adjustments  d) Layer → New
**Answer: b) Filter → Other → High Pass** — Filter → Other.

**3.** Under High Pass, the image turns —
a) red  b) grey, with edges highlighted  c) black  d) invisible
**Answer: b) grey, with edges highlighted** — grey with edges showing.

**4.** The Radius is adjusted to about —
a) 0.3–0.5  b) 2–5  c) 20–50  d) 150
**Answer: b) 2–5** — 2–5, up from the lowest value.

**5.** Overlay as a blend mode gives —
a) a subtler effect  b) a stronger, higher-contrast effect  c) no effect  d) a darker file
**Answer: b) a stronger, higher-contrast effect** — Overlay = stronger; Soft Light = subtler.

**6.** The effect is fine-tuned by lowering the filter's —
a) Radius only  b) Opacity  c) Size  d) Resolution
**Answer: b) Opacity** — Opacity.
