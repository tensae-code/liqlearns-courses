# The Parts an Image Is Made Of — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What three parts is an image made of?" is: Points, lines and filled areas**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is a single point in an image called?" is: Lines and areas**
**Answer: False** — A pixel

**3. (Sub lesson 1) True or false: the answer to "What is a house, in parts?" is: Lines and areas**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Why name the parts first?" is: In the Grade 9 graphics chapter, before processing**
