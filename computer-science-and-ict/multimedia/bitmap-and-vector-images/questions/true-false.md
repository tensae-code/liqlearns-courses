# Bitmap and Vector Images — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a bitmap image built from?" is: Pixels — tiny coloured squares in a grid**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What happens when a bitmap is stretched bigger?" is: JPEG**
**Answer: False** — The squares show and the picture turns blocky and blurred

**3. (Sub lesson 1) True or false: the answer to "Which bitmap format suits photographs?" is: JPEG**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Which format suits sharp edges or transparency?" is: Simple pictures and short animations**
**Answer: False** — PNG

**5. (Sub lesson 1) True or false: the answer to "What is GIF used for?" is: Simple pictures and short animations**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does a vector image store?" is: The computer redraws it perfectly from its rules at each size**
**Answer: False** — The rules for its shapes — lines, curves and fills

**7. (Sub lesson 2) True or false: the answer to "Why does a vector stay sharp at any size?" is: The computer redraws it perfectly from its rules at each size**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What kinds of pictures are drawn as vectors?" is: GIMP and Photoshop**
**Answer: False** — Logos, diagrams and lettering

**9. (Sub lesson 2) True or false: the answer to "Which editors work mainly with bitmaps?" is: GIMP and Photoshop**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Can a bitmap be turned truly back into a vector?" is: Pixels — tiny coloured squares in a grid**
**Answer: False** — No — a vector can become a bitmap, but not the other way
