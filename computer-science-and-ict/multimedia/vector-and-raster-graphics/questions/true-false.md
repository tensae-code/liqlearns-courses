# Vector and Raster Graphics — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does a raster image store?" is: A colour for every pixel in a grid**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is resolution?" is: JPG and PNG**
**Answer: False** — The pixel count across and down

**3. (Sub lesson 1) True or false: the answer to "What shows when a raster is over-enlarged?" is: Pixelation — the squares show**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Which kind suits photographs?" is: As a centre, a radius and a fill**
**Answer: False** — Raster

**5. (Sub lesson 1) True or false: the answer to "Name two raster formats." is: JPG and PNG**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does a vector image store?" is: Vector**
**Answer: False** — Instructions — shapes defined by rules

**7. (Sub lesson 2) True or false: the answer to "How is a vector circle stored?" is: As a centre, a radius and a fill**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Why do vectors stay sharp at any size?" is: A colour for every pixel in a grid**
**Answer: False** — The shapes are recomputed on every redraw

**9. (Sub lesson 2) True or false: the answer to "Which kind suits logos and diagrams?" is: Vector**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is the vector trade-off?" is: Pixelation — the squares show**
**Answer: False** — Clean shapes, poorly suited to photographic subtlety
