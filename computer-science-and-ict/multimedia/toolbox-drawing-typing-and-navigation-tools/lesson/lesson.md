# Toolbox — drawing, typing and navigation tools

## Do it first

Before reading on, think about the last three things you do with a picture program besides fixing photos: draw a shape, write a title on the picture, and zoom in to check a corner. This lesson's tools do those three.

## Drawing and typing

- **Pen** — draws accurate shapes, vectors, selections and paths; family: Freeform Pen, Curvature Pen, Add/Delete Anchor Point, Convert Point.
- **Horizontal Type** — adds standard text; family: Vertical Type, Vertical/Horizontal Type Mask.
- **Path Selection** (the black arrow) — selects and moves a whole path at once; family: Direct Selection.
- **Rectangle** — draws rectangular paths, vector or pixel shapes; hold **Shift** while dragging for a perfect square. Family: Rounded Rectangle, Ellipse, Triangle, Polygon, Line, Custom Shape.

## Navigation — moving the view

- **Hand** — drags a zoomed image around the screen.
- **Zoom** — click to zoom into an area; Alt-click to zoom out.
