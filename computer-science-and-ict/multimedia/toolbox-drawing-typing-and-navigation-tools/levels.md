# Toolbox — drawing, typing and navigation tools — depth

This lesson is one whole lesson with no sub lessons. Pass mark: the learner can do and explain the lesson's one thing — the last Toolbox families draw and write — Pen, Type, Path Selection and shape tools — and move the view itself: the Hand drags a zoomed image and Zoom clicks in and out. Practice deepens with more items from the question files and harder corners of the same skill (new images, new values, the same steps), never with new content the lesson does not teach.
