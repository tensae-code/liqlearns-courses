# Toolbox — drawing, typing and navigation tools — fill in the blank

Fill each blank with the word or words that complete the sentence.

**1.** The ____ tool drags a zoomed image around the screen.
**Answer: Hand**

**2.** Add/Delete ____ Point is in the Pen family.
**Answer: Anchor**

**3.** Hold ____ while dragging with the Rectangle tool for a perfect square.
**Answer: Shift**
