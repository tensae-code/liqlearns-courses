# Toolbox — drawing, typing and navigation tools — multiple choice

Pick the one right answer.

**1.** The Pen tool draws —
a) only circles  b) accurate shapes, vectors, selections and paths  c) text  d) gradients
**Answer: b) accurate shapes, vectors, selections and paths** — shapes, vectors, selections, paths.

**2.** A perfect square is drawn with the Rectangle tool by holding —
a) Alt  b) Shift  c) Ctrl  d) Enter
**Answer: b) Shift** — Shift while dragging.

**3.** The black-arrow Path Selection tool —
a) selects one anchor point  b) selects and moves a whole path at once  c) types text  d) samples colour
**Answer: b) selects and moves a whole path at once** — the whole path at once.

**4.** To zoom OUT with the Zoom tool —
a) double-click  b) Alt-click  c) right-click  d) press Shift
**Answer: b) Alt-click** — Alt-click zooms out.

**5.** The Hand tool —
a) draws hands  b) drags a zoomed image around the screen  c) erases  d) measures
**Answer: b) drags a zoomed image around the screen** — it drags the view.

**6.** Standard text is added with —
a) Horizontal Type  b) the Pen  c) the Hand  d) the Eyedropper
**Answer: a) Horizontal Type** — Horizontal Type.
