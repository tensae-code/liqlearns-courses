# Toolbox — drawing, typing and navigation tools — short answer

Answer in a sentence or a short list.

**1.** Name the tools in the Rectangle family.
**Answer:** Rounded Rectangle, Ellipse, Triangle, Polygon, Line and Custom Shape.

**2.** How do the Hand and Zoom tools differ from the other tools in this title?
**Answer:** They do not change the image itself — they move and magnify the VIEW of it (navigation).
