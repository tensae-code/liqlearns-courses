# Toolbox — drawing, typing and navigation tools — true or false

Say whether each statement is true or false.

**1.** Vertical Type is in the Horizontal Type family.
**Answer: True** — with the two Type Mask tools.

**2.** The Ellipse tool is in the Rectangle family.
**Answer: True** — Rounded Rectangle, Ellipse, Triangle, Polygon, Line, Custom Shape.

**3.** The Zoom tool can only zoom in.
**Answer: False** — click zooms in; Alt-click zooms out.
