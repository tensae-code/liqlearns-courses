# The Photoshop Toolbox — selecting and moving tools — true or false

Say whether each statement is true or false.

**1.** The Toolbox is two columns by default.
**Answer: False** — single-column by default; the double arrow expands it to two.

**2.** The Magic Wand sits in the Object Selection family.
**Answer: True** — with Quick Selection.

**3.** The Artboard tool is in the Move family.
**Answer: True** — Move's family includes Artboard.
