# The Photoshop Toolbox — selecting and moving tools — multiple choice

Pick the one right answer.

**1.** A tool's hidden family is revealed by —
a) the small arrow at its bottom-right, or right-clicking it  b) double-clicking the canvas  c) the File menu  d) pressing Enter
**Answer: a) the small arrow at its bottom-right, or right-clicking it** — arrow or right-click.

**2.** The Move tool moves —
a) only text  b) layers, selections and guides  c) the whole window  d) colours
**Answer: b) layers, selections and guides** — layers, selections and guides.

**3.** How many lasso tools are there in the family?
a) one  b) two  c) three  d) five
**Answer: c) three** — Lasso, Polygonal Lasso, Magnetic Lasso — confirmed in the teacher guide's Unit 4 answer key.

**4.** The Marquee family does NOT include —
a) Rectangular  b) Elliptical  c) Single row  d) Magnetic
**Answer: d) Magnetic** — Magnetic belongs to the Lasso family.

**5.** Object Selection works by —
a) typing the object's name  b) drawing a rough selection around the object  c) clicking the background  d) scanning the image
**Answer: b) drawing a rough selection around the object** — draw rough; the tool finds the object.

**6.** Hovering over a tool shows —
a) its price  b) a short description and a usage video  c) the layer stack  d) nothing
**Answer: b) a short description and a usage video** — description + usage video.
