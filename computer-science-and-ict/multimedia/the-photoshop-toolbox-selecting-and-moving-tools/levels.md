# The Photoshop Toolbox — selecting and moving tools — depth

This lesson is one whole lesson with no sub lessons. Pass mark: the learner can do and explain the lesson's one thing — the left Toolbox holds tool families behind small arrows — Move, the Marquee tools, the Lasso tools and Object Selection — the tools that select and move. Practice deepens with more items from the question files and harder corners of the same skill (new images, new values, the same steps), never with new content the lesson does not teach.
