# Effects for Animated Images — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — An effect is a change spread over frames
Sub lesson 1 questions from the type files. Pass mark: It changes the picture gradually, frame by frame; Opacity raised or lowered step by step, so a thing appears or vanishes; The first state and the last state of the effect; In equal steps between the first and last states; One smooth change.

## Sub lesson 2 — Using effects with restraint — timing and purpose
Sub lesson 2 questions from the type files. Pass mark: The frame delays — many frames for a slow fade, few for a flash; A story purpose — marking the magic object, ending the scene; The eye stops believing any of them; One effect, well placed; Few frames — it is over quickly.
