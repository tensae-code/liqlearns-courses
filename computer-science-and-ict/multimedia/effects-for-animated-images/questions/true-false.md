# Effects for Animated Images — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: It changes the picture gradually, frame by frame**
**Answer: True**

**2. (Sub lesson 1) True or false: It changes the picture gradually, frame by frame** — as the answer to: What is a fade?
**Answer: False — Opacity raised or lowered step by step, so a thing appears or vanishes**

**3. (Sub lesson 1) True or false: The first state and the last state of the effect**
**Answer: True**

**4. (Sub lesson 1) True or false: The first state and the last state of the effect** — as the answer to: How are the in-between frames built?
**Answer: False — In equal steps between the first and last states**

**5. (Sub lesson 1) True or false: One smooth change**
**Answer: True**

**6. (Sub lesson 2) True or false: One smooth change** — as the answer to: What sets an effect's timing?
**Answer: False — The frame delays — many frames for a slow fade, few for a flash**

**7. (Sub lesson 2) True or false: A story purpose — marking the magic object, ending the scene**
**Answer: True**

**8. (Sub lesson 2) True or false: A story purpose — marking the magic object, ending the scene** — as the answer to: Why do five competing effects fail?
**Answer: False — The eye stops believing any of them**

**9. (Sub lesson 2) True or false: One effect, well placed**
**Answer: True**

**10. (Sub lesson 2) True or false: One effect, well placed** — as the answer to: What does a flash get?
**Answer: False — Few frames — it is over quickly**
