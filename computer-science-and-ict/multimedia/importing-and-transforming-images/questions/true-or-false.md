# Importing and transforming images — true or false

Say whether each sentence is true or false.

**1.** Pasting an image uses Edit → Paste / Ctrl+V in the project.
**Answer: True** — the paste route.

**2.** Rotate and Skew is one of the operations in the options panel.
**Answer: True** — as taught.

**3.** The boundary box appears before the image is selected.
**Answer: False** — select the image first, then click Free Transform.
