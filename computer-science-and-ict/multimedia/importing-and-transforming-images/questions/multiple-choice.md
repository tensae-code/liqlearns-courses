# Importing and transforming images — multiple choice

Pick the one right answer.

**1.** An image enters a project by —
a) importing or pasting  b) scanning only  c) typing it  d) recording it
**Answer: a) importing or pasting** — the two routes.

**2.** Importing an image runs —
a) Edit → Paste  b) File → Import → choose the image → Open  c) Control → Test Movie  d) File → New
**Answer: b) File → Import → choose the image → Open** — the import route.

**3.** Modifying an image uses the —
a) Paint Bucket  b) Text Tool  c) Free Transform Tool  d) Motion Guide
**Answer: c) Free Transform Tool** — one tool, four operations.

**4.** When Free Transform is clicked, what appears?
a) a new layer  b) a boundary box  c) the library  d) a text field
**Answer: b) a boundary box** — the box the operations work from.

**5.** Which is NOT a Free Transform operation?
a) Scale  b) Distort  c) Envelope  d) Import
**Answer: d) Import** — Import brings the image in; it is not a transform.
