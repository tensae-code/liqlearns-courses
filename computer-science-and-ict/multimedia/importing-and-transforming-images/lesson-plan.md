# Lesson plan — Importing and transforming images

**Course:** Computer Science and ICT · **Title:** Multimedia · **Lesson:** Importing and transforming images
**Place in the curriculum:** Ethiopia Grade 10, Unit 4 — Image Processing and Multimedia (printed pp. 139–181).
**The one thing this lesson teaches:** an image enters a project by importing or pasting, and is modified with the Free Transform Tool — Rotate and Skew, Scale, Distort or Envelope — from its boundary box.
**This lesson's own level:** it stands on Inserting and styling text: the same import and paste routes now carry images, and a new tool does the modifying.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 2 seconds, looping.

## Sub lessons
This lesson is one whole lesson — it has no sub lessons (a short, single-skill lesson; his ruling 2026-11-09).

## Before this lesson
- Recommended first: Inserting and styling text in a multimedia project — the import and paste routes. Recommended, never forced. A learner can land here directly; the lesson stands alone.

## What the learner can do when it ends
1. Import an image and paste an image, each by the book's route.
2. Run the Free Transform sequence in order.
3. Name the four operations and say what each does to the picture.
## What you need
A computer with Flash for the real doing; a printed photo or drawing for the mime work.

## If the learner is stuck
- Hunts for four separate tools → one tool, four operations: Free Transform shows the boundary box, the options panel chooses the operation.
- Drags the picture itself to scale → scaling is done from the boundary box the tool draws, not by pulling the image's middle.
