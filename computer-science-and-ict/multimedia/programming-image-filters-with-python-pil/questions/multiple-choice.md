# Programming Image Filters with Python PIL — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) In Pillow, `pixels[x, y]` gives you —**
a) The pixel’s price  b) The RGB triple at column x, row y  c) The whole image  d) The file name
**Answer: b) The RGB triple at column x, row y — And the same address accepts a new triple, changing the image.**

**2. (Sub lesson 1) An image object in Pillow knows its size and its —**
a) Owner  b) Mode, such as RGB  c) Date  d) Price
**Answer: b) Mode, such as RGB — The mode says how the pixels are coded; a colour photo’s mode is RGB.**

**3. (Sub lesson 2) The greyscale rule replaces a triple by —**
a) (0, 0, 0)  b) The triple reversed  c) Its average, three times  d) (255, 255, 255)
**Answer: c) Its average, three times — Equal numbers make a grey of the same brightness.**

**4. (Sub lesson 2) The negative of the pixel (200, 60, 40) is —**
a) (40, 60, 200)  b) (55, 195, 215)  c) (100, 100, 100)  d) (255, 255, 255)
**Answer: b) (55, 195, 215) — Subtract each number from 255: 255−200=55, 255−60=195, 255−40=215.**
