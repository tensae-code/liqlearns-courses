# Programming Image Filters with Python PIL — true or false

Say whether each statement is true or false.

**1. (Sub lesson 2) A filter program should save its result over the original file so nothing is lost.**
**Answer: False — Saving over the original destroys it; the rule is to save under a new name.**

**2. (Sub lesson 1) Two nested loops — one over columns, one over rows — can visit every pixel of an image.**
**Answer: True — The grid is exactly columns × rows; the two loops cover all of it.**
