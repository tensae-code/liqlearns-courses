# Authoring tools — naming the Flash screen

## Do it first

On paper, sketch the window of any program you know well and label its parts. Before reading on, say what you would call the strip of menus, the working space, and the box of tools. This lesson names the parts of the worked authoring window.

## Sub lesson 1 — Authoring tools and capture tools

**Authoring tools** provide an **integrated environment** for joining a production's elements, with **interactive user control** — information flowing **both ways** between application and user — so high-quality audio/video applications can be built with little expertise.

Packages named: **Macromedia Authorware, Adobe Premiere, Macromedia Flash, Everest Authoring System, Icon Author** and **ImageQ**. Beside the authoring packages stand the **capture tools**: computer, scanner, digital camera and sound recorder — the tools that bring real-world media in.

## Sub lesson 2 — The Flash screen — six elements

The worked environment is **Macromedia Flash**, opened by the route: **Start → All Programs → Macromedia → Macromedia Flash MX**.

Its screen elements are: the **menu bar**; the **Timeline window** — when things happen: playback time and frame rate; the **work area** — the white **Stage** inside the grey **Workspace**; the **layer panel**; the **toolbox**; and the many **panels** — options, actions, properties among them.

Name the screen before you work in it: every later Flash lesson in this title points at these six elements.

## Say it to your companion

Point (in the air or on your sketch) and name the six Flash screen elements for your companion, with the Timeline's and the work area's jobs in full.
