# Authoring tools — naming the Flash screen — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Authoring tools provide —
a) only storage  b) an integrated environment for joining elements, with interactive user control  c) a printer route  d) file compression
**Answer: b) an integrated environment for joining elements, with interactive user control** — two-way control is the mark.

**2. (Sub lesson 1)** Which is NOT an authoring package named in the lesson?
a) Macromedia Authorware  b) Icon Author  c) ImageQ  d) Sound Forge
**Answer: d) Sound Forge** — Sound Forge is sound software from the requirements lesson.

**3. (Sub lesson 1)** The capture tools named are —
a) printer, plotter, modem, router  b) computer, scanner, digital camera, sound recorder  c) mouse, keyboard, monitor, speaker  d) pen, paper, ruler, chart
**Answer: b) computer, scanner, digital camera, sound recorder** — the tools that bring media in.

**4. (Sub lesson 2)** Flash MX is opened by —
a) File → Open as Library  b) Start → All Programs → Macromedia → Macromedia Flash MX  c) Control → Test Movie  d) Insert → Timeline
**Answer: b) Start → All Programs → Macromedia → Macromedia Flash MX** — the book's route.

**5. (Sub lesson 2)** The Timeline window holds —
a) the toolbox  b) when things happen — playback time and frame rate  c) the colour swatches  d) the library
**Answer: b) when things happen — playback time and frame rate** — time lives in the Timeline.

**6. (Sub lesson 2)** The white Stage sits inside —
a) the menu bar  b) the grey Workspace  c) the layer panel  d) a panel
**Answer: b) the grey Workspace** — white inside grey.
