# Authoring tools — naming the Flash screen — short answer

Answer in one or two sentences.

**1. (Sub lesson 1)** Why can high-quality applications be built 'with little expertise' in an authoring tool?
**Answer:** Because the tool provides an integrated environment for joining the elements, with interactive control, instead of demanding raw code for every join.

**2. (Sub lesson 2)** Name the six screen elements in any order.
**Answer:** Menu bar, Timeline window, work area (Stage in Workspace), layer panel, toolbox, panels.
