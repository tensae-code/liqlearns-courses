# Lesson plan — Authoring tools — naming the Flash screen

**Course:** Computer Science and ICT · **Title:** Multimedia · **Lesson:** Authoring tools — naming the Flash screen
**Place in the curriculum:** Ethiopia Grade 10, Unit 4 — Image Processing and Multimedia (printed pp. 139–181).
**The one thing this lesson teaches:** authoring tools join a production's elements in an integrated environment with two-way interactive control — and the worked environment, Macromedia Flash MX, has six named screen elements.
**This lesson's own level:** it stands on Multimedia authoring — analysis to distribution: the tools are what the stages are worked in.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 2 seconds, looping.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Authoring tools and capture tools** — what authoring tools are, the packages named, and the capture tools beside them.
2. **The Flash screen — six elements** — opening Flash MX by the book's route and naming menu bar, Timeline, work area, layer panel, toolbox and panels.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Multimedia authoring — analysis to distribution. Recommended, never forced. A learner can land here directly; the lesson stands alone.

## What the learner can do when it ends
1. Say what authoring tools provide, and name the six packages and four capture tools.
2. Open Flash MX by the book's route (on paper or a real machine).
3. Name the six screen elements with their jobs.
## What you need
Paper and a pencil. A computer with Flash helps for the hands-on, but the naming work is done on the sketch.
