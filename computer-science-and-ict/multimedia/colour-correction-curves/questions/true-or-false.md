# Colour correction — Curves — true or false

Say whether each statement is true or false.

**1.** Decreasing contrast does the reverse of the S-curve.
**Answer: True** — highlights down, shadows up.

**2.** Curves needs less care than Levels.
**Answer: False** — it is more powerful, so MORE care is needed.

**3.** Hiding the layer lets you compare with the original.
**Answer: True** — the compare step.
