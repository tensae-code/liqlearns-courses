# Sharpen with Smart Sharpen — multiple choice

Pick the one right answer.

**1.** Smart Sharpen is reached from —
a) the Image menu  b) the Filter menu  c) the Layer Palette  d) the File menu
**Answer: b) the Filter menu** — the Filter menu.

**2.** The starting Amount is —
a) 50%  b) 100%  c) 150%  d) 300%
**Answer: c) 150%** — 150%.

**3.** The starting Radius is —
a) around 1 or 2 — try 1 first  b) 10  c) 0.1  d) 50
**Answer: a) around 1 or 2 — try 1 first** — 1 or 2, try 1 first.

**4.** Smart Sharpen's advantage over Unsharp Mask is —
a) it is faster  b) built-in noise reduction  c) it crops too  d) it adds colour
**Answer: b) built-in noise reduction** — noise reduction built in.

**5.** Sharpening can bring with it —
a) noise  b) red eye  c) hot spots  d) layers
**Answer: a) noise** — noise — which Smart Sharpen can reduce.
