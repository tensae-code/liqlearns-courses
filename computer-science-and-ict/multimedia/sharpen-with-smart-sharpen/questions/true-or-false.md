# Sharpen with Smart Sharpen — true or false

Say whether each statement is true or false.

**1.** You should try Radius 1 before Radius 2.
**Answer: True** — try 1 first.

**2.** Smart Sharpen and Unsharp Mask are the same tool.
**Answer: False** — Smart Sharpen adds built-in noise reduction.

**3.** Smart Sharpen is a Filter-menu tool.
**Answer: True** — Filter → Sharpen.
