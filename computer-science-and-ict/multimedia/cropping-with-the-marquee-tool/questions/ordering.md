# Cropping with the Marquee Tool — ordering

Put the steps in order.

1. Select the Rectangular Marquee Tool
2. Drag a marquee around the area to keep
3. Choose Image → Crop
4. Open the image

**Answer — the right order:**
1. Open the image
2. Select the Rectangular Marquee Tool
3. Drag a marquee around the area to keep
4. Choose Image → Crop
