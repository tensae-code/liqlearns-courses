# Cropping with the Marquee Tool — multiple choice

Pick the one right answer.

**1.** The marquee crop uses which tool?
a) Crop Tool  b) Rectangular Marquee Tool  c) Lasso  d) Zoom Tool
**Answer: b) Rectangular Marquee Tool** — Rectangular Marquee.

**2.** After dragging the marquee, the crop is done from —
a) File → Save  b) Image → Crop  c) Edit → Paste  d) Layer → New
**Answer: b) Image → Crop** — Image → Crop.

**3.** The marquee is drawn around —
a) the area to remove  b) the area to keep  c) the whole screen  d) the toolbar
**Answer: b) the area to keep** — the area to keep.

**4.** The marquee crop is described as —
a) the slow careful crop  b) the quick simple crop  c) the print-size crop  d) the automatic crop
**Answer: b) the quick simple crop** — quick and simple.

**5.** Once Image → Crop is chosen, the image is cropped —
a) after saving  b) immediately  c) after restarting  d) never
**Answer: b) immediately** — immediately.
