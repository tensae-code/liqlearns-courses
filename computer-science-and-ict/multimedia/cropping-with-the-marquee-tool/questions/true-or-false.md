# Cropping with the Marquee Tool — true or false

Say whether each statement is true or false.

**1.** The marquee alone, without the menu command, does not crop the image.
**Answer: True** — Image → Crop finishes the job.

**2.** The marquee crop needs the Crop Tool as well.
**Answer: False** — Marquee Tool + Image → Crop only.

**3.** You drag the marquee around the area you want to keep.
**Answer: True** — keep inside, cut outside.
