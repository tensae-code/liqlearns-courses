# Cropping with the Marquee Tool

## Do it first

You already know one crop (the Crop Tool). Before reading on, guess how a selection tool could do the same job in fewer steps — select what you keep, and tell the program to throw away the rest.

## The marquee crop, step by step

The quick, simple crop:

1. Open the image.
2. Select the **Rectangular Marquee Tool**.
3. Click and drag a marquee around the area to keep.
4. Use the main menu **Image → Crop** — the image is cropped immediately.
