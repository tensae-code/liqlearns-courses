# Cropping with the Marquee Tool — depth

This lesson is one whole lesson with no sub lessons. Pass mark: the learner can do and explain the lesson's one thing — the quick simple crop: select the Rectangular Marquee Tool, drag a marquee around the area to keep, then Image → Crop — the image is cropped immediately. Practice deepens with more items from the question files and harder corners of the same skill (new images, new values, the same steps), never with new content the lesson does not teach.
