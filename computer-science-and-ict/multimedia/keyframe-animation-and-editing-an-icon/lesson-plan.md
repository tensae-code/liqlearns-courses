# Lesson plan — Keyframe animation — and editing an icon

**Course:** Computer Science and ICT · **Title:** Multimedia · **Lesson:** Keyframe animation — and editing an icon
**Place in the curriculum:** Ethiopia Grade 10, Unit 4 — Image Processing and Multimedia (printed pp. 139–181).
**The one thing this lesson teaches:** rotation animation is built keyframe by keyframe — place, add keyframe, turn a little, repeat — played with Enter and previewed with Control → Test Movie; an icon is edited through its Properties panel.
**This lesson's own level:** it stands on Drawing and filling a first Flash piece: the learner has an object on the Stage to animate.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 2 seconds, looping.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Animating by keyframes** — place the object, add keyframes, turn a little each time, play with Enter, preview with Test Movie.
2. **Editing an icon** — select the icon, read and change its properties in the Properties panel, run and re-edit until satisfied.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Drawing and filling a first Flash piece. Recommended, never forced. A learner can land here directly; the lesson stands alone.

## What the learner can do when it ends
1. Build a rotation by keyframes in the book's order.
2. Play with Enter and preview with Ctrl+Enter, and say how they differ in purpose.
3. Edit an icon through the Properties panel, in the judge-and-re-edit loop.
## What you need
A computer with Flash for the real doing; paper for the turn planning.

## If the learner is stuck
- Expects the object to move by itself after one keyframe → nothing moves until each keyframe holds a new turn; the duplicates carry the object forward, the turns make the motion.
- Confuses Enter with Ctrl+Enter → Enter plays from the first keyframe in the authoring screen; Ctrl+Enter previews the test movie.
