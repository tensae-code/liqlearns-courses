# Keyframe animation — and editing an icon — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Pressing Enter from the first keyframe plays the animation.
**Answer: True** — the in-screen play route.

**2. (Sub lesson 2)** Editing an icon is finished after the first change.
**Answer: False** — run or pause to judge, then re-edit until satisfied.

**3. (Sub lesson 2)** The Properties panel shows duration and sound among an icon's properties.
**Answer: True** — from the taught list.
