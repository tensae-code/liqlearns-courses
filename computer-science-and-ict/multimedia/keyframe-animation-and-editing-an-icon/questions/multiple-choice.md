# Keyframe animation — and editing an icon — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** When you add a keyframe, Flash —
a) deletes the object  b) duplicates the previous frame's contents  c) plays the movie  d) opens the library
**Answer: b) duplicates the previous frame's contents** — the duplicate carries the object forward.

**2. (Sub lesson 1)** In the book's run, the object is turned first —
a) 45° up  b) 90° to the right  c) 180° at once  d) 10° left
**Answer: b) 90° to the right** — 90° right, then face-down, then 270°.

**3. (Sub lesson 1)** Smoother animation comes from —
a) bigger angle steps  b) smaller angle steps  c) fewer keyframes  d) no keyframes
**Answer: b) smaller angle steps** — smaller steps, more keyframes.

**4. (Sub lesson 1)** Control → Test Movie is pressed as —
a) Enter  b) Ctrl+S  c) Ctrl+Enter  d) F6
**Answer: c) Ctrl+Enter** — the test-movie preview.

**5. (Sub lesson 2)** An icon is —
a) only a picture  b) any graphical, textual, audio or video element met through the GUI  c) a file format  d) a layer
**Answer: b) any graphical, textual, audio or video element met through the GUI** — the wide definition taught.

**6. (Sub lesson 2)** Icon properties are read and changed in —
a) the Timeline  b) the Properties panel  c) Color Swatches  d) the library only
**Answer: b) the Properties panel** — select, then the panel.
