# Keyframe animation — and editing an icon — short answer

Answer in one or two sentences.

**1. (Sub lesson 2)** What is the icon-editing loop?
**Answer:** Select the icon, read and change its properties in the Properties panel, run or pause to judge, and re-edit until satisfied.

**2. (Sub lesson 2)** Name the Properties panel's seven property kinds.
**Answer:** Appearance, placement, size, duration, contents, sound, colour.
