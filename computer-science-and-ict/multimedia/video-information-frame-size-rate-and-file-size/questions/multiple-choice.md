# Video Information — Frame Size, Rate and File Size — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a video, mechanically?**
a) A row of still frames shown fast enough to move  b) One frame's dimensions in pixels — width by height  c) How many frames pass each second — the motion's smoothness  d) Either number — frame size or frame rate
**Answer: a) A row of still frames shown fast enough to move**

**2. (Sub lesson 1) What is frame size?**
a) How many frames pass each second — the motion's smoothness  b) One frame's dimensions in pixels — width by height  c) Either number — frame size or frame rate  d) Pixels per frame × bytes per pixel × rate × seconds (with the sound)
**Answer: b) One frame's dimensions in pixels — width by height**

**3. (Sub lesson 1) What does frame rate decide?**
a) Either number — frame size or frame rate  b) Pixels per frame × bytes per pixel × rate × seconds (with the sound)  c) How many frames pass each second — the motion's smoothness  d) Because every frame is a full picture, many times a second
**Answer: c) How many frames pass each second — the motion's smoothness**

**4. (Sub lesson 1) What grows the file when raised?**
a) Pixels per frame × bytes per pixel × rate × seconds (with the sound)  b) Because every frame is a full picture, many times a second  c) Not a luxury but the condition of its existence  d) Either number — frame size or frame rate
**Answer: d) Either number — frame size or frame rate**

**Answer: a) Pixels per frame × bytes per pixel × rate × seconds (with the sound)**
