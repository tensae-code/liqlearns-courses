# Video Information — Frame Size, Rate and File Size — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a video, mechanically?**
**Answer: A row of still frames shown fast enough to move**

**2. (Sub lesson 1) What is frame size?**
**Answer: One frame's dimensions in pixels — width by height**

**3. (Sub lesson 1) What does frame rate decide?**
**Answer: How many frames pass each second — the motion's smoothness**

**4. (Sub lesson 1) What grows the file when raised?**
**Answer: Either number — frame size or frame rate**

**5. (Sub lesson 1) How is a video's file size worked out?**
**Answer: Pixels per frame × bytes per pixel × rate × seconds (with the sound)**

**6. (Sub lesson 2) Why is raw video enormous?**
**Answer: Because every frame is a full picture, many times a second**

**7. (Sub lesson 2) What is compression to video?**
**Answer: Not a luxury but the condition of its existence**

**8. (Sub lesson 2) Name the book's video formats.**
**Answer: AVI, MOV, WMV, RM and MPEG**

**9. (Sub lesson 2) When is the format chosen, and why?**
**Answer: At the start — size, quality and company are decided there**

**10. (Sub lesson 2) Which chapter's arithmetic is this?**
**Answer: Mongolia's Grade 10 video chapter**
