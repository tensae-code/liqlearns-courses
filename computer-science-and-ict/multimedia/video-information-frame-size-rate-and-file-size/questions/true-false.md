# Video Information — Frame Size, Rate and File Size — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a video, mechanically?" is: A row of still frames shown fast enough to move**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is frame size?" is: How many frames pass each second — the motion's smoothness**
**Answer: False** — One frame's dimensions in pixels — width by height

**3. (Sub lesson 1) True or false: the answer to "What does frame rate decide?" is: How many frames pass each second — the motion's smoothness**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What grows the file when raised?" is: Pixels per frame × bytes per pixel × rate × seconds (with the sound)**
**Answer: False** — Either number — frame size or frame rate

**5. (Sub lesson 1) True or false: the answer to "How is a video's file size worked out?" is: Pixels per frame × bytes per pixel × rate × seconds (with the sound)**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Why is raw video enormous?" is: Not a luxury but the condition of its existence**
**Answer: False** — Because every frame is a full picture, many times a second

**7. (Sub lesson 2) True or false: the answer to "What is compression to video?" is: Not a luxury but the condition of its existence**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Name the book's video formats." is: At the start — size, quality and company are decided there**
**Answer: False** — AVI, MOV, WMV, RM and MPEG

**9. (Sub lesson 2) True or false: the answer to "When is the format chosen, and why?" is: At the start — size, quality and company are decided there**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Which chapter's arithmetic is this?" is: A row of still frames shown fast enough to move**
**Answer: False** — Mongolia's Grade 10 video chapter
