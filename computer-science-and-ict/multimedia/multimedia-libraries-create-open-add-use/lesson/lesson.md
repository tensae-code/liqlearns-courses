# Multimedia libraries — create, open, add, use

## Do it first

Think of a drawing you have made twice because you did not keep the first one. Before reading on, list three things your class re-draws or re-records for every project. A library exists so those things are made once and used forever.

## Sub lesson 1 — Creating and opening libraries

The multimedia **library** holds the visual and audio elements — **icons** — a project needs; viewers need suitable software to open its files.

A **permanent library** is created by building a Flash file whose library contains the wanted symbols and **placing that file in the libraries folder** of the Flash application folder. **Sample libraries** can likewise be saved for future use via **File → Save As** — location, name, Save.

Libraries are **opened** with **File → Open as Library** — browse, choose, Open — and **closed** with **File → Close / Ctrl+W**, exiting the application, or opening another library.

## Sub lesson 2 — Adding and using icons

An icon is **added** to an open library by **File → Import / Ctrl+R** and choosing the icon file. An icon is **used** by opening the library and **double-clicking** the wanted icon.

The library is the project's memory: draw the school badge once, import the anthem once — and every later project starts with both already in hand.
