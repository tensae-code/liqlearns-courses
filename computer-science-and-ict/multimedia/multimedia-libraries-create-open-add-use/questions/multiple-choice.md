# Multimedia libraries — create, open, add, use — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The library holds —
a) only text files  b) the visual and audio elements (icons) a project needs  c) printed pages  d) file formats
**Answer: b) the visual and audio elements (icons) a project needs** — icons for reuse.

**2. (Sub lesson 1)** A permanent library is a Flash file placed —
a) on the desktop  b) in the libraries folder of the Flash application folder  c) in the Recycle Bin  d) on a CD only
**Answer: b) in the libraries folder of the Flash application folder** — the placing makes it permanent.

**3. (Sub lesson 1)** Sample libraries are saved via —
a) File → Save As  b) Control → Test Movie  c) Edit → Paste  d) File → Close
**Answer: a) File → Save As** — location, name, Save.

**4. (Sub lesson 1)** Libraries are opened with —
a) Open as Library  b) Import to Stage  c) Save As  d) Print
**Answer: a) Open as Library** — File → Open as Library.

**5. (Sub lesson 1)** Closing a library can be done by —
a) Ctrl+R  b) File → Close / Ctrl+W  c) F6  d) Enter
**Answer: b) File → Close / Ctrl+W** — one of the three closing ways.

**6. (Sub lesson 2)** An icon is added to an open library by —
a) double-clicking it  b) File → Import / Ctrl+R and choosing the file  c) dragging the Stage  d) pressing F5
**Answer: b) File → Import / Ctrl+R and choosing the file** — the import route.

**7. (Sub lesson 2)** An icon is used by —
a) renaming it  b) opening the library and double-clicking the wanted icon  c) deleting the library  d) saving the project
**Answer: b) opening the library and double-clicking the wanted icon** — open, then double-click.
