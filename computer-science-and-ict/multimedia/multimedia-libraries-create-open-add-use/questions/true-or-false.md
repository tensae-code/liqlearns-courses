# Multimedia libraries — create, open, add, use — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Viewers need suitable software to open library files.
**Answer: True** — as taught.

**2. (Sub lesson 1)** Exiting the application is one way to close a library.
**Answer: True** — one of the three ways.

**3. (Sub lesson 2)** Ctrl+R opens a library.
**Answer: False** — Ctrl+R imports an icon into an open library; opening is Open as Library.
