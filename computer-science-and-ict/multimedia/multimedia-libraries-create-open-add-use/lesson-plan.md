# Lesson plan — Multimedia libraries — create, open, add, use

**Course:** Computer Science and ICT · **Title:** Multimedia · **Lesson:** Multimedia libraries — create, open, add, use
**Place in the curriculum:** Ethiopia Grade 10, Unit 4 — Image Processing and Multimedia (printed pp. 139–181).
**The one thing this lesson teaches:** a multimedia library stores the symbols a project needs for reuse: a permanent library is a Flash file placed in the application's libraries folder, opened with Open as Library, added to by Import, and used by double-clicking an icon.
**This lesson's own level:** it stands on the Flash lessons before it: symbols made in the drawing, keyframe and motion-guide lessons are what a library keeps.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 2 seconds, looping.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Creating and opening libraries** — what the library holds; the permanent library — a Flash file in the libraries folder; sample libraries by Save As; open with Open as Library, close three ways.
2. **Adding and using icons** — add an icon by File → Import / Ctrl+R; use an icon by opening the library and double-clicking it.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Drawing and filling a first Flash piece; Keyframe animation — the symbols worth keeping. Recommended, never forced. A learner can land here directly; the lesson stands alone.

## What the learner can do when it ends
1. Create a permanent library and a sample library.
2. Open a library with Open as Library and close it three ways.
3. Add an icon by Import and use one by double-clicking.

## If the learner is stuck
- Saves a normal file and calls it a permanent library → permanence comes from the placing: the file must sit in the libraries folder of the Flash application folder.
- Tries to use an icon from a closed library → open the library first; the double-click works on the open library's icon.
