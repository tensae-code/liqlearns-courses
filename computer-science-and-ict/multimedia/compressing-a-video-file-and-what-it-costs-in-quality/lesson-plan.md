**The one thing this lesson teaches:** Compressing a video makes its file smaller so it stores and travels easily — but compression is a bargain: the more you squeeze, the more quality you pay away, and a file can only be played when the computer holds the codec it was made with.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Why compress, and how** — A video file is **compressed** to make it **smaller**: a smaller file takes less storage and travels faster. Compression works by keeping less of the original picture and sound information — the encoder throws away detail the eye is least likely to miss, and a **codec** is the recipe that does the squeezing and the un-squeezing. Choosing a stronger compression gives a smaller file every time.
2. **What compression costs — and the codec problem** — What is thrown away cannot come back: strong compression **lowers the quality** — pictures soften and block, sound thins. So the maker chooses a balance: small enough to share, clear enough to watch. And a compressed file needs its own **codec** to play: if the computer does not support the file's codec, the file will not play until that codec is available.
