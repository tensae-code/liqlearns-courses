# Compressing a Video File — and What It Costs in Quality — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Why is a video compressed?" is: To make its file smaller — less storage, faster travel**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How does compression make a file smaller?" is: Detail the eye is least likely to miss**
**Answer: False** — By keeping less of the original picture and sound information

**3. (Sub lesson 1) True or false: the answer to "What does the encoder throw away first?" is: Detail the eye is least likely to miss**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is a codec?" is: A smaller file**
**Answer: False** — The recipe that squeezes and un-squeezes the file

**5. (Sub lesson 1) True or false: the answer to "What does stronger compression always give?" is: A smaller file**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does strong compression cost?" is: No — what is thrown away cannot come back**
**Answer: False** — Quality — pictures soften and block, sound thins

**7. (Sub lesson 2) True or false: the answer to "Can thrown-away detail come back?" is: No — what is thrown away cannot come back**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What balance must the maker choose?" is: Its own codec on the computer**
**Answer: False** — Small enough to share, clear enough to watch

**9. (Sub lesson 2) True or false: the answer to "What does a compressed file need in order to play?" is: Its own codec on the computer**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What happens if the computer does not support the file's codec?" is: To make its file smaller — less storage, faster travel**
**Answer: False** — The file will not play until that codec is available
