# A Troubleshooting Case Study — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does a troubleshooting case study start with?" is: The fault as it was found**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is recorded for each check in the case?" is: One thing only**
**Answer: False** — What was checked and what happened

**3. (Sub lesson 1) True or false: the answer to "Why are the checks kept in order?" is: So the cause can be followed step by step**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How many things are changed at a time?" is: So you know which change mattered**
**Answer: False** — One thing only

**5. (Sub lesson 1) True or false: the answer to "What ends a troubleshooting case study?" is: The fix that removed the fault**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Why change one thing at a time?" is: The change after which the fault disappears**
**Answer: False** — So you know which change mattered

**7. (Sub lesson 2) True or false: the answer to "What do you do if a check changes nothing?" is: Record it and move to the next check**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What proves the cause of the fault?" is: No — the case works by checked steps**
**Answer: False** — The change after which the fault disappears

**9. (Sub lesson 2) True or false: the answer to "Why write the steps of a fix down?" is: So the same fault can be fixed faster next time**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Is guessing the method of a case study?" is: What was checked and what happened**
**Answer: False** — No — the case works by checked steps
