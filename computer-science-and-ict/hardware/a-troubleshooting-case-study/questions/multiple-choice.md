# A Troubleshooting Case Study — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does a troubleshooting case study start with?**
a) The fault as it was found  b) What was checked and what happened  c) So the cause can be followed step by step  d) One thing only
**Answer: a) The fault as it was found**

**2. (Sub lesson 1) What is recorded for each check in the case?**
a) So the cause can be followed step by step  b) What was checked and what happened  c) One thing only  d) The fix that removed the fault
**Answer: b) What was checked and what happened**

**3. (Sub lesson 1) Why are the checks kept in order?**
a) One thing only  b) The fix that removed the fault  c) So the cause can be followed step by step  d) So you know which change mattered
**Answer: c) So the cause can be followed step by step**

**4. (Sub lesson 1) How many things are changed at a time?**
a) The fix that removed the fault  b) So you know which change mattered  c) Record it and move to the next check  d) One thing only
**Answer: d) One thing only**

**5. (Sub lesson 1) What ends a troubleshooting case study?**
a) The fix that removed the fault  b) So you know which change mattered  c) Record it and move to the next check  d) The change after which the fault disappears
**Answer: a) The fix that removed the fault**

**6. (Sub lesson 2) Why change one thing at a time?**
a) Record it and move to the next check  b) So you know which change mattered  c) The change after which the fault disappears  d) So the same fault can be fixed faster next time
**Answer: b) So you know which change mattered**

**7. (Sub lesson 2) What do you do if a check changes nothing?**
a) The change after which the fault disappears  b) So the same fault can be fixed faster next time  c) Record it and move to the next check  d) No — the case works by checked steps
**Answer: c) Record it and move to the next check**

**8. (Sub lesson 2) What proves the cause of the fault?**
a) So the same fault can be fixed faster next time  b) No — the case works by checked steps  c) The fault as it was found  d) The change after which the fault disappears
**Answer: d) The change after which the fault disappears**

**9. (Sub lesson 2) Why write the steps of a fix down?**
a) So the same fault can be fixed faster next time  b) No — the case works by checked steps  c) The fault as it was found  d) What was checked and what happened
**Answer: a) So the same fault can be fixed faster next time**

**10. (Sub lesson 2) Is guessing the method of a case study?**
a) The fault as it was found  b) No — the case works by checked steps  c) What was checked and what happened  d) So the cause can be followed step by step
**Answer: b) No — the case works by checked steps**
