# Inside the CPU — CU, ALU and registers

## Do it first

A head teacher directs a school but does not teach every class; teachers do the teaching; a notice board holds today's lessons until they are taught. Before reading on, guess which CPU part directs, which works, and which holds.

## Sub lesson 1 — The control unit — it directs

The CPU has three sub-components, joined by a bus — the cable that carries data between them. The control unit directs the other elements to carry out instructions. It does not perform the instructions itself — as the brain directs the body, the control unit directs the CPU's work.

## Sub lesson 2 — The ALU — it calculates and compares

The ALU executes instructions. It does arithmetic operations — add, subtract, multiply, divide — and logical operations: comparisons using <, >, =, <= and >=. Every sum and every 'is this bigger?' decision passes through the ALU.

## Sub lesson 3 — Registers — they hold for a moment

Registers — the CPU's memory unit — are temporary storage locations where instructions loaded from main memory wait before the ALU works on them. Watch the GIF: an instruction travels from a register along the bus to the ALU, while the control unit directs the traffic — hold, travel, work.
