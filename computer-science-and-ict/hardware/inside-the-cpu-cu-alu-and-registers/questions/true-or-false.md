# Inside the CPU — CU, ALU and registers — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** As the brain directs the body, the control unit directs the CPU's work.
**Answer: True**

**2. (Sub lesson 3)** A register keeps instructions forever, even with the power off.
**Answer: False**

**3. (Sub lesson 2)** Comparing 7 > 5 is work for the ALU.
**Answer: True**
