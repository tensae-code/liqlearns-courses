# Inside the CPU — CU, ALU and registers — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The CPU's three sub-components are joined by —
a) A printer cable to the wall  b) A bus, the cable that carries data between them  c) Nothing  d) A wireless link only
**Answer: b) A bus, the cable that carries data between them** — The three sub-components are joined by a bus.

**2. (Sub lesson 1)** The control unit —
a) Does all the calculations  b) Directs the other elements to carry out instructions, without performing them itself  c) Stores files permanently  d) Prints results
**Answer: b) Directs the other elements to carry out instructions, without performing them itself** — The control unit directs; it does not perform instructions itself.

**3. (Sub lesson 2)** Which part executes instructions?
a) The register  b) The bus  c) The ALU  d) The monitor
**Answer: c) The ALU** — The ALU executes instructions.

**4. (Sub lesson 2)** Which of these is a logical operation for the ALU?
a) Adding two numbers  b) Comparing with < and >=  c) Printing a page  d) Storing a file
**Answer: b) Comparing with < and >=** — Logical operations are comparisons using <, >, =, <=, >=.

**5. (Sub lesson 2)** The ALU's arithmetic operations are —
a) Add, subtract, multiply, divide  b) Copy, paste, delete  c) Open, close, save  d) Record, play, stop
**Answer: a) Add, subtract, multiply, divide** — Arithmetic: add, subtract, multiply, divide.

**6. (Sub lesson 3)** Registers are —
a) Permanent archives  b) Temporary storage locations where instructions wait before the ALU works on them  c) Output devices  d) Types of key
**Answer: b) Temporary storage locations where instructions wait before the ALU works on them** — Registers hold instructions temporarily, loaded from main memory, before the ALU works on them.

**7. (Sub lesson 3)** Instructions in a register were loaded from —
a) The printer  b) Main memory  c) The mouse  d) A CD only
**Answer: b) Main memory** — Instructions are loaded from main memory into registers.
