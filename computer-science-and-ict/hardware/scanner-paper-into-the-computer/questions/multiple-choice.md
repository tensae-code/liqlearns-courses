# Scanner — paper into the computer — multiple choice

Pick the one right answer.

**1.** A scanner converts —
a) Digital files into paper  b) Printed text, handwriting or an object into a digital document  c) Sound into light  d) Electricity into heat
**Answer: b) Printed text, handwriting or an object into a digital document** — A scanner accepts printed text, handwriting or an object and converts it into a digital document.

**2.** The advantage of scanning a document is —
a) It uses more paper  b) Data enters directly from the source document without copying and typing  c) It prints in colour  d) It works without a computer
**Answer: b) Data enters directly from the source document without copying and typing** — Data goes in directly from the source document — no copying and typing.

**3.** Which of these can be scanned?
a) Only photographs  b) A picture, text, or a mark on paper  c) Only printed books  d) Nothing handwritten
**Answer: b) A picture, text, or a mark on paper** — What is scanned can be a picture, text, or a mark on paper.

**4.** A scanner is —
a) An output device  b) An input device  c) A storage device  d) A processing device
**Answer: b) An input device** — A scanner enters data into the computer — input.
