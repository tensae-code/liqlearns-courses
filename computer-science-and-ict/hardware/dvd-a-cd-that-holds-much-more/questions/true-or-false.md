# DVD — a CD that holds much more — true or false

Say whether each statement is true or false.

**1.** DVD and CD are the same size of disk.
**Answer: True**

**2.** 'Digital Video Disc' is the correct expansion of DVD.
**Answer: False**

**3.** A DVD stores much more than a CD.
**Answer: True** — 4.7–17 GB against 700 MB.
