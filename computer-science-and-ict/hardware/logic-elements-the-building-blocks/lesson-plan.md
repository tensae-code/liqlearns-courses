## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **What a logic element is** — A **logic element** is a small circuit with inputs and one output: signals arrive as 1s and 0s, and the element puts out the result of one logical operation. The AND element gives 1 only when all inputs are 1; the OR element gives 1 when at least one input is 1; the NOT element flips its single input. The book teaches elements straight after operations — first the rule, then the thing that obeys it.
2. **Building bigger work from elements** — Elements join: the output of one feeds the input of another, and a chain of elements can add numbers, compare them, or remember a bit. The whole processor is such chains — millions of building blocks, each doing one tiny logical job exactly. That is why the lesson calls them building blocks: nothing in the machine is cleverer than the chain; the chain is the cleverness.
