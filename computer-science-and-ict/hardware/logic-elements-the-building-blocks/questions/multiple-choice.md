# Logic Elements — the Building Blocks — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a logic element?**
a) A small circuit with inputs and one output  b) Only when all inputs are 1  c) When at least one input is 1  d) Flips its single input
**Answer: a) A small circuit with inputs and one output**

**2. (Sub lesson 1) When does an AND element give 1?**
a) When at least one input is 1  b) Only when all inputs are 1  c) Flips its single input  d) Logical operations
**Answer: b) Only when all inputs are 1**

**3. (Sub lesson 1) When does an OR element give 1?**
a) Flips its single input  b) Logical operations  c) When at least one input is 1  d) The output of one feeds the input of another
**Answer: c) When at least one input is 1**

**4. (Sub lesson 1) What does a NOT element do?**
a) Logical operations  b) The output of one feeds the input of another  c) Add numbers and compare them (or remember a bit)  d) Flips its single input
**Answer: d) Flips its single input**

**5. (Sub lesson 1) In the book's order, what comes just before elements?**
a) Logical operations  b) The output of one feeds the input of another  c) Add numbers and compare them (or remember a bit)  d) Chains of millions of logic elements
**Answer: a) Logical operations**

**6. (Sub lesson 2) How do elements join?**
a) Add numbers and compare them (or remember a bit)  b) The output of one feeds the input of another  c) Chains of millions of logic elements  d) One tiny logical job
**Answer: b) The output of one feeds the input of another**

**7. (Sub lesson 2) Name two jobs a chain of elements can do.**
a) Chains of millions of logic elements  b) One tiny logical job  c) Add numbers and compare them (or remember a bit)  d) Because everything bigger is built from them
**Answer: c) Add numbers and compare them (or remember a bit)**

**8. (Sub lesson 2) What is the whole processor, in this picture?**
a) One tiny logical job  b) Because everything bigger is built from them  c) A small circuit with inputs and one output  d) Chains of millions of logic elements
**Answer: d) Chains of millions of logic elements**

**9. (Sub lesson 2) How big is one element's job?**
a) One tiny logical job  b) Because everything bigger is built from them  c) A small circuit with inputs and one output  d) Only when all inputs are 1
**Answer: a) One tiny logical job**

**10. (Sub lesson 2) Why are they called building blocks?**
a) A small circuit with inputs and one output  b) Because everything bigger is built from them  c) Only when all inputs are 1  d) When at least one input is 1
**Answer: b) Because everything bigger is built from them**
