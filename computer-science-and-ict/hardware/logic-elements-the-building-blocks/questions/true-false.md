# Logic Elements — the Building Blocks — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a logic element?" is: A small circuit with inputs and one output**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "When does an AND element give 1?" is: When at least one input is 1**
**Answer: False** — Only when all inputs are 1

**3. (Sub lesson 1) True or false: the answer to "When does an OR element give 1?" is: When at least one input is 1**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does a NOT element do?" is: Logical operations**
**Answer: False** — Flips its single input

**5. (Sub lesson 1) True or false: the answer to "In the book's order, what comes just before elements?" is: Logical operations**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How do elements join?" is: Add numbers and compare them (or remember a bit)**
**Answer: False** — The output of one feeds the input of another

**7. (Sub lesson 2) True or false: the answer to "Name two jobs a chain of elements can do." is: Add numbers and compare them (or remember a bit)**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is the whole processor, in this picture?" is: One tiny logical job**
**Answer: False** — Chains of millions of logic elements

**9. (Sub lesson 2) True or false: the answer to "How big is one element's job?" is: One tiny logical job**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why are they called building blocks?" is: A small circuit with inputs and one output**
**Answer: False** — Because everything bigger is built from them
