# Reading Component Data Books and Datasheets — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) A data book gives information about what?**
a) Electronic components  b) A datasheet  c) Voltage, current and other limits  d) What each pin is for and how to connect it
**Answer: a) Electronic components**

**2. (Sub lesson 1) What is another name for a component's data sheet?**
a) Voltage, current and other limits  b) A datasheet  c) What each pin is for and how to connect it  d) The component's manufacturer
**Answer: b) A datasheet**

**3. (Sub lesson 1) What ratings does a datasheet list?**
a) What each pin is for and how to connect it  b) The component's manufacturer  c) Voltage, current and other limits  d) So the component is not damaged
**Answer: c) Voltage, current and other limits**

**4. (Sub lesson 1) What does a datasheet show about a component's pins?**
a) The component's manufacturer  b) So the component is not damaged  c) That its data-book values match  d) What each pin is for and how to connect it
**Answer: d) What each pin is for and how to connect it**

**5. (Sub lesson 1) Who writes data books?**
a) The component's manufacturer  b) So the component is not damaged  c) That its data-book values match  d) The component can fail or be damaged
**Answer: a) The component's manufacturer**

**6. (Sub lesson 2) Why check a component's maximum voltage?**
a) That its data-book values match  b) So the component is not damaged  c) The component can fail or be damaged  d) Always the data book
**Answer: b) So the component is not damaged**

**7. (Sub lesson 2) Before replacing a component, what do you check?**
a) The component can fail or be damaged  b) Always the data book  c) That its data-book values match  d) When setting up computer electronic systems
**Answer: c) That its data-book values match**

**8. (Sub lesson 2) What can happen beyond a component's rated limits?**
a) Always the data book  b) When setting up computer electronic systems  c) Electronic components  d) The component can fail or be damaged
**Answer: d) The component can fail or be damaged**

**9. (Sub lesson 2) Data book or guess — which does a builder use?**
a) Always the data book  b) When setting up computer electronic systems  c) Electronic components  d) A datasheet
**Answer: a) Always the data book**

**10. (Sub lesson 2) When is the data book used in Papua New Guinea's lessons?**
a) Electronic components  b) When setting up computer electronic systems  c) A datasheet  d) Voltage, current and other limits
**Answer: b) When setting up computer electronic systems**
