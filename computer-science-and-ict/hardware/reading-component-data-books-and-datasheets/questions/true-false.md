# Reading Component Data Books and Datasheets — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "A data book gives information about what?" is: Electronic components**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is another name for a component's data sheet?" is: What each pin is for and how to connect it**
**Answer: False** — A datasheet

**3. (Sub lesson 1) True or false: the answer to "What ratings does a datasheet list?" is: Voltage, current and other limits**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does a datasheet show about a component's pins?" is: So the component is not damaged**
**Answer: False** — What each pin is for and how to connect it

**5. (Sub lesson 1) True or false: the answer to "Who writes data books?" is: The component's manufacturer**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Why check a component's maximum voltage?" is: The component can fail or be damaged**
**Answer: False** — So the component is not damaged

**7. (Sub lesson 2) True or false: the answer to "Before replacing a component, what do you check?" is: That its data-book values match**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What can happen beyond a component's rated limits?" is: When setting up computer electronic systems**
**Answer: False** — The component can fail or be damaged

**9. (Sub lesson 2) True or false: the answer to "Data book or guess — which does a builder use?" is: Always the data book**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "When is the data book used in Papua New Guinea's lessons?" is: A datasheet**
**Answer: False** — When setting up computer electronic systems
