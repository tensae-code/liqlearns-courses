## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **What a data book is** — A **data book** is the manufacturer's book of information about **electronic components**; a single component's sheet from it is a **datasheet**. It lists the component's **ratings — voltage, current and other limits** — and shows **what each pin is for and how to connect it**.
2. **Using a data book to choose and connect a component** — Before a component is used or replaced, its **data-book values are checked** — above all the **maximum voltage**, because a component used **beyond its rated limits can fail or be damaged**. In Papua New Guinea's lessons the data book comes out whenever computer electronic systems are set up: the rule is data book, never guess.
