# Input devices — putting data in — multiple choice

Pick the one right answer.

**1. Input devices —**
a) bring results out  b) insert data into the computer system  c) store data forever
**Answer: b) insert data into the computer system**

**2. How many input devices does the book's list name?**
a) Five  b) Six  c) Eight
**Answer: c) Eight** — Keyboard, mouse, scanner, touch screen, light pen, barcode reader, microphone, camera.

**3. Which of these is an input device?**
a) Printer  b) Microphone  c) Monitor
**Answer: b) Microphone** — A microphone inputs the spoken word.

**4. A camera is an input device because it —**
a) prints photos  b) captures photographs into the system  c) shows films
**Answer: b) captures photographs into the system**

**5. Which pair are both pointing input devices?**
a) Mouse and light pen  b) Printer and speaker  c) Disk and CD
**Answer: a) Mouse and light pen**
