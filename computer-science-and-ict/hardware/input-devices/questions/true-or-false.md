# Input devices — putting data in — true or false

Say whether each statement is true or false.

**1. A scanner is an input device.**
**Answer: True** — It converts hardcopy into softcopy — data in.

**2. A monitor is in the book's input list.**
**Answer: False** — The monitor is an output device; the input list has eight named devices.

**3. A barcode reader inserts data into the system.**
**Answer: True**

**4. Every piece of data enters the computer through an input device.**
**Answer: True** — Data cannot walk in by itself.
