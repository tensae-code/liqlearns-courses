# Hands-on — Input devices — putting data in

The lesson with your hands and your feet, not only your eyes.

## Door diary
For one day, note each time data enters a computer or phone around you, and which input device it crossed through. Keyboard or camera — which door was busiest?

## Eight cards
Make a card per device: name on one side, the data it admits on the other. Shuffle and test yourself — name face-up, say the data; data face-up, name the device.
