# Flip-Flops — RS, JK, D and T — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 1) A flip-flop is also called a ____ circuit, because it has two stable states.**
**Answer: bistable** — Bi- means two: it rests stably in state 0 or state 1.

**2. (Sub lesson 1) The RS input that makes Q = 0 is called ____.**
**Answer: reset (R)** — Set writes 1; reset clears to 0.

**3. (Sub lesson 2) The flip-flop whose single input is copied to Q on each clock tick is the ____ flip-flop.**
**Answer: D** — D for data: Q next = D now.

**4. (Sub lesson 2) When J and K are both 1, a JK flip-flop ____ on each tick.**
**Answer: toggles** — Its output flips to the opposite state every tick.
