# Flip-Flops — RS, JK, D and T — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Q and Q̄ are always opposite to each other in a healthy flip-flop.**
**Answer: True** — Q̄ is by definition the opposite of Q; the forbidden RS case is dangerous precisely because it breaks this rule.

**2. (Sub lesson 1) When neither RS input is active, the flip-flop's Q becomes 0.**
**Answer: False** — With neither active it holds — Q keeps its previous value. That holding is the memory.

**3. (Sub lesson 2) A JK flip-flop has no forbidden input combination.**
**Answer: True** — All four J/K combinations are defined: hold, reset, set, toggle.

**4. (Sub lesson 2) A D flip-flop's output follows D continuously, tick or no tick.**
**Answer: False** — Q copies D only at the clock tick; between ticks Q holds its stored value.
