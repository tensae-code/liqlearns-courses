# Robot Sensors — How a Robot Feels Its World — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Thymio's senses
Sub lesson 1 questions from the type files. Pass mark: A sensor — a part that turns a piece of the world into a signal; They bounce light off what is near and read the return; The surface below — dark line from light floor; A number or a yes/no it can use; Blind to everything it cannot sense.

## Sub lesson 2 — Testing sensors honestly
Sub lesson 2 questions from the type files. Pass mark: Whether Thymio's sensors are effective with all materials; A surface that swallows light, or one that reflects it away (answers vary: dark, transparent); Where detection succeeds and where it fails; The program must be written for the sensor the robot actually has; A scientist's question — tested, not assumed.
