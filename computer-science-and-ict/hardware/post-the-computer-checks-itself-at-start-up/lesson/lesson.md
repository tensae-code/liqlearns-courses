# POST — the computer checks itself at start-up

## Do it first

Press the power button of a computer in your mind and watch the first seconds. Before any program opens, the machine is already busy — checking itself. Write what you think it checks. Then read on and compare.

## Sub lesson 1 — What POST checks

Every time a computer starts, it runs **POST — the Power On Self-Test**. POST checks the **keyboard, RAM (memory), disk drives and other hardware**, to confirm they are all working before the computer goes on.

## Sub lesson 2 — How POST reports a fault

If POST finds an error, it reports it in one of two ways:

- a **text error message on the screen**, or
- a **pattern of short and long beeps** — the beep codes, taught in the next lesson.

The book's advice on a boot error message is plain: **type the exact message into an internet search** to learn more about it. Copy it exactly — one changed word can find the wrong answer.

> **Teacher evidence:** in class this check is run live — the teacher starts a real machine and the class watches POST work, then reads its beep patterns together (teacher guide, printed p. 91).
