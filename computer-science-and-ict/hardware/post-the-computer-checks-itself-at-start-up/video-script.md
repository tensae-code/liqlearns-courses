# Video script — POST — the computer checks itself at start-up

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then. Short script; the placement names no full video need for this lesson.

---

Switch on. Wait. The computer is checking itself.

Keyboard. Memory. Disk drives. Hardware.
That check has a name: POST.
Power On Self-Test.

All well? The computer goes on.
A fault? A message on the screen —
or beeps: short, long, in a pattern.

See a message? Copy it exactly.
Search those exact words. Learn more.
