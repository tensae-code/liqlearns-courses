# Lesson plan — POST — the computer checks itself at start-up

**Course:** Computer Science and ICT · **Title:** Hardware · **Lesson:** POST — the computer checks itself at start-up
**Place in the curriculum:** Unit 5 — Hardware Troubleshooting and Preventive Maintenance (CURRICULUM.md).
**The one thing this lesson teaches:** POST — the Power On Self-Test — is the check the computer runs on its own hardware every time it starts, reporting trouble as a message on screen or as beeps.
**This lesson's own level:** It stands on Troubleshooting — start with the simple checks: POST is the first specific check after the simple ones.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **What POST checks** — At start-up the computer tests its keyboard, RAM, disk drives and other hardware to confirm they are working.
2. **How POST reports a fault** — A text error message on screen, or a pattern of short and long beeps. On a boot error message, type the exact message into an internet search to learn more.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: the lessons before this one in Hardware on the ladder. Recommended, never forced — a learner may land on this lesson directly, and it stands alone.

## What the learner can do when it ends
1. Write POST in full and say, in one sentence, when it runs.
2. A machine shows a boot error message. Write your next two steps, in order.
3. Name the two ways POST can report an error.

## What you need
A Windows school computer if one is available — paper works too, screen by screen. Paper and a pencil.

## If the learner is stuck
- Thinks POST is a program you open → POST runs by itself, at start-up, before your programs. You never click it.
- Copies the error message roughly → the search needs the exact message; one word changed, one answer lost.
