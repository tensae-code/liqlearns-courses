# POST — the computer checks itself at start-up — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** POST stands for —
a) Power On Self-Test  b) Program Open Start Tool  c) Personal Operating System Test  d) Power Off System Timer
**Answer: a) Power On Self-Test** — the start-up self-check.

**2. (Sub lesson 1)** POST runs —
a) when you click its icon  b) every time the computer starts  c) only when a fault is found  d) once a month
**Answer: b) every time the computer starts** — at every start-up.

**3. (Sub lesson 1)** POST checks —
a) your documents  b) keyboard, RAM, disk drives and other hardware  c) the internet speed  d) your password
**Answer: b) keyboard, RAM, disk drives and other hardware** — the hardware list in the book.

**4. (Sub lesson 2)** POST reports an error by —
a) shutting down silently  b) a text message on screen, or a pattern of beeps  c) a printed report  d) an email
**Answer: b) a text message on screen, or a pattern of beeps** — message or beeps — the two ways.

**5. (Sub lesson 2)** On a boot error message, the book's advice is —
a) ignore it  b) restart ten times  c) type the exact message into an internet search  d) replace the RAM
**Answer: c) type the exact message into an internet search** — the exact message, searched online.
