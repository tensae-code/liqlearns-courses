# POST — the computer checks itself at start-up — short answer

Answer in a sentence or two.

**1. (Sub lesson 1)** In one sentence: what is POST?
**Answer: The start-up check the computer runs on its keyboard, RAM, disk drives and other hardware to confirm they are working.**

**2. (Sub lesson 2)** Why must an error message be copied exactly before searching?
**Answer: Because the search learns from the exact words; a changed word can find the wrong fault and the wrong fix.**
