# POST — the computer checks itself at start-up — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** POST confirms the hardware is working before the computer goes on.
**Answer: True** — that is its job.

**2. (Sub lesson 2)** A rough copy of an error message is good enough for a search.
**Answer: False** — the book says type the exact message.

**3. (Sub lesson 2)** Beeps are one of the two ways POST reports a fault.
**Answer: True** — message on screen, or beeps.
