# Hands-on — POST — the computer checks itself at start-up

The lesson with your hands, not only your eyes.

## Watch a start-up
Start a school computer and watch the first screen closely. List anything the machine reports checking or finding. If your machine shows nothing, say so — and say what the beeps would tell you instead.

## Exact words
Your teacher writes a boot error message on the board. Copy it exactly, character for character. Swap with a partner and check each other's copy — the search only works with the exact message.
