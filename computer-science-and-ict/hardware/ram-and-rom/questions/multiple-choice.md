# RAM and ROM — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) RAM stores —**
a) permanent data only  b) the instructions and data in use at the present moment  c) only pictures
**Answer: b) the instructions and data in use at the present moment**

**2. (Sub lesson 1) Volatile means —**
a) contents are lost when the computer is switched off  b) very fast  c) very large
**Answer: a) contents are lost when the computer is switched off**

**3. (Sub lesson 1) RAM's speed is —**
a) much slower than ROM  b) high speed  c) zero
**Answer: b) high speed** — Book's table.

**4. (Sub lesson 2) ROM holds —**
a) temporary data  b) permanent data that stays whether the computer is on or off  c) nothing until switch-on
**Answer: b) permanent data that stays whether the computer is on or off**

**5. (Sub lesson 2) ROM can be —**
a) read and written freely  b) only read  c) erased at switch-off
**Answer: b) only read**

**6. (Sub lesson 2) "RAM is permanent storage" — the guide's key says this is —**
a) correct  b) a common miss: RAM is NOT permanent storage  c) true for new computers
**Answer: b) a common miss: RAM is NOT permanent storage** — Guide printed pp. 31–34.
