# RAM and ROM — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) RAM contents survive switch-off.**
**Answer: False** — RAM is volatile — its contents are lost.

**2. (Sub lesson 1) You can write to RAM in ordinary use.**
**Answer: True** — Read-and-write, in the book's table.

**3. (Sub lesson 2) ROM data stays when the computer is off.**
**Answer: True**

**4. (Sub lesson 2) ROM is faster than RAM.**
**Answer: False** — The table says ROM is much slower.
