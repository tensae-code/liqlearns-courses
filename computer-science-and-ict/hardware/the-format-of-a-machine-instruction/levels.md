# The Format of a Machine Instruction — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Fields — operation code and addresses
Sub lesson 1 questions from the type files. Pass mark: An operation code field and address field(s); What to do — add, load, store, jump — from the processor's instruction set; Where the operands are — registers or memory addresses; 16 operations; a 12-bit address reaches 4096 cells; A budget of bits — spent between variety of operations and reach of addresses.

## Sub lesson 2 — Formats by address count — three, two, one, zero
Sub lesson 2 questions from the type files. Pass mark: Three-address, two-address, one-address and zero-address; An implied accumulator; A stack — the operands are understood; Shorter instructions and a simpler processor; more instructions per job; The architecture's founding compromise.
