# The Format of a Machine Instruction — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: An operation code field and address field(s)**
**Answer: True**

**2. (Sub lesson 1) True or false: An operation code field and address field(s)** — as the answer to: What does the opcode name?
**Answer: False — What to do — add, load, store, jump — from the processor's instruction set**

**3. (Sub lesson 1) True or false: Where the operands are — registers or memory addresses**
**Answer: True**

**4. (Sub lesson 1) True or false: Where the operands are — registers or memory addresses** — as the answer to: In a 16-bit instruction with a 4-bit opcode, how many operations and addresses fit?
**Answer: False — 16 operations; a 12-bit address reaches 4096 cells**

**5. (Sub lesson 1) True or false: A budget of bits — spent between variety of operations and reach of addresses**
**Answer: True**

**6. (Sub lesson 2) True or false: A budget of bits — spent between variety of operations and reach of addresses** — as the answer to: What classes has the format by address count?
**Answer: False — Three-address, two-address, one-address and zero-address**

**7. (Sub lesson 2) True or false: An implied accumulator**
**Answer: True**

**8. (Sub lesson 2) True or false: An implied accumulator** — as the answer to: What does zero-address work on?
**Answer: False — A stack — the operands are understood**

**9. (Sub lesson 2) True or false: Shorter instructions and a simpler processor; more instructions per job**
**Answer: True**

**10. (Sub lesson 2) True or false: Shorter instructions and a simpler processor; more instructions per job** — as the answer to: What is the format choice called in the lesson?
**Answer: False — The architecture's founding compromise**
