# The CPU — the brain of the computer — true or false

Say whether each statement is true or false.

**1. Data is actually worked on in the CPU.**
**Answer: True** — Input devices bring it in; the CPU works on it.

**2. Logical operations — comparing and deciding — happen in the CPU.**
**Answer: True**

**3. Registers are one of the CPU's three components.**
**Answer: True**

**4. The CPU is the same thing as the monitor.**
**Answer: False** — The monitor is an output device.
