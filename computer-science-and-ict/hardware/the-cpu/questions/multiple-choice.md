# The CPU — the brain of the computer — multiple choice

Pick the one right answer.

**1. CPU stands for —**
a) central processing unit  b) computer personal unit  c) central program utility
**Answer: a) central processing unit**

**2. The CPU is called —**
a) the memory of the computer  b) the brain of the computer  c) the screen of the computer
**Answer: b) the brain of the computer**

**3. The CPU does which operations?**
a) Arithmetic, logical and control  b) Only arithmetic  c) Only printing
**Answer: a) Arithmetic, logical and control**

**4. How many components does the CPU have?**
a) Two  b) Three  c) Five
**Answer: b) Three** — ALU, control unit, registers.

**5. Which is NOT a CPU component?**
a) Registers  b) Control unit  c) Barcode reader
**Answer: c) Barcode reader** — A barcode reader is an input device.
