# How Real Numbers Are Represented Inside the Computer — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Sign, exponent and mantissa**
**Answer: True**

**2. (Sub lesson 1) True or false: Sign, exponent and mantissa** — as the answer to: What formula gives the value?
**Answer: False — sign × mantissa × 2^exponent**

**3. (Sub lesson 1) True or false: The mantissa's first digit is 1**
**Answer: True**

**4. (Sub lesson 1) True or false: The mantissa's first digit is 1** — as the answer to: What do more exponent bits buy, and more mantissa bits?
**Answer: False — Wider range; finer precision**

**5. (Sub lesson 1) True or false: The bit count is fixed — each field's share is taken from the others'**
**Answer: True**

**6. (Sub lesson 2) True or false: The bit count is fixed — each field's share is taken from the others'** — as the answer to: What are the representation's two edges?
**Answer: False — Range (overflow and underflow) and precision (values sharing one stored neighbour)**

**7. (Sub lesson 2) True or false: Its binary mantissa does not terminate — the stored value is a close neighbour**
**Answer: True**

**8. (Sub lesson 2) True or false: Its binary mantissa does not terminate — the stored value is a close neighbour** — as the answer to: Where do long computations' errors come from?
**Answer: False — Accumulated rounding at the precision limit**

**9. (Sub lesson 2) True or false: Grade 12's lessons on calculation errors**
**Answer: True**

**10. (Sub lesson 2) True or false: Grade 12's lessons on calculation errors** — as the answer to: Is floating point a failure?
**Answer: False — No — a chosen compromise: range and honesty about precision in one row of bits**
