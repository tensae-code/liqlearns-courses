# Boolean Laws and De Morgan's Theorems — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) The law A + B·C = (A + B)·(A + C) holds in Boolean algebra even though it does not hold in ordinary school algebra.**
**Answer: True** — Boolean algebra has both distributive laws; this second one is proved by an eight-row truth table.

**2. (Sub lesson 1) A + A = 2A in Boolean algebra.**
**Answer: False** — There is no 2 in Boolean algebra: A + A = A, the idempotent law.

**3. (Sub lesson 2) Breaking a De Morgan bar over a bracket changes + into · and · into +.**
**Answer: True** — That is the working picture of both theorems: break the bar, change the operation.

**4. (Sub lesson 2) After simplifying an expression, there is no way to check you did not change its meaning.**
**Answer: False** — The truth table is the check: build the tables of the original and the simplified expression and compare the columns.
