# Device Manager — finding problem hardware — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Device Manager is —
a) an antivirus  b) the central, organised view of all Windows-recognised hardware  c) a printer setting  d) a beep code
**Answer: b) the central, organised view of all Windows-recognised hardware** — the organised hardware view.

**2. (Sub lesson 1)** The route to Device Manager passes through —
a) Settings, then Update & Security  b) Control Panel, then Hardware and Sound  c) BIOS, then CMOS  d) Task Manager, then Performance
**Answer: b) Control Panel, then Hardware and Sound** — Control Panel → Hardware and Sound.

**3. (Sub lesson 1)** Device Manager sits under —
a) System and Security  b) Devices and Printers  c) User Accounts  d) Programs
**Answer: b) Devices and Printers** — under Devices and Printers.

**4. (Sub lesson 2)** A yellow triangle with an exclamation mark means —
a) the device is disabled  b) the device has a problem  c) the driver is unknown  d) the device is removed
**Answer: b) the device has a problem** — the problem sign.

**5. (Sub lesson 2)** A red X means the device is —
a) working well  b) disabled, removed, or not found  c) missing its driver  d) overheating
**Answer: b) disabled, removed, or not found** — the widest of the bad signs.

**6. (Sub lesson 2)** A downward arrow means —
a) a problem  b) not found  c) disabled  d) downloading
**Answer: c) disabled** — disabled — the arrow's only meaning.

**7. (Sub lesson 2)** A yellow question mark is fixed by —
a) restarting  b) installing the right driver  c) reseating the card  d) replacing the battery
**Answer: b) installing the right driver** — Windows does not know the driver — install the right one.

**8. (Sub lesson 3)** The guide's fix for a flagged device begins —
a) Update Driver at once  b) right-click the device, then Properties  c) open Event Viewer  d) search online first
**Answer: b) right-click the device, then Properties** — right-click → Properties → Driver → Update Driver.
