# Device Manager — finding problem hardware — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Device Manager can enable or disable hardware.
**Answer: True** — one of its named uses.

**2. (Sub lesson 2)** A yellow question mark means the device has a virus.
**Answer: False** — it means Windows does not know which driver to install.

**3. (Sub lesson 3)** An internet search is the FIRST step of the guide's fix sequence.
**Answer: False** — it is the fallback, after Update Driver.
