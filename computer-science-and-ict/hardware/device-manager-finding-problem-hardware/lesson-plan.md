# Lesson plan — Device Manager — finding problem hardware

**Course:** Computer Science and ICT · **Title:** Hardware · **Lesson:** Device Manager — finding problem hardware
**Place in the curriculum:** Unit 5 — Hardware Troubleshooting and Preventive Maintenance (CURRICULUM.md).
**The one thing this lesson teaches:** Device Manager is the organised view of all the hardware Windows knows: five steps take you there, and four signs — yellow triangle, red X, down arrow, yellow question mark — mark the devices in trouble.
**This lesson's own level:** It stands on Event Viewer — reading the error log: the log tells the story, Device Manager shows the device itself.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Reaching Device Manager — five steps** — Search box, Control Panel, Hardware and Sound, then Device Manager under Devices and Printers — the book's five printed steps.
2. **The four problem signs** — Yellow triangle with an exclamation mark: a problem. Red X: disabled, removed or not found. Downward arrow: disabled. Yellow question mark: Windows does not know which driver to install.
3. **Fixing a flagged device (teacher guide — evidence)** — The guide's working sequence: right-click the flagged device, Properties, the Driver tab, Update Driver — with an internet search as the fallback.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## What the learner can do when it ends
1. Write the five steps to Device Manager in order, without looking.
2. Draw the four signs from memory and write each meaning beside it.
3. A device carries a yellow question mark. Write what is wrong and what fixes it.

## If the learner is stuck
- Mixes the red X and the down arrow → both can mean disabled, but the red X also covers removed or not found; the arrow means disabled only.
- Takes a search shortcut to Device Manager → the five-step route is the skill being taught; shortcuts come after the route is known.
