# Keyboard Shortcut Keys — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a shortcut key?**
**Answer: A key combination that issues a command at once**

**2. (Sub lesson 1) Name the three common modifier keys.**
**Answer: Ctrl, Alt and Shift**

**3. (Sub lesson 1) Which chord saves?**
**Answer: Ctrl+S**

**4. (Sub lesson 1) Which chord undoes?**
**Answer: Ctrl+Z**

**5. (Sub lesson 1) Where does a program print a command's shortcut?**
**Answer: In the menu, beside the command**

**6. (Sub lesson 2) Name the clipboard family.**
**Answer: Ctrl+X cut, Ctrl+C copy, Ctrl+V paste**

**7. (Sub lesson 2) Which chord selects all?**
**Answer: Ctrl+A**

**8. (Sub lesson 2) Which chord opens Find?**
**Answer: Ctrl+F**

**9. (Sub lesson 2) How are shortcuts best learned?**
**Answer: One at a time, in real work, a week each**

**10. (Sub lesson 2) What is the deeper gift beyond speed?**
**Answer: Flow — the thought never breaks to hunt a menu**
