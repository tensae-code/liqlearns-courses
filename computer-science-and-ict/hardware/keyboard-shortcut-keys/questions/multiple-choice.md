# Keyboard Shortcut Keys — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a shortcut key?**
a) A key combination that issues a command at once  b) Ctrl, Alt and Shift  c) Ctrl+S  d) Ctrl+Z
**Answer: a**

**2. (Sub lesson 1) Name the three common modifier keys.**
a) Ctrl, Alt and Shift  b) Ctrl+S  c) Ctrl+Z  d) In the menu, beside the command
**Answer: a**

**3. (Sub lesson 1) Which chord saves?**
a) Ctrl+S  b) Ctrl+Z  c) In the menu, beside the command  d) Ctrl+X cut, Ctrl+C copy, Ctrl+V paste
**Answer: a**

**4. (Sub lesson 1) Which chord undoes?**
a) Ctrl+Z  b) In the menu, beside the command  c) Ctrl+X cut, Ctrl+C copy, Ctrl+V paste  d) Ctrl+A
**Answer: a**

**5. (Sub lesson 1) Where does a program print a command's shortcut?**
a) In the menu, beside the command  b) Ctrl+X cut, Ctrl+C copy, Ctrl+V paste  c) Ctrl+A  d) Ctrl+F
**Answer: a**
