# Keyboard Shortcut Keys — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A key combination that issues a command at once**
**Answer: True**

**2. (Sub lesson 1) True or false: A key combination that issues a command at once** — as the answer to: Name the three common modifier keys.
**Answer: False — Ctrl, Alt and Shift**

**3. (Sub lesson 1) True or false: Ctrl+S**
**Answer: True**

**4. (Sub lesson 1) True or false: Ctrl+S** — as the answer to: Which chord undoes?
**Answer: False — Ctrl+Z**

**5. (Sub lesson 1) True or false: In the menu, beside the command**
**Answer: True**

**6. (Sub lesson 2) True or false: In the menu, beside the command** — as the answer to: Name the clipboard family.
**Answer: False — Ctrl+X cut, Ctrl+C copy, Ctrl+V paste**

**7. (Sub lesson 2) True or false: Ctrl+A**
**Answer: True**

**8. (Sub lesson 2) True or false: Ctrl+A** — as the answer to: Which chord opens Find?
**Answer: False — Ctrl+F**

**9. (Sub lesson 2) True or false: One at a time, in real work, a week each**
**Answer: True**

**10. (Sub lesson 2) True or false: One at a time, in real work, a week each** — as the answer to: What is the deeper gift beyond speed?
**Answer: False — Flow — the thought never breaks to hunt a menu**
