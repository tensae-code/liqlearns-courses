# Video script — Keyboard Shortcut Keys

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A **shortcut key** is a **combination** — a modifier key held (Ctrl, Alt, Shift) plus a letter or function key pressed — that issues a command at once: Ctrl+S saves, Ctrl+C copies, Ctrl+V pastes, Ctrl+Z undoes. The combination is a chord, pressed together, not a sequence typed slowly. Programs share a common family (the editing chords above work almost everywhere) and add their own; the menu beside a command usually prints its shortcut, teaching you the road at the moment you walk the long way.
Grade 7's session builds the **working set** a learner uses daily: saving and opening (Ctrl+S, Ctrl+O), the clipboard family (cut, copy, paste — Ctrl+X, C, V), undo and redo (Ctrl+Z, Ctrl+Y), select all (Ctrl+A), find (Ctrl+F), and moving between windows and fields (Alt+Tab, Tab). The way to learn them is one at a time, in real work: choose the shortcut for the command you use most, use only it for a week, then add the next. Speed is the visible gift; the deeper one is flow — the hands stay, the thought never breaks to hunt a menu.
