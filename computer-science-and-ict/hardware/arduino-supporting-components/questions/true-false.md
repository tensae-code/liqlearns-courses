# Arduino Supporting Components — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The kit that surrounds the board — the parts its projects are built from**
**Answer: True**

**2. (Sub lesson 1) True or false: The kit that surrounds the board — the parts its projects are built from** — as the answer to: What is the breadboard?
**Answer: False — The solderless field where circuits are assembled and changed**

**3. (Sub lesson 1) True or false: Join board, breadboard and components as removable roads**
**Answer: True**

**4. (Sub lesson 1) True or false: Join board, breadboard and components as removable roads** — as the answer to: Why inventory the kit before projects?
**Answer: False — A builder who cannot name the parts cannot read a circuit diagram — diagrams are written in these parts**

**5. (Sub lesson 1) True or false: The resistor**
**Answer: True**

**6. (Sub lesson 2) True or false: The resistor** — as the answer to: Name three output devices in the kit.
**Answer: False — LED, piezo buzzer, servo/stepper motors, LCD (any three)**

**7. (Sub lesson 2) True or false: The push button and the sensor modules**
**Answer: True**

**8. (Sub lesson 2) True or false: The push button and the sensor modules** — as the answer to: Which sensor modules does the book name?
**Answer: False — Light, sound, temperature and soil-moisture sensors**

**9. (Sub lesson 2) True or false: Sense something, decide, act**
**Answer: True**

**10. (Sub lesson 2) True or false: Sense something, decide, act** — as the answer to: Where does Indonesia teach this?
**Answer: False — Grade 12, Bab 2 B.3 — supporting components of the single-board controller**
