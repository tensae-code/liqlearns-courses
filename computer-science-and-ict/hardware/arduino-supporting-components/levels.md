# Arduino Supporting Components — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — The bench — breadboard, power and wires
Sub lesson 1 questions from the type files. Pass mark: The kit that surrounds the board — the parts its projects are built from; The solderless field where circuits are assembled and changed; Join board, breadboard and components as removable roads; A builder who cannot name the parts cannot read a circuit diagram — diagrams are written in these parts; The resistor.
