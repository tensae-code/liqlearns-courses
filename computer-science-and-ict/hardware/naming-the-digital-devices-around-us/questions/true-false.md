# Naming the Digital Devices Around Us — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Tablette, ordinateur, écran, souris (tablet, computer, screen, mouse)**
**Answer: True**

**2. (Sub lesson 1) True or false: Tablette, ordinateur, écran, souris (tablet, computer, screen, mouse)** — as the answer to: What three things does the fiche match together?
**Answer: False — Picture, name, and the thing itself**

**3. (Sub lesson 1) True or false: A class cannot talk about, share or care for tools it cannot name together**
**Answer: True**

**4. (Sub lesson 1) True or false: A class cannot talk about, share or care for tools it cannot name together** — as the answer to: What is the fiche called?
**Answer: False — Les différents appareils — the different devices**

**5. (Sub lesson 1) True or false: The mouse**
**Answer: True**

**6. (Sub lesson 2) True or false: The mouse** — as the answer to: What is a screen not?

**7. (Sub lesson 2) True or false: One thing**
**Answer: True**

**8. (Sub lesson 2) True or false: One thing** — as the answer to: What fails when names slide between things?
**Answer: False — Instructions, programs and care routines**

**9. (Sub lesson 2) True or false: The course's later precision**
