# Frequently Used Combinational Circuits — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: It turns one active input line (of 2ⁿ) into its n-bit binary code**
**Answer: True**

**2. (Sub lesson 1) True or false: It turns one active input line (of 2ⁿ) into its n-bit binary code** — as the answer to: What does a decoder do?
**Answer: False — It activates exactly one of 2ⁿ output lines, chosen by its n-bit code**

**3. (Sub lesson 1) True or false: Inside a keyboard — naming the pressed key as a code**
**Answer: True**

**4. (Sub lesson 1) True or false: Inside a keyboard — naming the pressed key as a code** — as the answer to: Give a decoder at work.
**Answer: False — Choosing which memory bank or display digit a code addresses**

**5. (Sub lesson 1) True or false: Mirror images around a code — compress lines to bits; expand bits to one line**
**Answer: True**

**6. (Sub lesson 2) True or false: Mirror images around a code — compress lines to bits; expand bits to one line** — as the answer to: What does a multiplexer do?
**Answer: False — It chooses one of several inputs to send to its single output, steered by control bits**

**7. (Sub lesson 2) True or false: It routes one input to one of several outputs**
**Answer: True**

**8. (Sub lesson 2) True or false: It routes one input to one of several outputs** — as the answer to: What does a comparator report?
**Answer: False — Whether its two numbers stand greater, equal or less — three outputs**

**9. (Sub lesson 2) True or false: Combinational circuits — output a pure function of today's inputs, no memory**
**Answer: True**

**10. (Sub lesson 2) True or false: Combinational circuits — output a pure function of today's inputs, no memory** — as the answer to: What is built from this toolkit?
**Answer: False — Everything memoryless the CPU does — its present-tense electronics**
