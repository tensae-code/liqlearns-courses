# Steps 2–6 — test a scenario, fix, verify, document — ordering

Put the steps in the right order.

**1. (Sub lesson 1)** These steps are mixed up. Write them in the right order:

- Document the issue
- Develop a scenario
- Implement the solution
- Test the scenario
- Verify system functionality
- Make a plan of action

**Answer (right order):** Develop a scenario → Test the scenario → Make a plan of action → Implement the solution → Verify system functionality → Document the issue
