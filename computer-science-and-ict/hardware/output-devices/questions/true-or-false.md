# Output devices — getting results out — true or false

Say whether each statement is true or false.

**1. A speaker is an output device.**
**Answer: True** — It outputs computer sound.

**2. A hard copy is the version inside the computer.**
**Answer: False** — That is softcopy; a hard copy is on paper.

**3. The plotter is printer-like.**
**Answer: True** — The book describes it so — for graphical pictures and posters.

**4. Output results must be in a form humans understand.**
**Answer: True** — That is the definition's heart.
