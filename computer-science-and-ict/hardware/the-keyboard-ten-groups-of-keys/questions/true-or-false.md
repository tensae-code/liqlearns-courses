# The keyboard — ten groups of keys — true or false

Say whether each statement is true or false.

**1. (Sub lesson 2)** ALT gives alternate operations in combination with other keys.
**Answer: True**

**2. (Sub lesson 1)** The typing keys include letters, numbers, punctuation and symbols.
**Answer: True**

**3. (Sub lesson 3)** The numeric keypad is used mainly for drawing pictures.
**Answer: False**
