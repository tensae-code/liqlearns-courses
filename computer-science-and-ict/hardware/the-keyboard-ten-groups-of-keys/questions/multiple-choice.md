# The keyboard — ten groups of keys — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Escape is used to —
a) Save a file  b) Cancel or close an operation  c) Type capital letters  d) Scroll a page
**Answer: b) Cancel or close an operation** — Escape cancels or closes an operation; it sits at the top-left.

**2. (Sub lesson 1)** Backspace deletes —
a) The character before the cursor  b) The whole document  c) The character after the cursor only  d) Nothing
**Answer: a) The character before the cursor** — Backspace deletes the character before the cursor.

**3. (Sub lesson 1)** F1 is mostly —
a) Print  b) Help  c) Save  d) Delete
**Answer: b) Help** — Function keys do specific tasks; F1 is mostly Help.

**4. (Sub lesson 1)** Which keys are in the navigation and editing group?
a) Home, End, Page Up, Page Down, Delete, Insert  b) Only letters  c) Only numbers  d) CTRL and ALT
**Answer: a) Home, End, Page Up, Page Down, Delete, Insert** — Navigation and editing: arrows, Home, End, Page Up, Page Down, Delete, Insert.

**5. (Sub lesson 2)** CTRL is used —
a) Alone, to type letters  b) With other keys — for bold, italic, underline, save, copy, cut and paste  c) Only for games  d) To switch the computer off
**Answer: b) With other keys — for bold, italic, underline, save, copy, cut and paste** — CTRL works in combination with other keys.

**6. (Sub lesson 2)** The Windows key on its own —
a) Deletes text  b) Opens and closes the Start menu  c) Prints the screen  d) Locks the computer
**Answer: b) Opens and closes the Start menu** — The Windows key opens and closes the Start menu.

**7. (Sub lesson 2)** Windows + L —
a) Opens Computer  b) Shows the desktop  c) Locks the computer or switches users  d) Opens Help
**Answer: c) Locks the computer or switches users** — Windows+L locks the computer or switches users; D shows the desktop, E opens Computer.

**8. (Sub lesson 3)** The numeric keypad is —
a) A screen  b) Numbers grouped like a calculator for quick entry  c) A mouse part  d) A printer tray
**Answer: b) Numbers grouped like a calculator for quick entry** — The numeric keypad groups numbers like a calculator for quick entry.
