**The keyboard.**

First, brainstorm: what do you already know about this? Say it out loud.

Now the one thing: the keyboard enters data through keys grouped by function into ten groups — from Escape and Backspace to the Windows key and the numeric keypad.

**The ten groups.** The keyboard enters data through keys grouped by function: Escape, which cancels or closes an operation, at the top-left; Backspace, which deletes the character before the cursor; the function keys, which do specific tasks — F1 is mostly Help; the navigation and editing keys — arrows, Home, End, Page Up, Page Down, Delete, Insert; the typing or alphanumeric keys — letters, numbers, punctuation and symbols; and the four directional arrow keys, which also appear among the navigation keys..
**Keys that work with partners — CTRL, ALT, the Windows key.** CTRL is used with other keys — bold, italic, underline, save, copy, cut and paste are done with CTRL held down.
**The numeric keypad.** At the right of most full keyboards sits the numeric keypad: numbers grouped together like a calculator, for quick entry of figures.

Now you: Draw a keyboard and outline each of the ten groups in its own colour, with a label.
