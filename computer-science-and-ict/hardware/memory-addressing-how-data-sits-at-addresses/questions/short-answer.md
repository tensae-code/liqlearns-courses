# Memory Addressing — How Data Sits at Addresses — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a memory address?**
**Answer: The number of a storage place in memory's long row**

**2. (Sub lesson 1) How does the processor find a value?**
**Answer: By its address — as a letter is found by the address on its envelope**

**3. (Sub lesson 1) What happens when a value is stored?**
**Answer: It is placed at an address**

**4. (Sub lesson 1) What are physical addresses?**
**Answer: The real places in the memory hardware — the machine's own street**

**5. (Sub lesson 1) How does a variable's name relate to an address?**
**Answer: The name is the programmer's address for the same place; the system joins name to physical address**

**6. (Sub lesson 2) What does addressing limit?**
**Answer: How much memory a processor can use — the number of addresses it can name**

**7. (Sub lesson 2) Why does the book teach addressing in Grade 8?**
**Answer: It explains how the machine finds one exact value among billions**

**8. (Sub lesson 2) Memory is pictured as what?**
**Answer: A street — a long row of numbered places, not a heap**

**9. (Sub lesson 2) Is 'how much can it address' a real specification?**
**Answer: Yes — it caps the memory the machine can use**

**10. (Sub lesson 2) Where does Indonesia teach this?**
**Answer: Grade 8, Bab 5 B — memory addressing (pengalamatan memori)**
