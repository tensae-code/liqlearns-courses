# Memory Addressing — How Data Sits at Addresses — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What is a memory address?** → **The number of a storage place in memory's long row**

**2. (Sub lesson 1) How does the processor find a value?** → **By its address — as a letter is found by the address on its envelope**

**3. (Sub lesson 1) What happens when a value is stored?** → **It is placed at an address**

**4. (Sub lesson 1) What are physical addresses?** → **The real places in the memory hardware — the machine's own street**

**5. (Sub lesson 1) How does a variable's name relate to an address?** → **The name is the programmer's address for the same place; the system joins name to physical address**

**6. (Sub lesson 2) What does addressing limit?** → **How much memory a processor can use — the number of addresses it can name**

**7. (Sub lesson 2) Why does the book teach addressing in Grade 8?** → **It explains how the machine finds one exact value among billions**

**8. (Sub lesson 2) Memory is pictured as what?** → **A street — a long row of numbered places, not a heap**

**9. (Sub lesson 2) Is 'how much can it address' a real specification?** → **Yes — it caps the memory the machine can use**

**10. (Sub lesson 2) Where does Indonesia teach this?** → **Grade 8, Bab 5 B — memory addressing (pengalamatan memori)**
