# Memory Addressing — How Data Sits at Addresses — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The number of a storage place in memory's long row**
**Answer: True**

**2. (Sub lesson 1) True or false: The number of a storage place in memory's long row** — as the answer to: How does the processor find a value?
**Answer: False — By its address — as a letter is found by the address on its envelope**

**3. (Sub lesson 1) True or false: It is placed at an address**
**Answer: True**

**4. (Sub lesson 1) True or false: It is placed at an address** — as the answer to: What are physical addresses?
**Answer: False — The real places in the memory hardware — the machine's own street**

**5. (Sub lesson 1) True or false: The name is the programmer's address for the same place; the system joins name to physical address**
**Answer: True**

**6. (Sub lesson 2) True or false: The name is the programmer's address for the same place; the system joins name to physical address** — as the answer to: What does addressing limit?
**Answer: False — How much memory a processor can use — the number of addresses it can name**

**7. (Sub lesson 2) True or false: It explains how the machine finds one exact value among billions**
**Answer: True**

**8. (Sub lesson 2) True or false: It explains how the machine finds one exact value among billions** — as the answer to: Memory is pictured as what?
**Answer: False — A street — a long row of numbered places, not a heap**

**9. (Sub lesson 2) True or false: Yes — it caps the memory the machine can use**
**Answer: True**

**10. (Sub lesson 2) True or false: Yes — it caps the memory the machine can use** — as the answer to: Where does Indonesia teach this?
**Answer: False — Grade 8, Bab 5 B — memory addressing (pengalamatan memori)**
