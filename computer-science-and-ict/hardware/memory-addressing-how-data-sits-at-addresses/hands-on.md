# Hands-on — Memory Addressing — How Data Sits at Addresses

The lesson with your hands and your feet, not only your eyes.

## Task one
**Address a street** — Draw a street of 16 memory houses. Store five named values at addresses, then 'run' three fetches: given only the addresses, write what the processor brings back.

## Task two
**Name to address** — Write a tiny program plan with three variables. Make the table the system keeps: variable name, address, value — and show it changing after one new assignment.
