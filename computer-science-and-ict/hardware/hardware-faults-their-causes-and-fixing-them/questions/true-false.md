# Hardware Faults — Their Causes and Fixing Them — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Power, display, storage, input, overheating, connection**
**Answer: True**

**2. (Sub lesson 1) True or false: Power, display, storage, input, overheating, connection** — as the answer to: What is the largest and cheapest family?
**Answer: False — Connection faults — loose and oxidised contacts**

**3. (Sub lesson 1) True or false: Dust, fans, dried thermal paste**
**Answer: True**

**4. (Sub lesson 1) True or false: Dust, fans, dried thermal paste** — as the answer to: What are storage faults' warning signs?
**Answer: False — Disk unseen, clicking, vanishing files**

**5. (Sub lesson 1) True or false: The same symptom has many parents**
**Answer: True**

**6. (Sub lesson 2) True or false: The same symptom has many parents** — as the answer to: Name the fixing order.
**Answer: False — Observe/record, test cheap and external first, open the case only then, verify under load**

**7. (Sub lesson 2) True or false: Separate the symptom's parents — the fault moves with the guilty part**
**Answer: True**

**8. (Sub lesson 2) True or false: Separate the symptom's parents — the fault moves with the guilty part** — as the answer to: Name two safety rules inside the case.
**Answer: False — Power off; static care (and one change at a time)**

**9. (Sub lesson 2) True or false: Only on evidence**
**Answer: True**

**10. (Sub lesson 2) True or false: Only on evidence** — as the answer to: What is done with a fault beyond the school's tools?
**Answer: False — Reported with its evidence, not hidden by guessing**
