# Command-line tools — ipconfig and ping — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The Command Prompt can be opened by typing ___ in the Run window.
a) ping  b) cmd  c) net  d) run
**Answer: b) cmd**

**2. (Sub lesson 1)** ipconfig is the utility that —
a) deletes files  b) verifies network settings and connections  c) draws pictures  d) installs programs
**Answer: b) verifies network settings and connections**

**3. (Sub lesson 1)** ipconfig tells a host's —
a) IP address, subnet mask and default gateway  b) owner and price  c) screen size  d) battery level
**Answer: a) IP address, subnet mask and default gateway**

**4. (Sub lesson 2)** ping transmits —
a) a file  b) a datagram to another host  c) an email  d) a program
**Answer: b) a datagram to another host**

**5. (Sub lesson 2)** If the network works properly, the receiving host —
a) keeps the datagram  b) returns it  c) prints it  d) deletes it
**Answer: b) returns it**

**6. (Sub lesson 2)** The book pings the default gateway at —
a) 8.8.8.8  b) 192.168.0.1  c) 10.0.0.1  d) 127.0.0.1
**Answer: b) 192.168.0.1**
