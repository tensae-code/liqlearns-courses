# Command-line tools — ipconfig and ping — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** ipconfig is a TCP/IP utility.
**Answer: True**

**2. (Sub lesson 2)** A returned ping proves the road between the hosts is open.
**Answer: True**

**3. (Sub lesson 1)** The Command Prompt is found only on a disc.
**Answer: False**
