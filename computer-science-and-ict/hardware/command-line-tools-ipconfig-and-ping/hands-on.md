# Hands-on — Command-line tools — ipconfig and ping

The lesson with your hands, not only your eyes.

## Own-address lab
On a school computer, open the prompt and run ipconfig. Record your IP address, subnet mask and default gateway — the guide's own laboratory practice (teacher evidence).

## Ping the gateway
Ping the default gateway you recorded. Note whether the datagram returned, and write one sentence on what the result proves.
