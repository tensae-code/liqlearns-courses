# Hands-on — Digital and Analog Pins — pinMode, Read and Write

The lesson with your hands and your feet, not only your eyes.

## Task one
**Mode, read, write** — On paper, write the pin commands for a night-light: a light sensor on an analog pin, an LED on a digital pin, the LED on a PWM pin for fading. Label each pin's mode and command.

## Task two
**Fault find** — A program sets an LED pin as INPUT, then digitalWrites it; a button pin is never given a mode. Explain what each fault does and the one-line fix for each.
