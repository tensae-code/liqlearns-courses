# Digital and Analog Pins — pinMode, Read and Write — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What must every pin be told first?** → **Its direction — with pinMode(pin, INPUT or OUTPUT)**

**2. (Sub lesson 1) What is the beginner's most common silent fault?** → **A pin set to the wrong mode**

**3. (Sub lesson 1) What does digitalWrite do?** → **Drives an output pin fully on (HIGH) or off (LOW)**

**4. (Sub lesson 1) What does digitalRead report?** → **An input pin's state — the button pressed or not**

**5. (Sub lesson 1) What does analogRead do?** → **Converts a varying voltage from a sensor into a number — 0 to 1023 on the Uno**

**6. (Sub lesson 2) What does analogWrite set?** → **An output's average level — 0 to 255 — dimming an LED or pacing a motor**

**7. (Sub lesson 2) Digital is the language of what, analog of what?** → **Digital for decisions, analog for degrees**

**8. (Sub lesson 2) Name a sensor each analog input might read.** → **A light sensor or a temperature sensor**

**9. (Sub lesson 2) The course's one commandment for pins is what?** → **Set the mode, then read or write**

**10. (Sub lesson 2) Where does Indonesia teach this?** → **Grade 12, Bab 3 J–K — digital and analog pin commands**
