# Digital and Analog Pins — pinMode, Read and Write — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Its direction — with pinMode(pin, INPUT or OUTPUT)**
**Answer: True**

**2. (Sub lesson 1) True or false: Its direction — with pinMode(pin, INPUT or OUTPUT)** — as the answer to: What is the beginner's most common silent fault?
**Answer: False — A pin set to the wrong mode**

**3. (Sub lesson 1) True or false: Drives an output pin fully on (HIGH) or off (LOW)**
**Answer: True**

**4. (Sub lesson 1) True or false: Drives an output pin fully on (HIGH) or off (LOW)** — as the answer to: What does digitalRead report?
**Answer: False — An input pin's state — the button pressed or not**

**5. (Sub lesson 1) True or false: Converts a varying voltage from a sensor into a number — 0 to 1023 on the Uno**
**Answer: True**

**6. (Sub lesson 2) True or false: Converts a varying voltage from a sensor into a number — 0 to 1023 on the Uno** — as the answer to: What does analogWrite set?
**Answer: False — An output's average level — 0 to 255 — dimming an LED or pacing a motor**

**7. (Sub lesson 2) True or false: Digital for decisions, analog for degrees**
**Answer: True**

**8. (Sub lesson 2) True or false: Digital for decisions, analog for degrees** — as the answer to: Name a sensor each analog input might read.
**Answer: False — A light sensor or a temperature sensor**

**9. (Sub lesson 2) True or false: Set the mode, then read or write**
**Answer: True**

**10. (Sub lesson 2) True or false: Set the mode, then read or write** — as the answer to: Where does Indonesia teach this?
**Answer: False — Grade 12, Bab 3 J–K — digital and analog pin commands**
