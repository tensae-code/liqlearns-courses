# Von Neumann Architecture — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does the von Neumann architecture store in the same memory?**
a) The program and the data it works on  b) The number that names one memory cell  c) One machine can load and run many different programs  d) Stored instructions — data the processor fetches
**Answer: a) The program and the data it works on**

**2. (Sub lesson 1) What is a memory address?**
a) One machine can load and run many different programs  b) The number that names one memory cell  c) Stored instructions — data the processor fetches  d) One instruction or one value, under its address
**Answer: b) The number that names one memory cell**

**3. (Sub lesson 1) Why does storing the program matter?**
a) Stored instructions — data the processor fetches  b) One instruction or one value, under its address  c) One machine can load and run many different programs  d) Fetch, decode, execute
**Answer: c) One machine can load and run many different programs**

**4. (Sub lesson 1) What are programs treated as in this design?**
a) One instruction or one value, under its address  b) Fetch, decode, execute  c) Directs the work and the movement of data  d) Stored instructions — data the processor fetches
**Answer: d) Stored instructions — data the processor fetches**

**5. (Sub lesson 1) What sits in each memory cell?**
a) One instruction or one value, under its address  b) Fetch, decode, execute  c) Directs the work and the movement of data  d) Sums and comparisons — the arithmetic and logic
**Answer: a) One instruction or one value, under its address**

**6. (Sub lesson 2) What are the three steps of the processor's cycle?**
a) Directs the work and the movement of data  b) Fetch, decode, execute  c) Sums and comparisons — the arithmetic and logic  d) The instruction in hand and the values in play
**Answer: b) Fetch, decode, execute**

**7. (Sub lesson 2) What does the control unit do?**
a) Sums and comparisons — the arithmetic and logic  b) The instruction in hand and the values in play  c) Directs the work and the movement of data  d) The single shared path between processor and memory
**Answer: c) Directs the work and the movement of data**

**8. (Sub lesson 2) What does the ALU do?**
a) The instruction in hand and the values in play  b) The single shared path between processor and memory  c) The program and the data it works on  d) Sums and comparisons — the arithmetic and logic
**Answer: d) Sums and comparisons — the arithmetic and logic**

**9. (Sub lesson 2) What do registers hold?**
a) The instruction in hand and the values in play  b) The single shared path between processor and memory  c) The program and the data it works on  d) The number that names one memory cell
**Answer: a) The instruction in hand and the values in play**

**10. (Sub lesson 2) What is the von Neumann bottleneck?**
a) The program and the data it works on  b) The single shared path between processor and memory  c) The number that names one memory cell  d) One machine can load and run many different programs
**Answer: b) The single shared path between processor and memory**
