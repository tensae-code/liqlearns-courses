# Von Neumann Architecture — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does the von Neumann architecture store in the same memory?**
**Answer: The program and the data it works on**

**2. (Sub lesson 1) What is a memory address?**
**Answer: The number that names one memory cell**

**3. (Sub lesson 1) Why does storing the program matter?**
**Answer: One machine can load and run many different programs**

**4. (Sub lesson 1) What are programs treated as in this design?**
**Answer: Stored instructions — data the processor fetches**

**5. (Sub lesson 1) What sits in each memory cell?**
**Answer: One instruction or one value, under its address**

**6. (Sub lesson 2) What are the three steps of the processor's cycle?**
**Answer: Fetch, decode, execute**

**7. (Sub lesson 2) What does the control unit do?**
**Answer: Directs the work and the movement of data**

**8. (Sub lesson 2) What does the ALU do?**
**Answer: Sums and comparisons — the arithmetic and logic**

**9. (Sub lesson 2) What do registers hold?**
**Answer: The instruction in hand and the values in play**

**10. (Sub lesson 2) What is the von Neumann bottleneck?**
**Answer: The single shared path between processor and memory**
