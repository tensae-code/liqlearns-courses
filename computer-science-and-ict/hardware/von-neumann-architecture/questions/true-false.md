# Von Neumann Architecture — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does the von Neumann architecture store in the same memory?" is: The program and the data it works on**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is a memory address?" is: One instruction or one value, under its address**
**Answer: False** — The number that names one memory cell

**3. (Sub lesson 1) True or false: the answer to "Why does storing the program matter?" is: One machine can load and run many different programs**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What are programs treated as in this design?" is: Directs the work and the movement of data**
**Answer: False** — Stored instructions — data the processor fetches

**5. (Sub lesson 1) True or false: the answer to "What sits in each memory cell?" is: One instruction or one value, under its address**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What are the three steps of the processor's cycle?" is: The instruction in hand and the values in play**
**Answer: False** — Fetch, decode, execute

**7. (Sub lesson 2) True or false: the answer to "What does the control unit do?" is: Directs the work and the movement of data**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does the ALU do?" is: The program and the data it works on**
**Answer: False** — Sums and comparisons — the arithmetic and logic

**9. (Sub lesson 2) True or false: the answer to "What do registers hold?" is: The instruction in hand and the values in play**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is the von Neumann bottleneck?" is: One machine can load and run many different programs**
**Answer: False** — The single shared path between processor and memory
