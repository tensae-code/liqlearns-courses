# Kinds of Machine Instructions — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Movers and workers — transfer, arithmetic, logic
Sub lesson 1 questions from the type files. Pass mark: They move values without changing them — load, store, move, push, pop; Load goes memory → register; store goes register → memory; Add, subtract, multiply, divide, increment, decrement; Bitwise — to every bit of a word at once; An instruction sliding a word's bits left or right.

## Sub lesson 2 — Choosers and speakers — control and input/output
Sub lesson 2 questions from the type files. Pass mark: The program counter — where the next instruction comes from; A jump taken only if a test on the last result holds — the machine's if; The return — where to come back to; The machine's ports, to its devices; Data transfer, arithmetic/logic, control, and input/output.
