# Kinds of Machine Instructions — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: They move values without changing them — load, store, move, push, pop**
**Answer: True**

**2. (Sub lesson 1) True or false: They move values without changing them — load, store, move, push, pop** — as the answer to: What is the difference between load and store?
**Answer: False — Load goes memory → register; store goes register → memory**

**3. (Sub lesson 1) True or false: Add, subtract, multiply, divide, increment, decrement**
**Answer: True**

**4. (Sub lesson 1) True or false: Add, subtract, multiply, divide, increment, decrement** — as the answer to: How do logic instructions apply their operations?
**Answer: False — Bitwise — to every bit of a word at once**

**5. (Sub lesson 1) True or false: An instruction sliding a word's bits left or right**
**Answer: True**

**6. (Sub lesson 2) True or false: An instruction sliding a word's bits left or right** — as the answer to: What do control instructions steer?
**Answer: False — The program counter — where the next instruction comes from**

**7. (Sub lesson 2) True or false: A jump taken only if a test on the last result holds — the machine's if**
**Answer: True**

**8. (Sub lesson 2) True or false: A jump taken only if a test on the last result holds — the machine's if** — as the answer to: What does a call remember that a jump does not?
**Answer: False — The return — where to come back to**

**9. (Sub lesson 2) True or false: The machine's ports, to its devices**
**Answer: True**

**10. (Sub lesson 2) True or false: The machine's ports, to its devices** — as the answer to: Name the four families.
**Answer: False — Data transfer, arithmetic/logic, control, and input/output**
