# Kinds of Machine Instructions — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What do data-transfer instructions do?** → **They move values without changing them — load, store, move, push, pop**

**2. (Sub lesson 1) What is the difference between load and store?** → **Load goes memory → register; store goes register → memory**

**3. (Sub lesson 1) Name the arithmetic family.** → **Add, subtract, multiply, divide, increment, decrement**

**4. (Sub lesson 1) How do logic instructions apply their operations?** → **Bitwise — to every bit of a word at once**

**5. (Sub lesson 1) What is a shift?** → **An instruction sliding a word's bits left or right**

**6. (Sub lesson 2) What do control instructions steer?** → **The program counter — where the next instruction comes from**

**7. (Sub lesson 2) What is a conditional branch?** → **A jump taken only if a test on the last result holds — the machine's if**

**8. (Sub lesson 2) What does a call remember that a jump does not?** → **The return — where to come back to**

**9. (Sub lesson 2) What do input/output instructions speak through?** → **The machine's ports, to its devices**

**10. (Sub lesson 2) Name the four families.** → **Data transfer, arithmetic/logic, control, and input/output**
