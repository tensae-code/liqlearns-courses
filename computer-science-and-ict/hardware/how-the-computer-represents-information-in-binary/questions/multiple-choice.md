# How the Computer Represents Information in Binary — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) In what form does the computer hold information?**
a) Binary form — patterns of 0s and 1s in memory  b) By character codes — each character matched to a number, stored in binary  c) No — they are held in their own binary codings  d) Data and the program
**Answer: a) Binary form — patterns of 0s and 1s in memory**

**2. (Sub lesson 1) How is text stored?**
a) No — they are held in their own binary codings  b) By character codes — each character matched to a number, stored in binary  c) Data and the program  d) In the same memory, in the same form
**Answer: b) By character codes — each character matched to a number, stored in binary**

**3. (Sub lesson 1) Do pictures and sounds escape the binary rule?**
a) Data and the program  b) In the same memory, in the same form  c) No — they are held in their own binary codings  d) Input, processor, memory and output
**Answer: c) No — they are held in their own binary codings**

**4. (Sub lesson 1) What two kinds of binary does memory hold?**
