# Six basic network problems — cable to overload — matching

Match each item on the left with the right partner on the right.

**1. (Sub lesson 1)** Match:
1. Cable problem — a) damaged connecting cable
2. Connectivity problem — b) port physically down
3. Out-of-reach issue — c) host too far from access point
4. Configuration issue — d) wrong routing setting
5. Software issue — e) version mismatch
6. Traffic overload — f) link beyond capacity

**Answer key:** 1-a; 2-b; 3-c; 4-d; 5-e; 6-f
