# Six basic network problems — cable to overload — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A physically damaged connecting cable is —
a) a cable problem  b) traffic overload  c) a software issue  d) out of reach
**Answer: a) a cable problem**

**2. (Sub lesson 1)** Source cannot reach destination because the port is down —
a) configuration issue  b) connectivity problem  c) cable problem only  d) version mismatch
**Answer: b) connectivity problem**

**3. (Sub lesson 1)** A wireless host too far from the access point is —
a) an out-of-reach issue  b) a routing problem  c) traffic overload  d) a cable problem
**Answer: a) an out-of-reach issue**

**4. (Sub lesson 2)** A wrong routing setting is —
a) a software issue  b) a configuration issue  c) out of reach  d) a cable problem
**Answer: b) a configuration issue**

**5. (Sub lesson 2)** Version mismatch interrupting IP packet transmission is —
a) a software issue  b) traffic overload  c) a connectivity problem  d) a cable problem
**Answer: a) a software issue**

**6. (Sub lesson 2)** A link carrying more than its capacity is —
a) out of reach  b) traffic overload  c) a configuration issue  d) a dead port
**Answer: b) traffic overload**
