# Six basic network problems — cable to overload — true or false

Say whether each statement is true or false.

**1. (Sub lesson 2)** Traffic overload makes a link or device behave abnormally.
**Answer: True**

**2. (Sub lesson 1)** An obstructing object between host and access point can cause an out-of-reach issue.
**Answer: True**

**3. (Sub lesson 2)** All six problems are physical damage.
**Answer: False**
