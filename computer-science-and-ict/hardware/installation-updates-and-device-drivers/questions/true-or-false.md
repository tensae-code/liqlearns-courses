# Installation, updates and device drivers — true or false

Say whether each statement is true or false.

**1. (Sub lesson 2)** Steps for the same activity can differ between two versions of one operating system.
**Answer: True**

**2. (Sub lesson 3)** Any driver will do, as long as some driver is installed.
**Answer: False**

**3. (Sub lesson 1)** Preventive maintenance is done after a failure, to repair it.
**Answer: False**
