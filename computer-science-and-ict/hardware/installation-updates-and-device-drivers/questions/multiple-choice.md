# Installation, updates and device drivers — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Software preventive maintenance mainly means —
a) deleting old programs  b) upgrading and installing software updates  c) buying a faster computer  d) switching the computer off
**Answer: b) upgrading and installing software updates** — updates keep security and reliability up.

**2. (Sub lesson 1)** Preventive maintenance saves —
a) only electricity  b) time and money, and reduces failures  c) disk space only  d) nothing measurable
**Answer: b) time and money, and reduces failures**

**3. (Sub lesson 2)** Installing a program includes —
a) only copying its files  b) configuring hardware or software and setting up drivers and plugins  c) only printing its manual  d) only restarting the computer
**Answer: b) configuring hardware or software and setting up drivers and plugins**

**4. (Sub lesson 2)** The unit's hands-on work is prepared for Windows because —
a) no other system exists  b) of its user base and graphical ease  c) other systems need no installation  d) Windows never changes
**Answer: b) of its user base and graphical ease**

**5. (Sub lesson 3)** A device driver is —
a) a person who delivers computers  b) the special program that controls a specific hardware device  c) a cable for a printer  d) a kind of storage disk
**Answer: b) the special program that controls a specific hardware device**

**6. (Sub lesson 3)** A working printer prints nothing. The first suspect is —
a) the paper  b) its driver — missing or wrong  c) the screen  d) the keyboard
**Answer: b) its driver — missing or wrong** — the right drivers are essential for devices to work properly.
