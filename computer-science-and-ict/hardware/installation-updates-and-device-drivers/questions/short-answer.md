# Installation, updates and device drivers — short answer

Answer in a sentence or two.

**1. (Sub lesson 1)** Why should a school install software updates regularly instead of waiting?
**Answer: Updates keep the system secure and reliable; regular preventive maintenance saves time and money and reduces failures.**

**2. (Sub lesson 3)** A new mouse is attached and the computer ignores it. Explain the likely cause in driver terms.
**Answer: The mouse's device driver — the program that controls that specific device — is missing or wrong, so the device cannot work properly even though the hardware is fine.**
