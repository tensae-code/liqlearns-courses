# Installation, updates and device drivers

## Do it first

A new printer is plugged into a computer and nothing prints. The printer works. The computer works. Something in between is missing. Write what you think it is — then work the lesson.

## Sub lesson 1 — Preventive maintenance — updates that prevent failure

**Software preventive maintenance** means **upgrading and installing software updates** for **security and reliability**. Done regularly, it **saves time and money and reduces failures** — most fixing work later in this unit is work that good maintenance would have prevented.

> **Teacher evidence:** the guide defines preventive maintenance as **regular and systematic inspection, cleaning and replacement of worn parts, materials and systems**, which **prevents failure by keeping them in good working order** (teacher guide — evidence, printed pp. 111–112).

## Sub lesson 2 — Installing — making a program ready to run

**Installing** is **making a program ready to run**. It can include **configuring hardware or software** and **setting up device drivers and plugins** — installation is wider than copying files.

This unit's hands-on work is prepared for **Windows**, because of its wide user base and graphical ease. Other operating systems do the same activities **by their own instructions**, and steps can differ **even between versions of one system**.

## Sub lesson 3 — Device drivers — the program that controls a device

A **device driver** is the **special program that controls a specific hardware device** attached to the computer. The **right drivers are essential** for devices to work properly: no driver, or the wrong driver, and a working device stays silent — like the printer in Do it first.
