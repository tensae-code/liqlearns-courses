# Single-Board Controllers — Microcontrollers — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A microcontroller mounted on a printed circuit board, exposing its pins**
**Answer: True**

**2. (Sub lesson 1) True or false: A microcontroller mounted on a printed circuit board, exposing its pins** — as the answer to: What does the microcontroller chip hold?
**Answer: False — Processor, memory and input/output on one chip**

**3. (Sub lesson 1) True or false: One — written for the device it lives in**
**Answer: True**

**4. (Sub lesson 1) True or false: One — written for the device it lives in** — as the answer to: When does its program run?
**Answer: False — From the moment power arrives**

**5. (Sub lesson 1) True or false: The computer runs many programs under an operating system; the controller is one program in a board**
**Answer: True**

**6. (Sub lesson 2) True or false: The computer runs many programs under an operating system; the controller is one program in a board** — as the answer to: What is the controller's life-loop?
**Answer: False — Read inputs, decide by its program, drive outputs — forever**

**7. (Sub lesson 2) True or false: Power parts, a clock, connection pins and often a USB door for loading the program**
**Answer: True**

**8. (Sub lesson 2) True or false: Power parts, a clock, connection pins and often a USB door for loading the program** — as the answer to: Name two devices a controller lives in.
**Answer: False — A washing machine and a smart trash bin (also: toys)**

**9. (Sub lesson 2) True or false: Arduino**
**Answer: True**

**10. (Sub lesson 2) True or false: Arduino** — as the answer to: Where does Indonesia teach this?
**Answer: False — Grade 12, Bab 2 B — single-board controllers**
