# Frequently Used Sequential Circuits — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Registers — a word held in flip-flops
Sub lesson 1 questions from the type files. Pass mark: A row of flip-flops holding one word — loaded and read together; 8, 16, 32 or 64 bits; It moves its bits one place along the row; Multiplication by 2 (left) — the shift of the arithmetic lessons; Between parallel words and serial streams — for transmission.

## Sub lesson 2 — Counters — flip-flops that count
Sub lesson 2 questions from the type files. Pass mark: It counts pulses in binary — its state advances by one at each pulse; One binary place of the count; It divides it — each stage pulses at half the previous rate; Timing events and sequencing operations (also: frequency division); Gates → functions → combinational circuits → memory → registers and counters → the computer's architecture.
