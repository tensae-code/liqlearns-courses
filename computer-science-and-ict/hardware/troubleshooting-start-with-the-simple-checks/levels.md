# Troubleshooting — start with the simple checks — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub Lessons"). Practice is tied to the learner's skill number, as before. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — What troubleshooting is
Sub lesson 1 questions from the type files. Pass mark: the learner can state and use what this part teaches — A systematic approach: review, diagnose and identify the problem, moving from general to specific. Hardware troubleshooting works on devices; software troubleshooting works on errors and bugs in software.

## Sub lesson 2 — The first simple checks
Sub lesson 2 questions from the type files. Pass mark: the learner can state and use what this part teaches — Plugged into a working outlet; everything switched on; for a blank screen, the monitor's power and its connection to the system unit; keyboard, mouse, monitor and speakers properly plugged in.

## Sub lesson 3 — Port or device? Swap to find out
Sub lesson 3 questions from the type files. Pass mark: the learner can state and use what this part teaches — Try a different port, or swap the device for one that works, to separate a port fault from a device fault. Safety: switch the computer off before removing or replacing parts.
