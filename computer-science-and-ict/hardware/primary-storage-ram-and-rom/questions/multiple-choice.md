# Primary storage — RAM and ROM — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Primary storage is —
a) Storage outside the machine  b) The computer's main memory, holding program instructions and data  c) The printer tray  d) The backup copy
**Answer: b) The computer's main memory, holding program instructions and data** — Primary storage is the computer's main memory.

**2. (Sub lesson 1)** The three types of primary storage are —
a) RAM, ROM and CMOS  b) CD, DVD and tape  c) CRT, LCD and LED  d) Input, output and storage
**Answer: a) RAM, ROM and CMOS** — Primary storage has three types: RAM, ROM and CMOS.

**3. (Sub lesson 1)** RAM holds —
a) The startup program only  b) The programs and data the CPU needs while a program runs  c) Nothing  d) Printed pages
**Answer: b) The programs and data the CPU needs while a program runs** — RAM is the read-write main memory holding what the CPU needs while a program runs.

**4. (Sub lesson 1)** RAM is volatile, which means —
a) It explodes  b) Its contents are lost when power goes off  c) It is very fast only  d) It cannot be read
**Answer: b) Its contents are lost when power goes off** — Volatile: contents are lost when power goes off.

**5. (Sub lesson 2)** ROM's program is —
a) Written by the user each morning  b) Built in at the factory; the user cannot change or erase it, only read it  c) Downloaded daily  d) Typed on the keyboard
**Answer: b) Built in at the factory; the user cannot change or erase it, only read it** — ROM holds a factory-built-in program the user cannot change or erase.

**6. (Sub lesson 2)** ROM holds the instructions used —
a) For printing photos  b) When the computer is switched on — starting up and displaying information  c) For games only  d) For deleting files
**Answer: b) When the computer is switched on — starting up and displaying information** — ROM holds the startup instructions used when the computer is switched on.

**7. (Sub lesson 2)** At power-off, which memory keeps its contents?
a) RAM  b) ROM  c) Neither  d) Both
**Answer: b) ROM** — ROM is non-volatile; RAM's contents are lost.
