# Primary storage — RAM and ROM — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** RAM is the read-write main memory.
**Answer: True**

**2. (Sub lesson 2)** A user can erase and rewrite ROM like a document.
**Answer: False**

**3. (Sub lesson 1)** Storage devices are of two types: primary and secondary.
**Answer: True**
