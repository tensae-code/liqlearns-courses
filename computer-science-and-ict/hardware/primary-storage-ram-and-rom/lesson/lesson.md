# Primary storage — RAM and ROM

## Do it first

Two notebooks sit on a desk. One is wiped clean every night. The other was printed once at the factory and can never be changed — it tells the desk's owner how to start every morning. Before reading on, guess which memory in a computer is wiped, and which is printed forever.

## Sub lesson 1 — Primary storage — the main memory

Storage devices hold files, and they are of two types: primary and secondary. Primary storage is the computer's main memory: it holds program instructions and data. It has three types — RAM, ROM and CMOS. CMOS gets its own place in the next lesson; this lesson is RAM and ROM.

## Sub lesson 2 — RAM — working memory that vanishes

RAM stores data temporarily. It is the read-write main memory, holding the programs and data the CPU needs while a program runs. RAM is volatile: its contents are lost when the power goes off. Watch the GIF: the desk is full while the power is on — switch off, and the desk is empty, while the factory plate beside it never changes.

[GIF 10946 — RAM vanishing at power-off]

## Sub lesson 3 — ROM — the factory program that stays

ROM stores information permanently. A program is built into it at the factory, which the user cannot change or erase — only read. ROM holds the instructions used when the computer is switched on, such as starting up and displaying information on screen. ROM is non-volatile: switch the power off and its contents stay.
