**Primary storage.**

First, brainstorm: what do you already know about this? Say it out loud.

Now the one thing: primary storage is the computer's main memory, of three types — RAM, ROM and CMOS: RAM holds what the CPU needs while a program runs and vanishes at power-off; ROM holds the factory startup program forever.

**Primary storage — the main memory.** Storage devices hold files, and they are of two types: primary and secondary.
**RAM — working memory that vanishes.** RAM stores data temporarily.
**ROM — the factory program that stays.** ROM stores information permanently.

Now you: Draw RAM as a desk cleared when the power goes off, ROM as a factory-printed plate that never changes.
