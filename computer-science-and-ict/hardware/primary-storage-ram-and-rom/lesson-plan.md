# Lesson plan — Primary storage — RAM and ROM

**Course:** Computer Science and ICT · **Title:** Hardware · **Lesson:** Primary storage — RAM and ROM
**Place in the curriculum:** Title 2 — Hardware of the Computer Science and ICT ladder (TITLES.md); Ethiopia Grade 8, Unit 2 — Computer Hardware.
**The one thing this lesson teaches:** primary storage is the computer's main memory, of three types — RAM, ROM and CMOS: RAM holds what the CPU needs while a program runs and vanishes at power-off; ROM holds the factory startup program forever.
**This lesson's own level:** it stands on the storage function and the CPU lessons: registers hold for a moment; main memory holds for the work session — or for the machine's whole life.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. ## If the learner is stuck
- Mixes volatile and non-volatile → RAM is volatile (lost at power-off); ROM is non-volatile (stays).
- Thinks ROM can be edited like a file → ROM's program is built in at the factory; the user cannot change or erase it, only read it.
