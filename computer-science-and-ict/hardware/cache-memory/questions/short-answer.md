# Cache Memory — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is cache memory?**
**Answer: A very small, very fast memory between the processor and main memory**

**2. (Sub lesson 1) Where does cache sit?**
**Answer: Inside or immediately beside the CPU**

**3. (Sub lesson 1) What does cache hold?**
**Answer: Copies of the data and instructions used most, or needed again soon**

**4. (Sub lesson 1) Why is cache small?**
**Answer: It is made of fast, expensive memory — only a little can be afforded**

**5. (Sub lesson 2) Where does the processor look first?**
**Answer: In the cache**

**6. (Sub lesson 2) What is a hit?**
**Answer: The needed data is found in the cache and delivered at cache speed**

**7. (Sub lesson 2) What happens on a miss?**
**Answer: Data is fetched from RAM and a copy is left in the cache**

**8. (Sub lesson 2) Why does the trick work?**
**Answer: Programs return again and again to the same instructions and nearby data**

**9. (Sub lesson 2) What job does cache do, in one phrase?**
**Answer: It stands closest, so the processor almost never waits**

**10. (Sub lesson 1) Which chapter teaches this?**
**Answer: Laos Grade 8 ICT, Chapter 1 §1.2.5**
