# Cache Memory — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A very small, very fast memory between the processor and main memory**
**Answer: True**

**2. (Sub lesson 1) True or false: Copies of the data and instructions used most, or needed again soon** — as the answer to: Where does cache sit?
**Answer: False — Inside or immediately beside the CPU**

**3. (Sub lesson 1) True or false: Copies of the data and instructions used most, or needed again soon**
**Answer: True**

**4. (Sub lesson 1) True or false: In the cache** — as the answer to: Why is cache small?
**Answer: False — It is made of fast, expensive memory — only a little can be afforded**

**5. (Sub lesson 2) True or false: In the cache**
**Answer: True**

**6. (Sub lesson 2) True or false: Data is fetched from RAM and a copy is left in the cache** — as the answer to: What is a hit?
**Answer: False — The needed data is found in the cache and delivered at cache speed**

**7. (Sub lesson 2) True or false: Data is fetched from RAM and a copy is left in the cache**
**Answer: True**

**8. (Sub lesson 2) True or false: It stands closest, so the processor almost never waits** — as the answer to: Why does the trick work?
**Answer: False — Programs return again and again to the same instructions and nearby data**

**9. (Sub lesson 2) True or false: It stands closest, so the processor almost never waits**
**Answer: True**

**10. (Sub lesson 1) True or false: A very small, very fast memory between the processor and main memory** — as the answer to: Which chapter teaches this?
**Answer: False — Laos Grade 8 ICT, Chapter 1 §1.2.5**
