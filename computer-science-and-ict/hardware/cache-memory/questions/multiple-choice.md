# Cache Memory — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is cache memory?**
a) A very small, very fast memory between the processor and main memory  b) Inside or immediately beside the CPU  c) Copies of the data and instructions used most, or needed again soon  d) It is made of fast, expensive memory — only a little can be afforded
**Answer: a**

**2. (Sub lesson 1) Where does cache sit?**
a) Copies of the data and instructions used most, or needed again soon  b) Inside or immediately beside the CPU  c) It is made of fast, expensive memory — only a little can be afforded  d) In the cache
**Answer: b**

**3. (Sub lesson 1) What does cache hold?**
a) It is made of fast, expensive memory — only a little can be afforded  b) In the cache  c) Copies of the data and instructions used most, or needed again soon  d) The needed data is found in the cache and delivered at cache speed
**Answer: c**

**4. (Sub lesson 1) Why is cache small?**
a) In the cache  b) The needed data is found in the cache and delivered at cache speed  c) Data is fetched from RAM and a copy is left in the cache  d) It is made of fast, expensive memory — only a little can be afforded
**Answer: d**

**Answer: a**
