# The Motherboard — the Main Circuit Board — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is the motherboard?" is: The computer's main circuit board — the large board every other component connects to**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What are the motherboard's other names?" is: Inside the system unit, filling the floor of the box**
**Answer: False** — The system board, or main board

**3. (Sub lesson 1) True or false: the answer to "Where is the motherboard found?" is: Inside the system unit, filling the floor of the box**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does the motherboard make of the separate parts?" is: The parts are a box of unrelated electronics**
**Answer: False** — One computer — it joins them into a single working system

**5. (Sub lesson 1) True or false: the answer to "What happens without it?" is: The parts are a box of unrelated electronics**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What holds the CPU on the board?" is: Memory modules and expansion cards**
**Answer: False** — The CPU socket

**7. (Sub lesson 2) True or false: the answer to "What do slots hold?" is: Memory modules and expansion cards**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What do the board's buses carry?" is: Its socket, slots and connectors decide what fits this machine**
**Answer: False** — Data, instructions and power between everything plugged in

**9. (Sub lesson 2) True or false: the answer to "Why does a technician ask about the board before fitting a part?" is: Its socket, slots and connectors decide what fits this machine**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What decides what a computer can become?" is: The computer's main circuit board — the large board every other component connects to**
**Answer: False** — The motherboard — its socket, slots and connectors
