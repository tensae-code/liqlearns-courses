# Defragmenting — putting a file's pieces back together

## Do it first

Imagine a book whose pages have been torn out and shelved in twelve different rooms. Reading it would take all day. A hard disk can end up the same way. Write what you think 'defragmenting' does about it — then take the book's steps.

## Sub lesson 1 — Fragmentation — what it is and why it slows the machine

As files are **deleted and updated**, a file's pieces get **scattered into non-adjacent spaces** on the disk. That scattering is **fragmentation** — and **reading scattered files takes the system longer**, so the machine slows.

[Picture 17715 — a disk shown scattered, then gathered into one continuous band]

> **Teacher evidence, in plain consequence terms:** fragmentation is file pieces **scattered in non-adjacent disk areas, so the system takes longer to read them and the machine slows** (teacher guide, printed pp. 95–98) — the guide and the student book define it the same way.

## Sub lesson 2 — Defragmenting — the book's steps (doing)

A **defragmenter ('defragger')** finds the scattered pieces and **reorganises them into the fewest possible adjoining regions**, speeding the computer up.

[GIF 17716 — scattered file pieces gathering back into one continuous block (defragmentation)]

The book's steps, in order:

1. **Search Windows Administrative Tools** and open it.
2. **Double-click Defragment and Optimize Drives.**
3. **Select the drive.**
4. Click **Optimize**.

One number first: a drive reporting **0% fragmented needs no defragmentation** — check before you run.
