# Defragmenting — putting a file's pieces back together — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Defragmenting speeds the computer up.
**Answer: True** — adjoining pieces read faster.

**2. (Sub lesson 2)** Defragmenting deletes the files it moves.
**Answer: False** — it reorganises the same files' pieces.

**3. (Sub lesson 2)** You select the drive before clicking Optimize.
**Answer: True** — step three, then step four.
