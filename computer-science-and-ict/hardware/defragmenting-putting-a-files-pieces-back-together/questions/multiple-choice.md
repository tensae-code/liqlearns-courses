# Defragmenting — putting a file's pieces back together — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Fragmentation is —
a) a virus kind  b) a file's pieces scattered into non-adjacent spaces on the disk  c) a full disk  d) a broken disk
**Answer: b) a file's pieces scattered into non-adjacent spaces on the disk** — scattered pieces — the definition.

**2. (Sub lesson 1)** Fragmentation grows as files are —
a) backed up  b) deleted and updated  c) printed  d) scanned
**Answer: b) deleted and updated** — deleting and updating scatter the pieces.

**3. (Sub lesson 1)** Reading scattered files —
a) is faster  b) takes the system longer  c) uses no disk  d) damages RAM
**Answer: b) takes the system longer** — longer — so the machine slows.

**4. (Sub lesson 2)** A defragmenter —
a) deletes old files  b) reorganises scattered pieces into the fewest possible adjoining regions  c) formats the drive  d) installs drivers
**Answer: b) reorganises scattered pieces into the fewest possible adjoining regions** — gathering into adjoining regions.

**5. (Sub lesson 2)** The steps begin —
a) click Optimize  b) search Windows Administrative Tools and open it  c) select the drive  d) open Device Manager
**Answer: b) search Windows Administrative Tools and open it** — Administrative Tools first.

**6. (Sub lesson 2)** Inside Administrative Tools, you double-click —
a) Event Viewer  b) Defragment and Optimize Drives  c) Device Manager  d) Backup and Restore
**Answer: b) Defragment and Optimize Drives** — the defrag tool's full name.

**7. (Sub lesson 2)** A drive at 0% fragmented —
a) needs urgent defragmentation  b) needs no defragmentation  c) is broken  d) must be formatted
**Answer: b) needs no defragmentation** — the book's note: no work needed.

**8. (Sub lesson 3)** In the Grade 12 depth, a fragmented disk's files are —
a) deleted  b) broken and stored in unmanaged space  c) compressed  d) renamed
**Answer: b) broken and stored in unmanaged space** — so the computer is slow to bring the fragments together to open them (Grade 12 Student Textbook, printed pp. 146–147).

**9. (Sub lesson 3)** Disk Defragmenter rearranges files so each file is —
a) copied twice  b) stored in one sequence  c) hidden  d) printed
**Answer: b) stored in one sequence** — reducing fragmentation and speeding data retrieval.

**10. (Sub lesson 3)** The Grade 12 route to Disk Defragmenter is —
a) typing "Disk Defragment" in the Windows search box  b) right-clicking the desktop  c) opening Device Manager  d) the Recycle Bin
**Answer: a) typing "Disk Defragment" in the Windows search box.**
