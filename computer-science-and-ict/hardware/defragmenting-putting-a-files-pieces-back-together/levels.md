# Defragmenting — putting a file's pieces back together — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub Lessons"). Practice is tied to the learner's skill number, as before. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Fragmentation — what it is and why it slows the machine
Sub lesson 1 questions from the type files. Pass mark: the learner can state and use what this part teaches — As files are deleted and updated, a file's pieces get scattered into non-adjacent spaces; reading scattered files takes the system longer. (The guide's plain-consequence definition — teacher evidence — says the same.)

## Sub lesson 2 — Defragmenting — the book's steps (doing)
Sub lesson 2 questions from the type files. Pass mark: the learner can state and use what this part teaches — Search Windows Administrative Tools and open it; double-click Defragment and Optimize Drives; select the drive; click Optimize. A drive at 0% fragmented needs no defragmentation.

## Sub lesson 3 — The Grade 12 depth — fragmentation in unmanaged space, and the search-box route
Sub lesson 3 questions from the type files. Pass mark: the learner can state and use what this part teaches — In Grade 12 depth: files broken and stored in unmanaged space slow the opening of files; Disk Defragmenter stores each file in one sequence, speeding retrieval; access by typing "Disk Defragment" in the Windows search box (Grade 12 Student Textbook, Unit 5, printed pp. 146–147).
