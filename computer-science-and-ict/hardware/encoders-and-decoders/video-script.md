# Video script — Encoders and Decoders

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Ten keys, one pressed. The machine wants that as a code. That job is the encoder's.

Press 7: the outputs say 0111. Press 9: they say 1001. It is the BCD code of the key.

Inside, it is just OR gates reading the code table column by column.

The decoder runs it backwards. A code goes in; one line out of many wakes up.

Two inputs, four outputs. Code 10 wakes output 2 — and only output 2.

n bits name 2-to-the-n lines. That one rule sizes both circuits.
