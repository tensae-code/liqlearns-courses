# Encoders and Decoders — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 1) The circuit that turns one active line out of many into a binary code is called an ____.**
**Answer: encoder** — It encodes 'which one' as a number.

**2. (Sub lesson 1) In the decimal-to-BCD encoder, the 8-weight output is the OR of input lines 8 and ____.**
**Answer: 9** — Only digits 8 and 9 have the BCD 8-bit set.

**3. (Sub lesson 2) A decoder with 4 inputs can select up to ____ output lines.**
**Answer: 16** — 2⁴ = 16 patterns, so up to 16 outputs.

**4. (Sub lesson 2) In a 2-to-4 decoder, the output that is active for input 01 is output ____.**
**Answer: 1** — The active output's number equals the input code's value: 01₂ = 1.
