# Installing software on a PC — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Software should be taken only from —
a) any website that offers it free  b) reliable, trusted sources  c) a stranger's flash disk, un scanned  d) the oldest disc you can find
**Answer: b) reliable, trusted sources** — trusted sources protect the machine from malicious software.

**2. (Sub lesson 2)** Step 1 of installing from media is —
a) restart Windows  b) agree to the licence  c) insert the disc into the optical drive or the USB into its port  d) close the installer
**Answer: c) insert the disc into the optical drive or the USB into its port**

**3. (Sub lesson 2)** AutoPlay does not appear. The fallback is —
a) give up  b) open the Computer window, right-click the drive icon, choose Install/Run Program from your media  c) restart and hope  d) delete the disc's files
**Answer: b) open the Computer window, right-click the drive icon, choose Install/Run Program from your media**

**4. (Sub lesson 2)** A User Account Control warning appears. You answer with —
a) the serial number  b) the administrator password, or Yes/Continue  c) a disc swap  d) nothing — you close it
**Answer: b) the administrator password, or Yes/Continue**

**5. (Sub lesson 3)** Step 4 is —
a) close the installer window  b) restart Windows  c) wait for the program to report success or failure  d) start using the program
**Answer: c) wait for the program to report success or failure**

**6. (Sub lesson 3)** The last step, step 7, is —
a) insert the disc  b) start using the program  c) agree to the licence  d) scan the disk
**Answer: b) start using the program**
