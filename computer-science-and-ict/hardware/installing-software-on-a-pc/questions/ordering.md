# Installing software on a PC — ordering

Put the steps in the right order.

**1. (Sub lesson 2)** These steps are mixed up. Write them in the right order:

- Close the installer window
- Insert the disc or USB
- Start using the program
- Run the installation program
- Wait for success or failure
- Follow the on-screen instructions
- Restart Windows if prompted

**Answer (right order):** Insert the disc or USB → Run the installation program → Follow the on-screen instructions → Wait for success or failure → Close the installer window → Restart Windows if prompted → Start using the program
