# Installing software on a PC — true or false

Say whether each statement is true or false.

**1. (Sub lesson 2)** A serial number can come from the box, the manual, paper, or the shipment email.
**Answer: True**

**2. (Sub lesson 3)** If the installer is slow, closing it early is step 4.
**Answer: False**

**3. (Sub lesson 1)** Before installing you should check disk space and the operating-system type. (teacher guide — evidence)
**Answer: True**
**4. (Sub lesson 1)** Before installing, flash disks, CDs and hard disks should be scanned before their files or software are opened. (teacher guide — evidence)
**Answer: True** — the guide's pre-install checklist (printed pp. 99–100).
