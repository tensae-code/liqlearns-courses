# Hands-on — Installing software on a PC

The lesson with your hands, not only your eyes.

## Paper install
On paper, draw the seven steps as seven boxes. Under step 2 draw the AutoPlay dialog; under the same box, in smaller writing, the fallback route. Swap with a partner and check each other's order.

## Source check
A friend offers a program from an unknown website on a flash disk. Write the checks you run before installing — source, requirements, space, and the scan — using the checklist in sub lesson 1.
