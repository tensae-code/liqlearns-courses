# Lesson plan — Installing software on a PC

**Course:** Computer Science and ICT · **Title:** Hardware · **Lesson:** Installing software on a PC
**Place in the curriculum:** Unit 5 — Maintenance and Troubleshooting (CURRICULUM.md).
**The one thing this lesson teaches:** Installing software on a PC follows seven steps in a fixed order — from a trusted source, through the installer, to a restarted, working program.
**This lesson's own level:** It stands on Installation, updates and device drivers: the learner knows what installing means and why sources matter.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
1. **Trusted sources first** — where software comes from — stores, download, shipped media — and trusted sources only; the guide's pre-install requirements checklist (teacher evidence).
2. **Steps 1–3 — start the installer and answer it** — insert media; run the installer (AutoPlay route and the Computer-window fallback); answer UAC, licence, serial number, disc swaps and install place.
3. **Steps 4–7 — finish, restart, use** — wait for success or failure; close the installer; restart if prompted; start using the program.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Installation, updates and device drivers, in this same title. Recommended, never forced — a learner may land on this lesson directly, and it stands alone.

## What the learner can do when it ends
1. Name the safe sources of software and say why trusted sources matter.
2. Carry out the seven install steps in the book's order.
3. Use the fallback route when AutoPlay does not appear.
4. Answer the installer's prompts: UAC, licence, serial number, disc swap, install place.

## What you need
A Windows school computer and an install disc or USB if available — paper works too, screen by screen. Paper and a pencil.

## If the learner is stuck
- AutoPlay never appears → do not stop: Computer window, right-click the drive icon, Install/Run Program from your media.
- Tempted to close the installer early → step 4 is a real step: wait for success or failure first.
