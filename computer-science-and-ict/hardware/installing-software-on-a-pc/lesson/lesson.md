# Installing software on a PC

## Do it first

You are handed a program on a disc and told: install it. Write the steps you would take, in order, before you read on. Keep your list — you will correct it against the seven steps.

## Sub lesson 1 — Trusted sources first

Get software the safe way: **buy it from software stores or galleries**, **download it**, or **have it shipped** to you, on **CD, DVD or USB**. Take software **only from reliable, trusted sources** — that is what protects the machine from **malicious software**.

> **Teacher evidence — check before you install (teacher guide — evidence, printed pp. 99–100):** study the software's **detailed requirements** first; check the **operating-system type** (Windows, Unix/Linux, Mac); confirm an **appropriate place with enough disk space**; consider **CPU processing power and graphics capability** where the software needs them; **choose the source carefully**, especially online; and **scan flash disks, CDs and hard disks before opening** files or software from them. The principle behind it: the **number and type of applications installed directly affect a computer's speed, efficiency and security**, so install only what is required. Where there is no school laboratory, the teacher demonstrates install and uninstall on their own laptop or desktop while pupils record the steps.

> **Teacher evidence — getting software safely (teacher guide — evidence):** take software from **trusted sources and software hubs**, buy it from **software companies and online stores**, or take it from **friends and school intranet repositories**. Before downloading from the internet: **check the website address**; keep **active virus and malware scanners** running; if the site is not trusted, **look elsewhere**; **check the download link is really the one wanted**; and **avoid download programs and installers** that wrap the file you want in other software.

## Sub lesson 2 — Steps 1–3 — start the installer and answer it

The seven steps, in order — the first three:

1. **Insert the disc** into the optical drive, or the **USB drive into its port**.
2. **Run the installation program** — it usually **starts by itself**, or through the **AutoPlay dialog's Install/Setup choice**. If it does not start: open the **Computer window**, **right-click the drive icon** and choose **Install/Run Program from your media**, or **AutoPlay**.
3. **Follow the on-screen instructions carefully** — answer any **User Account Control** warning with the **administrator password or Yes/Continue**; **agree to the software licence**; supply a **serial number** if asked (from the **box, manual, paper or shipment email**); **swap discs** if asked; and **choose where the files install**.

## Sub lesson 3 — Steps 4–7 — finish, restart, use

4. **Wait** for the program to report **success or failure**.
5. **Close the installer window**.
6. **Restart Windows if prompted**.
7. **Start using the program**.

Do not skip the wait in step 4: a half-finished install closed early is a broken program.

## Say it to your companion

Walk your companion through all seven steps in order, including what you do if AutoPlay never appears. They stop you if you change the order.
