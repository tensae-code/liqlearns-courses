# Installing Main Memory

## Do it first

Memory installs in a minute and fails in a second: a module half-seated is a machine that will not start. Laos's Grade 8 chapter gives main memory its own bench procedure. This lesson presses it home.

## Sub lesson 1 — Matching module to slot

The install begins with **matching**: the module's type must fit the board's **memory slots**, and its **notch** — the gap cut in the module's contact edge — sits off-centre, so a module can only seat **one way round**, in a slot made for its kind. The slot's **end clips are opened outward** first. The module is held **by its edges**, contacts down, notch over the slot's key, standing straight above the slot before any pressure is used.

## Sub lesson 2 — Pressing home to the clips

Seating is one even act: **both thumbs press the module straight down**, firmly and evenly at both ends, until the **end clips snap up into the module's side notches** by themselves. The clips closing are the install's receipt — a module whose clips have not closed is not installed, however straight it looks. Laos's order closes the practical: check each module's clips, and remember that an unseated module announces itself at switch-on as a dead machine or beep codes, sending the installer back to this lesson's clips.
