# Installing Main Memory — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Matching module to slot
Sub lesson 1 questions from the type files. Pass mark: The module's type to the board's memory slots; The off-centre notch in its contact edge, over the slot's key; Its end clips are opened outward; By its edges, contacts down, standing straight above the slot; Both thumbs press straight down, evenly at both ends.

## Sub lesson 2 — Pressing home to the clips
Sub lesson 2 questions from the type files. Pass mark: The end clips snapping up into the module's side notches by themselves; A dead machine or beep codes; Laos Grade 8 ICT, Chapter 2 §2.3; Even pressure seats the whole contact edge at once; No — the notch and key prevent it; force only damages.
