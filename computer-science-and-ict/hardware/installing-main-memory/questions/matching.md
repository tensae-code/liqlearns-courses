# Installing Main Memory — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What must be matched before installing memory?** → **The module's type to the board's memory slots**

**2. (Sub lesson 1) What makes a module fit only one way round?** → **The off-centre notch in its contact edge, over the slot's key**

**3. (Sub lesson 1) What is done to the slot first?** → **Its end clips are opened outward**

**4. (Sub lesson 1) How is the module held?** → **By its edges, contacts down, standing straight above the slot**

**5. (Sub lesson 1) How is it seated?** → **Both thumbs press straight down, evenly at both ends**

**6. (Sub lesson 2) What is the receipt of a seated module?** → **The end clips snapping up into the module's side notches by themselves**

**7. (Sub lesson 2) What announces an unseated module at switch-on?** → **A dead machine or beep codes**

**8. (Sub lesson 2) Which chapter teaches this?** → **Laos Grade 8 ICT, Chapter 2 §2.3**

**9. (Sub lesson 2) Why press at both ends, not one?** → **Even pressure seats the whole contact edge at once**

**10. (Sub lesson 2) Can a module be forced the wrong way round?** → **No — the notch and key prevent it; force only damages**
