# Installing Main Memory — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The module's type to the board's memory slots**
**Answer: True**

**2. (Sub lesson 1) True or false: Its end clips are opened outward** — as the answer to: What makes a module fit only one way round?
**Answer: False — The off-centre notch in its contact edge, over the slot's key**

**3. (Sub lesson 1) True or false: Its end clips are opened outward**
**Answer: True**

**4. (Sub lesson 1) True or false: Both thumbs press straight down, evenly at both ends** — as the answer to: How is the module held?
**Answer: False — By its edges, contacts down, standing straight above the slot**

**5. (Sub lesson 1) True or false: Both thumbs press straight down, evenly at both ends**
**Answer: True**

**6. (Sub lesson 2) True or false: A dead machine or beep codes** — as the answer to: What is the receipt of a seated module?
**Answer: False — The end clips snapping up into the module's side notches by themselves**

**7. (Sub lesson 2) True or false: A dead machine or beep codes**
**Answer: True**

**8. (Sub lesson 2) True or false: Even pressure seats the whole contact edge at once** — as the answer to: Which chapter teaches this?
**Answer: False — Laos Grade 8 ICT, Chapter 2 §2.3**

**9. (Sub lesson 2) True or false: Even pressure seats the whole contact edge at once**
**Answer: True**

**10. (Sub lesson 2) True or false: The module's type to the board's memory slots** — as the answer to: Can a module be forced the wrong way round?
**Answer: False — No — the notch and key prevent it; force only damages**
