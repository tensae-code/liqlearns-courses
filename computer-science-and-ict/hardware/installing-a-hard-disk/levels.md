# Installing a Hard Disk — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Mounting in the bay
Sub lesson 1 questions from the type files. Pass mark: In a drive bay of its size inside the case; Screwed firm on its sides; It spins thousands of turns a minute; a loose disk vibrates and fails early; A single fall can kill it and every file it holds; The power lead (from the power supply) and the data lead (to the board).

## Sub lesson 2 — Power and data — the two leads
Sub lesson 2 questions from the type files. Pass mark: Everything read from and written to the disk; Each in its own socket, one way, without force; The disk does not appear to the machine at system install; Laos Grade 8 ICT, Chapter 2 §2.6; A lead or the seat — not the program.
