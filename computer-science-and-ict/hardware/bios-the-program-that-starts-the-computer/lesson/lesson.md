## BIOS — the program that starts the computer

**BIOS** stands for **basic input/output system**. It is the program a computer uses to **start the system after it is powered on**.

BIOS also **manages the flow of data between the operating system and the attached devices**: the **hard disk, video adapter, keyboard, mouse and printer**.

## When the fault is a BIOS setting

If a machine **boots but stops after POST**, the fault is likely a **BIOS setting**. The book's ruling is firm: **take it to a computer hardware technician**. Fixing a BIOS setting needs good hardware knowledge — it is not a first fix to try yourself.

> **Teacher evidence:** the class demonstration deliberately provokes BIOS error messages so pupils can see them — while deliberately **not** teaching how BIOS settings are changed, because pupils copying it would create new faults (teacher guide, printed p. 91). The settings stay locked away in this course too: see the error, name it, hand it to a technician.
