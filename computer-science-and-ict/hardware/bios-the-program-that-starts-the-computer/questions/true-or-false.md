# BIOS — the program that starts the computer — true or false

Say whether each sentence is true or false.

**1.** BIOS runs after the operating system has fully loaded.
**Answer: False** — BIOS starts the system at power-on, before the operating system.

**2.** Pupils are taught to change BIOS settings in this unit.
**Answer: False** — never — settings are left to a technician; even the class demonstration does not teach them.
