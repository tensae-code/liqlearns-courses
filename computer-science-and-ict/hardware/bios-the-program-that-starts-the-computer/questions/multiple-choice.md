# BIOS — the program that starts the computer — multiple choice

Pick the one right answer.

**1.** BIOS stands for —
a) basic input/output system  b) binary internal operating software  c) boot image operating system  d) basic internet output service
**Answer: a) basic input/output system** — basic input/output system.

**2.** BIOS's first job is —
a) printing documents  b) starting the system after power-on  c) scanning for viruses  d) connecting to the internet
**Answer: b) starting the system after power-on** — it starts the system.

**3.** BIOS manages data flow between the operating system and —
a) only the printer  b) hard disk, video adapter, keyboard, mouse and printer  c) the internet  d) other computers
**Answer: b) hard disk, video adapter, keyboard, mouse and printer** — the five named devices.

**4.** A machine boots but stops after POST. The likely fault is —
a) a virus  b) a BIOS setting  c) dust  d) a full disk
**Answer: b) a BIOS setting** — the book's reading of that symptom.

**5.** A BIOS-setting fault goes to —
a) the pupil, with a video  b) a computer hardware technician  c) the antivirus  d) nobody — restart fixes it
**Answer: b) a computer hardware technician** — it needs good hardware knowledge.
