# Antivirus — installing it and scanning regularly — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A virus is a program that —
a) cleans the disk  b) copies itself by modifying other programs and inserting its own code  c) speeds up the machine  d) backs up files
**Answer: b) copies itself by modifying other programs and inserting its own code** — the book's exact definition.

**2. (Sub lesson 1)** Infection arrives —
a) only by keyboard  b) over the internet or on someone else's flash disk  c) through the monitor  d) from dust
**Answer: b) over the internet or on someone else's flash disk** — the two named roads.

**3. (Sub lesson 1)** An infection usually shows itself —
a) at once, with a message  b) only once it causes a problem  c) never  d) at POST
**Answer: b) only once it causes a problem** — the quiet guest — late signs.

**4. (Sub lesson 2)** Antivirus software —
a) prevents, detects and removes malware  b) only detects  c) only removes  d) creates backups
**Answer: a) prevents, detects and removes malware** — all three jobs.

**5. (Sub lesson 2)** The book's free examples are —
a) Word, Excel, Paint, Notepad  b) AVAST, AVG, AVIRA and Bitdefender  c) Chrome and Firefox  d) Kaspersky only
**Answer: b) AVAST, AVG, AVIRA and Bitdefender** — the four named free guards.

**6. (Sub lesson 2)** The install route's second step is —
a) run the setup file  b) open the maker's result  c) scan the machine  d) restart
**Answer: b) open the maker's result** — search, then the maker's result.

**7. (Sub lesson 2)** The maintenance rule is —
a) scan once, at install  b) scan regularly  c) scan only when files vanish  d) never scan
**Answer: b) scan regularly** — regularly — the rule.

**8. (Sub lesson 2)** Regular scanning matters because some malware —
a) is too big  b) embeds silently and waits for a trigger  c) hides in the monitor  d) changes beep codes
**Answer: b) embeds silently and waits for a trigger** — the sleeping trigger-waiters.
