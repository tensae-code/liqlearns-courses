# Antivirus — installing it and scanning regularly — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** A virus inserts its own code into other programs.
**Answer: True** — that is its copying method.

**2. (Sub lesson 2)** Antivirus exists only in commercial (paid) form.
**Answer: False** — the book names free forms and four free examples.

**3. (Sub lesson 2)** Saving the setup file and running it is one of the book's two install ways.
**Answer: True** — install directly, or save and run.
