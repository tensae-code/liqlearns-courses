# Units of data storage — bit, byte, KB, MB, GB, TB — true or false

Say whether each statement is true or false.

**1. A byte is smaller than a bit.**
**Answer: False** — A byte is 8 bits — larger.

**2. Each step above the byte is 1,024 of the one below.**
**Answer: True**

**3. 1,024 GB make one terabyte.**
**Answer: True**

**4. A bit can be a 1 or a 0.**
**Answer: True** — A single binary digit.
