# Units of data storage — bit, byte, KB, MB, GB, TB — fill in the blank

Fill each blank with the missing word or words.

**1. 8 bits make one ____.**
**Answer: byte**

**2. 1,024 ____ make one megabyte.**
**Answer: KB / kilobytes**

**3. A single binary digit, 1 or 0, is a ____.**
**Answer: bit**
