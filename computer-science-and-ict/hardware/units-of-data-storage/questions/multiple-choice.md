# Units of data storage — bit, byte, KB, MB, GB, TB — multiple choice

Pick the one right answer.

**1. A bit is —**
a) 8 bytes  b) a single binary digit, 1 or 0  c) 1,024 bytes
**Answer: b) a single binary digit, 1 or 0**

**2. One byte is —**
a) 1,024 bits  b) 8 bits  c) 100 bits
**Answer: b) 8 bits**

**3. One kilobyte is —**
a) 1,000 bytes  b) 1,024 bytes  c) 8 bytes
**Answer: b) 1,024 bytes** — Every step from the byte up is 1,024.

**4. One gigabyte is —**
a) 1,024 MB  b) 1,024 KB  c) 1,024 bytes
**Answer: a) 1,024 MB**

**5. The largest unit in the book's staircase is —**
a) megabyte  b) gigabyte  c) terabyte
**Answer: c) terabyte** — TB = 1,024 GB.

**6. A CD's 700 MB sits on which step?**
a) Kilobyte  b) Megabyte  c) Terabyte
**Answer: b) Megabyte**
