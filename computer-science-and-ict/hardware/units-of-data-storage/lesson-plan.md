# Lesson plan — Units of data storage — bit, byte, KB, MB, GB, TB

**Course:** Computer Science and ICT · **Title:** Hardware · **Lesson:** Units of data storage — bit, byte, KB, MB, GB, TB
**Place in the curriculum:** Unit 2 — Computer Hardware — in the title Hardware on the ICT course ladder (TITLES.md).
**The one thing this lesson teaches:** Storage size is measured from the bit (a single binary digit, 1 or 0) through the byte (8 bits), kilobyte (1,024 bytes), megabyte (1,024 KB), gigabyte (1,024 MB) and terabyte (1,024 GB).
**This lesson's own level:** It stands on the secondary storage lessons: sizes like 700 MB and 8.4 GB were named there; this lesson builds the staircase those sizes stand on. It is the last lesson of Unit 2.

## What the learner can do when it ends
1. Define a bit (a single binary digit, 1 or 0) and a byte (8 bits).
2. Recite the staircase: KB = 1,024 bytes; MB = 1,024 KB; GB = 1,024 MB; TB = 1,024 GB.
3. Place the CD (700 MB) and DVD (8.4 GB) sizes on the staircase.

## What you need
Paper and a pencil.
