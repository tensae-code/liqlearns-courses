# Check Disk and closing stuck programs — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Check Disk —
a) deletes files  b) fixes errors on the computer  c) installs updates  d) defragments by itself
**Answer: b) fixes errors on the computer**

**2. (Sub lesson 1)** Check Disk should be run —
a) only after a crash  b) weekly, even with no visible problems  c) once a year  d) never on the C drive
**Answer: b) weekly, even with no visible problems**

**3. (Sub lesson 1)** The Check Disk route starts with —
a) right-click the C drive and choose Properties  b) open Task Manager  c) type in the search box  d) restart the computer
**Answer: a) right-click the C drive and choose Properties**

**4. (Sub lesson 1)** In Properties, you press —
a) the Format button  b) the Check button, to start the scan wizard  c) the Delete button  d) the Share button
**Answer: b) the Check button, to start the scan wizard**

**5. (Sub lesson 2)** The best way to close a program is —
a) End Task at once  b) its File menu — Close/Exit  c) unplugging  d) the power button
**Answer: b) its File menu — Close/Exit**

**6. (Sub lesson 2)** The second way closes a program —
a) at once, through End Task  b) after a week  c) only on paper  d) never completely
**Answer: a) at once, through End Task**
