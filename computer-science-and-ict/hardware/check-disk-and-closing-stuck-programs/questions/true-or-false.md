# Check Disk and closing stuck programs — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Check Disk is only for disks that already show problems.
**Answer: False**

**2. (Sub lesson 2)** Ctrl+Alt+Delete brings up Task Manager / the Close Program dialog.
**Answer: True**

**3. (Sub lesson 2)** End Task is the book's first choice for closing any program.
**Answer: False**
