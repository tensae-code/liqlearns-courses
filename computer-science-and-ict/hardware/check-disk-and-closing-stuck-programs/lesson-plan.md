# Lesson plan — Check Disk and closing stuck programs

**Course:** Computer Science and ICT · **Title:** Hardware · **Lesson:** Check Disk and closing stuck programs
**Place in the curriculum:** Unit 5 — Maintenance and Troubleshooting (CURRICULUM.md).
**The one thing this lesson teaches:** Check Disk hunts and fixes disk errors on a weekly rhythm, and a program that will not close from its File menu can be ended at once through Task Manager's End Task.
**This lesson's own level:** It stands on Fixing a slow or frozen application: End Task returns here as a general closing technique, beside a new tool, Check Disk.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
1. **Check Disk — fix errors before they show** — weekly error-fixing; right-click C drive → Properties → Check → the scan wizard.
2. **Closing a halted program — the second way** — File menu Close/Exit first; the Ctrl+Alt+Delete → End Task second way.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Fixing a slow or frozen application, in this same title. Recommended, never forced — a learner may land on this lesson directly, and it stands alone.

## What the learner can do when it ends
1. Run Check Disk from the C drive's Properties, weekly.
2. Close a program by its File menu first.
3. End a stuck program at once through Task Manager → End Task.

## What you need
A Windows school computer if available — paper works too. Paper and a pencil.

## If the learner is stuck
- Waits for visible damage before checking the disk → the rhythm is weekly, problems or not.
- Force-closes everything as a first move → the File menu Close/Exit is the book's best way; End Task is the second way.
