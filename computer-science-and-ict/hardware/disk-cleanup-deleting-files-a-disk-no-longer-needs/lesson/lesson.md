# Disk Cleanup — deleting the files a disk no longer needs

## Do it first

A disk is nearly full, yet the class's real work is small. Something else is eating the space. Write what you think it is — then work the lesson.

## Sub lesson 1 — What Disk Cleanup removes — and how often

**Disk Cleanup deletes unused and unwanted files** on the hard disk **to free space** — the **garbage and old internet files that accumulate over time**. It can be **run manually or scheduled automatically**, and it **should be performed weekly**.

[Picture 31309 — a bin emptying temporary and cache files out of a disk]

## Sub lesson 2 — Running it — one search away

Reach it by **typing "Disk Cleanup" in the Windows search box**. Run it, let it clear the files it lists, and the disk has room to work again. Weekly, the pile never grows back into a slow computer.
