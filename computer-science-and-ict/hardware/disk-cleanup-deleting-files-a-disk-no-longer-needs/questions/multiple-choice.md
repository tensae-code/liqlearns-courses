# Disk Cleanup — deleting the files a disk no longer needs — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Disk Cleanup deletes —
a) your documents  b) unused and unwanted files to free space  c) the operating system  d) installed programs only
**Answer: b) unused and unwanted files to free space**

**2. (Sub lesson 1)** The files it removes include —
a) garbage and old internet files that accumulate over time  b) this week's homework  c) the teacher's backups  d) new downloads
**Answer: a) garbage and old internet files that accumulate over time**

**3. (Sub lesson 1)** Disk Cleanup should be performed —
a) once ever  b) weekly  c) only when the disk dies  d) daily at midnight only
**Answer: b) weekly**

**4. (Sub lesson 1)** It can be run —
a) manually or scheduled automatically  b) only by the manufacturer  c) only from a disc  d) never on a PC
**Answer: a) manually or scheduled automatically**

**5. (Sub lesson 2)** You reach Disk Cleanup by —
a) typing "Disk Cleanup" in the Windows search box  b) right-clicking the desktop  c) opening the Recycle Bin  d) pressing Ctrl+Alt+Delete
**Answer: a) typing "Disk Cleanup" in the Windows search box**
