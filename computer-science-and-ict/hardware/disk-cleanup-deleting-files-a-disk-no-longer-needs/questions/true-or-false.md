# Disk Cleanup — deleting the files a disk no longer needs — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Temporary files accumulate again after a cleanup.
**Answer: True**

**2. (Sub lesson 1)** Disk Cleanup deletes the files you still need for your work.
**Answer: False**

**3. (Sub lesson 1)** A scheduled cleanup runs without you starting it each time.
**Answer: True**
