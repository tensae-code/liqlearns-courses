# Disk Cleanup — deleting the files a disk no longer needs — short answer

Answer in a sentence or two.

**1. (Sub lesson 1)** Why weekly, and not once?
**Answer: The garbage and old internet files accumulate over time, so a single cleanup fills up again; performed weekly — manually or scheduled — the space stays free.**

**2. (Sub lesson 2)** Give the route and the two run modes.
**Answer: Type "Disk Cleanup" in the Windows search box; it can be run manually or scheduled automatically.**
