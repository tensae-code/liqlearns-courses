# Lesson plan — Disk Cleanup — deleting the files a disk no longer needs

**Course:** Computer Science and ICT · **Title:** Hardware · **Lesson:** Disk Cleanup — deleting the files a disk no longer needs
**Place in the curriculum:** Unit 5 — Maintenance and Troubleshooting (CURRICULUM.md).
**The one thing this lesson teaches:** Disk Cleanup frees space by deleting the unused and unwanted files a disk collects — run weekly, by hand or on a schedule, from one search.
**This lesson's own level:** It stands on Fixing a slow computer: this is the full-disk suspect's own tool, in full.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
1. **What Disk Cleanup removes — and how often** — unused and unwanted files — garbage and old internet files; manual or scheduled; weekly.
2. **Running it — one search away** — type "Disk Cleanup" in the Windows search box and run it.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Fixing a slow computer — malware and full disk, in this same title. Recommended, never forced — a learner may land on this lesson directly, and it stands alone.

## What the learner can do when it ends
1. Say what Disk Cleanup deletes and why.
2. Run it from the Windows search box.
3. State the weekly rhythm, manual or scheduled.

## What you need
A Windows school computer if available — paper works too. Paper and a pencil.
