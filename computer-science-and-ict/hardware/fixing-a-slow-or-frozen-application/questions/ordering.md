# Fixing a slow or frozen application — ordering

Put the steps in the right order.

**1. (Sub lesson 1)** These steps are mixed up. Write them in the right order:

- End Task on the frozen application
- Close and reopen the application
- Restart the computer
- Update the application

**Answer (right order):** Close and reopen the application → Update the application → End Task on the frozen application → Restart the computer
