# Fixing a slow or frozen application — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The first move for a slow application is —
a) restart the computer  b) close and reopen the application  c) unplug the power  d) End Task
**Answer: b) close and reopen the application**

**2. (Sub lesson 1)** If reopening does not help, you —
a) update the application — Help menu, check for updates  b) hit the screen  c) delete the application at once  d) wait a week
**Answer: a) update the application — Help menu, check for updates**

**3. (Sub lesson 2)** The keys that open Task Manager are —
a) Ctrl+Shift+Esc written on paper only  b) Ctrl+Alt+Delete  c) Alt+F4 alone  d) the Windows key twice
**Answer: b) Ctrl+Alt+Delete**

**4. (Sub lesson 2)** In Task Manager the frozen app is ended from —
a) the Performance tab  b) the Processes tab — select it, then End Task  c) the Start menu  d) the Recycle Bin
**Answer: b) the Processes tab — select it, then End Task**

**5. (Sub lesson 2)** If force quit is impossible, the last resort is —
a) unplugging at once  b) restarting the computer, which closes all open apps  c) removing the battery first  d) calling the seller
**Answer: b) restarting the computer, which closes all open apps**

**6. (Sub lesson 3)** In the guide's frozen-computer key, the last resort is — (teacher guide — evidence)
a) restarting Explorer  b) holding the power button  c) unplugging the power cable or removing the laptop battery  d) pressing a key to wake from Sleep
**Answer: c) unplugging the power cable or removing the laptop battery**
