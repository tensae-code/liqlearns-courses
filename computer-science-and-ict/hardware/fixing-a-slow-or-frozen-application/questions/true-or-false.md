# Fixing a slow or frozen application — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A frozen application always needs a computer restart first.
**Answer: False**

**2. (Sub lesson 2)** End Task closes the selected application at once.
**Answer: True**

**3. (Sub lesson 3)** A blank screen may simply be Sleep mode — a mouse click or key press wakes it. (teacher guide — evidence)
**Answer: True**
