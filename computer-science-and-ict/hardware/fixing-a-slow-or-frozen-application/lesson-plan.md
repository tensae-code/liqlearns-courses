# Lesson plan — Fixing a slow or frozen application

**Course:** Computer Science and ICT · **Title:** Hardware · **Lesson:** Fixing a slow or frozen application
**Place in the curriculum:** Unit 5 — Maintenance and Troubleshooting (CURRICULUM.md).
**The one thing this lesson teaches:** A slow or frozen application is fixed in an escalating order: reopen it, update it, force-quit it through Task Manager, and only then restart the whole computer.
**This lesson's own level:** It stands on Troubleshooting — find the fault, find its cause: this is that system applied to one application.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
1. **First moves — reopen, then update** — close and reopen; update through the Help menu or an online search.
2. **Force quit — Task Manager and End Task** — Ctrl+Alt+Delete → Task Manager → Processes tab → End Task; restart as the last resort.
3. **The wider keys — frozen computer and blank screen (teacher guide — evidence)** — the guide's ordered keys: Explorer restart, held power button, unplug last (teacher evidence); the four blank-screen checks in order (teacher evidence).

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Troubleshooting — find the fault, find its cause, in this same title. Recommended, never forced — a learner may land on this lesson directly, and it stands alone.

## What the learner can do when it ends
1. Reopen, then update, a slow application.
2. Force-quit a frozen application through Task Manager → End Task.
3. Give the guide's frozen-computer escalation and blank-screen checks in order (teacher evidence).

## If the learner is stuck
- Reaches for the power cable first → the order escalates: reopen, update, End Task, restart — unplugging is the guide's last resort, after the held power button.
- Task Manager will not open from the desktop → the route is the keys themselves: hold Ctrl+Alt+Delete.
