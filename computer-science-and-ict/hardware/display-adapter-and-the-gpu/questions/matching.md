# The Display Adapter and the GPU — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What does the display adapter produce?** → **The image the monitor shows**

**2. (Sub lesson 1) What does it render the picture into?** → **The signal sent to the screen, at its size and rate**

**3. (Sub lesson 1) Where can a display adapter live?** → **As a card in an expansion slot, or built into the board or processor**

**4. (Sub lesson 1) What is the GPU?** → **The graphics processing unit — a processor specialised for picture work**

**5. (Sub lesson 2) How does GPU work differ from CPU work?** → **Thousands of small similar calculations done in parallel**

**6. (Sub lesson 2) What picture work must be done for every frame?** → **The colour of every dot on the screen**

**7. (Sub lesson 2) What memory does the adapter carry?** → **Its own memory for the images it is building**

**8. (Sub lesson 2) When is the GPU the limit of a machine?** → **For drawing, video and games — picture work**

**9. (Sub lesson 2) Which chapter teaches this?** → **Laos Grade 8 ICT, Chapter 1 §1.6**

**10. (Sub lesson 1) Can the screen show anything without this work?** → **No — the image must be produced somewhere**
