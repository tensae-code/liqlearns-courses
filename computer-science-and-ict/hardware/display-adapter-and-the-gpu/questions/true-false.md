# The Display Adapter and the GPU — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The image the monitor shows**
**Answer: True**

**2. (Sub lesson 1) True or false: As a card in an expansion slot, or built into the board or processor** — as the answer to: What does it render the picture into?
**Answer: False — The signal sent to the screen, at its size and rate**

**3. (Sub lesson 1) True or false: As a card in an expansion slot, or built into the board or processor**
**Answer: True**

**4. (Sub lesson 1) True or false: Thousands of small similar calculations done in parallel** — as the answer to: What is the GPU?
**Answer: False — The graphics processing unit — a processor specialised for picture work**

**5. (Sub lesson 2) True or false: Thousands of small similar calculations done in parallel**
**Answer: True**

**6. (Sub lesson 2) True or false: Its own memory for the images it is building** — as the answer to: What picture work must be done for every frame?
**Answer: False — The colour of every dot on the screen**

**7. (Sub lesson 2) True or false: Its own memory for the images it is building**
**Answer: True**

**8. (Sub lesson 2) True or false: Laos Grade 8 ICT, Chapter 1 §1.6** — as the answer to: When is the GPU the limit of a machine?
**Answer: False — For drawing, video and games — picture work**

**9. (Sub lesson 2) True or false: Laos Grade 8 ICT, Chapter 1 §1.6**
**Answer: True**

**10. (Sub lesson 1) True or false: The image the monitor shows** — as the answer to: Can the screen show anything without this work?
**Answer: False — No — the image must be produced somewhere**
