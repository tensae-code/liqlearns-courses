# Hard disk, optical disk, flash disk and SD card — true or false

Say whether each statement is true or false.

**1. Magnetic tape and the floppy disk are added to the storage examples by the teacher guide's key.**
**Answer: True** — Guide printed pp. 31–32, 34 — evidence, not the student book's list.

**2. Secondary storage keeps data permanently.**
**Answer: True** — That is what makes these four 'secondary'.

**3. A DVD holds less than a CD.**
**Answer: False** — DVD up to 8.4 GB; CD up to 700 MB.

**4. Backup means keeping a spare copy safe.**
**Answer: True**
