# System Restore — rolling back to when it worked — short answer

Answer in a sentence or two.

**1. (Sub lesson 1)** A program installed on Monday breaks the machine on Tuesday. Explain the restore move and the habit that makes it possible.
**Answer: Restore the system to the restore point saved when the program was installed on Monday, rolling back to the healthy settings; it works because a point was saved at install time, while the system functioned normally.**

**2. (Sub lesson 2)** Name the table's solutions for a frozen screen.
**Answer: Close programs, System Restore, restart the computer, Check Disk.**
