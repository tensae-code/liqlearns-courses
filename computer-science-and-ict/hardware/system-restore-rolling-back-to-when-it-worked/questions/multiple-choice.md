# System Restore — rolling back to when it worked — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A restore point is —
a) a copy of your documents  b) a secure copy of system settings while the system functions normally  c) a spare hard disk  d) a printed report
**Answer: b) a secure copy of system settings while the system functions normally**

**2. (Sub lesson 1)** Save a restore point —
a) whenever new software is installed  b) only after a crash  c) once a year  d) never — they save themselves after trouble
**Answer: a) whenever new software is installed**

**3. (Sub lesson 1)** System Restore is reached through —
a) Start → Programs → Accessories → System Tools → System Restore  b) the Recycle Bin  c) Device Manager  d) the volume icon
**Answer: a) Start → Programs → Accessories → System Tools → System Restore**

**4. (Sub lesson 2)** For a slow computer the table gives —
a) Disk Cleanup, Disk Defragmentation, close programs, run antivirus  b) only restart  c) only System Restore  d) format and reinstall
**Answer: a) Disk Cleanup, Disk Defragmentation, close programs, run antivirus**

**5. (Sub lesson 2)** For a frozen screen the table gives —
a) close programs, System Restore, restart the computer, Check Disk  b) only Disk Cleanup  c) only antivirus  d) only defragmentation
**Answer: a) close programs, System Restore, restart the computer, Check Disk**
