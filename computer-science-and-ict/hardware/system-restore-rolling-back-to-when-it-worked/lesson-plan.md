# Lesson plan — System Restore — rolling back to when it worked

**Course:** Computer Science and ICT · **Title:** Hardware · **Lesson:** System Restore — rolling back to when it worked
**Place in the curriculum:** Unit 5 — Maintenance and Troubleshooting (CURRICULUM.md).
**The one thing this lesson teaches:** System Restore keeps restore points — secure copies of a healthy system's settings — so a machine broken by a later change can be rolled back; save a point whenever new software is installed.
**This lesson's own level:** It stands on the unit's fixing lessons: when a fix fails, Restore is the way back to a known-good system.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
1. **Restore points — save one when you install** — the restore point defined; save one at every install; the Start → Programs → Accessories → System Tools route.
2. **The common-problems table — the unit's fixes in one view** — the closing table: slow computer's four fixes; frozen screen's four fixes.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## If the learner is stuck
- Looks for a restore point after the crash that was never saved → points are saved while the system is healthy, at install time.
- Treats Restore as a file backup → it copies system settings, the system's health — not your documents.
