## Sub lesson 1 — Restore points — save one when you install

**System Restore creates a restore point — a secure copy of system settings while the system functions normally** — or **restores the system to a previous point**. Save a restore point **whenever new software is installed**: if the new software brings a malfunction, the system can be **rolled back** and **got running again**. Both creating and restoring are reached by **Start → Programs → Accessories → System Tools → System Restore**.

## Sub lesson 2 — The common-problems table — the unit's fixes in one view

The unit's closing table pairs problems with its taught solutions:

- **Frozen screen** → **close programs, System Restore, restart the computer, Check Disk**.
