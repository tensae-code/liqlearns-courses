# Windows Update — downloading fixes and features — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Windows Update works without any internet connection.
**Answer: False**

**2. (Sub lesson 2)** The search box is a second route to Windows Update.
**Answer: True**

**3. (Sub lesson 1)** Security fixes are part of what updates bring.
