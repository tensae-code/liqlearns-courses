# Windows Update — downloading fixes and features — short answer

Answer in a sentence or two.

**1. (Sub lesson 1)** Why is updating preventive maintenance?
**Answer: Installing updates keeps security and reliability current, preventing the failures and attacks that old software invites — maintenance done before trouble, not after.**

**2. (Sub lesson 2)** Give the full route from Start menu to downloading.
**Answer: Open Windows Update from its icon in the Start menu (or type "Window Update" in the search box), then choose Download update; the computer connects to the Microsoft server and downloads and installs the updates.**
