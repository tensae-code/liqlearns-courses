# Windows Update — downloading fixes and features — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Windows Update keeps the computer up to date with —
a) new wallpapers only  b) new features and the latest security  c) other people's files  d) faster internet
**Answer: b) new features and the latest security**

**2. (Sub lesson 1)** It connects over the internet to —
a) any file site  b) the Microsoft server  c) the school server only  d) a neighbour's computer
**Answer: b) the Microsoft server**

**3. (Sub lesson 1)** Updates are —
a) downloaded and installed  b) only looked at  c) printed  d) stored on paper
**Answer: a) downloaded and installed**

**4. (Sub lesson 2)** One route in is —
a) the Windows Update icon in the Start menu  b) the Recycle Bin  c) the volume icon  d) the printer queue
**Answer: a) the Windows Update icon in the Start menu**

**5. (Sub lesson 2)** The choice that starts it is —
a) Delete update  b) Download update  c) Hide update  d) Print update
**Answer: b) Download update**
