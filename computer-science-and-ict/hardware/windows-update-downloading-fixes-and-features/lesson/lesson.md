# Windows Update — downloading fixes and features

## Do it first

A message says your computer is out of date and at risk. Write where the fixes come from and how the computer fetches them — then work the lesson.

## Sub lesson 1 — What Windows Update does

**Windows Update keeps the computer up to date** with **new features and the latest security**. It **connects over the internet to the Microsoft server** to **download and install updates** — the fixes travel from the maker to your machine.

[Picture 31310 — an update travelling from a server to a computer, with a shield arriving with it]

## Sub lesson 2 — Running it — icon, search, download

Open it from the **Windows Update icon in the Start menu** — or by **typing "Window Update" in the search box**, as the book prints it. Then the **Download update** choice starts it: the computer fetches and installs what the server offers.
