# Lesson plan — Windows Update — downloading fixes and features

**Course:** Computer Science and ICT · **Title:** Hardware · **Lesson:** Windows Update — downloading fixes and features
**Place in the curriculum:** Unit 5 — Maintenance and Troubleshooting (CURRICULUM.md).
**The one thing this lesson teaches:** Windows Update connects to Microsoft's server over the internet and downloads the newest features and security fixes — keeping the system current is a maintenance duty, not an option.
**This lesson's own level:** It stands on Installation, updates and device drivers: this is the update half of preventive maintenance, worked as a doing-lesson.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
1. **What Windows Update does** — current features and latest security; the internet connection to the Microsoft server; download and install.
2. **Running it — icon, search, download** — the Start-menu icon or the search box; the Download update choice.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Installation, updates and device drivers, in this same title. Recommended, never forced — a learner may land on this lesson directly, and it stands alone.

## What the learner can do when it ends
1. Say what Windows Update downloads and installs.
2. Open it from the Start menu or the search box.
3. Start the download with the Download update choice.

## What you need
A Windows school computer with an internet connection if available — paper works too. Paper and a pencil.
