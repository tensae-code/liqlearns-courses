# CMOS errors — when the battery needs replacing — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The CMOS chip stores —
a) your documents  b) everything from the time and date to system hardware settings  c) only the time  d) the antivirus
**Answer: b) everything from the time and date to system hardware settings** — time and date through to hardware settings.

**2. (Sub lesson 1)** CMOS holds the configuration of —
a) Windows  b) BIOS  c) the printer  d) the network
**Answer: b) BIOS** — the BIOS configuration.

**3. (Sub lesson 2)** A CMOS alert on screen means —
a) a virus  b) its battery needs replacing  c) the disk is full  d) POST has failed
**Answer: b) its battery needs replacing** — the battery is the fix.

**4. (Sub lesson 2)** The new battery must be —
a) any round battery  b) a bigger one  c) exactly the same as the old one  d) rechargeable
**Answer: c) exactly the same as the old one** — exactly the same — the book's words.

**5. (Sub lesson 2)** The battery is removed —
a) quickly, with the power on  b) carefully, with the computer off  c) by a magnet  d) while Windows runs
**Answer: b) carefully, with the computer off** — carefully — and the unit's safety rule: off first.
