# Command-line tools — tracert, nslookup and netstat — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** tracert determines —
a) the route data takes to a destination  b) a host's own address only  c) the disk space  d) the user list
**Answer: a) the route data takes to a destination**

**2. (Sub lesson 1)** tracert helps find —
a) lost files  b) where packets are lost and where problems sit  c) free ports only  d) the printer
**Answer: b) where packets are lost and where problems sit**

**3. (Sub lesson 1)** nslookup is —
a) a DNS utility displaying the IP address of a hostname, or the reverse  b) a disk tool  c) an antivirus  d) a cable tester
**Answer: a) a DNS utility displaying the IP address of a hostname, or the reverse**

**4. (Sub lesson 1)** The book shows nslookup with Google's DNS at —
a) 192.168.0.1  b) 8.8.8.8  c) 10.0.0.1  d) 255.255.255.0
**Answer: b) 8.8.8.8**

**5. (Sub lesson 2)** netstat shows —
a) the status of each active network connection and what services are running  b) only the gateway  c) deleted packets  d) the route
**Answer: a) the status of each active network connection and what services are running**

**6. (Sub lesson 2)** Which is a standalone application named in the lesson?
a) packet sniffer  b) word processor  c) paint program  d) media player
**Answer: a) packet sniffer**
