# Hands-on — Command-line tools — tracert, nslookup and netstat

The lesson with your hands, not only your eyes.

## Hop map
Draw a route of six hops to a distant host; mark hop 4 as the loss point. Write under it the command that draws such a map and the conclusion a troubleshooter takes from it.

## Tool chooser
Write five fault cards (lost packets, name will not resolve, unknown connection open, address check, gateway test). Match each to its tool: tracert, nslookup, netstat, ipconfig, ping.
