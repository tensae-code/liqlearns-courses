# Lesson plan — Backups — copy your work before anything goes wrong

**Course:** Computer Science and ICT · **Title:** Hardware · **Lesson:** Backups — copy your work before anything goes wrong
**Place in the curriculum:** Unit 5 — Hardware Troubleshooting and Preventive Maintenance (CURRICULUM.md).
**The one thing this lesson teaches:** A backup copies your data to external storage so work survives a failure — and the standing rule of this whole unit is: backup first, before any troubleshooting begins.
**This lesson's own level:** It stands on Antivirus — installing it and scanning regularly: guards first, copies second, repairs last.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Why back up — and the rule before troubleshooting** — A backup copies data or files to external storage — a cloud server or an external hard drive. Standing rule: backup is the first step before any troubleshooting; if none exists, do not start — first check with the user the date of the last backup, what it contains, its integrity, and that all restore media are available.
2. **The Windows backup steps (doing)** — Control Panel, Backup and Restore, Set up backup, then Create a system image, choose the destination drive, Next, Start backup — or search 'backup' and choose Backup settings.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## If the learner is stuck
- Wants to fix first, back up later → the rule is absolute in the book: no backup, no start. The fix can wait an hour; lost data cannot come back.
- Backs up to the same disk → a backup lives on EXTERNAL storage: a cloud server or an external drive, away from the failure.
