# Backups — copy your work before anything goes wrong — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A backup copies data to —
a) the same folder  b) external storage — a cloud server or an external hard drive  c) the printer  d) RAM
**Answer: b) external storage — a cloud server or an external hard drive** — external — away from the failure.

**2. (Sub lesson 1)** The standing rule says backup is —
a) the last step of troubleshooting  b) the first step before any troubleshooting  c) optional for small faults  d) the teacher's job only
**Answer: b) the first step before any troubleshooting** — first step — before any troubleshooting.

**3. (Sub lesson 1)** If no backup exists, you —
a) start carefully  b) do not start; check with the user first  c) delete the fault  d) change the settings
**Answer: b) do not start; check with the user first** — do not start — the book's words.

**4. (Sub lesson 1)** The user-checks include —
a) the date of the last backup, what it contains, its integrity, restore media available  b) the user's password and PIN  c) the machine's price  d) the beep code
**Answer: a) the date of the last backup, what it contains, its integrity, restore media available** — the four checks in order.

**5. (Sub lesson 2)** The Windows route begins —
a) search 'backup'  b) open Control Panel  c) Ctrl+Alt+Delete  d) open Device Manager
**Answer: b) open Control Panel** — Control Panel first, on this route.

**6. (Sub lesson 2)** After Backup and Restore, you choose —
a) Create a system image at once  b) Set up backup  c) Start backup  d) Defragment
**Answer: b) Set up backup** — Set up backup comes before the image step.

**7. (Sub lesson 2)** The destination drive can be —
a) only a flash disk  b) a hard disk, a DVD, or a network place  c) only the same disk  d) the monitor
**Answer: b) a hard disk, a DVD, or a network place** — the three named destinations.

**8. (Sub lesson 2)** The route's last click is —
a) Next  b) Create  c) Start backup  d) Finish and delete
**Answer: c) Start backup** — Next, then Start backup.
