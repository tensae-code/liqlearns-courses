# Backups — copy your work before anything goes wrong — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub Lessons"). Practice is tied to the learner's skill number, as before. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Why back up — and the rule before troubleshooting
Sub lesson 1 questions from the type files. Pass mark: the learner can state and use what this part teaches — A backup copies data or files to external storage — a cloud server or an external hard drive. Standing rule: backup is the first step before any troubleshooting; if none exists, do not start — first check with the user the date of the last backup, what it contains, its integrity, and that all restore media are available.
