# Speech recognition — entering data by talking — true or false

Say whether each statement is true or false.

**1.** The book describes speech recognition as the latest technology, still under research.
**Answer: True**

**2.** In speech recognition, the microphone performs the ordered action itself.
**Answer: False**

**3.** Speech recognition removes the need for any processing — the microphone obeys by itself.
**Answer: False** — the computer processes the speech and performs the action.
