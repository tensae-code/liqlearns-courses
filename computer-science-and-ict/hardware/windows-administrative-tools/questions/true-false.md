# Windows Administrative Tools — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Computer Management, Disk Management, Services, Task Scheduler, Firewall with Advanced Security, Performance Monitor**
**Answer: True**

**2. (Sub lesson 1) True or false: Computer Management, Disk Management, Services, Task Scheduler, Firewall with Advanced Security, Performance Monitor** — as the answer to: What is Computer Management?
**Answer: False — The umbrella console — users, disks, services, events in one frame**

**3. (Sub lesson 1) True or false: Jobs at times and triggers — the maintenance calendar**
**Answer: True**

**4. (Sub lesson 1) True or false: Jobs at times and triggers — the maintenance calendar** — as the answer to: What does Disk Management shape?
**Answer: False — Partitions and drives**

**5. (Sub lesson 1) True or false: The background workers — started, stopped and set**
**Answer: True**

**6. (Sub lesson 2) True or false: The background workers — started, stopped and set** — as the answer to: By what do administrative tools differ?
**Answer: False — Reach — they change the system for every user, persistently**

**7. (Sub lesson 2) True or false: Administer only when administering, record changes, test on one machine first, keep a way back**
**Answer: True**

**8. (Sub lesson 2) True or false: Administer only when administering, record changes, test on one machine first, keep a way back** — as the answer to: What is the change log called?
**Answer: False — The next troubleshooter's diary**

**9. (Sub lesson 2) True or false: Restore points and backups**
**Answer: True**

**10. (Sub lesson 2) True or false: Restore points and backups** — as the answer to: What is the lesson's last word on the levers?
**Answer: False — They are lent, not owned**
