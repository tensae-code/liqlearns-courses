## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The computer platform** — Grade 8's hardware unit names the whole machine the **computer platform**: the **motherboard** at its centre, the **processor** that works on it, and the **ports** that connect everything else. Before any single part is studied, the book sets out the platform's **standard specifications** — the list of what a complete, working platform should have.
2. **Choosing by specifications — and upgrading later** — Choosing a computer means **comparing specifications**: what processor, how much memory and storage, which ports — against the work the machine must do and the money there is. A platform that can be **upgraded** later — more memory, a bigger disk — serves longer than one that cannot, so **upgradeability** is itself one of the specifications to check before buying.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
