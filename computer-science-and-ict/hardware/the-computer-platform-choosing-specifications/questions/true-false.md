# The Computer Platform — Choosing Specifications — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does Grade 8's hardware unit call the whole machine?" is: The computer platform**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What sits at the centre of the platform?" is: The ports**
**Answer: False** — The motherboard

**3. (Sub lesson 1) True or false: the answer to "What works on the motherboard?" is: The processor**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What connects everything else to the platform?" is: Comparing specifications**
**Answer: False** — The ports

**5. (Sub lesson 1) True or false: the answer to "What does the book set out before any single part is studied?" is: The platform's standard specifications**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does choosing a computer mean?" is: The processor and the amount of memory or storage**
**Answer: False** — Comparing specifications

**7. (Sub lesson 2) True or false: the answer to "Against what are specifications compared?" is: The work the machine must do and the money there is**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Name two specifications to compare." is: A platform that can be upgraded serves longer**
**Answer: False** — The processor and the amount of memory or storage

**9. (Sub lesson 2) True or false: the answer to "What can an upgradeable platform take later?" is: More memory or a bigger disk**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why is upgradeability itself a specification to check?" is: The motherboard**
**Answer: False** — A platform that can be upgraded serves longer
