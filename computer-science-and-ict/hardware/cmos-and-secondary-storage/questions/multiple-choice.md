# CMOS — and secondary storage keeps data for good — multiple choice

Pick the one right answer.

**1.** CMOS stands for —
a) Central Memory Operating System  b) Complementary Metal Oxide Semiconductor  c) Computer Memory On Screen  d) Copy Machine Optical Sensor
**Answer: b) Complementary Metal Oxide Semiconductor** — CMOS = Complementary Metal Oxide Semiconductor.

**2.** CMOS is used to —
a) Print pages  b) Store information when the computer shuts off  c) Cool the CPU  d) Connect the mouse
**Answer: b) Store information when the computer shuts off** — CMOS stores information when the computer shuts off.

**3.** Secondary storage keeps programs and data —
a) Only while typing  b) Permanently and long-term  c) For one second  d) Never
**Answer: b) Permanently and long-term** — Secondary storage keeps programs and data permanently and long-term.

**4.** Which of these is secondary storage?
a) A register  b) Magnetic tape  c) The ALU  d) RAM
**Answer: b) Magnetic tape** — Magnetic tape, magnetic disk, optical disk, punched cards and punched paper are secondary storage.

**5.** A backup is —
a) A copy on the same spot  b) Data stored in a different place from the original, for use if the original is lost to disaster  c) A deleted file  d) A printed list
**Answer: b) Data stored in a different place from the original, for use if the original is lost to disaster** — A backup lives in a different place from the original.
