# CMOS — and secondary storage keeps data for good

## Do it first

Your phone remembers its settings even after the battery dies completely. Something inside kept them without power from the wall. Before reading on, guess what kind of memory that could be — and where your photos live for years at a time.

## CMOS — the third primary memory

CMOS — Complementary Metal Oxide Semiconductor — is the third primary memory type. It is used to store information when the computer shuts off, and it is found in components including the CPU and digital cameras.

## Secondary storage — permanent and long-term

Secondary (auxiliary) storage sits external to the computer's main memory work and keeps programs and data permanently and long-term. Its family in this unit: magnetic tape, magnetic disk, optical disk, punched cards and punched paper — the next lessons take tape, disks and optical disks one by one.

## Backup — a copy in a different place

The unit's backup note: a backup is data stored in a different place from the original, so that if the original is lost to disaster, the copy can be used. A copy on the same disk in the same machine is not yet a backup — place is the point.
