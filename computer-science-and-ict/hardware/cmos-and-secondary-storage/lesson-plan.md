# Lesson plan — CMOS — and secondary storage keeps data for good

**Course:** Computer Science and ICT · **Title:** Hardware · **Lesson:** CMOS — and secondary storage keeps data for good
**Place in the curriculum:** Title 2 — Hardware of the Computer Science and ICT ladder (TITLES.md); Ethiopia Grade 8, Unit 2 — Computer Hardware.
**The one thing this lesson teaches:** CMOS is the third primary memory, keeping information when the computer shuts off — and secondary storage sits outside the machine's main memory, keeping programs and data permanently, with backups kept in a different place.
**This lesson's own level:** it stands on the RAM and ROM lesson: the third primary type completes the set, then the second great storage family.

## If the learner is stuck
- Thinks CMOS is a camera part only → CMOS is a primary memory type, found in components including the CPU AND digital cameras.
- Thinks any second copy is a backup → a backup is stored in a DIFFERENT PLACE from the original, against disaster.
