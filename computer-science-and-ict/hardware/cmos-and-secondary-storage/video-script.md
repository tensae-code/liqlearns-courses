**CMOS.**

First, brainstorm: what do you already know about this? Say it out loud.

Now the one thing: CMOS is the third primary memory, keeping information when the computer shuts off — and secondary storage sits outside the machine's main memory, keeping programs and data permanently, with backups kept in a different place.

**CMOS — the third primary memory.** CMOS — Complementary Metal Oxide Semiconductor — is the third primary memory type.
**Secondary storage — permanent and long-term.** Secondary (auxiliary) storage sits external to the computer's main memory work and keeps programs and data permanently and long-term.
**Backup — a copy in a different place.** The unit's backup note: a backup is data stored in a different place from the original, so that if the original is lost to disaster, the copy can be used.
