# The mouse — buttons and connections — multiple choice

Pick the one right answer.

**1.** The mouse controls —
a) The printer  b) The cursor or pointer  c) The power supply  d) The fan
**Answer: b) The cursor or pointer** — The mouse is a hand-operated device controlling the cursor or pointer.

**2.** The left button is used to click — for example, to —
a) See properties  b) Select text  c) Scroll  d) Switch off
**Answer: b) Select text** — Left click — e.g. to select text.

**3.** Right-clicking a file can show —
a) Its properties  b) Tomorrow's weather  c) A game  d) The desktop only
**Answer: a) Its properties** — Right-click — e.g. to see a file's properties.

**4.** The middle button is used for —
a) Typing  b) Scrolling  c) Deleting  d) Saving
**Answer: b) Scrolling** — The middle button is used for scrolling — and is sometimes missing.

**5.** A cordless mouse is —
a) A wired mouse  b) A wireless mouse  c) A keyboard  d) A broken mouse
**Answer: b) A wireless mouse** — Mice connect by cable or wirelessly (a cordless mouse).
