# Beep codes — what the start-up sounds mean — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub Lessons"). Practice is tied to the learner's skill number, as before. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — One short beep — and silence
Sub lesson 1 questions from the type files. Pass mark: the learner can state and use what this part teaches — One short beep means a normal boot. No beep while the machine runs points at the beeper itself; no beep at all points at the power supply.

## Sub lesson 2 — Power-supply patterns
Sub lesson 2 questions from the type files. Pass mark: the learner can state and use what this part teaches — Steady short beeps and steady long beeps both name the power supply — bad, or voltages wrong; replacement is usually needed.

## Sub lesson 3 — RAM and video patterns
Sub lesson 3 questions from the type files. Pass mark: the learner can state and use what this part teaches — One long continuous beep: a RAM stick has failed — test sticks one at a time. One long and two short: video-card failure — reseat the card first, then replace it.
