# Beep codes — what the start-up sounds mean — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Every BIOS maker uses exactly the same beep patterns.
**Answer: False** — each maker has its own patterns — note yours and search it.

**2. (Sub lesson 2)** Steady long beeps also name the power supply.
**Answer: True** — both steady patterns do.

**3. (Sub lesson 3)** The standing method is: note the exact sequence, then search it online.
**Answer: True** — the book's method for every pattern.
