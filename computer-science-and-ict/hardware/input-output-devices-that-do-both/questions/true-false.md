# Input-Output Devices — Devices That Do Both — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: It carries data both ways — in and out**
**Answer: True**

**2. (Sub lesson 1) True or false: Speaker out, microphone in** — as the answer to: The touchscreen's two directions are what?
**Answer: False — Shows the picture (output) and feels the finger (input)**

**3. (Sub lesson 1) True or false: Speaker out, microphone in**
**Answer: True**

**4. (Sub lesson 1) True or false: Greece Grade 7 Pliroforiki A, Unit 2** — as the answer to: Name a storage device that does both.
**Answer: False — The hard disk (or USB stick — reads and writes)**

**5. (Sub lesson 1) True or false: Greece Grade 7 Pliroforiki A, Unit 2**
**Answer: True**

**6. (Sub lesson 2) True or false: By which way data moves for the job at hand** — as the answer to: What do input and output name?
**Answer: False — Directions of data travel — not species of device**

**7. (Sub lesson 2) True or false: By which way data moves for the job at hand**
**Answer: True**

**8. (Sub lesson 2) True or false: A sort that cannot admit its exceptions starts lying about everything else** — as the answer to: Which devices answer 'both'?
**Answer: False — Touchscreen, headset, modem, read-write storage (any from the lesson)**

**9. (Sub lesson 2) True or false: A sort that cannot admit its exceptions starts lying about everything else**
**Answer: True**

**10. (Sub lesson 2) True or false: It carries data both ways — in and out** — as the answer to: Both at once or how else?
**Answer: False — At once, or in turns**
