# Resource Monitor — finding what is slowing the computer — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub Lessons"). Practice is tied to the learner's skill number, as before. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Opening Resource Monitor and reading the CPU tab
Sub lesson 1 questions from the type files. Pass mark: the learner can state and use what this part teaches — Open it by searching its name in the Windows search box. The CPU tab groups processes (running in black, suspended in blue, not responding in red), services, associated handles and associated modules.

## Sub lesson 2 — Fixing the slow machine
Sub lesson 2 questions from the type files. Pass mark: the learner can state and use what this part teaches — Find the heavy application in the CPU column, right-click it and End process — or right-click and Search online to learn what an unknown application is.

## Sub lesson 3 — The guide's greedy-app fix (teacher guide — evidence)
Sub lesson 3 questions from the type files. Pass mark: the learner can state and use what this part teaches — The guide keys the same cure from its side: open Resource Monitor, find the application taking the large share of CPU and memory, and stop or restart it.
