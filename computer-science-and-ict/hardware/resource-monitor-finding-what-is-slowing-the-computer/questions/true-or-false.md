# Resource Monitor — finding what is slowing the computer — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Resource Monitor shows which process listens on which port.
**Answer: True** — part of its network depth.

**2. (Sub lesson 2)** Suspended processes show in red.
**Answer: False** — suspended is blue; red is not responding.

**3. (Sub lesson 3)** The guide's cure for a greedy application is to stop or restart it.
**Answer: True** — teacher guide, printed pp. 97–98.


**4. (Sub lesson 3)** The guide measures a greedy application by its share of CPU only, never memory.
**Answer: False** — the guide says the large share of CPU and memory.
