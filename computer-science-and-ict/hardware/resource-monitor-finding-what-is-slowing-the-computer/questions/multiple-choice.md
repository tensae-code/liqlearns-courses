# Resource Monitor — finding what is slowing the computer — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Resource Monitor is opened by —
a) Ctrl+Alt+Delete  b) searching its name in the Windows search box  c) Control Panel  d) BIOS
**Answer: b) searching its name in the Windows search box** — search its name — the book's route.

**2. (Sub lesson 1)** Resource Monitor tracks in depth —
a) only the CPU  b) CPU, network, memory and disk  c) only passwords  d) beep codes
**Answer: b) CPU, network, memory and disk** — the four, in depth.

**3. (Sub lesson 1)** On the CPU tab, a running process shows in —
a) red  b) blue  c) black  d) yellow
**Answer: c) black** — black means running.

**4. (Sub lesson 1)** A process in red is —
a) suspended  b) not responding  c) the heaviest  d) a service
**Answer: b) not responding** — red means not responding.

**5. (Sub lesson 1)** The CPU tab groups processes, services, and —
a) backups and firewalls  b) associated handles and associated modules  c) logs and events  d) drivers and ports
**Answer: b) associated handles and associated modules** — handles and modules fill in for the selected process.

**6. (Sub lesson 2)** For a slow machine, you find the heavy application in —
a) the Security log  b) the CPU column  c) Device Manager  d) the Recycle Bin
**Answer: b) the CPU column** — the CPU column names it.

**7. (Sub lesson 2)** The cure for the heavy application is —
a) right-click it and End process  b) delete Windows  c) change BIOS settings  d) ignore it
**Answer: a) right-click it and End process** — right-click → End process.

**8. (Sub lesson 2)** For an UNKNOWN application, the book's safer first move is —
a) End process at once  b) right-click and Search online to learn what it is  c) rename it  d) print its name
**Answer: b) right-click and Search online to learn what it is** — learn before you end.


**9. (Sub lesson 3)** The guide's cure for a computer slowed by one greedy application is —
a) format the disk  b) open Resource Monitor, find the application taking the large share of CPU and memory, and stop or restart it  c) change the BIOS settings  d) ignore it
**Answer: b) open Resource Monitor, find the application taking the large share of CPU and memory, and stop or restart it** — the guide's keyed fix (teacher guide — evidence).
