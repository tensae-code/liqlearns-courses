# Lesson plan — Resource Monitor — finding what is slowing the computer

**Course:** Computer Science and ICT · **Title:** Hardware · **Lesson:** Resource Monitor — finding what is slowing the computer
**Place in the curriculum:** Unit 5 — Hardware Troubleshooting and Preventive Maintenance (CURRICULUM.md).
**The one thing this lesson teaches:** Resource Monitor is the deeper look: it shows which processes press on the CPU, memory, disk and network — and a slow machine is fixed by finding its heavy application and ending it.
**This lesson's own level:** It stands on Watching performance — Task Manager: the quick view first, the deep view second.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Opening Resource Monitor and reading the CPU tab** — Open it by searching its name in the Windows search box. The CPU tab groups processes (running in black, suspended in blue, not responding in red), services, associated handles and associated modules.
2. **Fixing the slow machine** — Find the heavy application in the CPU column, right-click it and End process — or right-click and Search online to learn what an unknown application is.
3. **The guide's greedy-app fix (teacher guide — evidence)** — The guide keys the same cure from its side: open Resource Monitor, find the application taking the large share of CPU and memory, and stop or restart it.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## What the learner can do when it ends
1. Write how Resource Monitor is opened, and name its four groups on the CPU tab.
2. A process shows in red. Write what the colour means.
3. An unknown program takes half the CPU. Write your two right-click choices and which you use first, and why.

## What you need
A Windows school computer if one is available — paper works too, screen by screen. Paper and a pencil.

## If the learner is stuck
- Ends processes at random → find the heavy one in the CPU column first; an unknown one gets Search online before any ending.
- Reads red as 'running fast' → the colours are states: black running, blue suspended, red not responding.
