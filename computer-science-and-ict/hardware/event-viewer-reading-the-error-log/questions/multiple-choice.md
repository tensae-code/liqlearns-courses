# Event Viewer — reading the error log — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Event Viewer is opened through —
a) the Control Panel printer page  b) the Windows search box, in three steps  c) BIOS  d) the Recycle Bin
**Answer: b) the Windows search box, in three steps** — search box first — the book's route.

**2. (Sub lesson 1)** Windows records errors in Event Viewer when —
a) you ask it to  b) system or application errors occur  c) the battery dies  d) POST runs
**Answer: b) system or application errors occur** — errors are logged as they occur.

**3. (Sub lesson 2)** Most troubleshooting uses —
a) the Security log only  b) the Windows Logs  c) the Recycle Bin  d) Device Manager
**Answer: b) the Windows Logs** — the Windows Logs hold the working categories.

**4. (Sub lesson 2)** The Application log holds events from —
a) logon attempts  b) system components such as drivers  c) installed games only  d) the printer
**Answer: b) system components such as drivers** — as the book assigns it.

**5. (Sub lesson 2)** The Security log records —
a) driver events  b) program installs  c) logon attempts and resource access  d) beep codes
**Answer: c) logon attempts and resource access** — when security logging is on.

**6. (Sub lesson 2)** An event records all of these EXCEPT —
a) date and time  b) severity  c) the user's password  d) event ID number
**Answer: c) the user's password** — passwords are never part of an event.

**7. (Sub lesson 3)** To open an event's full detail, you —
a) restart Windows  b) double-click the entry  c) delete the log  d) press Ctrl+Alt+Delete
**Answer: b) double-click the entry** — double-click opens the detail.

**8. (Sub lesson 3)** If the detail does not give the fix, the book's next move is —
a) give up  b) search the internet  c) replace the disk  d) change BIOS settings
**Answer: b) search the internet** — search on — the ID and source are the search words.
