# Event Viewer — reading the error log — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Event Viewer must be installed before it can record errors.
**Answer: False** — Windows records errors in it as they occur; you only open it.

**2. (Sub lesson 2)** Every event shows which user was logged in.
**Answer: True** — one of the six recorded facts.

**3. (Sub lesson 3)** Double-clicking an event deletes it.
**Answer: False** — it opens its full detail.
