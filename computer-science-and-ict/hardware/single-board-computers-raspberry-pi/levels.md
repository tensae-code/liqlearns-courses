# Single-Board Computers — Raspberry Pi — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — One board, whole computer
Sub lesson 1 questions from the type files. Pass mark: A complete computer — processor, memory, storage, connections — on one printed circuit board; A real operating system and ordinary programs, like a PC; The Raspberry Pi — the book uses the Pi 3; It is where the course's two worlds meet — a computer you use, and a board you wire; General-purpose input/output pins through which the computer senses and drives the world.

Sub lesson 2 questions from the type files. Pass mark: Lights, buttons, sensors and motors; A PC is a computer of many boards, with no GPIO; A whole computer, but sealed — no open pins; A controller board (a microcontroller), not a full computer; Grade 12, Bab 2 A — single-board computers.
