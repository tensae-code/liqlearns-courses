# Single-Board Computers — Raspberry Pi — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A complete computer — processor, memory, storage, connections — on one printed circuit board**
**Answer: True**

**2. (Sub lesson 1) True or false: A complete computer — processor, memory, storage, connections — on one printed circuit board** — as the answer to: What does an SBC run?
**Answer: False — A real operating system and ordinary programs, like a PC**

**3. (Sub lesson 1) True or false: The Raspberry Pi — the book uses the Pi 3**
**Answer: True**

**4. (Sub lesson 1) True or false: The Raspberry Pi — the book uses the Pi 3** — as the answer to: Why does the chapter open with the SBC?
**Answer: False — It is where the course's two worlds meet — a computer you use, and a board you wire**

**5. (Sub lesson 1) True or false: General-purpose input/output pins through which the computer senses and drives the world**
**Answer: True**

**6. (Sub lesson 2) True or false: General-purpose input/output pins through which the computer senses and drives the world** — as the answer to: What can GPIO drive or sense?
**Answer: False — Lights, buttons, sensors and motors**

**7. (Sub lesson 2) True or false: A PC is a computer of many boards, with no GPIO**
**Answer: True**

**8. (Sub lesson 2) True or false: A PC is a computer of many boards, with no GPIO** — as the answer to: How does a smartphone differ?
**Answer: False — A whole computer, but sealed — no open pins**

**9. (Sub lesson 2) True or false: A controller board (a microcontroller), not a full computer**
**Answer: True**

**10. (Sub lesson 2) True or false: A controller board (a microcontroller), not a full computer** — as the answer to: Where does Indonesia teach this?
**Answer: False — Grade 12, Bab 2 A — single-board computers**
