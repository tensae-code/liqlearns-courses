# Network troubleshooting — detect, then fix — short answer

Answer in a sentence or two.

**1. (Sub lesson 1)** Give the three purposes of a network.
**Answer: To share resources such as printers and scanners, to exchange files, and to enable electronic communications.**

**2. (Sub lesson 2)** Define network troubleshooting in one sentence.
**Answer: The collection of techniques and procedures to locate, analyse and fix network issues — detecting the cause first, then minimising and resolving faults so the system runs uninterrupted.**
