# Lesson plan — Network troubleshooting — detect, then fix

**Course:** Computer Science and ICT · **Title:** Hardware · **Lesson:** Network troubleshooting — detect, then fix
**Place in the curriculum:** Unit 5 — Maintenance and Troubleshooting (CURRICULUM.md).
**The one thing this lesson teaches:** A network joins computers to share resources and communicate, and network troubleshooting is the ordered craft of detecting a connection fault's cause first, then minimising and resolving it.
**This lesson's own level:** It stands on Troubleshooting: the same systematic craft, now on the connections between machines.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
1. **What a network is — and how it connects** — two or more computers; sharing, files, communications; the five connection media.
2. **Network troubleshooting — detect the cause first** — locate, analyse, fix; cause first; the definition of a network problem.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Troubleshooting — find the fault, find its cause, in this same title. Recommended, never forced — a learner may land on this lesson directly, and it stands alone.

## What the learner can do when it ends
1. Define a network and name what networks are for.
2. Name the five connection media.
3. Define network troubleshooting and a network problem.

## What you need
Paper and a pencil. A school network to look at, if there is one.

## If the learner is stuck
- Treats every network fault as one broken computer → a network problem disrupts the CONNECTION between the computer and the content.
- Fixes before detecting → the order is cause first, then minimise and resolve.
