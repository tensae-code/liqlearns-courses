# Linear vs Pipelined Processing — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Linear processing — one at a time, whole
Sub lesson 1 questions from the type files. Pass mark: Only after the current one is completely finished; Fetch, decode, execute; One — the others wait idle; The machine — two of three stages are always waiting; It is simple to build and easy to reason about.

## Sub lesson 2 — Pipelining — stages overlapping
Sub lesson 2 questions from the type files. Pass mark: Each stage works on a different instruction — execute, decode and fetch overlap; An assembly line; On every cycle; Throughput (instructions per time) — not the speed of a single instruction; When an instruction needs a result the line has not finished yet.
