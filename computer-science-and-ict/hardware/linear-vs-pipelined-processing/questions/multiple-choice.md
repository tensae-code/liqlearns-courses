# Linear vs Pipelined Processing — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) In linear processing, when is the next instruction fetched?**
a) Only after the current one is completely finished  b) Fetch, decode, execute  c) One — the others wait idle  d) The machine — two of three stages are always waiting
**Answer: a) Only after the current one is completely finished**

**2. (Sub lesson 1) Through which stages does an instruction pass?**
a) One — the others wait idle  b) Fetch, decode, execute  c) The machine — two of three stages are always waiting  d) It is simple to build and easy to reason about
**Answer: b) Fetch, decode, execute**

**3. (Sub lesson 1) At any moment in linear processing, how many stages work?**
a) The machine — two of three stages are always waiting  b) It is simple to build and easy to reason about  c) One — the others wait idle  d) Each stage works on a different instruction — execute, decode and fetch overlap
**Answer: c) One — the others wait idle**

**4. (Sub lesson 1) What does linear processing waste?**
a) It is simple to build and easy to reason about  b) Each stage works on a different instruction — execute, decode and fetch overlap  c) An assembly line  d) The machine — two of three stages are always waiting
**Answer: d) The machine — two of three stages are always waiting**

**5. (Sub lesson 1) What is linear processing's virtue?**
a) It is simple to build and easy to reason about  b) Each stage works on a different instruction — execute, decode and fetch overlap  c) An assembly line  d) On every cycle
**Answer: a) It is simple to build and easy to reason about**

**6. (Sub lesson 2) In pipelining, what happens at each stage at once?**
a) An assembly line  b) Each stage works on a different instruction — execute, decode and fetch overlap  c) On every cycle  d) Throughput (instructions per time) — not the speed of a single instruction
**Answer: b) Each stage works on a different instruction — execute, decode and fetch overlap**

**7. (Sub lesson 2) Like what is pipelining pictured?**
a) On every cycle  b) Throughput (instructions per time) — not the speed of a single instruction  c) An assembly line  d) When an instruction needs a result the line has not finished yet
**Answer: c) An assembly line**

**8. (Sub lesson 2) Once the line fills, how often does an instruction finish?**
a) Throughput (instructions per time) — not the speed of a single instruction  b) When an instruction needs a result the line has not finished yet  c) Only after the current one is completely finished  d) On every cycle
**Answer: d) On every cycle**

**9. (Sub lesson 2) What does pipelining raise — and what does it not?**
a) Throughput (instructions per time) — not the speed of a single instruction  b) When an instruction needs a result the line has not finished yet  c) Only after the current one is completely finished  d) Fetch, decode, execute
**Answer: a) Throughput (instructions per time) — not the speed of a single instruction**

**10. (Sub lesson 2) When does the line stumble?**
a) Only after the current one is completely finished  b) When an instruction needs a result the line has not finished yet  c) Fetch, decode, execute  d) One — the others wait idle
**Answer: b) When an instruction needs a result the line has not finished yet**
