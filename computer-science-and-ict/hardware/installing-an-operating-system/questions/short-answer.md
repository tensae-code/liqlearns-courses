# Installing an Operating System — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) Where does the install begin?**
**Answer: In the BIOS setup — telling the machine to boot from the install disc**

**2. (Sub lesson 1) Why boot from the disc first?**
**Answer: The hard disk is empty; the install program lives on the disc**

**3. (Sub lesson 1) What does the install program do to the disk?**
**Answer: Prepares it — partition and formatting — then copies the system's files**

**4. (Sub lesson 1) What appears when the install succeeds?**
**Answer: The desktop, standing up for the first time**

**5. (Sub lesson 1) What is the chapter's rule during an install?**
**Answer: Read each screen fully and answer in the book's order**

**6. (Sub lesson 2) Name the first steps after installing.**
**Answer: Set date, time and display; check devices and drivers; confirm disks appear**

**7. (Sub lesson 2) What is installed for devices the system does not see?**
**Answer: Their drivers**

**8. (Sub lesson 2) When is other software installed?**
**Answer: Only after the system itself is checked**

**9. (Sub lesson 2) Which chapter teaches this?**
**Answer: Laos Grade 8 ICT, Chapter 3 §3.1**

**10. (Sub lesson 2) How long does the guide time this practical?**
**Answer: Three hours of supervised bench work**
