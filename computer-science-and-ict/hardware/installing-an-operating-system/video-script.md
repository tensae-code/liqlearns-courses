# Video script — Installing an Operating System

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

The install begins in the **BIOS setup**: the machine is told to **start (boot) from the install disc** before its empty hard disk. With the XP disc in the drive, the machine starts into the install program, which **prepares the disk** (its partition and formatting), **copies the system's files**, and restarts into the new system's own screens — language, name, and the product details — until the **desktop stands up for the first time**. Laos's rule throughout is the chapter's rule: read each screen fully and answer in the book's order; an install hurried past its questions is an install done twice.
A fresh system is not yet a working system. The **first steps after installing** are: set the **date, time and display** right; check that the machine **sees its devices** (and install the **drivers** for those it does not — the next section's work); and confirm the disk and drives appear as they should. Only then is software installed on top. The lesson's judgement, which the whole chapter stands on: the operating system is the ground every program stands on, so its install is checked like a foundation — level, complete, and only then built upon.
