# Software Faults — Their Causes and Fixing Them — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Application, system, malware, capacity, settings faults**
**Answer: True**

**2. (Sub lesson 1) True or false: Application, system, malware, capacity, settings faults** — as the answer to: What is the largest innocent family?
**Answer: False — Settings faults — the wrong option faithfully obeyed**

**3. (Sub lesson 1) True or false: Corrupt files; bugs (or a version at war with the system)**
**Answer: True**

**4. (Sub lesson 1) True or false: Corrupt files; bugs (or a version at war with the system)** — as the answer to: Name two system-fault causes.
**Answer: False — Damaged system files; driver troubles (or too much starting at once)**

**5. (Sub lesson 1) True or false: The fix for a bug is not the fix for a full disk**
**Answer: True**

**6. (Sub lesson 2) True or false: The fix for a bug is not the fix for a full disk** — as the answer to: Name the fixing order.
**Answer: False — Restart, update, check capacity/settings, scan, repair/reinstall, restore**

**7. (Sub lesson 2) True or false: Half of software's ghosts are states, not faults**
**Answer: True**

**8. (Sub lesson 2) True or false: Half of software's ghosts are states, not faults** — as the answer to: When is restore used?
**Answer: False — When the fault survives repair and reinstall**

**9. (Sub lesson 2) True or false: Regular updates, disk cleaning, backup habits, removing the unused**
**Answer: True**

**10. (Sub lesson 2) True or false: Regular updates, disk cleaning, backup habits, removing the unused** — as the answer to: What is the best fix, in the closing phrase?
**Answer: False — The fault that never happens**
