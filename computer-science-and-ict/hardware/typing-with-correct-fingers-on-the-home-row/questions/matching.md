# Typing With Correct Fingers on the Home Row — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) Where do the fingers rest when typing correctly?** → **On the home row — the middle row of letter keys**

**2. (Sub lesson 1) Which keys carry the small bumps?** → **F and J — the index fingers find them by touch**

**3. (Sub lesson 1) Where do the thumbs rest?** → **Over the space bar**

**4. (Sub lesson 1) What does each finger own?** → **Its starting keys, and the keys above and below them that it reaches for**

**5. (Sub lesson 1) What does a finger do after reaching for a key?** → **It returns home to its starting key**

**6. (Sub lesson 2) What does typing-trainer software do?** → **It drills finger placement, shows which finger strikes each letter, and measures speed and accuracy**

**7. (Sub lesson 2) What is the trainer's order?** → **Placement first, accuracy second, speed last**

**8. (Sub lesson 2) Why must speed come last?** → **Speed built on wrong fingers must be unlearned; speed on correct placement only grows**

**9. (Sub lesson 2) How should practice be scheduled?** → **Short daily practice, not one long session**

**10. (Sub lesson 2) What two numbers does the trainer report?** → **Typing speed and accuracy**
