# Typing With Correct Fingers on the Home Row — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: On the home row — the middle row of letter keys**
**Answer: True**

**2. (Sub lesson 1) True or false: On the home row — the middle row of letter keys** — as the answer to: Which keys carry the small bumps?
**Answer: False — F and J — the index fingers find them by touch**

**3. (Sub lesson 1) True or false: Over the space bar**
**Answer: True**

**4. (Sub lesson 1) True or false: Over the space bar** — as the answer to: What does each finger own?
**Answer: False — Its starting keys, and the keys above and below them that it reaches for**

**5. (Sub lesson 1) True or false: It returns home to its starting key**
**Answer: True**

**6. (Sub lesson 2) True or false: It returns home to its starting key** — as the answer to: What does typing-trainer software do?
**Answer: False — It drills finger placement, shows which finger strikes each letter, and measures speed and accuracy**

**7. (Sub lesson 2) True or false: Placement first, accuracy second, speed last**
**Answer: True**

**8. (Sub lesson 2) True or false: Placement first, accuracy second, speed last** — as the answer to: Why must speed come last?
**Answer: False — Speed built on wrong fingers must be unlearned; speed on correct placement only grows**

**9. (Sub lesson 2) True or false: Short daily practice, not one long session**
**Answer: True**

**10. (Sub lesson 2) True or false: Short daily practice, not one long session** — as the answer to: What two numbers does the trainer report?
**Answer: False — Typing speed and accuracy**
