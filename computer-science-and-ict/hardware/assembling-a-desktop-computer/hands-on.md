# Hands-on — Assembling a Desktop Computer

The lesson with your hands, not only your eyes.

## Assemble it for real

With the power off and unplugged, assemble a desktop computer: lay out the parts, join each to the system unit, connect the power last, check every join, then switch on. Write the order you worked in.

## The dark-screen check

Your assembled computer's screen stays dark. Write — and then, if a teacher allows, carry out — the checks in order: monitor cable, monitor switched on, power at the wall, each join seated. Record which check found the fault, or that all were sound.
