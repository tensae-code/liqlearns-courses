# Assembling a Desktop Computer — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) The monitor is where a desktop computer's processing happens.**
**Answer: False** — Processing and storage live in the system unit; the monitor shows the work.

**2. (Sub lesson 2) Forcing a cable into a port it does not fit can bend pins and break the port.**
**Answer: True** — Matching, never forcing, is the assembly rule.

**3. (Sub lesson 3) Checking every connection before switching on is part of assembling, not an extra.**
**Answer: True** — The check is the last step of the assembly itself.

**4. (Sub lesson 3) A dark screen at start-up proves a part is broken.**
**Answer: False** — Check the joins first; a loose cable is the commonest cause.
