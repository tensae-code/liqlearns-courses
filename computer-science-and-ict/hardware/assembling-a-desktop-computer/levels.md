# Assembling a Desktop Computer — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure). Practice is tied to the learner's skill number, as before. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — The parts you will assemble
Sub lesson 1 questions from the type files. Pass mark: name the parts of a desktop computer — system unit, monitor, keyboard, mouse and cables — and say what each one does.

## Sub lesson 2 — Putting the parts together
Sub lesson 2 questions from the type files. Pass mark: assemble a desktop computer: join each part to the system unit with the power off, matching cables to ports without forcing, and connect the power last.

## Sub lesson 3 — Checking and starting the assembled computer
Sub lesson 3 questions from the type files. Pass mark: check an assembled computer before and at start-up, and work through its connections in order when the screen stays dark.
