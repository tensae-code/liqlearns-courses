# Computer hardware — the part you can touch — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Software is hardware because it is inside the machine.**
**Answer: False** — Software is instructions — not physical, not touchable.

**2. (Sub lesson 2) Storage devices are one of the four families.**
**Answer: True**

**3. (Sub lesson 2) The four families are sorted by the colour of each part.**
**Answer: False** — They are sorted by function — by job.

**4. (Sub lesson 2) Input, process, output and store echo the four functions from Unit 1.**
**Answer: True**
