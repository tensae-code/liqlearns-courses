# Computer hardware — the part you can touch — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Hardware is —**
a) the instructions inside a computer  b) the physical part of the computer you can see and touch  c) a kind of data
**Answer: b) the physical part of the computer you can see and touch**

**2. (Sub lesson 1) Which of these is hardware?**
a) A program  b) A keyboard  c) An idea
**Answer: b) A keyboard** — You can see and touch a keyboard.

**3. (Sub lesson 2) Hardware falls into how many families by function?**
a) Two  b) Three  c) Four
**Answer: c) Four** — Input, CPU, output, storage.

**4. (Sub lesson 2) The family that PUTS data in is —**
a) output devices  b) input devices  c) storage devices
**Answer: b) input devices**

**5. (Sub lesson 2) The CPU belongs to which family?**
a) The processing family — it is the central processing unit  b) Storage  c) Output
**Answer: a) The processing family — it is the central processing unit**
