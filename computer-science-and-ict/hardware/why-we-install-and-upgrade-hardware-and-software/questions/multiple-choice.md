# Why We Install and Upgrade Hardware and Software — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does installing answer?**
a) A gap — a capability the machine does not yet have  b) A printer where none was; more memory where programs starve; a larger disk where data outgrew the old  c) A job needs a program the machine does not carry  d) 'This is being installed so that … can be done, which cannot be done now'
**Answer: a) A gap — a capability the machine does not yet have**

**2. (Sub lesson 1) Give a hardware-install reason.**
a) A job needs a program the machine does not carry  b) A printer where none was; more memory where programs starve; a larger disk where data outgrew the old  c) 'This is being installed so that … can be done, which cannot be done now'  d) No — installation answers a gap, never a whim
**Answer: b) A printer where none was; more memory where programs starve; a larger disk where data outgrew the old**

**3. (Sub lesson 1) Give a software-install reason.**
a) 'This is being installed so that … can be done, which cannot be done now'  b) No — installation answers a gap, never a whim  c) A job needs a program the machine does not carry  d) A shortfall — the capability exists but no longer suffices
**Answer: c) A job needs a program the machine does not carry**

**4. (Sub lesson 1) What sentence must an installer finish?**
a) No — installation answers a gap, never a whim  b) A shortfall — the capability exists but no longer suffices  c) For new features, fixed faults and security — and because newer work demands newer versions  d) 'This is being installed so that … can be done, which cannot be done now'
**Answer: d) 'This is being installed so that … can be done, which cannot be done now'**

**5. (Sub lesson 1) Is habit a reason to install?**
a) No — installation answers a gap, never a whim  b) A shortfall — the capability exists but no longer suffices  c) For new features, fixed faults and security — and because newer work demands newer versions  d) When speed, capacity or reliability fall behind the work
**Answer: a) No — installation answers a gap, never a whim**

**6. (Sub lesson 2) What does upgrading answer?**
a) For new features, fixed faults and security — and because newer work demands newer versions  b) A shortfall — the capability exists but no longer suffices  c) When speed, capacity or reliability fall behind the work  d) Before it takes the data with it
**Answer: b) A shortfall — the capability exists but no longer suffices**

**7. (Sub lesson 2) Why is software upgraded?**
a) When speed, capacity or reliability fall behind the work  b) Before it takes the data with it  c) For new features, fixed faults and security — and because newer work demands newer versions  d) A stated reason, a chosen time, and the old state safe to return to
**Answer: c) For new features, fixed faults and security — and because newer work demands newer versions**

**8. (Sub lesson 2) Why is hardware upgraded?**
a) Before it takes the data with it  b) A stated reason, a chosen time, and the old state safe to return to  c) A gap — a capability the machine does not yet have  d) When speed, capacity or reliability fall behind the work
