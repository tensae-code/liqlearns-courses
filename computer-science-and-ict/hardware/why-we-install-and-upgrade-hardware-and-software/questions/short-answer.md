# Why We Install and Upgrade Hardware and Software — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does installing answer?**
**Answer: A gap — a capability the machine does not yet have**

**2. (Sub lesson 1) Give a hardware-install reason.**
**Answer: A printer where none was; more memory where programs starve; a larger disk where data outgrew the old**

**3. (Sub lesson 1) Give a software-install reason.**
**Answer: A job needs a program the machine does not carry**

**4. (Sub lesson 1) What sentence must an installer finish?**
**Answer: 'This is being installed so that … can be done, which cannot be done now'**

**5. (Sub lesson 1) Is habit a reason to install?**
**Answer: No — installation answers a gap, never a whim**

**6. (Sub lesson 2) What does upgrading answer?**
**Answer: A shortfall — the capability exists but no longer suffices**

**7. (Sub lesson 2) Why is software upgraded?**
**Answer: For new features, fixed faults and security — and because newer work demands newer versions**

**8. (Sub lesson 2) Why is hardware upgraded?**
**Answer: When speed, capacity or reliability fall behind the work**

**9. (Sub lesson 2) Why replace a failing drive early?**
**Answer: Before it takes the data with it**

**10. (Sub lesson 2) What three guards does Fiji put on any change?**
**Answer: A stated reason, a chosen time, and the old state safe to return to**
