# Why We Install and Upgrade Hardware and Software — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does installing answer?" is: A gap — a capability the machine does not yet have**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Give a hardware-install reason." is: A job needs a program the machine does not carry**
**Answer: False** — A printer where none was; more memory where programs starve; a larger disk where data outgrew the old

**3. (Sub lesson 1) True or false: the answer to "Give a software-install reason." is: A job needs a program the machine does not carry**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What sentence must an installer finish?" is: No — installation answers a gap, never a whim**
**Answer: False** — 'This is being installed so that … can be done, which cannot be done now'

**5. (Sub lesson 1) True or false: the answer to "Is habit a reason to install?" is: No — installation answers a gap, never a whim**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does upgrading answer?" is: For new features, fixed faults and security — and because newer work demands newer versions**
**Answer: False** — A shortfall — the capability exists but no longer suffices

**7. (Sub lesson 2) True or false: the answer to "Why is software upgraded?" is: For new features, fixed faults and security — and because newer work demands newer versions**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Why is hardware upgraded?" is: Before it takes the data with it**
**Answer: False** — When speed, capacity or reliability fall behind the work

**9. (Sub lesson 2) True or false: the answer to "Why replace a failing drive early?" is: Before it takes the data with it**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What three guards does Fiji put on any change?" is: A gap — a capability the machine does not yet have**
**Answer: False** — A stated reason, a chosen time, and the old state safe to return to
