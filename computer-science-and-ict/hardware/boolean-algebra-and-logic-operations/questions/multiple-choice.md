# Boolean Algebra and Logic Operations — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) A Boolean variable can hold —**
a) Any number  b) Only 0 or 1  c) 0, 1 or 2  d) Only letters
**Answer: b) Only 0 or 1** — Boolean algebra has exactly two values: 0 and 1 (false and true).

**2. (Sub lesson 1) In Boolean algebra, 1 + 1 equals —**
a) 2  b) 10  c) 1  d) 0
**Answer: c) 1** — The + is logical addition (OR): at least one input is 1, so the result is 1. There is no 2 in this algebra.

**3. (Sub lesson 1) AND gives 1 when —**
a) At least one input is 1  b) All inputs are 1  c) The inputs are different  d) One input is 0
**Answer: b) All inputs are 1** — AND is 'all': a single 0 input makes the output 0.

**4. (Sub lesson 2) XOR gives 1 when the inputs are —**
a) Both 1  b) Both 0  c) Different  d) The same
**Answer: c) Different** — XOR is 'one or the other but not both': 0⊕1 = 1 and 1⊕0 = 1, while 1⊕1 = 0.

**5. (Sub lesson 2) A truth table for an expression with 4 inputs has how many rows?**
a) 4  b) 8  c) 16  d) 32
**Answer: c) 16** — The row count is 2ⁿ: 2⁴ = 16 rows.

**6. (Sub lesson 2) For Y = A · B̄, the output is 1 only on the row —**
a) A = 0, B = 0  b) A = 0, B = 1  c) A = 1, B = 0  d) A = 1, B = 1
**Answer: c) A = 1, B = 0** — AND needs all inputs 1: A must be 1 and B̄ must be 1, so B = 0. Only the row A = 1, B = 0 gives 1.
