# Boolean Algebra and Logic Operations — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) In Boolean algebra, OR and ordinary addition always give the same result.**
**Answer: False** — They differ at 1 + 1: ordinary addition gives 2, OR gives 1.

**2. (Sub lesson 1) NOT has one input and its output is always the opposite of the input.**
**Answer: True** — Negation flips the single value: NOT 0 = 1, NOT 1 = 0.

**3. (Sub lesson 2) XOR and OR have exactly the same truth table.**
**Answer: False** — They differ on one row: 1 OR 1 = 1, but 1 XOR 1 = 0.

**4. (Sub lesson 2) Two expressions with the same truth table do exactly the same job.**
**Answer: True** — The truth table is the complete behaviour; same table, same behaviour, whatever the expressions look like.
