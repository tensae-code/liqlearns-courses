# Boolean Algebra and Logic Operations — short answer

Answer in your own words, in one or two sentences.

**1. (Sub lesson 1) Say in words how OR and AND differ, and give the one row where each is easiest to tell apart.**
**Answer: OR gives 1 when at least one input is 1; AND gives 1 only when all inputs are 1. The row A = 1, B = 0 separates them: OR gives 1 there, AND gives 0.**

**2. (Sub lesson 2) Why is a truth table a complete description of an operation?**
**Answer: Because it lists every input combination that can ever occur and the output for each one; nothing about the operation's behaviour is left out, so two operations with the same table are the same behaviour.**
