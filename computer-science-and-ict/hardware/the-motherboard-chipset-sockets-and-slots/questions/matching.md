# The Motherboard — Chipset, Sockets and Slots — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What directs the motherboard's work?** → **Its chipset — the set of controller chips**

**2. (Sub lesson 1) What does the chipset manage?** → **The flow of data between processor, memory and the other parts**

**3. (Sub lesson 1) What are the board's pathways called?** → **Buses**

**4. (Sub lesson 1) Why does the chipset decide compatibility?** → **It decides which processors and memory the board can work with**

**5. (Sub lesson 2) What holds the processor?** → **The CPU socket, shaped for one processor family**

**6. (Sub lesson 2) Where do RAM modules go?** → **In the memory slots, clicked in by their edges**

**7. (Sub lesson 2) What do expansion slots take?** → **Extra cards — display, sound, network**

**8. (Sub lesson 2) What is the installer's first question about a part?** → **Does it fit this socket, this slot?**
