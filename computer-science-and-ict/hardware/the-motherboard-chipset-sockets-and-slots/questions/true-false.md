# The Motherboard — Chipset, Sockets and Slots — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Its chipset — the set of controller chips**
**Answer: True**

**2. (Sub lesson 1) True or false: Buses** — as the answer to: What does the chipset manage?
**Answer: False — The flow of data between processor, memory and the other parts**

**3. (Sub lesson 1) True or false: Buses**
**Answer: True**

**4. (Sub lesson 1) True or false: The CPU socket, shaped for one processor family** — as the answer to: Why does the chipset decide compatibility?
**Answer: False — It decides which processors and memory the board can work with**

**5. (Sub lesson 2) True or false: The CPU socket, shaped for one processor family**
**Answer: True**

**6. (Sub lesson 2) True or false: Extra cards — display, sound, network** — as the answer to: Where do RAM modules go?
**Answer: False — In the memory slots, clicked in by their edges**

**7. (Sub lesson 2) True or false: Extra cards — display, sound, network**
**Answer: True**

**8. (Sub lesson 2) True or false: Laos Grade 8 ICT, Chapter 1 §1.3** — as the answer to: What is the installer's first question about a part?
**Answer: False — Does it fit this socket, this slot?**

**9. (Sub lesson 2) True or false: Laos Grade 8 ICT, Chapter 1 §1.3**
**Answer: True**

**10. (Sub lesson 1) True or false: Its chipset — the set of controller chips** — as the answer to: Why must a CPU and a board be chosen for each other?
