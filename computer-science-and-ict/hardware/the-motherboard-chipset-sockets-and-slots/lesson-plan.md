## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The chipset — the board's traffic direction** — The motherboard's work is directed by its **chipset**: the set of controller chips that **manage the flow of data between the processor, memory and the other parts**. Every journey inside the machine — a keystroke to the CPU, a picture to the screen — passes under the chipset's direction, along the board's pathways (its **buses**). The chipset a board carries decides which processors and memory it can work with, so it is the board's character, not just its wiring.
2. **Sockets and slots — where parts plug in** — Parts join the board at three kinds of fitting. The **CPU socket** holds the processor — shaped for one family of processors, which is why a CPU and a board must be chosen for each other. **Memory slots** take the RAM modules, clicked in by their edges. **Expansion slots** take extra cards — display, sound, network — that grow what the machine can do. Laos teaches the fittings by name because the installer's first question about any part is the board's question: does it fit this socket, this slot?
