# Lesson plan — Storage devices — keeping data

**Course:** Computer Science and ICT · **Title:** Hardware · **Lesson:** Storage devices — keeping data
**Place in the curriculum:** Unit 2 — Computer Hardware — in the title Hardware on the ICT course ladder (TITLES.md).
**The one thing this lesson teaches:** A storage device stores data temporarily or permanently: primary storage (main memory) holds current data, programs and instructions the processor needs now, while secondary storage keeps data permanently.
**This lesson's own level:** It stands on Output devices: the last hardware family — the keeping family — opens here with its great divide.
