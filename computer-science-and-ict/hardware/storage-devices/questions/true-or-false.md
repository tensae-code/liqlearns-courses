# Storage devices — keeping data — true or false

Say whether each statement is true or false.

**1. Storage devices are one of the four hardware families.**
**Answer: True**

**2. Primary and secondary storage do the same job.**
**Answer: False** — Primary holds for now; secondary keeps permanently.

**3. Programs the processor is running now sit in primary storage.**
**Answer: True**

**4. Secondary storage is temporary.**
**Answer: False** — Secondary storage keeps data permanently.
