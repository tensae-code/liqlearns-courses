# Storage devices — keeping data — multiple choice

Pick the one right answer.

**1. A storage device —**
a) stores data temporarily or permanently  b) only prints data  c) only shows data
**Answer: a) stores data temporarily or permanently**

**2. Primary storage is also called —**
a) main memory  b) the cupboard  c) secondary storage
**Answer: a) main memory**

**3. Primary storage holds —**
a) only old files  b) current data, programs and instructions the processor needs now  c) nothing
**Answer: b) current data, programs and instructions the processor needs now**

**4. Secondary storage —**
a) keeps data permanently  b) loses everything at switch-off  c) holds only this second's sum
**Answer: a) keeps data permanently**

**5. The lesson's picture for primary storage is —**
a) a now shelf  b) a keep-for-good cabinet  c) a printer
**Answer: a) a now shelf**
