# Processing devices — the CPU, the brain of the computer — multiple choice

Pick the one right answer.

**1.** Data from an input device must be — before it goes to an output device.
a) Stored forever  b) Processed  c) Printed  d) Deleted
**Answer: b) Processed** — Data must be processed before it goes to an output device.

**2.** A processing device converts data into —
a) Paper  b) Useful information  c) Heat  d) Sound only
**Answer: b) Useful information** — A processing device converts data into useful information.

**3.** The CPU is called —
a) The hand of the computer  b) The brain of the computer  c) The eye of the computer  d) The memory of the computer
**Answer: b) The brain of the computer** — The CPU is the brain of the computer.

**4.** CPU speed is measured in —
a) Metres  b) Hertz (Hz)  c) Litres  d) Birr
**Answer: b) Hertz (Hz)** — Its speed is measured in hertz.

**5.** One hertz is —
a) One cycle per second  b) One file per folder  c) One key per keyboard  d) One page per minute
**Answer: a) One cycle per second** — One hertz = one cycle per second.
