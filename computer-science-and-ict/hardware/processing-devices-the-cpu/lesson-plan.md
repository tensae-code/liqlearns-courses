# Lesson plan — Processing devices — the CPU, the brain of the computer

**Course:** Computer Science and ICT · **Title:** Hardware · **Lesson:** Processing devices — the CPU, the brain of the computer
**Place in the curriculum:** Title 2 — Hardware of the Computer Science and ICT ladder (TITLES.md); Ethiopia Grade 8, Unit 2 — Computer Hardware.
**The one thing this lesson teaches:** data from an input device must be processed before it reaches an output device — and the main processing device is the CPU, the brain of the computer, whose speed is measured in hertz.
**This lesson's own level:** it stands on the input lessons and Unit 1's processing function: now the physical device that does the processing.

## If the learner is stuck
- Thinks the CPU is the whole box → the CPU is the processor chip inside; the box holds many parts.
- Thinks hertz measures size → hertz measures speed: one hertz = one cycle per second.
