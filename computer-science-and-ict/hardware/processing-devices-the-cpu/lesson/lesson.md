## Processing devices

Data from an input device must be processed before it goes to an output device. A processing device converts data into useful information — it is the middle of the flow you learned in Unit 1, in physical form.

[Picture 10942 — processing devices]

## The CPU — the brain

The CPU (processor) is the main processing device — the brain of the computer. It performs instructions in response to commands. Its speed is measured in hertz (Hz): one hertz is one cycle per second. A faster CPU completes more cycles — more instruction steps — every second.
