# Combinational and Sequential Logic Circuits — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Only on the inputs it holds now — no memory of before**
**Answer: True**

**2. (Sub lesson 1) True or false: XOR for the sum, AND for the carry** — as the answer to: What does a half-adder add?
**Answer: False — Two bits, into a sum and a carry**

**3. (Sub lesson 1) True or false: XOR for the sum, AND for the carry**
**Answer: True**

**4. (Sub lesson 1) True or false: Add whole numbers, place by place** — as the answer to: What does a full-adder add?
**Answer: False — Three bits — two bits and the carry-in**

**5. (Sub lesson 1) True or false: Add whole numbers, place by place**
**Answer: True**

**6. (Sub lesson 2) True or false: A circuit holding one bit, set and reset by its inputs, keeping it until told to change** — as the answer to: What does a sequential output depend on?
**Answer: False — Its inputs and what it remembers — its stored state**

**7. (Sub lesson 2) True or false: A circuit holding one bit, set and reset by its inputs, keeping it until told to change**
**Answer: True**

**8. (Sub lesson 2) True or false: Pulses, in binary — each flip-flop a place** — as the answer to: What do chained flip-flops become?
**Answer: False — Counters (and registers)**

**9. (Sub lesson 2) True or false: Pulses, in binary — each flip-flop a place**
**Answer: True**

**10. (Sub lesson 2) True or false: Only on the inputs it holds now — no memory of before** — as the answer to: The one question that sorts any circuit is what?
**Answer: False — Does it remember?**
