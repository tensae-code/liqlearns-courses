# Optical disks — pits, lands and the three CDs — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** An optical disk is read and written by —
a) A magnet  b) Laser light  c) A needle  d) Ink
**Answer: b) Laser light** — Optical disks are read and written by laser light.

**2. (Sub lesson 1)** The burned part of the surface is the —
a) Land, representing 0  b) Pit, representing 1  c) Track  d) Sector
**Answer: b) Pit, representing 1** — The burned part is the pit, representing 1; land (unburned) represents 0.

**3. (Sub lesson 1)** Land represents —
a) 1  b) 0  c) A letter  d) An error
**Answer: b) 0** — Land represents 0.

**4. (Sub lesson 2)** A CD stores — on one side.
a) 700 MB  b) 4.7 GB  c) 1 TB  d) 700 GB
**Answer: a) 700 MB** — A CD stores 700 MB on one side.

**5. (Sub lesson 2)** CD-R is also called WORM because it is —
a) Shaped like a worm  b) Write once, read many times  c) Written by hand  d) Erasable daily
**Answer: b) Write once, read many times** — CD-R: write once, then read many times — WORM.

**6. (Sub lesson 2)** Which CD can be written and erased as many times as wanted?
a) CD-ROM  b) CD-R  c) CD-RW  d) None
**Answer: c) CD-RW** — CD-RW is the erasable optical disc.

**7. (Sub lesson 2)** CD-ROM data can be —
a) Written and erased freely  b) Only read, never written or erased  c) Written once  d) Burned by hand
**Answer: b) Only read, never written or erased** — CD-ROM is read only.
