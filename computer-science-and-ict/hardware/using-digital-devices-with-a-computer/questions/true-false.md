# Using Digital Devices with a Computer — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does a digital camera capture?" is: Photographs in digital form.**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does a webcam capture?" is: Capture on the device, transfer to the computer, check, process, then save as a named file.**
**Answer: False** — Moving pictures of what is in front of the computer, sent while it is used.

**3. (Sub lesson 1) True or false: the answer to "Why is capturing only the first step?" is: Because the captured material must still be transferred, checked, processed and saved on the computer.**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How are a device and a computer usually connected?" is: Open the transferred material and check it arrived whole.**
**Answer: False** — By a cable to the computer, or without wires.

**5. (Sub lesson 1) True or false: the answer to "What lets the computer speak to a connected device?" is: The driver and program that came for the device.**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is the joint-work order in this lesson?" is: So the file can be found again later.**
**Answer: False** — Capture on the device, transfer to the computer, check, process, then save as a named file.

**7. (Sub lesson 2) True or false: the answer to "How does a webcam's timing differ from a camera's?" is: A webcam sends pictures while you use it; a camera stores them first.**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What should you do right after a transfer?" is: Moving pictures of what is in front of the computer, sent while it is used.**
**Answer: False** — Open the transferred material and check it arrived whole.

**9. (Sub lesson 2) True or false: the answer to "What does processing a photograph mean here?" is: Working on it on the computer, for example cropping it.**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why save with a clear file name?" is: By a cable to the computer, or without wires.**
**Answer: False** — So the file can be found again later.
