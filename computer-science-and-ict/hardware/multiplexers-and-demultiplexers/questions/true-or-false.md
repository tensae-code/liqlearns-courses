# Multiplexers and Demultiplexers — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) The unselected inputs of a multiplexer have no effect on its output.**
**Answer: True** — Only the input chosen by the select code is connected through; the others are cut off by their closed AND gates.

**2. (Sub lesson 1) A multiplexer can also generate a switching function of its select lines when its data inputs are fixed at 0s and 1s.**
**Answer: True** — With the select lines as variables, the pattern of fixed inputs chooses which function appears at Y.

**3. (Sub lesson 2) In a demultiplexer, every output copies the input, and the select lines choose which copy is loudest.**
**Answer: False** — Only the selected output copies the input; all other outputs are held at 0.

**4. (Sub lesson 2) Multiplexing lets several conversations share one transmission line by taking turns.**
**Answer: True** — The MUX picks whose data travels and the DEMUX delivers it, switching fast enough that each pair seems to own the line.
