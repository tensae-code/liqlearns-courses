# Multiplexers and Demultiplexers — short answer

Answer in your own words, in one or two sentences.

**1. (Sub lesson 1) Why is the multiplexer fairly called 'a rotary switch with a digital hand'?**
**Answer: Like a rotary switch it connects exactly one of several inputs to a single output. The 'hand' that turns it is not mechanical but the binary code on the select lines — change the code and the switch jumps to another input instantly.**

**2. (Sub lesson 2) A school has one expensive printer port line running to four rooms... explain with MUX/DEMUX thinking what is wrong with this sentence: 'We use a demultiplexer at the computer to choose which room's data comes in.'**
**Answer: Choosing among several incoming sources to feed one line is the multiplexer's direction (many inputs, one output). A demultiplexer does the opposite (one input delivered to one of many outputs). The sentence swaps them: the computer end needs a MUX to select the room; a DEMUX would be the choice at the far end if one computer's output had to be delivered to one of several rooms.**
