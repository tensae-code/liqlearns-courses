# Multiplexers and Demultiplexers — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 1) The short name for a multiplexer is ____.**
**Answer: MUX** — And the demultiplexer is the DEMUX.

**2. (Sub lesson 1) A 16-to-1 multiplexer needs ____ select lines.**
**Answer: 4** — 2⁴ = 16 inputs are named by a 4-bit select code.

**3. (Sub lesson 2) In a 1-to-4 DEMUX, the outputs that are not selected stay at ____.**
**Answer: 0** — Only the selected output follows the data input.

**4. (Sub lesson 2) Inside the multiplexer, the selected input passes because its ____ gate is opened by the select pattern.**
**Answer: AND** — One AND gate per input, enabled by exactly one select pattern; the opened gate passes its input to the OR gate.
