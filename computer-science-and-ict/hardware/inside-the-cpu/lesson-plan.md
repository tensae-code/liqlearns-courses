# Lesson plan — Inside the CPU — ALU, control unit, registers

**Course:** Computer Science and ICT · **Title:** Hardware · **Lesson:** Inside the CPU — ALU, control unit, registers
**Place in the curriculum:** Unit 2 — Computer Hardware — in the title Hardware on the ICT course ladder (TITLES.md).
**The one thing this lesson teaches:** The ALU performs arithmetic and logical operations; the control unit controls and directs the whole system's operation; registers are the CPU's small, high-speed memory holding temporary results and control information.
**This lesson's own level:** It stands on The CPU — the brain of the computer: the three named components are now taken one by one.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The ALU — works out and compares** — Arithmetic operations — add, subtract, multiply, divide — and logical operations: comparing numbers, letters and special characters.
2. **The control unit — directs everything** — The unit that controls and directs the whole system's operation.
3. **Registers — hold things for a moment** — The CPU's small, high-speed memory, holding temporary results and control information — not permanent storage.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## What the learner can do when it ends
1. State the ALU's two operation families, with examples of each.
2. Say what the control unit does: controls and directs the whole system's operation.
3. Say what registers are — small, high-speed memory for temporary results and control information — and correct the common mistake: registers, not the ALU, hold temporary results.
