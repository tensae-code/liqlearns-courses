# Inside the CPU — ALU, control unit, registers — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Multiply and divide are arithmetic operations of the ALU.**
**Answer: True**

**2. (Sub lesson 2) The control unit calculates the answers itself.**
**Answer: False** — It directs; the ALU calculates.

**3. (Sub lesson 3) Registers are high-speed memory.**
**Answer: True**

**4. (Sub lesson 3) Registers keep data permanently.**
**Answer: False** — They hold things temporarily, for a moment.
