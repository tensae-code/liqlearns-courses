# Keyboard and mouse — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) The keyboard enters data letter by letter.**
**Answer: True**

**2. (Sub lesson 2) Clicking an icon chooses it.**
**Answer: True**

**3. (Sub lesson 2) The mouse is used for typing long essays.**
**Answer: False** — Typing is the keyboard's job; the mouse points, clicks and moves.

**4. (Sub lesson 1) The mouse is an input device.**
**Answer: True** — Both devices in this lesson are input devices.
