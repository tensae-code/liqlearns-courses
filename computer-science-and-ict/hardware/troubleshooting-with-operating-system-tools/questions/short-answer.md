# Troubleshooting With Operating System Tools — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) Name five tools in the kit.**
**Answer: Built-in troubleshooters, Task Manager, Event Viewer, Device Manager, System Information/diagnostics**

**2. (Sub lesson 1) What do the built-in troubleshooters do?**
**Answer: Ask, test and repair common faults, guided**

**3. (Sub lesson 1) What is Task Manager called?**
**Answer: The crawling system's confession — what runs and what eats resources**

**4. (Sub lesson 1) What is Event Viewer?**
**Answer: The system's diary — errors and warnings timestamped**

**5. (Sub lesson 1) What names the guilty device?**
**Answer: Device Manager's yellow mark**

**6. (Sub lesson 2) Why read before repairing?**
**Answer: A restart burns the evidence**

**7. (Sub lesson 2) When is evidence gathered?**
**Answer: While the fault is present**

**8. (Sub lesson 2) To what are reports matched?**
**Answer: The unit's fault tables — hardware and software families**

**9. (Sub lesson 2) How is a fix verified?**
**Answer: By the same tool that found the fault**

**10. (Sub lesson 2) What is the professional's difference?**
**Answer: Evidence discipline with ordinary tools**
