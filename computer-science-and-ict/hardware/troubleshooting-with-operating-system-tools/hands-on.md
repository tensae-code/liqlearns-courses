# Hands-on — Troubleshooting With Operating System Tools

The lesson with your hands and your feet, not only your eyes.

## Task one
**Open the kit** — On a Windows machine (or from descriptions), open each of the five tools and record one real fact each reports about that machine.

## Task two
**Evidence file** — For one real or invented fault, write the evidence file: the two tool reports you would gather before touching anything, and the fault family each points to.
