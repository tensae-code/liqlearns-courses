# Watching performance — Task Manager

## Do it first

A computer has gone slow and hot, and no part is flagged anywhere. You need to SEE what it is straining at, live. Write the keys you would press first. Then follow the book's route exactly.

## Sub lesson 1 — Diagnostic tools — and the book's route in

**Diagnostic tools are software for diagnosing hardware problems.** Manufacturers supply their own — the book's example is a hard-drive maker's **boot-and-test tool** for its drives.

Of the book's top two tools, **Performance Monitor** gives a **quick view** of the machine. Reach it in the book's order:

1. Press **Ctrl + Alt + Delete** together.
2. Choose **Task Manager**.
3. Open the **Performance tab**.

[Picture 17709 — the Performance tab with CPU, memory, disk and network graphs labelled]

## Sub lesson 2 — The quick view — and two carried notes

The Performance tab shows four live measures: **CPU, memory, disk and Ethernet** — each with its own graph, rising and falling as the machine works.

Two notes travel with the tool:

- **Restarting clears unwanted temporary load** — a slow machine with no fault found may simply need a restart.
- An application sitting **near 100% CPU** should be **disabled and started again**.
