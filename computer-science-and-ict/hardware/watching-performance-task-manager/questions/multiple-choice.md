# Watching performance — Task Manager — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Diagnostic tools are —
a) hardware parts  b) software for diagnosing hardware problems  c) antivirus names  d) beep patterns
**Answer: b) software for diagnosing hardware problems** — software that diagnoses hardware.

**2. (Sub lesson 1)** The route to the Performance tab is —
a) search box, then Performance  b) Ctrl+Alt+Delete, Task Manager, Performance tab  c) Control Panel, then Performance  d) BIOS, then Performance
**Answer: b) Ctrl+Alt+Delete, Task Manager, Performance tab** — the book's three steps.

**3. (Sub lesson 1)** A hard-drive maker's boot-and-test tool is the book's example of —
a) a virus  b) a manufacturer-supplied diagnostic tool  c) a beep code  d) a backup
**Answer: b) a manufacturer-supplied diagnostic tool** — makers supply their own tools.

**4. (Sub lesson 2)** The Performance tab shows —
a) CPU, memory, disk and Ethernet  b) only the CPU  c) the device list  d) the error log
**Answer: a) CPU, memory, disk and Ethernet** — the four live measures.

**5. (Sub lesson 2)** Restarting a machine —
a) damages the disk  b) clears unwanted temporary load  c) deletes backups  d) changes BIOS settings
**Answer: b) clears unwanted temporary load** — the first carried note.

**6. (Sub lesson 2)** An application near 100% CPU should be —
a) left alone  b) disabled and started again  c) deleted at once  d) given more memory by hand
**Answer: b) disabled and started again** — the second carried note.

**7. (Sub lesson 3)** A computer is completely frozen. The guide's FIRST rescue is — (teacher guide — evidence)
a) unplug the power cable  b) open Task Manager with Ctrl+Alt+Delete and restart Windows Explorer  c) remove the battery  d) hold the power button
**Answer: b) open Task Manager with Ctrl+Alt+Delete and restart Windows Explorer** — Explorer sits in the Processes tab (Grade 12 Teacher Guide, printed pp. 104–105).

**8. (Sub lesson 3)** The guide's second frozen-computer step is — (teacher guide — evidence)
a) restart Explorer again  b) press and hold the power button for 5 to 10 seconds  c) unplug at once  d) close one application
**Answer: b) press and hold the power button for 5 to 10 seconds** — force shutdown, only after the Explorer restart fails.

**9. (Sub lesson 3)** Unplugging the power cable is — (teacher guide — evidence)
a) the first step  b) never allowed  c) the last resort, after the other options  d) a weekly habit
**Answer: c) the last resort, after the other options** — or remove a laptop's battery, likewise last.
