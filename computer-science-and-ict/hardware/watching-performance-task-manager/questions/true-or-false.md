# Watching performance — Task Manager — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Performance Monitor gives a quick view, not the deepest one.
**Answer: True** — the deeper look is Resource Monitor, next lesson.

**2. (Sub lesson 2)** You must buy Performance Monitor before using it.
**Answer: False** — it is reached through Task Manager, already in Windows.

**3. (Sub lesson 2)** Ethernet is one of the four measures on the Performance tab.
**Answer: True** — CPU, memory, disk, Ethernet.
