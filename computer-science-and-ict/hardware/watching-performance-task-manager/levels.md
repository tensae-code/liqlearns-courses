# Watching performance — Task Manager — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure — README, "Units, Lessons and Sub Lessons"). Practice is tied to the learner's skill number, as before. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Diagnostic tools — and the book's route in
Sub lesson 1 questions from the type files. Pass mark: the learner can state and use what this part teaches — Diagnostic tools are software for diagnosing hardware problems; makers supply their own. The book's route: Ctrl+Alt+Delete together, choose Task Manager, open the Performance tab.

## Sub lesson 2 — The quick view — and two carried notes
Sub lesson 2 questions from the type files. Pass mark: the learner can state and use what this part teaches — CPU, memory, disk and Ethernet at a glance. Restarting clears unwanted temporary load; an application near 100% CPU should be disabled and started again.


## Sub lesson 3 — Restarting Windows Explorer when the computer freezes (Grade 12 teacher guide — evidence)
Sub lesson 3 questions from the type files. Pass mark: the learner can state and use what this part teaches — For a completely frozen computer: Ctrl+Alt+Delete → Task Manager → Processes tab → restart Windows Explorer; then hold the power button 5–10 seconds; unplug (or remove a laptop battery) last resort only (Grade 12 Teacher Guide, printed pp. 104–105 — teacher evidence).
