# Video script — Watching performance — Task Manager

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then. Short script; the placement names no full video need for this lesson.

---

The machine is slow. Nothing is flagged.
Time to watch it work.

Three keys together: Control, Alt, Delete.
Choose Task Manager. Open Performance.

Four graphs, live:
CPU. Memory. Disk. Ethernet.

One app near a hundred percent?
Disable it. Start it again.
Nothing guilty? Restart —
a restart clears the temporary load.
