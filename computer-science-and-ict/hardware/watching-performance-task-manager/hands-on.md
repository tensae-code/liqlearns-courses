# Hands-on — Watching performance — Task Manager

The lesson with your hands, not only your eyes.

## Open the Performance tab
On a school computer: Ctrl+Alt+Delete, Task Manager, Performance. Read the four graphs aloud. Open a program and watch which graph moves most.

## Spot the strain
Your teacher loads the machine (or describes the graphs). Point to the measure under strain and say which carried note — restart, or disable and restart the app — fits, and why.
