# A Computer's Technical and Programmed Resources — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The hardware estate — processor, memory and devices, with their measures**
**Answer: True**

**2. (Sub lesson 1) True or false: The hardware estate — processor, memory and devices, with their measures** — as the answer to: How is the processor measured?
**Answer: False — By clock frequency, word length and instruction set**

**3. (Sub lesson 1) True or false: A resource — memory too small, a processor too slow**
**Answer: True**

**4. (Sub lesson 1) True or false: A resource — memory too small, a processor too slow** — as the answer to: Are technical resources infinite?
**Answer: False — No — they are finite and priced**

**5. (Sub lesson 1) True or false: Listing its resources with their numbers, not its advertisements**
**Answer: True**

**6. (Sub lesson 2) True or false: Listing its resources with their numbers, not its advertisements** — as the answer to: What are programmed resources?
**Answer: False — The software estate — system software and application software**

**7. (Sub lesson 2) True or false: Making the hardware usable — the operating system and utilities**
**Answer: True**

**8. (Sub lesson 2) True or false: Making the hardware usable — the operating system and utilities** — as the answer to: How do the estates relate?
**Answer: False — They multiply each other — hardware without software is inert; software without hardware is a text**

**9. (Sub lesson 2) True or false: By both estates together**
**Answer: True**

**10. (Sub lesson 2) True or false: By both estates together** — as the answer to: What two questions judge any machine?
**Answer: False — What does it have (technical), and what does it run (programmed)?**
