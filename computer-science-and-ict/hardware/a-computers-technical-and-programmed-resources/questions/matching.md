# A Computer's Technical and Programmed Resources — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What are technical resources?** → **The hardware estate — processor, memory and devices, with their measures**

**2. (Sub lesson 1) How is the processor measured?** → **By clock frequency, word length and instruction set**

**3. (Sub lesson 1) What does a machine usually lack when it cannot do a job?** → **A resource — memory too small, a processor too slow**

**4. (Sub lesson 1) Are technical resources infinite?** → **No — they are finite and priced**

**5. (Sub lesson 1) What does naming a machine honestly mean?** → **Listing its resources with their numbers, not its advertisements**

**6. (Sub lesson 2) What are programmed resources?** → **The software estate — system software and application software**

**7. (Sub lesson 2) What is system software's job?** → **Making the hardware usable — the operating system and utilities**

**8. (Sub lesson 2) How do the estates relate?** → **They multiply each other — hardware without software is inert; software without hardware is a text**

**9. (Sub lesson 2) How is a computer's capability for a job judged?** → **By both estates together**

**10. (Sub lesson 2) What two questions judge any machine?** → **What does it have (technical), and what does it run (programmed)?**
