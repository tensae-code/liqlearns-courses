# Fixing sound that is not working — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A player can be silent while the computer's volume is up.
**Answer: True**

**2. (Sub lesson 2)** The driver is the first thing to check when sound fails.
**Answer: False**

**3. (Sub lesson 2)** A driver can also be obtained as the latest version for the current operating system from a reputable source.
**Answer: True**
