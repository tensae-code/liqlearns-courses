# Lesson plan — Uninstalling software on a PC

**Course:** Computer Science and ICT · **Title:** Hardware · **Lesson:** Uninstalling software on a PC
**Place in the curriculum:** Unit 5 — Maintenance and Troubleshooting (CURRICULUM.md).
**The one thing this lesson teaches:** Uninstalling on a PC is one fixed procedure through Control Panel and Programs and Features — done properly, it frees space and speed; done by deleting icons, it does neither.
**This lesson's own level:** It stands on Installing software on a PC: uninstalling is installing in reverse, through the system's own route.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
1. **Why uninstall — and whose machine it is** — the gains — freed space and speed; proper uninstalling only; permission on shared or another person's machine; the guide's approval rule and layout warning (teacher evidence).
2. **The procedure — Control Panel to removed** — Control Panel; Uninstall a Program; select in Programs and Features; Uninstall/Change; the UAC prompt; on-screen instructions to the end.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Installing software on a PC, in this same title. Recommended, never forced — a learner may land on this lesson directly, and it stands alone.

## What the learner can do when it ends
1. Say what uninstalling frees and what it speeds up.
2. Carry out the six-step uninstall procedure in order.
3. State the permission rule for shared and other people's machines.

## What you need
A Windows school computer if available — paper works too, screen by screen. Paper and a pencil. On a school or shared machine, the owner's or technician's permission first.

## If the learner is stuck
- Deletes icons and folders by hand → that leaves the program installed; use Programs and Features so the system removes it properly.
- Cannot find the program → the Programs and Features window lists ALL installed software; look there, not on the desktop.
