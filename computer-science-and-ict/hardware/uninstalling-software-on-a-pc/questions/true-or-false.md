# Uninstalling software on a PC — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Deleting a program's icon uninstalls the program.
**Answer: False**

**2. (Sub lesson 2)** The on-screen directions during removal vary by program.
**Answer: True**

**3. (Sub lesson 2)** Programs and Features lists all installed software.
**Answer: True**
