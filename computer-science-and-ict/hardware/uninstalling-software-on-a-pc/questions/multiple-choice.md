# Uninstalling software on a PC — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Uninstalling unused programs frees —
a) screen brightness  b) hard-drive space, and increases speed  c) internet data  d) battery charge
**Answer: b) hard-drive space, and increases speed**

**2. (Sub lesson 1)** On a school or library computer, before uninstalling you —
a) act quickly and quietly  b) consult a technician or the owner  c) delete the icons first  d) ask another pupil only
**Answer: b) consult a technician or the owner**

**3. (Sub lesson 2)** The first step of the procedure is —
a) click Uninstall/Change  b) open the Control Panel  c) select the program  d) restart the computer
**Answer: b) open the Control Panel**

**4. (Sub lesson 2)** "Uninstall a Program" sits under which heading?
a) System  b) Hardware  c) Programs  d) Network
**Answer: c) Programs**

**5. (Sub lesson 2)** In Programs and Features you —
a) select the program, then click Uninstall/Change  b) delete the window  c) rename the program  d) close the list
**Answer: a) select the program, then click Uninstall/Change**

**6. (Sub lesson 2)** The User Account Control prompt is answered with —
a) the program's serial number  b) the administrator password or Continue  c) a disc swap  d) the owner's phone number
**Answer: b) the administrator password or Continue**
