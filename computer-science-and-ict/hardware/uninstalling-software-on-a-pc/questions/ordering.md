# Uninstalling software on a PC — ordering

Put the steps in the right order.

**1. (Sub lesson 2)** These steps are mixed up. Write them in the right order:

- Click Uninstall/Change
- Open the Control Panel
- Follow the on-screen instructions
- Click "Uninstall a Program"
- Select the program in Programs and Features
- Answer the User Account Control prompt

**Answer (right order):** Open the Control Panel → Click "Uninstall a Program" → Select the program in Programs and Features → Click Uninstall/Change → Answer the User Account Control prompt → Follow the on-screen instructions
