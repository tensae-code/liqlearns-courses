# Browsers and search engines — multiple choice

Pick the one right answer.

**1.** A browser is software for —
a) exploring the internet  b) cleaning the computer  c) writing only  d) making passwords
**Answer: a) exploring the internet** — locating and viewing pages, moving between them.

**2.** A search engine —
a) shows the pages  b) speeds up searching for information  c) is a cable  d) prints pages
**Answer: b) speeds up searching for information** — it speeds the search.

**3.** Google and Yahoo are the book's examples of —
a) browsers  b) search engines  c) websites  d) networks
**Answer: b) search engines** — search engines.

**4.** Moving from page to page is the job of —
a) the browser  b) the search engine  c) the status bar  d) the printer
**Answer: a) the browser** — the browser moves you.

**5.** You do not know a site's address, only its topic. First tool?
a) The printer  b) A search engine  c) The ruler  d) The desktop
**Answer: b) A search engine** — ask the guide first, then travel.

**6.** Viewing a web page happens in —
a) the browser  b) the search engine's office  c) a word processor  d) the Commander window
**Answer: a) the browser** — pages are viewed in the browser.
