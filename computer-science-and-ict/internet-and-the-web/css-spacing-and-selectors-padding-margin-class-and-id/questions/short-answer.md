# CSS — Spacing and Selectors: Padding, Margin, Class and ID — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does a selector do?**
**Answer: Names what a style rule hits**

**2. (Sub lesson 1) What does a class selector hit?**
**Answer: Every element wearing that class — the reusable uniform**

**3. (Sub lesson 1) What does an id selector hit?**
**Answer: The one element carrying that id — the named individual**

**4. (Sub lesson 1) What is choosing a selector, really?**
**Answer: Choosing the style's reach**

**5. (Sub lesson 1) What is padding?**
**Answer: Space inside the box — between its border and its contents (the cushion)**

**6. (Sub lesson 2) What is margin?**
**Answer: Space outside the border — between this box and its neighbours (the elbow room)**

**7. (Sub lesson 2) Which book practice applies both?**
**Answer: Styling table headers and cells**

**8. (Sub lesson 2) State the photograph picture.**
**Answer: Padding is the mount inside the frame; margin is the wall around it**

**9. (Sub lesson 2) What happens with the wrong selector?**
**Answer: A tidy accident — a style hitting the wrong elements**

**10. (Sub lesson 2) Which book teaches this?**
**Answer: Kuwait Grade 9 Digital Intelligence Term 1, Unit 1 CSS**
