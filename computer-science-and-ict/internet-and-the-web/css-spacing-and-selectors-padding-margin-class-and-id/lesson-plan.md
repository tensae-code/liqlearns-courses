## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Selectors — class for many, id for one** — A **selector** names what a style rule hits. An element selector hits every such element; a **class** selector hits every element **wearing that class** — the reusable uniform, given to many elements that must look alike (every price, every note); an **id** selector hits the **one** element carrying that id — the named individual (the page's single header banner). Choosing the selector is choosing the style's **reach**, and Kuwait teaches reach before decoration: a style that hits the wrong elements is a tidy accident.
2. **Padding and margin — the air inside and outside** — Every element is a box, and CSS spaces it twice: **padding** is the space **inside** the box, between its border and its contents — the cushion; **margin** is the space **outside** the border, between this box and its neighbours — the elbow room. The book's practice styles **table headers and cells**: header cells padded so their words breathe, the table margined from the text around it. Confusing the two spaces is the beginner's classic fault; the picture that cures it is a framed photograph — padding is the mount inside the frame, margin is the wall around it.
