# Sign-Up and Login with Server Scripting — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does sign-up collect, check, and store?" is: The details on a form; validated on the server; the account stored as a record**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Name three sign-up validations." is: By querying the store**
**Answer: False** — Presence; well-formed fields; the name not already taken

**3. (Sub lesson 1) True or false: the answer to "How is 'name taken' checked?" is: By querying the store**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Sign-up's two answers are what?" is: A form, a gate, a stored line**
**Answer: False** — An account made — or the field-by-field reasons it was not

**5. (Sub lesson 1) True or false: the answer to "Sign-up is the unit's whole craft in what one act?" is: A form, a gate, a stored line**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does login check?" is: The visitor is let in as that user — pages built for them**
**Answer: False** — The sent name and password against the stored record

**7. (Sub lesson 2) True or false: the answer to "On a match, what happens?" is: The visitor is let in as that user — pages built for them**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "On a mismatch, what does the message say?" is: A courtesy to the honest and a wall to the guesser**
**Answer: False** — 'Name or password not recognised' — not which part failed

**9. (Sub lesson 2) True or false: the answer to "Why not say which part failed?" is: A courtesy to the honest and a wall to the guesser**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What caution travels with this school model?" is: The details on a form; validated on the server; the account stored as a record**
**Answer: False** — Real systems store passwords protected, never readable — plain text files are a model of the shape
