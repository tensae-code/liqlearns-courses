# Sign-Up and Login with Server Scripting — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does sign-up collect, check, and store?**
a) The details on a form; validated on the server; the account stored as a record  b) Presence; well-formed fields; the name not already taken  c) By querying the store  d) An account made — or the field-by-field reasons it was not
**Answer: a) The details on a form; validated on the server; the account stored as a record**

**2. (Sub lesson 1) Name three sign-up validations.**
a) By querying the store  b) Presence; well-formed fields; the name not already taken  c) An account made — or the field-by-field reasons it was not  d) A form, a gate, a stored line
**Answer: b) Presence; well-formed fields; the name not already taken**

**3. (Sub lesson 1) How is 'name taken' checked?**
a) An account made — or the field-by-field reasons it was not  b) A form, a gate, a stored line  c) By querying the store  d) The sent name and password against the stored record
**Answer: c) By querying the store**

**4. (Sub lesson 1) Sign-up's two answers are what?**
a) A form, a gate, a stored line  b) The sent name and password against the stored record  c) The visitor is let in as that user — pages built for them  d) An account made — or the field-by-field reasons it was not
**Answer: d) An account made — or the field-by-field reasons it was not**

**5. (Sub lesson 1) Sign-up is the unit's whole craft in what one act?**
a) A form, a gate, a stored line  b) The sent name and password against the stored record  c) The visitor is let in as that user — pages built for them  d) 'Name or password not recognised' — not which part failed
**Answer: a) A form, a gate, a stored line**

**6. (Sub lesson 2) What does login check?**
a) The visitor is let in as that user — pages built for them  b) The sent name and password against the stored record  c) 'Name or password not recognised' — not which part failed  d) A courtesy to the honest and a wall to the guesser
**Answer: b) The sent name and password against the stored record**

**7. (Sub lesson 2) On a match, what happens?**
a) 'Name or password not recognised' — not which part failed  b) A courtesy to the honest and a wall to the guesser  c) The visitor is let in as that user — pages built for them  d) Real systems store passwords protected, never readable — plain text files are a model of the shape
**Answer: c) The visitor is let in as that user — pages built for them**

**8. (Sub lesson 2) On a mismatch, what does the message say?**
a) A courtesy to the honest and a wall to the guesser  b) Real systems store passwords protected, never readable — plain text files are a model of the shape  c) The details on a form; validated on the server; the account stored as a record  d) 'Name or password not recognised' — not which part failed
**Answer: d) 'Name or password not recognised' — not which part failed**

**9. (Sub lesson 2) Why not say which part failed?**
a) A courtesy to the honest and a wall to the guesser  b) Real systems store passwords protected, never readable — plain text files are a model of the shape  c) The details on a form; validated on the server; the account stored as a record  d) Presence; well-formed fields; the name not already taken
**Answer: a) A courtesy to the honest and a wall to the guesser**

**10. (Sub lesson 2) What caution travels with this school model?**
a) The details on a form; validated on the server; the account stored as a record  b) Real systems store passwords protected, never readable — plain text files are a model of the shape  c) Presence; well-formed fields; the name not already taken  d) By querying the store
