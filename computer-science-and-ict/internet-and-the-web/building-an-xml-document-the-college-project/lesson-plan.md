# Lesson plan — Building an XML document — the college project

**Course:** Computer Science and ICT · **Title:** Internet and the Web · **Lesson:** Building an XML document — the college project
**Place in the curriculum:** Title — Internet and the Web in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 12 book, Unit 4 — Web Authoring. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** the unit's project: build one college XML document in the book's stages — declaration, College root, three empty departments, names and numbers, courses, then teachers and students with their own sub-elements — saving after every stage as .xml.
**This lesson's own level:** it stands on every XML lesson before it — declaration, root, elements, attributes, entities and DTD have all been met; this project builds with all of them, in the book's exact stage order.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Stages 1–3 — declaration, College root, empty departments (doing)** — write the declaration, then a College root element instead of html; add three empty Department sub-elements; save after each step under your own name with an .xml extension
2. **Stage 4 — names, numbers and data types (doing)** — fill in each department's name and number, attaching a data type to values — the number as an integer attribute
3. **Stages 5–6 — courses, then teachers and students (doing)** — grow the structure with courses (name, number/code, credit hour, teacher with name and ID number) and empty student/teacher elements; finally add teachers' and students' own sub-elements such as name, sex and age; view in XML Notepad at each stage

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: DTD — the rulebook inside the document; Entities — declare once, reference by name. Recommended, never forced.

## What the learner can do when it ends
1. Build the college document through every stage, in order, saving after each.
2. Give departments names and numbers, with a data type attached to values.
3. Grow courses, teachers and students with their own sub-elements, checking the growing tree in XML Notepad.

## What you need
A computer with a text editor and a browser or XML Notepad.

## If the learner is stuck
- Rushes to the final document in one typing → the method is stages, saving after each; a fault found early is cheap, a fault found at the end is not.
- Writes html as the root → the root is College; this is an XML document, not a web page.
