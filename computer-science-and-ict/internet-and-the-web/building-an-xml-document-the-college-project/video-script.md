# Video script — Building an XML document — the college project

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

The project: one college, in XML. Build it in stages. Save after every stage.
Stage one: the declaration. Version, encoding.
Stage two: the root. College. Not html — College.
Stage three: three empty departments inside it.
Save. Look at it in XML Notepad. A root, three empty branches.
Stage four: name each department. Give each a number.
Attach a data type to the values — the number as an integer.
Save again. The tree has names now.
Stage five: courses grow inside a department.
Each course: its name, its number — its code. Its credit hour.
Its teacher: a name, and an ID number.
Empty student and teacher elements stand ready beside the courses.
Save. Check the tree.
Stage six: teachers and students get their own insides.
Name. Sex. Age. Person by person, element by element.
Save the final document, under your own name, as .xml.
Open it once more. The whole college, structured, in one document.
You built that — stage by stage.
