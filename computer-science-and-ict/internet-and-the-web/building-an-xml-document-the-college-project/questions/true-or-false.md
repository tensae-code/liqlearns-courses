# Building an XML document — the college project — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** You save only once, at the very end of the project.
**Answer: False** — saving happens after each step, under your own name, as .xml.

**2. (Sub lesson 2)** The growing document is viewed in XML Notepad at each stage.
**Answer: True** — Notepad checks ride along with the stages.

**3. (Sub lesson 3)** Students' sub-elements include name, sex and age.
**Answer: True** — name, sex and age are the named final-stage sub-elements.
