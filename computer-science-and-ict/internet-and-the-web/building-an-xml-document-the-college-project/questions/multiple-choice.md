# Building an XML document — the college project — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The project's root element is —
a) html  b) College  c) Department
**Answer: b) College** — College instead of html — this is XML, not a web page.

**2. (Sub lesson 1)** Stage 3 adds —
a) three empty Department sub-elements  b) three courses  c) the declaration
**Answer: a) three empty Department sub-elements** — three empty departments are stage 3.

**3. (Sub lesson 2)** The department number carries —
a) no data type  b) a data type — integer  c) a comment only
**Answer: b) a data type — integer** — the number as an integer attribute is the stage-4 instruction.

**4. (Sub lesson 3)** A course's teacher is given with —
a) name and ID number  b) a photograph  c) a password
**Answer: a) name and ID number** — teacher with name and ID number is stage 5's shape.
