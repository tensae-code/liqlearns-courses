# HTML Banner, Frame and Menu — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Where does the banner stand?" is: Across the top of the page**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does the banner carry?" is: The same on every page**
**Answer: False** — The site's name, logo and colours — whose site this is

**3. (Sub lesson 1) True or false: the answer to "How is the banner used across pages?" is: The same on every page**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does the frame arrangement do?" is: So banner and menu stay standing while the main region changes**
**Answer: False** — Divides the page into regions — top, side, main — each showing its own content

**5. (Sub lesson 1) True or false: the answer to "Why are standing parts kept separate from content?" is: So banner and menu stay standing while the main region changes**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is the menu?" is: Navigation — every main page one click away, from any page**
**Answer: False** — The standing list of links to the site's pages

**7. (Sub lesson 2) True or false: the answer to "What is the menu's job?" is: Navigation — every main page one click away, from any page**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Why should the menu look the same everywhere?" is: The site's furniture — banner names it, frame holds it, menu moves you through it**
**Answer: False** — So visitors learn it once

**9. (Sub lesson 2) True or false: the answer to "What are the three parts together called in this lesson?" is: The site's furniture — banner names it, frame holds it, menu moves you through it**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What changes from page to page — content or furniture?" is: Across the top of the page**
**Answer: False** — Content changes; the furniture stands
