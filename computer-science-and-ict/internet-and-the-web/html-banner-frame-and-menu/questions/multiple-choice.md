# HTML Banner, Frame and Menu — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Where does the banner stand?**
a) Across the top of the page  b) The site's name, logo and colours — whose site this is  c) The same on every page  d) Divides the page into regions — top, side, main — each showing its own content
**Answer: a) Across the top of the page**

**2. (Sub lesson 1) What does the banner carry?**
a) The same on every page  b) The site's name, logo and colours — whose site this is  c) Divides the page into regions — top, side, main — each showing its own content  d) So banner and menu stay standing while the main region changes
**Answer: b) The site's name, logo and colours — whose site this is**

**3. (Sub lesson 1) How is the banner used across pages?**
a) Divides the page into regions — top, side, main — each showing its own content  b) So banner and menu stay standing while the main region changes  c) The same on every page  d) The standing list of links to the site's pages
**Answer: c) The same on every page**

**4. (Sub lesson 1) What does the frame arrangement do?**
a) So banner and menu stay standing while the main region changes  b) The standing list of links to the site's pages  c) Navigation — every main page one click away, from any page  d) Divides the page into regions — top, side, main — each showing its own content
**Answer: d) Divides the page into regions — top, side, main — each showing its own content**

**5. (Sub lesson 1) Why are standing parts kept separate from content?**
a) So banner and menu stay standing while the main region changes  b) The standing list of links to the site's pages  c) Navigation — every main page one click away, from any page  d) So visitors learn it once
**Answer: a) So banner and menu stay standing while the main region changes**

**6. (Sub lesson 2) What is the menu?**
a) Navigation — every main page one click away, from any page  b) The standing list of links to the site's pages  c) So visitors learn it once  d) The site's furniture — banner names it, frame holds it, menu moves you through it
**Answer: b) The standing list of links to the site's pages**

**7. (Sub lesson 2) What is the menu's job?**
a) So visitors learn it once  b) The site's furniture — banner names it, frame holds it, menu moves you through it  c) Navigation — every main page one click away, from any page  d) Content changes; the furniture stands
**Answer: c) Navigation — every main page one click away, from any page**

**8. (Sub lesson 2) Why should the menu look the same everywhere?**
a) The site's furniture — banner names it, frame holds it, menu moves you through it  b) Content changes; the furniture stands  c) Across the top of the page  d) So visitors learn it once
**Answer: d) So visitors learn it once**

**9. (Sub lesson 2) What are the three parts together called in this lesson?**
a) The site's furniture — banner names it, frame holds it, menu moves you through it  b) Content changes; the furniture stands  c) Across the top of the page  d) The site's name, logo and colours — whose site this is
**Answer: a) The site's furniture — banner names it, frame holds it, menu moves you through it**

**10. (Sub lesson 2) What changes from page to page — content or furniture?**
a) Across the top of the page  b) Content changes; the furniture stands  c) The site's name, logo and colours — whose site this is  d) The same on every page
**Answer: b) Content changes; the furniture stands**
