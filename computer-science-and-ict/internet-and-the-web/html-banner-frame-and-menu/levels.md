# HTML Banner, Frame and Menu — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — The banner and the frame
Sub lesson 1 questions from the type files. Pass mark: Across the top of the page; The site's name, logo and colours — whose site this is; The same on every page; Divides the page into regions — top, side, main — each showing its own content; So banner and menu stay standing while the main region changes.

## Sub lesson 2 — The menu — the site's links, standing still
Sub lesson 2 questions from the type files. Pass mark: The standing list of links to the site's pages; Navigation — every main page one click away, from any page; So visitors learn it once; The site's furniture — banner names it, frame holds it, menu moves you through it; Content changes; the furniture stands.
