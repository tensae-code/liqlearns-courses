# Hands-on — Setting Up a Static Front Page

The lesson with your hands and your feet, not only your eyes.

## Task one
**Do the book's steps** — Work through Setting Up a Static Front Page exactly as South Sudan's book orders it, on a real computer if one is available; otherwise write the steps in order and check them against the book's order.

## Task two
