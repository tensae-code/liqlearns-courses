# Naming XML elements — and empty elements — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** <marker></marker> and <marker/> are the same empty element.
**Answer: True** — pair and self-closing tag write the same thing.

**2. (Sub lesson 2)** Element names may contain spaces if the space is small.
**Answer: False** — names cannot contain spaces at all.

**3. (Sub lesson 2)** Many words are reserved in XML naming.
**Answer: False** — no words are reserved except XML.
