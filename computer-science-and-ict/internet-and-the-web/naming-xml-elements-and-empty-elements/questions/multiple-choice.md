# Naming XML elements — and empty elements — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** An empty element can be written as —
a) only a self-closing tag  b) only an open-and-close pair  c) either — a pair, or a single self-closing tag
**Answer: c) either — a pair, or a single self-closing tag** — both writings are the same empty element.

**2. (Sub lesson 1)** In the bookstore record, the element carrying an attribute is —
a) title  b) book, with its category attribute  c) price
**Answer: b) book, with its category attribute** — book carries category; title/author/year/price hold text.

**3. (Sub lesson 2)** Which name is legal?
a) 1stname  b) my name  c) grade-level
**Answer: c) grade-level** — grade-level starts with a letter and its hyphen is allowed; the others break the start and space rules.

**4. (Sub lesson 2)** A name cannot start with —
a) a letter  b) the letters XML  c) an underscore
**Answer: b) the letters XML** — starting with XML is forbidden; letter and underscore starts are required forms.
