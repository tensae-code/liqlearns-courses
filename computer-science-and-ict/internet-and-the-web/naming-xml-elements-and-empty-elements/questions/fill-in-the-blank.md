# Naming XML elements — and empty elements — fill in the blank

Fill each blank with the right word or code.

**1. (Sub lesson 1)** An element is everything from its start tag to its ___ tag.
**Answer: end** — start tag to end tag is the element.

**2. (Sub lesson 2)** A name must start with a letter or an ___.
**Answer: underscore** — letter or underscore — never a digit.

**3. (Sub lesson 2)** Names may contain letters, digits, hyphens, underscores and ___.
**Answer: periods** — periods complete the allowed set.
