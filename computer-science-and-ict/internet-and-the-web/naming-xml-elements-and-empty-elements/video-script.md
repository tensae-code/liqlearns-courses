# Video script — Naming XML elements — and empty elements

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

An element is everything: start tag to end tag.
No content? It is an empty element.
Write it as a pair — or as one self-closing tag.
Names have rules. Case matters.
Start with a letter, or an underscore.
Never start with the letters X-M-L.
Letters, digits, hyphens, underscores, periods — yes.
Spaces — never. Only XML is reserved.
