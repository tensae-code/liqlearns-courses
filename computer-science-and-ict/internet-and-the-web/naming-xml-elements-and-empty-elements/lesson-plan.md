# Lesson plan — Naming XML elements — and empty elements

**Course:** Computer Science and ICT · **Title:** Internet and the Web · **Lesson:** Naming XML elements — and empty elements
**Place in the curriculum:** Title — Internet and the Web in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 12 book, Unit 4 — Web Authoring. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** an element is everything from start tag to end tag; an empty element can be written as a self-closing tag; and element names follow rules — case sensitive, starting with a letter or underscore, never with XML, with no spaces.
**This lesson's own level:** it stands on the syntax rules — the learner writes well-formed documents; this doing lesson names what an element may contain and what its name may be.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Elements, empty elements, and what an element can contain (doing)** — an element is everything from start tag to end tag; an element with no content is an empty element, written as an open-and-close pair or a single self-closing tag; an element can contain text, attributes, other elements, or a mix
2. **Naming rules (doing)** — names are case sensitive; must start with a letter or underscore; cannot start with the letters XML; may contain letters, digits, hyphens, underscores and periods; cannot contain spaces; no words are reserved except XML
