# Links within a page — jumping to a section — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) An in-page link needs the destination page's absolute URL.**
**Answer: False** — it needs # plus the location's name.

**2. (Sub lesson 1) The name attribute is placed at the spot the link should land on.**
**Answer: True** — name sits at the destination.

**3. (Sub lesson 2) In-page links help most on long pages.**
**Answer: True** — they save hunting up and down.
