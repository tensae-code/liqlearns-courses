# Links within a page — jumping to a section — fill in the blank

Fill each blank with the right word or code.

**1. (Sub lesson 1) The reference to a named location starts with the symbol ___.**
**Answer: #** — # plus the name.

**2. (Sub lesson 1) The attribute that names a location is the ___ attribute.**
**Answer: name** — name marks the spot.

**3. (Sub lesson 2) The guide's ring links three page files in a ___ — each to the next. (teacher guide — evidence)**
**Answer: ring** — a ring of pages.
