# Links within a page — jumping to a section — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) A location on a page is named with the anchor's —**
a) name attribute  b) target attribute  c) source attribute  d) controls attribute
**Answer: a) name attribute** — name marks the spot.

**2. (Sub lesson 1) A link to a named location has a reference value made of —**
a) the # symbol followed by the name  b) the full absolute URL only  c) the file name twice  d) a question mark
**Answer: a) the # symbol followed by the name** — # plus name is the reference.

**3. (Sub lesson 1) Clicking an in-page link —**
a) scrolls the reader straight to the named section  b) opens a new website  c) prints the page  d) closes the browser
**Answer: a) scrolls the reader straight to the named section** — the jump is the point.

**4. (Sub lesson 2) The book's first practice links —**
a) three separate documents to each other in all directions  b) one document to itself only  c) two images  d) no documents
**Answer: a) three separate documents to each other in all directions** — the ring of documents.

**5. (Sub lesson 2) The book's second practice builds —**
a) a three-section page with links to the top and between section starts  b) a table of sections  c) a video page  d) a one-line page
**Answer: a) a three-section page with links to the top and between section starts** — the sectioned page.

**6. (Sub lesson 2) The guide's practical note says the page must be — (teacher guide — evidence)**
a) long enough to scroll, or pupils cannot feel what the links are for  b) printed on paper  c) exactly one screen  d) kept secret
**Answer: a) long enough to scroll, or pupils cannot feel what the links are for** — no scroll, no felt jump.
