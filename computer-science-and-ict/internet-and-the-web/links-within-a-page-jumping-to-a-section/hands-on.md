# Hands-on — Links within a page — jumping to a section

The lesson with your hands, not only your eyes. You need a computer with a text editor and a browser for the doing parts.

## Build the sectioned page
Make a three-section page, long enough to scroll. Name each section's start, add links from the top to each section, and a link at the end back to the top.

## Ring of three
Build three small page files and link them in a ring — each page links to the next, and the last links back to the first — the book's first practice shape.
