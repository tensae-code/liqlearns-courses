# Lesson plan — Using email — inbox, reading, composing, forwarding

**Course:** Computer Science and ICT · **Title:** Internet and the Web · **Lesson:** Using email — inbox, reading, composing, forwarding
**Place in the curriculum:** Title 8 — Internet and the Web of the Computer Science and ICT ladder (TITLES.md); Ethiopia Grade 8, Unit 4 — Internet. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** a mailbox works in four moves: the inbox lists what arrived, the message pane opens one message to read and answer, the compose pane writes a new message (with attachments if needed), and forward sends a received message on to someone else.
**This lesson's own level:** it is a doing-lesson standing on the two email lessons before it — the learner has an account and can read an address; this lesson works the mailbox itself.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 2 seconds, looping.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The inbox and the message pane** — the inbox lists received mail by sender, subject and date; selecting one opens it in the message pane to read and answer
2. **The compose pane — writing and attaching** — click Compose; fill in the recipient's address and the subject, write the message, and upload files such as photos and documents as attachments if needed
3. **Forward — passing a message on** — forward shares a received email by sending it on to another person

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Creating an email account — Gmail sign-up; The parts of an email address. Recommended, never forced. A learner can land here directly; the lesson stands alone.

## What the learner can do when it ends
1. Read an inbox list by sender name, subject and date received.
2. Open a message in the message pane and say what can be done there.
3. Compose a message in order — address, subject, message, attachments — and forward a received email to another person.

## What you need
A computer or phone with an email account for the real activity; paper and a pencil for rehearsal.

## If the learner is stuck
- Writes the message before the address → compose order is address first, then subject, then the message; attachments last, if needed.
- Confuses forward with compose → forward sends on a message you received; compose starts a new one.
