# Using email — inbox, reading, composing, forwarding — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** The inbox is where emails received from others are viewed and managed.
**Answer: True — viewed and managed is the inbox's work.**

**2. (Sub lesson 2)** You must attach a file to every email you compose.
**Answer: False — attachments are optional: 'if you need to'.**

**3. (Sub lesson 3)** Forward sends a received email on to another person.
**Answer: True — that is the definition.**
