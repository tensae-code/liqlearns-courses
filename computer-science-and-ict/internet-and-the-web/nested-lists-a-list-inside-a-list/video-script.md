# Video script — Nested lists — a list inside a list

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

A list can hold a list.
Write the small one inside an item of the big one.
Indent it, so your eyes can follow.
The browser does not care about the spaces.
You do. Keep the code readable.
