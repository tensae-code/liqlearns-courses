# Hands-on — Nested lists — a list inside a list

The lesson with your hands, not only your eyes. You need a computer with a text editor and a browser for the doing parts.

## Climate inside a bullet
Rebuild the book's worked example: one bullet item holding an ordered list of climate actions. Then add a second bullet with its own inner list.

## Runners, grouped
Following the review model's shape: a nested list grouping famous Ethiopian women runners and men runners under square bullets — two groups, each with its own inner list.
