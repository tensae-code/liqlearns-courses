# Nested lists — a list inside a list — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) A nested list is —**
a) a list placed inside an item of another list  b) two lists side by side on a page  c) a list with no items  d) a list inside a table only
**Answer: a) a list placed inside an item of another list** — inside an item is the nesting.

**2. (Sub lesson 1) Which list types can be nested?**
a) any list type inside any other  b) only ordered inside unordered  c) only unordered inside ordered  d) only description lists
**Answer: a) any list type inside any other** — any inside any.

**3. (Sub lesson 1) The inner list is written —**
a) inside an item of the outer list  b) after the outer list ends  c) in the head section  d) in a separate file
**Answer: a) inside an item of the outer list** — position is the whole rule.

**4. (Sub lesson 2) The book's worked example puts —**
a) an ordered list of climate actions inside a bullet item  b) a table inside a heading  c) a video inside a list  d) bullets inside a paragraph
**Answer: a) an ordered list of climate actions inside a bullet item** — the book's example, exactly.

**5. (Sub lesson 2) The practice list uses —**
a) bullet headings and circle-bulleted items  b) numbered headings only  c) no bullets  d) discs throughout
**Answer: a) bullet headings and circle-bulleted items** — the fruit-and-vegetable practice shape.

**6. (Sub lesson 2) The review model's nested list groups — (teacher guide — evidence)**
a) famous Ethiopian women and men runners under square bullets  b) mountains by elevation  c) websites by name  d) subjects by grade
**Answer: a) famous Ethiopian women and men runners under square bullets** — the athlete-list model.
