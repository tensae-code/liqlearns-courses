# Nested lists — a list inside a list — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) The browser reads code indentation and changes the list because of it.**
**Answer: False** — indentation is ignored by the browser; it is kept for human readers (guide).

**2. (Sub lesson 2) An unordered list can sit inside an ordered list's item.**
**Answer: True** — any type inside any other.

**3. (Sub lesson 2) A nested list needs a special nesting tag.**
**Answer: False** — position inside an item does the nesting.
