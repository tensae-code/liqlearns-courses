# Nested lists — a list inside a list — fill in the blank

Fill each blank with the right word or code.

**1. (Sub lesson 1) A list inside a list is called a ___ list.**
**Answer: nested** — nested = one inside another.

**2. (Sub lesson 1) The inner list is written inside an ___ of the outer list.**
**Answer: item** — inside an item.

**3. (Sub lesson 2) The review model groups Ethiopian ___ under square bullets. (teacher guide — evidence)**
**Answer: runners** — women and men runners.
