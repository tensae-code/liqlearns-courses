# Nested lists — a list inside a list

## Do it first

A list item can hold more than words — it can hold a whole second list. Build the book's worked example: a bullet item that opens into a numbered list of climate actions inside it. That list-inside-a-list is this lesson.

## Sub lesson 1 — How nesting works

**Any list type can be placed inside any other.** The rule of position: the **inner list is written inside an item of the outer list**. Indenting the inner list in your code keeps it readable — the guide notes (teacher guide — evidence) that **code indentation, though ignored by the browser, is kept because it makes code readable**.

## Sub lesson 2 — The worked shapes

The book's worked example puts an **ordered list of climate actions inside a bullet item**. Its practice builds a **mixed fruit-and-vegetable list with bullet headings and circle-bulleted items**. The guide's own worked nested list groups fruits and vegetables the same way, and the Unit 4 review model (teacher guide — evidence) is a **nested athlete list grouping famous Ethiopian women and men runners under square bullets** — filed here as a verified expected output.

## Say it to your companion

## Do It Yourself
1. Build the book's worked example: an ordered climate list inside a bullet item.
2. Build the practice list: bullet headings, circle-bulleted fruit and vegetable items.
3. Write one nested list of your own school subjects, grouped by morning and afternoon.
