# The parts of a web address

## Do it first

Here is an address: http://www.moe.gov.et. It looks like one long word, but it is built from parts, like a sentence is built from words. Guess where one part ends and the next begins. This lesson draws the exact lines.

## Four parts, one address

Take the book's worked example: **http://www.google.com**. Part 1, the **protocol**: **http://** — the rules the page travels by. Part 2: **www**. Part 3, the **domain name**: **google** — whose site it is. Part 4, the **domain extension**: **.com**. Four parts, always in that order: protocol, www, domain name, extension.

## Extensions tell the type

The extension identifies the type of site. **.org** — a nonprofit or private organisation. **.edu** — education. **.gov** — government. **.net** — network. **.et** — Ethiopia. Now read the Ethiopian example with new eyes: **http://www.moe.gov.et** — protocol http://, www, domain name **moe**, and two endings: .gov (government) and .et (Ethiopia). It is the Ministry of Education's address — a government site in Ethiopia, exactly as its parts say.

## Say it to your companion

Tell your companion the four parts, using http://www.moe.gov.et, and what its last two parts tell you.
