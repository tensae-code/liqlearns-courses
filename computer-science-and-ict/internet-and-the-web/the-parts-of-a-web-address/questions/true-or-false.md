# The parts of a web address — true or false

Say whether each sentence is true or false.

**1.** The extension is the last part of an address.
**Answer: True** — protocol, www, name, extension — in that order.

**2.** .edu identifies education sites.
**Answer: True** — one of the book's named extensions.

**3.** http://www.moe.gov.et is a private company's address.
**Answer: False** — .gov says government; .et says Ethiopia.
