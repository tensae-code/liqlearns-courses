# The parts of a web address — multiple choice

Pick the one right answer.

**1.** How many main parts has a web address?
a) Two  b) Four  c) Three  d) Six
**Answer: b) Four** — protocol, www, domain name, extension.

**2.** In http://www.google.com, the protocol is —
a) www  b) http://  c) google  d) .com
**Answer: b) http://** — http:// comes first.

**3.** In the same address, the domain name is —
a) http  b) www  c) google  d) com
**Answer: c) google** — google is whose site it is.

**4.** .gov identifies —
a) education  b) government  c) a network  d) Ethiopia
**Answer: b) government** — government sites.

**5.** .et identifies —
a) education  b) Ethiopia  c) an organisation  d) a network
**Answer: b) Ethiopia** — Ethiopia's ending.

**6.** In http://www.moe.gov.et, 'moe' is —
a) the protocol  b) the domain name  c) the extension  d) the browser
**Answer: b) the domain name** — moe names the owner — the Ministry of Education.
