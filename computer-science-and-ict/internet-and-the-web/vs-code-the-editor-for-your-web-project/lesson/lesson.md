# VS Code — the Editor for Your Web Project

## Do it first

A hand-built website needs a workbench. Kuwait's Grade 9 web course opens its editor before its HTML: Visual Studio Code, where the whole 'Kuwait Future' site will be built. This lesson is the meeting and the first page.

## Sub lesson 1 — VS Code — the editor, and the project folder

**Visual Studio Code (VS Code)** is the **editor** the course builds in: a program for writing and organising code files, which shows the project's files beside the text being written. The working act that matters first is opening the **project folder**: the whole website lives in one folder — its pages, styles and images — and VS Code opened **on that folder** shows the site as a family, not as scattered files. Kuwait begins here because every later lesson says 'in your project…' and means this folder.

## Sub lesson 2 — Creating your first web page

The first page is **created inside the folder** from the editor: a new file, given its web name (the course's first is the site's home page), and saved so it exists on disk where the project can grow around it. The discipline is naming and placing from the first minute — a page outside the folder is a page the site cannot use, and a file unsaved is a page that exists only until the editor closes.
