# VS Code — the Editor for Your Web Project — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is VS Code?**
**Answer: The editor the course builds websites in — writing and organising code files**

**2. (Sub lesson 1) What does it show beside the text?**
**Answer: The project's files**

**3. (Sub lesson 1) What is opened first, and why there?**
**Answer: The project folder — the whole website lives in one folder, shown as a family**

**4. (Sub lesson 1) Where do a website's parts live?**
**Answer: In the one project folder — pages, styles and images**

**5. (Sub lesson 1) Where is the first web page created?**
**Answer: Inside the folder, from the editor**

**6. (Sub lesson 2) What two disciplines govern the first page?**
**Answer: Naming it properly, and saving it into the folder**

**7. (Sub lesson 2) What is a page outside the folder?**
**Answer: A page the site cannot use**

**8. (Sub lesson 2) What is an unsaved file?**
**Answer: A page that exists only until the editor closes**

**9. (Sub lesson 2) Which site does the course build in it?**
**Answer: The 'Kuwait Future' site**
