# Cookies — Small Files That Remember You — true or false

Say whether each statement is true or false.

**1. A cookie can run like a program and read your files.**
**Answer: False** — A cookie is plain text — a note, not a program; it cannot run or read anything.

**2. Deleting a site's cookies makes the site forget your sign-in and basket.**
**Answer: True** — That memory was the cookie; without it you are a new visitor.

**3. Private-browsing windows start with an empty cookie store that is emptied again at the end.**
**Answer: True** — That is exactly their cookie behaviour.

**4. The cookie consent box exists because sites must keep all cookies secret.**
**Answer: False** — Consent law requires asking before tracking cookies are set — the box is a choice, not a secrecy rule.
