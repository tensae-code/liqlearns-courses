# The structure of an HTML document — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Every HTML page has its own completely different skeleton.**
**Answer: False** — all pages share the one skeleton.

**2. (Sub lesson 1) The page's title sits in the head section.**
**Answer: True** — the title is information about the page.

**3. (Sub lesson 2) The document-type declaration is part of the body.**
**Answer: False** — it stands before the root element, at the top.
