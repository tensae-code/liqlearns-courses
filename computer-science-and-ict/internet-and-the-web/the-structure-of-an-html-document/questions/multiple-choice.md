# The structure of an HTML document — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) The first part of the skeleton is —**
a) a document-type declaration  b) the body  c) a paragraph  d) an image
**Answer: a) a document-type declaration** — the declaration announces the document type.

**2. (Sub lesson 1) The root element —**
a) wraps the whole page  b) holds only the title  c) displays the images  d) ends the document
**Answer: a) wraps the whole page** — everything sits inside the root.

**3. (Sub lesson 1) The head section holds —**
a) information about the page, such as its title  b) everything the browser displays  c) only images  d) the page's links only
**Answer: a) information about the page, such as its title** — head = about the page.

**4. (Sub lesson 1) The body section holds —**
a) everything the browser actually displays  b) the document-type declaration  c) information about the page only  d) nothing at all
**Answer: a) everything the browser actually displays** — body = what is displayed.

**5. (Sub lesson 2) From page to page, what changes is —**
a) what sits inside head and body  b) the skeleton itself  c) the order of the four parts  d) the root element
**Answer: a) what sits inside head and body** — same skeleton, different contents.

**6. (Sub lesson 2) The book's practice for this part is to —**
a) open a real page's source and hunt for the familiar tags  b) memorise a page without opening it  c) copy a page's pictures  d) print a page
**Answer: a) open a real page's source and hunt for the familiar tags** — hunting the tags in a real source.
