# Hands-on — The structure of an HTML document

The lesson with your hands, not only your eyes. You need a computer with a text editor and a browser for the doing parts.

## Skeleton hunt
Open three different real pages' sources. In each, find and write down the declaration, the root, one thing in the head and one thing in the body.

## Skeleton from memory
Write a complete empty skeleton in a text editor from memory — then add a title and one paragraph and open it.
