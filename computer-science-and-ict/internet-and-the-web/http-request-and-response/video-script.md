# Video script — HTTP — how a web page is requested and delivered

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Click. What happens?

Your browser asks. That is the request.
The connection is made.
The server finds the data.
The page travels back. That is the response.

Ask — connect — find — answer.
That protocol is HTTP.
