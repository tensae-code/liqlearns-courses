# HTTP — how a web page is requested and delivered — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** HTTP is a request–response protocol.
**Answer: True — a client requests; a server responds.**

**2. (Sub lesson 1)** HTTP also formats and transfers web page data such as text, images and video.
**Answer: True — formatting and transferring page data is its named work.**

**3. (Sub lesson 2)** IMAP and NTP are named as other protocols.
**Answer: True — both are named alongside HTTP.**
