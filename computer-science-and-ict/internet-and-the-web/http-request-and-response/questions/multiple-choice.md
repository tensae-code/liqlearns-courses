# HTTP — how a web page is requested and delivered — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** HTTP stands for —
a) Hypertext Transfer Protocol  b) High Telephone Transfer Post  c) Home Text Typing Program  d) Hypertext Typing Page
**Answer: a) Hypertext Transfer Protocol**

**2. (Sub lesson 1)** In HTTP, the client is —
a) the web host  b) the browser user  c) the database  d) the cable
**Answer: b) the browser user**

**3. (Sub lesson 1)** The server answers a request by —
a) picking the requested data from its database  b) asking another question  c) closing the connection at once  d) printing the page
**Answer: a) picking the requested data from its database**

**4. (Sub lesson 1)** The connection for an HTTP request is made through —
a) FTP  b) TCP  c) IMAP  d) NTP
**Answer: b) TCP**

**5. (Sub lesson 2)** HTTP messages are —
a) read by humans and stored  b) not read by humans and delivered immediately  c) always printed  d) never delivered
**Answer: b) not read by humans and delivered immediately**

**6. (Sub lesson 2)** SMTP messages are —
a) delivered immediately  b) stored and forwarded  c) drawn as pictures  d) spoken aloud
**Answer: b) stored and forwarded**
