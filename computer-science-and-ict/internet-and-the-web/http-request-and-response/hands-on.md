# Hands-on — HTTP — how a web page is requested and delivered

The lesson with your hands, not only your eyes.

## Act the round trip
In pairs: one is the browser, one is the server with a box of paper 'pages'. The browser hands over a written request naming a page; the server finds that page in the box and hands it back as the response. Swap roles, then run it fast — that speed is what HTTP does.

## Number the journey
Write the four steps on four cards, shuffle them, and put them back in order. Then label each card: who holds it — client or server?
