# Page layout with a table — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) In the book's layout, the header row —**
a) spans both columns  b) takes 20% of the width  c) holds only links  d) is the footer
**Answer: a) spans both columns** — header spans the full width.

**2. (Sub lesson 1) The sidebar takes — of the width.**
a) 20%  b) 80%  c) 50%  d) 100%
**Answer: a) 20%** — sidebar 20, content 80.

**3. (Sub lesson 1) The content area takes — of the width.**
a) 80%  b) 20%  c) 50%  d) 10%
**Answer: a) 80%** — the wide share is the content's.

**4. (Sub lesson 1) The footer row —**
a) also spans both columns  b) takes 80%  c) is a sidebar  d) holds the logo
**Answer: a) also spans both columns** — footer spans like the header.

**5. (Sub lesson 2) The guide's Activity 4.12 middle has — columns. (teacher guide — evidence)**
a) three: narrow–wide–narrow  b) one  c) two equal  d) five
**Answer: a) three: narrow–wide–narrow** — three-column middle in the guide's solution.

**6. (Sub lesson 2) The review model's page ends with — (teacher guide — evidence)**
a) a centred copyright footer  b) a video  c) a second head inside the first, copied as-is  d) no footer
**Answer: a) a centred copyright footer** — centred copyright footer; the model's head fault is not copied.
