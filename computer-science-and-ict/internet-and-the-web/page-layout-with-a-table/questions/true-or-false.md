# Page layout with a table — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Width, height and background-colour attributes give the layout bands their sizes and colours.**
**Answer: True** — those attributes do the sizing and colouring.

**2. (Sub lesson 1) The header carries the site logo in the book's layout.**
**Answer: True** — logo in the top band.

**3. (Sub lesson 2) The review model answer #4's head markup should be copied exactly. (teacher guide — evidence)**
**Answer: False** — it nests a second head inside the first — use its layout, not its head markup.
