# Hands-on — Page layout with a table

The lesson with your hands, not only your eyes. You need a computer with a text editor and a browser for the doing parts.

## Build the book's layout
Build the full layout: logo in the header band, links in the 20% sidebar, real content in the 80% area, a footer band. Open it and check the proportions by eye.

## Build the guide's wider layout
Rebuild your page as the guide's Activity 4.12 shape: top band, three-column middle with set percentage widths and background colours, bottom band — one table, merged cells.
