# Lesson plan — Page layout with a table

**Course:** Computer Science and ICT · **Title:** Internet and the Web · **Lesson:** Page layout with a table
**Place in the curriculum:** Title — Internet and the Web in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 11 book, Unit 4 — Web Development. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** one full-width table can lay out a whole page — a header row and a footer row each spanning both columns, a 20% sidebar and an 80% content area in the middle.
**This lesson's own level:** it stands on the tables and merging-cells lessons — the layout uses spans, widths, heights and background colours together.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The layout, band by band** — the book's header/sidebar/content/footer layout with its proportions
2. **The fuller models (teacher guide — evidence)** — the guide's three-column solution and the review model's two-column page

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Merging table cells — colspan and rowspan. Recommended, never forced.

## What the learner can do when it ends
1. Lay out a whole page with one table.
2. Set sidebar and content proportions of 20% and 80%.
3. Check a layout against the guide's verified models.

## What you need
A computer with a text editor and a browser.

## If the learner is stuck
- Header covers only one column → the header and footer rows must each span both columns; that is the merging lesson at work.
- Sidebar swallows the page → check the width values: sidebar 20%, content 80% — they must add to the whole width.
