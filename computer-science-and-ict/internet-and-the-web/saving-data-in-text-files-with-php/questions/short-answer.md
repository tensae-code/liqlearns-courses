# Saving Data in Text Files with PHP — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) Why must server data outlive the page?**
**Answer: Names signed up today are read tomorrow — the page forgets; the file stays**

**2. (Sub lesson 1) What is the unit's store?**
**Answer: A text file on the server — plain lines of characters**

**3. (Sub lesson 1) How is each record written?**
**Answer: As one line, its fields separated by a chosen mark**

**4. (Sub lesson 1) What is the format agreement?**
**Answer: Writer and reader use the same mark and the same field order**

**5. (Sub lesson 1) Give an example record line.**
**Answer: Aina|aina@mail.com|2026 — fields joined by |**

**6. (Sub lesson 2) What is PHP's writing rhythm?**
**Answer: Open the file, write the line, close the file**

**7. (Sub lesson 2) Which open mode keeps old records?**
**Answer: Appending**

**8. (Sub lesson 2) What does plain writing mode do?**
**Answer: Replaces the file's contents**

**9. (Sub lesson 2) How is saving checked in Malaysia's work?**
**Answer: By eye — open the file as text and read the new line among the old**

**10. (Sub lesson 2) If the line stands wrong, what is repaired?**
**Answer: The writing — not the idea**
