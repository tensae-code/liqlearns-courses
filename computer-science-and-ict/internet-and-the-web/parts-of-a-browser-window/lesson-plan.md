# Lesson plan — Parts of a browser window

**Course:** Computer Science and ICT · **Title:** Internet and the Web · **Lesson:** Parts of a browser window
**Place in the curriculum:** Title 8 — Internet and the Web in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 7 book, Unit 4 — Internet. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** the book's browser (Internet Explorer) has a menu bar, an address bar where you type an address and click GO or press Enter, and a status bar showing messages like download progress — with the guide adding a standard toolbar and the workspace.
**This lesson's own level:** it is a doing-lesson — it stands on knowing what a browser is, and prepares typing real addresses in the lesson after next.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The book's three elements** — menu bar, address bar / URL bar, status bar — where each sits and what it does
2. **Two more from the teacher guide (teacher guide — evidence)** — the standard toolbar and the workspace — and that browser screens vary with the software installed

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Browsers and search engines.  Recommended, never forced.

## What the learner can do when it ends
1. Point to the menu bar, address bar and status bar and say each job.
2. Type an address and load it with GO or Enter.
3. Name the guide's two extra elements: standard toolbar and workspace.
4. Write up the elements in Microsoft Word, as the book's practical sets.

## What you need
A computer with a browser — the school lab, as the book sets; Word for the write-up.

## If the learner is stuck
- Types the address into a search box instead → the address bar is the long bar at the top of the browser itself; an address typed there goes straight to the site.
- Cannot see a status bar → browsers vary (the guide's warning); find what your browser shows at its bottom while a page loads.
