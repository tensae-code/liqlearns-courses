# Parts of a browser window — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** The status bar is at the bottom of the browser window.
**Answer: True** — bottom bar, with messages.

**2. (Sub lesson 1)** You press Enter or click GO after typing an address.
**Answer: True** — that loads the page.

**3. (Sub lesson 2)** Every browser screen looks exactly the same.
**Answer: False** — screens vary with the software installed.
