# Creating an email account — Gmail sign-up — ordering

Put the steps in the right order.

**1. (Sub lesson 2)** Put these in sign-up order: enter the verification code and tap Verify — click Create account — enter a phone number — enter first and last name.
**Answer: click Create account → enter first and last name → enter a phone number → enter the verification code and tap Verify**

**2. (Sub lesson 3)** Put these in sign-up order: click 'I agree' — choose gender — choose a username — click Next (after the password).
**Answer: choose a username → click Next (after the password) → choose gender → click 'I agree'**
