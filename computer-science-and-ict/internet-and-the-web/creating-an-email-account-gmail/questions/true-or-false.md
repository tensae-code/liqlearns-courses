# Creating an email account — Gmail sign-up — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** You choose your own username for the account.
**Answer: True — choosing the username is step 4.**

**2. (Sub lesson 2)** You type the password once only.
**Answer: False — you enter it and type it again to confirm.**

**3. (Sub lesson 3)** Date of birth is part of the basic information the sign-up needs.
**Answer: True — name, birth date, gender, location and the chosen address name.**
