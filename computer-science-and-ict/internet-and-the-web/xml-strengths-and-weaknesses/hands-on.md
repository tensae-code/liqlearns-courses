# Hands-on — XML — strengths and weaknesses

The lesson with your hands, not only your eyes.

## Weigh a real choice
Take one real store of data — class marks, a shop's stock. Argue both sides on paper: XML for it, XML against it, using at least two items from each list. End with a verdict.

## Error hunt in print
Write out the advantages/disadvantages table as a poster, leaving the false bullet out. Add a footnote in your own words: what the bullet claimed, and why it is wrong.
