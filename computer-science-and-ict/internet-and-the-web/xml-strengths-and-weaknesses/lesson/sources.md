BOOK ERROR, flagged in the placements' verification block and taught corrected: the disadvantages table on printed p. 119 lists "It does not allow users to create their tags" as an XML disadvantage. That contradicts the whole unit — XML's point is that users define their own tags (printed pp. 101–102). This lesson teaches XML's real disadvantages as printed otherwise (processing application required; syntax similar to other text-based formats and confusable; no intrinsic data-type support; redundant syntax) and does NOT teach the false bullet as fact; it is named only here and in the lesson's error-hunt, as an error.
