# XML — strengths and weaknesses — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** An XML advantage is that documents are —
a) locked to one machine  b) transportable across systems and applications  c) always short
**Answer: b) transportable across systems and applications** — transportability is the first advantage.

**2. (Sub lesson 1)** XML separates data from —
a) itself  b) HTML  c) the user
**Answer: b) HTML** — separating data from HTML is a named advantage.

**3. (Sub lesson 2)** A real XML disadvantage is —
a) it requires a processing application  b) users cannot create their tags  c) it cannot travel between platforms
**Answer: a) it requires a processing application** — needing a processing application is real; the other two are false.

**4. (Sub lesson 2)** 'It does not allow users to create their tags' is —
a) XML's biggest disadvantage  b) a book error — creating tags is XML's whole point  c) an advantage
**Answer: b) a book error — creating tags is XML's whole point** — that bullet contradicts the whole unit and is taught as an error.
