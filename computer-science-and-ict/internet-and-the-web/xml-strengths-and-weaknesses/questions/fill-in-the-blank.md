# XML — strengths and weaknesses — fill in the blank

Fill each blank with the right word or code.

**1. (Sub lesson 1)** Data exchanges ___ between platforms with XML.
**Answer: quickly** — quick exchange is the advantage's wording.

**2. (Sub lesson 1)** XML separates data from ___.
**Answer: HTML** — data standing apart from HTML is the advantage.

**3. (Sub lesson 2)** XML's syntax can be confusing because it is very similar to other ___-based data-transmission formats.
**Answer: text** — text-based formats is the stated reason.
