# XML — strengths and weaknesses — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** XML simplifies the platform-exchange process.
**Answer: True** — that simplification is a named advantage.

**2. (Sub lesson 2)** XML has intrinsic, built-in data-type support.
**Answer: False** — no intrinsic data-type support is a named disadvantage.

**3. (Sub lesson 2)** XML's syntax is redundant.
**Answer: True** — redundancy — repeated tag names — is a named disadvantage.
