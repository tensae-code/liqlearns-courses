# HTML attributes — and the img element

## Do it first

Type a paragraph and open the page: its text sits at the left, as paragraphs do by default. Now add one extra piece inside the paragraph's start tag — your teacher shows you which — save, and look again. The text has jumped to the right. That extra piece is this lesson's subject.

## Sub lesson 1 — Attributes — name=value inside the start tag

An **attribute** gives an element **extra properties**. It is written **inside the start tag** as a **name=value pair**. Attributes are **usually optional**: a paragraph works without one — but with an **alignment attribute** its text can be pushed to the **right** instead of the **default left**. ## Sub lesson 2 — The img element needs its source attribute

Some elements **cannot work without** an attribute. The **image element** needs its **source attribute**, which **names the image file and where it lives**. The book's example assumes the image file sits **in the same folder as the page**. The guide adds (teacher guide — evidence): in its model pages the image addresses are **relative**, assuming an **images folder sitting beside the page file** — and its Activity 4.6 model pairs a right-aligned heading with a three-image page built exactly this way.
