# Lesson plan — HTML attributes — and the img element

**Course:** Computer Science and ICT · **Title:** Internet and the Web · **Lesson:** HTML attributes — and the img element
**Place in the curriculum:** Title — Internet and the Web in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 11 book, Unit 4 — Web Development. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** attributes give an element extra properties as name=value pairs inside its start tag — optional for most elements, but the image element cannot work without its source attribute.
**This lesson's own level:** it stands on the document-structure lesson — attributes are learned once whole pages can be written.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Attributes — name=value inside the start tag** — what an attribute is, where it is written, and the alignment example
2. **The img element needs its source attribute** — the source attribute the image element cannot work without; the guide's relative-address note

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: The structure of an HTML document. Recommended, never forced.

## What the learner can do when it ends
1. Write an attribute as a name=value pair inside a start tag.
2. Change a paragraph's alignment with an attribute.
3. Insert an image using its source attribute.

## What you need
A computer with a text editor and a browser; one image file in the page's folder.

## If the learner is stuck
- Writes the attribute outside the start tag → attributes live inside the start tag, as name=value.
- Image does not appear → check the source attribute names the file exactly, and that the file sits where the address says — the book's example keeps it in the page's own folder.
