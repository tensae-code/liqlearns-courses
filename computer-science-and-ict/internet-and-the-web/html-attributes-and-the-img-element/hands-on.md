# Hands-on — HTML attributes — and the img element

The lesson with your hands, not only your eyes. You need a computer with a text editor and a browser for the doing parts.

## Align it three ways
Write one paragraph. Show it left-aligned (no attribute), then right-aligned with the attribute. Save both versions and compare.

## Same-folder image
Put an image file in your page's folder, insert it with its source attribute, and open the page. Then move the file away and look again — that failure teaches what the source attribute does.
