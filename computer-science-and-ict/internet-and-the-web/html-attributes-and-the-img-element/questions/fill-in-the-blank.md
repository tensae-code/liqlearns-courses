# HTML attributes — and the img element — fill in the blank

Fill each blank with the right word or code.

**1. (Sub lesson 1) An attribute gives an element extra ___.**
**Answer: properties** — attributes = extra properties.

**2. (Sub lesson 1) Push a paragraph's text right with an ___ attribute.**
**Answer: alignment** — align = alignment.

**3. (Sub lesson 2) The img element's needed attribute is called its ___ attribute.**
**Answer: source** — source names the file.
