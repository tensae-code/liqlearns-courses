# HTML attributes — and the img element — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) An attribute is written as a name=value pair.**
**Answer: True** — that is its written form.

**2. (Sub lesson 1) Every element fails without an attribute.**
**Answer: False** — attributes are usually optional; the image element is the taught exception.

**3. (Sub lesson 2) The book's image example assumes the image file sits in the same folder as the page.**
**Answer: True** — same folder is the example's setup.
