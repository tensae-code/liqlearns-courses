# HTML attributes — and the img element — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) An attribute is written —**
a) inside the start tag, as a name=value pair  b) after the end tag  c) in the file name  d) in the head only
**Answer: a) inside the start tag, as a name=value pair** — attributes live inside the start tag.

**2. (Sub lesson 1) Attributes are usually —**
a) optional  b) forbidden  c) needed by every element to work at all  d) written in the browser
**Answer: a) optional** — usually optional — a paragraph works without one.

**3. (Sub lesson 1) Without any attribute, a paragraph's text sits at the —**
a) left  b) right  c) centre only  d) bottom
**Answer: a) left** — left is the default alignment.

**4. (Sub lesson 2) The image element cannot work without its —**
a) source attribute  b) alignment attribute  c) end tag  d) title
**Answer: a) source attribute** — no source, no image.

**5. (Sub lesson 2) The source attribute names —**
a) the image file and where it lives  b) the page's title  c) the visitor  d) the browser
**Answer: a) the image file and where it lives** — file plus location.

**6. (Sub lesson 2) In the guide's model pages, the image addresses are relative and assume — (teacher guide — evidence)**
a) an images folder sitting beside the page file  b) images on another continent  c) no folder at all  d) images inside the code
**Answer: a) an images folder sitting beside the page file** — the guide's own explanation of its models.
