# Static and dynamic web pages — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** You can modify a static page as you read it.
**Answer: False — you can read it, but not modify or interact with it.**

**2. (Sub lesson 2)** A dynamic page can show different content in a different time zone.
**Answer: True — time zone is one of the things it changes with.**

**3. (Sub lesson 1)** A static page is the right choice when information no longer needs to change.
**Answer: True — that is exactly its use.**
