# Static and dynamic web pages — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A static web page —
a) changes every hour  b) contains only static information — you can read it but not modify or interact with it  c) has no text  d) works only on phones
**Answer: b) contains only static information — you can read it but not modify or interact with it**

**2. (Sub lesson 1)** A static page stays the same until —
a) a visitor complains  b) it is updated  c) midnight  d) the browser closes
**Answer: b) it is updated**

**3. (Sub lesson 1)** Use a static page when —
a) information no longer needs to change  b) news breaks every hour  c) every visitor needs a different page  d) the page must greet by name
**Answer: a) information no longer needs to change**

**4. (Sub lesson 2)** A dynamic page's information changes depending on —
a) the viewer's shoe size  b) the viewer, the time of day, the time zone and the viewer's native language  c) the colour of the computer  d) nothing — it never changes
**Answer: b) the viewer, the time of day, the time zone and the viewer's native language**

**5. (Sub lesson 2)** A dynamic page changes —
a) only when its maker types it again  b) automatically, daily, to give visitors new content  c) never  d) only once a year
**Answer: b) automatically, daily, to give visitors new content**

**6. (Sub lesson 2)** A news page showing today's stories to each visitor is —
a) static  b) dynamic  c) printed  d) an email
**Answer: b) dynamic — it gives new content daily**
