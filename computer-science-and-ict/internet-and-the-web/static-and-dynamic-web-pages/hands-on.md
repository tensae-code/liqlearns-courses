# Hands-on — Static and dynamic web pages

The lesson with your hands, not only your eyes.

## Two visits
Visit one page today — in a browser if you can, on paper from memory if you cannot. Write down three things on it. Tomorrow, visit again and mark what changed and what stayed. Name its kind from the evidence.

## Make both kinds
On paper, draw one page twice: as a static page (the same both days) and as a dynamic page (new content on day two). Label what changed on the dynamic one.
