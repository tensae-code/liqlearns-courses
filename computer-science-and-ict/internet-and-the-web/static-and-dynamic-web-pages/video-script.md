# Video script — Static and dynamic web pages

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Two kinds of page.

A static page stays the same.
You read it. You do not change it.
It waits until someone updates it.

A dynamic page changes by itself.
New day — new content.
It can change for the viewer, the time, the language.

Still page — static. Changing page — dynamic.
