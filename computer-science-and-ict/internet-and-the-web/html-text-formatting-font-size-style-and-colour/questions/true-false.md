# HTML Text Formatting — Font Size, Style and Colour — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does this lesson format?" is: Text in hand-written HTML — its size, styles and colours**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does font size show on a page?" is: Bold and italic (either, for one)**
**Answer: False** — Rank — headings larger than body or detail text

**3. (Sub lesson 1) True or false: the answer to "Name the font styles the chapter teaches." is: Bold and italic (either, for one)**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does style show?" is: The page's background colour and the font colour of the text**
**Answer: False** — Emphasis — what the reader must not miss

**5. (Sub lesson 1) True or false: the answer to "In which two places is colour set?" is: The page's background colour and the font colour of the text**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What rule must the colour pair obey?" is: Setting size, style and colour on the same piece of text at once**
**Answer: False** — They must stay readable together — dark on light or light on dark

**7. (Sub lesson 2) True or false: the answer to "What does 'combining font properties' mean?" is: Setting size, style and colour on the same piece of text at once**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Why is decoration-everything a fault?" is: Grade 11 Term 2, Chapter 3 — after HTML structure, before links**
