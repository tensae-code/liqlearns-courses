**Course:** Computer Science and ICT · **Title:** Internet and the Web · **Lesson:** HTML Text Formatting — Font Size, Style and Colour
**Place in the curriculum:** ICT expansion — Libya (2026-11-14) — in the title Internet and the Web on the ICT course ladder (TITLES.md). **The one thing this lesson teaches:** Formatting text in hand-written HTML as Libya teaches it — changing a font's size, its styles, the page's background colour and the font's colour, and combining font properties in one place

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Size and style — how big, and in what manner** — Text formatting first fixes **how the words stand**: the **font size**, set for a piece of text so headings stand larger than body text; and the **font styles** — the manners of standing out the chapter teaches, such as **bold** and **italic** — used to mark what matters, not to decorate everything. The rule of the chapter is purpose: size shows **rank** (what is a heading, what is detail), style shows **emphasis** (what the reader must not miss).
2. **Colour and combining properties — background, font, together** — Colour is set in **two places**: the **background colour** of the page, and the **font colour** of the text — a pair that must stay **readable together**, dark text on a light ground or the reverse. The chapter closes by **combining font properties**: size, style and colour set on the **same piece of text at once**, so one heading can be large, bold and coloured in a single instruction. Combining is where formatting becomes design: every property chosen once, together, for one reason.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
