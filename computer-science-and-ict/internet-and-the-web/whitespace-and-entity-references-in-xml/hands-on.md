# Hands-on — Whitespace and entity references in XML

The lesson with your hands, not only your eyes.

## The swap drill
On paper, take five lines containing <, >, &, an apostrophe and a quotation mark as content. Rewrite each line with references in place. Swap with a partner and decode each other's.

## Space keeper
Type the same gappy sentence into an HTML page and into an XML document. Open both. Write down what happened to the spaces in each.
