# Whitespace and entity references in XML — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A wide gap of spaces typed in XML content stays wide.
**Answer: True** — XML does not truncate white spaces.

**2. (Sub lesson 2)** There are five predefined entity references.
**Answer: True** — less than, greater than, ampersand, apostrophe, quotation mark.

**3. (Sub lesson 2)** Replacing > with its reference is required because > is strictly illegal.
**Answer: False** — > is not strictly illegal — replacing it is good habit, not law.
