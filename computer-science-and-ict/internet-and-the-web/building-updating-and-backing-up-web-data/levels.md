# Building, Updating and Backing Up Web Data — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Building up and updating — the store at work
Sub lesson 1 questions from the type files. Pass mark: Building data up, updating it, backing it up; Validation — each is checked before it is stored; Found by its key, its fields corrected, and the store rewritten with the correction in place; Read the records, change the one, write the set back; A hand edit may break the format the readers depend on.

## Sub lesson 2 — Backing up — the copy that outlives the accident
Sub lesson 2 questions from the type files. Pass mark: A copy of the whole store, made regularly and kept apart from the working copy; So the accident that takes one copy does not take both; Tested — that it can actually be read back; A hope, not a backup; A trust.
