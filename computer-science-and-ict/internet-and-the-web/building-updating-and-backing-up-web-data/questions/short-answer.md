# Building, Updating and Backing Up Web Data — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What are this lesson's three duties?**
**Answer: Building data up, updating it, backing it up**

**2. (Sub lesson 1) Records are appended only after what?**
**Answer: Validation — each is checked before it is stored**

**3. (Sub lesson 1) How is a record updated?**
**Answer: Found by its key, its fields corrected, and the store rewritten with the correction in place**

**4. (Sub lesson 1) With text files, what does updating mechanically mean?**
**Answer: Read the records, change the one, write the set back**

**5. (Sub lesson 1) Why by program, never by hand edit?**
**Answer: A hand edit may break the format the readers depend on**

**6. (Sub lesson 2) What is a backup?**
**Answer: A copy of the whole store, made regularly and kept apart from the working copy**

**7. (Sub lesson 2) Why kept apart?**
**Answer: So the accident that takes one copy does not take both**

**8. (Sub lesson 2) What must be done to a backup besides making it?**
**Answer: Tested — that it can actually be read back**

**9. (Sub lesson 2) An untested backup is what?**
**Answer: A hope, not a backup**

**10. (Sub lesson 2) Keeping data for others is what, in Malaysia's close?**
**Answer: A trust**
