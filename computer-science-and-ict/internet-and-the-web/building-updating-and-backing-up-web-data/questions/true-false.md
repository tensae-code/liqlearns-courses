# Building, Updating and Backing Up Web Data — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What are this lesson's three duties?" is: Building data up, updating it, backing it up**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Records are appended only after what?" is: Found by its key, its fields corrected, and the store rewritten with the correction in place**
**Answer: False** — Validation — each is checked before it is stored

**3. (Sub lesson 1) True or false: the answer to "How is a record updated?" is: Found by its key, its fields corrected, and the store rewritten with the correction in place**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "With text files, what does updating mechanically mean?" is: A hand edit may break the format the readers depend on**
**Answer: False** — Read the records, change the one, write the set back

**5. (Sub lesson 1) True or false: the answer to "Why by program, never by hand edit?" is: A hand edit may break the format the readers depend on**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is a backup?" is: So the accident that takes one copy does not take both**
**Answer: False** — A copy of the whole store, made regularly and kept apart from the working copy

**7. (Sub lesson 2) True or false: the answer to "Why kept apart?" is: So the accident that takes one copy does not take both**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What must be done to a backup besides making it?" is: A hope, not a backup**
**Answer: False** — Tested — that it can actually be read back

**9. (Sub lesson 2) True or false: the answer to "An untested backup is what?" is: A hope, not a backup**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Keeping data for others is what, in Malaysia's close?" is: Building data up, updating it, backing it up**
**Answer: False** — A trust
