10. (Sub lesson 2) Keeping data for others is what, in Malaysia's close?

a) Validation — each is checked before it is stored
b) Read the records, change the one, write the set back
c) Building data up, updating it, backing it up
d) A hand edit may break the format the readers depend on
e) Found by its key, its fields corrected, and the store rewritten with the correction in place
f) So the accident that takes one copy does not take both
g) A hope, not a backup
h) A copy of the whole store, made regularly and kept apart from the working copy
i) A trust
j) Tested — that it can actually be read back
