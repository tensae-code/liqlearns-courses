# Building, Updating and Backing Up Web Data — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What are this lesson's three duties?**
a) Building data up, updating it, backing it up  b) Validation — each is checked before it is stored  c) Found by its key, its fields corrected, and the store rewritten with the correction in place  d) Read the records, change the one, write the set back
**Answer: a) Building data up, updating it, backing it up**

**2. (Sub lesson 1) Records are appended only after what?**
a) Found by its key, its fields corrected, and the store rewritten with the correction in place  b) Validation — each is checked before it is stored  c) Read the records, change the one, write the set back  d) A hand edit may break the format the readers depend on
**Answer: b) Validation — each is checked before it is stored**

**3. (Sub lesson 1) How is a record updated?**
a) Read the records, change the one, write the set back  b) A hand edit may break the format the readers depend on  c) Found by its key, its fields corrected, and the store rewritten with the correction in place  d) A copy of the whole store, made regularly and kept apart from the working copy
**Answer: c) Found by its key, its fields corrected, and the store rewritten with the correction in place**

**4. (Sub lesson 1) With text files, what does updating mechanically mean?**
a) A hand edit may break the format the readers depend on  b) A copy of the whole store, made regularly and kept apart from the working copy  c) So the accident that takes one copy does not take both  d) Read the records, change the one, write the set back
**Answer: d) Read the records, change the one, write the set back**

**5. (Sub lesson 1) Why by program, never by hand edit?**
a) A hand edit may break the format the readers depend on  b) A copy of the whole store, made regularly and kept apart from the working copy  c) So the accident that takes one copy does not take both  d) Tested — that it can actually be read back
**Answer: a) A hand edit may break the format the readers depend on**

**6. (Sub lesson 2) What is a backup?**
a) So the accident that takes one copy does not take both  b) A copy of the whole store, made regularly and kept apart from the working copy  c) Tested — that it can actually be read back  d) A hope, not a backup
**Answer: b) A copy of the whole store, made regularly and kept apart from the working copy**

**7. (Sub lesson 2) Why kept apart?**
a) Tested — that it can actually be read back  b) A hope, not a backup  c) So the accident that takes one copy does not take both  d) A trust
**Answer: c) So the accident that takes one copy does not take both**

**8. (Sub lesson 2) What must be done to a backup besides making it?**
a) A hope, not a backup  b) A trust  c) Building data up, updating it, backing it up  d) Tested — that it can actually be read back
**Answer: d) Tested — that it can actually be read back**

**9. (Sub lesson 2) An untested backup is what?**
a) A hope, not a backup  b) A trust  c) Building data up, updating it, backing it up  d) Validation — each is checked before it is stored
**Answer: a) A hope, not a backup**

**10. (Sub lesson 2) Keeping data for others is what, in Malaysia's close?**
a) Building data up, updating it, backing it up  b) A trust  c) Validation — each is checked before it is stored  d) Found by its key, its fields corrected, and the store rewritten with the correction in place
**Answer: b) A trust**
