# Hands-on — HTML or XML? Telling the two markup languages apart

The lesson with your hands, not only your eyes.

## The chart on one sheet
Draw the full comparison as a two-column chart on one big sheet — HTML left, XML right, one row per difference. Hang it where you revise.

## Spot the language
Collect five short code scraps (from lessons or a partner's writing). For each, name the language and the two rows of the chart that gave it away.
