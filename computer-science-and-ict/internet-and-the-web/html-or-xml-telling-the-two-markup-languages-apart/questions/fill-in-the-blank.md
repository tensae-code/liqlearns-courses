# HTML or XML? Telling the two markup languages apart — fill in the blank

Fill each blank with the right word or code.

**1. (Sub lesson 1)** XML files end in .___
**Answer: xml** — .xml against HTML's .html/.htm.

**2. (Sub lesson 2)** In the learning-curve row, XML also asks you to learn XPath, XML Schema and ___.
**Answer: DOM** — DOM completes the named set.

**3. (Sub lesson 2)** Case sensitivity: XML is sensitive, HTML is ___.
**Answer: not** — HTML is not case sensitive.
