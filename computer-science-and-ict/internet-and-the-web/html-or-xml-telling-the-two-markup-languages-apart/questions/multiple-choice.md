# HTML or XML? Telling the two markup languages apart — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** XML's purpose is —
a) display and presentation  b) transfer of data  c) printing pages
**Answer: b) transfer of data** — transfer of data is XML's purpose row.

**2. (Sub lesson 1)** Which is a framework for specifying markup languages?
a) HTML  b) XML  c) CSS
**Answer: b) XML** — XML is the framework; HTML is a predefined markup language.

**3. (Sub lesson 2)** In XML, coding errors are —
a) ignored if small  b) none allowed  c) fixed by the browser
**Answer: b) none allowed** — no errors are allowed in XML.

**4. (Sub lesson 2)** Closing tags in HTML are —
a) essential always  b) not always required  c) forbidden
**Answer: b) not always required** — not always required — the loose side of that row.
