# HTML or XML? Telling the two markup languages apart — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** HTML's tags are custom-defined by each author.
**Answer: False** — HTML's tags are predefined; XML's are custom-defined.

**2. (Sub lesson 1)** XML is driven by content; HTML is driven by format.
**Answer: True** — content-driven against format-driven is a named row.

**3. (Sub lesson 2)** Attribute quoting is required in HTML.
**Answer: False** — quoting is required in XML, not in HTML.
