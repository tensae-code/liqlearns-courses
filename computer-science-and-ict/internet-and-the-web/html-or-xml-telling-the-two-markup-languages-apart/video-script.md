# Video script — HTML or XML? Telling the two markup languages apart

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

HTML, or XML? Lay them side by side.
HTML: a predefined markup language. For display.
XML: a framework for markup languages. For data transfer.
XML is strict: proper nesting, no errors allowed, case matters.
Closing tags essential. Attribute values quoted. Always.
HTML is brief and familiar. XML takes more learning.
Two languages. Two jobs. Know the rows, know the difference.
