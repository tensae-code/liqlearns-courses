# Lesson plan — HTML or XML? Telling the two markup languages apart

**Course:** Computer Science and ICT · **Title:** Internet and the Web · **Lesson:** HTML or XML? Telling the two markup languages apart
**Place in the curriculum:** Title — Internet and the Web in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 12 book, Unit 4 — Web Authoring. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** HTML and XML differ row by row: language type, purpose, nesting, what drives them, size, learning curve, error tolerance, extensions, whitespace, case, tags, closing tags and quoting.
**This lesson's own level:** it stands on the whole XML run — the learner knows XML's rules from inside; this lesson sets the two markup languages side by side in the full comparison.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **What each language is, and what it is for** — language type (framework vs predefined), structural details, purpose (transfer vs display), driven by (content vs format), tags (custom vs predefined), extensions (.xml vs .html/.htm)
2. **Where XML is strict and HTML is loose** — nesting (proper in XML, no effect if improper in HTML), coding errors (none allowed vs small errors ignored), whitespace, case sensitivity, closing tags (essential vs not always required), attribute quoting (required vs not required)

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Well-formed XML — root, case and nesting rules; Naming XML elements — and empty elements. Recommended, never forced.

## What the learner can do when it ends
1. State the purpose difference: data transfer against display.
2. Give the strictness differences: nesting, errors, case, closing tags, quoting.
3. Give the identity differences: language type, tags, extensions, whitespace, size, learning curve.

## If the learner is stuck
- Calls XML a replacement for HTML → XML is a framework for specifying markup languages; HTML is one predefined markup language — they do different jobs.
- Forgives an XML error because HTML forgives → in XML, no coding errors are allowed.
