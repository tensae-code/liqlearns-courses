# Kinds of web browser

## Do it first

Think of every browser icon you have ever seen — on a phone, a school computer, a friend's laptop. Name them all. Now compare your list with the book's five pictured browsers.

## The five the book pictures

The most common browser applications, as the book pictures them, are five: **Internet Explorer**, **Mozilla Firefox**, **Google Chrome**, **Safari** and **Opera**. Different names, different makers — the same job: exploring the internet, locating and viewing web pages, moving from page to page. Whichever of the five is on your computer, the skills of this title — addresses, links, searching — work the same way in it.
