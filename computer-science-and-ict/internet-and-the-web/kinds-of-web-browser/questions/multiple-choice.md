# Kinds of web browser — multiple choice

Pick the one right answer.

**1.** How many browsers does the book picture?
a) Three  b) Five  c) Two  d) Ten
**Answer: b) Five** — Explorer, Firefox, Chrome, Safari, Opera.

**2.** Which is one of the five?
a) Yahoo  b) Safari  c) Word  d) Ethio-telecom
**Answer: b) Safari** — Safari is a browser; Yahoo is a search engine.

**3.** Mozilla ______ is a browser.
a) Firefox  b) Thunder  c) Reader  d) Office
**Answer: a) Firefox** — Mozilla Firefox.

**4.** Which is NOT among the book's five?
a) Opera  b) Google Chrome  c) Internet Explorer  d) Google search
**Answer: d) Google search** — Google search is a search engine, not a browser.

**5.** All five browsers share one job:
a) writing documents  b) exploring the internet  c) cleaning disks  d) making passwords
**Answer: b) exploring the internet** — the browser's job, from the earlier lesson.

**6.** ______ Explorer is a browser.
a) Internet  b) File  c) Windows  d) Web
**Answer: a) Internet** — Internet Explorer.
