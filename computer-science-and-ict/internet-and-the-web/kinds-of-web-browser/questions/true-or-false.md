# Kinds of web browser — true or false

Say whether each sentence is true or false.

**1.** Opera is one of the book's five browsers.
**Answer: True** — Explorer, Firefox, Chrome, Safari, Opera.

**2.** Chrome and the Google search engine are the same thing.
**Answer: False** — Chrome is a browser; Google search is a search engine.

**3.** Safari is a browser.
**Answer: True** — one of the five.
