# Hands-on — Kinds of web browser

The lesson with your hands, not only your eyes.

## Icon hunt
Hunt the computers and phones you can access for browser icons. Write down every browser name you find, and tick off which of the book's five you found in real life.

## Five-name chant
Write the five names as a list, cover it, and write it again from memory. Repeat until the five come in the book's order without a peek.
