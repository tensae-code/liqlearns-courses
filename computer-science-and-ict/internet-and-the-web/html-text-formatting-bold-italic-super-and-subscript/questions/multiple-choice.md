# HTML Text Formatting — Bold, Italic, Superscript and Subscript — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Which element makes text bold?**
a) <b>  b) Titles and foreign words (emphasis that leans)  c) Readers now read underlines as links  d) Size, relative to neighbouring text
**Answer: a**

**2. (Sub lesson 1) What is italic used for?**
a) Titles and foreign words (emphasis that leans)  b) Readers now read underlines as links  c) Size, relative to neighbouring text  d) A container — opening tag, text, closing tag
**Answer: a**

**3. (Sub lesson 1) Why should underline be used sparingly?**
a) Readers now read underlines as links  b) Size, relative to neighbouring text  c) A container — opening tag, text, closing tag  d) <sup> — superscript
**Answer: a**

**4. (Sub lesson 1) What do <big> and <small> change?**
a) Size, relative to neighbouring text  b) A container — opening tag, text, closing tag  c) <sup> — superscript  d) H<sub>2</sub>O
**Answer: a**

**5. (Sub lesson 1) What shape is every formatting element?**
a) A container — opening tag, text, closing tag  b) <sup> — superscript  c) H<sub>2</sub>O  d) Formulas and ordinals like 10th (also footnotes)
**Answer: a**
