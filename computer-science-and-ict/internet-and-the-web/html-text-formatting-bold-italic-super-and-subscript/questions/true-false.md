# HTML Text Formatting — Bold, Italic, Superscript and Subscript — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: <b>**
**Answer: True**

**2. (Sub lesson 1) True or false: <b>** — as the answer to: What is italic used for?
**Answer: False — Titles and foreign words (emphasis that leans)**

**3. (Sub lesson 1) True or false: Readers now read underlines as links**
**Answer: True**

**4. (Sub lesson 1) True or false: Readers now read underlines as links** — as the answer to: What do <big> and <small> change?
**Answer: False — Size, relative to neighbouring text**

**5. (Sub lesson 1) True or false: A container — opening tag, text, closing tag**
**Answer: True**

**6. (Sub lesson 2) True or false: A container — opening tag, text, closing tag** — as the answer to: Which element raises text?
**Answer: False — <sup> — superscript**

**7. (Sub lesson 2) True or false: H<sub>2</sub>O**
**Answer: True**

**8. (Sub lesson 2) True or false: H<sub>2</sub>O** — as the answer to: Name two homes of superscript.
**Answer: False — Formulas and ordinals like 10th (also footnotes)**

**9. (Sub lesson 2) True or false: Science writing — formulas and chemical names**
**Answer: True**

**10. (Sub lesson 2) True or false: Science writing — formulas and chemical names** — as the answer to: What is the family's rule of use?
**Answer: False — Formatting serves meaning, never decoration everywhere**
