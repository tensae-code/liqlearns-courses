# Lesson plan — Website Project — a School, Tourism or E-Library Site

**Course:** Computer Science and ICT · **Title:** Internet and the Web · **Lesson:** Website Project — a School, Tourism or E-Library Site
**Place in the curriculum:** ICT expansion — Libya (2026-11-14) — in the title Internet and the Web on the ICT course ladder (TITLES.md). Built new from Libya's student books (Libya Ministry of Education / Centre for Educational Curricula and Research, 2019–2020), because no existing lesson in the course covers this thing as its own lesson.
**The one thing this lesson teaches:** Libya's three set website projects — building a complete site for a secondary school, for a tourism company, or as an electronic library — using the whole Term 2 web course at once
**This lesson's own level:** It stands on the earlier lessons of its title and on the book's own order — it follows the book's lessons in sequence, so its neighbours in the book are its natural companions. It stands alone for a learner landing on it directly.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The three set projects — one course, three real sites** — Each project is a **complete website** for a named owner with a named audience: the **secondary-school website** serves pupils, parents and teachers; the **tourism-company website** must persuade visitors and show what the company offers; the **electronic library** must let readers **find and reach books**. The three differ in purpose — informing, persuading, providing — so the same HTML course is bent three ways, and choosing **pages, order and content** for the audience is the project's first and largest work.
2. **Building the project — the term's skills in order** — The build uses the term in its own order: **structure** every page (head, title, body), **format** the text (size, style, colour), **link** the pages and the outside with text and image links, **list and tabulate** what the site holds, then **publish**: a registered **domain**, a chosen **host**, and the files **uploaded by FTP**. A project is judged whole: does a visitor reach everything in a few clicks, do the pages look like one site, and does the published site — not the folder on your machine — actually work?

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
