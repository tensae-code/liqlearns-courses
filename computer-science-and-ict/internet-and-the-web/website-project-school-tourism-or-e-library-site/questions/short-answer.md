# Website Project — a School, Tourism or E-Library Site — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) Name Libya's three set website projects.**
**Answer: A secondary-school website, a tourism-company website, and an electronic library**

**2. (Sub lesson 1) What is each project's audience work?**
**Answer: Choosing pages, order and content for the site's named audience — the project's first and largest work**

**3. (Sub lesson 1) How do the three projects' purposes differ?**
**Answer: Informing (school), persuading (tourism), providing (e-library)**

**4. (Sub lesson 1) What must an e-library site let readers do?**
**Answer: Find and reach books**

**5. (Sub lesson 1) Name the build stages in the term's order.**
**Answer: Structure, formatting, links, lists and tables, then publishing (any four in order)**

**6. (Sub lesson 2) What does publishing require?**
**Answer: A registered domain, a chosen host, and the files uploaded by FTP**

**7. (Sub lesson 2) How is a project judged?**
**Answer: As a whole: reach, unity of look, and the published site actually working**

**8. (Sub lesson 2) Why is the published site judged, not the folder?**
**Answer: Because the folder working proves nothing about what visitors receive**

**9. (Sub lesson 2) Which term's course does this project close?**
**Answer: Libya's Grade 11 Term 2 web-authoring course**

**10. (Sub lesson 2) Is anything in the project new?**
**Answer: No — it uses the whole term's skills at once**
