# Website Project — a School, Tourism or E-Library Site — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Name Libya's three set website projects." is: A secondary-school website, a tourism-company website, and an electronic library**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is each project's audience work?" is: Informing (school), persuading (tourism), providing (e-library)**
**Answer: False** — Choosing pages, order and content for the site's named audience — the project's first and largest work

**3. (Sub lesson 1) True or false: the answer to "How do the three projects' purposes differ?" is: Informing (school), persuading (tourism), providing (e-library)**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What must an e-library site let readers do?" is: Structure, formatting, links, lists and tables, then publishing (any four in order)**
**Answer: False** — Find and reach books

**5. (Sub lesson 1) True or false: the answer to "Name the build stages in the term's order." is: Structure, formatting, links, lists and tables, then publishing (any four in order)**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does publishing require?" is: As a whole: reach, unity of look, and the published site actually working**
**Answer: False** — A registered domain, a chosen host, and the files uploaded by FTP

**7. (Sub lesson 2) True or false: the answer to "How is a project judged?" is: As a whole: reach, unity of look, and the published site actually working**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Why is the published site judged, not the folder?" is: Libya's Grade 11 Term 2 web-authoring course**
**Answer: False** — Because the folder working proves nothing about what visitors receive

**9. (Sub lesson 2) True or false: the answer to "Which term's course does this project close?" is: Libya's Grade 11 Term 2 web-authoring course**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Is anything in the project new?" is: A secondary-school website, a tourism-company website, and an electronic library**
**Answer: False** — No — it uses the whole term's skills at once
