# Accessing a website — address, keyword and ISP — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Route 1 to a website is —
a) guessing  b) typing its address and following links  c) asking a friend  d) restarting the computer
**Answer: b) typing its address and following links** — address first, then links.

**2. (Sub lesson 1)** 'The Victory of Adwa' is the book's example of —
a) an address  b) a search keyword  c) a browser  d) an ISP
**Answer: b) a search keyword** — a keyword search example.

**3. (Sub lesson 1)** Use the keyword route when —
a) you know the exact address  b) you know the topic but not the address  c) the computer is off  d) you want to print
**Answer: b) you know the topic but not the address** — keyword when only the topic is known.

**4. (Sub lesson 2)** Connecting to the internet requires —
a) a printer  b) an Internet Service Provider  c) a word processor  d) a password only
**Answer: b) an Internet Service Provider** — an ISP makes the connection.

**5. (Sub lesson 2)** Ethiopia's example ISP is —
a) Ethiopian Airlines  b) Ethio-telecom  c) the Ministry  d) Google
**Answer: b) Ethio-telecom** — Ethio-telecom.

**6. (Sub lesson 2)** The Bikila research is judged on —
a) one single correct answer  b) finding information, a half-page report, and listing your keywords  c) speed only  d) copying the first result
**Answer: b) finding information, a half-page report, and listing your keywords** — the guide's assessment rule.

**7. (Sub lesson 3)** Browsing information means —
a) printing pages  b) searching or finding information on the internet  c) closing the browser  d) saving every page
**Answer: b) searching or finding information on the internet**

**8. (Sub lesson 3)** The first searching step is —
a) press Enter  b) open a search engine using a web browser  c) click a result  d) type the answer
**Answer: b) open a search engine using a web browser**

**9. (Sub lesson 3)** After you press Enter, —
a) the computer switches off  b) a list of relevant websites — the search results — is displayed  c) a password is asked  d) the page prints
**Answer: b) a list of relevant websites — the search results — is displayed**
