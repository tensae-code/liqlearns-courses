# Accessing a website — address, keyword and ISP — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Following links is part of reaching information by address.
**Answer: True** — type the address, then travel by links.

**2. (Sub lesson 2)** Everything found online about Abebe Bikila is true.
**Answer: False** — false material circulates; use official sources.

**3. (Sub lesson 2)** An ISP is the company that connects you to the internet.
**Answer: True** — Internet Service Provider.

**4. (Sub lesson 3)** Google is the most popular search engine named.
**Answer: True — Google and Yahoo are named; Google is the most popular.**

**5. (Sub lesson 3)** If a result disappoints, you must start a brand-new search at once.
**Answer: False — you can return to the results page for more options.**
