# HTML Headings and Paragraphs — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "How many heading levels does HTML give?" is: Six — h1 to h6**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Which heading is biggest and most important?" is: An opening tag, the heading text, and a closing tag**
**Answer: False** — h1 — usually the page's title

**3. (Sub lesson 1) True or false: the answer to "What are the parts of a heading element?" is: An opening tag, the heading text, and a closing tag**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How do browsers show headings?" is: No — they are a rank, stepped down in order like chapters and sections**
**Answer: False** — Bold, sized by level, with space around them

**5. (Sub lesson 1) True or false: the answer to "Are heading levels just sizes?" is: No — they are a rank, stepped down in order like chapters and sections**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Which element wraps ordinary text?" is: No — running spaces and breaks are gathered and the text flows to the window's width**
**Answer: False** — The paragraph element — <p>…</p>

**7. (Sub lesson 2) True or false: the answer to "Are line breaks typed in the HTML shown by the browser?" is: No — running spaces and breaks are gathered and the text flows to the window's width**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How does HTML separate one thought from the next?" is: <h2>Sports Day</h2>**
**Answer: False** — A new <p> element for each paragraph

**9. (Sub lesson 2) True or false: the answer to "Write a level-2 heading element for the text Sports Day." is: <h2>Sports Day</h2>**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What carries a page's actual reading?" is: Six — h1 to h6**
**Answer: False** — The paragraphs, under their headings
