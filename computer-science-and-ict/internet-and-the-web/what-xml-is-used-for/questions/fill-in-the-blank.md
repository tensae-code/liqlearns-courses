# What XML is used for — fill in the blank

Fill each blank with the right word or code.

**1. (Sub lesson 1)** books holds book; book holds title, author and ___.
**Answer: type** — the three detail elements are title, author and type.

**2. (Sub lesson 2)** Data lacking ___ structure can suit XML storage.
**Answer: relational** — no relational shape is one of the two named cases.

**3. (Sub lesson 2)** XML presents web pages alongside other ___.
**Answer: resources** — presentation is XML plus other resources, together.
