# What XML is used for — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** In the book record, the element that holds title, author and type is —
a) books  b) book  c) type
**Answer: b) book** — book holds the three details; books holds book.

**2. (Sub lesson 1)** The outer element of the record is —
a) title  b) author  c) books
**Answer: c) books** — books is the outermost box.

**3. (Sub lesson 2)** XML suits storage when a database is inappropriate because the data is —
a) always huge  b) small in quantity, or lacking relational structure  c) printed on paper
**Answer: b) small in quantity, or lacking relational structure** — those are the two named cases.

**4. (Sub lesson 2)** For web pages, XML works —
a) alone, doing the presenting itself  b) alongside other resources that present the pages  c) only on paper
**Answer: b) alongside other resources that present the pages** — XML supplies structured data; other resources present it.
