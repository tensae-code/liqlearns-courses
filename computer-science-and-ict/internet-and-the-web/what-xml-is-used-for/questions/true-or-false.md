# What XML is used for — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** The tags in the book record say how the record should look on screen.
**Answer: False** — they say what each piece of data is, not how it looks.

**2. (Sub lesson 2)** Programmers sometimes prefer their own format for small amounts of data.
**Answer: True** — that preference is named for exactly this case.

**3. (Sub lesson 2)** A large store with a clear relational shape is the case XML storage is named for.
**Answer: False** — that is a database's case; XML storage is for small or non-relational data.
