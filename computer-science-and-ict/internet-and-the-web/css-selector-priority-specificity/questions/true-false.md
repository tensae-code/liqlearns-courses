# CSS Selector Priority — Which Rule Wins — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Priority — specificity: the more specific selector wins**
**Answer: True**

**2. (Sub lesson 1) True or false: Priority — specificity: the more specific selector wins** — as the answer to: What beats every selector?
**Answer: False — An inline style, written in the element's style attribute**

**3. (Sub lesson 1) True or false: Id highest, then class, then element**
**Answer: True**

**4. (Sub lesson 1) True or false: Id highest, then class, then element** — as the answer to: A class says blue, an element rule says black — which wins?
**Answer: False — The class rule — blue**

**5. (Sub lesson 1) True or false: Because until you can predict the winning rule, styling is guessing**
**Answer: True**

**6. (Sub lesson 2) True or false: Because until you can predict the winning rule, styling is guessing** — as the answer to: Two rules have equal priority — which wins?
**Answer: False — The later rule in the stylesheet**

**7. (Sub lesson 2) True or false: Elements generally first, then classes, ids sparingly, inline styles almost never**
**Answer: True**

**8. (Sub lesson 2) True or false: Elements generally first, then classes, ids sparingly, inline styles almost never** — as the answer to: Why are inline styles a trap?
**Answer: False — They cannot be overridden, so they fight every later design change**

**9. (Sub lesson 2) True or false: Find every rule touching the element and climb the priority ladder**
**Answer: True**

**10. (Sub lesson 2) True or false: Find every rule touching the element and climb the priority ladder** — as the answer to: What is the cascade?
**Answer: False — CSS's order of reading and settling rules — the flow that gives the style sheets their name**
