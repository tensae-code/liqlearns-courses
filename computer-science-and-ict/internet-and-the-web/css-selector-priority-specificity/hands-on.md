# Hands-on — CSS Selector Priority — Which Rule Wins

The lesson with your hands and your feet, not only your eyes.

## Task one
**Predict the winner** — Write three rules for one paragraph — element, class, id — with three colours. Predict the rendered colour, then check in a browser.

## Task two
**Fix by the ladder** — Take a page where a heading shows the wrong colour. List every rule that touches it and fix the colour by changing the right rule, not by adding an inline style.
