# Attributes or elements? Carrying the same information two ways — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** An attribute is a —
a) key-value pair on an element  b) second root  c) kind of comment
**Answer: a) key-value pair on an element** — key-value pair is the definition.

**2. (Sub lesson 1)** If an attribute value itself contains double quotes, you wrap it in —
a) no quotes  b) single quotes  c) double quotes twice
**Answer: b) single quotes** — single quotes rescue a value containing double quotes.

**3. (Sub lesson 2)** Gender as an attribute and gender as an element carry —
a) different information  b) exactly the same information  c) no information
**Answer: b) exactly the same information** — the paired example carries one fact two ways.

**4. (Sub lesson 2)** XML's rule for when to use attributes versus elements is —
a) always attributes  b) always elements  c) there is no such rule
**Answer: c) there is no such rule** — XML has no rule for the choice.
