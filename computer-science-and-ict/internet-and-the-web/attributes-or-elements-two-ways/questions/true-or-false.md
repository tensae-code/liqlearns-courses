# Attributes or elements? Carrying the same information two ways — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** An attribute value can be quoted with single quotes.
**Answer: True** — single or double quotes both quote a value.

**2. (Sub lesson 2)** Storing gender as an element instead of an attribute changes the information.
**Answer: False** — the information is the same; only its carrying form changes.

**3. (Sub lesson 1)** A value containing double quotes can still be wrapped in double quotes if you are careful.
**Answer: False** — it must be wrapped in single quotes instead.
