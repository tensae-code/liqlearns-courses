# Video script — Attributes or elements? Carrying the same information two ways

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

One fact. Two homes.
Gender, riding on the person element: an attribute.
Gender, sitting inside it: a child element.
Both carry the same information.
Which one is right? XML has no rule. None.
One craft point: a value with double quotes inside it?
Wrap that value in single quotes. Done.
