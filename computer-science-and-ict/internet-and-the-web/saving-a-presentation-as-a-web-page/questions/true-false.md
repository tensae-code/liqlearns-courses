# Saving a Presentation as a Web Page — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What job does this section do?" is: Publication — turning a presentation into pages anyone can view.**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does a presentation saved as a web page become?" is: It must speak for itself, with the explanation written on or under it.**
**Answer: False** — A small site — the slides as pages, in the talk's order.

**3. (Sub lesson 1) True or false: the answer to "What does the viewer need?" is: Only a browser — no presentation program and no presenter.**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What carries over in the saving?" is: At the first page, moving through with the links the saving provides.**
**Answer: False** — The slides' content and look — text, pictures and order.

**5. (Sub lesson 1) True or false: the answer to "What does not fully carry over?" is: The live performance — the speaker's words, timing, and program-run effects.**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How must a web-bound slide differ?" is: The second easy-tool rung — after Word pages, before hand-written HTML.**
**Answer: False** — It must speak for itself, with the explanation written on or under it.

**7. (Sub lesson 2) True or false: the answer to "What is the readiness check?" is: Walking the saved pages as a stranger would.**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Where does the viewer start?" is: A small site — the slides as pages, in the talk's order.**
**Answer: False** — At the first page, moving through with the links the saving provides.

**9. (Sub lesson 2) True or false: the answer to "Why publish this way at all?" is: So anyone with the link can view the talk, without the program or the room.**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Which rung of the book's ladder is this?" is: The slides' content and look — text, pictures and order.**
**Answer: False** — The second easy-tool rung — after Word pages, before hand-written HTML.
