# Saving a Presentation as a Web Page — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What job does this section do?**
a) Publication — turning a presentation into pages anyone can view  b) The slides' content and look — text, pictures and order  c) It must speak for itself, with the explanation written on or under it  d) At the first page, moving through with the links the saving provides
**Answer: a) Publication — turning a presentation into pages anyone can view**

**2. (Sub lesson 1) What does a presentation saved as a web page become?**
a) The live performance — the speaker's words, timing, and program-run effects  b) A small site — the slides as pages, in the talk's order  c) Walking the saved pages as a stranger would  d) So anyone with the link can view the talk, without the program or the room
**Answer: b) A small site — the slides as pages, in the talk's order**

**3. (Sub lesson 1) What does the viewer need?**
