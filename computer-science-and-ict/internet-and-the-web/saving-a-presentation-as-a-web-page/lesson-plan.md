# Lesson plan — Saving a Presentation as a Web Page

**Course:** Computer Science and ICT · **Title:** Internet and the Web · **Lesson:** Saving a Presentation as a Web Page
**Place in the curriculum:** ICT expansion — Belarus (2026-11-14) — in the title Internet and the Web on the ICT course ladder (TITLES.md). Built new from Belarus's *Інфарматыка* Grade 11, because no existing lesson in the course covers this thing as its own lesson.
**The one thing this lesson teaches:** A PowerPoint presentation can be published without PowerPoint: saving it as a web page turns its slides into linked pages a browser can walk through, so anyone with the link can view the talk.
**This lesson's own level:** It stands on the earlier lessons of its title and on the Belarus book's own order — it follows the book's sections in sequence, so its neighbours in the book are its natural companions. It stands alone for a learner landing on it directly.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Publishing slides as pages** — The job of this section is **publication**: a presentation normally needs its own program and its audience in the room, but saved **as a web page** it becomes a small site — the slides as pages, in the talk's order, that any **browser** can open. The viewer's part is simple: open the first page and move through the slides with the links the saving provides. The presenter's part ends at publishing: once saved as pages, the presentation no longer needs the presenter, the program, or the room.
2. **What carries over, what does not** — What carries over is the slides' **content and look**: text, pictures and order. What does not fully carry is the live performance — the speaker's words, the timing, and effects that depended on the program running. So a presentation meant for the web is prepared differently: each slide must **speak for itself**, with the explanation the speaker would have said written onto the slide or under it. The check is to walk the saved pages as a stranger would: if a slide only made sense while someone talked over it, it is not ready to be a page.

## What the learner can do when it ends
1. Publication — turning a presentation into pages anyone can view.
2. Only a browser — no presentation program and no presenter.
3. It must speak for itself, with the explanation written on or under it.
4. So anyone with the link can view the talk, without the program or the room.

## What you need
Paper and a pencil, and a computer with the program this lesson uses, if available.

## The run of the lesson (in order)
1. **Do it first** — Your talk is finished — but only the people in the room saw it. In this lesson you publish the presentation itself as web pages anyone can walk through, and you learn what a slide must carry when there is no speaker standing beside it. (lesson/lesson.md).
2. **The explanation** — the lesson text in lesson/lesson.md, in its parts in order.
   - ADD IMAGE: a picture of a row of presentation slides turning into a row of browser pages linked by arrows — the student studies the picture and names what each part shows.
   - ADD GIF: a GIF of one slide with the speaker's missing words being written in underneath it — the student watches once, then says what changed and why.
   - ADD AUDIO: a voice reading the lesson's key names and definitions aloud, in the order the lesson gives them — the student listens once through, then reads the same lines aloud along with the voice. (Audio is a described slot in this build; no audio file is made.)
3. **Say it to your companion** — the companion block in lesson/lesson.md.
   - ADD VIDEO: the script in video-script.md, filmed — the lesson in the super-simple voice (made later, when videos are made).
4. **Questions** — from questions/: multiple-choice, true-false, matching, short-answer — served at the learner's level and teaching-mix (levels.md).
5. **Hands-on** — hands-on.md.
6. **Do It Yourself** — the doing block at the end of lesson/lesson.md.
