# Hands-on — Saving a Presentation as a Web Page

The lesson with your hands and your feet, not only your eyes.

## Slides to site
Save a short presentation as a web page and open it in a browser. Walk it from first slide to last using only the provided links, and note anything that only made sense with a speaker.

## Make a slide speak
Take the weakest slide from the walk-through and rewrite it so it speaks for itself — the explanation written on or under the slide. Save and check it again as a stranger.
