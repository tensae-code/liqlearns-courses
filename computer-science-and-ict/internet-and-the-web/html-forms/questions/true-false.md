# HTML Forms — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: It collects a visitor's input and sends it to a server**
**Answer: True**

**2. (Sub lesson 1) True or false: It collects a visitor's input and sends it to a server** — as the answer to: Which attribute of <input> chooses the field kind?
**Answer: False — The type attribute**

**3. (Sub lesson 1) True or false: Radio buttons — checkboxes allow ticking any number**
**Answer: True**

**4. (Sub lesson 1) True or false: Radio buttons — checkboxes allow ticking any number** — as the answer to: What does every field need beside it?
**Answer: False — A <label> — the visible words saying what the field asks, joined by matching for and id**

**5. (Sub lesson 1) True or false: Grade 9, §5 — lists and forms in a webpage**
**Answer: True**

**6. (Sub lesson 2) True or false: Grade 9, §5 — lists and forms in a webpage** — as the answer to: How is a form sent?
**Answer: False — By its submit control**

**7. (Sub lesson 2) True or false: Action says where the data goes; method says how (GET in the address, POST in the body)**
**Answer: True**

**8. (Sub lesson 2) True or false: Action says where the data goes; method says how (GET in the address, POST in the body)** — as the answer to: What does the required attribute do?
**Answer: False — The browser will not send the form until that field is filled**

**9. (Sub lesson 2) True or false: An example inside the field showing the expected kind of answer**
**Answer: True**

**10. (Sub lesson 2) True or false: An example inside the field showing the expected kind of answer** — as the answer to: What is the politeness rule of forms?
**Answer: False — Ask only what will actually be used — a form requests a stranger's data**
