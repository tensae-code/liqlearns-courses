# Hands-on — Colours for Text and Background in CSS

The lesson with your hands and your feet, not only your eyes.

## Task one
**Three names, one colour** — Write one colour three ways — name, hex, rgb — and use each in a rule. Check all three render the same.

## Task two
**Contrast check** — Make two heading styles: one with a readable colour pair, one with a poor pair. Say what makes the first work and fix the second.
