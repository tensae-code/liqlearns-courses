## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Colour for text — the color property** — CSS colours text with the **color** property: `p { color: blue; }` recolours every paragraph. A colour can be named in several ways — by a **colour name** (red, darkgreen), by **hexadecimal** (`#FF0000`), or by **rgb()** values (`rgb(255, 0, 0)`) that mix red, green and blue light from 0 to 255. Vietnam's Grade 12 book gives colour its own lesson because colour is the first design decision a page makes — and the first that can go wrong, when text stops being readable against its ground.
2. **Backgrounds — the ground the page stands on** — The **background-color** property colours the ground behind an element — a heading's band, a box, or the whole page through `body`. Text colour and background colour are chosen **together**: the pair must keep **contrast** high enough to read comfortably, for every visitor, including those who see colours weakly. The book's discipline is the designer's: few colours, used consistently, each earning its place — decoration that fights the reading loses.
