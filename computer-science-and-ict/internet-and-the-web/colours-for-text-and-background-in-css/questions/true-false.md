# Colours for Text and Background in CSS — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: color**
**Answer: True**

**2. (Sub lesson 1) True or false: color** — as the answer to: What are three ways to name a colour in CSS?
**Answer: False — By a colour name, by a hexadecimal value, or by rgb() values**

**3. (Sub lesson 1) True or false: Pure red — full red light, no green, no blue**
**Answer: True**

**4. (Sub lesson 1) True or false: Pure red — full red light, no green, no blue** — as the answer to: What do the three rgb numbers range over?
**Answer: False — 0 to 255 each — the amounts of red, green and blue light**

**5. (Sub lesson 1) True or false: Text that stops being readable against its background**
**Answer: True**

**6. (Sub lesson 2) True or false: Text that stops being readable against its background** — as the answer to: Which property colours the ground behind an element?
**Answer: False — background-color**

**7. (Sub lesson 2) True or false: Through the body element's background-color**
**Answer: True**

**8. (Sub lesson 2) True or false: Through the body element's background-color** — as the answer to: What must the text/background pair keep?
**Answer: False — Contrast high enough to read comfortably, for every visitor**

**9. (Sub lesson 2) True or false: Few — used consistently, each earning its place**
**Answer: True**

**10. (Sub lesson 2) True or false: Few — used consistently, each earning its place** — as the answer to: What loses, when decoration fights reading?
**Answer: False — The decoration — readability wins**
