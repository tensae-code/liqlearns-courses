# Lesson plan — Project — Building a Website about AI Applications

**Course:** Computer Science and ICT · **Title:** Internet and the Web · **Lesson:** Project — Building a Website about AI Applications
**Place in the curriculum:** ICT expansion — Kuwait (2026-11-14) — in the title Internet and the Web on the ICT course ladder (TITLES.md). Built new from Kuwait's student books (Ministry of Education, State of Kuwait), because no existing lesson in the course covers this thing as its own lesson — the live tree and live lesson content were checked for the slug and for near matches before building.
**The one thing this lesson teaches:** Kuwait's Grade 9 integrated web project — a seven-file website, 'Explore AI Applications', with a contact form page, built in full
**This lesson's own level:** It stands on the earlier lessons of its title and on the book's own order — it follows the book's lessons in sequence, so its neighbours in the book are its natural companions. It stands alone for a learner landing on it directly.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The site — seven files, one subject** — **Explore AI Applications** is a **seven-file website**: its pages built in VS Code across the project — the home page and the application pages that survey where AI works — styled by the course's CSS, linked into one family, with images and tables in their HTML lessons' crafts. Seven files is the project's discipline: big enough that organisation matters (the project folder, consistent styles, working links everywhere), small enough to finish whole.
2. **The contact form page — the site that listens** — Among the seven stands the **contact form page**: the page where a visitor **writes to the site** — name, message, the form's fields and its sending. It changes the site's nature: every other page speaks; this one **listens**. Kuwait ends the hand-built site here, with hosting and FTP as the project's road out (taught beside it), because a site that can be visited and answered is the complete thing the year promised: designed, built, styled, linked, published, and open for reply.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## The run of the lesson (in order)
1. **Do it first** — The Grade 9 web course ends by building a whole site, on the course's own great subject: AI itself. Seven files, every HTML and CSS lesson spent at once, and a page where the site's visitors write back. This lesson is that build. (lesson/lesson.md).
2. **The explanation** — the lesson text in lesson/lesson.md, in its parts in order.
   - ADD IMAGE: a picture of the site — seven files, one subject as the lesson describes it — the student studies the picture and names what each part shows.
   - ADD GIF: a GIF of the contact form page — the site that listens in action — the student watches once, then says what changed and why.
   - ADD AUDIO: a voice reading the lesson's key names and definitions aloud, in the order the lesson gives them — the student listens once through, then reads the same lines aloud along with the voice. (Audio is a described slot in this build; no audio file is made.)
3. **Say it to your companion** — the companion block in lesson/lesson.md.
   - ADD VIDEO: the script in video-script.md, filmed — the lesson in the super-simple voice (made later, when videos are made).
4. **Questions** — from questions/: multiple-choice, true-false, matching, short-answer — served at the learner's level and teaching-mix (levels.md).
5. **Hands-on** — hands-on.md.
6. **Do It Yourself** — the doing block at the end of lesson/lesson.md.
