# Lesson plan — Void elements — br, img, hr

**Course:** Computer Science and ICT · **Title:** Internet and the Web · **Lesson:** Void elements — br, img, hr
**Place in the curriculum:** Title — Internet and the Web in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 11 book, Unit 4 — Web Development. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** a few elements have no content and no end tag — the line break, the image and the horizontal rule.
**This lesson's own level:** it stands on the tags-and-elements lesson — the learner knows the normal three-part element before meeting the exceptions.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## What the learner can do when it ends
1. Say what a void element is.
2. Use the line-break, image and horizontal-rule elements.
3. Build a page of three paragraphs separated by horizontal lines.

## What you need
A computer with a text editor and a browser.

1. **Do it first** — the learner types the book's worked example — a paragraph sandwiched between two horizontal lines, its text broken mid-sentence — before void elements are named (lesson/lesson.md).

   - ADD VIDEO: the script in video-script.md, filmed — the lesson retold in the super-simple voice (made later, when videos are made).

## If the learner is stuck
- Adds end tags to void elements → they have none; the one tag is the whole element.
- Confuses line break with paragraph → a break starts a new line inside the flow; a paragraph is its own element with its own start and end tags.
