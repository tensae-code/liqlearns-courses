# Hands-on — Void elements — br, img, hr

The lesson with your hands, not only your eyes. You need a computer with a text editor and a browser for the doing parts.

## Build the sandwich
Type the book's worked example exactly: line, paragraph broken mid-sentence, line. Open it and check all three effects.

## Stack pictures
Insert two images with a line break after each, as the guide notes — watch them stack vertically instead of running on.
