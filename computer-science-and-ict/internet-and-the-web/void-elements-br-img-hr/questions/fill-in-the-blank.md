# Void elements — br, img, hr — fill in the blank

Fill each blank with the right word or code.

**1. (Sub lesson 1) An element with no content and no end tag is called a ___ element.**
**Answer: void** — void = empty.

**2. (Sub lesson 2) To start a new line inside a paragraph, use the ___ element.**
**Answer: line-break** — the break element.

**3. (Sub lesson 2) Pictures stack ___ when line breaks follow them. (teacher guide — evidence)**
**Answer: vertically** — one under the other.
