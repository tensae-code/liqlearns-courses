# Void elements — br, img, hr — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) A void element has —**
a) no content and no end tag  b) two end tags  c) content but no start tag  d) a start tag only when printed
**Answer: a) no content and no end tag** — void means empty — one tag does the whole job.

**2. (Sub lesson 2) The line-break element —**
a) starts a new line  b) draws a line across the page  c) inserts an image  d) ends the page
**Answer: a) starts a new line** — br breaks the line.

**3. (Sub lesson 2) The horizontal-rule element —**
a) draws a horizontal line  b) inserts an image  c) starts a new line inside a paragraph  d) names the page
**Answer: a) draws a horizontal line** — hr draws the rule across.

**4. (Sub lesson 2) The image element —**
a) inserts an image  b) breaks a line  c) draws a rule  d) writes a heading
**Answer: a) inserts an image** — img inserts the image.

**5. (Sub lesson 2) The book's practice builds —**
a) three paragraphs separated by horizontal lines  b) one paragraph only  c) a table of paragraphs  d) a page with no lines
**Answer: a) three paragraphs separated by horizontal lines** — three paragraphs, lines between.

**6. (Sub lesson 2) Line breaks after images make the pictures — (teacher guide — evidence)**
a) stack vertically  b) vanish  c) shrink to nothing  d) turn into links
**Answer: a) stack vertically** — the guide's explanation for vertical stacking.
