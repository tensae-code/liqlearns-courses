# Void elements — br, img, hr — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) A void element needs an end tag like every other element.**
**Answer: False** — it has no end tag at all.

**2. (Sub lesson 1) The image element is a void element.**
**Answer: True** — it is one of the three taught here.

**3. (Sub lesson 2) A horizontal rule and a line break do the same job.**
**Answer: False** — the rule draws a line; the break only starts a new line.
