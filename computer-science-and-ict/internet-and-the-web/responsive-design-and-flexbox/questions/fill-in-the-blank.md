# Responsive Design and Flexbox — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 2) The width at which a responsive design switches its layout is called the ____.**
**Answer: breakpoint — Below the breakpoint, the media query's rules take over.**

**2. (Sub lesson 1) Flex children line up along the container's main ____.**
**Answer: axis — The main axis runs across for a row, or down for a column.**
