# Responsive Design and Flexbox — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) With Flexbox, every box must be given an exact pixel width or the layout breaks.**
**Answer: False — Flex boxes grow and shrink to share the available space; that is the point of the system.**

**2. (Sub lesson 2) Responsive design means building a completely separate website for phones.**
**Answer: False — One page responds: the same HTML and CSS, with media queries switching the layout.**
