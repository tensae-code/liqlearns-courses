# Responsive Design and Flexbox — short answer

Answer in your own words, in one or two sentences.

**1. (Sub lesson 2) A page shows three boxes across on a monitor but crushes them on a phone. Name the two tools from this lesson you would use, and what each one does.**
**Answer: Flexbox, so the boxes share space and wrap onto new lines by themselves as the screen narrows; and a media query with a breakpoint, so below a chosen width the CSS switches to a stacked, phone-sized layout.**
