# Responsive Design and Flexbox — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) In Flexbox, the boxes that arrange themselves are the children of —**
a) The browser  b) A flex container  c) The media query  d) The HTML head
**Answer: b) A flex container — You declare the container flexible; its children line up along the main axis and share the space.**

**2. (Sub lesson 1) What does wrapping do in a flex row?**
a) Deletes boxes that do not fit  b) Moves boxes that no longer fit onto the next line  c) Makes boxes transparent  d) Fixes boxes to exact pixels
**Answer: b) Moves boxes that no longer fit onto the next line — Like words in a paragraph, they flow instead of crushing.**

**3. (Sub lesson 2) A media query applies its rules when —**
a) The user clicks a button  b) Its condition about the screen is true  c) The page is printed  d) Always
**Answer: b) Its condition about the screen is true — For example, when the width is at or below the breakpoint.**
