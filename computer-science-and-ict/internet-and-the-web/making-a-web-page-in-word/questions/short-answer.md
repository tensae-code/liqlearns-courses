# Making a Web Page in Word — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is the method of this section?**
**Answer: Conversion — preparing a document in Word and saving it as a web page**

**2. (Sub lesson 1) What does Word write for you on saving?**
**Answer: The HTML code of the page**

**3. (Sub lesson 1) Does this method need knowledge of HTML tags?**
**Answer: No — the editor does the translating**

**4. (Sub lesson 1) What does the browser show after conversion?**
**Answer: The document's look, as far as a web page can carry it**

**5. (Sub lesson 1) When does this method suit?**
**Answer: For a quick page from material that already exists as a document**

**6. (Sub lesson 2) What is the cost of the conversion?**
**Answer: Heavy, editor-made code that is hard to change by hand**

**7. (Sub lesson 2) Whose code is behind such a page?**
**Answer: The editor's, not the author's**

**8. (Sub lesson 2) What comes after this method in the book's ladder?**
**Answer: Hand-written HTML in Notepad, then a proper site editor**

**9. (Sub lesson 2) What does each rung of the ladder trade?**
**Answer: Ease for control**

**10. (Sub lesson 2) What should be prepared before saving as a web page?**
**Answer: The document itself — text formatted, headings styled, pictures placed**
