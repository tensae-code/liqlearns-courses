# Making a Web Page in Word — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is the method of this section?**
a) Conversion — preparing a document in Word and saving it as a web page  b) The document's look, as far as a web page can carry it  c) Heavy, editor-made code that is hard to change by hand  d) Hand-written HTML in Notepad, then a proper site editor
**Answer: a) Conversion — preparing a document in Word and saving it as a web page**

**2. (Sub lesson 1) What does Word write for you on saving?**
a) For a quick page from material that already exists as a document  b) The HTML code of the page  c) The editor's, not the author's  d) Ease for control
**Answer: b) The HTML code of the page**

**3. (Sub lesson 1) Does this method need knowledge of HTML tags?**
