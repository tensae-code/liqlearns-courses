# Lesson plan — Making a Web Page in Word

**Course:** Computer Science and ICT · **Title:** Internet and the Web · **Lesson:** Making a Web Page in Word
**Place in the curriculum:** ICT expansion — Belarus (2026-11-14) — in the title Internet and the Web on the ICT course ladder (TITLES.md). Built new from Belarus's *Інфарматыка* Grade 11, because no existing lesson in the course covers this thing as its own lesson.
**The one thing this lesson teaches:** A web page can be made without writing code: MS Word saves a formatted document as a web page, turning its text, headings, pictures and links into a page a browser can show — at the cost of the heavy, editor-made code behind it.
**This lesson's own level:** It stands on the earlier lessons of its title and on the Belarus book's own order — it follows the book's sections in sequence, so its neighbours in the book are its natural companions. It stands alone for a learner landing on it directly.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Saving a document as a web page** — The method of this section is **conversion**: prepare the page as an ordinary **Word document** — text typed and formatted, headings styled, pictures placed — then save it **as a web page**, and Word writes the HTML for you. What the browser then shows keeps the document's look as far as a page can carry it. The method suits a quick page from material that already exists as a document, and it needs no knowledge of HTML tags — the editor does the translating.
2. **What the conversion costs** — The translated code is **the editor's, not yours**: Word writes far more of it than a person would, mixes the page's content with its own formatting machinery, and ties the page to how Word chose to build it — which makes the page hard to change later by hand, and sometimes heavier to load. That is why the book does not stop here: this section is the first, easiest rung of a ladder that continues to hand-written HTML in Notepad and then to a proper site editor — each rung trading ease for control.

## The run of the lesson (in order)
1. **Do it first** — Your class report already exists as a Word document. In one save, Word will turn it into a web page — no tags, no code. In this lesson you make that page, then look at what the easy way costs, which is why the book teaches harder ways after it. (lesson/lesson.md).
2. **The explanation** — the lesson text in lesson/lesson.md, in its parts in order.
