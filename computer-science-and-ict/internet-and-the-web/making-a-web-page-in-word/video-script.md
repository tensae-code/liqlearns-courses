# Video script — Making a Web Page in Word

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

The method of this section is **conversion**: prepare the page as an ordinary **Word document** — text typed and formatted, headings styled, pictures placed — then save it **as a web page**, and Word writes the HTML for you.
What the browser then shows keeps the document's look as far as a page can carry it.
The translated code is **the editor's, not yours**: Word writes far more of it than a person would, mixes the page's content with its own formatting machinery, and ties the page to how Word chose to build it — which makes the page hard to change later by hand, and sometimes heavier to load.
That is why the book does not stop here: this section is the first, easiest rung of a ladder that continues to hand-written HTML in Notepad and then to a proper site editor — each rung trading ease for control.
