# Making a Web Page in Word

## Do it first

Your class report already exists as a Word document. In one save, Word will turn it into a web page — no tags, no code. In this lesson you make that page, then look at what the easy way costs, which is why the book teaches harder ways after it.

## Sub lesson 1 — Saving a document as a web page

The method of this section is **conversion**: prepare the page as an ordinary **Word document** — text typed and formatted, headings styled, pictures placed — then save it **as a web page**, and Word writes the HTML for you. What the browser then shows keeps the document's look as far as a page can carry it. The method suits a quick page from material that already exists as a document, and it needs no knowledge of HTML tags — the editor does the translating.

[Picture — a Word document on one side and the same page in a browser on the other, with a Save As arrow between them]

## Sub lesson 2 — What the conversion costs

The translated code is **the editor's, not yours**: Word writes far more of it than a person would, mixes the page's content with its own formatting machinery, and ties the page to how Word chose to build it — which makes the page hard to change later by hand, and sometimes heavier to load. That is why the book does not stop here: this section is the first, easiest rung of a ladder that continues to hand-written HTML in Notepad and then to a proper site editor — each rung trading ease for control.
