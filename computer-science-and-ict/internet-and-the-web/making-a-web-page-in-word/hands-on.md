# Hands-on — Making a Web Page in Word

The lesson with your hands and your feet, not only your eyes.

## Document to page
Format a one-page document in Word with a heading, two paragraphs and a picture. Save it as a web page, open the result in a browser, and compare the look with the document.

## Look behind the page
Open the saved page's code and scroll through it. Count roughly how much code Word wrote for your one page, and find your heading text inside it. Say why this page would be hard to edit by hand.
