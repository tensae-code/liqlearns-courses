# Adding a video to a webpage — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) The video element works with no source attribute.**
**Answer: False** — the source attribute names the file it embeds.

**2. (Sub lesson 2) The controls attribute needs a value after an equals sign.**
**Answer: False** — it takes no value.

**3. (Sub lesson 2) Width and height change a video's size on the page.**
**Answer: True** — that is their job.
