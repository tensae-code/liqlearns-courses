# Adding a video to a webpage — fill in the blank

Fill each blank with the right word or code.

**1. (Sub lesson 1) The video element ___ a video file in the page.**
**Answer: embeds** — embed = place inside.

**2. (Sub lesson 2) Play, pause and volume appear when the ___ attribute is written.**
**Answer: controls** — controls brings the controls.

**3. (Sub lesson 2) A video's size is set by its width and ___ attributes.**
**Answer: height** — width and height together.
