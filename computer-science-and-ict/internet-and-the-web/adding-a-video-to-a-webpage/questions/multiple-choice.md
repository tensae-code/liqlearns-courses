# Adding a video to a webpage — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) A video file is embedded through —**
a) its source attribute  b) a heading  c) the title  d) a table
**Answer: a) its source attribute** — source names the file, as with img.

**2. (Sub lesson 2) A video's size on the page is set by —**
a) width and height attributes  b) the controls attribute  c) the file name  d) the paragraph tag
**Answer: a) width and height attributes** — width and height size the player.

**3. (Sub lesson 2) The controls attribute —**
a) takes no value  b) must equal the file name  c) sets the width  d) hides the video
**Answer: a) takes no value** — its presence alone adds the controls.

**4. (Sub lesson 2) The controls add —**
a) play, pause and volume controls  b) a title and a heading  c) a border  d) a new page
**Answer: a) play, pause and volume controls** — the visitor's playback controls.

**5. (Sub lesson 2) The book's practice asks you to —**
a) change width and height, and remove controls, to see each effect  b) delete the video  c) rename the file only  d) print the page
**Answer: a) change width and height, and remove controls, to see each effect** — learning by changing one attribute at a time.

**6. (Sub lesson 2) Changing a video element's attributes and watching the effect is keyed in the guide as — (teacher guide — evidence)**
a) a teacher-led exploration  b) a written exam  c) forbidden  d) homework only
**Answer: a) a teacher-led exploration** — Activity 4.7 is keyed that way.
