# Adding a video to a webpage

## Do it first

Your page can hold a moving picture, not only still ones. Insert a video file into a page — then, as the book's practice sets, change its size values and take one attribute away, and watch what each change does. This lesson names the element and its three attributes.

## Sub lesson 1 — The video element and its source

The **video element embeds a video file** in the page, again through a **source attribute** naming the file — the same pattern as the image element's source.

## Sub lesson 2 — Width, height and controls

Two attributes set the video's **size on the page**: **width** and **height**. A third, **controls**, **takes no value** — writing it in the tag **adds play, pause and volume controls** for the visitor. The book's practice is the experiment: change the width and height values, then remove the controls attribute, and see each effect. Activities like this are keyed in the guide as teacher-led explorations (teacher guide — evidence).
