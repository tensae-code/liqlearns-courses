# Lesson plan — Adding a video to a webpage

**Course:** Computer Science and ICT · **Title:** Internet and the Web · **Lesson:** Adding a video to a webpage
**Place in the curriculum:** Title — Internet and the Web in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 11 book, Unit 4 — Web Development. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** the video element embeds a video file through its source attribute; width and height set its size, and the controls attribute — which takes no value — adds play, pause and volume controls.
**This lesson's own level:** it stands on the attributes lesson — the video element is taught through its attributes.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The video element and its source** — embedding a video through its source attribute
2. **Width, height and controls** — the size attributes and the value-less controls attribute, learned by the book's experiment

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: HTML attributes — and the img element. Recommended, never forced.

## What the learner can do when it ends
1. Embed a video file in a page.
2. Set a video's size with width and height.
3. Add visitor controls with the controls attribute.

## What you need
A computer with a text editor and a browser; one video file in the page's folder.

## The run of the lesson (in order)
1. **Do it first** — the learner inserts a video, then changes its width and height and removes its controls, watching each effect, as the book's practice sets (lesson/lesson.md).
2. **The explanation** — the parts below, in order (lesson/lesson.md).

3. **Say it to your companion** — explain the lesson back in your own words (lesson/lesson.md).
   - ADD VIDEO: the script in video-script.md, filmed — the lesson retold in the super-simple voice (made later, when videos are made).
4. **Questions** — from questions/: multiple-choice, true-or-false, fill-in-the-blank — served at the learner's level (levels.md).
5. **Hands-on** — hands-on.md.
6. **Do It Yourself** — the doing block at the end of lesson/lesson.md.

## If the learner is stuck
- Gives controls a value → controls takes no value; its presence alone adds the controls.
- Video missing → check the source attribute names the file, as with the image element.
