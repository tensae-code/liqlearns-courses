# Hands-on — Ordered lists in HTML

The lesson with your hands, not only your eyes. You need a computer with a text editor and a browser for the doing parts.

## Top ten, three styles
Build the book's top-ten list. Show it in Arabic numerals, then in upper-case Roman numerals, then in lower-case letters — three saves, three looks.

## Grow the list
Start with three subjects. Add items one by one, reloading each time, as the review model does — watch the numbering extend itself without any number being typed.
