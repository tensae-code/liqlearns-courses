# Ordered lists in HTML — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) You must type 1, 2, 3 before the items of an ordered list.**
**Answer: False** — the tag numbers them.

**2. (Sub lesson 2) An ordered list can be numbered with letters.**
**Answer: True** — upper- or lower-case letters are a type choice.

**3. (Sub lesson 2) The type attribute is set on each item tag separately.**
**Answer: False** — it is set on the ordered-list tag.
