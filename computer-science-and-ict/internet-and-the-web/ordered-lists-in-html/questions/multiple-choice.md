# Ordered lists in HTML — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) An ordered list is built with —**
a) the ordered-list tag around item tags  b) item tags alone with typed numbers  c) the table tag  d) the anchor element
**Answer: a) the ordered-list tag around item tags** — list tag outside, items inside.

**2. (Sub lesson 1) In an ordered list, the numbers —**
a) appear by themselves; you never type them  b) must be typed before each item  c) are images  d) come from the browser's title
**Answer: a) appear by themselves; you never type them** — numbering is automatic.

**3. (Sub lesson 2) The default numbering of an ordered list is —**
a) Arabic numerals  b) Roman numerals  c) letters  d) bullets
**Answer: a) Arabic numerals** — 1, 2, 3 by default.

**4. (Sub lesson 2) The type attribute can switch numbering to —**
a) upper- or lower-case Roman numerals or upper- or lower-case letters  b) discs and squares  c) colours  d) page numbers
**Answer: a) upper- or lower-case Roman numerals or upper- or lower-case letters** — Roman or letters, either case.

**5. (Sub lesson 2) The guide states the default as — (teacher guide — evidence)**
a) ordinary numerals, changed by setting the type attribute  b) letters, changed by the border  c) bullets  d) no numbering
**Answer: a) ordinary numerals, changed by setting the type attribute** — the guide's plain statement.

**6. (Sub lesson 2) Adding an item to a list makes the numbering — (teacher guide — evidence)**
a) extend itself  b) break  c) start again wrongly  d) need renumbering by hand
**Answer: a) extend itself** — the review model's growing subjects list proves it.
