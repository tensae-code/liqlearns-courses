# Ordered lists in HTML

## Do it first

Some lists have an order that matters — first, second, third. Build the book's worked example: the WHO's top ten causes of death in Ethiopia, as a numbered list. Then change one attribute and watch the whole list renumber itself in a different style — that renumbering is this lesson, and the GIF shows it.

## Sub lesson 1 — Building an ordered list

An **ordered (numbered) list** is built with the **ordered-list tag around item tags** — one item tag per entry. The numbering appears by itself: you never type the numbers.

## Sub lesson 2 — Numbering styles — the type attribute

Numbering is **Arabic numerals by default** — 1, 2, 3. The **type attribute** can switch it to **upper- or lower-case Roman numerals** or **upper- or lower-case letters**. The guide states the default plainly (teacher guide — evidence): the default numbering of an ordered list is **ordinary numerals**, changed by setting the type attribute. Its worked set includes a **numbered name list** and **letter-numbered fruits**. The Unit 4 review model of a subjects list that grows by adding items (teacher guide — evidence) is filed here as a verified expected output: add an item tag, and the numbering extends itself.
