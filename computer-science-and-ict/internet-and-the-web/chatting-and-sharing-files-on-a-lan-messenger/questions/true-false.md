# Chatting and Sharing Files on a LAN Messenger — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a LAN messenger?" is: A messaging program that works on the school's local area network only**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is not needed for a LAN messenger to work?" is: Only inside the school's own network**
**Answer: False** — An internet connection

**3. (Sub lesson 1) True or false: the answer to "Which LAN messenger does Bhutan's Class V book use?" is: Qualia LAN Messenger**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How do you start a chat in it?" is: One message sent to everyone signed in at once**
**Answer: False** — Choose a signed-in person from the list and write to them

**5. (Sub lesson 1) True or false: the answer to "Where do LAN messages travel?" is: Only inside the school's own network**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What else can the messenger send besides chat?" is: Sent to the teacher as a LAN-messenger attachment**
**Answer: False** — Files — documents and pictures as attachments

**7. (Sub lesson 2) True or false: the answer to "What is a broadcast message?" is: One message sent to everyone signed in at once**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Who uses broadcasts in the classroom?" is: A messaging program that works on the school's local area network only**
**Answer: False** — The teacher, to reach the whole class

**9. (Sub lesson 2) True or false: the answer to "How is Class V's end-of-year folder handed in?" is: Sent to the teacher as a LAN-messenger attachment**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why is LAN sharing simpler than a drive here?" is: Qualia LAN Messenger**
**Answer: False** — The file travels directly between the school's computers
