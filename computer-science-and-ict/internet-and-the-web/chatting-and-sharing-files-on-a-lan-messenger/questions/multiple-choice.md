# Chatting and Sharing Files on a LAN Messenger — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a LAN messenger?**
a) A messaging program that works on the school's local area network only  b) An internet connection  c) Qualia LAN Messenger  d) Choose a signed-in person from the list and write to them
**Answer: a) A messaging program that works on the school's local area network only**

**2. (Sub lesson 1) What is not needed for a LAN messenger to work?**
a) Qualia LAN Messenger  b) An internet connection  c) Choose a signed-in person from the list and write to them  d) Only inside the school's own network
**Answer: b) An internet connection**

**3. (Sub lesson 1) Which LAN messenger does Bhutan's Class V book use?**
a) Choose a signed-in person from the list and write to them  b) Only inside the school's own network  c) Qualia LAN Messenger  d) Files — documents and pictures as attachments
**Answer: c) Qualia LAN Messenger**

**4. (Sub lesson 1) How do you start a chat in it?**
a) Only inside the school's own network  b) Files — documents and pictures as attachments  c) One message sent to everyone signed in at once  d) Choose a signed-in person from the list and write to them
**Answer: d) Choose a signed-in person from the list and write to them**

**5. (Sub lesson 1) Where do LAN messages travel?**
a) Only inside the school's own network  b) Files — documents and pictures as attachments  c) One message sent to everyone signed in at once  d) The teacher, to reach the whole class
**Answer: a) Only inside the school's own network**

**6. (Sub lesson 2) What else can the messenger send besides chat?**
a) One message sent to everyone signed in at once  b) Files — documents and pictures as attachments  c) The teacher, to reach the whole class  d) Sent to the teacher as a LAN-messenger attachment
**Answer: b) Files — documents and pictures as attachments**

**7. (Sub lesson 2) What is a broadcast message?**
a) The teacher, to reach the whole class  b) Sent to the teacher as a LAN-messenger attachment  c) One message sent to everyone signed in at once  d) The file travels directly between the school's computers
**Answer: c) One message sent to everyone signed in at once**

**8. (Sub lesson 2) Who uses broadcasts in the classroom?**
a) Sent to the teacher as a LAN-messenger attachment  b) The file travels directly between the school's computers  c) A messaging program that works on the school's local area network only  d) The teacher, to reach the whole class
**Answer: d) The teacher, to reach the whole class**

**9. (Sub lesson 2) How is Class V's end-of-year folder handed in?**
a) Sent to the teacher as a LAN-messenger attachment  b) The file travels directly between the school's computers  c) A messaging program that works on the school's local area network only  d) An internet connection
**Answer: a) Sent to the teacher as a LAN-messenger attachment**

**10. (Sub lesson 2) Why is LAN sharing simpler than a drive here?**
a) A messaging program that works on the school's local area network only  b) The file travels directly between the school's computers  c) An internet connection  d) Qualia LAN Messenger
**Answer: b) The file travels directly between the school's computers**
