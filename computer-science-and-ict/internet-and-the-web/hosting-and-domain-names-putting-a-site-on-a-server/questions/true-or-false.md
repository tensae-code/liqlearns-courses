# Hosting and domain names — putting a site on a server — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** One web server may host many sites.
**Answer: True** — one or many, depending on the service paid for.

**2. (Sub lesson 2)** If your chosen domain name is taken, you can register it anyway.
**Answer: False** — registration fails; another name must be found.

**3. (Sub lesson 1)** Uploading means moving the site's files down from the server to your computer.
**Answer: False** — uploading puts the files onto the host's remote server.
