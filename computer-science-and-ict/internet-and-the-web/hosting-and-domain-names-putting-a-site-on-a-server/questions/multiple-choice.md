# Hosting and domain names — putting a site on a server — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A hosting company provides —
a) free computers  b) online storage space on its remote server  c) printed pages
**Answer: b) online storage space on its remote server** — online storage space is the host's provision.

**2. (Sub lesson 1)** The web server is —
a) the actual machine where the site resides  b) the site's home page  c) the domain name
**Answer: a) the actual machine where the site resides** — the server is the machine itself.

**3. (Sub lesson 2)** A domain name must be —
a) long and clever  b) unique — if taken, registration fails  c) shared by many sites
**Answer: b) unique — if taken, registration fails** — uniqueness is enforced by registration.

**4. (Sub lesson 2)** A good domain name is —
a) hard to spell, so it is safe  b) easy to remember and easy to type  c) written in code
**Answer: b) easy to remember and easy to type** — memory and typing ease are the stated tests.
