# Hosting and domain names — putting a site on a server — fill in the blank

Fill each blank with the right word or code.

**1. (Sub lesson 1)** The company providing hosting space is called a web ___.
**Answer: host** — web host / hosting company.

**2. (Sub lesson 2)** The domain name is the part of the address after ___.
**Answer: www** — after "www" is where the domain name sits, as printed.

**3. (Sub lesson 2)** In the ministry example, the domain name as printed is "___.gov".
**Answer: moe** — "moe.gov" is the printed example.
