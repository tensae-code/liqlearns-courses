# Hands-on — Hosting and domain names — putting a site on a server

The lesson with your hands, not only your eyes.

## Name claim game
Each player writes a domain name for the same imaginary business. Check the names against each other: any duplicates fail registration, as a taken name does. Judge the survivors for memory and typing ease.

## Draw the hosting picture
Draw your site's folders on the left, an arrow up, and a server on the right wearing its domain name as a name plate. Label the host company beneath the server.
