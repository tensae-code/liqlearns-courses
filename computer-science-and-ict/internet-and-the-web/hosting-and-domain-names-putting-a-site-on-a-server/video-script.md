# Video script — Hosting and domain names — putting a site on a server

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Your site is built. Now it needs a home.
Upload its files to a hosting company — a web host.
The host provides online storage space.
The web server is the machine your site resides on.
One server can host many sites.
Now the name: the domain name. Your online address.
It must be unique. Taken? Registration fails. Choose another.
Easy to remember. Easy to type. That is a good name.
