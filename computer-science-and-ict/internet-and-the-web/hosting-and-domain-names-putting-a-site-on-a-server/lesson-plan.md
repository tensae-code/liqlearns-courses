# Lesson plan — Hosting and domain names — putting a site on a server

**Course:** Computer Science and ICT · **Title:** Internet and the Web · **Lesson:** Hosting and domain names — putting a site on a server
**Place in the curriculum:** Title — Internet and the Web in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 12 book, Unit 4 — Web Authoring. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** a site is published by uploading its files to the remote server of a hosting company; the web server is the machine the site resides on; and its domain name — registered, unique, easy to remember and type — becomes its online address.
**This lesson's own level:** it stands on the publishing lesson — the learner knows a site's folder structure; this lesson moves that structure onto a host's server and names it.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Hosting — uploading to the host's server** — a site is published by uploading its files to the remote server of a hosting company / web host, which provides online storage space; the web server is the actual machine where the site resides, and one server may host one or many sites
2. **Registering a domain name** — the domain name is the part of the address after www, becomes the online address, should be easy to remember and type, and must be unique — if it is taken, registration fails

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Publishing a website — root, index and folders. Recommended, never forced.

## What the learner can do when it ends
1. Say what a hosting company provides and what uploading does.
2. Say what the web server is and that one server may host many sites.
3. Say what a domain name is, why it must be unique, and what makes a good one.

## If the learner is stuck
- Confuses host and server → the host is the company providing space; the server is the actual machine the site resides on.
- Chooses a clever but hard name → a domain name should be easy to remember and type; it is the address people must use.
