# HTML5 Geolocation and Local Storage — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does geolocation give a page?" is: The device's position — latitude and longitude**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What must happen before a page gets the position?" is: Maps and local search (delivery estimates also counts)**
**Answer: False** — The browser asks the user for permission

**3. (Sub lesson 1) True or false: the answer to "What signals can position come from?" is: GPS, Wi-Fi or network signals**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What happens if the user refuses?" is: Yes — it is still there on return**
**Answer: False** — The page gets no position

**5. (Sub lesson 1) True or false: the answer to "Name two uses of geolocation." is: Maps and local search (delivery estimates also counts)**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What shape does local storage keep data in?" is: Settings and preferences (drafts also counts)**
**Answer: False** — Key–value pairs of text

**7. (Sub lesson 2) True or false: the answer to "Does local storage survive closing the browser?" is: Yes — it is still there on return**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is session storage's difference?" is: The device's position — latitude and longitude**
**Answer: False** — It forgets when the tab closes

**9. (Sub lesson 2) True or false: the answer to "Name two things kept in local storage." is: Settings and preferences (drafts also counts)**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Can one site read another site's local storage?" is: GPS, Wi-Fi or network signals**
**Answer: False** — No — storage is per-site
