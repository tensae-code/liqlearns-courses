# HTML5 Geolocation and Local Storage — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does geolocation give a page?**
a) The device's position — latitude and longitude  b) The browser asks the user for permission  c) GPS, Wi-Fi or network signals  d) The page gets no position
**Answer: a) The device's position — latitude and longitude**

**2. (Sub lesson 1) What must happen before a page gets the position?**
a) GPS, Wi-Fi or network signals  b) The browser asks the user for permission  c) The page gets no position  d) Maps and local search (delivery estimates also counts)
**Answer: b) The browser asks the user for permission**

**3. (Sub lesson 1) What signals can position come from?**
a) The page gets no position  b) Maps and local search (delivery estimates also counts)  c) GPS, Wi-Fi or network signals  d) Key–value pairs of text
**Answer: c) GPS, Wi-Fi or network signals**

**4. (Sub lesson 1) What happens if the user refuses?**
a) Maps and local search (delivery estimates also counts)  b) Key–value pairs of text  c) Yes — it is still there on return  d) The page gets no position
**Answer: d) The page gets no position**

**5. (Sub lesson 1) Name two uses of geolocation.**
a) Maps and local search (delivery estimates also counts)  b) Key–value pairs of text  c) Yes — it is still there on return  d) It forgets when the tab closes
**Answer: a) Maps and local search (delivery estimates also counts)**

**6. (Sub lesson 2) What shape does local storage keep data in?**
a) Yes — it is still there on return  b) Key–value pairs of text  c) It forgets when the tab closes  d) Settings and preferences (drafts also counts)
**Answer: b) Key–value pairs of text**

**7. (Sub lesson 2) Does local storage survive closing the browser?**
a) It forgets when the tab closes  b) Settings and preferences (drafts also counts)  c) Yes — it is still there on return  d) No — storage is per-site
**Answer: c) Yes — it is still there on return**

**8. (Sub lesson 2) What is session storage's difference?**
a) Settings and preferences (drafts also counts)  b) No — storage is per-site  c) The device's position — latitude and longitude  d) It forgets when the tab closes
**Answer: d) It forgets when the tab closes**

**9. (Sub lesson 2) Name two things kept in local storage.**
a) Settings and preferences (drafts also counts)  b) No — storage is per-site  c) The device's position — latitude and longitude  d) The browser asks the user for permission
**Answer: a) Settings and preferences (drafts also counts)**

**10. (Sub lesson 2) Can one site read another site's local storage?**
a) The device's position — latitude and longitude  b) No — storage is per-site  c) The browser asks the user for permission  d) GPS, Wi-Fi or network signals
**Answer: b) No — storage is per-site**
