# Hands-on — Creating a Blog

The lesson with your hands and your feet, not only your eyes.

## Task one
**Plan a real blog** — Plan a class blog: platform, name, address, theme, comment settings. Write the promise (how often, about what) in one sentence a reader could hold you to.

## Task two
**First post** — Write the first post (150–250 words) with a title, tags and one picture slot. Read it aloud: does the first line earn the second?
