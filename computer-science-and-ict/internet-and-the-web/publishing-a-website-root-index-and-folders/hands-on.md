# Hands-on — Publishing a website — root, index and folders

The lesson with your hands, not only your eyes.

## Paper site, real folders
Make a paper site: six page cards, four picture cards, one style card, one script card. Build its folder structure from envelopes — a root envelope holding index.html and four folder envelopes — and file every card.

## Map a real site
Choose a real site. Draw its tree as far as you can see it: root, home page, sub-directories, media folder. Mark what you identified and what you guessed.
