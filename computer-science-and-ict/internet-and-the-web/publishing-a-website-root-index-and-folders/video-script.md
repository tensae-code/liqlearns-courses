# Video script — Publishing a website — root, index and folders

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Publishing: your site leaves your computer.
It goes onto the internet. Onto a remote server.
Every site has a root: the top folder that holds everything.
In the root, the home page: index.html.
The server returns it when no file is named.
Pages folder: the other pages. Images folder.
CSS folder: the styling. Scripts folder: the JavaScript.
One root. One front door. Everything in its folder.
