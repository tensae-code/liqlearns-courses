# Lesson plan — Publishing a website — root, index and folders

**Course:** Computer Science and ICT · **Title:** Internet and the Web · **Lesson:** Publishing a website — root, index and folders
**Place in the curriculum:** Title — Internet and the Web in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 12 book, Unit 4 — Web Authoring. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** publishing is putting a site's original content onto a remote server; every site lives in a root directory holding an index.html home page and pages, images, CSS and scripts folders — worked on the real ethiopia.gov.et structure (teacher guide — evidence).
**This lesson's own level:** it stands on the Grade 11 website lessons — the learner has built pages with HTML; this lesson puts a finished site onto the internet, in its folder structure.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **What publishing is, and the root directory** — publishing is putting the website's original content onto the internet, onto a remote server — building and uploading sites, updating pages and posting content; every site is represented by a root directory, the top-level folder holding everything
2. **index.html and the site's folders — and a real site read the same way (teacher guide — evidence)** — an index.html home page file that servers return by default, a pages folder, an images folder, a CSS folder and a scripts folder; on ethiopia.gov.et the root, sub-directories, media directory and home page are each identified

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Building a web page with HTML (Grade 11 run); Designing a website (Grade 11 run). Recommended, never forced.

## What the learner can do when it ends
1. Define publishing: content onto the internet, onto a remote server.
2. Draw a site's root directory: index.html and the pages, images, CSS and scripts folders.
3. Identify root, sub-directories, media directory and home page on ethiopia.gov.et (teacher guide — evidence).

## What you need
Paper and a pencil; a computer helps for drawing a real site's tree.

## If the learner is stuck
- Treats the home page as any page → index.html is the file servers return by default when no file is named.
- Scatters files without folders → the structure is the lesson: root, then its named folders.
