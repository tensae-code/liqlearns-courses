# Publishing a website — root, index and folders — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Publishing a website means putting its content —
a) in a printed book  b) onto the internet, onto a remote server  c) on one classroom computer
**Answer: b) onto the internet, onto a remote server** — onto a remote server, on the internet, is the definition.

**2. (Sub lesson 1)** The root directory is —
a) the smallest file  b) the top-level folder holding everything  c) a kind of image
**Answer: b) the top-level folder holding everything** — the root holds the whole site.

**3. (Sub lesson 2)** When a visitor names no file, the server returns —
a) a random page  b) index.html, the home page file  c) an error always
**Answer: b) index.html, the home page file** — index.html is returned by default.

**4. (Sub lesson 2)** On ethiopia.gov.et, the guide's answers identify — (teacher guide — evidence)
a) only its colours  b) its root directory, sub-directories, media directory and home page  c) its password
**Answer: b) its root directory, sub-directories, media directory and home page** — the folder structure of a real site is the identified set.
