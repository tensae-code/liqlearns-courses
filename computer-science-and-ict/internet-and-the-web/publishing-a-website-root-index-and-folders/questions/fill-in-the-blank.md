# Publishing a website — root, index and folders — fill in the blank

Fill each blank with the right word or code.

**1. (Sub lesson 1)** The home page file is named ___.html
**Answer: index** — index.html is the default-returned file.

**2. (Sub lesson 2)** ethiopia.___.et is the real government site the publishing answers work on. (teacher guide — evidence)
**Answer: gov** — ethiopia.gov.et — a government site, as its extension says.

**3. (Sub lesson 1)** The top-level folder holding everything is the ___ directory.
**Answer: root** — root directory is the name.
