# Publishing a website — root, index and folders — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Publishing covers updating pages and posting content, not only first uploads.
**Answer: True** — building and uploading, updating and posting are all inside the definition.

**2. (Sub lesson 2)** JavaScript interactivity files live in the images folder.
**Answer: False** — scripts live in the scripts folder; images live in the images folder.

**3. (Sub lesson 2)** The CSS folder holds the site's styling code.
**Answer: True** — styling code is the CSS folder's content.
