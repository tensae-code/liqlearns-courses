# Designing an Application Framework (Wireframe) — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — The wireframe — pages as skeletons
Sub lesson 1 questions from the type files. Pass mark: A skeleton drawing of one page — boxes for its regions, labels for what each holds; Banner, menu, content, footer; Decoration — no colours, fonts or images beyond placeholders; One per page, in the same skeleton style; So pages can be compared and shared furniture checked for sameness.

## Sub lesson 2 — Joining the pages — the framework whole
Sub lesson 2 questions from the type files. Pass mark: The joins — each page's links drawn to their target pages; A map a builder can follow and a client can judge; Every promised page present; every link landing somewhere real; no orphan page; Only after the framework review passes; The rebuild the drawing exists to prevent.
