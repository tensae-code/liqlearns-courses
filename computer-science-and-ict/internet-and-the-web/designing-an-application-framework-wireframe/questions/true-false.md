# Designing an Application Framework (Wireframe) — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a wireframe?" is: A skeleton drawing of one page — boxes for its regions, labels for what each holds**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Name the usual regions." is: Decoration — no colours, fonts or images beyond placeholders**
**Answer: False** — Banner, menu, content, footer

**3. (Sub lesson 1) True or false: the answer to "What does a wireframe leave out?" is: Decoration — no colours, fonts or images beyond placeholders**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How many wireframes are drawn?" is: So pages can be compared and shared furniture checked for sameness**
**Answer: False** — One per page, in the same skeleton style

**5. (Sub lesson 1) True or false: the answer to "Why the same style?" is: So pages can be compared and shared furniture checked for sameness**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What completes the framework?" is: A map a builder can follow and a client can judge**
**Answer: False** — The joins — each page's links drawn to their target pages

**7. (Sub lesson 2) True or false: the answer to "The whole site stands as what?" is: A map a builder can follow and a client can judge**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Name the review's three checks." is: Only after the framework review passes**
**Answer: False** — Every promised page present; every link landing somewhere real; no orphan page

**9. (Sub lesson 2) True or false: the answer to "When does building begin?" is: Only after the framework review passes**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What does a framework fault found in code cost?" is: A skeleton drawing of one page — boxes for its regions, labels for what each holds**
**Answer: False** — The rebuild the drawing exists to prevent
