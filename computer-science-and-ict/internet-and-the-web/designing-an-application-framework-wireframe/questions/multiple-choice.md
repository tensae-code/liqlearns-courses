# Designing an Application Framework (Wireframe) — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a wireframe?**
a) A skeleton drawing of one page — boxes for its regions, labels for what each holds  b) Banner, menu, content, footer  c) Decoration — no colours, fonts or images beyond placeholders  d) One per page, in the same skeleton style
**Answer: a) A skeleton drawing of one page — boxes for its regions, labels for what each holds**

**2. (Sub lesson 1) Name the usual regions.**
a) Decoration — no colours, fonts or images beyond placeholders  b) Banner, menu, content, footer  c) One per page, in the same skeleton style  d) So pages can be compared and shared furniture checked for sameness
**Answer: b) Banner, menu, content, footer**

**3. (Sub lesson 1) What does a wireframe leave out?**
a) One per page, in the same skeleton style  b) So pages can be compared and shared furniture checked for sameness  c) Decoration — no colours, fonts or images beyond placeholders  d) The joins — each page's links drawn to their target pages
**Answer: c) Decoration — no colours, fonts or images beyond placeholders**

**4. (Sub lesson 1) How many wireframes are drawn?**
a) So pages can be compared and shared furniture checked for sameness  b) The joins — each page's links drawn to their target pages  c) A map a builder can follow and a client can judge  d) One per page, in the same skeleton style
**Answer: d) One per page, in the same skeleton style**

**5. (Sub lesson 1) Why the same style?**
a) So pages can be compared and shared furniture checked for sameness  b) The joins — each page's links drawn to their target pages  c) A map a builder can follow and a client can judge  d) Every promised page present; every link landing somewhere real; no orphan page
**Answer: a) So pages can be compared and shared furniture checked for sameness**

**6. (Sub lesson 2) What completes the framework?**
a) A map a builder can follow and a client can judge  b) The joins — each page's links drawn to their target pages  c) Every promised page present; every link landing somewhere real; no orphan page  d) Only after the framework review passes
**Answer: b) The joins — each page's links drawn to their target pages**

**7. (Sub lesson 2) The whole site stands as what?**
a) Every promised page present; every link landing somewhere real; no orphan page  b) Only after the framework review passes  c) A map a builder can follow and a client can judge  d) The rebuild the drawing exists to prevent
**Answer: c) A map a builder can follow and a client can judge**

**8. (Sub lesson 2) Name the review's three checks.**
a) Only after the framework review passes  b) The rebuild the drawing exists to prevent  c) A skeleton drawing of one page — boxes for its regions, labels for what each holds  d) Every promised page present; every link landing somewhere real; no orphan page
**Answer: d) Every promised page present; every link landing somewhere real; no orphan page**

**9. (Sub lesson 2) When does building begin?**
a) Only after the framework review passes  b) The rebuild the drawing exists to prevent  c) A skeleton drawing of one page — boxes for its regions, labels for what each holds  d) Banner, menu, content, footer
