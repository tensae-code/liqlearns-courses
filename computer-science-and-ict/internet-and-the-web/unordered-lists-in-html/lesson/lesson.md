# Unordered lists in HTML

## Do it first

Not every list has an order. A shopping list does not care what comes first — it needs marks, not numbers. Build the book's worked example: actions against climate change, with round open bullets. This lesson names the list and its three bullet shapes.

## Sub lesson 1 — Building an unordered list

An **unordered (bulleted) list** uses the **unordered-list tag** with the **same item tags** as an ordered list. Only the wrapper and the marks change: bullets instead of numbers.

## Sub lesson 2 — Bullet shapes — disc, square, circle

The **default bullet is a filled disc**. The **type attribute** can change it to a **square** or an **open circle** — the worked example lists **actions against climate change with circle bullets**. The guide states the default plainly (teacher guide — evidence): the default bullet of an unordered list is a **disc**, changed by setting the type attribute; its worked set pairs **letter-numbered fruits beside square-bulleted vegetables**.
