# Unordered lists in HTML — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Unordered and ordered lists use different item tags.**
**Answer: False** — the item tags are the same; the wrapper differs.

**2. (Sub lesson 2) The default bullet of an unordered list is a disc.**
**Answer: True** — the guide states it plainly too.

**3. (Sub lesson 2) An unordered list numbers its items if the list is long.**
**Answer: False** — it never numbers; order is not its job.
