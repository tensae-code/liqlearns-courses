# Unordered lists in HTML — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) An unordered list uses —**
a) the unordered-list tag with the same item tags  b) a different item tag from ordered lists  c) the table tag  d) typed bullet characters
**Answer: a) the unordered-list tag with the same item tags** — same items, unordered wrapper.

**2. (Sub lesson 1) Unordered lists are also called —**
a) bulleted lists  b) numbered lists  c) header lists  d) link lists
**Answer: a) bulleted lists** — bullets, not numbers.

**3. (Sub lesson 2) The default bullet is —**
a) a filled disc  b) a square  c) an open circle  d) a number
**Answer: a) a filled disc** — disc by default.

**4. (Sub lesson 2) The type attribute can change the bullet to —**
a) a square or an open circle  b) Roman numerals  c) letters only  d) nothing
**Answer: a) a square or an open circle** — square or circle.

**5. (Sub lesson 2) The book's worked example lists — with circle bullets.**
a) actions against climate change  b) causes of death  c) mountains and elevations  d) Ethiopian websites
**Answer: a) actions against climate change** — climate actions, circled.

**6. (Sub lesson 2) The guide pairs — (teacher guide — evidence)**
a) letter-numbered fruits beside square-bulleted vegetables  b) numbered vegetables beside disc fruits  c) one list only  d) tables beside lists
**Answer: a) letter-numbered fruits beside square-bulleted vegetables** — the guide's worked pairing.
