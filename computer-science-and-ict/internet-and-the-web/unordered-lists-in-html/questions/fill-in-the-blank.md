# Unordered lists in HTML — fill in the blank

Fill each blank with the right word or code.

**1. (Sub lesson 1) A bulleted list is built with the ___-list tag.**
**Answer: unordered** — unordered = bulleted.

**2. (Sub lesson 2) The three bullet shapes: disc, square and ___.**
**Answer: circle** — the open circle.

**3. (Sub lesson 2) Bullet shape is set with the ___ attribute.**
**Answer: type** — type again carries the style.
