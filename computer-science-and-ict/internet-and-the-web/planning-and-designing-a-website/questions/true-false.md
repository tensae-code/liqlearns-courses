# Planning and Designing a Website — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What two questions open a website plan?" is: Who is the audience, and what is the purpose?**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Name the four site structures." is: Hierarchical**
**Answer: False** — Linear, hierarchical, cycle and web

**3. (Sub lesson 1) True or false: the answer to "Which structure hangs pages in a tree from the home page?" is: Hierarchical**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What promise does a structure make to the visitor?" is: Where the title, menu, text and pictures stand — the same across the site**
**Answer: False** — At any page, the way onward and the way home are guessable from the shape

**5. (Sub lesson 1) True or false: the answer to "What does a page layout fix?" is: Where the title, menu, text and pictures stand — the same across the site**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Name the three ways of building a site." is: Putting the site on a server so visitors can reach it**
**Answer: False** — A CMS, hand-coded HTML, and design programs

**7. (Sub lesson 2) True or false: the answer to "What is hosting?" is: Putting the site on a server so visitors can reach it**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is tested before opening?" is: Plan, structure, build, host, test**
**Answer: False** — Every page and every link

**9. (Sub lesson 2) True or false: the answer to "What is the book's working order?" is: Plan, structure, build, host, test**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Name a real site the book's pupils plan." is: Who is the audience, and what is the purpose?**
**Answer: False** — The "Our School" site (any one of: the Animals of the Mongolian Red Book page)
