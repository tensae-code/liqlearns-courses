# Planning and Designing a Website

## Do it first

Mongolia's Grade 11 web chapter does not start with a tag. It starts with a plan: who the site is for, how its pages hang together, and how it will be built. This lesson is that planning — the 'Our School' site and the Mongolian Red Book animals page both begin here.

## Sub lesson 1 — Audience, purpose and structure

A website is planned from its **audience and purpose**: who must it serve, and what must those visitors be able to do? The pages are then hung on a **structure**: **linear** (pages in one line, like a story), **hierarchical** (a tree from the home page down), **cycle** (a ring returning on itself) or **web** (pages linked freely, many to many). Structure is a promise to the visitor: at any page, the way onward and the way home must be guessable from the shape alone.

## Sub lesson 2 — Layout and the way of building

Each page gets a **layout** — where the title, menu, text and pictures stand — kept the same across the site so visitors learn it once. Then the builder chooses the **way of building**: a **CMS** (content management system) that assembles pages from parts, **hand-coded HTML** written directly, or **design programs** that draw pages and write the code behind them. The plan ends with **hosting** — putting the site on a server — and **testing** every page and link before the world is invited. Mongolia's order is the professional one: plan, structure, build, host, test — in that sequence, never code first.
