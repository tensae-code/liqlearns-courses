# Designing a website — audience, navigation, consistency, simplicity, accessibility — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Website design is only about choosing colours.**
**Answer: False** — it also covers layout, navigation and graphics.

**2. (Sub lesson 2) Accessibility means nobody, including people with disabilities, is excluded.**
**Answer: True** — that is the fifth guideline.

**3. (Sub lesson 2) Overcrowding a page with graphics follows the simplicity guideline.**
**Answer: False** — simplicity says the opposite.
