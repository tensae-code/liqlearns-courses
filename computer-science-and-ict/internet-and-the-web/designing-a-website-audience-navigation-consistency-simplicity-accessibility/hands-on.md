# Hands-on — Designing a website — audience, navigation, consistency, simplicity, accessibility

The lesson with your hands, not only your eyes. You need a computer with a text editor and a browser for the doing parts.

## Judge a real site
Open a website you know. Score it 1–5 on each guideline: audience, navigation, consistency, simplicity, accessibility. Write one sentence of evidence for each score.

## Redesign on paper
Take the worst-scoring page and redraw it on paper following all five guidelines. Label where each guideline changed your drawing.
