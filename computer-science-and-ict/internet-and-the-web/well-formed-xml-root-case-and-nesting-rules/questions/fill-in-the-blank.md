# Well-formed XML — root, case and nesting rules — fill in the blank

Fill each blank with the right word or code.

**1. (Sub lesson 1)** Elements must be properly ___ inside each other.
**Answer: nested** — nesting, never overlapping, is the rule.

**2. (Sub lesson 2)** Comments use the ___-like comment syntax.
**Answer: HTML** — the HTML-like markers <!-- -->.

**3. (Sub lesson 2)** A student element in the corrected set carries an ___ attribute. (teacher guide — evidence)
**Answer: ID** — the ID attribute, quoted as rule 4 demands.
