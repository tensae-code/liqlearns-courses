# Well-formed XML — root, case and nesting rules — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Properly nested elements may overlap a little at the edges.
**Answer: False** — elements must not overlap at all.

**2. (Sub lesson 2)** An attribute value may be left unquoted when it is short.
**Answer: False** — attribute values must always be quoted.

**3. (Sub lesson 2)** In the guide's exercise, some lines are already correct. (teacher guide — evidence)
**Answer: False** — every piece of XML in that exercise contains an error.
