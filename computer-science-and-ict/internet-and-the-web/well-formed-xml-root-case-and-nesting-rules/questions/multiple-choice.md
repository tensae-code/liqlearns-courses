# Well-formed XML — root, case and nesting rules — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A document that follows the syntax rules is called —
a) valid-looking  b) well formed  c) finished
**Answer: b) well formed** — well formed is the term for following the syntax rules.

**2. (Sub lesson 1)** How many root elements may a document have?
a) two, if they are small  b) one only  c) as many as needed
**Answer: b) one only** — one root only, starting and ending with the same tag.

**3. (Sub lesson 1)** <Book> closed by </book> is —
a) fine — case does not matter  b) broken — elements are case sensitive  c) a comment
**Answer: b) broken — elements are case sensitive** — start and end case must match exactly.

**4. (Sub lesson 2)** The guide's corrected exercise names these error families — (teacher guide — evidence)
a) spelling, colour, length  b) root/parent, attribute, case-sensitivity, special-symbol  c) font, size, margin
**Answer: b) root/parent, attribute, case-sensitivity, special-symbol** — those four families are the named hunting list.
