# Lesson plan — Well-formed XML — root, case and nesting rules

**Course:** Computer Science and ICT · **Title:** Internet and the Web · **Lesson:** Well-formed XML — root, case and nesting rules
**Place in the curriculum:** Title — Internet and the Web in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 12 book, Unit 4 — Web Authoring. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** a document that follows XML's syntax rules is well formed — one root, matching case, proper nesting, quoted attribute values, and correct comments.
**This lesson's own level:** it stands on the viewing lesson — the learner has written and opened a file; this doing lesson checks that file against the first syntax rules, including the guide's corrected documents (teacher guide — evidence).

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **One root, matching case, proper nesting (doing)** — one root only, starting and ending with the same tag; elements are case sensitive; elements must not overlap and must nest properly
2. **Quoted values and correct comments — and the error families (doing)** — attribute values must always be quoted; comments use the HTML-like syntax; the guide names the error families to hunt

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Viewing XML — browser, text editor and XML Notepad. Recommended, never forced.

## What the learner can do when it ends
1. State the five rules and call a document that follows them well formed.
2. Fix a broken document: root, case, nesting, quoting and comment faults.
3. Recognise the guide's named error families (teacher guide — evidence).

## What you need
A computer with a text editor and a browser; paper and a pencil.

## If the learner is stuck
- Thinks overlapping is nesting → nested elements close inside their parent, in reverse order; overlapping crosses the boundaries.
- Forgives a case slip → XML is case sensitive; <Book> and <book> are different names.
