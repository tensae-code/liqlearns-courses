# Video script — Well-formed XML — root, case and nesting rules

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Five rules make a document well formed.
One root. Only one.
Case must match. Book is not book.
Nest properly. Never overlap.
Quote every attribute value.
Comments wear their proper markers.
Break one rule, and the document is not well formed.
Fix it, check it, then open it.
