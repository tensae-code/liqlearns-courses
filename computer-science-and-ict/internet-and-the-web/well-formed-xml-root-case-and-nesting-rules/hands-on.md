# Hands-on — Well-formed XML — root, case and nesting rules

The lesson with your hands, not only your eyes.

## The five-rule check
Print or copy a document. Go rule by rule with a ruler: one root? case matching? nesting clean? values quoted? comments correct? Tick each rule as it passes.

## Fix the broken set
On paper, write the five broken forms — then write each one's corrected form beside it, as the guide's corrected documents do (teacher guide — evidence).
