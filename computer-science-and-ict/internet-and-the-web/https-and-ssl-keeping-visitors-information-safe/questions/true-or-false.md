# HTTPS and SSL — how a site keeps visitors' information safe — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** HTTP and HTTPS are equally safe for private information.
**Answer: False** — HTTPS is the secure protocol; HTTP is not the one for private information.

**2. (Sub lesson 2)** A site's professional look proves it is secure.
**Answer: False** — the address-bar sign is the check, not the site's looks.

**3. (Sub lesson 2)** SSL stands for Secure Sockets Layer.
**Answer: True** — Secure Sockets Layer is the full name.
