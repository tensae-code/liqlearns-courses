# HTTPS and SSL — how a site keeps visitors' information safe — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A site needs HTTPS when —
a) it has many pictures  b) visitors give private information  c) it is a school site
**Answer: b) visitors give private information** — private information is the stated trigger.

**2. (Sub lesson 1)** HTTPS is enabled by —
a) an SSL certificate  b) a domain name  c) a CSS folder
**Answer: a) an SSL certificate** — the SSL certificate enables HTTPS.

**3. (Sub lesson 1)** SSL encrypts information —
a) at rest in a drawer  b) in transit between the website and its database  c) in printed copies
**Answer: b) in transit between the website and its database** — in transit, website to database, is SSL's encryption.

**4. (Sub lesson 2)** A secure site shows, in the address bar —
a) an information icon and 'Not secure'  b) a locked padlock  c) nothing at all
**Answer: b) a locked padlock** — the locked padlock is the secure sign.
