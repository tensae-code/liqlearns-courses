# Validating User Input on the Server — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is validation?**
a) Checking a sent value against its rules before the program uses or stores it  b) Presence, type, range, format, length  c) Range — a mark must lie between 0 and 100  d) Format
**Answer: a) Checking a sent value against its rules before the program uses or stores it**

**2. (Sub lesson 1) Name the standing checks.**
a) Range — a mark must lie between 0 and 100  b) Presence, type, range, format, length  c) Format  d) To the user, by field — so the sending can be corrected
**Answer: b) Presence, type, range, format, length**

**3. (Sub lesson 1) A mark of 140 fails which check?**
a) Format  b) To the user, by field — so the sending can be corrected  c) Range — a mark must lie between 0 and 100  d) It teaches nothing and protects by luck
**Answer: c) Range — a mark must lie between 0 and 100**
