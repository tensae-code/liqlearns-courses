# Hands-on — Examples of Websites — and the Languages Used to Build Them

The lesson with your hands and your feet, not only your eyes.

## Task one
**Kind census** — List ten websites you used this week; sort each by kind and name the design feature its work explains.

## Task two
**Which language speaks?** — Take one live page and identify one HTML fact, one CSS fact and one JavaScript fact about it, with evidence.
