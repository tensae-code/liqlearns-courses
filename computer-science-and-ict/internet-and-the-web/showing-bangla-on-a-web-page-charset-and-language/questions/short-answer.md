# Showing Bangla on a Web Page — Charset and Language — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does meta charset declare?**
**Answer: The character encoding the page uses**

**2. (Sub lesson 1) Write the declaration for a Unicode page.**
**Answer: <meta charset="utf-8">**

**3. (Sub lesson 1) Where does the charset line live?**
**Answer: First in the head**

**4. (Sub lesson 1) What happens without it?**
**Answer: The browser guesses the code — and Bangla arrives as boxes**

**5. (Sub lesson 1) Which encoding holds every script?**
**Answer: UTF-8**

**6. (Sub lesson 2) What does the lang attribute name?**
**Answer: The page's language**

**7. (Sub lesson 2) Write the html tag for a Bangla page.**
**Answer: <html lang="bn">**

**8. (Sub lesson 2) Name two users of the lang declaration.**
**Answer: Screen readers and search engines (also translation offers, font choice)**

**9. (Sub lesson 2) What are the two declarations together called in this lesson?**
**Answer: The page's passport**

**10. (Sub lesson 2) What does charset say, against lang?**
**Answer: Charset says how letters are coded; lang says what language they speak**
