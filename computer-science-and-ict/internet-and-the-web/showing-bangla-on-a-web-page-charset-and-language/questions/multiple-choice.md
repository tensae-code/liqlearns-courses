# Showing Bangla on a Web Page — Charset and Language — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does meta charset declare?**
a) The character encoding the page uses  b) <meta charset="utf-8">  c) First in the head  d) The browser guesses the code — and Bangla arrives as boxes
**Answer: a**

**2. (Sub lesson 1) Write the declaration for a Unicode page.**
a) <meta charset="utf-8">  b) First in the head  c) The browser guesses the code — and Bangla arrives as boxes  d) UTF-8
**Answer: a**

**3. (Sub lesson 1) Where does the charset line live?**
a) First in the head  b) The browser guesses the code — and Bangla arrives as boxes  c) UTF-8  d) The page's language
**Answer: a**

**4. (Sub lesson 1) What happens without it?**
a) The browser guesses the code — and Bangla arrives as boxes  b) UTF-8  c) The page's language  d) <html lang="bn">
**Answer: a**
