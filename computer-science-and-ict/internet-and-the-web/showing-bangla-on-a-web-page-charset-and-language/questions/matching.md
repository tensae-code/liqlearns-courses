# Showing Bangla on a Web Page — Charset and Language — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What does meta charset declare?** → **The character encoding the page uses**

**2. (Sub lesson 1) Write the declaration for a Unicode page.** → **<meta charset="utf-8">**

**3. (Sub lesson 1) Where does the charset line live?** → **First in the head**

**4. (Sub lesson 1) What happens without it?** → **The browser guesses the code — and Bangla arrives as boxes**

**5. (Sub lesson 1) Which encoding holds every script?** → **UTF-8**

**6. (Sub lesson 2) What does the lang attribute name?** → **The page's language**

**7. (Sub lesson 2) Write the html tag for a Bangla page.** → **<html lang="bn">**

**8. (Sub lesson 2) Name two users of the lang declaration.** → **Screen readers and search engines (also translation offers, font choice)**

**9. (Sub lesson 2) What are the two declarations together called in this lesson?** → **The page's passport**

**10. (Sub lesson 2) What does charset say, against lang?** → **Charset says how letters are coded; lang says what language they speak**
