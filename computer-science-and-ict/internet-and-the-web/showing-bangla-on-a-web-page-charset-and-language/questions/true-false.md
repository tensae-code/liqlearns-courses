# Showing Bangla on a Web Page — Charset and Language — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The character encoding the page uses**
**Answer: True**

**2. (Sub lesson 1) True or false: The character encoding the page uses** — as the answer to: Write the declaration for a Unicode page.
**Answer: False — <meta charset="utf-8">**

**3. (Sub lesson 1) True or false: First in the head**
**Answer: True**

**4. (Sub lesson 1) True or false: First in the head** — as the answer to: What happens without it?
**Answer: False — The browser guesses the code — and Bangla arrives as boxes**

**5. (Sub lesson 1) True or false: UTF-8**
**Answer: True**

**6. (Sub lesson 2) True or false: UTF-8** — as the answer to: What does the lang attribute name?
**Answer: False — The page's language**

**7. (Sub lesson 2) True or false: <html lang="bn">**
**Answer: True**

**8. (Sub lesson 2) True or false: <html lang="bn">** — as the answer to: Name two users of the lang declaration.
**Answer: False — Screen readers and search engines (also translation offers, font choice)**

**9. (Sub lesson 2) True or false: The page's passport**
**Answer: True**

**10. (Sub lesson 2) True or false: The page's passport** — as the answer to: What does charset say, against lang?
**Answer: False — Charset says how letters are coded; lang says what language they speak**
