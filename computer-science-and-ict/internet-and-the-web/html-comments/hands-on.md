# Hands-on — HTML Comments

The lesson with your hands and your feet, not only your eyes.

## Task one
('Label a page', 'Take an HTML page you built earlier and add comments labelling its banner, menu and main content, plus one reminder comment for a future edit. Confirm the page looks unchanged in the browser.')

## Task two
('Switch it off', 'Comment out one block of a page (a paragraph or an image) so it disappears without being deleted. Then restore it by removing only the marks.')
