# HTML Comments — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "How does an HTML comment begin and end?" is: It begins with <!-- and ends with -->**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Does the browser show comments?" is: No — it takes no space and shows nothing**
**Answer: False** — No — everything between the marks is ignored

**3. (Sub lesson 1) True or false: the answer to "Can a comment be a heading or image on the page?" is: No — it takes no space and shows nothing**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Can a comment cover several lines?" is: It swallows the rest of the page's code into the comment — the page breaks below it**
**Answer: False** — Yes

**5. (Sub lesson 1) True or false: the answer to "What does a missing closing mark do?" is: It swallows the rest of the page's code into the comment — the page breaks below it**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Who are comments for?" is: Labelling parts of a page, and leaving reminders (also: explaining unusual code)**
**Answer: False** — The people who maintain the code

**7. (Sub lesson 2) True or false: the answer to "Give two uses Malaysia's unit names." is: Labelling parts of a page, and leaving reminders (also: explaining unusual code)**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How can a comment switch code off?" is: Anyone who views the page's source**
**Answer: False** — Wrap the block in comment marks — hidden without deleting, restored by removing the marks

**9. (Sub lesson 2) True or false: the answer to "Who can read a comment?" is: Anyone who views the page's source**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What must never go in a comment?" is: It begins with <!-- and ends with -->**
**Answer: False** — Passwords or private remarks
