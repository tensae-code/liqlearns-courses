# Building a Site in FrontPage — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does FrontPage work on?" is: The whole site — its pages, folders and links together.**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How is a page edited in FrontPage?" is: By walking the site as a visitor, using only its links.**
**Answer: False** — Visually — text formatted, pictures and tables placed — while the editor writes the HTML underneath.

**3. (Sub lesson 1) True or false: the answer to "Where does FrontPage sit on the book's ladder?" is: In the middle — more control than Word conversion, less bare code than Notepad.**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What becomes real first in developing a site?" is: The course's opening design — purpose, audience, structure.**
**Answer: False** — The skeleton — home page and planned pages, linked as designed.

**5. (Sub lesson 1) True or false: the answer to "What fills the pages after the skeleton?" is: Prepared content — texts, prepared images, and tables where they help.**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How are links checked?" is: The same site idea is carried from design, through hand-written Notepad HTML, and rebuilt in FrontPage.**
**Answer: False** — By walking the site as a visitor, using only its links.

**7. (Sub lesson 2) True or false: the answer to "When is a developed site ready?" is: When it walks cleanly — ready for publication.**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What design work does the build start from?" is: Visually — text formatted, pictures and tables placed — while the editor writes the HTML underneath.**
**Answer: False** — The course's opening design — purpose, audience, structure.

**9. (Sub lesson 2) True or false: the answer to "Can the HTML underneath be viewed in FrontPage?" is: Yes — it can also be viewed and touched directly.**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is Belarus's deliberate pattern here?" is: The skeleton — home page and planned pages, linked as designed.**
**Answer: False** — The same site idea is carried from design, through hand-written Notepad HTML, and rebuilt in FrontPage.
