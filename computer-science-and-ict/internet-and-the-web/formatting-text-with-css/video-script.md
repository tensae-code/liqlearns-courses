# Video script — Formatting Text With CSS

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

CSS formats text with **properties on the text's element**. **font-family** names the typeface (with fallbacks — `font-family: Arial, sans-serif;` tries Arial, then any sans-serif). **font-size** sets the size, in pixels or relative units. **font-style** makes text *italic*; **font-weight** makes it **bold**. Vietnam's Grade 12 book teaches these as the CSS replacement for HTML's old formatting tags: the look now lives in the style sheet, where one change restyles every page.
Beyond the letters, CSS shapes the paragraph: **text-align** sets alignment (left, right, center, justify); **line-height** sets the spacing between lines; **letter-spacing** and **word-spacing** open the text out; **text-decoration** underlines or strikes through (and removes the underline from links). The book's rule is restraint: formatting serves reading — a page where everything shouts, aligns differently and glitters is a page nobody finishes.
