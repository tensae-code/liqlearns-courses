# Formatting Text With CSS — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) Which property names the typeface?** → **font-family**

**2. (Sub lesson 1) Why does font-family list several names?** → **They are fallbacks — the browser uses the first one it has**

**3. (Sub lesson 1) Which property sets the size of text?** → **font-size**

**4. (Sub lesson 1) Which two properties give italic and bold?** → **font-style gives italic; font-weight gives bold**

**5. (Sub lesson 1) Where does the look live, in CSS formatting?** → **In the style sheet — one change restyles every page**

**6. (Sub lesson 2) Which property aligns text?** → **text-align — left, right, center or justify**

**7. (Sub lesson 2) Which property sets the space between lines?** → **line-height**

**8. (Sub lesson 2) What do letter-spacing and word-spacing change?** → **The space between letters, and between words**

**9. (Sub lesson 2) What does text-decoration do?** → **Underlines or strikes through text — and can remove a link's underline**

**10. (Sub lesson 2) What is the book's rule for formatting?** → **Restraint — formatting serves reading**
