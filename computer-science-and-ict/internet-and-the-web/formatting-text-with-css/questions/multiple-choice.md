# Formatting Text With CSS — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Which property names the typeface?**
a) font-family  b) They are fallbacks — the browser uses the first one it has  c) font-size  d) font-style gives italic; font-weight gives bold
**Answer: a**

**2. (Sub lesson 1) Why does font-family list several names?**
a) They are fallbacks — the browser uses the first one it has  b) font-size  c) font-style gives italic; font-weight gives bold  d) In the style sheet — one change restyles every page
**Answer: a**

**3. (Sub lesson 1) Which property sets the size of text?**
a) font-size  b) font-style gives italic; font-weight gives bold  c) In the style sheet — one change restyles every page  d) text-align — left, right, center or justify
**Answer: a**

**4. (Sub lesson 1) Which two properties give italic and bold?**
a) font-style gives italic; font-weight gives bold  b) In the style sheet — one change restyles every page  c) text-align — left, right, center or justify  d) line-height
**Answer: a**

**5. (Sub lesson 1) Where does the look live, in CSS formatting?**
a) In the style sheet — one change restyles every page  b) text-align — left, right, center or justify  c) line-height  d) The space between letters, and between words
**Answer: a**

**6. (Sub lesson 2) Which property aligns text?**

**7. (Sub lesson 2) Which property sets the space between lines?**

**8. (Sub lesson 2) What do letter-spacing and word-spacing change?**

**9. (Sub lesson 2) What does text-decoration do?**
a) Underlines or strikes through text — and can remove a link's underline  b) Restraint — formatting serves reading  c) font-family  d) They are fallbacks — the browser uses the first one it has

**10. (Sub lesson 2) What is the book's rule for formatting?**
