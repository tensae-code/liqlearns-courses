# Formatting Text With CSS — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: font-family**
**Answer: True**

**2. (Sub lesson 1) True or false: font-family** — as the answer to: Why does font-family list several names?
**Answer: False — They are fallbacks — the browser uses the first one it has**

**3. (Sub lesson 1) True or false: font-size**
**Answer: True**

**4. (Sub lesson 1) True or false: font-size** — as the answer to: Which two properties give italic and bold?
**Answer: False — font-style gives italic; font-weight gives bold**

**5. (Sub lesson 1) True or false: In the style sheet — one change restyles every page**
**Answer: True**

**6. (Sub lesson 2) True or false: In the style sheet — one change restyles every page** — as the answer to: Which property aligns text?
**Answer: False — text-align — left, right, center or justify**

**7. (Sub lesson 2) True or false: line-height**
**Answer: True**

**8. (Sub lesson 2) True or false: line-height** — as the answer to: What do letter-spacing and word-spacing change?
**Answer: False — The space between letters, and between words**

**9. (Sub lesson 2) True or false: Underlines or strikes through text — and can remove a link's underline**
**Answer: True**

**10. (Sub lesson 2) True or false: Underlines or strikes through text — and can remove a link's underline** — as the answer to: What is the book's rule for formatting?
**Answer: False — Restraint — formatting serves reading**
