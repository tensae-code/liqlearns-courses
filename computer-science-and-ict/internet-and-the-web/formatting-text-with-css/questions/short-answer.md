# Formatting Text With CSS — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) Which property names the typeface?**
**Answer: font-family**

**2. (Sub lesson 1) Why does font-family list several names?**
**Answer: They are fallbacks — the browser uses the first one it has**

**3. (Sub lesson 1) Which property sets the size of text?**
**Answer: font-size**

**4. (Sub lesson 1) Which two properties give italic and bold?**
**Answer: font-style gives italic; font-weight gives bold**

**5. (Sub lesson 1) Where does the look live, in CSS formatting?**
**Answer: In the style sheet — one change restyles every page**

**6. (Sub lesson 2) Which property aligns text?**
**Answer: text-align — left, right, center or justify**

**7. (Sub lesson 2) Which property sets the space between lines?**
**Answer: line-height**

**8. (Sub lesson 2) What do letter-spacing and word-spacing change?**
**Answer: The space between letters, and between words**

**9. (Sub lesson 2) What does text-decoration do?**
**Answer: Underlines or strikes through text — and can remove a link's underline**

**10. (Sub lesson 2) What is the book's rule for formatting?**
**Answer: Restraint — formatting serves reading**
