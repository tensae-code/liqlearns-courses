# Hands-on — Formatting Text With CSS

The lesson with your hands and your feet, not only your eyes.

## Task one
**Restyle a page** — Take a plain HTML page. Add a style sheet that sets its font family, sizes for headings and paragraphs, and justified body text with comfortable line-height.

## Task two
**Before and after** — Format the same paragraph twice — once with HTML formatting tags, once with CSS. Say what the CSS way buys when the page grows to ten pages.
