# Hands-on — The CSS Box Model

The lesson with your hands and your feet, not only your eyes.

## Task one
**Draw the box** — For one element on a page you have made, draw its box with all four layers labelled and their sizes written in.

## Task two
**Fix the overflow** — Make two boxes of width 200px sit side by side in a 420px container, each with 10px padding and a 2px border. Compute first, then check in the browser.
