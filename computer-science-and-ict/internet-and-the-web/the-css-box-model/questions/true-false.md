# The CSS Box Model — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Content, padding, border, margin**
**Answer: True**

**2. (Sub lesson 1) True or false: Content, padding, border, margin** — as the answer to: Where is padding?
**Answer: False — Inside the box — clear space between the content and the edge**

**3. (Sub lesson 1) True or false: Its width, its style and its colour**
**Answer: True**

**4. (Sub lesson 1) True or false: Its width, its style and its colour** — as the answer to: Where is the margin?
**Answer: False — Outside the box — clear space between this box and its neighbours**

**5. (Sub lesson 1) True or false: The content, sized by width and height**
**Answer: True**

**6. (Sub lesson 2) True or false: The content, sized by width and height** — as the answer to: How is an element's true width computed?
**Answer: False — Width plus both paddings, both borders and both margins**

**7. (Sub lesson 2) True or false: Their paddings and borders were forgotten in the sum**
**Answer: True**

**8. (Sub lesson 2) True or false: Their paddings and borders were forgotten in the sum** — as the answer to: What happens to adjoining vertical margins?
**Answer: False — They collapse into one — the larger of the two**

**9. (Sub lesson 2) True or false: Draw the boxes — the picture finds the forgotten layer**
**Answer: True**

**10. (Sub lesson 2) True or false: Draw the boxes — the picture finds the forgotten layer** — as the answer to: Which layer takes the element's background colour?
**Answer: False — The content and padding area — the background reaches to the border's inside edge**
