# DTD — the rulebook inside the document — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** An internal DTD sits inside the XML file, wrapped in the DOCTYPE.
**Answer: True** — inside the file, in the DOCTYPE — that is what internal means here.

**2. (Sub lesson 2)** An album document listing language before release breaks the DTD.
**Answer: True** — the order singer, name, release, language is part of the rule.

**3. (Sub lesson 1)** A DTD checks whether the document's facts are true.
**Answer: False** — it checks structure and legality — validity — not the truth of the content.
