# DTD — the rulebook inside the document — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A DTD defines a document's —
a) colours and structure  b) structure and its legal elements and attributes  c) price and author
**Answer: b) structure and its legal elements and attributes** — structure plus legal elements and attributes is the DTD's content.

**2. (Sub lesson 1)** An application uses a DTD to verify that XML data is —
a) beautiful  b) valid  c) long
**Answer: b) valid** — valid — obeying its declared rules.

**3. (Sub lesson 2)** In the album DTD, the element that must come first inside album is —
a) name  b) release  c) singer
**Answer: c) singer** — the declared order is singer, name, release, language.

**4. (Sub lesson 2)** Each of the album's four parts is declared as —
a) an attribute  b) #PCDATA  c) an empty element
**Answer: b) #PCDATA** — each leaf holds parsed character data — text.
