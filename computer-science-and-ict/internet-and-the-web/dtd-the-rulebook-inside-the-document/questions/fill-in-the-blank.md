# DTD — the rulebook inside the document — fill in the blank

Fill each blank with the right word or code.

**1. (Sub lesson 1)** DTD stands for Document Type ___.
**Answer: Definition** — Document Type Definition.

**2. (Sub lesson 2)** The DOCTYPE of the album example names the root: ___.
**Answer: album** — album is the root the DOCTYPE names.

**3. (Sub lesson 2)** Data that obeys its DTD is called ___.
**Answer: valid** — valid is the verdict the application gives.
