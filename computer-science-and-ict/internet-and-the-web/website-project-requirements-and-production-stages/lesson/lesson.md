# Website Project — Requirements and Production Stages

## Do it first

Unit 2 of Egypt's Grade 11 project is the professional middle: before pages are built in Unit 3, the project — the Illustrated Dictionary of Computer Terms — is specified. What the site must do is written as requirements, and the making is divided into production stages, each with its own product.

## Sub lesson 1 — Requirements — what the site must do, written before building

**Requirements** are the project's contract: the statements of what the finished site must **do** and **be**, written before building begins and used after it ends to judge the result. For the dictionary site they name its jobs — visitors browse and search terms; an authorised user adds a term through a page; every term shows its meaning and illustration — and its qualities: pages consistent, data kept in a database, the site working in a school browser. A requirement is testable or it is a wish: 'adding a term stores it and the term then appears in search' can be checked; 'the site should be nice' cannot. Egypt devotes a full unit to this because pupils, like professionals, otherwise build first and discover the contract afterwards — from the complaints.

## Sub lesson 2 — Production stages — specification to finished site

The making is divided into **production stages**, each ending in something checkable: **analysis** (the audience and their needs), **design** (the site's structure, page pattern and database design), **implementation** (pages built, database created, code written), **testing** (the requirements tried one by one), and **publishing and maintenance** (the site placed where its audience reaches it, and kept correct after). The stages discipline the project twice over: work is done in an order where each stage feeds the next — no pages before the database design they write into — and a fault is traced to the stage that owns it, so a wrong requirement is not 'fixed' by patching code. The Grade 11 term is literally built in these stages: Unit 1 plans, Unit 2 specifies, Unit 3 produces.
