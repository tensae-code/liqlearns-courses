# Hands-on — HTML tables

The lesson with your hands, not only your eyes. You need a computer with a text editor and a browser for the doing parts.

## Mountains table
Build the book's worked example: Ethiopian mountains and their elevations, with a header row and visible borders.

## Borderless, then headers
Following the guide's Activity 4.11 shape: build a small multiplication table with no border, then rebuild it with row and column headers — and leave the corner header cell empty, as the guide points out.
