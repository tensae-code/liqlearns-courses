# Lesson plan — HTML tables

**Course:** Computer Science and ICT · **Title:** Internet and the Web · **Lesson:** HTML tables
**Place in the curriculum:** Title — Internet and the Web in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 11 book, Unit 4 — Web Development. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** a table organises data into rows and columns with four tags — table, row, header cell and data cell — and a border attribute makes its borders visible.
**This lesson's own level:** it stands on the attributes lesson — a table is elements and attributes working together.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **What a table is for, and its four tags** — the table's two jobs and its four tags
2. **Counting rows and columns; the border** — rows and columns counted from the elements; the border; the guide's header-and-corner teaching points

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: HTML attributes — and the img element. Recommended, never forced.

## What the learner can do when it ends
1. Build a table with the four table tags.
2. Count rows and columns from the elements.
3. Add visible borders with the border attribute.

## What you need
A computer with a text editor and a browser.

## If the learner is stuck
- Columns come out uneven → count the data elements in each row; every row needs the same count for a straight table.
- No borders show → the border attribute is what makes borders visible; a value of zero hides the grid (guide).
