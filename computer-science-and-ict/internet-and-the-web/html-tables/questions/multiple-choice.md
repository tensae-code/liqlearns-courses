# HTML tables — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) A table organises data into —**
a) rows and columns  b) pages and chapters  c) sounds and videos  d) files and folders
**Answer: a) rows and columns** — rows × columns is the table's shape.

**2. (Sub lesson 1) The tag that defines a row is the —**
a) row tag  b) header tag  c) data tag  d) table tag
**Answer: a) row tag** — one row element per row.

**3. (Sub lesson 1) Header cells are defined by the —**
a) header tag  b) data tag  c) row tag  d) border attribute
**Answer: a) header tag** — header tag = header cells.

**4. (Sub lesson 1) Ordinary data cells are defined by the —**
a) data tag  b) header tag  c) table tag  d) row tag
**Answer: a) data tag** — data tag = ordinary cells.

**5. (Sub lesson 2) The number of rows in a table is set by —**
a) the count of row elements  b) the count of header elements  c) the border value  d) the file name
**Answer: a) the count of row elements** — count the row elements.

**6. (Sub lesson 2) Visible borders are added by —**
a) the border attribute  b) the header tag  c) a second table  d) the title
**Answer: a) the border attribute** — border makes the grid visible.
