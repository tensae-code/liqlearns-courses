# HTML tables — fill in the blank

Fill each blank with the right word or code.

**1. (Sub lesson 1) The count of ___ elements in a row sets the columns.**
**Answer: data** — data elements per row = columns.

**2. (Sub lesson 1) A table's two jobs: hold data, and lay out page ___.**
**Answer: content** — content layout is the second job.

**3. (Sub lesson 2) The guide's Activity 4.11 solution is built as a ___ table. (teacher guide — evidence)**
**Answer: multiplication** — a multiplication grid.
