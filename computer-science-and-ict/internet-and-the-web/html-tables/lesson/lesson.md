# HTML tables

## Do it first

Data lines up best in rows and columns. Build this table: Ethiopian mountains in one column, their elevations in the next, with a heading row on top — the book's own worked example. Four tags do the whole job; this lesson names them while your table takes shape.

## Sub lesson 1 — What a table is for, and its four tags

A **table organises data into rows and columns** — and it can also **lay out page content**, as a later lesson shows. Four tags build it:

- The **table tag** defines the table.
- The **row tag** defines a row.
- The **header tag** defines header cells.
- The **data tag** defines ordinary data cells.

## Sub lesson 2 — Counting rows and columns; the border

The structure counts itself: the **count of row elements sets the rows**, and the **count of data elements in a row sets the columns**. A **border attribute adds visible borders**. The worked example tables **Ethiopian mountains with their elevations**. The guide's Activity 4.11 solution adds a teaching point (teacher guide — evidence): the same table is built first **borderless**, then rebuilt **with row and column headers** — with a **deliberately empty corner header cell** — and a **border value of zero is what hides the grid**. The guide solves that activity as a multiplication table.
