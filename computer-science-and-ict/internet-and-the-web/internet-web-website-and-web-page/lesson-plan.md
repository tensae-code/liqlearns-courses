# Lesson plan — Internet, Web, website and web page

**Course:** Computer Science and ICT · **Title:** Internet and the Web · **Lesson:** Internet, Web, website and web page
**Place in the curriculum:** Title 8 — Internet and the Web in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 7 book, Unit 4 — Internet. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** the internet is the network; the Web is how we reach the information on it; a website is a page or linked pages together; a web page is one page; and the home page is a site's first page.
**This lesson's own level:** it stands on the lesson before it — the network must exist before what travels on it can be sorted out.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Internet against Web** — the internet is the global network; the World Wide Web is the means of reaching the information on it
2. **Website, web page, home page** — a website is a page or linked pages; a web page is a single page; the home page is the first page, linking onward — and why people make pages

3. **The Web in depth — server, hyperlink, URL (Grade 8)** — the WWW as part of the internet (invented 1991, Tim Berners-Lee); pages stored on a web server, holding hyperlinks; the URL's two parts (Grade 8 growth, Wave 3 band B2)

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: The internet — a network of networks.  Recommended, never forced.

## What the learner can do when it ends
1. Tell the internet and the Web apart.
2. Define website, web page and home page.
3. Say when all three page-words mean the same thing.
4. Give three reasons people make web pages.

## What you need
Paper and a pencil.

## The run of the lesson (in order)
1. **Do it first** — the learner sorts four words — internet, Web, website, web page — by size, biggest first, before the definitions (lesson/lesson.md).
2. **The explanation** — the parts below, in order (lesson/lesson.md).
   - ADD IMAGE [Picture 11720]: a picture of pages joined by hyperlink threads into a website, one page carrying its two-part URL — the student traces a hyperlink and splits the URL aloud.
   - ADD IMAGE [Picture 10512]: a picture of a website drawn as a small book — cover is the home page, pages are web pages — the student points to cover and pages and names each one.
3. **Say it to your companion** — explain the lesson back in your own words (lesson/lesson.md).
   - ADD VIDEO: the script in video-script.md, filmed — the lesson retold in the super-simple voice (made later, when videos are made).
4. **Questions** — from questions/: multiple-choice, true-or-false, fill-in-the-blank — served at the learner's level (levels.md).
5. **Hands-on** — hands-on.md.
6. **Do It Yourself** — the doing block at the end of lesson/lesson.md.

## If the learner is stuck
- Mixes internet and Web → roads vs travelling: the network is the internet; reaching information on it is the Web.
- Mixes website and web page → a page is single; a site is the page or the linked collection.
