# Internet, Web, website and web page — fill in the blank

Fill each blank with the right word.

**1. (Sub lesson 1)** The World Wide ______ is the means of accessing information on the internet.
**Answer: Web**

**2. (Sub lesson 2)** A website's first page is its ______ page.
**Answer: home**

**3. (Sub lesson 2)** A single page of text, images, sound or video is a web ______.
**Answer: page**

**4. (Sub lesson 3)** A link to another web page is called a _______.
**Answer: hyperlink**

**5. (Sub lesson 3)** Web pages can be viewed through browsers such as Google Chrome, Internet Explorer and Mozilla _______.
**Answer: Firefox**

**Item. (Sub lesson 4)** HTTP is the set of ____ browsers and servers use to talk.
**Answer: rules** — one of the Web's four foundations (Grade 11 book, Unit 4).
