# Internet, Web, website and web page — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** The Web and the internet are exactly the same thing.
**Answer: False** — network vs the means of accessing its information.

**2. (Sub lesson 2)** A one-page website's web page and home page are the same page.
**Answer: True** — the guide's point: all three words meet in one page.

**3. (Sub lesson 2)** A home page links to the site's other pages.
**Answer: True** — like a cover leading to chapters.
