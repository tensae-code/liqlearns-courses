# Internet, Web, website and web page — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The Web is —
a) the global network itself  b) the means of accessing information on the internet  c) a single page  d) a browser only
**Answer: b) the means of accessing information on the internet** — the Web is how information on the network is reached.

**2. (Sub lesson 1)** The internet is —
a) a collection of pages only  b) the global network  c) one website  d) a search engine
**Answer: b) the global network** — the network itself.

**3. (Sub lesson 2)** A web page is —
a) a whole collection of sites  b) a single page of text, images, sound or video  c) a network cable  d) the first page only
**Answer: b) a single page of text, images, sound or video** — single page.

**4. (Sub lesson 2)** The home page is —
a) the last page  b) a website's first page, linking to its other pages  c) a printed page  d) the address bar
**Answer: b) a website's first page, linking to its other pages** — first page, linking onward.

**5. (Sub lesson 2)** A website is —
a) one page, or a collection of related linked pages  b) always exactly 100 pages  c) a kind of network  d) a password
**Answer: a) one page, or a collection of related linked pages** — a page or linked pages together.

**6. (Sub lesson 2)** People make web pages to —
a) share information and news, sell or advertise, express a view  b) hide all information  c) replace computers  d) stop communication
**Answer: a) share information and news, sell or advertise, express a view** — the book's three reasons.

**7. (Sub lesson 3)** The World Wide Web was invented in 1991 by —
a) Tim Berners-Lee  b) the Ministry  c) Google  d) no one — it always existed
**Answer: a) Tim Berners-Lee — 1991.**

**8. (Sub lesson 3)** A web page is stored on —
a) a web server  b) a printer  c) a keyboard  d) a flash disk only
**Answer: a) a web server — a document on the WWW, stored on a web server.**

**9. (Sub lesson 3)** The two main components of a URL are —
a) username and password  b) protocol identifier and resource name  c) sender and subject  d) request and response
**Answer: b) protocol identifier and resource name**

**10. (Sub lesson 4)** The Web was invented by —
a) Tim Berners-Lee, at CERN in Switzerland, in 1989  b) a telephone company, in 1969  c) a browser company, in 2001
d) no one — it grew by itself
**Answer: a) Tim Berners-Lee, at CERN in Switzerland, in 1989** (Grade 11 book, Unit 4).

**11. (Sub lesson 4)** Which list is the Web's four foundations?
a) HTML, HTTP, a web server and a web browser  b) email, files, chat and games  c) a keyboard, a mouse, a screen and a printer
d) a website, a web page, a home page and a link
**Answer: a) HTML, HTTP, a web server and a web browser.**
