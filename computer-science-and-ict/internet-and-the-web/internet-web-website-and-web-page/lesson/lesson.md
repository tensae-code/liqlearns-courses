# Internet, Web, website and web page

## Do it first

Four words people mix up: internet, Web, website, web page. Put them in order, biggest to smallest, as your best guess. This lesson sorts them properly — and one of your four is not a size at all, but a road.

## Sub lesson 1 — Internet against Web

The **internet** is the global network itself — the joined computers. The **Web** — the World Wide Web — is the **means of accessing the information** on that network: a collection of information reached through the internet. Same world, two ideas: the internet is the roads and wires; the Web is the travelling you do on them.

## Sub lesson 2 — Website, web page, home page

A **website** is a web page, or a collection of related, linked web pages. A **web page** is a single page of text, images, sound or video. The **home page** is a website's first page — it links to the site's other pages, like a book's cover leading to its chapters. One teacher-guide point worth keeping: where a website has only one page, website, web page and home page are all that same page. And why do people and organisations make pages at all? To **share information and news, to sell or advertise products, and to express a point of view**.

## Say it to your companion

Tell your companion the four words sorted: internet, Web, website, web page — with the home page placed too.
