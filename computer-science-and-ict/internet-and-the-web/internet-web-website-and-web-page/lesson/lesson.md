# Internet, Web, website and web page

## Do it first

Four words people mix up: internet, Web, website, web page. Put them in order, biggest to smallest, as your best guess. This lesson sorts them properly — and one of your four is not a size at all, but a road.

## Sub lesson 1 — Internet against Web

The **internet** is the global network itself — the joined computers. The **Web** — the World Wide Web — is the **means of accessing the information** on that network: a collection of information reached through the internet. Same world, two ideas: the internet is the roads and wires; the Web is the travelling you do on them.

## Sub lesson 2 — Website, web page, home page

A **website** is a web page, or a collection of related, linked web pages. A **web page** is a single page of text, images, sound or video. The **home page** is a website's first page — it links to the site's other pages, like a book's cover leading to its chapters. One teacher-guide point worth keeping: where a website has only one page, website, web page and home page are all that same page. And why do people and organisations make pages at all? To **share information and news, to sell or advertise products, and to express a point of view**.

## Sub lesson 3 — The Web in depth — server, hyperlink, URL (Grade 8)

The Grade 8 book takes the same Web further. The **World Wide Web** is a **collection of websites or web pages** — a **part of the internet**, **invented in 1991 by Tim Berners-Lee**. It is reached **from anywhere in the world**, over the internet, on **computers, laptops and cell phones**, and viewed through **browsers** such as **Google Chrome, Internet Explorer and Mozilla Firefox**. A **web page** is a document on the WWW, **stored on a web server**, holding **text, graphics, audio, video and hyperlinks** — links to other web pages. A **collection of linked web pages is a website**. Each page has its **own unique address**: the **Uniform Resource Locator (URL)**, with **two main components — the protocol identifier and the resource name**. In **http://www.google.com**, they are **http** and **www.google.com**.

## Sub lesson 4 — The Web's four foundations (Grade 11)

The Grade 11 book takes the same Web one level deeper. The Web is **one service of the internet — the most popular one**, among others such as **email and file transfer**: a **collection of websites and webpages reached over the internet with a browser**. **Tim Berners-Lee invented it in 1989 at CERN in Switzerland**, and it was formed from **four foundations**:

- **HTML** — the language webpages are written in.
- **HTTP** — the rules browsers and servers use to talk.
- **A web server** — software that stores webpages and answers browser requests.
- **A web browser** — software users view webpages with.

And its key word, one more time at this depth: a **website** is a **publicly accessible collection of interrelated webpages**, joined by **hypertext links** to pages, videos, images and more. The lessons after this one build real pages with the first foundation — HTML itself.

## Say it to your companion

Tell your companion the four words sorted: internet, Web, website, web page — with the home page placed too — then split http://www.google.com into its two URL parts. Then name the Web's four foundations and who invented the Web, where and when.

## Do It Yourself

1. Write all four definitions from memory.
2. Draw the book model and label it.
3. Give one real website and name its home page's job.
4. Write a URL and label its protocol identifier and its resource name.
5. Write the four foundations from memory and say what each one does.
