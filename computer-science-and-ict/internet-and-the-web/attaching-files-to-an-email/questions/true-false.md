# Attaching Files to an Email — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is an attachment?" is: A file sent together with an email**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Which command attaches a file?" is: A copy — the original stays on your computer**
**Answer: False** — Attach — the paperclip — while composing the message

**3. (Sub lesson 1) True or false: the answer to "What travels — the original or a copy?" is: A copy — the original stays on your computer**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is shown when a file is attached?" is: Because a message carrying a file is the complete act — the one real work most often needs**
**Answer: False** — Its name and size, listed with the message before sending

**5. (Sub lesson 1) True or false: the answer to "Why does the book teach attachments last in its e-mail chapter?" is: Because a message carrying a file is the complete act — the one real work most often needs**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How does a receiver spot an attachment?" is: Downloads (saves) it and opens it with a program that understands it**
**Answer: False** — By the message's paperclip

**7. (Sub lesson 2) True or false: the answer to "What does the receiver do with an attachment?" is: Downloads (saves) it and opens it with a program that understands it**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What are the three cares of attachments?" is: It is a letter in a language they cannot read — they have no program to open it**
**Answer: False** — Size, form and safety

**9. (Sub lesson 2) True or false: the answer to "Why can a file in a rare program fail its receiver?" is: It is a letter in a language they cannot read — they have no program to open it**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What should you do with an unexpected attachment?" is: A file sent together with an email**
**Answer: False** — Not open it — check with the sender first, as it may carry a virus
