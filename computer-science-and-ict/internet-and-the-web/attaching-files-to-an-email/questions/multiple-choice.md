# Attaching Files to an Email — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is an attachment?**
a) A file sent together with an email  b) Attach — the paperclip — while composing the message  c) A copy — the original stays on your computer  d) Its name and size, listed with the message before sending
**Answer: a) A file sent together with an email**

**2. (Sub lesson 1) Which command attaches a file?**
a) A copy — the original stays on your computer  b) Attach — the paperclip — while composing the message  c) Its name and size, listed with the message before sending  d) Because a message carrying a file is the complete act — the one real work most often needs
**Answer: b) Attach — the paperclip — while composing the message**

**3. (Sub lesson 1) What travels — the original or a copy?**
a) Its name and size, listed with the message before sending  b) Because a message carrying a file is the complete act — the one real work most often needs  c) A copy — the original stays on your computer  d) By the message's paperclip
**Answer: c) A copy — the original stays on your computer**

**4. (Sub lesson 1) What is shown when a file is attached?**
a) Because a message carrying a file is the complete act — the one real work most often needs  b) By the message's paperclip  c) Downloads (saves) it and opens it with a program that understands it  d) Its name and size, listed with the message before sending
**Answer: d) Its name and size, listed with the message before sending**

**5. (Sub lesson 1) Why does the book teach attachments last in its e-mail chapter?**
a) Because a message carrying a file is the complete act — the one real work most often needs  b) By the message's paperclip  c) Downloads (saves) it and opens it with a program that understands it  d) Size, form and safety
**Answer: a) Because a message carrying a file is the complete act — the one real work most often needs**

**6. (Sub lesson 2) How does a receiver spot an attachment?**

**7. (Sub lesson 2) What does the receiver do with an attachment?**

**8. (Sub lesson 2) What are the three cares of attachments?**
a) It is a letter in a language they cannot read — they have no program to open it  b) Not open it — check with the sender first, as it may carry a virus  c) A file sent together with an email  d) Size, form and safety

**10. (Sub lesson 2) What should you do with an unexpected attachment?**
