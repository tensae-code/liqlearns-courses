# Attaching Files to an Email

## Do it first

An email can carry more than words — a document, a picture, a whole file rides with it. In this lesson you learn attachments: how to send them, and how to receive them wisely.

## Sub lesson 1 — Attaching a file to a message

An **attachment** is a file sent together with an email. While composing the message, use the **Attach** command (the paperclip), choose the file from your computer, and it is listed with the message — name and size — before you **Send**. The file that travels is a copy: the original stays on your computer. Several files can ride with one message. Afghanistan's Grade 12 book teaches attachments inside its e-mail chapter, as the chapter's finishing skill: plain messages the student can already send; a message that carries a file is the complete act, the one real work most often needs — the homework, the photograph, the filled form.

## Sub lesson 2 — Receiving attachments — and attachment care

At the other end, a message with an attachment shows its paperclip; the receiver **downloads** (saves) the attached file and opens it with a program that understands it. Three cares govern attachments. **Size**: a very large file may be refused or fill the receiver's mailbox — send the smallest version that serves. **Form**: send a form the receiver can open; a file in a program they do not have is a letter in a language they cannot read. **Safety**: an attachment from an unknown sender, or an unexpected one from a known sender, may carry a virus — do not open it; check with the sender first. The paperclip is a door: welcome at your own choosing, never opened blindly.

## Say it to your companion

Tell your companion, in your own words: An attachment is a file that travels with an email: you attach it before sending, the receiver downloads and opens it — and attachments deserve care, because they can be too large, in a form the receiver cannot open, or unsafe. Then let your companion ask you one question about it — and answer from the lesson, not from memory of the book's exact words.
