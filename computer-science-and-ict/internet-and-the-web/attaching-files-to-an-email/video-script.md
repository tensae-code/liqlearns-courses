# Video script — Attaching Files to an Email

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

An **attachment** is a file sent together with an email.
While composing the message, use the **Attach** command (the paperclip), choose the file from your computer, and it is listed with the message — name and size — before you **Send**.
The file that travels is a copy: the original stays on your computer.
Several files can ride with one message.
Afghanistan's Grade 12 book teaches attachments inside its e-mail chapter, as the chapter's finishing skill: plain messages the student can already send; a message that carries a file is the complete act, the one real work most often needs — the homework, the photograph, the filled form.
At the other end, a message with an attachment shows its paperclip; the receiver **downloads** (saves) the attached file and opens it with a program that understands it.
Three cares govern attachments.
**Size**: a very large file may be refused or fill the receiver's mailbox — send the smallest version that serves.
**Form**: send a form the receiver can open; a file in a program they do not have is a letter in a language they cannot read.
**Safety**: an attachment from an unknown sender, or an unexpected one from a known sender, may carry a virus — do not open it; check with the sender first.
The paperclip is a door: welcome at your own choosing, never opened blindly.
