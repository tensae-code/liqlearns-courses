# The parts of an email address — true or false

Say whether each sentence is true or false.

**1.** Spaces are allowed inside an email address.
**Answer: False — spaces are not allowed.**

**2.** The @ symbol is read as 'at'.
**Answer: True — @ is the 'at' symbol between username and domain.**

**3.** Each email user's address name is unique to their account.
**Answer: True — each user has a unique name for their account.**
