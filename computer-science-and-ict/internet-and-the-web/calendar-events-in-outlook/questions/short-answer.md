# Calendar Events in Outlook — short answer

**1. (Sub lesson 1) What is setting up common events in the calendar?**
**Answer: The Outlook calendar holds events and meetings on a day-by-day grid: an event is an appointment with a time, and a meeting is an event with other people invited**

**2. (Sub lesson 1) What is the key work in setting up common events in the calendar?**
**Answer: The learner sets up common events in the calendar, creates meetings with invitees, and reads the calendar by day, week and month**
