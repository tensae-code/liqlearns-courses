# Bookmarking a Webpage for Later — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a bookmark?" is: A saved signpost to a webpage's address, kept inside the browser**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is a bookmark called in some browsers?" is: Because the bookmark leads to the living page at its address**
**Answer: False** — A favourite

**3. (Sub lesson 1) True or false: the answer to "When is a bookmark made?" is: While the page is open, by choosing Bookmark this page**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is saved in a bookmark — the page or its address?" is: Delete it, so the list stays honest**
**Answer: False** — Its address, not the page itself

**5. (Sub lesson 1) True or false: the answer to "Why does the returned page show updates?" is: Because the bookmark leads to the living page at its address**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What makes bookmarks findable?" is: A bookmark is a page you chose to keep; history is everything you visited**
**Answer: False** — Short clear names and folders for kinds of pages

**7. (Sub lesson 2) True or false: the answer to "What should be done with a bookmark to a moved or closed page?" is: Delete it, so the list stays honest**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Where do bookmarks live?" is: A saved signpost to a webpage's address, kept inside the browser**
**Answer: False** — In the bookmarks list or on the bookmarks toolbar

**9. (Sub lesson 2) True or false: the answer to "How does a bookmark differ from history?" is: A bookmark is a page you chose to keep; history is everything you visited**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "When does a bookmark serve best?" is: While the page is open, by choosing Bookmark this page**
**Answer: False** — When a good page will be needed again later
