# Video script — Entities — declare once, reference by name

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A long line, written again and again? Stop.
Declare it once. Give it a name. An entity.
ENTITY publisher — and the full text, tied to the name.
In the document, write only the reference: ampersand, name, semicolon.
The parser does the rest.
It expands the reference into the full text.
Declare once. Reference by name. Everywhere.
