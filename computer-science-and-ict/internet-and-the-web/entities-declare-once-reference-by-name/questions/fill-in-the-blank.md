# Entities — declare once, reference by name — fill in the blank

Fill each blank with the right word or code.

**1. (Sub lesson 1)** An entity is declared with an ___ declaration.
**Answer: ENTITY** — <!ENTITY …> is the declaration form.

**2. (Sub lesson 1)** The reference form is the name between & and ___.
**Answer: ;** — &name; — ampersand before, semicolon after.

**3. (Sub lesson 2)** The student book's example ties a ___ name to a printing company's name.
**Answer: publisher** — the publisher entity is the book's own example.
