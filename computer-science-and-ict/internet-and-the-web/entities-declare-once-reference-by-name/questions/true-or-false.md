# Entities — declare once, reference by name — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** The parser expands an entity reference into the full text.
**Answer: True** — expansion at processing is the entity's work — the GIF shows it.

**2. (Sub lesson 2)** An ENTITY declaration ties a name to replacement content.
**Answer: True** — name tied to content is the declaration.

**3. (Sub lesson 2)** Editing an entity declaration changes only the first reference to it.
**Answer: False** — every reference follows the one declaration.
