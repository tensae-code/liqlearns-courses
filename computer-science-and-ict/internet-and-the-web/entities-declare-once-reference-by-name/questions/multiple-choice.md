# Entities — declare once, reference by name — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** An entity must be —
a) used before it is declared  b) declared before use  c) written in HTML
**Answer: b) declared before use** — declared before use is the order.

**2. (Sub lesson 1)** An entity reference is written as —
a) the name between & and ;  b) the name in square brackets  c) the name alone
**Answer: a) the name between & and ;** — &name; is the reference form.

**3. (Sub lesson 1)** An internal parsed entity refers to —
a) a picture file  b) text a processor must parse  c) a printer
**Answer: b) text a processor must parse** — parsed text is what an internal parsed entity stands for.

**4. (Sub lesson 2)** In the guide's answer, the author and copyright lines are assembled — (teacher guide — evidence)
a) by typing them in full at every place  b) from the entities, by the parser  c) by the reader
**Answer: b) from the entities, by the parser** — defined once, assembled from the entities at processing.
