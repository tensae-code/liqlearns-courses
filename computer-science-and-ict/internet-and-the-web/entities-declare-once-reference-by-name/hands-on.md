# Hands-on — Entities — declare once, reference by name

The lesson with your hands, not only your eyes.

## Declare and use
On paper, declare one entity for a long line you often write — a school name, an address. Then write a short document using its reference three times. Count the writing you saved.

## Expansion watch
Write a document with two entity references. Beneath it, write out by hand exactly what the parser's expanded output will say. Swap with a partner and check each other's expansions.
