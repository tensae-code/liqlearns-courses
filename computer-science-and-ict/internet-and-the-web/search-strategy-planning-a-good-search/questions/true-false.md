# Search Strategy — Planning a Good Search — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a search strategy?" is: Planning a search before searching — the question, the keywords and how results will be judged**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is stated first in a planned search?" is: With exact phrases and added, more specific words**
**Answer: False** — The exact question — what do I need to know

**3. (Sub lesson 1) True or false: the answer to "What are keywords?" is: The few words a page answering the question would surely contain**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What do too-wide keywords cause?" is: Opened, judged by source and date, and the search refined if they miss**
**Answer: False** — A flood of useless pages

**5. (Sub lesson 1) True or false: the answer to "How is a search narrowed?" is: With exact phrases and added, more specific words**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Where might a planner search besides a search engine?" is: Where each fact came from, for citation**
**Answer: False** — Directly on a known trusted site

**7. (Sub lesson 2) True or false: the answer to "How are results worked?" is: Opened, judged by source and date, and the search refined if they miss**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does refine mean in searching?" is: Planning a search before searching — the question, the keywords and how results will be judged**
**Answer: False** — Changing the keywords and searching again

**9. (Sub lesson 2) True or false: the answer to "What is recorded as the search goes on?" is: Where each fact came from, for citation**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What does strategy turn citation into?" is: The few words a page answering the question would surely contain**
**Answer: False** — A habit, not only a rule
