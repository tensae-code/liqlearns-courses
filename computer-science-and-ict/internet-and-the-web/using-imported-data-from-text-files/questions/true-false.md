# Using Imported Data from Text Files — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does reading reverse?" is: Writing — open, read line by line, split each line into fields**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Splitting is the inverse of what?" is: The newline — or it rides into the last field and poisons comparisons**
**Answer: False** — The joining that stored the record

**3. (Sub lesson 1) True or false: the answer to "What must be trimmed from each line, and why?" is: The newline — or it rides into the last field and poisons comparisons**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "From what is the reader written?" is: Both writer and reader — or neither**
**Answer: False** — From the writer's format agreement — same separator, same field order

**5. (Sub lesson 1) True or false: the answer to "A format change must change what?" is: Both writer and reader — or neither**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Name three uses of imported records." is: Data made elsewhere, taken in and used as the program's own**
**Answer: False** — Listing on a page; searching; counting and totalling (also: answering a login)

**7. (Sub lesson 2) True or false: the answer to "What is 'imported data' in this unit?" is: Data made elsewhere, taken in and used as the program's own**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Data can be made by whom?" is: A round trip — three records in, the same three out, field for field**
**Answer: False** — An earlier visit, another program, or a person typing the file

**9. (Sub lesson 2) True or false: the answer to "What is the test of an import?" is: A round trip — three records in, the same three out, field for field**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "A login check is a use of what?" is: Writing — open, read line by line, split each line into fields**
**Answer: False** — The stored sign-up records, read back
