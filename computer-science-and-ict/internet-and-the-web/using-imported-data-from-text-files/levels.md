# Using Imported Data from Text Files — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Reading back — lines into records
Sub lesson 1 questions from the type files. Pass mark: Writing — open, read line by line, split each line into fields; The joining that stored the record; The newline — or it rides into the last field and poisons comparisons; From the writer's format agreement — same separator, same field order; Both writer and reader — or neither.

## Sub lesson 2 — Using the records — lists, searches, answers
Sub lesson 2 questions from the type files. Pass mark: Listing on a page; searching; counting and totalling (also: answering a login); Data made elsewhere, taken in and used as the program's own; An earlier visit, another program, or a person typing the file; A round trip — three records in, the same three out, field for field; The stored sign-up records, read back.
