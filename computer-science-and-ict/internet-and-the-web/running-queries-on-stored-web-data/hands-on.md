# Hands-on — Running Queries on Stored Web Data

The lesson with your hands and your feet, not only your eyes.

## Task one
('Run three queries', 'Over guestbook lines name|school|message, describe (steps or PHP) the queries: all entries from one named school; the count of entries per school; the entries in name order. State what each returns.')
