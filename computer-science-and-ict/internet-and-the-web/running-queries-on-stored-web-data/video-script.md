# Video script — Running Queries on Stored Web Data

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A **query** on stored web data **selects records by a condition**: all sign-ups from one school, all messages this week, the one record with this name. Over a text file, the program runs it as a **loop with a test**: read every record, **keep** those whose fields match the condition, discard the rest — the file's version of SQL's WHERE, built from the reading work of this unit. The result is a **new list**, not a changed store: querying reads; it does not write.
The kept records are then **worked**: **ordered** (by name, by date), **counted** (how many from each school — the file's GROUP BY, done by tallying), and **presented** as the answer on a page. Malaysia's queries are the unit's proof of purpose: the store was built line by line so that these questions could be answered in seconds — how many, which ones, whose. A store that cannot be queried was not designed; it was merely accumulated — and the difference is the field order and separator discipline this unit kept from its first line.
