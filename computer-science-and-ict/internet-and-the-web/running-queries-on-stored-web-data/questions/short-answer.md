# Running Queries on Stored Web Data — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does a query do?**
**Answer: Selects records by a condition**

**2. (Sub lesson 1) How is it run over a text file?**
**Answer: As a loop with a test — read every record, keep those matching, discard the rest**

**3. (Sub lesson 1) The file's WHERE is built from what earlier work?**
**Answer: The reading and splitting work of this unit**

**4. (Sub lesson 1) What is a query's result?**
**Answer: A new list — the store is not changed; querying reads, it does not write**

**5. (Sub lesson 1) Name a typical query over sign-up data.**
**Answer: All sign-ups from one school (also: all messages this week; the record with this name)**

**6. (Sub lesson 2) What three workings follow selection?**
**Answer: Ordering, counting, presenting**

**7. (Sub lesson 2) Counting per school is the file's version of what SQL clause?**
**Answer: GROUP BY — done by tallying**

**8. (Sub lesson 2) What questions was the store built to answer?**
**Answer: How many, which ones, whose**

**9. (Sub lesson 2) A store that cannot be queried was what?**
**Answer: Merely accumulated, not designed**

**10. (Sub lesson 2) What discipline made querying possible?**
**Answer: The field order and separator discipline kept from the first line**
