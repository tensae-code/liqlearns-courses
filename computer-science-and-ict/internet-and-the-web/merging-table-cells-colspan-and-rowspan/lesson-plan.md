# Lesson plan — Merging table cells — colspan and rowspan

**Course:** Computer Science and ICT · **Title:** Internet and the Web · **Lesson:** Merging table cells — colspan and rowspan
**Place in the curriculum:** Title — Internet and the Web in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 11 book, Unit 4 — Web Development. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** when a cell must cover several columns or rows, the colspan and rowspan attributes merge it across them.
**This lesson's own level:** it stands on the tables lesson — merging is the table's next move, learned on a plain table first.

## If the learner is stuck
- Cell spans the wrong way → colspan goes across columns; rowspan goes down rows. Say the direction aloud before choosing.
- Header looks crowded → the corner header cell is deliberately empty in the worked example; an empty corner is correct, not a gap.
