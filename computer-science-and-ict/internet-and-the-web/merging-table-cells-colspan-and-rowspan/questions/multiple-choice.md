# Merging table cells — colspan and rowspan — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) A cell covers several columns with the —**
a) colspan attribute  b) rowspan attribute  c) border attribute  d) header tag
**Answer: a) colspan attribute** — col-span = across columns.

**2. (Sub lesson 1) A cell covers several rows with the —**
a) rowspan attribute  b) colspan attribute  c) data tag  d) target attribute
**Answer: a) rowspan attribute** — row-span = down rows.

**3. (Sub lesson 1) The span attribute's value says —**
a) how many columns or rows the cell covers  b) the cell's colour  c) the table's name  d) the border's width
**Answer: a) how many columns or rows the cell covers** — the value is the count covered.

**4. (Sub lesson 2) In the worked example, the Cases header cell spans —**
a) the two columns beneath it: Total and New  b) all rows of the table  c) no columns  d) the corner cell
**Answer: a) the two columns beneath it: Total and New** — Cases stands over Total and New.

**5. (Sub lesson 2) The Deaths header cell —**
a) also spans Total and New  b) spans the corner  c) is missing  d) holds the figures
**Answer: a) also spans Total and New** — Cases and Deaths are built the same way.

**6. (Sub lesson 2) The corner header cell in the worked example is —**
a) left empty  b) filled with Cases  c) filled with a total  d) removed from the table
**Answer: a) left empty** — deliberately empty.
