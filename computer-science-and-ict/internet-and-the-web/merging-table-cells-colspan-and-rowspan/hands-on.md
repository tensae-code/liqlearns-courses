# Hands-on — Merging table cells — colspan and rowspan

The lesson with your hands, not only your eyes. You need a computer with a text editor and a browser for the doing parts.

## Build the two-level header
Build the book's example: Cases and Deaths each spanning Total and New, corner header empty. Fill in three rows of figures of your own.

## Rowspan by hand
Make a table where one cell runs down three rows with rowspan, and write beside it what the value counts.
