# Lesson plan — Viewing XML — browser, text editor and XML Notepad

**Course:** Computer Science and ICT · **Title:** Internet and the Web · **Lesson:** Viewing XML — browser, text editor and XML Notepad
**Place in the curriculum:** Title — Internet and the Web in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 12 book, Unit 4 — Web Authoring. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** an XML file can be edited in any text editor, viewed in any browser with its − / + folding signs, or opened in XML Notepad's Tree View — and XML by itself does nothing until a program handles it.
**This lesson's own level:** it stands on the parts lessons — the learner can read a document's parts; this doing lesson opens a real file three ways and works it.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Writing and opening a first file (doing)** — write in any text editor, save as .xml, and open it — in a browser, a viewing website, or a dedicated application
2. **The browser view and XML Notepad — and the warning** — browsers show colour-coded elements with + / − folding signs and View Source; XML Notepad shows Tree View and XSL Output; XML by itself does nothing

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Parts of an XML document — declaration and DTD; XML attributes and comments. Recommended, never forced.

## What the learner can do when it ends
1. Open and edit an XML file in a text editor.
2. View a file in a browser, using − / + to collapse and expand, and View Source.
3. Say what XML Notepad's two views show, and why XML alone does nothing.

## What you need
A computer with a text editor and at least one web browser; XML Notepad if available.

## If the learner is stuck
- Saves without .xml → the browser may not treat it as XML; the ending is part of the method.
- Expects the file to display itself styled → XML by itself does nothing; a program must send, receive, store or display it.
