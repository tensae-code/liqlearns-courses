# Video script — Viewing XML — browser, text editor and XML Notepad

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Write it. Any text editor will do. Notepad. WordPad.
Type the document. A note: sender, receiver, message.
Save it. The name ends .xml. That ending matters.
Open it in a browser. See the colours? See the minus sign?
Click the minus. The element folds away. Click the plus. It opens again.
Now open the same file in a second browser. Compare.
Same file. Same data. A different view.
Open XML Notepad. Tree View on one side. XSL Output on the other.
Remember: XML alone does nothing.
It is information wrapped in tags — until a program sends it, stores it, or shows it.
