# Viewing XML — browser, text editor and XML Notepad

## Do it first

Do it now, in this order: (1) open any text editor — Notepad or WordPad will do; (2) type a small XML document of your own — a note, with a sender and a receiver; (3) save it with an **.xml** ending; (4) open it in a browser; (5) open the same file in a second browser and compare what you see. That write–save–open method is the working method for this whole run of lessons (teacher guide — evidence). This lesson names every way of looking at the file you just opened.

## Sub lesson 1 — Writing and opening a first file (doing)

Work in this order — the order matters:

1. **Write** the document in **any text editor** (the guide names Notepad and WordPad — teacher guide — evidence).
2. **Save** it with an **.xml** ending.
3. **Open** it. Your choices: **any web browser**; a **website that views, edits or converts** XML; or a **dedicated application** such as **Oxygen** or **XML Notepad**.

Editing lives in the text editor; viewing can live anywhere on that list. The file is the same file in every place — only the view changes.

## Sub lesson 2 — The browser view and XML Notepad — and the warning

In most **browsers**, an XML file shows as **colour-coded elements**, with **+ / − signs to expand or collapse** the structure — click **−** and a branch folds away; click **+** and it opens again. Watch the GIF fold and unfold an element. **View Source** shows the code itself.

**XML Notepad** shows a **Tree View** and an **XSL Output** view — XSL is the **style sheet language for XML, as CSS is for HTML**.

The warning that runs through all of it: **XML by itself does nothing.** It is information wrapped in tags, and **a program must be written to send, receive, store or display it**.

## Say it to your companion

Tell your companion the three places you opened your file, one thing each showed you that the others did not, and why the file alone does nothing.

## Do It Yourself

1. Write, save and open your own note document as .xml in two browsers; write down one difference you saw.
2. Collapse one element with its − sign, then expand it with +.
3. Open View Source and find your declaration line.
