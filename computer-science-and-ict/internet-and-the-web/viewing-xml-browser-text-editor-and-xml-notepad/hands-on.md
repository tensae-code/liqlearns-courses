# Hands-on — Viewing XML — browser, text editor and XML Notepad

The lesson with your hands, not only your eyes.

## The two-browser check
Follow the guide's method on a real computer: write in a text editor, save as .xml, open in two browsers, then in XML Notepad if there is one. Tick off: colour-coding seen? − / + signs used? Tree View found?

## Fold and unfold
In a browser, collapse a whole branch of a document, then expand it level by level. Note which sign does which, in your own words.
