# Viewing XML — browser, text editor and XML Notepad — fill in the blank

Fill each blank with the right word or code.

**1. (Sub lesson 1)** To see the code itself in a browser, use View ___.
**Answer: Source** — View Source shows the code.

**2. (Sub lesson 2)** The sign that expands a folded element is ___.
**Answer: +** — plus expands; minus collapses.

**3. (Sub lesson 2)** A dedicated XML application named alongside Oxygen is XML ___.
**Answer: Notepad** — Oxygen and XML Notepad are the named applications.
