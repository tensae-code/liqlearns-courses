# Viewing XML — browser, text editor and XML Notepad — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A first XML file is written in —
a) a spreadsheet only  b) any text editor  c) a photo editor
**Answer: b) any text editor** — any text editor — Notepad or WordPad are named.

**2. (Sub lesson 1)** The file must be saved with the ending —
a) .html  b) .xml  c) .jpg
**Answer: b) .xml** — .xml is the ending the method requires.

**3. (Sub lesson 2)** In a browser, the − sign on an element —
a) deletes it  b) collapses it — folds its structure away  c) prints it
**Answer: b) collapses it — folds its structure away** — − collapses; + expands.

**4. (Sub lesson 2)** XML Notepad's two views are —
a) Tree View and XSL Output  b) Photo View and Print View  c) Code View and Games View
**Answer: a) Tree View and XSL Output** — Tree View and XSL Output are the two named views.
