# Viewing XML — browser, text editor and XML Notepad — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** The guide's method opens the file in at least two browsers and compares. (teacher guide — evidence)
**Answer: True** — write, save as .xml, open in two browsers, compare — then XML Notepad.

**2. (Sub lesson 2)** XML by itself does nothing.
**Answer: True** — a program must send, receive, store or display it.

**3. (Sub lesson 2)** XSL is the style sheet language for HTML.
**Answer: False** — XSL is for XML, as CSS is for HTML.
