# XML — marking up what data is — fill in the blank

Fill each blank with the right word or code.

**1. (Sub lesson 1)** XML stands for eXtensible ___ Language.
**Answer: Markup** — eXtensible Markup Language.

**2. (Sub lesson 2)** XML tags are written inside ___ brackets.
**Answer: angle** — tags sit in < and >.

**3. (Sub lesson 3)** HTML is about presentation; XML is about ___. (teacher guide — evidence)
**Answer: structure** — the guide keys the two as complements: presentation against structure.
