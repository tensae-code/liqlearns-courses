# XML — marking up what data is — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A presentational language like HTML says what the data is.
**Answer: False** — presentational languages are powerful for display but say nothing about what the data is.

**2. (Sub lesson 2)** Data held in XML is easier to organise and search.
**Answer: True** — custom tags name the data exactly, so organising and searching are easier.

**3. (Sub lesson 3)** In a regions-and-cities structure, the region tags must come from HTML's standard set. (teacher guide — evidence)
**Answer: False** — the tags are invented — country, region, city — which HTML's standard set does not offer.
