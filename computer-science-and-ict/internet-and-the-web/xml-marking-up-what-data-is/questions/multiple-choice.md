# XML — marking up what data is — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** XML describes mainly —
a) how a page looks  b) what data is and how it is structured  c) which colours a page uses
**Answer: b) what data is and how it is structured** — XML is about meaning and structure, for storage and exchange.

**2. (Sub lesson 1)** XML does NOT change —
a) how documents are filed  b) how a page looks  c) how documents are stored
**Answer: b) how a page looks** — looks belong to presentational languages; XML changes reading, filing and storing.

**3. (Sub lesson 2)** How do XML tags differ from HTML tags?
a) XML tags are predefined for everyone  b) XML tags are defined by the document's author to fit the data  c) XML has no tags
**Answer: b) XML tags are defined by the document's author to fit the data** — custom tags that meet the document's exact needs are XML's point.

**4. (Sub lesson 3)** XML was developed in the 1990s because HTML — (teacher guide — evidence)
a) was too colourful  b) does not allow new elements to be defined and is not extensible  c) had no browsers
**Answer: b) does not allow new elements to be defined and is not extensible** — that limit is the guide's stated reason for XML.
