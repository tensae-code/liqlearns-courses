# Lesson plan — XML — marking up what data is

**Course:** Computer Science and ICT · **Title:** Internet and the Web · **Lesson:** XML — marking up what data is
**Place in the curriculum:** Title — Internet and the Web in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 12 book, Unit 4 — Web Authoring. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** XML is a markup language whose tags describe what data is and how it is structured — not how it looks.
**This lesson's own level:** it stands on the Grade 11 HTML lessons — the learner already knows tags in angle brackets and that HTML has predefined tags; XML is the new step, where the tags are your own.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Structure, not looks** — XML describes what data is and how it is structured, for storage and exchange
2. **Your own tags** — unlike HTML's predefined tags, XML lets you define custom tags that fit the document
3. **Why XML exists — and Ethiopia structured in tags (teacher guide — evidence)** — XML was developed in the 1990s because HTML is not extensible; regions and cities of Ethiopia structured with invented tags

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson

## What the learner can do when it ends
1. Say what XML stands for and what it is for.
2. Say how XML tags differ from HTML tags.
3. Structure Ethiopian regions and cities with invented tags (teacher guide — evidence).

## If the learner is stuck
- Thinks XML changes how a page looks → XML does not change looks; it changes how documents are read, filed and stored.
- Thinks the tags are fixed → in XML you define the tags your document needs.
