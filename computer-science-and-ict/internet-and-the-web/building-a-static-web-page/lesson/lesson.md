# Building a Static Web Page

## Do it first

Grade 11 in Papua New Guinea builds real pages — static ones first. This lesson draws the line between static and dynamic, then builds a static page the guide's way.

## Sub lesson 1 — Static and dynamic pages

A **static page** shows **the same content to every visitor**. A **dynamic page** can **change its content — for example per user or from data**. Static pages are written in **HTML, styled with CSS**, need **no database**, and are viewed in a web browser.

[Picture — Static and dynamic pages]

## Sub lesson 2 — Creating a static page with a framework

A **framework** gives the builder **ready-made structure and styles, to build faster**. A simple information page — like a school information page — is a natural static page. To update a static page you **edit its files directly**, and before publishing you **test the page in a browser**.
