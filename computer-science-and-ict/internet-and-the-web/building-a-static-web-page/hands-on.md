# Hands-on — Building a Static Web Page

The lesson with your hands and your feet, not only your eyes.

## Static by hand
Write a one-page static site on paper as HTML structure: heading, paragraph, list, one link. Label which parts HTML carries and which CSS would style.

## Static or dynamic?
Your companion names five pages (school notice, bank balance, weather by town, club page, shop price list). You sort each: static or dynamic, and why.
