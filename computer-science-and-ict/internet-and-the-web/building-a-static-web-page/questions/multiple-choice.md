# Building a Static Web Page — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does a static web page show?**
a) The same content to every visitor  b) Change its content — for example per user or from data  c) HTML (styled with CSS)  d) Ready-made structure and styles, to build faster
**Answer: a) The same content to every visitor**

**2. (Sub lesson 1) What can a dynamic web page do?**
a) HTML (styled with CSS)  b) Change its content — for example per user or from data  c) Ready-made structure and styles, to build faster  d) No
**Answer: b) Change its content — for example per user or from data**

**3. (Sub lesson 1) Static pages are written in what language?**
a) Ready-made structure and styles, to build faster  b) No  c) HTML (styled with CSS)  d) A static page
**Answer: c) HTML (styled with CSS)**

**4. (Sub lesson 1) What does a framework give the page builder?**
a) No  b) A static page  c) By editing its files directly  d) Ready-made structure and styles, to build faster
**Answer: d) Ready-made structure and styles, to build faster**

**5. (Sub lesson 1) Does a static page need a database?**
a) No  b) A static page  c) By editing its files directly  d) Styles how the page looks
**Answer: a) No**

**6. (Sub lesson 2) Which kind of page suits a simple school information page?**
a) By editing its files directly  b) A static page  c) Styles how the page looks  d) A web browser
**Answer: b) A static page**

**7. (Sub lesson 2) How is a static page updated?**
a) Styles how the page looks  b) A web browser  c) By editing its files directly  d) Test the page in a browser
**Answer: c) By editing its files directly**

**8. (Sub lesson 2) What does CSS do on a web page?**
a) A web browser  b) Test the page in a browser  c) The same content to every visitor  d) Styles how the page looks
**Answer: d) Styles how the page looks**

**9. (Sub lesson 2) A web page is viewed in what?**
a) A web browser  b) Test the page in a browser  c) The same content to every visitor  d) Change its content — for example per user or from data
**Answer: a) A web browser**

**10. (Sub lesson 2) What should you do before publishing a page?**
a) The same content to every visitor  b) Test the page in a browser  c) Change its content — for example per user or from data  d) HTML (styled with CSS)
**Answer: b) Test the page in a browser**
