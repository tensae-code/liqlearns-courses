# Building a Static Web Page — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does a static web page show?" is: The same content to every visitor**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What can a dynamic web page do?" is: Ready-made structure and styles, to build faster**
**Answer: False** — Change its content — for example per user or from data

**3. (Sub lesson 1) True or false: the answer to "Static pages are written in what language?" is: HTML (styled with CSS)**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does a framework give the page builder?" is: A static page**
**Answer: False** — Ready-made structure and styles, to build faster

**5. (Sub lesson 1) True or false: the answer to "Does a static page need a database?" is: No**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Which kind of page suits a simple school information page?" is: Styles how the page looks**
**Answer: False** — A static page

**7. (Sub lesson 2) True or false: the answer to "How is a static page updated?" is: By editing its files directly**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does CSS do on a web page?" is: Test the page in a browser**
**Answer: False** — Styles how the page looks

**9. (Sub lesson 2) True or false: the answer to "A web page is viewed in what?" is: A web browser**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What should you do before publishing a page?" is: Change its content — for example per user or from data**
**Answer: False** — Test the page in a browser
