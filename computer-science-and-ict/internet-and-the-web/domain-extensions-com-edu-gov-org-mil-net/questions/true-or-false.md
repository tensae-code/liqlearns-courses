# Domain extensions — .com, .edu, .gov, .org, .mil, .net — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** The top-level domain is printed as three letters in these examples.
**Answer: True** — three letters is the printed form here.

**2. (Sub lesson 2)** .gov and .com name the same kind of owner.
**Answer: False** — .gov is government; .com is commercial.

**3. (Sub lesson 1)** The extension tells the kind of owner before any page is opened.
**Answer: True** — that announcement is the extension's use.
