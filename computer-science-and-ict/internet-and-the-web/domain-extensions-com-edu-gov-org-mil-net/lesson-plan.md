# Lesson plan — Domain extensions — .com, .edu, .gov, .org, .mil, .net

**Course:** Computer Science and ICT · **Title:** Internet and the Web · **Lesson:** Domain extensions — .com, .edu, .gov, .org, .mil, .net
**Place in the curriculum:** Title — Internet and the Web in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 12 book, Unit 4 — Web Authoring. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** the extension at the end of an address is its top-level domain: .com commercial, .edu educational, .gov government, .org non-profit, .mil military, .net network.
**This lesson's own level:** it stands on the hosting-and-domain-names lesson and the earlier web-address lesson — the learner can split an address into parts; this lesson reads the last part as a top-level domain and learns the six kinds.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. ## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The top-level domain — the ending that tells the owner** — the extension at the end of an address is its top-level domain, printed as three letters in the book's examples
2. **The six extensions** — .com for commercial sites, .edu for educational institutions, .gov for government, .org for non-profit organisations, .mil for military, .net for network

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Hosting and domain names — putting a site on a server; The parts of a web address. Recommended, never forced.

## What the learner can do when it ends
1. Say what a top-level domain is and where it sits.
2. Give all six extensions with their kinds of owner.
3. Read an unseen address's ending and name its kind of site.

## What you need
Paper and a pencil.

## If the learner is stuck
- Reads the extension as decoration → the extension is information: it tells the kind of owner.
- Mixes .org and .com → .com is commercial; .org is non-profit organisations.
