# Designing vs building a website — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Design and development are the same job.**
**Answer: False** — design plans; development builds.

**2. (Sub lesson 2) With WYSIWYG software there is no code in the finished page.**
**Answer: False** — the software writes the code for you.

**3. (Sub lesson 2) A text editor is harder to build with than WYSIWYG software.**
**Answer: True** — the book says so — and chooses it for that reason.
