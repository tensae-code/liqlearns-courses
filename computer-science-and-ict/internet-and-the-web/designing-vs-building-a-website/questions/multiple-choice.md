# Designing vs building a website — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Website design defines a site's —**
a) layout and overall look  b) server address  c) file password  d) visitor list
**Answer: a) layout and overall look** — design is the plan of look and layout.

**2. (Sub lesson 1) Web development is —**
a) the actual building of the site  b) the sketching of the site  c) the advertising of the site  d) the naming of the site
**Answer: a) the actual building of the site** — development builds what design planned.

**3. (Sub lesson 2) WYSIWYG stands for —**
a) what you see is what you get  b) write your site in your group  c) web pages you save in graphics  d) what you save is your game
**Answer: a) what you see is what you get** — the page you arrange is the page you get.

**4. (Sub lesson 2) The book's WYSIWYG example is —**
a) Adobe Dreamweaver  b) Notepad  c) a browser  d) a web server
**Answer: a) Adobe Dreamweaver** — Dreamweaver is the named WYSIWYG software.

**5. (Sub lesson 2) This unit teaches with a text editor because it is —**
a) faster  b) better for truly mastering the language  c) the only tool that exists  d) free of code
**Answer: b) better for truly mastering the language** — harder, but it teaches the language itself.

**6. (Sub lesson 2) The book's text-editor example is —**
a) Notepad  b) Dreamweaver  c) Chrome  d) Paint
**Answer: a) Notepad** — Notepad is the named simple text editor.
