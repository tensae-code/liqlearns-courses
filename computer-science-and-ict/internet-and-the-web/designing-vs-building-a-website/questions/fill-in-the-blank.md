# Designing vs building a website — fill in the blank

Fill each blank with the right word or code.

**1. (Sub lesson 1) ___ defines the layout and overall look; development builds it.**
**Answer: Design** — design first, building second.

**2. (Sub lesson 2) WYSIWYG means what you ___ is what you get.**
**Answer: see** — see = get.

**3. (Sub lesson 2) The unit teaches HTML in a simple ___ editor.**
**Answer: text** — a text editor such as Notepad.
