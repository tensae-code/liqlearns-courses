# Hands-on — Designing vs building a website

The lesson with your hands, not only your eyes. You need a computer with a text editor and a browser for the doing parts.

## Sort the jobs
Write eight website jobs on cards — four design, four building. Shuffle, sort, and say your rule for each sort.

## Look at both tools
If a computer is at hand, open a text editor and any web page's source. You are looking at what the text-editor way works with directly.
