# Designing vs building a website

## Do it first

Six jobs: choosing the colours; typing the code; planning the menu; saving the page file; sketching the layout; testing the page in a browser. Which are designing, and which are building? This lesson draws that line — then shows the two kinds of tool the building is done with.

## Sub lesson 1 — Design is the plan, development is the building

**Website design** defines the **layout and overall look** of a site. **Web development** is the **actual building** of it. The design says what the page should be; the development makes the page that exists.

## Sub lesson 2 — The two tool kinds — and why this unit uses a text editor

Sites can be built two ways:

- **WYSIWYG software** — "what you see is what you get", such as **Adobe Dreamweaver**: you arrange the page as it will look, and the software writes the code.
- **A simple text editor**, such as **Notepad**: you type the code yourself.

The text editor is harder, but better for **truly mastering the language** — which is why this whole unit teaches with a text editor.
