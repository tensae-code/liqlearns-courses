# Lesson plan — Designing vs building a website

**Course:** Computer Science and ICT · **Title:** Internet and the Web · **Lesson:** Designing vs building a website
**Place in the curriculum:** Title — Internet and the Web in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 11 book, Unit 4 — Web Development. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** design decides a site's layout and look; development builds it — with WYSIWYG software or with a text editor, and this unit builds with a text editor.
**This lesson's own level:** it stands on the design-guidelines lesson — the plan exists before the building tools are chosen.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Design is the plan, development is the building** — the line between planning a site and building it
2. **The two tool kinds — and why this unit uses a text editor** — WYSIWYG software against a text editor, and the book's reason for choosing the editor

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Designing a website — audience, navigation, consistency, simplicity, accessibility. Recommended, never forced.

## What the learner can do when it ends
1. Tell designing from building.
2. Name the two kinds of building tool.
3. Say why this unit teaches with a text editor.

## What you need
Paper and a pencil.

## If the learner is stuck
- Thinks WYSIWYG means no code exists → the software writes the code for you; the code is still there.
- Thinks the text editor is the worse tool → it is harder, and that is exactly why it teaches the language.
