# Unit 4 in short — the internet — multiple choice

Pick the one right answer.

**1.** The internet's named services include —
a) WWW, email, Telnet and FTP  b) only games  c) printing and scanning  d) word processing
**Answer: a) WWW, email, Telnet and FTP**

**2.** The two parts of a URL are —
a) username and domain  b) protocol identifier and resource name  c) sender and subject  d) request and response
**Answer: b) protocol identifier and resource name**

**3.** The protocol of the request-and-response round trip is —
a) FTP  b) HTTP  c) SMTP only  d) NTP
**Answer: b) HTTP**

**4.** Browsing searches the internet by —
a) guessing addresses  b) keywords in a search engine  c) phone calls  d) printing results first
**Answer: b) keywords in a search engine**

**5.** An email address has the format —
a) domainname@username  b) username@domainname  c) name@subject  d) www.email.com
**Answer: b) username@domainname**
