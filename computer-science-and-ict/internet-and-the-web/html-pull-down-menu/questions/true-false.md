# HTML Pull-Down Menu — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Which element makes a pull-down menu?" is: The <select> element**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Which element makes each choice inside it?" is: Folded — only the current choice visible, with a small arrow beside it**
**Answer: False** — The <option> element

**3. (Sub lesson 1) True or false: the answer to "How does the browser show the menu at rest?" is: Folded — only the current choice visible, with a small arrow beside it**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What happens when it is clicked?" is: As the menu's name — its name attribute**
**Answer: False** — The full list opens; clicking a choice folds it again with that choice showing

**5. (Sub lesson 1) True or false: the answer to "As what is the choice sent when the form is submitted?" is: As the menu's name — its name attribute**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "When does a pull-down suit well?" is: Misspellings and wrong entries — the visitor can only pick what is offered**
**Answer: False** — A choice from a fixed list — states, months, class names

**7. (Sub lesson 2) True or false: the answer to "What does it prevent?" is: Misspellings and wrong entries — the visitor can only pick what is offered**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "When does it suit badly?" is: The answers — clean and comparable**
**Answer: False** — When the list is very long, or the answer might not be on the list

**9. (Sub lesson 2) True or false: the answer to "What arrives cleaner with a pull-down?" is: The answers — clean and comparable**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is Malaysia's teaching point?" is: The <select> element**
**Answer: False** — Match the control to the answer: fixed and short — pull-down; open or long — another control
