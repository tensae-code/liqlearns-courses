# HTML Pull-Down Menu — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Which element makes a pull-down menu?**
a) The <select> element  b) The <option> element  c) Folded — only the current choice visible, with a small arrow beside it  d) The full list opens; clicking a choice folds it again with that choice showing
**Answer: a) The <select> element**

**2. (Sub lesson 1) Which element makes each choice inside it?**
a) Folded — only the current choice visible, with a small arrow beside it  b) The <option> element  c) The full list opens; clicking a choice folds it again with that choice showing  d) As the menu's name — its name attribute
**Answer: b) The <option> element**

**3. (Sub lesson 1) How does the browser show the menu at rest?**
a) The full list opens; clicking a choice folds it again with that choice showing  b) As the menu's name — its name attribute  c) Folded — only the current choice visible, with a small arrow beside it  d) A choice from a fixed list — states, months, class names
**Answer: c) Folded — only the current choice visible, with a small arrow beside it**

**4. (Sub lesson 1) What happens when it is clicked?**
a) As the menu's name — its name attribute  b) A choice from a fixed list — states, months, class names  c) Misspellings and wrong entries — the visitor can only pick what is offered  d) The full list opens; clicking a choice folds it again with that choice showing
**Answer: d) The full list opens; clicking a choice folds it again with that choice showing**

**5. (Sub lesson 1) As what is the choice sent when the form is submitted?**
a) As the menu's name — its name attribute  b) A choice from a fixed list — states, months, class names  c) Misspellings and wrong entries — the visitor can only pick what is offered  d) When the list is very long, or the answer might not be on the list
**Answer: a) As the menu's name — its name attribute**

**6. (Sub lesson 2) When does a pull-down suit well?**
a) Misspellings and wrong entries — the visitor can only pick what is offered  b) A choice from a fixed list — states, months, class names  c) When the list is very long, or the answer might not be on the list  d) The answers — clean and comparable
**Answer: b) A choice from a fixed list — states, months, class names**

**7. (Sub lesson 2) What does it prevent?**
a) When the list is very long, or the answer might not be on the list  b) The answers — clean and comparable  c) Misspellings and wrong entries — the visitor can only pick what is offered  d) Match the control to the answer: fixed and short — pull-down; open or long — another control
**Answer: c) Misspellings and wrong entries — the visitor can only pick what is offered**

**8. (Sub lesson 2) When does it suit badly?**
a) The answers — clean and comparable  b) Match the control to the answer: fixed and short — pull-down; open or long — another control  c) The <select> element  d) When the list is very long, or the answer might not be on the list
**Answer: d) When the list is very long, or the answer might not be on the list**

**9. (Sub lesson 2) What arrives cleaner with a pull-down?**
a) The answers — clean and comparable  b) Match the control to the answer: fixed and short — pull-down; open or long — another control  c) The <select> element  d) The <option> element
**Answer: a) The answers — clean and comparable**

**10. (Sub lesson 2) What is Malaysia's teaching point?**
a) The <select> element  b) Match the control to the answer: fixed and short — pull-down; open or long — another control  c) The <option> element  d) Folded — only the current choice visible, with a small arrow beside it
**Answer: b) Match the control to the answer: fixed and short — pull-down; open or long — another control**
