# Hands-on — Creating a WordPress Site Password and Setup

The lesson with your hands and your feet, not only your eyes.

## Task one
**Do the book's steps** — Work through Steps 5–6 — package information, finish registration, create your password; Installing WordPress exactly as South Sudan's book orders it, on a real computer if one is available; otherwise write the steps in order and check them against the book's order.

## Task two
**Show it to someone** — Take Doing it — Steps 5–6 — package information, finish registration, create your password; Installing WordPress in practice and show a partner what it does: do it once slowly, naming each step, then let the partner do it while you only watch and correct.
