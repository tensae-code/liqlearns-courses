# Hands-on — PageRank — How Search Engines Rank Pages

The lesson with your hands and your feet, not only your eyes.

## Rank four pages by hand
Use the four pages from Do it first (A links to B and C; B links to C; C links to A; D links to C). Start every page at 1/4. Round 1: each page hands its score along its arrows, split evenly — work out each page's new total. Round 2: repeat from the new scores. Write the three rounds as a table. Which page leads? What happens to D, and why?

## Break it, then fix it
Add a fifth page E that links only to itself. Run one more round. Where does E's score go, and what does that tell you about pages nobody links to?
