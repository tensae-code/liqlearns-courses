# PageRank — How Search Engines Rank Pages — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) A link from an important page and a link from an unknown page count exactly the same.**
**Answer: False — Votes are weighted: a link from an important page passes on more importance.**

**2. (Sub lesson 2) A page that nobody links to keeps a high PageRank because it links out a lot.**
**Answer: False — It receives nothing, so its score fades round by round, however much it links out.**
