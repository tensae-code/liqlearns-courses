# Web Utilities — Plug-ins, Filters and File Transfer — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a plug-in?**
**Answer: A small program that adds a capability to the browser**

**2. (Sub lesson 1) Give a plug-in's job.**
**Answer: Playing a kind of video or showing a kind of document the browser cannot show alone**

**3. (Sub lesson 1) What does a filter do?**
**Answer: Screens what comes in — blocking pages, adverts or set-aside material**

**4. (Sub lesson 1) Whose settings can a filter carry?**
**Answer: A school's or a parent's**

**5. (Sub lesson 1) What are the browser's two directions of help?**
**Answer: More power in (plug-ins), more protection around (filters)**

**6. (Sub lesson 2) What is file transfer?**
**Answer: Moving whole files between computers over the network**

**7. (Sub lesson 2) What was FTP built for?**
**Answer: File transfer**

**8. (Sub lesson 2) What do uploading and downloading mean?**
**Answer: Putting a file up; bringing a file down**

**9. (Sub lesson 2) Do web pages use transfer?**
**Answer: Yes — pages themselves arrive by transfer**

**10. (Sub lesson 2) Name Fiji's web working kit.**
**Answer: The browser extended, the browser guarded, and the files carried**
