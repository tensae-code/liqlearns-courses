# Web Utilities — Plug-ins, Filters and File Transfer — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a plug-in?" is: A small program that adds a capability to the browser**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Give a plug-in's job." is: Screens what comes in — blocking pages, adverts or set-aside material**
**Answer: False** — Playing a kind of video or showing a kind of document the browser cannot show alone

**3. (Sub lesson 1) True or false: the answer to "What does a filter do?" is: Screens what comes in — blocking pages, adverts or set-aside material**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Whose settings can a filter carry?" is: More power in (plug-ins), more protection around (filters)**
**Answer: False** — A school's or a parent's

**5. (Sub lesson 1) True or false: the answer to "What are the browser's two directions of help?" is: More power in (plug-ins), more protection around (filters)**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is file transfer?" is: File transfer**
**Answer: False** — Moving whole files between computers over the network

**7. (Sub lesson 2) True or false: the answer to "What was FTP built for?" is: File transfer**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What do uploading and downloading mean?" is: Yes — pages themselves arrive by transfer**
**Answer: False** — Putting a file up; bringing a file down

**9. (Sub lesson 2) True or false: the answer to "Do web pages use transfer?" is: Yes — pages themselves arrive by transfer**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Name Fiji's web working kit." is: A small program that adds a capability to the browser**
**Answer: False** — The browser extended, the browser guarded, and the files carried
