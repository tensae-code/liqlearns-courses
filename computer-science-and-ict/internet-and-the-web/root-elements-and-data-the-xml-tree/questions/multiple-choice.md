# Root, elements and data — the XML tree — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The single element that encloses everything is the —
a) data  b) root element  c) end tag
**Answer: b) root element** — one root encloses the whole document.

**2. (Sub lesson 1)** An element runs from —
a) the declaration to the DOCTYPE  b) its start tag to its end tag  c) one file to another
**Answer: b) its start tag to its end tag** — start tag to end tag is the element.

**3. (Sub lesson 1)** The end tag's name must —
a) be shorter than the start tag's  b) exactly match the start tag's  c) be in capitals
**Answer: b) exactly match the start tag's** — exact matching is the rule.

**4. (Sub lesson 2)** XML becomes a finished document when combined with —
a) nothing — it is finished alone  b) other resources such as a style sheet  c) a printer only
**Answer: b) other resources such as a style sheet** — a style sheet is the named partner resource.
