# Root, elements and data — the XML tree — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A document can have two root elements side by side.
**Answer: False** — the root is single — it encloses everything.

**2. (Sub lesson 2)** The data is held between an element's tags.
**Answer: True** — data sits between start and end tags.

**3. (Sub lesson 2)** The XML tree is drawn with the root at the bottom.
**Answer: False** — it is an upside-down tree — root at the top.
