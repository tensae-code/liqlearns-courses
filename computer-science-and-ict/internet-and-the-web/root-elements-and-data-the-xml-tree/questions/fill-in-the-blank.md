# Root, elements and data — the XML tree — fill in the blank

Fill each blank with the right word or code.

**1. (Sub lesson 1)** The information the elements convey is called the ___ / information set.
**Answer: content** — content / information set is the name given.

**2. (Sub lesson 1)** An element is the basic ___ block of a document.
**Answer: building** — elements are the building blocks.

**3. (Sub lesson 2)** Root, sub-elements and data together form a ___.
**Answer: hierarchy** — the hierarchy is what the tree draws.
