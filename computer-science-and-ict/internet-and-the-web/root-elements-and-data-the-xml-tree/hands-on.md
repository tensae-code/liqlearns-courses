# Hands-on — Root, elements and data — the XML tree

The lesson with your hands, not only your eyes.

## Draw the tree
On a big sheet, draw the athletes document as a tree: root at the top, branches down to the names. Label root, element and data on the drawing.

## Build a tree from tags
Write a small document on paper, then draw its tree beside it. Check: one root? Every element on the tree? Data at the leaves?
