# Video script — Root, elements and data — the XML tree

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A document is a tree, upside down.
At the top: one root. people.
Inside it: person. Inside that: name.
Inside name: first and last. Inside those: the data.
An element is start tag, content, end tag — one building block.
The tags must match, exactly.
XML alone is not finished.
Add a style sheet, and it becomes a document you can present.
