# Building Pages with Expression Web — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is Expression Web?" is: A visual web editor — pages made by design and corrected in code**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What are its two views?" is: Build in design view for speed; drop into code view to fix what visual tools placed clumsily**
**Answer: False** — Design view — the page as the visitor sees it — and code view, the HTML underneath

**3. (Sub lesson 1) True or false: the answer to "What is each view for?" is: Build in design view for speed; drop into code view to fix what visual tools placed clumsily**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Name one fault code view fixes?" is: A pupil who only designs has a page they cannot repair**
**Answer: False** — A wrong heading level, a mistyped link address, a table used where a list belongs (any one)

**5. (Sub lesson 1) True or false: the answer to "Why does the book pair the tool with raw HTML teaching?" is: A pupil who only designs has a page they cannot repair**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "In what order are project pages built?" is: The shared pattern — the same structure and dress across pages**
**Answer: False** — Structure first — headings, lists, navigation — then the dress of styles

**7. (Sub lesson 2) True or false: the answer to "What makes the pages visibly one site?" is: The shared pattern — the same structure and dress across pages**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Where is each finished page checked?" is: The two-view discipline — make it visually, verify it in code and in the browser**
**Answer: False** — Previewed in a real browser — the editor's view is a promise, the browser is the fact

**9. (Sub lesson 2) True or false: the answer to "What outlives the tool itself?" is: The two-view discipline — make it visually, verify it in code and in the browser**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Which site's pages does the project build in Expression Web?" is: A visual web editor — pages made by design and corrected in code**
**Answer: False** — The Illustrated Dictionary of Computer Terms site
