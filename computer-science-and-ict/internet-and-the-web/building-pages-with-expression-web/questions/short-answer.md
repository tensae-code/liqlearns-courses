# Building Pages with Expression Web — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is Expression Web?**
**Answer: A visual web editor — pages made by design and corrected in code**

**2. (Sub lesson 1) What are its two views?**
**Answer: Design view — the page as the visitor sees it — and code view, the HTML underneath**

**3. (Sub lesson 1) What is each view for?**
**Answer: Build in design view for speed; drop into code view to fix what visual tools placed clumsily**

**4. (Sub lesson 1) Name one fault code view fixes**
**Answer: A wrong heading level, a mistyped link address, a table used where a list belongs (any one)**

**5. (Sub lesson 1) Why does the book pair the tool with raw HTML teaching?**
**Answer: A pupil who only designs has a page they cannot repair**

**6. (Sub lesson 2) In what order are project pages built?**
**Answer: Structure first — headings, lists, navigation — then the dress of styles**

**7. (Sub lesson 2) What makes the pages visibly one site?**
**Answer: The shared pattern — the same structure and dress across pages**

**8. (Sub lesson 2) Where is each finished page checked?**
**Answer: Previewed in a real browser — the editor's view is a promise, the browser is the fact**

**9. (Sub lesson 2) What outlives the tool itself?**
**Answer: The two-view discipline — make it visually, verify it in code and in the browser**

**10. (Sub lesson 2) Which site's pages does the project build in Expression Web?**
**Answer: The Illustrated Dictionary of Computer Terms site**
