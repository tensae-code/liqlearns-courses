# Video script — Building Pages with Expression Web

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Expression Web shows a page **two ways at once**: the **design view**, where the page looks as the visitor will see it and text, headings, pictures and links are placed by hand and menu; and the **code view**, the HTML underneath, updating as you design and editable directly. The craft is moving between them: build in design view for speed, drop into code view to fix what the visual tools placed clumsily — a heading level wrong, a link's address mistyped, a table used where a list belongs. A pupil who only designs has a page they cannot repair; the book pairs the tool with the term's HTML teaching for exactly this reason.
The project pages are built in the term's order: the **structure** first — the page's headings, its lists of terms, its navigation links to the site's other pages — using the site's shared pattern so every page belongs visibly to one site; then the **dress** — the styles that give the dictionary its face. Each finished page is **previewed in a real browser**, because the editor's design view is a promise and the browser is the fact. Egypt's choice of a visual editor for the build, inside a course that also teaches raw HTML and PHP, is itself the lesson: tools change (Expression Web itself is retired), the two-view discipline — make it visually, verify it in code and in the browser — outlives every tool.
