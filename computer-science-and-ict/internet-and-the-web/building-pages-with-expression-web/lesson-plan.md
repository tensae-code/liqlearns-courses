# Lesson plan — Building Pages with Expression Web

**Course:** Computer Science and ICT · **Title:** Internet and the Web · **Lesson:** Building Pages with Expression Web
**Place in the curriculum:** ICT expansion — Egypt (2026-11-14) — in the title Internet and the Web on the ICT course ladder (TITLES.md). Built new from Egypt's student books (Egypt Ministry of Education and Technical Education / Ministry of Education), because no existing lesson in the course covers this thing as its own lesson.
**The one thing this lesson teaches:** A visual web editor — pages made by design and corrected in code.
**This lesson's own level:** It stands on the earlier lessons of its title and on the book's own order — it follows the book's lessons in sequence, so its neighbours in the book are its natural companions. It stands alone for a learner landing on it directly.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The visual editor — design view and code view** — Expression Web shows a page **two ways at once**: the **design view**, where the page looks as the visitor will see it and text, headings, pictures and links are placed by hand and menu; and the **code view**, the HTML underneath, updating as you design and editable directly. The craft is moving between them: build in design view for speed, drop into code view to fix what the visual tools placed clumsily — a heading level wrong, a link's address mistyped, a table used where a list belongs. A pupil who only designs has a page they cannot repair; the book pairs the tool with the term's HTML teaching for exactly this reason.
2. **Building the project pages — structure first, then dress** — The project pages are built in the term's order: the **structure** first — the page's headings, its lists of terms, its navigation links to the site's other pages — using the site's shared pattern so every page belongs visibly to one site; then the **dress** — the styles that give the dictionary its face. Each finished page is **previewed in a real browser**, because the editor's design view is a promise and the browser is the fact. Egypt's choice of a visual editor for the build, inside a course that also teaches raw HTML and PHP, is itself the lesson: tools change (Expression Web itself is retired), the two-view discipline — make it visually, verify it in code and in the browser — outlives every tool.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
