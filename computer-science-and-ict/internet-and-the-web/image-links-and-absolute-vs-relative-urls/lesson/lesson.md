# Image links — and absolute vs relative URLs

## Do it first

A link's clickable part does not have to be words. Put a picture in the words' place and the picture itself becomes the button. Try it with the three Ethiopian sites: their logos as the links, all the same width — the guide's worked set (teacher guide, printed pp. 66–71). This lesson then names the two ways the addresses in such links can be written.

## Sub lesson 1 — An image as the clickable part

An **image can be the clickable part of a link** by **placing the image element between the anchor's start and end tags**. Everything else about the link stays the same: the reference attribute still carries the destination. In the guide's worked set the three Ethiopian links are rebuilt exactly this way — **clickable logo images of equal width** (teacher guide — evidence). ## Sub lesson 2 — Absolute and relative URLs

The book distinguishes two kinds of address:

- An **absolute URL** gives **every part of the address — protocol, host name and path**.
- A **relative URL** gives a **path relative to the current page's location** — the form used **when the image and the page are in the same folder**.
