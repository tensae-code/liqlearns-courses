# Image links — and absolute vs relative URLs — fill in the blank

Fill each blank with the right word or code.

**1. (Sub lesson 1) The clickable part of a link can be text or an ___.**
**Answer: image** — an image can carry the click.

**2. (Sub lesson 2) An ___ URL gives every part of the address.**
**Answer: absolute** — absolute = all parts.

**3. (Sub lesson 2) A ___ URL is counted from the current page's location.**
**Answer: relative** — relative = from here.
