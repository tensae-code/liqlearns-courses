# Image links — and absolute vs relative URLs — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) An image link needs no anchor element.**
**Answer: False** — the anchor makes the link; the image is its clickable part.

**2. (Sub lesson 2) A relative URL includes the protocol and host name.**
**Answer: False** — those belong to the absolute form.

**3. (Sub lesson 2) Protocol, host name and path are the parts of an absolute URL.**
**Answer: True** — the book's three parts.
