# Image links — and absolute vs relative URLs — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) An image becomes a link's clickable part by —**
a) placing the image element between the anchor's start and end tags  b) putting the anchor inside the image file  c) naming the image after the site  d) printing the image
**Answer: a) placing the image element between the anchor's start and end tags** — image inside anchor = clickable image.

**2. (Sub lesson 1) In an image link, the destination is still carried by —**
a) the anchor's reference attribute  b) the image's colours  c) the file size  d) the heading
**Answer: a) the anchor's reference attribute** — the anchor still holds the address.

**3. (Sub lesson 1) The guide's worked set rebuilds the Ethiopian links as — (teacher guide — evidence)**
a) clickable logo images of equal width  b) text links in three colours  c) one shared link  d) printed logos
**Answer: a) clickable logo images of equal width** — logos, equal width.

**4. (Sub lesson 2) An absolute URL gives —**
a) every part of the address: protocol, host name and path  b) only the file name  c) only the protocol  d) nothing
**Answer: a) every part of the address: protocol, host name and path** — absolute = complete.

**5. (Sub lesson 2) A relative URL gives —**
a) a path relative to the current page's location  b) every part of the address  c) the server's password  d) a printed address
**Answer: a) a path relative to the current page's location** — relative = counted from the page.

**6. (Sub lesson 2) The relative form is the one used when —**
a) the image and the page are in the same folder  b) the site is abroad  c) the page has no folder  d) always, for every link
**Answer: a) the image and the page are in the same folder** — same folder is the book's case.
