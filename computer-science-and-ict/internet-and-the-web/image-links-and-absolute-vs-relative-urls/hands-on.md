# Hands-on — Image links — and absolute vs relative URLs

The lesson with your hands, not only your eyes. You need a computer with a text editor and a browser for the doing parts.

## Logos as buttons
Rebuild the three Ethiopian-site links as clickable logo images of equal width, following the guide's set. Click each logo to test it.

## Both ways
Write one address twice — absolute, with protocol, host and path, and relative, for a file in your page's folder. Say what the relative form leaves out.
