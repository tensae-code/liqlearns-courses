# Parts of an XML document — declaration and DTD — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** The declaration can name UTF-16 as its encoding.
**Answer: True** — UTF-8 and UTF-16 are both named.

**2. (Sub lesson 2)** The internal DTD subset is declared in a separate file.
**Answer: False** — internal means inside the same file.

**3. (Sub lesson 3)** Where a declaration says #PCDATA, more elements nest inside that element.
**Answer: False** — #PCDATA ends the chain — the content there is text.
