# Parts of an XML document — declaration and DTD — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The XML declaration gives —
a) the root element and its children  b) the version and the encoding  c) the file's price
**Answer: b) the version and the encoding** — version and encoding are the declaration's two pieces.

**2. (Sub lesson 1)** Encoding converts Unicode characters to —
a) pictures  b) their binary equivalent  c) HTML tags
**Answer: b) their binary equivalent** — that conversion is what encoding is here.

**3. (Sub lesson 2)** The DOCTYPE describes the document's —
a) colours and fonts  b) structure and restrictions  c) author's address
**Answer: b) structure and restrictions** — structure and restrictions are the DOCTYPE's job.

**4. (Sub lesson 3)** #PCDATA is —
a) a root element  b) parsed character data — text between a start and end tag  c) an attribute
**Answer: b) parsed character data — text between a start and end tag** — #PCDATA marks text content.
