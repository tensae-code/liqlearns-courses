# Parts of an XML document — declaration and DTD — fill in the blank

Fill each blank with the right word or code.

**1. (Sub lesson 1)** The declaration is also called a processing ___.
**Answer: instruction** — declaration / processing instruction are the two names given.

**2. (Sub lesson 2)** In the athletes document, people contains ___.
**Answer: person** — people contains person; person contains name.

**3. (Sub lesson 3)** The text between a start tag and an end tag is ___ character data.
**Answer: parsed** — #PCDATA — parsed character data.
