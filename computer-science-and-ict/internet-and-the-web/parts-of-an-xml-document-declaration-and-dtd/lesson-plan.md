# Lesson plan — Parts of an XML document — declaration and DTD

**Course:** Computer Science and ICT · **Title:** Internet and the Web · **Lesson:** Parts of an XML document — declaration and DTD
**Place in the curriculum:** Title — Internet and the Web in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 12 book, Unit 4 — Web Authoring. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** the first parts of a complete XML document: the declaration at the top, the DOCTYPE, the internal DTD's element declarations, and #PCDATA.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The declaration — version and encoding** — the XML declaration / processing instruction at the start gives the version and the encoding
2. **The DOCTYPE and the internal DTD subset** — the Document Type Declaration describes the document's structure and restrictions; the internal subset declares the elements inside the same file
3. **#PCDATA — parsed character data** — first and last hold #PCDATA: the text between a start tag and an end tag

## If the learner is stuck
- Confuses declaration with DOCTYPE → the declaration gives version and encoding; the DOCTYPE describes structure and restrictions.
- Reads #PCDATA as a tag name → it is not an element; it marks parsed character data — text.
