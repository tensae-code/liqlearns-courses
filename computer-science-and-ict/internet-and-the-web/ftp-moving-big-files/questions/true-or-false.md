# FTP — moving big files over the internet — true or false

Say whether each sentence is true or false.

**1.** FTP can transfer files between locations and computers.
**Answer: True — between locations and computers is its named work.**

**2.** A single huge file that email cannot carry is a job for FTP.
**Answer: True — large files are FTP's first named case.**

**3.** FTP is used to write the text of an email message.
**Answer: False — FTP transfers files; writing messages is email's work.**
