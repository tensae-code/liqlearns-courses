# FTP — moving big files over the internet — multiple choice

Pick the one right answer.

**1.** FTP stands for —
a) Fast Text Program  b) File Transfer Protocol  c) File Typing Page  d) First Telephone Post
**Answer: b) File Transfer Protocol**

**2.** FTP is the internet service for —
a) transferring files from one system to another  b) writing letters  c) making phone calls  d) drawing pictures
**Answer: a) transferring files from one system to another**

**3.** Use FTP when —
a) a message has three words  b) a file is large, or several files would be difficult to send by email  c) you have no news  d) a page is static
**Answer: b) a file is large, or several files would be difficult to send by email**

**4.** Downloading means —
a) sending a file away  b) bringing a file from another system to yours  c) deleting a file  d) naming a file
**Answer: b) bringing a file from another system to yours**

**5.** Uploading means —
a) reading a file  b) sending a file from your system to another  c) printing a file  d) closing a file
**Answer: b) sending a file from your system to another**
