# FTP — moving big files over the internet

## Do it first

You must send a very large file — far too big for an email — to a computer in another town, and after it, several more files. Email cannot carry them. There is a service built for exactly this job. Find its name and its letters.

## Moving files — the FTP service

**FTP** stands for **File Transfer Protocol**. It is the internet service for **transferring files from one system to another using the internet**. With FTP you can **download** a file, **upload** a file, and **transfer files between locations and computers** directly, machine to machine.

[IMAGE 11723 — a large file travelling by FTP]

## When FTP is the tool

Use FTP **when a file is large**, or **when several files are to be transferred that would be difficult to send by email**. That is the whole rule: small single messages travel by email; big files and bundles of files travel by FTP.

## Tip — from us, not from the books

**Tip — from us, not from the books:** before you send a big file any way at all, check its size first and tell the person receiving it that it is coming — a large file arriving unannounced can fill a small inbox or use up a person's data in one go.
