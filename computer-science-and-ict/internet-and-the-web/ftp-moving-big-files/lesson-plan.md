# Lesson plan — FTP — moving big files over the internet

**Course:** Computer Science and ICT · **Title:** Internet and the Web · **Lesson:** FTP — moving big files over the internet
**Place in the curriculum:** Title 8 — Internet and the Web of the Computer Science and ICT ladder (TITLES.md); Ethiopia Grade 8, Unit 4 — Internet. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** FTP — File Transfer Protocol — is the internet service for transferring files from one system to another: downloading, uploading and transferring files between locations and computers, used when a file is large or several files would be difficult to send by email.
**This lesson's own level:** it stands on the internet-services idea — the learner knows the internet offers services; this lesson teaches the service whose one job is moving files.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. ## What the learner can do when it ends
1. Say what FTP stands for: File Transfer Protocol.
2. Say what FTP does: downloads, uploads and transfers files between systems, locations and computers.
3. Name the two cases for FTP: a large file, and several files difficult to send by email.

## If the learner is stuck
- Thinks FTP is a kind of email → email carries messages with attachments; FTP's whole job is transferring the files themselves, system to system.
- Mixes download and upload → download brings a file to you; upload sends a file from you.
