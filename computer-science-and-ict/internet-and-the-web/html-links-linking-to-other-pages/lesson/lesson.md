# HTML links — linking to other pages

## Do it first

Point at a link on any page and the cursor turns into a hand — that is a link asking to be clicked. In this lesson you make your own: links to Ethiopian Airlines, Ethio-telecom and the Commercial Bank of Ethiopia, the book's own practice set — first opening in the same tab, then reworked to open in a new one. The guide solves this same set in full (teacher guide, printed pp. 66–71), so your links have a verified model to check against.

## Sub lesson 1 — The anchor element — reference and clickable text

**Links (hyperlinks)** are recognised when the **cursor turns into a hand**. A link is made with the **anchor element**: its **reference attribute carries the destination address — the URL (Uniform Resource Locator)** — and the **text between the tags is the clickable part** the visitor sees. **Only that clickable text shows on the page**; the address itself stays in the code.

## Sub lesson 2 — The target attribute — same tab or new tab

The **target attribute** decides **where the linked page opens**: in the **same window or tab by default**, or in a **new window or tab**. The guide names the whole trick (teacher guide — evidence): the same links reopen in a new tab by **changing one attribute** — the target attribute and its value. The book's practice links to **Ethiopian Airlines, Ethio-telecom and the Commercial Bank of Ethiopia**, then reworks them to open in a new tab.
