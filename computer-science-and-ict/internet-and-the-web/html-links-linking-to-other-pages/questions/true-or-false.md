# HTML links — linking to other pages — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) URL stands for Uniform Resource Locator.**
**Answer: True** — the link's address name.

**2. (Sub lesson 1) The destination address is the part of a link the visitor reads on the page.**
**Answer: False** — the visitor reads the clickable text; the address is in the code.

**3. (Sub lesson 2) The target attribute decides where the linked page opens.**
**Answer: True** — same tab or new tab.
