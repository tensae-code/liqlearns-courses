# HTML links — linking to other pages — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) A link is recognised on a page when —**
a) the cursor turns into a hand  b) the page is printed  c) the title changes  d) the browser closes
**Answer: a) the cursor turns into a hand** — the hand cursor is the sign.

**2. (Sub lesson 1) Links are made with the —**
a) anchor element  b) table element  c) video element  d) heading element
**Answer: a) anchor element** — the anchor makes the link.

**3. (Sub lesson 1) The reference attribute carries —**
a) the destination address (URL)  b) the clickable text  c) the page title  d) the image file
**Answer: a) the destination address (URL)** — reference = where the link goes.

**4. (Sub lesson 1) What shows on the page is —**
a) only the clickable text between the tags  b) the full URL always  c) the code  d) nothing
**Answer: a) only the clickable text between the tags** — the address stays in the code.

**5. (Sub lesson 2) By default, a linked page opens —**
a) in the same window or tab  b) always in a new tab  c) in a new computer  d) never
**Answer: a) in the same window or tab** — same tab is the default.

**6. (Sub lesson 2) The guide says new-tab opening is achieved by — (teacher guide — evidence)**
a) changing one attribute — the target  b) rewriting the whole page  c) adding three elements  d) removing the reference
**Answer: a) changing one attribute — the target** — one attribute is the whole trick.
