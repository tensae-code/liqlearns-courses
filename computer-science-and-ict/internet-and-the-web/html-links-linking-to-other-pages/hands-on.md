# Hands-on — HTML links — linking to other pages

The lesson with your hands, not only your eyes. You need a computer with a text editor and a browser for the doing parts.

## The Ethiopian set
Build the book's practice set: text links to Ethiopian Airlines, Ethio-telecom and the Commercial Bank of Ethiopia. Click each one and confirm it arrives.

## One attribute changed
Copy your link page. In the copy, change only the target attribute on each link so all three open in new tabs — the guide's trick, done by your own hand.
