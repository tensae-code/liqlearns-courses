# Online Chat — Text, Voice and Video Calls — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is text chat?" is: Live written conversation in short, immediately sent turns**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How does chat writing differ from letter writing?" is: Yahoo Messenger**
**Answer: False** — It is brief, quick and informal — but it is kept

**3. (Sub lesson 1) True or false: the answer to "What messenger does the book teach through?" is: Yahoo Messenger**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is the first rule of the live line?" is: Tone, pace and feeling**
**Answer: False** — Write nothing you would not want read back later

**5. (Sub lesson 1) True or false: the answer to "What does voice conversation return to the talk?" is: Tone, pace and feeling**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does video add?" is: More connection and more exposure**
**Answer: False** — The face — the far speaker seen as well as heard

**7. (Sub lesson 2) True or false: the answer to "What does each rise in mode cost?" is: More connection and more exposure**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "When is text the right mode?" is: To truly meet**
**Answer: False** — To leave a quick word

**9. (Sub lesson 2) True or false: the answer to "When is video the right mode?" is: To truly meet**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What must the mode be matched to?" is: Live written conversation in short, immediately sent turns**
**Answer: False** — The moment — never merely the newest
