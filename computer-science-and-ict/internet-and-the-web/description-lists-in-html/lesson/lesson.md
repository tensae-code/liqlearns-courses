# Description lists in HTML

## Do it first

A list can work like a small dictionary: a word, then what the word means. Build the book's worked example — a list that defines the three list tags themselves. Three new tags do it; this lesson names them as your dictionary takes shape.

## Sub lesson 1 — The three description tags

A **description list defines terms**, with three tags:

- The **description-list tag** wraps the whole list.
- The **term tag** adds the **item being defined**.
- The **description tag** adds **its definition**.

On the page, the **term stands out** and its **definition sits indented beneath it**.
