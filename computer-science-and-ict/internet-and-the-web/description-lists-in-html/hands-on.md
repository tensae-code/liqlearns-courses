# Hands-on — Description lists in HTML

The lesson with your hands, not only your eyes. You need a computer with a text editor and a browser for the doing parts.

## Define the unit
Write a description list defining five words from this unit: tag, element, attribute, link, table. Each term with a one-line definition in your own words.

## Three favourites
Build the book's practice: a dictionary of three favourite English words, each defined — then check its shape against the guide's model.
