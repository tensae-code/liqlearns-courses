# Description lists in HTML — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) A description list —**
a) defines terms  b) numbers items in order  c) only holds images  d) lays out a page
**Answer: a) defines terms** — definitions are its job.

**2. (Sub lesson 1) The whole description list is wrapped by —**
a) the description-list tag  b) the term tag  c) the description tag  d) the ordered-list tag
**Answer: a) the description-list tag** — one wrapper for the list.

**3. (Sub lesson 1) The item being defined is added by —**
a) the term tag  b) the description tag  c) the item tag  d) the header tag
**Answer: a) the term tag** — term = the word defined.

**4. (Sub lesson 1) A term's definition is added by —**
a) the description tag  b) the term tag  c) the unordered-list tag  d) the anchor element
**Answer: a) the description tag** — description = the meaning.

**5. (Sub lesson 2) The book's worked example defines —**
a) the three list tags themselves  b) three websites  c) three mountains  d) three videos
**Answer: a) the three list tags themselves** — the list tags, defined by a list.

**6. (Sub lesson 2) The book's practice is —**
a) a small dictionary of three favourite English words  b) a list of ten subjects  c) a table of words  d) a page of links
**Answer: a) a small dictionary of three favourite English words** — three favourite words.
