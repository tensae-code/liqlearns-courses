# Description lists in HTML — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) In a description list, the definition appears before its term.**
**Answer: False** — term first, definition beneath it.

**2. (Sub lesson 2) The guide's worked set includes a description list defining three English words. (teacher guide — evidence)**
**Answer: True** — Activities 4.13–4.16 are solved in full, this among them.

**3. (Sub lesson 2) A description list uses the same wrapper as an ordered list.**
**Answer: False** — it has its own description-list tag.
