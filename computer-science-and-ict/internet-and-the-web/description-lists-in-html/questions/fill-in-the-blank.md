# Description lists in HTML — fill in the blank

Fill each blank with the right word or code.

**1. (Sub lesson 1) The tag that adds the item being defined is the ___ tag.**
**Answer: term** — term = the word.

**2. (Sub lesson 1) The tag that adds the meaning is the ___ tag.**
**Answer: description** — description = the definition.

**3. (Sub lesson 2) On the page, the definition sits ___ beneath its term.**
**Answer: indented** — indented under the term.
