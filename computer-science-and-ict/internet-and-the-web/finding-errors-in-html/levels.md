# Finding Errors in HTML — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — The common faults
Sub lesson 1 questions from the type files. Pass mark: An unclosed tag — its effect runs to the page's end; Tags closed in the wrong order — </b> before </i> when <i> opened last; Nothing visible — the browser silently ignores it; Missing quotes around its value; No — they guess and carry on; the page is the evidence.

## Sub lesson 2 — The checking habit — page against code
Sub lesson 2 questions from the type files. Pass mark: A comparison — what the page shows against the code; At or just before the place where the wrongness starts; Its unclosed tag; One — then re-open the page, so each fix's effect is seen alone; Which fix actually worked.
