# Finding Errors in HTML — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Name the first common fault." is: An unclosed tag — its effect runs to the page's end**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is wrong nesting?" is: Nothing visible — the browser silently ignores it**
**Answer: False** — Tags closed in the wrong order — </b> before </i> when <i> opened last

**3. (Sub lesson 1) True or false: the answer to "What does a misspelled tag name do?" is: Nothing visible — the browser silently ignores it**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What breaks an attribute?" is: No — they guess and carry on; the page is the evidence**
**Answer: False** — Missing quotes around its value

**5. (Sub lesson 1) True or false: the answer to "Do browsers usually report HTML errors?" is: No — they guess and carry on; the page is the evidence**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is finding a fault, in Malaysia's method?" is: At or just before the place where the wrongness starts**
**Answer: False** — A comparison — what the page shows against the code

**7. (Sub lesson 2) True or false: the answer to "Where is the fault usually found?" is: At or just before the place where the wrongness starts**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "A heading swallows the whole page. Which fault do you suspect?" is: One — then re-open the page, so each fix's effect is seen alone**
**Answer: False** — Its unclosed tag

**9. (Sub lesson 2) True or false: the answer to "How many faults should you fix at once?" is: One — then re-open the page, so each fix's effect is seen alone**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What does fixing in batches hide?" is: An unclosed tag — its effect runs to the page's end**
