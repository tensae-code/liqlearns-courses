# Finding Errors in HTML — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Name the first common fault.**
a) An unclosed tag — its effect runs to the page's end  b) Tags closed in the wrong order — </b> before </i> when <i> opened last  c) Nothing visible — the browser silently ignores it  d) Missing quotes around its value
**Answer: a) An unclosed tag — its effect runs to the page's end**

**2. (Sub lesson 1) What is wrong nesting?**
a) Nothing visible — the browser silently ignores it  b) Tags closed in the wrong order — </b> before </i> when <i> opened last  c) Missing quotes around its value  d) No — they guess and carry on; the page is the evidence
**Answer: b) Tags closed in the wrong order — </b> before </i> when <i> opened last**

**3. (Sub lesson 1) What does a misspelled tag name do?**
a) Missing quotes around its value  b) No — they guess and carry on; the page is the evidence  c) Nothing visible — the browser silently ignores it  d) A comparison — what the page shows against the code
**Answer: c) Nothing visible — the browser silently ignores it**

**4. (Sub lesson 1) What breaks an attribute?**
a) No — they guess and carry on; the page is the evidence  b) A comparison — what the page shows against the code  c) At or just before the place where the wrongness starts  d) Missing quotes around its value
