# Hands-on — HTML tags and elements

The lesson with your hands, not only your eyes. You need a computer with a text editor and a browser for the doing parts.

## Build the model page
Type the minimal page — title and two paragraphs — save it as .html and open it. Then add horizontal rules between the paragraphs, as the guide's second model does.

## Tag hunt
Open any page's source. Find one heading, one paragraph, one bold and one italic element. Write each one's start tag, content and end tag.
