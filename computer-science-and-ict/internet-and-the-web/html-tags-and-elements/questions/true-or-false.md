# HTML tags and elements — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Tags are names the page author invents freely each time.**
**Answer: False** — tags are predefined names in angle brackets, with meanings browsers know.

**2. (Sub lesson 2) Bold and italic elements start a new line on screen.**
**Answer: False** — they run on within the line.

**3. (Sub lesson 3) The guide's second model page adds horizontal rules between the paragraphs. (teacher guide — evidence)**
**Answer: True** — that is the Activity 4.4 model.
