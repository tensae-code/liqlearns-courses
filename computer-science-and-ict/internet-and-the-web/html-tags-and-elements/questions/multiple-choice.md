# HTML tags and elements — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) HTML is —**
a) the markup language used to create webpages  b) a web browser  c) a web server  d) a kind of image file
**Answer: a) the markup language used to create webpages** — HTML is the language pages are written in.

**2. (Sub lesson 1) The current version of HTML is —**
a) HTML5  b) HTML1  c) HTMLX  d) HTML 2023
**Answer: a) HTML5** — HTML5 is the current version.

**3. (Sub lesson 1) A webpage file is saved with the extension —**
a) .html  b) .txt only  c) .jpg  d) .exe
**Answer: a) .html** — .html tells the browser it is a webpage.

**4. (Sub lesson 2) An element is normally —**
a) a start tag, content and an end tag together  b) only a start tag  c) only content with no tags  d) a file name
**Answer: a) a start tag, content and an end tag together** — three parts together make an element.

**5. (Sub lesson 2) Which elements start a new line on screen?**
a) heading and paragraph  b) bold and italic  c) bold only  d) italic only
**Answer: a) heading and paragraph** — headings and paragraphs break the line; bold and italic run on.

**6. (Sub lesson 3) In the guide's model first page, the title sits in the —**
a) head  b) body only  c) a table  d) an image
**Answer: a) head** — the title belongs to the head section.
