# HTML tags and elements — fill in the blank

Fill each blank with the right word or code.

**1. (Sub lesson 1) Tags are predefined names written in ___ brackets.**
**Answer: angle** — angle brackets < >.

**2. (Sub lesson 2) Elements are the ___ blocks of a page.**
**Answer: building** — elements build the page.

**3. (Sub lesson 2) A tag, its content and its end tag together are called an ___.**
**Answer: element** — element is the whole.
