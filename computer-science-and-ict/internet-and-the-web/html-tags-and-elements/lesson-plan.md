# Lesson plan — HTML tags and elements

**Course:** Computer Science and ICT · **Title:** Internet and the Web · **Lesson:** HTML tags and elements
**Place in the curriculum:** Title — Internet and the Web in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 11 book, Unit 4 — Web Development. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** a webpage is built from elements — a start tag, content and an end tag — written in a text editor and saved with the .html extension.
**This lesson's own level:** it stands on the designing-vs-building lesson — the learner builds with a text editor from here on.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **HTML, tags and the .html file** — what HTML is, what a tag is, and the .html save
2. **Elements — start tag, content, end tag** — the three parts of an element, and which elements start a new line
3. **Your first pages, checked against the models (teacher guide — evidence)** — the guide's model first pages as the verified expected output

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Designing vs building a website. Recommended, never forced.

## What the learner can do when it ends
1. Say what HTML is and name its current version.
2. Take any element apart into its three parts.
3. Write and save a first page and open it in a browser.

## What you need
A computer with a text editor and a browser; paper and a pencil.

## The run of the lesson (in order)
1. **Do it first** — the learner types the guide's model first page in a text editor, saves it as .html and opens it in a browser, before tags and elements are named (teacher guide — evidence) (lesson/lesson.md).
2. **The explanation** — the parts below, in order (lesson/lesson.md).
   - ADD IMAGE [Picture 17303]: a picture of one element taken apart into start tag, content and end tag, with its browser output beside it — the student labels the three parts.
   - ADD GIF [GIF 17320]: typing a page in a text editor and the browser rendering appearing (teacher guide — evidence) — the student follows the typing, then the rendering.
   - ADD AUDIO: a voice reading the lesson's key words and code aloud — the student listens and repeats each tag name.
3. **Say it to your companion** — explain the lesson back in your own words (lesson/lesson.md).
   - ADD VIDEO: the script in video-script.md, filmed — the lesson retold in the super-simple voice (made later, when videos are made).
4. **Questions** — from questions/: multiple-choice, true-or-false, fill-in-the-blank — served at the learner's level (levels.md).
5. **Hands-on** — hands-on.md.
6. **Do It Yourself** — the doing block at the end of lesson/lesson.md.

## If the learner is stuck
- Saves without .html → the browser cannot treat it as a webpage; the extension is part of the skill.
- Thinks bold starts a new line → bold and italic run on within the line; headings and paragraphs start new lines.
