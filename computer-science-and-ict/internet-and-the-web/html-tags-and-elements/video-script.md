# Video script — HTML tags and elements

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Open the text editor.
Type the page. A title. Two paragraphs.
Every part has a start tag, words, an end tag.
Save it. The name ends .html.
Open it in the browser.
There is your page. You built it.
Now check it against the model: title in the head, paragraphs in the body.
If a part is missing, add it, save, and look again.
