# HTML tags and elements

## Do it first

On a computer, open a text editor. Type a short page: a title and two paragraphs of your own words, using the tags your teacher shows you. Save the file with **.html** at the end of its name, then open it in a browser. You have built a webpage. This lesson names every part of what you just typed. (The teacher guide's model first pages are the verified expected output for this doing — teacher guide, printed pp. 62–64.)

## Sub lesson 1 — HTML, tags and the .html file

**HTML** is the **markup language used to create webpages**; the current version is **HTML5**. A page is written in a **text editor** and saved with the **.html extension**. Inside it, **tags** are **predefined names in angle brackets** — each tag has its own meaning, and browsers know how to render it: tags for **bold**, **paragraph**, **italic** and **heading** are the first examples.

## Sub lesson 2 — Elements — start tag, content, end tag

An **element** is normally a **start tag, content and an end tag** together — and elements are the **building blocks of a page**. Watch how they sit on the page: **heading and paragraph elements start a new line** on screen, while **bold and italic run on within the line**.
