## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Authoring — making pages without writing every tag** — A **web authoring program** is an application for **building web pages and whole sites** in which the author works mostly **visually** — typing text, placing pictures, choosing links — while the program **writes the HTML underneath**. Fiji names the class's leaders of its time: **Dreamweaver** and **FrontPage**. The author's job shifts from writing tags to making decisions — what the page says, how it is arranged, where its links go — and the program does the coding labour.
2. **HTML editors — the middle way** — Beside the full authoring programs stand **HTML editors**: programs that help a person **write HTML directly** — colouring the tags, completing them, checking them — without hiding the code. The two kinds divide by how much code the author wants to see: authoring programs hide it for speed and ease; editors show it for control and learning. Fiji places both in its advanced applications because a serious web worker meets the pair — and because every page either kind produces is still HTML, which the course teaches on its own terms alongside.

2. **The explanation** — the lesson text in lesson/lesson.md, in its parts in order.
