# Web Authoring Programs and HTML Editors — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a web authoring program?" is: An application for building web pages and sites where the author works mostly visually**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Who writes the HTML in an authoring program?" is: Dreamweaver and FrontPage**
**Answer: False** — The program writes it underneath, from the author's visual work

**3. (Sub lesson 1) True or false: the answer to "Name Fiji's two leading authoring programs." is: Dreamweaver and FrontPage**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does the author's job become?" is: The coding labour of writing the tags**
**Answer: False** — Making decisions — what the page says, how it is arranged, where links go

**5. (Sub lesson 1) True or false: the answer to "What labour does the program take over?" is: The coding labour of writing the tags**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is an HTML editor?" is: They colour the tags, complete them and check them — without hiding the code**
**Answer: False** — A program that helps a person write HTML directly — colouring, completing and checking tags

**7. (Sub lesson 2) True or false: the answer to "How do editors help?" is: They colour the tags, complete them and check them — without hiding the code**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How do the two kinds divide?" is: HTML**
**Answer: False** — By how much code the author wants to see — hidden for ease, shown for control

**9. (Sub lesson 2) True or false: the answer to "What is every produced page still made of?" is: HTML**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why does Fiji teach HTML itself alongside?" is: An application for building web pages and sites where the author works mostly visually**
**Answer: False** — Because both kinds of program produce HTML pages, and the worker must understand what is produced
