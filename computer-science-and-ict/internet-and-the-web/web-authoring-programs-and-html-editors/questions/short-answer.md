# Web Authoring Programs and HTML Editors — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a web authoring program?**
**Answer: An application for building web pages and sites where the author works mostly visually**

**2. (Sub lesson 1) Who writes the HTML in an authoring program?**
**Answer: The program writes it underneath, from the author's visual work**

**3. (Sub lesson 1) Name Fiji's two leading authoring programs.**
**Answer: Dreamweaver and FrontPage**

**4. (Sub lesson 1) What does the author's job become?**
**Answer: Making decisions — what the page says, how it is arranged, where links go**

**5. (Sub lesson 1) What labour does the program take over?**
**Answer: The coding labour of writing the tags**

**6. (Sub lesson 2) What is an HTML editor?**
**Answer: A program that helps a person write HTML directly — colouring, completing and checking tags**

**7. (Sub lesson 2) How do editors help?**
**Answer: They colour the tags, complete them and check them — without hiding the code**

**8. (Sub lesson 2) How do the two kinds divide?**
**Answer: By how much code the author wants to see — hidden for ease, shown for control**

**9. (Sub lesson 2) What is every produced page still made of?**
**Answer: HTML**

**10. (Sub lesson 2) Why does Fiji teach HTML itself alongside?**
**Answer: Because both kinds of program produce HTML pages, and the worker must understand what is produced**
