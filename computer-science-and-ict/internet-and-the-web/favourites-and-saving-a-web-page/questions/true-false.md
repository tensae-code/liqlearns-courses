# Favourites and Saving a Web Page — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does the favourites list keep?" is: A page's address, under a name you choose**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does saving a web page keep?" is: Saving — the saved copy opens offline**
**Answer: False** — A copy of the page itself, on your own computer

**3. (Sub lesson 1) True or false: the answer to "Which keeping works with no connection?" is: Saving — the saved copy opens offline**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "When is a favourite better than a saved copy?" is: The small bar that appears over a picture on a page, with save and print actions**
**Answer: False** — For a page you revisit, because it returns to the living, updated page

**5. (Sub lesson 1) True or false: the answer to "What is the image toolbar?" is: The small bar that appears over a picture on a page, with save and print actions**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does printing do?" is: Which page the browser opens with, every time**
**Answer: False** — Puts the page on paper

**7. (Sub lesson 2) True or false: the answer to "What does choosing the home page decide?" is: Which page the browser opens with, every time**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Why does the book teach Arabic in the browser?" is: Favourites (the address) and saving (the copy)**
**Answer: False** — So Arabic pages show correctly and can be read at all

**9. (Sub lesson 2) True or false: the answer to "Name the two ways of keeping a page." is: Favourites (the address) and saving (the copy)**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Whose browser chapter teaches this set?" is: A page's address, under a name you choose**
**Answer: False** — Libya's Grade 9 book, in its Internet Explorer chapter
