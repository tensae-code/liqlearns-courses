# Saving a Web Page to Your Computer — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does saving a web page keep?" is: A copy of the page — its words and pictures — as a file**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Where is the saved copy kept?" is: From the browser, while the page is open**
**Answer: False** — On your own computer, in your files

**3. (Sub lesson 1) True or false: the answer to "Why save a page at all?" is: So it can be opened again, even with no connection**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How is a page before it is saved?" is: In the right folder, like every file**
**Answer: False** — Borrowed — shown from far away, and gone when the browser closes

**5. (Sub lesson 1) True or false: the answer to "Does a saved copy change when the real page changes?" is: No — it keeps the page as it was on the day it was saved**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "From where is a page saved?" is: When the copy cannot be found again**
**Answer: False** — From the browser, while the page is open

**7. (Sub lesson 2) True or false: the answer to "What name should the saved copy get?" is: A name that says what the page is**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Where should the saved page be put?" is: On your own computer, in your files**
**Answer: False** — In the right folder, like every file

**9. (Sub lesson 2) True or false: the answer to "How do you check the saving worked?" is: Open the copy from the folder, without the internet**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "When was a page not saved properly?" is: Borrowed — shown from far away, and gone when the browser closes**
**Answer: False** — When the copy cannot be found again
