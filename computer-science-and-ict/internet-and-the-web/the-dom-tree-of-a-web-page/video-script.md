# Video script — The DOM — the Tree of a Web Page

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A browser does not keep a page as text. It builds a tree. The tree is called the DOM.

At the top: the document. Under it, every element is a node. Head. Body. Heading. Paragraph. Link.

The words inside are nodes too. They are the leaves.

Every node has a parent. It may have children. It has siblings beside it.

Why a tree? Because programs can climb it. A script finds one node, changes its text — and the page changes on the screen, at once.

Every interactive page you know is a program climbing this tree.
