# The DOM — the Tree of a Web Page — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) DOM stands for —**
a) Document Object Model  b) Data On Monitor  c) Document Opening Mode  d) Digital Object Machine
**Answer: a) Document Object Model — The model the browser builds of the page as a tree of nodes.**

**2. (Sub lesson 1) In the DOM tree, the words inside an element are —**
a) Attributes  b) Text nodes, the leaves of the tree  c) Not part of the tree  d) Parent nodes
**Answer: b) Text nodes, the leaves of the tree — Every piece of text is a node, at the end of a branch.**

**3. (Sub lesson 2) How does a script most simply find one particular element in the tree?**
a) By its colour  b) By counting lines of the file  c) By the id given to the element  d) By its position on the screen
**Answer: c) By the id given to the element — The id names one node so a program can go straight to it.**
