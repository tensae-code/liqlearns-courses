# The DOM — the Tree of a Web Page — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 1) At the very top of the DOM tree sits the ____ node.**
**Answer: document — The document node is the root, holding the whole page.**

**2. (Sub lesson 2) An element directly containing another is its ____.**
**Answer: parent — Every node has exactly one parent, except the root.**
