# The DOM — the Tree of a Web Page — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Two elements directly inside the same parent are siblings in the DOM.**
**Answer: True — Nodes sharing one parent are siblings, like the h1 and p inside a div.**

**2. (Sub lesson 2) When JavaScript changes a node, it rewrites the HTML file on the server.**
**Answer: False — It changes the living tree in the browser; the file is untouched, and a reload rebuilds the tree from the file.**
