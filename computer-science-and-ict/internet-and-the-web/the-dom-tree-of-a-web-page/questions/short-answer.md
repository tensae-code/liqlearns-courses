# The DOM — the Tree of a Web Page — short answer

Answer in your own words, in one or two sentences.

**1. (Sub lesson 2) Why does the browser build the DOM instead of just displaying the HTML text?**
**Answer: Because a tree can be searched and changed by programs — scripts find nodes, read and alter them, and the browser redraws the page from the changed tree at once, which is what makes pages interactive.**
