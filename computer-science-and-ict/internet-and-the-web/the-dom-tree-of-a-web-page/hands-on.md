# Hands-on — The DOM — the Tree of a Web Page

The lesson with your hands and your feet, not only your eyes.

## Draw the tree
Write a fragment of your own: a `div` containing a heading, a paragraph with a link inside, and a list of two items. Draw its DOM tree completely, marking element nodes as boxes and text nodes as ovals. Label one parent-child pair and one pair of siblings.

## See the real tree (if a browser is available)
Open any page, open the developer tools, and look at the Elements view: that is the page's DOM. Find the `body` node, one heading, and one text node. Change one word of the text in the tools and watch the page change — you have just done by hand what a script does.
