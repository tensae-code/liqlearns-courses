# Hands-on — Nesting HTML Elements Correctly

The lesson with your hands and your feet, not only your eyes.

## Task one
**Nest by hand** — Write a page fragment with four levels of nesting — section, paragraph, bold, link — closing tags written first as empty pairs, then filled.

## Task two
**Break and mend** — Take a fragment with two overlapping-tag faults. Draw its intended box tree, then rewrite the fragment so the mirror holds.
