# CSS — Styling the Look of a Webpage — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does CSS stand for?" is: Cascading Style Sheets**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does CSS set?" is: The page's structure and meaning — this is a heading, this is a paragraph**
**Answer: False** — A webpage's look — colours, fonts, sizes, spacing and layout

**3. (Sub lesson 1) True or false: the answer to "What does HTML carry, in the separation?" is: The page's structure and meaning — this is a heading, this is a paragraph**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does CSS carry?" is: One style change restyles every page using it; the same page can change look untouched in its words**
**Answer: False** — The presentation — how the structured page looks

**5. (Sub lesson 1) True or false: the answer to "Why is separation powerful?" is: One style change restyles every page using it; the same page can change look untouched in its words**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What are a CSS rule's two parts?" is: Inside a page, or as a separate file linked by many pages**
**Answer: False** — The selector — the part styled — and the declarations: property and value pairs

**7. (Sub lesson 2) True or false: the answer to "Where can a style sheet live?" is: Inside a page, or as a separate file linked by many pages**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Why does the senior course prefer the separate file?" is: CSS's order of authority — when rules meet, the nearer and more specific rule wins**
**Answer: False** — A site's look should live in one place

**9. (Sub lesson 2) True or false: the answer to "What is the cascade?" is: CSS's order of authority — when rules meet, the nearer and more specific rule wins**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What does CSS3 add?" is: Cascading Style Sheets**
**Answer: False** — Effects such as rounded shapes, shadows and movement
