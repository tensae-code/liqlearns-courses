# CSS — Styling the Look of a Webpage — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does CSS stand for?**
**Answer: Cascading Style Sheets**

**2. (Sub lesson 1) What does CSS set?**
**Answer: A webpage's look — colours, fonts, sizes, spacing and layout**

**3. (Sub lesson 1) What does HTML carry, in the separation?**
**Answer: The page's structure and meaning — this is a heading, this is a paragraph**

**4. (Sub lesson 1) What does CSS carry?**
**Answer: The presentation — how the structured page looks**

**5. (Sub lesson 1) Why is separation powerful?**
**Answer: One style change restyles every page using it; the same page can change look untouched in its words**

**6. (Sub lesson 2) What are a CSS rule's two parts?**
**Answer: The selector — the part styled — and the declarations: property and value pairs**

**7. (Sub lesson 2) Where can a style sheet live?**
**Answer: Inside a page, or as a separate file linked by many pages**

**8. (Sub lesson 2) Why does the senior course prefer the separate file?**
**Answer: A site's look should live in one place**

**9. (Sub lesson 2) What is the cascade?**
**Answer: CSS's order of authority — when rules meet, the nearer and more specific rule wins**

**10. (Sub lesson 2) What does CSS3 add?**
**Answer: Effects such as rounded shapes, shadows and movement**
