# Hands-on — Client-Side Scripting

The lesson with your hands and your feet, not only your eyes.

## Client or server?
Name five page events (checking a password length, showing a saved photo album, opening a menu, storing an order, greeting by name). Sort each: must run client-side, server-side, or either — and say why.

## Script the click
Write, in plain words, the script for a button that shows a hidden hint when clicked: the event, the check, the change on the page.
