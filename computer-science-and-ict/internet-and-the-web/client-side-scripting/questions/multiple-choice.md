# Client-Side Scripting — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Client-side means what?**
a) On the user's (client's) computer  b) In the web browser  c) JavaScript  d) Sends the page — the script then runs locally
**Answer: a) On the user's (client's) computer**

**2. (Sub lesson 1) A client-side script runs where?**
a) JavaScript  b) In the web browser  c) Sends the page — the script then runs locally  d) User actions like clicks
**Answer: b) In the web browser**

**3. (Sub lesson 1) Name a common client-side scripting language.**
a) Sends the page — the script then runs locally  b) User actions like clicks  c) JavaScript  d) Before the form is sent to the server
**Answer: c) JavaScript**

**4. (Sub lesson 1) In client-side scripting, the server does what?**
a) User actions like clicks  b) Before the form is sent to the server  c) No — it changes in the browser  d) Sends the page — the script then runs locally
**Answer: d) Sends the page — the script then runs locally**

**5. (Sub lesson 1) A client-side script can react to what?**
a) User actions like clicks  b) Before the form is sent to the server  c) No — it changes in the browser  d) Interactive
**Answer: a) User actions like clicks**

**6. (Sub lesson 2) Form checking by a script happens when?**
a) No — it changes in the browser  b) Before the form is sent to the server  c) Interactive  d) Loses its interactive behaviour
**Answer: b) Before the form is sent to the server**

**7. (Sub lesson 2) A page changed by a script needs a reload?**
a) Interactive  b) Loses its interactive behaviour  c) No — it changes in the browser  d) Interactive menus and controls
**Answer: c) No — it changes in the browser**

**8. (Sub lesson 2) Client-side scripts make pages what?**
a) Loses its interactive behaviour  b) Interactive menus and controls  c) On the user's (client's) computer  d) Interactive
**Answer: d) Interactive**

**9. (Sub lesson 2) If scripting is off, the page does what?**
a) Loses its interactive behaviour  b) Interactive menus and controls  c) On the user's (client's) computer  d) In the web browser
**Answer: a) Loses its interactive behaviour**

**10. (Sub lesson 2) The GUI unit pairs scripting with what?**
a) On the user's (client's) computer  b) Interactive menus and controls  c) In the web browser  d) JavaScript
**Answer: b) Interactive menus and controls**
