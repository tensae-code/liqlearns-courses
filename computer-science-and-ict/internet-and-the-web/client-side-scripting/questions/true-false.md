# Client-Side Scripting — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Client-side means what?" is: On the user's (client's) computer**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "A client-side script runs where?" is: Sends the page — the script then runs locally**
**Answer: False** — In the web browser

**3. (Sub lesson 1) True or false: the answer to "Name a common client-side scripting language." is: JavaScript**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "In client-side scripting, the server does what?" is: Before the form is sent to the server**
**Answer: False** — Sends the page — the script then runs locally

**5. (Sub lesson 1) True or false: the answer to "A client-side script can react to what?" is: User actions like clicks**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Form checking by a script happens when?" is: Interactive**
**Answer: False** — Before the form is sent to the server

**7. (Sub lesson 2) True or false: the answer to "A page changed by a script needs a reload?" is: No — it changes in the browser**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Client-side scripts make pages what?" is: Interactive menus and controls**
**Answer: False** — Interactive

**9. (Sub lesson 2) True or false: the answer to "If scripting is off, the page does what?" is: Loses its interactive behaviour**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "The GUI unit pairs scripting with what?" is: In the web browser**
**Answer: False** — Interactive menus and controls
