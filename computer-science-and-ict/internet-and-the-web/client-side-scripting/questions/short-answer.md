# Client-Side Scripting — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) Client-side means what?**
**Answer: On the user's (client's) computer**

**2. (Sub lesson 1) A client-side script runs where?**
**Answer: In the web browser**

**3. (Sub lesson 1) Name a common client-side scripting language.**
**Answer: JavaScript**

**4. (Sub lesson 1) In client-side scripting, the server does what?**
**Answer: Sends the page — the script then runs locally**

**5. (Sub lesson 1) A client-side script can react to what?**
**Answer: User actions like clicks**

**6. (Sub lesson 2) Form checking by a script happens when?**
**Answer: Before the form is sent to the server**

**7. (Sub lesson 2) A page changed by a script needs a reload?**
**Answer: No — it changes in the browser**

**8. (Sub lesson 2) Client-side scripts make pages what?**
**Answer: Interactive**

**9. (Sub lesson 2) If scripting is off, the page does what?**
**Answer: Loses its interactive behaviour**

**10. (Sub lesson 2) The GUI unit pairs scripting with what?**
**Answer: Interactive menus and controls**
