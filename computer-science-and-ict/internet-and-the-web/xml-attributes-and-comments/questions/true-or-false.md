# XML attributes and comments — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** personid="101" is an attribute whose value is 101.
**Answer: True** — personid is the name, "101" the quoted value.

**2. (Sub lesson 2)** A comment is part of the document's data.
**Answer: False** — a comment describes the code and is ignored — it is not data.

**3. (Sub lesson 1)** An attribute can be written with its value unquoted if the value is a number.
**Answer: False** — values must always be quoted, numbers included.
