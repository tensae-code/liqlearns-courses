# XML attributes and comments — fill in the blank

Fill each blank with the right word or code.

**1. (Sub lesson 1)** An attribute is a name-___ pair.
**Answer: value** — name-value pair is the term.

**2. (Sub lesson 2)** A ___ is a note describing the code, ignored by the parser.
**Answer: comment** — that is a comment's definition.

**3. (Sub lesson 2)** Comments are written with the ___-style comment markers.
**Answer: HTML** — HTML-style markers, <!-- -->.
