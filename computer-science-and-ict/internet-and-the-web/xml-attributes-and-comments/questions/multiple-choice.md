# XML attributes and comments — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** An attribute is —
a) a second root element  b) a name-value pair giving additional information about an element  c) a comment
**Answer: b) a name-value pair giving additional information about an element** — attributes add information about the element they ride on.

**2. (Sub lesson 1)** An attribute value must be —
a) unquoted  b) quoted in single or double quotes  c) written in capitals
**Answer: b) quoted in single or double quotes** — quoting is required.

**3. (Sub lesson 2)** While the code runs, the XML parser —
a) prints every comment  b) ignores comments  c) turns comments into elements
**Answer: b) ignores comments** — comments are ignored by the parser.

**4. (Sub lesson 2)** Comment markers in XML are —
a) the HTML-style markers <!-- -->  b) square brackets  c) curly braces
**Answer: a) the HTML-style markers <!-- -->** — XML comments use the HTML-style markers.
