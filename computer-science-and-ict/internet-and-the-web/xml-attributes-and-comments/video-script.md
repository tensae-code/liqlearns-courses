# Video script — XML attributes and comments

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

An element can carry more than its content.
Inside its start tag, an attribute: a name, and a value.
personid equals 101. The value wears quotes.
And a comment: a note for the human reader.
The parser ignores the comment. The code runs the same.
Attributes inform. Comments explain. Neither is the data.
