# JavaScript — Making Pages Interactive — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is JavaScript's layer in a web page?**
**Answer: Behaviour — the layer that makes the page respond**

**2. (Sub lesson 1) Where does a page's JavaScript run?**
**Answer: In the visitor's browser**

**3. (Sub lesson 1) What wakes a script?**
**Answer: An event — a click, a key press, a form sent**

**4. (Sub lesson 1) What can a script change without reloading the page?**
**Answer: What is shown or hidden, calculations, warnings — the page on the spot**

**5. (Sub lesson 1) What are the three layers, in Egypt's order?**
**Answer: HTML structure, CSS presentation, JavaScript behaviour**

**6. (Sub lesson 2) What are a first script's four moves?**
**Answer: An event wakes it, it reads the page's values, decides, and acts**

**7. (Sub lesson 2) Why is form checking the classic first JavaScript job?**
**Answer: The visitor is answered immediately by their own browser, with no round trip to the server**

**8. (Sub lesson 2) What does the course's quiz app use JavaScript for?**
**Answer: Asking, checking and scoring — the page's mind**

**9. (Sub lesson 2) What do HTML and CSS give the quiz app?**
**Answer: Its face — structure and presentation**

**10. (Sub lesson 2) Can an HTML-and-CSS page react to a click by itself?**
**Answer: No — without JavaScript it is fixed at the moment it loads**
