# JavaScript — Making Pages Interactive — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is JavaScript's layer in a web page?**
a) Behaviour — the layer that makes the page respond  b) In the visitor's browser  c) An event — a click, a key press, a form sent  d) What is shown or hidden, calculations, warnings — the page on the spot
**Answer: a) Behaviour — the layer that makes the page respond**

**2. (Sub lesson 1) Where does a page's JavaScript run?**
a) An event — a click, a key press, a form sent  b) In the visitor's browser  c) What is shown or hidden, calculations, warnings — the page on the spot  d) HTML structure, CSS presentation, JavaScript behaviour
**Answer: b) In the visitor's browser**

**3. (Sub lesson 1) What wakes a script?**
a) What is shown or hidden, calculations, warnings — the page on the spot  b) HTML structure, CSS presentation, JavaScript behaviour  c) An event — a click, a key press, a form sent  d) An event wakes it, it reads the page's values, decides, and acts
**Answer: c) An event — a click, a key press, a form sent**

**4. (Sub lesson 1) What can a script change without reloading the page?**
a) HTML structure, CSS presentation, JavaScript behaviour  b) An event wakes it, it reads the page's values, decides, and acts  c) The visitor is answered immediately by their own browser, with no round trip to the server  d) What is shown or hidden, calculations, warnings — the page on the spot
**Answer: d) What is shown or hidden, calculations, warnings — the page on the spot**

**5. (Sub lesson 1) What are the three layers, in Egypt's order?**
a) HTML structure, CSS presentation, JavaScript behaviour  b) An event wakes it, it reads the page's values, decides, and acts  c) The visitor is answered immediately by their own browser, with no round trip to the server  d) Asking, checking and scoring — the page's mind
**Answer: a) HTML structure, CSS presentation, JavaScript behaviour**

**6. (Sub lesson 2) What are a first script's four moves?**
a) The visitor is answered immediately by their own browser, with no round trip to the server  b) An event wakes it, it reads the page's values, decides, and acts  c) Asking, checking and scoring — the page's mind  d) Its face — structure and presentation
**Answer: b) An event wakes it, it reads the page's values, decides, and acts**

**7. (Sub lesson 2) Why is form checking the classic first JavaScript job?**
a) Asking, checking and scoring — the page's mind  b) Its face — structure and presentation  c) The visitor is answered immediately by their own browser, with no round trip to the server  d) No — without JavaScript it is fixed at the moment it loads
**Answer: c) The visitor is answered immediately by their own browser, with no round trip to the server**

**8. (Sub lesson 2) What does the course's quiz app use JavaScript for?**
a) Its face — structure and presentation  b) No — without JavaScript it is fixed at the moment it loads  c) Behaviour — the layer that makes the page respond  d) Asking, checking and scoring — the page's mind
**Answer: d) Asking, checking and scoring — the page's mind**

**9. (Sub lesson 2) What do HTML and CSS give the quiz app?**
a) Its face — structure and presentation  b) No — without JavaScript it is fixed at the moment it loads  c) Behaviour — the layer that makes the page respond  d) In the visitor's browser
**Answer: a) Its face — structure and presentation**

**10. (Sub lesson 2) Can an HTML-and-CSS page react to a click by itself?**
a) Behaviour — the layer that makes the page respond  b) No — without JavaScript it is fixed at the moment it loads  c) In the visitor's browser  d) An event — a click, a key press, a form sent
