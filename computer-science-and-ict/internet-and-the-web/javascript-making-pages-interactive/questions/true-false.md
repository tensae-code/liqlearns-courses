# JavaScript — Making Pages Interactive — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is JavaScript's layer in a web page?" is: Behaviour — the layer that makes the page respond**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Where does a page's JavaScript run?" is: An event — a click, a key press, a form sent**
**Answer: False** — In the visitor's browser

**3. (Sub lesson 1) True or false: the answer to "What wakes a script?" is: An event — a click, a key press, a form sent**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What can a script change without reloading the page?" is: HTML structure, CSS presentation, JavaScript behaviour**
**Answer: False** — What is shown or hidden, calculations, warnings — the page on the spot

**5. (Sub lesson 1) True or false: the answer to "What are the three layers, in Egypt's order?" is: HTML structure, CSS presentation, JavaScript behaviour**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What are a first script's four moves?" is: The visitor is answered immediately by their own browser, with no round trip to the server**
**Answer: False** — An event wakes it, it reads the page's values, decides, and acts

**7. (Sub lesson 2) True or false: the answer to "Why is form checking the classic first JavaScript job?" is: The visitor is answered immediately by their own browser, with no round trip to the server**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does the course's quiz app use JavaScript for?" is: Its face — structure and presentation**
**Answer: False** — Asking, checking and scoring — the page's mind

**9. (Sub lesson 2) True or false: the answer to "What do HTML and CSS give the quiz app?" is: Its face — structure and presentation**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Can an HTML-and-CSS page react to a click by itself?" is: Behaviour — the layer that makes the page respond**
**Answer: False** — No — without JavaScript it is fixed at the moment it loads
