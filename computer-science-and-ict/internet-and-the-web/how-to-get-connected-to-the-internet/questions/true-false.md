# How to Get Connected to the Internet — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Is a computer alone on the Internet?" is: No — a connection must join it to the network**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does a modem do?" is: Entry to the Internet through its permanently connected machines, by subscription, with a username and password**
**Answer: False** — Translates between the computer's digital signals and the telephone line's signals

**3. (Sub lesson 1) True or false: the answer to "What does an ISP give you?" is: Entry to the Internet through its permanently connected machines, by subscription, with a username and password**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How many things does the book's connection take?" is: Because browsing and e-mail all stand on this joining**
**Answer: False** — Four — device, modem, line, and an ISP account

**5. (Sub lesson 1) True or false: the answer to "Why is this lesson taught before the Web lessons?" is: Because browsing and e-mail all stand on this joining**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is set up on the computer?" is: The modem has dialled, the ISP has checked the account, and the computer is connected**
**Answer: False** — The ISP's number and the account's username and password

**7. (Sub lesson 2) True or false: the answer to "What does 'online' mean here?" is: The modem has dialled, the ISP has checked the account, and the computer is connected**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is the checking order when a connection fails?" is: Because dial-up connection time was paid for**
**Answer: False** — Line plugged in and free, modem answering, username and password exactly right, account live

**9. (Sub lesson 2) True or false: the answer to "Why did the book's world connect, work, and disconnect?" is: Because dial-up connection time was paid for**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What has not changed about the joining?" is: No — a connection must join it to the network**
**Answer: False** — Its four-part shape — device, carrier, line, account
