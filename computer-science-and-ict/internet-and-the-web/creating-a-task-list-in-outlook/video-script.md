# Video script — Creating a Task List in Outlook

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A task list in Outlook is the program's to-do list: each task has a subject, a date, and a state, so work to be done is written down, dated and ticked off as it is finished The learner creates tasks, gives them dates, and works the list — marking tasks complete as they are done Because unlisted jobs are forgotten jobs; the task list turns intentions into dated, checkable work.
