# Creating a Task List in Outlook — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is creating a task list?**
**Answer: A task list in Outlook is the program's to-do list: each task has a subject, a date, and a state, so work to be done is written down, dated and ticked off as it is finished**

**2. (Sub lesson 1) What is the key work in creating a task list?**
**Answer: The learner creates tasks, gives them dates, and works the list — marking tasks complete as they are done**

**3. (Sub lesson 1) Where does South Sudan teach creating a task list?**

**4. (Sub lesson 1) Why does creating a task list matter?**
**Answer: Because unlisted jobs are forgotten jobs; the task list turns intentions into dated, checkable work**

**5. (Sub lesson 1) What should a learner remember about creating a task list?**
**Answer: The book's own order for creating a task list — and how to show it in practice, not only name it**
