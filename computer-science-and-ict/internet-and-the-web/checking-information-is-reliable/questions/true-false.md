# Checking Information Is Reliable — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "When is information reliable?" is: When it is true, current enough for the question, and from a source that knows and can be checked**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Why does Egypt call searching a journey?" is: No — stale pages, dressed-up guesses and repeated opinion fail the same test**
**Answer: False** — A search rarely arrives in one step — the searcher compares at each stage, like a traveller checking signs

**3. (Sub lesson 1) True or false: the answer to "Is unreliable information always a lie?" is: No — stale pages, dressed-up guesses and repeated opinion fail the same test**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is the source check?" is: Whether another, independent source says the same**
**Answer: False** — Who published it, and would they know — named, expert sources outrank unnamed copiers

**5. (Sub lesson 1) True or false: the answer to "What is the agreement check?" is: Whether another, independent source says the same**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is one page, in evidence terms?" is: When it was made or updated, and whether the question needs newer**
**Answer: False** — A claim — two independent pages are evidence

**7. (Sub lesson 2) True or false: the answer to "What is the date check?" is: When it was made or updated, and whether the question needs newer**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Name Egypt's three young-searcher checks?" is: Research reports and bibliographic work — the same checks grown up**
**Answer: False** — Source, agreement and date

**9. (Sub lesson 2) True or false: the answer to "What later course lessons grow from these checks?" is: Research reports and bibliographic work — the same checks grown up**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is this lesson's real product — a warning or a habit?" is: When it is true, current enough for the question, and from a source that knows and can be checked**
**Answer: False** — A habit — checking everything that will be used
