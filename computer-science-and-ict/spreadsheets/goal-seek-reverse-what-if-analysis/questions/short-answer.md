# Goal Seek — Reverse What-If Analysis — short answer

**1. (Sub lesson 1) What is reverse What-If Analysis (Goal Seek)?**
**Answer: Goal Seek is reverse what-if analysis: instead of changing an input to see the result, you state the result you want and Excel works backwards to the input that produces it**

**2. (Sub lesson 1) What is the key work in reverse What-If Analysis (Goal Seek)?**
**Answer: The learner sets the target cell, the value it must reach, and the input cell Excel may change — then lets Goal Seek find the input value**
