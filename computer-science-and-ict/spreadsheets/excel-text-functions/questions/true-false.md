# Excel Text Functions — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Takes the first n characters of a text**
**Answer: True**

**2. (Sub lesson 1) True or false: Takes the first n characters of a text** — as the answer to: What does FIND report?
**Answer: False — The position of a piece inside a text (or an error if absent)**

**3. (Sub lesson 1) True or false: Find the separator, cut at it**
**Answer: True**

**4. (Sub lesson 1) True or false: Find the separator, cut at it** — as the answer to: What does SUBSTITUTE swap?
**Answer: False — Every occurrence of one piece for another**

**5. (Sub lesson 1) True or false: Position (FIND), cut (LEFT), replace (SUBSTITUTE)**
**Answer: True**

**6. (Sub lesson 2) True or false: Position (FIND), cut (LEFT), replace (SUBSTITUTE)** — as the answer to: What does TRIM remove?
**Answer: False — Extra spaces — leading, trailing and doubled**

**7. (Sub lesson 2) True or false: They make the same city count as two**
**Answer: True**

**8. (Sub lesson 2) True or false: They make the same city count as two** — as the answer to: What do UPPER and LOWER force?
**Answer: False — A text wholly into capitals or small letters**

**9. (Sub lesson 2) True or false: Analysis dies of dirty text — these do the cleaning**
**Answer: True**

**10. (Sub lesson 2) True or false: Analysis dies of dirty text — these do the cleaning** — as the answer to: What is the kit's audit virtue?
**Answer: False — Cleaning by formula is auditable by anyone**
