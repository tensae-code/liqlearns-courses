Sub lesson 1 questions from the type files. Pass mark: Takes the first n characters of a text; The position of a piece inside a text (or an error if absent); Find the separator, cut at it; Every occurrence of one piece for another; Position (FIND), cut (LEFT), replace (SUBSTITUTE).
