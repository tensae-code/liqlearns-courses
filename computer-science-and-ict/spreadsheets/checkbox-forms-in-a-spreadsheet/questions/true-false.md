# Checkbox Forms in a Spreadsheet — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A sheet area with controls a person operates, not only cells to type in**
**Answer: True**

**2. (Sub lesson 1) True or false: A sheet area with controls a person operates, not only cells to type in** — as the answer to: What is a checkbox?
**Answer: False — A small box that is ticked or unticked with a click**

**3. (Sub lesson 1) True or false: A customer form for a travel company's quotation program**
**Answer: True**

**4. (Sub lesson 1) True or false: A customer form for a travel company's quotation program** — as the answer to: What is ticked on the book's form?
**Answer: False — What the trip includes — meals, guide, insurance**

**5. (Sub lesson 1) True or false: Its friendly face**
**Answer: True**

**6. (Sub lesson 2) True or false: Its friendly face** — as the answer to: What does a linked cell read?
**Answer: False — TRUE when the box is ticked, FALSE when it is not**

**7. (Sub lesson 2) True or false: An IF adds a cost only when its box is ticked, for example**
**Answer: True**

**8. (Sub lesson 2) True or false: An IF adds a cost only when its box is ticked, for example** — as the answer to: What three rules make a form good?
**Answer: False — Labels a stranger understands, boxes grouped by meaning, nothing required left ambiguous**

**9. (Sub lesson 2) True or false: The quotation — the project's cost estimate**
**Answer: True**

**10. (Sub lesson 2) True or false: The quotation — the project's cost estimate** — as the answer to: What is the quotation only as honest as?
**Answer: False — The form's ticks**
