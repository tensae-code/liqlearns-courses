# Relative cell references — multiple choice

Pick the one right answer.

**1.** A relative reference adjusts when —
a) the screen is resized  b) the formula is copied, or rows/columns are inserted or deleted  c) the file is printed  d) never
**Answer: b) the formula is copied, or rows/columns are inserted or deleted**

**2.** The total for row 2 is built in —
a) E2  b) F2  c) B2  d) G2
**Answer: b) F2**

**3.** The total formula is —
a) =B2*C2*D2*E2  b) =B2+C2+D2+E2  c) B2+C2+D2+E2  d) =F2+B2
**Answer: b) =B2+C2+D2+E2**

**4.** Why is clicking cells recommended over typing them?
a) it uses less memory  b) it is quicker and typo-proof  c) it prints better  d) it is the only way
**Answer: b) it is quicker and typo-proof**

**5.** Typing b4 gives —
a) an error  b) B4 — case does not matter  c) a new sheet  d) nothing
**Answer: b) B4 — case does not matter**

**6.** At Grade 10, relative vs absolute references are taught —
a) throughout the unit body  b) only in the Unit 3 summary  c) in Unit 1  d) not at all
**Answer: b) only in the Unit 3 summary** — the unit body never covers the topic; the summary states it.

**7.** In the summary's contrast, a relative reference —
a) stays fixed  b) changes as a formula is copied  c) is deleted  d) becomes text
**Answer: b) changes as a formula is copied**
