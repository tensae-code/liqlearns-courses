# Hands-on — Inserting and Deleting Cells, Rows and Columns

The lesson with your hands, on a real computer running Excel 2007 where one is available — the book's own split: theory in class, hands-on in the lab.

## The class list
Type a list of five names with a mark beside each. A sixth pupil belongs between the second and third names: insert a row there and type the new name and mark. Check that every pupil below moved down with their own mark still beside their own name.

## Shift, both ways
In a small block of numbers, insert one cell shifting the others right; undo it, and insert again shifting down. Say what changed in the block's shape each time. Then delete the inserted cell each way — left, then up — until the block is back to its first shape.

## Several at once, and out again
Select two rows together and insert: count the new rows. Add a column to the left of the marks column in one move. Then delete the column you added and one of the rows you added, using the headings, and confirm the table closes up with no empty line left inside it.
