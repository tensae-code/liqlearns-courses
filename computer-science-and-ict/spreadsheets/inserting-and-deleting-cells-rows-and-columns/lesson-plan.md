# Lesson plan — Inserting and Deleting Cells, Rows and Columns

**Course:** Computer Science and ICT · **Title:** Spreadsheets · **Lesson:** Inserting and Deleting Cells, Rows and Columns
**Place in the curriculum:** ICT expansion — Eritrea (2026-11-14) — in the title Spreadsheets on the ICT course ladder (TITLES.md). Built new from Eritrea's *Information and Communications Technology for Grade 8 — Textbook*, because no existing lesson teaches this thing as its own lesson.
**The one thing this lesson teaches:** A worksheet can be modified after it is built: insert cells and the neighbours shift right or down to make room, delete cells and the neighbours shift left or up to close the gap — and whole rows and columns insert and delete the same way, a row appearing above the place you chose and a column to its left, in Excel 2007 from the Home tab's Insert and Delete tools or by right-clicking.
**This lesson's own level:** It stands on knowing what cells, rows and columns are and how to select them; everything about inserting and deleting them — including the shift choices the dialog offers — is built inside the lesson, in Excel 2007, the version Eritrea's book teaches.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Inserting and deleting cells** — Select the cell where room is needed; Home tab → Insert → Insert Cells opens a small dialog: shift the existing cells right, or shift them down (or take a whole row or column). Deleting mirrors it: Home tab → Delete → Delete Cells, and the dialog asks which way the remaining cells should shift to close the gap — left, or up. The sheet is never left with a hole; everything moves together, formulas travelling with their cells.
2. **Inserting and deleting rows and columns** — Select a cell in the row — or the row's number heading itself: Home tab → Insert → Insert Sheet Rows puts a whole new row above the chosen one; Insert Sheet Columns puts a whole new column to the left. Selecting several rows or columns first inserts that many at once. Deleting is the mirror: select the row or column heading and Home tab → Delete → Delete Sheet Rows / Delete Sheet Columns removes it whole, and everything below or beside it moves up or across to close the space. Right-clicking a heading offers the same Insert and Delete.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## What the learner can do when it ends
1. Insert cells, choosing whether the existing cells shift right or down, and say what happens to the cells that were there.
2. Delete cells, choosing whether the remaining cells shift left or up to close the gap.
3. Insert a row above a chosen place and a column to the left of a chosen place, and insert several at once by selecting several first.
4. Delete whole rows and columns, and say why deleting cells is not the same as clearing their contents.

## What you need
A computer running Microsoft Excel 2007 for the hands-on work (the book's own version). On paper first: a drawn grid and paper slips make the shifting visible before a real sheet is touched.

## If the learner is stuck
Inserts a row and expects it below the selection → a new row appears above the chosen row, and a new column to the left of the chosen column; choose the place with that rule in mind. Uses Delete on the keyboard expecting the cells to vanish → the Delete key only clears contents, leaving empty cells; removing the cells themselves — so neighbours shift in — is Delete Cells / Delete Sheet Rows from the Home tab or right-click. Fears losing data when inserting → inserting moves existing cells aside, it does not overwrite them; check the shift direction in the dialog before confirming.
