# Spreadsheets — data in rows, columns and cells — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** A cell is where a row and a column meet.
**Answer: True** — one box, at the crossing of one row and one column.

**2. (Sub lesson 1)** A spreadsheet can only store data; it cannot calculate.
**Answer: False** — it calculates values with formulas in the cells.

**3. (Sub lesson 2)** A spreadsheet is used to sort data.
**Answer: True** — sorting, manipulating and arranging data is its work.
