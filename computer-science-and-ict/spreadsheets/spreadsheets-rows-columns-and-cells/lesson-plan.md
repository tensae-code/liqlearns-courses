# Lesson plan — Spreadsheets — data in rows, columns and cells

**Course:** Computer Science and ICT · **Title:** Spreadsheets · **Lesson:** Spreadsheets — data in rows, columns and cells
**Place in the curriculum:** Title 6 — Spreadsheets in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 8 book, Unit 3 — Computer Software. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** a spreadsheet organises and calculates data in cells — a data file of rows and columns that sorts data and lets the user manipulate and arrange it easily, calculating values with formulas.
**This lesson's own level:** it opens the Spreadsheets title. It stands on application software — the spreadsheet is the application kind that works on data in tables.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **What a spreadsheet is** — an application to organise and calculate data in cells; a data file of rows and columns, used to sort data and let a user manipulate and arrange data easily, calculating values with mathematical formulas in the cells
2. **Its parts, and tables** — on opening, its important buttons, rows, columns and headers appear; it creates tables in rows and columns so data can be analysed quickly and easily

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Application software — programs for particular jobs. Recommended, never forced.

## What the learner can do when it ends
1. Say what a spreadsheet is and what it is used for.
2. Point to a row, a column and a cell, and name each.
3. Say how a spreadsheet calculates: with mathematical formulas in the cells.
4. Say why data kept in tables of rows and columns can be analysed quickly and easily.

## What you need
Paper and a pencil; a computer with a spreadsheet program, if you can look at one.

## If the learner is stuck
- Mixes up row and column → a row runs across, a column runs down; the cell is the one box where a row and a column meet.
- Thinks a spreadsheet is only a table for looking at → it also calculates: values are worked out by formulas in the cells.
