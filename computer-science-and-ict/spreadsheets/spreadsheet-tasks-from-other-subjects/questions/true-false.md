# Spreadsheet Tasks from Other Subjects — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What kinds of tasks does this practicum use?" is: Calculation tasks from different subject areas.**
**Answer: True**

**Answer: False** — Once — the sheet recalculates it for every row.
