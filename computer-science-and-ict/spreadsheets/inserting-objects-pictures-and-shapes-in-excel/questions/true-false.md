# Inserting Objects — Pictures and Shapes in Excel — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does inserting objects mean?" is: Bringing things that are not cell data into the worksheet**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Name the two main kinds of object inserted." is: It can be moved and sized where the worksheet needs it**
**Answer: False** — Pictures and shapes

**3. (Sub lesson 1) True or false: the answer to "Where does an inserted object sit?" is: On the sheet, over the grid**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What can be done with an inserted object?" is: The real thing the numbers are about**
**Answer: False** — It can be moved and sized where the worksheet needs it

**5. (Sub lesson 1) True or false: the answer to "What carries on underneath an object?" is: The cells and their values**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does a picture show?" is: An arrow and a box (or a callout)**
**Answer: False** — The real thing the numbers are about

**7. (Sub lesson 2) True or false: the answer to "What does a shape do? Give one job." is: It points, groups or explains**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Name two example shapes." is: Laying out the worksheet for printing**
**Answer: False** — An arrow and a box (or a callout)

**9. (Sub lesson 2) True or false: the answer to "Where does the book place this lesson in the Excel unit?" is: In the formatting part — after data is entered and formatted**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What comes after objects in the unit?" is: Pictures and shapes**
**Answer: False** — Laying out the worksheet for printing
