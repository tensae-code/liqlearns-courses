# Lesson plan — Spreadsheet functions — SUM, AVERAGE, MAX, MIN

**Course:** Computer Science and ICT · **Title:** Spreadsheets · **Lesson:** Spreadsheet functions — SUM, AVERAGE, MAX, MIN
**Place in the curriculum:** Title 6 — Spreadsheets in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 8 book, Unit 3 — Computer Software. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** functions are predefined formulas with a fixed shape — =, the function name, an opening parenthesis, the arguments separated by commas, a closing parenthesis — and the named ones are sum, average, maximum and minimum.
**This lesson's own level:** it is a doing-lesson. It stands on Spreadsheet formulas — a function is a formula already written for you, waiting for its arguments.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. ## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **What a function is** — a predefined formula with a fixed shape: =, the function name, an opening parenthesis, the arguments separated by commas, a closing parenthesis; the named functions are sum, average, maximum and minimum
2. **Totalling a column — =SUM(C3:C6), and your own table** — the worked example totals a column as =SUM(C3:C6); the activity builds a pupil table — name, age, gender, grade, two test scores — and finds the sum of the tests

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Spreadsheet formulas — starting with =. Recommended, never forced.

## What the learner can do when it ends
1. Say what a function is and write its shape: =, name, (, arguments separated by commas, ).
2. Name the four functions: sum, average, maximum, minimum.
3. Read =SUM(C3:C6) part by part and say what it totals.
4. Build a pupil table — name, age, gender, grade and two test scores — and find the sum of the tests in the spreadsheet.

## What you need
A computer with a spreadsheet program — this lesson is learned by doing it.

## If the learner is stuck
- Writes SUM without the equal sign → a function begins with = like every formula.
- Separates arguments with spaces or full stops → the arguments are separated by commas, inside the parentheses.
