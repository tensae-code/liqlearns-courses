# Spreadsheet functions — SUM, AVERAGE, MAX, MIN — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A function is —
a) a typed number  b) a predefined formula  c) a kind of cell  d) a chart title
**Answer: b) a predefined formula** — already written, waiting for its arguments.

**2. (Sub lesson 1)** A function begins with —
a) its name  b) an opening parenthesis  c) an equal sign  d) a comma
**Answer: c) an equal sign** — like every formula.

**3. (Sub lesson 1)** The arguments of a function are separated by —
a) spaces  b) commas  c) full stops  d) minus signs
**Answer: b) commas** — inside the parentheses.

**4. (Sub lesson 1)** Which list names the book's four functions?
a) sum, average, maximum, minimum  b) copy, cut, paste, delete  c) open, save, print, close  d) add, plus, total, count
**Answer: a) sum, average, maximum, minimum.**

**5. (Sub lesson 2)** =SUM(C3:C6) totals —
a) one cell only  b) the values in the range C3 to C6  c) every cell in the sheet  d) the row C only
**Answer: b) the values in the range C3 to C6** — the argument names the cells to total.
