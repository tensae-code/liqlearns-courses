# Spreadsheet functions — SUM, AVERAGE, MAX, MIN — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** A function ends with a closing parenthesis.
**Answer: True** — the shape is =, name, (, arguments, ).

**2. (Sub lesson 1)** MAX finds the smallest value and MIN the biggest.
**Answer: False** — MAX is maximum, the biggest; MIN is minimum, the smallest.

**3. (Sub lesson 2)** In the activity, pupils find the sum of two test scores in a table they entered themselves.
**Answer: True** — name, age, gender, grade and two test scores, then the sum of the tests.
