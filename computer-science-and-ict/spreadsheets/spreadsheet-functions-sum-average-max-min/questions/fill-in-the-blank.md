# Spreadsheet functions — SUM, AVERAGE, MAX, MIN — fill in the blank

Fill each blank with the right word.

**1. (Sub lesson 1)** Functions are ______ formulas — already written for you.
**Answer: predefined**

**2. (Sub lesson 1)** After the function name comes an opening ______.
**Answer: parenthesis**

**3. (Sub lesson 2)** The function that totals values is ______.
**Answer: SUM**

**4. (Sub lesson 3)** The typed route ends by pressing ______.
**Answer: Enter**

**5. (Sub lesson 3)** Several arguments in one function are separated by ______.
**Answer: commas**
