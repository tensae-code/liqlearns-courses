# Hands-on — Spreadsheet functions — SUM, AVERAGE, MAX, MIN

The lesson with your hands, not only your eyes.

## The class table

Build the activity table for five classmates (or invent five pupils): name, age, gender, grade, Test 1, Test 2. Add a Sum column and total each pupil's two tests with SUM. Check one row by hand.

## Four questions, four functions

On one column of test scores, ask the sheet four questions: SUM for the total, AVERAGE for the middle value, MAX for the top score, MIN for the lowest. Write the four function formulas on paper first, with their arguments — then type them and compare answers.

## All five over the grade record (Grade 10 depth)

Take a students' grade record table. Under it, compute all five: SUM, AVERAGE, COUNT, MAX, MIN — first by typing each function, then delete one and restore it with AutoSum, checking the guessed range before you press Enter. COUNT's answer is a count of numeric cells: check it against the number of pupils with marks.
