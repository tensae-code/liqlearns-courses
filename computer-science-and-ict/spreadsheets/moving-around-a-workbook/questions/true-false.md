# Moving Around a Workbook — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is the active cell?" is: The cell with the thick border — the cell you are working in**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What do the arrow keys do in a sheet?" is: Returns the active cell to A1, the start of the sheet**
**Answer: False** — Move the active cell one cell at a time

**3. (Sub lesson 1) True or false: the answer to "What does Ctrl+Home do?" is: Returns the active cell to A1, the start of the sheet**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How does the Name Box move you?" is: Scrolling changes what you see; moving changes which cell is active**
**Answer: False** — Type a cell reference such as M50 and press Enter — the active cell jumps there

**5. (Sub lesson 1) True or false: the answer to "What is the difference between scrolling and moving?" is: Scrolling changes what you see; moving changes which cell is active**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Where are a workbook's sheets found?" is: Click its sheet tab**
**Answer: False** — Behind the sheet tabs at the bottom of the window

**7. (Sub lesson 2) True or false: the answer to "How do you bring another sheet to the front?" is: Click its sheet tab**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What are the tab arrows for?" is: Tabs between sheets; keys and the Name Box inside a sheet**
**Answer: False** — Scrolling the row of sheet tabs when there are too many to show

**9. (Sub lesson 2) True or false: the answer to "What are the two halves of moving around a workbook?" is: Tabs between sheets; keys and the Name Box inside a sheet**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why does Fiji teach moving before creating?" is: The cell with the thick border — the cell you are working in**
**Answer: False** — A learner who cannot travel cannot check, correct or find anything in a big workbook
