**The one thing this lesson teaches:** Conditional formatting colours cells by their values: you set a rule — above average, below average, unique, duplicate, or a new rule of your own — and Excel highlights every cell that meets it, changing the colours by itself when the values change.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Highlighting by rule** — **Conditional formatting** means the **formatting follows a condition**: if a cell's value meets the **rule**, the cell is **highlighted** — filled or coloured — automatically. Ready-made rules highlight values **above average** or **below average**, and pick out **unique** values or **duplicate** values in a range.
2. **Making a new rule — and living colours** — When no ready rule fits, you build a **new formatting rule**: state the condition and the formatting it triggers. The deep point of the lesson: the colours are **alive** — edit a value so it crosses the rule, and its highlighting appears or disappears by itself, because the rule watches the values, not the colours.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
