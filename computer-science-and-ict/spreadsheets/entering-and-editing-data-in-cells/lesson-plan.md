# Lesson plan — Entering and Editing Data in Cells

**Course:** Computer Science and ICT · **Title:** Spreadsheets · **Lesson:** Entering and Editing Data in Cells
**Place in the curriculum:** ICT expansion — Belarus (2026-11-14) — in the title Spreadsheets on the ICT course ladder (TITLES.md). Built new from Belarus's *Інфарматыка* Grade 10, because no existing lesson in the course covers this thing as its own lesson.
**The one thing this lesson teaches:** Entering data means selecting a cell, typing, and confirming the entry; editing means changing what a cell already holds — by retyping it, or by correcting it in place in the cell or the formula bar — without disturbing its neighbours.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Entering data** — To **enter** data: select the cell, type the text, number or formula, and confirm — with Enter, which moves the selection down, or with another movement key, which confirms and moves that way. While you type, the entry is not yet in the cell: it can be cancelled, and it shows in the **formula bar** as you work. Typing into an occupied cell and confirming **replaces** its old content completely — entry is always whole-cell, never an addition to what was there.
2. **Editing what is already there** — **Editing** changes an existing entry without retyping all of it: double-click the cell (or use the formula bar) and the entry opens for correction — move the cursor inside it, delete or insert characters, and confirm. Editing is the right tool for a long formula with one wrong reference, or a label with one wrong letter. The section closes with the workbook itself: a finished sheet is kept by **saving the workbook**, so the entered and edited data survives the program closing — unsaved work exists only while the program stays open.

## The run of the lesson (in order)
1. **Do it first** — A sheet with two hundred entries has one wrong digit. Retyping the whole entry risks a new mistake; in this lesson you learn to enter data cleanly and to edit a cell in place — and to save the workbook so the work stays done. (lesson/lesson.md).
2. **The explanation** — the lesson text in lesson/lesson.md, in its parts in order.
   - ADD IMAGE: a picture of a selected cell with typed numbers appearing in it and in the formula bar above the sheet — the student studies the picture and names what each part shows.
   - ADD GIF: a GIF of a long entry opened for editing with the cursor blinking in its middle, one letter being corrected — the student watches once, then says what changed and why.
   - ADD AUDIO: a voice reading the lesson's key names and definitions aloud, in the order the lesson gives them — the student listens once through, then reads the same lines aloud along with the voice. (Audio is a described slot in this build; no audio file is made.)
