# Formatting cells — alignment, borders, fill and number formats — true or false

Say true or false.

**1. (Sub lesson 1)** There are three horizontal and three vertical alignments.
**Answer: True**

**2. (Sub lesson 2)** A number format changes the value itself.
**Answer: False** — it changes how the value displays — 0.5 can show as 50%.

**3. (Sub lesson 2)** The closing practical uses Tahoma at size 32.
**Answer: True**
