# Formatting cells — alignment, borders, fill and number formats — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** By nature, text in a cell sits —
a) top-right  b) bottom-left  c) centred  d) top-left
**Answer: b) bottom-left** — numbers sit bottom-right.

**2. (Sub lesson 1)** Hand-drawn border lines come from —
a) Cell Styles  b) Draw Borders tools  c) Number Format  d) Freeze Panes
**Answer: b) Draw Borders tools**

**3. (Sub lesson 1)** Fill Color paints —
a) the letters  b) the cell's background  c) the border  d) the whole sheet
**Answer: b) the cell's background**

**4. (Sub lesson 2)** Cell Styles apply —
a) one border at a time  b) professional title/header formatting in one selection  c) a chart style  d) a filter
**Answer: b) professional title/header formatting in one selection**

**5. (Sub lesson 2)** Number formats are set from —
a) the Font Color dropdown  b) the Number Format dropdown  c) the Borders dropdown  d) the View tab
**Answer: b) the Number Format dropdown**
