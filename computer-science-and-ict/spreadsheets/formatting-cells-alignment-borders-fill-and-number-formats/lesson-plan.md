# Lesson plan — Formatting cells — alignment, borders, fill and number formats

**Course:** Computer Science and ICT · **Title:** Spreadsheets · **Lesson:** Formatting cells — alignment, borders, fill and number formats
**Place in the curriculum:** Unit 3 — Application Software, Grade 10 depth, in the Spreadsheets title of the Computer Science and ICT ladder (TITLES.md). The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** content is positioned inside the cell by horizontal and vertical alignment, framed by borders, backed by fill colour — or dressed in one pick by Cell Styles — and number formats tell Excel what kind of data a value is.
**This lesson's own level:** it is a doing-lesson. It stands on Formatting cells — fonts and emphasis; this lesson positions, frames and classifies what the last lesson dressed.

The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. ## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Alignment, borders and fill** — pass mark: align content both ways, add and draw borders, and fill a cell's background.
2. **Cell Styles and number formats** — pass mark: apply a Cell Style and set number formats so a value displays in its proper form.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Formatting cells — fonts and emphasis. Recommended, never forced.

## What the learner can do when it ends
1. Align content three ways horizontally and three ways vertically.
2. Add borders from the dropdown and draw borders by hand.
3. Paint a cell's background with Fill Color.
4. Apply a Cell Style in one selection, and set a number format so a value displays as date, percentage or currency.

## What you need
A computer with Excel.

## If the learner is stuck
- The number will not show as a percentage → it was typed as text or the format was not applied; use the Number Format dropdown on the selected cell.
- Fill covered the words → Fill Color paints the background only; if the text vanished, the font colour matches the fill — change one of them.
