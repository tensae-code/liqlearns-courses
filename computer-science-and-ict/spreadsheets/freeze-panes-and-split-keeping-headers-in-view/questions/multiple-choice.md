# Freeze panes and Split — keeping headers in view — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** To freeze a header row, select —
a) the header row itself  b) the row below it  c) the last row  d) the whole sheet
**Answer: b) the row below it** — what is above the selection freezes.

**2. (Sub lesson 1)** Freeze Panes is on —
a) the Data tab  b) the Insert tab  c) the View tab  d) the Home tab
**Answer: c) the View tab**

**3. (Sub lesson 1)** The frozen part is marked by —
a) a red border  b) a grey line  c) bold text  d) a new window
**Answer: b) a grey line**

**4. (Sub lesson 2)** Split is removed by —
a) Unfreeze Panes  b) clicking Split again  c) saving  d) Esc
**Answer: b) clicking Split again**

**5. (Sub lesson 2)** Split serves best for —
a) printing  b) comparing distant sections without a new window  c) adding formulas  d) hiding headings
**Answer: b) comparing distant sections without a new window**
