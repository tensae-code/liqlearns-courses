# Freeze panes and Split — keeping headers in view — true or false

Say true or false.

**1. (Sub lesson 1)** While frozen, scrolling continues beneath or beside the frozen part.
**Answer: True**

**2. (Sub lesson 2)** Each split pane scrolls independently.
**Answer: True**

**3. (Sub lesson 1)** Freeze Panes opens a new window for the headings.
**Answer: False** — the frozen part stays in the same window, above a grey line.
