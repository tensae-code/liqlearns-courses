# Worksheet Tabs — Adding, Renaming and Moving — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Clicking a worksheet tab brings that sheet to the front, ready to work on.**
**Answer: True**

**2. (Sub lesson 1) A new sheet added with right-click → Insert appears before the tab that was right-clicked.**
**Answer: True**

**3. (Sub lesson 2) Renaming a tab changes the contents of the sheet.**
**Answer: False** — Renaming changes only the label; the sheet's contents do not change.

**4. (Sub lesson 3) Dragging a tab moves the sheet into a different workbook.**
**Answer: False** — Dragging reorders sheets inside the same workbook; Move or Copy can send a sheet to another open workbook.
