# Hands-on — Worksheet Tabs — Adding, Renaming and Moving

The lesson with your hands, on a real computer running Excel 2007 where one is available — the book's own split: theory in class, hands-on in the lab.

## Build a term workbook
Start a new workbook. Add sheets until there are five tabs. Rename them: Term 1 Marks, Term 2 Marks, Term 3 Marks, Fees, Notes. If a name is wrong, rename it again — renaming costs nothing inside the sheet.

## Reorder twice
Move Notes to the front by dragging its tab. Then move it back to the end using right-click → Move or Copy, choosing the place before which it should sit — for the end, the move-to-end choice. Say out loud which way felt more exact, and why.

## The copy test
Use Move or Copy with Create a copy ticked to copy Fees. Check both copies hold the same content, then rename the copy Fees — Copy, so no two tabs in the workbook carry the same name. This is how a new term's sheet is started from last term's shape.
