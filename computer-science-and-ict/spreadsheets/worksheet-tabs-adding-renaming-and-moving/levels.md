# Worksheet Tabs — Adding, Renaming and Moving — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure). Practice is tied to the learner's skill number, as before. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Worksheet tabs and adding a new worksheet
Sub lesson 1 questions from the type files. Pass mark: switch between sheets by their tabs, and add a new worksheet by the Insert Worksheet button, by Shift+F11, and by right-click → Insert.

## Sub lesson 2 — Renaming a worksheet tab
Sub lesson 2 questions from the type files. Pass mark: rename a tab by double-clicking it and by right-click → Rename, typing the new name and pressing Enter.

## Sub lesson 3 — Moving and copying a worksheet
Sub lesson 3 questions from the type files. Pass mark: move a sheet by dragging its tab to the arrow's place, and move or copy it exactly with right-click → Move or Copy.
