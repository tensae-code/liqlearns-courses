# The Excel Window and Ribbon — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What fills the middle of the Excel window?" is: The worksheet of rows and columns**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What goes on the worksheet?" is: What a spreadsheet is**
**Answer: False** — The data

**3. (Sub lesson 1) True or false: the answer to "What is the Excel window called in the book?" is: The main interface of Microsoft Excel**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does the unit's first lesson teach, before this one?" is: The strip of tabs and tools for working on the worksheet**
**Answer: False** — What a spreadsheet is

**5. (Sub lesson 1) True or false: the answer to "What runs across the top of the window?" is: The ribbon**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is the ribbon?" is: Laying out the page**
**Answer: False** — The strip of tabs and tools for working on the worksheet

**7. (Sub lesson 2) True or false: the answer to "Name two kinds of work whose tools live on the ribbon." is: Formatting and inserting**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What third kind of work lives there, for a later lesson?" is: Grade 11**
**Answer: False** — Laying out the page

**9. (Sub lesson 2) True or false: the answer to "Why is the ribbon's layout learned once, early?" is: So later lessons can simply say where a tool lives**
**Answer: True**
