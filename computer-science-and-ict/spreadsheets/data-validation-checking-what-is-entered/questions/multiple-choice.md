# Data Validation — Checking What Is Entered — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is data validation?**
a) Setting the rules for what may be entered in a cell  b) A whole number in a range, a date in a period, a value from a list  c) It is refused, with a message saying why  d) A shared workbook is only as good as what others are allowed to type into it
