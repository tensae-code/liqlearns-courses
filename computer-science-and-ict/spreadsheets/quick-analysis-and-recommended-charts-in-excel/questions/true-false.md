# Quick Analysis and Recommended Charts in Excel — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "When does the Quick Analysis tool appear?" is: When you select a block of data**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does Quick Analysis offer for the selection?" is: For speed — common analyses offered in one place**
**Answer: False** — Formatting, charts, totals, tables and sparklines

**3. (Sub lesson 1) True or false: the answer to "Why does the tool exist?" is: For speed — common analyses offered in one place**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What are recommended charts?" is: The selection — categories with values, values over time**
**Answer: False** — Chart kinds Excel picks to suit the selected data

**5. (Sub lesson 1) True or false: the answer to "What does Excel read before recommending?" is: The selection — categories with values, values over time**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Who still makes the final choice of chart?" is: Which chart suits which data**
**Answer: False** — You do

**7. (Sub lesson 2) True or false: the answer to "What does previewing each suggestion teach?" is: Which chart suits which data**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Where else do recommended charts appear besides Quick Analysis?" is: Honestly — the type must fit the data**
**Answer: False** — On the Insert ribbon

**9. (Sub lesson 2) True or false: the answer to "What must a suggested chart show the data as?" is: Honestly — the type must fit the data**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is Quick Analysis a gallery of?" is: When you select a block of data**
**Answer: False** — Instant help for exactly the selected data
