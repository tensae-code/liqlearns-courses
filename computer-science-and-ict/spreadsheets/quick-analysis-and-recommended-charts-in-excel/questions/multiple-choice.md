# Quick Analysis and Recommended Charts in Excel — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) When does the Quick Analysis tool appear?**
a) When you select a block of data  b) Chart kinds Excel picks to suit the selected data  c) You do  d) On the Insert ribbon
**Answer: a) When you select a block of data**

**2. (Sub lesson 1) What does Quick Analysis offer for the selection?**
a) The selection — categories with values, values over time  b) Formatting, charts, totals, tables and sparklines  c) Which chart suits which data  d) Honestly — the type must fit the data
**Answer: b) Formatting, charts, totals, tables and sparklines**

**3. (Sub lesson 1) Why does the tool exist?**
a) You do  b) On the Insert ribbon  c) For speed — common analyses offered in one place  d) Instant help for exactly the selected data
**Answer: c) For speed — common analyses offered in one place**

**4. (Sub lesson 1) What are recommended charts?**
a) Which chart suits which data  b) Honestly — the type must fit the data  c) When you select a block of data  d) Chart kinds Excel picks to suit the selected data
**Answer: d) Chart kinds Excel picks to suit the selected data**

**5. (Sub lesson 1) What does Excel read before recommending?**
a) The selection — categories with values, values over time  b) On the Insert ribbon  c) Instant help for exactly the selected data  d) Formatting, charts, totals, tables and sparklines
**Answer: a) The selection — categories with values, values over time**

**6. (Sub lesson 2) Who still makes the final choice of chart?**

a) Honestly — the type must fit the data  b) Formatting, charts, totals, tables and sparklines  c) Chart kinds Excel picks to suit the selected data  d) You do
