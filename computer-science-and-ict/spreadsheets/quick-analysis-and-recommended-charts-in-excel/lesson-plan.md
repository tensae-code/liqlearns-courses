**The one thing this lesson teaches:** Excel helps you analyse selected data fast: the Quick Analysis tool offers formatting, charts, totals and tables for the selection in one click — and its recommended charts are chart kinds Excel picks to suit the data you selected.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The Quick Analysis tool** — Select a block of data and the **Quick Analysis** tool appears: one button opening a small gallery of instant help for exactly that selection — **formatting, charts, totals, tables** and sparklines. It exists for speed: the common analyses of a selection are offered before you go hunting through the ribbon.
2. **Recommended charts** — Inside Quick Analysis (and the Insert ribbon), **recommended charts** are the chart kinds **Excel suggests for your data**: it reads the selection — categories with values, values over time — and proposes the chart types that would show it honestly. You still choose; but the recommendation is a strong first answer, and previewing each suggestion against the data teaches which chart suits which data.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
