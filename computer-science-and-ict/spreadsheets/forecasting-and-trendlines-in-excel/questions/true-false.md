# Forecasting and Trendlines in Excel — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: By seeing — a scatter plot of the values**
**Answer: True**

**2. (Sub lesson 1) True or false: By seeing — a scatter plot of the values** — as the answer to: What is a trendline?
**Answer: False — The line that best follows the points**

**3. (Sub lesson 1) True or false: Its equation**
**Answer: True**

**4. (Sub lesson 1) True or false: Its equation** — as the answer to: How is its fit read?
**Answer: False — Points hugging the line support it; a cloud mocks it**

**5. (Sub lesson 1) True or false: A climb (or fall) that is really the season's rhythm**
**Answer: True**

**6. (Sub lesson 2) True or false: A climb (or fall) that is really the season's rhythm** — as the answer to: What does FORECAST.LINEAR return?
**Answer: False — The line's value at a future x**

**7. (Sub lesson 2) True or false: The past's pattern**
**Answer: True**

**8. (Sub lesson 2) True or false: The past's pattern** — as the answer to: Name two world-changes that break it.
**Answer: False — A competitor opens; a law changes (or a season turns)**

**9. (Sub lesson 2) True or false: The farther it reaches**
**Answer: True**

**10. (Sub lesson 2) True or false: The farther it reaches** — as the answer to: How is a forecast honestly reported?
**Answer: False — With its pattern and its doubts — 'on the trend, about X, if nothing changes'**
