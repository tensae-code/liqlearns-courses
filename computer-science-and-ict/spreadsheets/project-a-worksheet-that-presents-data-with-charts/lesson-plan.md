## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Building the group's worksheet** — The group **chooses a topic** and gathers its **real data** into a **worksheet**: tidy rows and columns, clear labels, values that can be checked. The worksheet is the project's foundation — every chart drawn from it inherits its honesty or its errors.
2. **Presenting the data with charts** — From the worksheet, the group builds the **charts that present the data**: the right chart kind for each question the topic raises, formatted so an audience reads it at a glance. Presenting means the group can walk an audience from the data to the chart to the conclusion — and answer for all three.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
