# Project — a Worksheet That Presents Data with Charts — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does the group choose first?" is: A topic**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What fills the worksheet?" is: Tidy rows and columns, clear labels, checkable values**
**Answer: False** — The topic's real data

**3. (Sub lesson 1) True or false: the answer to "What makes a good foundation worksheet?" is: Tidy rows and columns, clear labels, checkable values**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does every chart inherit from the worksheet?" is: Charts built from the worksheet**
**Answer: False** — Its honesty or its errors

**5. (Sub lesson 1) True or false: the answer to "What presents the data?" is: Charts built from the worksheet**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How is the chart kind chosen?" is: So an audience reads it at a glance**
**Answer: False** — The right kind for each question the topic raises

**7. (Sub lesson 2) True or false: the answer to "How must a chart be formatted?" is: So an audience reads it at a glance**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What walk must the group be able to make?" is: A group**
**Answer: False** — From the data to the chart to the conclusion

**9. (Sub lesson 2) True or false: the answer to "Who works on the project?" is: A group**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What must the group answer for?" is: A topic**
**Answer: False** — The data, the chart and the conclusion — all three
