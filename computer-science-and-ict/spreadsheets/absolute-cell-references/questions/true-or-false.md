# Absolute cell references — $B$9 — true or false

Say true or false.

**1.** Pressing F4 after selecting a reference can make it absolute.
**Answer: True**

**2.** When the bonus formula is copied down, $B$9 changes to $B$10, $B$11 and so on.
**Answer: False — $B$9 stays fixed for all rows; the relative cells change.**

**3.** At Grade 10 the relative/absolute contrast is summary content, not body-taught content.
**Answer: True — flagged as summary-only in this lesson's sources.**
