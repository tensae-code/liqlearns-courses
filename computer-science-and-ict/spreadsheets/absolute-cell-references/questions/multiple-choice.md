# Absolute cell references — $B$9 — multiple choice

Pick the one right answer.

**1.** An absolute reference —
a) moves when copied  b) stays constant even when copied or moved  c) works only in row 9  d) is typed without =
**Answer: b) stays constant even when copied or moved**

**2.** $B$9 is made by —
a) pressing Enter twice  b) putting $ before the column and the row  c) using capital letters  d) clicking the fill handle
**Answer: b) putting $ before the column and the row** — F4 after selecting the reference does it too.

**3.** The bonus-mark formula in F2 is —
a) =B2+C2+D2+E2+B9 only in F2  b) =B2+C2+D2+E2+$B$9  c) =$B$2+$C$2+$D$2+$E$2+B9  d) =B9+C9+D9+E9
**Answer: b) =B2+C2+D2+E2+$B$9** — Only the shared bonus is pinned.

**4.** In ((A1 + A4) − B5) × $F$2, the absolute reference is —
a) A1  b) A4  c) B5  d) $F$2
**Answer: d) $F$2** — From the teacher guide's keyed answer.

**5.** The bonus mark for every student is held in —
a) F9  b) B9  c) G1  d) F2
**Answer: b) B9** — The book's text misprints it once as F9 — the cell is B9.
