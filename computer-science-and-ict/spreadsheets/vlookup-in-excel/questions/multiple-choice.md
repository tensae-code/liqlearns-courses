# VLOOKUP in Excel — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does VLOOKUP search?**
a) The first column of a table, for the lookup value  b) The value in the stated column of the found row  c) The spreadsheet's join — tables lending columns through a shared key  d) Vertical — the search runs down a column
**Answer: a**

**2. (Sub lesson 1) What does it return?**
a) The value in the stated column of the found row  b) The spreadsheet's join — tables lending columns through a shared key  c) Vertical — the search runs down a column  d) Records live in rows
**Answer: a**
