# Lesson plan — Types of Data — Text, Numbers, Formulas

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Text and numbers** — **Text** data is words and labels: names, headings, notes — anything the sheet describes rather than calculates with. **Numeric** data is a number the sheet can calculate with: a quantity, a price, a mark. The difference is behaviour, not looks: a number typed as text (for example inside a label like 'Room 12') just sits there, while a true number can be added, averaged and compared. Dates and times count as numbers underneath, which is why the sheet can subtract one date from another and answer in days.
2. **Formulas — the calculating kind** — A **formula** is an entry that tells the sheet to calculate: it begins with the equals sign and names cells and operations, and the cell shows the formula's **result**, not the formula itself. Change a number the formula uses and the result changes with it — that is the whole point of a spreadsheet. Reading a sheet means knowing which kind each cell holds: a result that looks like an ordinary number may be a formula's answer that will move when its inputs move, while a typed number stays until someone retypes it.

In this lesson you learn the three types of data a spreadsheet holds, and how to tell them apart. (lesson/lesson.md).
