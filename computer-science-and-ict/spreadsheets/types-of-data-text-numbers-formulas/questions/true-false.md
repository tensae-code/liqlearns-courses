# Types of Data — Text, Numbers, Formulas — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What are the three types of data in a cell?" is: Text, a number, or a formula.**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is text data for?" is: With the equals sign.**
**Answer: False** — Words and labels — what the sheet describes rather than calculates with.

**3. (Sub lesson 1) True or false: the answer to "What is numeric data?" is: A number the sheet can calculate with.**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Is the difference between text and numbers about looks?" is: The result changes with it.**
**Answer: False** — No — it is about behaviour: what the program can do with the entry.

**5. (Sub lesson 1) True or false: the answer to "Why can the sheet subtract one date from another?" is: Because dates and times count as numbers underneath.**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How does a formula entry begin?" is: A typed number.**
**Answer: False** — With the equals sign.

**7. (Sub lesson 2) True or false: the answer to "What does a formula cell show?" is: The formula's result, not the formula itself.**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What happens to a result when an input changes?" is: Words and labels — what the sheet describes rather than calculates with.**
**Answer: False** — The result changes with it.

**9. (Sub lesson 2) True or false: the answer to "How can you tell a formula cell from a typed number?" is: Select the cell and look in the formula bar.**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What stays fixed until retyped?" is: No — it is about behaviour: what the program can do with the entry.**
**Answer: False** — A typed number.
