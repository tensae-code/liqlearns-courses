# Formatting cells — fonts and emphasis — multiple choice

Pick the one right answer.

**1.** Every cell starts in the font —
a) Tahoma  b) Calibri  c) Arial  d) Times
**Answer: b) Calibri**

**2.** Hovering over a font in the dropdown gives —
a) a definition  b) a live preview  c) a printout  d) a warning
**Answer: b) a live preview**

**3.** A custom font size can be —
a) only picked  b) typed in  c) only increased by one  d) set by the ruler
**Answer: b) typed in**

**4.** Italic from the keyboard is —
a) Ctrl+B  b) Ctrl+U  c) Ctrl+I  d) Ctrl+P
**Answer: c) Ctrl+I**

**5.** Font Color is chosen from —
a) the Fill Color dropdown  b) the Font Color dropdown  c) the Borders dropdown  d) the Number Format dropdown
**Answer: b) the Font Color dropdown** — Fill Color paints the background — the next lesson.
