# Automatic Recalculation — When Data Changes, Results Change — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: When a value changes, every formula depending on it works itself out again at once**
**Answer: True**

**2. (Sub lesson 1) True or false: Through other formulas, in a chain** — as the answer to: What was the total, really?
**Answer: False — A standing instruction, not a typed number**

**3. (Sub lesson 1) True or false: Through other formulas, in a chain**
**Answer: True**

**4. (Sub lesson 1) True or false: A living calculator that cannot go stale** — as the answer to: A sheet of typed totals is what?
**Answer: False — A photograph**

**5. (Sub lesson 1) True or false: A living calculator that cannot go stale**
**Answer: True**

**6. (Sub lesson 2) True or false: A derived value — build it with a formula** — as the answer to: How far do recalculation chains run?
**Answer: False — As far as the formulas reach**

**7. (Sub lesson 2) True or false: A derived value — build it with a formula**
**Answer: True**

**8. (Sub lesson 2) True or false: Instantly and everywhere downstream** — as the answer to: What must the builder check?
**Answer: False — The chain's sources — one wrong source poisons every result downstream**

**9. (Sub lesson 2) True or false: Instantly and everywhere downstream**
**Answer: True**
