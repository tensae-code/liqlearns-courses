# What-If Analysis in Excel

## Do it first

What-if analysis is Excel's way of asking 'what happens if this number changes?' — you change an input cell and watch every result that depends on it recalculate

## Sub lesson 1 — What if analysis

What-if analysis is Excel's way of asking 'what happens if this number changes?' — you change an input cell and watch every result that depends on it recalculate The learner builds a small model — inputs, formulas, results — then changes one input at a time and records how the results move, first by hand and then with Excel's what-if tools Because decisions are made on numbers that might change; what-if analysis shows the effect before the decision is taken.

In your mind's eye: what if analysis.
