# What-If Analysis in Excel — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is what if analysis?**
**Answer: What-if analysis is Excel's way of asking 'what happens if this number changes?' — you change an input cell and watch every result that depends on it recalculate**

**2. (Sub lesson 1) What is the key work in what if analysis?**
**Answer: The learner builds a small model — inputs, formulas, results — then changes one input at a time and records how the results move, first by hand and then with Excel's what-if tools**

**3. (Sub lesson 1) Where does South Sudan teach what if analysis?**
**Answer: In Secondary ICT, South Sudan Grade 10 S2 Student, printed p. 91 — What if analysis**

**4. (Sub lesson 1) Why does what if analysis matter?**
**Answer: Because decisions are made on numbers that might change; what-if analysis shows the effect before the decision is taken**

**5. (Sub lesson 1) What should a learner remember about what if analysis?**
**Answer: The book's own order for what if analysis — and how to show it in practice, not only name it**
