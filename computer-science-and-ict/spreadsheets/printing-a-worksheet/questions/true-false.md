# Printing a Worksheet — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Where do you always start before printing?" is: In print preview**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does print preview show?" is: In page setup — before printing**
**Answer: False** — The worksheet exactly as it will land on paper, page by page

**3. (Sub lesson 1) True or false: the answer to "Where do you fix a badly split table?" is: In page setup — before printing**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What three things does page setup decide here?" is: Marks the chosen part of the sheet as the only part that prints**
**Answer: False** — Paper size, portrait or landscape direction, and margins

**5. (Sub lesson 1) True or false: the answer to "What does a print area do?" is: Marks the chosen part of the sheet as the only part that prints**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What three choices do you make in the Print box?" is: That it holds the paper size and direction your setup promised**
**Answer: False** — The printer, the pages to print, and the number of copies

**7. (Sub lesson 2) True or false: the answer to "What paper check do you make at the real printer?" is: That it holds the paper size and direction your setup promised**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What do you do with the printed sheets first?" is: The setup — then print again, rather than accepting a bad sheet**
**Answer: False** — Read them like a stranger — checking for clipped columns or near-empty pages

**9. (Sub lesson 2) True or false: the answer to "A column is clipped on paper. What do you fix?" is: The setup — then print again, rather than accepting a bad sheet**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why not print first and check later?" is: In print preview**
**Answer: False** — Every bad sheet wastes paper — the preview shows the faults for free
