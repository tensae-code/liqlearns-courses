# Lesson plan — Printing a Worksheet

**Course:** Computer Science and ICT · **Title:** Spreadsheets · **Lesson:** Printing a Worksheet

**The one thing this lesson teaches:** Printing a worksheet means checking it in print preview first, setting the page up so the table fits the paper, choosing what to print and how many copies, and only then sending it to the printer.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Before printing — preview and page setup** — Always start in **print preview**: the screen shows the worksheet exactly as it will land on paper, page by page. If the table is split badly, fix it in **page setup** before printing — paper size, **portrait or landscape** direction, and **margins** — and, for a wide table, the setting that fits it to one page wide. You can also mark a **print area** so only the chosen part of the sheet prints, not every stray cell around it.
2. **Printing — printer, pages and copies** — When the preview is right, open **Print** and choose: the **printer**, the **pages** to print (all, or a range), and the **number of copies**. Check the real printer holds the paper your setup promised — size and direction — then print. Take the sheets and read them like a stranger: if a column is clipped or a page is nearly empty, the fault is in the setup, so fix the setup and print again rather than accepting a bad sheet.
