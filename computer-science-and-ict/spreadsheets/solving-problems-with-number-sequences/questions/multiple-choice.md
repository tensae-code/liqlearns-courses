# Solving Problems with Number Sequences — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is solving by tabulating?**
a) Turning a word problem into a table — quantities as columns, steps as rows  b) Inspection — every intermediate value stands visible  c) At its row, not at the answer  d) A column where each term is built by a rule from the ones before
**Answer: a) Turning a word problem into a table — quantities as columns, steps as rows**

**2. (Sub lesson 1) What is the method's power?**
a) At its row, not at the answer  b) Inspection — every intermediate value stands visible  c) A column where each term is built by a rule from the ones before  d) Each term is the sum of the two before it
**Answer: b) Inspection — every intermediate value stands visible**

**3. (Sub lesson 1) Where is a wrong turn found?**
a) A column where each term is built by a rule from the ones before  b) Each term is the sum of the two before it  c) At its row, not at the answer  d) 1, 1, 2, 3, 5, 8
**Answer: c) At its row, not at the answer**

**4. (Sub lesson 1) What is a number sequence in the sheet?**
