# History of the Electronic Spreadsheet — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Change one number and every total depending on it had to be re-added by hand**
**Answer: True**

**2. (Sub lesson 1) True or false: Change one number and every total depending on it had to be re-added by hand** — as the answer to: What does an electronic spreadsheet do when a number changes?
**Answer: False — It recalculates itself — every formula that depends on the number updates**

**3. (Sub lesson 1) True or false: VisiCalc, in 1979**
**Answer: True**

**4. (Sub lesson 1) True or false: VisiCalc, in 1979** — as the answer to: Who made VisiCalc?
**Answer: False — Dan Bricklin and Bob Frankston**

**5. (Sub lesson 1) True or false: To run VisiCalc — the program sold the computer**
**Answer: True**

**6. (Sub lesson 2) True or false: To run VisiCalc — the program sold the computer** — as the answer to: What did Lotus 1-2-3 add in 1983?
**Answer: False — It made the spreadsheet a business standard on the IBM PC, adding charts and database features**

**7. (Sub lesson 2) True or false: With the graphical interface — clicking cells instead of memorising commands**
**Answer: True**

**8. (Sub lesson 2) True or false: With the graphical interface — clicking cells instead of memorising commands** — as the answer to: What did Google Sheets change in 2006?
**Answer: False — It put the spreadsheet online in a browser, free — recalculation for anyone**

**9. (Sub lesson 2) True or false: Automatic recalculation — change a number and the sheet redoes the maths**
**Answer: True**

**10. (Sub lesson 2) True or false: Automatic recalculation — change a number and the sheet redoes the maths** — as the answer to: In Armenia's Grade 6 book, what comes right after this history?
**Answer: False — The features of using electronic spreadsheets (§11) — the sheet itself**
