# Removing Duplicate Data — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The same record entered more than once in a worksheet**
**Answer: True**

**2. (Sub lesson 1) True or false: The same record entered more than once in a worksheet** — as the answer to: What does it poison?

**5. (Sub lesson 1) True or false: When the chosen identifying columns all agree**
