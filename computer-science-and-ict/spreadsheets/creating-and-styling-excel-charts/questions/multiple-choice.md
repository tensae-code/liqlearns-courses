# Creating and styling Excel charts — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The first step in creating a chart is —
a) open the Design tab  b) select the source cells, including titles and labels  c) type a title  d) print the sheet
**Answer: b) select the source cells, including titles and labels**

**2. (Sub lesson 1)** Charts are inserted from —
a) the Data tab  b) the View tab  c) the Insert tab  d) the File menu
**Answer: c) the Insert tab**

**3. (Sub lesson 1)** Recommended Charts —
a) prints charts  b) suggests types fitted to the data  c) deletes charts  d) sorts data
**Answer: b) suggests types fitted to the data**

**4. (Sub lesson 2)** Titles, legends and data labels are added with —
a) Quick Layout  b) Chart Styles  c) Add Chart Element  d) Filter
**Answer: c) Add Chart Element**

**5. (Sub lesson 2)** An element's text is edited by —
a) double-clicking its placeholder and typing  b) sorting it  c) freezing it  d) saving the file
**Answer: a) double-clicking its placeholder and typing**
