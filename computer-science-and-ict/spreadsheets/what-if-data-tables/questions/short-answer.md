# What If Data Tables — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is data Tables?**
**Answer: A data table is Excel's automatic what-if grid: it takes one or two changing inputs and fills a whole table with the results the model gives for each value**

**2. (Sub lesson 1) What is the key work in data Tables?**
**Answer: The learner lays out the input values in a row or column, links the result cell, and lets the Data Table command fill in every result at once**

**3. (Sub lesson 1) Where does South Sudan teach data Tables?**
**Answer: In Secondary ICT, South Sudan Grade 10 S2 Student, printed p. 93 — Data Tables**

**4. (Sub lesson 1) Why does data Tables matter?**
**Answer: Because trying twenty input values by hand is slow and error-prone; the data table does the repetition exactly**

**5. (Sub lesson 1) What should a learner remember about data Tables?**
**Answer: The book's own order for data Tables — and how to show it in practice, not only name it**
