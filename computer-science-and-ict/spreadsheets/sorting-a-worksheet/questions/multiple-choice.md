# Sorting a worksheet — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The scope decision comes —
a) after sorting  b) first, before sorting  c) only when printing  d) never
**Answer: b) first, before sorting**

**2. (Sub lesson 1)** Sorting a whole sheet by one column means —
a) only that column moves  b) all rows move together  c) a new sheet opens  d) headings freeze
**Answer: b) all rows move together**

**3. (Sub lesson 1)** Data can be sorted by cell colour, font colour or —
a) icon  b) printer  c) password  d) chart
**Answer: a) icon**

**4. (Sub lesson 2)** The sorting commands are on —
a) the View tab  b) the Data tab  c) the Insert tab  d) the File menu
**Answer: b) the Data tab**

**5. (Sub lesson 2)** Descending for names is —
a) A→Z  b) Z→A  c) 0→9  d) by date
**Answer: b) Z→A**
