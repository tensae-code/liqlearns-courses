# Sorting a worksheet — true or false

Say true or false.

**1. (Sub lesson 1)** Sorting only a range leaves neighbouring tables untouched.
**Answer: True**

**2. (Sub lesson 2)** In a sheet sort, you select a cell in the column to sort by.
**Answer: True**

**3. (Sub lesson 2)** Sorting changes the contents of the cells.
**Answer: False** — it changes the order of the rows, not their contents.
