# Lesson plan — Sorting a worksheet

**Course:** Computer Science and ICT · **Title:** Spreadsheets · **Lesson:** Sorting a worksheet
**Place in the curriculum:** Unit 3 — Application Software, Grade 10 depth, in the Spreadsheets title of the Computer Science and ICT ladder (TITLES.md). The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** sorting reorganises a worksheet by one column — the scope decision comes first (whole sheet, rows moving together, or only a range), then Data tab, then Ascending (A→Z) or Descending (Z→A).
**This lesson's own level:** it is a doing-lesson. It stands on entering data in a sheet; sorting changes the order of rows, never their contents.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The scope decision — whole sheet or only a range** — pass mark: state the scope decision and sort a whole sheet by one column, rows moving together.
2. **Sorting the whole sheet — in order** — pass mark: sort descending, and sort only a range leaving neighbours untouched.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Freeze panes and Split — keeping headers in view. Recommended, never forced.

## What the learner can do when it ends
1. Name the sort orders: alphabetical, numerical, by date, custom list, and by colour or icon.
2. Decide the scope — whole sheet or only a range — before sorting.
3. Sort a whole sheet by one column from the Data tab, Ascending or Descending.
4. Check that rows moved together, each keeping its own data.

## What you need
A computer with Excel and a worksheet of named rows.

## If the learner is stuck
- A pupil's marks ended up on the wrong row → the sort was done on a range of one column only; undo, and sort the whole sheet so rows move together.
- Nothing reordered → check a cell in the chosen column was selected before the Data tab command.
