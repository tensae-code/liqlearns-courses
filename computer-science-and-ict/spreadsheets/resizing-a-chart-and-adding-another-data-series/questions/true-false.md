# Resizing a Chart and Adding Another Data Series — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What appears on a chart's edges when you click it?" is: Handles**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does a corner handle change?" is: One direction only**
**Answer: False** — Height and width together

**3. (Sub lesson 1) True or false: the answer to "What does an edge handle change?" is: One direction only**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Why does a chart's size matter?" is: A new row or column of data added to the chart's picture**
**Answer: False** — Too small hides labels; too big crowds out the data

**5. (Sub lesson 1) True or false: the answer to "What is an extra data series?" is: A new row or column of data added to the chart's picture**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How is a series added?" is: Its own colour and a legend entry**
**Answer: False** — Select the chart and add the new data to its range

**7. (Sub lesson 2) True or false: the answer to "What comes with a new series in the plot?" is: Its own colour and a legend entry**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What happens after adding the series?" is: No — it redraws itself**
**Answer: False** — The chart updates automatically

**9. (Sub lesson 2) True or false: the answer to "Must the chart be rebuilt by hand?" is: No — it redraws itself**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is a chart, in this lesson's words?" is: Handles**
**Answer: False** — A living object on the sheet
