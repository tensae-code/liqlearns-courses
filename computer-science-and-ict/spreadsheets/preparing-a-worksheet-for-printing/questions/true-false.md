# Preparing a Worksheet for Printing — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Where is Page Setup found?" is: On the Page Layout tab**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Portrait or landscape for a wide worksheet?" is: The white frame around the printed page**
**Answer: False** — Landscape

**3. (Sub lesson 1) True or false: the answer to "What are margins?" is: The white frame around the printed page**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does Fit to Page do?" is: Chosen rows or columns — the headings of a long list**
**Answer: False** — Scales the sheet so all its columns print one page wide

**5. (Sub lesson 1) True or false: the answer to "What can repeat on every printed page?" is: Chosen rows or columns — the headings of a long list**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does the print preview show?" is: The page count, and that no column is cut off at an edge**
**Answer: False** — The worksheet exactly as paper will receive it

**7. (Sub lesson 2) True or false: the answer to "Name two checks in the preview." is: The page count, and that no column is cut off at an edge**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What can over-scaling do to the text?" is: Set that part as the print area**
**Answer: False** — Shrink it past reading size

**9. (Sub lesson 2) True or false: the answer to "How do you print only part of a sheet?" is: Set that part as the print area**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "When do you finally click Print?" is: On the Page Layout tab**
**Answer: False** — Only when the preview is right
