# Preparing a Worksheet for Printing — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Where is Page Setup found?**
a) On the Page Layout tab  b) Landscape  c) Chosen rows or columns — the headings of a long list  d) Shrink it past reading size
**Answer: a) On the Page Layout tab**

**2. (Sub lesson 1) Portrait or landscape for a wide worksheet?**
a) The white frame around the printed page  b) Landscape  c) The worksheet exactly as paper will receive it  d) Set that part as the print area
**Answer: b) Landscape**

**3. (Sub lesson 1) What are margins?**
a) Scales the sheet so all its columns print one page wide  b) The page count, and that no column is cut off at an edge  c) The white frame around the printed page  d) Only when the preview is right
**Answer: c) The white frame around the printed page**

**4. (Sub lesson 1) What does Fit to Page do?**
a) Chosen rows or columns — the headings of a long list  b) Shrink it past reading size  c) On the Page Layout tab  d) Scales the sheet so all its columns print one page wide
**Answer: d) Scales the sheet so all its columns print one page wide**

**5. (Sub lesson 1) What can repeat on every printed page?**
a) Chosen rows or columns — the headings of a long list  b) The worksheet exactly as paper will receive it  c) Set that part as the print area  d) Landscape
**Answer: a) Chosen rows or columns — the headings of a long list**

**6. (Sub lesson 2) What does the print preview show?**
a) The page count, and that no column is cut off at an edge  b) The worksheet exactly as paper will receive it  c) Only when the preview is right  d) The white frame around the printed page
**Answer: b) The worksheet exactly as paper will receive it**

**7. (Sub lesson 2) Name two checks in the preview.**
a) Shrink it past reading size  b) On the Page Layout tab  c) The page count, and that no column is cut off at an edge  d) Scales the sheet so all its columns print one page wide
**Answer: c) The page count, and that no column is cut off at an edge**

**8. (Sub lesson 2) What can over-scaling do to the text?**
a) Set that part as the print area  b) Landscape  c) Chosen rows or columns — the headings of a long list  d) Shrink it past reading size
**Answer: d) Shrink it past reading size**

**9. (Sub lesson 2) How do you print only part of a sheet?**
a) Set that part as the print area  b) Only when the preview is right  c) The white frame around the printed page  d) The worksheet exactly as paper will receive it
**Answer: a) Set that part as the print area**

**10. (Sub lesson 2) When do you finally click Print?**
a) On the Page Layout tab  b) Only when the preview is right  c) Scales the sheet so all its columns print one page wide  d) The page count, and that no column is cut off at an edge
**Answer: b) Only when the preview is right**
