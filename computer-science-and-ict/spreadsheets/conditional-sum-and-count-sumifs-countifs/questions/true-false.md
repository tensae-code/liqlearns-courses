# Conditional Sum and Count — SUMIFS and COUNTIFS — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Adds only the values whose rows meet every stated condition**
**Answer: True**

**2. (Sub lesson 1) True or false: Adds only the values whose rows meet every stated condition** — as the answer to: What is SUMIFS' argument order?
**Answer: False — The summed range first, then pairs of criteria range and criteria**

**3. (Sub lesson 1) True or false: SUMIF puts its summed range last; SUMIFS puts it first**
**Answer: True**

**4. (Sub lesson 1) True or false: SUMIF puts its summed range last; SUMIFS puts it first** — as the answer to: What does COUNTIFS do?
**Answer: False — Counts the rows meeting every condition**

**5. (Sub lesson 1) True or false: 'How much' (SUMIFS) and 'how many' (COUNTIFS)**
**Answer: True**

**6. (Sub lesson 2) True or false: 'How much' (SUMIFS) and 'how many' (COUNTIFS)** — as the answer to: Under how many conditions?
**Answer: False — Any number — every condition must hold**

**7. (Sub lesson 2) True or false: The pivot table — the same summarising done by dragging**
**Answer: True**

**8. (Sub lesson 2) True or false: The pivot table — the same summarising done by dragging** — as the answer to: What discipline travels with conditional numbers?
**Answer: False — State the conditions before computing, and report them with the number**

**9. (Sub lesson 2) True or false: A whole truth cut in half**
**Answer: True**
