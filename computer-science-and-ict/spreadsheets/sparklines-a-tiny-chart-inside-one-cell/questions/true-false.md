# Sparklines — a Tiny Chart Inside One Cell — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a sparkline?" is: A tiny chart that lives inside one cell**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How much data does one sparkline draw?" is: Axes and labels**
**Answer: False** — One row or one column

**3. (Sub lesson 1) True or false: the answer to "What does a sparkline not have?" is: Axes and labels**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does a column of sparklines let you read?" is: Select the data, insert the sparkline, name the cell that holds it**
**Answer: False** — The shape of every row at a glance — rising, falling, steady

**5. (Sub lesson 1) True or false: the answer to "What are the steps to create one?" is: Select the data, insert the sparkline, name the cell that holds it**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How is a sparkline formatted?" is: Its data points — highest, lowest, first, last, negative**
**Answer: False** — With its own colours and styles

**7. (Sub lesson 2) True or false: the answer to "What can be marked on a sparkline?" is: Its data points — highest, lowest, first, last, negative**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Why mark the highest and lowest points?" is: Inside one cell of the worksheet**
**Answer: False** — So the eye lands on the extremes at once

**9. (Sub lesson 2) True or false: the answer to "Where does the sparkline live?" is: Inside one cell of the worksheet**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Does a sparkline replace reading the numbers?" is: A tiny chart that lives inside one cell**
**Answer: False** — No — it shows the shape beside the numbers
