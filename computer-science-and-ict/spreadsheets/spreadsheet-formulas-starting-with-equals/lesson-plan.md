# Lesson plan — Spreadsheet formulas — starting with =

**Course:** Computer Science and ICT · **Title:** Spreadsheets · **Lesson:** Spreadsheet formulas — starting with =
**Place in the curriculum:** Title 6 — Spreadsheets in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 8 book, Unit 3 — Computer Software. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** a formula is an expression that operates on values in cells, built in order: select a cell, type =, select or type the cell address, enter the operator, select or type the next address, press Enter — and the result appears.
**This lesson's own level:** it is a doing-lesson. It stands on Spreadsheets — data in rows, columns and cells: a formula is typed into a cell and works on other cells’ values.

## What the learner can do when it ends
1. Say what a formula is: an expression that operates on values in a range of cells or a cell.
2. Build a formula in the six steps, in order, starting with the equal sign.
3. Read a formula's result in the cell where the formula stands.

## What you need
A computer with a spreadsheet program — this lesson is learned by doing it.

## If the learner is stuck
- Forgets the equal sign → a formula always begins with =; without it, the cell holds text, not a calculation.
- Types numbers instead of cell addresses → a formula that refers to other cells keeps working when those cells change; select the cell or type its address.
