# Spreadsheet formulas — starting with = — ordering

Put each set in the right order.

**1.** Put the six steps in order: press Enter and the result appears / type the equal sign / select a cell / enter the operator / select the next cell or type its address / select a cell or type its address.
**Answer: select a cell → type the equal sign → select a cell or type its address → enter the operator → select the next cell or type its address → press Enter and the result appears.**
