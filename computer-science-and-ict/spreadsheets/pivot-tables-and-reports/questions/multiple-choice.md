# Pivot Tables and Reports — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does a pivot table do to a list?**
a) Summarises it into a small grouped report  b) The grouping — one row per group  c) The field summarised for each group  d) Sum
**Answer: a) Summarises it into a small grouped report**

**2. (Sub lesson 1) What does the Rows area decide?**
a) The field summarised for each group  b) The grouping — one row per group  c) Sum  d) No — it is a view built on top of it
**Answer: b) The grouping — one row per group**

**3. (Sub lesson 1) What does the Values area hold?**
a) Sum  b) No — it is a view built on top of it  c) The field summarised for each group  d) Count, average and max (any three from the lesson)
**Answer: c) The field summarised for each group**

**4. (Sub lesson 1) What is the default summary?**
a) No — it is a view built on top of it  b) Count, average and max (any three from the lesson)  c) A further split of each total  d) Sum
**Answer: d) Sum**

**5. (Sub lesson 1) Does a pivot table change the source list?**
a) No — it is a view built on top of it  b) Count, average and max (any three from the lesson)  c) A further split of each total  d) Rearranging the fields to answer a new question instantly
**Answer: a) No — it is a view built on top of it**

**6. (Sub lesson 2) Name three summaries besides sum.**
a) A further split of each total  b) Count, average and max (any three from the lesson)  c) Rearranging the fields to answer a new question instantly  d) Refresh the pivot table
**Answer: b) Count, average and max (any three from the lesson)**

**7. (Sub lesson 2) What does a Columns field add?**
a) Rearranging the fields to answer a new question instantly  b) Refresh the pivot table  c) A further split of each total  d) Headings, with one record per row
**Answer: c) A further split of each total**

**8. (Sub lesson 2) What does repivoting mean?**
a) Refresh the pivot table  b) Headings, with one record per row  c) Summarises it into a small grouped report  d) Rearranging the fields to answer a new question instantly
**Answer: d) Rearranging the fields to answer a new question instantly**

**9. (Sub lesson 2) What must you do after the source data changes?**
a) Refresh the pivot table  b) Headings, with one record per row  c) Summarises it into a small grouped report  d) The grouping — one row per group
**Answer: a) Refresh the pivot table**

**10. (Sub lesson 2) What must the source list have first?**
a) Summarises it into a small grouped report  b) Headings, with one record per row  c) The grouping — one row per group  d) The field summarised for each group
**Answer: b) Headings, with one record per row**
