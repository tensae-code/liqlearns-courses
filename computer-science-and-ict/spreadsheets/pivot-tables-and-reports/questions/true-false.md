# Pivot Tables and Reports — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does a pivot table do to a list?" is: Summarises it into a small grouped report**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does the Rows area decide?" is: No — it is a view built on top of it**
**Answer: False** — The grouping — one row per group

**3. (Sub lesson 1) True or false: the answer to "What does the Values area hold?" is: The field summarised for each group**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is the default summary?" is: A further split of each total**
**Answer: False** — Sum

**5. (Sub lesson 1) True or false: the answer to "Does a pivot table change the source list?" is: No — it is a view built on top of it**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Name three summaries besides sum." is: Refresh the pivot table**

**8. (Sub lesson 2) True or false: the answer to "What does repivoting mean?" is: Summarises it into a small grouped report**
**Answer: False** — Rearranging the fields to answer a new question instantly
