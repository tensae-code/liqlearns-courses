## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Logical functions — a formula that tests** — A **logical function** works on a **test**: it compares a value with a condition — is this mark at least the pass mark? — and returns **one answer if the test is true and another if it is false**. The test is written with the comparison signs the formulas lessons already met. With a logical function the sheet stops only calculating and starts **reporting a judgement** in words the reader understands, for every row at once.
2. **Moving a formula — cut, copy and paste** — A formula written once is rarely needed once. **Copy and paste** a formula to the neighbouring cells and Excel **adjusts its cell references** to each new row — the fill-handle lesson's rule, worked by hand. **Cut and paste** moves the formula itself to a new home. Libya pairs the two teachings in one section because they are one daily skill: write the deciding formula once, then spread it down the whole class list.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
