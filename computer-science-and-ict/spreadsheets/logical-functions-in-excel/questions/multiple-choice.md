# Logical Functions in Excel — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does a logical function do?**
a) It tests a condition and answers differently according to the result  b) One answer if the test is true and another if it is false  c) Is this mark at least the pass mark?  d) With comparison signs, comparing a value with a condition
**Answer: a) It tests a condition and answers differently according to the result**

**2. (Sub lesson 1) What two answers can it return?**
a) Is this mark at least the pass mark?  b) One answer if the test is true and another if it is false  c) With comparison signs, comparing a value with a condition  d) It stops only calculating and starts reporting a judgement
**Answer: b) One answer if the test is true and another if it is false**

**3. (Sub lesson 1) Give an example of a test.**
a) With comparison signs, comparing a value with a condition  b) It stops only calculating and starts reporting a judgement  c) Is this mark at least the pass mark?  d) Excel adjusts its cell references to each new row
**Answer: c) Is this mark at least the pass mark?**

a) It stops only calculating and starts reporting a judgement  b) Excel adjusts its cell references to each new row  c) It moves the formula itself to a new home  d) With comparison signs, comparing a value with a condition
