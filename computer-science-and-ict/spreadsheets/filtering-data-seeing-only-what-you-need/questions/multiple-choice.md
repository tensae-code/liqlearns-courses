# Filtering data — seeing only what you need — multiple choice

Pick the one right answer.

**1.** Before filtering, the sheet must have —
a) a chart  b) a header row naming each column  c) frozen panes  d) a password
**Answer: b) a header row naming each column**

**2.** Filter is switched on from —
a) Data tab → Filter  b) View → Filter  c) Insert → Filter  d) File → Filter
**Answer: a) Data tab → Filter**

**3.** When Filter is on, a dropdown arrow appears —
a) in one cell only  b) in every header cell  c) on the ruler  d) beside the sheet name
**Answer: b) in every header cell**

**4.** To show only some values, first —
a) check Select All  b) uncheck Select All, then check the wanted values  c) delete the rest  d) sort the sheet
**Answer: b) uncheck Select All, then check the wanted values**

**5.** All filters are removed by —
a) saving  b) clicking Filter again on the Data tab  c) pressing Esc  d) closing Excel
**Answer: b) clicking Filter again on the Data tab**
