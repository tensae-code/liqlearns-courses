# Filtering data — seeing only what you need — true or false

Say true or false.

**1.** Filtered-out rows are deleted for good.
**Answer: False** — they are hidden and return when the filter is removed.

**2.** The menu of a column's arrow lists the values found in that column.
**Answer: True**

**3.** A sheet without a header row can be filtered the same way.
**Answer: False** — the book requires a header row naming each column.
