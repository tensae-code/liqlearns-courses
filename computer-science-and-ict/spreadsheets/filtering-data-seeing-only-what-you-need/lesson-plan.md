# Lesson plan — Filtering data — seeing only what you need

**Course:** Computer Science and ICT · **Title:** Spreadsheets · **Lesson:** Filtering data — seeing only what you need
**Place in the curriculum:** Unit 3 — Application Software, Grade 10 depth, in the Spreadsheets title of the Computer Science and ICT ladder (TITLES.md). The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** a filter hides every row except the values you check: header row first, Data → Filter, open the column's dropdown arrow, uncheck Select All, check only the wanted values, OK.
**This lesson's own level:** it is a doing-lesson. It stands on Sorting a worksheet; sorting reorders rows, filtering hides the ones you do not need.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. ## Before this lesson
- Recommended first: Sorting a worksheet. Recommended, never forced.

## What the learner can do when it ends
1. Say why the sheet needs a header row before filtering.
2. Turn Filter on and find the dropdown arrow in every header cell.
3. Show only chosen values by unchecking Select All and checking the wanted ones.
4. Remove all filters so the whole list returns.

## What you need
A computer with Excel and a worksheet with a header row.

## If the learner is stuck
- No dropdown arrows → Filter was not turned on, or there is no header row; add the header row, then Data → Filter.
- Too few rows show → a value you need is unchecked; open the arrow and check it again.
