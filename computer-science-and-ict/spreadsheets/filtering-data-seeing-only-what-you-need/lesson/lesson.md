# Filtering data — seeing only what you need

## Do it first

The grade list holds the whole school. You need only one class's rows. Do not delete the rest — filter the list down to what you need, then bring it all back.

## Filtering — in the book's order

Filters **narrow a worksheet down to only the rows needed**. Hidden rows are not deleted — they return when the filter is removed.

In the book's order:

1. The sheet must have a **header row naming each column**.
2. **Data tab → Filter** — a **dropdown arrow appears in every header cell**.
3. Click the **arrow of the column to filter by**.
4. In the menu, **uncheck Select All**, then **check only the values wanted**.
5. Click **OK** — the other rows hide.
6. Clicking **Filter again** on the Data tab **removes all filters** and the full list returns.

## Do It Yourself

1. Add a header row if your sheet lacks one, then turn Filter on from the Data tab.
2. Filter a column to one value only, and count the rows that remain.
3. Remove all filters and confirm every row is back.
