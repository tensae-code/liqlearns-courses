# Cell references

## Do it first

A cell holds 40. Another cell holds =40+10 typed with numbers. Change the first cell to 90 — the answer cell still says 50. It was frozen. Now rebuild the answer cell using the first cell's name instead of the number 40, and change the first cell again. This time the answer moves. That moving is this lesson.

## Naming a cell

A **cell reference** identifies a cell by its **column letter and row number** — **A1**, **E4**. A formula can use the reference **instead of the value**: =A1+10 works on whatever A1 holds.

## Why references keep a formula alive

That gives **flexibility**: change the value in a referenced cell and **every formula using it updates automatically**, with no rewriting. And a cell containing a formula can itself be **referenced by another formula** — answers can build on answers.

## Say it to your companion

Tell your companion, in your own words: a cell reference names a cell by column letter and row number, so a formula can use the cell instead of a typed number — and updates by itself when the cell changes. Use the lesson's own words for the key names.
