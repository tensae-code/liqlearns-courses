# Cell references — multiple choice

Pick the one right answer.

**1.** A cell reference is made of —
a) row number, then column letter  b) column letter, then row number  c) the cell's colour  d) the sheet's name
**Answer: b) column letter, then row number** — A1, E4.

**2.** Which of these is a cell reference?
a) 4E  b) E4  c) EE  d) 44
**Answer: b) E4**

**3.** When a referenced cell's value changes, formulas using it —
a) must be rewritten  b) update automatically  c) turn into text  d) stop working
**Answer: b) update automatically** — That flexibility is the point of references.

**4.** A cell holding a formula can be —
a) never used again  b) referenced by another formula  c) only deleted  d) printed only
**Answer: b) referenced by another formula** — Answers can build on answers.
