# Merging Cells in Excel — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A selected block of cells into one large cell**
**Answer: True**

**2. (Sub lesson 1) True or false: Format → Cells → Alignment → Merge cells** — as the answer to: Whose value survives a merge?
**Answer: False — The block's top-left value**

**3. (Sub lesson 1) True or false: Format → Cells → Alignment → Merge cells**
**Answer: True**

**4. (Sub lesson 1) True or false: Its top-left corner's address** — as the answer to: What does the Merge and Center button add?
**Answer: False — It joins and centres in one act**

**5. (Sub lesson 1) True or false: Its top-left corner's address**
**Answer: True**

**6. (Sub lesson 2) True or false: Select across the table's width, merge, then type the title** — as the answer to: What is merging's daily job?
**Answer: False — Placing a title centred over a whole table**

**7. (Sub lesson 2) True or false: Select across the table's width, merge, then type the title**
**Answer: True**

**8. (Sub lesson 2) True or false: Sorting and selecting — a partly merged column refuses tidy sorts** — as the answer to: Is merging data work or formatting?
**Answer: False — Formatting — the numbers below are untouched**

**9. (Sub lesson 2) True or false: Sorting and selecting — a partly merged column refuses tidy sorts**
**Answer: True**

**10. (Sub lesson 2) True or false: A selected block of cells into one large cell** — as the answer to: Which chapter teaches this?
