# Scenario Manager in Excel — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is scenario Manager?**
**Answer: The Scenario Manager stores named sets of input values — a best case, an expected case, a worst case — and applies each set to the same model in one step**

**2. (Sub lesson 1) What is the key work in scenario Manager?**
**Answer: The learner creates scenarios by naming them and entering their input values, then shows each scenario and compares the results side by side**

**3. (Sub lesson 1) Where does South Sudan teach scenario Manager?**

**4. (Sub lesson 1) Why does scenario Manager matter?**
**Answer: Because a plan should be tested against more than one future, and scenarios keep those futures named, saved and comparable**
