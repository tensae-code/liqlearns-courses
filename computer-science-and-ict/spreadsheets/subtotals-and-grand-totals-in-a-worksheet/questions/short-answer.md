# Subtotals and Grand Totals in a Worksheet — short answer

Answer in your own words, in one or two sentences.

**1. (Sub lesson 2) A learner inserts subtotals on an unsorted list of sales and gets five subtotal rows for the same shop. What went wrong, and how is it fixed?**
**Answer: The Subtotal tool starts a new group every time the grouping value changes, so the shop's scattered rows became five separate groups. Fix: remove the subtotals, sort the list by the shop column so each shop's rows stand together, then insert the subtotals again.**
