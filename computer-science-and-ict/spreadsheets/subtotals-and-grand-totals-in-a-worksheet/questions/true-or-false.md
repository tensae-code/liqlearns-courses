# Subtotals and Grand Totals in a Worksheet — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) The grand total equals all the subtotals added together.**
**Answer: True — Each row belongs to exactly one group, so the group sums add up to the whole.**

**2. (Sub lesson 2) Removing subtotals with Remove All deletes the original data rows.**
**Answer: False — Only the inserted subtotal and grand total rows are removed; the original list comes back untouched.**
