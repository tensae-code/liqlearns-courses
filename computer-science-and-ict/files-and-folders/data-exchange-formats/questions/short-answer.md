# Data Exchange Formats — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) Why can't programs just read each other's files?**
**Answer: Each program stores data in its own internal shape, which others cannot read**

**2. (Sub lesson 1) What is a data exchange format?**
**Answer: An agreed public shape for handing data over, so the receiver can rebuild it**

**3. (Sub lesson 1) What is the simplest exchange format?**
**Answer: Plain text**

**4. (Sub lesson 1) How does a table travel as CSV?**
**Answer: Values separated by commas, one row per line**

**5. (Sub lesson 1) Where does Armenia teach exchange formats?**
**Answer: Grade 6, §17 — General concepts of data exchange formats**

**6. (Sub lesson 2) How does XML carry data?**
**Answer: Wrapped in named tags, like <name>…</name>**

**7. (Sub lesson 2) How does JSON carry data?**
**Answer: As name–value pairs and lists, in a shape borrowed from JavaScript**

**8. (Sub lesson 2) What do XML and JSON share?**
**Answer: Both are plain text, human-readable, and need both sides to agree on the names**

**9. (Sub lesson 2) Which format fits a flat table?**
**Answer: CSV**

**10. (Sub lesson 2) What three questions choose a format?**
**Answer: Flat or structured? Readable by people? Accepted by the receiver's program?**
