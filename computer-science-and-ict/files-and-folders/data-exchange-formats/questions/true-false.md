# Data Exchange Formats — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Each program stores data in its own internal shape, which others cannot read**
**Answer: True**

**2. (Sub lesson 1) True or false: Each program stores data in its own internal shape, which others cannot read** — as the answer to: What is a data exchange format?
**Answer: False — An agreed public shape for handing data over, so the receiver can rebuild it**

**3. (Sub lesson 1) True or false: Plain text**
**Answer: True**

**4. (Sub lesson 1) True or false: Plain text** — as the answer to: How does a table travel as CSV?
**Answer: False — Values separated by commas, one row per line**

**5. (Sub lesson 1) True or false: Grade 6, §17 — General concepts of data exchange formats**
**Answer: True**

**6. (Sub lesson 2) True or false: Grade 6, §17 — General concepts of data exchange formats** — as the answer to: How does XML carry data?
**Answer: False — Wrapped in named tags, like <name>…</name>**

**7. (Sub lesson 2) True or false: As name–value pairs and lists, in a shape borrowed from JavaScript**
**Answer: True**

**8. (Sub lesson 2) True or false: As name–value pairs and lists, in a shape borrowed from JavaScript** — as the answer to: What do XML and JSON share?
**Answer: False — Both are plain text, human-readable, and need both sides to agree on the names**

**9. (Sub lesson 2) True or false: CSV**
**Answer: True**

**10. (Sub lesson 2) True or false: CSV** — as the answer to: What three questions choose a format?
**Answer: False — Flat or structured? Readable by people? Accepted by the receiver's program?**
