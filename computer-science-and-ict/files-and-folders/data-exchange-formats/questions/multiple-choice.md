# Data Exchange Formats — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Why can't programs just read each other's files?**
a) Each program stores data in its own internal shape, which others cannot read  b) An agreed public shape for handing data over, so the receiver can rebuild it  c) Plain text  d) Values separated by commas, one row per line
