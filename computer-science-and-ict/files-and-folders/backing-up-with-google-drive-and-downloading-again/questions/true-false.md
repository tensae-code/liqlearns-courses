# Backing Up with Google Drive — and Downloading Again — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is Google Drive, in this lesson?" is: Google's online storage, where backup copies are kept away from the computer**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does uploading mean here?" is: Each file listed with its name and size**
**Answer: False** — Copying files from the computer to Google Drive over the internet

**3. (Sub lesson 1) True or false: the answer to "What happens to the originals when you upload?" is: They stay on the computer — Drive holds a copy**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Why watch an upload until it finishes?" is: Anywhere you can sign in to the account**
**Answer: False** — A half-uploaded backup is a backup of half the work

**5. (Sub lesson 1) True or false: the answer to "What does Drive show as the check a file arrived?" is: Each file listed with its name and size**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is downloading?" is: Uploading, then downloading again and opening the returned file**
**Answer: False** — Bringing a file back from Drive to the computer

**7. (Sub lesson 2) True or false: the answer to "Where can the return journey start from?" is: Anywhere you can sign in to the account**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does the downloaded file become?" is: Google's online storage, where backup copies are kept away from the computer**
**Answer: False** — A working file again on the computer

**9. (Sub lesson 2) True or false: the answer to "What does Class VII practise in the same sitting?" is: Uploading, then downloading again and opening the returned file**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why practise the return at once?" is: They stay on the computer — Drive holds a copy**
**Answer: False** — To have proof, not hope, that the backup works
