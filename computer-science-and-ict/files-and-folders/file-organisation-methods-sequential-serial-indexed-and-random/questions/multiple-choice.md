# File Organisation Methods — Sequential, Serial, Indexed and Random — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) In a serial file, records are stored —**
a) Sorted by key  b) In the order they arrive, unsorted  c) By calculated address  d) Inside an index
**Answer: b) In the order they arrive, unsorted — In the order they arrive, unsorted — adding is easy, finding is a long read.**

**2. (Sub lesson 1) A payroll run that processes every employee record in order fits —**
a) Random organisation  b) Serial organisation  c) Sequential organisation  d) No organisation
**Answer: c) Sequential organisation — Sequential organisation — every record is visited anyway, in key order.**

**3. (Sub lesson 2) Random (direct) organisation finds a record's address by —**
a) Reading the whole file  b) Calculating it from the key (hashing)  c) Asking the user  d) Looking in a printed index
**Answer: b) Calculating it from the key (hashing) — Calculating it from the key (hashing) — one jump, whatever the file size.**
