# File Organisation Methods — Sequential, Serial, Indexed and Random — true or false

Say whether each statement is true or false.

**1. (Sub lesson 2) An indexed-sequential file can be processed in key order and also jumped into directly.**
**Answer: True — Both powers at once — that is the whole point of adding the index to a sorted file.**

**2. (Sub lesson 1) A sequential file lets you reach the last record as fast as the first.**
**Answer: False — Access is in order from the start; the last record costs a full read to reach.**
