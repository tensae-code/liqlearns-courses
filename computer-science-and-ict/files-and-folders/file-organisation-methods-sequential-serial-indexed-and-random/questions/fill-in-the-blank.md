# File Organisation Methods — Sequential, Serial, Indexed and Random — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 2) The side table that points key ranges to places in an indexed-sequential file is called the ____.**
**Answer: index — Like a book's index — small, and it tells you where to jump.**

**2. (Sub lesson 2) Calculating a record's address from its key is called ____.**
**Answer: hashing — The hash formula turns the key into the address.**
