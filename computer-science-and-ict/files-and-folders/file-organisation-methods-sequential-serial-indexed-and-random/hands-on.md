# Hands-on — File Organisation Methods — Sequential, Serial, Indexed and Random

The lesson with your hands and your feet, not only your eyes.

## Model the four
With ten numbered cards, build each organisation in turn: arrival order (serial), sorted (sequential), sorted with a small index card (indexed), and scattered by the rule 'address = number × 3 mod 11' (random). Time a search for card 7 in each, with a watch or by counting reads.

## Choose and defend
Write one line each: the organisation you would choose for (a) a school's end-of-term report run over all pupils, (b) a bus company's seat lookup for one booking, (c) a teacher collecting homework slips during one lesson — with the reason in the same line.
