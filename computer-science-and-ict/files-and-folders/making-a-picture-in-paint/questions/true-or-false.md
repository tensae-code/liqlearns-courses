# Making a picture in Paint — true or false

Say whether each statement is true or false.

**1. Images can be viewed, edited and created in Paint.**
**Answer: True**

**2. Paint must be bought and installed before Windows can draw pictures.**
**Answer: False** — Paint is Windows' built-in one.

**3. GIMP and Adobe Photoshop can also create image files.**
**Answer: True**
