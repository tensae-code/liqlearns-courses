# Making a picture in Paint — multiple choice

Pick the one right answer.

**1. Windows' built-in image program is —**
a) GIMP  b) Microsoft Paint  c) Adobe Photoshop
**Answer: b) Microsoft Paint**

**2. Which list is all image programs from the book?**
a) Paint, Paint 3D, GIMP, Adobe Photoshop  b) WordPad, Notepad, Paint, Excel  c) Paint, File Explorer, Notepad, Word
**Answer: a) Paint, Paint 3D, GIMP, Adobe Photoshop**

**3. In the practical, after opening Paint you —**
a) open an old photo only  b) create your own image, then save it  c) print at once
**Answer: b) create your own image, then save it**

**4. Images in programs like Paint can be —**
a) viewed, edited and created  b) only printed  c) only deleted
**Answer: a) viewed, edited and created**
