# Lesson plan — Making a picture in Paint

**Course:** Computer Science and ICT · **Title:** Files and Folders · **Lesson:** Making a picture in Paint
**Place in the curriculum:** Unit 1 — Organization of Files — in the title Files and Folders on the ICT course ladder (TITLES.md).
**The one thing this lesson teaches:** An image file can be created in Microsoft Paint, Windows' built-in image program: Start, open Paint, create your own image, save it.
**This lesson's own level:** It stands on the document and text lessons: files you write come first; now a file you draw.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## What the learner can do when it ends
1. Name programs that view, edit and create images: Microsoft Paint, Paint 3D, GIMP, Adobe Photoshop.
2. Say which one is built into Windows: Paint.
3. Open Paint, create an image, and save it as a file.

## What you need
A Windows computer with Paint.

## If the learner is stuck
Cannot find Paint → it is Windows' built-in image program; open it from Start like the other programs in this unit. Forgets to save → an unsaved drawing is not yet a file; saving is the step that makes it one.
