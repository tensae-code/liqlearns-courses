# Hands-on — Backing up files in Windows

The lesson with your hands, not only your eyes — on a real computer where the lesson needs one.

## A real backup
Take a backup of one real folder using the lesson's five steps. Afterwards open the external drive, find the copy, and open one copied file from it — proof the copy is whole.

## Step calling
On paper, a partner shuffles the five steps. You lay them in order and mime each click. Then swap, with the partner calling steps and you stopping them on any error.
