# Backing up files in Windows — ordering

Put each set in the right order.

**1.** Put the backup steps in order: click Backup in the left column — plug the external device in — choose Update and Security — select the removable backup drive — open Start and choose Settings.
**Answer: plug the external device in — open Start and choose Settings — choose Update and Security — click Backup in the left column — select the removable backup drive.**

**2.** Put the Settings route in order: Update and Security — Settings — Backup.
**Answer: Settings — Update and Security — Backup.**
