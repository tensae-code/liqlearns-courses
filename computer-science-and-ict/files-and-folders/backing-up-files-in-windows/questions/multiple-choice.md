# Backing up files in Windows — multiple choice

Pick the one right answer.

**1.** The first step in taking a backup is —
a) click Backup  b) plug the external device in  c) choose Update and Security
**Answer: b) plug the external device in**

**2.** Settings is opened from —
a) the Recycle Bin  b) Start (or by typing 'settings' in the search box)  c) the File menu of Word
**Answer: b) Start (or by typing 'settings' in the search box)**

**3.** Backup is found inside —
a) Devices  b) Update and Security  c) Personalisation
**Answer: b) Update and Security**

**4.** In the Backup screen you click Backup in —
a) the left column  b) the title bar  c) a pop-up advert
**Answer: a) the left column**

**5.** The last step is to —
a) restart the computer  b) select the removable backup drive  c) delete the original files
**Answer: b) select the removable backup drive**
