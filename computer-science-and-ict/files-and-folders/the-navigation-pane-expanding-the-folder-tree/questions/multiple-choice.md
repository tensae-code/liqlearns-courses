# The Navigation pane — expanding the folder tree — multiple choice

Pick the one right answer.

**1. A right-pointing triangle beside a folder means —**
a) no subfolders  b) subfolders are hidden inside  c) subfolders are displayed
**Answer: b) subfolders are hidden inside**

**2. No triangle beside a folder means —**
a) the folder is empty of files  b) the folder has no subfolders  c) the folder is pinned
**Answer: b) the folder has no subfolders**

**3. Clicking a triangle —**
a) deletes the branch  b) toggles between hidden and displayed  c) renames the folder
**Answer: b) toggles between hidden and displayed**

**4. To pin a folder, right-click it and choose —**
a) Pin to Quick access  b) Delete  c) Rename
**Answer: a) Pin to Quick access** (teacher guide — evidence).
