# Lesson plan — The Navigation pane — expanding the folder tree

**Course:** Computer Science and ICT · **Title:** Files and Folders · **Lesson:** The Navigation pane — expanding the folder tree
**Place in the curriculum:** Unit 1 — Organization of Files — in the title Files and Folders on the ICT course ladder (TITLES.md).
**The one thing this lesson teaches:** The Navigation pane shows the folder tree — Quick Access, OneDrive, This PC and Network — and its triangles tell the story: no triangle, no subfolders; right-pointing, subfolders hidden; down-pointing, subfolders displayed. Any folder can be pinned to Quick Access (teacher guide — evidence).
**This lesson's own level:** It stands on Navigating with the Address bar: two travel tools — the bar across the top, and now the tree down the left side.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## What the learner can do when it ends
1. Name the Navigation pane's main sections: Quick Access, OneDrive, This PC, Network.
2. Read the triangles: none — no subfolders; right-pointing — subfolders hidden; down-pointing — subfolders displayed.
3. Expand and collapse a branch by clicking its triangle.
4. Pin a folder to Quick Access by right-clicking it and choosing 'Pin to Quick access' (teacher guide — evidence).

## What you need
A computer with File Explorer.

## If the learner is stuck
Reads the triangle backwards → right means shut (hidden inside), down means open (displayed) — like an arrow falling open. Pinned folder not visible → it lives in the Quick access area of the same pane, at the top.
