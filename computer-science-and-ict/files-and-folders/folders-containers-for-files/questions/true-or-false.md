# Folders — containers for files — true or false

Say whether each statement is true or false.

**1. A folder is the interrelated data itself.**
**Answer: False** — the file is the data itself; a folder is only the container.

**2. Paper records are easily damaged, misfiled or misplaced.**
**Answer: True** — the teacher guide's concluding frame (teacher guide — evidence).

**3. Computer files can travel by network, disk and flash memory.**
**Answer: True**
