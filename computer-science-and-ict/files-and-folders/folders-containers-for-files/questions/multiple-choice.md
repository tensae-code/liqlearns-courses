# Folders — containers for files — multiple choice

Pick the one right answer.

**1. A folder is —**
a) a single file  b) a container holding related files together  c) a kind of extension
**Answer: b) a container holding related files together** — also called a directory.

**2. A folder inside another folder is called —**
a) an extension  b) a subfolder  c) a drive
**Answer: b) a subfolder**

**3. Which one carries an extension identifying its type?**
a) a folder  b) a file  c) both
**Answer: b) a file** — folders do not carry extensions.

**4. The book pictures a folder through —**
a) a bookshelf  b) the manila dossier folders of an office  c) a school bag
**Answer: b) the manila dossier folders of an office**
