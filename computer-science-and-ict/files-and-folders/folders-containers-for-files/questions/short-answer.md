# Folders — containers for files — short answer

Answer in one or two short sentences.

**1. Give the book's difference between a file and a folder in one sentence.**
**Answer: A file is the interrelated data itself; a folder is only the container that holds files together.**

**2. Name two troubles of the paper way of filing.**
**Answer: Any two of: easily damaged, misfiled or misplaced; hard to search; needs much office space.**
