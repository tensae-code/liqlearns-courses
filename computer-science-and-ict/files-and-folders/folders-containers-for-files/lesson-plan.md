# Lesson plan — Folders — containers for files

**Course:** Computer Science and ICT · **Title:** Files and Folders · **Lesson:** Folders — containers for files
**Place in the curriculum:** Unit 1 — Organization of Files — in the title Files and Folders on the ICT course ladder (TITLES.md).
**The one thing this lesson teaches:** A folder (a directory) is a container that holds related files together — and a folder inside a folder is a subfolder; a file is the data itself, a folder is only the container, and folders carry no extension.
**This lesson's own level:** It stands on What a file is: files come first, then the containers that hold them.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## What the learner can do when it ends
1. Say what a folder is: a container holding related files together.
2. Say what a subfolder is: a folder inside another folder.
3. Give the book's difference: a file is the interrelated data itself; a folder is only the container — and files carry extensions, folders do not.
4. Tell the paper way from the computer way: paper records are kept by hand and are easily damaged, misfiled or misplaced; computer files are easy to create and manage and can travel (teacher guide — evidence).

## What you need
A computer with File Explorer. If one is near, a real paper dossier or folder from an office or home.

## If the learner is stuck
Calls a folder a file → point at the dossier: the cover holds, the papers are held. A folder holds; a file is held. Thinks a subfolder is a different thing → it is the same thing, one step in: a folder inside a folder.
