# Folders — containers for files

## Do it first

Think of an office, or of your own home. Where are the papers about one thing kept? The membership papers of an edir. The receipts of an ekub. They are not loose on the floor — they sit together inside a cover. Hold that picture. Now open a computer and look for the same idea.

## Folders and subfolders

A **folder** — also called a **directory** — is a container that holds related files together.

The book pictures it through the office: a manila dossier folder holds the papers that belong together. A computer folder does the same work for files.

A folder can sit inside another folder. A folder inside a folder is a **subfolder**. Watch one open, and then the smaller one inside it:

## File or folder — the difference

Keep the difference sharp:

- A **file** is the interrelated data itself — the letter, the photograph, the song.
- A **folder** is only the container that holds files (and subfolders) together.

And one mark tells them apart: files carry **extensions** that identify their type — .docx, .mp3 and the rest. Folders do not carry extensions.

## Paper first, then computer (teacher guide — evidence)

People filed on paper long before computers. That paper way — the way an edir, an ekub and your own school still keep many records — is created, maintained and used by hand. It is easily damaged, misfiled or misplaced, it is hard to search, and it needs much office space.

[Picture 12517 — a worn, overstuffed paper dossier beside the same records tidy on a screen]

Computer-based filing is easy to create and manage, and the files travel — by network, disk, flash memory and CD/DVD — onto a file system. Same job, new container: the folder on screen does what the dossier does on the shelf, without the shelf.

## Say it to your companion

Tell your companion what a folder is and what a subfolder is. Then give the difference in one breath: a file is the data itself, a folder is only the container — and which of the two carries an extension?

## Do It Yourself

1. Open any folder on a computer. Count the files inside it, then count the subfolders. Write both numbers and one file's extension.
2. On paper, draw a folder called School. Inside it draw two subfolders, and write two file names in each — with their extensions.
3. Find a paper folder or dossier at home or school. Name one way it is like a computer folder and one way the computer folder is better.
