# Saving, Opening and Naming a Scratch Project File — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does New do in the File menu?**
**Answer: It starts a fresh project**

**2. (Sub lesson 1) What does Save do?**
**Answer: It writes the project to its file**

**3. (Sub lesson 1) What does Save As do?**
**Answer: It writes the project under a new name or place**

**4. (Sub lesson 1) What does Open do?**
**Answer: It loads a saved project back**

**5. (Sub lesson 1) What extensions do Scratch project files carry?**
**Answer: .sb and .sb2**

**6. (Sub lesson 2) What does the file ending say?**
**Answer: What kind of file it is**

**7. (Sub lesson 2) What happens to unsaved work when the program closes?**
**Answer: It is lost for good**

**8. (Sub lesson 2) When should saving happen?**
**Answer: As a habit inside the work, not a chore after it**

**9. (Sub lesson 2) When does the book say to save?**
**Answer: When the project starts, and again as it grows**

**10. (Sub lesson 2) Which menu holds all four actions?**
**Answer: The File menu**
