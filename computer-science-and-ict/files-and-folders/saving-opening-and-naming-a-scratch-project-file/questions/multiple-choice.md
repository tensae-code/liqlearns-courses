# Saving, Opening and Naming a Scratch Project File — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does New do in the File menu?**
a) It starts a fresh project  b) It writes the project to its file  c) It loads a saved project back  d) What kind of file it is
**Answer: a) It starts a fresh project**

**2. (Sub lesson 1) What does Save do?**
a) It writes the project under a new name or place  b) It writes the project to its file  c) .sb and .sb2  d) It is lost for good
**Answer: b) It writes the project to its file**

**3. (Sub lesson 1) What does Save As do?**
a) It loads a saved project back  b) What kind of file it is  c) It writes the project under a new name or place  d) As a habit inside the work, not a chore after it
**Answer: c) It writes the project under a new name or place**

**4. (Sub lesson 1) What does Open do?**
a) .sb and .sb2  b) It is lost for good  c) When the project starts, and again as it grows  d) It loads a saved project back
**Answer: d) It loads a saved project back**

**5. (Sub lesson 1) What extensions do Scratch project files carry?**
a) .sb and .sb2  b) What kind of file it is  c) As a habit inside the work, not a chore after it  d) The File menu
**Answer: a) .sb and .sb2**

**6. (Sub lesson 2) What does the file ending say?**
a) It is lost for good  b) What kind of file it is  c) When the project starts, and again as it grows  d) It starts a fresh project
**Answer: b) What kind of file it is**

**7. (Sub lesson 2) What happens to unsaved work when the program closes?**
a) As a habit inside the work, not a chore after it  b) The File menu  c) It is lost for good  d) It writes the project to its file
**Answer: c) It is lost for good**

**8. (Sub lesson 2) When should saving happen?**
a) When the project starts, and again as it grows  b) It starts a fresh project  c) It writes the project under a new name or place  d) As a habit inside the work, not a chore after it
**Answer: d) As a habit inside the work, not a chore after it**

**9. (Sub lesson 2) When does the book say to save?**
a) When the project starts, and again as it grows  b) The File menu  c) It writes the project to its file  d) It loads a saved project back
**Answer: a) When the project starts, and again as it grows**

**10. (Sub lesson 2) Which menu holds all four actions?**
a) It starts a fresh project  b) The File menu  c) It writes the project under a new name or place  d) .sb and .sb2
**Answer: b) The File menu**
