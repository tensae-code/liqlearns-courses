# Saving, Opening and Naming a Scratch Project File — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does New do in the File menu?" is: It starts a fresh project**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does Save do?" is: It loads a saved project back**
**Answer: False** — It writes the project to its file

**3. (Sub lesson 1) True or false: the answer to "What does Save As do?" is: It writes the project under a new name or place**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does Open do?" is: What kind of file it is**
**Answer: False** — It loads a saved project back

**5. (Sub lesson 1) True or false: the answer to "What extensions do Scratch project files carry?" is: .sb and .sb2**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does the file ending say?" is: As a habit inside the work, not a chore after it**
**Answer: False** — What kind of file it is

**7. (Sub lesson 2) True or false: the answer to "What happens to unsaved work when the program closes?" is: It is lost for good**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "When should saving happen?" is: The File menu**
**Answer: False** — As a habit inside the work, not a chore after it

**9. (Sub lesson 2) True or false: the answer to "When does the book say to save?" is: When the project starts, and again as it grows**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Which menu holds all four actions?" is: It writes the project to its file**
**Answer: False** — The File menu
