# Hands-on — Saving, Opening and Naming a Scratch Project File

The lesson with your hands and your feet, not only your eyes.

## Save, close, open
Start a project, save it with Save As under a describing name, close Scratch, then Open the file and prove it is the same project.

## Beat the warning
Write the save-project warning from memory, then build the habit: save at the start of your next three projects before adding a single block.
