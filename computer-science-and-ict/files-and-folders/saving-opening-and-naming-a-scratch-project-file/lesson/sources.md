Placement choice: this lesson was built new for the ICT expansion (Palestine, 2026-11-14) because no existing lesson in the course covers this thing as its own lesson — the live tree was checked for the slug and for near matches before building. The placements file named this slug directly (NEW LESSON NEEDED — files-and-folders/saving-opening-and-naming-a-scratch-project-file). It sits in the Files and Folders title (files-and-folders/), following the book's own order.

Palestine’s own way (Grade 7, Programming): the Scratch course deepens in three units — programming graphics, sprites and backgrounds, sprite stories and dialogues. Local grounding is explicit: the pen unit opens by asking whether Scratch can draw ornaments like the decorations of Al-Aqsa Mosque; the stage is explained as a theatre whose actors (sprites) follow the director exactly and in order.


Kazakhstan's own way (Kobdikova G1 Digital Literacy): every keyword is given in three languages (Kazakh–Russian–English); the same national curriculum frame as the Almatykitap Grade 1 book (information etiquette / programming / robots, themes "Journey" and "Traditions and folklore") but this Arman-PV team teaches robotics on LEGO Mindstorms Education EV3 instead of WeDo 2.0, and Scratch through Kazakh folklore heroes (Aldar Kose, Makta Kyz) and national instruments (dombyra, kobyz, zhetigen); each project lesson is tiered A/B/C by difficulty.

Kazakhstan's own way (Sagimbaeva G1 Digital Literacy): Grade 1 digital literacy is organised by cross-cutting themes ("Journey"; "Traditions and folklore" — a linear algorithm is taught through setting up a yurt); Scratch programming and Lego Education WeDo 2.0 robotics already start in Grade 1; lessons carry QR codes to videos.
