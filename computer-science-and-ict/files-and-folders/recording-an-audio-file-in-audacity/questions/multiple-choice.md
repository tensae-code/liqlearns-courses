# Recording an audio file in Audacity — multiple choice

Pick the one right answer.

**1. Audacity is —**
a) a paid spreadsheet  b) a free program for recording sound  c) part of File Explorer
**Answer: b) a free program for recording sound** (teacher guide — evidence).

**2. An Audacity recording is saved as —**
a) a document file  b) an audio file  c) a folder
**Answer: b) an audio file**

**3. The audio format the guide names for a recording is —**
a) MP3  b) .docx  c) .txt
**Answer: a) MP3**

**4. A saved Audacity recording is kept —**
a) only inside the program  b) as a file, in a folder, like other files  c) on paper
**Answer: b) as a file, in a folder, like other files**
