# Recording an audio file in Audacity — true or false

Say whether each statement is true or false.

**1. Audacity costs money before you can record.**
**Answer: False** — it is a free program (teacher guide — evidence).

**2. A saved recording can be copied, moved and renamed like other files.**
**Answer: True**

**3. An audio file can be copied, moved and renamed like a document file.**
**Answer: True**
