# Video script — Recording an audio file in Audacity

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A file can be a **sound**.

The program is **Audacity**. It is free.
Open it. Press record. Speak.
Stop. **Save** the recording.

Now the sound is a file — an **audio file**.
It lives in a folder, like your documents and pictures.
