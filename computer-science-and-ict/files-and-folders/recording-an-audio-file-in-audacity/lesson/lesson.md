# Recording an audio file in Audacity

## Do it first

Clap once. The sound existed, and now it is gone. A document file keeps words and a picture file keeps a drawing — what keeps a sound? If a computer is near, look for a program with a record button. This lesson names the free program the teacher guide adds to this unit's practicals.

## Recording in Audacity (teacher guide — evidence)

The guide adds this doing-lesson beside Paint: create an **audio file** with **Audacity**, a free program for recording sound.

[Picture 12530 — the Audacity window with a recorded sound wave and its record and stop buttons]

The shape of the work is the same as every file in this unit: open the program, make the thing — here, record your voice or a sound — and save it as a file. The guide names **MP3** among the formats a recording can be kept in.

Save the recording into a folder, like every other file you have made in this unit — then it can be copied, moved, renamed and found again, exactly like a document or a picture.

## Say it to your companion

Tell your companion what Audacity is and what kind of file it makes. Then walk the shape of the work: open, record, save — and name the audio format the guide names.

## Do It Yourself

1. Open Audacity. Record a few seconds — your name and your school, said clearly.
2. Save the recording as an audio file in your folder, with a name that says what it is.
3. Find the file in File Explorer and read its extension aloud.
