# Hands-on — Recording an audio file in Audacity

The lesson with your hands, not only your eyes.

## Record and file it
Record a short greeting in Audacity — or on a phone if there is no lab — save it as an audio file, and file it in the same folder as your Paint picture. Two made files, side by side.

## Hear the extension
Find your recording in File Explorer. Read its extension and say what kind of file it is, using the extension drill from What a file is.
