# Opening a File You Saved Earlier — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Where does a saved file wait until you open it?" is: In the folder where you saved it, under the name you gave it**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What do you look for first when opening a saved file?" is: The Documents folder or the class folder**
**Answer: False** — Its icon and its name in its folder

**3. (Sub lesson 1) True or false: the answer to "Why does the book teach opening right after saving?" is: A file you cannot find again might as well not exist**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What makes a saved file easy to find again?" is: The program that made it, with your work inside**
**Answer: False** — A clear name saved in a known folder

**5. (Sub lesson 1) True or false: the answer to "What folder does the class often save into?" is: The Documents folder or the class folder**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How do you open a file from its folder?" is: Start the work again from nothing**
**Answer: False** — Double-click it

**7. (Sub lesson 2) True or false: the answer to "What opens when you double-click a saved file?" is: The program that made it, with your work inside**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is the menu route for opening from inside a program?" is: In the folder where you saved it, under the name you gave it**
**Answer: False** — File, then Open, then choose the folder and the name

**9. (Sub lesson 2) True or false: the answer to "What must you not do when you have saved work?" is: Start the work again from nothing**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What do you do when you finish working on an opened file?" is: A file you cannot find again might as well not exist**
**Answer: False** — Save again, then close the file
