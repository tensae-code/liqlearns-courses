# Opening a File You Saved Earlier — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Where does a saved file wait until you open it?**
a) In the folder where you saved it, under the name you gave it  b) Its icon and its name in its folder  c) A file you cannot find again might as well not exist  d) A clear name saved in a known folder
**Answer: a) In the folder where you saved it, under the name you gave it**

**2. (Sub lesson 1) What do you look for first when opening a saved file?**
a) A file you cannot find again might as well not exist  b) Its icon and its name in its folder  c) A clear name saved in a known folder  d) The Documents folder or the class folder
**Answer: b) Its icon and its name in its folder**

**3. (Sub lesson 1) Why does the book teach opening right after saving?**
a) A clear name saved in a known folder  b) The Documents folder or the class folder  c) A file you cannot find again might as well not exist  d) Double-click it
**Answer: c) A file you cannot find again might as well not exist**

**4. (Sub lesson 1) What makes a saved file easy to find again?**
a) The Documents folder or the class folder  b) Double-click it  c) The program that made it, with your work inside  d) A clear name saved in a known folder
**Answer: d) A clear name saved in a known folder**

**5. (Sub lesson 1) What folder does the class often save into?**
a) The Documents folder or the class folder  b) Double-click it  c) The program that made it, with your work inside  d) File, then Open, then choose the folder and the name
**Answer: a) The Documents folder or the class folder**

**6. (Sub lesson 2) How do you open a file from its folder?**
a) The program that made it, with your work inside  b) Double-click it  c) File, then Open, then choose the folder and the name  d) Start the work again from nothing
**Answer: b) Double-click it**

**7. (Sub lesson 2) What opens when you double-click a saved file?**
a) File, then Open, then choose the folder and the name  b) Start the work again from nothing  c) The program that made it, with your work inside  d) Save again, then close the file
**Answer: c) The program that made it, with your work inside**

**8. (Sub lesson 2) What is the menu route for opening from inside a program?**
a) Start the work again from nothing  b) Save again, then close the file  c) In the folder where you saved it, under the name you gave it  d) File, then Open, then choose the folder and the name
**Answer: d) File, then Open, then choose the folder and the name**

**9. (Sub lesson 2) What must you not do when you have saved work?**
a) Start the work again from nothing  b) Save again, then close the file  c) In the folder where you saved it, under the name you gave it  d) Its icon and its name in its folder
**Answer: a) Start the work again from nothing**

**10. (Sub lesson 2) What do you do when you finish working on an opened file?**
a) In the folder where you saved it, under the name you gave it  b) Save again, then close the file  c) Its icon and its name in its folder  d) A file you cannot find again might as well not exist
**Answer: b) Save again, then close the file**
