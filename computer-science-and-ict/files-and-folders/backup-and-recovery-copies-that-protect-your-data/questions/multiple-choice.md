# Backup and recovery — copies that protect your data — multiple choice

Pick the one right answer.

**1.** A backup is —
a) the original file, renamed  b) a digital copy of what matters most, kept on a separate system or medium  c) a printed list of filenames
**Answer: b) a digital copy of what matters most, kept on a separate system or medium**

**2.** Backup and recovery is also called —
a) operational recovery  b) file conversion  c) zipping
**Answer: a) operational recovery**

**3.** Which is NOT one of the dangers a backup protects against?
a) a virus or malware attack  b) accidental deletion  c) a file having a long name
**Answer: c) a file having a long name**

**4.** Restoring means —
a) deleting the copy  b) copying backed-up data back to its original device or a new one  c) making the first copy
**Answer: b) copying backed-up data back to its original device or a new one**

**5.** A backup copy kept in the same folder on the same disk fails because —
a) it shares the original's fate if the disk fails  b) folders cannot hold two files  c) the name would be too long
**Answer: a) it shares the original's fate if the disk fails**
