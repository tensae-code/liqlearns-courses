# Creating and saving a document file — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A document file is made in —
a) a word processor  b) Paint  c) the Recycle Bin
**Answer: a) a word processor** — WordPad, MS Word and LibreOffice Writer are named.

**2. (Sub lesson 1)** The practical's document is titled —
a) Ethiopian Wildlife  b) Ethiopian Cultural Foods  c) My First File
**Answer: b) Ethiopian Cultural Foods**

**3. (Sub lesson 2)** Save does what?
a) saves a new file  b) updates a file that is already saved  c) deletes the old file
**Answer: b) updates a file that is already saved**

**4. (Sub lesson 2)** You want an existing file kept under a new name as well. Use —
a) Save  b) Save As  c) neither
**Answer: b) Save As** — Save As saves to a new place or under a new name.
