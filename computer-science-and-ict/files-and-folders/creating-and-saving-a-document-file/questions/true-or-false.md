# Creating and saving a document file — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Files are made by software.
**Answer: True**

**2. (Sub lesson 2)** Save As leaves the original file as it was when it saves under a new name.
**Answer: True**

**3. (Sub lesson 2)** The first saving of a brand-new file is plain Save work, not Save As.
**Answer: False** — a new file is saved with Save As, with a place and a name.

**4. (Sub lesson 3)** Some features of the original file may not survive a format change, so the new file should be checked and the original kept.
**Answer: True**

**5. (Sub lesson 3)** Word saves the pupil's work automatically every 10 minutes by default (teacher guide — evidence).
**Answer: True**
