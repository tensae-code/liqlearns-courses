# Creating and saving a document file — short answer

Answer in one or two short sentences.

**1. (Sub lesson 2)** A classmate saves every change with Save As and ends with five copies. What went wrong?
**Answer: Changes to an already-saved file, same place and same name, are Save work; Save As each time makes a new copy instead of updating the file.**

**2. (Sub lesson 3)** Why does a program's default format guarantee everything is stored correctly, and why change it anyway?
**Answer:** The default format is the program's own, so all of its features fit it exactly. The format is changed when the file must work in another program or form — for example a TIFF image needed as a JPEG.
