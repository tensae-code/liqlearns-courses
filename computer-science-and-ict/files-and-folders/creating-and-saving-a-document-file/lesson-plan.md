# Lesson plan — Creating and saving a document file

**Course:** Computer Science and ICT · **Title:** Files and Folders · **Lesson:** Creating and saving a document file
**Place in the curriculum:** Unit 1 — Organization of Files — in the title Files and Folders on the ICT course ladder (TITLES.md).
**The one thing this lesson teaches:** A document file is made in a word processor, and saving splits in two: Save updates a file already saved; Save As saves a new file, or an existing file to a new place or under a new name.
**This lesson's own level:** It stands on Opening File Explorer: the learner can reach their files, and now makes the first kind — a document.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Creating the document** — files are made by software; the practical builds a document titled Ethiopian Cultural Foods in a word processor.
2. **Save and Save As** — Save updates an already-saved file; Save As saves a new file, or an existing file to a new place or under a new name.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## What the learner can do when it ends
1. Name programs that make document files: WordPad, MS Word, LibreOffice Writer.
2. Build a document titled Ethiopian Cultural Foods, with a paragraph typed from sources.
3. Say the difference: Save updates an already-saved file; Save As saves new, or to a new place or name.

## What you need
A computer with a word processor (WordPad, MS Word or LibreOffice Writer).

## If the learner is stuck
Uses Save As every time → ask where the file should live: same place, same name means Save; new file, new place or new name means Save As. Cannot start the paragraph → start from one food and one fact about it; the title is given, the paragraph grows from sources.
