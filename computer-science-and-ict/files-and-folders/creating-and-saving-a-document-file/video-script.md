# Video script — Creating and saving a document file

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Files are made by programs.
A document is made in a **word processor** — WordPad, Word, LibreOffice Writer.

Make one now.
Title: **Ethiopian Cultural Foods**.
Type your paragraph.

Now save it. Two kinds of saving — do not mix them.
The file is new? **Save As**. Give it a place. Give it a name.
The file is already saved, and you changed it? **Save**. Same place, same name, new work kept.

Save As starts the file's life.
Save keeps it up to date.

---

Grade 10 depth — a short save-in-another-format walkthrough: File. Save As. Browse. Pick the file. Open the Save as type list — choose JPEG. Save. Now check the new file, and keep the original safe: some features may not survive the change.
