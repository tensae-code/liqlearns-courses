# Creating and saving a document file

## Do it first

Open a word processor. Type one line about a food from your home — injera, tibs, shiro, whatever you know best. Now look: that line lives only on this screen. Close nothing yet. This lesson builds the book's document properly, and then teaches the two kinds of saving that put a file safely on the computer.

## Sub lesson 1 — Creating the document

Files are made by software. A document file is made in a **word processor** — the book names **WordPad**, **MS Word** and **LibreOffice Writer**.

The practical: build a document titled **Ethiopian Cultural Foods**. Type a paragraph about it, gathered from your sources — the foods, where they come from, how they are eaten.

## Sub lesson 2 — Save and Save As

Saving is two different jobs, and the names must not be mixed:

- **Save** updates a file that is **already saved**. The work you just did replaces the older saved work, in the same place, under the same name.
- **Save As** saves a **new** file for the first time — or saves an existing file **to a new place** or **under a new name**, leaving the original as it was.

First saving of Ethiopian Cultural Foods? That is Save As work: the file is new, and it needs a place and a name. Every saving after that, same place, same name? That is plain Save.

*Tip — from us, not from the books: save early and save often — a few seconds of saving protects an hour of typing.*

## Say it to your companion

Tell your companion how the Ethiopian Cultural Foods document is made, and then the difference between Save and Save As. Let your companion test you: 'The file is brand new — which one?' 'You changed one line in a saved file — which one?'

## Do It Yourself

1. In a word processor, create the document titled Ethiopian Cultural Foods and type a real paragraph about the foods.
2. Save it with Save As into a folder you choose, under its title as the name.
3. Add one more sentence, then use Save. Close the document, open it again, and check both parts are there.
