# Hands-on — Project — Class Folders and a Paint Drawing of a Computer Part

The lesson with your hands and your feet, not only your eyes.

## Build the class tree
Create the three main folders, each with teachers and pupils subfolders, and put one real file of each kind in its home.

## Draw and file it
Draw your favourite computer part in Paint, save it, and file it in the project's pictures folder under a name that says what it shows.
