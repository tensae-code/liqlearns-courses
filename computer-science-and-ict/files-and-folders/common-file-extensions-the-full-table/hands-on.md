# Hands-on — Common file extensions — the full table

The lesson with your hands, not only your eyes — on a real computer where the lesson needs one.

## Table from memory
Cover the picture. Write the whole table on paper — extension, type, contents. Uncover and mark your own work; rewrite every row you missed.

## Real files, real rows
On a real computer, find one file for each row of the table that you can. Write its full name beside the row. Rows with no file found stay marked 'none found here'.
