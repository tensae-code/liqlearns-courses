# Lesson plan — Common file extensions — the full table

**Course:** Computer Science and ICT · **Title:** Files and Folders · **Lesson:** Common file extensions — the full table
**Place in the curriculum:** Unit 1 — Organization of Files (Grade 10 depth) — in the title Files and Folders on the ICT course ladder (CURRICULUM.md).
**The one thing this lesson teaches:** the fuller table of file types, extensions and contents — and the rule that how long an extension may be differs by system: optional in Unix, required in Linux and Windows; three characters in DOS, three or four in Windows, unlimited in Unix-based systems.
**This lesson's own level:** It stands on File name extensions — reading a file's ending: the learner can already read an ending; this lesson widens the set to the full table and adds the length rules.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
This lesson is one whole lesson — it has no sub lessons (a short, single-skill lesson; his ruling 2026-11-09).

## Before this lesson
- Recommended first: File name extensions — reading a file's ending, in this same title. Recommended, never forced.

## What the learner can do when it ends
1. Pair each taught extension with its file type and contents.
2. Say which systems require an extension and which make it optional.
3. State the length rule for DOS, for Windows, and for Unix-based systems.

## What you need
Paper and a pencil. A computer with files on it, if one is near.

## The run of the lesson (in order)
1. **Do it first** — write every file ending you already know on paper, and beside each one the kind of file — before the full table is shown (lesson/lesson.md).

## If the learner is stuck
- Mixes .xls with .doc → anchor by program: the spreadsheet endings carry an x (xlsx, xls); the Word endings carry a d (doc, docx).
- Thinks every system allows any length → DOS is the strict one: three characters only.
