# Common file extensions — the full table — multiple choice

Pick the one right answer.

**1.** A .pdf file is —
a) a presentation  b) a portable document  c) an Access database
**Answer: b) a portable document**

**2.** Which endings name compression?
a) .zip / .rar  b) .mp3 / .wav  c) .doc / .docx
**Answer: a) .zip / .rar**

**3.** An .exe file is —
a) a simple text file  b) a self-extracting program  c) a spreadsheet
**Answer: b) a self-extracting program**

**4.** In which system is an extension optional?
a) Windows  b) Linux  c) Unix
**Answer: c) Unix**

**5.** DOS allows an extension of —
a) three characters  b) unlimited length  c) four characters only
**Answer: a) three characters**
