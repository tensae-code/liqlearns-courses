# Hands-on — Deleting a file — Recycle Bin and permanent delete

The lesson with your hands, not only your eyes.

## Delete and restore drill
Delete a practice file by each of the three routes in turn, restoring it from the Recycle Bin after each delete. The drill ends when all three routes and one restore are done cleanly.

## The guide's model delete (teacher guide — evidence)
In the guide's model run, delete the duplicated testfile copy and find it waiting in the Recycle Bin (teacher guide — evidence). Say the guide's discussion point aloud: duplicates waste storage and clutter organisation — while a deliberate copy on a different device is good backup practice.
