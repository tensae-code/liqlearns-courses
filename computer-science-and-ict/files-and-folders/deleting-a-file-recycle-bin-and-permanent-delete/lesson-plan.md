# Lesson plan — Deleting a file — Recycle Bin and permanent delete

**Course:** Computer Science and ICT · **Title:** Files and Folders · **Lesson:** Deleting a file — Recycle Bin and permanent delete
**Place in the curriculum:** Unit 1 — Organization of Files — in the title Files and Folders on the ICT course ladder (TITLES.md).
**The one thing this lesson teaches:** Deleting tidies duplicated and unwanted files — Delete key, right-click → Delete, or Home → Delete — and an ordinary delete goes to the Recycle Bin, from which it can be restored, while Shift+Delete deletes permanently.
**This lesson's own level:** It stands on Moving a file: files can be made, copied, renamed and moved — now the learner removes them, safely.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. ## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Deleting — three ways, and what a folder takes with it** — the Delete key, right-click → Delete, Home → Delete, with Ctrl for several; deleting a folder deletes everything inside it.
2. **The Recycle Bin, restoring, and permanent delete** — ordinary deletes land in the Recycle Bin and can be restored; Shift+Delete skips the Bin forever; never delete what you do not know on the local disk.

3. **Deleting at Grade 10 depth — the three routes, and why we delete** — right-click → Delete (then Yes), the Delete key, or dragging onto the Recycle Bin icon; deleting a folder deletes everything inside it; the reasons: freeing disk space, removing duplicates and unneeded data, and making sensitive information unavailable to others.
4. **Restoring at Grade 10 depth — and the three times it cannot be done** — double-click the Bin, find the file, right-click → Restore, and it returns to its original location; impossible when the file is not in the Bin, when the Bin has been emptied, or when Shift+Delete was used.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## What the learner can do when it ends
1. Delete three ways: Delete key, right-click → Delete, Home → Delete — Ctrl held to select several first.
2. Say what deleting a folder does: everything inside it is deleted too.
3. Restore a file from the Recycle Bin.
4. Tell the two deletes apart: ordinary delete → Recycle Bin (restorable); Shift+Delete → permanent, skipping the Bin.
5. Keep the caution: the local disk holds files the computer needs — do not delete what you do not know.

## What you need
A computer with File Explorer and practice files you may delete.

## If the learner is stuck
Thinks Delete destroys at once → open the Bin and show the file waiting there; restoring is the proof. Cannot tell the two deletes apart → ordinary Delete goes to the Bin (a net); Shift+Delete skips the Bin (no net, forever).
