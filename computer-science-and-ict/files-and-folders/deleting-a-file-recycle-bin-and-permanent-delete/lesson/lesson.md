# Deleting a file — Recycle Bin and permanent delete

## Do it first

Delete a practice file — one made only for practice. Gone? Now try to get it back. Where would a deleted file wait, if it waited anywhere? Try your ideas first. This lesson gives the book's deleting routes, and the safety net underneath one of them — and the route that has no net at all.

## Sub lesson 1 — Deleting — three ways, and what a folder takes with it

Deleting tidies the computer: it removes **duplicated and unwanted files**.

The three routes:

- Press the **Delete key**, or
- **Right-click → Delete**, or
- **Home → Delete**.

For several files at once, hold **Ctrl** and select them first, then delete.

One weighty rule: **deleting a folder deletes everything inside it** — every file and subfolder goes with it. Look inside a folder before you delete it.

## Sub lesson 2 — The Recycle Bin, restoring, and permanent delete

An ordinary delete does not destroy the file. It goes to the **Recycle Bin** — and from the Bin, a file **can be restored** to where it was.

The other delete has no net: **Shift+Delete deletes permanently, skipping the Bin.** There is no restore after it. Use it only when you mean forever.

And the section's closing caution, whole: **the local disk holds files the computer needs to run — do not delete what you do not know.**

## Sub lesson 3 — Deleting at Grade 10 depth — the three routes, and why we delete

*The second pass. The Grade 9 routes stand; here they are worked in full, with their reasons.*

Deletion removes a file from the file system into the **Recycle Bin** — the desktop location where deleted files and folders wait temporarily, in every Windows version. The routes:

[Picture 14114 — three routes to the Bin]

1. **Right-click** the file and choose **Delete** — then **Yes** in the confirmation dialogue.
2. **Select** the file and press the **Delete key**.
3. **Drag** the file onto the **Recycle Bin icon**.

Deleting a **folder** deletes **everything inside it** — the warning to carry into every folder delete.

Why delete at all? The reasons named: **freeing disk space**; removing **duplicates and unneeded data** that cause confusion; and making **sensitive information unavailable to others**. And the permanent way stands where Grade 9 left it: holding **Shift** while pressing Delete **bypasses the Recycle Bin** and removes the file completely.

## Sub lesson 4 — Restoring at Grade 10 depth — and the three times it cannot be done

Files deleted from the hard drive are **not removed at once** — they wait in the Recycle Bin, and from there they can be restored:

[Picture 14115 — restoring, and when you cannot]

[GIF 14125 — Restore sends the file home]

1. **Double-click** the Recycle Bin icon.
2. **Find** the file in the list shown.
3. **Right-click** it and choose **Restore** — it leaves the Bin and returns to its **original location**.

Restoration is **impossible** in three stated cases: the file **is not in the Recycle Bin**; the Bin **has been emptied** (right-click the Bin icon → **Empty Recycle Bin**); or the file was deleted with **Shift+Delete**. Restoring in the wider sense — returning lost, stolen or damaged data from backup — is the Backup lessons' ground, and it is why the copies exist.
