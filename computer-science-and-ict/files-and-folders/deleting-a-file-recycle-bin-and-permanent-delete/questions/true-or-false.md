# Deleting a file — Recycle Bin and permanent delete — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Deleting tidies duplicated and unwanted files.
**Answer: True**

**2. (Sub lesson 2)** A file deleted with Shift+Delete can be restored from the Recycle Bin.
**Answer: False** — Shift+Delete skips the Bin; it is permanent.
