# Deleting a file — Recycle Bin and permanent delete — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 1)** Hold ____ to select several files before deleting them together.**
**Answer: Ctrl**

**2. (Sub lesson 2)** Do not delete what you do not ____ — the local disk holds files the computer needs to run.**
**Answer: know**

**3. (Sub lesson 4)** A restored file returns to its ______ location.
**Answer: original**
