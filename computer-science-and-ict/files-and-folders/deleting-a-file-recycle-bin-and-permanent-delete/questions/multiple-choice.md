# Deleting a file — Recycle Bin and permanent delete — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Which list is the book's three deleting routes?
a) Delete key, right-click → Delete, Home → Delete  b) Ctrl+X, Ctrl+C, Ctrl+V  c) F2, Delete key, Shift
**Answer: a) Delete key, right-click → Delete, Home → Delete**

**2. (Sub lesson 1)** Deleting a folder —
a) deletes only the folder's name  b) deletes everything inside it  c) moves its contents out first
**Answer: b) deletes everything inside it**

**3. (Sub lesson 2)** An ordinary delete sends the file to —
a) the Recycle Bin  b) another drive  c) the printer
**Answer: a) the Recycle Bin** — from which it can be restored.

**4. (Sub lesson 2)** Shift+Delete —
a) restores the file  b) deletes permanently, skipping the Bin  c) renames the file
**Answer: b) deletes permanently, skipping the Bin**
