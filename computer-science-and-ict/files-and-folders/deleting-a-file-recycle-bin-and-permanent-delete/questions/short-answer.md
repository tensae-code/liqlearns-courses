# Deleting a file — Recycle Bin and permanent delete — short answer

Answer in one or two short sentences.

**1. (Sub lesson 2)** Two pupils delete the same practice file, one with Delete, one with Shift+Delete. Only one can change their mind. Which one, and why?
**Answer: The Delete-key pupil — the file waits in the Recycle Bin and can be restored. Shift+Delete is permanent.**
