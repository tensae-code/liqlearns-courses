# Deleting a file — Recycle Bin and permanent delete — ordering

Put the steps in the right order.

**1. (Sub lesson 2)** Put the restore in order.
Steps: The file is back where it was · Open the Recycle Bin · Choose Restore · Delete a file by an ordinary delete
**Answer: 1. Delete a file by an ordinary delete. 2. Open the Recycle Bin. 3. Choose Restore. 4. The file is back where it was.**

**2. (Sub lesson 3)** Put the right-click delete route in order: choose Delete — right-click the file — click Yes in the confirmation dialogue.
**Answer: right-click the file — choose Delete — click Yes in the confirmation dialogue.**
