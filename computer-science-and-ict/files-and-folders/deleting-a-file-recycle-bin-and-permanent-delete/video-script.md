# Video script — Deleting a file — Recycle Bin and permanent delete

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

**Deleting** tidies up. Three ways.

**Delete key.** Right-click — **Delete**. Home — **Delete**.
Many files? Hold **Ctrl**, select, delete.
A folder? Everything inside goes too. Look first.

Where does it go? The **Recycle Bin**.
From the Bin, a file can come back — **restore** it.

But **Shift+Delete**? No Bin. No return. Forever.

And never delete what you do not know.
The disk holds files the computer needs.
