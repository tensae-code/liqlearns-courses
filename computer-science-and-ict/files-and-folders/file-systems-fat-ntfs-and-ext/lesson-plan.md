## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **What a file system is — the disk's order** — A **file system** is the way an **operating system organises, names, stores and finds files** on a disk. It decides how a file gets its **name**, where its data is **stored**, and how it is **found again** — the disk's whole order. Without a file system, the disk's data is an unlabelled pile: the bytes are there, but no name points to them and nothing can be retrieved. Every save and every open you have ever done ran through a file system.
2. **The named families — FAT, NTFS and ext** — Sri Lanka's book names the families a learner will meet. The **FAT** family — **FAT16 and FAT32** — is the oldest and simplest of the set, long used on small drives and memory cards. **NTFS** is the file system of **Windows**, built for larger disks and files. **ext4** and **ReiserFS** belong to **Linux**. There are several families because they were made at different times, for different disk sizes and different operating systems — the file system you can use is the one your operating system knows.
