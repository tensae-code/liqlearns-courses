# File Systems — FAT, NTFS and ext — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a file system?" is: The way an operating system organises, names, stores and finds files on a disk**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What happens without a file system?" is: The operating system**
**Answer: False** — The disk's data is an unlabelled pile — no name points to a file and nothing can be found again

**3. (Sub lesson 1) True or false: the answer to "Who manages the file system?" is: The operating system**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does the file system decide?" is: Every save and every open**
**Answer: False** — How a file is named, where its data is stored, and how it is found again

**5. (Sub lesson 1) True or false: the answer to "What runs through a file system every time?" is: Every save and every open**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Name the FAT file systems in Sri Lanka's book." is: NTFS**
**Answer: False** — FAT16 and FAT32

**7. (Sub lesson 2) True or false: the answer to "Which file system does Windows use?" is: NTFS**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Name a Linux file system from the book." is: On small drives and memory cards**
**Answer: False** — ext4 (or ReiserFS)

**9. (Sub lesson 2) True or false: the answer to "Where is the FAT family long used?" is: On small drives and memory cards**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why are there several file systems?" is: The way an operating system organises, names, stores and finds files on a disk**
**Answer: False** — They were made at different times, for different disk sizes and different operating systems
