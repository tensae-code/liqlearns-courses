# File Systems — FAT, NTFS and ext — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a file system?**
**Answer: The way an operating system organises, names, stores and finds files on a disk**

**2. (Sub lesson 1) What happens without a file system?**
**Answer: The disk's data is an unlabelled pile — no name points to a file and nothing can be found again**

**3. (Sub lesson 1) Who manages the file system?**
**Answer: The operating system**

**4. (Sub lesson 1) What does the file system decide?**
**Answer: How a file is named, where its data is stored, and how it is found again**

**5. (Sub lesson 1) What runs through a file system every time?**
**Answer: Every save and every open**

**6. (Sub lesson 2) Name the FAT file systems in Sri Lanka's book.**
**Answer: FAT16 and FAT32**

**7. (Sub lesson 2) Which file system does Windows use?**
**Answer: NTFS**

**8. (Sub lesson 2) Name a Linux file system from the book.**
**Answer: ext4 (or ReiserFS)**

**9. (Sub lesson 2) Where is the FAT family long used?**
**Answer: On small drives and memory cards**

**10. (Sub lesson 2) Why are there several file systems?**
**Answer: They were made at different times, for different disk sizes and different operating systems**
