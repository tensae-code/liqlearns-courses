# Hands-on — File Systems — FAT, NTFS and ext

The lesson with your hands and your feet, not only your eyes.

## Task one
('Name the system under your files', 'On a computer you can use, find which file system its disk uses (its properties will say). Write the family name and one thing that tells you it belongs to that family.')

## Task two
('Order from a pile', 'Take ten loose papers with no names or folders. Time how long finding one takes. Then give each a name and an order — your own file system — and time the finding again. Write what changed.')
