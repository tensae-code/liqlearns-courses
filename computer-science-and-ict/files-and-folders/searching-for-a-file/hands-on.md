# Hands-on — Searching for a file

The lesson with your hands, not only your eyes.

## Hide and search
A partner notes the name of a file somewhere on the computer without telling you its folder. Find it using route 1. Then hide one for them and watch them use route 2. Both files found, both routes used.

## Part-name ladder
Take one file's name. Search with its first two letters, then four, then the whole name. After each search, say how the results changed.
