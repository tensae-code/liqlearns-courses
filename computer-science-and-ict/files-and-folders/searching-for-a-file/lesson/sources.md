Saudi Arabia's own way (Grade 4, Digital Skills): the primary Digital Skills course (Binary Logic) is built as three units per term with the same guide pattern as the intermediate books (outcomes, important points, steps, answers, unit project, "Test Yourself"), files on the Ain platform, and a strong Arabic/English bilingual-typing strand — pupils switch the keyboard between Arabic and English with Alt+Shift and learn text direction, hamza and Arabic punctuation on the keyboard alongside Word skills; Scratch is introduced in Term 1 through algorithms from daily life. This citation is PARTIAL — Term 1 only. (teacher guide — evidence)

Morocco's own way (Grade 1): ICT from age 6 built entirely on handling real hardware first — plug in, switch on, draw with the mouse, type in Word — with every unit taught in the same five-step rhythm (mobilisation, découverte, application, évaluation, réemploi) in pairs/groups, and files taught through paper folders and plastic sleeves before the screen. (teacher guide — evidence)

Cuba's own way (Grade 5): The Grade 5 programme is built around extracting information from Cuban educational software, encyclopedias and EcuRed into word-processor documents, then Scratch — drawing/animation first (Unit 3), control/movement/appearance blocks in Unit 4. (teacher programme — evidence)

Cuba's own way (Grade 5): Same Grade 5 content as the Programa, recast as per-unit teaching tables with hour allocations; Unit 4 is renamed “Aprendiendo y creando” and taught purely as Scratch control, movement and appearance blocks. (teacher guide — evidence)

Cuba's own way (Grade 5): Student text mirrors the programme in four chapters; word-processing is taught as a research workflow (synonyms, symbols, searching, copying texts and images from sources), and Scratch is introduced through its paint editor before movement/appearance/control blocks.

Sri Lanka's own way (Grade 8 Reading Book): number systems and binary conversion open Grade 8; "physical computing" is logic gates taught through water-valve and street-lamp analogies; Scratch selection structures and mobile/smart-device apps sit in the Programming chapter.

Indonesia's own way (Indonesia Grade 7 G7 Informatika teacher guide): Panduan Umum sets out capaian pembelajaran, pedagogy principles and assessment for Grade 7; each chapter guide presents the essential material, pre-learning assessment, a step-by-step guide to the student book, enrichment/remedial, answer keys and parent interaction. (teacher guide — evidence)


Kazakhstan's own way (Kadirkulov G3 Digital Literacy): Grade 3 is built around making a whole Scratch game (scenario, scenes, characters, costumes) and an EV3 robotics project, with Word and PowerPoint taught as the project's tools; "Check yourself! Creative tasks" lessons close each section (printed pp. 29, 59, 95, 126 — assessment pages, not placed).

Kazakhstan's own way (Kadirkulov G3 «Цифровая грамотность»): the Almatykitap Grade 3 digital literacy book is built as projects: a Scratch game built scene by scene, then a robotics project that oddly starts in Word (the project document is written and illustrated first) before the robot arm moves, and a cleaner robot is built; presentations and a photo collection close the year.

Kazakhstan's own way (Kadirkulov G3 «Ақпараттық-коммуникациялық технологиялар»): the older Almatykitap Grade 3 ICT book (2018, a different book from the 2021 Digital Literacy, Book 23) is organised by cross-curricular themes — Living Nature, What is Good and What is Bad, Time, Architecture, Art, Outstanding People, Water is the Source of Life, Culture of Rest — and teaches sound (playback, effects, recording, processing) and the graphics editor inside them, ending every theme with a defended mini-project.
