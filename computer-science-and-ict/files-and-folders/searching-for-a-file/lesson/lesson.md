# Searching for a file

## Do it first

Somewhere on this computer is a file whose name you know — but whose folder you have forgotten. Hunt for it the slow way, folder by folder, and notice the cost. The full name is not even needed for what comes next. This lesson gives the book's two search routes.

## Searching for a file — two routes

Windows can find a file from **part of its name** — the full name is not needed.

**Route 1 — the Windows key.** Press the **Windows key** and **type part or all of the name**. The matching files appear in the results — **click the file** to open it.

**Route 2 — File Explorer's Search field.** In File Explorer, select **Computer/This PC** — or **one specific drive**, to search only there — and **type in the Search field at the top-right**.

## Say it to your companion

Tell your companion the two search routes, step by step. Then answer: you want to search one drive only, not the whole computer — which route, and what do you select first?

## Do It Yourself

1. Press the Windows key, type part of a file's name, and open the file from the results.
2. In File Explorer, select This PC and search from the Search field for another file.
3. Search one single drive only, for the same kind of file. Say what selecting the drive first changed.
