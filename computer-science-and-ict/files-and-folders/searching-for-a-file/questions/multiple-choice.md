# Searching for a file — multiple choice

Pick the one right answer.

**1. To find a file, you need —**
a) its full name and folder  b) part of its name only  c) its size
**Answer: b) part of its name only** — the full name is not needed.

**2. Route 1 begins by pressing —**
a) F2  b) the Windows key  c) Ctrl
**Answer: b) the Windows key** — then type part or all of the name.

**3. In File Explorer, the Search field sits —**
a) at the top-right  b) in the Status bar  c) in the Navigation pane
**Answer: a) at the top-right**

**4. To search only one drive, you first select —**
a) Quick Access  b) that one specific drive  c) the Recycle Bin
**Answer: b) that one specific drive**
