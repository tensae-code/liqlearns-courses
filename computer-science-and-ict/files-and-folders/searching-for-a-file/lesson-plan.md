# Lesson plan — Searching for a file

**Course:** Computer Science and ICT · **Title:** Files and Folders · **Lesson:** Searching for a file
**Place in the curriculum:** Unit 1 — Organization of Files — in the title Files and Folders on the ICT course ladder (TITLES.md).
**The one thing this lesson teaches:** Windows can find a file from part of its name: press the Windows key and type part or all of the name, or search from File Explorer's Search field with This PC (or one drive) selected.
**This lesson's own level:** It stands on Deleting a file: the handling set is nearly complete — copying, moving, renaming, deleting — and searching finds what handling cannot reach by browsing.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## What the learner can do when it ends
1. Search by the Windows key route: press it, type part or all of the name, click the file in the results.
2. Search by the File Explorer route: select Computer/This PC (or one drive), type in the Search field at the top-right.
3. Say why a whole drive or one drive is chosen: to search everywhere, or only there.

## What you need
A computer with files on it — one of them 'lost' in a folder you do not remember.

## If the learner is stuck
Types the full name from memory and mistypes it → part of the name is enough; type the part you are sure of and pick from the results. Searches the wrong place → select This PC for everywhere, or the one drive to search only there.
