# Video script — Searching for a file

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Lost a file? **Search** for it.
You do not need the whole name. Part is enough.

Route one: **Windows key**. Type part of the name. Click the file.

Route two: File Explorer.
Select **This PC** — or one drive, to search only there.
Type in the **Search** box, top-right.

Part of a name beats opening every folder.
