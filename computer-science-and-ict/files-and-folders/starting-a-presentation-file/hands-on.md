# Hands-on — Starting a presentation file

The lesson with your hands, not only your eyes.

## Start the wildlife file
Do the practical with a partner: open PowerPoint, New, Blank Presentation, and put a title and one line about Ethiopian wildlife on the first slide. Save the file in your folder.

## Four files line-up
Line up the files you have made in this unit — document, .txt, picture, presentation. For each, say the program that made it and the extension it carries.
