# Lesson plan — Starting a presentation file

**Course:** Computer Science and ICT · **Title:** Files and Folders · **Lesson:** Starting a presentation file
**Place in the curriculum:** Unit 1 — Organization of Files — in the title Files and Folders on the ICT course ladder (TITLES.md).
**The one thing this lesson teaches:** A presentation file is built from separate pages called slides, in software such as MS PowerPoint or LibreOffice: open the program, choose New, then a Blank Presentation, and begin adding content.
**This lesson's own level:** It stands on the document, text, picture and audio lessons: the last of the unit's file-making lessons — a file made of slides.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

- Recommended first: Making a picture in Paint, in this same title. Recommended, never forced — a learner may land on this lesson directly, and it stands alone.

## What the learner can do when it ends
1. Say what a presentation file is built from: separate pages, called slides.
2. Name presentation software: MS PowerPoint and LibreOffice.
3. Start one the practical's way: open PowerPoint, choose New, then a Blank Presentation, and begin content about Ethiopian wildlife.

## What you need
A computer with MS PowerPoint or LibreOffice.
