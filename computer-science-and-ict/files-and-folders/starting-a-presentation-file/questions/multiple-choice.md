# Starting a presentation file — multiple choice

Pick the one right answer.

**1. A presentation file is built from —**
a) paragraphs only  b) separate pages called slides  c) one long page
**Answer: b) separate pages called slides**

**2. Presentation software named in the book is —**
a) MS PowerPoint and LibreOffice  b) Paint and Notepad  c) File Explorer
**Answer: a) MS PowerPoint and LibreOffice**

**3. In the practical, after opening PowerPoint you choose —**
a) Open, then a saved file  b) New, then a Blank Presentation  c) Print
**Answer: b) New, then a Blank Presentation**
