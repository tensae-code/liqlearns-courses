# Starting a presentation file

## Do it first

You have made files of words, of plain text, of a drawing, of a sound. One kind remains in this unit: the file you show a room, one big page at a time, while you talk. If you have ever watched a teacher flip through screens on a projector, you have seen one. Try to name the program. This lesson starts one the book's way.

## Starting a presentation file

Presentation files are built from separate pages — **slides** — in software such as **MS PowerPoint** or **LibreOffice**.

The group practical, in the book's order:

1. Open **PowerPoint**.
2. Choose **New**.
3. Choose a **Blank Presentation**.
4. Begin adding content — the practical's content is **Ethiopian wildlife**.

[Picture 12531 — a blank first slide with a wildlife title typed on it]

Full presentation skills belong to a later unit. Here the point is smaller and complete: a presentation is a file like any other — made by software, saved under a name, kept in a folder.

## Say it to your companion

Tell your companion what a presentation file is built from, and name the two programs. Then give the practical's steps in order, ending with the wildlife content.

## Do It Yourself

1. Open PowerPoint (or LibreOffice). Choose New, then a Blank Presentation.
2. Type a title about Ethiopian wildlife on the first slide, and one line under it.
3. Save the file into your folder and read its extension aloud — what kind of file does it name?
