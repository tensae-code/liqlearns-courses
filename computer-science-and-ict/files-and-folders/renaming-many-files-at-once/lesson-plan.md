# Lesson plan — Renaming many files at once

**Course:** Computer Science and ICT · **Title:** Files and Folders · **Lesson:** Renaming many files at once
**Place in the curriculum:** Unit 1 — Organization of Files — in the title Files and Folders on the ICT course ladder (TITLES.md).
**The one thing this lesson teaches:** Many files are renamed in one typing: select them all in Explorer, press F2, type the new name once, and Windows numbers them in sequence — test, test (1), test (2).
**This lesson's own level:** It stands on Renaming a file or folder: one name at a time first; now a whole row at once.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## What the learner can do when it ends
1. Rename many files at once: select all, F2, type the name once.
2. Say how Windows keeps the names apart: numbering in sequence — test, test (1), test (2).
3. Say the extension rule: if extensions are shown, the extension must be included in what is typed.

## What you need
A computer with a folder of practice files.

## If the learner is stuck
Only one file renamed → the selection came first and was lost; select all the files, then F2 while they are all still selected. Extensions vanished from the names → if extensions are shown, include the extension in the typed name.
