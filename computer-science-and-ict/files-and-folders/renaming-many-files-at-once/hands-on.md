# Hands-on — Renaming many files at once

The lesson with your hands, not only your eyes.

## Photo set rename
Take five copied picture files and rename them in one typing to a set name — for example Trip, Trip (1), Trip (2). Check every name in the row.

## Before and after list
Write the old names of a practice set in one column and the new numbered names in another. Show a partner which single typing produced the whole second column.
