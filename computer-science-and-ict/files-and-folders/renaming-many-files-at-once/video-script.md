# Video script — Renaming many files at once

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Five files. One name. Type it **once**.

Select them all.
Press **F2**.
Type the name: **test**.

Now look: test. test (1). test (2).
Windows numbers them for you.

Extensions showing? Type the extension too.
