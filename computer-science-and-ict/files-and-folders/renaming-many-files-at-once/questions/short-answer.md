# Renaming many files at once — short answer

Answer in one or two short sentences.

**1. Why does Windows add (1), (2), (3) instead of giving every file the typed name exactly?**
**Answer: Names must stay unique inside the folder — the numbers keep each file's name different while sharing the typed name.**

**2. A pupil renames a row and the extensions disappear from the names. What rule was broken?**
**Answer: If extensions are shown, the extension must be included in what is typed.**
