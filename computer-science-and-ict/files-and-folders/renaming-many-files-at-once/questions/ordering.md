# Renaming many files at once — ordering

Put the steps in the right order.

**1. Put the steps in order.
Steps: Type the new name once · Select all the files · Press F2 · Windows numbers the row
**Answer: 1. Select all the files. 2. Press F2. 3. Type the new name once. 4. Windows numbers the row.**

**2. A row renamed from the typing 'photo' reads —
Names: photo (2) · photo · photo (1)
**Answer: photo, photo (1), photo (2)** — in sequence.
