# Renaming many files at once — multiple choice

Pick the one right answer.

**1. To rename many files at once, after selecting them all you press —**
a) Enter  b) F2  c) Ctrl+C
**Answer: b) F2** — then type the new name once.

**2. Typing 'test' for a selected row gives —**
a) test, test, test  b) one file only  c) test, test (1), test (2)…
**Answer: c) test, test (1), test (2)…** — numbered in sequence.

**3. If extensions are shown, what you type must include —**
a) the date  b) the extension  c) your name
**Answer: b) the extension**
