# Renaming many files at once

## Do it first

Here are five files, all needing the same new name. Rename them one by one, the way the last lesson taught. Slow, yes? There is a way to type the name once and let the computer do the rest. This lesson is that way — the book's own steps.

## Renaming many files at once — the book's steps

1. **Select all the files** in Explorer (the selection ways from Copying a file: Ctrl, Shift, or drag a box).
2. **Press F2.**
3. **Type the new name once.**
4. Windows applies it to **all** the selected files, **numbering them in sequence**.

The book's example: type **test**, and the row becomes **test**, **test (1)**, **test (2)**, and so on — the numbers keep every name unique inside the folder.

One rule to keep: **if extensions are shown, the extension must be included in what is typed** — type the full name, ending and all.

## Say it to your companion

Tell your companion the steps for renaming many files at once. Then say what the row looks like after typing 'test' once — all the names, in order.

## Do It Yourself

1. Select five practice files. Press F2 and rename them all with one typing. Read the resulting names aloud.
2. Rename another set with extensions showing. Include the extension in what you type.
3. Say why the numbers (1), (2), (3) appear — what rule are they keeping?
