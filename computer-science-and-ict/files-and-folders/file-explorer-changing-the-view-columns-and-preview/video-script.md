# Video script — File Explorer — changing the view, columns and preview

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Same folder. **Eight** ways to see it.

Open the **View** tab.
**Tiles**: icon, type, size.
**Details**: name, type, size, dates.
**List**: name and icon only.
**Small icons. Medium icons.**
**Large. Extra-large**: big thumbnails.
**Content**: dates and size too.
Hover first — the view previews. Then click.

In Details, **right-click a heading**. Tick **Date Created**. It appears.

And the **Preview pane** — View, Panes.
Click a file. See inside it. No opening.

One folder at a time — changes stay in the folder you changed.
