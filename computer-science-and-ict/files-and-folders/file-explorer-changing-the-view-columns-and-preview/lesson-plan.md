# Lesson plan — File Explorer — changing the view, columns and preview

**Course:** Computer Science and ICT · **Title:** Files and Folders · **Lesson:** File Explorer — changing the view, columns and preview
**Place in the curriculum:** Unit 1 — Organization of Files — in the title Files and Folders on the ICT course ladder (TITLES.md).
**The one thing this lesson teaches:** A folder's display is changed from the View tab — eight views from Tiles to Content — column headings are added or removed by right-clicking a heading in Details view, and the Preview pane (View → Panes) shows a file's contents without opening it (teacher guide — evidence).
**This lesson's own level:** It stands on File Explorer — naming its parts (student book) and rests on the teacher guide's guide-only practical, labelled teacher evidence throughout.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The eight views** — Tiles, Details, List, Small icons, Medium icons, Large and Extra-large icons, and Content — hovering previews each view before it is chosen (teacher guide — evidence).
2. **Adding and removing column headings** — in Details view, right-click any heading and tick a heading such as 'Date Created' to add it, untick to remove it (teacher guide — evidence).
3. **The Preview pane** — View → Panes turns the Preview pane on, and it shows a file's contents without opening it; changes apply to the current folder only (teacher guide — evidence).

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## What the learner can do when it ends
1. Change a folder's view from the View tab, naming all eight views.
2. Say what Details view shows: name with type, size, and dates modified and created.
3. Add a column heading such as 'Date Created' by right-clicking a heading and ticking it; remove it by unticking.
4. Turn on the Preview pane (View → Panes) and preview a file without opening it.
5. Say the scope rule: view changes apply to the current folder only.

## What you need
A computer with File Explorer and a folder holding several kinds of files.

## If the learner is stuck
Looking for the views on the Home tab → display lives on the View tab; Home holds the doing commands (New folder, Copy, Delete). Heading menu will not open → you must be in Details view, and right-click a heading itself, not a file.
