# File Explorer — changing the view, columns and preview — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** How many views does the View tab offer?
a) five  b) eight  c) nine
**Answer: b) eight** (teacher guide — evidence).

**2. (Sub lesson 1)** Details view shows name with —
a) type, size, and dates modified and created  b) icons only  c) thumbnails only
**Answer: a) type, size, and dates modified and created**

**3. (Sub lesson 2)** A column heading is added in Details view by —
a) double-clicking a file  b) right-clicking any heading and ticking it  c) pressing F2
**Answer: b) right-clicking any heading and ticking it**

**4. (Sub lesson 3)** The Preview pane shows —
a) the file's contents without opening it  b) the Recycle Bin  c) only file names
**Answer: a) the file's contents without opening it**
