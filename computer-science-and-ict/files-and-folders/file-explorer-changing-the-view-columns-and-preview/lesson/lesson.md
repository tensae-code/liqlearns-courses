# File Explorer — changing the view, columns and preview

## Do it first

Open a folder of files. The files are showing one way — but it is not the only way. Try to make them show as big pictures. Then as a plain list. Then with their sizes and dates beside them. Any way you can. This guide-only lesson (teacher guide — evidence) teaches the one tab that does all of it — and two tricks that ride with it.

## Sub lesson 1 — The eight views (teacher guide — evidence)

How a folder's contents are displayed is changed from the **View tab**. There are **eight views**:

- **Tiles** — icon plus file type and size.
- **Details** — name with **type, size, and dates modified and created**.
- **List** — name and icon only.
- **Small icons** — like List.
- **Medium icons** — like Tiles but name only, with image thumbnails.
- **Large icons** and **Extra-large icons** — name only, with larger thumbnails.
- **Content** — icon, last-modified date, size, and date taken for images.

**Hovering previews each view** before it is chosen — look first, then click.

## Sub lesson 2 — Adding and removing column headings (teacher guide — evidence)

In **Details view** the columns themselves can be changed:

1. **Right-click any column heading.**
2. **Tick** a heading to add it — for example **'Date Created'**.
3. **Untick** it to remove it again.

[Picture 12555 — one folder in Details view with the heading menu open and Date Created ticked]

The folder now shows the new column beside the old ones — dates created, standing next to dates modified.

## Sub lesson 3 — The Preview pane (teacher guide — evidence)

The **Preview pane** shows a file's **contents without opening it**:

1. Open the **View** tab.
2. Choose **Panes** and turn the **Preview pane** on.
3. Click a file once — its contents show in the pane.

One scope rule closes the lesson: **changes apply to the current folder only.** Another folder keeps its own view until you change it too.

## Say it to your companion

Tell your companion the eight views in order. Then walk the two tricks: how is 'Date Created' added in Details view — and how does the Preview pane show a file without opening it?

## Do It Yourself

1. Open a folder. Set it to Tiles, then List, then Extra-large icons, hovering to preview each view first.
2. Switch to Details view. Right-click a heading, tick Date Created. Check the new column, then untick it.
3. Turn on the Preview pane from View → Panes. Click three files and read their contents without opening any of them.
