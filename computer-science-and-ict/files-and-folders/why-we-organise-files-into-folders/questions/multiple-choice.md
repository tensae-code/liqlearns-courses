# Why we organise files into folders — multiple choice

Pick the one right answer.

**1. Folders matter because they —**
a) make files bigger  b) keep related files organised and easy to locate  c) delete old files
**Answer: b) keep related files organised and easy to locate**

**2. Without folders, every file would need —**
a) an extension  b) a unique name  c) a password
**Answer: b) a unique name** — everything would sit in one place.

**3. My-letter.doc can exist in two folders because —**
a) the computer does not check names  b) each folder is its own place, so the name must only be unique inside its folder  c) one copy is hidden
**Answer: b) each folder is its own place**

**4. Without folders, which files would all sit in one place?**
a) only documents  b) documents, programs and operating-system files  c) only pictures
**Answer: b) documents, programs and operating-system files**
