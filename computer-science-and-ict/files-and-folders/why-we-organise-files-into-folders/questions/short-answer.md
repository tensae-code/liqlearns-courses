# Why we organise files into folders — short answer

Answer in one or two short sentences.

**1. Name two things that go wrong when there are no folders.**
**Answer: Everything — documents, programs and operating-system files — sits in one place, and every file needs a unique name.**

**2. Why does grouping files in folders make a file easy to locate?**
**Answer: Related files sit together, so you go straight to the folder that holds the file you want.**
