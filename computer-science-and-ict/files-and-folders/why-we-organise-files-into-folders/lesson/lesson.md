# Why we organise files into folders

## Do it first

Picture your desktop with no folders at all. Every document, every program file, every system file — all poured into one place, hundreds of names in one long spill. Now try to find one letter in it. Say what makes the search hard. Then look at the same desktop with its files grouped in folders, and feel the difference.

## Why folders matter

Folders keep related files **organised and easy to locate**. That is the whole reason, and it is enough: what belongs together sits together, and you go straight to the folder that holds it.

[Picture 12519 — two desktops side by side: one cluttered, one tidy in folders]

## Life with no folders

Without folders, documents, programs and operating-system files would all sit in one place. And a harder rule would follow: **every file would need a unique name** — no two files in the one place could share a name.

With folders, that rule relaxes. The book's own example: **My-letter.doc** can exist in two different folders at the same time, because each folder is its own place. The name only has to be unique inside its folder.

## Do It Yourself

1. Look at a real desktop or home screen. Count the loose files and the folders. Say which screen — cluttered or grouped — you would rather search, and why.
2. Write two folder names. Under each, write the same file name, My-letter.doc, and one sentence about what each letter could be about. Same name, two places — both allowed.
3. Name three groups of files in your own life that belong in three different folders. Write the folder names.
