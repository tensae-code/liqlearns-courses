# Video script — Copying a file

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

**Copying** makes a twin. The first file stays. A second file appears.

Select your file.
Many files? Hold **Ctrl** and click each one. Or hold **Shift**. Or drag a box.

Now copy. Right-click — **Copy**. Or **Ctrl+C**. Or **Home — Copy**.
Open the folder where the copy should live.
**Paste** — right-click, Paste. Or Home — Paste.

Two copies now. That is copying.
One copy only? Do not copy. **Move** — that is another lesson.

And a copy in the same folder gets a new ending: **- Copy**.
