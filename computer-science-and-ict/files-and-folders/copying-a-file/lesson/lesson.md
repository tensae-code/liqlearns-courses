# Copying a file

## Do it first

Take any file and try to make a second one just like it, in another folder. Any way you can. When you have done it, check the first folder: is the original still there? It should be — that is the heart of this lesson. Now learn the book's ways of doing it, in the book's order.

## Copying a file — the book's steps

**Select the file first.** For several files: hold **Ctrl** and click each one, or hold **Shift** for a block of neighbours, or **drag a box** around them.

Then **Copy**, three ways:

- **Right-click → Copy**, or
- **Ctrl+C**, or
- **Home → Copy**.

Then open the **destination folder** and **Paste** — by **right-click → Paste** or **Home → Paste**.

[GIF 12535 — the right-click Copy, open folder, Paste sequence]

**Copying leaves more than one copy.** The original stays where it was, and the copy stands in the new place. If you want only one copy to exist, do not copy — **move** instead (a later lesson).

[Picture 12534 — one file becoming two, the second named with - Copy after it]

A copy made **into the same folder** cannot share the original's exact name, so Windows adds a number or **'- Copy'** to its name to keep it unique.

## Say it to your companion

Tell your companion how to select several files three ways, and how to copy three ways. Then say the rule: copying leaves more than one copy — for a single copy, what do you do instead?

## Do It Yourself

1. Copy a file into a different folder using right-click Copy and Paste. Check both folders.
2. Copy the same file with Ctrl+C and Home → Paste. Check the destination.
3. Copy a file into its own folder. Write down the name the copy was given, and say why it could not keep the plain name.
