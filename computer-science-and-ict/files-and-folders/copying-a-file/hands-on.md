# Hands-on — Copying a file

The lesson with your hands, not only your eyes.

## The guide's model copy (teacher guide — evidence)
In the Test1 and Test2 folders from the guide's model run, write 'I Love Ethiopian Cultures' into testfile1.txt in Test1, then copy testfile1 into Test2 (teacher guide — evidence). Check: the file now stands in both folders.

## Three ways race
Copy one file three times, once by each copy way — right-click, Ctrl+C, Home → Copy. Paste each into a different folder and verify all three copies exist.
