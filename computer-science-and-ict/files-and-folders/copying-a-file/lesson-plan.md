# Lesson plan — Copying a file

**Course:** Computer Science and ICT · **Title:** Files and Folders · **Lesson:** Copying a file
**Place in the curriculum:** Unit 1 — Organization of Files — in the title Files and Folders on the ICT course ladder (TITLES.md).
**The one thing this lesson teaches:** Copying duplicates a file: select it (Ctrl or Shift held, or drag a box, for several), Copy by right-click, Ctrl+C or Home → Copy — then Paste in the destination folder; a copy made in the same folder gets a number or '- Copy' added to its name.
**This lesson's own level:** It stands on Creating a new folder: there is somewhere for a copy to go. For one copy only, the book says move instead — that is the next-but-one lesson.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. ## What the learner can do when it ends
1. Select one file, and several files with Ctrl, with Shift, or by dragging a box.
2. Copy three ways: right-click Copy, Ctrl+C, or Home → Copy — then Paste by right-click or Home → Paste.
3. Say what copying leaves behind: more than one copy — and what name a same-folder copy gets: a number or '- Copy'.

## What you need
A computer with File Explorer and a file to copy.

## If the learner is stuck
Original vanished → that was a move, not a copy; copying always leaves the original in place. Several files will not select together → Ctrl for scattered files, Shift for a neighbour block, or drag a box around them.
