# Copying a file — multiple choice

Pick the one right answer.

**1. Copying a file leaves —**
a) one copy only  b) more than one copy  c) no copies
**Answer: b) more than one copy** — for a single copy, move instead.

**2. To select scattered files one by one, hold —**
a) Shift  b) Ctrl  c) Alt
**Answer: b) Ctrl** — and click each file.

**3. The keyboard way to Copy is —**
a) Ctrl+V  b) Ctrl+X  c) Ctrl+C
**Answer: c) Ctrl+C**

**4. A copy made into the same folder gets —**
a) the same name  b) a number or '- Copy' added to its name  c) no name
**Answer: b) a number or '- Copy' added** — so its name stays unique.
