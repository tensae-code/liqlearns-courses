# Hands-on — File name extensions — reading a file's ending

The lesson with your hands, not only your eyes — on a real computer where the lesson needs one.

## Ending hunt
Find ten files on a school or home computer. Write each name, underline its extension, and write its kind beside it. Do not open any file — the ending alone must do the work.

## Ending dictation
A partner reads a filename aloud, ending and all. You say the kind of file and the program that opens it. Ten names each, then swap.
