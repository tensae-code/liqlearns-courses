# File name extensions — reading a file's ending — multiple choice

Pick the one right answer.

**1.** The extension of a filename is —
a) the first three letters of the name  b) the letters after the last period, at the end of the name  c) the folder the file sits in
**Answer: b) the letters after the last period, at the end of the name**

**2.** How long is an extension, as this lesson teaches it?
a) always exactly one letter  b) three or four letters  c) always ten letters
**Answer: b) three or four letters**

**3.** The operating system uses the extension to —
a) make the file smaller  b) choose which application opens the file  c) hide the file
**Answer: b) choose which application opens the file**

**4.** A file ending in .jpg is —
a) an audio file  b) an image file  c) a spreadsheet
**Answer: b) an image file**

**5.** A file ending in .mp3 is —
a) an audio file  b) a Word document  c) an image file
**Answer: a) an audio file**

**6.** Which pair both name spreadsheets?
a) .docx / .doc  b) .xlsx / .xls  c) .jpg / .jpeg
**Answer: b) .xlsx / .xls**
