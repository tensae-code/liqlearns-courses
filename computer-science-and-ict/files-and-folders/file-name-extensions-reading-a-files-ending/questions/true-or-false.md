# File name extensions — reading a file's ending — true or false

Say whether each sentence is true or false.

**1.** The extension states the file's character and use.
**Answer: True**

**2.** When you double-click a .jpg picture, the operating system picks the picture application because of the extension.
**Answer: True**

**3.** Android is not an operating system.
**Answer: False — Android is one of the operating systems named in this lesson**

**4.** .docx and .doc are audio endings.
**Answer: False — they are Word document endings**
