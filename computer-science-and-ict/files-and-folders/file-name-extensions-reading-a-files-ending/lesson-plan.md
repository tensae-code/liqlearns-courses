# Lesson plan — File name extensions — reading a file's ending

**Course:** Computer Science and ICT · **Title:** Files and Folders · **Lesson:** File name extensions — reading a file's ending
**Place in the curriculum:** Unit 1 — Organization of Files (Grade 10 depth) — in the title Files and Folders on the ICT course ladder (CURRICULUM.md).
**The one thing this lesson teaches:** every file type carries a three- or four-letter identifier after a period at the end of its name — the extension — which states the file's character and use, and which the operating system uses to choose the application that opens the file.
**This lesson's own level:** It stands on What a file is and Folders — containers for files: the learner already knows a file by its icon; this lesson teaches them to read its name. The fuller extension table is the next lesson.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## What the learner can do when it ends
1. Read the ending of a filename and say what kind of file it is.
2. Say why the operating system cares about the extension: it chooses which application opens the file.
3. Tell .jpg/.jpeg, .docx/.doc, .mp3 and .xlsx/.xls apart by kind.
4. Name the systems that manage all this: Windows, Unix, Linux, DOS, Android.

## What you need
A computer with files on it, or a phone. Paper and a pencil.

## If the learner is stuck
- Reads the whole name but misses the ending → cover everything before the last period with a finger; what is left is the extension.
- Thinks the extension is decoration → double-click the .jpg example in mind: the ending is how the system picks the picture application.
