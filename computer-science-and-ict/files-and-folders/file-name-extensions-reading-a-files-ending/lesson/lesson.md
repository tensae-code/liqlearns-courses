# File name extensions — reading a file's ending

## Do it first

Look at the names of files on a computer or phone near you. Do not open any of them. Read only the last part of each name — the letters after the final full stop — and say them out loud: *jpg … docx … mp3 …* Those endings are telling you something. This lesson teaches you to read them.

## Reading the ending

Every file type carries an identifier of three or four letters after a period at the end of its name. That identifier is the file name **extension**.

[Picture 14103 — four files, endings highlighted]

The extension states the file's character and its use. And it does a job: the **operating system** uses the extension to choose which application opens the file when you double-click it. The worked example to hold in mind is a picture file: double-click a file ending in **.jpg**, and the system opens it in its picture application — because the ending told it to.

First endings to know by heart:

- **.jpg / .jpeg** — an image file.
- **.docx / .doc** — a Word document.
- **.mp3** — an audio file.
- **.xlsx / .xls** — a spreadsheet.

The systems that manage files, folders and extensions are the operating systems. The ones named here are **Windows, Unix, Linux, DOS and Android**. Whichever one you use, it is reading endings all day long, every time you open a file.

## Say it to your companion

Read three file endings to your companion. For each one, say the kind of file and the program that will open it. Then let your companion test you with three more.

## Do It Yourself

1. Write down ten filenames from a real computer or phone. Underline each extension.
2. Beside each one, write its kind: image, Word document, audio, or spreadsheet — or 'not yet learned' if its ending is new to you.
3. Say, in one sentence, what would go wrong if a file lost its extension.
