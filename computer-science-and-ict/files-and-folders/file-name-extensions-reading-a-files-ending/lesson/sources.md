**Acceptance count: taught in 4 countries (Ethiopia, Uganda, Armenia, Kazakhstan).**

No book error touches this lesson's pages. Question answers were checked against the teacher guide's Unit 1 review keys (printed pp. 18–21) (teacher guide — evidence): the guide's key confirms that a file sent without its extension cannot be opened because the system does not know which program to use — the scenario is worked in full in the File paths lesson's sources.

Saudi Arabia's own way (Grade 8, Digital Skills): the Binary Logic series is taught in fixed periods (33 periods this term) with the student book mirrored by this guide — unit/lesson description, learning outcomes, "important points", lesson steps, worked answers and group unit projects, with all practice files delivered through the national Ain enrichment platform (ien.edu.sa). The term is three applied units: video production in Shotcut, charts in Excel, and programming a virtual robot in VEXcode VR where pupils read their own blocks as Python. (teacher guide — evidence)

Saudi Arabia's own way (Grade 4, Digital Skills): the primary Digital Skills course (Binary Logic) is built as three units per term with the same guide pattern as the intermediate books (outcomes, important points, steps, answers, unit project, "Test Yourself"), files on the Ain platform, and a strong Arabic/English bilingual-typing strand — pupils switch the keyboard between Arabic and English with Alt+Shift and learn text direction, hamza and Arabic punctuation on the keyboard alongside Word skills; Scratch is introduced in Term 1 through algorithms from daily life. This citation is PARTIAL — Term 1 only. (teacher guide — evidence)

Switzerland's own way (Grades 5–6, Décodage 5e–6e): Cycle 2 moves from unplugged games to real tools while keeping the game frame: the imaginary city “Square CT” teaches classification, decision trees, conditionals, indentation and flowcharts (logigrammes); ScratchJr tells emotion and climate stories; the Swiss Thymio robot is programmed in VPL; data is taught through binary pixel coding and colour coding; and “Enquêtes” (inquiries) teach addition-as-algorithm, debugging, sorting, the Nim winning strategy, Caesar ciphers and sensor experiments. Médias/Usages scenarios cover cyberbullying, screen practices, news and media stereotypes.

Armenia's own way (Armenia Grade 6 G6 student): Same author pair as Grade 5, one year on: the § sequence moves from society/data-rights into number systems and computing systems, then a long spreadsheet-and-diagrams block, and ends with algorithms in flowcharts and a block-based programming language.


Kazakhstan's own way (Kobdikova G1 Digital Literacy): every keyword is given in three languages (Kazakh–Russian–English); the same national curriculum frame as the Almatykitap Grade 1 book (information etiquette / programming / robots, themes "Journey" and "Traditions and folklore") but this Arman-PV team teaches robotics on LEGO Mindstorms Education EV3 instead of WeDo 2.0, and Scratch through Kazakh folklore heroes (Aldar Kose, Makta Kyz) and national instruments (dombyra, kobyz, zhetigen); each project lesson is tiered A/B/C by difficulty.

Kazakhstan's own way (Kobdikova G2 Digital Literacy): the same six-part national Grade 2 frame as the Almatykitap book, but the tools differ: the "word by word" part builds a spoken-text dialogue between two Scratch characters, sound is recorded and trimmed in the Windows Voice Recorder app (not WavePad), media players AIMP and Windows Media Player are named, the keyboard trainer is the online typingstudy.com Kazakh course, the text editor is WordPad, and the Dancing Robot dances to the Kazakh folk melody "Kamajai" loaded through the EV3 Sound Editor.

Kazakhstan's own way (Kadirkulov G7 Informatika, 2019 edition): Almatykitap's other Grade 7 book (2019, printed in Turkey) follows the same five-part frame as the Atamura 2017 book — units and memory, networks and antivirus, spreadsheets with conditional formatting and modelling, programming solutions with interface design (its bibliography is Lazarus/Delphi-based), and 3D modelling of objects and events in SketchUp.

Kazakhstan's own way (Kadirkulov G7 «Информатика» 2019 edition): the 2019 Almatykitap Grade 7 book is not the 2023 Python book (Book 15): after measurement, networks and spreadsheets it teaches programming through the Lazarus project interface — interface elements, data types, branching, nested and compound conditions — and ends with 3D modelling of objects and events (house, car, table, chair, window, glass as the final tasks).
