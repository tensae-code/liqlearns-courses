# Directory structure — root, parent and child folders

## Do it first

On paper, draw one big box. Inside it, draw two smaller boxes. Inside one of those, draw two smaller boxes still. You have just drawn the shape this lesson names — the shape a computer keeps your files in.

## The tree

The operating system shows files in a **hierarchical tree** — folders inside folders, level under level, like your drawing.

[Picture 14105 — the directory tree]

The top folder of the tree — the one inside nothing else — is the **root directory**. On the main partition it is usually **C:\**; for a DVD/CD drive the root is **D:\**.

A directory that sits inside another directory is a **subdirectory**. The pair are spoken of as a family: the folder that holds is the **parent**, and the folder held inside it is the **child**. One folder can be a child of the folder above it and a parent of the folders below it at the same time.

And the tree has a working rule: **related files are stored together in the same directory**, so they stay findable. A tree where related things scatter across unrelated folders is a tree that has stopped doing its job.

## Say it to your companion

Explain the tree to your companion with your drawing: point to the root, name one parent, name its child, and say why related files sit together.

## Do It Yourself

1. Draw the top three levels of a real drive's folders, or of your phone's files if it shows them. Label the root, one parent and one child.
2. Take six imaginary files about one school subject. Say which single directory they should all live in, and why.
3. Find one folder on a real computer that is both a child and a parent. Write down the three names that prove it.
