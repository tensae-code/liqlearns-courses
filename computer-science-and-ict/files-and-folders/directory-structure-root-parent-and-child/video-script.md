# Video script — Directory structure — root, parent and child folders

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Folders inside folders. That is a **tree**.

At the very top sits one folder inside nothing else.
That is the **root** — usually **C:**.

A folder inside another folder is a **subdirectory**.
The one that holds it is its **parent**. The one held is its **child**.

And keep related files together in one directory —
so you can find them again.

Now you. Root? Parent? Child? Point and say.
