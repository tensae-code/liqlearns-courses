# Hands-on — Directory structure — root, parent and child folders

The lesson with your hands, not only your eyes — on a real computer where the lesson needs one.

## Paper tree
Draw a school as a tree: the school is the root's child, each grade a folder, each subject a folder inside its grade. Label one parent and one child pair.

## Real tree walk
In File Explorer, open This PC, then one folder, then a folder inside it. At each level say out loud: root, parent, or child — of what?
