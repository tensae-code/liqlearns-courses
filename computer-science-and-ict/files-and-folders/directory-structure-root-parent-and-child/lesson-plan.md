# Lesson plan — Directory structure — root, parent and child folders

**Course:** Computer Science and ICT · **Title:** Files and Folders · **Lesson:** Directory structure — root, parent and child folders
**Place in the curriculum:** Unit 1 — Organization of Files (Grade 10 depth) — in the title Files and Folders on the ICT course ladder (CURRICULUM.md).
**The one thing this lesson teaches:** the operating system shows files in a hierarchical tree: the top folder is the root directory (usually C:\ on the main partition), a directory inside another is a subdirectory, and the pair are spoken of as parent and child — and related files are stored together in the same directory to keep them findable.
**This lesson's own level:** It stands on Folders — containers for files: the learner knows a folder can hold a subfolder; this lesson names the whole tree and its family words. File paths, the next lesson, walk this tree.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. ## Before this lesson

## What the learner can do when it ends
1. Point to the root of a directory tree and name it.
2. Tell a parent folder from its child (subdirectory).
3. Say why related files are stored together in the same directory.

## What you need
Paper and a pencil. A computer with folders on it, if one is near.

## If the learner is stuck
- Calls every folder a root → there is only one top: the root is the folder that is inside nothing else.
- Mixes parent and child → the parent holds; the child is held. Ask 'which one is inside which?'
