# Directory structure — root, parent and child folders — multiple choice

Pick the one right answer.

**1.** The root directory is —
a) the smallest folder in the tree  b) the top folder, inside nothing else  c) any folder with files in it
**Answer: b) the top folder, inside nothing else**

**2.** On the main partition, the root is usually —
a) D:\  b) C:\  c) E:\
**Answer: b) C:\**

**3.** A directory inside another directory is called —
a) a root  b) a subdirectory  c) a drive
**Answer: b) a subdirectory**

**4.** In the pair 'parent and child', the parent is —
a) the folder held inside  b) the folder that holds the other  c) the file at the bottom
**Answer: b) the folder that holds the other**

**5.** Related files are stored together in the same directory so that —
a) the disk spins faster  b) they stay findable  c) the tree looks bigger
**Answer: b) they stay findable**
