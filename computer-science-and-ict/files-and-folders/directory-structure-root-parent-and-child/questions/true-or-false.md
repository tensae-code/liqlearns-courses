# Directory structure — root, parent and child folders — true or false

Say whether each sentence is true or false.

**1.** The operating system shows files in a hierarchical tree.
**Answer: True**

**2.** For a DVD/CD drive, the root can be D:\.
**Answer: True**

**3.** A folder can be a child of the folder above it and a parent of folders below it at the same time.
**Answer: True**

**4.** Every folder in a tree is a root.
**Answer: False — only the top folder is the root**
