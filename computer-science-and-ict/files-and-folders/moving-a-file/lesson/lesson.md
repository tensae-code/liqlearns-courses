# Moving a file

## Do it first

Move one file into a different folder, any way you can. Then look back at the first folder. Empty of that file? Good — that absence is the whole difference between this lesson and copying. Now learn the book's three ways of moving, each in its own steps. Do not reorder them: each way is a sequence, and the sequence is the skill.

## Sub lesson 1 — Cut and paste

Moving keeps **only one copy**. For more copies, copy instead — never the other way round.

The first way is **cut and paste**:

1. Select the file.
2. **Cut** it — **right-click → Cut**, or **Home → Cut**, or **Ctrl+X**. The file now waits on a **temporary clipboard**.
3. Open the destination folder.
4. **Paste** — or press **Ctrl+V**. The file lands in its new place, and its old place is empty.

## Sub lesson 2 — Drag-and-drop with the right mouse button

The second way is **drag-and-drop**:

1. Make sure **both windows are visible** — the folder the file is in, and the folder it is going to.
2. Drag the file with the **right mouse button held** from one window to the other.
3. On release, a menu appears — choose **'Move here'**.

[GIF 12546 — a file being dragged from one window and dropped into another]

The right button is what brings the menu: it lets you choose Move here at the drop, instead of guessing what the drag will do.

## Sub lesson 3 — Move to Folder

The third way is the **Move to Folder** command:

1. Select the file.
2. **Home → Move to Folder.**
3. **Browse** to the destination folder.
4. Click **Move**. The file goes there, and only there.

[Picture 12545 — the three moving methods as three mini-strips]

Three ways, one result: the file stands in the new place, and nowhere else.

## Say it to your companion

Tell your companion the three moving methods, each in its steps. Then answer the test question: a file must exist in one place only, in a new folder — which family of methods, and why not copying?

## Do It Yourself

1. Move a file by cut and paste with Ctrl+X and Ctrl+V. Check: new place has it, old place does not.
2. With two windows visible, drag a file with the right mouse button and choose Move here.
3. Move a third file with Home → Move to Folder. Say all three methods' names from memory.
