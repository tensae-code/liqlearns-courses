# Lesson plan — Moving a file

**Course:** Computer Science and ICT · **Title:** Files and Folders · **Lesson:** Moving a file
**Place in the curriculum:** Unit 1 — Organization of Files — in the title Files and Folders on the ICT course ladder (TITLES.md).
**The one thing this lesson teaches:** Moving keeps only one copy, and it is done three ways: cut and paste (Ctrl+X, then Ctrl+V), right-button drag-and-drop choosing 'Move here', and Home → Move to Folder.
**This lesson's own level:** It stands on Copying a file: copying makes two; moving is the other half of the pair — one copy, new place.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Cut and paste** — right-click Cut, or Home → Cut, or Ctrl+X — the file waits on a temporary clipboard — then Paste / Ctrl+V at the destination.
2. **Drag-and-drop with the right mouse button** — both windows visible; drag with the right button held and choose 'Move here' from the menu on release.
3. **Move to Folder** — Home → Move to Folder, browse to the destination, click Move.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## What the learner can do when it ends
1. Say what moving does that copying does not: it keeps only one copy.
2. Move by cut and paste: Cut (right-click, Home → Cut, or Ctrl+X), then Paste / Ctrl+V.
3. Move by right-button drag-and-drop, choosing 'Move here' on release, with both windows visible.
4. Move by Home → Move to Folder, browsing to the destination and clicking Move.

## What you need
A computer with File Explorer, two folders, and a file to move.

## If the learner is stuck
File ends up in both places → a copy happened, not a move; moving leaves the old place empty — check there first. Drag gives no Move here menu → the drag must use the right mouse button, and both windows must be visible.
