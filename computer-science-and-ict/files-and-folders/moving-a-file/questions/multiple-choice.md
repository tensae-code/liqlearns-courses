# Moving a file — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Moving a file leaves —
a) two copies  b) only one copy  c) no copy
**Answer: b) only one copy** — for more copies, copy instead.

**2. (Sub lesson 1)** The keyboard Cut is —
a) Ctrl+C  b) Ctrl+V  c) Ctrl+X
**Answer: c) Ctrl+X**

**3. (Sub lesson 2)** In drag-and-drop moving, the file is dragged with —
a) the left button only  b) the right mouse button held  c) no button
**Answer: b) the right mouse button held** — then choose Move here on release.

**4. (Sub lesson 3)** Home → Move to Folder ends with clicking —
a) Copy  b) Move  c) Rename
**Answer: b) Move** — after browsing to the destination.
