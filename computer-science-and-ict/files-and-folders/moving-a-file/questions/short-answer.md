# Moving a file — short answer

Answer in one or two short sentences.

**1. (Sub lesson 1)** A pupil cuts a file and the computer is switched off before pasting. Why was Cut riskier than the other methods here?
**Answer: The cut file waits on a temporary clipboard; until it is pasted it has not landed anywhere new.**

**2. (Sub lesson 3)** Name all three moving methods.
**Answer: Cut and paste; drag-and-drop with the right mouse button (Move here); Home → Move to Folder.**
