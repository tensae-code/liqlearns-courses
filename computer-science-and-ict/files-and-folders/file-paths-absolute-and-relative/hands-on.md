# Hands-on — File paths — absolute and relative

The lesson with your hands, not only your eyes — on a real computer where the lesson needs one.

## Walk a path
In File Explorer, pick a file at least three folders down. Write its absolute path on paper first — then click through your own written path and check you arrive.

## Stand and point
Stand (in Explorer) in a folder. A partner names a file below it. Write the relative path from where you stand. Swap roles three times.
