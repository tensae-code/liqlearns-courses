# Lesson plan — File paths — absolute and relative

**Course:** Computer Science and ICT · **Title:** Files and Folders · **Lesson:** File paths — absolute and relative
**Place in the curriculum:** Unit 1 — Organization of Files (Grade 10 depth) — in the title Files and Folders on the ICT course ladder (CURRICULUM.md).
**The one thing this lesson teaches:** a path lists, from a drive letter, which folders to open to reach a file: an absolute pathname gives the complete route from the root and works from anywhere, while a relative pathname is given from the current working directory — and identical filenames are allowed in different directories because their pathnames differ.
**This lesson's own level:** It stands on Directory structure — root, parent and child folders: the learner knows the tree; this lesson learns to write the route down it. It is a doing-lesson: the learner walks paths on a real tree.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Absolute paths — the full route from the root** — the full pathname from the drive letter through every folder to the filename; why identical filenames can live in different directories.
2. **Relative paths — from where you stand** — the path given from the current working directory; the drive-relative trap the guide keys (teacher guide — evidence).

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Directory structure — root, parent and child folders, in this same title. Recommended, never forced.

## What the learner can do when it ends
1. Write the absolute pathname of a file, from the drive letter to the filename.
2. Write a relative pathname from a stated working directory.
3. Explain why two files can share one filename.
4. Spot the drive-relative trap and say why it doubles a path (teacher guide — evidence).

## What you need
Paper and a pencil. A computer with folders on it, if one is near.

1. **Do it first** — before any definition, write down — folder by folder — how you would tell a friend to find one music file four folders down on a school computer (lesson/lesson.md).

4. **Questions** — from questions/ — served at the learner's level and teaching-mix (levels.md).

## If the learner is stuck
- Writes a relative path starting from the drive letter → that is the absolute route; a relative path starts from where you stand.
- Falls into the drive-relative trap → a path like D:sources still leans on a remembered working directory; joined together they can double, as the guide's key shows (teacher guide — evidence).
