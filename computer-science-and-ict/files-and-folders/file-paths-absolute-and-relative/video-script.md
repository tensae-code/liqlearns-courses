# Video script — File paths — absolute and relative

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A **path** is directions to a file.
Folder by folder. From the drive letter to the name.

Write the whole route from the root — that is an **absolute** path.
It works from anywhere.

Stand in one folder and give directions from there —
that is a **relative** path. Shorter. But it only works from there.

Two files, one name? No problem.
Their paths are different — so the files are different.

Now you. Write a path. Walk it. Arrive.
