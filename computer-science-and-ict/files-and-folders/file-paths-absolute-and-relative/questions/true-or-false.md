# File paths — absolute and relative — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** An absolute pathname works from anywhere.
**Answer: True**

**2. (Sub lesson 1)** The full pathname ends with the filename.
**Answer: True**

**3. (Sub lesson 2)** A relative pathname names every folder from the root.
**Answer: False — it names only the folders above or below the working directory that lead to the file**

**4. (Sub lesson 2)** A relative path still works after you move to a different folder.
**Answer: False — it is given from one working directory only**
