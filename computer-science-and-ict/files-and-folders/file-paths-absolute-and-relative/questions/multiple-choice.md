# File paths — absolute and relative — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** An absolute pathname —
a) starts from the folder you are standing in  b) gives the complete route from the root  c) never includes a filename
**Answer: b) gives the complete route from the root**

**2. (Sub lesson 1)** Two files can share the same filename when —
a) they sit in different directories, so their pathnames differ  b) one of them is hidden  c) they were made on the same day
**Answer: a) they sit in different directories, so their pathnames differ**

**3. (Sub lesson 1)** A path begins with —
a) a filename  b) a drive letter  c) a file extension
**Answer: b) a drive letter**

**4. (Sub lesson 2)** A relative pathname is given from —
a) the root  b) the current working directory  c) another computer
**Answer: b) the current working directory**

**5. (Sub lesson 2)** A drive-relative path such as D:sources can go wrong because —
a) it deletes the file  b) joined with the remembered current directory it can double the path  c) it changes the extension
**Answer: b) joined with the remembered current directory it can double the path**
