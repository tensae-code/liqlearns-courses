# File paths — absolute and relative — ordering

Put each set in the right order.

**1. (Sub lesson 1)** Put the parts of this pathname in their walking order: song.mp3 — Music — C:\ — School.
**Answer: C:\ — School — Music — song.mp3.**

**2. (Sub lesson 1)** Put the walk in order: open the last folder — start at the drive letter — reach the filename — open the first folder.
**Answer: start at the drive letter — open the first folder — open the last folder — reach the filename.**
