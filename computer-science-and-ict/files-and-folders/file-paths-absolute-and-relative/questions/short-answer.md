# File paths — absolute and relative — short answer

Answer in a sentence or two.

**1. (Sub lesson 1)** In the path C:\Games\Solitaire\Solitaire.exe, what is the file, and what is its extension (teacher guide — evidence: the guide's worked key)?
**Answer:** The file is Solitaire.exe; its extension is .exe. The drive is C:, the folder Games, the subfolder Solitaire.

**2. (Sub lesson 2)** Why is the absolute path the safe one to write in a program or script?
**Answer:** Because it gives the complete route from the root and works from anywhere; a relative or drive-relative path depends on the working directory and can double or break.
