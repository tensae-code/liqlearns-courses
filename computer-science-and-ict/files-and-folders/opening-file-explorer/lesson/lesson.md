# Opening File Explorer

## Do it first

You know the window and its nine parts. But how do you get it open? Try now: open File Explorer any way you can think of. However you did it, keep the window open — this lesson gives you the book's three ways, in the book's order, so at least one of them always works.

## Three ways, in the book's order

1. **Click the File Explorer icon on the taskbar.** The window opens at once.
2. **Start button, then File Explorer.** Click the Start button, then click File Explorer in what opens.
3. **The keyboard shortcut.** Hold the **Windows key** and press **E**.

Practise all three until each one is in your hands — icon, Start, keys. Different computers hide different things; with three ways, you are never locked out of your files.

## Say it to your companion

Tell your companion the three ways to open File Explorer, in order. Then open it each way while your companion watches and names the way you used.

## Do It Yourself

1. Close File Explorer. Open it with the taskbar icon. Close it again.
2. Open it from the Start button. Close it again.
3. Open it with Windows key + E. Leave it open and name its nine parts from the last lesson.
