# Hands-on — Opening File Explorer

The lesson with your hands, not only your eyes.

## Three doors race
With a partner and one computer (or two), open File Explorer by each of the three ways in turn, closing it between ways. Say the way aloud as you use it. The set is done when all three ways have opened the window.

## Teach the keys
Teach Windows key + E to someone who has never used it — a family member or a classmate. Watch them do it twice without your hands helping.
