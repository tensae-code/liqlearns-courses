# Lesson plan — Opening File Explorer

**Course:** Computer Science and ICT · **Title:** Files and Folders · **Lesson:** Opening File Explorer
**Place in the curriculum:** Unit 1 — Organization of Files — in the title Files and Folders on the ICT course ladder (TITLES.md).
**The one thing this lesson teaches:** File Explorer opens three ways, in the book's order: the taskbar icon, Start then File Explorer, or the keyboard shortcut Windows key + E.
**This lesson's own level:** It stands on File Explorer — naming its parts: the learner can name the window, and now opens it three ways.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## What the learner can do when it ends
1. Open File Explorer by clicking its taskbar icon.
2. Open File Explorer from the Start button.
3. Open File Explorer with Windows key + E.

## What you need
A Windows computer.

## If the learner is stuck
Cannot find the taskbar icon → fall back down the list: Start then File Explorer always works, and Windows key + E works from anywhere. Presses E alone → both keys together: hold Windows, tap E.
