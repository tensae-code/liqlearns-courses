# Opening File Explorer — multiple choice

Pick the one right answer.

**1. The book's first way to open File Explorer is —**
a) Windows key + E  b) clicking the File Explorer icon on the taskbar  c) the Search box
**Answer: b) clicking the File Explorer icon on the taskbar**

**2. The keyboard shortcut for File Explorer is —**
a) Ctrl + E  b) Alt + E  c) Windows key + E
**Answer: c) Windows key + E**

**3. The second way in the book's order is —**
a) Start button, then File Explorer  b) right-click the desktop  c) the Recycle Bin
**Answer: a) Start button, then File Explorer**

**4. If the taskbar icon cannot be found, File Explorer can still be opened by —**
a) the Recycle Bin  b) Start, then File Explorer, or Windows key + E  c) Paint
**Answer: b) Start, then File Explorer, or Windows key + E** — the other two ways in the book's list.
