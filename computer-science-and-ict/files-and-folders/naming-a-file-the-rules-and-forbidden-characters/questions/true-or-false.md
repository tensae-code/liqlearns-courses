# Naming a file — the rules and the forbidden characters — true or false

Say whether each sentence is true or false.

**1.** Spaces are allowed in a filename.
**Answer: True**

**2.** The character / may be used inside a filename.
**Answer: False — / is in the forbidden row**

**3.** assignment.doc and memo.xls are valid names.
**Answer: True**

**4.** Control characters are allowed in filenames.
**Answer: False — control characters are forbidden**
