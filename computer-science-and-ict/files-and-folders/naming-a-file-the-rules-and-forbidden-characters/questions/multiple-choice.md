# Naming a file — the rules and the forbidden characters — multiple choice

Pick the one right answer.

**1.** A filename should be chosen to —
a) hide the contents  b) reflect the contents  c) be as short as one letter
**Answer: b) reflect the contents**

**2.** Which name is valid?
a) io*asst.doc  b) first? name.xls  c) report.pdf
**Answer: c) report.pdf**

**3.** Which character is forbidden in a filename?
a) #  b) ?  c) -
**Answer: b) ?**

**4.** Which name is invalid because of the = sign?
a) memo.xls  b) payroll=list.pdf  c) assignment.doc
**Answer: b) payroll=list.pdf**

**5.** Who chooses a file's name?
a) the operating system  b) its creator  c) the printer
**Answer: b) its creator**
