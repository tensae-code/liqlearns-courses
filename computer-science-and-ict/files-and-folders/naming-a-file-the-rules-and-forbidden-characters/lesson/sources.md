This lesson stands on teacher-guide evidence: the student book asks how to name a file and for valid and invalid examples but never prints the rules; the guide's review key supplies them, and the lesson is built from that key, labelled here. One dated claim in the same key is NOT taught: the key states filenames as 'strings of one to eight letters' — the old DOS rule, against the book's own Windows teaching — flagged in the guide's own error list and left out of the lesson.
