This lesson stands on teacher-guide evidence: the student book asks how to name a file and for valid and invalid examples but never prints the rules; the guide's review key supplies them, and the lesson is built from that key, labelled here. One dated claim in the same key is NOT taught: the key states filenames as 'strings of one to eight letters' — the old DOS rule, against the book's own Windows teaching — flagged in the guide's own error list and left out of the lesson. The student book's corresponding exercise sits in its Unit 1 review (printed pp. 27–35).

Saudi Arabia's own way (Grade 3, continuing education): a workbook-style book for the continuing-education (adult/lifelong learning) track — every one of the 16 lessons opens with "I want to learn" objectives and closes with written exercises, and everything is taught on an older Windows desktop (Start menu, "My Computer", Recycle Bin) with Notepad as the only application, worked through step-by-step practicals in the school lab.
