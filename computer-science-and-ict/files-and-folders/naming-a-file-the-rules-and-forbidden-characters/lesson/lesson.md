# Naming a file — the rules and the forbidden characters

## Do it first

You are about to save your IT assignment. Write its filename on paper first. Now write a second name — one you think the computer might refuse. Keep both. This lesson gives you the rules to judge them by. (The rules themselves come from the teacher guide's key — the teaching below states them plainly, as rules.)

## The rules

A filename is chosen by **its creator**, and it should **reflect the contents** of the file — *assignment*, *memo*, *report* tell the next reader what is inside.

[Picture 14116 — valid and invalid names]

**Allowed** in a name: letters **A–Z**, numbers **0–9**, **spaces**, and these special characters:

$ # & + @ ! ( ) - { } ' ` _ ~

**Forbidden** in a name:

* | < > \ ^ = ? / [ ] " — and control characters.

Judge the keyed examples:

- **Valid:** assignment.doc — memo.xls — report.pdf. Nothing forbidden in them.
- **Invalid:** io*asst.doc (the * is forbidden) — first? name.xls (the ? is forbidden) — payroll=list.pdf (the = is forbidden).

The fix for an invalid name is always the same shape: take the forbidden character out, or swap it for an allowed one, and keep the name reflecting the contents.

## Say it to your companion

Give your companion one valid name and one invalid name of your own making. They must judge each and name the forbidden character in the invalid one. Then swap.

## Do It Yourself

1. Judge these names and fix the invalid ones: budget#2026.xlsx — what?.doc — my file.pdf — a/b test.txt — report(final).pdf.
2. Name three files you really own so each name reflects its contents, using only allowed characters.
3. Write the full forbidden row from memory. Check it character by character.
