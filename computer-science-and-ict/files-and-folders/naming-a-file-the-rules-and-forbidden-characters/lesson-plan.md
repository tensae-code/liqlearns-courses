# Lesson plan — Naming a file — the rules and the forbidden characters

**Course:** Computer Science and ICT · **Title:** Files and Folders · **Lesson:** Naming a file — the rules and the forbidden characters
**Place in the curriculum:** Unit 1 — Organization of Files (Grade 10 depth) — in the title Files and Folders on the ICT course ladder (CURRICULUM.md).
**The one thing this lesson teaches:** a filename is chosen by its creator to reflect the contents; letters A–Z, numbers 0–9, spaces and a listed set of special characters are allowed, while * | < > \ ^ = ? / [ ] " and control characters are forbidden (teacher guide — evidence: the rules are supplied only in the guide's key).
**This lesson's own level:** It stands on the extension lessons and Renaming a file or folder: the learner can rename; this lesson — built on teacher-guide evidence — teaches which names the system will accept. The student book asks for the rules but never prints them; the guide's key supplies them.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
This lesson is one whole lesson — it has no sub lessons (a short, single-skill lesson; his ruling 2026-11-09).

## Before this lesson
- Recommended first: File name extensions — reading a file's ending, and Renaming a file or folder, in this same title. Recommended, never forced.

## What the learner can do when it ends
1. Name a file so its name reflects its contents.
2. Tell an allowed character from a forbidden one.
3. Judge a filename valid or invalid and fix an invalid one.

## What you need
Paper and a pencil.

## The run of the lesson (in order)
1. **Do it first** — write the best name you can for a file holding your IT assignment, and one name you suspect the computer would refuse — before the rules are shown (lesson/lesson.md).
2. **The explanation** — the lesson text in lesson/lesson.md, in its parts in order.
   - ADD IMAGE [Picture 14116]: a picture of a valid filename beside an invalid one, the forbidden character in the invalid one circled — the student judges three more names against the same picture.
   - ADD AUDIO: a voice reading the lesson's key names and steps aloud, in the order the lesson gives them — the student listens once through, then reads the same lines aloud along with the voice. (Audio is a described slot in this build; no audio file is made.)
3. **Say it to your companion** — give your companion one valid and one invalid name and let them say which is which, and why (lesson/lesson.md).
   - ADD VIDEO: the script in video-script.md, filmed — made later, when videos are made.
4. **Questions** — from questions/ — served at the learner's level and teaching-mix (levels.md).
5. **Hands-on** — hands-on.md.
6. **Do It Yourself** — judge and fix six names against the forbidden list (lesson/lesson.md).

## Add-ons for this lesson (the full list)
- IMAGE [Picture 14116] — valid against invalid, forbidden character circled → the student judges names against it.
- AUDIO — the forbidden characters read aloud one by one → the student listens once, then reads along.
- VIDEO — the video-script filmed (made later) → the student judges names along with it.

## If the learner is stuck
- Uses a forbidden character without noticing → check the name against the forbidden row character by character before saving.
- Names a file 'work' or 'new' → the creator chooses the name to reflect the contents; a name that says nothing helps no one find it again.
