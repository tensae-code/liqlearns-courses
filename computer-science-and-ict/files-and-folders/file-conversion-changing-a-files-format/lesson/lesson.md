# File conversion — changing a file's format

## Do it first

Think of a Word document that must be read by someone whose program cannot open Word files. The words are fine — the wrapping is wrong. What could you do, without retyping a single word? Hold your answer; this lesson names it.

## Sub lesson 1 — Conversion and converter software

**Conversion** changes a file from one format into another. It is needed when a file will not work with the program you must use. The worked example: turn a Word **.doc** into a **PDF**.

[Picture 14107 — .doc through the converter, out as .pdf]

There are dozens of formats for documents, graphics and spreadsheets, and two routes between them:

1. **Import** the file into the other application (the Import and export lesson teaches this in full).
2. Run a **conversion program**.

A file converter works by a simple flow, in this order: **upload** the file — **choose the target format** — **convert**. Six converter products are named in the books as examples of such programs; the flow is the same whichever one you meet.

## Sub lesson 2 — Vector and bitmap formats (teacher guide — evidence)

This part comes from the teacher guide's own teaching notes, which draw a distinction the student book never makes.

[Picture 14108 — vector against bitmap]

[GIF 14126 — the zoom test]

**Vector formats** — SVG, WMF, EPS, PDF, CDR, AI — build a picture from basic geometric shapes, so its quality stays the same at any size. SVG can show vector images directly, with no bitmap version needed.

**Bitmap formats** — JPEG, PNG, APNG, GIF, WebP, BMP, MPEG4 — build the picture from a rectangular array of **pixels**, each pixel carrying numbers that fix its colour. Zoom a bitmap far enough and you see the squares; zoom a vector and the edge stays smooth.

## Say it to your companion

Explain conversion to your companion using the .doc-to-PDF example and the three-step converter flow. Then hold up the two circles: which is vector, which is bitmap, and how does the zoom prove it?

## Do It Yourself

1. Convert one real file — a document to PDF — using the upload, choose, convert flow. Write down the two extensions.
2. Take one picture file and zoom it as far as it goes. Is it a bitmap? What do you see that proves it?
3. Name three vector formats and three bitmap formats from memory. Check them against the lesson.
