# File conversion — changing a file's format — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** The worked conversion example turns a Word .doc into a PDF.
**Answer: True**

**2. (Sub lesson 2)** PDF is listed among the vector formats (teacher guide — evidence).
**Answer: True**

**3. (Sub lesson 2)** JPEG and PNG are vector formats.
**Answer: False — they are bitmap formats**

**4. (Sub lesson 2)** A bitmap's pixels each carry numbers that fix their colour.
**Answer: True**
