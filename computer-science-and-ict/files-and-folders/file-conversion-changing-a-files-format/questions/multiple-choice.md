# File conversion — changing a file's format — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Conversion means —
a) deleting a file  b) changing a file from one format into another  c) renaming a folder
**Answer: b) changing a file from one format into another**

**2. (Sub lesson 1)** Conversion is needed when —
a) a file will not work with the program you must use  b) the disk is full  c) the file has no name
**Answer: a) a file will not work with the program you must use**

**3. (Sub lesson 1)** The two routes to a converted file are importing into the other application and —
a) printing it  b) running a conversion program  c) deleting the original
**Answer: b) running a conversion program**

**4. (Sub lesson 1)** A file converter's flow, in order, is —
a) convert, choose, upload  b) upload, choose the target format, convert  c) choose, upload, print
**Answer: b) upload, choose the target format, convert**

**5. (Sub lesson 2)** A vector picture is built from —
a) pixels  b) basic geometric shapes  c) commas
**Answer: b) basic geometric shapes**

**6. (Sub lesson 2)** Zoomed far enough, a bitmap picture —
a) stays perfectly smooth  b) shows its pixels as squares  c) turns into text
**Answer: b) shows its pixels as squares**
