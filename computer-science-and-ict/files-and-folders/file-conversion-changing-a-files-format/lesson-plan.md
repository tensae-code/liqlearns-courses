# Lesson plan — File conversion — changing a file's format

**Course:** Computer Science and ICT · **Title:** Files and Folders · **Lesson:** File conversion — changing a file's format
**Place in the curriculum:** Unit 1 — Organization of Files (Grade 10 depth) — in the title Files and Folders on the ICT course ladder (CURRICULUM.md).
**The one thing this lesson teaches:** conversion changes a file from one format into another — needed when a file will not work with the program you must use — by importing it into the other application or by running a converter program through its upload–choose target format–convert flow; and (teacher guide — evidence) vector formats build a picture from geometric shapes while bitmap formats build it from pixels.
**This lesson's own level:** It stands on the two extension lessons: the learner knows formats by their endings; this lesson changes one ending — and the format behind it — into another. It is a doing-lesson.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Conversion and converter software** — changing a file from one format into another; the two routes; the converter's upload–choose–convert flow.
2. **Vector and bitmap formats (teacher guide — evidence)** — the guide's distinction the student book never makes: shapes that stay smooth at any size against pictures built from pixels.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Common file extensions — the full table, in this same title. Recommended, never forced.

## What the learner can do when it ends
1. Say what conversion is and when it is needed.
2. Name the two routes to a converted file.
3. Run the converter flow in order: upload, choose the target format, convert.
4. Tell a vector format from a bitmap format and say what each does when it grows (teacher guide — evidence).

## What you need
A computer, if one is near. Paper and a pencil.

## The run of the lesson (in order)
1. **Do it first** — name a time a file would not open or would not work in the program you had — before the word conversion is given (lesson/lesson.md).
2. **The explanation** — the lesson text in lesson/lesson.md, in its parts in order.
   - ADD IMAGE [Picture 14107]: a picture of a .doc file passing through a converter box and coming out as a .pdf file — the student traces the file's journey and names each stage.
   - ADD IMAGE [Picture 14108]: a picture of the same circle drawn both ways — smooth vector outline against a grid of coloured pixels — the student says which side stays smooth zoomed.
   - ADD GIF [GIF 14126]: a bitmap picture going blocky as it zooms while the vector one stays smooth — the student watches both sides and names the difference. (Teacher guide — evidence.)
   - ADD AUDIO: a voice reading the lesson's key names and steps aloud, in the order the lesson gives them — the student listens once through, then reads the same lines aloud along with the voice. (Audio is a described slot in this build; no audio file is made.)
3. **Say it to your companion** — explain conversion to your companion with the .doc to PDF example, then tell vector from bitmap (lesson/lesson.md).
   - ADD VIDEO: the script in video-script.md, filmed — made later, when videos are made.
4. **Questions** — from questions/ — served at the learner's level and teaching-mix (levels.md).
5. **Hands-on** — hands-on.md.
6. **Do It Yourself** — convert one real file, or walk the Renaissance Dam paragraph from Word to PDF on paper (lesson/lesson.md).
