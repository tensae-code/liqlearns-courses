## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **OneDrive inside Teams — where the upload goes** — **OneDrive** is Microsoft's cloud storage, and Kuwait's pupils meet it **inside Microsoft Teams** — the platform's files lead to the same cloud the class's work lives in. An **upload** copies a file or folder from your device **up** to that storage: the original stays on the device, and the cloud copy is the one reachable anywhere, any time, from any signed-in device.
2. **Uploading — files and whole folders** — The act is the same for one file and for many: choose what goes up — a **single file**, or a **folder**, which carries everything inside it in one move — start the upload, and **wait for it to finish** before trusting it: a half-uploaded folder is a promise, not a copy. The closing check is the skill: open the cloud copy and see the work there, whole, before calling the job done.
