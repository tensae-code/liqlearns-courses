# OneDrive — Uploading Files and Folders

## Do it first

The cloud lesson before this one said what the digital cloud is. This one does the daily act: Kuwait's Grade 4 book teaches uploading — files and folders sent up to OneDrive, through the Teams platform the class already lives in. This lesson is that act, done carefully.

## Sub lesson 1 — OneDrive inside Teams — where the upload goes

**OneDrive** is Microsoft's cloud storage, and Kuwait's pupils meet it **inside Microsoft Teams** — the platform's files lead to the same cloud the class's work lives in. An **upload** copies a file or folder from your device **up** to that storage: the original stays on the device, and the cloud copy is the one reachable anywhere, any time, from any signed-in device.

In your mind's eye: oneDrive inside Teams — where the upload goes.

## Sub lesson 2 — Uploading — files and whole folders

The act is the same for one file and for many: choose what goes up — a **single file**, or a **folder**, which carries everything inside it in one move — start the upload, and **wait for it to finish** before trusting it: a half-uploaded folder is a promise, not a copy. The closing check is the skill: open the cloud copy and see the work there, whole, before calling the job done.

In your mind's eye: uploading — files and whole folders.
