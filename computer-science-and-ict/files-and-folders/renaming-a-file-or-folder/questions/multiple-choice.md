# Renaming a file or folder — multiple choice

Pick the one right answer.

**1. How many renaming methods does the book teach?**
a) two  b) three  c) four
**Answer: c) four**

**2. The keyboard method of renaming is —**
a) F2  b) Ctrl+R  c) Windows key + E
**Answer: a) F2** — select the file, press F2.

**3. In the slow-click method, clicking the name again too fast —**
a) deletes the file  b) opens the file instead  c) renames it twice
**Answer: b) opens the file instead**

**4. Renaming may need —**
a) an Internet connection  b) permission, sometimes administrator rights  c) a printer
**Answer: b) permission, sometimes administrator rights**
