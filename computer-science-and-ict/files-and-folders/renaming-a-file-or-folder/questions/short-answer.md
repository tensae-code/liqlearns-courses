# Renaming a file or folder — short answer

Answer in one or two short sentences.

**1. Name the four renaming methods.**
**Answer: Right-click → Rename; select and press F2; File menu → Rename; single-click, wait a few seconds, click the name again.**

**2. A pupil clicks a name twice quickly and the file opens. What should they change?**
**Answer: Slow down — click once, wait a few seconds, then click the name again so it becomes editable.**
