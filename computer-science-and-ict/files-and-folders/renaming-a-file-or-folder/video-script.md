# Video script — Renaming a file or folder

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A bad name? **Rename** it. Four ways.

One: **right-click — Rename**.
Two: select it, press **F2**.
Three: **File menu — Rename**.
Four: click once. **Wait.** Click the name again. Now type.

Too fast on way four? The file opens. Slow down.
And remember: renaming may need permission.
