# Renaming a file or folder

## Do it first

Take a file with a clumsy name — New Text Document, Untitled, anything — and rename it to something that says what it is. Any way you can. Count the ways you find. The book teaches four. This lesson gives all four, and the timing trick that makes the fourth one work.

## Renaming — four methods

First, a warning the book gives: renaming needs **permission** — sometimes **administrator rights**. If a rename is refused, that is why.

The four routes:

1. **Right-click → Rename.** Right-click the file or folder, choose Rename, type the new name.
2. **F2.** Select the file or folder and press **F2**, then type.
3. **File menu → Rename.** Use the File menu's Rename command.
4. **The slow second click.** Single-click the name once, **wait a few seconds**, then click the name again — it becomes editable, and you type the new name.

Click too fast the second time and you have not renamed anything — you have **opened** the file instead. Slow is the skill.

## Say it to your companion

Tell your companion the four renaming methods in order. Then explain the fourth way's timing: what happens if the second click comes too fast?

## Do It Yourself

1. Rename a file with right-click → Rename.
2. Rename a folder with F2.
3. Rename another file with the slow second click — click, wait, click the name. If it opens instead, close it and try slower.
