# Lesson plan — Renaming a file or folder

**Course:** Computer Science and ICT · **Title:** Files and Folders · **Lesson:** Renaming a file or folder
**Place in the curriculum:** Unit 1 — Organization of Files — in the title Files and Folders on the ICT course ladder (TITLES.md).
**The one thing this lesson teaches:** A file or folder is renamed four ways: right-click → Rename; select and press F2; File menu → Rename; or single-click, wait a few seconds, and click the name again — clicking too fast opens the file instead.
**This lesson's own level:** It stands on Copying a file: handling files comes before changing their names. Renaming needs permission — sometimes administrator rights.

## What the learner can do when it ends
1. Rename four ways: right-click → Rename; F2; File menu → Rename; the slow second click.
2. Say the timing trick of the fourth way: wait a few seconds, or the click opens the file.
3. Say what renaming may need: permission, sometimes administrator rights.

## What you need
A computer with File Explorer and a file or folder of your own to rename.

## If the learner is stuck
File opens instead of renaming → the second click came too fast; the wait between clicks is the method. Rename is refused → renaming needs permission, sometimes administrator rights; use a file of your own.
