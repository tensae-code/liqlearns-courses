# Hands-on — Renaming a file or folder

The lesson with your hands, not only your eyes.

## Four ways, one file
Rename the same practice file four times, once by each method, changing the name a little each time. Say the method aloud as you use it.

## Name it well
Find three files with clumsy names (New, Untitled, Copy). Rename each to a name that says what the file is, using a different method each time.
