# Drives — where files live — depth

This lesson is one whole lesson with no sub lessons. Whole-lesson pass mark: the learner can do what the outcomes in lesson-plan.md name, answered from the lesson's own question files.
Practice deepens inside the one lesson: first the items that name and recognise, then the items that explain and correct a mistake, then the items that apply the idea to a new example from the learner's own day. More items and harder corners, same single skill.

Grade 10 depth (added 2026-11-12): the pass mark now also covers the full letter table (A: floppy, C: default hard drive, CD/DVD last letter, USB next free letter), cloud drives named with their backup use, and the Explorer practical done on a real machine.
