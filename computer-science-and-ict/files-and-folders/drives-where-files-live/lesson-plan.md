# Lesson plan — Drives — where files live

**Course:** Computer Science and ICT · **Title:** Files and Folders · **Lesson:** Drives — where files live
**Place in the curriculum:** Unit 1 — Organization of Files — in the title Files and Folders on the ICT course ladder (TITLES.md).
**The one thing this lesson teaches:** A drive is the hardware that stores and retrieves data, files, programs and the operating system — named by letter in Windows (C:, D:, F:), a tree from the root '/' in Linux — and a drive is not a driver: a driver is software that lets a device talk to the operating system.
**This lesson's own level:** It stands on Searching for a file: the learner can find any file — now they learn where all files actually live, and the drive/driver confusion is killed for good.

## What the learner can do when it ends
1. Say what a drive is: the hardware component that stores and retrieves data, files, programs and the operating system.
2. Say how Windows names drives (letters: C:, D:, F:) and how Linux names them (a tree from the root '/').
3. Give the drive/driver difference: a drive stores; a driver is software code letting a hardware device talk to the operating system.

## If the learner is stuck
Mixes drive and driver → anchor on the verbs: a drive stores (a thing), a driver lets a device talk (a program). Thinks the letter is the drive's name everywhere → letters are Windows' way; Linux grows a tree from '/'.
