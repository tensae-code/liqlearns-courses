# Drives — where files live — multiple choice

Pick the one right answer.

**1. A drive is —**
a) software for printing  b) the hardware component that stores and retrieves data  c) a folder
**Answer: b) the hardware component that stores and retrieves data**

**2. Windows names drives —**
a) by letter: C:, D:, F:  b) by colour  c) from the root '/'
**Answer: a) by letter: C:, D:, F:**

**3. A driver is —**
a) a small drive  b) software code letting a hardware device talk to the operating system  c) a drive letter
**Answer: b) software code letting a hardware device talk to the operating system**

**4. When you open a word processor, it is loaded from —**
a) the printer  b) the hard drive  c) the keyboard
**Answer: b) the hard drive** — and saves go back to a drive.
