# Drives — where files live — true or false

Say whether each statement is true or false.

**1. Linux names its drives with a tree beginning at the root '/'.**
**Answer: True**

**2. A drive and a driver are the same thing.**
**Answer: False** — a drive stores; a driver is software that lets a device talk to the operating system.

**3.** OneDrive and Google Drive are cloud drives, reached over the internet.
**Answer: True**

**4.** A driver is a piece of storage hardware.
**Answer: False — a driver is software that lets hardware talk to the operating system**
