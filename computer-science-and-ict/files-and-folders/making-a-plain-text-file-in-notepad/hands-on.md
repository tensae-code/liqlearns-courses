# Hands-on — Making a plain text file in Notepad

The lesson with your hands, not only your eyes.

## The plain file
Open Notepad by the book's route and type a real note — a shopping list or three lines about your day. Save it, find it in File Explorer, and read its full name aloud, extension included.

## Plain against dressed
Type the same sentence in Notepad and in a word processor, and make the word-processor copy bold and coloured. Hold the two side by side and name what the .txt file cannot do.
