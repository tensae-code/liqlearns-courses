# Video script — Making a plain text file in Notepad

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

The plainest file of all: a **text file**.

Open **Notepad**. The book's way:
**Start**. Type **Notepad**. Press **Enter**.

Type your words.
Save. The name ends **.txt**.

No bold. No colours. No fonts.
Just words — plain text.
And plain text opens almost anywhere.
