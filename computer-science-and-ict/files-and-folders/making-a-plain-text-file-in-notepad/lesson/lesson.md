# Making a plain text file in Notepad

## Do it first

A document file can carry bold, colours and fonts. But sometimes you want the words and nothing else. Look for the plainest writing program on this computer — no font ribbons, no picture tools. Try to open it. This lesson names it and walks the book's route to it.

## Making the file

The easiest text file route in Windows is **Notepad**, the built-in text editor. Open it in the book's order:

1. Click **Start**.
2. Type **Notepad** in the Run/Search box.
3. Press **Enter**. The editor opens.

[GIF 12527 — searching Notepad from Start and the editor opening]

Type your text. What you are making is **plaintext**: a Notepad file is saved with a **.txt** extension, with **no special formatting or fonts** — words only, exactly as typed.

[Picture 12526 — the Notepad window with a line of plain text and .txt on its name]

That plainness is the point. A .txt file opens on almost any computer, in almost any program, and nothing in it can hide inside fancy formatting.

## Say it to your companion

Tell your companion the three steps to open Notepad, in order. Then say what a Notepad file is — its extension, and what it has not got.

## Do It Yourself

1. Open Notepad by the book's route: Start, type Notepad, Enter.
2. Type three lines about your school. Save the file and check its name ends in .txt.
3. Open the file again. Say one thing that is in it (the words) and two things that are not (formatting, fonts).
