# Making a plain text file in Notepad — multiple choice

Pick the one right answer.

**1. The easiest text file route in Windows is —**
a) Paint  b) Notepad  c) PowerPoint
**Answer: b) Notepad** — the built-in text editor.

**2. A Notepad file is saved with the extension —**
a) .docx  b) .txt  c) .mp3
**Answer: b) .txt**

**3. A Notepad file has —**
a) many fonts  b) pictures inside  c) no special formatting or fonts
**Answer: c) no special formatting or fonts** — it is plaintext.
