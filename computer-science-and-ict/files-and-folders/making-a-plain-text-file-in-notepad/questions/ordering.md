# Making a plain text file in Notepad — ordering

Put the steps in the right order.

**1. Put the book's route to Notepad in order.
Steps: Press Enter · Click Start · Type Notepad in the Run/Search box
**Answer: 1. Click Start. 2. Type Notepad in the Run/Search box. 3. Press Enter.**

**2. Which file is the plain text file?
Files: letter.docx · notes.txt · song.mp3
**Answer: notes.txt** — the .txt extension marks the plaintext file.
