# Saving and Versioning a Scratch Project — multiple choice

Pick the one right answer.

**1. Signed in to a Scratch account, a project —**
a) Saves automatically to the account  b) Can never be saved  c) Saves only on paper
**Answer: a) Saves automatically to the account** — Accounts auto-save as you work.

**2. File > Save to your computer puts the project —**
a) On the stage  b) As a file on the machine  c) In a sound
**Answer: b) As a file on the machine** — A copy on the computer itself.

**3. A named version, saved before a big change, protects you because —**
a) It stops changes happening  b) The last good state still exists if the change spoils the project  c) It adds enemies
**Answer: b) The last good state still exists if the change spoils the project** — Versions are a way back.

**4. Which evidence is this lesson built on?**
a) A student book chapter  b) The teacher guide's notes, filed as evidence  c) A final exam
**Answer: b) The teacher guide's notes, filed as evidence** — Teacher-guide evidence only — its sources say so.
