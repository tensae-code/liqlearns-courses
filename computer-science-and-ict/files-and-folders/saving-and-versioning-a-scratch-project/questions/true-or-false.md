# Saving and Versioning a Scratch Project — true or false

Say whether each statement is true or false.

**1. Saving to your computer and account auto-save are the same route.**
**Answer: False** — Two routes: the account saves online; the menu keeps a file on the machine.

**2. Versions should mark the project's stage in their names.**
**Answer: True** — A name like 'Maze — enemies added' tells you what that copy holds.

**3. One working copy is enough however big the project grows.**
**Answer: False** — Growth is exactly when named versions matter.
