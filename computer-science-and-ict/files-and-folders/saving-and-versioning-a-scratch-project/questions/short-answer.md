# Saving and Versioning a Scratch Project — short answer

Answer in a sentence or two.

**1. A classmate lost a signed-out session's project. Explain both routes they can use next time.**
**Answer:** A sound answer: sign in to an account so Scratch auto-saves online as they work, and/or use File > Save to your computer to keep their own file copy on the machine.

**2. Why save a version BEFORE the change, not after?**
**Answer:** A sound answer: the version must preserve the state before the risk; saving after the change preserves the changed (possibly spoiled) state and the good one is already gone.
