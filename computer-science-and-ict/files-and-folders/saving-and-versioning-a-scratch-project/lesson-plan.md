# Lesson plan — Saving and Versioning a Scratch Project

**Course:** Computer Science and ICT · **Title:** Files and Folders · **Lesson:** Saving and Versioning a Scratch Project
**Place in the curriculum:** ICT expansion — Finland (2026-11-14) — in the title Files and Folders on the ICT course ladder (TITLES.md). Built new from Finland's *Ensiaskeleet ohjelmointiin* (teacher guide, Opettajan opas, Versio 2.0 — teacher notes only), because no existing lesson teaches this thing as its own lesson.
**The one thing this lesson teaches:** A Scratch project is kept two ways — logged-in Scratch saves it automatically to the account, and File > Save to your computer keeps a copy on the machine — and a growing project is kept in named versions, so a bad change never destroys the last good state. This lesson stands on teacher-guide evidence only.
**This lesson's own level:** It stands on using Scratch projects; saving routes and named versions are built inside the lesson from the teacher guide's notes.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
This lesson is one whole lesson — it has no sub lessons (a short, single-skill lesson; his ruling 2026-11-09).

## Before this lesson
- Recommended first: nothing in Files and Folders needs to come first — it stands alone with a Scratch project in front of the learner. Recommended, never forced — a learner may land on this lesson directly, and it stands alone.
- Finland's own way is kept: this placement sits in Finland's two-part Scratch path — Part 1 moves towards the interactive-story project and Part 2 towards the self-built maze game, in the Luetaan (Let's read) then Ohjelmoidaan (Let's program) rhythm, with pair work, reflection and peer showing built in.

## What the learner can do when it ends
1. Say how a logged-in Scratch account saves a project differently from a signed-out session.
2. Save a Scratch project to the computer with File > Save to your computer.
3. Keep named versions of a growing project and say why versions protect work.

## What you need
A computer with Scratch.

## If the learner is stuck
Project gone after closing → neither route was used: not signed in, and never saved to the computer. Afraid to try a big change → save a named version first; experiments are safe when yesterday's good state is kept.
