# Lesson plan — Compressing and uncompressing files — zipping

**Course:** Computer Science and ICT · **Title:** Files and Folders · **Lesson:** Compressing and uncompressing files — zipping
**Place in the curriculum:** Unit 1 — Organization of Files (Grade 10 depth) — in the title Files and Folders on the ICT course ladder (CURRICULUM.md).
**The one thing this lesson teaches:** compression (zipping) shrinks a file's logical size while keeping the same data — saving disk space and making transfer faster — by right-click, Send to, Compressed (zipped) folder; and a zipped folder opens back up by Extract All or by dragging an item out, with WinRAR, WinZip and 7-Zip as the named tools.
**This lesson's own level:** It stands on the extension table (where .zip/.rar first appeared) and the backup lessons (where size and transfer matter). It is a doing-lesson with the book's own Ethiopian practical.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Zipping — squeezing a file or folder** — what compression does to size; the right-click → Send to → Compressed (zipped) folder route, in order.
2. **Unzipping — opening the package back up** — Extract All, or dragging a single item out; the named tools; adding a file to a zip (teacher guide — evidence on the space saved).

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Common file extensions — the full table, in this same title. Recommended, never forced.

## What the learner can do when it ends
1. Say what compression changes and what it keeps.
2. Zip a file or folder by the book's route, in order.
3. Unzip by Extract All, and take a single item out by dragging.
4. Name the three popular compression tools.

## What you need
A Windows computer. Paper and a pencil.

## If the learner is stuck
- Looks for Zip on the left-click menu → the route is a right-click (or press and hold), then Send to.
- Fears the data is cut down with the size → the logical size shrinks; the same data comes back on unzipping — that is the point of the tool.
