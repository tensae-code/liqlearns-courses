# Hands-on — Compressing and uncompressing files — zipping

The lesson with your hands, not only your eyes — on a real computer where the lesson needs one.

## The Dam practical, in full
Write and save a paragraph about the Ethiopian Renaissance Dam. Zip it. Unzip it onto the desktop. Add a file to the zip. Copy the zip to external storage — the book's own practical, every step.

## Size witness
Write the size of a folder before zipping and the size of its zip beside it. Say the saving as a sentence: 'The same data, ___ smaller.'
