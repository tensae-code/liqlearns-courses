# Compressing and uncompressing files — zipping — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Several files can be combined into one zipped folder for sharing.
**Answer: True**

**2. (Sub lesson 1)** Zipped folders cannot be worked with like ordinary folders in Windows.
**Answer: False — they are worked with just like ordinary folders**

**3. (Sub lesson 2)** A single item can be taken out of a zipped folder by opening it and dragging or copying the item out.
**Answer: True**

**4. (Sub lesson 2)** Compression makes transfer over a network slower.
**Answer: False — the smaller size makes transfer faster**
