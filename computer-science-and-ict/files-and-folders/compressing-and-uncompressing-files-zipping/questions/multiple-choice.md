# Compressing and uncompressing files — zipping — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Compression (zipping) shrinks a file's —
a) data  b) logical size, keeping the same data  c) name
**Answer: b) logical size, keeping the same data**

**2. (Sub lesson 1)** To zip a folder you point to Send to and choose —
a) Extract All  b) Compressed (zipped) folder  c) Backup
**Answer: b) Compressed (zipped) folder**

**3. (Sub lesson 1)** After zipping, the zipped folder appears —
a) on the desktop only  b) in the same place, with the same name  c) inside the Recycle Bin
**Answer: b) in the same place, with the same name**

**4. (Sub lesson 2)** To unzip everything you right-click the zipped folder and choose —
a) Send to  b) Extract All  c) Delete
**Answer: b) Extract All**

**5. (Sub lesson 2)** The popular compression tools named are —
a) Word, Excel, Paint  b) WinRAR, WinZip and 7-Zip  c) OneDrive and Google Drive
**Answer: b) WinRAR, WinZip and 7-Zip**

**6. (Sub lesson 2)** Zipping can save up to how much hard-disk space (teacher guide — evidence)?
a) 10 percent  b) 50 percent  c) 80 percent or more
**Answer: c) 80 percent or more**
