# Lesson plan — Navigating with the Address bar

**Course:** Computer Science and ICT · **Title:** Files and Folders · **Lesson:** Navigating with the Address bar
**Place in the curriculum:** Unit 1 — Organization of Files — in the title Files and Folders on the ICT course ladder (TITLES.md).
**The one thing this lesson teaches:** The Address bar shows the full path of the current folder, each folder in it carries a drop-down of its subfolders, and the Back/Forward buttons return to folders already visited.
**This lesson's own level:** It stands on the File Explorer lessons: the learner knows the window — now they travel with its Address bar instead of opening folder after folder.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## What the learner can do when it ends
1. Say what the Address bar shows: the full path of the current folder.
2. Jump to a folder by clicking its name in the Address bar.
3. Open a folder's drop-down with the right-pointing arrow beside its name, and jump into a subfolder from the list.
4. Return to visited folders with the Back and Forward buttons.

## What you need
A computer with File Explorer and some nested folders.

## If the learner is stuck
Clicks through every folder to go back → the bar is the shortcut: click the folder's name in the path itself. Cannot find a subfolder → use the arrow beside the folder's name; its list holds the subfolders.
