# Navigating with the Address bar — multiple choice

Pick the one right answer.

**1. The Address bar shows —**
a) the file sizes  b) the full path of the current folder  c) the Recycle Bin
**Answer: b) the full path of the current folder**

**2. Clicking the right-pointing arrow beside a folder name —**
a) deletes the folder  b) turns it downward and lists that folder's contents  c) renames the folder
**Answer: b) turns it downward and lists that folder's contents**

**3. Previously visited folders are reached by —**
a) the Back and Forward buttons  b) the Search box only  c) restarting the computer
**Answer: a) the Back and Forward buttons** — or by clicking a folder name in the bar.

**4. You are three folders deep and click the top folder's name in the Address bar. You —**
a) delete the folders between  b) jump straight back to that folder  c) open a new window
**Answer: b) jump straight back to that folder**
