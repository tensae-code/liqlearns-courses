# Import and export — data in, data out — true or false

Say whether each sentence is true or false.

**1.** Exporting moves information out of a program into a file.
**Answer: True**

**2.** .txt, .bmp, .jpg and .gif are named as common export formats.
**Answer: True**

**3.** Importing and exporting travel in the same direction.
**Answer: False — import brings in; export sends out**
