# Import and export — data in, data out — multiple choice

Pick the one right answer.

**1.** Importing means —
a) moving data out of a program into a file  b) moving files or data from one program into another  c) deleting data
**Answer: b) moving files or data from one program into another**

**2.** A CSV file is —
a) a picture file  b) a text file whose values are separated by commas  c) a program
**Answer: b) a text file whose values are separated by commas**

**3.** In the worked pair, the CSV file is imported into —
a) Word  b) an Excel spreadsheet  c) Paint
**Answer: b) an Excel spreadsheet**

**4.** Exporting is done from —
a) the View menu  b) the program's File menu  c) the Recycle Bin
**Answer: b) the program's File menu**

**5.** Notes exported from OneNote come out as —
a) .mp3 files  b) .doc files  c) .exe files
**Answer: b) .doc files**
