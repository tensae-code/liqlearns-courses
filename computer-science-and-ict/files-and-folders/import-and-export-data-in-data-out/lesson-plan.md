# Lesson plan — Import and export — data in, data out

**Course:** Computer Science and ICT · **Title:** Files and Folders · **Lesson:** Import and export — data in, data out
**Place in the curriculum:** Unit 1 — Organization of Files (Grade 10 depth) — in the title Files and Folders on the ICT course ladder (CURRICULUM.md).
**The one thing this lesson teaches:** importing moves files or data from one program into another — bringing information in — and exporting moves information out of a program into a file, done from the program's File menu by choosing the target format.
**This lesson's own level:** It stands beside File conversion: conversion changes a format, importing and exporting move data between programs. The learner knows CSV's neighbours from the extension table.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
This lesson is one whole lesson — it has no sub lessons (a short, single-skill lesson; his ruling 2026-11-09).

## Before this lesson
- Recommended first: File conversion — changing a file's format, in this same title. Recommended, never forced.

## What the learner can do when it ends
1. Tell importing from exporting by direction.
2. Walk the book's worked pair: a CSV file imported into a spreadsheet; the spreadsheet exported back to CSV.
3. Export from the File menu, choosing the target format, and name common export formats.

## What you need
Paper and a pencil. A computer with a spreadsheet program, if one is near.

## The run of the lesson (in order)
1. **Do it first** — say, before any definition, which way the data travels in each of these: a downloaded marks file entering a spreadsheet; a finished spreadsheet saved out as a text file (lesson/lesson.md).
2. **The explanation** — the lesson text in lesson/lesson.md, in its parts in order.
   - ADD IMAGE [Picture 14109]: a picture of two arrows between a program window and a file — one pointing in labelled import, one pointing out labelled export — with a CSV file in the middle — the student points along each arrow and says the direction word.
   - ADD AUDIO: a voice reading the lesson's key names and steps aloud, in the order the lesson gives them — the student listens once through, then reads the same lines aloud along with the voice. (Audio is a described slot in this build; no audio file is made.)
3. **Say it to your companion** — tell your companion which is import and which is export in the CSV pair, and how you know (lesson/lesson.md).
   - ADD VIDEO: the script in video-script.md, filmed — made later, when videos are made.
4. **Questions** — from questions/ — served at the learner's level and teaching-mix (levels.md).
5. **Hands-on** — hands-on.md.
6. **Do It Yourself** — import one real CSV or text file into a spreadsheet, or walk it on paper (lesson/lesson.md).
