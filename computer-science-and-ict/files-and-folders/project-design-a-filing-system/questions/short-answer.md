# Project: design a filing system — short answer

Answer in one or two short sentences.

**1. (Sub lesson 2)** Why set a naming standard before building?
**Answer: So every folder and file name follows one pattern — the system stays predictable and files stay findable as it grows.**

**2. (Sub lesson 3)** What makes the project finished, not half-done?
**Answer: The plan built for real in File Explorer, matching the drawing, and shown to the teacher.**
