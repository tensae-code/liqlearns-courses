# Project: design a filing system — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Case 1's hard drive holds all student files —
a) in tidy folders  b) in the root folder  c) on discs
**Answer: b) in the root folder** — documents, spreadsheets and pictures all together.

**2. (Sub lesson 1)** Each plan must be drawn as —
a) a paragraph  b) a visual tool  c) a table of dates
**Answer: b) a visual tool** — listing the folders and what belongs in each.

**3. (Sub lesson 2)** The book's example naming pattern is —
a) Name_Date  b) Grade_Section  c) Section_File
**Answer: b) Grade_Section**

**4. (Sub lesson 3)** The project ends by —
a) handing in the drawing only  b) building the plan in File Explorer and showing it to the teacher  c) deleting the plan
**Answer: b) building the plan in File Explorer and showing it to the teacher**
