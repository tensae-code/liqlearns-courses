# Lesson plan — Project: design a filing system

**Course:** Computer Science and ICT · **Title:** Files and Folders · **Lesson:** Project: design a filing system
**Place in the curriculum:** Unit 1 — Organization of Files — in the title Files and Folders on the ICT course ladder (TITLES.md).
**The one thing this lesson teaches:** A filing system is planned before it is built: draw the plan as a visual tool, list the folders and what belongs in each, set a naming standard (the book's example pattern: Grade_Section), then build it for real in File Explorer and show it to the teacher.
**This lesson's own level:** It stands on the whole unit: every doing-lesson — creating, copying, moving, renaming, deleting, searching — is used here at once, on a plan of the learner's own.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The two cases and the drawn plan** — a new school record officer organising a hard drive where all student files sit in the root folder, and a pupil organising files for their own Grade 9 subjects; each plan is drawn as a visual tool listing folders and what belongs in each.
2. **The naming standard** — one pattern every name follows — the book's example pattern: Grade_Section.
3. **Build it for real and show it** — the plan is built in File Explorer with the unit's own skills and shown to the teacher.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## What the learner can do when it ends
1. Draw a filing plan as a visual tool: the folders, and what belongs in each.
2. Work both cases: the school record officer's mixed root folder, and a pupil's own Grade 9 subjects.

4. Build the plan for real in File Explorer and show it to the teacher.

## What you need
Paper and a pencil for the plan; a computer with File Explorer for the build.

## If the learner is stuck
Plan exists only as a list of names → the book requires a visual tool: draw the folders as boxes inside boxes, the way the tree will look. Names drift from the standard halfway → write the standard at the top of the drawing and audit every name against it before building.
