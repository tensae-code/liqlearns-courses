# Video script — Project: design a filing system

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A messy drive. Every file in the root. One pile.

**Plan first.** Draw it — a visual tool.
Folders as boxes. What belongs in each, listed.

**Set the standard.** One pattern for every name.
The book's example: **Grade_Section**.

**Then build it.** For real, in File Explorer.
Folders made. Files moved home. Names to the standard.

Draw it. Name it. Build it. Show it.
