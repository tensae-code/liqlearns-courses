# Project: design a filing system

## Do it first

Picture a hard drive the messy way: every student file — documents, spreadsheets, pictures — sitting together in the root folder, one level, no order. That drive belongs to a new school record officer, and it is the first of this project's two cases. The second case is closer to home: your own files, for your own Grade 9 subjects. Start grouping the pile in your head. This project turns the grouping into a plan, the plan into a standard, and the standard into a real built system.

## Sub lesson 1 — The two cases and the drawn plan

The mini-project works **two cases**:

- **Case 1 — the school record officer.** A new record officer must organise a hard drive where **all student files — documents, spreadsheets, pictures — sit in the root folder**.
- **Case 2 — your own subjects.** A pupil organising files for their own **Grade 9 subjects**.

Each plan must be **drawn as a visual tool** — a picture of the system before it exists — and must **list the folders and what belongs in each**.

[Picture 12557 — a hand-drawn folder plan beside the same plan built on screen]

## Sub lesson 2 — The naming standard

A plan is not finished until its names obey one rule. The plan must **set a naming standard** — one pattern that every folder and file name follows.

The book's example pattern: **Grade_Section** — as in a name built from the grade, an underscore, and the section. Choose your pattern, write it at the top of the drawing, and check every name in the plan against it.

## Sub lesson 3 — Build it for real and show it

Then the plan leaves the paper: it is **built for real in File Explorer** — folders created by the unit's own steps, files copied and moved into their places, names renamed to the standard — and **shown to the teacher**.

A plan that stays on paper is half a project. The built system, matching the drawing folder for folder, is the finished work.

## Say it to your companion

Present your project to your companion as you would to the teacher: the case, the drawn plan folder by folder, the naming standard, and how the built system matches the drawing.

## Do It Yourself

1. Draw the full plan for Case 2 — your own Grade 9 subjects — as a visual tool, listing what belongs in each folder.
2. Write your naming standard at the top of the drawing, improving on Grade_Section if your plan needs more.
3. Build the plan in File Explorer. Put at least one real file in each folder, then compare screen against drawing, folder by folder.
