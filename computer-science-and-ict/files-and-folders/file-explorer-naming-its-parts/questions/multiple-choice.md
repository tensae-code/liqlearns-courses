# File Explorer — naming its parts — multiple choice

Pick the one right answer.

**1. In Windows, files and folders are handled through —**
a) Paint  b) File Explorer  c) Notepad
**Answer: b) File Explorer**

**2. Clicking a column heading —**
a) deletes the column  b) sorts the listing by it  c) opens a new window
**Answer: b) sorts the listing by it**

**3. The Quick Access area is part of —**
a) the Status bar  b) the Ribbon  c) the Navigation pane
**Answer: c) the Navigation pane**

**4. Which part shows the path of the current folder?**
a) the Address bar  b) the Search box  c) the Status bar
**Answer: a) the Address bar**

**5. How many parts of the File Explorer window does the book teach?**
a) five  b) seven  c) nine
**Answer: c) nine**
