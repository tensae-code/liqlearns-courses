# File Explorer — naming its parts

## Do it first

Open File Explorer. Do not click anything yet. Just look. The window is not one plain box — it is built of parts, each with its own job. Point at each part you can pick out: something on the left, something across the top, a long bar, a small box at the corner. Guess what each part is for. Then learn their nine names.

## The nine parts

In Windows, files and folders are handled through **File Explorer**. Its window is taught part by part — nine parts:

[Picture 12521 — a full File Explorer window with all nine parts labelled]

1. **Navigation pane** — the left-hand pane, with the **Quick Access** area; a folder can be pinned to Quick Access so it is always at hand.
2. **Forward and Back buttons** — move between folders you have already visited.
3. **Ribbon** — the strip of commands across the top.
4. **Address bar** — shows where you are: the path of the current folder.
5. **Column headings** — the headings over the file list; clicking one sorts the list by it.
6. **Search box** — type part of a name here to find a file.
7. **The file and folder listing** — the main area, showing the current folder's contents.
8. **Preview/Details pane** — shows a chosen file's preview or its details.
9. **Status bar** — the bar at the foot of the window.

Learn them in the picture's order, top to bottom, left to right: pane, buttons, Ribbon, Address bar, headings, Search box, listing, Preview pane, Status bar.

## Say it to your companion

Tell your companion the nine parts in order, pointing at each one on a real window (or on the picture) as you name it. Then let your companion name a part — you say its job.

## Do It Yourself

1. Open File Explorer. Point at each of the nine parts and say its name aloud, without looking at the list.
2. Click a column heading, for example Name. Say what changed in the listing. Click it again and say what changed this time.
3. Pin a folder you use often to Quick Access. Say which part of the window you used, and where the folder now appears.
