# Lesson plan — File Explorer — naming its parts

**Course:** Computer Science and ICT · **Title:** Files and Folders · **Lesson:** File Explorer — naming its parts
**Place in the curriculum:** Unit 1 — Organization of Files — in the title Files and Folders on the ICT course ladder (TITLES.md).
**The one thing this lesson teaches:** In Windows, files and folders are handled through File Explorer, and its window has nine parts to know by name — from the Navigation pane to the Status bar.
**This lesson's own level:** It stands on files and folders themselves: now the learner meets the window where all of them are handled.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. ## What the learner can do when it ends
1. Name the nine parts of the File Explorer window.
2. Say what the Navigation pane, Ribbon, Address bar, Search box and Preview/Details pane each do.
3. Say what clicking a column heading does, and what pinning a folder to Quick Access means.

## What you need
A computer with File Explorer open.

## If the learner is stuck
Mixes the Address bar and the Search box → the Address bar shows where you are; the Search box finds. Place tells them apart: address sits over the listing's path, search sits at the top-right. Forgets the pane names → left is Navigation, right is Preview/Details.
