# What a file is — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A file can be a document, a picture, a video or an audio file.
**Answer: True**

**2. (Sub lesson 1)** Every file has exactly the same icon.
**Answer: False** — the icon differs by file type and its associated program.

**3. (Sub lesson 2)** A .pptx file is a PowerPoint file.
**Answer: True**

**4. (Sub lesson 3)** The course has six units, and programming comes last.
**Answer: True**

**5. (Sub lesson 4)** A disk is a physical storage device, while a drive is a file system that may exist across many disks (teacher guide — evidence).
**Answer: True**
