# What a file is — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A file is —
a) a folder on the desktop  b) a collection of data stored as one unit under a filename  c) a program that opens documents
**Answer: b) a collection of data stored as one unit under a filename**

**2. (Sub lesson 1)** On screen, a file is shown by —
a) its full contents  b) an icon  c) its extension only
**Answer: b) an icon** — the icon differs by file type and program, so the type is recognised at a glance.

**3. (Sub lesson 2)** A file ending in .mp3 is —
a) a video file  b) a spreadsheet  c) an audio file
**Answer: c) an audio file**

**4. (Sub lesson 2)** A file ending in .xlsx is —
a) a spreadsheet  b) a Word document  c) an audio file
**Answer: a) a spreadsheet**

**5. (Sub lesson 3)** The first unit of the course is —
a) Computer Network  b) Organization of Files  c) Fundamentals of Programming
**Answer: b) Organization of Files**

**6. (Sub lesson 3)** Every unit of the book begins with —
a) a test  b) Brainstorming questions  c) the unit summary
**Answer: b) Brainstorming questions** — starting from what pupils already know.
