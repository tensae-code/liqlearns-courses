# What a file is — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 1)** A file is stored under a ____.
**Answer: filename**

**2. (Sub lesson 2)** The short ending of a file's name, like .docx, is called its ____.
**Answer: extension**

**3. (Sub lesson 3)** Unit 3, Application Software, teaches Word, then Excel, then ____.
**Answer: PowerPoint**
