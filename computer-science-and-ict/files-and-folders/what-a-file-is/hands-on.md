# Hands-on — What a file is

The lesson with your hands, not only your eyes.

## Icon hunt
Open a folder full of files. Cover the names with a strip of paper so only the icons show. Name the kind of each file from its icon alone, then lift the paper and check.

## Extension cards
Write five file names on cards — letter.docx, song.mp3, marks.xlsx, film.mp4, slides.pptx. A partner reads a card; you say the kind and the program family it belongs to. Five cards, then swap.

## Draw the road
On one sheet, draw six boxes for the six units and join them with arrows. Under each box write one word for what it is about. Keep the sheet at the front of your exercise book.

## File management audit (Grade 10 depth)
Pick one real folder tree — a school computer's or your own. Walk it and judge it as file management: can everything be found again? Is anything shared that should have its access controlled? Write one improvement and make it.
