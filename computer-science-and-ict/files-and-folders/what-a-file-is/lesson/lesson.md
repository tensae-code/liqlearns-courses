# What a file is

## Do it first

Look at your desktop, or at the files on a phone. How many different kinds of thing can you see? A letter. A photograph. A song. A video. Before anyone names them, say out loud what each one is and how you can tell. Keep your answers — this lesson names what you were looking at, and then shows you the whole road of this course.

## Sub lesson 1 — What a file is

A **file** is a collection of data stored as one unit under a **filename**.

A file can be a document, a picture, text, a video or an audio file. On screen a file is shown by an **icon** — a small picture that stands for the file. The icon is not the same for every file: it changes with the file's type and with the program that opens it, so you can recognise the type at a glance, before you open anything.

Look again at the files you named. The letter was a document file. The photograph was a picture file. Your eyes were reading icons — that is how the computer shows you each file's kind.

## Sub lesson 2 — Telling file types by their extensions (teacher guide — evidence)

A file's name carries a short ending called its **extension**, and the extension tells the type too. Learn these five:

- **.docx** — a Word document
- **.pptx** — a PowerPoint file
- **.xlsx** — a spreadsheet
- **.mp3** — an audio file
- **.mp4** — a video file

Say each one aloud with its kind. When the extension is showing, you can name a file's kind without opening it at all.

## Sub lesson 3 — The road ahead — six units, and how each unit runs

This course has six units, and they run in this order:

1. **Organization of Files** — the unit you are in now.
2. **Computer Network**
3. **Application Software** — Word, then Excel, then PowerPoint.
4. **Image Processing and Multimedia**
5. **Information and Computer Security**
6. **Fundamentals of Programming** — problem solving, flowcharts, and first scripts.

[Picture 12515 — the six-unit road map, from organizing files to first flowcharts and Scratch scripts]

Every unit runs the same way. It opens with **Brainstorming** questions that start from what you already know. Then come numbered sections with group activities and practical exercises, boxes that pin down the key concepts, a summary, and a review exercise at the end. The year is planned as 72 periods in all, and this unit — Organization of Files — takes 12 of them (teacher guide — evidence). When a new unit feels big, remember the rhythm: brainstorm first, then practise, then review.

## Say it to your companion

Tell your companion what a file is, in your own words. Then name the six units of the course in order, and say how every unit begins. Let your companion name one extension — you say what kind of file it is.

## Do It Yourself

1. Find five files on a computer or phone. For each one, write its name, its kind, and how you knew — its icon or its extension.
2. Draw the six-unit road map on paper, in order, from memory. Check it against the picture and fix any unit that is out of place.
3. Ask someone at home where they keep an important paper record — for example an edir or ekub membership list. Say one thing that record and a computer file have in common.
