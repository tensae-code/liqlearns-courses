# Lesson plan — Creating a new folder

**Course:** Computer Science and ICT · **Title:** Files and Folders · **Lesson:** Creating a new folder
**Place in the curriculum:** Unit 1 — Organization of Files — in the title Files and Folders on the ICT course ladder (TITLES.md).
**The one thing this lesson teaches:** A new folder is created where it should live: go there in File Explorer, open the Home menu, click New folder, type the name, and click outside the text area to finish.
**This lesson's own level:** It stands on everything so far: the learner knows folders and File Explorer — now they make a folder with their own hands. The doing-lessons of file handling begin here.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide.
