# Creating a new folder — multiple choice

Pick the one right answer.

**1. The first step in creating a folder is —**
a) type the name  b) go to where the folder should live  c) click New folder
**Answer: b) go to where the folder should live**

**2. The New folder button is found in —**
a) the Home menu  b) the Search box  c) the Status bar
**Answer: a) the Home menu**

**3. You finish naming the folder by —**
a) pressing Delete  b) closing the window  c) clicking outside the text area
**Answer: c) clicking outside the text area**
