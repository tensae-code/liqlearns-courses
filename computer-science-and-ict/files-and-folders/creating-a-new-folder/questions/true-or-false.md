# Creating a new folder — true or false

Say whether each statement is true or false.

**1. A folder is created where you are standing in File Explorer.**
**Answer: True** — that is why step 1 is going to the right place first.

**2. The name is typed before the New folder button is clicked.**
**Answer: False** — click New folder first, then type the name.

**3. The folder's name is typed after clicking New folder, and finished by clicking outside the text area.**
**Answer: True**
