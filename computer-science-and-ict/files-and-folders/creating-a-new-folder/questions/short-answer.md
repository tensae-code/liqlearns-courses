# Creating a new folder — short answer

Answer in one or two short sentences.

**1. Why does the book put 'go to where the folder should live' first?**
**Answer: A folder is created where you are standing in File Explorer — so you must stand in the right place before creating it.**

**2. A pupil's new folder appears in the wrong place. Which step did they skip or rush?**
**Answer: Step 1 — going to where the folder should live before clicking New folder.**
