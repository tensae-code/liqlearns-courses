# Creating a new folder

## Do it first

You know what a folder is and why it matters. Now make one. Try first, any way you can: create a new folder somewhere on this computer and give it your name. However you did it, this lesson gives the book's own order — the order to trust when your way is not there.

## Creating a new folder — the book's order

1. **Go to where the folder should live** — open that place in File Explorer first.
2. In File Explorer, open the **Home** menu.
3. Click the **New folder** button.
4. **Type the folder's name.**
5. **Click outside the text area** to finish.

## Say it to your companion

Tell your companion the five steps in order, from memory. Then make a folder while your companion checks each step against the list.

## Do It Yourself

1. Go to Documents. Create a new folder there by the book's steps and name it with your own name.
2. Create a second folder inside the first — a subfolder — using the same five steps.
3. Say the five steps aloud once more, pointing at the screen place each step happened.
