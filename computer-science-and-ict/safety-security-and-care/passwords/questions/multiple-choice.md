# Passwords — making a strong one — multiple choice

Pick the one right answer.

**1.** A password is —
a) a kind of cable  b) a sequence of characters verifying a user's identity  c) a user name  d) a program
**Answer: b) a sequence of characters verifying a user's identity** — it verifies identity at authentication.

**2.** The book calls a password —
a) the last resort  b) the first line of defence  c) a decoration  d) a game
**Answer: b) the first line of defence** — first line of defence.

**3.** A strong password is at least —
a) 3 characters  b) 8 characters  c) 100 characters  d) 1 character
**Answer: b) 8 characters** — at least 8.

**4.** The mix in a strong password is —
a) only numbers  b) lowercase, uppercase, numbers and symbols  c) only your name  d) only symbols
**Answer: b) lowercase, uppercase, numbers and symbols** — all four kinds mixed.

**5.** Rule one is —
a) use one password everywhere  b) use a unique password for the account  c) use your birthday  d) tell a friend
**Answer: b) use a unique password for the account** — unique per account.

**6.** The guide compares an unprotected computer to —
a) a locked safe  b) a house door left unlocked overnight  c) a guarded bank  d) a puzzle
**Answer: b) a house door left unlocked overnight** — the unlocked-door analogy.
