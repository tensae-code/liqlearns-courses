# Encryption and RSA Public-Key Cryptography — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) The public key must be guarded as carefully as the private key.**
**Answer: False** — The public key only locks; it can be shared with the whole world.

**2. (Sub lesson 2) Factoring a very large product of two primes is easy for modern computers.**
**Answer: False** — No known method factors such products in useful time — that is RSA's protection.

**3. (Sub lesson 2) A message locked with your public key can be opened with your private key.**
**Answer: True** — Public locks, private unlocks.
