## Backup — the Windows route, in order

Backup returns here as a prevention strategy, with its Windows route. In the book's order:

1. **Right-click Start**.
2. Open **Control Panel**.
3. Choose **System and Security**.
4. Choose **Backup and Restore**.
5. Click **Backup now** — the files are copied to the backup place.

**Cloud backup** is the other form taught: a business's server data and applications backed up onto a **remote server**, away from the building.

## The firewall — what it is

A **firewall** is the network security device that **monitors incoming and outgoing traffic** and **allows or blocks it by a set of security rules** — a gate with a rulebook.

One plain warning travels with it: **a firewall does not stop all viruses**. Antivirus is still needed, and **Windows Defender covers what the firewall misses**.

## Switching the Defender Firewall on — the book's route, in order

In the book's exact order:

1. Open **Start** → **Settings**.
2. Choose **Update & Security**.
3. Choose **Windows Security**.
4. Choose **Firewall & network protection**.
5. **Select a network profile**.
6. Switch **Microsoft Defender Firewall on**.

Three warnings come with the switch. Switching it **off** leaves the device and the network **more vulnerable**. If a needed application is blocked, **let it through the firewall** — do not turn the firewall off. And if a setting will not turn on, or errors appear, **go to the troubleshooter**.
