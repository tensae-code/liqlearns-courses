# Backup and firewall in Windows — multiple choice

Pick the one right answer.

**1.** The backup route begins —
a) Start → Settings → Update & Security  b) right-click Start → Control Panel  c) open Word → File → Save  d) press Delete
**Answer: b) right-click Start → Control Panel** — then System and Security → Backup and Restore.

**2.** Cloud backup means —
a) files copied to a disk in the same room  b) a business's server data and applications backed up onto a remote server  c) printing files  d) deleting old files
**Answer: b) a business's server data and applications backed up onto a remote server** — remote = away from the building.

**3.** A firewall —
a) monitors incoming and outgoing traffic and allows or blocks it by security rules  b) deletes all viruses  c) makes the internet faster  d) writes documents
**Answer: a) monitors incoming and outgoing traffic and allows or blocks it by security rules** — a gate with a rulebook.

**4.** In the firewall route, after Update & Security you choose —
a) Backup and Restore  b) Windows Security  c) User Accounts  d) Control Panel
**Answer: b) Windows Security** — then Firewall & network protection.

**5.** A needed application is blocked by the firewall. You should —
a) switch the firewall off  b) uninstall the firewall  c) let the application through the firewall  d) never use the application
**Answer: c) let the application through the firewall** — the book's own warning.

**6.** The firewall misses some viruses. What covers what it misses?
a) the Recycle Bin  b) Windows Defender (antivirus)  c) the printer  d) cloud backup
**Answer: b) Windows Defender (antivirus)** — a firewall does not stop all viruses.
