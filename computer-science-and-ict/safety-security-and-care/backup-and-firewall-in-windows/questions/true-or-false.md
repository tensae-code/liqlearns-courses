# Backup and firewall in Windows — true or false

Say whether each sentence is true or false.

**1.** Switching the Defender Firewall off leaves the device and network more vulnerable.
**Answer: True** — the book's warning on the switch.

**2.** Backup now is clicked inside Backup and Restore.
**Answer: True** — the last step of the backup route.

**3.** If a firewall setting will not turn on, you should ignore the error.
**Answer: False** — errors go to the troubleshooter.
