# Backup and firewall in Windows — fill in the blank

Fill each blank with the right word.

**1.** Backup route: Control Panel → ______ and Security → Backup and Restore.
**Answer: System**

**2.** Firewall route: Settings → Update & Security → ______ Security.
**Answer: Windows**

**3.** Before switching the firewall on, you select a network ______.
**Answer: profile**
