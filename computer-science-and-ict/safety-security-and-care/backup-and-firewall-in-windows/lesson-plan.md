# Lesson plan — Backup and firewall in Windows

**Course:** Computer Science and ICT · **Title:** Safety, Security and Care · **Lesson:** Backup and firewall in Windows
**Place in the curriculum:** Unit 5 — Information and Computer Security (CURRICULUM.md).
**The one thing this lesson teaches:** two defences worked in Windows itself: backup through Control Panel → System and Security → Backup and Restore, and the Defender Firewall switched on through Settings → Update & Security → Windows Security → Firewall & network protection — in the book's exact routes.
**This lesson's own level:** it stands on the prevention lesson of this unit — the learner knows backup and the firewall as two bricks of the technical wall. It needs nothing else.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. ## Before this lesson
- Recommended first: Threat prevention strategies (the Grade 10 growth of Securing your computer — the checklist). Recommended, never forced.

## What the learner can do when it ends
1. Run the backup route in order: Start → Control Panel → System and Security → Backup and Restore → Backup now.
2. Define cloud backup: server data and applications backed up onto a remote server.
3. Define a firewall: it monitors traffic and allows or blocks it by security rules.
4. Run the Defender Firewall route in order and switch it on for a chosen profile.
5. State the three warnings: off = vulnerable; let a blocked app through instead of switching off; errors go to the troubleshooter.

## What you need
A Windows school computer if one is available — paper works too, screen by screen.

## If the learner is stuck
- Cannot find Backup and Restore → it lives under System and Security in Control Panel — the route, not the search box, is the skill.
- Wants to switch the firewall off for a blocked app → the book's rule: let the app through the firewall; off leaves everything vulnerable.
