# Video script — Backup and firewall in Windows

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Two jobs. Two routes. In order.

JOB ONE — BACKUP.
Right-click Start. Control Panel.
System and Security. Backup and Restore.
Backup now. The files are copied.

JOB TWO — THE FIREWALL.
Start. Settings. Update and Security.
Windows Security.
Firewall and network protection.
Pick a profile. Switch it ON.

The firewall checks the traffic —
some through, some stopped.
But it does not stop all viruses.
Antivirus still stands beside it.

Blocked program? Let it THROUGH the firewall.
Never switch the firewall off.
