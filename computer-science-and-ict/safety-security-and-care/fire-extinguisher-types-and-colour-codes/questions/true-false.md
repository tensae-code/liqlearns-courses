# Fire Extinguisher Types and Colour Codes — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "How are fires classed?" is: By what is burning**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Which fire class does a computer lab fear most?" is: By what is burning**
**Answer: False** — Electrical equipment

**3. (Sub lesson 1) True or false: the answer to "What must water never touch?" is: Electricity or liquid fuel**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does foam do to a liquid fire?" is: By what is burning**
**Answer: False** — Smothers it

**5. (Sub lesson 1) True or false: the answer to "Why is CO₂ the lab's extinguisher?" is: It smothers electrical fires without leaving residue**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does the colour code announce?" is: Red**

**7. (Sub lesson 2) True or false: the answer to "Which colour means water?" is: Red**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Which colour means dry powder?" is: The extinguisher's type**
**Answer: False** — Blue

**9. (Sub lesson 2) True or false: the answer to "Which colour means CO₂?" is: Black**
**Answer: True**
