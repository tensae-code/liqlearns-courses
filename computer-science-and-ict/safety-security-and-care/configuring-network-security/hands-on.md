# Hands-on — Configuring Network Security

The lesson with your hands and your feet, not only your eyes.

## Task one
**Configure a simple network** — For a home or school network you know, write its security configuration: authentication rules, three firewall decisions with reasons, and where encryption applies.

## Task two
**Audit the defaults** — List the security settings a new router or school network ships with. Mark each 'keep' or 'change', with the factor each decision serves.
