# Configuring Network Security — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A set of factors working together — who may enter, what may travel, what is watched, what protects when a defence fails**
**Answer: True**

**2. (Sub lesson 1) True or false: A set of factors working together — who may enter, what may travel, what is watched, what protects when a defence fails** — as the answer to: Why are factors taught before configuration?
**Answer: False — Settings chosen without the factors are superstition**

**3. (Sub lesson 1) True or false: The factors turned into settings, one device at a time**
**Answer: True**

**4. (Sub lesson 1) True or false: The factors turned into settings, one device at a time** — as the answer to: What does password authentication demand?
**Answer: False — A named user and a strong password for every entry — no open doors, no shared secrets**

**5. (Sub lesson 1) True or false: Which traffic may pass and which is turned away**
**Answer: True**

**6. (Sub lesson 2) True or false: Which traffic may pass and which is turned away** — as the answer to: How should firewall rules be kept?
**Answer: False — Set deliberately and reviewed — not left at the installer's defaults**

**7. (Sub lesson 2) True or false: Scrambles traffic and stored data for anyone without the key**
**Answer: True**

**8. (Sub lesson 2) True or false: Scrambles traffic and stored data for anyone without the key** — as the answer to: How does Grade 12 practise the whole?
**Answer: False — As a role-play — configuring a simple network's security end to end**

**9. (Sub lesson 2) True or false: Grade 11 Bab V C.2 and Grade 12 Bab 4 J — network security configuration**
**Answer: True**

**10. (Sub lesson 2) True or false: Grade 11 Bab V C.2 and Grade 12 Bab 4 J — network security configuration** — as the answer to: A strong password on an open door is what?
