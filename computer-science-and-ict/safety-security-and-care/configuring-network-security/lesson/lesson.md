# Configuring Network Security

## Do it first

Configuring network security — setting a network's defences: password authentication, firewall settings and encryption methods, practised on a simple network

## Sub lesson 1 — The factors first — what network security stands on

A network's security is not one tool but a set of **factors** working together: who may enter, what may travel, what is watched, and what is protected when a defence fails. Indonesia's senior books teach the factors first (Grade 11's network-security factors, Grade 12's closing security chapter) and then the **configuration** — because settings chosen without the factors are superstition: a strong password on an open door, encryption on a network whose keys are shared with the street. Configuration is the factors turned into settings, one device at a time.

## Sub lesson 2 — The settings — authentication, firewall, encryption

Three settings carry most of a small network's safety. **Password authentication**: every entry demands a named user and a strong password — no open doors, no shared secrets. The **firewall**: its rules decide which traffic may pass and which is turned away, set deliberately and reviewed, not left at the installer's defaults. **Encryption**: the method by which traffic and stored data are scrambled for anyone without the key, chosen and applied so the network's own conversation is private. Grade 12 practises the whole as a role-play — configuring a simple network's security end to end — because these settings are learned by setting them.
