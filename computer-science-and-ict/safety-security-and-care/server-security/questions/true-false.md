# Server Security — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: It holds many people's data, always on and always reachable**
**Answer: True**

**2. (Sub lesson 1) True or false: Only the administrators, each under their own name** — as the answer to: What does an attacker gain from a server, against a workstation?
**Answer: False — The building, not one desk**

**3. (Sub lesson 1) True or false: Only the administrators, each under their own name**
**Answer: True**

**4. (Sub lesson 1) True or false: The server runs only the services it exists to give** — as the answer to: Why no shared master account?
**Answer: False — Misuse could not be traced to a person — and the key, once leaked, opens everything**

**5. (Sub lesson 2) True or false: The server runs only the services it exists to give**
**Answer: True**

**6. (Sub lesson 2) True or false: Patched software, backups kept apart, and a physically secured room and console** — as the answer to: Why is every extra service a risk?
**Answer: False — Every extra service is an extra door**

**7. (Sub lesson 2) True or false: Patched software, backups kept apart, and a physically secured room and console**
**Answer: True**

**8. (Sub lesson 2) True or false: Security of data sent through the network** — as the answer to: Why must logs be watched, not just kept?
**Answer: False — An alarm that rings to an empty street protects nothing**

**9. (Sub lesson 2) True or false: Security of data sent through the network**
**Answer: True**

**10. (Sub lesson 1) True or false: It holds many people's data, always on and always reachable** — as the answer to: Which chapter teaches this?
**Answer: False — Laos Grade 10 ICT, Chapter 3 §3.1**
