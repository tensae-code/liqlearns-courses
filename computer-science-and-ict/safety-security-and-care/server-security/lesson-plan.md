## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Why the server is the prize and the risk** — The **server** is the network's serving machine, and its security is different in kind from a single computer's: it holds **many people's data in one place**, it is **always on and always reachable** by the network, and its services run whether anyone watches or not. An attacker who takes a workstation takes a desk; an attacker who takes the server takes the building. Laos therefore gives server security its own section, before data in transit and e-commerce: defend the centre first.
2. **How a server is secured** — Server security layers the chapter's defences at their strictest. **Access is minimal and named**: only the administrators hold administrative accounts, each under their own name, with strong passwords — no shared master key. **Services are minimal too**: a server runs only the services it exists to give, because every extra service is an extra door. Its **software is kept patched**, its **files backed up apart**, its **room and console physically secured** (a locked door is a security control), and its **logs watched** — a server nobody reads the logs of is a building whose alarm rings to an empty street.
