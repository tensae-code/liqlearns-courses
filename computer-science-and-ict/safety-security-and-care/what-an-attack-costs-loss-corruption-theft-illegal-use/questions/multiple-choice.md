# What an attack costs — loss, corruption, theft, illegal use — multiple choice

Pick the one right answer.

**1.** What is destruction or loss of information?
a) destroyed components, or data lost — for example to a failed hard disk  b) unauthorised alteration of stored files — such as adding or reducing student marks  c) unauthorised use of computer or network services — such as running private marketing over school Internet  d) using the system's normal function for the attacker's other, unlawful purpose
**Answer: a) destroyed components, or data lost — for example to a failed hard disk**

**2.** What is corruption of information?
a) destroyed components, or data lost — for example to a failed hard disk  b) unauthorised use of computer or network services — such as running private marketing over school Internet  c) using the system's normal function for the attacker's other, unlawful purpose  d) unauthorised alteration of stored files — such as adding or reducing student marks
**Answer: d) unauthorised alteration of stored files — such as adding or reducing student marks**

**3.** What is theft of services?
a) unauthorised alteration of stored files — such as adding or reducing student marks  b) using the system's normal function for the attacker's other, unlawful purpose  c) unauthorised use of computer or network services — such as running private marketing over school Internet  d) destroyed components, or data lost — for example to a failed hard disk
**Answer: c) unauthorised use of computer or network services — such as running private marketing over school Internet**

**4.** What is illegal usage?
a) unauthorised use of computer or network services — such as running private marketing over school Internet  b) using the system's normal function for the attacker's other, unlawful purpose  c) destroyed components, or data lost — for example to a failed hard disk  d) unauthorised alteration of stored files — such as adding or reducing student marks
**Answer: b) using the system's normal function for the attacker's other, unlawful purpose**

**5.** Raising a friend's marks in the school database is —
a) loss  b) corruption of information  c) theft of services  d) maintenance
**Answer: b) corruption of information**

**6.** Impacts of an attack can be psychological, financial, legal or —
a) musical  b) political  c) seasonal  d) optional
**Answer: b) political**
