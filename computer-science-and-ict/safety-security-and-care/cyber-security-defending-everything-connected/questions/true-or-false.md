# Cyber security — defending everything connected — true or false

Say whether each sentence is true or false.

**1.** End-user education is one of cyber security's categories.
**Answer: True** — the user is part of the defence.

**2.** Cyber security protects only computers, not phones or networks.
**Answer: False** — systems, networks, programs, devices and data.

**3.** Intellectual property such as trade secrets is something attackers are after.
**Answer: True** — the teacher guide's keyed list.
