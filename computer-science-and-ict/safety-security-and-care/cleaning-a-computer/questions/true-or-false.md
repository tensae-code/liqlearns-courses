# Cleaning a computer — why, how often, with what — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Dust can cause a fire inside a computer.
**Answer: True** — conductive dust can short-circuit or cause fire.

**2. (Sub lesson 1)** The weekly outside clean uses a wet cloth.
**Answer: False** — a dry cloth.

**3. (Sub lesson 2)** Cleaning wipers serve the casing, monitor and keyboard.
**Answer: True** — the kit table says so.
