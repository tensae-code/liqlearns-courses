# Five kinds of security

## Do it first

A pupil's marks are changed on a teacher's laptop. A payroll spreadsheet is opened by the wrong person. A phone is never updated. Three different things went wrong — because three different things needed securing. Sort them as you read.

## Sorted by what is secured

The kinds of computer security are sorted by what is being secured. Information security secures information from unauthorised access, modification and deletion — a pupil's marks changed on a teacher's laptop is its example. Application security builds security features into applications against cyber threats — payroll or marks held in a spreadsheet are its ground. Mobile and computer security keeps handheld devices and standalone machines updated and patched.

## Networks and cyber

Network security secures the software and hardware technologies of a network — a firewall protects networks from Internet-based attacks. (Cloud security and IoT security are named as topics for a later grade.) Cyber security protects computer systems that communicate over computer networks. And security is not only technological: it is managerial too — people, rules and decisions, not only machines.

## Say it to your companion

Tell your companion, in your own words: security is sorted by what is being secured: information, applications, devices, networks, and systems that talk over networks. Then name the key words of this lesson — information security, application security, network security, cyber security — and say what each one means.
