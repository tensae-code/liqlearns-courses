# Five kinds of security — tf

Say whether each statement is true or false.

**1.** True or false: information security — securing information from unauthorised access, modification and deletion.
**Answer: True**

**2.** True or false: application security — building security features into applications against cyber threats.
**Answer: True**

**3.** True or false: network security is the opposite: it has nothing to do with securing the software and hardware technologies of a network.
**Answer: False** — network security is about securing the software and hardware technologies of a network.
