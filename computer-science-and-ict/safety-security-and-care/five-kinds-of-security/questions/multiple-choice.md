# Five kinds of security — multiple choice

Pick the one right answer.

**1.** What is information security?
a) securing information from unauthorised access, modification and deletion  b) building security features into applications against cyber threats  c) securing the software and hardware technologies of a network  d) protecting computer systems that communicate over computer networks
**Answer: a) securing information from unauthorised access, modification and deletion**

**2.** What is application security?
a) securing information from unauthorised access, modification and deletion  b) securing the software and hardware technologies of a network  c) protecting computer systems that communicate over computer networks  d) building security features into applications against cyber threats
**Answer: d) building security features into applications against cyber threats**

**3.** What is network security?
a) building security features into applications against cyber threats  b) protecting computer systems that communicate over computer networks  c) securing the software and hardware technologies of a network  d) securing information from unauthorised access, modification and deletion
**Answer: c) securing the software and hardware technologies of a network**

**4.** What is cyber security?
a) securing the software and hardware technologies of a network  b) protecting computer systems that communicate over computer networks  c) securing information from unauthorised access, modification and deletion  d) building security features into applications against cyber threats
**Answer: b) protecting computer systems that communicate over computer networks**

**5.** A firewall protecting a network from Internet attacks belongs to —
a) information security  b) network security  c) device patching  d) application design
**Answer: b) network security**

**6.** Security is both technological and —
a) managerial  b) musical  c) temporary  d) invisible
**Answer: a) managerial** — people and rules count too.
