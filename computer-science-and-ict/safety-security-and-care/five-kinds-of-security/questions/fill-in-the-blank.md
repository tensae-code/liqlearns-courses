# Five kinds of security — fill

Fill each blank with the right word or words.

**1.** _____ is building security features into applications against cyber threats. (Name the term.)
**Answer: application security**

**2.** _____ is securing the software and hardware technologies of a network. (Name the term.)
**Answer: network security**

**3.** _____ is protecting computer systems that communicate over computer networks. (Name the term.)
**Answer: cyber security**
