# Lesson plan — Creating a new user account

**Course:** Computer Science and ICT · **Title:** Safety, Security and Care · **Lesson:** Creating a new user account
**Place in the curriculum:** Unit 5 — Information and Computer Security (CURRICULUM.md).
**The one thing this lesson teaches:** a new user account is created in the book's order: 'Add a new user in PC settings' → 'Add someone else to this PC' → username, passphrase and security questions → Next — and the new user starts with no administrator access.
**This lesson's own level:** it stands on the accounts lesson of this unit — the learner knows Administrator, Standard and Guest and what each may do. It needs nothing else.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
This lesson is one whole lesson — it has no sub lessons (a short, single-skill lesson; his ruling 2026-11-09).

## Before this lesson
- Recommended first: User accounts — Administrator, Standard, Guest (with its Grade 10 growth). Recommended, never forced.

## What the learner can do when it ends
1. Run the four creation steps in the book's order.
2. State that the new user has no administrator access by default.
3. State that the Microsoft-account route requires an internet connection.

## What you need
A Windows school computer if one is available — paper works too, screen by screen.

## If the learner is stuck
- Stops after step 1 → step 1 only opens PC settings; the account is made at 'Add someone else to this PC' and finished at Next.
- Expects the new account to be an administrator → by default it is not; that is deliberate.
