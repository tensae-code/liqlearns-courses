# Creating a new user account — multiple choice

Pick the one right answer.

**1.** The first click is —
a) Add someone else to this PC  b) Add a new user in PC settings  c) Next  d) Empty Recycle Bin
**Answer: b) Add a new user in PC settings** — the route opens in PC settings.

**2.** The second step is to scroll down and click —
a) Backup now  b) Add someone else to this PC  c) Firewall & network protection  d) Add or Remove User Accounts
**Answer: b) Add someone else to this PC** — step two of four.

**3.** On the third step you enter —
a) only a username  b) the username, passphrase and security questions and answers  c) the school's address  d) a product key
**Answer: b) the username, passphrase and security questions and answers** — all three are entered before Next.

**4.** By default, the new user —
a) is an administrator  b) has no administrator access  c) cannot sign in  d) deletes other accounts
**Answer: b) has no administrator access** — power is added later only if needed.

**5.** Creating an account with a Microsoft account requires —
a) a printer  b) an internet connection  c) a CD  d) a second computer
**Answer: b) an internet connection** — the local route does not.
