# Creating a new user account — true or false

Say whether each sentence is true or false.

**1.** Clicking Next completes the creation, and the new account appears in the list.
**Answer: True** — the fourth step and its result.

**2.** Security questions are set after the account is created, from the desktop.
**Answer: False** — they are entered at step three, before Next.

**3.** The local creation route needs no internet connection.
**Answer: True** — only the Microsoft-account route does.
