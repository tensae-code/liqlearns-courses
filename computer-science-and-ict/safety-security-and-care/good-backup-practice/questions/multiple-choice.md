# Good Backup Practice — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What decides whether a backup saves you?**
a) Good practice — whether the copy is there, recent and readable on the bad day  b) Back up regularly, on a schedule  c) Work made since the last backup cannot be saved by it  d) The copy lives away from the original — another device, another place or the cloud
**Answer: a) Good practice — whether the copy is there, recent and readable on the bad day**

**2. (Sub lesson 1) What is the first rule of good backup practice?**
a) Work made since the last backup cannot be saved by it  b) Back up regularly, on a schedule  c) The copy lives away from the original — another device, another place or the cloud  d) Because a single backup can fail too
**Answer: b) Back up regularly, on a schedule**

**3. (Sub lesson 1) Why must backup be scheduled, not remembered?**
a) The copy lives away from the original — another device, another place or the cloud  b) Because a single backup can fail too  c) Work made since the last backup cannot be saved by it  d) By checking it — opening the copy and confirming the files are there and readable
**Answer: c) Work made since the last backup cannot be saved by it**

**4. (Sub lesson 1) What does separate mean for a backup?**
a) Because a single backup can fail too  b) By checking it — opening the copy and confirming the files are there and readable  c) Restoring — bringing a file back from the backup  d) The copy lives away from the original — another device, another place or the cloud
**Answer: d) The copy lives away from the original — another device, another place or the cloud**

**5. (Sub lesson 1) Why keep more than one copy of important work?**
a) Because a single backup can fail too  b) By checking it — opening the copy and confirming the files are there and readable  c) Restoring — bringing a file back from the backup  d) Google Drive
**Answer: a) Because a single backup can fail too**

**6. (Sub lesson 2) How is a backup proved?**
a) Restoring — bringing a file back from the backup  b) By checking it — opening the copy and confirming the files are there and readable  c) Google Drive  d) Destroy both the original and the copy together
**Answer: b) By checking it — opening the copy and confirming the files are there and readable**

**7. (Sub lesson 2) What should be practised before it is needed?**
a) Google Drive  b) Destroy both the original and the copy together  c) Restoring — bringing a file back from the backup  d) Regular, separate, and more than one
**Answer: c) Restoring — bringing a file back from the backup**

**8. (Sub lesson 2) Which service does Class VII practise backup on?**
a) Destroy both the original and the copy together  b) Regular, separate, and more than one  c) Good practice — whether the copy is there, recent and readable on the bad day  d) Google Drive
**Answer: d) Google Drive**

**9. (Sub lesson 2) What can one accident do to a backup kept beside the original?**
a) Destroy both the original and the copy together  b) Regular, separate, and more than one  c) Good practice — whether the copy is there, recent and readable on the bad day  d) Back up regularly, on a schedule
**Answer: a) Destroy both the original and the copy together**

**10. (Sub lesson 2) What three words summarise good practice?**
a) Good practice — whether the copy is there, recent and readable on the bad day  b) Regular, separate, and more than one  c) Back up regularly, on a schedule  d) Work made since the last backup cannot be saved by it
**Answer: b) Regular, separate, and more than one**
