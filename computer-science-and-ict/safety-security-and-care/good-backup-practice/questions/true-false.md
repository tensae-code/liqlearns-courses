# Good Backup Practice — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What decides whether a backup saves you?" is: Good practice — whether the copy is there, recent and readable on the bad day**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is the first rule of good backup practice?" is: Because a single backup can fail too**
**Answer: False** — Back up regularly, on a schedule

**3. (Sub lesson 1) True or false: the answer to "Why must backup be scheduled, not remembered?" is: Work made since the last backup cannot be saved by it**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does separate mean for a backup?" is: Restoring — bringing a file back from the backup**
**Answer: False** — The copy lives away from the original — another device, another place or the cloud

**5. (Sub lesson 1) True or false: the answer to "Why keep more than one copy of important work?" is: Because a single backup can fail too**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How is a backup proved?" is: Destroy both the original and the copy together**
**Answer: False** — By checking it — opening the copy and confirming the files are there and readable

**7. (Sub lesson 2) True or false: the answer to "What should be practised before it is needed?" is: Restoring — bringing a file back from the backup**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Which service does Class VII practise backup on?" is: Good practice — whether the copy is there, recent and readable on the bad day**
**Answer: False** — Google Drive

**9. (Sub lesson 2) True or false: the answer to "What can one accident do to a backup kept beside the original?" is: Destroy both the original and the copy together**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What three words summarise good practice?" is: Work made since the last backup cannot be saved by it**
**Answer: False** — Regular, separate, and more than one
