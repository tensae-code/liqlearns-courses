# Good Backup Practice

## Do it first

Having a backup is a start; having a good one is a habit. Class VII's backup chapter ends with practice: the rules that decide whether, on the bad day, the copy is actually there, recent and readable.

## Sub lesson 1 — The rules of a good backup — regular, separate, more than one

Good backup practice has three standing rules. **Regular**: back up on a schedule, not when you remember — work made since the last backup is work the backup cannot save. **Separate**: the copy lives away from the original — another device, another place, or the cloud — so one accident cannot take both. **More than one**: important work keeps copies in more than one place, because a single backup can fail too.

## Sub lesson 2 — Proving the backup — check and restore

A backup is only believed when it is **checked**: open the copy now and then and confirm the files are there and readable, and practise **restoring** — bringing a file back — before the day you must. Class VII teaches backup to Google Drive in the same chapter: the practice and the tool together, so the habit forms on the service the pupils actually use.
