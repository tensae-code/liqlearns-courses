# Starting up a computer — true or false

Say whether each sentence is true or false.

**1.** The teacher checks the connections with the pupils.
**Answer: True** — the book builds the teacher check into step one.

**2.** You should press power before plugging in the cord.
**Answer: False** — cord and checks come first.

**3.** The operating system loads automatically at start-up.
**Answer: True** — you wait while it loads.
