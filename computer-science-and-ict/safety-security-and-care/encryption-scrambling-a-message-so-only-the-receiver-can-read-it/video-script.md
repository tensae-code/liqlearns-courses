# Video script — Encryption — Scrambling a Message So Only the Receiver Can Read It

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

**Encryption** turns a readable message into **scramble** — ciphertext — that only the intended **receiver** can turn back, with the matching key. Everyone between sender and receiver — the network, the servers, an interceptor — handles the scramble and learns nothing from it. Kuwait's worksheet is **WhatsApp's end-to-end encryption**: the message is scrambled on the sender's phone and unscrambled only on the receiver's, so even the service carrying it cannot read it — 'end to end' names exactly whose hands hold keys: the two ends, and no one between.
The same theme teaches **private (incognito) browsing** with a warning built in: a private window keeps the browsing **off the device's own history** — the next user of the machine sees nothing — but it does **not** encrypt the journey or hide it from the network. Kuwait places the two together so they are never confused: encryption protects the message's **contents on its journey**; private mode protects only the **traces on your own machine**. Different shields, different attacks.
