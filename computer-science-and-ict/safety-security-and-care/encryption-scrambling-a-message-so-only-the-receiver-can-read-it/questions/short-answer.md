# Encryption — Scrambling a Message So Only the Receiver Can Read It — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is encryption?**
**Answer: Turning a readable message into scramble (ciphertext) only the intended receiver can turn back**

**2. (Sub lesson 1) Who can read the scramble between sender and receiver?**
**Answer: No one — everyone between handles scramble and learns nothing**

**3. (Sub lesson 1) What is end-to-end encryption?**
**Answer: Scrambled on the sender's phone, unscrambled only on the receiver's — even the service cannot read it**

**4. (Sub lesson 1) Whose hands hold the keys in end-to-end?**
**Answer: The two ends — and no one between**

**5. (Sub lesson 1) Which app is Kuwait's worksheet?**
**Answer: WhatsApp**

**6. (Sub lesson 2) What does private (incognito) browsing protect?**
**Answer: The device's own history — the next user of the machine sees nothing**

**7. (Sub lesson 2) What does private browsing NOT do?**
**Answer: Encrypt the journey or hide it from the network**

**8. (Sub lesson 2) State the difference in one line.**
**Answer: Encryption protects contents on the journey; private mode protects traces on your own machine**

**9. (Sub lesson 2) Under which theme is this taught?**
**Answer: Security procedures for the CIA pillars — Theme 3**

**10. (Sub lesson 2) Which book teaches this?**
**Answer: Kuwait Grade 10 Information Technology Term 1, Unit 1 Theme 3**
