# The 90/10 rule — security is mostly you — multiple choice

Pick the one right answer.

**1.** What is the 90/10 rule?
a) only 10% of security countermeasures are technical; 90% of defence relies on the user following good practices  b) the 10% of security that tools and software provide  c) the habits of the user, carrying 90% of security defence  d) what students, teachers, employees, merchants and citizens must learn and practise
**Answer: a) only 10% of security countermeasures are technical; 90% of defence relies on the user following good practices**

**2.** What is technical countermeasures?
a) only 10% of security countermeasures are technical; 90% of defence relies on the user following good practices  b) the habits of the user, carrying 90% of security defence  c) what students, teachers, employees, merchants and citizens must learn and practise  d) the 10% of security that tools and software provide
**Answer: d) the 10% of security that tools and software provide**

**3.** What is good computer practices?
a) the 10% of security that tools and software provide  b) what students, teachers, employees, merchants and citizens must learn and practise  c) the habits of the user, carrying 90% of security defence  d) only 10% of security countermeasures are technical; 90% of defence relies on the user following good practices
**Answer: c) the habits of the user, carrying 90% of security defence**

**4.** What is security awareness?
a) the habits of the user, carrying 90% of security defence  b) what students, teachers, employees, merchants and citizens must learn and practise  c) only 10% of security countermeasures are technical; 90% of defence relies on the user following good practices  d) the 10% of security that tools and software provide
**Answer: b) what students, teachers, employees, merchants and citizens must learn and practise**

**5.** Under the 90/10 rule, the bigger share of defence is —
a) new hardware  b) the user's good practices  c) faster Internet  d) more passwords
**Answer: b) the user's good practices**

**6.** A school with strong software but careless users is —
a) fully safe  b) protected only in the small technical slice  c) breaking the law  d) offline
**Answer: b) protected only in the small technical slice**
