# The 90/10 rule — security is mostly you — fill

Fill each blank with the right word or words.

**1.** _____ is the 10% of security that tools and software provide. (Name the term.)
**Answer: technical countermeasures**

**2.** _____ is the habits of the user, carrying 90% of security defence. (Name the term.)
**Answer: good computer practices**

**3.** _____ is what students, teachers, employees, merchants and citizens must learn and practise. (Name the term.)
**Answer: security awareness**
