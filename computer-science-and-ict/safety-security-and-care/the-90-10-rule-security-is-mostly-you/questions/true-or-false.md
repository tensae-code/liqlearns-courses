# The 90/10 rule — security is mostly you — tf

Say whether each statement is true or false.

**1.** True or false: the 90/10 rule — only 10% of security countermeasures are technical; 90% of defence relies on the user following good practices.
**Answer: True**

**2.** True or false: technical countermeasures — the 10% of security that tools and software provide.
**Answer: True**

**3.** True or false: good computer practices is the opposite: it has nothing to do with the habits of the user, carrying 90% of security defence.
**Answer: False** — good computer practices is about the habits of the user, carrying 90% of security defence.
