# The 90/10 rule — security is mostly you

## Do it first

Imagine a school buys the best antivirus money can buy — then a pupil clicks every link, shares every password and leaves every machine logged in. How much of the school's security did the purchase really buy? Keep your answer; this lesson puts a number on it.

## The rule

There is a customary rule of computer security — the 90/10 rule. Only 10% of security countermeasures are technical. The other 90% of security defence relies on the user, and on the user following good computer practices. The strongest software guards only the small slice; the person's habits guard the big slice.

[Picture 20902 — The 90/10 rule — a pie of security]

## Why awareness carries the unit

That is why security awareness matters so much — for students, teachers, employees, merchants and all citizens. A rule like this changes where the effort goes: teach the people, and the technology they already have starts to work. Neglect the people, and no purchase can fill the gap.

## Say it to your companion

Tell your companion, in your own words: only 10% of security countermeasures are technical; 90% of security defence relies on the user following good computer practices. Then name the key words of this lesson — the 90/10 rule, technical countermeasures, good computer practices, security awareness — and say what each one means.
