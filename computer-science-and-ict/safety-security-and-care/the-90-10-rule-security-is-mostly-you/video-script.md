# Video script — The 90/10 rule — security is mostly you

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

This is **The 90/10 rule — security is mostly you**.

**the 90/10 rule** — only 10% of security countermeasures are technical; 90% of defence relies on the user following good practices.

**technical countermeasures** — the 10% of security that tools and software provide.

**good computer practices** — the habits of the user, carrying 90% of security defence.

**security awareness** — what students, teachers, employees, merchants and citizens must learn and practise.
