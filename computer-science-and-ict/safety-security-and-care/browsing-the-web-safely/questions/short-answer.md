# Browsing the Web Safely — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is checked before a page loads?**
**Answer: The address — that the name is exactly the name meant**

**2. (Sub lesson 1) What is a copycat site?**
**Answer: A site with a famous name slightly altered, built to harvest details**

**3. (Sub lesson 1) What must a page asking for a password show?**
**Answer: The padlock / https — an encrypted road to the site**

**4. (Sub lesson 1) How is their absence on such a page treated?**
**Answer: As a stop sign**

**5. (Sub lesson 2) How are shouting pop-ups handled?**
**Answer: Closed, never obeyed — a real warning never arrives as a shouting web page**

**6. (Sub lesson 2) Where are downloads taken from?**
**Answer: Only the maker's own site**

**7. (Sub lesson 2) What happens to a file a page pushes unasked?**
**Answer: It is refused**

**8. (Sub lesson 2) How much information does a strange form get?**
**Answer: The least the errand truly needs**

**9. (Sub lesson 2) When is browsing unsafe, in the sequence's rule?**
**Answer: The moment the page starts making the choices**

**10. (Sub lesson 1) Which chapter teaches this?**
**Answer: Laos Grade 12 ICT, Chapter 2 §II.5**
