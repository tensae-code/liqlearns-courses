# SQL injection — tf

Say whether each statement is true or false.

**1.** True or false: SQL injection — an attacker injecting unauthorised input into an SQL statement.
**Answer: True**

**2.** True or false: SQL — the language websites use to talk to their databases (Structured Query Language).
**Answer: True**

**3.** True or false: injection is the opposite: it has nothing to do with slipping unauthorised input into a statement so it is obeyed.
**Answer: False** — injection is about slipping unauthorised input into a statement so it is obeyed.
