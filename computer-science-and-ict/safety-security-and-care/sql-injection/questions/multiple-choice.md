# SQL injection — multiple choice

Pick the one right answer.

**1.** What is SQL injection?
a) an attacker injecting unauthorised input into an SQL statement  b) the language websites use to talk to their databases (Structured Query Language)  c) slipping unauthorised input into a statement so it is obeyed  d) only on websites where the database can be reached using a user's ID and password
**Answer: a) an attacker injecting unauthorised input into an SQL statement**

**2.** What is SQL?
a) an attacker injecting unauthorised input into an SQL statement  b) slipping unauthorised input into a statement so it is obeyed  c) only on websites where the database can be reached using a user's ID and password  d) the language websites use to talk to their databases (Structured Query Language)
**Answer: d) the language websites use to talk to their databases (Structured Query Language)**

**3.** What is injection?
a) the language websites use to talk to their databases (Structured Query Language)  b) only on websites where the database can be reached using a user's ID and password  c) slipping unauthorised input into a statement so it is obeyed  d) an attacker injecting unauthorised input into an SQL statement
**Answer: c) slipping unauthorised input into a statement so it is obeyed**

**4.** What is where it works?
a) slipping unauthorised input into a statement so it is obeyed  b) only on websites where the database can be reached using a user's ID and password  c) an attacker injecting unauthorised input into an SQL statement  d) the language websites use to talk to their databases (Structured Query Language)
**Answer: b) only on websites where the database can be reached using a user's ID and password**

**5.** The attacker in an SQL injection speaks to the website's —
a) printer  b) database, in its own language  c) screen  d) keyboard
**Answer: b) database, in its own language**

**6.** SQL injection needs a website where —
a) anyone can post photos  b) the database can be reached using a user's ID and password  c) there is no login at all  d) the server is off
**Answer: b) the database can be reached using a user's ID and password**
