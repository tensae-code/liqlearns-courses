# SQL injection — fill

Fill each blank with the right word or words.

**1.** _____ is the language websites use to talk to their databases (Structured Query Language). (Name the term.)
**Answer: SQL**

**2.** _____ is slipping unauthorised input into a statement so it is obeyed. (Name the term.)
**Answer: injection**

**3.** _____ is only on websites where the database can be reached using a user's ID and password. (Name the term.)
**Answer: where it works**
