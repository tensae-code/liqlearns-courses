---

This is **SQL injection**.

**SQL injection** — an attacker injecting unauthorised input into an SQL statement.

**SQL** — the language websites use to talk to their databases (Structured Query Language).

**injection** — slipping unauthorised input into a statement so it is obeyed.

**where it works** — only on websites where the database can be reached using a user's ID and password.
