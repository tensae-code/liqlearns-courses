# User accounts — Administrator, Standard, Guest — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Disruption of service is one of security's three threats.
**Answer: True** — theft/damage to hardware, theft/damage to information, disruption.

**2. (Sub lesson 2)** Standard accounts can install any program.
**Answer: False** — installing is the Administrator's power.

**3. (Sub lesson 2)** Every user should always work as Administrator.
**Answer: False** — everyday work belongs on Standard; power is given by need.
