# User accounts — Administrator, Standard, Guest — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Computer security protects against —
a) theft of or damage to hardware and information, and disruption of service  b) dust only  c) slow typing  d) homework
**Answer: a) theft of or damage to hardware and information, and disruption of service** — the three named threats.

**2. (Sub lesson 1)** A user account is made of —
a) a picture and a song  b) a user name plus a password  c) a cable and a plug  d) a name only
**Answer: b) a user name plus a password** — identity = user name + password.

**3. (Sub lesson 2)** The Administrator can —
a) do everyday tasks only  b) control the whole computer and install programs  c) never sign in  d) only browse
**Answer: b) control the whole computer and install programs** — full control, including installing.

**4. (Sub lesson 2)** A Standard account cannot —
a) run existing programs  b) install programs or make big changes  c) write documents  d) sign in
**Answer: b) install programs or make big changes** — everyday tasks yes; installing and big changes no.

**5. (Sub lesson 2)** A Guest account —
a) is the most powerful  b) lets anyone sign in, not recognised by name  c) needs no computer  d) is for installing
**Answer: b) lets anyone sign in, not recognised by name** — anyone, unnamed.

**6. (Sub lesson 1)** The protection this lesson teaches for accounts is —
a) locks on the door only  b) passwords  c) fingerprints only  d) nothing
**Answer: b) passwords** — passwords on user accounts.
