# Confidentiality, integrity, availability — the CIA triad — tf

Say whether each statement is true or false.

**1.** True or false: confidentiality — information available only to the intended audience — only authorised users can access it.
**Answer: True**

**2.** True or false: integrity — data that can be trusted — correct, authentic, reliable, not wrongly changed.
**Answer: True**

**3.** True or false: availability is the opposite: it has nothing to do with information available to authorised users whenever they require it.
**Answer: False** — availability is about information available to authorised users whenever they require it.
