# Shut down, Sleep and Sign Out — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The Shut down route, in order, is —
a) Power → Start → Shut down  b) Start → Power → Shut down  c) Start → Shut down → Power  d) File → Exit
**Answer: b) Start → Power → Shut down** — Start, Power, Shut down.

**2. (Sub lesson 1)** Shut down leaves the computer —
a) asleep  b) fully off, the proper way  c) signed out only  d) restarting forever
**Answer: b) fully off, the proper way** — fully off, by the route.

**3. (Sub lesson 2)** Sleep is found —
a) in Settings only  b) by the same Start → Power route  c) on the desktop icon  d) in Word
**Answer: b) by the same Start → Power route** — same route, choosing Sleep.

**4. (Sub lesson 2)** A sleeping computer —
a) is fully off  b) looks off but restarts faster  c) loses all work always  d) cannot wake
**Answer: b) looks off but restarts faster** — looks off, wakes fast, keeps your place.

**5. (Sub lesson 3)** Sign Out is chosen —
a) from the Power menu  b) by clicking the signed-in user name at the top-right of the Start screen  c) from the Recycle Bin  d) by unplugging
**Answer: b) by clicking the signed-in user name at the top-right of the Start screen** — user name, top-right, Sign Out.

**6. (Sub lesson 3)** Stepping away for a long time: choose —
a) Sleep  b) Shut down  c) Sign Out only  d) nothing
**Answer: b) Shut down** — the guide's rule: long absence, shut down.
