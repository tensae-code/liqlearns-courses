# Lesson plan — Shut down, Sleep and Sign Out

**Course:** Computer Science and ICT · **Title:** Safety, Security and Care · **Lesson:** Shut down, Sleep and Sign Out
**Place in the curriculum:** Title 13 — Safety, Security and Care in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 7 book, Unit 5 — Security and Safety of Computer. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** in Windows 10, Shut down runs Start → Power → Shut down; Sleep takes the same route and wakes fast; Sign Out leaves the account free for the next person — and the guide adds when to choose each.
**This lesson's own level:** it is a doing-lesson — it pairs with the start-up lesson before it: one turns the machine on properly, this one leaves it properly.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Shut down** — Start button → Power button → Shut down, in that order
2. **Sleep** — the same Start → Power route choosing Sleep; the computer looks off but restarts faster
3. **Sign Out — and choosing (teacher guide — evidence)** — click the signed-in user name at the top-right of the Start screen and choose Sign Out; the guide's choice rule: shut down for a long absence, sleep for a brief one

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson

## What the learner can do when it ends
1. Shut down by Start → Power → Shut down, in order.
2. Put the computer to Sleep by the same route.
3. Sign out by the user-name route.
4. Choose shut down or sleep for a long or brief absence, with the guide's reasons.

## If the learner is stuck
- Holds the power button to switch off → the proper route is Start → Power → Shut down; the held button is a forced stop, not a shutdown.
- Leaves the machine asleep all weekend → the guide's caution: asleep for an extended absence, the battery runs down; shut down instead.
