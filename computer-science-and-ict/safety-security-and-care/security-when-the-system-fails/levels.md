# Security When the System Fails — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — What system failure threatens
Sub lesson 1 questions from the type files. Pass mark: The machine or its software stopping, breaking or working wrongly, with no attacker; A failed disk, a power cut, and a corrupting program (or worn parts); Data lost (availability) and data damaged (integrity); Every disk fails eventually; Laos Grade 10 ICT, Chapter 3 §2.4.

## Sub lesson 2 — The defences — copies, power and recovery
Sub lesson 2 questions from the type files. Pass mark: Backups — copies kept apart and kept current; Only if restoring from them has been practised; Time to close the machine's work cleanly; A written recovery order — what restarts, in what order, by whom; The data does not care whether a thief or a dead disk took it.
