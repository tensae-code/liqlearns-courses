# Security When the System Fails — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What is a system failure?** → **The machine or its software stopping, breaking or working wrongly, with no attacker**

**2. (Sub lesson 1) Name three causes of system failure.** → **A failed disk, a power cut, and a corrupting program (or worn parts)**

**3. (Sub lesson 1) Which two losses does failure inflict?** → **Data lost (availability) and data damaged (integrity)**

**4. (Sub lesson 1) Why is failure certain in a way attacks are not?** → **Every disk fails eventually**

**5. (Sub lesson 2) What is the first defence against failure?** → **Backups — copies kept apart and kept current**

**6. (Sub lesson 2) When do backups count?** → **Only if restoring from them has been practised**

**7. (Sub lesson 2) What does a UPS buy in a power cut?** → **Time to close the machine's work cleanly**

**8. (Sub lesson 2) What turns a bad day into procedure?** → **A written recovery order — what restarts, in what order, by whom**

**9. (Sub lesson 2) Why is failure a security event?** → **The data does not care whether a thief or a dead disk took it**

**10. (Sub lesson 1) Which chapter teaches this?** → **Laos Grade 10 ICT, Chapter 3 §2.4**
