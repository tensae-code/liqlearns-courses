# Security When the System Fails — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The machine or its software stopping, breaking or working wrongly, with no attacker**
**Answer: True**

**2. (Sub lesson 1) True or false: Data lost (availability) and data damaged (integrity)** — as the answer to: Name three causes of system failure.
**Answer: False — A failed disk, a power cut, and a corrupting program (or worn parts)**

**3. (Sub lesson 1) True or false: Data lost (availability) and data damaged (integrity)**
**Answer: True**

**4. (Sub lesson 1) True or false: Backups — copies kept apart and kept current** — as the answer to: Why is failure certain in a way attacks are not?
**Answer: False — Every disk fails eventually**

**5. (Sub lesson 2) True or false: Backups — copies kept apart and kept current**
**Answer: True**

**6. (Sub lesson 2) True or false: Time to close the machine's work cleanly** — as the answer to: When do backups count?
**Answer: False — Only if restoring from them has been practised**

**7. (Sub lesson 2) True or false: Time to close the machine's work cleanly**
**Answer: True**

**8. (Sub lesson 2) True or false: The data does not care whether a thief or a dead disk took it** — as the answer to: What turns a bad day into procedure?
**Answer: False — A written recovery order — what restarts, in what order, by whom**

**9. (Sub lesson 2) True or false: The data does not care whether a thief or a dead disk took it**
**Answer: True**

**10. (Sub lesson 1) True or false: The machine or its software stopping, breaking or working wrongly, with no attacker** — as the answer to: Which chapter teaches this?
**Answer: False — Laos Grade 10 ICT, Chapter 3 §2.4**
