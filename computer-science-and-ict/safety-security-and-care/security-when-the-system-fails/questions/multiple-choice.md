# Security When the System Fails — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a system failure?**
a) The machine or its software stopping, breaking or working wrongly, with no attacker  b) A failed disk, a power cut, and a corrupting program (or worn parts)  c) Data lost (availability) and data damaged (integrity)  d) Every disk fails eventually
**Answer: a**

**2. (Sub lesson 1) Name three causes of system failure.**
a) Data lost (availability) and data damaged (integrity)  b) A failed disk, a power cut, and a corrupting program (or worn parts)  c) Every disk fails eventually  d) Backups — copies kept apart and kept current
**Answer: b**

**3. (Sub lesson 1) Which two losses does failure inflict?**
a) Every disk fails eventually  b) Backups — copies kept apart and kept current  c) Data lost (availability) and data damaged (integrity)  d) Only if restoring from them has been practised
**Answer: c**

**4. (Sub lesson 1) Why is failure certain in a way attacks are not?**
a) Backups — copies kept apart and kept current  b) Only if restoring from them has been practised  c) Time to close the machine's work cleanly  d) Every disk fails eventually
**Answer: d**

**Answer: b**
