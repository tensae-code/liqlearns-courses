# Handling portable devices safely — calls, headsets, distance — true or false

Say true or false for each one.

**1.** Speakerphone should be used whenever possible for calls.
**Answer: True.**

**2.** Long conversations can harm muscle, skin and ear.
**Answer: True.**

**3.** Keeping the phone against your body all day follows Rule 3.
**Answer: False** — Rule 3 says keep devices away from the body; carry them in a bag.
