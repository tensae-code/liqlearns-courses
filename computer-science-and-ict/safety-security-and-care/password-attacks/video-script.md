This is **Password attacks**.

**a dictionary attack** — trying possible passwords taken from a dictionary.

**brute force** — decoding a password by trial and error — time-consuming.

**shoulder surfing** — physically looking over the user's shoulder to steal a password.

**a rainbow table** — pre-computed hash values used to find passwords.
