# Password attacks — tf

Say whether each statement is true or false.

**1.** True or false: a dictionary attack — trying possible passwords taken from a dictionary.
**Answer: True**

**2.** True or false: brute force — decoding a password by trial and error — time-consuming.
**Answer: True**

**3.** True or false: shoulder surfing is the opposite: it has nothing to do with physically looking over the user's shoulder to steal a password.
**Answer: False** — shoulder surfing is about physically looking over the user's shoulder to steal a password.
