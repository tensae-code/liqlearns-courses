# Password attacks — multiple choice

Pick the one right answer.

**1.** What is a dictionary attack?
a) trying possible passwords taken from a dictionary  b) decoding a password by trial and error — time-consuming  c) physically looking over the user's shoulder to steal a password  d) pre-computed hash values used to find passwords
**Answer: a) trying possible passwords taken from a dictionary**

**2.** What is brute force?
a) trying possible passwords taken from a dictionary  b) physically looking over the user's shoulder to steal a password  c) pre-computed hash values used to find passwords  d) decoding a password by trial and error — time-consuming
**Answer: d) decoding a password by trial and error — time-consuming**

**3.** What is shoulder surfing?
a) decoding a password by trial and error — time-consuming  b) pre-computed hash values used to find passwords  c) physically looking over the user's shoulder to steal a password  d) trying possible passwords taken from a dictionary
**Answer: c) physically looking over the user's shoulder to steal a password**

**4.** What is a rainbow table?
a) physically looking over the user's shoulder to steal a password  b) pre-computed hash values used to find passwords  c) trying possible passwords taken from a dictionary  d) decoding a password by trial and error — time-consuming
**Answer: b) pre-computed hash values used to find passwords**

**5.** Which password attack uses no computer at all?
a) brute force  b) rainbow table  c) shoulder surfing  d) dictionary attack
**Answer: c) shoulder surfing** — just an eye over a shoulder.

**6.** Brute force is described as —
a) instant  b) time-consuming trial and error  c) a kind of phishing  d) watching
**Answer: b) time-consuming trial and error**
