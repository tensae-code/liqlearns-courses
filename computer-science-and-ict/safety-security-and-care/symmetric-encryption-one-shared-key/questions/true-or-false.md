# Symmetric Encryption — One Shared Key — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Decryption with a symmetric cipher uses a different key from encryption.**
**Answer: False** — One and the same key does both jobs — that is what symmetric means.

**2. (Sub lesson 1) A bigger key space makes brute-force trying of all keys hopeless.**
**Answer: True** — 128-bit keys have more values than anyone can try; 25 shifts can be tried in a minute.

**3. (Sub lesson 1) AES and the Caesar shift differ in shape: AES uses two keys.**
**Answer: False** — Both are symmetric — one shared key; AES differs in strength and scale, not in shape.

**4. (Sub lesson 2) Real systems often use asymmetric encryption to deliver a symmetric key, then symmetric encryption for the data.**
**Answer: True** — That marriage is the standard design: asymmetric solves delivery, symmetric carries bulk fast.
