# Symmetric Encryption — One Shared Key — short answer

Answer in your own words, in one or two sentences.

**1. (Sub lesson 2) Explain the key-distribution problem to someone who has never heard of encryption.**
**Answer: Both people need the same secret key before any secret message can travel, but every road the key itself could travel on is watched by the same attackers the encryption is meant to defeat — so you need a safe channel to start a safe channel.**

**2. (Sub lesson 1) Why does security rest on the key and not on keeping the method secret?**
**Answer: A method is one secret shared by millions of users and cannot be changed once leaked, while a key is one user's small, cheap, changeable secret — and with a large key space, knowing the method still leaves the attacker all keys to try.**
