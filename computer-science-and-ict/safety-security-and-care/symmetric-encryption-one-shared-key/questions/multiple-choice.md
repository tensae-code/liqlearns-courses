# Symmetric Encryption — One Shared Key — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Symmetric encryption means —**
a) Two different keys  b) One and the same key encrypts and decrypts  c) No key at all  d) The key is published
**Answer: b) One and the same key encrypts and decrypts** — Symmetric = the same key both ways, like one padlock key.

**2. (Sub lesson 1) With shift key 3, the letter H encrypts to —**
a) E  b) K  c) L  d) D
**Answer: b) K** — H + 3 places forward = K (and HALLO becomes KDOOR).

**3. (Sub lesson 1) In a modern cipher like AES, what is kept secret?**
a) The method  b) The alphabet  c) The key  d) The existence of the message
**Answer: c) The key** — The method is public; the key alone is the secret.

**4. (Sub lesson 1) Why can a shift cipher be broken by hand?**
a) It has only 25 possible keys, so all can be tried  b) It uses letters  c) It is old  d) It is symmetric
**Answer: a) It has only 25 possible keys, so all can be tried** — A tiny key space invites brute force; a 128-bit key space forbids it.

**5. (Sub lesson 2) The key-distribution problem is —**
a) Keys are expensive  b) Both sides need the same key first, but sending it safely needs the safe channel encryption was meant to create  c) Keys get lost  d) There are too many keys
**Answer: b) Both sides need the same key first, but sending it safely needs the safe channel encryption was meant to create** — That circle is the problem asymmetric encryption was invented to break.

**6. (Sub lesson 2) Symmetric encryption is still used for bulk data mainly because it is —**
a) Old  b) Fast  c) Secret  d) Free
**Answer: b) Fast** — Speed is its great strength; real systems pair it with asymmetric key delivery.
