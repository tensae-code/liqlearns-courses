# Video script — Symmetric Encryption — One Shared Key

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A secret message needs a key. In symmetric encryption, one key does both jobs.

It locks the message. The same key unlocks it.

Caesar shifted every letter by the key. Three forward to lock, three back to unlock.

Modern ciphers do the same job with huge keys — far too many to guess.

But both sides need the key first. Sending it safely is the hard part.

Symmetric is fast. Getting the key there is its famous problem.
