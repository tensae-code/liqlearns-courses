**Acceptance count: taught in 2 countries (Germany, Malaysia).**

Germany is counted from a partially-held copy: the held PDF is a PARTIAL, disordered screenshot compilation (see the book entry above), and this placement rests on the book's verified complete contents and sampled pages.

Placement choice: this lesson was built new for the ICT expansion (Germany, 2026-11-14) because no existing lesson in the course covers this thing as its own lesson — the live tree was checked for the slug and for near matches before building. 

Germany's own way: a Bavarian NTG Gymnasium book built on four deep strands — graph theory (adjacency matrices, breadth-first search, Dijkstra), coding and cryptography (symmetric/asymmetric encryption, signatures), network communication, and AI up to neural networks — closing with student projects including programming a social bot. This lesson keeps that depth: the idea is taught whole, with the book's own worked way, not thinned down.

Malaysia's own way (Grade 9, ASK Tingkatan 3): Tingkatan 3 is unusually advanced for Grade 9 — a full cryptography unit (ciphers taught, compared and chosen), search and sort algorithms in pseudocode/flowchart, and a full databases-and-SQL unit built in Microsoft Access (entities, keys, cardinality, forms, SQL with Boolean expressions, reports) before returning to Python functions and procedures.

Malaysia's own way (Grade 11, SK Tingkatan 5): the final-year elective is exam-level computer science — computer architecture (fetch-decode-execute, Von Neumann, pipelining) and logic gates with Boolean expressions, a 57-page advanced SQL chapter that starts from ERD and normalisation, and a full web-programming chapter pair: client-side JavaScript (including sorting/searching, standard library, arrays) and server-side PHP working with text files, validation, queries, sign-up/login, ending in an interactive website build.
