# What security and computer security mean

## Do it first

Think of this textbook. Using it in class to study is fine. Using it inside an examination is not. Same book, same pupil — one use is allowed, the other is not. That difference — allowed and not allowed — is where this lesson starts.

## Security — freedom from danger

Security in general is the quality of being secure: freedom from danger — that is safety — and freedom from fear or anxiety. For institutions and business, the working definition is protection, and the measures taken to guard against sabotage, crime, attack or escape. Ethiopia's federal Information Network Security Agency — INSA — is the national cyber-security agency, the country's own guardian for this work.

## Computer security

Computer security is the protection of computer systems and information from harm, theft and unauthorised use. It is also the process of preventing and detecting unauthorised use — stopping it before it happens, and catching it when it happens. Unauthorised means not allowed: using this textbook in class or in study is authorised; using it during an examination is not.

## Say it to your companion

Tell your companion, in your own words: security is freedom from danger, and computer security is protecting computer systems and information from harm, theft and unauthorised use. Then name the key words of this lesson — security, computer security, unauthorised use, INSA — and say what each one means.
