# What security and computer security mean — tf

Say whether each statement is true or false.

**1.** True or false: security — freedom from danger, and freedom from fear or anxiety.
**Answer: True**

**2.** True or false: computer security — the protection of computer systems and information from harm, theft and unauthorised use.
**Answer: True**

**3.** True or false: unauthorised use is the opposite: it has nothing to do with using a system or information in a way that is not allowed.
**Answer: False** — unauthorised use is about using a system or information in a way that is not allowed.

**4.** Connecting a computer to a network and the internet is what exposes it to viruses and hackers.
**Answer: True** — the exposure comes with the connection.

**5.** A hacker is a person who gains unauthorised access to data.
**Answer: True** — the book's definition.
