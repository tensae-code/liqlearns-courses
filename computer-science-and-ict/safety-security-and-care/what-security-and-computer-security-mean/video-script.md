This is **What security and computer security mean**.

**security** — freedom from danger, and freedom from fear or anxiety.

**computer security** — the protection of computer systems and information from harm, theft and unauthorised use.

**unauthorised use** — using a system or information in a way that is not allowed.

**INSA** — Ethiopia's federal Information Network Security Agency, the national cyber-security agency.

Now you try. Say each word. Say what it means.
