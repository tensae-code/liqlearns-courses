# Using a smartphone properly — ten rules — true or false

Say true or false for each one.

**1.** Taking a break from your phone is one of the ten rules.
**Answer: True.**

**2.** Browsing unnecessary links is recommended.
**Answer: False** — the rule is to avoid browsing unnecessary links.

**3.** A phone may be used in places with a lot of electrical equipment.
**Answer: False** — the rule says do not use it there.
