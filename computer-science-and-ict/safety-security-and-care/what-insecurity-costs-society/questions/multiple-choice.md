# What insecurity costs — impact on society — multiple choice

Pick the one right answer.

**1.** Security risks arise from —
a) intentional or unintentional misuse of computers, networks and the internet  b) computers being switched on  c) typing too fast  d) having too many files
**Answer: a) intentional or unintentional misuse of computers, networks and the internet** — the book's own opening line.

**2.** Which list is the book's five costs of violated security?
a) hardware, software, confidential information, data integrity, availability  b) paper, pencils, books, desks, chairs  c) speed, colour, size, weight, price  d) teachers, pupils, parents, guards, cleaners
**Answer: a) hardware, software, confidential information, data integrity, availability** — all five, in the book's order.

**3.** A hacker who controls a computer by remote access —
a) repairs it for free  b) runs it from far away as if at its keyboard  c) only looks at its case  d) cannot do anything
**Answer: b) runs it from far away as if at its keyboard** — remote control is the far end of the hacker's range.

**4.** Data integrity is lost when —
a) data is changed so it can no longer be trusted  b) a file is printed  c) a password is typed  d) the screen is cleaned
**Answer: a) data is changed so it can no longer be trusted** — integrity is about data staying true.

**5.** Violating information and computer security is —
a) encouraged  b) ignored  c) punishable  d) impossible
**Answer: c) punishable** — the book states it plainly.
