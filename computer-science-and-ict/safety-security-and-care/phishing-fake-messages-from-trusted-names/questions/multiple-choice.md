# Phishing — fake messages from trusted names — multiple choice

Pick the one right answer.

**1.** What is phishing?
a) fraudulent communications appearing to come from a reputable source, sent to steal data or install malware  b) a trusted name the message pretends to be — a bank or known service  c) sensitive data such as credit-card and login information  d) learning to recognise it
**Answer: a) fraudulent communications appearing to come from a reputable source, sent to steal data or install malware**

**2.** What is a reputable source?
a) fraudulent communications appearing to come from a reputable source, sent to steal data or install malware  b) sensitive data such as credit-card and login information  c) learning to recognise it  d) a trusted name the message pretends to be — a bank or known service
**Answer: d) a trusted name the message pretends to be — a bank or known service**

**3.** What is what phishing steals?
a) a trusted name the message pretends to be — a bank or known service  b) learning to recognise it  c) sensitive data such as credit-card and login information  d) fraudulent communications appearing to come from a reputable source, sent to steal data or install malware
**Answer: c) sensitive data such as credit-card and login information**

**4.** What is the defence against phishing?
a) sensitive data such as credit-card and login information  b) learning to recognise it  c) fraudulent communications appearing to come from a reputable source, sent to steal data or install malware  d) a trusted name the message pretends to be — a bank or known service
**Answer: b) learning to recognise it**

**5.** A message that seems to be from Telebirr asks you to 'confirm' your PIN by a link. This is most likely —
a) a gift  b) phishing  c) an update  d) eavesdropping
**Answer: b) phishing** — a trusted name is being borrowed to steal login details.

**6.** Phishing usually arrives by —
a) post  b) email  c) radio  d) printer
**Answer: b) email**
