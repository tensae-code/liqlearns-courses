# Phishing — fake messages from trusted names — tf

Say whether each statement is true or false.

**1.** True or false: phishing — fraudulent communications appearing to come from a reputable source, sent to steal data or install malware.
**Answer: True**

**2.** True or false: a reputable source — a trusted name the message pretends to be — a bank or known service.
**Answer: True**

**3.** True or false: what phishing steals is the opposite: it has nothing to do with sensitive data such as credit-card and login information.
**Answer: False** — what phishing steals is about sensitive data such as credit-card and login information.
