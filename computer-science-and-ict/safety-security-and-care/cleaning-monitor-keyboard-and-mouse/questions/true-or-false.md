# Cleaning monitor, keyboard and mouse — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Spraying water directly on a monitor screen is the book's method.
**Answer: False** — never spray; moisten the cloth.

**2. (Sub lesson 2)** Keyboard cleaning should be gentle around the keys.
**Answer: True** — gently is part of the procedure.

**3. (Sub lesson 3)** A mouse can be reconnected while still damp.
**Answer: False** — let all parts dry first.
