# Ergonomic guidelines — eight habits at the computer — true or false

Say true or false for each one.

**1.** You should face the screen directly.
**Answer: True.**

**2.** Elbows should be held far out from the body.
**Answer: False** — elbows stay comfortably close to the body.

**3.** A chair that supports the lower back is one of the guidelines.
**Answer: True.**
