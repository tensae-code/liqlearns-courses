# Comparing Cipher Methods — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — The methods on the table
Sub lesson 1 questions from the type files. Pass mark: A rule that turns plaintext into ciphertext, with some key or pattern; It moves every letter by the same number of places; Each letter is swapped for another by a fixed table — not necessarily in alphabet order; The letters' order — the letters themselves are kept; Strength and weakness both follow from how the method works.

## Sub lesson 2 — The grounds of comparison
Sub lesson 2 questions from the type files. Pass mark: Strength, what the method hides, and ease of correct use; Only 25 keys exist to try; Word lengths and letter frequencies; The letters themselves — only their order is hidden; No — it is stronger here, weaker there, easier for this user; the table gives reasons.
