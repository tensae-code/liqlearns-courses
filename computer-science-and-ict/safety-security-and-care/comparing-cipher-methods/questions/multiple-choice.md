# Comparing Cipher Methods — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What shape do all the unit's methods share?**
a) A rule that turns plaintext into ciphertext, with some key or pattern  b) It moves every letter by the same number of places  c) Each letter is swapped for another by a fixed table — not necessarily in alphabet order  d) The letters' order — the letters themselves are kept
**Answer: a) A rule that turns plaintext into ciphertext, with some key or pattern**

**2. (Sub lesson 1) How does a shift (Caesar) method work?**
a) Each letter is swapped for another by a fixed table — not necessarily in alphabet order  b) It moves every letter by the same number of places  c) The letters' order — the letters themselves are kept  d) Strength and weakness both follow from how the method works
**Answer: b) It moves every letter by the same number of places**

**3. (Sub lesson 1) How does a substitution method differ?**
a) The letters' order — the letters themselves are kept  b) Strength and weakness both follow from how the method works  c) Each letter is swapped for another by a fixed table — not necessarily in alphabet order  d) Strength, what the method hides, and ease of correct use
**Answer: c) Each letter is swapped for another by a fixed table — not necessarily in alphabet order**

**4. (Sub lesson 1) What does a transposition method change?**
a) Strength and weakness both follow from how the method works  b) Strength, what the method hides, and ease of correct use  c) Only 25 keys exist to try  d) The letters' order — the letters themselves are kept
**Answer: d) The letters' order — the letters themselves are kept**

**5. (Sub lesson 1) Why does comparison start with the working?**
a) Strength and weakness both follow from how the method works  b) Strength, what the method hides, and ease of correct use  c) Only 25 keys exist to try  d) Word lengths and letter frequencies
**Answer: a) Strength and weakness both follow from how the method works**

**6. (Sub lesson 2) On what grounds are methods compared?**
a) Only 25 keys exist to try  b) Strength, what the method hides, and ease of correct use  c) Word lengths and letter frequencies  d) The letters themselves — only their order is hidden
**Answer: b) Strength, what the method hides, and ease of correct use**

**7. (Sub lesson 2) Why is a shift weak on strength?**
a) Word lengths and letter frequencies  b) The letters themselves — only their order is hidden  c) Only 25 keys exist to try  d) No — it is stronger here, weaker there, easier for this user; the table gives reasons

**8. (Sub lesson 2) What clues does substitution leave?**
a) The letters themselves — only their order is hidden  b) No — it is stronger here, weaker there, easier for this user; the table gives reasons  c) A rule that turns plaintext into ciphertext, with some key or pattern  d) Word lengths and letter frequencies

a) The letters themselves — only their order is hidden  b) No — it is stronger here, weaker there, easier for this user; the table gives reasons  c) A rule that turns plaintext into ciphertext, with some key or pattern  d) It moves every letter by the same number of places
