# Comparing Cipher Methods — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What shape do all the unit's methods share?" is: A rule that turns plaintext into ciphertext, with some key or pattern**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How does a shift (Caesar) method work?" is: Each letter is swapped for another by a fixed table — not necessarily in alphabet order**
**Answer: False** — It moves every letter by the same number of places

**3. (Sub lesson 1) True or false: the answer to "How does a substitution method differ?" is: Each letter is swapped for another by a fixed table — not necessarily in alphabet order**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does a transposition method change?" is: Strength and weakness both follow from how the method works**
**Answer: False** — The letters' order — the letters themselves are kept

**5. (Sub lesson 1) True or false: the answer to "Why does comparison start with the working?" is: Strength and weakness both follow from how the method works**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "On what grounds are methods compared?" is: Only 25 keys exist to try**
**Answer: False** — Strength, what the method hides, and ease of correct use

**7. (Sub lesson 2) True or false: the answer to "Why is a shift weak on strength?" is: Only 25 keys exist to try**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What clues does substitution leave?" is: The letters themselves — only their order is hidden**
**Answer: False** — Word lengths and letter frequencies

**9. (Sub lesson 2) True or false: the answer to "What does transposition leave visible?" is: The letters themselves — only their order is hidden**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Can a method be simply 'better'?" is: A rule that turns plaintext into ciphertext, with some key or pattern**
**Answer: False** — No — it is stronger here, weaker there, easier for this user; the table gives reasons
