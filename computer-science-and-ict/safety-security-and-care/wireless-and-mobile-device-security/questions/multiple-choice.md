# Wireless and Mobile Device Security — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Why does wireless traffic need special care?**
a) It travels through the air, beyond the room — anyone in reach can listen  b) Encryption and the network password  c) An invitation — any listener may read unencrypted traffic and join  d) A copied network name harvesting whoever joins
