# Antivirus software — scan, detect, remove — multiple choice

Pick the one right answer.

**1.** Antivirus software functions to —
a) scan, detect and remove viruses  b) write, print and save documents  c) connect, browse and download  d) shut down, sleep and restart
**Answer: a) scan, detect and remove viruses** — the three jobs, in order.

**2.** The second of the three jobs is —
a) scan  b) detect  c) remove  d) install
**Answer: b) detect** — scan first, detect second, remove third.

**3.** Which of these is in the fuller malware list antivirus guards against?
a) keyloggers  b) spreadsheets  c) monitors  d) printers
**Answer: a) keyloggers** — botnets, rootkits and keyloggers join the list.

**4.** A file is flagged as infected. That is the job called —
a) scan  b) detect  c) remove  d) backup
**Answer: b) detect** — flagging is detecting.

**5.** You cannot remove a virus before you —
a) print it  b) detect it  c) name the computer  d) restart twice
**Answer: b) detect it** — the order is fixed.
