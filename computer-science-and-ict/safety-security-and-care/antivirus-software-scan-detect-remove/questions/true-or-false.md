# Antivirus software — scan, detect, remove — true or false

Say whether each sentence is true or false.

**1.** Antivirus software protects against worms and spyware as well as viruses.
**Answer: True** — all three are named.

**2.** Remove comes before scan in the antivirus order.
**Answer: False** — scan → detect → remove.

**3.** A rootkit is a kind of malware antivirus guards against.
**Answer: True** — the fuller key-concept list.
