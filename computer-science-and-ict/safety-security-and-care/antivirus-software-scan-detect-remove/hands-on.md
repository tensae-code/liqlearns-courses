# Hands-on — Antivirus software — scan, detect, remove

The lesson with your hands, not only your eyes.

## Three-job drill
Hide six file cards in a folder — one marked INFECTED underneath. A partner 'scans' by turning cards one by one, 'detects' by calling the infected card, 'removes' it from the folder. Swap roles.

## Guard list
Write the six malware kinds as a guard list poster for the classroom wall, one line per kind saying what it does — from the threats lesson.
