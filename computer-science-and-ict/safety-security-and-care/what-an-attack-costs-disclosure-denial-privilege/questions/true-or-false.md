# What an attack costs — disclosure, denial, privilege — tf

Say whether each statement is true or false.

**1.** True or false: disclosure of information — dissemination of information to anyone unauthorised — such as a photographed internal letter posted publicly.
**Answer: True**

**2.** True or false: denial of use — the intentional degradation or blocking of resources so intended users cannot reach them.
**Answer: True**

**3.** True or false: elevation of privilege is the opposite: it has nothing to do with using a system weakness to gain rights that should not be available.
**Answer: False** — elevation of privilege is about using a system weakness to gain rights that should not be available.
