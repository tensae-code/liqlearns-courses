# Ciphers in Problem Solving — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — The problem shape — need, choice, application
Sub lesson 1 questions from the type files. Pass mark: A situation with a secrecy need — a message that must travel unreadable and arrive readable by one reader; State the need, choose the method, apply it exactly, hand over ciphertext and key by separate paths; By a separate safe path — never with the ciphertext; Letter by letter, with the chosen key or table; The ciphertext only.

## Sub lesson 2 — Checking the solution — decrypt and judge
Sub lesson 2 questions from the type files. Pass mark: From the reader's end — decrypt and recover the plaintext exactly; The application failed — rework the encryption; Could an unintended hand break this method in the time the secret must last?; The choice was wrong for the need — solve again with a stronger method; With that judgement written down.
