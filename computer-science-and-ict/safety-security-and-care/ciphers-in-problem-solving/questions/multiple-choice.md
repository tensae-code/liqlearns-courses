# Ciphers in Problem Solving — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does a cipher problem state?**
a) A situation with a secrecy need — a message that must travel unreadable and arrive readable by one reader  b) State the need, choose the method, apply it exactly, hand over ciphertext and key by separate paths  c) By a separate safe path — never with the ciphertext  d) Letter by letter, with the chosen key or table
**Answer: a) A situation with a secrecy need — a message that must travel unreadable and arrive readable by one reader**

**2. (Sub lesson 1) What is the solving chain?**
a) By a separate safe path — never with the ciphertext  b) State the need, choose the method, apply it exactly, hand over ciphertext and key by separate paths  c) Letter by letter, with the chosen key or table  d) The ciphertext only
**Answer: b) State the need, choose the method, apply it exactly, hand over ciphertext and key by separate paths**

**3. (Sub lesson 1) How is the key handed over?**
a) Letter by letter, with the chosen key or table  b) The ciphertext only  c) By a separate safe path — never with the ciphertext  d) From the reader's end — decrypt and recover the plaintext exactly
**Answer: c) By a separate safe path — never with the ciphertext**

**4. (Sub lesson 1) How exactly is the method applied?**
a) The ciphertext only  b) From the reader's end — decrypt and recover the plaintext exactly  c) The application failed — rework the encryption  d) Letter by letter, with the chosen key or table
**Answer: d) Letter by letter, with the chosen key or table**

**5. (Sub lesson 1) What travels through the untrusted hands?**
a) The ciphertext only  b) From the reader's end — decrypt and recover the plaintext exactly  c) The application failed — rework the encryption  d) Could an unintended hand break this method in the time the secret must last?
**Answer: a) The ciphertext only**

**6. (Sub lesson 2) How is the solution checked?**
a) The application failed — rework the encryption  b) From the reader's end — decrypt and recover the plaintext exactly  c) Could an unintended hand break this method in the time the secret must last?  d) The choice was wrong for the need — solve again with a stronger method
**Answer: b) From the reader's end — decrypt and recover the plaintext exactly**

**7. (Sub lesson 2) One wrong letter in the recovery means what?**
a) Could an unintended hand break this method in the time the secret must last?  b) The choice was wrong for the need — solve again with a stronger method  c) The application failed — rework the encryption  d) With that judgement written down
**Answer: c) The application failed — rework the encryption**

**8. (Sub lesson 2) What judgement follows the check?**
a) The choice was wrong for the need — solve again with a stronger method  b) With that judgement written down  c) A situation with a secrecy need — a message that must travel unreadable and arrive readable by one reader  d) Could an unintended hand break this method in the time the secret must last?
**Answer: d) Could an unintended hand break this method in the time the secret must last?**

**9. (Sub lesson 2) If it could, what was wrong?**
a) The choice was wrong for the need — solve again with a stronger method  b) With that judgement written down  c) A situation with a secrecy need — a message that must travel unreadable and arrive readable by one reader  d) State the need, choose the method, apply it exactly, hand over ciphertext and key by separate paths
**Answer: a) The choice was wrong for the need — solve again with a stronger method**

**10. (Sub lesson 2) How do Malaysia's problems end?**
a) A situation with a secrecy need — a message that must travel unreadable and arrive readable by one reader  b) With that judgement written down  c) State the need, choose the method, apply it exactly, hand over ciphertext and key by separate paths  d) By a separate safe path — never with the ciphertext
