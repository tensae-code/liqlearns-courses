# Ciphers in Problem Solving — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does a cipher problem state?" is: A situation with a secrecy need — a message that must travel unreadable and arrive readable by one reader**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is the solving chain?" is: By a separate safe path — never with the ciphertext**
**Answer: False** — State the need, choose the method, apply it exactly, hand over ciphertext and key by separate paths

**3. (Sub lesson 1) True or false: the answer to "How is the key handed over?" is: By a separate safe path — never with the ciphertext**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How exactly is the method applied?" is: The ciphertext only**
**Answer: False** — Letter by letter, with the chosen key or table

**5. (Sub lesson 1) True or false: the answer to "What travels through the untrusted hands?" is: The ciphertext only**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How is the solution checked?" is: The application failed — rework the encryption**
**Answer: False** — From the reader's end — decrypt and recover the plaintext exactly

**7. (Sub lesson 2) True or false: the answer to "One wrong letter in the recovery means what?" is: The application failed — rework the encryption**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What judgement follows the check?" is: The choice was wrong for the need — solve again with a stronger method**
**Answer: False** — Could an unintended hand break this method in the time the secret must last?

**9. (Sub lesson 2) True or false: the answer to "If it could, what was wrong?" is: The choice was wrong for the need — solve again with a stronger method**
**Answer: True**
