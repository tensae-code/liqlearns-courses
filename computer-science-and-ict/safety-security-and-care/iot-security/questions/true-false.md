# IoT Security — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: It is a computer — a way into its network**
**Answer: True**

**2. (Sub lesson 1) True or false: It is a computer — a way into its network** — as the answer to: Name three weaknesses things ship with.
**Answer: False — Default passwords, rare updates, owners who think them too small to matter**

**3. (Sub lesson 1) True or false: Thousands of captured things aimed together at others**
**Answer: True**

**4. (Sub lesson 1) True or false: Thousands of captured things aimed together at others** — as the answer to: Through what might an attacker enter a whole network?
**Answer: False — One weak thing — a camera, a toy**

**5. (Sub lesson 1) True or false: The same factory (default) password**
**Answer: True**

**6. (Sub lesson 2) True or false: The same factory (default) password** — as the answer to: Name the five standing measures.
**Answer: False — Change defaults, update, segment the IoT network, switch off unneeded features, buy from updating makers**

**7. (Sub lesson 2) True or false: So a captured thing cannot reach computers holding data**
**Answer: True**

**8. (Sub lesson 2) True or false: So a captured thing cannot reach computers holding data** — as the answer to: What should be switched off?
**Answer: False — Features and services a device does not need**

**9. (Sub lesson 2) True or false: That it publishes updates**
**Answer: True**

**10. (Sub lesson 2) True or false: That it publishes updates** — as the answer to: When is security architecture, not decoration?
**Answer: False — When it is decided inside the design**
