# Spam — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Unwanted mail sent in bulk to addresses that never asked for it**
**Answer: True**

**2. (Sub lesson 1) True or false: Sending costs almost nothing — a few buyers from a million pay for it** — as the answer to: Give three kinds of spam content.
**Answer: False — Worthless-goods advertisements, false prizes, and chain pleas (also forged letters)**

**3. (Sub lesson 1) True or false: Sending costs almost nothing — a few buyers from a million pay for it**
**Answer: True**

**4. (Sub lesson 1) True or false: Malware (in attachments) and phishing (in its links)** — as the answer to: Who pays spam's real costs?
**Answer: False — Every inbox — in time, storage, network load and buried true mail**

**5. (Sub lesson 1) True or false: Malware (in attachments) and phishing (in its links)**
**Answer: True**

**6. (Sub lesson 2) True or false: Never reply, never buy, never click, never open attachments, guard the address** — as the answer to: What does a spam filter do?
**Answer: False — Learns the flood's shapes and files spam apart from real mail**

**7. (Sub lesson 2) True or false: Never reply, never buy, never click, never open attachments, guard the address**
**Answer: True**

**8. (Sub lesson 2) True or false: The flood begins where addresses are given away** — as the answer to: Why is replying the worst response?
**Answer: False — It proves a person reads that address, which is then sold on as live**

**9. (Sub lesson 2) True or false: The flood begins where addresses are given away**
**Answer: True**

**10. (Sub lesson 2) True or false: Unwanted mail sent in bulk to addresses that never asked for it** — as the answer to: Which chapter teaches this?
**Answer: False — Laos Grade 10 ICT, Chapter 3 §4.4**
