# Spam — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — What spam is
Sub lesson 1 questions from the type files. Pass mark: Unwanted mail sent in bulk to addresses that never asked for it; Worthless-goods advertisements, false prizes, and chain pleas (also forged letters); Sending costs almost nothing — a few buyers from a million pay for it; Every inbox — in time, storage, network load and buried true mail; Malware (in attachments) and phishing (in its links).

## Sub lesson 2 — What spam carries, and the defences
Sub lesson 2 questions from the type files. Pass mark: Learns the flood's shapes and files spam apart from real mail; Never reply, never buy, never click, never open attachments, guard the address; It proves a person reads that address, which is then sold on as live; The flood begins where addresses are given away; Laos Grade 10 ICT, Chapter 3 §4.4.
