# Asymmetric Encryption — Two Keys — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) The public key must be kept as secret as the private key.**
**Answer: False** — The public key is built to be published; guarding it is unnecessary.

**2. (Sub lesson 1) What one key of a pair locks, only the other key of the pair unlocks.**
**Answer: True** — That linkage is the definition of the key pair.

**3. (Sub lesson 2) Asymmetric encryption removes the need for any shared secret to travel before secret messages.**
**Answer: True** — Public keys travel openly and lock only; private keys never travel.

**4. (Sub lesson 2) Your browser's protected connection to a far shop is an everyday use of this lesson's idea.**
**Answer: True** — HTTPS begins with a key-pair exchange of exactly this shape.
