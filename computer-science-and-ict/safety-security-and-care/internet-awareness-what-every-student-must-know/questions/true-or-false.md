# Internet awareness — what every student must know — tf

Say whether each statement is true or false.

**1.** True or false: electronic footprints — the traces even messages to known friends leave, which others can misuse.
**Answer: True**

**2.** True or false: grooming — what predators do after contact — winning trust to lure a pupil into false security.
**Answer: True**

**3.** True or false: a safe download is the opposite: it has nothing to do with a download judged legal and free of malicious code before it is opened.
**Answer: False** — a safe download is about a download judged legal and free of malicious code before it is opened.
