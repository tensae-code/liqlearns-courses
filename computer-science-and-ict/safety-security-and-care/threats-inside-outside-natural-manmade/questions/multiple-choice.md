# Threats — inside, outside, natural, man-made — multiple choice

Pick the one right answer.

**1.** What is internal threats?
a) threats that come from inside an institution  b) threats that come from outside an institution  c) damage done by mistake, an unintended action  d) attacks done deliberately
**Answer: a) threats that come from inside an institution**

**2.** What is external threats?
a) threats that come from inside an institution  b) damage done by mistake, an unintended action  c) attacks done deliberately  d) threats that come from outside an institution
**Answer: d) threats that come from outside an institution**

**3.** What is accidental attacks?
a) threats that come from outside an institution  b) attacks done deliberately  c) damage done by mistake, an unintended action  d) threats that come from inside an institution
**Answer: c) damage done by mistake, an unintended action**

**4.** What is intentional attacks?
a) damage done by mistake, an unintended action  b) attacks done deliberately  c) threats that come from inside an institution  d) threats that come from outside an institution
**Answer: b) attacks done deliberately**

**5.** Deleting a file by mistake is —
a) intentional  b) accidental  c) natural  d) impossible
**Answer: b) accidental**

**6.** A flood damaging the server room is a threat from —
a) an insider  b) natural factors  c) a password  d) an application
**Answer: b) natural factors**
