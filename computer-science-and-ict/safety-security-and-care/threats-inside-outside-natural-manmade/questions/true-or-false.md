# Threats — inside, outside, natural, man-made — tf

Say whether each statement is true or false.

**1.** True or false: internal threats — threats that come from inside an institution.
**Answer: True**

**2.** True or false: external threats — threats that come from outside an institution.
**Answer: True**

**3.** True or false: accidental attacks is the opposite: it has nothing to do with damage done by mistake, an unintended action.
**Answer: False** — accidental attacks is about damage done by mistake, an unintended action.
