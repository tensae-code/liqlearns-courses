# Protecting Files — Read-Only, Hidden, Encrypted — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What can you do with a read-only file?**
a) Open and read it, but not change or save over it  b) In the file's properties  c) Keeps it out of the folder listing  d) By switching hidden items on
**Answer: a) Open and read it, but not change or save over it**

**2. (Sub lesson 1) Where is read-only set?**
a) Keeps it out of the folder listing  b) In the file's properties  c) By switching hidden items on  d) The careless, not the determined
**Answer: b) In the file's properties**

**3. (Sub lesson 1) What does hiding a file do?**
a) By switching hidden items on  b) The careless, not the determined  c) Keeps it out of the folder listing  d) Open and read it, but not change or save over it
**Answer: c) Keeps it out of the folder listing**

**4. (Sub lesson 1) How is a hidden file seen again?**
a) The careless, not the determined  b) Open and read it, but not change or save over it  c) In the file's properties  d) By switching hidden items on
**Answer: d) By switching hidden items on**

**5. (Sub lesson 1) Whom do the gentle guards stop?**
a) The careless, not the determined  b) Open and read it, but not change or save over it  c) In the file's properties  d) Keeps it out of the folder listing
**Answer: a) The careless, not the determined**

**6. (Sub lesson 2) What does encryption do to a file?**
a) The key — the password  b) Scrambles its contents so it reads as noise without the key  c) It stays locked  d) Edits
**Answer: b) Scrambles its contents so it reads as noise without the key**

**7. (Sub lesson 2) What unlocks an encrypted file?**
a) It stays locked  b) Edits  c) The key — the password  d) Encryption
**Answer: c) The key — the password**

**8. (Sub lesson 2) What happens if an encrypted file is copied elsewhere?**
a) Edits  b) Encryption  c) Scrambles its contents so it reads as noise without the key  d) It stays locked
**Answer: d) It stays locked**

**9. (Sub lesson 2) Match the guards: read-only guards against…**
a) Edits  b) Encryption  c) Scrambles its contents so it reads as noise without the key  d) The key — the password
**Answer: a) Edits**

**10. (Sub lesson 2) Which guard works against anyone without the key?**
a) Scrambles its contents so it reads as noise without the key  b) Encryption  c) The key — the password  d) It stays locked
**Answer: b) Encryption**
