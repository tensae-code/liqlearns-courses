# Protecting Files — Read-Only, Hidden, Encrypted — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What can you do with a read-only file?" is: Open and read it, but not change or save over it**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Where is read-only set?" is: Open and read it, but not change or save over it**
**Answer: False** — In the file's properties

**3. (Sub lesson 1) True or false: the answer to "What does hiding a file do?" is: Keeps it out of the folder listing**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How is a hidden file seen again?" is: Open and read it, but not change or save over it**
**Answer: False** — By switching hidden items on

**5. (Sub lesson 1) True or false: the answer to "Whom do the gentle guards stop?" is: The careless, not the determined**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does encryption do to a file?" is: The key — the password**
**Answer: False** — Scrambles its contents so it reads as noise without the key

**7. (Sub lesson 2) True or false: the answer to "What unlocks an encrypted file?" is: The key — the password**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What happens if an encrypted file is copied elsewhere?" is: Scrambles its contents so it reads as noise without the key**
**Answer: False** — It stays locked

**9. (Sub lesson 2) True or false: the answer to "Match the guards: read-only guards against…" is: Edits**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Which guard works against anyone without the key?" is: Scrambles its contents so it reads as noise without the key**
**Answer: False** — Encryption
