# Hands-on — Protecting Files — Read-Only, Hidden, Encrypted

The lesson with your hands and your feet, not only your eyes.

## Task one
('Three locks drill', 'On a practice file you own: set it read-only and try to edit it; hide it and find it again; then write — without doing it on anything precious — the steps your system gives for encrypting a folder. Record what each guard did and did not stop.')

## Task two
('Choose the guard', 'For each case pick a protection and defend it in one sentence: a class marks file others keep overwriting; a diary on a shared computer; a fees record sent to another office.')
