# Video script — Protecting Files — Read-Only, Hidden, Encrypted

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A **read-only** file can be opened and read but **not changed or saved over** — set in the file's properties, it stops accidents and casual edits, though anyone can untick it. A **hidden** file is kept **out of the folder listing** — the folder looks empty of it until hidden items are switched on. Both are gentle guards: they stop the *careless*, not the *determined*, and the book teaches them as the first rung of file protection.
**Encryption** scrambles a file's contents so it reads as **noise without the key** — the password that unlocks it. In the book's practical, a file or folder is encrypted on the computer so that only the owner's account can open it sensibly; copied elsewhere, it stays locked. The three protections stack by strength: read-only guards against *edits*, hidden against *eyes*, encryption against *anyone without the key* — which is why the book's security unit ends here.
