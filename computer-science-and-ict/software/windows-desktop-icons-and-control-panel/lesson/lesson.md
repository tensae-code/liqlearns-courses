# Windows Desktop, Icons and Control Panel

## Do it first

Start a computer and look at the first screen Windows shows. Count the little pictures on it. In this lesson you name that screen, arrange its pictures, and meet the one room where Windows itself is set.

## Sub lesson 1 — The desktop and arranging its icons

When Windows finishes starting, the screen it shows is the **desktop** — the working surface where everything begins. On it stand **icons**: small pictures, each standing for a program, a file or a folder, opened with a double-click. Icons can be **arranged** — dragged to new places, lined up in a grid and sorted — so the desktop stays tidy and every program is found at once. A desktop you have arranged yourself is the first step of working in Windows the Sudanese way: in order, not in a pile.

## Sub lesson 2 — The Control Panel — where Windows is set

The **Control Panel** is the place where Windows gathers its **settings** — the choices that decide how the computer itself looks and behaves. You open it from the Start menu, and it shows its settings as icons, one for each part of the machine. The lessons after this one in Sudan's Grade 5 book live inside it: the appearance of Windows and the date and time are both changed from this one room. Open the Control Panel when the computer itself — not a document — needs to change.
