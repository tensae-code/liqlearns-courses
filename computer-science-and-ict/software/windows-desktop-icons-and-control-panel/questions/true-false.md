# Windows Desktop, Icons and Control Panel — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is the desktop in Windows?" is: The working surface Windows shows when starting finishes, where everything begins**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is an icon?" is: Dragging them into order — lined up and sorted so each is found at once**
**Answer: False** — A small picture standing for a program, a file or a folder

**3. (Sub lesson 1) True or false: the answer to "How is a thing on the desktop opened?" is: With a double-click on its icon**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does arranging icons mean?" is: The place where Windows gathers the settings for how the computer itself looks and behaves**
**Answer: False** — Dragging them into order — lined up and sorted so each is found at once

**5. (Sub lesson 1) True or false: the answer to "Why keep the desktop arranged?" is: So every program is found quickly instead of hunted for in a pile**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is the Control Panel?" is: As icons, one for each part of the machine**
**Answer: False** — The place where Windows gathers the settings for how the computer itself looks and behaves

**7. (Sub lesson 2) True or false: the answer to "How is the Control Panel opened?" is: From the Start menu**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How does the Control Panel show its settings?" is: When the computer itself — not a document — needs to change**
**Answer: False** — As icons, one for each part of the machine

**9. (Sub lesson 2) True or false: the answer to "Name two things changed from the Control Panel in this book." is: The appearance of Windows, and the date and time**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "When do you open the Control Panel?" is: A small picture standing for a program, a file or a folder**
**Answer: False** — When the computer itself — not a document — needs to change
