# Windows Desktop, Icons and Control Panel — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is the desktop in Windows?**
**Answer: The working surface Windows shows when starting finishes, where everything begins**

**2. (Sub lesson 1) What is an icon?**
**Answer: A small picture standing for a program, a file or a folder**

**3. (Sub lesson 1) How is a thing on the desktop opened?**
**Answer: With a double-click on its icon**

**4. (Sub lesson 1) What does arranging icons mean?**
**Answer: Dragging them into order — lined up and sorted so each is found at once**

**5. (Sub lesson 1) Why keep the desktop arranged?**
**Answer: So every program is found quickly instead of hunted for in a pile**

**6. (Sub lesson 2) What is the Control Panel?**
**Answer: The place where Windows gathers the settings for how the computer itself looks and behaves**

**7. (Sub lesson 2) How is the Control Panel opened?**
**Answer: From the Start menu**

**8. (Sub lesson 2) How does the Control Panel show its settings?**
**Answer: As icons, one for each part of the machine**

**9. (Sub lesson 2) Name two things changed from the Control Panel in this book.**
**Answer: The appearance of Windows, and the date and time**

**10. (Sub lesson 2) When do you open the Control Panel?**
**Answer: When the computer itself — not a document — needs to change**
