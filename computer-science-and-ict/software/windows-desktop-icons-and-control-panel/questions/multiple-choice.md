# Windows Desktop, Icons and Control Panel — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is the desktop in Windows?**
a) The working surface Windows shows when starting finishes, where everything begins  b) A small picture standing for a program, a file or a folder  c) Dragging them into order — lined up and sorted so each is found at once  d) The place where Windows gathers the settings for how the computer itself looks and behaves
**Answer: a) The working surface Windows shows when starting finishes, where everything begins**

**2. (Sub lesson 1) What is an icon?**
a) With a double-click on its icon  b) A small picture standing for a program, a file or a folder  c) So every program is found quickly instead of hunted for in a pile  d) From the Start menu
**Answer: b) A small picture standing for a program, a file or a folder**

**3. (Sub lesson 1) How is a thing on the desktop opened?**
a) Dragging them into order — lined up and sorted so each is found at once  b) The place where Windows gathers the settings for how the computer itself looks and behaves  c) With a double-click on its icon  d) As icons, one for each part of the machine
**Answer: c) With a double-click on its icon**

**4. (Sub lesson 1) What does arranging icons mean?**
a) So every program is found quickly instead of hunted for in a pile  b) From the Start menu  c) The appearance of Windows, and the date and time  d) Dragging them into order — lined up and sorted so each is found at once
**Answer: d) Dragging them into order — lined up and sorted so each is found at once**

**5. (Sub lesson 1) Why keep the desktop arranged?**
a) So every program is found quickly instead of hunted for in a pile  b) The place where Windows gathers the settings for how the computer itself looks and behaves  c) As icons, one for each part of the machine  d) When the computer itself — not a document — needs to change
**Answer: a) So every program is found quickly instead of hunted for in a pile**

**6. (Sub lesson 2) What is the Control Panel?**
a) From the Start menu  b) The place where Windows gathers the settings for how the computer itself looks and behaves  c) The appearance of Windows, and the date and time  d) The working surface Windows shows when starting finishes, where everything begins
**Answer: b) The place where Windows gathers the settings for how the computer itself looks and behaves**

**7. (Sub lesson 2) How is the Control Panel opened?**
a) As icons, one for each part of the machine  b) When the computer itself — not a document — needs to change  c) From the Start menu  d) A small picture standing for a program, a file or a folder
**Answer: c) From the Start menu**

**8. (Sub lesson 2) How does the Control Panel show its settings?**
a) The appearance of Windows, and the date and time  b) The working surface Windows shows when starting finishes, where everything begins  c) With a double-click on its icon  d) As icons, one for each part of the machine
**Answer: d) As icons, one for each part of the machine**

**9. (Sub lesson 2) Name two things changed from the Control Panel in this book.**
a) The appearance of Windows, and the date and time  b) When the computer itself — not a document — needs to change  c) A small picture standing for a program, a file or a folder  d) Dragging them into order — lined up and sorted so each is found at once
**Answer: a) The appearance of Windows, and the date and time**

**10. (Sub lesson 2) When do you open the Control Panel?**
a) The working surface Windows shows when starting finishes, where everything begins  b) When the computer itself — not a document — needs to change  c) With a double-click on its icon  d) So every program is found quickly instead of hunted for in a pile
