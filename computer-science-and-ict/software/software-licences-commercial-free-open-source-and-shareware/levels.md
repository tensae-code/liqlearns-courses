# Software Licences — Commercial, Free, Open-Source and Shareware — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — The licence — permission, written in advance
Sub lesson 1 questions from the type files. Pass mark: The maker's written permission saying what a user may do with a program; Cost, copying/sharing, seeing and changing the code, and how long it may be used (any three); Piracy — whatever the copy cost; Software that is sold; its licence is bought and copying/sharing are forbidden; Software given at no cost, usable without payment on its maker's terms.

## Sub lesson 2 — The types — commercial, free, open-source, trial
Sub lesson 2 questions from the type files. Pass mark: Its source code is open to study and change, and changed versions may be shared under the licence; Software given to try for a limited time or with limits, after which the full licence must be bought; Commercial, trial, free, open-source (tightest to most open as taught); No — the licence, not the copy, fixes what you may do; Grade 12 IT, Chapter 3 — legal legislation and computer systems, in both sections' books.
