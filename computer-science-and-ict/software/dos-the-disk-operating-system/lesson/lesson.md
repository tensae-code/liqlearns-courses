# DOS — the Disk Operating System

## Do it first

Before Windows filled the screen with pictures, one system ran the personal computer from a bare prompt and typed commands: DOS. Laos's Grade 7 teacher guide — not the student book — gives DOS its own activity, the first of its expanded software syllabus. This lesson meets the system the guide teaches.

## Sub lesson 1 — What DOS is

**DOS — the Disk Operating System** — is an **operating system for personal computers** that works by **typed commands at a prompt**, with no pictures, windows or mouse. It is loaded from disk when the machine starts (that is its name's meaning), takes charge of the **files on the disks** — listing, copying, running, deleting — and starts the programs the user names. It is a **single-user, single-task** system: one person, one program at a time, and the whole of the machine given to that program.

## Sub lesson 2 — Why DOS is still taught

The guide teaches DOS beside Windows because DOS is the **root system of the personal computer**: the command prompt inside later Windows systems is DOS's descendant, its file and disk ideas (drives named by letters, files with names and extensions, directories as a tree) are the ideas Windows inherited, and its discipline — exact names, exact spelling, the machine doing exactly what was typed and nothing it was not — is the discipline all command work still demands. DOS and Unix are taught alongside Windows in the senior years' background for the same reason: the old systems explain the new one's shape.
