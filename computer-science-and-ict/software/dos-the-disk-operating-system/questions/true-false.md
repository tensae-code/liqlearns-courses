# DOS — the Disk Operating System — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Disk Operating System**
**Answer: True**

**2. (Sub lesson 1) True or false: It is loaded from disk at start-up and manages the files on the disks** — as the answer to: How does DOS take its orders?
**Answer: False — As typed commands at a prompt — no pictures, windows or mouse**

**3. (Sub lesson 1) True or false: It is loaded from disk at start-up and manages the files on the disks**
**Answer: True**

**4. (Sub lesson 1) True or false: Single-user, single-task — one person, one program at a time** — as the answer to: What does DOS take charge of?
**Answer: False — The files on the disks — listing, copying, running, deleting**

**5. (Sub lesson 1) True or false: Single-user, single-task — one person, one program at a time**
