# DOS — the Disk Operating System — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does DOS stand for?**
a) Disk Operating System  b) As typed commands at a prompt — no pictures, windows or mouse  c) It is loaded from disk at start-up and manages the files on the disks  d) The files on the disks — listing, copying, running, deleting
**Answer: a**

**Answer: b**

**3. (Sub lesson 1) Why is it called a disk operating system?**
