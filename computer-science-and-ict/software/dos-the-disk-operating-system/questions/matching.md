# DOS — the Disk Operating System — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What does DOS stand for?** → **Disk Operating System**

**2. (Sub lesson 1) How does DOS take its orders?** → **As typed commands at a prompt — no pictures, windows or mouse**

**3. (Sub lesson 1) Why is it called a disk operating system?** → **It is loaded from disk at start-up and manages the files on the disks**

**4. (Sub lesson 1) What does DOS take charge of?** → **The files on the disks — listing, copying, running, deleting**

**5. (Sub lesson 1) What kind of system is DOS, by users and tasks?** → **Single-user, single-task — one person, one program at a time**

**6. (Sub lesson 2) What inside later Windows is DOS's descendant?** → **The command prompt**

**7. (Sub lesson 2) Name two file ideas Windows inherited from DOS.** → **Drive letters, and file names with extensions in a directory tree**

**8. (Sub lesson 2) What discipline does command work demand?** → **Exact names and exact spelling — the machine does exactly what was typed**

**9. (Sub lesson 2) Which source teaches this lesson?** → **Laos Grade 7 ICT teacher guide, Activity 14 (teacher guide — evidence)**

**10. (Sub lesson 2) Where does DOS sit in the guide's syllabus?** → **First of its expanded software activities, before Windows/Linux and Unix/Mac**
