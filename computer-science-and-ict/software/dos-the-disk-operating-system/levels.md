# DOS — the Disk Operating System — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — What DOS is
Sub lesson 1 questions from the type files. Pass mark: Disk Operating System; As typed commands at a prompt — no pictures, windows or mouse; It is loaded from disk at start-up and manages the files on the disks; The files on the disks — listing, copying, running, deleting; Single-user, single-task — one person, one program at a time.

## Sub lesson 2 — Why DOS is still taught
Sub lesson 2 questions from the type files. Pass mark: The command prompt; Drive letters, and file names with extensions in a directory tree; Exact names and exact spelling — the machine does exactly what was typed; Laos Grade 7 ICT teacher guide, Activity 14 (teacher guide — evidence); First of its expanded software activities, before Windows/Linux and Unix/Mac.
