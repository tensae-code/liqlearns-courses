# Installing utility software — anti-virus

## Do it first

An anti-virus program protects a computer only when it is ON the computer. A laboratory machine with no anti-virus installed is unprotected, however good the program is. So the skill is the installing itself. Here it is, in the order it is done.

## The four steps, in order

1. **Search and download.** Search for Avast anti-virus on the internet and download the **.exe file**.
2. **Double-click the file.** Double-click the .exe — it is usually found in the **Downloads folder**.
3. **Run.** In the dialog box that appears, follow the instructions, clicking **Run** to start the install.
4. **Wait.** Wait a few minutes while it installs.

Do the steps in this order and in no other: there is nothing to double-click before the download, and nothing installs before Run is clicked.
