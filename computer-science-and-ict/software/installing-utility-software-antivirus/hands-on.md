# Hands-on — Installing utility software — anti-virus

The lesson with your hands, not only your eyes.

## Walk the steps on paper

Write the four steps on four cards. Shuffle them, then lay them back in order: download — double-click — Run — wait. A partner checks your order against the lesson.

## Laboratory install

In the laboratory, install the anti-virus on a machine that does not have it, following the four steps exactly. A teacher or partner watches the doing and ticks each step as it is done — this install is assessed by watching, not by a written key.
