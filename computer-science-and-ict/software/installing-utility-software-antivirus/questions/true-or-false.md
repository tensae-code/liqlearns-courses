# Installing utility software — anti-virus — true or false

Say whether each sentence is true or false.

**1.** You can double-click the .exe before it has downloaded.
**Answer: False** — the download comes first; the file must exist before it can be opened.

**2.** Installing anti-virus in the laboratory is a task pupils are assessed on by doing it.
**Answer: True** — it is the unit's standing practical assessment task.
