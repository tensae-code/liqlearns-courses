# Installing utility software — anti-virus — multiple choice

Pick the one right answer.

**1.** The first step in installing Avast anti-virus is —
a) click Run  b) search for it on the internet and download the .exe file  c) double-click in Downloads  d) wait a few minutes
**Answer: b) search for it on the internet and download the .exe file** — nothing can be clicked before the file exists.

**2.** The downloaded .exe is usually found in —
a) the Recycle Bin  b) the Downloads folder  c) Documents  d) the printer
**Answer: b) the Downloads folder.**

**3.** In the dialog box, you click — to start the install.
a) Run  b) Delete  c) Print  d) Close
**Answer: a) Run.**

**4.** The last step is —
a) download again  b) restart the search  c) wait a few minutes while it installs  d) close the dialog at once
**Answer: c) wait a few minutes while it installs.**
