# Lesson plan — Installing utility software — anti-virus

**Course:** Computer Science and ICT · **Title:** Software · **Lesson:** Installing utility software — anti-virus
**Place in the curriculum:** Title 3 — Software in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 8 book, Unit 3 — Computer Software. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** installing an anti-virus program follows four steps in order: download the .exe file, double-click it, click Run and follow the dialog, then wait while it installs.
**This lesson's own level:** it stands on the utility-software lesson — anti-virus is a system utility, and this lesson is the doing of putting one on a computer.

## What the learner can do when it ends
1. Download the anti-virus .exe file from the internet.
2. Find the .exe in the Downloads folder and double-click it.
3. Click Run in the dialog box and follow its instructions.
4. Wait while the program installs, and say why a laboratory computer needs anti-virus installed.

## What you need
A computer connected to the internet — this lesson is learned by doing it, in a laboratory if one is available.

## If the learner is stuck
- Double-clicks before the download finishes → the .exe must be fully downloaded first; step order is the skill.
- Hunts for the .exe all over the computer → it is usually found in the Downloads folder.
- Closes the dialog during the wait → installing takes a few minutes; wait for it to finish.
