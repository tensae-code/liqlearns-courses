# Adding a Keyboard Language — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What sets the letters a key produces?**
a) The keyboard language Windows is using  b) Yes — several at once, and you switch between them  c) Dari  d) Because adding Dari makes the computer usable in the country's own language
**Answer: a) The keyboard language Windows is using**

**2. (Sub lesson 1) Can a computer hold more than one keyboard language?**
a) Dari  b) Yes — several at once, and you switch between them  c) Because adding Dari makes the computer usable in the country's own language  d) Regional and Language Options in the Control Panel
**Answer: b) Yes — several at once, and you switch between them**

**3. (Sub lesson 1) Which language does Afghanistan's book add?**
a) Because adding Dari makes the computer usable in the country's own language  b) Regional and Language Options in the Control Panel  c) Dari  d) The language and its keyboard layout, then confirm
**Answer: c) Dari**

**4. (Sub lesson 1) Why is this taught as its own lesson in Afghanistan?**
a) Regional and Language Options in the Control Panel  b) The language and its keyboard layout, then confirm  c) The language bar  d) Because adding Dari makes the computer usable in the country's own language
**Answer: d) Because adding Dari makes the computer usable in the country's own language**

**5. (Sub lesson 1) Through which settings is a language added in the book's Windows XP?**
a) Regional and Language Options in the Control Panel  b) The language and its keyboard layout, then confirm  c) The language bar  d) By clicking the language bar or with its key combination, Alt+Shift in the book's Windows
**Answer: a) Regional and Language Options in the Control Panel**

**6. (Sub lesson 2) What do you choose when you add a language?**
a) The language bar  b) The language and its keyboard layout, then confirm  c) By clicking the language bar or with its key combination, Alt+Shift in the book's Windows  d) The language bar — the active language, not the letters printed on the keys
**Answer: b) The language and its keyboard layout, then confirm**

**7. (Sub lesson 2) What shows the active language on the taskbar?**
a) By clicking the language bar or with its key combination, Alt+Shift in the book's Windows  b) The language bar — the active language, not the letters printed on the keys  c) The language bar  d) The program follows the language that is active
**Answer: c) The language bar**

**8. (Sub lesson 2) How do you switch between your languages?**
a) The language bar — the active language, not the letters printed on the keys  b) The program follows the language that is active  c) The keyboard language Windows is using  d) By clicking the language bar or with its key combination, Alt+Shift in the book's Windows
**Answer: d) By clicking the language bar or with its key combination, Alt+Shift in the book's Windows**

**9. (Sub lesson 2) What should you check before you type?**
a) The language bar — the active language, not the letters printed on the keys  b) The program follows the language that is active  c) The keyboard language Windows is using  d) Yes — several at once, and you switch between them
**Answer: a) The language bar — the active language, not the letters printed on the keys**

**10. (Sub lesson 2) What follows the active language — the program or the keys?**
a) The keyboard language Windows is using  b) The program follows the language that is active  c) Yes — several at once, and you switch between them  d) Dari
