# Adding a Keyboard Language — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What sets the letters a key produces?" is: The keyboard language Windows is using**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Can a computer hold more than one keyboard language?" is: Dari**
**Answer: False** — Yes — several at once, and you switch between them

**3. (Sub lesson 1) True or false: the answer to "Which language does Afghanistan's book add?" is: Dari**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Why is this taught as its own lesson in Afghanistan?" is: Regional and Language Options in the Control Panel**
**Answer: False** — Because adding Dari makes the computer usable in the country's own language

**5. (Sub lesson 1) True or false: the answer to "Through which settings is a language added in the book's Windows XP?" is: Regional and Language Options in the Control Panel**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What do you choose when you add a language?" is: The language bar**
**Answer: False** — The language and its keyboard layout, then confirm

**7. (Sub lesson 2) True or false: the answer to "What shows the active language on the taskbar?" is: The language bar**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How do you switch between your languages?" is: The language bar — the active language, not the letters printed on the keys**
**Answer: False** — By clicking the language bar or with its key combination, Alt+Shift in the book's Windows

**9. (Sub lesson 2) True or false: the answer to "What should you check before you type?" is: The language bar — the active language, not the letters printed on the keys**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What follows the active language — the program or the keys?" is: The keyboard language Windows is using**
**Answer: False** — The program follows the language that is active
