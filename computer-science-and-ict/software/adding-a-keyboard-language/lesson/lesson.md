# Adding a Keyboard Language

## Do it first

Your keyboard has English letters printed on it — yet with one setting it can type Dari. In this lesson you learn how a keyboard language is added, and how you switch to it.

## Sub lesson 1 — What a keyboard language is

The letters a key produces are not fixed by the plastic: they are set by the **keyboard language** (input language) Windows is using. With English active, a key gives its English letter; switch the language and the same keys give that language's letters, in its own layout. A computer can hold several keyboard languages at once. Afghanistan's Grade 10 book teaches this as its own lesson because it is the step that makes the computer usable in the country's own language: adding **Dari** lets the learner type Dari text in any program.

[Picture — the language settings window with Dari being added to the list of keyboard languages]

## Sub lesson 2 — Adding Dari — and switching to it

The language is added through the language settings (in the book's Windows XP, through Regional and Language Options in the Control Panel): open the settings, choose **Add**, pick the language — Dari — and its keyboard layout, and confirm. From then on the **language bar** on the taskbar shows the active language, and you switch between your languages by clicking it or with its key combination (in the book's Windows, **Alt+Shift**). The rule to remember: look at the language bar before you type — the program follows the language that is active, not the letters printed on the keys.

[Picture — the language bar on the taskbar showing two languages, English and Dari, ready to switch]

Tell your companion, in your own words: A keyboard language can be added to Windows so the same keyboard types another language's letters: Afghanistan's books add Dari this way, and the language bar then switches between the languages as you type.
