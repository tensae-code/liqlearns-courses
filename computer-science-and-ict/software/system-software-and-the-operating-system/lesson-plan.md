# Lesson plan — System software and the operating system

**Course:** Computer Science and ICT · **Title:** Software · **Lesson:** System software and the operating system
**Place in the curriculum:** Title 3 — Software in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 7 book, Unit 3 — Computer Software. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** system software controls and manages the hardware, and the operating system is its most important program.
**This lesson's own level:** it stands on the lesson before it — software has two types; this lesson takes the first type.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **System software — the manager** — what system software does: controls, integrates and manages the hardware, and lets user, hardware and applications work together
2. **The operating system** — the most important program: it loads programs at start, supervises input and output, and manages files; Windows in Ethiopia
3. **The operating system in greater depth** — the Grade 8 depth: it communicates with the hardware and allows other programs to run; its five basic tasks (file, memory and process management, handling input and output, controlling peripheral devices) and common services; applications require an OS; the names Windows, Mac OS, Ubuntu, Unix and Linux

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Computer software — instructions that make hardware work.  Recommended, never forced.

## What the learner can do when it ends
1. Say what system software does, and what it does not do.
2. Name the operating system as the most important program.
3. List the operating system's jobs: loading programs, supervising input/output, managing files.
4. Name Microsoft Windows as the operating system most used in Ethiopia.
5. Name the operating system's five basic tasks and the five operating-system names: Windows, Mac OS, Ubuntu, Unix and Linux.

## What you need
A computer running Windows if you can use one; paper and a pencil.

## If the learner is stuck
- Thinks the operating system writes documents → no: it loads the program that writes; the writing program is application software.
- Thinks system software does nothing because it is invisible → watch a start-up: everything before the desktop is its work.
