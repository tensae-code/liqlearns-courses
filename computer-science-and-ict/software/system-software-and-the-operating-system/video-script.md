# Video script — System software and the operating system

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

System software runs the computer.
It controls the hardware. It manages the parts.
It does not do your job. It makes your job possible.

The biggest program is the operating system.
It loads your programs. It watches input and output. It manages files.

In Ethiopia, the name you will see most is Windows.
