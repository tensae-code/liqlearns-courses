# System software and the operating system — fill in the blank

Fill each blank with the right word.

**1. (Sub lesson 1)** System software ______ and manages the hardware components.
**Answer: controls**

**2. (Sub lesson 2)** The ______ system loads programs when the computer starts.
**Answer: operating**

**3. (Sub lesson 2)** The operating system supervises input and ______ and manages files.
**Answer: output**
