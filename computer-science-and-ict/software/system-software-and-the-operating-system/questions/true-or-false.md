# System software and the operating system — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** System software runs in the background while you work.
**Answer: True** — it manages the machine while applications do the jobs.

**2. (Sub lesson 2)** The operating system manages files.
**Answer: True** — one of its three named jobs.

**3. (Sub lesson 2)** Microsoft Windows is an application for writing letters.
**Answer: False** — Windows is the operating system — system software.

**4. (Sub lesson 3)** Applications can work without an operating system.
**Answer: False** — applications require an operating system to work.
