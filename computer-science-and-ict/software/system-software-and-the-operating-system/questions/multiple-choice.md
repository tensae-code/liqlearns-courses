# System software and the operating system — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** System software —
a) writes your letters  b) controls, integrates and manages the hardware  c) is a game  d) prints documents
**Answer: b) controls, integrates and manages the hardware** — it manages the machine and lets user, hardware and applications work together.

**2. (Sub lesson 1)** Does system software do the user's specific tasks?
a) Yes, all of them  b) No — it runs the machine so the tasks can happen  c) Only letters  d) Only sums
**Answer: b) No — it runs the machine so the tasks can happen** — it does not do the user's specific tasks.

**3. (Sub lesson 2)** The most important program in system software is —
a) the game  b) the operating system  c) the word processor  d) the picture program
**Answer: b) the operating system** — the operating system.

**4. (Sub lesson 2)** Which is NOT a job of the operating system?
a) Loading programs at start  b) Supervising input and output  c) Writing your essay for you  d) Managing files
**Answer: c) Writing your essay for you** — the operating system manages; it does not write your essay.

**5. (Sub lesson 2)** The operating system most commonly used in Ethiopia is —
a) Microsoft Windows  b) Linux only  c) Mac only  d) LOGO
**Answer: a) Microsoft Windows** — the book names Microsoft Windows.

**6. (Sub lesson 1)** System software lets which three work together?
a) User, hardware and applications  b) Pen, paper and ink  c) Teacher, pupil and book  d) Screen, chair and desk
**Answer: a) User, hardware and applications** — user, hardware and applications.

**7. (Sub lesson 3)** The operating system's basic tasks are —
a) file, memory and process management, handling input and output, and controlling peripheral devices  b) typing, printing, drawing, saving, closing  c) copy, cut, paste, delete, rename  d) reading, writing, counting, singing, playing
**Answer: a) file, memory and process management, handling input and output, and controlling peripheral devices.**

**8. (Sub lesson 3)** Which list names operating systems?
a) Word, Excel, Access, PowerPoint, Paint  b) Windows, Mac OS, Ubuntu, Unix, Linux  c) Printer, mouse, keyboard, screen, disk  d) Copy, Paste, Cut, Save, Print
**Answer: b) Windows, Mac OS, Ubuntu, Unix, Linux.**
