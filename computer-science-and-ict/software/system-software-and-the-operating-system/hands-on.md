# Hands-on — System software and the operating system

The lesson with your hands, not only your eyes.

## Watch a start-up
Watch a computer start. Write down everything that happens on screen before anyone touches the keyboard or mouse. Every line on your list is the operating system at work.

## Manager for a day
In a group of three, one person is the manager: the other two may only pass things through the manager, never directly. Notice how the manager makes the work possible without doing the task itself — that is system software.

## The manager's five tasks

Watch a computer in use for ten minutes: a file opened, a program started, a page printed. Write each thing you saw under one of the five basic tasks — file management, memory management, process management, handling input and output, controlling peripheral devices. Every observed moment belongs to the manager.
