# System software and the operating system

## Do it first

Press the power button. A moment later you are ready to write. Who did all the work in between — loading, checking, preparing? Not you. A program did it, quietly, before you touched anything. That program is this lesson's subject.

## Sub lesson 1 — System software — the manager

System software controls, integrates and manages the hardware components of the computer. It lets the user, the hardware and the application programs all work together. It does not do your specific tasks — it does not write your letter or add your numbers. It runs the machine so those jobs can happen.

## Sub lesson 2 — The operating system

The operating system is the most important program in system software. It loads programs when the computer starts, it supervises input and output, and it manages files. The most commonly used operating system in Ethiopia, the book names, is **Microsoft Windows**.
