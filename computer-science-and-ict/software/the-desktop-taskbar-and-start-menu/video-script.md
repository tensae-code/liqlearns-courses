# Video script — The Desktop, Taskbar and Start Menu

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

The **desktop** is the first screen after Windows starts. On it stand **icons** — small pictures with names — each one a door: double-click an icon to open its program or file. The Grade 4 guide adds the tools around the desktop: **Windows Search** finds programs and files by name, a built-in program such as the **Calculator** opens from the Start menu, and **Get Help** answers questions about Windows itself. (teacher guide — evidence; PARTIAL — Term 1 only)
The **taskbar** is the bar along the bottom of the desktop. At its start sits the **Start button**; along it sit a button for every **open program**, so you can jump between programs; at its end sit the **clock**, the **date** and the **language** indicator. Clicking Start opens the **Start menu** — the list from which programs are opened and the computer is shut down.
