# The Desktop, Taskbar and Start Menu

## Do it first

Switch a computer on and wait. The screen you land on — the desktop — is your worktable. In this lesson you learn its parts: the icons on it, the taskbar under it, and the Start menu behind the Start button.

## Sub lesson 1 — The desktop and its icons

The **desktop** is the first screen after Windows starts. On it stand **icons** — small pictures with names — each one a door: double-click an icon to open its program or file. The Grade 4 guide adds the tools around the desktop: **Windows Search** finds programs and files by name, a built-in program such as the **Calculator** opens from the Start menu, and **Get Help** answers questions about Windows itself. ## Sub lesson 2 — The taskbar and the Start menu

The **taskbar** is the bar along the bottom of the desktop. At its start sits the **Start button**; along it sit a button for every **open program**, so you can jump between programs; at its end sit the **clock**, the **date** and the **language** indicator. Clicking Start opens the **Start menu** — the list from which programs are opened and the computer is shut down.

## Say it to your companion

Tell your companion, in your own words: When Windows starts, you land on the desktop: its icons are the doors to programs and files, the taskbar along the bottom holds the Start button, the clock, the date, the language and a button for every open program, and the Start menu is where programs are opened from. Then let your companion ask you one question about it — and answer from the lesson, not from memory of the book's exact words.
