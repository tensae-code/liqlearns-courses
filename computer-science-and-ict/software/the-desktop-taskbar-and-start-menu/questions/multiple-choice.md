# The Desktop, Taskbar and Start Menu — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is the first screen after Windows starts?**
a) The desktop  b) Finds programs and files by name  c) Along the bottom of the desktop  d) A button for it, so you can jump between programs
**Answer: a) The desktop**

**2. (Sub lesson 1) What is an icon?**
a) The Calculator  b) A small picture with a name — a door to a program or file  c) The Start button  d) The clock, the date and the language indicator
**Answer: b) A small picture with a name — a door to a program or file**

**3. (Sub lesson 1) How do you open a program from its desktop icon?**
a) Along the bottom of the desktop  b) A button for it, so you can jump between programs  c) Double-click the icon  d) The Start menu — programs are opened from it, and the computer is shut down from it
**Answer: c) Double-click the icon**

**4. (Sub lesson 1) What does Windows Search do?**
a) The Start button  b) The clock, the date and the language indicator  c) The desktop  d) Finds programs and files by name
**Answer: d) Finds programs and files by name**

**5. (Sub lesson 1) Name a built-in program the guide opens from the Start menu.**
a) The Calculator  b) A button for it, so you can jump between programs  c) The Start menu — programs are opened from it, and the computer is shut down from it  d) A small picture with a name — a door to a program or file
**Answer: a) The Calculator**

**6. (Sub lesson 2) Where is the taskbar?**
a) The clock, the date and the language indicator  b) Along the bottom of the desktop  c) The desktop  d) Double-click the icon
**Answer: b) Along the bottom of the desktop**

**7. (Sub lesson 2) What sits at the start of the taskbar?**
a) The Start menu — programs are opened from it, and the computer is shut down from it  b) A small picture with a name — a door to a program or file  c) The Start button  d) Finds programs and files by name
**Answer: c) The Start button**

**8. (Sub lesson 2) What does the taskbar show for every open program?**
a) The desktop  b) Double-click the icon  c) The Calculator  d) A button for it, so you can jump between programs
**Answer: d) A button for it, so you can jump between programs**

**9. (Sub lesson 2) What three things sit at the end of the taskbar?**
a) The clock, the date and the language indicator  b) A small picture with a name — a door to a program or file  c) Finds programs and files by name  d) Along the bottom of the desktop
**Answer: a) The clock, the date and the language indicator**

**10. (Sub lesson 2) What opens when you click Start?**
a) Double-click the icon  b) The Start menu — programs are opened from it, and the computer is shut down from it  c) The Calculator  d) The Start button
**Answer: b) The Start menu — programs are opened from it, and the computer is shut down from it**
