# The Desktop, Taskbar and Start Menu — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is the first screen after Windows starts?" is: The desktop**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is an icon?" is: Double-click the icon**
**Answer: False** — A small picture with a name — a door to a program or file

**3. (Sub lesson 1) True or false: the answer to "How do you open a program from its desktop icon?" is: Double-click the icon**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does Windows Search do?" is: The Calculator**
**Answer: False** — Finds programs and files by name

**5. (Sub lesson 1) True or false: the answer to "Name a built-in program the guide opens from the Start menu." is: The Calculator**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Where is the taskbar?" is: The Start button**
**Answer: False** — Along the bottom of the desktop

**7. (Sub lesson 2) True or false: the answer to "What sits at the start of the taskbar?" is: The Start button**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does the taskbar show for every open program?" is: The clock, the date and the language indicator**
**Answer: False** — A button for it, so you can jump between programs

**9. (Sub lesson 2) True or false: the answer to "What three things sit at the end of the taskbar?" is: The clock, the date and the language indicator**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What opens when you click Start?" is: The desktop**
**Answer: False** — The Start menu — programs are opened from it, and the computer is shut down from it
