# What an Interface Is — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is an interface?**
a) The whole meeting place between a user and a system  b) Windows and menus (or screen, messages)  c) Type and choose (or press)  d) Every action, at once
**Answer: a) The whole meeting place between a user and a system**

**2. (Sub lesson 1) Name two things the system shows.**
a) Type and choose (or press)  b) Windows and menus (or screen, messages)  c) Every action, at once  d) A car's dashboard
**Answer: b) Windows and menus (or screen, messages)**

**3. (Sub lesson 1) Name two things the user may do.**
a) Every action, at once  b) A car's dashboard  c) Type and choose (or press)  d) Typed orders, answered in text
**Answer: c) Type and choose (or press)**

**4. (Sub lesson 1) What does a good interface answer?**
a) A car's dashboard  b) Typed orders, answered in text  c) Windows, icons and menus  d) Every action, at once
**Answer: d) Every action, at once**

**5. (Sub lesson 1) Give a non-computer interface.**
a) A car's dashboard  b) Typed orders, answered in text  c) Windows, icons and menus  d) A mouse
**Answer: a) A car's dashboard**

**6. (Sub lesson 2) What does a command interface take?**
a) Windows, icons and menus  b) Typed orders, answered in text  c) A mouse  d) Software, interface, then the operating system
**Answer: b) Typed orders, answered in text**

**7. (Sub lesson 2) What does a graphical interface show?**
a) A mouse  b) Software, interface, then the operating system  c) Windows, icons and menus  d) Through its interface
**Answer: c) Windows, icons and menus**

**8. (Sub lesson 2) What works a graphical interface?**
a) Software, interface, then the operating system  b) Through its interface  c) The whole meeting place between a user and a system  d) A mouse
**Answer: d) A mouse**

**9. (Sub lesson 2) What is the chapter's order?**
a) Software, interface, then the operating system  b) Through its interface  c) The whole meeting place between a user and a system  d) Windows and menus (or screen, messages)
**Answer: a) Software, interface, then the operating system**

**10. (Sub lesson 2) How is an operating system mostly met?**
a) The whole meeting place between a user and a system  b) Through its interface  c) Windows and menus (or screen, messages)  d) Type and choose (or press)
**Answer: b) Through its interface**
