# What an Interface Is — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is an interface?" is: The whole meeting place between a user and a system**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Name two things the system shows." is: Type and choose (or press)**
**Answer: False** — Windows and menus (or screen, messages)

**3. (Sub lesson 1) True or false: the answer to "Name two things the user may do." is: Type and choose (or press)**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does a good interface answer?" is: A car's dashboard**
**Answer: False** — Every action, at once

**5. (Sub lesson 1) True or false: the answer to "Give a non-computer interface." is: A car's dashboard**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does a command interface take?" is: Windows, icons and menus**
**Answer: False** — Typed orders, answered in text

**7. (Sub lesson 2) True or false: the answer to "What does a graphical interface show?" is: Windows, icons and menus**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What works a graphical interface?" is: Software, interface, then the operating system**
**Answer: False** — A mouse

**9. (Sub lesson 2) True or false: the answer to "What is the chapter's order?" is: Software, interface, then the operating system**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "How is an operating system mostly met?" is: The whole meeting place between a user and a system**
**Answer: False** — Through its interface
