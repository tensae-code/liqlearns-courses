## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The meeting place of user and machine** — An **interface** is the whole meeting place between a user and a system: what the system shows — screen, windows, menus, messages — and what the user may do — type, choose, press. A good interface shows what can be done and answers every action at once. The word is wider than computers: a car's dashboard is an interface too, but in this course it is the computer's face that matters.
2. **Command and graphical interfaces** — Interfaces come in kinds: a **command interface** takes typed orders and answers in text; a **graphical interface** shows windows, icons and menus worked with a mouse. The Grade 8 chapter walks this road in order — software, interface, then the operating system itself — because an operating system is mostly met *through* its interface, and the pupil should know the face before the system behind it.
