## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Free software and the GPL — freedom with a guard** — **Free software** is software the user may run, study, share and improve — the freedom is in the rights, not the price. Its guard is the **GPL** (General Public License): a licence that grants those freedoms and defends them, requiring that shared and improved versions keep the same freedoms — freedom that cannot be quietly taken away downstream. **Open-source** names the same world by its visible side: the source code stands open for any programmer to read and better.
2. **The free programs — and Soyombo, Mongolia's own** — The world the licence built is standing software, not theory: **Linux**, the free operating system; **OpenOffice**, the free office suite — in Mongolia, **Mongolian OpenOffice**; **GIMP** for images, **Inkscape** for drawing, **Blender** for 3D. Mongolia's own flag in this world is **Soyombo Linux** — a Mongolian Linux distribution, named for the Soyombo symbol, made so the free system speaks Mongolia's language and serves Mongolia's users. The lesson's pride is the point: open source is not only received by Mongolia; Mongolia builds in it.
