# Free and Open-Source Software — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What freedoms does free software grant?" is: To run, study, share and improve the software**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Is 'free' about the price?" is: The General Public License — granting the freedoms and requiring shared versions to keep them**
**Answer: False** — No — about the rights

**3. (Sub lesson 1) True or false: the answer to "What is the GPL?" is: The General Public License — granting the freedoms and requiring shared versions to keep them**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does open-source name the world by?" is: Linux, OpenOffice, GIMP, Inkscape (any four of: Blender)**
**Answer: False** — Its visible side — the source code standing open

**5. (Sub lesson 1) True or false: the answer to "Name four great free programs from the lesson." is: Linux, OpenOffice, GIMP, Inkscape (any four of: Blender)**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is Soyombo Linux?" is: So the free system speaks Mongolia's language and serves Mongolia's users**
**Answer: False** — Mongolia's own Linux distribution, named for the Soyombo symbol

**7. (Sub lesson 2) True or false: the answer to "Why was Soyombo made?" is: So the free system speaks Mongolia's language and serves Mongolia's users**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Which office suite has a Mongolian edition in the book?" is: The freedoms cannot be quietly taken away**
**Answer: False** — OpenOffice — Mongolian OpenOffice

**9. (Sub lesson 2) True or false: the answer to "What cannot be done downstream under the GPL?" is: The freedoms cannot be quietly taken away**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is the lesson's closing claim?" is: To run, study, share and improve the software**
**Answer: False** — Open source is not only received by Mongolia; Mongolia builds in it
