# Free and Open-Source Software — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What freedoms does free software grant?**
a) To run, study, share and improve the software  b) No — about the rights  c) The General Public License — granting the freedoms and requiring shared versions to keep them  d) Its visible side — the source code standing open
**Answer: a) To run, study, share and improve the software**

**2. (Sub lesson 1) Is 'free' about the price?**
