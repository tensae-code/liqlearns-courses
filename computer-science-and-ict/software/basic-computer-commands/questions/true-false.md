# Basic Computer Commands — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Select the thing first — click it or drag across it so the program knows what you mean**
**Answer: True**

**2. (Sub lesson 1) True or false: Select the thing first — click it or drag across it so the program knows what you mean** — as the answer to: What is the difference between cut and copy?
**Answer: False — Copy leaves the original and puts a copy on the clipboard; cut removes the original and puts it on the clipboard**

**3. (Sub lesson 1) True or false: It puts the clipboard's content in at the place you choose**
**Answer: True**

**4. (Sub lesson 1) True or false: It puts the clipboard's content in at the place you choose** — as the answer to: What is the clipboard?
**Answer: False — The computer's temporary holding place for the last thing cut or copied**

**5. (Sub lesson 1) True or false: It moves — the thing leaves its old place and appears in the new one**
**Answer: True**

**6. (Sub lesson 2) True or false: It moves — the thing leaves its old place and appears in the new one** — as the answer to: What does undo do?
**Answer: False — It takes back the last action — and pressed again, the one before that**

**7. (Sub lesson 2) True or false: It does again an action that was undone**
**Answer: True**

**8. (Sub lesson 2) True or false: It does again an action that was undone** — as the answer to: Why do undo and redo matter for a learner?
**Answer: False — They make trying safe — you can try, look, and step back instead of starting over**

**9. (Sub lesson 2) True or false: Ctrl+Z**
**Answer: True**

**10. (Sub lesson 2) True or false: Ctrl+Z** — as the answer to: What is the usual keyboard shortcut for redo?
**Answer: False — Ctrl+Y (in many programs Ctrl+Shift+Z)**
