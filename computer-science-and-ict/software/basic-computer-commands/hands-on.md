# Hands-on — Basic Computer Commands

The lesson with your hands and your feet, not only your eyes.

## Task one
**Move and duplicate** — In any editor, write three short lines. Select the middle line and copy-paste it at the end (duplicate), then cut-paste the first line after it (move). Say which command did which.

## Task two
**Undo chain** — Make five small changes to a document, then undo them one by one, naming each action as it disappears. Redo two of them.
