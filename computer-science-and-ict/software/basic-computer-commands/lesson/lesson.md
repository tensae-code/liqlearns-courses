# Basic Computer Commands

## Do it first

Before you can make anything on a computer, you need six small orders that work in almost every program. This lesson learns them on purpose, one by one.

## Sub lesson 1 — Select, cut, copy and paste — moving pieces of work

To work on something you first **select** it: click it, or drag across it, so the program knows what you mean. **Copy** puts a copy of the selected thing on the clipboard (the original stays); **cut** puts it on the clipboard and removes the original. **Paste** puts the clipboard's content in at the place you choose. Cut-paste moves; copy-paste duplicates. Armenia's Grade 2 book teaches these as the 'important commands' — the first commands a child is trusted with, because they work the same in a text editor, a picture editor and a file window.

## Sub lesson 2 — Undo and redo — the commands that forgive

**Undo** takes back the last action; pressed again, it takes back the one before. **Redo** does again an action that was undone. Together they make experimenting safe: a learner can try, look, and step back instead of starting over. The keyboard forms — Ctrl+Z for undo, Ctrl+Y (or Ctrl+Shift+Z) for redo — are among the first shortcuts worth memorising, and Armenia's Grade 2 teacher guide builds its very first sample lesson plan around these commands.
