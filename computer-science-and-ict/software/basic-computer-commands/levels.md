# Basic Computer Commands — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Select, cut, copy and paste — moving pieces of work
Sub lesson 1 questions from the type files. Pass mark: Select the thing first — click it or drag across it so the program knows what you mean; Copy leaves the original and puts a copy on the clipboard; cut removes the original and puts it on the clipboard; It puts the clipboard's content in at the place you choose; The computer's temporary holding place for the last thing cut or copied; It moves — the thing leaves its old place and appears in the new one.

## Sub lesson 2 — Undo and redo — the commands that forgive
Sub lesson 2 questions from the type files. Pass mark: It takes back the last action — and pressed again, the one before that; It does again an action that was undone; They make trying safe — you can try, look, and step back instead of starting over; Ctrl+Z; Ctrl+Y (in many programs Ctrl+Shift+Z).
