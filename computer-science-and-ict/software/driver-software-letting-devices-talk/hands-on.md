# Hands-on — Driver software — letting devices talk to the operating system

The lesson with your hands, not only your eyes.

## Trace the conversation

On paper, draw three boxes: COMPUTER — DRIVER — PRINTER. Draw an arrow from the computer to the printer labelled "the page to print", and an arrow back labelled "ready / printing / done". Say each arrow's job out loud as you draw it.

## Device census

List every peripheral attached to a computer you can see — printer, mouse, keyboard, flash drive. Beside each, write: "needs a driver to talk to the operating system". Then mark which ones connect with a cable and which connect without one.
