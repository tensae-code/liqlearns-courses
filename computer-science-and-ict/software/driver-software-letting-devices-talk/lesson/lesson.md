# Driver software — letting devices talk to the operating system

## Do it first

Think of the last device you attached to a computer — a printer, perhaps. The computer did not know that printer before. Yet a moment later it could send a page to it and the printer could answer back. What made them understand each other? This lesson names it.

## What a driver is

A **driver** is software that **controls hardware devices** — the microprocessor, memory, the hard drive and the peripherals. It lets them **send and receive information**, so that peripheral devices can **communicate with the operating system**. Without the driver, the device and the operating system have no way to talk.

## The printer driver

The clearest example is the **printer driver**. It connects a printer to the operating system. When you print, your words travel from the computer, through the driver, to the printer — and the printer's answers travel back the same way. The driver stands in the middle, in charge of the conversation.

## Without wires

Modern computers also connect to peripherals **without physical connections**, using **wireless and Bluetooth technology**. The driver is still needed — the conversation still has to be controlled — but no cable carries it.
