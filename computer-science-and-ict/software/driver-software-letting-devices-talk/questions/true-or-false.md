# Driver software — letting devices talk to the operating system — true or false

Say whether each sentence is true or false.

**1.** A driver is a piece of hardware you can touch.
**Answer: False** — a driver is software that controls hardware.

**2.** Peripheral devices communicate with the operating system through their drivers.
**Answer: True** — that is the driver's job.

**3.** A device connected by Bluetooth needs no driver.
**Answer: False** — wireless changes how the talk travels, not who controls it.
