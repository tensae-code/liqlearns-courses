# Driver software — letting devices talk to the operating system — fill in the blank

Fill each blank with the right word.

**1.** A ______ is software that controls hardware devices.
**Answer: driver**

**2.** The ______ driver connects a printer to the operating system.
**Answer: printer**

**3.** Computers connect to peripherals without cables using wireless and ______ technology.
**Answer: Bluetooth**
