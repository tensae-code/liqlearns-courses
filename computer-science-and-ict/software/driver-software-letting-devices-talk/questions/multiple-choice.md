# Driver software — letting devices talk to the operating system — multiple choice

Pick the one right answer.

**1.** A driver is —
a) a cable  b) software that controls hardware devices  c) a kind of printer  d) a storage disk
**Answer: b) software that controls hardware devices** — a driver is software, not a thing you can touch.

**2.** A driver lets devices —
a) send and receive information  b) print by themselves  c) store electricity  d) replace the operating system
**Answer: a) send and receive information** — so peripherals can communicate with the operating system.

**3.** The book's example of a driver connecting a device to the operating system is —
a) the mouse driver  b) the printer driver  c) the keyboard driver  d) the screen driver
**Answer: b) the printer driver** — it connects a printer to the OS.

**4.** Which of these does a driver control?
a) Only printers  b) Only the screen  c) Microprocessor, memory, hard drive and peripherals  d) Only games
**Answer: c) Microprocessor, memory, hard drive and peripherals** — the book's own list.

**5.** Modern computers connect to peripherals without physical connections using —
a) paper and ink  b) wireless and Bluetooth technology  c) longer cables  d) the printer driver alone
**Answer: b) wireless and Bluetooth technology.**
