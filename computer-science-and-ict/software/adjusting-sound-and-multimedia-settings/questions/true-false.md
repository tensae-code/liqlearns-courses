# Adjusting Sound and Multimedia Settings — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What are sound's two directions on a computer?" is: Output — what you hear; input — what a microphone records**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Where do most sound troubles live?" is: Because adjusting media settings is a system skill — running the machine, not only using its programs**
**Answer: False** — In the settings — volume down, muted, wrong device, wrong socket — not in broken hardware

**3. (Sub lesson 1) True or false: the answer to "Why does the book teach this in the operating-system chapter?" is: Because adjusting media settings is a system skill — running the machine, not only using its programs**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What sits between output and input?" is: The taskbar's speaker icon or the Control Panel**
**Answer: False** — The volume control

**5. (Sub lesson 1) True or false: the answer to "Where is the Volume Control opened from?" is: The taskbar's speaker icon or the Control Panel**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What do its sliders set?" is: The master volume — after checking Mute is off**
**Answer: False** — The master volume and the level of each source

**7. (Sub lesson 2) True or false: the answer to "What is the first slider to raise?" is: The master volume — after checking Mute is off**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What device choices do the fuller settings hold?" is: Plug, power, mute, volume, device**
**Answer: False** — The playback and recording devices

**9. (Sub lesson 2) True or false: the answer to "What is the troubleshooting order?" is: Plug, power, mute, volume, device**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Most silent computers — what happens by the end of that order?" is: Output — what you hear; input — what a microphone records**
**Answer: False** — Most speak before you reach the end
