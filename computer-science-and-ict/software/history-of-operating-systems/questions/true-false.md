# History of Operating Systems — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: An operating system — operators loaded programs by hand, one at a time**
**Answer: True**

**2. (Sub lesson 1) True or false: An operating system — operators loaded programs by hand, one at a time** — as the answer to: What pain did batch monitors solve?
**Answer: False — The machine idling while humans loaded work — jobs were queued automatically**

**3. (Sub lesson 1) True or false: Many users interacting with one machine at once**
**Answer: True**

**4. (Sub lesson 1) True or false: Many users interacting with one machine at once** — as the answer to: What lasting pattern did Unix set in 1969?
**Answer: False — Small tools, files for everything, and portability across machines**

**5. (Sub lesson 1) True or false: Linux directly; today's mobile systems indirectly (Android from Linux, iOS from Unix kin)**
**Answer: True**

**6. (Sub lesson 2) True or false: Linux directly; today's mobile systems indirectly (Android from Linux, iOS from Unix kin)** — as the answer to: What did the graphical systems replace?
**Answer: False — Typed command lines — windows, icons and a mouse took their place**

**7. (Sub lesson 2) True or false: MS-DOS in 1981; the graphical Macintosh in 1984**
**Answer: True**

**8. (Sub lesson 2) True or false: MS-DOS in 1981; the graphical Macintosh in 1984** — as the answer to: What did Linux prove in 1991?
**Answer: False — A system could be built openly, by a world of volunteers**

**9. (Sub lesson 2) True or false: Touch, apps and sensors — the phone in everyone's pocket**
**Answer: True**

**10. (Sub lesson 2) True or false: Touch, apps and sensors — the phone in everyone's pocket** — as the answer to: What question does each generation's system answer?
**Answer: False — Its hardware's question — scarce machine time, then one person's desk, then everyone's pocket**
