# History of Operating Systems — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What did the first computers run without?** → **An operating system — operators loaded programs by hand, one at a time**

**2. (Sub lesson 1) What pain did batch monitors solve?** → **The machine idling while humans loaded work — jobs were queued automatically**

**3. (Sub lesson 1) What did time-sharing add?** → **Many users interacting with one machine at once**

**4. (Sub lesson 1) What lasting pattern did Unix set in 1969?** → **Small tools, files for everything, and portability across machines**

**5. (Sub lesson 1) Which modern systems descend from Unix?** → **Linux directly; today's mobile systems indirectly (Android from Linux, iOS from Unix kin)**

**6. (Sub lesson 2) What did the graphical systems replace?** → **Typed command lines — windows, icons and a mouse took their place**

**7. (Sub lesson 2) When did MS-DOS arrive, and the Macintosh?** → **MS-DOS in 1981; the graphical Macintosh in 1984**

**8. (Sub lesson 2) What did Linux prove in 1991?** → **A system could be built openly, by a world of volunteers**

**9. (Sub lesson 2) What did iOS and Android rebuild the system around?** → **Touch, apps and sensors — the phone in everyone's pocket**

**10. (Sub lesson 2) What question does each generation's system answer?** → **Its hardware's question — scarce machine time, then one person's desk, then everyone's pocket**
