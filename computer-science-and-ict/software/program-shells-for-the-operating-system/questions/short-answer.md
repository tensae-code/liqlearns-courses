# Program Shells for the Operating System — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a program shell?**
**Answer: A program that stands over the operating system and gives it an easier face**

**2. (Sub lesson 1) How do shells show files?**
**Answer: As lists and panels**

**3. (Sub lesson 1) How are commands given in a shell?**
**Answer: Chosen from menus instead of typed from memory**

**4. (Sub lesson 1) Is the shell the operating system itself?**
**Answer: No — remove it and the system still works**

**5. (Sub lesson 1) What is the shell called, in the lesson's picture?**
**Answer: A coat the system wears for the user's comfort**

**6. (Sub lesson 2) What two things do shells add?**
**Answer: Speed and sight**

**7. (Sub lesson 2) What do two panels show together?**
**Answer: Source and destination for copying**

**8. (Sub lesson 2) What does a viewer do?**
**Answer: Opens a file without its own program**

**9. (Sub lesson 2) Where does the shells lesson sit in the chapter?**
**Answer: At the end, after files and directories**

**10. (Sub lesson 2) Who can use a shell usefully?**
**Answer: A pupil who already knows what a file operation is**
