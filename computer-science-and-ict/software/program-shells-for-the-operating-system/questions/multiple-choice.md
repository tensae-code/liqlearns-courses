# Program Shells for the Operating System — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a program shell?**
a) A program that stands over the operating system and gives it an easier face  b) As lists and panels  c) Chosen from menus instead of typed from memory  d) No — remove it and the system still works
**Answer: a) A program that stands over the operating system and gives it an easier face**

**2. (Sub lesson 1) How do shells show files?**
a) Chosen from menus instead of typed from memory  b) As lists and panels  c) No — remove it and the system still works  d) A coat the system wears for the user's comfort
**Answer: b) As lists and panels**

**3. (Sub lesson 1) How are commands given in a shell?**
a) No — remove it and the system still works  b) A coat the system wears for the user's comfort  c) Chosen from menus instead of typed from memory  d) Speed and sight
**Answer: c) Chosen from menus instead of typed from memory**

**4. (Sub lesson 1) Is the shell the operating system itself?**
