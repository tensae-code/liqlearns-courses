## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **What a program shell is** — A **program shell** (программная оболочка) is a program that stands over the operating system and gives the user an easier face for it: files shown as lists and panels, commands chosen from menus instead of typed from memory. The shell is not the system — remove it and the operating system still works; it is a coat the system wears for the user's comfort.
2. **What shells add** — Shells add **speed and sight**: two panels show source and destination together for copying, viewers open a file without its program, and searches and comparisons are one key away. Grade 8 teaches shells at the end of its operating-system chapter — after files and directories — because a shell is only useful to a pupil who already knows what a file operation is.
