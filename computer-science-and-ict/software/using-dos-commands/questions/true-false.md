# Using DOS Commands — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: DOS's working face — drive, path and a waiting cursor**
**Answer: True**

**2. (Sub lesson 1) True or false: The directory tree — the disk's folders as branches** — as the answer to: How is work done at the prompt?
**Answer: False — Type the command's name, its subject, and Enter — exactly**

**3. (Sub lesson 1) True or false: The directory tree — the disk's folders as branches**
**Answer: True**

**4. (Sub lesson 1) True or false: Deletes a named file, with no recycle bin to forgive a slip** — as the answer to: What does DATE do?
**Answer: False — Shows and sets the machine's date**

**5. (Sub lesson 2) True or false: Deletes a named file, with no recycle bin to forgive a slip**
**Answer: True**

**6. (Sub lesson 2) True or false: Erases a disk completely and lays a fresh empty structure** — as the answer to: What does DISKCOPY copy?
**Answer: False — A whole floppy disk to another, track by track**

**7. (Sub lesson 2) True or false: Erases a disk completely and lays a fresh empty structure**
**Answer: True**

**8. (Sub lesson 2) True or false: Commands that show, commands that change, and commands that prepare** — as the answer to: What is the standing rule for FORMAT?
**Answer: False — Only for a disk whose contents are known and finished with**

**9. (Sub lesson 2) True or false: Commands that show, commands that change, and commands that prepare**
**Answer: True**

**10. (Sub lesson 1) True or false: DOS's working face — drive, path and a waiting cursor** — as the answer to: Which source teaches this lesson?
