# Using DOS Commands

## Do it first

Laos's Grade 10 teacher guide ends with a practical the student book never contains: finding and using the commands of DOS at the command prompt. This lesson works at that prompt, with the appendix's own command set.

## Sub lesson 1 — The prompt and its commands

The **command prompt** is DOS's bare working face: a drive letter, a path, and a waiting cursor, where work is done by **typing a command's name, its subject, and Enter**. Commands are exact: a wrong letter is not a near miss but no command at all. The appendix's working set divides by job — commands that **show** (the disk's tree and contents), commands that **change** (copying, deleting, setting), and commands that **prepare** (formatting) — and the prompt answers each with text, an error, or a dangerous silence the careful worker learns to read.

## Sub lesson 2 — The appendix's commands — FORMAT, DISKCOPY, TREE, DEL, DATE

Five commands carry the practical. **TREE** shows the directory tree — the disk's folders drawn as branches — the map before any work. **DATE** shows and sets the machine's date. **DEL** deletes a named file — gone at the prompt, with no recycle bin to forgive a slip, so the name is read twice before Enter. **DISKCOPY** copies a whole floppy disk to another, track by track. **FORMAT** prepares a disk for use by **erasing everything on it and laying a fresh empty structure** — the appendix's most dangerous command, taught last and hedged with the standing rule: a formatting order is given only for a disk whose contents are known and finished with.
