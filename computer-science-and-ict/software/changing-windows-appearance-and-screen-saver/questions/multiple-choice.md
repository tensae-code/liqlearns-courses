# Changing Windows Appearance and Screen Saver — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is the general appearance of Windows?**
a) How Windows looks — the background picture, the colours of windows and bars, and the size of what is shown  b) In the appearance settings, reached through the Control Panel  c) The picture behind the icons on the desktop  d) A moving picture or pattern that covers the screen when the computer is left alone for a set time
**Answer: a) How Windows looks — the background picture, the colours of windows and bars, and the size of what is shown**

**2. (Sub lesson 1) Where is the appearance changed?**
a) No — it dresses the same Windows in a chosen look  b) In the appearance settings, reached through the Control Panel  c) So the learner makes the computer their own before using its tools for real work  d) To protect screens from a still picture burning into them
**Answer: b) In the appearance settings, reached through the Control Panel**

**3. (Sub lesson 1) Does changing the appearance change how programs work?**
a) The picture behind the icons on the desktop  b) A moving picture or pattern that covers the screen when the computer is left alone for a set time  c) No — it dresses the same Windows in a chosen look  d) Which saver, and how many idle minutes start it
**Answer: c) No — it dresses the same Windows in a chosen look**
