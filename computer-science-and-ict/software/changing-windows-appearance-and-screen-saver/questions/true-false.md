# Changing Windows Appearance and Screen Saver — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is the general appearance of Windows?" is: How Windows looks — the background picture, the colours of windows and bars, and the size of what is shown**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Where is the appearance changed?" is: The picture behind the icons on the desktop**
**Answer: False** — In the appearance settings, reached through the Control Panel

**3. (Sub lesson 1) True or false: the answer to "Does changing the appearance change how programs work?" is: No — it dresses the same Windows in a chosen look**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is the background?" is: A moving picture or pattern that covers the screen when the computer is left alone for a set time**
**Answer: False** — The picture behind the icons on the desktop

**5. (Sub lesson 1) True or false: the answer to "Why does Sudan's book teach appearance early?" is: So the learner makes the computer their own before using its tools for real work**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is a screen saver?" is: Which saver, and how many idle minutes start it**
**Answer: False** — A moving picture or pattern that covers the screen when the computer is left alone for a set time

**7. (Sub lesson 2) True or false: the answer to "Why were screen savers first made?" is: To protect screens from a still picture burning into them**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What two choices do you make when setting a screen saver?" is: Touch the mouse or press a key — your work returns as you left it**
**Answer: False** — Which saver, and how many idle minutes start it

**9. (Sub lesson 2) True or false: the answer to "What else does a screen saver do today?" is: It hides your work from passing eyes**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "How does the screen wake from the saver?" is: In the appearance settings, reached through the Control Panel**
**Answer: False** — Touch the mouse or press a key — your work returns as you left it
