## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The general appearance of Windows** — Windows does not have to look the way it arrived. Its **general appearance** — the picture behind the icons (the **background**), the colours of windows and bars, and the size of what is shown — is changed in the appearance settings, reached through the Control Panel. Changing the appearance changes nothing about how programs work: it dresses the same Windows in a look the person at the computer chose, which is why Sudan's book teaches it early, before the tools are used for real work.
2. **The screen saver** — A **screen saver** is a moving picture or pattern that covers the screen when the computer is left alone for a set number of minutes. It was born to protect old screens from a still picture burning into them, and it still guards the screen — and hides your work from passing eyes. You **set** the screen saver in the same appearance settings: choose the saver, choose how many minutes of idleness start it. Touching the mouse or a key wakes the screen and brings your work back exactly as you left it.
