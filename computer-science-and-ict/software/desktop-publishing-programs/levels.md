# Desktop Publishing Programs — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Publishing — the page as a design
Sub lesson 1 questions from the type files. Pass mark: Producing designed pages on a computer — text, pictures, headlines and columns placed exactly; Frames and pages — each block of text or picture in its own positioned frame.

## Sub lesson 2 — DTP or word processor — the deciding question
Sub lesson 2 questions from the type files. Pass mark: When the document is read in order — a letter, an essay, a report; When the page is looked at as a whole and its look is part of its message.
