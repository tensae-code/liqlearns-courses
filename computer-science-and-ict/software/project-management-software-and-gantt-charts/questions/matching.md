# Project Management Software and Gantt Charts — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What are project management's four questions?** → **What must be done, in what order and how long, by whom, and at what cost**

**2. (Sub lesson 1) What is a Gantt chart?** → **Tasks down the side, time across the top, each task a bar from start to finish**

**3. (Sub lesson 1) What is a dependency on the chart?** → **An order rule — this task cannot start until that one ends**

**4. (Sub lesson 1) Which software does the book teach?** → **GanttProject — open-source project management software**

**5. (Sub lesson 1) What is entered to draw the plan?** → **The tasks, their durations and their order**

**6. (Sub lesson 2) What is allocated to each task?** → **Its people and its budget (cost)**

**7. (Sub lesson 2) What does the plan show early?** → **An overloaded person or an overrun budget — before they show in life**

**8. (Sub lesson 2) What is marked to manage progress?** → **What is actually done — so plan can be compared against reality**

**9. (Sub lesson 2) What re-forecasts itself from progress?** → **The finish date**
