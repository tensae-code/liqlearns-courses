# Project Management Software and Gantt Charts — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: What must be done, in what order and how long, by whom, and at what cost**
**Answer: True**

**2. (Sub lesson 1) True or false: What must be done, in what order and how long, by whom, and at what cost** — as the answer to: What is a Gantt chart?
**Answer: False — Tasks down the side, time across the top, each task a bar from start to finish**

**3. (Sub lesson 1) True or false: An order rule — this task cannot start until that one ends**
**Answer: True**

**4. (Sub lesson 1) True or false: An order rule — this task cannot start until that one ends** — as the answer to: Which software does the book teach?
**Answer: False — GanttProject — open-source project management software**

**5. (Sub lesson 1) True or false: The tasks, their durations and their order**
**Answer: True**

**6. (Sub lesson 2) True or false: The tasks, their durations and their order** — as the answer to: What is allocated to each task?
**Answer: False — Its people and its budget (cost)**

**7. (Sub lesson 2) True or false: An overloaded person or an overrun budget — before they show in life**
**Answer: True**

**8. (Sub lesson 2) True or false: An overloaded person or an overrun budget — before they show in life** — as the answer to: What is marked to manage progress?
**Answer: False — What is actually done — so plan can be compared against reality**

**9. (Sub lesson 2) True or false: The finish date**
**Answer: True**

**10. (Sub lesson 2) True or false: The finish date** — as the answer to: What does the software give a small team?
**Answer: False — The whole project seen in one look — its reports**
