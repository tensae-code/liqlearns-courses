# The Windows Operating System — First Look — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What kind of software is Windows?**
a) System software — an operating system  b) First, when the computer is switched on, before any application  c) Passing your orders to the machine and the machine's answers back to you  d) No — every program works through the operating system
**Answer: a) System software — an operating system**

**2. (Sub lesson 1) When is Windows loaded?**
a) Passing your orders to the machine and the machine's answers back to you  b) First, when the computer is switched on, before any application  c) No — every program works through the operating system  d) Because Windows is the system every application stands on
**Answer: b) First, when the computer is switched on, before any application**

**3. (Sub lesson 1) What does the operating system stay in charge of?**
a) No — every program works through the operating system  b) Because Windows is the system every application stands on  c) Passing your orders to the machine and the machine's answers back to you  d) The desktop, with its icons and taskbar
**Answer: c) Passing your orders to the machine and the machine's answers back to you**

**4. (Sub lesson 1) Can an application run before Windows is running?**
a) Because Windows is the system every application stands on  b) The desktop, with its icons and taskbar  c) The taskbar, carrying the Start button and the clock  d) No — every program works through the operating system
**Answer: d) No — every program works through the operating system**

**5. (Sub lesson 1) Why does the Yemen book give Windows a whole unit before any application?**
a) Because Windows is the system every application stands on  b) The desktop, with its icons and taskbar  c) The taskbar, carrying the Start button and the clock  d) Icons, standing for programs, files and folders
**Answer: a) Because Windows is the system every application stands on**

**6. (Sub lesson 2) What does Windows show you first?**
a) The taskbar, carrying the Start button and the clock  b) The desktop, with its icons and taskbar  c) Icons, standing for programs, files and folders  d) Windows, on top of the desktop
**Answer: b) The desktop, with its icons and taskbar**

**7. (Sub lesson 2) What runs along the bottom of the screen?**
a) Icons, standing for programs, files and folders  b) Windows, on top of the desktop  c) The taskbar, carrying the Start button and the clock  d) The desktop — the system's home screen
**Answer: c) The taskbar, carrying the Start button and the clock**

**8. (Sub lesson 2) What are the small pictures on the desktop?**
a) Windows, on top of the desktop  b) The desktop — the system's home screen  c) System software — an operating system  d) Icons, standing for programs, files and folders
**Answer: d) Icons, standing for programs, files and folders**

**9. (Sub lesson 2) Where do programs open into?**
a) Windows, on top of the desktop  b) The desktop — the system's home screen  c) System software — an operating system  d) First, when the computer is switched on, before any application
**Answer: a) Windows, on top of the desktop**

**10. (Sub lesson 2) What does closing everything bring you back to?**
a) System software — an operating system  b) The desktop — the system's home screen  c) First, when the computer is switched on, before any application  d) Passing your orders to the machine and the machine's answers back to you
**Answer: b) The desktop — the system's home screen**
