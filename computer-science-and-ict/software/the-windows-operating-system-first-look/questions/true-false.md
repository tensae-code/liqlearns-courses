# The Windows Operating System — First Look — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What kind of software is Windows?" is: System software — an operating system**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "When is Windows loaded?" is: Passing your orders to the machine and the machine's answers back to you**
**Answer: False** — First, when the computer is switched on, before any application

**3. (Sub lesson 1) True or false: the answer to "What does the operating system stay in charge of?" is: Passing your orders to the machine and the machine's answers back to you**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Can an application run before Windows is running?" is: Because Windows is the system every application stands on**
**Answer: False** — No — every program works through the operating system

**5. (Sub lesson 1) True or false: the answer to "Why does the Yemen book give Windows a whole unit before any application?" is: Because Windows is the system every application stands on**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does Windows show you first?" is: The taskbar, carrying the Start button and the clock**
**Answer: False** — The desktop, with its icons and taskbar

**7. (Sub lesson 2) True or false: the answer to "What runs along the bottom of the screen?" is: The taskbar, carrying the Start button and the clock**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What are the small pictures on the desktop?" is: Windows, on top of the desktop**
**Answer: False** — Icons, standing for programs, files and folders

**9. (Sub lesson 2) True or false: the answer to "Where do programs open into?" is: Windows, on top of the desktop**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What does closing everything bring you back to?" is: System software — an operating system**
**Answer: False** — The desktop — the system's home screen
