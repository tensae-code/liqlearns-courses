# The Windows Operating System — First Look — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What kind of software is Windows?**
**Answer: System software — an operating system**

**2. (Sub lesson 1) When is Windows loaded?**
**Answer: First, when the computer is switched on, before any application**

**3. (Sub lesson 1) What does the operating system stay in charge of?**
**Answer: Passing your orders to the machine and the machine's answers back to you**

**4. (Sub lesson 1) Can an application run before Windows is running?**
**Answer: No — every program works through the operating system**

**5. (Sub lesson 1) Why does the Yemen book give Windows a whole unit before any application?**
**Answer: Because Windows is the system every application stands on**

**6. (Sub lesson 2) What does Windows show you first?**
**Answer: The desktop, with its icons and taskbar**

**7. (Sub lesson 2) What runs along the bottom of the screen?**
**Answer: The taskbar, carrying the Start button and the clock**

**8. (Sub lesson 2) What are the small pictures on the desktop?**
**Answer: Icons, standing for programs, files and folders**

**9. (Sub lesson 2) Where do programs open into?**
**Answer: Windows, on top of the desktop**

**10. (Sub lesson 2) What does closing everything bring you back to?**
**Answer: The desktop — the system's home screen**
