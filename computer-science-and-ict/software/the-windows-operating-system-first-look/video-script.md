# Video script — The Windows Operating System — First Look

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Windows is an operating system — the most important piece of system software on the computer. When the machine is switched on, Windows is loaded first: it wakes the hardware, checks it, and then stays in charge the whole time you work, passing your orders to the machine and the machine's answers back to you. No application program can run until Windows is running, because every program works through the operating system. That is why the Yemen book opens a whole unit on Windows before it opens a single application.
What Windows shows you first is the desktop, with its icons and the taskbar along the bottom carrying the Start button and the clock. A first look is enough for this lesson: this is the system's home screen, programs open from here into windows, and everything you close brings you back here. The parts themselves — icons, the window, the desktop, the menus — get their own lessons next; this first look simply names the place and the system that runs it.
