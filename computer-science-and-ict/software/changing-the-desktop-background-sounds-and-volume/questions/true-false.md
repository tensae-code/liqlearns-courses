# Changing the Desktop Background, Sounds and Volume — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is the desktop background?" is: The picture behind the icons**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How is the background changed?" is: A drawing you made in Paint, saved as a file**
**Answer: False** — By choosing a picture in the settings

**3. (Sub lesson 1) True or false: the answer to "What picture of your own can become the background?" is: A drawing you made in Paint, saved as a file**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What are system sounds?" is: Starting the computer; an error (or a notification)**
**Answer: False** — The little sounds Windows makes at events

**5. (Sub lesson 1) True or false: the answer to "Name two events with system sounds." is: Starting the computer; an error (or a notification)**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What else can be done to system sounds besides changing them?" is: How loud all sound is**
**Answer: False** — They can be silenced

**7. (Sub lesson 2) True or false: the answer to "What does the volume control set?" is: How loud all sound is**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is a theme?" is: As one**
**Answer: False** — A bundle — background, sounds and colours chosen together

**9. (Sub lesson 2) True or false: the answer to "How is a theme applied?" is: As one**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Whose work can stand behind every program you open?" is: The picture behind the icons**
**Answer: False** — Your own — your Paint drawing
