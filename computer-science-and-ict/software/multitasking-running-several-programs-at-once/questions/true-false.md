# Multitasking — Running Several Programs at Once — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does a multitasking operating system do?" is: Runs several programs at once, sharing the machine's time among them**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does each open program keep?" is: The one that takes the keyboard and stands in front**
**Answer: False** — Its window, its work and its place

**3. (Sub lesson 1) True or false: the answer to "What is the active window?" is: The one that takes the keyboard and stands in front**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Is an inactive program closed?" is: Alt+Tab**
**Answer: False** — No — it holds its work, waiting

**5. (Sub lesson 1) True or false: the answer to "What switch cycles the windows?" is: Alt+Tab**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How does work travel between programs?" is: A picture from Paint copied into a Word document**
**Answer: False** — By copying and pasting — the clipboard is the ferry

**7. (Sub lesson 2) True or false: the answer to "What is the book's own inter-program journey?" is: A picture from Paint copied into a Word document**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What should you name before typing?" is: One program receiving another's commands**
**Answer: False** — Your active window

**9. (Sub lesson 2) True or false: the answer to "What are most multi-program accidents?" is: One program receiving another's commands**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Who owns the work in your hands — why must you know?" is: Runs several programs at once, sharing the machine's time among them**
**Answer: False** — The program it was made in — its tools and saves are that program's
