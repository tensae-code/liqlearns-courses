# The Calculator Program — multiple choice

Pick the one right answer.

**1. The Calculator program is for —**
a) drawing  b) calculating  c) writing stories
**Answer: b) calculating** — It works out number calculations.

**2. The sign for adding is —**
a) −  b) ÷  c) +
**Answer: c) +** — Plus is the adding sign.

**3. To work out 7 + 5, press —**
a) 7, +, 5, =  b) =, 7, 5, +  c) 5 only
**Answer: a) 7, +, 5, =** — Number, sign, number, equals.

**4. Before a new calculation you should —**
a) keep the old numbers in  b) clear the old calculation  c) close the desktop
**Answer: b) clear the old calculation** — So old numbers do not mix in.
