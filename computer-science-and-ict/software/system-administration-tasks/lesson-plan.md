## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Diagnosing a system** — **System administration** is **looking after a computer system so it works for its users**, and its first task with any fault is to **diagnose — find what is wrong — before changing anything**. Administration is done by the **system administrator**, who keeps notes of changes so the system can be understood and restored.
2. **Performing basic administration** — The basic tasks include **managing user accounts**, keeping settings and access under control, and **regular maintenance that prevents faults and breakdowns**. After any fix, an administrator **tests that the system works**, and the documentation of what was done helps the next administrator who meets the system.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
