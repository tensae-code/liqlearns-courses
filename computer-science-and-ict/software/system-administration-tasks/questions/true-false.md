# System Administration Tasks — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is system administration?" is: Looking after a computer system so it works for its users**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does diagnosing mean?" is: The system administrator**
**Answer: False** — Finding what is wrong

**3. (Sub lesson 1) True or false: the answer to "What is the first administration step with a fault?" is: Diagnose before changing anything**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Who performs system administration tasks?" is: Managing user accounts**
**Answer: False** — The system administrator

**5. (Sub lesson 1) True or false: the answer to "Why keep notes of changes to a system?" is: So the system can be understood and restored**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Name one basic administration task." is: Test that the system works**
**Answer: False** — Managing user accounts

**7. (Sub lesson 2) True or false: the answer to "How do administrators protect a system?" is: By keeping settings and access under control**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What should an administrator do after a fix?" is: It shows what was done and why**
**Answer: False** — Test that the system works

**Answer: True**
