# System Administration Tasks — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is system administration?**
a) Looking after a computer system so it works for its users  b) Finding what is wrong  c) Diagnose before changing anything  d) The system administrator
**Answer: a) Looking after a computer system so it works for its users**

**2. (Sub lesson 1) What does diagnosing mean?**
a) Diagnose before changing anything  b) Finding what is wrong  c) The system administrator  d) So the system can be understood and restored
**Answer: b) Finding what is wrong**

**3. (Sub lesson 1) What is the first administration step with a fault?**
a) The system administrator  b) So the system can be understood and restored  c) Diagnose before changing anything  d) Managing user accounts
**Answer: c) Diagnose before changing anything**

**4. (Sub lesson 1) Who performs system administration tasks?**
a) So the system can be understood and restored  b) Managing user accounts  c) By keeping settings and access under control  d) The system administrator
**Answer: d) The system administrator**

**5. (Sub lesson 1) Why keep notes of changes to a system?**
a) So the system can be understood and restored  b) Managing user accounts  c) By keeping settings and access under control  d) Test that the system works
**Answer: a) So the system can be understood and restored**

**6. (Sub lesson 2) Name one basic administration task.**
a) By keeping settings and access under control  b) Managing user accounts  c) Test that the system works  d) Faults and breakdowns
**Answer: b) Managing user accounts**

**7. (Sub lesson 2) How do administrators protect a system?**
a) Test that the system works  b) Faults and breakdowns  c) By keeping settings and access under control  d) It shows what was done and why
**Answer: c) By keeping settings and access under control**

**8. (Sub lesson 2) What should an administrator do after a fix?**
a) Faults and breakdowns  b) It shows what was done and why  c) Looking after a computer system so it works for its users  d) Test that the system works
**Answer: d) Test that the system works**

**9. (Sub lesson 2) What does regular maintenance prevent?**
a) Faults and breakdowns  b) It shows what was done and why  c) Looking after a computer system so it works for its users  d) Finding what is wrong
**Answer: a) Faults and breakdowns**

**10. (Sub lesson 2) How does documentation help the next administrator?**
a) Looking after a computer system so it works for its users  b) It shows what was done and why  c) Finding what is wrong  d) Diagnose before changing anything
**Answer: b) It shows what was done and why**
