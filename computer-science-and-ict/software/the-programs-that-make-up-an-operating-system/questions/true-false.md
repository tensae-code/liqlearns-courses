# The Programs That Make Up an Operating System — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Is an operating system one program?" is: No — a set of programs**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What starts the system at switch-on?" is: Memory, the processor's time and the devices**
**Answer: False** — The loader

**3. (Sub lesson 1) True or false: the answer to "What does the kernel manage?" is: Memory, the processor's time and the devices**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What speaks to each device?" is: Right after the concept of an operating system**
**Answer: False** — A driver

**5. (Sub lesson 1) True or false: the answer to "Where does this lesson sit in the book?" is: Right after the concept of an operating system**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does the loader bring in?" is: The drivers and the interface**
**Answer: False** — The kernel

**7. (Sub lesson 2) True or false: the answer to "What does the kernel start next?" is: The drivers and the interface**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What do programs ask the kernel for?" is: Shares them fairly and guards them**
**Answer: False** — Memory, time and devices

**9. (Sub lesson 2) True or false: the answer to "What two things does the kernel do with them?" is: Shares them fairly and guards them**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is booting, once the parts are named?" is: No — a set of programs**
**Answer: False** — A queue of programs, each starting the next
