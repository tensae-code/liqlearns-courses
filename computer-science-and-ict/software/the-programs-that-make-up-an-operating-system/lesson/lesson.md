# The Programs That Make Up an Operating System

## Do it first

'The operating system' sounds like one thing. Grade 8's lesson takes it apart: an operating system is a set of programs, each with its own job in starting and running the machine.

## Sub lesson 1 — The parts of the system

An operating system is made of **programs**: the **loader** that starts the system when the machine switches on, the **kernel** that manages memory, the processor's time and the devices, **drivers** that speak to each device, and the **utilities and interface programs** the user meets. Uzbekistan's Grade 8 book gives the composition its own lesson, right after the concept of an operating system.

[Picture — The parts of the system]

## Sub lesson 2 — How the parts work together

At switch-on the loader brings the kernel in; the kernel starts the drivers and the interface; from then on every program asks the kernel for memory, time and devices, and the kernel shares them fairly and guards them. Name the parts and the booting of a computer stops being magic: it is a queue of programs, each starting the next.
