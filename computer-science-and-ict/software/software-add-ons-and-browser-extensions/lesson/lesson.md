# Software Add-ons and Browser Extensions

## Do it first

Your browser did not ship with a download helper or an ad blocker. Someone added them. Rwanda's S3 book teaches add-ons as their own topic — what they are, how they get in, and how they come out.

## Sub lesson 1 — What add-ons are

An **add-on** is a **small program that adds a feature to a bigger program** — the host. In a browser, add-ons are called **extensions** (and plug-ins in the book's wording): a **Download Helper** that grabs video, an **ad blocker** that strips adverts from pages. The host gives the add-on its doorway; the add-on does one extra job the host's makers left out or left open. Rwanda's S3 book files them under software, beside installing and uninstalling whole programs.

## Sub lesson 2 — Installing, disabling and removing add-ons

In the book's Firefox walkthrough, an add-on is **installed from the browser's add-ons page**: search the add-on's name, choose it, and confirm — it appears in the browser ready to work. Control stays with the user afterwards: an add-on can be **disabled** (switched off but kept) or **removed** (taken out completely) from the same page. The book's rule of sense: an add-on touches everything the browser shows, so install only ones you can name a job for.
