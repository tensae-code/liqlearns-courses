# Software Add-ons and Browser Extensions — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is an add-on?**
a) A small program that adds a feature to a bigger program  b) The host  c) Extensions (plug-ins in the book's wording)  d) Download Helper
**Answer: a) A small program that adds a feature to a bigger program**

**2. (Sub lesson 1) What is the bigger program called?**
a) Extensions (plug-ins in the book's wording)  b) The host  c) Download Helper  d) Strips adverts from pages
**Answer: b) The host**

**3. (Sub lesson 1) What are browser add-ons called?**
a) Download Helper  b) Strips adverts from pages  c) Extensions (plug-ins in the book's wording)  d) A small program that adds a feature to a bigger program
**Answer: c) Extensions (plug-ins in the book's wording)**

**4. (Sub lesson 1) Name one add-on from Rwanda's book.**
a) Strips adverts from pages  b) A small program that adds a feature to a bigger program  c) The host  d) Download Helper
**Answer: d) Download Helper**

**5. (Sub lesson 1) What does an ad blocker do?**
a) Strips adverts from pages  b) A small program that adds a feature to a bigger program  c) The host  d) Extensions (plug-ins in the book's wording)
