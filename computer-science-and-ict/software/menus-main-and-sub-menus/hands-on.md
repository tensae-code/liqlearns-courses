# Hands-on — Menus — Main and Sub-Menus

The lesson with your hands and your feet, not only your eyes.

## Walk a menu
On a real computer, open a main menu from a menu bar, read every command aloud, then close it with Escape without choosing anything.

## Find the arrow
Find one menu item with an arrow, open its sub-menu by pointing, and click the last command in it. Write the full path you walked: menu → sub-menu → command.
