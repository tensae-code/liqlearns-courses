# Menus — Main and Sub-Menus — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a menu?" is: A list of commands the program offers you to pick from**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Where does a main menu open from?" is: Names on the menu bar that open main menus**
**Answer: False** — The menu bar at the top of a window, or the Start button

**3. (Sub lesson 1) True or false: the answer to "What are File, Edit and View examples of?" is: Names on the menu bar that open main menus**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What happens when you click a command in a menu?" is: Press Escape, or click somewhere else**
**Answer: False** — The command is carried out and the menu closes

**5. (Sub lesson 1) True or false: the answer to "How do you close a menu without choosing?" is: Press Escape, or click somewhere else**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What marks an item that holds a sub-menu?" is: Point at the item with the arrow, without clicking**
**Answer: False** — A small arrow at its right edge

**7. (Sub lesson 2) True or false: the answer to "How do you open a sub-menu?" is: Point at the item with the arrow, without clicking**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Where does a sub-menu open?" is: Two steps — main menu, then sub-menu, then click**
**Answer: False** — Out sideways, beside the main-menu item

**9. (Sub lesson 2) True or false: the answer to "How deep can a command be?" is: Two steps — main menu, then sub-menu, then click**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What happens if you slide off the sub-menu path?" is: A list of commands the program offers you to pick from**
**Answer: False** — The sub-menu closes and you point at the item again
