## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The main menu — a list of commands** — A **menu** is a list of choices the program offers, so you pick a command instead of typing or remembering it. The **main menu** is the first list: it opens from the **menu bar** at the top of a window — File, Edit, View and their neighbours — or from the Start button. Clicking a name opens its list; clicking a command in the list carries it out and closes the menu. Pressing Escape, or clicking elsewhere, closes the menu without choosing anything.
2. **The sub-menu — a menu inside a menu** — Some items in a main menu carry a small **arrow** at their right edge. Pointing at such an item — without clicking — opens a **sub-menu**: a second, smaller list that opens out sideways, offering the choices inside that one item. So a command can be two steps deep: main menu first, then across to the sub-menu, then click the exact command. If you slide off the path, the sub-menu closes and you simply point again.
