# The Control Panel and Its Settings — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is the Control Panel?" is: The place Windows gathers the settings for how the computer itself behaves and looks**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How is it opened?" is: Icons or categories, one per area of the machine**
**Answer: False** — From the Start menu

**3. (Sub lesson 1) True or false: the answer to "What does its window show?" is: Icons or categories, one per area of the machine**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Why does the book teach it late, in Grade 12?" is: Nowhere else — nothing about the setup lives anywhere else**
**Answer: False** — By then the learner has met many of its rooms one by one and can see the whole workshop at once

**5. (Sub lesson 1) True or false: the answer to "Where does the computer's own setup live, besides here?" is: Nowhere else — nothing about the setup lives anywhere else**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does Display set?" is: Add or Remove Programs — never by deleting its folder**
**Answer: False** — The wallpaper, screen saver and resolution

**7. (Sub lesson 2) True or false: the answer to "What is the correct way to remove a program?" is: Add or Remove Programs — never by deleting its folder**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What do User Accounts do there?" is: Respect — change one thing at a time, remember what it was, and put it back if wrong**
**Answer: False** — Make and guard the people's accounts

**9. (Sub lesson 2) True or false: the answer to "What is the workshop's one rule?" is: Respect — change one thing at a time, remember what it was, and put it back if wrong**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why does knowing the Control Panel remove fear of a strange computer?" is: The place Windows gathers the settings for how the computer itself behaves and looks**
**Answer: False** — Every unfamiliar machine is adjusted from the same room
