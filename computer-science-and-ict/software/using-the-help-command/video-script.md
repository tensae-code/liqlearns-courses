# Video script — Using the Help Command

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Almost every program carries its own **Help**: a built-in book about itself, opened from the **Help menu** or with **F1**.
Windows itself has **Help and Support**, reached from the Start menu.
Help exists because no course can teach every command of every program — Afghanistan's Grade 12 book ends its system lessons with Help for exactly that reason: it is the skill that replaces the teacher when the teacher is not there.
The learner who can use Help is never fully stuck; the one who cannot is stuck at the first unfamiliar dialog.
Help is entered three ways.
The **Contents** shows the help book's chapters, for learning a topic in order.
The **Index** is an alphabetical list of topics — type the first letters of the thing you want, as in a book's index, and jump to it.
**Search** finds every help page containing your words, for when you know the words but not where the topic lives.
In all three, the craft is the same: name the thing you are trying to do in the program's own words — 'insert picture', not 'put the photo in' — read the steps it gives, and follow them on your own work.
Help answers best those who ask precisely; and when Help has answered once, the path is yours forever.
