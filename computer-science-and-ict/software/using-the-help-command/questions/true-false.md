# Using the Help Command — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is the Help command?" is: The built-in teacher inside Windows and its programs**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How is Help opened?" is: Help and Support, from the Start menu**
**Answer: False** — From the Help menu, or with F1

**3. (Sub lesson 1) True or false: the answer to "What is Windows' own help called, and where is it reached?" is: Help and Support, from the Start menu**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Why does the book end its system lessons with Help?" is: The learner who can use Help**
**Answer: False** — Because no course can teach every command — Help is the skill that replaces the teacher

**5. (Sub lesson 1) True or false: the answer to "Who is never fully stuck?" is: The learner who can use Help**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What are Help's three ways in?" is: The help book's chapters — learning a topic in order**
**Answer: False** — Contents, Index and Search

**7. (Sub lesson 2) True or false: the answer to "What is the Contents for?" is: The help book's chapters — learning a topic in order**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How does the Index work?" is: When you know the words but not where the topic lives**
**Answer: False** — An alphabetical topic list — type the first letters and jump to the topic

**9. (Sub lesson 2) True or false: the answer to "When is Search the right way in?" is: When you know the words but not where the topic lives**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is the craft of asking Help?" is: The built-in teacher inside Windows and its programs**
**Answer: False** — Name the thing in the program's own words, then follow the steps it gives
