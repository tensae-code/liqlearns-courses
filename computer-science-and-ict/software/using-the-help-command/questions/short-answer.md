# Using the Help Command — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is the Help command?**
**Answer: The built-in teacher inside Windows and its programs**

**2. (Sub lesson 1) How is Help opened?**
**Answer: From the Help menu, or with F1**

**3. (Sub lesson 1) What is Windows' own help called, and where is it reached?**
**Answer: Help and Support, from the Start menu**

**4. (Sub lesson 1) Why does the book end its system lessons with Help?**
**Answer: Because no course can teach every command — Help is the skill that replaces the teacher**

**5. (Sub lesson 1) Who is never fully stuck?**
**Answer: The learner who can use Help**

**6. (Sub lesson 2) What are Help's three ways in?**
**Answer: Contents, Index and Search**

**7. (Sub lesson 2) What is the Contents for?**
**Answer: The help book's chapters — learning a topic in order**

**8. (Sub lesson 2) How does the Index work?**
**Answer: An alphabetical topic list — type the first letters and jump to the topic**

**9. (Sub lesson 2) When is Search the right way in?**
**Answer: When you know the words but not where the topic lives**

**10. (Sub lesson 2) What is the craft of asking Help?**
**Answer: Name the thing in the program's own words, then follow the steps it gives**
