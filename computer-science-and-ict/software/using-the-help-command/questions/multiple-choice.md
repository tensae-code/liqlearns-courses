# Using the Help Command — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is the Help command?**
a) The built-in teacher inside Windows and its programs  b) From the Help menu, or with F1  c) Help and Support, from the Start menu  d) Because no course can teach every command — Help is the skill that replaces the teacher
**Answer: a) The built-in teacher inside Windows and its programs**

**2. (Sub lesson 1) How is Help opened?**
a) Help and Support, from the Start menu  b) From the Help menu, or with F1  c) Because no course can teach every command — Help is the skill that replaces the teacher  d) The learner who can use Help
**Answer: b) From the Help menu, or with F1**

**3. (Sub lesson 1) What is Windows' own help called, and where is it reached?**
a) Because no course can teach every command — Help is the skill that replaces the teacher  b) The learner who can use Help  c) Help and Support, from the Start menu  d) Contents, Index and Search
**Answer: c) Help and Support, from the Start menu**

**4. (Sub lesson 1) Why does the book end its system lessons with Help?**
a) The learner who can use Help  b) Contents, Index and Search  c) The help book's chapters — learning a topic in order  d) Because no course can teach every command — Help is the skill that replaces the teacher
**Answer: d) Because no course can teach every command — Help is the skill that replaces the teacher**

**5. (Sub lesson 1) Who is never fully stuck?**
