# Lesson plan — Using the Help Command

**Course:** Computer Science and ICT · **Title:** Software · **Lesson:** Using the Help Command
**Place in the curriculum:** ICT expansion — Afghanistan (2026-11-14) — in the title Software on the ICT course ladder (TITLES.md). Built new from Afghanistan's *Computer* Grade 12, because no existing lesson in the course covers this thing as its own lesson.
**The one thing this lesson teaches:** The Help command is the built-in teacher inside Windows and its programs: it answers questions about the very program you are using, by contents, by index and by search — if you learn to ask it.
**This lesson's own level:** It stands on the earlier lessons of its title and on the Afghanistan book's own order — it follows the book's sections in sequence, so its neighbours in the book are its natural companions. It stands alone for a learner landing on it directly.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Help — the teacher built into the program** — Almost every program carries its own **Help**: a built-in book about itself, opened from the **Help menu** or with **F1**. Windows itself has **Help and Support**, reached from the Start menu. Help exists because no course can teach every command of every program — Afghanistan's Grade 12 book ends its system lessons with Help for exactly that reason: it is the skill that replaces the teacher when the teacher is not there. The learner who can use Help is never fully stuck; the one who cannot is stuck at the first unfamiliar dialog.
2. **Three ways in — contents, index, search** — Help is entered three ways. The **Contents** shows the help book's chapters, for learning a topic in order. The **Index** is an alphabetical list of topics — type the first letters of the thing you want, as in a book's index, and jump to it. **Search** finds every help page containing your words, for when you know the words but not where the topic lives. In all three, the craft is the same: name the thing you are trying to do in the program's own words — 'insert picture', not 'put the photo in' — read the steps it gives, and follow them on your own work. Help answers best those who ask precisely; and when Help has answered once, the path is yours forever.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
