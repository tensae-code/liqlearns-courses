# Hands-on — Using the Help Command

The lesson with your hands and your feet, not only your eyes.

## Ask the inside teacher
In any program, open Help and answer three set questions using it alone: one from the Contents, one from the Index, one from Search. Write the question, the way in, and the answer. Note which way was fastest for which question.

## Name it in the program's words
Take five everyday requests — 'put the photo in', 'make the letters fat', 'save it somewhere else'. Rewrite each in the program's own words, then test your version in Help's Index: did it land on the topic first try? Fix the ones that missed.
