# Getting Started with Windows XP — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What kind of software is Windows XP?**
**Answer: System software — an operating system**

**2. (Sub lesson 1) When is Windows loaded?**
**Answer: First, when the computer is switched on, before any other program**

**3. (Sub lesson 1) What does the operating system stay in charge of?**
**Answer: Passing your orders to the machine and its answers back to you**

**4. (Sub lesson 1) Can an application run before Windows?**
**Answer: No — no application can run until Windows is running**

**5. (Sub lesson 1) Why does the book begin the software chapter with Windows?**
**Answer: Because Windows is the ground every other program stands on**

**6. (Sub lesson 2) What is the desktop?**
**Answer: The working surface Windows shows first, like a real desk across the screen**

**7. (Sub lesson 2) What are icons?**
**Answer: Small pictures that stand for programs, files and folders**

**8. (Sub lesson 2) How is an icon opened?**
**Answer: With a double-click**

**9. (Sub lesson 2) What runs across the bottom of the screen?**
**Answer: The taskbar, with the Start button, open programs and the clock**

**10. (Sub lesson 2) Where does everything in Windows begin from?**
**Answer: The desktop — an icon or the Start menu**
