# Getting Started with Windows XP — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What kind of software is Windows XP?" is: System software — an operating system**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "When is Windows loaded?" is: Passing your orders to the machine and its answers back to you**
**Answer: False** — First, when the computer is switched on, before any other program

**3. (Sub lesson 1) True or false: the answer to "What does the operating system stay in charge of?" is: Passing your orders to the machine and its answers back to you**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Can an application run before Windows?" is: Because Windows is the ground every other program stands on**
**Answer: False** — No — no application can run until Windows is running

**5. (Sub lesson 1) True or false: the answer to "Why does the book begin the software chapter with Windows?" is: Because Windows is the ground every other program stands on**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is the desktop?" is: Small pictures that stand for programs, files and folders**
**Answer: False** — The working surface Windows shows first, like a real desk across the screen

**7. (Sub lesson 2) True or false: the answer to "What are icons?" is: Small pictures that stand for programs, files and folders**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How is an icon opened?" is: The taskbar, with the Start button, open programs and the clock**
**Answer: False** — With a double-click

**9. (Sub lesson 2) True or false: the answer to "What runs across the bottom of the screen?" is: The taskbar, with the Start button, open programs and the clock**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Where does everything in Windows begin from?" is: System software — an operating system**
**Answer: False** — The desktop — an icon or the Start menu
