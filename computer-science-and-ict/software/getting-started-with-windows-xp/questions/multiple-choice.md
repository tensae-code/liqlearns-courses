# Getting Started with Windows XP — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What kind of software is Windows XP?**
a) System software — an operating system  b) First, when the computer is switched on, before any other program  c) Passing your orders to the machine and its answers back to you  d) No — no application can run until Windows is running
**Answer: a) System software — an operating system**

**2. (Sub lesson 1) When is Windows loaded?**
a) Passing your orders to the machine and its answers back to you  b) First, when the computer is switched on, before any other program  c) No — no application can run until Windows is running  d) Because Windows is the ground every other program stands on
**Answer: b) First, when the computer is switched on, before any other program**

**3. (Sub lesson 1) What does the operating system stay in charge of?**
a) No — no application can run until Windows is running  b) Because Windows is the ground every other program stands on  c) Passing your orders to the machine and its answers back to you  d) The working surface Windows shows first, like a real desk across the screen
**Answer: c) Passing your orders to the machine and its answers back to you**

**4. (Sub lesson 1) Can an application run before Windows?**
a) Because Windows is the ground every other program stands on  b) The working surface Windows shows first, like a real desk across the screen  c) Small pictures that stand for programs, files and folders  d) No — no application can run until Windows is running
**Answer: d) No — no application can run until Windows is running**

**5. (Sub lesson 1) Why does the book begin the software chapter with Windows?**
a) Because Windows is the ground every other program stands on  b) The working surface Windows shows first, like a real desk across the screen  c) Small pictures that stand for programs, files and folders  d) With a double-click
**Answer: a) Because Windows is the ground every other program stands on**

**6. (Sub lesson 2) What is the desktop?**
a) Small pictures that stand for programs, files and folders  b) The working surface Windows shows first, like a real desk across the screen  c) With a double-click  d) The taskbar, with the Start button, open programs and the clock
**Answer: b) The working surface Windows shows first, like a real desk across the screen**

**7. (Sub lesson 2) What are icons?**
a) With a double-click  b) The taskbar, with the Start button, open programs and the clock  c) Small pictures that stand for programs, files and folders  d) The desktop — an icon or the Start menu
**Answer: c) Small pictures that stand for programs, files and folders**

**8. (Sub lesson 2) How is an icon opened?**
a) The taskbar, with the Start button, open programs and the clock  b) The desktop — an icon or the Start menu  c) System software — an operating system  d) With a double-click
**Answer: d) With a double-click**

**9. (Sub lesson 2) What runs across the bottom of the screen?**
a) The taskbar, with the Start button, open programs and the clock  b) The desktop — an icon or the Start menu  c) System software — an operating system  d) First, when the computer is switched on, before any other program
**Answer: a) The taskbar, with the Start button, open programs and the clock**

**10. (Sub lesson 2) Where does everything in Windows begin from?**
a) System software — an operating system  b) The desktop — an icon or the Start menu  c) First, when the computer is switched on, before any other program  d) Passing your orders to the machine and its answers back to you
**Answer: b) The desktop — an icon or the Start menu**
