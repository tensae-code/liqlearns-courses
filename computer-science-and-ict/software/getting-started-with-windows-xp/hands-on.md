# Hands-on — Getting Started with Windows XP

The lesson with your hands and your feet, not only your eyes.

## Draw your desktop
Draw the Windows desktop from memory: the icons, the taskbar, the Start button and the clock, each labelled. Then sit at a real computer, compare, and fix every difference you find.

## Open and return
On a real computer, open a program from an icon, then close it and return to the desktop. Do the same from the Start menu. Say which way was quicker, and why the desktop is called a desk.
