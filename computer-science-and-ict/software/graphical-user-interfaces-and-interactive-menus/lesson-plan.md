## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **GUI objects — icons, cursors, buttons** — A **GUI — graphical user interface** — lets the user work by pointing at pictures instead of typing text commands. Its objects include the **icon**, a small picture representing something; the **cursor**, which shows where the pointer is; and the **button**, pressed to start an action.
2. **Creating interactive menus** — A **menu** offers **a list of choices**, and it is **interactive — the system responds to the user**: choosing a menu item runs its action. Menus should be clear and easy to follow. The guide's GUI objects are icons, cursors and buttons, and an interactive menu is built from them.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
