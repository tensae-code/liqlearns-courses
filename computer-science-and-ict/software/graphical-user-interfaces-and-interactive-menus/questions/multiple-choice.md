# Graphical User Interfaces and Interactive Menus — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) GUI stands for what?**
a) Graphical User Interface  b) A small picture representing something  c) Where the pointer is  d) Start an action
**Answer: a) Graphical User Interface**

**2. (Sub lesson 1) What is an icon?**
a) Where the pointer is  b) A small picture representing something  c) Start an action  d) Text commands
**Answer: b) A small picture representing something**

**3. (Sub lesson 1) What does the cursor show?**
a) Start an action  b) Text commands  c) Where the pointer is  d) A list of choices
**Answer: c) Where the pointer is**

**4. (Sub lesson 1) A button is pressed to do what?**
a) Text commands  b) A list of choices  c) The system responds to the user  d) Start an action
**Answer: d) Start an action**

**5. (Sub lesson 1) A GUI replaces typing what?**
a) Text commands  b) A list of choices  c) The system responds to the user  d) Runs its action
**Answer: a) Text commands**

**6. (Sub lesson 2) A menu offers what?**
a) The system responds to the user  b) A list of choices  c) Runs its action  d) Clear and easy to follow
**Answer: b) A list of choices**

**7. (Sub lesson 2) Interactive means what?**
a) Runs its action  b) Clear and easy to follow  c) The system responds to the user  d) Icons, cursors and buttons
**Answer: c) The system responds to the user**

**8. (Sub lesson 2) Choosing a menu item does what?**
a) Clear and easy to follow  b) Icons, cursors and buttons  c) Graphical User Interface  d) Runs its action
**Answer: d) Runs its action**

**9. (Sub lesson 2) Menus should be what?**
a) Clear and easy to follow  b) Icons, cursors and buttons  c) Graphical User Interface  d) A small picture representing something
**Answer: a) Clear and easy to follow**

**10. (Sub lesson 2) The guide's GUI objects include what?**
a) Graphical User Interface  b) Icons, cursors and buttons  c) A small picture representing something  d) Where the pointer is
**Answer: b) Icons, cursors and buttons**
