# Graphical User Interfaces and Interactive Menus — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) GUI stands for what?**
**Answer: Graphical User Interface**

**2. (Sub lesson 1) What is an icon?**
**Answer: A small picture representing something**

**3. (Sub lesson 1) What does the cursor show?**
**Answer: Where the pointer is**

**4. (Sub lesson 1) A button is pressed to do what?**
**Answer: Start an action**

**5. (Sub lesson 1) A GUI replaces typing what?**
**Answer: Text commands**

**6. (Sub lesson 2) A menu offers what?**
**Answer: A list of choices**

**7. (Sub lesson 2) Interactive means what?**
**Answer: The system responds to the user**

**8. (Sub lesson 2) Choosing a menu item does what?**
**Answer: Runs its action**

**9. (Sub lesson 2) Menus should be what?**
**Answer: Clear and easy to follow**

**10. (Sub lesson 2) The guide's GUI objects include what?**
**Answer: Icons, cursors and buttons**
