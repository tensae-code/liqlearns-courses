# Unix and Mac Operating Systems — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Unix and the Macintosh system**
**Answer: True**

**2. (Sub lesson 1) True or false: By the command line** — as the answer to: What is Unix built for?
**Answer: False — Many users and many tasks at once on one machine**

**3. (Sub lesson 1) True or false: By the command line**
**Answer: True**

**4. (Sub lesson 1) True or false: Linux** — as the answer to: What is Unix famous for?
**Answer: False — Stability on servers and large machines**

**5. (Sub lesson 1) True or false: Linux**
**Answer: True**

**6. (Sub lesson 2) True or false: Apple's — for its own computers** — as the answer to: Name two Unix ideas in modern systems.
**Answer: False — Files in a tree, and permissions for each user**

**7. (Sub lesson 2) True or false: Apple's — for its own computers**
**Answer: True**

**8. (Sub lesson 2) True or false: The modern Mac system is built on a Unix heart** — as the answer to: What work is the Mac known for?
**Answer: False — Design, publishing, picture and sound work**

**9. (Sub lesson 2) True or false: The modern Mac system is built on a Unix heart**
**Answer: True**

**10. (Sub lesson 2) True or false: Unix and the Macintosh system** — as the answer to: Which source teaches this lesson?
**Answer: False — Laos Grade 7 ICT teacher guide, Activity 16 (teacher guide — evidence)**
