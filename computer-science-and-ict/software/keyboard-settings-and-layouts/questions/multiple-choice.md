# Keyboard Settings and Layouts — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Where are keyboard settings reached from?**
a) Through the Control Panel  b) How long a key must be held before it starts repeating  c) How fast the repeated characters come once repeating starts  d) So an accidental hold does not fill the page with repeated characters
**Answer: a) Through the Control Panel**

**2. (Sub lesson 1) What is the repeat delay?**
a) How fast the repeated characters come once repeating starts  b) How long a key must be held before it starts repeating  c) So an accidental hold does not fill the page with repeated characters  d) Fit the computer to the person, instead of the person struggling with the computer
**Answer: b) How long a key must be held before it starts repeating**

**3. (Sub lesson 1) What is the repeat rate?**
a) So an accidental hold does not fill the page with repeated characters  b) Fit the computer to the person, instead of the person struggling with the computer  c) How fast the repeated characters come once repeating starts  d) The map of a language's letters onto the keys
**Answer: c) How fast the repeated characters come once repeating starts**

**4. (Sub lesson 1) Why does a beginner want a longer repeat delay?**
a) Fit the computer to the person, instead of the person struggling with the computer  b) The map of a language's letters onto the keys  c) Which letters the same keys give — Dari letters in Dari's own arrangement  d) So an accidental hold does not fill the page with repeated characters
**Answer: d) So an accidental hold does not fill the page with repeated characters**

**5. (Sub lesson 1) What do keyboard settings really do?**
a) Fit the computer to the person, instead of the person struggling with the computer  b) The map of a language's letters onto the keys  c) Which letters the same keys give — Dari letters in Dari's own arrangement  d) No — only the map changed
**Answer: a) Fit the computer to the person, instead of the person struggling with the computer**

**6. (Sub lesson 2) What is a keyboard layout?**
a) Which letters the same keys give — Dari letters in Dari's own arrangement  b) The map of a language's letters onto the keys  c) No — only the map changed  d) Which layout is active on the language bar
**Answer: b) The map of a language's letters onto the keys**

**7. (Sub lesson 2) What does the Dari layout change?**
a) No — only the map changed  b) Which layout is active on the language bar  c) Which letters the same keys give — Dari letters in Dari's own arrangement  d) The map — the active layout
**Answer: c) Which letters the same keys give — Dari letters in Dari's own arrangement**

**8. (Sub lesson 2) Did adding a language change the hardware?**
a) Which layout is active on the language bar  b) The map — the active layout  c) Through the Control Panel  d) No — only the map changed
**Answer: d) No — only the map changed**

**9. (Sub lesson 2) The wrong letters appear — what is the first check?**
a) Which layout is active on the language bar  b) The map — the active layout  c) Through the Control Panel  d) How long a key must be held before it starts repeating
**Answer: a) Which layout is active on the language bar**

**10. (Sub lesson 2) What do you switch when letters are wrong — the keyboard or the map?**
a) Through the Control Panel  b) The map — the active layout  c) How long a key must be held before it starts repeating  d) How fast the repeated characters come once repeating starts
**Answer: b) The map — the active layout**
