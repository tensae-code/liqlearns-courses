# Keyboard Settings and Layouts — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Where are keyboard settings reached from?" is: Through the Control Panel**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is the repeat delay?" is: How fast the repeated characters come once repeating starts**
**Answer: False** — How long a key must be held before it starts repeating

**3. (Sub lesson 1) True or false: the answer to "What is the repeat rate?" is: How fast the repeated characters come once repeating starts**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Why does a beginner want a longer repeat delay?" is: Fit the computer to the person, instead of the person struggling with the computer**
**Answer: False** — So an accidental hold does not fill the page with repeated characters

**5. (Sub lesson 1) True or false: the answer to "What do keyboard settings really do?" is: Fit the computer to the person, instead of the person struggling with the computer**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is a keyboard layout?" is: Which letters the same keys give — Dari letters in Dari's own arrangement**
**Answer: False** — The map of a language's letters onto the keys

**7. (Sub lesson 2) True or false: the answer to "What does the Dari layout change?" is: Which letters the same keys give — Dari letters in Dari's own arrangement**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Did adding a language change the hardware?" is: Which layout is active on the language bar**
**Answer: False** — No — only the map changed

**9. (Sub lesson 2) True or false: the answer to "The wrong letters appear — what is the first check?" is: Which layout is active on the language bar**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What do you switch when letters are wrong — the keyboard or the map?" is: Through the Control Panel**
**Answer: False** — The map — the active layout
