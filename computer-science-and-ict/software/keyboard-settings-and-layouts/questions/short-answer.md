# Keyboard Settings and Layouts — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) Where are keyboard settings reached from?**
**Answer: Through the Control Panel**

**2. (Sub lesson 1) What is the repeat delay?**
**Answer: How long a key must be held before it starts repeating**

**3. (Sub lesson 1) What is the repeat rate?**
**Answer: How fast the repeated characters come once repeating starts**

**4. (Sub lesson 1) Why does a beginner want a longer repeat delay?**
**Answer: So an accidental hold does not fill the page with repeated characters**

**5. (Sub lesson 1) What do keyboard settings really do?**
**Answer: Fit the computer to the person, instead of the person struggling with the computer**

**6. (Sub lesson 2) What is a keyboard layout?**
**Answer: The map of a language's letters onto the keys**

**7. (Sub lesson 2) What does the Dari layout change?**
**Answer: Which letters the same keys give — Dari letters in Dari's own arrangement**

**8. (Sub lesson 2) Did adding a language change the hardware?**
**Answer: No — only the map changed**

**9. (Sub lesson 2) The wrong letters appear — what is the first check?**
**Answer: Which layout is active on the language bar**

**10. (Sub lesson 2) What do you switch when letters are wrong — the keyboard or the map?**
**Answer: The map — the active layout**
