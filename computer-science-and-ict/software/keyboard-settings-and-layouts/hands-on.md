# Hands-on — Keyboard Settings and Layouts

The lesson with your hands and your feet, not only your eyes.

## Set it for a beginner
Open the keyboard settings (or describe them from the picture). Set the repeat delay and rate as you would for a young beginner, and say why. Then set them for an expert typist and say what changed.

## Name that layout
Type the same row of keys under two layouts on a real computer (or from layout maps on paper). Write out what each layout gave, and state in one sentence what a layout is.
