# Video script — Keyboard Settings and Layouts

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

The keyboard has **settings** of its own, reached through the Control Panel.
They govern behaviour such as the **repeat delay** — how long a key must be held before it starts repeating — and the **repeat rate** — how fast the repeated characters then come — and how fast the cursor blinks.
These are set once, to suit the typist: a beginner wants a longer delay so an accidental hold does not fill the page, while a fast typist wants a short delay and a fast rate.
Settings are the computer fitting itself to the person, not the person struggling with the computer.
The **layout** decides which character each key gives.
A layout is the map of a language's letters onto the keys: the English layout puts the letters where the key tops show them, while the Dari layout the book added earlier puts Dari letters on the same keys in Dari's own arrangement.
That is why adding a language changed what the keys type without changing any hardware — only the map changed.
The lesson's rule: when the wrong letters appear, nothing is broken — check which layout is active on the language bar, and switch the map, not the keyboard.
