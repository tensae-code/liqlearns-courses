# Right-Click Shortcut Menus — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does a right-click open?" is: A shortcut menu**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is a shortcut menu?" is: Arranging the desktop itself**
**Answer: False** — A short list of orders that belong to the thing you clicked

**3. (Sub lesson 1) True or false: the answer to "What does right-clicking the desktop give?" is: The desktop menu**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is the desktop menu for?" is: The menu for the computer itself and its drives**
**Answer: False** — Arranging the desktop itself

**5. (Sub lesson 1) True or false: the answer to "What does right-clicking a file or folder give?" is: A menu of orders that act on that file or folder**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does right-clicking This PC open?" is: It is restored or removed for good**
**Answer: False** — The menu for the computer itself and its drives

**7. (Sub lesson 2) True or false: the answer to "Where do deleted files wait?" is: In the Recycle Bin**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What can happen to a file in the Recycle Bin?" is: Right-click a thing to see what you can do with it**
**Answer: False** — It is restored or removed for good

**9. (Sub lesson 2) True or false: the answer to "What does right-clicking the taskbar open?" is: The taskbar menu**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What one habit serves everywhere?" is: A short list of orders that belong to the thing you clicked**
**Answer: False** — Right-click a thing to see what you can do with it
