# Hands-on — The Start Menu and Its Options

The lesson with your hands, on a real Windows 7 computer where one is available — the book's own split: theory in class, hands-on in the lab.

## Read the menu
Open the Start menu. Write down everything on the left side, then everything on the right side. Beside each name, write one line: what opens when you click it.

## Two ways to the same program
Pick one program that is not pinned. Reach it first through All Programs, folder by folder. Close the menu, open it again, and reach the same program by typing its name in the search box. Which way was faster — and which way works when you do not know the name?

## The arrow drill
Without clicking the final choice, open the arrow beside Shut down five times. Each time, name a situation out loud first — "I am leaving for five minutes, my work stays open" — then point to the option that fits. Lock, log off, switch user, restart, sleep: one real situation for each.
