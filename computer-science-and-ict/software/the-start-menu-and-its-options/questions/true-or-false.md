# The Start Menu and Its Options — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) The search box sits at the bottom of the Start menu's left side.**
**Answer: True** — It waits under the programs on the left.

**2. (Sub lesson 1) Control Panel is found on the left side of the Start menu, among the programs.**
**Answer: False** — Control Panel is a place, on the right side.

**3. (Sub lesson 2) Log off closes your session but leaves the computer on for the next person.**
**Answer: True**

**4. (Sub lesson 2) Switch user closes all of the first user's programs.**
**Answer: False** — Switch user keeps the first user's programs open, untouched.
