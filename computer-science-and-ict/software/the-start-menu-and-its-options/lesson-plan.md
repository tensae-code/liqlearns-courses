# Lesson plan — The Start Menu and Its Options

**Course:** Computer Science and ICT · **Title:** Software · **Lesson:** The Start Menu and Its Options
**Place in the curriculum:** ICT expansion — Eritrea (2026-11-14) — in the title Software on the ICT course ladder (TITLES.md). Built new from Eritrea's *Information and Communications Technology for Grade 8 — Textbook*, because no existing lesson teaches this thing as its own lesson.
**The one thing this lesson teaches:** In Windows 7, the Start menu is the main door to everything on the computer: click Start and its left side lists your programs — with All Programs opening the full list — its right side lists your places (your folders, Computer, Control Panel, Help and Support), a search box sits at the bottom, and beside the Shut down button an arrow holds the other session options: switch user, log off, lock, restart and sleep.
**This lesson's own level:** It stands on switching a Windows computer on and using a mouse and keyboard; everything else — every part of the menu and every option on it — is built inside the lesson, in Windows 7, the system Eritrea's book teaches.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. ## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Opening the Start menu and reading its two sides** — Three ways to open it — click the Start button in the bottom-left corner, press the Windows key, or press Ctrl+Esc — and how to read what opens: the left side is programs (pinned programs at the top, programs you used recently below them, All Programs at the bottom); the right side is your places — your name and picture at the top, then Documents, Pictures, Music, Computer, Control Panel and Help and Support; the search box waits at the bottom left.
2. **The options: All Programs, search, and the arrow beside Shut down** — All Programs opens the full list of everything installed, in folders; the search box finds a program or file when you type its first letters; the Shut down button switches the computer off properly — and the small arrow beside it holds the rest: Switch user (another person signs in without closing your work), Log off (your session closes, the computer stays on), Lock (your work stays open behind your password), Restart (off and on again) and Sleep (a low-power pause that wakes fast).

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## What the learner can do when it ends
1. Open the Start menu three ways: the Start button, the Windows key, and Ctrl+Esc.
2. Name what the left side of the menu holds (programs, All Programs, the search box) and what the right side holds (your places: Documents, Pictures, Music, Computer, Control Panel, Help and Support).
3. Find a program that is not pinned or recent, by opening All Programs and by typing in the search box.
4. Use the arrow beside Shut down to choose the right session option — switch user, log off, lock, restart, sleep — and say how each differs from shutting down.

## What you need
A computer running Windows 7 for the hands-on work (the book's own system). On paper first: a pencil and a drawn copy of the menu are enough to learn its parts.

## If the learner is stuck
Clicks Start and hunts blindly → stop and read the menu's own map: programs left, places right, search at the bottom. Confuses Lock with Log off → Lock keeps your work open behind a password; Log off closes your session but leaves the computer on for the next person. Reaches for the power button on the box → the Shut down button in the menu is the proper off: it closes everything in order first.
