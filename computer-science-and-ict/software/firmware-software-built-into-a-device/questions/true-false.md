# Firmware — Software Built into a Device — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is firmware?" is: Software stored permanently inside a device, telling its hardware how to start and do its basic work**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Where is firmware stored?" is: It checks the hardware and hands over to the operating system**
**Answer: False** — In the device's ROM, inside the device itself

**3. (Sub lesson 1) True or false: the answer to "Why is it called firm?" is: It sits between soft software, which changes easily, and hard hardware, which does not change**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Which programs are firmware besides the computer's start-up?" is: Rarely — it is rarely seen and rarely changed**
**Answer: False** — The controlling programs inside devices such as a washing machine, a router or a printer

**5. (Sub lesson 1) True or false: the answer to "What does a computer's firmware do at start-up?" is: It checks the hardware and hands over to the operating system**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "When does firmware work?" is: A device that may not start at all**
**Answer: False** — At moments other software cannot — starting and controlling the device

**7. (Sub lesson 2) True or false: the answer to "How often is firmware changed?" is: Rarely — it is rarely seen and rarely changed**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How must a firmware update be done?" is: Software stored permanently inside a device, telling its hardware how to start and do its basic work**
**Answer: False** — Carefully

**9. (Sub lesson 2) True or false: the answer to "What can a damaged firmware cause?" is: A device that may not start at all**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "How long does a device's firmware serve?" is: It sits between soft software, which changes easily, and hard hardware, which does not change**
**Answer: False** — For the device's whole life
