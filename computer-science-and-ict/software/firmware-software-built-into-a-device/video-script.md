---

**Firmware** is software stored **permanently inside a device** — in its ROM — that tells the hardware how to start and how to do its basic work. The computer's start-up program is firmware; so is the controlling program inside a washing machine, a router or a printer. It is called *firm* because it sits between soft software, which changes easily, and hard hardware, which does not change at all.
Firmware works at the moments other software cannot: it **starts the machine** — checking the hardware and handing over to the operating system — and it **controls a device's built-in job** for the device's whole life. It is rarely seen and rarely changed; when it is updated, the update is done carefully, because a device whose firmware is damaged may not start at all.
