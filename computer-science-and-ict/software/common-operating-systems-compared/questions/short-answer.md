# Common Operating Systems Compared — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does this lesson compare?**
**Answer: The common operating systems, by what each is and where it is used**

**2. (Sub lesson 1) Name the system of most school and office PCs.**
**Answer: Microsoft Windows**

**3. (Sub lesson 1) What is Linux?**
**Answer: A free, open operating system found on servers, school machines and programmers' computers**

**4. (Sub lesson 1) Do different operating systems do different manager's jobs?**
**Answer: No — all start the machine, run programs and manage files and devices**

**5. (Sub lesson 1) So what is the comparison really about?**
**Answer: Which system fits which job and place**

**6. (Sub lesson 2) Name one thing systems are compared on.**
**Answer: What machines they run on (any one of: cost, openness, programs and support)**

**7. (Sub lesson 2) Which named system is free?**
**Answer: Linux**

**8. (Sub lesson 2) What may be done with open-source code?**
**Answer: It may be studied and altered**

**9. (Sub lesson 2) Can the right answer differ by place?**
**Answer: Yes — a school lab, a server and a home computer may each fit a different system**

**10. (Sub lesson 2) What skill is Libya teaching by comparing, not listing?**
**Answer: Judgement — choosing the system that fits**
