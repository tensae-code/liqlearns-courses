# Working with the Start Menu — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Where is the Start button?" is: At the left end of the taskbar**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What else opens the Start menu?" is: The full list of everything installed on the computer**
**Answer: False** — The Windows key on the keyboard

**3. (Sub lesson 1) True or false: the answer to "What does All Programs open?" is: The full list of everything installed on the computer**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does Windows keep above the program list?" is: The program opens and the menu closes itself behind it**
**Answer: False** — The programs you use most, one click away

**5. (Sub lesson 1) True or false: the answer to "What happens to the Start menu when you click a program?" is: The program opens and the menu closes itself behind it**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does the menu's right side reach?" is: Ending your session while leaving the computer on for the next person**
**Answer: False** — Your documents and drives, Control Panel, Help and Search

**7. (Sub lesson 2) True or false: the answer to "What is Log Off for?" is: Ending your session while leaving the computer on for the next person**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is Turn Off Computer for?" is: Windows must close every program and save its own work first**
**Answer: False** — Shutting Windows down safely

**9. (Sub lesson 2) True or false: the answer to "Why not just pull the power out?" is: Windows must close every program and save its own work first**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What are the Start menu's two leaving buttons?" is: At the left end of the taskbar**
**Answer: False** — Log Off and Turn Off Computer
