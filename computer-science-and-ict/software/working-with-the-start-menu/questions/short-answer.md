# Working with the Start Menu — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) Where is the Start button?**
**Answer: At the left end of the taskbar**

**2. (Sub lesson 1) What else opens the Start menu?**
**Answer: The Windows key on the keyboard**

**3. (Sub lesson 1) What does All Programs open?**
**Answer: The full list of everything installed on the computer**

**4. (Sub lesson 1) What does Windows keep above the program list?**
**Answer: The programs you use most, one click away**

**5. (Sub lesson 1) What happens to the Start menu when you click a program?**
**Answer: The program opens and the menu closes itself behind it**

**6. (Sub lesson 2) What does the menu's right side reach?**
**Answer: Your documents and drives, Control Panel, Help and Search**

**7. (Sub lesson 2) What is Log Off for?**
**Answer: Ending your session while leaving the computer on for the next person**

**8. (Sub lesson 2) What is Turn Off Computer for?**
**Answer: Shutting Windows down safely**

**9. (Sub lesson 2) Why not just pull the power out?**
**Answer: Windows must close every program and save its own work first**

**10. (Sub lesson 2) What are the Start menu's two leaving buttons?**
**Answer: Log Off and Turn Off Computer**
