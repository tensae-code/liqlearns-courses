# Working with the Start Menu — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Where is the Start button?**
a) At the left end of the taskbar  b) The Windows key on the keyboard  c) The full list of everything installed on the computer  d) The programs you use most, one click away
**Answer: a) At the left end of the taskbar**

**2. (Sub lesson 1) What else opens the Start menu?**
a) The full list of everything installed on the computer  b) The Windows key on the keyboard  c) The programs you use most, one click away  d) The program opens and the menu closes itself behind it
**Answer: b) The Windows key on the keyboard**

**3. (Sub lesson 1) What does All Programs open?**
a) The programs you use most, one click away  b) The program opens and the menu closes itself behind it  c) The full list of everything installed on the computer  d) Your documents and drives, Control Panel, Help and Search
**Answer: c) The full list of everything installed on the computer**

**4. (Sub lesson 1) What does Windows keep above the program list?**
a) The program opens and the menu closes itself behind it  b) Your documents and drives, Control Panel, Help and Search  c) Ending your session while leaving the computer on for the next person  d) The programs you use most, one click away
**Answer: d) The programs you use most, one click away**

**5. (Sub lesson 1) What happens to the Start menu when you click a program?**
a) The program opens and the menu closes itself behind it  b) Your documents and drives, Control Panel, Help and Search  c) Ending your session while leaving the computer on for the next person  d) Shutting Windows down safely
**Answer: a) The program opens and the menu closes itself behind it**

**6. (Sub lesson 2) What does the menu's right side reach?**
a) Ending your session while leaving the computer on for the next person  b) Your documents and drives, Control Panel, Help and Search  c) Shutting Windows down safely  d) Windows must close every program and save its own work first
**Answer: b) Your documents and drives, Control Panel, Help and Search**

**7. (Sub lesson 2) What is Log Off for?**
a) Shutting Windows down safely  b) Windows must close every program and save its own work first  c) Ending your session while leaving the computer on for the next person  d) Log Off and Turn Off Computer
**Answer: c) Ending your session while leaving the computer on for the next person**

**8. (Sub lesson 2) What is Turn Off Computer for?**
a) Windows must close every program and save its own work first  b) Log Off and Turn Off Computer  c) At the left end of the taskbar  d) Shutting Windows down safely
**Answer: d) Shutting Windows down safely**

**9. (Sub lesson 2) Why not just pull the power out?**
a) Windows must close every program and save its own work first  b) Log Off and Turn Off Computer  c) At the left end of the taskbar  d) The Windows key on the keyboard
**Answer: a) Windows must close every program and save its own work first**

**10. (Sub lesson 2) What are the Start menu's two leaving buttons?**
a) At the left end of the taskbar  b) Log Off and Turn Off Computer  c) The Windows key on the keyboard  d) The full list of everything installed on the computer
**Answer: b) Log Off and Turn Off Computer**
