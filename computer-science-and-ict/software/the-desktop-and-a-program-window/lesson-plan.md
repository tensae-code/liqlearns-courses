# Lesson plan — The Desktop and a Program Window

**Course:** Computer Science and ICT · **Title:** Software · **Lesson:** The Desktop and a Program Window
**Place in the curriculum:** ICT expansion — Azerbaijan (2026-11-14) — in the title Software on the ICT course ladder (TITLES.md). Built new from Azerbaijan's *İnformatika 2, Grade 2*, because no existing lesson teaches this thing as its own lesson at this level.
**The one thing this lesson teaches:** When a computer starts, the screen shows the desktop — the computer's main work surface — and each program you open appears in its own window on that desktop.
**This lesson's own level:** Grade 2 simple — it stands on the child's own everyday world and on the lessons named below; every new word is built inside the lesson from things the child can do at once.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Before this lesson
- Recommended first: Computer Hardware and Keyboard and Mouse in the course. Recommended, never forced — a learner may land on this lesson directly, and it stands alone. It is kept separate from Cambodia's The Desktop and Windows of an Operating System, which teaches an operating system's desktop and window management for Grade 10; this is the Grade 2 first naming of the desktop and one program window.

## What the learner can do when it ends
1. Say what the desktop is and what sits on it.
2. Say what a program window is, and point to its title bar.
3. Tell the desktop apart from a window, and say what happens when a window is closed.

## What you need
A computer to switch on and look at, or a large picture of a desktop with an open window. A computer is used for looking in this lesson; the naming can be done from the picture.

## The run of the lesson (in order)
1. **Do it first** — Look at a switched-on computer screen before any program is opened: the icons sit on a surface, like papers on a desk. That surface is the desktop. Open a program and it appears inside a frame — a window. This lesson names both. (lesson/lesson.md).

## If the learner is stuck
Calls the whole screen 'the window' → cover the open window with a hand: what is underneath is the desktop; the framed part is the window. Thinks closing a window switches the computer off → close it and show the desktop still there, ready.
