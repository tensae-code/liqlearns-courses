# The Desktop and a Program Window — multiple choice

Pick the one right answer.

**1. The desktop is —**
a) a program  b) the computer's main surface, where icons sit  c) a window's bar
**Answer: b) the computer's main surface, where icons sit** — Like the top of a school desk.

**2. A program you open appears in —**
a) a window  b) the keyboard  c) a folder only
**Answer: a) a window** — A framed area where that program's work happens.

**3. The top bar of a window —**
a) names the program  b) is the desktop  c) closes the computer
**Answer: a) names the program** — The title bar tells which program's window it is.

**4. When you close a window —**
a) the computer breaks  b) the desktop is there underneath  c) all icons vanish forever
**Answer: b) the desktop is there underneath** — Closing a window is not switching off.
