# The Desktop and a Program Window — true or false

Say whether each statement is true or false.

**1. Icons sit on the desktop.**
**Answer: True** — Small pictures standing for programs and files.

**2. The desktop is one program's window.**
**Answer: False** — The desktop is the surface; windows open on it.

**3. More than one window can be open on one desktop.**
**Answer: True** — Each program has its own window.
