**Acceptance count: taught in 3 countries (Azerbaijan, Yemen, Uzbekistan).**

Yemen's own way (Grade 10): a skills ladder — every unit alternates short teaching topics with a named تدريب (guided training) and نشاط (activity), and Windows itself is taught as a school subject for a full unit before any application is opened.

Overlap note: kept separate from software/the-desktop-and-windows-of-an-operating-system (Cambodia, Grade 10) — that lesson teaches an operating system's desktop for older learners; this is the Grade 2 first naming of the desktop and one program window.

Placement choice: this lesson was built new for the ICT expansion (Azerbaijan, 2026-11-14) because no existing lesson in the course covers this thing as its own lesson at this Grade 2 level — the live tree was checked first, including the overlap watches named in the merger brief. The placements file named this slug directly (NEW LESSON NEEDED — software/the-desktop-and-a-program-window). It sits in the Software title (software/), where the placements file placed it. It is one whole lesson with no sub lessons — a small Grade 2 lesson running straight through.

Azerbaijan's own way: informatics starts two full years before touching a computer — objects and their features, information in everyday life, and algorithms as daily-life sequences and true/false judgements; the computer itself, WordPad, Paint and Calculator arrive only in the final unit. This lesson keeps that order and that Grade 2 voice.


Uzbekistan's own way (Grade 5): informatics opens with a full lesson of safety and hygiene before the machine is even described, and Paint gets five of the seventeen lessons — drawing is the grade-5 child's main creative tool, with keyboard training on a typing trainer in between. The Boltaev-team informatics line runs from keyboard trainers and Paint in Grades 5–6 to a full Pascal course in Grades 8–9; this book is its Russian-language edition.
