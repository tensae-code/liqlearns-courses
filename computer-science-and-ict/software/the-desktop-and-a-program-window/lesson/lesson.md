# The Desktop and a Program Window

## Do it first

Look at a switched-on computer screen before any program is opened: the icons sit on a surface, like papers on a desk. That surface is the desktop. Open a program and it appears inside a frame — a window. This lesson names both.

## The Desktop and a Program Window

When the computer is switched on and ready, the screen shows the **desktop** — the main surface of the computer, like the top of a school desk. On the desktop sit **icons**: small pictures, each one standing for a program or a file, waiting to be opened.

Open a program and it appears in a **window**: a framed area of the screen where that program's work happens. The window has a top bar that names the program, and the work of the program fills the space under it. A window can be closed when the work is done, and the desktop is there again underneath.

One desktop can hold more than one window: open two programs and each has its own window. The desktop is the desk; each window is like one exercise book opened on it. Knowing which surface is the desktop and which frame is a program's window is the first map of the computer screen — every program in this unit opens in a window on the desktop.

## Say it to your companion

Tell your companion, in your own words: When a computer starts, the screen shows the desktop — the computer's main work surface — and each program you open appears in its own window on that desktop. Then let your companion ask you one question about it — and answer from the lesson, not from memory of the book's exact words.

## Do It Yourself

1. Show it, don't just say it: say what the desktop is and what sits on it.
2. Show it, don't just say it: say what a program window is, and point to its title bar.
3. Show it, don't just say it: tell the desktop apart from a window, and say what happens when a window is closed.
