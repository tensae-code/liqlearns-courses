# Types of Operating Systems — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: It collects jobs and runs them in groups, without interaction**
**Answer: True**

**2. (Sub lesson 1) True or false: It collects jobs and runs them in groups, without interaction** — as the answer to: How does time-sharing give each user the machine?
**Answer: False — It slices the processor's time among many interactive users, so each feels alone**

**3. (Sub lesson 1) True or false: An answer within a strict deadline**
**Answer: True**

**4. (Sub lesson 1) True or false: An answer within a strict deadline** — as the answer to: Why is a late answer a wrong answer in real-time systems?
**Answer: False — They control planes, medical devices and robots — acting late can be acting wrongly**

**5. (Sub lesson 1) True or false: Operating systems before it (§12) and the history of operating systems after it (§14)**
**Answer: True**

**6. (Sub lesson 2) True or false: Operating systems before it (§12) and the history of operating systems after it (§14)** — as the answer to: What separates single-user from multi-user systems?
**Answer: False — How many people the system serves at once — one, or many**

**7. (Sub lesson 2) True or false: One hidden inside an appliance or vehicle, running one dedicated job**
**Answer: True**

**8. (Sub lesson 2) True or false: One hidden inside an appliance or vehicle, running one dedicated job** — as the answer to: What extra cares does a mobile system have?
**Answer: False — Touch input, sensors and battery care**

**9. (Sub lesson 2) True or false: Yes — a phone's system is single-user, mobile and time-sharing together**
**Answer: True**

**10. (Sub lesson 2) True or false: Yes — a phone's system is single-user, mobile and time-sharing together** — as the answer to: Which type is a school server's system?
**Answer: False — Multi-user (and usually time-sharing)**
