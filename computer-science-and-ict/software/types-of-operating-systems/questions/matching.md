# Types of Operating Systems — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) How does a batch system handle jobs?** → **It collects jobs and runs them in groups, without interaction**

**2. (Sub lesson 1) How does time-sharing give each user the machine?** → **It slices the processor's time among many interactive users, so each feels alone**

**3. (Sub lesson 1) What does a real-time system guarantee?** → **An answer within a strict deadline**

**4. (Sub lesson 1) Why is a late answer a wrong answer in real-time systems?** → **They control planes, medical devices and robots — acting late can be acting wrongly**

**5. (Sub lesson 1) In Armenia's Grade 9 book, what surrounds the types lesson?** → **Operating systems before it (§12) and the history of operating systems after it (§14)**

**6. (Sub lesson 2) What separates single-user from multi-user systems?** → **How many people the system serves at once — one, or many**

**7. (Sub lesson 2) What is an embedded operating system?** → **One hidden inside an appliance or vehicle, running one dedicated job**

**8. (Sub lesson 2) What extra cares does a mobile system have?** → **Touch input, sensors and battery care**

**9. (Sub lesson 2) Can one system belong to several types at once?** → **Yes — a phone's system is single-user, mobile and time-sharing together**

**10. (Sub lesson 2) Which type is a school server's system?** → **Multi-user (and usually time-sharing)**
