## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The desktop — the starting screen** — The **desktop** is the working surface the computer shows after start-up, before any program is opened. It holds the background picture, the taskbar along the bottom with the Start button, and the shortcuts you use most. Managing the desktop means keeping it tidy and reachable: the things you open every day sit on it, and everything else lives in folders where it can be found.
2. **Icons — pictures that open things** — An **icon** is a small picture that stands for a program, a file or a folder. Double-clicking an icon opens the thing it stands for; a small arrow on an icon marks it as a **shortcut**, a pointer to the real thing, which stays safely in its folder. Icons can be moved, arranged and renamed, and deleting a shortcut never deletes the real program or file behind it.
