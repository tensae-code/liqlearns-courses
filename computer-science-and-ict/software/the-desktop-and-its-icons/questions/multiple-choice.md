# The Desktop and Its Icons — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is the desktop?**
a) The screen the computer shows after start-up, before any program opens  b) The taskbar, with the Start button  c) As soon as the computer has finished starting  d) The icon is a shortcut — a pointer to the real thing
**Answer: a) The screen the computer shows after start-up, before any program opens**

**2. (Sub lesson 1) What sits along the bottom of the desktop?**
a) The background picture and the shortcuts you use most  b) The taskbar, with the Start button  c) A small picture that stands for a program, a file or a folder  d) Only the pointer goes — the real program or file stays
**Answer: b) The taskbar, with the Start button**

**3. (Sub lesson 1) What else does the desktop hold?**
a) Keeping it tidy, with everyday things on it and the rest in folders  b) Double-click the icon  c) The background picture and the shortcuts you use most  d) Move them, arrange them and rename them
**Answer: c) The background picture and the shortcuts you use most**

**4. (Sub lesson 1) What does managing the desktop mean?**
a) As soon as the computer has finished starting  b) The icon is a shortcut — a pointer to the real thing  c) The screen the computer shows after start-up, before any program opens  d) Keeping it tidy, with everyday things on it and the rest in folders
**Answer: d) Keeping it tidy, with everyday things on it and the rest in folders**

**5. (Sub lesson 1) When do you see the desktop?**
