# The Desktop and Its Icons — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is the desktop?" is: The screen the computer shows after start-up, before any program opens**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What sits along the bottom of the desktop?" is: The background picture and the shortcuts you use most**
**Answer: False** — The taskbar, with the Start button

**3. (Sub lesson 1) True or false: the answer to "What else does the desktop hold?" is: The background picture and the shortcuts you use most**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does managing the desktop mean?" is: As soon as the computer has finished starting**
**Answer: False** — Keeping it tidy, with everyday things on it and the rest in folders

**5. (Sub lesson 1) True or false: the answer to "When do you see the desktop?" is: As soon as the computer has finished starting**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is an icon?" is: Double-click the icon**
**Answer: False** — A small picture that stands for a program, a file or a folder

**7. (Sub lesson 2) True or false: the answer to "How do you open the thing an icon stands for?" is: Double-click the icon**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does a small arrow on an icon mean?" is: Only the pointer goes — the real program or file stays**
**Answer: False** — The icon is a shortcut — a pointer to the real thing

**9. (Sub lesson 2) True or false: the answer to "What happens if you delete a shortcut icon?" is: Only the pointer goes — the real program or file stays**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What can you do with icons on the desktop?" is: The screen the computer shows after start-up, before any program opens**
**Answer: False** — Move them, arrange them and rename them
