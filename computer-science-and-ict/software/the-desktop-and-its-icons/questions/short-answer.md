# The Desktop and Its Icons — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is the desktop?**
**Answer: The screen the computer shows after start-up, before any program opens**

**2. (Sub lesson 1) What sits along the bottom of the desktop?**
**Answer: The taskbar, with the Start button**

**3. (Sub lesson 1) What else does the desktop hold?**
**Answer: The background picture and the shortcuts you use most**

**4. (Sub lesson 1) What does managing the desktop mean?**
**Answer: Keeping it tidy, with everyday things on it and the rest in folders**

**5. (Sub lesson 1) When do you see the desktop?**
**Answer: As soon as the computer has finished starting**

**6. (Sub lesson 2) What is an icon?**
**Answer: A small picture that stands for a program, a file or a folder**

**7. (Sub lesson 2) How do you open the thing an icon stands for?**
**Answer: Double-click the icon**

**8. (Sub lesson 2) What does a small arrow on an icon mean?**
**Answer: The icon is a shortcut — a pointer to the real thing**

**9. (Sub lesson 2) What happens if you delete a shortcut icon?**
**Answer: Only the pointer goes — the real program or file stays**

**10. (Sub lesson 2) What can you do with icons on the desktop?**
**Answer: Move them, arrange them and rename them**
