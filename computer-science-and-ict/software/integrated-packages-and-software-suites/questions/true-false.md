# Integrated Packages and Software Suites — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is an integrated package?" is: A single program combining the common jobs — word processing, spreadsheet, database, graphics — in one program**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is an integrated package's strength?" is: Depth — each job inside is a lighter version of a dedicated program's work**
**Answer: False** — Sameness — learn one program and every job feels familiar

**3. (Sub lesson 1) True or false: the answer to "What is its limit?" is: Depth — each job inside is a lighter version of a dedicated program's work**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Who is an integrated package for?" is: Easily — the parts share one way of working**
**Answer: False** — Everyday work, not the heaviest professional work

**5. (Sub lesson 1) True or false: the answer to "How does work move inside an integrated package?" is: Easily — the parts share one way of working**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is a software suite?" is: A look, a way of working, and easy movement of work between them**
**Answer: False** — A set of separate, full programs sold and installed together as one product

**7. (Sub lesson 2) True or false: the answer to "What do a suite's programs share?" is: A look, a way of working, and easy movement of work between them**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Are a suite's programs cut-down versions?" is: Microsoft Office**
**Answer: False** — No — each is independent and complete

**9. (Sub lesson 2) True or false: the answer to "Give the standing example class of a suite." is: Microsoft Office**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is Fiji's test for telling the shapes apart?" is: A single program combining the common jobs — word processing, spreadsheet, database, graphics — in one program**
**Answer: False** — Count the programs — one program with several hats is a package; several full programs in one box is a suite
