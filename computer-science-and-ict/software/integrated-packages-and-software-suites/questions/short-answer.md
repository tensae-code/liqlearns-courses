# Integrated Packages and Software Suites — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is an integrated package?**
**Answer: A single program combining the common jobs — word processing, spreadsheet, database, graphics — in one program**

**2. (Sub lesson 1) What is an integrated package's strength?**
**Answer: Sameness — learn one program and every job feels familiar**

**3. (Sub lesson 1) What is its limit?**
**Answer: Depth — each job inside is a lighter version of a dedicated program's work**

**4. (Sub lesson 1) Who is an integrated package for?**
**Answer: Everyday work, not the heaviest professional work**

**5. (Sub lesson 1) How does work move inside an integrated package?**
**Answer: Easily — the parts share one way of working**

**6. (Sub lesson 2) What is a software suite?**
**Answer: A set of separate, full programs sold and installed together as one product**

**7. (Sub lesson 2) What do a suite's programs share?**
**Answer: A look, a way of working, and easy movement of work between them**

**8. (Sub lesson 2) Are a suite's programs cut-down versions?**
**Answer: No — each is independent and complete**

**9. (Sub lesson 2) Give the standing example class of a suite.**
**Answer: Microsoft Office**

**10. (Sub lesson 2) What is Fiji's test for telling the shapes apart?**
**Answer: Count the programs — one program with several hats is a package; several full programs in one box is a suite**
