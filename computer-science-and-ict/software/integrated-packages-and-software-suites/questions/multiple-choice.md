# Integrated Packages and Software Suites — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is an integrated package?**
a) A single program combining the common jobs — word processing, spreadsheet, database, graphics — in one program  b) Sameness — learn one program and every job feels familiar  c) Depth — each job inside is a lighter version of a dedicated program's work  d) Everyday work, not the heaviest professional work
**Answer: a) A single program combining the common jobs — word processing, spreadsheet, database, graphics — in one program**

**2. (Sub lesson 1) What is an integrated package's strength?**
a) Depth — each job inside is a lighter version of a dedicated program's work  b) Sameness — learn one program and every job feels familiar  c) Everyday work, not the heaviest professional work  d) Easily — the parts share one way of working
**Answer: b) Sameness — learn one program and every job feels familiar**

**3. (Sub lesson 1) What is its limit?**
a) Everyday work, not the heaviest professional work  b) Easily — the parts share one way of working  c) Depth — each job inside is a lighter version of a dedicated program's work  d) A set of separate, full programs sold and installed together as one product
**Answer: c) Depth — each job inside is a lighter version of a dedicated program's work**

**4. (Sub lesson 1) Who is an integrated package for?**
a) Easily — the parts share one way of working  b) A set of separate, full programs sold and installed together as one product  c) A look, a way of working, and easy movement of work between them  d) Everyday work, not the heaviest professional work
**Answer: d) Everyday work, not the heaviest professional work**

**5. (Sub lesson 1) How does work move inside an integrated package?**
