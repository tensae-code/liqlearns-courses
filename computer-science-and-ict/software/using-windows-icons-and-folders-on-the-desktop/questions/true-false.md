# Using Windows — Icons and Folders on the Desktop — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is the desktop?" is: The screen Windows shows when it has started — background, taskbar and icons**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is an icon?" is: Double-click the icon**
**Answer: False** — A small labelled picture standing for a program, a file or a folder

**3. (Sub lesson 1) True or false: the answer to "How do you open what an icon stands for?" is: Double-click the icon**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does a small arrow on an icon mean?" is: Only the pointer goes — the real program or file behind it is not deleted**
**Answer: False** — It is a shortcut — a pointer to the real thing, which stays in its place

**5. (Sub lesson 1) True or false: the answer to "What happens if you delete a shortcut icon?" is: Only the pointer goes — the real program or file behind it is not deleted**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is a folder on the desktop?" is: In a class students folder of set files, saved with clear unit-and-name file names**
**Answer: False** — A container that opens as a window showing the files and folders inside it

**7. (Sub lesson 2) True or false: the answer to "How does Fiji's book say work should be kept?" is: In a class students folder of set files, saved with clear unit-and-name file names**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How do you switch between open windows?" is: Closing, minimising and making the window full-screen**
**Answer: False** — From the taskbar

**9. (Sub lesson 2) True or false: the answer to "What are the buttons at a window's top corner for?" is: Closing, minimising and making the window full-screen**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why keep the desktop tidy?" is: The screen Windows shows when it has started — background, taskbar and icons**
**Answer: False** — So the things you use most can be found and opened at once
