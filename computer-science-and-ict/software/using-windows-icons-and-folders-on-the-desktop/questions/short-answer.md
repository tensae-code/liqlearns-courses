# Using Windows — Icons and Folders on the Desktop — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is the desktop?**
**Answer: The screen Windows shows when it has started — background, taskbar and icons**

**2. (Sub lesson 1) What is an icon?**
**Answer: A small labelled picture standing for a program, a file or a folder**

**3. (Sub lesson 1) How do you open what an icon stands for?**
**Answer: Double-click the icon**

**4. (Sub lesson 1) What does a small arrow on an icon mean?**
**Answer: It is a shortcut — a pointer to the real thing, which stays in its place**

**5. (Sub lesson 1) What happens if you delete a shortcut icon?**
**Answer: Only the pointer goes — the real program or file behind it is not deleted**

**6. (Sub lesson 2) What is a folder on the desktop?**
**Answer: A container that opens as a window showing the files and folders inside it**

**7. (Sub lesson 2) How does Fiji's book say work should be kept?**
**Answer: In a class students folder of set files, saved with clear unit-and-name file names**

**8. (Sub lesson 2) How do you switch between open windows?**
**Answer: From the taskbar**

**9. (Sub lesson 2) What are the buttons at a window's top corner for?**
**Answer: Closing, minimising and making the window full-screen**

**10. (Sub lesson 2) Why keep the desktop tidy?**
**Answer: So the things you use most can be found and opened at once**
