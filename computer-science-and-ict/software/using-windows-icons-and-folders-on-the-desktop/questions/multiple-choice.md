# Using Windows — Icons and Folders on the Desktop — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is the desktop?**
a) The screen Windows shows when it has started — background, taskbar and icons  b) A small labelled picture standing for a program, a file or a folder  c) Double-click the icon  d) It is a shortcut — a pointer to the real thing, which stays in its place
**Answer: a) The screen Windows shows when it has started — background, taskbar and icons**

**2. (Sub lesson 1) What is an icon?**
a) Double-click the icon  b) A small labelled picture standing for a program, a file or a folder  c) It is a shortcut — a pointer to the real thing, which stays in its place  d) Only the pointer goes — the real program or file behind it is not deleted
**Answer: b) A small labelled picture standing for a program, a file or a folder**

**3. (Sub lesson 1) How do you open what an icon stands for?**
a) It is a shortcut — a pointer to the real thing, which stays in its place  b) Only the pointer goes — the real program or file behind it is not deleted  c) Double-click the icon  d) A container that opens as a window showing the files and folders inside it
**Answer: c) Double-click the icon**

**4. (Sub lesson 1) What does a small arrow on an icon mean?**
a) Only the pointer goes — the real program or file behind it is not deleted  b) A container that opens as a window showing the files and folders inside it  c) In a class students folder of set files, saved with clear unit-and-name file names  d) It is a shortcut — a pointer to the real thing, which stays in its place
**Answer: d) It is a shortcut — a pointer to the real thing, which stays in its place**

**5. (Sub lesson 1) What happens if you delete a shortcut icon?**

**6. (Sub lesson 2) What is a folder on the desktop?**
