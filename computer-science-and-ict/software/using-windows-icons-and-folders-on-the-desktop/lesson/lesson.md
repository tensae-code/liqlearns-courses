# Using Windows — Icons and Folders on the Desktop

## Do it first

Your desktop is not a wallpaper with pictures on it — it is your workbench. Fiji's Years 7–8 book gives using it a full section: the icons, the folders and the windows you open from it. This lesson teaches working from the desktop as one skill.

## Sub lesson 1 — The desktop and its icons

The **desktop** is the screen Windows shows when it has started: a background, the taskbar, and **icons** — small labelled pictures, each standing for a program, a file or a folder. **Double-clicking** an icon opens the thing it stands for. Icons can be moved and arranged so the things you use most sit where your hand expects them; an icon with a small arrow is a **shortcut**, a pointer — deleting the shortcut never deletes the real thing behind it.

## Sub lesson 2 — Folders and windows from the desktop

A **folder** on the desktop is a container you open like any folder: double-click it and a **window** opens showing what is inside — files and more folders. Working well from the desktop means keeping it like Fiji's class **students folder**: a few clear folders with names that say what they hold, instead of a scatter of loose files. A window is closed, minimised or made full-screen with the buttons at its top corner, and switching between open windows is done from the taskbar — the desktop stays the home you return to.
