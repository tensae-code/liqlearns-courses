# Utilities and language translators — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What does utility software do?
a) Writes letters  b) Analyses, configures, improves and maintains the system  c) Draws pictures  d) Plays music
**Answer: b) Analyses, configures, improves and maintains the system** — utilities keep the system healthy.

**2. (Sub lesson 1)** Which utility keeps a safe copy of your work?
a) Virus protection  b) Backup software  c) Data recovery  d) The translator
**Answer: b) Backup software** — backup keeps the copy before anything is lost.

**3. (Sub lesson 1)** Your file is already lost. Which utility tries to bring it back?
a) Backup  b) Data recovery  c) Virus protection  d) Compiler
**Answer: b) Data recovery** — recovery works after the loss.

**4. (Sub lesson 2)** A language translator converts —
a) letters into numbers  b) programs from one computer language to another  c) pictures into sound  d) files into folders
**Answer: b) programs from one computer language to another** — it converts programs between languages.

**5. (Sub lesson 2)** Compilers are used to —
a) develop programs in different languages  b) clean the keyboard  c) print posters  d) play games
**Answer: a) develop programs in different languages** — compilers and translators develop programs.

**6. (Sub lesson 1)** Virus protection is an example of —
a) application software for letters  b) utility software  c) hardware  d) a storage device
**Answer: b) utility software** — it is one of the book's three utility examples.

**7. (Sub lesson 3)** Disk formatters and disk partition editors belong to —
a) system utilities  b) storage management utilities  c) file management utilities  d) miscellaneous utilities only
**Answer: b) storage management utilities.**

**8. (Sub lesson 4)** Ping and Traceroute are examples of —
a) anti-virus programs  b) disk formatters  c) network utilities  d) data compression
**Answer: c) network utilities** — they monitor, analyse and configure networks.

**9. (Sub lesson 4)** A disk formatter —
a) repairs a broken disk  b) prepares a storage device for first use and erases it permanently  c) copies files to another disk  d) finds viruses
**Answer: b) prepares a storage device for first use and erases it permanently.**
