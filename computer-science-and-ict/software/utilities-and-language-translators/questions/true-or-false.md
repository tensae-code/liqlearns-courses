# Utilities and language translators — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Backup software and data recovery do exactly the same job.
**Answer: False** — backup copies before loss; recovery rescues after loss.

**2. (Sub lesson 1)** Many utility programs are built into the operating system.
**Answer: True** — the teacher guide notes this about utilities.

**3. (Sub lesson 2)** A language translator translates letters for people to read.
**Answer: False** — it converts programs between computer languages.

**4. (Sub lesson 3)** Utility software is included in operating systems and is also available separately, like anti-virus.
**Answer: True** — both routes are named in the book.

**5. (Sub lesson 4)** Formatting a disk leaves its files untouched.
**Answer: False** — a disk formatter prepares the device for first use and erases it permanently.
