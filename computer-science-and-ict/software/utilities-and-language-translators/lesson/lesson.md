# Utilities and language translators

## Do it first

Imagine you wrote a long piece of work — and the file is gone. What could have saved you? A copy kept safe somewhere else. Programs that keep copies, rescue lost work and guard against viruses are this lesson's first subject.

## Keeping the system healthy

Utility software analyses the system, configures it, improves its performance and maintains it. The book's examples: **backup software** keeps a safe copy of your work; **data recovery** tries to bring back lost data; **virus protection** guards the computer against viruses. Many utilities are built into the operating system, ready to help when errors strike.

## Language translators

A language translator converts programs from one computer language to another. It covers compilers and translators — the tools used to develop programs in different languages. Programmers write in a language people can manage; translators turn that into what the machine follows.
