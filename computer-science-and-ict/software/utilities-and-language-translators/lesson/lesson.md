# Utilities and language translators

## Do it first

Imagine you wrote a long piece of work — and the file is gone. What could have saved you? A copy kept safe somewhere else. Programs that keep copies, rescue lost work and guard against viruses are this lesson's first subject.

## Sub lesson 1 — Keeping the system healthy

Utility software analyses the system, configures it, improves its performance and maintains it. The book's examples: **backup software** keeps a safe copy of your work; **data recovery** tries to bring back lost data; **virus protection** guards the computer against viruses. Many utilities are built into the operating system, ready to help when errors strike.

## Sub lesson 2 — Language translators

A language translator converts programs from one computer language to another. It covers compilers and translators — the tools used to develop programs in different languages. Programmers write in a language people can manage; translators turn that into what the machine follows.

## Sub lesson 3 — The four families of utility software

Utility software is system software used to **solve a particular problem of a user**. It is **included in operating systems** and also **available separately — like anti-virus**. It manages the **configuration, performance and maintenance** of the system, and helps with **backup, restore and anti-virus installation**.

Its families are four:

1. **System utilities** — anti-virus, diagnostic programs, network utilities.
2. **Storage management utilities** — backup software, disk formatters, disk partition editors.
3. **File management utilities** — data recovery, data compression, data conversion.
4. **Miscellaneous utilities** — the rest of the toolbox.

## Sub lesson 4 — Utilities explained one by one

Names are not enough — here is what each named utility does.

**System utilities.** **Anti-virus software** gives a virus-free environment: it detects worm, spyware, trojan horse and boot viruses and blocks new ones, and can be set to scan periodically; Avast, McAfee and Norton are the named examples. A **diagnostic program** automatically checks the working state of software, hardware, a whole system or a network, and guides the user to the problem it finds; diagnostics are also built into consumer electronics and games. **Network utilities** monitor, analyse and configure networks — Ping and Traceroute are the common examples.

**Storage management utilities.** **Backup software** copies data and files so loss or accidental deletion can be recovered. A **disk scanner** finds physical and logical disk problems, and is provided by all operating systems. **Disk formatters** prepare a storage device — hard disk, magnetic disk, USB flash — for first use, and in doing so erase it permanently. **Disk partition editors** divide a disk into separately managed regions called partitions — the first step in preparing a new disk, before any file system is created.

**File management utilities.** **Data recovery** fetches data that is inaccessible, lost, corrupted, destroyed or formatted away, when it cannot be reached normally. **Data compression** reduces the bits needed to store or send data — halving a file is a ratio of two — and its two kinds are lossless and lossy. **Data conversion** changes computer data from one format to another.
