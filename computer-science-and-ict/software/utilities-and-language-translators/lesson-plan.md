# Lesson plan — Utilities and language translators

**Course:** Computer Science and ICT · **Title:** Software · **Lesson:** Utilities and language translators
**Place in the curriculum:** Title 3 — Software in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 7 book, Unit 3 — Computer Software. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** utility programs keep the system healthy — backup, data recovery, virus protection — and language translators change programs from one computer language to another.
**This lesson's own level:** it stands on the system-software lesson — utilities are part of that same system side.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved (Sub lessons 1–2 are the Grade 7 depth; Sub lessons 3–4 are the Grade 8 growth of this lesson, added 2026-11-12):

1. **Keeping the system healthy** — utility software analyses, configures, improves and maintains the system; backup, data recovery, virus protection
2. **Language translators** — converting programs from one computer language to another; compilers
3. **The four families of utility software** — system utilities, storage management utilities, file management utilities, and miscellaneous utilities
4. **Utilities explained one by one** — what each named utility actually does: anti-virus, diagnostics, network utilities, backup, disk scanner, disk formatters, partition editors, data recovery, compression, conversion (teacher-guide explanations)

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: System software and the operating system.  Recommended, never forced.

## What the learner can do when it ends
1. Say what utility software does.
2. Name the three example utilities: backup, data recovery, virus protection.
3. Say what a language translator converts, and what compilers are for.
4. Name the four families of utility software, with one example utility in each of the first three.
5. Explain what anti-virus, a disk formatter, a partition editor and data compression each do.

## What you need
Paper and a pencil.

## If the learner is stuck
- Thinks backup and recovery are the same → backup copies BEFORE loss; recovery rescues AFTER loss.
- Thinks translators translate for people → these translate programs between computer languages.
