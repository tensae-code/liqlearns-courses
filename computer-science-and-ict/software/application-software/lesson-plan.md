# Lesson plan — Application software — programs for particular jobs

**Course:** Computer Science and ICT · **Title:** Software · **Lesson:** Application software — programs for particular jobs
**Place in the curriculum:** Title 3 — Software in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 7 book, Unit 3 — Computer Software. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** application software is made for a particular need, and the book names five kinds — word processing, spreadsheets, database management, graphics and presentation software.
**This lesson's own level:** it stands on the system-software lessons — this is the other type, the one the user works with directly.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **What application software is** — end-user software made for a particular need — the programs you work with directly
2. **The five kinds** — word processing, spreadsheets, database management, graphics and presentation software, each with the book's examples
3. **More examples — activities and their programs** — the Grade 8 depth: manipulating text, numbers, audio, graphics or a combination; photo editing, an accounting application, a web browser, a media player, a flight simulator and games
4. **Software inside everyday machines** — traffic lights and ATMs need software to work (teacher-guide discussion, keyed)
5. **One program, a package, a suite** — the Grade 9 depth: application software may be a single program (MS Notepad), a package of programs working together on one task, or a suite — a larger set of related, independent programs sharing a common user interface, such as the Microsoft Office Suite; LibreOffice is the free alternative

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: System software and the operating system.  Recommended, never forced.

## What the learner can do when it ends
1. Say what application software is.
2. Name the five kinds the book gives.
3. Match each kind to its example: Word, Excel, Access, AutoCAD, PowerPoint.
4. Match each kind to a job: letters, payrolls, records, buildings, slides.
5. Name the six Grade 8 example activities and the kind of program each one uses.
6. Answer, with reasons: do traffic lights and ATMs need software to work?
7. Tell apart a single program, a package and a suite, and name the free alternative to MS Office.

## What you need
Paper and a pencil; a computer with any of the named programs if you can look at one.

## If the learner is stuck
- Names programs but not kinds → the kind is the job family: many programs can be word processors; Word is one of them.
- Puts Excel with word processing → spreadsheets calculate in tables; word processors shape text.
