# Application software — programs for particular jobs

## Do it first

Name three different jobs you have seen a computer do — writing a letter, adding up a payroll, showing slides. One program does not do all three. Each job has its own program. Those job programs are this lesson's subject.

## Sub lesson 1 — What application software is

Application software — also called end-user software — is made for a particular need. It is the software you, the user, work with directly: you open it, you do your job in it, you close it when the job is done.

[Picture 10503 — programs for particular jobs]

## Sub lesson 2 — The five kinds

The book names five kinds. **Word processing** creates, edits, formats and saves text — Word, WordPerfect, WordPad — for letters, textbooks, exams and worksheets. **Spreadsheets** calculate and analyse data in tables — Excel, FoxPro — for payrolls and rosters. **Database management** builds data tables, inserts records and answers queries — Access. **Graphics software** creates and edits images — AutoCAD, for buildings, bridges and houses. **Presentation software** shows ideas as slides — PowerPoint.

## Sub lesson 3 — More examples — activities and their programs

Go deeper: an application program is designed to help users **perform an activity** — manipulating **text, numbers, audio, graphics, or a combination of these**. Each program has a specific purpose. The examples to know: **photo editing**, an **accounting application**, a **web browser**, a **media player**, a **flight simulator**, and **games**.

## Sub lesson 4 — Software inside everyday machines

Do traffic lights and ATMs need software to work? **Yes.** A road traffic and safety light system and an Automated Teller Machine both run on **operating systems, storage and other software**. In traffic systems, software sits at several layers — in some systems the controller hardware and software come from the same maker, in others the controller hardware is independent of the software; the named traffic-system software includes **Linsig, Transyt, Corsim/Transyt-7F and Vissim**. The vast majority of ATMs worldwide run a **Microsoft Windows** operating system — chiefly Windows XP Professional or Windows XP Embedded.

## Sub lesson 5 — One program, a package, a suite

Application software comes in three shapes. It may be a **single program** — MS Notepad, for writing and editing simple text. It may be a **package** — a set of programs working together on one task. Or it may be a **suite** — a larger set of related, independent programs sharing a **common user interface**, such as the **Microsoft Office Suite**. Working deeper still: the kinds named for revision are word processing, presentation, spreadsheet, **desktop publishing** and **database management** software — and the frame holding them all is that a computer system is hardware plus software: **application software is what the user works with directly**, while system software (operating system, utilities, device drivers) keeps the hardware working and provides the interface. Beside MS Office stands **LibreOffice**, the free alternative.
