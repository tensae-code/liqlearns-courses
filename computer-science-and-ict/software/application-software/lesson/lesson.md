# Application software — programs for particular jobs

## Do it first

Name three different jobs you have seen a computer do — writing a letter, adding up a payroll, showing slides. One program does not do all three. Each job has its own program. Those job programs are this lesson's subject.

## Sub lesson 1 — What application software is

Application software — also called end-user software — is made for a particular need. It is the software you, the user, work with directly: you open it, you do your job in it, you close it when the job is done.

## Sub lesson 2 — The five kinds

The book names five kinds. **Word processing** creates, edits, formats and saves text — Word, WordPerfect, WordPad — for letters, textbooks, exams and worksheets. **Spreadsheets** calculate and analyse data in tables — Excel, FoxPro — for payrolls and rosters. **Database management** builds data tables, inserts records and answers queries — Access. **Graphics software** creates and edits images — AutoCAD, for buildings, bridges and houses. **Presentation software** shows ideas as slides — PowerPoint.

## Say it to your companion

Tell your companion the five kinds of application software, with one example program and one job for each kind.
