# Hands-on — Application software — programs for particular jobs

The lesson with your hands, not only your eyes.

## Job cards
Write five job cards: a letter to write, a class roster to total, a list of library books to search, a house to draw, a talk to present. Deal each card to the kind of software that should do it, and say why.

## Spot the program
Look at any computer you can use and list the application programs on it. Beside each, write the job it is for.
