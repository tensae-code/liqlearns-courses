# Application software — programs for particular jobs — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** The user works directly with application software.
**Answer: True** — you open it, do your job, close it.

**2. (Sub lesson 2)** FoxPro is named as a spreadsheet example.
**Answer: True** — the book names Excel and FoxPro.

**3. (Sub lesson 2)** WordPad is presentation software.
**Answer: False** — WordPad is word processing.

**4. (Sub lesson 3)** Application software can manipulate a combination of text, numbers, audio and graphics.
**Answer: True** — activities may combine all of these.

**5. (Sub lesson 4)** An ATM works without any software.
**Answer: False** — ATMs run on operating systems, storage and other software.

**6. (Sub lesson 5)** LibreOffice is the free alternative used alongside MS Office.
**Answer: True** — named as the free alternative.

**7. (Sub lesson 5)** Application software is what the user works with directly; system software keeps the hardware working.
**Answer: True** — that is the frame: hardware plus software, the user working with the applications.
