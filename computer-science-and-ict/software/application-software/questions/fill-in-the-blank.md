# Application software — programs for particular jobs — fill in the blank

Fill each blank with the right word.

**1. (Sub lesson 1)** Application software is also called ______ software.
**Answer: end-user**

**2. (Sub lesson 2)** ______ builds data tables, inserts records and answers queries.
**Answer: Database management**

**3. (Sub lesson 2)** Letters, textbooks, exams and worksheets are jobs for ______ processing.
**Answer: word**

**4. (Sub lesson 3)** A ______ simulator is one of the named examples of application software.
**Answer: flight**

**5. (Sub lesson 4)** The vast majority of ATMs run a Microsoft ______ operating system.
**Answer: Windows**

**6. (Sub lesson 5)** A set of programs working together on one task is a ______.
**Answer: package**
