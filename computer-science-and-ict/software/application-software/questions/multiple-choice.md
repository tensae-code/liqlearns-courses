# Application software — programs for particular jobs — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Application software is made for —
a) running the machine only  b) a particular need of the user  c) cleaning the screen  d) starting the computer
**Answer: b) a particular need of the user** — it is end-user software for a particular job.

**2. (Sub lesson 2)** Which kind creates, edits, formats and saves text?
a) Spreadsheets  b) Word processing  c) Graphics  d) Database
**Answer: b) Word processing** — word processing — Word, WordPerfect, WordPad.

**3. (Sub lesson 2)** A payroll is worked out in —
a) a word processor  b) a spreadsheet  c) presentation software  d) graphics software
**Answer: b) a spreadsheet** — spreadsheets calculate data in tables — Excel.

**4. (Sub lesson 2)** Access is the book's example of —
a) database management  b) graphics  c) presentation  d) word processing
**Answer: a) database management** — Access builds tables, inserts records, answers queries.

**5. (Sub lesson 2)** AutoCAD, for buildings and bridges, is —
a) a spreadsheet  b) graphics software  c) a database  d) an operating system
**Answer: b) graphics software** — graphics software creates and edits images.

**6. (Sub lesson 2)** PowerPoint is —
a) presentation software  b) a utility  c) system software  d) a storage device
**Answer: a) presentation software** — presentation software shows ideas as slides.

**7. (Sub lesson 3)** A flight simulator is an example of —
a) an operating system  b) application software  c) a utility  d) hardware
**Answer: b) application software** — a program for a specific activity, one of the six Grade 8 examples.

**8. (Sub lesson 4)** Do traffic lights need software to work?
a) No — they are only lamps and wires  b) Yes — the system runs on operating systems, storage and other software  c) Only at night  d) Only in cities
**Answer: b) Yes — the system runs on operating systems, storage and other software.**
