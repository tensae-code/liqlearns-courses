# Video script — System or application? Telling software apart

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Two kinds of software. How do you tell them apart?

Ask three questions.
What is it for — everything, or one job?
When does it run — always, or only while you use it?
Do you work with it — or does it hide in the background?

Windows: system. Word: application.
Now you can sort them all.
