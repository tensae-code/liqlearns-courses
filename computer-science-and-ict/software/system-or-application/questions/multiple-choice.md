# System or application? Telling software apart — multiple choice

Pick the one right answer.

**1.** System software is —
a) specific purpose  b) general purpose  c) only for letters  d) only for games
**Answer: b) general purpose** — general purpose — it serves the whole machine.

**2.** Application software runs —
a) from power-on to power-off  b) only while the user uses it  c) all night  d) before the computer starts
**Answer: b) only while the user uses it** — it runs while you use it, then you close it.

**3.** Which runs in the background, without the user interacting with it?
a) Word  b) A spreadsheet  c) System software  d) PowerPoint
**Answer: c) System software** — users do not interact with system software directly.

**4.** The book's example pair is —
a) Windows and Word  b) Excel and Access  c) Logo and Word  d) Firefox and Chrome
**Answer: a) Windows and Word** — Windows (system) against Word (application).

**5.** A program for one specific job is —
a) system software  b) application software  c) hardware  d) a utility only
**Answer: b) application software** — specific purpose means application software.

**6.** You always interact with —
a) system software  b) application software  c) the power supply  d) the background
**Answer: b) application software** — application software is the program in front of you.
