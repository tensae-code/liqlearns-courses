# System or application? Telling software apart — true or false

Say whether each sentence is true or false.

**1.** System software runs from power-on to power-off.
**Answer: True** — that is its running-time row in the comparison.

**2.** Users interact directly with system software all day.
**Answer: False** — it runs in the background.

**3.** Word is system software.
**Answer: False** — Word is the book's application example.
