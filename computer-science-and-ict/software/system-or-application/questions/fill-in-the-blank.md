# System or application? Telling software apart — fill in the blank

Fill each blank with the right word.

**1.** System software is ______ purpose; application software is specific purpose.
**Answer: general**

**2.** ______ is the book's system-software example; Word is its application example.
**Answer: Windows**

**3.** System software runs in the ______ while you work.
**Answer: background**
