# System or application? Telling software apart

## Do it first

Two names: Windows and Word. One runs the whole computer. One writes letters. Sort them — which is which — and say how you know. This lesson gives you the book's full comparison, so you can sort any program, not just these two.

## The comparison

**Purpose.** System software is general purpose — it serves the whole machine. Application software is specific purpose — it serves one job. **When it runs.** System software runs from the moment the power goes on until it goes off. Application software runs only while you are using it. **Who meets it.** You do not interact with system software; it runs in the background. With application software, you always interact — it is the program in front of you. **The example pair.** Windows is system software. Word is application software.
