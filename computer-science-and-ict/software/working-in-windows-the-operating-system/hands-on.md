# Hands-on — Working in Windows — the Operating System

The lesson with your hands and your feet, not only your eyes.

## Start and name what you see
Start a computer (or picture one starting). Name the operating system, the first screen you land on, and one program you could open from it.

## Layer cake
Draw three layers — hardware at the bottom, the operating system in the middle, programs and the user on top — and label what each layer does.
