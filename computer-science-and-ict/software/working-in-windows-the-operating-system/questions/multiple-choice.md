# Working in Windows — the Operating System — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is Windows, in the book's teaching?**
a) An operating system  b) System software  c) The machine's parts  d) The desktop
**Answer: a) An operating system**

**2. (Sub lesson 1) What kind of software is an operating system?**
a) When the computer starts  b) System software  c) The application programs  d) Windows
**Answer: b) System software**

**3. (Sub lesson 1) When does the operating system start?**
a) The machine's parts  b) The desktop  c) When the computer starts  d) Through menus and icons you click
**Answer: c) When the computer starts**

**4. (Sub lesson 1) What does the operating system manage?**
a) The application programs  b) Windows  c) The user, the programs and the hardware  d) The machine's parts
**Answer: d) The machine's parts**

**5. (Sub lesson 1) What does the operating system run?**
a) The application programs  b) The desktop  c) Through menus and icons you click  d) The desktop and its shortcut menus
**Answer: a) The application programs**

**6. (Sub lesson 2) What do you land on when Windows starts?**
a) Windows  b) The desktop  c) The user, the programs and the hardware  d) An operating system
**Answer: b) The desktop**

**7. (Sub lesson 2) In what do programs open?**
a) Through menus and icons you click  b) The desktop and its shortcut menus  c) Windows  d) System software
**Answer: c) Windows**

**8. (Sub lesson 2) How do you give orders in Windows?**
a) The user, the programs and the hardware  b) An operating system  c) When the computer starts  d) Through menus and icons you click
**Answer: d) Through menus and icons you click**

**9. (Sub lesson 2) Between what is the operating system the layer?**
a) The user, the programs and the hardware  b) The desktop and its shortcut menus  c) System software  d) The machine's parts
**Answer: a) The user, the programs and the hardware**

**10. (Sub lesson 2) What do the lessons after this one take one piece at a time?**
a) An operating system  b) The desktop and its shortcut menus  c) When the computer starts  d) The application programs
**Answer: b) The desktop and its shortcut menus**
