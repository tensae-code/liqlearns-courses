# Windows and Dialog Boxes — First Steps — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a window?**
a) The framed box a program or folder opens in  b) The title bar, naming what is open  c) Sends the window to the taskbar, still open  d) By dragging its title bar
**Answer: a) The framed box a program or folder opens in**

**2. (Sub lesson 1) What runs across the top of a window?**
a) Sends the window to the taskbar, still open  b) The title bar, naming what is open  c) By dragging its title bar  d) Shuts the window
**Answer: b) The title bar, naming what is open**

**3. (Sub lesson 1) What does minimise do?**
a) By dragging its title bar  b) Shuts the window  c) Sends the window to the taskbar, still open  d) A small window that asks a question or takes a choice
**Answer: c) Sends the window to the taskbar, still open**

**4. (Sub lesson 1) How is a window moved?**
a) Shuts the window  b) A small window that asks a question or takes a choice  c) When the program needs an answer from you  d) By dragging its title bar
**Answer: d) By dragging its title bar**

**5. (Sub lesson 1) What does close do?**
a) Shuts the window  b) A small window that asks a question or takes a choice  c) When the program needs an answer from you  d) Accept and cancel
**Answer: a) Shuts the window**

**6. (Sub lesson 2) What is a dialog box?**
a) When the program needs an answer from you  b) A small window that asks a question or takes a choice  c) Accept and cancel  d) It waits until the dialog is answered or cancelled
**Answer: b) A small window that asks a question or takes a choice**

**7. (Sub lesson 2) When does a dialog box appear?**
a) Accept and cancel  b) It waits until the dialog is answered or cancelled  c) When the program needs an answer from you  d) Inside the drawing editor's window
**Answer: c) When the program needs an answer from you**

**8. (Sub lesson 2) Name the common pair of dialog buttons.**
a) It waits until the dialog is answered or cancelled  b) Inside the drawing editor's window  c) The framed box a program or folder opens in  d) Accept and cancel
**Answer: d) Accept and cancel**

**9. (Sub lesson 2) What happens to the work behind a dialog box?**
a) It waits until the dialog is answered or cancelled  b) Inside the drawing editor's window  c) The framed box a program or folder opens in  d) The title bar, naming what is open
**Answer: a) It waits until the dialog is answered or cancelled**

**10. (Sub lesson 2) Where does the Grade 5 programme rehearse dialog boxes?**
a) The framed box a program or folder opens in  b) Inside the drawing editor's window  c) The title bar, naming what is open  d) Sends the window to the taskbar, still open
**Answer: b) Inside the drawing editor's window**
