# Windows and Dialog Boxes — First Steps — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a window?**
**Answer: The framed box a program or folder opens in**

**2. (Sub lesson 1) What runs across the top of a window?**
**Answer: The title bar, naming what is open**

**3. (Sub lesson 1) What does minimise do?**
**Answer: Sends the window to the taskbar, still open**

**4. (Sub lesson 1) How is a window moved?**
**Answer: By dragging its title bar**

**5. (Sub lesson 1) What does close do?**
**Answer: Shuts the window**

**6. (Sub lesson 2) What is a dialog box?**
**Answer: A small window that asks a question or takes a choice**

**7. (Sub lesson 2) When does a dialog box appear?**
**Answer: When the program needs an answer from you**

**8. (Sub lesson 2) Name the common pair of dialog buttons.**
**Answer: Accept and cancel**

**9. (Sub lesson 2) What happens to the work behind a dialog box?**
**Answer: It waits until the dialog is answered or cancelled**

**10. (Sub lesson 2) Where does the Grade 5 programme rehearse dialog boxes?**
**Answer: Inside the drawing editor's window**
