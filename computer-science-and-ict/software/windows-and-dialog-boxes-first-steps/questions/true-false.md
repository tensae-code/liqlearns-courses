# Windows and Dialog Boxes — First Steps — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a window?" is: The framed box a program or folder opens in**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What runs across the top of a window?" is: Sends the window to the taskbar, still open**
**Answer: False** — The title bar, naming what is open

**3. (Sub lesson 1) True or false: the answer to "What does minimise do?" is: Sends the window to the taskbar, still open**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How is a window moved?" is: Shuts the window**
**Answer: False** — By dragging its title bar

**5. (Sub lesson 1) True or false: the answer to "What does close do?" is: Shuts the window**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is a dialog box?" is: When the program needs an answer from you**
**Answer: False** — A small window that asks a question or takes a choice

**7. (Sub lesson 2) True or false: the answer to "When does a dialog box appear?" is: When the program needs an answer from you**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Name the common pair of dialog buttons." is: It waits until the dialog is answered or cancelled**
**Answer: False** — Accept and cancel

**9. (Sub lesson 2) True or false: the answer to "What happens to the work behind a dialog box?" is: It waits until the dialog is answered or cancelled**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Where does the Grade 5 programme rehearse dialog boxes?" is: The framed box a program or folder opens in**
**Answer: False** — Inside the drawing editor's window
