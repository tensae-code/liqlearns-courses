# Lesson plan — Computer software — instructions that make hardware work

**Course:** Computer Science and ICT · **Title:** Software · **Lesson:** Computer software — instructions that make hardware work
**Place in the curriculum:** Title 3 — Software in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 7 book, Unit 3 — Computer Software. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** software is a collection of instructions that tells the computer what to do and how, and hardware can do nothing without it.
**This lesson's own level:** it stands on the Hardware title — the learner knows the parts you can touch; this lesson adds the instructions that make those parts work.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving or in steps — a GIF here is 2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **What software is** — software as instructions, and why hardware alone can do nothing
2. **The two types of software** — system software and application software, named as the two kinds

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: the Hardware lessons — what the machine's parts are.  Recommended, never forced.

## What the learner can do when it ends
1. Say what software is: instructions that tell the computer what to do and how.
2. Explain why hardware can do nothing without software.
3. Name the two types of software: system software and application software.

## What you need
A computer if you have one; paper and a pencil if not.

## If the learner is stuck
- Thinks software is a part you can touch → software is instructions, not a thing; you can touch the disk it is stored on, never the instructions themselves.
- Mixes the two types → ask: does it run the computer, or does it do my job? That question sorts every program in this unit.
