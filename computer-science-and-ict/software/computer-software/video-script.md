# Video script — Computer software — instructions that make hardware work

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Software is instructions.
Instructions tell the computer what to do. And how to do it.

A computer with no software can do nothing.
It cannot even start.

Hardware needs software. Software needs hardware.
They need each other.

Two kinds of software.
System software runs the computer.
Application software does your job.
