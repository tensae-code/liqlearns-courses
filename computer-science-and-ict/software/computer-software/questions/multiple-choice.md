# Computer software — instructions that make hardware work — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is software?
a) A part of the computer you can touch  b) A collection of instructions that tells the computer what to do  c) A kind of screen  d) A power cable
**Answer: b) A collection of instructions that tells the computer what to do** — software is instructions, not a physical part.

**2. (Sub lesson 1)** Without an operating system, a computer —
a) works slowly  b) cannot even start  c) works without a screen  d) needs no software
**Answer: b) cannot even start** — the book states it plainly: without an operating system a computer cannot even start.

**3. (Sub lesson 1)** Hardware and software are interdependent. That means —
a) they are the same thing  b) each one needs the other  c) hardware is better  d) software is heavier
**Answer: b) each one needs the other** — neither works alone.

**4. (Sub lesson 2)** How many types of software does the book name?
a) One  b) Two  c) Three  d) Five
**Answer: b) Two** — system software and application software.

**5. (Sub lesson 2)** Which type runs and manages the computer itself?
a) Application software  b) System software  c) Game software  d) Picture software
**Answer: b) System software** — system software runs the machine.

**6. (Sub lesson 2)** A program made for one particular job, like writing a letter, is —
a) system software  b) application software  c) hardware  d) an instruction
**Answer: b) application software** — application software is made for a particular need.
