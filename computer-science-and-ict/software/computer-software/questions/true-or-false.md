# Computer software — instructions that make hardware work — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** You can touch software with your hands.
**Answer: False** — software is instructions; you can touch the disk, not the instructions.

**2. (Sub lesson 1)** A computer can start with no operating system at all.
**Answer: False** — without an operating system it cannot even start.

**3. (Sub lesson 2)** Application software is one of the two types of software.
**Answer: True** — the two types are system and application software.
