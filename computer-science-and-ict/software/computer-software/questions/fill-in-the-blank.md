# Computer software — instructions that make hardware work — fill in the blank

Fill each blank with the right word.

**1. (Sub lesson 1)** Software is a collection of ______ that tells the computer what to do.
**Answer: instructions**

**2. (Sub lesson 2)** The two types of software are system software and ______ software.
**Answer: application**

**3. (Sub lesson 1)** Without an operating ______, a computer cannot even start.
**Answer: system**
