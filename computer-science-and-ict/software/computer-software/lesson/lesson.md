# Computer software — instructions that make hardware work

## Do it first

Imagine a computer with nothing inside it telling it what to do. No instructions at all. What could it do? Nothing — it could not even start. Everything a computer does, it does because instructions tell it to. Those instructions are this lesson's subject.

## Sub lesson 1 — What software is

Software is a collection of instructions, or programs, that tells the computer what to do and how to do it. Hardware — the part you can touch — can do nothing without software. Without an operating system, a computer cannot even start. Hardware and software need each other: neither one works alone. This needing-each-other is called being interdependent.

## Sub lesson 2 — The two types of software

Software is of two types. **System software** runs and manages the computer itself. **Application software** is made for a particular job you want done, like writing a letter. The next lessons take each type in turn — first the system side, then the programs for particular jobs.
