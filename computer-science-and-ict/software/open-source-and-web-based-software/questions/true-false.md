# Open-Source and Web-Based Software — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Software whose source code is published for anyone to use, study, change and share under its licence**
**Answer: True**

**2. (Sub lesson 1) True or false: Software whose source code is published for anyone to use, study, change and share under its licence** — as the answer to: What four freedoms does the licence give?
**Answer: False — Use, study, change, and share**

**3. (Sub lesson 1) True or false: Linux and LibreOffice (also Inkscape)**
**Answer: True**

**4. (Sub lesson 1) True or false: Linux and LibreOffice (also Inkscape)** — as the answer to: Why do many eyes help?
**Answer: False — Faults in published code are found by the crowd**

**5. (Sub lesson 1) True or false: The secret recipe — closed source code**
**Answer: True**

**6. (Sub lesson 2) True or false: The secret recipe — closed source code** — as the answer to: How is web-based software used?
**Answer: False — Through the browser — it runs on a server, nothing is installed**

**7. (Sub lesson 2) True or false: The same program and your files, wherever you sign in**
**Answer: True**

**8. (Sub lesson 2) True or false: The same program and your files, wherever you sign in** — as the answer to: How do updates reach users?
**Answer: False — The maker updates it once, for everyone at once**

**9. (Sub lesson 2) True or false: It needs a connection, and your data lives on someone else's computer**
**Answer: True**

**10. (Sub lesson 2) True or false: It needs a connection, and your data lives on someone else's computer** — as the answer to: What should the user know?
**Answer: False — Which trade they are making — control, convenience and trust differ by kind**
