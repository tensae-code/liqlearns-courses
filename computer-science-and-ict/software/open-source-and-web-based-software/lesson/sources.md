Placement choice: this lesson was built new for the ICT expansion (Vietnam, 2026-11-14) because no existing lesson in the course covers this thing as its own lesson — the live tree was checked for the slug and the live lesson content was checked for near matches before building. The live open-source lesson teaches free software and the GPL as a movement; Vietnam's Grade 11 lesson pairs open source with web-based software — programs running on the Internet — and that pairing, and the web-based half, are taught by no live lesson. The placements file named this slug directly (NEW LESSON NEEDED — software/open-source-and-web-based-software). It sits in the Software title (software/), following the book's own order. Provenance scope note: the placements stocked here are from Vietnam's “Kết nối tri thức với cuộc sống” (Connecting Knowledge with Life) Tin học books (Vietnamese) — one series, Grades 3–12, from Nhà xuất bản Giáo dục Việt Nam, splitting from Grade 10 into Computer Science (Khoa học máy tính) and Applied Informatics (Tin học ứng dụng) orientations, each with its own specialist-topic (Chuyên đề) volumes; the books are image-only PDFs read from rendered pages. Every placement stocked here is from a student book and counts toward the acceptance count; there are no teacher guides in this country. Media slots in lesson/lesson.md are described slots only ([Picture — …]); no picture numbers are invented.

Vietnam's own way (Grade 11 Tin học 11 Khoa học máy tính): from Grade 11 the two orientations are separate books but share a common core (Bài 1–16 here: operating systems, inside the computer, and a full databases strand ending at SQL); the CS-only second half is algorithm engineering in Python — arrays, search and sort, time complexity, stepwise refinement, modular design and building code libraries.

Vietnam's own way (Grade 11 Tin học 11 Tin học ứng dụng): Bài 1–16 are the same common core as the Computer Science orientation book (spot-checked page-identical, e.g. Bài 1); the Applied-only second half is hands-on database administration in Microsoft Access (through backup), then photo editing in GIMP and film-making/animation.
