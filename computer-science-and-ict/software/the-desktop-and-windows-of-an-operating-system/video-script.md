# Video script — The Desktop and Windows of an Operating System

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

The computer starts. The screen is ready.

This screen is the desktop. It is the home screen.

On it: a background. Small pictures: icons. Click an icon. It opens.

At the bottom: the taskbar. It shows what is open.

Every program opens in a window. A window is a box with a frame.

Top of the window: the title bar. It says the name.

Three buttons: make it small to the taskbar. Make it fill the screen. Close it.

Pull the title bar: the window moves. Pull a corner: the window grows or shrinks.

Many windows open? Click the one you want. It comes to the front.
