# Lesson plan — The Desktop and Windows of an Operating System

**Course:** Computer Science and ICT · **Title:** Software · **Lesson:** The Desktop and Windows of an Operating System
**Place in the curriculum:** ICT expansion — Cambodia (2026-11-14) — in the title Software on the ICT course ladder (TITLES.md). Built new from Cambodia's *Information and Communication Technology, Grade 10*, because no existing lesson teaches this thing as its own lesson.
**The one thing this lesson teaches:** When an operating system has started, the screen you land on is the desktop — a working surface holding icons over a background, with the taskbar along the bottom — and every program you open appears inside a window: a framed box with a title bar and control buttons that you can move, resize, minimise, maximise and close.
**This lesson's own level:** It stands on switching a computer on and using a mouse; the desktop, its parts, and every window move are built inside the lesson.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The desktop — the screen you start from** — The desktop is the operating system's home screen: a background across the whole screen, icons standing on it (small pictures that open programs, files and folders), and the taskbar along the bottom, which shows what is open and holds the way into the system.
2. **Windows — the framed boxes programs open in** — A window is a framed rectangle a program or folder opens inside: a title bar across the top naming it and carrying the minimise, maximise/restore and close buttons; drag the title bar to move it, drag an edge or corner to resize it, and when several windows are open, click the one you want — or its taskbar button — to bring it to the front.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: System Software and the Operating System in Software. Recommended, never forced — a learner may land on this lesson directly, and it stands alone.
- Cambodia's own way is kept: in Cambodia's Grade 10 book this session comes in Chapter 1, straight after meeting the computer itself — the desktop and its windows are learned as the place all later work, including the OpenOffice Writer chapters, happens.

## What the learner can do when it ends
1. Name the desktop and its parts: background, icons and taskbar, and say what each one is for.
2. Open a program or folder from a desktop icon.
3. Read a window: name it from its title bar and find the minimise, maximise/restore and close buttons.
4. Move a window by its title bar and resize it by an edge or corner.
5. Bring the window you want to the front when several are open, using the window itself or its taskbar button.

## What you need
A computer that has started up to its desktop, with a mouse. On paper first: a drawn desktop and a paper window frame are enough to learn the names.

## If the learner is stuck
Thinks the desktop is the computer box on the desk → the desktop in this lesson is a screen: the operating system's home screen, named after a real desk top because it is the surface you work on. Closes a window and thinks the work is deleted → closing only shuts the window; the file stays where it was saved. Drags a window by its middle and it will not move → windows move by the title bar, and resize by an edge or a corner.
