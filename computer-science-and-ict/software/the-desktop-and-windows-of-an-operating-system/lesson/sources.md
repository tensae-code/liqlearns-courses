Placement choice: this lesson was built new for the ICT expansion (Cambodia, 2026-11-14) because no existing lesson in the course covers this thing as its own lesson — the live tree was checked first: Software's System Software and the Operating System teaches the operating system's job, and its The Start Menu and Its Options teaches the Start menu; neither teaches the desktop surface itself or how to move, resize, minimise, maximise and close windows. The placements file named this slug directly (NEW LESSON NEEDED — software/the-desktop-and-windows-of-an-operating-system). It sits in the Software title (software/).

Cambodia's own way: ICT is taught through Khmer-language office life — personal, official and business letters, job applications and Cornell note-taking — in OpenOffice Writer, with a dedicated session on typing Khmer script, and the book closes with STEM and e-learning rather than programming. This lesson keeps Cambodia's order: the desktop and its windows are met in Chapter 1, before any application is opened.
