# The Desktop and Windows of an Operating System — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) The desktop only appears after you open a program.**
**Answer: False** — The desktop is there first; programs open on top of it.

**2. (Sub lesson 1) The taskbar shows a button for every open window.**
**Answer: True**

**3. (Sub lesson 2) Closing a window deletes the file that was open in it.**
**Answer: False** — Closing shuts the window; the file stays where it was saved.

**4. (Sub lesson 2) Dragging a corner of a window changes the window's size.**
**Answer: True** — Corners and edges resize; the title bar moves.
