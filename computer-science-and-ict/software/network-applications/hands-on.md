# Hands-on — Network Applications

The lesson with your hands and your feet, not only your eyes.

## Task one
**Role naming** — For three things you do online (read a page, send mail, get a file), name the client, the server and what travels between them.

## Task two
**Unplug test** — Open a browser and a mail client with the network off and note exactly what each can and cannot do; write the sentence that defines a network application from what you saw.
