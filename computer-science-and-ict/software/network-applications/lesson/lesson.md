# Network Applications

## Do it first

Most applications work alone on one machine. Grade 7's software chapter ends with the other kind: the applications that are pointless alone — the ones whose whole job is to reach across a network to other machines and other people.

## Sub lesson 1 — Applications that reach across the network

A **network application** is a program whose work needs a **network**: it sends, receives or shares information with other computers. The book's family: the **web browser** (asks servers for pages and shows them), the **mail client** (sends and receives letters through mail servers), **chat and call programs** (carry talk between people), and **file-transfer programs** (move files between machines). Unplug the network and each is an empty shell — that dependence is their definition.

## Sub lesson 2 — Client and server — the two halves

Network applications work in **pairs of roles**. The **client** is the program on your machine that asks; the **server** is the program (on another machine) that answers and serves — the page, the letter, the file. Your browser is a client; the site's machine runs the server half. Both halves are applications, and the network between them is only the road: confusing the road with the workers is the beginner's error this section exists to prevent.
