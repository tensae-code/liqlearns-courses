# Network Applications — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What is a network application?** → **A program whose work needs a network — it sends, receives or shares information with other computers**

**2. (Sub lesson 1) Name the book's four families.** → **Browsers, mail clients, chat/call programs and file-transfer programs**

**3. (Sub lesson 1) What does a browser do?** → **It asks servers for pages and shows them**

**4. (Sub lesson 1) What is left of a network application with the network unplugged?** → **An empty shell — that dependence is its definition**

**5. (Sub lesson 1) What does a mail client work through?** → **Mail servers**

**6. (Sub lesson 2) What is a client?** → **The program on your machine that asks**

**7. (Sub lesson 2) What is a server?** → **The program on another machine that answers and serves**

**8. (Sub lesson 2) Give the browser example in roles.** → **Your browser is the client; the site's machine runs the server half**

**9. (Sub lesson 2) Is the network itself an application?** → **No — it is the road between the two application halves**

**10. (Sub lesson 2) Name the two halves of every network application.** → **Client and server**
