# Network Applications — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A program whose work needs a network — it sends, receives or shares information with other computers**
**Answer: True**

**2. (Sub lesson 1) True or false: A program whose work needs a network — it sends, receives or shares information with other computers** — as the answer to: Name the book's four families.
**Answer: False — Browsers, mail clients, chat/call programs and file-transfer programs**

**3. (Sub lesson 1) True or false: It asks servers for pages and shows them**
**Answer: True**

**4. (Sub lesson 1) True or false: It asks servers for pages and shows them** — as the answer to: What is left of a network application with the network unplugged?
**Answer: False — An empty shell — that dependence is its definition**

**5. (Sub lesson 1) True or false: Mail servers**
**Answer: True**

**6. (Sub lesson 2) True or false: Mail servers** — as the answer to: What is a client?
**Answer: False — The program on your machine that asks**

**7. (Sub lesson 2) True or false: The program on another machine that answers and serves**
**Answer: True**

**8. (Sub lesson 2) True or false: The program on another machine that answers and serves** — as the answer to: Give the browser example in roles.
**Answer: False — Your browser is the client; the site's machine runs the server half**

**9. (Sub lesson 2) True or false: No — it is the road between the two application halves**
**Answer: True**

**10. (Sub lesson 2) True or false: No — it is the road between the two application halves** — as the answer to: Name the two halves of every network application.
**Answer: False — Client and server**
