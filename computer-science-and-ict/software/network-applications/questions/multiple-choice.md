# Network Applications — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a network application?**
a) A program whose work needs a network — it sends, receives or shares information with other computers  b) Browsers, mail clients, chat/call programs and file-transfer programs  c) It asks servers for pages and shows them  d) An empty shell — that dependence is its definition
**Answer: a**

**2. (Sub lesson 1) Name the book's four families.**
a) Browsers, mail clients, chat/call programs and file-transfer programs  b) It asks servers for pages and shows them  c) An empty shell — that dependence is its definition  d) Mail servers
**Answer: a**

**3. (Sub lesson 1) What does a browser do?**
a) It asks servers for pages and shows them  b) An empty shell — that dependence is its definition  c) Mail servers  d) The program on your machine that asks
**Answer: a**

**4. (Sub lesson 1) What is left of a network application with the network unplugged?**
a) An empty shell — that dependence is its definition  b) Mail servers  c) The program on your machine that asks  d) The program on another machine that answers and serves
**Answer: a**

**5. (Sub lesson 1) What does a mail client work through?**
a) Mail servers  b) The program on your machine that asks  c) The program on another machine that answers and serves  d) Your browser is the client; the site's machine runs the server half
**Answer: a**

**6. (Sub lesson 2) What is a client?**
a) The program on your machine that asks  b) The program on another machine that answers and serves  c) Your browser is the client; the site's machine runs the server half  d) No — it is the road between the two application halves
**Answer: a**

**7. (Sub lesson 2) What is a server?**
a) The program on another machine that answers and serves  b) Your browser is the client; the site's machine runs the server half  c) No — it is the road between the two application halves  d) Client and server
**Answer: a**

**8. (Sub lesson 2) Give the browser example in roles.**
a) Your browser is the client; the site's machine runs the server half  b) No — it is the road between the two application halves  c) Client and server  d) A program whose work needs a network — it sends, receives or shares information with other computers
**Answer: a**

**9. (Sub lesson 2) Is the network itself an application?**
a) No — it is the road between the two application halves  b) Client and server  c) A program whose work needs a network — it sends, receives or shares information with other computers  d) Browsers, mail clients, chat/call programs and file-transfer programs
**Answer: a**

**10. (Sub lesson 2) Name the two halves of every network application.**
a) Client and server  b) A program whose work needs a network — it sends, receives or shares information with other computers  c) Browsers, mail clients, chat/call programs and file-transfer programs  d) It asks servers for pages and shows them
