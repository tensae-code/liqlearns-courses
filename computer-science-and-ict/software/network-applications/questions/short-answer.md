# Network Applications — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a network application?**
**Answer: A program whose work needs a network — it sends, receives or shares information with other computers**

**2. (Sub lesson 1) Name the book's four families.**
**Answer: Browsers, mail clients, chat/call programs and file-transfer programs**

**3. (Sub lesson 1) What does a browser do?**
**Answer: It asks servers for pages and shows them**

**4. (Sub lesson 1) What is left of a network application with the network unplugged?**
**Answer: An empty shell — that dependence is its definition**

**5. (Sub lesson 1) What does a mail client work through?**
**Answer: Mail servers**

**6. (Sub lesson 2) What is a client?**
**Answer: The program on your machine that asks**

**7. (Sub lesson 2) What is a server?**
**Answer: The program on another machine that answers and serves**

**8. (Sub lesson 2) Give the browser example in roles.**
**Answer: Your browser is the client; the site's machine runs the server half**

**9. (Sub lesson 2) Is the network itself an application?**
**Answer: No — it is the road between the two application halves**

**10. (Sub lesson 2) Name the two halves of every network application.**
**Answer: Client and server**
