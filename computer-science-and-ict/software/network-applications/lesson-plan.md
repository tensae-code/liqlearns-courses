**Course:** Computer Science and ICT · **Title:** Software · **Lesson:** Network Applications

**The one thing this lesson teaches:** The applications whose work happens across a network: browsers, mail clients, chat and file-transfer programs — software that is only half on your machine, the other half on someone else's (Moldova Grade 7, Informatică, §3.12).
**This lesson's own level:** It stands on the earlier lessons of its title and on the book's own order — it follows the book's lessons in sequence, so its neighbours in the book are its natural companions. It stands alone for a learner landing on it directly.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Applications that reach across the network** — A **network application** is a program whose work needs a **network**: it sends, receives or shares information with other computers. The book's family: the **web browser** (asks servers for pages and shows them), the **mail client** (sends and receives letters through mail servers), **chat and call programs** (carry talk between people), and **file-transfer programs** (move files between machines). Unplug the network and each is an empty shell — that dependence is their definition.
2. **Client and server — the two halves** — Network applications work in **pairs of roles**. The **client** is the program on your machine that asks; the **server** is the program (on another machine) that answers and serves — the page, the letter, the file. Your browser is a client; the site's machine runs the server half. Both halves are applications, and the network between them is only the road: confusing the road with the workers is the beginner's error this section exists to prevent.

## The run of the lesson (in order)
1. **Do it first** — Most applications work alone on one machine. Grade 7's software chapter ends with the other kind: the applications that are pointless alone — the ones whose whole job is to reach across a network to other machines and other people. (lesson/lesson.md).
2. **The explanation** — the lesson text in lesson/lesson.md, in its parts in order.
   - ADD IMAGE: a picture of applications that reach across the network as the lesson describes it — the student studies the picture and names what each part shows.
