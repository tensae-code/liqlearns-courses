# Operating Systems for Smart Devices — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does a smart device run on, like a computer?" is: An operating system**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What kind of software is an operating system?" is: The device's applications**
**Answer: False** — System software

**3. (Sub lesson 1) True or false: the answer to "Name two jobs of a smart device's operating system." is: Starting the device and managing its parts**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does the operating system run?" is: Connections to networks**
**Answer: False** — The device's applications

**5. (Sub lesson 1) True or false: the answer to "What is the main way in on a smart device?" is: The touch screen**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What connections does the operating system handle?" is: The applications of smart devices**
**Answer: False** — Connections to networks

**7. (Sub lesson 2) True or false: the answer to "What two resources does it look after?" is: Memory and battery**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What stands on the operating system, in the next lesson?" is: Grade 11**
**Answer: False** — The applications of smart devices
