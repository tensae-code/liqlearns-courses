# Operating Systems for Smart Devices — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does a smart device run on, like a computer?**
a) An operating system  b) System software  c) The device's applications  d) Connections to networks
**Answer: a) An operating system**

**2. (Sub lesson 1) What kind of software is an operating system?**
a) Starting the device and managing its parts  b) System software  c) The touch screen  d) Memory and battery
**Answer: b) System software**

**3. (Sub lesson 1) Name two jobs of a smart device's operating system.**
a) The device's applications  b) Connections to networks  c) Starting the device and managing its parts  d) The applications of smart devices
**Answer: c) Starting the device and managing its parts**

**4. (Sub lesson 1) What does the operating system run?**
a) The touch screen  b) Memory and battery  c) Changing its operating system  d) The device's applications
**Answer: d) The device's applications**

**5. (Sub lesson 1) What is the main way in on a smart device?**
a) The touch screen  b) Connections to networks  c) The applications of smart devices  d) Grade 11
**Answer: a) The touch screen**

**6. (Sub lesson 2) What connections does the operating system handle?**
a) Memory and battery  b) Connections to networks  c) Changing its operating system  d) An operating system
**Answer: b) Connections to networks**

**7. (Sub lesson 2) What two resources does it look after?**
a) The applications of smart devices  b) Grade 11  c) Memory and battery  d) System software
**Answer: c) Memory and battery**

**8. (Sub lesson 2) What stands on the operating system, in the next lesson?**
a) Changing its operating system  b) An operating system  c) Starting the device and managing its parts  d) The applications of smart devices
**Answer: d) The applications of smart devices**

**9. (Sub lesson 2) What changes how the same device feels?**
a) Changing its operating system  b) Grade 11  c) System software  d) The device's applications
**Answer: a) Changing its operating system**

**10. (Sub lesson 2) Which grade's book teaches this lesson?**
a) An operating system  b) Grade 11  c) Starting the device and managing its parts  d) The touch screen
**Answer: b) Grade 11**
