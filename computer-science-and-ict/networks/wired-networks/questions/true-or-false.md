# Wired networks — true or false

Say whether each sentence is true or false.

**1.** A wired network needs physical cables.
**Answer: True** — linked by Ethernet cables.

**2.** Only computers can join a wired network.
**Answer: False** — printers and other devices too.

**3.** Ethernet is a wired-network technology.
**Answer: True** — a wired network is an Ethernet network.
