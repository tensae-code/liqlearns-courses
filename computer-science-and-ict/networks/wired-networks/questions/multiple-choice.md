# Wired networks — multiple choice

Pick the one right answer.

**1.** A wired network links devices by —
a) radio waves  b) Ethernet cables  c) satellite  d) infrared
**Answer: b) Ethernet cables** — Ethernet cables.

**2.** A wired network is also called an —
a) Ethernet network  b) infrared network  c) satellite network  d) PAN only
**Answer: a) Ethernet network** — Ethernet network.

**3.** It is the most common kind of —
a) WAN technology  b) LAN technology  c) protocol  d) software
**Answer: b) LAN technology** — LAN technology.

**4.** A wired network links —
a) one device only  b) two or more computers, printers and other devices  c) only phones  d) only satellites
**Answer: b) two or more computers, printers and other devices** — two or more devices.

**5.** In the lab picture, cables run —
a) nowhere  b) from each device to a central point  c) only between printers  d) through the air
**Answer: b) from each device to a central point** — to a central point.
