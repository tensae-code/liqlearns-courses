# Cellular networks — cells, base stations, MSC — true or false

Say whether each sentence is true or false.


**1. (Sub lesson 1)** A base station can assign a channel to a caller.
**Answer: True** — locate, track, assign, hand over.

**2. (Sub lesson 2)** Base stations work independently, with nothing coordinating them.
**Answer: False** — the MSC coordinates them all.

**3. (Sub lesson 3)** WiMax is a wireless WAN in star topology.
**Answer: True** — keyed in the guide — base station at the centre.
