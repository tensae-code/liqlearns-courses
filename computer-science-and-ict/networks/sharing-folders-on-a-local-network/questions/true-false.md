# Sharing Folders on a Local Network — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does sharing a folder do?" is: Offers it to the local network while it stays on its own computer**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What should be shared, by the book's habit?" is: Its network path through its owner's computer**
**Answer: False** — The folder the work needs — not the whole disk

**3. (Sub lesson 1) True or false: the answer to "By what is a shared folder reached?" is: Its network path through its owner's computer**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What do sharing permissions decide?" is: Read it — only its owner writes there**
**Answer: False** — Who may only read and who may change the folder

**5. (Sub lesson 1) True or false: the answer to "What may the class do with the materials folder?" is: Read it — only its owner writes there**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is a computer known by on the network?" is: ipconfig, at the command line**
**Answer: False** — Its IP address

**7. (Sub lesson 2) True or false: the answer to "Which command finds your own IP address?" is: ipconfig, at the command line**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does ipconfig print?" is: The door opened and governed; the house numbered**
**Answer: False** — The machine's addresses

**9. (Sub lesson 2) True or false: the answer to "Name the lesson's pair." is: The door opened and governed; the house numbered**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "In which unit does this lesson stand?" is: Offers it to the local network while it stays on its own computer**
**Answer: False** — Mongolia's Grade 9 networks unit
