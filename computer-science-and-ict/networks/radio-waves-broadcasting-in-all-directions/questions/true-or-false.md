# Radio waves — broadcasting in all directions — true or false

Say whether each sentence is true or false.


**1. (Sub lesson 1)** Waves of 1–300 GHz are microwaves.
**Answer: True** — behaviour matters more than the boundary.

**2. (Sub lesson 2)** Radio antennas must be carefully aligned with each receiver.
**Answer: False** — radio needs no alignment.

**3. (Sub lesson 4)** The guide keys wireless as beating wired on expandability without running cables.
**Answer: True** — one of the four keyed counts.
