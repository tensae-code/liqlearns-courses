# Intranet a Private Network Inside An Organisation

## Do it first

An intranet is a private network inside one organisation that uses internet technology — web pages, browsers, file sharing — but is open only to the organisation's own people

## Sub lesson 1 — Intranet

An intranet is a private network inside one organisation that uses internet technology — web pages, browsers, file sharing — but is open only to the organisation's own people The learner identifies what an intranet offers inside a school or office — shared files, internal pages, shared resources — and who may use it Because an organisation needs the internet's easy tools without the internet's open door; the intranet is that private version.
