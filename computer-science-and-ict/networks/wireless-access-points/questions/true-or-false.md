# Wireless access points — true or false

Say whether each sentence is true or false.

**1.** A WAP joins wireless devices into a network.
**Answer: True** — that is its job.

**2.** A WAP is where messages start and end.
**Answer: False** — it is an intermediary; messages start and end at end devices.

**3.** Wi-Fi devices reach the network through a WAP.
**Answer: True** — Wi-Fi is named.

**4.** An access point can repeat for wireless nodes, doubling their reach.
**Answer: True** — the AP bridges and can also repeat.
