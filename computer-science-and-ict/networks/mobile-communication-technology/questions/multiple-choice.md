# Mobile Communication Technology — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Name the four generations and each one's gift.**
a) 1G analogue voice; 2G digital voice and SMS; 3G mobile data; 4G fast data  b) SMS — the short written message  c) The SIM card  d) By codes — code division
**Answer: a) 1G analogue voice; 2G digital voice and SMS; 3G mobile data; 4G fast data**

**2. (Sub lesson 1) What arrived with 2G that outlived expectations?**
a) The SIM card  b) SMS — the short written message  c) By codes — code division  d) The ground one base station serves
**Answer: b) SMS — the short written message**

**3. (Sub lesson 1) What carries the subscriber's identity in GSM?**
a) By codes — code division  b) The ground one base station serves  c) The SIM card  d) Phone by radio to the nearest station, routed through switches, out at the far station to the other phone
**Answer: c) The SIM card**

**4. (Sub lesson 1) How does CDMA spread calls?**
a) The ground one base station serves  b) Phone by radio to the nearest station, routed through switches, out at the far station to the other phone  c) Steppe distances — from Ulaanbaatar across the aimags along roads and settlements  d) By codes — code division
**Answer: d) By codes — code division**

**5. (Sub lesson 1) What is a cell?**

**Answer: a) The ground one base station serves**

**8. (Sub lesson 2) Why is the technology called cellular?**
