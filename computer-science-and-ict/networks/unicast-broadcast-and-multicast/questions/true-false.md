# Unicast, Broadcast and Multicast — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: One sender to one receiver**
**Answer: True**

**2. (Sub lesson 1) True or false: One sender to one receiver** — as the answer to: Name a unicast example.
**Answer: False — A message to one friend (or a page to one browser)**

**3. (Sub lesson 1) True or false: A thousand viewers need a thousand streams**
**Answer: True**

**4. (Sub lesson 1) True or false: A thousand viewers need a thousand streams** — as the answer to: What is broadcast?
**Answer: False — One sender to every receiver on the network**

**5. (Sub lesson 1) True or false: It burdens everyone, wanted or not**
**Answer: True**

**6. (Sub lesson 2) True or false: It burdens everyone, wanted or not** — as the answer to: What is multicast?
**Answer: False — One sender to a chosen group of receivers**

**7. (Sub lesson 2) True or false: Only those who joined the group**
**Answer: True**

**8. (Sub lesson 2) True or false: Only those who joined the group** — as the answer to: How does multicast save the road?
**Answer: False — One stream branches only where members wait**

**9. (Sub lesson 2) True or false: A live lesson streamed to enrolled classes**
**Answer: True**

**10. (Sub lesson 2) True or false: A live lesson streamed to enrolled classes** — as the answer to: What decides the mode?
**Answer: False — The audience — one, all, or the group between**
