# Video script — Designing a Simple Network from a Brief

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

The work starts with **research**: find out the users' needs and the place, and let the **brief state the problem the network must solve**. Before anything is connected, the plan lists **the devices and media needed** and is **drawn**, so every connection is clear before building begins.
To **configure** the network is to set up each device so the network works. The network is then **tested — that the devices can communicate** — and **managed**: a named person checks that it keeps working and fixes faults. The design meets its brief when the working network does what the brief asked.
