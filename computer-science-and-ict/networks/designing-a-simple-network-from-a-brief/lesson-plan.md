## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **From brief to network plan** — The work starts with **research**: find out the users' needs and the place, and let the **brief state the problem the network must solve**. Before anything is connected, the plan lists **the devices and media needed** and is **drawn**, so every connection is clear before building begins.
2. **Configuring and managing the simple network** — To **configure** the network is to set up each device so the network works. The network is then **tested — that the devices can communicate** — and **managed**: a named person checks that it keeps working and fixes faults. The design meets its brief when the working network does what the brief asked.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
