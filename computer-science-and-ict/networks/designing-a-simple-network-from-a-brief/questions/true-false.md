# Designing a Simple Network from a Brief — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does the brief for a network state first?" is: The problem the network must solve**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is listed before anything is connected?" is: That the devices can communicate**
**Answer: False** — The devices and media needed

**3. (Sub lesson 1) True or false: the answer to "What does it mean to configure a network?" is: Set up each device so the network works**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is tested when the network is built?" is: Find out the users' needs and the place**
**Answer: False** — That the devices can communicate

**5. (Sub lesson 1) True or false: the answer to "What does managing a network include?" is: Checking it keeps working and fixing faults**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is the first research step?" is: So every connection is clear before building**
**Answer: False** — Find out the users' needs and the place

**7. (Sub lesson 2) True or false: the answer to "What does a simple network connect?" is: A small number of devices in one place**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Why draw the network plan before building?" is: The working network doing what the brief asked**
**Answer: False** — So every connection is clear before building

**9. (Sub lesson 2) True or false: the answer to "Who manages a simple school network?" is: A named person responsible for it**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What proves the design met the brief?" is: The devices and media needed**
**Answer: False** — The working network doing what the brief asked
