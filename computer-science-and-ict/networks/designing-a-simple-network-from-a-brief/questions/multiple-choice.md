# Designing a Simple Network from a Brief — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does the brief for a network state first?**
a) The problem the network must solve  b) The devices and media needed  c) Set up each device so the network works  d) That the devices can communicate
**Answer: a) The problem the network must solve**

**2. (Sub lesson 1) What is listed before anything is connected?**
a) Set up each device so the network works  b) The devices and media needed  c) That the devices can communicate  d) Checking it keeps working and fixing faults
**Answer: b) The devices and media needed**

**3. (Sub lesson 1) What does it mean to configure a network?**
a) That the devices can communicate  b) Checking it keeps working and fixing faults  c) Set up each device so the network works  d) Find out the users' needs and the place
**Answer: c) Set up each device so the network works**

**4. (Sub lesson 1) What is tested when the network is built?**
a) Checking it keeps working and fixing faults  b) Find out the users' needs and the place  c) A small number of devices in one place  d) That the devices can communicate
**Answer: d) That the devices can communicate**

**5. (Sub lesson 1) What does managing a network include?**
a) Checking it keeps working and fixing faults  b) Find out the users' needs and the place  c) A small number of devices in one place  d) So every connection is clear before building
**Answer: a) Checking it keeps working and fixing faults**

**6. (Sub lesson 2) What is the first research step?**
a) A small number of devices in one place  b) Find out the users' needs and the place  c) So every connection is clear before building  d) A named person responsible for it
**Answer: b) Find out the users' needs and the place**

**7. (Sub lesson 2) What does a simple network connect?**
a) So every connection is clear before building  b) A named person responsible for it  c) A small number of devices in one place  d) The working network doing what the brief asked
**Answer: c) A small number of devices in one place**

**8. (Sub lesson 2) Why draw the network plan before building?**
a) A named person responsible for it  b) The working network doing what the brief asked  c) The problem the network must solve  d) So every connection is clear before building
**Answer: d) So every connection is clear before building**

**9. (Sub lesson 2) Who manages a simple school network?**
a) A named person responsible for it  b) The working network doing what the brief asked  c) The problem the network must solve  d) The devices and media needed
**Answer: a) A named person responsible for it**

**10. (Sub lesson 2) What proves the design met the brief?**
a) The problem the network must solve  b) The working network doing what the brief asked  c) The devices and media needed  d) Set up each device so the network works
**Answer: b) The working network doing what the brief asked**
