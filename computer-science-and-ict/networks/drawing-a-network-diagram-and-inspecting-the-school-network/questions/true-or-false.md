# Drawing a network diagram — and inspecting the school network — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** The practical ends with reporting back to class.
**Answer: True** — report back is the closing step.

**2. (Sub lesson 2)** You should unplug the school's working cables to inspect them.
**Answer: False** — examine a real cable as the practical directs — the inspection is of a cable, connectors and wires; never break the working network.

**3. (Sub lesson 2)** Paper is an accepted way to redraw the figure.
**Answer: True** — Packet Tracer, GNS3, or on paper.
