# Network Performance and Effectiveness — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Performance — the measurable side
Sub lesson 1 questions from the type files. Pass mark: Bandwidth, throughput, delay (latency), reliability; How much data the road can carry; How long a message takes to cross; How often the network works, whole and unharmed; So complaints become findings — 'delay is high at noon'.

## Sub lesson 2 — Effectiveness — performance for a purpose
Sub lesson 2 questions from the type files. Pass mark: Whether the network serves its users' actual work; Performance nobody needs is not effectiveness; Thirty pupils at 9 a.m.; Find the narrow place and widen that, not everything; An old device, a busy hour, a long cable.
