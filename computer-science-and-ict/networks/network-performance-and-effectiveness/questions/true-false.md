# Network Performance and Effectiveness — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Bandwidth, throughput, delay (latency), reliability**
**Answer: True**

**2. (Sub lesson 1) True or false: Bandwidth, throughput, delay (latency), reliability** — as the answer to: What is bandwidth?
**Answer: False — How much data the road can carry**

**3. (Sub lesson 1) True or false: How long a message takes to cross**
**Answer: True**

**4. (Sub lesson 1) True or false: How long a message takes to cross** — as the answer to: What does reliability measure?
**Answer: False — How often the network works, whole and unharmed**

**5. (Sub lesson 1) True or false: So complaints become findings — 'delay is high at noon'**
**Answer: True**

**6. (Sub lesson 2) True or false: So complaints become findings — 'delay is high at noon'** — as the answer to: What does effectiveness ask?
**Answer: False — Whether the network serves its users' actual work**

**7. (Sub lesson 2) True or false: Performance nobody needs is not effectiveness**
**Answer: True**

**8. (Sub lesson 2) True or false: Performance nobody needs is not effectiveness** — as the answer to: When does the example network fail effectively?
**Answer: False — Thirty pupils at 9 a.m.**

**9. (Sub lesson 2) True or false: Find the narrow place and widen that, not everything**
**Answer: True**

**10. (Sub lesson 2) True or false: Find the narrow place and widen that, not everything** — as the answer to: Name three narrow places.
**Answer: False — An old device, a busy hour, a long cable**
