# Video script — IP address classes and network masks

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Five classes. The first number decides.

A: 0 to 127. Few networks, many hosts.
B: 128 to 191.
C: 192 to 223. Many networks, few hosts.
D: multicast. E: experimental.

The mask splits network from node:
255.0.0.0 — 255.255.0.0 — 255.255.255.0.
