# IP address classes and network masks — multiple choice

Pick the one right answer.


**1. (Sub lesson 1)** Class B's first octet runs —
a) 0–127  b) 128–191  c) 192–223  d) 240–255
**Answer: b) 128–191** — 128–191.

**2. (Sub lesson 1)** Class A has —
a) many networks, few hosts  b) few networks, very many hosts  c) three network octets  d) no hosts
**Answer: b) few networks, very many hosts** — first octet only is network — few networks, very many hosts.

**3. (Sub lesson 1)** Class D (224–239) is for —
a) host addresses  b) multicast  c) experiments  d) masks
**Answer: b) multicast** — multicast; E is experimental.

**4. (Sub lesson 2)** The default mask for Class C is —
a) 255.0.0.0  b) 255.255.0.0  c) 255.255.255.0  d) 0.0.0.0
**Answer: c) 255.255.255.0** — 255.255.255.0.

**5. (Sub lesson 2)** By leading bits, an address starting 110 is class —
a) A  b) B  c) C  d) D
**Answer: c) C** — 110 = C, keyed in the guide.
