# IP address classes and network masks — true or false

Say whether each sentence is true or false.


**1. (Sub lesson 1)** Classes D and E serve as ordinary host addresses.
**Answer: False** — only A, B and C serve as host addresses.

**2. (Sub lesson 1)** Class C gives many networks with few hosts each.
**Answer: True** — three network octets.

**3. (Sub lesson 2)** A network mask separates the network portion from the node portion.
**Answer: True** — that is its job.
