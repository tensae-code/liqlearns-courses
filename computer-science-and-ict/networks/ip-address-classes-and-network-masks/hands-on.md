# Hands-on — IP address classes and network masks

The lesson with your hands, not only your eyes.


## Find the class (the book's exercises, in its order)
1. Find the class of given addresses by first octet. 2. Rewrite addresses in binary and check the class by leading bits. 3. On a real networked computer, read its address, class and mask.

## Mask match
Three address cards (one A, one B, one C) and three mask cards. Match mask to address and defend each match by counting 255s.
