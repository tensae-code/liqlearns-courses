# Coaxial cable — a core inside a shield — true or false

Say whether each sentence is true or false.


**1. (Sub lesson 1)** Coax and twisted pair carry signals the same way and at the same frequencies.
**Answer: False** — coax carries higher frequencies because of its build.

**2. (Sub lesson 2)** The plastic cover is the innermost layer of coax.
**Answer: False** — the cover is outermost; the core is innermost.

**3. (Sub lesson 3)** Thick coax has better noise immunity than thin coax.
**Answer: True** — thick: better noise immunity; thin: limited isolation.
