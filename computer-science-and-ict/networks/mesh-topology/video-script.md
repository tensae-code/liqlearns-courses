In a mesh topology, every node connects directly to every other node — it is also called complete topology. With every path present, there is no traffic congestion, data security is strong, and the network is robust: one link down, the rest still work. Faults are easy to identify. Watch the GIF: one link is cut, and messages reroute around it.

Now look at the picture. Name each part.
That is mesh topology.
