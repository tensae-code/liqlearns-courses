# Mesh topology — multiple choice

Pick the one right answer.

**1.** In a mesh, every node connects —
a) to one switch  b) directly to every other node  c) to two neighbours  d) to the bus
**Answer: b) directly to every other node** — to every other node.

**2.** Mesh is also called —
a) star topology  b) complete topology  c) ring topology  d) bus topology
**Answer: b) complete topology** — complete topology.

**3.** If one mesh link fails —
a) the network stops  b) the rest still work  c) all data is lost  d) the switch fails
**Answer: b) the rest still work** — the network is robust.

**4.** Mesh faults are —
a) hard to isolate  b) easy to identify  c) invisible  d) always fatal
**Answer: b) easy to identify** — easy to identify.

**5.** Mesh is impractical for medium-to-large networks because of —
a) weak security  b) cable length, cost and complexity  c) congestion  d) slow printers
**Answer: b) cable length, cost and complexity** — length, cost and complexity.
