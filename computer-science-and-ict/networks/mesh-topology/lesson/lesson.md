# Mesh topology

## Do it first

Take five dots. Join every dot to every other dot — no exceptions. Count your lines when you finish. That complete web is this lesson's shape.

## Every node to every other node

In a **mesh topology**, **every node connects directly to every other node** — it is also called **complete topology**. With every path present, there is **no traffic congestion**, **data security is strong**, and the network is **robust: one link down, the rest still work**. **Faults are easy to identify**. Watch the GIF: one link is cut, and messages reroute around it.

## The price of completeness

Against all that: the **cable length, cost and complexity** make mesh **impractical for medium-to-large networks**. Every added node must link to all the others, so the web grows faster than the network.
