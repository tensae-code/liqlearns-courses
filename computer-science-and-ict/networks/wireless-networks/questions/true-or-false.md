# Wireless networks — true or false

Say whether each sentence is true or false.

**1.** A wireless network can expand an existing wired network.
**Answer: True** — expand or replace is named.

**2.** A wireless network needs no wires anywhere at all.
**Answer: False** — its backbone is always a wired network.

**3.** Radio waves replace wires between device and WAP.
**Answer: True** — instead of wires.
