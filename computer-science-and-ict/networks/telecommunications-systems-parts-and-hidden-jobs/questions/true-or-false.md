# Telecommunications systems — parts and hidden jobs — true or false

Say whether each sentence is true or false.


**1. (Sub lesson 1)** Telecommunications exchanges information only as voice.
**Answer: False** — any form — voice, data, text, images, audio, video.

**2. (Sub lesson 3)** The system must keep information secure at all times.
**Answer: True** — one of the hidden jobs.

**3. (Sub lesson 4)** Voice, video and data can share one modern network.
**Answer: True** — keyed in the guide.
