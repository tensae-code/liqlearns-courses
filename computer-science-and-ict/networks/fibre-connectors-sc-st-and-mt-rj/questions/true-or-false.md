# Fibre connectors — SC, ST, MT-RJ — true or false

Say whether each sentence is true or false.


**1.** The ST connector uses a push/pull lock.
**Answer: False** — ST uses a bayonet lock; SC is push/pull.

**2.** MT-RJ is much larger than an RJ45.
**Answer: False** — it is the same size as an RJ45.

**3.** SC stands for subscriber channel.
**Answer: True** — subscriber channel (SC).
