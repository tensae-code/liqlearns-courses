# Infrared — short-range invisible light — true or false

Say whether each sentence is true or false.


**1.** You can see an infrared beam crossing the room.
**Answer: False** — infrared is invisible to the eye.

**2.** Infrared is used between a PC and a peripheral.
**Answer: True** — and for indoor LANs.

**3.** Infrared is a guided medium.
**Answer: False** — it is unguided — radiation through air.
