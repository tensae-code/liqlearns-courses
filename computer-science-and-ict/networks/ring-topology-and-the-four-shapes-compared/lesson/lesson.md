## Sub lesson 1 — Ring topology

In a **ring topology**, **each node connects only to its two neighbours**, forming a **ring**. A message for a distant node **passes through intermediate nodes acting as repeaters** — each **re-sends the signal at full strength** — and traffic flows in **one direction**. ## Sub lesson 2 — The four shapes compared

Rings are **easy to install and reconfigure**, and faults show up as **a node receiving nothing for a long time** — but **one failed node stops the whole ring**, so rings suit only **small node counts**.

The unit's comparison table sets the four side by side. **Bus:** cheap and little cable, but faults hard to isolate and one break stops all. **Mesh:** robust, secure, no congestion, faults easy to find — but costly and complex. **Star:** cheap, easy, robust — but the switch is a single point of failure. **Ring:** easy to install and reconfigure — but one failed node stops the ring. Choosing a topology is choosing which weakness you can live with.
