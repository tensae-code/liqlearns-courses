# Ring topology — and the four shapes compared — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Rings suit only small node counts.
**Answer: True** — one failure stops the ring.

**2. (Sub lesson 2)** A fault in a ring can show as a node receiving nothing for a long time.
**Answer: True** — that is the named sign.

**3. (Sub lesson 2)** Mesh is the cheapest topology to cable.
**Answer: False** — mesh is costly; bus and star are the cheaper shapes.
