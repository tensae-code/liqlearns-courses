# Asynchronous, Synchronous and Isochronous Transmission — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The receiver knowing where each bit and character begins**
**Answer: True**

**2. (Sub lesson 1) True or false: The receiver knowing where each bit and character begins** — as the answer to: What opens and closes an asynchronous character?
**Answer: False — A start bit and stop bits**

**3. (Sub lesson 1) True or false: Irregular traffic like a keyboard's**
**Answer: True**

**4. (Sub lesson 1) True or false: Irregular traffic like a keyboard's** — as the answer to: What is asynchronous transmission's price?
**Answer: False — Extra bits on every character**

**5. (Sub lesson 1) True or false: Yes — any length of time**
**Answer: True**

**6. (Sub lesson 2) True or false: Yes — any length of time** — as the answer to: What do synchronous sender and receiver share?
**Answer: False — A clock**

**7. (Sub lesson 2) True or false: In large blocks with small control frames**
**Answer: True**

**8. (Sub lesson 2) True or false: In large blocks with small control frames** — as the answer to: Why is synchronous transfer efficient for bulk?
**Answer: False — The timing tax is paid once per block**

**9. (Sub lesson 2) True or false: A rate with bounded delay**
**Answer: True**

**10. (Sub lesson 2) True or false: A rate with bounded delay** — as the answer to: Which traffic needs isochronous timing?
