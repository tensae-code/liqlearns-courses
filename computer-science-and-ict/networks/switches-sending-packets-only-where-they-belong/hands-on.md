# Hands-on — Switches — sending packets only where they belong

The lesson with your hands, not only your eyes.

## Two post offices
In a group, act the hub first: every message is copied to everyone. Then act the switch: read the name, deliver to one person only. Time both.

## Build the table
Draw a switch with four ports. Invent a table: computer name, address, port. Route three packets using only the table.
