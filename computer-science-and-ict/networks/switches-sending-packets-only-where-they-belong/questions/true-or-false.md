# Switches — sending packets only where they belong — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** A switch sends a copy to every port.
**Answer: False** — that is the hub; the switch forwards only to the destination.

**2. (Sub lesson 2)** A hub does not send back to the sender.
**Answer: True** — to every connected computer except the sender.

**3. (Sub lesson 2)** Printers and servers can connect through a switch.
**Answer: True** — named among the devices it interconnects.
