# Switches — sending packets only where they belong — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A switch forwards packets —
a) to every computer  b) only to their specific destination  c) to the sender only  d) to no one
**Answer: b) only to their specific destination** — only to the destination.

**2. (Sub lesson 1)** A switch learns —
a) passwords  b) each computer's physical address and its switch port  c) file names  d) web pages
**Answer: b) each computer's physical address and its switch port** — address and port, into a table.

**3. (Sub lesson 2)** A hub —
a) is intelligent  b) broadcasts everything to every connected computer except the sender  c) chooses the best route  d) stores web pages
**Answer: b) broadcasts everything to every connected computer except the sender** — it broadcasts.

**4. (Sub lesson 2)** A switch interconnects devices in —
a) a small network  b) one computer  c) a satellite  d) a single cable only
**Answer: a) a small network** — a small network.

**5. (Sub lesson 2)** Which device is called unintelligent?
a) The switch  b) The hub  c) The router  d) The NIC
**Answer: b) The hub** — the hub.
