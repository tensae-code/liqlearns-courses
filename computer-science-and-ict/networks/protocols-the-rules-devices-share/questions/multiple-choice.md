# Protocols — the rules devices share — multiple choice

Pick the one right answer.

**1.** A protocol is —
a) a cable  b) the set of rules governing data communication  c) a printer  d) a password
**Answer: b) the set of rules governing data communication** — rules governing data communication.

**2.** Devices must follow —
a) different rules each  b) the same rules to interact  c) no rules  d) paper rules only
**Answer: b) the same rules to interact** — the same rules.

**3.** Protocol software —
a) instructs devices how to connect and talk  b) prints pages  c) stores photos  d) boosts signals
**Answer: a) instructs devices how to connect and talk** — it instructs devices how to connect and talk.

**4.** IP is used for —
a) addressing devices and forwarding data between networks  b) drawing pictures  c) typing letters  d) charging phones
**Answer: a) addressing devices and forwarding data between networks** — addressing and forwarding.

**5.** IP's detail is promised for —
a) Grade 8  b) Grade 10  c) Grade 12 only  d) this lesson
**Answer: b) Grade 10** — Grade 10.
