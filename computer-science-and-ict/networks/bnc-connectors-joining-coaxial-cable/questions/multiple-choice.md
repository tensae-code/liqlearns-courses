# BNC connectors — joining coaxial cable — multiple choice

Pick the one right answer.


**1.** BNC stands for —
a) Binary Network Connector  b) Bayonet Neill-Concelman  c) Broadband Node Cable  d) Basic Network Clip
**Answer: b) Bayonet Neill-Concelman** — Bayonet Neill-Concelman.

**2.** The BNC T connector —
a) closes the end of a run  b) joins a device into a run of cable  c) joins fibre to copper  d) tests the cable
**Answer: b) joins a device into a run of cable** — the T taps a device into a run.

**3.** The BNC terminator —
a) starts the signal  b) closes the end of a run  c) doubles the signal  d) crimps the plug
**Answer: b) closes the end of a run** — it closes the end of a run.

**4.** BNC connectors join —
a) fibre-optic cable  b) coaxial cable  c) twisted pair only  d) satellites
**Answer: b) coaxial cable** — they join coaxial cable.

**5.** How many common BNC forms does the lesson teach?
a) two  b) three  c) four  d) six
**Answer: b) three** — three: plain, T, terminator.
