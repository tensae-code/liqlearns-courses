# BNC connectors — joining coaxial cable — true or false

Say whether each sentence is true or false.


**1.** The plain BNC connector closes the end of a cable run.
**Answer: False** — the terminator closes the end; the plain BNC joins cable to device.

**2.** A device can be joined into the middle of a coax run.
**Answer: True** — with the BNC T connector.

**3.** BNC connectors are used with fibre-optic cable.
**Answer: False** — BNC joins coaxial cable.
