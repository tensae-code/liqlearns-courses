# Keeping Our Network Secured — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Where is a network secured?**
a) At its doors — joining, opening, passwords  b) A door with no lock  c) Deliberately, file by file  d) The whole computer
**Answer: a**

**2. (Sub lesson 1) What is a shared password called in this lesson?**
a) A door with no lock  b) Deliberately, file by file  c) The whole computer  d) It is stopped and asked about — never waved through
**Answer: a**

**3. (Sub lesson 1) How should sharing be set?**
a) Deliberately, file by file  b) The whole computer  c) It is stopped and asked about — never waved through  d) Habits
**Answer: a**

**4. (Sub lesson 1) What is shared by accident, if careless?**
a) The whole computer  b) It is stopped and asked about — never waved through  c) Habits  d) Logging out, locking screens, reporting strange messages
**Answer: a**

**5. (Sub lesson 1) What happens to a stranger's request to join?**
