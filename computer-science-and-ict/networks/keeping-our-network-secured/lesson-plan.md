# Lesson plan — Keeping Our Network Secured

**Place in the curriculum:** ICT expansion — Bangladesh (2026-11-14) — in the title Networks on the ICT course ladder (TITLES.md). **The one thing this lesson teaches:** keeping our network secured: the class's own work of protecting the network they built — passwords, care with strangers and shared files, and watching the network's doors (Bangladesh Grade 7 Digital Technology, Learning Experience 6, Session 4).

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The doors of a network** — A network is secured at its **doors**: who may **join** it, who may **open** each shared thing, and what **passwords** guard both. The class's rules from the session: strong passwords that are never shared — a shared password is a door with no lock; sharing set deliberately, file by file, not the whole computer by accident; and care with **strangers' requests** — an unknown device or person asking to join or receive files is stopped and asked about, never waved through to be polite.
2. **Watching and habits — security as behaviour** — Tools guard a network once; **habits** guard it daily: logging out, locking screens, reporting the strange message instead of clicking it, and keeping the class's own list of who holds what access. The session's title is first-person plural — *we* will keep *our* network secured — because a network's security is the behaviour of everyone on it: one careless member is every member's risk. The security lessons of this course grow from this seed: the checklist, the policy, the cyber-intelligence unit all begin as a class keeping its own small network safe on purpose.
