# Star topology — true or false

Say whether each sentence is true or false.

**1.** A star is easy to install and reconfigure.
**Answer: True** — named among its strengths.

**2.** Star devices send messages directly to each other.
**Answer: False** — never directly — via the switch.

**3.** A failed node in a star stops the whole network.
**Answer: False** — a failed switch does; the star is otherwise robust.
