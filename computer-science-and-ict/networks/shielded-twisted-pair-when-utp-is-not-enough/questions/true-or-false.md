# Shielded twisted pair — when UTP is not enough — true or false

Say whether each sentence is true or false.


**1. (Sub lesson 1)** Twisting removes the need for shielding everywhere.
**Answer: False** — where interference sources are many, STP is preferred.

**Answer: True** — all three defences together.

**3. (Sub lesson 4)** In UTP, each pair is twisted at a different rate.
**Answer: True** — keyed in the guide — different rates cut interference.
