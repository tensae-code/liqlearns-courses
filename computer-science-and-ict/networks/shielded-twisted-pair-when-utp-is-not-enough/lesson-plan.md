# Lesson plan — Shielded twisted pair — when UTP is not enough

**Course:** Computer Science and ICT · **Title:** Networks · **Lesson:** Shielded twisted pair — when UTP is not enough
**Place in the curriculum:** Title — Networks in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 10 book, Unit 2 — Computer Network. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** Where interference is heavy, **STP** wraps each pair in **foil** and all pairs in a **braid or foil**, cutting **crosstalk and EMI/RFI**.
**This lesson's own level:** it stands on UTP cable, RJ45 — the learner already knows the unshielded cable this one improves on.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Crosstalk — wires troubling each other** — crosstalk defined; twisting reduces it; heavy-interference places
2. **STP — foil on each pair, braid over all** — foil per pair, braid or foil over all; cancellation + twisting + shielding
3. **Where STP serves** — fast Ethernet and telephone voice/data channels
4. **UTP against STP (teacher guide — evidence)** — the guide's keyed comparison

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: UTP cable, RJ45 and straight-through vs crossover. Recommended, never forced.

## What the learner can do when it ends
1. Say what crosstalk is.
2. Describe STP's two shielding layers.
3. Say which troubles STP cuts, from inside and outside.
4. Compare UTP and STP from the guide's key.

Paper and a pencil.

## If the learner is stuck
- If the learner cannot keep the layers apart: foil hugs each pair; the braid or foil hugs all four pairs together. Inside trouble = crosstalk; outside trouble = EMI/RFI.
