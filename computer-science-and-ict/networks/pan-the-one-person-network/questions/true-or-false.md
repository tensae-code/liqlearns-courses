# PAN — the one-person network — true or false

Say whether each sentence is true or false.

**1.** Bluetooth devices need cables to work together.
**Answer: False** — no cables — put them down, switch them on.

**2.** A PAN is the smallest network by size.
**Answer: True** — smallest on the size ladder.

**3.** Streaming a film to the TV can happen over a PAN.
**Answer: True** — one of the named examples.
