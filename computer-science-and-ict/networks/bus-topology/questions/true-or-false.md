# Bus topology — true or false

Say whether each sentence is true or false.

**1.** Adding nodes to a bus is flexible.
**Answer: False** — inflexible — tap spacing is optimised for the bus length.

**2.** A bus uses little cable.
**Answer: True** — one backbone serves all nodes.

**3.** Every bus node has a dedicated link to a switch.
**Answer: False** — that is the star; bus nodes share the backbone.
