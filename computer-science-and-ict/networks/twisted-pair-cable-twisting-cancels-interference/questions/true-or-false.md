# Twisted-pair cable — twisting cancels interference — true or false

Say whether each sentence is true or false.


**1. (Sub lesson 1)** Fibre is a guided medium that carries electric current.
**Answer: False** — fibre carries light; twisted pair and coax carry current.

**2. (Sub lesson 2)** The two wires in a twisted pair are insulated copper conductors.
**Answer: True** — two insulated copper conductors twisted together.

**3. (Sub lesson 3)** Parallel wires suffer interference equally.
**Answer: False** — parallel wires suffer unequally; twisting evens it.
