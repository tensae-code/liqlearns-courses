# Lesson plan — Twisted-pair cable — twisting cancels interference

**Course:** Computer Science and ICT · **Title:** Networks · **Lesson:** Twisted-pair cable — twisting cancels interference
**Place in the curriculum:** Title — Networks in the Computer Science and ICT ladder (TITLES.md); stocked from Ethiopia's Grade 10 book, Unit 2 — Computer Network. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** Two copper wires are **twisted together** so interference strikes both equally and **cancels at the receiver**.
**This lesson's own level:** it stands on Wired and wireless media — the learner already knows guided media carry the signal inside a conduit.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Guided media carry the signal inside a conduit** — guided media, copper for twisted pair and coax, light for fibre
2. **Two wires, one signal, one ground** — one wire carries the signal, the other is the ground reference
3. **Why the twist cancels interference** — twisting swaps the nearer wire each turn, so both suffer equally and noise cancels

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## What you need
Paper and a pencil; two pieces of string or wire if you have them.

## The run of the lesson (in order)
1. **Do it first** — Take two loose strings. Lay them side by side, straight. Now twist them round each other. The twisted pair is not decoration — this lesson shows what the twist does to noise. (lesson/lesson.md).

## If the learner is stuck
- If the learner thinks the twist is only for strength, return to the swap: at every turn the nearer wire changes, so the noise lands equally on both — and equal noise cancels.
