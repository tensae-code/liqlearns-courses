# Keeping a Message Secret — Packets, TCP and Encryption Keys — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Transmission Control Protocol**
**Answer: True**

**2. (Sub lesson 1) True or false: Transmission Control Protocol** — as the answer to: What does TCP number?
**Answer: False — The packets**

**3. (Sub lesson 1) True or false: Acknowledgements of what arrived**
**Answer: True**

**4. (Sub lesson 1) True or false: Acknowledgements of what arrived** — as the answer to: What happens to missing pieces under TCP?
**Answer: False — They are sent again**

**5. (Sub lesson 1) True or false: IP is the addressing; TCP is the promise-keeping**
**Answer: True**

**6. (Sub lesson 2) True or false: IP is the addressing; TCP is the promise-keeping** — as the answer to: What does encryption lock?
**Answer: False — The contents of the packets, with a key**

**7. (Sub lesson 2) True or false: Only scrambled data**
**Answer: True**

**8. (Sub lesson 2) True or false: Only scrambled data** — as the answer to: What if the pirate catches the key?
**Answer: False — The lock opens for them too — secrecy dies with the key's safety**

**9. (Sub lesson 2) True or false: Guard keys, change them, never send them alongside the message**
**Answer: True**

**10. (Sub lesson 2) True or false: Guard keys, change them, never send them alongside the message** — as the answer to: What does TCP alone not give?
**Answer: False — Secrecy — packets can arrive whole and still be read**
