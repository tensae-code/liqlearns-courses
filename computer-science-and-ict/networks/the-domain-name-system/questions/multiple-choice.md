# The Domain Name System — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does DNS stand for?**
a) Domain Name System  b) By IP addresses — numbers  c) By domain names — readable names  d) Translates a domain name into its IP address
**Answer: a**

**2. (Sub lesson 1) By what do machines reach each other?**
a) By domain names — readable names  b) By IP addresses — numbers  c) Translates a domain name into its IP address  d) A machine holding the name-and-number directory for its part of the internet
**Answer: b**

**3. (Sub lesson 1) By what do people visit sites?**
a) Translates a domain name into its IP address  b) A machine holding the name-and-number directory for its part of the internet  c) By domain names — readable names  d) The computer asks DNS, the server returns the number, the visit goes to that number
**Answer: c**

**4. (Sub lesson 1) What does DNS do?**
a) A machine holding the name-and-number directory for its part of the internet  b) The computer asks DNS, the server returns the number, the visit goes to that number  c) There is no visit, however healthy the connection  d) Translates a domain name into its IP address
**Answer: d**

**Answer: a**
