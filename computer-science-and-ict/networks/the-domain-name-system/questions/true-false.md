# The Domain Name System — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Domain Name System**
**Answer: True**

**2. (Sub lesson 1) True or false: By domain names — readable names** — as the answer to: By what do machines reach each other?
**Answer: False — By IP addresses — numbers**

**3. (Sub lesson 1) True or false: By domain names — readable names**
**Answer: True**

**4. (Sub lesson 1) True or false: A machine holding the name-and-number directory for its part of the internet** — as the answer to: What does DNS do?
**Answer: False — Translates a domain name into its IP address**

**5. (Sub lesson 1) True or false: A machine holding the name-and-number directory for its part of the internet**
**Answer: True**

**6. (Sub lesson 2) True or false: There is no visit, however healthy the connection** — as the answer to: What happens when a name is typed, in order?
**Answer: False — The computer asks DNS, the server returns the number, the visit goes to that number**

**7. (Sub lesson 2) True or false: There is no visit, however healthy the connection**
**Answer: True**

**8. (Sub lesson 2) True or false: IP is where a machine is; DNS is how people ask for it by name** — as the answer to: How do the parts of a domain name read?
**Answer: False — The name, then the ending that says its kind or country**

**9. (Sub lesson 2) True or false: IP is where a machine is; DNS is how people ask for it by name**
**Answer: True**

**10. (Sub lesson 2) True or false: Domain Name System** — as the answer to: Which chapter teaches this?
**Answer: False — Laos Grade 8 ICT, Chapter 5 §5.3.2**
