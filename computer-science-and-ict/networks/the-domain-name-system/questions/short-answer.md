# The Domain Name System — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does DNS stand for?**
**Answer: Domain Name System**

**2. (Sub lesson 1) By what do machines reach each other?**
**Answer: By IP addresses — numbers**

**3. (Sub lesson 1) By what do people visit sites?**
**Answer: By domain names — readable names**

**4. (Sub lesson 1) What does DNS do?**
**Answer: Translates a domain name into its IP address**

**5. (Sub lesson 1) What is a DNS server?**
**Answer: A machine holding the name-and-number directory for its part of the internet**

**6. (Sub lesson 2) What happens when a name is typed, in order?**
**Answer: The computer asks DNS, the server returns the number, the visit goes to that number**

**7. (Sub lesson 2) What happens if the name is not found?**
**Answer: There is no visit, however healthy the connection**

**8. (Sub lesson 2) How do the parts of a domain name read?**
**Answer: The name, then the ending that says its kind or country**

**9. (Sub lesson 2) Why is DNS taught beside IP addresses?**
**Answer: IP is where a machine is; DNS is how people ask for it by name**

**10. (Sub lesson 2) Which chapter teaches this?**
**Answer: Laos Grade 8 ICT, Chapter 5 §5.3.2**
