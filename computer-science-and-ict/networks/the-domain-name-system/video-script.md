# Video script — The Domain Name System

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Every computer on the internet is reached by an **IP address** — a number — but numbers are for machines: no user types a number to visit a school or a ministry. Instead they type a **domain name** — the readable name of a site, built in parts (the name, then the ending that says its kind or country). The **Domain Name System (DNS)** is the internet's service that **translates the name the person typed into the IP address the machines need**, before the visit can begin.
When a name is typed, the computer **asks DNS**: a **DNS server** — a machine holding the name-and-number directory for its part of the internet — **looks the name up and returns the number**, and the visit then goes to that number exactly as if it had been typed. If the name is not found, there is no visit, however healthy the connection — the famous failure that is a name problem, not a wire problem. Laos teaches DNS inside its addressing section because the pair is the whole addressing story: IP is where a machine is; DNS is how people ask for it by name.
