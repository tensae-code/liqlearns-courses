# MAN — a city's network — multiple choice

Pick the one right answer.

**1.** MAN stands for —
a) Main Area Network  b) Metropolitan Area Network  c) Mobile Access Network  d) Medium Area Network
**Answer: b) Metropolitan Area Network** — Metropolitan Area Network.

**2.** A MAN covers —
a) one room  b) one building  c) an entire city  d) the whole world only
**Answer: c) an entire city** — an entire city.

**3.** The book's MAN example joins —
a) three bank branches in one city  b) three countries  c) three phones  d) three printers
**Answer: a) three bank branches in one city** — three bank branches.

**4.** The bank's MAN runs over —
a) its own new cables only  b) the city's existing telephone network (Ethio-telecom's)  c) satellite only  d) Bluetooth
**Answer: b) the city's existing telephone network (Ethio-telecom's)** — the existing telephone network.

**5.** A MAN interconnects —
a) LANs across a city  b) only single computers  c) only peripherals  d) only cables
**Answer: a) LANs across a city** — building LANs across the city.
