# Project: set up a small peer-to-peer network — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Step 1 connects computers to the hub or switch with —
a) Bluetooth only  b) UTP cables  c) fibre only  d) paper
**Answer: b) UTP cables** — UTP cables.

**2. (Sub lesson 1)** Step 2 sets up —
a) a Windows Homegroup and chooses what to share  b) the Internet first  c) a server  d) a WAN
**Answer: a) a Windows Homegroup and chooses what to share** — a Homegroup.

**3. (Sub lesson 2)** Permission levels include —
a) view, or view and edit, or specific people  b) only full control for everyone  c) no levels exist  d) print only
**Answer: a) view, or view and edit, or specific people** — view / view-and-edit / specific people.

**4. (Sub lesson 2)** Step 4 tests by —
a) asking the teacher  b) browsing the shared folders from every computer  c) restarting all machines  d) deleting a folder
**Answer: b) browsing the shared folders from every computer** — browsing from every computer.

**5. (Sub lesson 2)** Internet access is enabled —
a) first, before cabling  b) only once file transfer is verified  c) never  d) before testing
**Answer: b) only once file transfer is verified** — only after transfer is verified.

**6. (Sub lesson 2)** Every Internet-connected machine needs —
a) a firewall and current Windows updates  b) a second screen  c) no password  d) a printer
**Answer: a) a firewall and current Windows updates** — firewall and updates.
