# Video script — Project: set up a small peer-to-peer network

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then. This is a FULL walkthrough script — the placements name a walkthrough need for this practical.

---

Five steps. In order. Do not skip.

Step one. Power the hub. Cable every computer to it. UTP cables.
Step two. Set up the Homegroup. Choose what to share.
Step three. Turn on discovery. Turn on file and printer sharing.
Folder by folder, choose: view — or view and edit — or specific people.
Step four. Test it. From every computer, open the shared folders.
Type the user name and password when asked.
Can every computer reach the files? Good.
Step five — only now — the Internet.
Every machine needs a firewall. Every machine needs its updates.
One sick computer can spread sickness to the whole network.

Five steps. In order. Your small network is built.
