# Hands-on — Project: set up a small peer-to-peer network

The lesson with your hands, not only your eyes.

## The full build
In a group of 2–5, build the network exactly in the five steps. Tick each step off only when the next computer proves it works.

## Permission drill
Set one folder to view-only and one to view-and-edit. From the second computer, prove the difference: open both, change only one.
