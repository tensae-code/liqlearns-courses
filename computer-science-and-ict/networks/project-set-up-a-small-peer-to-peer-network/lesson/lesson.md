# Project: set up a small peer-to-peer network

## Do it first

Build the last lessons for real: cable the machines, share a folder, open it from another computer. Follow the five steps in order — do not skip to the Internet step. Begin by powering the hub.

## Sub lesson 1 — Connect and share (steps 1–3)

**Step 1: connect the hardware** — a **hub or switch (usually a router with several LAN ports)** powered on, computers **cabled to it with UTP**. **Step 2: set up a Windows Homegroup** and **choose which libraries and devices to share**. **Step 3: turn on network discovery and file-and-printer sharing** in advanced sharing settings, then **set sharing options and a permission level — view, or view and edit, or specific people — folder by folder**.

## Sub lesson 2 — Test, then connect (steps 4–5)

**Step 4: test** by **browsing the shared folders from every computer**, entering a **user name and password** where asked. Watch the GIF: the shared folder opens from the second computer — the sharing works. **Step 5: only once file transfer is verified, enable Internet access** — with the warning: **every Internet-connected machine needs a firewall and current Windows updates**, because malicious activity entering through one computer spreads quickly through the whole network.
