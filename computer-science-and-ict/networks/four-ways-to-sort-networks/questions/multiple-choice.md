# Four ways to sort networks — multiple choice

Pick the one right answer.

**1.** Networks are sorted by how many perspectives?
a) Two  b) Three  c) Four  d) Six
**Answer: c) Four** — four perspectives.

**2.** PAN, LAN, MAN and WAN are sorted by —
a) medium  b) size or geographical coverage  c) topology  d) access
**Answer: b) size or geographical coverage** — size / coverage.

**3.** Bus, mesh, star and ring are sorted by —
a) medium  b) size  c) topology  d) access
**Answer: c) topology** — topology — the shape.

**4.** Peer-to-peer and client-server are sorted by —
a) medium  b) size  c) topology  d) resource security and access
**Answer: d) resource security and access** — security and access.

**5.** Wired and wireless are sorted by —
a) connection medium  b) size  c) topology  d) access
**Answer: a) connection medium** — the connection medium.
