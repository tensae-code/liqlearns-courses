# Wi-Fi — Wireless LAN Technology — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Wireless LAN technology — devices joining a network by radio**
**Answer: True**

**2. (Sub lesson 1) True or false: Wireless LAN technology — devices joining a network by radio** — as the answer to: What do devices connect to?
**Answer: False — An access point**

**3. (Sub lesson 1) True or false: 2.4 GHz and 5 GHz**
**Answer: True**

**4. (Sub lesson 1) True or false: 2.4 GHz and 5 GHz** — as the answer to: Which band travels farther?
**Answer: False — 2.4 GHz**

**5. (Sub lesson 1) True or false: 5 GHz, over shorter reach**
**Answer: True**

**6. (Sub lesson 2) True or false: 5 GHz, over shorter reach** — as the answer to: Why is range also risk?
**Answer: False — Radio crosses walls — the network extends into the street**

**7. (Sub lesson 2) True or false: Listening in (also password guessing, false access points)**
**Answer: True**

**8. (Sub lesson 2) True or false: Listening in (also password guessing, false access points)** — as the answer to: Name two defences.
**Answer: False — A strong network password and WPA2/WPA3 encryption (also changing the router admin password)**

**9. (Sub lesson 2) True or false: That other listeners are present**
**Answer: True**

**10. (Sub lesson 2) True or false: That other listeners are present** — as the answer to: What does the access point join the wireless devices to?
**Answer: False — The wired network and the internet**
