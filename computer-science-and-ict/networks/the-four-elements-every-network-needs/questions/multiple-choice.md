# The four elements every network needs — multiple choice

Pick the one right answer.

**1.** How many fundamental elements does every network have?
a) Two  b) Three  c) Four  d) Five
**Answer: c) Four** — four elements.

**2.** Which element manages the connected end devices and services?
a) Hardware  b) Network software  c) The medium  d) A printer
**Answer: b) Network software** — network software.

**3.** The medium can be —
a) wired or wireless  b) only wired  c) only wireless  d) paper
**Answer: a) wired or wireless** — wired or wireless.

**4.** Hardware splits into —
a) end devices and intermediary devices  b) cables and air  c) senders and disks  d) rules and software
**Answer: a) end devices and intermediary devices** — end and intermediary devices.

**5.** A network missing one element —
a) works slowly  b) cannot function  c) works on one computer  d) needs Bluetooth
**Answer: b) cannot function** — it cannot function without each element.
