# The four elements every network needs — true or false

Say whether each sentence is true or false.

**1.** Protocols are one of the four elements.
**Answer: True** — hardware, software, protocols, medium.

**2.** The medium carries messages between end devices.
**Answer: True** — that is its job.

**3.** Network software is a physical device.
**Answer: False** — software manages devices and services; hardware is physical.
