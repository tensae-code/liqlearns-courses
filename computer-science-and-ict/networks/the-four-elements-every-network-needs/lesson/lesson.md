# The four elements every network needs

## Do it first

Name four things you would need before two computers could talk to each other at all. Hold your list — this lesson names the four every network needs, and none of them can be left out.

## Four elements, none missing

Every network is built from **four elements**, and it **cannot function without** any one of them: **hardware**, **network software**, **protocols**, and the **connection / transmission medium**.

## What each element does

**Hardware** is the physical equipment. **Network software** manages the connected end devices and the services. **Protocols** are the shared rules (their own lesson is ahead). The **medium** — **wired or wireless** — carries messages between end devices. The hardware itself splits into two kinds: **end devices** and **intermediary devices** — the next lessons take them one by one.
