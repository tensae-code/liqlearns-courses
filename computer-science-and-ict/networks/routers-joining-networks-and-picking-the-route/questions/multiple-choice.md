# Routers — joining networks and picking the route — multiple choice

Pick the one right answer.

**1.** A router is likened to —
a) a postman in one building  b) a taxi driver choosing among streets  c) a printer  d) a cable layer
**Answer: b) a taxi driver choosing among streets** — a taxi driver choosing by distance and traffic.

**2.** Routing means —
a) storing files  b) finding the best path for messages  c) printing addresses  d) boosting signals
**Answer: b) finding the best path for messages** — finding the best path.

**3.** A router connects —
a) identical cables only  b) dissimilar, different networks together  c) a keyboard to a screen  d) files to folders
**Answer: b) dissimilar, different networks together** — different networks together.

**4.** If sender and receiver are on the same switch, the router —
a) is always needed  b) is not needed  c) must approve the message  d) stores the message
**Answer: b) is not needed** — not needed.

**5.** A routing table holds —
a) passwords  b) destination networks and interface numbers  c) file sizes  d) user names
**Answer: b) destination networks and interface numbers** — destination networks and interfaces.
