# Hands-on — Configuring Network Devices

The lesson with your hands and your feet, not only your eyes.

## Task one
**Configure on paper** — Design a four-device school network. Write each device's full settings — address, gateway, name service — and the order you would set and test them in.

## Task two
**Hunt the stranger** — Given a settings table for five devices where one holds another network's gateway and two share an address, find both faults and write the corrections.
