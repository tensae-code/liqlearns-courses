# Virtual Private Networks — VPN — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does VPN stand for?**
a) Virtual private network  b) A private connection across a public network  c) It is encrypted — wrapped so only the two ends can read it  d) Because no new wire is laid
**Answer: a) Virtual private network**

**2. (Sub lesson 1) What does a VPN make?**
a) It is encrypted — wrapped so only the two ends can read it  b) A private connection across a public network  c) Because no new wire is laid  d) Because encryption keeps everyone else out
**Answer: b) A private connection across a public network**

**3. (Sub lesson 1) How is the data protected on the public road?**
a) Because no new wire is laid  b) Because encryption keeps everyone else out  c) It is encrypted — wrapped so only the two ends can read it  d) Virtual private network
**Answer: c) It is encrypted — wrapped so only the two ends can read it**

**4. (Sub lesson 1) Why is it called virtual?**
a) Because encryption keeps everyone else out  b) Virtual private network  c) A private connection across a public network  d) Because no new wire is laid
**Answer: d) Because no new wire is laid**

**5. (Sub lesson 1) Why is it called private?**
a) Because encryption keeps everyone else out  b) Virtual private network  c) A private connection across a public network  d) It is encrypted — wrapped so only the two ends can read it
**Answer: a) Because encryption keeps everyone else out**

**6. (Sub lesson 2) What job does the guide name for a VPN?**
a) A branch office reaching head office files  b) Joining separated sites and people as if on one local network  c) The public internet  d) Its own locked carriage — privacy
**Answer: b) Joining separated sites and people as if on one local network**

**7. (Sub lesson 2) Give one user of a VPN from the lesson.**
a) The public internet  b) Its own locked carriage — privacy  c) A branch office reaching head office files  d) The privacy of a private one

**8. (Sub lesson 2) What road does a VPN use?**
a) Its own locked carriage — privacy  b) The privacy of a private one  c) Joining separated sites and people as if on one local network  d) The public internet

**9. (Sub lesson 2) What does the organisation keep on that road?**
a) Its own locked carriage — privacy  b) The privacy of a private one  c) Joining separated sites and people as if on one local network  d) A branch office reaching head office files
**Answer: a) Its own locked carriage — privacy**

**10. (Sub lesson 2) Finish the lesson's summary: the reach of a public network with…**
