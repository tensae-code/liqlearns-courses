# IP addresses — IPv4 and IPv6 — fill in the blank

Fill each blank with the right word.


**1. (Sub lesson 1)** IP stands for ______ Protocol.
**Answer: Internet**

**2. (Sub lesson 2)** IPv4 is written as ______ numbers separated by dots.
**Answer: four**

**3. (Sub lesson 2)** Each of the four numbers is called an ______.
**Answer: octet**


**4. (Sub lesson 3)** One worked address in the guide's key is 137.142.______.49.
**Answer: 208**
