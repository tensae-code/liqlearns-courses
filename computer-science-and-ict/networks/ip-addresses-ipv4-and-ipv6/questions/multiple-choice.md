# IP addresses — IPv4 and IPv6 — multiple choice

Pick the one right answer.


**1. (Sub lesson 1)** An IP address is —
a) a cable type  b) the unique address identifying a device on a network  c) a password  d) a satellite orbit
**Answer: b) the unique address identifying a device on a network** — unique device address.

**2. (Sub lesson 1)** IP addresses carry location information so information can be —
a) printed  b) routed between computers, routers and websites  c) compressed  d) crimped
**Answer: b) routed between computers, routers and websites** — routed.

**3. (Sub lesson 2)** IPv4 addresses are —
a) 16-bit  b) 32-bit  c) 64-bit  d) 8-bit
**Answer: b) 32-bit** — 32-bit.

**4. (Sub lesson 2)** In dotted decimal, each of the four numbers runs —
a) 0–99  b) 0–255  c) 1–1000  d) 0–9
**Answer: b) 0–255** — 0–255.

**5. (Sub lesson 3)** In the guide's worked key, one converted address is —
a) 94.176.117.21  b) 300.400.1.1  c) 1.2.3  d) 94-176-117-21
**Answer: a) 94.176.117.21** — 94.176.117.21.
