# IP addresses — IPv4 and IPv6 — true or false

Say whether each sentence is true or false.


**1. (Sub lesson 1)** Two devices on one network share one IP address.
**Answer: False** — the address is unique to the device.

**2. (Sub lesson 2)** IPv6 is the common current version.
**Answer: False** — IPv4 is the common current one; IPv6 stands beside it.

**3. (Sub lesson 2)** Each number in a dotted-decimal address is an octet.
**Answer: True** — four octets — the book's 'Octate' is a misprint.
