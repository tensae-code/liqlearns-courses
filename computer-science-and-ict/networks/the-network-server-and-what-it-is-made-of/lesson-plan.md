# Lesson plan — The Network Server and What It Is Made Of

**Course:** Computer Science and ICT · **Title:** Networks · **Lesson:** The Network Server and What It Is Made Of
**Place in the curriculum:** ICT expansion — Sudan (2026-11-14) — in the title Networks on the ICT course ladder (TITLES.md). Built new from Sudan's Grade 6 ICT student book, because no existing lesson in the course covers this thing as its own lesson.
**The one thing this lesson teaches:** In a client–server network one computer works for all the others: the server. The book names the server's parts: a fast processor to answer many requests at once; the motherboard that joins everything; a network (modem) adaptor — the card that connects the server to the network; a strong power supply; its operating system, which runs the serving programs; and a UPS — an uninterruptible power supply that keeps the server alive through a cut in the electricity, so the network's heart never stops without warning.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **What a network server is** — In a client–server network one computer works for all the others: the **server**. It holds the **shared files and programs** in one place, answers the client computers' requests, and keeps the network's data where it can be guarded and backed up. The clients ask; the server serves. Because the whole network leans on it, a server is built stronger than an ordinary computer — and Sudan's Grade 6 book takes it apart to show why.
2. **The parts of a server** — The book names the server's parts: a fast **processor** to answer many requests at once; the **motherboard** that joins everything; a **network (modem) adaptor** — the card that connects the server to the network; a strong **power supply**; its **operating system**, which runs the serving programs; and a **UPS** — an uninterruptible power supply that keeps the server alive through a cut in the electricity, so the network's heart never stops without warning. Miss any one part and the serving fails: the parts are the lesson.
