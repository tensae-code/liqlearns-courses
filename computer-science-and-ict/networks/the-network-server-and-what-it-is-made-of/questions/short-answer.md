# The Network Server and What It Is Made Of — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a server?**
**Answer: The computer that works for all the others in a client–server network**

**2. (Sub lesson 1) What does a server hold?**
**Answer: The shared files and programs, in one place**

**3. (Sub lesson 1) Who asks and who serves?**
**Answer: The clients ask; the server serves**

**4. (Sub lesson 1) Why is a server built stronger than an ordinary computer?**
**Answer: Because the whole network leans on it**

**5. (Sub lesson 1) What does the server's processor do?**
**Answer: Answers many requests at once**

**6. (Sub lesson 2) What joins all the server's parts together?**
**Answer: The motherboard**

**7. (Sub lesson 2) What connects the server to the network?**
**Answer: Its network (modem) adaptor card**

**8. (Sub lesson 2) What is a UPS?**
**Answer: An uninterruptible power supply that keeps the server alive through a cut in the electricity**

**9. (Sub lesson 2) What runs the server's serving programs?**
**Answer: Its operating system**

**10. (Sub lesson 2) What happens if one named part is missing?**
**Answer: The serving fails — each part has a job the others cannot do**
