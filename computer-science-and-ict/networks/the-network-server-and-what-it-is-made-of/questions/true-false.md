# The Network Server and What It Is Made Of — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a server?" is: The computer that works for all the others in a client–server network**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does a server hold?" is: Because the whole network leans on it**
**Answer: False** — The shared files and programs, in one place

**3. (Sub lesson 1) True or false: the answer to "Who asks and who serves?" is: The clients ask; the server serves**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Why is a server built stronger than an ordinary computer?" is: The motherboard**
**Answer: False** — Because the whole network leans on it

**5. (Sub lesson 1) True or false: the answer to "What does the server's processor do?" is: Answers many requests at once**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What joins all the server's parts together?" is: An uninterruptible power supply that keeps the server alive through a cut in the electricity**
**Answer: False** — The motherboard

**7. (Sub lesson 2) True or false: the answer to "What connects the server to the network?" is: Its network (modem) adaptor card**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is a UPS?" is: The serving fails — each part has a job the others cannot do**
**Answer: False** — An uninterruptible power supply that keeps the server alive through a cut in the electricity

**9. (Sub lesson 2) True or false: the answer to "What runs the server's serving programs?" is: Its operating system**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What happens if one named part is missing?" is: The shared files and programs, in one place**
**Answer: False** — The serving fails — each part has a job the others cannot do
