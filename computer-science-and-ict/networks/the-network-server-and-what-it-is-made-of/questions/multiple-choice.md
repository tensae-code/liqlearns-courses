# The Network Server and What It Is Made Of — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What is a server?**
a) The computer that works for all the others in a client–server network  b) The shared files and programs, in one place  c) Because the whole network leans on it  d) The motherboard
**Answer: a) The computer that works for all the others in a client–server network**

**2. (Sub lesson 1) What does a server hold?**
a) The clients ask; the server serves  b) The shared files and programs, in one place  c) Answers many requests at once  d) Its network (modem) adaptor card
**Answer: b) The shared files and programs, in one place**

**3. (Sub lesson 1) Who asks and who serves?**
a) Because the whole network leans on it  b) The motherboard  c) The clients ask; the server serves  d) An uninterruptible power supply that keeps the server alive through a cut in the electricity
**Answer: c) The clients ask; the server serves**

**4. (Sub lesson 1) Why is a server built stronger than an ordinary computer?**
a) Answers many requests at once  b) Its network (modem) adaptor card  c) Its operating system  d) Because the whole network leans on it
**Answer: d) Because the whole network leans on it**

**5. (Sub lesson 1) What does the server's processor do?**
a) Answers many requests at once  b) The motherboard  c) An uninterruptible power supply that keeps the server alive through a cut in the electricity  d) The serving fails — each part has a job the others cannot do
**Answer: a) Answers many requests at once**

**6. (Sub lesson 2) What joins all the server's parts together?**
a) Its network (modem) adaptor card  b) The motherboard  c) Its operating system  d) The computer that works for all the others in a client–server network
**Answer: b) The motherboard**

**7. (Sub lesson 2) What connects the server to the network?**
a) An uninterruptible power supply that keeps the server alive through a cut in the electricity  b) The serving fails — each part has a job the others cannot do  c) Its network (modem) adaptor card  d) The shared files and programs, in one place
**Answer: c) Its network (modem) adaptor card**

**8. (Sub lesson 2) What is a UPS?**
a) Its operating system  b) The computer that works for all the others in a client–server network  c) The clients ask; the server serves  d) An uninterruptible power supply that keeps the server alive through a cut in the electricity
**Answer: d) An uninterruptible power supply that keeps the server alive through a cut in the electricity**

**9. (Sub lesson 2) What runs the server's serving programs?**
a) Its operating system  b) The serving fails — each part has a job the others cannot do  c) The shared files and programs, in one place  d) Because the whole network leans on it
**Answer: a) Its operating system**

**10. (Sub lesson 2) What happens if one named part is missing?**
a) The computer that works for all the others in a client–server network  b) The serving fails — each part has a job the others cannot do  c) The clients ask; the server serves  d) Answers many requests at once
**Answer: b) The serving fails — each part has a job the others cannot do**
