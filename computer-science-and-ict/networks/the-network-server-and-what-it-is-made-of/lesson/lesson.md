# The Network Server and What It Is Made Of

## Do it first

A school office has one cupboard where every class register is kept, and one clerk who fetches them. If the clerk is absent, no register moves. In this lesson you meet the computer that plays that clerk for a whole network — and open it up to see what it is made of.

## Sub lesson 1 — What a network server is

In a client–server network one computer works for all the others: the **server**. It holds the **shared files and programs** in one place, answers the client computers' requests, and keeps the network's data where it can be guarded and backed up. The clients ask; the server serves. Because the whole network leans on it, a server is built stronger than an ordinary computer — and Sudan's Grade 6 book takes it apart to show why.

## Sub lesson 2 — The parts of a server

The book names the server's parts: a fast **processor** to answer many requests at once; the **motherboard** that joins everything; a **network (modem) adaptor** — the card that connects the server to the network; a strong **power supply**; its **operating system**, which runs the serving programs; and a **UPS** — an uninterruptible power supply that keeps the server alive through a cut in the electricity, so the network's heart never stops without warning. Miss any one part and the serving fails: the parts are the lesson.
