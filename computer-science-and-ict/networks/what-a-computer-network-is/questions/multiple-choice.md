# What a computer network is — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A computer network is —
a) one computer alone  b) two or more computers linked to share resources or communicate  c) a single printer  d) a kind of cable
**Answer: b) two or more computers linked to share resources or communicate** — linked computers sharing or communicating.

**2. (Sub lesson 1)** Which of these can a network share?
a) Only games  b) Printers, files and disks  c) Nothing  d) Only television
**Answer: b) Printers, files and disks** — resources named in the lesson.

**3. (Sub lesson 2)** Sharing a file by Bluetooth from a phone is —
a) not a network  b) an everyday example of a network  c) a WAN  d) a cable
**Answer: b) an everyday example of a network** — an everyday network.

**4. (Sub lesson 2)** The largest global network is —
a) a home network  b) Bluetooth  c) the Internet  d) a printer
**Answer: c) the Internet** — the Internet.

**5. (Sub lesson 2)** In the home network, devices join through —
a) each other directly only  b) one central device  c) the television aerial  d) a disk
**Answer: b) one central device** — one central device.

**6. (Sub lesson 2)** An ISP such as Ethio-telecom connects the home network —
a) to a global network  b) to a printer  c) to Bluetooth only  d) to a disk
**Answer: a) to a global network** — onward to a global network.
