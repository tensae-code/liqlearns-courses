# What a computer network is — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** A network must use cables.
**Answer: False** — Bluetooth sharing is a network with no cable.

**2. (Sub lesson 2)** Networks let computers communicate electronically.
**Answer: True** — that is part of the definition.

**3. (Sub lesson 2)** Work can become remote through networks.
**Answer: True** — one of the four shifts (teacher-guide evidence).
