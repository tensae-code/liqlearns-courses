# The network interface card — multiple choice

Pick the one right answer.

**1.** NIC stands for —
a) Network Internet Cable  b) Network Interface Card  c) New Internal Computer  d) Network Information Centre
**Answer: b) Network Interface Card** — Network Interface Card.

**2.** The NIC's job is to —
a) print documents  b) connect a computer to a network  c) store files  d) boost signals
**Answer: b) connect a computer to a network** — it connects the computer to the network.

**3.** In most laptops the NIC is —
a) missing  b) integrated into the board  c) a separate room  d) wireless only
**Answer: b) integrated into the board** — integrated into the board.

**4.** The NIC carries —
a) the slot the network cable plugs into  b) the printer paper  c) the screen  d) the keyboard
**Answer: a) the slot the network cable plugs into** — the cable slot.

**5.** The NIC is a —
a) software rule  b) hardware component  c) protocol  d) medium
**Answer: b) hardware component** — hardware.
