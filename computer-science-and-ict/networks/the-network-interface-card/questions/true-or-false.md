# The network interface card — true or false

Say whether each sentence is true or false.

**1.** A NIC can be a card plugged into the system.
**Answer: True** — one of its two forms.

**2.** A laptop never has a NIC.
**Answer: False** — most laptops have it integrated into the board.

**3.** The network cable plugs into the NIC.
**Answer: True** — the NIC carries that slot.
