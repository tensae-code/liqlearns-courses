# The network interface card — fill in the blank

Fill each blank with the right word.

**1.** The ______ connects a computer to a network.
**Answer: NIC (Network Interface Card)**

**2.** A NIC is either a plugged-in card or ______ into the board.
**Answer: integrated**

**3.** The network ______ plugs into the NIC's slot.
**Answer: cable**
