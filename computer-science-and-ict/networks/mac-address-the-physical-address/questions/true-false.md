# MAC Address — the Physical Address — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a MAC address?" is: The physical address fixed into a network card when it was made**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does the MAC address name?" is: No — each card carries a different one**
**Answer: False** — The device itself, wherever it goes

**3. (Sub lesson 1) True or false: the answer to "How is a MAC address written?" is: As six pairs of hexadecimal digits separated by colons or dashes**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Can two network cards share one MAC address?" is: The IP address**
**Answer: False** — No — each card carries a different one

**5. (Sub lesson 1) True or false: the answer to "What does an IP address name?" is: A device's place on a network — its logical address**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Which address changes when a device joins a new network?" is: To route data across networks to the right building**
**Answer: False** — The IP address

**7. (Sub lesson 2) True or false: the answer to "Which address stays with the device for life?" is: The MAC address**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is the IP address's job in delivery?" is: IP is where you are; MAC is who you are**
**Answer: False** — To route data across networks to the right building

**9. (Sub lesson 2) True or false: the answer to "What is the MAC address's job in delivery?" is: To hand the data to the exact card inside that building**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Say the difference in one line." is: The device itself, wherever it goes**
**Answer: False** — IP is where you are; MAC is who you are
