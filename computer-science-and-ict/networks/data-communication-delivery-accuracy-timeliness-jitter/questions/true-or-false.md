# Data communication — delivery, accuracy, timeliness, jitter — true or false

Say whether each sentence is true or false.


**1. (Sub lesson 1)** The teacher guide files data communication inside Satellite Networks.
**Answer: False** — the student book does; the guide gives it its own §2.7.

**2. (Sub lesson 2)** Timeliness and jitter are the same characteristic.
**Answer: False** — timeliness is on-time arrival; jitter is even timing.

**3. (Sub lesson 3)** A protocol is one of the five components.
**Answer: True** — message, sender, receiver, medium, protocol.
