# Hands-on — Data communication — delivery, accuracy, timeliness, jitter

The lesson with your hands, not only your eyes.


## Four-test post
Pass a written message around the class hand to hand. Break one rule at a time (wrong person, changed word, long delay, bunched timing) — the class names which characteristic failed.

## Component labels
Draw one real data journey (a photo shared by Bluetooth) and label its five components.
