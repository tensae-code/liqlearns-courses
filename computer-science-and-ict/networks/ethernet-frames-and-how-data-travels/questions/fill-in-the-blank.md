# Ethernet Frames and How Data Travels — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 1) A MAC address inside a frame is ____ bytes long.**
**Answer: 6 — Each MAC address occupies six bytes, written as pairs such as 3C:7A:9F.**

**2. (Sub lesson 2) The tool the SNT book uses to capture and read real frames is called ____.**
**Answer: Wireshark — Wireshark captures frames on the network and displays them byte by byte.**
