# Ethernet Frames and How Data Travels — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) The source MAC address comes before the destination MAC address in a frame.**
**Answer: False — The destination comes first, so a device can decide quickly whether the frame is for it; the source follows.**

**2. (Sub lesson 2) When the check sequence does not match, the receiver keeps the frame and guesses the damaged part.**
**Answer: False — A mismatch means the frame is discarded; the data must be sent again.**
