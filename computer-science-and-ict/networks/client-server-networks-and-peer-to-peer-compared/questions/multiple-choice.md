# Client-server networks — and peer-to-peer compared — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** In client-server, clients —
a) provide all resources  b) request; the server responds and provides  c) never connect  d) replace the server
**Answer: b) request; the server responds and provides** — clients request, the server provides.

**2. (Sub lesson 1)** Most resources are installed —
a) on every client  b) on the central server  c) on paper  d) on the printer only
**Answer: b) on the central server** — on the server.

**3. (Sub lesson 2)** Software is easier to upgrade in client-server because —
a) clients are faster  b) it is held on one machine  c) there is no software  d) peers upgrade it
**Answer: b) it is held on one machine** — held on one machine.

**4. (Sub lesson 2)** Security in client-server is —
a) trust-based only  b) enhanced, because the server handles it  c) absent  d) share-level only
**Answer: b) enhanced, because the server handles it** — the server handles it.

**5. (Sub lesson 2)** In the comparison, peer-to-peer data is —
a) centralised  b) held by each peer itself  c) held by one server  d) not held at all
**Answer: b) held by each peer itself** — each peer its own data.

**6. (Sub lesson 2)** As peers grow, peer-to-peer becomes —
a) more stable  b) less stable  c) a server  d) a WAN
**Answer: b) less stable** — less stable as peers grow.
