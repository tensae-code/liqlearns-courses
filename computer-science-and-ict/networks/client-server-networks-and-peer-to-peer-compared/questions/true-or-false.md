# Client-server networks — and peer-to-peer compared — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Clients in client-server need not share anything themselves.
**Answer: True** — the server provides.

**2. (Sub lesson 2)** Client-server is the cheaper of the two kinds.
**Answer: False** — client-server is costlier; peer-to-peer is cheaper.

**3. (Sub lesson 2)** System-wide services can run from the server.
**Answer: True** — named among the gains.
