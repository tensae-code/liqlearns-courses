# Video script — Client-server networks — and peer-to-peer compared

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

In a client-server network, multiple clients (workstations) connect to at least one central server where most resources are installed. Clients request; the server responds and provides. Clients need not share anything themselves, software is easier to upgrade because it is held on one machine, system-wide services run from the server, and security is enhanced because the server handles it.
