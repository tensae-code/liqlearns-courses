# LAN — a building's network — true or false

Say whether each sentence is true or false.

**1.** A LAN can hold thousands of computers.
**Answer: True** — large ones hold thousands.

**2.** A LAN spans a whole country.
**Answer: False** — a few kilometres — one building or campus.

**3.** A LAN shares storage, printers, programs and data.
**Answer: True** — the named resources.
