# Network Transfer Speed and Bandwidth — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does transfer speed count?" is: How much data crosses a link in one second**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "In what unit is transfer speed measured?" is: Eight**
**Answer: False** — Bits per second (bps) — scaling to kbps, Mbps and Gbps

**3. (Sub lesson 1) True or false: the answer to "How many bits are in one byte?" is: Eight**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is the most a 100 Mbps link can move in one second, in bytes?" is: Time = data size ÷ speed, with both sides in the same unit**
**Answer: False** — 12.5 megabytes

**5. (Sub lesson 1) True or false: the answer to "What is the formula for transfer time?" is: Time = data size ÷ speed, with both sides in the same unit**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is bandwidth?" is: The link is shared, and the path moves at its slowest link, with distance, interference and devices taking a share**
**Answer: False** — The link's capacity — the widest flow it can carry

**7. (Sub lesson 2) True or false: the answer to "Why is the speed a user gets usually below the bandwidth?" is: The link is shared, and the path moves at its slowest link, with distance, interference and devices taking a share**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What decides a multi-link path's speed?" is: At the end of the Grade 10 networks chapter, after packets, IP addresses and protocols**
**Answer: False** — Its slowest link

**9. (Sub lesson 2) True or false: the answer to "Where does Egypt place this lesson?" is: At the end of the Grade 10 networks chapter, after packets, IP addresses and protocols**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Name two planning jobs this number serves?" is: How much data crosses a link in one second**
**Answer: False** — Choosing a connection and judging how long a download will take
