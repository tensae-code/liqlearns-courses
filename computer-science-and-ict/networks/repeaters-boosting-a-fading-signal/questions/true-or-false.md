# Repeaters — boosting a fading signal — true or false

Say whether each sentence is true or false.

**1.** A repeater sends the signal on at its original strength.
**Answer: True** — regenerated to full strength.

**2.** An amplifier regenerates a clean signal.
**Answer: False** — an amplifier boosts noise along with the signal.

**3.** A repeater can extend a network beyond one cable segment.
**Answer: True** — that is why it is used.
