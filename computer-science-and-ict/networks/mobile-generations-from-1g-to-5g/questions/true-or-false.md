# Mobile generations — from 1G to 5G — true or false

Say whether each sentence is true or false.


**1. (Sub lesson 1)** 1G is the newest generation.
**Answer: False** — 1G is obsolete; the present is 4G.

**2. (Sub lesson 2)** 4G's other name is mobile broadband everywhere.
**Answer: True** — earned by its aims.

**3. (Sub lesson 3)** 5G is only about faster downloads.
**Answer: False** — it goes beyond speed — flexibility, latency, capacity.
