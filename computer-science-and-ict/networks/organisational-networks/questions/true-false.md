# Organisational Networks — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is an intranet?" is: A private network inside one organisation, using internet ways — pages, browsers, email**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Who may enter an intranet?" is: Its notices, shared files and internal mail**
**Answer: False** — Only the organisation's own people

**3. (Sub lesson 1) True or false: the answer to "What does a school intranet carry?" is: Its notices, shared files and internal mail**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is the intranet's value, in Fiji's phrase?" is: Yes — web pages and browsers, on a private network**
**Answer: False** — Exactly its wall — internet tools with the public left outside

**5. (Sub lesson 1) True or false: the answer to "Are intranet pages web pages?" is: Yes — web pages and browsers, on a private network**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is an extranet?" is: Suppliers checking orders, or parents reading reports**
**Answer: False** — Part of an intranet opened to chosen outsiders

**7. (Sub lesson 2) True or false: the answer to "Give an extranet example." is: Suppliers checking orders, or parents reading reports**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How are extranet visitors let in?" is: The internet itself — the public network everyone may enter**
**Answer: False** — To their part only, by account and password

**9. (Sub lesson 2) True or false: the answer to "What is the third circle?" is: The internet itself — the public network everyone may enter**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Name Fiji's three circles." is: A private network inside one organisation, using internet ways — pages, browsers, email**
**Answer: False** — Intranet (ours), extranet (ours, shared by invitation), internet (everyone's)
