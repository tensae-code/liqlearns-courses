# Peer-to-peer networks

## Do it first

Imagine a study group with no leader: everyone can share their notes with everyone, nobody is in charge. Draw that group as computers. That is this lesson's network.

## Every machine an equal

In a **peer-to-peer network**, **every machine is a peer — an equal** — able to **share files and resources**. There is **no server and no hierarchy**; it is also called a **workgroup**.

## Cheap and equal — small only

Advantages: **no server and no dedicated-machine cost**, and **all computers are equal**. Disadvantages: security is only **share-level, trust-based**, and it works only in **small environments — beyond about ten computers, administration becomes very difficult**.
