# Peer-to-peer networks — multiple choice

Pick the one right answer.

**1.** In peer-to-peer, every machine is —
a) a client only  b) a peer — an equal  c) a server  d) a guest
**Answer: b) a peer — an equal** — a peer, an equal.

**2.** Peer-to-peer has —
a) one central server  b) no server and no hierarchy  c) a strict hierarchy  d) ten servers
**Answer: b) no server and no hierarchy** — no server, no hierarchy.

**3.** Peer-to-peer is also called a —
a) workgroup  b) domain  c) WAN  d) backbone
**Answer: a) workgroup** — a workgroup.

**4.** Its security is —
a) server-handled  b) share-level and trust-based  c) military grade  d) automatic
**Answer: b) share-level and trust-based** — share-level, trust-based.

**5.** Beyond about how many computers does administration become very difficult?
a) Three  b) Ten  c) A hundred  d) A thousand
**Answer: b) Ten** — about ten.
