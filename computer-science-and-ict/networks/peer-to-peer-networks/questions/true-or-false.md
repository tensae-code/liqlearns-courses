# Peer-to-peer networks — true or false

Say whether each sentence is true or false.

**1.** Peer-to-peer costs no dedicated server machine.
**Answer: True** — no server, no dedicated-machine cost.

**2.** Peer-to-peer suits a whole city's offices.
**Answer: False** — small environments only.

**3.** All computers in a workgroup are equal.
**Answer: True** — every machine is a peer.
