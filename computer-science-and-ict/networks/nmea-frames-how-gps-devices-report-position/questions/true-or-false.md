# NMEA Frames — How GPS Devices Report Position — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) In NMEA, longitude is written with two digits of degrees, like latitude.**
**Answer: False — Longitude runs to 180°, so it takes three degree digits (dddmm.mmmm); latitude takes two.**

**2. (Sub lesson 2) A south latitude becomes a negative decimal value when converted.**
**Answer: True — The hemisphere letters set the sign: S and W are negative, N and E positive.**
