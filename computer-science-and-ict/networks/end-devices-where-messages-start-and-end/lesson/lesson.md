# End devices — where messages start and end

## Do it first

Send a message in your mind from a laptop to a printer. Which device starts it? Which one ends it? Those two are this lesson's devices.

## Hosts — senders and receivers

**End devices**, also called **hosts**, are the devices that **send or receive data** over the network. The sending one is the **sender**; the receiving one is the **receiver**. Every message on a network starts at an end device and ends at an end device — the devices in between only carry it.

## Examples to know

End devices include **computers** — desktops, laptops, file servers and web servers — **network printers**, **security cameras** and **mobile handheld devices**. If a device originates or finally receives the data, it is an end device; if it only passes data along, it is an intermediary device, and its lessons are next.
