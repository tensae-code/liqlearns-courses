# End devices — where messages start and end — multiple choice

Pick the one right answer.

**1.** End devices are also called —
a) routers  b) hosts  c) media  d) protocols
**Answer: b) hosts** — hosts.

**2.** The device that sends data is the —
a) receiver  b) sender  c) medium  d) server room
**Answer: b) sender** — the sender.

**3.** Which of these is an end device?
a) A network printer  b) A repeater  c) A switch  d) A cable
**Answer: a) A network printer** — a network printer sends/receives at the end of the journey.

**4.** A web server is —
a) an intermediary device  b) an end device (a computer)  c) a medium  d) a protocol
**Answer: b) an end device (a computer)** — servers are listed among the computers that are end devices.

**5.** Messages start and end at —
a) intermediary devices  b) end devices  c) cables  d) access points only
**Answer: b) end devices** — end devices.
