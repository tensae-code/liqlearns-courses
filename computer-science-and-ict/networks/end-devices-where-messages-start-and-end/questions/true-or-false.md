# End devices — where messages start and end — true or false

Say whether each sentence is true or false.

**1.** A security camera can be an end device.
**Answer: True** — it is named among the examples.

**2.** The receiver is the device that sends the data.
**Answer: False** — the sender sends; the receiver receives.

**3.** Mobile handheld devices can be hosts.
**Answer: True** — named among the examples.
