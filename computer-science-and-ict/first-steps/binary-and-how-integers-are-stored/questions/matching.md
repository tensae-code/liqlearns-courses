# Binary — and How Integers Are Stored — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) Which digits does binary use?** → **Only 0 and 1 — the two states of the computer's switches**

**2. (Sub lesson 1) How does place value grow in binary?** → **Each place is worth twice the one before it — 1, 2, 4, 8, 16**

**3. (Sub lesson 1) What is binary 1011 in decimal?** → **11 — that is 8 + 2 + 1**

**4. (Sub lesson 1) Why does the data strand start with binary?** → **Because every kind of data the computer holds is, at the bottom, numbers written in binary**

**5. (Sub lesson 1) What is one binary digit called?** → **A bit**

**6. (Sub lesson 2) In what is an integer stored?** → **In a fixed number of bits — 8, 16, 32 or 64**

**7. (Sub lesson 2) How many different values do 8 bits hold?** → **256**

**8. (Sub lesson 2) How is a negative integer stored?** → **In two's complement — invert the bits of the positive number and add 1**

**9. (Sub lesson 2) What does two's complement buy?** → **The same adder can add and subtract, and there is only one zero**

**10. (Sub lesson 2) What is overflow?** → **A result too big for the fixed row of bits — it wraps or corrupts**
