# Binary — and How Integers Are Stored — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Only 0 and 1 — the two states of the computer's switches**
**Answer: True**

**2. (Sub lesson 1) True or false: Only 0 and 1 — the two states of the computer's switches** — as the answer to: How does place value grow in binary?
**Answer: False — Each place is worth twice the one before it — 1, 2, 4, 8, 16**

**3. (Sub lesson 1) True or false: 11 — that is 8 + 2 + 1**
**Answer: True**

**4. (Sub lesson 1) True or false: 11 — that is 8 + 2 + 1** — as the answer to: Why does the data strand start with binary?
**Answer: False — Because every kind of data the computer holds is, at the bottom, numbers written in binary**

**5. (Sub lesson 1) True or false: A bit**
**Answer: True**

**6. (Sub lesson 2) True or false: A bit** — as the answer to: In what is an integer stored?
**Answer: False — In a fixed number of bits — 8, 16, 32 or 64**

**7. (Sub lesson 2) True or false: 256**
**Answer: True**

**8. (Sub lesson 2) True or false: 256** — as the answer to: How is a negative integer stored?
**Answer: False — In two's complement — invert the bits of the positive number and add 1**

**9. (Sub lesson 2) True or false: The same adder can add and subtract, and there is only one zero**
**Answer: True**

**10. (Sub lesson 2) True or false: The same adder can add and subtract, and there is only one zero** — as the answer to: What is overflow?
**Answer: False — A result too big for the fixed row of bits — it wraps or corrupts**
