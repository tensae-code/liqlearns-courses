The live binary lessons teach counting, conversion and binary arithmetic, and the circuits lessons meet two's complement inside an adder; no lesson teaches how integer data itself is stored — sign and range in a fixed number of bits — which is Vietnam Grade 10's data lesson. The placements file named this slug directly (NEW LESSON NEEDED — first-steps/binary-and-how-integers-are-stored). It sits in the First Steps title (first-steps/), following the book's own order.
