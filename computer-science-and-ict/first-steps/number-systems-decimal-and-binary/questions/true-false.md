# Number Systems — Decimal and Binary — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a number system?" is: A way of writing numbers from a small set of digits by place value**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How many digits does the decimal system use, and which?" is: A digit's worth depends on where it stands**
**Answer: False** — Ten digits — 0 to 9

**3. (Sub lesson 1) True or false: the answer to "What is place value?" is: A digit's worth depends on where it stands**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What are the first three decimal places worth, from the right?" is: Ten**
**Answer: False** — 1, 10 and 100 — each ten times the one before

**5. (Sub lesson 1) True or false: the answer to "What is the base of the decimal system?" is: Ten**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How many digits does binary use, and which?" is: 1, 2, 4 and 8 — each double the one before**
**Answer: False** — Two digits — 0 and 1

**7. (Sub lesson 2) True or false: the answer to "What are the first four binary places worth, from the right?" is: 1, 2, 4 and 8 — each double the one before**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is binary 1011 in decimal?" is: Its circuits have two easy states — on and off — which 1 and 0 match**
**Answer: False** — 11 — 8 + 0 + 2 + 1

**9. (Sub lesson 2) True or false: the answer to "Why does the computer use binary?" is: Its circuits have two easy states — on and off — which 1 and 0 match**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is the same in decimal and binary, and what differs?" is: A way of writing numbers from a small set of digits by place value**
**Answer: False** — The same: place value. Different: the base — ten against two
