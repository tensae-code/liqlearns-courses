# Lesson plan — Number Systems — Decimal and Binary

**Course:** Computer Science and ICT · **Title:** First Steps · **Lesson:** Number Systems — Decimal and Binary
**Place in the curriculum:** ICT expansion — Yemen (2026-11-14) — in the title First Steps on the ICT course ladder (TITLES.md). Built new from Yemen's *Computer* Grade 11, because no existing lesson in the course covers this thing as its own lesson.
**The one thing this lesson teaches:** A number system is a way of writing numbers from a small set of digits by place value: decimal uses ten digits (0–9) with places worth powers of ten, and binary — the system computers use — uses two digits (0 and 1) with places worth powers of two.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Decimal — counting in tens** — The **decimal system** writes every number with ten digits, **0 to 9**. Its secret is **place value**: a digit's worth depends on where it stands. Reading 347 from the right, the places are worth 1, 10, 100 — each place ten times the one before, the **powers of ten**. So 347 = 3×100 + 4×10 + 7×1. Ten is the system's **base**: ten digits, places multiplying by ten.
2. **Binary — counting in twos** — The **binary system** follows the same rule with base **two**: only two digits, **0 and 1**, and places worth 1, 2, 4, 8 — each place double the one before, the **powers of two**. So binary 1011 = 1×8 + 0×4 + 1×2 + 1×1 = 11 in decimal. The computer uses binary because its circuits have two easy states — on and off — which 1 and 0 match exactly. Same place-value idea, smaller base: that is the whole difference.
