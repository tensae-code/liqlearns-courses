# Processing — the computer works on the data — multiple choice

Pick the one right answer.

**1.** Processing means —
a) Inserting data  b) Doing operations on the entered data  c) Printing the result  d) Storing a file
**Answer: b) Doing operations on the entered data** — Processing is doing operations on the entered data.

**2.** Which of these is processing?
a) Typing marks into the computer  b) Working out the class average from the marks  c) Showing the roster on screen  d) Keeping the roster on a hard drive
**Answer: b) Working out the class average from the marks** — Totalling, averaging and ranking marks is processing.

**3.** Changing a photo's colours and brightness is —
a) Input  b) Output  c) Processing  d) Storage
**Answer: c) Processing** — Work done on the entered photo is processing.

**4.** In the roster example, the marks are —
a) The output  b) The input that processing works on  c) The printer  d) The storage
**Answer: b) The input that processing works on** — The marks are entered (input), then totalled and averaged (processing).
