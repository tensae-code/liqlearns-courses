# Storage — keeping data, and the four functions together — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Storage means —
a) Showing a result  b) Keeping data on internal or external storage  c) Typing data in  d) Adding numbers
**Answer: b) Keeping data on internal or external storage** — Storage is keeping data on the computer's internal or external storage.

**2. (Sub lesson 1)** Which of these is external storage?
a) A flash drive  b) The monitor  c) The keyboard  d) The speaker
**Answer: a) A flash drive** — A flash drive (and a compact disk) sit outside the machine — external storage.

**3. (Sub lesson 1)** The book's example of storage on a hard drive is —
a) A photo  b) Videos on CD  c) The class roster  d) A song played aloud
**Answer: c) The class roster** — The roster is kept on the hard drive; the photo is on phone memory and videos on CD.

**4. (Sub lesson 2)** The four functions in travelling order are —
a) Output, input, storage, process  b) Input, process, output, storage  c) Storage, output, process, input  d) Process, storage, input, output
**Answer: b) Input, process, output, storage** — Data travels input → process → output → storage.

**5. (Sub lesson 2)** In the teacher guide's keyed answer, a computer is —
a) Hardware only  b) Software only  c) Hardware and software together  d) A storage box
**Answer: c) Hardware and software together** — The guide's keyed answer: a computer is hardware and software together (teacher guide — evidence).

**6. (Sub lesson 2)** After data is stored, it can —
a) Never be used again  b) Be brought back and used again in the cycle  c) Only be printed  d) Only be deleted
**Answer: b) Be brought back and used again in the cycle** — Stored data comes back round the cycle when it is used again.
