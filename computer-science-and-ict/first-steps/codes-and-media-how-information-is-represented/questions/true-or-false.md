# Codes and Media — How Information Is Represented — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Letters are a code.**
**Answer: True** — Letters are signs standing for the sounds and words of a language.

**2. (Sub lesson 1) A code works even when the receiver has never learned it.**
**Answer: False** — Both sides must share the code's meanings.

**3. (Sub lesson 2) Changing the medium changes the information itself.**
**Answer: False** — The same information can ride as text, sound or a picture sign; the representation changes, not the information.

**4. (Sub lesson 2) A long official message that must be kept and checked later fits written text well.**
**Answer: True** — Written text can be kept, re-read and checked.
