# Hands-on — Codes and Media — How Information Is Represented

The lesson with your hands and your eyes, in the room you are in.

## Message hunt
Walk the room (or the school gate) and list five messages you find. For each, write three short answers: the code, the medium, the receiver it is meant for.

## One message, three forms
Take the message "no class on Monday". Write it as text, draw it as a picture sign a small child could read, and say how you would send it as sound. Under each form, write one line: who does this form reach well, and who does it leave out?

## Context swap
Keep the message, change the context: the receiver is now far away / cannot read / must keep proof of the message. For each new context, choose a new code or medium and write why the old form now fails.
