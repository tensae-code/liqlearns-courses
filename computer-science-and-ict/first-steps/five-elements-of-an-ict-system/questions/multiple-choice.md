# The five elements of an ICT system — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) A system is —**
a) one part alone  b) a set of parts that work together  c) a kind of computer
**Answer: b) a set of parts that work together**

**2. (Sub lesson 1) How many elements does the book name for an ICT system?**
a) Three  b) Four  c) Five  d) Seven
**Answer: c) Five** — Data, information, communication, user, technology.

**3. (Sub lesson 2) Which is the FIRST element in the book's order?**
a) User  b) Technology  c) Data  d) Communication
**Answer: c) Data**

**4. (Sub lesson 2) The element that is a person is —**
a) data  b) user  c) technology
**Answer: b) user** — The user accesses and uses the system.

**5. (Sub lesson 2) Information is —**
a) raw facts with no meaning  b) data processed and given meaning  c) a machine
**Answer: b) data processed and given meaning**
