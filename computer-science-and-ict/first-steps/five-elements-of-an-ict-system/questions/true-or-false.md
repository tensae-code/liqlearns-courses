# The five elements of an ICT system — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) If one element of a system is missing, the system still works exactly as it should.**
**Answer: False** — Take one part away and the whole thing stops working as it should.

**2. (Sub lesson 2) Technology is one of the five elements.**
**Answer: True**

**3. (Sub lesson 2) Data and information are the same element named twice.**
**Answer: False** — They are two different elements: data is raw; information is data given meaning.

**4. (Sub lesson 2) Communication means information passing from one place to another.**
**Answer: True**
