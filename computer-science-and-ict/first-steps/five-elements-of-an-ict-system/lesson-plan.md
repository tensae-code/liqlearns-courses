# Lesson plan — The five elements of an ICT system

**Course:** Computer Science and ICT · **Title:** First Steps · **Lesson:** The five elements of an ICT system
**Place in the curriculum:** Unit 1 — Introduction to Information & Communication Technology — in the title First Steps on the ICT course ladder (TITLES.md).
**The one thing this lesson teaches:** An ICT system is built from five elements — data, information, communication, user and technology — and each of the next lessons takes one of them in turn.
**This lesson's own level:** It stands on What ICT is: the learner knows ICT joins technologies together; now they learn what every ICT system is built from.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 1–2 seconds.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **A system built from parts** — What it means to call something a system: parts that work together, each with its own job.
2. **The five elements named** — The five elements in the book's order — data, information, communication, user, technology — each named with its one-line job.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: the lessons before this one in First Steps on the ladder. Recommended, never forced — a learner may land on this lesson directly, and it stands alone.
- The book's own rhythm is kept: this lesson opens with a brainstorm — the learner first says what they already know — before any definition is given.

## What the learner can do when it ends
1. Name the five elements of an ICT system in the book's order.
2. Give each element's one-line job.
3. Say why the elements belong together as a system.

## What you need
Paper and a pencil.

## The run of the lesson (in order)
1. **Do it first** — Think of one phone call. Someone speaks (that is one part). The words travel (another part). A phone carries them (another part). Before the call means anything, the sounds must mean something to the listener. Try to guess the parts of that call before you read on — this lesson names all five parts of every ICT system. ## If the learner is stuck
Forgets one element → count on fingers in the book's order: data, information, communication, user, technology. Confuses data and information → that pair gets its own two lessons next; here, data is raw, information is data given meaning.
