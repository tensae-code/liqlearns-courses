# The five elements of an ICT system

## Do it first

Think of one phone call. Someone speaks (that is one part). The words travel (another part). A phone carries them (another part). Before the call means anything, the sounds must mean something to the listener. Try to guess the parts of that call before you read on — this lesson names all five parts of every ICT system.

## Sub lesson 1 — A system built from parts

A system is a set of parts that work together. Take one part away and the whole thing stops working as it should. An ICT system is the same: it is built from parts — elements — and each element has its own job. The next lessons take the elements one by one; this lesson names them all, so you have the whole map before the detail.

## Sub lesson 2 — The five elements named

The book names five elements of an ICT system. 

[Picture 10103 — a five-part diagram with one icon per element]



1. **Data** — the raw facts: numbers, text, symbols, speech, images, before they mean anything.
2. **Information** — data that has been processed and given meaning.
3. **Communication** — information passing from one place to another.
4. **User** — the person who accesses and uses the system.
5. **Technology** — the tools and machines people make to solve problems.

Five elements. Say them in order: data, information, communication, user, technology.

## Say it to your companion

Tell your companion, in your own words: An ICT system is built from five elements — data, information, communication, user and technology — and each of the next lessons takes one of them in turn. Then let your companion ask you one question about it — and answer from the lesson, not from memory of the book's exact words.
