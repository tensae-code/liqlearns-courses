# Typing on the AZERTY Keyboard — sub lessons and depth

This file is the lesson's depth record, re-expressed as its SUB LESSONS (2026-11-08 restructure). Practice is tied to the learner's skill number, as before. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — The AZERTY layout — where the letters sit
Sub lesson 1 questions from the type files. Pass mark: say why the keyboard is called AZERTY, point to the first six top-row letters in order, and name how A, Z, Q, W and M differ from QWERTY and how figures are typed on the number row.

## Sub lesson 2 — Typing with the right fingers
Sub lesson 2 questions from the type files. Pass mark: sit in the home position with each finger owning its keys and thumbs on the space bar, and type a short line slowly and accurately without looking down.
