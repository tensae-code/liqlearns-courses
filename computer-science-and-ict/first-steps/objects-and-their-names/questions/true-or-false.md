# Objects and Their Names — true or false

Say whether each statement is true or false.

**1. A tree is an object.**
**Answer: True** — A tree can be pointed to and named.

**2. The word 'quickly' names an object.**
**Answer: False** — 'Quickly' is not a thing you can point to.

**3. A stone on the road is an object.**
**Answer: True** — Objects are outside as well as in the room.
