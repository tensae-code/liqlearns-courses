# Objects and Their Names — multiple choice

Pick the one right answer.

**1. Which of these is an object?**
a) A book  b) Running  c) Quickly
**Answer: a) A book** — A book is a thing you can point to and name.

**2. Every object has —**
a) a name  b) wings  c) a song
**Answer: a) a name** — The name tells us which thing we mean.

**3. Which of these is an object at home?**
a) Sleeping  b) A cup  c) Fast
**Answer: b) A cup** — A cup is one named thing.

**4. A cat is —**
a) not an object  b) an object  c) a colour
**Answer: b) an object** — Living things with names are objects too.
