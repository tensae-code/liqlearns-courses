# Sending Information — Sender, Message and Receiver — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Sender, message, receiver**
**Answer: True**

**2. (Sub lesson 1) True or false: Sender, message, receiver** — as the answer to: What do the French words émetteur and récepteur mean?
**Answer: False — Sender and receiver**

**3. (Sub lesson 1) True or false: A screen (paravent)**
**Answer: True**

**4. (Sub lesson 1) True or false: A screen (paravent)** — as the answer to: What must the receiver do?
**Answer: False — Rebuild the picture square by square, unseen**

**5. (Sub lesson 1) True or false: Only the agreed signals**
**Answer: True**

**6. (Sub lesson 2) True or false: Only the agreed signals** — as the answer to: What must both sides share in advance?

**7. (Sub lesson 2) True or false: Noise**
**Answer: True**

**8. (Sub lesson 2) True or false: Noise** — as the answer to: What does the sender's order tell the receiver?
