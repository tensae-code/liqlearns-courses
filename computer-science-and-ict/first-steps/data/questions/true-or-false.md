# Data — raw facts with no meaning yet — true or false

Say whether each statement is true or false.

**1. A photograph can be data.**
**Answer: True** — Images are one of the book's forms of data.

**2. Data always carries its meaning with it.**
**Answer: False** — By itself, data has no meaning; context supplies it.

**3. Symbols can be data.**
**Answer: True**

**4. If data has no meaning yet, it must be thrown away.**
**Answer: False** — It is raw material — the next step gives it meaning.
