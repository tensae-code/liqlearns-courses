# Data — raw facts with no meaning yet — multiple choice

Pick the one right answer.

**1. Data is —**
a) only numbers on a screen  b) any representation of an object or event  c) a finished answer
**Answer: b) any representation of an object or event**

**2. Which of these can be data?**
a) Numbers only  b) Text only  c) Numbers, text, symbols, speech and images
**Answer: c) Numbers, text, symbols, speech and images** — The book lists all five forms.

**3. A bare list of names and numbers, with no title, —**
a) explains itself  b) has no meaning by itself  c) is always wrong
**Answer: b) has no meaning by itself**

**4. Data is best described as —**
a) the raw material, before meaning is added  b) the final conclusion  c) a computer program
**Answer: a) the raw material, before meaning is added**

**5. Which is an example of data as speech?**
a) A printed price list  b) A name called out across the yard  c) A photograph
**Answer: b) A name called out across the yard** — A spoken name is data in speech form.
