# Minicomputers and mainframes — true or false

Say whether each statement is true or false.

**1.** Mainframes can serve many users at the same time.
**Answer: True**

**2.** A minicomputer is the fastest type of computer.
**Answer: False**

**3.** A minicomputer is more powerful than a mainframe.
**Answer: False** — it is smaller and less powerful than a mainframe.
