# What ICT is — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) The brainstorm comes after the definition in this course.**
**Answer: False** — The brainstorm comes first, before any definition.

**2. (Sub lesson 1) LOGO programming is the first unit of the course.**
**Answer: False** — It is the last unit, Unit 6.

**3. (Sub lesson 2) A mobile phone is part of ICT.**
**Answer: True** — The book names mobile phones among the communication technologies.

**4. (Sub lesson 2) ICT is one single machine.**
**Answer: False** — ICT is all the communication technologies together, joined by networks.
