# Output — showing the result — multiple choice

Pick the one right answer.

**1.** Output means —
a) Inserting data  b) Showing the result of processing to the user  c) Doing calculations  d) Keeping files
**Answer: b) Showing the result of processing to the user** — Output is showing the result of processing to the user.

**2.** Which of these is an output device in this lesson?
a) Keyboard  b) Camera  c) Monitor  d) Scanner
**Answer: c) Monitor** — Results are shown through a monitor, speaker or printer.

**3.** The book's output example is —
a) Typing numbers  b) The processed roster printed on paper  c) Saving a photo  d) Recording audio
**Answer: b) The processed roster printed on paper** — The processed roster printed on paper is the book's output example.

**4.** A result played through a speaker is —
a) Input  b) Storage  c) Output you hear  d) Processing
**Answer: c) Output you hear** — Sound from a speaker shows the result — output.
