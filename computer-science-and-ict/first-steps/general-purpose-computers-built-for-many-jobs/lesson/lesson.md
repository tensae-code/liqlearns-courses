# General-purpose computers — built for many jobs

## Do it first

One machine writes your essay in the morning, keeps the shop's accounts at noon, and plays a game in the evening. Before reading on, say what lets the same machine change jobs so completely.

## Designed for a variety of problems

A general-purpose computer is designed to solve a variety of problems. It runs programs, or sets of instructions, for different tasks — change the program and the same machine does a different job. That is what makes it flexible and versatile.

## The examples

Microcomputers, minicomputers and supercomputers are the book's examples of general-purpose computers. Notice what that means: size does not decide purpose — the smallest type and the largest type can both be general-purpose, because both run many different programs.
