# General-purpose computers — built for many jobs — true or false

Say whether each statement is true or false.

**1.** A supercomputer can be a general-purpose computer.
**Answer: True**

**2.** A general-purpose computer can only run one program in its life.
**Answer: False**

**3.** A general-purpose computer is flexible and versatile because it runs different programs for different tasks.
**Answer: True**
