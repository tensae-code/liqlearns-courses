# Types of Information — We See, Hear and Read — true or false

Say whether each statement is true or false.

**1. A song is information we hear.**
**Answer: True** — Music and speech reach the ears.

**2. Numbers are a type of information we read.**
**Answer: True** — Numbers are written down and read.

**3. One thing can give only one type of information, never two.**
**Answer: False** — A teacher can speak (heard) and write on the board (read) in the same lesson.
