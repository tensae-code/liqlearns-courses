# Fifth generation — AI and parallel processing

## Do it first

Imagine a hard sum set to one pupil, then the same work split between five pupils working at the same moment. Which group finishes first, and why? Hold that picture — it is this lesson's key technique.

## Machines that learn

The fifth generation is aimed at machines that can learn and organise themselves and solve complex problems. It uses artificial intelligence applications such as robotics, game playing, and understanding natural language — the language people speak.

[Picture 10906 — fifth generation]

## Parallel processing

The fifth generation's enabling technique is parallel processing: carrying out many data-processing tasks at the same time, so more is done in a given time and calculations run faster. Watch the GIF: one task splits into several streams that run side by side and finish together — that togetherness is the whole idea.
