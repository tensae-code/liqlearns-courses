**Fifth generation.**

First, brainstorm: what do you already know about this? Say it out loud.

Now the one thing: the fifth generation (present and beyond) aims at machines that learn and organise themselves — and its enabling technique is parallel processing: many tasks carried out at the same time.

**Machines that learn.** The fifth generation is aimed at machines that can learn and organise themselves and solve complex problems.
**Parallel processing.** The fifth generation's enabling technique is parallel processing: carrying out many data-processing tasks at the same time, so more is done in a given time and calculations run faster.
