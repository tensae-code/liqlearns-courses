# Fifth generation — AI and parallel processing — multiple choice

Pick the one right answer.

**1.** The fifth generation is aimed at machines that can —
a) Only add numbers  b) Learn and organise themselves and solve complex problems  c) Print paper faster  d) Use less paper
**Answer: b) Learn and organise themselves and solve complex problems** — Fifth-generation machines aim to learn, organise themselves and solve complex problems.

**2.** Which of these is an artificial-intelligence application named in this lesson?
a) Robotics  b) Typing  c) Filing paper  d) Photocopying
**Answer: a) Robotics** — Robotics, game playing and understanding natural language are named.

**3.** Parallel processing means —
a) Doing tasks one after another very slowly  b) Carrying out many data-processing tasks at the same time  c) Printing in parallel lines  d) Two people sharing one keyboard
**Answer: b) Carrying out many data-processing tasks at the same time** — Parallel processing carries out many tasks at the same time.

**4.** What does parallel processing gain?
a) More done in a given time; calculations run faster  b) Cheaper paper  c) Bigger screens  d) Quieter keyboards
**Answer: a) More done in a given time; calculations run faster** — More is done in a given time and calculations run faster.
