# Video script — Computing Systems — an Introduction

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A **computing system** is the whole that computes: the **hardware** (the physical devices), the **software** (the programs that run on them), the **data** (what is processed and stored), and the **people** who use and run it. Remove any part and the system stops doing its job: hardware without software is idle, software without data has nothing to work on. Armenia introduces computing systems as their own lesson in Grade 6 (§5), after number systems and before files.
Every computing system runs the same cycle: **input** brings data in, **processing** transforms it, **storage** keeps data and results for later, and **output** presents results to people. Systems are also **connected**: one system's output becomes another's input (a school office system feeding a report system). Judging a system means checking each stage — most failures live at the joins, where one stage hands over to the next.
