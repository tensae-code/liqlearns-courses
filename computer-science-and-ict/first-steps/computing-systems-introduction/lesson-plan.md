## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The parts of a computing system — hardware, software, data, people** — A **computing system** is the whole that computes: the **hardware** (the physical devices), the **software** (the programs that run on them), the **data** (what is processed and stored), and the **people** who use and run it. Remove any part and the system stops doing its job: hardware without software is idle, software without data has nothing to work on. Armenia introduces computing systems as their own lesson in Grade 6 (§5), after number systems and before files.
2. **How a computing system works — input, process, store, output** — Every computing system runs the same cycle: **input** brings data in, **processing** transforms it, **storage** keeps data and results for later, and **output** presents results to people. Systems are also **connected**: one system's output becomes another's input (a school office system feeding a report system). Judging a system means checking each stage — most failures live at the joins, where one stage hands over to the next.
