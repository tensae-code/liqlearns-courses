# Computing Systems — an Introduction — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Hardware, software, data and people**
**Answer: True**

**2. (Sub lesson 1) True or false: Hardware, software, data and people** — as the answer to: What is the hardware part?
**Answer: False — The physical devices — the parts you can touch**

**3. (Sub lesson 1) True or false: The programs that run on the hardware**
**Answer: True**

**4. (Sub lesson 1) True or false: The programs that run on the hardware** — as the answer to: Why is hardware without software idle?
**Answer: False — Nothing tells it what to do — there is no job running**

**5. (Sub lesson 1) True or false: Grade 6, §5 — after number systems, before files and their types**
**Answer: True**

**6. (Sub lesson 2) True or false: Grade 6, §5 — after number systems, before files and their types** — as the answer to: Name the four stages of a computing system's work.
**Answer: False — Input, processing, storage and output**

**7. (Sub lesson 2) True or false: Data and results are kept for later, not lost when processing ends**
**Answer: True**

**8. (Sub lesson 2) True or false: Data and results are kept for later, not lost when processing ends** — as the answer to: How do computing systems connect?
**Answer: False — One system's output becomes another system's input**

**9. (Sub lesson 2) True or false: At the joins — where one stage hands over to the next**
**Answer: True**

**10. (Sub lesson 2) True or false: At the joins — where one stage hands over to the next** — as the answer to: What does processing do?
**Answer: False — It transforms the input data into results**
