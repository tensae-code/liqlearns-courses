# What a computer cannot do — no IQ, no feelings — true or false

Say whether each statement is true or false.

**1.** A computer can decide by itself to start a task nobody instructed.
**Answer: False**

**2.** A computer does not tire after long hours of work.
**Answer: True**

**3.** Information stored in a computer can be recalled for as long as required.
**Answer: True**
