# Hands-on — Check Digits — The ISBN Control Number

The lesson with your hands and your feet, not only your eyes.

## Task one
**Check a real ISBN** — Take any book's ISBN-10. Work the weighted sum with the class and verify its check digit. Then change one digit and show the check fail.

## Task two
**Invent a check** — Design a simple check rule for a 4-digit class library number (your own weights). Test it: does it catch a swapped pair? A single wrong digit?
