# Hands-on — Package Information — Many Kinds in One Whole

The lesson with your hands and your feet, not only your eyes.

## Task one
('Package a place', 'Choose one place. Assemble its package: a text, a number set, a picture, and one more kind. Write beside each kind what it alone contributes.')

## Task two
('Audit a package', 'Take a textbook page or a web page as a package. List its kinds, mark any kind that adds nothing, and name one kind whose absence weakens the whole.')
