# Package Information — Many Kinds in One Whole — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is package information?" is: Many kinds of information gathered into one whole about one subject**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Name the kinds a package gathers." is: The subject they all serve**
**Answer: False** — Text, numbers, pictures, sound and video (recordings)

**3. (Sub lesson 1) True or false: the answer to "What binds the kinds together?" is: The subject they all serve**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "How do the kinds treat each other in a package?" is: The table corrects the memory the text relied on (any one of: the caption explains the photograph)**
**Answer: False** — They complete and check each other

**5. (Sub lesson 1) True or false: the answer to "Give an instance of one kind checking another." is: The table corrects the memory the text relied on (any one of: the caption explains the photograph)**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How must a kind earn its place?" is: The subject entire, not whichever kind was nearest**
**Answer: False** — By adding what the others cannot say

**7. (Sub lesson 2) True or false: the answer to "What must the reader who takes the package receive?" is: The subject entire, not whichever kind was nearest**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What chapters follow the package's introduction?" is: Mongolia's — its Grade 10 book's own chapter**
**Answer: False** — How it is processed, stored, and merged with other information

**9. (Sub lesson 2) True or false: the answer to "Whose own concept is 'package information'?" is: Mongolia's — its Grade 10 book's own chapter**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "How does the package relate to Grade 6's forms lesson?" is: Many kinds of information gathered into one whole about one subject**
**Answer: False** — Grade 6 listed the forms one by one; Grade 10 gathers them into one whole
