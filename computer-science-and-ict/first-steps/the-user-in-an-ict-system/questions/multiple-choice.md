# The user in an ICT system — multiple choice

Pick the one right answer.

**1. The user in an ICT system is —**
a) a program  b) the person who accesses and uses ICT  c) a storage device
**Answer: b) the person who accesses and uses ICT**

**2. Who develops and runs the software?**
a) The computer itself  b) Humans  c) Nobody
**Answer: b) Humans**

**3. Who decides whether an ICT system succeeds or fails?**
a) The hardware alone  b) Humans — the users  c) The weather
**Answer: b) Humans — the users**

**4. Setting the procedures — the agreed ways of doing things — is done by —**
a) people  b) the screen  c) the data
**Answer: a) people**

**5. Feeding data into the system is —**
a) a human job in the system  b) done by the data itself  c) not part of the system
**Answer: a) a human job in the system**
