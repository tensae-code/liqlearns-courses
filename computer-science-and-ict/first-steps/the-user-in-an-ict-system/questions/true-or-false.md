# The user in an ICT system — true or false

Say whether each statement is true or false.

**1. The user is a visitor to the system, not a part of it.**
**Answer: False** — The user is one of the five elements the system is built from.

**2. Humans build and maintain the hardware.**
**Answer: True**

**3. A system with perfect machines always succeeds, whatever people do.**
**Answer: False** — Careless people can make a system fail; careful people can make a modest system succeed.

**4. Running software is one of the human jobs the book names.**
**Answer: True**
