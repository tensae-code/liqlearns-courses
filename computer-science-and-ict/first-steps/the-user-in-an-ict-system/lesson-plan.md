# Lesson plan — The user in an ICT system

**Course:** Computer Science and ICT · **Title:** First Steps · **Lesson:** The user in an ICT system
**Place in the curriculum:** Unit 1 — Introduction to Information & Communication Technology — in the title First Steps on the ICT course ladder (TITLES.md).
**The one thing this lesson teaches:** The user is the person who accesses and uses ICT — humans develop and run the software, feed in data, build and maintain the hardware, set the procedures, and decide whether an ICT system succeeds or fails.
**This lesson's own level:** It stands on The five elements of an ICT system: the user is the fourth element, taken here in its own lesson.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. ## What the learner can do when it ends
1. Say who the user is: the person who accesses and uses ICT.
2. List the human jobs inside a system: develop and run software, feed in data, build and maintain hardware, set procedures.
3. Explain why people decide whether an ICT system succeeds or fails.

## What you need
Paper and a pencil.
