# The user in an ICT system

## Do it first

Press nothing. Before a phone is touched, who decides to pick it up? Before a computer shows anything, who typed, who built it, who repaired it last time it broke? List every person hidden behind one working computer. This lesson is about that person: the user.

## The user in an ICT system

The user is the person who accesses and uses ICT. 

[Picture 10107 — a pupil at a computer with arrows to software, data and hardware]



But the user does far more than sit at the screen. Humans develop and run the software. Humans feed in the data. Humans build and maintain the hardware. Humans set the procedures — the agreed ways of doing things. And so, in the end, humans decide whether an ICT system succeeds or fails. A system with perfect machines and careless people fails. A modest system with careful people can succeed.

That is why the user is an element of the system, not a visitor to it: the person is one of the parts the system is built from.

## Say it to your companion

Tell your companion, in your own words: The user is the person who accesses and uses ICT — humans develop and run the software, feed in data, build and maintain the hardware, set the procedures, and decide whether an ICT system succeeds or fails. Then let your companion ask you one question about it — and answer from the lesson, not from memory of the book's exact words.
