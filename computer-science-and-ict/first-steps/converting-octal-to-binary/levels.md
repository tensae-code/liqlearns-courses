# Converting Octal to Binary — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Each octal digit — three bits
Sub lesson 1 questions from the type files. Pass mark: Exactly three; Three bits make the same eight values, 000 to 111, as one octal digit, 0 to 7; 101; 010 — the leading zero is kept; They hold the places of the digits beside the group.

## Sub lesson 2 — Groups side by side — the binary answer
Sub lesson 2 questions from the type files. Pass mark: 100111₂ — 4→100, 7→111; 001000₂ — written in full as 1000₂; Side by side, in the same order as the octal digits; 010101₂ — 2→010, 5→101; By value — both numbers must name the same amount.
