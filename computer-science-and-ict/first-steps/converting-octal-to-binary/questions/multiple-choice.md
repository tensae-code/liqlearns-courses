# Converting Octal to Binary — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) How many binary digits is each octal digit worth?**
a) Exactly three  b) Three bits make the same eight values, 000 to 111, as one octal digit, 0 to 7  c) 101  d) 010 — the leading zero is kept
**Answer: a) Exactly three**

**2. (Sub lesson 1) Why three?**
a) 101  b) Three bits make the same eight values, 000 to 111, as one octal digit, 0 to 7  c) 010 — the leading zero is kept  d) They hold the places of the digits beside the group
**Answer: b) Three bits make the same eight values, 000 to 111, as one octal digit, 0 to 7**

**3. (Sub lesson 1) What is octal digit 5 in binary?**
a) 010 — the leading zero is kept  b) They hold the places of the digits beside the group  c) 101  d) 100111₂ — 4→100, 7→111
**Answer: c) 101**

**4. (Sub lesson 1) What is octal digit 2 in binary?**
a) They hold the places of the digits beside the group  b) 100111₂ — 4→100, 7→111  c) 001000₂ — written in full as 1000₂  d) 010 — the leading zero is kept
**Answer: d) 010 — the leading zero is kept**

**5. (Sub lesson 1) Why are leading zeros in a group kept?**
a) They hold the places of the digits beside the group  b) 100111₂ — 4→100, 7→111  c) 001000₂ — written in full as 1000₂  d) Side by side, in the same order as the octal digits
**Answer: a) They hold the places of the digits beside the group**

**6. (Sub lesson 2) What is 47₈ in binary?**
a) 001000₂ — written in full as 1000₂  b) 100111₂ — 4→100, 7→111  c) Side by side, in the same order as the octal digits  d) 010101₂ — 2→010, 5→101
**Answer: b) 100111₂ — 4→100, 7→111**

**7. (Sub lesson 2) What is 10₈ in binary?**
a) Side by side, in the same order as the octal digits  b) 010101₂ — 2→010, 5→101  c) 001000₂ — written in full as 1000₂  d) By value — both numbers must name the same amount
**Answer: c) 001000₂ — written in full as 1000₂**

**8. (Sub lesson 2) In what order are the groups written?**
a) 010101₂ — 2→010, 5→101  b) By value — both numbers must name the same amount  c) Exactly three  d) Side by side, in the same order as the octal digits
**Answer: d) Side by side, in the same order as the octal digits**

**9. (Sub lesson 2) What is 25₈ in binary?**
a) 010101₂ — 2→010, 5→101  b) By value — both numbers must name the same amount  c) Exactly three  d) Three bits make the same eight values, 000 to 111, as one octal digit, 0 to 7
**Answer: a) 010101₂ — 2→010, 5→101**

**10. (Sub lesson 2) How can you check a conversion?**
a) Exactly three  b) By value — both numbers must name the same amount  c) Three bits make the same eight values, 000 to 111, as one octal digit, 0 to 7  d) 101
**Answer: b) By value — both numbers must name the same amount**
