# Converting Octal to Binary — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "How many binary digits is each octal digit worth?" is: Exactly three**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Why three?" is: 101**
**Answer: False** — Three bits make the same eight values, 000 to 111, as one octal digit, 0 to 7

**3. (Sub lesson 1) True or false: the answer to "What is octal digit 5 in binary?" is: 101**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is octal digit 2 in binary?" is: They hold the places of the digits beside the group**
**Answer: False** — 010 — the leading zero is kept

**5. (Sub lesson 1) True or false: the answer to "Why are leading zeros in a group kept?" is: They hold the places of the digits beside the group**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is 47₈ in binary?" is: 001000₂ — written in full as 1000₂**
**Answer: False** — 100111₂ — 4→100, 7→111

**7. (Sub lesson 2) True or false: the answer to "What is 10₈ in binary?" is: 001000₂ — written in full as 1000₂**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "In what order are the groups written?" is: 010101₂ — 2→010, 5→101**
**Answer: False** — Side by side, in the same order as the octal digits

**9. (Sub lesson 2) True or false: the answer to "What is 25₈ in binary?" is: 010101₂ — 2→010, 5→101**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "How can you check a conversion?" is: Exactly three**
**Answer: False** — By value — both numbers must name the same amount
