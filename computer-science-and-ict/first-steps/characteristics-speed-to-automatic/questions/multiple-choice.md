# Characteristics of computers — speed, accuracy, diligence, versatility, reliability, automatic — multiple choice

Pick the one right answer.

**1.** A computer's operations are timed in —
a) Hours and days  b) Microseconds and nanoseconds  c) Weeks  d) Heartbeats
**Answer: b) Microseconds and nanoseconds** — Operations are timed in microseconds and nanoseconds.

**2.** When a computer gives a wrong answer, the errors usually come from —
a) The machine's tiredness  b) Inconsistent or inaccurate data put in  c) The weather  d) The screen
**Answer: b) Inconsistent or inaccurate data put in** — The machine calculates with full accuracy; errors come from bad data put in.

**3.** Diligence means a computer —
a) Works only in the morning  b) Never gets tired or loses concentration  c) Needs rest breaks  d) Forgets after an hour
**Answer: b) Never gets tired or loses concentration** — Diligence: no fatigue, no loss of concentration.

**4.** Reliability means —
a) The same result every time for the same set of data  b) A different result each time  c) Working only sometimes  d) Needing a person each step
**Answer: a) The same result every time for the same set of data** — Reliable = same data, same result, every time.

**5.** 'Automatic' means a task, once set going, is performed —
a) By hand, step by step  b) Without manual intervention  c) Only once a year  d) By another person
**Answer: b) Without manual intervention** — Automatic tasks run without manual intervention once set going.

**6.** Versatility means a computer can —
a) Do one job only  b) Do many different kinds of work with the same accuracy and efficiency  c) Change its colour  d) Work without electricity
**Answer: b) Do many different kinds of work with the same accuracy and efficiency** — Versatility: many kinds of work, same accuracy and efficiency.
