# Characteristics of computers — speed, accuracy, diligence, versatility, reliability, automatic

## Do it first

Think of the best human calculator you know. Can they add for ten hours without one mistake, without getting tired, and give the same answer every single time? Before reading on, say which of those three the human fails first.

## Speed and accuracy

Speed: a computer works at millions of instructions per second, and its operations are timed in microseconds and nanoseconds — millionths and billionths of a second. Accuracy: its calculations are done with full accuracy. When a computer's answer is wrong, the errors come from inconsistent or inaccurate data put in — the machine calculates exactly; bad data in, wrong answer out.

## Diligence, versatility, reliability

Diligence: a computer never gets tired — no fatigue, no loss of concentration, at hour one or hour ten. Versatility: it does many different kinds of work with the same accuracy and efficiency. Reliability: it gives the same result every time for the same set of data — ask it a hundred times, get the same answer a hundred times.

## Automatic

Automatic: once a task is set going, a computer performs it without manual intervention — nobody has to push each step along. The next lesson finishes the characteristics: remembering, and the two things a computer has not got — IQ and feelings.
