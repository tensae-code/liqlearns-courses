Kazakhstan's own way (Shaniev G9 Informatics): the bilingual Grade 9 book (taught in English for the trilingual programme) opens with computer literacy including netiquette and pricing a computer configuration, teaches databases practically (design, build, sort/filter, pivot tables, charts, a "family shop" mini-project), then Python lists in depth — and finishes with a whole chapter of 2D game programming in PyGame.

Kazakhstan's own way (Kolyeva G9 Informatika): the Mektep Grade 9 book is the Google-cloud book: joint work on documents and presentations in Google services with shared-access settings and network etiquette, a practical chapter on choosing and pricing a computer and its software, databases built inside spreadsheets, then Python lists (search, replace, sort, insert/delete, two-dimensional) and 2D games with PyGame.

Kazakhstan's own way (Yerzhanov G9 Informatics, English-medium): the English-medium twin of the Mektep Grade 9 book — the same four chapters (computer literacy with netiquette and pricing a computer, database basics with pivot tables and a "family shop" mini-project, Python lists, PyGame 2D games ending in a Program Arcade Game) taught in English with trilingual terminology.

Kazakhstan's own way (Mukhametzhanova G9 Informatika): the Atamura Grade 9 book covers the same ground as the Mektep book (information properties and joint document work, choosing a computer, databases, Python lists, PyGame) but in longer, deeper lessons — each topic runs seven to ten pages instead of two to four.

Kazakhstan's own way (Kadirkulov G9 Informatika): Almatykitap's Grade 9 book splits sorting and filtering into separate lessons plus an advanced-filter lesson, gives data input/output in one-dimensional arrays its own lesson, and has the fullest PyGame part of the wave — seven lessons ending in a complete "Footballer" game with sprite-collision detection.
