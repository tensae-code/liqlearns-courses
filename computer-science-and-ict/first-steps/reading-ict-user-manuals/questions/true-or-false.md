# Reading ICT User Manuals — true or false

Say whether each statement is true or false.

**1. A user manual is meant to be read as a story, from the first page to the last.**
**Answer: False** — It is a place to find answers; you read the part that matches your question.

**2. A manual on a screen can often be searched by word.**
**Answer: True** — Searching is one way to find the right part on a screen manual.

**3. Keeping the manual far away from its tool is a good system.**
**Answer: False** — The manual is kept with the tool, so it is there on the day it is needed.

**4. Following a manual can let a learner do a new job without waiting for a teacher to show them.**
**Answer: True** — That independence is the point of Activity 1.9.
