# Reading ICT User Manuals — multiple choice

Pick the one right answer.

**1. What is a user manual?**
a) A story book about computers  b) The instruction book that comes with an ICT tool  c) A list of prices
**Answer: b) The instruction book that comes with an ICT tool** — It is written by the tool's makers for the person who will use it.

**2. What is the first move when you use a manual?**
a) Read it from page one to the end  b) Name your question in plain words  c) Skip to the last page
**Answer: b) Name your question in plain words** — A manual is a place to find answers, so the question comes first.

**3. How do you find the right part of a manual?**
a) By the contents list, headings or index  b) By guessing a page  c) By asking the tool
**Answer: a) By the contents list, headings or index** — Those are the manual's own finding tools.

**4. A manual's steps must be followed —**
a) In any order  b) Backwards  c) In the order given
**Answer: c) In the order given** — Skipping a step is the commonest reason a job done from a manual fails.

**5. Safety warnings in a manual should be read —**
a) After you finish  b) Before you touch the tool  c) Only if something breaks
**Answer: b) Before you touch the tool** — A warning read late protects nobody.
