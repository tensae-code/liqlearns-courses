# From data to information — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Information is data that has been given meaning.**
**Answer: True**

**2. (Sub lesson 1) Processing data means throwing most of it away.**
**Answer: False** — It means collecting it, putting it into context and giving it meaning.

**3. (Sub lesson 2) There is always exactly one correct title for a data set.**
**Answer: False** — Many titles are acceptable where the data truly fits them.

**4. (Sub lesson 2) A conclusion is something you reach by interpreting data.**
**Answer: True**
