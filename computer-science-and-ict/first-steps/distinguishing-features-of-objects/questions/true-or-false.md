# Distinguishing Features of Objects — true or false

Say whether each statement is true or false.

**1. A distinguishing feature is shared by all the objects in a set.**
**Answer: False** — It is the feature only the one object has — that is what distinguishes it.

**2. Colour can be a distinguishing feature.**
**Answer: True** — One red book among blue books is told apart by colour.

**3. Alike objects can still have a distinguishing feature.**
**Answer: True** — Similar in many ways, different in one — that one distinguishes them.
