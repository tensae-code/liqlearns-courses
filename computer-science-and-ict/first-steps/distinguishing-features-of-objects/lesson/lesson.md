# Distinguishing Features of Objects

## Do it first

Two cups sit on the table. One has a handle that is broken; the other does not. That one difference tells them apart. This lesson teaches distinguishing features: the feature that makes one object different.

## Distinguishing Features of Objects

Objects can be similar in many ways and still be different in one way. The feature that makes an object **different** from another is its **distinguishing feature**.

Two pencils can both be long and yellow — but one is sharp and one is blunt. 'Sharp' is the distinguishing feature of the first pencil; it tells the two pencils apart. Two books can be the same size, but one is red and one is blue: colour distinguishes them.

When you must pick out one object from alike objects, look for its distinguishing feature — the one feature the others do not have. That is how you can ask for exactly the object you mean: 'the cup with the chip', 'the book with the torn cover'.
