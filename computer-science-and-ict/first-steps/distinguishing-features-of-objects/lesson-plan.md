# Lesson plan — Distinguishing Features of Objects

**Course:** Computer Science and ICT · **Title:** First Steps · **Lesson:** Distinguishing Features of Objects
**Place in the curriculum:** ICT expansion — Azerbaijan (2026-11-14) — in the title First Steps on the ICT course ladder (TITLES.md). Built new from Azerbaijan's *İnformatika 2, Grade 2*, because no existing lesson teaches this thing as its own lesson at this level.
**The one thing this lesson teaches:** A distinguishing feature is the feature that makes one object different from another — the one thing by which you can tell it apart.
**This lesson's own level:** Grade 2 simple — it stands on the child's own everyday world and on the lessons named below; every new word is built inside the lesson from things the child can do at once.

## What the learner can do when it ends
1. Say what a distinguishing feature is.
2. Find the distinguishing feature that tells two alike objects apart.
3. Ask for one exact object by naming its distinguishing feature.

## What you need
Pairs of alike objects with one clear difference — pencils, cups, books. No computer is needed.

## If the learner is stuck
Names a shared feature instead of the difference → ask 'Do both have it, or only this one?' Only the 'only this one' features distinguish. Cannot find one → lay the pair side by side and check colour, shape, size and marks one at a time.
