# Video script — Distinguishing Features of Objects

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Alike objects can differ in one way.

That one way is the distinguishing feature.

One pencil is sharp. One is blunt.

Find the feature only one has.

Use it to ask for the exact object.
