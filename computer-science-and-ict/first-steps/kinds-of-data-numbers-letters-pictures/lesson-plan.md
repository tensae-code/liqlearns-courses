## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Numbers and letters — data you can read as symbols** — **Numeric data** is made of numbers: a mark of 85, a price, a count of students — data the computer can calculate with. **Alphabetic data** is made of letters and words: a name, an address, a sentence — data the computer stores and shows, but does not add up. The two kinds are often mixed in one record — a student's name beside the student's mark — and a good user keeps them straight, because a number stored as letters cannot be calculated with.
2. **Pictures — data you see** — **Picture data** — photographs, drawings, scanned pages — is a third kind: data you take in by seeing, not by reading symbols. The computer stores a picture as its own kind of data, in far more storage than a name or a number takes, and shows it back on the screen or in print. Sound and moving pictures stand beside still pictures as further kinds, but the book's first classification is these three: numbers, letters, pictures.

## The run of the lesson (in order)
1. **Do it first** — A mark in a register is a number. A name is letters. A photo on a phone is a picture. All three are data. In this lesson you learn to tell the kinds of data apart and name the kind in front of you. (lesson/lesson.md).
2. **The explanation** — the lesson text in lesson/lesson.md, in its parts in order.
   - ADD IMAGE: a picture of a student record — the name in letters beside the mark in numbers — the student studies the picture and names what each part shows.
   - ADD GIF: a GIF of three kinds of data side by side — a number, a word, a picture — the student watches once, then says what changed and why.
   - ADD AUDIO: a voice reading the lesson's key names and definitions aloud, in the order the lesson gives them — the student listens once through, then reads the same lines aloud along with the voice. (Audio is a described slot in this build; no audio file is made.)
