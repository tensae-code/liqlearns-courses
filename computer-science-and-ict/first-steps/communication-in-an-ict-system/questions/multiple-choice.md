# Communication in an ICT system — multiple choice

Pick the one right answer.

**1. Communication is —**
a) storing information forever  b) passing information from one place to another  c) deleting information
**Answer: b) passing information from one place to another**

**2. Which of these counts as communication in the book?**
a) Only a phone call  b) Feeding information to a computer, reading it from a system, and messages between people  c) Only television
**Answer: b) Feeding information to a computer, reading it from a system, and messages between people**

**3. Communication devices are what let —**
a) computers talk to each other  b) computers get heavier  c) data disappear
**Answer: a) computers talk to each other**

**4. Without communication devices, each computer would be like —**
a) a library  b) an island  c) a river
**Answer: b) an island** — Its information could not reach anyone else.

**5. Reading information out of a system is —**
a) communication  b) storage only  c) not communication
**Answer: a) communication**
