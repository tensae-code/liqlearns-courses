# Communication in an ICT system — true or false

Say whether each statement is true or false.

**1. A message passing between two people is communication.**
**Answer: True**

**2. Communication only happens between two people.**
**Answer: False** — Feeding a computer and reading from a system are communication too.

**3. Communication devices let ICT systems talk to each other.**
**Answer: True**

**4. In the GIF, the message stays inside the first computer.**
**Answer: False** — It leaves, travels, and arrives at the other computer.
