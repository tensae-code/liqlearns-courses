# Converting Numbers Between Systems — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What stays the same when a number is converted?" is: Its value**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How is a number carried into decimal?" is: 5**
**Answer: False** — Each digit times its place value, then the parts are added

**3. (Sub lesson 1) True or false: the answer to "What is binary 101 in decimal?" is: 5**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is a digit's place value built from?" is: As its own lesson, after the number systems themselves**
**Answer: False** — The base raised to the digit's position

**5. (Sub lesson 1) True or false: the answer to "Where does conversion sit in Uzbekistan's Grade 8 book?" is: As its own lesson, after the number systems themselves**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How is a decimal number carried into another system?" is: In reverse — last first**
**Answer: False** — Divide by the new base again and again and keep the remainders

**7. (Sub lesson 2) True or false: the answer to "In what order are the remainders read?" is: In reverse — last first**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is 13 in binary?" is: By converting back**
**Answer: False** — 1101

**9. (Sub lesson 2) True or false: the answer to "How do you check a conversion?" is: By converting back**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is kept at every division?" is: Its value**
**Answer: False** — The remainder
