# Describing an Object by Its Features — Riddles — fill in the blank

Fill each blank with the missing word or words.

**1. A guessing game that describes an object by its features is a ____.**
**Answer: riddle**

**2. A riddle gives features but never says the object's ____.**
**Answer: name**

**3. Each new feature makes ____ objects fit.**
**Answer: fewer**
