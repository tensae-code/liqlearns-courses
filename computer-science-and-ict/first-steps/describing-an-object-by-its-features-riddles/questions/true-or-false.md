# Describing an Object by Its Features — Riddles — true or false

Say whether each statement is true or false.

**1. A riddle must never say the object's name.**
**Answer: True** — Naming it ends the guessing.

**2. A riddle can include a feature the object does not have.**
**Answer: False** — Every feature must be true.

**3. Features are given one at a time in a riddle.**
**Answer: True** — Each feature cuts the guesses down.
