# Describing an Object by Its Features — Riddles — multiple choice

Pick the one right answer.

**1. A riddle describes an object by —**
a) its name only  b) its features, without naming it  c) its price
**Answer: b) its features, without naming it** — The listener guesses from the features.

**2. In a good riddle, each new feature —**
a) makes more objects fit  b) makes fewer objects fit  c) changes the object
**Answer: b) makes fewer objects fit** — The guesses are cut down one feature at a time.

**3. Every feature in a riddle must be —**
a) funny  b) secret  c) true of the object
**Answer: c) true of the object** — A false feature breaks the riddle.

**4. 'Round, red, you can eat it' — the answer is most likely —**
a) a chair  b) an apple  c) a book
**Answer: b) an apple** — Round and red and eaten fits an apple.
