# Describing an Object by Its Features — Riddles — short answer

Answer in a sentence or two.

**1. Make a riddle for a pencil in three features.**
**Answer:** For example: 'I am long and thin. I have a point. You write with me.' (Any three true features, no name.)

**2. Why must every feature in a riddle be true?**
**Answer:** Because the listener trusts the features to find the one object; a false feature leads to a wrong guess.
