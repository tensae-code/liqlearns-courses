# The four functions of a computer — input — multiple choice

Pick the one right answer.

**1.** Which list gives the four basic functions of a computer?
a) Input, process, output, storage  b) Type, print, scan, copy  c) Open, close, save, delete  d) Charge, ring, speak, listen
**Answer: a) Input, process, output, storage** — The four functions are input, process, output and storage.

**2.** Input means —
a) Showing a result  b) Inserting data for the computer to work on  c) Keeping data forever  d) Printing a page
**Answer: b) Inserting data for the computer to work on** — Input is inserting data for the computer to work on.

**3.** Which of these is input?
a) A result on the screen  b) A printed roster  c) Recording audio  d) A saved file
**Answer: c) Recording audio** — Recording audio inserts data — it is input.

**4.** Before a computer can find the product of two numbers, it must first —
a) Print them  b) Have the numbers entered as input  c) Store them on a CD  d) Show them on screen
**Answer: b) Have the numbers entered as input** — The numbers must be entered before their product can be found.
