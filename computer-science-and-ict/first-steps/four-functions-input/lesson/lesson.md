# The four functions of a computer — input

## Do it first

Pick up a phone or imagine one. You type a friend's number, the phone finds the name, shows it on screen, and keeps it for next time. Four different things just happened. Try to name them before you read on.

## The four functions

Every computer does four basic things: input, process, output, storage. This lesson and the next three take one function each, in order — the order data travels.

[Picture 10908 — the four functions of a computer]

## Input — inserting data

Input is inserting data for the computer to work on. Typing on a keyboard is input. Taking a picture is input. Using a camera is input. Recording audio is input. The book's working example: before a computer can find the product of two numbers, the numbers must first be entered — that entering is input, and nothing can be processed until it happens.
