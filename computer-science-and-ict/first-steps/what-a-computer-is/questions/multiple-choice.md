# What a computer is — input, process, store, output — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) A modern computer processes —**
a) numbers only  b) numbers, text and pictures  c) pictures only
**Answer: b) numbers, text and pictures** — It is no longer only a calculating machine.

**2. (Sub lesson 1) The computer began as —**
a) a calculating machine  b) a television  c) a telephone
**Answer: a) a calculating machine**

**3. (Sub lesson 2) The four basic functions in order are —**
a) output, input, store, process  b) input, processing, storing, output  c) processing, output, input, storing
**Answer: b) input, processing, storing, output**

**4. (Sub lesson 2) Typing your name into a computer is which function?**
a) Output  b) Storing  c) Entering — input
**Answer: c) Entering — input**

**5. (Sub lesson 2) Seeing the finished letter on the screen is —**
a) input  b) output  c) processing
**Answer: b) output** — Processed data produced for the user.
