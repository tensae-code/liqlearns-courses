# What a computer is — input, process, store, output — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) A computer can process text.**
**Answer: True**

**2. (Sub lesson 2) Storing is one of the four basic functions.**
**Answer: True**

**3. (Sub lesson 2) Output comes before input in the cycle.**
**Answer: False** — Input is first; output is last.

**4. (Sub lesson 2) Every computer task is built from the four functions.**
**Answer: True**
