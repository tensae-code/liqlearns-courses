# ASCII Encoding in Octal — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does ASCII give every character?**
a) Its own code value — an agreed decimal number  b) 65  c) 97 — small letters have different values from capitals  d) 32
**Answer: a) Its own code value — an agreed decimal number**

**2. (Sub lesson 1) What is the ASCII value of A?**
a) 97 — small letters have different values from capitals  b) 65  c) 32  d) Looked up — in the ASCII table
**Answer: b) 65**

**3. (Sub lesson 1) What is the ASCII value of a (small a)?**
a) 32  b) Looked up — in the ASCII table  c) 97 — small letters have different values from capitals  d) By the divide-by-8 method, remainders read upwards
**Answer: c) 97 — small letters have different values from capitals**

**4. (Sub lesson 1) What is the ASCII value of the space?**
a) Looked up — in the ASCII table  b) By the divide-by-8 method, remainders read upwards  c) 101₈ — 65 converts to 101 in octal  d) 32
**Answer: d) 32**

**5. (Sub lesson 1) Is a character's value worked out or looked up?**
a) Looked up — in the ASCII table  b) By the divide-by-8 method, remainders read upwards  c) 101₈ — 65 converts to 101 in octal  d) 48 — the character, not the number zero
**Answer: a) Looked up — in the ASCII table**

**6. (Sub lesson 2) How is the value turned into octal?**
a) 101₈ — 65 converts to 101 in octal  b) By the divide-by-8 method, remainders read upwards  c) 48 — the character, not the number zero  d) Character, code value, octal
**Answer: b) By the divide-by-8 method, remainders read upwards**

**7. (Sub lesson 2) What is A in octal ASCII?**
a) 48 — the character, not the number zero  b) Character, code value, octal  c) 101₈ — 65 converts to 101 in octal  d) 102₈
**Answer: c) 101₈ — 65 converts to 101 in octal**

**8. (Sub lesson 2) What is the ASCII value of the digit character 0?**
a) Character, code value, octal  b) 102₈  c) Its own code value — an agreed decimal number  d) 48 — the character, not the number zero
**Answer: d) 48 — the character, not the number zero**

**9. (Sub lesson 2) What are the three steps of the chain, in order?**
a) Character, code value, octal  b) 102₈  c) Its own code value — an agreed decimal number  d) 65
**Answer: a) Character, code value, octal**

**10. (Sub lesson 2) What is B (value 66) in octal?**
a) Its own code value — an agreed decimal number  b) 102₈  c) 65  d) 97 — small letters have different values from capitals
**Answer: b) 102₈**
