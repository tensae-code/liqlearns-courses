# ASCII Encoding in Octal — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does ASCII give every character?" is: Its own code value — an agreed decimal number**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is the ASCII value of A?" is: 97 — small letters have different values from capitals**
**Answer: False** — 65

**3. (Sub lesson 1) True or false: the answer to "What is the ASCII value of a (small a)?" is: 97 — small letters have different values from capitals**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is the ASCII value of the space?" is: Looked up — in the ASCII table**
**Answer: False** — 32

**5. (Sub lesson 1) True or false: the answer to "Is a character's value worked out or looked up?" is: Looked up — in the ASCII table**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How is the value turned into octal?" is: 101₈ — 65 converts to 101 in octal**
**Answer: False** — By the divide-by-8 method, remainders read upwards

**7. (Sub lesson 2) True or false: the answer to "What is A in octal ASCII?" is: 101₈ — 65 converts to 101 in octal**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is the ASCII value of the digit character 0?" is: Character, code value, octal**
**Answer: False** — 48 — the character, not the number zero

**9. (Sub lesson 2) True or false: the answer to "What are the three steps of the chain, in order?" is: Character, code value, octal**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is B (value 66) in octal?" is: Its own code value — an agreed decimal number**
**Answer: False** — 102₈
