# Processing Information — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is processing information?" is: Working on received information to produce new information from it**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How does processed information differ from a copy?" is: Numbers gathered becoming a total (any one of: sounds heard becoming words understood)**
**Answer: False** — The output says something the input did not say alone

**3. (Sub lesson 1) True or false: the answer to "Give an example of processing." is: Numbers gathered becoming a total (any one of: sounds heard becoming words understood)**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What errors can processed information carry?" is: Comparing the result against the source, a second method, or plain sense**
**Answer: False** — A misheard word, a wrong total, a hasty conclusion (any one)

**5. (Sub lesson 1) True or false: the answer to "What is checking?" is: Comparing the result against the source, a second method, or plain sense**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What follows a failed check?" is: Confident mistakes**
**Answer: False** — Correcting what the check condemns

**7. (Sub lesson 2) True or false: the answer to "What does processing without checking manufacture?" is: Confident mistakes**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Why must checking happen before storing?" is: No — the definition names the act, not the tool**
**Answer: False** — Storing will faithfully keep whatever processing hands it — errors included

**9. (Sub lesson 2) True or false: the answer to "Does processing need a computer?" is: No — the definition names the act, not the tool**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What are the information road's stations around this lesson?" is: Working on received information to produce new information from it**
**Answer: False** — Receiving before it, storing after it
