# Converting Binary to Octal — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "How are the bits grouped?" is: In threes**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "From which end does grouping start?" is: Grouping from the left would misplace every value**
**Answer: False** — From the right — the places run from the right

**3. (Sub lesson 1) True or false: the answer to "Why must grouping start there?" is: Grouping from the left would misplace every value**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What if the last group has fewer than three bits?" is: 5**
**Answer: False** — It still counts — think of it as filled with leading zeros

**5. (Sub lesson 1) True or false: the answer to "What does the group 101 read as?" is: 5**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is 100111₂ in octal?" is: 52₈ — groups 101 and 010**
**Answer: False** — 47₈ — groups 100 and 111

**7. (Sub lesson 2) True or false: the answer to "What is 101010₂ in octal?" is: 52₈ — groups 101 and 010**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is 111₂ in octal?" is: They are inverses — spreading digits into bits, and gathering bits into digits**
**Answer: False** — 7₈ — one full group

**9. (Sub lesson 2) True or false: the answer to "How are the two octal–binary roads related?" is: They are inverses — spreading digits into bits, and gathering bits into digits**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is 1101101₂ in octal?" is: In threes**
**Answer: False** — 155₈ — groups 1, 101, 101 read as 001, 101, 101
