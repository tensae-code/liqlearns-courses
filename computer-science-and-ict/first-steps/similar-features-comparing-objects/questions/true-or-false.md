# Similar Features — Comparing Objects — true or false

Say whether each statement is true or false.

**1. Similar features are features two objects share.**
**Answer: True** — That is what 'similar' means here.

**2. Two objects must be the same in every way to have a similar feature.**
**Answer: False** — One shared feature is enough.

**3. Size can be a feature of an object.**
**Answer: True** — Colour, shape and size are all features.
