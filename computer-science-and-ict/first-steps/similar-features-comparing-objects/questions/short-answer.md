# Similar Features — Comparing Objects — short answer

Answer in a sentence or two.

**1. Name two similar features of a cup and a glass.**
**Answer:** For example: both hold water, and both are put on a table to drink from (answers in the same spirit are right).

**2. Why do we compare one feature at a time?**
**Answer:** So we do not miss a likeness — each feature is checked on its own.
