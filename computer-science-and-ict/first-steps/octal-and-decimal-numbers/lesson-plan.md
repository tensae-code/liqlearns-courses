## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Octal — counting in eights** — The **octal system** has base **8**: it uses only eight digits, **0 to 7** — the digits 8 and 9 never appear in an octal number. Its places are worth powers of eight: 1, 8, 64, 512, reading from the right. So octal 25 means 2×8 + 5×1 = 21 in decimal. Malaysia teaches octal first as a difference to state plainly: same place-value idea as decimal, smaller base, fewer digits.
2. **Decimal — counting in tens, and telling them apart** — The **decimal system** has base **10**: ten digits, 0 to 9, and places worth powers of ten: 1, 10, 100, 1000. The same written marks can belong to either system — 25 is twenty-five in decimal but twenty-one when it is octal — so a number's system must be known or marked (Malaysia writes the base as a small subscript, 25₈ against 25₁₀). Telling them apart is the first skill: check the digits (any 8 or 9 means it cannot be octal) and read the places by the right base.
