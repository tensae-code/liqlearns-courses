# Octal and Decimal Numbers — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is the base of the octal system?" is: 8 — octal counts in eights**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Which digits does octal use?" is: 1, 8, 64, 512 — powers of eight**
**Answer: False** — Only 0 to 7 — 8 and 9 never appear

**3. (Sub lesson 1) True or false: the answer to "What are the first octal place values, from the right?" is: 1, 8, 64, 512 — powers of eight**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is octal 25 in decimal?" is: So the difference between the systems is stated plainly before conversions begin**
**Answer: False** — 21 — 2×8 + 5×1

**5. (Sub lesson 1) True or false: the answer to "Why does Malaysia teach octal beside decimal first?" is: So the difference between the systems is stated plainly before conversions begin**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is the base of the decimal system?" is: 1, 10, 100, 1000 — powers of ten**
**Answer: False** — 10 — decimal counts in tens

**7. (Sub lesson 2) True or false: the answer to "What are the first decimal place values, from the right?" is: 1, 10, 100, 1000 — powers of ten**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Can the marks 25 belong to both systems?" is: With a small subscript base — 25₈ against 25₁₀**
**Answer: False** — Yes — 25 is 25 in decimal but 21 when read as octal

**9. (Sub lesson 2) True or false: the answer to "How does Malaysia mark which system a number is in?" is: With a small subscript base — 25₈ against 25₁₀**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "A number contains the digit 8. Can it be octal?" is: 8 — octal counts in eights**
**Answer: False** — No — octal has no digit 8
