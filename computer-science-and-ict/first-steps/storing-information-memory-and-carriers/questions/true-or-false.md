# Storing Information — Memory and Carriers — true or false

Say whether each statement is true or false.

**1. Memory can forget.**
**Answer: True** — That is one reason carriers are needed.

**2. A carrier can be shown to other people.**
**Answer: True** — A book or photograph can be kept and shared.

**3. Information that is not stored is kept forever.**
**Answer: False** — Unstored information is soon forgotten.
