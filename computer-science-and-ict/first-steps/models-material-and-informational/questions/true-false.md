# Models — Material and Informational — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a model?" is: A stand-in made to study an object instead of the object itself**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does a model keep and leave out?" is: The paper origami ger (any one of: a globe, a toy car)**
**Answer: False** — It keeps the features that matter for the purpose and leaves the rest out

**3. (Sub lesson 1) True or false: the answer to "Name a material model from the book." is: The paper origami ger (any one of: a globe, a toy car)**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is a material model made of?" is: Information — words, tables, drawings, formulas**
**Answer: False** — Physical material copying the object's shape and size

**5. (Sub lesson 1) True or false: the answer to "What is an informational model made of?" is: Information — words, tables, drawings, formulas**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Which kind does the computer work with?" is: What can be held, turned and tested teaches what the real thing cannot**
**Answer: False** — Informational models only

**7. (Sub lesson 2) True or false: the answer to "Why is a model's simplicity its use?" is: What can be held, turned and tested teaches what the real thing cannot**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Give an informational model of a bear." is: Yes — different purposes keep different features**
**Answer: False** — A description or table of its properties (any one of: a drawing)

**9. (Sub lesson 2) True or false: the answer to "Can one object have several models?" is: Yes — different purposes keep different features**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is every computer file, in this lesson's terms?" is: A stand-in made to study an object instead of the object itself**
**Answer: False** — An informational model — information standing in for a thing
