# Early Counting Devices — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: The fingers — ten of them, always carried**
**Answer: True**

**2. (Sub lesson 1) True or false: One stone stood for each thing counted** — as the answer to: Why does counting often go in tens?
**Answer: False — Because people first counted on ten fingers**

**3. (Sub lesson 1) True or false: One stone stood for each thing counted**
**Answer: True**

**4. (Sub lesson 1) True or false: It kept the count after the things counted had gone** — as the answer to: What is the idea all these tools share?
**Answer: False — Let one thing stand for another, and keep the stand-ins in order**

**5. (Sub lesson 1) True or false: It kept the count after the things counted had gone**
**Answer: True**

**6. (Sub lesson 2) True or false: Storing a count is the first step toward a computer's memory** — as the answer to: What did knots in a rope record?
**Answer: False — One knot for each item counted**

**7. (Sub lesson 2) True or false: Storing a count is the first step toward a computer's memory**
**Answer: True**

**8. (Sub lesson 2) True or false: Laos Grade 6 ICT, Chapter 3 §1** — as the answer to: What can fingers and loose stones not do well?
**Answer: False — Remember a count for a long time**

**9. (Sub lesson 2) True or false: Laos Grade 6 ICT, Chapter 3 §1**
**Answer: True**

**10. (Sub lesson 2) True or false: The fingers — ten of them, always carried** — as the answer to: Name the four early devices in the book's order.
**Answer: False — Fingers, stones, sticks and knotted rope**
