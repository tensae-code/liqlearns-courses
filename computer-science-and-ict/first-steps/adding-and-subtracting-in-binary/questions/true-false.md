# Adding and Subtracting in Binary — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Where do you start a binary addition?" is: At the right-hand column, as in decimal**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is 0 + 1 in binary?" is: 10 — write 0 and carry 1**
**Answer: False** — 1

**3. (Sub lesson 1) True or false: the answer to "What is 1 + 1 in binary?" is: 10 — write 0 and carry 1**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is 1 + 1 + 1, when a carry arrives?" is: 1000 — because 5 + 3 = 8**
**Answer: False** — 11 in binary — write 1 and carry 1

**5. (Sub lesson 1) True or false: the answer to "What is 101 + 11 in binary — and its decimal check?" is: 1000 — because 5 + 3 = 8**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is 1 − 1 in binary?" is: 0 − 1 — there is nothing to take from**
**Answer: False** — 0

**7. (Sub lesson 2) True or false: the answer to "What is the hard case in binary subtraction?" is: 0 − 1 — there is nothing to take from**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What do you do for 0 − 1?" is: 2 — one whole place**
**Answer: False** — Borrow from the next column

**9. (Sub lesson 2) True or false: the answer to "What is a borrowed 1 worth in your column?" is: 2 — one whole place**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is 101 − 11 in binary — and its decimal check?" is: At the right-hand column, as in decimal**
**Answer: False** — 10 — because 5 − 3 = 2
