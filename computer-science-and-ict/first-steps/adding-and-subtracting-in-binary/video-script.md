# Video script — Adding and Subtracting in Binary

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

Add column by column from the right, exactly as in decimal. The only sums are: 0 + 0 = 0, 0 + 1 = 1, and 1 + 1 = 10 in binary — write 0 and carry 1 into the next column, just as 5 + 5 carries in decimal. Where a carry arrives, add three digits: 1 + 1 + 1 = 11 in binary — write 1, carry 1. Example: 101 + 11 = 1000 (5 + 3 = 8 — check it in decimal).
Subtract column by column from the right: 0 − 0 = 0, 1 − 0 = 1, 1 − 1 = 0. The hard case is 0 − 1: borrow from the next column — the borrowed 1 is worth 2 in your column (a whole place), so 2 − 1 = 1, and the lending column drops by one. Example: 101 − 11 = 10 (5 − 3 = 2). Again the decimal check proves the binary work.
