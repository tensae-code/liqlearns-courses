# Information — Questions and Tasks Review — true or false

Say whether each statement is true or false.

**1. The ears are a sense that receives information.**
**Answer: True** — Ears receive sounds.

**2. Memory is a carrier outside the body.**
**Answer: False** — Memory is the store inside a person; books and paper are carriers.
