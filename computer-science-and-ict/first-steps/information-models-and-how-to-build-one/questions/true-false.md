# Information Models — and How to Build One — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What decides everything in building a model?" is: The purpose — what the model must answer**
**Answer: True**

**Answer: False** — Name the purpose; choose the properties; fix the form; check against the object

**3. (Sub lesson 1) True or false: the answer to "What happens to properties that do not matter for the purpose?" is: They are left out**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Where a model and the world disagree, what is repaired?" is: Position (distance), time and speed**
**Answer: False** — The model

**5. (Sub lesson 1) True or false: the answer to "What properties does the moving-car model keep?" is: Position (distance), time and speed**
