# Hands-on — Codes That Represent Data in the Computer

The lesson with your hands and your feet, not only your eyes.

## Make your own code
Invent a small coding table for the letters of your first name, giving each letter its own 4-bit pattern. Write your name in code, swap with a companion, and decode each other's names using only the tables.

## Count the patterns
Work out how many different characters a 3-bit code can hold, then a 4-bit code. Say why real coding systems needed more and more bits as more alphabets joined.
