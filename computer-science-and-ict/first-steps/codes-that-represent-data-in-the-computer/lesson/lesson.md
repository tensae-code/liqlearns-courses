# Codes That Represent Data in the Computer

## Do it first

A computer cannot store the letter A — it can only store patterns of 0 and 1. Yet it hands you your letter back perfectly. In this lesson you learn the trick between the two: coding systems.

## Sub lesson 1 — Why data needs codes

The computer's memory holds only **binary patterns** — strings of 0s and 1s. Numbers fit naturally, because binary writes numbers directly. But letters, punctuation and symbols have no natural binary shape, so people agreed **codes**: a **coding system** assigns every character its own fixed binary pattern. When you type A, the keyboard sends A's pattern; when the computer shows A, it looks the pattern up and draws the letter. Change the code and the same pattern would mean a different letter — the agreement is what makes the data mean anything.

## Sub lesson 2 — One pattern per character

A coding system is a **table**: character by character, pattern by pattern, with no two characters sharing a pattern. The more patterns the system allows, the more characters it can hold — digits and capital letters first, then small letters, punctuation, and the letters of other alphabets, Arabic among them. Text stored this way stays exact: a document saved today opens with every character in place, because each pattern still points at its own character in the table.
