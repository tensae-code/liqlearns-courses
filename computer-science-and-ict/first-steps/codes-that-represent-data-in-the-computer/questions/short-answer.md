# Codes That Represent Data in the Computer — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does the computer's memory actually hold?**
**Answer: Only binary patterns — strings of 0s and 1s**

**2. (Sub lesson 1) Why do numbers need no special code?**
**Answer: Binary writes numbers directly**

**3. (Sub lesson 1) Why do letters need codes?**
**Answer: They have no natural binary shape, so a pattern must be agreed for each one**

**4. (Sub lesson 1) What is a coding system?**
**Answer: An agreed table giving each character its own fixed binary pattern**

**5. (Sub lesson 1) What happens when you type the letter A?**
**Answer: The keyboard sends A's pattern into the computer**

**6. (Sub lesson 2) What shape is a coding system?**
**Answer: A table — character by character, pattern by pattern**

**7. (Sub lesson 2) Can two characters share one pattern?**
**Answer: No — each character has its own pattern**

**8. (Sub lesson 2) What decides how many characters a system can hold?**
**Answer: How many patterns it allows**

**9. (Sub lesson 2) Which characters came after digits and capitals in bigger systems?**
**Answer: Small letters, punctuation, and the letters of other alphabets, Arabic among them**

**10. (Sub lesson 2) Why does saved text open exactly as written?**
**Answer: Each stored pattern still points at its own character in the table**
