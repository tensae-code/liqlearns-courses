# Codes That Represent Data in the Computer — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does the computer's memory actually hold?" is: Only binary patterns — strings of 0s and 1s**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Why do numbers need no special code?" is: They have no natural binary shape, so a pattern must be agreed for each one**
**Answer: False** — Binary writes numbers directly

**3. (Sub lesson 1) True or false: the answer to "Why do letters need codes?" is: They have no natural binary shape, so a pattern must be agreed for each one**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is a coding system?" is: The keyboard sends A's pattern into the computer**
**Answer: False** — An agreed table giving each character its own fixed binary pattern

**5. (Sub lesson 1) True or false: the answer to "What happens when you type the letter A?" is: The keyboard sends A's pattern into the computer**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What shape is a coding system?" is: No — each character has its own pattern**
**Answer: False** — A table — character by character, pattern by pattern

**7. (Sub lesson 2) True or false: the answer to "Can two characters share one pattern?" is: No — each character has its own pattern**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What decides how many characters a system can hold?" is: Small letters, punctuation, and the letters of other alphabets, Arabic among them**
**Answer: False** — How many patterns it allows

**9. (Sub lesson 2) True or false: the answer to "Which characters came after digits and capitals in bigger systems?" is: Small letters, punctuation, and the letters of other alphabets, Arabic among them**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why does saved text open exactly as written?" is: Only binary patterns — strings of 0s and 1s**
**Answer: False** — Each stored pattern still points at its own character in the table
