# Codes That Represent Data in the Computer — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does the computer's memory actually hold?**
a) Only binary patterns — strings of 0s and 1s  b) Binary writes numbers directly  c) They have no natural binary shape, so a pattern must be agreed for each one  d) An agreed table giving each character its own fixed binary pattern
**Answer: a) Only binary patterns — strings of 0s and 1s**

**2. (Sub lesson 1) Why do numbers need no special code?**
a) They have no natural binary shape, so a pattern must be agreed for each one  b) Binary writes numbers directly  c) An agreed table giving each character its own fixed binary pattern  d) The keyboard sends A's pattern into the computer
**Answer: b) Binary writes numbers directly**

**4. (Sub lesson 1) What is a coding system?**
