# Objects — Questions and Tasks Review — multiple choice

Pick the one right answer.

**1. Which task belongs to this review?**
a) Grouping objects by a chosen feature  b) Typing on a computer  c) Drawing in Paint
**Answer: a) Grouping objects by a chosen feature** — Grouping was Unit 1's third lesson.

**2. A similar feature is —**
a) a feature two objects share  b) a feature no object has  c) an object's name
**Answer: a) a feature two objects share** — Similar means shared.

**3. If the riddle task goes wrong, the review tells you to —**
a) skip the unit  b) visit the riddles lesson again  c) stop learning
**Answer: b) visit the riddles lesson again** — Each task names the lesson it checks.

**4. A distinguishing feature tells —**
a) all objects apart at once  b) one exact object apart from alike ones  c) the price of an object
**Answer: b) one exact object apart from alike ones** — It is the feature only that object has.
