# Lesson plan — Objects — Questions and Tasks Review

**Course:** Computer Science and ICT · **Title:** First Steps · **Lesson:** Objects — Questions and Tasks Review
**Place in the curriculum:** ICT expansion — Azerbaijan (2026-11-14) — in the title First Steps on the ICT course ladder (TITLES.md). Built new from Azerbaijan's *İnformatika 2, Grade 2*, because no existing lesson teaches this thing as its own lesson at this level.
**The one thing this lesson teaches:** This review checks the whole Objects unit: naming objects, similar features, grouping by a feature, distinguishing features and riddles.
**This lesson's own level:** Grade 2 simple — it stands on the child's own everyday world and on the lessons named below; every new word is built inside the lesson from things the child can do at once.

## Before this lesson
- Recommended first: the five Objects lessons of Unit 1 in First Steps, from Objects and Their Names to Describing an Object by Its Features — Riddles. Recommended, never forced — a learner may land on this review directly, and each task names the lesson it checks.

## What the learner can do when it ends
1. Name objects and their features, and find similar features of a pair.
2. Group objects by a chosen feature and check the group; find a distinguishing feature.
3. Solve and make a riddle with true features only.

## What you need
The unit's objects on a table: mixed small objects for grouping, alike pairs for telling apart. No computer is needed.

## If the learner is stuck
Fails the grouping task → revisit Grouping Objects by a Feature: choose the feature first, then sort, then check. Fails the riddle task → revisit the riddles lesson and check every feature against the real object.
