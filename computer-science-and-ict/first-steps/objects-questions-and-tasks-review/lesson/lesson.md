# Objects — Questions and Tasks Review

## Do it first

Quick check before you start: name one object, say one feature it shares with another object, and say one feature that tells it apart. This lesson is the Objects unit's own questions and tasks — its check-yourself review.

## Objects — Questions and Tasks Review

This is the **review lesson** for the Objects unit — the book's own 'questions and tasks' page for everything about objects. Work through it task by task; each task checks one lesson of the unit.

**Task set 1 — names and features.** Name objects around you and say a feature of each: its colour, shape or size. Then take two objects and find their similar features — the features they share.

**Task set 2 — grouping and telling apart.** Group a set of objects by one chosen feature, say the feature first, and check every object. Then find a distinguishing feature — the one feature that tells one exact object apart from its alike neighbours.

**Task set 3 — riddles.** Solve a riddle by listening to the features one at a time, and make a riddle of your own with three or four true features and no name. If a task goes wrong, that task names the lesson to visit again — the review is a map back, not only a test.

## Say it to your companion

Tell your companion, in your own words: This review checks the whole Objects unit: naming objects, similar features, grouping by a feature, distinguishing features and riddles. Then let your companion ask you one question about it — and answer from the lesson, not from memory of the book's exact words.

## Do It Yourself

1. Show it, don't just say it: name objects and their features, and find similar features of a pair.
2. Show it, don't just say it: group objects by a chosen feature and check the group; find a distinguishing feature.
3. Show it, don't just say it: solve and make a riddle with true features only.
