# Number Systems — Positional Systems and the Binary System — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What makes a system positional?** → **A digit's value depends on its position in the number**

**2. (Sub lesson 1) What is a system's base?** → **Its number of different digits — and the weight each position step multiplies by**

**3. (Sub lesson 1) What is decimal's base and digits?** → **Base 10, digits 0–9**

**4. (Sub lesson 1) In 222, what are the three digits worth?** → **Two hundred, twenty and two**

**5. (Sub lesson 1) How is a positional number's value computed?** → **As the sum of its digits times their place weights**

**6. (Sub lesson 2) What are binary's base and digits?** → **Base 2, digits 0 and 1**

**7. (Sub lesson 2) What are binary's first place values?** → **1, 2, 4, 8, 16 — doubling each step**

**8. (Sub lesson 2) What is 101 in binary, in decimal?** → **5 (4 + 0 + 1)**

**9. (Sub lesson 2) Why does the computer use binary?** → **Its parts have two stable states, and one digit matches one state**

**10. (Sub lesson 2) What is one binary digit called?** → **A bit**
