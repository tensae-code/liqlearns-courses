# Number Systems — Positional Systems and the Binary System — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A digit's value depends on its position in the number**
**Answer: True**

**2. (Sub lesson 1) True or false: A digit's value depends on its position in the number** — as the answer to: What is a system's base?
**Answer: False — Its number of different digits — and the weight each position step multiplies by**

**3. (Sub lesson 1) True or false: Base 10, digits 0–9**
**Answer: True**

**4. (Sub lesson 1) True or false: Base 10, digits 0–9** — as the answer to: In 222, what are the three digits worth?
**Answer: False — Two hundred, twenty and two**

**5. (Sub lesson 1) True or false: As the sum of its digits times their place weights**
**Answer: True**

**6. (Sub lesson 2) True or false: As the sum of its digits times their place weights** — as the answer to: What are binary's base and digits?
**Answer: False — Base 2, digits 0 and 1**

**7. (Sub lesson 2) True or false: 1, 2, 4, 8, 16 — doubling each step**
**Answer: True**

**8. (Sub lesson 2) True or false: 1, 2, 4, 8, 16 — doubling each step** — as the answer to: What is 101 in binary, in decimal?
**Answer: False — 5 (4 + 0 + 1)**

**9. (Sub lesson 2) True or false: Its parts have two stable states, and one digit matches one state**
**Answer: True**

**10. (Sub lesson 2) True or false: Its parts have two stable states, and one digit matches one state** — as the answer to: What is one binary digit called?
**Answer: False — A bit**
