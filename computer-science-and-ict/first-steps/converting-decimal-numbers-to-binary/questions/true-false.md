# Converting Decimal Numbers to Binary — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What do you divide by, again and again?" is: By two**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What do you write down at each division?" is: When the answer reaches 0**
**Answer: False** — The remainder — always 0 or 1

**3. (Sub lesson 1) True or false: the answer to "When do you stop dividing?" is: When the answer reaches 0**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What are the divisions for 13?" is: No — a remainder on dividing by 2 is always 0 or 1**
**Answer: False** — 13 ÷ 2 = 6 rem 1; 6 ÷ 2 = 3 rem 0; 3 ÷ 2 = 1 rem 1; 1 ÷ 2 = 0 rem 1

**5. (Sub lesson 1) True or false: the answer to "Can a remainder ever be 2?" is: No — a remainder on dividing by 2 is always 0 or 1**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "In which order do you read the remainders?" is: 1101**
**Answer: False** — From last to first — upwards

**7. (Sub lesson 2) True or false: the answer to "What is 13 in binary?" is: 1101**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Where does the first remainder you found end up?" is: By place value — 1101 = 8 + 4 + 0 + 1 = 13**
**Answer: False** — As the last digit — the ones place of the binary number

**9. (Sub lesson 2) True or false: the answer to "How do you check a conversion?" is: By place value — 1101 = 8 + 4 + 0 + 1 = 13**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What does a failed check tell you?" is: By two**
**Answer: False** — A division or the reading direction went wrong — do the method again
