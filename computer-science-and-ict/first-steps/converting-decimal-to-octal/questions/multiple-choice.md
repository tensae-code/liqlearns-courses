# Converting Decimal to Octal — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What do you divide by, again and again?**
a) By 8 — the octal base  b) The remainder — always a digit from 0 to 7  c) When the answer reaches 0  d) 25 ÷ 8 = 3 rem 1; then 3 ÷ 8 = 0 rem 3
**Answer: a) By 8 — the octal base**

**2. (Sub lesson 1) What do you write down at each division?**
a) When the answer reaches 0  b) The remainder — always a digit from 0 to 7  c) 25 ÷ 8 = 3 rem 1; then 3 ÷ 8 = 0 rem 3  d) From last to first — upwards
**Answer: b) The remainder — always a digit from 0 to 7**

**3. (Sub lesson 1) When do the divisions stop?**
a) 25 ÷ 8 = 3 rem 1; then 3 ÷ 8 = 0 rem 3  b) From last to first — upwards  c) When the answer reaches 0  d) 31₈
**Answer: c) When the answer reaches 0**

**4. (Sub lesson 1) For 25, what are the divisions?**
a) From last to first — upwards  b) 31₈  c) The last remainder found — the biggest place  d) 25 ÷ 8 = 3 rem 1; then 3 ÷ 8 = 0 rem 3
**Answer: d) 25 ÷ 8 = 3 rem 1; then 3 ÷ 8 = 0 rem 3**

**5. (Sub lesson 1) In what order are the remainders read?**
a) From last to first — upwards  b) 31₈  c) The last remainder found — the biggest place  d) By place value — 31₈ = 3×8 + 1 = 25
**Answer: a) From last to first — upwards**

**6. (Sub lesson 2) What is 25 in octal?**
a) The last remainder found — the biggest place  b) 31₈  c) By place value — 31₈ = 3×8 + 1 = 25  d) 12₈ — 10 ÷ 8 = 1 rem 2, then 1 ÷ 8 = 0 rem 1, read upwards
**Answer: b) 31₈**

**7. (Sub lesson 2) Which remainder becomes the first octal digit?**
a) By place value — 31₈ = 3×8 + 1 = 25  b) 12₈ — 10 ÷ 8 = 1 rem 2, then 1 ÷ 8 = 0 rem 1, read upwards  c) The last remainder found — the biggest place  d) A division or the reading direction went wrong — work it again
**Answer: c) The last remainder found — the biggest place**

**8. (Sub lesson 2) How do you check the answer?**
a) 12₈ — 10 ÷ 8 = 1 rem 2, then 1 ÷ 8 = 0 rem 1, read upwards  b) A division or the reading direction went wrong — work it again  c) By 8 — the octal base  d) By place value — 31₈ = 3×8 + 1 = 25
**Answer: d) By place value — 31₈ = 3×8 + 1 = 25**

**9. (Sub lesson 2) What is 10 in octal?**
a) 12₈ — 10 ÷ 8 = 1 rem 2, then 1 ÷ 8 = 0 rem 1, read upwards  b) A division or the reading direction went wrong — work it again  c) By 8 — the octal base  d) The remainder — always a digit from 0 to 7
**Answer: a) 12₈ — 10 ÷ 8 = 1 rem 2, then 1 ÷ 8 = 0 rem 1, read upwards**

**10. (Sub lesson 2) What does a failed check mean?**
a) By 8 — the octal base  b) A division or the reading direction went wrong — work it again  c) The remainder — always a digit from 0 to 7  d) When the answer reaches 0
