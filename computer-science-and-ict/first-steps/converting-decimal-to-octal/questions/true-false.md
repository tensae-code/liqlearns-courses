# Converting Decimal to Octal — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What do you divide by, again and again?" is: By 8 — the octal base**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What do you write down at each division?" is: When the answer reaches 0**
**Answer: False** — The remainder — always a digit from 0 to 7

**3. (Sub lesson 1) True or false: the answer to "When do the divisions stop?" is: When the answer reaches 0**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "For 25, what are the divisions?" is: From last to first — upwards**
**Answer: False** — 25 ÷ 8 = 3 rem 1; then 3 ÷ 8 = 0 rem 3

**5. (Sub lesson 1) True or false: the answer to "In what order are the remainders read?" is: From last to first — upwards**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is 25 in octal?" is: The last remainder found — the biggest place**
**Answer: False** — 31₈

**7. (Sub lesson 2) True or false: the answer to "Which remainder becomes the first octal digit?" is: The last remainder found — the biggest place**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How do you check the answer?" is: 12₈ — 10 ÷ 8 = 1 rem 2, then 1 ÷ 8 = 0 rem 1, read upwards**
**Answer: False** — By place value — 31₈ = 3×8 + 1 = 25

**9. (Sub lesson 2) True or false: the answer to "What is 10 in octal?" is: 12₈ — 10 ÷ 8 = 1 rem 2, then 1 ÷ 8 = 0 rem 1, read upwards**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What does a failed check mean?" is: By 8 — the octal base**
**Answer: False** — A division or the reading direction went wrong — work it again
