## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Objects and their properties** — An **object** is any thing around us that can be named and pointed to — a book, a ger, the Mazaalai bear. Every object has **properties** (its **parameters**): the features by which it can be described and measured — a book's size, colour, weight and number of pages. To describe an object is to list its properties and their values; two objects of the same kind are told apart by the values their properties take.
2. **Environment and classification** — No object stands alone: each exists in an **environment** — the surroundings it belongs to and acts in. Objects are **classified** by shared properties: objects whose key properties match are put in one **class** (all books together, all bears together). Classification is the first information skill in the book's order: once the world is sorted into objects with properties, information about it can be stored, compared and reasoned with — the work the rest of the course builds on.
