# Converting Between Binary, Octal and Hexadecimal — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Because 8 = 2³ — every octal digit is exactly three binary digits**
**Answer: True**

**2. (Sub lesson 1) True or false: Because 8 = 2³ — every octal digit is exactly three binary digits** — as the answer to: How is binary grouped for octal?
**Answer: False — In threes from the right, the last group padded with leading zeros**

**3. (Sub lesson 1) True or false: 56₈ (101 | 110)**
**Answer: True**

**4. (Sub lesson 1) True or false: 56₈ (101 | 110)** — as the answer to: What arithmetic does the conversion need?
**Answer: False — None — only grouping**

**5. (Sub lesson 1) True or false: Long bit strings are shorter and safer to read grouped**
**Answer: True**

**6. (Sub lesson 2) True or false: Long bit strings are shorter and safer to read grouped** — as the answer to: Why groups of four for hexadecimal?
**Answer: False — Because 16 = 2⁴ — every hex digit is exactly four binary digits**

**7. (Sub lesson 2) True or false: 2E₁₆ (0010 | 1110)**
**Answer: True**

**8. (Sub lesson 2) True or false: 2E₁₆ (0010 | 1110)** — as the answer to: What letters does hexadecimal use, and for what?
**Answer: False — A–F, for the values ten to fifteen**

**9. (Sub lesson 2) True or false: Through binary — expand by threes, regroup by fours**
**Answer: True**

**10. (Sub lesson 2) True or false: Through binary — expand by threes, regroup by fours** — as the answer to: What are the bases, in the lesson's closing phrase?
**Answer: False — Views — some group the bits for the hand and eye**
