# Converting Between Binary, Octal and Hexadecimal — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Groups of three — binary and octal
Sub lesson 1 questions from the type files. Pass mark: Because 8 = 2³ — every octal digit is exactly three binary digits; In threes from the right, the last group padded with leading zeros; 56₈ (101 | 110); None — only grouping; Long bit strings are shorter and safer to read grouped.

## Sub lesson 2 — Groups of four — binary and hexadecimal
Sub lesson 2 questions from the type files. Pass mark: Because 16 = 2⁴ — every hex digit is exactly four binary digits; 2E₁₆ (0010 | 1110); A–F, for the values ten to fifteen; Through binary — expand by threes, regroup by fours; Views — some group the bits for the hand and eye.
