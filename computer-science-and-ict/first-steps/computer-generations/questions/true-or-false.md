# Computer generations — five periods of change — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A computer generation is a period marked by a major technological change.
**Answer: True**

**2. (Sub lesson 2)** There are six generations of computers.
**Answer: False**

**3. (Sub lesson 3)** In this course, definitions are given before any brainstorming.
**Answer: False**

**4. (Sub lesson 2)** The fourth generation is still the present generation alongside the fifth.
**Answer: True**
