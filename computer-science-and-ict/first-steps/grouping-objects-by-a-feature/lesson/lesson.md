# Grouping Objects by a Feature

## Do it first

Put all the red things in one pile and all the blue things in another. You have grouped by colour. This lesson teaches grouping: choose a feature first, then sort every object by it.

## Grouping Objects by a Feature

**Grouping** means putting objects that share a feature together. First you **choose the feature** — colour, shape, size, or what the object is for. Then every object goes with the objects that share that feature.

Group by colour: all the red objects in one group, all the blue objects in another group. Group by shape: all the round objects together, all the square objects together. The same objects can make different groups when you choose a different feature.

Every object in a group must have the chosen feature. If one object in the red group is not red, it is in the wrong group — move it. Checking a group means checking each object against the chosen feature.

## Say it to your companion

Tell your companion, in your own words: Objects that share one chosen feature can be put together in one group — grouping is sorting objects by a feature you choose first. Then let your companion ask you one question about it — and answer from the lesson, not from memory of the book's exact words.

## Do It Yourself

1. Show it, don't just say it: say what grouping is, and name the feature before sorting.
2. Show it, don't just say it: group a set of objects by colour, and again by shape.
3. Show it, don't just say it: check a finished group and move an object that does not have the chosen feature.
