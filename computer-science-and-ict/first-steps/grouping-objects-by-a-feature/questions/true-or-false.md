# Grouping Objects by a Feature — true or false

Say whether each statement is true or false.

**1. You should choose the feature before you start sorting.**
**Answer: True** — Choosing first makes the groups clear.

**2. An object that does not have the group's feature can stay in the group.**
**Answer: False** — It belongs in another group — move it.

**3. Grouping by shape and grouping by colour can give different groups from the same objects.**
**Answer: True** — A different feature makes different groups.
