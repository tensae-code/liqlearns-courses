# Grouping Objects by a Feature — multiple choice

Pick the one right answer.

**1. Grouping means —**
a) throwing objects away  b) putting objects that share a feature together  c) naming one object
**Answer: b) putting objects that share a feature together** — The shared feature makes the group.

**2. What must you do first when you group?**
a) Choose the feature  b) Close your eyes  c) Count to ten
**Answer: a) Choose the feature** — Colour, shape or size — choose before sorting.

**3. In a group made by colour 'red', every object must be —**
a) round  b) red  c) soft
**Answer: b) red** — Each object must have the chosen feature.

**4. Can the same objects be grouped in a different way?**
a) No, never  b) Yes, by choosing a different feature  c) Only by a teacher
**Answer: b) Yes, by choosing a different feature** — By colour first, then by shape, gives different groups.
