# Grouping Objects by a Feature — short answer

Answer in a sentence or two.

**1. You have red, blue, round and square blocks. Name two different ways to group them.**
**Answer:** By colour (red group, blue group) and by shape (round group, square group).

**2. How do you check a finished group?**
**Answer:** Check each object in it against the chosen feature; move any object that does not have it.
