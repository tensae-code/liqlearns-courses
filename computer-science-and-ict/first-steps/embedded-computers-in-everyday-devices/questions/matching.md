10. (Sub lesson 2) How many devices does one embedded computer serve?

a) When the device is made — it is built in, not added later
b) It is fitted to that one device — its parts and program serve the device it lives in
c) The wash programmes — the order and timing of filling, washing, rinsing and spinning
d) The engine and the car's systems as it runs
e) It answers the remote control and shows the chosen channel
f) The device stops being itself — a washing machine that cannot choose a programme is only a tub
g) One — the device it is built into
h) A computer built inside another device, put there when the device was made
i) A washing machine (any one of: a mobile phone, a car, a television)
j) Inside the device — the user uses the device, not the computer on its own
