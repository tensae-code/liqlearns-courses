# Embedded Computers in Everyday Devices — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is an embedded computer?**
**Answer: A computer built inside another device, put there when the device was made**

**2. (Sub lesson 1) Name a device with an embedded computer.**
**Answer: A washing machine (any one of: a mobile phone, a car, a television)**

**3. (Sub lesson 1) Where does the user meet the embedded computer?**
**Answer: Inside the device — the user uses the device, not the computer on its own**

**4. (Sub lesson 1) When is the embedded computer put into the device?**
**Answer: When the device is made — it is built in, not added later**

**5. (Sub lesson 1) How is an embedded computer fitted?**
**Answer: It is fitted to that one device — its parts and program serve the device it lives in**

**6. (Sub lesson 2) What does the washing machine's embedded computer control?**
**Answer: The wash programmes — the order and timing of filling, washing, rinsing and spinning**

**7. (Sub lesson 2) What does the embedded computer in a car help control?**
**Answer: The engine and the car's systems as it runs**

**8. (Sub lesson 2) What does the television's embedded computer do?**
**Answer: It answers the remote control and shows the chosen channel**

**9. (Sub lesson 2) What happens if the embedded computer is taken out?**
**Answer: The device stops being itself — a washing machine that cannot choose a programme is only a tub**

**10. (Sub lesson 2) How many devices does one embedded computer serve?**
**Answer: One — the device it is built into**
