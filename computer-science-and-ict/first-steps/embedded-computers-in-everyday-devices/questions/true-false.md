# Embedded Computers in Everyday Devices — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is an embedded computer?" is: A computer built inside another device, put there when the device was made**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Name a device with an embedded computer." is: Inside the device — the user uses the device, not the computer on its own**
**Answer: False** — A washing machine (any one of: a mobile phone, a car, a television)

**3. (Sub lesson 1) True or false: the answer to "Where does the user meet the embedded computer?" is: Inside the device — the user uses the device, not the computer on its own**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "When is the embedded computer put into the device?" is: It is fitted to that one device — its parts and program serve the device it lives in**
**Answer: False** — When the device is made — it is built in, not added later

**5. (Sub lesson 1) True or false: the answer to "How is an embedded computer fitted?" is: It is fitted to that one device — its parts and program serve the device it lives in**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does the washing machine's embedded computer control?" is: The engine and the car's systems as it runs**
**Answer: False** — The wash programmes — the order and timing of filling, washing, rinsing and spinning

**7. (Sub lesson 2) True or false: the answer to "What does the embedded computer in a car help control?" is: The engine and the car's systems as it runs**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does the television's embedded computer do?" is: The device stops being itself — a washing machine that cannot choose a programme is only a tub**
**Answer: False** — It answers the remote control and shows the chosen channel

**9. (Sub lesson 2) True or false: the answer to "What happens if the embedded computer is taken out?" is: The device stops being itself — a washing machine that cannot choose a programme is only a tub**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "How many devices does one embedded computer serve?" is: A computer built inside another device, put there when the device was made**
**Answer: False** — One — the device it is built into
