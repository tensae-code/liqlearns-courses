# Embedded Computers in Everyday Devices — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — An embedded computer — a computer built inside a device
Sub lesson 1 questions from the type files. Pass mark: A computer built inside another device, put there when the device was made; A washing machine (any one of: a mobile phone, a car, a television); Inside the device — the user uses the device, not the computer on its own; When the device is made — it is built in, not added later; It is fitted to that one device — its parts and program serve the device it lives in.

## Sub lesson 2 — What the embedded computer controls — the device's own job
Sub lesson 2 questions from the type files. Pass mark: The wash programmes — the order and timing of filling, washing, rinsing and spinning; The engine and the car's systems as it runs; It answers the remote control and shows the chosen channel; The device stops being itself — a washing machine that cannot choose a programme is only a tub; One — the device it is built into.
