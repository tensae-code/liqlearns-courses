**1. (Sub lesson 1) What does a computer actually store for a text character?**
a) A number — its ASCII code value  b) In binary  c) No — the same value 65 in two writings  d) Each octal digit stands for three bits
**Answer: a) A number — its ASCII code value**

**2. (Sub lesson 1) In what form is that value held inside the machine?**
a) No — the same value 65 in two writings  b) In binary  c) Each octal digit stands for three bits  d) The computer's own language — binary patterns the processor acts on directly
**Answer: b) In binary**

**3. (Sub lesson 1) Is octal 101 for A a different holding from binary 1000001?**
