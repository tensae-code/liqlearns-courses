# Octal, ASCII and Machine Language — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does a computer actually store for a text character?**
**Answer: A number — its ASCII code value**

**2. (Sub lesson 1) In what form is that value held inside the machine?**
**Answer: In binary**

**3. (Sub lesson 1) Is octal 101 for A a different holding from binary 1000001?**
**Answer: No — the same value 65 in two writings**

**4. (Sub lesson 1) Why is octal a shorter writing?**
**Answer: Each octal digit stands for three bits**

**5. (Sub lesson 1) What is machine language?**
**Answer: The computer's own language — binary patterns the processor acts on directly**

**6. (Sub lesson 2) Why do people group bits into octal or hexadecimal?**
**Answer: A page of raw bits cannot be read or checked by eye**

**7. (Sub lesson 2) How many bits does one hexadecimal digit stand for?**
**Answer: Four**

**8. (Sub lesson 2) What are the three views of one value in this lesson?**
**Answer: Octal writing, ASCII meaning, machine-language binary**

**9. (Sub lesson 2) Does octal change what the machine stores?**
**Answer: No — it only changes how people write the number**

**10. (Sub lesson 2) What does the processor act on directly?**
**Answer: The binary patterns of machine language**
