# Technology — tools people make to solve problems — true or false

Say whether each statement is true or false.

**1. Technology is wider than computers.**
**Answer: True** — Any tool or machine people create to solve a problem counts.

**2. The television solves the problem of seeing and hearing far-away events.**
**Answer: True**

**3. Rain is technology because it solves the problem of thirst.**
**Answer: False** — Rain is not made by humans.

**4. Medicine is one of the places the book finds technology.**
**Answer: True**
