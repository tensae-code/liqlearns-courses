# Converting Octal to Decimal — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What are the octal place values, from the right?" is: 1, 8, 64, 512 — powers of eight**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What do you do with each digit?" is: 4×8 = 32 — it stands in the eights place**
**Answer: False** — Multiply it by the place value it stands in

**3. (Sub lesson 1) True or false: the answer to "For 47₈, what is the 4 worth?" is: 4×8 = 32 — it stands in the eights place**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What do you do with the products?" is: 39 — 32 + 7**
**Answer: False** — Add them all — the sum is the decimal answer

**5. (Sub lesson 1) True or false: the answer to "What is 47₈ in decimal?" is: 39 — 32 + 7**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is 125₈ in decimal?" is: 8 — 1×8 + 0×1**
**Answer: False** — 85 — 64 + 16 + 5

**7. (Sub lesson 2) True or false: the answer to "What is 10₈ in decimal?" is: 8 — 1×8 + 0×1**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How can the forward method check this one?" is: 511 — 7×64 + 7×8 + 7×1**
**Answer: False** — Convert the decimal answer back by dividing by 8 — the starting octal number must return

**9. (Sub lesson 2) True or false: the answer to "What is 777₈ in decimal?" is: 511 — 7×64 + 7×8 + 7×1**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Does the order of multiplying matter?" is: 1, 8, 64, 512 — powers of eight**
**Answer: False** — No — biggest place first or smallest first, the products are the same
