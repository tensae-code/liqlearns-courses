# Converting Octal to Decimal — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What are the octal place values, from the right?**
a) 1, 8, 64, 512 — powers of eight  b) Multiply it by the place value it stands in  c) 4×8 = 32 — it stands in the eights place  d) Add them all — the sum is the decimal answer
**Answer: a) 1, 8, 64, 512 — powers of eight**

**2. (Sub lesson 1) What do you do with each digit?**
a) 4×8 = 32 — it stands in the eights place  b) Multiply it by the place value it stands in  c) Add them all — the sum is the decimal answer  d) 39 — 32 + 7
**Answer: b) Multiply it by the place value it stands in**

**3. (Sub lesson 1) For 47₈, what is the 4 worth?**
a) Add them all — the sum is the decimal answer  b) 39 — 32 + 7  c) 4×8 = 32 — it stands in the eights place  d) 85 — 64 + 16 + 5
**Answer: c) 4×8 = 32 — it stands in the eights place**

**4. (Sub lesson 1) What do you do with the products?**
a) 39 — 32 + 7  b) 85 — 64 + 16 + 5  c) 8 — 1×8 + 0×1  d) Add them all — the sum is the decimal answer
**Answer: d) Add them all — the sum is the decimal answer**

**5. (Sub lesson 1) What is 47₈ in decimal?**
a) 39 — 32 + 7  b) 85 — 64 + 16 + 5  c) 8 — 1×8 + 0×1  d) Convert the decimal answer back by dividing by 8 — the starting octal number must return
**Answer: a) 39 — 32 + 7**

**6. (Sub lesson 2) What is 125₈ in decimal?**

**7. (Sub lesson 2) What is 10₈ in decimal?**
a) Convert the decimal answer back by dividing by 8 — the starting octal number must return  b) 511 — 7×64 + 7×8 + 7×1  c) 8 — 1×8 + 0×1  d) No — biggest place first or smallest first, the products are the same
**Answer: c) 8 — 1×8 + 0×1**

**8. (Sub lesson 2) How can the forward method check this one?**
a) 511 — 7×64 + 7×8 + 7×1  b) No — biggest place first or smallest first, the products are the same  c) 1, 8, 64, 512 — powers of eight  d) Convert the decimal answer back by dividing by 8 — the starting octal number must return

**9. (Sub lesson 2) What is 777₈ in decimal?**
a) 511 — 7×64 + 7×8 + 7×1  b) No — biggest place first or smallest first, the products are the same  c) 1, 8, 64, 512 — powers of eight  d) Multiply it by the place value it stands in
**Answer: a) 511 — 7×64 + 7×8 + 7×1**
