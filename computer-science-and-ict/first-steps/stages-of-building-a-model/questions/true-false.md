# Stages of Building a Model — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "Name the stages of building a model." is: Meet object and purpose; study the object; choose properties; choose kind and form; build; test and repair**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "At which stage are models won and lost?" is: One that serves none**
**Answer: False** — Choosing the properties the purpose needs

**3. (Sub lesson 1) True or false: the answer to "What is a model built without a purpose?" is: One that serves none**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is a model never tested?" is: Form — it is built in matter**
**Answer: False** — A guess with good handwriting

**5. (Sub lesson 1) True or false: the answer to "What does a material model copy?" is: Form — it is built in matter**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does an information model copy?" is: Studying, predicting and presenting what cannot be handled directly**
**Answer: False** — Knowledge — built in information

**7. (Sub lesson 2) True or false: the answer to "What is a model for?" is: Studying, predicting and presenting what cannot be handled directly**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Why can some things only be modelled?" is: At the choice of kind — the stages before are one craft**
**Answer: False** — They are too big, too small, too far, too dangerous, or not yet built

**9. (Sub lesson 2) True or false: the answer to "Where do the two kinds fork?" is: At the choice of kind — the stages before are one craft**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Which books carry this modelling strand?" is: Meet object and purpose; study the object; choose properties; choose kind and form; build; test and repair**
**Answer: False** — Mongolia's IT books, Grades 6 to 9
