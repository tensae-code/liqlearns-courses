# Hands-on — Frequently Used Codes — Fixed-Length and Variable-Length

The lesson with your hands and your feet, not only your eyes.

## Task one
**Length counts** — Code the word 'BANANA' alphabet in a 3-bit fixed code and count the bits; then in a made variable code (A=0, N=10, B=110) and compare.

## Task two
**Code design** — Design a prefix-free variable code for a 5-letter alphabet with given frequencies, and prove no word starts another.
