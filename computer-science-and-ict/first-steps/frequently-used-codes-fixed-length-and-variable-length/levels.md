## Sub lesson 1 — Fixed-length codes — the same size for every character
Sub lesson 1 questions from the type files. Pass mark: A code giving every character the same number of bits; 2ⁿ — 128 for ASCII's 7 bits; Simplicity — any character's place is found by counting; Each letter as five symbols from two kinds (a/b) — an early binary code; A fixed set of symbols per character, drawn from a two-symbol alphabet.

## Sub lesson 2 — Variable-length codes — short words for frequent guests
Sub lesson 2 questions from the type files. Pass mark: A code giving frequent characters short words and rare ones long words; E is one dot; Q is dash-dash-dot-dash; Fewer bits on average for real messages; Prefix-free — no word is the start of another; With pauses between letters.
