# Frequently Used Codes — Fixed-Length and Variable-Length — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What is a fixed-length code?**
**Answer: A code giving every character the same number of bits**

**2. (Sub lesson 1) How many characters can n bits per character code?**
**Answer: 2ⁿ — 128 for ASCII's 7 bits**

**3. (Sub lesson 1) What is the architecture's virtue?**
**Answer: Simplicity — any character's place is found by counting**

**4. (Sub lesson 1) What is Bacon's code?**
**Answer: Each letter as five symbols from two kinds (a/b) — an early binary code**

**5. (Sub lesson 1) What is a binary alphabet?**
**Answer: A fixed set of symbols per character, drawn from a two-symbol alphabet**

**6. (Sub lesson 2) What is a variable-length code?**
**Answer: A code giving frequent characters short words and rare ones long words**

**7. (Sub lesson 2) Give the Morse example.**
**Answer: E is one dot; Q is dash-dash-dot-dash**

**8. (Sub lesson 2) What does variable length win?**
**Answer: Fewer bits on average for real messages**

**9. (Sub lesson 2) What must code words be, to stay decodable?**
**Answer: Prefix-free — no word is the start of another**

**10. (Sub lesson 2) How does Morse mark the borders?**
**Answer: With pauses between letters**
