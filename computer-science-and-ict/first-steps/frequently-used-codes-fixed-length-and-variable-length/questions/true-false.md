# Frequently Used Codes — Fixed-Length and Variable-Length — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A code giving every character the same number of bits**
**Answer: True**

**2. (Sub lesson 1) True or false: A code giving every character the same number of bits** — as the answer to: How many characters can n bits per character code?
**Answer: False — 2ⁿ — 128 for ASCII's 7 bits**

**3. (Sub lesson 1) True or false: Simplicity — any character's place is found by counting**
**Answer: True**

**4. (Sub lesson 1) True or false: Simplicity — any character's place is found by counting** — as the answer to: What is Bacon's code?
**Answer: False — Each letter as five symbols from two kinds (a/b) — an early binary code**

**5. (Sub lesson 1) True or false: A fixed set of symbols per character, drawn from a two-symbol alphabet**
**Answer: True**

**6. (Sub lesson 2) True or false: A fixed set of symbols per character, drawn from a two-symbol alphabet** — as the answer to: What is a variable-length code?
**Answer: False — A code giving frequent characters short words and rare ones long words**

**7. (Sub lesson 2) True or false: E is one dot; Q is dash-dash-dot-dash**
**Answer: True**

**8. (Sub lesson 2) True or false: E is one dot; Q is dash-dash-dot-dash** — as the answer to: What does variable length win?
**Answer: False — Fewer bits on average for real messages**

**9. (Sub lesson 2) True or false: Prefix-free — no word is the start of another**
**Answer: True**

**10. (Sub lesson 2) True or false: Prefix-free — no word is the start of another** — as the answer to: How does Morse mark the borders?
**Answer: False — With pauses between letters**
