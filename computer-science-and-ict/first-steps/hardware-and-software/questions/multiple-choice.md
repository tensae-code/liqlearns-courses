# Hardware and software — the two parts of a computer system — multiple choice

Pick the one right answer.

**1. A computer system has how many parts in this frame?**
a) One  b) Two  c) Five
**Answer: b) Two** — Hardware and software.

**2. Hardware is —**
a) the instructions  b) the part you can see and touch  c) a kind of data
**Answer: b) the part you can see and touch**

**3. Software is —**
a) the instructions that make hardware work  b) the screen glass  c) the keyboard
**Answer: a) the instructions that make hardware work**

**4. Hardware is taught in —**
a) Unit 2  b) Unit 6  c) Unit 1 only
**Answer: a) Unit 2**

**5. The book's comparison for the two parts is —**
a) a river and a boat  b) a body and a mind  c) a lock and a key
**Answer: b) a body and a mind**
