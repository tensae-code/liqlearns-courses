# Hardware and software — the two parts of a computer system — true or false

Say whether each statement is true or false.

**1. Software without hardware has nothing to run on.**
**Answer: True**

**2. Hardware alone, with no software, is a complete working system.**
**Answer: False** — Hardware without software sits silent.

**3. Software is taught in Unit 3.**
**Answer: True**

**4. You can touch software the way you touch a keyboard.**
**Answer: False** — Software is instructions — real, but not touchable.
