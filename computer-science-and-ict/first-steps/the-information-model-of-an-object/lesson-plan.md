## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The property table — the object as its model** — An object's **information model** is the organised information that stands for it. The book's chosen form is the **table of properties**: the object's name at the head, its properties in the rows — for the **cat**: its size, coat, voice, habits; for the **bird**: wing, flight, song; for the **human**: height, language, work; for the **snakes**: length, venom, movement. The table is a model because it keeps what the purpose needs and drops the rest: the living animal stays outside; its table can be compared, sorted and studied at a desk.
2. **Modelling the five-snout livestock** — The lesson's own modelling is Mongolia's wealth: the **five-snout livestock** (таван хошуу мал) — horse, camel, cow, sheep, goat — each modelled in its property table, so the five tables can be laid side by side and read against each other: which gives milk, which carries, which survives the dzud's cold. One form for every object makes unlike things comparable — that is the table's power, and the reason the whole modelling strand of the Mongolian books keeps returning to it.

2. **The explanation** — the lesson text in lesson/lesson.md, in its parts in order.
