# Lesson plan — Advantages and Limitations of Information Systems

**Course:** Computer Science and ICT · **Title:** Computers in Society · **Lesson:** Advantages and Limitations of Information Systems
**Place in the curriculum:** ICT expansion — China (2026-11-14) — in the title Computers in Society on the ICT course ladder (TITLES.md). Built new from China's *IT Compulsory 2*, because no existing lesson in the course covers this thing as its own lesson.
**The one thing this lesson teaches:** Information systems bring real advantages — speed, accuracy, huge storage, easy sharing and better decisions — and real limitations — cost, breakdowns and dependence, security and privacy risks, displaced jobs, and the need for trained people; using a system well means knowing both sides.
**This lesson's own level:** It stands on the lessons about what an information system is and how one is developed. It asks for judgement, not new technique.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The advantages** — An information system works at machine speed: a calculation or a search that takes a person a day takes the system seconds. It is **accurate** in the way machines are — the same rule applied the same way every time, without tiredness. It **stores** enormous amounts of data in a tiny space and finds any item again instantly. It **shares**: the same information reaches many people in many places at once, always identical. And because records are complete and current, managers can base **decisions** on facts instead of guesses — a school can see which class is falling behind while there is still time to help.
2. **The limitations** — Systems also have limits, and the book names them honestly. They **cost** — to buy, to install, to maintain and to replace. They create **dependence**: when the system, the network or the power fails, work that used to continue by hand may stop entirely. They open **security and privacy risks** — data gathered in one place is worth stealing, and personal information can leak or be misused. They can **displace jobs** — work once done by clerks is done by the system, and people must find new roles. And they demand **trained people**: an untrained user can enter wrong data, and the system's accuracy then only spreads the error faster — garbage in, garbage out.

## What the learner can do when it ends
1. Name the advantages of information systems: speed, accuracy, storage, sharing, better decisions.
2. Name the limitations: cost, dependence and breakdown, security and privacy risks, displaced jobs, the need for trained people.
3. Explain 'garbage in, garbage out' with an example.
4. Judge one real system you know, giving one true advantage and one true limitation of it.

## What you need
Paper and a pencil.

## The run of the lesson (in order)
1. **Do it first** — A school office that once kept results in paper files can now print a whole school's report cards in an afternoon. The same office, on the day the power fails or the password is lost, can print nothing at all. Both of those are the same system. This lesson puts its two sides side by side. (lesson/lesson.md).

## If the learner is stuck
Lists only advantages → ask: what happens on the day it breaks, who pays for it, whose job changed, and what happens to the personal data it holds? Thinks accuracy means the data is always right → the system applies rules accurately to whatever data it is given; wrong input gives wrong output, faster.
