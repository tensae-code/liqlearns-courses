# Advantages and Limitations of Information Systems — short answer

Answer each question in a few sentences.

**1. (Sub lesson 1) Give one advantage and one limitation of a mobile-money system, each in one sentence.**
**Answer:** Advantage: money reaches a person far away in seconds, with an accurate record kept automatically. Limitation: when the network or the system is down, no payment can be made at all — and account data gathered in one place is a target for fraud.

**2. (Sub lesson 2) A head teacher says: 'The new system is accurate, so our results can never be wrong again.' Correct her, politely, in two sentences.**
**Answer:** The system applies its rules accurately, but only to the data it is given. If a mark is entered wrongly, the system will total, rank and print that error perfectly — garbage in, garbage out.
