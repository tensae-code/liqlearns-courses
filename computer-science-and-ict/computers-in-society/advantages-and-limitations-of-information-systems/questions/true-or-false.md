# Advantages and Limitations of Information Systems — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) An information system applies the same rule the same way every time, without tiredness.**
**Answer: True** — That is machine accuracy.

**2. (Sub lesson 2) Once a school has an information system, breakdowns no longer matter.**
**Answer: False** — Dependence means a breakdown can stop work entirely.

**3. (Sub lesson 2) Information systems can displace some jobs, such as clerical work.**
**Answer: True** — Work once done by clerks is done by the system; people must find new roles.
