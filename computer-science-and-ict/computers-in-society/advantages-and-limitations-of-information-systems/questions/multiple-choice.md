# Advantages and Limitations of Information Systems — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Which of these is an advantage of an information system?**
a) It never costs anything  b) The same search takes seconds instead of a day  c) It needs no trained users  d) It cannot break down
**Answer: b) The same search takes seconds instead of a day** — Speed is the machine's first gift.

**2. (Sub lesson 1) 'Better decisions' is an advantage because —**
a) managers enjoy computers  b) records are complete and current, so decisions rest on facts  c) the system decides everything alone  d) paper is banned
**Answer: b) records are complete and current, so decisions rest on facts** — A school can see a class falling behind while help is still possible.

**3. (Sub lesson 2) Dependence is a limitation because —**
a) users like the system too much  b) when the system, network or power fails, work may stop entirely  c) systems are heavy to carry  d) screens are bright
**Answer: b) when the system, network or power fails, work may stop entirely** — Work that once continued by hand can stop with the machine.

**4. (Sub lesson 2) 'Garbage in, garbage out' means —**
a) systems produce rubbish bins  b) wrong data entered gives wrong results, spread quickly and accurately  c) old computers must be thrown away  d) printers waste paper
**Answer: b) wrong data entered gives wrong results, spread quickly and accurately** — The system is accurate with whatever it is given — including errors.

**5. (Sub lesson 2) Which is a limitation named in this lesson?**
a) Sharing data instantly  b) Huge storage  c) Personal information can leak or be misused  d) Fast calculations
**Answer: c) Personal information can leak or be misused** — Gathered data is worth stealing — a security and privacy risk.
