## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **The method — question, hypothesis, test** — A **scientific method of inquiry** is a disciplined way of asking: start from an **observation** and a sharp **question**; propose a **hypothesis** — an answer stated so it could prove wrong; design a **test** (experiment or observation plan) whose result can support or refute it; and record **evidence** honestly, including the results you did not hope for. Armenia's Grade 10 book closes with scientific methods (Lesson 34, Theme 24) — the computing course handing its learners the general method of finding out.
2. **Checking and sharing — variables, repetition, peer review** — A test is fair when it changes **one variable at a time** and holds the rest still (controls), and when it can be **repeated** by others with the same result. Science then shares: methods and data are published so others can **review, repeat and challenge** — peer review is organised doubt. In computing the same method runs A/B tests, benchmarks and debugging itself: a bug report is a hypothesis ('it fails when…') waiting for its test.

## What the learner can do when it ends
1. Observation and question, hypothesis, test, and honestly recorded evidence
2. It is stated so it could prove wrong — a test can refute it
3. Support or refute the hypothesis — either outcome counts
4. The results you did not hope for, recorded as carefully as the hoped-for ones
