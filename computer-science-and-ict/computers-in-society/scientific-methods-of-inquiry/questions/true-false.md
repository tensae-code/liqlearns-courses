# Scientific Methods of Inquiry — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Observation and question, hypothesis, test, and honestly recorded evidence**
**Answer: True**

**2. (Sub lesson 1) True or false: Observation and question, hypothesis, test, and honestly recorded evidence** — as the answer to: What makes a hypothesis scientific?
**Answer: False — It is stated so it could prove wrong — a test can refute it**

**3. (Sub lesson 1) True or false: Support or refute the hypothesis — either outcome counts**
**Answer: True**

**4. (Sub lesson 1) True or false: Support or refute the hypothesis — either outcome counts** — as the answer to: What does honest evidence include?
**Answer: False — The results you did not hope for, recorded as carefully as the hoped-for ones**

**7. (Sub lesson 2) True or false: So others can run it and get the same result — one unrepeatable result convinces nobody**
