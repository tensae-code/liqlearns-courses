# Scientific Methods of Inquiry — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) What are the method's working parts, in order?** → **Observation and question, hypothesis, test, and honestly recorded evidence**

**2. (Sub lesson 1) What makes a hypothesis scientific?** → **It is stated so it could prove wrong — a test can refute it**

**3. (Sub lesson 1) What must the test's result be able to do?** → **Support or refute the hypothesis — either outcome counts**

**4. (Sub lesson 1) What does honest evidence include?** → **The results you did not hope for, recorded as carefully as the hoped-for ones**

**5. (Sub lesson 1) Where does Armenia place scientific methods?** → **Grade 10, Lesson 34 (Theme 24) — the closing lesson of the book**

**6. (Sub lesson 2) What makes a test fair?** → **It changes one variable at a time and holds the rest still, as controls**

**7. (Sub lesson 2) Why must a test be repeatable?** → **So others can run it and get the same result — one unrepeatable result convinces nobody**

**8. (Sub lesson 2) What is peer review?** → **Organised doubt — others review, repeat and challenge published methods and data**

**9. (Sub lesson 2) How is a bug report a scientific object?** → **It is a hypothesis — 'it fails when…' — waiting for its test**

**10. (Sub lesson 2) Name two computing homes of the same method.** → **A/B tests and benchmarks (and debugging)**
