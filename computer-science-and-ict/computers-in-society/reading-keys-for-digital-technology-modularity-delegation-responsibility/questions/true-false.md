# Reading Keys for Digital Technology — Modularity, Delegation, Responsibility — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A technology is built from smaller parts that can be combined, replaced and reused**
**Answer: True**

**2. (Sub lesson 1) True or false: A technology is built from smaller parts that can be combined, replaced and reused** — as the answer to: What is a technology's socio-technical environment?
**Answer: False — The people, habits, rules and other machines around it**

**3. (Sub lesson 1) True or false: Camera and screen (also: battery, programs, network)**
**Answer: True**

**4. (Sub lesson 1) True or false: Camera and screen (also: battery, programs, network)** — as the answer to: Where do the Décodage guides put the reading keys?
**Answer: False — In the Introduction of every cycle's guide**

**5. (Sub lesson 1) True or false: Because a tool can only be understood that way**
**Answer: True**

**6. (Sub lesson 2) True or false: Because a tool can only be understood that way** — as the answer to: What is delegation?
**Answer: False — Handing work over to the machine**

**7. (Sub lesson 2) True or false: No — the person who delegates still answers for the result**
**Answer: True**

**8. (Sub lesson 2) True or false: No — the person who delegates still answers for the result** — as the answer to: What does pluralism say?
**Answer: False — There is never only one tool, one answer or one way — several ways exist and can be compared**

**9. (Sub lesson 2) True or false: The person who delegated and should have checked**
**Answer: True**

**10. (Sub lesson 2) True or false: The person who delegated and should have checked** — as the answer to: Give an example of delegation.
**Answer: False — Letting the map navigate (also: an alarm remembering, a spell-checker watching)**
