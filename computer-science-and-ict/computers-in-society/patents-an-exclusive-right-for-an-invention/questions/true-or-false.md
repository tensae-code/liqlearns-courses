# Patents — an exclusive right for an invention — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** All software automatically qualifies for a patent.
**Answer: False** — it must meet the responsible authority's standards.

**2. (Sub lesson 1)** Google's PageRank and Amazon's one-click are named as patented software-related inventions.
**Answer: True** — the book's examples.

**3. (Sub lesson 2)** A patent stops others making or selling an invention.
**Answer: True** — the guide's keyed distinction (teacher guide — evidence).
