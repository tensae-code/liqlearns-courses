# Copyright — automatic protection for original works — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A patent and a copyright protect the same things.
**Answer: False** — patents protect inventions; copyright protects works of authorship.

**2. (Sub lesson 2)** Graphical user interfaces can be registered.
**Answer: True** — named in the book.

**3. (Sub lesson 2)** Without registration, a creator owns no copyright at all.
**Answer: False** — ownership is automatic; registration gates the lawsuit.
