# Kinds of Plagiarism — and Detecting It — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Seven**
**Answer: True**

**2. (Sub lesson 1) True or false: Seven** — as the answer to: What is patchwork plagiarism?
**Answer: False — Stitching sentences from several sources into a 'new' text**

**3. (Sub lesson 1) True or false: Submitting another's whole work, and copying large parts without credit**
**Answer: True**

**4. (Sub lesson 1) True or false: Submitting another's whole work, and copying large parts without credit** — as the answer to: Can reusing your own old work be plagiarism?
**Answer: False — Yes — presenting it as new**

**5. (Sub lesson 1) True or false: The reader is lied to about whose work it is**
**Answer: True**

**6. (Sub lesson 2) True or false: The reader is lied to about whose work it is** — as the answer to: How does detection software work?
**Answer: False — It compares a text against vast libraries and reports matching passages**

**7. (Sub lesson 2) True or false: It steals credit and hollows the plagiarist's learning (also poisons trust)**
**Answer: True**

**8. (Sub lesson 2) True or false: It steals credit and hollows the plagiarist's learning (also poisons trust)** — as the answer to: Name two prevention habits.
**Answer: False — Note-taking in your own words and marking quotations (also crediting sources where used)**

**9. (Sub lesson 2) True or false: A welcome checker**
**Answer: True**

**10. (Sub lesson 2) True or false: A welcome checker** — as the answer to: Where must credit appear?
**Answer: False — Where the source is used, not only in a final list**
