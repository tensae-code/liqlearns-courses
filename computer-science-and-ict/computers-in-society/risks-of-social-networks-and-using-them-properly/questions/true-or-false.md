# Risks of social networks — and using them properly — true or false

Say whether each sentence is true or false.

**1.** Personal information being stolen is one of the named risks.
**Answer: True — stolen personal information is risk seven.**

**2.** Untrustworthy, misleading content is hard to find online.
**Answer: False — the risk is that it is easy to find.**

**3.** Online bullying or harassment is listed separately from cyberbullying.
**Answer: True — both are named in the list of eight.**
