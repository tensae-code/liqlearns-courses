# Systems Analysis and Design — the Eight Steps — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "How many steps does Sudan's book count for building a computerised system?" is: Eight**
**Answer: True**

**Answer: False** — Each step answers the question the next one needs

**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is systems analysis?" is: Analysis asks what; design answers how**
**Answer: False** — Studying the present system — its data, people and faults — and fixing what the new system must do

**5. (Sub lesson 1) True or false: the answer to "What is systems design?" is: Drawing the new system before it is built — its files, inputs, processing and outputs**
