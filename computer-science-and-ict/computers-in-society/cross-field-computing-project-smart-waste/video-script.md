# Video script — A Cross-Field Computing Project — the Smart Waste Project

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A **cross-field project** (praktik lintas bidang) takes a problem that belongs to another field and answers it with computing. Indonesia's Grade 12 project theme is **waste**: groups design a computing system for it — a **smart trash bin** built on Arduino that senses and responds, an application for a **waste bank** (where sorted waste is weighed, recorded and exchanged), or a compost-monitoring app. The computing is real — sensors, programs, data — and so is the other field: the group must understand waste itself, not only wires.
The project is run the way real projects are: a **group journal** records the work as it happens — decisions, faults, fixes — a **report** presents the finished system and what it does, a **presentation** shows it to others, and **peer assessment** lets the group judge its own members' contributions. The journal is the project's memory: without it the report is written from forgetting. The lesson the project teaches beyond any device is that a computing system is finished only when other people can understand it, use it, and judge whether it works.
