## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **One project, many fields — the waste theme** — A **cross-field project** (praktik lintas bidang) takes a problem that belongs to another field and answers it with computing. Indonesia's Grade 12 project theme is **waste**: groups design a computing system for it — a **smart trash bin** built on Arduino that senses and responds, an application for a **waste bank** (where sorted waste is weighed, recorded and exchanged), or a compost-monitoring app. The computing is real — sensors, programs, data — and so is the other field: the group must understand waste itself, not only wires.
2. **Working as a group — journal, report, presentation, assessment** — The project is run the way real projects are: a **group journal** records the work as it happens — decisions, faults, fixes — a **report** presents the finished system and what it does, a **presentation** shows it to others, and **peer assessment** lets the group judge its own members' contributions. The journal is the project's memory: without it the report is written from forgetting. The lesson the project teaches beyond any device is that a computing system is finished only when other people can understand it, use it, and judge whether it works.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
