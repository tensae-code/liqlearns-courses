# Intellectual property — owning a creative work — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Intellectual property can be held in the hand like a tool.
**Answer: False** — the rights are intangible.

**2. (Sub lesson 2)** Trademark protection requires a mark distinctive enough to identify a source.
**Answer: True** — the table's requirement row (teacher guide — evidence).

**3. (Sub lesson 2)** Copyright's granted right includes control of reproduction and distribution.
**Answer: True** — the table's rights row (teacher guide — evidence).
