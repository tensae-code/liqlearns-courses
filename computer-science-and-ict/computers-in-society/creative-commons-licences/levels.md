# Creative Commons Licences — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — The licences — permission granted in advance
Sub lesson 1 questions from the type files. Pass mark: A standard public permission a creator attaches to a work, saying what others may do with it and on what terms; Copyright keeps a work closed unless the maker opens it; a CC licence opens it in advance.

## Sub lesson 2 — Using CC work — credit and obey the terms
Sub lesson 2 questions from the type files. Pass mark: Copies and adaptations must carry the same licence; Read the licence, follow its conditions, and give the credit it asks.
