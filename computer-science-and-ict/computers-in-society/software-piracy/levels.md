# Software Piracy — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — What piracy is — using software without its licence
Sub lesson 1 questions from the type files. Pass mark: The unauthorised copying, distribution or use of software; Installing on more machines than the licence allows, and downloading a paid program from a pirate source (any two named forms).

## Sub lesson 2 — Why it is wrong — the maker's right and the law
Sub lesson 2 questions from the type files. Pass mark: As stolen property; Pay for the licence, use free software, or use openly licensed work.
