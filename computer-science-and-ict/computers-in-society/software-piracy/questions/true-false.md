# Software Piracy — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is software piracy?" is: The unauthorised copying, distribution or use of software**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Name two forms of piracy from the lesson." is: Copyright — the maker's right to be paid for copies**
**Answer: False** — Installing on more machines than the licence allows, and downloading a paid program from a pirate source (any two named forms)

**3. (Sub lesson 1) True or false: the answer to "Why is piracy tempting?" is: The copy works, though no licence was paid for**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does the maker lose in piracy?" is: Pay for the licence, use free software, or use openly licensed work**
**Answer: False** — The sale each pirate copy replaces

**5. (Sub lesson 1) True or false: the answer to "What protects software in law?" is: Copyright — the maker's right to be paid for copies**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How does the law treat pirated software?" is: Yes — distributing a copy without the licence is piracy**
**Answer: False** — As stolen property

**7. (Sub lesson 2) True or false: the answer to "What are the honest alternatives to piracy?" is: Pay for the licence, use free software, or use openly licensed work**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Between which two lessons does Bhutan place piracy?" is: The unauthorised copying, distribution or use of software**
**Answer: False** — Between copyright and Creative Commons

**9. (Sub lesson 2) True or false: the answer to "Is sharing a copy with a friend piracy?" is: Yes — distributing a copy without the licence is piracy**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Whose work is a program?" is: The copy works, though no licence was paid for**
**Answer: False** — Its maker's — software is work, and work is owned
