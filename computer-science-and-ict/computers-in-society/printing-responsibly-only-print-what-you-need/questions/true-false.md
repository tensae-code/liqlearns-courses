# Printing Responsibly — Only Print What You Need — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Paper, ink and energy**
**Answer: True**

**2. (Sub lesson 1) True or false: Paper, ink and energy** — as the answer to: What is the first responsible-printing question?
**Answer: False — Do I need this on paper at all?**

**3. (Sub lesson 1) True or false: Do I need all of it, or only part?**
**Answer: True**

**4. (Sub lesson 1) True or false: Do I need all of it, or only part?** — as the answer to: When is the pause taken?
**Answer: False — Before printing, every time**

**5. (Sub lesson 1) True or false: As a class habit in the Parcours, not as a scolding**
**Answer: True**

**6. (Sub lesson 2) True or false: As a class habit in the Parcours, not as a scolding** — as the answer to: How can pages be saved when printing?
**Answer: False — Print only the pages that matter, and use both sides when allowed**

**7. (Sub lesson 2) True or false: So a mistake is not printed twice**
**Answer: True**

**8. (Sub lesson 2) True or false: So a mistake is not printed twice** — as the answer to: How can one copy serve several readers?
**Answer: False — Share the printed copy between readers instead of one each**

**9. (Sub lesson 2) True or false: That it was never needed at all**
**Answer: True**

**10. (Sub lesson 2) True or false: That it was never needed at all** — as the answer to: Name the habit in one phrase.
**Answer: False — Only print what you need**
