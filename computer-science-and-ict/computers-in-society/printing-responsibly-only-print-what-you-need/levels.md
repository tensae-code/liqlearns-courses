# Printing Responsibly — Only Print What You Need — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — The pause before printing
Sub lesson 1 questions from the type files. Pass mark: Paper, ink and energy; Do I need this on paper at all?; Do I need all of it, or only part?; Before printing, every time; As a class habit in the Parcours, not as a scolding.

## Sub lesson 2 — Printing well when you do print
Sub lesson 2 questions from the type files. Pass mark: Print only the pages that matter, and use both sides when allowed; So a mistake is not printed twice; Share the printed copy between readers instead of one each; That it was never needed at all; Only print what you need.
