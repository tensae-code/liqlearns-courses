# What an information system is — short answer

Answer in a short sentence.

**1.** Name the four things an information system does with information.
**Answer: Collects, processes, stores and shares it with its users.**

**2.** Why is a lone computer, switched off in a store room, not yet an information system at work?
**Answer: Because nothing is being collected, processed, stored and shared by components working together for users.**
