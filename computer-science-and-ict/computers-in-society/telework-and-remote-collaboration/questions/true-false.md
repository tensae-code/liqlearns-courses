# Telework and Remote Collaboration — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Work done away from the employer's place — the work travels over networks, not the worker over roads**
**Answer: True**

**2. (Sub lesson 1) True or false: Journeys unspent; work for a distant employer without moving house (or hours shaped around life)** — as the answer to: What sets its shape?
**Answer: False — Its tools — connection, remotely reached office systems, communication channels**

**3. (Sub lesson 1) True or false: Journeys unspent; work for a distant employer without moving house (or hours shaped around life)**
**Answer: True**

**4. (Sub lesson 1) True or false: Greece Grade 10 Efarmoges Pliroforikis, Chapter 14** — as the answer to: From where may it be done?
**Answer: False — Home, another town, another country**

**5. (Sub lesson 1) True or false: Greece Grade 10 Efarmoges Pliroforikis, Chapter 14**
**Answer: True**

**6. (Sub lesson 2) True or false: Video meeting (or shared screen, or live-edited document)** — as the answer to: Name the two kinds of collaboration time.
**Answer: False — Synchronous (together in the moment) and asynchronous (in turns)**

**7. (Sub lesson 2) True or false: Video meeting (or shared screen, or live-edited document)**
**Answer: True**

**8. (Sub lesson 2) True or false: Everything agreed is written where all can find it** — as the answer to: Give an asynchronous example.
**Answer: False — Messages, comments, shared files answered in turns**

**9. (Sub lesson 2) True or false: Everything agreed is written where all can find it**
**Answer: True**

**10. (Sub lesson 2) True or false: Work done away from the employer's place — the work travels over networks, not the worker over roads** — as the answer to: Choosing rightly between the kinds decides what?
**Answer: False — Whether telework stands or falls**
