# Interaction Design Process — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "With what does the process open?" is: Understanding — the users, their tasks, and the setting**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is designed on that ground?" is: A named user and task**
**Answer: False** — The interaction — screens, controls, order of steps, words

**3. (Sub lesson 1) True or false: the answer to "To what must each design choice be answerable?" is: A named user and task**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "A design that cannot say whose task a screen serves has done what?" is: A rough, cheap, testable version of the interaction**
**Answer: False** — Skipped the first step

**5. (Sub lesson 1) True or false: the answer to "What is a prototype?" is: A rough, cheap, testable version of the interaction**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "On what is the prototype evaluated?" is: Refinement — the design changes where the evidence says it fails**
**Answer: False** — The chapter's three measures — with users

**7. (Sub lesson 2) True or false: the answer to "What do the findings drive?" is: Refinement — the design changes where the evidence says it fails**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Does the loop repeat?" is: Its judges are users — and users must be met**
**Answer: False** — Yes — prototype and evaluate again, until the measures pass

**9. (Sub lesson 2) True or false: the answer to "Why can interaction not be got right by thinking alone?" is: Its judges are users — and users must be met**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Which design is the final one?" is: Understanding — the users, their tasks, and the setting**
**Answer: False** — The one the loop releases — not the first one the designer loved
