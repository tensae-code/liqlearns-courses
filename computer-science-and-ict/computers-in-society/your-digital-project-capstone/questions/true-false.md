# Your Digital Project — Capstone — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a capstone project?" is: One finished piece of work that proves the whole term's skills together**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does project planning start from?" is: From the term's lessons — database, documents, cloud, meetings — chosen for the goal**
**Answer: False** — A single clear goal — what the project will show or do, and who it is for

**3. (Sub lesson 1) True or false: the answer to "Where do the project's parts come from?" is: From the term's lessons — database, documents, cloud, meetings — chosen for the goal**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does the plan name?" is: A separate Arabic activity booklet with an activity set for each lesson**
**Answer: False** — The parts, the order of making them, and how each part is known to be finished

**5. (Sub lesson 1) True or false: the answer to "What mirrors Egypt's Grade 7 lessons in print?" is: A separate Arabic activity booklet with an activity set for each lesson**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "When is each part of the project checked?" is: A fault found early is cheap; a fault found at presentation is not**
**Answer: False** — As it is finished — not only at the end

**7. (Sub lesson 2) True or false: the answer to "Why check early?" is: A fault found early is cheap; a fault found at presentation is not**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What happens at the presentation?" is: The pupil's own judgement — choosing tools for a purpose**
**Answer: False** — The pupil shows what the project does and answers questions about the choices made

**9. (Sub lesson 2) True or false: the answer to "What is the project's real subject, beyond the tools?" is: The pupil's own judgement — choosing tools for a purpose**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "How does Egypt's Grade 7 book close its lessons?" is: One finished piece of work that proves the whole term's skills together**
**Answer: False** — With self-assessment — each lesson opens with 'I can…' objectives and closes with Learn-by-doing
