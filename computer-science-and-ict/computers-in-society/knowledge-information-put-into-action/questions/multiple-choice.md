# Knowledge — information put into action — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Being told how to ride a bicycle is —
a) knowledge  b) information  c) wisdom  d) data
**Answer: b) information** — actually riding it is the knowledge.

**2. (Sub lesson 1)** Knowledge includes —
a) only facts  b) skill  c) only reading  d) machines
**Answer: b) skill** — knowledge includes skill.

**3. (Sub lesson 1)** Knowledge is built from —
a) reading, doing activities, discussing and observing  b) buying books only  c) waiting  d) copying
**Answer: a) reading, doing activities, discussing and observing** — the four building ways named in the book.

**4. (Sub lesson 2)** Explicit knowledge can be — (teacher guide — evidence)
a) only felt, never written  b) put into words, diagrams and formulas and shared  c) kept in one person's hands only  d) never taught
**Answer: b) put into words, diagrams and formulas and shared** — it travels through documents and websites.

**5. (Sub lesson 2)** Tacit knowledge is passed on by — (teacher guide — evidence)
a) email alone  b) working together  c) a formula  d) a poster
**Answer: b) working together** — it lives in the knower, so it passes in shared work.
