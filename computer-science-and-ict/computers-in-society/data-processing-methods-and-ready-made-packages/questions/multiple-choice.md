# Data Processing Methods and Ready-Made Packages — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does Sudan's book name the computer at its opening?**
a) A data-processing machine  b) Takes data in, works on it by set rules, and gives out information  c) Each transaction processed as it arrives  d) A monthly payroll
**Answer: a) A data-processing machine**

**2. (Sub lesson 1) What does a data-processing machine do?**
a) Data gathered first and processed together  b) Takes data in, works on it by set rules, and gives out information  c) Processing by hand, and processing by machines that are not computers  d) A bank balance
**Answer: b) Takes data in, works on it by set rules, and gives out information**

**3. (Sub lesson 1) What is batch processing?**
a) Each transaction processed as it arrives  b) A monthly payroll  c) Data gathered first and processed together  d) Software written once and sold ready to many users
**Answer: c) Data gathered first and processed together**

**4. (Sub lesson 1) What is processing at once?**
a) Processing by hand, and processing by machines that are not computers  b) A bank balance  c) A specially written program, built for one organisation's exact needs  d) Each transaction processed as it arrives
**Answer: d) Each transaction processed as it arrives**

**5. (Sub lesson 1) Name the two older ways behind both.**
a) Processing by hand, and processing by machines that are not computers  b) A monthly payroll  c) Software written once and sold ready to many users  d) Cheaper and instant, but it fits its buyer only as well as it fits everyone
**Answer: a) Processing by hand, and processing by machines that are not computers**

**6. (Sub lesson 2) Which job suits a batch?**
a) A bank balance  b) A monthly payroll  c) A specially written program, built for one organisation's exact needs  d) A data-processing machine
**Answer: b) A monthly payroll**

**7. (Sub lesson 2) Which job cannot wait for a batch?**
a) Software written once and sold ready to many users  b) Cheaper and instant, but it fits its buyer only as well as it fits everyone  c) A bank balance  d) Takes data in, works on it by set rules, and gives out information
**Answer: c) A bank balance**

**8. (Sub lesson 2) What is a ready-made package?**
a) A specially written program, built for one organisation's exact needs  b) A data-processing machine  c) Data gathered first and processed together  d) Software written once and sold ready to many users
**Answer: d) Software written once and sold ready to many users**

**9. (Sub lesson 2) What stands against the package?**
a) A specially written program, built for one organisation's exact needs  b) Cheaper and instant, but it fits its buyer only as well as it fits everyone  c) Takes data in, works on it by set rules, and gives out information  d) Each transaction processed as it arrives
**Answer: a) A specially written program, built for one organisation's exact needs**

**10. (Sub lesson 2) What is the package's trade-off?**
a) A data-processing machine  b) Cheaper and instant, but it fits its buyer only as well as it fits everyone  c) Data gathered first and processed together  d) Processing by hand, and processing by machines that are not computers
**Answer: b) Cheaper and instant, but it fits its buyer only as well as it fits everyone**
