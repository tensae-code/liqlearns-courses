# Data Processing Methods and Ready-Made Packages — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does Sudan's book name the computer at its opening?" is: A data-processing machine**
**Answer: True**

**Answer: False** — Takes data in, works on it by set rules, and gives out information

**Answer: True**

**Answer: False** — Each transaction processed as it arrives
