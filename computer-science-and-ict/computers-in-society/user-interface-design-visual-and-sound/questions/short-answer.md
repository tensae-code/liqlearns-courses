# User Interface Design — Visual and Sound — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) Name the interface kinds.**
**Answer: Command line, menu-driven, graphical**

**2. (Sub lesson 1) By what is the right kind judged?**
**Answer: Its users can work it without fear**

**3. (Sub lesson 1) State colour's two rules.**
**Answer: Same colour for the same kind of thing; alarm colours kept rare so they still alarm**

**4. (Sub lesson 1) What must an error message be?**
**Answer: Help — naming what happened, in the user's words, with the road out**

**5. (Sub lesson 1) Which chapter teaches it?**
**Answer: Greece Grade 12 Anaptyxi Efarmogon, Chapter 12**

**6. (Sub lesson 2) Name sound's two standing jobs.**
**Answer: Confirming signals and warnings**

**7. (Sub lesson 2) What must every sound do?**
**Answer: Earn its place**

**8. (Sub lesson 2) A program that sounds at everything teaches what?**
**Answer: Its user to hear nothing**

**9. (Sub lesson 2) State the one law of sight and sound.**
**Answer: Every signal tells the user what is true now**

**10. (Sub lesson 2) The designer's craft, in one phrase.**
**Answer: Keeping that promise kindly**
