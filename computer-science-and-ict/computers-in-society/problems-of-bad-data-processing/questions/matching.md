# Problems of Bad Data Processing — matching

Match each item on the left with the one it belongs to on the right.

**1. (Sub lesson 1) Where does data processing fail?** → **At every stage it runs through — collection, keeping and processing**

**2. (Sub lesson 1) Name two collection faults.** → **Asking the wrong people, recording carelessly, losing part of the returns**

**3. (Sub lesson 1) Name two keeping faults.** → **Duplicates and contradictions; files nobody can find or read**

**4. (Sub lesson 1) Name two processing faults.** → **The wrong tool for the data, and a formula trusted without checking (also: results read as saying more than they do)**

**5. (Sub lesson 1) Why name the faults stage by stage?** → **Each stage's small fault becomes the next stage's false fact**

**6. (Sub lesson 2) What three costs does bad processing bring?** → **Decisions on wrong numbers, money and time spent twice, and trust lost**

**7. (Sub lesson 2) Which cost is slowest to heal?** → **Trust in every figure published afterwards**

**8. (Sub lesson 2) What four cares prevent it?** → **Validate at entry, keep one clean copy of the truth, check results by a second road, and match the tool to the data**

**9. (Sub lesson 2) Bad processing is rarely what?** → **Bad luck — it is skipped care**

**10. (Sub lesson 2) Where does Indonesia teach this?** → **Grade 9, Bab III A.1 — basic problems of data processing**
