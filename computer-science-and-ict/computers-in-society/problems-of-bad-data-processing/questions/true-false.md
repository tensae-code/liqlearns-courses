# Problems of Bad Data Processing — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: At every stage it runs through — collection, keeping and processing**
**Answer: True**

**2. (Sub lesson 1) True or false: At every stage it runs through — collection, keeping and processing** — as the answer to: Name two collection faults.
**Answer: False — Asking the wrong people, recording carelessly, losing part of the returns**

**3. (Sub lesson 1) True or false: Duplicates and contradictions; files nobody can find or read**
**Answer: True**

**4. (Sub lesson 1) True or false: Duplicates and contradictions; files nobody can find or read** — as the answer to: Name two processing faults.
**Answer: False — The wrong tool for the data, and a formula trusted without checking (also: results read as saying more than they do)**

**5. (Sub lesson 1) True or false: Each stage's small fault becomes the next stage's false fact**
**Answer: True**

**6. (Sub lesson 2) True or false: Each stage's small fault becomes the next stage's false fact** — as the answer to: What three costs does bad processing bring?
**Answer: False — Decisions on wrong numbers, money and time spent twice, and trust lost**

**7. (Sub lesson 2) True or false: Trust in every figure published afterwards**
**Answer: True**

**8. (Sub lesson 2) True or false: Trust in every figure published afterwards** — as the answer to: What four cares prevent it?
**Answer: False — Validate at entry, keep one clean copy of the truth, check results by a second road, and match the tool to the data**

**9. (Sub lesson 2) True or false: Bad luck — it is skipped care**
**Answer: True**

**10. (Sub lesson 2) True or false: Bad luck — it is skipped care** — as the answer to: Where does Indonesia teach this?
**Answer: False — Grade 9, Bab III A.1 — basic problems of data processing**
