# Telegram — messaging over Wi-Fi and mobile internet — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Telegram can send audio files and contacts as well as texts.
**Answer: True — audio files and contacts are both in the seven.**

**2. (Sub lesson 2)** You find a friend with Telegram before you install the application.
**Answer: False — install is step 1; finding a friend is step 4.**
