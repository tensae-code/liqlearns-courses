# Video script — Writing a Data Analysis Report

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

The work is done. Now: tell it so it can be used.
A report starts with the question.
Then the data — honestly, gaps and all.
Then the findings, with charts as evidence.
Conclusions no stronger than the proof.
Recommendations — and then, action. That is the finish.
