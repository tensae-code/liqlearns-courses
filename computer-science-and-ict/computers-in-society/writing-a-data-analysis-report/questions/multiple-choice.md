# Writing a Data Analysis Report — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) The first part of a data analysis report states —**
a) the recommendations  b) the question — what was asked and why it matters  c) the charts  d) the cleaning rules
**Answer: b) the question — what was asked and why it matters** — The reader's first question is the report's first part.

**2. (Sub lesson 1) The data section must describe collection and cleaning honestly because —**
a) teachers check it  b) the reader's trust in every later finding is built there  c) it fills pages  d) the law of reports says so
**Answer: b) the reader's trust in every later finding is built there** — Gaps stated openly make the findings believable.

**3. (Sub lesson 1) In a report, a chart is —**
a) decoration  b) evidence for a finding  c) a replacement for all words  d) an optional extra
**Answer: b) evidence for a finding** — Charts persuade because they show.

**4. (Sub lesson 2) A conclusion should be —**
a) as strong as possible  b) exactly as strong as the evidence allows, and no further  c) written before the findings  d) kept secret
**Answer: b) exactly as strong as the evidence allows, and no further** — One term's data supports one term's conclusion.

**5. (Sub lesson 2) The data-processing process is completed when the report's recommendations are —**
a) printed  b) applied — discussed, decided on and acted on  c) filed  d) translated
**Answer: b) applied — discussed, decided on and acted on** — Application is the last stage of the general process.
