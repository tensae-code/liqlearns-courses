# Writing a Data Analysis Report — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) A report is written for its author, as a diary of the work.**
**Answer: False** — It is written for its reader and the reader's questions.

**2. (Sub lesson 2) 'Mathematics fell 12 points in Grade 9' is a better report sentence than 'some values decreased'.**
**Answer: True** — Numbers tied to their meaning; vague words persuade nobody.

**3. (Sub lesson 2) A finding the data only half-supports should be written as a half-finding.**
**Answer: True** — Honesty is a writing rule, not only a data rule.
