# Writing a Data Analysis Report — short answer

Answer each question in a few sentences.

**1. (Sub lesson 1) A report's data covers only the second term, but its conclusion says 'our school's results are falling every year'. What is wrong, and how should the sentence be written?**
**Answer:** The conclusion is stronger than the evidence: one term's data cannot speak about every year. Written honestly: 'In the second term, results fell in the subjects measured' — with a recommendation to gather earlier terms' data before claiming a trend.

**2. (Sub lesson 2) Name the five parts of a data analysis report and give the reader's question that each part answers.**
**Answer:** Question — 'what were you asked, and why does it matter?' Data — 'where did the data come from, and can I trust it?' Findings — 'what did you find?' Conclusions — 'what does it mean?' Recommendations — 'what should we do?'
