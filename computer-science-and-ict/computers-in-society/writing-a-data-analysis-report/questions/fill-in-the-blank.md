# Writing a Data Analysis Report — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 1) The report's skeleton runs: question, data, ____, conclusions, recommendations.**
**Answer: findings** — Findings carry the charts as evidence.

**2. (Sub lesson 2) A report is written for its ____, not its author.**
**Answer: reader** — Plain words; the question answered on the first page.

**3. (Sub lesson 1) The ____ section tells where the data came from and how it was cleaned.**
**Answer: data** — Trust is built on this honesty.
