# Hands-on — Writing a Data Analysis Report

The lesson with your hands and your feet, not only your eyes.

## Build the skeleton
Using the analysis lesson's findings (or the teacher's), write the report's five headings and, under each, exactly the material that belongs there — one or two lines each. Check: could a stranger follow it?

## Rewrite for the reader
Take these weak findings and rewrite each as a clear report sentence with numbers tied to meaning: 'some values decreased', 'attendance was not good', 'the chart shows things about marks'.
