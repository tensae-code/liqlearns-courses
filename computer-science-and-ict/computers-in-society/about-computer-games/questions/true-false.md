# About Computer Games — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a computer game?" is: A program made for playing**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "How does the player act in a game?" is: At once — the score changes, the figure moves, the level ends**
**Answer: False** — Through the keyboard, mouse or joystick

**3. (Sub lesson 1) True or false: the answer to "How does the game answer the player?" is: At once — the score changes, the figure moves, the level ends**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Where does the games lesson sit in Uzbekistan's Grade 5 book?" is: Learn to name what a game is**
**Answer: False** — Near the end of the year, after Paint

**5. (Sub lesson 1) True or false: the answer to "What must a pupil do before playing, in the book's order?" is: Learn to name what a game is**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Name two kinds of computer games." is: Speed, memory, attention and planning**
**Answer: False** — Races and adventures; puzzles and logic games (any two kinds)

**7. (Sub lesson 2) True or false: the answer to "What can a game train?" is: Speed, memory, attention and planning**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What care does a player keep?" is: A tool first and a toy second**
**Answer: False** — Sits well, rests the eyes, and stops at the agreed time

**9. (Sub lesson 2) True or false: the answer to "In the book's view, what is the computer first?" is: A tool first and a toy second**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "How does a pupil play a game 'as a lesson'?" is: A program made for playing**
**Answer: False** — By naming its kind and what it trains
