# Institutional Communication With Technology — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Communication inside the institution
Sub lesson 1 questions from the type files. Pass mark: An organised body like a school, office or ministry; Notices, orders and reports (also records); One true version; It comes through the institution's channel, from a named sender, and is kept as a record; The institution's rules and formality.

## Sub lesson 2 — Communication with the public
Sub lesson 2 questions from the type files. Pass mark: Announcements and service information (also answers, emergency warnings); Institutions across the region communicate the same way; The facts; One official source; Answer back — and be answered.
