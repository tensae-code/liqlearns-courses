# Institutional Communication With Technology — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: An organised body like a school, office or ministry**
**Answer: True**

**2. (Sub lesson 1) True or false: An organised body like a school, office or ministry** — as the answer to: Name three things official communication carries.
**Answer: False — Notices, orders and reports (also records)**

**3. (Sub lesson 1) True or false: One true version**
**Answer: True**

**4. (Sub lesson 1) True or false: One true version** — as the answer to: When is a digital message official?
**Answer: False — It comes through the institution's channel, from a named sender, and is kept as a record**

**5. (Sub lesson 1) True or false: The institution's rules and formality**
