# Monitoring and Evaluating a Project — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Monitoring — the plan, watched while there is time
Sub lesson 1 questions from the type files. Pass mark: Watching a running project against its plan while there is still time to fix it; Progress against milestones, spending against planned resources, and faults found while small; A wish; Regular, short and recorded; Report the milestone as it is, not as it was hoped.

## Sub lesson 2 — Evaluation — the finished project, judged whole
Sub lesson 2 questions from the type files. Pass mark: Whether the project delivered its scope, at the planned time and cost, and whether the result works for its users; Looking backward for the future — what went well, where the plan was wrong, what the next plan must change; Attention during, judgement after; The project's documents, kept from the first day; Grade 10 SMK Semester 2, Bab 3 B — monitoring and evaluation of projects.
