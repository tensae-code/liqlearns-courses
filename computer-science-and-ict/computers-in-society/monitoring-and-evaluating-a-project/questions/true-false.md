# Monitoring and Evaluating a Project — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Watching a running project against its plan while there is still time to fix it**
**Answer: True**

**2. (Sub lesson 1) True or false: Watching a running project against its plan while there is still time to fix it** — as the answer to: What three comparisons does monitoring make?
**Answer: False — Progress against milestones, spending against planned resources, and faults found while small**

**3. (Sub lesson 1) True or false: A wish**
**Answer: True**

**4. (Sub lesson 1) True or false: A wish** — as the answer to: What rhythm does monitoring keep?
**Answer: False — Regular, short and recorded**

**5. (Sub lesson 1) True or false: Report the milestone as it is, not as it was hoped**
**Answer: True**

**6. (Sub lesson 2) True or false: Report the milestone as it is, not as it was hoped** — as the answer to: What does evaluation judge?
**Answer: False — Whether the project delivered its scope, at the planned time and cost, and whether the result works for its users**

**7. (Sub lesson 2) True or false: Looking backward for the future — what went well, where the plan was wrong, what the next plan must change**
**Answer: True**

**8. (Sub lesson 2) True or false: Looking backward for the future — what went well, where the plan was wrong, what the next plan must change** — as the answer to: Monitoring and evaluation are one habit at two moments — which?
**Answer: False — Attention during, judgement after**

**9. (Sub lesson 2) True or false: The project's documents, kept from the first day**
**Answer: True**

**10. (Sub lesson 2) True or false: The project's documents, kept from the first day** — as the answer to: Where does Indonesia teach this?
**Answer: False — Grade 10 SMK Semester 2, Bab 3 B — monitoring and evaluation of projects**
