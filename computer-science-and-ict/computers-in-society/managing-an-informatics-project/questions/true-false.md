# Managing an Informatics Project — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: A bounded piece of work with a goal**
**Answer: True**

**2. (Sub lesson 1) True or false: A bounded piece of work with a goal** — as the answer to: What is project management?

**3. (Sub lesson 1) True or false: What will be made, who does each part, when each part lands, and with what resources**
**Answer: True**

**5. (Sub lesson 1) True or false: Unnamed work is undone work — a part with no owner has no finisher**
**Answer: True**

**6. (Sub lesson 2) True or false: Unnamed work is undone work — a part with no owner has no finisher** — as the answer to: What are milestones?

**7. (Sub lesson 2) True or false: A missing device, one person who alone knows a part, and data that has not arrived**
