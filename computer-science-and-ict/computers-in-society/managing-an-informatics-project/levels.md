# Managing an Informatics Project — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — The plan — what, who, when, with what
Sub lesson 1 questions from the type files. Pass mark: A bounded piece of work with a goal; What keeps the bound real — the work planned, tracked and delivered as intended; What will be made, who does each part, when each part lands, and with what resources; What will be made — and what is NOT included; Unnamed work is undone work — a part with no owner has no finisher.

## Sub lesson 2 — Running the plan — risks, changes and the record
Sub lesson 2 questions from the type files. Pass mark: The schedule's fixed points by which progress is judged; A missing device, one person who alone knows a part, and data that has not arrived; As a change to time or resources — recorded and agreed, never silently absorbed; Its memory and its proof; Grade 10 SMK Semester 2, Bab 3 A — informatics project management.
