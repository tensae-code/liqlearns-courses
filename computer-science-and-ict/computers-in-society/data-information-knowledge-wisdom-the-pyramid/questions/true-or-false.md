# Data, information, knowledge, wisdom — the pyramid — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Value rises as you climb the pyramid.
**Answer: True** — low at the base, very high at the tip.

**2. (Sub lesson 1)** Wisdom uses only logical thinking.
**Answer: False** — it includes intuitive, logical, creative and collective thinking.

**3. (Sub lesson 2)** Data's time direction, in the guide's chart, is prediction (teacher guide — evidence).
**Answer: False** — data looks to the past; prediction belongs to the higher layers.
