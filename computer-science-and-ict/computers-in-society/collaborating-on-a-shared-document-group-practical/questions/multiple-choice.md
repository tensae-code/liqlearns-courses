# Collaborating on a shared document — group practical — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The book's group size for the practical is —
a) three  b) five  c) eight  d) the whole class
**Answer: b) five** — form a group of five and name it.

**2. (Sub lesson 1)** The summary to write is —
a) five pages  b) a half-page on the benefits of collaboration tools for online learning and group work  c) a poem  d) a timetable
**Answer: b) a half-page on the benefits of collaboration tools for online learning and group work** — the set text and length.

**3. (Sub lesson 1)** The online document is named —
a) with the teacher's name  b) with the group name  c) with the date only  d) unnamed
**Answer: b) with the group name** — the naming rule.

**4. (Sub lesson 2)** During the meeting, the group changes the document —
a) the next day  b) by screen sharing, from wherever they are  c) by printing it  d) not at all
**Answer: b) by screen sharing, from wherever they are** — live editing is the heart.

**5. (Sub lesson 2)** The practical ends with —
a) deleting the document  b) discussing how the tools improve learning and teamwork, and sharing the experience with the class  c) a test  d) silence
**Answer: b) discussing how the tools improve learning and teamwork, and sharing the experience with the class** — the closing steps.
