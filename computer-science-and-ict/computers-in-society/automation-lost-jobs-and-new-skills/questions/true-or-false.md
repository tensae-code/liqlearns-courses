# Automation, lost jobs and new skills — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Automation only destroys jobs and creates none.
**Answer: False** — over time it creates about as many as it destroys.

**2. (Sub lesson 2)** The skills the market needs stay the same as jobs change.
**Answer: False** — the skills needed keep changing.

**3. (Sub lesson 2)** Digital literacy is now mandatory for success in the digital ecosystem, whatever a person's age or place.
**Answer: True** — the guide's balancing point (teacher guide — evidence).
