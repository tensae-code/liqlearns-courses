# Giving Peer Feedback on a Programming Project — true or false

Say whether each statement is true or false.

**1. Feedback is given for each member of the group, not only the leader.**
**Answer: True** — Every member gets the three moves.

**2. 'It was fine' is useful feedback.**
**Answer: False** — Nobody can act on it; feedback must be specific.

**3. The form is filled in before the project starts.**
**Answer: False** — It is used after the group projects, looking back at real work.
