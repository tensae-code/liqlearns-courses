# Computers in Manufacturing — CAD and CIM — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does CAD stand for?" is: Computer-aided design**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is CAD?" is: Computer-aided design**
**Answer: False** — Drawing and designing a product on a computer

**3. (Sub lesson 1) True or false: the answer to "Name one thing a designer can do to a CAD drawing." is: Turn it, zoom it or change it on screen**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does a mistake cost in CAD?" is: Computer-aided design**
**Answer: False** — An edit, not a new model

**5. (Sub lesson 1) True or false: the answer to "Where does Rwanda's guide file CAD?" is: Under the application areas of computers (teacher guide — evidence)**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does CIM stand for?" is: The whole factory — design, machines and stock counts**
**Answer: False** — Computer-integrated manufacturing

**7. (Sub lesson 2) True or false: the answer to "What is linked in CIM?" is: The whole factory — design, machines and stock counts**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What can drive the machine in CIM?" is: Computer-integrated manufacturing**
**Answer: False** — The design file itself

**9. (Sub lesson 2) True or false: the answer to "Why does the product match the drawing in CIM?" is: Because the design file drives the machine**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is the difference between CAD and CIM?" is: Computer-integrated manufacturing**
**Answer: False** — CAD designs the thing; CIM organises making it start to finish
