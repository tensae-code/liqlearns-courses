# The five components of an information system — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** People in a system are the trained specialists who run the technology and decide what new data to capture.
**Answer: True** — the book's people component.

**2. (Sub lesson 1)** Hardware includes the operating system and the antivirus.
**Answer: False** — those are software; hardware is the devices.

**3. (Sub lesson 2)** An attendance register is information the school generates (teacher guide — evidence).
**Answer: False** — the register is captured data; the absenteeism summary is the generated information.
