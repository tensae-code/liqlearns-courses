# Trade secrets — valuable information kept confidential — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A trade secret must be published to be protected.
**Answer: False** — confidentiality itself is the protection.

**2. (Sub lesson 1)** Source code can be a trade secret.
**Answer: True** — one of the named examples.

**3. (Sub lesson 2)** Winning a customer fairly, without touching their supplier's secrets, is honest commercial practice.
**Answer: True** — the standard allows fair competition.
