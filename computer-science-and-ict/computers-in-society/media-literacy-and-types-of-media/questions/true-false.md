# Media Literacy and Types of Media — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What are expression media?" is: The forms a message is shaped in — words, pictures, sound, video**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What are transmission media?" is: The ways a message is kept — files, discs, archives**
**Answer: False** — The ways a message travels — network, broadcast, carried print

**3. (Sub lesson 1) True or false: the answer to "What are recording media?" is: The ways a message is kept — files, discs, archives**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Why sort media into families?" is: All three — expressed, transmitted and recorded**
**Answer: False** — Each family can fail and mislead in its own way, so the reader checks the right one

**5. (Sub lesson 1) True or false: the answer to "How many families does one message usually use?" is: All three — expressed, transmitted and recorded**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What is media literacy?" is: That it was made — every choice in it was decided by someone**
**Answer: False** — Judging what media bring — who made it, why, what was left out, and whether it can be checked

**7. (Sub lesson 2) True or false: the answer to "What does the literate reader remember about every message?" is: That it was made — every choice in it was decided by someone**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What question tests an expression choice?" is: In the opening section, with data, information and knowledge — before ethics and security**
**Answer: False** — What would the same event look like expressed differently?

**9. (Sub lesson 2) True or false: the answer to "Where does Egypt place media literacy in the Grade 10 book?" is: In the opening section, with data, information and knowledge — before ethics and security**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Why does media literacy come first?" is: The forms a message is shaped in — words, pictures, sound, video**
**Answer: False** — Later lessons assume it — information cannot be protected or used honestly if messages cannot be judged
