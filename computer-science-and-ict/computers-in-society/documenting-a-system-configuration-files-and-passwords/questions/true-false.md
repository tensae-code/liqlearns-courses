# Documenting a System — Configuration Files and Passwords — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does system documentation record?" is: The system's configuration — its settings and set-up**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does a configuration file hold?" is: Who may use or change something**
**Answer: False** — Settings the system uses

**3. (Sub lesson 1) True or false: the answer to "Why document a printer share?" is: So others know it is shared and how to reach it**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What do permissions state?" is: Whenever the configuration changes**
**Answer: False** — Who may use or change something

**5. (Sub lesson 1) True or false: the answer to "What does server documentation include?" is: What the server provides and its settings**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "When should documentation be updated?" is: Delays and mistakes when fixing faults**
**Answer: False** — Whenever the configuration changes

**7. (Sub lesson 2) True or false: the answer to "Who uses system documentation?" is: Administrators and support staff**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What can a missing record cause?" is: System administration — a core duty of it**
**Answer: False** — Delays and mistakes when fixing faults

**9. (Sub lesson 2) True or false: the answer to "How must passwords in documentation be kept?" is: Protected — not written openly for all**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Documentation is part of which job?" is: Settings the system uses**
**Answer: False** — System administration — a core duty of it
