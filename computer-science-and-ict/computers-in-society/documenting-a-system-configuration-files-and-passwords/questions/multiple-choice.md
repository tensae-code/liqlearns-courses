# Documenting a System — Configuration Files and Passwords — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What does system documentation record?**
a) The system's configuration — its settings and set-up  b) Settings the system uses  c) So others know it is shared and how to reach it  d) Who may use or change something
**Answer: a) The system's configuration — its settings and set-up**

**2. (Sub lesson 1) What does a configuration file hold?**
a) So others know it is shared and how to reach it  b) Settings the system uses  c) Who may use or change something  d) What the server provides and its settings
**Answer: b) Settings the system uses**

**3. (Sub lesson 1) Why document a printer share?**
a) Who may use or change something  b) What the server provides and its settings  c) So others know it is shared and how to reach it  d) Whenever the configuration changes
**Answer: c) So others know it is shared and how to reach it**

**4. (Sub lesson 1) What do permissions state?**
a) What the server provides and its settings  b) Whenever the configuration changes  c) Administrators and support staff  d) Who may use or change something
**Answer: d) Who may use or change something**

**5. (Sub lesson 1) What does server documentation include?**
a) What the server provides and its settings  b) Whenever the configuration changes  c) Administrators and support staff  d) Delays and mistakes when fixing faults
**Answer: a) What the server provides and its settings**

**6. (Sub lesson 2) When should documentation be updated?**
a) Administrators and support staff  b) Whenever the configuration changes  c) Delays and mistakes when fixing faults  d) Protected — not written openly for all
**Answer: b) Whenever the configuration changes**

**7. (Sub lesson 2) Who uses system documentation?**
a) Delays and mistakes when fixing faults  b) Protected — not written openly for all  c) Administrators and support staff  d) System administration — a core duty of it
**Answer: c) Administrators and support staff**

**8. (Sub lesson 2) What can a missing record cause?**
a) Protected — not written openly for all  b) System administration — a core duty of it  c) The system's configuration — its settings and set-up  d) Delays and mistakes when fixing faults
**Answer: d) Delays and mistakes when fixing faults**

**9. (Sub lesson 2) How must passwords in documentation be kept?**
a) Protected — not written openly for all  b) System administration — a core duty of it  c) The system's configuration — its settings and set-up  d) Settings the system uses
**Answer: a) Protected — not written openly for all**

**10. (Sub lesson 2) Documentation is part of which job?**
a) The system's configuration — its settings and set-up  b) System administration — a core duty of it  c) Settings the system uses  d) So others know it is shared and how to reach it
**Answer: b) System administration — a core duty of it**
