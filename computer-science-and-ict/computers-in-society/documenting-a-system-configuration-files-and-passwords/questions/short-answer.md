# Documenting a System — Configuration Files and Passwords — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What does system documentation record?**
**Answer: The system's configuration — its settings and set-up**

**2. (Sub lesson 1) What does a configuration file hold?**
**Answer: Settings the system uses**

**3. (Sub lesson 1) Why document a printer share?**
**Answer: So others know it is shared and how to reach it**

**4. (Sub lesson 1) What do permissions state?**
**Answer: Who may use or change something**

**5. (Sub lesson 1) What does server documentation include?**
**Answer: What the server provides and its settings**

**6. (Sub lesson 2) When should documentation be updated?**
**Answer: Whenever the configuration changes**

**7. (Sub lesson 2) Who uses system documentation?**
**Answer: Administrators and support staff**

**8. (Sub lesson 2) What can a missing record cause?**
**Answer: Delays and mistakes when fixing faults**

**9. (Sub lesson 2) How must passwords in documentation be kept?**
**Answer: Protected — not written openly for all**

**10. (Sub lesson 2) Documentation is part of which job?**
**Answer: System administration — a core duty of it**
