# Plagiarism — other people's work is not yours — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Schools now use checking tools for originality.
**Answer: True** — named in the book.

**2. (Sub lesson 1)** Easy copy-and-paste has made plagiarism a smaller problem.
**Answer: False** — it has made it a major problem.

**3. (Sub lesson 2)** Paraphrasing a source removes the need to credit it.
**Answer: False** — credit the author in text and in the reference list (teacher guide — evidence).
