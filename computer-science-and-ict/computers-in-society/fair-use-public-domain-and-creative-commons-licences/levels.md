# Fair Use, Public Domain and Creative Commons Licences — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Fair use and the public domain
Sub lesson 1 questions from the type files. Pass mark: Using a protected work without permission for limited honest purposes, judged by amount, purpose and harm to the owner's market; Quotation in study or criticism (or classroom use, or news); Works no longer protected — anyone may use them wholly and freely; Its term ended, or it was never protected (laws, facts); Fair use borrows a living work carefully; the public domain is complete freedom.

## Sub lesson 2 — Creative Commons — the creator opens the door
Sub lesson 2 questions from the type files. Pass mark: The creator's standing permission, written in advance, stating what all may do with the work; BY credit, NC no commercial use, ND no derivatives, SA share-alike; No — the licence opens use, not ownership; What may I do with this work?; The wall (ask), fair use, public domain, Creative Commons.
