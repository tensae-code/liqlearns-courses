# Fair Use, Public Domain and Creative Commons Licences — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: Using a protected work without permission for limited honest purposes, judged by amount, purpose and harm to the owner's market**
**Answer: True**

**2. (Sub lesson 1) True or false: Works no longer protected — anyone may use them wholly and freely** — as the answer to: Name an honest purpose.
**Answer: False — Quotation in study or criticism (or classroom use, or news)**

**3. (Sub lesson 1) True or false: Works no longer protected — anyone may use them wholly and freely**
**Answer: True**

**4. (Sub lesson 1) True or false: Fair use borrows a living work carefully; the public domain is complete freedom** — as the answer to: How does a work enter it?
**Answer: False — Its term ended, or it was never protected (laws, facts)**

**5. (Sub lesson 1) True or false: Fair use borrows a living work carefully; the public domain is complete freedom**
**Answer: True**

**6. (Sub lesson 2) True or false: BY credit, NC no commercial use, ND no derivatives, SA share-alike** — as the answer to: What is a Creative Commons licence?
**Answer: False — The creator's standing permission, written in advance, stating what all may do with the work**

**7. (Sub lesson 2) True or false: BY credit, NC no commercial use, ND no derivatives, SA share-alike**
**Answer: True**

**8. (Sub lesson 2) True or false: What may I do with this work?** — as the answer to: Does the work stop being the creator's?
**Answer: False — No — the licence opens use, not ownership**

**9. (Sub lesson 2) True or false: What may I do with this work?**
**Answer: True**

**10. (Sub lesson 2) True or false: Using a protected work without permission for limited honest purposes, judged by amount, purpose and harm to the owner's market** — as the answer to: The four answers are what?
**Answer: False — The wall (ask), fair use, public domain, Creative Commons**
