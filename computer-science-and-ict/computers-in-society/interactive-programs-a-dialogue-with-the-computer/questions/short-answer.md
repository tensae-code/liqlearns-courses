# Interactive Programs — a Dialogue with the Computer — short answer

Answer in a short sentence of your own.

**1. (Sub lesson 1) What makes a program interactive?**
**Answer: The user and the program take turns, and the program acts depending on the user's input**

**2. (Sub lesson 1) Why can the same interactive program go many ways?**
**Answer: Because the user's answers steer it**

**3. (Sub lesson 1) What does an interactive program wait for?**
**Answer: The user's input**

**4. (Sub lesson 1) What is the deepest difference from a television or a printed book?**
**Answer: Those give everyone the same thing in the same order; an interactive program responds to you**

**5. (Sub lesson 1) Where does Afghanistan's book place this lesson?**
**Answer: Early in Grade 11, before the year's program work**

**6. (Sub lesson 2) Name the dialogue shape in a quiz program.**
**Answer: It asks a question and marks your answer**

**7. (Sub lesson 2) What is the first rule of a good interactive program?**
**Answer: Ask clearly, so the user knows what answer is wanted**

**8. (Sub lesson 2) What should a program do with an answer?**
**Answer: Accept it kindly, checking it makes sense**

**9. (Sub lesson 2) What must a program always show?**
**Answer: What happened because of the user's answer**

**10. (Sub lesson 2) What is an interactive program that ignores its user?**
**Answer: A broken conversation**
