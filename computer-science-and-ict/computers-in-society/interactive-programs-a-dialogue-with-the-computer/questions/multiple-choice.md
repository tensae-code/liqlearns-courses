# Interactive Programs — a Dialogue with the Computer — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) What makes a program interactive?**
a) The user and the program take turns, and the program acts depending on the user's input  b) Because the user's answers steer it  c) The user's input  d) Those give everyone the same thing in the same order; an interactive program responds to you
**Answer: a) The user and the program take turns, and the program acts depending on the user's input**

**2. (Sub lesson 1) Why can the same interactive program go many ways?**
a) The user's input  b) Because the user's answers steer it  c) Those give everyone the same thing in the same order; an interactive program responds to you  d) Early in Grade 11, before the year's program work
**Answer: b) Because the user's answers steer it**

**3. (Sub lesson 1) What does an interactive program wait for?**
a) Those give everyone the same thing in the same order; an interactive program responds to you  b) Early in Grade 11, before the year's program work  c) The user's input  d) It asks a question and marks your answer
**Answer: c) The user's input**

**4. (Sub lesson 1) What is the deepest difference from a television or a printed book?**
a) Early in Grade 11, before the year's program work  b) It asks a question and marks your answer  c) Ask clearly, so the user knows what answer is wanted  d) Those give everyone the same thing in the same order; an interactive program responds to you

**5. (Sub lesson 1) Where does Afghanistan's book place this lesson?**

**6. (Sub lesson 2) Name the dialogue shape in a quiz program.**
a) Ask clearly, so the user knows what answer is wanted  b) It asks a question and marks your answer  c) Accept it kindly, checking it makes sense  d) What happened because of the user's answer

**7. (Sub lesson 2) What is the first rule of a good interactive program?**

**Answer: c) Ask clearly, so the user knows what answer is wanted**

**8. (Sub lesson 2) What should a program do with an answer?**

**9. (Sub lesson 2) What must a program always show?**
