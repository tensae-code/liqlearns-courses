# Video script — Interactive Programs — a Dialogue with the Computer

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A program is **interactive** when the user and the program take turns: the program shows or asks something, **waits for the user's input**, and then acts *depending on that input*.
The same program can go many different ways on different runs, because the user's answers steer it.
Afghanistan's Grade 11 book gives this idea a whole lesson early, before the year's program work, because it names the deepest difference between a computer and a television or a printed book: those give everyone the same thing in the same order, while an interactive program responds to *you*.
The **dialogue** shape is everywhere once you look: a quiz program asks a question and marks *your* answer; a form asks for your name and uses it; a menu offers choices and follows the one you pick; a game world reacts to your moves.
Good interactive programs follow the dialogue's rules: ask clearly, so the user knows what answer is wanted; accept the answer kindly, checking it makes sense; and always show what happened because of it.
An interactive program that ignores its user is a broken conversation — the book's lesson is that the response is the program's half of the talk, and it must be worthy of the answer it was given.
