# How Information Flows in an Organisation — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does downward flow carry?" is: The decisions — plans, targets and instructions**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does each level do to the direction it receives?" is: The results — detail gathered and summarised, level by level**
**Answer: False** — Turns it into orders the level below can act on

**3. (Sub lesson 1) True or false: the answer to "What does upward flow carry?" is: The results — detail gathered and summarised, level by level**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Trace one fact upward at Viti." is: Orders go down whole and are divided; results come up divided and are joined**
**Answer: False** — Chairs made today → a line in a quarterly report → a fact in a director's decision

**5. (Sub lesson 1) True or false: the answer to "What is Fiji's symmetry of the vertical flow?" is: Orders go down whole and are divided; results come up divided and are joined**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does horizontal flow connect?" is: Without it each function decides from its own picture alone**
**Answer: False** — Functions at the same level — production, marketing, accounting telling each other what is true

**7. (Sub lesson 2) True or false: the answer to "Why is horizontal flow needed?" is: Without it each function decides from its own picture alone**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is the informal flow?" is: Listen to it, but never mistake it for the record**
**Answer: False** — Talk and messages — faster than every pipe, and not always true

**9. (Sub lesson 2) True or false: the answer to "How should a wise manager treat the informal flow?" is: Listen to it, but never mistake it for the record**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is this lesson's governing image?" is: The decisions — plans, targets and instructions**
**Answer: False** — Information moving like water in a building — up, down and across, by pipes someone built
