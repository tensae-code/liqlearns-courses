# An information system at work — HRIS — short answer

Answer in a short sentence.

**1. (Sub lesson 1)** Name the five kinds of data an HRIS stores.
**Answer: Recruitment data, demographic details, performance records, training records, and pay and benefits.**

**2. (Sub lesson 2)** Name the four HRIS software kinds.
**Answer: Recruitment; time and attendance; performance management; training and development.**
