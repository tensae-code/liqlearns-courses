# An information system at work — HRIS — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 2)** The book says information systems are now strategic assets, not just report machines.
**Answer: True** — the section's closing turn.

**2. (Sub lesson 2)** Training and development is not part of an HRIS.
**Answer: False** — it is the fourth software kind.

**3. (Sub lesson 1)** An HRIS holds data about products a company sells.
**Answer: False** — it holds employee data.
