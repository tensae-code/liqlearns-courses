# Lesson plan — An information system at work — HRIS

**Course:** Computer Science and ICT · **Title:** Computers in Society · **Lesson:** An information system at work — HRIS
**Place in the curriculum:** Title 14 — Computers in Society of the Computer Science and ICT ladder (TITLES.md); Ethiopia Grade 11, Unit 1 — Information Systems and Its Applications. The ladder is the recommended order, never a forced one.
**The one thing this lesson teaches:** a Human Resource Information System stores employee data and runs recruitment, attendance, performance and training software — systems are now strategic assets, not just report machines.
**This lesson's own level:** it stands on the five-components lesson just before it (recommended first, never forced): HRIS is those five components at work in one office.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide. GIFs come first where a thing must be shown moving — a GIF here is 2 seconds, looping.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **What an HRIS stores** — employee data: recruitment, demographics, performance, training, pay and benefits — on servers and networked computers.
2. **The HRIS software at work** — the four software kinds — recruitment, time and attendance, performance management, training — and the closing idea: systems as strategic assets.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: the lesson named in this plan's level line, inside this same title. Recommended, never forced. A learner can land here directly; the lesson stands alone.

## What the learner can do when it ends
1. List the five kinds of employee data an HRIS stores.
2. Name the four HRIS software kinds and what each does.
3. State the book's closing point: systems are strategic assets, not just report machines.

## If the learner is stuck
Mixes stored data with software → the card test: data is what is held (CVs, pay); software is what works on it (sorting applications, tying pay to hours). Thinks performance software only punishes → its evidence also keeps and promotes: keeping, promoting, moving or ending.
