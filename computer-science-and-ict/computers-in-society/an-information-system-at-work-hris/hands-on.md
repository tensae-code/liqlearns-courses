# Hands-on — An information system at work — HRIS

The lesson with your hands, not only your eyes.

## Build the record
On paper, build one employee record with the five stored kinds as headed sections. Invent a worker and fill it. Then answer three questions from the card alone — that answering is the system working.

## Sort the applications
Write six mini-applications on slips. Set one rule (a qualification, say) and sort them as recruitment software would. Note what the software still cannot judge — that gap is why people stay a component.
