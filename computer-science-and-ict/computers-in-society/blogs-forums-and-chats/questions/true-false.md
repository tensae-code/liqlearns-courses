# Blogs, Forums and Chats — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a blog?" is: One author's page of dated entries, newest first, with readers' comments under each entry.**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Who leads a blog?" is: Blog — publish and gather comments; forum — ask, answer and keep; chat — talk now.**
**Answer: False** — The author — the talk hangs on the author's entries.

**3. (Sub lesson 1) True or false: the answer to "What is a forum?" is: A lasting discussion where members open topics and others reply, sorted and searchable.**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What is a forum's strength?" is: Write as if the whole world may read it.**
**Answer: False** — A question asked once keeps its answers where the next asker can find them.

**5. (Sub lesson 1) True or false: the answer to "What is a chat?" is: Written conversation in real time, flowing past like speech.**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "How do the three forms divide the jobs?" is: In comments under each entry.**
**Answer: False** — Blog — publish and gather comments; forum — ask, answer and keep; chat — talk now.

**7. (Sub lesson 2) True or false: the answer to "Are these forms private writing?" is: No — they are public or semi-public, and messages can be copied and kept.**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What is the care rule for all three?" is: The author — the talk hangs on the author's entries.**
**Answer: False** — Write as if the whole world may read it.

**9. (Sub lesson 2) True or false: the answer to "What are forum replies grouped under?" is: Topics, also called threads.**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "Where do a blog's readers answer?" is: A question asked once keeps its answers where the next asker can find them.**
**Answer: False** — In comments under each entry.
