# Security breaches, liability and reporting them — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Only databases create liability; blogs and messages create none.
**Answer: False** — blogs and instant messaging add further liability.

**2. (Sub lesson 2)** How far each platform cooperates with monitoring is always clear from its privacy policy.
**Answer: False** — the guide says it is not always clear (teacher guide — evidence).

**3. (Sub lesson 2)** Law-enforcement and security bodies do monitor social media for unlawful activity and in investigations.
**Answer: True** — the guide states it plainly (teacher guide — evidence).
