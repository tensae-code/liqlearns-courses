# Using Information to Solve Problems — sub lessons and depth

This file is the lesson's depth record, expressed as its SUB LESSONS. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — A problem is a gap in information
Sub lesson 1 questions from the type files. Pass mark: A gap — some things are known, others are needed, and the answer sits across the gap; State the problem exactly, in your own words; What information is missing — what must be found out first?; It gives the search a target — it is half the solution; That they do not yet understand the problem.

## Sub lesson 2 — Find it, judge it, use it — then solve
Sub lesson 2 questions from the type files. Pass mark: Find the information, judge it, use it, then solve and check; In books, on the Internet, by asking people, and by measuring; Is it trustworthy, is it current, and is it really about this problem?; That the answer really answers the problem that was stated; The judging of the information and the using of it.
