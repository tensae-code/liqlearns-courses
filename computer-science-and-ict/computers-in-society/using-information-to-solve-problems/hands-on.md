# Hands-on — Using Information to Solve Problems

The lesson with your hands and your feet, not only your eyes.

## Task one
**Name the gap** — Take a real problem — planning a class trip's cost. State it exactly, then list the information you are missing before you can solve it.

## Task two
**Run the four steps** — Solve that same problem by the four steps: find, judge, use, solve-and-check. Write one line for each step.
