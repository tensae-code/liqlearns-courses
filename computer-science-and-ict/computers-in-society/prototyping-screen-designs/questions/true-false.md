# Prototyping Screen Designs — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What is a screen prototype?" is: A working rough version of the designed screens**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "With what is it built in Malaysia's course?" is: The database, the full workings, and the polish**
**Answer: False** — Java in NetBeans

**3. (Sub lesson 1) True or false: the answer to "What is deliberately left out?" is: The database, the full workings, and the polish**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What must the prototype keep?" is: The interaction**
**Answer: False** — Everything the interaction depends on — layout, order, wording, what happens on each click

**5. (Sub lesson 1) True or false: the answer to "What does the prototype exist to test?" is: The interaction**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Why is roughness a virtue?" is: Before building the system behind the screens**
**Answer: False** — Built fast, it can be changed in minutes when evaluation condemns a screen

**7. (Sub lesson 2) True or false: the answer to "When is the prototype made?" is: Before building the system behind the screens**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "Moving a button costs a drag on a prototype, and what in a finished system?" is: The loop — users try it, findings land, it changes, users try again**
**Answer: False** — A rebuild

**9. (Sub lesson 2) True or false: the answer to "Into what is the prototype thrown?" is: The loop — users try it, findings land, it changes, users try again**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What is a prototype nobody may criticise?" is: A working rough version of the designed screens**
