# Video script — Developing an Information System — the Four Stages

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A new system is not built in one jump.
Stage one: planning. Do we need it? Can we do it?
Stage two: analysis. What exactly must it do?
Stage three: design. Draw the blueprint — how it will do it.
Stage four: implementation. Build it. Test it. Change over.
Four stages. Always in that order.
