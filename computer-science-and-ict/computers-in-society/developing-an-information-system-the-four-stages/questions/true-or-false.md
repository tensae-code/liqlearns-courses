# Developing an Information System — the Four Stages — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Design comes before analysis in the four stages.**
**Answer: False** — Analysis (what) must come before design (how).

**2. (Sub lesson 1) Planning can end with the decision 'not yet'.**
**Answer: True** — If the system is not feasible, planning's honest answer is to stop or wait.

**3. (Sub lesson 2) Training users is part of implementation.**
**Answer: True** — Changeover includes moving data and training people.
