# Developing an Information System — the Four Stages — short answer

Answer each question in a few sentences.

**1. (Sub lesson 1) Why is it a mistake to start writing programs before analysis is finished?**
**Answer:** Because nobody has fixed what the system must do; the programs would be built on guesses, and changes discovered later — when users state their real needs — are far more expensive to make in code than on paper.

**2. (Sub lesson 2) Walk a school attendance system through the four stages in four sentences.**
**Answer:** Planning: the school checks the paper registers are slow and error-prone and that a simple system is affordable. Analysis: it fixes requirements — record attendance per class each morning, list absentees by 9 a.m. Design: the data structure for pupils and classes and the entry screen are drawn. Implementation: the system is built, tested against the requirements, registers are moved across and teachers trained.
