# Developing an Information System — the Four Stages — fill in the blank

Fill each blank with the missing word or words.

**1. (Sub lesson 1) Stage 1, ____, asks whether the system is needed and feasible.**
**Answer: planning** — Planning investigates and decides: go ahead, or not yet.

**2. (Sub lesson 2) Analysis answers the question ____; design answers the question ____.**
**Answer: what; how** — Requirements first, blueprint second.

**3. (Sub lesson 2) In implementation the system is built, ____ and changed over to.**
**Answer: tested** — Testing checks it against the requirements.
