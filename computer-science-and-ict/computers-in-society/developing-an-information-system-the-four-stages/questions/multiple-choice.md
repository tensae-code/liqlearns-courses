# Developing an Information System — the Four Stages — multiple choice

Pick the one right answer.

**1. (Sub lesson 1) Which stage asks whether a new system is feasible?**
a) Analysis  b) Design  c) Planning  d) Implementation
**Answer: c) Planning** — Planning investigates the problem and whether the system can be done.

**2. (Sub lesson 1) Requirements — exactly what the system must do — are fixed in —**
a) planning  b) design  c) analysis  d) implementation
**Answer: c) analysis** — Analysis answers 'what', before design answers 'how'.

**3. (Sub lesson 2) The blueprint of data structures, processes and screens is drawn in —**
a) design  b) planning  c) analysis  d) changeover
**Answer: a) design** — Design mistakes are cheap on paper.

**4. (Sub lesson 2) Changeover belongs to which stage?**
a) Planning  b) Analysis  c) Design  d) Implementation
**Answer: d) Implementation** — Implementation builds, tests and changes over to the new system.

**5. (Sub lesson 2) Testing checks the built system against —**
a) the designer's taste  b) the requirements written in analysis  c) other schools' systems  d) the price list
**Answer: b) the requirements written in analysis** — The requirements are the promises the system is judged against.
