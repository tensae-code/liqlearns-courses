# Information gathering — check the request before you answer it — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Systems collect data only by accident.
**Answer: False** — collecting is part of how they work.

**2. (Sub lesson 2)** Consent given after handing information over protects just as well.
**Answer: False** — consent protects before the handover; after it, control is lost.

**3. (Sub lesson 2)** A request that cannot explain its intention has told you something important.
**Answer: True** — an unexplained request answers the examination.
