# Information gathering — check the request before you answer it — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Many systems collect — as part of working.
a) nothing  b) user data and credentials  c) only weather  d) only music
**Answer: b) user data and credentials** — gathering is built into working.

**2. (Sub lesson 1)** What may be gathered, and why, is —
a) fully settled  b) disputed  c) forbidden always  d) never questioned
**Answer: b) disputed** — no single settled answer exists.

**3. (Sub lesson 1)** Consent is the protection against —
a) slow internet  b) information being stolen  c) homework  d) advertising only
**Answer: b) information being stolen** — the book's own pairing.

**4. (Sub lesson 2)** Before handing anything over, the user should —
a) type fast  b) examine the intention behind the request  c) ask a stranger  d) share publicly
**Answer: b) examine the intention behind the request** — the pause rule.

**5. (Sub lesson 2)** Extra care is needed for requests asking for —
a) the time  b) personal information or credentials  c) a song  d) a photo of a cat
**Answer: b) personal information or credentials** — the highest-stakes requests.
