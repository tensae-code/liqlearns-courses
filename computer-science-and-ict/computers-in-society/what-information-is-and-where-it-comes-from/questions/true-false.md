# What Information Is — and Where It Comes From — true or false

Say true or false, and fix the false ones in your own words.

**1. (Sub lesson 1) True or false: It reduces your uncertainty about the world**
**Answer: True**

**2. (Sub lesson 1) True or false: It reduces your uncertainty about the world** — as the answer to: Name three forms information takes.
**Answer: False — A fact, an event, a measurement**

**3. (Sub lesson 1) True or false: Checkable — able to be verified**
**Answer: True**

**4. (Sub lesson 1) True or false: Checkable — able to be verified** — as the answer to: Is everything on a screen information?
**Answer: False — No — decoration, opinion and noise travel the same wires**

**5. (Sub lesson 1) True or false: Never — the same fact told twice informs once**
**Answer: True**

**6. (Sub lesson 2) True or false: Never — the same fact told twice informs once** — as the answer to: What is a source?
**Answer: False — The person, organisation, instrument or document information comes from**

**7. (Sub lesson 2) True or false: The instrument and who read it**
**Answer: True**

**8. (Sub lesson 2) True or false: The instrument and who read it** — as the answer to: What is a report's source?
**Answer: False — The reporter and who sent them**

**9. (Sub lesson 2) True or false: No source at all**
**Answer: True**

**10. (Sub lesson 2) True or false: No source at all** — as the answer to: State the fiche's rule.
**Answer: False — No source, no trust**
