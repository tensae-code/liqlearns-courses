# Hands-on — ICT in STEM Learning and Careers

The lesson with your hands, not only your eyes.

## The four fields on one problem

Pick one real problem — clean water, a bridge, growing more food, or lighting a home. Write the four STEM fields in a row. Under each one, write what that field does for this problem. Then draw a line showing where mathematics is used by the other three.

## My STEM-ICT map

Write down one science or mathematics topic you are learning now. List every ICT tool that could help you with it — finding, recording, charting, modelling, asking an expert — and say what each tool would do. Mark the one you can actually use this week.
