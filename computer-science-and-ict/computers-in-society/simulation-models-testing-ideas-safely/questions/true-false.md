# Simulation Models — Testing Ideas Safely — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does a simulation model copy?" is: A real system or process**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What is the purpose of simulation?" is: Before building or changing the real system**
**Answer: False** — To test ideas without risk to the real thing

**3. (Sub lesson 1) True or false: the answer to "A simulation model is simpler than what?" is: The real system it copies**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "When are simulations used?" is: The inputs and conditions**
**Answer: False** — Before building or changing the real system

**5. (Sub lesson 1) True or false: the answer to "Testing ideas in a model costs what, compared with the real thing?" is: Less — and it is safer**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What do you change in a simulation?" is: The design or idea — not the real system**
**Answer: False** — The inputs and conditions

**7. (Sub lesson 2) True or false: the answer to "What do you watch in a simulation?" is: The outcomes (results)**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "If simulation outcomes are bad, what do you change?" is: The real system it represents**
**Answer: False** — The design or idea — not the real system

**9. (Sub lesson 2) True or false: the answer to "Why do pilots train in simulators?" is: Because mistakes there harm no one**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "A model must be checked against what?" is: To test ideas without risk to the real thing**
**Answer: False** — The real system it represents
