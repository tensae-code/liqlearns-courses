# Collaborative tools — communication, files, projects, charts and notes — short answer

Answer in one or two sentences.

**1. (Sub lesson 1)** Name the five kinds of collaborative tools.
**Answer:** Communication; documentation and file-sharing; project management; data visualisation; note-taking.

**2. (Sub lesson 2)** Give the data-visualisation tray's examples.
**Answer:** Google Charts, Tableau, Power BI, Grafana, Chartist, FusionCharts, Datawrapper, Infogram.
