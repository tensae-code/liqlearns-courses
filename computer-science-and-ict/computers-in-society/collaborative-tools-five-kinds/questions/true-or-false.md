# Collaborative tools — communication, files, projects, charts and notes — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Trello, Asana and ClickUp are project management tools.
**Answer: True** — the third tray.

**2. (Sub lesson 2)** Evernote, OneNote and Google Keep are data visualisation tools.
**Answer: False** — they are note-taking tools; visualisation is Tableau, Power BI and their kin.

**3. (Sub lesson 2)** Track changes, versioning and editing permissions are features of documentation and file-sharing tools.
**Answer: True** — the book's feature list for the tray.
