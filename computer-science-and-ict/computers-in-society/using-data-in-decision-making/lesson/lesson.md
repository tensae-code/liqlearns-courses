# Using Data in Decision Making

## Do it first

A head teacher must choose: more library books, or more lab computers? Both sides argue from feeling. This lesson is what data adds to that room.

## Sub lesson 1 — What data does for a decision

Data serves a decision in four ways: it **describes the present** (how the library and lab are actually used — not how each side imagines), it **compares the options** (cost and benefit of each, in the same measures), it **predicts** (next year's pupils, next year's needs), and it **checks afterwards** (did the chosen option do what was promised?). A decision with data is not guaranteed right; it is guaranteed **examinable** — its reasons can be shown, challenged and improved.

## Sub lesson 2 — Data's limits — the honest half

Jordan's lesson keeps the limits beside the praise: data is **about the past** (the future may differ), it measures **what is measurable** (a library's quiet value escapes the counter), it can be **wrong or gamed** (collected carelessly, or shaped to please), and it never **makes** the decision — values do: data says what each option costs and earns; people choose what matters. The mature user the book is building holds both halves: decide with data, and know exactly where the data stopped.
