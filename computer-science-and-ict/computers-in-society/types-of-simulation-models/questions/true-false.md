# Types of Simulation Models — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "In a simulation, what is an entity?" is: A thing that moves through or sits in the system**
**Answer: True**

**Answer: False** — What happens to entities over time

**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "Give a process in a shop simulation." is: A real, scaled copy you can touch**
**Answer: False** — Being served at the counter

**5. (Sub lesson 1) True or false: the answer to "A simulation model represents entities and what else?" is: Processes**
**Answer: True**
