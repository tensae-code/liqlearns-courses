# Quantitative Evaluation of Screen Design — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "What does a quantitative evaluation measure with?" is: Counts — numbers**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "Name the four counted things." is: By questionnaire — such as an average out of 5**
**Answer: False** — Task completion (success rate), time taken, errors made, satisfaction scores

**3. (Sub lesson 1) True or false: the answer to "How are satisfaction scores gathered?" is: By questionnaire — such as an average out of 5**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What must every reported number carry?" is: A number about nothing**
**Answer: False** — Its task and its users named

**5. (Sub lesson 1) True or false: the answer to "A success rate with no task named is what?" is: A number about nothing**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "Against what is each number set in discussion?" is: Failure — however pleasant the screens felt**
**Answer: False** — The design's aim for that task

**7. (Sub lesson 2) True or false: the answer to "A 2:40 average against an under-a-minute aim means what?" is: Failure — however pleasant the screens felt**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "How are failures ranked?" is: Indications, not proofs**
**Answer: False** — Lowest success first — repaired first

**9. (Sub lesson 2) True or false: the answer to "What are a small trial's figures?" is: Indications, not proofs**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "What does the evaluation end in?" is: Counts — numbers**
**Answer: False** — Decisions — which screens change, in what order, and what is measured again
