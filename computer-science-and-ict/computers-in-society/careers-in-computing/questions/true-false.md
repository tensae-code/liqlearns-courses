# Careers in Computing — true-false

Say whether each statement is true or false.

**1. (Sub lesson 1) True or false: the answer to "How does computing work first divide?" is: Into those who build systems and those who run them**
**Answer: True**

**2. (Sub lesson 1) True or false: the answer to "What does a programmer do?" is: Studies an organisation's needs and designs the system that meets them**
**Answer: False** — Writes the software

**3. (Sub lesson 1) True or false: the answer to "What does a systems analyst do?" is: Studies an organisation's needs and designs the system that meets them**
**Answer: True**

**4. (Sub lesson 1) True or false: the answer to "What does a network administrator do?" is: Guards the data**
**Answer: False** — Keeps the networks working

**5. (Sub lesson 1) True or false: the answer to "What does a database administrator do?" is: Guards the data**
**Answer: True**

**6. (Sub lesson 2) True or false: the answer to "What does a data entry operator do?" is: Make new users capable**
**Answer: False** — Turns the world's paper into the system's records

**7. (Sub lesson 2) True or false: the answer to "What do IT teachers and trainers do?" is: Make new users capable**
**Answer: True**

**8. (Sub lesson 2) True or false: the answer to "What does a systems manager do?" is: Installs, maintains and repairs the machines**
**Answer: False** — Plans and answers for the whole system

**9. (Sub lesson 2) True or false: the answer to "What does a technician do?" is: Installs, maintains and repairs the machines**
**Answer: True**

**10. (Sub lesson 2) True or false: the answer to "How is each career entered?" is: Into those who build systems and those who run them**
**Answer: False** — By the subjects and skills of this course, deepened in the career's direction
