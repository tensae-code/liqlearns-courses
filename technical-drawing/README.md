# Technical Drawing

Technical Drawing is a standalone school subject in the
curricula that teach it under its own name, with its own
textbooks. This folder holds one course per country, built
from that country's own Technical Drawing books — the same
pattern as the History and Civics and Citizenship folders.

Courses here:

- `ethiopia/` — Technical Drawing — Ethiopia, built from
  Ethiopia's Grade 12 Technical Drawing teacher guide alone
  (no student book in hand; see its ABOUT.md).

Technical Drawing material from other countries also stands
inside the Technology & Design world course as its Technical
Drawing strand. That strand is a different course and stays
as it is; a country's own standalone course here does not
replace it.
