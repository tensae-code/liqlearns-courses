# Video script — Sectioning — Words and Common Practice

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then. The lesson is text-first: this script says nothing the lesson text does not already teach.

This lesson is about one thing.
A section view shows interior details clearly: the object is imagined cut, a cutting-plane line shows where the object was cut to obtain the section view, and section lining (hatching) marks the cut faces so the section can be read.

Watch the drawing being made, step by step, in the order the lesson gives.

Outside views hide the inside. A sectional view answers by imagining the object cut open and part of it removed, so interior details stand clear instead of being guessed at from hidden lines.

Fix the terminology of sectioning and its common practices before drawing any type: the cutting-plane line shows where the object was cut; section lining — hatching — is drawn on the faces the cut passed through. These conventions are what make a section readable by anyone.

Remember it this way: A section view shows interior details clearly: the object is imagined cut, a cutting-plane line shows where the object was cut to obtain the section view, and section lining (hatching) marks the cut faces so the section can be read.
