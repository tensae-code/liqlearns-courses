# Secondary Auxiliary Views — Projecting a Projection

## Do it first

Before you read, try the lesson's task once with what you already know: Work one oblique-faced object through the full chain: principal views, primary auxiliary view, secondary auxiliary view. Circle the view where the true shape finally appears. Keep your first attempt — you will compare it with your work at the end.

## ℹ Info

For a surface inclined to all the principal planes — an oblique surface — even a first auxiliary view does not show the true shape. A secondary auxiliary view, projected again from the primary auxiliary view, gives the true shape no earlier view can show.

## When one auxiliary view is not enough

An oblique surface is inclined to every principal plane. Project it once and the auxiliary view is still not true, because the first auxiliary plane could be parallel to only one direction of the surface.

## Building the second projection

Build the secondary auxiliary view step by step from the primary one: treat the primary auxiliary view as your new starting view, set a new folding line, and project again. The true shape appears only in this last view. The lesson is almost all drawing practice — the skill is in doing the chain carefully, step by step.

> Tip — from us, not from the books: Draw first, judge after. A drawing you can compare against the lesson's standard teaches more than a perfect copy — keep every attempt and mark what changed.
