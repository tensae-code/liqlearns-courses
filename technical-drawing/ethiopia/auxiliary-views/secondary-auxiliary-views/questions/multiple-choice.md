# Secondary Auxiliary Views — Projecting a Projection — multiple choice

Pick the one right answer.

**1.** What does this lesson teach?
a) For a surface inclined to all the principal planes — an oblique surface — even a first auxiliary view does not show the true shape. A secondary auxiliary view, projected again from the primary auxiliary view, gives the true shape no earlier view can show.  b) A topic from a different level of this course  c) The Reference bibliography of the teacher guide  d) none of these
**Answer: a)** — That is what this lesson teaches.

**2.** Which of these belongs to this lesson?
a) When one auxiliary view is not enough  b) a topic from another course  c) today's weather  d) none of these
**Answer: a)** — That is this lesson's first part.
