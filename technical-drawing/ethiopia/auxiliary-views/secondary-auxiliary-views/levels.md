# Secondary Auxiliary Views — Projecting a Projection — depth

This lesson's parts are distinct and sequential, so they stand as its sub lessons (2026-11-09 ruling: sub lessons only where a lesson genuinely has distinct sequential parts). Practice is tied to the learner's skill number. The questions live in the type files.

Pass mark: For a surface inclined to all the principal planes — an oblique surface — even a first auxiliary view does not show the true shape. A secondary auxiliary view, projected again from the primary auxiliary view, gives the true shape no earlier view can show. — shown in the learner's own words and in a finished drawing task done to the lesson's standard.
