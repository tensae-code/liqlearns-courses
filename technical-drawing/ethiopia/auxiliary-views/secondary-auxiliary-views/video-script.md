# Video script — Secondary Auxiliary Views — Projecting a Projection

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then. The lesson is text-first: this script says nothing the lesson text does not already teach.

---

This lesson is about one thing.
For a surface inclined to all the principal planes — an oblique surface — even a first auxiliary view does not show the true shape. A secondary auxiliary view, projected again from the primary auxiliary view, gives the true shape no earlier view can show.

Watch the drawing being made, step by step, in the order the lesson gives.

An oblique surface is inclined to every principal plane. Project it once and the auxiliary view is still not true, because the first auxiliary plane could be parallel to only one direction of the surface.

Build the secondary auxiliary view step by step from the primary one: treat the primary auxiliary view as your new starting view, set a new folding line, and project again. The true shape appears only in this last view. The lesson is almost all drawing practice — the skill is in doing the chain carefully, step by step.

Remember it this way: For a surface inclined to all the principal planes — an oblique surface — even a first auxiliary view does not show the true shape. A secondary auxiliary view, projected again from the primary auxiliary view, gives the true shape no earlier view can show.

Now you. Say it back, in your own words. Then go and do it — today, at home, at school, in your street.
