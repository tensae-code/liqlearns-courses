# Video script — Drawing an Auxiliary View — The True Shape of an Inclined Surface

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then. The lesson is text-first: this script says nothing the lesson text does not already teach.

---

This lesson is about one thing.
To draw an auxiliary view of a whole object, project the object's features onto a plane parallel to its inclined surface; the drawing then describes the true shape of that surface.

Watch the drawing being made, step by step, in the order the lesson gives.

Set the auxiliary plane parallel to the inclined surface whose true shape you need. Parallel is the whole secret: only a plane parallel to a surface receives that surface's projection at its true size and shape.

Project the object's features, point by point, onto the auxiliary plane, carrying distances truly with folding and reference lines from the principal views. The result is the auxiliary view drawing of the object, with the inclined surface shown truly.

Remember it this way: To draw an auxiliary view of a whole object, project the object's features onto a plane parallel to its inclined surface; the drawing then describes the true shape of that surface.

Now you. Say it back, in your own words. Then go and do it — today, at home, at school, in your street.
