# Orthographic Projection — Points, Lines, Planes and Surfaces — depth

This lesson's parts are distinct and sequential, so they stand as its sub lessons (2026-11-09 ruling: sub lessons only where a lesson genuinely has distinct sequential parts). Practice is tied to the learner's skill number. The questions live in the type files.

Pass mark: Orthographic projection shows an object in principal views, but when an object has inclined or oblique planes or features, no principal view shows their true shape. The auxiliary view is the special orthographic view that answers this, built with folding lines and reference lines from the projection of points, lines and planes in space. — shown in the learner's own words and in a finished drawing task done to the lesson's standard.
