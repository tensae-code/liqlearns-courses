# Worked Developments — The Answer Plates — multiple choice

Pick the one right answer.

**1.** What does this lesson teach?
a) The teacher guide prints full-page worked solution drawings, lettered A to J, as the answers to the development exercises. They are the only place the course's expected drawing standard is fully visible, and they set the accuracy bar for all the development work in this level.  b) A topic from a different level of this course  c) The Reference bibliography of the teacher guide  d) none of these
**Answer: a)** — That is what this lesson teaches.

**2.** Which of these belongs to this lesson?
a) Reading the plates  b) a topic from another course  c) today's weather  d) none of these
**Answer: a)** — That is this lesson's first part.

Difficulty: 1 = recall of the lesson's one thing; 2 = telling this lesson's parts from other lessons' parts.
