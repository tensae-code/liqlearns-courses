# Lesson plan — Pictorial Sketching — Isometric Sketching Someone Else Could Build From

**Course:** Technical Drawing — Ethiopia · **Level folder:** Level 1 — Sketching and Visualisation · **Lesson:** Pictorial Sketching — Isometric Sketching Someone Else Could Build From
**Place in the curriculum:** Level 1 — Sketching and Visualisation (CURRICULUM.md).
**The one thing this lesson teaches:** A pictorial sketch is good when it carries enough detail that someone else can make a similar object from it: features on every side, basic dimensions and basic material descriptions, drawn as an isometric sketch on isometric grid paper.
**This lesson's own level:** Level 1 — Sketching and Visualisation (recommended, never forced).
**Guide time for this lesson:** 3 periods (1 theory, 2 practice) (teacher guide, printed pp. 7-18) — in the guide, practice takes the larger share wherever the lesson is split.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The lesson teaches through its text first: every picture's and GIF's teaching is also in the text, so the lesson is fully learnable by listening to its text read aloud.

## Sub lessons
This lesson has distinct sequential parts, one per part below; the parts run in order inside the one lesson, with no break between steps on the lesson page.
- Sketching an object so it can be remade
- What a complete pictorial sketch carries
- How the sketch is judged

## Before this lesson
- The levels before this one in CURRICULUM.md are recommended first — a soft hint, never a forced gate. A learner who lands here directly can start here.

## What the learner can do when it ends
1. State the lesson's one thing in their own words: A pictorial sketch is good when it carries enough detail that someone else can make a similar object from it: features on every side, basic dimensions and basic material descriptions, drawn as an isometric sketch on isometric grid paper.
2. Do the lesson's drawing task (Do It Yourself, below) to the standard the lesson sets.
3. Answer the lesson's questions from the lesson, without looking back.

## What you need
Paper (grid paper where the lesson says so), a pencil, and a ruler for checking — the drawing itself is free-hand or construction as the lesson directs. Nothing else.

## The run of the lesson (in order)
1. **Do it first** — the learner does the opening act of lesson/lesson.md before any explanation.
2. **The explanation** — the lesson's parts in order (lesson/lesson.md).
3. **Say it to your companion** — the learner explains the lesson's one thing and gives a real example (lesson/lesson.md).
4. **Questions** — from questions/: multiple-choice, true-or-false, short-answer, fill-in-the-blank, matching — served at the learner's level (levels.md).
5. **Hands-on** — hands-on.md.
6. **Do It Yourself** — the closing doing block (lesson/lesson.md).

## Add-ons for this lesson (the full list)
- IMAGE — a picture of a blocky object beside its isometric sketch on isometric grid paper → the student studies the picture and names what it shows, part by part, in the lesson's own words.
- GIF — the movement named in the lesson text, shown moving → the student watches, then describes the movement in words before drawing.
- VIDEO — the video-script filmed (made later) → the student listens and answers along. The lesson is fully learnable from its text alone; the video adds nothing the text does not teach.

## If the learner is stuck
- Go back to the one thing: A pictorial sketch is good when it carries enough detail that someone else can make a similar object from it: features on every side, basic dimensions and basic material descriptions, drawn as an isometric sketch on isometric grid paper. Work the Do it first act again, slowly, naming each step aloud as you draw it.
