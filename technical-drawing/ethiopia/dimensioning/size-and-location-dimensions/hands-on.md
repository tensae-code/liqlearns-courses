# Hands-on — Size and Location Dimensions — The Theory

The lesson with your hands, not only your eyes.

## Do the opening act again
Dimension one part fully. Then go through your figures and mark each one S for size or L for location. If either kind is missing, add it.

## Show it with real things
Work the lesson's drawing task on real paper, naming each step aloud as you do it: what you are drawing, why this step comes here, and what the finished drawing must show. Compare the result against the lesson's one thing: Dimensions divide into size dimensions, which say how big a feature is, and location dimensions, which say where it sits. Dimension figures state true size regardless of the drawing's scale, and a working drawing must be so complete a set of instructions that no further word need be given to the people fabricating the object.

## Check it for one day
For one day, look for this lesson's teaching in real made things around you — drawings, packages, sheet-metal objects, buildings. Each time you see it, note what you saw and what the lesson would say about it. Bring your notes back to the lesson.
