# Size and Location Dimensions — The Theory

## ℹ Info

Dimensions divide into size dimensions, which say how big a feature is, and location dimensions, which say where it sits. Dimension figures state true size regardless of the drawing's scale, and a working drawing must be so complete a set of instructions that no further word need be given to the people fabricating the object.

## Two kinds of dimension

A size dimension states how big a feature is — a length, a diameter, a thickness. A location dimension states where a feature sits — its distance from a face, an edge or another feature. A complete drawing needs both kinds: size without location leaves the maker guessing where things go.

## Choosing dimensions and the scale rule

Select convenient dimensions that properly describe a feature, and relate the scale of the drawing to the dimension figures: the figures state the true size of the object whatever scale the drawing is made at. Write letters and numerals in the accepted standard form.
