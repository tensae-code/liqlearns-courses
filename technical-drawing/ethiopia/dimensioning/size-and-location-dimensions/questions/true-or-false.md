# Size and Location Dimensions — The Theory — true or false

Say true or false, and say why.

**1.** This statement is the lesson's one thing: Dimensions divide into size dimensions, which say how big a feature is, and location dimensions, which say where it sits. Dimension figures state true size regardless of the drawing's scale, and a working drawing must be so complete a set of instructions that no further word need be given to the people fabricating the object.
**Answer: True** — it states the lesson's teaching in full.

**2.** A learner who lands on this lesson directly must finish every earlier level before starting it.
**Answer: False** — earlier levels are recommended first, never a forced gate; every lesson stands alone.

Difficulty: 1 = direct recall; 2 = applying the course's direct-entry rule.
