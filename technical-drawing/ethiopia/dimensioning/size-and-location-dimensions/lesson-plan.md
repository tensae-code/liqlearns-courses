# Lesson plan — Size and Location Dimensions — The Theory

**Course:** Technical Drawing — Ethiopia · **Level folder:** Level 4 — Dimensioning · **Lesson:** Size and Location Dimensions — The Theory
**Place in the curriculum:** Level 4 — Dimensioning (CURRICULUM.md).
**The one thing this lesson teaches:** Dimensions divide into size dimensions, which say how big a feature is, and location dimensions, which say where it sits. Dimension figures state true size regardless of the drawing's scale, and a working drawing must be so complete a set of instructions that no further word need be given to the people fabricating the object.
**This lesson's own level:** Level 4 — Dimensioning (recommended, never forced).
**Guide time for this lesson:** 2 periods (1 theory, 1 practice) (teacher guide, printed pp. 59-62) — in the guide, practice takes the larger share wherever the lesson is split.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The lesson teaches through its text first: every picture's and GIF's teaching is also in the text, so the lesson is fully learnable by listening to its text read aloud.
