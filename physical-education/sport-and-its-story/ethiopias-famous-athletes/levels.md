# Ethiopia's Famous Athletes — sub lessons and depth

This file is the lesson's depth record, re-expressed as its sub lessons. The questions live in the type files; this file is the by-sub-lesson view. The parts run from the youngest book's teaching to the oldest, as the placements stack them.

## Sub lesson 1 — Meselech Melkamu and Sileshi Sihine — the Grade 5 profiles
Pass mark: profile both athletes — event, birth year, birthplace — without looking.

## Sub lesson 2 — Kenenisa Bekele and Gezahegne Abera (teacher guide — evidence)
Pass mark: name each man's event and one victory from the guide's telling.

## Sub lesson 3 — Kenenisa again, Meseret Defar and Coach Sewnet Bishaw
Pass mark: name each person's field — runner or coach — and one fact from their profile.

## Sub lesson 4 — Ethiopia's Olympic heroes
Pass mark: match all five heroes to their Games and medals.
