# Games for Communication and Cooperation — sub lessons and depth

This file is the lesson's depth record, re-expressed as its sub lessons. The questions live in the type files; this file is the by-sub-lesson view. The parts run from the youngest book's teaching to the oldest, as the placements stack them.

## Sub lesson 1 — The Fishing game (Grade 3)
Pass mark: play the Fishing game in a group, casting and answering in turn.

## Sub lesson 2 — The Fishing game and the ball in the circle (Grade 4)
Pass mark: play the Fishing game and the ball-inside-the-circle game, calling and answering on every play.

## Sub lesson 3 — Signals before changes and the four-beat clapping game (teacher guide — evidence)
Pass mark: give a clear signal before changing a game, and clap the four-beat pattern in rows, joining exactly on the beat for 5 rounds.
