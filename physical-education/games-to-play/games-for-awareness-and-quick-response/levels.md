# Games for Awareness and Quick Response — sub lessons and depth

This file is the lesson's depth record, re-expressed as its sub lessons. The questions live in the type files; this file is the by-sub-lesson view. The parts run from the youngest book's teaching to the oldest, as the placements stack them.

## Sub lesson 1 — The Grade 3 games — covered eyes, the name call, Thief and Police
Pass mark: find the ball with covered eyes inside the marked space, and catch in the circle on your name call, two calls in a row.

## Sub lesson 2 — The Grade 4 games — the inside/outside command game
Pass mark: answer five inside/outside commands instantly and correctly, and dribble by foot inside the circle keeping control.

## Sub lesson 3 — Watch and listen — attention games on changing calls (teacher guide — evidence)
Pass mark: do exactly the called action through five changing calls without a mistake, and answer the number pattern without error.
