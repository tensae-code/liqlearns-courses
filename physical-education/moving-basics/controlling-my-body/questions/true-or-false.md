# Controlling My Body — true or false

Say if it is true or false.

**1. (Sub lesson 1)** Holding one body segment still while others move is part of controlling movement.
**Answer: True**

**2. (Sub lesson 2)** In bilateral efficiency, only the favourite hand is used.
**Answer: False**

**3. (Sub lesson 4)** The lower limbs can work independently of the upper limbs in physical activity.
**Answer: True**
