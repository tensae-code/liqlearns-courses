# Skiing for Beginners — sub lessons and depth

This file is the lesson's depth record, re-expressed as its sub lessons. The questions live in the type files; this file is the by-sub-lesson view. The parts run from the youngest book's teaching to the oldest, as the placements stack them.

## Sub lesson 1 — First steps on skis
Pass mark: name the two first steps as the guide teaches them — the sliding step and the alternating stride.

## Sub lesson 2 — Going down, turning and climbing
Pass mark: say how each is done in the guide's beginner set — descending in a stance, the step turn, climbing "ladder" style.

## Sub lesson 3 — Skiing the distance
Pass mark: say what the quarter builds to — covering 2–3 km and free skiing — and that safety theory and drill on skis go with the training.
