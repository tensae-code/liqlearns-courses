# Timed and Distance Running — matching

Match each part name to what it teaches.

1. Timed running — Grade 5: beating your own time — a
2. Running to the clock — middle distance (teacher guide — evidence) — b
3. Distance running — Grade 6: 1500 and 2000 metres — c

What each teaches:
a) timed runs over 20 metres past cones set 5 metres apart, and the 20–40 metre speed run — the aim is improving your time over the distance
b) middle-distance running to the clock — running slowly and steadily for 5–6 minutes, then 6–8 minutes in pairs and threes, correcting each other's form
c) an alternating-pace 1500 metres (500 m medium pace with 20 m marching breaks) and a medium-pace 2000 metre run

**Answer key:** 1–a · 2–b · 3–c
