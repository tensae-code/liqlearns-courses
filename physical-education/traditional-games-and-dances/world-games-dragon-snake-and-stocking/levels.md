# World Games — Dragon Snake and Stocking — sub lessons and depth

This file is the lesson's depth record, re-expressed as its sub lessons. The questions live in the type files; this file is the by-sub-lesson view. The parts run from the youngest book's teaching to the oldest, as the placements stack them.

## Sub lesson 1 — World traditional games — every country has its own
Pass mark: name the two world games taught in full and the home the book gives the Dragon Snake.

## Sub lesson 2 — Dragon Snake (የድራጎን እባብ) — Vietnam / China
Pass mark: form the dragon correctly (holding shoulders/waist), and state both endings: line traps leader = line wins; leader touches tail or breaks line = leader wins.

## Sub lesson 3 — Stocking (ስቶኪንግ) — the rising rope game
Pass mark: set Stocking correctly (two holders, one middle jumper) and describe the rope's rise and the singing/dancing around the jumper.
