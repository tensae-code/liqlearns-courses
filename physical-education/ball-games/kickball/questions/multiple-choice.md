# Kickball — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Kickball is…
a) The North-American kick-and-run ball game  b) A swimming game  c) A board game
**Answer: a) The North-American kick-and-run ball game**

**2. (Sub lesson 1)** Timor-Leste teaches kickball in…
a) The Grade 7 teacher guide's seven-sport appendix  b) A swimming appendix  c) The student book's stretching guide
**Answer: a) The Grade 7 teacher guide's seven-sport appendix**

**3. (Sub lesson 1)** For each sport in its appendix, the guide gives…
a) Basic rules and mini-games  b) Only a picture  c) Only a song
**Answer: a) Basic rules and mini-games**

**4. (Sub lesson 2)** The mini-games come…
a) Before the full game, to teach it piece by piece  b) Only after the full game is mastered  c) Instead of any game at all
**Answer: a) Before the full game, to teach it piece by piece**
