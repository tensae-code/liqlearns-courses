# Dangers when using simple machines, and safety in using simple machines — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A load on a pulley can drop if it is not secured.
**Answer: True** — Dropped loads are among the dangers of simple machines — never trust an unsecured load.

**2. (Sub lesson 2)** Safety with simple machines is a separate subject from using them.
**Answer: False** — Rwanda teaches safety as the closing lesson of the simple-machines unit itself.

**3. (Sub lesson 2)** You should check a simple machine before loading it.
**Answer: True** — Checking first is one of the safety practices that answer the dangers.
