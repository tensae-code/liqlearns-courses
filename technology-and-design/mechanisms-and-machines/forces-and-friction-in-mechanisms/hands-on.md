# Hands-on — Forces and friction in mechanisms

Real practice — this subject is learned by doing.

## Friction demonstration
Slide the same object across three surfaces — smooth, medium, rough. Measure how far it travels each time from the same push, and record which surface friction was strongest.

## Force hunt
Watch any moving thing for one minute — a door, a bicycle, a fan. Write every force you can catch it obeying, using the lesson's list.
