# Simulating a mechanism in software (Interactive Physics) before building it — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is simulation?
a) building and running a mechanism in software before making it in material b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) building and running a mechanism in software before making it in material**

**2. (Sub lesson 1)** What is Interactive Physics?
a) Only history b) the simulation software the module uses to model moving mechanisms c) Only storage d) A kind of glue
**Answer: b) the simulation software the module uses to model moving mechanisms**

**3. (Sub lesson 2)** What is pivot?
a) Only old tools b) Only painting c) the fixed point a part turns around d) Only a price
**Answer: c) the fixed point a part turns around**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) Only decoration b) Nothing to do with this lesson c) Only history d) before cutting material, a mechanism can be built in software and run: simulation in Interactive Physics shows whether the motion works — and fails cheaply when it does not.
**Answer: d) before cutting material, a mechanism can be built in software and run: simulation in Interactive Physics shows whether the motion works — and fails cheaply when it does not.**
