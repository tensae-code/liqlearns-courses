# Hands-on — Simple machines

Real practice — this subject is learned by doing.

## Machine hunt
Walk your home or school and find one real example of each type: lever, wheel and axle, pulley, inclined plane, wedge, screw. Write what work each makes easier.

## Name the type
For the wheelbarrow, crowbar, windlass, elevator and ladder, name the simple-machine type of each — then find one more example of your own for two of them.
