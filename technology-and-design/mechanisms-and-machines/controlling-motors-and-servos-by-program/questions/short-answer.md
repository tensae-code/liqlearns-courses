# Controlling motors and servos by program — short answer

Answer in one or two sentences.

**1. (Sub lesson 1)** Say in one sentence what this lesson teaches.
**Answer:** Controlling motors and servos by program — the annotated Motor_test code (analogWrite speeds, digitalWrite directions), writing code to drive a robot along drawn paths (square, diamond), and the Servo-Sweep and Servo-Knob programs with a potentiometer.

**2. (Sub lesson 2)** Name one material, tool or step this lesson works with.
**Answer:** Any one named in the lesson text — for example, the first step of sub lesson 1: Controlling motors and servos by program.
