# Drawing and reading architectural floor plans and elevations — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Every later view refers back to the floor plan.
**Answer: True** — The plan is the building's map.

**2. (Sub lesson 2)** An elevation is a perspective picture of a wall.
**Answer: False** — An elevation is a flat, true-size-projected view used as a building instruction.

**3. (Sub lesson 3)** Given span and pitch, the truss's height follows.
**Answer: True** — The two data points fix the triangle.
