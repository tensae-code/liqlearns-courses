# Computer-aided drawing (CAD) — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is CAD?
a) computer-aided drawing: making exact drawings in software b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) computer-aided drawing: making exact drawings in software**

**2. (Sub lesson 1)** What is drawing environment?
a) Only history b) the software's workspace: drawing area, toolbars, menus and precision aids c) Only storage d) A kind of glue
**Answer: b) the software's workspace: drawing area, toolbars, menus and precision aids**

**3. (Sub lesson 2)** What is snap?
a) Only old tools b) Only painting c) a precision aid that pulls the cursor to exact points such as ends and centres d) Only a price
**Answer: c) a precision aid that pulls the cursor to exact points such as ends and centres**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) Only decoration b) Nothing to do with this lesson c) Only history d) computer-aided drawing does the drawing board's work in software — used across jobs and projects wherever exact, changeable, shareable drawings are needed.
**Answer: d) computer-aided drawing does the drawing board's work in software — used across jobs and projects wherever exact, changeable, shareable drawings are needed.**

**5. (Sub lesson 2)** How does Iran's book teach this?
a) As theory only, never practised b) Only in a glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Persian
