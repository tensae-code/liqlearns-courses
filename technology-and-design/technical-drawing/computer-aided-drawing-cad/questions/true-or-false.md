# Computer-aided drawing (CAD) — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** CAD is computer-aided drawing: making exact drawings in software.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Drawing environment has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: the software's workspace: drawing area, toolbars, menus and precision aids.

**3. (Sub lesson 2)** Snap is a precision aid that pulls the cursor to exact points such as ends and centres.
**Answer: True** — That is how the book teaches it.
