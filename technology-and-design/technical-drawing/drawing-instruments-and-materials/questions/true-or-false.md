# Drawing instruments and materials — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Drawing board is the flat board that gives technical drawing its true working surface.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Millimetre paper has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: paper ruled in millimetre grids so measurements read straight from the sheet.

**3. (Sub lesson 2)** A-series is the standard paper sizes, each halving the one before, from A0 down.
**Answer: True** — That is how the book teaches it.
