Cuba's own way: Cuba teaches the drawing instruments and materials in both Grade 7 editions — the 1989 book with the drawing board, T-square, set squares, compass and the cajetín (title block), the 2023 book with the normalised line alphabet beside the instruments.

Iran's own way: Iran opens نقشه‌کشی (drawing) in Grade 7 with the kit itself — the drawing board set, grid and millimetre papers, and the A-series sizes — before a single line is drawn.
