# Packaging design — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Traditional packaging is packaging from plant materials such as coconut and banana leaves.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 2)** Eco-friendly material has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: material that does not burden the environment.

**3. (Sub lesson 2)** Complete label information is a label carrying everything the user needs to know.
**Answer: True** — That is how the book teaches it.
