# Video script — Size and Location Dimensions — the Theory

The super-simple voice, for the video that rides on top of the lesson (lesson-plan.md, add-on list). Made later, when videos are made; the script is the slot's written form until then.

---

A hole in a plate. What must the maker be told?

First: how big. The diameter. That is a size dimension.

Second: where. The centre, measured from two edges. Those are location dimensions.

Size says how big. Location says where. Every feature needs both questions answered.

And the figure always tells the truth about size — even when the drawing is drawn small.

A working drawing is a complete set of instructions. The maker asks nothing.

Dimension your plate so the maker asks nothing.
