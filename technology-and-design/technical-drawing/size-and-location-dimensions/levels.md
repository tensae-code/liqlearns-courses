# Size and Location Dimensions — the Theory — sub lessons and depth

This file is the lesson's depth record, re-expressed as its sub lessons. Practice is tied to the learner's skill number. The questions live in the type files; this file is the by-sub-lesson view.

## Sub lesson 1 — Size dimensions — how big
Sub lesson 1 questions from the type files. Pass mark: the learner can do, unaided, what this part teaches — dimensions that give the size of a feature itself: lengths, widths, diameters, radii, thicknesses.

## Sub lesson 2 — Location dimensions — where it sits
Sub lesson 2 questions from the type files. Pass mark: the learner can do, unaided, what this part teaches — dimensions that place a feature: distances from a face, an edge or a centre line to the feature.

## Sub lesson 3 — True size at any scale — and a complete set of instructions
Sub lesson 3 questions from the type files. Pass mark: the learner can do, unaided, what this part teaches — the figure states the object's real size regardless of the drawing's scale; the drawing must leave the maker nothing to ask.
