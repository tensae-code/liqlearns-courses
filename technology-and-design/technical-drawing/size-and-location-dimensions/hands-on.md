# Hands-on — Size and Location Dimensions — the Theory

The lesson with your hands, not only your eyes.

## Sort a real object's dimensions
Take a real object with a hole or a boss — a bracket, a lid, a tool. List every dimension a maker would need, then sort your list into two columns: SIZE and LOCATION. Any feature missing from one column is a dimension still to draw.

## The scale test
Draw one face of the object at half size. Write the true figures on it. Hand the sheet to a partner: can they state the object's real size from the figures alone, without measuring the drawing? That is the test working.
