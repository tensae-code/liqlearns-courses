# Size and Location Dimensions — the Theory — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** The thickness of a wall is a size dimension. — **True**

**2. (Sub lesson 2)** A diameter alone tells the maker where to drill a hole. — **False** (location dimensions to the centre are also needed)

**3. (Sub lesson 3)** A maker may safely get a size by scaling it off the drawing with a ruler instead of reading the figure. — **False** (the figure states the true size; the drawn line follows the scale)

**4. (Sub lesson 3)** Figures and numerals should be lettered in one accepted standard form all over the sheet. — **True**
