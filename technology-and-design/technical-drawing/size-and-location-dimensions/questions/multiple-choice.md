# Size and Location Dimensions — the Theory — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A size dimension tells the maker —
a) where a feature sits  b) how big a feature is  c) the name of the feature
**Answer: b) how big a feature is**

**2. (Sub lesson 1)** Which of these is a size dimension?
a) The distance of a hole's centre from an edge  b) The diameter of a hole  c) The distance between two centres, used to place them
**Answer: b) The diameter of a hole**

**3. (Sub lesson 2)** A location dimension is measured from —
a) a chosen face, edge or centre line to the feature  b) the title block  c) the edge of the sheet
**Answer: a) a chosen face, edge or centre line to the feature**

**4. (Sub lesson 2)** A holed plate is fully described when it carries —
a) only the hole's diameter  b) only the plate's outline  c) the hole's size and the location of its centre
**Answer: c) the hole's size and the location of its centre**

**5. (Sub lesson 3)** On a half-size drawing of a part that is truly 100 long, the figure must read —
a) 50  b) 100  c) 200
**Answer: b) 100**

**6. (Sub lesson 3)** The principle governing dimensioning is that a working drawing must be —
a) a complete set of instructions, needing no further word to the maker  b) as short as possible  c) drawn without figures
**Answer: a) a complete set of instructions, needing no further word to the maker**
