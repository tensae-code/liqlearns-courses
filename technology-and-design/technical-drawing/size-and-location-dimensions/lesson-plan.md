# Lesson plan — Size and Location Dimensions — the Theory

**Course:** Technical Drawing · **Title:** Technical Drawing · **Lesson:** Size and Location Dimensions — the Theory
**Place in the curriculum:** Unit 4 — Dimensioning (guide Lesson 4.2) (CURRICULUM.md).
**The one thing this lesson teaches:** every dimension is one of two kinds — a size dimension says how big a feature is; a location dimension says where it sits — and the figure always states the true size, whatever the drawing's scale.
**This lesson's own level:** it stands on the lesson before it in this unit — the parts of a dimension and the two reading systems (teacher evidence).

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. ## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Size dimensions — how big** — dimensions that give the size of a feature itself: lengths, widths, diameters, radii, thicknesses.
2. **Location dimensions — where it sits** — dimensions that place a feature: distances from a face, an edge or a centre line to the feature.
3. **True size at any scale — and a complete set of instructions** — the figure states the object's real size regardless of the drawing's scale; the drawing must leave the maker nothing to ask.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Dimensioning — lines, symbols and reading direction. Recommended, never forced.

## What the learner can do when it ends
1. Tell a size dimension from a location dimension on any drawing.
2. Choose the dimensions that properly describe a feature — no feature left without its size and its place.
3. State the governing rule of scale: the figure gives the true size of the object, even when the drawing is made smaller or larger.
4. Letter figures and numerals in the accepted standard form.
5. Explain the unit's principle: a working drawing is a complete set of instructions — the maker needs no further word.

## What you need
Paper, a sharp pencil, a ruler and an eraser. One of your own object drawings to dimension.
