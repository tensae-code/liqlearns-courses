# Working in QGIS — short answer

Answer in one or two sentences.

**1. (Sub lesson 1)** Say in one sentence what this lesson teaches.
**Answer:** Coordinate reference systems (transforming data from WGS 84 / EPSG:4326 to the Greek grid GGRS87 / EPSG:2100, on-the-fly CRS transformation) and organising work as QGIS projects (.qgs files, data references/paths).

**2. (Sub lesson 2)** Name one material, tool or step this lesson works with.
**Answer:** Any one named in the lesson text — for example, the first step of sub lesson 1: Working in QGIS.
