# Drawing the living-space layout plan — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** The beneficiary's wishes come before the drawing.
**Answer: True** — The arrangement starts from the beneficiary's individual wishes and needs.

**2. (Sub lesson 2)** A plan only needs to be functional; how it feels does not count.
**Answer: False** — The space is valued functionally and aesthetically together.

**3. (Sub lesson 2)** The arrangement plan is put on paper first.
**Answer: True** — Graphic design of living spaces puts the plan on paper before making changes.
