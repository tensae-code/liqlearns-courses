# Lesson plan — Arranging Dimensions — the Two Methods

**Course:** Technical Drawing · **Title:** Technical Drawing · **Lesson:** Arranging Dimensions — the Two Methods
**Place in the curriculum:** Unit 4 — Dimensioning (guide Lesson 4.3) (CURRICULUM.md).
**The one thing this lesson teaches:** dimensions can be arranged in a chain, each measured from the last, or in parallel, all measured from one datum — and the skilled drafter chooses the arrangement that describes the object with the fewest, clearest lines.
**This lesson's own level:** it stands on the two lessons before it in this unit — the parts of a dimension, and size versus location (teacher evidence). This is a doing lesson: most of it is drawing.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. The words carry the picture while the course is built and while the AI learns from the books; on the website the real add-on is dropped into that slot and the little explanation stays as the student's guide.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Chain arrangement — each from the last** — dimensions placed end to end in one line, each step measured from the previous feature.
2. **Parallel arrangement — all from one datum** — every location measured from a single chosen face or line, so no error can accumulate.
3. **Choosing well — fewer lines, nothing missing** — selecting dimensions to reduce the number of dimension lines, and preparing dimensions across different views.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Size and location dimensions — the theory. Recommended, never forced.

## What the learner can do when it ends
1. Dimension a stepped object in chain arrangement and say where its weakness lies.
2. Dimension the same object in parallel arrangement from one datum face, and say what it gains.
3. Choose between the two methods for a given object and defend the choice.
4. Reduce the number of dimension lines by selecting dimensions well, without leaving any feature undescribed.
5. Spread dimensions across the views of a drawing, each where it reads best.

## What you need
Paper, a sharp pencil, a ruler and an eraser.

1. **Do it first** — Draw a bar with three steps. Now ask: if you dimension the steps one after another like links, and the first step is made slightly wrong, what happens to the position of the last step? Hold your answer — the lesson names the two arrangements and their trade. (lesson/lesson.md).
