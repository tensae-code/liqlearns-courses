# Arranging Dimensions — the Two Methods — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** In chain arrangement, each dimension is measured from —
a) one common datum face  b) the previous feature  c) the centre of the sheet
**Answer: b) the previous feature**

**2. (Sub lesson 1)** The weakness of chain arrangement is that —
a) it uses too much paper  b) small making errors add up along the chain and move the last features  c) it needs no arrowheads
**Answer: b) small making errors add up along the chain and move the last features**

**3. (Sub lesson 2)** In parallel arrangement, every location is measured from —
a) one common datum  b) the last feature drawn  c) each other feature in turn
**Answer: a) one common datum**

**4. (Sub lesson 2)** Parallel dimension lines are placed —
a) at random  b) shortest nearest the object, longest outside  c) all crossing the object
**Answer: b) shortest nearest the object, longest outside**

**5. (Sub lesson 3)** A dimension should be removed from a drawing when —
a) its size is already fully fixed by the other dimensions given  b) it is a diameter  c) the drawing looks crowded, even if the feature is then undescribed
**Answer: a) its size is already fully fixed by the other dimensions given**

**6. (Sub lesson 3)** Dimensions should be spread —
a) all onto one view  b) across the views, each on the view that shows its feature most clearly  c) onto the title block
**Answer: b) across the views, each on the view that shows its feature most clearly**
