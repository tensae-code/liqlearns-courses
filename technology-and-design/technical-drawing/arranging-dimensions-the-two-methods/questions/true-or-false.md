# Arranging Dimensions — the Two Methods — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** Chain dimensioning is compact and suits objects where each step's own size matters most. — **True**

**2. (Sub lesson 2)** In parallel arrangement, an error in one feature's position shifts all the later features. — **False** (each is measured independently from the datum)

**3. (Sub lesson 3)** Giving the same size twice on a drawing is harmless. — **False** (the two figures can be made to contradict, and the maker cannot know which governs)

**4. (Sub lesson 3)** Reducing the number of dimension lines must never leave a feature without its size or its place. — **True**
