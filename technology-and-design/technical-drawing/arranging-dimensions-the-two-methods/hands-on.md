# Hands-on — Arranging Dimensions — the Two Methods

The lesson with your hands, not only your eyes.

## The accumulating error, measured
On a long strip of paper, mark three steps in a chain, measuring each from the last mark, deliberately rounding each measurement up by 1. Measure where the last mark lands against the true total. Now mark the same steps from one end only, rounding the same way. Compare the two last marks — the chain has drifted, the datum marks have not.

## Fewest lines challenge
Take a dimensioned drawing from this unit and, with a partner, try to remove one dimension line without leaving any feature undescribed. If you can, the drawing was carrying a repeated size; if you cannot, say why each line earns its place.
