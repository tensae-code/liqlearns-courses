# Graphic information and the kinds of drawings — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is graphic information?
a) Information about an object carried by an image b) A story told aloud only c) A list of prices d) Music written for an instrument
**Answer: a) Information about an object carried by an image**

**2. (Sub lesson 1)** Which is a pictorial (visual) image?
a) A dimensioned technical drawing b) A photograph of the object c) A wiring scheme d) A bar chart
**Answer: b) A photograph of the object**

**3. (Sub lesson 2)** Which belongs to graphic images proper?
a) A holiday snapshot b) A realistic portrait painting c) A technical drawing made to rules d) A word description
**Answer: c) A technical drawing made to rules**

**4. (Sub lesson 2)** Why can a maker work from a technical drawing?
a) It is the most colourful image b) It gives exact shape and size to rules c) It shows the object as the eye sees it d) It needs no reading
**Answer: b) It gives exact shape and size to rules**

**5. (Sub lesson 3)** What should a reader do first with an image?
a) Copy it in colour b) Name its kind, then read what that kind can tell c) Measure every line at once d) Ignore its labels
**Answer: b) Name its kind, then read what that kind can tell**
