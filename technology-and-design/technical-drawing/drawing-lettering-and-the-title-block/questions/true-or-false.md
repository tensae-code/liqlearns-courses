# Drawing lettering and the title block — true or false

Say whether each statement is true or false.

**1. (Sub lesson 2)** The title block is an optional decoration.
**Answer: False** — It is part of executing the drawing and names it.

**2. (Sub lesson 3)** Letters on a drawing may be any height that fits.
**Answer: False** — Lettering follows the standard font with set heights.

**3. (Sub lesson 1)** A standard layout helps a reader find views and dimensions.
**Answer: True** — Everything sits where the standard puts it.
