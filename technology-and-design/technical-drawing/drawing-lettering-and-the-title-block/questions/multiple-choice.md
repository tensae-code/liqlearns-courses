# Drawing lettering and the title block — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Why are sheet formats standard?
a) For decoration b) So any reader finds the drawing's parts in the same place c) To make sheets expensive d) So no title block is needed
**Answer: b) So any reader finds the drawing's parts in the same place**

**2. (Sub lesson 2)** What is the title block (асноўны надпіс)?
a) A decorative border b) The ruled box naming the drawing — object, maker, scale, sheet c) The largest view d) A list of instruments
**Answer: b) The ruled box naming the drawing — object, maker, scale, sheet**

**3. (Sub lesson 3)** Drawing lettering differs from handwriting because…
a) It is always joined up b) It follows a standard font with set heights c) It is written as fast as possible d) Each drafter invents a style
**Answer: b) It follows a standard font with set heights**

**4. (Sub lesson 2)** When is the title block filled in?
a) Never b) Months later c) As part of executing the drawing d) Only if the drawing is sold
**Answer: c) As part of executing the drawing**

**5. (Sub lesson 3)** Guide lines for lettering are used to…
a) Hide the letters b) Keep every letter the same height c) Replace the title block d) Draw the views
**Answer: b) Keep every letter the same height**
