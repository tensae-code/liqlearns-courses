# Lesson plan — Navigation

**Course:** Technology and Design · **Title:** Technical Drawing · **Lesson:** Navigation
**Place in the curriculum:** Technical Drawing (CURRICULUM.md) — stocked in the Fiji expansion, 2026-11-17.
**The one thing this lesson teaches:** navigation — nautical charts, modern navigation, basic directions, bearings/fixes/lines of position, dead reckoning, danger bearing, leeway, distance–speed–time.
**This lesson's own level:** it stands on Fiji student textbook(s) — see lesson/sources.md for the full record of each book. It counts in the acceptance count (student textbook, not evidence-only).

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. Picture and GIF numbers are assigned in a later media pass; the slots below are described in words.

## Sub lessons
1. **What navigation is** — Nautical charts, modern navigation, basic directions, bearings/fixes/lines of position, dead reckoning, danger bearing, leeway, distance–speed–time.
2. **The parts and how they fit together** — The named parts, terms and steps of the topic, taken in order.
3. **Using it well — and checking your work** — Applying the topic to a real task and checking the result against the lesson's own rules.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
