# Threads on drawings — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A thread drawing shows every turn of the helix.
**Answer: False** — Threads are represented conventionally, with set crest and root lines.

**2. (Sub lesson 2)** Internal and external threads use the same case on a drawing.
**Answer: False** — Each has the convention for its case, and the reader tells them apart by it.

**3. (Sub lesson 3)** A designation can include pitch where needed.
**Answer: True** — Kind, nominal size, and pitch or length where needed.
