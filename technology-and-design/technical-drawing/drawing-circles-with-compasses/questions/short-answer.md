# Drawing circles with compasses — short answer

Answer in one or two sentences.

**1. (Sub lesson 1)** Say in one sentence what this lesson teaches.
**Answer:** Drawing circles with compasses — The parts of the compasses, how to set and check them, drawing a circle, radius R and diameter, the 360° circle; exercises with R40 and a 60 mm diameter.

**2. (Sub lesson 2)** Name one material, tool or step this lesson works with.
**Answer:** Any one named in the lesson text — for example, the first step of sub lesson 1: Drawing circles with compasses.
