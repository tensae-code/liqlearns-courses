# Lesson plan — Reading technical drawings

**Course:** Technology and Design · **Title:** Technical Drawing · **Lesson:** Reading technical drawings
**Place in the curriculum:** Technical Drawing (CURRICULUM.md) — stocked in the Belarus expansion, 2026-11-17.
**The one thing this lesson teaches:** reading a drawing is an order, not a glance — title block first, then the views, the dimensions and the technical requirements, until the part's shape is fully understood.
**This lesson's own level:** it stands on a student textbook — Belarus's *Чарчэнне (Technical Drawing / Drafting), Grade 9*, by В. Н. Вінаградаў (V. N. Vinogradov), National Institute of Education, Minsk, 2008 (see lesson/sources.md). It counts in the acceptance count (student textbook, not evidence-only).

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. Picture and GIF numbers are assigned in a later media pass; the slots below are described in words.

## Sub lessons
1. **What a finished drawing tells you** — A finished drawing tells you what the object is, its shape in every view, its true sizes, and the requirements it must meet.
2. **The order of reading — title block first** — Belarus teaches a set order for reading a part's drawing: begin with the title block, which names the part and gives the scale and material; only then turn to the views.
3. **Views, dimensions and requirements** — After the title block, read the views to build the shape in your mind, then the dimensions for true sizes, then the technical requirements.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
