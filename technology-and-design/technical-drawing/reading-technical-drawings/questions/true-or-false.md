# Reading technical drawings — true or false

Say whether each statement is true or false.

**1. (Sub lesson 2)** You should start reading from the biggest view.
**Answer: False** — Belarus teaches title block first, then views, dimensions and requirements.

**2. (Sub lesson 3)** Reading ends when you have seen every line once.
**Answer: False** — It ends when the part's shape is fully understood.

**3. (Sub lesson 1)** A finished drawing can tell you the requirements a part must meet.
**Answer: True** — Technical requirements are part of what the drawing carries.
