# Secondary auxiliary views — projecting a projection — short answer

Answer in one or two sentences, or by doing the drawing step named.

**1. (Sub lesson 1)** Why is one auxiliary view not enough for an oblique surface?
**Answer:** One auxiliary plane can only be set parallel to one direction at a time, and the surface has no edge view to start from; the first projection must first win an edge view.

**2. (Sub lesson 3)** Give the four-link chain of this lesson.
**Answer:** Oblique surface → primary auxiliary view → edge view → secondary auxiliary view → true shape.
