# Secondary auxiliary views — projecting a projection — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A secondary auxiliary view is needed when a surface is…
a) normal b) inclined to one plane only c) oblique — inclined to all principal planes d) horizontal
**Answer: c) oblique — inclined to all principal planes**

**2. (Sub lesson 1)** What does the primary auxiliary view win for you?
a) The true shape at once b) An edge view of the surface (or a true-length direction) c) A pictorial view d) Nothing
**Answer: b) An edge view of the surface (or a true-length direction)**

**3. (Sub lesson 2)** Distances in the primary auxiliary view are transferred from…
a) the secondary view b) the neighbouring principal view c) your memory d) the pictorial sketch
**Answer: b) the neighbouring principal view**

**4. (Sub lesson 3)** In the secondary projection, distances are measured in…
a) the front view only b) the primary auxiliary view, from its reference line c) the object itself d) no view — they are guessed
**Answer: b) the primary auxiliary view, from its reference line**

**5. (Sub lesson 3)** The secondary auxiliary view finally shows the surface…
a) edge-on b) foreshortened c) in true shape and true size d) invisible
**Answer: c) in true shape and true size**
