# Hands-on — Secondary auxiliary views — projecting a projection

Real drawing practice with pencil and paper — this subject is learned by doing.

## The two-step build
Given front and top views of an oblique-faced block, build the primary then the secondary auxiliary view, labelling every point both times.

## Error hunt
Compare your secondary view with a partner's: any point whose distance differs is an error carried from step one — find where it entered.
