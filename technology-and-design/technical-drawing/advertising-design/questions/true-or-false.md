# Advertising design — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Poster work begins with study, not with drawing.
**Answer: True** — The stages are study first, then the production project.

**2. (Sub lesson 2)** The production project is improvised while the poster is being made.
**Answer: False** — The production project plans layout, lettering and making before production.

**3. (Sub lesson 2)** A school event gives the poster a real message and audience.
**Answer: True** — The book works the poster on a school event.
