| drawing with the computer's help (CAD): in essence it is using software to make drawings — the design software used with computers is called CAD software (Computer Aided Design), and there are now many CAD software packages serving different industries; the basic advantages of making drawings by computer (drawings are made exactly and quickly; easy to edit, supplement and store); the steps of making a drawing by computer — 1 start the software; 2 create a new drawing; 3 set up the basic parameters; 4 analyse the drawing and proceed to draw; 5 export the drawing; CAD software usually has similar command systems and ways of working, and the lesson uses AutoCAD as the example: its interface has four parts — the menu bar (the text row at the top; clicking a menu item opens the corresponding tool group), the toolbars (just below the menu; each button has its own icon for a command, the button's function shown by left-clicking it; toolbars are divided into function groups — drawing commands, dimensioning commands…), the drawing area (the largest space in the middle of the screen, below the toolbars, displaying the drawing's content, coordinate system, cursor…), and the command line (below the drawing area, for entering commands and data); the support functions — zooming and panning the screen (AutoCAD uses the mouse wheel: rolling the wheel in two opposite directions zooms in and out, holding the wheel and moving the mouse pans, double-clicking the wheel fits the whole drawing); automatic point snapping (OSNAP — type OS then press enter, the settings window appears, press OK to finish; note Endpoint, Midpoint, Centerpoint and Intersection are the end (cuối), middle, centre and intersection points; toggle automatic snapping with the F3 key); and the Ortho function for directing the Ox and Oy axes (with it on, the cursor moves only in the Ox or Oy direction — used to draw vertical or horizontal straight segments; toggle with the F8 key) (original string `drawing with the computer's help (CAD)`) | Vietnam, *Công nghệ 10 — Thiết kế và công nghệ*, printed p. 93 |
