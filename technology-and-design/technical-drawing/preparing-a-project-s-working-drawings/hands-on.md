# Hands-on — Preparing a project's working drawings

Real drawing practice with pencil and paper — this subject is learned by doing.

## Draw one object at two scales
Draw a simple block full size (1:1), then at half size (1:2). Put the true dimension on both. Measure the 1:2 drawing — it must be exactly half.

## List a full set
For a small project of your own (a lamp with an LED), list every drawing in its working set and what each one tells the maker.
