# Preparing a project's working drawings — short answer

Answer in one or two sentences, or by doing the drawing step named.

**1. (Sub lesson 2)** Why does the set need both a 1:1 drawing and 1:2 views?
**Answer:** The 1:1 working drawing lets the maker check parts at true size; the 1:2 views show the whole idea on the page at a glance.

**2. (Sub lesson 1)** What is a working drawing?
**Answer:** The exact, full-size drawing of the project, with true sizes, that the maker builds from.
