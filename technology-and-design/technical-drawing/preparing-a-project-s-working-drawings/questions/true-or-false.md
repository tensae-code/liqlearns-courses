# Preparing a project's working drawings — true or false

Say whether each statement is true or false.

**1. (Sub lesson 2)** At scale 1:2 the object itself becomes half size.
**Answer: False** — Only the drawing is half size; the object and its written dimensions stay true.

**2. (Sub lesson 3)** A complete working set includes the circuit's schematic and layout.
**Answer: True** — Both circuit drawings belong in the project's set.

**3. (Sub lesson 1)** The working drawing may be approximate, since the maker can guess.
**Answer: False** — The working drawing is the master drawing — it must be exact.
