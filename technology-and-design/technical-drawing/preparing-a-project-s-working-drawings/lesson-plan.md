# Lesson plan — Preparing a project's working drawings

**Course:** Technology and Design · **Title:** Technical Drawing · **Lesson:** Preparing a project's working drawings
**Place in the curriculum:** Technical Drawing (CURRICULUM.md) — stocked in the Malta expansion, 2026-11-17.
**The one thing this lesson teaches:** a project's working drawings are a set: the full-size working drawing at 1:1, the idea's plan and front views at 1:2, and the circuit's schematic and layout diagrams — everything a maker needs to build the project from paper.
**This lesson's own level:** it stands on a student workbook — Malta's *Design and Technology — Graphical Communication Component — Workbook 2 ("Communicate Graphically")*, Directorate for Quality and Standards in Education, Malta, 2015 (see lesson/sources.md). It counts in the acceptance count (student workbook, not evidence-only).

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. Picture and GIF numbers are assigned in a later media pass; the slots below are described in words.

## Sub lessons
1. **The full-size working drawing at 1:1** — The working drawing is the drawing the maker builds from: the project drawn full size, at scale 1:1, with the true sizes on it.
2. **Plan and front views at 1:2** — The project idea is also shown in plan (from above) and front view at scale 1:2 — half size — so the whole idea fits the page and can be read at a glance.
3. **The circuit drawings in the set** — An electronic project needs its circuit drawn too: the schematic (symbols, how it connects) and the circuit layout (where the parts sit).

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: the earlier lessons of Technical Drawing. Recommended, never forced.

## What the learner can do when it ends
1. Say what each drawing in a project's working-drawing set is for.
2. Explain scale 1:1 and scale 1:2, and why the written sizes stay true at both.
3. Name the circuit drawings in the set and the parts in the workbook's worked example.
## What you need
A pencil, a ruler, set squares and plain or grid paper.
