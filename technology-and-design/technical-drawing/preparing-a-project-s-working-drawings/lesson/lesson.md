# Preparing a project's working drawings

## Do it first
Draw a simple block full size (1:1), then at half size (1:2). Put the true dimension on both. Measure the 1:2 drawing — it must be exactly half.

## Sub lesson 1 — The full-size working drawing at 1:1
The working drawing is the drawing the maker builds from: the project drawn full size, at scale 1:1, with the true sizes on it. At 1:1 a length on the paper is the length on the thing, so parts can be checked against the drawing directly. This is the master drawing of the set — the one that must be exact.

## Sub lesson 2 — Plan and front views at 1:2
The project idea is also shown in plan (from above) and front view at scale 1:2 — half size — so the whole idea fits the page and can be read at a glance. At 1:2 every length on paper is half the true length; the dimensions written on the drawing still state the true sizes. The workbook's set teaches both scales side by side: same project, two scales, true sizes unchanged.

## Sub lesson 3 — The circuit drawings in the set
An electronic project needs its circuit drawn too: the schematic (symbols, how it connects) and the circuit layout (where the parts sit). The workbook's worked example runs on a 9 V supply with LEDs, 330 Ω resistors and a switch. A complete set — working drawing, views, schematic, layout — is what 'preparing a project's working drawings' means: nothing the maker needs is left in the designer's head.

## Say it to your companion
Explain in your own words: a project's working drawings are a set: the full-size working drawing at 1:1, the idea's plan and front views at 1:2, and the circuit's schematic and layout diagrams — everything a maker needs to build the project from paper. Say it once plainly, then answer one question your companion asks about it.

## Do It Yourself
1. Do the Do it first task again, carefully this time, using everything the lesson taught.
2. Check your work against the lesson's own checks — fix one thing you find.
3. Keep the sheet: it is practice evidence, and the next lesson builds on it.
