# Topographic drawing — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Topographic drawing (dibujo topográfico) is drawing that represents the land and its features.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Feature has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: a thing on the land that the drawing must show — a path, a bed, a tree.

**3. (Sub lesson 2)** Plan is the drawing that places work on the land before it is done.
**Answer: True** — That is how the book teaches it.
