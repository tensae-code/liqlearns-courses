# Topographic drawing — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is topographic drawing (dibujo topográfico)?
a) drawing that represents the land and its features b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) drawing that represents the land and its features**

**2. (Sub lesson 1)** What is feature?
a) Only history b) a thing on the land that the drawing must show — a path, a bed, a tree c) Only storage d) A kind of glue
**Answer: b) a thing on the land that the drawing must show — a path, a bed, a tree**

**3. (Sub lesson 2)** What is plan?
a) Only old tools b) Only painting c) the drawing that places work on the land before it is done d) Only a price
**Answer: c) the drawing that places work on the land before it is done**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) Only decoration b) Nothing to do with this lesson c) Only history d) topographic drawing (dibujo topográfico) draws the land itself: the first notions of representing ground — its shape and features — so that work on the land can be planned on paper.
**Answer: d) topographic drawing (dibujo topográfico) draws the land itself: the first notions of representing ground — its shape and features — so that work on the land can be planned on paper.**

**5. (Sub lesson 2)** How does Cuba's book teach this?
a) As theory only, never practised b) Only in a glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Spanish
**Answer: d) Through the book's own examples, steps and project work, in Spanish**
