# Orthographic projection — points, lines, planes and surfaces — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A line seen end-on projects as a point.
**Answer: True** — End-on, all its points project to the same place.

**2. (Sub lesson 2)** A normal surface shows true shape in one principal view.
**Answer: True** — It is parallel to that plane.

**3. (Sub lesson 3)** A foreshortened view shows the true shape of a face.
**Answer: False** — Foreshortening shrinks the face; the true shape needs a parallel plane.
