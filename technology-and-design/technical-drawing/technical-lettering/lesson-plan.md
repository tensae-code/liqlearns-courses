# Lesson plan — Technical lettering

**Course:** Technology and Design · **Title:** Technical Drawing · **Lesson:** Technical lettering
**Place in the curriculum:** Technical Drawing (CURRICULUM.md) — stocked in the Malta expansion, 2026-11-17.
**The one thing this lesson teaches:** every letter and number on a drawing is printed by hand, evenly and clearly, between guidelines — so anyone can read the drawing's words and figures at a glance.
**This lesson's own level:** it stands on a student workbook — Malta's *Design and Technology — Graphical Communication Component — Workbook 1 ("Communicate Graphically")*, Directorate for Quality and Standards in Education, Malta, 2015 (see lesson/sources.md). It counts in the acceptance count (student workbook, not evidence-only).

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. Picture and GIF numbers are assigned in a later media pass; the slots below are described in words.

## Sub lessons
1. **Printing letters and numbers evenly** — Lettering is printing, not joined-up writing: each capital letter and each number is drawn as its own clear shape, all the same height, evenly spaced, so the words on a drawing can never be misread.
2. **Guidelines, grids and vertical lettering** — Guidelines are the faint ruled lines that keep lettering level and one height: you print between them, never above or below.
3. **Lettering your name and class on the drawing** — A drawing is finished when it says who made it and what it is.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: the earlier lessons of Technical Drawing. Recommended, never forced.

## What the learner can do when it ends
1. Print capital letters and numbers evenly, all one height.
2. Use guidelines and a grid to keep lettering level and upright.
3. Print your name and class on a grid so anyone can read them.
## What you need
A pencil, a ruler, plain paper and grid paper.
