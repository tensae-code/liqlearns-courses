# Technical lettering — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Lettering on a drawing is joined-up writing done neatly.
**Answer: False** — Lettering is printing — each letter stands alone, clear and even.

**2. (Sub lesson 2)** A grid helps keep each letter upright and in its own space.
**Answer: True** — The squares hold the letters vertical and evenly spaced.

**3. (Sub lesson 1)** It does not matter if letters change height along a line.
**Answer: False** — Even, one-height letters are the whole point of lettering.
