# Drawing a labelled schematic of a made device — true or false

Say whether each statement is true or false.

**1. (Sub lesson 2) A correct label can be placed so crowded that it cannot be read, and still meet the standard.**
**Answer: False — The standard is correctly AND neatly labelled.**

**2. (Sub lesson 3) The schematic and the layout diagram answer different questions.**
**Answer: True — Connections vs arrangement.**

**3. (Sub lesson 1) The schematic is checked against the real device connection by connection.**
**Answer: True**
