# Drawing instruments, materials and the drawing workplace — true or false

Say whether each statement is true or false.

**1. (Sub lesson 3)** A tidy workplace is only decoration.
**Answer: False** — It is how accurate work stays accurate.

**2. (Sub lesson 1)** Drawings have always been executed in exactly the same way.
**Answer: False** — Execution has changed through history; hand instruments stay recognisable.

**3. (Sub lesson 2)** Independent work needs its own materials, listed in the appendices.
**Answer: True** — The appendices list the additional materials for independent work.
