# Technical drawing — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Cavalier perspective is the right drawing for taking true depth measurements.
**Answer: False** — Its depth is angled and shortened; it shows shape in one view, and measuring is done from orthographic views.

**2. (Sub lesson 2)** The scale written on a drawing is part of the drawing's language.
**Answer: True** — Without the scale, lengths read off the drawing cannot be converted to real lengths.

**3. (Sub lesson 1)** In an assembly drawing, parts are identified by numbered balloons linked to a parts list.
**Answer: True** — That numbering is how the reader ties each drawn part to the nomenclature.
