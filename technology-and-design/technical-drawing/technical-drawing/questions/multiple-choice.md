# Technical drawing — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Cavalier perspective shows…
a) an object in one pictorial view, front face true shape, depth at an angle b) only the front, flat c) the inside of a solid d) a photograph, always
**Answer: a) an object in one pictorial view, front face true shape, depth at an angle**

**2. (Sub lesson 1)** An assembly drawing (dessin d'ensemble) shows…
a) the whole mechanism assembled, parts numbered for the parts list b) one part alone, enlarged c) the factory building d) only hidden lines
**Answer: a) the whole mechanism assembled, parts numbered for the parts list**

**3. (Sub lesson 2)** Scale 2:1 means…
a) the drawing is twice the real size b) the drawing is half the real size c) drawing and object are equal d) the scale is unknown
**Answer: a) the drawing is twice the real size**

**4. (Sub lesson 2)** A line measures 30 mm on a 2:1 drawing. The real length is…
a) 15 mm b) 60 mm c) 30 mm d) 2 mm
**Answer: a) 15 mm**

**5. (Sub lesson 1)** Depth edges in cavalier perspective are…
a) drawn at an angle and shortened by a set ratio b) drawn true length, straight back c) never drawn d) always hidden
**Answer: a) drawn at an angle and shortened by a set ratio**
