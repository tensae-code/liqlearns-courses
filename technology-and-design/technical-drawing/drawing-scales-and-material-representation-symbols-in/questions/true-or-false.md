# Drawing scales and material representation symbols in architectural drawing — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Centre lines are drawn in a different type from visible edges.
**Answer: True** — Each line type carries its own meaning.

**2. (Sub lesson 2)** A detail of a joint is best drawn at a small scale like 1:500.
**Answer: False** — Details take large scales such as 1:10 or 1:1 so they can be read.

**3. (Sub lesson 3)** A builder can read any private symbol a drafter invents.
**Answer: False** — Symbols work because they are standard and shared.
