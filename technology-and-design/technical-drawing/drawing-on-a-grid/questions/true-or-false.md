# Drawing on a grid — copying and enlarging — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Grid (cuadrícula) is a network of equal squares laid over a drawing for copying or rescaling.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Enlarge/reduce has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: redrawing at a bigger or smaller size by the grid method.

**3. (Sub lesson 2)** Template (plantilla) is the full-size pattern traced onto material before cutting.
**Answer: True** — That is how the book teaches it.
