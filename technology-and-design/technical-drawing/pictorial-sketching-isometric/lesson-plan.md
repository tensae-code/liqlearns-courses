# Lesson plan — Pictorial sketching — isometric sketching that someone else could build from

**Course:** Technology and Design · **Title:** Technical Drawing · **Lesson:** Pictorial sketching — isometric sketching that someone else could build from
**Place in the curriculum:** Unit 1 — Sketching and Visualization — Lesson 1.3, 3 periods (1 theory, 2 practice) (CURRICULUM.md).
**The one thing this lesson teaches:** sketching a real object in isometric pictorial view, with enough true detail — features on every side, basic dimensions, material notes — that someone else could make a similar object from your sketch.
**This lesson's own level:** it stands on teacher-guide evidence only — the Grade 12 teacher guide is the sole book in hand for this subject (see lesson/sources.md). It needs pencil, paper and the earlier lessons of its unit as recommended background, nothing else.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**.

## Sub lessons
1. **Sketching a chosen object free-hand** — Pick an object and sketch it free-hand with enough detail that someone else can make a similar object.
2. **Reading a detailed technical sketch** — Compare your sketch with a detailed technical sketch of the same kind of object.
3. **How an isometric sketch is judged** — An isometric sketch is marked on four things.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: the earlier lessons of Unit 1 — Sketching and Visualization. Recommended, never forced.

## What the learner can do when it ends
1. Sketch a chosen object in isometric pictorial view.
2. Add features on every side, basic dimensions and a material description.
3. Check a sketch against a detailed technical sketch and repair what is missing.
4. Say how an isometric sketch is marked and where the points sit.
## What you need
A soft pencil, a small object to sketch, and squared or isometric grid paper if available.
