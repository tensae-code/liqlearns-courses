# Pictorial sketching — isometric sketching that someone else could build from — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Vertical edges stay vertical in an isometric sketch.
**Answer: True** — The two horizontal directions slope away symmetrically; verticals stay vertical.

**2. (Sub lesson 2)** A sketch with no dimensions can still let someone build a similar object reliably.
**Answer: False** — Basic dimensions are required.

**3. (Sub lesson 3)** Accuracy is worth more points than lettering.
**Answer: True** — Accuracy 25 against lettering 5.
