# Pictorial sketching — isometric sketching that someone else could build from — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** An isometric sketch shows which faces in one drawing?
a) Only the front b) Top, front and side together c) Only the back d) No faces, only sizes
**Answer: b) Top, front and side together**

**2. (Sub lesson 1)** Edges that are parallel on the object should in the isometric sketch be…
a) crossing b) parallel c) curved d) missing
**Answer: b) parallel**

**3. (Sub lesson 2)** A buildable sketch must show…
a) only the prettiest side b) features on every side, basic dimensions and material c) only a title d) only shading
**Answer: b) features on every side, basic dimensions and material**

**4. (Sub lesson 3)** How many points do concepts and principles of isometric sketches carry?
a) 5 b) 20 c) 25 d) 50
**Answer: d) 50**

**5. (Sub lesson 3)** Lettering carries how many points?
a) 5 b) 20 c) 25 d) 50
**Answer: a) 5**
