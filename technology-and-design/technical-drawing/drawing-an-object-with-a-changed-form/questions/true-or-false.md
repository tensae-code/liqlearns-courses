# Drawing an object with a changed form — true or false

Say whether each statement is true or false.

**1. (Sub lesson 2)** A changed form can be shown by sketching over the old drawing.
**Answer: False** — The changed drawing is executed completely in its own right.

**2. (Sub lesson 3)** Redesigning on paper can catch an unworkable change early.
**Answer: True** — The drawing is where the change is checked before material is cut.

**3. (Sub lesson 1)** Only the look of the object matters in a change of form.
**Answer: False** — Fit, strength and use must stay workable.
