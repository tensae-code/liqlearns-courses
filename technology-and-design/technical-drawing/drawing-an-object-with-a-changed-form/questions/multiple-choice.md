# Drawing an object with a changed form — multiple choice

Pick the one right answer.

**1. (Sub lesson 2)** A drawing of an object with a changed form must be…
a) A sketch over the old drawing b) Executed completely, with views and dimensions updated c) Left with old dimensions d) Drawn without views
**Answer: b) Executed completely, with views and dimensions updated**

**2. (Sub lesson 1)** What must stay in mind when changing a form?
a) Only how it looks b) The object must still work and fit what it joins c) The old dimensions d) The sheet colour
**Answer: b) The object must still work and fit what it joins**

**3. (Sub lesson 3)** Why redesign on paper?
a) Paper is the final product b) An unworkable change is caught before material is cut c) It avoids dimensions d) It is faster to guess
**Answer: b) An unworkable change is caught before material is cut**

**4. (Sub lesson 2)** Which is NOT an executed changed drawing?
a) Updated views b) New dimensions for the change c) Old dimensions of the changed feature left standing d) A workability check
**Answer: c) Old dimensions of the changed feature left standing**

**5. (Sub lesson 1)** A change can include…
a) Changing the title only b) Altering a length, shape, or adding/removing a part c) Erasing the title block d) Ignoring fit
**Answer: b) Altering a length, shape, or adding/removing a part**
