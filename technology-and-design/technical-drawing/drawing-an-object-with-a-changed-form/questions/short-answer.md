# Drawing an object with a changed form — short answer

Answer in one or two sentences, or by doing the drawing step named.

**1. (Sub lesson 2)** Why must old dimensions of a changed feature not remain on the drawing?
**Answer:** They would contradict the new form; the executed drawing must describe only the changed object, completely and consistently.

**2. (Sub lesson 3)** Name two checks that keep a changed object workable.
**Answer:** It still fits what it joins, still holds/does its job (fit, strength, use — any two).
