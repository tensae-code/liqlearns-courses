# Drawing an object with a changed form

## Do it first
Take a simple drawn object — a bracket or a box. Change one feature on paper: make it longer, or add a hole. Redraw the affected view completely with its new dimensions, and write one line on why the object still works.

## Sub lesson 1 — Seeing what can change
A changed form starts from the existing object: which features can be altered — a length, a shape, an added or removed part — and which must stay, because the object must still work and still join to what it joins.

## Sub lesson 2 — Executing the changed drawing
The changed object is drawn as a complete drawing in its own right: views, dimensions and conventions all updated to the new form. A change sketched over an old drawing, with old dimensions left standing, is not an executed drawing.

## Sub lesson 3 — Keeping the object workable
Every change is checked against the object's job: does it still fit, still hold, still do its work? Redesigning the shape on paper is cheap; the drawing is where an unworkable change is caught before material is cut.

## Say it to your companion
Explain in your own words: redesigning on paper means executing the drawing of an object whose form has been changed — the new shape is drawn fully and correctly, while the object stays a thing that can still be made and used. Say it once plainly, then answer one question your companion asks about it.

## Do It Yourself
1. Do the Do it first task again, carefully this time, using everything the lesson taught.
2. Check your work against the lesson's own checks — fix one thing you find.
3. Keep the sheet: it is practice evidence, and the next lesson builds on it.
