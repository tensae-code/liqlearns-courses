# Lesson plan — Drawing an auxiliary view — the true shape of an inclined surface

**Course:** Technology and Design · **Title:** Technical Drawing · **Lesson:** Drawing an auxiliary view — the true shape of an inclined surface
**Place in the curriculum:** Unit 2 — Auxiliary Views — Lesson 2.2, 2 periods (1 theory, 1 practice) (CURRICULUM.md).
**The one thing this lesson teaches:** producing a complete auxiliary view of a whole object: project its features onto a plane parallel to the inclined surface, and the drawing describes that surface's true shape.
**This lesson's own level:** it stands on teacher-guide evidence only — the Grade 12 teacher guide is the sole book in hand for this subject (see lesson/sources.md). It needs pencil, paper and the earlier lessons of its unit as recommended background, nothing else.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**.

## Sub lessons
1. **Set up: the edge view and the parallel plane** — Start from the view where the inclined surface shows as a line — its edge view.
2. **Project the features across** — From every corner and feature point of the inclined surface, draw a projector at right angles to the edge view, running across the folding line into the auxiliary space.
3. **Check the true shape** — Check your work three ways.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: the earlier lessons of Unit 2 — Auxiliary Views. Recommended, never forced.

## What the learner can do when it ends
1. Find the edge view of an inclined surface and set a folding line parallel to it.
2. Project feature points at right angles and transfer their distances correctly.
3. Complete an auxiliary view of a whole object.
4. Check an auxiliary view for right angles, equal distances and correct arrangement.
## What you need
A soft pencil, plain paper, a ruler, and an object with one slanted face if you can find one.
