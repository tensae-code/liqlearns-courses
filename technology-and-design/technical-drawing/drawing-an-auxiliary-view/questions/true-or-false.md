# Drawing an auxiliary view — the true shape of an inclined surface — true or false

Say whether each statement is true or false.

**1. (Sub lesson 2)** Points must be joined in the same order as on the object.
**Answer: True** — Wrong order twists the shape.

**2. (Sub lesson 3)** A hole on the inclined surface is transferred point by point like any other feature.
**Answer: True** — Curves and holes transfer the same way.

**3. (Sub lesson 1)** Any plane will do for an auxiliary view, parallel or not.
**Answer: False** — The plane must be parallel to the surface to show its true shape.
