# Drawing an auxiliary view — the true shape of an inclined surface — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Where do you start an auxiliary view?
a) From the view where the surface shows as a line — its edge view b) From a pictorial sketch c) From the back view d) From a photograph
**Answer: a) From the view where the surface shows as a line — its edge view**

**2. (Sub lesson 1)** The folding line for the auxiliary view is drawn…
a) parallel to the edge view b) across the object c) vertically, always d) around the object
**Answer: a) parallel to the edge view**

**3. (Sub lesson 2)** Projectors from the feature points are drawn…
a) at any angle b) at right angles to the edge view c) parallel to the edge view d) as curves
**Answer: b) at right angles to the edge view**

**4. (Sub lesson 2)** A point's distance from the reference line in the auxiliary view equals…
a) half its old distance b) its distance from the corresponding reference line in the neighbouring view c) zero d) the object's height
**Answer: b) its distance from the corresponding reference line in the neighbouring view**

**5. (Sub lesson 3)** The finished auxiliary view shows the inclined surface…
a) foreshortened b) in true shape c) edge-on d) upside down
**Answer: b) in true shape**
