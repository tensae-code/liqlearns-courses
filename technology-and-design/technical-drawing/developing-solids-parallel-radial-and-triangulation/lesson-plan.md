# Lesson plan — Developing Solids — Parallel Line, Radial Line, Triangulation

**Course:** Technical Drawing · **Title:** Technical Drawing · **Lesson:** Developing Solids — Parallel Line, Radial Line, Triangulation
**Place in the curriculum:** Unit 5 — Development and Intersection (guide Lesson '6.2' — misnumbered in the guide, see sources) (CURRICULUM.md).
**The one thing this lesson teaches:** three constructions develop every common solid: parallel line for prisms and cylinders, radial line for pyramids and cones, and triangulation — built on true lengths — for solids no view shows truly.
**This lesson's own level:** it stands on the lesson before it in this unit — what a development is (teacher evidence). This is the course's biggest lesson (12 periods in the guide, 10 of them practice): it is learned at the drawing board.

## Sub lessons
The parts of this lesson, in order — the list the learner sees from the start, locked ahead, each opening when the one before it is proved:

1. **Parallel-line development — prisms and cylinders** — the stretch-out line, generators parallel to each other, each face or station at its true width.
2. **Radial-line development — pyramids and cones** — all edges radiate from the apex; swing arcs with the true slant length and step the base perimeter along them.
3. **Triangulation — true lengths, triangle by triangle** — for oblique solids whose edges no view shows truly: find every edge's true length, then build the surface as a chain of true triangles.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: Surface development — flat sheets that become things. Recommended, never forced.

## What the learner can do when it ends
1. Develop a prism and a cylinder by the parallel-line method, with the stretch-out line equal to the perimeter or circumference.
2. Develop a pyramid and a cone by the radial-line method, swinging true slant lengths from the apex.
3. Find the true length of an inclined edge by the right-triangle rule: plan length as base, difference of heights as the upright, hypotenuse as the true length.
4. Develop an oblique solid by triangulation: divide its surface into triangles and build each at its true lengths, sharing edges in order.
5. Check a finished development: every edge at true length, fold lines marked, base attached, allowances added.

## What you need
Paper and card, a ruler, a compass, dividers, scissors and a sharp pencil.
