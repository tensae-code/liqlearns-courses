# Developing Solids — Parallel Line, Radial Line, Triangulation — true or false

Say whether each sentence is true or false.

**1. (Sub lesson 1)** The widths along a prism's stretch-out line must add up to the base perimeter exactly. — **True**

**2. (Sub lesson 2)** A cone sector whose arc is shorter than the base circumference will still roll into a cone that fits its base. — **False** (the arc must equal the circumference)

**3. (Sub lesson 3)** An inclined edge's length in plan is its true length. — **False** (the plan shows it shortened; the right-triangle construction gives the true length)

**4. (Sub lesson 3)** In triangulation, the diagonals drawn across faces must also be found at true length. — **True**
