# Hands-on — Drawing standards

Real practice — this subject is learned by doing.

## Find the norm at work
Take any technical drawing. List three things on it that a norm must have decided (line kinds, lettering, layout) and say what would go wrong if each maker chose freely.

## Norm or habit?
Sort five drawing practices into 'fixed by norm' and 'maker's choice'. Defend each sorting in one sentence.
