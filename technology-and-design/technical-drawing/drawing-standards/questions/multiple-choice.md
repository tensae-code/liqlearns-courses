# Drawing standards — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is norm (norma)?
a) an agreed written rule that work must follow b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) an agreed written rule that work must follow**

**2. (Sub lesson 1)** What is Norma Cubana (NC)?
a) Only history b) Cuba's national standard, here adapted from ISO for drawing c) Only storage d) A kind of glue
**Answer: b) Cuba's national standard, here adapted from ISO for drawing**

**3. (Sub lesson 2)** What is ISO?
a) Only old tools b) Only painting c) the international standard from which the Cuban drawing norm is adapted d) Only a price
**Answer: c) the international standard from which the Cuban drawing norm is adapted**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) Only decoration b) Nothing to do with this lesson c) Only history d) a norm (Norma Cubana, NC-ISO) is the agreed rule that makes drawings readable by everyone: what a norm is, why drawings follow one, and how the Cuban norm adapts the ISO standard.
**Answer: d) a norm (Norma Cubana, NC-ISO) is the agreed rule that makes drawings readable by everyone: what a norm is, why drawings follow one, and how the Cuban norm adapts the ISO standard.**

**5. (Sub lesson 2)** How does Cuba's book teach this?
a) As theory only, never practised b) Only in a glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Spanish
**Answer: d) Through the book's own examples, steps and project work, in Spanish**
