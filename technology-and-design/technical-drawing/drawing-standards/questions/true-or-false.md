# Drawing standards — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Norm (norma) is an agreed written rule that work must follow.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Norma cubana (nc) has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: Cuba's national standard, here adapted from ISO for drawing.

**3. (Sub lesson 2)** Iso is the international standard from which the Cuban drawing norm is adapted.
**Answer: True** — That is how the book teaches it.
