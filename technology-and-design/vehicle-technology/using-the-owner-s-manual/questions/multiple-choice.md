# Using the owner's manual — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is owner's manual?
a) the book written for one exact car model, the authority for its care b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) the book written for one exact car model, the authority for its care**

**2. (Sub lesson 1)** What is coolant?
a) Only history b) the fluid that carries the engine's heat to the radiator c) Only storage d) A kind of glue
**Answer: b) the fluid that carries the engine's heat to the radiator**

**3. (Sub lesson 2)** What is periodic check?
a) Only old tools b) Only painting c) an inspection done on a regular cycle, before failure d) Only a price
**Answer: c) an inspection done on a regular cycle, before failure**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) Only decoration b) Nothing to do with this lesson c) Only history d) the owner's manual is the car's own book: it fixes the periodic fluid checks — coolant, brake fluid, engine oil, battery fluid and windscreen-washer fluid — and how each is done.
**Answer: d) the owner's manual is the car's own book: it fixes the periodic fluid checks — coolant, brake fluid, engine oil, battery fluid and windscreen-washer fluid — and how each is done.**

**5. (Sub lesson 2)** How does Iran's book teach this?
a) As theory only, never practised b) Only in a glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Persian
**Answer: d) Through the book's own examples, steps and project work, in Persian**
