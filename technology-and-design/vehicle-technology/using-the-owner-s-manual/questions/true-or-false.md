# Using the owner's manual — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Owner's manual is the book written for one exact car model, the authority for its care.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Coolant has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: the fluid that carries the engine's heat to the radiator.

**3. (Sub lesson 2)** Periodic check is an inspection done on a regular cycle, before failure.
**Answer: True** — That is how the book teaches it.
