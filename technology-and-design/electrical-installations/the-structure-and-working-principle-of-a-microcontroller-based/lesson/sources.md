| the structure and working principle of a microcontroller-based automatic warning system: the general structure in a block diagram (sensor block → central control block → actuator block, with the user-interaction block exchanging with the centre), the blocks' roles (the sensor block supplying information about the monitored environment by converting physical quantities such as temperature and smoke concentration into electrical signals through sensors; the central control block processing the information from the sensors and issuing control commands to the program written and installed beforehand — the microcontroller integrated on a development board, whose electrical and mechanical interfaces make connecting sensors and actuators convenient and programming from a computer easy; the actuator block executing the commands — alarm buzzers, warning lights, phone calls or messages to preset numbers, opening water-spray valves; the user-interaction block — display screens and keypads for setting the system's working mode, today also phone applications), and the closed working cycle (collect information — sensors placed around the monitored object convert the quantities into analogue signals, digitised by the ADC on the microcontroller board; process the information and issue commands — the microcontroller works to its installed program and decides whether a warning situation exists, in normal state staying in a default mode with preset parameters, or taking user input through the interaction block to set the mode; execute the actions — sound the alarm, light the warning lamp, spray water, or notify the user by screen, message or phone call; the results change the monitored object's state and the sensors collect again in the next loop, giving continuous monitoring and warning) (original string `the structure and working principle of a microcontroller-based automatic warning system`) | Vietnam, *Chuyên đề học tập Công nghệ 12 — Công nghệ điện – điện tử*, printed p. 8 |
