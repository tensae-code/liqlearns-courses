# Reading a real wiring diagram — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is wiring diagram?
a) the drawing that shows how every wire and part in an installation connects b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) the drawing that shows how every wire and part in an installation connects**

**2. (Sub lesson 1)** What is tracing?
a) Only history b) following a wire run on the diagram from start to end, naming every part it touches c) Only storage d) A kind of glue
**Answer: b) following a wire run on the diagram from start to end, naming every part it touches**

**3. (Sub lesson 2)** What is wire run?
a) Only old tools b) Only painting c) the path one wire takes between the parts it joins d) Only a price
**Answer: c) the path one wire takes between the parts it joins**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) Only decoration b) Nothing to do with this lesson c) Only history d) a wiring diagram is the circuit's map: it shows how every wire and part connects, and reading it truly — tracing each run — comes before touching a wire.
**Answer: d) a wiring diagram is the circuit's map: it shows how every wire and part connects, and reading it truly — tracing each run — comes before touching a wire.**

**5. (Sub lesson 2)** How does Iran's book teach this?
a) As theory only, never practised b) Only in a glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Persian
**Answer: d) Through the book's own examples, steps and project work, in Persian**
