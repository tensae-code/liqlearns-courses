# Reading a real wiring diagram — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Wiring diagram is the drawing that shows how every wire and part in an installation connects.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Tracing has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: following a wire run on the diagram from start to end, naming every part it touches.

**3. (Sub lesson 2)** Wire run is the path one wire takes between the parts it joins.
**Answer: True** — That is how the book teaches it.
