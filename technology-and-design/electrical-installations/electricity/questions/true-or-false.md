# Electricity — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Conductor is a material that lets electric current pass.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Insulator has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: a material that blocks electric current.

**3. (Sub lesson 2)** Magnetic effect is the current's power to make magnetism, as in an electromagnet.
**Answer: True** — That is how the book teaches it.
