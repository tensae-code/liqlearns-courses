# Electricity at home and school — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Cable is conductors gathered together, each insulated, in one covering.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Neon tester has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: a small tester whose lamp glows when voltage is present.

**3. (Sub lesson 2)** Energy-saving plan is a written set of measures to reduce electricity consumption.
**Answer: True** — That is how the book teaches it.
