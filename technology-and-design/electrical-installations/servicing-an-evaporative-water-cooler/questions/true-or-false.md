# Servicing an evaporative (water) cooler — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Evaporative cooler is the cooler that cools air by passing it through wet pads.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Pads has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: the water-holding mats across the air's path where evaporation cools it.

**3. (Sub lesson 2)** Periodic service is maintenance done on a regular cycle, before failure.
**Answer: True** — That is how the book teaches it.
