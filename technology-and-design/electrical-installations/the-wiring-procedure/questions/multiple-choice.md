# The wiring procedure — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is wiring procedure?
a) the fixed order of wiring: lay out the parts, fix them, then connect them b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) the fixed order of wiring: lay out the parts, fix them, then connect them**

**2. (Sub lesson 1)** What is wire colours?
a) Only history b) the colour code that gives each wire's job a colour, so faults can be traced c) Only storage d) A kind of glue
**Answer: b) the colour code that gives each wire's job a colour, so faults can be traced**

**3. (Sub lesson 2)** What is fault tracing?
a) Only old tools b) Only painting c) finding a wiring fault by following the runs and colours d) Only a price
**Answer: c) finding a wiring fault by following the runs and colours**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) Only decoration b) Nothing to do with this lesson c) Only history d) all wiring follows one procedure: lay out the parts from the diagram, fix them in place, then connect them — with different wire colours so faults are easy to trace.
**Answer: d) all wiring follows one procedure: lay out the parts from the diagram, fix them in place, then connect them — with different wire colours so faults are easy to trace.**

**5. (Sub lesson 2)** How does Iran's book teach this?
a) As theory only, never practised b) Only in a glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Persian
**Answer: d) Through the book's own examples, steps and project work, in Persian**
