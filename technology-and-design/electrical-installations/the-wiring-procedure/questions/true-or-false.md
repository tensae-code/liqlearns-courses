# The wiring procedure — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Wiring procedure is the fixed order of wiring: lay out the parts, fix them, then connect them.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Wire colours has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: the colour code that gives each wire's job a colour, so faults can be traced.

**3. (Sub lesson 2)** Fault tracing is finding a wiring fault by following the runs and colours.
**Answer: True** — That is how the book teaches it.
