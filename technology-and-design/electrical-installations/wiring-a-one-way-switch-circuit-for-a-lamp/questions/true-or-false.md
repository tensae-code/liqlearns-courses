# Wiring a one-way switch circuit for a lamp — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** One-way switch is a switch that controls a lamp from one place.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Live conductor has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: the wire carrying the supply's power, which the switch must interrupt.

**3. (Sub lesson 2)** Lamp circuit is the circuit joining supply, switch and lamp.
**Answer: True** — That is how the book teaches it.
