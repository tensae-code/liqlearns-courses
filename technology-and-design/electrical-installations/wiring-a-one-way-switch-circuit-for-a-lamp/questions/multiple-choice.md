# Wiring a one-way switch circuit for a lamp — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is one-way switch?
a) a switch that controls a lamp from one place b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) a switch that controls a lamp from one place**

**2. (Sub lesson 1)** What is live conductor?
a) Only history b) the wire carrying the supply's power, which the switch must interrupt c) Only storage d) A kind of glue
**Answer: b) the wire carrying the supply's power, which the switch must interrupt**

**3. (Sub lesson 2)** What is lamp circuit?
a) Only old tools b) Only painting c) the circuit joining supply, switch and lamp d) Only a price
**Answer: c) the circuit joining supply, switch and lamp**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) Only decoration b) Nothing to do with this lesson c) Only history d) the one-way switch circuit is wiring's first complete job: supply, one switch, one lamp — connected so the switch, and only the switch, commands the light.
**Answer: d) the one-way switch circuit is wiring's first complete job: supply, one switch, one lamp — connected so the switch, and only the switch, commands the light.**
