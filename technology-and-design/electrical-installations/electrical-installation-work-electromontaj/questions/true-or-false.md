# Electrical installation work (electromontaj) — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Component knowledge comes before installation work in the book's order.
**Answer: True** — First study the components — then design, execute and fix.

**2. (Sub lesson 2)** Fault-finding needs no knowledge of how parts should work.
**Answer: False** — Diagnosis is component knowledge at work.

**3. (Sub lesson 2)** Starter relays are among the components studied.
**Answer: True** — Electromagnet, electric motor and starter relays are the named three.
