# Repairing electrical installations — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Continuity is whether a path for the current is unbroken from end to end.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Receptacle (toma) has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: the fixed socket into which a plug is inserted.

**3. (Sub lesson 2)** Fault is the break or defect that stops a circuit working.
**Answer: True** — That is how the book teaches it.
