# Biotechnology — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Biotechnology is using living systems — cells, microbes, enzymes — as technology.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Cell has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: the smallest unit of living systems.

**3. (Sub lesson 2)** Biofuel is fuel made from waste or plant matter by living processes.
**Answer: True** — That is how the book teaches it.
