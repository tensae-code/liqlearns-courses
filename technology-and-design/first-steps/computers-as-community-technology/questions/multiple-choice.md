# Computers as community technology — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What does a computer do with information?
a) It takes it in, processes it, stores it and displays it b) It eats it c) It hides it forever d) It turns it into paper only
**Answer: a) It takes it in, processes it, stores it and displays it**

**2. (Sub lesson 2)** Which computer serves one person at a desk?
a) A personal computer b) A mainframe c) A supercomputer d) A stove
**Answer: a) A personal computer**

**3. (Sub lesson 2)** What is a supercomputer built for?
a) Very large problems, like weather forecasting b) Making tea c) One person's homework only d) Nothing
**Answer: a) Very large problems, like weather forecasting**

**4. (Sub lesson 3)** Who designs the programs computers run?
a) Software engineers b) Plumbers c) Hunters d) Bakers
**Answer: a) Software engineers**

**5. (Sub lesson 3)** Who fixes and maintains computer machines?
a) Technicians b) IT managers only c) Nobody d) The computers fix themselves
**Answer: a) Technicians**
