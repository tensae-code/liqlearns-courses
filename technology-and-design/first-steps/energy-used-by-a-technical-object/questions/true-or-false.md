# Energy used by a technical object \u2014 true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Energy is needed to make objects, not only to run them.
**Answer: True** \u2014 The guides teach that making an object uses energy before the object is ever used.

**2. (Sub lesson 2)** Wood, oil and sunlight are all renewable sources.
**Answer: False** \u2014 Sunlight is renewable; oil is non-renewable, and wood is listed with the non-renewable sources in the Grade 3 guide.

**3. (Sub lesson 3)** A bicycle runs on muscular energy.
**Answer: True** \u2014 The rider's muscles are the bicycle's energy source.
