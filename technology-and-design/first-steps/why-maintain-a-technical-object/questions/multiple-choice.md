# Why maintain a technical object \u2014 multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Which is NOT a gain of maintenance?
a) The object keeps working b) The object lasts longer c) The object never needs checking again d) The object keeps its appearance
**Answer: c) The object never needs checking again**

**2. (Sub lesson 1)** Maintenance is\u2026
a) Regular care that keeps an object in working order b) Throwing an object away c) Buying a new object d) Painting over rust
**Answer: a) Regular care that keeps an object in working order**

**3. (Sub lesson 2)** Why is bicycle maintenance a safety matter?
a) Bicycles are expensive b) Worn brakes or a loose chain can fail on the road and hurt the rider c) It makes the bicycle heavier d) It changes the bicycle's colour
**Answer: b) Worn brakes or a loose chain can fail on the road and hurt the rider**

**4. (Sub lesson 2)** When an object's failure could hurt someone, maintenance is\u2026
a) Optional decoration b) A safety duty c) A waste of time d) Only for teachers
**Answer: b) A safety duty**

**5. (Sub lesson 1)** A neglected object usually\u2026
a) Improves by itself b) Fades, loosens and stops working c) Lasts longest d) Needs no parts
**Answer: b) Fades, loosens and stops working**
