# Hands-on \u2014 Why maintain a technical object

Real practice \u2014 this subject is learned by doing.

## Care comparison
Find a maintained and a neglected example of the same kind of object. Write three differences and trace each to a care that was done or skipped.

## Safety list
For a bicycle, list what could fail if never maintained, and beside each failure write who it could hurt. Present the list: maintenance as safety.
