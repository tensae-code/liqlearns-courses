# Eco-design \u2014 true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Eco-design only cares whether the object works.
**Answer: False** \u2014 Eco-design also asks about need, materials and end of life, from the start.

**2. (Sub lesson 2)** A prototype is the finished object sold to users.
**Answer: False** \u2014 A prototype is a first version built to test and learn from.

**3. (Sub lesson 2)** An eco-designed object should be repairable.
**Answer: True** \u2014 Repairability is one of the impact questions the prototype must answer.
