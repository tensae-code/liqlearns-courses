# Technology as a system — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Describing a system means listing its parts and nothing else.
**Answer: False** — A system is described by its functions and behaviour — inputs, transformation, outputs — not by a parts list alone.

**2. (Sub lesson 2)** The same system can be described from several points of view.
**Answer: True** — User, maker and maintainer each reveal different functions of the same system.

**3. (Sub lesson 2)** The life cycle of a system ends when it is sold.
**Answer: False** — Use, maintenance and end of life follow the making; the cycle runs from need expression to retirement.
