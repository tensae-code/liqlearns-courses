# Hands-on — Technology as a system

Real practice — this subject is learned by doing.

## System description sheet
Choose one system. Write: its function of use in one sentence; its inputs; what happens inside; its outputs. Add one line for each point of view — user, maker, maintainer.

## Life-cycle walk
For the same system, write one sentence for each life-cycle phase: the need, the specification, the making, the using, the maintaining, the end of life. Check your Cdcf sentence says what the system must do, not how it is built.
