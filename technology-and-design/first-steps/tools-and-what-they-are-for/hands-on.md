# Hands-on \u2014 Tools and what they are for

Real practice \u2014 this subject is learned by doing.

## Tool census
Count and list the tools in one room of your home. Write each tool's use beside it. Mark any tool whose use you do not know, and find out.

## Trade match
On cards, write six tools and six jobs separately. Shuffle and match each tool to its job, then to its trade. Explain one match aloud.
