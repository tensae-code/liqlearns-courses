# Hands-on \u2014 Parts of an object and the function of each part (ballpoint pen)

Real practice \u2014 this subject is learned by doing.

## Pen autopsy
Dismantle a ballpoint pen over a tray. Draw each part, label it, and write its function. Reassemble the pen and test that it writes.

## Ordinary vs retractable
If you have both kinds, dismantle a retractable pen too. Which parts are the same? Which are different, and what extra job does the click mechanism do?
