# Parts of an object and the function of each part (ballpoint pen) \u2014 true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Every part of the pen has the same function.
**Answer: False** \u2014 Each part has its own function \u2014 storing, holding, rolling, protecting, closing.

**2. (Sub lesson 2)** The ball rolls as you write and carries ink onto the paper.
**Answer: True** \u2014 That rolling ball is what makes it a ballpoint pen.

**3. (Sub lesson 1)** Ordinary and retractable pens have exactly the same parts.
**Answer: False** \u2014 The guides compare the two kinds; the retractable pen has its own mechanism parts beside the shared ones.
