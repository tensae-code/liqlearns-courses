# Hands-on — The need

Real practice — this subject is learned by doing.

## Need hunt
Take three objects around you. For each one, write the need it answers in one sentence that does not name the object. Swap with a partner: can they guess the object from the need alone?

## Client or user?
Pick one product — a school bag, a bus, a kettle. List everyone it serves. Mark each person C (client: asked for or paid for it) or U (user: uses it), and mark each client internal or external.
