# Hands-on \u2014 The function of a technical object

Real practice \u2014 this subject is learned by doing.

## Function hunt
Find five technical objects at home or school. For each, write its function in one sentence. For every tool, add the trade that uses it.

## Main or extra?
Take one object with more than one function \u2014 a bicycle, a phone, a bag. List its main function, its secondary functions, and what its esteem function is (look, brand). Present the three lists to a partner.
