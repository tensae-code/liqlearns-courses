# The function of a technical object

## Do it first
Pick up three made things near you \u2014 a pen, a cup, a tool. For each one, say in one sentence what it is for. If it is a tool, name the trade that uses it. You have just done the first job of technologie: identifying a technical object by its function.

## Sub lesson 1 \u2014 What a technical object is
Technologie means the tools and materials made by craft and industry, and the study of tools, machines and making processes. A technical object is something made by people to do a job: a hammer drives nails, a torch gives light, a bicycle carries its rider. To identify a technical object, look at what it is made to do \u2014 that job is its function.

## Sub lesson 2 \u2014 Giving a function and naming the trade
Every tool has a function you can state in one sentence: what it does for the person using it. Tools also belong to trades: the mason's trowel, the carpenter's saw, the tailor's scissors. When you meet a new tool, ask two questions: what is it for, and who uses it in their work? Answering both fixes the tool in your mind.

## Sub lesson 3 \u2014 Use function and esteem function
A technical object can have more than one function. The use function answers the need directly: a bicycle carries its rider. A main function can have secondary functions beside it: the same bicycle can also carry another person or goods. Objects also have an esteem function: how a thing looks, and its brand, influence which one a person chooses, even when two objects do the same job.

## Say it to your companion
Explain in your own words: a technical object is a made thing that answers a need: to understand one, name what it is for \u2014 its function \u2014 and, for a tool, the trade that uses it. Say it once plainly, then answer one question your companion asks about it.
