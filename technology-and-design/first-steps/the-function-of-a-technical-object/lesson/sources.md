Scope: Gabon's secured books are the combined *Super Efficace* Sciences teacher guides (Biologie / Sciences physiques / Technologie / TIC in one volume). Only the Technologie strand is stocked in this course; the Biologie and Sciences physiques strands belong to the Science course and the TIC strand to the ICT course.

Gabon's own way: Gabon teaches the technical object inside the combined Sciences guide, one Technologie lesson per palier: Grade 3 starts from tools and their trades, Grade 4 defines the objet technique and its characteristics, and Grade 5 separates the use function from the esteem function on the bicycle example \u2014 the same idea climbed one step per grade.
