# The function of a technical object \u2014 true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A stone lying in a river is a technical object.
**Answer: False** \u2014 A technical object is made by people to do a job; an untouched stone is a natural object.

**2. (Sub lesson 2)** One tool can be used in more than one trade.
**Answer: True** \u2014 The placements ask for the trade or trades in which a tool is used \u2014 a tool may serve several trades.

**3. (Sub lesson 3)** The esteem function answers the user's need directly.
**Answer: False** \u2014 The use function answers the need directly; the esteem function is about appearance and brand influencing choice.
