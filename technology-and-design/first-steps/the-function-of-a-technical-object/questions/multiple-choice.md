# The function of a technical object \u2014 multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What does technologie study?
a) Tools, machines and making processes b) Only plants c) Only the weather d) Stories and songs
**Answer: a) Tools, machines and making processes**

**2. (Sub lesson 1)** What is a technical object?
a) Anything found in nature untouched b) A made thing that does a job c) A picture in a book d) A word in a dictionary
**Answer: b) A made thing that does a job**

**3. (Sub lesson 2)** To understand a tool, which two questions do you ask?
a) How old is it and who sold it? b) What is it for, and which trade uses it? c) How heavy is it and what colour? d) Where was it bought and for how much?
**Answer: b) What is it for, and which trade uses it?**

**4. (Sub lesson 3)** A bicycle carrying its rider is showing its\u2026
a) Esteem function b) Use function c) Brand d) Colour
**Answer: b) Use function**

**5. (Sub lesson 3)** Choosing one bag over another because of its look and brand is the\u2026
a) Use function b) Main function c) Esteem function d) Secondary function
**Answer: c) Esteem function**
