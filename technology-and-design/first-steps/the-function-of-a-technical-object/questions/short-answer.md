# The function of a technical object \u2014 short answer

Answer in one or two sentences.

**1. (Sub lesson 1)** Say in one sentence what a technical object's function is.
**Answer:** Its function is the job it is made to do \u2014 the need it answers.

**2. (Sub lesson 3)** Give one main function and one secondary function of a bicycle.
**Answer:** Main: it carries its rider. Secondary: it can also carry another person or goods.
