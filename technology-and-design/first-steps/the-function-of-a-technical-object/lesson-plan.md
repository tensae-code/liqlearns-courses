# Lesson plan \u2014 The function of a technical object

**Course:** Technology and Design \u00b7 **Title:** First Steps \u00b7 **Lesson:** The function of a technical object
**Place in the curriculum:** First Steps (CURRICULUM.md) \u2014 stocked in the Gabon expansion, 2026-11-17.
**The one thing this lesson teaches:** a technical object is a made thing that answers a need: to understand one, name what it is for \u2014 its function \u2014 and, for a tool, the trade that uses it.
**This lesson's own level:** it stands on teacher-guide evidence only \u2014 Gabon's *Super Efficace* Sciences teacher guides (EDIG / \u00c9dicef, Institut P\u00e9dagogique National, 2024) are the books in hand for this topic (see lesson/sources.md). Teacher guides are evidence, counted nowhere in the acceptance count.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on \u2014 an image, a GIF, a video, an audio. Every slot is written as **"a picture of \u2026" in words, plus one little line saying what the student does with it**. Picture and GIF numbers are assigned in a later media pass; the slots below are described in words.

## Sub lessons
1. **What a technical object is** \u2014 Technologie studies tools, machines and making; a technical object is a made thing with a job to do.
2. **Giving a function and naming the trade** \u2014 For any tool, say what it does and name the trade or trades in which it is used.
3. **Use function and esteem function** \u2014 The use function answers a need directly; the esteem function \u2014 appearance and brand \u2014 also shapes choice.

Gate pool: all questions of the sub lesson \u2014 no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: the earlier lessons of First Steps. Recommended, never forced.

## What the learner can do when it ends
1. Say what a technical object is and what technologie studies.
2. Give a tool's function and name the trade that uses it.
3. Tell a use function from an esteem function, and a main function from a secondary one.
## What you need
Three everyday made objects, and a partner to listen.
