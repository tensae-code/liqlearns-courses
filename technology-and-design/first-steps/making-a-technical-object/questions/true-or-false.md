# Making a technical object \u2014 true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** The making run is the same whatever the object.
**Answer: True** \u2014 Gather, prepare, make, finish carries every make; only the object changes.

**2. (Sub lesson 2)** A sieve is used only in the kitchen.
**Answer: False** \u2014 Sieves work in the kitchen, in masonry and as filters.

**3. (Sub lesson 3)** The checkerboard is tested by playing a game on it.
**Answer: True** \u2014 A playable game is the proof the make succeeded.
