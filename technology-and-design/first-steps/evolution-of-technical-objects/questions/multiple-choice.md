# Evolution of technical objects — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A lignée (lineage) is a set of objects sharing…
a) The same maker b) One main function c) The same colour d) The same price
**Answer: b) One main function**

**2. (Sub lesson 1)** The main function of the ploughing lineage is…
a) Carrying water b) Turning/working the soil c) Cutting wood d) Storing grain
**Answer: b) Turning/working the soil**

**3. (Sub lesson 2)** Which is one of the five comparison points?
a) The maker's village b) Energy used c) The tool's nickname d) The shop that sold it
**Answer: b) Energy used**

**4. (Sub lesson 2)** Across a lineage, what stays the same?
a) The materials b) The main function c) The form d) The date
**Answer: b) The main function**

**5. (Sub lesson 3)** The mechanised end of the lineage draws on…
a) Only human muscle b) Animal and engine power c) Sunlight only d) No energy
**Answer: b) Animal and engine power**
