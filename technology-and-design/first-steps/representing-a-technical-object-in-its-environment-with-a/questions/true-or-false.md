# Representing a technical object in its environment, with a written description — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** The environment around a tool in a drawing is decoration.
**Answer: False** — The environment is information — scale, ground and what the tool acts on.

**2. (Sub lesson 2)** A descriptif is written to be read together with the drawing.
**Answer: True** — Words and drawing are two halves of one representation.

**3. (Sub lesson 3)** If the words and the drawing contradict each other, the representation is still complete.
**Answer: False** — A contradiction between the halves is a fault to fix before the representation communicates.
