# Lesson plan — Representing a technical object in its environment, with a written description

**Course:** Technology and Design · **Title:** First Steps · **Lesson:** Representing a technical object in its environment, with a written description
**Place in the curriculum:** First Steps (CURRICULUM.md) — stocked in the Haiti expansion, 2026-11-17.
**The one thing this lesson teaches:** a technical object is fully represented when it is shown in its environment of use together with a written description (descriptif) — the drawing shows where and how it works, the words say what it is.
**This lesson's own level:** it stands on teacher-guide evidence only — Haiti's ITAP Projet Nectar pedagogical sequences (MENFP) are the books in hand for this topic (see lesson/sources.md). Teacher guides are evidence, counted nowhere in the acceptance count.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. Picture and GIF numbers are assigned in a later media pass; the slots below are described in words.

## Sub lessons
1. **The object in its environment** — The representation places the tool where it is actually used.
2. **Writing the descriptif** — The written description completes what the drawing cannot say.
3. **Checking the pair — drawing and words together** — The representation is checked as one piece of communication.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: the earlier lessons of First Steps. Recommended, never forced.

## What the learner can do when it ends
1. Represent a tool inside its context of use.
2. Write a descriptif that completes the drawing.
3. Check a representation and its description as one pair.
## What you need
Drawing materials, a chosen mechanised tool to represent, and reference material on the tool's use.

## The run of the lesson (in order)
1. **Do it first** — the opening doing task in lesson/lesson.md.
2. **The explanation** — the sub lessons in order (lesson/lesson.md).
   - ADD IMAGE: a picture of a plough represented in its field — soil, worker and draft animal around it — with its written descriptif beside the drawing — the student finds one fact that only the environment shows and one that only the words give.
   - ADD GIF: a GIF of a bare tool outline gaining its environment piece by piece — ground, worker, load — until the scene shows the tool at work — the student names each added piece and the information it brings.
   - ADD AUDIO: a voice reading the two halves of a full representation — the object in its environment, and the written descriptif aloud — the student repeats them.
   - ADD VIDEO: a short video of the lesson demonstration — see video-script.md.
3. **Say it to your companion** — the learner explains the lesson's key rule aloud.
4. **Questions** — the questions/ files, spread over the sub lessons.
5. **Hands-on** — hands-on.md.
6. **Do It Yourself** — the closing doing block in lesson/lesson.md.
