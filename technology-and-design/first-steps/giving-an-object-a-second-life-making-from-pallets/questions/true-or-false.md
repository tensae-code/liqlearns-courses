# Giving an object a second life (making from pallets) \u2014 true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A pallet's wood is useless once its carrying life ends.
**Answer: False** \u2014 The wood is still sound; the bench is its second life.

**2. (Sub lesson 2)** Reuse can be practised as a real building project.
**Answer: True** \u2014 The bench build is reuse carried out as a making project.

**3. (Sub lesson 2)** The bench needs no test because it is made from old wood.
**Answer: False** \u2014 It is tested the honest way \u2014 by sitting on it; reused material must still prove itself.
