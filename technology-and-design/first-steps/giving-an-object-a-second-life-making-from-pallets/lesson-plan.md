# Lesson plan \u2014 Giving an object a second life (making from pallets)

**Course:** Technology and Design \u00b7 **Title:** First Steps \u00b7 **Lesson:** Giving an object a second life (making from pallets)
**Place in the curriculum:** First Steps (CURRICULUM.md) \u2014 stocked in the Gabon expansion, 2026-11-17.
**The one thing this lesson teaches:** reuse becomes a real make: reclaimed pallets, worked with saw, hammer, nails, screws and screwdriver, become a bench \u2014 an object given a second life.
**This lesson's own level:** it stands on teacher-guide evidence only \u2014 Gabon's *Super Efficace* Sciences teacher guides (EDIG / \u00c9dicef, Institut P\u00e9dagogique National, 2024) are the books in hand for this topic (see lesson/sources.md). Teacher guides are evidence, counted nowhere in the acceptance count.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on \u2014 an image, a GIF, a video, an audio. Every slot is written as **"a picture of \u2026" in words, plus one little line saying what the student does with it**. Picture and GIF numbers are assigned in a later media pass; the slots below are described in words.

## Sub lessons
1. **Reuse as a making project** \u2014 Old material is not waste when a maker sees a new object in it.
2. **Building a bench from pallets** \u2014 Saw, hammer, nails, screws and screwdriver turn pallet wood into seating.

Gate pool: all questions of the sub lesson \u2014 no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: the earlier lessons of First Steps. Recommended, never forced.

## What the learner can do when it ends
1. Explain reuse as a making project, not only a slogan.
2. List the tools and steps for the pallet bench.
3. Test a reuse make honestly: does it do its new job?
## What you need
Reclaimed pallets; saw, hammer, nails, screws and a screwdriver (or a talk-through with the tools shown).
