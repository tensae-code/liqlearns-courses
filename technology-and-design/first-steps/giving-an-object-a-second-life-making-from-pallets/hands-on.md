# Hands-on \u2014 Giving an object a second life (making from pallets)

Real practice \u2014 this subject is learned by doing.

## Second-life design
Choose one discarded item available to you. Design its second life on paper: the new object, the parts you will use, the tools needed, and the test that proves it works.

## Bench build or model
Build the pallet bench if materials and supervision allow; otherwise build a scale model of it from scrap card or sticks, following the same stages, and present both the model and the full-size plan.
