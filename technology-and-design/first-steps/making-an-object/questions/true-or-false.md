# Making an object \u2014 true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** You can join the parts before gathering any materials.
**Answer: False** \u2014 Gathering comes first; each step prepares the next.

**2. (Sub lesson 2)** A finished fan should open and close.
**Answer: True** \u2014 Opening into a half-circle and folding shut is the check that the make worked.

**3. (Sub lesson 2)** The ruler is one of the fan's materials that stays in the finished fan.
**Answer: False** \u2014 The ruler is a tool used in the making; the fan itself is paper, sticks and glue.
