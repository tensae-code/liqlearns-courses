# Board-game design project

## Do it first
Before reading on: take the materials this lesson names and try the task in your own way first. Then read how Kazakhstan's book teaches it, and compare.

## Sub lesson 1 — Board-game design project
Kazakhstan's books teach it this way (the student book, printed pp. 44–56): Board games and their history (§12); developing the board game (§13); making the game's details (§14); graphic documentation (§15); testing the game (§16); analysis and presenting the work (§§17–18) — Togyzkumalak as the worked example. The learner works through the named materials and steps in order, saying what each step does before doing the next one.

## Sub lesson 2 — Board-game design project — doing it yourself
Now the learner does the whole task unaided: board games and their history (§12); developing the board game (§13); making the game's details (§14); graphic documentation (§15); testing the game (§16); analysis and presenting the work (§§17–18) — Togyzkumalak as the worked example. Working from the first sub lesson's sequence, the learner plans the make, works through it step by step, and checks the finished piece against what the Kazakh book shows.
