# Composite materials — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Composite is a material made by joining two different materials so the mixture outperforms each part.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Matrix has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: the continuous material in a composite that binds and holds the shape.

**3. (Sub lesson 2)** Reinforcement is the stronger material embedded in a composite's matrix.
**Answer: True** — That is how the book teaches it.
