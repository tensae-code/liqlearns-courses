# Plastics as a material — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Recovered plastic is plastic saved after use and worked again into articles.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Punching block (sufridera) has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: the block that supports material while it is perforated.

**3. (Sub lesson 2)** Template (plantilla) is a pattern used to trace a shape repeatedly and exactly.
**Answer: True** — That is how the book teaches it.
