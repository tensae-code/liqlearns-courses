# Recycling as a technical chain — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Recycling is a single act: throwing waste in a bin.
**Answer: False** — It is a chain — collection, sorting, treatment, remaking — and it works only if every link works.

**2. (Sub lesson 1)** Unsorted waste can be treated as well as sorted waste.
**Answer: False** — Each material needs its own treatment; sorting by material is what makes treatment possible.

**3. (Sub lesson 2)** Glass loses its quality each time it loops.
**Answer: False** — Glass can repeat the loop — melt and remake — without losing quality.
