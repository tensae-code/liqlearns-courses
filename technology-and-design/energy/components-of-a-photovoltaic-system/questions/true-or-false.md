# Components of a photovoltaic system — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A system description missing one of the four components is still complete.
**Answer: False** — Panel, regulator, battery and inverter each hold a distinct job; omitting one leaves the system unexplained.

**2. (Sub lesson 2)** Panels and batteries work in direct current.
**Answer: True** — That is why the inverter is needed before the house's alternating-current appliances.

**3. (Sub lesson 3)** The inverter stores the system's electricity.
**Answer: False** — Storage is the battery's job; the inverter converts DC to AC.
