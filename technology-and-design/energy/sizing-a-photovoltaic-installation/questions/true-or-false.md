# Sizing a photovoltaic installation — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** An installation can be sized well without a load list.
**Answer: False** — The load list in watts is the foundation; without it the sizing is a guess.

**2. (Sub lesson 2)** The inverter must supply the summed power of the appliances running together.
**Answer: True** — Summing the appliance powers sets the inverter's size.

**3. (Sub lesson 3)** Battery capacity is measured in watts.
**Answer: False** — Battery capacity is calculated and stated in amp-hours (Ah).
