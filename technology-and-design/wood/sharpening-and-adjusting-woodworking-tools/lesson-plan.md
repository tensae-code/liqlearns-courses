# Lesson plan — Sharpening and adjusting woodworking tools

**Course:** Technology and Design · **Title:** Wood · **Lesson:** Sharpening and adjusting woodworking tools
**Place in the curriculum:** Wood (CURRICULUM.md) — stocked in the Moldova expansion, 2026-11-17.
**The one thing this lesson teaches:** woodworking tools must be sharpened and adjusted — set up — so they cut correctly; a tool out of adjustment does bad work however skilled the hand.
**This lesson's own level:** stocked from Moldova's *Educație tehnologică* (Technological Education) textbooks — see lesson/sources.md. Moldova counts in the acceptance count (student books, not evidence-only).

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. Picture and GIF numbers are assigned in a later media pass; the slots below are described in words.

## Sub lessons
1. **Sharpening — restoring the edge** — Grade 6 teaches tool care as a skill of its own: sharpening restores the cutting edge that work has dulled.
2. **Adjusting — setting up to cut correctly** — Sharpening alone is not enough: the tools of wood processing are also adjusted — set up — so they cut correctly.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: the earlier lessons of Wood. Recommended, never forced.

## What the learner can do when it ends
1. Explain why tools are sharpened and adjusted together.
2. Set up a woodworking tool so it cuts correctly.
3. Explain how Moldova's book teaches it.
## What you need
Blunt practice tools, sharpening equipment, and a safe sharpening station.
