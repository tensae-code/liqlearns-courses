# Sharpening and adjusting woodworking tools — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A skilled hand can make a blunt, unadjusted tool cut correctly.
**Answer: False** — Edge and adjustment decide the cut, however skilled the hand.

**2. (Sub lesson 1)** Sharpening and adjusting are taught as one tool-care skill.
**Answer: True** — The Grade 6 lesson joins them: set up so the tool cuts correctly.

**3. (Sub lesson 2)** A test cut belongs after set-up, on scrap.
**Answer: True** — Set-up ends by proving the cut before the real workpiece.
