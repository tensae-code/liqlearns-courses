# Hands-on — Sharpening and adjusting woodworking tools

Real practice — this subject is learned by doing.

## Edge check
Examine two tools, one keen and one dull (or clear pictures). Write how you can tell, and what each needs.

## Set-up list
For one tool you know, write its set-up checks in order: edge first, then adjustments — ending with a test cut on scrap.
