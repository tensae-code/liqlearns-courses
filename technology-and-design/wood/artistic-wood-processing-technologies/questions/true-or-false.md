# Artistic wood processing technologies — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** The artistic technologies are presented as a random shelf of tricks.
**Answer: False** — Their evolution is taught so each is understood as an answer found over time.

**2. (Sub lesson 2)** Pyrography with a heated tool is one of the artistic wood technologies.
**Answer: True** — The part names it among them.

**3. (Sub lesson 2)** Technique selection starts from the technique, not the article.
**Answer: False** — The designed article decides; the technique serves it.
