# Fretwork — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Fretwork cuts thick timber into beams.
**Answer: False** — Fretwork cuts ornaments in thin materials — plywood, plexiglas, soft metals, bone.

**2. (Sub lesson 1)** The fretsaw's deep U-frame lets the fine blade reach inside cuts.
**Answer: True** — The frame shape serves the inside cuts of an ornament.

**3. (Sub lesson 2)** The fretwork table and tool set are part of the technique.
**Answer: True** — The workplace holds the thin sheet so the blade can travel.
