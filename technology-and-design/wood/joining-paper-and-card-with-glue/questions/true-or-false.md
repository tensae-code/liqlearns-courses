# Joining paper and card with glue — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Adhesive (pegamento) is the glue used to join paper and card.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Application has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: spreading the adhesive evenly where the join belongs.

**3. (Sub lesson 2)** Work station cleanliness is keeping the gluing place clean so finished work is not marked.
**Answer: True** — That is how the book teaches it.
