# Culinary processing — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Primary processing happens before heat is applied.
**Answer: True** — Primary processing prepares the product; thermal processing then cooks it.

**2. (Sub lesson 2)** Open sandwiches (tartine) are the book's thermal-processing dish.
**Answer: False** — The tartine is assembled by primary processing; the compote is the thermal one.

**3. (Sub lesson 1)** The Grade 5–6 book joins processing to menus and balanced eating.
**Answer: True** — Its culinary-processing pages cover menus, balanced eating and culinary technologies.
