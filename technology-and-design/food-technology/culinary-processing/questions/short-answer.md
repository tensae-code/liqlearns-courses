# Culinary processing — short answer

Answer in one or two sentences.

**1. (Sub lesson 1)** What is the difference between primary and thermal processing?
**Answer:** Primary processing prepares the product (cleaning, sorting, cutting, assembling); thermal processing changes it with heat.

**2. (Sub lesson 2)** Which two first dishes carry the methods in Grade 4?
**Answer:** Open sandwiches (tartine) for primary processing and a fruit compote for thermal processing.
