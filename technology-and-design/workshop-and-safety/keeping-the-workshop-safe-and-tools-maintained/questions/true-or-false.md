# Keeping the workshop safe and tools maintained — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Storing tools is putting every tool in its place after use.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 2)** Oiling scissors has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: cleaning and oiling scissors so they keep cutting truly.

**3. (Sub lesson 2)** Tool maintenance is small regular care that prevents failure and injury.
**Answer: True** — That is how the book teaches it.
