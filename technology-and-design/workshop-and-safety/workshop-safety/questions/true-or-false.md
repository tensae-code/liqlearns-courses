# Workshop safety — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Personal safety is the rules that protect the learner — apron, tied hair, no loose items.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Materials safety has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: the rules for handling materials safely.

**3. (Sub lesson 2)** Tool safety is the rules for holding, using and putting away each tool.
**Answer: True** — That is how the book teaches it.
