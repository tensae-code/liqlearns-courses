# Workshop safety — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is personal safety?
a) the rules that protect the learner — apron, tied hair, no loose items b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) the rules that protect the learner — apron, tied hair, no loose items**

**2. (Sub lesson 1)** What is materials safety?
a) Only decoration b) the rules for handling materials safely c) Only a price d) A kind of glue
**Answer: b) the rules for handling materials safely**

**3. (Sub lesson 2)** What is tool safety?
a) Only history b) Only painting c) the rules for holding, using and putting away each tool d) Only storage
**Answer: c) the rules for holding, using and putting away each tool**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) workshop safety comes first: follow the workshop rules, dress safely, and respect the separate rules for materials and for tools. b) Only prices c) Only old tools d) Nothing practical
**Answer: a) workshop safety comes first: follow the workshop rules, dress safely, and respect the separate rules for materials and for tools.**

**5. (Sub lesson 2)** How does Malaysia's book teach this?
a) As theory only, never practised b) Only in the glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Malay (RBT)
**Answer: d) Through the book's own examples, steps and project work, in Malay (RBT)**
