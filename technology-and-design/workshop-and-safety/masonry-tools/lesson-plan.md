# Lesson plan — Masonry tools — use, care and dangers

**Course:** Technology and Design · **Title:** Workshop and Safety · **Lesson:** Masonry tools — use, care and dangers
**Place in the curriculum:** Workshop and Safety (CURRICULUM.md) — stocked in the Rwanda expansion, 2026-11-17.
**The one thing this lesson teaches:** the masonry tools — the builder's kit for stone, brick and mortar — are learned the same way as the carpenter's: name them, use them, maintain them, and know their dangers.
**This lesson's own level:** stocked from Rwanda's *Science and Elementary Technology* pupil's books (Rwanda Education Board) — see lesson/sources.md. Rwanda counts in the acceptance count (student books, not evidence-only). The lesson also carries teacher-guide evidence, named in sources and counted nowhere.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. Picture and GIF numbers are assigned in a later media pass; the slots below are described in words.

## Sub lessons
1. **Examples of masonry tools** — Straight after carpentry, Rwanda's Primary 5 book names the masonry tools: the builder's own kit, each tool with the work it does on a building site.
2. **Usage, maintenance and dangers** — The book then teaches the usage and maintenance of the masonry tools together with their dangers, in one lesson — the same pattern as carpentry: a tool kept well and used rightly is the safe tool, and the dangers are named so they can be avoided.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.
