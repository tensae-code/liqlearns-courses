# Portable power tools — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Eye and ear protection are part of power-tool work, not extras.
**Answer: True** — The book teaches protection with the tools.

**2. (Sub lesson 2)** A power tool can be set down while still moving if the bench is clear.
**Answer: False** — It must stop first; a moving tool walks and bites.

**3. (Sub lesson 3)** Small bits may turn faster than large bits.
**Answer: True** — That is the size-speed relation.
