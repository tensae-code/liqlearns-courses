# Mechanics and blacksmith tools — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A bench vice is one of the mechanic's common tools.
**Answer: True** — The Primary 6 list is spanners, hack saw, pliers, bench vice, screwdriver and mechanics hammer.

**2. (Sub lesson 2)** The blacksmith's tools are the same kit as the mechanic's.
**Answer: False** — The forge has its own tools — the guide's kit names the blacksmith hammer and blacksmith's pliers.

**3. (Sub lesson 1)** Where a mechanic stores tools is part of the lesson.
**Answer: True** — The book teaches identification, uses, use, maintenance and storage together.
