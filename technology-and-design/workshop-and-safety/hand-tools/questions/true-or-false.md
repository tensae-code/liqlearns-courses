# Hand tools — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) A screwdriver is a measuring device.**
**Answer: False — A screwdriver is a driving tool; rulers and tapes measure.**

**2. (Sub lesson 2) Using a knife to drive a screw is acceptable workshop practice.**
**Answer: False — The wrong tool damages the tool, the material or the maker.**

**3. (Sub lesson 3) A tool list is checked off as each component is finished.**
**Answer: True**
