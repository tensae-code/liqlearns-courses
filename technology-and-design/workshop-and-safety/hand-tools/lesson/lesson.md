# Hand tools

## Do it first
Gather five hand tools (or pictures of them): snips, a gimlet or awl, a mallet or hammer, a screwdriver, a ruler. Sort them into classes by the job each one does, and say the class names aloud.

## Sub lesson 1 — Classes of hand tools
Jamaica's project classifies hand tools according to use and purpose. Cutting tools sever material — snips and nippers for sheet and wire. Boring tools make holes — the gimlet, twisted by hand to start a hole in wood. Striking tools deliver blows — the mallet, whose softer head drives without damaging. Driving tools turn fasteners — the screwdriver, matched to the screw's head. Measuring devices — ruler and tape — size everything before any of the others touch it.

## Sub lesson 2 — Choosing the tool for the component
A maker does not grab a favourite tool; the component decides. Thin sheet for a car body asks for snips; the axle hole asks for the gimlet; the wheels' screws ask for the screwdriver that fits them. Choosing wrongly — cutting thick material with light snips, driving a screw with a knife — damages the tool, the material, or the maker. Jamaica's learners select appropriate materials and tools for each component of the car, one component at a time.

## Sub lesson 3 — The material and tool list
Professionals write it down. A material and tool list names what each component needs, in the order of making, so nothing is missing halfway and no time is lost hunting. Preparing the list is part of the design work in Jamaica's project — it is made before cutting begins, and checked as each component is finished.

## Say it to your companion
Explain in your own words: hand tools are chosen by the job: each tool belongs to a class by its use and purpose — cutting, boring, striking, driving, measuring — and a good maker lists the right tools and materials for every component before starting. Say it once plainly, then answer one question your companion asks about it.

## Do It Yourself
1. Do the Do it first task again, carefully this time, using everything the lesson taught.
2. Check your work against the lesson's own checks — fix one thing you find.
3. Keep the work: it is practice evidence, and the next lesson builds on it.
