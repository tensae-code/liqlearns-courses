# Measuring, marking and checking in wood and metal work — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Caliper (pie de rey) is an instrument that measures thickness and diameter precisely between its jaws.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Marking gauge (gramil) has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: a tool that scores a line parallel to an edge at a set distance.

**3. (Sub lesson 2)** False square is an adjustable square that carries any angle from one piece to another.
**Answer: True** — That is how the book teaches it.
