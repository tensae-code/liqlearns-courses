# Hands-on — The electric drilling machine

Real practice — this subject is learned by doing.

## Label the machine
On a diagram of the drill press, label all twelve parts the lesson names. Then draw the transmission path with arrows: motor, belt, spindle, drill.

## Set hole plan
Write the full plan for the set hole — 12 mm blind, 40 mm deep: fixing, bit check, depth control, and the three safety norms in order.
