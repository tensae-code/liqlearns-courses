# Building a program in Scratch — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is a Sprite?
a) the object that acts in a Scratch project b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) the object that acts in a Scratch project**

**2. (Sub lesson 1)** What is the Blocks Palette?
a) Only decoration b) where the code blocks are kept c) Only a price d) A kind of glue
**Answer: b) where the code blocks are kept**

**3. (Sub lesson 2)** What is debugging?
a) Only history b) Only painting c) finding and fixing errors in running code d) Only storage
**Answer: c) finding and fixing errors in running code**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) in Scratch, an algorithm and pseudocode become joined blocks in the Scripts Area — run the code, fix its errors, present the project. b) Only prices c) Only old tools d) Nothing practical
**Answer: a) in Scratch, an algorithm and pseudocode become joined blocks in the Scripts Area — run the code, fix its errors, present the project.**

**5. (Sub lesson 2)** How does Malaysia's book teach this?
a) As theory only, never practised b) Only in the glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Malay (RBT)
**Answer: d) Through the book's own examples, steps and project work, in Malay (RBT)**
