# Lesson plan — Building a program in Scratch

**Course:** Technology and Design · **Title:** Networks and Computers · **Lesson:** Building a program in Scratch
**Place in the curriculum:** Networks and Computers (CURRICULUM.md) — stocked in the Malaysia expansion, 2026-11-17.
**The one thing this lesson teaches:** in Scratch, an algorithm and pseudocode become joined blocks in the Scripts Area — run the code, fix its errors, present the project.
**This lesson's own level:** stocked from Malaysia's *Reka Bentuk dan Teknologi* (RBT — Design and Technology) textbooks — see lesson/sources.md. Malaysia counts in the acceptance count (student books, not evidence-only).

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. Picture and GIF numbers are assigned in a later media pass; the slots below are described in words.

## Sub lessons
1. **The Scratch workspace** — Scratch is learned as a place first: the menu bar, the Sprite that acts, the Stage it acts on, the Tabs, the Blocks Palette of code blocks, and the Scripts Area where blocks join into a program.
2. **From plan to running code** — The book builds sequence-control code from an algorithm and pseudocode — the plan becomes blocks — then runs the code, finds and fixes errors, and presents the project.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: the earlier lessons of Networks and Computers. Recommended, never forced.

## What the learner can do when it ends
1. Name the parts of the Scratch interface and what each holds.
2. Build sequence code from a plan, run it and fix an error.
3. Explain how Malaysia's book teaches it.
## What you need
A computer with Scratch (or Scratch pictures to study).
