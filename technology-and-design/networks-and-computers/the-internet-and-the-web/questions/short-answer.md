# The Internet and the Web — short answer

Answer in one or two sentences.

**1. (Sub lesson 1)** Say in one sentence what this lesson teaches.
**Answer:** What the Internet is, ways of connecting, server categories, IP addresses and DNS, Internet governance, the WWW, browser settings, search engines and organising useful addresses/portals.

**2. (Sub lesson 2)** Name one material, tool or step this lesson works with.
**Answer:** Any one named in the lesson text — for example, the first step of sub lesson 1: The Internet and the Web.
