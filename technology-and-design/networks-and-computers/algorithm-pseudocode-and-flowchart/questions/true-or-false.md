# Algorithm, pseudocode and flowchart — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** An algorithm is a step-by-step plan for solving a problem.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Pseudocode has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: the plan written in plain ordered words.

**3. (Sub lesson 2)** A flowchart is the plan drawn with symbols — start/end, process, input/output, flow.
**Answer: True** — That is how the book teaches it.
