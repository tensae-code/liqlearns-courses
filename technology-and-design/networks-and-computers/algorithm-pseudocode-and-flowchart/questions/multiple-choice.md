# Algorithm, pseudocode and flowchart — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is an algorithm?
a) a step-by-step plan for solving a problem b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) a step-by-step plan for solving a problem**

**2. (Sub lesson 1)** What is pseudocode?
a) Only decoration b) the plan written in plain ordered words c) Only a price d) A kind of glue
**Answer: b) the plan written in plain ordered words**

**3. (Sub lesson 2)** What is a flowchart?
a) Only history b) Only painting c) the plan drawn with symbols — start/end, process, input/output, flow d) Only storage
**Answer: c) the plan drawn with symbols — start/end, process, input/output, flow**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) an algorithm is the plan, pseudocode writes it in words, and a flowchart draws it in symbols — all checked and improved before use. b) Only prices c) Only old tools d) Nothing practical
**Answer: a) an algorithm is the plan, pseudocode writes it in words, and a flowchart draws it in symbols — all checked and improved before use.**

**5. (Sub lesson 2)** How does Malaysia's book teach this?
a) As theory only, never practised b) Only in the glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Malay (RBT)
**Answer: d) Through the book's own examples, steps and project work, in Malay (RBT)**
