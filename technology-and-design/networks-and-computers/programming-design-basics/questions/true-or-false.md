# Programming design basics — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A program is a coded instruction sequence that lets data be processed by a computer.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** An instruction has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: one coded step telling the machine what to do.

**3. (Sub lesson 2)** Data is the information a computer processes.
**Answer: True** — That is how the book teaches it.
