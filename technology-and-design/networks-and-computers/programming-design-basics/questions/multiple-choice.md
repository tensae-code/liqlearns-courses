# Programming design basics — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is a program?
a) a coded instruction sequence that lets data be processed by a computer b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) a coded instruction sequence that lets data be processed by a computer**

**2. (Sub lesson 1)** What is an instruction?
a) Only decoration b) one coded step telling the machine what to do c) Only a price d) A kind of glue
**Answer: b) one coded step telling the machine what to do**

**3. (Sub lesson 2)** What is data?
a) Only history b) Only painting c) the information a computer processes d) Only storage
**Answer: c) the information a computer processes**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) a program is a coded instruction sequence that lets a computer process data — and programs live inside everyday appliances. b) Only prices c) Only old tools d) Nothing practical
**Answer: a) a program is a coded instruction sequence that lets a computer process data — and programs live inside everyday appliances.**

**5. (Sub lesson 2)** How does Malaysia's book teach this?
a) As theory only, never practised b) Only in the glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Malay (RBT)
**Answer: d) Through the book's own examples, steps and project work, in Malay (RBT)**
