# Lesson plan — Programming design basics

**Course:** Technology and Design · **Title:** Networks and Computers · **Lesson:** Programming design basics
**Place in the curriculum:** Networks and Computers (CURRICULUM.md) — stocked in the Malaysia expansion, 2026-11-17.
**The one thing this lesson teaches:** a program is a coded instruction sequence that lets a computer process data — and programs live inside everyday appliances.
**This lesson's own level:** stocked from Malaysia's *Reka Bentuk dan Teknologi* (RBT — Design and Technology) textbooks — see lesson/sources.md. Malaysia counts in the acceptance count (student books, not evidence-only).

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. Picture and GIF numbers are assigned in a later media pass; the slots below are described in words.

## Sub lessons
1. **Programs live inside appliances** — Programming design begins at home: the smart TV, the digital clock, the remote control and the air conditioner all carry computer programs inside them.
2. **What a program is** — A program is a coded instruction sequence that lets data be processed by a computer: instructions, written in code, telling the machine what to do with what it senses and holds.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: the earlier lessons of Networks and Computers. Recommended, never forced.

## What the learner can do when it ends
1. Name programmed appliances and say what their programs do.
2. Define a program in the book’s own terms.
3. Explain how Malaysia's book teaches it.
## What you need
Programmed appliances to observe — TV, clock, remote, air conditioner.
