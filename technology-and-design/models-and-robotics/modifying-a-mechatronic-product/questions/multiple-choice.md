# Modifying a mechatronic product — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is modifying a product?
a) changing one part of an existing product to improve it b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) changing one part of an existing product to improve it**

**2. (Sub lesson 2)** What is motor torque?
a) Only decoration b) the turning strength of a motor, weighed in the worked examples c) Only a price d) A kind of glue
**Answer: b) the turning strength of a motor, weighed in the worked examples**

**3. (Sub lesson 2)** What is evaluating the modification?
a) Only history b) Only painting c) testing whether the changed product’s function truly improved d) Only storage
**Answer: c) testing whether the changed product’s function truly improved**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) modify from the block diagram: sketch the part, make the improvement, and evaluate the changed product’s function. b) Only prices c) Only old tools d) Nothing practical
**Answer: a) modify from the block diagram: sketch the part, make the improvement, and evaluate the changed product’s function.**

**5. (Sub lesson 2)** How does Malaysia's book teach this?
a) As theory only, never practised b) Only in the glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Malay (RBT)
**Answer: d) Through the book's own examples, steps and project work, in Malay (RBT)**
