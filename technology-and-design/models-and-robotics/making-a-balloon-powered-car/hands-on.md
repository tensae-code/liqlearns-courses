# Hands-on \u2014 Making a balloon-powered car

Real practice \u2014 this subject is learned by doing.

## Build and run
Build the balloon car. Run it three times on a smooth floor, measure each run's distance, and record the best. Keep the wheels straight and the balloon centred.

## Improve one thing
Change exactly one thing \u2014 bigger balloon, smoother floor, straighter axle \u2014 and run again. Report what changed and what it did to the distance.
