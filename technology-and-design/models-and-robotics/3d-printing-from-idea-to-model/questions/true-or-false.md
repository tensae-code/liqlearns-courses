# 3D printing, from idea to model — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** 3D printing builds an object by adding material layer by layer.
**Answer: True** — The object grows layer by layer from a digital model.

**2. (Sub lesson 3)** Any rough sketch can be sent straight to the printer with no model in between.
**Answer: False** — The idea must first be drawn as a 3D model and checked as printable.

**3. (Sub lesson 2)** Filament is stored wound on a spool.
**Answer: True** — Filament is a thin thread wound on a spool.
