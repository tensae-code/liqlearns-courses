# Technical modelling — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is technical modelling (modelismo técnico)?
a) building working models of technical objects b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) building working models of technical objects**

**2. (Sub lesson 1)** What is graphic representation?
a) Only history b) the drawing from which a model is built c) Only storage d) A kind of glue
**Answer: b) the drawing from which a model is built**

**3. (Sub lesson 2)** What is mechanics box?
a) Only old tools b) Only painting c) a construction set of bars, wheels, nuts and bolts for modelling d) Only a price
**Answer: c) a construction set of bars, wheels, nuts and bolts for modelling**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) Only decoration b) Nothing to do with this lesson c) Only history d) technical modelling (modelismo técnico) builds working models from a model, from a graphic representation, and freely — with the modelling box's parts, mechanisms included, under the workshop's safety and organisation norms.
**Answer: d) technical modelling (modelismo técnico) builds working models from a model, from a graphic representation, and freely — with the modelling box's parts, mechanisms included, under the workshop's safety and organisation norms.**

**5. (Sub lesson 2)** How does Cuba's book teach this?
a) As theory only, never practised b) Only in a glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Spanish
**Answer: d) Through the book's own examples, steps and project work, in Spanish**
