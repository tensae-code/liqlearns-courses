# Technical modelling — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Technical modelling (modelismo técnico) is building working models of technical objects.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Graphic representation has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: the drawing from which a model is built.

**3. (Sub lesson 2)** Mechanics box is a construction set of bars, wheels, nuts and bolts for modelling.
**Answer: True** — That is how the book teaches it.
