# First steps with UltiMaker Cura — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Cura slices a model into hundreds of thin horizontal layers.
**Answer: True** — The slicer cuts the model into thin layers and plans each layer's path.

**2. (Sub lesson 2)** A model floating above the bed in Cura is ready to print.
**Answer: False** — It must sit flat on the bed; placement is fixed on screen first.

**3. (Sub lesson 3)** Previewing the sliced model is part of preparing a print.
**Answer: True** — The preview is checked layer by layer before the file is sent.
