# Architectural model making — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Foam sheet (یونولیت) is the light foam board cut to form model walls and domes.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Hot-wire cutter has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: the heated wire tool that cuts foam cleanly.

**3. (Sub lesson 2)** Scale 1:50 is a model scale where 1 unit on the model is 50 units on the real building.
**Answer: True** — That is how the book teaches it.
