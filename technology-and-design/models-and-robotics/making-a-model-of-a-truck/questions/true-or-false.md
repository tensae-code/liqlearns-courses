# Making a model of a truck — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A model must be exactly the same size as the real truck.
**Answer: False** — A макет is a smaller copy that keeps the main parts.

**2. (Sub lesson 2)** The model is checked against the real truck when finished.
**Answer: True** — Every main part must be present and in the right place.

**3. (Sub lesson 2)** Plasticine plays no part in building the truck.
**Answer: False** — Plasticine joins and shapes the smaller pieces.
