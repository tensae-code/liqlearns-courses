# Making the model stick to the printer bed — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A model can come loose while the printer keeps printing into empty air.
**Answer: True** — Once detached, later layers have nothing to build on.

**2. (Sub lesson 2)** A bad first layer usually heals itself in later layers.
**Answer: False** — It will not heal; stop, fix the cause, and start again.

**3. (Sub lesson 3)** A clean and level bed helps the first layer grip evenly.
**Answer: True** — The first line is pressed evenly onto a clean, level bed.
