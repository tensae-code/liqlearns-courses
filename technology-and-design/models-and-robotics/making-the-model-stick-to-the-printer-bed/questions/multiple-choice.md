# Making the model stick to the printer bed — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Why does the first layer matter so much?
a) It is the model's foundation — if it does not grip, the whole print fails b) It is the only layer anyone sees c) It uses the most filament d) It decides the model's colour
**Answer: a) It is the model's foundation — if it does not grip, the whole print fails**

**2. (Sub lesson 1)** What can happen when first layers detach?
a) The model shifts, lifts at the corners, or comes loose completely b) The print gets faster c) The model grows bigger d) Nothing at all
**Answer: a) The model shifts, lifts at the corners, or comes loose completely**

**3. (Sub lesson 2)** How is adhesion secured?
a) A clean, level bed and a slow, close first layer b) Printing the first layer as fast as possible c) Starting with a dirty bed d) Skipping the first layer
**Answer: a) A clean, level bed and a slow, close first layer**

**4. (Sub lesson 2)** What is a brim?
a) Extra first-layer lines around the model's base giving it more holding area b) A hat for the printer c) The edge of the book d) A kind of support for overhangs
**Answer: a) Extra first-layer lines around the model's base giving it more holding area**

**5. (Sub lesson 3)** What should you do about a bad first layer?
a) Stop, fix the cause, and start again b) Let it run — it will heal itself c) Cover it and hope d) Add more speed
**Answer: a) Stop, fix the cause, and start again**
