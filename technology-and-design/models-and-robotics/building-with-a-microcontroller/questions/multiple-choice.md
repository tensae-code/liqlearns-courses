# Building with a microcontroller — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is circuit simulation?
a) building a working circuit in special software before real wiring b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) building a working circuit in special software before real wiring**

**2. (Sub lesson 1)** What is an input circuit?
a) Only decoration b) a circuit feeding signals into the microcontroller c) Only a price d) A kind of glue
**Answer: b) a circuit feeding signals into the microcontroller**

**3. (Sub lesson 2)** What is an output circuit?
a) Only history b) Only painting c) a circuit the microcontroller drives to act d) Only storage
**Answer: c) a circuit the microcontroller drives to act**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) build with a microcontroller in order: sketch, simulate in software, connect inputs and outputs, program simply, test and improve. b) Only prices c) Only old tools d) Nothing practical
**Answer: a) build with a microcontroller in order: sketch, simulate in software, connect inputs and outputs, program simply, test and improve.**

**5. (Sub lesson 2)** How does Malaysia's book teach this?
a) As theory only, never practised b) Only in the glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Malay (RBT)
**Answer: d) Through the book's own examples, steps and project work, in Malay (RBT)**
