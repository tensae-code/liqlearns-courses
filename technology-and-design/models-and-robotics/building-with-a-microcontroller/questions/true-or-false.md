# Building with a microcontroller — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Circuit simulation is building a working circuit in special software before real wiring.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** An input circuit has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: a circuit feeding signals into the microcontroller.

**3. (Sub lesson 2)** An output circuit is a circuit the microcontroller drives to act.
**Answer: True** — That is how the book teaches it.
