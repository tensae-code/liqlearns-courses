# Reading and drawing the block diagram (gambar rajah blok) of an existing mechatronic product — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Gambar rajah blok is a block diagram.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** An input block has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: the block that senses for the product.

**3. (Sub lesson 2)** The control block is the block that decides what the product does.
**Answer: True** — That is how the book teaches it.
