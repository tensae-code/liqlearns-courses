# Reading and drawing the block diagram (gambar rajah blok) of an existing mechatronic product — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is gambar rajah blok?
a) a block diagram b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) a block diagram**

**2. (Sub lesson 1)** What is an input block?
a) Only decoration b) the block that senses for the product c) Only a price d) A kind of glue
**Answer: b) the block that senses for the product**

**3. (Sub lesson 2)** What is the control block?
a) Only history b) Only painting c) the block that decides what the product does d) Only storage
**Answer: c) the block that decides what the product does**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) a block diagram (gambar rajah blok) reduces a mechatronic product to input, control and output blocks — read first, then drawn. b) Only prices c) Only old tools d) Nothing practical
**Answer: a) a block diagram (gambar rajah blok) reduces a mechatronic product to input, control and output blocks — read first, then drawn.**

**5. (Sub lesson 2)** How does Malaysia's book teach this?
a) As theory only, never practised b) Only in the glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Malay (RBT)
**Answer: d) Through the book's own examples, steps and project work, in Malay (RBT)**
