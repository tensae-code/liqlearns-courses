# Lesson plan — Reading and drawing the block diagram (gambar rajah blok) of an existing mechatronic product

**Course:** Technology and Design · **Title:** Models and Robotics · **Lesson:** Reading and drawing the block diagram (gambar rajah blok) of an existing mechatronic product
**Place in the curriculum:** Models and Robotics (CURRICULUM.md) — stocked in the Malaysia expansion, 2026-11-17.
**The one thing this lesson teaches:** a block diagram (gambar rajah blok) reduces a mechatronic product to input, control and output blocks — read first, then drawn.
**This lesson's own level:** stocked from Malaysia's *Reka Bentuk dan Teknologi* (RBT — Design and Technology) textbooks — see lesson/sources.md. Malaysia counts in the acceptance count (student books, not evidence-only).

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. Picture and GIF numbers are assigned in a later media pass; the slots below are described in words.

## Sub lessons
1. **Reading a product as blocks** — A block diagram — gambar rajah blok — reads a mechatronic product as three kinds of block: input blocks sense, the control block decides, output blocks act.
2. **Drawing the diagram** — The learner draws the diagram of an existing product: blocks placed, arrows showing what flows between them.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: the earlier lessons of Models and Robotics. Recommended, never forced.

## What the learner can do when it ends
1. Read a mechatronic product as input, control and output blocks.
2. Draw a block diagram of an existing product.
3. Explain how Malaysia's book teaches it.
## What you need
Diagram paper; a product to analyse.
