# Mechatronic design — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is mechatronic design?
a) design joining mechanical transmission, electronics and microcontroller control b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) design joining mechanical transmission, electronics and microcontroller control**

**2. (Sub lesson 1)** What is a sensor?
a) Only decoration b) an electronic component that detects and reports c) Only a price d) A kind of glue
**Answer: b) an electronic component that detects and reports**

**3. (Sub lesson 2)** What is microcontroller control?
a) Only history b) Only painting c) the control system directing the product’s mechanical and electronic parts d) Only storage
**Answer: c) the control system directing the product’s mechanical and electronic parts**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) mechatronic design joins mechanical transmission, electronic components and microcontroller control — each element’s function read in a real product. b) Only prices c) Only old tools d) Nothing practical
**Answer: a) mechatronic design joins mechanical transmission, electronic components and microcontroller control — each element’s function read in a real product.**

**5. (Sub lesson 2)** How does Malaysia's book teach this?
a) As theory only, never practised b) Only in the glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Malay (RBT)
**Answer: d) Through the book's own examples, steps and project work, in Malay (RBT)**
