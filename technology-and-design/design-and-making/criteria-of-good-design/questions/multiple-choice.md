# Criteria of good design — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is a criterion?
a) a named test a product is judged against b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) a named test a product is judged against**

**2. (Sub lesson 1)** What is exploring from real products?
a) Only decoration b) deriving the criteria by examining actual products c) Only a price d) A kind of glue
**Answer: b) deriving the criteria by examining actual products**

**3. (Sub lesson 2)** What is fair judgement?
a) Only history b) Only painting c) applying the same criteria the same way to every product d) Only storage
**Answer: c) applying the same criteria the same way to every product**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) good design is judged by criteria, explored from real products — the same tests applied to every product. b) Only prices c) Only old tools d) Nothing practical
**Answer: a) good design is judged by criteria, explored from real products — the same tests applied to every product.**

**5. (Sub lesson 2)** How does Malaysia's book teach this?
a) As theory only, never practised b) Only in the glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Malay (RBT)
**Answer: d) Through the book's own examples, steps and project work, in Malay (RBT)**
