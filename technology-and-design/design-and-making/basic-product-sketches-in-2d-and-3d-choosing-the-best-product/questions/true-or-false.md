# Basic product sketches in 2D and 3D; choosing the best product idea using the design elements; sketching the chosen product; improving the chosen sketch — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A 2d sketch is a flat sketch showing a product’s faces.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** A 3d sketch has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: a sketch showing the product’s whole form.

**3. (Sub lesson 2)** Choosing by the elements is selecting the best idea using the design elements as tests.
**Answer: True** — That is how the book teaches it.
