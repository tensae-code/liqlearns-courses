# Design project, step 1–3 (my dream car) — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is generating ideas?
a) producing several possible designs before choosing b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) producing several possible designs before choosing**

**2. (Sub lesson 2)** What is evaluating a sketch?
a) Only decoration b) judging the sketch against criteria — the design elements c) Only a price d) A kind of glue
**Answer: b) judging the sketch against criteria — the design elements**

**3. (Sub lesson 2)** What is improving a sketch?
a) Only history b) Only painting c) changing the design where evaluation found it weak d) Only storage
**Answer: c) changing the design where evaluation found it weak**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) project steps 1–3: generate ideas, sketch the chosen design, then analyse, evaluate and improve it against the design elements. b) Only prices c) Only old tools d) Nothing practical
**Answer: a) project steps 1–3: generate ideas, sketch the chosen design, then analyse, evaluate and improve it against the design elements.**

**5. (Sub lesson 2)** How does Malaysia's book teach this?
a) As theory only, never practised b) Only in the glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Malay (RBT)
**Answer: d) Through the book's own examples, steps and project work, in Malay (RBT)**
