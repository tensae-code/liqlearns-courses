# Prototyping — a mock-up before making — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Skipping the mock-up saves all the time the mock-up would have taken.**
**Answer: False — The same faults appear later, in expensive material.**

**2. (Sub lesson 2) Compatibility means checking the mock-up against the parts it must fit.**
**Answer: True**

**3. (Sub lesson 3) Accuracy and workability are the same test.**
**Answer: False — Accuracy checks against the design; workability checks that it actually works.**
