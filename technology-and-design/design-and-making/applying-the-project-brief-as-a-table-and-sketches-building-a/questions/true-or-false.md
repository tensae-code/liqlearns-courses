# Applying the project brief as a table and sketches; building a mock-up or model from the brief; evaluating the finished mock-up or model — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Applying the brief is turning the brief into a table and sketches that can be checked.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 2)** A mock-up has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: a trial model built from the brief.

**3. (Sub lesson 2)** Evaluating against the brief is judging the finished model by the requirements it came from.
**Answer: True** — That is how the book teaches it.
