# Applying the project brief as a table and sketches; building a mock-up or model from the brief; evaluating the finished mock-up or model — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is applying the brief?
a) turning the brief into a table and sketches that can be checked b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) turning the brief into a table and sketches that can be checked**

**2. (Sub lesson 2)** What is a mock-up?
a) Only decoration b) a trial model built from the brief c) Only a price d) A kind of glue
**Answer: b) a trial model built from the brief**

**3. (Sub lesson 2)** What is evaluating against the brief?
a) Only history b) Only painting c) judging the finished model by the requirements it came from d) Only storage
**Answer: c) judging the finished model by the requirements it came from**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) apply the brief as a table and sketches, build the mock-up or model from it, and evaluate the result against the brief. b) Only prices c) Only old tools d) Nothing practical
**Answer: a) apply the brief as a table and sketches, build the mock-up or model from it, and evaluate the result against the brief.**

**5. (Sub lesson 2)** How does Malaysia's book teach this?
a) As theory only, never practised b) Only in the glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Malay (RBT)
**Answer: d) Through the book's own examples, steps and project work, in Malay (RBT)**
