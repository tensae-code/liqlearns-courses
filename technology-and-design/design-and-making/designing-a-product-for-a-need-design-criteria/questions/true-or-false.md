# Designing a product for a need (design criteria) — true or false

Say whether each statement is true or false.

**1. (Sub lesson 2) A design can be 'good' without reference to any criteria.**
**Answer: False — It is good against its criteria, for its user and need.**

**2. (Sub lesson 1) A plainly stated need decides some design choices before designing starts.**
**Answer: True — 'For children, in hurricane season' already demands safety, toughness and simplicity.**

**3. (Sub lesson 3) Criteria turn design arguments from taste into judgement.**
**Answer: True**
