# Analysing the project plan and building the work schedule — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is work breakdown structure?
a) identifying all the activities a project contains b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) identifying all the activities a project contains**

**2. (Sub lesson 2)** What is estimating resources?
a) Only decoration b) judging what each activity needs before it starts c) Only a price d) A kind of glue
**Answer: b) judging what each activity needs before it starts**

**3. (Sub lesson 2)** What is a budget?
a) Only history b) Only painting c) the estimated cost of the whole project d) Only storage
**Answer: c) the estimated cost of the whole project**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) build a schedule in order: break down the work, order it, estimate resources and time, build the schedule, then cost and budget it. b) Only prices c) Only old tools d) Nothing practical
**Answer: a) build a schedule in order: break down the work, order it, estimate resources and time, build the schedule, then cost and budget it.**

**5. (Sub lesson 2)** How does Malaysia's book teach this?
a) As theory only, never practised b) Only in the glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Malay (RBT)
**Answer: d) Through the book's own examples, steps and project work, in Malay (RBT)**
