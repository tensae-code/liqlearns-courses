# Design project management — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is project management?
a) planning and steering a project from problem to finished product b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) planning and steering a project from problem to finished product**

**2. (Sub lesson 1)** What is generating design ideas?
a) Only decoration b) producing ideas to solve the project’s problem c) Only a price d) A kind of glue
**Answer: b) producing ideas to solve the project’s problem**

**3. (Sub lesson 2)** What is implementation steps?
a) Only history b) Only painting c) the ordered steps that carry a project through d) Only storage
**Answer: c) the ordered steps that carry a project through**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) design project management steers a project from problem to product: ideas generated, then implementation steps followed in order. b) Only prices c) Only old tools d) Nothing practical
**Answer: a) design project management steers a project from problem to product: ideas generated, then implementation steps followed in order.**

**5. (Sub lesson 2)** How does Malaysia's book teach this?
a) As theory only, never practised b) Only in the glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Malay (RBT)
**Answer: d) Through the book's own examples, steps and project work, in Malay (RBT)**
