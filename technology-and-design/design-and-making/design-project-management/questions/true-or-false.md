# Design project management — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Project management is planning and steering a project from problem to finished product.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Generating design ideas has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: producing ideas to solve the project’s problem.

**3. (Sub lesson 2)** Implementation steps is the ordered steps that carry a project through.
**Answer: True** — That is how the book teaches it.
