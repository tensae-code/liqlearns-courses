# Planning a design project — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** An organisation chart is a drawing of the project team and its posts.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** The project manager has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: the post carrying main determination, sub-determination, activity management and the team matrix.

**3. (Sub lesson 2)** Scheduling is ordering the work in time to avoid loss, control labour and manage materials.
**Answer: True** — That is how the book teaches it.
