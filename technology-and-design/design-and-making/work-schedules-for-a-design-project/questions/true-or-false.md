# Work schedules for a design project — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A gantt chart is a bar chart laying activities across time.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** A milestone has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: a marked key point in a network schedule.

**3. (Sub lesson 2)** Project control is checking resources, cost, quality and spending against the schedule.
