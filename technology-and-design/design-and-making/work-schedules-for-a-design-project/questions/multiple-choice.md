# Work schedules for a design project — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is a Gantt chart?
a) a bar chart laying activities across time b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) a bar chart laying activities across time**

**2. (Sub lesson 1)** What is a milestone?
a) Only decoration b) a marked key point in a network schedule c) Only a price d) A kind of glue
**Answer: b) a marked key point in a network schedule**

**3. (Sub lesson 2)** What is project control?
a) Only history b) Only painting c) checking resources, cost, quality and spending against the schedule d) Only storage
**Answer: c) checking resources, cost, quality and spending against the schedule**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) a work schedule is drawn as network blocks with milestones and as a Gantt chart — and controlled on resources, cost, quality and spending. b) Only prices c) Only old tools d) Nothing practical
**Answer: a) a work schedule is drawn as network blocks with milestones and as a Gantt chart — and controlled on resources, cost, quality and spending.**

**5. (Sub lesson 2)** How does Malaysia's book teach this?
a) As theory only, never practised b) Only in the glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Malay (RBT)
**Answer: d) Through the book's own examples, steps and project work, in Malay (RBT)**
