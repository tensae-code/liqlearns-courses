# Editing tools in CAD — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Mirror is the CAD edit that flips a part across a line.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Array has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: the CAD edit that repeats a part in an ordered pattern.

**3. (Sub lesson 2)** Trim is the CAD edit that cuts a line back to a boundary.
**Answer: True** — That is how the book teaches it.
