# Editing tools in CAD — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is mirror?
a) the CAD edit that flips a part across a line b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) the CAD edit that flips a part across a line**

**2. (Sub lesson 1)** What is array?
a) Only history b) the CAD edit that repeats a part in an ordered pattern c) Only storage d) A kind of glue
**Answer: b) the CAD edit that repeats a part in an ordered pattern**

**3. (Sub lesson 2)** What is trim?
a) Only old tools b) Only painting c) the CAD edit that cuts a line back to a boundary d) Only a price
**Answer: c) the CAD edit that cuts a line back to a boundary**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) Only decoration b) Nothing to do with this lesson c) Only history d) CAD editing tools change a drawing without redrawing it: mirror and array copy with order, rotate, trim, extend and scale reshape, and snap aids keep every edit precise.
**Answer: d) CAD editing tools change a drawing without redrawing it: mirror and array copy with order, rotate, trim, extend and scale reshape, and snap aids keep every edit precise.**
