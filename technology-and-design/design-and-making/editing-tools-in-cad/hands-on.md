# Hands-on — Editing tools in CAD

Real practice — this subject is learned by doing.

## Half the work
Draw one half of a symmetric shape, then mirror it. Write what the mirror line must be for the result to be correct.

## Plan the edits
Given a drawing with a hole in the wrong place and a line too long: name the edit tools, in order, that fix it without redrawing — and the snap points you would use.
