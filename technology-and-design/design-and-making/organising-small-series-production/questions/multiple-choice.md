# Organising small-series production — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A small series means…
a) One perfect unit b) The same device made repeatedly to one standard c) Many different devices d) A drawing set
**Answer: b) The same device made repeatedly to one standard**

**2. (Sub lesson 1)** The jump from prototype to series changes the question to…
a) 'Who made it?' b) 'Can we make it repeatedly, to standard?' c) 'What colour is it?' d) 'Is it art?'
**Answer: b) 'Can we make it repeatedly, to standard?'**

**3. (Sub lesson 2)** A run is organised by fixing…
a) Nothing in advance b) Roles, materials, order of work and checks c) Only the finish time d) The celebration
**Answer: b) Roles, materials, order of work and checks**

**4. (Sub lesson 2)** Each unit of the series is checked against…
a) The previous unit only b) The prototype that passed its test c) A guess d) Nothing
**Answer: b) The prototype that passed its test**

**5. (Sub lesson 3)** 'Continuing' production means…
a) Stopping often b) Keeping the run supplied and the standard held to the last unit c) Making units faster at any quality d) Changing the design mid-run
**Answer: b) Keeping the run supplied and the standard held to the last unit**
