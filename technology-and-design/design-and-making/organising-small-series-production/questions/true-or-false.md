# Organising small-series production — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A series is just a prototype made several times by luck.
**Answer: False** — A series is the same device to the same specification, unit after unit, under an organised run.

**2. (Sub lesson 2)** An organised run can be paced, costed and corrected.
**Answer: True** — Roles, materials, order and checks fixed in advance are what make correction possible.

**3. (Sub lesson 3)** The standard may quietly drift as the team tires, as long as units keep coming.
**Answer: False** — Holding the standard — the last unit matching the first — is what makes it production.
