# Drawing simple shapes with the line, circle and arc tools in CAD software — matching

Match each item on the left with the one on the right.

**1. (Sub lesson 1)** line tool — the CAD tool that draws a straight segment between two fixed points

**2. (Sub lesson 1)** circle tool — the CAD tool that draws a true circle from a centre and radius or diameter

**3. (Sub lesson 2)** arc tool — the CAD tool that draws part of a circle
