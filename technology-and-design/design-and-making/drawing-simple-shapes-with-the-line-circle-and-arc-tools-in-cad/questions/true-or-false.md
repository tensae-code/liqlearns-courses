# Drawing simple shapes with the line, circle and arc tools in CAD software — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Line tool is the CAD tool that draws a straight segment between two fixed points.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Circle tool has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: the CAD tool that draws a true circle from a centre and radius or diameter.

**3. (Sub lesson 2)** Arc tool is the CAD tool that draws part of a circle.
**Answer: True** — That is how the book teaches it.
