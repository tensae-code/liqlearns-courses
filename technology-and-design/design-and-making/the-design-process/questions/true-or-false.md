# The design process — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Generating only one idea is enough, because the first idea is always best.**
**Answer: False — The process asks for more than one idea before selecting.**

**2. (Sub lesson 2) Evaluation covers both the solution and the process itself.**
**Answer: True — The appendix's fifth aim is to evaluate the solution and the process.**

**3. (Sub lesson 3) Presenting results is part of the design process, not an extra.**
**Answer: True — Present results is the final step of Jamaica's 'E' Design Process.**
