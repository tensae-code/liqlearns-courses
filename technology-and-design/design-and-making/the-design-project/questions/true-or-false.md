# The design project — carrying a project through — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Testing a project means checking the made thing against its specification.
**Answer: True** — The test is a verdict: measured output against the specification's promise.

**2. (Sub lesson 2)** Context analysis covers only the technological side of a project.
**Answer: False** — Morocco's analysis is social, technological, economic and ecological.

**3. (Sub lesson 1)** The alternator can be chosen sensibly before the wind is measured.
**Answer: False** — Wind measurement comes first; alternator and rotor choices depend on it.
