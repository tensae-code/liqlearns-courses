# The design project — carrying a project through — short answer

Answer in one or two sentences.

**1. (Sub lesson 1)** List the stages of Morocco's wind-turbine project in order.
**Answer:** Context analysis; specification and SysML diagrams; functional chains; measure the wind and research the alternator; propose a buildable model; make and assemble the parts; test that it works.

**2. (Sub lesson 2)** Why does the project loop back to the model if the test fails?
**Answer:** Because the test judges the model, not just the making: if output misses the specification, the design — rotor, transmission or alternator choice — must be revised and remade.
