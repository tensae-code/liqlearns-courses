# Inventive problem solving — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is a non-inventive problem?
a) a problem that yields to known methods b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) a problem that yields to known methods**

**2. (Sub lesson 1)** What is an inventive problem?
a) Only decoration b) a problem with no ready solution, demanding a new idea c) Only a price d) A kind of glue
**Answer: b) a problem with no ready solution, demanding a new idea**

**3. (Sub lesson 2)** What is the inventive process?
a) Only history b) Only painting c) the step-by-step route for solving an inventive problem d) Only storage
**Answer: c) the step-by-step route for solving an inventive problem**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) tell non-inventive from inventive problems first — each kind has its own problem-solving process. b) Only prices c) Only old tools d) Nothing practical
**Answer: a) tell non-inventive from inventive problems first — each kind has its own problem-solving process.**

**5. (Sub lesson 2)** How does Malaysia's book teach this?
a) As theory only, never practised b) Only in the glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Malay (RBT)
**Answer: d) Through the book's own examples, steps and project work, in Malay (RBT)**
