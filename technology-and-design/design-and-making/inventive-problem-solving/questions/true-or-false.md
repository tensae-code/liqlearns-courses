# Inventive problem solving — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A non-inventive problem is a problem that yields to known methods.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** An inventive problem has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: a problem with no ready solution, demanding a new idea.

**3. (Sub lesson 2)** The inventive process is the step-by-step route for solving an inventive problem.
**Answer: True** — That is how the book teaches it.
