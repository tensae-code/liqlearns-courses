# Technical documentation — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Once the makers are present, the manual's quality does not matter.
**Answer: False** — The manual exists for when the makers are absent — the document is all the user will have.

**2. (Sub lesson 2)** The production steps belong inside the user manual.
**Answer: True** — Maintenance, repair and rebuilding all start from knowing how the thing was put together.

**3. (Sub lesson 3)** Steps in a manual can be written in any order.
**Answer: False** — Steps are written in the order the user will meet them.
