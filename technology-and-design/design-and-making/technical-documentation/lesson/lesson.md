# Technical documentation

## Do it first
Write instructions for a stranger to do something you know well — making tea, locking your house. Give them to someone and watch silently where they hesitate. Every hesitation is a documentation fault.

## Sub lesson 1 — The user manual — notice d'utilisation
Haiti's greenhouse sequence ends its making with documentation: each group writes the greenhouse's user manual, the notice d'utilisation. The manual is a technical document with a reader in mind — the person who will use the greenhouse without its builders standing beside them. Everything that person needs must be in the document, because the document is all they will have.

## Sub lesson 2 — Work plan and production steps inside the manual
The groups write the manual with a work plan and the production steps: how the greenhouse was planned and built, in order. Recording the production inside the user document serves the user directly — maintenance, repair and rebuilding all start from knowing how the thing was put together. Documentation that hides the making leaves the user helpless at the first fault.

## Sub lesson 3 — Writing for the person who will use the thing
A user manual is judged by its reader's success. Steps are written in the order the user will meet them, in plain words, with nothing the builders knew but forgot to write. The group's test is simple: hand the manual to someone who did not build the greenhouse and watch whether they can use and care for it from the document alone.

## Say it to your companion
Explain in your own words: technical documentation speaks for the made product after the makers leave: a user manual (notice d'utilisation) carries the product's work plan and production steps so a stranger can use what was built. Say it once plainly, then answer one question your companion asks about it.

## Do It Yourself
1. Do the Do it first task again, carefully this time, using everything the lesson taught.
2. Check your work against the lesson's own checks — fix one thing you find.
3. Keep your work: it is practice evidence, and the next lesson builds on it.
