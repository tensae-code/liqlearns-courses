# Lesson plan — Technical documentation

**Course:** Technology and Design · **Title:** Design and Making · **Lesson:** Technical documentation
**Place in the curriculum:** Design and Making (CURRICULUM.md) — stocked in the Haiti expansion, 2026-11-17.
**The one thing this lesson teaches:** technical documentation speaks for the made product after the makers leave: a user manual (notice d'utilisation) carries the product's work plan and production steps so a stranger can use what was built.
**This lesson's own level:** it stands on teacher-guide evidence only — Haiti's ITAP Projet Nectar pedagogical sequences (MENFP) are the books in hand for this topic (see lesson/sources.md). Teacher guides are evidence, counted nowhere in the acceptance count.

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. Picture and GIF numbers are assigned in a later media pass; the slots below are described in words.

## Sub lessons
1. **The user manual — notice d'utilisation** — The document that teaches the user the product.
2. **Work plan and production steps inside the manual** — The manual records how the product was made, not only how it is used.
3. **Writing for the person who will use the thing** — Clarity is the standard: steps in order, words the user owns.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: the earlier lessons of Design and Making. Recommended, never forced.

## What the learner can do when it ends
1. Say what a notice d'utilisation must do.
2. Include a work plan and production steps in a manual.
3. Test a manual on a reader who did not build the product.
## What you need
A made product to document (the class greenhouse or model), writing materials, and a reader from outside the building group for the test.
