# The 3D model in manufacturing design — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is acuan?
a) the mould from which a 3D model is made b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) the mould from which a 3D model is made**

**2. (Sub lesson 2)** What is electroplating?
a) Only decoration b) a finishing concept coating the model using electric current c) Only a price d) A kind of glue
**Answer: b) a finishing concept coating the model using electric current**

**3. (Sub lesson 2)** What is evaluating the model?
a) Only history b) Only painting c) judging the finished model to generate a more efficient design d) Only storage
**Answer: c) judging the finished model to generate a more efficient design**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) the 3D model runs sketch → mould (acuan) → make → finish (electrostatic, electroplating) → evaluate → ideas for a more efficient design. b) Only prices c) Only old tools d) Nothing practical
**Answer: a) the 3D model runs sketch → mould (acuan) → make → finish (electrostatic, electroplating) → evaluate → ideas for a more efficient design.**

**5. (Sub lesson 2)** How does Malaysia's book teach this?
a) As theory only, never practised b) Only in the glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Malay (RBT)
**Answer: d) Through the book's own examples, steps and project work, in Malay (RBT)**
