# The 3D model in manufacturing design — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Acuan is the mould from which a 3D model is made.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 2)** Electroplating has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: a finishing concept coating the model using electric current.

**3. (Sub lesson 2)** Evaluating the model is judging the finished model to generate a more efficient design.
**Answer: True** — That is how the book teaches it.
