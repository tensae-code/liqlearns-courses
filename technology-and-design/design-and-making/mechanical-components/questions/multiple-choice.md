# Mechanical components — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is a spur gear?
a) one of the named gear types b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) one of the named gear types**

**2. (Sub lesson 1)** What is a worm gear?
a) Only decoration b) one of the named gear types, driving at a right angle c) Only a price d) A kind of glue
**Answer: b) one of the named gear types, driving at a right angle**

**3. (Sub lesson 2)** What is a mechanical system?
a) Only history b) Only painting c) components working together in a product to do mechanical work d) Only storage
**Answer: c) components working together in a product to do mechanical work**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) mechanical components — gears in ten named types and the other machine elements — are read as one working system in a chosen product. b) Only prices c) Only old tools d) Nothing practical
**Answer: a) mechanical components — gears in ten named types and the other machine elements — are read as one working system in a chosen product.**

**5. (Sub lesson 2)** How does Malaysia's book teach this?
a) As theory only, never practised b) Only in the glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Malay (RBT)
**Answer: d) Through the book's own examples, steps and project work, in Malay (RBT)**
