# Combining materials in one article — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is recovered material?
a) material saved from use or waste and used again b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) material saved from use or waste and used again**

**2. (Sub lesson 1)** What is offcut?
a) Only history b) a leftover piece, used here for testing joins c) Only storage d) A kind of glue
**Answer: b) a leftover piece, used here for testing joins**

**3. (Sub lesson 2)** What is combination?
a) Only old tools b) Only painting c) using two or more materials together in one article d) Only a price
**Answer: c) using two or more materials together in one article**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) Only decoration b) Nothing to do with this lesson c) Only history d) one article can be built from several materials together — metal, recovered plastic, wood and wire — when each material is given the part of the work it does best.
**Answer: d) one article can be built from several materials together — metal, recovered plastic, wood and wire — when each material is given the part of the work it does best.**

**5. (Sub lesson 2)** How does Cuba's book teach this?
a) As theory only, never practised b) Only in a glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Spanish
**Answer: d) Through the book's own examples, steps and project work, in Spanish**
