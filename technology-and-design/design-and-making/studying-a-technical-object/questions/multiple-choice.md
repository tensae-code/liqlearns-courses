# Studying a technical object — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** The three study points are…
a) Price, colour, maker b) Form, materials of manufacture, function of use c) Weight, size, age d) Shape, shine, sound
**Answer: b) Form, materials of manufacture, function of use**

**2. (Sub lesson 1)** Fonction d'usage means…
a) The factory that made it b) What the user does with the object c) Its decoration d) Its weight
**Answer: b) What the user does with the object**

**3. (Sub lesson 2)** The manual tools in the Haiti sequence are studied from…
a) Memory only b) Photo documentation c) Advertisements d) Dreams
**Answer: b) Photo documentation**

**4. (Sub lesson 2)** The bêche is a…
a) Harrow b) Spade c) Motorised cultivator d) Plough
**Answer: b) Spade**

**5. (Sub lesson 3)** Why is the same study used for hand tools and machines?
a) To save paper b) So the comparison between them is exact c) Machines need no study d) It is not — different studies are used
**Answer: b) So the comparison between them is exact**
