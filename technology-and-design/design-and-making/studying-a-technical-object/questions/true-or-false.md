# Studying a technical object — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A study changes its questions depending on the object.
**Answer: False** — The study is fixed — form, materials, function of use — which is what makes comparisons valid.

**2. (Sub lesson 2)** A tool can be studied from photographic documentation, without the object in hand.
**Answer: True** — The Haiti sequence investigates the manual tools from photo documentation read with the three questions.

**3. (Sub lesson 3)** Function of use describes how the object was manufactured.
**Answer: False** — Function of use is what the user does with the object; manufacture belongs to the materials and form points.
