# Taking an object apart and putting it back together \u2014 true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Reassembling the object is part of the analysis, not an afterthought.
**Answer: True** \u2014 Putting it back and testing it proves the dismantling was understood.

**2. (Sub lesson 2)** All assemblies can be undone with care.
**Answer: False** \u2014 Glued, welded or riveted assemblies are non-demountable \u2014 they cannot be opened without damage.

**3. (Sub lesson 3)** Designers never think about dismantling.
**Answer: False** \u2014 Designers choose demountable assembly for parts that wear, so they can be changed.
