# Working safely with tools and materials — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Once safety has been taught once, it need not be thought about again.**
**Answer: False — Safety considerations are observed in every practical task.**

**2. (Sub lesson 2) Materials need safe handling just as tools do.**
**Answer: True — Sharp edges, splinters, dust and finishes must all be respected.**

**3. (Sub lesson 3) Safe working is assessed as part of Jamaica's project work.**
**Answer: True**
