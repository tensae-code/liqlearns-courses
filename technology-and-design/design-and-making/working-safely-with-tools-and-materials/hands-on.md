# Hands-on — Working safely with tools and materials

Real practice — this subject is learned by doing.

## Workspace audit
Audit a real workspace against the lesson: workspace, tools, materials. Write one line for each — safe, or fault found and fixed.

## Stage-by-stage safety
For a project you know (the toy car), write the safety consideration for each stage: cutting, boring, assembling, finishing. One real consideration per stage.
