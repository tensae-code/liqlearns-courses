# Function analysis

## Do it first
Before reading on: take the materials this lesson names and try the task in your own way first. Then read how Malaysia's book teaches it, and compare.

## Sub lesson 1 — Relating by function
Function analysis relates a product to the objects around it by function — what acts on what, and what each part does for the whole. The product stops being a shape and becomes a web of jobs.

## Sub lesson 2 — The function system and model
The web is drawn: a function system, then a function model built with interaction lines joining product and objects, each line a working relationship. The drawing is the analysis.

## Say it to your companion
Explain in your own words: function analysis relates a product to objects by function, drawn as a function system and a function model with interaction lines. Say it once plainly, then answer one question your companion asks about it.
