# Function analysis — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Function analysis is relating a product to objects by what each does.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 2)** A function system has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: the drawn web of a product’s functions.

**3. (Sub lesson 2)** Interaction lines is the lines joining product and objects in a function model.
**Answer: True** — That is how the book teaches it.
