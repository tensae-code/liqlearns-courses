# Function analysis — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is function analysis?
a) relating a product to objects by what each does b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) relating a product to objects by what each does**

**2. (Sub lesson 2)** What is a function system?
a) Only decoration b) the drawn web of a product’s functions c) Only a price d) A kind of glue
**Answer: b) the drawn web of a product’s functions**

**3. (Sub lesson 2)** What is interaction lines?
a) Only history b) Only painting c) the lines joining product and objects in a function model d) Only storage
**Answer: c) the lines joining product and objects in a function model**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) function analysis relates a product to objects by function, drawn as a function system and a function model with interaction lines. b) Only prices c) Only old tools d) Nothing practical
**Answer: a) function analysis relates a product to objects by function, drawn as a function system and a function model with interaction lines.**

**5. (Sub lesson 2)** How does Malaysia's book teach this?
a) As theory only, never practised b) Only in the glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Malay (RBT)
**Answer: d) Through the book's own examples, steps and project work, in Malay (RBT)**
