# Conventional vs modern tool technology — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Conventional technology is making products with simple hand tools.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 2)** Modern technology has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: making products with complex machine technology.

**3. (Sub lesson 2)** A hand tool is a tool powered and guided by the hand — knife, hammer, hand saw.
**Answer: True** — That is how the book teaches it.
