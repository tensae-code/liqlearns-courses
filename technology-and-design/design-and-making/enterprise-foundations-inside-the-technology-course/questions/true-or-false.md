# Enterprise foundations inside the technology course — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A haircut is a good because you can keep it in a box.
**Answer: False** — A haircut is a service — work done for you that cannot be stored.

**2. (Sub lesson 2)** An enterprise can be described as a system with inputs, transformation and products.
**Answer: True** — Morocco's course treats the enterprise with the same systems reading as a technical object.

**3. (Sub lesson 2)** Every product reaches its user directly from the maker.
**Answer: False** — Distribution channels may pass through wholesalers and retailers before the user.
