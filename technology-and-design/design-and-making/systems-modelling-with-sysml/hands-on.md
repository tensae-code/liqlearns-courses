# Hands-on — Systems modelling with SysML

Real practice — this subject is learned by doing.

## Three-diagram model
Take an automatic gate (or a street lamp). Draw: one requirements box list (three requirements), one use-case sketch (actors and services), one block diagram (four blocks). Link one requirement through all three.

## Fault hunt
Exchange models with a partner. Hunt for faults: a requirement no block serves, a block serving no requirement, a use case with no actor. Mark each fault and explain it in one sentence.
