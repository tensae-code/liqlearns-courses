# Systems modelling with SysML — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A SysML model is the system itself.
**Answer: False** — A model is a chosen view of the system — diagrams that answer set questions about it.

**2. (Sub lesson 1)** Behaviour diagrams and structure diagrams answer the same question.
**Answer: False** — Behaviour diagrams say what the system does; structure diagrams say what it is made of.

**3. (Sub lesson 2)** Tracing requirements into diagrams can reveal design faults before building.
**Answer: True** — A requirement with no block, or a block serving no requirement, is found on paper, cheaply.
