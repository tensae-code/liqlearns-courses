# Hands-on — Prototyping and testing solutions

Real practice — this subject is learned by doing.

## Build and test
Build the bottle filter with the four named layers. Test it with the same dirty water before and after, record both, and write whether the prototype meets the specification's need.

## Failure log
Deliberately note every way your prototype falls short (speed, clarity, leaks, taste of the result — observed, not drunk). Rank the failures and write which the next version fixes first.
