# Hands-on — Making a model / maquette from drawings to answer a specification

Real practice — this subject is learned by doing.

## Draw and build
Draw a simple object to a stated size, then build its maquette from your drawing. Measure three parts of the model against the drawing and record the differences.

## Specification check
Write the model's specification as one main function and two constraint functions. Check the finished maquette against each one and record pass or fail for each.
