# Making a model / maquette from drawings to answer a specification — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What must exist before a maquette is built?
a) The finished real product b) Drawings that answer the specification c) A photograph of a similar object d) A price list
**Answer: b) Drawings that answer the specification**

**2. (Sub lesson 1)** The cahier des charges states…
a) Only the colour b) The main function and the constraint functions c) The maker's name only d) Nothing — it is blank
**Answer: b) The main function and the constraint functions**

**3. (Sub lesson 2)** While building, each part is checked against…
a) The maker's memory b) The drawing c) A neighbour's model d) The clock
**Answer: b) The drawing**

**4. (Sub lesson 2)** If a cut part does not match the drawing, the right move is to…
a) Change the drawing quietly b) Hide the part c) Remake the part d) Abandon the model
**Answer: c) Remake the part**

**5. (Sub lesson 3)** A maquette can prove…
a) The real thing's strength b) Shape, proportion and assembly c) Seaworthiness in a storm d) That the product will sell
**Answer: b) Shape, proportion and assembly**
