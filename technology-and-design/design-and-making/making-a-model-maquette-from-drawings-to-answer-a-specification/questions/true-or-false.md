# Making a model / maquette from drawings to answer a specification — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A maquette can be started by cutting material before any drawing exists.
**Answer: False** — The sequence is specification, then drawings, then making — drawings first.

**2. (Sub lesson 2)** The specification stays beside the work while the model is built.
**Answer: True** — Every choice is checked against the drawing and the cahier des charges as building goes on.

**3. (Sub lesson 3)** A cardboard model that floats proves the full-size boat is seaworthy.
**Answer: False** — A model proves shape, proportion and assembly — not strength or seaworthiness.
