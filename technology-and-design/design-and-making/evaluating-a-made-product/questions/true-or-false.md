# Evaluating a made product — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1) Two judges using the same checklist should reach nearly the same verdict.**
**Answer: True**

**2. (Sub lesson 2) A product can be neat and accurate yet fail on functionality.**
**Answer: True — A tidy, true-to-drawing flashlight that does not light has failed its job.**

**3. (Sub lesson 3) If a product works, there is no need to check it against the original need.**
**Answer: False — It can work well and still answer the wrong need.**
