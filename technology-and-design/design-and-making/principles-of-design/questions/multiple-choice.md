# The principles of design — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is a principle of design?
a) a rule for arranging and using the elements b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) a rule for arranging and using the elements**

**2. (Sub lesson 2)** What is an element of design?
a) Only decoration b) one of the things a design is made of — line, shape, form, texture, size, colour, space c) Only a price d) A kind of glue
**Answer: b) one of the things a design is made of — line, shape, form, texture, size, colour, space**

**3. (Sub lesson 2)** What is applying a principle?
a) Only history b) Only painting c) using the rule while designing a real object d) Only storage
**Answer: c) using the rule while designing a real object**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) the principles of design are the rules for arranging the elements — and principles (how) must not be confused with elements (what). b) Only prices c) Only old tools d) Nothing practical
**Answer: a) the principles of design are the rules for arranging the elements — and principles (how) must not be confused with elements (what).**

**5. (Sub lesson 2)** How does Malaysia's book teach this?
a) As theory only, never practised b) Only in the glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Malay (RBT)
**Answer: d) Through the book's own examples, steps and project work, in Malay (RBT)**
