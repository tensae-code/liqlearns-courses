# The principles of design — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A principle of design is a rule for arranging and using the elements.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 2)** An element of design has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: one of the things a design is made of — line, shape, form, texture, size, colour, space.

**3. (Sub lesson 2)** Applying a principle is using the rule while designing a real object.
**Answer: True** — That is how the book teaches it.
