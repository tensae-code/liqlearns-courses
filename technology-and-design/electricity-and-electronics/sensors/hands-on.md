# Hands-on — Sensors

Real practice — this subject is learned by doing.

## Weather-station table
Build the table: Sensor / Measures / Principle / Signal kind (analogue or logic). Fill rows for thermistor and pressostat from the lesson, then add light and level sensors from your own reasoning.

## Garage-door flow
Draw the garage door's information flow: list what must be acquired (position, obstacle, user command), by which sensor each, and one decision that reads each acquisition. Mark what goes blind if the obstacle sensor fails.
