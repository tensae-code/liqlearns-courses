# Lesson plan — Technical functions of a system

**Course:** Technology and Design · **Title:** Electricity and Electronics · **Lesson:** Technical functions of a system
**Place in the curriculum:** Electricity and Electronics (CURRICULUM.md) — stocked in the Morocco expansion, 2026-11-17.
**The one thing this lesson teaches:** a technical object is read part by part through its technical functions: each part carries a function — supply, detect, time, switch, signal, transmit — and naming the functions explains how the whole object works.

## Sub lessons
1. **Reading a technical object part by part** — To understand a technical object, do not start with its shape — start with its parts and ask of each part: what function does it fulfil for the whole? The battery supplies energy, the throttle gives an instruction, the controller processes, the motor converts, the transmission transmits, the wheel acts on the road. The object becomes a chain of functions.
2. **Functions chain together** — Functions are not a list; they are chained. Energy flows through supply → conversion → transmission → action; information flows through detection → processing → signalling. Reading an object means tracing both flows from input to output and naming the function at each step.

## What the learner can do when it ends
1. Read a familiar object part by part, naming each part's technical function.
2. Trace the energy flow and the information flow through one object.
3. Use the function chain to say where a fault most likely sits.
## What you need
A familiar technical object (or its picture): scooter, lamp, fan or bicycle torch.
