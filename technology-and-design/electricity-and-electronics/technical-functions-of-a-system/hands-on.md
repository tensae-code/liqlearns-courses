# Hands-on — Technical functions of a system

Real practice — this subject is learned by doing.

## Function map of a scooter (or lamp)
Draw the object. Label every part you can name, and beside each label write its technical function in one word (supply, convert, transmit…). Join the labels with arrows to show the energy chain.

## Fault finder
A fan turns slowly and its lamp is off. Using the function chain (supply → switch → convert → transmit → act; signal for the lamp), list two places the fault could sit and say how the chain helped you choose them.
