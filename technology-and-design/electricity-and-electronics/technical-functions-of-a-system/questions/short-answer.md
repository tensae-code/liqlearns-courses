# Technical functions of a system — short answer

Answer in one or two sentences.

**1. (Sub lesson 1)** Name the reading method of this lesson in one sentence.
**Answer:** Read the object part by part, name each part's technical function, then trace the chains of functions (energy and information) from input to output.

**2. (Sub lesson 2)** A lamp lights but its timer never switches it off. Which function is faulty?
**Answer:** The timing function — supply, switching and signalling (light) all work; only the time-delay job fails.
