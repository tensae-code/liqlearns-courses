# Technical functions of a system — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** Reading a technical object part by part means asking of each part…
a) what function it fulfils for the whole b) what colour it is c) how much it cost d) who sold it
**Answer: a) what function it fulfils for the whole**

**2. (Sub lesson 1)** Morocco introduces technical functions on…
a) an electric scooter b) a steam train c) a water mill d) a telephone exchange
**Answer: a) an electric scooter**

**3. (Sub lesson 2)** On the scooter, the battery carries the function…
a) supply (energy) b) signalling c) timing d) sorting
**Answer: a) supply (energy)**

**4. (Sub lesson 2)** A scooter does not move but its motor tests healthy. The chain points first to…
a) the supply function — the battery b) the paintwork c) the rider's shoes d) nothing — chains cannot locate faults
**Answer: a) the supply function — the battery**

**5. (Sub lesson 1)** A part can be replaced by a different part if the new part…
a) carries the same function b) looks identical c) costs more d) is older
**Answer: a) carries the same function**
