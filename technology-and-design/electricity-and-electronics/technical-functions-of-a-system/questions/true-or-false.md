# Technical functions of a system — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Functions, not parts, are the stable way to describe a system.
**Answer: True** — Different parts can carry the same function; the function description survives the swap.

**2. (Sub lesson 2)** Energy and information flow through an object in chains of functions.
**Answer: True** — Supply → conversion → transmission → action for energy; detection → processing → signalling for information.

**3. (Sub lesson 2)** If an object fails, its shape tells you where the fault is.
**Answer: False** — The function chain locates faults: follow the flow and test each function's job in turn.
