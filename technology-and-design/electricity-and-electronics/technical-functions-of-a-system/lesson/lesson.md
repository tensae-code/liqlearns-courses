# Technical functions of a system

## Do it first
Take an electric scooter in your mind: battery, controller, throttle, motor, wheels, lamp. For each part ask 'what job does it do for the whole?' Those jobs are its technical functions — Morocco introduces them on exactly this scooter.

## Sub lesson 1 — Reading a technical object part by part
Morocco's Module 2 opens with this reading method on an electric scooter, then gives each great function its own lesson: power supply, detection, timing, switching, signalling, transmission. A part can be replaced by a different part carrying the same function — that is why functions, not parts, are the stable way to describe a system.

## Sub lesson 2 — Functions chain together
When an object fails, the function reading finds the fault: follow the chain and ask at each function 'is this job being done?' A scooter that does not move may have a healthy motor (conversion) but a dead battery (supply) — the chain tells you where to look first. This is the same systems reading as the functional analysis of the First Steps lessons, now applied inside one object.

## Say it to your companion
Explain in your own words: a technical object is read part by part through its technical functions: each part carries a function — supply, detect, time, switch, signal, transmit — and naming the functions explains how the whole object works. Say it once plainly, then answer one question your companion asks about it.
