# Hands-on — Making a working flashlight

Real practice — this subject is learned by doing.

## Build the flashlight
Build the flashlight following the lesson's order, with supervision. Test the switch after each connection stage, not only at the end.

## Contact check
If a built flashlight fails to light, check the contacts in order: battery base, screw-thread, foot contact, switch. Record which fault you found (or 'none — battery flat') and the fix.
