# Electrical circuit diagrams — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** An installation schema shows…
a) A photograph b) Components and connections in standard symbols c) Only prices d) The maker's portrait
**Answer: b) Components and connections in standard symbols**

**2. (Sub lesson 1)** The schema is drawn in…
a) Freehand guesses b) Standard symbols c) Secret codes d) Numbers only
**Answer: b) Standard symbols**

**3. (Sub lesson 2)** Existing installations are compared so that…
a) Time passes b) The schema records a chosen, justified solution c) The drawing looks old d) No choice is needed
**Answer: b) The schema records a chosen, justified solution**

**4. (Sub lesson 2)** A schema drawn before any comparison risks…
a) Being too neat b) Freezing the first idea unexamined c) Using symbols d) Being checked
**Answer: b) Freezing the first idea unexamined**

**5. (Sub lesson 3)** The finished schema is checked against…
a) The weather b) The chosen solution and the components list c) A neighbour's drawing only d) Nothing
**Answer: b) The chosen solution and the components list**
