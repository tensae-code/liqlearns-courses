# Electrical circuit diagrams — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** The schema is the first step of designing an installation.
**Answer: False** — Existing installations are compared and a solution chosen first; the schema records that decision.

**2. (Sub lesson 2)** Every connection in the real installation should appear in its schema.
**Answer: True** — The schema is checked against the components list so nothing needed is missing or unconnected.

**3. (Sub lesson 3)** Any personal symbols are as good as standard symbols in a schema.
**Answer: False** — Standard symbols let anyone read, check and build from the drawing.
