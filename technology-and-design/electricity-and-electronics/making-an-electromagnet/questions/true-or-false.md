# Making an electromagnet — true or false

Say whether each statement is true or false.

**1. (Sub lesson 2) The iron nail makes the electromagnet stronger than the coil alone in air.**
**Answer: True — The iron core concentrates the field.**

**2. (Sub lesson 3) Leaving the coil connected between tests is good practice.**
**Answer: False — It drains and warms the battery; disconnect between tests.**

**3. (Sub lesson 1) Listing the components is the first step of the build.**
**Answer: True**
