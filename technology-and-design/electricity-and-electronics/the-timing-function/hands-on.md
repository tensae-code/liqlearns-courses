# Hands-on — The timing function

Real practice — this subject is learned by doing.

## Barrier timing sheet
Write the automatic barrier's cycle as timed steps: detect → rise (time?) → hold open (set time) → fall. Choose a hold time for a car park and justify it: too short traps the car, too long blocks the road.

## R and C reasoning
A 555 delay must double. Name the two single changes that would do it (double R, or double C) and say what happens to the delay if both are halved instead.
