# The timing function — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Static timing has no moving parts.
**Answer: True** — The NE 555 times electronically, charging a capacitor through a resistor.

**2. (Sub lesson 2)** A timer's contact acts at the start of the count.
**Answer: False** — A delayed contact acts when the set time expires — that delay is the function's whole job.

**3. (Sub lesson 1)** The barrier's hold-open time is a timing-function setting.
**Answer: True** — Detection starts the cycle; timing holds the barrier open for the passage time.
