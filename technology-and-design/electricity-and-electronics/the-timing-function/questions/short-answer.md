# The timing function — short answer

Answer in one or two sentences.

**1. (Sub lesson 1)** How does the NE 555 produce a delay?
**Answer:** It charges a capacitor through a resistor; when the capacitor's voltage reaches the chip's threshold, the output switches — so R and C values set the delay.

**2. (Sub lesson 2)** Give one job for static timing and one for electromechanical timing, with a reason.
**Answer:** Static (555): a precise short delay inside an electronic control — no moving parts. Electromechanical: a robust delay in a high-power switching installation where mechanical contacts are already used.
