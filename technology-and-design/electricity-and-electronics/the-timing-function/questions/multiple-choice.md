# The timing function — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** A delayed contact…
a) changes state only when the set time has run b) changes state instantly, always c) never changes state d) measures voltage
**Answer: a) changes state only when the set time has run**

**2. (Sub lesson 1)** Morocco applies the timing function to…
a) an automatic barrier b) a kettle c) a bicycle d) a printer
**Answer: a) an automatic barrier**

**3. (Sub lesson 2)** In NE 555 static timing, the delay is set by…
a) a resistor and a capacitor (R and C) b) a small motor c) the colour of the chip d) a clock's hands
**Answer: a) a resistor and a capacitor (R and C)**

**4. (Sub lesson 2)** Bigger R or bigger C in a 555 circuit gives…
a) a longer delay b) a shorter delay c) no delay at all d) a louder signal
**Answer: a) a longer delay**

**5. (Sub lesson 2)** Electromechanical timing counts with…
a) a small motor or thermal/mechanical delay b) a capacitor only c) software only d) a water clock
**Answer: a) a small motor or thermal/mechanical delay**
