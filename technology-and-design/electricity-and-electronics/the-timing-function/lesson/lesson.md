# The timing function

## Do it first
Clap, count slowly to five, then clap again. The gap you held is a delay. An automatic barrier does the same: car detected, barrier rises, waits, then falls — the waiting is the timing function's work.

## Sub lesson 1 — Timers and delayed contacts
The delayed contact is the timer's hand: the coil or trigger starts the count, and the contact changes state only when the set time has run. Morocco applies the function to an automatic barrier: detection starts the cycle, timing holds the barrier open for the passage time, then the barrier closes.

## Sub lesson 2 — Static (NE 555) vs electromechanical timing
The 555's delay grows with the resistor and capacitor values: bigger R or bigger C, longer wait. Static timing suits small, exact delays inside electronic systems; electromechanical timing survives rough, high-power switching rooms. Morocco teaches both so the function is recognised in either clothing.

## Say it to your companion
Explain in your own words: the timing function makes a system wait: timers and delayed contacts hold an action for a set time — built two ways, electromechanical timing and static timing with the NE 555 — as on Morocco's automatic barrier. Say it once plainly, then answer one question your companion asks about it.
