# Lesson plan — The signalling function

**Course:** Technology and Design · **Title:** Electricity and Electronics · **Lesson:** The signalling function
**Place in the curriculum:** Electricity and Electronics (CURRICULUM.md) — stocked in the Morocco expansion, 2026-11-17.
**The one thing this lesson teaches:** the signalling function tells the world a system's state: a lamp like H1 lights to say a receiver is working — and signalling is read on a developed electrical diagram, where push-buttons code the signals a system sends.

## Sub lessons
1. **Visual signalling — lamp H1 and a receiver's state** — A signalling device converts a system's internal state into a sign the user can see or hear. Morocco's case is visual: lamp H1 lights to signal that a receiver (a motor, a heater) is in operation. The rule is one sign, one meaning: H1 lit = receiver running; H1 dark = receiver stopped.
2. **Reading a developed electrical diagram; push-button signal coding** — A developed diagram (schéma développé) spreads a circuit out in straight lines — power circuit and control circuit drawn separately, contacts shown at rest, every device carrying its label (H1 for the lamp, S for push-buttons). Push-buttons code commands and signals: press to start, press to stop, each button's action read from its contacts (NO/NC) in the diagram.

## What the learner can do when it ends
1. State the signalling rule 'one sign, one meaning' on the H1 example.
2. Read a small developed diagram: power vs control parts, contacts at rest, labels.
3. Say how push-buttons code start and stop signals.
## What you need
A simple developed diagram (printed or drawn) of a lamp-and-motor circuit.
