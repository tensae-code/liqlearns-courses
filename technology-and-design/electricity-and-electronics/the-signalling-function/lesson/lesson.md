# The signalling function

## Do it first
Look at any machine's pilot lamp: lit means one thing, dark means another. That lamp is signalling. Now find the same lamp on the machine's electrical diagram — reading the diagram is reading the signalling before the machine is even built.

## Sub lesson 1 — Visual signalling — lamp H1 and a receiver's state
Signalling closes the information chain for the human: detection sensed, processing decided, signalling announces. A good signal is visible from the user's place, unambiguous, and tied to the state it claims — H1 is wired so it can only light when the receiver truly runs, never merely when someone hopes it does.

## Sub lesson 2 — Reading a developed electrical diagram; push-button signal coding
Reading the developed diagram is a skill of following current paths: from the supply line, through contacts at rest, to each coil and lamp, asking 'if this button is pressed, what changes?' Morocco teaches the reading on the same circuits the learner wires, so diagram and bench check each other.

## Say it to your companion
Explain in your own words: the signalling function tells the world a system's state: a lamp like H1 lights to say a receiver is working — and signalling is read on a developed electrical diagram, where push-buttons code the signals a system sends. Say it once plainly, then answer one question your companion asks about it.
