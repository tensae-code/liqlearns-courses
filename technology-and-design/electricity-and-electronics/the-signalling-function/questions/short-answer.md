# The signalling function — short answer

Answer in one or two sentences.

**1. (Sub lesson 1)** Why must H1 be wired to the receiver's real state, not to the start button alone?
**Answer:** Because the signal's promise is 'receiver running': wired to the button it could light while the receiver has failed — a lying signal is worse than none.

**2. (Sub lesson 2)** How do you read what a push-button does in a developed diagram?
**Answer:** Find the button's contacts (label S), note NO or NC at rest, then follow the current path through them: pressing changes those contacts, so whatever coil or lamp lies beyond them energises or releases.
