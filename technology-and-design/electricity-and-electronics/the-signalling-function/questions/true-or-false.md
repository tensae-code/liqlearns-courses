# The signalling function — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Signalling announces the system's state to the user.
**Answer: True** — It closes the information chain for the human: detection sensed, processing decided, signalling announces.

**2. (Sub lesson 1)** H1 should be wired so it can light even when the receiver is not running.
**Answer: False** — A signal must be tied to the state it claims — H1 lights only when the receiver truly runs.

**3. (Sub lesson 2)** In a developed diagram, contacts are drawn in their rest state.
**Answer: True** — That convention lets the reader work out what a command will change.
