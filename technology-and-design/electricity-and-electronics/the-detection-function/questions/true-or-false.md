# The detection function — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A TOR detector reports how much of a thing there is.
**Answer: False** — It reports whether — present or absent, reached or not reached — two states only.

**2. (Sub lesson 2)** A system can process information that was never detected.
**Answer: False** — Detection opens the information chain; processing and signalling work on what detection delivers.

**3. (Sub lesson 1)** A robot arm's position can be reported as TOR information.
**Answer: True** — 'In position' or 'not in position' is a two-state, all-or-nothing report.
