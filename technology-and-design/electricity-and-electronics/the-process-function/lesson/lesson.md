# The process function

## Do it first
Write the steps for making tea as boxes and arrows: fill, heat, pour, wait, drink — with one diamond: 'hot enough?' That diamond makes it an algorithm. Morocco draws control the same way, and names its inventor: Al-Khawarizmi.

## Sub lesson 1 — Flowcharts (organigrammes) — the picture of processing
The word algorithm itself is taught with its origin: Al-Khawarizmi, the scholar whose name, latinised, gave 'algorithm' — a finite, ordered set of instructions that solves a problem. The flowchart is that set made visible, and Morocco's process lesson is built on drawing and reading organigrammes for real control tasks.

## Sub lesson 2 — Control from sensor information and instructions
Control is a loop, not a line: acquire → process → command → the world changes → acquire again. The flowchart of a controller therefore loops back on itself while its running condition holds, and exits only when the instruction says stop. Reading the loop — what is tested each turn, what each exit does — is reading the system's behaviour.

## Say it to your companion
Explain in your own words: the process function decides: it treats acquired information against instructions — drawn as a flowchart (organigramme), the algorithm's picture — and commands the system, as a drone's controller reads its whole sensor set. Say it once plainly, then answer one question your companion asks about it.
