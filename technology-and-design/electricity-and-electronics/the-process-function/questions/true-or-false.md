# The process function — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Every test diamond in a flowchart needs both of its exits drawn.
**Answer: True** — A missing exit is an incomplete process — the chart must say what happens on yes and on no.

**2. (Sub lesson 2)** A drone's controller reads its sensors once, at take-off.
**Answer: False** — Control loops continuously: acquire, process, command, many times per second.

**3. (Sub lesson 1)** Instructions alone, without sensor information, are enough for control.
**Answer: False** — Processing joins instructions to acquired information; without sensing, there is nothing to decide from.
