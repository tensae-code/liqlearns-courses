# The process function — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** In a flowchart, a diamond means…
a) a test with yes/no exits b) the end of the chart c) an action d) a sensor
**Answer: a) a test with yes/no exits**

**2. (Sub lesson 1)** The word 'algorithm' carries the name of…
a) Al-Khawarizmi b) a Roman emperor c) a Greek island d) the flowchart's inventor in 1950
**Answer: a) Al-Khawarizmi**

**3. (Sub lesson 1)** An algorithm is…
a) a finite, ordered set of instructions that solves a problem b) any long calculation c) a machine part d) a kind of sensor
**Answer: a) a finite, ordered set of instructions that solves a problem**

**4. (Sub lesson 2)** Processing joins which two inputs?
a) Acquired information and instructions b) Price and weight c) Colour and sound d) The user's wishes twice
**Answer: a) Acquired information and instructions**

**5. (Sub lesson 2)** Control is drawn as a loop because…
a) the system re-acquires and re-decides as the world changes b) paper is round c) one pass is forbidden d) sensors work only twice
**Answer: a) the system re-acquires and re-decides as the world changes**
