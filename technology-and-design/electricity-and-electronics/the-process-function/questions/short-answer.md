# The process function — short answer

Answer in one or two sentences.

**1. (Sub lesson 1)** Define 'algorithm' and name its origin as Morocco teaches it.
**Answer:** An algorithm is a finite, ordered set of instructions that solves a problem; the word comes from the name of the scholar Al-Khawarizmi, latinised.

**2. (Sub lesson 2)** Write the control loop for holding a tank level, in one line per step.
**Answer:** Acquire: read the level sensor. Process: compare with the instructed level. Command: open or close the inlet. Repeat while the system runs; exit on the stop instruction.
