# Lesson plan — The process function

**Course:** Technology and Design · **Title:** Electricity and Electronics · **Lesson:** The process function
**Place in the curriculum:** Electricity and Electronics (CURRICULUM.md) — stocked in the Morocco expansion, 2026-11-17.

## Sub lessons
1. **Flowcharts (organigrammes) — the picture of processing** — A flowchart draws processing as linked symbols: rounded ends for start/finish, rectangles for actions, diamonds for tests (yes/no), arrows for the order. Reading a flowchart is following the arrows and answering each diamond honestly; writing one forces a process to be complete — every test has both exits, every path reaches the end.
2. **Control from sensor information and instructions** — Processing joins two inputs: acquired information (what the sensors say now) and instructions (what the user or programme commands). The drone is the lesson's full case: its sensor set — position, altitude, orientation, obstacle — is acquired continuously, processed against the flight instructions, and turned into motor commands many times per second.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## What the learner can do when it ends
1. Draw and read a simple flowchart with one test diamond.
2. Say what 'algorithm' means and whose name it carries.
3. Describe control as a loop joining sensor information and instructions.
## What you need
Paper for flowcharts; a familiar control task to draw (filling, heating, a drone's hover).
