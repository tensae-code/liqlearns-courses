# The communicate function

## Do it first
Read a digital clock across the room: each digit is seven little bars, some lit, some dark. Count the lit bars in the digit 8 — all seven. That display is a system communicating with you, in the only language it needs: light patterns.

## Sub lesson 1 — Informing the user — displays
A good communication matches the message: a two-state state gets a lamp; a changing value gets a scale or digits; a warning gets a signal that cannot be missed. Morocco's lesson works the function on displays, because the display is where the whole chain becomes visible to the human it serves.

## Sub lesson 2 — The 7-segment display
Reading the display backwards is the maker's check: given a lit pattern, name the digit; given a digit, name its segments. Several displays side by side show multi-digit numbers, each driven by its own code — the principle inside counters, clocks and measuring instruments everywhere.

## Say it to your companion
Explain in your own words: the communicate function informs the user: it turns the system's state and results into displays a person can read — the seven-segment display spelling digits in light is its classic device. Say it once plainly, then answer one question your companion asks about it.
