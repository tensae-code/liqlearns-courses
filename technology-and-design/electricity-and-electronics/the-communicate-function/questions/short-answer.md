# The communicate function — short answer

Answer in one or two sentences.

**1. (Sub lesson 1)** Which segments light for the digit 0, and which single segment stays dark?
**Answer:** All segments except the middle one (g): a, b, c, d, e, f lit; g dark.

**2. (Sub lesson 2)** Why does the chain need a communicate function at all — why not end at process?
**Answer:** Because decisions locked inside the system serve no one: the user must read states and results to trust, use and command the system — communication is where the chain reaches the human.
