# The communicate function — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Communicate is the last function of the information chain.
**Answer: True** — Acquire and process come first; communicate delivers the result to the user and onward.

**2. (Sub lesson 2)** One display device suits every message equally well.
**Answer: False** — The device is matched to the message: lamp for a state, digits for an exact value, an unmissable signal for a warning.

**3. (Sub lesson 1)** Each digit on a 7-segment display is a code of lit and unlit segments.
**Answer: True** — The processor sends the code; the display shows the digit it spells.
