# Lesson plan — The communicate function

**Course:** Technology and Design · **Title:** Electricity and Electronics · **Lesson:** The communicate function

## Sub lessons
1. **Informing the user — displays** — Communicate is the information chain's last function: after acquiring and processing, the system must tell — results, states, warnings — in a form the user reads at a glance. Displays are its devices: lamps for states, dials and screens for values, and digit displays where numbers must be read exactly.
2. **The 7-segment display** — A 7-segment display draws any digit 0–9 by lighting a chosen subset of seven segments (labelled a–g) arranged as a figure-8. Each digit is a code: 0 lights all but the middle segment; 8 lights all seven; 1 lights only the two right segments. The processor sends the code; the display shows the digit.

## What the learner can do when it ends
1. Say what the communicate function must match to the message.
2. Draw the segment pattern for any digit 0–9.
3. Read a lit 7-segment pattern back into its digit.
## What you need
A 7-segment display or clock to observe; segment diagrams on paper.
