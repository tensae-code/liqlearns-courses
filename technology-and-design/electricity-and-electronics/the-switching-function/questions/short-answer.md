# The switching function — short answer

Answer in one or two sentences.

**1. (Sub lesson 1)** Trace the relay's operating principle in order.
**Answer:** Coil energised → magnetic field in the core → armature attracted → contacts change state (NO closes / NC opens) → load circuit made or broken → coil released → spring restores the rest state.

**2. (Sub lesson 2)** Why keep command and power circuits separate?
**Answer:** So a small, safe control signal (low current, near the user) can switch a large or dangerous load without the load's current ever passing through the command side.
