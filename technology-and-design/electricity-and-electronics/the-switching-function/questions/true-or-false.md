# The switching function — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A small command switch can safely switch any load, however big.
**Answer: False** — Switches have current limits; big loads are switched by a relay so the small command stays safe.

**2. (Sub lesson 2)** The relay's armature moves because the coil becomes an electromagnet.
**Answer: True** — Coil current magnetises the core; the attracted armature moves the contacts.

**3. (Sub lesson 1)** An NC contact opens when its device is commanded.
**Answer: True** — Normally closed means closed at rest; command opens it — the opposite of NO.
