# The transmission function — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A belt slipping under overload can protect the machine.
**Answer: True** — Slip is a weakness that doubles as protection: the belt gives before the organs break.

**2. (Sub lesson 2)** Transmission through an intermediate organ is used when the shafts touch each other.
**Answer: False** — The intermediate organ (belt, chain) links shafts at a distance; touching organs transmit directly.

**3. (Sub lesson 1)** Equal pulleys pass the speed unchanged.
**Answer: True** — Size differences are what change speed and turning effect.
