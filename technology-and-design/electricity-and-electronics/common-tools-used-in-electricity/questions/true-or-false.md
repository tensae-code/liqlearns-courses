# Common tools used in electricity — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Identifying the electrical tools is the unit's first lesson.
**Answer: True** — Rwanda opens the electricity unit with the common tools and their uses.

**2. (Sub lesson 2)** Any tool will do for electrical work if you are careful.
**Answer: False** — The right tool is part of the safety of the job — electrical work allows no guessing.

**3. (Sub lesson 2)** Each electrical tool is learned by name and use together.
**Answer: True** — Name plus use is the complete learning for every tool in the kit.
