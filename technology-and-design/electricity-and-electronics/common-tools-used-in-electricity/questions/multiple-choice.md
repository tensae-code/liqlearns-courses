# Common tools used in electricity — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What opens Rwanda's electricity unit?
a) Building circuits b) Identifying the common tools used in electricity c) Prices d) History
**Answer: b) Identifying the common tools used in electricity**

**2. (Sub lesson 1)** Why does identification come first?
a) Electrical work allows no guessing — the right tool is part of safety b) For decoration c) Tools are pretty d) It fills time
**Answer: a) Electrical work allows no guessing — the right tool is part of safety**

**3. (Sub lesson 2)** How is each tool learned?
a) By colour b) By name together with its use c) By weight d) By shop
**Answer: b) By name together with its use**

**4. (Sub lesson 2)** What tasks do the tools serve?
a) Cooking tasks b) Cutting, stripping, joining, testing and fixing in electrical work c) Garden tasks d) Sewing tasks
**Answer: b) Cutting, stripping, joining, testing and fixing in electrical work**

**5. (Sub lesson 1)** A tool you can name but cannot place in the work is…
a) Fully learned b) Only half learned c) The best tool d) Not a tool
**Answer: b) Only half learned**
