# Electronic design — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is a microcontroller?
a) a self-contained control chip b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) a self-contained control chip**

**2. (Sub lesson 1)** What is a microprocessor?
a) Only decoration b) the bare processing heart of a computer system c) Only a price d) A kind of glue
**Answer: b) the bare processing heart of a computer system**

**3. (Sub lesson 2)** What is inside parts?
a) Only history b) Only painting c) the named parts that make up a microcontroller d) Only storage
**Answer: c) the named parts that make up a microcontroller**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) a microcontroller is a self-contained control chip, distinct from a microprocessor — and its inside parts are learned before it is used. b) Only prices c) Only old tools d) Nothing practical
**Answer: a) a microcontroller is a self-contained control chip, distinct from a microprocessor — and its inside parts are learned before it is used.**

**5. (Sub lesson 2)** How does Malaysia's book teach this?
a) As theory only, never practised b) Only in the glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Malay (RBT)
**Answer: d) Through the book's own examples, steps and project work, in Malay (RBT)**
