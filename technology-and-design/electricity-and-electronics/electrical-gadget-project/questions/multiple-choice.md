# Electrical gadget project — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is a circuit design sketch?
a) the drawing of the gadget’s circuit before building b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) the drawing of the gadget’s circuit before building**

**2. (Sub lesson 2)** What is testing the gadget?
a) Only decoration b) checking the built gadget’s function against its design c) Only a price d) A kind of glue
**Answer: b) checking the built gadget’s function against its design**

**3. (Sub lesson 2)** What is evaluating function?
a) Only history b) Only painting c) judging how well the gadget does its job, from test evidence d) Only storage
**Answer: c) judging how well the gadget does its job, from test evidence**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) the electrical gadget project sketches the circuit, builds the gadget working, tests and evaluates its function, and proposes improvements. b) Only prices c) Only old tools d) Nothing practical
**Answer: a) the electrical gadget project sketches the circuit, builds the gadget working, tests and evaluates its function, and proposes improvements.**

**5. (Sub lesson 2)** How does Malaysia's book teach this?
a) As theory only, never practised b) Only in the glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Malay (RBT)
**Answer: d) Through the book's own examples, steps and project work, in Malay (RBT)**
