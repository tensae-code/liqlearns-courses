# Electrical gadget project — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A circuit design sketch is the drawing of the gadget’s circuit before building.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 2)** Testing the gadget has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: checking the built gadget’s function against its design.

**3. (Sub lesson 2)** Evaluating function is judging how well the gadget does its job, from test evidence.
**Answer: True** — That is how the book teaches it.
