| sensor modules (mô đun cảm biến): a module is a circuit containing the sensor and auxiliary electronic components that help the user connect and use the sensor easily in control circuits — in some modules the auxiliary component is a relay, an automatic switch often used to switch circuits on and off; the common modules — the light-sensor module converts light into a control signal (used for automatic lighting systems); the humidity-sensor module converts the environment's humidity (used for automatic watering circuits in smart agriculture); the temperature-sensor module converts temperature (used for automatic temperature-control circuits in life and production) (original string `sensor modules (mô đun cảm biến)`) | Vietnam, *Công nghệ 8*, printed p. 76 |
| practical: assembling control circuits using sensor modules, in five steps (1 study the module — find its supply input port and control output port; 2 study the circuit diagram — identify the main components and how they connect; 3 prepare the tools, materials and equipment; 4 assemble to the diagram; 5 power up, check the working, evaluate and adjust), assessed on correct order, correct firm safe connections, and correct function; three builds — the light-sensor module XH M131 controlling a 12 V LED lamp (its output port: normally-open contact, common terminal, normally-closed contact; supply port GND to the source's negative and VCC to positive; a trimmer potentiometer adjusts the light threshold; the lamp turns on automatically in the dark and off in the light), the temperature-sensor module XH W1209 controlling a 12 V fan (relay contacts K0/K1, digital display and setting buttons for the temperature limit; the fan switches automatically as the sensed temperature crosses the set limit), and the humidity-sensor module controlling a 12 V water pump for automatic plant watering (original string `practical`) | Vietnam, *Công nghệ 8*, printed p. 78 |
