# Casting — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** This lesson teaches casting as its own topic, in full.
**Answer: True** — That is the lesson's topic, as taught in Sri Lanka's textbook.

**2. (Sub lesson 2)** A part you can only point at, but cannot name or explain, is fully learned.
**Answer: False** — You must be able to name it and say what it does.

**3. (Sub lesson 3)** Checking is an extra that can always be skipped.
**Answer: False** — Checking is the last step of the work itself.
