# Sheet metal work — marking out, cutting, sawing, filing and drilling — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Scriber is the pointed tool that scratches fine marking lines on metal.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Centre punch has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: the punch that dents a hole's centre so the drill starts true (سنبه نشان).

**3. (Sub lesson 2)** Snips is the shears that cut thin sheet metal along marked lines.
**Answer: True** — That is how the book teaches it.
