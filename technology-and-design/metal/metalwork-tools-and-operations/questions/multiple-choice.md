# Metalwork — tools and operations — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is centre punch (granete)?
a) a pointed tool that marks a centre so a drill starts true b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) a pointed tool that marks a centre so a drill starts true**

**2. (Sub lesson 1)** What is tracing (trazado)?
a) Only history b) laying out the work lines on the metal before cutting c) Only storage d) A kind of glue
**Answer: b) laying out the work lines on the metal before cutting**

**3. (Sub lesson 2)** What is riveted joint?
a) Only old tools b) Only painting c) a joint made by rivets hammered to clamp the parts d) Only a price
**Answer: c) a joint made by rivets hammered to clamp the parts**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) Only decoration b) Nothing to do with this lesson c) Only history d) metalwork is a named set of tools and operations: files, shears, centre punch, drill, hacksaw and hammer at the bench vice — measuring, tracing, marking, checking, cutting, smoothing, perforating and bending, with riveted joints to join.
**Answer: d) metalwork is a named set of tools and operations: files, shears, centre punch, drill, hacksaw and hammer at the bench vice — measuring, tracing, marking, checking, cutting, smoothing, perforating and bending, with riveted joints to join.**

**5. (Sub lesson 2)** How does Cuba's book teach this?
a) As theory only, never practised b) Only in a glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Spanish
**Answer: d) Through the book's own examples, steps and project work, in Spanish**
