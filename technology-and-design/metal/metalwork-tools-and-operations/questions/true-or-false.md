# Metalwork — tools and operations — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Centre punch (granete) is a pointed tool that marks a centre so a drill starts true.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Tracing (trazado) has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: laying out the work lines on the metal before cutting.

**3. (Sub lesson 2)** Riveted joint is a joint made by rivets hammered to clamp the parts.
**Answer: True** — That is how the book teaches it.
