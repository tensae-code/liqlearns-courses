# Hands-on — Metalwork — tools and operations

Real practice — this subject is learned by doing.

## Order the operations
A sheet-metal box is to be made. Write the operations in order from measuring to finishing, naming the tool for each.

## Tool-to-task match
Match each task — starting a drill hole, cutting a curve in sheet, smoothing an edge, bending a strip — to its tool, and say what goes wrong with the wrong tool.
