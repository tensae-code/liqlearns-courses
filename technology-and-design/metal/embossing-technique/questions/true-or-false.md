# Embossing technique — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Relief is a design raised above its background surface.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Embossing tool has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: a smooth-ended tool that pushes metal into relief without cutting it.

**3. (Sub lesson 2)** Tool pressure is the force applied through the tool, which decides the relief's depth.
**Answer: True** — That is how the book teaches it.
