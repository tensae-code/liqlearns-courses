# Aquaponic design project — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is aquaponics?
a) a system joining fish and plants in one shared water loop b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) a system joining fish and plants in one shared water loop**

**2. (Sub lesson 1)** What is a component?
a) Only decoration b) one named part of the aquaponic system c) Only a price d) A kind of glue
**Answer: b) one named part of the aquaponic system**

**3. (Sub lesson 2)** What is a more efficient design?
a) Only history b) Only painting c) an improved system proposed from evaluating the model d) Only storage
**Answer: c) an improved system proposed from evaluating the model**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) aquaponics joins fish and plants in one water system — designed by sketch, model and evaluation, like any RBT product. b) Only prices c) Only old tools d) Nothing practical
**Answer: a) aquaponics joins fish and plants in one water system — designed by sketch, model and evaluation, like any RBT product.**

**5. (Sub lesson 2)** How does Malaysia's book teach this?
a) As theory only, never practised b) Only in the glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Malay (RBT)
**Answer: d) Through the book's own examples, steps and project work, in Malay (RBT)**
