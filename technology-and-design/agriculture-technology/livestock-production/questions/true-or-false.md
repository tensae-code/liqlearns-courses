# Livestock production — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Livestock production (producción pecuaria) is raising animals for food production.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Sustainable has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: able to keep going without using up what it depends on.

**3. (Sub lesson 2)** Species is a kind of living thing, such as chickens or rabbits.
**Answer: True** — That is how the book teaches it.
