# Cultivation production systems — true or false

Say whether each statement is true or false.

**1. (Sub lesson 2)** In Prakarya, this topic is learned by doing — planning, making and presenting — not only by reading.
**Answer: True** — The guides run every topic through design, production and presentation.

**2. (Sub lesson 3)** Safety procedures can be skipped when a material looks harmless.
**Answer: False** — Prosedur Keselamatan Kerja (workshop safety procedures) come before any making begins.

**3. (Sub lesson 1)** The Indonesian source for this lesson is a teacher guide, held as evidence.
**Answer: True** — The Prakarya teacher guides are EVIDENCE for this lesson and are counted nowhere in the acceptance count.
