# Caring for agricultural tools — maintenance, storage and dangers — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What does maintenance keep the tools in?
a) Boxes b) Good condition c) Water d) Secret
**Answer: b) Good condition**

**2. (Sub lesson 1)** Where are tools stored after use?
a) Anywhere b) In a safe place c) In the field d) Under a bed
**Answer: b) In a safe place**

**3. (Sub lesson 2)** Which dangers does the book name?
a) Noise and dust only b) Cuts from sharp tools and agrochemical mist c) Rain and sun d) None
**Answer: b) Cuts from sharp tools and agrochemical mist**

**4. (Sub lesson 2)** What stands against each danger?
a) Luck b) Precautions while using the tools c) Speed d) Silence
**Answer: b) Precautions while using the tools**

**5. (Sub lesson 1)** Maintenance and storage are…
a) Two unrelated chores b) One discipline: cleaned, kept and put away safely c) Optional d) Only for new tools
**Answer: b) One discipline: cleaned, kept and put away safely**
