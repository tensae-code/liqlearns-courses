# Caring for agricultural tools — maintenance, storage and dangers — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Tools are stored in a safe place after use.
**Answer: True** — Storage in a safe place is its own lesson in the unit.

**2. (Sub lesson 2)** Agrochemical mist is one of the named dangers.
**Answer: True** — The book names cuts from sharp tools and agrochemical mist.

**3. (Sub lesson 2)** The farm's safety teaching is copied from a workshop list.
**Answer: False** — The dangers and precautions are the farm's own — sharp tools and agrochemicals.
