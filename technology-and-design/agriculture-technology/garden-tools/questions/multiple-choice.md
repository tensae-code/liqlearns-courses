# Garden tools — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is maintenance?
a) the cleaning, checking and small repairs that keep a tool working b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) the cleaning, checking and small repairs that keep a tool working**

**2. (Sub lesson 1)** What is edge?
a) Only history b) the sharpened working rim of a cutting tool c) Only storage d) A kind of glue
**Answer: b) the sharpened working rim of a cutting tool**

**3. (Sub lesson 2)** What is storage?
a) Only old tools b) Only painting c) keeping tools in a set dry place, off the ground d) Only a price
**Answer: c) keeping tools in a set dry place, off the ground**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) Only decoration b) Nothing to do with this lesson c) Only history d) every garden tool has its work, its safe way of being used, and its care: a tool that is used right, cleaned and stored lasts and does not hurt its user.
**Answer: d) every garden tool has its work, its safe way of being used, and its care: a tool that is used right, cleaned and stored lasts and does not hurt its user.**

**5. (Sub lesson 2)** How does Cuba's book teach this?
a) As theory only, never practised b) Only in a glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Spanish
**Answer: d) Through the book's own examples, steps and project work, in Spanish**
