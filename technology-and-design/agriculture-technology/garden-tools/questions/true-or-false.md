# Garden tools — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Maintenance is the cleaning, checking and small repairs that keep a tool working.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Edge has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: the sharpened working rim of a cutting tool.

**3. (Sub lesson 2)** Storage is keeping tools in a set dry place, off the ground.
**Answer: True** — That is how the book teaches it.
