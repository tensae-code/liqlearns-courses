# Parts of a commercial fertigation system — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** The nutrient tank is where the fertiliser solution is held.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** A dripper set has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: micro-tubes and nipples that deliver solution to each plant.

**3. (Sub lesson 2)** The three basic components is source, medium and outlet — what every fertigation system must have.
**Answer: True** — That is how the book teaches it.
