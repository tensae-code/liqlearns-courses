# Parts of a commercial fertigation system — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is the nutrient tank?
a) where the fertiliser solution is held b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) where the fertiliser solution is held**

**2. (Sub lesson 1)** What is a dripper set?
a) Only decoration b) micro-tubes and nipples that deliver solution to each plant c) Only a price d) A kind of glue
**Answer: b) micro-tubes and nipples that deliver solution to each plant**

**3. (Sub lesson 2)** What is the three basic components?
a) Only history b) Only painting c) source, medium and outlet — what every fertigation system must have d) Only storage
**Answer: c) source, medium and outlet — what every fertigation system must have**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) a fertigation system has named parts — tank, pump, drippers, filter, timer, graded pipes — built on three basics: source, medium, outlet. b) Only prices c) Only old tools d) Nothing practical
**Answer: a) a fertigation system has named parts — tank, pump, drippers, filter, timer, graded pipes — built on three basics: source, medium, outlet.**

**5. (Sub lesson 2)** How does Malaysia's book teach this?
a) As theory only, never practised b) Only in the glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Malay (RBT)
**Answer: d) Through the book's own examples, steps and project work, in Malay (RBT)**
