# Agricultural production practices — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Compost is rotted organic matter worked into the soil to feed it.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Sowing calendar has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: the plan of what is sown in each season of the year.

**3. (Sub lesson 2)** Biological control is using living enemies of a pest to keep the pest down.
**Answer: True** — That is how the book teaches it.
