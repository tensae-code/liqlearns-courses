# Hands-on — Decorating fabric

Real practice — this subject is learned by doing.

## Leaf print trial
On scrap cloth or paper, print a row using a leaf or a cut vegetable as the stamp (with an adult, following dye/paint safety). Judge which print is cleanest and say why.

## Print or dye?
Examine three decorated cloths. For each decide: printed, dyed, or both — and write the evidence (back of the cloth, feel, edges of the pattern).
