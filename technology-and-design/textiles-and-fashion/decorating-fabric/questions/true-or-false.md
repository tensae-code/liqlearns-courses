# Decorating fabric — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Leaves can be used as printing stamps.
**Answer: True** — Samoa's book prints with leaves among its natural stamps.

**2. (Sub lesson 2)** Printing and dyeing are the same process.
**Answer: False** — Printing colours the surface; dyeing colours the fibre itself.

**3. (Sub lesson 3)** Dye containers should be labelled and kept away from food.
**Answer: True** — That is a basic dye-safety rule.
