# Knitted fabrics — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** One yarn can make a whole weft-knitted fabric.
**Answer: True** — Each loop is drawn through the previous one from a single travelling yarn.

**2. (Sub lesson 2)** Warp knitting is less stable and ladders more easily than weft knitting.
**Answer: False** — Warp knitting gives a more stable cloth that does not ladder as easily.

**3. (Sub lesson 3)** Knitted cloth usually resists creasing better than woven cloth.
**Answer: True** — The loop structure springs back instead of holding a crease.
