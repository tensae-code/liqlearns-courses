# The sewing machine — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A machine stitch uses only one thread.
**Answer: False** — It locks two threads together — one carried by the needle from above, one from below.

**2. (Sub lesson 2)** The motor feeds the material through as the stitches form.
**Answer: True** — Feeding the material is part of the motor-driven work.

**3. (Sub lesson 3)** Hand sewing disappeared completely when machines arrived.
**Answer: False** — Hand sewing with needle and sinew remains the older way, still used beside the machine.
