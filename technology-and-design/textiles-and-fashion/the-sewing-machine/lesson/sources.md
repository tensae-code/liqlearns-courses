Canada's own way (Nunavut): the machine stitch is taught against the community's older way — hand sewing with needle and sinew — named in the placements file as Nunavut's own way of teaching it. That contrast is carried here exactly as the book teaches it.

Samoa's own way: Samoa teaches the sewing machine by investigation — each learner investigates one part (handwheel, spool pin, take-up lever, tension knob, bobbin…) and reports what it does, with the answer table held in the book's appendix. The machine is learned part by part, from the handling up.
