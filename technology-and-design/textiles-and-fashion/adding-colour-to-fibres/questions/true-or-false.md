# Adding colour to fibres — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** The three siapo processes give different kinds of marks.
**Answer: True** — Soaking, rubbing and freehand painting each mark the cloth differently.

**2. (Sub lesson 2)** The upeti's carved pattern appears through rubbing.
**Answer: True** — The cloth takes the raised carved design as colour is rubbed over it.

**3. (Sub lesson 3)** Natural dyes are always better than synthetic dyes in every case.
**Answer: False** — Each dye is evaluated for the fibre and purpose; neither wins automatically.
