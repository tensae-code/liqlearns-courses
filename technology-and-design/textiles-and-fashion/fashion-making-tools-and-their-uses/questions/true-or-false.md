# Fashion-making tools and their uses — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Drafting tools is French curve and L-square/set square — the tools that draw the pattern.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Marking tools has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: tailor’s pencils and chalk, tracing wheel, carbon paper and pins.

**3. (Sub lesson 2)** The sharp-tool rule is store sharp tools in a special container.
**Answer: True** — That is how the book teaches it.
