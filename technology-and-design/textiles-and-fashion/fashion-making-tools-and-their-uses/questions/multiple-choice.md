# Fashion-making tools and their uses — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is drafting tools?
a) French curve and L-square/set square — the tools that draw the pattern b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) French curve and L-square/set square — the tools that draw the pattern**

**2. (Sub lesson 1)** What is marking tools?
a) Only decoration b) tailor’s pencils and chalk, tracing wheel, carbon paper and pins c) Only a price d) A kind of glue
**Answer: b) tailor’s pencils and chalk, tracing wheel, carbon paper and pins**

**3. (Sub lesson 2)** What is the sharp-tool rule?
a) Only history b) Only painting c) store sharp tools in a special container d) Only storage
**Answer: c) store sharp tools in a special container**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) fashion tools are learned in five families — measuring, drafting, cutting, marking, sewing — and sharp tools are stored in a special container. b) Only prices c) Only old tools d) Nothing practical
**Answer: a) fashion tools are learned in five families — measuring, drafting, cutting, marking, sewing — and sharp tools are stored in a special container.**

**5. (Sub lesson 2)** How does Malaysia's book teach this?
a) As theory only, never practised b) Only in the glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Malay (RBT)
**Answer: d) Through the book's own examples, steps and project work, in Malay (RBT)**
