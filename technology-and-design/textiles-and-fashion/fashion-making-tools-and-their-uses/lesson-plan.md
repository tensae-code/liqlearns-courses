# Lesson plan — Fashion-making tools and their uses

**Course:** Technology and Design · **Title:** Textiles and Fashion · **Lesson:** Fashion-making tools and their uses
**Place in the curriculum:** Textiles and Fashion (CURRICULUM.md) — stocked in the Malaysia expansion, 2026-11-17.
**The one thing this lesson teaches:** fashion tools are learned in five families — measuring, drafting, cutting, marking, sewing — and sharp tools are stored in a special container.
**This lesson's own level:** stocked from Malaysia's *Reka Bentuk dan Teknologi* (RBT — Design and Technology) textbooks — see lesson/sources.md. Malaysia counts in the acceptance count (student books, not evidence-only).

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. Picture and GIF numbers are assigned in a later media pass; the slots below are described in words.

## Sub lessons
1. **The tool families** — Fashion tools come in families by job: measuring (ruler, measuring tape), drafting (French curve, L-square/set square), cutting (paper scissors, fabric scissors, snips, seam ripper), marking (tailor’s pencils, tailor’s chalk, tracing wheel and carbon paper, pins), and sewing (thimble, hand needles, sewing machine, embroidery machine) — plus tweezers, hot-glue gun, stapler and tape.
2. **Sharp tools, safe storage** — The families end in a safety rule the book states plainly: store sharp tools in a special container.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: the earlier lessons of Textiles and Fashion. Recommended, never forced.

## What the learner can do when it ends
1. Name the five tool families and their members.
2. State the sharp-tool storage rule and why it exists.
3. Explain how Malaysia's book teaches it.
## What you need
Fashion tools or their pictures, sorted by family.
