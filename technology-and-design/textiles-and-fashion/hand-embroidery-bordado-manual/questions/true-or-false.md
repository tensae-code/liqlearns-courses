# Hand embroidery (bordado manual) — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Embroidery (bordado) is decorating cloth with stitched thread designs.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Graph paper reproduction has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: redrawing a design square by square to change its size.

**3. (Sub lesson 2)** Stitch type is a named embroidery stitch, chosen for the part it fills.
**Answer: True** — That is how the book teaches it.
