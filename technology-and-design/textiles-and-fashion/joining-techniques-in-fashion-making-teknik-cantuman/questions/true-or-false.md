# Joining techniques in fashion making (teknik cantuman) — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Teknik cantuman is joining techniques in fashion making.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Sulaman has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: embroidery — bead, appliqué, thread and ribbon joining that decorates.

**3. (Sub lesson 2)** Tampalan is patching/appliqué joined with glues or wax.
**Answer: True** — That is how the book teaches it.
