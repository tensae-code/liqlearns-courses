# Textile printing — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A weak design can be rescued by very careful cutting.
**Answer: False** — Each step prepares the next; a weak design makes a weak print.

**2. (Sub lesson 2)** Screen printing uses one screen per colour.
**Answer: True** — Each colour is printed through its own prepared mesh.

**3. (Sub lesson 3)** Craft-knife cutting should be slow, supervised and directed away from the body.
**Answer: True** — Knife safety is part of the stencil method.
