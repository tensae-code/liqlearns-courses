# Textile work — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Fabric (tejido) is cloth made from fibres, by weaving, knitting or felting.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** Fibre has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: the fine thread-like unit from which yarn and fabric are made.

**3. (Sub lesson 2)** Thimble (dedal) is a cap worn on the finger to push the needle safely.
**Answer: True** — That is how the book teaches it.
