# Traditional sewing and embroidery techniques — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Embroidery decorates folk garments in the tradition.
**Answer: True** — Folk garments are the lesson's first carriers.

**2. (Sub lesson 1)** Household and ritual objects are never embroidered.
**Answer: False** — Both are named among the decorated things.

**3. (Sub lesson 2)** Traditional ornament and colour form a language to be read before working.
**Answer: True** — The learner reads the ornament, then works it with the ornamental stitches.
