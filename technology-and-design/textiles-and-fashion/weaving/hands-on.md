# Hands-on — Weaving

Real practice — this subject is learned by doing.

## Paper weaving
Cut a card into warp strips still joined at the top. Weave paper strips across in plain weave. Then weave a second piece changing the pattern every row and compare the two.

## Name that weave
Examine three cloths (a towel, a shirt, a smooth dress fabric if available). Decide which weave each uses and write the evidence you saw.
