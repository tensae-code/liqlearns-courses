# Lesson plan — Machine sewing

**Course:** Technology and Design · **Title:** Textiles and Fashion · **Lesson:** Machine sewing
**Place in the curriculum:** Textiles and Fashion (CURRICULUM.md) — stocked in the Iran expansion, 2026-11-17.
**The one thing this lesson teaches:** machine sewing joins the machine's speed to the sewer's control: safety with the machine first, then ironing, simple machine stitching, and a complete make — a pillowcase with French seams.
**This lesson's own level:** stocked from Iran's *Work & Technology, Grade 7* (student book) — see lesson/sources.md. Iran counts in the acceptance count (student books, not evidence-only).

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. Picture and GIF numbers are assigned in a later media pass; the slots below are described in words.

## Sub lessons
1. **Safety and first stitching** — The sewing machine's needle moves faster than any hand can react, so its safety rules are strict: fingers clear of the needle's path, attention on the seam, machine stopped before adjustments.
2. **The pillowcase with French seams** — The module's project is a pillowcase.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson

3. Explain how Iran's book teaches it.
## What you need
A sewing machine if available, fabric, thread, iron and a pillowcase pattern; otherwise the lesson's sequence on paper.
