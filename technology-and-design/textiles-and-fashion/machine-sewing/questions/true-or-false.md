# Machine sewing — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Machine stitching is sewing with the sewing machine's powered needle.
**Answer: True** — That is how the book teaches it.

**2. (Sub lesson 1)** French seam has nothing to do with this lesson.
**Answer: False** — It is part of the lesson: a seam that encloses its raw edges by sewing twice, so nothing frays.

**3. (Sub lesson 2)** Pressing is ironing each seam and part flat as the work proceeds.
**Answer: True** — That is how the book teaches it.
