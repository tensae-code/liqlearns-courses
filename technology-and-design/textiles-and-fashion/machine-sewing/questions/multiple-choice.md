# Machine sewing — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is machine stitching?
a) sewing with the sewing machine's powered needle b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) sewing with the sewing machine's powered needle**

**2. (Sub lesson 1)** What is French seam?
a) Only history b) a seam that encloses its raw edges by sewing twice, so nothing frays c) Only storage d) A kind of glue
**Answer: b) a seam that encloses its raw edges by sewing twice, so nothing frays**

**3. (Sub lesson 2)** What is pressing?
a) Only old tools b) Only painting c) ironing each seam and part flat as the work proceeds d) Only a price
**Answer: c) ironing each seam and part flat as the work proceeds**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) Only decoration b) Nothing to do with this lesson c) Only history d) machine sewing joins the machine's speed to the sewer's control: safety with the machine first, then ironing, simple machine stitching, and a complete make — a pillowcase with French seams.
**Answer: d) machine sewing joins the machine's speed to the sewer's control: safety with the machine first, then ironing, simple machine stitching, and a complete make — a pillowcase with French seams.**

**5. (Sub lesson 2)** How does Iran's book teach this?
a) As theory only, never practised b) Only in a glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Persian
**Answer: d) Through the book's own examples, steps and project work, in Persian**
