# Seam and stitch reference tables — short answer

Answer in one or two sentences.

**1. (Sub lesson 1)** Say in one sentence what this lesson teaches.
**Answer:** Seam and stitch reference tables — the appendix tables: seam kinds drawn and described (петельный, обмёточная, козлик, крестообразный, потайной…) with what each is used for; decorative stitches (шов «вперёд иголку», тамбурный); ribbon-embroidery and bead-embroidery stitch charts (Appendix Tables 3–6, viewed by me).

**2. (Sub lesson 2)** Name one material, tool or step this lesson works with.
**Answer:** Any one named in the lesson text — for example, the first step of sub lesson 1: Seam and stitch reference tables.
