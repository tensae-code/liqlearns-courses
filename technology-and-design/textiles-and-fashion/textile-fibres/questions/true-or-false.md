# Textile fibres — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Synthetic and regenerated fibres are both manufactured, but start from different materials.
**Answer: True** — Synthetic fibres start from chemical building blocks; regenerated fibres start from cellulose.

**2. (Sub lesson 2)** Wool, angora, mohair and cashmere are all animal fibres.
**Answer: True** — All four are named as animal fibres in the Finnish cards.

**3. (Sub lesson 3)** A fibre's life cycle has nothing to do with how it should be cared for.
**Answer: False** — The cards treat properties, life cycle and care together for every fibre.
