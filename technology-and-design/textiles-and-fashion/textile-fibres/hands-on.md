# Hands-on — Textile fibres

Real practice — this subject is learned by doing.

## Sort real labels
Collect five clothing labels (your own clothes are enough). For each one, write the fibres named and sort each fibre into its family: synthetic, regenerated, protein-based or animal. Note any label you cannot sort and what you would need to find out.

## Care plan for wool
Write a short care plan for a sheep's wool item: how it should be washed, dried and stored so it lasts, and why animal fibres need gentler handling than a hard-wearing synthetic.
