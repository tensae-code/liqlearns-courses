# Fabric printing techniques — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** A printed pattern sits on the fabric's surface in definite shapes.
**Answer: True** — Printing applies pigment to the surface where the pattern belongs.

**2. (Sub lesson 2)** Wet prints should be stacked immediately to save time.
**Answer: False** — Each print must dry before stacking, or it will smudge.

**3. (Sub lesson 3)** Fabric printing in Finnish craft material is called kuviointi.
**Answer: True** — Kuviointi is the material's word for the patterning/printing work.
