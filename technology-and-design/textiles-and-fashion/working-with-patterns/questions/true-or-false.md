# Working with patterns — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** The whole layout should be planned before any cutting begins.
**Answer: True** — Cut only when the whole garment fits on the cloth.

**2. (Sub lesson 2)** Off-grain pieces hang straight and true.
**Answer: False** — Cloth cut off-grain hangs twisted.

**3. (Sub lesson 3)** A fold edge placed slightly off the fold still opens out symmetrical.
**Answer: False** — It opens lopsided; the edge must sit exactly on the fold.
