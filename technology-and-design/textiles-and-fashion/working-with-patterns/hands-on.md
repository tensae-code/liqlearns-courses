# Hands-on — Working with patterns

Real practice — this subject is learned by doing.

## Two widths
Using paper pieces for a simple top, plan the layout twice: on 90 cm-wide paper and on 115 cm-wide paper. Record how the arrangement changed and which wasted less.

## Grain check
Lay a pattern piece on cloth twice — once with the grain line parallel to the selvedge (measure both ends), once deliberately off — and note how each hangs when lifted.
