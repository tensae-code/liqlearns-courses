# Fashion design — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is fashion design?
a) the design of clothing and how it is worn b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) the design of clothing and how it is worn**

**2. (Sub lesson 2)** What is a type of fashion design?
a) Only decoration b) one division of the field, designing for a different wearer or occasion c) Only a price d) A kind of glue
**Answer: b) one division of the field, designing for a different wearer or occasion**

**3. (Sub lesson 2)** What is placing a garment?
a) Only history b) Only painting c) assigning a garment to its fashion type with reasons d) Only storage
**Answer: c) assigning a garment to its fashion type with reasons**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) fashion design is a defined design field with named types — each type designs for a different wearer and occasion. b) Only prices c) Only old tools d) Nothing practical
**Answer: a) fashion design is a defined design field with named types — each type designs for a different wearer and occasion.**

**5. (Sub lesson 2)** How does Malaysia's book teach this?
a) As theory only, never practised b) Only in the glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Malay (RBT)
**Answer: d) Through the book's own examples, steps and project work, in Malay (RBT)**
