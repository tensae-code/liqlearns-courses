# Adding texture to textiles — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Texture is chosen for a purpose and an effect, like colour.
**Answer: True** — Designers plan the surface as deliberately as the pattern.

**2. (Sub lesson 2)** Sinnet work lies flat and invisible in the textile.
**Answer: False** — Sinnet lays a raised cord pattern — relief that is also structure.

**3. (Sub lesson 3)** A printed feather pattern gives the same texture as real woven-in feathers.
**Answer: False** — Print imitates the look, not the depth and feel.
