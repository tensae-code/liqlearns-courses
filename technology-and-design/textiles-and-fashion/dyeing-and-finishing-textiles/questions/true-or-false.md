# Dyeing and finishing textiles — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Dye additives and mordants help a dyeing succeed.
**Answer: True** — Additives help the process and mordants help the dye bind.

**2. (Sub lesson 2)** Oxidising and reducing bleaching agents are the same thing.
**Answer: False** — They are two different families of agents with the same lightening job.

**3. (Sub lesson 3)** Finishing can only be done chemically.
**Answer: False** — Finishing can be mechanical or chemical.
