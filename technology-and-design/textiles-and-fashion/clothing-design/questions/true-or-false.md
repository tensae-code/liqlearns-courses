# Clothing design — true or false

Say whether each statement is true or false.

**1. (Sub lesson 1)** Clothing design is a staged creation process.
**Answer: True** — Study and ideas first, implementation in clothing last.

**2. (Sub lesson 1)** Implementation comes before theoretical study.
**Answer: False** — The stages run study → ideas → implementation.

**3. (Sub lesson 2)** The principles judge choices from sketch to garment.
**Answer: True** — They govern the whole process.
