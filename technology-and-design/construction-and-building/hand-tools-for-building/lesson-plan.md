# Lesson plan — Hand tools for building

**Course:** Technology and Design · **Title:** Construction and Building · **Lesson:** Hand tools for building
**Place in the curriculum:** Construction and Building (CURRICULUM.md) — stocked in the Samoa expansion, 2026-11-17.
**The one thing this lesson teaches:** building hand tools mark out, measure, cut and shape: string lines set out the work, chisels shape, spirit levels true it, tape rules size it, the marking gauge lines it, saws cut it — each cared for and used safely.
**This lesson's own level:** it stands on student book evidence — Samoa's MESC textbooks (see lesson/sources.md). It counts in the acceptance count (student book, not evidence-only).

A lesson plan also says **what goes on top of the lesson**: at the exact places marked below, the lesson page carries an add-on — an image, a GIF, a video, an audio. Every slot is written as **"a picture of …" in words, plus one little line saying what the student does with it**. Picture and GIF numbers are assigned in a later media pass; the slots below are described in words.

## Sub lessons
1. **Setting out and measuring — string lines, tape rules, spirit levels** — Work begins true or it never becomes true: string lines carry straight lines across a site, tape rules give sizes, spirit levels give level and plumb.
2. **Cutting and shaping — saws, chisels, the marking gauge, the sliding bevel** — Crosscut and panel saws cut timber; chisels pare and shape; the marking gauge scribes lines parallel to an edge; the sliding bevel copies and sets angles.
3. **Care and safe use** — A cared-for tool is accurate and safe; a neglected one is neither.

Gate pool: all questions of the sub lesson — no hardness ranking is written in questions/, so the sub lesson's whole question set is the gate pool.

## Before this lesson
- Recommended first: the earlier lessons of Construction and Building. Recommended, never forced.

## What the learner can do when it ends
1. Set out with a string line and prove level with a spirit level.
2. Match saw, chisel, gauge and bevel to their jobs.
3. State care and safety rules for building hand tools.
## What you need
Access to basic building tools for the hands-on, under supervision.
