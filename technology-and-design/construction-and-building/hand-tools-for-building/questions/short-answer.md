# Hand tools for building — short answer

Answer in one or two sentences.

**1. (Sub lesson 1)** Name the three setting-out/measuring tools in this lesson and each one's job.
**Answer:** Answer: String line (straight line across the site), tape rule (sizes), spirit level (proves level and plumb).

**2. (Sub lesson 3)** Give three care or safety rules for edged hand tools.
**Answer:** Answer: Any three of: keep edges sharp and guarded, clamp the work, hands behind the edge, carry point-down, clean and store dry, check handles before use.
