# Hands-on — Hand tools for building

Real practice — this subject is learned by doing.

## Set out a rectangle
With pegs and string lines, set out a 2 m × 1 m rectangle on the ground. Check the diagonals are equal — equal diagonals prove the corners square.

## Tool audit
Lay out the building tools available. For each: name it, state its job, check its condition (edge, handle, cleanliness) and record one care action it needs.
