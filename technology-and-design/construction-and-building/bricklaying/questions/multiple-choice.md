# Bricklaying — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is trowel?
a) the bricklayer's flat tool for spreading mortar and bedding bricks b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) the bricklayer's flat tool for spreading mortar and bedding bricks**

**2. (Sub lesson 1)** What is spirit level?
a) Only history b) the tool that proves a course horizontal and a face vertical c) Only storage d) A kind of glue
**Answer: b) the tool that proves a course horizontal and a face vertical**

**3. (Sub lesson 2)** What is stretcher bond?
a) Only old tools b) Only painting c) the bond where every brick shows its long face, courses offset by half a brick d) Only a price
**Answer: c) the bond where every brick shows its long face, courses offset by half a brick**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) Only decoration b) Nothing to do with this lesson c) Only history d) bricklaying builds a true wall course by course: trowel, spirit level and straightedge govern the work, and the half-brick wall rises in stretcher bond following a work flowchart.
**Answer: d) bricklaying builds a true wall course by course: trowel, spirit level and straightedge govern the work, and the half-brick wall rises in stretcher bond following a work flowchart.**

**5. (Sub lesson 2)** How does Iran's book teach this?
a) As theory only, never practised b) Only in a glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Persian
**Answer: d) Through the book's own examples, steps and project work, in Persian**
