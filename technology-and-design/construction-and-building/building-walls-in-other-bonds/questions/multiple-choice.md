# Building walls in other bonds — multiple choice

Pick the one right answer.

**1. (Sub lesson 1)** What is header bond?
a) the bond where every brick shows its end face, tying across the wall b) Only a price c) Only decoration d) Nothing to do with this lesson
**Answer: a) the bond where every brick shows its end face, tying across the wall**

**2. (Sub lesson 1)** What is header-and-stretcher bond?
a) Only history b) the bond alternating header and stretcher courses c) Only storage d) A kind of glue
**Answer: b) the bond alternating header and stretcher courses**

**3. (Sub lesson 2)** What is bond?
a) Only old tools b) Only painting c) the pattern in which bricks are laid so the wall holds together d) Only a price
**Answer: c) the pattern in which bricks are laid so the wall holds together**

**4. (Sub lesson 1)** What does this lesson teach, in one line?
a) Only decoration b) Nothing to do with this lesson c) Only history d) a one-brick wall needs stronger patterns: header bond, all ends showing, and header-and-stretcher bond, courses alternating — each bond tying the thicker wall together.
**Answer: d) a one-brick wall needs stronger patterns: header bond, all ends showing, and header-and-stretcher bond, courses alternating — each bond tying the thicker wall together.**

**5. (Sub lesson 2)** How does Iran's book teach this?
a) As theory only, never practised b) Only in a glossary c) Only as an exam d) Through the book's own examples, steps and project work, in Persian
**Answer: d) Through the book's own examples, steps and project work, in Persian**
