# Nine values our community lives by — multiple choice

Pick the one right answer.

**1.** What does this lesson teach?
a) The contents name the community's core values one by one: cooperation, tolerance, inclusiveness, meaningful participation, mutual respect, hospitality, integrity, accepting others' ideas, and hope.  b) A topic from a different level of this course  c) The syllabus of the teacher guide  d) none of these
**Answer: a)** — That is what this lesson teaches.

**2.** Which of these belongs to this lesson?
a) The nine core community values  b) a topic from another course  c) today's weather  d) none of these
**Answer: a)** — That is this lesson's first part.
