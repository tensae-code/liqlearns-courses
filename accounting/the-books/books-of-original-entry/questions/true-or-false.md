# Books of Original Entry — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** Source documents as the documentary evidence every record starts from: what a source document is, that it proves the transaction took place and is filed for reference, and the first of them — the …. (Sub lesson 1)
**Answer: True** — That is what this lesson teaches.

**2.** This lesson teaches the opposite of its one thing: it does not teach that before anything reaches the ledger, each transaction is first written, in time order, in a book of original entry — a journal fed by a source document that proves the transaction happened. (Sub lesson 1)
**Answer: False** — The lesson teaches exactly that: before anything reaches the ledger, each transaction is first written, in time order, in a book of original entry — a journal fed by a source document that proves the transaction happened.
