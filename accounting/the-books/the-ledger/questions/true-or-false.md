# The Ledger — true or false

Say whether each statement is true or false, and be ready to say why.

**1.** What the ledger is: the main book of accounts, one account for each item, an account as the T-shaped chronological record of everything affecting that item, with its title, debit (left) and credit …. (Sub lesson 1)
**Answer: True** — That is what this lesson teaches.

**2.** This lesson teaches the opposite of its one thing: it does not teach that the ledger is the main book of accounts: one account for each item, where every transaction is classified and summarised so the balance of any item can be found at any date. (Sub lesson 1)
**Answer: False** — The lesson teaches exactly that: the ledger is the main book of accounts: one account for each item, where every transaction is classified and summarised so the balance of any item can be found at any date.
